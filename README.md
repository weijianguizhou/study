## 如何使用本仓库

### 方式一：Obsidian 浏览（推荐）

用 [Obsidian](https://obsidian.md/) 打开此文件夹作为 Vault：

- **图谱视图**：可视化全部笔记的关联网络（430+ 条 `[[双向链接]]`）
- **MOC 入口**：从 `00-知识索引.md` 开始，逐层进入各领域
- **LaTeX 渲染**：`$...$` 和 `$$...$$` 数学公式直接显示
- **全文搜索**：`Ctrl+Shift+F` 搜索任意概念

### 方式二：直接阅读 Markdown

所有 `.md` 文件可在 GitHub/Gitee 直接预览，数学公式可配合浏览器插件（如 MathJax）渲染。

### 方式三：编译 LaTeX 教程

系统性教程为 `.tex` 格式，需 XeLaTeX 编译：

```bash
# 例：深度学习教程
cd 人工智能/深度学习教程/LaTeX
xelatex main.tex && xelatex main.tex   # 两次编译生成目录
```

> 环境要求：TeX Live 2024+，ctex 宏包（自动配置中文字体）。
