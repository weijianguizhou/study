# 25-逆运动学

正运动学：给关节角 → 算末端位姿（**唯一解**）。
逆运动学：给末端位姿 → 反推关节角（**可能0个、多个、或无穷个解**）。

---

# 复习一下逆运动学

## 1. 为什么逆运动学难

正运动学只是乘一堆三角函数矩阵——虽然复杂但是确定性的。逆运动学倒过来——从末端位姿反解关节角——意味着解非线性三角方程组。$\sin\theta$和$\cos\theta$搅在一起，直接解代数方程通常很难。

而且多解性来了：同一个末端位姿，关节角可以有不同组合。比如你伸手够桌子上的杯子——肘可以向上拐也可以向下拐，都能让手到同一个位置。这就对应逆运动学的两个不同解。

## 2. 2R机械臂的解析解

在平面里，两段连杆的末端位置具有简单的几何关系。用**余弦定理**：

$$x^2 + y^2 = L_1^2 + L_2^2 + 2L_1L_2\cos q_2$$

解出$\cos q_2$：

$$\cos q_2 = \frac{x^2 + y^2 - L_1^2 - L_2^2}{2L_1L_2}$$

$\sin q_2$有两种可能（$+\sqrt{1-c^2}$是肘向上，$-\sqrt{1-c^2}$是肘向下）。$q_2 = \operatorname{atan2}(\sin q_2, \cos q_2)$。

有了$q_2$，$q_1$由末端位置的极角减去第二段在$q_1$处的偏转角算出来。

## 3. 数值解——雅可比逆迭代

超过6自由度或几何太复杂（比如含球腕）时，解析解几乎不可能。这时用**迭代法**：从一个初始猜测开始，每一步用雅可比矩阵算出"往哪个方向调整关节角能缩小末端误差"。

$$\Delta \mathbf{x} = J(\mathbf{q}) \Delta \mathbf{q} \quad \implies \quad \Delta \mathbf{q} = J^{-1} \Delta \mathbf{x}$$

不断迭代直到$\|\mathbf{x}_{target} - \mathbf{x}_{actual}\| < \epsilon$。

这个方法的问题是：当$J$接近奇异时（机器人把胳膊伸得太直），$\Delta \mathbf{q}$会异常大——算法发散。实际中用**阻尼最小二乘**(Levenberg-Marquardt)：给$\Delta \mathbf{q}$加个惩罚项，不让它太大。

## 4. 可达性

不是随便给一个位姿机器人都够得着——关节有物理限位，连杆长度是固定的。位姿要求可能落在**工作空间**之外。这时逆运动学无解。实际中要先判断目标是否可达，不行就提示用户或"松弛"目标（比如只要求位置正确，姿态可以不同）。

# MATLAB实现

**解析解(2R)**：

```matlab
function [q1, q2] = ik_2R(px, py, L1, L2)
    c2 = (px^2 + py^2 - L1^2 - L2^2) / (2*L1*L2);
    c2 = max(-1, min(1, c2));     % 防止浮点越界
    s2_up = sqrt(1 - c2^2);       % 肘向上
    s2_dn = -sqrt(1 - c2^2);      % 肘向下
    
    q2_up = atan2(s2_up, c2);
    q2_dn = atan2(s2_dn, c2);
    q1_up = atan2(py, px) - atan2(L2*s2_up, L1 + L2*c2);
    q1_dn = atan2(py, px) - atan2(L2*s2_dn, L1 + L2*c2);
end
```

**数值解（雅可比逆迭代）**：

```matlab
q = zeros(6,1);   % 初始猜测
for iter = 1:100
    T = forward_kinematics(q);
    err = pose_error(T, target);   % 6维误差
    if norm(err) < 1e-6, break; end
    J = compute_jacobian(q);
    dq = J \ err;                  % 伪逆求解
    q = q + 0.5 * dq;
end
```

`J \ err`比`inv(J)*err`好——`\`自动处理奇异和非方阵。
