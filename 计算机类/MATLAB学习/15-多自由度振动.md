# 15-多自由度振动

$M\ddot{\mathbf{q}} + C\dot{\mathbf{q}} + K\mathbf{q} = \mathbf{F}$

---

# 一、二自由度系统

```matlab
m1 = 1; m2 = 1; k1 = 2; k2 = 2; k3 = 2;
M = diag([m1, m2]);
K = [k1+k2, -k2; -k2, k2+k3];
C = 0.02 * K;              % 比例阻尼

% 特征分析
[V, D] = eig(K, M);
omega_n = sqrt(diag(D));    % 固有频率
fprintf('固有频率: %.3f, %.3f rad/s\n', omega_n);

% 时域仿真
odefun = @(t, y) [y(3:4);
                  -M\(C*y(3:4) + K*y(1:2))];
[t, y] = ode45(odefun, [0, 30], [1; 0; 0; 0]);

plot(t, y(:,1:2)); legend('x1', 'x2');
```

---

# 二、模态分析

```matlab
[V, D] = eig(K, M);
omega = sqrt(diag(D));          % 固有频率（从小到大）
[omega_sorted, idx] = sort(omega);
modes = V(:, idx);              % 振型（对应排序后的频率）

for i = 1:length(modes)
    fprintf('模态%d: ω = %.3f rad/s\n', i, omega_sorted(i));
end
```

# 三、频响函数（多自由度）

```matlab
omega_vec = linspace(0.1, 5, 500);
n_dof = 2;
H = zeros(n_dof, n_dof, length(omega_vec));

for k = 1:length(omega_vec)
    H(:,:,k) = (-M*omega_vec(k)^2 + 1i*C*omega_vec(k) + K) \ eye(n_dof);
end

for i = 1:n_dof
    semilogy(omega_vec, squeeze(abs(H(i,i,:)))); hold on;
end
```
