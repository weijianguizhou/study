# 18-四元数与姿态动力学

四元数$q = w + xi + yj + zk$，单位四元数对应一个三维旋转。比旋转矩阵紧凑，无缝插值。

---

# 一、四元数的基本操作

```matlab
q = [1; 0; 0; 0];              % [w; x; y; z] 恒等旋转

% 四元数乘法 q3 = q1 * q2
quatmultiply = @(q1, q2) ...
    [q1(1)*q2(1) - q1(2:4)'*q2(2:4);
     q1(1)*q2(2:4) + q2(1)*q1(2:4) + cross(q1(2:4), q2(2:4))];
```

---

# 二、四元数 → 旋转矩阵

```matlab
function R = quat2rot(q)
    w = q(1); x = q(2); y = q(3); z = q(4);
    R = [1-2*(y^2+z^2), 2*(x*y-w*z), 2*(x*z+w*y);
         2*(x*y+w*z), 1-2*(x^2+z^2), 2*(y*z-w*x);
         2*(x*z-w*y), 2*(y*z+w*x), 1-2*(x^2+y^2)];
end
```

---

# 三、四元数运动学方程

$$\dot{q} = \frac{1}{2} q \otimes \begin{pmatrix} 0 \\ \omega \end{pmatrix}$$

```matlab
function dq = quat_kinematics(q, omega)
    Omega = [0, -omega'; omega, -skew(omega)];
    dq = 0.5 * Omega * q;
end
```

# 四、完整6-DOF航天器仿真

```matlab
m = 100; I = diag([50, 80, 30]);
r0 = [0;0;0]; v0 = [10;0;0];   % 位置速度
q0 = [1;0;0;0]; w0 = [0.1;0.2;0];  % 姿态

y0 = [r0; v0; q0; w0];
[t, y] = ode45(@(t,y) spacecraft_eom(t,y,m,I), [0 60], y0);

% 可视化轨迹
plot3(y(:,1), y(:,2), y(:,3)); xlabel('x'); ylabel('y'); zlabel('z');

function dydt = spacecraft_eom(~, y, m, I)
    r = y(1:3); v = y(4:6);
    q = y(7:10); q = q / norm(q);
    w = y(11:13);
    R = quat2rot(q);
    F = [0; 0; 0]; tau = [0; 0; 0];     % 无力矩
    dr = v; dv = F / m;
    dq = quat_kinematics(q, w);
    dw = I \ (tau - cross(w, I*w));
    dydt = [dr; dv; dq; dw];
end
```
