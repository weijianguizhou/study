# 一、六轴工业机器人DH表

```matlab
% 典型的KUKA/ABB式6R机器人
DH = [0,   0.3, 0,    pi/2;       % 关节1: 腰部旋转
      0,   0,   0.5, 0;           % 关节2: 大臂
      0,   0,   0,    pi/2;       % 关节3: 肘
      0,   0.4, 0,   -pi/2;      % 关节4: 腕部旋转
      0,   0,   0,    pi/2;       % 关节5
      0,   0.1, 0,   0];         % 关节6
```

# 二、正运动学

跟2R完全一样——循环乘DH矩阵。6个关节乘6次。

```matlab
T = eye(4);
for i = 1:6
    T = T * DH_transform(DH(i,1)+q(i), DH(i,2), DH(i,3), DH(i,4));
end
```

# 三、CTC控制（扩展到6轴）

```matlab
Kp = diag([500, 500, 300, 200, 150, 100]);
Kd = diag([80, 80, 50, 30, 20, 15]);

e = q_ref - q; de = dq_ref - dq;

% M, C, G 现在都是6×6和6×1了
M = six_axis_mass_matrix(q);  % 6×6
C = coriolis_matrix(q, dq);   % 6×6
G = gravity_vector(q);        % 6×1

tau = M * (ddq_ref + Kd*de + Kp*e) + C*dq + G;
```

# 四、计算性能技巧

6轴的$M$矩阵是$6\times6$的满阵。如果每个ode步都手动算，很慢。优化：

```matlab
% 1. 用符号工具箱预推导，导出matlabFunction
% 2. 用MEX编译成C（MATLAB Coder）
% 3. 用Simscape (让它算)
% 4. 向量化所有矩阵运算
```
