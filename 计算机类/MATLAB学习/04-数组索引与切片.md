# 04-数组索引与切片

MATLAB的索引用法比Python灵活，而且**索引从1开始**（跟数学书籍一致）。

---

# 一、基本索引

```matlab
A = [10, 20, 30, 40, 50];
A(1)        % 10  第一个（不是0！）
A(3)        % 30
A(end)      % 50  最后一个
A(end-1)    % 40  倒数第二个
```

---

# 二、矩阵索引

```matlab
A = [1, 2, 3;
     4, 5, 6;
     7, 8, 9];

A(2, 3)        % 6  第2行第3列
A(3, :)        % [7, 8, 9]  第3行所有列
A(:, 2)        % [2; 5; 8]  第2列所有行
A(2:3, 1:2)    % [4,5; 7,8]  第2-3行，第1-2列
```

---

# 三、线性索引（逐列数）

MATLAB按**列优先**顺序存矩阵。所以你可以把一个二维矩阵当一维来索引：

```matlab
A = [1 4 7;
     2 5 8;
     3 6 9];   % 内存顺序: 1,2,3,4,5,6,7,8,9

A(3)    % 2  (第3个元素，逐列数)
A(6)    % 8
```

---

# 四、逻辑索引

```matlab
x = [5, -3, 0, 8, -1, 2];
pos = x(x > 0)           % [5, 8, 2]  只取正数
x(x < 0) = 0             % 把负数全变成0  → [5, 0, 0, 8, 0, 2]

A = rand(3);
A(A > 0.5) = 1;          % 大于0.5的都变成1
```

逻辑索引是MATLAB里最常用的筛选手法——不用写循环。

---

# 五、赋值

```matlab
A = zeros(3, 4);
A(2, :) = [10, 20, 30, 40];   % 改第2行
A(:, 3) = 99;                  % 改第3列为全99
A(1:2, 1:2) = [1 2; 3 4];     % 改子矩阵
```

---

# 六、删除

```matlab
A(:, 2) = [];     % 删除第2列
A(3, :) = [];     % 删除第3行
```
