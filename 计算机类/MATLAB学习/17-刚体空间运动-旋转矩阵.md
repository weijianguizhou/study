# 17-刚体空间运动(旋转矩阵)

三维旋转$R \in SO(3)$满足$R^T R = I,\; \det(R)=1$。

---

# 一、旋转矩阵生成

```matlab
Rx = @(a) [1,0,0; 0,cos(a),-sin(a); 0,sin(a),cos(a)];
Ry = @(a) [cos(a),0,sin(a); 0,1,0; -sin(a),0,cos(a)];
Rz = @(a) [cos(a),-sin(a),0; sin(a),cos(a),0; 0,0,1];

R = Rz(0.3) * Ry(0.2) * Rx(0.1);   % ZYX欧拉角
```

---

# 二、角速度与旋转矩阵的微分

$$\dot{R} = R [\omega]_\times$$

其中$[\omega]_\times$是角速度$\omega$的反对称矩阵：

```matlab
skew = @(w) [0, -w(3), w(2);
             w(3), 0, -w(1);
             -w(2), w(1), 0];
```

---

# 三、Euler方程（无外力）

$$I\dot{\omega} + \omega \times (I\omega) = 0$$

```matlab
I = diag([1, 2, 3]);                % 主惯性矩
omega0 = [0.5; 0.1; 2.0];           % 初始角速度

odefun = @(t, w) -I \ (cross(w, I*w));
[t, w] = ode45(odefun, [0, 30], omega0);
plot(t, w); legend('ω_x', 'ω_y', 'ω_z');
```

这叫**无力矩陀螺**——角速度在体坐标系中绕最大惯性轴旋转。

---

# 四、Euler方程（有力矩）

$$I\dot{\omega} + \omega \times (I\omega) = \tau$$

加上旋转矩阵积分同步更新姿态：

```matlab
odefun = @(t, y) rigid_body_eom(t, y, I);
[t, y] = ode45(odefun, [0, 10], [eye(3); omega0]);

function dydt = rigid_body_eom(~, y, I)
    R = reshape(y(1:9), [3,3]);
    w = y(10:12);
    dR = R * skew(w);
    dw = I \ (-cross(w, I*w));
    dydt = [dR(:); dw];
end
```
