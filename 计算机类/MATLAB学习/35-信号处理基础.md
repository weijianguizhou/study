# 一、滤波器设计

```matlab
% 低通Butterworth滤波器
fc = 50; fs = 1000;                % 截止频率50Hz, 采样率1kHz
[b, a] = butter(4, fc/(fs/2), 'low');   % 4阶
y_filtered = filtfilt(b, a, y);         % 零相位滤波（正反各滤一次）
```

# 二、频谱分析

```matlab
fs = 1000; t = 0:1/fs:1;
x = sin(2*pi*50*t) + 0.5*sin(2*pi*120*t) + randn(size(t))*0.5;

N = length(x); X = fft(x);
f = (0:N-1) * fs / N;
plot(f(1:N/2), abs(X(1:N/2))/N*2);     % 单边谱
xlabel('频率 (Hz)'); title('幅值谱');
```

50Hz和120Hz处出现两个尖峰——正好对应两个正弦分量。
