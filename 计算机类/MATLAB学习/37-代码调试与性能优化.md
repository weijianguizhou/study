# 一、调试

```matlab
% 断点：点行号左边的小横杠
% dbstop if error    % 一出错就暂停

% 调试命令
dbstop if error          % 出错时暂停
dbstep                   % 单步执行
dbcont                   % 继续运行
dbquit                   % 退出调试
```

# 二、性能测量

```matlab
tic; mycode(); toc;      % 粗测时间

profile on; mycode(); profile viewer;   % 逐行耗时分析
```

---

# 三、预分配

```matlab
% 慢——循环中动态扩容
x = [];
for i = 1:100000
    x(end+1) = i^2;
end

% 快——预分配
x = zeros(1, 100000);
for i = 1:100000
    x(i) = i^2;
end
```

---

# 四、向量化

```matlab
% 慢
for i = 1:length(x), y(i) = sin(x(i)); end

% 快
y = sin(x);

% 逻辑索引代替if循环
x(x > 0.5) = 1;    % 比for+if快100倍
```
