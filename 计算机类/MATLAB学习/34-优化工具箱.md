# 34-优化工具箱

MATLAB的优化工具箱能解决线性/非线性/约束优化。

---

# 一、无约束优化 fminunc

```matlab
f = @(x) (x(1)-3)^2 + (x(2)+1)^2 + 5;
x0 = [0; 0];
[x_opt, f_min] = fminunc(f, x0);
fprintf('最优解: (%.3f, %.3f), 最小值: %.3f\n', x_opt, f_min);
```

---

# 二、约束优化 fmincon

$\min f(x)$ 使得 $Ax \leq b,\; A_{eq}x = b_{eq},\; lb \leq x \leq ub$

```matlab
f = @(x) x(1)^2 + x(2)^2;          % 最小化距离平方
x0 = [1; 1];
A = []; b = [];                     % 无线性不等式
Aeq = [1, 1]; beq = 2;              % x1 + x2 = 2
lb = [0; 0];                        % x≥0

[x_opt, f_min] = fmincon(f, x0, A, b, Aeq, beq, lb);
fprintf('最优: (%.3f, %.3f)\n', x_opt);
```

# 三、线性规划 linprog

```matlab
f = [-5; -3];                       % 目标系数（负=最大化）
A = [2, 1; 1, 2]; b = [8; 6];
lb = [0; 0];
x = linprog(f, A, b, [], [], lb);
```

# 四、最小二乘 lsqnonlin

```matlab
% 拟合数据 y = a*exp(b*x)
f = @(p) p(1)*exp(p(2)*x_data) - y_data;   % 残差
p0 = [1; -0.1];
p = lsqnonlin(f, p0);
```
