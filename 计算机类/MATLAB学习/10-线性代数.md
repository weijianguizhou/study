# 10-线性代数

MATLAB做线性代数是它的最强项。矩阵分解、特征值、最小二乘——全是内置的一行命令。

```matlab
A = [1, 2, 3; 4, 5, 6; 7, 8, 10];
b = [3; 3; 4];
```

---

# 一、方程求解

```matlab
x = A \ b;           % 解 Ax = b（优于 inv(A)*b）
```

`\`是MATLAB的万能求解器——根据$A$的性质自动选择LU/QR/Cholesky。**永远用`\`而不是`inv(A)*b`**。

---

# 二、矩阵分解

```matlab
[L, U, P] = lu(A);        % LU分解：PA = LU
[Q, R] = qr(A);           % QR分解
R_chol = chol(A'*A);      % Cholesky（要求正定）
[U, S, V] = svd(A);       % SVD: A = U*S*V'
[V, D] = eig(A);          % 特征分解
```

---

# 三、范数和条件数

```matlab
norm(A, 2)                % 2-范数（最大奇异值）
cond(A)                   % 条件数（越大越病态）
rank(A)                   % 秩
null(A)                   % 零空间基
orth(A)                   % 列空间标准正交基
```

---

# 四、最小二乘

```matlab
x = A \ b;                % 超定方程的最小二乘解
[Q, R] = qr(A);
x = R \ (Q' * b);         % 等价
```
