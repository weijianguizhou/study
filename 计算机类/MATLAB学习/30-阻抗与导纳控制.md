# 30-阻抗控制

阻抗控制不直接控制位置或力，而是控制**二者之间的关系**——让机器人表现得像一个弹簧-阻尼系统：

$$F_{ext} = K(x_d - x) + D(\dot{x}_d - \dot{x}) + M(\ddot{x}_d - \ddot{x})$$

---

# 一、阻抗控制的关节力矩

$$\tau = J^T(q) [K_p e + K_d \dot{e}] + G(q) - J^T(q) F_{ext}$$

```matlab
function tau = impedance_control(q, dq, x_d, dx_d, K_p, K_d, J, G)
    [T, J] = forward_kinematics_with_jacobian(q);
    x = T(1:3, 4);
    
    e = x_d - x;
    de = dx_d - J(1:3,:) * dq;    % 末端速度误差
    
    F_virtual = K_p * e + K_d * de;   % 虚拟力
    tau = J(1:3,:)' * F_virtual + G;   % 关节力矩
end
```

---

# 二、导纳控制（力→运动）

```matlab
% 测量外力F_ext → 修正目标位置
function x_cmd = admittance_control(F_ext, M_d, K_d, D_d, dt)
    persistent dx x
    if isempty(x), x = [0;0;0]; dx = [0;0;0]; end
    ddx = M_d \ (F_ext - D_d*dx - K_d*x);
    dx = dx + ddx * dt;
    x = x + dx * dt;
    x_cmd = x;
end
```

# 三、力/位混合控制

在某些方向控制位置，在另一些方向控制力。用一个**选择矩阵$S$**来分配：

$$\tau = J^T (S \cdot \tau_{pos} + (I-S) \cdot F_{des})$$

```matlab
S = diag([1, 1, 0]);    % X,Y控制位置，Z控制力
tau = J' * (S * tau_pos + (eye(3)-S) * F_desired);
```
