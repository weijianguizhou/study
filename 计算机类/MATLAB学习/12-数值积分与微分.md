# 12-数值积分与微分

---

# 一、数值积分

```matlab
% 自适应Simpson法（最推荐）
f = @(x) exp(-x.^2);
q = integral(f, 0, Inf)           % → √π/2

% 离散数据积分
x = 0:0.1:pi;
y = sin(x);
A = trapz(x, y)                    % 梯形法 ≈ 2

% 二重积分
f = @(x,y) sqrt(x.^2 + y.^2);
q2 = integral2(f, 0, 1, 0, 1);
```

---

# 二、数值微分

```matlab
x = 0:0.1:2*pi;
y = sin(x);
dy = diff(y) ./ diff(x);           % 前向差分
d2y = diff(y, 2) ./ diff(x(1:end-1)).^2;  % 二阶

% 更好的方法：gradient
[~, dy_grad] = gradient(y, 0.1);
```

---

# 三、非线性方程求解 fzero

```matlab
f = @(x) x^3 - 2*x - 5;
root = fzero(f, 2)                 % 初始猜测2，找到一个根
```

---

# 四、方程组求解 fsolve

```matlab
F = @(x) [x(1)^2 + x(2)^2 - 4;
           x(1)*x(2) - 1];
sol = fsolve(F, [1; 1]);           % 初始猜测[1,1]
```
