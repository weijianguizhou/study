# 14-动力学基础：单自由度振动

$$m\ddot{x} + c\dot{x} + kx = F(t)$$

---

# 一、自由振动 ($F=0$)

```matlab
m = 1; c = 0.3; k = 2;
omega_n = sqrt(k/m);              % 固有频率
zeta = c / (2*sqrt(m*k));        % 阻尼比

odefun = @(t, y) [y(2);
                  -(c/m)*y(2) - (k/m)*y(1)];
[t, y] = ode45(odefun, [0, 20], [1; 0]);

plot(t, y(:,1)); title('自由振动');
```

---

# 二、受迫振动

$$F(t) = F_0 \sin(\omega t)$$

```matlab
F0 = 0.5; omega_f = 1.8;

odefun = @(t, y) [y(2);
                  (F0*sin(omega_f*t) - c*y(2) - k*y(1))/m];

[t, y] = ode45(odefun, [0, 30], [0; 0]);
plot(t, y(:,1));
```

---

# 三、共振演示

激励频率$\omega_f$接近固有频率$\omega_n$时振幅激增：

```matlab
for omega_f = [0.5, 1.0, 1.4, 1.9, 2.0]
    odefun = @(t,y) [y(2); (F0*sin(omega_f*t)-c*y(2)-k*y(1))/m];
    [t, y] = ode45(odefun, [0 50], [0;0]);
    amp = max(abs(y(end-500:end, 1)));  % 稳态振幅
    fprintf('ω=%.1f: 振幅=%.3f\n', omega_f, amp);
end
```

# 四、频响函数 (FRF)

```matlab
omega_vec = logspace(-1, 1, 200);
H = 1 ./ (-m*omega_vec.^2 + 1i*c*omega_vec + k);

semilogx(omega_vec, 20*log10(abs(H)));
xlabel('ω (rad/s)'); ylabel('|H| (dB)');
title('频率响应');
```

振幅在$\omega \approx \omega_n$处达到峰值——这就是共振峰。
