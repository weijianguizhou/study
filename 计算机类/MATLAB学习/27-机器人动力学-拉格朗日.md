# 27-机器人动力学(拉格朗日)

$$M(\mathbf{q})\ddot{\mathbf{q}} + C(\mathbf{q},\dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}) = \tau$$

---

# 复习一下力学

## 1. 三项各是什么

**$M(\mathbf{q})$ — 质量矩阵**（惯性矩阵）：$n \times n$对称正定。$M_{ij}$表示"加速关节$i$需要关节$j$出多少力"。对角元是各关节的自惯性，非对角元是关节间的**耦合惯性**——加速关节1会让关节2感觉到一个"反作用力"，因为连杆在动。

注意$M$依赖于$\mathbf{q}$——机器人的惯性随着姿态变化。你把胳膊伸直时转动惯量比蜷缩时大得多。

**$C(\mathbf{q},\dot{\mathbf{q}})\dot{\mathbf{q}}$ — 科氏力和离心力**：依赖于速度的力。科氏力是两个关节同时运动时的交叉耦合效应（比如你甩链球时链子上各点的速度互相影响），离心力是单个关节旋转时质点被往外甩的趋势。

**$\mathbf{g}(\mathbf{q})$ — 重力项**：每个连杆的重力贡献的关节力矩。只跟位置$\mathbf{q}$有关，不依赖速度。

## 2. 拉格朗日法的思路

牛顿-欧拉法是从力出发，一根连杆一根连杆递推。拉格朗日法是从**能量**出发——只关心系统的动能$T$和势能$V$，不去管内部连杆之间复杂的约束力。

**拉格朗日量**：$L = T - V$

运动方程由**欧拉-拉格朗日方程**自动给出：

$$\frac{d}{dt}\frac{\partial L}{\partial \dot{q}_i} - \frac{\partial L}{\partial q_i} = \tau_i$$

把全部$n$个关节都写出来，整理成标准的机器人动力学形式。具体来说：$\frac{d}{dt}\frac{\partial L}{\partial \dot{q}}$里包含$\ddot{q}$的项聚成$M\ddot{q}$，只含$\dot{q}$乘积的项聚成$C\dot{q}$，只含$q$的项是$g$。

拉格朗日法的牛逼之处：你不用分析关节内部的约束力——能量只关心宏观的动和势，约束力在拉格朗日体系里自动被消除。对复杂的多体系统，这比牛顿-欧拉清爽得多。

只是计算量更大（$\frac{d}{dt}\frac{\partial L}{\partial \dot{q}}$要算一堆偏导数），而且$M,C,g$的表达式很快变得极其冗长——所以实际中都靠符号工具箱或递归算法。

# MATLAB实现

**符号推导质量矩阵**：

```matlab
syms m1 m2 L1 L2 g q1 q2 dq1 dq2 real

% 动能: T = ½Σ m_i v_i²
T = 0.5*m1*(0.5*L1*dq1)^2 ...
  + 0.5*m2*((L1*dq1*cos(q1) + 0.5*L2*(dq1+dq2)*cos(q1+q2))^2 ...
           + (L1*dq1*sin(q1) + 0.5*L2*(dq1+dq2)*sin(q1+q2))^2);
% 势能: V = Σ m_i g y_i
V = m1*g*(0.5*L1*sin(q1)) + m2*g*(L1*sin(q1) + 0.5*L2*sin(q1+q2));
L = T - V;

% M = ∂²L/∂q̇² (Hessian)
M = hessian(L, [dq1; dq2]);

% G = ∂V/∂q
G = jacobian(V, [q1; q2])';

% C通过Christoffel符号
M_func = matlabFunction(M, 'Vars', {[q1;q2], [m1;m2;L1;L2]});
G_func = matlabFunction(G, 'Vars', {[q1;q2], [m1;m2;L1;L2;g]});
```

```matlab
% 正向动力学仿真
odefun = @(t, y) robot_dynamics(y, M_func, C_func, G_func, params);
[t, y] = ode45(odefun, [0, 5], [0; 0; 0; 0]);

function dydt = robot_dynamics(y, M_f, C_f, G_f, p)
    q = y(1:2); dq = y(3:4);
    M = M_f(q, p(1:3)); C = C_f(q, dq, p(1:3)); G = G_f(q, p);
    tau = [0; 0];   % 自由摆动
    ddq = M \ (tau - C*dq - G);
    dydt = [dq; ddq];
end
```
