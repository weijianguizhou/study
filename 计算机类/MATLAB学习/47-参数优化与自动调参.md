# 47-参数优化与自动调参

手动调PID、LQR权重、轨迹参数既慢又不准。MATLAB的优化工具可以自动帮你找到最优参数。

---

# 一、PID自动优化

```matlab
G = tf(1, [1, 3, 2]);
options = pidtuneOptions('DesignFocus', 'reference-tracking');
[C, info] = pidtune(G, 'PIDF', options);
```

---

# 二、用fmincon优化任意控制器参数

```matlab
function cost = evaluate_pid(K)
    % K = [Kp, Ki, Kd]
    assignin('base', 'Kp', K(1)); assignin('base', 'Ki', K(2));
    assignin('base', 'Kd', K(3));
    simOut = sim('my_model', 'SrcWorkspace', 'current');
    y = simOut.logsout{1}.Values.Data;
    cost = sum((y - 1).^2);        % 跟踪单位阶跃的误差平方积分(ISE)
end

K_opt = fmincon(@evaluate_pid, [1, 0.1, 0.01], [], [], [], [], [0,0,0], [100,100,100]);
```

**注意**：`fmincon`每评估一次就要跑一遍Simulink仿真——如果仿真慢，优化就很慢。可以考虑用代理模型（surrogate）加速。

# 三、轨迹参数优化

```matlab
% 优化五次多项式的总时间T
function cost = eval_traj_time(T)
    [q_ref, dq_ref, ddq_ref] = generate_trajectory(T);
    % 模拟控制...
    cost = tracking_error + 0.01*T;  % 误差小 + 时间短
end
```

# 四、全局优化（GA/PSO）

`fmincon`只找局部最优。如果函数有很多局部极小值，用遗传算法：

```matlab
K_opt = ga(@evaluate_pid, 3, [],[],[],[], [0,0,0], [100,100,100]);
```

或粒子群：
```matlab
options = optimoptions('particleswarm', 'SwarmSize', 50);
K_opt = particleswarm(@evaluate_pid, 3, [0,0,0], [100,100,100], options);
```
