# 一、函数规范

```matlab
function [output1, output2] = myFunction(input1, input2, options)
%MYFUNCTION 简要描述
%   [output1, output2] = myFunction(input1, input2) 详细描述
%   参数:
%       input1  - 第一个输入
%       input2  - 第二个输入
%       options - (可选) 结构体，字段包括...
%   返回:
%       output1 - 结果1
%       output2 - 结果2

arguments
    input1 (1,1) double {mustBePositive}
    input2 (1,:) double
    options.verbose (1,1) logical = false   % R2019b+
end
```

# 二、结构体参数

```matlab
function result = solver(problem)
    % 用默认值填充缺失字段
    if ~isfield(problem, 'method'), problem.method = 'ode45'; end
    if ~isfield(problem, 'tspan'),  problem.tspan = [0, 10]; end
end

% 调用时传结构体
solver(struct('x0', [1;0], 'method', 'ode15s'));
```

# 三、常用的检查

```matlab
assert(nargin >= 2, '至少需要2个输入参数');
validateattributes(x, {'double'}, {'vector', 'positive'});
```

# 四、并行计算 (parfor)

```matlab
parfor i = 1:100
    results(i) = expensive_computation(i);
end
```

条件：各次迭代独立，工具条里点"Start Parallel Pool"。
