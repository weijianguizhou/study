# 一、三维曲线

```matlab
t = linspace(0, 10*pi, 500);
x = sin(t);
y = cos(t);
z = t;

plot3(x, y, z, 'LineWidth', 1.5);
xlabel('x'); ylabel('y'); zlabel('z');
title('三维螺旋线');
grid on;
```

---

# 二、曲面图 (mesh / surf)

```matlab
[X, Y] = meshgrid(-5:0.5:5, -5:0.5:5);   % 生成网格
Z = sin(sqrt(X.^2 + Y.^2)) ./ sqrt(X.^2 + Y.^2 + 1);

mesh(X, Y, Z);        % 网格曲面（透视线框）
surf(X, Y, Z);        % 填充曲面（更漂亮）
```

`meshgrid`生成两个矩阵——`X`存了所有网格点的x坐标，`Y`存了所有网格点的y坐标。然后`Z`用**逐元素运算**（加点的版本）算出每个点的高度。

```matlab
% 加色彩和光源
surf(X, Y, Z, 'EdgeColor', 'none');   % 去掉黑线
colormap jet;                          % 彩虹配色
colorbar;                              % 颜色条
shading interp;                        % 平滑着色
```

# 三、等高线

```matlab
contour(X, Y, Z, 20);          % 20条等高线
contourf(X, Y, Z, 20);         % 填充等高线
```
