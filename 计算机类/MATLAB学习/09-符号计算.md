# 09-符号计算

MATLAB有一个独特的**符号工具箱**（Symbolic Math Toolbox）——它能像人一样做代数推导，而不是数值近似。微分、积分、方程求解，都能出解析表达式。

```matlab
syms x y;      % 声明符号变量
```

---

# 一、符号化简

```matlab
syms x
f = (x^2 - 1) / (x - 1);
simplify(f)               % → x + 1（自动化简）

expand((x+1)^3)           % → x^3 + 3*x^2 + 3*x + 1
factor(x^3 - 1)           % → (x-1)*(x^2+x+1)
```

---

# 二、求导与积分

```matlab
syms x
f = x^3 * sin(x);

diff(f, x)                % 对x求导 → 3*x^2*sin(x) + x^3*cos(x)
diff(f, x, 2)             % 二阶导数
int(f, x)                 % 不定积分
int(f, x, 0, pi)          % 定积分从0到π
```

---

# 三、极限与级数

```matlab
limit(sin(x)/x, x, 0)     % → 1
symsum(1/n^2, n, 1, Inf)  % → π²/6
taylor(exp(x), x, 'Order', 5)   % e^x的4阶Taylor展开
```

---

# 四、解方程

```matlab
syms x
eqn = x^2 + 3*x + 2 == 0;
solve(eqn, x)             % → -2, -1

% 方程组
syms x y
eq1 = x + y == 5;
eq2 = 3*x - y == 7;
[x_sol, y_sol] = solve([eq1, eq2], [x, y]);
```

---

# 五、符号 → 数值转换

```matlab
syms x
f = sin(x);
f_num = matlabFunction(f);     % 把符号函数转成可数值计算的函数句柄
f_num(pi/4)                    % → 0.7071

% 或者用subs把符号变量替换成数值
subs(f, x, pi/3)               % → 0.8660（符号）
double(ans)                    % → 0.8660（数值）
```

---

# 六、拉普拉斯变换和傅里叶变换

```matlab
syms t s
f = exp(-t) * sin(t);
F = laplace(f, t, s)          % 拉氏变换
ilaplace(F, s, t)             % 逆拉氏变换

fourier(exp(-t^2), t)         % 傅里叶变换
```
