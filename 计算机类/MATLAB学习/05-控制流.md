# 05-控制流

MATLAB的控制流跟C/C++几乎一样——`if/else`、`for`、`while`、`switch`。语法上少了一些花括号，多了`end`。

---

# 一、if / elseif / else

```matlab
score = 85;

if score >= 90
    disp('A');
elseif score >= 80
    disp('B');
elseif score >= 70
    disp('C');
else
    disp('F');
end
```

```cmd
B
```

每个控制块以`end`结尾。没有花括号！`elseif`是一个词，不是`else if`。

---

# 二、for 循环

```matlab
% 遍历向量
for i = 1:5
    fprintf('i = %d\n', i);
end

% 遍历矩阵的每一列
A = rand(3, 4);
for col = A             % col每次取A的一列
    disp(col');
end

% 嵌套
for i = 1:3
    for j = 1:2
        fprintf('(%d,%d) ', i, j);
    end
    fprintf('\n');
end
```

MATLAB的`for`可以遍历**任何东西**——数组、矩阵列、元胞数组。比C的纯数值for灵活多了。

**告诫**：在MATLAB里能不用`for`就尽量不用。`for`循环在MATLAB里慢，向量化快。只有逻辑实在没法向量化的时候才用循环。

---

# 三、while 循环

```matlab
count = 0;
while count < 3
    fprintf('count = %d\n', count);
    count = count + 1;
end
```

---

# 四、switch / case

```matlab
day = 3;
switch day
    case 1
        disp('周一');
    case 2
        disp('周二');
    case {3, 4, 5}       % 多个值用元胞数组
        disp('工作日');
    otherwise
        disp('周末');
end
```

---

# 五、break 和 continue

```matlab
for i = 1:10
    if i == 4
        break;           % 跳出循环
    end
    fprintf('%d ', i);
end
fprintf('\n');            % 输出: 1 2 3

for i = 1:6
    if mod(i, 2) == 0
        continue;         % 跳过本轮
    end
    fprintf('%d ', i);
end
fprintf('\n');            % 输出: 1 3 5
```

---

# 六、try / catch（异常处理）

```matlab
try
    A = rand(3);
    B = inv(A);          % 求逆——可能失败
    disp('逆矩阵计算成功');
catch ME
    fprintf('出错: %s\n', ME.message);
end
```
