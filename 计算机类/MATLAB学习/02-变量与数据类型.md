# 02-变量与数据类型

MATLAB是**弱类型**语言——你不需要声明变量类型，MATLAB自己猜。但理解底层的数据类型很重要，尤其是数值精度的问题。

---

# 一、变量命名规则

```matlab
x = 5;           % 字母开头
y2 = 3.14;       % 可以有数字
my_var = 42;     % 可以有下划线
% 2x = 5;        % 不能数字开头！
% my-var = 5;    % 不能有连字符！
```

MATLAB**区分大小写**——`a`和`A`是不同的变量。变量名别用`i`和`j`——它们是MATLAB默认的虚数单位，用`1i`和`1j`来表示虚数。

---

# 二、数值类型

```matlab
a = 42                    % 默认是double（双精度浮点）
b = int32(42)             % 显式32位整数
c = single(3.14)          % 单精度浮点
d = 1 + 2i                % 复数（i或j都可以，1i是更推荐的写法）
e = true                  % 逻辑值 (还有false)
```

**MATLAB默认一切数字都是`double`**——即使你写`a = 5`，它在内存里也是8字节的双精度浮点数。这是跟C最大的不同——C的`int`是4字节的整数，MATLAB的"整数"其实是浮点。

想看变量的类型和大小：

```matlab
>> whos
  Name      Size            Bytes  Class
  a         1x1                 8  double
  b         1x1                 4  int32
  c         1x1                 4  single
  d         1x1                16  double (complex)
  e         1x1                 1  logical
```

# 三、特殊常量

```matlab
pi       % 3.1416
eps      % 2.2204e-16（机器精度——比1大的最小数到1的距离）
inf      % 无穷大（1/0的结果）
NaN      % Not a Number（0/0的结果）
realmax  % 最大正浮点数 ≈ 1.8e308
realmin  % 最小正浮点数 ≈ 2.2e-308
i, j     % 虚数单位（但推荐用1i和1j）
```

---

# 四、类型转换

```matlab
x = 3.14;
a = int32(x)         % → 3（截断）
b = double(a)        % → 3.0
c = num2str(42)      % 数字 → 字符串 '42'
d = str2num('3.14')  % 字符串 → 数字 3.14
```

---

# 五、字符串

```matlab
s1 = 'Hello World';
s2 = "Hello World";       % R2017a+ 双引号版本 = string类型

% 拼接
s3 = [s1, ' MATLAB'];     % 字符数组拼接
s4 = s2 + " MATLAB";      % string类型拼接（R2017a+）

% 格式化
name = '张三';
age = 20;
fprintf('我叫%s，今年%d岁\n', name, age);
% 或者用sprintf返回字符串
str = sprintf('我叫%s，今年%d岁', name, age);
```

---

# 六、逻辑类型

```matlab
a = true;                     % 逻辑1
b = false;                    % 逻辑0
c = 5 > 3;                    % 比较运算返回逻辑值
d = isprime(17);              % 很多函数返回逻辑值

% 逻辑值可以直接参与算术（true=1, false=0）
sum([true, false, true])     % → 2
```
