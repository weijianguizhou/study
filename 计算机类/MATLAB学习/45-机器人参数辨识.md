# 45-机器人参数辨识

真实机器人的动力学参数（质量、质心、惯量）很少能从CAD精确拿到。辨识就是从实验数据反推出这些参数。

---

# 一、动力学线性参数化

$$Y(q, \dot{q}, \ddot{q}) \cdot \pi = \tau$$

$Y$是**回归矩阵**（由运动学数据算出），$\pi$是未知参数向量（质量、惯量、摩擦系数等）。

**关键**：$\pi$是$Y$乘一下就出来的系数——动力学对参数本质是线性关系。

---

# 二、最小二乘辨识

采集$N$组不同的$q,\dot{q},\ddot{q}$和对应的$\tau$：

```matlab
% 堆叠：W * pi = T
W = [Y(q1,dq1,ddq1); Y(q2,dq2,ddq2); ... Y(qN,dqN,ddqN)];
T = [tau1; tau2; ... tauN];

pi_est = W \ T;         % 最小二乘解

tau_pred = W * pi_est;
residual = norm(T - tau_pred);
fprintf('残差: %.4f\n', residual);
```

# 三、激励轨迹设计

为了得到好的辨识结果，需要**充分激励**——轨迹要覆盖机器人的各种工作状态：

```matlab
% 傅里叶级数形式的激励轨迹
function [q, dq, ddq] = fourier_trajectory(t, a, b, w_f)
    n = length(a);
    q = zeros(n,1); dq = q; ddq = q;
    for k = 1:n
        q(k) = sum(a(k,:).*cos((1:5)*w_f*t) + b(k,:).*sin((1:5)*w_f*t));
        % ... 求导得到dq, ddq
    end
end
```

# 四、约束优化辨识

参数有物理约束（质量>0，惯量正定），用`fmincon`：

```matlab
pi_est = fmincon(@(p) norm(W*p - T)^2, pi0, [],[],[],[], lb, ub);
```
