# 48-机器人轨迹优化

让机器人用最短时间、最少能量走完指定路径——这是一个优化问题。

---

# 一、最短时间轨迹

$$\min_T \int_0^T dt \quad \text{s.t.} \quad \tau_{min} \leq \tau(t) \leq \tau_{max},\; \dot{q}_{min} \leq \dot{q}(t) \leq \dot{q}_{max}$$

把时间离散成$N$段，优化每段的$q_i$：

```matlab
function cost = min_time_cost(q_seq)
    T = size(q_seq, 2);
    dt = q_seq(:,2:end) - q_seq(:,1:end-1);
    cost = sum(sqrt(sum(dt.^2)));    % 路径总长度≈总时间
end
```

---

# 二、最小能量轨迹

$$\min \int_0^T \|\tau(t)\|^2 dt$$

```matlab
function energy = compute_energy(q_traj, dt)
    energy = 0;
    for k = 1:size(q_traj,2)-1
        q = q_traj(:,k); dq = (q_traj(:,k+1)-q)/dt;
        tau = compute_torque(q, dq, zeros(size(q)));
        energy = energy + norm(tau)^2 * dt;
    end
end
```

# 三、避障约束

把障碍物建模为惩罚函数：

```matlab
function penalty = obstacle_cost(q)
    T = forward_kinematics(q);
    pos = T(1:3,4);
    for obs = obstacles
        d = norm(pos - obs.center);
        if d < obs.radius
            penalty = penalty + (obs.radius - d)^2 * 1000;
        end
    end
end
```

总代价 = 时间/能量 + 避障惩罚，一起交给`fmincon`优化。

---

# 四：实际使用建议

纯数值优化路径可能不平滑。更实际的做法：

1. 先用样条或多项式生成光滑参考路径
2. 用优化微调关键路径点
3. 控制器负责跟踪，轨迹负责规划
