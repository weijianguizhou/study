# 36-数据导入与导出

---

# 一、MAT文件（.mat）

```matlab
save('my_data.mat', 'A', 'b', 'x');      % 保存
load('my_data.mat');                       % 加载
clear A b x;                               % 清变量
load('my_data.mat', 'A');                  % 只加载A
```

---

# 二、CSV/Excel

```matlab
data = readmatrix('data.csv');                        % 数字矩阵
T = readtable('data.csv');                            % 表（含表头）
data = xlsread('data.xlsx');                          % (老版本)
writematrix(A, 'output.csv');
writetable(T, 'output.xlsx');
```

---

# 三、文本文件

```matlab
fid = fopen('log.txt', 'w');
fprintf(fid, '结果: %.3f\n', result);
fclose(fid);

% 或直接用高级函数
data = fileread('log.txt');                           % 全读
lines = readlines('log.txt');                         % 逐行(R2020b+)
```
