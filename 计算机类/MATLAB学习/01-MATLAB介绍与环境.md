# 01-MATLAB介绍与环境

MATLAB的全称是**MAT**rix **LAB**oratory（矩阵实验室）。1984年MathWorks公司搞出来的，核心就是**矩阵运算**——在MATLAB里，一切皆矩阵。一个数不过是$1\times1$的矩阵。

跟Python比，MATLAB的矩阵操作语法更贴近数学——不用`import numpy as np`，开箱即用。搞控制、信号处理、机器人、Simulink仿真的工科生几乎人手一份。

---

# 一、界面认识

打开MATLAB，你看到四个主要区域：

- **命令窗口 (Command Window)**：最核心的地方。输入命令，回车执行。
- **工作区 (Workspace)**：显示当前内存里有哪些变量、什么类型、多大。
- **当前文件夹 (Current Folder)**：左边文件浏览器。
- **编辑器 (Editor)**：双击`.m`文件打开，写脚本用。

---

# 二、第一行命令

在命令窗口里直接敲：

```matlab
>> 2 + 3

ans =

     5
```

`ans`是MATLAB自动生成的变量名——当你不把结果赋值给任何变量时，结果就暂存在`ans`里。

```matlab
>> a = 10 * 4

a =

    40

>> a

a =

    40
```

MATLAB不用声明类型，赋值时自动决定。分号`;`可以**隐藏输出**：

```matlab
>> b = 5 * 6;    % 分号 = 执行但不显示结果
>> b

b =

    30
```

百分号`%`是注释——后面内容被忽略。

---

# 三、脚本：.m文件

在命令窗口一行行敲适合探索，但正式写程序要用**脚本**。

点击"新建脚本"，或者命令行`edit myscript`。新建一个`.m`文件：

```matlab
% myscript.m —— 第一个MATLAB脚本
x = 0:0.1:10;          % 0到10，步长0.1
y = sin(x);
plot(x, y);
xlabel('x');
ylabel('sin(x)');
title('正弦波');
grid on;
```

点编辑器上方的绿色三角形（运行），MATLAB会自动把脚本所在文件夹加入路径，然后执行。

---

# 四、帮助系统

MATLAB自带了海量文档。在命令窗口里查任何函数的用法：

```matlab
help sin          % 简要帮助
doc sin           % 弹出详细文档窗口
lookfor fourier   % 根据关键词搜函数
```

`doc`弹出的窗口有完整的函数签名、参数说明、**而且有例子代码**——这是学MATLAB最快的方式。碰到不认识的函数，第一反应应该是`doc 函数名`。

---

# 五、路径与工作目录

MATLAB只在**搜索路径**里的文件夹找`.m`文件。当前文件夹自动在路径里。

```matlab
pwd               % 当前目录
cd D:\myfolder     % 切换目录
ls                % 列出文件
addpath('D:\tools')   % 追加搜索路径
savepath              % 永久保存路径设置
```

---

# 六、几个有用的命令

```matlab
clc          % 清空命令窗口（变量还在）
clear        % 清空工作区所有变量
clear a b    % 只清a和b
close all    % 关闭所有图窗
who          % 列出工作区变量名
whos         % 列出变量名+大小+类型
```
