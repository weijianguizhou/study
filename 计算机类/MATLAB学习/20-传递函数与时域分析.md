# 20-传递函数与时域分析

---

# 复习一下控制理论

## 1. 什么是传递函数

一个线性时不变系统(LTI)，输入$u(t)$，输出$y(t)$。它们之间满足一个常系数线性微分方程：

$$a_n y^{(n)} + a_{n-1} y^{(n-1)} + \cdots + a_0 y = b_m u^{(m)} + \cdots + b_0 u$$

你当然可以直接解这个微分方程（用上篇的ode45），但在控制工程里，我们几乎从来不直接处理时域微分方程——太麻烦了。我们对它做**拉普拉斯变换**，把时域的微分运算变成频域的代数运算。

拉普拉斯变换的核心性质：$\mathcal{L}\{\dot{y}(t)\} = sY(s) - y(0)$。如果初始条件全为零（控制里通常这样假设），微分就变成了乘$s$——二阶导变成乘$s^2$，依此类推。

对微分方程两边取拉氏变换（零初始条件），得到：

$$(a_n s^n + a_{n-1}s^{n-1} + \cdots + a_0) Y(s) = (b_m s^m + \cdots + b_0) U(s)$$

整理一下：

$$G(s) = \frac{Y(s)}{U(s)} = \frac{b_m s^m + \cdots + b_0}{a_n s^n + \cdots + a_0}$$

$G(s)$就是**传递函数**——一个复变量$s$的有理分式。它完整描述了系统的输入输出关系。

## 2. 传递函数的物理含义

传递函数$G(s)$告诉你：输入一个频率为$\omega$的正弦信号，输出也是同频率的正弦，但幅度放大$|G(j\omega)|$倍，相位偏移$\angle G(j\omega)$。

写成复数：$u(t) = \sin(\omega t) \implies y(t) = |G(j\omega)| \sin(\omega t + \angle G(j\omega))$

这就是频域分析的核心思想——把任意输入分解成正弦波的叠加（傅里叶），每个频率分量都被$G(s)$独立地放大和移相，输出就是这些处理后的分量的叠加。线性系统的最大优点就是这个**叠加原理**。

## 3. 极点和零点

把传递函数因式分解：

$$G(s) = K \frac{(s-z_1)(s-z_2)\cdots(s-z_m)}{(s-p_1)(s-p_2)\cdots(s-p_n)}$$

- $z_i$是**零点**——$G(z_i)=0$
- $p_i$是**极点**——$G(p_i) \to \infty$

极点的位置决定系统的本质行为。对单位阶跃输入：
- 实轴负半轴的极点$p = -a \implies y(t) \sim e^{-at}$（指数衰减）
- 共轭复极点$p = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2} \implies y(t) \sim e^{-\zeta\omega_n t}\sin(\omega_d t)$（衰减振荡）
- **右半平面的极点$\implies$系统不稳定**——输出会发散

## 4. 阶跃响应的性能指标

给系统一个阶跃输入（从0跳到1），观察输出怎么跟上。衡量"跟得好不好"有几个指标：

- **上升时间$t_r$**：输出从10%升到90%所需时间
- **超调量$M_p$**：输出超出终值的最大百分比
- **调节时间$t_s$**：输出进入终值±2%范围内不再出来的时刻
- **稳态误差$e_{ss}$**：$t \to \infty$时输出和期望值的差距

# MATLAB实现

## 创建传递函数

```matlab
num = [1, 2]; den = [1, 3, 5, 1];
G = tf(num, den)
```

```cmd
G =
      s + 2
  -----------------
  s^3 + 3s^2 + 5s + 1
```

或者用`s`变量——更直观：

```matlab
s = tf('s');
G = (s + 2) / (s^3 + 3*s^2 + 5*s + 1);
```

## 时域响应

```matlab
step(G);                  % 阶跃响应——输入突然从0跳到1
impulse(G);               % 脉冲响应——输入是瞬间冲一下
```

阶跃响应是最常用的——它告诉你系统对"突然变化"的反应速度和平稳程度。

## 提取性能指标

```matlab
info = stepinfo(G);
fprintf('上升时间: %.3fs\n', info.RiseTime);
fprintf('超调量: %.1f%%\n', info.Overshoot);
fprintf('调节时间: %.3fs\n', info.SettlingTime);
```

## 极点和稳定性

```matlab
p = pole(G);              % 极点——分母多项式的根
z = zero(G);              % 零点——分子多项式的根
pzmap(G);                 % 画在复平面上

if all(real(p) < 0)
    disp('所有极点在左半平面——系统稳定');
else
    disp('存在右半平面极点——系统不稳定！');
end
```

如果所有极点都在左半平面（实部<0），那么所有自然模态都是衰减的→系统稳定。有一个极点在虚轴上→临界稳定（等幅振荡）。有一个在右半平面→发散。

## 串联、并联、反馈

工业系统里绝大多数是**反馈控制**结构。MATLAB里反馈连接直接用`feedback`：

```matlab
G = 1/(s^2 + 2*s + 1);       % 被控对象
C = 10*(s+1)/s;               % PI控制器
T = feedback(C*G, 1);         % 闭环系统：T = CG/(1+CG)
step(T);
```

`feedback(C*G, 1)`就是$\frac{C(s)G(s)}{1 + C(s)G(s)}$。"1"表示单位负反馈。如果是正反馈，最后一个参数改成`+1`。
