# 03-矩阵与向量

MATLAB = Matrix Laboratory。矩阵是MATLAB的灵魂——一切皆矩阵。这篇从创建到运算，把你喂饱。

---

# 一、创建向量

```matlab
% 行向量
v1 = [1, 2, 3, 4, 5];      % 逗号分隔
v2 = [1 2 3 4 5];           % 空格分隔也行

% 列向量
v3 = [1; 2; 3; 4; 5];      % 分号 = 换行
v4 = [1, 2, 3]';            % 转置

% 快速生成
x = 1:10;                   % 1到10，步长1
x = 1:2:9;                  % 1到9，步长2  → 1 3 5 7 9
x = linspace(0, 10, 5);     % 0到10，等间距取5个点 → 0 2.5 5 7.5 10
x = logspace(0, 2, 5);      % 10^0到10^2，对数等间距 → 1 3.16 10 31.6 100
```

---

# 二、创建矩阵

```matlab
A = [1, 2, 3;
     4, 5, 6;
     7, 8, 9];             % 3×3矩阵，分号换行

% 特殊矩阵
Z = zeros(3, 4);           % 3×4全零矩阵
O = ones(2, 3);            % 2×3全1矩阵
I = eye(4);                % 4×4单位矩阵
R = rand(3, 2);            % 3×2均匀分布随机数 [0,1]
N = randn(5, 1);           % 5×1正态分布随机数 (均值0,方差1)
D = diag([1 2 3]);         % 对角矩阵，对角元=1,2,3
```

---

# 三、矩阵拼接

```matlab
A = [1 2; 3 4];
B = [5 6; 7 8];

C = [A, B];                % 水平拼接 → 2×4
D = [A; B];                % 垂直拼接 → 4×2
```

---

# 四、矩阵运算

```matlab
A = [1 2; 3 4];
B = [5 6; 7 8];

A + B           % 逐元素加
A * B           % 矩阵乘法（线性代数的乘法！）
A .* B          % 逐元素乘（加点的版本）
A / B           % A * inv(B)
A \ B           % inv(A) * B （解Ax=B）
A ^ 2           % A * A
A .^ 2          % 每个元素平方

A'              % 共轭转置（实矩阵就是普通转置）
inv(A)          % 逆矩阵
det(A)          % 行列式
rank(A)         % 秩
eig(A)          % 特征值
[V, D] = eig(A); % 特征向量V和特征值D
```

**加点的版本**（`. *`, `. /`, `. ^`）是MATLAB的特色——对矩阵逐元素做运算而不是做矩阵运算。这是新手最容易搞混的地方。

---

# 五、矩阵的尺寸信息

```matlab
A = rand(3, 4);
size(A)          % [3, 4]
size(A, 1)       % 3  行数
size(A, 2)       % 4  列数
length(A)        % max(size(A))  最大维度
numel(A)         % 12  元素总数
```

# 六、向量化——MATLAB的精髓

**避免用循环**，用向量化操作。向量化操作底层是C写的，飞快。

```matlab
% 慢（不MATLAB的方式）
x = rand(1, 1000000);
y = zeros(1, 1000000);
for i = 1:length(x)
    y(i) = sin(x(i));
end

% 快（MATLAB的方式）
x = rand(1, 1000000);
y = sin(x);          % 直接对整个向量操作，底层并行化
```

**原则**：如果你在写`for`循环，先停下来想想能不能用向量化替代。在MATLAB里写C风格的循环约等于浪费MATLAB的性能。
