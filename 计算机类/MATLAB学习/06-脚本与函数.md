# 06-脚本与函数

把一堆命令写成`.m`文件，有两种形式：**脚本**（Script）和**函数**（Function）。

---

# 一、脚本

脚本就是一串顺序执行的命令，共用工作区的变量。

```matlab
% myscript.m
x = 0:0.1:2*pi;
y = sin(x);
plot(x, y);
```

运行脚本：命令窗口里打`myscript`就行了（不用打`.m`扩展名）。脚本里的变量运行后**留在工作区**。

---

# 二、函数

函数有自己的独立工作区，不影响外面。

**MATLAB的函数极有特点**：一个`.m`文件里只能有一个"主函数"，而且**文件名必须和函数名一致**。

```matlab
% add.m
function c = add(a, b)
    c = a + b;
end
```

```matlab
>> add(3, 5)
ans =
     8
```

如果函数名和文件名不一致，MATLAB用文件名来查找函数，函数名被忽略——很容易出诡异的bug。

### 多返回值

```matlab
% minmax.m
function [lo, hi] = minmax(v)
    lo = min(v);
    hi = max(v);
end
```

```matlab
>> [a, b] = minmax([3, 1, 4, 1, 5])
a = 1
b = 5
```

### 多参数 + 默认值（nargin）

```matlab
function result = mypower(base, exponent)
    if nargin < 2          % nargin = 调用时传了几个参数
        exponent = 2;      % 默认平方
    end
    result = base ^ exponent;
end
```

---

# 三、子函数

同一个`.m`文件里可以在主函数后面附加多个子函数——只有主函数对外可见，子函数只能在文件内部调用。

```matlab
% mytools.m
function y = main_calc(x)
    y = helper(x) * 2;
end

function z = helper(x)     % 子函数——外部看不到
    z = x^2 + 1;
end
```

---

# 四、匿名函数

一行能写完的简单函数，用`@`：

```matlab
f = @(x) x^2 + 3*x + 1;   % f = x² + 3x + 1
f(5)                       % → 41

g = @(x, y) sqrt(x^2 + y^2);
g(3, 4)                    % → 5
```

匿名函数特别适合作为参数传给其他函数（如`integral`、`fzero`）。

---

# 五、局部函数（R2016b+）

从R2016b开始，脚本文件的末尾也可以加局部函数——不用非得在函数文件里。

```matlab
% myscript.m
x = 5;
y = helper(x)     % 调用下面定义的局部函数

function z = helper(a)
    z = a^2 + 1;
end
```

**规则**：脚本里的局部函数必须放在脚本**最后面**。
