# 11-多项式与插值

MATLAB里多项式用**系数向量**表示——从最高次幂到常数项。

---

# 一、多项式的表示

$$p(x) = x^3 - 6x^2 + 11x - 6$$

```matlab
p = [1, -6, 11, -6];                % 系数向量
roots(p)                            % 求根 → [3; 2; 1]
polyval(p, 2.5)                     % 代入x=2.5的值

% 已知根，返回多项式系数
poly([1, 2, 3])                     % → [1, -6, 11, -6]
```

---

# 二、多项式拟合 (polyfit)

一堆离散点，找最优多项式：

```matlab
x = 0:0.1:10;
y = 2*x.^3 - 5*x.^2 + 3*x + randn(size(x))*20;   % 三次多项式 + 噪声

p = polyfit(x, y, 3);               % 三次拟合
y_fit = polyval(p, x);              % 估算值

plot(x, y, 'o', x, y_fit, '-');
legend('数据点', '拟合曲线');
```

---

# 三、插值 (interp1)

已知离散点，推测中间值：

```matlab
x = [0, 1, 2, 3, 4];
y = [0, 1, 4, 9, 16];

xq = 0:0.1:4;
y_linear = interp1(x, y, xq, 'linear');    % 线性插值
y_spline = interp1(x, y, xq, 'spline');    % 三次样条插值
y_pchip  = interp1(x, y, xq, 'pchip');     % 分段三次Hermite

plot(x, y, 'o', xq, y_linear, xq, y_spline, xq, y_pchip);
legend('原始', '线性', '样条', 'PCHIP');
```

`spline`给光滑曲线（过每个点），`pchip`更保守（不会过冲）。

# 四、二维插值

```matlab
[X, Y] = meshgrid(1:5, 1:5);
Z = peaks(5);                          % 5×5粗网格
[Xq, Yq] = meshgrid(1:0.2:5, 1:0.2:5); % 细网格
Zq = interp2(X, Y, Z, Xq, Yq, 'spline');
surf(Xq, Yq, Zq);
```
