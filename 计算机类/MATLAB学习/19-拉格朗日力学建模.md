# 19-拉格朗日力学建模

拉格朗日方法：**只用能量，不用力**。对复杂多体系统比牛顿-欧拉清爽得多。

---

# 一、拉格朗日方程

$$L = T - V \quad\text{(拉格朗日量 = 动能 - 势能)}$$

$$\frac{d}{dt}\frac{\partial L}{\partial \dot{q}_i} - \frac{\partial L}{\partial q_i} = Q_i$$

$q_i$是广义坐标，$Q_i$是广义力。

---

# 二、符号推导（单摆）

```matlab
syms m L g th dth real            % 符号变量

% 动能 T = ½ m (L θ̇)²
T = 0.5 * m * (L * dth)^2;

% 势能 V = mgL(1 - cosθ)
V = m * g * L * (1 - cos(th));

% 拉格朗日量
L = T - V;

% 手动推导 Euler-Lagrange 方程
% d/dt(∂L/∂θ̇) - ∂L/∂θ = 0
dL_ddth = diff(L, dth);              % ∂L/∂θ̇
ddt_dL_ddth = diff(dL_ddth, th) * dth;  % d/dt(∂L/∂θ̇)（链式法则）
dL_dth = diff(L, th);                % ∂L/∂θ
eom = ddt_dL_ddth - dL_dth;          % 运动方程

simplify(eom)
% 输出: L*m*(L*diff(th,t,2) + g*sin(th))
```

# 三、双摆的拉格朗日方程（符号推导）

```matlab
syms m1 m2 L1 L2 g th1 th2 dth1 dth2 real

% 位置
x1 = L1*sin(th1); y1 = -L1*cos(th1);
x2 = x1 + L2*sin(th2); y2 = y1 - L2*cos(th2);

% 速度
dx1 = L1*dth1*cos(th1); dy1 = L1*dth1*sin(th1);
dx2 = dx1 + L2*dth2*cos(th2); dy2 = dy1 + L2*dth2*sin(th2);

% 动能
T = 0.5*m1*(dx1^2+dy1^2) + 0.5*m2*(dx2^2+dy2^2);
% 势能
V = m1*g*y1 + m2*g*y2;
L = T - V;

% 对θ1和θ2各自推运动方程（省略繁琐的微分步骤）
```
