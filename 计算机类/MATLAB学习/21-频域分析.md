# 复习一下控制理论

## 1. 频率响应的物理含义

上一节说了，传递函数$G(s)$把$s=j\omega$代进去，$G(j\omega)$就是**频率响应**——系统对频率为$\omega$的正弦输入的稳态响应。

为什么是$j\omega$？因为正弦信号$\sin(\omega t)$的拉普拉斯变换是$\frac{\omega}{s^2+\omega^2}$——它的极点恰好在虚轴上$\pm j\omega$。系统的稳态输出由输入信号极点的贡献主导（传递函数自己的极点贡献随时间衰减，对应暂态）。

$$u(t) = A\sin(\omega t) \implies y_{ss}(t) = A|G(j\omega)|\sin(\omega t + \angle G(j\omega))$$

## 2. Bode图

Bode图把频率响应拆成两张子图：
- **幅频图**：$20\log_{10}|G(j\omega)|$（单位：分贝dB），横轴对数坐标
- **相频图**：$\angle G(j\omega)$（单位：度），横轴对数坐标

为什么要取对数？因为频率范围通常跨越好几个数量级（0.001到1000 rad/s），线性坐标根本看不清低频段。对数坐标压缩了高频、展宽了低频，整条曲线都能看全。

幅值取dB也是同样的原因——幅值可能从0.001变到1000，取对数后变成-60dB到+60dB。而且dB有个特别方便的性质：两个传递函数串联时幅值dB直接相加，相位也直接相加。乘除变加减。

$$|G_1 G_2|_{dB} = |G_1|_{dB} + |G_2|_{dB}$$

## 3. Nyquist图

Nyquist图把$G(j\omega)$的实部和虚部画在复平面上，$\omega$从$0$扫到$\infty$。它在**稳定性判断**上比Bode图更强。

**Nyquist稳定判据**是控制工程里最重要的定理之一：开环传递函数$G(s)H(s)$的Nyquist曲线逆时针包围$(-1,0)$点的圈数$N$，必须等于$G(s)H(s)$在右半平面的极点数$P$，闭环系统才稳定。

$$Z = P - N$$

$Z$是闭环右半平面极点数。$Z=0$才是稳定的。

直观理解：$(-1,0)$这个点对应着"分母为零"——闭环系统的极点。如果Nyquist曲线不包围这个点，闭环就没有不稳定极点。本质上是在看"开环的频率响应是否会在某个频率恰好给出增益=1、相位=180°的情况"，如果是——正反馈，发散。

## 4. 稳定裕度

- **增益裕度(GM)**：相位=-180°时，增益还能增大多少dB才到0dB。GM>0意味着Nyquist曲线没碰到$(-1,0)$。
- **相位裕度(PM)**：增益=0dB时，相位离-180°还有多少度。PM>0意味着有"相位余量"。

物理意义：增益裕度告诉你"放大倍数还能增大多少系统才不稳"，相位裕度告诉你"延迟还能增加多少度系统才不稳"。实际工程中，延迟相当于相位滞后，所以PM太小意味着对时延敏感。

# MATLAB实现

```matlab
s = tf('s');
G = 10 / (s * (s + 2) * (s + 5));   % 典型的三阶系统

bode(G); grid on;                    % Bode图
margin(G);                           % Bode图 + 标注GM和PM
```

```matlab
nyquist(G);                          % Nyquist图
```

`margin`函数直接给你算好增益裕度和相位裕度，图上标出来：

```matlab
[Gm, Pm, Wcg, Wcp] = margin(G);
fprintf('增益裕度: %.1f dB\n', 20*log10(Gm));
fprintf('相位裕度: %.1f°\n', Pm);
fprintf('截止频率: %.2f rad/s\n', Wcp);
```

工程经验：PM应该>45°（好的设计>60°），GM应该>6dB。

## 带宽

```matlab
fb = bandwidth(G);   % -3dB截止频率——增益降到直流增益的1/√2时的频率
```

带宽越大，系统响应越快——高频分量能通过，输出就能更快地跟上输入的变化。但带宽太大也意味着噪声过得多，传感器噪声会被放大。这是一个折中。
