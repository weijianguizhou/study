# 07-绘图基础

MATLAB的`plot`是它的另一个灵魂——三行代码出论文级图表。

---

# 一、基本二维图

```matlab
x = linspace(0, 2*pi, 100);
y1 = sin(x);
y2 = cos(x);

plot(x, y1);                     % 只画sin

plot(x, y1, x, y2);              % 画两条
legend('sin(x)', 'cos(x)');      % 图例
xlabel('x');                      % 横轴标签
ylabel('y');                      % 纵轴标签
title('正弦与余弦');
grid on;                          % 加网格
```

`plot`会自动分配不同颜色给每条线。

---

# 二、线型、颜色、标记

```matlab
plot(x, y, 'r--o')         % 红色(r)，虚线(--)，圆圈标记(o)

% 更清楚的写法
plot(x, y, 'Color', [0.2, 0.6, 0.3], ...
           'LineStyle', '-', ...
           'LineWidth', 2, ...
           'Marker', 'o', ...
           'MarkerSize', 6);
```

常用颜色：`r`红 `g`绿 `b`蓝 `k`黑 `m`品红 `c`青。线型：`-`实线 `--`虚线 `:`点线 `-.`点划线。

---

# 三、多子图 (subplot)

```matlab
subplot(2, 2, 1);          % 2行2列，第1个
plot(x, sin(x));
title('sin');

subplot(2, 2, 2);          % 第2个
plot(x, cos(x));
title('cos');

subplot(2, 2, 3);          % 第3个
plot(x, sin(2*x));
title('sin(2x)');

subplot(2, 2, 4);          % 第4个
plot(x, cos(2*x));
title('cos(2x)');
```

---

# 四、其他常用图表

```matlab
% 柱状图
x = [1, 2, 3, 4];
y = [10, 20, 15, 25];
bar(x, y);

% 直方图
data = randn(1000, 1);
histogram(data, 30);        % 分30个桶

% 散点图
x = randn(100, 1);
y = 0.5 * x + randn(100, 1) * 0.3;
scatter(x, y, 40, 'filled');

% 饼图
slices = [30, 20, 15, 35];
labels = {'A','B','C','D'};
pie(slices, labels);
```

# 五、保存与导出

```matlab
saveas(gcf, 'myplot.png');         % 当前图窗存为PNG
print('myplot', '-dpng', '-r300'); % 300 DPI高清图
exportgraphics(gcf, 'myplot.pdf'); % 导出为PDF (R2020a+)
```

# 六、双Y轴

```matlab
yyaxis left;
plot(x, sin(x));
ylabel('sin(x)');

yyaxis right;
plot(x, exp(x));
ylabel('exp(x)');
```
