# 26-雅可比矩阵

---

# 复习一下机器人学

## 1. 速度映射：关节 → 末端

$$\dot{\mathbf{x}} = J(\mathbf{q}) \dot{\mathbf{q}}$$

$\dot{\mathbf{q}} \in \mathbb{R}^n$是关节速度，$\dot{\mathbf{x}} \in \mathbb{R}^6$是末端速度（3个线速度+3个角速度）。$J$是$6 \times n$的雅可比矩阵。

**雅可比不是常量**——它依赖于当前位形$\mathbf{q}$。同样的关节角速度，在机器人蜷缩和伸直时产生的末端速度完全不同。你挥拳头时肘关节转同样的角度，手臂伸直时拳头的线速度比弯曲时大得多——这就是雅可比随位形变化的直观体现。

## 2. 线速度部分怎么算

末端的线速度是各个关节贡献的叠加。转动关节$i$让末端产生一个线速度，等于关节的角速度矢量和末端到关节位置的力臂的叉积：

$$\mathbf{v}_{end} = \sum_i \dot{q}_i (\mathbf{z}_i \times (\mathbf{p}_{end} - \mathbf{p}_i))$$

其中$\mathbf{z}_i$是关节$i$的旋转轴方向（在基座标系下），$\mathbf{p}_i$是关节$i$的位置，$\mathbf{p}_{end}$是末端位置。

叉积的直观理解：力臂越长（$\mathbf{p}_{end} - \mathbf{p}_i$大）、角速度越大（$\dot{q}_i$大）、力臂和转轴垂直时，线速度最大。

所以雅可比第$i$列的前三行（线速度部分）$= \mathbf{z}_i \times (\mathbf{p}_{end} - \mathbf{p}_i)$。后三行（角速度部分）$= \mathbf{z}_i$（转动关节的角速度直接贡献末端角速度）。

## 3. 力域中的雅可比——力传递

虚功原理：关节做的功 = 末端做的功。

$$\tau^T \dot{\mathbf{q}} = \mathbf{F}^T \dot{\mathbf{x}} = \mathbf{F}^T J \dot{\mathbf{q}}$$

因为对任意$\dot{\mathbf{q}}$成立，所以：

$$\tau = J^T \mathbf{F}$$

关节力矩 = 雅可比的**转置** × 末端力/力矩。这是力控制的核心公式——你要在末端施加多大的力，关节要出多大的力矩。

## 4. 奇异性

当$J$不满秩时（通常因为机器人把一些关节"对齐"了，丢失了一个或多个运动方向），逆运动学和力控制都会出问题：很小的末端速度需要无穷大的关节速度，很小的末端力需要无穷大的关节力矩。

条件数$\kappa(J) = \frac{\sigma_{max}(J)}{\sigma_{min}(J)}$衡量"离奇异有多近"——$\kappa$很大说明快丢秩了，应该避免这个位形。

# MATLAB实现

```matlab
function J = geometric_jacobian(DH, q)
    n = size(DH,1);
    J = zeros(6, n);
    T = eye(4);
    z_axes = zeros(3, n);
    p_joints = zeros(3, n);
    
    % 第一遍：记录每个关节的位置和Z轴
    for i = 1:n
        T = T * DH_transform(DH(i,1)+q(i), DH(i,2), DH(i,3), DH(i,4));
        z_axes(:,i) = T(1:3, 3);
        p_joints(:,i) = T(1:3, 4);
    end
    p_end = T(1:3, 4);
    
    % 第二遍：填雅可比
    for i = 1:n
        J(1:3, i) = cross(z_axes(:,i), p_end - p_joints(:,i));
        J(4:6, i) = z_axes(:,i);
    end
end
```

## 奇异性检测

```matlab
s = svd(J);
fprintf('条件数: %.1f\n', max(s)/min(s));
if min(s) < 1e-4
    warning('接近奇异位形！');
end
```
