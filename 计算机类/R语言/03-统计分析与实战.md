# 统计分析与实战

R是统计学家写的语言，做统计分析是R的看家本领。t检验、回归分析、方差分析，这些在别的语言里要装好几个包的事，R里就一行。

# 一、t检验

t检验用于比较两组数据的均值是否有显著差异。

## 1.1 数学背景

给你两组独立样本$\{x_1,\dots,x_n\}$和$\{y_1,\dots,y_m\}$，想知道它们的总体均值是否相同。

零假设$H_0$：两个总体均值相等（$\mu_x = \mu_y$）。
备择假设$H_1$：两个总体均值不等（$\mu_x \neq \mu_y$）。

t统计量：

$$t = \frac{\bar{x} - \bar{y}}{s_p \sqrt{\frac{1}{n} + \frac{1}{m}}}$$

其中$s_p$是合并标准差。如果$|t|$很大，意味着两组的差距远超随机波动，就拒绝$H_0$——"两者有显著差异"。

p值：在$H_0$成立的前提下，观察到比当前更极端结果的概率。p值越小，证据越倾向于拒绝$H_0$。惯例是p < 0.05就算"显著"。

## 1.2 独立样本t检验

```r
# 手动挡 vs 自动挡的油耗有没有显著差异？
auto_mpg   <- mtcars$mpg[mtcars$am == 0]   # 自动挡的油耗
manual_mpg <- mtcars$mpg[mtcars$am == 1]   # 手动挡的油耗

t.test(auto_mpg, manual_mpg)
```


**结论**：p值 = 0.0014 < 0.05，拒绝零假设。手动挡和自动挡的油耗有**显著差异**。手动挡平均油耗24.4 mpg，自动挡只有17.1 mpg——手动挡省油多了。

## 1.3 配对t检验

同一组对象在两种条件下的比较（比如减肥前后体重）：

```r
# 虚构10个人减肥前后的体重
before <- c(80, 75, 90, 85, 78, 95, 82, 88, 76, 92)
after  <- c(78, 73, 87, 82, 76, 91, 80, 86, 74, 89)

t.test(before, after, paired = TRUE)
```

# 二、线性回归

## 2.1 数学背景

回归分析研究一个因变量$Y$和一组自变量$X_1, X_2, \dots, X_k$之间的关系。最简单的是一元线性回归：

$$Y = \beta_0 + \beta_1 X + \varepsilon$$

$\beta_0$是截距（$X=0$时$Y$的预期值），$\beta_1$是斜率（$X$每增加1，$Y$预期增加多少）。$\varepsilon$是随机误差，假设$\varepsilon \sim N(0, \sigma^2)$。

参数的估计用**最小二乘法**——找使得$\sum(Y_i - \hat{Y}_i)^2$最小的$\beta_0, \beta_1$。

R里用`lm()`函数，`lm`就是"linear model"。

## 2.2 一元线性回归

```r
# 车重能不能预测油耗？
model <- lm(mpg ~ wt, data = mtcars)
summary(model)
```

**读结果**：

- **Intercept**（截距）= 37.285：理论上车重为0时油耗37.3 mpg（实际不存在0重量的车，这是数学外推）。
- **wt**（斜率）= -5.345：**车重每增加1吨，油耗减少约5.3 mpg**——车越重越耗油（合理）。
- 两个系数的p值都极小（星星`***`），说明都是**显著的**。
- **$R^2 = 0.753$**：车重这一个变量就解释了油耗75.3%的变异——很牛逼了。

所以回归方程是：

$$\widehat{mpg} = 37.3 - 5.3 \times wt$$

# 三、方差分析（ANOVA）

## 3.1 数学背景

t检验比较两组，ANOVA比较**三组及以上**的均值是否有差异。

思路：把总变异拆成两部分——**组间变异**（不同组之间的差异）和**组内变异**（同一组内部的随机波动）。

$$F = \frac{\text{组间方差}}{\text{组内方差}}$$

如果F值很大（组间差异远超组内波动），就说明不同组之间确实有别。

## 3.2 单因素ANOVA

```r
# 不同气缸数的车，油耗是否有显著差异？
# 先把cyl从数值变成因子
mtcars$cyl_factor <- factor(mtcars$cyl)

# 做ANOVA
aov_result <- aov(mpg ~ cyl_factor, data = mtcars)
summary(aov_result)
```

```cmd
            Df Sum Sq Mean Sq F value   Pr(>F)
cyl_factor   2  824.8   412.4    39.7 4.98e-09 ***
Residuals   29  301.3    10.4
```

p值极小——不同气缸数的油耗**确实有显著差异**。

## 3.3 事后检验：到底哪两组不一样？

ANOVA只告诉你"至少有一组不一样"，但不告诉你具体是哪组。事后用Tukey检验：

```r
TukeyHSD(aov_result)
```

```cmd
  Tukey multiple comparisons of means

```

**三组两两之间的p值都小于0.05**——4缸、6缸、8缸的油耗确实两两不同。

# 四、实战：完整数据分析流程

把上面学的东西串起来，做一个完整的分析流程：

```r
library(dplyr)
library(ggplot2)

# 1. 先看看数据长啥样
data(mtcars)
glimpse(mtcars)

# 2. 基本统计
mtcars %>%
    group_by(cyl) %>%
    summarise(
        count = n(),
        avg_mpg = mean(mpg),
        sd_mpg = sd(mpg)
    )

# 3. 画图看看
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
    geom_boxplot() +
    labs(title = "不同气缸数的油耗对比",
         x = "气缸数", y = "油耗 (mpg)") +
    theme_minimal()

# 4. 统计检验：是显著的吗？
t.test(mpg ~ am, data = mtcars)       # 手动vs自动
aov_result <- aov(mpg ~ factor(cyl), data = mtcars)
summary(aov_result)

# 5. 建立模型
model <- lm(mpg ~ wt + hp, data = mtcars)
summary(model)

# 6. 预测新数据
new_cars <- data.frame(
    wt = c(2.5, 3.0, 3.5),
    hp = c(120, 150, 200)
)
predicted <- predict(model, newdata = new_cars)
print(predicted)
```

典型的分析思路：**描述性统计 → 可视化 → 检验 → 建模 → 预测**。

# 五、总结

| 分析方法 | R函数 | 适用场景 |
|---------|-------|---------|
| t检验（两组比较）| `t.test()` | 两组均值差异 |
| 线性回归 | `lm()` | 用X预测Y |
| 方差分析 | `aov()` + `summary()` | 三组及以上均值比较 |
| 事后检验 | `TukeyHSD()` | ANOVA后看具体差异 |
| 预测 | `predict()` | 用建好的模型预测新数据 |
