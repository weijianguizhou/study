# 三、dplyr 数据操作

dplyr的核心是五个动词，搭配管道`%>%`使用。管道的意思是把左边的结果传到右边函数里——像流水线一样。

```r
library(dplyr)

# 管道操作：先筛选，再按组汇总，最后排序
mtcars %>%
    filter(cyl >= 6) %>%       # 只要6缸或8缸的车
    group_by(cyl) %>%          # 按气缸数分组
    summarise(
        count = n(),
        avg_mpg = mean(mpg),
        avg_hp = mean(hp)
    ) %>%
    arrange(desc(avg_mpg))     # 按平均油耗降序
```

```cmd
# A tibble: 2 × 4
    cyl count avg_mpg avg_hp
  <dbl> <int>   <dbl>  <dbl>
1     6     7    19.7   122.
2     8    14    15.1   209.
```

这句话翻译成人话："数据 → 过滤 → 分组 → 汇总 → 排序"。每一步都把结果传给下一步。每一行都是一个简洁的动词，逻辑一目了然。

## 3.1 五个核心动词

| 动词 | 作用 | 等价SQL |
|------|------|---------|
| `filter()` | 筛选行（按条件） | `WHERE` |
| `select()` | 选择列 | `SELECT` |
| `arrange()` | 排序 | `ORDER BY` |
| `mutate()` | 添加/修改列 | 计算列 |
| `summarise()` | 汇总（配合`group_by`）| `GROUP BY` + 聚合 |

```r
# select：只要这几列
mtcars %>% select(mpg, hp, wt) %>% head(3)
```

```cmd
                   mpg  hp    wt
Mazda RX4         21.0 110 2.620
Mazda RX4 Wag     21.0 110 2.875

```

```r
# mutate：算新列
mtcars %>%
    select(mpg, hp, wt) %>%
    mutate(
        power_ratio = hp / wt,         # 马力/重量比（推重比）
        efficient = ifelse(mpg > 20, "省油", "费油")
    ) %>%
    head(5)
```

# 四、ggplot2 画图

R的画图神器。它的语法是**图层叠加**——先搭一个基础（数据+坐标轴），然后一层一层往上加几何元素（点、线、柱子……）。

```r
library(ggplot2)

# 散点图：马力 vs 油耗
ggplot(mtcars, aes(x = hp, y = mpg)) +
    geom_point(aes(color = factor(cyl)), size = 3) +   # 点，颜色按气缸数
    geom_smooth(method = "lm", se = FALSE) +           # 线性拟合线
    labs(
        title = "马力 vs 油耗",
        x = "马力 (hp)",
        y = "油耗 (mpg)",
        color = "气缸数"
    ) +
    theme_minimal()
```

```r
# 箱线图：不同气缸数的油耗分布
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
    geom_boxplot() +
    labs(title = "不同气缸数的油耗分布",
         x = "气缸数", y = "油耗 (mpg)") +
    theme_minimal()
```

```r
# 直方图：油耗分布
ggplot(mtcars, aes(x = mpg)) +
    geom_histogram(binwidth = 3, fill = "steelblue", color = "white") +
    labs(title = "油耗分布", x = "油耗 (mpg)", y = "频数") +
    theme_minimal()
```

**ggplot2的公式**：

```
ggplot(数据, aes(x=..., y=..., color=...)) +   # 基础：数据 + 美学映射
    geom_xxx(...) +                            # 几何层：画什么
    labs(...) +                                # 标签：标题/坐标轴
    theme_xxx()                                # 主题：外观
```

对比Python的matplotlib那种"创建一个figure→add_subplot→调用plot函数→set_title"——ggplot2的图层语法明显更符合人类思维。

# 五、常用图表速查

| 想表达什么 | 用什么geom |
|-----------|-----------|
| 两个连续变量的关系 | `geom_point()` 散点图 |
| 趋势线 | `geom_smooth(method="lm")` 线性拟合 |
| 分类变量的分布 | `geom_boxplot()` 箱线图 |
| 单个变量的分布 | `geom_histogram()` 直方图 |
| 分类变量的计数 | `geom_bar()` 柱状图 |
| 随时间变化 | `geom_line()` 折线图 |
| 两个变量+频数密度 | `geom_density2d()` 等高线密度 |
