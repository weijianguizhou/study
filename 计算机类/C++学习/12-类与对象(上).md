# 12-类与对象(上)

C++的面向对象跟C的结构体一脉相承——但多了"封装"和"方法"。类就是把数据和操作这些数据的函数绑在一起。

---

# 一、从 struct 到 class

```cpp
#include <iostream>
#include <string>

class Student {
public:                       // 公开的
    std::string name;
    int age;
    double score;

    void print() {            // 方法：操作自己的数据
        std::cout << name << "，" << age << "岁，成绩" << score << std::endl;
    }
};

int main() {
    Student s1;               // 创建对象（不用写class/struct前缀）
    s1.name = "张三";
    s1.age = 20;
    s1.score = 95.5;
    s1.print();

    Student s2{"李四", 21, 88.0};  // C++11统一初始化
    s2.print();
}
```

```cmd
张三，20岁，成绩95.5
李四，21岁，成绩88
```

`class`和`struct`在C++里几乎一样——唯一区别是`struct`默认`public`，`class`默认`private`。

---

# 二、访问控制：public vs private

```cpp
class BankAccount {
private:                           // 私有的——外部不能直接访问
    std::string password;
    double balance;

public:                            // 公开的——外部可以访问
    void deposit(double amount) {
        if (amount > 0)            // 通过方法控制数据合法性
            balance += amount;
    }

    double getBalance() { return balance; }   // 只读访问器
};

int main() {
    BankAccount acc;
    acc.deposit(1000);
    // acc.balance = 99999;     // 编译错误！私有的不能碰
    std::cout << acc.getBalance() << std::endl;
}
```

**封装原则**：数据私有，方法公开。外部不能直接改你的内部数据——只能通过你规定的方法（带检查、带日志）来操作。这叫"把数据藏起来"（Data Hiding）。

---

# 三、构造函数

一个对象被创建时自动调用的函数。用来初始化对象的状态。

```cpp
class Student {
private:
    std::string name;
    int age;

public:
    // 构造函数——名字跟类名一样，没有返回值
    Student(const std::string &n, int a) {
        name = n;
        age = a;
        std::cout << name << " 被创建了" << std::endl;
    }

    // 默认构造函数
    Student() : name("未知"), age(0) {}

    void print() {
        std::cout << name << "，" << age << "岁" << std::endl;
    }
};

int main() {
    Student s1("张三", 20);   // 调用带参的构造函数
    s1.print();

    Student s2;               // 调用默认构造函数
    s2.print();
}
```

```cmd
张三 被创建了
张三，20岁
未知，0岁
```

**初始化列表**（更高效的初始化方式）：

```cpp
Student(const std::string &n, int a)
    : name(n), age(a)           // 初始化列表——直接在内存里构造，不先赋默认值
{
    // 函数体可以空着，或者做额外的逻辑
}
```

冒号后面叫**初始化列表**。它比在函数体里用`=`赋值效率高——`=`是先默认初始化再赋值，初始化列表是直接就构造好了。

# 四、析构函数

对象被销毁时自动调用的函数。用来做清理——释放资源、关闭文件、断开连接。

```cpp
~Student() {     // ~类名，无参数无返回值
    std::cout << name << " 被销毁了" << std::endl;
}
```

一个类只能有一个析构函数。它会在对象生命周期结束时自动调用——函数返回、`delete`、程序结束……不用你手动调。
