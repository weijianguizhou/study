# 02-变量与数据类型

C/C++跟Python最大的不同：**每个变量必须先声明类型才能用**。编译器要知道给这个变量分配多大内存、怎么解释里面的二进制。这篇把C的基本数据类型过一遍。

---

# 一、整数类型

## 1.1 四种基本整数

| 类型 | 典型大小 | 范围 |
|------|---------|------|
| `char` | 1字节(8位) | -128 ~ 127 或 0 ~ 255 |
| `short` | 2字节 | -32768 ~ 32767 |
| `int` | 4字节 | -2,147,483,648 ~ 2,147,483,647 |
| `long long` | 8字节 | -9×10¹⁸ ~ 9×10¹⁸ |

**`int`就是最常用的整数类型**。在32位和64位系统上都是4字节（跟`long`的宽度在不同平台可能不一样——这是C语言历史上的一笔烂账，写跨平台代码时要注意）。

```c
#include <stdio.h>

int main() {
    int age = 20;
    short year = 2026;
    long long big = 1234567890123LL;  // LL后缀表示long long常量
    char grade = 'A';                  // 字符本质上是个小整数

    printf("age = %d\n", age);
    printf("year = %hd\n", year);     // %hd 是 short 的格式
    printf("big = %lld\n", big);      // %lld 是 long long 的格式
    printf("grade = %c (ASCII: %d)\n", grade, grade);  // %c 字符, %d 对应ASCII值
    return 0;
}
```

```cmd
age = 20
year = 2026
big = 1234567890123
grade = A (ASCII: 65)
```

## 1.2 `unsigned`——只有非负数

```c
unsigned int x = 42;       // 0 ~ 4294967295
unsigned char y = 255;     // 0 ~ 255
```

无符号数把最高位（符号位）也用来表示数值了，所以范围扩大一倍但只能是非负数。

**坑**：无符号和有符号混用时会发生隐式转换，容易出诡异的bug。比如`-1 > 1U`的结果是`true`——因为-1先转成无符号（变成巨大的数4294967295），然后比较。

## 1.3 `sizeof`——看看到底占几个字节

```c
#include <stdio.h>

int main() {
    printf("char:      %zu 字节\n", sizeof(char));
    printf("short:     %zu 字节\n", sizeof(short));
    printf("int:       %zu 字节\n", sizeof(int));
    printf("long:      %zu 字节\n", sizeof(long));
    printf("long long: %zu 字节\n", sizeof(long long));
    printf("float:     %zu 字节\n", sizeof(float));
    printf("double:    %zu 字节\n", sizeof(double));
    printf("指针:       %zu 字节\n", sizeof(void*));
    return 0;
}
```

```cmd
char:      1 字节
short:     2 字节
int:       4 字节
long:      4 字节
long long: 8 字节
float:     4 字节
double:    8 字节
指针:       8 字节
```

`sizeof`是编译期运算符（不是函数）——编译器在编译时就知道每个类型多大，直接替换成常量。`%zu`是`size_t`的格式说明符。

# 二、浮点类型

```c
float  pi = 3.14159f;    // f后缀表示float常量（不加默认double）
double e  = 2.718281828;  // 双精度
```

IEEE 754标准下：
- `float`：32位（1位符号+8位指数+23位尾数），约7位有效数字
- `double`：64位（1位符号+11位指数+52位尾数），约16位有效数字

**日常写代码直接用`double`**，现代CPU上double不比float慢，精度还好得多。`float`只在你明确需要省内存（比如一个存了百万个数的数组）的时候才用。

```c
double a = 0.1;
double b = 0.2;
printf("%.20f\n", a + b);   // 0.30000000000000004441
```

浮点不是精确的——0.1在二进制里是无限循环小数（就像1/3在十进制里是0.333...一样），截断后就差那么一丁点。**别用`==`比较浮点数**。

# 三、字符类型

`char`在C里本质是1字节的整数。每个字符对应一个ASCII码：

```c
char c = 'A';
printf("%c = %d\n", c, c);   // A = 65

// 大小写转换（利用ASCII的数学关系）
char lower = 'a';
char upper = lower - 32;     // 'a'(97) - 32 = 'A'(65)
printf("%c → %c\n", lower, upper);

// 判断是否数字
char digit = '7';
if (digit >= '0' && digit <= '9')
    printf("%c 是数字\n", digit);
```

大写字母A-Z的ASCII是65-90。小写a-z是97-122。大小写差32——二进制的第5位是0=大写、1=小写。

# 四、类型转换

```c
int a = 10, b = 3;

// 整数除法：两整数相除结果还是整数（截断）
printf("%d / %d = %d\n", a, b, a / b);   // 3

// 要想得浮点数，至少一个操作数是浮点
printf("%d / %d = %f\n", a, b, (double)a / b);  // 3.333333

// 强制类型转换
double pi = 3.14159;
int trunc_pi = (int)pi;    // 3，直接截掉小数
printf("%d\n", trunc_pi);
```

C/C++的隐式转换规则：表达式里"窄"的类型自动升级成"宽"的类型（`char→int→long→float→double`）。

# 五、常量

```c
#define PI 3.14159           // 预处理宏（C风格，不推荐C++里用）
const double E = 2.71828;    // const常量（有类型，编译器能检查）

enum Color { RED, GREEN, BLUE };   // 枚举（一组命名整数常量）
// RED=0, GREEN=1, BLUE=2

enum Status { OK = 200, NOT_FOUND = 404, ERROR = 500 };
```

C++里尽量用`const`代替`#define`——`const`有类型、有作用域、能调试。`#define`只是文本替换，出错了编译器报的行号是展开后的位置，根本找不到源头。
