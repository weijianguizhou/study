# 04-运算符与表达式

运算符就是告诉计算机做什么运算的符号。C的运算符又多又杂，这篇按优先级分组讲。

---

# 一、算术运算符

```c
int a = 10, b = 3;
printf("a + b = %d\n", a + b);   // 13
printf("a - b = %d\n", a - b);   // 7
printf("a * b = %d\n", a * b);   // 30
printf("a / b = %d\n", a / b);   // 3  整数除法截断
printf("a %% b = %d\n", a % b);  // 1  取余
```

`%`是取余（模运算）：$10 \div 3 = 3\text{余}1$。注意`printf`里打`%`要写成`%%`。

**整数除法截断**是C的一个特性——两整数相除结果也是整数。`10/3`就是3，不是3.333。想得小数，把其中一个转成浮点：`(double)a / b`。

```c
int x = 5;
x++;      // x = 6  后加
++x;      // x = 7  前加
x--;      // x = 6  后减

// 前加和后加的区别：
int y = x++;    // y = 6, x = 7  先用x的旧值赋值，再自增
int z = ++x;    // z = 8, x = 8  先自增，再赋值
```

# 二、关系运算符（比大小）

返回`1`（真）或`0`（假）。C里没有独立的`bool`类型（C99以后有了`_Bool`，但1/0照样用）。

```c
int a = 10, b = 5;
printf("a > b  = %d\n", a > b);    // 1
printf("a < b  = %d\n", a < b);    // 0
printf("a >= b = %d\n", a >= b);   // 1
printf("a <= b = %d\n", a <= b);   // 0
printf("a == b = %d\n", a == b);   // 0  相等要用==
printf("a != b = %d\n", a != b);   // 1  不等
```

**经典坑**：`=`是赋值，`==`是判断相等。

```c
int x = 5;
if (x = 10)    // 把10赋给x，返回10（非0=真），条件永远成立！
    printf("这行永远会执行\n");
```

这种bug编译器不报错（因为语法合法），但逻辑全乱。防范方法：常量写左边——`if (10 == x)`，这样少写一个等号会编译报错。

# 三、逻辑运算符

```c
int a = 1, b = 0;    // 非0=真，0=假
printf("a && b = %d\n", a && b);   // 0  与：两边都真才真
printf("a || b = %d\n", a || b);   // 1  或：有一边真就真
printf("!a     = %d\n", !a);       // 0  非：取反
```

**短路求值**：`&&`左边为假，右边根本不算；`||`左边为真，右边不算。这个特性很有用：

```c
// 安全地判断指针非空再访问
if (p != NULL && p->value > 10)    // 如果p是NULL，p->value根本不会执行
```

# 四、位运算符

对整数的二进制位直接操作。嵌入式、底层优化、位标志的常用工具。

```c
unsigned char a = 0b00001111;   // 15
unsigned char b = 0b00110011;   // 51

printf("a & b  = 0x%02X\n", a & b);    // 0x03  按位与
printf("a | b  = 0x%02X\n", a | b);    // 0x3F  按位或
printf("a ^ b  = 0x%02X\n", a ^ b);    // 0x3C  按位异或
printf("~a     = 0x%02X\n", ~a);       // 按位取反
printf("a << 2 = 0x%02X\n", a << 2);   // 0x3C  左移2位
printf("b >> 1 = 0x%02X\n", b >> 1);   // 0x19  右移1位
```

$$
\begin{aligned}
a &= 0000\,1111_2 \\
b &= 0011\,0011_2 \\
a \,\&\, b &= 0000\,0011_2 = 3 \\
a \mid b &= 0011\,1111_2 = 63 \\
a \oplus b &= 0011\,1100_2 = 60
\end{aligned}
$$

**常用操作**：

```c
// 判断某位是0还是1
if (x & (1 << 3))   // x的第3位（从0数）是1吗？

// 把某位置1
x |= (1 << 5);      // 把第5位置1

// 把某位清0
x &= ~(1 << 2);     // 把第2位清0

// 交换两数（不用中间变量）
a ^= b; b ^= a; a ^= b;

// 乘/除2的幂（比乘法除法快）
x = y << 3;   // y * 8
x = y >> 1;   // y / 2
```

# 五、赋值与复合赋值

```c
int a = 10;
a += 5;    // a = a + 5
a -= 3;    // a = a - 3
a *= 2;    // a = a * 2
a /= 4;    // a = a / 4
a %= 3;    // a = a % 3
a &= 0xF;  // a = a & 0xF
a |= 0x80; // a = a | 0x80
a <<= 2;   // a = a << 2
```

# 六、三元条件运算符

```c
int max = (a > b) ? a : b;   // 如果a>b取a，否则取b

// 等价于：
int max;
if (a > b) max = a; else max = b;
```
