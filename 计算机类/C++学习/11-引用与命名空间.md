# 11-引用与命名空间

前面C的内容讲完了，从这篇开始进入C++独有的特性。第一个就是**引用**——不用指针也能修改变量的神器。

---

# 一、引用（Reference）

引用就是给一个变量**取别名**。就像你大名叫"张三"，小名叫"阿三"——叫哪个名字指的都是同一个人。

```cpp
#include <iostream>

int main() {
    int a = 42;
    int &ref = a;      // ref 是 a 的引用（别名）

    std::cout << "a = " << a << std::endl;     // 42
    std::cout << "ref = " << ref << std::endl; // 42

    ref = 100;   // 通过引用改a
    std::cout << "a = " << a << std::endl;     // 100

    std::cout << "地址相同: " << &a << " == " << &ref << std::endl;
}
```

```cmd
a = 42
ref = 42
a = 100
地址相同: 0x7fff... == 0x7fff...
```

引用和指针最大的区别：
- **引用必须在声明时初始化**，之后不能再换成别的变量。
- **引用没有"空引用"**，它一定指向某个合法变量。
- 使用引用时不用写`*`和`&`——直接用，编译器帮你把底层的解引用干了。

# 二、引用做函数参数：不用指针也能改外部变量

```cpp
void swap(int &x, int &y) {
    int temp = x;
    x = y;
    y = temp;
}

int main() {
    int a = 10, b = 20;
    swap(a, b);    // 直接传变量，不用取地址
    std::cout << a << " " << b << std::endl;  // 20 10
}
```

对比C里的`swap(int *x, int *y)`——调用要`swap(&a, &b)`，函数里要用`*x`。C++的引用让代码清爽多了。

## 值传递 vs 引用传递

| | 值传递 | 引用传递 |
|---|---|---|
| 声明 | `void f(int x)` | `void f(int &x)` |
| 调用 | `f(a)` | `f(a)` |
| 开销 | 拷贝整个变量（大对象很贵）| 只传地址（几乎免费）|
| 能改外部吗 | 不能 | 能 |

建议：**只读参数用`const`引用**（既高效又安全）：

```cpp
void print(const std::string &s) {
    // s 只读，不会意外修改
    std::cout << s << std::endl;
}
```

# 三、命名空间（namespace）

命名空间解决**名字冲突**的问题。两个人写了两个叫`init`的函数，你同时用他们的代码——编译报错。命名空间把名字关进不同的"房间"。

```cpp
namespace A {
    void hello() { std::cout << "A::hello\n"; }
}

namespace B {
    void hello() { std::cout << "B::hello\n"; }
}

int main() {
    A::hello();   // 用::指定
    B::hello();
}
```

```cpp
// using 声明：省略前缀
using std::cout;
using std::endl;
cout << "不用写std::了" << endl;

// using namespace：全导入（不推荐在头文件里用）
using namespace std;
```

`std`就是C++标准库的命名空间。所有标准库的东西都在`std`里。自己写代码不要用`using namespace std`在头文件里——会污染全局命名空间。
