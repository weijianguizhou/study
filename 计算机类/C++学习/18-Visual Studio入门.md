# 18-Visual Studio入门

前面一直在用命令行`g++`编译。真正做项目时，IDE能让你的效率翻几倍——代码补全、断点调试、项目管理，一条龙。这篇带你装好VS跑起来。

---

# 一、安装

去 [visualstudio.microsoft.com](https://visualstudio.microsoft.com) 下载**Visual Studio Community**（免费）。安装时勾选**"使用C++的桌面开发"**工作负荷。安装要十几二十分钟，喝杯水等着。

装完后打开，你看到的界面分为几块：左侧项目浏览器、中间代码编辑器、下方输出/错误窗口。

---

# 二、第一个VS项目

1. 打开VS → **创建新项目** → 选 **"控制台应用"**（C++）→ 下一步
2. 给项目起个名（比如`HelloWorld`），选一个文件夹存
3. 点创建

VS会自动生成一个`HelloWorld.cpp`：

```cpp
#include <iostream>

int main() {
    std::cout << "Hello World!\n";
    return 0;
}
```

按`Ctrl+F5`（不调试运行），会弹一个黑窗口显示"Hello World!"。

---

# 三、调试

调试是IDE最重要的功能。别用`printf`一行行打印来排查——断点调试快十倍。

1. 在代码行号的左边点一下，出现一个**红点**（断点）
2. 按`F5`启动调试
3. 程序运行到断点会**暂停**，这时你可以：
   - 把鼠标悬停在变量上——看它的值
   - `F10`：**逐过程**（执行当前行，不进入函数内部）
   - `F11`：**逐语句**（如果当前行有函数调用，进入到函数里面）
   - `Shift+F11`：**跳出**（从函数里跳出来）
   - `F5`：继续运行到下一个断点或程序结束
4. 左下角有**局部变量窗口**和**监视窗口**——你可以把变量拖进监视窗口持续跟踪

---

# 四、VS的项目结构

VS把相关文件组织成解决方案（`.sln`）和项目（`.vcxproj`）：

```
解决方案 (MyApp.sln)
├── 项目1 (MyApp.vcxproj)
│   ├── main.cpp
│   ├── utils.cpp
│   └── utils.h
└── 项目2 (MyLib.vcxproj)
    └── library.cpp
```

一个解决方案可以包含多个项目。比如一个`exe`项目 + 一个`lib`项目。

---

# 五、常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+F5` | 编译+运行（不调试）|
| `F5` | 开始调试 |
| `F9` | 切换断点 |
| `F10` | 逐过程 |
| `F11` | 逐语句 |
| `Ctrl+K, Ctrl+C` | 注释选中行 |
| `Ctrl+K, Ctrl+U` | 取消注释 |
| `Ctrl+F` | 查找 |
| `Ctrl+Shift+F` | 全局查找 |
