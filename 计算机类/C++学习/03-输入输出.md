# 03-输入输出

程序不能光自己在内存里嗨，得跟人交流。C用`printf`/`scanf`，C++用`cin`/`cout`。这篇都讲，顺带把格式化输出整明白。

---

# 一、C风格：printf 输出

`printf`的核心是**格式字符串**——一个带`%`占位符的模板，后面的参数逐一填入。

## 1.1 格式占位符

| 占位符 | 类型 | 说明 |
|--------|------|------|
| `%d` | int | 十进制整数 |
| `%f` | float/double | 浮点数（默认6位小数）|
| `%.2f` | float/double | 保留2位小数 |
| `%c` | char | 单个字符 |
| `%s` | char* | 字符串 |
| `%p` | void* | 指针地址 |
| `%x` / `%X` | int | 十六进制（小写/大写）|
| `%o` | int | 八进制 |
| `%%` | — | 输出一个百分号 |
| `%zu` | size_t | sizeof的返回类型 |

```c
#include <stdio.h>

int main() {
    int age = 20;
    double score = 95.5;
    char grade = 'A';
    char name[] = "张三";

    printf("我叫%s，今年%d岁\n", name, age);
    printf("成绩: %.1f 分, 等级: %c\n", score, grade);
    printf("十六进制: 255 = 0x%X\n", 255);
    printf("地址: %p\n", &age);

    return 0;
}
```

```cmd
我叫张三，今年20岁
成绩: 95.5 分, 等级: A
十六进制: 255 = 0xFF
地址: 00000073211FFAB4
```

## 1.2 格式控制

```c
printf("右对齐: |%10d|\n", 42);       // |        42|
printf("左对齐: |%-10d|\n", 42);      // |42        |
printf("补零:   |%010d|\n", 42);      // |0000000042|
printf("浮点:   |%.3f|\n", 3.14159);  // |3.142|
```

# 二、C风格：scanf 输入

```c
#include <stdio.h>

int main() {
    int age;
    double height;
    char name[50];

    printf("年龄: ");
    scanf("%d", &age);               // 注意：变量前面要加 &

    printf("身高(米): ");
    scanf("%lf", &height);           // double用%lf，float用%f

    printf("名字: ");
    scanf("%s", name);               // 字符串不用加&——数组名本身就是地址

    printf("%s，%d岁，%.2f米\n", name, age, height);
    return 0;
}
```

```cmd
年龄: 20
身高(米): 1.75
名字: 张三
张三，20岁，1.75米
```

**`&`是什么意思？** `scanf`需要知道"把输入的值存到哪个内存位置"。`&age`就是取`age`的地址——把地址传进去，`scanf`顺着地址找到那片内存，把值写进去。这叫**传址**。

为什么`scanf("%s", name)`不用加`&`？因为数组名`name`本身就是指向第一个元素的指针，它已经是个地址了。

## scanf的坑

`scanf`读字符串时遇到**空格**就停了——输"张 三"只会读到"张"。要读一行带空的用`fgets`。

`scanf`不检查缓冲区溢出——如果你只预留了50字节的数组，用户输入了500个字符……后果自负。安全的替代是`fgets(name, 50, stdin)`，或者在格式串里限制宽度：`scanf("%49s", name)`。

# 三、C++风格：cin / cout

```cpp
#include <iostream>
#include <string>
#include <iomanip>

int main() {
    int age;
    double height;
    std::string name;

    std::cout << "年龄: ";
    std::cin >> age;

    std::cout << "身高(米): ";
    std::cin >> height;

    std::cout << "名字: ";
    std::cin >> name;                    // 读到空格停

    std::cout << name << "，" << age << "岁，"
              << std::fixed << std::setprecision(2)  // 固定2位小数
              << height << "米" << std::endl;

    return 0;
}
```

C++的IO：
- **不需要格式占位符**——编译器根据变量类型自动选
- **不需要`&`**——C++的引语在底层自动处理了地址
- **安全的字符串**——`std::string`自动管理内存，不怕溢出

`std::endl`和`"\n"`的区别：`endl`多干一件事——**刷新输出缓冲区**。频繁刷新会拖慢IO，大部分时候用`"\n"`就够了。

# 四、读带空格的整行

```cpp
#include <iostream>
#include <string>

int main() {
    std::string line;
    std::cout << "输入一句话: ";
    std::getline(std::cin, line);     // 读一整行，保留空格
    std::cout << "你输入的是: " << line << std::endl;
    return 0;
}
```

```cmd
输入一句话: Hello World from C++
你输入的是: Hello World from C++
```
