# 10-结构体与枚举

数组只能存同类型的数据。结构体让你把不同类型的数据打包成一个整体——学生的名字（字符串）+年龄（int）+成绩（double），一锅端。

---

# 一、struct 定义和使用

```c
#include <stdio.h>
#include <string.h>

// 定义一个结构体类型
struct Student {
    char name[50];
    int age;
    double score;
};

int main() {
    // 创建结构体变量
    struct Student s1;
    strcpy(s1.name, "张三");   // 字符数组不能直接赋值，得用strcpy
    s1.age = 20;
    s1.score = 95.5;

    printf("姓名: %s, 年龄: %d, 成绩: %.1f\n", s1.name, s1.age, s1.score);
    return 0;
}
```

```cmd
姓名: 张三, 年龄: 20, 成绩: 95.5
```

C里每次用结构体都要写`struct Student`，有点烦。通常用`typedef`给个短名字：

```c
typedef struct {
    char name[50];
    int age;
    double score;
} Student;

int main() {
    Student s1 = {"李四", 21, 88.0};  // 直接初始化
    printf("%s, %d岁\n", s1.name, s1.age);
}
```

C++里不需要`typedef`——`struct`名直接就是类型名。

---

# 二、结构体指针

```c
Student s = {"张三", 20, 95.5};
Student *p = &s;

// 通过指针访问成员：用 ->
printf("%s\n", p->name);     // 等价 (*p).name
printf("%d\n", p->age);
```

`p->name`是`(*p).name`的简写，意思是"顺着指针找到结构体，再拿它的name成员"。

---

# 三、枚举 enum

把一组命名常量打包：

```c
enum Color { RED, GREEN, BLUE };          // RED=0, GREEN=1, BLUE=2
enum Status { OK = 200, NOT_FOUND = 404, ERROR = 500 };

int main() {
    enum Color c = GREEN;
    printf("%d\n", c);   // 1

    if (c == GREEN)
        printf("是绿色\n");
}
```

C++里用`enum class`更安全（作用域限定，不会全局命名冲突）：

```cpp
enum class Color { Red, Green, Blue };
Color c = Color::Red;
// int x = c;  // 编译错误！enum class不能隐式转int
```
