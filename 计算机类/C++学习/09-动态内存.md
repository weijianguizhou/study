# 09-动态内存

前面所有变量的内存都是**编译器自动管的**——函数里声明一个`int a`，函数返回时它自动销毁。这叫**栈内存**。但有时候你需要在运行时才决定数组多大、需要让一个变量活得比函数更久——这时候得手动管理**堆内存**。

---

# 一、malloc 和 free（C风格）

```c
#include <stdio.h>
#include <stdlib.h>   // malloc, free

int main() {
    int n;
    printf("要几个数？");
    scanf("%d", &n);

    // 在堆上分配 n 个 int 的空间
    int *arr = (int*)malloc(n * sizeof(int));

    // 像普通数组一样用
    for (int i = 0; i < n; i++)
        arr[i] = i * 10;

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    free(arr);    // 用完记得还！
    return 0;
}
```

```cmd
要几个数？5
0 10 20 30 40
```

`malloc(n * sizeof(int))`：向操作系统申请$n \times 4$字节的内存。返回这块内存的起始地址（`void*`指针，需要强制转成`int*`）。

`free(arr)`：把内存还给操作系统。**不调用free就会内存泄漏**——程序运行越久占的内存越多，最终把系统内存吃光。

---

# 二、new 和 delete（C++风格）

C++用`new`和`delete`代替`malloc/free`。它们不仅分配内存，还会调用构造函数和析构函数（后面类那篇讲）。

```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "要几个数？";
    std::cin >> n;

    // 分配数组
    int *arr = new int[n];

    for (int i = 0; i < n; i++)
        arr[i] = i * 10;

    for (int i = 0; i < n; i++)
        std::cout << arr[i] << " ";

    delete[] arr;    // 数组删除用 delete[]
    return 0;
}
```

| C | C++ |
|----|-----|
| `malloc(size)` | `new Type` / `new Type[n]` |
| `free(ptr)` | `delete ptr` / `delete[] ptr` |
| 返回`void*`需强转 | 返回正确类型 |
| 不调用构造/析构 | 调用构造/析构 |

**规则**：`new`了就用`delete`，`new[]`了就用`delete[]`。混用是未定义行为。

---

# 三、内存泄漏

```c
void leak() {
    int *p = malloc(1000000);   // 申请了1M内存
    // 忘了free！函数返回后p消失，但那1M内存还在堆里没人管
}
```

每次调用`leak`都泄漏1MB。循环1000次就吃掉1GB内存。程序跑久了内存爆掉，操作系统杀进程。

**防范**：谁申请、谁释放。在申请的那行后面马上写一句`free`（或`delete`），再在中间填代码。
