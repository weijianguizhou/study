# 一、智能指针

前面讲了`new`/`delete`——手管内存容易出事。忘了`delete`就内存泄漏，多`delete`一次就崩溃。C++11起，**智能指针**自动管理内存——对象不用了就自动释放。别再写`delete`了。

## 1.1 unique_ptr — 独占所有权

一个对象只能有一个`unique_ptr`指向它。不能拷贝，只能转移。

```cpp
#include <memory>
#include <iostream>

class Foo {
public:
    Foo()  { std::cout << "构造\n"; }
    ~Foo() { std::cout << "析构\n"; }
    void hello() { std::cout << "Hello\n"; }
};

int main() {
    std::unique_ptr<Foo> p1(new Foo);     // C++11
    auto p2 = std::make_unique<Foo>();     // C++14（推荐）
    
    p2->hello();

    // std::unique_ptr<Foo> p3 = p2;      // 编译错误！不能拷贝
    std::unique_ptr<Foo> p3 = std::move(p2);  // 转移所有权
    // p2现在为空，p3拥有Foo对象
}  // 离开作用域，自动析构
```

```cmd
构造
构造
Hello
析构
析构
```

`std::make_unique`是推荐做法——一条语句完成分配和包装，没有裸`new`。

## 1.2 shared_ptr — 共享所有权

多个`shared_ptr`可以指向同一个对象。最后一个`shared_ptr`销毁时对象才释放。内部用引用计数跟踪还有几个指针在用。

```cpp
auto p1 = std::make_shared<int>(42);
auto p2 = p1;            // 引用计数 = 2
// p2离开作用域，计数减到1
// p1离开作用域，计数减到0，对象释放
```

## 1.3 什么时候用哪个

| | unique_ptr | shared_ptr |
|---|---|---|
| 开销 | 零开销（跟裸指针一样大）| 有引用计数 |
| 所有权 | 独占 | 共享 |
| 适用 | 局部变量、容器元素、工厂函数返回值 | 多个地方需要共享的对象 |

**绝大多数时候用`unique_ptr`**。需要共享才上`shared_ptr`。

# 二、模板

模板让你写一份代码，适配任意类型。STL的`vector<int>`和`vector<string>`用的是同一份模板代码，编译器按需生成。

## 2.1 函数模板

```cpp
template <typename T>
T max(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    std::cout << max(3, 5) << std::endl;           // 5 (T=int)
    std::cout << max(3.14, 2.71) << std::endl;     // 3.14 (T=double)
    std::cout << max<std::string>("abc", "abd") << std::endl;  // abd
}
```

编译器看到`max(3,5)`时，自动推导`T=int`，生成一个`max`的int版本。这不是运行时决定的——是**编译期**的事。

## 2.2 类模板

```cpp
template <typename T>
class Box {
    T value;
public:
    Box(T v) : value(v) {}
    T get() { return value; }
};

int main() {
    Box<int> b1(42);
    Box<std::string> b2("hello");
    std::cout << b1.get() << " " << b2.get() << std::endl;
}
```
