# 14-继承与多态

面向对象的三大支柱：**封装**（上两篇讲了）、**继承**、**多态**。继承让你复用代码，多态让你用统一的接口操作不同的对象。

---

# 一、继承

```cpp
class Animal {                     // 基类（父类）
protected:                         // 子类可以访问，外部不行
    std::string name;
public:
    Animal(const std::string &n) : name(n) {}
    void eat() { std::cout << name << " is eating\n"; }
};

class Dog : public Animal {        // Dog 继承自 Animal
public:
    Dog(const std::string &n) : Animal(n) {}  // 调父类构造

    void bark() { std::cout << name << " says: 汪汪！\n"; }
};

int main() {
    Dog d("旺财");
    d.eat();    // 继承了父类的方法
    d.bark();   // 自己的方法
}
```

```cmd
旺财 is eating
旺财 says: 汪汪！
```

**三种继承方式**：

| 继承方式 | 父类public→子类 | 父类protected→子类 | 父类private→子类 |
|---------|---------------|-------------------|-----------------|
| `public` | public | protected | 不可访问 |
| `protected` | protected | protected | 不可访问 |
| `private` | private | private | 不可访问 |

99%的情况用`public`继承——"Dog is a Animal"的关系。

# 二、多态与虚函数

**多态**：同一个接口，不同行为。基类的指针或引用，可以指向不同的子类，调用对应子类的版本。

```cpp
class Animal {
public:
    virtual void speak() {           // virtual = 多态的关键
        std::cout << "Animal sound\n";
    }
};

class Dog : public Animal {
public:
    void speak() override {          // override = 编译器帮我检查是否真的重写了
        std::cout << "汪汪！\n";
    }
};

class Cat : public Animal {
public:
    void speak() override {
        std::cout << "喵喵！\n";
    }
};

int main() {
    Animal *animals[] = {new Dog(), new Cat(), new Dog()};

    for (auto a : animals)
        a->speak();   // 调用的是子类的版本！

    for (auto a : animals)
        delete a;
}
```

```cmd
汪汪！
喵喵！
汪汪！
```

**没有`virtual`的话**，`a->speak()`永远调的是`Animal`的版本——因为编译器只看指针的类型，不看指针实际指向什么东西。

**有了`virtual`**，编译器给每个对象塞了一张**虚函数表（vtable）**。运行时通过查表找到真正的函数地址。代价是每次虚函数调用多一次间接寻址。

# 三、纯虚函数和抽象类

```cpp
class Shape {
public:
    virtual double area() = 0;    // = 0 = 纯虚函数，子类必须实现
    virtual ~Shape() {}           // 虚析构函数（重要！）
};

class Circle : public Shape {
    double r;
public:
    Circle(double r) : r(r) {}
    double area() override { return 3.14159 * r * r; }
};

class Rectangle : public Shape {
    double w, h;
public:
    Rectangle(double w, double h) : w(w), h(h) {}
    double area() override { return w * h; }
};
```

含有纯虚函数的类叫**抽象类**——不能直接创建对象。它的作用就是给所有子类规定"你必须实现这些函数"。

**关于虚析构函数**：如果基类的析构函数不是虚的，当用基类指针删除子类对象时，子类的析构函数不会被调用——可能导致资源泄漏。写成`virtual ~Shape() {}`就保证了正确的析构顺序。
