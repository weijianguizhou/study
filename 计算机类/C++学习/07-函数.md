# 07-函数

函数就是把一段逻辑打包，取个名字，以后随时随地调它。打好了包你就不用每次都重写同样的代码了。

---

# 一、函数的定义和调用

```c
#include <stdio.h>

// 返回值类型 函数名(参数列表) { 函数体 }
int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(3, 5);
    printf("3 + 5 = %d\n", result);
    printf("10 + 20 = %d\n", add(10, 20));
    return 0;
}
```

```cmd
3 + 5 = 8
10 + 20 = 30
```

`add`函数接收两个`int`，返回它们的和（也是`int`）。函数调用本质是跳转——程序跑到`add`的代码那儿去执行，`return`以后跳回来。

## 函数声明 vs 函数定义

C要求函数在使用前**声明**。声明只告诉编译器"有这么一个函数，它长这样"，不写函数体：

```c
// 声明（放最前面）
int add(int a, int b);

int main() {
    printf("%d\n", add(1, 2));   // 编译器知道add的存在了
    return 0;
}

// 定义（放后面，函数体写这里）
int add(int a, int b) {
    return a + b;
}
```

**声明=写契约**（签名），**定义=写实现**（函数体）。声明可以重复多次，定义只能一次。

# 二、参数传递：值传递

```c
void change(int x) {
    x = 100;   // 只改了局部变量x，外面不受影响
}

int main() {
    int a = 42;
    change(a);
    printf("%d\n", a);   // 42，没变！
    return 0;
}
```

C/C++默认是**值传递**——函数收到的是变量的**副本**，改副本不影响原件。想改原件？得传地址（指针），后面指针那篇讲。

# 三、递归

函数自己调用自己。

```c
// 阶乘: n! = n * (n-1)!
int factorial(int n) {
    if (n <= 1) return 1;          // 终止条件
    return n * factorial(n - 1);   // 递归调用
}

int main() {
    printf("5! = %d\n", factorial(5));  // 120
    return 0;
}
```

递归的核心：**终止条件 + 问题规模缩小**。每一层都把问题缩小一点，最终到终止条件开始"往回"计算结果。

注意递归层数太深会**栈溢出**——每次递归调用都在栈上占一块内存，层数太多栈就爆了。

# 四、C++的函数重载

C++允许**同一个名字的函数，参数不同**：

```cpp
#include <iostream>

int add(int a, int b)       { return a + b; }
double add(double a, double b) { return a + b; }
int add(int a, int b, int c)   { return a + b + c; }

int main() {
    std::cout << add(1, 2) << std::endl;        // 3 (调int版)
    std::cout << add(1.5, 2.5) << std::endl;    // 4.0 (调double版)
    std::cout << add(1, 2, 3) << std::endl;     // 6 (调三参数版)
}
```

编译器根据参数类型和个数**自动选**调用哪个版本。这叫**函数重载**——C没有这个特性。

# 五、C++的默认参数

```cpp
void greet(std::string name, std::string greeting = "你好") {
    std::cout << greeting << "，" << name << "！" << std::endl;
}

int main() {
    greet("张三");                    // 你好，张三！
    greet("李四", "早上好");           // 早上好，李四！
}
```

默认参数有几个规矩：
1. 有默认值的参数必须放在**最后面**
2. 声明和定义只能有一处写默认值（通常写在声明里）

# 六、作用域与static

```c
void counter() {
    static int count = 0;   // static局部变量=只初始化一次，函数退出也不销毁
    count++;
    printf("第%d次调用\n", count);
}

int main() {
    counter();  // 第1次调用
    counter();  // 第2次调用
    counter();  // 第3次调用
}
```

局部`static`变量的生命周期是整个程序运行期间，但只能在该函数内部访问。它就像是"这个函数的私有持久记忆"。
