# 08-指针与内存

指针是C/C++最强大的特性，也是初学者最大的噩梦。它让你直接操作内存地址——权力极大，危险也极大。这篇帮你搞清指针的本质。

---

# 一、内存地址和取址

```c
int a = 42;
printf("a的值: %d\n", a);
printf("a的地址: %p\n", &a);    // & = "取地址"
```

```cmd
a的值: 42
a的地址: 000000A1B2C3D4E0
```

计算机的内存就像一个巨大的储物柜——每个格子里能存一个字节的数据，每个格子有一个编号（地址）。声明`int a = 42`的时候，系统在内存里找了连续4个格子（int占4字节），把42存进去，最左边那个格子的编号就是`a`的地址。

`&`运算符就是问"你这个变量住哪儿"。

---

# 二、指针：存地址的变量

```c
int a = 42;
int *p = &a;      // p是一个"指向int的指针"，存的是a的地址

printf("p的值(存的地址): %p\n", p);       // 地址
printf("p指向的东西: %d\n", *p);          // 42  解引用 = 沿着地址去找那个值
printf("a的地址: %p\n", &a);              // 和p一样
```

```cmd
p的值(存的地址): 000000A1B2C3D4E0
p指向的东西: 42
a的地址: 000000A1B2C3D4E0
```

**关键概念**：

```
变量a:  [    42    ]   ← 存在地址 0x...
变量p:  [ &a = 0x... ]   ← 存的是a的地址

a  → 42
p  → 0x...
*p → 42  (沿着p存的地址去找到a的值)
```

`int *p`的意思是"p是个指针，指向int"。`*p`是"解引用"——沿着指针去拿它指向的那个变量的值。

---

# 三、指针为什么有用：传地址修改外部变量

```c
void swap(int *x, int *y) {
    int temp = *x;   // 拿到x指向的东西的值
    *x = *y;         // 把y指向的东西的值写进x指向的地址
    *y = temp;       // 把临时值写进y指向的地址
}

int main() {
    int a = 10, b = 20;
    swap(&a, &b);    // 传a和b的地址进去
    printf("a=%d, b=%d\n", a, b);  // a=20, b=10
}
```

没有指针的时候，函数只能操作副本。有了指针，函数顺着地址找到原变量，直接改了它。

---

# 四、指针与数组

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;          // 数组名=指向第一个元素的指针

printf("%d\n", *p);       // 10   第一个元素
printf("%d\n", *(p+1));   // 20   下一个（指针+1 = 跳过1个int=跳过4字节）
printf("%d\n", p[2]);     // 30   []也是给指针用的

// 用指针遍历数组
for (int *p = arr; p < arr + 5; p++)
    printf("%d ", *p);
```

```cmd
10 20 30 40 50
```

`*(p+i)`和`p[i]`完全等价。`[]`只是`*`的语法糖。

---

# 五、指针的两个危险

**野指针**：指针声明了但没初始化，里面装的是随机垃圾地址。解引用它——程序行为未定义（可能崩，可能静默地毁了别处的数据，调试到哭）。

```c
int *p;       // 野指针！不知道指向哪
*p = 42;      // 未定义行为！
```

**悬空指针**：指向的内存已经被释放了。还去访问它——也是未定义行为。

```c
int *p = malloc(sizeof(int));
free(p);
*p = 42;      // 悬空指针！p指的那块内存已经还回去了
```

**防范**：声明指针时初始化为`NULL`，释放后也置为`NULL`。

# 六、NULL和nullptr

```c
int *p = NULL;    // C的写法（NULL就是0）
if (p == NULL) printf("指针为空\n");

// C++11之后用nullptr（类型安全）
int *q = nullptr;
```
