# 13-类与对象(下)

上篇讲了构造/析构/访问控制。这篇把剩下的常用特性补上：拷贝控制、this指针、static成员、运算符重载。

---

# 一、拷贝构造函数

当你用一个已存在的对象去创建新对象时调用：

```cpp
class Student {
    std::string name;
public:
    Student(const std::string &n) : name(n) {}

    // 拷贝构造
    Student(const Student &other)
        : name(other.name)
    {
        std::cout << "拷贝了 " << name << std::endl;
    }
};

int main() {
    Student s1("张三");
    Student s2 = s1;      // 拷贝构造
    Student s3(s1);       // 也是拷贝构造
}
```

注意区分**拷贝构造**和**赋值**：

```cpp
Student s2 = s1;    // 拷贝构造（创建新对象时）
s2 = s1;            // 赋值运算符（两个都已经存在的对象）
```

如果你没写拷贝构造函数，编译器会自动生成一个——逐成员拷贝（浅拷贝）。对于只含基本类型和`std::string`的类来说够用了。但如果你的类里有指针指向自己管理的内存（深拷贝需要的场景），必须自己写。

# 二、this指针

每个成员函数内部都有一个隐式的`this`指针，指向调用这个函数的那个对象：

```cpp
class Counter {
    int count;
public:
    Counter() : count(0) {}

    Counter& increment() {     // 返回自己的引用
        count++;
        return *this;          // this = 指向自己的指针，*this = 自己
    }

    int get() { return count; }
};

int main() {
    Counter c;
    c.increment().increment().increment();  // 链式调用
    std::cout << c.get() << std::endl;      // 3
}
```

# 三、static成员

属于整个类，不属于任何一个具体对象。所有对象共享同一份。

```cpp
class Student {
    static int total;   // 声明静态成员变量
public:
    Student() { total++; }
    ~Student() { total--; }
    static int getTotal() { return total; }  // 静态成员函数
};

int Student::total = 0;   // 静态变量必须在类外定义

int main() {
    Student s1, s2;
    std::cout << Student::getTotal() << std::endl;  // 2
}
```

`static`成员函数没有`this`指针——它不属于具体对象，所以不能访问非静态成员变量。

# 四、运算符重载

让自定义类型也能用`+` `-` `<<` `==` 这些运算符。

```cpp
class Vector {
    double x, y;
public:
    Vector(double x, double y) : x(x), y(y) {}

    Vector operator+(const Vector &other) const {
        return Vector(x + other.x, y + other.y);
    }

    bool operator==(const Vector &other) const {
        return x == other.x && y == other.y;
    }

    friend std::ostream& operator<<(std::ostream &os, const Vector &v) {
        os << "(" << v.x << ", " << v.y << ")";
        return os;
    }
};

int main() {
    Vector v1(1, 2), v2(3, 4);
    Vector v3 = v1 + v2;
    std::cout << v3 << std::endl;   // (4, 6)
    std::cout << (v1 == v2) << std::endl;  // 0 (false)
}
```

`<<`运算符不能写成成员函数（因为左操作数是`std::ostream`不是`Vector`），所以用**友元函数**——在类里声明`friend`，在类外定义。
