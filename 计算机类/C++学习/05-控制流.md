# 05-控制流

代码不是一条直线跑到黑的——要根据条件分岔、要根据循环重复。C里的控制流关键字很少：`if/else`、`switch`、`for`、`while`、`do-while`。但就这几个家伙，能表达任意复杂的逻辑。

---

# 一、if / else if / else

```c
#include <stdio.h>

int main() {
    int score = 85;

    if (score >= 90) {
        printf("A\n");
    } else if (score >= 80) {
        printf("B\n");
    } else if (score >= 70) {
        printf("C\n");
    } else if (score >= 60) {
        printf("D\n");
    } else {
        printf("F\n");
    }
    return 0;
}
```

```cmd
B
```

花括号`{}`只在超过一条语句时必须写。但**永远写花括号**——省略`{}`以后加代码容易写出逻辑完全不同的bug：

```c
// 危险写法（和你想象的不一样）
if (a > 0)
    printf("正数\n");
    printf("这一行不受if控制！\n");  // 缩进骗了你的眼睛
```

---

# 二、switch

当你要对同一个变量判断一堆不同的值，`switch`比一长串`if-else`更清晰。

```c
int day = 3;
switch (day) {
    case 1: printf("周一\n"); break;
    case 2: printf("周二\n"); break;
    case 3: printf("周三\n"); break;
    case 4: printf("周四\n"); break;
    case 5: printf("周五\n"); break;
    case 6:
    case 7: printf("周末\n"); break;
    default: printf("不存在的日子\n");
}
```

```cmd
周三
```

**`break`千万不能忘**。C的`switch`有"fall-through"特性——没遇到`break`就继续往下执行后面的`case`。`case 6:`后面故意没写`break`，就是为了让6和7共享同一段代码。

`switch`里只能判断**整数类型**（`int`、`char`、`enum`）。不能判断字符串、浮点数。

# 三、for 循环

```c
// 基本形式：for(初始化; 条件; 每轮结束后执行)
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
printf("\n");
```

```cmd
0 1 2 3 4
```

刚学时把它翻译成人话："i从0开始，只要i小于5就执行循环体，每次执行完i加1"。

```c
// 倒着数
for (int i = 10; i > 0; i -= 2)
    printf("%d ", i);           // 10 8 6 4 2

// 死循环
for (;;) { /* 条件为空 = 永远为真 */ }

// C99风格：循环变量在for里声明（C++一直支持，C从C99开始支持）
```

**什么时候用`for`**：知道循环次数，或者遍历数组。

---

# 四、while 和 do-while

```c
// while：先检查条件，后执行
int count = 0;
while (count < 3) {
    printf("%d ", count);
    count++;
}
printf("\n");
```

```cmd
0 1 2
```

```c
// do-while：先执行一次，再检查条件（至少跑一次）
int n = 0;
do {
    printf("输入正数: ");
    scanf("%d", &n);
} while (n <= 0);

printf("你输入了 %d\n", n);
```

**用`while`**：不知道循环多少次，靠条件判断。比如读文件到末尾、等用户输入合法值。

---

# 五、break 和 continue

```c
// break：立即跳出整个循环
for (int i = 0; i < 10; i++) {
    if (i == 4) break;
    printf("%d ", i);
}   // 输出: 0 1 2 3

// continue：跳过本轮，进入下一轮
for (int i = 0; i < 6; i++) {
    if (i % 2 == 0) continue;   // 偶数跳过
    printf("%d ", i);
}   // 输出: 1 3 5
```

---

# 六、goto（尽量别用）

```c
// 跳出深层嵌套循环时偶尔有用
for (int i = 0; i < 10; i++)
    for (int j = 0; j < 10; j++)
        if (i * j == 42)
            goto found;

found:
printf("找到了\n");
```

`goto`在C里唯一的正当用途是跳出深层嵌套循环和错误处理的统一跳转（类似C++的异常）。滥用`goto`会让代码变成意大利面——逻辑跳来跳去没法追踪。绝大多数情况用`break`和`return`就够。
