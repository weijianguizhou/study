# 20-多文件项目管理

一个项目只有一个`main.cpp`——那是玩具。真正的项目成百上千个文件，必须按模块拆开。这篇教你C++项目的标准组织方式。

---

# 一、头文件和源文件的分离

每个模块分两个文件：`.h`（接口——告诉外面"我能干什么"）和`.cpp`（实现——具体怎么干）。

```
my_project/
├── student.h      ← 声明：Student类长啥样
├── student.cpp    ← 实现：具体函数体
└── main.cpp       ← 用Student
```

`student.h`（**只写声明，不写实现**）：

```cpp
#pragma once              // 防止重复包含

#include <string>

class Student {
    std::string name;
    int age;
    double score;
public:
    Student(const std::string &n, int a, double s);
    void print() const;
    double getScore() const;
};
```

`student.cpp`（**写实现**）：

```cpp
#include "student.h"       // 包含自己的头文件
#include <iostream>

Student::Student(const std::string &n, int a, double s)
    : name(n), age(a), score(s) {}

void Student::print() const {
    std::cout << name << "，" << age << "岁" << std::endl;
}

double Student::getScore() const {
    return score;
}
```

`main.cpp`（**用**）：

```cpp
#include "student.h"

int main() {
    Student s("张三", 20, 95.5);
    s.print();
}
```

编译：

```bash
g++ main.cpp student.cpp -o my_app
```

---

# 二、#pragma once 和 #include 守卫

`#pragma once`告诉编译器："这个头文件每个`.cpp`只包含一次"。等价于传统的：

```cpp
#ifndef STUDENT_H
#define STUDENT_H
// ... 内容 ...
#endif
```

用`#pragma once`更简洁，现代编译器都支持。

# 四、目录规范

稍微大一点的项目：

```
my_project/
├── CMakeLists.txt
├── src/              ← 所有 .cpp
│   ├── main.cpp
│   ├── student.cpp
│   └── utils.cpp
├── include/          ← 所有 .h
│   ├── student.h
│   └── utils.h
└── tests/            ← 单元测试
    └── test_student.cpp
```

`CMakeLists.txt`：

```cmake
add_executable(my_app
    src/main.cpp
    src/student.cpp
    src/utils.cpp
)
target_include_directories(my_app PRIVATE include)
```

---

# 五、不要include .cpp ！

新手常犯的错误——在A.cpp里写`#include "B.cpp"`。这会让你编译时同一个函数出现两次定义，链接器报错`multiple definition`。

**铁律**：
- `.h`文件用`#include`引入
- `.cpp`文件**独立编译**，靠链接器拼到一起
- 不要`#include`任何`.cpp`文件
