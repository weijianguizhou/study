这份教程整理自 Visual Studio 2026 官方文档、C++ 团队博客与笔者在实际项目中的使用经验，面向\textbf{用 C++ 写代码的人}。

Visual Studio 2026 是微软于 2025 年 11 月 11 日正式发布的新一代集成开发环境，内部版本号为 18.x。与上一代相比，它有三处根本变化：\textbf{MSVC 编译器版本与 IDE 版本解耦}、\textbf{新建 C++ 项目默认使用 C++20}、\textbf{AI 辅助深度融入日常开发流程}。这些变化让不少沿用多年的经验与配置习惯失效，也是本书存在的理由。

全书共十三章，按"装好能跑 $\rightarrow$ 会用 IDE $\rightarrow$ 写出工程级代码"三段推进。每一章都尽量回答三个问题：这个功能解决什么问题、在界面上的哪个位置、以及踩坑时该怎么排查。书中的命令、开关与路径均取自官方文档，并在写作时逐条核对过版本。

本书有 Markdown 与 LaTeX 两个版本，内容一致：Markdown 版便于在 Obsidian 中检索与双链跳转，LaTeX 版便于打印与离线阅读。两者都放在 \codeP{计算机类\textbackslash{}Visual Studio 2026使用指南} 下。

限于篇幅与版本节奏，书中涉及具体版本号之处均以写作时（2026 年 10 月）的稳定通道为准；微软每月更新一次 IDE，遇到与书中不一致的地方，请以 \ui{帮助 > 关于 Microsoft Visual Studio} 显示的版本号与官方发行说明为准。
