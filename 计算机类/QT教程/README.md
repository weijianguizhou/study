## 环境要求

- **操作系统**：Windows 10/11
- **Qt版本**：Qt 5.15.x（推荐 LTS 版本）
- **编译器**：MinGW 8.1 或 MSVC 2019/2022
- **IDE**：Qt Creator 4.x
- **C++标准**：C++11 及以上

## 学习建议

1. 按章节顺序学习，循序渐进
2. 每章完成后再进行下一章
3. 动手实践每个代码示例
4. 完成每章末尾的练习题
5. 遇到问题多查阅 Qt 官方文档
