## 概念解释

### 什么是MOC？

MOC（Meta-Object Compiler）是Qt的元对象编译器，它处理包含Q_OBJECT宏的头文件，生成额外的C++源代码。

### MOC的工作流程

`
头文件(.h) → MOC → moc_xxx.cpp → 编译器 → 目标文件
`

### MOC生成的内容

1. 信号的实现
2. 槽函数的元信息
3. 属性系统代码
4. 动态类型转换代码
5. QMetaObject类的实例

### 启用MOC

在.pro文件中，Qt会自动处理Q_OBJECT宏：

`pro
# Qt自动调用MOC处理包含Q_OBJECT的头文件
QT += core gui
`

## 代码示例

### 手动运行MOC

`ash
# 手动运行MOC（通常由构建系统自动处理）
moc myclass.h -o moc_myclass.cpp
`

### MOC生成的代码示例

`cpp
// moc_myclass.cpp（自动生成，简化示例）
#include "myclass.h"
#include <QtCore/qobjectdefs.h>

// 信号实现
void MyClass::signalName(int param)
{
    QMetaObject::activate(this, &staticMetaObject, 0, nullptr);
}

// 元对象数据
const QMetaObject MyClass::staticMetaObject = {
    { &QObject::staticMetaObject, qt_meta_stringdata_MyClass.data,
      qt_meta_data_MyClass, qt_static_metacall, nullptr, nullptr }
};
`

## 注意事项

1. 包含Q_OBJECT的头文件必须被MOC处理
2. 不要在.cpp文件中包含Q_OBJECT
3. 如果修改了信号或槽，需要重新构建
4. MOC生成的文件通常不需要手动修改
