# 02-05 信号与槽的线程安全

> **前置**：[[02-04-信号与槽的高级特性|高级特性]] | **后续**：[[02-06-MOC元对象编译器|MOC]]

## 概念解释

### 线程安全的信号槽

Qt的信号槽机制是线程安全的，不同连接类型有不同的行为：

| 连接类型 | 发送线程 | 接收线程 | 线程安全 |
|----------|----------|----------|----------|
| Direct Connection | 当前线程 | 当前线程 | 否 |
| Queued Connection | 当前线程 | 接收者线程 | 是 |
| Blocking Queued | 当前线程 | 接收者线程 | 是（阻塞） |
| Auto Connection | 自动选择 | 自动选择 | 是 |

### 跨线程通信

`cpp
// 在工作线程中发射信号
class Worker : public QObject
{
    Q_OBJECT
    
public slots:
    void doWork() {
        // 在工作线程中执行
        emit resultReady(result);
    }
    
signals:
    void resultReady(const QString &result);
};

// 在主线程中连接
QThread *thread = new QThread(this);
Worker *worker = new Worker;
worker->moveToThread(thread);

connect(thread, &QThread::started, worker, &Worker::doWork);
connect(worker, &Worker::resultReady, this, &MainWindow::handleResult);
connect(worker, &Worker::resultReady, thread, &QThread::quit);

thread->start();
`

## 代码示例

### 线程安全的下载器

`cpp
class DownloadWorker : public QObject
{
    Q_OBJECT
    
public slots:
    void download(const QUrl &url) {
        QNetworkAccessManager manager;
        QNetworkReply *reply = manager.get(QNetworkRequest(url));
        
        connect(reply, &QNetworkReply::finished, [this, reply]() {
            emit finished(reply->readAll());
            reply->deleteLater();
        });
    }
    
signals:
    void finished(const QByteArray &data);
};

// 主线程使用
void MainWindow::startDownload()
{
    QThread *thread = new QThread(this);
    DownloadWorker *worker = new DownloadWorker;
    worker->moveToThread(thread);
    
    connect(thread, &QThread::started, worker, [worker]() {
        worker->download(QUrl("https://example.com/file.zip"));
    });
    
    connect(worker, &DownloadWorker::finished, this, [this](const QByteArray &data) {
        qDebug() << "Downloaded" << data.size() << "bytes";
    });
    
    connect(worker, &DownloadWorker::finished, thread, &QThread::quit);
    connect(thread, &QThread::finished, worker, &QObject::deleteLater);
    connect(thread, &QThread::finished, thread, &QObject::deleteLater);
    
    thread->start();
}
`

### 避免死锁

`cpp
// 错误：可能导致死锁
connect(worker, &Worker::signal, mainThread, &MainThread::slot, 
        Qt::BlockingQueuedConnection);

// 正确：确保不会在同一线程使用BlockingQueuedConnection
if (QThread::currentThread() != receiver->thread()) {
    connect(sender, &Sender::signal, receiver, &Receiver::slot, 
            Qt::BlockingQueuedConnection);
} else {
    connect(sender, &Sender::signal, receiver, &Receiver::slot, 
            Qt::DirectConnection);
}
`

## 注意事项

1. Direct Connection在接收者线程执行，需要注意线程安全
2. BlockingQueued Connection不要在同一线程使用
3. 跨线程修改Qt对象需要使用信号槽或QMetaObject::invokeMethod
4. 使用QMutex保护共享数据
