# 02-04 信号与槽的高级特性

> **前置**：[[02-03-自定义信号与槽|自定义]] | **后续**：[[02-05-信号与槽的线程安全|线程安全]]

## 概念解释

### 信号转发

一个信号可以连接到另一个信号：

`cpp
connect(sender, &Sender::signalA, receiver, &Receiver::signalB);
`

### 信号与槽的断开

`cpp
// 断开所有连接
disconnect(sender, &Sender::signal, receiver, &Receiver::slot);

// 断开特定连接
disconnect(connection);
`

### 信号参数的默认值

`cpp
// 信号声明
signals:
    void dataReady(const QByteArray &data, bool compressed = false);

// 连接时可以使用带默认参数的信号
connect(sender, &Sender::dataReady, receiver, &Receiver::handleData);
// 当发射时，compressed参数会使用默认值false
`

### QSignalMapper

QSignalMapper用于将多个信号映射到同一个槽，常用于动态创建的控件：

`cpp
QSignalMapper *mapper = new QSignalMapper(this);

for (int i = 0; i < 5; ++i) {
    QPushButton *button = new QPushButton(QString::number(i));
    connect(button, &QPushButton::clicked, mapper, &QSignalMapper::map);
    mapper->setMapping(button, i);
}

connect(mapper, &QSignalMapper::mappedInt, this, &MyClass::buttonClicked);
`

## 代码示例

### 信号槽的高级用法

`cpp
class EventBus : public QObject
{
    Q_OBJECT
    
public:
    // 信号转发
    void forwardSignal() {
        emit dataReceived("转发的数据");
    }
    
signals:
    void dataReceived(const QString &data);
    void errorOccurred(const QString &error);
};

// 使用Lambda进行条件过滤
connect(sender, &Sender::signal, this, [this](int value) {
    if (value > 100) {
        this->handleHighValue(value);
    }
});

// 使用sender()获取发送者
connect(sender, &Sender::signal, this, [this]() {
    QObject *senderObj = sender();
    if (auto *button = qobject_cast<QPushButton*>(senderObj)) {
        qDebug() << "Button text:" << button->text();
    }
});
`

### 多信号槽连接管理

`cpp
class SignalManager : public QObject
{
    Q_OBJECT
    
public:
    void connectAll() {
        // 保存连接以便后续断开
        m_connections.append(
            connect(sender1, &Sender1::signal, this, &SignalManager::handle1));
        m_connections.append(
            connect(sender2, &Sender2::signal, this, &SignalManager::handle2));
    }
    
    void disconnectAll() {
        for (auto &conn : m_connections) {
            disconnect(conn);
        }
        m_connections.clear();
    }
    
private:
    QList<QMetaObject::Connection> m_connections;
};
`

## 注意事项

1. 信号转发可能导致无限循环
2. 断开连接时要确保对象有效
3. Lambda捕获的变量要注意生命周期
4. 使用QSignalMapper时注意内存管理
