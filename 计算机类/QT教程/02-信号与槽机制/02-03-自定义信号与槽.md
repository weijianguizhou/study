# 02-03 自定义信号与槽

## 概念解释

### 自定义信号

信号在类的signals区域声明，无需实现：

`cpp
class MyClass : public QObject
{
    Q_OBJECT
    
signals:
    void dataReady(const QByteArray &data);
    void errorOccurred(int errorCode, const QString &message);
    void progressChanged(int percentage);
};
`

### 自定义槽

槽在public slots、protected slots或private slots区域声明：

`cpp
class MyClass : public QObject
{
    Q_OBJECT
    
public slots:
    void processData(const QByteArray &data);
    
protected slots:
    void onError(int code);
    
private slots:
    void updateUI();
};
`

### 信号发射

使用emit关键字发射信号：

`cpp
void MyClass::someFunction()
{
    // 处理数据...
    
    emit dataReady(data);      // 发射信号
    emit progressChanged(50);  // 发射带参数的信号
}
`

## 代码示例

### 完整示例：下载管理器

`cpp
// downloadmanager.h
#ifndef DOWNLOADMANAGER_H
#define DOWNLOADMANAGER_H

#include <QObject>
#include <QUrl>
#include <QByteArray>

class DownloadManager : public QObject
{
    Q_OBJECT
    
public:
    explicit DownloadManager(QObject *parent = nullptr);
    
    void startDownload(const QUrl &url);
    
signals:
    void downloadStarted(const QUrl &url);
    void downloadProgress(qint64 bytesReceived, qint64 bytesTotal);
    void downloadFinished(const QByteArray &data);
    void downloadError(const QString &errorMessage);
    
public slots:
    void cancelDownload();
    
private slots:
    void onReadyRead();
    void onFinished();
    
private:
    QUrl m_url;
    QByteArray m_buffer;
};

#endif // DOWNLOADMANAGER_H
`

`cpp
// downloadmanager.cpp
#include "downloadmanager.h"
#include <QNetworkAccessManager>
#include <QNetworkReply>

DownloadManager::DownloadManager(QObject *parent)
    : QObject(parent)
{
}

void DownloadManager::startDownload(const QUrl &url)
{
    m_url = url;
    m_buffer.clear();
    
    QNetworkAccessManager *manager = new QNetworkAccessManager(this);
    QNetworkReply *reply = manager->get(QNetworkRequest(url));
    
    connect(reply, &QNetworkReply::readyRead, 
            this, &DownloadManager::onReadyRead);
    connect(reply, &QNetworkReply::finished, 
            this, &DownloadManager::onFinished);
    connect(reply, &QNetworkReply::errorOccurred,
            this, [this](QNetworkReply::NetworkError) {
        emit downloadError(reply->errorString());
    });
    
    emit downloadStarted(url);
}

void DownloadManager::cancelDownload()
{
    // 实现取消逻辑
}

void DownloadManager::onReadyRead()
{
    QNetworkReply *reply = qobject_cast<QNetworkReply*>(sender());
    if (reply) {
        m_buffer.append(reply->readAll());
        emit downloadProgress(m_buffer.size(), -1);
    }
}

void DownloadManager::onFinished()
{
    emit downloadFinished(m_buffer);
    sender()->deleteLater();
}
`

## 注意事项

1. 信号不需要实现，只需声明
2. 槽函数需要在.cpp文件中实现
3. 使用emit关键字发射信号
4. 信号参数类型要与连接的槽兼容
