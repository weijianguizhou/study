# 02-02 信号与槽的连接方式

> **前置**：[[02-01-信号与槽概述|概述]] | **后续**：[[02-03-自定义信号与槽|自定义]]

## 概念解释

### 五种连接类型

Qt提供了五种连接类型：

| 连接类型 | 枚举值 | 说明 |
|----------|--------|------|
| Auto Connection | Qt::AutoConnection | 自动选择（默认） |
| Direct Connection | Qt::DirectConnection | 直接调用 |
| Queued Connection | Qt::QueuedConnection | 队列调用 |
| Blocking Queued Connection | Qt::BlockingQueuedConnection | 阻塞队列调用 |
| Unique Connection | Qt::UniqueConnection | 唯一连接 |

### 连接语法

`cpp
// Qt5新语法（推荐）
connect(sender, &Sender::signal, receiver, &Receiver::slot);

// Qt4旧语法（已过时）
connect(sender, SIGNAL(signal()), receiver, SLOT(slot()));
`

### Auto Connection工作原理

- 如果发送者和接收者在同一对象：直接调用
- 如果发送者和接收者在不同线程：队列调用
- 与QueuedConnection相同

## 代码示例

### 不同连接类型示例

`cpp
// 直接连接：槽函数在发送信号的线程中执行
connect(sender, &Sender::signal, 
        receiver, &Receiver::slot, 
        Qt::DirectConnection);

// 队列连接：槽函数在接收者所在线程执行
connect(sender, &Sender::signal, 
        receiver, &Receiver::slot, 
        Qt::QueuedConnection);

// 阻塞队列：发送线程等待槽函数执行完成
connect(sender, &Sender::signal, 
        receiver, &Receiver::slot, 
        Qt::BlockingQueuedConnection);

// 唯一连接：防止重复连接
connect(sender, &Sender::signal, 
        receiver, &Receiver::slot, 
        Qt::UniqueConnection);
`

### Lambda表达式连接

`cpp
// 使用lambda作为槽
connect(button, &QPushButton::clicked, [this]() {
    this->setWindowTitle("Button Clicked!");
});

// 带参数的lambda
connect(spinBox, QOverload<int>::of(&QSpinBox::valueChanged),
    [this](int value) {
        label->setText(QString::number(value));
    });
`

### 一对多连接

`cpp
// 一个信号连接到多个槽
connect(button, &QPushButton::clicked, this, &MyClass::handleClick1);
connect(button, &QPushButton::clicked, this, &MyClass::handleClick2);

// 多个信号连接到同一个槽
connect(button1, &QPushButton::clicked, this, &MyClass::handleClick);
connect(button2, &QPushButton::clicked, this, &MyClass::handleClick);
`

## 注意事项

1. 默认使用Auto Connection
2. 跨线程使用Queued Connection
3. 避免使用BlockingQueuedConnection导致死锁
4. 使用UniqueConnection防止重复连接
