# 02-01 信号与槽概述

## 概念解释

### 什么是信号与槽？

信号与槽是Qt框架中对象间通信的核心机制。当某个事件发生时，对象会发出一个信号（signal），如果有其他对象连接了这个信号对应的槽（slot），槽函数就会被自动调用。

### 信号（Signal）

- 信号是一种特殊的函数，由moc自动生成
- 信号只需声明，无需实现
- 信号可以有参数
- 信号可以连接到多个槽
- 信号可以连接到其他信号

### 槽（Slot）

- 槽是普通的C++成员函数
- 可以被调用
- 可以有参数
- 可以连接到多个信号
- 可以被直接调用

### 信号槽的优势

| 特性 | 信号槽 | 回调函数 |
|------|--------|----------|
| 类型安全 | 是 | 否 |
| 松耦合 | 是 | 否 |
| 可连接多个槽 | 是 | 否 |
| 可动态断开 | 是 | 否 |

## 代码示例

### 基本信号槽连接

`cpp
#include <QPushButton>

QPushButton *button = new QPushButton("Click me");

// 信号: clicked
// 槽: 无名lambda
connect(button, &QPushButton::clicked, []() {
    qDebug() << "Button clicked!";
});

// 或者连接到槽函数
connect(button, &QPushButton::clicked, this, &MyClass::onButtonClicked);
`

### 常见信号示例

`cpp
// 按钮信号
connect(button, &QPushButton::clicked, ...);
connect(button, &QPushButton::pressed, ...);
connect(button, &QPushButton::released, ...);

// 文本框信号
connect(lineEdit, &QLineEdit::textChanged, ...);
connect(lineEdit, &QLineEdit::returnPressed, ...);

// 滑块信号
connect(slider, &QSlider::valueChanged, ...);

// 定时器信号
connect(timer, &QTimer::timeout, ...);
`

## 注意事项

1. 信号和槽参数类型必须兼容
2. 信号参数可以多于槽参数
3. 信号槽连接必须在对象生存期内完成
4. 避免循环引用导致内存泄漏
