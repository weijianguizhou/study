# 03-06 日期时间控件

> **前置**：[[03-05-对话框控件详解|对话框]] | **后续**：[[03-07-自定义控件开发|自定义]]

## 概念解释

### 日期时间控件

| 控件类 | 说明 |
|--------|------|
| QDateEdit | 日期输入 |
| QTimeEdit | 时间输入 |
| QDateTimeEdit | 日期时间输入 |
| QCalendarWidget | 日历选择 |

### QDateTimeEdit属性

| 属性 | 说明 |
|------|------|
| dateTime | 当前日期时间 |
| date | 日期部分 |
| time | 时间部分 |
| format | 显示格式 |
| calendarPopup | 日历弹出 |

## 代码示例

### 日期时间编辑

`cpp
// 日期编辑
QDateEdit *dateEdit = new QDateEdit(QDate::currentDate(), this);
dateEdit->setDisplayFormat("yyyy-MM-dd");
dateEdit->setCalendarPopup(true);

// 时间编辑
QTimeEdit *timeEdit = new QTimeEdit(QTime::currentTime(), this);
timeEdit->setDisplayFormat("HH:mm:ss");

// 日期时间编辑
QDateTimeEdit *dateTimeEdit = new QDateTimeEdit(QDateTime::currentDateTime(), this);
dateTimeEdit->setDisplayFormat("yyyy-MM-dd HH:mm:ss");
dateTimeEdit->setCalendarPopup(true);

// 信号连接
connect(dateTimeEdit, &QDateTimeEdit::dateTimeChanged, 
    [](const QDateTime &dateTime) {
        qDebug() << "DateTime:" << dateTime;
    });
`

### 日历控件

`cpp
QCalendarWidget *calendar = new QCalendarWidget(this);
calendar->setGridVisible(true);
calendar->setSelectedDate(QDate::currentDate());

connect(calendar, &QCalendarWidget::clicked, 
    [](const QDate &date) {
        qDebug() << "Selected:" << date;
    });
`

## 注意事项

1. 使用setDisplayFormat设置显示格式
2. setCalendarPopup(true)启用日历弹出
3. 可以设置日期范围限制
