# 03-02 输入控件详解

## 概念解释

### 输入控件类型

| 控件类 | 说明 |
|--------|------|
| QLineEdit | 单行输入 |
| QTextEdit | 多行富文本编辑 |
| QPlainTextEdit | 多行纯文本编辑 |
| QSpinBox | 整数输入 |
| QDoubleSpinBox | 浮点数输入 |
| QSlider | 滑块输入 |

### QLineEdit常用属性

| 属性 | 说明 |
|------|------|
| text | 输入文本 |
| placeholderText | 占位文本 |
| maxLength | 最大长度 |
| readOnly | 只读模式 |
| echoMode | 显示模式 |

### QLineEdit回显模式

| 模式 | 说明 |
|------|------|
| Normal | 正常显示 |
| NoEcho | 不显示 |
| Password | 密码显示 |
| PasswordEchoOnEdit | 编辑时显示密码 |

## 代码示例

### 单行输入框

`cpp
QLineEdit *lineEdit = new QLineEdit(this);
lineEdit->setPlaceholderText("请输入用户名...");
lineEdit->setMaxLength(20);
lineEdit->setClearButtonEnabled(true);

// 信号连接
connect(lineEdit, &QLineEdit::textChanged, [](const QString &text) {
    qDebug() << "Text changed:" << text;
});

connect(lineEdit, &QLineEdit::returnPressed, []() {
    qDebug() << "Return pressed!";
});

// 验证器
QRegExpValidator *validator = new QRegExpValidator(
    QRegExp("[A-Za-z0-9]+"), lineEdit);
lineEdit->setValidator(validator);
`

### 密码输入框

`cpp
QLineEdit *passwordEdit = new QLineEdit(this);
passwordEdit->setEchoMode(QLineEdit::Password);
passwordEdit->setPlaceholderText("请输入密码...");
`

### 数字输入框

`cpp
// 整数输入
QSpinBox *spinBox = new QSpinBox(this);
spinBox->setRange(0, 100);
spinBox->setValue(50);
spinBox->setSuffix("%");
spinBox->setSingleStep(5);

connect(spinBox, QOverload<int>::of(&QSpinBox::valueChanged),
    [](int value) {
        qDebug() << "Value:" << value;
    });

// 浮点数输入
QDoubleSpinBox *doubleSpinBox = new QDoubleSpinBox(this);
doubleSpinBox->setRange(0.0, 100.0);
doubleSpinBox->setDecimals(2);
doubleSpinBox->setSingleStep(0.1);
`

### 文本编辑器

`cpp
QTextEdit *textEdit = new QTextEdit(this);
textEdit->setPlaceholderText("请输入内容...");
textEdit->setAcceptRichText(true);

// 获取纯文本
QString plainText = textEdit->toPlainText();

// 获取富文本
QString html = textEdit->toHtml();

// 连接信号
connect(textEdit, &QTextEdit::textChanged, []() {
    qDebug() << "Text edited!";
});
`

## 注意事项

1. 使用验证器限制输入内容
2. 密码输入框使用Password回显模式
3. QTextEdit支持富文本，QPlainTextEdit只支持纯文本
4. 大量文本编辑建议使用QPlainTextEdit
