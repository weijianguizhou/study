# 03-05 对话框控件详解

> **前置**：[[03-04-容器控件详解|容器]] | **后续**：[[03-06-日期时间控件|日期时间]]

## 概念解释

### 对话框类型

| 类 | 说明 |
|-----|------|
| QMessageBox | 消息对话框 |
| QInputDialog | 输入对话框 |
| QColorDialog | 颜色选择对话框 |
| QFontDialog | 字体选择对话框 |
| QFileDialog | 文件选择对话框 |
| QDialog | 自定义对话框 |

### 对话框模式

| 模式 | 说明 |
|------|------|
| 模态对话框 | 阻塞父窗口操作 |
| 非模态对话框 | 不阻塞父窗口操作 |
| 应用程序模态 | 阻塞整个应用程序 |

## 代码示例

### 消息对话框

`cpp
// 信息对话框
QMessageBox::information(this, "信息", "操作成功完成！");

// 警告对话框
QMessageBox::warning(this, "警告", "文件不存在！");

// 错误对话框
QMessageBox::critical(this, "错误", "无法保存文件！");

// 确认对话框
QMessageBox::StandardButton reply;
reply = QMessageBox::question(this, "确认", "确定要删除吗？",
    QMessageBox::Yes | QMessageBox::No);

if (reply == QMessageBox::Yes) {
    // 执行删除操作
}
`

### 输入对话框

`cpp
// 文本输入
bool ok;
QString text = QInputDialog::getText(this, "输入", "请输入名称：",
    QLineEdit::Normal, "", &ok);
if (ok && !text.isEmpty()) {
    qDebug() << "Input:" << text;
}

// 数字输入
int value = QInputDialog::getInt(this, "输入", "请输入数量：",
    50, 0, 100, 1, &ok);

// 选项输入
QStringList items;
items << "选项1" << "选项2" << "选项3";
QString item = QInputDialog::getItem(this, "选择", "请选择：",
    items, 0, false, &ok);
`

### 自定义对话框

`cpp
class LoginDialog : public QDialog
{
    Q_OBJECT
    
public:
    LoginDialog(QWidget *parent = nullptr) : QDialog(parent)
    {
        setWindowTitle("登录");
        
        QVBoxLayout *layout = new QVBoxLayout(this);
        
        m_usernameEdit = new QLineEdit(this);
        m_passwordEdit = new QLineEdit(this);
        m_passwordEdit->setEchoMode(QLineEdit::Password);
        
        m_loginBtn = new QPushButton("登录", this);
        m_cancelBtn = new QPushButton("取消", this);
        
        QHBoxLayout *btnLayout = new QHBoxLayout();
        btnLayout->addWidget(m_loginBtn);
        btnLayout->addWidget(m_cancelBtn);
        
        layout->addWidget(new QLabel("用户名："));
        layout->addWidget(m_usernameEdit);
        layout->addWidget(new QLabel("密码："));
        layout->addWidget(m_passwordEdit);
        layout->addLayout(btnLayout);
        
        connect(m_loginBtn, &QPushButton::clicked, this, &QDialog::accept);
        connect(m_cancelBtn, &QPushButton::clicked, this, &QDialog::reject);
    }
    
    QString username() const { return m_usernameEdit->text(); }
    QString password() const { return m_passwordEdit->text(); }
    
private:
    QLineEdit *m_usernameEdit;
    QLineEdit *m_passwordEdit;
    QPushButton *m_loginBtn;
    QPushButton *m_cancelBtn;
};

// 使用自定义对话框
LoginDialog dialog(this);
if (dialog.exec() == QDialog::Accepted) {
    QString user = dialog.username();
    QString pass = dialog.password();
}
`

## 注意事项

1. 模态对话框使用exec()方法
2. 非模态对话框使用show()方法
3. 自定义对话框通常继承自QDialog
4. 使用accept()和reject()关闭对话框
