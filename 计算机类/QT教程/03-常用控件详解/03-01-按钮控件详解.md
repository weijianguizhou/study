## 概念解释

### Qt按钮控件类型

| 控件类 | 说明 |
|--------|------|
| QPushButton | 普通按钮 |
| QToolButton | 工具按钮 |
| QRadioButton | 单选按钮 |
| QCheckBox | 复选框 |
| QCommandLinkButton | 命令链接按钮 |
| QDialogButtonBox | 对话框按钮组 |

### QPushButton常用属性

| 属性 | 说明 |
|------|------|
| text | 按钮文本 |
| icon | 按钮图标 |
| iconSize | 图标大小 |
| flat | 平面样式 |
| enabled | 是否启用 |
| checkable | 是否可选中 |
| checked | 是否选中 |

## 代码示例

### 基本按钮使用

`cpp
#include <QPushButton>
#include <QIcon>

// 创建按钮
QPushButton *button = new QPushButton("点击我", this);

// 设置属性
button->setIcon(QIcon(":/icons/click.png"));
button->setIconSize(QSize(24, 24));
button->setToolTip("这是一个按钮");
button->setShortcut(QKeySequence("Ctrl+O"));

// 连接信号
connect(button, &QPushButton::clicked, []() {
    qDebug() << "Button clicked!";
});

// 可选中按钮
QPushButton *toggleBtn = new QPushButton("切换", this);
toggleBtn->setCheckable(true);
connect(toggleBtn, &QPushButton::toggled, [](bool checked) {
    qDebug() << "Toggled:" << checked;
});
`

### 工具按钮

`cpp
QToolButton *toolButton = new QToolButton(this);
toolButton->setText("Tool");
toolButton->setIcon(QIcon(":/icons/tool.png"));
toolButton->setToolButtonStyle(Qt::ToolButtonTextBesideIcon);
toolButton->setPopupMode(QToolButton::MenuButtonPopup);

// 创建下拉菜单
QMenu *menu = new QMenu(this);
menu->addAction("Option 1");
menu->addAction("Option 2");
toolButton->setMenu(menu);
`

### 单选按钮和复选框

`cpp
// 单选按钮组
QButtonGroup *group = new QButtonGroup(this);
QRadioButton *rb1 = new QRadioButton("Option 1", this);
QRadioButton *rb2 = new QRadioButton("Option 2", this);
group->addButton(rb1, 1);
group->addButton(rb2, 2);

connect(group, QOverload<int>::of(&QButtonGroup::buttonClicked),
    [](int id) {
        qDebug() << "Selected:" << id;
    });

// 复选框
QCheckBox *cb = new QCheckBox("同意条款", this);
connect(cb, &QCheckBox::stateChanged, [](int state) {
    qDebug() << "State:" << state;
});
`

## 注意事项

1. 按钮的clicked信号最常用
2. 使用setCheckable创建切换按钮
3. 工具按钮适合工具栏使用
4. 单选按钮需要放在QButtonGroup中
