# 03-04 容器控件详解

> **前置**：[[03-03-显示控件详解|显示]] | **后续**：[[03-05-对话框控件详解|对话框]]

## 概念解释

### 容器控件类型

| 控件类 | 说明 |
|--------|------|
| QGroupBox | 分组框 |
| QTabWidget | 标签页 |
| QStackedWidget | 堆叠部件 |
| QScrollArea | 滚动区域 |
| QToolBox | 工具箱 |
| QMdiArea | MDI区域 |

### 容器控件的作用

- 组织和管理子控件
- 提供分页或切换功能
- 提供滚动浏览功能
- 实现多文档界面

## 代码示例

### 分组框

`cpp
QGroupBox *group = new QGroupBox("选项", this);
QVBoxLayout *layout = new QVBoxLayout(group);

QRadioButton *rb1 = new QRadioButton("选项1", group);
QRadioButton *rb2 = new QRadioButton("选项2", group);
QCheckBox *cb = new QCheckBox("启用", group);

layout->addWidget(rb1);
layout->addWidget(rb2);
layout->addWidget(cb);
`

### 标签页

`cpp
QTabWidget *tabWidget = new QTabWidget(this);

QWidget *tab1 = new QWidget();
QWidget *tab2 = new QWidget();
QWidget *tab3 = new QWidget();

tabWidget->addTab(tab1, "标签1");
tabWidget->addTab(tab2, "标签2");
tabWidget->addTab(tab3, QIcon(":/icons/star.png"), "标签3");

// 设置标签位置
tabWidget->setTabPosition(QTabWidget::North);

// 信号连接
connect(tabWidget, &QTabWidget::currentChanged, [](int index) {
    qDebug() << "Tab changed:" << index;
});
`

### 堆叠部件

`cpp
QStackedWidget *stacked = new QStackedWidget(this);

QWidget *page1 = new QWidget();
QWidget *page2 = new QWidget();
QWidget *page3 = new QWidget();

stacked->addWidget(page1);
stacked->addWidget(page2);
stacked->addWidget(page3);

// 切换页面
stacked->setCurrentIndex(0);

// 配合按钮使用
QPushButton *nextBtn = new QPushButton("下一页", this);
connect(nextBtn, &QPushButton::clicked, [stacked]() {
    int index = stacked->currentIndex() + 1;
    if (index < stacked->count()) {
        stacked->setCurrentIndex(index);
    }
});
`

### 滚动区域

`cpp
QScrollArea *scrollArea = new QScrollArea(this);
QWidget *contentWidget = new QWidget();
QVBoxLayout *layout = new QVBoxLayout(contentWidget);

for (int i = 0; i < 20; ++i) {
    layout->addWidget(new QLabel("Item " + QString::number(i)));
}

scrollArea->setWidget(contentWidget);
scrollArea->setWidgetResizable(true);
`

## 注意事项

1. QGroupBox适合分组相关控件
2. QTabWidget提供多页面切换
3. QStackedWidget一次只显示一个页面
4. QScrollArea用于显示超出视口的内容
