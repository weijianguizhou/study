# 03-03 显示控件详解

> **前置**：[[03-02-输入控件详解|输入]] | **后续**：[[03-04-容器控件详解|容器控件]]

## 概念解释

### 显示控件类型

| 控件类 | 说明 |
|--------|------|
| QLabel | 标签显示 |
| QProgressBar | 进度条 |
| QLCDNumber | LCD数字显示 |
| QTextBrowser | 富文本浏览器 |
| QCalendarWidget | 日历显示 |

### QLabel常用功能

| 方法 | 说明 |
|------|------|
| setText() | 设置文本 |
| setPixmap() | 设置图片 |
| setMovie() | 设置动画 |
| setAlignment() | 设置对齐方式 |
| setWordWrap() | 启用自动换行 |

### QProgressBar属性

| 属性 | 说明 |
|------|------|
| minimum | 最小值 |
| maximum | 最大值 |
| value | 当前值 |
| format | 显示格式 |
| textVisible | 文本可见 |

## 代码示例

### 标签显示

`cpp
QLabel *label = new QLabel(this);

// 文本标签
label->setText("Hello, Qt!");
label->setAlignment(Qt::AlignCenter);
label->setWordWrap(true);

// 图片标签
QPixmap pixmap(":/images/logo.png");
label->setPixmap(pixmap.scaled(200, 200, Qt::KeepAspectRatio));

// HTML标签
label->setText("<h1>标题</h1><p>这是<b>加粗</b>文本</p>");

// 动画标签
QMovie *movie = new QMovie(":/images/animation.gif");
label->setMovie(movie);
movie->start();
`

### 进度条

`cpp
QProgressBar *progressBar = new QProgressBar(this);
progressBar->setRange(0, 100);
progressBar->setValue(50);
progressBar->setFormat("%v%");

// 模拟进度更新
QTimer *timer = new QTimer(this);
connect(timer, &QTimer::timeout, [progressBar]() {
    int value = progressBar->value() + 1;
    if (value > 100) value = 0;
    progressBar->setValue(value);
});
timer->start(100);
`

### LCD数字显示

`cpp
QLCDNumber *lcd = new QLCDNumber(this);
lcd->setDigitCount(8);
lcd->setMode(QLCDNumber::Dec);
lcd->setSegmentStyle(QLCDNumber::Flat);
lcd->display("12:34:56");
`

### 文本浏览器

`cpp
QTextBrowser *browser = new QTextBrowser(this);
browser->setOpenExternalLinks(true);
browser->setHtml("<h1>Welcome</h1>"
                  "<p>Click <a href='https://qt.io'>here</a></p>");
`

## 注意事项

1. QLabel可以显示多种类型的内容
2. 进度条的format可以自定义显示格式
3. LCD数字显示适合时钟等场景
4. QTextBrowser支持富文本和超链接
