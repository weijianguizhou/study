# 04-03 表单布局详解

## 概念解释

### QFormLayout

表单布局是专门用于创建表单的布局管理器，每行包含一个标签和一个输入控件。

### 常用方法

| 方法 | 说明 |
|------|------|
| addRow(label, field) | 添加一行 |
| addRow(field) | 无标签行 |
| addRow(label, layout) | 标签+布局 |
| setLabelAlignment() | 设置标签对齐 |
| setFieldGrowthPolicy() | 设置字段增长策略 |

### 字段增长策略

| 策略 | 说明 |
|------|------|
| FieldsStayAtSizeHint | 保持默认大小 |
| ExpandingFieldsGrow | 字段扩展填充 |
| AllNonFixedFieldsGrow | 所有非固定字段增长 |

## 代码示例

### 基本表单布局

`cpp
QFormLayout *formLayout = new QFormLayout(this);
formLayout->setContentsMargins(10, 10, 10, 10);
formLayout->setSpacing(8);

formLayout->addRow("姓名：", new QLineEdit());
formLayout->addRow("邮箱：", new QLineEdit());
formLayout->addRow("年龄：", new QSpinBox());
formLayout->addRow("生日：", new QDateEdit());
formLayout->addRow("简介：", new QTextEdit());
`

### 无标签行

`cpp
QFormLayout *layout = new QFormLayout(this);

layout->addRow("用户名：", new QLineEdit());
layout->addRow("密码：", new QLineEdit());
layout->addRow(new QCheckBox("记住密码"));
layout->addRow(new QCheckBox("自动登录"));
layout->addRow(new QPushButton("登录"));
`

### 自定义对齐

`cpp
QFormLayout *layout = new QFormLayout(this);
layout->setLabelAlignment(Qt::AlignRight);
layout->setFieldGrowthPolicy(QFormLayout::ExpandingFieldsGrow);

layout->addRow("长标签：", new QLineEdit());
layout->addRow("短：", new QLineEdit());
`

### 使用布局作为字段

`cpp
QFormLayout *layout = new QFormLayout(this);

// 使用水平布局作为字段
QHBoxLayout *nameLayout = new QHBoxLayout();
nameLayout->addWidget(new QLineEdit());
nameLayout->addWidget(new QPushButton("..."));
layout->addRow("文件：", nameLayout);

// 使用网格布局作为字段
QGridLayout *grid = new GridLayout();
grid->addWidget(new QLineEdit(), 0, 0);
grid->addWidget(new QSpinBox(), 0, 1);
layout->addRow("范围：", grid);
`

## 注意事项

1. 表单布局自动对齐标签和字段
2. 适合创建设置界面和表单
3. setLabelAlignment控制标签对齐方式
4. setFieldGrowthPolicy控制字段增长策略
