# 04-01 盒布局详解

## 概念解释

### 盒布局类型

| 类 | 说明 |
|-----|------|
| QHBoxLayout | 水平布局（从左到右） |
| QVBoxLayout | 垂直布局（从上到下） |

### 布局属性

| 属性 | 说明 |
|------|------|
| margin | 边距 |
| spacing | 控件间距 |
| addStretch | 添加伸缩空间 |

## 代码示例

### 基本水平布局

`cpp
QHBoxLayout *hLayout = new QHBoxLayout(this);

QPushButton *btn1 = new QPushButton("按钮1", this);
QPushButton *btn2 = new QPushButton("按钮2", this);
QPushButton *btn3 = new QPushButton("按钮3", this);

hLayout->addWidget(btn1);
hLayout->addWidget(btn2);
hLayout->addWidget(btn3);
`

### 基本垂直布局

`cpp
QVBoxLayout *vLayout = new QVBoxLayout(this);

QLabel *label = new QLabel("标题", this);
QLineEdit *edit = new QLineEdit(this);
QPushButton *button = new QPushButton("确定", this);

vLayout->addWidget(label);
vLayout->addWidget(edit);
vLayout->addWidget(button);
`

### 带间距和边距

`cpp
QVBoxLayout *layout = new QVBoxLayout(this);
layout->setContentsMargins(10, 10, 10, 10);  // 左、上、右、下
layout->setSpacing(5);  // 控件间距

layout->addWidget(new QLabel("项目1", this));
layout->addWidget(new QLabel("项目2", this));
layout->addWidget(new QLabel("项目3", this));
`

### 伸缩空间

`cpp
QHBoxLayout *layout = new QHBoxLayout(this);

QPushButton *leftBtn = new QPushButton("左对齐", this);
QPushButton *rightBtn = new QPushButton("右对齐", this);

layout->addWidget(leftBtn);
layout->addStretch();  // 添加伸缩空间
layout->addWidget(rightBtn);
`

### 嵌套布局

`cpp
// 主窗口使用垂直布局
QVBoxLayout *mainLayout = new QVBoxLayout(this);

// 顶部使用水平布局
QHBoxLayout *topLayout = new QHBoxLayout();
topLayout->addWidget(new QPushButton("新建", this));
topLayout->addWidget(new QPushButton("打开", this));
topLayout->addWidget(new QPushButton("保存", this));

// 中部内容区
QTextEdit *textEdit = new QTextEdit(this);

// 底部按钮
QHBoxLayout *bottomLayout = new QHBoxLayout();
bottomLayout->addStretch();
bottomLayout->addWidget(new QPushButton("确定", this));
bottomLayout->addWidget(new QPushButton("取消", this));

mainLayout->addLayout(topLayout);
mainLayout->addWidget(textEdit, 1);  // stretch参数使textEdit占据剩余空间
mainLayout->addLayout(bottomLayout);
`

## 注意事项

1. addWidget的stretch参数控制控件比例
2. addStretch用于对齐和填充空间
3. 嵌套布局可以创建复杂界面
4. 使用setContentsMargins设置边距
