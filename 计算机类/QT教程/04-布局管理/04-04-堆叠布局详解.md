# 04-04 堆叠布局详解

## 概念解释

### QStackedLayout

堆叠布局一次只显示一个子控件，类似QStackedWidget但更灵活。

### 常用方法

| 方法 | 说明 |
|------|------|
| addWidget(widget) | 添加控件 |
| addLayout(layout) | 添加子布局 |
| setCurrentIndex(index) | 设置当前显示的索引 |
| currentIndex() | 获取当前索引 |
| count() | 获取总数 |

### 切换动画

可以配合QPropertyAnimation实现平滑切换效果。

## 代码示例

### 基本堆叠布局

`cpp
QStackedLayout *stackedLayout = new QStackedLayout(this);

QWidget *page1 = new QWidget();
QWidget *page2 = new QWidget();
QWidget *page3 = new QWidget();

// 为每个页面添加不同的背景色
page1->setStyleSheet("background-color: lightblue;");
page2->setStyleSheet("background-color: lightgreen;");
page3->setStyleSheet("background-color: lightyellow;");

stackedLayout->addWidget(page1);
stackedLayout->addWidget(page2);
stackedLayout->addWidget(page3);

// 切换页面
stackedLayout->setCurrentIndex(0);  // 显示第一个页面
`

### 配合导航按钮

`cpp
// 主窗口
QWidget *window = new QWidget();
QVBoxLayout *mainLayout = new QVBoxLayout(window);

// 导航按钮
QPushButton *prevBtn = new QPushButton("上一页", window);
QPushButton *nextBtn = new QPushButton("下一页", window);
QLabel *pageLabel = new QLabel("第 1 页", window);

// 堆叠布局
QStackedLayout *stackedLayout = new QStackedLayout();
for (int i = 0; i < 5; ++i) {
    QWidget *page = new QWidget();
    page->setStyleSheet(QString("background-color: hsl(%1, 100, 80);").arg(i * 60));
    stackedLayout->addWidget(page);
}

// 导航逻辑
auto updatePageLabel = [stackedLayout, pageLabel]() {
    pageLabel->setText(QString("第 %1 页")
        .arg(stackedLayout->currentIndex() + 1));
};

connect(prevBtn, &QPushButton::clicked, [stackedLayout, updatePageLabel]() {
    int index = stackedLayout->currentIndex() - 1;
    if (index >= 0) {
        stackedLayout->setCurrentIndex(index);
        updatePageLabel();
    }
});

connect(nextBtn, &QPushButton::clicked, [stackedLayout, updatePageLabel]() {
    int index = stackedLayout->currentIndex() + 1;
    if (index < stackedLayout->count()) {
        stackedLayout->setCurrentIndex(index);
        updatePageLabel();
    }
});

mainLayout->addLayout(stackedLayout);
mainLayout->addWidget(pageLabel);
`

## 注意事项

1. 一次只能显示一个控件或布局
2. 通过setCurrentIndex切换显示内容
3. 适合创建向导、选项卡式界面
4. 可以配合动画实现切换效果
