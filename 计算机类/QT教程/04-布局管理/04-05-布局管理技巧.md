# 04-05 布局管理技巧

## 概念解释

### 布局嵌套

布局可以相互嵌套，创建复杂的界面结构：

- 水平布局中嵌套垂直布局
- 垂直布局中嵌套网格布局
- 网格布局中嵌套其他布局

### 大小策略

| 策略 | 说明 |
|------|------|
| Fixed | 固定大小 |
| Minimum | 最小大小 |
| Maximum | 最大大小 |
| Preferred | 首选大小 |
| Expanding | 可扩展 |
| MinimumExpanding | 最小且可扩展 |
| Ignored | 忽略大小策略 |

### 伸缩因子（Stretch Factor）

控制控件在布局中占据的比例：

`cpp
layout->addWidget(widget1, 1);  // 占1份
layout->addWidget(widget2, 2);  // 占2份
layout->addWidget(widget3, 1);  // 占1份
`

## 代码示例

### 复杂布局嵌套

`cpp
// 创建一个典型的IDE布局
QWidget *window = new QWidget();
QVBoxLayout *mainLayout = new QVBoxLayout(window);

// 菜单栏（已存在）

// 工具栏
QHBoxLayout *toolbarLayout = new QHBoxLayout();
toolbarLayout->addWidget(new QPushButton("新建", window));
toolbarLayout->addWidget(new QPushButton("打开", window));
toolbarLayout->addWidget(new QPushButton("保存", window));
toolbarLayout->addStretch();
toolbarLayout->addWidget(new QLineEdit(window));

// 主内容区（左中右）
QHBoxLayout *contentLayout = new QHBoxLayout();

// 左侧项目树
QTreeView *projectTree = new QTreeView(window);
projectTree->setMinimumWidth(200);

// 中间编辑区
QTextEdit *editor = new QTextEdit(window);

// 右侧属性面板
QListWidget *properties = new QListWidget(window);
properties->setMinimumWidth(150);

contentLayout->addWidget(projectTree);
contentLayout->addWidget(editor, 1);  // 编辑区占据剩余空间
contentLayout->addWidget(properties);

// 状态栏
QStatusBar *statusBar = new QStatusBar(window);
QLabel *statusLabel = new QLabel("就绪", window);
statusBar->addWidget(statusLabel);

mainLayout->addLayout(toolbarLayout);
mainLayout->addLayout(contentLayout, 1);
mainLayout->addWidget(statusBar);
`

### 使用SpacerItem

`cpp
QHBoxLayout *layout = new QHBoxLayout(this);

// 左对齐
layout->addWidget(new QPushButton("左", this));

// 中间填充
layout->addSpacerItem(new QSpacerItem(40, 20, 
    QSizePolicy::Expanding, QSizePolicy::Minimum));

// 右对齐
layout->addWidget(new QPushButton("右", this));
`

### 大小策略控制

`cpp
QLineEdit *fixedEdit = new QLineEdit(this);
fixedEdit->setSizePolicy(QSizePolicy::Fixed, QSizePolicy::Fixed);
fixedEdit->setMaximumWidth(100);

QTextEdit *expandEdit = new QTextEdit(this);
expandEdit->setSizePolicy(QSizePolicy::Expanding, QSizePolicy::Expanding);
`

### QSplitter分隔器

`cpp
QSplitter *splitter = new QSplitter(Qt::Horizontal, this);

QTreeView *left = new QTreeView(splitter);
QTextEdit *right = new QTextEdit(splitter);

splitter->addWidget(left);
splitter->addWidget(right);

// 设置初始大小比例
splitter->setSizes({200, 400});

// 允许用户拖拽调整
splitter->setChildrenCollapsible(false);
`

## 注意事项

1. 合理使用伸缩因子控制布局比例
2. 使用QSplitter让用户调整布局
3. 避免过度嵌套，保持布局简洁
4. 使用setSizePolicy控制控件大小策略
