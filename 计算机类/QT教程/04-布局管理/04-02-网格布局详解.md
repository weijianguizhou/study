# 04-02 网格布局详解

> **前置**：[[04-01-盒布局详解|盒布局]] | **后续**：[[04-03-表单布局详解|表单布局]]

## 概念解释

### QGridLayout

网格布局将空间划分为行和列的网格，适合创建表格式布局。

### 常用方法

| 方法 | 说明 |
|------|------|
| addWidget(widget, row, col) | 添加到指定位置 |
| addWidget(widget, row, col, rowSpan, colSpan) | 跨多行多列 |
| addRow(row, label, field) | 添加一行（标签+字段） |
| addLayout(layout, row, col) | 添加子布局 |
| setColumnStretch(col, stretch) | 设置列拉伸比例 |
| setRowStretch(row, stretch) | 设置行拉伸比例 |

## 代码示例

### 基本网格布局

`cpp
QGridLayout *layout = new QGridLayout(this);

// 添加控件到网格
layout->addWidget(new QLabel("姓名：", this), 0, 0);
layout->addWidget(new QLineEdit(this), 0, 1);

layout->addWidget(new QLabel("年龄：", this), 1, 0);
layout->addWidget(new QSpinBox(this), 1, 1);

layout->addWidget(new QLabel("邮箱：", this), 2, 0);
layout->addWidget(new QLineEdit(this), 2, 1);
`

### 跨行跨列

`cpp
QGridLayout *layout = new QGridLayout(this);

// 跨两列
layout->addWidget(new QLabel("标题", this), 0, 0, 1, 2, Qt::AlignCenter);

// 正常控件
layout->addWidget(new QLabel("名称：", this), 1, 0);
layout->addWidget(new QLineEdit(this), 1, 1);

// 跨两行
layout->addWidget(new QTextEdit(this), 2, 0, 2, 1);

layout->addWidget(new QPushButton("按钮1", this), 2, 1);
layout->addWidget(new QPushButton("按钮2", this), 3, 1);
`

### 设置拉伸比例

`cpp
QGridLayout *layout = new QGridLayout(this);

// 三列，中间列占据更多空间
layout->addWidget(new QLabel("左", this), 0, 0);
layout->addWidget(new QLabel("中", this), 0, 1);
layout->addWidget(new QLabel("右", this), 0, 2);

layout->setColumnStretch(0, 1);
layout->setColumnStretch(1, 3);  // 中间列是其他的3倍宽
layout->setColumnStretch(2, 1);
`

### 使用addRow方法

`cpp
QGridLayout *layout = new QGridLayout(this);

// 等效于上面的方法
layout->addRow(0, new QLabel("姓名："), new QLineEdit());
layout->addRow(1, new QLabel("年龄："), new QSpinBox());
layout->addRow(2, new QLabel("邮箱："), new QLineEdit());
`

## 注意事项

1. 行列索引从0开始
2. 使用setColumnStretch设置列宽比例
3. 跨行跨列时注意坐标计算
4. 网格布局适合表单和网格状界面
