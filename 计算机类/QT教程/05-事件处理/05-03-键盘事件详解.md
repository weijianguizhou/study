# 05-03 键盘事件详解

> **前置**：[[05-02-鼠标事件详解|鼠标]] | **后续**：[[05-04-定时器事件详解|定时器]]

## 概念解释

### 键盘事件类型

| 事件 | 说明 |
|------|------|
| keyPressEvent | 按键按下 |
| keyReleaseEvent | 按键释放 |

### 按键标识

Qt使用Qt::Key枚举标识按键：

| 按键 | 标识 |
|------|------|
| 字母键 | Qt::Key_A - Qt::Key_Z |
| 数字键 | Qt::Key_0 - Qt::Key_9 |
| 功能键 | Qt::Key_F1 - Qt::Key_F12 |
| 方向键 | Qt::Key_Left等 |
| 修饰键 | Qt::Key_Shift等 |

### 按键状态

| 方法 | 说明 |
|------|------|
| key() | 按键标识 |
| text() | 按键文本 |
| modifiers() | 修饰键状态 |
| isAutoRepeat() | 是否自动重复 |

## 代码示例

### 基本键盘事件

`cpp
class KeyWidget : public QWidget
{
    Q_OBJECT
    
public:
    explicit KeyWidget(QWidget *parent = nullptr) : QWidget(parent)
    {
        setFocusPolicy(Qt::StrongFocus);
    }
    
signals:
    void keyPressed(int key);
    
protected:
    void keyPressEvent(QKeyEvent *event) override
    {
        // 检查修饰键
        bool ctrl = event->modifiers() & Qt::ControlModifier;
        bool shift = event->modifiers() & Qt::ShiftModifier;
        
        // 快捷键处理
        if (ctrl && event->key() == Qt::Key_S) {
            qDebug() << "保存";
            return;
        }
        
        if (ctrl && event->key() == Qt::Key_Z) {
            qDebug() << "撤销";
            return;
        }
        
        // 方向键处理
        switch (event->key()) {
        case Qt::Key_Up:
            qDebug() << "向上";
            break;
        case Qt::Key_Down:
            qDebug() << "向下";
            break;
        case Qt::Key_Left:
            qDebug() << "向左";
            break;
        case Qt::Key_Right:
            qDebug() << "向右";
            break;
        default:
            qDebug() << "按键：" << event->text();
            break;
        }
        
        emit keyPressed(event->key());
    }
    
    void keyReleaseEvent(QKeyEvent *event) override
    {
        if (event->isAutoRepeat()) {
            return;  // 忽略自动重复
        }
        qDebug() << "释放：" << event->key();
    }
};
`

### 方向键控制移动

`cpp
class MovableWidget : public QWidget
{
    Q_OBJECT
    
public:
    explicit MovableWidget(QWidget *parent = nullptr) : QWidget(parent)
    {
        setFocusPolicy(Qt::StrongFocus);
        setGeometry(100, 100, 50, 50);
    }
    
protected:
    void keyPressEvent(QKeyEvent *event) override
    {
        const int step = 10;
        QPoint newPos = pos();
        
        switch (event->key()) {
        case Qt::Key_Up:
            newPos.ry() -= step;
            break;
        case Qt::Key_Down:
            newPos.ry() += step;
            break;
        case Qt::Key_Left:
            newPos.rx() -= step;
            break;
        case Qt::Key_Right:
            newPos.rx() += step;
            break;
        default:
            QWidget::keyPressEvent(event);
            return;
        }
        
        // 边界检查
        if (parentWidget()) {
            QRect parentRect = parentWidget()->rect();
            newPos.setX(qBound(0, newPos.x(), parentRect.width() - width()));
            newPos.setY(qBound(0, newPos.y(), parentRect.height() - height()));
        }
        
        move(newPos);
    }
    
    void paintEvent(QPaintEvent *) override
    {
        QPainter painter(this);
        painter.setBrush(Qt::cyan);
        painter.drawRect(rect());
        painter.drawText(rect(), Qt::AlignCenter, "用方向键移动");
    }
};
`

## 注意事项

1. 使用setFocusPolicy设置焦点策略
2. 检查modifiers()获取修饰键状态
3. isAutoRepeat()可以过滤重复按键
4. 处理完事件后不要忘记调用基类实现
