## 概念解释

### 事件循环

Qt使用事件循环处理所有用户输入和系统事件：

1. 事件被放入事件队列
2. 事件循环从队列取出事件
3. 将事件分发给目标对象
4. 对象处理事件
5. 返回事件循环继续处理下一个事件

### 事件类型

| 事件类型 | 说明 |
|----------|------|
| QMouseEvent | 鼠标事件 |
| QKeyEvent | 键盘事件 |
| QWheelEvent | 滚轮事件 |
| QResizeEvent | 大小变化事件 |
| QPaintEvent | 绘制事件 |
| QTimerEvent | 定时器事件 |
| QDropEvent | 拖放事件 |

### 事件处理函数

`cpp
class MyWidget : public QWidget
{
protected:
    // 事件处理函数
    void mousePressEvent(QMouseEvent *event) override;
    void mouseReleaseEvent(QMouseEvent *event) override;
    void mouseMoveEvent(QMouseEvent *event) override;
    void keyPressEvent(QKeyEvent *event) override;
    void paintEvent(QPaintEvent *event) override;
    void resizeEvent(QResizeEvent *event) override;
    bool event(QEvent *event) override;  // 通用事件处理
};
`

## 代码示例

### 基本事件处理

`cpp
class EventWidget : public QWidget
{
    Q_OBJECT
    
public:
    explicit EventWidget(QWidget *parent = nullptr) : QWidget(parent)
    {
        setMouseTracking(true);  // 启用鼠标跟踪
        setFocusPolicy(Qt::StrongFocus);  // 启用键盘焦点
    }
    
protected:
    void mousePressEvent(QMouseEvent *event) override
    {
        if (event->button() == Qt::LeftButton) {
            qDebug() << "左键按下：" << event->pos();
        }
        QWidget::mousePressEvent(event);  // 调用基类实现
    }
    
    void keyPressEvent(QKeyEvent *event) override
    {
        qDebug() << "按键：" << event->text();
        QWidget::keyPressEvent(event);
    }
    
    void paintEvent(QPaintEvent *event) override
    {
        QPainter painter(this);
        painter.fillRect(rect(), Qt::lightGray);
        painter.drawText(rect(), Qt::AlignCenter, "点击或按键盘测试事件");
    }
};
`

### 事件传播

`cpp
bool EventWidget::event(QEvent *event)
{
    switch (event->type()) {
    case QEvent::MouseButtonPress:
        qDebug() << "鼠标按下事件";
        break;
    case QEvent::KeyPress:
        qDebug() << "按键事件";
        break;
    default:
        break;
    }
    
    return QWidget::event(event);  // 继续事件传播
}
`

## 注意事项

1. 事件处理函数通常需要调用基类实现
2. 使用setMouseTracking启用鼠标跟踪
3. 使用setFocusPolicy设置焦点策略
4. 事件会被传播到父对象
