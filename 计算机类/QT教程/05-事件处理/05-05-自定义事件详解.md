# 05-05 自定义事件详解

> **前置**：[[05-04-定时器事件详解|定时器]] | **后续**：[[05-06-事件过滤器详解|过滤器]]

## 概念解释

### 自定义事件类型

可以通过继承QEvent创建自定义事件：

`cpp
class MyCustomEvent : public QEvent
{
public:
    static const QEvent::Type EventType = 
        static_cast<QEvent::Type>(QEvent::User + 1);
    
    MyCustomEvent(const QString &data)
        : QEvent(EventType)
        , m_data(data)
    {}
    
    QString data() const { return m_data; }
    
private:
    QString m_data;
};
`

### 发送自定义事件

`cpp
// 方式1：使用QCoreApplication::sendEvent
MyCustomEvent *event = new MyCustomEvent("自定义数据");
QCoreApplication::sendEvent(targetObject, event);

// 方式2：使用postEvent（异步）
QCoreApplication::postEvent(targetObject, new MyCustomEvent("数据"));
`

### 处理自定义事件

`cpp
bool MyClass::event(QEvent *event)
{
    if (event->type() == MyCustomEvent::EventType) {
        MyCustomEvent *myEvent = static_cast<MyCustomEvent*>(event);
        qDebug() << "收到自定义事件：" << myEvent->data();
        return true;
    }
    
    return QObject::event(event);
}
`

## 代码示例

### 完整的自定义事件示例

`cpp
// myevent.h
#ifndef MYEVENT_H
#define MYEVENT_H

#include <QEvent>
#include <QString>

class DataReadyEvent : public QEvent
{
public:
    static const QEvent::Type EventType = 
        static_cast<QEvent::Type>(QEvent::User + 1);
    
    DataReadyEvent(const QByteArray &data, int id)
        : QEvent(EventType)
        , m_data(data)
        , m_id(id)
    {}
    
    QByteArray data() const { return m_data; }
    int id() const { return m_id; }
    
private:
    QByteArray m_data;
    int m_id;
};

#endif // MYEVENT_H
`

`cpp
// eventreceiver.h
#ifndef EVENTRECEIVER_H
#define EVENTRECEIVER_H

#include <QObject>
#include "myevent.h"

class EventReceiver : public QObject
{
    Q_OBJECT
    
public:
    explicit EventReceiver(QObject *parent = nullptr) : QObject(parent) {}
    
protected:
    bool event(QEvent *event) override
    {
        if (event->type() == DataReadyEvent::EventType) {
            DataReadyEvent *dataEvent = static_cast<DataReadyEvent*>(event);
            processData(dataEvent->data(), dataEvent->id());
            return true;
        }
        return QObject::event(event);
    }
    
private:
    void processData(const QByteArray &data, int id)
    {
        qDebug() << "处理数据：" << data.size() << "bytes, ID:" << id;
    }
};

#endif // EVENTRECEIVER_H
`

`cpp
// 使用自定义事件
EventReceiver *receiver = new EventReceiver(this);
QByteArray data = "Hello, Custom Event!";
DataReadyEvent *event = new DataReadyEvent(data, 42);
QCoreApplication::postEvent(receiver, event);
`

## 注意事项

1. 自定义事件类型必须大于QEvent::User
2. 使用postEvent发送的事件会被自动删除
3. 使用sendEvent发送的事件需要手动删除
4. 事件处理函数返回true表示事件已处理
