# 01-03 第一个Qt程序

## 概念解释

### Qt程序的基本结构

每个Qt程序都包含以下基本元素：

1. **头文件包含**：引入所需的Qt模块
2. **main函数**：程序入口点
3. **QApplication对象**：管理应用程序的控制流和主要设置
4. **窗口/控件**：用户界面元素
5. **事件循环**：处理用户输入和系统事件

### QApplication类

QApplication是Qt程序的核心类，负责：
- 初始化窗口系统
- 处理命令行参数
- 管理应用程序的事件循环
- 提供全局设置

### 事件循环（Event Loop）

`cpp
return app.exec(); // 进入事件循环
`

事件循环会持续监听用户输入、系统事件，并分发给相应的对象处理。

## 代码示例

### 最简单的Qt窗口程序

`cpp
// main.cpp
#include <QApplication>
#include <QWidget>

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);
    
    QWidget window;
    window.setWindowTitle("我的第一个Qt程序");
    window.resize(400, 300);
    window.show();
    
    return app.exec();
}
`

### 带按钮的程序

`cpp
#include <QApplication>
#include <QWidget>
#include <QPushButton>
#include <QVBoxLayout>

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);
    
    QWidget window;
    window.setWindowTitle("按钮示例");
    window.resize(300, 200);
    
    QVBoxLayout *layout = new QVBoxLayout(&window);
    QPushButton *button = new QPushButton("点击我", &window);
    
    layout->addWidget(button);
    
    // 连接信号与槽
    QObject::connect(button, &QPushButton::clicked, [](){
        qDebug() << "按钮被点击了！";
    });
    
    window.show();
    return app.exec();
}
`

## 注意事项

1. 确保项目.pro文件中包含QT += core gui
2. 所有Qt对象需要在显示前创建
3. 必须调用show()方法才能显示窗口
4. exec()会阻塞直到程序退出
