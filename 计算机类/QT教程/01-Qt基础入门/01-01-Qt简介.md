# 01-01 Qt简介

## 概念解释

### 什么是Qt？

Qt（读作"cute"）是一个跨平台的C++应用程序开发框架，由挪威Trolltech公司于1995年首次发布。现由The Qt Company维护。Qt提供了丰富的API和工具，用于开发图形用户界面（GUI）应用程序以及非GUI程序。

### Qt的发展历程

| 版本 | 年份 | 重要特性 |
|------|------|----------|
| Qt 1.0 | 1995 | 首次发布 |
| Qt 2.0 | 1999 | 支持OpenGL |
| Qt 3.0 | 2001 | 多线程支持 |
| Qt 4.0 | 2005 | 全新API设计 |
| Qt 5.0 | 2012 | 模块化架构 |
| Qt 5.15 | 2020 | 最后的开源5.x LTS |

### Qt的核心特点

1. **跨平台性**：支持Windows、Linux、macOS、Android、iOS等
2. **面向对象**：基于C++，提供元对象系统
3. **信号与槽机制**：类型安全的对象通信方式
4. **丰富的API**：覆盖GUI、网络、数据库、多线程等
5. **强大的工具链**：Qt Creator、Qt Designer、Qt Linguist

### Qt的应用场景

- 桌面应用程序（如WPS Office、VirtualBox）
- 嵌入式系统（如车载系统、工业控制）
- 移动应用开发
- 科学计算可视化
- 游戏开发

## 代码示例

Qt程序的基本结构：

```cpp
#include <QApplication>
#include <QLabel>

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);
    
    QLabel label("Hello, Qt!");
    label.show();
    
    return app.exec();
}
```


## 注意事项

1. Qt采用LGPL或商业许可协议，注意合规使用
2. Qt 5.x是目前最稳定的版本，推荐初学者使用
3. 需要理解Qt的元对象系统，否则某些功能无法使用
