# 01-02 Qt开发环境搭建

## 概念解释

### Qt开发环境组成

- **Qt SDK**：Qt库和开发工具
- **Qt Creator**：官方集成开发环境
- **编译器**：MinGW或MSVC
- **调试器**：GDB或CDB

### 安装步骤

1. 访问Qt官网下载在线安装程序
2. 登录Qt账户（可免费注册）
3. 选择安装组件
4. 配置编译器路径
5. 验证安装

### Windows平台编译器选择

| 编译器 | 优点 | 缺点 |
|--------|------|------|
| MinGW | 免费、开源 | 性能略低 |
| MSVC 2019 | 性能好、兼容性强 | 需要Visual Studio |
| MSVC 2022 | 最新特性支持 | 可能有兼容性问题 |

## 代码示例

验证Qt安装的测试程序：


```cpp
#include <QApplication>
#include <QMessageBox>

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);
    
    QMessageBox::information(nullptr, 
        "Qt安装验证", 
        "Qt开发环境搭建成功！");
    
    return 0;
}
```

## 注意事项

1. 安装路径不要包含中文或空格
2. 建议安装所有常用组件
3. 配置环境变量后需要重启IDE
4. 不同Qt版本可能不兼容
