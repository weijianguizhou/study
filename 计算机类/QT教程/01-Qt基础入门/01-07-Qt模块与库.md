## 概念解释

### Qt模块化架构

Qt 5.x采用模块化设计，主要分为：

| 类别 | 说明 |
|------|------|
| Qt Core | 核心非GUI功能 |
| Qt GUI | 基础GUI功能 |
| Qt Widgets | 窗口组件 |
| Qt Quick | QML和Qt Quick |
| Qt Multimedia | 多媒体功能 |
| Qt Network | 网络编程 |
| Qt SQL | 数据库操作 |
| Qt Test | 单元测试 |

### 常用模块

`
QT += core      # 核心模块（默认包含）
QT += gui       # GUI模块（默认包含）
QT += widgets   # 窗口组件
QT += network   # 网络
QT += sql       # 数据库
QT += xml       # XML处理
QT += multimedia # 多媒体
QT += webenginewidgets # Web引擎
QT += concurrent # 并发编程
`

### 静态库与动态库

| 类型 | 优点 | 缺点 |
|------|------|------|
| 静态库 | 部署简单、无依赖 | 体积大、更新困难 |
| 动态库 | 体积小、易更新 | 依赖库文件、部署复杂 |

## 代码示例

### 使用网络模块

`pro
# .pro文件
QT += core gui widgets network
`

`cpp
#include <QNetworkAccessManager>
#include <QNetworkReply>
#include <QUrl>

class Downloader : public QObject
{
    Q_OBJECT
public:
    void download(const QUrl &url)
    {
        QNetworkAccessManager *manager = new QNetworkAccessManager(this);
        connect(manager, &QNetworkAccessManager::finished,
                this, &Downloader::onFinished);
        manager->get(QNetworkRequest(url));
    }
    
private slots:
    void onFinished(QNetworkReply *reply)
    {
        qDebug() << "Downloaded:" << reply->readAll().size() << "bytes";
        reply->deleteLater();
    }
};
`

## 注意事项

1. 只包含需要的模块，减少编译时间
2. 部署时确保包含所有依赖的DLL
3. 不同模块可能有不同的许可证要求
4. 静态编译需要购买商业许可
