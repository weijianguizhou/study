## 概念解释

### Qt项目文件类型

| 文件类型 | 扩展名 | 用途 |
|----------|--------|------|
| 项目文件 | .pro | 项目配置 |
| 头文件 | .h | 类声明 |
| 源文件 | .cpp | 类实现 |
| UI文件 | .ui | 界面设计 |
| 资源文件 | .qrc | 资源管理 |
| 翻译文件 | .ts/.qm | 国际化 |

### .pro文件详解

`pro
# 项目名称
TARGET = MyApp

# 模块
QT += core gui widgets

# C++标准
CONFIG += c++17

# 源文件
SOURCES += main.cpp mainwindow.cpp

# 头文件
HEADERS += mainwindow.h

# 界面文件
FORMS += mainwindow.ui

# 资源文件
RESOURCES += resources.qrc
`

### 目录结构规范

`
MyApp/
├── MyApp.pro          # 项目文件
├── src/               # 源代码目录
│   ├── main.cpp
│   ├── mainwindow.h
│   └── mainwindow.cpp
├── ui/                # UI文件目录
│   └── mainwindow.ui
├── resources/         # 资源目录
│   ├── icons/
│   └── resources.qrc
├── translations/      # 翻译文件
│   └── app_zh_CN.ts
├── tests/             # 测试目录
└── docs/              # 文档目录
`

## 代码示例

### .pro文件配置示例

`pro
QT += core gui widgets network sql

TARGET = MyApp
TEMPLATE = app

CONFIG += c++17

# 定义宏
DEFINES += QT_DEPRECATED_WARNINGS

# 包含路径
INCLUDEPATH += PWD/third_party

# 链接库
LIBS += -LPWD/libs -lmylib

# 源文件
SOURCES += \
    main.cpp \
    mainwindow.cpp \
    database.cpp

HEADERS += \
    mainwindow.h \
    database.h

FORMS += \
    mainwindow.ui
`

### 资源文件示例

`xml
<RCC>
    <qresource prefix="/">
        <file>icons/app.png</file>
        <file>icons/close.png</file>
        <file>styles/default.qss</file>
    </qresource>
</RCC>
`

## 注意事项

1. 文件路径使用相对路径
2. 使用反斜杠或双正斜杠
3. 资源文件编译后会嵌入到可执行文件中
4. 大型项目建议使用子目录模式
