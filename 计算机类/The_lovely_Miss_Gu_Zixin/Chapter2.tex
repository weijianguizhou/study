\section{\LaTeX 文档的基本结构 (Preamble vs. Body)}
\LaTeX 文档由两大部分组成，分工明确：

\begin{itemize}
    \item \textbf{导言区 (Preamble):} 位于 \texttt{\textbackslash documentclass} 和 \texttt{\textbackslash begin\{document\}} 之间。用于加载宏包、定义全局格式（如页边距、字体）和设置元数据（标题、作者）。
    \item \textbf{正文区 (Body):} 位于 \texttt{document} 环境内部。这是你输入实际文字、图表和公式的地方。
\end{itemize}
下面我们来详细聊聊每个部分
\subsection{文档类声明：\texttt{documentclass}}
每个 LaTeX 文档都必须以 \texttt{documentclass} 开头。这一命令用于定义文档的类型，也就是我们要创建的文档格式，比如文章、报告、书籍等。
\begin{lstlisting}
	\documentclass[选项]{文档类}	
\end{lstlisting}

\begin{mybox}{常见的文档类}

    \begin{description}
        \item[\texttt{article / ctexart}] \textcolor{blue}{轻量化选择}。适合论文、作业。没有“章”(\texttt{\textbackslash chapter})的概念。
        \item[\texttt{report / ctexrep}] \textcolor{blue}{结构化选择}。适合较长的实验报告或本科毕业论文，支持“章”。
        \item[\texttt{book / ctexbook}] \textcolor{blue}{出版级选择}。默认双面打印，会自动处理奇偶页的页码位置。
        \item[\texttt{beamer}] \textcolor{blue}{演示神器}。用于制作 PDF 格式的幻灯片，学术会议必备。
    \end{description}
\end{mybox}

\begin{mybox}{常见选项}
	\begin{description}
		\item[10pt,11pt,12pt]设置字体大小，默认为10pt.
		\item[a4paper,letterpapper]设置纸张大小，默认为letterpaper
		\item[twocolumn]将文档排版为双栏格式
		\item[draft]启用调试，显示超出边界的内容  
	\end{description}
\end{mybox}
如
\begin{lstlisting}
	\documentclass[12pt, a4paper]{article}
\end{lstlisting}
上述示例表示创建一个字体大小为 12pt、纸张为 A4 的文章文档。

\section{宏包 (Package) 的使用与管理}
\subsection{加载宏包}
宏包是 LaTeX 的扩展功能模块，用于实现特定的功能。例如：
\begin{lstlisting}
	\usepackage{graphicx} % 加载图片支持
	\usepackage{amsmath}  % 数学公式支持
	\usepackage{ctex}     % 中文支持
\end{lstlisting}

\subsection{全局设置}
在导言区可以设置文档的全局属性，例如页边距、字体、颜色等。例如：
\begin{lstlisting}
	\setlength{\parindent}{2em} % 设置段落缩进为 2 个字符
	\setlength{\parskip}{1em}  % 设置段落间距为 1em
\end{lstlisting}

\section{第一个 \LaTeX 文档示例}

下面就是一个标准的 \LaTeX{} 源代码示例。麻雀虽小，五脏俱全。你可以直接把这个复制粘贴到你的VS Code里，保存为 \texttt{hello\_gu.tex}，然后用 \texttt{XeLaTeX} 编译，就能看到你的第一个 \LaTeX{} 文档了！
\begin{lstlisting}[caption={Hello Gu 完整代码}]
% ======= 1. 导言区 (Preamble) =======
\documentclass{ctexart} % 使用支持中文的文档类

% ======= 2. 正文区 (Body) =======
\begin{document}

Hello, Gu! 
你好，小顾！

\end{document}
\end{lstlisting}

\bigskip
\noindent \textbf{代码解析：}
\begin{itemize}
    \item \texttt{ctexart}: 是专门为中文优化的文档类，确保你的“Gu”能被正确识别。
    \item \texttt{document} 环境: 只有放在这两个命令之间的内容才会被打印到 PDF 上。
\end{itemize}
