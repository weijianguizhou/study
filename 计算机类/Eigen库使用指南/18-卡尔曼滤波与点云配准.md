# 一、卡尔曼滤波

## 数学背景

卡尔曼滤波是机器人定位、目标跟踪里最经典的算法。核心思想：**预测 → 观测 → 修正**，循环往复。

你有一个随时间变化的系统状态$\mathbf{x}$（比如位置+速度）。你知道它怎么变（运动模型），也知道传感器能测什么（观测模型），但两个都有噪声。卡尔曼滤波就是在这两个都不完美的信息源之间找一个最优的折中。

**预测**（根据运动模型猜下一时刻状态）：
$$\hat{\mathbf{x}}_k = F \mathbf{x}_{k-1}$$
$$\hat{P}_k = F P_{k-1} F^T + Q$$

**更新**（根据传感器观测修正猜测）：
$$K = \hat{P}_k H^T (H \hat{P}_k H^T + R)^{-1}$$
$$\mathbf{x}_k = \hat{\mathbf{x}}_k + K(\mathbf{z}_k - H \hat{\mathbf{x}}_k)$$
$$P_k = (I - KH) \hat{P}_k$$

这些公式里：
- $F$：状态转移矩阵——"上一时刻的状态怎么变成这一时刻"
- $H$：观测矩阵——"状态里哪些变量能被观测到"
- $Q$：过程噪声协方差——你有多信任运动模型
- $R$：观测噪声协方差——你有多信任传感器
- $K$：**卡尔曼增益**——决定你更信模型的预测还是传感器的观测

## 代码

```C++
#include <iostream>
#include <Eigen/Dense>

class KalmanFilter {
public:
    Eigen::MatrixXd F, H, Q, R;
    Eigen::VectorXd x;   // 状态估计
    Eigen::MatrixXd P;   // 估计协方差

    KalmanFilter(const Eigen::MatrixXd& F_, const Eigen::MatrixXd& H_,
                 const Eigen::MatrixXd& Q_, const Eigen::MatrixXd& R_,
                 const Eigen::VectorXd& x0, const Eigen::MatrixXd& P0)
        : F(F_), H(H_), Q(Q_), R(R_), x(x0), P(P0) {}

    void predict() {
        x = F * x;
        P = F * P * F.transpose() + Q;
    }

    void update(const Eigen::VectorXd& z) {
        Eigen::VectorXd y = z - H * x;
        Eigen::MatrixXd S = H * P * H.transpose() + R;
        Eigen::MatrixXd K = P * H.transpose() * S.inverse();
        x = x + K * y;
        P = (Eigen::MatrixXd::Identity(P.rows(), P.cols()) - K * H) * P;
    }
};

int main() {
    // 状态: [px, py, vx, vy]
    // 观测: [px, py] (只看到位置，看不到速度)

    int n_state = 4, n_obs = 2;
    double dt = 1.0;

    // F: 匀速运动
    Eigen::MatrixXd F = Eigen::MatrixXd::Identity(n_state, n_state);
    F(0, 2) = dt; F(1, 3) = dt;

    // H: 只看位置
    Eigen::MatrixXd H = Eigen::MatrixXd::Zero(n_obs, n_state);
    H(0, 0) = 1; H(1, 1) = 1;

    Eigen::MatrixXd Q = Eigen::MatrixXd::Identity(n_state, n_state) * 0.01;
    Eigen::MatrixXd R = Eigen::MatrixXd::Identity(n_obs, n_obs) * 0.1;

    Eigen::VectorXd x0 = Eigen::Vector4d(0, 0, 1, 0);
    Eigen::MatrixXd P0 = Eigen::MatrixXd::Identity(4, 4) * 1000;

    KalmanFilter kf(F, H, Q, R, x0, P0);

    // 一组观测（模拟传感器测量）
    std::vector<Eigen::Vector2d> obs = {
        {0.1, 0.05}, {1.05, -0.02}, {2.0, 0.1}, {3.1, -0.05}, {3.98, 0.08}
    };

    for (size_t i = 0; i < obs.size(); i++) {
        kf.predict();
        kf.update(obs[i]);
        std::cout << "步" << i << " 估计位置: ("
                  << kf.x(0) << ", " << kf.x(1) << ")"
                  << " 速度: (" << kf.x(2) << ", " << kf.x(3) << ")" << std::endl;
    }
}
```

```cmd

步1 估计位置: (1.05, -0.0201) 速度: (1.04, -0.02)
步2 估计位置: (2.00, 0.0972) 速度: (0.997, 0.044)
步3 估计位置: (3.10, -0.0455) 速度: (1.07, -0.065)
步4 估计位置: (3.98, 0.0749) 速度: (0.937, 0.078)
```

即使传感器只看位置没看速度，滤波器也把速度估计出来了——因为运动模型（匀速）和连续的位置观测共同暗示了速度。

# 二、点云配准 (ICP简化版)

## 数学背景

给你两坨三维点云$P = \{\mathbf{p}_1,\dots,\mathbf{p}_n\}$和$Q = \{\mathbf{q}_1,\dots,\mathbf{q}_n\}$。假设第$i$个点$\mathbf{p}_i$刚好对应第$i$个点$\mathbf{q}_i$（对应关系已知），找最优的旋转$R$和平移$\mathbf{t}$让：

$$\mathbf{q}_i \approx R\mathbf{p}_i + \mathbf{t}, \quad \forall i$$

最优的标准是最小化所有点变换后的位置和目标的距离平方和：

$$\min_{R,\mathbf{t}} \sum_{i=1}^n \|R\mathbf{p}_i + \mathbf{t} - \mathbf{q}_i\|^2$$

$R$必须是合法的旋转矩阵（$R^T R = I$，$\det(R)=1$）。

### 先搞定平移

把上面的目标函数对$\mathbf{t}$求导。令$\bar{\mathbf{p}} = \frac{1}{n}\sum \mathbf{p}_i$，$\bar{\mathbf{q}} = \frac{1}{n}\sum \mathbf{q}_i$。设$\mathbf{p}'_i = \mathbf{p}_i - \bar{\mathbf{p}}$，$\mathbf{q}'_i = \mathbf{q}_i - \bar{\mathbf{q}}$（中心化后的点）。

展开目标函数，可以证明最优的$\mathbf{t}$满足：

$$\mathbf{t} = \bar{\mathbf{q}} - R\bar{\mathbf{p}}$$

这很直观——把两个点云的重心对齐之后，平移就被分离出去了。剩下只需要找最优的旋转$R$来对齐中心化后的点：

$$\min_{R} \sum_{i=1}^n \|R\mathbf{p}'_i - \mathbf{q}'_i\|^2$$

### 展开旋转的优化

展开平方：

$$\sum_i \|R\mathbf{p}'_i - \mathbf{q}'_i\|^2 = \sum_i \left( \|R\mathbf{p}'_i\|^2 + \|\mathbf{q}'_i\|^2 - 2\mathbf{q}'_i{}^T R\mathbf{p}'_i \right)$$

因为$R$是正交矩阵，$\|R\mathbf{p}'_i\|^2 = \|\mathbf{p}'_i\|^2$（旋转保长度）。所以前两项跟$R$无关。**最小化上面这个等价于最大化**：

$$\sum_i \mathbf{q}'_i{}^T R\mathbf{p}'_i = \operatorname{tr}\!\left(R \sum_i \mathbf{p}'_i \mathbf{q}'_i{}^T\right)$$

中间这个求和就是交叉协方差矩阵：

$$H = \sum_{i=1}^n \mathbf{p}'_i \mathbf{q}'_i{}^T \quad (= P'^T Q'\;\text{写成矩阵形式})$$

所以问题变成了：找正交矩阵$R$最大化$\operatorname{tr}(RH^T)$。

### SVD给出答案

对$H$做SVD：$H = U\Sigma V^T$。可以证明（利用迹的性质和奇异值的非负性），最大化$\operatorname{tr}(RH^T)$的$R$是：

$$R = V U^T$$

然后用$\det(R)$判断是否反射——如果$\det(R) = -1$（不是合法旋转），把$V$的最后一列取负号纠正。

## 代码

```C++
#include <iostream>
#include <Eigen/Dense>
#include <Eigen/SVD>

int main() {
    int n = 50;

    // 造一坨随机点云 P
    Eigen::MatrixXd P = Eigen::MatrixXd::Random(n, 3) * 5;

    // 给它做一个真实的旋转+平移，造出 Q
    Eigen::Matrix3d R_true = Eigen::AngleAxisd(0.5, Eigen::Vector3d::UnitZ())
                           * Eigen::AngleAxisd(0.3, Eigen::Vector3d::UnitY());
    Eigen::Vector3d t_true(1.5, -0.5, 2.0);

    Eigen::MatrixXd Q = (R_true * P.transpose()).transpose();
    Q.rowwise() += t_true.transpose();
    Q += 0.02 * Eigen::MatrixXd::Random(n, 3);  // 加一丁点噪声模拟真实传感器

    // -- 求解 --
    // 1. 去中心化
    Eigen::RowVector3d centroid_P = P.colwise().mean();
    Eigen::RowVector3d centroid_Q = Q.colwise().mean();
    P.rowwise() -= centroid_P;
    Q.rowwise() -= centroid_Q;

    // 2. 交叉协方差
    Eigen::Matrix3d H = P.transpose() * Q;

    // 3. SVD
    Eigen::JacobiSVD<Eigen::Matrix3d> svd(H, Eigen::ComputeFullU | Eigen::ComputeFullV);
    Eigen::Matrix3d R = svd.matrixV() * svd.matrixU().transpose();

    // 4. 纠正反射
    if (R.determinant() < 0) {
        Eigen::Matrix3d V = svd.matrixV();
        V.col(2) = -V.col(2);
        R = V * svd.matrixU().transpose();
    }

    // 5. 平移
    Eigen::Vector3d t = centroid_Q.transpose() - R * centroid_P.transpose();

    std::cout << "真实 R:\n" << R_true << std::endl;
    std::cout << "求解 R:\n" << R << std::endl;
    std::cout << "旋转误差(范数): " << (R - R_true).norm() << std::endl;
    std::cout << "真实 t: " << t_true.transpose() << std::endl;
    std::cout << "求解 t: " << t.transpose() << std::endl;
}
```

-0.256489  0.000000  0.963956
