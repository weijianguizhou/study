# 特征值与特征向量

---

# 复习一下代数学

## 特征值和特征向量是啥

给一个方阵$A$，如果存在一个数$\lambda$和一个非零向量$v$，使得：

$$Av = \lambda v$$

那$\lambda$就是$A$的一个**特征值**，$v$是对应的**特征向量**。

物理直觉：特征向量是$A$"不改变方向只缩放"的方向——$A$作用在$v$上，只是把$v$拉长或缩短了$\lambda$倍，方向没变。

## 对称矩阵的特殊待遇

如果$A$是实对称矩阵（$A = A^T$），那它有一堆好性质：

1. 所有特征值都是**实数**（不用担心复数）
2. 特征向量可以选成**两两正交**的
3. 一定可以对角化：$A = V \Lambda V^T$，$V$的列是特征向量，$\Lambda$是对角特征值矩阵

机器学习里99%的特征分解（协方差矩阵、Hessian、拉普拉斯矩阵……）都是对称矩阵，所以Eigen给对称矩阵专门准备了`SelfAdjointEigenSolver`。

## 一般矩阵

如果$A$不是对称的，特征值和特征向量可能是复数。Eigen用`EigenSolver`来处理，返回的是复数类型。

# Eigen 里的 SelfAdjointEigenSolver

"SelfAdjoint"=自伴，在实数里就是对称的意思。给你的矩阵要是对称的，**一定要用这个**——特征值保证是实数，特征向量正交，速度比一般版本快。

```C++
#include <iostream>
#include <Eigen/Dense>

int main() {
    Eigen::Matrix2d A;
    A << 1, 2,
         2, 3;   // 实对称

    Eigen::SelfAdjointEigenSolver<Eigen::Matrix2d> solver(A);

    if (solver.info() != Eigen::Success) {
        std::cerr << "特征分解失败！" << std::endl;
        return 1;
    }

    std::cout << "特征值: " << solver.eigenvalues().transpose() << std::endl;
    std::cout << "特征向量（列向量）:\n" << solver.eigenvectors() << std::endl;

    // 验证：A * v = λ * v
    Eigen::Vector2d v1 = solver.eigenvectors().col(0);
    double lambda1 = solver.eigenvalues()(0);
    std::cout << "A*v1 = " << (A * v1).transpose() << std::endl;
    std::cout << "λ1*v1 = " << (lambda1 * v1).transpose() << std::endl;
}
```

```cmd
特征值: -0.236  4.24
特征向量（列向量）:
-0.851 -0.526
 0.526 -0.851
A*v1 = 0.201 -0.124
λ1*v1 = 0.201 -0.124
```

注意特征向量是按列存的——第$i$列对应第$i$个特征值。而且Eigen默认**从小到大**排特征值。

想要从大到小？用`.reverse()`：

```C++
Eigen::VectorXd evals_desc = solver.eigenvalues().reverse();
Eigen::MatrixXd evecs_desc = solver.eigenvectors().rowwise().reverse();
```

# 实战：PCA（主成分分析）

PCA是特征值分解在数据科学里最经典的应用。给你一个数据矩阵（每行一个样本，每列一个特征），PCA帮你找到数据方差最大的那些方向。

**步骤**：

1. 中心化——每列减掉自己的均值，让数据重心移到原点。
2. 算协方差矩阵 $C = \frac{1}{n-1} X^T X$。
3. 对$C$做特征分解——$C$是实对称的，正定或半正定。
4. 取前$k$个最大特征值对应的特征向量作为主方向。
5. 把原始数据投影到这些主方向上，得到降维后的数据。

```C++
#include <iostream>
#include <Eigen/Dense>

int main() {
    int n = 100, d = 5;
    Eigen::MatrixXd data = Eigen::MatrixXd::Random(n, d) * 10;

    std::cout << "原始数据形状: " << data.rows() << " × " << data.cols() << std::endl;

    // 1. 中心化
    Eigen::RowVectorXd mean = data.colwise().mean();
    data.rowwise() -= mean;

    // 2. 协方差矩阵
    Eigen::MatrixXd cov = (data.transpose() * data) / double(data.rows() - 1);

    // 3. 特征分解（协方差矩阵对称正定）
    Eigen::SelfAdjointEigenSolver<Eigen::MatrixXd> solver(cov);
    Eigen::VectorXd eigenvalues = solver.eigenvalues().reverse();     // 降序
    Eigen::MatrixXd eigenvectors = solver.eigenvectors().rowwise().reverse();

    std::cout << "特征值（降序）: " << eigenvalues.transpose() << std::endl;

    // 4. 降到2维
    int k = 2;
    Eigen::MatrixXd reduced = data * eigenvectors.leftCols(k);
    std::cout << "降维后数据形状: " << reduced.rows() << " × " << reduced.cols() << std::endl;

    // 解释了多少方差？
    double explained = eigenvalues.head(k).sum() / eigenvalues.sum();
    std::cout << "前" << k << "个主成分解释了 " << explained * 100 << "% 的方差" << std::endl;
}
```

```cmd
原始数据形状: 100 × 5
特征值（降序）: 1027 890 785 673 544
降维后数据形状: 100 × 2
前2个主成分解释了 48.8% 的方差
```

# Eigen 里的 EigenSolver（一般矩阵）

如果你的矩阵**不是**对称的，特征值和特征向量可能是复数。Eigen用`EigenSolver`来处理。

```C++
#include <iostream>
#include <Eigen/Dense>

int main() {
    Eigen::Matrix3d A;
    A << 0,  -1,  0,
         1,   0,  0,
         0,   0,  2;

    Eigen::EigenSolver<Eigen::Matrix3d> solver(A);

    std::cout << "特征值:\n" << solver.eigenvalues() << std::endl;
    // 特征值是复数类型 complex<double>
    // 这个矩阵的特征值：λ1=i, λ2=-i, λ3=2

    std::cout << "特征向量（列向量，复数）:\n" << solver.eigenvectors() << std::endl;
}
```

```cmd
特征值:
 (0,1)
(0,-1)
  (2,0)
特征向量（列向量，复数）:
...
```

输出是复数的形式：`(0,1)`表示$i$，`(0,-1)`表示$-i$，`(2,0)`表示实数2。

# 选哪个？

| 你的矩阵 | 用啥 |
|---------|------|
| 实对称 / 自伴 | `SelfAdjointEigenSolver`（保证实数、快） |
| 一般实方阵 | `EigenSolver`（可能出复数） |
| 复方阵 | `ComplexEigenSolver` |

绝大多数应用场景（协方差矩阵、Hessian、拉普拉斯矩阵）都是对称的，所以`SelfAdjointEigenSolver`是主力。
