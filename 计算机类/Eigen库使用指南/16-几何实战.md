# 一、坐标系变换基础

## 数学背景

现实中的刚体变换包含**旋转**和**平移**两部分。想把一个在坐标系$A$中的点$\mathbf{p}^A$转到坐标系$B$中，操作是：

$$\mathbf{p}^B = R_{A \to B} \; \mathbf{p}^A + \mathbf{t}_{A \to B}$$

$R_{A \to B}$是把向量从坐标系$A$旋转到坐标系$B$的旋转矩阵，$\mathbf{t}_{A \to B}$是$A$的原点在$B$中的位置。

换成齐次坐标，写成一条式子：

$$\begin{pmatrix} \mathbf{p}^B \\ 1 \end{pmatrix} = \begin{pmatrix} R_{A \to B} & \mathbf{t}_{A \to B} \\ \mathbf{0}^T & 1 \end{pmatrix} \begin{pmatrix} \mathbf{p}^A \\ 1 \end{pmatrix}$$

这个$4\times4$矩阵$T_{A \to B}$就是把坐标系$A$中的点映射到坐标系$B$的**齐次变换矩阵**。

### 多个坐标系的串联

如果你有三个坐标系$A,B,C$，并且知道$T_{A \to B}$和$T_{B \to C}$，那从$A$直接到$C$的变换就是：

$$T_{A \to C} = T_{B \to C} \cdot T_{A \to B}$$

**注意乘的顺序**：右边的先作用。把$A$中的点先转到$B$（$T_{A \to B}$），再转到$C$（$T_{B \to C}$）。

这也是机器人正向运动学的基础——把每根连杆的变换矩阵乘起来，就从基座标系一路上到末端了。

# 二、机器人手眼标定

## 场景

相机装在机械臂末端（眼在手上）。相机看到物体在相机坐标系下的位置$\mathbf{p}^{cam}$，你想知道它在机器人基座坐标系下的位置$\mathbf{p}^{base}$。

你需要一个变换$T_{cam \to base}$——相机坐标系到基座标系的齐次变换。

## 代码

```C++
#include <iostream>
#include <Eigen/Geometry>

int main() {
    // 相机在基座系下的位姿：位于(0.5, 0, 0.8)，绕Z轴转180°
    Eigen::Affine3f T_base_to_cam = Eigen::Translation3f(0.5, 0.0, 0.8)
                                  * Eigen::AngleAxisf(M_PI, Eigen::Vector3f::UnitZ());

    // 物体在相机里的坐标
    Eigen::Vector3f obj_in_cam(0.1, 0.05, 0.5);

    // 转到基座系下
    Eigen::Vector3f obj_in_base = T_base_to_cam * obj_in_cam;

    std::cout << "基座系下物体位置: " << obj_in_base.transpose() << std::endl;
}
```

```cmd
基座系下物体位置: 0.4 -0.05 1.3
```

# 三、DH参数到齐次变换

## 数学背景

机器人学里，描述一根连杆相对于上一根连杆的位姿，用**四个DH参数**：$(\theta, d, a, \alpha)$。

- $\theta$（关节角）：绕$Z_{i-1}$轴旋转的角度
- $d$（连杆偏距）：沿$Z_{i-1}$轴平移的距离
- $a$（连杆长度）：沿$X_i$轴平移的距离
- $\alpha$（扭角）：绕$X_i$轴旋转的角度

一根连杆的变换是这四个基本操作的乘积——但相乘的**顺序**很讲究：

**先沿$Z$轴做旋转和平移，再沿（旋转后的）$X$轴做平移和旋转**。写成矩阵：

$$T_i = \text{Rot}_Z(\theta) \cdot \text{Trans}_Z(d) \cdot \text{Trans}_X(a) \cdot \text{Rot}_X(\alpha)$$

展开这个乘积：

$$T_i = \begin{pmatrix}
\cos\theta & -\sin\theta\cos\alpha &  \sin\theta\sin\alpha & a\cos\theta \\
\sin\theta &  \cos\theta\cos\alpha & -\cos\theta\sin\alpha & a\sin\theta \\
0          &  \sin\alpha          &  \cos\alpha           & d          \\
0          &  0                   &  0                    & 1
\end{pmatrix}$$

这就是经典的DH变换矩阵。把第1根到第$n$根连杆的这些矩阵全乘起来：

$$T_{total} = T_1 \cdot T_2 \cdot \cdots \cdot T_n$$

$T_{total}$的平移部分就是末端执行器在基座标系下的位置。

## 代码

```C++
#include <iostream>
#include <Eigen/Geometry>

int main() {
    float theta = M_PI / 4;
    float d = 0.3, a = 0.5, alpha = 0;

    // 注意：顺序是按 DH 约定的顺序，先Z轴再X轴
    Eigen::Affine3f T = Eigen::Translation3f(0, 0, d)
                      * Eigen::AngleAxisf(theta, Eigen::Vector3f::UnitZ())
                      * Eigen::Translation3f(a, 0, 0)
                      * Eigen::AngleAxisf(alpha, Eigen::Vector3f::UnitX());

    std::cout << "DH变换矩阵:\n" << T.matrix() << std::endl;
    std::cout << "末端位置: " << T.translation().transpose() << std::endl;
}
```

```cmd
DH变换矩阵:
 0.707107 -0.707107         0  0.353553
 0.707107  0.707107         0  0.353553
        0         0         1       0.3
        0         0         0         1
末端位置: 0.353553 0.353553 0.3
```

# 四、航迹推演 (Dead Reckoning)

## 数学背景

假设你有一个移动机器人在平面上跑。初始时刻你知道它在原点，朝向正X轴。之后每个时刻有一个小运动——前进一小段$\Delta s$，转一小点$\Delta\theta$。

关键问题：**全局位姿怎么更新**？

如果每一步的相对运动是$\Delta T$（一个齐次变换矩阵），那新位姿$T_{k+1}$等于旧位姿$T_k$右边乘上这个相对运动：

$$T_{k+1} = T_k \cdot \Delta T$$

为什么是**右乘**而不是左乘？因为$\Delta T$是在机器人**自己的局部坐标系**里描述的——"往前走0.1米"这个动作，不管机器人当前朝向哪里，在它自己看来就是朝前。右乘的意思就是"在当前位姿的基础上，再做一步局部的运动"。

## 代码

```C++
#include <iostream>
#include <Eigen/Geometry>
#include <vector>

int main() {
    std::vector<Eigen::Affine3f> poses;
    poses.push_back(Eigen::Affine3f::Identity());  // 初始位姿在原点

    for (int i = 1; i <= 10; i++) {
        // 每步：前进0.1米 + 稍微往左转
        Eigen::Affine3f delta = Eigen::Translation3f(0.1, 0, 0)
                              * Eigen::AngleAxisf(0.1, Eigen::Vector3f::UnitZ());

        poses.push_back(poses.back() * delta);  // 右乘=在局部系运动
    }

    for (int i = 0; i < poses.size(); i++) {
        std::cout << "步" << i << ": 位置="
                  << poses[i].translation().transpose() << std::endl;
    }
}
```

```cmd
步0: 位置=0 0 0
步1: 位置=0.0998334 0.00998334 0
步2: 位置=0.198669 0.0398667 0
步3: 位置=0.29552 0.08933 0
步4: 位置=0.389418 0.157955 0
...
```

可以看到轨迹是弧线——每步在局部朝前运动，但每一步之后朝向在变，所以整体画出来是圆弧。

# 五、相机投影（针孔模型）

## 数学背景

相机把三维世界拍成二维照片，这件事在几何上分两步。

### 第一步：世界坐标 → 相机坐标（外参）

相机在三维空间里有一个位置和一个朝向。把世界坐标$P_{world}$转到相机坐标$P_{cam}$：

$$P_{cam} = R \cdot P_{world} + \mathbf{t}$$

或者用齐次变换$T_{world \to cam}$：

$$P_{cam} = T_{world \to cam} \cdot P_{world}$$

### 第二步：相机坐标 → 像素坐标（内参）

针孔相机模型下，相机坐标系里一个点$(X, Y, Z)$投影到图像平面，通过相似三角形：

$$\tilde{x} = f\frac{X}{Z}, \quad \tilde{y} = f\frac{Y}{Z}$$

$f$是焦距，$\tilde{x}, \tilde{y}$是以光心为原点的图像坐标（单位是毫米）。

再把毫米转成像素：像素坐标$(u, v)$：

$$u = f_x \frac{X}{Z} + c_x, \quad v = f_y \frac{Y}{Z} + c_y$$

其中$f_x = f / s_x$（$s_x$是每个像素的物理宽度），$c_x, c_y$是光心在像素坐标系下的位置。

写成齐次形式：

$$\begin{pmatrix} u \\ v \\ 1 \end{pmatrix} \sim \begin{pmatrix} f_x & 0 & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} X \\ Y \\ Z \end{pmatrix}$$

左边是齐次坐标（第三个分量不一定是1，除以它得到真正的像素坐标）。右边那个$3\times3$矩阵就是**内参矩阵$K$**。

### 总流程

世界3D点 → 外参$(R, \mathbf{t})$转到相机坐标系 → 内参$K$投影 → 除以深度得到像素坐标。

$$\lambda \begin{pmatrix} u \\ v \\ 1 \end{pmatrix} = K \cdot (R \cdot P_{world} + \mathbf{t}) = K \cdot T_{world \to cam} \cdot P_{world}$$

## 代码

```C++
#include <iostream>
#include <Eigen/Geometry>

int main() {
    // 相机位于(2, 0, 1)，朝向原点
    Eigen::Vector3f cam_pos(2, 0, 1);
    Eigen::Vector3f look_at(0, 0, 0);
    Eigen::Vector3f look_dir = (look_at - cam_pos).normalized();

    // 构建世界→相机 的变换
    Eigen::Affine3f T_world_to_cam = Eigen::Translation3f(-cam_pos)
                                   * Eigen::Quaternionf::FromTwoVectors(
                                       Eigen::Vector3f::UnitZ(), look_dir);

    // 内参（焦距500，光心在(320, 240)）
    Eigen::Matrix3f K;
    K << 500,   0, 320,
           0, 500, 240,
           0,   0,   1;

    // 世界系的一个3D点
    Eigen::Vector3f P_world(0, 0.5, 0.5);

    // 转到相机系
    Eigen::Vector3f P_cam = T_world_to_cam * P_world;

    // 投影 → 再除以Z
    Eigen::Vector3f p_homo = K * P_cam;
    Eigen::Vector2f pixel(p_homo.x() / p_homo.z(), p_homo.y() / p_homo.z());

    std::cout << "相机坐标系下: " << P_cam.transpose() << std::endl;
    std::cout << "像素坐标: " << pixel.transpose() << std::endl;
}
```

`FromTwoVectors(UnitZ(), look_dir)`找到"把UnitZ旋转到look_dir方向"的那个旋转，本质就是让相机光轴对准目标。
