# 仿射变换 (Affine)

旋转只是转方向。现实中你还要**平移**（把物体挪个位置）、可能还要**缩放**。这些操作拧在一起，用$4\times4$的**齐次变换矩阵**统一搞定。Eigen里这个叫`Affine3f`（`f`是float，还有`d`是double）。

---

# 复习一下代数学

## 齐次坐标

三维空间的一个点$\mathbf{p} = (x, y, z)$，写成齐次坐标就是$(x, y, z, 1)$。一个方向向量$\mathbf{v} = (v_x, v_y, v_z)$，齐次坐标是$(v_x, v_y, v_z, 0)$——最后一位为0表示"不受平移影响"。

## 齐次变换矩阵

一个$4\times4$的矩阵把旋转、平移、缩放全打包了：

$$T = \begin{pmatrix} R & \mathbf{t} \\ \mathbf{0}^T & 1 \end{pmatrix}$$

- 左上$3\times3$的$R$管旋转（也可能含缩放）
- 右边$3\times1$的$\mathbf{t}$管平移
- 底下一行$[0\;0\;0\;1]$保证是仿射变换

变换一个点：$T \cdot (x,y,z,1)^T = (R\mathbf{p} + \mathbf{t}, 1)$。旋转加平移一气呵成。

变换一个方向：$T \cdot (v_x,v_y,v_z,0)^T = (R\mathbf{v}, 0)$。平移被自动忽略——方向的齐次坐标末位是0，乘$\mathbf{t}$后那部分直接没了。

# Eigen 里的 Affine

## 构造

```C++
#include <iostream>
#include <Eigen/Geometry>

int main() {
    // 方式1：一条链式表达式搞定（最推荐）
    Eigen::Affine3f T = Eigen::Translation3f(1, 2, 3)  // 平移
                      * Eigen::AngleAxisf(M_PI/4, Eigen::Vector3f::UnitZ())  // 旋转
                      * Eigen::Scaling(0.5);  // 缩放

    std::cout << "4×4齐次矩阵:\n" << T.matrix() << std::endl;

    // 方式2：从单位变换开始，一步步来
    Eigen::Affine3f T2 = Eigen::Affine3f::Identity();
    T2.translate(Eigen::Vector3f(1, 2, 3));   // 右乘平移
    T2.rotate(Eigen::AngleAxisf(M_PI/4, Eigen::Vector3f::UnitZ()));  // 右乘旋转
    T2.scale(0.5);                             // 右乘缩放
}
```

```cmd
4×4齐次矩阵:

 0.353553  0.353553         0         2
        0         0       0.5         3
        0         0         0         1
```

## 变换点 vs 变换方向

**非常重要的区别**：

- **点**有位置，受平移影响。
- **方向向量**只是一个箭头，平移对它没意义。

```C++
Eigen::Affine3f T = Eigen::Translation3f(2, 3, 4)
                  * Eigen::AngleAxisf(M_PI/2, Eigen::Vector3f::UnitZ());

Eigen::Vector3f point(1, 0, 0);       // "在(1,0,0)的那个点"
Eigen::Vector3f direction(1, 0, 0);   // "指向东方的箭头"

// 变换点：使用完整的 Affine（带平移）
Eigen::Vector3f point_new = T * point;

// 变换方向：只用旋转部分，丢掉平移
Eigen::Vector3f dir_new = T.linear() * direction;

std::cout << "点变换后: " << point_new.transpose() << std::endl;
std::cout << "方向变换后: " << dir_new.transpose() << std::endl;
```

`T.linear()`提取左上角$3\times3$的旋转+缩放矩阵，把最右列的平移扔了。

## 访问各个部分

```C++
Eigen::Affine3f T = /* ... */;

T.matrix();           // 完整的 4×4 矩阵
T.translation();      // 平移部分 (3×1 向量)
T.linear();           // 旋转+缩放部分 (3×3)
T.rotation();         // 只提取旋转 (3×3，把缩放剥离)
T(0, 3);              // 访问第0行第3列——平移的X分量
```

## 法向量变换

3D图形学里有个坑。如果你在做渲染，法向量$\mathbf{n}$（表面垂线）的变换跟普通方向向量不一样。

普通方向向量$\mathbf{v}$：变换后 = $R \cdot \mathbf{v}$。

法向量$\mathbf{n}$：

- 如果**只有旋转没有缩放**，直接用$R$就行。
- 如果**有非均匀缩放**（各向异性缩放），必须用$(R^{-1})^T$。

```C++
Eigen::Matrix3f normalMatrix = T.linear().inverse().transpose();
Eigen::Vector3f n_new = (normalMatrix * n).normalized();
```

为啥这样？非均匀缩放把表面拉歪了，原来垂直于表面的法向量不再垂直了。$(R^{-1})^T$恰好把法向量纠正到正确的方向。

## OpenGL 兼容

```C++
glLoadMatrixf(T.data());
```

# Translation（平移）

单独用平移时可以只用`Translation3f`，不一定要整个`Affine3f`：

```C++
Eigen::Translation3f t(1.0, 2.0, 3.0);
Eigen::Vector3f p(0, 0, 0);
Eigen::Vector3f p_t = t * p;  // [1, 2, 3]^T

// 平移和旋转混合
auto T = t * Eigen::AngleAxisf(M_PI/4, Eigen::Vector3f::UnitZ());
```

---

# Scaling（缩放）

```C++
// 均匀缩放——所有方向一样
Eigen::UniformScaling<float> s(2.0);

// 非均匀缩放
Eigen::DiagonalMatrix<float, 3> s_vec(0.5, 1.0, 2.0);

// 缩放混在矩阵里
Eigen::Matrix3f T = s * Eigen::AngleAxisf(M_PI/4, Eigen::Vector3f::UnitZ());
```

# pretranslate 和 prerotate

除了`translate()`和`rotate()`（右乘），还有`pretranslate()`和`prerotate()`（左乘）。区别在于变换的先后顺序：

```C++
// 右乘：先旋转，再平移
T.rotate(...);
T.translate(...);

// 左乘：先平移，再旋转
T.prerotate(...);
T.pretranslate(...);
```

对于全局位姿累积来说，右乘和左乘分别对应"在局部坐标系下运动"和"在全局坐标系下运动"。搞清你要哪个很重要。
