# QR 分解与最小二乘

---

# 复习一下代数学

## QR分解是啥

把一个矩阵$A$（不一定是方阵！）写成一个**正交矩阵$Q$**和一个**上三角矩阵$R$**的乘积：

$$A = QR$$

- $Q$满足$Q^T Q = I$（正交矩阵）。正交矩阵的牛逼之处在于它的逆就是它的转置，$Q^{-1} = Q^T$。
- $R$是上三角矩阵。

那解$Ax = b$怎么用到QR分解？把$A$换掉：
$$QRx = b \implies Rx = Q^T b \quad (\text{左边乘}Q^T\text{，利用了}Q^TQ = I)$$

最后一步只是解一个上三角的$R$——回代就行，$O(n^2)$。

## QR是怎么算出来的

QR分解的核心工具是**Householder反射**。思路是这样的：

想象你要把向量$\mathbf{v}$变成$[\|\mathbf{v}\|, 0, 0, \ldots]^T$（模长相同的、只在第一维非零的向量）。你找一面"镜子"（超平面），把$\mathbf{v}$反射过去。

这面"镜子"可以用一个矩阵$H = I - 2\frac{\mathbf{u}\mathbf{u}^T}{\mathbf{u}^T\mathbf{u}}$来表示（$\mathbf{u}$是镜子的法向量）。$H$就是Householder矩阵，它是对称的、正交的。

对矩阵$A$做QR分解时，过程是这样的：

1. 看$A$的第一列$\mathbf{a}_1$。找一个Householder矩阵$H_1$，让$H_1\mathbf{a}_1$变成只第一个元素非零的向量。
2. $H_1A$的第一列下面对角线的部分全变成零了。
3. 再看$H_1A$的第二列（只看对角线以下的元素）。找$H_2$，把第二列对角线以下消零。
4. 继续下去……最后得到一个上三角矩阵$R = H_{n-1} \cdots H_1 A$。
5. 同时$Q = H_1 \cdots H_{n-1}$（注意反射矩阵都是自己的逆，所以$Q^T = H_{n-1} \cdots H_1$）。

整个过程从第一列扫到最后一列，每次铲掉对角线以下的部分。这就是"一系列反射把矩阵逐列铲成上三角"。

## QR和最小二乘

如果$A$是长方形矩阵（比如$5\times3$，5个方程3个未知数），方程组$Ax=b$通常**没有精确解**——5个方程约束3个变量，太苛刻了。这时候退一步，求**最小二乘解**：

$$\min_x \|Ax - b\|^2$$

"找一个$x$让$Ax$和$b$的差距（残差平方和）最小"。

QR分解天然适合解最小二乘。不详细推导了，结论就是：
$$Rx = Q^T b$$
解出来$x$就是最小二乘解。

# Eigen 里的 HouseholderQR

这是最标准的QR，啥附加操作都没有，纯粹、快速。

```C++
#include <iostream>
#include <Eigen/Dense>

int main() {
    // 5个方程，3个未知数（超定）
    Eigen::MatrixXf A = Eigen::MatrixXf::Random(5, 3);
    Eigen::VectorXf b = Eigen::VectorXf::Random(5);

    std::cout << "A (5x3):\n" << A << std::endl;
    std::cout << "b: " << b.transpose() << std::endl;

    Eigen::VectorXf x = A.householderQr().solve(b);
    std::cout << "最小二乘解 x: " << x.transpose() << std::endl;

    // 验证：残差 = ||Ax - b||
    float residual = (A * x - b).norm();
    std::cout << "残差: " << residual << std::endl;
}
```

```cmd
A (5x3):
 -0.824  -0.199   0.577
  0.924  -0.237  -0.237
-0.0532   0.146   0.453
  0.463  -0.568  -0.481
 -0.147   0.265   0.148
b: 0.634 0.334 -0.779 0.674 -0.344
最小二乘解 x: -0.254 -0.658  0.327
残差: 1.032
```

残差不为零——因为超定方程通常没有精确解。这个$x$已经是让残差**最小的**那个$x$了。

## 把Q和R拿出来

有时候你不是只要解，还想看看$Q$和$R$长啥样：

```C++
Eigen::MatrixXf A = Eigen::MatrixXf::Random(5, 3);
Eigen::HouseholderQR<Eigen::MatrixXf> qr(A);

// R就是上三角的部分
Eigen::MatrixXf R = qr.matrixQR().triangularView<Eigen::Upper>();

// Q拿出来的方法有点绕——Eigen不显式存Q，只存了一堆Householder向量
// 取出thin Q（和A列数相同的Q）：
Eigen::MatrixXf thinQ = qr.householderQ() * Eigen::MatrixXf::Identity(5, 3);

std::cout << "Q (thin, 前3列):\n" << thinQ << std::endl;
std::cout << "R:\n" << R.topRows(3) << std::endl;

// 验证 A ≈ Q * R
float err = (A - thinQ * R.topRows(3)).norm();
std::cout << "||A - QR|| = " << err << std::endl;  // 应该非常接近0
```

```cmd
||A - QR|| = 1.23e-07
```

# Eigen 里的 ColPivHouseholderQR

标准QR有个隐患：如果在消元的过程中某一列全都很小，那你用它当主元来消后续列的时候，精度就崩了。

`ColPivHouseholderQR`在每个消元步骤**加了一个列置换**：它选当前剩余的列里范数最大的那一列作为主元。这个操作叫**列主元 (Column Pivoting)**。

$$AP = QR$$

$P$是列置换矩阵。加了$P$以后，数值更稳定，而且可以通过$R$的对角元来判断矩阵的秩。

```C++
Eigen::MatrixXf A = Eigen::MatrixXf::Random(6, 4);
Eigen::VectorXf b = Eigen::VectorXf::Random(6);

Eigen::ColPivHouseholderQR<Eigen::MatrixXf> qr(A);
Eigen::VectorXf x = qr.solve(b);

// 看一下列是怎么被重排的
std::cout << "列置换索引: " << qr.colsPermutation().indices().transpose() << std::endl;
// 比如输出 [1 3 0 2] 意思是：新的第0列是原来的第1列，新的第1列是原来的第3列……

// R（上三角部分，已经按照置换后的顺序了）
Eigen::MatrixXf R = qr.matrixQR().topRows(4).triangularView<Eigen::Upper>();
std::cout << "R:\n" << R << std::endl;

// 秩（通过R的对角元判断）
std::cout << "A的秩: " << qr.rank() << std::endl;
```

**一句话总结**：`HouseholderQR`是"快速最小二乘"，`ColPivHouseholderQR`是"稳健最小二乘"。不知道输啥就上 ColPiv。
