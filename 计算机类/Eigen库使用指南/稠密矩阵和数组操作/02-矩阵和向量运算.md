# 转置和共轭
复习一下代数学：
## 代数基础
### 1. 转置 (Transpose)
对于一个矩阵 $A = [a_{ij}]$，其转置记为 $A^\top$ 或 $A^T$，定义为将行与列互换：
$$(A^\top)_{ij} = a_{ji}.$$
- **性质**：
  - $(A^\top)^\top = A$
  - $(A + B)^\top = A^\top + B^\top$
  - $(cA)^\top = c A^\top$（$c$ 为标量）
  - $(AB)^\top = B^\top A^\top$

### 2. 共轭 (Conjugate)
对于复数 $z = a + bi$（$a,b\in\mathbb{R}$），其共轭为 $\bar{z} = a - bi$。
对于矩阵 $A$，其共轭 $\overline{A}$ 是对每个元素取共轭：
$$(\overline{A})_{ij} = \overline{a_{ij}}.$$
- **性质**：
  - $\overline{\overline{A}} = A$
  - $\overline{A+B} = \overline{A} + \overline{B}$
  - $\overline{cA} = \bar{c} \overline{A}$
  - $\overline{AB} = \overline{A} \cdot \overline{B}$

### 3. 共轭转置 (Conjugate Transpose / Hermitian Adjoint)
也称厄米共轭，记为 $A^\dagger$ 或 $A^H$：
$$A^\dagger = \overline{A^\top} = (\overline{A})^\top.$$
即先转置再取共轭（或先共轭再转置）。
- **性质**：
  - $(A^\dagger)^\dagger = A$
  - $(A + B)^\dagger = A^\dagger + B^\dagger$
  - $(cA)^\dagger = \bar{c} A^\dagger$
  - $(AB)^\dagger = B^\dagger A^\dagger$

### 4. 特殊矩阵类型
- **实矩阵**：若 $A$ 为实矩阵，则 $\overline{A}=A$，故 $A^\dagger = A^\top$。
- **对称矩阵**：$A^\top = A$。
- **厄米矩阵**：$A^\dagger = A$（类比实对称）。
- **正交矩阵**：$A^\top A = I$（实矩阵，且 $A^{-1}=A^\top$）。
- **酉矩阵**：$A^\dagger A = I$（复矩阵，且 $A^{-1}=A^\dagger$）。

### 5. 内积关系
在复内积空间中，$\langle \mathbf{x}, \mathbf{y} \rangle = \mathbf{x}^\dagger \mathbf{y}$。共轭转置保证了：
$$\langle A\mathbf{x}, \mathbf{y} \rangle = \langle \mathbf{x}, A^\dagger \mathbf{y} \rangle.$$


### 6. 转置、共轭对行列式与迹的影响

- **行列式**：
  $$\det(A^\top) = \det(A),\qquad 
  \det(\overline{A}) = \overline{\det(A)},\qquad 
  \det(A^\dagger) = \overline{\det(A)}.$$

- **迹**：
  $$\operatorname{tr}(A^\top) = \operatorname{tr}(A),\qquad 
  \operatorname{tr}(\overline{A}) = \overline{\operatorname{tr}(A)},\qquad 
  \operatorname{tr}(A^\dagger) = \overline{\operatorname{tr}(A)}.$$

### 7. 特殊矩阵的进一步分类

| 条件               | 实矩阵时名称       | 复矩阵时名称       | 关键性质                         |
|-------------------|-------------------|-------------------|----------------------------------|
| $A^\top = A$    | 对称矩阵          | -                 | 特征值为实数（实对称）           |
| $A^\dagger = A$ | 对称矩阵          | **厄米矩阵**       | 特征值为实数；可酉对角化         |
| $A^\top A = I$  | **正交矩阵**      | -                 | 行/列向量为标准正交基；特征值模长=1 |
| $A^\dagger A = I$| -                | **酉矩阵**         | 保持内积；特征值模长=1           |
| $A A^\dagger = A^\dagger A$ | 正规矩阵（实对称、正交等） | **正规矩阵** | 可酉对角化 |

### 8. 与向量内积和投影的关系

- **内积**（复向量）：
  $$\langle \mathbf{x}, \mathbf{y} \rangle = \mathbf{x}^\dagger \mathbf{y} = \sum_i \overline{x_i} y_i.$$
- **投影算子**：若 $P$ 是正交投影，则 $P^2 = P$ 且 $P^\dagger = P$（厄米且幂等）。
- **最小二乘解**：对于超定方程 $A\mathbf{x} \approx \mathbf{b}$，正规方程为 $A^\dagger A \mathbf{x} = A^\dagger \mathbf{b}$。

### 9. 简单例子

设 $A = \begin{bmatrix} 1 & i \\ 2+3i & 4 \end{bmatrix}$。

- 转置：
  $$A^\top = \begin{bmatrix} 1 & 2+3i \\ i & 4 \end{bmatrix}.$$
- 共轭：
  $$\overline{A} = \begin{bmatrix} 1 & -i \\ 2-3i & 4 \end{bmatrix}.$$
- 共轭转置：
  $$A^\dagger = \overline{A^\top} = \begin{bmatrix} 1 & 2-3i \\ -i & 4 \end{bmatrix}.$$


### 10. 常见注意事项

- 对于实矩阵，共轭转置退化为转置，但复矩阵中两者不同。
- 转置不改变矩阵的秩；共轭也不改变秩。
- 若 $A$ 可逆，则 $(A^\top)^{-1} = (A^{-1})^\top$，$(\overline{A})^{-1} = \overline{A^{-1}}$，$(A^\dagger)^{-1} = (A^{-1})^\dagger$。

# 矩阵乘法
矩阵乘法仍旧使用运算符`*`
```C++
#include <iostream>
#include <Eigen/Dense>

int main() {
  Eigen::Matrix2d mat;
  mat << 1, 2, 3, 4;
  Eigen::Vector2d u(-1, 1), v(2, 0);
  std::cout << "Here is mat*mat:\n" << mat * mat << std::endl;
  std::cout << "Here is mat*u:\n" << mat * u << std::endl;
  std::cout << "Here is u^T*mat:\n" << u.transpose() * mat << std::endl;
  std::cout << "Here is u^T*v:\n" << u.transpose() * v << std::endl;
  std::cout << "Here is u*v^T:\n" << u * v.transpose() << std::endl;

  mat = mat * mat;
  std::cout << "Now mat is mat:\n" << mat << std::endl;
}
```

# 点积和叉积
## 代数学基础

在向量代数中，**点积**（内积）和**叉积**（向量积）是两种基本的二元运算，分别用于度量向量的夹角、投影以及生成垂直向量等。

---

### 1. 点积 (Dot Product / Inner Product)

#### 定义
对于 $\mathbb{R}^n$ 中的两个向量 $\mathbf{a} = (a_1, a_2, \dots, a_n)$ 和 $\mathbf{b} = (b_1, b_2, \dots, b_n)$，其点积定义为：
$$\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^n a_i b_i = a_1 b_1 + a_2 b_2 + \cdots + a_n b_n.$$

在 $\mathbb{C}^n$ 中，常用厄米内积：$\langle \mathbf{a}, \mathbf{b} \rangle = \sum_{i=1}^n \overline{a_i} b_i$，但实点积即为此特例。

#### 几何意义
$$\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \, \|\mathbf{b}\| \cos \theta,$$
其中 $\theta$ 为两向量之间的夹角，$\|\mathbf{a}\| = \sqrt{\mathbf{a} \cdot \mathbf{a}}$ 为模长。

- 若 $\mathbf{a} \cdot \mathbf{b} = 0$，则 $\mathbf{a} \perp \mathbf{b}$（正交）。
- 若 $\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \|\mathbf{b}\|$，则同向；若为负值，则夹角为钝角。

#### 代数性质
对任意向量 $\mathbf{a}, \mathbf{b}, \mathbf{c}$ 及标量 $k$：
1. 对称性：$\mathbf{a} \cdot \mathbf{b} = \mathbf{b} \cdot \mathbf{a}$。
2. 线性：$(k\mathbf{a}) \cdot \mathbf{b} = k(\mathbf{a} \cdot \mathbf{b})$，$(\mathbf{a}+\mathbf{b})\cdot \mathbf{c} = \mathbf{a}\cdot \mathbf{c} + \mathbf{b}\cdot \mathbf{c}$。
3. 正定性：$\mathbf{a} \cdot \mathbf{a} \ge 0$，且等号成立当且仅当 $\mathbf{a} = \mathbf{0}$。

#### 坐标计算示例
$\mathbf{a} = (1,2,3),\; \mathbf{b} = (4,5,6)$，则
$$\mathbf{a}\cdot \mathbf{b} = 1\cdot4 + 2\cdot5 + 3\cdot6 = 4+10+18 = 32.$$

#### 应用
- 计算向量长度：$\|\mathbf{a}\| = \sqrt{\mathbf{a}\cdot \mathbf{a}}$。
- 求投影：$\mathbf{a}$ 在 $\mathbf{b}$ 上的标量投影为 $\dfrac{\mathbf{a}\cdot \mathbf{b}}{\|\mathbf{b}\|}$，向量投影为 $\dfrac{\mathbf{a}\cdot \mathbf{b}}{\|\mathbf{b}\|^2}\,\mathbf{b}$。
- 判断正交性、计算夹角。

---

### 2. 叉积 (Cross Product / Vector Product)

##### 定义（仅限 $\mathbb{R}^3$）
对于 $\mathbb{R}^3$ 中两个向量 $\mathbf{a} = (a_1, a_2, a_3)$ 和 $\mathbf{b} = (b_1, b_2, b_3)$，其叉积 $\mathbf{a} \times \mathbf{b}$ 是一个向量：
$$\mathbf{a} \times \mathbf{b} = 
\begin{vmatrix}
\mathbf{i} & \mathbf{j} & \mathbf{k} \\
a_1 & a_2 & a_3 \\
b_1 & b_2 & b_3
\end{vmatrix}
= (a_2 b_3 - a_3 b_2,\; a_3 b_1 - a_1 b_3,\; a_1 b_2 - a_2 b_1).$$
也可用排列符号写出：$(\mathbf{a}\times\mathbf{b})_i = \sum_{j,k} \varepsilon_{ijk} a_j b_k$。

#### 几何意义
- 方向：垂直于 $\mathbf{a}$ 和 $\mathbf{b}$ 所张成的平面，由右手定则确定（$\mathbf{a}$ 转向 $\mathbf{b}$，拇指方向）。
- 模长：$\|\mathbf{a}\times \mathbf{b}\| = \|\mathbf{a}\| \, \|\mathbf{b}\| \sin \theta$，其中 $\theta$ 为 $\mathbf{a},\mathbf{b}$ 夹角 $(0\le\theta\le\pi)$。
- 几何上，该模长等于以 $\mathbf{a},\mathbf{b}$ 为边的平行四边形的面积。

#### 代数性质
1. 反交换性：$\mathbf{a}\times \mathbf{b} = -\,\mathbf{b}\times \mathbf{a}$。
2. 线性：$(k\mathbf{a})\times \mathbf{b} = k(\mathbf{a}\times \mathbf{b}) = \mathbf{a}\times(k\mathbf{b})$，$(\mathbf{a}+\mathbf{b})\times \mathbf{c} = \mathbf{a}\times\mathbf{c} + \mathbf{b}\times\mathbf{c}$。
3. 不满足结合律，但满足**雅可比恒等式**：
   $\mathbf{a}\times(\mathbf{b}\times\mathbf{c}) + \mathbf{b}\times(\mathbf{c}\times\mathbf{a}) + \mathbf{c}\times(\mathbf{a}\times\mathbf{b}) = 0$。
4. 与点积的关系（标量三重积）：
   $$\mathbf{a}\cdot(\mathbf{b}\times\mathbf{c}) = \mathbf{b}\cdot(\mathbf{c}\times\mathbf{a}) = \mathbf{c}\cdot(\mathbf{a}\times\mathbf{b}) = \det([\mathbf{a}\;\mathbf{b}\;\mathbf{c}]).$$
   其绝对值等于三向量张成的平行六面体体积。
5. 向量三重积：
   $$\mathbf{a}\times(\mathbf{b}\times\mathbf{c}) = (\mathbf{a}\cdot\mathbf{c})\mathbf{b} - (\mathbf{a}\cdot\mathbf{b})\mathbf{c}.$$

#### 坐标计算示例
$\mathbf{a} = (1,2,3),\; \mathbf{b} = (4,5,6)$：
$$\mathbf{a}\times\mathbf{b} = (2\cdot6 - 3\cdot5,\; 3\cdot4 - 1\cdot6,\; 1\cdot5 - 2\cdot4) = (12-15,\;12-6,\;5-8) = (-3,\;6,\;-3).$$

验证 $\mathbf{a}\cdot(\mathbf{a}\times\mathbf{b}) = 1\cdot(-3)+2\cdot6+3\cdot(-3) = -3+12-9=0$，垂直成立。

#### 应用
- 求法向量：平面由两个不共线向量张成时，法向量为 $\mathbf{a}\times\mathbf{b}$。
- 计算力矩：$\boldsymbol{\tau} = \mathbf{r}\times\mathbf{F}$。
- 计算角动量：$\mathbf{L} = \mathbf{r}\times\mathbf{p}$。

---

### 3. 点积与叉积的比较

| 特性           | 点积 ($\cdot$)                | 叉积 ($\times$)                 |
|----------------|-------------------------------|---------------------------------|
| 输入维度       | $\mathbb{R}^n$（任意 $n$）     | $\mathbb{R}^3$（仅三维）         |
| 输出           | 标量                          | 向量                            |
| 交换性         | 对称：$\mathbf{a}\cdot\mathbf{b}=\mathbf{b}\cdot\mathbf{a}$ | 反对称：$\mathbf{a}\times\mathbf{b}=-\mathbf{b}\times\mathbf{a}$ |
| 几何意义       | 投影，夹角余弦                | 垂直向量，平行四边形面积        |
| 零条件         | 正交时为零                    | 平行时为零（$\sin\theta=0$）     |
| 与自身运算     | $\mathbf{a}\cdot\mathbf{a}=\|\mathbf{a}\|^2$ | $\mathbf{a}\times\mathbf{a}=0$ |

---

### 4. 推广：高维的外积

在 $\mathbb{R}^n$ 中，叉积是一般外积（楔积）的特例。两个向量的外积 $\mathbf{a}\wedge\mathbf{b}$ 是一个二阶反对称张量，其分量 $(\mathbf{a}\wedge\mathbf{b})_{ij}=a_i b_j - a_j b_i$。在三维中，该张量通过对偶映射等价于叉积向量。

---

# 基本算术规约运算（ Basic arithmetic reduction operations）

`Eigen`还提供了一些简化操作，可以将给定的矩阵或向量简化为单个值，例如所有系数的和（由 sum ()计算）、积（prod()）或最大值（maxCoeff()）和最小值（minCoeff())。
```C++
#include <iostream>
#include <Eigen/Dense>

使用命名空间std；
int main() {
  Eigen::Matrix2d mat;
  mat << 1, 2, 3, 4;
  cout << "这里是 mat.sum(): " << mat.sum() << endl;
  cout << "这里是 mat.prod(): " << mat.prod() << endl;
  cout << "这里是 mat.mean(): " << mat.mean() << endl;
  cout << "这里是 mat.minCoeff(): " << mat.minCoeff() << endl;
  cout << "这里是 mat.maxCoeff(): " << mat.maxCoeff() << endl;
  cout << "这里是 mat.trace(): " << mat.trace() << endl;
}
```

```cmd
mat.mean() 的值：2.5；

```
