# 逗号初始化器

> **前置**：[[04-块操作|转置]] | **后续**：[[06-切片和索引操作|切片与索引]]

Eigen提供了一种逗号初始化语法，使用户能够轻松设置矩阵、向量或数组的所有系数。只需从左上角开始，从左到右、从上到下列出系数即可。对象的大小需要预先指定。如果列出的系数过少或过多，Eigen将会报错。

```C++
Matrix3f m；
m << 1, 2, 3, 4, 5, 6, 7, 8, 9;
std::cout << m;
```

```cmd
Matrix3f m；
m << 1, 2, 3, 4, 5, 6, 7, 8, 9;
std::cout << m;
```
此外，初始化列表的元素本身可以是向量或矩阵。一个常见的用途是将向量或矩阵连接起来。例如，以下是如何连接两个行向量。请记住，在使用逗号初始化器之前，必须先设置列表的大小。
```C++
RowVectorXd vec1(3);
vec1 << 1, 2, 3;
std::cout << "vec1 = " << vec1 << std::endl;

RowVectorXd vec2(4);
vec2 << 1, 4, 9, 16;
std::cout << "vec2 = " << vec2 << std::endl;

RowVectorXd joined(7);
joined << vec1, vec2;
std::cout << "joined = " << joined << std::endl;
```
```cmd
vec1 = 1 2 3
vec2 =  1  4  9 16
joined =  1  2  3  1  4  9 16
```


```C++
MatrixXf matA(2, 2);
matA << 1, 2, 3, 4;
MatrixXf matB(4, 4);
matB << matA, matA / 10, matA / 10, matA;
std::cout << matB << std::endl;
```

```cmd
  1   2 0.1 0.2
  3   4 0.3 0.4
0.1 0.2   1   2
0.3 0.4   3   4
```

```C++
Matrix3f m;
m.row(0) << 1, 2, 3;
m.block(1, 0, 2, 2) << 4, 5, 7, 8;
m.col(2).tail(2) << 6, 9;
std::cout << m;
```
```cmd
1 2 3
4 5 6
7 8 9
```
# 特殊矩阵与数组

`Matrix` 和 `Array` 类提供了多种静态方法，用于生成特殊矩阵/数组。

### Zero() —— 零矩阵/数组

`Zero()` 将全部系数初始化为零，有三种重载形式：

| 形式 | 适用对象 | 示例 |
|------|----------|------|
| `Zero()` | 固定大小对象 | `Array33f::Zero()` |
| `Zero(n)` | 一维动态大小对象 | `ArrayXf::Zero(3)` |
| `Zero(n, m)` | 二维动态大小对象 | `ArrayXXf::Zero(3, 4)` |

```cpp
// 固定大小数组
Array33f a1 = Array33f::Zero();
std::cout << a1 << "\n\n";
// 输出：
// 0 0 0
// 0 0 0
// 0 0 0

// 一维动态数组
ArrayXf a2 = ArrayXf::Zero(3);
std::cout << a2 << "\n\n";
// 输出：0 0 0

// 二维动态数组
ArrayXXf a3 = ArrayXXf::Zero(3, 4);
std::cout << a3 << "\n";
// 输出：3x4 的全零矩阵
```


### Constant(value) —— 常数矩阵/数组

`Constant(value)` 将所有系数设为指定的常数值。若需要指定大小，额外参数放在 value 之前：

```cpp
// 固定大小
Matrix3f m = Matrix3f::Constant(2.5);

// 动态大小：Constant(rows, cols, value)
MatrixXd m2 = MatrixXd::Constant(3, 4, 1.2);
```

### Random() —— 随机矩阵/数组

`Random()` 用随机系数填充矩阵或数组：

```cpp
MatrixXd m = MatrixXd::Random(3, 3);
```

### Identity() —— 单位矩阵

`Identity()` 生成单位矩阵。**注意**：此方法仅适用于 `Matrix`，不适用于 `Array`，因为"单位矩阵"是线性代数概念。

```cpp
Matrix3d I = Matrix3d::Identity();
MatrixXd Id = MatrixXd::Identity(4, 4);  // 4x4 单位矩阵
```

### LinSpaced(size, low, high) —— 等间距向量

`LinSpaced()` 仅适用于向量和一维数组，生成从 `low` 到 `high` 等间距分布的 `size` 个元素的向量。

```cpp
// 生成 10 个从 0 到 90 等间距的值
ArrayXf angles = ArrayXf::LinSpaced(10, 0, 90);

// 示例：打印角度、弧度、正弦、余弦表
ArrayXXf table(10, 4);
table.col(0) = ArrayXf::LinSpaced(10, 0, 90);
table.col(1) = EIGEN_PI / 180 * table.col(0);
table.col(2) = table.col(1).sin();
table.col(3) = table.col(1).cos();
std::cout << " Degrees   Radians   Sine   Cosine\n";
std::cout << table << std::endl;
```


### setXxx() —— 就地设置

Eigen 还提供了 `setZero()`、`setIdentity()` 和 `setLinSpaced()` 等就地设置方法，可以直接修改已有对象的内容。

以下是三种构建分块矩阵$J = \begin{bmatrix} O & I \\ I & O \end{bmatrix}$的对比方法：

```cpp
const int size = 6;

// 方法一：静态方法 + 赋值
MatrixXd mat1(size, size);
mat1.topLeftCorner(size/2, size/2) = MatrixXd::Zero(size/2, size/2);
mat1.topRightCorner(size/2, size/2) = MatrixXd::Identity(size/2, size/2);
mat1.bottomLeftCorner(size/2, size/2) = MatrixXd::Identity(size/2, size/2);
mat1.bottomRightCorner(size/2, size/2) = MatrixXd::Zero(size/2, size/2);

// 方法二：setXxx() 方法（更简洁）
MatrixXd mat2(size, size);
mat2.topLeftCorner(size/2, size/2).setZero();
mat2.topRightCorner(size/2, size/2).setIdentity();
mat2.bottomLeftCorner(size/2, size/2).setIdentity();
mat2.bottomRightCorner(size/2, size/2).setZero();

// 方法三：逗号初始化器
MatrixXd mat3(size, size);
mat3 << MatrixXd::Zero(size/2, size/2),
        MatrixXd::Identity(size/2, size/2),
        MatrixXd::Identity(size/2, size/2),
        MatrixXd::Zero(size/2, size/2);
```

## 作为临时对象使用

静态方法（如 `Zero()`、`Constant()`）返回的是**表达式对象**，在实际使用时才会求值，因此**不会产生额外的运行时开销**。

### 在表达式中使用

```cpp
MatrixXd m = MatrixXd::Random(3, 3);
m = (m + MatrixXd::Constant(3, 3, 1.2)) * 50;
```


这里 `MatrixXd::Constant(3, 3, 1.2)` 创建了一个临时对象，直接参与矩阵运算。

### 逗号初始化器构造临时矩阵

逗号初始化器也可用于构造临时对象，但需要调用 `.finished()` 来获取最终的矩阵对象：

```cpp
MatrixXf mat = MatrixXf::Random(2, 3);
// 用逗号初始化器构造临时 2x2 矩阵，左乘 mat
mat = (MatrixXf(2, 2) << 0, 1, 1, 0).finished() * mat;
```


这里的 `finished()` 是必需的，它表示逗号初始化已完成，返回构造好的矩阵对象。
