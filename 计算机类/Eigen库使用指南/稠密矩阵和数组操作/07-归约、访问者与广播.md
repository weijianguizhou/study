本章节介绍 Eigen 的归约（Reductions）、访问者（Visitors）和广播（Broadcasting）功能。
# 归约（Reductions）

> **前置**：[[06-切片和索引操作|切片索引]] | **返回**：[[01-Matrix类|Matrix/Array 基础]]
在 Eigen 中，**归约**是指接收一个矩阵或数组，并返回一个**单一标量值**的函数。
## 基本归约操作

| 方法            | 说明            |
| ------------- | ------------- |
| `.sum()`      | 所有系数的总和       |
| `.prod()`     | 所有系数的乘积       |
| `.mean()`     | 所有系数的平均值      |
| `.minCoeff()` | 所有系数中的最小值     |
| `.maxCoeff()` | 所有系数中的最大值     |
| `.trace()`    | 矩阵的迹（对角线系数之和） |

```cpp
#include <iostream>
#include <Eigen/Dense>
using namespace std;

int main() {
    Matrix2d mat;
    mat << 1, 2,
           3, 4;
    cout << "Here is mat.sum(): " << mat.sum() << endl;
    cout << "Here is mat.prod(): " << mat.prod() << endl;
    cout << "Here is mat.mean(): " << mat.mean() << endl;
    cout << "Here is mat.minCoeff(): " << mat.minCoeff() << endl;
    cout << "Here is mat.maxCoeff(): " << mat.maxCoeff() << endl;
    cout << "Here is mat.trace(): " << mat.trace() << endl;
}
```
```cmd
Here is mat.sum(): 10
Here is mat.prod(): 24
Here is mat.mean(): 2.5
Here is mat.minCoeff(): 1
Here is mat.maxCoeff(): 4
Here is mat.trace(): 5
```

>  `trace()` 等价于 `mat.diagonal().sum()`。

## 范数计算

| 方法 | 说明 |
|------|------|
| `.squaredNorm()` | 欧几里得（ℓ²）范数的平方 |
| `.norm()` | 欧几里得（ℓ²）范数（`squaredNorm` 的平方根） |
| `.lpNorm<p>()` | 系数向量的 ℓᵖ 范数 |

对于**矩阵**，`norm()` 返回的是 **Frobenius 范数**（或称 Hilbert-Schmidt 范数）。`lpNorm<Infinity>()` 返回 ℓ^∞ 范数，即系数绝对值的最大值。

```cpp
#include <iostream>
#include <Eigen/Dense>

int main() {
    VectorXf v(2);
    MatrixXf m(2, 2), n(2, 2);
    v << -1, 2;
    m << 1, -2,
         -3, 4;

    std::cout << "v.squaredNorm() = " << v.squaredNorm() << std::endl;
    std::cout << "v.norm() = " << v.norm() << std::endl;
    std::cout << "v.lpNorm<1>() = " << v.lpNorm<1>() << std::endl;
    std::cout << "v.lpNorm<Infinity>() = " << v.lpNorm<Eigen::Infinity>() << std::endl;

    std::cout << std::endl;

    std::cout << "m.squaredNorm() = " << m.squaredNorm() << std::endl;
    std::cout << "m.norm() = " << m.norm() << std::endl;
    std::cout << "m.lpNorm<1>() = " << m.lpNorm<1>() << std::endl;
    std::cout << "m.lpNorm<Infinity>() = " << m.lpNorm<Eigen::Infinity>() << std::endl;
}
```
```cmd
v.squaredNorm() = 5
v.norm() = 2.23607
v.lpNorm<1>() = 3
v.lpNorm<Infinity>() = 2

m.squaredNorm() = 30
m.norm() = 5.47723
m.lpNorm<1>() = 10
m.lpNorm<Infinity>() = 4
```

## 算子范数（Operator Norms）

矩阵的 **1-范数**（最大列绝对值和）和 **∞-范数**（最大行绝对值和）可以这样计算：

```cpp
#include <iostream>
#include <Eigen/Dense>

int main() {
    MatrixXf m(2, 2);
    m << 1, -2,
         -3, 4;

    std::cout << "1-norm(m) = " << m.cwiseAbs().colwise().sum().maxCoeff()
              << " == " << m.colwise().lpNorm<1>().maxCoeff() << std::endl;
    std::cout << "infty-norm(m) = " << m.cwiseAbs().rowwise().sum().maxCoeff()
              << " == " << m.rowwise().lpNorm<1>().maxCoeff() << std::endl;
}
```
```cmd
1-norm(m) = 6 == 6
infty-norm(m) = 7 == 7
```

## 布尔归约（Boolean Reductions）

| 方法 | 说明 |
|------|------|
| `.all()` | 所有系数均为 `true` 时返回 `true` |
| `.any()` | 至少有一个系数为 `true` 时返回 `true` |
| `.count()` | 返回 `true` 的系数个数 |

这些方法通常与系数比较操作结合使用：

```cpp
#include <iostream>
#include <Eigen/Dense>

int main() {
    Eigen::ArrayXXf a(2, 2);
    a << 1, 2,
         3, 4;

    std::cout << "(a > 0).all() = " << (a > 0).all() << std::endl;
    std::cout << "(a > 0).any() = " << (a > 0).any() << std::endl;
    std::cout << "(a > 0).count() = " << (a > 0).count() << std::endl;

    std::cout << std::endl;

    std::cout << "(a > 2).all() = " << (a > 2).all() << std::endl;
    std::cout << "(a > 2).any() = " << (a > 2).any() << std::endl;
    std::cout << "(a > 2).count() = " << (a > 2).count() << std::endl;
}
```
```cmd
(a > 0).all() = 1
(a > 0).any() = 1
(a > 0).count() = 4

(a > 2).all() = 0
(a > 2).any() = 1
(a > 2).count() = 2
```


# 访问者（Visitors）

访问者用于获取矩阵或数组中**某个系数所在的位置**（行索引和列索引）。

- `maxCoeff(&row, &col)`：返回最大值及其位置
- `minCoeff(&row, &col)`：返回最小值及其位置

位置参数的类型应为 `Eigen::Index`。

```cpp
#include <iostream>
#include <Eigen/Dense>

int main() {
    Eigen::MatrixXf m(2, 2);
    m << 1, 2,
         3, 4;

    // 获取最大值位置
    Eigen::Index maxRow, maxCol;
    float max = m.maxCoeff(&maxRow, &maxCol);

    // 获取最小值位置
    Eigen::Index minRow, minCol;
    float min = m.minCoeff(&minRow, &minCol);

    std::cout << "Max: " << max << ", at: " << maxRow << "," << maxCol << std::endl;
    std::cout << "Min: " << min << ", at: " << minRow << "," << minCol << std::endl;
}
```
```cmd
Max: 4, at: 1,1
Min: 1, at: 0,0
```


# 部分归约（Partial Reductions）

部分归约可以对矩阵或数组**按列**或**按行**进行操作。

- `.colwise()`：对每一列分别进行归约，返回**行向量**
- `.rowwise()`：对每一行分别进行归约，返回**列向量**

```cpp
#include <iostream>
#include <Eigen/Dense>
using namespace std;

int main() {
    MatrixXf mat(2, 4);
    mat << 1, 2, 6, 9,
           3, 1, 7, 2;

    std::cout << "Column's maximum: " << std::endl
              << mat.colwise().maxCoeff() << std::endl;
}
```
```cmd
Column's maximum: 
3 2 7 9
```

按行操作：
```cpp
std::cout << "Row's maximum: " << std::endl
          << mat.rowwise().maxCoeff() << std::endl;
```
```cmd
Row's maximum: 
9
7
```

## 部分归约与其他操作结合

以下示例找到**列元素之和最大**的那一列：

```cpp
#include <iostream>
#include <Eigen/Dense>

int main() {
    Eigen::MatrixXf mat(2, 4);
    mat << 1, 2, 6, 9,
           3, 1, 7, 2;

    Eigen::Index maxIndex;
    float maxNorm = mat.colwise().sum().maxCoeff(&maxIndex);

    std::cout << "Maximum sum at position " << maxIndex << std::endl;
    std::cout << "The corresponding vector is: " << std::endl;
    std::cout << mat.col(maxIndex) << std::endl;
    std::cout << "And its sum is: " << maxNorm << std::endl;
}
```
```cmd
Maximum sum at position 2
The corresponding vector is: 
6
7
And its sum is: 13
```

数学上，若

$m = \begin{bmatrix} 1 & 2 & 6 & 9 \\ 3 & 1 & 7 & 2 \end{bmatrix}$

则

$m.colwise().sum() = \begin{bmatrix} 4 & 3 & 13 & 11 \end{bmatrix}$

最大值为 13，位于第 2 列（索引 2）。


# 广播（Broadcasting）

广播的概念与部分归约类似，但方向相反：它将一个**向量**通过**复制**扩展成一个矩阵。

#### 列方向广播

将一个列向量**加到每一列**上：

```cpp
#include <iostream>
#include <Eigen/Dense>
using namespace std;

int main() {
    MatrixXf mat(2, 4);
    mat << 1, 2, 6, 9,
           3, 1, 7, 2;

    VectorXf v(2);
    v << 0, 1;

    // 将 v 加到 mat 的每一列
    mat.colwise() += v;

    std::cout << "Broadcasting result: " << std::endl;
    std::cout << mat << std::endl;
}
```
```cmd
Broadcasting result: 
1 2 6 9
4 2 8 3
```

等价于：

$\begin{bmatrix} 1 & 2 & 6 & 9 \\ 3 & 1 & 7 & 2 \end{bmatrix}+\begin{bmatrix} 0 & 0 & 0 & 0 \\ 1 & 1 & 1 & 1 \end{bmatrix}=\begin{bmatrix} 1 & 2 & 6 & 9 \\ 4 & 2 & 8 & 3 \end{bmatrix}$



## 行方向广播

将一个行向量**加到每一行**上：

```cpp
#include <iostream>
#include <Eigen/Dense>
using namespace std;

int main() {
    MatrixXf mat(2, 4);
    mat << 1, 2, 6, 9,
           3, 1, 7, 2;

    VectorXf v(4);
    v << 0, 1, 2, 3;

    // 将 v 转置后加到 mat 的每一行
    mat.rowwise() += v.transpose();

    std::cout << "Broadcasting result: " << std::endl;
    std::cout << mat << std::endl;
}
```
```cmd
Broadcasting result: 
1 3 8 12
3 2 9 5
```

>  **重要限制**：
> - 列方向/行方向运算的向量必须是 `Vector` 类型（如 `VectorXf`），不能是 `Matrix`
> - 对于 `Array`，对应类型是 `ArrayXf`
> - 矩阵和数组**不应混用**在同一表达式中
> - 对于 `Array`，还可以使用 `*=`、`/=` 等进行逐元素乘除；矩阵不支持这些操作

## 广播与其他操作结合：寻找最近邻

以下示例在矩阵 `m` 的各列中，找到与向量 `v` **欧几里得距离最近**的列：

```cpp
#include <iostream>
#include <Eigen/Dense>

int main() {
    Eigen::MatrixXf m(2, 4);
    m << 1, 23, 6, 9,
         3, 11, 7, 2;

    Eigen::VectorXf v(2);
    v << 2, 3;

    Eigen::Index index;
    (m.colwise() - v).colwise().squaredNorm().minCoeff(&index);

    std::cout << "Nearest neighbour is column " << index << ":" << std::endl;
    std::cout << m.col(index) << std::endl;
}
```
```cmd
Nearest neighbour is column 0:
1
3
```

**逐步解析**：

1. `m.colwise() - v`：广播操作，将 `v` 从 `m` 的每一列中减去

   $m.colwise() - v = \begin{bmatrix} -1 & 21 & 4 & 7 \\ 0 & 8 & 4 & -1 \end{bmatrix}$


2. `.colwise().squaredNorm()`：部分归约，计算每列的平方范数
   $(m.colwise() - v).colwise().squaredNorm() = \begin{bmatrix} 1 & 505 & 32 & 50 \end{bmatrix}$


3. `.minCoeff(&index)`：找到最小值的索引（列 0），即最近邻
