`Eigen`数组类(Array class),和`C++`中的数组类相比，更加普遍，目的是进行线性运算。此外，数组类还提供了一种简便的方法来执行系数级运算，这些运算可能不具有线性代数意义，例如将一个常数加到数组中的每个系数上，或者将两个数组的系数相乘。

# 数组类

> **前置**：[[02-矩阵和向量运算|矩阵运算]] | **后续**：[[04-块操作|转置]]
`Array`同样是一个类模板。它接受与`Matrix`相同的模板参数。与`Matrix`相同，前三个参数是必要的：
```C++
Array<typename Scalar, int RowsAtCompileTime, int ColsAtCompileTime>
```
数组通常是一维或二维的，所以我们会约定一些类型，如下：

| 类型                               | `Typedef`   |
| -------------------------------- | ----------- |
| `Array<float,Dynamic,1>`         | `ArrayXf `  |
| `Array<float,3,1> `              | `Array3f `  |
| `Array<double,Dynamic,Dynamic> ` | `ArrayXXd ` |
| `Array<double,3,3> `             | `Array33d ` |

# 访问数组中的值
括号运算符被重载，可以像操作矩阵一样对数组的系数进行读写访问。此外， `<<` 运算符可用于初始化数组（通过逗号初始化器）或打印数组。
```C++
#include <Eigen/Dense>
#include <iostream>

int main() {
  Eigen::ArrayXXf m(2, 2);

  // assign some values coefficient by coefficient
  m(0, 0) = 1.0;
  m(0, 1) = 2.0;
  m(1, 0) = 3.0;
  m(1, 1) = m(0, 1) + m(1, 0);

  // print values to standard output
  std::cout << m << std::endl << std::endl;

  // using the comma-initializer is also allowed
  m << 1.0, 2.0, 3.0, 4.0;

  // print values to standard output
  std::cout << m << std::endl;
}
```
# 加减和乘法运算
通过重载运算符`+,-,*`来实现
```C++
#include <Eigen/Dense>
#include <iostream>

int main() {
  Eigen::ArrayXXf a(3, 3);
  Eigen::ArrayXXf b(3, 3);
  a << 1, 2, 3, 4, 5, 6, 7, 8, 9;
  b << 1, 2, 3, 1, 2, 3, 1, 2, 3;

  // Adding two arrays
  std::cout << "a + b = " << std::endl << a + b << std::endl << std::endl;

  // Subtracting a scalar from an array
  std::cout << "a - 2 = " << std::endl << a - 2 << std::endl;
}
```

```C++
#include <Eigen/Dense>
#include <iostream>

int main() {
  Eigen::ArrayXXf a(2, 2);
  Eigen::ArrayXXf b(2, 2);
  a << 1, 2, 3, 4;
  b << 5, 6, 7, 8;
  std::cout << "a * b = " << std::endl << a * b << std::endl;
}
```
# 其他系数运算

| 运算函数      | 作用                                 |
| --------- | ---------------------------------- |
| `.sqrt()` | 对数组中的每一个系数进行开方                     |
| `.abs()`  | 对数组中的每一个系数取绝对值                     |
| `.abs()`  | 给定两个相同大小的数组，可以重构出一个两个数组对应系数取最小值的数组 |
```C++
#include <Eigen/Dense>
#include <iostream>

int main() {
  Eigen::ArrayXf a = Eigen::ArrayXf::Random(5);
  a *= 2;
  std::cout << "a =" << std::endl << a << std::endl;
  std::cout << "a.abs() =" << std::endl << a.abs() << std::endl;
  std::cout << "a.abs().sqrt() =" << std::endl << a.abs().sqrt() << std::endl;
  std::cout << "a.min(a.abs().sqrt()) =" << std::endl << a.min(a.abs().sqrt()) << std::endl;
}

```
# 数组表达式和矩阵表达式之间的转换
运算不能直接应用于数组，数组运算也不能直接应用于矩阵。因此，如果需要进行线性代数运算（例如矩阵乘法），则应该使用矩阵；如果需要进行系数运算，则应该使用数组。然而，有时情况并非如此简单，可能需要同时使用矩阵运算和数组运算。在这种情况下，需要将矩阵转换为数组，反之亦然。这样，无论对象声明为数组还是矩阵，都可以访问所有运算。

矩阵表达式有一个`.array()`方法，可以将其“转换”为数组表达式，从而方便地进行系数运算。反之，数组表达式也有一个`.matrix()`方法。与所有Eigen表达式抽象一样，这不会产生任何运行时开销。`.array ()`和`.matrix()`都可以用作右值和左值。

在Eigen中，表达式中混合使用矩阵和数组是不允许的。例如，你不能直接将矩阵和数组相加；运算符的操作数要么都是矩阵，要么都是数组。不过，使用`.array()`和`.matrix()` `+`可以轻松地在两者之间进行转换。这条规则的例外是赋值运算符：允许将矩阵表达式赋值给数组变量，也允许将数组表达式赋值给矩阵变量。
以下示例展示了如何使用`.array()`方法对Matrix对象进行数组运算。例如，该语句接受两个矩阵 A和B，将它们都转换为数组，使用 .array() 方法将它们按系数相乘，并将结果赋值给矩阵变量 A （这是合法的，因为Eigen允许将数组表达式赋值给矩阵变量）。

`result = m.array() * n.array()``m``n``result`

事实上，这种用法非常常见，以至于Eigen提供了一个`const .cwiseProduct(.)`方法来计算矩阵的系数乘积。示例程序中也对此进行了演示。

```C++
#include <Eigen/Dense>
#include <iostream>

使用Eigen::MatrixXf；

int main() {
  MatrixXf m(2, 2);
  MatrixXf n(2, 2);
  MatrixXf result(2, 2);

  m << 1, 2, 3, 4;
  n << 5, 6, 7, 8;

  结果 = m * n；
  std::cout << "-- 矩阵 m*n: --\n" << result << "\n\n" ;
  result = m.array() * n.array();
  std::cout << "-- 数组 m*n: --\n" << result << "\n\n" ;
  result = m.cwiseProduct(n);
  std::cout << "-- 使用 cwiseProduct: --\n" << result << "\n\n" ;
  result = m.array() + 4;
  std::cout << "-- 数组 m + 4: --\n" << result << "\n\n" ;
}
```

类似地，如果`array1`和`array2`是数组，则该表达式`array1.matrix() * array2.matrix()`计算它们的矩阵乘积。

以下是一个更高级的例子。该表达式`(m.array() + 4).matrix() * m`将矩阵中的每个系数加 4 `m`，然后计算结果与矩阵的乘积`m`。类似地，该表达式计算矩阵和`(m.array() * n.array()).matrix() * m`的系数乘积，然后计算结果与矩阵的乘积。

```C++
#include <Eigen/Dense>
#include <iostream>

using Eigen::MatrixXf;

int main() {
  MatrixXf m(2, 2);
  MatrixXf n(2, 2);
  MatrixXf result(2, 2);

  m << 1, 2, 3, 4;
  n << 5, 6, 7, 8;

  result = (m.array() + 4).matrix() * m;
  std::cout << "-- Combination 1: --\n" << result << "\n\n";
  result = (m.array() * n.array()).matrix() * m;
  std::cout << "-- Combination 2: --\n" << result << "\n\n";
}
```
