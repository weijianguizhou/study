# 旋转的表达

做机器人、视觉、SLAM的时候，旋转是最基础的运算。`Eigen`里有**四种**表达旋转的方式，混着用还互转。这篇给你理清楚。

---

# 复习一下代数学

## 旋转的四种数学表达

三维空间的旋转本质只有**3个自由度**（比如绕三个坐标轴各转多少度），但不同表达方式用不同数量的数字来存。

| 表达方式 | 数据量 | 优点 | 缺点 |
|----------|--------|------|------|
| **旋转矩阵** $R_{3\times3}$ | 9个数 | 直接算变换，物理清楚 | 冗余（6个约束：正交+det=1），插值难 |
| **角+轴** (Angle-Axis) | 4个数（1个角+3D轴） | 几何直观——"绕这根棍转多少度" | 复合旋转不方便 |
| **四元数** (Quaternion) | 4个数 | 紧凑、无万向节锁、有Slerp插值 | 不如旋转矩阵直观 |
| **欧拉角** (Euler Angles) | 3个数 | 人类最直观 | **万向节锁**，而且有24种不同约定 |

**Eigen 全支持**。而且它们之间可以互相转换，通过构造器或赋值就行。

一般工程套路：**拿四元数存旋转，要变换向量时转成旋转矩阵，构造旋转时用角+轴**。

## 旋转矩阵该满足啥

一个$3\times3$矩阵$R$是合法的旋转矩阵，必须满足两条：

- $R^T R = I$（正交——列向量两两正交且长度为1）
- $\det(R) = 1$（不是-1，排除反射）

# AngularAxis — 角+轴

你要绕一根棍转一个角度。这就是`AngleAxis`。构造它的时候只需要两个东西：转多少度，绕着哪个轴。

**那个轴必须是单位向量**（长度为1）。Eigen不会帮你检查。

```C++
#include <iostream>
#include <Eigen/Geometry>

int main() {
    // 绕 Z 轴转 45°
    Eigen::AngleAxisf rot_z(M_PI / 4, Eigen::Vector3f::UnitZ());

    // 绕任意轴（记得归一化！）
    Eigen::Vector3f my_axis(1, 1, 0);
    my_axis.normalize();
    Eigen::AngleAxisf rot_any(M_PI / 3, my_axis);

    // 旋转向量
    Eigen::Vector3f v(1, 0, 0);
    std::cout << "绕Z轴转45°: " << (rot_z * v).transpose() << std::endl;
    std::cout << "绕(1,1,0)转60°: " << (rot_any * v).transpose() << std::endl;

    // 拿角度和轴出来
    std::cout << "角度: " << rot_z.angle() << " rad" << std::endl;
    std::cout << "轴: " << rot_z.axis().transpose() << std::endl;

    // 转成旋转矩阵
    Eigen::Matrix3f R = rot_z.toRotationMatrix();
    std::cout << "旋转矩阵:\n" << R << std::endl;
}
```

```cmd
绕Z轴转45°: 0.707 0.707     0
绕(1,1,0)转60°: 0.5 0.5 -0.707
角度: 0.785398 rad
轴: 0 0 1
旋转矩阵:
 0.707 -0.707      0
 0.707  0.707      0
     0      0      1
```

# Quaternion — 四元数

## 数学背景

四元数是个古老的数学发明（Hamilton，1843年），形式是$q = w + xi + yj + zk$，其中$i^2=j^2=k^2=ijk=-1$。

单位四元数（$|q|=1$）刚好对应三维空间的一个旋转。其核心公式：

$$q = \cos\left(\frac{\theta}{2}\right) + \sin\left(\frac{\theta}{2}\right)(a_x i + a_y j + a_z k)$$

这个$q$就表示绕轴$\mathbf{a} = (a_x, a_y, a_z)$旋转角度$\theta$。

旋转向量$\mathbf{v}$的公式：$\mathbf{v}' = q \mathbf{v} q^{-1}$（把$\mathbf{v}$看成纯四元数$0 + v_x i + v_y j + v_z k$来算）。

复合旋转直接乘四元数：$q_{total} = q_2 q_1$，意思是先转$q_1$，再转$q_2$。

## 球面线性插值 Slerp

四元数最牛逼的功能：**Slerp**（Spherical Linear Interpolation）。在两个旋转之间平滑过渡，做动画和姿态插值的时候爽到飞起。

## 代码

```C++
#include <iostream>
#include <Eigen/Geometry>

int main() {
    // 从角+轴造一个四元数
    Eigen::Quaternionf q = Eigen::AngleAxisf(M_PI / 4, Eigen::Vector3f::UnitZ());
    std::cout << "四元数 (x,y,z,w): " << q.coeffs().transpose() << std::endl;

    // 直接旋转向量——四元数重载了 * 运算符
    Eigen::Vector3f v(1, 0, 0);
    std::cout << "旋转前: " << v.transpose() << std::endl;
    std::cout << "旋转后: " << (q * v).transpose() << std::endl;

    // 复合两个旋转: q3 = q * q2，先q2后q
    Eigen::Quaternionf q2 = Eigen::AngleAxisf(M_PI / 2, Eigen::Vector3f::UnitX());
    Eigen::Quaternionf q3 = q * q2;
    std::cout << "复合后: " << (q3 * v).transpose() << std::endl;

    // Slerp! 在两个旋转的一半位置
    Eigen::Quaternionf q_mid = q.slerp(0.5, q2);
    std::cout << "一半位置: " << (q_mid * v).transpose() << std::endl;

    // 忘了归一化？补一下
    q.normalize();
}
```

```cmd
四元数 (x,y,z,w): 0 0 0.382683 0.92388
旋转前: 1 0 0
旋转后: 0.707 0.707     0
复合后:  0.707   0.5   0.5
一半位置: 0.8315 0.4375 0.3426
```

**两个大坑**：

1. `q.coeffs()`的顺序是$(x, y, z, w)$，但`Quaternionf(w, x, y, z)`的构造顺序是$(w, x, y, z)$。记混了会debug到哭。

2. 四元数必须保持单位长度。浮点运算累积误差可能让它漂移，时不时`.normalize()`一下。

## 四种表达互转

```C++
Eigen::Matrix3f R;
Eigen::AngleAxisf aa;
Eigen::Quaternionf q;

// 旋转矩阵 → 其他的（通过构造器）
Eigen::Quaternionf q_from_R(R);          // 前提：R 是合法的旋转矩阵
Eigen::AngleAxisf aa_from_R(R);

// 角+轴 → 其他的
Eigen::Quaternionf q_from_aa = aa;
Eigen::Matrix3f R_from_aa = aa.toRotationMatrix();

// 四元数 → 其他的
Eigen::Matrix3f R_from_q = q.toRotationMatrix();
Eigen::AngleAxisf aa_from_q(q);

// 矩阵 ← 四元数（反向）
Eigen::Matrix3f R2 = Eigen::Quaternionf(...).toRotationMatrix();
```

基本上都是隐式转换或构造器，不需要记额外的函数名。

# 欧拉角

欧拉角就是把旋转拆成绕三个轴的依次旋转。问题在于**顺序不同结果完全不同**（一共24种约定），而且有一个臭名昭著的**万向节锁**。

不过日常你需要的可能只是从欧拉角快速构造一个旋转矩阵。Eigen不直接提供"欧拉角→旋转矩阵"的函数，你得手动拼接AngleAxis：

```C++
// 机器人学常用的 ZYX（RPY: Roll-Pitch-Yaw）
float roll  = 0.1;   // 绕 X
float pitch = 0.2;   // 绕 Y
float yaw   = 0.3;   // 绕 Z

// 注意乘的顺序：从右往左读——先绕X，再绕Y，最后绕Z
Eigen::Matrix3f R_zyx = Eigen::AngleAxisf(yaw,   Eigen::Vector3f::UnitZ())
                      * Eigen::AngleAxisf(pitch, Eigen::Vector3f::UnitY())
                      * Eigen::AngleAxisf(roll,  Eigen::Vector3f::UnitX());
```

还有ZYZ顺序（机器人学里另一种常用约定）：

```C++
Eigen::Matrix3f R_zyz = Eigen::AngleAxisf(a1, Eigen::Vector3f::UnitZ())
                      * Eigen::AngleAxisf(a2, Eigen::Vector3f::UnitY())
                      * Eigen::AngleAxisf(a3, Eigen::Vector3f::UnitZ());
```
