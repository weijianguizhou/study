# LU 分解

# 复习一下代数学

## LU分解是啥

给一个方阵$A$，如果能把它写成一个**下三角矩阵$L$**和一个**上三角矩阵$U$**的乘积：

$$A = LU$$

这就是**LU分解**。

为啥这个分解有用？因为三角矩阵的方程求解超级简单。$Ax = b$变成$LUx = b$。先设$y = Ux$，解$Ly = b$（这叫**前代**——从上往下一行行代进去），再解$Ux = y$（这叫**回代**——从下往上一行行代回去）。两步都是$O(n^2)$的事儿。

举个例子：如果
$$L = \begin{pmatrix} 1 & 0 & 0 \\ 2 & 1 & 0 \\ 3 & 4 & 1 \end{pmatrix}, \quad b = \begin{pmatrix} 5 \\ 16 \\ 41 \end{pmatrix}$$

解$Ly = b$：
- 第一行：$1 \cdot y_1 = 5 \implies y_1 = 5$
- 第二行：$2y_1 + y_2 = 16 \implies 10 + y_2 = 16 \implies y_2 = 6$
- 第三行：$3y_1 + 4y_2 + y_3 = 41 \implies 15 + 24 + y_3 = 41 \implies y_3 = 2$

从上往下一行行来，不用解方程组，直接代入就行。这就是前代。

## 选主元

简单的LU分解有个毛病：如果在对角线上出现0（或者非常接近0的数），除法就炸了（或者精度崩了）。解决方法是**选主元**——在每一步消元之前，把当前列里绝对值最大的那一行换到对角位置上来。这叫"部分主元"(Partial Pivoting)。

$$\text{带部分主元的LU：} \quad PA = LU$$

$P$是一个**置换矩阵**（就是单位矩阵换了几行的结果），记录了主元选择时做了哪些行交换。

说白了：$P$把$A$的行重新排了一下，让数值最大的元素站在最关键的位置上，然后对重排后的$PA$做标准LU分解。

# Eigen 里的 PartialPivLU

`PartialPivLU`就是带部分主元的LU分解。在Eigen里，它是**普适方阵求解的首选**——如果你的$A$是个普通可逆方阵，直接用这个。

```C++
#include <iostream>
#include <Eigen/Dense>

int main() {
    Eigen::Matrix3d A;
    A << 2, -1,  0,
        -1,  2, -1,
         0, -1,  2;
    Eigen::Vector3d b(1, 0, 1);

    Eigen::PartialPivLU<Eigen::Matrix3d> lu(A);

    // 解方程
    Eigen::Vector3d x = lu.solve(b);
    std::cout << "解 x: " << x.transpose() << std::endl;

    // 如果非要逆矩阵（不推荐，但偶尔小矩阵方便）
    std::cout << "A的逆:\n" << lu.inverse() << std::endl;

    // 顺便拿个行列式
    std::cout << "det(A) = " << lu.determinant() << std::endl;
}
```

```cmd
解 x: 1.25 1.5 1.25
A的逆:
0.75 0.5 0.25
 0.5   1  0.5
0.25 0.5 0.75
det(A) = 4
```

注意，`PartialPivLU`有`inverse()`和`determinant()`方法，但这是对**小矩阵**方便的。对于大矩阵，**不要调用`inverse()`**——用`solve()`。

# Eigen 里的 FullPivLU

`PartialPivLU`虽然好用，但它假设你的矩阵是**可逆的**。万一矩阵是奇异的呢？万一你想知道矩阵的**秩**是多少呢？这时候`FullPivLU`上场。

`FullPivLU`在行和列两个方向上都做置换：

$$P_1 A P_2 = LU$$

同时做行置换$P_1$和列置换$P_2$。这样无论矩阵多烂都能处理，而且附带一系列的**诊断功能**——秩、零空间、列空间。

```C++
#include <iostream>
#include <Eigen/Dense>

int main() {
    Eigen::Matrix3f A;
    A << 1, 2, 5,
         2, 1, 4,
         3, 0, 3;
    // 注意：第三行 = 第一行 + 第二行，所以秩只有2

    Eigen::FullPivLU<Eigen::Matrix3f> lu(A);

    std::cout << "A的秩: " << lu.rank() << std::endl;
    std::cout << "A可逆吗: " << (lu.isInvertible() ? "是" : "不是") << std::endl;

    // 零空间（核）：Ax = 0 的非零解
    std::cout << "零空间的基:\n" << lu.kernel() << std::endl;

    // 列空间（值域）：A的各列张成的空间
    std::cout << "列空间的基:\n" << lu.image(A) << std::endl;
}
```

```cmd
A的秩: 2
A可逆吗: 不是
零空间的基:
 0.5
   1
-0.5
列空间的基:
5 1
4 2
3 3
```

零空间给出了一个向量$[0.5, 1, -0.5]^T$。验算一下：$1\times0.5 + 2\times1 + 5\times(-0.5) = 0.5 + 2 - 2.5 = 0$，第二行$2\times0.5 + 1\times1 + 4\times(-0.5) = 1 + 1 - 2 = 0$，第三行$3\times0.5 + 0\times1 + 3\times(-0.5) = 1.5 - 1.5 = 0$。全对上了。

**一个小坑**：`lu.image(A)`得把原来的$A$传进去当参数，不能省略。这设计确实别扭，但Eigen就是这么定的，记住就行。

## 阈值：什么叫"非零"

矩阵的秩依赖于一个判断标准——多小的数才算零。浮点运算里几乎不会有精确的零，所以需要设一个**阈值**。

Eigen 默认用"对角大小 $\times$ 机器精度"当阈值，大多数情况下合理。但如果你知道你的数据精度范围不一样，可以自己调：

```C++
Eigen::Matrix2d A;
A << 2, 1,
     2, 0.9999999999;  // 几乎秩亏——两行几乎成比例

Eigen::FullPivLU<Eigen::Matrix2d> lu(A);
std::cout << "默认阈值下的秩: " << lu.rank() << std::endl;  // 2
lu.setThreshold(1e-5);  // 放宽一点
std::cout << "阈值1e-5下的秩: " << lu.rank() << std::endl;  // 1
```

注意：改阈值**不需要重新分解**。`setThreshold()`只影响`rank()`等诊断函数的判断标准，分解本身不变。

# PartialPivLU 和 FullPivLU 怎么选

| 你关心什么 | 用啥 |
|-----------|------|
| 就解个方程，矩阵肯定可逆 | `PartialPivLU`，快 |
| 想知道矩阵的秩 | `FullPivLU` |
| 想分析零空间/列空间 | `FullPivLU` |
| 矩阵可能是奇异的 | `FullPivLU` |
| 矩阵很大（比如 1000×1000）| `PartialPivLU`（快很多）|

说白了，**能 Partial 就 Partial，需要诊断信息才 Full**。
