# 一、ODE求解（Runge-Kutta 4阶）

## 复习一下代数学

### 1. 一阶常微分方程

一阶ODE的标准形式是：

$$\frac{d\mathbf{x}}{dt} = \mathbf{f}(\mathbf{x}, t)$$

给你一个初始状态$\mathbf{x}(t_0)$，想知道$t > t_0$之后$\mathbf{x}(t)$是啥。绝大多数现实问题没有解析解，得上数值方法。

### 2. 欧拉法（最朴素的数值积分）

最简单的想法是：既然$d\mathbf{x}/dt = \mathbf{f}$，那在一个小时间步$\Delta t$里，$\mathbf{x}$的变化量大概就是$\mathbf{f} \cdot \Delta t$：

$$\mathbf{x}_{n+1} = \mathbf{x}_n + \Delta t \cdot \mathbf{f}(\mathbf{x}_n, t_n)$$

这就是**前向欧拉法 (Forward Euler)**。它只用了区间起点的斜率来估计整个区间。

问题出在哪？欧拉法本质上是对真正的解$\mathbf{x}(t)$做了一阶Taylor展开：

$$\mathbf{x}(t_n + \Delta t) = \mathbf{x}(t_n) + \Delta t \cdot \dot{\mathbf{x}}(t_n) + \frac{\Delta t^2}{2}\ddot{\mathbf{x}}(t_n) + O(\Delta t^3)$$

欧拉法只保留了前两项，丢掉了$\Delta t^2$及更高阶的项。每一步的**局部截断误差**是$O(\Delta t^2)$。如果总共积了$N = (t_f - t_0)/\Delta t$步，**全局误差**累积成$O(\Delta t)$。这叫**一阶方法**。

想让精度高，就得用更小的步长$\Delta t$，但步数就多了。更好的办法是用更高阶的方法——在每一步里多用几个信息点。

### 3. RK4 — 用四个斜率

Runge-Kutta方法的核心思想：在区间$[t_n, t_n+\Delta t]$里，不只看起点的斜率，还看**中间几个点**的斜率，然后用一个巧妙的加权平均来近似整个区间的平均斜率。

RK4（四阶）用四个斜率：

$$k_1 = \mathbf{f}(\mathbf{x}_n, t_n) \quad\quad\quad \text{(起点斜率)}$$

$$k_2 = \mathbf{f}\!\left(\mathbf{x}_n + \frac{\Delta t}{2}k_1,\; t_n + \frac{\Delta t}{2}\right) \quad\quad \text{(中点用}k_1\text{估计后的斜率)}$$

$$k_3 = \mathbf{f}\!\left(\mathbf{x}_n + \frac{\Delta t}{2}k_2,\; t_n + \frac{\Delta t}{2}\right) \quad\quad \text{(中点用}k_2\text{修正后的斜率)}$$

$$k_4 = \mathbf{f}\!\left(\mathbf{x}_n + \Delta t \, k_3,\; t_n + \Delta t\right) \quad\quad \text{(终点斜率)}$$

最终的递推公式是这四个斜率的加权平均：

$$\mathbf{x}_{n+1} = \mathbf{x}_n + \frac{\Delta t}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

**为什么权重是$[1,2,2,1]$？** 这是精心设计的，使得对真正的$\mathbf{x}(t)$做Taylor展开到$\Delta t^4$项时，所有截断误差项刚好抵消。这样局部截断误差是$O(\Delta t^5)$，全局误差是$O(\Delta t^4)$——比欧拉法的一阶高了三个量级。

### 4. 物理例子：弹簧-质量-阻尼

一个质量块挂在弹簧上，还受阻尼。它的运动方程是牛顿第二定律：

$$m\ddot{x} + c\dot{x} + kx = 0$$

- $m$：质量
- $c$：阻尼系数——速度越大，阻力越大
- $k$：弹簧刚度——拉得越远，回弹力越大

这个二阶ODE可以写成两个一阶ODE。令$s_1 = x$（位移），$s_2 = \dot{x}$（速度）。则：

$$\dot{s}_1 = s_2 \quad \text{(位置的变化率 = 速度)}$$
$$\dot{s}_2 = \ddot{x} = -\frac{c}{m}s_2 - \frac{k}{m}s_1 \quad \text{(速度的变化率 = 加速度)}$$

写成向量形式：$\dot{\mathbf{s}} = \mathbf{f}(\mathbf{s}) = \begin{pmatrix} s_2 \\ -\frac{c}{m}s_2 - \frac{k}{m}s_1 \end{pmatrix}$。

## 代码

```C++
#include <iostream>
#include <Eigen/Dense>

int main() {
    double m = 1.0, c = 0.3, k = 2.0;
    double dt = 0.01;
    int steps = 500;

    Eigen::Vector2d s(1.0, 0.0);  // 初始：位移1，速度0

    // f(s, t) = ds/dt
    auto f = [&](const Eigen::Vector2d& s, double t) -> Eigen::Vector2d {
        return Eigen::Vector2d(s(1), -(c / m) * s(1) - (k / m) * s(0));
    };

    for (int i = 0; i < steps; i++) {
        double t = i * dt;

        Eigen::Vector2d k1 = f(s, t);
        Eigen::Vector2d k2 = f(s + 0.5 * dt * k1, t + 0.5 * dt);
        Eigen::Vector2d k3 = f(s + 0.5 * dt * k2, t + 0.5 * dt);
        Eigen::Vector2d k4 = f(s + dt * k3, t + dt);

        s += (dt / 6.0) * (k1 + 2 * k2 + 2 * k3 + k4);

        if (i % 100 == 0)
            std::cout << "t=" << t << "  x=" << s(0) << "  v=" << s(1) << std::endl;
    }
}
```

```cmd
t=0.00  x=0.9999  v=-0.0199
t=1.00  x=0.5354  v=-0.2376
t=2.00  x=0.1536  v=-0.0702
t=3.00  x=0.0294  v=-0.0003
t=4.00  x=-0.0005  v=0.0070
```

位移在逐渐衰减——阻尼在吃掉能量。大概$t=3$秒以后几乎回到零。经典的欠阻尼振荡。

# 二、Eigen 性能小撇步

## 固定尺寸 vs 动态尺寸

```C++
Eigen::Matrix3d A;              // 好——栈上分配，编译器全知道，极致优化
Eigen::MatrixXd B(3, 3);       // 浪费——堆上分配
```

编译器对固定尺寸矩阵能疯狂展开循环、用寄存器、上SIMD。$\leq 4\times4$一律固定尺寸。

## noalias() 省一趟拷贝

$C = A * B$实际上会先求$A*B$存到一个临时变量里，再拷给$C$。如果你知道$C$不会和$A$或$B$的存储重叠（99%的情况下不会），直接：

```C++
C.noalias() = A * B;    // 跳过临时变量
```

## 表达式模板自动融合

```C++
Eigen::VectorXd result = a + b + c;  // 编译器把它合成一趟循环
```

不要写成`tmp = a + b; result = tmp + c;`——这会打断融合，多一次中间分配。

## 预分配 + compute() 避免反复分配

```C++
Eigen::LLT<Eigen::MatrixXd> llt(100);  // 一次分配

for (int iter = 0; iter < 1000; iter++) {
    llt.compute(A);          // 内存复用，不再分配
    Eigen::VectorXd x = llt.solve(b);
}
```

## 行优先 vs 列优先

Eigen默认列优先。如果你要频繁取行（比如点云$n\times3$），换行优先让缓存更友好：

```C++
typedef Eigen::Matrix<double, Eigen::Dynamic, 3, Eigen::RowMajor> PointCloud;
```
