# 03-文件与目录操作

文件与目录操作是 Linux 日常使用中最核心、最基础的一章。无论是系统管理员、开发人员还是普通用户，每天都会频繁使用这些命令。本章将为你详细讲解从浏览目录到文件压缩归档的全套操作。

---

## 1. 目录浏览

### 1.1 `pwd` — 显示当前工作目录

`pwd`（Print Working Directory）用于显示当前所在的目录路径。当你迷失在复杂的目录结构中时，`pwd` 是你忠实的指南针。

```bash
$ pwd
/home/john/Documents

$ cd /var/log
$ pwd
/var/log
```

**物理路径 vs 逻辑路径**

当目录包含符号链接（软链接）时，`pwd` 的 `-P` 和 `-L` 选项就会体现出区别：

- `-L`（默认，Logical）：显示逻辑路径，即包含符号链接的路径
- `-P`（Physical）：显示物理路径，解析所有符号链接后的真实路径

```bash
# 创建一个符号链接进行演示
$ mkdir -p /tmp/real_dir
$ ln -s /tmp/real_dir /tmp/link_dir

# 通过符号链接进入目录
$ cd /tmp/link_dir

# 逻辑路径（默认）：保留了符号链接的路径
$ pwd -L
/tmp/link_dir

# 物理路径：解析了符号链接后的真实路径
$ pwd -P
/tmp/real_dir

# 默认行为等同于 -L
$ pwd
/tmp/link_dir
```

> **实用场景**：在脚本中需要获取脚本所在的真实目录时，常用 `cd "$(dirname "$0")" && pwd -P` 来获取脚本的真实物理路径。

### 1.2 `ls` — 列出目录内容

`ls` 是使用频率最高的命令之一。它不仅列出文件，还能展示文件的权限、大小、修改时间等详细信息。

#### 1.2.1 基本用法

```bash
$ ls
Desktop  Documents  Downloads  Music  Pictures  Videos
```

#### 1.2.2 `-l`：长格式输出

长格式会显示文件类型与权限、硬链接数、所有者、所属组、文件大小、最后修改时间和文件名。

```bash
$ ls -l
total 24
drwxr-xr-x 2 john staff 4096 Jul 25 14:30 Desktop
drwxr-xr-x 5 john staff 4096 Jul 20 09:15 Documents
drwxr-xr-x 3 john staff 4096 Jul 26 18:42 Downloads
-rw-r--r-- 1 john staff 1207 Jul 25 16:00 notes.txt
-rwxr-xr-x 1 john staff  256 Jul 24 10:00 script.sh
```

**长格式各字段含义：**

| 字段示例 | 含义 |
|---------|------|
| `drwxr-xr-x` | 文件类型+权限（d=目录，-=文件，l=链接） |
| `1` | 硬链接数 |
| `john` | 所有者 |
| `staff` | 所属组 |
| `4096` | 文件大小（字节） |
| `Jul 25 14:30` | 最后修改时间 |
| `notes.txt` | 文件名 |

**权限详解**（详见 [[05-用户与权限管理|用户与权限管理]]）：

```
类型  所有者权限   组权限   其他人权限
 d     rwx        r-x      r-x
```

- `r` = 读取（4），`w` = 写入（2），`x` = 执行（1）
- `rwx` = 4+2+1 = 7（完全权限）
- `r--` = 4（只读）
- `rw-` = 6（读写）

#### 1.2.3 `-a`：显示所有文件（包括隐藏文件）

Linux 中以 `.` 开头的文件是隐藏文件（类似 Windows 的隐藏属性），`ls -a` 可以显示它们。

```bash
$ ls -a
.  ..  .bashrc  .config  .gitconfig  .ssh  Desktop  Documents

# 注意 . 和 .. 的含义：
# .   → 当前目录
# ..  → 上一级目录
```

`-A` 选项显示隐藏文件但排除 `.` 和 `..`：

```bash
$ ls -A
.bashrc  .config  .gitconfig  .ssh  Desktop  Documents
```

#### 1.2.4 `-h`：人类可读的文件大小

不加 `-h` 时，`ls -l` 以字节为单位显示大小，对于大文件很不直观。`-h`（Human-readable）会自动转换为 K、M、G 等单位。

```bash
# 没有 -h：大小以字节显示
$ ls -l
-rw-r--r-- 1 john staff 1572864 Jul 25 16:00 data.csv
-rw-r--r-- 1 john staff 536870912 Jul 24 10:00 ubuntu.iso

# 加了 -h：易读的格式
$ ls -lh
-rw-r--r-- 1 john staff 1.5M Jul 25 16:00 data.csv
-rw-r--r-- 1 john staff 512M Jul 24 10:00 ubuntu.iso
```

#### 1.2.5 `-t` 和 `-S`：按时间 / 按大小排序

```bash
# -t：按修改时间排序（最新的在前）
$ ls -lt
drwxr-xr-x 3 john staff 4096 Jul 26 18:42 Downloads   # 最新
drwxr-xr-x 2 john staff 4096 Jul 25 14:30 Desktop
-rw-r--r-- 1 john staff 1207 Jul 25 16:00 notes.txt
-rwxr-xr-x 1 john staff  256 Jul 24 10:00 script.sh   # 最旧

# -S：按文件大小排序（最大的在前）
$ ls -lS
-rw-r--r-- 1 john staff 1572864 Jul 25 16:00 data.csv
-rw-r--r-- 1 john staff   12070 Jul 23 09:00 report.txt
-rw-r--r-- 1 john staff    1207 Jul 25 16:00 notes.txt
-rw-r--r-- 1 john staff     256 Jul 24 10:00 script.sh
```

#### 1.2.6 `-r`：反转排序

```bash
# -tr：按时间逆序（最旧的文件在前，方便找到很久没动的文件）
$ ls -ltr
-rwxr-xr-x 1 john staff   256 Jul 24 10:00 script.sh   # 最旧
-rw-r--r-- 1 john staff  1207 Jul 25 16:00 notes.txt
drwxr-xr-x 2 john staff 4096 Jul 25 14:30 Desktop
drwxr-xr-x 3 john staff 4096 Jul 26 18:42 Downloads   # 最新

# -Sr：按大小逆序（最小的在前）
$ ls -lSr
-rw-r--r-- 1 john staff     256 Jul 24 10:00 script.sh
-rw-r--r-- 1 john staff    1207 Jul 25 16:00 notes.txt
-rw-r--r-- 1 john staff 1572864 Jul 25 16:00 data.csv
```

#### 1.2.7 `-R`：递归列出子目录

```bash
$ ls -R project/
project/:
README.md  src/  tests/  build/

project/src:
main.c  util.c  header.h

project/src/sub/
nested.c

project/tests:
test_main.c

project/build:
（空目录）
```

#### 1.2.8 `--color`：彩色输出

现代 Linux 发行版通常默认启用了颜色，文件类型以不同颜色区分：

| 颜色 | 文件类型 |
|-----|---------|
| 蓝色 | 目录 |
| 绿色 | 可执行文件 |
| 青色 | 符号链接 |
| 红色（背景） | 设置了 setuid 的文件 |
| 红色文本 | 归档文件（.tar, .gz, .zip...）|

```bash
# 禁用颜色输出
$ ls --color=never

# 强制颜色输出（在管道中保持颜色时有用）
$ ls --color=always | less -R
```

#### 1.2.9 `-i`：显示 inode 号

```bash
$ ls -li
total 16
524289 -rw-r--r-- 1 john staff 1207 Jul 25 16:00 notes.txt
524290 drwxr-xr-x 2 john staff 4096 Jul 26 11:00 scripts/
```

#### 1.2.10 常用组合拳

```bash
# ls -lah：显示所有文件（含隐藏）、长格式、人类可读大小
$ ls -lah
total 36K
drwxr-xr-x  5 john staff 4.0K Jul 26 20:00 .
drwxr-xr-x 20 john staff 4.0K Jul 26 19:00 ..
-rw-------  1 john staff 1.2K Jul 25 16:00 .bashrc
drwxr-xr-x  2 john staff 4.0K Jul 26 11:00 .ssh
-rw-r--r--  1 john staff 1.5M Jul 25 16:30 data.csv
-rw-r--r--  1 john staff 1.2K Jul 25 16:00 notes.txt

# ls -ltr：按时间逆序，快速找到最近修改的文件
$ ls -ltr
...

# ls -lSrh：按大小逆序（小文件在前）、人类可读
$ ls -lSrh
...
```

### 1.3 `cd` — 切换目录

`cd`（Change Directory）用于在不同目录之间穿梭。

#### 1.3.1 基本跳转

```bash
# 切换到用户主目录
$ cd
$ pwd
/home/john

# 等价写法
$ cd ~
$ cd $HOME

# 切换到根目录
$ cd /
$ pwd
/

# 切换到上一级目录
$ cd ..
$ pwd
/

# 连续向上一级
$ cd /usr/local/bin
$ cd ../..    # 回到 /usr
$ pwd
/usr

# 简化写法：向上两级
$ cd /usr/local/bin
$ cd ../../   # 同上
$ pwd
/usr
```

#### 1.3.2 `cd -`：回到上一个目录

这是非常有用的快捷键，让你在两个目录之间快速切换。

```bash
$ cd /var/log
$ pwd
/var/log

$ cd /etc/nginx
$ pwd
/etc/nginx

$ cd -         # 回到 /var/log
/var/log
$ pwd
/var/log

$ cd -         # 再回到 /etc/nginx
/etc/nginx
```

#### 1.3.3 实际演练：目录跳转

```bash
# 假设你从家目录出发
$ cd ~
$ pwd
/home/john

$ cd /usr/share
$ cd /etc/systemd/system
$ cd -          # → /usr/share
$ cd -          # → /etc/systemd/system
$ cd            # → /home/john

# 用相对路径进入当前目录下的子目录
$ cd ~/Documents
$ pwd
/home/john/Documents

# 用相对路径进入深层目录
$ mkdir -p project/src/utils
$ cd project/src/utils
$ pwd
/home/john/Documents/project/src/utils
```

### 1.4 `tree` — 树状显示目录结构

`tree` 以树形图的方式展示目录结构，非常直观。在某些发行版中可能需要先安装：

```bash
# Debian/Ubuntu
$ sudo apt install tree

# CentOS/RHEL
$ sudo yum install tree

# Arch Linux
$ sudo pacman -S tree
```

#### 1.4.1 基本用法

```bash
$ tree
.
├── Desktop
├── Documents
│   ├── notes
│   │   ├── linux.md
│   │   └── python.md
│   └── reports
│       └── 2024-Q1.md
├── Downloads
└── Pictures

4 directories, 4 files
```

#### 1.4.2 常用选项

```bash
# -L 限制层级深度
$ tree -L 1
.
├── Desktop
├── Documents
├── Downloads
└── Pictures

# -d 只显示目录
$ tree -d
.
├── Desktop
├── Documents
│   ├── notes
│   └── reports
├── Downloads
└── Pictures

# -a 显示隐藏文件
$ tree -a

# -h 显示文件大小（人类可读）
$ tree -h

# 组合使用：只显示前2层目录、含隐藏文件、人类可读大小
$ tree -L 2 -a -h
[ 4.0K]  .
├── [ 4.0K]  .config
│   ├── [ 2.5K]  starship.toml
│   └── [ 1.2K]  git.config
├── [ 4.0K]  Documents
│   ├── [ 4.0K]  notes
│   └── [ 4.0K]  reports
└── [ 4.0K]  Downloads

# -I 排除特定模式的文件/目录
$ tree -I "node_modules|*.log"
```

## 2. 文件查看

### 2.1 `cat` — 连接并显示文件内容

`cat`（concatenate）是最简单的文件内容查看工具，适合查看短文件。

```bash
$ cat hello.txt
Hello, World!
This is a simple text file.
```

#### 2.1.1 `-n`：显示行号

```bash
$ cat -n hello.txt
     1  Hello, World!
     2  This is a simple text file.
     3
     4  Line 4 is here.
```

`-b` 选项对非空行编号（跳过空白行）：

```bash
$ cat -b hello.txt
     1  Hello, World!
     2  This is a simple text file.

     3  Line 4 is here.
```

#### 2.1.2 合并文件

`cat` 的原始设计意图就是连接多个文件：

```bash
$ cat part1.txt
First part of the story.

$ cat part2.txt
Second part of the story.

# 连接显示
$ cat part1.txt part2.txt
First part of the story.
Second part of the story.

# 合并并保存为新文件
$ cat part1.txt part2.txt > full_story.txt
$ cat full_story.txt
First part of the story.
Second part of the story.
```

#### 2.1.3 其他实用选项

```bash
# -s：压缩连续空行为单行
$ cat -s file_with_many_blank_lines.txt

# -E：在每行末尾显示 $
$ cat -E script.sh
#!/bin/bash$
echo "Hello"$
```

#### 2.1.4 `cat` 的局限性

`cat` 会一次性输出文件的全部内容。对于大文件（如日志文件动辄几百MB），`cat` 会导致终端疯狂滚动，这时候应该用 `less` 或 `tail`/`head` 来查看。

---

### 2.2 `less` — 分页查看文件

`less` 是 `more` 的增强版（"less is more"），允许你向前/向后自由翻页浏览文件内容。

```bash
$ less /var/log/syslog
```

#### 2.2.1 常用导航按键

| 按键 | 功能 |
|-----|------|
| `Space` 或 `f` | 向下翻一页 |
| `b` | 向上翻一页 |
| `j` 或 `↓` | 向下滚动一行 |
| `k` 或 `↑` | 向上滚动一行 |
| `g` | 跳到文件开头 |
| `G` | 跳到文件末尾 |
| `50g` 或 `50G` | 跳到第 50 行 |
| `100p` | 跳到文件的 100% 位置 |

#### 2.2.2 搜索功能

```bash
# 按下 / 后输入搜索词，回车
/search_term     # 向下搜索
?search_term     # 向上搜索

# 搜索后按：
n                # 跳转到下一个匹配项
N                # 跳转到上一个匹配项
```

#### 2.2.3 其他常用功能

| 按键 | 功能 |
|-----|------|
| `-N`（启动选项） | 显示行号 |
| `-i`（启动选项） | 搜索时忽略大小写 |
| `q` | 退出 |
| `h` | 显示帮助 |
| `v` | 使用默认编辑器打开当前文件 |
| `F` | 类似 `tail -f`，实时追踪文件更新 |

```bash
# 带行号、忽略大小写打开文件
$ less -N -i /var/log/app.log
```

### 2.3 `head` — 查看文件开头

`head` 默认显示文件的前 10 行。

```bash
# 默认显示前 10 行
$ head /var/log/syslog

# -n 指定行数
$ head -n 20 /var/log/syslog     # 显示前 20 行
$ head -5 /var/log/syslog        # 显示前 5 行
```

**多个文件：**

```bash
$ head -3 file1.txt file2.txt
==> file1.txt <==
Line 1
Line 2
Line 3

==> file2.txt <==
Another 1
Another 2
Another 3
```

---

### 2.4 `tail` — 查看文件末尾

`tail` 默认显示文件的后 10 行。

```bash
# 查看最后 20 行
$ tail -n 20 /var/log/syslog

# 查看从第 100 行开始到末尾
$ tail -n +100 /var/log/syslog
```

#### 2.4.1 `-f`：实时追踪（follow）

这是 `tail` 最常用的功能，常用于实时查看日志文件：

```bash
# 实时追踪（文件有新增内容时自动显示）
$ tail -f /var/log/nginx/access.log
192.168.1.1 - - [27/Jul/2026:10:00:01] "GET /index.html" 200 5123
192.168.1.2 - - [27/Jul/2026:10:00:02] "POST /api/users" 201 1024
# （实时滚动，按 Ctrl+C 停止）

# -F：即使文件被删除后重新创建也会继续追踪（用于日志轮转场景）
$ tail -F /var/log/nginx/access.log
```

**实用场景：**

```bash
# 实时查看系统日志
$ sudo tail -f /var/log/syslog

# 同时追踪多个日志文件
$ tail -f /var/log/nginx/access.log /var/log/nginx/error.log
==> /var/log/nginx/access.log <==
...
==> /var/log/nginx/error.log <==
...

# 配合 grep 过滤日志
$ tail -f /var/log/app.log | grep "ERROR"
```

### 2.5 `file` — 识别文件类型

Linux 下文件没有扩展名也能被正确识别，因为 `file` 命令通过读取文件的"魔数"（magic number）来判断真实类型。

```bash
$ file report.txt
report.txt: ASCII text

$ file script.sh
script.sh: Bourne-Again shell script, ASCII text executable

$ file portrait.png
portrait.png: PNG image data, 1920 x 1080, 8-bit/color RGB, non-interlaced

$ file /bin/ls
/bin/ls: ELF 64-bit LSB shared object, x86-64, version 1 (SYSV), dynamically linked

# 文件没有扩展名也能正确识别
$ file mysterious_file
mysterious_file: PDF document, version 1.4

# 文件夹
$ file Documents/
Documents/: directory

# 符号链接
$ file /usr/bin/python
/usr/bin/python: symbolic link to python3.10
```

### 2.6 `stat` — 查看文件详细元数据

`stat` 比 `ls -l` 提供更详尽的文件元数据，包括 inode 号、三种时间戳等。

```bash
$ stat notes.txt
  File: notes.txt
  Size: 1207        Blocks: 8          IO Block: 4096   regular file
Device: 802h/2050d  Inode: 524289      Links: 1
Access: (0644/-rw-r--r--)  Uid: (1000/  john)   Gid: (1000/  john)
Access: 2026-07-25 16:00:00.000000000 +0800
Modify: 2026-07-25 16:00:00.000000000 +0800
Change: 2026-07-25 16:05:00.000000000 +0800
 Birth: 2026-07-20 09:15:30.000000000 +0800
```

**三种时间戳的区别：**

| 时间 | 含义 | 何时更新 |
|-----|------|---------|
| Access（atime） | 访问时间 | 读取文件内容时更新 |
| Modify（mtime） | 修改时间 | 文件内容被修改时更新 |
| Change（ctime） | 变更时间 | 文件元数据（权限、所有者等）或内容改变时更新 |
| Birth | 创建时间 | 文件创建时（部分文件系统支持）|

```bash
# 访问文件（用 cat 读取）
$ cat notes.txt > /dev/null
$ stat -c "%x" notes.txt    # 查看 Access 时间 → 已更新

# 修改内容
$ echo "new line" >> notes.txt
$ stat -c "%y" notes.txt    # 查看 Modify 时间 → 已更新

# 修改权限
$ chmod 644 notes.txt
$ stat -c "%z" notes.txt    # 查看 Change 时间 → 已更新
```

**格式化输出：**

```bash
# 只显示特定字段
$ stat -c "Size: %s bytes, Permissions: %a, Owner: %U" notes.txt
Size: 1207 bytes, Permissions: 644, Owner: john

# 显示 inode 号
$ stat -c "%i %n" *
524289 notes.txt
524291 script.sh
```

### 2.7 `wc` — 统计行数、单词数、字符数

`wc`（Word Count）是文本文件统计的利器。

```bash
$ cat sample.txt
Hello World
This is Linux
It is great

$ wc sample.txt
 3  7 34 sample.txt
# ↑  ↑  ↑
# 行  词  字节
```

#### 2.7.1 各选项

```bash
# -l：只统计行数
$ wc -l sample.txt
3 sample.txt

# -w：只统计单词数
$ wc -w sample.txt
7 sample.txt

# -c：只统计字节数
$ wc -c sample.txt
34 sample.txt

# -m：统计字符数（多字节字符时与 -c 不同）
$ wc -m sample.txt
34 sample.txt
```

#### 2.7.2 实用示例

```bash
# 统计目录下所有 .c 文件的代码行数
$ wc -l src/*.c
  120 src/main.c
   85 src/util.c
   45 src/parser.c
  250 total

# 统计当前目录下有多少个文件
$ ls | wc -l
15

# 统计用户数量
$ wc -l /etc/passwd
42 /etc/passwd

# 统计日志中 ERROR 出现的次数
$ grep "ERROR" /var/log/app.log | wc -l
137
```

## 3. 文件创建与编辑

### 3.1 `touch` — 创建空文件 / 更新时间戳

`touch` 有两个主要用途：创建空文件和更新文件的访问/修改时间。

```bash
# 创建空文件
$ touch newfile.txt
$ ls -l newfile.txt
-rw-r--r-- 1 john staff 0 Jul 27 10:00 newfile.txt

# 批量创建多个空文件
$ touch file1.txt file2.txt file3.txt
$ ls
file1.txt  file2.txt  file3.txt
```

**更新时间戳：**

```bash
# 如果文件已存在，touch 会更新其修改时间和访问时间为当前时间
$ touch existing_file.txt

# -a：只更新访问时间
$ touch -a file.txt

# -m：只更新修改时间
$ touch -m file.txt

# -t：设置指定时间（格式：[[CC]YY]MMDDhhmm[.ss]）
$ touch -t 202401011200.00 old_file.txt
$ stat -c "%y" old_file.txt
2024-01-01 12:00:00.000000000 +0800

```

## 4. 文件复制、移动与删除

### 4.1 `cp` — 复制文件与目录

#### 4.1.1 基本复制

```bash
# 复制文件到同一目录下（相当于备份）
$ cp original.txt backup.txt

# 复制文件到另一个目录（保持原名）
$ cp file.txt /home/john/Documents/

# 复制多个文件到目录
$ cp file1.txt file2.txt file3.txt /home/john/backups/
```

#### 4.1.2 `-r`：递归复制目录

```bash
# 复制整个目录（必须是 -r，不是 -R 但在 Linux 上通常一样）
$ cp -r project/ project_backup/

# 复制目录内容到目标目录（而非将源目录作为子目录）
$ cp -r src/* dst/
```

#### 4.1.3 `-i`：覆盖前确认

```bash
# 当目标文件已存在时会询问
$ cp -i source.txt existing.txt
cp: overwrite 'existing.txt'? y

# 某些发行版默认为 cp 设置了 alias cp='cp -i'，可用 \cp 临时绕过
$ \cp source.txt existing.txt    # 不询问，直接覆盖
```

#### 4.1.4 `-p` 与 `-a`：保留属性

```bash
# -p：保留原始文件的时间戳、权限和所有者
$ cp -p original.txt copy.txt

# -a：归档模式 = -dpR（保留所有属性 + 递归 + 不解引用链接）
# 这是最全面的复制方式，用于备份
$ cp -a important_dir/ important_dir_backup/

# 验证：原文件和拷贝的时间戳相同
$ stat -c "%y" original.txt
2026-07-25 16:00:00.000000000 +0800
$ stat -c "%y" copy.txt
2026-07-25 16:00:00.000000000 +0800
```

#### 4.1.5 其他选项

```bash
# -u：仅当源文件比目标文件新，或目标文件不存在时才复制
$ cp -u src/*.txt backups/

# -v：显示详细的复制过程
$ cp -v file1.txt file2.txt /tmp/
'file1.txt' -> '/tmp/file1.txt'
'file2.txt' -> '/tmp/file2.txt'

# -n：不覆盖已有文件
$ cp -n source.txt existing.txt
```

### 4.2 `mv` — 移动与重命名

Linux 中重命名和移动使用的是同一个命令 `mv`，因为本质上移动文件就是改变其在文件系统中的路径。

#### 4.2.1 重命名

```bash
# 重命名文件
$ mv old_name.txt new_name.txt

# 重命名目录
$ mv old_project/ new_project/

# 批量重命名的思路：mv 本身不能批量，但可以配合循环
$ for f in *.txt; do mv "$f" "${f%.txt}.md"; done
# 将所有 .txt 文件重命名为 .md
```

#### 4.2.2 移动

```bash
# 移动文件到目录
$ mv file.txt /home/john/Documents/

# 移动多个文件
$ mv file1.txt file2.txt /home/john/backups/

# 移动目录
$ mv old_location_dir/ /new/path/
```

#### 4.2.3 `-i`：覆盖前确认

```bash
$ mv -i source.txt existing.txt
mv: overwrite 'existing.txt'? y
```

#### 4.2.4 实用技巧

```bash
# mv 也可以用来快速重命名并移动
$ mv /tmp/download.txt ~/Documents/notes/linux-notes.txt

# -v 显示操作过程
$ mv -v *.log archives/
renamed 'app.log' -> 'archives/app.log'
renamed 'error.log' -> 'archives/error.log'
```

### 4.3 `rm` — 删除文件与目录

> **⚠️ 严重警告：Linux 没有回收站！`rm` 删除的文件无法恢复（除非使用专业的数据恢复工具）。在执行 `rm` 之前务必三思，尤其是 `rm -rf`。**

#### 4.3.1 删除文件

```bash
$ rm file.txt
$ rm file1.txt file2.txt file3.txt
```

#### 4.3.2 `-r`：递归删除目录

```bash
$ rm -r old_project/
# 删除目录及其所有内容
```

#### 4.3.3 `-f`：强制删除

```bash
$ rm -f file.txt         # 不询问，不报错（即使文件不存在）
$ rm -rf old_project/    # 强制递归删除（极其危险！）
```

#### 4.3.4 `-i`：逐个确认

```bash
$ rm -i *.log
rm: remove regular file 'app.log'? y
rm: remove regular file 'error.log'? n
rm: remove regular file 'debug.log'? y
```

#### 4.3.5 安全删除策略

由于 Linux 没有回收站，推荐以下安全策略：

```bash
# 策略1：先用 ls 列出要删除的文件，确认无误后再替换为 rm
$ ls *.log
app.log  error.log  debug.log
$ rm *.log              # 确认上面的就是你要删除的

# 策略2：先移到 /tmp（类似回收站），确认不需要后再删除
$ mv important_file.txt /tmp/
# ... 工作几天，发现确实不需要了 ...
$ rm /tmp/important_file.txt
# 或者：系统重启后 /tmp 会被自动清理（取决于发行版配置）

# 策略3：创建自定义 trash 函数
$ mkdir -p ~/.trash
$ trash() { mv "$@" ~/.trash/; }
$ untrash() { mv ~/.trash/"$1" .; }

# 策略4：使用 -i 模式（在你的 .bashrc 中设置）
# alias rm='rm -i'  ← 很多发行版的默认配置
```

#### 4.3.6 `rmdir`：删除空目录

```bash
$ rmdir empty_dir/
$ rmdir dir1/ dir2/ dir3/

# 如果目录非空会报错
$ rmdir non_empty/
rmdir: failed to remove 'non_empty/': Directory not empty

# 使用 rm -r 删除非空目录
$ rm -r non_empty/
```

## 5. 文件查找

### 5.1 `find` — 强大的文件搜索工具

`find` 是 Linux 中最强大也最复杂的文件搜索命令，它实时遍历文件系统来查找符合条件的文件。

#### 5.1.1 基本语法

```
find [路径] [表达式] [动作]
```

#### 5.1.2 按名称查找

```bash
# 在当前目录及子目录中查找名为 "config.txt" 的文件
$ find . -name "config.txt"
./app/config.txt

# 使用通配符
$ find . -name "*.log"
./logs/app.log
./logs/error.log
./logs/debug.log

# -iname：忽略大小写
$ find . -iname "README*"
./project/readme.md
./project/README.md

# -not 或 !：取反
$ find . -not -name "*.txt"
# 找所有不是 .txt 的文件
```

#### 5.1.3 按类型查找

```bash
# -type f：只查找普通文件
$ find . -type f -name "*.py"

# -type d：只查找目录
$ find . -type d -name "test*"
./project/tests
./project/tests/unit

# -type l：只查找符号链接
$ find /usr/bin -type l
```

#### 5.1.4 按时间查找

```bash
# -mtime n：n 天前修改的文件
#  n  = 恰好 n 天前
# +n  = n 天之前（更早）
# -n  = n 天之内（更近）

# 最近 7 天内修改过的文件
$ find . -mtime -7

# 7 天前修改的文件
$ find . -mtime 7

# 7 天以前修改的文件
$ find . -mtime +7

# -mmin：按分钟（用法类似）
$ find . -mmin -30          # 30 分钟内修改的

# -atime：按访问时间；-ctime：按变更时间
$ find . -atime -1          # 24 小时内被访问的
$ find . -ctime +30         # 30 天前变更的
```

#### 5.1.5 按大小查找

```bash
# 大于 100MB 的文件
$ find . -size +100M

# 小于 10KB 的文件
$ find . -size -10k

# 精确匹配 1GB 的文件
$ find . -size 1G

# 查找空文件
$ find . -size 0
$ find . -empty

# 大小单位：c(字节), k(KB), M(MB), G(GB)
```

#### 5.1.6 按权限查找

```bash
# 查找权限为 777 的文件
$ find . -perm 777

# 查找所有用户都有写权限的文件（危险检查）
$ find . -perm -o+w

# 查找设置了 SUID 的文件
$ find / -perm -4000 2>/dev/null
```

#### 5.1.7 多条件组合

```bash
# AND（默认，所有条件同时满足）
$ find . -name "*.log" -size +1M

# OR（-o）
$ find . -name "*.jpg" -o -name "*.png"

# 分组（用括号转义）
$ find . \( -name "*.jpg" -o -name "*.png" \) -size +500k
```

#### 5.1.8 `-exec`：对查找到的文件执行操作

```bash
# 删除所有 .log 文件
$ find . -name "*.log" -exec rm {} \;
#                                      ↑
#        {} 代表找到的每个文件    \; 表示命令结束

# 将所有 .jpg 文件移动到 images/ 目录
$ find . -name "*.jpg" -exec mv {} images/ \;

# 批量修改文件权限
$ find . -type f -name "*.sh" -exec chmod +x {} \;

# -exec command {} +  (批量传递，效率更高)
$ find . -name "*.log" -exec du -ch {} +
# 与 \; 的区别：+ 将所有文件作为一批参数传给命令，\; 是逐个调用

# 交互式确认后再删除
$ find . -name "*.tmp" -exec rm -i {} \;

# 查找大文件并显示详细信息
$ find /home -type f -size +100M -exec ls -lh {} \;
```

#### 5.1.9 结合管道

```bash
# find + xargs 比 -exec 在某些场景更高效
$ find . -name "*.txt" | xargs grep "TODO"
# 在所有 .txt 文件中搜索 "TODO"

# find + xargs 处理带空格的文件名（推荐方式）
$ find . -name "*.txt" -print0 | xargs -0 grep "TODO"
# -print0 和 -0 使用 null 字符作为分隔符，避免文件名中空格造成的问题

# 统计所有 .js 文件的代码行数
$ find . -name "*.js" | xargs wc -l | tail -1
```

#### 5.1.10 综合实战

```bash
# 查找并删除 30 天前的日志文件
$ find /var/log -name "*.log" -mtime +30 -delete

# 查找大于 100MB 的文件并按大小降序排列
$ find . -type f -size +100M -exec ls -lh {} \; | sort -k5 -h -r

# 查找所有空目录并删除
$ find . -type d -empty -delete

# 查找最近修改过的配置文件
$ find /etc -type f -name "*.conf" -mtime -1

# 查找不属于任何用户的文件
$ find /home -nouser
# 查找不属于任何组的文件
$ find /home -nogroup
```

### 5.2 `locate` — 基于数据库的快速查找

`locate` 不是实时搜索文件系统，而是搜索由 `updatedb` 定期构建的文件名数据库，因此速度极快。

```bash
# 安装（部分发行版需手动安装）
$ sudo apt install plocate   # Debian/Ubuntu
$ sudo yum install mlocate   # CentOS/RHEL

# 先更新数据库（通常系统会定时执行，需要时可手动触发）
$ sudo updatedb

# 使用 locate 查找
$ locate bashrc
/etc/bash.bashrc
/etc/skel/.bashrc
/home/john/.bashrc
/usr/share/base-files/dot.bashrc

# 注意：locate 只能找到 updatedb 执行时已存在的文件
# 刚创建的文件可能找不到，需要先 sudo updatedb

# -i 忽略大小写
$ locate -i readme

# -c 只显示匹配数量
$ locate -c ".conf"
128

# 限制结果数量
$ locate -l 10 "*.log"
```

**`locate` vs `find` 对比：**

| 特性 | `find` | `locate` |
|-----|--------|---------|
| 搜索方式 | 实时遍历文件系统 | 查询预建数据库 |
| 速度 | 慢（需遍历） | 极快（查表） |
| 实时性 | 实时 | 有延迟（需 updatedb） |
| 功能 | 极其丰富 | 简单（仅按名称） |
| 权限 | 只能搜有权限的目录 | 显示数据库中的所有结果 |

### 5.3 `which` — 查找命令的完整路径

# 查找 python 命令的完整路径
$ which python

$ which git

```bash
$ echo $PATH
/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin

# 如果可执行文件不在 PATH 中
$ which my_custom_script
# (无输出)
```

## 6. 压缩与归档

### 6.1 `tar` — 归档工具

`tar`（Tape Archive）的设计初衷是将多个文件打包成一个归档文件（不压缩），配合 gzip 等压缩工具实现打包+压缩。

#### 6.1.1 基本语法

```
tar [选项] [归档文件名] [要归档的文件/目录]
```

**常用选项速查：**

| 选项 | 含义 |
|-----|------|
| `-c` | create：创建归档 |
| `-x` | extract：解包 |
| `-t` | list：列出归档内容 |
| `-v` | verbose：显示详细信息 |
| `-f` | file：指定归档文件名（必须） |
| `-z` | gzip：使用 gzip 压缩/解压 |
| `-j` | bzip2：使用 bzip2 压缩/解压 |
| `-J` | xz：使用 xz 压缩/解压 |
| `-C` | 指定解压目录 |
| `--exclude` | 排除特定文件 |

#### 6.1.2 打包与解包（不压缩）

```bash
# 创建目录结构用作演示
$ mkdir -p myproject/src myproject/docs myproject/tests
$ echo "int main(){}" > myproject/src/main.c
$ echo "# Docs" > myproject/docs/README.md
$ echo "# Tests" > myproject/tests/test.c

# 打包：将 myproject/ 目录打包成 project.tar
$ tar -cvf project.tar myproject/
myproject/
myproject/src/
myproject/src/main.c
myproject/docs/
myproject/docs/README.md
myproject/tests/
myproject/tests/test.c

# 查看归档内容
$ tar -tvf project.tar
drwxr-xr-x john/staff       0 2026-07-27 10:00 myproject/
drwxr-xr-x john/staff       0 2026-07-27 10:00 myproject/src/
-rw-r--r-- john/staff      14 2026-07-27 10:00 myproject/src/main.c
drwxr-xr-x john/staff       0 2026-07-27 10:00 myproject/docs/
-rw-r--r-- john/staff       7 2026-07-27 10:00 myproject/docs/README.md
drwxr-xr-x john/staff       0 2026-07-27 10:00 myproject/tests/
-rw-r--r-- john/staff       8 2026-07-27 10:00 myproject/tests/test.c

# 解包
$ tar -xvf project.tar
myproject/
myproject/src/
...
```

#### 6.1.3 压缩打包（最常用）

```bash
# 使用 gzip 压缩（.tar.gz 或 .tgz）——最常用
$ tar -czvf project.tar.gz myproject/

# 使用 bzip2 压缩（.tar.bz2）——压缩率更高但更慢
$ tar -cjvf project.tar.bz2 myproject/

# 使用 xz 压缩（.tar.xz）——压缩率最高
$ tar -cJvf project.tar.xz myproject/
```

#### 6.1.4 解压

```bash
# 自动识别压缩格式（现代 tar 通常支持，不需要手动指定 z/j/J）
$ tar -xvf project.tar.gz
$ tar -xvf project.tar.bz2
$ tar -xvf project.tar.xz

# 如果需要显式指定：
$ tar -xzvf project.tar.gz     # gzip
$ tar -xjvf project.tar.bz2    # bzip2
$ tar -xJvf project.tar.xz     # xz
```

#### 6.1.5 其他实用操作

```bash
# 解压到指定目录
$ tar -xvf project.tar.gz -C /tmp/

# 从归档中提取单个文件
$ tar -xvf project.tar.gz myproject/src/main.c

# 从归档中提取某类文件（使用通配符）
$ tar -xvf project.tar.gz --wildcards '*.c'

# 打包时排除某些文件
$ tar -czvf project.tar.gz myproject/ --exclude='*.tmp' --exclude='node_modules'

# 打包时排除列表中指定的文件
$ cat exclude_list.txt
*.log
.git/
__pycache__/
$ tar -czvf project.tar.gz myproject/ --exclude-from=exclude_list.txt

# 将文件追加到已有归档
$ echo "newfile" > new.txt
$ tar -rvf project.tar new.txt
```

#### 6.1.6 `.tar.gz` vs `.tar.bz2` vs `.tar.xz` vs `.zip`

| 格式 | 压缩率 | 速度 | 跨平台 | 场景 |
|------|--------|------|--------|------|
| `.tar.gz` | 中 | 快 | 好 | 日常使用、网络传输 |
| `.tar.bz2` | 较高 | 慢 | 一般 | 需要较强压缩时 |
| `.tar.xz` | 最高 | 最慢 | 一般 | 存档、发布源码包 |
| `.zip` | 低 | 快 | 极好 | 跨平台分享 |

```bash
# 压缩率对比示例
$ tar -czf test.tar.gz large_dir/
$ tar -cjf test.tar.bz2 large_dir/
$ zip -r test.zip large_dir/
$ ls -lh test.*
-rw-r--r-- 1 john staff  45M test.tar.gz
-rw-r--r-- 1 john staff  38M test.tar.bz2
-rw-r--r-- 1 john staff  52M test.zip
```

## 7. 重定向与管道

重定向和管道是 Linux Shell 最强大的特性之一，它们让你可以将多个简单命令组合成复杂的数据处理管线。

### 7.1 标准数据流

Linux 中每个进程都有三个标准数据流：

| 编号 | 名称 | 缩写 | 默认目标 | 用途 |
|-----|------|-----|---------|------|
| 0 | 标准输入 | stdin | 键盘 | 程序读取数据 |
| 1 | 标准输出 | stdout | 终端屏幕 | 程序正常输出 |
| 2 | 标准错误 | stderr | 终端屏幕 | 程序错误输出 |

```bash
# 直观理解三个流
$ ls existing_dir    # stdout → 正常输出
file1.txt  file2.txt

$ ls nonexistent_dir  # stderr → 错误输出
ls: cannot access 'nonexistent_dir': No such file or directory

# 两者流是独立的！即使你重定向了 stdout，stderr 仍然会打印到屏幕
```

### 7.2 输出重定向

#### 7.2.1 `>`：覆盖重定向

```bash
# 将命令的标准输出写入文件（覆盖已有内容）
$ echo "Hello" > output.txt
$ cat output.txt
Hello

$ echo "World" > output.txt
$ cat output.txt
World                       # ← "Hello" 被覆盖了
```

#### 7.2.2 `>>`：追加重定向

```bash
$ echo "Line 1" > log.txt
$ echo "Line 2" >> log.txt
$ echo "Line 3" >> log.txt
$ cat log.txt
Line 1
Line 2
Line 3
```

#### 7.2.3 错误输出重定向

```bash
# 将错误输出重定向到文件
$ ls nonexistent_dir 2> error.log
$ cat error.log
ls: cannot access 'nonexistent_dir': No such file or directory

# 将正常输出和错误输出重定向到不同文件
$ ls existing_dir nonexistent_dir > out.txt 2> err.txt
$ cat out.txt
existing_dir:
file1.txt
$ cat err.txt
ls: cannot access 'nonexistent_dir': No such file or directory
```

#### 7.2.4 `&>`：同时重定向 stdout 和 stderr

```bash
# 同时重定向标准输出和标准错误到同一个文件
$ ls existing_dir nonexistent_dir &> combined.log
$ cat combined.log
ls: cannot access 'nonexistent_dir': No such file or directory
existing_dir:
file1.txt

# 追加模式
$ ls existing_dir nonexistent_dir &>> all_output.log
```

**不同写法的等价关系：**

```bash
$ command &> file
# 等价于
$ command > file 2>&1

$ command &>> file
# 等价于
$ command >> file 2>&1
```

#### 7.2.5 `/dev/null`：数据黑洞

```bash
# 丢弃所有输出（静默执行）
$ ls nonexistent_dir 2> /dev/null

# 丢弃 stdout 和 stderr
$ command > /dev/null 2>&1

# 只保留 stderr 到屏幕，丢弃 stdout
$ command > /dev/null
```

### 7.3 输入重定向 `<`

```bash
# 将文件内容作为命令的标准输入
$ wc -l < /etc/passwd
42

# 对比：直接读文件和重定向的区别
$ wc -l /etc/passwd
42 /etc/passwd              # ← 有文件名
$ wc -l < /etc/passwd
42                          # ← 只有数字，因为 wc 不知道文件名

# Here Document：用 << 定义多行输入
$ cat << EOF
Line 1
Line 2
EOF
Line 1
Line 2

# Here Document 实战：在脚本中写入多行内容
$ cat << 'EOF' > config.ini
[database]
host = localhost
port = 3306
user = admin
EOF
$ cat config.ini
[database]
host = localhost
port = 3306
user = admin
```

### 7.4 管道 `|`

管道将前一个命令的**标准输出**连接到后一个命令的**标准输入**。

```bash
# 基础管道
$ ls -l | head -5

# 管道链：多级处理
$ cat /var/log/syslog | grep "ERROR" | head -20

# 统计当前目录下的文件数量
$ ls | wc -l

# 查看使用最多空间的前 5 个目录
$ du -sh * | sort -rh | head -5
1.2G    videos
500M    photos
200M    documents
100M    downloads
50M     music
```

#### 7.4.1 综合管线实战

**分析日志文件中出现频率最高的 IP 地址：**

```bash
# 假设 access.log 格式为：IP - - [时间] "请求" 状态码 大小
$ cat access.log | head -3
192.168.1.1 - - [27/Jul/2026:10:00:01] "GET /index.html" 200 5123
10.0.0.5 - - [27/Jul/2026:10:00:02] "POST /api/users" 201 1024
192.168.1.1 - - [27/Jul/2026:10:00:03] "GET /about" 200 2048

# 提取 IP 地址
$ awk '{print $1}' access.log | head -3
192.168.1.1
10.0.0.5
192.168.1.1

# 统计 IP 出现次数，排序并取 Top 10
$ awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10
   1523 192.168.1.1
    876 10.0.0.5
    543 172.16.0.100
    234 10.0.0.8
    120 192.168.1.100
     87 192.168.2.50
     45 10.0.0.12
     23 172.16.0.200
     12 10.0.0.3
      8 192.168.1.200
```

#### 7.4.2 管线中每个命令的详解

```bash
# awk '{print $1}'     → 提取每行第一列（IP地址）
# sort                    → 排序（将相同 IP 排在一起，供 uniq 使用）
# uniq -c                 → 统计连续重复行出现的次数
# sort -rn                → 按数字逆序排列（出现次数最高的在前）
# head -10                → 只取前 10 行
```

#### 7.4.3 管道与重定向的实战组合

```bash
# 查找大文件并生成报告
$ find /home -type f -size +100M -exec ls -lh {} \; 2>/dev/null | \
  sort -k5 -h -r > large_files_report.txt

$ cat large_files_report.txt
-rw-r--r-- 1 john staff 1.2G Jul 20 15:00 /home/john/videos/movie.mp4
-rw-r--r-- 1 john staff 500M Jul 18 10:00 /home/john/projects/database.dump
-rw-r--r-- 1 john staff 200M Jul 25 09:00 /home/john/downloads/ubuntu.iso

# 统计代码仓库中各语言的代码行数
$ find . -name "*.py" -o -name "*.js" -o -name "*.ts" | \
  xargs wc -l | sort -rn | head -10
```

## 8. 总结

本章涵盖了 Linux 中最核心和最高频使用的文件与目录操作命令：

| 分类 | 核心命令 | 关键要点 |
|-----|---------|---------|
| 目录浏览 | `pwd`, `ls`, `cd`, `tree` | `ls -lah` 是最常用组合；`cd -` 快速切换 |
| 文件查看 | `cat`, `less`, `head`, `tail`, `file`, `stat`, `wc` | `less` 分页浏览大文件；`tail -f` 实时追踪日志 |
| 文件创建 | `touch`, `mkdir`, `echo`, `nano`, `vim` | `mkdir -p` 递归创建；重定向 `>` 和 `>>` 创建文件 |
| 复制移动 | `cp`, `mv` | `cp -a` 完整备份；`mv` 兼顾重命名和移动 |
| 文件删除 | `rm`, `rmdir` | Linux 无回收站，慎用 `rm -rf` |
| 文件查找 | `find`, `locate`, `which`, `whereis` | `find` 最强大但慢；`locate` 极快但有延迟 |
| 压缩归档 | `tar`, `gzip`, `zip` | `tar -czvf` 是最常用的压缩打包方式 |
| 重定向与管道 | `>`, `>>`, `2>`, `&>`, `\|` | 管道是 Linux 哲学的精髓 |

**核心哲学：**
- Linux 中一切皆文件
- 小命令组合成大功能（管道是灵魂）
- 重定向让你灵活控制数据流
- 删除前多确认，没有回收站
