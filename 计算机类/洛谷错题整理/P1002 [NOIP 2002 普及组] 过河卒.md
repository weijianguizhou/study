## 题目描述

棋盘上 $A$ 点有一个过河卒，需要走到目标 $B$ 点。卒行走的规则：可以向下、或者向右。同时在棋盘上 $C$ 点有一个对方的马，该马所在的点和所有跳跃一步可达的点称为对方马的控制点。因此称之为“马拦过河卒”。

棋盘用坐标表示，$A$ 点 $(0, 0)$、$B$ 点 $(n, m)$，同样马的位置坐标是需要给出的。

![](https://cdn.luogu.com.cn/upload/image_hosting/ipmwl52i.png)

现在要求你计算出卒从 $A$ 点能够到达 $B$ 点的路径的条数，假设马的位置是固定不动的，并不是卒走一步马走一步。

## 输入格式

一行四个正整数，分别表示 $B$ 点坐标和马的坐标。

## 输出格式

一个整数，表示所有的路径条数。

## 输入输出样例 #1

### 输入 #1

```
6 6 3 3

```

### 输出 #1

```
6

```

## 说明/提示

对于 $100 \%$ 的数据，$1 \le n, m \le 20$，$0 \le$ 马的坐标 $\le 20$。

保证起点不是马的控制点。

# 解决方案
## 1. 题目背景（结合你的代码）

- 有一个 **棋盘**，范围是从 `(0,0)` 到 `(a,b)`（a、b 由输入给出）。
    
- 你控制一个 **士兵（solider）** 初始在 `(0,0)`，要去目标点 `(a,b)`。
    
- 士兵只能 **向右** 或 **向下** 移动（每次走一步）。
    
- 棋盘上有一匹 **马（horse）** 在 `(c,d)`，马会控制它自己所在的位置以及它可以一步跳到的 **8 个“日”字位置**。士兵不能走进这些被控制的格子。
    
- 问：**从起点到终点有多少条不同的合法路径**？
    

---

## 2. 问题的核心难点

如果不考虑马的控制，那么从 `(0,0)` 到 `(a,b)` 只能向右/向下走的路径数是一个简单的组合数：

路径数=(a+ba)路径数=(aa+b​)

但加上马的控制点后，我们需要 **避开这些禁止格子**。直接枚举所有路径会爆炸（路径数可能非常大），因此必须用 **动态规划**。

---

## 3. 算法思路（动态规划）

动态规划的核心思想：**用一个小问题的解，逐步推导出大问题的解**。

### 3.1 状态定义

设 `dp[i][j]` 表示从 `(0,0)` 走到 `(i,j)` 的合法路径数目。

### 3.2 转移方程

由于士兵只能从 **上方** `(i-1,j)` 或 **左方** `(i,j-1)` 走过来，因此：

`dp[i][j]=dp[i−1][j]+dp[i][j−1]dp[i][j]=dp[i−1][j]+dp[i][j−1]`

**但前提是** `(i,j)` 本身不是被马控制的格子（如果是，则 `dp[i][j]=0`，因为不能停在那里）。

### 3.3 边界条件

- `dp[0][0] = 1`（如果起点不被马控制，否则为 0）。
    
- 对于 `i=0` 的第一行，只能从左方来，所以 `dp[0][j] = dp[0][j-1]`（如果 `(0,j)` 不被控制）。
    
- 对于 `j=0` 的第一列，只能从上方来，所以 `dp[i][0] = dp[i-1][0]`（如果 `(i,0)` 不被控制）。
    

### 3.4 计算顺序

按行、列递增的顺序计算（外层 `i` 从 0 到 a，内层 `j` 从 0 到 b），这样计算 `dp[i][j]` 时需要的 `dp[i-1][j]` 和 `dp[i][j-1]` 都已经算好了。

---

## 4. 与你的代码对照

- **马的控制点**：代码中先计算出马 `(c,d)` 及其 8 个日字位置，存入 `control` 数组。随后在双重循环中判断当前格子 `(i,j)` 是否在马的位置或任一控制点上。
    
- **DP 数组**：`long long dp[21][21]`（因为题目中 a,b ≤ 20，所以 21 足够），使用 `memset` 初始化为 0。
    
- **转移实现**：

```C++
if (controlled) dp[i][j] = 0;
    else if (i == 0 && j == 0) dp[i][j] = 1;
    else {
        long long sum = 0;
        if (i > 0) sum += dp[i-1][j];
        if (j > 0) sum += dp[i][j-1];
        dp[i][j] = sum;
    }
```
    
- **最终输出**：`dp[a][b]` 即从起点到终点的路径总数。
    
---

## 5. 举例说明

假设棋盘大小 `a=3, b=3`，马在 `(1,1)`。  
马的控制点为：自身 `(1,1)` 加上 `(-1,0)、(3,0)…` 等落在棋盘内的点。我们只考虑 0~3 范围内的格子。

手动算一部分：

- `dp[0][0]=1`
    
- `dp[0][1]=1`（因为 `(0,1)` 不被控制，只能从左来）
    
- `dp[0][2]=1`（不被控制）
    
- `dp[1][0]=1`（不被控制，只能从上来）
    
- `dp[1][1]=0`（被马控制）
    
- `dp[1][2] = dp[0][2]+dp[1][1] = 1+0 = 1`
    
- … 最终得到 `dp[3][3]` 即为答案。
    

---

## 6. 总结

- **问题本质**：带障碍物的网格路径计数（只能右或下）。
    
- **算法**：动态规划，时间复杂度 O(a×b)，空间 O(a×b)（可优化到一行，但本题 a,b ≤ 20 无需优化）。
    
- **关键点**：正确标记所有马控制的格子（马自身+日字位），然后在 DP 中跳过这些格子。

代码：
```C++
#include<iostream>
#include<cstring>
using namespace std;
class solider{
    public:
        int x,y;
        solider(int a,int b){
            x=a;
            y=b;
        }
};

class horse{
    public:
        int x,y;
        horse(int a,int b){
            x=a;
            y=b;
        }
};

  
int main(){
    int a,b,c,d;
    cin>>a>>b>>c>>d;
    solider s(0,0);
    solider destination(a,b);
    horse h(c,d);
    horse control[8]={
        {h.x-2,h.y-1},{h.x-2,h.y+1},
        {h.x-1,h.y-2},{h.x-1,h.y+2},
        {h.x+1,h.y-2},{h.x+1,h.y+2},
        {h.x+2,h.y-1},{h.x+2,h.y+1}
    };

    long long dp[21][21];
    memset(dp, 0, sizeof(dp));//**将从 `dp` 开始、长度为 `sizeof(dp)` 的内存区域全部填充为 0**。
    for (int i = 0; i <= a; i++) {
        for (int j = 0; j <= b; j++) {
            // Check if (i, j) is controlled by horse
            bool controlled = false;
            if (i == h.x && j == h.y) {
                controlled = true;
            } else {
                for (int k = 0; k < 8; k++) {
                    if (i == control[k].x && j == control[k].y) {
                        controlled = true;
                        break;
                    }
                }
            }
            if (controlled) {
                dp[i][j] = 0;
            } else if (i == 0 && j == 0) {
                dp[i][j] = 1;
            } else {
                long long sum = 0;
                if (i > 0) sum += dp[i-1][j];
                if (j > 0) sum += dp[i][j-1];
                dp[i][j] = sum;
            }
        }
    }
    cout << dp[a][b] << endl;
    return 0;
}
```
