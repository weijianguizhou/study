# 数据结构

前面我们存单个变量——一个数、一个字符串。现实里你要处理的通常是一坨数据。Python有四个内置容器：list、tuple、dict、set。这篇挨个讲清楚，每个都带大量例子。

---

# 一、list（列表）

列表是Python最常用的容器——**有序、可变、可重复**。类似C++的`std::vector`。

## 1.1 基本操作

```python
# 创建
fruits = ["苹果", "香蕉", "橘子"]
nums = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]    # 可以混类型

# 索引（从0开始，负数从末尾倒数）
print(fruits[0])     # 苹果
print(fruits[-1])    # 橘子   倒数第一个

# 切片 [start:stop:step]
print(nums[1:4])     # [2, 3, 4]   索引1到3
print(nums[:3])      # [1, 2, 3]   从头到索引2
print(nums[::2])     # [1, 3, 5]   每隔一个取
print(nums[::-1])    # [5, 4, 3, 2, 1]   反向
```

```cmd
苹果
橘子
[2, 3, 4]
[1, 2, 3]
[1, 3, 5]
[5, 4, 3, 2, 1]
```

## 1.2 增删改

```python
fruits = ["苹果", "香蕉"]

# 增加
fruits.append("橘子")              # 加到末尾
fruits.insert(1, "葡萄")           # 在索引1的位置插入
fruits.extend(["西瓜", "芒果"])     # 合并另一个列表

print(fruits)
```

```cmd
['苹果', '葡萄', '香蕉', '橘子', '西瓜', '芒果']
```

```python
# 删除
fruits.pop()          # 弹出最后一个，返回"芒果"
fruits.pop(1)         # 弹出索引1的，返回"葡萄"
fruits.remove("苹果")  # 按值删除（只删第一个匹配的）

print(fruits)
```

```cmd
['香蕉', '橘子', '西瓜']
```

```python
# 修改
nums = [10, 20, 30]
nums[1] = 25
print(nums)           # [10, 25, 30]
```

## 1.3 查找与排序

```python
nums = [5, 2, 8, 1, 9, 2]

print(len(nums))             # 6   长度
print(nums.count(2))         # 2   2出现了几次
print(nums.index(8))         # 2   值8的索引

nums.sort()                  # 原地排序（升序）
print(nums)                  # [1, 2, 2, 5, 8, 9]

nums.sort(reverse=True)      # 降序
print(nums)                  # [9, 8, 5, 2, 2, 1]

# sorted() 返回新列表，不改变原列表
original = [3, 1, 2]
new = sorted(original)
print(original)   # [3, 1, 2]   没变
print(new)        # [1, 2, 3]
```

## 1.4 列表推导式（复习+进阶）

```python
# 基本
squares = [x**2 for x in range(6)]
print(squares)   # [0, 1, 4, 9, 16, 25]

# 带条件
evens = [x for x in range(10) if x % 2 == 0]
print(evens)     # [0, 2, 4, 6, 8]

# 带if-else（注意位置变了）
labels = ["偶数" if x % 2 == 0 else "奇数" for x in range(5)]
print(labels)    # ['偶数', '奇数', '偶数', '奇数', '偶数']
```

# 二、tuple（元组）

元组和列表几乎一样，但有一个关键区别：**不可变**。创建之后不能增删改。因为没有修改操作，元组比列表更轻量、更安全。

```python
# 创建
t1 = (1, 2, 3)
t2 = 4, 5, 6          # 括号可以省略
t3 = (42,)            # 单元素元组必须加逗号！(42)只是带括号的整数

# 和列表一样的用法
print(t1[0])          # 1
print(t1[1:3])        # (2, 3)
print(len(t1))        # 3
print(2 in t1)        # True

# 但不能修改：
# t1[0] = 10          # TypeError!
```

**妙用：多变量交换和返回多值**

```python
# 一行交换两个变量
a, b = 10, 20
a, b = b, a
print(a, b)           # 20 10

# 函数返回多值
def min_max(numbers):
    return min(numbers), max(numbers)

lo, hi = min_max([3, 1, 4, 1, 5, 9])
print(lo, hi)         # 1 9
```

# 三、dict（字典）

字典是**键-值对**的容器。用键来查值——类似哈希表、unordered_map。键必须是不可变类型（字符串、数字、元组都行），值啥都可以。

## 3.1 基本操作

```python
# 创建
student = {"name": "张三", "age": 20, "score": 95}
empty = {}            # 空字典

# 访问
print(student["name"])        # 张三
print(student.get("gender", "未知"))  # 未知  键不存在时不报错，返回默认值

# 增/改
student["gender"] = "男"      # 增加新键值
student["score"] = 97         # 修改已有键
print(student)
```

```cmd
张三
未知
{'name': '张三', 'age': 20, 'score': 97, 'gender': '男'}
```

## 3.2 遍历

```python
student = {"name": "张三", "age": 20, "score": 97}

# 遍历键
for key in student:
    print(key, end=" ")

print()

# 遍历键值对（最常用）
for key, value in student.items():
    print(f"{key}: {value}")
```

```cmd
name age score
name: 张三
age: 20
score: 97
```

## 3.3 字典推导式

```python
# 把列表变字典
fruits = ["苹果", "香蕉", "橘子"]
fruit_len = {f: len(f) for f in fruits}
print(fruit_len)

# 翻转键和值
original = {"a": 1, "b": 2, "c": 3}
reversed_dict = {v: k for k, v in original.items()}
print(reversed_dict)
```

```cmd
{'苹果': 2, '香蕉': 2, '橘子': 2}
{1: 'a', 2: 'b', 3: 'c'}
```

# 四、set（集合）

集合是**无序、不重复**的容器。底层是哈希表。交、并、差运算非常快。

```python
# 创建
s1 = {1, 2, 3, 3, 3}      # 自动去重 → {1, 2, 3}
s2 = set([3, 4, 5])        # 从列表创建

# 去重
nums = [1, 2, 2, 3, 3, 3]
unique = list(set(nums))
print(unique)              # [1, 2, 3]  顺序不保证

# 集合运算
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a & b)      # {3, 4}     交集
print(a | b)      # {1,2,3,4,5,6}  并集
print(a - b)      # {1, 2}     差集（a有b没有的）
print(a ^ b)      # {1,2,5,6}  对称差（只在一边的）

# 增删
a.add(100)                # 加一个
a.remove(1)               # 删一个（不存在会报错）
a.discard(999)            # 删一个（不存在也不报错）
```

```cmd
[1, 2, 3]
{3, 4}
{1, 2, 3, 4, 5, 6}
{1, 2}
{1, 2, 5, 6}
```

## 集合推导式

```python
s = {x*x for x in range(5)}
print(s)    # {0, 1, 4, 9, 16}
```

# 五、怎么选？

| 场景 | 用啥 |
|------|------|
| 有序、可改、可能有重复 | `list` |
| 固定不变的数据（如坐标、RGB值）| `tuple` |
| 用名字查东西（如姓名→成绩）| `dict` |
| 去重、判断存在性、集合运算 | `set` |
