# 控制流与函数

数据有了，现在得学会"怎么处理"。控制流决定代码的执行路线——什么时候走哪条路、什么时候循环。函数把一段逻辑打包起来，重复用。

---

# 一、条件判断：if / elif / else

Python的条件判断就三个关键字。语法上**靠缩进来圈定代码块**（不像C靠大括号），这是Python最显著的特征。

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("D")
```

```cmd
B
```

**注意**：`elif`不是`else if`——Python把它缩成一个词了。缩进必须一致（4个空格是惯例，别混用Tab）。

条件可以是任意值——Python会把非零、非空的东西当`True`：

```python
x = [1, 2, 3]      # 非空列表 → True
if x:
    print("列表有东西")

s = ""             # 空字符串 → False
if not s:
    print("字符串是空的")
```

```cmd
列表有东西
字符串是空的
```

# 二、循环

## 2.1 for 循环

Python的`for`跟C不一样。它**不是**`for(i=0; i<n; i++)`那种计数循环，而是**遍历一个可迭代对象里的每个元素**：

```python
# 遍历列表
fruits = ["苹果", "香蕉", "橘子"]
for f in fruits:
    print(f"我喜欢{f}")
```

```cmd
我喜欢苹果
我喜欢香蕉
我喜欢橘子
```

想计数怎么办？用`range()`：

```python
# range(n): 0, 1, 2, ..., n-1
for i in range(5):
    print(i, end=" ")
```

```cmd
0 1 2 3 4
```

```python
# range(start, stop, step)
for i in range(10, 0, -2):   # 10, 8, 6, 4, 2
    print(i, end=" ")
```

```cmd
10 8 6 4 2
```

要是需要同时拿索引和值，用`enumerate()`：

```python
fruits = ["苹果", "香蕉", "橘子"]
for i, f in enumerate(fruits):
    print(f"{i}: {f}")
```

```cmd
0: 苹果
1: 香蕉
2: 橘子
```

## 2.2 while 循环

```python
count = 0
while count < 3:
    print(f"第{count+1}次")
    count += 1
```

```cmd
第1次
第2次
第3次
```

## 2.3 break 和 continue

```python
# break: 直接跳出循环
for i in range(10):
    if i == 4:
        break
    print(i, end=" ")
```
```cmd
0 1 2 3
```

```python
# continue: 跳过本次，进入下一次
for i in range(6):
    if i % 2 == 0:    # 偶数就跳过
        continue
    print(i, end=" ")
```
```cmd
1 3 5
```

# 三、函数

## 3.1 定义和调用

```python
def add(a, b):
    """返回a和b的和（这是文档字符串）"""
    return a + b

result = add(3, 5)
print(result)        # 8
print(add("Hello", "World"))  # "HelloWorld"  字符串也能加
```

Python函数不用写返回类型（3.5以后可以写类型注释，但不强制）。三引号里的字符串叫**docstring**——函数的说明书。

## 3.2 默认参数

```python
def greet(name, greeting="你好"):
    return f"{greeting}，{name}！"

print(greet("张三"))              # 你好，张三！
print(greet("李四", "早上好"))     # 早上好，李四！
```

**警告**：默认参数不要用可变对象（比如空列表）！

```python
# 坑！
def bad_idea(items=[]):     # 这个空列表只创建一次，所有调用共享
    items.append(1)
    return items

print(bad_idea())   # [1]
print(bad_idea())   # [1, 1]  出乎意料！
```

正确写法：

```python
def good_idea(items=None):
    if items is None:
        items = []
    items.append(1)
    return items
```

## 3.3 可变参数 *args 和 **kwargs

```python
# *args: 接收任意数量位置参数，打包成元组
def sum_all(*numbers):
    return sum(numbers)

print(sum_all(1, 2, 3, 4))     # 10

# **kwargs: 接收任意数量关键字参数，打包成字典
def print_info(**info):
    for key, value in info.items():
        print(f"{key}: {value}")

print_info(name="张三", age=20, city="北京")
```

```cmd
10
name: 张三
age: 20
city: 北京
```

## 3.4 返回多个值

Python函数可以"返回多个值"——其实返回的是一个元组：

```python
def divmod_custom(a, b):
    return a // b, a % b

quotient, remainder = divmod_custom(10, 3)
print(f"商={quotient}, 余={remainder}")
```

```cmd
商=3, 余=1
```

## 3.5 lambda（匿名函数）

一行能写完的简单函数，用`lambda`：

```python
square = lambda x: x * x
print(square(5))   # 25

# 常用在排序、过滤里
pairs = [(1, "一"), (3, "三"), (2, "二")]
pairs.sort(key=lambda p: p[0])   # 按第一个元素排序
print(pairs)
```

```cmd
25
[(1, '一'), (2, '二'), (3, '三')]
```

# 四、列表推导式

这玩意儿是Python的精髓之一——把循环和条件浓缩到一行里。

```python
# 生成0到9的平方
squares = [x*x for x in range(10)]
print(squares)
```

```cmd
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```

```python
# 只保留偶数的平方
even_squares = [x*x for x in range(10) if x % 2 == 0]
print(even_squares)
```

```cmd
[0, 4, 16, 36, 64]
```

```python
# 嵌套循环的推导式
pairs = [(x, y) for x in "AB" for y in "12"]
print(pairs)
```

```cmd
[('A', '1'), ('A', '2'), ('B', '1'), ('B', '2')]
```

不仅列表有推导式，字典和集合也有（后面讲）。

# 五、异常处理

程序遇到错误不应该直接崩——应该优雅地处理。

```python
try:
    num = int(input("输入一个数字: "))
    print(f"100 / {num} = {100 / num}")
except ValueError:
    print("叫你输入数字，输了个啥玩意儿")
except ZeroDivisionError:
    print("分母不能是零！初中数学白学了？")
except Exception as e:
    print(f"未知错误: {e}")
else:
    print("没出错，完美执行")      # try没抛异常才走这里
finally:
    print("不管出不出错，我都执行")  # 清理资源放这里
```
