# 文件IO与模块

程序光在内存里跑没意义——数据得读进来、结果得写出去。还得学会把代码拆到多个文件里。这篇搞定这两件事。

# 一、读写文件

## 1.1 基础操作

```python
# 写文件
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("你好，世界\n")
    f.write("第二行\n")

# 读文件
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()          # 一次性全读
    print(content)
```

```cmd
你好，世界
第二行
```

**`with`语句**自动管理文件——退出`with`块自动关闭文件，不用手动`f.close()`。**永远用`with`**。

`encoding="utf-8"`必须写。Windows上默认是GBK，不写的话中文会乱码。Python 3里默认可能也是系统编码，不确定就显式写`utf-8`。

## 1.2 打开模式

| 模式 | 含义 |
|------|------|
| `"r"` | 只读（默认）|
| `"w"` | 写。**文件存在就清空**，不存在就创建 |
| `"a"` | 追加。存在就往后写，不存在就创建 |
| `"r+"` | 读写 |
| `"b"` | 二进制模式（如`"rb"`读图片）|

```python
# 追加模式
with open("test.txt", "a", encoding="utf-8") as f:
    f.write("追加的第三行\n")
```

## 1.3 逐行处理

大文件不要一次性`read()`——内存撑爆。逐行读：

```python
with open("test.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(f"读到: {line.strip()}")   # strip()去掉末尾的换行符
```

```cmd
读到: 你好，世界
读到: 第二行
读到: 追加的第三行
```

`f.readlines()`返回一个列表，每行一个元素。但同样——大文件别用。

## 1.4 CSV文件

CSV就是用逗号分隔的值表格。Python自带`csv`模块：

```python
import csv

# 写CSV
data = [
    ["姓名", "年龄", "成绩"],
    ["张三", 20, 95],
    ["李四", 21, 88],
]

with open("students.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(data)

# 读CSV
with open("students.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

```cmd
['姓名', '年龄', '成绩']
['张三', '20', '95']
['李四', '21', '88']
```

`newline=""`是为了防止Windows下多出空行。

# 二、模块与包

## 2.1 import 的三种写法

```python
import math               # 全部导入，用math.xxx
from math import sqrt     # 只导入sqrt，直接用
from math import *        # 全导入到当前命名空间（不推荐，容易冲突）
import numpy as np        # 重命名，简洁
```

## 2.2 常用内置模块速览

```python
# math — 数学函数
import math
print(math.pi)            # 3.141592653589793
print(math.sqrt(16))      # 4.0
print(math.sin(math.pi/2))  # 1.0

# random — 随机数
import random
print(random.randint(1, 10))      # 1到10的随机整数
print(random.random())            # 0到1的随机浮点数
print(random.choice(["A","B","C"]))  # 随机选一个

# datetime — 日期时间
from datetime import datetime
now = datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))   # 格式化输出
print(now.strftime("%Y年%m月%d日"))

# os — 操作系统接口
import os
print(os.getcwd())        # 当前工作目录
print(os.listdir("."))    # 列出当前目录下有哪些文件
```

## 2.3 自己写模块

在同一个文件夹下创建`mymath.py`：

```python
# mymath.py
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

PI = 3.14159
```

然后在另一个文件里用：

```python
# main.py
import mymath

print(mymath.add(3, 5))       # 8
print(mymath.PI)              # 3.14159
```

Python找模块的路径是：当前目录 → 环境变量`PYTHONPATH`里的目录 → 标准库目录。所以同目录下的`.py`文件直接能当模块用。

## 2.4 if __name__ == "__main__"

写脚本的时候经常看到这行。它的意思是："如果这个文件是被直接运行的，执行下面的代码；如果是被import的，别执行"。

```python
# mymath.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    # 直接运行 python mymath.py 时才执行
    print("测试: 3 + 5 =", add(3, 5))
```

这样别人`import mymath`的时候不会莫名其妙跑出来测试输出。

# 三、json处理

JSON是数据交换的通用格式。Python里`json`模块把JSON和dict互转：

```python
import json

# Python对象 → JSON字符串
data = {
    "name": "张三",
    "age": 20,
    "hobbies": ["编程", "跑步"],
    "married": False
}
json_str = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str)
```

```cmd
{
  "name": "张三",
  "age": 20,
  "hobbies": ["编程", "跑步"],
  "married": false
}
```

```python
# JSON字符串 → Python对象
json_str = '{"name": "李四", "score": 95}'
obj = json.loads(json_str)
print(obj["name"])    # 李四

# 读写JSON文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open("data.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
print(loaded["name"])   # 张三
```

`ensure_ascii=False`让中文正常显示而不是`\uXXXX`。`indent=2`让输出整齐。

# 四、异常处理进阶

```python
# 手动抛出异常
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为零")
    return a / b

try:
    print(divide(10, 0))
except ValueError as e:
    print(f"出错了: {e}")
```

```cmd
出错了: 除数不能为零
```
