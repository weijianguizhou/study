# 第10章：排序

## 10.1 排序的基本概念

### 排序的定义

**排序（Sorting）**是将一组"无序"的记录序列调整为"有序"的记录序列的操作。假设含有 $n$ 个记录的序列为：

$$\{R_1, R_2, \dots, R_n\}$$

其相应的关键字序列为 $\{K_1, K_2, \dots, K_n\}$。排序就是要确定一种排列 $p(1), p(2), \dots, p(n)$，使得相应的关键字满足下列**非递减**（或非递增）关系：

$$K_{p(1)} \le K_{p(2)} \le \dots \le K_{p(n)}$$

### 稳定性

| 概念 | 定义 |
|------|------|
| **稳定排序（Stable Sort）** | 关键字相等的任意两个记录，排序前后相对位置保持不变 |
| **不稳定排序（Unstable Sort）** | 关键字相等的记录在排序后相对位置可能改变 |

> 例如：序列 `[(A,3), (B,1), (C,3)]` 按数字排序。稳定排序后 `(B,1)` 在前，`(A,3)` 在 `(C,3)` 之前（保持原相对顺序）。不稳定排序则可能让 `(C,3)` 排在 `(A,3)` 前面。

### 内部排序 vs 外部排序

| 类型 | 定义 |
|------|------|
| **内部排序** | 整个排序过程不需要访问外存便能完成（数据全部放在内存中） |
| **外部排序** | 待排序记录的数量很大，内存一次容纳不下，需要访问外存的排序 |

本章集中讨论**内部排序**。

### 排序方法分类

| 类别 | 代表算法 | 核心思想 |
|------|----------|----------|
| **插入类** | 直接插入排序、折半插入排序、希尔排序 | 将无序子序列中的一个或几个记录插入到有序序列中 |
| **交换类** | 冒泡排序、快速排序 | 通过交换逆序元素进行排序 |
| **选择类** | 简单选择排序、堆排序 | 从记录的无序子序列中选择关键字最小或最大的记录，将它加入到有序子序列中 |
| **归并类** | 归并排序 | 通过归并两个或两个以上的有序子序列逐步增加有序序列的长度 |
| **其他** | 基数排序 | 多关键字排序思想 |

## 10.2 插入排序类

### 10.2.1 直接插入排序（Straight Insertion Sort）

#### 算法思想

将待排序的记录按其关键字值的大小逐个插入到一个已经排好序的有序序列中，直到所有记录插入完为止。

**形象理解**：类似于打扑克牌时摸牌整理的过程——每次摸一张新牌，从右向左扫描手中的牌，找到合适位置插入。

#### 哨兵优化

设置 `a[0]` 作为**监视哨（Sentinel）**，存放待插入的元素。从后向前查找插入位置时，哨兵作为"边界"，避免每次判断是否越界。

#### 算法步骤

1. 假设第一个元素 `a[0]`（或 `a[1]`）已自然有序
2. 从第 $i$ 个（$i=2,3,\dots,n$）元素开始，取出 `a[i]` 暂存
3. 在 `a[0..i-1]` 中从后向前查找 `a[i]` 应插入的位置 `j`
4. 将 `a[j+1..i-1]` 的元素向后移动一位
5. 将 `a[i]` 插入位置 `j`

#### 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|-----------|------|
| **最好情况** | $O(n)$ | 初始序列为正序（已有序），每趟只比较 1 次，不移动 |
| **最坏情况** | $O(n^2)$ | 初始序列为逆序，每趟比较 $i$ 次，移动 $i+1$ 次 |
| **平均情况** | $O(n^2)$ | 等概率下比较 $n^2/4$ 次 |
| **空间复杂度** | $O(1)$ | 仅需常数辅助空间 |
| **稳定性** | **稳定** | 从后向前查找，相等时不后移 |

#### 排序过程演示

```
初始序列: [49, 38, 65, 97, 76, 13, 27, 49#]

第1趟: [38] 插入到 49 前面 -> [38, 49, 65, 97, 76, 13, 27, 49#]
第2趟: [65] 已在正确位置    -> [38, 49, 65, 97, 76, 13, 27, 49#]
第3趟: [97] 已在正确位置    -> [38, 49, 65, 97, 76, 13, 27, 49#]
第4趟: [76] 插入到 97 前面 -> [38, 49, 65, 76, 97, 13, 27, 49#]
第5趟: [13] 插入到最前面    -> [13, 38, 49, 65, 76, 97, 27, 49#]
第6趟: [27] 插入到 38 前面 -> [13, 27, 38, 49, 65, 76, 97, 49#]
第7趟: [49#]插入到 65 前面 -> [13, 27, 38, 49, 49#, 65, 76, 97]
最终:                       [13, 27, 38, 49, 49#, 65, 76, 97]
```

> 注意：`49#` 仍然在 `49` 的后面，体现了**稳定性**。


#### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 直接插入排序（带哨兵）
// a[0] 作为哨兵，实际数据从 a[1] 到 a[n]
void InsertSort(vector<int>& a) {
    int n = a.size() - 1;
    for (int i = 2; i <= n; i++) {
        if (a[i] < a[i - 1]) {
            a[0] = a[i];
            a[i] = a[i - 1];
            int j;
            for (j = i - 2; a[0] < a[j]; j--)
                a[j + 1] = a[j];
            a[j + 1] = a[0];
        }
    }
}

// 直接插入排序（无哨兵、下标从0开始）
void InsertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

int main() {
    vector<int> a1 = {0, 49, 38, 65, 97, 76, 13, 27, 49};
    InsertSort(a1);
    cout << "带哨兵版本: ";
    for (int i = 1; i < (int)a1.size(); i++)
        cout << a1[i] << " ";
    cout << endl;

    vector<int> a2 = {49, 38, 65, 97, 76, 13, 27, 49};
    InsertionSort(a2);
    cout << "无哨兵版本: ";
    for (int x : a2) cout << x << " ";
    cout << endl;
    return 0;
}
```

### 10.2.2 折半插入排序（Binary Insertion Sort）

#### 算法思想

在直接插入排序的基础上，用**折半查找**确定插入位置，从而减少比较次数。但记录的**移动次数不变**（仍需依次后移）。

> 由于仅减少了比较次数（从 $O(n)$ 降到 $O(\log n)$），而移动次数仍是 $O(n)$，因此总体时间复杂度仍为 $O(n^2)$。

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

void BinaryInsertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int low = 0, high = i - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (key < arr[mid])
                high = mid - 1;
            else
                low = mid + 1;
        }
        for (int j = i - 1; j >= low; j--)
            arr[j + 1] = arr[j];
        arr[low] = key;
    }
}

int main() {
    vector<int> a = {49, 38, 65, 97, 76, 13, 27};
    BinaryInsertionSort(a);
    for (int x : a) cout << x << " ";
    cout << endl;
    return 0;
}
```

#### Python 实现

```python
from typing import List

def binary_insertion_sort(arr: List[int]) -> None:
    n = len(arr)
    for i in range(1, n):
        key = arr[i]
        low, high = 0, i - 1
        while low <= high:
            mid = low + (high - low) // 2
            if key < arr[mid]:
                high = mid - 1
            else:
                low = mid + 1
        for j in range(i - 1, low - 1, -1):
            arr[j + 1] = arr[j]
        arr[low] = key


if __name__ == "__main__":
    a = [49, 38, 65, 97, 76, 13, 27]
    binary_insertion_sort(a)
    print(a)  # [13, 27, 38, 49, 65, 76, 97]
```

### 10.2.3 希尔排序（Shell Sort）

#### 算法思想

希尔排序是插入排序的一种改进，其核心思想是：通过**增量（Gap）**将序列分成若干个子序列，先让这些子序列基本有序，然后再对全体序列进行插入排序。

由于插入排序在"基本有序"时效率很高（接近 $O(n)$），希尔排序通过"大步跳跃"的方式快速减少逆序对。

#### 增量序列

常见的增量序列：
- **Shell 原始序列**：$d_k = \lfloor n/2 \rfloor, \lfloor n/4 \rfloor, \dots, 1$
- **Hibbard 序列**：$d_k = 2^k - 1$（如 1, 3, 7, 15, ...）
- **Knuth 序列**：$d_k = (3^k - 1) / 2$（如 1, 4, 13, 40, ...）

#### 算法步骤

令增量 $gap$ 从 $n/2$ 递减到 1，对于每个 $gap$：

1. 将序列分成 $gap$ 个子序列：索引为 $i, i+gap, i+2gap, \dots$ 的属于同一个子序列
2. 对每个子序列进行**直接插入排序**
3. 减小增量，重复上述过程，直到 $gap=1$

#### 排序过程演示

```
初始: [49, 38, 65, 97, 76, 13, 27, 49, 55, 4]

gap=5:
  下标0,5 ->  49,13  -> [13, 49]
  下标1,6 ->  38,27  -> [27, 38]
  下标2,7 ->  65,49  -> [49, 65]
  下标3,8 ->  97,55  -> [55, 97]
  下标4,9 ->  76,4   -> [4, 76]
  -> [13, 27, 49, 55, 4, 49, 38, 65, 97, 76]

gap=3:
  下标0,3,6,9 -> 13,55,38,76 -> [13, 38, 55, 76]
  下标1,4,7   -> 27,4,65     -> [4, 27, 65]
  下标2,5,8   -> 49,49,97    -> [49, 49, 97]
  -> [13, 4, 49, 38, 27, 49, 55, 65, 97, 76]

gap=1: 最终插入排序
  -> [4, 13, 27, 38, 49, 49, 55, 65, 76, 97]
```

#### 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|-----------|------|
| **最好情况** | $O(n \log n)$ | 取决于增量序列 |
| **平均情况** | $O(n^{1.3})$ 至 $O(n^{1.5})$ | 与增量序列有关 |
| **最坏情况** | $O(n^2)$ | 使用 Shell 原始序列时 |
| **空间复杂度** | $O(1)$ | |
| **稳定性** | **不稳定** | 跳跃式移动会打乱相等元素的相对位置 |

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

void ShellSort(vector<int>& arr) {
    int n = arr.size();
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j;
            for (j = i; j >= gap && arr[j - gap] > temp; j -= gap) {
                arr[j] = arr[j - gap];
            }
            arr[j] = temp;
        }
        cout << "gap=" << gap << ": ";
        for (int x : arr) cout << x << " ";
        cout << endl;
    }
}

int main() {
    vector<int> a = {49, 38, 65, 97, 76, 13, 27, 49, 55, 4};
    ShellSort(a);
    return 0;
}
```

#### Python 实现

```python
from typing import List

def shell_sort(arr: List[int]) -> None:
    """希尔排序，使用 Shell 原始增量 n/2"""
    n = len(arr)
    gap = n // 2
    while gap > 0:
        for i in range(gap, n):
            temp = arr[i]
            j = i
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        print(f"gap={gap}: {arr}")
        gap //= 2


def shell_sort_knuth(arr: List[int]) -> None:
    """希尔排序，使用 Knuth 增量序列 (3^k - 1) / 2"""
    n = len(arr)
    gap = 1
    while gap < n // 3:
        gap = gap * 3 + 1
    while gap > 0:
        for i in range(gap, n):
            temp = arr[i]
            j = i
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        gap //= 3


if __name__ == "__main__":
    print("===== Shell 原始增量 =====")
    a = [49, 38, 65, 97, 76, 13, 27, 49, 55, 4]
    shell_sort(a)

    print("\n===== Knuth 增量 =====")
    b = [49, 38, 65, 97, 76, 13, 27, 49, 55, 4]
    shell_sort_knuth(b)
```

## 10.3 交换排序类

### 10.3.1 冒泡排序（Bubble Sort）

#### 算法思想

从第一个元素开始，依次比较相邻两个元素的关键字，若为逆序（`a[j] > a[j+1]`），则交换。一趟扫描后，最大（或最小）的元素"沉"到最后。**重复 $n-1$ 趟**，每趟确定一个元素的最终位置。

#### 优化：提前终止

若在某趟扫描中**未发生任何交换**，说明序列已经有序，可以提前终止排序。

#### 排序过程演示

```
初始: [49, 38, 65, 97, 76, 13, 27]
     -------------------
第1趟: 38,49,65,76,13,27,|97   (97 沉底)
第2趟: 38,49,65,13,27,|76,97   (76 沉底)
第3趟: 38,49,13,27,|65,76,97   (65 沉底)
第4趟: 38,13,27,|49,65,76,97   (49 沉底)
第5趟: 13,27,|38,49,65,76,97   (38 沉底)
第6趟: 13,|27,38,49,65,76,97   (27 沉底)
最终:  13,27,38,49,65,76,97
```

#### 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|-----------|------|
| **最好情况** | $O(n)$ | 正序（已有序），第一趟无交换即结束 |
| **最坏情况** | $O(n^2)$ | 逆序 |
| **平均情况** | $O(n^2)$ | |
| **空间复杂度** | $O(1)$ | |
| **稳定性** | **稳定** | 相邻交换，相等时不交换 |


#### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 冒泡排序（基本版）
void BubbleSort_Basic(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1])
                swap(arr[j], arr[j + 1]);
        }
    }
}

// 冒泡排序（优化版：提前终止）
void BubbleSort_Optimized(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

// 冒泡排序（进阶版：记录最后交换位置）
void BubbleSort_Advanced(vector<int>& arr) {
    int n = arr.size();
    int lastSwap = n - 1;
    while (lastSwap > 0) {
        int bound = lastSwap;
        lastSwap = 0;
        for (int j = 0; j < bound; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                lastSwap = j;
            }
        }
    }
}

int main() {
    vector<int> a1 = {49, 38, 65, 97, 76, 13, 27};
    BubbleSort_Basic(a1);
    cout << "基本版: ";
    for (int x : a1) cout << x << " "; cout << endl;

    vector<int> a2 = {49, 38, 65, 97, 76, 13, 27};
    BubbleSort_Optimized(a2);
    cout << "优化版: ";
    for (int x : a2) cout << x << " "; cout << endl;

    vector<int> a3 = {49, 38, 65, 97, 76, 13, 27};
    BubbleSort_Advanced(a3);
    cout << "进阶版: ";
    for (int x : a3) cout << x << " "; cout << endl;
    return 0;
}
```

#### Python 实现

```python

        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]

def bubble_sort_optimized(arr: List[int]) -> None:

    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]

        if not swapped:

def bubble_sort_advanced(arr: List[int]) -> None:

        last_swap = 0
        for j in range(bound):

                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                last_swap = j

    print(f"优化版: {a2}")

    bubble_sort_advanced(a3)
    print(f"进阶版: {a3}")
```

### 10.3.2 快速排序（Quick Sort）

#### 算法思想

快速排序是目前实践中**最快的内部排序算法之一**，使用**分治法（Divide and Conquer）**策略：

1. 从待排序序列中选择一个元素作为**枢轴（Pivot）**
2. 通过一趟**划分（Partition）**，将序列分为两部分：左半部分关键字 $\le$ 枢轴，右半部分关键字 $\ge$ 枢轴
3. 递归地对左右两部分继续快速排序

#### 划分算法（Partition）

**方法一：Hoare 双指针法**——设置左右指针 `i, j`，`i` 从左向右扫描，`j` 从右向左扫描。当 `i` 遇到大于等于枢轴的元素、`j` 遇到小于等于枢轴的元素时，交换它们。最后 `i` 和 `j` 相遇的位置就是枢轴的位置。

**方法二：Lomuto 分区法**——用 `pivot` 选最后一个元素，维护变量 `i` 标记小于枢轴区域的边界。遍历数组，每遇到小于枢轴的元素就与 `i+1` 位置交换。

#### 枢轴选择策略

| 策略 | 优点 | 缺点 |
|------|------|------|
| **首元素** | 实现简单 | 在有序/逆序时退化为 $O(n^2)$ |
| **随机选择** | 降低最坏情况概率 | 随机数生成有开销 |
| **三数取中法** | 平衡性能和实现复杂度 | 需多次比较 |

#### 优化策略

1. **小数组切换插入排序**：当子数组长度较小时（如 $< 10$），使用插入排序更快
2. **尾递归优化**：先递归较短的那一半，用循环处理较长的一半，控制递归栈深度为 $O(\log n)$
3. **三向切分**：处理大量重复元素时，将数组分为小于、等于、大于枢轴三部分

#### 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|-----------|------|
| **最好情况** | $O(n \log n)$ | 每次划分均匀（枢轴将序列平分） |
| **平均情况** | $O(n \log n)$ | |
| **最坏情况** | $O(n^2)$ | 序列有序（枢轴每次选到最值） |
| **空间复杂度** | $O(\log n)$ | 递归栈深度（平均情况），最坏 $O(n)$ |
| **稳定性** | **不稳定** | 划分过程中相等元素的相对位置可能改变 |

```cpp
int partition_lomuto(vector<int>& arr, int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return i + 1;
}

// Hoare 双指针分区法
int partition_hoare(vector<int>& arr, int low, int high) {
    int pivot = arr[low];
    int i = low, j = high;
    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;
        if (i < j) arr[i++] = arr[j];
        while (i < j && arr[i] <= pivot) i++;
        if (i < j) arr[j--] = arr[i];
    }
    arr[i] = pivot;
    return i;
}

// 三数取中 + Hoare 分区
int medianOfThree(vector<int>& arr, int low, int high) {
    int mid = low + (high - low) / 2;
    if (arr[low] > arr[mid]) swap(arr[low], arr[mid]);
    if (arr[low] > arr[high]) swap(arr[low], arr[high]);
    if (arr[mid] > arr[high]) swap(arr[mid], arr[high]);
    swap(arr[low], arr[mid]);
    return arr[low];
}

    if (high - low + 1 <= 10) {

            arr[j + 1] = key;

    stk.push({0, (int)arr.size() - 1});
    while (!stk.empty()) {
        auto [low, high] = stk.top();
        stk.pop();
        if (low >= high) continue;
        int pivotIdx = partition_hoare(arr, low, high);
        if (pivotIdx - low > high - pivotIdx) {
            if (low < pivotIdx - 1) stk.push({low, pivotIdx - 1});
            if (pivotIdx + 1 < high) stk.push({pivotIdx + 1, high});

            if (pivotIdx + 1 < high) stk.push({pivotIdx + 1, high});
            if (low < pivotIdx - 1) stk.push({low, pivotIdx - 1});
        }
    }
```

## 10.4 选择排序类

### 10.4.1 简单选择排序（Simple Selection Sort）

#### 算法思想

第 $i$ 趟（$i = 0, 1, \dots, n-2$）从无序区 $[i, n-1]$ 中选出关键字**最小**的记录，将其与第 $i$ 个位置的记录交换。经过 $n-1$ 趟后，排序完成。

#### 复杂度分析

| 项目 | 数值 |
|------|------|
| **比较次数** | $\sum_{i=1}^{n-1} (n-i) = \frac{n(n-1)}{2}$（固定，与初始状态无关）|
| **移动次数** | 最好 $0$ 次（已有序），最坏 $3(n-1)$ 次 |
| **时间复杂度** | $O(n^2)$ |
| **空间复杂度** | $O(1)$ |
| **稳定性** | **不稳定**（交换可能打乱相等元素顺序）|

> 例如 `[5, 5, 2]` -> 选择排序交换第一个 5 和 2，导致第一个 5 排到第二个 5 后面。

#### 排序过程演示

```
初始: [49, 38, 65, 97, 76, 13, 27]
第1趟: [13], 38, 65, 97, 76, 49, 27   (选 13)
第2趟: [13, 27], 65, 97, 76, 49, 38   (选 27)
第3趟: [13, 27, 38], 97, 76, 49, 65   (选 38)
第4趟: [13, 27, 38, 49], 76, 97, 65   (选 49)
第5趟: [13, 27, 38, 49, 65], 97, 76   (选 65)
第6趟: [13, 27, 38, 49, 65, 76], 97   (选 76)
最终:  [13, 27, 38, 49, 65, 76, 97]
```


#### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

void SelectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx])
                minIdx = j;
        }
        if (minIdx != i)
            swap(arr[i], arr[minIdx]);
    }
}

int main() {
    vector<int> a = {49, 38, 65, 97, 76, 13, 27};
    SelectionSort(a);
    for (int x : a) cout << x << " ";
    cout << endl;
    return 0;
}
```

### 10.4.2 堆排序（Heap Sort）

#### 堆的定义

堆是一个**完全二叉树**，且每个结点的值与其孩子结点的值之间存在特定的大小关系：

- **大顶堆（Max Heap）**：每个结点的值都**大于或等于**其左右孩子结点的值（$K_i \ge K_{2i+1}$ 且 $K_i \ge K_{2i+2}$）
- **小顶堆（Min Heap）**：每个结点的值都**小于或等于**其左右孩子结点的值（$K_i \le K_{2i+1}$ 且 $K_i \le K_{2i+2}$）

#### 数组下标关系（从0开始）

| 关系 | 表达式 |
|------|--------|
| 结点 $i$ 的左孩子 | $2i + 1$ |
| 结点 $i$ 的右孩子 | $2i + 2$ |
| 结点 $i$ 的父结点 | $\lfloor (i-1)/2 \rfloor$ |
| 最后一个非叶结点 | $\lfloor n/2 \rfloor - 1$ |

#### 堆调整（AdjustDown / Heapify）

当一个结点的左右子树都已满足堆的性质，但根结点本身可能违反堆的性质时，调用**向下调整**操作：

1. 将根结点与其两个孩子中较大者（大顶堆）比较
2. 若根结点小于较大孩子，则交换
3. 递归向下调整被交换的子树

时间复杂度：$O(\log n)$（即树的高度）。

#### 建堆（Build Heap）——Floyd 算法

从最后一个非叶结点（$\lfloor n/2 \rfloor - 1$）开始，自底向上依次对每个结点执行 `AdjustDown`。**建堆的时间复杂度为 $O(n)$**（而非 $O(n \log n)$）：

$$T(n) = \sum_{k=1}^{\lfloor \log_2 n \rfloor} 2^{k-1} \cdot (\lfloor \log_2 n \rfloor - k) \approx O(n)$$

其中 $2^{k-1}$ 是第 $k$ 层结点数，$(\lfloor \log_2 n \rfloor - k)$ 是向下调整的最大层数。

#### 排序过程

1. **建堆**：将无序序列建成大顶堆（升序排序用大顶堆，降序用小顶堆）
2. **交换**：将堆顶（最大值）与末尾元素交换，堆大小减 1
3. **调整**：对新的堆顶执行 `AdjustDown`，恢复堆性质
4. 重复步骤 2、3，共 $n-1$ 次

#### 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| **时间复杂度** | $O(n \log n)$（建堆 $O(n)$ + $n-1$ 次调整每次 $O(\log n)$）|
| **空间复杂度** | $O(1)$ |
| **稳定性** | **不稳定**（交换堆顶和堆尾可能打乱相等元素顺序）|

#### 排序过程演示

```
初始: [49, 38, 65, 97, 76, 13, 27]

建大顶堆后: [97, 76, 65, 49, 38, 13, 27]

第1趟: 交换97<->27, 堆调整 -> [76, 49, 65, 27, 38, 13,   | 97]
第2趟: 交换76<->13, 堆调整 -> [65, 49, 13, 27, 38,   | 76, 97]
第3趟: 交换65<->38, 堆调整 -> [49, 38, 13, 27,   | 65, 76, 97]
第4趟: 交换49<->27, 堆调整 -> [38, 27, 13,   | 49, 65, 76, 97]
第5趟: 交换38<->13, 堆调整 -> [27, 13,   | 38, 49, 65, 76, 97]
第6趟: 交换27<->13, 堆调整 -> [13,   | 27, 38, 49, 65, 76, 97]
最终:  [13, 27, 38, 49, 65, 76, 97]
```

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 堆调整（大顶堆），向下调整
void AdjustDown(vector<int>& arr, int parent, int len) {
    int temp = arr[parent];
    int child = 2 * parent + 1; // 左孩子
    while (child < len) {
        // 选较大的孩子
        if (child + 1 < len && arr[child + 1] > arr[child])
            child++;
        // 父节点 > 最大孩子，OK
        if (temp >= arr[child]) break;
        // 孩子上移
        arr[parent] = arr[child];
        parent = child;
        child = 2 * parent + 1;
    }
    arr[parent] = temp;
}

// 建堆
void BuildHeap(vector<int>& arr) {
    int n = arr.size();
    for (int i = n / 2 - 1; i >= 0; i--)
        AdjustDown(arr, i, n);
}

// 堆排序
void HeapSort(vector<int>& arr) {
    BuildHeap(arr);
    int n = arr.size();
    // 依次将堆顶与末尾交换，再调整
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]);
        AdjustDown(arr, 0, i); // 堆大小减 1
    }
}

int main() {
    vector<int> a = {49, 38, 65, 97, 76, 13, 27};
    HeapSort(a);
    for (int x : a) cout << x << " ";
    cout << endl;
    return 0;
}
```

```python
def adjust_down(arr: List[int], parent: int, length: int) -> None:

    temp = arr[parent]
    child = 2 * parent + 1
    while child < length:
        if child + 1 < length and arr[child + 1] > arr[child]:
            child += 1
        if temp >= arr[child]:
            break
        arr[parent] = arr[child]
        parent = child
        child = 2 * parent + 1
```

## 10.5 归并排序（Merge Sort）

### 算法思想

归并排序基于**分治法**，将两个或两个以上的有序子序列归并为一个新的有序序列。基本思想：

1. **分解**：将含 $n$ 个记录的序列递归地分成两个长度大致相等的子序列
2. **求解**：递归地对两个子序列进行归并排序
3. **合并**：将两个有序子序列归并为一个有序序列

### 二路归并（Merge Two Sorted Arrays）

```cpp
// 将有序子数组 a[low..mid] 和 a[mid+1..high] 归并
void Merge(vector<int>& arr, int low, int mid, int high) {
    vector<int> temp(high - low + 1);
    int i = low, j = mid + 1, k = 0;
    while (i <= mid && j <= high) {
        if (arr[i] <= arr[j])
            temp[k++] = arr[i++];
        else
            temp[k++] = arr[j++];
    }
    while (i <= mid)  temp[k++] = arr[i++];
    while (j <= high) temp[k++] = arr[j++];
    for (i = 0; i < k; i++) arr[low + i] = temp[i];
}
```

### 排序过程演示

```
初始: [49, 38, 65, 97, 76, 13, 27]

递归分解:
[49,38,65,97,  76,13,27]
[49,38 | 65,97 | 76,13 | 27]
[49][38][65][97][76][13][27]

自底向上归并:
[38,49] [65,97] [13,76] [27]
[38,49,65,97] [13,27,76]
[13,27,38,49,65,76,97]
```

### 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|-----------|------|
| **最好** | $O(n \log n)$ | 无论初始状态如何，均需 $\log n$ 层归并 |
| **最坏** | $O(n \log n)$ | |
| **平均** | $O(n \log n)$ | |
| **空间复杂度** | $O(n)$ | 需要临时数组 |
| **稳定性** | **稳定** | 左半部分优先，相等时不改变相对位置 |

> **递推分析**：归并排序的递推式 T(n) = 2T(n/2) + O(n) 可通过Master定理求解。递推关系的通用解法详见 [[../../数理基础/离散数学/10-递推关系与生成函数|离散数学 - 递推关系]]。

### 应用：外部排序

归并排序是**外部排序**的核心算法。当待排序数据过大无法全部装入内存时，使用多路归并进行排序。

### C++ 实现

```cpp
#include <vector>

// 合并两个有序子数组
void Merge(vector<int>& arr, vector<int>& temp,
           int low, int mid, int high) {
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high) {
        if (arr[i] <= arr[j])
            temp[k++] = arr[i++];
        else
            temp[k++] = arr[j++];
    }
    while (i <= mid)  temp[k++] = arr[i++];
    while (j <= high) temp[k++] = arr[j++];

}

// 递归实现（自顶向下）
void MergeSort_Recursive(vector<int>& arr, vector<int>& temp,
                         int low, int high) {
    if (low >= high) return;
    int mid = low + (high - low) / 2;
    MergeSort_Recursive(arr, temp, low, mid);
    MergeSort_Recursive(arr, temp, mid + 1, high);
    Merge(arr, temp, low, mid, high);
}

void MergeSort(vector<int>& arr) {
    vector<int> temp(arr.size());
    MergeSort_Recursive(arr, temp, 0, arr.size() - 1);
}

// 迭代实现（自底向上）
void MergeSort_Iterative(vector<int>& arr) {
    int n = arr.size();
    vector<int> temp(n);
    // size 为每次归并的子序列长度，依次取 1,2,4,8,...
    for (int size = 1; size < n; size *= 2) {
        for (int low = 0; low < n - size; low += 2 * size) {
            int mid = low + size - 1;
            int high = min(low + 2 * size - 1, n - 1);
            Merge(arr, temp, low, mid, high);
        }
    }
}
```

```python
from typing import List

# 合并两个有序子数组
def merge(arr: List[int], temp: List[int],
          low: int, mid: int, high: int) -> None:
    i, j, k = low, mid + 1, low
    while i <= mid and j <= high:
        if arr[i] <= arr[j]:
            temp[k] = arr[i]
            i += 1
        else:
            temp[k] = arr[j]
            j += 1
        k += 1
    while i <= mid:
        temp[k] = arr[i]; i += 1; k += 1
    while j <= high:
        temp[k] = arr[j]; j += 1; k += 1
    for i in range(low, high + 1):
        arr[i] = temp[i]

# 递归实现（自顶向下）
def merge_sort_recursive(arr: List[int], temp: List[int],
                         low: int, high: int) -> None:
    if low >= high:
        return
    mid = low + (high - low) // 2
    merge_sort_recursive(arr, temp, low, mid)
    merge_sort_recursive(arr, temp, mid + 1, high)
    merge(arr, temp, low, mid, high)

def merge_sort(arr: List[int]) -> None:
    temp = [0] * len(arr)
    merge_sort_recursive(arr, temp, 0, len(arr) - 1)

# 迭代实现（自底向上）
def merge_sort_iterative(arr: List[int]) -> None:
    n = len(arr)
    temp = [0] * n
    size = 1
    while size < n:
        low = 0
        while low < n - size:
            mid = low + size - 1
            high = min(low + 2 * size - 1, n - 1)
            merge(arr, temp, low, mid, high)
            low += 2 * size
        size *= 2


if __name__ == "__main__":
    a1 = [49, 38, 65, 97, 76, 13, 27]
    merge_sort(a1)
    print(f"递归版: {a1}")

    a2 = [49, 38, 65, 97, 76, 13, 27]
    merge_sort_iterative(a2)
    print(f"迭代版: {a2}")
```

## 10.6 基数排序（Radix Sort）

### 多关键字排序思想

基数排序是一种**多关键字排序**方法，按关键字的不同位值（个位、十位、百位……）依次进行排序。有两种策略：

- **MSD（Most Significant Digit）最高位优先**：先按最高位排序，再按次高位……需要递归分治
- **LSD（Least Significant Digit）最低位优先**：先按最低位排序，再按次低位……适合"分配-收集"方式

### 以十进制为基数的 LSD 排序

假设待排序的关键字为十进制数字，基数为 $b=10$，共 $d$ 位（最大位数为 $d$）：

1. 设置 10 个桶（队列）`B[0]` 到 `B[9]`
2. 从最低位（个位）到最高位，重复 $d$ 轮：
   - **分配（Distribution）**：根据当前位的数字，将记录分配到对应桶中
   - **收集（Collection）**：按 `B[0]` 到 `B[9]` 的顺序依次从桶中收集记录

### 复杂度分析

$$T(n) = O(d \cdot (n + b))$$

其中：
- $n$：待排序元素个数
- $d$：关键字的**最大位数**（Digits）
- $b$：基数（Base），即桶的数量（十进制为 10）

| 项目 | 分析 |
|------|------|
| **时间复杂度** | $O(d \cdot (n + b))$，当 $d$ 和 $b$ 为常数时即为 $O(n)$ |
| **空间复杂度** | $O(n + b)$，需要桶存储空间 |
| **稳定性** | **稳定**（LSD 方式下，相同关键字按入桶顺序出桶，相对位置不变）|

### 排序过程演示

```
初始: [329, 457, 657, 839, 436, 720, 355]

第1趟 (个位, d=0):
  桶0:[720]  桶5:[355]  桶6:[436]
  桶7:[457,657]  桶9:[329,839]
  收集: [720, 355, 436, 457, 657, 329, 839]

第2趟 (十位, d=1):
  桶2:[720,329]  桶3:[436,839]  桶5:[355,457,657]
  收集: [720, 329, 436, 839, 355, 457, 657]

第3趟 (百位, d=2):
  桶3:[329,355]  桶4:[436,457]  桶6:[657]
  桶7:[720]  桶8:[839]
  收集: [329, 355, 436, 457, 657, 720, 839]
```

> 注意：`457` 在 `657` 之前（因为十位排序时 `457<657`），体现了**稳定性**。

### 桶排序（Bucket Sort）

桶排序是基数排序的变体：将数据分布到有限数量的桶中，每个桶分别排序（通常用插入排序），然后将各桶中的数据有序合并。桶排序适用于**数据均匀分布**的情况。

### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

// LSD 基数排序（以10为基数）
void RadixSort(vector<int>& arr) {
    if (arr.empty()) return;
    int n = arr.size();

    // 找出最大值以确定最大位数
    int maxVal = *max_element(arr.begin(), arr.end());
    int d = 0; // 位数
    while (maxVal > 0) { maxVal /= 10; d++; }

    // 10 个桶（队列）
    vector<queue<int>> buckets(10);

    int divisor = 1; // 当前位的除数：1(个位),10(十位),100(百位)...
    for (int digit = 0; digit < d; digit++) {
        // 分配
        for (int num : arr) {
            int idx = (num / divisor) % 10;
            buckets[idx].push(num);
        }
        // 收集
        int k = 0;
        for (int i = 0; i < 10; i++) {
            while (!buckets[i].empty()) {
                arr[k++] = buckets[i].front();
                buckets[i].pop();
            }
        }
        divisor *= 10;

        // 输出每趟结果
        cout << "第" << digit + 1 << "趟: ";
        for (int x : arr) cout << x << " ";
        cout << endl;
    }
}

int main() {
    vector<int> a = {329, 457, 657, 839, 436, 720, 355};
    RadixSort(a);
    return 0;
}
```

### Python 实现

```python
from typing import List
from collections import deque

def radix_sort(arr: List[int]) -> None:
    """LSD 基数排序（以10为基数）"""
    if not arr:
        return

    max_val = max(arr)
    d = 0
    while max_val > 0:
        max_val //= 10
        d += 1

    buckets = [deque() for _ in range(10)]
    divisor = 1

    for digit in range(d):
        # 分配
        for num in arr:
            idx = (num // divisor) % 10
            buckets[idx].append(num)
        # 收集
        k = 0
        for i in range(10):
            while buckets[i]:
                arr[k] = buckets[i].popleft()
                k += 1
        divisor *= 10

        print(f"第{digit + 1}趟: {arr}")


if __name__ == "__main__":
    a = [329, 457, 657, 839, 436, 720, 355]
    radix_sort(a)
```

## 10.7 各种内部排序方法的比较讨论

### 综合比较表

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 适用场景 |
|------|------|------|------|------|------|----------|
| **直接插入排序** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **是** | $n$ 较小且基本有序 |
| **折半插入排序** | $O(n \log n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **是** | $n$ 较小，比较代价高于移动代价 |
| **希尔排序** | $O(n)$ | $O(n^{1.3})$ | $O(n^2)$ | $O(1)$ | **否** | 中等规模，要求常数空间 |
| **冒泡排序** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **是** | $n$ 较小，教学用 |
| **快速排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | **否** | $n$ 较大，通用场景，实际中最快 |
| **简单选择排序** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **否** | $n$ 较小，移动代价高时代替冒泡 |
| **堆排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | **否** | 需要保证最坏 $O(n \log n)$ 且 $O(1)$ 空间 |
| **归并排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | **是** | 要求稳定排序，外部排序基础 |
| **基数排序** | $O(d(n+b))$ | $O(d(n+b))$ | $O(d(n+b))$ | $O(n+b)$ | **是** | 关键字可分解为"位"，范围有限 |
| **桶排序** | $O(n+k)$ | $O(n+k)$ | $O(n^2)$ | $O(n+k)$ | **是** | 数据均匀分布 |

### 不稳定的排序方法

简单选择排序、堆排序和希尔排序、快速排序是**不稳定的排序方法**。

### 选择排序算法的建议

| 场景 | 推荐算法 |
|------|----------|
| 小规模（$n < 50$）| 直接插入排序、冒泡排序 |
| 中等规模（$50 < n < 10000$）| 希尔排序 |
| 大规模（$n > 10000$）| 快速排序、归并排序 |
| 需要稳定 | 归并排序、基数排序、直接插入排序 |
| 需要 $O(1)$ 额外空间 | 堆排序、希尔排序 |
| 需要保证最坏 $O(n \log n)$ | 堆排序、归并排序 |
| 基本有序数据 | 直接插入排序、冒泡排序 |

### 时间与空间的关系

- 若降低空间复杂度，往往会增大时间复杂度（以时间换空间）
- 若增加空间复杂度，往往可以减小时间复杂度（以空间换时间）
- 在算法设计中，**时间资源**通常比空间资源更为宝贵

## 总结

1. **排序**是将无序序列调整为有序序列的操作，**稳定性**是评估排序算法的重要特性
2. **内部排序**十大算法可分为五类：
   - **插入类**：直接插入排序（$O(n^2)$ 稳定）、折半插入排序、希尔排序（$O(n^{1.3})$ 不稳定）
   - **交换类**：冒泡排序（$O(n^2)$ 稳定）、快速排序（$O(n \log n)$ 不稳定，最坏 $O(n^2)$）
   - **选择类**：简单选择排序（$O(n^2)$ 不稳定）、堆排序（$O(n \log n)$ 不稳定，$O(1)$ 空间）
   - **归并类**：归并排序（$O(n \log n)$ 稳定，$O(n)$ 空间）
   - **其他**：基数排序（$O(d(n+b))$ 稳定）
3. **算法选择指南**：
   - **小规模**（$n < 50$）：直接插入排序
   - **中等规模**：希尔排序
   - **大规模**：
     - 通用：快速排序（实际最快，但注意最坏情况）
     - 需要稳定：归并排序
     - 需要 $O(1)$ 空间且保证 $O(n \log n)$：堆排序
   - **数据分布特殊**：基数排序（整数，范围小）、桶排序（均匀分布）
4. 不稳定的排序方法：**简单选择排序、堆排序、希尔排序、快速排序**
