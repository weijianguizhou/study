# 队列

队列（Queue）是只允许在表的一端进行插入、在另一端进行删除的线性表。和[[04-栈|栈]]一样，队列也是运算受限的线性表——但它遵循完全不同的操作原则：**先进先出**。本章从定义、ADT、链式存储、循环队列到双端队列和优先队列，系统讲解队列结构的方方面面。

## 队列的定义与基本概念

### 定义

**队列**是只允许在一端进行插入、在另一端进行删除的线性表。允许删除的一端称为**队头**（_Front_），允许插入的一端称为**队尾**（_Rear_）。当队列中没有元素时，称为**空队列**（_Empty Queue_）。

队列的修改遵循**先进先出**（First In First Out，简称 **FIFO**）原则。

若队列 $Q = (a_1, a_2, \dots, a_n)$，则：
- $a_1$ 为队头元素（最早入队，最先出队）
- $a_n$ 为队尾元素（最晚入队，最后出队）

### 队列与栈的比较

| 对比维度 | 栈（Stack） | 队列（Queue） |
| -------- | ----------- | ------------- |
| 操作原则 | LIFO（后进先出） | FIFO（先进先出） |
| 插入位置 | 栈顶（同一端） | 队尾（rear） |
| 删除位置 | 栈顶（同一端） | 队头（front） |
| 数学类比 | 一摞盘子 | 排队买票 |
| 典型应用 | 函数调用、撤销、表达式求值 | 任务调度、BFS、缓冲 |

### 生活中的队列

- **排队购票**：先到的人先得到服务。
- **打印机任务队列**：先提交的文档先打印。
- **消息队列（Message Queue）**：分布式系统中先进先出的消息传递。
- **CPU 就绪队列**：操作系统中等待调度的进程按 FIFO 排队。

## 队列的抽象数据类型（ADT）定义

### 数据对象

$$
D = \{ a_i \mid a_i \in \text{ElemSet},\; i = 1, 2, \dots, n,\; n \ge 0 \}
$$

### 数据关系

$$
R_1 = \{ \langle a_{i-1}, a_i \rangle \mid a_{i-1}, a_i \in D,\; i = 2, \dots, n \}
$$

其中约定 $a_1$ 端为队头，$a_n$ 端为队尾。

### 基本操作表

| 操作 | 原型 | 功能描述 |
| ---- | ---- | -------- |
| 初始化 | `InitQueue(&Q)` | 构造一个空队列 $Q$ |
| 销毁 | `DestroyQueue(&Q)` | 销毁已存在的队列 $Q$，释放内存 |
| 判空 | `QueueEmpty(Q)` | 若 $Q$ 为空队列返回 `true`，否则返回 `false` |
| 清空 | `ClearQueue(&Q)` | 将 $Q$ 清为空队列 |
| 求长度 | `QueueLength(Q)` | 返回 $Q$ 中元素个数 |
| 取队头 | `GetHead(Q, &e)` | 用 $e$ 返回队头元素（$Q$ 非空） |
| 入队 | `EnQueue(&Q, e)` | 将元素 $e$ 插入为新的队尾元素 |
| 出队 | `DeQueue(&Q, &e)` | 删除队头元素，并用 $e$ 返回其值 |
| 遍历 | `QueueTraverse(Q, visit())` | 从队头到队尾依次访问每个元素 |

> **时间复杂度**：上述所有基本操作（除遍历外）均可在 $O(1)$ 时间内完成。

## 链队列（Linked Queue）

### 存储结构

链队列基于**带头结点的单链表**实现，需要两个指针：

- **`front`**（队头指针）：指向头结点（即链表中的哨兵结点）。
- **`rear`**（队尾指针）：指向最后一个实际元素结点。

```
    front                          rear
     │                              │
     ▼                              ▼
  ┌──────┐   ┌───┐   ┌───┐   ┌───┐
  │ head │──→│a_1│──→│a_2│──→│a_3│──→ nullptr
  └──────┘   └───┘   └───┘   └───┘
  头结点     ↑ 队头             ↑ 队尾
```

### 空队列条件

当队列为空时，`front` 和 `rear` **均指向头结点**：

```
    front / rear
         │
         ▼
      ┌──────┐
      │ head │──→ nullptr
      └──────┘
```

### 入队操作 EnQueue

在队尾（`rear` 所指结点之后）插入新结点：

```
步骤：
1. 创建新结点 node(e, nullptr)
2. rear->next = node     // 将尾结点的 next 指向新结点
3. rear = node           // 更新 rear 指向新尾结点
```

时间复杂度：$O(1)$。

### 出队操作 DeQueue

删除队头结点（即 `front->next` 指向的结点）：

```
步骤：
1. if (front == rear) return false  // 队列空
2. p = front->next                  // 指向要删除的队头结点
3. e = p->data                      // 取出数据
4. front->next = p->next            // 跳过被删除的结点
5. if (rear == p) rear = front      // 若删除后队列为空，更新 rear
6. delete p
```

时间复杂度：$O(1)$。

**特别注意**：若出队的是最后一个元素（此时 `rear == p`），必须将 `rear` 重新指向头结点 `front`，否则 `rear` 将成为一个悬空指针。

### C++ 完整实现

```cpp
#include <iostream>
#include <stdexcept>

template <typename T>
struct QueueNode {
    T data;
    QueueNode<T>* next;
    
    QueueNode() : next(nullptr) {}                          // 头结点构造
    QueueNode(const T& val) : data(val), next(nullptr) {}   // 数据结点构造
};

template <typename T>
class LinkedQueue {
private:
    QueueNode<T>* front;  // 队头指针（指向头结点）
    QueueNode<T>* rear;   // 队尾指针（指向尾结点）
    int count;            // 当前元素个数

public:
    // 构造函数：创建头结点
    LinkedQueue() : count(0) {
        front = rear = new QueueNode<T>();  // front 和 rear 都指向头结点
    }

    // 析构函数
    ~LinkedQueue() {
        clear();
        delete front;  // 删除头结点
    }

    // 拷贝构造函数
    LinkedQueue(const LinkedQueue& other) : count(0) {
        front = rear = new QueueNode<T>();
        
        QueueNode<T>* p = other.front->next;
        while (p != nullptr) {
            rear->next = new QueueNode<T>(p->data);
            rear = rear->next;
            ++count;
            p = p->next;
        }
    }

    // 赋值运算符
    LinkedQueue& operator=(const LinkedQueue& other) {
        if (this != &other) {
            clear();
            
            QueueNode<T>* p = other.front->next;
            while (p != nullptr) {
                rear->next = new QueueNode<T>(p->data);
                rear = rear->next;
                ++count;
                p = p->next;
            }
        }
        return *this;
    }

    // 判空
    bool empty() const {
        return front == rear;  // 队头队尾指向同一头结点时为空
    }

    // 返回队列长度
    int size() const {
        return count;
    }

    // 取队头元素
    T getHead() const {
        if (empty()) {
            throw std::runtime_error("Queue is empty!");
        }
        return front->next->data;
    }

    // 获取队尾元素
    T getTail() const {
        if (empty()) {
            throw std::runtime_error("Queue is empty!");
        }
        return rear->data;
    }

    // 入队（尾插法）
    void enQueue(const T& e) {
        QueueNode<T>* newNode = new QueueNode<T>(e);
        rear->next = newNode;
        rear = newNode;
        ++count;
    }

    // 出队
    T deQueue() {
        if (empty()) {
            throw std::runtime_error("Queue underflow!");
        }
        
        QueueNode<T>* p = front->next;
        T data = p->data;
        front->next = p->next;
        
        // 若删除的是最后一个结点，需要更新 rear
        if (rear == p) {
            rear = front;
        }
        
        delete p;
        --count;
        return data;
    }

    // 清空队列
    void clear() {
        while (front->next != nullptr) {
            QueueNode<T>* p = front->next;
            front->next = p->next;
            delete p;
        }
        rear = front;
        count = 0;
    }

    // 遍历（从队头到队尾）
    void traverse(void (*visit)(const T&)) const {
        QueueNode<T>* p = front->next;
        while (p != nullptr) {
            visit(p->data);
            p = p->next;
        }
    }

    // 打印
    void print() const {
        if (empty()) {
            std::cout << "[Empty Queue]" << std::endl;
            return;
        }
        std::cout << "LinkedQueue (front -> rear): ";
        QueueNode<T>* p = front->next;
        while (p != nullptr) {
            std::cout << p->data;
            p = p->next;
            if (p) std::cout << " <- ";
        }
        std::cout << std::endl;
    }
};

//     q.print();                       // 3 <- 4 <- 5
//     std::cout << q.size() << " " << q.getHead() << std::endl; // 3 3
//     return 0;
// }
```

### Python 完整实现

```python
from __future__ import annotations
from typing import TypeVar, Generic, Optional, Callable

T = TypeVar('T')

class QueueNode(Generic[T]):
    """链队列结点"""
    
    __slots__ = ('data', 'next')
    
    def __init__(self, data: Optional[T] = None, 
                 nxt: Optional[QueueNode[T]] = None):
        self.data: Optional[T] = data
        self.next: Optional[QueueNode[T]] = nxt
    
    def __repr__(self) -> str:
        return f"QueueNode({self.data!r})"


class LinkedQueue(Generic[T]):
    """链队列 —— 基于带头结点的单链表实现"""

    def __init__(self):
        """构造空队列，创建头结点"""
        head = QueueNode[T]()  # 头结点（哨兵结点）
        self._front: QueueNode[T] = head
        self._rear: QueueNode[T] = head
        self._count: int = 0

    def __len__(self) -> int:
        return self._count

    def __bool__(self) -> bool:
        return not self.empty()

    def __str__(self) -> str:
        if self.empty():
            return "LinkedQueue([])"
        items: list[str] = []
        p = self._front.next
        while p is not None:
            items.append(str(p.data))
            p = p.next
        return f"LinkedQueue([{', '.join(items)}])"

    def __repr__(self) -> str:
        return self.__str__()

    def __iter__(self):
        """从队头到队尾迭代"""
        p = self._front.next
        while p is not None:
            yield p.data
            p = p.next

    def empty(self) -> bool:
        """判空：front 和 rear 指向同一头结点"""
        return self._front is self._rear

    def size(self) -> int:
        """返回队列长度"""
        return self._count

    def get_head(self) -> T:
        """返回队头元素（不删除）"""
        if self.empty():
            raise IndexError("Queue is empty!")
        return self._front.next.data  # type: ignore

    def get_tail(self) -> T:
        """返回队尾元素"""
        if self.empty():
            raise IndexError("Queue is empty!")
        return self._rear.data  # type: ignore

    def en_queue(self, e: T) -> None:
        """入队（尾插法）"""
        new_node = QueueNode(e)
        self._rear.next = new_node
        self._rear = new_node
        self._count += 1

    def de_queue(self) -> T:
        """出队（删除队头结点）"""
        if self.empty():
            raise IndexError("Queue underflow!")
        
        p = self._front.next   # 要删除的结点
        data = p.data           # type: ignore
        self._front.next = p.next
        
        # 若删除后队列为空，更新 rear 指向头结点
        if self._rear is p:
            self._rear = self._front
        
        self._count -= 1
        return data  # type: ignore

    def clear(self) -> None:
        """清空队列"""
        self._front.next = None
        self._rear = self._front
        self._count = 0

    def traverse(self, visit: Callable[[T], None]) -> None:
        """从队头到队尾遍历"""
        p = self._front.next
        while p is not None:
            visit(p.data)  # type: ignore
            p = p.next


# ===== 使用示例 =====
if __name__ == "__main__":
    q = LinkedQueue[int]()
    for i in range(1, 6):
        q.en_queue(i)
    print(q)                  # LinkedQueue([1, 2, 3, 4, 5])
    print(q.de_queue())       # 1
    print(q.de_queue())       # 2
    print(q)                  # LinkedQueue([3, 4, 5])
    print(len(q), q.get_head())  # 3 3
```

## 循环队列（Circular Queue）

### 为什么需要循环队列？

顺序存储实现队列时，若简单用数组线性存储，会出现"**假溢出**"问题：

```
  0   1   2   3   4   5
┌───┬───┬───┬───┬───┬───┐
│   │   │a_3│a_4│a_5│   │  front=2, rear=5
└───┴───┴───┴───┴───┴───┘
```

此时 `rear = 5` 已到数组末尾，但数组前端还有空闲空间（下标 0、1 处）——队并非真正满，只是 `rear` 无法继续向后移动。**循环队列**正是为解决此问题而设计。

### 存储结构

将顺序存储的数组在逻辑上视为一个**首尾相接的圆环**：

```
        ┌───┬───┬───┐
        │   │a_6│a_7│
        ├───┼───┼───┤
        │a_5│       │a_1│
        ├───┤       ├───┤
        │a_4│       │a_2│
        └───┴───┴───┘
            a_3
```

通过**模运算** `index = (index + 1) % maxSize` 实现指针的循环移动。

### 指针约定

- **`front`**：指向**队头元素**所在位置。
- **`rear`**：指向队尾元素的下一个位置（即**下一个可插入位置**）。
- 初始状态：`front = rear = 0`。

### 队空判断

$$ \text{front} == \text{rear} $$

### 队满判断（常见的三种方法）

由于队空和队满时 `front` 与 `rear` 都可能相等，需要额外的机制加以区分：

#### 方法一：少用一个元素空间

约定在入队前检查尾指针循环意义下加 $1$ 后是否等于头指针。若相等则认为队满。

$$ (\text{rear} + 1) \bmod \text{maxSize} == \text{front} $$

**代价**：实际可用空间为 $\text{maxSize} - 1$。

#### 方法二：增设计数器

增设整型变量 `count`，记录当前队列中元素个数。

- **队空**：`count == 0`
- **队满**：`count == maxSize`

#### 方法三：增设标志位

增设布尔变量 `tag`，入队置 `1`，出队置 `0`。

- 当 `front == rear && tag == 0` 时队空。
- 当 `front == rear && tag == 1` 时队满。

### 入队与出队

**入队```EnQueue```**：

```
1. 判断队满
2. data[rear] = e
3. rear = (rear + 1) % maxSize
```

**出队```DeQueue```**：

```
1. 判断队空
2. e = data[front]
3. front = (front + 1) % maxSize
```

### C++ 完整实现（使用方法一：少用一个元素空间）

```cpp
#include <iostream>
#include <stdexcept>

template <typename T>
class CircularQueue {
private:
    T* data;
    int front;     // 队头指针
    int rear;      // 队尾指针（指向队尾元素的下一个位置）
    int capacity;  // 数组总容量

public:
    explicit CircularQueue(int maxSize = 10) 
        : front(0), rear(0), capacity(maxSize + 1) {
        // 多分配一个空间，用于区分队空和队满
        data = new T[capacity];
    }

    ~CircularQueue() {
        delete[] data;
    }

    CircularQueue(const CircularQueue& other)
        : front(other.front), rear(other.rear), capacity(other.capacity) {
        data = new T[capacity];
        for (int i = 0; i < capacity; ++i) {
            data[i] = other.data[i];
        }
    }

    CircularQueue& operator=(const CircularQueue& other) {
        if (this != &other) {
            delete[] data;
            capacity = other.capacity;
            front = other.front;
            rear = other.rear;
            data = new T[capacity];
            for (int i = 0; i < capacity; ++i) {
                data[i] = other.data[i];
            }
        }
        return *this;
    }

    // 判空
    bool empty() const {
        return front == rear;
    }

    // 判满
    bool full() const {
        return (rear + 1) % capacity == front;
    }

    // 返回队列长度
    int size() const {
        return (rear - front + capacity) % capacity;
    }

    // 返回最大容量
    int maxSize() const {
        return capacity - 1;  // 实际可用容量
    }

    // 取队头元素
    T getHead() const {
        if (empty()) {
            throw std::runtime_error("Queue is empty!");
        }
        return data[front];
    }

    // 取队尾元素
    T getTail() const {
        if (empty()) {
            throw std::runtime_error("Queue is empty!");
        }
        // 队尾元素在 rear 的前一个位置
        int tailPos = (rear - 1 + capacity) % capacity;
        return data[tailPos];
    }

    // 入队
    void enQueue(const T& e) {
        if (full()) {
            throw std::runtime_error("Queue overflow!");
        }
        data[rear] = e;
        rear = (rear + 1) % capacity;
    }

    // 出队
    T deQueue() {
        if (empty()) {
            throw std::runtime_error("Queue underflow!");
        }
        T e = data[front];
        front = (front + 1) % capacity;
        return e;
    }

    // 清空
    void clear() {
        front = rear = 0;
    }

    // 打印
    void print() const {
        if (empty()) {
            std::cout << "[Empty Queue]" << std::endl;
            return;
        }
        std::cout << "CircularQueue (front -> rear): ";
        int i = front;
        while (i != rear) {
            std::cout << data[i] << " ";
            i = (i + 1) % capacity;
        }
        std::cout << std::endl;
    }
};
```

### C++ 实现（方法二：增设计数器）

```cpp
template <typename T>
class CircularQueueCount {
private:
    T* data;
    int front;
    int rear;
    int capacity;
    int count;  // 当前元素个数

public:
    explicit CircularQueueCount(int maxSize = 10)
        : front(0), rear(0), capacity(maxSize), count(0) {
        data = new T[capacity];
    }

    ~CircularQueueCount() { delete[] data; }

    bool empty() const { return count == 0; }
    bool full() const  { return count == capacity; }
    int size() const   { return count; }

    T getHead() const {
        if (empty()) throw std::runtime_error("Queue is empty!");
        return data[front];
    }

    void enQueue(const T& e) {
        if (full()) throw std::runtime_error("Queue overflow!");
        data[rear] = e;
        rear = (rear + 1) % capacity;
        ++count;
    }

    T deQueue() {
        if (empty()) throw std::runtime_error("Queue underflow!");
        T e = data[front];
        front = (front + 1) % capacity;
        --count;
        return e;
    }
};
```

### Python 完整实现

```python
from typing import TypeVar, Generic, Optional, List

T = TypeVar('T')

class CircularQueue(Generic[T]):
    """
    循环队列 —— 基于数组实现（少用一个元素空间区分队空/队满）
    实际可用 capacity = max_size - 1 个位置
    """

    def __init__(self, max_size: int = 10):
        self._capacity: int = max_size + 1  # 多分配一个空间
        self._data: List[Optional[T]] = [None] * self._capacity
        self._front: int = 0
        self._rear: int = 0

    def __len__(self) -> int:
        """返回队列长度"""
        return (self._rear - self._front + self._capacity) % self._capacity

    def __bool__(self) -> bool:
        return not self.empty()

    def __str__(self) -> str:
        if self.empty():
            return "CircularQueue([])"
        items: list[str] = []
        i = self._front
        while i != self._rear:
            items.append(str(self._data[i]))
            i = (i + 1) % self._capacity
        return f"CircularQueue([{', '.join(items)}])"

    def __repr__(self) -> str:
        return self.__str__()

    def empty(self) -> bool:
        """判空"""
        return self._front == self._rear

    def full(self) -> bool:
        """判满（少用一个元素空间）"""
        return (self._rear + 1) % self._capacity == self._front

    def size(self) -> int:
        """返回队列长度"""
        return len(self)

    @property
    def max_size(self) -> int:
        """实际最大容量"""
        return self._capacity - 1

    def get_head(self) -> T:
        """取队头元素"""
        if self.empty():
            raise IndexError("Queue is empty!")
        return self._data[self._front]  # type: ignore

    def get_tail(self) -> T:
        """取队尾元素"""
        if self.empty():
            raise IndexError("Queue is empty!")
        tail_pos = (self._rear - 1 + self._capacity) % self._capacity
        return self._data[tail_pos]  # type: ignore

    def en_queue(self, e: T) -> None:
        """入队"""
        if self.full():
            raise OverflowError("Queue overflow!")
        self._data[self._rear] = e
        self._rear = (self._rear + 1) % self._capacity

    def de_queue(self) -> T:
        """出队"""
        if self.empty():
            raise IndexError("Queue underflow!")
        result = self._data[self._front]
        self._data[self._front] = None  # 帮助垃圾回收
        self._front = (self._front + 1) % self._capacity
        return result  # type: ignore

    def clear(self) -> None:
        """清空队列"""
        for i in range(self._capacity):
            self._data[i] = None
        self._front = self._rear = 0


# ===== 使用示例 =====
if __name__ == "__main__":
    cq = CircularQueue[int](5)  # 实际可用 4 个位置
    cq.en_queue(10)
    cq.en_queue(20)

    print(cq)                    # CircularQueue([10, 20, 30])

    print("Full:", cq.full())    # True
    print("Size:", cq.size())    # 4
```

### 一、杨辉三角

杨辉三角（帕斯卡三角）的每一行都可以利用队列递推生成。核心思想：每次从队头取出上一行的两个相邻数相加得到当前行的数。

#### 算法（利用队列的 FIFO 特性）

1. 首行 `1` 入队。
2. 对于第 $i$ 行（$i > 1$）：
   - 队头取一个数，与上一次取出的数相加，结果入队。
   - 当前行结束时入队一个 `1`（每行末尾的 `1`）。

#### C++ 实现

```cpp
#include <iostream>
#include <queue>
#include <iomanip>

void printYangHui(int n) {
    std::queue<int> q;
    
    for (int i = 0; i < n; ++i) {
        int prev = 0;  // 前一个元素，用于计算本行元素
        
        // 每行开始补齐队列有 i+1 个元素
        if (i == 0) {
            q.push(1);
        } else {
            // 在队尾加入一个 0 作为辅助（用于计算行尾的 1）
            q.push(0);
            
            for (int j = 0; j <= i; ++j) {
                int val = q.front(); q.pop();
                int newVal = prev + val;
                std::cout << std::setw(4) << newVal;
                q.push(newVal);
                prev = val;
            }
            std::cout << std::endl;
            continue;
        }
        
        // 第一行直接打印
        std::cout << std::setw(4) << 1 << std::endl;
    }
}

// int main() {
//     printYangHui(8);
//     return 0;
// }
```

### 二、广度优先搜索（BFS）

BFS 是图的遍历算法之一，队列在其中扮演核心角色。

#### 算法

1. 访问起始顶点 $v_0$，将其标记为已访问，并入队。
2. 循环，直到队列为空：
   - 队头顶点 $v$ 出队。
   - 访问 $v$ 的所有未被访问的邻接顶点，标记并依次入队。

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <queue>

void bfs(const std::vector<std::vector<int>>& graph, int start) {
    int n = graph.size();
    std::vector<bool> visited(n, false);
    std::queue<int> q;
    
    visited[start] = true;
    q.push(start);
    
    while (!q.empty()) {
        int v = q.front(); q.pop();
        std::cout << v << " ";  // 访问当前顶点
        
        for (int neighbor : graph[v]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
    std::cout << std::endl;
}

// int main() {
//     // 邻接表表示的无向图
//     std::vector<std::vector<int>> graph = {
//         {1, 2},     // 0
//         {0, 3, 4},  // 1
//         {0, 5, 6},  // 2
//         {1},        // 3
//         {1},        // 4
//         {2},        // 5
//         {2}         // 6
//     };
//     bfs(graph, 0);  // 0 1 2 3 4 5 6
//     return 0;
// }
```

#### Python 实现

```python
from typing import List
from collections import deque

def bfs(graph: List[List[int]], start: int) -> List[int]:
    """
    广度优先搜索（BFS）
    
    graph: 邻接表
    start: 起始顶点
    返回: BFS 遍历序列
    """
    n = len(graph)
    visited: List[bool] = [False] * n
    result: List[int] = []
    q: deque[int] = deque()
    
    visited[start] = True
    q.append(start)
    
    while q:
        v = q.popleft()
        result.append(v)
        
        for neighbor in graph[v]:
            if not visited[neighbor]:
                visited[neighbor] = True
                q.append(neighbor)
    
    return result


# BFS 求最短路径（无权图）
def bfs_shortest_path(graph: List[List[int]], 
                      start: int, target: int) -> List[int]:
    """BFS 求无权图最短路径"""
    n = len(graph)
    visited = [False] * n
    parent = [-1] * n  # 记录路径中的前驱顶点
    q: deque[int] = deque()
    
    visited[start] = True
    q.append(start)
    
    while q:
        v = q.popleft()
        if v == target:
            # 回溯构造路径
            path: List[int] = []
            while v != -1:
                path.append(v)
                v = parent[v]
            path.reverse()
            return path
        
        for neighbor in graph[v]:
            if not visited[neighbor]:
                visited[neighbor] = True
                parent[neighbor] = v
                q.append(neighbor)
    
    return []  # 不可达


# ===== 测试 =====
if __name__ == "__main__":
    graph = [
        [1, 2],
        [0, 3, 4],
        [0, 5, 6],
        [1],
        [1],
        [2],
        [2],
    ]
    
    print("BFS:", bfs(graph, 0))          # [0, 1, 2, 3, 4, 5, 6]
    print("Path 0->6:", bfs_shortest_path(graph, 0, 6))  # [0, 2, 6]
```

### 四、滑动窗口问题

滑动窗口是一类常见问题：维护一个固定大小的窗口，在序列上滑动，实时求解窗口内的最大值/最小值。利用**单调队列**可将复杂度优化至 $O(n)$。

#### 问题描述

给定数组 `nums` 和窗口大小 `k`，求每个滑动窗口的最大值。

#### C++ 单调队列实现

```cpp
#include <iostream>
#include <vector>
#include <deque>

std::vector<int> maxSlidingWindow(const std::vector<int>& nums, int k) {
    std::vector<int> result;
    std::deque<int> dq;  // 存储下标，保持队列中元素递减
    
    for (int i = 0; i < (int)nums.size(); ++i) {
        // 移除窗口外的元素
        if (!dq.empty() && dq.front() == i - k) {
            dq.pop_front();
        }
        
        // 保持队列递减：从队尾移除所有小于当前元素的
        while (!dq.empty() && nums[dq.back()] < nums[i]) {
            dq.pop_back();
        }
        
        dq.push_back(i);
        
        // 窗口成形后记录最大值
        if (i >= k - 1) {
            result.push_back(nums[dq.front()]);
        }
    }
    
    return result;
}

//     std::vector<int> nums = {1, 3, -1, -3, 5, 3, 6, 7};
//     int k = 3;
//     auto result = maxSlidingWindow(nums, k);
//     // 预期：[3, 3, 5, 5, 6, 7]
//     for (int x : result) std::cout << x << " ";
//     std::cout << std::endl;
//     return 0;
// }
```

#### Python 实现

```python
from typing import List
from collections import deque

def max_sliding_window(nums: List[int], k: int) -> List[int]:
    """
    滑动窗口最大值 —— 使用单调递减队列
    
    时间复杂度: O(n)
    空间复杂度: O(k)
    """
    result: List[int] = []
    dq: deque[int] = deque()  # 存储下标，保持队列中元素值递减
    
    for i, num in enumerate(nums):
        # 移除窗口外元素
        if dq and dq[0] == i - k:
            dq.popleft()
        
        # 保持队列递减：从队尾移除所有小于当前值的索引
        while dq and nums[dq[-1]] < num:
            dq.pop()
        
        dq.append(i)
        
        # 窗口成形后记录最大值
        if i >= k - 1:
            result.append(nums[dq[0]])
    
    return result


# ===== 测试 =====

    k = 3
    print(max_sliding_window(nums, k))  # [3, 3, 5, 5, 6, 7]
```

## 双端队列（Deque）

### 定义

双端队列（Double-Ended Queue）是允许在**两端**都可以进行插入和删除运算的线性表。

| 操作 | 说明 |
| ---- | ---- |
| `pushFront(e)` | 在队头插入元素 $e$ |
| `pushBack(e)` | 在队尾插入元素 $e$ |
| `popFront()` | 删除队头元素并返回其值 |
| `popBack()` | 删除队尾元素并返回其值 |

双端队列可视为**栈 + 队列的综合体**，兼具 LIFO 和 FIFO 的能力。

### Python 的 collections.deque

Python 标准库的 `deque` 是基于**双向链表**实现的双端队列，两端操作均为 $O(1)$：

```python
from collections import deque

dq: deque[int] = deque()

# 两端插入
dq.append(1)         # 右端入队 → deque([1])
dq.append(2)         # deque([1, 2])
dq.appendleft(0)     # 左端入队 → deque([0, 1, 2])

# 两端删除
dq.pop()             # 右端出队 → 2,   deque([0, 1])
dq.popleft()         # 左端出队 → 0,   deque([1])

# 扩展
dq.extend([3, 4])           # 右端批量追加
dq.extendleft([-1, -2])     # 左端批量追加（注意逆序）

# 其他操作
dq.rotate(2)         # 循环右移 2 位
dq.rotate(-1)        # 循环左移 1 位
dq.clear()           # 清空
```

```python
T = TypeVar('T')

class StackViaDeque:
    """用 deque 实现栈（仅使用一端）"""
    def __init__(self):
        self._data: deque[T] = deque()

    def pop(self) -> T: return self._data.pop()
    def top(self) -> T: return self._data[-1]
    def __len__(self) -> int: return len(self._data)

class QueueViaDeque:
    """用 deque 实现队列（一端入另一端出）"""
    def __init__(self):
        self._data: deque[T] = deque()
    
    def enqueue(self, e: T) -> None: self._data.append(e)
    def dequeue(self) -> T: return self._data.popleft()
    def front(self) -> T: return self._data[0]
    def __len__(self) -> int: return len(self._data)
```

## 优先队列（Priority Queue）简介

### 概念与 ADT

**优先队列**是一种特殊的队列，其中每个元素都附带一个**优先级（Priority）**。出队操作总是返回当前队列中**优先级最高**（或最低）的元素，而非最早入队的元素。

换言之，优先队列的出队规则是**按照优先级排序的 FIFO**。

### ADT 基本操作

| 操作 | 说明 |
| ---- | ---- |
| `insert(e, priority)` | 将元素 $e$ 以优先级 $\text{priority}$ 插入 |
| `deleteMin()` / `deleteMax()` | 删除并返回优先级最小/最大的元素 |
| `getMin()` / `getMax()` | 返回优先级最小/最大的元素（不删除） |
| `size()` / `empty()` | 长度/判空 |

### 基于堆（Heap）的实现

优先队列最常见的底层实现是**二叉堆（Binary Heap）**：

- **最小堆（Min-Heap）**：父结点的值 $\le$ 子结点的值，堆顶为最小元素 → `deleteMin()` 只需 $O(\log n)$。
- **最大堆（Max-Heap）**：父结点的值 $\ge$ 子结点的值，堆顶为最大元素 → `deleteMax()` 只需 $O(\log n)$。

### Python 的 heapq 模块

Python 的 `heapq` 模块实现的是**最小堆**：

```python
import heapq
from typing import List, Tuple

# 基本用法（最小堆）
nums = [3, 1, 5, 2, 4]
heapq.heapify(nums)  # 原地建堆 → [1, 2, 5, 3, 4]

heapq.heappush(nums, 0)  # 插入 → [0, 2, 1, 3, 4, 5]
smallest = heapq.heappop(nums)  # 弹出最小 → 0

# 实现最大堆（取反）
max_heap: List[int] = []
for x in [3, 1, 5, 2, 4]:
    heapq.heappush(max_heap, -x)
largest = -heapq.heappop(max_heap)  # 5

# 自定义优先级的优先队列
class PriorityQueue:
    """基于 heapq 的优先队列封装"""
    
    def __init__(self):
        self._heap: List[Tuple[int, int, object]] = []
        self._counter = 0  # 确保同优先级时 FIFO
    
    def push(self, item, priority: int) -> None:
        """插入元素及其优先级（数值越小优先级越高）"""
        heapq.heappush(self._heap, (priority, self._counter, item))
        self._counter += 1
    
    def pop(self):
        """弹出优先级最高的元素（最小堆，值最小的优先）"""
        if not self._heap:
            raise IndexError("Priority queue is empty!")
        return heapq.heappop(self._heap)[2]
    
    def peek(self):
        """查看最高优先级元素"""
        if not self._heap:
            raise IndexError("Priority queue is empty!")
        return self._heap[0][2]
    
    def __len__(self) -> int:
        return len(self._heap)
    
    def __bool__(self) -> bool:
        return bool(self._heap)


# ===== 测试 =====
if __name__ == "__main__":
    pq = PriorityQueue()
    pq.push("Task A", priority=3)
    pq.push("Task B", priority=1)
    pq.push("Task C", priority=2)
    
    while pq:
        print(pq.pop())  # Task B, Task C, Task A
```

### 优先队列的应用场景

1. **Dijkstra 最短路径算法**：每次选择距离最小的顶点。
2. **Huffman 编码**：每次合并权值最小的两个结点。
3. **任务调度**：按优先级执行任务。
4. **A* 寻路算法**：选取估计代价最小的结点扩展。
5. **TOP-K 问题**：用大小为 $k$ 的最小堆维护最大的 $k$ 个元素。

## 总结

| 主题 | 核心要点 |
| ---- | -------- |
| **定义** | 队列是只允许一端插入、另一端删除的线性表，遵循 FIFO 原则 |
| **ADT** | 包含 `InitQueue`、`EnQueue`、`DeQueue`、`GetHead` 等操作，均为 $O(1)$ |
| **链队列** | 带头结点的单链表，`front` 指向头结点，`rear` 指向尾结点 |
| **循环队列** | 数组 + 模运算解决假溢出，三种判满方法（少用一个空间/计数器/标志位） |
| **杨辉三角** | 利用队列 FIFO 特性逐行生成 |
| **BFS** | 图/树的广度优先搜索以队列为核心 |
| **排队模拟** | 离散事件模拟，队列刻画顾客等待 |
| **滑动窗口** | 单调队列在 $O(n)$ 内求解窗口极值 |
| **双端队列** | 两端都可插入删除，兼具栈和队列特性 |
| **优先队列** | 按优先级出队，底层用堆实现，C++ `priority_queue` 和 Python `heapq` |

队列作为线性表的第二类受限结构，在广度优先搜索、消息队列、任务调度等方面有不可替代的地位。理解队列的 FIFO 特性和各种实现方式，是学习[[08-图|图论算法]]、[[10-排序|排序算法]]和操作系统调度等后续内容的基础。
