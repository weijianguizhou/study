# 第08章 图

> 图 (Graph) 是一种比树更为复杂的非线性数据结构。在图中，结点之间的关系是**多对多**的，即任意两个数据元素之间都可能存在联系。图的应用极为广泛，涵盖社交网络分析、路径规划、网络流、编译优化等众多领域。本章是数据结构课程的另一核心重头戏。

## 8.1 图的定义和术语

> **理论基础**：图的基本定义、握手定理及其数学证明见 [[../../数理基础/离散数学/06-图论基础|离散数学 - 图论基础]]。本章侧重数据结构的存储表示和算法实现。

### 8.1.1 图的抽象定义

图 $G$ 由两个集合组成——**顶点集** $V$（非空有穷集合）和**边集** $E$（可以是空集），记作：

$$G = (V, E)$$

其中：
- $V = \{v_1, v_2, \dots, v_n\}$ 是顶点的有穷非空集合。
- $E$ 是连接顶点对的边的集合。每条边由一对顶点 $(v_i, v_j)$（无向边）或 $\langle v_i, v_j \rangle$（有向边）表示。

### 8.1.2 基本分类

**无向图 (Undirected Graph)**：若边集 $E$ 中，$\langle v_i, v_j \rangle \in E$ 必有 $\langle v_j, v_i \rangle \in E$，即边没有方向。无向边记为 $(v_i, v_j)$。

**有向图 (Directed Graph / Digraph)**：边（称为**弧**）有方向。弧 $\langle v_i, v_j \rangle$ 中，$v_i$ 为**弧尾 (Tail)**（起点），$v_j$ 为**弧头 (Head)**（终点）。$\langle v_i, v_j \rangle \neq \langle v_j, v_i \rangle$，两者是不同的弧。

**网 (Network / Weighted Graph)**：弧或边带有**权值 (Weight)** 的图，分别称作有向网或无向网。权值可以表示距离、费用、时间等。

### 8.1.3 核心术语

| 术语 | 说明 |
|---|---|
| **完全图** | 无向完全图：有 $\frac{n(n-1)}{2}$ 条边；有向完全图：有 $n(n-1)$ 条弧。 |
| **稀疏图 / 稠密图** | 若边或弧的数量 $e < n \log_2 n$，称为稀疏图；否则为稠密图。 |
| **子图** | $G' = (V', E')$ 满足 $V' \subseteq V$ 且 $E' \subseteq E$，则 $G'$ 是 $G$ 的子图。 |
| **邻接点** | 无向图中若存在边 $(v_i, v_j)$，则 $v_i$ 与 $v_j$ 互为邻接点。在有向图中 $\langle v_i, v_j \rangle$ 为弧，则 $v_j$ 是 $v_i$ 的邻接点。 |
| **度 (Degree)** | 无向图：与顶点 $v$ 关联的边的数目，记作 $TD(v)$。有向图：**出度** $OD(v)$ 是以 $v$ 为弧尾的弧数；**入度** $ID(v)$ 是以 $v$ 为弧头的弧数；$TD(v) = OD(v) + ID(v)$。 |
| **路径 (Path)** | 顶点序列 $\{v_{p_1}, v_{p_2}, \dots, v_{p_m}\}$，其中相邻顶点之间存在边或弧。 |
| **路径长度** | 路径上边或弧的数目（无权图）或权值之和（网）。 |
| **简单路径** | 路径中顶点不重复出现。 |
| **回路 (Cycle)** | 第一个顶点和最后一个顶点相同的路径。 |
| **简单回路** | 除首尾外其余顶点不重复的回路。 |
| **连通图** | 无向图中任意两顶点间均有路径相通。 |
| **连通分量** | 无向图的**极大连通子图**。 |
| **强连通图** | 有向图中任意两顶点 $v_i, v_j$，都存在从 $v_i$ 到 $v_j$ 和从 $v_j$ 到 $v_i$ 的有向路径。 |
| **强连通分量** | 有向图的极大强连通子图。 |
| **生成树** | 连通图的**极小连通子图**，包含全部 $n$ 个顶点和 $n-1$ 条边。 |
| **生成森林** | 非连通图中各连通分量的生成树的集合。 |

### 8.1.4 图的基本操作

| 操作 | 说明 |
|---|---|
| `CreatGraph(&G, V, VR)` | 按顶点集 $V$ 和边集 $VR$ 的定义构造图 $G$。 |
| `DestroyGraph(&G)` | 销毁图 $G$。 |
| `LocateVex(G, u)` | 返回顶点 $u$ 在图中的位置。 |
| `GetVex(G, v)` | 返回顶点 $v$ 的值。 |
| `FirstAdjVex(G, v)` | 返回 $v$ 的第一个邻接点。 |
| `NextAdjVex(G, v, w)` | 返回 $v$ 相对于 $w$ 的下一个邻接点。 |
| `InsertVex(&G, v)` | 插入顶点 $v$。 |
| `DeleteVex(&G, v)` | 删除顶点 $v$ 及相关的边。 |
| `InsertArc(&G, v, w)` | 插入弧 $\langle v, w \rangle$。 |
| `DeleteArc(&G, v, w)` | 删除弧 $\langle v, w \rangle$。 |
| `DFSTraverse(G)` | 深度优先遍历。 |
| `BFSTraverse(G)` | 广度优先遍历。 |

## 8.2 图的存储结构

### 8.2.1 邻接矩阵 (Adjacency Matrix)

**定义**：用一个二维数组 $A[i][j]$ 存储顶点间的邻接关系。对于具有 $n$ 个顶点的图，邻接矩阵是 $n \times n$ 的方阵。

- **无权图**：

$$A[i][j] = \begin{cases} 1 & \text{若 } (v_i, v_j) \text{ 或 } \langle v_i, v_j \rangle \text{ 是图中的边/弧} \\ 0 & \text{否则} \end{cases}$$

- **网（加权图）**：

$$A[i][j] = \begin{cases} w_{ij} & \text{若 } (v_i, v_j) \text{ 或 } \langle v_i, v_j \rangle \text{ 是图中的边/弧} \\ \infty & \text{否则} \end{cases}$$

**特点**：
- 无向图的邻接矩阵是**对称矩阵**（$A[i][j] = A[j][i]$），有向图一般不对称。
- 空间复杂度：$O(|V|^2)$。适合**稠密图**。
- 判断两顶点间是否有边：$O(1)$。
- 统计顶点度：无向图——扫描第 $i$ 行非零元素个数；有向图——第 $i$ 行非零元个数为出度，第 $i$ 列非零元个数为入度。

```cpp
// C++ 邻接矩阵实现
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

class GraphAdjMatrix {
private:
    int V;                       // 顶点数
    vector<vector<int>> matrix;   // 邻接矩阵
    bool isWeighted;              // 是否带权

public:
    // 构造函数：n个顶点，无向图/带权标志
    GraphAdjMatrix(int n, bool directed = false, bool weighted = false)
        : V(n), isWeighted(weighted) {
        int defaultVal = weighted ? INT_MAX : 0;
        matrix.assign(V, vector<int>(V, defaultVal));
        if (!weighted) {
            for (int i = 0; i < V; i++)
                matrix[i][i] = 0;
        }
    }

    // 添加边 (无权图)
    void addEdge(int u, int v) {
        if (isWeighted) return;
        matrix[u][v] = 1;
        // 无向图: 对称添加
        // 此处假设无向图，如需有向图则去掉下面一行
        matrix[v][u] = 1;
    }

    // 添加带权边 (网)
    void addEdge(int u, int v, int weight) {
        matrix[u][v] = weight;
        // 无向图对称
        matrix[v][u] = weight;
    }

    // 移除边
    void removeEdge(int u, int v) {
        int defaultVal = isWeighted ? INT_MAX : 0;
        matrix[u][v] = defaultVal;
        matrix[v][u] = defaultVal;
    }

    // 获取顶点 v 的所有邻接点
    vector<int> getNeighbors(int v) {
        vector<int> neighbors;
        int inf = isWeighted ? INT_MAX : 0;
        for (int i = 0; i < V; i++) {
            if (matrix[v][i] != inf && i != v)
                neighbors.push_back(i);
        }
        return neighbors;
    }

    void print() {
        for (int i = 0; i < V; i++) {
            for (int j = 0; j < V; j++) {
                if (isWeighted && matrix[i][j] == INT_MAX)
                    cout << "INF ";
                else
                    cout << matrix[i][j] << " ";
            }
            cout << endl;
        }
    }

    int getV() const { return V; }
    const vector<vector<int>>& getMatrix() const { return matrix; }
};
```

```python
# Python 邻接矩阵实现
from typing import List, Optional


class GraphAdjMatrix:
    def __init__(self, n: int, directed: bool = False, weighted: bool = False):
        self.V = n
        self.is_weighted = weighted
        self.directed = directed
        default_val = float('inf') if weighted else 0
        self.matrix = [[default_val] * n for _ in range(n)]

    def add_edge(self, u: int, v: int, weight: Optional[float] = None):
        if self.is_weighted and weight is not None:
            self.matrix[u][v] = weight
            if not self.directed:
                self.matrix[v][u] = weight
        else:
            self.matrix[u][v] = 1
            if not self.directed:
                self.matrix[v][u] = 1

    def remove_edge(self, u: int, v: int):
        default_val = float('inf') if self.is_weighted else 0
        self.matrix[u][v] = default_val
        if not self.directed:
            self.matrix[v][u] = default_val

    def get_neighbors(self, v: int) -> List[int]:
        inf = float('inf') if self.is_weighted else 0
        return [i for i in range(self.V) if self.matrix[v][i] != inf and i != v]

    def print_matrix(self):
        for row in self.matrix:
            print(" ".join("INF" if x == float('inf') else str(x) for x in row))
```

### 8.2.2 邻接表 (Adjacency List)

**定义**：对每个顶点建立一条单链表，链表中存储与该顶点相连的边信息。

- **顶点表**：数组，每个元素存储顶点信息和指向第一条依附于该顶点的边的指针。
- **边结点**：存储邻接点的编号（位置）和指向下一条边的指针。若是网，边结点中还包含权值信息。

**特点**：
- 空间复杂度：$O(|V| + |E|)$。适合**稀疏图**。
- 无向图的邻接表中，每条边存储两次（出现在两个顶点的链表中）。
- 有向图中，求顶点的出度容易（扫描其链表），但求入度需要遍历整个邻接表。
- 为同时方便求出度和入度，有向图可以使用**逆邻接表**。

```cpp
// C++ 邻接表实现
#include <iostream>
#include <vector>
#include <list>
using namespace std;

class GraphAdjList {
private:
    int V;
    bool directed;
    vector<list<pair<int, int>>> adj; // adj[v] = list of (neighbor, weight)

public:
    GraphAdjList(int n, bool directed = false)
        : V(n), directed(directed) {
        adj.resize(V);
    }

    // 无权边
    void addEdge(int u, int v) {
        adj[u].push_back({v, 1}); // 权值默认为1
        if (!directed)
            adj[v].push_back({u, 1});
    }

    // 带权边
    void addEdge(int u, int v, int weight) {
        adj[u].push_back({v, weight});
        if (!directed)
            adj[v].push_back({u, weight});
    }

    // 获取所有邻接点(不含权值)
    vector<int> getNeighbors(int v) {
        vector<int> neighbors;
        for (auto& edge : adj[v])
            neighbors.push_back(edge.first);
        return neighbors;
    }

    // 获取所有邻接点(含权值)
    vector<pair<int, int>> getEdges(int v) {
        return vector<pair<int, int>>(adj[v].begin(), adj[v].end());
    }

    int getV() const { return V; }
    const list<pair<int, int>>& operator[](int v) const { return adj[v]; }

    void print() {
        for (int i = 0; i < V; i++) {
            cout << "v" << i << " -> ";
            for (auto& edge : adj[i])
                cout << "(" << edge.first << "," << edge.second << ") ";
            cout << endl;
        }
    }
};
```

```python
# Python 邻接表实现
from typing import List, Tuple


class GraphAdjList:
    def __init__(self, n: int, directed: bool = False):
        self.V = n
        self.directed = directed
        self.adj: List[List[Tuple[int, int]]] = [[] for _ in range(n)]

    def add_edge(self, u: int, v: int, weight: int = 1):
        self.adj[u].append((v, weight))
        if not self.directed:
            self.adj[v].append((u, weight))

    def get_neighbors(self, v: int) -> List[int]:
        return [neighbor for neighbor, _ in self.adj[v]]

    def get_edges(self, v: int) -> List[Tuple[int, int]]:
        return self.adj[v][:]

    def print_adj(self):
        for i in range(self.V):
            print(f"v{i} -> {self.adj[i]}")
```

### 8.2.3 十字链表 (Orthogonal List) —— 有向图专用

十字链表将有向图的邻接表和逆邻接表合为一体，既能方便地求出度，也能方便地求入度。

**弧结点 (ArcBox)** 的结构：

```cpp
struct ArcBox {
    int tailVex;      // 弧尾顶点位置
    int headVex;      // 弧头顶点位置
    ArcBox* hlink;    // 指向下一个有相同弧头的弧（入弧链）
    ArcBox* tlink;    // 指向下一个有相同弧尾的弧（出弧链）
    int weight;       // 权值（网）
};
```

**顶点结点 (VexNode)** 的结构：

```cpp
struct VexNode {
    int data;
    ArcBox* firstin;   // 指向第一条入弧
    ArcBox* firstout;  // 指向第一条出弧
};
```

```cpp
// C++ 十字链表完整实现
#include <iostream>
#include <vector>
using namespace std;

struct ArcBox {
    int tailVex, headVex;
    ArcBox* hlink;   // 入弧链：指向下一个弧头相同的弧
    ArcBox* tlink;   // 出弧链：指向下一个弧尾相同的弧
    int weight;

    ArcBox(int tail, int head, int w = 1)
        : tailVex(tail), headVex(head), hlink(nullptr), tlink(nullptr), weight(w) {}
};

struct VexNode {
    int data;
    ArcBox* firstin;
    ArcBox* firstout;

    VexNode(int d) : data(d), firstin(nullptr), firstout(nullptr) {}
};

class OrthogonalGraph {
private:
    vector<VexNode> vertices;

public:
    OrthogonalGraph(int n) {
        for (int i = 0; i < n; i++)
            vertices.push_back(VexNode(i));
    }

    void addArc(int tail, int head, int weight = 1) {
        ArcBox* arc = new ArcBox(tail, head, weight);

        // 插入出弧链（按弧尾链接，头插法）
        arc->tlink = vertices[tail].firstout;
        vertices[tail].firstout = arc;

        // 插入入弧链（按弧头链接，头插法）
        arc->hlink = vertices[head].firstin;
        vertices[head].firstin = arc;
    }

    // 获取顶点 v 的出度
    int getOutDegree(int v) {
        int count = 0;
        ArcBox* p = vertices[v].firstout;
        while (p) { count++; p = p->tlink; }
        return count;
    }

    // 获取顶点 v 的入度
    int getInDegree(int v) {
        int count = 0;
        ArcBox* p = vertices[v].firstin;
        while (p) { count++; p = p->hlink; }
        return count;
    }

    void print() {
        for (int i = 0; i < vertices.size(); i++) {
            cout << "V" << i << " 出弧: ";
            ArcBox* p = vertices[i].firstout;
            while (p) {
                cout << "(" << p->tailVex << "->" << p->headVex << "," << p->weight << ") ";
                p = p->tlink;
            }
            cout << " | 入弧: ";
            p = vertices[i].firstin;
            while (p) {
                cout << "(" << p->tailVex << "->" << p->headVex << ") ";
                p = p->hlink;
            }
            cout << endl;
        }
    }
};
```

```python
# Python 十字链表实现
class ArcBox:
    def __init__(self, tail_vex: int, head_vex: int, weight: int = 1):
        self.tail_vex = tail_vex
        self.head_vex = head_vex
        self.hlink = None   # 下一个同弧头的弧
        self.tlink = None   # 下一个同弧尾的弧
        self.weight = weight


class VexNode:
    def __init__(self, data: int):
        self.data = data
        self.firstin = None   # 第一条入弧
        self.firstout = None  # 第一条出弧


class OrthogonalGraph:
    def __init__(self, n: int):
        self.vertices = [VexNode(i) for i in range(n)]

    def add_arc(self, tail: int, head: int, weight: int = 1):
        arc = ArcBox(tail, head, weight)
        # 出弧链
        arc.tlink = self.vertices[tail].firstout
        self.vertices[tail].firstout = arc
        # 入弧链
        arc.hlink = self.vertices[head].firstin
        self.vertices[head].firstin = arc

    def get_out_degree(self, v: int) -> int:
        count = 0
        p = self.vertices[v].firstout
        while p:
            count += 1
            p = p.tlink
        return count

    def get_in_degree(self, v: int) -> int:
        count = 0
        p = self.vertices[v].firstin
        while p:
            count += 1
            p = p.hlink
        return count

    def print_graph(self):
        for i, v in enumerate(self.vertices):
            out_str = []
            p = v.firstout
            while p:
                out_str.append(f"({p.tail_vex}->{p.head_vex})")
                p = p.tlink
            in_str = []
            p = v.firstin
            while p:
                in_str.append(f"({p.tail_vex}->{p.head_vex})")
                p = p.hlink
            print(f"V{i} 出: {out_str} | 入: {in_str}")
```

### 8.2.4 邻接多重表 (Adjacency Multilist) —— 无向图专用

邻接多重表中，每条边仅用一个结点表示，被两个顶点各自的链表所共享。适用于对无向图的边进行频繁操作（如删除边、标记边）的场景。

```
边结点结构:
┌──────┬──────┬──────┬──────┬──────┬──────┐
│mark  │iVex  │iLink │jVex  │jLink │info  │
└──────┴──────┴──────┴──────┴──────┴──────┘
 标记   顶点i  依附i   顶点j  依附j   权值
         的下一条边       的下一条边
```

```cpp
// C++ 邻接多重表
#include <iostream>
#include <vector>
using namespace std;

struct EdgeNode {
    int iVex, jVex;       // 该边依附的两个顶点
    EdgeNode* iLink;      // 指向下一条依附于 iVex 的边
    EdgeNode* jLink;      // 指向下一条依附于 jVex 的边
    int weight;

    EdgeNode(int i, int j, int w = 1)
        : iVex(i), jVex(j), iLink(nullptr), jLink(nullptr), weight(w) {}
};

class AMLGraph {
private:
    vector<int> vertices;
    vector<EdgeNode*> firstEdge;  // 每个顶点的第一条边

public:
    AMLGraph(int n) {
        for (int i = 0; i < n; i++) {
            vertices.push_back(i);
            firstEdge.push_back(nullptr);
        }
    }

    void addEdge(int u, int v, int weight = 1) {
        EdgeNode* edge = new EdgeNode(u, v, weight);

        // 头插法插入顶点 u 的链表
        edge->iLink = firstEdge[u];
        firstEdge[u] = edge;

        // 头插法插入顶点 v 的链表
        edge->jLink = firstEdge[v];
        firstEdge[v] = edge;
    }

    void print() {
        for (int i = 0; i < vertices.size(); i++) {
            cout << "V" << i << " -> ";
            EdgeNode* p = firstEdge[i];
            while (p) {
                // 确定另一个顶点
                int neighbor = (p->iVex == i) ? p->jVex : p->iVex;
                cout << "(V" << neighbor << "," << p->weight << ") ";
                // 沿正确的链继续
                if (p->iVex == i)
                    p = p->iLink;
                else
                    p = p->jLink;
            }
            cout << endl;
        }
    }
};
```

```python
# Python 邻接多重表
class EdgeNode:
    def __init__(self, i_vex: int, j_vex: int, weight: int = 1):
        self.i_vex = i_vex
        self.j_vex = j_vex
        self.i_link = None  # 下一条依附 i_vex 的边
        self.j_link = None  # 下一条依附 j_vex 的边
        self.weight = weight


class AMLGraph:
    def __init__(self, n: int):
        self.vertices = list(range(n))
        self.first_edge = [None] * n

    def add_edge(self, u: int, v: int, weight: int = 1):
        edge = EdgeNode(u, v, weight)
        edge.i_link = self.first_edge[u]
        self.first_edge[u] = edge
        edge.j_link = self.first_edge[v]
        self.first_edge[v] = edge

    def print_graph(self):
        for i in range(len(self.vertices)):
            neighbors = []
            p = self.first_edge[i]
            while p:
                neighbor = p.j_vex if p.i_vex == i else p.i_vex
                neighbors.append(f"(V{neighbor},{p.weight})")
                p = p.i_link if p.i_vex == i else p.j_link
            print(f"V{i} -> {neighbors}")
```

## 8.3 图的遍历

图的遍历是从图中某一顶点出发访问图中其余顶点，使得每个顶点被访问一次且仅访问一次。图可能包含回路，因此遍历时需要设置**访问标志数组** `visited[]` 以避免重复访问。

### 8.3.1 深度优先搜索 (DFS)

深度优先搜索类似于树的先根遍历，尽可能"深"地搜索图。

**算法思路**：
1. 从起始顶点 $v$ 出发，访问 $v$ 并标记为已访问。
2. 依次从 $v$ 的未被访问的邻接点出发进行深度优先搜索，直至图中所有与 $v$ 有路径相通的顶点都被访问到。
3. 若图中仍有未访问的顶点，则另选一个未访问的顶点作为起始点，重复上述过程（处理非连通图）。

#### 递归实现

### 8.3.3 复杂度分析

| 表示法 | DFS | BFS |
|---|---|---|
| **邻接矩阵** | $O(|V|^2)$ | $O(|V|^2)$ |
| **邻接表** | $O(|V| + |E|)$ | $O(|V| + |E|)$ |

- 每个顶点访问一次：$O(|V|)$。
- 邻接矩阵中找邻接点需扫描整行，每条边各被检查一次为 $O(|E|)$（但扫描整行的开销是 $O(|V|^2)$）。
- 邻接表中遍历所有邻接链，每条边被处理一次，总开销 $O(|V| + |E|)$。

## 8.4 最小生成树 (MST)

### 8.4.1 MST 性质

**问题描述**：在带权连通图中，选取 $n-1$ 条边构成一棵生成树，使得这些边的权值之和**最小**。

**MST 性质**：设 $G = (V, E)$ 是一个连通网，$U$ 是 $V$ 的一个非空真子集。若边 $(u, v) \in E$ 中 $u \in U$、$v \in V-U$，且 $(u, v)$ 是**所有连接 $U$ 与 $V-U$ 的边中权值最小者**，则必定存在一棵包含边 $(u, v)$ 的最小生成树。

### 8.4.2 Prim 算法

**核心思想**（加点法）：从某个顶点开始，每次选一条权值最小且连接已选顶点集 $U$ 和未选顶点集 $V-U$ 的边，将对应顶点加入 $U$，直到所有顶点都在 $U$ 中。

- 时间复杂度：$O(|V|^2)$（朴素实现），适合**稠密图**。
- 用堆优化可达 $O(|E| \log |V|)$。

```cpp
// C++ Prim 算法（朴素 O(V²)）
#include <vector>
#include <iostream>
#include <climits>
using namespace std;

void prim(const vector<vector<int>>& graph, int start = 0) {
    int V = graph.size();
    vector<int> key(V, INT_MAX);      // 顶点到MST的最小边权值
    vector<int> parent(V, -1);        // MST中每个顶点的父结点
    vector<bool> inMST(V, false);

    key[start] = 0;

    for (int count = 0; count < V - 1; count++) {
        // 从 V-U 中选出 key 值最小的顶点 u
        int u = -1, minKey = INT_MAX;
        for (int v = 0; v < V; v++) {
            if (!inMST[v] && key[v] < minKey) {
                minKey = key[v];
                u = v;
            }
        }

        if (u == -1) break;  // 图不连通
        inMST[u] = true;

        // 更新 u 的邻接点的 key 值
        for (int v = 0; v < V; v++) {
            if (graph[u][v] != 0 && graph[u][v] != INT_MAX
                && !inMST[v] && graph[u][v] < key[v]) {
                parent[v] = u;
                key[v] = graph[u][v];
            }
        }
    }

    // 输出结果
    int totalWeight = 0;
    cout << "Prim MST (最小生成树)：" << endl;
    for (int v = 0; v < V; v++) {
        if (v != start && parent[v] != -1) {
            cout << parent[v] << " - " << v << " : " << graph[parent[v]][v] << endl;
            totalWeight += graph[parent[v]][v];
        }
    }
    cout << "总权值: " << totalWeight << endl;
}
```

```cpp
#include <functional>

void primHeap(const vector<vector<pair<int, int>>>& adj, int start = 0) {
    int V = adj.size();
    vector<int> key(V, INT_MAX);
    vector<int> parent(V, -1);
    vector<bool> inMST(V, false);

    // 优先队列: (边权, 顶点编号)
    priority_queue<pair<int, int>, vector<pair<int, int>>,
                   greater<pair<int, int>>> pq;

    key[start] = 0;

        pq.pop();

        if (inMST[u]) continue;
        inMST[u] = true;

        for (auto& edge : adj[u]) {
            int v = edge.first;
            int weight = edge.second;
            if (!inMST[v] && weight < key[v]) {
                parent[v] = u;
                key[v] = weight;
                pq.push({key[v], v});
            }
        }

            cout << parent[v] << " - " << v << " : " << key[v] << endl;
            totalWeight += key[v];

    cout << "总权值: " << totalWeight << endl;
}
```

```python
def prim_heap(adj: list, start: int = 0):

    key = [float('inf')] * V
    parent = [-1] * V
    in_mst = [False] * V
    key[start] = 0
    pq = [(0, start)]  # (权值, 顶点)
```

### 8.4.3 Kruskal 算法

**核心思想**（加边法）：按边权值从小到大的顺序选取边，若该边连接的两个顶点不在同一连通分量中（不形成回路），则将该边加入生成树。使用**并查集 (Union-Find)** 判断是否形成回路。

- 时间复杂度：$O(|E| \log |E|)$，适合**稀疏图**。
- 主要开销在对边的排序上。

#### 并查集 (Union-Find / Disjoint Set Union)

```cpp
// C++ 并查集
class UnionFind {
private:
    vector<int> parent;
    vector<int> rank;  // 按秩合并

public:
    UnionFind(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        for (int i = 0; i < n; i++)
            parent[i] = i;
    }

    // 查找根结点（路径压缩）
    int find(int x) {
        if (parent[x] != x)
            parent[x] = find(parent[x]);
        return parent[x];
    }

    // 合并两个集合（按秩合并）
    void unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        if (rank[rx] < rank[ry])
            parent[rx] = ry;
        else if (rank[rx] > rank[ry])
            parent[ry] = rx;
        else {
            parent[ry] = rx;
            rank[rx]++;
        }
    }

    bool connected(int x, int y) {
        return find(x) == find(y);
    }
};
```

```python
# Python 并查集
class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]

    def unite(self, x: int, y: int):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return
        if self.rank[rx] < self.rank[ry]:
            self.parent[rx] = ry
        elif self.rank[rx] > self.rank[ry]:
            self.parent[ry] = rx
        else:
            self.parent[ry] = rx
            self.rank[rx] += 1

    def connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)
```

#### Kruskal 核心实现

```cpp
// C++ Kruskal 算法
#include <algorithm>
#include <vector>

struct Edge {
    int u, v, weight;
    Edge(int u, int v, int w) : u(u), v(v), weight(w) {}

    // 按权值从小到大排序
    bool operator<(const Edge& other) const {
        return weight < other.weight;
    }
};

void kruskal(int V, const vector<Edge>& edges) {
    vector<Edge> sortedEdges = edges;
    sort(sortedEdges.begin(), sortedEdges.end());

    UnionFind uf(V);
    vector<Edge> mst;
    int totalWeight = 0;

    for (const Edge& e : sortedEdges) {
        if (!uf.connected(e.u, e.v)) {
            uf.unite(e.u, e.v);
            mst.push_back(e);
            totalWeight += e.weight;

            if (mst.size() == V - 1) break;
        }
    }

    cout << "Kruskal MST:" << endl;
    for (const Edge& e : mst)
        cout << e.u << " - " << e.v << " : " << e.weight << endl;
    cout << "总权值: " << totalWeight << endl;
}
```

## 8.5 有向无环图 (DAG) 的应用

### 8.5.1 拓扑排序 (Topological Sort)

**定义**：将有向无环图中的顶点排成线性序列，使得对于任意弧 $\langle v_i, v_j \rangle$，$v_i$ 在序列中排在 $v_j$ 之前。拓扑排序用于检测图中的回路。

#### 方法一：Kahn 算法（入度法）

```cpp
// C++ 拓扑排序 (Kahn 算法 / 入度法)
#include <queue>
vector<int> topologicalSortKahn(int V, const vector<vector<int>>& adj) {
    vector<int> indegree(V, 0);

    // 统计入度
    for (int u = 0; u < V; u++) {
        for (int v : adj[u]) {
            indegree[v]++;
        }
    }

    queue<int> q;
    for (int i = 0; i < V; i++) {
        if (indegree[i] == 0)
            q.push(i);
    }

    vector<int> result;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        result.push_back(u);

        for (int v : adj[u]) {
            indegree[v]--;
            if (indegree[v] == 0)
                q.push(v);
        }
    }

    // 若 result.size() < V，说明有回路
    if (result.size() < V) {
        cout << "图中存在回路！" << endl;
        return {};
    }
    return result;
}
```

```python
# Python 拓扑排序 (Kahn 算法)
from collections import deque

def topological_sort_kahn(V: int, adj: list) -> list:
    indegree = [0] * V
    for u in range(V):
        for v in adj[u]:
            indegree[v] += 1

    q = deque([i for i in range(V) if indegree[i] == 0])
    result = []

    while q:
        u = q.popleft()
        result.append(u)
        for v in adj[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                q.append(v)

    if len(result) < V:
        print("图中存在回路！")
        return []
    return result
```

#### 方法二：DFS 逆后序法

```cpp
// C++ 拓扑排序 (DFS 逆后序)
void topoDFS(int u, const vector<vector<int>>& adj,
             vector<bool>& visited, vector<bool>& onPath,
             stack<int>& stk, bool& hasCycle) {
    visited[u] = true;
    onPath[u] = true;

    for (int v : adj[u]) {
        if (!visited[v]) {
            topoDFS(v, adj, visited, onPath, stk, hasCycle);
        } else if (onPath[v]) {
            hasCycle = true;  // 发现回边
        }
    }

    onPath[u] = false;
    stk.push(u);  // 后序入栈
}

vector<int> topologicalSortDFS(int V, const vector<vector<int>>& adj) {
    vector<bool> visited(V, false);
    vector<bool> onPath(V, false);
    stack<int> stk;
    bool hasCycle = false;

    for (int i = 0; i < V; i++) {
        if (!visited[i])
            topoDFS(i, adj, visited, onPath, stk, hasCycle);
    }

    if (hasCycle) {
        cout << "图中存在回路！" << endl;
        return {};
    }

    vector<int> result;
    while (!stk.empty()) {
        result.push_back(stk.top());
        stk.pop();
    }
    return result;
}
```

```python
# Python 拓扑排序 (DFS 逆后序)
def topological_sort_dfs(V: int, adj: list) -> list:
    visited = [False] * V
    on_path = [False] * V
    stack = []
    has_cycle = [False]

    def dfs(u):
        visited[u] = True
        on_path[u] = True
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
            elif on_path[v]:
                has_cycle[0] = True
        on_path[u] = False
        stack.append(u)

    for i in range(V):
        if not visited[i]:
            dfs(i)

    if has_cycle[0]:
        print("图中存在回路！")
        return []

    return stack[::-1]  # 逆序输出
```

### 8.5.2 关键路径 (Critical Path)

**AOE 网 (Activity On Edge)**：带权的有向无环图，顶点表示**事件**（状态），边表示**活动**（工序），边权表示活动持续时间。AOE 网用于**工程进度管理**。

- **源点**：入度为 0 的顶点（工程开始）。
- **汇点**：出度为 0 的顶点（工程完成）。
- **关键路径**：从源点到汇点的最长路径，决定了工程的最短完成时间。
- **关键活动**：关键路径上的活动，活动余量为 0。

**四个关键时间量**：
- $ve(j)$：事件 $j$ 的**最早发生时间**。$ve(\text{源点}) = 0$，在拓扑有序上递推：
  $$ve(j) = \max\{ve(k) + w(\langle k, j \rangle)\}$$
- $vl(j)$：事件 $j$ 的**最迟发生时间**。$vl(\text{汇点}) = ve(\text{汇点})$，在逆拓扑序上递推：
  $$vl(j) = \min\{vl(k) - w(\langle j, k \rangle)\}$$
- $ee(i)$：活动 $\langle j, k \rangle$ 的最早开始时间：$ee(i) = ve(j)$。
- $el(i)$：活动 $\langle j, k \rangle$ 的最迟开始时间：$el(i) = vl(k) - w(\langle j, k \rangle)$。

若 $ee(i) = el(i)$，则活动 $i$ 为关键活动。

```cpp
// C++ 关键路径算法
#include <vector>
#include <stack>
#include <iostream>
#include <climits>
using namespace std;

struct Arc {
    int from, to, weight;
};

void criticalPath(int V, const vector<Arc>& arcs) {
    // 构建邻接表和逆邻接表
    vector<vector<pair<int, int>>> adj(V);     // (to, weight)
    vector<vector<int>> revAdj(V);              // 逆邻接表 (用于回推 vl)
    vector<int> indegree(V, 0);

    for (const Arc& arc : arcs) {
        adj[arc.from].push_back({arc.to, arc.weight});
        revAdj[arc.to].push_back(arc.from);
        indegree[arc.to]++;
    }

    // 1. 拓扑排序，同时计算 ve
    stack<int> topoOrder;
    vector<int> ve(V, 0);

    queue<int> q;
    for (int i = 0; i < V; i++)
        if (indegree[i] == 0) q.push(i);

    while (!q.empty()) {
        int j = q.front(); q.pop();
        topoOrder.push(j);
        for (auto& edge : adj[j]) {
            int k = edge.first, w = edge.second;
            indegree[k]--;
            if (indegree[k] == 0) q.push(k);
            if (ve[j] + w > ve[k])
                ve[k] = ve[j] + w;
        }
    }

    if (topoOrder.size() != V) {
        cout << "图中存在回路，无法计算关键路径！" << endl;
        return;
    }

    // 2. 计算 vl（逆拓扑序）
    vector<int> vl(V, INT_MAX);
    vl[V - 1] = ve[V - 1];  // 汇点

    while (!topoOrder.empty()) {
        int k = topoOrder.top();
        topoOrder.pop();
        if (vl[k] == INT_MAX) vl[k] = ve[k];
        for (int j : revAdj[k]) {
            for (auto& edge : adj[j]) {
                if (edge.first == k && vl[k] - edge.second < vl[j]) {
                    vl[j] = vl[k] - edge.second;
                }
            }
        }
    }

    // 3. 计算活动的最早/最迟开始时间，判断关键活动
    cout << "\n关键路径（关键活动）：" << endl;
    cout << "事件 ve\tvl" << endl;
    for (int i = 0; i < V; i++)
        cout << "v" << i << "    " << ve[i] << "\t" << vl[i] << endl;

    cout << "\n关键活动：" << endl;
    int totalTime = ve[V - 1];
    for (const Arc& arc : arcs) {
        int j = arc.from, k = arc.to, w = arc.weight;
        int ee = ve[j];
        int el = vl[k] - w;
        if (ee == el) {
            cout << j << " -> " << k << " (权值: " << w << ")" << endl;
        }
        cout << "  活动 " << j << "->" << k << "  ee=" << ee << " el=" << el;
        cout << " 余量=" << (el - ee) << endl;
    }
    cout << "工程最短完成时间: " << totalTime << endl;
}
```

```python
from collections import deque

def critical_path(V: int, arcs: list):
    """
    arcs: list of (from, to, weight)
    """
    adj = [[] for _ in range(V)]
    rev_adj = [[] for _ in range(V)]
    indegree = [0] * V

    for u, v, w in arcs:
        adj[u].append((v, w))
        rev_adj[v].append(u)
        indegree[v] += 1

    # 1. 拓扑排序 + 计算 ve
    q = deque([i for i in range(V) if indegree[i] == 0])
    topo = []
    ve = [0] * V

    while q:
        j = q.popleft()
        topo.append(j)
        for k, w in adj[j]:
            indegree[k] -= 1
            if indegree[k] == 0:
                q.append(k)
            ve[k] = max(ve[k], ve[j] + w)

    if len(topo) != V:
        print("图中存在回路！")
        return

    # 2. 计算 vl（逆序）
    vl = [float('inf')] * V
    vl[V - 1] = ve[V - 1]

    for k in reversed(topo):
        if vl[k] == float('inf'):
            vl[k] = ve[k]
        for j in rev_adj[k]:
            for v, w in adj[j]:
                if v == k:
                    vl[j] = min(vl[j], vl[k] - w)

    # 3. 输出
    print("\n事件 ve  vl")
    for i in range(V):
        print(f"v{i} {ve[i]:<5} {vl[i]}")

    print("\n关键活动:")
    for j, k, w in arcs:
        ee = ve[j]
        el = vl[k] - w
        mark = " **关键**" if ee == el else ""
        print(f"  {j} -> {k}  w={w}  ee={ee}  el={el}  余量={el - ee}{mark}")

    print(f"工程最短时间: {ve[V - 1]}")
```

## 8.6 最短路径

### 8.6.1 Dijkstra 算法（单源最短路径，非负权）

**核心思想**：贪心策略。维护已确定最短路径的顶点集合 $S$，每次从 $V - S$ 中选择当前距离最短的顶点加入 $S$，然后用它更新其邻接点的距离。

#### 邻接矩阵版 $O(|V|^2)$

```cpp
// C++ Dijkstra 邻接矩阵 O(V²)
#include <climits>
void dijkstra(const vector<vector<int>>& graph, int src) {
    int V = graph.size();
    vector<int> dist(V, INT_MAX);
    vector<bool> visited(V, false);
    vector<int> prev(V, -1);  // 记录前驱顶点，用于路径重建

    dist[src] = 0;

    for (int count = 0; count < V; count++) {
        // 选择当前距离最小的未访问顶点
        int u = -1, minDist = INT_MAX;
        for (int v = 0; v < V; v++) {
            if (!visited[v] && dist[v] < minDist) {
                minDist = dist[v];
                u = v;
            }
        }

        if (u == -1) break;
        visited[u] = true;

        // 更新邻接点的距离
        for (int v = 0; v < V; v++) {
            if (!visited[v] && graph[u][v] != 0 && graph[u][v] != INT_MAX
                && dist[u] + graph[u][v] < dist[v]) {
                dist[v] = dist[u] + graph[u][v];
                prev[v] = u;
            }
        }
    }

    // 输出结果
    cout << "Dijkstra 从顶点 " << src << " 出发的最短路径：" << endl;
    for (int i = 0; i < V; i++) {
        cout << src << " -> " << i << " : ";
        if (dist[i] == INT_MAX) {
            cout << "不可达" << endl;
        } else {
            cout << dist[i] << "  (路径: ";
            // 重建路径
            vector<int> path;
            for (int v = i; v != -1; v = prev[v])
                path.push_back(v);
            reverse(path.begin(), path.end());
            for (int p : path) cout << p << " ";
            cout << ")" << endl;
        }
    }
}
```

```cpp
// C++ Dijkstra 堆优化
#include <queue>

void dijkstraHeap(const vector<vector<pair<int, int>>>& adj, int src) {
    int V = adj.size();
    vector<int> dist(V, INT_MAX);
    vector<int> prev(V, -1);

    // 优先队列: (距离, 顶点)
    priority_queue<pair<int, int>, vector<pair<int, int>>,
                   greater<pair<int, int>>> pq;

    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        int d = pq.top().first;
        int u = pq.top().second;
        pq.pop();

        if (d > dist[u]) continue;  // 过时的记录，跳过

        for (auto& edge : adj[u]) {
            int v = edge.first;
            int weight = edge.second;
            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                prev[v] = u;
                pq.push({dist[v], v});
            }
        }
    }

    cout << "Dijkstra (堆优化) 从顶点 " << src << " 出发：" << endl;
    for (int i = 0; i < V; i++) {
        cout << src << " -> " << i << " : ";
        if (dist[i] == INT_MAX)
            cout << "不可达" << endl;
        else
            cout << dist[i] << endl;
    }
}
```

### 8.6.2 Floyd-Warshall 算法（所有点对最短路径）

**核心思想**：动态规划。$dp[k][i][j]$ 表示从 $i$ 到 $j$ 且中间顶点编号不超过 $k$ 的最短路径长度。状态转移：

$$dist[i][j] = \min(dist[i][j],\ dist[i][k] + dist[k][j])$$

空间优化后，可以在原矩阵上直接更新（因为第 $k$ 轮使用的 $dist[i][k]$ 和 $dist[k][j]$ 在第 $k$ 轮不会改变）。

时间复杂度：$O(|V|^3)$

```cpp
// C++ Floyd-Warshall 所有点对最短路径
void floydWarshall(vector<vector<int>>& dist) {
    int V = dist.size();

    // 初始化：dist 就是邻接矩阵
    // dist[i][j] = 权值 或 INT_MAX (不可达) 或 0 (i==j)

    // 记录前驱（用于路径重建）
    vector<vector<int>> next(V, vector<int>(V, -1));
    for (int i = 0; i < V; i++) {
        for (int j = 0; j < V; j++) {
            if (dist[i][j] != INT_MAX && i != j)
                next[i][j] = j;
        }
    }

    // 以 k 为中间点
    for (int k = 0; k < V; k++) {
        for (int i = 0; i < V; i++) {
            for (int j = 0; j < V; j++) {
                if (dist[i][k] != INT_MAX && dist[k][j] != INT_MAX
                    && dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                    next[i][j] = next[i][k];
                }
            }
        }
    }

    // 检查负环
    for (int i = 0; i < V; i++) {
        if (dist[i][i] < 0) {
            cout << "图中存在负权回路！" << endl;
            return;
        }
    }

    // 输出结果
    cout << "Floyd-Warshall 所有点对最短路径：" << endl;
    for (int i = 0; i < V; i++) {
        for (int j = 0; j < V; j++) {
            if (dist[i][j] == INT_MAX)
                cout << "INF ";
            else
                cout << dist[i][j] << " ";
        }
        cout << endl;
    }

    // 路径重建示例
    cout << "\n路径重建示例（0->V-1）：";
    if (next[0][V - 1] != -1) {
        int u = 0;
        while (u != V - 1) {
            cout << u << " -> ";
            u = next[u][V - 1];
        }
        cout << V - 1 << endl;
    }
}
```

```python
# Python Floyd-Warshall 所有点对最短路径
def floyd_warshall(dist: list):
    """
    dist: 邻接矩阵, dist[i][j] = 权值 或 float('inf')
    原地修改 dist, 返回最短路径矩阵
    """
    V = len(dist)
    # 记录路径
    nxt = [[j if dist[i][j] != float('inf') and i != j else -1
           for j in range(V)] for i in range(V)]

    for k in range(V):
        for i in range(V):
            for j in range(V):
                if dist[i][k] != float('inf') and dist[k][j] != float('inf'):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]
                        nxt[i][j] = nxt[i][k]

    # 检查负环
    for i in range(V):
        if dist[i][i] < 0:
            print("图中存在负权回路！")
            return None

    print("Floyd-Warshall 所有点对最短路径：")
    for row in dist:
        print(" ".join("INF" if x == float('inf') else str(x) for x in row))

    # 路径重建
    def reconstruct(u, v):
        if nxt[u][v] == -1:
            return []
        path = [u]
        while u != v:
            u = nxt[u][v]
            path.append(u)
        return path

    print(f"\n路径 0 -> {V-1}: {reconstruct(0, V-1)}")
    return dist
```

### 8.6.3 Bellman-Ford 算法（含负权边）

可以处理负权边，但不能处理负权回路。时间复杂度 $O(|V| \cdot |E|)$。

```cpp
// C++ Bellman-Ford 单源最短路径（含负权边）
#include <tuple>

bool bellmanFord(int V, const vector<tuple<int, int, int>>& edges, int src,
                 vector<int>& dist) {
    dist.assign(V, INT_MAX);
    dist[src] = 0;

    // 松弛 V-1 次
    for (int i = 1; i <= V - 1; i++) {
        bool updated = false;
        for (const auto& edge : edges) {
            int u = get<0>(edge), v = get<1>(edge), w = get<2>(edge);
            if (dist[u] != INT_MAX && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                updated = true;
            }
        }
        if (!updated) break;  // 提前终止
    }

    // 检测负权回路
    for (const auto& edge : edges) {
        int u = get<0>(edge), v = get<1>(edge), w = get<2>(edge);
        if (dist[u] != INT_MAX && dist[u] + w < dist[v]) {
            cout << "存在负权回路！" << endl;
            return false;
        }
    }

    return true;
}
```

```python
# Python Bellman-Ford 单源最短路径（含负权边）
def bellman_ford(V: int, edges: list, src: int) -> list:
    """
    edges: list of (u, v, weight)
    返回: dist 数组，若存在负权回路返回 None
    """

    dist[src] = 0

    # 松弛 V-1 次
    for _ in range(V - 1):
        updated = False
        for u, v, w in edges:
            if dist[u] != float('inf') and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break

    # 检测负权回路
    for u, v, w in edges:
        if dist[u] != float('inf') and dist[u] + w < dist[v]:
            print("存在负权回路！")
            return None

    return dist
```

### 8.6.4 最短路径算法总结

| 算法 | 适用条件 | 时间复杂度 | 特点 |
|---|---|---|---|
| **Dijkstra** | 非负权，单源 | $O(|V|^2)$ 或 $O((|V|+|E|)\log |V|)$ | 贪心，最常用 |
| **Floyd-Warshall** | 所有点对 | $O(|V|^3)$ | 动态规划，可处理负权但不能有负环 |
| **Bellman-Ford** | 单源，可含负权 | $O(|V| \cdot |E|)$ | 能检测负权回路 |
| **SPFA** | Bellman-Ford 队列优化 | 平均 $O(|E|)$，最坏 $O(|V| \cdot |E|)$ | 实际常比 Bellman-Ford 快 |

## 总结

本章全面覆盖了图的定义、存储和经典算法：

1. **图的术语和分类**是理解后续内容的基础，无向图/有向图、连通性、度等概念至关重要。
2. **存储结构四种**：邻接矩阵（简单直观，$O(|V|^2)$ 空间）、邻接表（节省空间，$O(|V|+|E|)$）、十字链表（有向图专用，同时方便出/入度）、邻接多重表（无向图专用，边共享）。
3. **DFS 和 BFS** 是图的遍历基础，也是很多高级算法（拓扑排序、连通分量）的基石。
4. **MST** 两大算法：Prim（加点法，$O(|V|^2)$，适合稠密图）和 Kruskal（加边法+并查集，$O(|E|\log |E|)$，适合稀疏图）。
5. **DAG 应用**：拓扑排序（Kahn 和 DFS 两种方法），关键路径（AOE 网，$ve/vl$ 计算）。
6. **最短路径三大算法**：Dijkstra（贪心，非负权，最常用）、Floyd-Warshall（动态规划，所有点对）、Bellman-Ford（可含负权，能检测负环）。
