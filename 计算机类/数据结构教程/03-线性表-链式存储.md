# 线性表——链式存储

## 3.1 链表的基本概念

### 3.1.1 链式存储的思想

**链式存储**打破了顺序存储中元素必须物理相邻的要求。链表通过"结点"来组织数据：每个结点包含**数据域**和**指针域**，指针域存储下一个（或前一个）结点的地址。

**结点（Node）结构**：

```
  单链表结点:                    双链表结点:
  ┌──────┬──────┐              ┌──────┬──────┬──────┐
  │ data │ next │              │ prev │ data │ next │
  └──────┴──────┘              └──────┴──────┴──────┘
   数据域  指针域               前驱指针 数据域 后继指针
```

**链表整体结构**：

```
head → [a1|●] → [a2|●] → [a3|●] → [an|NULL]
        ↑                           ↑
      首元结点                     尾结点
```

### 3.1.2 关键概念

| 术语 | 说明 |
|-----|------|
| **结点（Node）** | 链表的基本存储单元，含数据域和指针域 |
| **头指针（Head Pointer）** | 指向链表中第一个结点的指针；若链表**有头结点**则指向头结点 |
| **头结点（Head Node）** | 附设在首元结点之前的一个结点，数据域通常不存信息或存放表长等信息 |
| **首元结点** | 链表中存储第一个数据元素的结点 |
| **尾结点** | 链表最后一个结点，其 `next` 指针为 `NULL`（或指向头结点于循环链表中）|

### 3.1.3 带头结点 vs 不带头结点

| 对比维度 | 带头结点 | 不带头结点 |
|---------|---------|-----------|
| 结构图示 | `head → [头结点] → [a1] → [a2] → ...` | `head → [a1] → [a2] → ...` |
| 空表判断 | `head->next == nullptr` | `head == nullptr` |
| 首元结点操作 | 与其他位置操作统一，无需特殊处理 | 插入/删除首元素需特殊处理 |
| 代码复杂度 | 较简洁 | 需多写分支判断 |
| 额外空间 | 多一个结点 | 无 |

> **实用建议**：在算法实现中，**带头结点**的链表由于操作统一而更常用，本文默认采用带头结点。

### 3.1.4 顺序存储 vs 链式存储 全面对比

| 对比维度 | 顺序表（数组） | 链表 |
|---------|:-----------:|:---:|
| **存储方式** | 连续内存空间 | 结点可散列存储 |
| **容量** | 固定/需预先分配（或动态扩容） | 按需分配，无容量限制 |
| **随机存取** | $O(1)$ ✓ | $O(n)$ ✗ |
| **按位插入/删除** | $O(n)$（需移动） | $O(n)$（找前驱） |
| **给定结点后插入/删除** | — | $O(1)$ |
| **存储密度** | 高（纯数据） | 低（需指针额外开销） |
| **缓存友好性** | 好（连续存储） | 差（结点分散） |
| **查找（按值）** | $O(n)$ | $O(n)$ |
| **实现复杂度** | 简单 | 指针操作需谨慎 |

## 3.2 单链表（Singly Linked List）

### 3.2.1 单链表结点的定义

**C++ 定义**：

```cpp
template <typename T>
struct LNode {
    T data;           // 数据域
    LNode<T>* next;   // 指针域，指向直接后继

    // 构造函数
    LNode() : next(nullptr) {}
    LNode(const T& val) : data(val), next(nullptr) {}
    LNode(const T& val, LNode<T>* p) : data(val), next(p) {}
};
```

**Python 定义**：

```python
from typing import Optional, Any

class LNode:
    """单链表结点"""
    def __init__(self, data: Any = None):
        self.data = data       # 数据域
        self.next: Optional[LNode] = None  # 指针域
```

### 3.2.2 单链表的 ADT 定义

```
ADT LinkList {
    数据对象 D:  {ai | ai ∈ ElemType, i = 1, 2, ..., n, n ≥ 0}
    数据关系 S:  {<a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, i = 2, ..., n}
    基本操作 P:
        CreateList_H(n):  头插法创建含 n 个元素的单链表
        CreateList_T(n):  尾插法创建含 n 个元素的单链表
        Empty():          判断链表是否为空
        Length():         返回链表长度
        GetElem(i, &e):   获取第 i 个元素（从 1 开始）
        LocateElem(e):    按值查找，返回首次出现位置
        Insert(i, e):     在第 i 个位置插入元素 e
        Delete(i, &e):    删除第 i 个元素，并用 e 返回
        Reverse():        原地反转链表
        Clear():          清空链表
        Traverse(visit):  遍历链表
} ADT LinkList
```

## 3.3 单链表基本操作详解

### 3.3.1 创建链表：头插法

**原理**：每次将新结点插入到链表头部（头结点之后）。生成链表顺序与输入顺序**相反**。

```
输入序列: 10, 20, 30

Step 1: head → [30] → NULL
Step 2: head → [20] → [30] → NULL
Step 3: head → [10] → [20] → [30] → NULL

最终: head → [10] → [20] → [30] → NULL  （输入 10,20,30 但构造时每次插在头部）
```

> 实际上头插法的结果是**逆序**的：若输入 $(a_1, a_2, ..., a_n)$，头插法得到的链表为 $a_n → ... → a_2 → a_1$。

**时间复杂度**：$O(n)$（每个元素插入操作是 $O(1)$，$n$ 个共 $O(n)$）

**C++ 实现**：

```cpp
template <typename T>
void LinkList<T>::CreateList_H(const vector<T>& values) {
    for (const T& val : values) {
        LNode<T>* newNode = new LNode<T>(val);
        newNode->next = head->next;  // 新结点指向原首元结点
        head->next = newNode;        // 头结点指向新结点
    }
}
```

**Python 实现**：

```python
@classmethod
def create_head_insert(cls, values: list) -> 'LinkList':
    """头插法创建链表，O(n)"""
    ll = cls()
    for val in values:
        new_node = LNode(val)
        new_node.next = ll._head.next
        ll._head.next = new_node
    return ll
```

### 3.3.2 创建链表：尾插法

**原理**：每次将新结点插入到链表尾部。生成链表顺序与输入顺序**相同**。需要一个尾指针 `tail` 始终指向最后一个结点。

```
输入序列: 10, 20, 30

初始: head → NULL  (tail = head)
Step 1: head → [10] → NULL  (tail 更新)
Step 2: head → [10] → [20] → NULL
Step 3: head → [10] → [20] → [30] → NULL
```

**时间复杂度**：$O(n)$

**C++ 实现**：

```cpp
template <typename T>
void LinkList<T>::CreateList_T(const vector<T>& values) {
    LNode<T>* tail = head;  // tail 指向尾结点（初始为头结点）
    for (const T& val : values) {
        LNode<T>* newNode = new LNode<T>(val);
        tail->next = newNode;  // 尾结点链接新结点
        tail = newNode;        // 更新尾指针
    }
}
```

**Python 实现**：

```python
@classmethod
def create_tail_insert(cls, values: list) -> 'LinkList':
    """尾插法创建链表，O(n)"""
    ll = cls()
    tail = ll._head  # 初始尾指针指向头结点
    for val in values:
        new_node = LNode(val)
        tail.next = new_node
        tail = new_node  # 更新尾指针
    return ll
```

```python
def __str__(self) -> str:

        p = p.next
```

### 3.3.4 求表长 Length()

**原理**：从头指针开始，沿 `next` 指针链遍历，计数直到尾结点（`NULL`）。

**时间复杂度**：$O(n)$

**C++ 实现**：

```cpp
template <typename T>
int LinkList<T>::Length() const {
    int len = 0;
    LNode<T>* p = head->next;  // 从首元结点开始
    while (p) {
        len++;
        p = p->next;
    }
    return len;
}
```

**Python 实现**：

```python
def __len__(self) -> int:
    """返回链表长度，O(n)"""
    length = 0
    p = self._head.next
    while p:
        length += 1
        p = p.next
    return length
```

### 3.3.5 按位查找 GetElem(i, &e)

**原理**：从首元结点出发，沿指针链向后移动 $i-1$ 步，定位到第 $i$ 个结点。

```
查找第 i 个元素:
  p = head → next;  // p 指向首元结点（第 1 个）
  j = 1;
  while (p && j < i) { p = p->next; j++; }
  // 循环结束: j = i 或 p = NULL
```

**时间复杂度**：$O(n)$（最坏需遍历到表尾）

**C++ 实现**：

```cpp
template <typename T>
bool LinkList<T>::GetElem(int i, T& e) const {
    if (i < 1) return false;
    LNode<T>* p = head->next;
    int j = 1;
    while (p && j < i) {
        p = p->next;
        j++;
    }
    if (!p) return false;  // i 超过表长
    e = p->data;
    return true;
}
```

**Python 实现**：

```python
def get_elem(self, i: int) -> Any:
    """获取第 i 个元素（位序从 1 开始），O(n)"""
    if i < 1:
        raise IndexError(f"位序 {i} 必须 >= 1")
    p = self._head.next
    j = 1
    while p and j < i:
        p = p.next
        j += 1
    if not p:
        raise IndexError(f"位序 {i} 越界")
    return p.data
```

### 3.3.6 按值查找 LocateElem(e)

**原理**：从首元结点出发依次比较各结点数据域，找到则返回位序，未找到返回 0（或 -1）。

**时间复杂度**：$O(n)$（最坏需遍历到表尾）

**C++ 实现**：

```cpp
template <typename T>
int LinkList<T>::LocateElem(const T& e) const {
    LNode<T>* p = head->next;
    int pos = 1;
    while (p) {
        if (p->data == e) return pos;
        p = p->next;
        pos++;
    }
    return 0;  // 未找到
}
```

**Python 实现**：

```python
def locate_elem(self, e: Any) -> int:
    """按值查找，返回首次出现的位序（从 1 开始），未找到返回 0，O(n)"""
    p = self._head.next
    pos = 1
    while p:
        if p.data == e:
            return pos
        p = p.next
        pos += 1
    return 0
```

### 3.3.7 插入元素 Insert(i, e)

**原理**：在第 $i$ 个位置插入新元素 $e$，需要先找到第 $i-1$ 个结点（前驱），然后执行指针重链。

**指针操作步骤**：

```
插入前:  ... → [p] → [p->next] → ...
                     ↑
              s = [新结点e]

Step 1:  s->next = p->next;     // 新结点指向原第 i 个结点
Step 2:  p->next = s;            // 前驱结点指向新结点

插入后:  ... → [p] → [e] → [原第i个结点] → ...
```

> **Warning**：步骤顺序不可颠倒！若先执行 `p->next = s`，会丢失原后继结点的引用。

**时间复杂度**：
- 查找前驱：$O(n)$
- 插入操作：$O(1)$
- 总体：$O(n)$

> **特例**：若已知前驱结点 `p`，仅需执行上述两步操作，时间复杂度为 $O(1)$。这正是链表胜过顺序表的场景。

**C++ 实现**：

```cpp
template <typename T>
bool LinkList<T>::Insert(int i, const T& e) {
    if (i < 1) return false;

    // 找到第 i-1 个结点（插入位置的前驱）
    LNode<T>* p = head;
    int j = 0;
    while (p && j < i - 1) {
        p = p->next;
        j++;
    }

    if (!p) return false;  // i 越界

    LNode<T>* s = new LNode<T>(e);
    s->next = p->next;
    p->next = s;
    return true;
}

// 在给定结点 p 之后插入（O(1)）
template <typename T>
bool LinkList<T>::InsertAfter(LNode<T>* p, const T& e) {
    if (!p) return false;
    LNode<T>* s = new LNode<T>(e);
    s->next = p->next;
    p->next = s;
    return true;
}
```

**Python 实现**：

```python
def insert(self, i: int, e: Any) -> bool:
    """在第 i 个位置插入元素 e（位序从 1 开始），O(n)"""
    if i < 1:
        return False

    # 找到第 i-1 个结点
    p = self._head
    j = 0
    while p and j < i - 1:
        p = p.next
        j += 1

    if not p:
        return False

    new_node = LNode(e)
    new_node.next = p.next
    p.next = new_node
    return True

# 在给定结点 p 之后插入（O(1)）
def insert_after(self, p: LNode, e: Any) -> None:
    """在结点 p 之后插入新元素 e，O(1)"""
    if not p:
        return
    new_node = LNode(e)
    new_node.next = p.next
    p.next = new_node
```

### 3.3.8 删除元素 Delete(i, &e)

**原理**：删除第 $i$ 个元素，先找到第 $i-1$ 个结点（前驱），然后修改指针删除第 $i$ 个结点。

**指针操作步骤**：

```
删除前:  ... → [p] → [q] → [q->next] → ...
             前驱    待删

Step 1:  p->next = q->next;     // 前驱跳过待删结点
Step 2:  delete q;               // 释放内存

删除后:  ... → [p] → [q->next] → ...
```

**时间复杂度**：$O(n)$（找前驱），但若已知前驱则为 $O(1)$。

**C++ 实现**：

```cpp
template <typename T>
bool LinkList<T>::Delete(int i, T& e) {
    if (i < 1) return false;

    // 找到第 i-1 个结点
    LNode<T>* p = head;
    int j = 0;
    while (p->next && j < i - 1) {
        p = p->next;
        j++;
    }

    if (!p->next) return false;  // 第 i 个结点不存在

    LNode<T>* q = p->next;   // q 指向待删结点
    e = q->data;              // 保存被删结点的值
    p->next = q->next;        // 摘除结点
    delete q;                 // 释放内存
    return true;
}
```

**Python 实现**：

```python
def delete(self, i: int) -> Any:
    """删除第 i 个元素，返回被删元素的值，O(n)"""
    if i < 1:
        raise IndexError(f"位序 {i} 必须 >= 1")

    # 找到第 i-1 个结点
    p = self._head
    j = 0
    while p.next and j < i - 1:
        p = p.next
        j += 1

    if not p.next:
        raise IndexError(f"位序 {i} 越界")

    q = p.next         # 待删结点
    e = q.data         # 保存数据
    p.next = q.next    # 摘除结点
    return e
```

### 3.3.9 反转链表 Reverse()

**原理**：将链表原地反转，使原来 $a_1 → a_2 → ... → a_n$ 变为 $a_n → ... → a_2 → a_1$。

#### 方法一：迭代法（三指针）

**核心思想**：遍历链表，逐个改变 `next` 指针方向。

```
初始：  head → [A]→[B]→[C]→NULL
        pre=null, cur=A, next=null

Step1: next = B;  A→null;  pre=A;  cur=B
Step2: next = C;  B→A;     pre=B;  cur=C
Step3: next=null; C→B;     pre=C;  cur=null (停止)

结果：  head → [C]→[B]→[A]→NULL
```

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

**C++ 实现**：

```cpp
template <typename T>
void LinkList<T>::Reverse() {
    LNode<T>* prev = nullptr;
    LNode<T>* curr = head->next;
    while (curr) {
        LNode<T>* next = curr->next;  // 暂存后继
        curr->next = prev;            // 反转指针
        prev = curr;                  // 前移 prev
        curr = next;                  // 前移 curr
    }
    head->next = prev;  // 头结点指向新首元结点
}
```

**Python 实现**：

```python
def reverse(self) -> None:
    """原地反转链表（迭代法），O(n), S(1)"""
    prev = None
    curr = self._head.next
    while curr:
        next_node = curr.next  # 暂存后继
        curr.next = prev       # 反转指针
        prev = curr            # 前移 prev
        curr = next_node       # 前移 curr
    self._head.next = prev     # 头结点指向新首元结点
```

#### 方法二：递归法

**核心思想**：递归到最后一个结点，回溯时修改指针。

```cpp
// C++ 递归反转
template <typename T>
LNode<T>* LinkList<T>::ReverseRecursive(LNode<T>* node) {
    if (!node || !node->next) return node;

    LNode<T>* newHead = ReverseRecursive(node->next);
    node->next->next = node;  // 后继指向自己
    node->next = nullptr;     // 自己的 next 置空
    return newHead;
}

template <typename T>
void LinkList<T>::Reverse_Recursive() {
    head->next = ReverseRecursive(head->next);
}
```

```python
# Python 递归反转
def reverse_recursive(self) -> None:
    """递归反转链表，O(n), S(n)（递归栈）"""
    def _reverse(node: Optional[LNode]) -> Optional[LNode]:
        if not node or not node.next:
            return node
        new_head = _reverse(node.next)
        node.next.next = node
        node.next = None
        return new_head

    self._head.next = _reverse(self._head.next)
```

### 3.3.10 清空与析构

**C++ 实现**：

```cpp
// 清空链表（保留头结点）
template <typename T>
void LinkList<T>::Clear() {
    LNode<T>* p = head->next;
    while (p) {
        LNode<T>* temp = p;
        p = p->next;
        delete temp;
    }
    head->next = nullptr;
}

// 析构函数
template <typename T>
LinkList<T>::~LinkList() {
    Clear();
    delete head;
    head = nullptr;
}
```

**Python 实现**：

```python
def clear(self) -> None:
    """清空链表（保留头结点），O(n)"""
    p = self._head.next
    while p:
        nxt = p.next
        p.next = None  # 断开引用，辅助 GC
        p = nxt
    self._head.next = None
```

## 3.4 单链表的完整实现

### 3.4.1 C++ 完整实现

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>
using namespace std;

// ==================== 结点定义 ====================

template <typename T>
struct LNode {
    T data;
    LNode<T>* next;

    LNode() : next(nullptr) {}
    LNode(const T& val) : data(val), next(nullptr) {}
    LNode(const T& val, LNode<T>* p) : data(val), next(p) {}
};

// ==================== 单链表类定义 ====================

template <typename T>
class LinkList {
private:
    LNode<T>* head;  // 头指针（指向头结点）

public:
    // ===== 构造与析构 =====

    LinkList() {
        head = new LNode<T>();  // 创建头结点（不存数据）
    }

    LinkList(const vector<T>& values) {
        head = new LNode<T>();
        LNode<T>* tail = head;
        for (const T& val : values) {
            LNode<T>* node = new LNode<T>(val);
            tail->next = node;
            tail = node;
        }
    }

    // 拷贝构造
    LinkList(const LinkList<T>& other) {
        head = new LNode<T>();
        LNode<T>* tail = head;
        LNode<T>* p = other.head->next;
        while (p) {
            tail->next = new LNode<T>(p->data);
            tail = tail->next;
            p = p->next;
        }
    }

    ~LinkList() {
        Clear();
        delete head;
    }

    // 赋值运算符
    LinkList<T>& operator=(const LinkList<T>& other) {
        if (this != &other) {
            Clear();
            LNode<T>* tail = head;
            LNode<T>* p = other.head->next;
            while (p) {
                tail->next = new LNode<T>(p->data);
                tail = tail->next;
                p = p->next;
            }
        }
        return *this;
    }

    // ===== 基本操作 =====

    bool Empty() const { return head->next == nullptr; }

    int Length() const {
        int len = 0;
        LNode<T>* p = head->next;
        while (p) { len++; p = p->next; }
        return len;
    }

    void CreateList_H(const vector<T>& values) {
        for (const T& val : values) {
            LNode<T>* node = new LNode<T>(val);
            node->next = head->next;
            head->next = node;
        }
    }

    void CreateList_T(const vector<T>& values) {
        LNode<T>* tail = head;
        while (tail->next) tail = tail->next;  // 找到尾部
        for (const T& val : values) {
            LNode<T>* node = new LNode<T>(val);
            tail->next = node;
            tail = node;
        }
    }

    bool GetElem(int i, T& e) const {
        if (i < 1) return false;
        LNode<T>* p = head->next;
        int j = 1;
        while (p && j < i) { p = p->next; j++; }
        if (!p) return false;
        e = p->data;
        return true;
    }

    int LocateElem(const T& e) const {
        LNode<T>* p = head->next;
        int pos = 1;
        while (p) {
            if (p->data == e) return pos;
            p = p->next; pos++;
        }
        return 0;
    }

    bool PriorElem(const T& cur_e, T& pre_e) const {
        LNode<T>* p = head;
        while (p->next) {
            if (p->next->data == cur_e) {
                if (p == head) return false;  // 第一个元素无前驱
                pre_e = p->data;
                return true;
            }
            p = p->next;
        }
        return false;
    }

    bool NextElem(const T& cur_e, T& next_e) const {
        LNode<T>* p = head->next;
        while (p && p->next) {
            if (p->data == cur_e) {
                next_e = p->next->data;
                return true;
            }
            p = p->next;
        }
        return false;
    }

    bool Insert(int i, const T& e) {
        if (i < 1) return false;
        LNode<T>* p = head;
        int j = 0;
        while (p && j < i - 1) { p = p->next; j++; }
        if (!p) return false;

        LNode<T>* node = new LNode<T>(e);
        node->next = p->next;
        p->next = node;
        return true;
    }

    bool Delete(int i, T& e) {
        if (i < 1) return false;
        LNode<T>* p = head;
        int j = 0;
        while (p->next && j < i - 1) { p = p->next; j++; }
        if (!p->next) return false;

        LNode<T>* q = p->next;
        e = q->data;
        p->next = q->next;
        delete q;
        return true;
    }

    void Reverse() {
        LNode<T>* prev = nullptr;
        LNode<T>* curr = head->next;
        while (curr) {
            LNode<T>* next = curr->next;
            curr->next = prev;
            prev = curr;
            curr = next;
        }
        head->next = prev;
    }

    void Clear() {
        LNode<T>* p = head->next;
        while (p) {
            LNode<T>* temp = p;
            p = p->next;
            delete temp;
        }
        head->next = nullptr;
    }

    void Print() const {
        LNode<T>* p = head->next;
        while (p) {
            cout << p->data;
            if (p->next) cout << " → ";
            p = p->next;
        }
        cout << endl;
    }

    // 返回头结点
    LNode<T>* GetHead() const { return head; }
};
```

```python
from typing import Optional, Any, Callable, List


class LNode:
    """单链表结点"""

    def __init__(self, data: Any = None):
        self.data = data
        self.next: Optional['LNode'] = None


class LinkList:
    """带头结点的单链表"""

    # ==================== 构造 ====================

    def __init__(self):
        """初始化空链表（带头结点），O(1)"""
        self._head = LNode()  # 头结点（不存数据）

    @classmethod
    def from_list(cls, values: List[Any], head_insert: bool = False) -> 'LinkList':
        """
        从列表创建链表
        head_insert=True: 头插法（逆序）；False: 尾插法（顺序）
        """
        ll = cls()
        if head_insert:
            for val in values:
                node = LNode(val)
                node.next = ll._head.next
                ll._head.next = node
        else:
            tail = ll._head
            for val in values:
                node = LNode(val)
                tail.next = node
                tail = node
        return ll

    # ==================== 属性 ====================

    @property
    def head(self) -> LNode:
        """返回头结点（数据域为空）"""
        return self._head

    @property
    def first(self) -> Optional[LNode]:
        """返回首元结点"""
        return self._head.next

    # ==================== 基本操作 ====================

    def __len__(self) -> int:
        """返回链表长度，O(n)"""
        length = 0
        p = self._head.next
        while p:
            length += 1
            p = p.next
        return length

    def __str__(self) -> str:
        """字符串表示，O(n)"""
        items = []
        p = self._head.next
        while p:
            items.append(str(p.data))
            p = p.next
        return " → ".join(items) if items else "(空链表)"

    def __repr__(self) -> str:
        return f"LinkList([{str(self)}])"

    def __iter__(self):
        """支持迭代，O(n)"""
        p = self._head.next
        while p:
            yield p.data
            p = p.next

    def __getitem__(self, index: int) -> Any:
        """支持 L[i] 访问（0-based 下标），O(n)"""
        if index < 0:
            # 支持负索引
            length = len(self)
            index += length
        if index < 0:
            raise IndexError(f"下标 {index} 越界")
        p = self._head.next
        for _ in range(index):
            if not p:
                raise IndexError(f"下标 {index} 越界")
            p = p.next
        if not p:
            raise IndexError(f"下标 {index} 越界")
        return p.data

    def empty(self) -> bool:
        """判断链表是否为空，O(1)"""
        return self._head.next is None

    def get_elem(self, i: int) -> Any:
        """按位查找：获取第 i 个元素（位序从 1 开始），O(n)"""
        if i < 1:
            raise IndexError(f"位序 {i} 必须 >= 1")
        p = self._head.next
        j = 1
        while p and j < i:
            p = p.next
            j += 1
        if not p:
            raise IndexError(f"位序 {i} 越界，表长为 {len(self)}")
        return p.data

    def locate_elem(self, e: Any) -> int:
        """按值查找：返回首次出现的位序（从 1 开始），未找到返回 0，O(n)"""
        p = self._head.next
        pos = 1
        while p:
            if p.data == e:
                return pos
            p = p.next
            pos += 1
        return 0

    def prior_elem(self, cur_e: Any) -> Optional[Any]:
        """获取 cur_e 的前驱元素，O(n)"""
        p = self._head
        while p.next:
            if p.next.data == cur_e:
                if p is self._head:
                    return None  # 第一个元素无前驱
                return p.data
            p = p.next
        return None

    def next_elem(self, cur_e: Any) -> Optional[Any]:
        """获取 cur_e 的后继元素，O(n)"""
        p = self._head.next
        while p and p.next:
            if p.data == cur_e:
                return p.next.data
            p = p.next
        return None

    def insert(self, i: int, e: Any) -> bool:
        """在第 i 个位置插入元素 e（位序从 1 开始），O(n)"""
        if i < 1:
            return False
        p = self._head
        j = 0
        while p and j < i - 1:
            p = p.next
            j += 1
        if not p:
            return False

        new_node = LNode(e)
        new_node.next = p.next
        p.next = new_node
        return True

    def insert_after(self, node: LNode, e: Any) -> None:
        """在给定结点 node 之后插入新元素 e，O(1)"""
        if node is None:
            return
        new_node = LNode(e)
        new_node.next = node.next
        node.next = new_node

    def delete(self, i: int) -> Any:
        """删除第 i 个元素，返回被删元素的值，O(n)"""
        if i < 1:
            raise IndexError(f"位序 {i} 必须 >= 1")
        p = self._head
        j = 0
        while p.next and j < i - 1:
            p = p.next
            j += 1
        if not p.next:
            raise IndexError(f"位序 {i} 越界")

        q = p.next
        e = q.data
        p.next = q.next
        return e

    def prepend(self, e: Any) -> None:
        """在头部添加元素，O(1)"""
        node = LNode(e)
        node.next = self._head.next
        self._head.next = node

    def append(self, e: Any) -> None:
        """在尾部添加元素，O(n)（如需频繁尾部操作应维护尾指针）"""
        p = self._head
        while p.next:
            p = p.next
        p.next = LNode(e)

    def reverse(self) -> None:
        """原地反转链表（迭代法），O(n), S(1)"""
        prev = None
        curr = self._head.next
        while curr:
            nxt = curr.next
            curr.next = prev
            prev = curr
            curr = nxt
        self._head.next = prev

    def clear(self) -> None:
        """清空链表（保留头结点），O(n)"""
        p = self._head.next
        while p:
            nxt = p.next
            p.next = None  # 辅助垃圾回收
            p = nxt
        self._head.next = None

    def to_list(self) -> List[Any]:
        """将链表转换为 Python 列表，O(n)"""
        return list(self)

    def find_node(self, i: int) -> Optional[LNode]:
        """返回指向第 i 个元素的结点的指针（用于高效连续操作），O(n)"""
        if i < 1:
            return None
        p = self._head.next
        j = 1
        while p and j < i:
            p = p.next
            j += 1
        return p
```

## 3.5 双链表（Doubly Linked List）

### 3.5.1 结点结构

双链表每个结点有两个指针域：一个指向前驱 `prev`，一个指向后继 `next`。

```
NULL ← [prev|data|next] ↔ [prev|data|next] ↔ [prev|data|next] → NULL
        ↑ 头结点（无数据）        ↑ 首元结点           ↑ 尾结点
```

**双链表的优势**：
- 可从任意结点出发访问其前驱和后继
- 删除给定结点时无需先找到前驱（可直接通过 `p->prev` 访问）
- 反向遍历方便

**C++ 结点定义**：

```cpp
template <typename T>
struct DNode {
    T data;
    DNode<T>* prev;
    DNode<T>* next;

    DNode() : prev(nullptr), next(nullptr) {}
    DNode(const T& val) : data(val), prev(nullptr), next(nullptr) {}
};
```

**Python 结点定义**：

```python
class DNode:
    """双链表结点"""
    def __init__(self, data: Any = None):
        self.data = data
        self.prev: Optional['DNode'] = None
        self.next: Optional['DNode'] = None
```

### 3.5.2 双链表的插入操作

在结点 `p` 之后插入新结点 `s`：

```
插入前:  ... ↔ [p] ↔ [p->next] ↔ ...
                 ↑
          s = [新结点e]

Step 1:  s->next = p->next;
Step 2:  s->prev = p;
Step 3:  p->next->prev = s;  // 若 p->next 不为空
Step 4:  p->next = s;

插入后:  ... ↔ [p] ↔ [e] ↔ [原p->next] ↔ ...
```

**注意**：步骤 3 需要判断 `p->next` 是否为 `NULL`，若为尾结点则跳过。

**时间复杂度**：已知前驱 $p$ 时 $O(1)$，否则需先查找前驱 $O(n)$。

**C++ 实现**：

```cpp
template <typename T>
bool DLinkList<T>::Insert(int i, const T& e) {
    if (i < 1) return false;

    DNode<T>* p = head;  // head 为头结点
    int j = 0;
    while (p && j < i - 1) { p = p->next; j++; }
    if (!p) return false;

    DNode<T>* s = new DNode<T>(e);

    s->next = p->next;
    s->prev = p;
    if (p->next) p->next->prev = s;
    p->next = s;

    return true;
}
```

**Python 实现**：


### 3.5.3 双链表的删除操作

删除结点 `p` 的后继结点 `q`：

```
删除前:  ... ↔ [p] ↔ [q] ↔ [q->next] ↔ ...
             前驱    待删

Step 1:  p->next = q->next;
Step 2:  if (q->next) q->next->prev = p;
Step 3:  delete q;  // 释放内存

删除后:  ... ↔ [p] ↔ [q->next] ↔ ...
```

**C++ 实现**：

```cpp
template <typename T>
bool DLinkList<T>::Delete(int i, T& e) {
    if (i < 1) return false;

    DNode<T>* p = head;
    int j = 0;
    while (p->next && j < i - 1) { p = p->next; j++; }
    if (!p->next) return false;

    DNode<T>* q = p->next;
    e = q->data;
    p->next = q->next;
    if (q->next) q->next->prev = p;
    delete q;

    return true;
}
```

**Python 实现**：

## 3.6 循环链表（Circular Linked List）

### 3.6.1 单循环链表

**结构**：尾结点的 `next` 指针指向头结点（或首元结点），形成环。

```
     ┌→ [头结点] → [a1] → [a2] → ... → [an] ┐
     └───────────────────────────────────────┘
```

**判断空表**（带头结点）：`head->next == head`

**判断表尾**：`p->next == head`

**特点**：
- 从任一结点出发均可遍历整个链表
- 适合需要循环访问的场景

### 3.6.2 双循环链表

```
     ┌→ [头结点] ↔ [a1] ↔ [a2] ↔ ... ↔ [an] ┐
     └───────────────────────────────────────┘
```

**判断空表**（带头结点）：`head->next == head && head->prev == head`

## 3.7 静态链表（Static Linked List）

### 3.7.1 概念

**静态链表**是用**一维数组**来描述线性链表。数组中的每个分量是一个结点，含数据域 `data` 和游标域 `cursor`（存储下一个结点在数组中的下标，而非内存地址）。

```
下标:   0       1       2       3       4       5       ...
      [游标] [data,cursor] [data,cursor] [data,cursor] ...
      备用链表头                         数据链表头
```

- **游标（cursor）**：存放下一个结点的数组下标（相当于指针）。
- 第 0 个元素通常作为**备用链表**的头结点（管理空闲空间）。
- 数组最后一个元素通常作为**数据链表**的头结点。

**适用场景**：在不支持指针的早期高级语言（如 FORTRAN）中实现链表功能。在现代编程中已较少使用，但理解其原理有助于深入理解"链式"的本质。

**C++ 结构定义**：

```cpp
#define MAXSIZE 1000

template <typename T>
struct SNode {
    T data;
    int cursor;  // 游标：下一个结点的数组下标

template <typename T>
class StaticLinkList {
private:
    SNode<T> space[MAXSIZE];
    int avail;  // 备用链表头下标

    void Free(int k);  // 释放结点
    // ...
};
```

## 3.8 应用案例

### 3.8.1 一元多项式的链表表示与加法

**数据结构设计**：多项式的每一项为一个结点，包含系数 `coef`、指数 `exp` 和 `next` 指针。链表按指数降序排列。

$$P(x) = c_1 x^{e_1} + c_2 x^{e_2} + \dots + c_m x^{e_m}, \quad e_1 > e_2 > \dots > e_m$$

**加法算法**：类似于有序表归并。
- 同时遍历多项式 A 和 B
- 若指数相等：系数相加（若和不为 0，新建结点）
- 若指数不等：取指数较高的项

**时间复杂度**：$O(m + n)$，其中 $m, n$ 分别为两个多项式的项数。

**C++ 实现**：

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 多项式项结点
struct PolyNode {
    double coef;     // 系数
    int exp;         // 指数
    PolyNode* next;

    PolyNode(double c = 0, int e = 0) : coef(c), exp(e), next(nullptr) {}
};

class Polynomial {
private:
    PolyNode* head;  // 带头结点

public:
    Polynomial() { head = new PolyNode(); }
    ~Polynomial() {
        PolyNode* p = head;
        while (p) {
            PolyNode* temp = p;
            p = p->next;
            delete temp;
        }
    }

    // 插入一项（保持指数降序）
    void insertTerm(double coef, int exp) {
        if (coef == 0) return;
        PolyNode* p = head;
        while (p->next && p->next->exp > exp)
            p = p->next;

        if (p->next && p->next->exp == exp) {
            p->next->coef += coef;
            if (p->next->coef == 0) {
                PolyNode* temp = p->next;
                p->next = temp->next;
                delete temp;
            }
        } else {
            PolyNode* node = new PolyNode(coef, exp);
            node->next = p->next;
            p->next = node;
        }
    }

    // 多项式加法
    Polynomial add(const Polynomial& other) const {
        Polynomial result;
        PolyNode* p1 = this->head->next;
        PolyNode* p2 = other.head->next;

        while (p1 && p2) {
            if (p1->exp == p2->exp) {
                double sum = p1->coef + p2->coef;
                if (sum != 0) result.insertTerm(sum, p1->exp);
                p1 = p1->next; p2 = p2->next;
            } else if (p1->exp > p2->exp) {
                result.insertTerm(p1->coef, p1->exp);
                p1 = p1->next;
            } else {
                result.insertTerm(p2->coef, p2->exp);
                p2 = p2->next;
            }
        }

        while (p1) {
            result.insertTerm(p1->coef, p1->exp);
            p1 = p1->next;
        }
        while (p2) {
            result.insertTerm(p2->coef, p2->exp);
            p2 = p2->next;
        }

        return result;
    }

    // 求值（霍纳法则优化）
    double evaluate(double x) const {
        double result = 0;
        PolyNode* p = head->next;
        while (p) {
            result += p->coef * pow(x, p->exp);
            p = p->next;
        }
        return result;
    }

    void print() const {
        if (!head->next) { cout << "0" << endl; return; }
        PolyNode* p = head->next;
        while (p) {
            if (p != head->next && p->coef > 0) cout << "+ ";
            cout << p->coef << "x^" << p->exp << " ";
            p = p->next;
        }
        cout << endl;
    }
};
```

### 3.8.2 LRU 缓存淘汰算法（链表实现）

**LRU（Least Recently Used）**：当缓存满时，淘汰最久未使用的数据。

**数据结构**：使用**双链表 + 哈希表**实现 $O(1)$ 访问和更新。双链表维护访问顺序（头部为最近访问，尾部为最久未访问），哈希表提供 $O(1)$ 定位。

**Python 完整实现**：

```python
from typing import Optional, Dict, Any


class LRUNode:
    """LRU 双链表结点"""
    __slots__ = ('key', 'value', 'prev', 'next')

    def __init__(self, key: Any = None, value: Any = None):
        self.key = key
        self.value = value
        self.prev: Optional['LRUNode'] = None
        self.next: Optional['LRUNode'] = None


class LRUCache:
    """基于双链表 + 哈希表的 LRU 缓存"""

    def __init__(self, capacity: int):
        if capacity <= 0:
            raise ValueError("容量必须 > 0")
        self._capacity = capacity
        self._cache: Dict[Any, LRUNode] = {}

        # 虚拟头尾结点（哨兵）
        self._head = LRUNode()  # 头部哨兵
        self._tail = LRUNode()  # 尾部哨兵
        self._head.next = self._tail
        self._tail.prev = self._head

    def _remove_node(self, node: LRUNode) -> None:
        """从链表中移除结点，O(1)"""
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_to_head(self, node: LRUNode) -> None:
        """将结点添加到链表头部（最近使用），O(1)"""
        node.next = self._head.next
        node.prev = self._head
        self._head.next.prev = node
        self._head.next = node

    def _move_to_head(self, node: LRUNode) -> None:
        """将结点移动到头部，O(1)"""
        self._remove_node(node)
        self._add_to_head(node)

    def _pop_tail(self) -> LRUNode:
        """移除尾部结点（最久未使用），返回被移除的结点，O(1)"""
        node = self._tail.prev
        self._remove_node(node)
        return node

    def get(self, key: Any) -> Any:
        """获取缓存值，若不存在返回 -1，O(1)"""
        if key not in self._cache:
            return -1
        node = self._cache[key]
        # 移到头部（标记为最近使用）
        self._move_to_head(node)
        return node.value

    def put(self, key: Any, value: Any) -> None:
        """插入或更新缓存，O(1)"""
        if key in self._cache:
            # 更新已有值并移到头部
            node = self._cache[key]
            node.value = value
            self._move_to_head(node)
            return

        # 新建结点
        node = LRUNode(key, value)
        self._cache[key] = node
        self._add_to_head(node)

        # 容量超限时淘汰最久未使用
        if len(self._cache) > self._capacity:
            removed = self._pop_tail()
            del self._cache[removed.key]

    def __len__(self) -> int:
        return len(self._cache)

    def __contains__(self, key: Any) -> bool:
        return key in self._cache

    def __str__(self) -> str:
        items = []
        p = self._head.next
        while p != self._tail:
            items.append(f"{p.key}:{p.value}")
            p = p.next
        return "{" + ", ".join(items) + "}"


# ==================== LRU 测试 ====================

if __name__ == "__main__":
    cache = LRUCache(3)
    print(f"初始缓存: {cache}")

    cache.put(1, "A")
    cache.put(2, "B")
    cache.put(3, "C")
    print(f"加入 1:A, 2:B, 3:C: {cache}")     # 3:C, 2:B, 1:A

    cache.get(2)  # 访问 2，移到头部
    print(f"访问 2 后: {cache}")                 # 2:B, 3:C, 1:A

    cache.put(4, "D")  # 容量满，淘汰最久的 (1:A)
    print(f"加入 4:D 后: {cache}")               # 4:D, 2:B, 3:C

    print(f"get(1) = {cache.get(1)}")           # -1 (已淘汰)
    print(f"get(2) = {cache.get(2)}")           # B
```

**C++ 核心实现（LRU）**：

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

struct LRUNode {
    int key, value;
    LRUNode *prev, *next;
    LRUNode(int k = 0, int v = 0) : key(k), value(v), prev(nullptr), next(nullptr) {}
};

class LRUCache {
private:
    int capacity;
    unordered_map<int, LRUNode*> cache;
    LRUNode *head, *tail;  // 哨兵结点

    void removeNode(LRUNode* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
    }

    void addToHead(LRUNode* node) {
        node->next = head->next;
        node->prev = head;
        head->next->prev = node;
        head->next = node;
    }

    void moveToHead(LRUNode* node) {
        removeNode(node);
        addToHead(node);
    }

    LRUNode* popTail() {
        LRUNode* node = tail->prev;
        removeNode(node);
        return node;
    }

public:
    LRUCache(int cap) : capacity(cap) {
        head = new LRUNode();
        tail = new LRUNode();
        head->next = tail;
        tail->prev = head;
    }

    ~LRUCache() {
        LRUNode* p = head;
        while (p) {
            LRUNode* temp = p;
            p = p->next;
            delete temp;
        }
    }

    int get(int key) {
        if (cache.find(key) == cache.end()) return -1;
        LRUNode* node = cache[key];
        moveToHead(node);
        return node->value;
    }

    void put(int key, int value) {
        if (cache.find(key) != cache.end()) {
            LRUNode* node = cache[key];
            node->value = value;
            moveToHead(node);
            return;
        }

        LRUNode* node = new LRUNode(key, value);
        cache[key] = node;
        addToHead(node);

        if (cache.size() > capacity) {
            LRUNode* removed = popTail();
            cache.erase(removed->key);
            delete removed;
        }
    }
};
```

## 3.9 约瑟夫环问题（Josephus Problem）

**问题描述**：$n$ 个人围成一圈，从第 $k$ 个人开始报数，数到 $m$ 的人出列，然后从下一个人继续报数，直到所有人都出列。求出列顺序。

**链表解法**：使用**单循环链表**（不带头结点），每报到 $m$ 时就删除当前结点。

**时间复杂度**：$O(nm)$ 或使用数学递推 $O(n)$。

**Python 实现**：

```python
def josephus(n: int, m: int) -> list:
    """
    n 个人围成一圈，从第 1 个人开始报数，每报到 m 者出列。
    返回出列顺序列表。
    O(nm)
    """
    # 创建单循环链表（不带头结点）
    head = LNode(1)
    p = head
    for i in range(2, n + 1):
        p.next = LNode(i)
        p = p.next
    p.next = head  # 尾结点指向头结点，形成环

    result = []
    prev = p  # prev 初始指向尾结点（即 head 的前驱）
    curr = head

    while n > 0:
        # 报数：走 m-1 步
        for _ in range(m - 1):
            prev = curr
            curr = curr.next

        # 删除 curr 结点
        result.append(curr.data)
        prev.next = curr.next
        curr = curr.next
        n -= 1

    return result


def josephus_math(n: int, m: int) -> int:
    """
    数学递推法（O(n)）：求最后存活者的编号（从 0 开始编号）。
    公式：f(1) = 0; f(i) = (f(i-1) + m) % i
    """
    survivor = 0
    for i in range(2, n + 1):
        survivor = (survivor + m) % i
    return survivor + 1  # 转为从 1 开始的编号


# 测试
print("出列顺序:", josephus(7, 3))          # [3, 6, 2, 7, 5, 1, 4]
print("最后存活:", josephus_math(7, 3))     # 4
```

## 总结

| 知识点 | 要点 |
|-------|------|
| **链表基本概念** | 结点 = 数据域 + 指针域；头指针、头结点、首元结点 |
| **带头结点优势** | 操作统一，无需特殊处理首元结点 |
| **单链表插入/删除** | 查找前驱 $O(n)$，但给定前驱仅 $O(1)$（比顺序表灵活） |
| **头插法 vs 尾插法** | 头插法逆序、$O(1)$ 每次；尾插法顺序、需维护尾指针 |
| **链表反转** | 迭代法 $O(n)$ 时间、$O(1)$ 空间；递归法 $O(n)$ 时间、$O(n)$ 栈空间 |
| **双链表** | 可双向遍历；删除给定结点无需前驱 |
| **循环链表** | 尾结点指向头结点；适合循环型问题（约瑟夫环） |
| **静态链表** | 数组实现链表（游标代替指针） |
| **应用** | 多项式加法（链表归并）、LRU 缓存（双链表+哈希表）、约瑟夫环（循环链表） |
