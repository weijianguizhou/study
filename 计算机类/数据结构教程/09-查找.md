# 第09章：查找

## 9.1 查找的基本概念

### 查找表

**查找表（Search Table）**是由同一类型的数据元素（或记录）构成的集合。数据元素之间可能存在某种特定的逻辑关系（如线性关系、树型关系等），也可能不存在任何关系。

| 概念 | 定义 |
|------|------|
| **查找表** | 由同一类型的数据元素（或记录）构成的集合 |
| **关键字（Key）** | 数据元素中某个数据项的值，用以标识一个数据元素 |
| **主关键字（Primary Key）** | 可以唯一标识一个记录的关键字 |
| **次关键字（Secondary Key）** | 可以识别若干记录的关键字 |
| **查找（Search）** | 根据给定的值，在查找表中确定其关键字等于给定值的数据元素（或记录） |

> **查找的结果只有两种**：查找成功（找到目标记录）和查找失败（未找到目标记录）。

### 静态查找表 vs 动态查找表

| 类型 | 定义 | 典型结构 |
|------|------|----------|
| **静态查找表（Static Search Table）** | 仅作查询和检索操作，不涉及插入和删除 | 顺序表、有序表 |
| **动态查找表（Dynamic Search Table）** | 在查询后，还需要进行插入或删除操作 | 二叉排序树、AVL树、B-树 |

### 平均查找长度（Average Search Length, ASL）

为衡量查找算法的效率，引入**平均查找长度（ASL）**的概念。

对于含有 $n$ 个数据元素的表，查找成功时的平均查找长度为：

$$ASL_{\text{成功}} = \sum_{i=1}^{n} P_i \cdot C_i$$

其中：
- $P_i$ 为查找表中第 $i$ 个数据元素的概率，在等概率假设下 $P_i = \frac{1}{n}$
- $C_i$ 为找到其第 $i$ 个数据元素时需比较的关键字次数

同样地，**查找不成功的平均查找长度**是所有可能的查找不成功情况下的比较次数的加权平均。

## 9.2 静态查找表

### 9.2.1 顺序查找（Sequential Search）

#### 基本思想

从表的一端开始，依次将每个记录的关键字与给定值 `k` 比较。若某个记录的关键字与 `k` 相等，则查找成功；若扫描完整个表仍未找到相等的关键字，则查找失败。

**特点**：对表的结构没有任何要求——可以是有序的，也可以是无序的；可以是顺序存储，也可以是链式存储。

#### 哨兵优化

在顺序存储方式下，可以通过设置**哨兵（Sentinel）**来简化边界判断。将哨兵放置在表的 0 号位置（或表尾），赋值为要查找的关键字值，然后从后向前（或从前向后）查找。这样在循环中只需要检查是否遇到了哨兵，而不需要每次都判断是否越界。

**哨兵查找的步骤**：
1. 将待查找的关键字值赋给 `a[0]`（哨兵位置）
2. 从最后一个元素 `a[n]` 开始向前扫描
3. 当 `a[i] == key` 时停止循环
4. 若 `i == 0`，说明未找到（遇到了哨兵）；否则查找成功，返回索引 `i`

#### 平均查找长度

在等概率假设下：

- **查找成功的 ASL**：$ASL_{ss} = \sum_{i=1}^{n} \frac{1}{n} \cdot i = \frac{n+1}{2}$
- **查找不成功的 ASL**：需要比较 $n+1$ 次（含哨兵），即 $ASL = n+1$

时间复杂度为 $O(n)$。

#### 适用场景

- 数据量较小的情况
- 链表存储的线性表（不支持随机访问，只能用顺序查找）
- 无序表

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 顺序查找（带哨兵），返回下标（0表示未找到）
int SeqSearch_Sentry(vector<int>& a, int key) {
    int n = a.size() - 1; // a[0]是哨兵，实际数据从a[1]开始
    a[0] = key;           // 设置哨兵
    int i;
    for (i = n; a[i] != key; --i); // 从后向前查找
    return i; // i==0表示未找到
}

// 顺序查找（无哨兵），返回下标（-1表示未找到）
int SeqSearch(const vector<int>& a, int key) {
    int n = a.size();
    for (int i = 0; i < n; ++i) {
        if (a[i] == key) return i;
    }
    return -1;
}

// 测试
int main() {
    // 使用哨兵，下标从1开始存储，a[0]预留为哨兵
    vector<int> a = {0, 5, 12, 34, 8, 19, 27, 42}; // a[0]=0是哨兵占位
    cout << "带哨兵查找 34: " << SeqSearch_Sentry(a, 34) << endl; // 输出: 4
    cout << "带哨兵查找 99: " << SeqSearch_Sentry(a, 99) << endl; // 输出: 0 (未找到)

    // 无哨兵版本
    vector<int> b = {5, 12, 34, 8, 19, 27, 42};
    cout << "无哨兵查找 19: " << SeqSearch(b, 19) << endl; // 输出: 4
    cout << "无哨兵查找 99: " << SeqSearch(b, 99) << endl; // 输出: -1 (未找到)

    return 0;
}
```

#### Python 实现

```python
from typing import List, Optional

# 顺序查找（带哨兵），返回下标（0表示未找到）
def seq_search_sentry(a: List[int], key: int) -> int:
    """a[1..n]存储数据，a[0]为哨兵"""
    n = len(a) - 1          # 实际数据元素个数
    a[0] = key              # 设置哨兵
    i = n
    while a[i] != key:
        i -= 1
    return i                # i==0 表示未找到

# 顺序查找（无哨兵），返回下标（-1表示未找到）
def seq_search(a: List[int], key: int) -> int:
    n = len(a)
    for i in range(n):
        if a[i] == key:
            return i
    return -1


if __name__ == '__main__':
    # 带哨兵版本：下标1开始存数据，下标0是哨兵
    a = [0, 5, 12, 34, 8, 19, 27, 42]  # index 0预留哨兵
    print(f"带哨兵查找 34: {seq_search_sentry(a, 34)}")  # 4
    print(f"带哨兵查找 99: {seq_search_sentry(a, 99)}")  # 0 (未找到)

    # 无哨兵版本
    b = [5, 12, 34, 8, 19, 27, 42]
    print(f"无哨兵查找 19: {seq_search(b, 19)}")  # 4
    print(f"无哨兵查找 99: {seq_search(b, 99)}")  # -1 (未找到)
```

### 9.2.2 折半查找（Binary Search）

#### 基本思想

折半查找要求查找表是**有序的**（按关键字递增或递减排列）。每次将查找区间从中间一分为二，通过与中间位置的关键字比较，确定下一次查找哪个子区间，从而将查找范围缩小一半。

**前提条件**：表必须**顺序存储**且**关键字有序**。

#### 查找公式

$$mid = \left\lfloor \frac{low + high}{2} \right\rfloor$$

#### 算法步骤

1. 设置初始查找区间：`low = 0`, `high = n - 1`
2. 当 `low <= high` 时：
   - 计算 `mid = (low + high) // 2`
   - 若 `a[mid] == key`，查找成功，返回 `mid`
   - 若 `key < a[mid]`，则 `high = mid - 1`（到前半区间找）
   - 若 `key > a[mid]`，则 `low = mid + 1`（到后半区间找）
3. 若 `low > high`，查找失败

#### 判定树（Decision Tree）

将折半查找过程用二叉树表示，即为**判定树**：
- 树中每个**圆形结点**表示表中一个记录，结点中的值为该记录在表中的位置
- 树中每个**方形结点**（叶子）表示查找不成功的位置
- 判定树中序遍历结果即为有序表的顺序排列

若有序表长度为 $n$，则折半查找的判定树是唯一的。其深度为 $\lfloor \log_2 n \rfloor + 1$，与同样结点数的完全二叉树深度相同。

#### 平均查找长度

在等概率假设下，折半查找的 ASL 为：

$$ASL = \frac{1}{n} \sum_{i=1}^{n} h_i = \log_2 (n+1) - 1 \approx O(\log n)$$

其中 $h_i$ 为第 $i$ 个结点在判定树中的层数（比较次数）。

查找成功最多比较 $\lfloor \log_2 n \rfloor + 1$ 次，查找不成功最多比较 $\lfloor \log_2 n \rfloor + 1$ 次。

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 折半查找（迭代版）
int BinarySearch(const vector<int>& a, int key) {
    int low = 0, high = a.size() - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2; // 避免溢出
        if (a[mid] == key)
            return mid;
        else if (key < a[mid])
            high = mid - 1;
        else
            low = mid + 1;
    }
    return -1; // 未找到
}

// 折半查找（递归版）
int BinarySearch_Recursive(const vector<int>& a, int key, int low, int high) {
    if (low > high) return -1;
    int mid = low + (high - low) / 2;
    if (a[mid] == key)
        return mid;
    else if (key < a[mid])
        return BinarySearch_Recursive(a, key, low, mid - 1);
    else
        return BinarySearch_Recursive(a, key, mid + 1, high);
}

int main() {
    vector<int> a = {3, 8, 15, 21, 34, 47, 59, 68, 72, 89}; // 有序表

    cout << "迭代查找 34: " << BinarySearch(a, 34) << endl;          // 4
    cout << "迭代查找 99: " << BinarySearch(a, 99) << endl;          // -1

    cout << "递归查找 68: " << BinarySearch_Recursive(a, 68, 0, 9) << endl; // 7
    cout << "递归查找 10: " << BinarySearch_Recursive(a, 10, 0, 9) << endl; // -1

    return 0;
}
```

#### Python 实现

```python
from typing import List

# 折半查找（迭代版）
def binary_search(a: List[int], key: int) -> int:
    low, high = 0, len(a) - 1
    while low <= high:
        mid = low + (high - low) // 2
        if a[mid] == key:
            return mid
        elif key < a[mid]:
            high = mid - 1
        else:
            low = mid + 1
    return -1

# 折半查找（递归版）
def binary_search_recursive(a: List[int], key: int, low: int, high: int) -> int:
    if low > high:
        return -1
    mid = low + (high - low) // 2
    if a[mid] == key:
        return mid
    elif key < a[mid]:
        return binary_search_recursive(a, key, low, mid - 1)
    else:
        return binary_search_recursive(a, key, mid + 1, high)


if __name__ == '__main__':
    a = [3, 8, 15, 21, 34, 47, 59, 68, 72, 89]  # 有序表
    print(f"迭代查找 34: {binary_search(a, 34)}")              # 4
    print(f"迭代查找 99: {binary_search(a, 99)}")              # -1
    print(f"递归查找 68: {binary_search_recursive(a, 68, 0, 9)}") # 7
    print(f"递归查找 10: {binary_search_recursive(a, 10, 0, 9)}") # -1
```

### 9.2.3 分块查找（Block Search / 索引顺序查找）

#### 基本思想

分块查找是顺序查找和折半查找的一种折中方案。基本思想是：

1. 将 $n$ 个元素的表分成 $b$ 个**块（Block）**，每个块包含 $s$ 个记录（$n = b \cdot s$）
2. 块与块之间按关键字**有序**（第 $i$ 块的最大关键字 < 第 $i+1$ 块的最小关键字）
3. 每个块内部的元素可以是**无序**的
4. 建立一个**索引表**，索引表中的每个项包含该块的最大关键字和该块的起始地址

**查找过程**：
1. 先在索引表中查找，确定待查关键字可能属于哪个块
2. 再在确定的块内进行顺序查找

#### 平均查找长度

若索引表用顺序查找：

$$ASL_{bs} = L_b + L_w = \frac{b+1}{2} + \frac{s+1}{2}$$

其中 $L_b$ 为查索引表的平均长度，$L_w$ 为块内查找的平均长度。

当 $s \approx \sqrt{n}$ 时，ASL 取得最小值 $\sqrt{n} + 1$。

若索引表用折半查找：

$$ASL_{bs} \approx \log_2 (b+1) + \frac{s+1}{2}$$

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 索引项：包含每个块的最大关键字和起始位置
struct IndexItem {
    int maxKey;  // 该块的最大关键字
    int start;   // 该块的起始下标
    int end;     // 该块的结束下标
};

// 分块查找：先在索引表中用顺序查找定位，再在块内顺序查找
int BlockSearch(const vector<int>& a, const vector<IndexItem>& index, int key) {
    int b = index.size();

    // 第一步：在索引表中查找所属块
    int block = -1;
    // 对于非递减有序的块间关系：key <= 某块最大值时，可能在该块
    for (int i = 0; i < b; ++i) {
        if (key <= index[i].maxKey) {
            block = i;
            break;
        }
    }
    if (block == -1) return -1; // 超出所有块的最大关键字

    // 第二步：在确定的块内顺序查找
    for (int i = index[block].start; i <= index[block].end; ++i) {
        if (a[i] == key) return i;
    }
    return -1;
}

int main() {
    // 示例数据：分块存储
    // 块1: 5, 8, 3 (max=8)    块2: 12, 18, 15 (max=18)   块3: 25, 21, 30 (max=30)
    vector<int> a = {5, 8, 3, 12, 18, 15, 25, 21, 30};

    vector<IndexItem> index = {
        {8,  0, 2},   // 第0块: maxKey=8,  下标0~2
        {18, 3, 5},   // 第1块: maxKey=18, 下标3~5
        {30, 6, 8}    // 第2块: maxKey=30, 下标6~8
    };

    cout << "查找 18: " << BlockSearch(a, index, 18) << endl;  // 4
    cout << "查找 99: " << BlockSearch(a, index, 99) << endl;  // -1

    return 0;
}
```

#### Python 实现

```python
from typing import List

class IndexItem:
    def __init__(self, max_key: int, start: int, end: int):
        self.max_key = max_key
        self.start = start
        self.end = end

# 分块查找
def block_search(a: List[int], index: List[IndexItem], key: int) -> int:
    # 第一步：在索引表中查找所属块
    block = -1
    for i, item in enumerate(index):
        if key <= item.max_key:
            block = i
            break
    if block == -1:
        return -1

    # 第二步：在确定的块内顺序查找
    for i in range(index[block].start, index[block].end + 1):
        if a[i] == key:
            return i
    return -1


if __name__ == '__main__':
    a = [5, 8, 3, 12, 18, 15, 25, 21, 30]
    index = [
        IndexItem(8,  0, 2),   # 第0块: maxKey=8,  下标0~2
        IndexItem(18, 3, 5),   # 第1块: maxKey=18, 下标3~5
        IndexItem(30, 6, 8)    # 第2块: maxKey=30, 下标6~8
    ]
    print(f"查找 18: {block_search(a, index, 18)}")  # 4
    print(f"查找 99: {block_search(a, index, 99)}")  # -1
```

## 9.3 动态查找表——二叉排序树（BST）

### 9.3.1 定义与性质

**二叉排序树**（Binary Search Tree, BST）或者是一棵空树，或者是具有如下性质的二叉树：

1. 若它的**左子树**不空，则左子树上**所有**结点的值均**小于**根结点的值
2. 若它的**右子树**不空，则右子树上**所有**结点的值均**大于**根结点的值
3. 它的**左、右子树**也都分别是二叉排序树

> **重要推论**：二叉排序树的**中序遍历**序列是一个递增有序序列。

### 9.3.2 查找

从根结点开始，若根结点为空，则查找失败；否则将查找关键字与根结点的关键字比较：
- 若相等，查找成功
- 若小于根结点关键字，进入左子树继续查找
- 若大于根结点关键字，进入右子树继续查找

查找路径上的最后一个结点即为查找失败时访问到的结点。

#### 递归查找

```cpp
BSTNode* BST_Search_Recursive(BSTNode* T, int key) {
    if (T == nullptr || T->data == key)
        return T;
    if (key < T->data)
        return BST_Search_Recursive(T->lchild, key);
    else
        return BST_Search_Recursive(T->rchild, key);
}
```

#### 迭代查找

```cpp
BSTNode* BST_Search(BSTNode* T, int key) {
    while (T != nullptr && key != T->data) {
        if (key < T->data)
            T = T->lchild;
        else
            T = T->rchild;
    }
    return T; // 未找到时返回 nullptr
}
```

### 9.3.3 插入

**插入规则**：新结点总是作为**叶子结点**插入到二叉排序树中。

1. 若二叉排序树为空，则新结点作为根结点
2. 若新结点的关键字小于根结点的关键字，则插入到左子树
3. 若新结点的关键字大于根结点的关键字，则插入到右子树
4. 若新结点的关键字等于已有结点的关键字，则**不插入**（或根据具体需求处理）

### 9.3.4 删除

删除一个结点后，必须保持二叉排序树的特性。设待删除结点为 `p`，分为三种情况：

| 情况 | 描述 | 处理方法 |
|------|------|----------|
| **情况 1** | `p` 是叶子结点（无孩子） | 直接删除 `p`，将其父结点指向 `nullptr` |
| **情况 2** | `p` 只有一个孩子（左或右） | 用孩子结点替换 `p` 的位置 |
| **情况 3** | `p` 有两个孩子 | 找到 `p` 的**直接后继**（右子树中最左结点）或**直接前驱**（左子树中最右结点），将其值复制到 `p`，然后删除那个后继（前驱）结点 |

> 对于情况3：由于后继（前驱）结点最多只有一个孩子，因此问题退化为情况1或情况2。

### 9.3.5 平均查找长度

二叉排序树的查找 ASL 与树的**形态**密切相关：

- **最好情况**：二叉排序树左右子树均匀分布（平衡），与折半查找相当，$ASL = O(\log n)$
- **最坏情况**：插入序列有序，树退化为单链，$ASL = \frac{n+1}{2} = O(n)$

### 9.3.6 C++ 完整实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

// 二叉排序树结点
struct BSTNode {
    int data;
    BSTNode* lchild;
    BSTNode* rchild;
    BSTNode(int val) : data(val), lchild(nullptr), rchild(nullptr) {}
};

// ---------- 查找（迭代） ----------
BSTNode* BST_Search(BSTNode* T, int key) {
    while (T != nullptr && T->data != key) {
        if (key < T->data)
            T = T->lchild;
        else
            T = T->rchild;
    }
    return T;
}

// ---------- 查找（递归） ----------
BSTNode* BST_Search_Recursive(BSTNode* T, int key) {
    if (T == nullptr || T->data == key) return T;
    if (key < T->data) return BST_Search_Recursive(T->lchild, key);
    else               return BST_Search_Recursive(T->rchild, key);
}

// ---------- 插入 ----------
void BST_Insert(BSTNode*& T, int key) {
    if (T == nullptr) {
        T = new BSTNode(key);
    } else if (key < T->data) {
        BST_Insert(T->lchild, key);
    } else if (key > T->data) {
        BST_Insert(T->rchild, key);
    }
    // 若 key == T->data，不插入（避免重复）
}

// 从数组创建二叉排序树
BSTNode* BST_Create(const vector<int>& nums) {
    BSTNode* root = nullptr;
    for (int x : nums) {
        BST_Insert(root, x);
    }
    return root;
}

// ---------- 辅助：找最小值 ----------
BSTNode* BST_FindMin(BSTNode* T) {
    if (T == nullptr) return nullptr;
    while (T->lchild != nullptr) T = T->lchild;
    return T;
}

    if (T == nullptr) return;

    if (key < T->data) {
        BST_Delete(T->lchild, key);
    } else if (key > T->data) {
        BST_Delete(T->rchild, key);
    } else {
        // 找到目标结点 T
        // 情况1 & 2：无左孩子 或 无右孩子
        if (T->lchild == nullptr) {
            BSTNode* temp = T;
            T = T->rchild;
            delete temp;
        } else if (T->rchild == nullptr) {
            BSTNode* temp = T;
            T = T->lchild;
            delete temp;
        }
        // 情况3：有两个孩子
        else {
            BSTNode* successor = BST_FindMin(T->rchild); // 找直接后继
            T->data = successor->data;                   // 值替换
            BST_Delete(T->rchild, successor->data);      // 删除后继
        }
    }
}

    if (T == nullptr) return;
    BST_InOrder(T->lchild);
    cout << T->data << " ";
    BST_InOrder(T->rchild);
```

## 9.4 平衡二叉树（AVL Tree）

### 9.4.1 定义

**平衡二叉树（Balanced Binary Tree）**，又称 **AVL 树**（由 Adelson-Velsky 和 Landis 提出），是指树中每个结点的左、右子树高度之差的绝对值不超过 1 的**二叉排序树**。

**平衡因子（Balance Factor, BF）**：

$$BF = h_L - h_R$$

其中 $h_L$ 和 $h_R$ 分别为结点左、右子树的高度。AVL 树要求 $|BF| \le 1$。

### 9.4.2 平衡旋转

当在 AVL 树中插入或删除结点导致某个结点的 $|BF| > 1$ 时，需要通过**旋转**来恢复平衡。旋转分四种基本类型：

#### LL 型（右单旋转）

**情景**：在结点 `A` 的**左**孩子的**左**子树中插入导致 `A` 不平衡。

**处理**：对 `A` 进行一次**右单旋转（Right Rotation）**——让 `B` 成为新的根，`A` 成为 `B` 的右孩子，`B` 的原右子树成为 `A` 的左子树。

```
      A                  B
     / \                / \
    B   C     →        D   A
   / \                    / \
  D   E                  E   C
```

#### RR 型（左单旋转）

**情景**：在结点 `A` 的**右**孩子的**右**子树中插入导致 `A` 不平衡。

**处理**：对 `A` 进行一次**左单旋转（Left Rotation）**。

```
    A                      B
   / \                    / \
  C   B        →         A   E
     / \                / \
    D   E              C   D
```

#### LR 型（先左旋后右旋）

**情景**：在结点 `A` 的**左**孩子的**右**子树中插入导致 `A` 不平衡。

**处理**：先对 `B` 进行**左单旋转**，再对 `A` 进行**右单旋转**。

```
      A                  A                  C
     / \                / \                / \
    B   D     →        C   D     →        B   A
   / \                / \                /   / \
  E   C              B   G              E   F   D
     / \            / \
    F   G          E   F
```

#### RL 型（先右旋后左旋）

**情景**：在结点 `A` 的**右**孩子的**左**子树中插入导致 `A` 不平衡。

**处理**：先对 `B` 进行**右单旋转**，再对 `A` 进行**左单旋转**。与 LR 型对称。

### 9.4.3 插入后的重平衡

AVL 树的插入操作是**递归**实现的。每次插入后，从插入点向根方向回溯，检查每个结点是否平衡，若不平衡则进行相应的旋转操作。

### 9.4.4 AVL 树的最少结点数

设高度为 $h$ 的 AVL 树的最少结点数为 $N_h$，则有递推关系：

$$N_0 = 0,\quad N_1 = 1,\quad N_2 = 2$$

$$N_h = N_{h-1} + N_{h-2} + 1 \quad (h \ge 3)$$

这说明 $N_h$ 与斐波那契数列有关：$N_h = F_{h+2} - 1$（其中 $F_0 = 0, F_1 = 1$）。

最大深度（含 $n$ 个结点的 AVL 树）约为：

$$h \approx \log_{\phi} (\sqrt{5}(n+1)) - 2 \approx 1.44 \log_2 n$$

其中 $\phi = \frac{1+\sqrt{5}}{2}$（黄金比例）。

### 9.4.5 时间复杂度

AVL 树的查找、插入、删除时间复杂度均为 $O(\log n)$，其中 $n$ 为树中结点数。相比普通 BST，AVL 树保证了最坏情况下的性能。

```cpp
    AVLNode* B_left = B->lchild;

    A->rchild = B_left;

    updateHeight(A);
    updateHeight(B);
    return B;
}

    if (T == nullptr)
        return new AVLNode(key);

    if (key < T->data)
        T->lchild = AVL_Insert(T->lchild, key);
    else if (key > T->data)
        T->rchild = AVL_Insert(T->rchild, key);
    else
        return T; // 不插入重复值

    updateHeight(T);
    int bf = getBalanceFactor(T);

    // LL型：左子树高，且插入在左子树的左边
    if (bf > 1 && key < T->lchild->data)
        return rotateRight(T);

    // RR型：右子树高，且插入在右子树的右边
    if (bf < -1 && key > T->rchild->data)
        return rotateLeft(T);

    // LR型：左子树高，且插入在左子树的右边
    if (bf > 1 && key > T->lchild->data) {
        T->lchild = rotateLeft(T->lchild);
        return rotateRight(T);
    }

    // RL型：右子树高，且插入在右子树的左边
    if (bf < -1 && key < T->rchild->data) {
        T->rchild = rotateRight(T->rchild);
        return rotateLeft(T);
    }

    return T;
}

    while (T != nullptr && T->lchild != nullptr)
        T = T->lchild;
    return T;
}

// 删除结点

    if (T == nullptr) return nullptr;

    if (key < T->data)
        T->lchild = AVL_Delete(T->lchild, key);
    else if (key > T->data)
        T->rchild = AVL_Delete(T->rchild, key);
    else {
        // 找到目标结点
        if (T->lchild == nullptr || T->rchild == nullptr) {
            AVLNode* temp = (T->lchild != nullptr) ? T->lchild : T->rchild;
            if (temp == nullptr) {  // 无孩子
                temp = T;
                T = nullptr;
            } else {                // 一个孩子
                *T = *temp;         // 复制孩子的内容
            }
            delete temp;
        } else {
            // 两个孩子：找后继替换
            AVLNode* successor = AVL_FindMin(T->rchild);
            T->data = successor->data;
            T->rchild = AVL_Delete(T->rchild, successor->data);
        }
    }

    if (T == nullptr) return nullptr;

    updateHeight(T);
    int bf = getBalanceFactor(T);

    // LL型
    if (bf > 1 && getBalanceFactor(T->lchild) >= 0)

    // LR型
    if (bf > 1 && getBalanceFactor(T->lchild) < 0) {
        T->lchild = rotateLeft(T->lchild);
        return rotateRight(T);

    // RR型
    if (bf < -1 && getBalanceFactor(T->rchild) <= 0)
        return rotateLeft(T);

    // RL型
    if (bf < -1 && getBalanceFactor(T->rchild) > 0) {
        T->rchild = rotateRight(T->rchild);
        return rotateLeft(T);
    }

    return T;
}
```

## 9.5 B-树和 B+树

### 9.5.1 B-树（B-Tree）

#### 定义

B-树是一种**平衡的多路查找树**。它通过在每个结点中存储多个关键字和多个子树指针，将树的**高度降低**，从而减少查找过程中的磁盘 I/O 次数。B-树特别适合用于**文件系统**和**数据库索引**等需要与外部存储设备交互的场景。

#### m 阶 B-树的性质

一棵 $m$ 阶 B-树（$m \ge 3$），或者为空树，或者为满足下列特性的 $m$ 叉树：

1. 树中每个结点至多有 $m$ 棵子树，即至多含有 $m-1$ 个关键字
2. 若根结点不是叶子结点，则至少有两棵子树
3. 除根之外的所有**非叶结点**至少有 $\lceil m/2 \rceil$ 棵子树，即至少含有 $\lceil m/2 \rceil - 1$ 个关键字
4. 所有**叶子结点**都在同一层，且不带任何信息（可视为外部结点或失败结点）
5. 所有**非叶结点**的结构如下：

```
(n, A₀, K₁, A₁, K₂, A₂, ..., Kₙ, Aₙ)
```

其中：
- $n$ 为该结点中的关键字个数（$\lceil m/2 \rceil - 1 \le n \le m-1$，根结点 $1 \le n \le m-1$）
- $K_i$（$1 \le i \le n$）为关键字，且 $K_1 < K_2 < \dots < K_n$
- $A_i$（$0 \le i \le n$）为指向子树根结点的指针，且 $A_{i-1}$ 所指子树中所有结点的关键字均小于 $K_i$，$A_i$ 所指子树中所有结点的关键字均大于 $K_i$

#### B-树结点的 C 语言结构描述

```cpp

    int keynum;                  // 结点中关键字个数
    struct BTNode *parent;       // 指向双亲结点的指针

    Record *recptr[m+1];         // 记录指针向量
```

#### B-树查找

B-树的查找类似于二叉排序树的查找，但每个结点内需要执行**顺序查找**（或折半查找）来确定进入哪个子树。

**查找访问的结点数**（含 $N$ 个关键字的 $m$ 阶 B-树）：

$$\text{最大访问结点数} \le \log_{\lceil m/2 \rceil} \left( \frac{N+1}{2} \right) + 1$$

#### B-树插入（分裂）

1. 先用查找过程定位应该插入的叶子结点位置（实际插入到含有关键字的最底层非叶结点）
2. 若该结点中关键字数 $< m-1$，直接将新关键字插入合适位置
3. 若该结点中关键字数 $= m-1$（即插入后变为 $m$ 个关键字，**溢出**），则需要**分裂**：
   - 将溢出结点分为三个部分：中间关键字 $K_{\lceil m/2 \rceil}$、前半部分、后半部分
   - 中间关键字**上提**到父结点，前半部分和后半部分各成为独立的结点
   - 若上提导致父结点溢出，则继续向上分裂，直到根结点
   - 若根结点溢出，则新建一个根结点（树高 $+1$）

#### B-树删除（借位与合并）

删除比插入更复杂，主要分几种情况：

1. **删除的关键字在叶子结点（最底层非叶结点）**：
   - 删除后关键字数仍 $\ge \lceil m/2 \rceil - 1$：直接删除
   - 删除后关键字数不足：
     - 若**左兄弟**（或右兄弟）的关键字数 $\ge \lceil m/2 \rceil$：从兄弟**借**一个关键字（通过父结点转发）
     - 若左、右兄弟关键字数都不足 $\lceil m/2 \rceil$：与兄弟**合并**，并将父结点中对应的关键字一起拉下（可能导致父结点向上递归处理）

2. **删除的关键字在内部结点**：
   - 用该关键字的**直接前驱**（左子树中最大关键字）或**直接后继**（右子树中最小关键字）替换，然后问题转化为在子树中删除那个前驱/后继

### 9.5.2 B+树（B+ Tree）

B+树是 B-树的一种变体，广泛应用于数据库索引（如 MySQL 的 InnoDB 引擎）。

#### B+树与 B-树的主要区别

| 特性 | B-树 | B+树 |
|------|------|------|
| **关键字存放** | 所有结点都存放关键字和记录指针 | 只有**叶子结点**存放完整记录，内部结点仅作索引 |
| **叶子结点结构** | 叶子结点之间不链接 | 叶子结点按关键字顺序用**链表**链接，便于范围查询 |
| **内部结点中的关键字** | 对应本结点的记录 | 是其对应子树中关键字的**最大值**（或最小值），可能不与叶子一一对应 |
| **查找路径** | 可能在非叶结点就找到 | 无论成功与否，都必须走到**叶子结点** |
| **插入/删除** | 相对简单 | 只在叶子结点插入/删除，但索引需同步更新 |

#### B+树的特点

- 所有叶子结点包含全部关键字及指向相应记录的指针，叶子结点之间按关键字大小顺序链接
- 每个非叶结点中的关键字 $K_i$ 是其相应指针 $A_i$ 所指子树中关键字的**最大值**（或最小值）
- 查找必须从根走到叶子结点，即使内部结点中有对应的关键字（仅作为路标）

### 9.5.3 C++ 实现（3阶B-树的查找与插入）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

const int M = 3;               // B-树的阶（M=3，关键字最多2个，最少1个）
const int MAX_KEY = M - 1;     // 结点最大关键字数 = 2
const int MIN_KEY = M / 2;     // 结点最小关键字数 = 1（根除外）

// B-树结点
struct BTreeNode {
    int keys[MAX_KEY + 1];      // 关键字数组，多一个位置用于分裂时的暂存
    BTreeNode* children[M + 1]; // 子树指针数组
    int num;                    // 当前关键字个数
    bool isLeaf;                // 是否为叶子结点

    BTreeNode(bool leaf) : num(0), isLeaf(leaf) {
        for (int i = 0; i <= M; i++) children[i] = nullptr;
    }
};

// B-树查找
// 返回目标结点及关键字下标；若未找到，node=nullptr
bool BTree_Search(BTreeNode* node, int key,
                  BTreeNode*& resultNode, int& pos) {
    if (node == nullptr) return false;

    int i = 0;
    while (i < node->num && key > node->keys[i]) i++;

    if (i < node->num && key == node->keys[i]) {
        resultNode = node;
        pos = i;
        return true;
    }

    if (node->isLeaf) return false;

    return BTree_Search(node->children[i], key, resultNode, pos);
}

// 将关键字 key 插入非满结点（分裂前的插入）
void BTree_InsertNonFull(BTreeNode* node, int key) {
    int i = node->num - 1;

    if (node->isLeaf) {
        // 叶子结点：找到插入位置，后移元素
        while (i >= 0 && key < node->keys[i]) {
            node->keys[i + 1] = node->keys[i];
            i--;
        }
        node->keys[i + 1] = key;
        node->num++;
    } else {
        // 内部结点：找到应插入的子树
        while (i >= 0 && key < node->keys[i]) i--;
        i++;

        // 如果子树已满，先分裂
        if (node->children[i]->num == MAX_KEY) {
            BTree_SplitChild(node, i);
            if (key > node->keys[i]) i++;
        }
        BTree_InsertNonFull(node->children[i], key);
    }
}

// 分裂满的孩子结点
// node: 父结点（非满）, childIndex: 待分裂的孩子下标
void BTree_SplitChild(BTreeNode* parent, int childIndex) {
    BTreeNode* child = parent->children[childIndex];
    BTreeNode* newSibling = new BTreeNode(child->isLeaf);
    newSibling->num = MIN_KEY - 1; // ┌M/2┐-1

    // 将 child 的后半部分关键字复制到新结点
    for (int j = 0; j < MIN_KEY - 1; j++)
        newSibling->keys[j] = child->keys[j + MIN_KEY];

    // 如果不是叶子，复制子树指针
    if (!child->isLeaf) {
        for (int j = 0; j < MIN_KEY; j++)
            newSibling->children[j] = child->children[j + MIN_KEY];
    }

    child->num = MIN_KEY - 1; // child 保留前半部分

    // 在父结点中为新结点腾出位置
    for (int j = parent->num; j > childIndex; j--)
        parent->children[j + 1] = parent->children[j];
    parent->children[childIndex + 1] = newSibling;

    // 在父结点中为提升上来的关键字腾位置
    for (int j = parent->num - 1; j >= childIndex; j--)
        parent->keys[j + 1] = parent->keys[j];
    parent->keys[childIndex] = child->keys[MIN_KEY - 1]; // 中间关键字上提
    parent->num++;
}

// B-树插入主函数
BTreeNode* BTree_Insert(BTreeNode* root, int key) {
    // 查找是否已存在
    BTreeNode* found = nullptr;
    int pos;
    if (BTree_Search(root, key, found, pos))
        return root; // 不插入重复值

    if (root->num == MAX_KEY) {
        // 根已满，需要新建根结点
        BTreeNode* newRoot = new BTreeNode(false);
        newRoot->children[0] = root;
        BTree_SplitChild(newRoot, 0);
        BTree_InsertNonFull(newRoot, key);
        return newRoot;
    } else {
        BTree_InsertNonFull(root, key);
        return root;
    }
}

// 中序遍历（用于验证）
void BTree_InOrder(BTreeNode* node) {
    if (node == nullptr) return;
    for (int i = 0; i < node->num; i++) {
        if (!node->isLeaf) BTree_InOrder(node->children[i]);
        cout << node->keys[i] << " ";
    }
    if (!node->isLeaf) BTree_InOrder(node->children[node->num]);
}

// 层序遍历（便于观察树结构）
void BTree_LevelOrder(BTreeNode* root) {
    if (root == nullptr) return;
    vector<BTreeNode*> q = {root};
    while (!q.empty()) {
        vector<BTreeNode*> next;
        for (auto node : q) {
            cout << "[";
            for (int i = 0; i < node->num; i++) {
                if (i > 0) cout << ",";
                cout << node->keys[i];
            }
            cout << "] ";
            if (!node->isLeaf) {
                for (int i = 0; i <= node->num; i++)
                    next.push_back(node->children[i]);
            }
        }
        cout << endl;
        q = next;
    }
}

// 测试
int main() {
    BTreeNode* root = new BTreeNode(true); // 初始为空叶子

    int nums[] = {10, 20, 5, 6, 12, 30, 7, 17};
    int n = sizeof(nums) / sizeof(nums[0]);

    cout << "依次插入: ";
    for (int i = 0; i < n; i++) {
        cout << nums[i] << " ";
        root = BTree_Insert(root, nums[i]);
    }
    cout << "\n\n";

    cout << "中序遍历: ";
    BTree_InOrder(root);
    cout << "\n\n";

    cout << "层序遍历（观察B-树结构）:\n";
    BTree_LevelOrder(root);

    // 查找测试
    BTreeNode* found = nullptr;
    int pos;

}
```

```python
from typing import Optional, Tuple, List

M = 3
MAX_KEY = M - 1   # = 2
MIN_KEY = M // 2   # = 1

class BTreeNode:
    def __init__(self, leaf: bool):
        self.keys: List[int] = []
        self.children: List['BTreeNode'] = []
        self.is_leaf = leaf

    def __repr__(self):
        return f"[{','.join(map(str, self.keys))}]"

# B-树查找
def btree_search(node: Optional[BTreeNode], key: int) -> Tuple[Optional[BTreeNode], int]:
    if node is None:
        return None, -1

    i = 0
    while i < len(node.keys) and key > node.keys[i]:
        i += 1

    if i < len(node.keys) and key == node.keys[i]:
        return node, i

    if node.is_leaf:
        return None, -1

    return btree_search(node.children[i], key)

# 分裂满的孩子结点
def btree_split_child(parent: BTreeNode, child_idx: int) -> None:
    child = parent.children[child_idx]
    new_sibling = BTreeNode(child.is_leaf)

    # 后一半关键字移到新结点
    mid_idx = MIN_KEY - 1  # 中间关键字的索引
    new_sibling.keys = child.keys[mid_idx + 1:]
    child.keys = child.keys[:mid_idx]

    # 如果不为叶子，后一半子树指针也移动到新结点
    if not child.is_leaf:
        new_sibling.children = child.children[mid_idx + 1:]
        child.children = child.children[:mid_idx + 1]

    # 关键字上提到父结点
    mid_key = child.keys[mid_idx] if mid_idx < len(child.keys) else \
              parent.keys[child_idx]  # 实际上需要的是 child 中原来的中间值

    # 插入到父结点
    parent.keys.insert(child_idx, mid_key)
    parent.children.insert(child_idx + 1, new_sibling)

# 插入到非满结点
def btree_insert_nonfull(node: BTreeNode, key: int) -> None:
    i = len(node.keys) - 1

    if node.is_leaf:
        # 找到插入位置
        while i >= 0 and key < node.keys[i]:
            i -= 1
        node.keys.insert(i + 1, key)
    else:
        # 找到应插入的子树
        while i >= 0 and key < node.keys[i]:
            i -= 1
        i += 1

        # 如果子树已满，先分裂
        if len(node.children[i].keys) == MAX_KEY:
            btree_split_child(node, i)
            if key > node.keys[i]:
                i += 1
        btree_insert_nonfull(node.children[i], key)

# B-树插入主函数
def btree_insert(root: BTreeNode, key: int) -> BTreeNode:
    # 检查是否已存在
    found, _ = btree_search(root, key)
    if found is not None:
        return root  # 不插入重复值

    if len(root.keys) == MAX_KEY:
        # 根已满，需要新建根
        new_root = BTreeNode(False)
        new_root.children.append(root)
        btree_split_child(new_root, 0)
        btree_insert_nonfull(new_root, key)
        return new_root
    else:
        btree_insert_nonfull(root, key)
        return root

# 中序遍历
def btree_in_order(node: Optional[BTreeNode]) -> None:
    if node is None:
        return
    for i, key in enumerate(node.keys):
        if not node.is_leaf:
            btree_in_order(node.children[i])
        print(key, end=" ")
    if not node.is_leaf:
        btree_in_order(node.children[len(node.keys)])

# 层序遍历
def btree_level_order(root: Optional[BTreeNode]) -> None:
    if root is None:
        return
    q = [root]
    while q:
        next_q = []
        for node in q:
            print(node, end=" ")
            if not node.is_leaf:
                next_q.extend(node.children)
        print()
        q = next_q


if __name__ == '__main__':
    root = BTreeNode(True)  # 初始为空叶子

    nums = [10, 20, 5, 6, 12, 30, 7, 17]
    print("依次插入: ", end="")
    for x in nums:
        print(x, end=" ")
        root = btree_insert(root, x)
    print("\n")

    print("中序遍历: ", end="")
    btree_in_order(root)
    print("\n")

    print("层序遍历（观察B-树结构）:")
    btree_level_order(root)

    # 查找测试
    found, pos = btree_search(root, 12)
    print(f"\n查找 12: {'找到' if found else '未找到'}")
    found, pos = btree_search(root, 99)
    print(f"查找 99: {'找到' if found else '未找到'}")
```

## 9.6 哈希表（Hash Table）

### 9.6.1 基本概念

**哈希表（Hash Table）**，又称**散列表**，是一种根据关键字直接访问数据存储位置的数据结构。通过**哈希函数（Hash Function）**将关键字映射到表中的一个位置，从而加快查找速度。

| 概念 | 定义 |
|------|------|
| **哈希函数 $H(key)$** | 把关键字映射到哈希地址的函数 |
| **冲突（Collision）** | 不同的关键字通过哈希函数计算出相同的地址 |
| **同义词（Synonym）** | 产生冲突的多个关键字互称为同义词 |
| **装载因子 $\alpha$** | $\alpha = n / m$，其中 $n$ 为记录数，$m$ 为表长 |
| **哈希表** | 根据哈希函数和冲突处理方法构造的查找表 |

### 9.6.2 哈希函数的构造方法

#### 1. 直接定址法

取关键字或关键字的某个线性函数值为哈希地址：

$$H(key) = key \quad \text{或} \quad H(key) = a \cdot key + b$$

**优点**：计算简单，不存在冲突（当关键字不同时）
**缺点**：仅适合于**地址集合大小 = 关键字集合大小**的情况，空间浪费严重

#### 2. 数字分析法

假设关键字集合中的每个关键字都由 $s$ 位数字组成 $(u_1, u_2, \dots, u_s)$，分析所有关键字，提取**分布均匀**的若干位或它们的组合作为地址。

**适用**：能预先估计出全体关键字每位上各种数字出现的频度，且关键字位数较多。

#### 3. 平方取中法

取关键字**平方值的中间几位**作为哈希地址。平方的目的是"扩大差别"，而中间各位能受到整个关键字中各位的影响。

**适用**：关键字中的每一位都有某些数字重复出现频度很高的现象。

#### 4. 折叠法

将关键字分割成若干部分（每部分长度与哈希地址位数相同），然后取它们的**叠加和**为哈希地址。有两种叠加方法：

- **移位叠加**：将各部分的最低位对齐相加
- **间界叠加**：从一端向另一端沿分割界来回折叠后对齐相加

**适用**：关键字的数字位数特别多。

#### 5. 除留余数法（最常用）

$$H(key) = key \bmod p$$

其中 $p \le m$（$m$ 为表长），通常 $p$ 选为不大于 $m$ 的**素数**或不含 20 以下的质因子。

**Why 选素数？**：素数的因数少，可减少因除数的周期性导致的冲突。

#### 6. 随机数法

取关键字的随机函数值为它的哈希地址：

$$H(key) = random(key)$$

**适用**：关键字长度不等的情况。

### 9.6.3 冲突处理方法

#### 一、开放定址法（Open Addressing）

当发生冲突时，为冲突的地址 $H(key)$ 按某种探查序列求得下一个空地址：

$$H_i = (H(key) + d_i) \bmod m, \quad i = 1, 2, \dots, s$$

其中 $d_i$ 为增量序列，有三种常用取法：

**1. 线性探测再散列**

$$d_i = c \cdot i \quad (\text{最简单：} c = 1)$$

即 $H_i = (H(key) + i) \bmod m$。冲突发生时，依次探测下一个位置。

**问题**：容易产生**聚集（Clustering）**——同义词和非同义词在解决冲突时都可能占用同一探查序列中的位置。

**2. 平方探测再散列（二次探测）**

$$d_i = 1^2, -1^2, 2^2, -2^2, \dots$$

**优点**：可避免基本聚集
**条件**：要求表长 $m$ 是形如 $4k+3$ 的素数，才能保证探查到整个表

**3. 随机探测再散列**

$d_i$ 是一组**伪随机数列**。

#### 二、链地址法（拉链法/Chaining）

将所有哈希地址相同的记录（同义词）链接在同一个**链表**中。

- 哈希表的每个位置（桶 Bucket）是一个链表的头指针
- 查找时，先由哈希函数计算地址，再在对应链表中顺序查找
- 插入时，若发生冲突，直接插入对应链表中即可

**优点**：
- 不会出现"表满"的情况
- 删除操作简单
- 负载因子 $\alpha$ 可以大于 1
- 适合记录数不确定的情况

#### 三、建立公共溢出区

将哈希表分为**基本表**和**溢出表**两部分。发生冲突的记录统一存入溢出表。

### 9.6.4 哈希表的查找性能分析

**影响哈希表 ASL 的因素**：

1. **哈希函数**的选择——哈希函数越均匀，查找效率越高
2. **冲突处理方法**——不同方法对聚集的抑制效果不同
3. **装载因子 $\alpha$**——$\alpha$ 越小，发生冲突的概率越低，但空间利用率越低

#### 各种冲突处理方法的平均查找长度

| 处理方法 | 查找成功的 ASL | 查找不成功的 ASL |
|----------|---------------|------------------|
| 线性探测 | $\frac{1}{2} \left( 1 + \frac{1}{1-\alpha} \right)$ | $\frac{1}{2} \left( 1 + \frac{1}{(1-\alpha)^2} \right)$ |
| 平方探测 | $-\frac{1}{\alpha} \ln(1-\alpha)$ | $\frac{1}{1-\alpha}$ |
| 链地址法 | $1 + \frac{\alpha}{2}$ | $\alpha + e^{-\alpha}$ |

### 9.6.5 哈希表的扩容（Rehash）

当装载因子 $\alpha$ 超过一定阈值（通常取 0.7~0.8）时，冲突概率急剧增大，此时需要**扩容**：

1. 创建一个新的、更大的哈希表（通常大小扩为原来的两倍）
2. 将原表中的所有记录重新计算哈希地址并插入新表
3. 释放旧表

> 注意：扩容时所有元素都需要**重新哈希**，因为哈希函数依赖表长 $m$。

### 9.6.6 C++ 完整实现

```cpp

    OpenAddressingHash(int size = 11) : m(size), n(0) {
        table.resize(m);
        occupied.resize(m, false);
        deleted.resize(m, false);
    }

    // 查找：返回下标，-1表示未找到
    int search(int key) {
        int h0 = hashFunc(key);
        for (int i = 0; i < m; i++) {
            int idx = (h0 + i) % m;
            if (!occupied[idx] && !deleted[idx])
                return -1; // 遇到从未使用过的位置，必然不存在
            if (occupied[idx] && table[idx] == key)
                return idx;
        }
        return -1;
    }

    // 插入：成功返回 true，表满返回 false
    bool insert(int key) {
        if (n >= m) return false; // 表满

        // 检查是否已存在
        if (search(key) != -1) return true;

        int h0 = hashFunc(key);
        for (int i = 0; i < m; i++) {
            int idx = (h0 + i) % m;
            if (!occupied[idx] || deleted[idx]) {
                table[idx] = key;
                occupied[idx] = true;
                deleted[idx] = false;
                n++;
                return true;
            }
        }
        return false; // 未找到空位
    }

    // 删除（惰性删除）
    bool remove(int key) {
        int pos = search(key);
        if (pos == -1) return false;
        deleted[pos] = true;   // 标记为删除状态
        occupied[pos] = false;
        n--;
        return true;
    }

    void display() {
        cout << "哈希表内容：\n";
        for (int i = 0; i < m; i++) {
            cout << "[" << i << "] ";
            if (deleted[i])
                cout << "已删除";
            else if (occupied[i])
                cout << table[i];
            else
                cout << "空";
            cout << endl;
        }
    }
};

class ChainHash {
private:
    vector<list<int>> buckets;
    int m;

    int hashFunc(int key) { return key % m; }

public:
    ChainHash(int size = 11) : m(size) {
        buckets.resize(m);
    }

    void insert(int key) {
        int idx = hashFunc(key);
        // 避免重复插入
        for (int v : buckets[idx]) {
            if (v == key) return;
        }
        buckets[idx].push_back(key);
    }

    bool search(int key) {
        int idx = hashFunc(key);
        for (int v : buckets[idx]) {
            if (v == key) return true;
        }
        return false;
    }

    bool remove(int key) {
        int idx = hashFunc(key);
        auto& lst = buckets[idx];
        for (auto it = lst.begin(); it != lst.end(); ++it) {
            if (*it == key) {
                lst.erase(it);
                return true;
            }
        }
        return false;
    }

    void display() {
        cout << "拉链法哈希表内容：\n";
        for (int i = 0; i < m; i++) {
            cout << "[" << i << "] -> ";
            for (int v : buckets[i])
                cout << v << " -> ";
            cout << "nullptr" << endl;
        }
    }

    // 装载因子
    double loadFactor() {
        int total = 0;
        for (auto& lst : buckets) total += lst.size();
        return (double)total / m;
    }
};

class ReHashTable {
private:
    vector<int> table;
    vector<bool> occupied;
    int m, n;
    const double LOAD_FACTOR = 0.75;

    int hashFunc(int key) { return key % m; }

    void resize() {
        vector<int> oldTable = table;
        vector<bool> oldOcc = occupied;
        int oldM = m;

        // 扩容：新表长为旧表的两倍并取最近的素数
        m = nextPrime(2 * oldM);
        table.assign(m, 0);
        occupied.assign(m, false);
        n = 0;

        // 重新插入所有元素
        for (int i = 0; i < oldM; i++) {
            if (oldOcc[i]) {
                insert(oldTable[i]);
            }
        }
        cout << "   [扩容] 表长 " << oldM << " -> " << m << endl;
    }

    bool isPrime(int num) {
        if (num < 2) return false;
        int limit = sqrt(num);
        for (int i = 2; i <= limit; i++)
            if (num % i == 0) return false;
        return true;
    }

    int nextPrime(int num) {
        while (!isPrime(num)) num++;
        return num;
    }

public:
    ReHashTable(int size = 7) : m(nextPrime(size)), n(0) {
        table.resize(m);
        occupied.resize(m, false);
    }

    bool insert(int key) {
        if ((double)n / m >= LOAD_FACTOR)
            resize();

        int h0 = hashFunc(key);
        for (int i = 0; i < m; i++) {
            int idx = (h0 + i) % m;
            if (!occupied[idx]) {
                table[idx] = key;
                occupied[idx] = true;
                n++;
                return true;
            }
            if (table[idx] == key) return true; // 已存在
        }
        return false;
    }

    bool search(int key) {
        int h0 = hashFunc(key);
        for (int i = 0; i < m; i++) {
            int idx = (h0 + i) % m;
            if (!occupied[idx]) return false;
            if (table[idx] == key) return true;
        }
        return false;
    }

    void display() {
        cout << "表长 m=" << m << ", 记录数 n=" << n
             << ", 装载因子 α=" << (double)n / m << endl;
    }
};
```

```python
            print(f"  [{i}] -> {chain}")

class RehashTable:
    LOAD_FACTOR = 0.75

    def __init__(self, size: int = 7):
        self.m = self._next_prime(size)
        self.n = 0
        self.table = [None] * self.m
        self.occupied = [False] * self.m

    def _hash(self, key: int) -> int:
        return key % self.m

    @staticmethod
    def _is_prime(num: int) -> bool:
        if num < 2:
            return False
        for i in range(2, int(sqrt(num)) + 1):
            if num % i == 0:
                return False
        return True

    def _next_prime(self, num: int) -> int:
        while not self._is_prime(num):
            num += 1
        return num

    def _resize(self):
        old_table = self.table
        old_occ = self.occupied
        old_m = self.m

        self.m = self._next_prime(2 * old_m)
        self.table = [None] * self.m
        self.occupied = [False] * self.m
        self.n = 0

        for i in range(old_m):
            if old_occ[i]:
                self.insert(old_table[i])
        print(f"   [扩容] 表长 {old_m} -> {self.m}")

    def insert(self, key: int) -> bool:
        if self.n / self.m >= self.LOAD_FACTOR:
            self._resize()

        h0 = self._hash(key)
        for i in range(self.m):
            idx = (h0 + i) % self.m
            if not self.occupied[idx]:
                self.table[idx] = key
                self.occupied[idx] = True
                self.n += 1
                return True
            if self.table[idx] == key:
                return True
        return False
```

## 总结

1. **查找**是数据处理中的基础操作，衡量查找算法效率的核心指标是**平均查找长度（ASL）**
2. **静态查找**（不涉及插入/删除）：
   - **顺序查找**：$O(n)$，无需有序，适用于任何表
   - **折半查找**：$O(\log n)$，要求表有序且顺序存储
   - **分块查找**：折中方案，最佳分块大小 $s \approx \sqrt{n}$
3. **动态查找**：
   - **二叉排序树（BST）**：$O(\log n)$ 平均，$O(n)$ 最坏（退化为链）。主要操作：查找、插入（新结点必为叶子）、删除（三种情况）
   - **AVL 树**：通过四种旋转（LL/RR/LR/RL）维持平衡，保证 $O(\log n)$ 的最坏性能。最少结点数 $N_h = F_{h+2} - 1$
   - **B-树**：$m$ 阶平衡多路查找树，树高度低，适合外存查找。通过**分裂**和**合并/借位**维持结构
   - **B+树**：所有关键字在叶子，叶子链表支持范围查询，内部结点仅作索引
4. **哈希表**：通过哈希函数 $H(key)$ 将关键字映射到地址，理想情况下 $O(1)$ 查找。关键问题：
   - **哈希函数构造**：除留余数法最常用（$p$ 取素数）
   - **冲突处理**：开放定址法（线性/平方探测）、链地址法
   - **装载因子 $\alpha$** 直接影响性能，$\alpha$ 过大时需**扩容（Rehash）**
