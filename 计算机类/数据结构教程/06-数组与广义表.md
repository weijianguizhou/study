# 数组与广义表

数组（Array）是最基本、最常用的数据结构，几乎所有高级语言都将其作为内置类型提供。广义表（Generalized List）则是线性表的推广——表中元素本身也可以是广义表，具有递归定义的特点。本章将系统阐述数组的存储与地址映射、矩阵的压缩存储以及广义表的实现。

## 数组的定义与基本概念

### 数组的 ADT 定义

数组是由一组类型相同的数据元素构成的有序集合。$n$ 维数组可以视为一维数组的推广：它的每个维度都有一个索引范围，每个元素通过 $n$ 个下标唯一标识。

#### 数据对象（n 维数组）

$$
D = \{ a_{j_1, j_2, \dots, j_n} \mid j_i = 0, 1, \dots, b_i - 1,\; i = 1, 2, \dots, n \}
$$

其中 $b_i$ 是第 $i$ 维的长度。

#### 数据关系

$$
R = \{ R_1, R_2, \dots, R_n \}
$$

其中 $R_i$ 是第 $i$ 维上的偏序关系：

$$
R_i = \{ \langle a_{j_1,\dots,j_i,\dots,j_n}, \; a_{j_1,\dots,j_i+1,\dots,j_n} \rangle \mid 
0 \le j_k \le b_k - 1, \; 1 \le k \le n, \; k \ne i, \; 0 \le j_i \le b_i - 2 \}
$$

#### 二维数组的简化定义

以最常见的二维数组（矩阵）为例：

- **数据对象**：$D = \{ a_{ij} \mid 0 \le i \le b_1 - 1,\; 0 \le j \le b_2 - 1 \}$
- **行关系**：$\text{ROW} = \{ \langle a_{i,j}, a_{i+1,j} \rangle \mid 0 \le i \le b_1 - 2,\; 0 \le j \le b_2 - 1 \}$
- **列关系**：$\text{COL} = \{ \langle a_{i,j}, a_{i,j+1} \rangle \mid 0 \le i \le b_1 - 1,\; 0 \le j \le b_2 - 2 \}$

### 数组的基本操作

| 操作 | 原型 | 功能描述 |
| ---- | ---- | -------- |
| 初始化 | `InitArray(&A, n, bound_1, ..., bound_n)` | 构造数组 $A$，指定维数 $n$ 和各维长度 |
| 销毁 | `DestroyArray(&A)` | 销毁数组 $A$，释放内存 |
| 取值 | `Value(A, &e, index_1, ..., index_n)` | 读取指定下标元素的值赋给 $e$ |
| 赋值 | `Assign(&A, e, index_1, ..., index_n)` | 将 $e$ 的值赋给指定下标的元素 |

> 数组通常**不提供插入和删除操作**（一经定义，结构固定）。这使得数组的存储管理极其简单，但限制了其灵活性。

### 数组与线性表的关系

数组是线性表的推广，二者的关系如下：

| 维度 | 逻辑结构 | 前驱/后继 | 线性表关系 |
| ---- | -------- | --------- | ---------- |
| 一维数组 | 线性结构 | 每个元素最多一个前驱一个后继 | 本身就是线性表 |
| 二维数组 | 每个元素属于两个线性表 | 行上前驱后继 + 列上前驱后继 | 数据元素为线性表的线性表 |
| $n$ 维数组 | 每个元素属于 $n$ 个线性表 | $n$ 个方向各有前驱后继 | 递归定义 |

## 数组的顺序存储与地址映射

### 核心问题

数组是**多维结构**，但计算机内存是**一维结构**。存储数组时必须将多维空间元素映射到一维地址空间。这种映射方式称为**存储映象**。

两种最基本的映射方式：
1. **行优先存储（Row-Major Order）**：以行序为主序，低下标优先。
2. **列优先存储（Column-Major Order）**：以列序为主序，高下标优先。

### 行优先存储（Row-Major Order）

在行优先存储下，数组的第 $i+1$ 行紧接在第 $i$ 行之后排列。

以 $m \times n$ 的二维数组 $A$ 为例：

```
逻辑数组 A[0..m-1][0..n-1]:
  [0,0] [0,1] ... [0,n-1]  |  [1,0] [1,1] ... [1,n-1]  |  ...  |  [m-1,0] ... [m-1,n-1]

物理存储（行优先）:
  A[0][0], A[0][1], ..., A[0][n-1], A[1][0], ..., A[m-1][n-1]
```

#### 地址计算公式

对于二维数组 $A[m][n]$，元素 $A[i][j]$（$0 \le i < m$，$0 \le j < n$）的行优先存储地址为：

$$
\text{LOC}(A[i][j]) = \text{LOC}(A[0][0]) + (i \times n + j) \times L
$$

其中 $L$ 是每个元素的存储字节数。

#### 通用地址公式（n 维数组）

设 $n$ 维数组各维长度为 $b_1, b_2, \dots, b_n$，每个元素占 $L$ 个存储单元，基地址为 $\text{LOC}(A[0,0,\dots,0])$。

**行优先存储**（先排最右下标，从右到左）：

$$
\text{LOC}(a_{j_1,j_2,\dots,j_n}) = \text{LOC}(A[0,\dots,0]) + \left( \sum_{i=1}^{n} j_i \times c_i \right) \times L
$$

其中：

$$
c_i = \prod_{k=i+1}^{n} b_k,\quad c_n = 1
$$

$c_i$ 称为第 $i$ 维的**权值**（或跨度），表示 $a_{j_1,\dots,j_i,\dots,j_n}$ 中第 $i$ 维下标变化一个单位时对应物理位置的偏移量。

**二维实例展开**：

$$c_1 = b_2 \times b_3 \times \cdots \times b_n = n,\quad c_2 = 1$$

$$\text{LOC}(A[i][j]) = \text{LOC}(A[0][0]) + (i \times n + j \times 1) \times L$$

**三维实例**（$A[l][m][n]$）：

$$c_1 = m \times n,\quad c_2 = n,\quad c_3 = 1$$

$$\text{LOC}(A[i][j][k]) = \text{LOC}(A[0][0][0]) + (i \times m \times n + j \times n + k) \times L$$

> C/C++、Python（NumPy 默认）等主流语言均采用**行优先存储**。

### 列优先存储（Column-Major Order）

在列优先存储下，数组的第 $j+1$ 列紧接在第 $j$ 列之后排列。

以 $m \times n$ 的二维数组 $A$ 为例：

```
逻辑数组 A[0..m-1][0..n-1]:
  [0,0] [1,0] ... [m-1,0]  |  [0,1] [1,1] ... [m-1,1]  |  ...  |  [0,n-1] ... [m-1,n-1]

物理存储（列优先）:
  A[0][0], A[1][0], ..., A[m-1][0], A[0][1], ..., A[m-1][n-1]
```

#### 地址计算公式

对于 $m \times n$ 的二维数组，元素 $A[i][j]$ 的列优先存储地址为：

$$
\text{LOC}(A[i][j]) = \text{LOC}(A[0][0]) + (j \times m + i) \times L
$$

> FORTRAN、MATLAB 等采用**列优先存储**。

### C++ 与 Python 数组遍历性能对比

由于 CPU 缓存（Cache）的局部性原理，按存储顺序遍历数组比跳跃式访问快得多。

```cpp
#include <iostream>
#include <chrono>
#include <vector>

// 行优先遍历（缓存友好）
double rowMajorTraverse(const std::vector<std::vector<int>>& mat) {
    int m = mat.size(), n = mat[0].size();
    long long sum = 0;
    
    auto start = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < n; ++j) {
            sum += mat[i][j];
        }
    }
    auto end = std::chrono::high_resolution_clock::now();
    
    return std::chrono::duration<double, std::milli>(end - start).count();
}

// 列优先遍历（缓存不友好）
double colMajorTraverse(const std::vector<std::vector<int>>& mat) {
    int m = mat.size(), n = mat[0].size();
    long long sum = 0;
    
    auto start = std::chrono::high_resolution_clock::now();
    for (int j = 0; j < n; ++j) {
        for (int i = 0; i < m; ++i) {
            sum += mat[i][j];
        }
    }
    auto end = std::chrono::high_resolution_clock::now();
    
    return std::chrono::duration<double, std::milli>(end - start).count();
}
```

```python
import time
import random
from typing import List


def row_major_traverse(mat: List[List[int]]) -> float:
    """行优先遍历"""
    m, n = len(mat), len(mat[0])
    total = 0
    
    start = time.perf_counter()
    for i in range(m):
        for j in range(n):
            total += mat[i][j]
    end = time.perf_counter()
    
    return end - start


def col_major_traverse(mat: List[List[int]]) -> float:
    """列优先遍历"""
    m, n = len(mat), len(mat[0])
    total = 0
    
    start = time.perf_counter()
    for j in range(n):
        for i in range(m):
            total += mat[i][j]
    end = time.perf_counter()
    
    return end - start


# ===== 性能对比 =====
if __name__ == "__main__":
    m, n = 5000, 5000
    # 注意：Python 中嵌套列表并非连续存储，差异不如 C++ 显著但依然存在
    mat = [[1] * n for _ in range(m)]
    
    t1 = row_major_traverse(mat)
    t2 = col_major_traverse(mat)
    
    print(f"Row-Major traverse: {t1:.4f} s")
    print(f"Col-Major traverse: {t2:.4f} s")
    print(f"Speedup: {t2 / t1:.2f}x")
```

## 矩阵的压缩存储

当矩阵中有大量零元素或重值元素时，存储每一个元素是对空间的浪费。**压缩存储**的核心思想是：只存储矩阵中的非零元素（或有用元素），并建立位置映射以便快速寻址。

### 评估指标

- **稀疏因子（Sparsity Factor）**：

$$
\delta = \frac{t}{m \times n}
$$

其中 $m \times n$ 为总元素数，$t$ 为非零元素个数。通常 $\delta \le 0.05$ 视为**稀疏矩阵**。

### 一、对称矩阵的压缩存储

#### 定义

$n$ 阶方阵 $A$ 满足 $a_{ij} = a_{ji}$（$0 \le i,j < n$）。

#### 压缩策略

只存储**下三角**（含主对角线）的 $\frac{n(n+1)}{2}$ 个元素，上三角元素可通过对称性获得。

#### 下标映射公式

将下三角元素按行优先存储在一维数组 $B$ 中：

```
B[0], B[1], B[2], ... 对应:
a[0][0], a[1][0], a[1][1], a[2][0], a[2][1], a[2][2], ...

访问 a[i][j] (0 <= j <= i < n):
  k = i*(i+1)/2 + j          →  B[k] = a[i][j]
  
访问 a[i][j] (0 <= i < j < n) — 通过对称性:
  k = j*(j+1)/2 + i          →  B[k] = a[j][i] = a[i][j]
```

统一公式：

$$k = \begin{cases} \frac{i(i+1)}{2} + j, & i \ge j \\ \frac{j(j+1)}{2} + i, & i < j \end{cases}$$

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>

template <typename T>
class SymmetricMatrix {
private:
    int n;                     // 矩阵阶数
    std::vector<T> data;      // 压缩存储的一维数组

    // 将 (i, j) 映射为一维索引
    int index(int i, int j) const {
        // 统一处理：总是将较大的下标放在前面
        if (i >= j) {
            return i * (i + 1) / 2 + j;
        } else {
            return j * (j + 1) / 2 + i;
        }
    }

public:
    explicit SymmetricMatrix(int order) : n(order) {
        if (n <= 0) throw std::invalid_argument("Order must be positive!");
        data.resize(n * (n + 1) / 2);
    }

    int order() const { return n; }

    // 设置元素值（同时设置对称位置）
    void set(int i, int j, const T& val) {
        if (i < 0 || i >= n || j < 0 || j >= n) {
            throw std::out_of_range("Index out of range!");
        }
        data[index(i, j)] = val;
    }

    // 获取元素值
    T get(int i, int j) const {
        if (i < 0 || i >= n || j < 0 || j >= n) {
            throw std::out_of_range("Index out of range!");
        }
        return data[index(i, j)];
    }

    // 打印完整矩阵
    void print() const {
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                std::cout << get(i, j) << " ";
            }
            std::cout << std::endl;
        }
    }

    // 打印压缩存储的内容
    void printStorage() const {
        std::cout << "Compressed storage (lower triangle, row-major):" << std::endl;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j <= i; ++j) {
                std::cout << "(" << i << "," << j << ")=" 
                          << data[index(i, j)] << " ";
            }
            std::cout << std::endl;
        }
    }
};
```

#### Python 实现

```python
from typing import List


class SymmetricMatrix:
    """对称矩阵的压缩存储"""

    def __init__(self, n: int):
        """创建 n 阶对称矩阵"""
        if n <= 0:
            raise ValueError("Order must be positive!")
        self._n: int = n
        # 只存储下三角（含主对角线）共 n*(n+1)/2 个元素
        self._data: List[float] = [0.0] * (n * (n + 1) // 2)

    def _index(self, i: int, j: int) -> int:
        """将二维下标 (i,j) 映射为一维存储索引"""
        if i >= j:
            return i * (i + 1) // 2 + j
        else:
            return j * (j + 1) // 2 + i

    @property
    def order(self) -> int:
        return self._n

    def set(self, i: int, j: int, val: float) -> None:
        """设置元素值（自动同步对称位置）"""
        self._check_bounds(i, j)
        self._data[self._index(i, j)] = val

    def get(self, i: int, j: int) -> float:
        """获取元素值"""
        self._check_bounds(i, j)
        return self._data[self._index(i, j)]

    def _check_bounds(self, i: int, j: int) -> None:
        if not (0 <= i < self._n and 0 <= j < self._n):
            raise IndexError(f"Index ({i},{j}) out of range!")

    def to_matrix(self) -> List[List[float]]:
        """返回完整的 n×n 矩阵（展开形式）"""
        return [[self.get(i, j) for j in range(self._n)] 
                for i in range(self._n)]

    def print_storage(self) -> None:
        """打印压缩存储内容"""
        print("Compressed storage (lower triangle, row-major):")
        for i in range(self._n):
            row_items = []
            for j in range(i + 1):
                row_items.append(f"({i},{j})={self._data[self._index(i, j)]}")
            print("  ".join(row_items))

    def __str__(self) -> str:
        lines = []
        for i in range(self._n):
            lines.append(" ".join(f"{self.get(i, j):4g}" 
                                   for j in range(self._n)))
        return "\n".join(lines)


# ===== 测试 =====
if __name__ == "__main__":
    sm = SymmetricMatrix(4)
    for i in range(4):
        for j in range(i + 1):
            sm.set(i, j, i * 10 + j)
    print(sm)
    sm.print_storage()
```

### 二、三对角矩阵的压缩存储

#### 定义

三对角矩阵（Tridiagonal Matrix）中，非零元素集中在以主对角线为中心的**三条对角线上**：

$$
a_{ij} = 0, \quad \text{当 } |i - j| > 1
$$

即只有 $|i - j| \le 1$ 的位置可能非零。

#### 压缩策略

按行优先顺序，只存储三条对角线上共 $3n - 2$ 个元素（第一条和最后一条对角线上各有 $n-1$ 个元素，主对角线有 $n$ 个元素；每条对角线上空位不存）。

#### 下标映射公式

在一维数组 $B$ 中，按行优先存储三对角线上的元素：

| 行 i | 该行元素（列） | 对应 B 下标 |
| ---- | ------------ | ---------- |
| 0 | j=0,1 | 0, 1 |
| 1 | j=0,1,2 | 2, 3, 4 |
| 2 | j=1,2,3 | 5, 6, 7 |
| ... | ... | ... |
| i | ... | ... |

一般地，元素 $a_{ij}$（$|i - j| \le 1$）在一维数组中的下标 $k$ 为：

$$
k = 2i + j \quad (0 \le i < n,\; i-1 \le j \le i+1)
$$

反过来，$B[k]$ 对应的 $(i, j)$：

$$i = \left\lfloor \frac{k+1}{3} \right\rfloor,\quad j = k - 2i$$

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>

template <typename T>
class TridiagonalMatrix {
private:
    int n;
    std::vector<T> data;

    bool isValid(int i, int j) const {
        return i >= 0 && i < n && j >= 0 && j < n && std::abs(i - j) <= 1;
    }

public:
    explicit TridiagonalMatrix(int order) : n(order) {
        if (n <= 0) throw std::invalid_argument("Order must be positive!");
        data.resize(3 * n - 2);
    }

    int order() const { return n; }

    void set(int i, int j, const T& val) {
        if (!isValid(i, j)) {
            throw std::out_of_range("Index out of tridiagonal bounds!");
        }
        data[2 * i + j] = val;
    }

    T get(int i, int j) const {
        if (std::abs(i - j) > 1) {
            return T(0);  // 超出三对角线范围均为零
        }
        if (!(i >= 0 && i < n && j >= 0 && j < n)) {
            throw std::out_of_range("Index out of range!");
        }
        return data[2 * i + j];
    }

    void print() const {
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                std::cout << get(i, j) << "\t";
            }
            std::cout << std::endl;
        }
    }
};
```

```python
from typing import List


class TridiagonalMatrix:
    """三对角矩阵的压缩存储"""

    def __init__(self, n: int):
        if n <= 0:
            raise ValueError("Order must be positive!")
        self._n: int = n
        # 只存储 3n - 2 个三对角线上元素
        self._data: List[float] = [0.0] * (3 * n - 2)

    @property
    def order(self) -> int:
        return self._n

    def _is_valid(self, i: int, j: int) -> bool:
        return 0 <= i < self._n and 0 <= j < self._n and abs(i - j) <= 1

    def _index(self, i: int, j: int) -> int:
        """将 (i, j) 映射为压缩存储索引"""
        return 2 * i + j

    def set(self, i: int, j: int, val: float) -> None:
        if not self._is_valid(i, j):
            raise IndexError(f"Index ({i},{j}) out of tridiagonal bounds!")
        self._data[self._index(i, j)] = val

    def get(self, i: int, j: int) -> float:
        if abs(i - j) > 1:
            return 0.0  # 超出三对角线范围，必然为零
        if not (0 <= i < self._n and 0 <= j < self._n):
            raise IndexError(f"Index ({i},{j}) out of range!")
        return self._data[self._index(i, j)]

    def to_matrix(self) -> List[List[float]]:
        return [[self.get(i, j) for j in range(self._n)] 
                for i in range(self._n)]

    def __str__(self) -> str:
        lines = []
        for i in range(self._n):
            lines.append("\t".join(f"{self.get(i, j):4g}" 
                                    for j in range(self._n)))
        return "\n".join(lines)


# ===== 测试 =====
if __name__ == "__main__":
    tm = TridiagonalMatrix(5)
    for i in range(5):
        tm.set(i, i, 100 + i)
        if i < 4:
            tm.set(i, i + 1, 10 * (i + 1))
        if i > 0:
            tm.set(i, i - 1, -5 * i)
    print(tm)
```

### 三、稀疏矩阵（Sparse Matrix）

稀疏矩阵指非零元素远少于总元素的矩阵，通常 $\delta \le 0.05$。若用二维数组存储会浪费大量空间，需要专门的压缩存储方法。

#### 3.1 三元组表示法（Triple Sequence List）

用一个**三元组** $(i, j, a_{ij})$ 唯一确定一个非零元：$i$ 为行号，$j$ 为列号，$a_{ij}$ 为元素值。

所有非零元的三元组按**行号递增、同行按列号递增**的顺序排列，构成三元组表。

```
矩阵 A:          三元组表:
┌     ┐          row col value
│0 5 0│          0   1   5
│0 0 3│          1   2   3
│4 0 0│          2   0   4
└     ┘
```

##### C++ 三元组实现

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>
#include <algorithm>

template <typename T>
struct Triple {
    int row, col;
    T value;
    
    Triple(int r = 0, int c = 0, T v = T()) 
        : row(r), col(c), value(v) {}
};

template <typename T>
class SparseMatrix {
private:
    int rows, cols;
    std::vector<Triple<T>> data;

public:
    SparseMatrix(int m, int n) : rows(m), cols(n) {}

    int numRows() const { return rows; }
    int numCols() const { return cols; }
    int numNonZero() const { return (int)data.size(); }

    // 设置元素值
    void set(int i, int j, const T& val) {
        if (i < 0 || i >= rows || j < 0 || j >= cols) {
            throw std::out_of_range("Index out of range!");
        }
        
        // 查找是否已存在
        for (auto& t : data) {
            if (t.row == i && t.col == j) {
                if (val == T(0)) {
                    // 置零：删除该三元组
                    data.erase(std::remove_if(data.begin(), data.end(),
                        [i, j](const Triple<T>& t) {
                            return t.row == i && t.col == j;
                        }), data.end());
                } else {
                    t.value = val;
                }
                return;
            }
        }
        
        // 新非零元，按顺序插入
        if (val != T(0)) {
            auto it = data.begin();
            while (it != data.end() && 
                   (it->row < i || (it->row == i && it->col < j))) {
                ++it;
            }
            data.insert(it, Triple<T>(i, j, val));
        }
    }

    // 获取元素值
    T get(int i, int j) const {
        for (const auto& t : data) {
            if (t.row == i && t.col == j) return t.value;
        }
        return T(0);
    }

    // 打印三元组表
    void printTriple() const {
        std::cout << "SparseMatrix " << rows << "x" << cols 
                  << " (non-zero: " << data.size() << ")" << std::endl;
        std::cout << "Row\tCol\tValue" << std::endl;
        for (const auto& t : data) {
            std::cout << t.row << "\t" << t.col << "\t" 
                      << t.value << std::endl;
        }
    }

    // 打印完整矩阵
    void print() const {
        for (int i = 0; i < rows; ++i) {
            for (int j = 0; j < cols; ++j) {
                std::cout << get(i, j) << "\t";
            }
            std::cout << std::endl;
        }
    }

    // 矩阵加法
    SparseMatrix add(const SparseMatrix& other) const {
        if (rows != other.rows || cols != other.cols) {
            throw std::invalid_argument("Matrix dimensions mismatch!");
        }
        
        SparseMatrix result(rows, cols);
        int p = 0, q = 0;
        
        while (p < (int)data.size() && q < (int)other.data.size()) {
            if (data[p].row < other.data[q].row ||
                (data[p].row == other.data[q].row && 
                 data[p].col < other.data[q].col)) {
                result.set(data[p].row, data[p].col, data[p].value);
                ++p;
            } else if (data[p].row > other.data[q].row ||
                       (data[p].row == other.data[q].row && 
                        data[p].col > other.data[q].col)) {
                result.set(other.data[q].row, other.data[q].col, 
                           other.data[q].value);
                ++q;
            } else {
                T sum = data[p].value + other.data[q].value;
                result.set(data[p].row, data[p].col, sum);
                ++p; ++q;
            }
        }
        
        while (p < (int)data.size()) {
            result.set(data[p].row, data[p].col, data[p].value);
            ++p;
        }
        while (q < (int)other.data.size()) {
            result.set(other.data[q].row, other.data[q].col, 
                       other.data[q].value);
            ++q;
        }
        
        return result;
    }
};
```

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import List, Optional


@dataclass
class Triple:
    """稀疏矩阵三元组：行、列、值"""
    row: int
    col: int
    value: float
    
    def __repr__(self) -> str:
        return f"({self.row},{self.col},{self.value})"


class SparseMatrix:
    """稀疏矩阵 —— 三元组表示法"""

    def __init__(self, m: int, n: int):
        self._rows: int = m
        self._cols: int = n
        self._data: List[Triple] = []

    @property
    def num_rows(self) -> int:
        return self._rows

    @property
    def num_cols(self) -> int:
        return self._cols

    @property
    def num_nonzero(self) -> int:
        return len(self._data)

    def set(self, i: int, j: int, val: float) -> None:
        """设置元素值（0 值自动删除）"""
        if not (0 <= i < self._rows and 0 <= j < self._cols):
            raise IndexError(f"Index ({i},{j}) out of range!")
        
        # 查找是否已存在
        for k, t in enumerate(self._data):
            if t.row == i and t.col == j:
                if val == 0:
                    self._data.pop(k)
                else:
                    t.value = val
                return
        
        # 新非零元，按行号+列号顺序插入
        if val != 0:
            insert_pos = 0
            while (insert_pos < len(self._data) and
                   (self._data[insert_pos].row < i or
                    (self._data[insert_pos].row == i and 
                     self._data[insert_pos].col < j))):
                insert_pos += 1
            self._data.insert(insert_pos, Triple(i, j, val))

    def get(self, i: int, j: int) -> float:
        """获取元素值"""
        for t in self._data:
            if t.row == i and t.col == j:
                return t.value
        return 0.0

    def to_matrix(self) -> List[List[float]]:
        """展开为完整二维矩阵"""
        mat = [[0.0] * self._cols for _ in range(self._rows)]
        for t in self._data:
            mat[t.row][t.col] = t.value
        return mat

    def print_triple(self) -> None:
        """打印三元组表"""
        print(f"SparseMatrix {self._rows}x{self._cols} "
              f"(non-zero: {len(self._data)})")
        print(f"{'Row':<6}{'Col':<6}{'Value':<10}")
        print("-" * 22)
        for t in self._data:
            print(f"{t.row:<6}{t.col:<6}{t.value:<10}")

    def add(self, other: SparseMatrix) -> SparseMatrix:
        """稀疏矩阵加法"""
        if self._rows != other._rows or self._cols != other._cols:
            raise ValueError("Matrix dimensions mismatch!")
        
        result = SparseMatrix(self._rows, self._cols)
        p = q = 0
        
        while p < len(self._data) and q < len(other._data):
            a = self._data[p]
            b = other._data[q]
            
            if (a.row, a.col) < (b.row, b.col):
                result.set(a.row, a.col, a.value)
                p += 1
            elif (a.row, a.col) > (b.row, b.col):
                result.set(b.row, b.col, b.value)
                q += 1
            else:
                s = a.value + b.value
                result.set(a.row, a.col, s)
                p += 1
                q += 1
        
        while p < len(self._data):
            result.set(self._data[p].row, self._data[p].col, 
                       self._data[p].value)
            p += 1
        
        while q < len(other._data):
            result.set(other._data[q].row, other._data[q].col,
                       other._data[q].value)
            q += 1
        
        return result

    def __str__(self) -> str:
        lines = []
        for i in range(self._rows):
            lines.append("\t".join(f"{self.get(i, j):6g}" 
                                    for j in range(self._cols)))
        return "\n".join(lines)
```

#### 3.2 三元组快速转置算法

矩阵转置 $B = A^T$ 即 $(i, j, v) \to (j, i, v)$。

##### 基本算法

遍历三元组表，将每个三元组的行列互换后插入目标矩阵的正确位置。时间复杂度 $O(t \times n)$（$t$ 为非零元数），效率较低。

##### 快速转置算法（Fast Transpose）

利用两个辅助数组：

- `num[col]`：原矩阵中每列非零元素的个数。
- `pos[col]`：每列第一个非零元在转置矩阵 $B.data$ 中的起始位置。

其中：

$$
\begin{aligned}
\text{pos}[0] &= 0 \\
\text{pos}[\text{col}] &= \text{pos}[\text{col}-1] + \text{num}[\text{col}-1], \quad \text{col} \ge 1
\end{aligned}
$$

**时间复杂度**：$O(t + n)$。

##### C++ 快速转置实现

```cpp
template <typename T>
SparseMatrix<T> fastTranspose(const SparseMatrix<T>& A) {
    int m = A.numRows(), n = A.numCols(), t = A.numNonZero();
    SparseMatrix<T> B(n, m);
    
    if (t == 0) return B;
    
    // 获取 A 的三元组数据
    std::vector<Triple<T>> aData = A.getData();  // 假设增加了 getData()
    
    // 1. 统计每列非零元个数
    std::vector<int> num(n, 0);
    for (const auto& tr : aData) {
        ++num[tr.col];
    }
    
    // 2. 计算每列第一个非零元在 B.data 中的位置
    std::vector<int> pos(n, 0);
    for (int col = 1; col < n; ++col) {
        pos[col] = pos[col - 1] + num[col - 1];
    }
    
    // 3. 一次扫描完成转置
    std::vector<Triple<T>> bData(t);
    for (const auto& tr : aData) {
        int col = tr.col;
        int index = pos[col];
        bData[index] = Triple<T>(col, tr.row, tr.value);
        ++pos[col];
    }
    
    B.setData(bData);  // 假设增加了 setData()
    return B;
}
```

##### Python 快速转置实现

```python
def fast_transpose(sparse_mat: SparseMatrix) -> SparseMatrix:
    """稀疏矩阵的快速转置算法"""
    m, n = sparse_mat.num_rows, sparse_mat.num_cols
    t = sparse_mat.num_nonzero
    
    result = SparseMatrix(n, m)
    if t == 0:
        return result
    
    data = sparse_mat._data  # 访问内部三元组列表
    
    # 1. 统计每列非零元个数
    num = [0] * n
    for triple in data:
        num[triple.col] += 1
    
    # 2. 计算每列第一个非零元在转置矩阵中的位置
    pos = [0] * n
    for col in range(1, n):
        pos[col] = pos[col - 1] + num[col - 1]
    
    # 3. 一次扫描完成转置
    b_data = [None] * t
    for triple in data:
        col = triple.col
        index = pos[col]
        b_data[index] = Triple(col, triple.row, triple.value)
        pos[col] += 1
    
    result._data = b_data  # 直接赋给结果
    return result
```

#### 3.3 十字链表表示法

当稀疏矩阵中非零元位置频繁变化时（如矩阵加法导致产生或消除非零元），三元组的顺序表插入/删除需移动大量数据。**十字链表**提供了一个更灵活的表示法。

##### 结构

- **结点**包含：行号 `row`、列号 `col`、值 `value`、**向右指针** `right`（指向同行下一非零元）、**向下指针** `down`（指向同列下一非零元）。
- **行头指针数组** `rowHead[]`：`rowHead[i]` 指向第 $i$ 行第一个非零元。
- **列头指针数组** `colHead[]`：`colHead[j]` 指向第 $j$ 列第一个非零元。

```
   rowHead[0] → (0,1,5) → right → nullptr
   rowHead[1] → (1,2,3) → nullptr
   rowHead[2] → (2,0,8) → nullptr
```

##### C++ 十字链表节点定义

```cpp
        T value;
```

```cpp
public:
    SparseMatrixFull(int m, int n) : rows(m), cols(n) {}

    // 获取三元组（供转置等操作使用）
    const std::vector<Triple>& getData() const { return triples; }
    void setData(const std::vector<Triple>& t) { triples = t; }

    int numRows() const { return rows; }
    int numCols() const { return cols; }
    int numNonZero() const { return (int)triples.size(); }

    void set(int i, int j, const T& val) {
        for (auto& tr : triples) {
            if (tr.row == i && tr.col == j) {
                if (val == T(0)) {
                    triples.erase(
                        std::remove_if(triples.begin(), triples.end(),
                            [i, j](const Triple& t) {
                                return t.row == i && t.col == j;
                            }), triples.end());
                } else {
                    tr.value = val;
                }
                return;
            }
        }
        if (val != T(0)) {
            auto it = triples.begin();
            while (it != triples.end() && 
                   (it->row < i || (it->row == i && it->col < j))) {
                ++it;
            }
            triples.insert(it, Triple(i, j, val));
        }
    }

    T get(int i, int j) const {
        for (const auto& tr : triples) {
            if (tr.row == i && tr.col == j) return tr.value;
        }
        return T(0);
    }
```

## 广义表（Generalized List）

### 定义

**广义表**是线性表的推广。在广义表中，元素 $a_i$ 可以是**原子**（不可再分的单个数据元素），也可以是另一个**广义表**。

#### 递归定义

1. 广义表是一个有限序列。
2. 广义表的元素可以是**原子**（Atom），也可以是**子表**（Sublist，即另一个广义表）。
3. 广义表可以为空。

#### 形式化定义

$$
\text{LS} = (a_1, a_2, \dots, a_n)
$$

其中 $n \ge 0$，$a_i$ 是原子或广义表。

#### 示例

| 广义表 | 描述 |
| ------ | ---- |
| $A = ()$ | 空表，长度为 $0$ |
| $B = (e)$ | 含一个原子 $e$ 的表 |
| $C = (a, (b, c, d))$ | 含一个原子 $a$ 和一个子表 $(b, c, d)$ |
| $D = (A, B, C)$ | 含三个子表 |
| $E = (a, E)$ | 递归表，无限深度 |

### 基本概念

| 术语 | 定义 |
| ---- | ---- |
| **原子（Atom）** | 广义表中不可再分的元素 |
| **子表（Sublist）** | 广义表中是另一个广义表的元素 |
| **表头（Head）** | 广义表非空时的第一个元素（可能是原子也可能是子表） |
| **表尾（Tail）** | 删除表头后剩余元素组成的广义表（永远是一个广义表） |
| **长度（Length）** | 广义表中最外层元素的个数 |
| **深度（Depth）** | 广义表嵌套层次的最大值：$\text{depth}(LS) = \max(\text{depth}(a_i)) + 1$ |

#### 表头与表尾举例

| 广义表 | 表头 Head | 表尾 Tail |
| ------ | --------- | --------- |
| $(a, (b, c), d)$ | $a$ | $((b, c), d)$ |
| $((a, b), c)$ | $(a, b)$ | $(c)$ |
| $(a)$ | $a$ | $()$ |
| $()$ | 无定义 | 无定义 |

> **重要性质**：任何非空广义表的**表尾总是一个广义表**。这一性质是头尾分解法实现广义表递归操作的理论基础。

### 广义表的性质

1. **广义表的层次结构**：广义表可以嵌套任意深度。
2. **广义表的共享性**：同一子表可被不同广义表（或同一广义表的不同位置）共享。
3. **广义表的递归性**：广义表可以直接或间接地包含自己。

### 存储结构：头尾链表存储法

最常用的广义表存储结构是**头尾链表存储法**，也叫**广义表的二叉链表表示法**。

#### 结点结构

每个结点需要区分其类型（原子/子表），因此设置一个**标志域** `tag`：

```
tag = 0 (ATOM):    结点是原子
  ┌─────┬───────────┬─────┐
  │ tag │   data    │ tp  │
  │  0  │   原子值   │ ←──→│  tp 指向同一层的下一个元素（相当于表尾）
  └─────┴───────────┴─────┘

tag = 1 (LIST):    结点是子表
  ┌─────┬───────────┬─────┐
  │ tag │    hp     │ tp  │
  │  1  │  子表指针  │ ←──→│  hp 指向子表的第一个元素，tp 指向下一个元素
  └─────┴───────────┴─────┘
```

- **`hp`（head pointer）**：指向子表的第一个元素（仅当 `tag == LIST` 时有效）。
- **`tp`（tail pointer）**：指向同一层的下一个元素（即表尾）。

此表示法恰好将广义表转化为**二叉树**：
- `hp` 对应二叉树的**左孩子**（子表内容）。
- `tp` 对应二叉树的**右孩子**（下一个兄弟）。

#### 示例：广义表 $C = (a, (b, c))$

```
                   ┌──────────────┐
                   │ tag=1  hp│tp │──────→ nullptr
                   └──┬───────────┘
                      │ hp
          ┌───────────┘
          ▼
┌──────────────────┐    ┌──────────────────┐
│ tag=0  data='a' │───→│ tag=1  hp│tp    │────→ nullptr
│             tp  │    └──┬───────────────┘
└──────────────────┘       │ hp
                      ┌────┘
                      ▼
           ┌──────────────────┐    ┌──────────────────┐
           │ tag=0  data='b' │───→│ tag=0  data='c' │──→ nullptr
           │             tp  │    │             tp  │
           └──────────────────┘    └──────────────────┘
```

### C++ 广义表完整实现

```cpp
#include <iostream>
#include <string>
#include <cctype>
#include <stdexcept>
#include <memory>

// 结点类型标志
enum NodeType { ATOM = 0, LIST = 1 };

// 广义表结点
template <typename T>
struct GLNode {
    NodeType tag;
    
    union {
        T atom;            // tag == ATOM 时使用
        struct {
            GLNode* hp;    // 子表指针
            GLNode* tp;    // 下一元素指针（表尾）
        } ptr;             // tag == LIST 时使用
    };
    
    // 原子结点构造
    GLNode(T val) : tag(ATOM), atom(val) {}
    
    // 子表结点构造
    GLNode(GLNode* h, GLNode* t) : tag(LIST) {
        ptr.hp = h;
        ptr.tp = t;
    }
};

template <typename T>
class GeneralizedList {
private:
    GLNode<T>* head;  // 指向广义表的第一个结点

    // 析构辅助（递归删除所有结点）
    void destroy(GLNode<T>* node) {
        if (node == nullptr) return;
        if (node->tag == LIST) {
            destroy(node->ptr.hp);
        }
        destroy(node->ptr.tp);  // 也是 tp
        delete node;
    }

    // 深度计算（递归）
    int depthHelper(GLNode<T>* node) const {
        if (node == nullptr) return 1;
        if (node->tag == ATOM) return 0;
        
        int maxDepth = 0;
        GLNode<T>* p = node->ptr.hp;
        while (p != nullptr) {
            int d = depthHelper(p);
            if (d > maxDepth) maxDepth = d;
            p = p->ptr.tp;
        }
        return maxDepth + 1;
    }

    // 打印辅助
    void printHelper(GLNode<T>* node) const {
        if (node == nullptr) {
            std::cout << "()";
            return;
        }
        if (node->tag == ATOM) {
            std::cout << node->atom;
        } else {
            std::cout << "(";
            GLNode<T>* p = node->ptr.hp;
            while (p != nullptr) {
                if (p != node->ptr.hp) std::cout << ", ";
                printNode(p);
                p = p->ptr.tp;
            }
            std::cout << ")";
        }
    }

    void printNode(GLNode<T>* node) const {
        if (node->tag == ATOM) {
            std::cout << node->atom;
        } else {
            printHelper(node);  // 递归打印子表
        }
    }

    // 复制辅助
    GLNode<T>* copyHelper(GLNode<T>* node) {
        if (node == nullptr) return nullptr;
        
        if (node->tag == ATOM) {
            return new GLNode<T>(node->atom);
        } else {
            GLNode<T>* newHp = copyHelper(node->ptr.hp);
            GLNode<T>* newTp = copyHelper(node->ptr.tp);
            return new GLNode<T>(newHp, newTp);
        }
    }

public:
    GeneralizedList() : head(nullptr) {}

    ~GeneralizedList() {
        destroy(head);
    }

    GeneralizedList(const GeneralizedList& other) {
        head = copyHelper(other.head);
    }

    GeneralizedList& operator=(const GeneralizedList& other) {
        if (this != &other) {
            destroy(head);
            head = copyHelper(other.head);
        }
        return *this;
    }

    // 创建空表
    void createEmpty() {
        head = nullptr;
    }

    // 创建原子表
    void createAtom(T val) {
        destroy(head);
        head = new GLNode<T>(val);
    }

    // 获取深度
    int depth() const {
        return depthHelper(head);
    }

    // 判空
    bool empty() const {
        return head == nullptr;
    }

    // 打印
    void print() const {
        if (head == nullptr) {
            std::cout << "()" << std::endl;
            return;
        }
        if (head->tag == ATOM) {
            std::cout << "(" << head->atom << ")" << std::endl;
        } else {
            printHelper(head);
            std::cout << std::endl;
        }
    }
```

### Python 广义表完整实现

```python
from __future__ import annotations
from enum import Enum, auto
from typing import Union, Optional, List


class NodeType(Enum):
    ATOM = auto()
    LIST = auto()


class GLNode:
    """广义表结点"""
    
    def __init__(self, tag: NodeType, data=None, 
                 hp: Optional[GLNode] = None, 
                 tp: Optional[GLNode] = None):
        self.tag: NodeType = tag
        if tag == NodeType.ATOM:
            self.data = data  # 原子值
        else:
            self.hp: Optional[GLNode] = hp  # 子表指针（表头）
            self.tp: Optional[GLNode] = tp  # 下一元素指针（表尾）
    
    def __repr__(self) -> str:
        if self.tag == NodeType.ATOM:
            return f"ATOM({self.data!r})"
        else:
            return f"LIST(hp=..., tp=...)"


class GeneralizedList:
    """广义表 —— 头尾链表存储法"""

    def __init__(self):
        self._head: Optional[GLNode] = None

    @staticmethod
    def _build_from_nested(data: Union[None, list, object]) -> Optional[GLNode]:
        """
        从嵌套 Python 列表构造广义表
        
        例如: ['a', ['b', 'c']] → 广义表 (a, (b, c))
        """
        if data is None or (isinstance(data, list) and len(data) == 0):
            return None
        
        if not isinstance(data, list):
            # 原子
            return GLNode(NodeType.ATOM, data=data)
        
        # 列表：创建一连串的 LIST 结点
        if len(data) == 0:
            return None
        
        # 构造链
        first_node = None
        prev_node = None
        
        for item in data:
            if isinstance(item, list):
                # 子表
                sub_node = GeneralizedList._build_from_nested(item)
                node = GLNode(NodeType.LIST, hp=sub_node)
            else:
                # 原子
                node = GLNode(NodeType.ATOM, data=item)
            
            if first_node is None:
                first_node = node
                prev_node = node
            else:
                prev_node.tp = node
                prev_node = node
        
        return first_node

    @classmethod
    def from_nested(cls, data: list) -> GeneralizedList:
        """从嵌套列表创建广义表"""
        gl = cls()
        gl._head = cls._build_from_nested(data)
        return gl

    def empty(self) -> bool:
        return self._head is None

    def depth(self) -> int:
        """计算广义表深度"""
        return self._depth_helper(self._head)

    def _depth_helper(self, node: Optional[GLNode]) -> int:
        if node is None:
            return 1
        if node.tag == NodeType.ATOM:
            return 0
        
        max_depth = 0
        cur = node  # 遍历本层所有元素
        while cur is not None:
            if cur.tag == NodeType.LIST:
                d = self._depth_helper(cur.hp)
                if d > max_depth:
                    max_depth = d
            cur = cur.tp
        return max_depth + 1

    def head(self):
        """返回表头"""
        if self._head is None:
            raise ValueError("Cannot get head of empty list!")
        if self._head.tag == NodeType.ATOM:
            return self._head.data
        else:
            # 返回子表
            sub = GeneralizedList()
            sub._head = self._head.hp
            return sub

    def tail(self) -> GeneralizedList:
        """返回表尾"""
        if self._head is None:
            raise ValueError("Cannot get tail of empty list!")
        sub = GeneralizedList()
        sub._head = self._head.tp  # tp 总是一个广义表
        return sub

    def to_nested(self) -> Union[None, list, object]:
        """将广义表展开为嵌套 Python 列表"""
        return self._to_nested_helper(self._head)

    def _to_nested_helper(self, node: Optional[GLNode]) -> Union[None, list, object]:
        if node is None:
            return []
        
        result: list = []
        cur = node
        while cur is not None:
            if cur.tag == NodeType.ATOM:
                result.append(cur.data)
            else:
                result.append(self._to_nested_helper(cur.hp))
            cur = cur.tp
        return result

    def __str__(self) -> str:
        return self._str_helper(self._head, is_outer=True)

    def _str_helper(self, node: Optional[GLNode], is_outer: bool = False) -> str:
        if node is None:
            return "()"
        
        # 如果是单原子（最外层）
        if node.tag == NodeType.ATOM and node.tp is None and is_outer:
            return f"({node.data!r})"
        
        result = "("
        cur = node
        first = True
        while cur is not None:
            if not first:
                result += ", "
            first = False
            
            if cur.tag == NodeType.ATOM:
                result += repr(cur.data)
            else:
                result += self._str_helper(cur.hp)
            
            cur = cur.tp
        result += ")"
        return result

    def __repr__(self) -> str:
        return f"GeneralizedList({self})"


# ===== 使用示例 =====
if __name__ == "__main__":
    # 从嵌套列表创建
    gl = GeneralizedList.from_nested(['a', ['b', 'c'], 'd'])
    print(f"广义表: {gl}")                    # ('a', ('b', 'c'), 'd')
    print(f"深度:   {gl.depth()}")            # 2
    print(f"嵌套表示: {gl.to_nested()}")     # ['a', ['b', 'c'], 'd']
    
    # 空表
    gl_empty = GeneralizedList.from_nested([])
    print(f"空表: {gl_empty}")                # ()
    
    # 单原子
    gl_atom = GeneralizedList.from_nested(['x'])
    print(f"单原子: {gl_atom}")               # ('x',)
    
    # 纯原子表
    gl_flat = GeneralizedList.from_nested([1, 2, 3, 4])
    print(f"平表: {gl_flat}")                 # (1, 2, 3, 4)
    print(f"深度: {gl_flat.depth()}")         # 1
    
    # 深层嵌套
    gl_deep = GeneralizedList.from_nested(['a', ['b', ['c', 'd']]])
    print(f"深层: {gl_deep}")                 # ('a', ('b', ('c', 'd')))
    print(f"深度: {gl_deep.depth()}")         # 3
```

## 总结

| 主题 | 核心要点 |
| ---- | -------- |
| **数组定义** | 同类型元素的有限序列，一经定义结构固定，无插入删除 |
| **行优先/列优先** | 主流语言（C/C++/Python）用行优先；FORTRAN/MATLAB 用列优先；地址公式依各维权值计算 |
| **缓存性能** | 按存储顺序遍历（如 C++ 行优先则按行遍历）可大幅提升性能 |
| **对称矩阵** | 仅存下三角 $\frac{n(n+1)}{2}$ 个元素，下标映射 $k = \frac{i(i+1)}{2} + j$ |
| **三对角矩阵** | 仅存 $3n-2$ 个元素，映射 $k = 2i + j$ |
| **稀疏矩阵** | 三元组表 $(i, j, v)$，快速转置 $O(t+n)$；十字链表适合动态修改 |
| **广义表** | 线性表的推广，元素可以是原子或子表；头尾链表存储法（二叉链表）；支持递归定义 |

数组是所有高级语言的基石；矩阵压缩存储在数值计算和科学模拟中不可或缺；广义表的递归结构为 LISP 等函数式语言提供了理论根基。
