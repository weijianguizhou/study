# 数据结构 · 学习笔记索引

> **数据结构**是计算机科学与技术的核心基础课程，研究非数值计算的程序设计问题中计算机的操作对象以及它们之间的关系和操作。本教程涵盖数据结构的基本概念、线性结构、树型结构、图状结构、查找与排序等核心内容，每章均提供 C++ 和 Python 双语言完整实现。

## 学习路线建议

```
第1阶段：基础概念（第01章）
    ├── 数据结构的基本概念与术语
    ├── 算法分析方法（时间复杂度 + 空间复杂度）
    └── 编程环境搭建（C++ / Python）

第2阶段：线性结构（第02-05章）
    ├── 顺序表 → 链表 → 栈与队列 → 数组与广义表
    └── 重点：掌握插入/删除的复杂度推导、顺序vs链式的权衡

第3阶段：非线性结构（第06-07章）
    ├── 树与二叉树 → 图
    └── 重点：递归思想、遍历算法、最短路径与最小生成树

第4阶段：算法应用（第08-10章）
    ├── 查找 → 排序 → 综合应用
    └── 重点：哈希表的冲突处理、各类排序的稳定性与适用场景
```

> **学习提示**：每章末尾的**习题与思考**部分建议动手编码实现，纸上得来终觉浅，绝知此事要躬行。遇到代码实现困难时，可以查看对应章节提供的完整 C++/Python 代码作为参考。
