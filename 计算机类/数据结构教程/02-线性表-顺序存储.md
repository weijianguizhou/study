# 线性表——顺序存储

## 2.1 线性表的基本概念

### 2.1.1 线性表的定义

**线性表（Linear List）** 是**零个或多个**具有相同数据类型的 $n$ 个（$n \ge 0$）数据元素的**有限序列**。

正式地记为：

$$\text{List} = (a_1, a_2, \dots, a_{i-1}, a_i, a_{i+1}, \dots, a_n)$$

其中：
- $a_i$：线性表中的数据元素（$1 \le i \le n$）
- $n$：线性表的长度（表长）；当 $n = 0$ 时称为**空表**
- $i$：数据元素在线性表中的**位序**（从 1 开始计数）

### 2.1.2 线性表的关键特征

| 特征 | 说明 |
|-----|------|
| **有限性** | 线性表中数据元素个数 $n$ 是有限的，不可能包含无限个元素。 |
| **序列性** | 线性表中的元素是**有序**的，在逻辑上**依次排列**。 |
| **一对一关系** | 每个数据元素（除首尾外）有且仅有一个**直接前驱**和一个**直接后继**。 |

**元素间关系的精确描述**：

- 第一个元素 $a_1$ **没有前驱**，称为**表头**
- 最后一个元素 $a_n$ **没有后继**，称为**表尾**
- 对于任意 $a_i$（$1 < i < n$）：
  - **直接前驱**：$a_{i-1}$
  - **直接后继**：$a_{i+1}$

### 2.1.3 核心术语

| 术语 | 英文 | 描述 |
|-----|------|------|
| 数据元素 | Data Element | 线性表中的基本个体，可以是数字、字符、结构体等 |
| 表长 | Length | 线性表中数据元素的总数，记为 $n$ |
| 空表 | Empty List | $n = 0$ 时的线性表 |
| 位序 | Position | 元素在线性表中的位置，通常从 1 开始计数 |
| 前驱 | Predecessor | 在 $a_i$ 之前紧邻的元素 $a_{i-1}$ |
| 后继 | Successor | 在 $a_i$ 之后紧邻的元素 $a_{i+1}$ |

### 2.1.4 线性表的举例

- **26 个英文字母表**：`(A, B, C, ..., Z)`
- **学生成绩单**：`(98, 87, 92, 76, 85)`，每个元素为数值型
- **扑克牌点数**：`(2, 3, 4, ..., 10, J, Q, K, A)`，同花色按点数排列
- **稀疏多项式**：每一项是一个数对 $(c_i, e_i)$，按指数降序排列

## 2.2 顺序表（Sequential List）

### 2.2.1 顺序存储结构

**顺序存储结构**是指用一组**地址连续的存储单元**依次存储线性表的数据元素。线性表的顺序表示称为**顺序表**。

**示意图**：

```
逻辑结构:   a1 → a2 → a3 → ... → an
            ↓    ↓    ↓         ↓
存储结构:  [a1] [a2] [a3] [...] [an]
地址:      b    b+L  b+2L ...   b+(n-1)L
```

其中 $b$ 是基地址，$L$ 是每个元素占用的存储单元数。

**随机存取**：根据基地址和位序，可在 $O(1)$ 时间内直接访问任意元素。

$$LOC(a_i) = LOC(a_1) + (i - 1) \times L$$

### 2.2.2 顺序表的 ADT 定义

```
ADT SqList {
    数据对象 D:  {ai | ai ∈ ElemType, i = 1, 2, ..., n, n ≥ 0}
    数据关系 S:  {<a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, i = 2, ..., n}
    基本操作 P:
        InitList(&L):        构造一个空的顺序表 L
        DestroyList(&L):     销毁顺序表 L
        ListEmpty(L):        若 L 为空表，返回 true，否则返回 false
        ListLength(L):       返回 L 中元素个数（表长）
        ClearList(&L):       将 L 重置为空表
        GetElem(L, i, &e):   用 e 返回 L 中第 i 个元素的值（1 ≤ i ≤ ListLength(L)）
        LocateElem(L, e):    返回 L 中第 1 个与 e 值相等的元素的位序；若不存在则返回 0
        PriorElem(L, cur_e, &pre_e):
                             若 cur_e 是 L 的元素且不是第一个，用 pre_e 返回其前驱
        NextElem(L, cur_e, &next_e):
                             若 cur_e 是 L 的元素且不是最后一个，用 next_e 返回其后继
        ListInsert(&L, i, e):在 L 中第 i 个位置插入新元素 e（1 ≤ i ≤ ListLength(L)+1）
        ListDelete(&L, i, &e):删除 L 的第 i 个元素，并用 e 返回其值
        ListTraverse(L, visit()):依次对 L 的每个元素调用函数 visit()
} ADT SqList
```

### 2.2.3 顺序表的优缺点

| 优点 | 缺点 |
|-----|------|
| ① 随机存取：按位序访问 $O(1)$ | ① 插入/删除需大量移动元素 $O(n)$ |
| ② 存储密度高：无额外指针开销 | ② 需要预先分配连续空间 |
| ③ 实现简单，数组天然支持 | ③ 空间大小固定，可能溢出或浪费 |

## 2.3 顺序表的基本操作分析

### 2.3.1 按位查找 GetElem(L, i, &e)

**原理**：利用随机存取特性，直接通过下标访问第 $i-1$ 个数组元素。

**时间复杂度**：$O(1)$

**元素移动次数**：0

```cpp
// C++
template <typename T>
bool SqList<T>::GetElem(int i, T& e) {
    if (i < 1 || i > length) return false;  // 位序越界
    e = data[i - 1];  // 直接下标访问，O(1)
    return true;
}
```

```python
# Python
def get_elem(self, i: int) -> T:
    """获取第 i 个元素（位序从 1 开始），O(1)"""
    if i < 1 or i > self._length:
        raise IndexError(f"位序 {i} 越界，有效范围 1~{self._length}")
    return self._data[i - 1]
```

### 2.3.2 按值查找 LocateElem(L, e)

**原理**：从第一个元素开始，依次与目标值比较，直到找到相等的元素或遍历完所有元素。

**时间复杂度**：$O(n)$

**元素移动次数**：0

**平均比较次数（等概率）**：$\frac{n+1}{2}$

```cpp
// C++
template <typename T>
int SqList<T>::LocateElem(const T& e) {
    for (int i = 0; i < length; i++) {
        if (data[i] == e)
            return i + 1;  // 返回位序（从 1 开始）
    }
    return 0;  // 未找到
}
```

```python
# Python
def locate_elem(self, e: T) -> int:
    """查找值为 e 的第一个元素，返回其位序（从 1 开始），未找到返回 0，O(n)"""
    for i in range(self._length):
        if self._data[i] == e:
            return i + 1
    return 0
```

### 2.3.3 插入元素 ListInsert(&L, i, e)

**原理**：在第 $i$ 个位置（$1 \le i \le n+1$）插入新元素 $e$，需要将第 $i$ 到第 $n$ 个元素依次向后移动一位，然后插入新元素，表长加一。

**移动过程图解**（在位置 $i=3$ 插入 $X$）：

```
插入前： [a1] [a2] [a3] [a4] [a5] [  ]   length = 5
                          ↑ (位序 3)

Step 1:  移动 a5 → [a1] [a2] [a3] [a4] [  ] [a5]
Step 2:  移动 a4 → [a1] [a2] [a3] [  ] [a4] [a5]
Step 3:  移动 a3 → [a1] [a2] [  ] [a3] [a4] [a5]
Step 4:  插入 X  → [a1] [a2] [ X ] [a3] [a4] [a5]

插入后： length = 6
```

**时间复杂度分析**：
- 插入位置 $i = n+1$（表尾）：移动 0 次 → $O(1)$（最好）
- 插入位置 $i = 1$（表头）：移动 $n$ 次 → $O(n)$（最坏）
- 期望移动次数（等概率插入到各位置）：$\sum_{i=1}^{n+1} \frac{1}{n+1} (n-i+1) = \frac{n}{2}$ → $O(n)$（平均）

**C++ 实现**：

```cpp
template <typename T>
bool SqList<T>::ListInsert(int i, const T& e) {
    // 位序检查：允许插入到 1 ~ length+1
    if (i < 1 || i > length + 1) return false;
    // 存储空间已满
    if (length >= maxSize) return false;

    // 第 i 个及之后的元素后移（从最后一个开始）
    // 第 i 个元素的下标是 i-1，最后元素下标是 length-1
    for (int j = length - 1; j >= i - 1; j--)
        data[j + 1] = data[j];

    data[i - 1] = e;  // 插入新元素
    length++;         // 表长加 1
    return true;
}
```

**Python 实现**：

```python
def list_insert(self, i: int, e: T) -> bool:
    """在第 i 个位置插入元素 e（位序从 1 开始），O(n)"""
    if i < 1 or i > self._length + 1:
        return False
    if self._length >= self._capacity:
        self._resize(self._capacity * 2)  # 动态扩容

    # 第 i 个及之后的元素后移
    for j in range(self._length - 1, i - 2, -1):
        self._data[j + 1] = self._data[j]

    self._data[i - 1] = e
    self._length += 1
    return True
```

### 2.3.4 删除元素 ListDelete(&L, i, &e)

**原理**：删除第 $i$ 个元素（$1 \le i \le n$），将其值保存至 $e$，再将第 $i+1$ 到第 $n$ 个元素依次向前移动一位，表长减一。

**移动过程图解**（删除位序 $i=2$ 的元素）：

```
删除前： [a1] [a2] [a3] [a4] [a5]   length = 5
              ↑ (位序 2，目标删除)

Step 1:  保存 a2 → e = a2
Step 2:  移动 a3 → [a1] [a3] [a3] [a4] [a5]
Step 3:  移动 a4 → [a1] [a3] [a4] [a4] [a5]
Step 4:  移动 a5 → [a1] [a3] [a4] [a5] [a5]

删除后： [a1] [a3] [a4] [a5] [   ]   length = 4
```

**时间复杂度分析**：
- 删除位置 $i = n$（表尾）：移动 0 次 → $O(1)$（最好）
- 删除位置 $i = 1$（表头）：移动 $n-1$ 次 → $O(n)$（最坏）
- 期望移动次数（等概率删除各位置）：$\sum_{i=1}^{n} \frac{1}{n} (n-i) = \frac{n-1}{2}$ → $O(n)$（平均）

**C++ 实现**：

```cpp
template <typename T>
bool SqList<T>::ListDelete(int i, T& e) {
    // 位序检查：只能删除 1 ~ length
    if (i < 1 || i > length) return false;

    e = data[i - 1];  // 保存被删元素的值

    // 第 i+1 个及之后的元素前移
    for (int j = i; j < length; j++)
        data[j - 1] = data[j];

    length--;  // 表长减 1
    return true;
}
```

**Python 实现**：

```python
def list_delete(self, i: int) -> T:
    """删除第 i 个元素，返回被删元素的值（位序从 1 开始），O(n)"""
    if i < 1 or i > self._length:
        raise IndexError(f"位序 {i} 越界，有效范围 1~{self._length}")

    e = self._data[i - 1]  # 保存被删元素

    # 第 i+1 个及之后的元素前移
    for j in range(i, self._length):
        self._data[j - 1] = self._data[j]

    self._length -= 1
    return e
```

### 2.3.5 有序表归并 Merge(L1, L2, &L3)

**原理**：将两个有序顺序表 LA 和 LB 合并为一个新的有序表 LC。使用双指针法，依次比较两个表的当前元素，将较小的放入 LC。

**算法步骤**：
1. 初始化 $i = 0$（指向 LA 第一个元素），$j = 0$（指向 LB 第一个元素），$k = 0$（指向 LC）
2. 当 $i < len(LA)$ 且 $j < len(LB)$ 时循环：
   - 若 `LA[i] ≤ LB[j]`，则 `LC[k++] = LA[i++]`
   - 否则 `LC[k++] = LB[j++]`
3. 若 LA 有剩余，将剩余元素复制至 LC
4. 若 LB 有剩余，将剩余元素复制至 LC

**时间复杂度**：$O(m + n)$，其中 $m, n$ 分别为 LA、LB 的长度。

**C++ 实现**：

```cpp
template <typename T>
void Merge(const SqList<T>& LA, const SqList<T>& LB, SqList<T>& LC) {
    int i = 0, j = 0, k = 0;
    int m = LA.GetLength();
    int n = LB.GetLength();

    // 合并两个有序表
    while (i < m && j < n) {
        T elemA, elemB;
        LA.GetElem(i + 1, elemA);
        LB.GetElem(j + 1, elemB);
        if (elemA <= elemB) {
            T val; LA.GetElem(i + 1, val);
            LC.ListInsert(k + 1, val);
            i++;
        } else {
            T val; LB.GetElem(j + 1, val);
            LC.ListInsert(k + 1, val);
            j++;
        }
        k++;
    }

    // 处理 LA 剩余元素
    while (i < m) {
        T val; LA.GetElem(i + 1, val);
        LC.ListInsert(k + 1, val);
        i++; k++;
    }

    // 处理 LB 剩余元素
    while (j < n) {
        T val; LB.GetElem(j + 1, val);
        LC.ListInsert(k + 1, val);
        j++; k++;
    }
}
```

**Python 实现**：

```python
def merge_sorted(la: list, lb: list) -> list:
    """合并两个有序列表，返回新的有序列表，O(m + n)"""
    lc = []
    i = j = 0
    m, n = len(la), len(lb)

    while i < m and j < n:
        if la[i] <= lb[j]:
            lc.append(la[i])
            i += 1
        else:
            lc.append(lb[j])
            j += 1

    # 处理剩余元素
    lc.extend(la[i:])
    lc.extend(lb[j:])

    return lc
```

### 2.3.6 合并（去重求并集）Union(LA, LB)

**原理**：将两个顺序表 LA 和 LB（分别表示集合 A、B），求集合的并集 $A \cup B$ 存入 LC。

**算法步骤**：
1. 将 LA 中的所有元素复制到 LC
2. 遍历 LB 中的每个元素，若不在 LC 中则插入到 LC 末尾

**时间复杂度**：$O(n^2)$（朴素实现中使用顺序查找），可优化到 $O(n \log n)$ 或 $O(n)$。

**C++ 实现**：

```cpp
template <typename T>
void Union(const SqList<T>& LA, const SqList<T>& LB, SqList<T>& LC) {
    int lenA = LA.GetLength();
    int lenB = LB.GetLength();

    // 将 LA 的所有元素复制到 LC
    for (int i = 0; i < lenA; i++) {
        T val; LA.GetElem(i + 1, val);
        LC.ListInsert(i + 1, val);
    }

    // 遍历 LB，若不在 LC 中则加入
    for (int j = 0; j < lenB; j++) {
        T elemB; LB.GetElem(j + 1, elemB);
        if (LC.LocateElem(elemB) == 0) {
            LC.ListInsert(LC.GetLength() + 1, elemB);
        }
    }
}
```

**Python 实现**：

```python
def union_sets(la: SqList, lb: SqList) -> SqList:
    """求两个集合的并集"""
    lc = SqList(la.length() + lb.length())
    # 复制 la 全部元素
    for i in range(la.length()):
        lc.list_insert(i + 1, la.get_elem(i + 1))
    # 将 lb 中不在 lc 的元素插入
    for j in range(lb.length()):
        elem = lb.get_elem(j + 1)
        if lc.locate_elem(elem) == 0:
            lc.list_insert(lc.length() + 1, elem)
    return lc
```

## 2.4 顺序表的完整实现

### 2.4.1 C++ 模板类实现

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

template <typename T>
class SqList {
private:
    T* data;       // 存储空间的基地址（动态数组）
    int length;    // 当前表长（元素个数）
    int maxSize;   // 当前分配的最大存储容量

    // 动态扩容（加倍策略）
    void resize(int newCapacity) {
        T* newData = new T[newCapacity];
        for (int i = 0; i < length; i++)
            newData[i] = data[i];
        delete[] data;
        data = newData;
        maxSize = newCapacity;
    }

public:
    // ========== 构造与析构 ==========

    // 默认构造函数
    SqList(int initSize = 16) {
        maxSize = initSize;
        data = new T[maxSize];
        length = 0;
    }

    // 拷贝构造函数
    SqList(const SqList<T>& other) {
        maxSize = other.maxSize;
        length = other.length;
        data = new T[maxSize];
        for (int i = 0; i < length; i++)
            data[i] = other.data[i];
    }

    // 析构函数
    ~SqList() {
        delete[] data;
        data = nullptr;
    }

    // 赋值运算符重载
    SqList<T>& operator=(const SqList<T>& other) {
        if (this != &other) {
            delete[] data;
            maxSize = other.maxSize;
            length = other.length;
            data = new T[maxSize];
            for (int i = 0; i < length; i++)
                data[i] = other.data[i];
        }
        return *this;
    }

    // ========== 基本操作 ==========

    // 判断是否为空
    bool Empty() const { return length == 0; }

    // 返回表长
    int GetLength() const { return length; }

    // 返回当前容量
    int GetCapacity() const { return maxSize; }

    // 清空
    void Clear() { length = 0; }

    // 按位查找：获取第 i 个元素（位序从 1 开始）
    bool GetElem(int i, T& e) const {
        if (i < 1 || i > length) return false;
        e = data[i - 1];
        return true;
    }

    // 按值查找：返回第一个等于 e 的元素的位序（从 1 开始），0 表示未找到
    int LocateElem(const T& e) const {
        for (int i = 0; i < length; i++) {
            if (data[i] == e)
                return i + 1;
        }
        return 0;
    }

    // 获取前驱：返回 cur_e 的前驱
    bool PriorElem(const T& cur_e, T& pre_e) const {
        int loc = LocateElem(cur_e);
        if (loc <= 1) return false;  // 不存在或是第一个元素
        return GetElem(loc - 1, pre_e);
    }

    // 获取后继：返回 cur_e 的后继
    bool NextElem(const T& cur_e, T& next_e) const {
        int loc = LocateElem(cur_e);
        if (loc == 0 || loc >= length) return false;
        return GetElem(loc + 1, next_e);
    }

    // 插入：在第 i 个位置插入元素 e，O(n)
    bool ListInsert(int i, const T& e) {
        if (i < 1 || i > length + 1) return false;
        // 容量检查，必要时扩容
        if (length >= maxSize)
            resize(maxSize * 2);

        // 从最后开始后移元素
        for (int j = length - 1; j >= i - 1; j--)
            data[j + 1] = data[j];

        data[i - 1] = e;
        length++;
        return true;
    }

    // 删除：删除第 i 个元素，将其值存入 e 返回，O(n)
    bool ListDelete(int i, T& e) {
        if (i < 1 || i > length) return false;

        e = data[i - 1];

        // 从第 i 个开始前移元素
        for (int j = i; j < length; j++)
            data[j - 1] = data[j];

        length--;
        return true;
    }

    // 遍历：对每个元素调用函数 visit
    template <typename Func>
    void Traverse(Func visit) const {
        for (int i = 0; i < length; i++)
            visit(data[i]);
    }

    // 打印所有元素
    void Print() const {
        cout << "[";
        for (int i = 0; i < length; i++) {
            cout << data[i];
            if (i < length - 1) cout << ", ";
        }
        cout << "]" << endl;
    }

    // 访问指定位置的元素（重载 [] 运算符）
    T& operator[](int index) {
        if (index < 0 || index >= length)
            throw out_of_range("Index out of range");
        return data[index];
    }

    const T& operator[](int index) const {
        if (index < 0 || index >= length)
            throw out_of_range("Index out of range");
        return data[index];
    }
};

// ==================== 测试代码 ====================

int main() {
    cout << "========== 顺序表测试 ==========" << endl;

    // 创建顺序表
    SqList<int> L(5);
    cout << "表是否为空: " << (L.Empty() ? "是" : "否") << endl;

    // 插入元素
    cout << "\n--- 插入元素 ---" << endl;
    L.ListInsert(1, 10);
    L.ListInsert(2, 20);
    L.ListInsert(3, 30);
    L.ListInsert(2, 15);  // 在位置 2 插入 15
    cout << "插入后表: "; L.Print();
    cout << "表长: " << L.GetLength() << endl;

    // 查找
    cout << "\n--- 查找 ---" << endl;
    int val;
    L.GetElem(2, val);
    cout << "第 2 个元素: " << val << endl;
    cout << "元素 30 的位置: " << L.LocateElem(30) << endl;

    // 前驱后继
    int pre, next;
    L.PriorElem(20, pre);
```

### 2.4.2 Python 类实现

```python
from typing import Any, Callable, Optional

class SqList:
    """顺序表（动态数组实现）"""

    def __init__(self, capacity: int = 16):
        """初始化空顺序表，O(1)"""
        self._data: list = [None] * capacity
        self._length: int = 0
        self._capacity: int = capacity

    def __len__(self) -> int:
        """返回表长，O(1)"""
        return self._length

    def __str__(self) -> str:
        """字符串表示"""
        items = [str(self._data[i]) for i in range(self._length)]
        return f"[{', '.join(items)}]"

    def __repr__(self) -> str:
        return f"SqList({self})"

    def __getitem__(self, index: int) -> Any:
        """支持 L[index] 访问（0-based 下标），O(1)"""
        if index < 0:
            index += self._length
        if index < 0 or index >= self._length:
            raise IndexError(f"下标 {index} 越界，有效范围 0~{self._length - 1}")
        return self._data[index]

    def __setitem__(self, index: int, value: Any) -> None:
        """支持 L[index] = value 赋值（0-based 下标），O(1)"""
        if index < 0:
            index += self._length
        if index < 0 or index >= self._length:
            raise IndexError(f"下标 {index} 越界，有效范围 0~{self._length - 1}")
        self._data[index] = value

    def __iter__(self):
        """支持 for x in L 迭代"""
        for i in range(self._length):
            yield self._data[i]

    # ========== 容量管理 ==========

    def _resize(self, new_capacity: int) -> None:
        """动态扩容/缩容，O(n)"""
        new_data = [None] * new_capacity
        for i in range(self._length):
            new_data[i] = self._data[i]
        self._data = new_data
        self._capacity = new_capacity

    @property
    def capacity(self) -> int:
        """返回当前容量"""
        return self._capacity

    @property
    def length(self) -> int:
        """返回表长"""
        return self._length

    # ========== 基本操作 ==========

    def empty(self) -> bool:
        """判断顺序表是否为空，O(1)"""
        return self._length == 0

    def clear(self) -> None:
        """清空顺序表，O(1)"""
        self._length = 0

    def get_elem(self, i: int) -> Any:
        """按位查找：获取第 i 个元素（位序从 1 开始），O(1)"""

        if i < 1 or i > self._length:
            raise IndexError(f"位序 {i} 越界，有效范围 1~{self._length}")
        return self._data[i - 1]

    def locate_elem(self, e: Any) -> int:
        """按值查找：返回第一个等于 e 的元素的位序（从 1 开始），未找到返回 0，O(n)"""
        for i in range(self._length):
            if self._data[i] == e:
                return i + 1
        return 0

    def prior_elem(self, cur_e: Any) -> Optional[Any]:
        """获取 cur_e 的前驱元素，O(n)"""
        loc = self.locate_elem(cur_e)
        if loc <= 1:
            return None
        return self._data[loc - 2]

    def next_elem(self, cur_e: Any) -> Optional[Any]:
        """获取 cur_e 的后继元素，O(n)"""
        loc = self.locate_elem(cur_e)
        if loc == 0 or loc >= self._length:
            return None
        return self._data[loc]

    def list_insert(self, i: int, e: Any) -> bool:
        """在第 i 个位置插入元素 e（位序从 1 开始），O(n)"""

        if i < 1 or i > self._length + 1:
            return False

        # 容量不足时扩容为 2 倍
        if self._length >= self._capacity:
            self._resize(self._capacity * 2)

        # 第 i 个及之后的元素后移
        for j in range(self._length - 1, i - 2, -1):
            self._data[j + 1] = self._data[j]

        self._data[i - 1] = e
        self._length += 1
        return True

    def list_delete(self, i: int) -> Any:
        """删除第 i 个元素（位序从 1 开始），返回被删元素的值，O(n)"""
        if i < 1 or i > self._length:
            raise IndexError(
                f"位序 {i} 越界，有效范围 1~{self._length}")

        e = self._data[i - 1]

        # 第 i+1 个及之后的元素前移
        for j in range(i, self._length):
            self._data[j - 1] = self._data[j]

        self._length -= 1
        return e

    def append(self, e: Any) -> None:
        """在表尾添加元素，均摊 O(1)"""
        self.list_insert(self._length + 1, e)

    def pop(self) -> Any:
        """删除最后一个元素并返回，O(1)"""
        if self._length == 0:
            raise IndexError("空表不可删除")
        e = self._data[self._length - 1]
        self._length -= 1
        return e

    def traverse(self, visit: Callable[[Any], None]) -> None:
        """遍历：对每个元素调用 visit 函数"""
        for i in range(self._length):
            visit(self._data[i])

    # ========== 高级操作 ==========

    def reverse(self) -> None:
        """原地反转，O(n)"""
        left, right = 0, self._length - 1
        while left < right:
            self._data[left], self._data[right] = \
                self._data[right], self._data[left]
            left += 1
            right -= 1

    def index_of(self, e: Any, start: int = 1) -> int:
        """从位序 start 开始查找元素 e，返回位序（从 1 开始），未找到返回 0"""
        if start < 1:
            start = 1
        for i in range(start - 1, self._length):
            if self._data[i] == e:
                return i + 1
        return 0

    @classmethod
    def merge_sorted(cls, la: 'SqList', lb: 'SqList') -> 'SqList':
        """合并两个有序顺序表，返回新的有序顺序表，O(m + n)"""
        lc = cls(la.length + lb.length)
        i = j = 0
        while i < la.length and j < lb.length:
            if la[i] <= lb[j]:
                lc.list_insert(lc.length + 1, la[i])
                i += 1
            else:
                lc.list_insert(lc.length + 1, lb[j])
                j += 1
        while i < la.length:
            lc.list_insert(lc.length + 1, la[i])
            i += 1
        while j < lb.length:
            lc.list_insert(lc.length + 1, lb[j])
            j += 1
        return lc
```

### 2.5.1 一元多项式的表示与运算

**数据结构设计**：
用一个顺序表存储多项式，每个元素存储一个非零项（系数 + 指数），按指数降序排列。

$$P_n(x) = p_0 x^{e_0} + p_1 x^{e_1} + \cdots + p_m x^{e_m}$$

**C++ 实现**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 多项式的一项
struct Term {
    double coef;  // 系数
    int exp;      // 指数

    Term(double c = 0, int e = 0) : coef(c), exp(e) {}
    bool operator<(const Term& other) const { return exp > other.exp; }
    bool operator==(const Term& other) const { return exp == other.exp; }
};

class Polynomial {
private:
    vector<Term> terms;  // 顺序表存储多项式项

    // 合并同类项并排序
    void normalize() {
        if (terms.empty()) return;
        sort(terms.begin(), terms.end());

        vector<Term> merged;
        for (const auto& t : terms) {
            if (!merged.empty() && merged.back().exp == t.exp)
                merged.back().coef += t.coef;
            else if (t.coef != 0)  // 去掉系数为 0 的项
                merged.push_back(t);
        }
        // 再次过滤系数为 0 的项
        vector<Term> final_terms;
        for (const auto& t : merged) {
            if (t.coef != 0.0) final_terms.push_back(t);
        }
        terms = final_terms;
    }

public:
    Polynomial() {}
    Polynomial(const vector<Term>& t) : terms(t) { normalize(); }

    // 加法
    Polynomial add(const Polynomial& other) const {
        vector<Term> result = terms;
        result.insert(result.end(), other.terms.begin(), other.terms.end());
        return Polynomial(result);
    }

    // 乘法
    Polynomial mul(const Polynomial& other) const {
        vector<Term> result;
        for (const auto& t1 : terms)
            for (const auto& t2 : other.terms)
                result.push_back(Term(t1.coef * t2.coef, t1.exp + t2.exp));
        return Polynomial(result);
    }

    // 多项式求值（霍纳法则）
    double evaluate(double x) const {
        // 利用霍纳法则：a0 + x(a1 + x(a2 + ...))
        double result = 0;
        for (const auto& t : terms)
            result += t.coef * pow(x, t.exp);
        return result;
    }

    void print() const {
        if (terms.empty()) { cout << "0" << endl; return; }
        for (size_t i = 0; i < terms.size(); i++) {
            if (i > 0 && terms[i].coef > 0) cout << "+ ";
            cout << terms[i].coef << "x^" << terms[i].exp << " ";
        }
        cout << endl;
    }
};

int main() {
    // P1 = 3x^3 + x + 1
    Polynomial p1({Term(3, 3), Term(1, 1), Term(1, 0)});
    // P2 = 2x^3 - x^2 + 4
    Polynomial p2({Term(2, 3), Term(-1, 2), Term(4, 0)});

    cout << "P1 = "; p1.print();
    cout << "P2 = "; p2.print();

    Polynomial sum = p1.add(p2);
    cout << "P1 + P2 = "; sum.print();

    Polynomial product = p1.mul(p2);
    cout << "P1 × P2 = "; product.print();

    cout << "P1(2) = " << p1.evaluate(2) << endl;

    return 0;
}
```

## 总结

| 知识点 | 要点 |
|-------|------|
| **线性表定义** | 零个或多个元素的有限序列，一对一关系 |
| **顺序表** | 连续地址空间存储，支持随机存取 $O(1)$ |
| **按位查找** | 时间复杂度 $O(1)$，无需移动元素 |
| **按值查找** | 时间复杂度 $O(n)$，平均比较 $\frac{n+1}{2}$ 次 |
| **插入** | 需移动 $n - i + 1$ 个元素，平均移动 $\frac{n}{2}$ 次，$O(n)$ |
| **删除** | 需移动 $n - i$ 个元素，平均移动 $\frac{n-1}{2}$ 次，$O(n)$ |
| **有序归并** | 时间复杂度 $O(m + n)$，双指针法 |
| **优点** | 随机存取快，存储密度高，实现简单 |
| **缺点** | 插入/删除慢，空间固定或需提前分配 |
