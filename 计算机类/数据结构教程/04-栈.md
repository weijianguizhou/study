# 栈

栈（Stack）是限定仅在表的一端进行插入和删除运算的线性表。栈是程序设计与算法实现中最重要的基础数据结构之一。本章将从定义到 ADT、从顺序实现到链式实现、从基础操作到经典应用，全面阐述栈的方方面面。

## 栈的定义与基本概念

### 定义

**栈**是限制在表的一端进行插入和删除运算的线性表。允许进行插入和删除操作的一端称为**栈顶**（_Top_），另一端称为**栈底**（_Bottom_）。当表中没有任何元素时，称为**空栈**（_Empty Stack_）。

栈的修改遵循**后进先出**（Last In First Out，简称 **LIFO**）或**先进后出**（First In Last Out，简称 **FILO**）的原则。这意味着在任何时刻，只有栈顶元素可以被访问或删除，而新元素只能从栈顶插入。

若栈 $S = (a_1, a_2, \dots, a_n)$，则 $a_1$ 为栈底元素，$a_n$ 为栈顶元素。退栈（Pop）的第一个元素必然是栈顶元素 $a_n$。

### 栈与线性表的关系

栈是一种**特殊的线性表**——它从线性表继承了一对一的逻辑关系，但对操作做了限定：

| 对比维度 | 线性表 | 栈 |
| -------- | ------ | ----- |
| 插入位置 | 任意位置 | 仅栈顶 |
| 删除位置 | 任意位置 | 仅栈顶 |
| 访问方式 | 按位置随机访问 | 仅访问栈顶 |
| 操作特性 | 无特殊限制 | LIFO 后进先出 |

### 生活中的栈

- **餐盘取放**：叠放的盘子，只能从最上面取走，也只能放到最上面。
- **浏览器的后退按钮**：访问历史按照后进先出的顺序回溯。
- **撤销操作（Undo）**：编辑器的撤销功能正是利用栈记录每一步操作。
- **函数调用**：程序语言层面的函数调用也通过调用栈（Call Stack）来管理。

## 栈的抽象数据类型（ADT）定义

栈的 ADT 包含数据对象、数据关系和基本操作三个部分。

### 数据对象

$$
D = \{ a_i \mid a_i \in \text{ElemSet},\; i = 1, 2, \dots, n,\; n \ge 0 \}
$$

### 数据关系

$$
R_1 = \{ \langle a_{i-1}, a_i \rangle \mid a_{i-1}, a_i \in D,\; i = 2, \dots, n \}
$$

其中约定 $a_n$ 端为栈顶，$a_1$ 端为栈底。

### 基本操作表

| 操作 | 原型 | 功能描述 |
| ---- | ---- | -------- |
| 初始化 | `InitStack(&S)` | 构造一个空栈 $S$ |
| 销毁 | `DestroyStack(&S)` | 销毁已存在的栈 $S$，释放内存 |
| 判空 | `StackEmpty(S)` | 若 $S$ 为空栈返回 `true`，否则返回 `false` |
| 清空 | `ClearStack(&S)` | 将 $S$ 清为空栈 |
| 求长度 | `StackLength(S)` | 返回 $S$ 中元素个数 |
| 取栈顶 | `GetTop(S, &e)` | 用 $e$ 返回栈顶元素（$S$ 非空） |
| 入栈 | `Push(&S, e)` | 将元素 $e$ 插入为新的栈顶元素 |
| 出栈 | `Pop(&S, &e)` | 删除栈顶元素，并用 $e$ 返回其值 |
| 遍历 | `StackTraverse(S, visit())` | 从栈底到栈顶依次访问每个元素 |

> **时间复杂度**：上述所有基本操作（除遍历外）均可在 $O(1)$ 时间内完成——这正是栈作为高效数据结构的核心优势。

## 顺序栈（Sequential Stack）

### 存储结构

顺序栈使用**一组地址连续的存储单元**（数组）存放栈中的数据元素。需要额外维护一个整型变量 `top`（栈顶指针），指示栈顶元素在数组中的位置。

- **栈底**固定不变，通常对应数组下标 `0` 或 `-1`。
- **栈顶**随入栈/出栈操作动态变化。

```
  ┌───┬───┬───┬───┬───┬───┐
  │ a1│ a2│ a3│   │   │   │  ← 数组 data[maxSize]
  └───┴───┴───┴───┴───┴───┘
    ↑           ↑
  栈底        top=3（指向当前栈顶 a3 的位置）
```

### 判空与判满

- **判空**：`top == -1`（栈顶指针指向 $-1$ 表示无任何元素）
- **判满**：`top == maxSize - 1`（栈顶指针到达数组末尾）

### 入栈操作 Push

```
步骤：
1. 检查是否栈满，若满则报错（上溢）或扩容
2. top++（栈顶指针上移）
3. data[top] = e（将新元素存入栈顶位置）
```

### 出栈操作 Pop

```
步骤：
1. 检查是否栈空，若空则报错（下溢）
2. e = data[top]（取出栈顶元素）
3. top--（栈顶指针下移）
```

### C++ 模板类完整实现

```cpp
#include <iostream>
#include <stdexcept>

template <typename T>
class SeqStack {
private:
    T* data;       // 存储元素的数组
    int top;       // 栈顶指针
    int capacity;  // 栈的最大容量

public:
    // 构造函数：分配空间
    explicit SeqStack(int maxSize = 100) 
        : top(-1), capacity(maxSize) {
        data = new T[capacity];
    }

    // 析构函数：释放空间
    ~SeqStack() {
        delete[] data;
    }

    // 拷贝构造函数
    SeqStack(const SeqStack& other)
        : top(other.top), capacity(other.capacity) {
        data = new T[capacity];
        for (int i = 0; i <= top; ++i) {
            data[i] = other.data[i];
        }
    }

    // 赋值运算符
    SeqStack& operator=(const SeqStack& other) {
        if (this != &other) {
            delete[] data;
            capacity = other.capacity;
            top = other.top;
            data = new T[capacity];
            for (int i = 0; i <= top; ++i) {
                data[i] = other.data[i];
            }
        }
        return *this;
    }

    // 判空
    bool empty() const {
        return top == -1;
    }

    // 判满
    bool full() const {
        return top == capacity - 1;
    }

    // 返回栈长度
    int size() const {
        return top + 1;
    }

    // 返回栈容量
    int maxSize() const {
        return capacity;
    }

    // 取栈顶元素
    T getTop() const {
        if (empty()) {
            throw std::runtime_error("Stack is empty!");
        }
        return data[top];
    }

    // 入栈
    void push(const T& e) {
        if (full()) {
            throw std::runtime_error("Stack overflow!");
        }
        data[++top] = e;  // top 先加 1，再赋值
    }

    // 出栈
    T pop() {
        if (empty()) {
            throw std::runtime_error("Stack underflow!");
        }
        return data[top--];  // 先返回栈顶元素，top 再减 1
    }

    // 清空栈
    void clear() {
        top = -1;
    }

    // 从栈底到栈顶遍历
    void traverse(void (*visit)(const T&)) const {
        for (int i = 0; i <= top; ++i) {
            visit(data[i]);
        }
    }

    // 打印栈（调试用）
    void print() const {
        if (empty()) {
            std::cout << "[Empty Stack]" << std::endl;
            return;
        }
        std::cout << "Stack (bottom -> top): ";
        for (int i = 0; i <= top; ++i) {
            std::cout << data[i] << " ";
        }
        std::cout << std::endl;
    }
};

// 使用示例

//     SeqStack<int> s(10);
//     for (int i = 1; i <= 5; ++i) s.push(i);
//     s.print();  // 1 2 3 4 5
//     std::cout << s.pop() << std::endl;  // 5
//     std::cout << s.getTop() << std::endl;  // 4
//     std::cout << s.size() << std::endl;  // 4
//     return 0;
// }
```

### Python 完整实现

```python
from typing import TypeVar, Generic, List, Optional

T = TypeVar('T')

class SeqStack(Generic[T]):
    """顺序栈 —— 基于列表（动态数组）实现"""

    def __init__(self, max_size: int = 100):
        """构造空栈，可指定最大容量"""
        self._data: List[Optional[T]] = [None] * max_size
        self._top: int = -1
        self._capacity: int = max_size

    def __len__(self) -> int:
        """返回栈长度"""
        return self._top + 1

    def __bool__(self) -> bool:
        """非空返回 True"""
        return not self.empty()

    def __str__(self) -> str:
        if self.empty():
            return "SeqStack([])"
        items = [str(self._data[i]) for i in range(self._top + 1)]
        return f"SeqStack([{', '.join(items)}])"

    def __repr__(self) -> str:
        return self.__str__()

    @property
    def capacity(self) -> int:
        """返回栈容量"""
        return self._capacity

    def empty(self) -> bool:
        """判空"""
        return self._top == -1

    def full(self) -> bool:
        """判满"""
        return self._top == self._capacity - 1

    def size(self) -> int:
        """返回栈长度"""
        return self._top + 1

    def get_top(self) -> T:
        """返回栈顶元素"""
        if self.empty():
            raise IndexError("Stack is empty!")
        return self._data[self._top]  # type: ignore

    def push(self, e: T) -> None:
        """入栈：将元素 e 压入栈顶"""
        if self.full():
            raise OverflowError("Stack overflow!")
        self._top += 1
        self._data[self._top] = e

    def pop(self) -> T:
        """出栈：删除并返回栈顶元素"""
        if self.empty():
            raise IndexError("Stack underflow!")
        result = self._data[self._top]
        self._data[self._top] = None  # 帮助垃圾回收
        self._top -= 1
        return result  # type: ignore

    def clear(self) -> None:
        """清空栈"""
        for i in range(self._top + 1):
            self._data[i] = None
        self._top = -1

    def traverse(self, visit) -> None:
        """从栈底到栈顶遍历"""
        for i in range(self._top + 1):
            visit(self._data[i])


# ===== 使用示例 =====
if __name__ == "__main__":
    s = SeqStack[int](10)
    for i in range(1, 6):
        s.push(i)
    print(s)              # SeqStack([1, 2, 3, 4, 5])
    print(s.pop())        # 5
    print(s.get_top())    # 4
    print(s.size())       # 4
    print(s.empty())      # False
```

| 操作 | 时间复杂度 | 空间复杂度 |
| ---- | ---------- | ---------- |
| `push()` | $O(1)$ | — |
| `pop()` | $O(1)$ | — |

| `empty()` / `full()` | $O(1)$ | — |
| `traverse()` | $O(n)$ | — |

## 共享栈（两栈共享空间）

共享栈是一种利用**同一个数组空间**存放两个栈的数据结构。两个栈的栈底分别位于数组的两端，栈顶向中间生长。

### 设计思想

```
  ┌───┬───┬───┬───┬───┬───┬───┬───┐
  │ a1│ a2│ a3│   │   │ b3│ b2│ b1│
  └───┴───┴───┴───┴───┴───┴───┴───┘
    ↑               ↑   ↑           ↑
  S1栈底        S1.top  S2.top    S2栈底
  (top1=-1)                       (top2=maxSize)
```

- **栈S1**：`top1 = -1`（空），栈底在数组低端，向高端生长。
- **栈S2**：`top2 = maxSize`（空），栈底在数组高端，向低端生长。
- **共享条件**：当 `top1 + 1 == top2` 时，整个共享空间被填满。

### C++ 实现

```cpp
#include <iostream>
#include <stdexcept>

template <typename T>
class SharedStack {
private:
    T* data;
    int top1;      // 栈S1的栈顶指针
    int top2;      // 栈S2的栈顶指针
    int capacity;

public:
    explicit SharedStack(int maxSize = 100)
        : top1(-1), top2(maxSize), capacity(maxSize) {
        data = new T[capacity];
    }

    ~SharedStack() {
        delete[] data;
    }

    bool empty(int stackNo) const {
        if (stackNo == 1) return top1 == -1;
        if (stackNo == 2) return top2 == capacity;
        throw std::invalid_argument("Invalid stack number!");
    }

    bool full() const {
        return top1 + 1 == top2;
    }

    int size(int stackNo) const {
        if (stackNo == 1) return top1 + 1;
        if (stackNo == 2) return capacity - top2;
        throw std::invalid_argument("Invalid stack number!");
    }

    T getTop(int stackNo) const {
        if (stackNo == 1) {
            if (top1 == -1) throw std::runtime_error("Stack 1 is empty!");
            return data[top1];
        }
        if (stackNo == 2) {
            if (top2 == capacity) throw std::runtime_error("Stack 2 is empty!");
            return data[top2];
        }
        throw std::invalid_argument("Invalid stack number!");
    }

    void push(int stackNo, const T& e) {
        if (full()) throw std::runtime_error("Shared stack overflow!");
        if (stackNo == 1) {
            data[++top1] = e;
        } else if (stackNo == 2) {
            data[--top2] = e;
        } else {
            throw std::invalid_argument("Invalid stack number!");
        }
    }

    T pop(int stackNo) {
        if (stackNo == 1) {
            if (top1 == -1) throw std::runtime_error("Stack 1 underflow!");
            return data[top1--];
        }
        if (stackNo == 2) {
            if (top2 == capacity) throw std::runtime_error("Stack 2 underflow!");
            return data[top2++];
        }
        throw std::invalid_argument("Invalid stack number!");
    }

    void print() const {
        std::cout << "=== SharedStack ===" << std::endl;
        std::cout << "Stack1 (size=" << size(1) << "): ";
        for (int i = 0; i <= top1; ++i) std::cout << data[i] << " ";
        std::cout << std::endl;
        std::cout << "Stack2 (size=" << size(2) << "): ";
        for (int i = capacity - 1; i >= top2; --i) std::cout << data[i] << " ";
        std::cout << std::endl;
        std::cout << "Free space: " 
                  << (top2 - top1 - 1) << "/" << capacity << std::endl;
    }
};
```

### Python 实现

```python
from typing import TypeVar, Generic, Optional, List

T = TypeVar('T')

class SharedStack(Generic[T]):
    """两栈共享空间"""

    def __init__(self, max_size: int = 100):
        self._data: List[Optional[T]] = [None] * max_size
        self._top1: int = -1        # 栈S1的栈顶指针
        self._top2: int = max_size  # 栈S2的栈顶指针
        self._capacity: int = max_size

    def empty(self, stack_no: int) -> bool:
        """判空"""
        if stack_no == 1:
            return self._top1 == -1
        if stack_no == 2:
            return self._top2 == self._capacity
        raise ValueError("Invalid stack number!")

    def full(self) -> bool:
        """共享空间是否已满"""
        return self._top1 + 1 == self._top2

    def size(self, stack_no: int) -> int:
        """返回指定栈长度"""
        if stack_no == 1:
            return self._top1 + 1
        if stack_no == 2:
            return self._capacity - self._top2
        raise ValueError("Invalid stack number!")

    def get_top(self, stack_no: int) -> T:
        """取栈顶元素"""
        if stack_no == 1:
            if self._top1 == -1:
                raise IndexError("Stack 1 is empty!")
            return self._data[self._top1]  # type: ignore
        if stack_no == 2:
            if self._top2 == self._capacity:
                raise IndexError("Stack 2 is empty!")
            return self._data[self._top2]  # type: ignore
        raise ValueError("Invalid stack number!")

    def push(self, stack_no: int, e: T) -> None:
        """入栈"""
        if self.full():
            raise OverflowError("Shared stack overflow!")
        if stack_no == 1:
            self._top1 += 1
            self._data[self._top1] = e
        elif stack_no == 2:
            self._top2 -= 1
            self._data[self._top2] = e
        else:
            raise ValueError("Invalid stack number!")

    def pop(self, stack_no: int) -> T:
        """出栈"""
        if stack_no == 1:
            if self._top1 == -1:
                raise IndexError("Stack 1 underflow!")
            result = self._data[self._top1]
            self._data[self._top1] = None
            self._top1 -= 1
            return result  # type: ignore
        if stack_no == 2:
            if self._top2 == self._capacity:
                raise IndexError("Stack 2 underflow!")
            result = self._data[self._top2]
            self._data[self._top2] = None
            self._top2 += 1
            return result  # type: ignore
        raise ValueError("Invalid stack number!")

    def __str__(self) -> str:
        s1_size = self.size(1)
        s2_size = self.size(2)
        free = self._top2 - self._top1 - 1
        items1 = [str(self._data[i]) for i in range(s1_size)]
        items2 = [str(self._data[self._capacity - 1 - i]) 
                  for i in range(s2_size)]
        return (f"SharedStack(S1[{', '.join(items1)}], "
                f"S2[{', '.join(items2)}], free={free}/{self._capacity})")
```

## 链栈（Linked Stack）

### 存储结构

链栈采用**链式存储结构**实现，栈顶指针就是链表的头指针（即 `top` 指向链表第一个结点）。插入和删除操作均限制在链头位置进行。

```
  top
   │
   ▼
  ┌───┐    ┌───┐    ┌───┐
  │a_n│───→│a_n│───→│a_1│───→ nullptr
  └───┘    └───┘    └───┘
  栈顶               栈底
```

**为什么栈顶在链头？**

- 单链表的头插和头删操作均为 $O(1)$。
- 若将栈顶设在链尾，出栈时需要找到前驱结点，时间复杂度为 $O(n)$。
- 因此栈顶设在链头是自然的、高效的。

### 链栈的优势

1. **无栈满问题**：只要内存足够，链栈就可以无限扩展。
2. **无需预分配空间**：不像顺序栈需要事先指定最大容量。
3. **灵活的存储管理**：每个元素独立分配结点空间。

### C++ 完整实现

```cpp
#include <iostream>
#include <stdexcept>

template <typename T>
struct StackNode {
    T data;
    StackNode<T>* next;
    
    StackNode(const T& val) : data(val), next(nullptr) {}
    StackNode(const T& val, StackNode<T>* nxt) : data(val), next(nxt) {}
};

template <typename T>
class LinkedStack {
private:
    StackNode<T>* top;  // 栈顶指针（链头）
    int count;          // 当前元素个数

public:
    // 构造函数
    LinkedStack() : top(nullptr), count(0) {}

    // 析构函数
    ~LinkedStack() {
        clear();
    }

    // 拷贝构造函数
    LinkedStack(const LinkedStack& other) : top(nullptr), count(0) {
        // 递归/辅助复制：从 other 的链头开始逐结点复制
        if (other.top == nullptr) return;
        
        // 先复制第一个结点
        top = new StackNode<T>(other.top->data);
        count = 1;
        
        StackNode<T>* src = other.top->next;
        StackNode<T>* dst = top;
        while (src != nullptr) {
            dst->next = new StackNode<T>(src->data);
            dst = dst->next;
            src = src->next;
            ++count;
        }
    }

    // 赋值运算符
    LinkedStack& operator=(const LinkedStack& other) {
        if (this != &other) {
            clear();
            if (other.top == nullptr) return *this;
            
            top = new StackNode<T>(other.top->data);
            count = 1;
            
            StackNode<T>* src = other.top->next;
            StackNode<T>* dst = top;
            while (src != nullptr) {
                dst->next = new StackNode<T>(src->data);
                dst = dst->next;
                src = src->next;
                ++count;
            }
        }
        return *this;
    }

    // 移动构造函数
    LinkedStack(LinkedStack&& other) noexcept
        : top(other.top), count(other.count) {
        other.top = nullptr;
        other.count = 0;
    }

    // 移动赋值运算符
    LinkedStack& operator=(LinkedStack&& other) noexcept {
        if (this != &other) {
            clear();
            top = other.top;
            count = other.count;
            other.top = nullptr;
            other.count = 0;
        }
        return *this;
    }

    // 判空
    bool empty() const {
        return top == nullptr;
    }

    // 返回栈长度
    int size() const {
        return count;
    }

    // 取栈顶元素
    T getTop() const {
        if (empty()) {
            throw std::runtime_error("Stack is empty!");
        }
        return top->data;
    }

    // 入栈（头插法）
    void push(const T& e) {
        StackNode<T>* newNode = new StackNode<T>(e, top);
        top = newNode;
        ++count;
    }

    // 出栈（头删法）
    T pop() {
        if (empty()) {
            throw std::runtime_error("Stack underflow!");
        }
        StackNode<T>* temp = top;
        T data = top->data;
        top = top->next;
        delete temp;
        --count;
        return data;
    }

    // 清空栈
    void clear() {
        while (top != nullptr) {
            StackNode<T>* temp = top;
            top = top->next;
            delete temp;
        }
        count = 0;
    }

    // 遍历（从栈顶到栈底）
    void traverse(void (*visit)(const T&)) const {
        StackNode<T>* p = top;
        while (p != nullptr) {
            visit(p->data);
            p = p->next;
        }
    }

    // 打印（调试用）
    void print() const {
        if (empty()) {
            std::cout << "[Empty Stack]" << std::endl;
            return;
        }
        std::cout << "LinkedStack (top -> bottom): ";
        StackNode<T>* p = top;
        while (p != nullptr) {
            std::cout << p->data;
            p = p->next;
            if (p) std::cout << " -> ";
        }
        std::cout << std::endl;
    }
};
```

### Python 完整实现

```python
from __future__ import annotations
from typing import TypeVar, Generic, Optional, Callable, Any

T = TypeVar('T')

class StackNode(Generic[T]):
    """链栈结点"""
    
    __slots__ = ('data', 'next')
    
    def __init__(self, data: T, nxt: Optional[StackNode[T]] = None):
        self.data: T = data
        self.next: Optional[StackNode[T]] = nxt

    def __repr__(self) -> str:
        return f"StackNode({self.data!r})"


class LinkedStack(Generic[T]):
    """链栈 —— 基于单链表实现"""

    def __init__(self):
        """构造空链栈"""
        self._top: Optional[StackNode[T]] = None
        self._count: int = 0

    def __len__(self) -> int:
        return self._count

    def __bool__(self) -> bool:
        return not self.empty()

    def __str__(self) -> str:
        if self.empty():
            return "LinkedStack([])"
        items: list[str] = []
        p = self._top
        while p is not None:
            items.append(str(p.data))
            p = p.next
        return f"LinkedStack([{', '.join(items)}])"

    def __repr__(self) -> str:
        return self.__str__()

    def __iter__(self):
        p = self._top
        while p is not None:
            yield p.data
            p = p.next

    def empty(self) -> bool:
        """判空"""
        return self._top is None

    def size(self) -> int:
        """返回栈长度"""
        return self._count

    def get_top(self) -> T:
        """返回栈顶元素（不删除）"""
        if self.empty():
            raise IndexError("Stack is empty!")
        return self._top.data

    def push(self, e: T) -> None:
        """入栈（头插法）"""
        new_node = StackNode(e, self._top)
        self._top = new_node
        self._count += 1

    def pop(self) -> T:
        """出栈（头删法）"""
        if self.empty():
            raise IndexError("Stack underflow!")
        result = self._top.data
        self._top = self._top.next
        self._count -= 1
        return result

    def clear(self) -> None:
        """清空链栈"""
        self._top = None
        self._count = 0

    def traverse(self, visit: Callable[[T], None]) -> None:
        """从栈顶到栈底遍历"""
        p = self._top
        while p is not None:
            visit(p.data)
            p = p.next


# ===== 使用示例 =====
if __name__ == "__main__":
    ls = LinkedStack[int]()
    for i in range(1, 6):
        ls.push(i)
    print(ls)             # LinkedStack([5, 4, 3, 2, 1])
    print(ls.pop())       # 5
    print(ls.get_top())   # 4
    print(len(ls))        # 4
```

### 顺序栈与链栈对比

| 对比维度 | 顺序栈 | 链栈 |
| -------- | ------ | ---- |
| 存储方式 | 数组，连续空间 | 链表，离散空间 |
| 最大容量 | 有上限（需预分配） | 仅受内存限制 |
| 空间利用率 | 预分配可能浪费 | 每个元素有指针开销 |
| 入栈/出栈 | $O(1)$ | $O(1)$ |
| 栈满问题 | 存在上溢 | 仅当内存耗尽 |
| 缓存友好性 | 好（连续内存） | 差（结点分散） |
| 实现复杂度 | 简单 | 稍复杂 |

### 一、数制转换

#### 问题描述

将非负十进制整数 $N$ 转换为 $d$（$2 \le d \le 36$）进制数。

#### 算法原理

利用公式 $N = (N \div d) \times d + N \bmod d$ 连续求余数，直至商为 $0$。由于先求出的余数应排在低位，后求出的余数应排在高位，利用栈的 LIFO 特性恰好可以实现逆序输出。

#### 步骤

1. 当 $N > 0$ 时：
   - 将 $N \bmod d$ 压入栈
   - $N = N \div d$
2. 依次弹栈输出，得到转换后的 $d$ 进制数。

#### 示例：$(1348)_{10}$ 转八进制

```
1348 ÷ 8 = 168 余 4  →  push 4
168  ÷ 8 = 21  余 0  →  push 0
21   ÷ 8 = 2   余 5  →  push 5
2    ÷ 8 = 0   余 2  →  push 2

弹栈输出：2 5 0 4
结果：(1348)_10 = (2504)_8
```

#### C++ 实现

```cpp
#include <iostream>

    if (N == 0) return "0";

        s.push(digits[N % d]);
        N /= d;
    }
    
    std::string result;
    while (!s.empty()) {
        result += s.top();
        s.pop();
    }
    return result;
}
```

### 二、括号匹配检验

#### 问题描述

给定一个包含不同括号的字符串（`()`、`[]`、`{}`），检验括号是否正确配对与嵌套。

#### 算法思想

利用栈的 LIFO 特性：

1. 遍历字符串每个字符：
   - 遇到**左括号**（`(`、`[`、`{`），则**入栈**。
   - 遇到**右括号**（`)`、`]`、`}`），则：
     - 若栈为空，匹配失败（右括号多余）。
     - 若栈顶元素与当前右括号匹配，则**出栈**。
     - 否则匹配失败（括号类型不匹配）。
2. 遍历结束后：
   - 若栈为空，匹配成功。
   - 若栈非空，匹配失败（左括号多余）。

#### C++ 实现

```cpp
#include <iostream>
#include <string>
#include <stack>

bool isValidBrackets(const std::string& s) {
    std::stack<char> st;
    
    for (char ch : s) {
        // 左括号入栈
        if (ch == '(' || ch == '[' || ch == '{') {
            st.push(ch);
        }
        // 右括号匹配
        else if (ch == ')' || ch == ']' || ch == '}') {
            if (st.empty()) return false;  // 右括号多余
            
            char top = st.top();
            if ((ch == ')' && top == '(') ||
                (ch == ']' && top == '[') ||
                (ch == '}' && top == '{')) {
                st.pop();
            } else {
                return false;  // 类型不匹配
            }
        }
    }
    return st.empty();  // 栈空则匹配成功
}

//     std::cout << std::boolalpha;
//     std::cout << isValidBrackets("()") << std::endl;       // true
//     std::cout << isValidBrackets("()[]{}") << std::endl;   // true
//     std::cout << isValidBrackets("([)]") << std::endl;     // false
//     std::cout << isValidBrackets("{[]}") << std::endl;     // true
//     std::cout << isValidBrackets("(") << std::endl;        // false
//     std::cout << isValidBrackets("]") << std::endl;        // false
```

```python
def is_valid_brackets(s: str) -> bool:
    """检验括号是否正确匹配"""
    stack: list[str] = []
    pairs = {')': '(', ']': '[', '}': '{'}
    
    for ch in s:
        if ch in '([{':         # 左括号入栈
            stack.append(ch)
        elif ch in ')]}':       # 右括号匹配
            if not stack:
                return False
            if stack[-1] != pairs[ch]:
                return False    # 类型不匹配
            stack.pop()
    
    return not stack            # 栈空则匹配成功
```

### 三、行编辑程序

#### 问题描述

模拟一个简单的行编辑器：用户在终端输入的字符序列被接收，通过以下两个控制字符进行编辑：

- `#`（退格符）：删除前一个有效字符。
- `@`（退行符）：清除当前行所有有效字符（退行符本身不计入）。

#### 算法设计

利用栈作为输入缓冲区：

1. 读取字符序列，逐字符处理。
2. 普通字符直接入栈。
3. 遇到 `#`：若栈非空，将栈顶元素出栈。
4. 遇到 `@`：清空整个栈。
5. 处理完成后，栈中剩余字符即为最终的有效行内容。

#### C++ 实现

```cpp
#include <iostream>
#include <string>
#include <stack>
#include <algorithm>

std::string lineEdit(const std::string& input) {
    std::stack<char> s;
    
    for (char ch : input) {
        if (ch == '#') {
            if (!s.empty()) s.pop();
        } else if (ch == '@') {
            while (!s.empty()) s.pop();
        } else {
            s.push(ch);
        }
    }
    
    // 从栈中恢复字符串（需要反转）
    std::string result;
    while (!s.empty()) {
        result.push_back(s.top());
        s.pop();
    }
    std::reverse(result.begin(), result.end());
    return result;
}

// int main() {
//     std::cout << lineEdit("Hello# World!") << std::endl;    // Hell World!
//     // 输入:  "Hello# World!"  → '#'删除'o' → "Hell World!"
//    
//     std::cout << lineEdit("First Line@Second") << std::endl; // Second
//     // 输入:  "First Line@Second" → '@'清空 → "Second"
//    
//     std::cout << lineEdit("ab##c") << std::endl;             // c
//     // 输入: a→push, b→push, #→pop(b), #→pop(a), c→push → "c"
//

// }
```

#### Python 实现

```python
def line_edit(input_str: str) -> str:
    """
    模拟行编辑程序
    
    - '#'  : 删除前一个有效字符（退格符）
    - '@'  : 清空当前行所有字符（退行符）
    """
    stack: list[str] = []
    
    for ch in input_str:
        if ch == '#':
            if stack:
                stack.pop()
        elif ch == '@':
            stack.clear()
        else:
            stack.append(ch)
    
    return ''.join(stack)
```

### 四、表达式求值

表达式求值是栈最经典的编译原理应用，涉及三种表达式形式：

| 表达式形式 | 举例 | 说明 |
| ---------- | ---- | ---- |
| 中缀表达式（Infix） | `(3 + 4) × 5 - 6` | 运算符在两个操作数之间 |
| 前缀表达式（Prefix / 波兰式） | `- × + 3 4 5 6` | 运算符在两个操作数之前 |
| 后缀表达式（Postfix / 逆波兰式） | `3 4 + 5 × 6 -` | 运算符在两个操作数之后 |

计算机对后缀表达式的求值非常简洁（无需括号和优先级判断），因此编译器通常先做**中缀→后缀**转换，再求值。

---

#### 4.1 后缀表达式求值

##### 算法

1. 从左到右扫描后缀表达式。
2. 遇到**操作数**（数字）时，将其压入栈。
3. 遇到**运算符**时，从栈中弹出两个操作数：
   - 先弹出的是右操作数（`operand2`）
   - 后弹出的是左操作数（`operand1`）
   - 执行运算：`operand1 op operand2`，将结果压回栈。
4. 表达式扫描完毕，栈顶即为最终结果。

##### C++ 实现

```cpp
#include <iostream>
#include <string>
#include <stack>
#include <sstream>
#include <cctype>

double evaluatePostfix(const std::string& postfix) {
    std::stack<double> s;
    std::istringstream iss(postfix);
    std::string token;
    
    while (iss >> token) {
        // 如果是数字
        if (isdigit(token[0]) || 
            (token.size() > 1 && token[0] == '-')) {
            s.push(std::stod(token));
        }
        // 如果是运算符
        else {
            double b = s.top(); s.pop();  // 右操作数
            double a = s.top(); s.pop();  // 左操作数
            double result = 0;
            
            switch (token[0]) {
                case '+': result = a + b; break;
                case '-': result = a - b; break;
                case '*': result = a * b; break;
                case '/': 
                    if (b == 0) throw std::runtime_error("Division by zero!");
                    result = a / b; 
                    break;
                default:
                    throw std::runtime_error("Unknown operator: " + token);
            }
            s.push(result);
        }
    }
    
    if (s.empty()) throw std::runtime_error("Invalid expression!");
    return s.top();
}

// int main() {
//     std::cout << evaluatePostfix("3 4 + 5 * 6 -") << std::endl;  // 29
//     std::cout << evaluatePostfix("10 2 3 + *") << std::endl;      // 50
//     std::cout << evaluatePostfix("2 3 4 * +") << std::endl;      // 14
//     return 0;
// }
```

##### Python 实现

```python
import operator
from typing import Union

def evaluate_postfix(postfix: str) -> float:
    """后缀表达式求值"""
    stack: list[float] = []
    
    ops = {
        '+': operator.add,
        '-': operator.sub,
        '*': operator.mul,
        '/': operator.truediv,
    }
    
    for token in postfix.split():
        # 尝试作为数字解析
        try:
            stack.append(float(token))
        except ValueError:
            # 是运算符
            b = stack.pop()  # 右操作数
            a = stack.pop()  # 左操作数
            if token == '/' and b == 0:
                raise ZeroDivisionError("Division by zero!")
            stack.append(ops[token](a, b))
    
    return stack[0] if stack else 0.0


# ===== 测试 =====

    print(evaluate_postfix("3 4 + 5 * 6 -"))   # 29.0
    print(evaluate_postfix("10 2 3 + *"))       # 50.0
    print(evaluate_postfix("2 3 4 * +"))        # 14.0
```

#### 4.2 中缀表达式转后缀表达式（逆波兰式）

##### 算法步骤

转换过程中，操作数直接输出，运算符用栈管理。

| 优先级 | 运算符 |
| ------ | ------ |
| 0 | `)` |
| 1 | `(` |
| 2 | `+` `-` |
| 3 | `*` `/` |
| 4 | `^`（指数） |

**算法规则**：

1. 从左到右扫描中缀表达式，读入一个符号 `ch`：
2. 若 `ch` 是**操作数**（字母或数字），直接输出（追加到后缀表达式）。
3. 若 `ch` 是**左括号** `(`，将其入栈。
4. 若 `ch` 是**右括号** `)`，不断弹出栈顶运算符并输出，直到弹出左括号 `(` 为止（左括号不输出，只弹出）。
5. 若 `ch` 是**运算符**：
   - 若栈空或栈顶为 `(`，直接将 `ch` 入栈。
   - 否则，若 `ch` 的优先级**大于**栈顶运算符的优先级，将 `ch` 入栈。
   - 否则，不断弹出栈顶优先级**大于或等于** `ch` 优先级的运算符并输出，然后将 `ch` 入栈。
6. 表达式扫描完毕，将栈中剩余运算符全部弹出并输出。

##### C++ 实现

```cpp
#include <iostream>
#include <string>
#include <stack>
#include <cctype>

// 返回运算符优先级
int precedence(char op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    if (op == '^') return 3;
    return 0;  // '(' 的最低优先级
}

// 判断是否为运算符
bool isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || 
           ch == '/' || ch == '^';
}

std::string infixToPostfix(const std::string& infix) {
    std::stack<char> s;
    std::string postfix;
    
    for (size_t i = 0; i < infix.length(); ++i) {
        char ch = infix[i];
        
        // 跳过空格
        if (ch == ' ') continue;
        
        // 操作数：直接输出
        if (isalnum(ch) || ch == '.') {
            // 处理多位数/多字母操作数
            while (i < infix.length() && 
                   (isalnum(infix[i]) || infix[i] == '.')) {
                postfix += infix[i++];
            }
            postfix += ' ';
            --i;  // 抵消 for 循环的 ++i
        }
        // 左括号入栈
        else if (ch == '(') {
            s.push(ch);
        }
        // 右括号：弹出直到左括号
        else if (ch == ')') {
            while (!s.empty() && s.top() != '(') {
                postfix += s.top();
                postfix += ' ';
                s.pop();
            }
            if (!s.empty()) s.pop();  // 弹出 '('
        }
        // 运算符
        else if (isOperator(ch)) {
            while (!s.empty() && s.top() != '(' &&
                   precedence(s.top()) >= precedence(ch)) {
                postfix += s.top();
                postfix += ' ';
                s.pop();
            }
            s.push(ch);
        }
    }
    
    // 弹出剩余运算符
    while (!s.empty()) {
        postfix += s.top();
        postfix += ' ';
        s.pop();
    }
    
    return postfix;
}

// int main() {
//     std::cout << infixToPostfix("3+4*5-6") << std::endl;    // 3 4 5 * + 6 -
//     std::cout << infixToPostfix("(3+4)*5-6") << std::endl;  // 3 4 + 5 * 6 -
//     std::cout << infixToPostfix("a+b*(c-d)") << std::endl;  // a b c d - * +
```

##### Python 实现

```python
def infix_to_postfix(infix: str) -> str:
    """中缀表达式转后缀表达式"""
    precedence = {'+': 1, '-': 1, '*': 2, '/': 2, '^': 3}
    
    stack: list[str] = []
    postfix: list[str] = []
    i = 0
    
    while i < len(infix):
        ch = infix[i]
        
        if ch.isspace():
            i += 1
            continue
        
        if ch.isalnum() or ch == '.':  # 操作数
            j = i
            while j < len(infix) and (infix[j].isalnum() or infix[j] == '.'):
                j += 1
            postfix.append(infix[i:j])
            i = j
            continue
        
        elif ch == '(':
            stack.append(ch)
        
        elif ch == ')':
            while stack and stack[-1] != '(':
                postfix.append(stack.pop())
            if stack:
                stack.pop()  # 弹出 '('
            else:
                raise ValueError("Mismatched parentheses!")
        
        elif ch in precedence:  # 运算符
            while (stack and stack[-1] != '(' and
                   precedence.get(stack[-1], 0) >= precedence[ch]):
                postfix.append(stack.pop())
            stack.append(ch)
        
        else:
            raise ValueError(f"Unknown character: {ch}")
        
        i += 1
    
    # 弹出剩余运算符
    while stack:
        if stack[-1] == '(':
            raise ValueError("Mismatched parentheses!")
        postfix.append(stack.pop())
    
    return ' '.join(postfix)


# ===== 测试 =====

    print(infix_to_postfix("3+4*5-6"))        # 3 4 5 * + 6 -
    print(infix_to_postfix("(3+4)*5-6"))      # 3 4 + 5 * 6 -
    print(infix_to_postfix("a+b*(c-d)"))      # a b c d - * +
    print(infix_to_postfix("(1+2)*(3+4)"))    # 1 2 + 3 4 + *
```

#### 4.3 中缀表达式直接求值

使用**双栈法**：一个操作数栈，一个运算符栈。

##### 算法

1. 初始化操作数栈 `numStack` 和运算符栈 `opStack`。
2. 从左到右扫描中缀表达式：
   - **操作数**（数字）：直接存入 `numStack`。
   - **左括号** `(`：直接存入 `opStack`。
   - **右括号** `)`：反复从 `opStack` 弹出运算符并从 `numStack` 弹出两个操作数进行运算，直到弹出左括号为止。
   - **运算符** `op`：
     - 若 `opStack` 为空或栈顶为 `(`，将 `op` 入栈。
     - 若 `op` 优先级 > 栈顶优先级，将 `op` 入栈。
     - 否则，反复从 `opStack` 弹出运算符并与 `numStack` 中两个操作数运算，直到 `op` 可以入栈为止。
3. 表达式扫描完毕，反复弹出 `opStack` 中运算符进行计算，直到栈空。
4. `numStack` 栈顶即为最终结果。

##### C++ 实现

```cpp
#include <iostream>
#include <string>
#include <stack>
#include <cctype>
#include <cmath>

class ExpressionEvaluator {
private:
    std::stack<char> opStack;
    std::stack<double> numStack;

    int precedence(char op) {
        if (op == '+' || op == '-') return 1;
        if (op == '*' || op == '/') return 2;
        if (op == '^') return 3;
        return 0;
    }

    void applyOp(char op) {
        if (numStack.size() < 2) 
            throw std::runtime_error("Invalid expression!");
        double b = numStack.top(); numStack.pop();
        double a = numStack.top(); numStack.pop();
        switch (op) {
            case '+': numStack.push(a + b); break;
            case '-': numStack.push(a - b); break;
            case '*': numStack.push(a * b); break;
            case '/': 
                if (b == 0) throw std::runtime_error("Division by zero!");
                numStack.push(a / b); break;
            case '^': numStack.push(pow(a, b)); break;
        }
    }

public:
    double evaluate(const std::string& expr) {
        while (!opStack.empty()) opStack.pop();
        while (!numStack.empty()) numStack.pop();

        for (size_t i = 0; i < expr.length(); ++i) {
            char ch = expr[i];

            if (isspace(ch)) continue;

            if (isdigit(ch) || ch == '.') {
                // 读取完整数字
                std::string numStr;
                while (i < expr.length() && 
                       (isdigit(expr[i]) || expr[i] == '.')) {
                    numStr += expr[i++];
                }
                numStack.push(std::stod(numStr));
                --i;
            }
            else if (ch == '(') {
                opStack.push(ch);
            }
            else if (ch == ')') {
                while (!opStack.empty() && opStack.top() != '(') {
                    applyOp(opStack.top());
                    opStack.pop();
                }
                if (!opStack.empty()) opStack.pop();  // 弹出 '('
            }
            else if (ch == '+' || ch == '-' || 
                     ch == '*' || ch == '/' || ch == '^') {
                while (!opStack.empty() && opStack.top() != '(' &&
                       precedence(opStack.top()) >= precedence(ch)) {
                    applyOp(opStack.top());
                    opStack.pop();
                }
                opStack.push(ch);
            }
        }

        // 处理剩余运算符
        while (!opStack.empty()) {
            applyOp(opStack.top());
            opStack.pop();
        }

        if (numStack.empty()) throw std::runtime_error("Invalid expression!");
        return numStack.top();
    }
};

//     std::cout << eval.evaluate("10 * (2 + 3)") << std::endl;     // 50
//     std::cout << eval.evaluate("2 ^ 3 + 1") << std::endl;        // 9
//     return 0;
// }
```

##### Python 实现

```python
from __future__ import annotations
from typing import List, Union

class ExpressionEvaluator:
    """中缀表达式直接求值（使用双栈法）"""

    def __init__(self):
        self._num_stack: List[float] = []
        self._op_stack: List[str] = []

    @staticmethod
    def _precedence(op: str) -> int:
        """返回运算符优先级"""
        if op in '+-':
            return 1
        if op in '*/':
            return 2
        if op == '^':
            return 3
        return 0

    def _apply_op(self) -> None:
        """弹出运算符栈顶运算符，并应用到操作数栈顶两个数上"""
        if len(self._num_stack) < 2:
            raise ValueError("Invalid expression!")
        
        op = self._op_stack.pop()
        b = self._num_stack.pop()
        a = self._num_stack.pop()
        
        if op == '+':
            self._num_stack.append(a + b)
        elif op == '-':
            self._num_stack.append(a - b)
        elif op == '*':
            self._num_stack.append(a * b)
        elif op == '/':
            if b == 0:
                raise ZeroDivisionError("Division by zero!")
            self._num_stack.append(a / b)
        elif op == '^':
            self._num_stack.append(a ** b)

    def evaluate(self, expr: str) -> float:
        """对中缀表达式求值"""
        self._num_stack.clear()
        self._op_stack.clear()
        
        i = 0
        while i < len(expr):
            ch = expr[i]
            
            if ch.isspace():
                i += 1
                continue
            
            if ch.isdigit() or ch == '.':  # 读取完整数字
                j = i
                while j < len(expr) and (expr[j].isdigit() or expr[j] == '.'):
                    j += 1
                self._num_stack.append(float(expr[i:j]))
                i = j
                continue
            
            elif ch == '(':
                self._op_stack.append(ch)
            
            elif ch == ')':
                while self._op_stack and self._op_stack[-1] != '(':
                    self._apply_op()
                if self._op_stack and self._op_stack[-1] == '(':
                    self._op_stack.pop()  # 弹出 '('
                else:
                    raise ValueError("Mismatched parentheses!")
            
            elif ch in '+-*/^':
                while (self._op_stack and 
                       self._op_stack[-1] != '(' and
                       self._precedence(self._op_stack[-1]) >= self._precedence(ch)):
                    self._apply_op()
                self._op_stack.append(ch)
            
            i += 1
        
        # 处理剩余运算符
        while self._op_stack:
            if self._op_stack[-1] == '(':
                raise ValueError("Mismatched parentheses!")
            self._apply_op()
        
        if len(self._num_stack) != 1:
            raise ValueError("Invalid expression!")
        
        return self._num_stack[0]


# ===== 测试 =====

    evaluator = ExpressionEvaluator()
    print(evaluator.evaluate("3 + 4 * 5 - 6"))     # 17.0
    print(evaluator.evaluate("(3 + 4) * 5 - 6"))   # 29.0
    print(evaluator.evaluate("10 * (2 + 3)"))      # 50.0
    print(evaluator.evaluate("2 ^ 3 + 1"))         # 9.0
    print(evaluator.evaluate("1 + 2 * 3 - 4 / 2")) # 5.0
```

### 五、迷宫求解（回溯法）

#### 问题描述

给定一个 $m \times n$ 的二维迷宫，`0` 表示可通路径，`1` 表示墙壁。从起点 $(startX, startY)$ 走到终点 $(endX, endY)$，找出可行路径。

#### 算法思想（DFS 回溯 + 栈）

1. 将起点入栈。
2. 循环，直到栈空或找到终点：
   - 取栈顶位置作为当前位置，标记为已访问。
   - 按上、右、下、左的顺序探索相邻位置：
     - 若相邻位置是终点，路径找到。
     - 若相邻位置可通且未访问，则将其入栈，继续下一轮。
   - 若四个方向均不可通，栈顶位置出栈（回溯）。
3. 栈空表示无可行路径。

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <stack>
#include <utility>

using namespace std;

// 方向数组：上、右、下、左
const int dx[] = {-1, 0, 1, 0};
const int dy[] = {0, 1, 0, -1};

struct Position {
    int x, y;
    Position(int x = 0, int y = 0) : x(x), y(y) {}
};

bool mazeSolver(const vector<vector<int>>& maze,
                int startX, int startY,
                int endX, int endY,
                vector<Position>& path) {
    int m = maze.size();
    int n = maze[0].size();
    
    // 访问标记矩阵
    vector<vector<bool>> visited(m, vector<bool>(n, false));
    
    stack<Position> s;
    s.push(Position(startX, startY));
    visited[startX][startY] = true;
    
    while (!s.empty()) {
        Position cur = s.top();
        
        // 到达终点
        if (cur.x == endX && cur.y == endY) {
            // 将栈中路径复制到 path（栈底到栈顶）
            stack<Position> temp;
            while (!s.empty()) {
                temp.push(s.top());
                s.pop();
            }
            while (!temp.empty()) {
                path.push_back(temp.top());
                temp.pop();
            }
            return true;
        }
        
        // 试探四个方向
        bool found = false;
        for (int dir = 0; dir < 4; ++dir) {
            int nx = cur.x + dx[dir];
            int ny = cur.y + dy[dir];
            
            if (nx >= 0 && nx < m && ny >= 0 && ny < n &&
                maze[nx][ny] == 0 && !visited[nx][ny]) {
                s.push(Position(nx, ny));
                visited[nx][ny] = true;
                found = true;
                break;  // 找到一条通路即前进
            }
        }
        
        // 四个方向都不可通，回溯
        if (!found) {
            s.pop();
        }
    }
    
    return false;  // 无解
}
```

```python
from __future__ import annotations
from typing import List, Tuple, Optional

# 方向：上、右、下、左
DIRECTIONS: List[Tuple[int, int]] = [(-1, 0), (0, 1), (1, 0), (0, -1)]


def maze_solver(maze: List[List[int]],
                start: Tuple[int, int],
                end: Tuple[int, int]) -> Optional[List[Tuple[int, int]]]:
    """
    迷宫求解（回溯法 + 栈实现）
    
    maze: 二维迷宫，0=通路，1=墙壁
    start: 起点坐标 (x, y)
    end:   终点坐标 (x, y)
    返回：路径列表（包含起点和终点），若无解则返回 None
    """
    m, n = len(maze), len(maze[0])
    visited: List[List[bool]] = [[False] * n for _ in range(m)]
    
    stack: List[Tuple[int, int]] = [start]
    visited[start[0]][start[1]] = True
    
    while stack:
        x, y = stack[-1]  # 取栈顶
        
        # 到达终点
        if (x, y) == end:
            return list(stack)
        
        # 试探四个方向
        found = False
        for dx, dy in DIRECTIONS:
            nx, ny = x + dx, y + dy
            if (0 <= nx < m and 0 <= ny < n and
                maze[nx][ny] == 0 and not visited[nx][ny]):
                stack.append((nx, ny))
                visited[nx][ny] = True
                found = True
                break
        
        # 四个方向均不可通，回溯
        if not found:
            stack.pop()
    
    return None


def print_maze_path(maze: List[List[int]], 
                    path: List[Tuple[int, int]]) -> None:
    """可视化迷宫路径"""
    m, n = len(maze), len(maze[0])
    grid = [['#' if cell == 1 else ' ' for cell in row] for row in maze]
    
    for i, (x, y) in enumerate(path):
        if i == 0:
            grid[x][y] = 'S'  # 起点
        elif i == len(path) - 1:
            grid[x][y] = 'E'  # 终点
        else:
            grid[x][y] = '.'
    
    print('+' + '-' * (n * 2 + 1) + '+')
    for row in grid:
        print('| ' + ' '.join(row) + ' |')
    print('+' + '-' * (n * 2 + 1) + '+')
```

### 六、递归与栈

#### 函数调用栈

每当我们调用一个函数，计算机都会在内存的"调用栈（Call Stack）"上压入一个**栈帧（Stack Frame）**，包含：

- 函数的返回地址
- 局部变量
- 参数值

当函数返回时，对应的栈帧被弹出，控制权交还给调用者。这完美诠释了 LIFO 特性：最后被调用的函数最先返回。

```
int funcC() { return 3; }
int funcB() { return funcC() + 2; }  
int funcA() { return funcB() + 1; }
int main() { return funcA(); }

调用栈变化：
main() → main(),funcA() → main(),funcA(),funcB() → main(),funcA(),funcB(),funcC()
→ main(),funcA(),funcB() → main(),funcA() → main()
```

#### 尾递归与优化

**尾递归**是指递归调用发生在函数体最后一条语句的递归形式。编译器（如支持尾递归优化的语言）可以将尾递归转化为循环，从而避免栈溢出并节省空间。

```cpp
// 普通递归：每次调用都需要保留当前函数的栈帧
int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);  // 乘法在递归调用之后，不是尾递归
}

// 尾递归形式
int factorialTail(int n, int acc = 1) {
    if (n <= 1) return acc;
    return factorialTail(n - 1, n * acc);  // 递归调用是最后一步
}
```

```python
# 普通递归（非尾递归）
def factorial(n: int) -> int:
    if n <= 1:
        return 1
    return n * factorial(n - 1)  # 乘法在递归调用之后

# 尾递归形式（Python 不优化尾递归，但写法仍可减少某些开销）
def factorial_tail(n: int, acc: int = 1) -> int:
    if n <= 1:
        return acc
    return factorial_tail(n - 1, n * acc)
```

#### 递归转非递归

任何递归算法都可以转换为非递归（迭代）形式。递归转非递归的标准策略是使用显式栈模拟调用栈。

**示例：递归版树的先序遍历 → 非递归版**

```cpp
// 递归版先序遍历
void preorderRecursive(TreeNode* root) {
    if (root == nullptr) return;
    visit(root);
    preorderRecursive(root->left);
    preorderRecursive(root->right);
}

// 非递归版（用栈模拟）
void preorderIterative(TreeNode* root) {
    if (root == nullptr) return;
    std::stack<TreeNode*> s;
    s.push(root);
    
    while (!s.empty()) {
        TreeNode* node = s.top(); s.pop();
        visit(node);
        // 先压右再压左，保证左子树先访问
        if (node->right) s.push(node->right);
        if (node->left)  s.push(node->left);
    }
}
```

```python
from __future__ import annotations
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

# 递归版先序遍历
def preorder_recursive(root: Optional[TreeNode]) -> List[int]:
    result: List[int] = []
    def dfs(node: Optional[TreeNode]) -> None:
        if node is None:
            return
        result.append(node.val)
        dfs(node.left)
        dfs(node.right)
    dfs(root)
    return result

# 非递归版（用栈模拟）
def preorder_iterative(root: Optional[TreeNode]) -> List[int]:
    if root is None:
        return []
    
    result: List[int] = []
    stack: List[TreeNode] = [root]
    
    while stack:
        node = stack.pop()
        result.append(node.val)
        # 先压右再压左，保证左子树先出栈
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    
    return result
```

### 七、深度优先搜索（DFS）的非递归实现

深度优先搜索（Depth First Search）天然可以用栈来实现。递归版 DFS 隐式使用调用栈，而非递归版则显式管理一个辅助栈。

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <stack>

// 图的邻接表 DFS 非递归实现
void dfsIterative(const std::vector<std::vector<int>>& graph, int start) {
    int n = graph.size();
    std::vector<bool> visited(n, false);
    std::stack<int> s;
    
    s.push(start);
    visited[start] = true;
    
    while (!s.empty()) {
        int v = s.top(); s.pop();
        std::cout << v << " ";  // 访问当前顶点
        
        // 遍历所有邻接顶点
        for (int neighbor : graph[v]) {
            if (!visited[neighbor]) {
                s.push(neighbor);
                visited[neighbor] = true;
            }
        }
    }
    std::cout << std::endl;
}
```

```python
from typing import List

def dfs_iterative(graph: List[List[int]], start: int) -> List[int]:
    """
    图的深度优先搜索（非递归，使用显式栈）
    
    graph: 邻接表表示
    start: 起始顶点编号
    返回: DFS 遍历序列
    """
    n = len(graph)
    visited = [False] * n
    result: List[int] = []
    stack: List[int] = [start]
    visited[start] = True
    
    while stack:
        v = stack.pop()
        result.append(v)
        
        # 逆序遍历邻接点以保证与递归版相同的遍历顺序
        for neighbor in reversed(graph[v]):
            if not visited[neighbor]:
                visited[neighbor] = True
                stack.append(neighbor)
    
    return result

        result.append(v)
        for neighbor in graph[v]:
            if not visited[neighbor]:
                dfs(neighbor)
    
    dfs(start)
    return result


# ===== 测试 =====
if __name__ == "__main__":
    graph = [
        [1, 2],     # 0
        [0, 3, 4],  # 1
        [0, 5, 6],  # 2
        [1],        # 3
        [1],        # 4
        [2],        # 5
        [2],        # 6
    ]
    
    print("Iterative DFS:", dfs_iterative(graph, 0))  # [0, 2, 6, 5, 1, 4, 3]
    print("Recursive DFS:", dfs_recursive(graph, 0))  # [0, 1, 3, 4, 2, 5, 6]
```

## 总结

本章从栈的[[03-线性表|线性表]]本质出发，系统阐述了：

| 主题 | 核心要点 |
| ---- | -------- |
| **定义** | 栈是限定仅在表的一端（栈顶）进行插入和删除的线性表，遵循 LIFO 原则 |
| **ADT** | 包含 `InitStack`、`Push`、`Pop`、`GetTop` 等基本操作，均为 $O(1)$ 复杂度 |
| **顺序栈** | 基于数组实现，top 指针管理，可能发生上溢；共享栈可提高空间利用率 |
| **链栈** | 基于单链表实现，栈顶在链头，无上溢限制，但有指针开销 |
| **数制转换** | 利用栈逆序输出余数 |
| **括号匹配** | 左括号入栈，右括号与栈顶匹配后出栈 |
| **行编辑** | 用栈刻画退格符和退行符的行为 |
| **表达式求值** | 中缀转后缀（运算符栈）+ 后缀求值（操作数栈），或双栈法直接求值 |
| **迷宫求解** | DFS 回溯 + 栈：前进时入栈，死路时出栈 |
| **递归** | 递归的本质是隐式使用调用栈；尾递归可优化为迭代；任意递归可通过显式栈转为非递归 |
| **非递归 DFS** | 图/树的深度优先搜索用显式栈替代递归 |

栈虽结构简单，但其应用遍布算法、编译原理、操作系统、人工智能等各个领域。深刻理解栈的 LIFO 本质，是掌握后续[[05-队列|队列]]、[[06-数组与广义表|数组]]乃至[[07-树和二叉树|树]]和[[08-图|图]]的遍历算法的重要基础。
