## 7.1 树的定义和基本术语

### 7.1.1 树的递归定义

树 (Tree) 是由 $n(n \ge 0)$ 个结点组成的**有限集合**：

1. 若 $n = 0$，称为**空树**。
2. 若 $n > 0$，则：
   - 有一个特定的结点被称为**根 (Root)**，它只有直接后继，没有直接前驱。
   - 除根以外的其余结点可被划分为 $m(m \ge 0)$ 个**互不相交**的有限集合 $T_1, T_2, \dots, T_m$，其中每一个集合本身又是一棵树，称为根的**子树 (Subtree)**。

树的定义是**递归**的：在定义树时用到了"子树"这一概念，子树本身也是树。这种递归性质使得很多树的算法天然适合用递归实现。

```
         A           ← 根结点（层次 1）
       / | \
      B  C  D        ← 层次 2
     / \    |
    E   F   G        ← 层次 3
       / \
      H   I          ← 层次 4
```

### 7.1.2 基本术语

| 术语 | 说明 |
|---|---|
| **结点 (Node)** | 数据元素加上若干指向子树的分支。 |
| **结点的度 (Degree)** | 结点拥有的子树（分支）的个数。 |
| **树的度** | 树中所有结点的度的**最大值**。 |
| **叶子结点 / 终端结点** | 度为 0 的结点。上图中 E、H、I、G、D 为叶子。 |
| **分支结点 / 非终端结点** | 度大于 0 的结点。 |
| **双亲 / 孩子 (Parent / Child)** | 直接前驱为双亲，直接后继为孩子。B 是 A 的孩子，A 是 B 的双亲。 |
| **兄弟 (Sibling)** | 具有相同双亲的结点。B、C、D 互为兄弟。 |
| **堂兄弟** | 双亲是兄弟的结点。E 和 G 是堂兄弟。 |
| **祖先 / 子孙** | 从根到某结点路径上的所有结点叫该结点的祖先；以某结点为根的子树中的所有结点叫该结点的子孙。 |
| **路径 / 路径长度** | 从根到该结点所经分支和结点构成路径，路径上的**分支数目**为路径长度。 |
| **结点的层次 (Level)** | 根结点层次为 1；若某结点在第 $l$ 层，则其子树的根在第 $l+1$ 层。 |
| **树的深度 / 高度** | 树中叶子结点所在的最大层次。上图深度为 4。 |

### 7.1.3 树的分类

- **有序树 (Ordered Tree)**：子树之间存在确定的次序关系（从左到右有顺序）。
- **无序树 (Unordered Tree)**：子树之间不考虑次序。
- **森林 (Forest)**：$m(m \ge 0)$ 棵**互不相交**的树的集合。删去一棵树的根，就得到一片森林；给森林加上一个根结点，就得到一棵树。

## 7.2 二叉树的定义与性质

### 7.2.1 二叉树的递归定义

二叉树是由 $n(n \ge 0)$ 个结点的有限集合构成的，这个集合：
- 或者为**空集**（$n=0$，空二叉树）；
- 或者由一个**根结点**以及两棵**互不相交**的、分别称为**左子树**和**右子树**的二叉树组成。

**关键区别**：二叉树不是树的特例，二叉树严格区分左子树和右子树。即使只有一棵子树，也须区分它是左子树还是右子树。两棵不同的二叉树如下：

```
     A        A
    /    vs    \
   B            B
  (只有左子树)   (只有右子树)
```

这两种情况在二叉树中被视为**不同的二叉树**，但在普通树的定义中是同一棵树。

### 7.2.2 满二叉树与完全二叉树

**满二叉树 (Full Binary Tree)**：深度为 $k$ 且含有 $2^k - 1$ 个结点的二叉树。每一层上的结点数都达到最大值。叶子结点都在最底层。

```
         A                   深度 k=3, 结点数=2³-1=7
       /   \                 
      B     C               第1层: 1 个结点
     / \   / \              第2层: 2 个结点
    D   E F   G             第3层: 4 个结点
```

**完全二叉树 (Complete Binary Tree)**：深度为 $k$ 的、有 $n$ 个结点的二叉树，当且仅当其每一个结点都与深度为 $k$ 的满二叉树中编号从 $1$ 至 $n$ 的结点**一一对应**。叶子结点只在层次最大的两层出现；若某个结点无左子树，则一定无右子树。

```
         A                  完全二叉树（n=5）
       /   \                结点与满二叉树编号 1~5 对应
      B     C              （满二叉树结点1~5见上图）
     / \   
    D   E   
```

> **理论基础**：树的数学等价定义、Cayley定理和性质的严格数学证明见 [[../../数理基础/离散数学/07-树|离散数学 - 树]]。本章侧重数据结构实现。

### 7.2.3 二叉树的重要性质

**性质 1**：在二叉树的第 $i$ 层上至多有 $2^{i-1}$ 个结点（$i \ge 1$）。

> **证明（数学归纳法）**：当 $i=1$（第一层），只有一个根结点，$2^{1-1} = 2^0 = 1$，成立。假设对第 $i$ 层成立，即最多有 $2^{i-1}$ 个结点。二叉树的每个结点最多有两个孩子，因此第 $i+1$ 层的结点数最多为第 $i$ 层结点数的两倍，即 $2 \times 2^{i-1} = 2^i$。结论得证。

**性质 2**：深度为 $k$ 的二叉树至多有 $2^k - 1$ 个结点（$k \ge 1$）。

> **证明**：由性质 1，每层结点数的最大值之和为
> $$\sum_{i=1}^{k} 2^{i-1} = 2^0 + 2^1 + \dots + 2^{k-1} = 2^k - 1$$
> 这是等比数列求和：$S_k = \sum_{i=0}^{k-1} 2^i = \frac{2^k - 1}{2 - 1} = 2^k - 1$。

**性质 3**：对任何一棵非空二叉树 $T$，若叶子结点数为 $n_0$，度为 2 的结点数为 $n_2$，则必有

$$n_0 = n_2 + 1$$

> **证明**：设二叉树中度为 1 的结点数为 $n_1$，则总结点数 $n = n_0 + n_1 + n_2$。从分支的角度看，除根结点外，每个结点都有一条边从双亲指向它，所以总边数 $B = n - 1$。另一方面，这些边均由度为 1 和度为 2 的结点产生：度为 1 的结点贡献 1 条边，度为 2 的结点贡献 2 条边，故 $B = n_1 + 2n_2$。于是：
> $$n - 1 = n_1 + 2n_2$$
> 代入 $n = n_0 + n_1 + n_2$：
> $$n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$$
> 化简得 $n_0 = n_2 + 1$。

**性质 4**：具有 $n$ 个结点的完全二叉树的深度为 $\lfloor \log_2 n \rfloor + 1$。

> **证明**：设深度为 $k$，由性质 2 和完全二叉树的定义：
> $$2^{k-1} - 1 < n \le 2^k - 1 \quad \text{或} \quad 2^{k-1} \le n < 2^k$$
> 取对数得 $k - 1 \le \log_2 n < k$，由于 $k$ 是整数，故 $k = \lfloor \log_2 n \rfloor + 1$。

**性质 5**：对一棵有 $n$ 个结点的完全二叉树（深度为 $\lfloor \log_2 n \rfloor + 1$），按层序（自上而下、自左而右）从 $1$ 开始编号，则对于任意编号为 $i$ 的结点：
- 若 $i = 1$，则该结点是根，无双亲；若 $i > 1$，其双亲编号为 $\lfloor i/2 \rfloor$。
- 若 $2i \le n$，则其左孩子编号为 $2i$；否则无左孩子。
- 若 $2i + 1 \le n$，则其右孩子编号为 $2i + 1$；否则无右孩子。

> **证明思路**：利用完全二叉树的"紧凑排列"性质——结点从上到下、从左到右依次排列。设双亲编号为 $i$，其两个孩子中间最多隔一个结点，编号为 $2i$ 和 $2i+1$。

## 7.3 二叉树的存储结构

### 7.3.1 顺序存储结构

适用于**完全二叉树**。将二叉树的结点按层序从上到下、从左到右依次存入一维数组。编号为 $i$ 的结点存储在数组的第 $i$ 个位置（下标可为 $i-1$）。

**索引关系**（0-based 下标，适用于大部分编程语言）：

- 父结点索引为 $i$，则左孩子索引为 $2i+1$，右孩子索引为 $2i+2$。
- 孩子结点索引为 $j$，则父结点索引为 $\lfloor (j-1)/2 \rfloor$。

对于普通二叉树（非完全），用"虚结点"补齐空位，会造成空间浪费（深度为 $k$ 的右斜树需要 $2^k-1$ 个空间）。

```cpp
// C++ 顺序存储二叉树（完全二叉树）
#include <iostream>
#include <vector>
#include <cmath>
using namespace std;

class SeqBinaryTree {
private:
    vector<int> data;
public:
    SeqBinaryTree() {}
    SeqBinaryTree(const vector<int>& arr) : data(arr) {}

    int getLeft(int index) {
        int pos = 2 * index + 1;
        return (pos < data.size()) ? data[pos] : -1;
    }

    int getRight(int index) {
        int pos = 2 * index + 2;
        return (pos < data.size()) ? data[pos] : -1;
    }

    int getParent(int index) {
        if (index == 0) return -1;
        return data[(index - 1) / 2];
    }

    void levelOrder() {
        for (int val : data)
            cout << val << " ";
        cout << endl;
    }
};
```

```python
# Python 顺序存储二叉树（完全二叉树）
class SeqBinaryTree:
    def __init__(self, arr=None):
        self.data = arr if arr else []

    def get_left(self, index):
        pos = 2 * index + 1
        return self.data[pos] if pos < len(self.data) else None

    def get_right(self, index):
        pos = 2 * index + 2
        return self.data[pos] if pos < len(self.data) else None

    def get_parent(self, index):
        if index == 0:
            return None
        return self.data[(index - 1) // 2]

    def level_order(self):
        return self.data
```

### 7.3.2 链式存储结构（二叉链表）

最常用的二叉树存储方式。每个结点包含三个域：

```cpp
struct TreeNode {
    int data;
    TreeNode* lchild;
    TreeNode* rchild;
}
```

- $n$ 个结点的二叉链表中，共有 $2n$ 个指针域，其中 $n-1$ 个指向孩子（因为有 $n-1$ 条边），剩下的 $n+1$ 个为空（`nullptr`/`None`）。这些空指针域正是[[07-树与二叉树#7.6 线索二叉树|线索二叉树]]要利用的空间。

```cpp
// C++ 二叉链表
#include <iostream>
using namespace std;

struct BiTNode {
    int data;
    BiTNode* lchild;
    BiTNode* rchild;

    BiTNode(int val) : data(val), lchild(nullptr), rchild(nullptr) {}
};

class BinaryTree {
public:
    BiTNode* root;
    BinaryTree() : root(nullptr) {}

    // 构建示例树
    static BinaryTree createDemo() {
        BinaryTree bt;
        bt.root = new BiTNode(1);
        bt.root->lchild = new BiTNode(2);
        bt.root->rchild = new BiTNode(3);
        bt.root->lchild->lchild = new BiTNode(4);
        bt.root->lchild->rchild = new BiTNode(5);
        bt.root->rchild->lchild = new BiTNode(6);
        bt.root->rchild->rchild = new BiTNode(7);
        return bt;
    }
};
```

```python
# Python 二叉链表
class BiTNode:
    def __init__(self, val):
        self.data = val
        self.lchild = None
        self.rchild = None


class BinaryTree:
    def __init__(self):
        self.root = None

    @staticmethod
    def create_demo():
        bt = BinaryTree()
        bt.root = BiTNode(1)
        bt.root.lchild = BiTNode(2)
        bt.root.rchild = BiTNode(3)
        bt.root.lchild.lchild = BiTNode(4)
        bt.root.lchild.rchild = BiTNode(5)
        bt.root.rchild.lchild = BiTNode(6)
        bt.root.rchild.rchild = BiTNode(7)
        return bt
```

## 7.4 二叉树的遍历

遍历二叉树是二叉树操作的核心。遍历是指按某种搜索路径**访问**二叉树中的每个结点，使得每个结点都被访问一次且仅访问一次。按访问根结点的先后顺序，有三种基本遍历方式：

- **前序遍历 (Preorder / DLR)**：访问根 → 遍历左子树 → 遍历右子树
- **中序遍历 (Inorder / LDR)**：遍历左子树 → 访问根 → 遍历右子树
- **后序遍历 (Postorder / LRD)**：遍历左子树 → 遍历右子树 → 访问根

> **约定**：D 代表根结点 (Data)，L 代表左子树 (Left)，R 代表右子树 (Right)。

```
示例二叉树：
        1
       / \
      2   3
     / \   \
    4   5   6

前序遍历：1, 2, 4, 5, 3, 6
中序遍历：4, 2, 5, 1, 3, 6
后序遍历：4, 5, 2, 6, 3, 1
```

### 7.4.1 前序遍历

#### 递归实现

```cpp
// C++ 前序遍历（递归）
void preorderRecursive(BiTNode* root) {
    if (root == nullptr) return;
    cout << root->data << " ";     // 访问根结点
    preorderRecursive(root->lchild); // 遍历左子树
    preorderRecursive(root->rchild); // 遍历右子树
}
```

```python
# Python 前序遍历（递归）
def preorder_recursive(root: BiTNode):
    if root is None:
        return
    print(root.data, end=" ")      # 访问根结点
    preorder_recursive(root.lchild) # 遍历左子树
    preorder_recursive(root.rchild) # 遍历右子树
```

#### 非递归实现（用栈）

```cpp
// C++ 前序遍历（非递归）
#include <stack>
void preorderNonRecursive(BiTNode* root) {
    if (root == nullptr) return;
    stack<BiTNode*> stk;
    stk.push(root);
    while (!stk.empty()) {
        BiTNode* node = stk.top();
        stk.pop();
        cout << node->data << " ";
        // 先压右孩子，后压左孩子（确保左孩子先弹栈）
        if (node->rchild != nullptr) stk.push(node->rchild);
        if (node->lchild != nullptr) stk.push(node->lchild);
    }
}
```

```python
# Python 前序遍历（非递归）
def preorder_non_recursive(root: BiTNode):
    if root is None:
        return
    stack = [root]
    while stack:
        node = stack.pop()
        print(node.data, end=" ")
        # 先压右孩子，后压左孩子
        if node.rchild:
            stack.append(node.rchild)
        if node.lchild:
            stack.append(node.lchild)
```

### 7.4.2 中序遍历

#### 递归实现

```cpp
// C++ 中序遍历（递归）

    if (root == nullptr) return;

    cout << root->data << " ";
    inorderRecursive(root->rchild);
}
```

```python
# Python 中序遍历（递归）
def inorder_recursive(root: BiTNode):
    if root is None:
        return
    inorder_recursive(root.lchild)
    print(root.data, end=" ")
    inorder_recursive(root.rchild)
```

#### 非递归实现（用栈）

中序非递归遍历的核心思想：沿着左孩子一路到底，沿途的结点全部入栈；弹出栈顶结点访问，然后转向其右子树。

```cpp
// C++ 中序遍历（非递归）
#include <stack>
void inorderNonRecursive(BiTNode* root) {
    stack<BiTNode*> stk;
    BiTNode* p = root;
    while (p != nullptr || !stk.empty()) {
        // 沿左子树一直向下
        while (p != nullptr) {
            stk.push(p);
            p = p->lchild;
        }
        // 栈顶元素访问
        p = stk.top();
        stk.pop();
        cout << p->data << " ";
        // 转向右子树
        p = p->rchild;
    }
}
```

```python
# Python 中序遍历（非递归）
def inorder_non_recursive(root: BiTNode):
    stack = []
    p = root
    while p or stack:
        # 沿左子树一直向下
        while p:
            stack.append(p)
            p = p.lchild
        # 栈顶元素访问
        p = stack.pop()
        print(p.data, end=" ")
        # 转向右子树
        p = p.rchild
```

### 7.4.3 后序遍历

#### 递归实现

```cpp
// C++ 后序遍历（递归）
void postorderRecursive(BiTNode* root) {
    if (root == nullptr) return;
    postorderRecursive(root->lchild);
    postorderRecursive(root->rchild);
    cout << root->data << " ";
}
```

```python
# Python 后序遍历（递归）
def postorder_recursive(root: BiTNode):
    if root is None:
        return
    postorder_recursive(root.lchild)
    postorder_recursive(root.rchild)
    print(root.data, end=" ")
```

#### 非递归实现（用栈）

后序遍历的非递归实现较复杂，因为要确保左、右子树都访问完毕后才访问根。常用方法是用双栈法或者记录上一次访问的结点。

**方法一：双栈法**

```cpp
// C++ 后序遍历（非递归：双栈法）
#include <stack>
#include <vector>
void postorderNonRecursive(BiTNode* root) {
    if (root == nullptr) return;
    stack<BiTNode*> stk1, stk2;
    stk1.push(root);
    while (!stk1.empty()) {
        BiTNode* node = stk1.top();
        stk1.pop();
        stk2.push(node);
        if (node->lchild != nullptr) stk1.push(node->lchild);
        if (node->rchild != nullptr) stk1.push(node->rchild);
    }
    while (!stk2.empty()) {
        cout << stk2.top()->data << " ";
        stk2.pop();
    }
}
```

**方法二：单栈 + 上次访问记录**

```cpp
// C++ 后序遍历（非递归：单栈法）
void postorderNonRecursive2(BiTNode* root) {
    stack<BiTNode*> stk;
    BiTNode* p = root;
    BiTNode* lastVisited = nullptr;
    while (p != nullptr || !stk.empty()) {
        while (p != nullptr) {
            stk.push(p);
            p = p->lchild;
        }
        p = stk.top();
        if (p->rchild == nullptr || p->rchild == lastVisited) {
            cout << p->data << " ";
            stk.pop();
            lastVisited = p;
            p = nullptr;
        } else {
            p = p->rchild;
        }
    }
}
```

```python
# Python 后序遍历（非递归：双栈法）
def postorder_non_recursive(root: BiTNode):
    if root is None:
        return
    stack1, stack2 = [root], []
    while stack1:
        node = stack1.pop()
        stack2.append(node)
        if node.lchild:
            stack1.append(node.lchild)
        if node.rchild:
            stack1.append(node.rchild)
    while stack2:
        print(stack2.pop().data, end=" ")


# Python 后序遍历（非递归：单栈法）
def postorder_non_recursive2(root: BiTNode):
    stack = []
    p = root
    last_visited = None
    while p or stack:
        while p:
            stack.append(p)
            p = p.lchild
        p = stack[-1]
        if p.rchild is None or p.rchild == last_visited:
            print(p.data, end=" ")
            stack.pop()
            last_visited = p
            p = None
        else:
            p = p.rchild
```

### 7.4.4 层次遍历

使用**队列**逐层访问，从上到下、从左到右。

```cpp
// C++ 层次遍历
#include <queue>
void levelOrder(BiTNode* root) {
    if (root == nullptr) return;
    queue<BiTNode*> q;
    q.push(root);
    while (!q.empty()) {
        BiTNode* node = q.front();
        q.pop();
        cout << node->data << " ";
        if (node->lchild != nullptr) q.push(node->lchild);
        if (node->rchild != nullptr) q.push(node->rchild);
    }
}
```

```python
# Python 层次遍历

def level_order(root: BiTNode):

        return
    queue = deque([root])

        node = queue.popleft()
        print(node.data, end=" ")
        if node.lchild:
            queue.append(node.lchild)
        if node.rchild:
            queue.append(node.rchild)
```

### 7.4.5 遍历的复杂度分析

- **时间复杂度**：$O(n)$。无论哪种遍历方式，每个结点都被访问一次。
- **空间复杂度**：
  - 递归：最坏情况下（单支树）递归栈深度为 $O(n)$，平均为 $O(\log n)$。
  - 非递归：栈/队列的最大空间也是 $O(n)$（最坏情形）。

### 7.4.6 由遍历序列重建二叉树

**唯一确定一棵二叉树**需要同时已知：
- 前序遍历 + 中序遍历；或
- 后序遍历 + 中序遍历。

**仅知前序和后序不能唯一确定**一棵二叉树（左右子树不明确的结点互换会产生歧义）。

#### 前序 + 中序重建

**思路**：前序的第一个元素是根结点；在中序中找到根的位置，左边是左子树的中序序列，右边是右子树的中序序列；根据左子树的长度切分前序序列，递归构建。

```cpp
// C++ 由前序 + 中序重建二叉树
#include <vector>
#include <unordered_map>
using namespace std;

BiTNode* buildFromPreIn(
    const vector<int>& preorder, int preStart, int preEnd,
    const vector<int>& inorder, int inStart, int inEnd,
    unordered_map<int, int>& inorderIndex
) {
    if (preStart > preEnd || inStart > inEnd) return nullptr;

    int rootVal = preorder[preStart];
    BiTNode* root = new BiTNode(rootVal);

    int rootIndex = inorderIndex[rootVal];
    int leftSize = rootIndex - inStart;

    root->lchild = buildFromPreIn(
        preorder, preStart + 1, preStart + leftSize,
        inorder, inStart, rootIndex - 1,
        inorderIndex
    );
    root->rchild = buildFromPreIn(
        preorder, preStart + leftSize + 1, preEnd,
        inorder, rootIndex + 1, inEnd,
        inorderIndex
    );
    return root;
}

BiTNode* buildTreePreIn(const vector<int>& preorder, const vector<int>& inorder) {
    unordered_map<int, int> inorderIndex;
    for (int i = 0; i < inorder.size(); i++)
        inorderIndex[inorder[i]] = i;
    return buildFromPreIn(preorder, 0, preorder.size() - 1,
                          inorder, 0, inorder.size() - 1, inorderIndex);
}
```

```python
# Python 由前序 + 中序重建二叉树
def build_tree_pre_in(preorder: list, inorder: list) -> BiTNode:
    inorder_index = {val: i for i, val in enumerate(inorder)}

    def build(pre_start, pre_end, in_start, in_end):
        if pre_start > pre_end or in_start > in_end:
            return None
        root_val = preorder[pre_start]
        root = BiTNode(root_val)
        root_idx = inorder_index[root_val]
        left_size = root_idx - in_start
        root.lchild = build(pre_start + 1, pre_start + left_size,
                            in_start, root_idx - 1)
        root.rchild = build(pre_start + left_size + 1, pre_end,
                            root_idx + 1, in_end)
        return root

    return build(0, len(preorder) - 1, 0, len(inorder) - 1)
```

## 7.6 线索二叉树 (Threaded Binary Tree)

### 7.6.1 线索化的动机

在具有 $n$ 个结点的二叉链表中，共有 $2n$ 个指针域，其中只有 $n-1$ 个指向孩子，剩余的 $n+1$ 个指针域为空（`nullptr`/`None`）。**线索化**就是利用这些空指针域来存放指向遍历序列中**前驱**和**后继**的指针，从而简化遍历过程，实现对二叉树的线性遍历而无需使用栈。

### 7.6.2 结点结构

增加两个标志域 `LTag` 和 `RTag` 来区分指针域指向的是孩子还是线索：

```cpp
struct ThreadNode {
    int data;
    ThreadNode* lchild;
    ThreadNode* rchild;
    int LTag; // 0: 指向左孩子; 1: 指向前驱
    int RTag; // 0: 指向右孩子; 1: 指向后继

    ThreadNode(int val)
        : data(val), lchild(nullptr), rchild(nullptr), LTag(0), RTag(0) {}
};
```

```python
class ThreadNode:
    def __init__(self, val):
        self.data = val
        self.lchild = None
        self.rchild = None
        self.LTag = 0  # 0: 孩子; 1: 线索
        self.RTag = 0
```

### 7.6.3 中序线索化

中序线索化的核心思想：在中序遍历过程中，用一个 `pre` 指针记录前驱结点，将当前结点与前驱结点的空指针建立线索关系。通常引入一个**头结点**来简化操作，头结点的 `lchild` 指向树根，`rchild` 指向中序遍历的最后一个结点。

```cpp
// C++ 中序线索化
class ThreadedBinaryTree {
private:
    ThreadNode* head; // 头结点

    void inorderThreading(ThreadNode* p, ThreadNode*& pre) {
        if (p == nullptr) return;
        // 递归左子树
        inorderThreading(p->lchild, pre);
        // 处理当前结点与前驱的关系
        if (p->lchild == nullptr) {
            p->lchild = pre;
            p->LTag = 1;
        }
        if (pre != nullptr && pre->rchild == nullptr) {
            pre->rchild = p;
            pre->RTag = 1;
        }
        pre = p;
        // 递归右子树
        inorderThreading(p->rchild, pre);
    }

public:
    ThreadedBinaryTree() {
        head = new ThreadNode(-1);
        head->LTag = 0;
        head->RTag = 1;
        head->rchild = head;
    }

    void buildFromRoot(ThreadNode* root) {
        head->lchild = root;
        head->LTag = 0;
        ThreadNode* pre = head;
        inorderThreading(root, pre);
        // 处理最后一个结点
        pre->rchild = head;
        pre->RTag = 1;
    }

    // 在中序线索树中找第一个被访问的结点（最左下的结点）
    ThreadNode* firstNode(ThreadNode* p) {
        while (p->LTag == 0) p = p->lchild;
        return p;
    }

    // 在中序线索树中找后继
    ThreadNode* nextNode(ThreadNode* p) {
        // 如果RTag==1（线索），右指针直接指向后继
        if (p->RTag == 1) return p->rchild;
        // 否则，后继是右子树的最左下结点
        return firstNode(p->rchild);
    }

    // 中序线索树上的遍历
    void inorderTraverse() {
        ThreadNode* p = head->lchild;
        while (p != head) {
            p = firstNode(p);
            cout << p->data << " ";
            while (p->RTag == 1 && p->rchild != head) {
                p = p->rchild;
                cout << p->data << " ";
            }
            p = p->rchild;
        }
    }

    // 在中序线索树中找前驱
    ThreadNode* priorNode(ThreadNode* p) {
        if (p->LTag == 1) return p->lchild;
        // 前驱是左子树的最右下结点
        p = p->lchild;
        while (p->RTag == 0) p = p->rchild;
        return p;
    }
};
```

```python
# Python 中序线索化
class ThreadedBinaryTree:
    def __init__(self):
        self.head = ThreadNode(-1)
        self.head.LTag = 0
        self.head.RTag = 1
        self.head.rchild = self.head

    def _inorder_threading(self, p: ThreadNode, pre: list):
        """pre 使用单元素列表模拟引用传递"""
        if p is None:
            return
        self._inorder_threading(p.lchild, pre)
        if p.lchild is None:
            p.lchild = pre[0]
            p.LTag = 1
        if pre[0] is not None and pre[0].rchild is None:
            pre[0].rchild = p
            pre[0].RTag = 1
        pre[0] = p
        self._inorder_threading(p.rchild, pre)

    def build_from_root(self, root: ThreadNode):
        self.head.lchild = root
        self.head.LTag = 0
        pre = [self.head]
        self._inorder_threading(root, pre)
        pre[0].rchild = self.head
        pre[0].RTag = 1

    def _first_node(self, p: ThreadNode) -> ThreadNode:
        while p.LTag == 0:
            p = p.lchild
        return p

    def _next_node(self, p: ThreadNode) -> ThreadNode:
        if p.RTag == 1:
            return p.rchild
        return self._first_node(p.rchild)

    def inorder_traverse(self):
        p = self.head.lchild
        while p != self.head:
            p = self._first_node(p)
            print(p.data, end=" ")
            while p.RTag == 1 and p.rchild != self.head:
                p = p.rchild
                print(p.data, end=" ")
            p = p.rchild
```

### 7.6.4 前序线索化和后序线索化

前序线索化与中序类似，只是线索化指针的时机不同：

```cpp

    if (p == nullptr) return;
    // 处理当前结点
    if (p->lchild == nullptr) {
        p->lchild = pre;
        p->LTag = 1;

    if (pre != nullptr && pre->rchild == nullptr) {
        pre->rchild = p;
        pre->RTag = 1;
    }
    pre = p;
    // 递归左子树（注意：只有LTag==0时才是真正的左孩子）
    if (p->LTag == 0)
        preorderThreading(p->lchild, pre);
    // 递归右子树
    preorderThreading(p->rchild, pre);
}
```

### 7.7.3 孩子-兄弟表示法（二叉链表）

这是最实用的一种树的存储方式，又称**左孩子右兄弟表示法**。它可以将任意树转换为二叉树。每个结点含有：

- `nextsibling`：指向下一个兄弟

```cpp
// 树的先根遍历（对应二叉树的前序遍历）
void preorderTree(CSNode* root) {

    cout << root->data << " ";
    preorderTree(root->firstChild);
    preorderTree(root->nextSibling);
}

// 树的后根遍历（对应二叉树的中序遍历）
void postorderTree(CSNode* root) {
    if (root == nullptr) return;
    postorderTree(root->firstChild);
    cout << root->data << " ";
    postorderTree(root->nextSibling);
}
```

## 7.8 森林与二叉树的转换

### 7.8.1 树转换为二叉树

**转换规则**（孩子-兄弟表示法）：
1. **加线**：在树中所有兄弟结点之间加一条连线。
2. **抹线**：对树中每个结点，只保留它与第一个孩子之间的连线，删除它与其他孩子之间的连线。
3. **旋转调整**：以根结点为轴心，将整棵树顺时针旋转约 45°，使其结构层次分明。

经此变换，任何一棵树都能唯一地转化为一棵二叉树。转换后的二叉树中，左孩子对应原树的第一个孩子，右孩子对应原树的下一个兄弟。

### 7.8.2 森林转换为二叉树

设森林 $F = \{T_1, T_2, \dots, T_n\}$，转化为二叉树 $B$：
1. 将各棵树 $T_i$ 分别转换为二叉树 $B_i$。
2. $B_1$ 的根结点作为 $B$ 的根结点。
3. $B_1$ 的子树森林（左子树不变）作为 $B$ 的左子树。
4. $B_2, B_3, \dots, B_n$ 依次作为上一棵二叉树根的右子树（即 $B_i$ 成为 $B_{i-1}$ 根结点的右子树）。

```cpp
// C++ 森林转二叉树
BiTNode* forestToBinaryTree(vector<CSNode*>& forest) {
    if (forest.empty()) return nullptr;
    // 森林中每棵树都已用孩子-兄弟法表示
    // 第一棵树的根作为二叉树的根
    BiTNode* root = new BiTNode(forest[0]->data);
    root->lchild = forest[0]->firstChild;   // 第一棵树的子树
    // 其余树依次作为右子树相连
    BiTNode* current = root;
    for (int i = 1; i < forest.size(); i++) {
        current->rchild = new BiTNode(forest[i]->data);
        current->rchild->lchild = forest[i]->firstChild;
        current = current->rchild;
    }
    return root;
}
```

```python
# Python 森林转二叉树
def forest_to_binary_tree(forest: list) -> BiTNode:

        current.rchild = BiTNode(forest[i].data)
        current.rchild.lchild = forest[i].first_child
        current = current.rchild
    return root
```

### 7.8.3 二叉树还原为森林

**逆转换规则**：
1. 若二叉树的根有右孩子，则右孩子以及其所有右子树代表原森林中第二棵及以后的树。
2. 每棵树的根：二叉树中不断沿右指针找到的结点就是各棵树的根。
3. 每棵树内部：左孩子 = 第一个孩子，右孩子 = 下一个兄弟（即原孩子-兄弟表示法）。

### 7.8.4 树和森林的遍历

| 遍历方式 | 树/森林 | 等价于二叉树的 | 说明 |
|---|---|---|---|
| 先根（先序）遍历 | 树 | 前序遍历 | 访问根→依次先根遍历各子树 |
| 后根（后序）遍历 | 树 | 中序遍历 | 依次后根遍历各子树→访问根 |
| 先序遍历 | 森林 | 前序遍历 | 先根遍历第1棵树→先序遍历剩余森林 |
| 中序遍历 | 森林 | 中序遍历 | 后根遍历第1棵树→中序遍历剩余森林 |

> **关键结论**：树的"先根遍历"等价于对应二叉树的前序遍历，树的"后根遍历"等价于对应二叉树的中序遍历。

## 7.9 哈夫曼树 (Huffman Tree)

> **编码理论**：哈夫曼编码的最优性证明见 [[../../数理基础/离散数学/07-树#哈夫曼树|离散数学 - 哈夫曼树]]。

### 7.9.1 基本概念

- **路径长度**：从根到该结点的路径上的分支数目。
- **结点的权**：根据应用需要赋予结点的有意义的数值。
- **带权路径长度**：从根到该结点的路径长度 $l_i$ 与该结点权值 $w_i$ 的乘积 $w_i \times l_i$。
- **树的带权路径长度 (WPL)**：树中所有**叶子结点**的带权路径长度之和。

$$WPL = \sum_{i=1}^{n} w_i \times l_i$$

- **哈夫曼树 (最优二叉树)**：在含有 $n$ 个给定权值叶子结点的二叉树中，WPL 最小的那棵。

### 7.9.2 哈夫曼算法

**构造步骤**：
1. 根据给定的 $n$ 个权值 $\{w_1, w_2, \dots, w_n\}$，构造 $n$ 棵只有根结点的二叉树集合 $F = \{T_1, T_2, \dots, T_n\}$，每棵树的根权值为对应权值。
2. 从 $F$ 中选取**两棵根结点权值最小**的树，分别作为左、右子树，构造一棵新二叉树。新树根结点的权值等于左右子树根结点权值之和。
3. 从 $F$ 中删除这两棵树，加入新生成的树。
4. 重复步骤 2 和 3，直到 $F$ 中只剩一棵树，此树即为哈夫曼树。

时间复杂度：使用最小堆（优先队列）每次选最小两棵树，共 $n-1$ 次合并，每次堆操作 $O(\log n)$，总计 $O(n \log n)$。

### 7.9.3 哈夫曼编码

**前缀编码**：任意一个字符的编码都不是另一个字符编码的前缀。哈夫曼编码是一种最优的前缀编码。

编码方式：在哈夫曼树中，所有左分支标记为 `0`，右分支标记为 `1`。从根到叶子结点的路径上的标记序列即为该叶子对应字符的编码。字符出现频率越高，其编码越短。

### 7.9.4 完整实现（建树、编码、解码）

```cpp
// C++ 哈夫曼树完整实现
#include <iostream>
#include <queue>
#include <unordered_map>
#include <vector>
#include <string>
using namespace std;

// 哈夫曼树结点
struct HuffNode {
    char ch;           // 字符（仅叶子结点有效）
    int weight;        // 权值
    HuffNode* left;
    HuffNode* right;

    HuffNode(char c, int w) : ch(c), weight(w), left(nullptr), right(nullptr) {}
};

// 用于最小堆的比较器
struct Compare {
    bool operator()(HuffNode* a, HuffNode* b) {
        return a->weight > b->weight;
    }
};

class HuffmanTree {
private:
    HuffNode* root;
    unordered_map<char, string> encodeMap; // 字符->编码
    unordered_map<string, char> decodeMap; // 编码->字符

    // 递归生成编码表
    void buildCodeMap(HuffNode* node, string code) {
        if (node == nullptr) return;
        if (node->left == nullptr && node->right == nullptr) {
            encodeMap[node->ch] = code;
            decodeMap[code] = node->ch;
            return;
        }
        buildCodeMap(node->left, code + "0");
        buildCodeMap(node->right, code + "1");
    }

    void freeTree(HuffNode* node) {
        if (node == nullptr) return;
        freeTree(node->left);
        freeTree(node->right);
        delete node;
    }

public:
    HuffmanTree() : root(nullptr) {}

    // 输入：字符及对应频率（权重）
    void build(const unordered_map<char, int>& freq) {
        priority_queue<HuffNode*, vector<HuffNode*>, Compare> minHeap;

        // 将所有字符对应的结点加入最小堆
        for (auto& kv : freq) {
            minHeap.push(new HuffNode(kv.first, kv.second));
        }

        // 不断合并最小的两棵树
        while (minHeap.size() > 1) {
            HuffNode* left = minHeap.top(); minHeap.pop();
            HuffNode* right = minHeap.top(); minHeap.pop();
            HuffNode* parent = new HuffNode('\0', left->weight + right->weight);
            parent->left = left;
            parent->right = right;
            minHeap.push(parent);
        }

        root = minHeap.top();
        // 构建编码表
        buildCodeMap(root, "");
    }

    // 编码：字符串 -> 二进制编码字符串
    string encode(const string& text) {
        string result;
        for (char c : text) {
            if (encodeMap.find(c) == encodeMap.end()) {
                throw runtime_error("Character not in encoding table");
            }
            result += encodeMap[c];
        }
        return result;
    }

    // 解码：二进制编码字符串 -> 字符串
    string decode(const string& encoded) {
        string result;
        string current;
        for (char bit : encoded) {
            current += bit;
            if (decodeMap.find(current) != decodeMap.end()) {
                result += decodeMap[current];
                current = "";
            }
        }
        return result;
    }

    // 获取编码表
    unordered_map<char, string> getEncodings() const {
        return encodeMap;
    }

    // WPL 计算
    int getWPL(HuffNode* node, int depth) {
        if (node == nullptr) return 0;
        if (node->left == nullptr && node->right == nullptr)
            return node->weight * depth;
        return getWPL(node->left, depth + 1) + getWPL(node->right, depth + 1);
    }

    int getWPL() { return getWPL(root, 0); }

    ~HuffmanTree() { freeTree(root); }
};
```

```python
# Python 哈夫曼树完整实现
import heapq
from typing import Dict, Optional


class HuffNode:
    def __init__(self, ch: str, weight: int):
        self.ch = ch
        self.weight = weight
        self.left: Optional[HuffNode] = None
        self.right: Optional[HuffNode] = None

    def __lt__(self, other):
        return self.weight < other.weight


class HuffmanTree:
    def __init__(self):
        self.root: Optional[HuffNode] = None
        self.encode_map: Dict[str, str] = {}
        self.decode_map: Dict[str, str] = {}

    def _build_code_map(self, node: Optional[HuffNode], code: str):
        if node is None:
            return
        if node.left is None and node.right is None:
            self.encode_map[node.ch] = code
            self.decode_map[code] = node.ch
            return
        self._build_code_map(node.left, code + "0")
        self._build_code_map(node.right, code + "1")

    def build(self, freq: Dict[str, int]):
        heap = []
        for ch, weight in freq.items():
            heapq.heappush(heap, HuffNode(ch, weight))

        while len(heap) > 1:
            left = heapq.heappop(heap)
            right = heapq.heappop(heap)
            parent = HuffNode('\0', left.weight + right.weight)
            parent.left = left
            parent.right = right
            heapq.heappush(heap, parent)

        self.root = heap[0]
        self._build_code_map(self.root, "")

    def encode(self, text: str) -> str:
        result = []
        for ch in text:
            if ch not in self.encode_map:
                raise ValueError(f"Character '{ch}' not in encoding table")
            result.append(self.encode_map[ch])
        return "".join(result)

    def decode(self, encoded: str) -> str:
        result = []
        current = ""
        for bit in encoded:
            current += bit
            if current in self.decode_map:
                result.append(self.decode_map[current])
                current = ""
        return "".join(result)

    def get_encodings(self) -> Dict[str, str]:
        return self.encode_map

    def _get_wpl(self, node: Optional[HuffNode], depth: int) -> int:
        if node is None:
            return 0
        if node.left is None and node.right is None:
            return node.weight * depth
        return self._get_wpl(node.left, depth + 1) + self._get_wpl(node.right, depth + 1)

    def get_wpl(self) -> int:
        return self._get_wpl(self.root, 0)
```

## 7.10 二叉排序树 (BST)

### 7.10.1 定义与性质

**二叉排序树**（Binary Search Tree，BST）或是一棵空树，或是具有如下性质的二叉树：

1. 若左子树非空，则左子树上所有结点的值均**小于**根结点的值。
2. 若右子树非空，则右子树上所有结点的值均**大于**根结点的值。
3. 左、右子树本身也各是一棵二叉排序树。

**中序遍历一棵 BST 得到的序列是递增有序的**。

### 7.10.2 查找

#### 递归查找

```cpp

}
```

### 7.10.4 删除

删除操作分三种情况：
1. **被删结点是叶子**：直接删除。
2. **被删结点只有一个孩子**：用孩子替代被删结点。
3. **被删结点有两个孩子**：用左子树的最大结点（直接前驱）或右子树的最小结点（直接后继）替代被删结点，然后删除那个替代结点。

```cpp
// C++ BST 删除
BSTNode* findMin(BSTNode* root) {
    while (root->lchild != nullptr)
        root = root->lchild;
    return root;
}

BSTNode* remove(BSTNode* root, int key) {
    if (root == nullptr) return nullptr;
    if (key < root->data) {
        root->lchild = remove(root->lchild, key);
    } else if (key > root->data) {
        root->rchild = remove(root->rchild, key);
    } else {
        // 情况 1 & 2: 0个或1个孩子
        if (root->lchild == nullptr) {
            BSTNode* temp = root->rchild;
            delete root;
            return temp;
        } else if (root->rchild == nullptr) {
            BSTNode* temp = root->lchild;
            delete root;
            return temp;
        }
        // 情况 3: 两个孩子——用右子树最小值替代
        BSTNode* successor = findMin(root->rchild);
        root->data = successor->data;
        root->rchild = remove(root->rchild, successor->data);
    }
    return root;
}
```

```python
# Python BST 删除
def find_min(root: BSTNode) -> BSTNode:
    while root.lchild:
        root = root.lchild
    return root


def remove(root: Optional[BSTNode], key: int) -> Optional[BSTNode]:
    if root is None:
        return None
    if key < root.data:
        root.lchild = remove(root.lchild, key)
    elif key > root.data:
        root.rchild = remove(root.rchild, key)
    else:
        # 情况 1 & 2
        if root.lchild is None:
            return root.rchild
        elif root.rchild is None:
            return root.lchild
        # 情况 3
        successor = find_min(root.rchild)
        root.data = successor.data
        root.rchild = remove(root.rchild, successor.data)
    return root
```

## 7.11 平衡二叉树 (AVL)

### 7.11.1 定义

**平衡二叉树**（AVL 树，以发明者 Adelson-Velsky 和 Landis 命名）是一棵二叉排序树，且树中**每个结点的左、右子树深度之差的绝对值不超过 1**。

- **平衡因子 (Balance Factor, BF)**：$BF = h_L - h_R$，其中 $h_L$ 和 $h_R$ 分别为左、右子树的高度。
- 平衡二叉树要求 $|BF| \le 1$ 对所有结点恒成立。

### 7.11.2 AVL 树的最小/最大结点数

设高度为 $h$ 的 AVL 树含有最少结点数为 $N_h$，则有以下递推关系：

$$N_0 = 0,\quad N_1 = 1,\quad N_2 = 2$$

$$N_h = N_{h-1} + N_{h-2} + 1 \quad (h \ge 3)$$

由此可推出含有 $n$ 个结点的 AVL 树的最大高度约为 $1.44 \log_2 n$，因此查找、插入、删除的最坏时间复杂度均为 $O(\log n)$。

### 7.11.3 四种旋转操作

插入导致失衡后，根据失衡结点的平衡因子及其孩子结点的平衡因子分类：

| 类型 | 情况描述 | 旋转方式 | 图示 |
|---|---|---|---|
| **LL** | 在失衡结点左子树的左子树中插入 | 右旋 (R) | 失衡结点顺时针旋转 |
| **RR** | 在失衡结点右子树的右子树中插入 | 左旋 (L) | 失衡结点逆时针旋转 |
| **LR** | 在失衡结点左子树的右子树中插入 | 先左旋后右旋 (LR) | 先对左孩子左旋，再对失衡结点右旋 |
| **RL** | 在失衡结点右子树的左子树中插入 | 先右旋后左旋 (RL) | 先对右孩子右旋，再对失衡结点左旋 |

```
LL 旋转（右旋）:
     A (BF=2)           B
    /                   / \
   B (BF=1)    ==>     C   A
  /
 C

RR 旋转（左旋）:
   A (BF=-2)           B
    \                 / \
     B (BF=-1) ==>   A   C
      \
       C
```

### 7.11.4 完整 C++ 实现

```cpp
// C++ AVL 树完整实现
#include <iostream>
#include <algorithm>
using namespace std;

struct AVLNode {
    int data;
    int height;
    AVLNode* left;
    AVLNode* right;

    AVLNode(int val) : data(val), height(1), left(nullptr), right(nullptr) {}
};

class AVLTree {
private:
    AVLNode* root;

    int getHeight(AVLNode* node) {
        return node ? node->height : 0;
    }

    int getBalance(AVLNode* node) {
        return node ? getHeight(node->left) - getHeight(node->right) : 0;
    }

    void updateHeight(AVLNode* node) {
        node->height = 1 + max(getHeight(node->left), getHeight(node->right));
    }

    // 右旋（处理LL）
    AVLNode* rotateRight(AVLNode* y) {
        AVLNode* x = y->left;
        AVLNode* T2 = x->right;

        x->right = y;
        y->left = T2;

        updateHeight(y);
        updateHeight(x);

        return x;  // 新根
    }

    // 左旋（处理RR）
    AVLNode* rotateLeft(AVLNode* x) {
        AVLNode* y = x->right;
        AVLNode* T2 = y->left;

        y->left = x;
        x->right = T2;

        updateHeight(x);
        updateHeight(y);

        return y;  // 新根
    }

    AVLNode* insertNode(AVLNode* node, int key) {
        // 1. 标准 BST 插入
        if (node == nullptr)
            return new AVLNode(key);

        if (key < node->data)
            node->left = insertNode(node->left, key);
        else if (key > node->data)
            node->right = insertNode(node->right, key);
        else
            return node;  // 不允许重复

        // 2. 更新高度
        updateHeight(node);

        // 3. 获取平衡因子，检查是否失衡
        int balance = getBalance(node);

        // LL: 左子树的左边插入
        if (balance > 1 && key < node->left->data)
            return rotateRight(node);

        // RR: 右子树的右边插入
        if (balance < -1 && key > node->right->data)
            return rotateLeft(node);

        // LR: 左子树的右边插入
        if (balance > 1 && key > node->left->data) {
            node->left = rotateLeft(node->left);
            return rotateRight(node);
        }

        // RL: 右子树的左边插入
        if (balance < -1 && key < node->right->data) {
            node->right = rotateRight(node->right);
            return rotateLeft(node);
        }

        return node;
    }

    AVLNode* findMin(AVLNode* node) {
        while (node->left) node = node->left;
        return node;
    }

    AVLNode* deleteNode(AVLNode* node, int key) {
        if (node == nullptr) return nullptr;

        if (key < node->data)
            node->left = deleteNode(node->left, key);
        else if (key > node->data)
            node->right = deleteNode(node->right, key);
        else {
            if (node->left == nullptr || node->right == nullptr) {
                AVLNode* temp = node->left ? node->left : node->right;
                if (temp == nullptr) {
                    temp = node;
                    node = nullptr;
                } else {
                    *node = *temp;  // 拷贝内容
                }
                delete temp;
            } else {
                AVLNode* temp = findMin(node->right);
                node->data = temp->data;
                node->right = deleteNode(node->right, temp->data);
            }
        }

        if (node == nullptr) return nullptr;

        updateHeight(node);
        int balance = getBalance(node);

        // LL
        if (balance > 1 && getBalance(node->left) >= 0)
            return rotateRight(node);
        // LR
        if (balance > 1 && getBalance(node->left) < 0) {
            node->left = rotateLeft(node->left);
            return rotateRight(node);
        }
        // RR
        if (balance < -1 && getBalance(node->right) <= 0)
            return rotateLeft(node);
        // RL
        if (balance < -1 && getBalance(node->right) > 0) {
            node->right = rotateRight(node->right);
            return rotateLeft(node);
        }

        return node;
    }

    void inorderPrint(AVLNode* node) {
        if (node == nullptr) return;
        inorderPrint(node->left);
        cout << node->data << " ";
        inorderPrint(node->right);
    }

public:
    AVLTree() : root(nullptr) {}

    void insert(int key) {
        root = insertNode(root, key);
    }

    void remove(int key) {
        root = deleteNode(root, key);
    }

    bool search(int key) {
        AVLNode* cur = root;
        while (cur) {
            if (key == cur->data) return true;
            cur = (key < cur->data) ? cur->left : cur->right;
        }
```

```python
# Python AVL 树完整实现
from typing import Optional


class AVLNode:
    def __init__(self, val: int):
        self.data = val
        self.height = 1
        self.left: Optional[AVLNode] = None
        self.right: Optional[AVLNode] = None


class AVLTree:
    def __init__(self):
        self.root: Optional[AVLNode] = None

    def _height(self, node: Optional[AVLNode]) -> int:
        return node.height if node else 0

    def _balance(self, node: Optional[AVLNode]) -> int:
        return self._height(node.left) - self._height(node.right) if node else 0

    def _update_height(self, node: AVLNode):
        node.height = 1 + max(self._height(node.left), self._height(node.right))

    def _rotate_right(self, y: AVLNode) -> AVLNode:
        x = y.left
        t2 = x.right
        x.right = y
        y.left = t2
        self._update_height(y)
        self._update_height(x)
        return x

    def _rotate_left(self, x: AVLNode) -> AVLNode:
        y = x.right
        t2 = y.left
        y.left = x
        x.right = t2
        self._update_height(x)
        self._update_height(y)
        return y

    def _insert(self, node: Optional[AVLNode], key: int) -> AVLNode:
        if node is None:
            return AVLNode(key)

        if key < node.data:
            node.left = self._insert(node.left, key)
        elif key > node.data:
            node.right = self._insert(node.right, key)
        else:
            return node

        self._update_height(node)
        balance = self._balance(node)

        # LL
        if balance > 1 and key < node.left.data:
            return self._rotate_right(node)
        # RR
        if balance < -1 and key > node.right.data:
            return self._rotate_left(node)
        # LR
        if balance > 1 and key > node.left.data:
            node.left = self._rotate_left(node.left)
            return self._rotate_right(node)
        # RL
        if balance < -1 and key < node.right.data:
            node.right = self._rotate_right(node.right)
            return self._rotate_left(node)

        return node

    def _find_min(self, node: AVLNode) -> AVLNode:
        while node.left:
            node = node.left
        return node

    def _delete(self, node: Optional[AVLNode], key: int) -> Optional[AVLNode]:
        if node is None:
            return None

        if key < node.data:
            node.left = self._delete(node.left, key)
        elif key > node.data:
            node.right = self._delete(node.right, key)
        else:
            if node.left is None or node.right is None:
                temp = node.left if node.left else node.right
                if temp is None:
                    node = None
                else:
                    node = temp
            else:
                temp = self._find_min(node.right)
                node.data = temp.data
                node.right = self._delete(node.right, temp.data)

        if node is None:
            return None

        self._update_height(node)
        balance = self._balance(node)

        # LL
        if balance > 1 and self._balance(node.left) >= 0:
            return self._rotate_right(node)
        # LR
        if balance > 1 and self._balance(node.left) < 0:
            node.left = self._rotate_left(node.left)
            return self._rotate_right(node)
        # RR
        if balance < -1 and self._balance(node.right) <= 0:
            return self._rotate_left(node)
        # RL
        if balance < -1 and self._balance(node.right) > 0:
            node.right = self._rotate_right(node.right)
            return self._rotate_left(node)

        return node

    def insert(self, key: int):
        self.root = self._insert(self.root, key)

    def remove(self, key: int):
        self.root = self._delete(self.root, key)

    def search(self, key: int) -> bool:
        cur = self.root
        while cur:
            if key == cur.data:
                return True
            cur = cur.left if key < cur.data else cur.right
        return False

    def inorder(self, node: Optional[AVLNode] = None) -> list:
        if node is None:
            node = self.root
        result = []
        def dfs(n):
            if n is None:
                return
            dfs(n.left)
            result.append(n.data)
            dfs(n.right)
        dfs(node)
        return result


# 测试

    for x in [10, 20, 30, 40, 50, 25]:
        avl.insert(x)
    print(avl.inorder())  # [10, 20, 25, 30, 40, 50]
    avl.remove(30)
    print(avl.inorder())  # [10, 20, 25, 40, 50]
    print(avl.search(25)) # True
    print(avl.search(30)) # False
```

## 总结

本章系统地介绍了树和二叉树的核心知识体系：

1. **树的定义与术语**是理解树结构的基础，递归定义贯穿始终。
2. **二叉树**是树结构中最重要的一种，其五个性质带有严格的数学证明。
3. **存储结构**包括顺序和链式两大类，二叉链表是最常用的方式。
4. **遍历**是二叉树操作的核心，前/中/后序各有递归与非递归实现方式，层次遍历用队列。
5. **线索二叉树**利用空指针加速遍历，使遍历不需要栈。
6. **树与森林的转换**建立了树—二叉树—森林之间的等价关系。
7. **哈夫曼树**及其编码是数据压缩的经典算法。
8. **BST** 提供高效的动态查找，但可能退化为链表。
9. **AVL 树**通过旋转操作保证平衡，将最坏时间复杂度控制在 $O(\log n)$。
