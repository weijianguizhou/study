\chapter{弯曲内力}
\section{弯曲的概念}
\begin{mydefinition}{梁}
    以弯曲形变为主的杆件习惯上称为梁。
\end{mydefinition}

\begin{mydefinition}{对称弯曲}
    当作用于杆件上的所有外力都在纵向对称面内时，弯曲形变后的轴线将是位于这个对称面内的一条曲线，我们称这种弯曲为对称弯曲。
\end{mydefinition}

\section{受弯杆件的简化}
为了方便我们对弯曲杆件内力进行计算，我们对梁进行简化，得出计算简图。我们将重点讨论支座和载荷的简化。

\subsection{支座的几种基本形式}
\begin{itemize}
    \item \textbf{固定铰支座：} 只能限制杆件在垂直于轴线方向的位移，不能限制杆件绕支座的转动。提供的反力有两个分量，分别是竖向反力和水平反力。
    \item \textbf{可动铰支座：} 只能限制杆件在垂直于轴线方向的位移，不能限制杆件绕支座的转动。提供的反力只有一个分量，即竖向反力。
    \item \textbf{固定端支座：} 既能限制杆件的位移，又能限制杆件的转动。提供的反力有三个分量，分别是竖向反力、水平反力和弯矩。
\end{itemize}

\begin{myTheorem}{载荷集度、剪力和弯矩间的关系}
    设梁上作用的分布载荷集度为 \(q(x)\)（以向上为正，或按特定约定，此处采用材料力学常用约定：\(q\) 向下为正），则剪力 \(F_Q(x)\)、弯矩 \(M(x)\) 与载荷集度 \(q(x)\) 之间存在如下微分关系：
    \begin{align}
        \frac{dF_Q(x)}{dx} &= -q(x) \quad \text{（若 \(q\) 向上为正，则此处无负号，视具体约定而定）} \\
        \frac{dM(x)}{dx} &= F_Q(x)
    \end{align}
    联立上述两式，可得弯矩与载荷集度的二阶微分关系：
    \[ \frac{d^2M(x)}{dx^2} = -q(x) \]

    对上述微分关系积分，可得到剪力和弯矩的积分关系：
    \[ F_Q(x_2) - F_Q(x_1) = -\int_{x_1}^{x_2} q(x) \, dx \]
    \[ M(x_2) - M(x_1) = \int_{x_1}^{x_2} F_Q(x) \, dx \]

    根据以上关系，可以总结出绘制剪力图和弯矩图的便捷规律：
    \begin{itemize}
        \item \textbf{无荷载段（\(q=0\)）}：\(F_Q\) 为常数，剪力图水平；\(M\) 为一次函数（斜直线）。
        \item \textbf{受均布荷载段（\(q=\) 常数）}：\(F_Q\) 为一次函数（斜直线）；\(M\) 为二次函数（抛物线）。当 \(q>0\) 时，抛物线开口向下（凸形）；当 \(q<0\) 时，抛物线开口向上（凹形）。
        \item \textbf{集中力作用处}：剪力图 \(F_Q\) 发生突变，突变值等于集中力的大小；弯矩图 \(M\) 连续但斜率发生突变（形成尖点），且尖点方向与集中力方向一致。
        \item \textbf{集中力偶作用处}：弯矩图 \(M\) 发生突变，突变值等于集中力偶的大小；剪力图 \(F_Q\) 不变。
        \item \textbf{极值条件}：在剪力 \(F_Q(x)=0\) 的截面处，弯矩 \(M(x)\) 取得极值（极大值或极小值）。
    \end{itemize}
\end{myTheorem}

\section{平面刚架和曲杆的弯曲内力}

\subsection*{平面刚架}
由多根直杆在端点处通过刚性节点（刚结点）连接而成的结构称为平面刚架。刚结点能传递力和力矩，因此刚架在受力变形时，杆件之间的夹角保持不变。

与单根直梁不同，刚架中各杆件的横截面上一般同时存在三种内力分量：
\begin{itemize}
    \item \textbf{轴力 \(F_N\)}：沿杆件轴向，以拉伸为正。
    \item \textbf{剪力 \(F_Q\)}：沿杆件截面切线方向。
    \item \textbf{弯矩 \(M\)}：在杆件平面内使杆件发生弯曲的力偶。
\end{itemize}

\textbf{刚架内力图的绘制要点：}
\begin{enumerate}
    \item 绘制刚架内力图时，通常需要分段对每根直杆单独分析，列出各杆的内力方程。
    \item \textbf{弯矩图}：规定画在杆件的受压侧（即弯曲变形后的凹入一侧），通常不标正负号。
    \item \textbf{剪力图和轴力图}：可以画在杆件的任意一侧，但必须标出正负号。
    \item \textbf{刚结点处的校验}：对刚结点取矩，所有杆端弯矩的代数和必须为零（结点平衡条件），这是校核刚架弯矩图是否正确的重要依据。
\end{enumerate}

\subsection*{曲杆}
轴线为曲线的杆件称为曲杆。曲杆的弯曲内力分析通常采用局部坐标系（极坐标或正交曲线坐标）。

在曲杆的任意截面上，建立以截面形心为原点的局部坐标系：
\begin{itemize}
    \item 取截面外法线方向（或沿杆轴切线方向）为法向，与之垂直的方向为切向。
    \item 截面上的内力可分解为：
    \begin{itemize}
        \item \textbf{轴力 \(F_N\)}：沿截面外法线方向（或切线方向，视定义）。
        \item \textbf{剪力 \(F_Q\)}：沿截面切线方向（或法线方向）。
        \item \textbf{弯矩 \(M\)}：作用在曲杆平面内的力偶。
    \end{itemize}
\end{itemize}

\textbf{曲杆内力计算注意事项：}
\begin{enumerate}
    \item 使用截面法截开曲杆时，外力的分解需要依据截面处的切线方向和法线方向进行，不能简单地沿竖直或水平方向列平衡方程。
    \item \textbf{弯矩的正负约定}：通常约定使曲杆的曲率增大（即凹面受拉）的弯矩为正，反之使曲率减小的弯矩为负。
    \item 曲杆的弯矩图一般画在受拉侧，其图形沿弧长变化。
\end{enumerate}

\begin{myTheorem}{曲杆微元平衡方程}
    对曲杆的微元段，沿弧长方向建立局部坐标系，设微元段的长度为 \(ds\)，则曲杆微元平衡方程为：
\begin{align*}
    &\text{曲杆微元平衡方程（局部坐标）：} \\
    &\frac{dF_N}{ds} - F_Q \cdot \frac{d\theta}{ds} + q_n = 0 \\
    &\frac{dF_Q}{ds} + F_N \cdot \frac{d\theta}{ds} + q_t = 0 \\
    &\frac{dM}{ds} = F_Q
\end{align*}
\end{myTheorem}
其中，\(s\) 为弧长，\(\theta\) 为曲率角，\(q_n\) 和 \(q_t\) 分别为沿法向和切向的分布载荷集度。
