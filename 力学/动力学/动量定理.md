# 动量：
- **定义：** 质点的质量与速度的乘积称为质点的**动量**。
    $$\vec{p} = m\vec{v}$$
    质点系内各质点动量的矢量和称为**质点系的动量**。
    $$\vec{P} = \sum m_i \vec{v}_i = \sum m_i \vec{u}_i = \frac{d}{dt} \sum m_i \vec{r}_i$$
    记总质量 $m = \sum m_i$
    定义质心矢径 $\vec{r}_c = \frac{\sum m_i \vec{r}_i}{m}$
    则
    $$\vec{P} = \frac{d}{dt} \sum m_i \vec{r}_i = \frac{d}{dt} (m\vec{r}_c)$$
    即质点系的动量等于质心速度与其全部质量的乘积。

# 冲量：

- **定义：** 如果作用力是**常量**，我们用力与作用时间的乘积来衡量力在这段时间的累积作用效果。
    于是，我们把作用力与作用时间的乘积称为常力的冲量。
    $$\vec{I} = \vec{F}t$$
    若作用力 $\vec{F}$ 是变量，在微小时间间隔 $dt$ 内，$\vec{F}$ 的冲量称为元冲量。
    即$$d\vec{I} = \vec{F}dt$$
    
    则
    
    $$\vec{I} = \int_{t_1}^{t_2} \vec{F}dt$$
# 动量定理：

$\because \frac{d}{dt}(m\vec{v}) = \vec{F}$

则 $d(m\vec{v}) = \vec{F}dt$

$m d\vec{v} = \vec{F}dt$

积分，则有 $m\vec{v}_2 - m\vec{v}_1 = \int_{t_1}^{t_2} \vec{F}dt = \vec{I}$

对于质点系，分析其中的一个质点 $i$：

$d(m_i \vec{v}_i) = (\vec{F}_i^{(e)} + \vec{F}_i^{(i)})dt = \vec{F}_i^{(e)}dt + \vec{F}_i^{(i)}dt$

$\because$ 共 $n$ 个质点，则

$\sum d(m_i \vec{v}_i) = \sum \vec{F}_i^{(e)}dt + \sum \vec{F}_i^{(i)}dt$

由牛顿第三定律，$\sum \vec{F}_i^{(i)}dt = 0$

则 $d\vec{P} = \sum \vec{F}_i^{(e)}dt = \sum d\vec{I}_i^{(e)}$，亦可写作 $\frac{d\vec{P}}{dt} = \sum \vec{F}_i^{(e)}$

$\int_{P_1}^{P_2} d\vec{P} = \sum \int_{t_1}^{t_2} \vec{F}_i^{(e)}dt$

$\vec{P}_2 - \vec{P}_1 = \sum \vec{I}_i^{(e)}$

---

# 质点系动量守恒定律：

如果作用于质点系的外力的主矢量恒等于零，根据上述论述，质点系的动量保持不变，为常矢量，即：

$$\vec{P}_2 = \vec{P}_1$$

将矢量向坐标轴上投影，即该质点系的动量在该坐标轴上的分量保持不变，即 $P_{2x} = P_{1x}$。


# 质心运动定理


由前文 $\vec{r}_c = \frac{\sum m_i \vec{r}_i}{\sum m_i} = \frac{\sum m_i \vec{r}_i}{m}$

$$\begin{cases} x_c = \frac{\sum m_i x_i}{\sum m_i} = \frac{\sum m_i x_i}{m} \\ y_c = \frac{\sum m_i y_i}{\sum m_i} = \frac{\sum m_i y_i}{m} \\ z_c = \frac{\sum m_i z_i}{\sum m_i} = \frac{\sum m_i z_i}{m} \end{cases}$$

即，建立了**质心的运动方程**。

又由前文 $\frac{d}{dt}(m\vec{v}_c) = \sum \vec{F}_i^{(e)}$

对于质量不变的质点系，上式又可改写为：

$$m \frac{d\vec{v}_c}{dt} = \sum \vec{F}_i^{(e)}$$

$$m\vec{a}_c = \sum \vec{F}_i^{(e)}$$

由此，一个质点系的运动我们可以看作一个质点的运动，且只有**外力的作用**才能改变质心的运动状态。

将质心速度和外力向各轴上投影，即得质心运动微分方程。
