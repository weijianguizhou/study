**描述质点系相对于定点或质心的运动状态及其变化规律。**

# 动量矩：
![[动量矩.png]]
- **质点 $Q$ 的动量对于点 $O$ 的矩**，定义为质点对于点 $O$ 的**动量矩**：
    
    $$\vec{M}_O(m\vec{v}) = \vec{r} \times m\vec{v}$$
    
- **质点 $Q$ 的动量对于轴的矩**，为 $m\vec{v}$ 在 $Oxy$ 内投影 $(m\vec{v})_{xy}$ 对于点 $O$ 的矩。
    

**注：** $[\vec{M}_O(m\vec{v})]_z = M_z(m\vec{v})$

- **质点系的动量矩：**
    $$\vec{L}_O = \sum \vec{M}_O(m_i\vec{v}_i)$$$$L_z = \sum M_z(m_i\vec{v}_i)$$
## 对于绕定轴转动的刚体：

$$L_z = \sum M_z(m_i\vec{v}_i) = \sum m_i v_i r_i = \omega \sum m_i r_i^2$$

令 $J_z = \sum m_i r_i^2$，则 $L_z = \omega J_z$

于是称 $J_z$ 为**转动惯量**。

# 动量矩定理：
![[动量矩定理.png]]

将**动量矩对时间取一次导数**：

$$\frac{d}{dt}\vec{M}_O(m\vec{v}) = \frac{d}{dt}(\vec{r} \times m\vec{v}) = \frac{d\vec{r}}{dt} \times m\vec{v} + \vec{r} \times \frac{d}{dt}(m\vec{v})$$

由质点动力学基本方程有 $\frac{d}{dt}(m\vec{v}) = \vec{F}$，又 $O$ 为定点，$\frac{d\vec{r}}{dt} = \vec{v}$，$\vec{v} \times m\vec{v} = 0$。

$$\therefore \frac{d}{dt}\vec{M}_O(m\vec{v}) = \vec{M}_O(\vec{F})$$

## 常用投影式：

$$\frac{d}{dt}M_x(m\vec{v}) = M_x(\vec{F}), \quad \frac{d}{dt}M_y(m\vec{v}) = M_y(\vec{F}), \quad \frac{d}{dt}M_z(m\vec{v}) = M_z(\vec{F})$$

---

对于一个质点系呢？先分析第 $i$ 个质点：

$$\frac{d}{dt} \vec{M}_O(m_i \vec{v}_i) = \vec{M}_O(\vec{F}_i^{(i)}) + \vec{M}_O(\vec{F}_i^{(e)})$$

两边相加：

$$\sum \frac{d}{dt} \vec{M}_O(m_i \vec{v}_i) = \sum \vec{M}_O(\vec{F}_i^{(i)}) + \sum \vec{M}_O(\vec{F}_i^{(e)})$$

由牛顿第三定律：$\sum \vec{M}_O(\vec{F}_i^{(i)}) = \vec{0}$。

于是有

$$\sum \frac{d}{dt} \vec{M}_O(m_i \vec{v}_i) = \frac{d}{dt} \sum \vec{M}_O(m_i \vec{v}_i) = \frac{d}{dt} \vec{L}_O$$

于是

$$\frac{d}{dt} \vec{L}_O = \sum \vec{M}_O(\vec{F}_i^{(e)})$$

**注：上述动量矩定理仅限于固定点、固定轴。**

### 动量矩守恒定律：

$\sum \vec{M}_O(\vec{F}_i^{(e)}) = 0$ 时，$\vec{L}_O = \text{const}$。

##### 由此可导出面积速度定理：

设 $M$ 仅在有心力作用下绕 $O$ 点运动，

$\sum \vec{M}_O(\vec{F}_i^{(e)}) = 0$。

则 $\vec{r} \times m\vec{v} = \text{const}$，$\vec{r} \times m \frac{d\vec{r}}{dt} = \text{const}$。

$\vec{r} \times \frac{d\vec{r}}{dt} = \text{const}$，又 $\vec{r} \times d\vec{r}$ 为矢量三角形面积的两倍，

$\therefore \frac{dA}{dt} = \text{const}$

**即为面积速度定理。**

# 刚体绕定轴转动的转动微分方程：

对于一个定轴转动的刚体（默认转轴为 $z$），由动量矩定理：

$$\frac{d}{dt}(J_z \omega) = \sum M_z(\vec{F}_i), \quad J_z \frac{d\omega}{dt} = \sum M_z(\vec{F}_i)$$

即 $J_z \alpha = \sum M_z(\vec{F}_i)$ 或 $J_z \frac{d^2\phi}{dt^2} = \sum M_z(\vec{F}_i)$。

## 回转半径：

回转半径（或惯性半径）定义为：

$$\rho_z = \sqrt{\frac{J_z}{m}}$$

对于几何形状相同的均质物体，其回转半径的公式相同，且有 $J_z = m\rho_z^2$。

## 平行轴定理：
![[平行轴定理.png]]

$$J_z = J_{z_c} + md^2$$

这里，$z \parallel z_c$ 且 $d = |z, z_c|$。

**证明（Pf）：**

$$J_z = \sum m_i (x_i^2 + y_i^2)$$

$$J_{z_c} = \sum m_i [x_i^2 + (y_i - d)^2] = \sum m_i (x_i^2 + y_i^2) + \sum m_i d^2 - 2d \sum m_i y_{i_c}$$

由质心坐标公式，$y_c \sum m_i = \sum m_i y_i$ ，又 $y_c = d$。

于是有 $J_{z_c} = J_z - md^2$。

**证毕。**

# 质点系相对于质心的动量矩定理：
![[质点系相对于质心的动量矩.png]]

以质心 $C$ 为原点，取一平移参考系 $Cx'y'z'$。则质点系对质心的动量矩为：

$$\vec{L}_C = \sum \vec{M}_C(m_i \vec{v}_i) = \sum (\vec{r}_i' \times m_i \vec{v}_i)$$

若 $m_i$ 为动点，则 $Cx'y'z'$ 为动参考系，则有 $\vec{v}_i = \vec{v}_C + \vec{v}_{ir}$。

则

$$\vec{L}_C = \sum [m_i \vec{r}_i' \times (\vec{v}_C + \vec{v}_{ir})] = \sum (m_i \vec{r}_i' \times \vec{v}_C) + \sum (m_i \vec{r}_i' \times \vec{v}_{ir})$$

又 $\vec{r}_C' = 0$

$$\therefore \vec{L}_C = \sum \vec{M}_C(m_i \vec{v}_{ir}) = \sum (\vec{r}_i' \times m_i \vec{v}_{ir})$$

**即：以质点的绝对速度和相对速度算出来的对质心的动量矩结果相同。**

---

### 若对一固定点 $O$ 取矩：

$$\vec{L}_O = \sum \vec{M}_O(m_i \vec{v}_i) = \sum (\vec{r}_i \times m_i \vec{v}_i)$$

$$\vec{r}_i = \vec{r}_C + \vec{r}_i'$$

于是

$$\vec{L}_O = \sum [(\vec{r}_C + \vec{r}_i') \times m_i \vec{v}_i]$$

$$= \vec{r}_C \times \sum (m_i \vec{v}_i) + \sum (\vec{r}_i' \times m_i \vec{v}_i)$$

又 $\sum (m_i \vec{v}_i) = m \vec{v}_C$。

$$\therefore \text{质点系对于定点 } O \text{ 的动量矩为：}$$

$$\vec{L}_O = \vec{r}_C \times m \vec{v}_C + \vec{L}_C$$

对上述式子对时间求导：

$$\frac{d\vec{L}_O}{dt} = \frac{d}{dt}(\vec{r}_C \times m\vec{v}_C + \vec{L}_C) = \sum (\vec{r}_i \times \vec{F}_i^{(e)})$$

又 $\vec{r}_i = \vec{r}_C + \vec{r}_i'$

$$\frac{d\vec{r}_C}{dt} \times m\vec{v}_C + \vec{r}_C \times \frac{d}{dt}(m\vec{v}_C) + \frac{d\vec{L}_C}{dt} = \sum (\vec{r}_C \times \vec{F}_i^{(e)}) + \sum (\vec{r}_i' \times \vec{F}_i^{(e)})$$

又 $\frac{d\vec{r}_C}{dt} = \vec{v}_C$，$\vec{v}_C \times \vec{v}_C = 0$。$\frac{d\vec{v}_C}{dt} = \vec{a}_C$，$m\vec{a}_C = \sum \vec{F}_i^{(e)}$

$\therefore$ 上式可化为：

$$\frac{d\vec{L}_C}{dt} = \sum (\vec{r}_i' \times \vec{F}_i^{(e)})$$

**即得：质点系相对于质心的动量矩定理**

$$\frac{d\vec{L}_C}{dt} = \sum \vec{M}_C(\vec{F}_i^{(e)})$$

### 刚体的平面运动微分方程：

在工程实际中，大部分平面运动刚体可以抽象为具有质量对称面，且平行于此对称面运动的力学模型。 ——《理论力学 I 哈工大》

刚体对质心轴的动量矩为 $L_C = J_C \omega$

$m\vec{a}_C = \sum \vec{F}^{(e)}$, $\quad \frac{d}{dt}(J_C \omega) = J_C \alpha = \sum M_C(\vec{F}^{(e)})$

则上述式子可写作：

$$m \frac{d^2\vec{r}_C}{dt^2} = \sum \vec{F}^{(e)}, \quad J_C \frac{d^2\phi}{dt^2} = \sum M_C(\vec{F}^{(e)})$$

此即为**刚体平面运动的微分方程**。

**两个投影式：**

$$\begin{cases} m a_{Cx} = \sum F_x \\ m a_{Cy} = \sum F_y \\ J_C \alpha = \sum M_C(\vec{F}^{(e)}) \end{cases} \quad \begin{cases} m a_t^C = \sum F_t \\ m a_n^C = \sum F_n \\ J_C \alpha = \sum M_C(\vec{F}^{(e)}) \end{cases}$$
