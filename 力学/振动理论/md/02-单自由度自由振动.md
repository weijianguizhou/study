## 1 无阻尼自由振动

### 1.1 运动方程

最基本的振动系统：质量 $m$ + 弹簧 $k$，无外力，无阻尼。

由 Newton 第二定律：
$$m\ddot{x} = -kx \quad\Rightarrow\quad m\ddot{x} + kx = 0$$

标准形式：
$$\ddot{x} + \omega_n^2 x = 0$$

### 1.2 固有频率 $\omega_n$

$$\boxed{\omega_n = \sqrt{\frac{k}{m}}}$$

- 单位：$\text{rad/s}$
- **系统固有属性**：仅取决于 $m$ 和 $k$，与初始条件无关

物理解释：
- $k$ 大（弹簧硬）→ $\omega_n$ 大 → 振动快
- $m$ 大（惯性大）→ $\omega_n$ 小 → 振动慢

**常用关系**：

| 表达式 | 含义 |
|--------|------|
| $f_n = \frac{1}{2\pi}\sqrt{k/m}$ | 固有频率 (Hz) |
| $T_n = 2\pi\sqrt{m/k}$ | 固有周期 (s) |
| $\omega_n = \sqrt{g/\delta_{st}}$ | 由静变形求频率 |

> **静变形法**：$\delta_{st} = mg/k$，则 $\omega_n = \sqrt{g/\delta_{st}}$。只需测量静变形即可得固有频率！

### 1.3 通解形式

特征方程：$s^2 + \omega_n^2 = 0 \;\Rightarrow\; s = \pm i\omega_n$

**形式一**（余弦+正弦）：
$$\boxed{x(t) = A\cos\omega_n t + B\sin\omega_n t}$$

**形式二**（幅值+相位）：
$$\boxed{x(t) = X\sin(\omega_n t + \phi)}$$

后者的优点是振幅 $X$ 和相位 $\phi$ 物理意义明确。转换关系：
$$X = \sqrt{A^2 + B^2}, \quad \phi = \arctan(A/B)$$

### 1.4 初始条件求解

给定 $x(0) = x_0$, $\dot{x}(0) = v_0$：

**用形式一求解**：
$$A = x_0, \quad B = \frac{v_0}{\omega_n}$$
$$x(t) = x_0\cos\omega_n t + \frac{v_0}{\omega_n}\sin\omega_n t$$

**用形式二**：
$$X = \sqrt{x_0^2 + (v_0/\omega_n)^2}, \quad \phi = \arctan\frac{\omega_n x_0}{v_0}$$

### 1.5 能量守恒

无阻尼系统机械能守恒：
$$E = T + V = \frac{1}{2}m\dot{x}^2 + \frac{1}{2}kx^2 = \text{const} = \frac{1}{2}kX^2$$

能量以 $2f_n$ 的频率在动能和势能之间交替转换：
- 平衡位置：全为动能 $T = T_{\max}$，$V = 0$
- 最大位移处：全为势能 $V = V_{\max}$，$T = 0$

## 2 等效刚度与等效质量

### 2.1 等效系统法步骤

1. **确定广义坐标**：选择一个能完整描述变形状态的位移
2. **计算等效刚度 $k_{eq}$**：施加单位位移，弹性恢复力大小
3. **计算等效质量 $m_{eq}$**：使等效系统的动能 = 原系统动能
4. **求固有频率**：$\omega_n = \sqrt{k_{eq}/m_{eq}}$

### 2.2 常见构型的等效刚度

| 构型 | 等效刚度 $k_{eq}$ | 记忆来源 |
|------|-------------------|---------|
| **悬臂梁端部** | $\dfrac{3EI}{L^3}$ | $\delta = PL^3/(3EI)$ |
| **简支梁中点** | $\dfrac{48EI}{L^3}$ | $\delta = PL^3/(48EI)$ |
| **两端固支梁中点** | $\dfrac{192EI}{L^3}$ | 约束最强 |
| **轴向拉伸杆** | $\dfrac{EA}{L}$ | Hooke 定律 |
| **扭转圆轴** | $\dfrac{GJ}{L}$ | 扭转公式 |

**记忆口诀**：编号 3 → 48 → 192，分母都是 $EI/L^3$。

### 2.3 扭转振动

转动运动方程：
$$J\ddot{\theta} + k_t\theta = 0$$

固有频率：$\omega_n = \sqrt{k_t/J}$

**平动-转动类比表**：

| 平动 | 转动 |
|------|------|
| 位移 $x$ | 角位移 $\theta$ |
| 质量 $m$ | 转动惯量 $J$ |
| 刚度 $k$ | 扭转刚度 $k_t$ |
| 力 $F$ | 转矩 $T$ |

### 2.4 能量法求等效参数

$$k_{eq} = \frac{2V_{\max}}{X^2}, \quad m_{eq} = \frac{2T_{\max}}{\omega_n^2 X^2}$$

对于有分布质量的梁，等效质量包含梁自身质量的贡献。例如悬臂梁端部质量系统：
$$m_{eq} = m_{\text{tip}} + \frac{33}{140}\rho A L \approx m_{\text{tip}} + 0.2357\,m_{\text{beam}}$$

## 3 有阻尼自由振动

### 3.1 运动方程与标准形式

引入粘性阻尼力 $F_d = c\dot{x}$：
$$m\ddot{x} + c\dot{x} + kx = 0$$

标准形式：
$$\boxed{\ddot{x} + 2\zeta\omega_n\dot{x} + \omega_n^2 x = 0}$$

其中：
- $\omega_n = \sqrt{k/m}$ —— 无阻尼固有频率
- $\zeta = \dfrac{c}{2m\omega_n} = \dfrac{c}{c_c}$ —— **阻尼比**
- $c_c = 2m\omega_n = 2\sqrt{km}$ —— **临界阻尼系数**

### 3.2 特征方程与根

设 $x = Ce^{st}$，代入得特征方程：
$$s^2 + 2\zeta\omega_n s + \omega_n^2 = 0$$

特征根：
$$s_{1,2} = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2 - 1}$$

根据 $\zeta$ 的大小，有三种情况：

### 3.3 欠阻尼 $0 < \zeta < 1$

$\sqrt{\zeta^2 - 1} = i\sqrt{1-\zeta^2}$，特征根为共轭复根：
$$s_{1,2} = -\zeta\omega_n \pm i\omega_d$$

其中 **有阻尼固有频率**：$\omega_d = \omega_n\sqrt{1-\zeta^2}$

通解：
$$\boxed{x(t) = e^{-\zeta\omega_n t}(A\cos\omega_d t + B\sin\omega_d t)}$$

或：
$$\boxed{x(t) = Xe^{-\zeta\omega_n t}\sin(\omega_d t + \phi)}$$

由初始条件：
$$A = x_0, \quad B = \frac{v_0 + \zeta\omega_n x_0}{\omega_d}$$

**欠阻尼振动特征**：
- 振幅按指数衰减：$Xe^{-\zeta\omega_n t}$
- 振动频率降低：$\omega_d < \omega_n$
- $\zeta \ll 1$ 时，$\omega_d \approx \omega_n$
- $\zeta \to 1$ 时，$\omega_d \to 0$（振动消失）

### 3.4 临界阻尼 $\zeta = 1$

特征根为重根：$s_1 = s_2 = -\omega_n$

通解：
$$\boxed{x(t) = (A + Bt)e^{-\omega_n t}}$$

由初始条件：$A = x_0$, $B = v_0 + \omega_n x_0$

**临界阻尼特性**：
- 无振荡
- **以最快速度返回平衡位置**（重要！）
- 工程仪表、车辆悬挂的理想状态

### 3.5 过阻尼 $\zeta > 1$

特征根为两个不相等的负实根：
$$s_{1,2} = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2 - 1} < 0$$

通解：
$$\boxed{x(t) = Ae^{s_1 t} + Be^{s_2 t}}$$

**过阻尼特性**：
- 无振荡
- 阻尼越大，返回越慢
- 极度过阻尼时，衰减由绝对值较小的 $s_2$ 主导

### 3.6 三种阻尼情况对比总结

| 阻尼范围 | 特征根 | 运动形态 | $\zeta$ 增大对返回速度的影响 |
|---------|--------|---------|--------------------------|
| $\zeta = 0$ | $\pm i\omega_n$ | 等幅振荡 | —— |
| $0<\zeta<1$ | 复根 | 衰减振荡 | 衰减加快 |
| $\zeta = 1$ | 重实根 | 无振荡，最快 | **临界点** |
| $\zeta > 1$ | 两负实根 | 无振荡，渐慢 | 越来越慢 |

### 3.7 对数衰减率 $\delta$

**定义**：相邻两同向峰值之比的自然对数
$$\boxed{\delta = \ln\frac{x_n}{x_{n+1}} = \frac{2\pi\zeta}{\sqrt{1-\zeta^2}}}$$

**近似公式**（$\zeta \ll 1$）：
$$\delta \approx 2\pi\zeta, \quad \zeta \approx \frac{\delta}{2\pi}$$

**多周期测量**（提高精度）：
$$\ln\frac{x_n}{x_{n+N}} = N\delta$$

**实验测定阻尼比的步骤**：
1. 记录自由振动衰减曲线
2. 测量一系列峰值 $x_1, x_2, \ldots, x_{N+1}$
3. 计算 $\delta = \frac{1}{N}\ln(x_1/x_{N+1})$
4. 由 $\zeta = \delta/\sqrt{4\pi^2 + \delta^2}$ 得阻尼比

## 4 能量法再论

### 4.1 Rayleigh 能量法

用于求复杂系统（非标准弹簧-质量）的固有频率。

**步骤**：
1. 假设运动形式 $x(t) = X\sin\omega_n t$
2. 计算最大动能 $T_{\max} = \frac{1}{2}m_{eq}(\omega_n X)^2$
3. 计算最大势能 $V_{\max} = \frac{1}{2}k_{eq}X^2$
4. 由 $T_{\max} = V_{\max}$ 解出 $\omega_n^2$

**关键**：假设振型要与实际振型接近。一般取**静变形曲线**效果较好。

### 4.2 等效阻尼的能量方法

对于非粘性阻尼（如库仑阻尼、结构阻尼），可定义**等效粘性阻尼**：

设一周期内耗散能量为 $\Delta W$（可由实验测得），等效阻尼系数为：
$$c_{eq} = \frac{\Delta W}{\pi\omega X^2}$$

由此可定义等效阻尼比：
$$\zeta_{eq} = \frac{c_{eq}}{2m\omega_n} = \frac{\Delta W}{2\pi m\omega_n\omega X^2}$$
