## 1. 两自由度系统的运动方程

### 1.1 运动方程的建立——直接法

#### 物理模型

```
墙 ---[k1, c1]--- [m1] ---[k2, c2]--- [m2] ---[k3, c3]--- 墙
                  ↑ F1(t)              ↑ F2(t)
```

#### Newton 第二定律

**质量 $m_1$**：

$$m_1\ddot{x}_1 = -k_1 x_1 - c_1\dot{x}_1 + k_2(x_2 - x_1) + c_2(\dot{x}_2 - \dot{x}_1) + F_1(t)$$

- $-k_1 x_1 - c_1\dot{x}_1$：墙对 $m_1$ 的弹性力和阻尼力
- $+k_2(x_2 - x_1) + c_2(\dot{x}_2 - \dot{x}_1)$：$m_2$ 通过中间弹簧/阻尼对 $m_1$ 的作用力（相对位移/速度）

**质量 $m_2$**：

$$m_2\ddot{x}_2 = -k_3 x_2 - c_3\dot{x}_2 - k_2(x_2 - x_1) - c_2(\dot{x}_2 - \dot{x}_1) + F_2(t)$$

整理为矩阵形式：

$$\begin{bmatrix} m_1 & 0 \\ 0 & m_2 \end{bmatrix} 
\begin{Bmatrix} \ddot{x}_1 \\ \ddot{x}_2 \end{Bmatrix} + 
\begin{bmatrix} c_1+c_2 & -c_2 \\ -c_2 & c_2+c_3 \end{bmatrix} 
\begin{Bmatrix} \dot{x}_1 \\ \dot{x}_2 \end{Bmatrix} + 
\begin{bmatrix} k_1+k_2 & -k_2 \\ -k_2 & k_2+k_3 \end{bmatrix} 
\begin{Bmatrix} x_1 \\ x_2 \end{Bmatrix} = 
\begin{Bmatrix} F_1(t) \\ F_2(t) \end{Bmatrix}$$

#### 一般形式

$$\boxed{\mathbf{M}\ddot{\mathbf{x}} + \mathbf{C}\dot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{F}(t)}$$

### 1.2 矩阵的性质

| 矩阵 | 符号 | 性质 |
|---|---|---|
| 质量矩阵 | $\mathbf{M}$ | 对角（集中质量）、正定 |
| 刚度矩阵 | $\mathbf{K}$ | 对称、正定（完全约束）或半正定（有刚体模态） |
| 阻尼矩阵 | $\mathbf{C}$ | 对称（比例阻尼），非对角元$<0$表示耦合 |

**刚度矩阵的物理含义**：

$$K_{ij} = \text{在自由度 } j \text{ 上产生单位位移所需在自由度 } i \text{ 上施加的力}$$

- 对角线 $k_{ii}$ -> 自刚度（刚度影响系数）
- 非对角线 $k_{ij}$ -> 互刚度（耦合刚度）
- $k_{ii} = \sum k_{\text{连接到 i}}$，$k_{ij} = -k_{\text{连接 i 和 j}}$（$i \neq j$）

### 1.3 方程的耦合形式

#### 静力耦合（刚度耦合）

$K$ 的非对角元 $\neq 0$。最常见的形式：质量通过弹簧连接，一个质量的位移产生对另一个质量的恢复力。

例：上述矩阵中 $K_{12} = K_{21} = -k_2 \neq 0$ -> 静力耦合。

#### 动力耦合（质量耦合）

$M$ 的非对角元 $\neq 0$。较罕见，出现在特定广义坐标下（悬挂摆的平动-转动耦合）。

#### 阻尼耦合

$C$ 的非对角元 $\neq 0$。非比例阻尼导致振型耦合（即振型不是纯实数）。

## 2. 无阻尼自由振动

### 2.1 特征值问题

无阻尼自由振动：$\mathbf{C} = \mathbf{0}$，$\mathbf{F} = \mathbf{0}$

设解为 $\mathbf{x}(t) = \mathbf{X} \sin(\omega t + \phi)$，代入 $\mathbf{M}\ddot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{0}$：

$$\boxed{(\mathbf{K} - \omega^2 \mathbf{M}) \mathbf{X} = \mathbf{0}}$$

这就是 **广义特征值问题**。

#### 频率方程

非零解条件（$\mathbf{X} \neq \mathbf{0}$）：

$$\boxed{\det(\mathbf{K} - \omega^2 \mathbf{M}) = 0}$$

对两自由度系统展开：

$$\det \begin{bmatrix} k_{11} - \omega^2 m_1 & k_{12} \\ k_{12} & k_{22} - \omega^2 m_2 \end{bmatrix} = 0$$

$$(k_{11} - \omega^2 m_1)(k_{22} - \omega^2 m_2) - k_{12}^2 = 0$$

这是 $\omega^2$ 的二次方程，两个正实根 $\omega_1^2 < \omega_2^2$：

$$\boxed{\omega_{1,2}^2 = \frac{1}{2}\left( \frac{k_{11}}{m_1} + \frac{k_{22}}{m_2} \right) \mp \frac{1}{2}\sqrt{\left( \frac{k_{11}}{m_1} - \frac{k_{22}}{m_2} \right)^2 + \frac{4k_{12}^2}{m_1 m_2}}}$$

**物理意义**：
- $\omega_1$（基频）：两质量同向振动时的固有频率
- $\omega_2$（高阶）：两质量反向振动时的固有频率（刚度"感觉上"更大）

### 2.2 固有振型（模态）

将 $\omega_i^2$ 代回特征方程，求振型（幅值比）：

$$\boxed{\frac{X_2^{(i)}}{X_1^{(i)}} = \frac{k_{11} - \omega_i^2 m_1}{-k_{12}}}$$

振型只确定到比例因子——乘任意常数仍是振型。

#### 两个振型

**第一阶振型**（$\omega_1$，基频）：
$$\mathbf{X}^{(1)} = \begin{Bmatrix} 1 \\ r_1 \end{Bmatrix},\qquad r_1 > 0$$
两个质量**同相**运动，位移符号相同。

**第二阶振型**（$\omega_2$）：
$$\mathbf{X}^{(2)} = \begin{Bmatrix} 1 \\ r_2 \end{Bmatrix},\qquad r_2 < 0$$
两个质量**反相**运动，位移符号相反。

### 2.3 节点与振型的物理意义

| 概念 | 说明 |
|---|---|
| **节点** | 振型中位移恒为零的位置。第一阶：0 个内部节点；第二阶：1 个内部节点 |
| **一般规律** | 第 $i$ 阶振型有 $i-1$ 个节点 |
| **振型激励** | 若初始条件按某阶振型，则系统纯粹以该频率振动（不激发其他频率） |
| **一般响应** | 一般初始条件 -> 各阶振型的线性组合（叠加原理） |

#### 为什么同相频率低，反相频率高？

同相振动时，中间弹簧 $(k_2)$ 基本不受拉伸/压缩，等效刚度较小 $\rightarrow \omega_1$ 低。

反相振动时，中间弹簧大幅压缩/拉伸，等效刚度较大 $\rightarrow \omega_2$ 高。

## 3. 模态的正交性

### 3.1 关于质量矩阵的正交性

这是振动理论中**最重要的性质**，使得模态叠加法成为可能。

#### 推导

由特征值问题的对称性：

$$\mathbf{K}\mathbf{X}^{(i)} = \omega_i^2 \mathbf{M}\mathbf{X}^{(i)}$$
$$\mathbf{K}\mathbf{X}^{(j)} = \omega_j^2 \mathbf{M}\mathbf{X}^{(j)}$$

第一式左乘 $(\mathbf{X}^{(j)})^{\top}$，第二式左乘 $(\mathbf{X}^{(i)})^{\top}$，利用 $\mathbf{K}$ 和 $\mathbf{M}$ 的对称性：

$$(\mathbf{X}^{(j)})^{\top}\mathbf{K}\mathbf{X}^{(i)} = \omega_i^2 (\mathbf{X}^{(j)})^{\top}\mathbf{M}\mathbf{X}^{(i)}$$
$$(\mathbf{X}^{(i)})^{\top}\mathbf{K}\mathbf{X}^{(j)} = \omega_j^2 (\mathbf{X}^{(i)})^{\top}\mathbf{M}\mathbf{X}^{(j)}$$

由于 $\mathbf{K}$ 对称，$(\mathbf{X}^{(j)})^{\top}\mathbf{K}\mathbf{X}^{(i)} = (\mathbf{X}^{(i)})^{\top}\mathbf{K}\mathbf{X}^{(j)}$，两式相减：

$$(\omega_i^2 - \omega_j^2) \cdot (\mathbf{X}^{(i)})^{\top}\mathbf{M}\mathbf{X}^{(j)} = 0$$

假设 $\omega_i \neq \omega_j$（不同频率），则必须：

$$\boxed{(\mathbf{X}^{(i)})^{\top} \mathbf{M} \mathbf{X}^{(j)} = 0, \qquad i \neq j}$$

**关于质量矩阵的正交性**。同样可推出：

$$\boxed{(\mathbf{X}^{(i)})^{\top} \mathbf{K} \mathbf{X}^{(j)} = 0, \qquad i \neq j}$$

**关于刚度矩阵的正交性**。

### 3.2 模态质量与模态刚度

当 $i=j$ 时：

| 量 | 定义 | 与单自由度类比 |
|---|---|---|
| 模态质量 | $m_i = (\mathbf{X}^{(i)})^{\top} \mathbf{M} \mathbf{X}^{(i)}$ | 等效质量 |
| 模态刚度 | $k_i = (\mathbf{X}^{(i)})^{\top} \mathbf{K} \mathbf{X}^{(i)}$ | 等效刚度 |
| 固有频率 | $\omega_i^2 = k_i / m_i$ | **和单自由度公式完全一致！** |

### 3.3 振型的归一化

由于振型只确定到比例因子，可任意归一：

| 方式 | 条件 | 用途 |
|---|---|---|
| 最大分量归一化 | $\max\|X^{(i)}\|=1$ | 一般分析 |
| 质量归一化 | $(\mathbf{X}^{(i)})^{\top}\mathbf{M}\mathbf{X}^{(i)} = 1$ | 模态叠加法（最常用） |
| 特定自由度归一化 | $X_1^{(i)} = 1$ | 教学演示 |

**正交归一化条件**（质量归一化后）：
$$\mathbf{\Phi}^{\top}\mathbf{M}\mathbf{\Phi} = \mathbf{I},\qquad \mathbf{\Phi}^{\top}\mathbf{K}\mathbf{\Phi} = \text{diag}(\omega_1^2, \omega_2^2)$$

## 4. 固有振型的物理意义与坐标变换

### 4.1 主坐标（模态坐标）

#### 模态矩阵

$$\mathbf{\Phi} = \begin{bmatrix} \mathbf{X}^{(1)} & \mathbf{X}^{(2)} \end{bmatrix}$$

#### 坐标变换

$$\boxed{\mathbf{x}(t) = \mathbf{\Phi} \mathbf{q}(t)}$$

其中 $\mathbf{q} = [q_1, q_2]^{\top}$ 称为 **主坐标** 或 **模态坐标**。

**物理意义**：
- $\mathbf{x}$（物理坐标）：每个质量的实际位移（耦合的、观察到的）
- $\mathbf{q}$（模态坐标）：各阶振型参与整体响应的"强度"（解耦的、内在的）
- 变换将耦合的物理运动"投影"到独立的模态子空间

逆变换：$\mathbf{q} = \mathbf{\Phi}^{-1}\mathbf{x}$（若 $\mathbf{\Phi}$ 非奇异）

### 4.2 运动方程的解耦

将 $\mathbf{x} = \mathbf{\Phi}\mathbf{q}$ 代入 $\mathbf{M}\ddot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{0}$，左乘 $\mathbf{\Phi}^{\top}$：

$$\mathbf{\Phi}^{\top}\mathbf{M}\mathbf{\Phi} \ddot{\mathbf{q}} + \mathbf{\Phi}^{\top}\mathbf{K}\mathbf{\Phi} \mathbf{q} = \mathbf{0}$$

利用正交性 -> 对角化：

$$\boxed{m_1 \ddot{q}_1 + k_1 q_1 = 0}$$
$$\boxed{m_2 \ddot{q}_2 + k_2 q_2 = 0}$$

等价于：
$$\ddot{q}_1 + \omega_1^2 q_1 = 0,\qquad \ddot{q}_2 + \omega_2^2 q_2 = 0$$

**结论**：在模态坐标中，两自由度系统分解为两个**独立的单自由度振子**！

- $q_1(t) = A_1\cos\omega_1 t + (B_1/\omega_1)\sin\omega_1 t$
- $q_2(t) = A_2\cos\omega_2 t + (B_2/\omega_2)\sin\omega_2 t$

回到物理坐标：
$$\mathbf{x}(t) = q_1(t)\mathbf{X}^{(1)} + q_2(t)\mathbf{X}^{(2)}$$

## 5. 强迫振动

### 5.1 无阻尼强迫振动——模态叠加法

外力 $\mathbf{F}(t)$ 作用下：

$$\mathbf{M}\ddot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{F}(t)$$

模态变换后左乘 $\mathbf{\Phi}^{\top}$：

$$m_i \ddot{q}_i + k_i q_i = (\mathbf{X}^{(i)})^{\top} \mathbf{F}(t) = f_i(t)$$

其中 $f_i(t) = (\mathbf{X}^{(i)})^{\top}\mathbf{F}(t)$ 称为**第 $i$ 阶模态力**。

#### 物理意义

- 模态力 = 外力在振型上的"投影"
- 若外力与某阶振型正交，则该阶模态不被激发
- 例：对称外力激发对称振型（一阶），反对称外力激发反对称振型（二阶）

#### 谐波激励稳态解

若 $\mathbf{F}(t) = \mathbf{F}_0 \sin\omega t$，每个解耦方程的标准稳态解：

$$q_i(t) = \frac{(\mathbf{X}^{(i)})^{\top} \mathbf{F}_0}{k_i - \omega^2 m_i} \sin\omega t$$

物理响应：
$$\mathbf{x}(t) = \sum_{i=1}^{2} \frac{(\mathbf{X}^{(i)})^{\top} \mathbf{F}_0}{k_i - \omega^2 m_i} \mathbf{X}^{(i)} \sin\omega t$$

### 5.2 动力吸振器（Dynamic Vibration Absorber, DVA）

#### 问题

主系统 $(m_1, k_1)$ 在 $\omega \approx \omega_{n1} = \sqrt{k_1/m_1}$ 附近共振，振幅极大。

**方案**：附加调谐的 $(m_2, k_2)$ 子系统 -> 在主系统固有频率处产生反共振点 -> $m_1$ 振幅为零。

#### 运动方程

主系统上加吸振器 $(m_2, k_2)$，$m_1$ 受 $F_0\sin\omega t$：

$$\begin{bmatrix} m_1 & 0 \\ 0 & m_2 \end{bmatrix}
\begin{Bmatrix} \ddot{x}_1 \\ \ddot{x}_2 \end{Bmatrix} + 
\begin{bmatrix} k_1+k_2 & -k_2 \\ -k_2 & k_2 \end{bmatrix}
\begin{Bmatrix} x_1 \\ x_2 \end{Bmatrix} = 
\begin{Bmatrix} F_0 \\ 0 \end{Bmatrix} \sin\omega t$$

#### 稳态解

$$\begin{bmatrix} k_1+k_2-\omega^2 m_1 & -k_2 \\ -k_2 & k_2-\omega^2 m_2 \end{bmatrix}
\begin{Bmatrix} X_1 \\ X_2 \end{Bmatrix} = 
\begin{Bmatrix} F_0 \\ 0 \end{Bmatrix}$$

解得：

$$X_1 = \frac{(k_2 - \omega^2 m_2)F_0}{(k_1+k_2-\omega^2 m_1)(k_2-\omega^2 m_2) - k_2^2}$$

$$X_2 = \frac{k_2 F_0}{(k_1+k_2-\omega^2 m_1)(k_2-\omega^2 m_2) - k_2^2}$$

#### 调谐条件

**使 $X_1 = 0$**：

**分子** $k_2 - \omega^2 m_2 = 0 \Rightarrow \boxed{\omega = \sqrt{k_2/m_2} = \omega_a}$

即吸振器的固有频率必须等于激励频率。

#### 设计步骤

1. 测量主系统固有频率 $\omega_{n1} = \sqrt{k_1/m_1}$（或确定关心的激励频率 $\omega$）
2. 选择质量比 $\mu = m_2/m_1$（通常 0.05~0.25）
3. 确定吸振器质量 $m_2 = \mu m_1$
4. 计算吸振器刚度 $k_2 = m_2 \omega^2$

#### 安装前后的频响变化

| 阶段 | 共振峰数量 | 主质量响应 |
|---|---|---|
| 安装前 | 1 个（$\omega_{n1}$） | 共振时极大 |
| 安装后 | 2 个（$\omega_{n1}$ 上下各一） | 原 $\omega_{n1}$ 处 $X_1=0$ |

**注意**：安装吸振器引入了两个新共振频率，如果激励频率变化（如变速机器），必须考虑这些新共振峰的位置。

#### 有阻尼吸振器

添加阻尼 $c_2$ 到吸振器中可拓宽有效频带但消不完全消除振动。最优阻尼（Den Hartog 公式）：

$$\zeta_{\text{opt}} = \sqrt{\frac{3\mu}{8(1+\mu)^3}}$$

## 6. Python 代码实现

### 6.1 两自由度系统固有频率和振型计算

```python
import numpy as np
from scipy.linalg import eigh  # 对称广义特征值（更稳定）

# ============ 系统参数 ============
m1, m2 = 10.0, 5.0          # 质量 (kg)
k1, k2, k3 = 1000.0, 500.0, 800.0  # 刚度 (N/m)

# 矩阵
M = np.array([[m1, 0.0],
              [0.0, m2]])
K = np.array([[k1 + k2, -k2],
              [-k2,     k2 + k3]])

# ============ 特征值求解 ============
# scipy.linalg.eigh 专用于对称广义特征值问题，结果按序排列
eigvals, eigvecs = eigh(K, M)  # omega^2 和对应的振型

omega_n = np.sqrt(eigvals)
f_n = omega_n / (2 * np.pi)

print("固有频率:")
for i, (w, f) in enumerate(zip(omega_n, f_n)):
    print(f"  第{i+1}阶: omega = {w:.4f} rad/s, f = {f:.4f} Hz")

print("\n固有振型 (已正交归一):")
for i in range(2):
    print(f"  phi_{i+1} = [{eigvecs[0, i]:.6f}, {eigvecs[1, i]:.6f}]")

# ============ 验证正交性 ============
print("\n正交性验证:")
print("Phi^T @ M @ Phi (应为单位阵):")
print(eigvecs.T @ M @ eigvecs)
print("\nPhi^T @ K @ Phi (应为 diag(omega^2)):")
print(eigvecs.T @ K @ eigvecs)
print(f"期望: diag({eigvals[0]:.4f}, {eigvals[1]:.4f})")
```

### 6.2 动力吸振器频响分析

```python
def dva_frequency_response(m1, k1, m2, k2, F0, omega_range):
    """
    计算动力吸振器系统的频响
    
    返回 X1, X2 在 omega_range 上的幅值
    """
    X1 = np.zeros(len(omega_range))
    X2 = np.zeros(len(omega_range))
    
    for i, w in enumerate(omega_range):
        # 动刚度矩阵 Z = K - w^2 M
        Z = np.array([[k1 + k2 - w**2 * m1, -k2],
                      [-k2,                  k2 - w**2 * m2]])
        F_vec = np.array([F0, 0.0])
        
        try:
            X = np.linalg.solve(Z, F_vec)
            X1[i] = abs(X[0])
            X2[i] = abs(X[1])
        except np.linalg.LinAlgError:
            X1[i] = np.inf
            X2[i] = np.inf
    
    return X1, X2

# 调用
omega = np.linspace(2, 30, 1000)
X1_dva, X2_dva = dva_frequency_response(10, 1000, 1, 100, 10, omega)

# 对比：无吸振器的原系统
omega_n1 = np.sqrt(1000/10)  # = 10 rad/s
print(f"原系统固有频率: {omega_n1:.2f} rad/s")
print(f"吸振器在 {omega_n1:.2f} rad/s 处: X1 ≈ {np.interp(omega_n1, omega, X1_dva):.4e}")
```

### 6.3 两自由度系统 Newmark-$\beta$ 法（通用）

```python
def newmark_beta_2dof(M, K, C, F, dt, beta=0.25, gamma=0.5):
    """
    Newmark-beta 法求解两自由度系统
    
    Parameters
    ----------
    M, K, C : (2, 2) ndarray  质量、刚度、阻尼矩阵
    F : (n, 2) ndarray        外力 [F1, F2]
    dt : float                时间步长
    
    Returns
    -------
    x, v, a : (n, 2) ndarray  位移、速度、加速度
    """
    n = len(F)
    x = np.zeros((n, 2))
    v = np.zeros((n, 2))
    a = np.zeros((n, 2))
    
    a[0] = np.linalg.solve(M, F[0] - C @ v[0] - K @ x[0])
    
    # 有效刚度 (恒定步长时可预分解)
    K_eff = K + gamma/(beta*dt) * C + 1/(beta*dt**2) * M
    K_eff_inv = np.linalg.inv(K_eff)  # 2x2 求逆很便宜
    
    a1 = 1/(beta*dt**2)
    a2 = 1/(beta*dt)
    a3 = 0.5/beta - 1
    b1 = gamma/(beta*dt)
    b2 = gamma/beta - 1
    b3 = dt * (0.5*gamma/beta - 1)
    
    for i in range(n - 1):
        F_eff = (F[i+1] + 
                 M @ (a1*x[i] + a2*v[i] + a3*a[i]) +
                 C @ (b1*x[i] + b2*v[i] + b3*a[i]))
        
        x[i+1] = K_eff_inv @ F_eff
        a[i+1] = a1*(x[i+1] - x[i]) - a2*v[i] - a3*a[i]
        v[i+1] = v[i] + (1-gamma)*dt*a[i] + gamma*dt*a[i+1]
    
    return x, v, a
```

### 6.4 模态叠加法时域求解

```python
def modal_superposition_2dof(M, K, F, t):
    """
    模态叠加法求解两自由度系统无阻尼响应
    """
    from scipy.linalg import eigh
    
    eigvals, phi = eigh(K, M)
    omega_n = np.sqrt(eigvals)
    
    n_dof = 2
    n_step = len(t)
    dt = t[1] - t[0]
    
    # 模态质量
    m_modal = np.array([phi[:, i] @ M @ phi[:, i] for i in range(n_dof)])
    
    # 模态力
    f_modal = F @ phi  # (n_step, 2)
    
    # 各模态的 Duhamel 积分
    q = np.zeros((n_step, n_dof))
    for mode in range(n_dof):
        omega = omega_n[mode]
        mi = m_modal[mode]
        
        for i in range(1, n_step):
            # 梯形积分
            tau = t[i] - t[:i+1]
            h_tau = np.sin(omega * tau) / (mi * omega)
            q[i, mode] = np.trapz(f_modal[:i+1, mode] * h_tau[::-1], 
                                  dx=dt) if i > 0 else 0.0
    
    # 回物理坐标
    x = (phi @ q.T).T  # (n_step, 2)
    return x, q, phi, omega_n
```

## 关键公式总结

| 公式类型 | 表达式 | 说明 |
|---|---|---|
| 矩阵运动方程 | $\mathbf{M}\ddot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{F}$ | 两自由度一般形式 |
| 特征值问题 | $(\mathbf{K} - \omega^2\mathbf{M})\mathbf{X} = \mathbf{0}$ | 求固有频率和振型 |
| 频率方程 | $\det(\mathbf{K} - \omega^2\mathbf{M}) = 0$ | 求 $\omega_1, \omega_2$ |
| 正交性（M） | $(\mathbf{X}^{(i)})^{\top}\mathbf{M}\mathbf{X}^{(j)} = 0\;(i\neq j)$ | 质量正交 |
| 正交性（K） | $(\mathbf{X}^{(i)})^{\top}\mathbf{K}\mathbf{X}^{(j)} = 0\;(i\neq j)$ | 刚度正交 |
| 模态变换 | $\mathbf{x} = \mathbf{\Phi}\mathbf{q}$ | 物理坐标 $\to$ 模态坐标 |
| 解耦方程 | $\ddot{q}_i + \omega_i^2 q_i = f_i/m_i$ | 独立单自由度 |
| 吸振器条件 | $\omega_a = \sqrt{k_2/m_2} = \omega$ | 反共振 |
