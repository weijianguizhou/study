# 随机振动初步

> **前置**：[[10-非线性振动初步|非线性振动]] | **后续**：[[12-振动控制与应用|振动控制]]

> 随机振动研究激励/响应具有随机性的系统振动问题。本章从随机过程统计描述出发，建立自相关函数、功率谱密度（PSD）及其在单自由度线性系统响应分析中的工程处理方法。

---

## 11.1 随机过程基础

### 确定性振动 vs 随机振动

| 性质 | 确定性振动 | 随机振动 |
|:---|:---|:---|
| 预测性 | 可精确预测 | 仅可统计描述 |
| 激励 | 简谐/周期/瞬态力 | 地震、风湍流、路面、波浪 |
| 响应表征 | 位移/速度时程 | 均值、方差、PSD、PDF |

### 随机过程三要素

- **样本函数（Sample Function）**：固定 $\omega$ 得到的时间函数 $x(t)$
- **系集（Ensemble）**：全部样本函数的集合
- **系集平均（Ensemble Average）**：固定时间 $t$，对全部样本函数取期望

### 平稳随机过程

**严平稳（Strict-sense Stationary, SSS）**：有限维联合分布对时移不变

**宽平稳（Wide-sense Stationary, WSS）**（工程常用）：
1. 均值 $\mu_X = \text{const}$（不随时间变化）
2. 自相关函数仅与时间差有关：$R_X(t_1,t_2) = R_X(\tau), \tau = t_2 - t_1$

### 各态历经性（Ergodicity）

单一样本的时间平均等于系集平均：
$$
\lim_{T \to \infty}\frac{1}{2T}\int_{-T}^{T} x(t)dt = \mu_X
$$
$$
\lim_{T \to \infty}\frac{1}{2T}\int_{-T}^{T} x(t)x(t+\tau)dt = R_X(\tau)
$$

**各态历经性假设的重要性**：工程师通常仅观测到一次实现（如一次地震记录），该假设允许用单个时间历程推断系集统计特性。

## 11.2 统计描述

### 均值与均方值

$$
\mu_X(t) = E[X(t)] = \int_{-\infty}^{\infty} x f_X(x,t)dx
$$

$$
\psi_X^{2}(t) = E[X^{2}(t)] = \int_{-\infty}^{\infty} x^{2} f_X(x,t)dx
$$

$\psi_X$ 称为**均方根值（RMS）**。

### 方差与标准差

$$
\sigma_X^{2}(t) = E[(X(t) - \mu_X)^{2}] = \psi_X^{2} - \mu_X^{2}
$$

对于零均值过程（$\mu_X = 0$），$\sigma_X^{2} = \psi_X^{2}$。振动信号处理中通常先去除均值（去趋势），得到零均值过程。

### 自相关函数（Autocorrelation Function）

$$
R_X(\tau) = E[X(t)X(t+\tau)]
$$

关键性质：
1. $R_X(0) = \psi_X^{2} \ge 0$（零时差给出均方值）
2. $R_X(\tau) = R_X(-\tau)$（偶函数）
3. $|R_X(\tau)| \le R_X(0)$（零时差最大）
4. $\lim_{\tau \to \infty} R_X(\tau) = \mu_X^{2}$（时差无关联，过程无周期成分）
5. 周期成分 $\implies$ 自相关函数也含同频周期成分

自相关函数的衰减速率对应过程的**带宽**：衰减越快 → 带宽越宽 → PSD 越平坦。

### 互相关函数（Cross-correlation Function）

$$
R_{XY}(\tau) = E[X(t)Y(t+\tau)]
$$

$$
R_{YX}(\tau) = R_{XY}(-\tau)
$$

两个过程独立时：$R_{XY}(\tau) = \mu_X\mu_Y$。

---

## 11.3 频域描述

### 功率谱密度（Power Spectral Density, PSD）

自相关函数的 Fourier 变换（Wiener-Khinchin 定理）：
$$
S_X(\omega) = \int_{-\infty}^{\infty} R_X(\tau)e^{-i\omega\tau}d\tau
$$
$$
R_X(\tau) = \frac{1}{2\pi}\int_{-\infty}^{\infty} S_X(\omega)e^{i\omega\tau}d\omega
$$

均方值 = 总功率 = PSD 的频率积分：
$$
\psi_X^{2} = R_X(0) = \frac{1}{2\pi}\int_{-\infty}^{\infty} S_X(\omega)d\omega
$$

**单侧谱**（$\omega \ge 0$）：$W_X(\omega) = 2 S_X(\omega)$

PSD 的物理意义：$S_X(\omega_0)\Delta\omega$ 为窄频带 $[\omega_0, \omega_0 + \Delta\omega]$ 内的平均功率贡献。

### 白噪声（White Noise）

理想化随机过程：所有频率上 PSD 为常数：
$$
S_X(\omega) = S_0 = \text{const}
$$
$$
R_X(\tau) = S_0\delta(\tau)
$$

任何两不同时刻的取值完全无关，均方值 $\psi_X^{2} \to \infty$（物理不可实现）。

**物理近似**：PSD 在远大于系统分析带宽的频率范围内保持平直的过程。

### 窄带与宽带过程

- **宽带过程**：PSD 分布在较宽频率范围，自相关函数衰减快
- **窄带过程**：能量集中在中心频率 $\omega_0$ 附近，自相关函数为衰减余弦：
  $$
  R_X(\tau) = \alpha e^{-\beta|\tau|}\cos(\omega_0\tau)
  $$

线性系统在宽带激励下的共振响应即为典型窄带过程。

## 11.4 线性系统对随机激励的响应

### 频率响应函数

单自由度系统：$m\ddot{x} + c\dot{x} + kx = f(t)$

$$
H(\omega) = \frac{1}{k - m\omega^{2} + i c\omega} = \frac{1/k}{1 - (\omega/\omega_n)^{2} + i\,2\zeta\omega/\omega_n}
$$

### 输入输出 PSD 关系

$$
\boxed{S_Y(\omega) = |H(\omega)|^{2} S_X(\omega)}
$$

$$
S_{XY}(\omega) = H(\omega) S_X(\omega)
$$

响应均方值：
$$
E[Y^{2}] = \frac{1}{2\pi}\int_{-\infty}^{\infty} |H(\omega)|^{2} S_X(\omega) d\omega
$$

系统的频率选择特性 $|H(\omega)|^{2}$ 对输入谱加权，总均方响应为各频率分量贡献之和。这就是随机振动分析的核心公式。

### SDOF 白噪声响应

设 $S_X(\omega) = S_0$（常数），则：
$$
E[Y^{2}] = \frac{\pi S_0}{c k}
$$

**关键结论**：位移均方响应与阻尼成反比（$E[Y^{2}] \propto 1/\zeta$）。在共振频带附近引入附加阻尼的效果最显著。

### 基座加速度激励

$$
S_x(\omega) = \frac{S_{\ddot{x}_g}(\omega)}{(\omega_n^{2} - \omega^{2})^{2} + (2\zeta\omega_n\omega)^{2}}
$$

## 11.5 疲劳与首次穿越问题

### 峰值分布（窄带 Gaussian 过程）

峰值概率密度服从 Rayleigh 分布：
$$
f_P(p) = \frac{p}{\sigma_X^{2}}\exp\left(-\frac{p^{2}}{2\sigma_X^{2}}\right), \quad p \ge 0
$$

### 穿越率（Rice 公式）

$$
\nu_{\alpha}^{+} = \nu_0 \exp\left(-\frac{\alpha^{2}}{2\sigma_X^{2}}\right)
$$

其中零穿越率：
$$
\nu_0 = \frac{1}{2\pi}\sqrt{\frac{\int_0^{\infty} \omega^{2}S_X(\omega)d\omega}{\int_0^{\infty} S_X(\omega)d\omega}}
$$

$\nu_0$ 约等于过程的表观频率。

### Miner 线性累积损伤理论

$$
D = \sum_i \frac{n_i}{N_i}
$$

$n_i$ 为应力水平 $S_i$ 下的实际循环次数，$N_i$ 为该水平的疲劳寿命（S-N 曲线）。$D = 1$ 时疲劳失效。

对窄带随机振动，结合 Basquin 形式的 S-N 曲线 $N(s) = C s^{-b}$ 及 Rayleigh 分布，可获得闭合的疲劳寿命预测公式。

### 首次穿越问题

阈值 $x = b$ 的可靠性函数：
$$
R(t) \approx \exp(-\nu_b^{+} t)
$$

失效率由穿越率 $\nu_b^{+}$ 直接给定。当 $b/\sigma_X \gg 1$ 时，假设穿越为 Poisson 过程，首次穿越时间近似为指数分布。

## 11.6 Python 代码

### 白噪声生成与 SDOF 随机响应模拟

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import welch, lsim, TransferFunction

np.random.seed(42)
fs, T = 200.0, 100.0
N = int(T * fs)
t = np.linspace(0, T, N)

wn = 2.0 * np.pi * 2.0
zeta = 0.05
m, k = 1.0, m * wn**2
c = 2 * zeta * m * wn
sys = TransferFunction([1.0], [m, c, k])

S0 = 0.5
dt = 1.0 / fs
white = np.sqrt(S0 * fs) * np.random.randn(N)

t_resp, x, _ = lsim(sys, U=white, T=t)

# PSD 估计 (Welch)
f_in, Pxx = welch(white, fs, nperseg=4096)
f_out, Pyy = welch(x, fs, nperseg=4096)

fig, axes = plt.subplots(2, 2, figsize=(12, 8))
axes[0,0].plot(t[-2000:], x[-2000:], lw=0.4)
axes[0,0].set_title('位移响应时程')
axes[0,1].hist(x, bins=60, density=True, alpha=0.7)
axes[0,1].set_title('位移概率密度')
axes[1,0].loglog(f_in, Pxx, lw=0.6, label='输入')
axes[1,0].loglog(f_out, Pyy, lw=0.8, label='输出')
axes[1,0].legend(); axes[1,0].set_title('PSD 对比 (Welch)')

# 理论 vs 模拟
f_theory = np.linspace(0.01, 5, 500)
w = 2.0 * np.pi * f_theory
H2 = np.abs(1.0 / (k - m*w**2 + 1j*c*w))**2
axes[1,1].plot(f_theory, S0 * H2, label='理论 $|H|^2S_0$')
axes[1,1].plot(f_out, Pyy, lw=0.6, alpha=0.7, label='Welch')
axes[1,1].legend(); axes[1,1].set_xlim(0, 5)
plt.tight_layout(); plt.show()
```

### PSD 估计（Welch 方法）与穿越率

```python
def crossing_rate(x, dt, level=0.0):
    upward = ((x[:-1] < level) & (x[1:] >= level)).sum()
    return upward / (len(x) * dt)

def spectral_moment(Sx, f, k):
    return np.trapz((2*np.pi*f)**k * Sx, f)

f, Pxx = welch(x, fs, nperseg=4096)
m0 = spectral_moment(Pxx, f, 0)
m2 = spectral_moment(Pxx, f, 2)
nu0_theory = np.sqrt(m2 / m0) / (2 * np.pi)
nu0_sim = crossing_rate(x, dt)
print(f"零穿越率: 理论={nu0_theory:.3f} Hz, 模拟={nu0_sim:.3f} Hz")

# 高于阈值的穿越率
b_levels = np.linspace(0.5, 3.0, 6) * np.sqrt(m0)
for bv in b_levels / np.sqrt(m0):
    nu = crossing_rate(x, dt, bv * np.sqrt(m0))
    print(f"  b/sigma={bv:.1f}, nu_b^+={nu:.4f} Hz")
```
