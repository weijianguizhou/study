## 12.2 隔振理论

### 力传递率（Force Transmissibility）

机器通过刚度 $k$、阻尼 $c$ 的隔振元件安装在基础上，在简谐激励 $F_0\sin\omega t$ 下，传递力与激振力的幅值比：

$$
\boxed{T_f = \frac{|F_T|_{\max}}{F_0} = \frac{\sqrt{1 + [2\zeta r]^{2}}}{\sqrt{[1 - r^{2}]^{2} + [2\zeta r]^{2}}}}
$$

其中 $r = \omega/\omega_n$ 为频率比，$\zeta = c/(2m\omega_n)$ 为阻尼比。

**关键特性**：
- 所有 $\zeta$ 曲线在 $r = \sqrt{2}$ 处相交于 $T_f = 1$（不变点）
- $r < \sqrt{2}$：传递率 $\ge 1$（无隔振效果，$T_f$ 可能 $> 1$）
- $r > \sqrt{2}$：$T_f < 1$，频率比越大、阻尼越小，隔振效果越优

### 隔振效率与设计准则

**设计原则**：
1. 选择隔振器使固有频率远低于工作频率：$r > 3 \sim 4$（传递率 < 10%）
2. 阻尼的权衡：共振区需大阻尼降低峰值；隔振区小阻尼提高效果
3. 静态变形约束：$k = mg/\delta_{\text{st}}$，过软隔振器造成过大下沉量

### 基础隔振

基础运动激励下位移传递率与力传递率形式完全相同。精密设备隔振需 $\omega_n \ll \omega$，即采用极软隔振器。

### 隔振材料选型

| 材料 | 阻尼比 $\zeta$ | 工作频率 | 特点 |
|:---|:---:|:---|:---|
| 天然/合成橡胶 | 0.05–0.15 | 5–30 Hz | 刚度形状可调 |
| 金属螺旋弹簧 | $\approx$ 0.005 | 宽频 | 大变形、承载力强 |
| 空气弹簧 | 0.03–0.10 | 1–2 Hz | 刚度极低、承载力可调 |
| 钢丝网垫 | 0.10–0.25 | 宽频 | 耐高温、耐腐蚀、干摩擦阻尼 |
| 双层隔振 | — | — | 高频衰减斜率 –40 dB/dec |

## 12.3 动力吸振器设计

### 无阻尼动力吸振器

主系统 $(m_1, k_1)$ 受简谐力激励，附加无阻尼吸振器 $(m_2, k_2)$。

**反共振条件**：当激励频率等于吸振器固有频率 $\omega = \omega_a = \sqrt{k_2/m_2}$ 时，主系统振幅 $X_1 = 0$。

主系统位移幅值：
$$
X_1 = \frac{(k_2 - m_2\omega^{2})F_0}{(k_1 + k_2 - m_1\omega^{2})(k_2 - m_2\omega^{2}) - k_2^{2}}
$$

### Den Hartog 最优调谐公式

有阻尼 DVA 的最优参数（$H_\infty$ 优化准则）：

定义参数：$\mu = m_2/m_1$（质量比）、$\alpha = \omega_a/\omega_1$（调谐比）

$$
\alpha_{\text{opt}} = \frac{1}{1 + \mu}
$$

$$
\zeta_{\text{opt}} = \sqrt{\frac{3\mu}{8(1+\mu)}}
$$

替代的 $H_2$ 优化（宽带激励均方响应最小化）：
$$
\alpha_{\text{opt}} = \frac{1}{\sqrt{1+\mu}}, \quad \zeta_{\text{opt}} = \sqrt{\frac{\mu(4+3\mu)}{8(1+\mu)(2+\mu)}}
$$

### 其他形式吸振器

- **多频吸振器**：并联多个不同调谐频率的 DVA 覆盖多共振峰
- **非线性吸振器（NES）**：立方非线性弹簧，能量靶向传递，宽频
- **分布式吸振器**：梁/板等连续结构的模态作为吸振器

## 12.4 阻尼技术

### 自由阻尼层（Free-layer Damping）

将黏弹性材料粘贴在结构表面，耗能来自拉伸/压缩变形。适用薄壁结构，厚度越大效果越优。

### 约束阻尼层（Constrained-layer Damping）

黏弹性层外覆刚性约束层（如铝板），迫使黏弹性层发生剪切变形。耗能效率远高于自由阻尼层，尤适用于低频。

### 黏弹性阻尼材料

复模量：$E^{*} = E(1 + i\eta)$，$\eta$ 为损耗因子。典型黏弹性材料 $\eta = 0.1 \sim 2.0$（金属仅为 $10^{-4} \sim 10^{-3}$）。

WLF 温度-频率等效方程：可在频率和温度间等效转换，设计者调节配方匹配工作条件。

## 12.5 振动主动控制简介

### 前馈控制（Feedforward）

检测与激励相关的参考信号，通过自适应 FIR 滤波器生成反相控制信号。对周期性激励效果极佳。

Filtered-X LMS 更新律：
$$
\mathbf{w}(n+1) = \mathbf{w}(n) + 2\mu e(n)\hat{\mathbf{r}}(n)
$$

- $\mathbf{w}$：FIR 系数向量
- $\hat{\mathbf{r}}(n)$：经次级通道模型滤波的参考信号
- $e(n)$：误差传感器信号

### LQR 最优反馈控制

系统状态方程 $\dot{\mathbf{x}} = \mathbf{Ax} + \mathbf{Bu}$：

最优控制律：$\mathbf{u} = -\mathbf{R}^{-1}\mathbf{B}^{T}\mathbf{Px}$

Riccati 方程：$\mathbf{A}^{T}\mathbf{P} + \mathbf{PA} - \mathbf{PBR}^{-1}\mathbf{B}^{T}\mathbf{P} + \mathbf{Q} = \mathbf{0}$

$\mathbf{Q}$ 为状态代价权重，$\mathbf{R}$ 为控制能量代价权重。

### PID 振动控制

$$
u(t) = K_p e(t) + K_i\int_0^{t} e(\tau)d\tau + K_d\frac{de}{dt}
$$

通常设置 $e(t) = 0 - y(t)$（零位归零）。通过试凑或 Ziegler-Nichols 方法整定增益。

> **溢出（Spillover）问题**：柔性结构中，控制力可能激发控制带宽外的高阶模态，导致闭环不稳定。解决方案包括低通滤波控制信号、采用搭配式传感器-作动器布局、引入观测器估计溢出模态。

### 压电材料

| 类型 | 特点 | 应用 |
|:---|:---|:---|
| PZT（锆钛酸铅） | 高机电耦合系数 | 高效作动器 |
| PVDF（聚偏氟乙烯） | 柔性，可粘贴曲面 | 分布式传感器 |
| MFC（宏纤维复合材料） | 纤维压电，柔顺+大驱动力 | 结构控制作动器 |

## 12.6 工程案例分析

### 案例一：建筑物抗震——TMD 调谐质量阻尼器

**台北 101 大楼**（508 m）在第 87–92 层悬挂 660 吨钢球 TMD：
- 摆长约 11.5 m，调谐至 0.15 Hz（结构一阶弯曲模态，周期约 6.7 s）
- 8 个油压阻尼器提供附加阻尼
- 台风季最大振幅 $\pm 1$ m；削减楼层加速度约 30–40%

TMD 最优调谐（$H_\infty$ 准则）：
$$
f_{\text{TMD}} = f_{\text{结构}} \cdot \frac{1}{1 + \mu_{\text{eff}}}
$$
$$
\zeta_{\text{opt}} = \sqrt{\frac{3\mu_{\text{eff}}}{8(1+\mu_{\text{eff}})}}
$$

有效质量比 $\mu_{\text{eff}}$ 一般取值 $0.01 \sim 0.05$。

### 案例二：转子动力学基础——Jeffcott 转子

刚性圆盘（质量 $m$，质心偏心 $\varepsilon$）装在弹性轴上，Jeffcott 转子在固定坐标系下的运动方程：

$$
m\ddot{x} + c\dot{x} + kx = m\varepsilon\Omega^{2}\cos\Omega t + mg
$$
$$
m\ddot{y} + c\dot{y} + ky = m\varepsilon\Omega^{2}\sin\Omega t
$$

- **临界转速**：$\Omega = \omega_n$ 时振幅剧增
- 启动应迅速穿越临界转速
- 超临界转速：**自定心效应**——质心位移趋于零，几何中心绕质心旋转
- 动平衡目的是将残留偏心 $\varepsilon$ 压至容许值以下
- 相频分析：亚临界 $x$ 与激励同相，超临界反相（$180^{\circ}$ 相位翻转）

### 案例三：1/4 车辆模型

二自由度车辆悬挂模型：
- $m_s$：悬挂质量（车身）
- $m_u$：非悬挂质量（车轮+车轴）
- $k_s, c_s$：悬挂弹簧/阻尼器
- $k_t, c_t$：轮胎刚度/阻尼

运动方程：
$$
m_s\ddot{x}_s + c_s(\dot{x}_s - \dot{x}_u) + k_s(x_s - x_u) = 0
$$
$$
m_u\ddot{x}_u + c_s(\dot{x}_u - \dot{x}_s) + k_s(x_u - x_s) + k_t(x_u - y_r) + c_t(\dot{x}_u - \dot{y}_r) = 0
$$

设计准则的双重制约：
1. **乘坐舒适性**：车身加速度 RMS 最小
2. **行驶安全性**：轮胎动态载荷 RMS 最小（维持接地力）

低频段（< 5 Hz）舒适性与安全性折中最为突出。

### 案例四：Tacoma Narrows 桥梁风致振动

1940 年 11 月 7 日大桥在约 19 m/s 风速下发生扭转颤振并倒塌。

**气动弹性力学机理**：超过临界风速后，主梁气动自激力与结构模态耦合，产生负阻尼效应（有效阻尼由正变负），从气流中持续注入能量 → 振幅指数增长 → 结构失效。

**现代抗风设计对策**：
1. CFD + 风洞试验确定临界风速
2. 主梁断面气动优化（风嘴 → 流线型截面）
3. 机翼型截面提高颤振临界风速
4. TMD / TLCD 附加阻尼
5. 涡激振动（VIV）规避设计（Scruton 数）

## 12.7 Python 代码

### 力传递率曲线

```python
import numpy as np
import matplotlib.pyplot as plt

def transmissibility(r, zeta):
    return np.sqrt(1 + (2*zeta*r)**2) / np.sqrt((1 - r**2)**2 + (2*zeta*r)**2)

r = np.linspace(0, 5, 500)
for z in [0.0, 0.05, 0.1, 0.2, 0.5, 1.0]:
    plt.plot(r, transmissibility(r, z), label=f'$\\zeta={z}$')

plt.axhline(1, color='gray', ls='--')
plt.axvline(np.sqrt(2), color='gray', ls='--')
plt.text(np.sqrt(2)+0.1, 0.15, '$\\sqrt{2}$', fontsize=12)
plt.xlabel('$\\omega/\\omega_n$'); plt.ylabel('$T_f$')
plt.title('力传递率曲线'); plt.legend(); plt.grid(alpha=0.3)
plt.ylim(0, 5); plt.tight_layout(); plt.show()
```

### TMD 最优参数与幅频响应

```python
def tmd_optimal(mu):
    return 1.0/(1.0 + mu), np.sqrt(3*mu/(8*(1+mu)))

def tmd_amplification(r, mu, alpha, zeta_a):
    A = 1 - r**2; B = 2 * zeta_a * r; C = mu * r**2
    D = alpha**2 - r**2; E = 2 * zeta_a * r
    num = np.sqrt(A**2 + B**2)
    den = np.sqrt((A*D - B*E - C*(1-alpha**2))**2 + (A*E + B*D)**2)
    return num / den

r = np.linspace(0.5, 1.5, 500)
for mu in [0.01, 0.05, 0.1]:
    alpha, zeta = tmd_optimal(mu)
    plt.plot(r, tmd_amplification(r, mu, alpha, zeta),
             label=f'$\\mu={mu}$')
plt.axvline(1, color='gray', ls='--')
plt.xlabel('$\\omega/\\omega_1$'); plt.ylabel('$|X_1|/(F_0/k_1)$')
plt.legend(); plt.grid(alpha=0.3); plt.tight_layout(); plt.show()
```
