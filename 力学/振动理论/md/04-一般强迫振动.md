## 1. 周期激励的 Fourier 级数解法

### 1.1 Fourier 级数的基本概念

#### 物理背景

实际工程中许多激励力具有周期性：
- 旋转机械的不平衡力（转速恒定）
- 往复式发动机的惯性力
- 曲柄连杆机构的周期性载荷
- 齿轮啮合力

#### 数学定义

任何满足 **Dirichlet 条件** 的周期函数 $F(t)$（周期 $T = 2\pi/\omega$）可展开为 Fourier 级数：

$$F(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \bigl( a_n \cos n\omega t + b_n \sin n\omega t \bigr)$$

其中 $\omega = 2\pi/T$ 称为 **基频**，$n\omega$ 为第 $n$ 次 **谐波频率**。

Fourier 系数由正交性积分给出：

$$a_n = \frac{2}{T}\int_{0}^{T} F(t) \cos n\omega t \,dt, \quad n=0,1,2,\ldots$$

$$b_n = \frac{2}{T}\int_{0}^{T} F(t) \sin n\omega t \,dt, \quad n=1,2,3,\ldots$$

#### Dirichlet 条件

函数 $F(t)$ 在周期 $T$ 内：
1. 绝对可积
2. 有限个极大值和极小值
3. 有限个第一类间断点

工程中的连续和分段连续函数均满足。

#### 物理意义

- $a_0/2$：力的**静载分量**（时间平均值）
- $a_n \cos n\omega t + b_n \sin n\omega t$：第 $n$ 次谐波分量，频率为基频的 $n$ 倍
- $F_n = \sqrt{a_n^2 + b_n^2}$：第 $n$ 次谐波的幅值
- $\phi_{Fn} = \arctan(a_n/b_n)$：第 $n$ 次谐波的相位

**等价正弦形式**：

$$F(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} F_n \sin(n\omega t + \phi_{Fn})$$

### 1.2 叠加原理与总响应

#### 核心思想

线性系统的最大优势：**叠加原理**。将复杂的周期力分解为若干简单谐波力，分别求各自的稳态响应，再叠加。

#### 运动方程

$$m\ddot{x} + c\dot{x} + kx = \frac{a_0}{2} + \sum_{n=1}^{\infty} (a_n \cos n\omega t + b_n \sin n\omega t)$$

#### 各分量响应

**静载响应**（$a_0/2$）：
$$x_0 = \frac{a_0}{2k}$$

**第 $n$ 次谐波响应**：

引入频率比 $r_n = \frac{n\omega}{\omega_n}$：

$$X_n = \frac{F_n/k}{\sqrt{(1 - r_n^2)^2 + (2\zeta r_n)^2}}$$

$$\phi_n = \arctan\frac{2\zeta r_n}{1 - r_n^2}$$

**总稳态响应**：

$$x(t) = \frac{a_0}{2k} + \sum_{n=1}^{\infty} \frac{F_n/k}{\sqrt{(1 - r_n^2)^2 + (2\zeta r_n)^2}} \sin\bigl( n\omega t + \phi_{Fn} - \phi_n \bigr)$$

其中 $F_n = \sqrt{a_n^2 + b_n^2}$，$\phi_{Fn} = \arctan(a_n/b_n)$（注意象限）。

### 1.3 截断与收敛性讨论

#### 收敛率

| Fourier 系数的衰减 | $a_n, b_n$ 渐近行为 | 对应函数特征 |
|---|---|---|
| 快速 | $\sim O(1/n^2)$ | 连续且分段光滑 |
| 中速 | $\sim O(1/n)$ | 存在跳跃间断 |
| 缓慢 | 更慢 | 存在脉冲类尖峰 |

#### Gibbs 现象

在间断点处，Fourier 级数的部分和出现过冲，幅值约为跳变的 **9%**。增加项数只减小过冲宽度，不减小过冲幅值。

#### 工程截断准则

由于单自由度系统的**低通滤波**特性（$|H(\omega)| \to 0$ 当 $\omega \gg \omega_n$），高频分量贡献很小。

**实用截断准则**：取前 $N$ 阶，使得
$$r_N = \frac{N\omega}{\omega_n} \geq 3 \sim 5$$

即最高谐波频率超过固有频率 3~5 倍。

## 2. 单位脉冲响应

### 2.1 Dirac $\delta$ 函数的定义与性质

#### 核心概念

$\delta(t - \tau)$ 不是普通函数，而是**广义函数（分布）**，描述 $t=\tau$ 时刻集中作用的单位冲量。

#### 定义

$$\delta(t - \tau) = 0, \qquad t \neq \tau$$

$$\int_{-\infty}^{\infty} \delta(t - \tau)\,dt = 1$$

#### 筛选性质（最重要）

$$\int_{-\infty}^{\infty} f(t)\,\delta(t - \tau)\,dt = f(\tau)$$

$\delta$ 函数从 $f(t)$ 中"筛选"出 $t=\tau$ 时刻的值。→ 这是建立卷积积分的数学基础。

#### 物理诠释

- **量纲**：$[\delta] = [\text{时间}]^{-1}$（积分等于 1，无单位）
- **物理近似**：锤击力（极短时间、极大峰值，冲量固定）
- $\delta(t-\tau)$：在 $t=\tau$ 时刻作用的**单位脉冲力**（冲量 = 1 N·s）

#### 函数序列极限表示

**矩形脉冲序列**：
$$\delta(t) = \lim_{\varepsilon \to 0} \frac{1}{\varepsilon}\bigl[ H(t) - H(t-\varepsilon) \bigr],\quad H \text{ 为 Heaviside 阶跃函数}$$

**高斯函数极限**：
$$\delta(t) = \lim_{\sigma \to 0} \frac{1}{\sqrt{2\pi}\,\sigma} e^{-t^2/(2\sigma^2)}$$

#### $\delta'(t)$ 的物理意义

$\delta'(t)$（$\delta$ 的导数）表示**力偶**（一对大小相等、方向相反、无限靠近的脉冲），在弯矩激励问题中有应用。

### 2.2 脉冲响应函数的推导

#### 问题提法

欠阻尼单自由度系统在 $t=0$ 时刻受单位脉冲作用：

$$m\ddot{x} + c\dot{x} + kx = \delta(t), \qquad x(0^-) = \dot{x}(0^-) = 0$$

#### 关键分析：$t=0$ 处积分

在 $[0^-, 0^+]$ 上积分运动方程：

$$\int_{0^-}^{0^+} \! m\ddot{x}\,dt + \int_{0^-}^{0^+} \! c\dot{x}\,dt + \int_{0^-}^{0^+} \! kx\,dt = \int_{0^-}^{0^+} \! \delta(t)\,dt = 1$$

逐项分析：
- $\int kx\,dt = 0$（$x$ 连续，无穷小区间积分 → 0）
- $\int c\dot{x}\,dt = c[x(0^+) - x(0^-)] = 0$（$x$ 连续，区间趋于零时跳跃为零）
- $\int m\ddot{x}\,dt = m[\dot{x}(0^+) - \dot{x}(0^-)] = 1$

#### 等效初始条件

$$x(0^+) = 0, \qquad \dot{x}(0^+) = \frac{1}{m}$$

**物理意义**：脉冲瞬间使质量获得了速度 $1/m$，位移来不及变化。→ 等效为**具有初速度 $1/m$ 的自由振动问题**。

#### 脉冲响应函数（Impulse Response Function, IRF）

$$h(t) = \frac{1}{m\omega_d} e^{-\zeta\omega_n t} \sin\omega_d t, \qquad t > 0$$

且 $h(t) = 0$ 对 $t < 0$（**因果性**）。

式中 $\omega_d = \omega_n\sqrt{1-\zeta^2}$ 为有阻尼固有频率。

### 2.3 脉冲响应函数的性质与物理意义

| 性质 | 数学表达 | 物理意义 |
|---|---|---|
| 因果性 | $h(t)=0,\; t<0$ | 系统不能在激励之前响应 |
| 时不变性 | 脉冲在 $\tau$ 时刻 → 响应为 $h(t-\tau)$ | 系统特性不随时间变化 |
| 记忆衰减 | $|h(t)| \sim e^{-\zeta\omega_n t}$ | 脉冲的影响随时间指数衰减 |
| 稳态增益 | $\int_0^\infty h(t)\,dt = 1/k$ | 单位脉冲总位移 = 静柔度 |
| 与传递函数 | $\mathcal{L}\{h(t)\} = H(s) = 1/(ms^2+cs+k)$ | IRF 的 Laplace 变换 = 传递函数 |

#### "记忆"的物理类比

系统像有"记性"——一次锤击后，系统以指数衰减的正弦波"记得"这次扰动。
- **记忆强度**：由衰减指数 $\zeta\omega_n$ 决定，阻尼越大忘得越快
- **回忆频率**：以 $\omega_d$ 的频率振荡
- **记忆容量（总位移）**：$\int_0^\infty h(t)\,dt = 1/k$，就是静柔度

## 3. 任意激励的响应——卷积积分（Duhamel 积分）

### 3.1 基本思想：脉冲序列的叠加

#### 核心思路

任意力 $F(t)$ = 一系列时间上连续、幅值 $F(\tau)$ 的脉冲的连续和。

在 $t=\tau$ 时刻、宽度 $d\tau$ 的脉冲，**冲量** = $F(\tau)\,d\tau$。

该微元在 $t$ 时刻产生的响应微元：
$$dx(t) = F(\tau)\,d\tau \cdot h(t-\tau)$$

将所有 $\tau \in [0,t]$ 的脉冲微元累加：

$$x(t) = \int_{0}^{t} F(\tau)\,h(t-\tau)\,d\tau$$

这就是 **Duhamel 积分**（卷积积分）。

#### Duhamel 积分完整形式

将 $h(t)$ 代入，得到欠阻尼系统的完整响应公式：

$$x(t) = \frac{1}{m\omega_d} \int_{0}^{t} F(\tau)\, e^{-\zeta\omega_n (t-\tau)} \sin\bigl[ \omega_d (t-\tau) \bigr]\,d\tau$$

加上初始条件的影响（自由振动项）：

$$x(t) = e^{-\zeta\omega_n t}\Bigl( x_0 \cos\omega_d t + \frac{\dot{x}_0 + \zeta\omega_n x_0}{\omega_d}\sin\omega_d t \Bigr) + \text{Duhamel 积分项}$$

#### 交换对称形式

$$x(t) = \int_{0}^{t} F(t-\tau)\,h(\tau)\,d\tau$$

两种形式等价，离散化时按方便选择。

### 3.2 阶跃响应（Step Response）

#### 激励：$F(t) = F_0 H(t)$

**工程意义**：突然施加的恒定力（如突然放置重物、突然通电的电磁力）。

#### 推导

代入 Duhamel 积分：

$$x(t) = \frac{F_0}{m\omega_d} \int_{0}^{t} e^{-\zeta\omega_n (t-\tau)} \sin\omega_d (t-\tau)\,d\tau$$

令 $u = t-\tau$，$du = -d\tau$：

$$x(t) = \frac{F_0}{m\omega_d} \int_{0}^{t} e^{-\zeta\omega_n u} \sin\omega_d u\,du$$

积分公式（$\int e^{ax}\sin bx\,dx$ 型）得结果：

$$x(t) = \frac{F_0}{k} \Bigl[ 1 - e^{-\zeta\omega_n t}\Bigl( \cos\omega_d t + \frac{\zeta}{\sqrt{1-\zeta^2}} \sin\omega_d t \Bigr) \Bigr]$$

#### 物理特征

| 物理量 | 公式 | 说明 |
|---|---|---|
| 稳态位移 | $x_{\text{ss}} = F_0/k$ | = 静力作用下的位移 |
| 最大超调（$\zeta=0$） | $x_{\max} = 2F_0/k$ | 100% 超调（无阻尼） |
| 稳定时间 | $t_s \approx 4/(\zeta\omega_n)$ | 响应进入 ±2\% 误差带 |

### 3.3 斜坡响应（Ramp Response）

#### 激励：$F(t) = \alpha t H(t)$

**工程意义**：匀速加载（材料试验机加载、缓慢施加的风荷载）。

#### 结果

$$x(t) = \frac{\alpha}{k} \Bigl[ t - \frac{2\zeta}{\omega_n} + e^{-\zeta\omega_n t}\Bigl( \frac{2\zeta}{\omega_n}\cos\omega_d t + \frac{2\zeta^2-1}{\omega_d}\sin\omega_d t \Bigr) \Bigr]$$

#### 物理特征

- 稳态响应：$x_{\text{ss}}(t) = \frac{\alpha}{k}\bigl(t - \frac{2\zeta}{\omega_n}\bigr)$ — 与输入平行的斜坡
- **固定滞后**：$\Delta t_{\text{lag}} = 2\zeta/\omega_n$ — 阻尼的耗能导致系统"跟不上"
- 阻尼越大，滞后越大；$\zeta=0$ 时无滞后

## 4. 频域方法——Fourier 变换

### 4.1 从时域到频域

对于非周期激励（瞬态冲击、地震波、风荷载等），不能直接用 Fourier 级数，需要 Fourier 变换（积分）。

#### Fourier 变换对

$$\hat{F}(\omega) = \mathcal{F}\{F(t)\} = \int_{-\infty}^{\infty} F(t)\, e^{-i\omega t}\,dt$$

$$F(t) = \mathcal{F}^{-1}\{\hat{F}(\omega)\} = \frac{1}{2\pi} \int_{-\infty}^{\infty} \hat{F}(\omega)\, e^{i\omega t}\,d\omega$$

**频谱**：$\hat{F}(\omega)$ 一般为复值函数
- 幅值谱：$|\hat{F}(\omega)|$（频率成分的"强度"）
- 相位谱：$\angle\hat{F}(\omega)$（各频率成分的相移）
- 能量谱密度：$|\hat{F}(\omega)|^2$

### 4.2 频响函数 $H(\omega)$ 与频域求解

对方程 $m\ddot{x} + c\dot{x} + kx = F(t)$ 两边作 Fourier 变换，利用 $\mathcal{F}\{\ddot{x}\} = -\omega^2\hat{X}$，$\mathcal{F}\{\dot{x}\} = i\omega\hat{X}$：

$$(-m\omega^2 + ic\omega + k)\hat{X}(\omega) = \hat{F}(\omega)$$

#### 频响函数（Frequency Response Function, FRF）

$$H(\omega) = \frac{1}{-m\omega^2 + ic\omega + k} = \frac{1/k}{1 - r^2 + 2i\zeta r}, \qquad r = \frac{\omega}{\omega_n}$$

#### 核心关系

$$\hat{X}(\omega) = H(\omega) \cdot \hat{F}(\omega)$$

**时域的卷积 = 频域的乘积！** → 极简形式

时域响应：$x(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} H(\omega)\,\hat{F}(\omega)\, e^{i\omega t}\,d\omega$

### 4.3 $H(\omega)$ 的物理意义

| 特性 | 公式 | 物理含义 |
|---|---|---|
| 幅频 | $\|H(\omega)\| = \frac{1/k}{\sqrt{(1-r^2)^2+(2\zeta r)^2}}$ | 增益（输出/输入幅值比） |
| 相频 | $\angle H(\omega) = -\arctan\frac{2\zeta r}{1-r^2}$ | 输出滞后输入的相位 |
| 共振增益 | $\|H(\omega_n)\| = \frac{1}{2k\zeta}$ | 小阻尼时极大 |
| 半功率带宽 | $\Delta\omega \approx 2\zeta\omega_n$ | 衡量"尖锐程度" |
| 与传递函数 | $H(\omega) = H(s)\|_{s=i\omega}$ | FRF = 传递函数沿虚轴 |

### 4.4 Fourier 变换法 vs Duhamel 积分

| 方面 | Duhamel 积分（时域） | Fourier 变换（频域） |
|---|---|---|
| 物理直观性 | 高（脉冲叠加） | 中（频谱叠加） |
| 解析激励 | 可处理 | 需有解析 Fourier 变换 |
| 实测时程数据 | 需逐步积分 | FFT 极高效 |
| 非线性/时变系统 | 可适应 | 不适用 |

## 5. 冲击响应谱（Shock Response Spectrum）

### 5.1 定义与基本概念

#### 问题

冲击是极短时间内的剧烈力/加速度变化。不同频率的结构对同一冲击的响应完全不同。→ 冲击响应谱刻画这一关系。

#### 定义

$$S_d(\omega_n, \zeta) = \max_{t} |x(t; \omega_n, \zeta)|$$

即一系列不同 $\omega_n$ 的单自由度振子在同一冲击下的最大位移响应。

#### 三种谱

| 名称 | 定义 | 物理意义 |
|---|---|---|
| 位移谱 $S_d$ | $\max\|x(t)\|$ | 最大相对位移 |
| 伪速度谱 $S_v$ | $\omega_n S_d$ | 与最大应变能相关 |
| 伪加速度谱 $S_a$ | $\omega_n^2 S_d$ | 与最大惯性力（基底剪力）相关 |

#### 三分区特性

- **低频（等位移区）**：$S_d \approx$ 常值（冲击的总位移量）
- **中频（等速度区）**：$S_v \approx$ 常值
- **高频（等加速度区）**：$S_a \approx$ 常值（输入加速度峰值）

### 5.2 半正弦脉冲的冲击响应谱

激励：$F(t) = F_0\sin(\pi t/t_d)$，$0 \leq t \leq t_d$

无阻尼位移响应（闭合形式）：

$$x(t) = \frac{F_0/k}{1 - (\frac{2\tau}{\pi})^2} \Bigl[ \sin\frac{\pi t}{t_d} - \frac{2\tau}{\pi}\sin(2\pi t/T_n) \Bigr], \quad t \leq t_d$$

$$x(t) = \frac{(F_0/k) \cdot 2\frac{2\tau}{\pi}}{(\frac{2\tau}{\pi})^2 - 1} \cos\frac{\pi t_d}{T_n} \sin\frac{2\pi}{T_n}(t - \frac{t_d}{2}), \quad t \geq t_d$$

其中 $\tau = t_d/T_n$。

#### 特征

- **短脉冲**（$t_d/T_n \ll 1$）：$S_d \approx 2I/(m\omega_n)$（冲量控制）
- **长脉冲**（$t_d/T_n \gg 1$）：$S_d \approx 2F_0/k$（静力幅值控制）
- **最大动态放大因子**：约 **1.75**（$t_d/T_n \approx 0.7$）

### 5.3 矩形脉冲与三角脉冲的冲击响应谱

| 脉冲形状 | 最大动态放大因子 | 说明 |
|---|---|---|
| 矩形 $F(t)=F_0,\; 0<t<t_d$ | **~2.0** | 最尖锐的加载/卸载 → 最大放大 |
| 半正弦 $F_0\sin(\pi t/t_d)$ | **~1.75** | 中等尖锐 |
| 三角 $F_0(1-\|2t/t_d-1\|)$ | **~1.5** | 最平滑 → 最小放大 |

**一般性原理**：冲击的尖锐程度（高频含量）决定最大响应。越尖锐 → 高频分量越多 → 最大放大因子越大。

## 6. 数值方法

### 6.1 基本思路

当 $F(t)$ 为实测离散数据或过于复杂无法解析积分时，将时间离散为步长 $\Delta t$ 的序列，在每个步长内近似积分并递推。

### 6.2 Newmark-$\beta$ 法

#### 基本递推公式

$$\dot{x}_{n+1} = \dot{x}_n + (1-\gamma)\Delta t\,\ddot{x}_n + \gamma\Delta t\,\ddot{x}_{n+1}$$

$$x_{n+1} = x_n + \Delta t\,\dot{x}_n + \Bigl(\frac{1}{2} - \beta\Bigr)\Delta t^2\,\ddot{x}_n + \beta\Delta t^2\,\ddot{x}_{n+1}$$

#### 参数选择

| $\beta$ | $\gamma$ | 方法名 | 稳定性 |
|---|---|---|---|
| 1/4 | 1/2 | 平均加速度法 | **无条件稳定** |
| 1/6 | 1/2 | 线性加速度法 | 条件稳定 $\Delta t/T_n \leq 0.55$ |
| 1/12 | 1/2 | Fox-Goodwin | 条件稳定 |

**最常用**：$\beta=1/4$，$\gamma=1/2$（平均加速度法，无条件稳定）。

### 6.3 Runge-Kutta 法

将二阶 ODE 化为一阶状态空间方程组：

$$\frac{d}{dt} \begin{pmatrix} x \\ \dot{x} \end{pmatrix} = \begin{pmatrix} \dot{x} \\ \frac{1}{m}(F(t) - c\dot{x} - kx) \end{pmatrix}$$

即 $\dot{\mathbf{y}} = \mathbf{f}(t, \mathbf{y})$。

标准 RK4：

$$\mathbf{k}_1 = \Delta t \cdot \mathbf{f}(t_n, \mathbf{y}_n)$$
$$\mathbf{k}_2 = \Delta t \cdot \mathbf{f}(t_n + \tfrac{\Delta t}{2}, \mathbf{y}_n + \tfrac{1}{2}\mathbf{k}_1)$$
$$\mathbf{k}_3 = \Delta t \cdot \mathbf{f}(t_n + \tfrac{\Delta t}{2}, \mathbf{y}_n + \tfrac{1}{2}\mathbf{k}_2)$$
$$\mathbf{k}_4 = \Delta t \cdot \mathbf{f}(t_n + \Delta t, \mathbf{y}_n + \mathbf{k}_3)$$
$$\mathbf{y}_{n+1} = \mathbf{y}_n + \frac{1}{6}(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4)$$

#### RK4 特点

- 四阶精度 $O(\Delta t^4)$
- 显式（不需迭代）
- 编程实现极简
- 对刚性系统步长受限

## 7. Python 代码实现

### 7.1 Duhamel 积分数值计算

```python
import numpy as np
import matplotlib.pyplot as plt

def duhamel_response(F, t, m, k, c, x0=0.0, v0=0.0):
    """
    用梯形法则数值计算 Duhamel 积分响应
    
    Parameters:
    -----------
    F : array 激励力数组 (N)
    t : array 时间数组 (s)
    m, k, c : float 质量(kg), 刚度(N/m), 阻尼(N·s/m)
    x0, v0 : float 初始位移(m)和速度(m/s)
    
    Returns:
    --------
    x : array 位移响应 (m)
    """
    omega_n = np.sqrt(k / m)
    zeta = c / (2 * np.sqrt(m * k))
    omega_d = omega_n * np.sqrt(1 - zeta**2) if zeta < 1 else 0.0
    
    dt = t[1] - t[0]
    n = len(t)
    x = np.zeros(n)
    
    def h(tau):
        """脉冲响应函数"""
        if tau <= 0:
            return 0.0
        return np.exp(-zeta * omega_n * tau) * np.sin(omega_d * tau) / (m * omega_d)
    
    for i in range(1, n):
        integ = 0.0
        for j in range(i + 1):
            tau = t[i] - t[j]
            fj = F[j]
            if j == 0 or j == i:
                integ += 0.5 * fj * h(tau)
            else:
                integ += fj * h(tau)
        integ *= dt
        
        # 自由振动部分
        edt = np.exp(-zeta * omega_n * t[i])
        x_free = edt * (
            x0 * np.cos(omega_d * t[i]) +
            (v0 + zeta * omega_n * x0) / omega_d * np.sin(omega_d * t[i])
        )
        x[i] = x_free + integ
    
    return x
```

### 7.2 Newmark-$\beta$ 法

```python
def newmark_beta_sdof(m, k, c, F, dt, x0=0.0, v0=0.0, 
                      beta=0.25, gamma=0.5):
    """
    Newmark-beta 法求解单自由度系统
    
    平均加速度法: beta=0.25, gamma=0.5 (无条件稳定)
    
    状态: y = [x, v, a]
    """
    n = len(F)
    x = np.zeros(n); v = np.zeros(n); a = np.zeros(n)
    
    x[0], v[0] = x0, v0
    a[0] = (F[0] - c * v[0] - k * x[0]) / m
    
    k_eff = k + gamma * c / (beta * dt) + m / (beta * dt**2)
    
    a1 = m / (beta * dt) + gamma * c / beta
    a2 = m / (2 * beta) + dt * c * (gamma / (2 * beta) - 1)
    
    for i in range(n - 1):
        F_pred = (F[i+1] + 
                  a1 * v[i] + a2 * a[i] +
                  (m / (beta * dt**2) + gamma * c / (beta * dt)) * x[i])
        
        x[i+1] = F_pred / k_eff
        a[i+1] = ((x[i+1] - x[i]) / (beta * dt**2) - 
                   v[i] / (beta * dt) - 
                   (0.5 / beta - 1) * a[i])
        v[i+1] = (v[i] + (1 - gamma) * dt * a[i] + 
                  gamma * dt * a[i+1])
    
    return x, v, a
```

### 7.3 Runge-Kutta 法

```python
def rk4_sdof(m, k, c, F_func, t_span, y0, dt):
    """
    RK4 法求解单自由度系统 m*x'' + c*x' + k*x = F(t)
    
    F_func: callable F(t)
    t_span: (t_start, t_end)
    y0: [x0, v0]
    """
    t_start, t_end = t_span
    n = int((t_end - t_start) / dt) + 1
    t = np.linspace(t_start, t_end, n)
    
    y = np.zeros((n, 2))
    y[0] = y0  # [x0, v0]
    
    def rhs(t_val, y_val):
        """状态空间右端函数"""
        x_i, v_i = y_val
        a_i = (F_func(t_val) - c * v_i - k * x_i) / m
        return np.array([v_i, a_i])
    
    for i in range(n - 1):
        ti, yi = t[i], y[i]
        
        k1 = dt * rhs(ti, yi)
        k2 = dt * rhs(ti + 0.5*dt, yi + 0.5*k1)
        k3 = dt * rhs(ti + 0.5*dt, yi + 0.5*k2)
        k4 = dt * rhs(ti + dt, yi + k3)
        
        y[i+1] = yi + (k1 + 2*k2 + 2*k3 + k4) / 6.0
    
    return t, y[:, 0], y[:, 1]
```

```python
# 半正弦脉冲激励
dt = 0.01
t = np.arange(0, 5.0, dt)

F_func = lambda t_val: F0 * np.sin(np.pi * t_val / td) if 0 <= t_val <= td else 0.0
t_rk, x_rk, _ = rk4_sdof(m, k, c, F_func, (0, 5.0), [0, 0], dt)
```

## 关键公式总结

| 公式 | 表达式 | 适用场景 |
|---|---|---|
| Fourier 级数 | $F(t) = \frac{a_0}{2} + \sum (a_n\cos n\omega t + b_n\sin n\omega t)$ | 周期激励 |
| 脉冲响应函数 | $h(t) = \frac{1}{m\omega_d}e^{-\zeta\omega_n t}\sin\omega_d t$ | 系统基本动态特性 |
| Duhamel 积分 | $x(t) = \int_0^t F(\tau)h(t-\tau)d\tau$ | 任意激励的时域解 |
| 频响函数 | $H(\omega) = \frac{1/k}{1-r^2+2i\zeta r}$ | 任意激励的频域解 |
| 频域关系 | $\hat{X}(\omega) = H(\omega)\hat{F}(\omega)$ | FFT 快速计算 |
| 冲击响应谱 | $S_d(\omega_n) = \max_t\|x(t;\omega_n)\|$ | 冲击工程设计 |
| Newmark-$\beta$ | $x_{n+1} = x_n + \Delta t\dot{x}_n + (\frac{1}{2}-\beta)\Delta t^2\ddot{x}_n + \beta\Delta t^2\ddot{x}_{n+1}$ | 逐步时程积分 |

```
周期激励 → Fourier 级数 → 各谐波响应叠加 → 总响应
                              ↓ 推广到非周期
任意激励 → Fourier 变换 → H(ω)·F̂(ω) → 逆变换 → x(t)
                              ↕ 卷积定理
                         Duhamel 积分（时域卷积）
                              ↕ 离散化
                         数值积分（Newmark-β / RK4）
                              ↓ 工程应用
                         冲击响应谱（最值 vs ω_n）
```
