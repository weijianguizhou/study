## 1 振动的定义与分类

### 1.1 什么是振动

**振动**（Vibration）——物体在平衡位置附近的往复运动。

广义定义：系统状态变量围绕参考值随时间的交替变化。本质是**恢复力**与**惯性**的耦合，能量在动能与势能之间周期性转换。

振动三要素：
- **振幅** $A$：偏离平衡位置的最大距离
- **频率** $f$：单位时间内全振动的次数
- **相位** $\phi$：描述振动状态的参数

### 1.2 振动分类全景图

```
                ┌── 自由振动 (Free Vibration): 初始激励后无外力
                │
按激励方式 ──┼── 强迫振动 (Forced Vibration): 持续外部激励
                │
                ├── 自激振动 (Self-Excited): 从非振荡能获取能量
                │
                └── 参数振动 (Parametric): 系统参数周期性变化
                
                ┌── 无阻尼 (Undamped): 能量守恒，等幅振动
                │
按阻尼情况 ──┼── 欠阻尼 (Underdamped): ζ < 1，衰减振荡
                │
                ├── 临界阻尼 (Critically damped): ζ = 1，最快回位
                │
                └── 过阻尼 (Overdamped): ζ > 1，缓慢回位

                ┌── 线性振动: 叠加原理成立
按系统特性 ──┤
                └── 非线性振动: Duffing, van der Pol 等

                ┌── 确定性: 简谐/周期/非周期激励
按激励特性 ──┤
                └── 随机振动: 统计方法描述
```

### 1.3 关键公式速查

| 分类      | 运动方程                                                              | 典型示例    |
| ------- | ----------------------------------------------------------------- | ------- |
| 无阻尼自由振动 | $m\ddot{x} + kx = 0$                                              | 弹簧-质量系统 |
| 有阻尼自由振动 | $m\ddot{x} + c\dot{x} + kx = 0$                                   | 带减振器的机械 |
| 简谐强迫振动  | $m\ddot{x} + c\dot{x} + kx = F_0\sin\omega t$                     | 发动机激励   |
| 非线性振动   | $\ddot{x} + \delta\dot{x} + \alpha x + \beta x^3 = F\cos\omega t$ | 大变形结构   |

## 2 振动系统的离散化

### 2.1 连续系统 vs 离散系统

| 特性 | 连续系统 | 离散系统 |
|------|---------|---------|
| 自由度 | 无穷多 | 有限个 |
| 控制方程 | 偏微分方程 | 常微分方程 |
| 求解难度 | 高，少数有解析解 | 可数值求解 |
| 建模方法 | 弹性力学 | 集中质量、有限元 |

### 2.2 三种离散化方法

**(1) 集中质量法（Lumped Mass Method）**
- 将分布质量集中到离散点
- 点间用无质量弹性元件连接
- 质量矩阵为对角阵，实现简单
- 适用于：质量分布较集中的结构

**(2) 假设模态法（Assumed Modes Method）**
$$y(x,t) = \sum_{i=1}^{n} q_i(t)\phi_i(x)$$

- $\phi_i(x)$：满足边界条件的试函数（如梁的振型函数）
- $q_i(t)$：广义坐标（时间函数）
- 通过 Lagrange 方程或 Galerkin 法得到关于 $q_i$ 的 ODE 组
- 精度取决于试函数的选择

**(3) 有限单元法（FEM）**
- 将连续体划分为有限个单元
- 单元内假设位移模式（形函数）
- 通过能量原理建立单元方程，组装整体方程
- 最通用、最强大的工程分析方法

### 2.3 自由度的概念

**自由度（DOF）** = 完全确定系统位置所需的独立坐标数

- 弹簧-质量：1 DOF
- 平面双摆：2 DOF
- 空间刚体：6 DOF（3 平动 + 3 转动）

## 3 简谐振动基础

### 3.1 定义与表达式

**简谐运动**（Simple Harmonic Motion, SHM）——恢复力与位移成正比的周期性运动。

$$x(t) = A\sin(\omega t + \phi)$$

| 符号 | 名称 | 单位 | 物理意义 |
|------|------|------|---------|
| $A$ | 振幅 | m | 最大位移 |
| $\omega$ | 角频率 | rad/s | $2\pi$ 秒内振动次数 |
| $\phi$ | 初相位 | rad | $t=0$ 时的相位 |
| $T$ | 周期 | s | 一次全振动的时间 |
| $f$ | 频率 | Hz | 每秒振动次数 |

### 3.2 参数关系

$$\omega = 2\pi f = \frac{2\pi}{T}$$
$$T = \frac{1}{f} = \frac{2\pi}{\omega}$$

速度：$\dot{x} = \omega A\cos(\omega t + \phi)$ ——相位超前 $\pi/2$
加速度：$\ddot{x} = -\omega^2 x$ ——与位移反向，大小成正比

**特征方程**：$\ddot{x} + \omega^2 x = 0$

### 3.3 旋转矢量法（相量法）

**核心思想**：用一个长度为 $A$、以角速度 $\omega$ 旋转的矢量来表示简谐运动。

- 矢量在 $x$ 轴的投影 = 位移 $x(t)$
- 矢量在 $y$ 轴的投影 = $A\sin(\omega t + \phi + \pi/2)$（速度方向）

**优势**：
- 直观表示振幅、频率、相位的几何关系
- 简谐量的合成 = 矢量叠加
- 初相位 = $t=0$ 时矢量与参考轴夹角

### 3.4 复数表示法

$$x(t) = \Re\{A e^{i(\omega t + \phi)}\} = \Re\{\bar{A}e^{i\omega t}\}$$

其中 **复振幅** $\bar{A} = Ae^{i\phi}$ 同时包含振幅和相位信息。

**优势**：
- 三角函数 → 复数代数运算
- 微分 → 乘 $i\omega$：$\frac{d}{dt}e^{i\omega t} = i\omega e^{i\omega t}$
- 频域分析的基础工具

**重要约定**：物理量 = 复数的实部（或虚部），线性运算可先对复数进行，最后取实部。

## 4 振动系统的三类基本元件

任何复杂振动系统都可以由三种基本元件组合而成。

### 4.1 质量/惯量元件 —— 储存动能

| 运动形式 | 方程 | 参数 |
|---------|------|------|
| 平动 | $F = m\ddot{x}$ | $m$：质量 (kg) |
| 转动 | $T = J\ddot{\theta}$ | $J$：转动惯量 (kg·m²) |

- **绝对元件**：运动参照惯性系
- 动能：$T = \frac{1}{2}m\dot{x}^2$ 或 $T = \frac{1}{2}J\dot{\theta}^2$

### 4.2 弹簧元件 —— 储存势能

**Hooke 定律**（线性弹簧）：$F = kx$

- $k$：弹簧刚度 (N/m)，$x$：相对变形量
- **相对元件**：力取决于端点相对位移
- **非线性弹簧**：$F = k_1x + k_2x^2 + k_3x^3$（多项式拟合）
- 势能：$V = \frac{1}{2}kx^2$

#### 等效弹簧

| 连接方式 | 等效刚度公式 | 记忆口诀 |
|---------|------------|---------|
| **串联** | $\displaystyle\frac{1}{k_{eq}} = \sum\frac{1}{k_i}$ | 弹簧串联刚度倒数和 |
| **并联** | $k_{eq} = \sum k_i$ | 弹簧并联刚度直接加 |

> **物理理解**：串联时弹簧受力相同（串联电路电流），并联时弹簧变形相同（并联电路电压）。串联刚度总小于最软的弹簧，并联刚度总大于最硬的弹簧。

### 4.3 阻尼元件 —— 耗散能量

| 阻尼类型 | 数学模型 | 特征 |
|---------|---------|------|
| **粘性阻尼** | $F_d = c\dot{x}$ | 与速度成正比，最常用 |
| **库仑阻尼** | $F_d = \mu N\cdot\sgn(\dot{x})$ | 干摩擦，恒力大小 |
| **结构阻尼** | $F_d = \frac{h}{\omega}\dot{x}$ | 材料内摩擦，复刚度 $k(1+i\eta)$ |

**粘性阻尼耗散能**（一个周期内）：
若 $x = X\sin\omega t$，则
$$\Delta W_d = \pi c\omega X^2$$

## 5 能量法

### 5.1 Rayleigh 能量法

**基本思想**：保守系统最大动能 = 最大势能

设运动形式 $x(t) = X\sin\omega_n t$，则：

$$T_{\max} = \frac{1}{2}m(\omega_n X)^2, \quad V_{\max} = \frac{1}{2}kX^2$$

由 $T_{\max} = V_{\max}$：
$$\omega_n = \sqrt{\frac{k}{m}}$$

**适用场景**：
- 连续系统或复杂系统
- 无需建立微分方程，只需计算能量
- 精度取决于假设振型的合理性

### 5.2 Rayleigh-Ritz 法（推广）

假设振型为多个基函数的线性组合：
$$\phi(x) = \sum_{i=1}^{n} a_i\psi_i(x)$$

由 $\partial(T_{\max} - V_{\max})/\partial a_i = 0$ 导出特征值问题，可求多阶固有频率。

## 6 D'Alembert 原理

### 6.1 核心思想

> **在运动物体上假想地施加惯性力 $(-m\ddot{x})$ 后，可将动力学问题当作静力学平衡问题处理。**

数学表述：
$$\sum(F_i - m_i\ddot{r}_i)\cdot\delta r_i = 0$$

### 6.2 应用示例

对弹簧-质量-阻尼系统：
1. 主动力：$-kx$ (弹簧), $-c\dot{x}$ (阻尼), $F(t)$ (外力)
2. 惯性力：$-m\ddot{x}$
3. "平衡"方程：$F(t) - kx - c\dot{x} - m\ddot{x} = 0$
4. 整理：$m\ddot{x} + c\dot{x} + kx = F(t)$

### 6.3 与 Newton 法对比

| 方法 | 视角 | 优势 |
|------|------|------|
| Newton 法 | 加速度 ↔ 力 | 直接、物理直观 |
| D'Alembert 法 | 惯性力 + 平衡 | 形式上与静力学一致，便于使用虚功原理 |

**D'Alembert + 虚功原理 → Lagrange 方程**

