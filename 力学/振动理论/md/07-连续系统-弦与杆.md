## 7.1 连续系统与离散系统的区别

### 7.1.1 从离散到连续——自由度概念的扩展

前六章讨论的离散系统（单自由度、多自由度）由有限个集中质量、弹簧和阻尼器组成，其运动由有限个常微分方程（ODE）描述。然而，工程中的许多结构——如弦、杆、梁、板和壳——其质量和弹性是连续分布的。这类**连续系统**（continuous system）拥有**无限多个自由度**，其运动必须用**偏微分方程**（PDE）来描述。

**离散系统 vs 连续系统：**

| 特征 | 离散系统 | 连续系统 |
|------|----------|----------|
| 自由度 | 有限个 | 无限个 |
| 控制方程 | ODE | PDE |
| 广义坐标 | $q_1(t),\dots,q_n(t)$ | $y(x,t)$ |
| 固有频率数 | 有限个 | 无穷多个 |
| 特征值问题 | $\det(\mathbf{K}-\omega^2\mathbf{M})=0$ | Sturm-Liouville 问题 |
| 边界条件 | 不直接参与方程 | 内在于解中 |

从数学上看，离散系统求解的是代数特征值问题；而连续系统求解的是微分算子的特征值问题，涉及边界条件。

**连续系统的建模步骤：**
1. 取微元体，建立力平衡方程或能量关系；
2. 得到关于位移 $y(x,t)$ 的 PDE；
3. 施加边界条件和初始条件；
4. 用分离变量法或积分变换法求解。

### 7.1.2 边界条件的核心作用

离散系统的固有频率完全由系统内部参数（$m$, $k$, $c$）决定。而在连续系统中，**边界条件**是解的内在组成部分——相同的 PDE 在不同边界条件下会给出完全不同的固有频率和振型。这是连续系统与离散系统最显著的区别之一。

## 7.2 弦的横向振动

### 7.2.1 物理模型与基本假设

考虑一根张紧的柔软弦，长度为 $L$，单位长度质量为 $\rho$，在张力 $T$ 作用下处于平衡位置。弦做微小横向振动，位移记为 $y(x,t)$。

**基本假设：**
1. **小挠度假设**：位移 $y$ 远小于弦长 $L$，斜率 $\partial y/\partial x$ 很小；
2. **均匀性假设**：$\rho$ 和 $T$ 沿弦长不变；
3. **柔性假设**：弦不抵抗弯曲，张力沿弦的方向；
4. **无阻尼假设**：忽略能量耗散。

### 7.2.2 波动方程的推导

在 $x$ 处取长度为 $dx$ 的微段。微段两端受张力 $T$ 作用，方向沿弦的切线方向。在微小振动的条件下：

$$\sin\theta \approx \tan\theta = \frac{\partial y}{\partial x}$$

微段在 $y$ 方向的受力为：

$$F_y = T\sin(\theta + d\theta) - T\sin\theta \approx T\frac{\partial}{\partial x}\left(\frac{\partial y}{\partial x}\right)dx = T\frac{\partial^2 y}{\partial x^2}dx$$

由牛顿第二定律 $F = ma$，微段质量 $\rho\,dx$，加速度 $\partial^2 y/\partial t^2$：

$$\rho\,dx \cdot \frac{\partial^2 y}{\partial t^2} = T\frac{\partial^2 y}{\partial x^2}dx$$

约去 $dx$ 得到经典的**一维波动方程**：

$$\boxed{\frac{\partial^2 y}{\partial t^2} = c^2\frac{\partial^2 y}{\partial x^2}, \quad c = \sqrt{\frac{T}{\rho}}}$$

> **物理意义**：其中 $c$ 为波速（wave speed），量纲为 m/s。张力越大，波速越高；线密度越大，波速越低。波动方程是双曲型 PDE 的典范——信息以有限速度 $c$ 在弦上传播。

### 7.2.3 分离变量法

假设解可以写为空间函数与时间函数的乘积：

$$y(x,t) = Y(x) \cdot T(t)$$

代入波动方程：

$$Y(x)\ddot{T}(t) = c^2 Y''(x) T(t)$$

两边除以 $c^2 Y(x) T(t)$：

$$\frac{\ddot{T}(t)}{c^2 T(t)} = \frac{Y''(x)}{Y(x)} = -\beta^2 \quad (\text{常数})$$

> 引入分离常数 $-\beta^2$ 保证了时间方程的解是简谐振动，符合物理实际。

得到两个常微分方程：

$$\boxed{\text{空间方程：}\; Y''(x) + \beta^2 Y(x) = 0}$$

$$\boxed{\text{时间方程：}\; \ddot{T}(t) + \omega^2 T(t) = 0, \quad \omega = \beta c}$$

空间方程的通解：
$$Y(x) = A\sin(\beta x) + B\cos(\beta x)$$

时间方程的通解：
$$T(t) = C\sin(\omega t) + D\cos(\omega t)$$

### 7.2.4 两端固定的弦

**边界条件**：$y(0,t)=0$, $y(L,t)=0$，即 $Y(0)=0$, $Y(L)=0$。

由 $Y(0)=0$ 得 $B = 0$，故 $Y(x) = A\sin(\beta x)$。

由 $Y(L)=A\sin(\beta L)=0$，$A\neq 0$，得频率方程：

$$\sin(\beta L) = 0 \;\Rightarrow\; \beta_n L = n\pi, \; n=1,2,3,\dots$$

**固有频率和振型：**

$$\boxed{\beta_n = \frac{n\pi}{L}, \quad \omega_n = \frac{n\pi}{L}\sqrt{\frac{T}{\rho}},\quad Y_n(x) = \sin\left(\frac{n\pi x}{L}\right)}$$

$n=1$ 为基频（fundamental frequency），弦以半个波长振动；$n=2$ 为第一泛音，弦以完整波长振动；所有泛音都是基频的整数倍（谐波关系）。

### 7.2.5 一端固定一端自由的弦

**边界条件**：$Y(0)=0$, $Y'(L)=0$。

由 $Y'(L) = A\beta\cos(\beta L)=0$ 得频率方程 $\cos(\beta L)=0$。

$$\omega_n = \frac{(2n-1)\pi}{2L}\sqrt{\frac{T}{\rho}}, \quad Y_n(x)=\sin\left(\frac{(2n-1)\pi x}{2L}\right)$$

> 与两端固定不同，固有频率不是基频的整数倍（半奇数倍），振型在自由端取到极值。

### 7.2.6 两端自由的弦

**边界条件**：$Y'(0)=0$, $Y'(L)=0$。

固有频率方程与两端固定相同：$\beta_n L = n\pi$，但基频对应 $n=0$（$\beta_0=0$），$\omega_0=0$——**刚体平移模态**。

固有振型：$Y_n(x)=\cos(n\pi x/L)$, $n=0,1,2,\dots$。

### 7.2.7 振型的正交性

**定理**：不同阶次的固有振型关于质量分布加权正交：
$$\int_0^L Y_m(x) Y_n(x)\,dx = 0, \quad m \neq n$$

**证明**：$Y_m$ 和 $Y_n$ 分别满足空间方程，将 $Y_m''+\beta_m^2 Y_m=0$ 乘 $Y_n$，$Y_n''+\beta_n^2 Y_n=0$ 乘 $Y_m$，相减并积分，利用边界条件即得。

同样有关于刚度的正交性：
$$\int_0^L Y_m'(x) Y_n'(x)\,dx = 0, \quad m \neq n$$

## 7.3 杆的纵向振动

### 7.3.1 物理模型与波动方程

考虑均匀弹性杆，长度 $L$，截面积 $A$，密度 $\rho$，弹性模量 $E$。杆做纵向振动，位移记为 $u(x,t)$。基本假设：(1) 平截面假设；(2) 横向惯性忽略；(3) Hooke 定律 $\sigma = E\varepsilon$。

微段应变 $\varepsilon = \partial u/\partial x$，截面力 $P = \sigma A = EA\,\partial u/\partial x$。

由牛顿第二定律得到：

$$\boxed{\frac{\partial^2 u}{\partial t^2} = c_L^2\frac{\partial^2 u}{\partial x^2}, \quad c_L = \sqrt{\frac{E}{\rho}}}$$

$c_L$ 为纵波波速。钢材中约 5172 m/s。

> 杆的纵向振动方程在形式上与弦的横向振动完全相同——都是一维波动方程。区别仅在于波速的物理来源。

### 7.3.2 不同边界条件下的解

| 边界条件 | 频率方程 | 固有频率 $\omega_n$ | 固有振型 $U_n(x)$ |
|----------|----------|---------------------|---------------------|
| 固定-固定 | $\sin(\beta L)=0$ | $\frac{n\pi}{L}\sqrt{E/\rho}$ | $\sin(n\pi x/L)$ |
| 固定-自由 | $\cos(\beta L)=0$ | $\frac{(2n-1)\pi}{2L}\sqrt{E/\rho}$ | $\sin((2n-1)\pi x/(2L))$ |
| 自由-自由 | $\sin(\beta L)=0$ | $\frac{n\pi}{L}\sqrt{E/\rho}$ ($n\ge 0$) | $\cos(n\pi x/L)$ |

自由-自由杆存在零频率的刚体模态（$n=0$）。

## 7.4 杆的扭转振动

### 7.4.1 扭转波动方程

均匀圆截面杆的扭转振动，扭转角 $\theta(x,t)$ 满足：

$$\boxed{\frac{\partial^2\theta}{\partial t^2} = c_T^2\frac{\partial^2\theta}{\partial x^2}, \quad c_T = \sqrt{\frac{G}{\rho}}}$$

$c_T$ 为扭转波速（剪切波速）。对大多数金属 $G \approx E/[2(1+\nu)]$，故 $c_T < c_L$。

**三种波动对比：**

| 类型 | 波速 | 驱动力/刚度 |
|------|------|-------------|
| 弦横波 | $c=\sqrt{T/\rho}$ | 张力 |
| 杆纵波 | $c_L=\sqrt{E/\rho}$ | 弹性模量 |
| 杆扭转波 | $c_T=\sqrt{G/\rho}$ | 剪切模量 |

三者的控制方程都是一维波动方程——这是连续介质力学中波传播的普适形式。

## 7.5 模态叠加法用于连续系统

### 7.5.1 模态展开

任意响应展开为固有振型的无穷级数：

$$\boxed{y(x,t) = \sum_{n=1}^{\infty} Y_n(x)\, q_n(t)}$$

代入受迫振动方程并利用正交性，得到解耦的模态方程：

$$\boxed{M_n \ddot{q}_n(t) + K_n q_n(t) = Q_n(t), \quad n=1,2,3,\dots}$$

其中：
- **模态质量**：$M_n = \int_0^L \rho Y_n^2(x)\,dx$
- **模态刚度**：$K_n = \int_0^L T [Y_n'(x)]^2\,dx$
- **模态力**：$Q_n(t) = \int_0^L f(x,t)Y_n(x)\,dx$
- **固有频率**：$\omega_n = \sqrt{K_n/M_n}$

> 模态叠加法将无限自由度的 PDE 转化为无穷多个解耦的 ODE，每个 ODE 恰好是单自由度简谐振子的方程。在工程实践中，取前若干阶模态即可获得满意精度。

### 7.5.2 含阻尼的受迫振动

当系统包含粘性阻尼时：
$$M_n \ddot{q}_n + 2\zeta_n\omega_n M_n \dot{q}_n + K_n q_n = Q_n(t)$$

简谐激励 $f(x,t)=F(x)\sin(\Omega t)$ 下的稳态响应：
$$y(x,t) = \sum_{n=1}^{\infty} \frac{Y_n(x)}{K_n} \cdot \frac{1}{\sqrt{(1-\Omega^2/\omega_n^2)^2 + (2\zeta_n\Omega/\omega_n)^2}} \cdot \sin(\Omega t - \phi_n)$$

### 7.5.3 集中力作用下的响应

若在 $x=x_0$ 处作用集中力 $F(t)=F_0\sin(\Omega t)$：
$$y(x,t) = F_0 \sum_{n=1}^{\infty} \frac{Y_n(x)Y_n(x_0)}{K_n(1-\Omega^2/\omega_n^2)}\sin(\Omega t)$$

> 若激振点位于某阶振型的节点（$Y_n(x_0)=0$），则该阶模态不被激发——这是模态测试中布置传感器的关键依据。

## 7.6 数值模拟

### 7.6.1 弦振动的有限差分解

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

L = 1.0; T = 100.0; rho = 0.01
c = np.sqrt(T / rho)
nx = 101; dx = L / (nx - 1)
dt = 0.5 * dx / c   # CFL 条件
nt = 2000
x = np.linspace(0, L, nx)

u = np.zeros((3, nx))
u[0, :] = np.sin(np.pi * x / L) * 0.1   # 初始位移

for n in range(1, nt):
    for i in range(1, nx - 1):
        u[2, i] = (c * dt / dx) ** 2 * (
            u[1, i + 1] - 2 * u[1, i] + u[1, i - 1]
        ) + 2 * u[1, i] - u[0, i]
    u[2, 0] = 0.0; u[2, -1] = 0.0
    u[0, :] = u[1, :]; u[1, :] = u[2, :]

fig, ax = plt.subplots(figsize=(10, 3))
line, = ax.plot(x, u[2, :], 'b-', lw=2)
ax.set_xlim(0, L); ax.set_ylim(-0.15, 0.15)
ax.set_xlabel('x'); ax.set_ylabel('y(x,t)')
ax.set_title('两端固定弦的振动')

def update(n):
    for i in range(1, nx - 1):
        u[2, i] = (c * dt / dx) ** 2 * (
            u[1, i + 1] - 2 * u[1, i] + u[1, i - 1]
        ) + 2 * u[1, i] - u[0, i]
    u[2, 0] = 0.0; u[2, -1] = 0.0
    u[0, :] = u[1, :]; u[1, :] = u[2, :]
    line.set_ydata(u[2, :])
    return line,

ani = FuncAnimation(fig, update, frames=500, interval=20, blit=True)
plt.show()
```

### 7.6.2 绘制前五阶振型

```python
import numpy as np
import matplotlib.pyplot as plt

L = 1.0
x = np.linspace(0, L, 200)
fig, ax = plt.subplots(figsize=(8, 6))
colors = ['blue', 'red', 'green', 'orange', 'purple']

for n in range(1, 6):
    Y_n = np.sin(n * np.pi * x / L)
    ax.plot(x, Y_n + 0.2 * (n - 1), color=colors[n-1], lw=2,
            label=f'n={n}')

ax.set_xlabel('x'); ax.set_ylabel('Y_n(x)')
ax.set_title('两端固定弦的前五阶固有振型')
ax.legend(); ax.grid(True, alpha=0.3)
plt.tight_layout(); plt.show()
```

### 7.6.3 不同边界条件下固有频率对比

```python
import numpy as np

L = 1.0; T = 100.0; rho = 0.01; c = np.sqrt(T / rho)

print("边界条件          固有频率 (Hz)")
print("-" * 40)

n_values = np.arange(1, 6)
omega_ff = n_values * np.pi * c / L
print("两端固定:      ", np.round(omega_ff / (2 * np.pi), 2))

omega_cf = (2 * n_values - 1) * np.pi * c / (2 * L)
print("一端固定一端自由:", np.round(omega_cf / (2 * np.pi), 2))

omega_elas = n_values * np.pi * c / L
print("两端自由(弹性): ", np.round(omega_elas / (2 * np.pi), 2))
```

## 7.7 小结

本章从离散系统过渡到连续系统，建立了弦和杆的一维波动方程：

1. 连续系统由 PDE 描述，拥有无穷多自由度；边界条件内在于解中；
2. 一维波动方程 $\partial^2\phi/\partial t^2=c^2\partial^2\phi/\partial x^2$ 是弦、杆纵振、杆扭振的统一数学形式；
3. 分离变量法将 PDE 分解为空间 ODE 和时间 ODE，边界条件确定固有频率和振型；
4. 振型满足正交性，模态叠加法将 PDE 解耦为无穷多个单自由度方程；
5. 有限差分法是求解复杂边界和初始条件下波动问题的有力工具。
