## 学习路线建议

### 先修知识

- **常微分方程**：一阶/二阶线性 ODE、特征方程法（第 1–4 章的基础）
- **线性代数**：矩阵特征值、对角化、二次型（第 5–7 章的工具）
- **动力学**：Newton 第二定律、达朗贝尔原理、Lagrange 方程
- **数学分析**：Fourier 级数与 Laplace 变换（第 3–4 章、第 8 章）

### 建议学习顺序

**第一阶段（基础）**：第 01 → 02 → 03 → 04 章
- 单自由度系统是全部振动理论的基础，必须牢固掌握简谐响应、放大因子、传递率等核心概念。

**第二阶段（多自由度与模态）**：第 05 → 06 → 07 章
- 从 2DOF 直观理解耦合振动的物理图像，再用矩阵方法推广到 NDOF，熟练掌握模态叠加法。

**第三阶段（连续系统与近似法）**：第 08 → 09 章
- 连续系统的偏微分方程建模，Rayleigh-Ritz 与 FEM 的数值思想。

**第四阶段（专题深入）**：第 10 → 11 → 12 章
- 非线性（Duffing、混沌）、随机振动（PSD、疲劳）、振动控制（隔振、TMD、主动控制）及工程案例。

### 学习建议

1. **先数学后物理**：每章涉及的数学工具需先回顾预备知识
2. **动手数值实验**：每章的 Python 代码建议自己跑一遍并修改参数观察规律
3. **注意物理量纲**：特别注意频率、阻尼比、质量比的量纲一致性
4. **建立工程直觉**：对振动控制章节的设计准则，多结合具体案例定性理解
5. **看参考书的例题**：本笔记作为学习路线指南，需配合经典教材的完整推导和习题
