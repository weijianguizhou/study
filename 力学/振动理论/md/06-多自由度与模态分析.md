## 1. $n$ 自由度系统的运动方程

### 1.1 矩阵形式的运动方程

与两自由度系统完全一致的矩阵形式：

$$\boxed{\mathbf{M}\ddot{\mathbf{x}} + \mathbf{C}\dot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{F}(t)}$$

其中各矩阵为 $n \times n$ 方阵，$\mathbf{x}, \mathbf{F} \in \R^n$。

### 1.2 质量矩阵 $\mathbf{M}$ ($n \times n$)

| 类型 | 构造方式 | 性质 |
|---|---|---|
| **集中质量矩阵** | $\mathbf{M} = \text{diag}(m_1, \ldots, m_n)$ | 对角，正定 |
| **一致质量矩阵** | $\mathbf{M} = \int \rho \mathbf{N}^{\top}\mathbf{N}\,dV$ | 非对角（有限元法），正定 |

### 1.3 刚度矩阵 $\mathbf{K}$ ($n \times n$)

#### 物理含义

$$K_{ij} = \begin{cases} 
\sum_{k \text{ 连接到 } i} k_{ik}, & i = j \\[6pt]
-k_{ij}, & i \neq j \text{ 且有连接} \\[2pt]
0, & i \neq j \text{ 无连接}
\end{cases}$$

#### 构建规则（弹簧-质量链）

对于 $n$ 自由度弹簧-质量链（每质量 $m_i$，弹簧 $k_i$ 连接 $m_i$ 和 $m_{i+1}$，两端 $k_0$ 和 $k_n$ 连固定墙）：

$$\mathbf{K} = \begin{bmatrix}
k_0 + k_1 & -k_1 & 0 & \cdots & 0 \\
-k_1 & k_1 + k_2 & -k_2 & \cdots & 0 \\
0 & -k_2 & k_2 + k_3 & \cdots & 0 \\
\vdots & \vdots & \vdots & \ddots & -k_{n-1} \\
0 & 0 & 0 & -k_{n-1} & k_{n-1} + k_n
\end{bmatrix}$$

#### 性质

- **对称**：$\mathbf{K} = \mathbf{K}^{\top}$（Maxwell 互等定理）
- **正定/半正定**：完全约束时正定（$\mathbf{x}^{\top}\mathbf{K}\mathbf{x} > 0$，$\forall \mathbf{x} \neq \mathbf{0}$）；存在刚体自由度时半正定
- **带状稀疏**：带宽 = 最大连接距离（有限元节点编号决定）

### 1.4 阻尼矩阵 $\mathbf{C}$ ($n \times n$)

真实阻尼的物理机制极其复杂，工程中通常采用简化模型：

| 模型 | 公式 | 特点 |
|---|---|---|
| **Rayleigh 阻尼** | $\mathbf{C} = \alpha\mathbf{M} + \beta\mathbf{K}$ | 两个参数，可同时对角化 |
| **模态阻尼** | 直接指定各阶 $\zeta_i$ | 不构建 $\mathbf{C}$ |
| **Caughey 阻尼** | $\mathbf{C} = \mathbf{M}\sum a_j(\mathbf{M}^{-1}\mathbf{K})^j$ | $n$ 个参数可匹配 $n$ 阶阻尼比 |
| **非比例阻尼** | 一般矩阵 | 需复模态理论 |

**$\mathbf{C}$ 能被 $\mathbf{\Phi}$ 对角化的条件**（Caughey & O'Kelly, 1965）：

$$\mathbf{C}\mathbf{M}^{-1}\mathbf{K} = \mathbf{K}\mathbf{M}^{-1}\mathbf{C}$$

Rayleigh 阻尼显然满足这一条件。

## 2. 固有值问题

### 2.1 特征值问题的提法

无阻尼自由振动：$\mathbf{M}\ddot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{0}$

设 $\mathbf{x}(t) = \bm{\phi} \sin(\omega t + \theta)$，代入得：

$$\boxed{(\mathbf{K} - \omega^2 \mathbf{M}) \bm{\phi} = \mathbf{0}}$$

**广义特征值问题**的标准形式。

#### 频率方程

非零解条件（$\bm{\phi} \neq \mathbf{0}$）：

$$\boxed{\det(\mathbf{K} - \omega^2 \mathbf{M}) = 0}$$

这是一个关于 $\omega^2$ 的 $n$ 次代数方程，$n$ 个正实根：

$$0 \leq \omega_1^2 \leq \omega_2^2 \leq \cdots \leq \omega_n^2$$

固有频率：

$$\boxed{\omega_1 \leq \omega_2 \leq \cdots \leq \omega_n}$$

### 2.2 固有振型（模态）

将 $\omega_i^2$ 代回特征方程，求得的 $\bm{\phi}_i$ 为第 $i$ 阶振型（确定到比例因子）。

所有 $n$ 个振型构成 **模态矩阵**：

$$\boxed{\mathbf{\Phi} = [\bm{\phi}_1, \bm{\phi}_2, \ldots, \bm{\phi}_n] \in \R^{n \times n}}$$

- $\mathbf{\Phi}$ 的**第 $i$ 列** = 第 $i$ 阶振型
- $\mathbf{\Phi}$ 的**第 $j$ 行** = 第 $j$ 个自由度在各阶振型中的分量

### 2.3 固有频率与振型的物理规律

| 阶次 | 频率 | 振型特征 | 节点数 |
|---|---|---|---|
| 1 | $\omega_1$（基频） | 所有质量同相 | 0 |
| 2 | $\omega_2$ | 一次反向 | 1 |
| 3 | $\omega_3$ | 两次反向 | 2 |
| $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ |
| $i$ | $\omega_i$ | $i-1$ 次反向 | $i-1$ |

**直观理解**：
- 低阶振型：各质量"协同"运动，刚度"感觉"较小 $\to$ 频率低
- 高阶振型：相邻质量反复反向，刚度"感觉"较大 $\to$ 频率高

### 2.4 特征值问题的数值方法概述

| 方法 | 特点 | 适用规模 |
|---|---|---|
| 子空间迭代法 | 同时求前 $r$ 阶 | $n \lesssim 10^6$ |
| Lanczos 法 | 收敛极快，最流行 | $n \lesssim 10^7$ |
| Jacobi-Davidson | 适合内点特征值 | $n \lesssim 10^5$ |
| 逆幂迭代 | 求单阶（最低频或频移附近） | 各种规模 |

在 Python 中：`scipy.linalg.eigh(K, M)` 对中小规模（$n \lesssim 10^3$）精度和效率俱佳。

## 3. 模态正交性

### 3.1 关于 $\mathbf{M}$ 和 $\mathbf{K}$ 的正交性

#### 推导（$i \neq j$）

由对称性：
$$\mathbf{K}\bm{\phi}_i = \omega_i^2\mathbf{M}\bm{\phi}_i$$
$$\mathbf{K}\bm{\phi}_j = \omega_j^2\mathbf{M}\bm{\phi}_j$$

$$\bm{\phi}_j^{\top}\mathbf{K}\bm{\phi}_i = \omega_i^2\bm{\phi}_j^{\top}\mathbf{M}\bm{\phi}_i$$
$$\bm{\phi}_i^{\top}\mathbf{K}\bm{\phi}_j = \omega_j^2\bm{\phi}_i^{\top}\mathbf{M}\bm{\phi}_j$$

因为 $\mathbf{K}$ 对称：$\bm{\phi}_j^{\top}\mathbf{K}\bm{\phi}_i = \bm{\phi}_i^{\top}\mathbf{K}\bm{\phi}_j$

相减：
$$(\omega_i^2 - \omega_j^2) \cdot \bm{\phi}_i^{\top}\mathbf{M}\bm{\phi}_j = 0$$

$\omega_i \neq \omega_j \Rightarrow \boxed{\bm{\phi}_i^{\top}\mathbf{M}\bm{\phi}_j = 0}$（关于 $\mathbf{M}$ 正交）

类似可证 $\boxed{\bm{\phi}_i^{\top}\mathbf{K}\bm{\phi}_j = 0}$（关于 $\mathbf{K}$ 正交）

#### 矩阵形式

$$\boxed{\mathbf{\Phi}^{\top} \mathbf{M} \mathbf{\Phi} = \mathbf{M}_{\text{modal}} = \text{diag}(m_1, \ldots, m_n)}$$
$$\boxed{\mathbf{\Phi}^{\top} \mathbf{K} \mathbf{\Phi} = \mathbf{K}_{\text{modal}} = \text{diag}(k_1, \ldots, k_n)}$$

其中：
- $m_i = \bm{\phi}_i^{\top}\mathbf{M}\bm{\phi}_i$：**模态质量**（第 $i$ 阶）
- $k_i = \bm{\phi}_i^{\top}\mathbf{K}\bm{\phi}_i$：**模态刚度**（第 $i$ 阶）

#### 模态频率公式

$$\boxed{\omega_i^2 = \frac{k_i}{m_i}}$$

与单自由度公式 $\omega_n = \sqrt{k/m}$ 完全一致！这就是模态分析的数学本质。

### 3.2 质量归一化

将各阶振型归一化使模态质量 $=1$：

$$\tilde{\bm{\phi}}_i = \frac{\bm{\phi}_i}{\sqrt{\bm{\phi}_i^{\top}\mathbf{M}\bm{\phi}_i}}$$

归一化后的模态矩阵满足：

$$\boxed{\mathbf{\Phi}^{\top} \mathbf{M} \mathbf{\Phi} = \mathbf{I}_{n\times n}}$$
$$\boxed{\mathbf{\Phi}^{\top} \mathbf{K} \mathbf{\Phi} = \mathbf{\Omega}^2 = \text{diag}(\omega_1^2, \ldots, \omega_n^2)}$$

### 3.3 正交性的深层含义

| 视角 | 含义 |
|---|---|
| **物理** | 不同模态间无能量交换。以某阶振型激发系统 -> 只在该阶振动 |
| **数学** | $\mathbf{\Phi}$ 是对 $(\mathbf{K}, \mathbf{M})$ 的同时对角化矩阵 |
| **线性代数** | 振型构成 $(\R^n, \langle\cdot,\cdot\rangle_{\mathbf{M}})$ 中的正交基 |
| **动力学** | 任何自由振动 = 各阶模态的线性组合（谱分解） |

## 4. 模态叠加法（Mode Superposition）

### 4.1 基本变换

$$\boxed{\mathbf{x}(t) = \mathbf{\Phi} \mathbf{q}(t) = \sum_{i=1}^{n} q_i(t) \bm{\phi}_i}$$

- $\mathbf{x}$：物理坐标（可观测、耦合的）
- $\mathbf{q}$：模态坐标（不可直接观测、解耦的）
- $q_i$：第 $i$ 阶振型参与系统响应的"强度"

#### 逆变换

若 $\mathbf{M}$ 正定（满秩），$\mathbf{\Phi}$ 可逆：

$$\mathbf{q}(t) = \mathbf{\Phi}^{-1} \mathbf{x}(t)$$

在质量归一化下：$\mathbf{\Phi}^{-1} = \mathbf{\Phi}^{\top}\mathbf{M}$

### 4.2 运动方程的解耦

将 $\mathbf{x} = \mathbf{\Phi}\mathbf{q}$ 代入运动方程，左乘 $\mathbf{\Phi}^{\top}$：

$$\mathbf{\Phi}^{\top}\mathbf{M}\mathbf{\Phi}\,\ddot{\mathbf{q}} + \mathbf{\Phi}^{\top}\mathbf{C}\mathbf{\Phi}\,\dot{\mathbf{q}} + \mathbf{\Phi}^{\top}\mathbf{K}\mathbf{\Phi}\,\mathbf{q} = \mathbf{\Phi}^{\top}\mathbf{F}(t)$$

质量归一化 + 比例阻尼对角化后：

$$\boxed{\ddot{q}_i + 2\zeta_i\omega_i\dot{q}_i + \omega_i^2 q_i = \bm{\phi}_i^{\top}\mathbf{F}(t) = f_i(t)}$$

$i = 1, 2, \ldots, n$

#### $f_i(t) = \bm{\phi}_i^{\top}\mathbf{F}(t)$ —— 模态力

**物理意义**：外力在第 $i$ 阶振型上的"投影"。如果外力分布与某阶振型正交 $\rightarrow$ 该阶模态完全不被激发。

### 4.3 各模态的独立求解

每个解耦方程都是标准单自由度受迫振动，零初始条件下的解（Duhamel 积分）：

$$q_i(t) = \frac{1}{\omega_{di}} \int_0^t f_i(\tau)\, e^{-\zeta_i\omega_i(t-\tau)} \sin\omega_{di}(t-\tau)\,d\tau$$

其中 $\omega_{di} = \omega_i\sqrt{1 - \zeta_i^2}$。

物理空间响应：

$$\boxed{\mathbf{x}(t) = \sum_{i=1}^{n} q_i(t)\,\bm{\phi}_i}$$

### 4.4 模态叠加法计算流程

```
  M x'' + C x' + K x = F(t)      (耦合的 n DOF)
              |
    求解特征值问题: det(K - ω²M) = 0
    得: Φ = [φ₁, φ₂, ..., φ_n],  ω₁ ≤ ω₂ ≤ ... ≤ ω_n
              |
    坐标变换: x = Φ q
              |
    q_i'' + 2ζᵢωᵢ q_i' + ωᵢ² q_i = φᵢᵀ F(t)    (n 个解耦的 SDOF)
              |
    各模态独立求解 (Duhamel 积分 / 数值积分)
              |
    叠加: x(t) = Σ q_i(t) φ_i    (回到物理坐标)
```

### 4.5 计算量对比

| 方法 | 计算量 | 适用场景 |
|---|---|---|
| 直接时程积分（Newmark-$\beta$）| $O(n^3)$ 或 $O(n b^2)$ 每步 | 全部模态参与 |
| 完整模态叠加 | $O(n^3)$ 特征值 + $O(n^2)$ 每步 | 模态贡献明确 |
| **截断模态叠加** | $O(r^3)$ 特征值 + $O(n r)$ 每步 | **性价比最优** |

## 5. 比例阻尼（Rayleigh 阻尼）

### 5.1 定义与形式

$$\boxed{\mathbf{C} = \alpha \mathbf{M} + \beta \mathbf{K}}$$

- $\alpha$：$[\text{s}^{-1}]$，质量比例系数
- $\beta$：$[\text{s}]$，刚度比例系数

### 5.2 模态阻尼比

在模态坐标下：

$$c_i = \bm{\phi}_i^{\top}\mathbf{C}\bm{\phi}_i = \alpha m_i + \beta k_i$$

$$\boxed{\zeta_i = \frac{c_i}{2m_i\omega_i} = \frac{\alpha}{2\omega_i} + \frac{\beta\omega_i}{2}}$$

#### Rayleigh 阻尼曲线

```
ζ ↑
  |   \    α/(2ω) 支配     /  βω/2 支配
  |    \                 /
  |     \    ______     /
  |      \  /      \   /
  |       \/        \ /
  |       /\________/\
  |      /            \
  |     /              \
  +-----+-------+-------+----→ ω
        ω₁     ω=√(α/β)  ω_n
               (ζ_min)
```

- **低频**（$\omega \ll \sqrt{\alpha/\beta}$）：$\zeta \approx \alpha/(2\omega)$，质量阻尼主导
- **高频**（$\omega \gg \sqrt{\alpha/\beta}$）：$\zeta \approx \beta\omega/2$，刚度阻尼主导
- **最小阻尼比**：$\zeta_{\min} = \sqrt{\alpha\beta}$，出现在 $\omega = \sqrt{\alpha/\beta}$

### 5.3 参数拟合

已知两阶模态 $i$, $j$ 的阻尼比 $\zeta_i$, $\zeta_j$：

$$\begin{bmatrix} \frac{1}{2\omega_i} & \frac{\omega_i}{2} \\[4pt] \frac{1}{2\omega_j} & \frac{\omega_j}{2} \end{bmatrix}
\begin{Bmatrix} \alpha \\ \beta \end{Bmatrix} = 
\begin{Bmatrix} \zeta_i \\ \zeta_j \end{Bmatrix}$$

解：

$$\alpha = \frac{2\omega_i\omega_j}{\omega_j^2 - \omega_i^2} (\zeta_i\omega_j - \zeta_j\omega_i)$$

$$\beta = \frac{2}{\omega_j^2 - \omega_i^2} (\zeta_j\omega_j - \zeta_i\omega_i)$$

**通常选取**：$\omega_1$（基频）和结构中一个重要的高频模态。

### 5.4 Rayleigh 阻尼的局限性

- 只有 2 个参数 $\to$ 只能精确匹配 2 阶模态的阻尼比
- 其他模态的 $\zeta_i$ 由曲线推定，可能与实际偏离
- 质量阻尼项 $\alpha\mathbf{M}$ 可能导致非零刚体模态阻尼（刚体运动也被阻尼），物理上不一定合理
- 需要多阶精确阻尼比时 $\to$ 使用 **Caughey 系列阻尼**

## 6. 模态截断

### 6.1 为什么截断？

对于大型有限元模型（$n = 10^5 \sim 10^7$）：

| 原因 | 说明 |
|---|---|
| 计算成本 | 全模态 $O(n^3)$ 不可行 |
| 物理理由 | 高频模态响应贡献极小 |
| 激励限制 | 外激励只有低频成分 |
| 阻尼衰减 | 高频模态被阻尼迅速衰减 |

$\therefore$ 只保留前 $r$ 阶模态（$r \ll n$）。

### 6.2 截断模态叠加

$$\boxed{\mathbf{x}(t) \approx \sum_{i=1}^{r} q_i(t)\,\bm{\phi}_i = \mathbf{\Phi}_r \mathbf{q}_r(t)}$$

$\mathbf{\Phi}_r \in \R^{n \times r}$：截断模态矩阵（只含前 $r$ 列）

### 6.3 模态参与因子与有效质量

设基础运动方向为 $\mathbf{r} \in \R^n$（单位方向向量）。

#### 模态参与因子

$$\boxed{\Gamma_i = \frac{\bm{\phi}_i^{\top} \mathbf{M} \mathbf{r}}{m_i}}$$

衡量第 $i$ 阶模态对 $\mathbf{r}$ 方向整体响应的贡献。

#### 有效模态质量

$$\boxed{m_{\text{eff},i} = \frac{(\bm{\phi}_i^{\top}\mathbf{M}\mathbf{r})^2}{m_i}}$$

衡量第 $i$ 阶模态"携带"了多少质量在 $\mathbf{r}$ 方向的运动中。

#### 关键性质

$$\boxed{\sum_{i=1}^{n} m_{\text{eff},i} = \mathbf{r}^{\top}\mathbf{M}\mathbf{r} = M_{\text{total}}}$$

所有模态的有效质量之和 = 总质量！

#### 截断准则（抗震设计标准）

$$\frac{\sum_{i=1}^{r} m_{\text{eff},i}}{M_{\text{total}}} \geq 0.90 \quad (\text{90\%})$$

即保留的模态有效质量累计 $\geq$ 总质量的 90%。

### 6.4 截断准则汇总

| 准则 | 条件 | 适用范围 |
|---|---|---|
| 频率准则 | $\omega_r \geq 3\sim5 \times \omega_{\text{激励}}$ | 已知激励频带 |
| 有效质量准则 | $\sum_{i=1}^r m_{\text{eff},i} \geq 0.9 M_{\text{total}}$ | 抗震设计（最常用） |
| 响应收敛 | $x(t)$ 随 $r$ 增加基本不变 | 精确分析 |

## 7. 实验模态分析（EMA）简介

### 7.1 频响函数矩阵

#### 定义

$H_{jk}(\omega)$ = 仅在 $k$ 自由度上施加单位简谐力时，$j$ 自由度的稳态位移响应（复数）。

$$\hat{\mathbf{X}}(\omega) = \mathbf{H}(\omega) \hat{\mathbf{F}}(\omega)$$

#### 模态展开式

$$\boxed{\mathbf{H}(\omega) = \sum_{i=1}^{n} \frac{\bm{\phi}_i \bm{\phi}_i^{\top}}{m_i(\omega_i^2 - \omega^2 + 2i\zeta_i\omega_i\omega)}}$$

这是 EMA 的理论基础。每一项 $\frac{\bm{\phi}_i \bm{\phi}_i^{\top}}{m_i(\omega_i^2 - \omega^2 + 2i\zeta_i\omega_i\omega)}$ 是第 $i$ 阶模态对 FRF 矩阵的贡献。

$\bm{\phi}_i \bm{\phi}_i^{\top}$ 是秩为 1 的外积矩阵（$n \times n$），所以 $\mathbf{H}(\omega)$ 是 $n$ 个秩-1 矩阵的加权和。

### 7.2 模态参数识别方法

| 方法 | 原理 | 适用条件 |
|---|---|---|
| **峰值拾取** | FRF 幅值峰值 $\to \omega_i$；半功率带宽 $\to \zeta_i$；虚部比 $\to$ 振型 | 阻尼小、模态稀疏 |
| **圆拟合（Nyquist）** | Nyquist 图中模态近似为圆 | 单模态主导的频段 |
| **PolyMAX** | 频域多参考点最小二乘复频域 | 密集模态、高阻尼（工业标准） |
| **SSI（随机子空间）** | 时域随机子空间辨识 | 环境激励（OMA） |

### 7.3 EMA 工作流程

```
1. 激励 (力锤/激振器)
        ↓
2. 测量 (加速度计/力传感器 → FRF)
        ↓
3. 信号处理 (H₁ / H₂ / H_v 估计器, 相干函数检查)
        ↓
4. 参数识别 (提取 ω_i, ζ_i, φ_i)
        ↓
5. 验证 (MAC 矩阵, 合成 FRF vs 实测 FRF)
```

#### MAC（Modal Assurance Criterion）矩阵

$$\text{MAC}_{ij} = \frac{|\bm{\phi}_i^{\top}\bm{\phi}_j|^2}{(\bm{\phi}_i^{\top}\bm{\phi}_i)(\bm{\phi}_j^{\top}\bm{\phi}_j)}$$

- $\text{MAC}_{ii} = 1$（恒等于 1）
- $\text{MAC}_{ij} \approx 0$（$i \neq j$）表示两振型正交/独立
- 若两阶振型 MAC 接近 1 $\to$ 可能是同一物理模态被重复识别

## 8. Python 代码实现

### 8.1 $n$ 自由度系统模态分析

```python
import numpy as np
from scipy.linalg import eigh

def modal_analysis(M, K, n_modes=None):
    """
    n 自由度系统的模态分析
    
    Parameters
    ----------
    M, K : (n, n) ndarray
        质量和刚度矩阵（对称）
    n_modes : int, optional
        需要保留的模态数（默认全部）
    
    Returns
    -------
    omega_n : (n_modes,) ndarray  固有频率 (rad/s)
    phi : (n, n_modes) ndarray    模态矩阵（质量归一化）
    f_n : (n_modes,) ndarray      固有频率 (Hz)
    """
    n = M.shape[0]
    if n_modes is None or n_modes > n:
        n_modes = n
    
    # 仅求解前 n_modes 阶
    eigvals, eigvecs = eigh(K, M, subset_by_index=(0, n_modes - 1))
    
    omega_sq = np.maximum(eigvals, 0.0)
    omega_n = np.sqrt(omega_sq)
    f_n = omega_n / (2 * np.pi)
    
    # 质量归一化：phi^T M phi = I
    phi = np.zeros((n, n_modes))
    for i in range(n_modes):
        vec = eigvecs[:, i]
        norm = np.sqrt(vec @ M @ vec)
        phi[:, i] = vec / norm if norm > 1e-15 else vec
    
    return omega_n, phi, f_n


# ============ 示例：n 自由度弹簧-质量链 ============
def build_chain_system(n_dof, m_val=1.0, k_val=1000.0, 
                        fixed_both_ends=True):
    """构建 n 自由度弹簧-质量链的 M 和 K"""
    M = m_val * np.eye(n_dof)
    K = np.zeros((n_dof, n_dof))
    
    for i in range(n_dof):
        if fixed_both_ends:
            K[i, i] = 2 * k_val if 0 < i < n_dof - 1 else k_val
        else:
            K[i, i] = (2 if 0 < i < n_dof - 1 else 1) * k_val
        if i > 0:
            K[i, i-1] = -k_val
        if i < n_dof - 1:
            K[i, i+1] = -k_val
    
    return M, K


n_dof = 10
M, K = build_chain_system(n_dof)

omega_n, phi, f_n = modal_analysis(M, K)

for i in range(min(5, n_dof)):
    print(f"Mode {i+1}: ω = {omega_n[i]:8.2f}, "
          f"f = {f_n[i]:8.3f} Hz")

# 验证正交性
I_err = np.max(np.abs(phi.T @ M @ phi - np.eye(n_dof)))
print(f"\n正交性验证: max|ΦᵀMΦ - I| = {I_err:.2e}")
```

### 8.2 模态参与因子与有效质量

```python
def modal_participation_factors(M, phi, direction=None):
    """
    计算模态参与因子和有效模态质量
    
    direction: (n,) array  基础运动方向向量（默认 = [1,1,...,1]^T）
    """
    n, n_modes = phi.shape
    if direction is None:
        direction = np.ones(n)
    
    gamma = np.zeros(n_modes)
    m_eff = np.zeros(n_modes)
    
    Mr = M @ direction
    total_mass = direction @ Mr
    
    for i in range(n_modes):
        gamma[i] = phi[:, i] @ Mr  # (质量归一化后 m_i = 1)
        m_eff[i] = gamma[i] ** 2
    
    cumsum_m_eff = np.cumsum(m_eff) / total_mass
    
    return gamma, m_eff, cumsum_m_eff, total_mass

gamma, m_eff, cum_ratio, M_total = modal_participation_factors(M, phi)

print(f"总质量 = {M_total:.2f}")
print(f"\n{'Mode':<6} {'m_eff':<10} {'累计/总质量':<12}")
for i in range(min(5, n_dof)):
    print(f"{i+1:<6} {m_eff[i]:<10.4f} {cum_ratio[i]:<12.4f}")

# 确定满足 90% 准则所需模态数
r_90 = np.searchsorted(cum_ratio, 0.90) + 1
print(f"\n满足 90%% 有效质量准则需 {r_90} 阶模态 (共 {n_dof} 阶)")
```

### 8.3 模态叠加法时域求解

```python
def modal_superposition_ndof(M, K, F, t, zeta=None, 
                              alpha=None, beta=None):
    """
    模态叠加法求解 n 自由度系统（Rayleigh 阻尼）
    
    Parameters
    ----------
    M, K : (n, n) ndarray
    F : (n_step, n_dof) ndarray  外力
    t : (n_step,) ndarray        时间
    zeta : (n_dof,) ndarray      各阶模态阻尼比
    alpha, beta : float          Rayleigh 系数（若 zeta=None）
    """
    n_dof = M.shape[0]
    n_step = len(t)
    dt = t[1] - t[0]
    
    # 模态分析
    omega_n, phi, _ = modal_analysis(M, K)
    
    # 计算阻尼比
    if zeta is None:
        if alpha is not None and beta is not None:
            zeta = 0.5 * (alpha / omega_n + beta * omega_n)
        else:
            zeta = np.full(n_dof, 0.01)
    
    # 模态力
    f_modal = F @ phi  # (n_step, n_dof)
    
    # 各模态 Duhamel 积分
    q = np.zeros((n_step, n_dof))
    for mode in range(n_dof):
        w = omega_n[mode]
        z = zeta[mode]
        if z >= 1:
            continue
        wd = w * np.sqrt(1 - z**2)
        fm = f_modal[:, mode]
        
        for i in range(1, n_step):
            tau = t[i] - t[:i+1]
            h = np.exp(-z * w * tau) * np.sin(wd * tau) / wd
            q[i, mode] = np.trapz(fm[:i+1] * h[::-1], dx=dt)
    
    # 物理坐标
    x = (phi @ q.T).T  # (n_step, n_dof)
    return x, q, phi, omega_n
```

### 8.4 频响函数矩阵计算

```python
def compute_frf_matrix(omega_n, phi, zeta, omega_range):
    """
    由模态参数计算频响函数矩阵 H(ω)
    
    Returns: H (n_freq, n_dof, n_dof) - complex
    """
    n_dof, n_modes = phi.shape
    n_freq = len(omega_range)
    H = np.zeros((n_freq, n_dof, n_dof), dtype=complex)
    
    for i, w in enumerate(omega_range):
        for mode in range(n_modes):
            wm = omega_n[mode]
            zm = zeta[mode]
            denom = wm**2 - w**2 + 2j * zm * wm * w
            H[i] += np.outer(phi[:, mode], phi[:, mode]) / denom
    
    return H


# 使用示例
omega_scan = np.linspace(1, 100, 2000)
zeta_all = np.full(n_dof, 0.02)
H_mat = compute_frf_matrix(omega_n, phi, zeta_all, omega_scan)

# H_{5,1}(omega): 第 1 DOF 激励 -> 第 5 DOF 响应
FRF_5_1 = np.abs(H_mat[:, 4, 0])
```

### 8.5 Rayleigh 阻尼系数拟合

```python
def fit_rayleigh_damping(omega_i, omega_j, zeta_i, zeta_j):
    """
    由两阶模态阻尼比拟合 Rayleigh 系数
    """
    denom = omega_j**2 - omega_i**2
    alpha = 2 * omega_i * omega_j * (zeta_i * omega_j - zeta_j * omega_i) / denom
    beta = 2 * (zeta_j * omega_j - zeta_i * omega_i) / denom
    return alpha, beta

# 例：要求第 1 阶和第 4 阶模态均为 2% 阻尼比
alpha_fit, beta_fit = fit_rayleigh_damping(omega_n[0], omega_n[3], 0.02, 0.02)
print(f"Rayleigh 系数: alpha = {alpha_fit:.6f}, beta = {beta_fit:.6f}")

# 验证
zeta_fitted = 0.5 * (alpha_fit / omega_n + beta_fit * omega_n)
print(f"拟合后各阶阻尼比: {zeta_fitted}")
```

## 关键公式总结

| 公式 | 表达式 | 说明 |
|---|---|---|
| 运动方程 | $\mathbf{M}\ddot{\mathbf{x}} + \mathbf{C}\dot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{F}$ | $n$ DOF 一般形式 |
| 特征值问题 | $(\mathbf{K} - \omega^2\mathbf{M})\bm{\phi} = \mathbf{0}$ | 广义特征值 |
| 频率方程 | $\det(\mathbf{K} - \omega^2\mathbf{M}) = 0$ | $n$ 次方程 |
| 正交性 (M) | $\mathbf{\Phi}^{\top}\mathbf{M}\mathbf{\Phi} = \mathbf{I}$ | 质量归一化后 |
| 正交性 (K) | $\mathbf{\Phi}^{\top}\mathbf{K}\mathbf{\Phi} = \text{diag}(\omega_i^2)$ | |
| 模态变换 | $\mathbf{x} = \mathbf{\Phi}\mathbf{q}$ | 解耦 |
| 解耦方程 | $\ddot{q}_i + 2\zeta_i\omega_i\dot{q}_i + \omega_i^2 q_i = \bm{\phi}_i^{\top}\mathbf{F}$ | $n$ 个 SDOF |
| Rayleigh 阻尼 | $\mathbf{C} = \alpha\mathbf{M} + \beta\mathbf{K}$ | 比例阻尼 |
| 模态阻尼比 | $\zeta_i = \alpha/(2\omega_i) + \beta\omega_i/2$ | Rayleigh |
| 有效模态质量 | $m_{\text{eff},i} = (\bm{\phi}_i^{\top}\mathbf{M}\mathbf{r})^2$ | 截断准则 |
| FRF 展开 | $\mathbf{H}(\omega) = \sum \frac{\bm{\phi}_i\bm{\phi}_i^{\top}}{\omega_i^2 - \omega^2 + 2i\zeta_i\omega_i\omega}$ | EMA 基础 |
