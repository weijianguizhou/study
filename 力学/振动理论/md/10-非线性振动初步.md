# 非线性振动初步

> 非线性系统展现出叠加原理失效、频率-振幅耦合、跳跃现象、极限环与混沌等独特动力学行为。本章覆盖非线性来源、相平面理论、经典方程（Duffing、Van der Pol、单摆）及近似解法，为后续深入研究打基础。

---

## 10.1 非线性振动的来源

### 几何非线性

大变形下应变-位移关系的非线性化，产生非线性恢复力项：
$$
\kappa = \frac{w''}{[1+(w')^{2}]^{3/2}}
$$
展开后导出三次非线性项。典型包括悬臂梁大挠度、弦的大振幅、薄板大挠度（von Karman板理论）。

### 材料非线性

超出线弹性范围时应力-应变关系偏离胡克定律：
- **弹塑性**：屈服后非线性
- **超弹性**：橡胶 S 形应力-应变曲线
- **黏弹性**：复模量随频率/温度变化

### 接触与间隙非线性

刚度突变/分段线性表现：
- 齿轮齿侧间隙
- 裂纹呼吸效应
- 干摩擦阻尼接合面

### 硬弹簧与软弹簧

| 类型 | 恢复力 | 特征 |
|:---:|:---|:---|
| 硬弹簧 | $F = k_1 x + k_3 x^{3},\, k_3 > 0$ | 振幅增大，频率升高 |
| 软弹簧 | $F = k_1 x + k_3 x^{3},\, k_3 < 0$ | 振幅增大，频率降低 |

对于硬弹簧，势阱比线性弹簧的抛物形势阱更陡，大振幅时约束更强。

### 非线性阻尼

- 二次阻尼：$F_d = c_2|\dot{x}|\dot{x}$
- Coulomb 阻尼：$F_d = \mu N\,\text{sgn}(\dot{x})$
- 黏弹性/迟滞阻尼

## 10.2 非线性系统的特征

### 叠加原理的失效

非线性算子 $\mathcal{N}$ 下 $\mathcal{N}(\alpha x_1 + \beta x_2) \neq \alpha\mathcal{N}(x_1) + \beta\mathcal{N}(x_2)$。对于 Duffing 方程，两解之和不再满足方程——叠加不成立。

### 固有频率随振幅变化

弱非线性 Duffing 系统中频率为振幅的函数：
$$
\omega_n(A) \approx \omega_0\left(1 + \frac{3}{8}\varepsilon A^{2}\right)
$$

- **硬弹簧** $\varepsilon > 0$：频率随振幅增大 → 幅频曲线向右弯
- **软弹簧** $\varepsilon < 0$：频率随振幅减小 → 幅频曲线向左弯

### 跳跃现象（Jump Phenomenon）

这是非线性系统最突出的特征之一：
- **多解区间** $\omega_1 < \omega < \omega_2$ 内存在三个稳态解（两个稳定 + 一个不稳定）
- 扫频上行：振幅到达 $\omega_2$ 后突然降至低分支
- 扫频下行：振幅到达 $\omega_1$ 后突然跳至高分支
- **迟滞效应**：跳动的方向取决于扫频方向

### 次谐波与超谐波共振

非线性系统可将能量在不同频率分量间传递：
- **超谐波共振**：$\omega \approx \omega_n/n$（激励频率为固有频率的分数倍）
- **次谐波共振**：$\omega \approx m\omega_n$（激励频率为固有频率的整数倍）
- **组合共振**：多频激励满足 $\omega_1 \pm \omega_2 \approx \omega_n$

### 自激振动与极限环

自激振动从恒定能源汲取能量维持振荡。极限环是相平面上的孤立闭轨，对应自激稳态周期运动：
- 颤振（flutter）：风速超临界时机翼弯曲-扭转耦合
- 再生颤振：刀具-工件切削颤振
- 黏滑运动：机床导轨爬行

## 10.3 相平面分析

### 相平面（位移-速度平面）

二阶自治系统化为等价一阶微分方程组：
$$
\begin{cases} \dot{x} = y \\ \dot{y} = -f(x,y) \end{cases}
$$
横轴 $x$、纵轴 $y = \dot{x}$ 构成相平面，解在相平面上的轨迹称为**相轨迹**，满足：
$$
\frac{dy}{dx} = -\frac{f(x,y)}{y}
$$

相轨迹沿顺时针方向运行，闭轨对应周期运动，螺旋线对应阻尼振动。

### 奇点（平衡点）的分类

| 阻尼比 $\zeta$ | 特征值性质 | 奇点类型 |
|:---:|:---|:---|
| $\zeta = 0$ | 纯虚数 $\pm i\omega_n$ | 中心（椭圆轨道族） |
| $0 < \zeta < 1$ | 共轭复数，负实部 | 稳定焦点（螺旋收敛） |
| $-1 < \zeta < 0$ | 共轭复数，正实部 | 不稳定焦点 |
| $\zeta > 1$ | 相异负实根 | 稳定结点 |
| $\zeta < -1$ | 相异正实根 | 不稳定结点 |
| 鞍点 | 一正一负实根 | 鞍点 |

### 极限环

稳定极限环：内外轨线均向环线收敛

不稳定极限环：内外轨线均远离环线

半稳定极限环：一侧收敛、一侧发散

> **Poincaré-Bendixson 定理**（平面系统的核心定理）：若无奇点且轨线始终不离开某有界区域，则 $\omega$ 极限集必为奇点、闭轨或奇点与联结轨线构成的连通集。

### 等倾线法

等倾线是相平面上缓斜率为常数的点的轨迹，利用它可以手绘或构图分析相图的全局拓扑结构。

## 10.4 经典非线性方程

### Duffing 方程

$$
\ddot{x} + 2\zeta\dot{x} + \alpha x + \beta x^{3} = F\cos\omega t
$$

- $\beta > 0$：硬弹簧；$\beta < 0$：软弹簧
- 受迫 Duffing 可表现主共振、次谐波和混沌运动
- 无阻尼自由振动具有封闭形式的 Hamilton 函数解

$$
H(x,y) = \frac{1}{2}y^{2} + \frac{1}{2}\alpha x^{2} + \frac{1}{4}\beta x^{4}
$$

双势阱型（$\alpha < 0, \beta > 0$）存在三个平衡点：$x = 0$（鞍点）、$x = \pm\sqrt{-\alpha/\beta}$（中心），是产生混沌的典型系统。

### Van der Pol 方程

$$
\ddot{x} - \mu(1 - x^{2})\dot{x} + x = 0, \quad \mu > 0
$$

自激振荡的经典模型：
- $|x| < 1$ 时负阻尼 → 注入能量
- $|x| > 1$ 时正阻尼 → 耗散能量
- 能量平衡处 $|x| \approx 1$ 形成稳定极限环
- 当 $\mu \ll 1$：接近正弦振荡，振幅 $\approx 2$
- 当 $\mu \gg 1$：弛豫振荡（慢变段 + 快速跳跃）

### 单摆的大振幅振动

精确方程：$\ddot{\theta} + (g/L)\sin\theta = 0$。$\sin\theta$ 展开引入 $\theta^{3}$ 等非线性项。

精确周期（第一类完全椭圆积分）：
$$
T = 4\sqrt{\frac{L}{g}}\,K(k), \quad k = \sin\frac{\theta_{\max}}{2}
$$

级数展开：
$$
T = T_0\left[1 + \frac{1}{4}\sin^{2}\frac{\theta_{\max}}{2} + \frac{9}{64}\sin^{4}\frac{\theta_{\max}}{2} + \cdots\right]
$$

零振幅周期 $T_0 = 2\pi\sqrt{L/g}$。当 $\theta_{\max} = 90^{\circ}$ 时，$T \approx 1.18 T_0$（误差约 18%）。

若总能量超过鞍点势能（$\theta = \pi$），单摆进入单向旋转而非往复摆动。相图中的**分界线（separatrix）**为连接鞍点的特殊轨道，分隔摆动与旋转。

## 10.5 近似解法

### 摄动法（Perturbation Method）

将解展开为小参数 $\varepsilon$ 的幂级数：
$$
x(t,\varepsilon) = x_0(t) + \varepsilon x_1(t) + \varepsilon^{2}x_2(t) + \cdots
$$

问题：直接展开常导致**长期项**（$t\cos\omega t$），破坏解的有界性。

### Lindstedt-Poincaré 法

同时展开频率和解：$\omega^{2} = \omega_0^{2} + \varepsilon\omega_1^{2} + \varepsilon^{2}\omega_2^{2} + \cdots$

引入新时间变量 $\tau = \omega t$，选择各阶 $\omega_i^{2}$ 消除长期项。频率-振幅关系为：
$$
\omega = \omega_0\left[1 + \frac{3\varepsilon}{8\omega_0^{2}}A^{2} - \frac{15\varepsilon^{2}}{256\omega_0^{4}}A^{4} + \mathcal{O}(A^{6})\right]
$$

### 平均法（Method of Averaging）

假设解形如 $x = a(t)\cos[\omega_0 t + \beta(t)]$ 的慢变幅-相形式，利用"振幅和相位在一个周期内变化很小"的特性，对右端函数跨周期取平均。所得的自治化幅值相方程给出稳态解与稳定性。

### 谐波平衡法（Harmonic Balance Method）

假设稳态解为截断 Fourier 级数，代入方程后令各谐波系数相等，导出幅频代数方程组。

对 Duffing 方程取单谐波近似 $x = A\cos(\omega t - \phi)$，得：
$$
\left[(\alpha - \omega^{2})A + \frac{3}{4}\beta A^{3}\right]^{2} + (2\zeta\omega A)^{2} = F^{2}
$$

## 10.6 混沌振动简介

### 确定性混沌的特征

1. **对初值极端敏感**：相邻轨线指数分离
2. **拓扑传递性**：有限区域内轨线遍历
3. **稠密周期轨线**：任意邻域内存在无穷多不稳定周期轨线

### Lyapunov 指数

$$
\lambda = \lim_{t\to\infty} \frac{1}{t}\ln\frac{\|\delta\mathbf{x}(t)\|}{\|\delta\mathbf{x}_0\|}
$$

- $\lambda < 0$：规则运动（收敛）
- $\lambda = 0$：中性稳定（周期/准周期）
- $\lambda > 0$：混沌

最大 Lyapunov 指数 $\lambda_1$ 为混沌的首要指示器。

### Poincaré 截面

每周期采样一次，将连续系统降维为 Poincaré 映射 $\mathbf{P}: \mathbb{R}^{2} \to \mathbb{R}^{2}$：
- **周期-$k$ 运动**：截面上 $k$ 个点
- **准周期运动**：截面上为闭合曲线
- **混沌运动**：截面呈分形点集（奇怪吸引子）

### 分岔（Bifurcation）

随参数连续变化，相图拓扑结构发生质的改变：
- **鞍结分岔**：稳定与不稳定不动点碰撞消失
- **Hopf 分岔**：焦点失稳并产生极限环
- **倍周期分岔**：$T \to 2T \to 4T \to \dots$（通向混沌的主要路径之一）

## 10.7 Python 代码

### Duffing 方程数值求解与相平面绘制

```python
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def duffing(t, y, delta, alpha, beta, gamma, omega):
    x, v = y
    dxdt = v
    dvdt = -delta * v - alpha * x - beta * x**3 + gamma * np.cos(omega * t)
    return [dxdt, dvdt]

delta, alpha, beta, gamma, omega = 0.25, -1.0, 1.0, 0.3, 1.0
y0 = [0.5, 0.0]

sol = solve_ivp(duffing, (0, 500), y0,
                args=(delta, alpha, beta, gamma, omega),
                t_eval=np.linspace(0, 500, 20000), method='RK45', rtol=1e-9)
x, v = sol.y

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))
ax1.plot(sol.t[-2000:], x[-2000:], lw=0.6)
ax1.set_xlabel('$t$'); ax1.set_ylabel('$x(t)$')
ax1.set_title('Duffing方程时程')
ax2.plot(x[-4000:], v[-4000:], lw=0.3, color='blue')
ax2.set_xlabel('$x$'); ax2.set_ylabel('$\\dot{x}$')
ax2.set_aspect('equal')
ax2.set_title('相图')
plt.tight_layout(); plt.show()
```

### 分岔图

```python
def bifurcation_diagram(gamma_range, n_transient=300, n_sample=100):
    delta, alpha, beta, omega = 0.25, -1.0, 1.0, 1.0
    T = 2 * np.pi / omega
    bifur = []
    for gamma in gamma_range:
        sol = solve_ivp(duffing, [0, (n_transient + n_sample) * T],
                        [0.5, 0.0],
                        args=(delta, alpha, beta, gamma, omega),
                        max_step=T/50, rtol=1e-9)
        x_vals = sol.y[0, -n_sample:]
        bifur.extend([(gamma, xv) for xv in x_vals])
    return np.array(bifur)

gamma_vals = np.linspace(0.1, 0.5, 400)
data = bifurcation_diagram(gamma_vals)
plt.figure(figsize=(10, 6))
plt.plot(data[:,0], data[:,1], 'k.', markersize=0.3, alpha=0.6)
plt.xlabel('$\\gamma$'); plt.ylabel('$x$ (Poincaré)')
plt.title('Duffing 方程分岔图')
plt.tight_layout(); plt.show()
```
