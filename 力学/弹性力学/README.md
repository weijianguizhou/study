# 课程笔记 / 笔记模板

本目录包含两套可独立使用的 LaTeX 笔记模板。

## 1. 课程笔记模板（「李思风」极简学术）— 默认

主文件 `课程笔记模板.tex`，样式 `preamble.tex`。中文 `book`，方正宋体、
细边框圆角定理盒、行内加粗标签，内置 12 款封面。**用 XeLaTeX 编译两次。**

```
课程笔记模板.tex      # 主文件（替换所有 【】 即可用）
preamble.tex          # 样式：字体 / 配色 / 定理·定义·例题环境
封面/                 # 12 款封面 + 封面模板索引.md
章节示例/             # 前言.tex、绪论.tex、第一章示例.tex、附录.tex
说明文档/             # 符号约定与工作要求.md
```

用法：

1. 把整个 `课程笔记` 目录复制到新项目；
2. 打开 `课程笔记模板.tex`，替换所有 `【】`；
3. 换封面：改主文件里的 `\input{封面/cover_*}`（见 `封面/封面模板索引.md`，一次只启用一行）；
4. XeLaTeX 编译两次。

> 章节文件顶部保留 `% !TeX root = ../课程笔记模板.tex`，否则单编章节会报假错误。

## 2. 笔记整理模板（分栏 & 多主题框）

位于子目录 `笔记整理模板（分栏&多主题框）/`，基于自定义文类 `textbook.cls`，
含中/英两个主文件、参考文献与示例章节。

```
笔记整理模板（分栏&多主题框）/
├── cn-mynotes.tex      # 中文主文件
├── mynote.tex          # 英文主文件
├── textbook.cls        # 文类（分栏、多主题框、定理环境）
├── main.bib            # 参考文献
├── 导言.tex、摘要.tex
├── 1.tex … 5.tex       # 中文示例章节（泛函分析）
├── Appendix.tex
├── chapter1.tex … chapter4.tex   # 英文示例章节
└── images/             # 图片素材
```

用法：进入该子目录，用 XeLaTeX 编译 `cn-mynotes.tex` 或 `mynote.tex`。

> 说明：`chapter1–4.tex` 目前内容彼此相同，是示例占位文件，可按需精简。
