## 1. 符号约定

### 1.1 字型（粗体 / 正体）

| 对象 | 记号 | 说明 |
|---|---|---|
| 向量（含希腊字母） | `\boldsymbol{...}` | 如 $\boldsymbol{a}$、$\boldsymbol{\lambda}$、$\boldsymbol{\rho}$、$\boldsymbol{\epsilon}$、$\boldsymbol{\omega}$、$\boldsymbol{v}$ |
| 矩阵 | `\boldsymbol{...}` | 如方向余弦矩阵 $\boldsymbol{A}$、单位阵 $\boldsymbol{I}$、叉乘矩阵 $\boldsymbol{\tilde{\omega}}$ |
| 标量分量 / 元素 | 不加粗 | $a_{ij}$、$\omega_i$、$\epsilon_4$、$\lambda_i$ |
| 单位向量组 | `\mathbf{...}` | $\mathbf{a}_i$、$\mathbf{b}_i$、$\mathbf{e}_{i\|A}$（沿用正文已有风格） |

**关键规则：**
- 矩阵一律粗体（`\boldsymbol`），**不用** `\mathbf` 表示矩阵。
- 希腊字母向量**必须**用 `\boldsymbol`——`\mathbf{\lambda}`、`\mathbf{\epsilon}` 对希腊字母**不生效**（会显示为不加粗），这是常见 bug。
- 加粗只作用于符号本身，不加粗 `\times`、`+`、数字、$\mu$ 等。

### 1.2 方向余弦矩阵

- 方向余弦矩阵统一用 $\boldsymbol{A}$，元素统一用 $a_{ij}$（$\bar{a}_{ij}$ 亦可）。
- 关系：$v_A = \boldsymbol{A}\,v_B$、$\boldsymbol{A}^{\mathrm{T}}\boldsymbol{A}=\boldsymbol{I}$（正交性，性质五）。
- 连续转动中的相对方向余弦矩阵保留 $\boldsymbol{C}_{A\bar B},\boldsymbol{C}_{\bar B B},\boldsymbol{C}_{AB}$（**加粗**），不再用单字母 `C`。

### 1.3 相对量与参考系：右下标约定（禁止左右上标）

**一律使用右下标，禁止 `${}^A\omega^B$ 这类左右上标写法。**

**关键规则：凡表示"在参考系 $x$ 中表达/取分量"的下标，一律写成 `|x`（竖线+参考系字母），
例如 $\nu_{i|A}$、$\boldsymbol{\nu}_{|A}$、$\dfrac{\mathrm{d}\boldsymbol{v}}{\mathrm{d}t}\Big|_A$、
$\mathbf{v}_{|A}$、$\boldsymbol{I}_{|A}$。相对转动量同样用竖线：$\boldsymbol{\omega}_{X|Y}$ 表示
**X 在 Y 中的角速度**（竖线前=物体，竖线后=参考系）。罗德里格斯向量沿用双下标 $\boldsymbol{\rho}_{AB}$。**

| 含义 | 记号 |
|---|---|
| $B$ 在 $A$ 中的角速度（竖线前=物体，竖线后=参考系） | $\boldsymbol{\omega}_{B\|A}$ |
| $A$ 在 $B$ 中的角速度 | $\boldsymbol{\omega}_{A\|B}$ |
| 反对称性 | $\boldsymbol{\omega}_{B\|A}=-\boldsymbol{\omega}_{A\|B}$ |
| $B$ 相对 $A$ 的罗德里格斯向量 | $\boldsymbol{\rho}_{AB}$，分量 $\rho_{AB,i}$ |
| 向量 $\boldsymbol{v}$ 在参考系 $A$ 中的一阶时间导数 | $\dfrac{\mathrm{d}\boldsymbol{v}}{\mathrm{d}t}\Big\|_A$ |
| $\boldsymbol{v}$ 在 $A$ 中的分量行阵 | $\boldsymbol{\nu}_{\|A}$（在 $B$ 中 $\boldsymbol{\nu}_{\|B}$） |
| 分量行阵的时间导数 | $\dot{\boldsymbol{\nu}}_{\|A}$、$\dot{\boldsymbol{\nu}}_{\|B}$ |
| 分量 | $\nu_{i\|A}$、$\nu_{i\|B}$（沿用 $\boldsymbol{e}_{i\|A}$ 的 `|A` 风格） |
| 向量 $\boldsymbol{v}$ 在 $A$ 中的投影列阵 | $\mathbf{v}_{\|A}$（在 $B$ 中 $\mathbf{v}_{\|B}$） |
| 投影列阵对应的叉乘矩阵 | $\tilde{\boldsymbol{v}}_{\|A}$、$\tilde{\boldsymbol{v}}_{\|B}$ |
| 惯性并矢在 $A$ 中的矩阵/分量 | $\boldsymbol{I}_{\|A}$、$\boldsymbol{I}_{ij\|A}$ |

### 1.4 角速度

- 角速度**向量**：$\boldsymbol{\omega}$（加粗）。
- 角速度**矩阵**（叉乘矩阵）：$\boldsymbol{\tilde{\omega}}$，满足
  $\boldsymbol{\tilde{\omega}} = \boldsymbol{A}^{\mathrm{T}}\dot{\boldsymbol{A}}$，
  $\dot{\boldsymbol{A}} = \boldsymbol{A}\,\boldsymbol{\tilde{\omega}}$，
  其分量式
  $\boldsymbol{\tilde{\omega}}=\begin{bmatrix}0&-\omega_3&\omega_2\\ \omega_3&0&-\omega_1\\ -\omega_2&\omega_1&0\end{bmatrix}$。
- 分量 $\omega_1,\omega_2,\omega_3$ 不加粗。

## 2. 工作要求（编辑规范）

### 2.1 公式环境

- 所有行间公式一律用 `equation` 环境并加 `\label`；
- **禁止** `$$...$$`、裸 `$$`、行内散落的 `(1)`、`(2)`… 手写编号、`\tag{}`；
- 多行公式用 `aligned` 包在单个 `equation` 中。

### 2.2 label 命名

格式：`eq:小节:描述`，描述可用中文。

例：
```latex
\label{eq:角速度矢量:定义}
\label{eq:角速度矩阵:反对称形式}
\label{eq:螺旋运动:a_star公式}
\label{eq:方向余弦的定义}
```

### 2.3 交叉引用

- 用 `\eqref{label}`（编号带括号）、`\ref{label}`、`\pageref{label}`；
- 正文提到某式时写「由式~\eqref{...}」。

### 2.4 记号一致性检查清单

- [ ] 无左右上标 `${}^A...`（应改为右下标）；
- [ ] "在参考系 $x$ 中表达"的下标一律用 `|x`（如 $\nu_{i|A}$、$\boldsymbol{\nu}_{|A}$、$\dfrac{\mathrm{d}\boldsymbol{v}}{\mathrm{d}t}\Big|_A$、$\mathbf{v}_{|A}$、$\boldsymbol{I}_{|A}$）；
- [ ] 角速度用竖线下标 $\boldsymbol{\omega}_{X|Y}$（X 在 Y 中），反对称 $\boldsymbol{\omega}_{B|A}=-\boldsymbol{\omega}_{A|B}$；罗德里格斯向量 $\boldsymbol{\rho}_{AB}$；
- [ ] 矩阵全部 `\boldsymbol` 粗体；
- [ ] 希腊向量用 `\boldsymbol`，无 `\mathbf{\lambda}` 类错误；
- [ ] 方向余弦矩阵统一 $\boldsymbol{A}$、元素 $a_{ij}$；
- [ ] $\tilde{\omega}$ / $\widetilde{\omega}$ 统一为 $\boldsymbol{\tilde{\omega}}$；
- [ ] `\mathrm{T}`、`\mathrm{d}` 用正体（`^{\mathrm{T}}`、`\frac{\mathrm{d}}{\mathrm{d}t}`）。

### 2.6 常用替换对照表

| 旧写法 | 新写法 |
|---|---|
| `${}^A\boldsymbol{\omega}^B` | `\boldsymbol{\omega}_{B|A}` |
| `${}^B\boldsymbol{\omega}^A` | `\boldsymbol{\omega}_{A|B}` |
| `${}^A\frac{\mathrm{d}\boldsymbol{v}}{\mathrm{d}t}` | `\frac{\mathrm{d}\boldsymbol{v}}{\mathrm{d}t}\Big|_A` |
| `${}^A\boldsymbol{\nu}` / `${}^A\dot{\boldsymbol{\nu}}` | `\boldsymbol{\nu}_{|A}` / `\dot{\boldsymbol{\nu}}_{|A}` |
| `${}^A\nu_i` / `${}^A\dot{\nu}_1` | `\nu_{i|A}` / `\dot{\nu}_{1|A}` |
| `${}^A\boldsymbol{\rho}^B` | `\boldsymbol{\rho}_{AB}` |
| `\mathbf{v_A}` / `\mathbf{v_B}` | `\mathbf{v}_{|A}` / `\mathbf{v}_{|B}` |
| `\tilde{\boldsymbol{v}}_A` / `\tilde{\boldsymbol{v}}_B` | `\tilde{\boldsymbol{v}}_{|A}` / `\tilde{\boldsymbol{v}}_{|B}` |
| `\boldsymbol{I}_A` / `\boldsymbol{I}_B` | `\boldsymbol{I}_{|A}` / `\boldsymbol{I}_{|B}` |
| `\tilde{\mathbf{v}}` / `\tilde{\mathbf{p}}` / `\tilde{\mathbf{q}}` / `\tilde{\mathbf{r}}` | `\tilde{\boldsymbol{v}}` / … |
| `\mathbf{A}_{AB}` / `\mathbf{A}_{ij}` | `\boldsymbol{A}_{AB}` / `\boldsymbol{A}_{ij}` |
| `\mathbf{\lambda}` | `\boldsymbol{\lambda}` |
| `\tilde{\omega}` / `\widetilde{\omega}` | `\boldsymbol{\tilde{\omega}}` |
| `C_{A\bar B}` / `C_{\bar B B}` / `C_{AB}` | `\boldsymbol{C}_{A\bar B}` / `\boldsymbol{C}_{\bar B B}` / `\boldsymbol{C}_{AB}` |
| 旋转矩阵 `C` / 普通 `A` | `\boldsymbol{A}`（元素 `a_{ij}`） |
