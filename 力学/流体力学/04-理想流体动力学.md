# 第四章 理想流体动力学

[[00-流体力学MOC|流体力学索引]]

---

理想流体（inviscid fluid）即 $\mu=0$ 的无粘流体。虽然真实流体都有粘性，但在许多大 Reynolds 数问题中粘性影响仅限于壁面附近的边界层内，主流区可近似为理想流体。本章建立理想流体的控制方程，并系统讨论 Bernoulli 方程、势流理论、复变方法及其在工程中的应用。

[[../../数理基础/向量微积分]] 和 [[../../数理基础/数学物理方程/00-数学物理方程MOC|偏微分方程]] 是本章的重要数学基础。

## 4.1 欧拉方程

### 4.1.1 雷诺输运定理

对任意控制体 $V(t)$，物理量 $\Phi = \int_{V(t)}\rho\phi\,dV$ 的物质导数由 Reynolds 输运定理给出：

$$
\frac{D\Phi}{Dt} = \frac{D}{Dt}\int_{V(t)}\rho\phi\,dV = \int_{V(t)}\frac{\partial(\rho\phi)}{\partial t}\,dV + \oint_{S(t)}\rho\phi\,\mathbf{u}\cdot\mathbf{n}\,dS
$$

该定理连接了系统法（Lagrange 描述）与控制体法（Euler 描述），是推导流体力学控制方程的桥梁。

### 4.1.2 动量方程的推导

对有限控制体应用动量守恒定律：控制体内动量的变化率等于体积力与表面力之和。

$$
\frac{D}{Dt}\int_{V(t)}\rho\mathbf{u}\,dV = \int_{V(t)}\rho\mathbf{f}\,dV + \oint_{S(t)}\mathbf{n}\cdot\boldsymbol{\sigma}\,dS
$$

运用 Reynolds 输运定理和高斯散度定理：

$$
\int_V\left[\frac{\partial(\rho\mathbf{u})}{\partial t} + \nabla\cdot(\rho\mathbf{u}\mathbf{u})\right]dV = \int_V\rho\mathbf{f}\,dV + \int_V\nabla\cdot\boldsymbol{\sigma}\,dV
$$

由于控制体任意性，得到微分形式的 Cauchy 动量方程：

$$
\rho\frac{D\mathbf{u}}{Dt} = \rho\mathbf{f} + \nabla\cdot\boldsymbol{\sigma}
$$

或分量形式：

$$
\rho\frac{Du_i}{Dt} = \rho f_i + \frac{\partial\sigma_{ji}}{\partial x_j}
$$

该方程适用于**任何连续介质**，是其应力张量 $\boldsymbol{\sigma}$ 的本构关系尚未引入时的通用形式。

### 4.1.3 理想流体的应力张量

理想流体内部无剪切应力，只有法向压力：

$$
\sigma_{ij} = -p\delta_{ij}
$$

其中 $p$ 为热力学压力，$\delta_{ij}$ 为 Kronecker delta。负号表示压力沿法向向内。

代入 Cauchy 动量方程：

$$
\rho\frac{Du_i}{Dt} = \rho f_i - \frac{\partial p}{\partial x_i}
$$

矢量形式即为**欧拉方程**（Euler equations, 1755）：

$$
\boxed{\rho\frac{D\mathbf{u}}{Dt} = -\nabla p + \rho\mathbf{f}}
$$

### 4.1.4 直角坐标展开

在 $(x,y,z)$ 坐标系中展开物质导数：

$$
\begin{cases}
\displaystyle \rho\left(\frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y} + w\frac{\partial u}{\partial z}\right) = -\frac{\partial p}{\partial x} + \rho f_x \\[10pt]
\displaystyle \rho\left(\frac{\partial v}{\partial t} + u\frac{\partial v}{\partial x} + v\frac{\partial v}{\partial y} + w\frac{\partial v}{\partial z}\right) = -\frac{\partial p}{\partial y} + \rho f_y \\[10pt]
\displaystyle \rho\left(\frac{\partial w}{\partial t} + u\frac{\partial w}{\partial x} + v\frac{\partial w}{\partial y} + w\frac{\partial w}{\partial z}\right) = -\frac{\partial p}{\partial z} + \rho f_z
\end{cases}
$$

### 4.1.5 兰姆-葛罗米柯形式

利用矢量恒等式可将对流项改写为：

$$
(\mathbf{u}\cdot\nabla)\mathbf{u} = \nabla\left(\frac{q^2}{2}\right) - \mathbf{u}\times\boldsymbol{\omega}
$$

其中 $q = |\mathbf{u}|$ 为速度大小，$\boldsymbol{\omega} = \nabla\times\mathbf{u}$ 为**涡量**（vorticity）。代入 Euler 方程：

$$
\frac{\partial\mathbf{u}}{\partial t} + \nabla\left(\frac{q^2}{2}\right) - \mathbf{u}\times\boldsymbol{\omega} = -\frac{1}{\rho}\nabla p + \mathbf{f}
$$

该形式将涡量显式引入方程，为后续导出 Bernoulli 方程和讨论涡动力学奠定了基础。

### 4.1.6 涡量方程

对 Euler 方程取旋度，利用 $\nabla\times\nabla(\cdot)=0$，得到涡量输运方程：

$$
\frac{D\boldsymbol{\omega}}{Dt} = (\boldsymbol{\omega}\cdot\nabla)\mathbf{u} - \boldsymbol{\omega}(\nabla\cdot\mathbf{u})
$$

对不可压流体 $\nabla\cdot\mathbf{u}=0$：

$$
\frac{D\boldsymbol{\omega}}{Dt} = (\boldsymbol{\omega}\cdot\nabla)\mathbf{u}
$$

这表明在理想流体中涡线随流体运动，涡管强度守恒。对比 [[05-粘性流体动力学]] 中的涡量方程将看到粘性项 $\nu\nabla^2\boldsymbol{\omega}$ 的出现。

## 4.2 伯努利方程

Bernoulli 方程是 Euler 方程沿流线或全场的第一积分，流体力学中最重要的关系式之一。

### 4.2.1 沿流线积分（定常有旋）

假设：
1. **定常**：$\partial/\partial t = 0$
2. **质量力有势**：$\mathbf{f} = -\nabla\Pi$，重力场中 $\Pi = gz$
3. **密度为常数**（或正压流体 $\rho = \rho(p)$）

沿流线方向取线元 $d\mathbf{l} = \mathbf{u}\,dt$，点乘兰姆形式方程：

$$
\nabla\left(\frac{q^2}{2}\right)\cdot d\mathbf{l} - (\mathbf{u}\times\boldsymbol{\omega})\cdot d\mathbf{l} = -\frac{1}{\rho}\nabla p\cdot d\mathbf{l} - \nabla\Pi\cdot d\mathbf{l}
$$

由于 $\mathbf{u}\times\boldsymbol{\omega} \perp \mathbf{u}$，$(\mathbf{u}\times\boldsymbol{\omega})\cdot d\mathbf{l}=0$。沿流线积分：

$$
\int d\left(\frac{q^2}{2}\right) + \int\frac{dp}{\rho} + \int d\Pi = \text{const}
$$

对于不可压流体 $\rho = \text{const}$：

$$
\boxed{\frac{p}{\rho} + \frac{q^2}{2} + gz = C} \quad \text{沿流线}
$$

各项量纲为 $\text{J/kg}$（单位质量能量）：

$$
\frac{p}{\rho} \;\; \text{压强势能} \quad \frac{q^2}{2} \;\; \text{动能} \quad gz \;\; \text{重力势能}
$$

工程中常乘以 $\rho$ 写为压力形式：

$$
\boxed{p + \frac12\rho q^2 + \rho gz = p_0}
$$

其中 $p_0$ 为总压（stagnation pressure），$p$ 为静压，$\frac12\rho q^2$ 为动压（dynamic pressure）。

### 4.2.2 无旋流动的全场 Bernoulli 方程

若流动无旋 $\boldsymbol{\omega} = 0$，则 $(\mathbf{u}\times\boldsymbol{\omega})=0$ 在全场成立，积分常数不依赖于流线选择：

$$
\frac{p}{\rho} + \frac{q^2}{2} + gz = \text{const} \quad \text{全流场}
$$

这是无旋势流的重要特性：整个流场具有相同的总能量。

### 4.2.3 非定常 Bernoulli 方程

对于无旋非定常流动，存在速度势 $\phi$ 使得 $\mathbf{u} = \nabla\phi$。兰姆形式变为：

$$
\nabla\left(\frac{\partial\phi}{\partial t}\right) + \nabla\left(\frac{q^2}{2}\right) = -\frac{1}{\rho}\nabla p - \nabla\Pi
$$

沿任意路径积分：

$$
\boxed{\frac{\partial\phi}{\partial t} + \frac{q^2}{2} + \frac{p}{\rho} + gz = F(t)}
$$

$F(t)$ 为时间函数，可通过边界条件确定。例如对于自由面波动问题，$F(t)$ 与波高等有关。

### 4.2.4 可压缩流的 Bernoulli 方程

对正压流体 $p = C\rho^\gamma$（等熵过程）：

$$
\int\frac{dp}{\rho} = \frac{\gamma}{\gamma-1}\frac{p}{\rho}
$$

Bernoulli 方程：

$$
\frac{q^2}{2} + \frac{\gamma}{\gamma-1}\frac{p}{\rho} + gz = \text{const}
$$

其中 $\gamma = c_p/c_v$ 为比热比。

## 4.3 伯努利方程的应用

### 4.3.1 皮托管测速

皮托管（Pitot tube）将总压孔对准来流，静压孔感受当地静压。驻点处 $q=0$，测得总压 $p_0$：

$$
p_0 = p_\infty + \frac12\rho U^2
$$

来流速度：

$$
U = \sqrt{\frac{2(p_0-p_\infty)}{\rho}}
$$

对高速气流需考虑压缩性修正。实际 Pitot 管头部形状影响校准系数，工程中引入修正因子 $C_p$。

### 4.3.2 文丘里流量计

文丘里管（Venturi tube）利用收缩-扩张段产生压差测量流量。设入口截面 $A_1$、喉部 $A_2$：

连续性方程：$A_1u_1 = A_2u_2$

Bernoulli 方程（忽略损失）：

$$
p_1 + \frac12\rho u_1^2 = p_2 + \frac12\rho u_2^2
$$

解得理论流量：

$$
Q = A_2\sqrt{\frac{2(p_1-p_2)}{\rho[1-(A_2/A_1)^2]}}
$$

实际流量需乘以排放系数 $C_d$（约为 0.95-0.99）：

$$
Q_{\text{actual}} = C_d Q
$$

### 4.3.3 托里拆利小孔出流

大容器侧壁小孔，液面距孔口高度 $h$。Bernoulli 方程取自由液面（$u\approx0, p=p_a$）和孔口处（$p=p_a$）：

$$
\rho gh + p_a = \frac12\rho u^2 + p_a
$$

**托里拆利定理**（Torricelli, 1643）：

$$
\boxed{u = \sqrt{2gh}}
$$

结果与自由落体速度相同（能量守恒）。实际速度略小，引入流速系数 $C_v \approx 0.97$。

### 4.3.4 虹吸管

虹吸管（siphon）利用大气压差实现液体的跨壁传输。管中最高点压力最低，若低于饱和蒸汽压则发生气蚀（cavitation），流动中断。

### 4.3.5 空化（汽蚀）

当局部压力降至该温度下的饱和蒸汽压 $p_v$，液体汽化形成空泡：

$$
p_{\min} \le p_v
$$

空泡溃灭产生局部高温高压，严重侵蚀固体表面。空化数（cavitation number）：

$$
\sigma_c = \frac{p_\infty - p_v}{\frac12\rho U^2}
$$

### 4.3.6 压力系数

工程无量纲量——压力系数（pressure coefficient）：

$$
C_p = \frac{p - p_\infty}{\frac12\rho U^2} = 1 - \left(\frac{q}{U}\right)^2
$$

Bernoulli 方程的直接结果。

## 4.4 速度势与流函数

### 4.4.1 速度势

对无旋流动 $\nabla\times\mathbf{u}=0$，存在标量势 $\phi$：

$$
\boxed{\mathbf{u} = \nabla\phi} \quad \text{或} \quad u_i = \frac{\partial\phi}{\partial x_i}
$$

不可压条件 $\nabla\cdot\mathbf{u}=0$ 给出 Laplace 方程：

$$
\boxed{\nabla^2\phi = 0}
$$

Laplace 方程为椭圆型偏微分方程，其解具有优良的数学性质：
- 线性可叠加
- 极值原理（最大/最小值在边界上）
- 解由边界条件唯一确定

### 4.4.2 流函数

二维不可压流动 $\nabla\cdot\mathbf{u}=0$ 自动满足存在**流函数** $\psi$：

$$
u = \frac{\partial\psi}{\partial y}, \quad v = -\frac{\partial\psi}{\partial x}
$$

流函数恒满足连续性方程。流线为 $\psi = \text{const}$，两点间流函数差等于通过该连线的体积流量：

$$
Q_{AB} = \psi_B - \psi_A
$$

### 4.4.3 Cauchy-Riemann 条件与复势

对无旋不可压流动，速度势和流函数同时存在，且满足：

$$
\frac{\partial\phi}{\partial x} = \frac{\partial\psi}{\partial y} = u, \quad \frac{\partial\phi}{\partial y} = -\frac{\partial\psi}{\partial x} = v
$$

这正是 Cauchy-Riemann 条件。因此 $\phi$ 和 $\psi$ 共轭调和：

$$
\nabla^2\phi = 0, \quad \nabla^2\psi = 0
$$

流线与势线处处正交（$\nabla\phi \cdot \nabla\psi = 0$），构成**流网**（flow net）。流网可用于手绘估算势流解，是经典流体力学的重要工程方法。

### 4.4.4 极坐标形式

$$
u_r = \frac{\partial\phi}{\partial r} = \frac{1}{r}\frac{\partial\psi}{\partial\theta}, \quad
u_\theta = \frac{1}{r}\frac{\partial\phi}{\partial\theta} = -\frac{\partial\psi}{\partial r}
$$

## 4.5 平面势流与复势

### 4.5.1 复势

定义复变量 $z = x + iy = re^{i\theta}$ 和**复势**（complex potential）：

$$
w(z) = \phi(x,y) + i\psi(x,y)
$$

复速度：

$$
\frac{dw}{dz} = \frac{\partial\phi}{\partial x} + i\frac{\partial\psi}{\partial x} = u - iv
$$

速度大小 $q = |dw/dz|$，方向角 $\theta = -\arg(dw/dz)$。

### 4.5.2 基本解

Laplace 方程线性，可通过基本解的叠加构造复杂流动。

#### 均匀流 Uniform flow

来流速度 $U$ 与 $x$ 轴夹角 $\alpha$：

$$
w(z) = Uze^{-i\alpha}
$$

$$
\phi = U(x\cos\alpha + y\sin\alpha), \quad \psi = U(y\cos\alpha - x\sin\alpha)
$$

#### 点源/点汇 Source/Sink

位于 $z_0$ 处强度为 $m$（源 $m>0$，汇 $m<0$）：

$$
w(z) = \frac{m}{2\pi}\ln(z - z_0)
$$

$$
\phi = \frac{m}{2\pi}\ln r, \quad \psi = \frac{m}{2\pi}\theta
$$

体积流量：$Q = m$。$r \to 0$ 时速度趋于无穷（奇点）。

#### 偶极子 Doublet

源和汇无限接近的极限，偶极矩向量指向负 $x$ 方向：

$$
w(z) = \frac{\kappa}{2\pi z}
$$

$$
\phi = \frac{\kappa}{2\pi}\frac{\cos\theta}{r}, \quad \psi = -\frac{\kappa}{2\pi}\frac{\sin\theta}{r}
$$

流线为过原点的圆族。

#### 点涡 Point vortex

$$
w(z) = -\frac{i\Gamma}{2\pi}\ln(z - z_0)
$$

$$
\phi = \frac{\Gamma}{2\pi}\theta, \quad \psi = -\frac{\Gamma}{2\pi}\ln r
$$

速度场：$u_\theta = \Gamma/(2\pi r)$，$u_r=0$。流线为同心圆，速度与 $1/r$ 成正比。点涡奇点处速度无穷大。

环量（circulation）：

$$
\Gamma = \oint\mathbf{u}\cdot d\mathbf{l} = \int_0^{2\pi} \frac{\Gamma}{2\pi r}\, r\,d\theta = \Gamma
$$

自洽。环量正方向定义为逆时针。

### 4.5.3 镜像法

对于存在平壁边界的流动，可用镜像法满足法向速度为零的条件。例如点源位于 $x=0$ 平面附近，在对称位置放置等强度点源。

### 4.5.4 复势的保角映射

若 $\zeta = f(z)$ 是解析函数，则 $w(z) = W(f(z))$ 仍为复势。保角映射可将复杂物理平面变换为简单计算平面。

关键定理：**Riemann 映射定理**——任意单连通区域可共形映射到单位圆。

**Joukowski 变换**：

$$
\zeta = z + \frac{c^2}{z}
$$

该变换将 $z$ 平面上的圆柱映射为 $\zeta$ 平面上的椭圆或翼型（Joukowski 翼型）。通过适当选择圆心和半径，可生成不同弯度和厚度的翼型。

Kutta 条件在 Joukowski 翼型中自动满足：后缘驻点保证流动光滑流出。

## 4.6 圆柱绕流

### 4.6.1 无环量圆柱绕流

均匀流 $U$ 沿 $x$ 方向叠加位于原点的偶极子（$\kappa = 2\pi U a^2$）：

$$
w(z) = Uz + \frac{Ua^2}{z} = U\left(z + \frac{a^2}{z}\right)
$$

极坐标速度分量：

$$
u_r = U\left(1 - \frac{a^2}{r^2}\right)\cos\theta, \quad u_\theta = -U\left(1 + \frac{a^2}{r^2}\right)\sin\theta
$$

验证边界条件：
- $r=a$：$u_r = 0$（不可穿透）
- $r\to\infty$：$u_r\to U\cos\theta$，$u_\theta\to -U\sin\theta$（恢复均匀流）

表面速度分布：

$$
u_\theta(a,\theta) = -2U\sin\theta
$$

驻点位于 $\theta = 0,\pi$。表面压力系数：

$$
C_p(\theta) = 1 - \left(\frac{u_\theta}{U}\right)^2 = 1 - 4\sin^2\theta
$$

### 4.6.2 有环量圆柱绕流

叠加点涡：

$$
w(z) = Uz + \frac{Ua^2}{z} - \frac{i\Gamma}{2\pi}\ln\frac{z}{a}
$$

速度场：

$$
u_r = U\left(1 - \frac{a^2}{r^2}\right)\cos\theta
$$

$$
u_\theta = -U\left(1 + \frac{a^2}{r^2}\right)\sin\theta + \frac{\Gamma}{2\pi r}
$$

表面速度：

$$
u_\theta(a,\theta) = -2U\sin\theta + \frac{\Gamma}{2\pi a}
$$

驻点位置方程 $u_\theta(a,\theta_s)=0$：

$$
\sin\theta_s = \frac{\Gamma}{4\pi U a}
$$

- $\Gamma < 4\pi Ua$：两个驻点在圆柱表面
- $\Gamma = 4\pi Ua$：一个驻点
- $\Gamma > 4\pi Ua$：驻点脱离圆柱（脱体）

### 4.6.3 达朗伯佯谬

D'Alembert（1752）指出：理想流体中在恒定来流下的任意物体所受合力为零。

对圆柱绕流，表面压力 $p(a,\theta) = p_\infty + \frac12\rho U^2(1-4\sin^2\theta)$ 对称分布：

$$
F_x = -\int_0^{2\pi} p(a,\theta)\cos\theta\,a\,d\theta = 0
$$

$$
F_y = -\int_0^{2\pi} p(a,\theta)\sin\theta\,a\,d\theta = 0
$$

阻力为零，升力也为零。这与日常经验矛盾——真实流体中物体必然受到阻力。

D'Alembert 佯谬的"解决"：真实流体具有粘性，导致：
1. 摩擦阻力（skin friction）
2. 压差阻力（form drag）——边界层分离产生
3. 涡脱落导致的诱导阻力

然而理想流体理论不能完全抛弃——它正确描述了升力产生的机制，Kutta-Joukowski 定理建立了升力与环量的关系，是机翼理论的基石。

## 4.7 库塔-儒科夫斯基升力定理

### 4.7.1 定理陈述

Kutta-Joukowski 升力定理（1902, 1906）：定常均匀来流 $U$ 绕过任意二维物体，若围绕物体存在环量 $\Gamma$，则单位展长所受升力为：

$$
\boxed{L = \rho U\Gamma}
$$

方向由 Joukowski 法则确定：将来流逆环量方向旋转 $90^\circ$。

### 4.7.2 证明（以有环量圆柱绕流为例）

表面压力由 Bernoulli 方程：

$$
p(a,\theta) = p_\infty + \frac12\rho\left[U^2 - u_\theta(a,\theta)^2\right]
$$

代入 $u_\theta = -2U\sin\theta + \Gamma/(2\pi a)$：

$$
p = p_\infty + \frac12\rho U^2 - \frac12\rho\left(4U^2\sin^2\theta - \frac{2U\Gamma}{\pi a}\sin\theta + \frac{\Gamma^2}{4\pi^2 a^2}\right)
$$

垂直方向上压力积分得升力：

$$
L = -\int_0^{2\pi} p\sin\theta\,a\,d\theta
$$

仅 $\sin\theta$ 线性项贡献非零：

$$
L = -\int_0^{2\pi} \left[-\frac12\rho\left(-\frac{2U\Gamma}{\pi a}\sin\theta\right)\right]\sin\theta\,a\,d\theta = \frac{\rho U\Gamma}{\pi}\int_0^{2\pi}\sin^2\theta\,d\theta = \rho U\Gamma
$$

$\square$

### 4.7.3 Kutta 条件

**Kutta 条件**（Kutta condition）：带尖锐后缘的翼型在定常绕流中，后缘处流动光滑流出（速度有限）。

数学表述：后缘处上下表面速度相等：

$$
u_{\text{upper}}(\text{TE}) = u_{\text{lower}}(\text{TE})
$$

Kutta 条件唯一确定了翼型的环量，使升力确定。

### 4.7.4 薄翼理论

薄翼（thin airfoil）在攻角 $\alpha$ 下：

- 平均弧线分解为弯度分布和厚度分布
- 厚度不贡献升力
- 弯度（camber）和攻角产生环量

对零弯度对称翼型：

$$
\Gamma = \pi c U\sin\alpha
$$

升力系数：

$$
C_L = \frac{L}{\frac12\rho U^2 c} = 2\pi\sin\alpha \approx 2\pi\alpha \quad (\alpha \text{ 小})
$$

升力线斜率 $dC_L/d\alpha = 2\pi$。

## 4.8 开尔文环量定理与亥姆霍兹涡定理

### 4.8.1 开尔文环量定理

Lord Kelvin（1869）证明：在理想流体（无粘、正压、质量力有势）中，沿任意闭合流体线的环量不随时间变化：

$$
\frac{D\Gamma}{Dt} = \frac{D}{Dt}\oint_C \mathbf{u}\cdot d\mathbf{l} = 0
$$

**证明**：

$$
\frac{D\Gamma}{Dt} = \frac{D}{Dt}\oint \mathbf{u}\cdot d\mathbf{l} = \oint \frac{D\mathbf{u}}{Dt}\cdot d\mathbf{l} + \oint \mathbf{u}\cdot\frac{D(d\mathbf{l})}{Dt}
$$

第二项：$D(d\mathbf{l})/Dt = d\mathbf{u}$，$\oint \mathbf{u}\cdot d\mathbf{u} = \oint d(u^2/2) = 0$。

第一项代入 Euler 方程：$D\mathbf{u}/Dt = -\nabla p/\rho - \nabla\Pi$

$$
\oint \left(-\frac{1}{\rho}\nabla p - \nabla\Pi\right)\cdot d\mathbf{l} = -\oint \frac{dp}{\rho} - \oint d\Pi = 0
$$

正压流体 $\oint dp/\rho = 0$（单值函数），重力势能 $\oint d\Pi = 0$。$\square$

**重要推论**：
1. 初始无旋的流动保持无旋
2. 涡管强度沿管长守恒
3. 涡线不能终止于流体内部

### 4.8.2 亥姆霍兹涡定理

Hermann von Helmholtz（1858）提出了涡运动的三大定理：

**第一定理**：涡线随流体运动（在理想流体中涡线永远是同一组流体质点组成的线）。

**第二定理**：涡管强度（$\Gamma = \oint \mathbf{u}\cdot d\mathbf{l}$）沿涡管长度不变。

**第三定理**：涡管不能在流体内部终止，必须形成封闭环或延伸到边界（如起始涡、附着涡）。

这些定理是理解升力产生、涡环传播（如烟圈）和尾涡结构的基础。

### 4.8.3 机翼启动涡

翼型从静止开始加速时，后缘产生**启动涡**（starting vortex）。Kelvin 定理要求总环量为零，因此机翼周围产生等值反向的**附着涡**。这就是升力的涡机制。

## 4.9 数值方法

### 4.9.1 涡面元法

对任意形状物体的势流求解，将物面离散为 $N$ 个面元（panel），在每个面元上分布源或涡。

源面元法：未知源强度 $\sigma_j$，在控制点满足法向速度为零：

$$
\sum_{j=1}^N \frac{\sigma_j}{2\pi}\int_{\text{panel}_j} \frac{\partial}{\partial n_i}\left(\ln r_{ij}\right)\, dS_j = -\mathbf{U}\cdot\mathbf{n}_i
$$

得到 $N\times N$ 线性方程组，求解 $\sigma_j$ 后可得全场速度和压力。

涡面元法结合 Kutta 条件，可求解带升力的翼型问题。

### 4.9.2 复势叠加的通用方法

对任意二维势流问题：

1. 确定边界形状
2. 选择基本解（源/汇/涡/偶极子）的组合
3. 在边界上满足不可穿透条件
4. 利用镜像法或保角映射处理复杂边界

## 4.10 Python 示例

### 4.10.1 圆柱绕流流线和压力分布

```python
import numpy as np
import matplotlib.pyplot as plt

U, a, Gamma = 1.0, 1.0, 0.0  # 无环量

x = np.linspace(-3, 3, 301)
y = np.linspace(-3, 3, 301)
X, Y = np.meshgrid(x, y)
R = np.sqrt(X**2 + Y**2)
Theta = np.arctan2(Y, X)

mask = R >= a

# 复势
phi = U * (R + a**2/R) * np.cos(Theta) + Gamma/(2*np.pi) * Theta
psi = U * (R - a**2/R) * np.sin(Theta) - Gamma/(2*np.pi) * np.log(R/a)

phi[~mask] = np.nan
psi[~mask] = np.nan

# 速度分量
u_r = U*(1 - a**2/R**2)*np.cos(Theta)
u_th = -U*(1 + a**2/R**2)*np.sin(Theta) + Gamma/(2*np.pi*R)
u = u_r*np.cos(Theta) - u_th*np.sin(Theta)
v = u_r*np.sin(Theta) + u_th*np.cos(Theta)
u[~mask] = np.nan; v[~mask] = np.nan

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# 流线
ax1.contour(X, Y, psi, levels=30, colors='b', linestyles='-', alpha=0.6)
ax1.streamplot(X[::5,::5], Y[::5,::5], u[::5,::5], v[::5,::5],
               color=np.sqrt(u[::5,::5]**2+v[::5,::5]**2),
               cmap='viridis', density=1.0)
ax1.add_artist(plt.Circle((0, 0), a, color='gray', alpha=0.4))
ax1.set_aspect('equal')
ax1.set_xlim(-3, 3); ax1.set_ylim(-3, 3)
ax1.set_title('Cylinder Potential Flow (Streamlines + Velocity)')

# 表面压力系数
theta = np.linspace(0, 2*np.pi, 200)
Cp = 1 - 4*np.sin(theta)**2
ax2.plot(theta*180/np.pi, Cp, 'b-', linewidth=2)
ax2.axhline(0, color='gray', ls='--')
ax2.set_xlabel(r'$\theta$ (deg)'); ax2.set_ylabel(r'$C_p$')
ax2.set_title('Pressure Coefficient on Cylinder Surface')
ax2.set_ylim(-3.5, 1.5)
ax2.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### 4.10.2 复势叠加演示

```python
def source(x, y, xs, ys, m):
    """点源复势"""
    z = x + 1j*y
    zs = xs + 1j*ys
    return m/(2*np.pi) * np.log(z - zs)

def uniform(x, y, U, alpha=0):
    """均匀流复势"""
    z = x + 1j*y
    return U * z * np.exp(-1j*alpha)

# 半体绕流：均匀流 + 点源
X, Y = np.meshgrid(np.linspace(-2, 4, 200), np.linspace(-2, 2, 150))
w = uniform(X, Y, 1.0) + source(X, Y, 0, 0, 2.0)
psi = np.imag(w)

plt.figure(figsize=(8, 4))
plt.contour(X, Y, psi, levels=30, colors='b', alpha=0.6)
# 驻点位置 xs = -m/(2πU) = -0.318
plt.plot(-0.318, 0, 'ro', markersize=6, label='Stagnation point')
plt.axhline(0, color='gray', ls=':')
plt.xlabel('x'); plt.ylabel('y')
plt.title('Half-body: Uniform Flow + Source')
plt.axis('equal'); plt.xlim(-2, 4); plt.ylim(-2, 2)
plt.legend(); plt.grid(True, alpha=0.2)
plt.show()
```

## 4.11 本章小结

| 核心概念 | 公式/要点 |
|----------|-----------|
| Euler 方程 | $\rho\frac{D\mathbf{u}}{Dt} = -\nabla p + \rho\mathbf{f}$ |
| Bernoulli 方程（定常） | $\frac{p}{\rho} + \frac12 q^2 + gz = C$（沿流线） |
| Bernoulli 方程（无旋） | 全场常数 |
| 非定常 Bernoulli | $\frac{\partial\phi}{\partial t} + \frac12 q^2 + \frac{p}{\rho} + gz = F(t)$ |
| 速度势 | $\mathbf{u} = \nabla\phi$, $\nabla^2\phi = 0$ |
| 流函数 | $u = \partial\psi/\partial y$, $v = -\partial\psi/\partial x$ |
| 复势 | $w(z) = \phi + i\psi$, $dw/dz = u-iv$ |
| 均匀流 | $w = Uz$ |
| 点源/汇 | $w = \frac{m}{2\pi}\ln z$ |
| 偶极子 | $w = \frac{\kappa}{2\pi z}$ |
| 点涡 | $w = -\frac{i\Gamma}{2\pi}\ln z$ |
| 圆柱无环量 | $w = U(z + a^2/z)$，$C_p = 1-4\sin^2\theta$ |
| Kutta-Joukowski | $L = \rho U\Gamma$ |
| D'Alembert 佯谬 | 理想流体零阻力 |
| Kelvin 环量定理 | $D\Gamma/Dt = 0$ |

## 总结

理想流体动力学忽略了粘性，却成功预测了升力并提供了完整的势流理论框架。核心方程 Euler 方程配合 Bernoulli 积分可解决大量工程流动问题。通过速度势和复势理论，二维势流化归为复变函数的边值问题。基本解的叠加可构造复杂的绕流场。Kutta-Joukowski 升力定理 $L = \rho U\Gamma$ 是空气动力学的基础。

然而理想流体预测零阻力（D'Alembert 佯谬），完全无法解释阻力的存在——这正是粘性效应，将在 [[05-粘性流体动力学]] 中深入探讨。
