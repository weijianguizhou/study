# 第九章 可压缩流动

## 引言

当流体速度接近或超过声速时，密度变化不再可以忽略。**可压缩流动**（compressible flow）的研究涉及气体动力学中独特的现象——激波、膨胀波、壅塞——这些现象在航空发动机、火箭推进、超音速巡航和高超声速再入中起着决定性作用。

本章从热力学基础出发，建立可压缩流动的控制方程，深入讨论一维等熵流动、正激波、斜激波和 Prandtl-Meyer 膨胀，最后简要介绍高超音速流动的特征。

---

## 9.1 热力学基础

### 9.1.1 状态方程

完全气体状态方程：

$$
\boxed{p = \rho RT}
$$

其中 $R$ 是气体常数（空气 $R \approx 287\ \text{J/(kg·K)}$）。

### 9.1.2 内能与焓

- **内能**（specific internal energy）：$e = c_v T$
- **焓**（specific enthalpy）：$h = e + p/\rho = c_p T$

$c_v$ 和 $c_p$ 分别是定容比热容和定压比热容。对于完全气体，$c_v$ 和 $c_p$ 仅为温度的函数。若在关心的温度范围内近似为常数，称**量热完全气体**。

### 9.1.3 比热比

$$
\gamma = \frac{c_p}{c_v}
$$

- 空气：$\gamma \approx 1.4$（双原子分子）
- 氦气：$\gamma \approx 5/3$（单原子分子）
- 高温空气：$\gamma$ 随温度下降（振动激发、离解效应）

### 9.1.4 等熵关系

对于等熵过程，$p/\rho^\gamma = \text{const}$。结合状态方程得到温度关系：

$$
\frac{T_2}{T_1} = \left(\frac{p_2}{p_1}\right)^{\frac{\gamma-1}{\gamma}} = \left(\frac{\rho_2}{\rho_1}\right)^{\gamma-1}
$$

### 9.1.5 声速

声速定义为小扰动在流体中的传播速度：

$$
a = \sqrt{\left(\frac{\partial p}{\partial \rho}\right)_s}
$$

对于完全气体：

$$
\boxed{a = \sqrt{\gamma R T}}
$$

标准海平面大气中，$a \approx 340\ \text{m/s}$。

## 9.2 Mach 数与流动分类

### 9.2.1 Mach 数定义

Mach 数是可压缩流动中最重要的无量纲参数：

$$
\boxed{Ma = \frac{u}{a}}
$$

### 9.2.2 流动分类

| 范围 | 名称 | 典型特征 |
|------|------|----------|
| $Ma < 0.3$ | 不可压缩 | $\Delta\rho/\rho < 5\%$，可忽略压缩性 |
| $0.3 < Ma < 0.8$ | 亚音速 | 压缩性显著，但无激波 |
| $0.8 < Ma < 1.2$ | **跨音速** | 局部超音速区 + 激波，阻力剧增 |
| $1.2 < Ma < 5.0$ | 超音速 | 激波与膨胀波并存 |
| $Ma > 5.0$ | **高超音速** | 强激波、高温气体效应 |

### 9.2.3 Mach 角

在超音速流动中，小扰动传播区域被 Mach 锥界定：

$$
\mu = \arcsin\frac{1}{Ma}
$$

Mach 锥外部的区域不受下游扰动的影响——这是超音速流动与亚音速流动的根本区别。

---

## 9.3 可压缩流动基本方程

### 9.3.1 连续性方程

$$
\frac{\partial\rho}{\partial t} + \nabla\cdot(\rho\boldsymbol u) = 0
$$

### 9.3.2 动量方程（Euler 方程，无粘可压缩）

$$
\rho\frac{D\boldsymbol u}{Dt} = -\nabla p
$$

### 9.3.3 能量方程

忽略热传导和粘性耗散（等熵假设）：

$$
\frac{D}{Dt}\left(h + \frac12 u^2\right) = 0
$$

即沿流线总焓守恒：

$$
\boxed{h_0 = h + \frac12 u^2 = \text{const}}
$$

### 9.3.4 总参数

驻点状态（等熵减速到速度为 0）的总参数：

- **总温**：$T_0 = T + \dfrac{u^2}{2c_p} = T\left(1 + \dfrac{\gamma-1}{2}Ma^2\right)$
- **总压**：$p_0 = p\left(1 + \dfrac{\gamma-1}{2}Ma^2\right)^{\gamma/(\gamma-1)}$
- **总密度**：$\rho_0 = \rho\left(1 + \dfrac{\gamma-1}{2}Ma^2\right)^{1/(\gamma-1)}$

## 9.4 一维等熵流动

### 9.4.1 变截面管道流动

考虑截面积 $A(x)$ 变化的一维定常等熵流动。连续性方程和动量方程联合给出面积-速度关系（**面积-马赫数关系**）：

$$
\frac{dA}{A} = (Ma^2 - 1)\frac{du}{u}
$$

这一关系揭示了可压缩流动中面积变化效果的**反转**：

- **亚音速**（$Ma < 1$）：面积减小，流速增大（同不可压缩流体）
- **超音速**（$Ma > 1$）：面积增大，流速增大（**反转！**）

### 9.4.2 Laval 喷管

为了使气流从亚音速连续加速到超音速，必须使用先收缩后扩张的喷管——**Laval 喷管**。

- **喉部**（throat）处 $dA/dx = 0$，恰好 $Ma = 1$（声速截面）
- 喉部面积 $A^*$ 与任意截面处的 Mach 数关系：

  $$
  \left(\frac{A}{A^*}\right)^2 = \frac{1}{Ma^2}\left[\frac{2}{\gamma+1}\left(1+\frac{\gamma-1}{2}Ma^2\right)\right]^{\frac{\gamma+1}{\gamma-1}}
  $$

### 9.4.3 壅塞（Choking）

当 Laval 喷管背压（出口外部压力）低于某一临界值时，喉部达到声速（$Ma=1$），此时通过喷管的质量流量达到最大值：

$$
\dot m_{\max} = \frac{A^* p_0}{\sqrt{T_0}}\sqrt{\frac{\gamma}{R}\left(\frac{2}{\gamma+1}\right)^{\frac{\gamma+1}{\gamma-1}}}
$$

进一步降低背压对喷管内的流量无影响——喷管发生**壅塞**。

```python
import numpy as np

def area_mach_relation(ma, gamma=1.4):
    """从 Mach 数计算面积比 A/A*"""
    term = (2/(gamma+1)) * (1 + (gamma-1)/2 * ma**2)
    return (1/ma) * term**((gamma+1)/(2*(gamma-1)))

def mass_flow_rate(A_star, p0, T0, gamma=1.4, R=287):
    """壅塞条件下 Laval 喷管的最大质量流量"""
    return (A_star * p0 / np.sqrt(T0)
            * np.sqrt(gamma/R * (2/(gamma+1))**((gamma+1)/(gamma-1))))

# 示例：计算给定 A/A* 对应的 Mach 数（亚音速和超音速分支）
def mach_from_area_ratio(area_ratio, supersonic=False, gamma=1.4):
    """通过 Newton 法求解面积比-马赫数关系"""
    ma = 0.5 if not supersonic else 2.0
    for _ in range(50):
        f = area_mach_relation(ma, gamma) - area_ratio
        df = (area_mach_relation(ma*1.001, gamma)
              - area_mach_relation(ma*0.999, gamma)) / (0.002*ma)
        ma -= f / df
        if abs(f) < 1e-12:
            break
    return ma

A_ratio = 2.0
ma_sub = mach_from_area_ratio(A_ratio, supersonic=False)
ma_sup = mach_from_area_ratio(A_ratio, supersonic=True)
print(f"A/A* = {A_ratio}: Ma_sub = {ma_sub:.4f}, Ma_sup = {ma_sup:.4f}")
```

## 9.5 正激波

### 9.5.1 基本现象

激波是超音速流动中的一种强间断，气体通过激波时压力、密度、温度急剧升高，速度亚音速化。正激波（激波面与来流垂直）是最简单的激波形式。

### 9.5.2 Rankine-Hugoniot 关系

控制方程在激波前后守恒量跨越激波面不变：

**连续性**：$\rho_1 u_1 = \rho_2 u_2$

**动量**：$p_1 + \rho_1 u_1^2 = p_2 + \rho_2 u_2^2$

**能量**：$h_1 + \frac12 u_1^2 = h_2 + \frac12 u_2^2$

对于完全气体，推导得到激波前后的关系：

- **密度比**（激波最强时趋于有限值）：

  $$
  \frac{\rho_2}{\rho_1} = \frac{(\gamma+1)Ma_1^2}{2 + (\gamma-1)Ma_1^2}
  $$

  当 $Ma_1 \to \infty$ 时，$\rho_2/\rho_1 \to (\gamma+1)/(\gamma-1) = 6$（$\gamma=1.4$）

- **压力比**：

  $$
  \frac{p_2}{p_1} = 1 + \frac{2\gamma}{\gamma+1}(Ma_1^2 - 1)
  $$

- **温度比**：

  $$
  \frac{T_2}{T_1} = \frac{p_2}{p_1}\frac{\rho_1}{\rho_2}
  $$

- **激波后 Mach 数**：

  $$
  Ma_2^2 = \frac{(\gamma-1)Ma_1^2 + 2}{2\gamma Ma_1^2 - (\gamma-1)}
  $$

  激波后总是亚音速（$Ma_2 < 1$）。

### 9.5.3 Prandtl 关系

Prandtl 发现了一个优美的关系：

$$
\boxed{u_1 u_2 = a^{*2}}
$$

其中 $a^*$ 是**临界声速**（在 $Ma=1$ 处的声速）。该关系表明激波前后的速度乘积恒等于临界声速的平方。

### 9.5.4 激波熵增

激波是不可逆过程，熵增为：

$$
\Delta s = c_p \ln\left[\left(1 + \frac{2\gamma}{\gamma+1}(Ma_1^2-1)\right)^{-\frac{1}{\gamma}}
\left(\frac{(\gamma+1)Ma_1^2}{2+(\gamma-1)Ma_1^2}\right)^{\frac{\gamma-1}{\gamma}}\right]
$$

熵增始终为正，且随 $Ma_1$ 增大而增大。弱激波（$Ma_1 \to 1^+$）的熵增为三阶小量，这是激波可近似为等熵的分析依据。

## 9.6 斜激波

### 9.6.1 几何关系

当超音速气流经过一个楔角 $\theta$ 的压缩拐角时，形成附着于物面的斜激波。波角 $\beta$ 与来流 Mach 数 $Ma_1$ 和转角 $\theta$ 满足 **$\theta\!-\!\beta\!-\!Ma$ 关系**：

$$
\tan\theta = 2\cot\beta\,\frac{Ma_1^2\sin^2\beta - 1}{Ma_1^2(\gamma + \cos 2\beta) + 2}
$$

### 9.6.2 解的分类

给定 $Ma_1$ 和 $\theta$，$\beta$ 有两个解：

- **强激波解**（$\beta$ 较大，激波后 $Ma_2 < 1$）
- **弱激波解**（$\beta$ 较小，激波后 $Ma_2 > 1$，除非 $\theta$ 很大）

工程实际中，背部压力较低时通常出现弱激波。存在最大转角 $\theta_{\max}$，超过该值激波脱体，变为前方弓形激波。

### 9.6.3 激波极线

激波极线（shock polar）是在速度平面上描述激波后可能状态的曲线。对于给定的来流条件，激波后速度矢量终点的轨迹是一条封闭曲线（在 $u\!-\!v$ 平面上）。激波极线是分析激波-激波相互作用、激波-边界层干扰的有力工具。

## 9.7 Prandtl-Meyer 膨胀

### 9.7.1 膨胀波

超音速气流经过**外凸角**时发生膨胀，形成扇形膨胀波——**Prandtl-Meyer 膨胀**。与激波不同，膨胀波是等熵过程，连续偏转。

### 9.7.2 Prandtl-Meyer 函数

气流从 $Ma=1$ 膨胀到 $Ma$ 的总偏转角由 Prandtl-Meyer 函数给出：

$$
\nu(Ma) = \sqrt{\frac{\gamma+1}{\gamma-1}}\,
\arctan\sqrt{\frac{\gamma-1}{\gamma+1}(Ma^2-1)} - \arctan\sqrt{Ma^2-1}
$$

气流从 $Ma_1$ 偏转 $\theta$ 角到 $Ma_2$ 时：

$$
\nu(Ma_2) = \nu(Ma_1) + \theta
$$

```python
import numpy as np

def prandtl_meyer(ma, gamma=1.4):
    """Prandtl-Meyer 函数（弧度）"""
    sqrt_term = np.sqrt(ma**2 - 1)
    sqrt_ratio = np.sqrt((gamma-1)/(gamma+1))
    return (np.sqrt((gamma+1)/(gamma-1))
            * np.arctan(sqrt_ratio * sqrt_term)
            - np.arctan(sqrt_term))

def mach_from_pm(nu_target, gamma=1.4, tol=1e-10):
    """逆 Prandtl-Meyer 函数：由偏转角求 Ma（Newton 法）"""
    ma = 1.5
    for _ in range(100):
        nu = prandtl_meyer(ma, gamma)
        f = nu - nu_target
        df = (prandtl_meyer(ma*1.001, gamma)
              - prandtl_meyer(ma*0.999, gamma)) / (0.002*ma)
        ma -= f / df
        if abs(f) < tol:
            break
    return ma

# 例：Ma=2.0 气流偏转 10° 后的 Ma
theta = np.deg2rad(10)
nu1 = prandtl_meyer(2.0)
nu2 = nu1 + theta
ma2 = mach_from_pm(nu2)
print(f"膨胀后 Mach 数: {ma2:.4f}")
```

## 9.8 跨音速流动

### 9.8.1 跨音速流动特征

在 $Ma_\infty$ 略低于 1 时，机翼上表面局部区域出现超音速区，以激波终止——形成**激波-边界层干扰**，导致激波诱导分离。跨音速流动的主要特征：

- **波阻**的急剧增加（**音障**）
- 激波振荡导致抖振（buffet）
- 需要特殊的翼型设计（超临界翼型）

### 9.8.2 面积律

Whitcomb 面积律指出：跨音速阻力主要取决于飞行器横截面面积沿轴向的分布，平滑分布可减小波阻——"可乐瓶"形机身设计。

## 9.9 高超音速流动

### 9.9.1 特征

当 $Ma > 5$ 时，进入高超音速（hypersonic）范围，流动具有以下特征：

1. **薄激波层**：激波与物面间距极小（$\delta/d \sim 1/Ma^2$）
2. **熵层**：激波强弯曲导致很大的熵梯度
3. **粘性相互作用**：边界层排挤效应显著影响外部激波
4. **高温气体效应**：分子振动激发、离解、电离、化学非平衡
5. **气动加热**：动能大量转化为热能，壁面热流极大

### 9.9.2 气动加热

驻点热流（Fay-Riddell 公式）：

$$
\dot q_w = 0.763\,Pr^{-0.6}\sqrt{\rho_e\mu_e}\,
\sqrt{\frac{du_e}{dx}}\,(h_0 - h_w)
$$

高超音速飞行器的热防护系统需要耐高温材料（如 C/C 复合材料）或烧蚀冷却。

### 9.9.3 高超声速相似律

对于细长体，远端来流 Mach 数很大时，激波极度贴近物面。引入**高超声速相似参数**：

$$
K = Ma_\infty \tau
$$

其中 $\tau$ 是细长体的厚度比。当 $K$ 相同时，不同组合的 $Ma_\infty$ 和 $\tau$ 产生相似流场。

## 9.10 激波-边界层相互作用

这是可压缩流动中最重要的交叉问题。激波撞击边界层导致：

- 压力突增沿边界层向上游传播（上游影响）
- 边界层增厚，严重时导致分离
- 分离泡形成，产生额外的压缩波/激波系

相互作用类型：
- **入射激波/边界层干扰**（二维）
- **激波/湍流边界层干扰**（STBLI）
- **激波诱导分离**（SBLI）

STBLI 是超音速进气道设计和翼型性能预测中的关键问题。

---

## 总结

1. **可压缩流动**的核心特征是密度变化不可忽略，Mach 数是流动分类的核心参数。
2. **一维等熵流动**通过 Laval 喷管实现亚音速→超音速的连续加速。喉部 $Ma=1$ 时发生壅塞，流量达到最大值，这是喷管设计和火箭发动机的基本原理。
3. **正激波**由 Rankine-Hugoniot 关系描述。Prandtl 关系 $u_1 u_2 = a^{*2}$ 是激波特性的简洁表述。
4. **斜激波**满足 $\theta\!-\!\beta\!-\!Ma$ 关系，存在最大偏转角限制。**Prandtl-Meyer 膨胀**是超音速气流转弯的等熵方式。
5. **高超音速流动**涉及薄激波层、高温气体效应和气动加热，是航空航天工程的核心挑战。
