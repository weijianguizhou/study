## Physics-Informed Neural Networks (PINN)

### 核心思想

Raissi et al. (2019) 提出 PINN：将 [[05-粘性流体动力学|NS 方程]] 的残差作为损失函数的一部分，训练神经网络同时满足数据和物理约束。

损失函数：

$$
\mathcal{L} = \mathcal{L}_{\text{data}} + \lambda \mathcal{L}_{\text{PDE}}
$$

其中 $\mathcal{L}_{\text{PDE}} = \frac{1}{N} \sum_{i=1}^N \left| \mathcal{R}(u_\theta(x_i, t_i)) \right|^2$，$\mathcal{R}$ 为 PDE 残差。

```python
# PINN 损失函数示意
def pinn_loss(model, x_data, u_data, x_pde):
    # 数据损失
    u_pred = model(x_data)
    loss_data = ((u_pred - u_data)**2).mean()

    # PDE 损失（自动微分）
    x_pde.requires_grad = True
    u = model(x_pde)
    u_t = torch.autograd.grad(u, x_pde, create_graph=True)[0][:, 0]
    u_x = torch.autograd.grad(u, x_pde, create_graph=True)[0][:, 1]
    # ... 计算 NS 残差
    loss_pde = (residual**2).mean()

    return loss_data + 1e-3 * loss_pde
```

### 优势与局限

- **优势**：无网格；反向传播自动微分高效处理高维 PDE；反问题（参数辨识）天然适配
- **局限**：训练收敛慢且不稳定；对多尺度（湍流）问题表现不佳；缺乏严格误差界

### 发展

- **VPINN** / **hp-VPINN**：变分形式 + 自适应细化
- **PINO**：傅里叶神经算子 + PINN 损失
- **湍流 PINN**：加入 $k$-$\varepsilon$ 辅助方程约束

## 流动控制

### 被动控制

- **涡发生器**：微型涡产生装置，将主流能量带入边界层，延迟分离
- **沟槽 / 超疏水表面 (SHS)**：减阻（[[07-边界层理论|壁面律]] 中的虚拟滑移）
- **鲨鱼皮 / riblet**：仿生减阻，减阻率约 5–8%

### 主动控制

- **合成射流 (SJ)**：零净质量流量射流，用于分离控制和混合增强
- **吹气/吸气**：改变边界层动量厚度
- **壁面振荡**：展向周期振荡减阻（~40% 减阻率）

```python
# 合成射流激励器速度边界条件（示意）
def synthetic_jet(t, x, A=0.1, f=10):
    return A * np.sin(2 * np.pi * f * t) * np.exp(-x**2 / 0.01)
```

### 等离子体流动控制

- **DBD (介质阻挡放电) 等离子体激励器**
- 通过电风产生近壁体积力，诱导加速
- 优势：无运动部件、响应快（ms 级）
- 应用：翼型分离抑制、射流矢量控制

## 生物流体力学

### 心血管流体力学

- **血流动力学**：低 $Re$ 脉动流，[[05-粘性流体动力学|Womersley 解]] 描述动脉脉动速度分布

$$
u(r, t) = \text{Re}\left[ \frac{i A}{\rho \omega} \left(1 - \frac{J_0(\alpha r / R)}{J_0(\alpha)} \right) e^{i \omega t} \right]
$$

其中 Womersley 数 $\alpha = R \sqrt{\omega / \nu}$

- **动脉粥样硬化**：低壁面剪切应力 (WSS) 区域易发斑块
- **心室内流**：涡环形成与破裂，影响射血效率
- **医学应用**：CFD 辅助血管支架设计、TAVI 手术规划

### 昆虫飞行

- **非定常高升力机制**（Weis-Fogh 理论）：
  - **翻转效应 (clap & fling)**：两翅合拢后分离，诱导额外环量
  - **前缘涡 (LEV)**：翼前缘附着涡不脱落，大幅提升升力
  - **尾迹捕获 (wake capture)**：从先前拍翅膀产生的尾迹中回收能量
- $Re \sim 10^2–10^4$，适用 NS 方程，但网格量巨大

### 鱼类游动

- **变形体推进**：Beltrami 涡量子、反卡门涡街（推力产生）
- **推进效率**：Strouhal 数 $St = fA/U$ 通常在 0.25–0.35 最优
- **仿生 AUV**：Boxfish、金枪鱼、鳐鱼型水下机器人

```python
# 计算鱼类游动 Strouhal 数
def strouhal_number(freq, amplitude, speed):
    return freq * amplitude / speed
```

## 多相流

### VOF（Volume of Fluid）

求解相体积分数 $\alpha$ 的输运方程：

$$
\frac{\partial \alpha}{\partial t} + \nabla \cdot (\alpha \mathbf{u}) = 0
$$

- 界面重构：PLIC（分段线性）
- 应用：波浪破碎、溃坝、射流雾化

```python
# VOF 单步界面传输（示意）
def vof_advection(alpha, u, v, dt, dx, dy):
    flux_x = np.maximum(0, u) * alpha[:-1] + np.minimum(0, u) * alpha[1:]
    alpha -= dt/dx * (flux_x[1:] - flux_x[:-1])
    return alpha
```

### Level Set

用 $\phi(\mathbf{x}, t)$ 的零等值面表示界面，$\phi$ 一般为符号距离函数：

$$
\frac{\partial \phi}{\partial t} + \mathbf{u} \cdot \nabla \phi = 0
$$

- **优点**：界面连续光滑、曲率计算精确
- **缺点**：质量守恒性差（需 reinitialization 校正）

### CLSVOF / coupled Level Set and VOF

将 Level Set 的精度与 VOF 的守恒性结合，是当前多相流高精度仿真的主流方法。

## 微纳尺度流动

### Knudsen 数与流动分区

$$
Kn = \frac{\lambda}{L}
$$

| 范围 | 分区 | 模型 |
|------|------|------|
| $Kn < 0.01$ | 连续流 | NS 方程 + 无滑移 |
| $0.01 < Kn < 0.1$ | 滑移流 | NS + 滑移边界 |
| $0.1 < Kn < 10$ | 过渡流 | Burnett 方程 / DSMC |
| $Kn > 10$ | 分子自由流 | Boltzmann 方程 / DSMC |

### 滑移边界条件

Maxwell 滑移速度：

$$
u_s - u_w = \frac{2-\sigma}{\sigma} \lambda \left( \frac{\partial u}{\partial n} \right)_w
$$

温度跳动（Smoluchowski 条件）：

$$
T_s - T_w = \frac{2-\sigma_T}{\sigma_T} \frac{2\gamma}{\gamma+1} \frac{Kn}{Pr} \lambda \left( \frac{\partial T}{\partial n} \right)_w
$$

### 应用

- **MEMS / NEMS**：微泵、微阀、微混合器
- **纳流控**：DNA 测序、离子选择性传输
- **直接模拟 Monte Carlo (DSMC)**：稀薄气体标准方法

```python
# DSMC 碰撞对采样（示意）
def dsmc_collision(particles, dt, viscosity):
    # Bird 的 NTC 方法
    pairs = random_select_pairs(particles)
    for p1, p2 in pairs:
        vr = np.linalg.norm(p1.v - p2.v)
        prob = vr * dt / viscosity
        if random() < prob:
            p1.v, p2.v = elastic_collision(p1, p2)
```

## 环境流体力学

### 大气边界层

- **中性 / 稳定 / 不稳定层结**：Monin-Obukhov 相似理论
- **对数律风速廓线**（中性）：

$$
U(z) = \frac{u_*}{\kappa} \ln \left( \frac{z}{z_0} \right)
$$

- **污染扩散**：Gaussian plume 模型：

$$
C(x,y,z) = \frac{Q}{2\pi U \sigma_y \sigma_z}
\exp\left(-\frac{y^2}{2\sigma_y^2}\right)
\left[ \exp\left(-\frac{(z-H)^2}{2\sigma_z^2}\right) + \exp\left(-\frac{(z+H)^2}{2\sigma_z^2}\right) \right]
$$

```python
# Gaussian 烟羽模型
def gaussian_plume(Q, U, x, y, z, H, sigma_y, sigma_z):
    C = Q / (2 * np.pi * U * sigma_y * sigma_z)
    C *= np.exp(-y**2 / (2 * sigma_y**2))
    C *= (np.exp(-(z-H)**2 / (2 * sigma_z**2)) +
          np.exp(-(z+H)**2 / (2 * sigma_z**2)))
    return C
```

## 天体物理流体力学

### 吸积盘

- Kepler 旋转 $\Omega_K = \sqrt{GM/r^3}$
- $\alpha$-盘模型（Shakura-Sunyaev）：$\nu_t = \alpha c_s H$
- 磁旋转不稳定性 (MRI)：角动量向外传输的关键机制

### 恒星对流

- Schwarzschild 判据：$\nabla > \nabla_{\text{ad}}$ 不稳定
- 混合长度理论 (MLT)：最简单的对流模型
- [[08-涡量动力学|涡量]] 和磁场的相互作用产生太阳磁活动

### 星际介质 (ISM)

- 多相：热晕 (T~10^6 K) / warm (10^4 K) / cold (10–100 K)
- 激波与湍流：超新星遗迹、分子云形成

## 超流体与量子涡旋

### 超流体 He-II

- 双流体模型：正常流体 (粘性) + 超流成分 (无粘)
- 量子化涡旋：环量 $\oint v_s \cdot dl = \frac{h}{m}$
- 涡旋网格：量子湍流（Quantum Turbulence）

### Bose-Einstein 凝聚体 (BEC)

- Gross-Pitaevskii 方程（非线性 Schrödinger）：

$$
i\hbar \frac{\partial \psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2 \psi + V \psi + g|\psi|^2 \psi
$$

- 涡格/涡环；与经典湍流的类比

## 开放未解问题

### NS 方程光滑性（千禧年问题）

三维 NS 方程是否始终存在全局光滑解？Millennium Prize Problem，至今未解。

### 湍流封闭问题

Reynolds 应力 $\overline{u_i' u_j'}$ 永远需要用更低阶量近似——**湍流没有"正确"的封闭模型**。

### 转捩预测

从层流到湍流的转捩路径（容错转捩 / bypass 转捩）仍难以工程化准确预测。

### 减阻上限

能效极限：壁面湍流减阻是否存在理论上限？

### 机器学习 + 流体力学

- 数据驱动模型 / 可解释 AI
- 湍流模型发现（Sparsity-promoting 回归）
- 几何深流（Geometric Deep Flow）

## 总结

本章梳理了流体力学在 2020 年代的多条前沿脉络。数据科学（PINN、ML 建模）正在重塑传统 CFD 范式；生物流体将机制研究与医学工程紧密耦合；微纳/多相/环境/天体等分支展示了流体力学的跨学科广度。与此同时，NS 方程的光滑性和湍流封闭等基础问题依然悬而未决。理解这些问题既是挑战，也是未来研究的起点。
