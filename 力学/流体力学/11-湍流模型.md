# 湍流模型与数值模拟

## 概述

湍流是流体力学中尚未完全解决的核心难题。其多尺度、非定常、三维涡旋结构使得直接数值模拟的计算代价极其高昂。本章系统梳理湍流数值模拟的三大途径（DNS / LES / RANS）及常用湍流模型，并讨论混合方法（DES）。

---

## 湍流的基本特征

- **随机性与拟序结构共存**：湍流看似随机，但存在拟序涡结构（如发卡涡、涡管）
- **宽能谱**：能量从大涡（含能区）经惯性子区传递到小涡（耗散区）
- **Reynolds 数效应**：湍流强度与 $Re$ 正相关

Kolmogorov 尺度：

$$
\eta = \left( \frac{\nu^3}{\varepsilon} \right)^{1/4}, \quad
u_\eta = (\nu \varepsilon)^{1/4}, \quad
\tau_\eta = \left( \frac{\nu}{\varepsilon} \right)^{1/2}
$$

其中 $\varepsilon$ 为湍动能耗散率。

---

## 湍流模拟的三条途径

### DNS（直接数值模拟）

直接求解完整的 [[05-粘性流体动力学|NS 方程]]，不引入任何模型。所有尺度（从含能涡到 Kolmogorov 尺度）均被解析。

网格量估计：

$$
N \sim Re^{9/4}
$$

- 例：$Re = 10^6$ 时 $N \sim 10^{13.5}$，远超当前超算能力
- **优点**：精度最高，可提供湍流数据库
- **缺点**：仅适用于低 $Re$、简单几何

### LES（大涡模拟）

只解析大尺度涡，小尺度涡通过亚格子模型建模。基于**尺度分离**思想。

网格量：

$$
N \sim Re^{1.8} \quad (\text{DNS}) \quad\to\quad N \sim Re^{0.4} \quad (\text{LES})
$$

- 适合工程中高 $Re$ 问题
- 需注意近壁面解析的代价（WMLES 可缓解）

### RANS（Reynolds 平均 Navier-Stokes）

将 NS 方程作时间平均，所有尺度均需模化。

$$
\frac{\partial \bar{u}_i}{\partial t} + \bar{u}_j \frac{\partial \bar{u}_i}{\partial x_j} =
-\frac{1}{\rho}\frac{\partial \bar{p}}{\partial x_i} + \nu \frac{\partial^2 \bar{u}_i}{\partial x_j \partial x_j}
- \frac{\partial \overline{u_i' u_j'}}{\partial x_j}
$$

其中 $\overline{u_i' u_j'}$ 为 **Reynolds 应力**，需模化封闭。

---

## 涡粘假设

Boussinesq 涡粘假设：

$$
-\overline{u_i' u_j'} = 2 \nu_t S_{ij} - \frac{2}{3} k \delta_{ij}
$$

其中 $\nu_t$ 为涡粘系数，$S_{ij}$ 为平均应变率张量，$k = \frac{1}{2}\overline{u_i' u_i'}$ 为湍动能。

---

## 零方程模型

不使用额外输运方程，直接将 $\nu_t$ 与平均流场关联。

### Baldwin-Lomax 模型

两层代数模型：

$$
\nu_t = \begin{cases}
\nu_{t,\text{inner}} = \kappa y^+ \left[1 - \exp(-y^+/A^+)\right]^2 & \text{(内层)} \\
\nu_{t,\text{outer}} = \alpha C_{cp} F_{\text{wake}} & \text{(外层)}
\end{cases}
$$

其中 $y^+$ 为 [[07-边界层理论|壁面律]] 中的无量纲距离。

- 优点：计算量极小
- 缺点：对分离流、强曲率流动效果差

---

## 一方程模型

### Spalart-Allmaras（SA）模型

求解修正涡粘 $\tilde{\nu}$ 的输运方程：

$$
\frac{D \tilde{\nu}}{D t} = c_{b1} \tilde{S} \tilde{\nu}
- c_{w1} f_w \left( \frac{\tilde{\nu}}{d} \right)^2
+ \frac{1}{\sigma} \left[ \nabla \cdot ((\nu + \tilde{\nu}) \nabla \tilde{\nu}) + c_{b2} (\nabla \tilde{\nu})^2 \right]
$$

- 专为**航空航天**外流设计
- 对附着流和轻度分离流表现出色
- 对壁面距离 $d$ 敏感

```python
# SA 模型源项示例（Python 伪代码）
def sa_source(nu_tilde, S, d, nu, rho):
    cb1, cb2, sigma, kappa = 0.1355, 0.622, 2/3, 0.41
    cw1 = cb1 / kappa**2 + (1 + cb2) / sigma
    chi = nu_tilde / nu
    fv1 = chi**3 / (chi**3 + 7.1**3)
    Stilde = S + nu_tilde / (kappa**2 * d**2) * fv1
    production = cb1 * Stilde * nu_tilde
    destruction = cw1 * (nu_tilde / d)**2
    return production - destruction
```

## 两方程模型

### $k$-$\varepsilon$ 模型

输运 $k$ 和 $\varepsilon$：

$$
\frac{D k}{D t} = P_k - \varepsilon + \nabla \cdot \left( \frac{\nu_t}{\sigma_k} \nabla k \right)
$$

$$
\frac{D \varepsilon}{D t} = \frac{\varepsilon}{k} (c_{\varepsilon 1} P_k - c_{\varepsilon 2} \varepsilon)
+ \nabla \cdot \left( \frac{\nu_t}{\sigma_\varepsilon} \nabla \varepsilon \right)
$$

涡粘：$\nu_t = C_\mu \dfrac{k^2}{\varepsilon}$

- 标准常数：$C_\mu = 0.09, \; c_{\varepsilon 1} = 1.44, \; c_{\varepsilon 2} = 1.92$
- **缺点**：对逆压梯度、分离流预测不佳；近壁面需壁面函数

### $k$-$\omega$ SST（Shear Stress Transport）

Menter 将 $k$-$\omega$（近壁）与 $k$-$\varepsilon$（远场）通过混合函数结合：

$$
\frac{D \omega}{D t} = \alpha \frac{P_k}{\nu_t} - \beta \omega^2
+ \nabla \cdot \left( \frac{\nu_t}{\sigma_\omega} \nabla \omega \right)
+ 2(1-F_1)\frac{\sigma_{\omega 2}}{\omega} \nabla k \cdot \nabla \omega
$$

$$F_1$$ 为混合函数，在壁面处 $F_1 = 1$（$k$-$\omega$），远离壁面 $F_1 = 0$（$k$-$\varepsilon$）。

- 对分离流、逆压梯度表现优异
- 航空航天领域首选 RANS 模型之一

```python
# k-omega SST 混合函数 F1（示意）
def F1(k, omega, d, nu):
    arg1 = min(max(np.sqrt(k) / (0.09 * omega * d),
                   500 * nu / (d**2 * omega)),
               4 * sigma_omega2 * k / (CD_kw * d**2))
    return np.tanh(arg1**4)
```

## 雷诺应力模型（RSM / LRR）

直接输运 Reynolds 应力 $\overline{u_i' u_j'}$，放弃涡粘假设：

$$
\frac{D \overline{u_i' u_j'}}{D t} = P_{ij} + \Phi_{ij} - \varepsilon_{ij} + D_{ij}
$$

- $P_{ij}$：生成项；$\Phi_{ij}$：压力应变再分配项（关键项）
- **优点**：可捕获各向异性、曲率、旋转效应
- **缺点**：7 个方程，计算成本高，数值刚性大

---

## LES 亚格子模型

### Smagorinsky 模型

$$
\nu_t = (C_s \Delta)^2 |\bar{S}|, \quad
\tau_{ij} - \frac{1}{3}\tau_{kk}\delta_{ij} = -2\nu_t \bar{S}_{ij}
$$

- $C_s \approx 0.1 \sim 0.2$（Smagorinsky 常数）
- 标准 $C_s$ 在近壁面、层流区耗散过大

### 动态 Smagorinsky 模型

Germano 通过两次滤波（网格滤波 + 检验滤波）动态计算 $C_s$：

$$
C_s^2 = -\frac{1}{2} \frac{\langle L_{ij} M_{ij} \rangle}{\langle M_{kl} M_{kl} \rangle}
$$

其中 $L_{ij} = \widehat{\bar{u}_i \bar{u}_j} - \hat{\bar{u}}_i \hat{\bar{u}}_j$，$M_{ij} = \Delta^2 |\hat{\bar{S}}|\hat{\bar{S}}_{ij} - \widehat{\Delta^2 |\bar{S}| \bar{S}_{ij}}$

- 无需预设常数
- 可在近壁面自动退化为 Smagorinsky
- 可能出现负 $\nu_t$（需平均或截断）

### WALE 模型

壁面自适应局部涡粘模型，适合复杂壁面流动：

$$
\nu_t = (C_w \Delta)^2 \frac{(S_{ij}^d S_{ij}^d)^{3/2}}{(\bar{S}_{ij}\bar{S}_{ij})^{5/2} + (S_{ij}^d S_{ij}^d)^{5/4}}
$$

## 混合方法

### DES（分离涡模拟）

RANS-LES 混合策略：

- 近壁面区域使用 RANS（SA 或 SST）
- 主流动区域使用 LES
- 通过修改长度尺度实现切换：

$$
\tilde{d} = \min(d_{\text{wall}}, C_{\text{DES}} \Delta)
$$

```python
# DES 长度尺度切换
def des_length(d_wall, delta, C_DES=0.65):
    return min(d_wall, C_DES * delta)
```

### DDES / IDDES

- **DDES**（延迟 DES）：引入 shielding 函数，防止 RANS 层内过早切换，避免网格诱导分离
- **IDDES**（改进 DDES）：进一步提升壁面湍流解析能力

---

## 壁面处理

### 壁面函数

- 适用于 $y^+ > 30$ 的高 $Re$ 网格
- 基于 [[07-边界层理论|壁面律]] 对数律：$u^+ = \frac{1}{\kappa} \ln y^+ + C$

### 低 $Re$ 近壁模型

- 需网格加密至 $y^+ \approx 1$
- 对 $k$-$\omega$ 模型自然支持
- 对 $k$-$\varepsilon$ 模型需添加阻尼函数

## 湍流模型的选用指南

| 模型 | 计算成本 | 精度 | 适用场景 |
|------|---------|------|---------|
| Baldwin-Lomax | 极低 | 低 | 简单外部流、初步设计 |
| SA | 低 | 中 | 航空航天外流、附着流 |
| $k$-$\varepsilon$ | 低 | 中 | 工程内流、无分离 |
| $k$-$\omega$ SST | 中 | 高 | 分离流、叶轮机械 |
| RSM | 高 | 中-高 | 强旋转、弯曲管道 |
| LES | 极高 | 高 | 基础研究、复杂分离 |
| DNS | 极高 | 最高 | 低 $Re$ 机理研究 |

## 湍流的数值稳定性

- **高 $Re$ 近壁面**：$k$-$\varepsilon$ 易发散，推荐 SST 或 $y^+$ 敏感的 SA
- **转捩预测**：需耦合 [[06-层流与湍流|层流向湍流转捩]] 模型（如 $\gamma$-$Re_\theta$）
- **非定常湍流**：URANS / LES 需关注 CFL 条件和时间步长：

$$
\Delta t < \frac{\Delta x_{\min}}{U_{\text{bulk}}}
$$

```python
# CFL 条件与时间步长估算
def calc_dt(dx, dy, dz, u, v, w, CFL=0.8):
    cfl = (u/dx + v/dy + w/dz) * dt
    return CFL / max(cfl)
```

## 后处理与湍流统计

- **时间平均**：$\langle u \rangle = \frac{1}{T} \int_0^T u(t) dt$
- **Reynolds 应力**：$\langle u'v' \rangle = \langle uv \rangle - \langle u \rangle \langle v \rangle$
- **能谱 $E(\kappa)$**：通过 FFT 获得，验证 $-5/3$ 律
- **Q 准则**：$Q = \frac{1}{2}(||\Omega||^2 - ||S||^2) > 0$ 标识涡结构

```python
# Q 准则涡识别
def Q_criterion(vel_grad):
    S2 = np.sum(vel_grad.symmetric()**2)
    Omega2 = np.sum(vel_grad.skew()**2)
    return 0.5 * (Omega2 - S2)
```

## 常见数值问题

- **数值耗散**：迎风格式耗散过大，会"抹平"湍流结构——LES 推荐高阶格式（如 WENO）
- **交界面不匹配**：RANS/LES 交界处需保证湍流量的连续传递
- **入口湍流生成**：合成涡法（SEM / DFSEM）生成湍流入口

## 代码示例：SA 模型求解

```python
import numpy as np

def solve_SA(nu_tilde, U, nu, dx, dt, d_wall):
    """一维 SA 模型时间推进（简化示意）"""
    S = np.abs(np.gradient(U, dx))
    chi = nu_tilde / nu
    fv1 = chi**3 / (chi**3 + 7.1**3)
    Stilde = S + nu_tilde / (0.41 * d_wall)**2 * fv1

    P = 0.1355 * Stilde * nu_tilde
    D = 0.622 * (nu_tilde / d_wall)**2
    Diff = (nu + nu_tilde) * np.gradient(np.gradient(nu_tilde, dx), dx)

    nu_tilde += dt * (P - D + Diff)
    nu_tilde = np.maximum(nu_tilde, 0)  # 正定约束
    return nu_tilde
```

## 总结

本章从 DNS/LES/RANS 三条途径出发，系统覆盖了零方程（Baldwin-Lomax）、一方程（SA）、两方程（$k$-$\varepsilon$、$k$-$\omega$ SST）及 RSM 等 RANS 模型，阐述了 LES 的 Smagorinsky、动态 Smagorinsky 和 WALE 亚格子模型，以及 DES/DDES/IDDES 混合方法。模型的选择取决于流动问题、可用计算资源和精度需求。湍流模型的本质是对 [[06-层流与湍流|NS 方程]] 中未解析尺度进行模化，任何模型都不是普适的——理解模型的假设与局限是正确使用的关键。
