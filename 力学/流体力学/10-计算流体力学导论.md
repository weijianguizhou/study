# 第十章 计算流体力学导论

## 引言

计算流体力学（Computational Fluid Dynamics, CFD）是利用计算机数值求解流体力学控制方程的科学。自 1950 年代 von Neumann 和 Richtmyer 的开创性工作以来，CFD 已发展为与理论流体力学和实验流体力学并立的第三大研究范式。今天，CFD 贯穿航空、汽车、能源、环境、生物医学等领域的流动分析与设计优化。

本章覆盖 CFD 的核心概念：离散化方法、有限差分基础、经典格式的稳定性分析、压力-速度耦合算法，以及完整的 Python 算例。

---

## 10.1 CFD 工作流程

一个典型的 CFD 分析包括以下步骤：

```
几何建模 → 网格生成 → 物理模型选择 → 边界条件设置
    → 数值求解（迭代/推进） → 收敛判定 → 后处理与可视化
```

### 10.1.1 网格类型

- **结构化网格**：六面体/四边形，节点有序排列。精度高，适合简单几何，但复杂外形处理困难。
- **非结构化网格**：四面体/三角形，节点连接拓扑灵活。适合复杂几何，但计算精度和效率低于结构化网格。
- **贴体网格**：沿物面生成的正交/近正交网格，用于边界层解析。
- **自适应网格（AMR）**：根据解的特征自动加密/粗化网格。

### 10.1.2 边界条件类型

| 类型 | 适用范围 | 典型设置 |
|------|----------|----------|
| 壁面 | 固壁边界 | 无滑移：$\boldsymbol u = 0$；绝热或等温 |
| 入口 | 来流边界 | $u = U_\infty$，$T = T_\infty$（指定值） |
| 出口 | 出流边界 | 压力出口或 $\partial \boldsymbol u/\partial n = 0$ |
| 对称 | 对称平面 | $\partial(\cdot)/\partial n = 0$ |
| 远场 | 外流截断 | 基于特征变量的无反射边界条件 |
| 周期 | 旋转/平移对称 | 两侧对应点物理量相等 |

## 10.2 离散化方法

### 10.2.1 有限差分法（FDM）

FDM 是最早发展的数值方法。将计算域划分为网格节点，用差分商近似偏导数。优点是概念直观，实现简单；缺点是对复杂几何的处理不够灵活。

### 10.2.2 有限体积法（FVM）

FVM 将守恒型控制方程在控制体积上积分，利用 Gauss 散度定理将体积分转化为面积分：

$$
\int_\Omega \frac{\partial U}{\partial t} d\Omega + \oint_{\partial\Omega} \boldsymbol F \cdot \boldsymbol n \, dS = \int_\Omega Q \, d\Omega
$$

FVM 天然满足局部和全局守恒，是当前主流商业/开源 CFD 软件（Fluent、OpenFOAM、CFX）的核心方法。

### 10.2.3 有限元法（FEM）

FEM 将方程乘试函数后在单元上积分，得到弱形式。对复杂几何和自适应网格有天然优势，在固体力学和流固耦合中广泛应用。对于纯流动问题，FVM 比 FEM 更主流，但 FEM 已成功应用于不可压缩 Navier-Stokes 方程。

## 10.3 有限差分方法

### 10.3.1 Taylor 展开与差商

函数 $u(x)$ 在 $x_{i+1}$ 和 $x_{i-1}$ 处的 Taylor 展开：

$$
u_{i+1} = u_i + \Delta x\,u_i' + \frac{\Delta x^2}{2}u_i'' + \frac{\Delta x^3}{6}u_i''' + \frac{\Delta x^4}{24}u_i^{(4)} + \cdots
$$

$$
u_{i-1} = u_i - \Delta x\,u_i' + \frac{\Delta x^2}{2}u_i'' - \frac{\Delta x^3}{6}u_i''' + \frac{\Delta x^4}{24}u_i^{(4)} - \cdots
$$

由这些展开可构造各种差分格式。

### 10.3.2 一阶导数差分格式

**前向差分（FDS）**：

$$
\left.\frac{\partial u}{\partial x}\right|_i = \frac{u_{i+1} - u_i}{\Delta x} + O(\Delta x)
$$

**后向差分（BDS）**：

$$
\left.\frac{\partial u}{\partial x}\right|_i = \frac{u_i - u_{i-1}}{\Delta x} + O(\Delta x)
$$

**中心差分（CDS）**：

$$
\left.\frac{\partial u}{\partial x}\right|_i = \frac{u_{i+1} - u_{i-1}}{2\Delta x} + O(\Delta x^2)
$$

### 10.3.3 二阶导数差分格式

通过组合两个一阶导数的中心差分可得：

$$
\left.\frac{\partial^2 u}{\partial x^2}\right|_i = \frac{u_{i+1} - 2u_i + u_{i-1}}{\Delta x^2} + O(\Delta x^2)
$$

### 10.3.4 精度阶数

截断误差的主导项决定格式的精度阶数。例如，中心差分为二阶精度（$O(\Delta x^2)$），前向差分为一阶精度（$O(\Delta x)$）。高阶格式（四阶、六阶等）可通过更多点的加权组合构造，常用于 DNS 和波动问题。

## 10.4 一维对流方程

考虑一维线性对流方程：

$$
\frac{\partial u}{\partial t} + c\frac{\partial u}{\partial x} = 0,\quad c > 0
$$

在时间和空间上分别进行离散。

### 10.4.1 FTCS 格式

Forward-Time Central-Space：

$$
u_i^{n+1} = u_i^n - \frac{c\Delta t}{2\Delta x}(u_{i+1}^n - u_{i-1}^n)
$$

**von Neumann 稳定性分析**：令 $u_i^n = G^n e^{ikx_i}$，代入得：

$$
G = 1 - i\frac{c\Delta t}{\Delta x}\sin(k\Delta x)
$$

$|G|^2 = 1 + \left(\frac{c\Delta t}{\Delta x}\sin(k\Delta x)\right)^2 \ge 1$，因此 FTCS 对对流方程**无条件不稳定**——FTCS 在物理上不可用。

### 10.4.2 Lax 格式

Lax 将 $u_i^n$ 替换为空间平均：

$$
u_i^{n+1} = \frac12(u_{i+1}^n + u_{i-1}^n) - \frac{c\Delta t}{2\Delta x}(u_{i+1}^n - u_{i-1}^n)
$$

稳定性条件（CFL 条件）为 $|c\Delta t/\Delta x| \le 1$。但 Lax 格式存在较大的数值耗散。

### 10.4.3 Lax-Wendroff 格式

Lax-Wendroff 是二阶精度格式，通过 Taylor 展开引入高阶项：

$$
u_i^{n+1} = u_i^n - \frac{c\Delta t}{2\Delta x}(u_{i+1}^n - u_{i-1}^n)
          + \frac{c^2\Delta t^2}{2\Delta x^2}(u_{i+1}^n - 2u_i^n + u_{i-1}^n)
$$

稳定条件：$|c\Delta t/\Delta x| \le 1$。相比 Lax 格式，数值耗散小得多，是经典的两步格式。

### 10.4.4 迎风格式（Upwind）

利用特征方向信息：

$$
u_i^{n+1} = u_i^n - \frac{c\Delta t}{\Delta x}(u_i^n - u_{i-1}^n)
$$

von Neumann 分析给出：$G = 1 - \sigma + \sigma e^{-ik\Delta x}$，其中 $\sigma = c\Delta t/\Delta x$。

稳定性条件：$0 \le \sigma \le 1$。迎风格式在满足 CFL 条件时稳定，但为一阶精度，数值耗散较大。

```python
import numpy as np
import matplotlib.pyplot as plt

def upwind_1d_convection(c, L=1.0, nx=100, nt=200):
    """一维对流方程迎风格式求解"""
    dx = L / nx
    x = np.linspace(0, L, nx)
    sigma = 0.5
    dt = sigma * dx / c

    # 初始条件：Gaussian 脉冲
    u = np.exp(-((x - 0.2) / 0.05)**2)
    u_new = u.copy()

    for _ in range(nt):
        u_new[1:] = u[1:] - sigma * (u[1:] - u[:-1])
        u_new[0] = u[0]  # 入口边界
        u, u_new = u_new, u

    return x, u

x, u = upwind_1d_convection(1.0)
plt.plot(x, np.exp(-((x - 0.7) / 0.05)**2), '--k', label='Exact')
plt.plot(x, u, '-r', label='Upwind')
plt.legend()
plt.title('一维对流方程：迎风格式')
plt.show()
```

## 10.5 一维扩散方程

考虑一维扩散方程：

$$
\frac{\partial u}{\partial t} = \alpha\frac{\partial^2 u}{\partial x^2}
$$

### 10.5.1 显式格式（FTCS 扩散）

$$
u_i^{n+1} = u_i^n + \frac{\alpha\Delta t}{\Delta x^2}(u_{i+1}^n - 2u_i^n + u_{i-1}^n)
$$

稳定性条件：

$$
d = \frac{\alpha\Delta t}{\Delta x^2} \le \frac12
$$

其中 $d$ 为扩散数。

### 10.5.2 Crank-Nicolson 隐式格式

Crank-Nicolson 将空间差分取为 $n$ 和 $n+1$ 时刻的平均，是无条件稳定的二阶精度格式：

$$
\frac{u_i^{n+1} - u_i^n}{\Delta t} = \frac{\alpha}{2\Delta x^2}
\left[(u_{i+1}^{n+1} - 2u_i^{n+1} + u_{i-1}^{n+1}) + (u_{i+1}^n - 2u_i^n + u_{i-1}^n)\right]
$$

整理为三对角线性系统：

$$
-\frac{d}{2}u_{i-1}^{n+1} + (1+d)u_i^{n+1} - \frac{d}{2}u_{i+1}^{n+1} = \frac{d}{2}u_{i-1}^n + (1-d)u_i^n + \frac{d}{2}u_{i+1}^n
$$

其中 $d = \alpha\Delta t/\Delta x^2$。

```python
import numpy as np
from scipy.linalg import solve_banded

def crank_nicolson_1d(alpha, L=1.0, nx=50, dt=0.01, nt=100):
    """Crank-Nicolson 求解一维扩散方程"""
    dx = L / nx
    d = alpha * dt / dx**2
    x = np.linspace(0, L, nx+1)

    # 初始条件
    u = np.sin(np.pi * x)

    # 构造三对角矩阵（带存储格式）
    ab = np.zeros((3, nx+1))
    ab[0, 1:] = -d/2         # 上对角线
    ab[1, :] = 1 + d         # 主对角线
    ab[2, :-1] = -d/2        # 下对角线

    for _ in range(nt):
        rhs = (d/2 * np.roll(u, 1) + (1-d) * u + d/2 * np.roll(u, -1))
        rhs[0] = 0; rhs[-1] = 0  # Dirichlet b.c.
        u = solve_banded((1, 1), ab, rhs)

    return x, u

x, u = crank_nicolson_1d(0.1, nt=200)
x_ex = np.linspace(0, 1, 100)
u_ex = np.exp(-0.1*np.pi**2*200*0.01) * np.sin(np.pi*x_ex)
plt.plot(x_ex, u_ex, '--k', label='Exact')
plt.plot(x, u, 'or', markersize=3, label='C-N')
plt.legend()
plt.title('Crank-Nicolson 一维扩散')
plt.show()
```

### 10.5.3 其他隐式格式

- **Laasonen 格式**（全隐式）：无条件稳定，一阶时间精度
- **Richardson 外推**：可提高时间精度
- **ADI 法**（交替方向隐式）：将多维问题分解为几个一维隐式步

## 10.6 von Neumann 稳定性分析

### 10.6.1 基本原理

von Neumann 分析假设周期边界条件，将差分解展开为 Fourier 级数。考察单个 Fourier 分量：

$$
u_i^n = G^n e^{ikx_i}
$$

代入差分格式，得到**增长因子** $G(k)$。稳定的充要条件为：

$$
|G| \le 1 + O(\Delta t) \quad\text{(或通常简化为 } |G| \le 1\text{)}
$$

对所有的波数 $k$ 成立。

### 10.6.2 CFL 条件

Courant-Friedrichs-Lewy（CFL）条件是显式格式稳定性的必要（通常也是充分）条件，其物理含义是数值依赖域必须包含物理依赖域。

对于一维对流方程，CFL 条件为：

$$
\boxed{\sigma = \frac{c\Delta t}{\Delta x} \le 1}
$$

其中 $\sigma$ 称为 CFL 数或 Courant 数。对于多维问题，CFL 条件更严格，例如二维对流方程：

$$
\sigma = \frac{c\Delta t}{\Delta x} + \frac{c\Delta t}{\Delta y} \le 1
$$

### 10.6.3 常见格式的稳定性汇总

| 格式 | 方程类型 | 稳定性条件 |
|------|---------|-----------|
| FTCS（对流） | 一维对流 | 无条件不稳定 |
| 迎风 | 一维对流 | $0 \le \sigma \le 1$ |
| Lax | 一维对流 | $\|\sigma\| \le 1$ |
| Lax-Wendroff | 一维对流 | $\|\sigma\| \le 1$ |
| FTCS（扩散） | 一维扩散 | $d \le 1/2$ |
| Crank-Nicolson | 一维扩散 | 无条件稳定 |
| 全隐式 | 一维扩散 | 无条件稳定 |

## 10.7 多维与不可压缩求解

### 10.7.1 不可压缩 N-S 方程求解的困难

不可压缩 N-S 方程中压力没有独立方程——它由速度场的散度为零条件（$\nabla \cdot \boldsymbol u = 0$）隐式确定。这一约束是求解的主要困难，需要特殊的压力-速度耦合算法。

### 10.7.2 SIMPLE 算法

SIMPLE（Semi-Implicit Method for Pressure Linked Equations）由 Patankar 和 Spalding（1972）提出，是压力修正方法的经典代表。

**基本思路**：

1. 从猜测的压力场 $p^*$ 出发，求解离散动量方程，得到速度场 $\boldsymbol u^*$
2. 速度场一般不满足连续性方程，构造压力修正方程修正压力
3. 重复直到收敛

**核心步骤**：

```
1. 猜测 p*
2. 求解动量方程 → u*, v*
3. 求解压力修正方程 p'          
4. 修正：p = p* + α_p·p'
         u = u* + u'(p')
5. 求解其他标量方程（k, ε 等）
6. 以修正后的压力作为新猜测，回到步 2，直到残差满足要求
```

其中 $\alpha_p$ 是亚松弛因子（通常 0.3 $\sim$ 0.8）以保证收敛。

**SIMPLE 的变种**：

- **SIMPLER**：用压力方程代替修正，更稳定但计算量更大
- **SIMPLEC**：改进的修正系数，收敛速度更快
- **PISO**：多步修正，适用于非定常流动

### 10.7.3 投影法（Projection Method）

Chorin（1968）提出了另一种思路——分步法。将 N-S 方程拆分为：

**Step 1（预测步）**：忽略压力项，计算中间速度 $\boldsymbol u^*$：

$$
\frac{\boldsymbol u^* - \boldsymbol u^n}{\Delta t} = -(\boldsymbol u^n \cdot \nabla)\boldsymbol u^n + \nu\nabla^2\boldsymbol u^n
$$

**Step 2（投影步）**：将 $\boldsymbol u^*$ 投影到无散空间：

$$
\frac{\boldsymbol u^{n+1} - \boldsymbol u^*}{\Delta t} = -\nabla\phi,\qquad
\nabla\cdot\boldsymbol u^{n+1} = 0
$$

对上式取散度得到 Poisson 方程：

$$
\nabla^2\phi = \frac{1}{\Delta t}\nabla\cdot\boldsymbol u^*
$$

求解 $\phi$ 后，更新压力和速度：

$$
p^{n+1} = p^n + \phi,\qquad
\boldsymbol u^{n+1} = \boldsymbol u^* - \Delta t\,\nabla\phi
$$

投影法形式简洁，广泛用于不可压缩 DNS 和 LES。

## 10.8 Python 求解器示例

### 10.8.1 一维对流方程（迎风格式 + 精确解比较）

```python
import numpy as np
import matplotlib.pyplot as plt

def solve_advection_1d(c=1.0, L=2.0, nx=200, sigma=0.5, nt=400):
    dx = L / nx
    dt = sigma * dx / c
    x = np.linspace(0, L, nx)
    u = np.exp(-((x - 0.3) / 0.08)**2)
    u_init = u.copy()

    for _ in range(nt):
        u[1:] -= sigma * (u[1:] - u[:-1])

    u_exact = np.exp(-(((x - 0.3) - c*nt*dt) / 0.08)**2)
    return x, u, u_exact

x, u_num, u_ex = solve_advection_1d()
plt.plot(x, u_num, label='Numerical')
plt.plot(x, u_ex, '--', label='Exact')
plt.legend()
plt.show()
```

### 10.8.2 一维扩散方程（Crank-Nicolson）

```python
import numpy as np
from scipy.linalg import solve_banded

def solve_diffusion_1d(alpha=0.1, L=1.0, nx=100, dt=0.005, nt=500):
    dx = L / nx
    d = alpha * dt / dx**2
    x = np.linspace(0, L, nx+1)
    u = np.sin(np.pi * x)

    ab = np.zeros((3, nx+1))
    ab[0, 1:] = -d/2
    ab[1, :] = 1 + d
    ab[2, :-1] = -d/2

    for _ in range(nt):
        rhs = (d/2 * np.roll(u, 1) + (1-d) * u + d/2 * np.roll(u, -1))
        rhs[0] = 0; rhs[-1] = 0
        u = solve_banded((1, 1), ab, rhs)

    u_ex = np.sin(np.pi * x) * np.exp(-alpha * np.pi**2 * nt * dt)
    return x, u, u_ex
```

### 10.8.3 二维 Poisson 方程求解器

以下代码用 Jacobi 迭代法求解 $\nabla^2 p = f$ 在 $[0,1]^2$ 上，$p=0$ 在边界。

```python
import numpy as np

def poisson_2d_jacobi(f, nx=64, ny=64, max_iter=10000, tol=1e-6):
    """Jacobi 迭代求解 2D Poisson 方程"""
    dx = 1.0 / (nx - 1)
    dy = 1.0 / (ny - 1)
    p = np.zeros((ny, nx))
    p_new = p.copy()
    dx2, dy2 = dx**2, dy**2
    denom = 2 * (dx2 + dy2)

    for it in range(max_iter):
        p_new[1:-1, 1:-1] = (
            dy2 * (p[1:-1, :-2] + p[1:-1, 2:]) +
            dx2 * (p[:-2, 1:-1] + p[2:, 1:-1]) -
            dx2 * dy2 * f[1:-1, 1:-1]
        ) / denom

        diff = np.max(np.abs(p_new - p))
        p, p_new = p_new, p
        if diff < tol:
            return p, it + 1
    return p, max_iter

# 测试算例
nx = ny = 64
x = np.linspace(0, 1, nx)
y = np.linspace(0, 1, ny)
X, Y = np.meshgrid(x, y)
f = -2 * np.sin(np.pi * X) * np.sin(np.pi * Y) * np.pi**2 * 2  # 使解析解已知
p, n_iter = poisson_2d_jacobi(f)
print(f"Converged in {n_iter} iterations")

# 精确解对比
p_exact = np.sin(np.pi * X) * np.sin(np.pi * Y)
print(f"L2 error: {np.sqrt(np.sum((p - p_exact)**2)):.2e}")
```

以上代码仅为教学演示。实际工程求解器会使用更高效的迭代方法（SOR、Multigrid、Krylov 子空间法如 CG/GMRES）。

## 10.9 前沿主题概览

### 高阶格式
- **WENO**（加权本质无振荡格式）：捕捉激波的同时保持高阶精度
- **谱方法**：使用全局 Fourier/Chebyshev 多项式展开，指数收敛

### 湍流模拟
- **RANS**（Reynolds-Averaged Navier-Stokes）：工程标准，$k\!-\!\varepsilon$、$k\!-\!\omega$ SST 等
- **LES**（Large Eddy Simulation）：直接计算大尺度涡，模化亚格子尺度
- **DNS**（Direct Numerical Simulation）：直接求解所有尺度，计算量极大（$Re^{9/4}$）

### 网格技术
- **动网格/重叠网格**：处理运动边界（叶片旋转、飞行器分离）
- **浸入边界法（IBM）**：在简单直角网格上模拟复杂边界

### 多物理场耦合
- **流-固耦合（FSI）**：气动弹性、生物瓣膜
- **流-热-化耦合**：燃烧、高超声速热化学非平衡

### AI 与 CFD
- **数据驱动湍流模型**：用神经网络改进 RANS 模化
- **物理信息神经网络（PINN）**：将 PDE 嵌入损失函数，无需网格
- **代理模型/降阶模型（ROM）**：加速设计和优化循环

---

## 总结

1. **CFD 工作流程**涉及几何、网格、物理模型、求解器和后处理的完整链条。**有限体积法**因天然守恒性成为主流商业软件的基础。
2. **有限差分法**以 Taylor 展开为核心，构造各阶精度的导数近似。一阶导数的前向/后向/中心差分的精度和稳定性不同。
3. 一维对流方程中，FTCS 无条件不稳定，**迎风格式**和 **Lax-Wendroff 格式**在满足 CFL 条件（$\sigma \le 1$）时稳定。
4. 一维扩散方程中，显式格式要求 $d \le 1/2$；**Crank-Nicolson 隐式格式**无条件稳定、二阶精度，是扩散问题的首选。
5. **von Neumann 分析**是线性稳定性分析的通用框架。CFL 条件规定了显式格式时间步长的上界。
6. 不可压缩 N-S 方程的压力-速度耦合通过 **SIMPLE 算法**（稳态）或 **投影法**（非定常）处理。**Poisson 方程**的迭代求解是关键子步骤。
7. Python 适合教学和原型开发；高性能 CFD 需使用 Fortran/C++ 和并行计算（MPI/GPU）。

> **关联章节**：CFD 求解的对象是[[05-粘性流体动力学]]的 N-S 方程。边界层问题（[[07-边界层理论]]）需要特殊的壁面处理或壁面函数。可压缩流动（[[09-可压缩流动]]）的激波捕捉需要高阶保单调格式。数学基础涉及[[../../数理基础/向量微积分]]（散度定理）、[[../../数理基础/数学物理方程/00-数学物理方程MOC|偏微分方程]]（抛物型/双曲型分类）和[[../../数理基础/ODE常微分方程]]（时间推进）。
