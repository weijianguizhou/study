# 第8章：自定义命令与环境

LaTeX 的优势之一在于其极高的可扩展性。通过自定义命令、环境和计数器，用户可以构建自己的"宏包级"抽象，大幅提升写作效率。

---

## 8.1 自定义命令

### 8.1.1 \newcommand 基础

基本语法：

```latex
\newcommand{⟨命令名⟩}[⟨参数个数⟩]{⟨定义⟩}
\newcommand{⟨命令名⟩}[⟨参数个数⟩][⟨默认值⟩]{⟨定义⟩}
```

**示例：无参数命令**

```latex
\newcommand{\ve}{\varepsilon}
\newcommand{\R}{\mathbb{R}}
```
使用：`$\ve > 0$, $\R^n$`

**示例：带参数命令**

```latex
\newcommand{\norm}[1]{\lVert #1 \rVert}
```
使用：`$\norm{v}$` 或 `$\norm{\mathbf{x}}$`，输出 `‖v‖`、`‖x‖`。

### 8.1.2 多参数命令

```latex
\newcommand{\deriv}[3]{\frac{\mathrm{d}^{#1} #2}{\mathrm{d} #3^{#1}}}
```
使用：`$\deriv{2}{y}{x}$` 输出 `d²y/dx²`。

### 8.1.3 可选参数

在参数个数后以 `[⟨默认值⟩]` 指定可选参数，使用 `#1` 引用：

```latex
\newcommand{\keyword}[2][红]{\textcolor{#1}{\textbf{#2}}}
```
使用：`\keyword{重要}`（红色）或 `\keyword[蓝]{重要}`（蓝色）。

> 注意：可选参数在 LaTeX 中默认为第一个参数。若需多个可选参数，推荐使用 `xparse` 宏包。

### 8.1.4 \renewcommand 与 \providecommand

- `\renewcommand`：重定义**已有**命令

```latex
\renewcommand{\epsilon}{\varepsilon}
```

- `\providecommand`：仅在命令**未定义**时定义，用于宏包兼容

```latex
\providecommand{\todo}[1]{\textbf{[TODO: #1]}}
```

### 8.1.5 \DeclareRobustCommand——处理脆弱命令

在移动参数（如章节标题、脚注）中使用 `\newcommand` 定义的命令可能导致错误。此时应使用 `\DeclareRobustCommand`：

```latex
\DeclareRobustCommand{\TODO}[1]{\textbf{#1}}
```
使用：`\section{\TODO{待完善的部分}}`

> Mittelbach 等 *The LaTeX Companion* 第 12 章指出，对于会出现在章节标题、浮动体标题等"移动参数"中的命令，应始终使用 `\DeclareRobustCommand` 以确保稳定性。

## 8.2 自定义环境

### 8.2.1 \newenvironment 基础

```latex
\newenvironment{⟨名称⟩}[⟨参数个数⟩]{⟨起始代码⟩}{⟨结束代码⟩}
```

**示例：定理环境**

```latex
\newenvironment{mytheorem}[1][定理]
  {\textbf{#1}\itshape}
  {\par}
```
使用：

```latex
\begin{mytheorem}
  每个大于 1 的正整数都可以唯一分解为素数的乘积。
\end{mytheorem}
```

### 8.2.2 带参数的环境

参数在 `⟨起始代码⟩` 中以 `#1`、`#2` 引用：

```latex
\newenvironment{definition}[1][定义]
  {\par\noindent\textbf{#1.}\ \itshape}
  {\par}
```

### 8.2.3 \renewenvironment 重定义环境

与命令同理，使用 `\renewenvironment` 覆盖已有环境：

```latex
\renewenvironment{abstract}
  {\par\small\noindent\textbf{摘要}\quad}
  {\par}
```

## 8.3 计数器的操作

### 8.3.1 创建与操作计数器

计数器是 LaTeX 编号系统的底层机制：

| 命令 | 作用 |
|------|------|
| `\newcounter{⟨name⟩}[⟨within⟩]` | 新建计数器（within 可选，指定父级计数器） |
| `\setcounter{⟨name⟩}{⟨n⟩}` | 设置计数值 |
| `\addtocounter{⟨name⟩}{⟨n⟩}` | 增加计数值 |
| `\value{⟨name⟩}` | 获取计数值（用于表达式） |
| `\stepcounter{⟨name⟩}` | 加 1（同时复位子计数器） |
| `\refstepcounter{⟨name⟩}` | 加 1，且使该值可被 `\label` 引用 |

**示例：自定义定理计数器**

```latex
\newcounter{theorem}[section]
\renewcommand{\thetheorem}{\thesection.\arabic{theorem}}

\newcommand{\theorem}[1]{%
  \refstepcounter{theorem}%
  \textbf{定理~\thetheorem.}~#1\par}
```
使用：

```latex
\section{基础}
\theorem{素数分解唯一性}
```

### 8.3.2 控制编号输出格式

`\the⟨计数器名⟩` 控制计数器的显示格式：

| 格式化命令 | 示例 |
|------------|------|
| `\arabic{⟨ctr⟩}` | 1, 2, 3, … |
| `\roman{⟨ctr⟩}` | i, ii, iii, … |
| `\Roman{⟨ctr⟩}` | I, II, III, … |
| `\alph{⟨ctr⟩}` | a, b, c, … |
| `\Alph{⟨ctr⟩}` | A, B, C, … |
| `\fnsymbol{⟨ctr⟩}` | ∗, †, ‡, …（脚注符号） |

```latex
\renewcommand{\thesection}{\Roman{section}}
\renewcommand{\thesubsection}{\thesection.\Alph{subsection}}
```

> 刘海洋《LaTeX 入门》第 5 章指出，合理的编号格式约定是文档可读性的重要组成部分，务必保持一致性。

## 8.4 基础宏编程

### 8.4.1 原始定义命令

LaTeX 底层基于 TeX 宏语言，提供了更底层的定义方式：

| 命令 | 含义 |
|------|------|
| `\def⟨cmd⟩{⟨body⟩}` | 无条件定义，覆盖已有定义 |
| `\edef⟨cmd⟩{⟨body⟩}` | 定义并**立即展开** body 中的宏 |
| `\gdef⟨cmd⟩{⟨body⟩}` | 全局定义（无视分组） |
| `\xdef⟨cmd⟩{⟨body⟩}` | 全局定义 + 立即展开 |

```latex
{\def\foo{局部} \foo} % 输出"局部"
\gdef\bar{全局}        % 全局定义
{\bar}                 % 在分组外仍有效
```

### 8.4.2 \let 命令复制

`\let` 将一条命令的当前含义复制给另一条命令，常用于保存后再重定义：

```latex
\let\oldsection\section
\renewcommand{\section}[1]{%
  \oldsection{#1}%
  \markright{第~\thesection~节}}
```

### 8.4.3 条件判断

LaTeX 的条件判断系统来自 TeX：

**\ifx——比较两个宏的定义是否相同**

```latex
\ifx\cmdA\cmdB ⟨相等时⟩ \else ⟨不等时⟩ \fi
```

**\ifnum——数值比较**

```latex
\ifnum\value{page}>10 ⟨后续页⟩ \else ⟨首页内容⟩ \fi
```

### 8.4.4 \loop...\repeat 循环

```latex
\newcount\mycount
\mycount=1
\loop
  $n = \the\mycount$\\
  \advance\mycount by 1
\ifnum\mycount<6
\repeat
```

输出 n = 1 到 n = 5。

> **警告**：`\loop` 若不慎写成无限循环，将导致 TeX 栈溢出而崩溃。
