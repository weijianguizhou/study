# 02 · 文档结构与基础命令

## 2.1 源文件结构

一个 LaTeX 源文件由两部分组成：**导言区**（preamble）和**正文区**（document body）。

```latex
% ====== 导言区 ======
\documentclass[12pt,a4paper]{article}   % 文档类声明，带选项
\usepackage{ctex}                        % 加载宏包
\usepackage{amsmath,amssymb}
\title{示例文档}                         % 元数据
\author{作者}

% ====== 正文区 ======
\begin{document}
\maketitle
这是正文内容。
\end{document}
```

**`\documentclass[options]{class}`** 声明文档类。常用文档类：

| 文档类 | 用途 |
|--------|------|
| `article` | 论文、报告、短文 |
| `report` | 长篇报告、学位论文（有 chapter 命令） |
| `book` | 书籍（有 part, chapter，支持 openright） |
| `beamer` | 演示文稿（见第10章） |
| `ctexart` / `ctexrep` / `ctexbook` | ctex 宏包提供的中文文档类 |

常见选项：`10pt/11pt/12pt`（字号）、`a4paper/letterpaper`（纸张）、`twocolumn`（双栏）、`oneside/twoside`。

## 2.2 基础命令语法

LaTeX 命令（command / macro）以反斜杠 `\` 开头，分为三种形式：

1. **无参数命令**：`\command`
2. **带可选参数**：`\command[options]` 如 `\documentclass[12pt]{article}`
3. **带必选参数**：`\command{arg}` 或 `\command{arg1}{arg2}`

**特殊字符的转义**：

| 字符 | 含义 | 输入方式 |
|------|------|----------|
| `#` | 宏参数 | `\#` |
| `$` | 数学模式 | `\$` |
| `%` | 注释 | `\%` |
| `&` | 表格对齐 | `\&` |
| `_` | 下标 | `\_` |
| `{ }` | 分组 | `\{` `\}` |
| `~` | 不可断空格 | `\textasciitilde{}` |
| `\` | 命令引导 | `\textbackslash{}` |

**空格与换行**：连续空格合并为一个；单个换行视为空格；**空行**表示段落结束。行末 `%` 可消除该行换行引入的空格。

**分组**：`{作用域}` 用于限制命令效果的范围。

```latex
{ \Large 这段文字较大 } 这段恢复正常大小。
```

## 2.3 长度与单位

LaTeX 支持的长度单位：

| 单位 | 含义 | 换算 |
|------|------|------|
| pt | 点（point） | 1 in = 72.27 pt |
| mm | 毫米 | 1 cm = 10 mm |
| cm | 厘米 | 1 in = 2.54 cm |
| in | 英寸 | 1 in = 25.4 mm |
| em | 当前字体 M 的宽度 | 相对单位 |
| ex | 当前字体 x 的高度 | 相对单位 |

**弹性长度**（glue）：由固定值加伸缩量构成，如 `\textwidth=15cm plus 2cm minus 1cm`。LaTeX 利用胶合实现两端对齐排版。

常用长度命令：`\textwidth`、`\textheight`、`\parindent`（段落缩进）、`\baselineskip`（基线间距）。

## 2.4 宏包管理

宏包（package）是 `.sty` 文件，通过 `\usepackage` 加载：

```latex
\usepackage[options]{package}
```

宏包搜索路径由 TeX 发行版维护。CTAN（Comprehensive TeX Archive Network, https://ctan.org）是官方宏包仓库，收录超过 6000 个宏包。
