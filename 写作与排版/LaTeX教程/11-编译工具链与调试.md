# 11 · 编译工具链与调试

## 11.1 编译引擎对比

| 引擎 | 命令 | 输出 | 特点 |
|------|------|------|------|
| TeX | `tex` | DVI | 原始引擎，基本不用 |
| pdfTeX | `pdflatex` | PDF | 直接生成 PDF，中文需额外配置 |
| XeTeX | `xelatex` | PDF | 支持 Unicode 和系统字体，**推荐中文** |
| LuaTeX | `lualatex` | PDF | 支持 Lua 脚本，灵活处理字体 |
| (La)TeX | `latex` | DVI | 需 dvipdfmx 转 PDF |

**推荐策略**：
- 中文文档：`xelatex`
- 西文科技文档：`pdflatex` 或 `lualatex`
- 需要高级 OpenType 特性：`lualatex`

引用：刘海洋《LaTeX 入门》附录A。

## 11.2 编译流程

**含交叉引用的文档**需执行多次编译。标准流程：

```
xelatex main.tex       # 第1次：生成 .aux 辅助文件
xelatex main.tex       # 第2次：读入 .aux 解决引用
```

**含 BibTeX 参考文献**的流程：

```
xelatex main.tex       # 第1次：写 .aux，标记引用
bibtex   main          # 生成 .bbl 参考文献列表
xelatex main.tex       # 第2次：嵌入参考文献
xelatex main.tex       # 第3次：更新交叉引用
```

**含索引**（MakeIndex）：

```
xelatex main.tex
makeindex main.idx     # 生成 .ind 索引文件
xelatex main.tex
```

**latexmk 自动化**（推荐日常使用）：

```bash
latexmk -xelatex main.tex          # 自动执行所需次数
latexmk -xelatex -pvc main.tex     # 持续监控文件变化，自动重编译
latexmk -c                         # 清理辅助文件
```

## 11.3 常见报错对照

| # | 错误信息 | 原因 | 解决方法 |
|---|---------|------|---------|
| 1 | `! Undefined control sequence.` | 使用了未定义的命令 | 检查拼写，是否忘记 `\usepackage` |
| 2 | `! LaTeX Error: File 'xxx.sty' not found.` | 宏包文件缺失 | 安装宏包（tlmgr install xxx）或检查文件名 |
| 3 | `! Missing $ inserted.` | 数学命令在文本模式使用 | 在公式内使用，或添加 `$...$` |
| 4 | `! Extra }, or forgotten $.` | 括号或数学模式不匹配 | 检查 `{` `}` `$` 配对 |
| 5 | `! LaTeX Error: Environment xxx undefined.` | 环境未定义 | 检查是否加载了对应宏包 |
| 6 | `! Package inputenc Error: Unicode char ...` | 字符编码问题 | 使用 xelatex 或添加 `\usepackage[utf8]{inputenc}` |
| 7 | `! Emergency stop.` | 严重错误强制终止 | 查看之前第一个 Error |
| 8 | `! Dimension too large.` | TeX 内部计算溢出 | 减小数值或使用 `\begin{scope}[fpu=true]` |

## 11.4 调试技巧

**逐一排查法**：先用 `%` 注释掉一半内容，若编译通过则说明错误在另一半中，不断二分缩小范围。

**日志分析**：编译后查看 `.log` 文件。错误行通常以 `!` 开头，TeX 会指出出错位置（行号）。

**辅助工具**：

```latex
% 在导言区加入输出调试信息
\typeout{当前页边距：\the\oddsidemargin}

% 列出所有加载的宏包版本
\listfiles
```

编译时带 `-interaction=nonstopmode` 选项让 TeX 尽量继续而非停等：

```bash
xelatex -interaction=nonstopmode main.tex
```

**MWE（Minimal Working Example）**：制作最小可工作示例是排错的最佳实践——从完整文档中删除无关部分，保留能复现问题的最少代码。
