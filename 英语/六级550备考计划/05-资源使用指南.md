# 资源使用指南

> 你的两条主线：**不背单词**（词汇）+ **星火英语十合一六级通关**（真题与专项）。回到 [[00-总览与使用说明|总览]]
>
> **与课程的配合**：每日任务表里已并入课程任务（课后复习 ≥50min/门、作业 ≥1h/门）。课程多的日子，优先完成课程，CET-6 降到最低档；无课日把时间补给 CET-6。

## 一、不背单词（App）
**定位**：词汇主阵地。每天雷打不动。

1. **词库选择**：选"六级核心词"（或按 App 内 CET6 词书），别贪多。
2. **每日新词量**：基础期 40 / 强化期 30 / 冲刺期 0（只复习）。
3. **固定时段**：建议固定同一时段（如早起或睡前 20 分钟）学新词，形成习惯。
4. **复习必做**：App 按记忆曲线排的复习一定要当天清完，这是它最值钱的地方。
5. **生词外溢**：仍记不住的词，每周日整理进你的 LaTeX 单词本，冲刺期回看。

## 二、星火英语十合一六级通关（主教材）
**套装构成**（以十合一为准）：真题卷（16 套真题 + 3 套预测）、词汇册、听力专项、阅读专项、写作专项、翻译专项、语法/长难句册、应试指南、自测卷、答题卡。

| 分册 | 用法 | 用到哪个阶段 |
|---|---|---|
| 应试指南 | 开考前通读，了解流程与题型 | W1 |
| 词汇册 | 不背单词的对照补充 + 高频词串记 | 全程 |
| 听力专项 | 每天精听 1 篇（四步法） | W1–W6 |
| 阅读专项 | 每天精做仔细阅读 1 篇；强化期加入匹配 | W1–W11 |
| 语法/长难句 | 每天拆 1 个长难句，练句子主干 | W1–W8 |
| 写作专项 | 学模板 + 积累好句 | W4 起 |
| 翻译专项 | 每周练 2 段，对照解析改 | W4 起 |
| 真题卷 | 按 [[01-阶段计划]] 的真题分配表做 | 全程 |
| 自测卷 | 基础期末阶段自测 | W6 末 |
| 预测卷 | 冲刺期模考用（2 套）+ 考前备用 | W12–W15 |
| 答题卡 | 考前 1–2 天按 1:1 演练填涂 | 12.10–12.11 |

### 听力四步精听法（基础期每天用）
1. **盲听**：不看文本，完整听一遍，尽量抓主旨
2. **逐句听**：一句一句听，听不出的地方看文本，标出生词和连读
3. **跟读**：跟着录音读 1–2 遍，模仿语音语调
4. **复盘**：整理生词、信号词、同义替换，记入错题本

### 阅读精做步骤（基础期每天用）
1. **限时 8–10 分钟**做完 1 篇仔细阅读
2. 对答案，**不看解析先自己回找**定位句
3. 看解析，标记"同义替换"点
4. 整理生词 + 长难句，抄 1 句进错题本

## 三、错题本建议（冲刺期回看的关键）
建议单独建一篇 `错题本` 笔记，每条记录：
- 题型 / 日期 / 原文定位
- 我选了什么、正确答案是什么、为什么错
- 生词 / 同义替换 / 固定表达

## 四、时间安排参考（以晚上为主，可自行微调）
```
19:00–19:20  不背单词（新词 + 复习）
19:20–19:45  听力精听 1 篇
19:45–20:15  阅读精做 1 篇
20:15–20:25  写作/翻译积累
20:25–20:30  今日小结（可选）
```
周末上午/下午：完整套题或模考 2.5–3 小时。
