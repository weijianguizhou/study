# 数模与模数转换

> **桥梁章节**：连接模拟与数字 | **前置**：[[01-数制与编码|数制（数字表示）]] + [[../../模拟电路/章节/02-二极管及其应用|模拟信号处理]] | **后续**：[[11-可编程逻辑器件|PLD（与 ADC/DAC 接口）]]

## 一、概述

### 1.1 为什么要转换

```
模拟信号 ←→ 数字系统 ←→ 数字信号
    ↑                    ↑
   ADC                 DAC
```

- **ADC**（Analog-to-Digital Converter）：模拟 → 数字
- **DAC**（Digital-to-Analog Converter）：数字 → 模拟

### 1.2 应用场景

- 传感器信号采集（温度、压力、声音）→ ADC → 单片机
- 单片机 → DAC → 音频输出 / 电机控制

## 二、D/A 转换器（DAC）

### 2.1 基本原理

DAC 将数字量 $D$ 转换为模拟电压 $V_{out}$：

$$V_{out} = K \cdot D \cdot V_{REF}$$

其中 $D = D_{n-1}2^{n-1} + D_{n-2}2^{n-2} + \cdots + D_12^1 + D_02^0$

### 2.2 权电阻网络 DAC

```
    D0      D1       D2       D3
     │       │        │        │
    ┌┴┐     ┌┴┐      ┌┴┐      ┌┴┐
VREF │8R    │4R      │2R      │ R
    └┬┘     └┬┘      └┬┘      └┬┘
     │       │        │        │
     └───────┴────────┴────────┴───⊕── V₀
                                    │
                                   Rf
                                    │
                                   ┴ GND
```

**输出电压**：
$$V_o = -V_{REF} \cdot \frac{R_f}{R} \left(\frac{D_3}{1} + \frac{D_2}{2} + \frac{D_1}{4} + \frac{D_0}{8}\right)$$

**优点**：原理简单
**缺点**：电阻值范围宽（精度要求高，难以匹配）

### 2.3 倒 T 形电阻网络 DAC（最常用）

```
          R      R      R      2R
VREF ──┬─■─┬──┬─■─┬──┬─■─┬──┬─■─┬── GND
       │  │  │  │  │  │  │  │
       2R  2R  2R  2R  2R
       │  │  │  │  │  │  │  │
       └─D3 └─D2 └─D1 └─D0
                 接到运放虚构地
```

**输出电压**：
$$V_o = -\frac{V_{REF}}{2^n}(D_{n-1} \cdot 2^{n-1} + \cdots + D_0 \cdot 2^0)$$

**特点**：
- 只用 R 和 2R 两种电阻 → 易于匹配
- 各支路电流恒定（与开关状态无关）→ 开关速度高
- 运算放大器输入端虚地 → 减小寄生电容影响

### 2.4 DAC 主要指标

| 指标 | 含义 |
|------|------|
| **分辨率** | $V_{REF} / 2^n$，位数 $n$ 越高分辨率越高 |
| **转换误差** | 实际输出与理论值的偏差（LSB 表示） |
| **建立时间** | 数字输入变化到输出稳定的时间 |
| **非线性误差** | 实际曲线与理想直线的偏差 |

## 三、A/D 转换器（ADC）

### 3.1 ADC 的基本过程

```
模拟信号 → 采样 → 保持 → 量化 → 编码 → 数字信号
```

### 3.2 采样定理

$$f_s \geq 2f_{max}$$

- $f_s$：采样频率
- $f_{max}$：被采样信号的最高频率分量
- 不满足时产生**混叠失真**（Aliasing）

### 3.3 采样保持电路

```
Vi ──┬── M（MOSFET）── C ──┬── 输出缓冲器 ── V₀
     │                    │
     └── 控制信号         ┴ GND
```

- 采样阶段：M 导通，电容充电至 $V_i$
- 保持阶段：M 断开，电容保持电压
- 保持时间 $t_H$ 应足够 ADC 完成转换

### 3.4 量化与编码

- **量化**：将连续的模拟量离散化为有限个电平
- **量化误差**：$\pm \frac{1}{2}$ LSB（固有误差）

```
模拟输入范围 0~8V，3 位 ADC：
8V ── 111 ── 7/8 × 8 = 7V
7V ── 110 ── 6/8 × 8 = 6V
...        ...
1V ── 001 ── 1/8 × 8 = 1V
0V ── 000 ── 0V
```

## 四、ADC 的类型

### 4.1 并联比较型 ADC（Flash ADC）

**结构**：
- $2^n - 1$ 个比较器并行工作
- 电阻分压产生参考电平
- 比较器输出 → 优先编码器 → 数字输出

**特点**：
- **速度最快**（ns 级，一次比较）
- 分辨率受限：$n$ 位需要 $2^n - 1$ 个比较器
- 8 位需要 255 个比较器 → 芯片面积大、功耗高

**适用**：超高速应用（示波器、雷达）

### 4.2 逐次逼近型 ADC（SAR ADC）

**工作原理**：二分法逐次比较

```
V_in ──┬── 比较器 ──→ SAR 逻辑 ──→ DAC
       │                            │
       └────────────────────────────┘
```

**转换过程**（以 4 位为例）：
1. 设 DAC = 1000（1/2 VREF），比较
2. 若 V_in > DAC → 保留位 1，设下一位 1100
   若 V_in < DAC → 位 1 清 0，设下一位 0100
3. 重复直到所有位确定

**特点**：
- $n$ 位需要 $n$ 个时钟周期
- **速度中等**（μs 级）
- 精度高，功耗低
- **最常用的 ADC 类型**

### 4.3 双积分型 ADC

**工作原理**：
1. 对输入电压 $V_{in}$ 固定时间积分
2. 对参考电压 $-V_{REF}$ 反向积分至 0
3. 反向积分时间与 $V_{in}$ 成正比

**特点**：
- **速度慢**（ms 级）
- **精度极高**（可到 20+ 位）
- 抗干扰能力强（积分过程平均了噪声）
- 用于数字万用表、高精度测量

### 4.4 Σ-Δ 型 ADC

**工作原理**：
- 过采样 + 噪声整形 + 数字滤波
- 用 1 位比较器高速采样，再通过数字滤波器恢复

**特点**：
- 精度高（16~24 位）
- 对模拟前端的滤波要求低
- 速度中等
- 用于音频、高精度传感器

### 4.5 四种 ADC 对比

| 类型 | 速度 | 精度 | 功耗 | 成本 | 应用 |
|------|------|------|------|------|------|
| **并联比较型** | 极快 | 低 | 高 | 高 | 高速示波器 |
| **逐次逼近型** | 中 | 高 | 低 | 低 | 数据采集、单片机 |
| **双积分型** | 慢 | 极高 | 中 | 中 | 数字万用表 |
| **Σ-Δ 型** | 中 | 极高 | 中 | 中 | 音频、精密测量 |

## 五、ADC/DAC 的主要参数

### 5.1 静态参数

| 参数 | 含义 |
|------|------|
| **分辨率** | 位数 $n$ 或最小量化单位 $V_{LSB} = V_{REF}/2^n$ |
| **失调误差** | 输入为 0 时输出不为 0 的偏移 |
| **增益误差** | 实际满量程与理论满量程的偏差 |
| **微分非线性 DNL** | 实际步长与理论步长的偏差（$\leq \pm 0.5LSB$ 时为单调） |
| **积分非线性 INL** | 整体传输曲线与理想直线的偏差 |

### 5.2 动态参数

| 参数 | 含义 |
|------|------|
| **转换速度** | 每秒转换次数（SPS） |
| **建立时间**（DAC） | 数字变化到输出稳定的时间 |
| **信噪比 SNR** | 信号功率 / 噪声功率 |
| **有效位数 ENOB** | 实际有效分辨率（$ENOB = (SNR - 1.76) / 6.02$） |
| **无杂散动态范围 SFDR** | 信号功率 / 最大谐波功率 |

---

## 六、ADC 选型要点

| 应用 | 推荐 ADC 类型 | 典型参数 |
|------|--------------|----------|
| 温度测量 | Σ-Δ 或双积分 | 12~16 位，10~100 SPS |
| 音频录音 | Σ-Δ | 16~24 位，48~192k SPS |
| 电机控制 | SAR | 10~12 位，1M~10M SPS |
| 高速示波器 | 并联比较型 | 8~10 位，1G+ SPS |
| 万用表 | 双积分 | 16~22 位，1~10 SPS |

## 总结要点

| 概念 | 要点 |
|------|------|
| DAC | 数字 → 模拟，倒 T 形最常用 |
| ADC 过程 | 采样 → 保持 → 量化 → 编码 |
| 采样定理 | $f_s \geq 2f_{max}$ |
| SAR ADC | 最常用，$n$ 位需 $n$ 个时钟 |
| 并联比较型 | 最快，但面积和功耗大 |
| 双积分型 | 最准最慢 |
| ENOB | $SNR$ 决定实际有效精度 |
