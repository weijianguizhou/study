# 数制与编码

## 一、常用数制

### 1.1 数制对照

| 数制 | 基数 | 数码 | 后缀 |
|------|------|------|------|
| **二进制** | 2 | 0, 1 | B |
| **八进制** | 8 | 0~7 | O（或 Q） |
| **十进制** | 10 | 0~9 | D |
| **十六进制** | 16 | 0~9, A~F | H |

### 1.2 按权展开

任意进制数可表示为按权展开式：

$$(N)_R = \sum_{i=-m}^{n-1} a_i \times R^i$$

示例：
- $1101.01_2 = 1\times2^3 + 1\times2^2 + 0\times2^1 + 1\times2^0 + 0\times2^{-1} + 1\times2^{-2} = 13.25_{10}$
- $3A_{16} = 3\times16^1 + 10\times16^0 = 58_{10}$

## 二、进制转换

### 2.1 其他进制 → 十进制

**方法**：按权展开后求和

### 2.2 十进制 → 其他进制

**整数部分**：除基取余法（从下往上读）

```
例：25 → 二进制
25 ÷ 2 = 12 余 1 ─┐
12 ÷ 2 = 6  余 0 ─┤
6  ÷ 2 = 3  余 0 ─┤
3  ÷ 2 = 1  余 1 ─┤
1  ÷ 2 = 0  余 1 ─┤→ 11001B
```

**小数部分**：乘基取整法（从上往下读）

```
例：0.625 → 二进制
0.625 × 2 = 1.25 ── 1 ─┐
0.25  × 2 = 0.5  ── 0 ─┤
0.5   × 2 = 1.0  ── 1 ─┤→ 0.101B
```

### 2.3 二进制 ↔ 八进制/十六进制

| 转换方向 | 方法 |
|----------|------|
| 二 → 八 | 3 位一组（整数左补 0，小数右补 0） |
| 二 → 十六 | 4 位一组 |
| 八 → 二 | 每位转 3 位二进制 |
| 十六 → 二 | 每位转 4 位二进制 |

示例：
- $1101011_2 = 001\,101\,011 = 153_O$
- $1101011_2 = 0110\,1011 = 6B_H$

## 三、二进制数的运算

### 3.1 算术运算

- 加法：$0+0=0$，$0+1=1$，$1+1=0$（进位 1）
- 减法：借一当二
- 乘法：左移相加
- 除法：右移相减

### 3.2 逻辑运算

- 与（AND）：$1 \cdot 1 = 1$，其余为 0
- 或（OR）：$0 + 0 = 0$，其余为 1
- 非（NOT）：$\overline{0} = 1$，$\overline{1} = 0$
- 异或（XOR）：相异为 1，相同为 0

## 四、带符号数的表示

### 4.1 三种表示法

| 表示法 | 正数 | 负数示例（-5） | 特点 |
|--------|------|----------------|------|
| **原码** | 最高位 0 | $\textcolor{red}{1}101$ | 直观，但加减复杂 |
| **反码** | 同原码 | $\textcolor{red}{1}010$ | 负数 = 原码按位取反 |
| **补码** | 同原码 | $\textcolor{red}{1}011$ | 负数 = 反码 + 1 |

> 计算机一律用**补码**表示和运算

### 4.2 补码运算

$$[X+Y]_补 = [X]_补 + [Y]_补 \pmod{2^n}$$

- 减法转为加法：$X - Y = X + (-Y)$
- $[-Y]_补$ 的计算：$[Y]_补$ 连同符号位取反加 1

### 4.3 溢出判断

检测方法：两个正数相加得负数，或两个负数相加得正数

```verilog
overflow = (a_{n-1} == b_{n-1}) && (sum_{n-1} != a_{n-1})
```

## 五、常用编码

### 5.1 BCD 码

用 4 位二进制表示 1 位十进制数：

| 十进制 | 8421 BCD | 余 3 码 | 5421 BCD |
|--------|----------|---------|----------|
| 0 | 0000 | 0011 | 0000 |
| 1 | 0001 | 0100 | 0001 |
| 2 | 0010 | 0101 | 0010 |
| 3 | 0011 | 0110 | 0011 |
| 4 | 0100 | 0111 | 0100 |
| 5 | 0101 | 1000 | 1000 |
| 6 | 0110 | 1001 | 1001 |
| 7 | 0111 | 1010 | 1010 |
| 8 | 1000 | 1011 | 1011 |
| 9 | 1001 | 1100 | 1100 |

**8421 BCD**：用"0"~"9"的二进制表示，$1010 \sim 1111$ 为无效码

### 5.2 格雷码（Gray Code）

- 相邻两个数仅 1 位不同
- 消除多位数同时变化时的过渡毛刺
- 常用于计数器、ADC

**二进制 → 格雷码**：
$$G_i = B_i \oplus B_{i+1}$$

**格雷码 → 二进制**：
$$B_i = G_i \oplus B_{i+1}$$（$B_n = 0$ 开始递推）

### 5.3 ASCII 码

- 7 位编码，表示 128 个字符
- 0~31：控制字符
- 32~126：可打印字符
- 常见：'0' = 48（30H），'A' = 65（41H），'a' = 97（61H）

### 5.4 奇偶校验码

- 在数据后加 1 位校验位
- 使"1"的个数为奇数（奇校验）或偶数（偶校验）
- 只能检测奇数位错误，不能纠错

| 0111 | +7 | +7 | +7 |

## 总结要点

| 概念 | 要点 |
|------|------|
| 转换方法 | 整数除基取余，小数乘基取整 |
| 计算机存储 | 统一使用补码 |
| BCD 码 | 8421 最常用，$1010 \sim 1111$ 无效 |
| 格雷码 | 相邻仅变 1 位，防冒险 |
| 溢出 | 符号位进位与次高位进位不同 |
