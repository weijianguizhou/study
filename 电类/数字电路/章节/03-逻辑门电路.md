# 逻辑门电路

## 一、基本逻辑门

### 1.1 门电路符号（国家标准）

| 门类型 | 国标符号 | 表达式 |
|--------|----------|--------|
| 与门 | $\&$ | $Y = AB$ |
| 或门 | $\geq 1$ | $Y = A+B$ |
| 非门 | $1$ | $Y = \overline{A}$ |
| 与非门 | $\&$ ○ | $Y = \overline{AB}$ |
| 或非门 | $\geq 1$ ○ | $Y = \overline{A+B}$ |
| 异或门 | $=1$ | $Y = A \oplus B$ |
| 同或门 | $=1$ ○ | $Y = A \odot B$ |

### 1.2 正逻辑与负逻辑

- **正逻辑**：高电平 = 1，低电平 = 0（通常默认）
- **负逻辑**：高电平 = 0，低电平 = 1

> 正逻辑下的与门 = 负逻辑下的或门

## 二、TTL 门电路

### 2.1 TTL 基本结构

- **TTL**（Transistor-Transistor Logic）：输入端和输出端均为 BJT
- 电源 $V_{CC} = 5V$（早期），新系列为 3.3V / 2.5V
- 逻辑摆幅：$V_{OH} \geq 2.4V$，$V_{OL} \leq 0.4V$

### 2.2 TTL 与非门结构

```
输入 A ──┬─→ R1 ──→ T1(e)
输入 B ──┤          T1(c) ──→ T2(b) ──→ T2(c) ──→ T3(b) ──→ T3(e) ──→ 输出 Y
         │          T1 多发射极    T2 分相器       T3 推挽输出
         └─→ R1 ──→ T1(e)
```

**工作逻辑**：输入有 0 → $T_1$ 基极被拉低 → $T_2$ 截止 → $T_4$ 截止 → $T_3$ 导通 → 输出高电平

### 2.3 电气特性

| 参数 | 含义 | 典型值 |
|------|------|--------|
| $V_{OH}$ | 输出高电平 | $\geq 2.4V$ |
| $V_{OL}$ | 输出低电平 | $\leq 0.4V$ |
| $V_{IH}$ | 输入高电平阈值 | $\geq 2.0V$ |
| $V_{IL}$ | 输入低电平阈值 | $\leq 0.8V$ |
| $I_{OH}$ | 高电平输出电流 | $-0.4mA$ |
| $I_{OL}$ | 低电平输出电流 | $16mA$ |
| $t_{pd}$ | 平均传输延迟 | $几 ns \sim 几十 ns$ |

### 2.4 噪声容限

$$V_{NH} = V_{OH(min)} - V_{IH(min)}$$
$$V_{NL} = V_{IL(max)} - V_{OL(max)}$$

噪声容限越大，抗干扰能力越强

### 2.5 TTL 系列

| 系列 | 功耗/门 | 延迟/门 | 特点 |
|------|---------|---------|------|
| 74 标准 | 10mW | 10ns | 早期 |
| 74L 低功耗 | 1mW | 33ns | 功耗低 |
| 74S 肖特基 | 19mW | 3ns | 肖特基钳位，快 |
| 74LS 低功耗肖特基 | 2mW | 9.5ns | 最经典 |
| 74ALS 先进低功耗 | 1mW | 4ns | 改进 |
| 74F 快速 | 4mW | 3.5ns | 高速 |

## 三、CMOS 门电路

### 3.1 基本单元（反相器）

```
+ VDD
  │
  MP (P-MOS)
  │
  └─── 输出 Y
  │
  MN (N-MOS)
  │
  ┴ GND
```

- $A = 1$：MN 导通，MP 截止 → $Y = 0$
- $A = 0$：MN 截止，MP 导通 → $Y = 1$

> **特点**：静态时总有一个 MOS 截止，几乎不耗电

### 3.2 CMOS 与非门

```
  A ──┬─ MP1 ──┐        VDD
      │        │          │
  B ──┤  MP2 ──┤─ Y      ─┤
      │        │          │
      └─ MN1 ──┤─ GND    MP1 ─ MP2
               │          │
          MN2 ─┘─ GND     Y
                          │
                      MN1 ─┤─ GND
                      MN2 ─┘─ GND
```

- A 和 B 均为 1 → MN1、MN2 导通，MP1、MP2 截止 → $Y = 0$
- 任一输入为 0 → 对应 NMOS 截止、PMOS 导通 → $Y = 1$

### 3.3 CMOS 系列的优点

| 方面 | TTL | CMOS |
|------|-----|------|
| 静态功耗 | 高（mA 级） | 极低（μA 级） |
| 电源电压 | 5V（严格） | 3~18V（宽范围） |
| 噪声容限 | 一般 | 大（约 0.45 VDD） |
| 扇出 | 10~20 | >50 |
| 温度范围 | 窄 | 宽 |
| 集成度 | 低 | 高 |

### 3.4 CMOS 系列

| 系列 | 特点 |
|------|------|
| **4000 系列** | 早期，宽电压范围，速度慢 |
| **74HC** | CMOS 高速，$V_{CC}=2\sim6V$，兼容 TTL 逻辑 |
| **74HCT** | TTL 兼容型（输入阈值与 TTL 相同） |
| **74AC** | 先进 CMOS，速度极快 |
| **74AHC** | 高速 + 低功耗，替代 HC |

### 3.5 CMOS 的注意事项

- **静电敏感**：MOS 管栅极极易被静电击穿
- **输入不能悬空**：应接 VDD 或 GND，否则逻辑不确定且可能振荡
- **输出不能直接短路**：会损坏器件
- **未用门处理**：输入接 VDD 或 GND，或并联使用

## 四、TTL 与 CMOS 的接口问题

### 4.1 TTL 驱动 CMOS

- TTL $V_{OH} \approx 2.4V$ 可能不足以保证 CMOS 识别为高电平
- 解决方案：TTL 输出端接上拉电阻至 $V_{DD}$

### 4.2 CMOS 驱动 TTL

- CMOS 的 $I_{OH}$ 可能不足以驱动 TTL
- 解决方案：增加 CMOS 缓冲器或使用专门驱动门

### 4.3 混合使用原则

- 同电源电压下 74HC 可直接驱动 74LS，反之需要上拉电阻
- 74HCT 专为兼容 TTL 设计，可直接替换 74LS

## 五、集电极开路门（OC 门 / OD 门）

- OC 门：TTL 集电极开路输出
- OD 门：CMOS 漏极开路输出
- 特点：需要外接**上拉电阻**才能正常工作

**主要应用**：
1. **线与**：多个 OC 门输出可以直接并联
2. **电平转换**：上拉电阻接不同电压可改变输出电平
3. **驱动大电流负载**（LED、继电器等）

上拉电阻计算公式：
$$R_{P(min)} = \frac{V_{CC} - V_{OL(max)}}{I_{OL(max)} - N \cdot I_{IL}}$$
$$R_{P(max)} = \frac{V_{OH(min)} - V_{OH}}{M \cdot I_{IH}}$$

## 六、三态门

### 6.1 工作原理

- 三种输出状态：高电平、低电平、**高阻态（Z）**
- 高阻态：输出与内部电路断开，呈高阻抗

### 6.2 符号与真值表

```
EN ──┬── 三态门
     │
A ───┘── Y
```

| A | EN | Y |
|---|---|---|
| 0 | 1 | 0 |
| 1 | 1 | 1 |
| × | 0 | Z |

### 6.3 应用

- **总线系统**：多个设备共享一条数据线
- **数据方向控制**：双向 I/O 引脚
- **多路数据选择**：各门的使能端分时选通

> 同一时刻最多只能有一个三态门处于非高阻状态，否则总线冲突

---

## 七、传输门（TG）

- CMOS 传输门：NMOS + PMOS 并联
- 控制信号 $C$ 和 $\overline{C}$ 互补
- $C = 1$：开关导通，信号双向传输
- $C = 0$：开关断开，高阻态
- 常用于模拟开关、采样保持电路、数据选择器

---

## 总结要点

| 概念 | 要点 |
|------|------|
| TTL | BJT 实现，$V_{CC}=5V$，74LS 最经典 |
| CMOS | MOS 实现，功耗极低，74HC/74HCT 最常见 |
| OC/OD 门 | 需上拉电阻，可线与、电平转换 |
| 三态门 | 高阻态 Z，总线应用，不可同时使能多个 |
| 未用输入 | TTL 悬空视为高电平，CMOS 禁止悬空 |
