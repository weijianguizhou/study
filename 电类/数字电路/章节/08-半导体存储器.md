# 半导体存储器

## 一、存储器概述

### 1.1 存储器的层级

```
CPU 寄存器  ← 最快、最小、最贵
   ↑
 Cache（SRAM）
   ↑
 主存（DRAM）
   ↑
 SSD / HDD  ← 最慢、最大、最便宜
```

### 1.2 半导体存储器分类

```
半导体存储器
├── RAM（随机存取存储器）
│   ├── SRAM（静态 RAM）— 触发器存储
│   └── DRAM（动态 RAM）— 电容存储
└── ROM（只读存储器）
    ├── 掩模 ROM（出厂已固定）
    ├── PROM（可编程一次）
    ├── EPROM（紫外擦除）
    ├── EEPROM（电擦除，字节级）
    └── Flash（闪存，块擦除）
```

## 二、RAM——随机存取存储器

### 2.1 SRAM（静态 RAM）

**存储单元**：6 个 MOS 管构成的双稳态触发器

```
  VDD
   │
  MP1 ──┬── MP2
   │   Q │   Q̅
  MN1 ──┴── MN2
   │       │
  MN3     MN4
   │       │
  BL      BL̅
```

**特点**：
- 数据由触发器状态保持（不需要刷新）
- 速度快（ns 级）
- 集成度较低（6 个管子/位）
- 不掉电不丢失数据
- 用作 Cache、寄存器

### 2.2 DRAM（动态 RAM）

**存储单元**：1 个 MOS 管 + 1 个电容

```
  WL
   │
   ┴─→ M
       │
       C
       │
       ┴ GND
```

**特点**：
- 数据存储在电容上（电荷代表 1/0）
- 集成度高（1 个管子/位）
- **需要定时刷新**（约每 64ms 刷新一次）
- 速度较慢（几十 ns）
- 用作主存

### 2.3 SRAM vs DRAM

| 对比 | SRAM | DRAM |
|------|------|------|
| 存储单元 | 6 个 MOS | 1 个 MOS + 电容 |
| 速度 | 快（1~10ns） | 慢（50~100ns） |
| 集成度 | 低 | 高 |
| 功耗 | 较高 | 较低（但需刷新） |
| 刷新 | 不需要 | 需要 |
| 用途 | Cache | 主存 |
| 价格 | 贵 | 便宜 |

## 三、ROM——只读存储器

### 3.1 掩模 ROM

- 由制造商在芯片生产过程中写入数据
- 不能修改
- 适合批量生产

### 3.2 PROM（可编程 ROM）

- 出厂时全为 1（保险丝连接）
- 用户通过大电流烧断熔丝写入 0
- **只能写一次**

### 3.3 EPROM（可擦除 PROM）

- 用紫外线照射石英窗口擦除（15~30 分钟）
- 可重复编程
- 写入电压高于正常电压（12.5V）

### 3.4 EEPROM（电可擦除 PROM）

- 用电信号擦除（字节级）
- 可在线改写
- 擦写次数有限（约 10 万次）
- 用于存储配置参数

### 3.5 Flash（闪存）

- EEPROM 的改进型
- **块擦除**（按扇区擦除，不能按字节擦除）
- 写入速度比 EEPROM 快
- NAND Flash：高密度，用于 SSD、U 盘
- NOR Flash：随机访问快，用于代码存储

## 四、存储容量与扩展

### 4.1 容量表示

$$\text{容量} = 2^{\text{地址线数}} \times \text{数据线位数}$$

例：
- $2^{10} \times 4 = 1K \times 4 = 4Kb = 512B$
- $2^{20} \times 8 = 1M \times 8 = 8Mb = 1MB$

### 4.2 位扩展

- 多个芯片的数据线分别接不同位
- 地址线、控制线并联
- 例：两片 $1K \times 4$ → $1K \times 8$

```
            ┌─────────┐
A0~A9 ─────┤ 芯片 1   ├─ D0~D3
            │ $1K\times4$│
     ───────┤          ├─ D4~D7
            │ 芯片 2   │
            └─────────┘
```

### 4.3 字扩展

- 用片选信号 CS 选择地址范围
- 各芯片数据线并联
- 例：两片 $1K \times 8$ → $2K \times 8$

```
A10
  │
  ┌─┬─→ 芯片 1（CS）
  │ └─→ 芯片 2（CS）
  └───（通过反相器/译码器）
```

## 五、存储器时序

### 5.1 RAM 时序参数

| 参数 | 含义 |
|------|------|
| $t_{RC}$ | 读周期时间 |
| $t_{AA}$ | 地址访问时间（地址到数据有效） |
| $t_{ACS}$ | 片选访问时间 |
| $t_{OH}$ | 输出保持时间 |
| $t_{WC}$ | 写周期时间 |
| $t_{WP}$ | 写脉冲宽度 |

### 5.2 读时序

```
地址 ──┐   ┌───────────
       └───┘
         ├─ t_AA ─┤
CS ────┐   ┌─────
       └───┘
         ├─ t_ACS ─┤
数据 ──────────┐   ┌───
               └───┘
                  ← t_OH →
```

## 六、存储器的应用

### 6.1 用 ROM 实现组合逻辑

- ROM 本质是一个**地址译码器 + 存储阵列**
- 地址线 = 输入变量，数据线 = 输出函数
- 将真值表直接烧入 ROM → 实现任意组合逻辑

### 6.2 用 RAM 实现 FIFO

- 先进先出缓冲器
- 写地址指针 + 读地址指针
- 满/空标志检测

---

## 总结要点

| 类型 | 特点 | 用途 |
|------|------|------|
| SRAM | 快、贵、无需刷新 | Cache |
| DRAM | 慢、便宜、需刷新 | 主存 |
| EPROM | 紫外擦除、可多次写 | 原型开发 |
| EEPROM | 电擦除、字节级 | 配置存储 |
| Flash | 块擦除、高密度 | SSD、U 盘 |

| 概念 | 要点 |
|------|------|
| 扩展方式 | 位扩展（增字长）、字扩展（增容量） |
| ROM 实现逻辑 | 地址=输入，数据=输出，即查表 |
