# 脉冲波形产生与整形

## 一、概述

数字系统中需要各种脉冲信号：
- **时钟信号**（方波）
- **定时信号**（固定宽度的脉冲）
- **整形信号**（将不规则波形变为数字信号）

常用电路：**555 定时器**、**施密特触发器**、**单稳态触发器**、**多谐振荡器**

## 二、555 定时器

### 2.1 内部结构

```
V₊ (8) ─┬─────────────────────── V₊
         │        ┌─────┐
         │   R1   │     │
(5) V_C ─┼─┬── R2 ┤ +   │  比较器 C1
         │  │     │     │
         │  └───→ ┤ -   │
         │        └─────┘
         │        ┌─────┐
         │   R3   │     │
(2) TRIG ─┼──────┤ -   │  比较器 C2
         │  │    │     │
         │  └───→┤ +   │
         │       └─────┘
         │        ┌─────┐
(4) R̅ ──┼────────┤ R   │  SR
         │        │     ├─ Q ──┬── (3) OUT
(6) TH ──┼────────┤ S   │      │
         │        └─────┘      │
         │                    ─┴─ N-MOS
(1) GND ─┴────────(7) DIS ──── 放电管
```

- 分压电阻 $R_1 = R_2 = R_3 = 5k\Omega$
- 比较器阈值：$V_{C1(+)} = \frac{2}{3}V_{CC}$，$V_{C2(-)} = \frac{1}{3}V_{CC}$
- 引脚 4（$\overline{R}$）：复位（低电平有效）

### 2.2 引脚功能

| 引脚 | 名称 | 功能 |
|------|------|------|
| 1 | GND | 电源地 |
| 2 | TRIG | 触发输入（$< \frac{1}{3}V_{CC}$ 时触发） |
| 3 | OUT | 输出 |
| 4 | $\overline{R}$ | 复位（=0 时输出低电平） |
| 5 | V_C | 控制电压（外接电压可调节阈值） |
| 6 | TH | 阈值输入（$> \frac{2}{3}V_{CC}$ 时复位） |
| 7 | DIS | 放电端（内部 N-MOS 漏极） |
| 8 | $V_{CC}$ | 正电源（$4.5V \sim 16V$） |

## 三、555 的三种基本电路

### 3.1 单稳态触发器

**电路连接**：
```
V₊ ──┬── R ──┬── (7) DIS
     │       │
     │       └── (6) TH
     │       │
     C ──────┴── GND
     │
(2) TRIG ──── 输入（负脉冲触发）
(3) OUT ──── V₀（输出）
(4) R̅ ──── V₊
```

**时序**：
```
Vi  ──┐   ┌────────────────
      └───┘
         │
Vo  ─────────┐   ┌─────────
              └───┘
              ├─ tw ─┤
```

**脉冲宽度**：
$$t_W = RC \ln\left(\frac{V_{CC}}{V_{CC} - \frac{2}{3}V_{CC}}\right) = RC \ln 3 \approx 1.1 RC$$

**特点**：
- 输入触发脉冲（低电平，$<\frac{1}{3}V_{CC}$）
- 输出固定宽度的正脉冲
- 用于定时、延时、脉冲展宽

### 3.2 多谐振荡器（无稳态）

**电路连接**：
```
V₊ ─┬── R1 ──┬── (7) DIS
    │        │
    │        └── R2 ──┬── (6) TH
    │                 │    (2) TRIG
    │                 C
    └─────────────────┴── GND
(3) OUT ───── V₀
(4) R̅ ───── V₊
```

**输出波形**：
```
Vo  ┌──┐  ┌──┐  ┌──┐  ┌──┐
    │  │  │  │  │  │  │  │
    ┘  └──┘  └──┘  └──┘  └──
    ├─t1┤├─t2┤
```

**时间参数**：
- 充电时间（高电平）：$t_1 = (R_1 + R_2)C \ln 2 \approx 0.693(R_1 + R_2)C$
- 放电时间（低电平）：$t_2 = R_2 C \ln 2 \approx 0.693 R_2 C$
- **周期**：$T = t_1 + t_2 = 0.693(R_1 + 2R_2)C$
- **占空比**：$D = \frac{t_1}{T} = \frac{R_1 + R_2}{R_1 + 2R_2} > 50\%$

> 若需占空比 50%，可在 R2 两端并联二极管（充电路径不同）

### 3.3 施密特触发器

**电路连接**：
```
(2) TRIG ──┬── 输入
(6) TH  ───┘
(3) OUT ──── 输出
```

**滞回特性**：
```
Vo
│  ┌────────────
│  │          ↑ V₊
│  │    ┌─────┘
│  │    │
│  └────┘
│       ↓ V₋
└────────────────── Vi
```

**阈值电压**：
- 正向阈值：$V_{T+} = \frac{2}{3}V_{CC}$
- 负向阈值：$V_{T-} = \frac{1}{3}V_{CC}$
- 滞回宽度：$\Delta V_T = V_{T+} - V_{T-} = \frac{1}{3}V_{CC}$

**用途**：
- 波形整形（将正弦波、三角波变为方波）
- 噪声消除（滞回特性滤除噪声）
- 电平检测

## 四、集成施密特触发器

### 4.1 常用芯片

| 芯片 | 型号 | 说明 |
|------|------|------|
| 六反相器 | 74LS14 | 6 路施密特反相器 |
| 四与非门 | 74LS132 | 4 路施密特与非门 |
| 四或非门 | 74LS33 | 4 路施密特或非门 |

### 4.2 施密特反相器的应用

**波形整形**：
```
输入（正弦波）：
   ／＼  ／＼  ／＼
  ／    ＼／    ＼／

输出（方波）：
  ┌──┐  ┌──┐  ┌──
  │  │  │  │  │
  ┘  └──┘  └──┘
```

**RC 振荡器**（用施密特反相器）：
```
      R
 OUT ──┬──┬── IN
       │  │
       C  └── GND
```

周期：$T = RC \ln\left(\frac{V_{T+}}{V_{T-}} \cdot \frac{V_{CC}-V_{T-}}{V_{CC}-V_{T+}}\right)$

## 五、晶体振荡器

### 5.1 石英晶体特性

- **压电效应**：机械振动 ↔ 电信号
- 等效电路：$RLC$ 串联谐振 + 并联电容
- **极高 Q 值**（$10^4 \sim 10^6$）
- 频率稳定性：$10^{-5} \sim 10^{-6}$（远优于 RC 振荡器）

### 5.2 典型晶振电路

```
V₊
 │
 R ──┬── 晶振 ──┬── 输出
     │         │
     C1        C2
     │         │
     ┴         ┴
   GND       GND
```

- 通常配合反相器使用（如 74HC04）
- $C_1, C_2$ 为负载电容（影响振荡频率精度）

---

## 六、三种电路的比较

| 电路类型 | 输出 | 触发方式 | 用途 |
|----------|------|----------|------|
| **单稳态** | 固定宽度脉冲 | 外部触发 | 定时、延时、脉冲展宽 |
| **多谐振荡器** | 方波（自激） | 无需触发 | 产生时钟信号 |
| **施密特触发器** | 整形波形 | 缓慢变化的输入 | 波形整形、电平检测 |

---

## 总结要点

| 电路 | 公式 | 关键 |
|------|------|------|
| 单稳态 | $t_W \approx 1.1RC$ | 负脉冲触发，产生固定脉宽 |
| 多谐振荡器 | $T \approx 0.693(R_1+2R_2)C$ | 自激振荡，产生方波 |
| 施密特触发器 | $V_{T+}=\frac{2}{3}V_{CC}$, $V_{T-}=\frac{1}{3}V_{CC}$ | 滞回比较，整形消噪 |
| 晶振 | $f$ = 标称频率 | 高稳定度时钟源 |
