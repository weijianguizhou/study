# 可编程逻辑器件

> **综合章**：需前置 [[02-逻辑代数基础|逻辑代数]] → [[03-逻辑门电路|门电路]] → [[04-组合逻辑电路|组合逻辑]] → [[05-触发器|触发器]] → [[06-时序逻辑电路|时序逻辑]] → [[07-计数器与寄存器|计数器]] → [[08-半导体存储器|存储器]]

## 一、概述

**可编程逻辑器件**（PLD）是一种可以由用户通过编程定义其逻辑功能的半导体器件。

### 1.1 与固定逻辑器件的对比

| 对比 | 固定逻辑（74 系列） | PLD |
|------|-------------------|-----|
| 功能 | 出厂固定 | 用户可编程 |
| 集成度 | 低（每片几个门） | 高（数千~数百万门） |
| 灵活性 | 低（更换功能需换芯片） | 高（可重新编程） |
| 开发周期 | 长（PCB 改版） | 短（软件修改即可） |
| 批量成本 | 低 | 中 |

### 1.2 发展历程

```
PROM（可编程只读存储器）
    → PAL（可编程阵列逻辑）
        → GAL（通用阵列逻辑）
            → CPLD（复杂可编程逻辑器件）
                → FPGA（现场可编程门阵列）
```

## 二、简单 PLD 结构

### 2.1 基本思想

所有逻辑函数都可以表示为**与-或表达式**。

PLD 的基本结构：
```
输入  →  与阵列（乘积项） →  或阵列（求和）  →  输出
```

### 2.2 PROM

- **与阵列固定**（全译码器）
- **或阵列可编程**
- 实现 $n$ 输入 → $2^n$ 个最小项 → 任意 $m$ 个输出
- 缺点是输入增加时规模过大

### 2.3 PAL

- **与阵列可编程**
- **或阵列固定**
- 每个输出是若干个乘积项之和
- 速度快，但灵活性有限

### 2.4 GAL

- 在 PAL 基础上增加 **输出逻辑宏单元（OLMC）**
- 可配置为：组合输出、寄存器输出、输入模式
- 可擦写（电擦除，可重复编程）

## 三、CPLD

### 3.1 结构

```
      ┌─────────────────────┐
      │     全局互连         │
      │ ┌───┐ ┌───┐ ┌───┐  │
      │ │PAL│ │PAL│ │PAL│  │
      │ │块 │ │块 │ │块 │  │
      │ ├───┤ ├───┤ ├───┤  │
      │ │宏 │ │宏 │ │宏 │  │
      │ │单 │ │单 │ │单 │  │
      │ │元 │ │元 │ │元 │  │
      │ └───┘ └───┘ └───┘  │
      │ I/O │ I/O │ I/O    │
      └─────────────────────┘
```

### 3.2 特点

- 基于 **乘积项架构**（与-或阵列）
- 非易失性（掉电后配置保持）
- 时序可预测（延迟固定）
- 集成度：数百~数万逻辑单元
- 适合**中等规模**、**组合逻辑较多**的设计

### 3.3 典型厂商

| 厂商 | 系列 |
|------|------|
| Altera（Intel） | MAX 系列（MAX 7000, MAX 10） |
| Xilinx（AMD） | XC9500, CoolRunner |
| Lattice | ispMACH, MachXO |

## 四、FPGA

### 4.1 结构

```
┌─────┬─────┬─────┬─────┬─────┐
│ IOB │ IOB │ IOB │ IOB │ IOB │
├─────┼─────┼─────┼─────┼─────┤
│ IOB │ CLB │ PI  │ CLB │ IOB │
├─────┼─────┼─────┼─────┼─────┤
│ IOB │ PI  │ BRAM│ PI  │ IOB │
├─────┼─────┼─────┼─────┼─────┤
│ IOB │ CLB │ PI  │ CLB │ IOB │
├─────┼─────┼─────┼─────┼─────┤
│ IOB │ IOB │ IOB │ IOB │ IOB │
└─────┴─────┴─────┴─────┴─────┘
```

| 组件 | 说明 |
|------|------|
| **CLB**（可配置逻辑块） | 基本逻辑单元，含 LUT + 触发器 |
| **IOB**（输入输出块） | 封装引脚接口，可配置电平标准 |
| **PI**（可编程互连） | 连接各 CLB 和 IOB 的布线资源 |
| **BRAM**（块状 RAM） | 嵌入式存储器 |
| **DSP**（数字信号处理块） | 硬件乘法器、累加器 |
| **PLL/DCM**（时钟管理） | 倍频、分频、相位调整 |

### 4.2 查找表（LUT）原理

FPGA 不用与-或阵列，而用 **查找表（Look-Up Table）** 实现逻辑：

- $n$ 输入 LUT = $2^n \times 1$ 位的 SRAM 表
- 输入作为地址查表，直接输出结果
- 4 输入 LUT 可以实现任意 4 输入逻辑函数

### 4.3 特点

- **基于 SRAM**（掉电后配置丢失，需外挂配置芯片）
- 逻辑单元以 LUT + 触发器为核心
- 集成度极高（数百万~数千万门）
- **适合大规模、寄存器密集、流水线设计**
- 动态可重构（部分 FPGA 支持）

### 4.4 典型厂商

| 厂商 | 系列 |
|------|------|
| Xilinx（AMD） | Spartan（低端）、Artix（中端）、Kintex（高端）、Virtex（旗舰） |
| Altera（Intel） | Cyclone（低端）、Arria（中端）、Stratix（高端） |
| Lattice | ECP5, iCE40（低功耗） |
| Microchip（Microsemi） | PolarFire（军工、低功耗） |

## 五、CPLD vs FPGA

| 对比 | CPLD | FPGA |
|------|------|------|
| **架构** | 乘积项（与-或阵列） | LUT（查找表） |
| **集成度** | 数百~数万门 | 数千~数千万门 |
| **存储** | 非易失（FLASH/EEPROM） | SRAM（掉电丢失） |
| **时序** | 固定延迟，可预测 | 延迟取决于布线 |
| **适用** | 中等规模、组合逻辑多 | 大规模、寄存器多、流水线 |
| **功耗** | 较低 | 较高 |
| **速度** | 中等 | 高 |
| **价格** | 便宜 | 较贵 |

## 六、硬件描述语言

### 6.1 Verilog HDL

```verilog
// D 触发器示例
module dff (
    input  wire clk,
    input  wire d,
    output reg  q
);
    always @(posedge clk) begin
        q <= d;
    end
endmodule
```

### 6.2 VHDL

```vhdl
-- D 触发器示例
entity dff is
    port (
        clk : in  std_logic;
        d   : in  std_logic;
        q   : out std_logic
    );
end dff;

architecture behavioral of dff is
begin
    process(clk)
    begin
        if rising_edge(clk) then
            q <= d;
        end if;
    end process;
end behavioral;
```

### 6.3 设计流程

```
RTL 设计（Verilog/VHDL）
    ↓
功能仿真（ModelSim / VCS）
    ↓
综合（Synthesis）→ 网表
    ↓
实现（Implement）
   ├─ 布局（Place）
   └─ 布线（Route）
    ↓
时序仿真
    ↓
生成比特流 → 下载到 FPGA
```

## 总结要点

| 概念 | 要点 |
|------|------|
| PROM → PAL → GAL → CPLD → FPGA | PLD 发展历程 |
| CPLD | 乘积项架构，非易失，时序可预测 |
| FPGA | LUT 架构，SRAM 配置，高密度 |
| LUT | $n$ 输入 LUT = $2^n \times 1$ SRAM 表 |
| 设计流程 | RTL → 仿真 → 综合 → 布局布线 → 下载 |
| Verilog / VHDL | 两种主流硬件描述语言 |
