# 触发器

> **前置**：[[03-逻辑门电路|逻辑门]] → [[04-组合逻辑电路|组合逻辑]] | **后续**：[[06-时序逻辑电路|时序逻辑]] → [[07-计数器与寄存器|计数器]]

## 一、触发器概述

- **触发器**（Flip-Flop）是数字电路中最基本的**记忆单元**
- 具有两个稳定状态：**0** 和 **1**
- 在时钟（CP/CLK）控制下切换状态
- 构成寄存器、计数器、状态机的基础

### 触发器与锁存器的区别

| 对比 | 锁存器（Latch） | 触发器（Flip-Flop） |
|------|-----------------|-------------------|
| 触发方式 | 电平敏感 | 边沿触发 |
| 输出变化 | CLK 电平期间随时变化 | 仅在时钟边沿变化 |
| 抗干扰 | 较差 | 较好 |

## 二、基本 SR 锁存器

### 2.1 结构

由两个与非门（或或非门）交叉耦合构成：

```
S ──┬─ & ──┬── Q
    │      │
    │      │
R ──┼─ & ──┘
    │      │
    └──────┘── Q̅
```

### 2.2 特性表（与非门实现，低电平有效）

| $\overline{S}$ | $\overline{R}$ | Q | $\overline{Q}$ | 状态 |
|----------------|----------------|---|---|------|
| 0 | 0 | 1 | 1 | **不允许** |
| 0 | 1 | 1 | 0 | 置 1 |
| 1 | 0 | 0 | 1 | 置 0 |
| 1 | 1 | $Q_0$ | $\overline{Q_0}$ | 保持 |

> **约束条件**：$\overline{S}$ 和 $\overline{R}$ 不能同时为 0

### 2.3 或非门实现（高电平有效）

| S | R | Q | 状态 |
|---|---|---|---|
| 0 | 0 | $Q_0$ | 保持 |
| 0 | 1 | 0 | 置 0 |
| 1 | 0 | 1 | 置 1 |
| 1 | 1 | x | **不允许** |

> 约束：$SR = 0$

## 三、时钟触发器

### 3.1 电平触发的 SR 触发器

```
CP ─┬─ & ─┬─ S ──┬─ & ─┬── Q
    │     │      │    │
S ──┼─ & ─┘      │    │
    │            ├─ & ─┘
R ──┼─ & ─┬─ R ─┤    │
    │     │      └─ & ─── Q̅
    └─ & ─┘
```

- CP = 0 时：保持
- CP = 1 时：Q 随 S、R 变化

---

## 四、边沿触发器（核心）

### 4.1 D 触发器

**最常用**的触发器

**符号**：
```
    ┌────┐
  D─┤    │
    │    ├─ Q
 CP─┤>   │
    │    ├─ Q̅
  R─┤    │
    └────┘
```

**特性方程**：
$$Q_{n+1} = D$$

**真值表**：

| CP | D | $Q_{n+1}$ |
|----|---|-----------|
| ↑ | 0 | 0 |
| ↑ | 1 | 1 |

> ↑ 表示时钟上升沿触发，↓ 表示下降沿触发

### 4.2 JK 触发器

**功能最全**的触发器

**特性方程**：
$$Q_{n+1} = J\overline{Q_n} + \overline{K}Q_n$$

**真值表**：

| J | K | $Q_{n+1}$ | 模式 |
|---|---|-----------|------|
| 0 | 0 | $Q_n$ | 保持 |
| 0 | 1 | 0 | 置 0 |
| 1 | 0 | 1 | 置 1 |
| 1 | 1 | $\overline{Q_n}$ | 翻转 |

### 4.3 T 触发器

**计数器的基础**

- **T 触发器**：$Q_{n+1} = T \oplus Q_n = T\overline{Q_n} + \overline{T}Q_n$
- **T' 触发器**（T 恒为 1）：$Q_{n+1} = \overline{Q_n}$（每来一个时钟翻转一次）

**真值表**：

| T | $Q_{n+1}$ |
|---|-----------|
| 0 | $Q_n$（保持） |
| 1 | $\overline{Q_n}$（翻转） |

### 4.4 四种触发器转换

| 所需触发器 | 转换方法 |
|-----------|----------|
| **D → JK** | $D = J\overline{Q} + \overline{K}Q$ |
| **D → T** | $D = T \oplus Q$ |
| **JK → D** | $J = D, K = \overline{D}$ |
| **JK → T** | $J = T, K = T$ |

## 五、触发器的异步控制

大多数触发器具有异步输入端，优先于时钟：

| 引脚 | 含义 | 有效电平 |
|------|------|----------|
| $R_D$（CLR） | 异步清零 | 低电平 |
| $S_D$（PRE） | 异步置 1 | 低电平 |

**优先级**：
$$\text{异步端} > \text{时钟 CP} > \text{同步输入}$$

## 六、触发器的动态特性

### 6.1 时间参数

| 参数 | 含义 |
|------|------|
| $t_{su}$ | **建立时间**— 数据在时钟到来前稳定的时间 |
| $t_h$ | **保持时间**— 数据在时钟到来后保持稳定的时间 |
| $t_{pd}$ | **传输延迟**— 时钟到输出的延迟 |
| $t_W$ | **脉冲宽度**— 时钟脉冲的最小宽度 |

### 6.2 时序约束

```
      ┌───────┐
 CLK ─┤       ├────────
      │ ←t_su→│←t_h→│
 D ────┐     ┌───────
       └─────┘
```

- 建立时间违例 → 可能采到错误数据
- 保持时间违例 → 可能发生亚稳态

### 6.3 亚稳态

- 触发器输出处于 0 和 1 之间的不确定状态
- 可能持续不确定时间后才稳定
- **避免方法**：
  - 满足建立/保持时间
  - 多级同步（两级 D 触发器同步异步信号）

## 七、触发器应用示例

### 7.1 二分频电路

用 T' 触发器（或 D 触发器 $D = \overline{Q}$）：

```
CLK ──┬── CP ──→ Q 输出
      │
      └── D = Q̅
```

输入频率 $f_{CLK}$，输出频率 $f_{CLK}/2$

### 7.2 寄存器

多个 D 触发器共用时钟信号，同时存储多位数据。

### 7.3 数据同步

用两级 D 触发器同步异步输入信号：

```
异步信号 → D1 ──→ Q1 ──→ D2 ──→ Q2（同步后）
              CP ↑       CP ↑
```

## 总结要点

| 类型 | 特性方程 | 特点 |
|------|---------|------|
| **D** | $Q_{n+1} = D$ | 最常用，最简单 |
| **JK** | $Q_{n+1} = J\overline{Q} + \overline{K}Q$ | 功能最全 |
| **T** | $Q_{n+1} = T \oplus Q$ | 计数器基础 |
| **SR** | $Q_{n+1} = S + \overline{R}Q$ | 有约束 $SR=0$ |

- 触发方式：边沿触发（优于电平触发）
- 异步端：CLR（清零）、PRE（置位），优先级高于时钟
- 关键时序：建立时间 > 保持时间 > 传输延迟
