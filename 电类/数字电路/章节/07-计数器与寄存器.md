# 计数器与寄存器

## 一、计数器概述

计数器是数字系统中最常用的时序逻辑器件，用于：
- 计数（事件次数、脉冲数量）
- 分频（产生更低频率的时钟）
- 定时（产生延时）
- 地址产生（按顺序访问存储器）

### 1.1 分类

```
计数器
├── 按时钟
│   ├── 同步计数器
│   └── 异步计数器（纹波计数器）
├── 按进制
│   ├── 二进制计数器
│   ├── 十进制计数器
│   └── 任意进制计数器
├── 按方向
│   ├── 加法计数器
│   ├── 减法计数器
│   └── 可逆计数器
└── 按功能
    ├── 普通计数器
    ├── 可预置计数器
    └── 带使能计数器
```

## 二、异步计数器

### 2.1 模 2ⁿ 异步加法计数器

用 T' 触发器（$J=K=1$ 或 $D=\overline{Q}$）级联：

```
CP ──┬── CP  ───┬── CP  ───┬── CP  ───┬── CP
      │  FF0    │   FF1    │   FF2    │   FF3
      ├──>  Q0  ├──>  Q1   ├──>  Q2   ├──>  Q3
```

- 前一级输出作为后一级时钟
- 各级翻转有延迟叠加（纹波效应）

**时序图**：

```
CP   ┌┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌┐
     ─┘ └┘ └┘ └┘ └┘ └┘ └┘ └┘ └┘
Q0   ─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
      ┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └
Q1   ────┐   ┌───┐   ┌───┐   ┌───
         └───┘   └───┘   └───┘
Q2   ────────┐       ┌───────┐
             └───────┘       └───────
```

### 2.2 异步减法计数器

- 下降沿触发时，取 $Q$ 作为下级时钟
- 或取 $\overline{Q}$ 作为上升沿触发的下级时钟

### 2.3 异步计数器特点

| 优点 | 缺点 |
|------|------|
| 电路简单，级联方便 | 速度慢（纹波延迟累积） |
| 功耗低 | 存在毛刺 |
| 适合低速计数 | 不适合做高频分频 |

## 三、同步计数器

### 3.1 同步二进制加法计数器

所有触发器共用同一时钟，通过组合逻辑控制各触发器的输入：

**4 位二进制同步加法计数器**（T 触发器）：

| 位数 | T 输入 | 说明 |
|------|--------|------|
| FF0 | $T_0 = 1$ | 每来一个 CP 就翻转 |
| FF1 | $T_1 = Q_0$ | Q0=1 时翻转 |
| FF2 | $T_2 = Q_0Q_1$ | Q0=Q1=1 时翻转 |
| FF3 | $T_3 = Q_0Q_1Q_2$ | Q0=Q1=Q2=1 时翻转 |

**逻辑图**：
```
CP ──┬── CP0  CP1  CP2  CP3
      │   │    │    │    │
      │  FF0  FF1  FF2  FF3
      │   │    │    │    │
      │   Q0 ─┤    │    │
      │   │   │    │    │
      │   Q1────┤   │    │
      │   │   │   │    │    │
      │   Q2───────┤    │
      │   │   │   │   │    │
      │   Q3──────────┤
      1   &   &&  &&&
```

### 3.2 同步加减控制

- **加/减控制端 U/D**：
  - U/D = 1：加法（进位条件）
  - U/D = 0：减法（借位条件）

### 3.3 同步可预置计数器

可预置数 $D_3D_2D_1D_0$ 在 LOAD 信号有效时装入计数器

| 功能 | 信号 | 操作 |
|------|------|------|
| 异步清零 | CLR = 0 | 立即清零（优先级最高） |
| 同步置数 | LOAD = 0 | CP 有效时将 D 装入 |
| 计数 | LOAD = 1, EN = 1 | 每来 CP 计数一次 |
| 保持 | EN = 0 | 状态不变 |

## 四、常用计数器芯片

### 4.1 74LS161（4 位二进制同步计数器）

| 引脚 | 功能 |
|------|------|
| CLR | 异步清零（低电平） |
| LOAD | 同步置数（低电平） |
| ENP, ENT | 计数使能（高电平有效） |
| $D_3 \sim D_0$ | 预置数据输入 |
| $Q_3 \sim Q_0$ | 计数值输出 |
| RCO | 进位输出（计数到 1111 时有效） |

### 4.2 74LS160（十进制同步计数器）

- 与 74LS161 引脚完全兼容
- 计数到 1001（9）后返回 0000 并产生进位
- 用于十进制计数

### 4.3 74LS193（4 位二进制可逆计数器）

- 独立加法时钟 CPU 和减法时钟 CPD
- 异步清零 CLR
- 异步置数 LOAD

### 4.4 74LS290（异步十进制计数器）

- 内置模 2 和模 5 两部分
- 模 2 + 模 5 级联 = 十进制计数器
- 异步清零和置 9

## 五、任意进制计数器设计

### 5.1 清零法（复位法）

利用计数器的清零端，在计数到 $N$ 时强制清零。

**设计 N 进制计数器**：
1. 对 $N$ 进制计数：计数到 $N$ 时清零
2. 检测 $N$ 对应的输出状态
3. 将该状态译码产生清零信号

示例：用 74LS161 构成 6 进制计数器（计数 0~5）：

```
Q3 Q2 Q1 Q0
0  1  1  0  =  6（检测到 6 时清零）
```

将 $Q_2$ 和 $Q_1$ 与非后接 CLR

### 5.2 置数法

利用计数器的置数端，在计数到某值时装入预设值。

**第 1 种置数方式**（预置 0）：
- 计数到 $N-1$ 时置数，装入 0
- 6 进制：计数到 5 时置数 0

**第 2 种置数方式**（预置初值）：
- 计数器从初值 $M$ 计数到最大数（1111）
- 产生 LOAD 信号，装入 $M$

### 5.3 清零法 vs 置数法

| 方法 | 优点 | 缺点 |
|------|------|------|
| **清零法** | 简单 | 有短暂毛刺（异步清零） |
| **置数法**（同步） | 无毛刺 | 电路稍复杂 |
| **置数法**（异步） | 简单 | 也有毛刺 |

## 六、寄存器

### 6.1 基本寄存器

- 多个 D 触发器共用时钟，同时存储多位数据
- 74LS175：4D 寄存器（带公共时钟和公共清零）

### 6.2 移位寄存器

**原理**：每个时钟将数据右移或左移 1 位

```
数据输入 → FF0(D) → Q0 → FF1(D) → Q1 → FF2(D) → Q2 → FF3(D) → Q3
                   └──→ 串行输出
```

**74LS194**：4 位双向移位寄存器

| S1 | S0 | 功能 |
|----|----|------|
| 0 | 0 | 保持 |
| 0 | 1 | 右移 |
| 1 | 0 | 左移 |
| 1 | 1 | 并行置数 |

### 6.3 移位寄存器的应用

| 应用 | 原理 |
|------|------|
| **串并转换** | 串行输入 $n$ 个时钟后，并行输出 |
| **并串转换** | 并行置数后，串行移位输出 |
| **环形计数器** | 输出反馈到输入，循环移位一个 1 |
| **扭环计数器** | 反相后反馈，产生 2n 个状态 |
| **序列发生器** | 移位寄存器 + 组合逻辑产生指定序列 |

### 6.4 环形计数器

```
Q0 ─┬─ D1 ──→ Q1 ──┬─ D2 ──→ Q2 ──┬─ D3 ──→ Q3 ──┬─ D0 ──→ Q0
    │               │               │               │
    └───────────────┴───────────────┴───────────────┘
```

**初始值**：1000（一个 1，其余为 0）

**状态序列**：$1000 \to 0100 \to 0010 \to 0001 \to 1000$

**特点**：
- 状态数 = 触发器数量（$n$ 个触发器用 $n$ 个有效状态）
- 不需要额外的译码电路（每个状态输出就是 1 位）
- 利用率低

## 七、计数器应用：分频

### 7.1 分频比

- 模 $N$ 计数器的进位/借位输出频率为输入频率的 $1/N$
- $n$ 位二进制计数器最高位输出 $f_{out} = f_{CLK} / 2^n$

### 7.2 任意分频

- 整数分频：用任意进制计数器实现
- 奇数分频：用计数器 + 组合逻辑实现占空比 50%

## 总结要点

| 芯片 | 类型 | 特点 |
|------|------|------|
| 74LS160 | 十进制同步计数器 | 同步置数，异步清零 |
| 74LS161 | 4 位二进制同步计数器 | 最常用 |
| 74LS163 | 4 位二进制同步计数器 | 同步清零 |
| 74LS193 | 可逆计数器 | 双时钟 |
| 74LS194 | 移位寄存器 | 双向，并行置数 |

- 任意进制：**清零法**（异步，有毛刺）或**置数法**（同步，无毛刺）
- 移位寄存器：串/并转换、环形计数器、序列发生器
