# 1.放大电路的构成
放大电路用于放大微弱信号，输出端得到幅度增大、能量加强的信号。
![[放大电路的构成.jpg]]
放大的本质是**能量的控制和转换**。输出信号的能量是由直流电源提供的。而控制能量的元器件就是我们前面学习的晶体三极管和场效应管。

# 放大电路的组成原则
对于三极管放大电路，首先电源电压的设置要使得三极管**发射结正偏，集电结反偏**，保证晶体三极管工作在放大区

下图，三极管作为放大器件；电源VBB和RB保证发射结能正偏；$V_{CC}$和$R_{c}$保证集电结处于反偏![[3c1f58a08fe10f9d9c11d8399f26988c.png]]
如果换成PNP管，那么电源VBB和VCC的的极性需要取反哦

其次，元件的安排要保证信号的有效传输，也就是输入信号必须能够作用在放大管的输入回路上，同时当负载接入时，必须保证放大管输出回路的动态电流能够用于负载上。

![[e2a7792c7e7908f36432d202c63b0f77.jpg]]上图信号传输过程可以看出放大电路中直流量和交流量同时作用，但由于电容等电抗元件的存在，直流量所流经的通路和信号所流经的通路不完全相同，为了研究方便，将它们的作用区分出来，于是有了直流通路和交流通路

# 直流通路交流通路
**直流通路**是在直流电源作用下直流电流流经的通路
1. 信号源视为短路

2. 电容视为开路

3. 电感线圈视为短路

**交流通路**是输入信号作用下交流信号流经的通路
1. 直流电源视为短路

2. 容量大的电容(如耦合电容)视为短路

在分析放大电路时，要遵循“**先静态，后动态**”的原则，

**求解静态工作点时利用直流通路**

**求解动态参数时利用交流通路**

两种通路不可混淆哦~~~
