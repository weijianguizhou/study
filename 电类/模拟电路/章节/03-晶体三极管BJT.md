# 晶体三极管（BJT）

## 一、结构与符号

### 1.1 物理结构

BJT 由三层半导体构成，分为两个类型：

```
NPN:     N — P — N      PNP:     P — N — P
        e    b    c               e    b    c
```

- **发射区**（e）：重掺杂，提供载流子
- **基区**（b）：很薄，轻掺杂
- **集电区**（c）：面积最大，收集载流子

### 1.2 符号与电流方向

```
NPN:    c           PNP:    c
        │                   │
        │                   │
   b ───┼───           b ───┼───
        │                   │
        e                   e
   i_C: 从 c→e          i_C: 从 e→c
   i_B: 从 b→e          i_B: 从 e→b
```

---

## 二、放大原理（以 NPN 为例）

### 2.1 外部偏置条件

- 发射结 **正偏**：$V_{BE} > 0$（Si 约 0.7V）
- 集电结 **反偏**：$V_{CE} > V_{BE}$

### 2.2 内部载流子运动

```
发射区发射电子 → 基区扩散（小部分复合形成 i_B）
                                 ↘ 大部分被集电区收集形成 i_C
```

- $i_E = i_B + i_C$
- **共基电流传输系数**：$\bar\alpha = \frac{i_C}{i_E} \approx 0.98 \sim 0.999$
- **共射电流放大系数**：$\bar\beta = \frac{\bar\alpha}{1 - \bar\alpha} = \frac{i_C}{i_B}$

$$i_C = \beta i_B$$
$$i_E = (1 + \beta)i_B$$

---

## 三、特性曲线

### 3.1 输入特性

$$v_{BE} = f(i_B) \big|_{v_{CE} = \text{常数}}$$

- 类似二极管伏安特性
- $V_{CE}$ 增大时曲线略右移（基区宽度调制效应）

### 3.2 输出特性

$$i_C = f(v_{CE}) \big|_{i_B = \text{常数}}$$

分为三个区：

| 区域 | 条件 | 特点 |
|------|------|------|
| **截止区** | $i_B = 0$ | $i_C \approx 0$，类似开路 |
| **放大区** | $v_{CE} > 0.3V$ | $i_C = \beta i_B$，恒流特性 |
| **饱和区** | $v_{CE} < 0.3V$ | $i_C \not\propto i_B$，类似短路 |

---

## 四、三种工作状态

| 状态 | 发射结 | 集电结 | $i_C$ | 用途 |
|------|--------|--------|-------|------|
| **放大** | 正偏 | 反偏 | $\beta i_B$ | 模拟放大 |
| **饱和** | 正偏 | 正偏 | $\approx V_{CC}/R_C$ | 数字电路"导通" |
| **截止** | 反偏 | 反偏 | $\approx 0$ | 数字电路"断开" |

---

## 五、静态工作点（Q 点）

### 5.1 为什么要设置 Q 点

- 使 BJT 在放大区工作
- 避免信号失真（截止失真 / 饱和失真）

### 5.2 典型偏置电路：分压式偏置

```
+ VCC
  │
  R1 ─┬─ R_C
      │   │
      b   c
      e
      │   │
  R2 ─┴─ R_E
              ┴ GND
```

$$V_B \approx V_{CC} \frac{R_2}{R_1 + R_2}$$
$$V_E = V_B - V_{BE}$$
$$I_E = \frac{V_E}{R_E} \approx I_C$$
$$V_{CE} = V_{CC} - I_C(R_C + R_E)$$

### 5.3 温度稳定性

分压式偏置通过 $R_E$ 引入直流负反馈稳定 Q 点：

$$T \uparrow \to I_C \uparrow \to V_E \uparrow \to V_{BE} \downarrow \to I_B \downarrow \to I_C \downarrow$$

## 六、BJT 小信号模型

### 6.1 h 参数等效模型

$$\begin{cases}
v_{be} = h_{ie} i_b + h_{re} v_{ce} \\
i_c = h_{fe} i_b + h_{oe} v_{ce}
\end{cases}$$

### 6.2 简化模型（忽略 $h_{re}, h_{oe}$）

```
  b ──┬─── r_be ──┬─── c
      │           │
      i_b         β i_b
      │           │
  e ──┴───────────┴─── e
```

### 6.3 参数估算

$$r_{be} = r_{bb'} + (1 + \beta) \frac{26\,\mathrm{mV}}{I_{EQ}}$$

- $r_{bb'}$：基区体电阻（约 100~300Ω）
- $\frac{26\,\mathrm{mV}}{I_{EQ}}$：发射结小信号电阻（室温）

---

## 七、BJT 的高频特性

### 7.1 高频等效电路

- 考虑结电容：$C_{b'e}$（发射结扩散电容）、$C_{b'c}$（集电结势垒电容）
- **密勒效应**：$C_{b'c}$ 等效到输入端为 $(1 - A_v)C_{b'c}$

### 7.2 特征频率 $f_T$

- $\beta$ 下降到 1 时的频率
- $$f_T \approx \frac{g_m}{2\pi(C_{b'e} + C_{b'c})}$$

### 7.3 高频管与低频管

| 类型 | $f_T$ | 应用 |
|------|-------|------|
| 低频管 | 几 MHz | 音频、一般放大 |
| 高频管 | 几百 MHz~GHz | 射频通信 |

---

## 总结要点

| 概念 | 要点 |
|------|------|
| 放大条件 | 发射结正偏，集电结反偏 |
| 三极管电流关系 | $i_E = i_B + i_C$, $i_C = \beta i_B$ |
| 三种状态 | 放大、饱和、截止 |
| Q 点稳定 | 分压式偏置 + 发射极电阻 |
| $r_{be}$ | $r_{bb'} + (1+\beta)\frac{26mV}{I_{EQ}}$ |
| 高频限制 | 结电容、密勒效应、$f_T$ |
