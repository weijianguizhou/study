# 二极管及其应用

## 一、二极管的结构与符号

- **结构**：PN 结 + 两个电极（阳极 P、阴极 N）
- **符号**：▷|（箭头方向为正向电流方向）
- **封装**：玻璃管、塑料、金属壳等

---

## 二、二极管的伏安特性

### 2.1 特性曲线

```
I
│
│  正向区
│  /   (导通后近似线性)
│ /
└───────────→ V
 │    ┌ V_{th}
 │    └─ 死区电压
 │ 反向区 (几乎为 0)
 │
 └ 反向击穿区
```

### 2.2 几个关键参数

| 参数 | 含义 |
|------|------|
| $V_F$ | 正向导通压降（Si 约 0.7V） |
| $I_F$ | 最大正向电流 |
| $V_R$ | 最大反向工作电压（峰值） |
| $I_R$ | 反向漏电流 |
| $t_{rr}$ | 反向恢复时间 |

## 三、二极管的等效模型

| 模型 | 图示 | 适用场景 |
|------|------|----------|
| **理想模型** | 正偏短路，反偏开路 | 开关电路分析 |
| **恒压降模型** | 正偏 $V_F$（0.7V），反偏开路 | 直流近似分析 |
| **折线模型** | 正偏 $V_{th} + r_D \cdot i$ | 大信号分析 |
| **小信号模型** | $r_d = \frac{V_T}{I_{DQ}}$ | 交流小信号分析 |

小信号电阻：$r_d = \frac{dV}{dI} = \frac{V_T}{I_{DQ}}$

## 四、整流电路

### 4.1 半波整流

```
输入 ~  →  D  →  R_L  →  输出（脉动直流）
```
- 只利用交流电的一半周期
- 输出脉动大，效率低
- 平均电压 $V_{avg} = \frac{V_m}{\pi} \approx 0.318 V_m$

### 4.2 全波桥式整流

```
输入 ~      D1 ─┬─ D2
              │   │
             R_L  │
              │   │
         D3 ─┴─ D4
```

- 正负半周均导通
- 平均电压 $V_{avg} = \frac{2V_m}{\pi} \approx 0.637 V_m$
- 纹波频率为输入频率的 2 倍

### 4.3 整流后加滤波电容

- 电容充电快、放电慢 → 输出电压平滑
- 空载时 $V_{out} \approx \sqrt{2} V_{rms}$
- 带载时 $V_{out} \approx 1.2 V_{rms}$（经验值）

## 五、稳压电路（稳压管）

### 5.1 稳压管的工作原理

- 工作在**反向击穿区**
- 击穿后电流变化很大，但电压几乎不变 → **稳压**
- 需要串联限流电阻 $R$，防止电流过大烧毁

### 5.2 基本稳压电路

$$V_{out} = V_Z \quad (I_Z \leq I \leq I_{ZM})$$

选择限流电阻 $R$：
$$R = \frac{V_{in} - V_Z}{I_Z + I_L}$$

### 5.3 稳压管参数

| 参数 | 含义 |
|------|------|
| $V_Z$ | 稳定电压 |
| $I_{Zmin}$ | 最小稳定电流 |
| $I_{Zmax}$ | 最大稳定电流 |
| $r_Z$ | 动态电阻（越小越好） |
| $P_Z$ | 最大耗散功率 |

## 六、其他类型二极管

| 类型 | 特点 | 典型应用 |
|------|------|----------|
| **肖特基二极管** | 金属-半导体结，$V_F$ 低（0.3V），开关快 | 高频整流、DC-DC |
| **发光二极管（LED）** | 正向电致发光，$V_F \approx 1.8 \sim 3.3V$ | 指示灯、照明 |
| **光电二极管** | 反偏时光照产生光电流 | 光探测器 |
| **变容二极管** | 利用势垒电容随电压变化的特性 | 压控振荡器 VCO |
| **TVS 二极管** | 瞬态电压抑制，响应快 | 电路保护 |

---

## 七、二极管的应用实例

### 7.1 限幅电路

- 将信号电压限制在某个范围内
- 串联限幅 / 并联限幅

### 7.2 钳位电路

- 将信号的直流电平移动到某一固定值
- 由二极管 + 电容 + 电阻组成

### 7.3 续流二极管

- 并联在电感负载两端
- 在开关关断时为电感电流提供通路，防止高压感应击穿

---

## 总结要点

| 场景 | 关键点 |
|------|--------|
| 整流 | 桥式最常用，加滤波电容平滑输出 |
| 稳压 | 稳压管必须串联限流电阻 |
| 开关 | 注意反向恢复时间，高速选肖特基 |
| 保护 | 续流二极管保护感性负载 |
