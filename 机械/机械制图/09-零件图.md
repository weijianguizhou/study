# 第九章 零件图

## 9.1 零件图概述

零件是组成机器的最小单元。零件图是表达单个零件结构形状、尺寸大小和技术要求的图样，是制造和检验零件的依据。

一张完整的零件图应包含以下四方面内容：

| 内容   | 说明                                                                   |                                          |
| ---- | -------------------------------------------------------------------- | ---------------------------------------- |
| 一组视图 | 运用[[07-机件表达方法                                                        | 第七章]]所学的视图、剖视图、断面图等方法，完整、清晰地表达零件的内外部结构形状 |
| 完整尺寸 | 正确、完整、清晰、合理地标注出制造和检验零件所需的全部尺寸                                        |                                          |
| 技术要求 | 用规定的符号、数字或文字说明零件在制造和检验时应达到的质量要求，如表面粗糙度、尺寸公差、几何公差、热处理等（详见[[10-零件图技术要求 | 第十章]]）                                   |
| 标题栏  | 位于图框右下角，填写零件名称、材料、数量、比例、图号、设计者等信息                                    |                                          |

零件图与装配图的关系：零件图是装配图的基础，装配图是零件图的依据。零件图中的配合尺寸、相互位置关系必须与装配图一致。

## 9.2 零件图的视图选择

视图选择的核心目标：用最少数量的视图，将零件内外结构形状完整、清晰地表达出来。

### 主视图的选择原则

1. **反映零件的结构形状特征**——主视图应最能显示零件各组成部分的形状和相对位置
2. **反映零件的工作位置或加工位置**——尽量符合零件在机器中的工作状态或主要加工工序的装夹姿态

| 零件类型 | 主视图放置原则 | 示例 |
|----------|---------------|------|
| 轴类零件 | 轴线水平放置（符合车削加工位置） | 传动轴、阶梯轴 |
| 轮盘类零件 | 轴线水平放置（符合车削加工位置） | 齿轮、皮带轮、法兰盘 |
| 箱体类零件 | 按工作位置放置 | 齿轮箱、泵体、阀体 |
| 叉架类零件 | 按工作位置放置，常需倾斜表达 | 拨叉、连杆、支架 |

### 其他视图的确定

在确定主视图后，按以下步骤逐一检查是否需要补充视图：
- 主视图中未表达清楚的内腔结构 → 加剖视图
- 局部细小结构 → 加局部放大图
- 倾斜结构 → 加斜视图
- 轴上的键槽、销孔 → 加断面图
- 对称零件 → 可用半剖视图节省视图数量

基本原则：**在完整表达零件结构的前提下，视图数量应最少。**

几种视图组合方案示例：

| 方案 | 适用情况 |
|------|----------|
| 主视图 + 俯视图（或左视图） | 结构简单的块状零件 |
| 全剖主视图 + 左视图 | 轮盘类、端盖类 |
| 半剖主视图 + 全剖左/俯视图 | 对称箱体 |
| 主视图 + 局部剖 + 断面图 | 轴类零件 |
| 主视图 + 斜视图 + 局部剖 | 叉架类零件 |

## 9.3 典型零件的表达方法

机械零件按结构特点可分为四类典型零件，各有推荐的表达方案。

### 9.3.1 轴套类零件

轴套类零件的主体由共轴回转体组成，主要在车床上加工。

| 推荐表达方案 | 说明 |
|-------------|------|
| 主视图 | 轴线水平放置，以符合加工位置；键槽朝上或朝前 |
| 断面图 | 在键槽、销孔等位置作移出断面，表达截面形状和深度 |
| 局部放大图 | 退刀槽、越程槽等细小结构用局部放大图表达 |
| 局部剖视图 | 表达内部油孔、中心孔等 |

轴类零件通常一个基本视图即可表达主体形状，配合若干个断面图和局部放大图构成完整表达。

### 9.3.2 轮盘类零件

轮盘类零件包括皮带轮、齿轮、法兰盘、端盖等，主体为回转体，轴向尺寸较短。

| 推荐表达方案 | 说明 |
|-------------|------|
| 全剖主视图 | 轴线水平放置，表达轮毂、轮缘、腹板及键槽孔的轴向分布 |
| 左视图 | 表达轮辐数量、减轻孔分布、安装孔周向位置等 |
| 局部剖 | 若轮辐非对称或需表达局部结构时补充使用 |

轮辋（辐板）上的孔常按"旋转剖"或"简化画法"处理，即按圆周均布绘制，不论实际角度。

### 9.3.3 叉架类零件

叉架类零件如拨叉、连杆、支架，结构由工作部分、连接部分和支撑部分组成，常含倾斜结构。

| 推荐表达方案 | 说明 |
|-------------|------|
| 主视图 | 按工作位置放置，反映主要结构形状 |
| 斜视图 | 表达倾斜臂的实形 |
| 局部剖视图 | 表达油孔、销孔等内部结构 |
| 断面图 | 表达连接臂的截面形状（工字形、矩形等） |

叉架类零件是最不规则的典型零件，视图数量往往较多，需灵活运用各类表达方法。

### 9.3.4 箱体类零件

箱体类零件如齿轮箱、泵体、阀体、缸体，结构最为复杂，内外形状均不规则。

| 推荐表达方案 | 说明 |
|-------------|------|
| 主视图（剖视） | 按工作位置放置，多用全剖或局部剖表达内部型腔 |
| 俯视图/仰视图（剖视） | 表达上下方向的内部结构及安装面 |
| 左视图/右视图 | 表达侧面结构及各油口、安装孔布置 |
| 局部剖视 | 表达局部壁厚、孔内结构 |
| 局部放大图 | 表达铸造圆角、小油孔等 |

箱体类零件通常需要三个或更多基本视图，且多数采用剖视画法。读图和绘图时应灵活使用 [[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]] 中的三维模型辅助理解复杂内腔。

### 四类典型零件表达方法汇总

| 零件类型 | 主视图 | 常用配图 | 视图数量 | 特点 |
|----------|--------|----------|----------|------|
| 轴套类 | 轴线水平 | 断面图、局部放大图 | 1个基本视图 + 若干辅助 | 结构简单，切削加工为主 |
| 轮盘类 | 轴线水平（全剖） | 左视图 | 2个基本视图 | 回转体，轴向短 |
| 叉架类 | 工作位置 | 斜视图、局部剖、断面图 | 2~3个基本视图 + 辅助 | 不规则，含倾斜结构 |
| 箱体类 | 工作位置（剖视） | 俯/仰/左/右视图（剖视） | 3个及以上基本视图 | 结构复杂，内外均不规则 |

## 9.4 零件图上的尺寸标注

[[07-机件表达方法|第七章]]已介绍了组合体尺寸标注的基本方法（定形尺寸、定位尺寸、总体尺寸），本章重点解决尺寸标注的**合理性**问题——即尺寸标注如何满足设计与工艺要求。

### 9.4.1 尺寸基准

尺寸基准是标注尺寸的起点。合理的尺寸标注必须以选定的基准为依据。

| 基准类型 | 定义 | 示例 |
|----------|------|------|
| 设计基准 | 确定零件在部件中位置的面、线或点 | 轴的轴线、箱体底面安装面 |
| 工艺基准 | 加工和测量时使用的面、线或点 | 车削时的轴端面、铣削时的定位面 |

**基准重合原则**：尽可能使设计基准与工艺基准统一，以减少加工误差。

### 9.4.2 常见零件的基准选择

- **轴类零件**：径向基准——轴线；轴向基准——重要轴肩端面（安装轴承或齿轮的定位端面）
- **箱体类零件**：高度方向——底面（安装面）；宽度方向——对称中心面；长度方向——重要孔的轴线或端面
- **轮盘类零件**：径向基准——轴线；轴向基准——与轴装配的定位端面
- **叉架类零件**：高度方向——安装底面或主要孔的轴线；长度和宽度方向——对称面或安装面

### 9.4.3 尺寸标注的注意事项

**（1）重要尺寸直接注出**

凡影响产品性能、装配精度和零件互换性的尺寸，必须从设计基准直接注出，不得由其他尺寸间接推算。

**（2）避免注成封闭尺寸链**

封闭尺寸链中每个尺寸的误差会积累，导致精度无法保证。正确的做法是：选择一个次要尺寸不注（开口环），或将次要尺寸加括号作参考尺寸。

```
封闭尺寸链（错误）：A ── B ── C，且标注 A + B + C = 总长
开口尺寸链（正确）：A + B + (C) = 总长，C不注或加括号
```

**（3）考虑加工和测量方便**

尺寸标注应符合加工顺序。例如轴类零件先车外圆后铣键槽，键槽位置应从轴肩端面注起而非从轴端注起。

**（4）配合尺寸标注要对应**

轴和孔有配合关系的尺寸，应标注在对应的基准上。例如轴上装轴承的轴颈直径与箱体轴承孔直径均以公称尺寸 $d$ 标注，基准各自独立但在装配图中形成配合。

## 9.5 常见零件工艺结构

零件上一些结构并非出于功能需要，而是为了满足制造工艺要求。制图时必须按国家标准规定正确表达这些工艺结构。

### 9.5.1 铸造工艺结构

**铸造圆角**

为防止铸件在冷却收缩时尖角处产生裂纹（应力集中），以及防止铸型尖角处掉砂，铸件各表面相交处应制成圆角。铸造圆角半径一般取 $R3 \sim R5$。铸造圆角在图上必须画出。

**拔模斜度**

为便于从铸型中起模，铸件沿拔模方向的表面应设拔模斜度。拔模斜度一般为 $1:20 \sim 1:100$（约 $1° \sim 3°$）。拔模斜度通常不注，可在技术要求中统一说明；若不需机械加工也可不画，标注 "拔模斜度 $1:50$"。

### 9.5.2 机械加工工艺结构

**倒角**

轴端和孔口加工出的小锥面称为倒角，作用是便于装配、保护螺纹和保护操作者安全。

```
  倒角标注示例：
  
  ┌─────────┐
  │         │ 标注 C1 表示 1×45° 倒角
  │ 轴      │ (轴向倒角量 = 1mm，角度 = 45°)
  │         │
  └───\─────┘
    C1  ↑
        倒角面
```

**退刀槽和越程槽**

车削螺纹或阶梯面时，为便于车刀退出常在轴肩处车出一圈槽——退刀槽；磨削时为便于砂轮越过加工面——越程槽。

```
  退刀槽画法与标注：
  
  ┌──────────┐   ┌─退刀槽
  │  退刀槽  │   │  槽宽 × 槽底直径
  │  2×Φ18  │   │  标注: 2×Φ18
  └────\───/─┘   │  或 槽宽×槽深: 2×1
    ↑         ↑
    退刀槽   标注
```

**钻孔结构**

用钻头钻孔时，孔的末端会留有钻头锥顶的自然角度（钻头顶角 $118°$）。在图上钻孔末端应画 $120°$ 锥角（简化规定）。

```
  钻孔结构画法：
  
  钻孔 (通孔):          钻孔 (盲孔):
  ┌──┐  ┌──┐           ┌──┐
  │  │  │  │           │  │
  │  │  │  │           │  │
  └──┘  └──┘           └──\──┘
      ↑  ↑                  ↑
   用钻头钻通          孔底120°锥角
  
  标注: 4×Φ10 通孔      标注: 4×Φ10 深20 孔深25
```

**凸台和凹坑**

零件与其他表面配合的接触面，一般只加工局部面积，其余部分铸出或作凹入处理。凸台和凹坑的作用是减少加工面积，保证接触良好。

### 9.5.3 常见工艺结构汇总

| 结构名称 | 用途 | 画法规定 | 标注方法 |
|----------|------|----------|----------|
| 铸造圆角 | 防止应力集中和掉砂 | 必须画出圆角，半径 R3~R5 | 在图样右上角注"未注铸造圆角 R3~R5" |
| 拔模斜度 | 便于从铸型中取出 | 可不画，或画 1:50 斜度 | 技术要求中注"拔模斜度 1:50" |
| 倒角 | 便于装配，保护螺纹 | C1/C2 表示 1×45° 或 2×45° | $C1$、$C2$，或写 $1 \times 45°$ |
| 退刀槽 | 便于车刀退出 | 槽口放大部分画法 | $2 \times \phi 18$ 或 $2 \times 1$ |
| 越程槽 | 便于砂轮越程 | 槽口放大部分画法 | 标注槽宽 × 槽底直径或槽宽 × 槽深 |
| 钻孔锥底 | 钻头顶角 118° 自然形成 | 画 120° 锥角 | $4 \times \phi 10$ 通孔；盲孔加深度 |
| 凸台 | 减少加工面积 | 凸起部分用轮廓线画 | 标注凸台加工面尺寸及粗糙度 |
| 凹坑 | 保证接触面贴合 | 凹入部分用轮廓线画 | 标注凹坑尺寸 |

## 9.6 读零件图的方法与步骤

### 9.6.1 读零件图的一般步骤

| 步骤 | 内容 | 目的 |
|------|------|------|
| ① 看标题栏 | 了解零件名称、材料、数量、比例 | 对零件有一个概括认识，判断零件类型 |
| ② 分析视图 | 找出主视图，弄清各视图的表达方法和剖切位置 | 理解各视图的投影关系和表达意图 |
| ③ 想象形状 | 运用形体分析法，分部分、想形状、合整体 | 在脑海中建立零件的三维形状 |
| ④ 分析尺寸 | 找出各方向尺寸基准，区分定形、定位、总体尺寸 | 理解零件的具体大小和尺寸关系 |
| ⑤ 了解技术要求 | 查看表面粗糙度代号、尺寸公差、几何公差、热处理要求 | 理解零件的制造质量要求（详见[[10-零件图技术要求|第十章]]） |

建议结合 [[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]] 对复杂零件（尤其是箱体类）进行三维建模，通过旋转观察帮助理解多视图投影关系。

### 9.6.2 读图示例一：传动轴

**① 看标题栏**

标题栏标明：零件名称——传动轴，材料——45钢，比例1:1。判断为轴套类零件。

**② 分析视图**

视图组成：主视图（轴线水平）+ 两个移出断面图（键槽处）+ 局部放大图（退刀槽处）。主视图上有局部剖表达中心孔。

**③ 想象形状**

运用形体分析法分解传动轴：
- 左端：$\phi 30$ 轴段，有键槽（通过断面图确认槽宽×槽深）
- 中左：$\phi 35$ 轴肩，装轴承定位面
- 中段：$\phi 40$ 轴段，装齿轮
- 中右：$\phi 35$ 轴肩，对称布置
- 右端：$\phi 30$ 轴段，有键槽

综合起来为一根阶梯轴，轴向由五个圆柱段组成，两端各有键槽。

**④ 分析尺寸**

- 径向基准：轴线
- 轴向基准：中间 $\phi 40$ 段的左端面（安装齿轮的定位面）
- 各轴段直径尺寸：从直径基准 $\phi 40$ 往两端递减
- 长度尺寸：从轴向基准出发注出各段长度
- 键槽尺寸：从轴肩端面标定键槽的轴向位置

**⑤ 了解技术要求**

表面需调质处理 HB220~250；轴颈 $\phi 35$ 处表面粗糙度 $Ra\ 1.6$；键槽宽有尺寸公差（见[[10-零件图技术要求|第十章]]）。

### 9.6.3 读图示例二：泵体

**① 看标题栏**

零件名称——泵体，材料——HT200（灰铸铁），比例 1:2。判断为箱体类零件。

**② 分析视图**

采用四个视图：全剖主视图（过泵腔和进出油口剖切）、全剖俯视图（过轴承孔轴线剖切）、左视图（局部剖表达安装孔）、局部放大图（表达油封槽）。

**③ 想象形状**

泵体结构分为五部分：
- 泵腔部分：中部空腔，容纳齿轮
- 进出油口：管螺纹接口，位于泵腔两侧
- 轴承孔部分：左右各一，安装轴承
- 安装底板：底面，有四个螺栓安装孔
- 油封及端盖安装面：两侧法兰面

泵体外部形状为方体+圆柱体组合，内部有泵腔、油道和轴承孔。

**④ 分析尺寸**

- 高度方向基准：底面安装面
- 宽度方向基准：前后对称面
- 长度方向基准：左右对称面
- 安装尺寸：底板上四个螺栓孔间距和孔径
- 配合尺寸：轴承孔 $\phi 62H7$、齿轮轴孔 $\phi 30H7$
- 总体尺寸：长×宽×高

**⑤ 了解技术要求**

铸件不得有气孔、缩松等缺陷；未注铸造圆角 $R3$；轴承孔内表面 $Ra\ 0.8$；轴承孔有圆柱度要求。

## 总结

本章系统讲解了零件图的完整知识体系：

1. 零件图的四项基本内容：视图、尺寸、技术要求、标题栏
2. 主视图选择的两大原则：加工/工作位置、结构特征
3. 四类典型零件各有推荐的表达方案，应熟练运用
4. 尺寸标注的核心是基准选择，遵循基准重合原则，避免封闭尺寸链
5. 工艺结构（铸造圆角、倒角、退刀槽、钻孔锥底等）必须按国标规定画法和标注
6. 读零件图的五步法：标题栏 → 视图分析 → 想象形状 → 尺寸分析 → 技术要求
