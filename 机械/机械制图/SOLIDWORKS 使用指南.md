# 一、 核心概念与工作流

在正式动笔（动鼠标）之前，必须理解SOLIDWORKS的**参数化建模**逻辑：

- **基于特征**：三维模型是由一个个独立的功能（如拉伸、切除、圆角）叠加而成的。
    
- **全约束草图**：在把2D变3D之前，必须通过尺寸和几何关系让草图完全确定。
    
- **单一数据源**：零件、装配体、工程图三者互相关联。修改零件，装配体和工程图会自动更新。
    

# 二、 基础操作三步走（核心教学）

### 第一步：新建文件与界面认识

1. 打开软件，点击 **新建**（Ctrl + N），选择 **零件 (Part)**。
    
2. **认识界面**：
    
    - **特征经理设计树（左侧）**：记录你所有的建模步骤（历史记录）。
        
    - **控制面板/功能区（顶部）**：工具栏，最常用的是“草图”和“特征”标签页。
        
    - **前视/上视/右视基准面**：虚拟的画板，所有建模都从这三个面之一开始。
        

### 第二步：2D草图绘制（建模的基石）

1. **选择基准面**：在左侧设计树单击“上视基准面”，在弹出的快捷菜单中点击 **草图绘制**。
    
2. **绘制几何图形**：在顶部工具栏选择 **边角矩形** 或 **圆**，在屏幕中心（原点）附近画出大致形状。
    
3. **添加几何关系**（至关重要）：
    
    - 选中一条线，可以在左侧属性栏设为“水平”或“垂直”。
        
    - 按住 `Ctrl` 键同时选中两个圆，可以约束它们为“同心”或“相等”。
        
4. **标注智能尺寸**：点击 **智能尺寸** 工具，点击线条或圆，拖出并输入具体数值（如 $100\text{ mm}$）。
    
5. **观察草图颜色**：
    
    - 蓝色：欠约束（还能用鼠标拖动，不建议进行下一步）。
        
    - **黑色**：完全约束（无法拖动，标准状态）。
        
    - 红色/黄色：过度约束（尺寸冲突，需删除多余尺寸）。
        

### 第三步：3D特征生成（2D变3D）

1. **拉伸凸台/基体（最常用）**：
    
    - 保持草图选中状态，切换到 **特征** 标签页。
        
    - 点击 **拉伸凸台/基体**。
        
    - 在左侧设置拉伸深度（例如 $20\text{ mm}$），点击绿色的 **对勾** 确认。
        
2. **拉伸切除（做减法）**：
    
    - 鼠标左键点击刚刚生成的实体表面（它现在成为了一个新的基准面）。
        
    - 点击 **草图绘制**，在表面上画一个圆。
        
    - 切换到 **特征** 标签页，点击 **拉伸切除**。
        
    - 方向选择 **完全贯穿**，点击确定，实体上就会被挖出一个孔。
        
3. **修饰特征**：
    
    - 点击 **圆角** 工具，选中实体的某条棱边，输入半径（如 $5\text{ mm}$），即可将直角变为圆弧。
        

# 三、 高级建模特征简述

当你掌握了拉伸后，可以尝试以下进阶特征（逻辑相同：2D $\rightarrow$ 3D）：

|**特征工具**|**核心原理**|**典型应用**|
|---|---|---|
|**旋转凸台**|绕着一根中心轴旋转草图 $360^\circ$|轴、杯子、球体、皮带轮|
|**扫描**|让一个截面草图沿着一条路径线移动|管道、弹簧、扶手|
|**放样**|在多个不同的基准面草图之间进行平滑过渡|鼠标外壳、花瓶、飞机机翼|

# 四、 装配体与工程图

### 1. 装配体 (Assembly)——把零件组合起来

- 新建文件选择 **装配体**。
    
- 点击 **插入零部件**，把画好的多个零件放进来（第一个放进来的零件默认固定，无法移动）。
    
- 使用 **配合 (Mate)** 工具：
    
    - **同轴心**：让两个孔或轴对齐。
        
    - **重合**：让两个表面贴在一起。
        
    - **距离**：限制两个零件之间的间距。
        

### 2. 工程图 (Drawing)——用于生产加工的2D图纸

- 新建文件选择 **工程图**，选择图纸大小（如A3）。
    
- 在右侧的“调色板”中，把零件的 **前视图**、**上视图**、**等轴测图**（3D图）直接拖拽到图纸上。
    
- 使用 **智能尺寸** 自动或手动标注长、宽、高、孔径等加工数据。
    

# 五、 新手高效操作秘籍

- **鼠标捷径**：
    
    - **中键（滚轮）按住并拖动**：旋转视角。
        
    - **Shift + 中键**：缩放视角。
        
    - **Ctrl + 中键**：平移视角。
        
    - **滚轮滚动**：放大缩小（鼠标指针在哪里，就以哪里为中心放大）。
        
- **快捷键 `S`**：在屏幕任意地方按下 `S` 键，会弹出一个快捷工具箱（草图状态下是草图工具，3D状态下是3D工具），能大幅提升画图速度。
    
- **空格键**：按下空格键会弹出“定向”面板，可以快速切换到“正视于”（让草图面平行于你的眼睛，最常用）。
