# 第八章 标准件与常用件

## 8.1 螺纹

螺纹是机械零件上最常见的结构之一，本章以螺纹为起点系统讲解标准件与常用件的画法和标注。

### 螺纹的形成

螺纹是在圆柱或圆锥表面上沿螺旋线切削而成的连续凸起和沟槽。在车床上车削螺纹是最常见的加工方式：工件旋转一周，刀具沿轴向移动一个螺距，即形成一圈螺纹。

| 概念 | 说明 |
|------|------|
| 螺旋线 | 圆柱面上一点绕轴线等速旋转同时沿轴向等速移动形成的空间曲线 |
| 螺纹 | 沿螺旋线切削的牙型连续体，分凸起（牙顶）和沟槽（牙底） |
| 外螺纹 | 在圆柱外表面上切出的螺纹（如螺栓杆上的螺纹） |
| 内螺纹 | 在圆柱内表面（孔壁）上切出的螺纹（如螺母孔内的螺纹） |

### 螺纹五要素

螺纹的五要素是确定螺纹规格和画法的依据：

| 要素 | 符号 | 说明 | 常见类型/取值 |
|------|------|------|---------------|
| ① 牙型 | — | 螺纹轴向剖面的轮廓形状 | 三角形、梯形、锯齿形、矩形 |
| ② 大径 | $d$（外）/ $D$（内） | 螺纹的最大直径，代表螺纹规格 | 公称直径，如 M16 的 $d=16$ |
| ③ 线数 | $n$ | 螺纹螺旋线的条数 | 单线 $n=1$（最常用）、双线 $n=2$、多线 |
| ④ 螺距与导程 | $P$ / $P_h$ | $P$=相邻两牙轴向距离；$P_h = n \cdot P$ | 粗牙/细牙 |
| ⑤ 旋向 | — | 螺纹的旋转方向 | 右旋（常用，不标注）、左旋（标注 LH） |

线数与导程的关系：

$$P_h = n \cdot P$$

单线螺纹 $P_h = P$，即导程等于螺距；多线螺纹导程为螺距的整数倍。

### 常用螺纹牙型对比

| 螺纹种类 | 牙型代号 | 牙型角 | 牙型特征 | 主要用途 |
|----------|----------|--------|----------|----------|
| 普通螺纹 | M | $60^\circ$ | 三角形，等边 | 连接与紧固（最常用） |
| 管螺纹 | G / R / NPT | $55^\circ$ 或 $60^\circ$ | 三角形，有锥度或圆柱 | 管路密封连接 |
| 梯形螺纹 | Tr | $30^\circ$ | 等腰梯形 | 传动（如丝杠、车床丝杆） |
| 锯齿形螺纹 | B | $3^\circ/30^\circ$（工作面$3^\circ$） | 不对称梯形 | 单向受力传动（如千斤顶、压力机） |
| 矩形螺纹 | （非标） | $0^\circ$ | 矩形 | 传动效率高，但强度低，已少用 |

### 螺纹的画法规定

螺纹画法是机械制图的重要基本功，内外螺纹的规定必须牢记。

**外螺纹画法（如螺栓杆）：**

```
      粗实线（大径）    ← 终止线用粗实线
      ↓                        ↓
   ┌──────────────────────┐
   │  ██████████████████  │
   │  ░░░░░░░░░░░░░░░░░░  │  ← 细实线（小径 d₁≈0.85d）
   └──────────────────────┘
         ↑
    倒角（约 1.5×45°）
```

- **大径（牙顶）**：画**粗实线**
- **小径（牙底）**：画**细实线**（约大径的 0.85 倍）
- **螺纹终止线**：画**粗实线**
- **倒角**：在端部画出
- 在垂直于轴线的投影（圆的视图）中，小径圆用约 **3/4 圈细实线圆**表示，大径圆为粗实线整圆

**内螺纹画法（如螺母孔，剖视）：**

```
    细实线（大径）→  │░░░░░░░░░░░░░░░░░░│
                      │██████████████████│  ← 粗实线（小径）
                      │░░░░░░░░░░░░░░░░░░│
                      ────────────────────  ← 终止线（粗实线）
    
    剖面线画到粗实线（小径处）为止。
```

- **大径（牙底）**：画**细实线**（与外螺纹相反！）
- **小径（牙顶）**：画**粗实线**
- **螺纹终止线**：画**粗实线**
- 未剖视的内螺纹，大径与小径均画虚线
- 在垂直于轴线的投影中，大径圆用约 3/4 圈细实线圆；小径圆为粗实线整圆

**外螺纹与内螺纹的线型对比（核心记忆）：**

| 项目 | 外螺纹 | 内螺纹 |
|------|--------|--------|
| 大径（剖面视图中） | **粗实线** | **细实线** |
| 小径（剖面视图中） | **细实线** | **粗实线** |
| 终止线 | 粗实线 | 粗实线 |
| 端面倒角圆 | 不画 | 不画 |
| 3/4 圈细实线圆 | 小径圆 | 大径圆 |

**内外螺纹旋合画法：**

内外螺纹旋合时，旋合部分按**外螺纹**的画法绘制，其余部分仍按各自的画法。剖面线应画到粗实线处。

### 螺纹的标注格式

| 螺纹种类 | 标注格式 | 示例 | 说明 |
|----------|----------|------|------|
| 粗牙普通螺纹 | `M 公称直径-公差带代号` | `M16-7H` | 粗牙不注螺距 |
| 细牙普通螺纹 | `M 公称直径×螺距-公差带代号` | `M16×1.5-6H` | 细牙必须注螺距 |
| 梯形螺纹 | `Tr 公称直径×导程(P螺距)-公差带代号` | `Tr40×7-7H` | 单线时导程=螺距 |
| 梯形螺纹（多线） | `Tr 公称直径×导程(P螺距)-公差带代号` | `Tr40×14(P7)-7H` | 双线，螺距 7 |
| 锯齿形螺纹 | | `B40×7-7H` | 标注方式与梯形螺纹类似 |
| 管螺纹 | `特征代号 尺寸代号` | `G1/2` | **注意**：尺寸代号并非螺纹大径！ |
| 左旋螺纹 | 标注末尾加 `LH` | `M16×1.5-6H-LH` | 右旋不注，左旋必注 |

螺纹旋合标注：`M16×1.5-6H/6g`，分子为内螺纹公差代号，分母为外螺纹公差代号。

关于螺纹配合公差等级的选配，详见 [[10-零件图技术要求|第十章 零件图技术要求]]。

## 8.2 螺纹紧固件

螺纹紧固件利用螺纹的自锁原理将两个或多个零件连接在一起，是机械中应用最广泛的连接方式。

### 三种基本连接方式

| 连接方式 | 结构组成 | 适用场合 | 特点 |
|----------|----------|----------|------|
| **螺栓连接** | 螺栓 + 螺母 + 垫圈 | 被连接件均不太厚，能钻通孔 | 可拆卸，连接可靠，最常用 |
| **双头螺柱连接** | 双头螺柱 + 螺母 + 垫圈 | 被连接件之一很厚或不允许钻通孔 | 一端旋入被连接件螺纹孔，另一端用螺母紧固 |
| **螺钉连接** | 螺钉 | 不经常拆卸的场合 | 省去螺母，结构紧凑；头部形式多样 |

### 螺栓连接的比例画法

螺栓连接的各部分尺寸常以螺栓公称直径 $d$ 为基准按比例画出：

| 零件 | 尺寸参数（以 $d$ 为基准） |
|------|--------------------------|
| 螺栓公称长度 $l$ | 需计算选定：$l \geq$ 被连接件总厚度 + 垫圈厚度 + 螺母厚度 + 伸出量 |
| 螺栓头部厚度 | $\approx 0.7d$ |
| 螺栓头部对边距 | $\approx 1.7d$ |
| 螺母厚度 | $\approx 0.8d$ |
| 垫圈外径 | $\approx 2.2d$ |
| 垫圈厚度 | $\approx 0.15d$ |

```
    螺栓连接装配示意图（简化画法）：
    
           ┌─────┐  ← 螺栓头
    ───────┼─────┼───────  被连接件 1（通孔孔径 ≈ 1.1d）
    ───────┼─────┼───────  被连接件 2（通孔孔径 ≈ 1.1d）
           │     │
         ┌─┴─────┴─┐  ← 垫圈
         ├─┴─────┴─┤  ← 螺母（六角形简化画法）
    
    注意：通孔直径取 1.1d，剖面线应画到粗实线处且方向相反。
```

### 双头螺柱连接

双头螺柱连接用于被连接件之一较厚或不宜钻通孔的情况。

- **旋入端**（$b_m$）：完全旋入被连接件的螺纹孔中，其长度根据被连接件材料确定：
  - 钢、青铜：$b_m = d$
  - 铸铁：$b_m = 1.25d \sim 1.5d$
  - 铝合金：$b_m = 2d$
- **螺母端**：与被连接的通孔件配合，画法同普通螺栓连接。

螺纹孔的深度：钻孔深度 = $b_m +$ 螺纹收尾长度，画图时适当加深。

### 螺钉连接

螺钉直接旋入被连接件的螺纹孔中，利用螺钉头将被连接件压紧，适用于受力不大且不经常拆卸的场合。

| 头部形式 | 代号 | 特点 |
|----------|------|------|
| 圆柱头 | GB/T 65 | 头部露出，可用一字或十字旋具 |
| 沉头 | GB/T 68 | 头部埋入零件表面，外形平整 |
| 半圆头 | GB/T 67 | 头部圆弧光滑，美观 |
| 内六角圆柱头 | GB/T 70.1 | 头部可埋入沉孔，拧紧力矩大 |

### 紧固件的标记示例

| 名称 | 标记示例 | 含义 |
|------|----------|------|
| 六角头螺栓 | `螺栓 GB/T 5782 M10×50` | 螺纹规格 M10，公称长度 50mm |
| 双头螺柱 | `螺柱 GB/T 899 M10×50` | 两端均为 M10 螺纹，$b_m = 1.5d$ |
| 开槽圆柱头螺钉 | `螺钉 GB/T 65 M8×30` | 螺纹规格 M8，公称长度 30mm |
| 开槽沉头螺钉 | `螺钉 GB/T 68 M6×20` | 螺纹规格 M6，公称长度 20mm |
| 1 型六角螺母 | `螺母 GB/T 6170 M10` | 与 M10 螺栓配合 |
| 平垫圈 | `垫圈 GB/T 97.1 10` | 用于 M10 螺栓 |

## 8.3 键与销

### 键连接

键用于轴和轴上零件（如齿轮、带轮、联轴器）之间的**周向固定**，以传递扭矩。

**普通平键：**

平键是矩形截面的连接件，靠两侧面传递扭矩。按端部形状分 A/B/C 三种型式：

| 型式 | 端部形状 | 键槽形状 | 用途 |
|------|----------|----------|------|
| A 型（圆头） | 两端圆弧 | 用端铣刀加工键槽，槽端为圆弧 | 最常用 |
| B 型（方头） | 两端方形 | 用盘铣刀加工键槽，槽端为矩形 | 轴的应力集中较小 |
| C 型（一端圆一端方） | 一端圆弧一端方形 | A/B 型槽的混合 | 用于轴端 |

**键槽的画法与尺寸标注：**

键槽在轴上铣出，在轮毂上插出（或拉出）。画图时需标出键槽宽度 $b$、深度 $t$（轴槽深）和 $t_1$（轮毂槽深）、键槽长度 $l$。

轴槽深 $t$ 和轮毂槽深 $t_1$ 可从国家标准中按轴的直径查表获得。

$$
\text{平键工作面的受力：靠键的两个侧面传递扭矩，顶面有间隙不传力}
$$

**半圆键：**

半圆键呈弓形，能在轴槽中摆动以适应轮毂槽的斜度，适用于锥形轴端或传递较小扭矩的场合。键槽用半圆键槽铣刀加工，轴槽深且应力集中较大是其主要缺点。

**键的标记示例：**

| 名称 | 标记示例 | 说明 |
|------|----------|------|
| 普通平键 A 型 | `键 8×7×25 GB/T 1096` | $b=8$, $h=7$, $l=25$, A 型圆头 |
| 普通平键 B 型 | `键 B8×7×25 GB/T 1096` | B 型方头，须标注 B |
| 普通平键 C 型 | `键 C8×7×25 GB/T 1096` | C 型一端圆一端方 |
| 半圆键 | `键 6×10×25 GB/T 1099` | $b=6$, $h=10$, $d_1=25$（半圆键的基本尺寸） |

键与键槽的配合公差详见 [[10-零件图技术要求|第十章]]。

### 销连接

销主要用于零件的**定位**和**连接**，也可作安全装置中的过载剪断元件。

| 种类 | 特征 | 用途 | 画法要点 |
|------|------|------|----------|
| **圆柱销** | 直圆柱体 | 定位（承受不大的载荷） | 标注直径×长度 |
| **圆锥销** | 圆锥体，锥度 1:50 | 定位与连接，可多次拆装 | 标注小端直径×长度 |
| **开口销** | 截面为半圆或扁平，弯成环状 | 防止螺母松动（与槽形螺母配用） | 标注公称直径×长度 |

圆锥销具有 1:50 的标准锥度，具有良好的自锁性，能保证多次拆装后仍有可靠的定位精度。

**销的标记示例：**

| 名称 | 标记示例 | 说明 |
|------|----------|------|
| 圆柱销 | `销 GB/T 119.1 8m6×30` | 公称直径 8mm，长度 30mm |
| 圆锥销 | `销 GB/T 117 8×30` | 小端直径 8mm，长度 30mm |
| 开口销 | `销 GB/T 91 5×40` | 公称直径 5mm，长度 40mm |

## 8.4 滚动轴承

滚动轴承是支承旋转轴的标准组件，具有摩擦阻力小、旋转精度高、标准化程度高等优点。

### 滚动轴承的结构

| 组成部分 | 作用 | 材料 |
|----------|------|------|
| **内圈** | 紧配合在轴颈上，随轴一起旋转 | 轴承钢（GCr15 等） |
| **外圈** | 装在轴承座孔内，通常固定不动 | 轴承钢（GCr15 等） |
| **滚动体** | 在内外圈滚道间滚动，传递载荷 | 轴承钢，有球、圆柱滚子、圆锥滚子等 |
| **保持架** | 将滚动体均匀隔开，防止相互碰撞 | 低碳钢、铜合金或工程塑料 |

### 三种基本类型

| 类型 | 代号 | 滚动体形状 | 承载方向 | 典型应用 |
|------|------|-----------|----------|----------|
| **深沟球轴承** | 6 | 球（钢球） | 主要承受径向载荷，能承受少量双向轴向载荷 | 电机、减速器、一般机械 |
| **圆锥滚子轴承** | 3 | 圆锥滚子 | 承受径向和轴向联合载荷（单方向轴向） | 汽车轮毂、机床主轴、轧机 |
| **推力球轴承** | 5 | 球（钢球） | 仅承受轴向载荷 | 立式钻床主轴、起重机吊钩 |

轴承的通用画法和规定画法均依照国家标准 GB/T 4459.7，在装配图中通常按简化画法或示意画法绘制。

### 滚动轴承的代号

滚动轴承代号由**基本代号**、**前置代号**和**后置代号**组成，其中基本代号最为常用。

**基本代号的结构（以 6208 为例）：**

| 位置 | 内容 | 示例值 | 含义 |
|------|------|--------|------|
| 第一位（从右数第 5 位） | 类型代号 | **6** | 深沟球轴承（6 类） |
| 第二位（从右数第 4 位） | 宽度系列代号 | **2** | 宽度系列 2（省略时取常用系列） |
| 第三位（从右数第 3 位） | 直径系列代号 | **0** | 轻系列（0 省略不写） |
| 第四、五位（从右数第 1-2 位） | 内径代号 | **08** | 内径 $d = 08 \times 5 = 40\text{mm}$ |

**内径代号规则：**

| 内径代号 | 内径计算方法 | 示例 |
|----------|-------------|------|
| 00 | $d = 10\text{mm}$ | 6000：内径 10mm |
| 01 | $d = 12\text{mm}$ | 6001：内径 12mm |
| 02 | $d = 15\text{mm}$ | 6002：内径 15mm |
| 03 | $d = 17\text{mm}$ | 6003：内径 17mm |
| 04~99 | $d = \text{代号} \times 5$ | 6208：内径 40mm（$8\times5$） |

**常用类型代号：**

| 代号 | 轴承类型 |
|------|----------|
| 0 | 双列角接触球轴承 |
| 1 | 调心球轴承 |
| 2 | 调心滚子轴承和推力调心滚子轴承 |
| 3 | 圆锥滚子轴承 |
| 5 | 推力球轴承 |
| 6 | 深沟球轴承 |
| 7 | 角接触球轴承 |
| N | 圆柱滚子轴承 |

## 8.5 弹簧

弹簧是利用材料的弹性变形来储存能量、缓冲吸振或控制运动的常用弹性元件。

### 圆柱螺旋弹簧的类型

| 类型 | 受力方向 | 特点 | 典型应用 |
|------|----------|------|----------|
| **压缩弹簧** | 轴向受压 | 各圈之间有间隙，两端并紧磨平 | 减振器、气门弹簧、模具顶料 |
| **拉伸弹簧** | 轴向受拉 | 各圈之间无间隙（并紧），两端有挂钩 | 弹簧秤、弹簧卡箍 |
| **扭转弹簧** | 受扭矩 | 各圈之间有间隙，两端有扭臂 | 夹子、门铰链 |

### 弹簧的规定画法

弹簧在装配图和零件图中的绘制有一定简化规定（GB/T 4459.4），核心规则如下：

- 在平行于轴线的投影面上，**各圈的轮廓线画成直线**以替代螺旋线
- 有效圈数 $n > 4$ 时，两端各画 $1\sim2$ 圈（含支承圈），中间各圈可省略不画，只画簧丝剖面中心的连线（点画线）
- 右旋弹簧按右旋画（不特别说明时默认右旋），左旋弹簧标注 **LH**（无论左旋右旋，均可画成右旋并标注旋向）
- 在装配图中被剖切时，簧丝剖面直径 $\leq 2\text{mm}$ 时可用涂黑表示；$\leq 1\text{mm}$ 时可示意画出

```
    弹簧的简化画法（压缩弹簧，全剖视图）：
    
    ┌──┐                    ┌──┐
    │██│ ← 支承圈（磨平）    │██│
    │██├──┐              ┌──┤██│
    │  │  │    ...       │  │  │ ← 省略中间各圈
    │  │  │    (簧丝)    │  │  │
    │  │──┘              └──│  │
    │██│                    │██│
    └──┘                    └──┘
    ←────── H₀（自由高度）──────→
    
    用点画线连接簧丝剖面中心表示省略的中间各圈。
```

### 弹簧的主要参数

| 参数 | 符号 | 定义 |
|------|------|------|
| 簧丝直径 | $d$ | 弹簧钢丝的截面直径 |
| 弹簧中径 | $D_2$ | 弹簧的平均直径 |
| 弹簧外径 | $D = D_2 + d$ | |
| 弹簧内径 | $D_1 = D_2 - d$ | |
| 节距 | $t$ | 相邻两圈簧丝中心之间的轴向距离 |
| 自由高度 | $H_0$ | 无载荷时弹簧的总高度（压缩弹簧） |
| 有效圈数 | $n$ | 参与弹性变形的圈数 |
| 总圈数 | $n_1 = n + n_{\text{支}}$ | 含两端并紧的支承圈（通常 $n_{\text{支}}=1.5\sim2$） |
| 旋绕比 | $C = D_2 / d$ | 反映弹簧卷绕程度，常用 $4\sim14$ |

### 弹簧的标记方法

弹簧的标记格式：`弹簧 类型 d×D₂×H₀ 标准编号`

示例：
- `压缩弹簧 3×20×50 GB/T 2089`——簧丝直径 3mm，中径 20mm，自由高度 50mm
- `拉伸弹簧 LⅡ 2.5×16×60 GB/T 2088`——LⅡ 型挂钩

## 8.6 齿轮

齿轮是机械传动中最常用的传动件，通过轮齿的啮合来传递运动和动力。

### 齿轮的分类

| 分类 | 齿轮类型 | 两轴位置关系 | 齿向特征 | 典型应用 |
|------|----------|-------------|----------|----------|
| 平行轴传动 | **圆柱齿轮** | 两轴线平行 | 直齿、斜齿、人字齿 | 减速器、变速箱 |
| 相交轴传动 | **圆锥齿轮（伞齿轮）** | 两轴线相交 | 直齿、螺旋齿 | 差速器、钻床传动 |
| 交错轴传动 | **蜗轮蜗杆** | 两轴线交错（通常垂直） | 蜗杆为螺旋齿 | 大减速比传动、分度机构 |

### 直齿圆柱齿轮的基本参数

| 参数 | 符号 | 标准值/公式 | 说明 |
|------|------|------------|------|
| 齿数 | $z$ | 根据传动比确定 | |
| 模数 | $m$ | 标准系列值（mm） | **齿轮计算的核心参数**，已标准化（GB/T 1357） |
| 压力角 | $\alpha$ | $20^\circ$（标准） | 啮合点受力方向与运动方向夹角 |
| 齿顶高系数 | $h_a^*$ | $1$（标准） | 齿顶高 $h_a = h_a^* \cdot m$ |
| 顶隙系数 | $c^*$ | $0.25$（标准） | 顶隙 $c = c^* \cdot m$ |

模数 $m$ 是齿轮最重要的基本参数，定义为：

$$m = \frac{p}{\pi}$$

其中 $p$ 为齿距（分度圆上相邻两齿对应点的弧长）。标准模数使齿轮设计与加工规范化。

### 直齿圆柱齿轮各圆直径计算公式

| 名称 | 符号 | 计算公式 |
|------|------|----------|
| 分度圆直径 | $d$ | $d = m \cdot z$ |
| 齿顶圆直径 | $d_a$ | $d_a = m(z + 2h_a^*) = m(z + 2)$ |
| 齿根圆直径 | $d_f$ | $d_f = m(z - 2h_a^* - 2c^*) = m(z - 2.5)$ |
| 基圆直径 | $d_b$ | $d_b = d \cdot \cos\alpha$ |
| 中心距 | $a$ | $a = \dfrac{d_1 + d_2}{2} = \dfrac{m(z_1 + z_2)}{2}$ |

以上公式适用于标准渐开线直齿圆柱齿轮（$h_a^*=1, c^*=0.25, \alpha=20^\circ$）。

### 单个齿轮的画法

```
    直齿圆柱齿轮画法（非圆视图，轴向投影）：
    
    齿顶圆 ──── 粗实线 ────┐
    分度圆 ─ ─ 点画线 ─ ─ ┤  ← 分度圆用点画线
    齿根圆 ──── 细实线 ────┘     （或省略不画）
    
    当需要剖视时：
    
    齿顶线 ──── 粗实线 ────┐
                            │
    齿根线 ──── 粗实线 ────┤  ← 剖视时齿根为粗实线
    分度线 ─ ─ 点画线 ─ ─ ┤  ← 分度线用点画线
                            │
    剖面线 ──── 画到齿根处 ┘
```

| 部位 | 线型规定 |
|------|----------|
| 齿顶线 / 齿顶圆 | **粗实线** |
| 分度线 / 分度圆 | **点画线**（细点画线） |
| 齿根线 / 齿根圆 | 非剖视时用**细实线**或**省略**；剖视时用**粗实线** |
| 轮齿剖切 | 轮齿部分按不剖处理（不画剖面线） |

在平行于齿轮轴线的视图中，轮齿部分不画齿形，仅画出齿顶线、分度线和齿根线。当需要剖视时，轮齿规定按不剖处理。

### 齿轮啮合的画法

一对齿轮啮合时，在剖视图中啮合区画**五条线**：

```
    两齿轮啮合区放大（剖视图）：
    
    主动轮                从动轮
    ─── 齿顶线（粗）      ─── 齿顶线（粗）
    ─ ─ 分度线（点画）    ← 两分度线相切于节点
    ─── 齿根线（粗）      ─── 齿根线（粗）
                          ─── 从动轮齿根线 ⤵
    
    其中一齿轮的齿顶线画成虚线（被遮挡）
    或被省略，共五条主要线。
```

啮合区画法要点：
- 在剖视图中，啮合区一个齿轮的轮齿画可见，另一个齿轮的轮齿被遮挡部分画虚线或不画
- 两个齿轮的分度圆（分度线）相切
- 齿顶线与另一齿轮的齿根线之间有**顶隙** $c = c^* \cdot m = 0.25m$

在端面视图（垂直于轴线的投影）中：
- 两个分度圆相切，均用点画线
- 啮合区齿顶圆均用粗实线（或以虚线表示被遮挡齿顶）

## 总结

本章系统介绍了机械图样中最常见的几类标准件与常用件的画法、标注和选用规则。
