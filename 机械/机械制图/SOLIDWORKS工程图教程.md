# SOLIDWORKS 工程图完整教程

SOLIDWORKS 工程图模块（Drawing）是将三维模型转化为符合国家标准的二维生产图纸的核心工具。与手工制图中"一根线一根线地画"不同，SOLIDWORKS 工程图采用**参数化投影**机制——视图由三维模型自动生成，尺寸由建模特征自动继承，模型修改后图纸自动更新。本教程假设你已掌握基础零件建模（参考 [[SOLIDWORKS 使用指南|SOLIDWORKS 建模指南]]），重点讲解从模型到图纸的完整工作流。

> **核心原则**：工程图的一切信息应**由模型驱动**。建模时标注的尺寸和公差是"源"，工程图中的标注只是"投影"。永远不要在工程图中用"手动覆盖值"来强行修改一个在模型中本应正确的尺寸。

---

## 一、工程图环境入门

### 1.1 两种创建方式

| 方式 | 操作路径 | 适用场景 |
|:---|:---|:---|
| **从零件/装配体制作工程图** | 在零件或装配体窗口中 → `文件 → 从零件制作工程图`（或 `从装配体制作工程图`） | **推荐方式**。建模完成后直接出图，模型与图纸自动关联 |
| **新建工程图后插入模型** | `文件 → 新建 → 工程图` → 选择模板 → 随后通过视图调色板或 `插入 → 模型` 引入模型 | 适用已有 .slddrw 文件需要更换模型，或多模型放在同一图纸 |

> 推荐工作流：打开已建好的零件 → `文件 → 从零件制作工程图` → 选模板 → 立即进入工程图环境，模型已自动关联。

### 1.2 图纸格式选择

新建工程图时弹出的对话框提供两类选项：

| 模板类型 | 说明 | 推荐度 |
|:---|:---|:---:|
| **标准模板 (GB)** | SOLIDWORKS 安装时自带的国标模板，包含标准图框和标题栏，尺寸 A0~A4 | ★★★★★ 初学者首选 |
| **自定义模板 (.drwdot)** | 公司或个人预先设计好的模板，包含企业 LOGO、自定义标题栏、特定字体和线型 | ★★★★★ 企业用户必须使用 |
| **空白图纸** | 无图框无标题栏，需要从头搭建 | ★☆☆☆☆ 仅用于练习或特殊用途 |

### 1.3 界面布局详解

进入工程图后，界面分为四大区域：

```
┌──────────────────────────────────────────────────┐
│  命令管理器 (CommandManager) —顶部—               │
│  "视图布局" | "注解" | "草图" | "评估" 等标签页   │
├──────────┬───────────────────┬───────────────────┤
│ Feature  │                   │   视图调色板       │
│ Manager  │    图纸区域       │  (View Palette)   │
│ 设计树   │   (Drawing        │   右侧任务窗格    │
│ (左侧)   │    Sheet)         │                  │
│          │                  │  - 前视图          │
│ 列出所有 │  图纸 1/图纸 2   │  - 上视图         │
│ 视图、   │                   │  - 右视图          │
│ 图纸格式 │                   │  - 等轴测图       │
│ 等内容   │                   │  - 当前模型视图    │
│          │                   │  - 注解视图        │
└──────────┴───────────────────┴───────────────────┘
```

- **FeatureManager 设计树（左侧）**：列出每张图纸、每个视图、图纸格式。右键任一项目可访问属性。
- **命令管理器（顶部）**：工程图专用标签页——`视图布局` 控制视图创建与编辑，`注解` 控制尺寸/符号/注释，`草图` 提供辅助绘制工具。
- **视图调色板（右侧）**：显示当前模型可用的标准视图和已保存视图，**拖入图纸**即可创建视图。
- **图纸区**：即实际图纸页面，所有视图和标注均在此操作。

### 1.4 鼠标操作（工程图 vs 零件模式）

| 操作 | 零件/装配体模式 | 工程图模式 |
|:---|:---|:---|
| 中键拖拽 | **旋转**模型 | **平移**图纸 |
| 滚轮滚动 | 缩放模型 | 缩放图纸 |
| Ctrl + 中键拖拽 | 平移模型 | *(不常用)* |
| Shift + 中键拖拽 | 缩放模型 | *(不常用)* |
| 左键点击 | 选中特征/面 | 选中视图/尺寸/线条 |
| 右键 | 弹出上下文菜单 | 弹出上下文菜单（与所在位置相关） |

> 工程图中**没有旋转**操作，因为图纸是二维平面。习惯零件模式旋转的用户需要适应：在工程图中中键拖拽是平移。

## 二、图纸与模板设置

### 2.1 图纸属性

右键图纸空白处 → **属性**，弹出的"图纸属性"对话框包含以下关键设置：

| 属性项 | 推荐设置 | 说明 |
|:---|:---|:---|
| **投影类型** | **第一角投影**（国标 GB） | 中国/欧洲标准：主视图在上，俯视图在下，左视图在右。若出图给美方企业则选**第三角投影** |
| **比例** | 通常选 1:1 或按零件大小调整 | 整张图纸的统一比例，单个视图可独立设比例覆盖 |
| **图纸格式** | 点击"浏览"更换 | 允许在创建后更换图框和标题栏 |

对比两种投影类型（参考 [[01-制图基础与国家标准|第一章]]）：

| 投影类型 | 主视图位置 | 俯视图位置 | 左视图位置 | 标识符号 | 适用地区 |
|:---|:---|:---|:---|:---|:---|
| **第一角** ☶ | 中央 | 主视图**下方** | 主视图**右方** | ⏢（左小右大梯形） | 中国 GB、ISO 国际标准、欧洲 |
| **第三角** ☷ | 中央 | 主视图**上方** | 主视图**左方** | ⏣（左大右小梯形） | 美国 ANSI、日本 JIS |

### 2.2 编辑图纸格式 vs 编辑图纸

这是一个极易混淆的概念：

| 概念 | 进入方式 | 包含内容 | 可编辑内容 |
|:---|:---|:---|:---|
| **编辑图纸格式** | 右键图纸空白 → `编辑图纸格式` | 图框线、标题栏表格、公司 LOGO、图幅分区线 | 标题栏文字、图框样式、自动属性链接 |
| **编辑图纸** | 右键图纸空白 → `编辑图纸`（返回） | 视图、尺寸、注解、BOM 表格 | 一切视图和标注 |

在"编辑图纸格式"状态下，标题栏中的文字通常是**属性链接**而非手打文字，双击可见其真实值如 `$PRPSHEET:"SW-文件名称(File Name)"`。

### 2.3 自定义标题栏（关键技能）

**步骤**：

1. 右键图纸空白 → `编辑图纸格式`
2. 使用草图工具（直线、矩形）绘制或修改标题栏表格，可预先用 AutoCAD 画好再导入
3. 在每个单元格中插入**属性链接**：

| 标题栏单元格 | 属性链接语法 | 说明 |
|:---|:---|:---|
| 图样名称 | `$PRPSHEET:"SW-文件名称(File Name)"` | 自动显示零件文件名 |
| 材料标记 | `$PRPSHEET:"Material"` | 显示零件中定义的材料（如 45、Q235A） |
| 重量 | `$PRPSHEET:"Weight"` | 自动计算或手动填写的重量 |
| 比例 | `$PRP:"SW-图纸比例(Sheet Scale)"` | 当前图纸比例 |
| 设计/审核/日期 | `$PRP:"SW-作者(Author)"` 等 | 从文件属性读取 |
| 自定义属性 | `$PRPSHEET:"{你的属性名}"` | 在零件 `文件 → 属性` 中定义的自定义属性 |

4. 插入链接：`插入 → 注解 → 注释` → 在文本框内光标位置 → 点击左侧 PropertyManager 中的"链接到属性"按钮 → 选"图纸属性中所指定视图中显示的模型"或"当前文件"
5. 完成编辑后 → 右键 → `编辑图纸` 返回正常模式

> **技巧**：在零件文件中预先填写 `文件 → 属性 → 自定义` 标签页中的属性（如 "Material" = "HT200", "零件号" = "ZC-01-001"），工程图标题栏自动同步填入。

### 2.4 保存为模板文件 (.drwdot)

完成图纸格式设计（图框 + 属性链接的标题栏 + 默认字体/线型设置）后：

1. `文件 → 另存为`
2. 文件类型选 **工程图模板 (\*.drwdot)**
3. 浏览到模板文件夹（默认路径：`C:\ProgramData\SOLIDWORKS\SOLIDWORKS 20XX\templates\` 或在 `选项 → 文件位置 → 文件模板` 中查看）
4. 命名（如 "A4-横向-公司模板"），保存

此后新建工程图时，该模板出现在"高级"选项卡中。

### 2.5 设置默认线型与字体

`选项（齿轮图标）→ 文档属性`，在如下标签页中设置：

| 设置项 | 路径 | 推荐设置 |
|:---|:---|:---|
| 尺寸字体 | `文档属性 → 尺寸` | 仿宋_GB2312 或 长仿宋体, 3.5mm 字高（GB/T 14691） |
| 注解字体 | `文档属性 → 注解 → 注释` | 同上，技术要求正文用 5mm |
| 线型 | `文档属性 → 线型` | 可见边线=粗实线 0.5mm，隐藏边线=虚线 0.25mm，中心线=点画线 0.25mm |
| 箭头 | `文档属性 → 尺寸 → 箭头` | 实心闭合箭头，长度 4mm |
| 单位 | `文档属性 → 单位` | MMGS（毫米·克·秒），小数位数 2 位 |

> 将这些设置保存在 .drwdot 模板中，以后新建工程图自动继承。

## 三、插入模型视图（核心）

### 3.1 标准三视图

**操作**：`插入 → 工程图视图 → 标准三视图` → 在弹出的对话框中浏览并选择零件或装配体文件 → 确定。

系统自动按**第一角投影**生成：主视图（前视图）、俯视图（上视图）、左视图（右视图）。三视图之间保持"长对正、高平齐、宽相等"的投影关系。

> 若不希望使用前/上/右视图作为标准三视图，则需要先进入零件文件，在模型中将需要的方向保存为命名视图，再使用"模型视图"方法。

### 3.2 模型视图（从视图调色板拖入）——推荐方式

1. 若从零件直接制作的工程图，右侧**视图调色板**已自动加载该模型的所有标准视图
2. **拖入主视图**：在调色板中找到"前视"（或你需要的方向）→ 按住鼠标左键拖到图纸中央 → 释放
3. 主视图就位后，PropertyManager 自动切换到"投影视图"模式：向**下方**移动鼠标自动生成俯视图，向**右侧**移动自动生成左视图，向**右下方**移动生成轴测图
4. 全部就位后点击绿色对勾

| 调色板视图名 | 对应手工制图术语 | 国标习惯用法 |
|:---|:---|:---|
| *前视 | 主视图 | 最能表达零件形状的方向 |
| *上视 | 俯视图 | 放在主视图下方 |
| *右视 | 左视图 | 放在主视图右方（第一角） |
| *后视 | 后视图 | 按需 |
| *左视 | 右视图 | 按需 |
| *下视 | 仰视图 | 按需 |
| *当前视图 | 建模时的当前屏幕方向 | 自定义视角 |
| *等轴测 | 正等轴测图 | 用作参考图放在图纸角落 |

### 3.3 投影视图

已有主视图后，可根据需要向任意方向生成投影视图：

1. **选中**已有视图（出现绿色虚线边框）
2. `插入 → 工程图视图 → 投影视图`
3. 移动鼠标到主视图的上下左右各方向 → 预览图框跟随移动
4. 在合适位置点击放置

> 投影视图**继承父视图的显示样式和比例**，且与父视图保持投影对齐关系。按住 Ctrl 键拖动可解除对齐关系。

### 3.4 辅助视图（向视图）

用于表达斜面上的真实形状（参考 [[07-机件表达方法|第七章]] 中的斜视图概念）：

1. `插入 → 工程图视图 → 辅助视图`
2. 在已有视图中**选择一条斜边线**（必须是一条直线边，表示投影方向垂直于该线）
3. 沿垂直方向拖出辅助视图 → 点击放置
4. 可选中辅助视图后拖动箭头标签调整位置

> 辅助视图自动垂直于所选的参考边线方向，适用于法兰斜孔、斜面凸台等特征。

### 3.5 命名视图

如果调色板中预设方向不满足需求，可预先在模型中保存自定义视角：

1. 在零件文件中，旋转模型到理想方向 → 按**空格键**打开"定向"面板
2. 点击"新建视图"图标 → 命名如"加工方向一"
3. 回到工程图 → 调色板刷新（或关闭重开工程图）→ 新命名视图出现在列表中，可拖入

### 3.6 视图属性设置

右键任一视图 → 在弹出工具栏中或右键菜单中调整：

| 属性 | 选项 | 说明 |
|:---|:---|:---|
| **显示样式** | 线架图 / 隐藏线可见 / 消除隐藏线 / 着色 / 带边线上色 | 线架图=全部边线显示；消除隐藏线=**最常用出图模式**，隐藏不可见轮廓；带边线上色=审核用直观查看 |
| **缩放比例** | 使用父关系 / 使用图纸比例 / 使用自定义比例 | 每个视图可独立设比例。如整体 1:1，某个局部放大视图设 2:1 |
| **切边显示** | 切边可见 / 切边不可见 / 切线用双点画线 | 控制圆角处切线是否显示 |
| **品质** | 草稿品质 / 高品质 | 大装配时可选"草稿品质"加速 |

## 四、剖视图与断面图

### 4.1 全剖视图

**步骤**：

1. `插入 → 工程图视图 → 剖面视图`
2. 此时鼠标光标变为画线模式，在父视图上**画一条直线穿过零件中心**（使用推断线捕捉圆心或中点自动对齐）
3. 直线首尾确定后，向剖切方向移动鼠标 → 剖视图预览跟随
4. 点击放置剖视图，自动生成带有剖切符号（A-A）的剖面图

> 剖视图默认放在剖切箭头指向的一侧。若方向反了，在放置前按 Tab 键翻转，或生成后在 PropertyManager 中勾选"反转方向"。

### 4.2 半剖视图

当零件左右对称，只需剖开一半（参考 [[09-零件图|第九章]]）：

1. 在剖面视图的剖切线绘制步骤中，画**一条折线**：从零件边缘画到中心，再从中心画向零件同侧边缘（形成倒 L 形）
2. 或在剖面视图生成后，编辑剖切线的草图，将直线修改为只覆盖一半
3. 默认生成的剖面视图即为半剖——只有剖切线覆盖区域被剖开

### 4.3 阶梯剖视图

用于不在同一直线上的特征（如多级阶梯孔）：

1. 在剖面视图命令下，画**多段相连直线**（折线）穿过所有待剖特征
2. 勾选 PropertyManager 中的"阶梯剖切"选项
3. 生成的剖视图将多段剖切线"展开"到同一平面上显示

> 手工制图中阶梯剖的"转折处不画线"规则在 SOLIDWORKS 中自动处理。

### 4.4 旋转剖视图

用于圆周分布的特征（如法兰上的螺栓孔）：

1. `插入 → 工程图视图 → 旋转剖视图`
2. 先在圆心点击确定旋转中心，再画两条相交的剖切线分别指向两个孔
3. 生成剖视图：其中一个孔被"旋转"到与另一孔同一平面后剖开显示

### 4.5 局部剖视图（断开的剖视图）

用于表达零件局部内部结构，不剖整图：

1. `插入 → 工程图视图 → 断开的剖视图`
2. 用样条曲线工具在父视图上画**封闭轮廓**（圈出想剖开的区域）
3. 在 PropertyManager 中设置**剖切深度**（可输入具体数值，或从另一个视图中选择一条边来确定深度）
4. 点击确定 → 封闭区域内出现剖面线

### 4.6 断面图（移出断面）

`插入 → 工程图视图 → 剖面视图`，但在 PropertyManager 中勾选"只显示切面"—即只显示切口位置的截面形状，常用于轴类零件的键槽、退刀槽等。

### 4.7 剖面线的编辑

点击剖面线（斜线区域）→ PropertyManager 提供以下修改项：

| 修改项 | 选项 | 说明 |
|:---|:---|:---|
| **样式** | ANSI31 (45° 斜线) / ANSI32 (交叉斜线) / ANSI33 (蜂窝) / 等等 | ANSI 标准规定了不同材料的剖面线样式 |
| **比例** | 0.5 / 1 / 2 / 3 | 数值越小剖面线越密。薄壁件选 0.5，大铸件选 2~3 |
| **角度** | 0° / 45° / 90° / 135° 等 | 默认 45°，相邻零件剖面线应相反方向（45° 和 135°） |

材料与剖面线样式的常见对应：

| ANSI 代号 | 剖面线样式 | 代表材料 |
|:---|:---|:---|
| ANSI31 | 单方向 45° 平行斜线 | **钢铁（通用金属）**——最常用 |
| ANSI32 | 双方向 45° 交叉斜线 | 钢/硬质合金 |
| ANSI33 | 双向 30° 交叉 | 铜及铜合金 |
| ANSI34 | 双向水平-垂直交叉 | 塑料、绝缘材料 |
| ANSI37 | 单方向 45° + 短横线 | 铝 / 轻合金 |
| ANSI38 | 对角线网格 | 铸铁（灰色） |

## 五、局部放大图与断裂视图

### 5.1 局部放大图

用于表达微小细节（如退刀槽、细小圆角、小孔），参考 [[09-零件图|第九章]] 局部放大图规范：

1. `插入 → 工程图视图 → 局部视图`
2. 在父视图上**画一个圆**框出待放大区域
3. 移动鼠标，放大于预览框中跟随出现
4. 点击放置后，在 PropertyManager 中设定**放大比例**（如 2:1, 5:1, 10:1）
5. 可在 PropertyManager 中修改局部放大图的名称样式（如 `Ⅰ` `Ⅱ` `A` `B`）

| 比例选择建议 | 适用情境 |
|:---|:---|
| 2:1 | 略小的细节，如较大圆角、键槽端部 |
| 5:1 | 常规局部放大，如退刀槽、越程槽、细小孔 |
| 10:1 | 极精细结构，如微小倒角、螺纹牙型 |

### 5.2 断裂视图（适用于长轴类零件）

长轴、长杆类零件全图太长时，截断中间重复段：

1. 选中已有视图
2. `插入 → 工程图视图 → 断裂视图`
3. 在视图上拖动鼠标设定**两个断裂位置**（截断的起点和终点）
4. 在 PropertyManager 中选择**断裂线样式**：

| 断裂线样式 | 适用对象 |
|:---|:---|
| **直线** | 一般轴类、杆类 |
| **曲线** | 圆柱体（曲线的弯曲方向模拟圆柱断裂的自然形态） |
| **锯齿线** | 管材、型材、木质件 |

5. 设置断裂间隙（断裂处两段之间的距离），默认 5mm 即可
6. 确定后，视图被压缩，中间的重复段消失，尺寸标注自动保持正确（标注的仍是真实长度）

> 撤销：选中断裂视图 → 右键 → `删除断裂视图`

### 5.3 裁剪视图

只保留视图的局部，其余隐藏：

1. 在要裁剪的视图上，用草图工具画**封闭轮廓**（圆、矩形或样条曲线闭合圈）
2. 选中该封闭轮廓
3. `插入 → 工程图视图 → 裁剪视图`
4. 轮廓外的全部图线消失，仅保留轮廓内内容

> 移除裁剪：右键裁剪视图 → `裁剪视图 → 移除裁剪视图`

## 六、尺寸标注

### 6.1 模型项目（强烈推荐！）

这是工程图模块最重要的标注方式——**直接导入建模时标注的尺寸和公差**：

**操作**：`插入 → 模型项目` → 在 PropertyManager 中设置：

| 参数 | 推荐设置 | 说明 |
|:---|:---|:---|
| 来源 | **整个模型** | 导入所有特征尺寸；也可选"所选特征"只导入部分 |
| 尺寸 | ☑ 标记为图纸的尺寸 | 全部导入 |
| 注释 | 按需勾选 | 导入零件级别的注释和表面粗糙度 |
| 参考几何体 | 按需勾选 | 导入基准面、基准轴 |
| 孔标注 | ☑ 勾选 | 自动导入异形孔规格 |
| 输入到所有视图 | ☑ 勾选 | 系统自动将每个尺寸放到最合适的视图上 |

点击确认后，所有建模尺寸自动分布到各视图中。

> **后续手动整理是必须的**：自动导入的尺寸位置往往不够理想，需要手动移动、删除重复/多余尺寸、将尺寸分配至更合适的视图。但这远比手工一个个标注快得多。

### 6.2 智能尺寸（手工标注）

与草图环境操作一致，用于补充模型项目未涵盖的尺寸：

| 尺寸类型 | 操作 | 显示格式 |
|:---|:---|:---|
| **线性尺寸** | 点击两条平行线，或点击两点 | `50` |
| **直径** | 点击圆形边线 | `∅50`（自动加 ∅） |
| **半径** | 点击圆弧边线 | `R25`（自动加 R） |
| **角度** | 点击两条非平行线 | `45°` |
| **弧长** | 先点击弧的两个端点，再点击弧本身 | `⌒31.4`（带弧长符号） |
| **虚交点尺寸** | Ctrl + 同时选两条不相交的边线 → 再点"点"工具创建虚拟交点 → 以虚拟交点为基准标注 | 标注到虚拟交点的距离 |

### 6.3 倒角尺寸

SOLIDWORKS 不支持直接用智能尺寸标注 C2 格式的倒角，需用专用工具：

1. `注解 → 倒角尺寸`（需先切换到"注解"标签页）
2. 在 PropertyManager 中选择标注样式：`距离×角度` / `距离×距离` / `倒角`（即 C 格式）
3. 点击倒角边线 → 选择参考边 → 放置标注

常见倒角标注形式：`C2`（45° 倒角，两边均为 2mm）、`2×45°`、`2×2`

### 6.4 尺寸布局与整理技巧

| 操作 | 方法 |
|:---|:---|
| **对齐一组尺寸** | Ctrl + 点击多个尺寸 → 右键 → `对齐` → 选择对齐方式（共线/等距/靠左/靠右/靠上/靠下） |
| **自动排列** | 框选所有尺寸 → 右键 → `自动排列尺寸` |
| **尺寸居中** | 右键尺寸 → `显示选项 → 尺寸界线居中` |
| **移动尺寸到另一视图** | 按住 Shift 键拖拽尺寸到目标视图 |
| **隐藏/显示尺寸** | 右键尺寸 → `隐藏`（仍存在但不显示）；视图右键 → `显示隐藏的尺寸` 恢复 |
| **在尺寸值上加括号** | 选中尺寸 → PropertyManager 中勾选"基本尺寸"（括号表示参考尺寸） |

### 6.5 尺寸布局国标规范速查

| 规则 | 要求 | 参考标准 |
|:---|:---|:---|
| 尺寸线间距 | 平行尺寸线之间保持 8~10mm | GB/T 4458.4 |
| 尺寸不能标在虚线上 | 表示不可见轮廓的虚线不能作为尺寸界线的起点 | [[09-零件图\|第九章]] |
| 避免封闭尺寸链 | 不要将所有尺寸串成一个封闭环，应留一个"开口"作为参考 | 加工工艺要求 |
| 同一特征尺寸集中 | 如轴上一键槽的长×宽×深三个尺寸应集中标注在一个视图 | GB/T 4458.4 |
| 基准选择 | 设计基准与工艺基准尽量重合 | [[10-零件图技术要求\|第十章]] |

### 6.6 参考尺寸

手动添加但**不驱动模型**的尺寸，在 SOLIDWORKS 中以括号显示：

1. `智能尺寸` 标注后 → 在 PropertyManager 的"其它"标签页中勾选"参考尺寸"
2. 或在 `插入 → 模型项目` 导入后，右键尺寸 → `设为参考尺寸`

参考尺寸用于检验，告知检验员"这个尺寸是参考值，不作为判定依据"。

## 七、注解与符号（关键技术要求标注）

工程图中的技术要求通过各类符号和注解传达。参阅 [[10-零件图技术要求|第十章]] 了解各符号的国标规定。

### 7.1 中心线与中心符号线

| 类型 | 插入路径 | 适用对象 | 操作 |
|:---|:---|:---|:---|
| **中心线** | `插入 → 注解 → 中心线` | 回转体（圆柱、圆锥、孔）的视图 | 点击视图，自动分析并添加所有圆柱面的中心线 |
| **中心符号线** | `插入 → 注解 → 中心符号线` | 单个圆或圆弧 | 点击圆形边线 → 自动生成十字中心线，可拖动端点到合适长度 |

> GB 标准要求所有圆形特征必须标注中心线。中心线超出轮廓 3~5mm，由细点画线绘制。

### 7.2 表面粗糙度

**操作**：`插入 → 注解 → 表面粗糙度符号`

1. 在 PropertyManager 中选定符号类型：

| 符号 | 含义 | 用途 |
|:---|:---|:---|
| √ | **基本符号**（无横线） | 仅表示表面，不标注任何要求 |
| √̅ | **去除材料符号**（带横线） | 切削加工面——车、铣、刨、磨等 |
| √̲ | **不去除材料符号**（带圈） | 铸件、锻件、冲压件等非切削面 |

2. 在"符号布局"中输入 Ra 值（如 `Ra 1.6`）
3. 还可输入：加工方法（如"磨"）、取样长度、加工余量等
4. 点击放置——符号尖端**必须从材料外部指向被加工表面**，通常放在可见轮廓线或尺寸界线的延长线上

| 常用 Ra 值 | 对应加工方法 | 典型应用 |
|:---|:---|:---|
| Ra 25 | 粗车、粗铣 | 非配合面、毛坯面 |
| Ra 12.5 | 粗加工 | 不重要的接触面 |
| Ra 6.3 | 半精加工 | 一般配合面 |
| Ra 3.2 | 精车、精铣 | 较重要的配合面、基准面 |
| Ra 1.6 | 磨削 | 轴承位、密封面 |
| Ra 0.8 | 精磨、研磨 | 高精度配合、导轨面 |
| Ra 0.4 | 超精加工 | 精密偶件、量块 |

> **批量标注**：若零件其余表面粗糙度相同，在图样右上角标注"其余 Ra 6.3"等，避免重复标注每一个面。

### 7.3 基准特征符号

用于形位公差的基准标注：

1. `插入 → 注解 → 基准特征符号`
2. 将符号放置到基准要素上：
   - 若基准为**轮廓线**或**表面**，符号直接放在轮廓线上（三角形底部对齐轮廓线）
   - 若基准为**轴线**或**中心平面**，符号放在尺寸线的延长线上
3. 在 PropertyManager 中填写基准字母：**大写** A, B, C...（不要用 I, O, Q——易与数字混淆）
4. 拖动调整位置

### 7.4 几何公差 (GD&T) 框格

**操作**：`插入 → 注解 → 形位公差`

1. 弹出"属性"对话框，在"符号"下拉中选择几何公差符号：

| 分类 | 符号 | 名称 | 含义 |
|:---|:---|:---|:---|
| 形状 | — | 直线度 | 表面或轴线在直线方向上的变动量 |
| 形状 | □ | 平面度 | 表面在平面方向上的变动量 |
| 形状 | ○ | 圆度 | 圆截面形状的变动量 |
| 形状 | ⌭ | 圆柱度 | 圆柱面形状的变动量 |
| 方向 | ∥ | 平行度 | 相对基准的平行变动量 |
| 方向 | ⊥ | 垂直度 | 相对基准的垂直变动量 |
| 方向 | ∠ | 倾斜度 | 相对基准的角度变动量 |
| 位置 | ⊕ | 位置度 | 要素相对基准的位置变动量 |
| 位置 | ◎ | 同轴度/同心度 | 轴线相对基准轴线的偏移 |
| 位置 | ≡ | 对称度 | 中心面相对基准中心面的偏移 |
| 跳动 | ↗ | 圆跳动 | 回转一周的跳动量 |
| 跳动 | ↗↗ | 全跳动 | 连续回转的跳动量 |

2. 填写公差值（如 `0.05`），若需要加 `∅` 或 `S∅` ——如在公差值前的框中打勾
3. 填写基准字母（如 A, B, C）
4. 若需要最大实体要求（Ⓜ），在基准后点击"包容条件"选择
5. 确定后，点击要附加到的尺寸或特征

> 形位公差框格必须通过引线**附着到尺寸线**或**指向特征表面**。

### 7.5 焊接符号

`插入 → 注解 → 焊接符号` → 选择合适的焊缝形式和尺寸 → 附着到焊缝指示线。

### 7.6 孔标注

专用于异形孔向导创建的孔（简单拉伸切除的孔不适用）：

1. `插入 → 注解 → 孔标注`
2. 点击异形孔 → 自动生成完整标注，格式如：

```
4×∅10 通孔
∨∅16 ∇6
```

含义：4 个直径 10 的通孔，锪孔直径 16、深 6。

### 7.7 注释文字（技术要求）

1. `插入 → 注解 → 注释`
2. 在图纸上拖动矩形框放置文本
3. 可输入多行文字，使用菜单栏上的"堆叠"按钮写入分数形式（如 `H7/f6`）
4. **插入属性链接**：在注释文本中光标定位 → 点击 PropertyManager 中的"链接到属性"图标 → 选择属性 → 自动插入 `$PRPSHEET:"属性名"` 引用

典型技术要求内容示例：
```
技术要求
1. 未注圆角 R2~R3。
2. 热处理：调质 220~250 HBW。
3. 未注尺寸公差按 GB/T 1804-m 级执行。
4. 材料：$PRPSHEET:"Material"。
```

### 7.8 其他常用注解符号

| 符号类型 | 插入路径 | 用途 |
|:---|:---|:---|
| **基准目标** | `注解 → 基准目标` | 局部面作为基准时标记接触点/线/面 |
| **销钉符号** | `注解 → 销钉符号` | 标记定位销孔 |
| **区域剖面线/填充** | `注解 → 区域剖面线/填充` | 手工绘制剖面线或填充封闭区域 |
| **多转折引线** | 右键注释 → `添加引线` → 多段 | 需要拐弯指向时 |

## 八、材料明细表 (BOM) 与零件序号（装配图）

本节内容仅适用于装配体工程图。相关规范参考 [[11-装配图|第十一章]]。

### 8.1 插入材料明细表 (BOM)

1. 选中主视图（或任一装配体视图）
2. `插入 → 表格 → 材料明细表`
3. 在 PropertyManager 中选择模板：`bom-standard`（标准 BOM）或 `bom-no-numbers`（无序号列）
4. 选择合适的 BOM 模板后 → 点击绿色对勾
5. BOM 自动附着到标题栏上方，从下往上填充（国标要求）

**BOM 列属性**（右键 BOM → `插入 → 列` 可添加）：

| 列标题 | 对应属性 | 说明 |
|:---|:---|:---|
| 序号 | (自动编号) | 从 1 开始递增 |
| 零件号 | SW-文件名称 | 零件文件名 |
| 说明 | Description | 零件描述文字 |
| 数量 | (自动统计) | 装配体中的实例数量 |
| 材料 | Material | 零件材料属性 |
| 重量 | Weight | 单件毛重 |
| 备注 | 自定义 | 可选附加信息 |

### 8.2 排序与分组

右键 BOM → `排序` → 可按序号、零件号、说明等列排序。默认按序号升序。

### 8.3 自动零件序号

1. 选中主视图
2. `插入 → 注解 → 自动零件序号`
3. 系统自动为视图中所有零件标注带圆圈的数字序号
4. 在 PropertyManager 中选择序号排列方式：方形/圆形/靠左/靠右/靠上/靠下
5. 序号布局不满意可手动拖动单个箭头和数字

### 8.4 手动零件序号

`插入 → 注解 → 零件序号` → 逐个点击零件边线 → 拖出放置。手动方式适用于自动序号布局不理想时补漏。

### 8.5 成组零件序号

选择多个已放置的零件序号 → 右键 → `组合` → 可垂直或水平叠放，节省空间并整齐美观。

| 组合方式 | 效果 |
|:---|:---|
| 水平 | 多个序号水平排成一行，共用一个指引线 |
| 垂直 | 多个序号上下叠放，如 `④⑤⑥` 共用一个引线 |

## 九、图层的使用

### 9.1 打开图层工具栏

`视图 → 工具栏 → 图层`（勾选后图层下拉框出现在界面底部或作为独立工具栏）

### 9.2 新建图层及推荐设置

点击图层工具栏中的"图层属性" → 新建：

| 图层名称 | 颜色 | 线型 | 线宽 | 包含内容 |
|:---|:---|:---|:---|:---|
| 0 层 | 黑色 | 实线 | 0.5mm | （默认层）粗实线轮廓 |
| 细实线层 | 黑色 | 实线 | 0.25mm | 尺寸线、尺寸界线、剖面线、指引线 |
| 虚线层 | 蓝色 | 虚线 | 0.25mm | 隐藏轮廓线 |
| 中心线层 | 红色 | 点画线 | 0.25mm | 中心线、轴线 |
| 尺寸标注层 | 黑色 | 实线 | 0.25mm | 尺寸文本与箭头 |
| 文本注解层 | 黑色 | 实线 | 0.25mm | 技术要求、注释、粗糙度符号 |
| 图框层 | 黑色 | 实线 | 0.7mm | 图框外边框 |

> 线宽设置遵循 GB/T 17450：粗线 0.5~0.7mm，细线为粗线的 1/2。参考 [[01-制图基础与国家标准|第一章]]。

### 9.3 将对象移动到指定图层

1. 选中一个或多个对象（尺寸、注释、线条等）
2. 在图层下拉框中直接选择目标图层
3. 对象的颜色、线型、线宽自动按照目标图层的设置更新

### 9.4 线宽显示开关

`视图 → 线宽显示`—勾选为开启，去除勾选则在屏幕上所有线都以细线显示（仅影响屏幕显示，不影响打印）。建议出图前勾选以核对线型正确性。

## 十、导出与打印

### 10.1 导出 PDF（最常用）

`文件 → 另存为` → 保存类型选 `Adobe Portable Document Format (*.pdf)` → 点击左下角 **"选项"** 按钮（重要！必须点开）：

| 选项 | 推荐设置 | 说明 |
|:---|:---|:---|
| **嵌入字体** | ☑ 勾选 | 防止对方电脑缺少仿宋体时乱码 |
| **颜色/灰度** | **黑白** | 工程图必须选黑白——彩色线条在打印时会变灰色 |
| **高品质** | ○ 选择 | 确保线条和文字清晰 |
| **导出范围** | 全部图纸 / 当前图纸 / 所选图纸 | 多页图纸时选"全部图纸"生成一个 PDF 文件 |

### 10.2 导出 DWG/DXF（供 AutoCAD 使用）

`文件 → 另存为` → 保存类型选 `DWG (*.dwg)` 或 `DXF (*.dxf)` → 点击 **"选项"**：

| 关键设置 | 推荐值 | 说明 |
|:---|:---|:---|
| **输出版本** | AutoCAD 2013 或更低 | 提高兼容性，老版本 AutoCAD 也能打开 |
| **字体映射** | TrueType → SHX | 见下方详细说明 |
| **激活 1:1 输出** | ☑ 勾选 | 确保比例精确，不缩放 |
| **图层映射** | 使用默认映射文件 | 导线型/轮廓线→对应 AutoCAD 图层 |
| **样条曲线导出** | 样条曲线 | 不建议转为多段线，会丢失平滑度 |
| **输出所有图纸到一个文件** | ☑ 勾选（单张除外） | 每页图纸放一个模型空间 |

**字体映射建议**：

| SOLIDWORKS 字体 | 映射到 AutoCAD SHX 字体 | 理由 |
|:---|:---|:---|
| 仿宋_GB2312 | gbcbig.shx（大字体）+ gbeitc.shx | 保留仿宋风格 |
| Arial | txt.shx | 兼容性强 |
| Times New Roman | romans.shx | 罗马字体 |
| ISOCP | isocp.shx | 对应 ISO 字体 |

可在 `选项 → 导出 → 文件格式 → DWG/DXF` 中预先设置默认字体映射，避免每次导出重复配置。

### 10.3 打印设置

`文件 → 打印` → 在打印对话框中：

| 设置项 | 推荐 |
|:---|:---|
| 打印机 | 选择物理打印机或 PDF 虚拟打印机 |
| 纸张大小 | 与模板一致（A4/A3/A2/A1/A0） |
| 方向 | 纵向/横向，与图纸模板方向一致 |
| 比例 | **比例 100%**（保证 1:1 出图；如果纸张不够大，勾选"适合图纸"由打印机自动缩放） |
| 打印范围 | 全部图纸 / 当前图纸 / 所选图纸 |
| **颜色/线宽** | 勾选"黑白打印"，取消"彩色/灰度打印" |
| 线宽 | 在 `页面设置` 中可覆盖文档默认线宽 |

### 10.4 批量导出（Task Scheduler）

适用于一个项目有几十张工程图需要统一转 PDF/DWG：

1. Windows 开始菜单 → SOLIDWORKS 工具 → **SOLIDWORKS Task Scheduler**
2. 点击 `输出文件` 任务
3. 添加所有 .slddrw 文件到列表
4. 选择输出格式：PDF / DWG / DXF / eDrawings
5. 设置输出选项（与单文件导出相同）
6. 点击"完成"→ 任务加入队列自动批量执行

> Task Scheduler 可以**无人值守**运行，适合下班前提交、第二天早上收结果。

## 十一、常见问题与最佳实践

### 11.1 视图比例不一致时如何统一

**问题**：主视图设为 1:1，投影视图却继承了不同的比例。

**解决**：右键视图 → 属性 → 缩放比例 → 选择 **"使用图纸比例"** 或手动统一数值。所有相关视图可框选后统一设置。

### 11.2 剖面线不显示 / 密度不对

| 现象 | 原因 | 解决 |
|:---|:---|:---|
| 剖面线完全不出现 | "断开的剖视图"深度设为 0 | 重新设定剖切深度 |
| 剖面线过密（几乎全黑） | 比例设置太小（0.1 等） | 点击剖面线 → 比例调为 1~3 |
| 剖面线过疏（几乎看不到斜线） | 比例设置太大（10 等） | 比例调为 0.5~1 |
| 剖面线方向错误 | 未手动调整角度 | 点击剖面线 → 修改角度 |

### 11.3 尺寸悬空（Dangling Dimensions）

**现象**：工程图中某些尺寸变为**褐色/黄褐色**，无法编辑。

**原因**：三维模型中对应的边、面、特征被删除或修改，导致工程图中的尺寸引用丢失。

**解决**：
1. 点击褐色尺寸 → 右键 → `重新连接` 或 `编辑参考`
2. 将悬空的尺寸引线拖到新的边/面上重新绑定
3. 若确认不需要该尺寸 → 直接删除
4. **预防**：建模时尽量在精加工后的最终模型上出图，避免出图后再大幅修改模型结构。

### 11.4 大装配工程图性能优化

| 措施 | 操作路径 | 效果 |
|:---|:---|:---|
| **轻化模式** | 打开工程图时右下角选"轻化" | 视图只加载显示数据，不加载特征树数据，打开速度提升数倍 |
| **草稿品质视图** | 右键视图 → 品质 → 草稿品质 | 不计算隐藏线，显著加速大型装配体工程图的刷新 |
| **隐藏不需要的零部件** | 在装配体中预先压缩或用显示状态隐藏 | 减少每个视图的计算量 |
| **分离的工程图** | `文件 → 另存为` → 保存类型选"分离的工程图 (\*.slddrw)" | 脱离模型文件仍可打开查看，但不实时关联更新 |
| **减少剖面视图数量** | 用局部剖代替全剖 | 减少计算量 |

### 11.5 模板与文件管理最佳实践

| 事项 | 推荐做法 |
|:---|:---|
| 模板存放路径 | 统一放在网络共享盘或 PDM 库，所有工程师使用同一套模板 |
| 模板命名规则 | `{图幅}-{方向}-{用途}.drwdot`，如 `A4-横向-零件图模板.drwdot` |
| 文件命名规则 | `{项目代号}-{零件号}-{图号}.slddrw`，如 `ZC-01-001.slddrw` |
| 关联管理 | 工程图中参考的零件/装配体文件**使用相对路径**或**与工程图放在同一目录**，避免改名/移动后找不到参考 |
| 版本管理 | 使用 `文件 → 另存为` 保存历史版本，命名加日期后缀如 `ZC-01-001_20260101.slddrw` |

### 11.6 工程图文件与模型的关联管理

工程图（.slddrw）通过文件路径引用零件（.sldprt）和装配体（.sldasm）。当文件被重命名或移动时，关联会断开：

- 打开工程图时，若找不到参考模型，SOLIDWORKS 会弹出"文件未找到"对话框
- **修复**：点击"浏览"→ 导航到新的文件位置 → 重新关联
- **预防**：使用 SOLIDWORKS Explorer 重命名/移动文件（保留关联）；或使用 PDM 系统管理

### 11.7 定期保存提醒

工程图操作涉及大量计算（尤其剖面视图和大型装配体），SOLIDWORKS 偶尔会崩溃。养成 Ctrl+S 的习惯。建议在 `选项 → 系统选项 → 备份/恢复` 中设置自动恢复间隔为 **10 分钟**。

## 总结

SOLIDWORKS 工程图模块将三维建模与二维出图的鸿沟彻底抹平。核心工作流可以归纳为：

```
建立三维模型 → 插入标准三视图/剖视图 → 导入模型项目(尺寸+注解)
    → 手动整理/补充标注 → 填写技术要求和标题栏 → 导出 PDF/DWG → 审核下发
```

掌握本教程中的十一项核心技能，你就可以独立完成从三维模型到生产图纸的全流程。建议将日常使用中高频的操作**保存为模板和快捷键**，让工具适应你的工作习惯，而非相反。
