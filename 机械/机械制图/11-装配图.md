# 第十一章 装配图

## 11.1 装配图概述

装配图是表达机器或部件整体结构的图样。与[[09-零件图|第九章]]的零件图不同，装配图反映的不是单个零件的结构，而是**零件之间的装配连接关系、部件的工作原理、传动路线以及主要零件的结构形状**。

装配图的作用可概括为：
- **指导装配**：工人依据装配图将各零件组装成部件或整机
- **指导检验**：技术部门依据装配图中的配合关系和技术要求进行装配质量检验
- **指导安装与维修**：用户和维修人员依据装配图进行设备的安装、调试与拆卸维修

一张完整的装配图必须包含以下四个方面的内容：

| 序号 | 内容 | 说明 |
|:---:|------|------|
| ① | 一组视图 | 表达装配体的装配关系、工作原理和主要零件的结构形状。通常包括主视图（反映主要装配关系）和各方向的辅助视图 |
| ② | 必要的尺寸 | 仅标注性能规格尺寸、装配尺寸、安装尺寸和总体尺寸，**不是零件的全部定形定位尺寸** |
| ③ | 技术要求 | 用文字或符号说明装配要求、检验要求、试验规范、使用注意事项等 |
| ④ | 零件序号、标题栏和明细栏 | 对所有零件编号并在明细栏中列出名称、数量、材料等信息，形成物料清单（BOM） |

装配图中每个零件都应有一个**序号**，通过指引线连接到对应零件上。标题栏和明细栏位于图幅右下角，明细栏按序号列出全部零部件的详细信息。这一套编号与列表体系在[[#11.5 装配图中的序号与明细栏|11.5 节]]中详细说明。

## 11.2 装配图的表达方法

装配图的表达方法与[[07-机件表达方法|第七章]]所述的零件图表达方法有显著区别：**零件图是一个零件的多视图，装配图是多个零件在同一视图上的组合表达**。

### 11.2.1 一般表达方法

在装配图中，多个零件投影在同一视图内，需要合理处理遮挡关系。被遮挡的零件轮廓用虚线表示或省略不画，以保持图面清晰。优先表达装配关系和工作原理，次要结构可适当简化。

### 11.2.2 规定画法

规定画法是制图标准中对于装配图表达的统一要求，必须严格遵守：

**（1）剖面线区分法**

相邻两零件的剖面线必须有所区别：剖面线的方向相反，或方向相同但间距不同。同一零件在所有视图中的剖面线必须方向相同、间距一致，这是读者识别同一零件在不同视图中投影的关键依据。

**（2）实心件不剖处理**

对于**实心零件**，当剖切平面通过其轴线纵向剖切时，这些零件按**不剖**处理，即不画剖面线，只画外形轮廓。这些实心件包括：轴（shaft）、销（pin）、键（key）、螺栓（bolt）、螺钉（screw）、螺母（nut）、垫圈（washer）、球（ball）等。圆标件明细见[[08-标准件与常用件|第八章]]。

**（3）紧固件和实心件**的纵向剖切均不画剖面线，但当需要表达其内部结构（如孔、槽）时可采用局部剖。

### 11.2.3 剖面线的画法要点

装配图中剖面线不仅起区分材料的作用，更是**区分不同零件**的标识手段。两个配合零件的剖面线关系示例如下：

```
零件A：   ╱ ╱ ╱ ╱ ╱ ╱   (方向：45° 右斜)
零件B：   ╲ ╲ ╲ ╲ ╲ ╲   (方向：45° 左斜，与A相反)

或

零件A：   ╱ ╱ ╱ ╱ ╱ ╱   (间距：3mm)
零件B：   ╱  ╱  ╱  ╱  ╱   (方向同A，间距更宽)
```

## 11.3 装配图的特殊表达方法

除了规定画法外，装配图还有一系列特殊的表达方法，用于简化复杂装配结构的表达。

### 11.3.1 沿结合面剖切

将剖切平面沿两个零件的**接触面（结合面）**进行剖切。此时，接触面上不画剖面线（因为剖切面在接触面上，未切割实体），而其他被切割的零件仍画剖面线。这种方式能清晰表达接触面两侧零件的形状关系。

### 11.3.2 拆卸画法

假想地拆去装配体中的某个或某几个零件，单独画出剩余部分的视图。在图上须标注"拆去件×"（如"拆去件3、件4"）。由于拆去的零件未画出，其遮挡的零件得以暴露，便于表达内部结构。

### 11.3.3 单独表示某一零件

当装配图中某零件的结构表达不够清楚时，可在装配图外适当位置单独画出该零件的某个视图（如单独再画一个局部视图或向视图），并标注该零件的序号或名称。类似于零件图的补充视图，但画在装配图中。

### 11.3.4 假想画法

用**双点画线**（—··—··—）绘制两类内容：
- **不属于本部件但相关的相邻零部件**的轮廓，如与本装配体相连接的另一部件的外形
- **运动件的极限位置**，如手柄运动的两个端点位置、摇臂的摆动范围

这一方法与[[07-机件表达方法|第七章]]中局部视图的假想画法概念一致。

### 11.3.5 夸大画法

对于装配体中的薄垫片、微小间隙、锥度很小的锥面等结构，若按真实比例绘制将无法清晰辨认，允许**不按比例而适当夸大**画出，以增强图纸的可读性。

### 11.3.6 简化画法

装配图中的简化画法包括：
- 若干相同零件组（如螺栓连接组）只详细画出**一处**，其余用中心线（点画线）标出其位置并加注明
- 零件上的倒角、圆角、退刀槽等次要结构可省略不画
- 滚动轴承可按简化画法表示（详见[[08-标准件与常用件|第八章]]）
- 零件上的工艺结构（如铸造圆角、拔模斜度）通常不表示

## 11.4 装配图上的尺寸标注

装配图中的尺寸标注与[[09-零件图|第九章]]有本质区别：**装配图不标注零件的全部定形尺寸和定位尺寸**，而只标注与装配体整体相关的四类重要尺寸。下表总结四类尺寸及其意义：

| 类别 | 含义 | 典型示例 |
|------|------|----------|
| **性能（规格）尺寸** | 反映机器或部件性能规格的尺寸，是最先确定的参数 | 泵的进出口直径、阀门的公称通径、减速器的中心距 |
| **装配尺寸** | 保证零件间配合关系和相对位置精度的尺寸 | 配合尺寸（如 $\Phi 30\frac{H7}{f6}$）、中心距、零件间相对位置尺寸 |
| **安装尺寸** | 将部件安装在基础上或与其他部件连接所需的尺寸 | 地脚螺栓孔距、安装螺栓孔直径、安装底面到轴中心的高度 |
| **总体尺寸** | 部件的外形轮廓尺寸，用于包装、运输、安装空间规划 | 总长 $L$、总宽 $W$、总高 $H$ |

四类尺寸的标注原则：
- 性能尺寸和总体尺寸是**必需标注**的
- 装配尺寸中的配合代号必须按标准格式标注：$\text{基本尺寸}\frac{\text{孔公差带代号}}{\text{轴公差带代号}}$，例如 $\Phi 50\frac{H8}{h7}$
- 安装尺寸对于需要固定安装的部件必须标注
- 公差与配合的详细规定参见[[10-零件图技术要求|第十章]]

## 11.5 装配图中的序号与明细栏

### 11.5.1 零部件的序号编排

装配图中所有零件和部件都必须编注序号，编制规则如下：

| 规则 | 具体要求 |
|------|----------|
| 唯一性 | 同一种零件（相同的形状、尺寸、材料）在图上使用**同一序号**，且只标注一次 |
| 书写位置 | 序号写在指引线末端的**水平短线上方**或**小圆内** |
| 排列方式 | 按**顺时针**或**逆时针**方向整齐排列在视图外侧，便于查找 |
| 指引线要求 | 指引线不能相互交叉；当其末端指到的零件剖面很薄（如垫片）时，末端应画**实心圆点**（·） |
| 分组编号 | 标准件（如螺栓、螺母、轴承）可统一标注或按标准号分组标注 |

序号的标注样式示例（两种常见形式）：

```
方式一（水平短线）:                方式二（小圆）:
                                
    5 ─────────               ───────── ⑤
       ╲                           ╱
        ╲                         ╱
         ╲                       ╱
          ╲                     ╱
  ┌─────────┐              ┌─────────┐
  │  零件   │              │  零件   │
  └─────────┘              └─────────┘
```

### 11.5.2 明细栏（BOM）的格式与填写

明细栏（Bill of Materials, BOM）位于标题栏正上方，按**自下而上**的顺序逐行填写（序号小的在下方，序号大的在上方）。这样编排便于在设计过程中增补新的零件条目而不必整体重排。

明细栏的标准格式（简化示意）：

```

├────┼──────────┼────────────────┼────┼──────┼──────┼──────┤
```

明细栏各列说明：
- **序号**：与装配图上指引线的序号对应，自下而上编排
- **代号**：零件的图号或标准号（标准件填国标代号）
- **名称**：零件的名称（如泵体、齿轮轴、深沟球轴承）
- **数量**：该零件在装配体中的总件数
- **材料**：零件的材料牌号（如HT200、45钢、Q235）
- **重量**：单件重量（非必需时可省略）
- **备注**：用于附加说明（如表面处理要求、来源信息等）

明细栏填写规则：
1. 序号**自下而上**递增
2. 标准件在备注栏注明"标准件"或写国标号
3. 重量列可根据需要保留或省略
4. 明细栏外框线用粗实线，内部分隔线用细实线

## 11.6 装配结构的合理性

装配结构的设计不仅要满足功能要求，还要确保装拆方便、加工经济。以下是装配结构合理性的常见原则：

### 11.6.1 避免过约束

两个零件在**同一方向**（如轴向）不应当有两组接触面同时约束。只保留一组接触面起到定位作用即可，其余位置留出间隙。过约束会导致装配困难，甚至无法装配。

### 11.6.2 接触面转角处需有退让

两零件接触面的转角处不得直接紧贴尖角，而应有**退刀槽**或**倒角让位**，以便于刀具走刀和零件顺利装配：

```
不合理设计:          合理设计 (有退刀槽):
┌─────┐              ┌─────┐
│     │  ┌──┐        │     │  ┌──┐
│   ┌─┼──┘  │        │   ┌─┼─┐│  │
│   └─┼──┐  │        │   │ └─┘│  │
│     │  └──┘        │   │    └──┘
└─────┘              └───┘
  接触角无退让           有退刀槽
```

### 11.6.3 轴端与孔的配合处应有引导锥

在轴端装入孔的配合面上，轴端外圆应倒角或加工成锥面作为**引导锥**，便于轴顺利滑入孔中而不损坏配合面。

### 11.6.4 接触面数量尽可能少

装配接触面的数量应尽可能减少。过多接触面不但增加加工难度和成本，还会因加工误差累积导致装配精度下降。结构设计应以**最少的接触面满足功能需求**。

### 11.6.5 其他合理性要求

- **便于装拆**：紧固件周围应留有足够的扳手空间；需经常拆卸的零件不宜用过盈配合
- **便于维修**：易损件（密封件、轴承等）应设计为可独立更换的结构
- **定位可靠**：关键零部件应有稳定的定位基准面

如果使用三维装配软件进行装配结构校验，参见 [[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]] 中的装配体干涉检查和运动仿真方法。

## 11.7 读装配图与拆画零件图

读装配图是机械工程师的基本功，目的是从装配图中获取以下信息：部件的工作原理、各零件之间的装配连接关系、以及各零件的主要结构形状。

### 11.7.1 读装配图的方法与步骤

| 步骤 | 名称 | 任务 | 方法 |
|:---:|------|------|------|
| ① | 概括了解 | 了解部件名称、用途、零件总数和类型 | 看标题栏获取部件名称，看明细栏统计零件总数、标准件数量和主要零件的材料 |
| ② | 分析视图 | 搞清楚用了哪些视图及它们之间的对应关系 | 确定主视图的投射方向和表达重点；识别各辅助视图的类型（全剖/半剖/局部剖/向视图等）及其表达内容 |
| ③ | 分析工作原理与装配关系 | 理解动力传递路线和零件配合关系 | 从**运动输入端**（如齿轮轴、电机轴）出发，沿传动路线逐一分析各零件的作用和相互间的配合关系；关注配合代号判断配合性质 |
| ④ | 分析零件形状 | 分离出每个零件在各视图中的投影轮廓 | 利用**剖面线方向与间距**区分不同零件；利用**序号和指引线**定位零件；将被遮挡后隐藏的轮廓线补充完整 |
| ⑤ | 综合归纳 | 形成对装配体的完整认识 | 将以上各步的分析结果综合，形成对装配体结构、原理和性能的整体认识 |

### 11.7.2 按剖面线区分零件的技巧

剖面线是读装配图时最重要的零件识别标志。识别技巧：
- 同一零件的剖面线方向相同、间距一致（跨视图也一致）
- 相邻两接触零件的剖面线必不相同（方向不同或间距不同）
- 实心标准件（轴、销、键、螺栓、螺钉、螺母）沿轴向不画剖面线

### 11.7.3 拆画零件图

当需要从装配图中获取某零件的独立加工图时，就要进行**拆画**。

拆画零件图的步骤：
1. **分离轮廓**：从装配图各视图中，利用剖面线和序号辨认出目标零件在各视图中的投影轮廓
2. **补全线条**：补充被其他零件遮挡而未能表现的轮廓线、转向线等
3. **确定视图方案**：选择最能表达该零件结构特征的方向作为主视图，必要时调整视图配置
4. **完整标注尺寸**：按照[[09-零件图|第九章]]的要求标注零件的全部定形尺寸、定位尺寸和总体尺寸
5. **标注技术要求**：按照[[10-零件图技术要求|第十章]]的要求标注尺寸公差、形位公差、表面粗糙度和文字技术要求
6. **补全内容**：绘制标题栏，填写零件名称、材料、比例等信息

### 11.7.4 读图实例：齿轮油泵

以齿轮油泵装配图为例，展示完整的读图过程：

**（1）概括了解**

从标题栏得知该部件为"齿轮油泵"（gear oil pump），从明细栏得知共由约15个零件组成，包括泵体、泵盖、主动齿轮轴、从动齿轮轴、轴承、密封件、紧固件等。泵体、泵盖材料为HT200（灰铸铁），齿轮轴材料为45钢。

**（2）分析视图**

装配图采用三个视图：
- 主视图：通过主动齿轮轴轴线作全剖，表达油泵内部齿轮啮合情况和泵体、泵盖的装配关系
- 俯视图：不加剖切，表达泵的外形和进出口法兰位置
- 左视图：通过从动齿轮轴轴线作全剖，进一步表达两齿轮轴的定位和轴承安装结构

**（3）分析工作原理**

工作过程：
- 外部动力通过主动齿轮轴（序号5）输入，带动主动齿轮旋转
- 主动齿轮驱动从动齿轮（序号6）反向旋转
- 在吸入腔（进油口一侧），两齿轮齿退出啮合，齿间容积增大，形成低压，将油液从进油口吸入
- 油液随齿轮旋转被带到排油腔（出油口一侧）
- 在排油腔，两齿轮齿进入啮合，齿间容积减小，将油液从出油口压出
- 轴承（序号4）支撑两齿轮轴，泵盖与泵体之间以密封垫片（序号7）保证密封

传动路线：主动齿轮轴 → 主动齿轮（与从动齿轮啮合）→ 从动齿轮 → 从动齿轮轴

**（4）分析装配关系**

关键配合关系：
- 主动齿轮轴与泵体孔的配合：$\Phi 20\frac{H7}{f6}$（间隙配合，保证轴能灵活旋转）
- 两齿轮轴的中心距：$a = 36 \pm 0.02\text{ mm}$
- 泵盖与泵体的配合：止口配合，轴向由螺栓连接压紧密封垫片

**（5）分析零件形状**

利用剖面线分离各零件主要结构。例如：泵体（序号2）为具有进出油口法兰的壳形铸件，有两个平行孔用于安装齿轮轴。泵盖（序号8）为带轴承孔的板状件，与泵体合箱后形成齿轮工作腔。

**（6）拆画从动齿轮轴零件图**

如果要从装配图中拆画从动齿轮轴（序号6），过程是：
- 在主视图和左视图中分离出从动齿轮轴的投影轮廓（其剖面线方向与泵体和齿轮不同）
- 补全被泵体和齿轮遮挡的轮廓线
- 按零件图标准标注轴各部分直径、长度、键槽尺寸及公差
- 标注表面粗糙度：轴颈 $\Phi 20\frac{H7}{f6}$ 处 $Ra\;1.6$，其余 $Ra\;6.3$

## 总结

装配图是表达机器或部件整体结构关系的核心工程图样。本章从装配图的内容构成入手，系统介绍了装配图的规定画法与特殊表达方法，明确了装配图上四类尺寸的标注原则，详细说明了零件序号编排和明细栏的填写规则，并讨论了装配结构的合理性要求，最后以读装配图和拆画零件图作为应用能力的落脚点。

装配图与零件图的关系可以概括为：
- 零件图是**制造**的依据：一人一图，标注全部尺寸和技术要求
- 装配图是**组装**的依据：多件共图，标注装配关系和连接尺寸
- 装配图由零件图拆分投影而来，零件图可以从装配图拆画还原

掌握读装配图和拆画零件图的能力，是学习机械设计的核心目标之一。在实际工作中，使用 [[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]] 等三维CAD软件可以高效完成装配建模、干涉检查、运动仿真和自动生成明细栏的工作，大幅提升设计效率。
