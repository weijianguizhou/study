# 第七章 机件表达方法

在工程实际中，机件的结构形状千变万化。仅凭三视图（参见[[03-投影基础|第三章]]）往往无法将复杂机件的内外结构表达得既清晰又完整。国家标准《技术制图》和《机械制图》规定了一整套机件表达方法，包括视图、剖视图、断面图、局部放大图和简化画法等。正确选用和灵活组合这些表达方法，是机械制图的核心技能。

## 7.1 视图

视图是机件向投影面投射所得的图形，主要用于表达机件的外部形状。按投射方向和范围的不同，分为基本视图、向视图、斜视图和局部视图。

### 7.1.1 基本视图

国标规定以正六面体的六个面作为基本投影面。将机件置于六面体中央，分别向六个面进行投射，得到六个基本视图：

| 视图名称 | 投射方向 |
|----------|----------|
| 主视图 | 从前向后 |
| 俯视图 | 从上向下 |
| 左视图 | 从左向右 |
| 右视图 | 从右向左 |
| 仰视图 | 从下向上 |
| 后视图 | 从后向前 |

**展开方式**：正立投影面（主视图所在面）保持不动，其余五个投影面按国标规定方向旋转展开，最终与正立投影面共面。展开后的配置关系如下：

```
                  (仰视图)
(右视图)      (主视图)      (左视图)      (后视图)
                  (俯视图)
```

**配置口诀**：主视图居中定，俯视图正下方，左视图正右方，右视图正左方，仰视图正上方，后视图在左视图正右方。

各视图之间应保持投影对应关系——"三等关系"：
- 主视图与俯视图、仰视图：**长对正**
- 主视图与左视图、右视图：**高平齐**
- 俯视图、仰视图与左视图、右视图：**宽相等**

当基本视图严格按照上述配置关系放置时，无需标注视图名称。

### 7.1.2 向视图

向视图是可以自由配置的基本视图。当基本视图因图幅限制不能按标准配置放置时，必须进行标注。

**标注方法**：在相应视图附近用箭头（细实线）指明投射方向，箭头旁注写大写拉丁字母；在向视图上方注写相同的字母，格式为 "$X$ 向"。箭头应垂直于所指视图的轮廓线。

**示例**：若将右视图移至图纸空白处，应在主视图左侧画箭头并注 "$A$"，右视图上方注 "$A$ 向"。字母按水平方向书写，无论箭头指向何方。

### 7.1.3 斜视图

将机件向不平行于任何基本投影面的辅助投影面投射，所得的视图称为斜视图。

**适用场景**：机件上有倾斜结构，在基本视图中无法反映该部分的真实形状。

**画法与标注**：斜视图只需画出倾斜结构的实形，其余部分用波浪线断开省略。标注方式与向视图相同（箭头 + 字母）。若斜视图经过旋转放置以方便读图，应在字母旁加注旋转箭头，并在图下方注明"（旋转）"字样。

### 7.1.4 局部视图

将机件的某一部分向基本投影面投射所得的视图称为局部视图。

**适用场景**：机件的主要形状已在其他视图中表达清楚，仅个别局部结构需要补充表达时使用，避免了画完整的视图。

**画法要点**：
- 断裂边界用**波浪线**表示
- 波浪线不得超过机件外轮廓，不得穿过孔、槽等中空部分
- 当表达结构的外围轮廓完整且封闭时，波浪线可省略

**标注**：用箭头 + 字母指明部位和方向，局部视图上方注写对应字母。

## 7.2 剖视图

### 7.2.1 剖视图的基本概念

当机件内部结构复杂时，视图中的虚线会大量堆积，使图形难以辨认。此时应采用剖视图来表达内部结构。

**定义**：假想用剖切面剖开机件，将处在观察者与剖切面之间的部分移去，将剩余部分向投影面投射，所得的图形称为剖视图（简称剖视）。

**要点**：剖切是假想的，一个视图取剖视后不影响其他视图的完整性，其他视图仍按完整机件绘制。

剖切面与机件材料接触的部分称为剖面区域，在剖面区域内必须画上剖面符号。

### 7.2.2 剖面符号

国标规定，金属材料的剖面符号为与水平方向成 $45^\circ$ 的细实线（剖面线），线间距约 $2 \sim 6$ mm，要求均匀等距。

| 材料类别 | 剖面符号 |
|----------|----------|
| 金属材料（通用） | $45^\circ$ 等间距细实线 |
| 非金属材料 | 双向 $45^\circ$ 细实线（网格状） |
| 线圈绕组元件 | 垂直于绕线方向的细实线 |
| 玻璃及透明材料 | 双向 $45^\circ$ 等间距细实线 |

**关键规则**：
- 同一零件各视图中的剖面线方向和间距必须一致
- 相邻零件的剖面线应取不同方向或不同间距，以区分不同零件
- 当图形主要轮廓线为 $45^\circ$ 时，剖面线可改为 $30^\circ$ 或 $60^\circ$

### 7.2.3 剖视图的标注

剖视图的标注包含三个要素，缺一不可（特殊情况除外）：

| 标注要素 | 图形符号 | 说明 |
|----------|----------|------|
| 剖切符号 | 粗短画线（线宽 $\approx 1.5b$，长 $5 \sim 10$ mm） | 标在剖切面的起讫处，不与轮廓线相交 |
| 投射方向 | 箭头 | 画在起讫处粗短画线的外侧，垂直于粗短画线 |
| 字母 | 大写拉丁字母（$A$、$B$ 等） | 注写在箭头外侧和剖视图上方，格式为 "$A-A$" |

标注流程：

```
粗短画线 → 箭头 → 字母 → 剖视图上方标注"A-A"
```

多条剖视图在同一图纸上时，字母按顺序使用（$A-A$、$B-B$、$C-C$ ……），不得重复。剖切符号的粗短画线应画在轮廓线之外，不与图形的轮廓线相交。

**省略标注的条件**：
1. 剖视图按投影关系配置且中间无其他图形隔开时，可省略箭头
2. 单一剖切面通过机件对称平面且剖视图按投影关系配置时，可完全省略标注

### 7.2.4 画剖视图的注意事项

1. 剖切是假想的——一个视图取剖视后，其他视图仍按完整机件画出
2. 剖视图中一般不再画虚线，除非画某些虚线有助于读图
3. 剖面区域后方可见的轮廓线必须画全，绝不可遗漏
4. 剖切面后的可见轮廓线应全部画出，不要只画断面

## 7.3 剖视图的种类

根据剖切范围的不同，剖视图分为全剖视图、半剖视图和局部剖视图三种。

| 种类 | 剖切范围 | 适用条件 | 标注 | 典型示例 |
|------|----------|----------|------|----------|
| 全剖视图 | 完全剖开机件 | 外形简单、内部结构复杂 | 需标注（特殊情况可省略） | 圆筒、轴承座、箱体 |
| 半剖视图 | 对称中心线为界，一半视图一半剖视 | 内、外形均需表达，且机件对称 | 标注同全剖视图 | 对称壳体、法兰盘 |
| 局部剖视图 | 局部剖开，波浪线分界 | 表达局部内部结构需要 | 一般不标注 | 孔、槽、螺纹孔 |

### 7.3.1 全剖视图

用剖切面将机件完全剖开所得的剖视图。

**适用条件**：机件的外形简单（外形已在其他视图中表达清楚），但内部结构比较复杂（如阶梯孔、异形孔、肋板分布等）。

**画法**：剖切面一般通过机件的前后对称平面（或左右对称平面），将机件分为前后两半，移去前半部分，将后半部分向正立投影面投射。

### 7.3.2 半剖视图

当机件具有对称平面时，以对称中心线为界，一半画成视图（表达外形），另一半画成剖视图（表达内部），称为半剖视图。

**适用条件**：内、外形均需表达，且机件对称或基本对称。

**画法要点**：
- 视图与剖视的分界线必须是**细点画线**（对称中心线），绝不能用粗实线
- 视图的一半原则上不画虚线，剖视一半中已表达清楚的内部结构对应的虚线应省略
- 标注直径尺寸时，尺寸线应略超过对称中心线并只画一个箭头

**优势**：一个图形同时表达内外形状，经济高效。

### 7.3.3 局部剖视图

用剖切面局部地剖开机件所得的剖视图。剖切范围与外形之间用波浪线分界。

**适用条件**：
- 仅局部内部结构需要表达
- 机件不对称，不宜用半剖
- 对称机件的轮廓线与对称中心线重合时（此时全剖和半剖都会丢失信息）

**画法要点**：
- 波浪线表示断裂边界，不得超过机件轮廓线
- 波浪线不得穿过孔、槽等中空部位
- 局部剖视图一般不标注剖切位置

**最大优势**：灵活方便，同一视图中可画出多处局部剖视，互不影响。

## 7.4 剖切面的种类

根据机件结构特点，可选用不同形式的剖切面。国标规定了三种剖切面：

| 剖切面种类 | 剖切面形式 | 特点 | 标注要点 | 典型应用 |
|------------|------------|------|----------|----------|
| 单一剖切面 | 一个平面 | 最常用，平行于基本投影面 | 通过对称面时可省略标注 | 通用 |
| 几个平行的剖切平面 | 多个平行的平面 | 阶梯状转折 | 转折处须标注字母 | 多层多孔结构 |
| 几个相交的剖切平面 | 多个相交的平面 | 旋转后投射 | 起讫处须完整标注 | 盘类、摇臂类零件 |

### 7.4.1 单一剖切面

用一个剖切平面剖开机件的方法，是最基本、最常用的剖切方式。

剖切面一般为平行于基本投影面的平面（正平面、水平面或侧平面）。也可采用倾斜于基本投影面的剖切面，此时获得斜剖视图，可按投影关系或旋转后绘制。

当单一剖切面通过机件的对称平面且剖视图按投影关系配置时，标注可完全省略。

关于肋板和轮辐：当剖切面沿肋板或轮辐的**纵向**（长度方向）剖切时，剖到区域不画剖面符号，用粗实线将肋板与相邻部分分开。沿**横向**剖切时，仍须画剖面符号。此规定与[[05-组合体|第五章]]中的画法不同。

### 7.4.2 几个平行的剖切平面（阶梯剖）

用两个或多个互相平行的剖切平面剖开机件的方法。各剖切面在转折处以直角连接。

**标注**：起讫处和每一转折处均须画粗短画线并注写相同字母，起讫处加箭头指明方向。剖视图上方标注 "$A-A$"。

**注意事项**：
1. 转折处不应与视图的轮廓线重合或相交
2. 转折处在剖视图中不画分界线
3. 应避免剖出不完整的结构要素

**应用**：机件内部结构分布在几个互相平行的平面上时使用，如多级台阶孔、不同高度的孔组等。

### 7.4.3 几个相交的剖切平面（旋转剖）

用两个或多个相交的剖切平面（其交线垂直于某一基本投影面）剖开机件的方法。剖切后将倾斜剖切面绕交线旋转到与投影面平行，再投射。

**操作流程**：先剖开 → 再旋转 → 后投射。

**标注**：起讫处画粗短画线、箭头和字母，转折处也画粗短画线，剖视图上方标注 "$A-A$"。

**典型应用**：
- 盘类零件（法兰盘、端盖、带轮）：表达沿圆周分布的孔和肋
- 摇臂、支架类零件：表达倾斜臂的断面形状

**注意**：位于剖切面后方、未被剖切的结构应按原位置投射，不随剖切面旋转。

## 7.5 断面图

### 7.5.1 断面图的概念

**定义**：假想用剖切面将机件的某处切断，仅画出该剖切面与机件接触部分（即断面）的图形，称为断面图（简称断面）。

断面图与剖视图的区别：

| 对比项 | 剖视图 | 断面图 |
|--------|--------|--------|
| 图形内容 | 断面 + 断面后方可见轮廓线 | **仅**断面形状 |
| 表达重点 | 内部结构整体 | 断面的局部形状 |
| 应用场景 | 整体或半整体内部结构 | 局部断面形状（轴槽、轮辐等） |

**记忆口诀**："剖视图画切面后的全部，断面图只画切断的面。"

断面图分为移出断面图和重合断面图两种。

### 7.5.2 移出断面图

画在视图之外的断面图称为移出断面图。

**画法**：
- 轮廓线用**粗实线**绘制
- 尽量画在剖切符号的延长线上
- 图形对称时可画在视图的中断处

**标注规则**：

| 断面位置 | 断面形状 | 标注要求 |
|----------|----------|----------|
| 剖切符号延长线上 | 对称 | 完全不标注 |
| 剖切符号延长线上 | 不对称 | 剖切符号 + 箭头，不注字母 |
| 其他任意位置 | 不限 | 完整标注（剖切符号 + 箭头 + 字母） |

**特殊处理**：
- 当剖切面通过回转面形成的孔或凹坑的轴线时，断面图按剖视图绘制（画出孔后的轮廓线）
- 当剖切面通过非圆孔导致断面完全分离时，也按剖视图绘制

**典型应用**：轴类零件上键槽的断面、销孔断面、轮辐断面、手柄断面等。

### 7.5.3 重合断面图

画在视图之内的断面图称为重合断面图。

**画法**：
- 轮廓线用**细实线**绘制（区别于移出断面的粗实线）
- 直接画在视图中的剖切位置上
- 当视图轮廓线与重合断面重叠时，视图轮廓线应连续画出，不可中断

**标注**：重合断面图一般不需标注。

移出断面与重合断面对比：

| 对比项 | 移出断面图 | 重合断面图 |
|--------|------------|------------|
| 位置 | 视图之外 | 视图之内 |
| 轮廓线 | 粗实线 | 细实线 |
| 标注 | 一般需标注 | 一般不标注 |
| 清晰度 | 高，不遮挡视图 | 可能遮挡视图轮廓 |
| 适用 | 重要或复杂的断面 | 简单的断面（角钢截面等） |

## 7.6 局部放大图

### 7.6.1 定义与用途

将机件上部分细小复杂的结构用大于原图形比例画出的图形，称为局部放大图。

**用途**：机件上的细小结构（小孔、小槽、退刀槽、细小圆角等）在原视图上难以表达清楚，也不便标注尺寸时使用。

### 7.6.2 标注方法

1. 在原视图上，用**细实线圆**（或长圆形）圈出需要放大的部位
2. 当有多处需要放大时，用罗马数字编号（$\mathrm{I}$、$\mathrm{II}$、$\mathrm{III}$ ……）
3. 在局部放大图的上方注写对应罗马数字和比例：

$$ \mathrm{I} \quad 2:1 $$

### 7.6.3 比例的含义

局部放大图上标注的比例，是指放大图中图形尺寸与**实物实际尺寸**之比，**而非**与原图图形尺寸之比。

实例：若原图比例为 $1:5$，局部放大图标注 $2:1$，则放大图上的图形大小是实物的 $2$ 倍，是原图上图形的 $10$ 倍。

局部放大图可根据需要画成视图、剖视图或断面图，与被放大部位的原表达方式无关。

## 7.7 简化画法

国标规定了一系列简化表达方法，在保证图样清晰无误的前提下，减少绘图工作量，提高效率。

### 7.7.1 相同结构的简化

当机件上有若干相同的结构（孔、槽、齿等）按一定规律分布时，只需完整画出 $1 \sim 2$ 个，其余用中心线或细实线表示分布范围，并在图上注明总数。例如：法兰盘上 $6 \times \phi 10$ 均布孔，画出 $1 \sim 2$ 个即可。

### 7.7.2 对称图形的简化

对称机件的视图可只画一半或四分之一，在对称中心线的两端画出两条与之垂直的短平行细实线（对称符号）。此法相当于将半剖视图的思路推广到所有对称视图。

### 7.7.3 肋板与轮辐的剖视处理

- **纵向剖切**（剖切面沿肋/轮辐的长度方向）：剖到的肋/轮辐上**不画剖面符号**，用粗实线将肋与相邻部分分开
- **横向剖切**（剖切面垂直于肋/轮辐的长度方向）：正常画出剖面符号

判断依据：确认剖切面是沿结构长度方向（纵向）还是垂直长度方向（横向）。

### 7.7.4 均匀分布孔的画法

回转体上沿圆周均匀分布的孔组，若不在剖切面上，可将孔旋转到剖切面上画出，并注明数量。此法省略了额外的向视图或剖视图，且无需附加标注。

### 7.7.5 较长机件的折断画法

较长机件（轴、杆、型材等）沿长度方向形状一致或有规律变化时，可断开后缩短绘制，断裂处画波浪线或折断线。标注尺寸时，仍按**实际长度**标注。

### 7.7.6 小结构的省略

- 小圆角（$R \leq 0.5$ mm）、小倒角（$C \leq 0.5$ mm）在视图中可省略不画，但须在技术要求中用文字注明
- 小的相贯线和截交线，在不影响真实感的前提下可用直线或圆弧代替

### 7.7.7 平面的简化表示

当需要在视图中指明某一面为平面时，可在该平面图形内画出两条相交的**细实线对角线**。例如，圆柱体上的扁平面（扳手夹持面），在圆的图形内画两条相交细实线即表示该处为平面。

## 总结

本章介绍的机件表达方法是机械制图课程中实用性最强、内容最丰富的一章。

**核心知识框架**：

| 表达方法类别 | 核心功能 | 具体方法 |
|--------------|----------|----------|
| 视图 | 表达**外形** | 基本视图、向视图、斜视图、局部视图 |
| 剖视图 | 表达**内部结构** | 全剖、半剖、局部剖 + 单一剖/阶梯剖/旋转剖 |
| 断面图 | 表达**断面形状** | 移出断面、重合断面 |
| 局部放大图 | 表达**细小结构** | 局部放大 |
| 简化画法 | **提高效率** | 相同结构、对称图形、折断画法等 |

**选择表达方案的原则**：
1. 先用基本视图，尽量少用辅助视图
2. 内部结构复杂优先用剖视（全剖或半剖）
3. 局部问题局部解决（局部剖、局部视图）
4. 断面图用于表达轴类、轮辐类零件的断面
5. 细小结构用局部放大图
6. 在保证清晰的条件下合理使用简化画法
7. 用尽量少的视图完整、清晰地表达全部形状——"少而精"

**常见错误提醒**：
- 半剖视图的分界线错用粗实线（正确：细点画线）
- 剖面线方向在同一零件不同视图中不一致
- 波浪线穿过孔洞或超出轮廓线
- 肋板纵向剖切时误画剖面符号
- 断面图按剖视图绘制，多画了后方轮廓
