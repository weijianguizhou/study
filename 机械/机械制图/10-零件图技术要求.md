# 第十章 零件图技术要求的标注

零件图不仅要表达零件的结构形状和尺寸，还要标注制造和检验所需的技术要求。在前两章 [[08-标准件与常用件|第八章]] 和 [[09-零件图|第九章]] 中已学习了零件图的视图表达和尺寸标注，本章介绍表面粗糙度、极限与配合、几何公差及其他技术要求的标注方法。

## 10.1 表面粗糙度

### 定义与评定参数

表面粗糙度是指零件加工表面上由较小间距和峰谷组成的微观几何形状误差。它与宏观几何误差（形状误差）和中间几何误差（波纹度）一起构成零件的表面形貌。

最常用的评定参数是**轮廓算术平均偏差** $Ra$，单位为 μm：

$$Ra = \frac{1}{n}\sum_{i=1}^{n}|y_i| \approx \frac{1}{l}\int_{0}^{l}|y(x)|dx$$

即在取样长度 $l$ 内，轮廓偏距绝对值的算术平均值。其他常用参数包括 $Rz$（微观不平度十点高度）和 $Ry$（轮廓最大高度）。

### $Ra$ 值与表面特征对照表

| $Ra$ (μm) | 表面特征 | 加工方法举例 | 应用实例 |
|:---:|:---|:---|:---|
| 50 | 粗糙，可见明显刀痕 | 粗车、粗铣、粗刨、钻孔 | 非配合面、倒角 |
| 25 | 微见刀痕 | 粗车、粗刨、立铣 | 非配合表面 |
| 12.5 | 半光，可见加工痕迹 | 精车、精铣、粗磨 | 支架、箱体非配合面 |
| 6.3 | 半光，微见加工痕迹 | 精车、精铣、精刨 | 一般配合面、齿轮非工作面 |
| 3.2 | 光，不可见加工痕迹 | 精磨、精铰 | 轴颈、齿轮工作面 |
| 1.6 | 光，可辨加工痕迹方向 | 精磨、研磨 | 重要配合面、滑动轴承 |
| 0.8 | 很光，不可辨加工纹理 | 精磨、珩磨 | 精密配合面 |
| 0.4 | 很光，暗光泽面 | 超精磨、抛光 | 量具工作面 |
| 0.2 | 镜面，亮光泽面 | 超精加工 | 精密量规 |
| 0.1 | 镜面，雾状镜面 | 超精加工、镜面磨 | 光学零件接触面 |

### 表面粗糙度符号

| 符号 | 含义 |
|:---:|:---|
| √ | 基本符号，可用任何方法获得（不指定加工方式） |
| √（上加横线） | 必须用去除材料的方法获得（车、铣、磨等） |
| √（中间加小圆圈） | 必须用不去除材料的方法获得（铸、锻、冲压等） |

符号上方可标注 $Ra$ 数值，如 $\sqrt[3.2]{}$ 表示 $Ra$ 上限值为 3.2 μm。若标注 $Ra$ 范围，写为 $\sqrt[3.2]{1.6}$ 表示上限 3.2 μm，下限 1.6 μm。

### 标注规则

1. **尖端方向**：代号尖端必须从材料外指向被测表面
2. **数字方向**：数字大小和方向与同一图样上尺寸数字一致；当符号画在右侧或下方时，数字应旋转以便水平阅读
3. **标注位置**：标注在可见轮廓线、尺寸界线或其延长线上；也可标注在指引线上
4. **多个表面**：同一零件不同表面可分别标注不同粗糙度要求
5. **统一标注**：当零件多数表面粗糙度相同时，在图纸右上角统一标注，其余表面分别标注。右上角符号比图中符号高度大一号
6. **同一表面不同要求**：当同一表面有不同粗糙度要求时，用细实线分隔标注

**方向规则说明**：

```
  ←数字与尺寸数字同向→
        3.2/
      ────┤── 尖端从外部指向表面
           │
        表面
```

**标注示例**：轴类零件各段表面粗糙度不同时，每段分别标注；齿轮齿面标注 $Ra=1.6$，轮毂孔标注 $Ra=3.2$，端面标注 $Ra=6.3$，其余非加工面标注不去除材料符号。花键齿侧标注 $Ra=0.8$，其余标注 $Ra=3.2$。

表面粗糙度值的选择原则：在满足使用要求的前提下，尽可能选择较大的 $Ra$ 值以降低加工成本。轻型机械一般 $Ra=0.4\sim6.3$ μm，重型机械一般 $Ra=3.2\sim25$ μm。

## 10.2 极限与配合

### 互换性

互换性是指同一规格的一批零件，任取其一，不经选择和修配就能装配到机器上，并满足规定的使用性能要求。

互换性的技术基础是**标准化**和**计量技术**。实现互换性的核心手段就是规定零件的极限尺寸和配合制度。

### 基本术语

**尺寸术语：**

- **基本尺寸** $D$（孔）/ $d$（轴）：设计给定的尺寸，是确定偏差的基准
- **实际尺寸**：通过测量得到的尺寸
- **极限尺寸**：允许尺寸变化的两个界限值
  - 最大极限尺寸 $D_{\text{max}}$ / $d_{\text{max}}$
  - 最小极限尺寸 $D_{\text{min}}$ / $d_{\text{min}}$

**偏差与公差：**

上偏差（ES/es）和下偏差（EI/ei），大写字母用于孔，小写字母用于轴：

$$ES = D_{\text{max}} - D, \quad EI = D_{\text{min}} - D$$

$$es = d_{\text{max}} - d, \quad ei = d_{\text{min}} - d$$

公差 $T$ 是允许尺寸的变动量，取绝对值：

$$T_h = |ES - EI|, \quad T_s = |es - ei|$$

公差带由代表上、下偏差的两条直线所限定的区域，用下列图示表示：

```
  上偏差(ES/es)
  ┌─────────────┐  ← 最大极限尺寸
  │  公差带区域  │
  │  (公差值 T)  │
  └─────────────┘  ← 最小极限尺寸
  下偏差(EI/ei)
───────────────────── 零线（基本尺寸）
```

### 标准公差（IT）

标准公差分为 20 个等级，代号 IT01、IT0、IT1 至 IT18，精度依次降低。标准公差数值 $T$ 与基本尺寸区间和等级有关。

| 等级 | 适用范围 | 应用举例 |
|:---:|:---|:---|
| IT01 ~ IT1 | 量块等高精度量规 | 基准量块 |
| IT2 ~ IT4 | 精密量规、精密零件 | 精密量规工作尺寸 |
| IT5 ~ IT6 | 精密配合 | 精密机床主轴、发动机活塞销 |
| IT7 ~ IT8 | 常用配合等级 | 一般机械中广泛应用 |
| IT9 ~ IT10 | 较低精度配合 | 一般机械中次要配合 |
| IT11 ~ IT13 | 粗配合 | 无配合要求的尺寸 |
| IT14 ~ IT16 | 非配合 | 一般粗加工尺寸 |
| IT17 ~ IT18 | 自由尺寸 | 铸造、锻造毛坯尺寸 |

同一基本尺寸区间内，各级 IT 标准公差值举例（基本尺寸 30~50mm）：

| 等级 | IT5 | IT6 | IT7 | IT8 | IT9 | IT10 | IT11 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 公差值(μm) | 11 | 16 | 25 | 39 | 62 | 100 | 160 |

加工方法与可达到的 IT 等级对照：

| 加工方法 | 可达等级 | 加工方法 | 可达等级 |
|:---|:---:|:---|:---:|
| 精密磨削 | IT5 | 精车 | IT7~IT8 |
| 研磨、珩磨 | IT4~IT5 | 粗车 | IT11~IT12 |
| 铰孔 | IT6~IT7 | 钻孔 | IT11~IT13 |
| 拉削 | IT7~IT8 | 铸造 | IT14~IT16 | |

### 基本偏差

基本偏差系列共 28 种代号，确定了公差带相对于零线的位置：

- **孔**（大写）：A, B, C, CD, D, E, EF, F, FG, G, H, J, JS, K, M, N, P, R, S, T, U, V, X, Y, Z, ZA, ZB, ZC
- **轴**（小写）：a, b, c, cd, d, e, ef, f, fg, g, h, j, js, k, m, n, p, r, s, t, u, v, x, y, z, za, zb, zc

其中 H 孔（下偏差 EI = 0）和 h 轴（上偏差 es = 0）为基准件基本偏差，使用最广。

基本偏差在公差带图中的位置规律：

```
    A B C ...             ... ZC  孔（大间隙→大过盈）
────┼────────────────────────────── 零线（H: EI=0）
    a b c ...             ... zc  轴（大间隙→大过盈）
```

- 孔 A~H：基本偏差为下偏差 EI（靠近零线），与轴形成间隙配合
- 孔 J~ZC：基本偏差为上偏差 ES（远离零线），与轴形成过渡或过盈配合
- 轴 a~h：基本偏差为上偏差 es（靠近零线），与孔形成间隙配合
- 轴 j~zc：基本偏差为下偏差 ei（远离零线），与孔形成过渡或过盈配合

公差带代号由基本偏差代号 + 公差等级数字组成，如 H7、f6、k6 等。完整标注形式为：$\Phi30\text{H7}$（孔）或 $\Phi30\text{f6}$（轴）。

## 10.3 配合

配合是指基本尺寸相同的、相互结合的孔和轴公差带之间的关系。

### 配合制

**基孔制**——基本偏差为 H 的孔的公差带固定，改变轴的公差带以获得各种配合。由于孔比轴难加工，基孔制应用最为广泛。

**基轴制**——基本偏差为 h 的轴的公差带固定，改变孔的公差带。用于以下情况：标准件配合（如滚动轴承外圈与箱体孔）、用冷拉光轴不加工的场合、同一轴上需要多种配合。

### 配合的三种类型

用公差带相对位置示意三种配合（上方为孔公差带，下方为轴公差带）：

**间隙配合**（孔>轴，有间隙）：

```
┌─────────┐  孔公差带
│ 间 隙 δ │
└─────────┘
┌───┐      轴公差带
└───┘
────────────────── 零线
```
$X_{\text{min}} = EI - es \geq 0$，$X_{\text{max}} = ES - ei$

**过盈配合**（轴>孔，有过盈）：

```
┌───┐      孔公差带
└───┘
┌─────────┐  轴公差带
│ 过 盈 δ │
└─────────┘
────────────────── 零线
```
$Y_{\text{min}} = EI - es \leq 0$（此处取过盈为负值），过盈量 $|Y| = D_{\text{shaft}} - D_{\text{hole}}$

**过渡配合**（公差带交叠）：

```
┌────────────┐  孔公差带
│   交叠区   │
└────────────┘
   ┌────────┐   轴公差带
   └────────┘
────────────────── 零线
```
可能产生间隙也可能产生过盈，最大间隙 $X_{\text{max}} = ES - ei$，最大过盈 $Y_{\text{max}} = EI - es$

### 配合代号与标注

配合代号由基本尺寸 + 孔公差带代号/轴公差带代号组成：

| 配合代号示例 | 含义 |
|:---|:---|
| $\Phi30\text{H7/f6}$ | 基孔制间隙配合，孔 H7，轴 f6 |
| $\Phi30\text{F7/h6}$ | 基轴制间隙配合，孔 F7，轴 h6 |
| $\Phi30\text{H7/r6}$ | 基孔制过盈配合 |
| $\Phi30\text{H7/k6}$ | 基孔制过渡配合 |

在零件图上标注为 $\Phi30^{+0.021}_{0}$（孔）或 $\Phi30^{-0.020}_{-0.033}$（轴 f6）。

### 配合计算示例

以 $\Phi30\text{H7/f6}$ 为例，基孔制间隙配合：

查表得：孔 $\Phi30\text{H7}$（基本尺寸 30mm，IT7，基本偏差 H）$ES = +21\mu m$，$EI = 0$

轴 $\Phi30\text{f6}$（基本尺寸 30mm，IT6，基本偏差 f）：$es = -20\mu m$，$ei = -33\mu m$

则配合极限：

$$X_{\text{max}} = ES - ei = +21 - (-33) = 54\mu m = 0.054\text{mm}$$

$$X_{\text{min}} = EI - es = 0 - (-20) = 20\mu m = 0.020\text{mm}$$

该配合在任何情况下都保持至少 0.020mm 的间隙，适用于有相对转动的一般配合部位。

### 配合类型对比总表

| 类型 | 公差带关系 | 间隙/过盈 | 典型代号 | 特点 | 应用 |
|:---|:---:|:---|:---|:---|:---|
| 大间隙配合 | 孔远在轴上 | 间隙很大 | H7/d9, H7/e8 | 间隙充裕 | 松配合、温度补偿 |
| 一般间隙配合 | 孔在轴上 | 中等间隙 | H7/f7, H7/g6 | 保证良好润滑 | 旋转运动 |
| 小间隙配合 | 孔略在轴上 | 间隙很小 | H7/h6 | 定心好 | 精密滑动、可拆 |
| 过渡配合 | 交叠部分小 | 可能间隙可能过盈 | H7/k6, H7/n6 | 定位精确 | 需拆卸的精密件 |
| 轻过盈配合 | 轴略在孔上 | 小过盈 | H7/p6, H7/r6 | 传递小扭矩 | 不拆卸的配合 |
| 重过盈配合 | 轴远在孔上 | 大过盈 | H7/s6, H7/u6 | 传递大扭矩 | 永久性配合 |

### 常用配合选择原则

| 配合类型 | 应用场合 | 常用代号 |
|:---|:---|:---|
| 间隙配合（大间隙） | 高速旋转、温度变化大 | H7/e8, H8/d9 |
| 间隙配合（中隙） | 有相对运动、润滑好 | H7/f7, H7/g6, H8/f8 |
| 间隙配合（小间隙） | 精密滑动配合、定心 | H7/h6, H6/h5 |
| 过盈配合（轻过盈） | 传递较小扭矩、定位 | H7/p6, H7/r6 |
| 过盈配合（中过盈） | 传递中等扭矩 | H7/s6, H7/t6 |
| 过盈配合（重过盈） | 传递大扭矩、永久结合 | H7/u6, H7/x6 |
| 过渡配合 | 定位精确、需要拆卸 | H7/k6, H7/m6, H7/n6 |

## 10.4 几何公差（GD&T）

### 几何公差概述

几何公差（原称"形位公差"）是形状公差和位置公差的统称。它控制零件上各几何要素的形状、方向和位置偏离理想状态的程度。

### 几何公差的四类项目

| 类别 | 项目名称 | 符号 | 有无基准 | 说明 |
|:---|:---|:---:|:---:|:---|
| 形状公差 | 直线度 | — | 无 | 控制表面或轴线素线的直线程度 |
| 形状公差 | 平面度 | ◇ | 无 | 控制平面偏离理想平面的程度 |
| 形状公差 | 圆度 | ○ | 无 | 控制圆柱/圆锥截面轮廓的圆整程度 |
| 形状公差 | 圆柱度 | /○/ | 无 | 同时控制圆柱面的圆度和母线直线度 |
| 方向公差 | 平行度 | // | 有 | 控制被测要素相对于基准的平行程度 |
| 方向公差 | 垂直度 | ⊥ | 有 | 控制被测要素相对于基准的垂直程度 |
| 方向公差 | 倾斜度 | ∠ | 有 | 控制被测要素与基准成给定角度的准确度 |
| 位置公差 | 位置度 | ⊕ | 有 | 控制点、线、面相对于基准的准确位置 |
| 位置公差 | 同轴度 | ◎ | 有 | 控制两轴线同轴程度 |
| 位置公差 | 对称度 | ⇌ | 有 | 控制被测要素相对于基准的对称程度 |
| 跳动公差 | 圆跳动 | ↗ | 有 | 旋转一周中指示器在指定方向的变动量 |
| 跳动公差 | 全跳动 | ↗↗ | 有 | 旋转中测头沿轮廓移动，指示器的总变动量 |

### 标注方法

几何公差用**公差框格**标注，从被测要素引出指引线：

```
┌───┬──────┬─────┐
│ ⊥ │φ0.05 │  A  │   ← 表示相对于基准A的垂直度，公差值φ0.05mm
└───┴──────┴─────┘
  ↑     ↑      ↑
 符号  公差值  基准字母
```

框格内容从左到右依次为：**几何特征符号** → **公差值**（若为圆柱体在公差值前加 $\Phi$）→ **基准字母**（大写字母套圈如 Ⓐ）。

基准符号用大写字母加圆圈标注在基准要素上，如：

```
    Ⓐ
────●────  基准要素（被测基准面或线）
```

### 标注示例

- `⊥ Φ0.05 A` — 被测轴线相对于基准平面 A 的垂直度公差为 Φ0.05 mm，公差带为直径 Φ0.05 的圆柱体
- `// 0.02 A` — 被测平面相对于基准平面 A 的平行度公差为 0.02 mm
- `◎ Φ0.03 A—B` — 被测轴线相对于公共基准 A—B 的同轴度公差为 Φ0.03 mm
- `⊕ Φ0.1 Ⓜ A B C` — 孔的位置度相对于三个基准 A、B、C，应用最大实体要求，公差 Φ0.1 mm
- `— 0.01` — 被测表面素线的直线度公差为 0.01 mm（形状公差，无基准）
- `○ 0.005` — 被测圆柱截面的圆度公差为 0.005 mm

### 公差原则

独立原则：尺寸公差和几何公差分别满足要求，互不相关（默认原则）。

相关要求：
- **包容要求** （E）：实际尺寸不超越最大实体边界，保证配合性质，标注 Ⓔ
- **最大实体要求** （M）：当被测要素偏离最大实体尺寸时允许几何公差增大，标注 Ⓜ

### 未注公差说明

图纸上未单独标注公差的尺寸，按 GB/T 1804 规定的未注公差执行。未注公差分四个等级：

| 等级代号 | 名称 | 适用范围 |
|:---:|:---|:---|
| f | 精密级 | 精密机械 |
| m | 中等级 | 一般机械（最常用） |
| c | 粗糙级 | 低精度要求 |
| v | 最粗级 | 非配合尺寸 |

在技术要求中注明："未注尺寸公差按 GB/T 1804-m"，"未注几何公差按 GB/T 1184-K"。

### 技术要求的书写格式

在零件图标题栏上方的空白处，用"技术要求"作为标题，按以下顺序逐条书写：

1. 对材料的热处理要求和表面硬度
2. 铸造圆角、起模斜度等铸造工艺要求
3. 未注尺寸公差和几何公差标准
4. 表面处理要求（镀、涂、发蓝等）
5. 其他加工、检验的特殊要求

示例：

> **技术要求**
> 1. 调质处理 HB 220~250
> 2. 未注铸造圆角 R3~R5
> 3. 未注尺寸公差按 GB/T 1804-m
> 4. 未注几何公差按 GB/T 1184-K
> 5. 表面发蓝处理

## 总结

本章介绍了零件图中技术要求的核心内容：

1. **表面粗糙度**：用 $Ra$ 值评定表面质量，通过特定符号标注在零件图上，$Ra$ 值的选择需平衡功能需求与加工成本。
2. **极限与配合**：通过基本尺寸、极限偏差和标准公差控制尺寸精度，IT7/IT8 为最常用配合等级。
3. **配合制度**：基孔制最常用（H 孔基准），配合分为间隙、过盈和过渡三种类型，分别适用于不同功能要求。
4. **几何公差**：控制零件的形状和位置精度，用公差框格标注几何特征符号、公差值和基准。
5. **其他技术要求**：包括热处理、表面处理、材料牌号和未注公差标准，均需在零件图中明确标注。

技术要求标注的准确性直接关系到零件的可制造性和使用性能，是机械制图的重要基本功。
