## 学习路线

```
第1-2章 (制图基础)   → 掌握工具和国标
第3章 (投影基础)     → 点线面的投影规律
第4-5章 (基本体/组合体) → 从简单立体到复杂形体
第6章 (轴测图)       → 理解三维形体
第7章 (表达方法)     → 学会剖视和断面
第8章 (标准件)       → 螺纹齿轮的规范化画法
第9-10章 (零件图)    → 完整的零件图设计与标注
第11章 (装配图)      → 读懂和绘制装配图
第12章 (CAD)         → 从手工绘图过渡到软件绘图
```
