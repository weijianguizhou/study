# 第十二章 计算机辅助绘图

## 12.1 CAD 概述

CAD（Computer-Aided Design，计算机辅助设计）是指利用计算机软硬件系统辅助工程设计的全流程技术。从二维电子图板到三维数字化样机，CAD 已深度嵌入现代制造业的每一个环节。

### CAD 的发展历程

| 年代 | 阶段 | 里程碑事件 |
|:---:|:---|:---|
| 1963 | 萌芽期 | Ivan Sutherland 发表博士论文《Sketchpad》，首次实现光笔人机图形交互，被誉为 CAD 之父 |
| 1970s | 二维普及期 | AutoCAD 诞生（1982年），DWG 格式成为二维工程图事实标准；同时期出现线框三维模型 |
| 1980s | 曲面与实体期 | Bezier 和 B-spline 曲面理论成熟；ACIS 和 Parasolid 实体建模内核出现 |
| 1990s | 参数化革命 | PTC 推出 Pro/ENGINEER（1987年），开创**参数化特征建模**范式——这是 CAD 史上最重要的转折 |
| 2000s | 中端崛起 | SOLIDWORKS 凭借 Windows 原生界面和易用性迅速占领中小企业市场 |
| 2010s-至今 | 云端与智能 | Onshape 等云原生 CAD 出现；生成式设计（Generative Design）引入 AI |

### 主流 CAD 软件

| 软件 | 核心优势 | 内核 | 适用领域 | 备注 |
|:---|:---|:---|:---|:---|
| AutoCAD | 二维绘图通用性最强 | 自有 | 建筑、机械、电气 | .dwg 格式为行业标准 |
| SOLIDWORKS | 三维参数化，易学易用 | Parasolid | 通用机械设计（**本教程选它**） | 全球用户超 600 万 |
| CATIA | 曲面造型能力顶尖 | 自有 | 航空航天、汽车外形 | 波音 777 首次全数字化设计 |
| UG/NX | 模具与加工一体化 | Parasolid | 模具、数控加工 | Siemens 旗下，CAM 集成度极高 |
| Creo | 参数化建模先驱 | Granite | 消费电子、结构设计 | 原 Pro/E，严谨的全参驱动 |
| Inventor | 与 AutoCAD 同生态 | ShapeManager | 中小型机械设计 | Autodesk 家族，与 DWG 无缝互通 |

### 二维 vs 三维

- **二维 CAD**：本质是"电子图板"——用鼠标替代铅笔，在屏幕上画线、画圆、标尺寸。它加速了绘图过程，降低了修改成本，但没有改变设计的根本逻辑：你仍然在"画每一根线"。
- **三维 CAD**：是现代设计的核心范式。设计师直接构建产品的**数字样机**（Digital Mock-Up），二维工程图由三维模型**自动投影**生成。修改模型时，所有视图同步更新，彻底消除了"改一个尺寸需改所有视图"的痛苦。

> **初学者的建议**：直接学习三维 CAD。先建立三维建模的思维，二维出图自然水到渠成。正如学会了写文章就不怕写字，学会三维建模后二维出图只是"点击按钮"。

## 12.2 从手工制图到 CAD 的思维转变

### 传统手工制图的工作流

```
识图(理解零件形状) → 选幅面(确定图纸大小) → 画基准线(用丁字尺+三角板)
    → 画底稿(所有视图同步推进，遵循长对正高平齐宽相等)
    → 加深描粗(分线型——粗实线/细实线/虚线/点画线)
    → 标注尺寸(箭头+数字+尺寸线) → 填写标题栏和技术要求 → 审核修改
```

回想[[05-组合体|第五章]]中的轴承座：画一张中等复杂度的零件图通常需要 **2~4 小时**，若有一处尺寸错误需要修改，往往意味着大面积擦除重画——因为三视图中一个特征的尺寸在三个视图中都出现，改一处必须改三处。

### CAD 的核心优势

1. **修改灵活**：改一个尺寸，所有相关特征、所有视图**自动更新**。这是 CAD 最颠覆性的能力——"改图恐惧症"从此治愈。
2. **精确绘图**：草图约束（几何约束 + 尺寸约束）和捕捉功能，确保线长、间距、角度绝对精确。不存在"手抖画歪了 0.5mm"这种问题。
3. **自动投影**：建立三维模型后，三视图、剖视图、轴测图、局部放大图**一键生成**，无需逐一绘制。软件替你执行"长对正、高平齐、宽相等"。
4. **便于协作**：数字文件易于存储、传输、版本管理（PDM/PLM 系统），支持多人协同设计。一个零件的三维模型可以被整条供应链共享。
5. **仿真与制造集成**：CAD 模型可直接导入 CAE 做有限元分析（应力、变形、热学），导入 CAM 生成数控加工 G 代码，导入 3D 打印机直接制造。实现**设计-分析-制造**全数字化链路。

### 手工制图知识在 CAD 中的延续

**以下核心知识全部适用于 CAD，一项都不浪费：**

| 手工制图知识 | CAD 中的延续 |
|:---|:---|
| 三视图投影规律（长对正、高平齐、宽相等） | CAD 工程图模块**遵循相同规则**自动投影 |
| 形体分析法（叠加 + 切割） | 对应 CAD 的**特征建模逻辑**（凸台 = 叠加，切除 = 切割） |
| 剖视概念 | 在 CAD 中可**任意定义剖切平面**，一键生成全剖、半剖、局部剖 |
| 尺寸标注规范（GB/T 4458.4） | CAD 标注**遵循相同标准**，你已学过的标注原则直接迁移 |
| 公差与表面粗糙度 | CAD 支持在模型中定义**三维标注（PMI）**，二维图纸自动继承 |
| 螺纹/齿轮等标准件画法 | CAD 提供**标准件库**（Toolbox），按国标规格直接调用 |

> **一句话总结**：手工制图建立的理论基础在 CAD 中 **100% 适用**。CAD 只是把手中的笔换成了鼠标，把脑海中的三维模型直接呈现在屏幕上。你在前面 11 章投入的时间一点都不浪费——你建立的"空间想象力"是所有三维建模的根基。

## 12.3 参数化建模的核心思想

### 二维草图的三个状态

参数化建模的第一步是**二维草图**。草图中每条线、每个弧都有"约束状态"：

| 状态 | SOLIDWORKS 颜色 | 含义 | 下一步操作 |
|:---|:---|:---|:---|
| 欠约束 | 🔵 蓝色 | 图元可被自由拖动，某些尺寸或位置未确定 | 添加尺寸约束或几何约束 |
| 完全约束 | ⚫ 黑色 | 每个图元的每个自由度都被锁定 | **此时才能用于生成特征** ✅ |
| 过约束 | 🔴🔴 红色/黄色 | 存在冲突的约束条件 | 删除相互矛盾的多余约束 |

### 全约束的概念

约束分为两大类：

- **几何约束**：定义图元之间的**几何关系**——水平、竖直、共线、同心、平行、垂直、相切、对称、固定、相等……
- **尺寸约束**：定义图元的**大小和位置**——长度、角度、直径/半径、两点距离、点到线距离……

草图中一个自由的二维图元（如一条线段）有 4 个自由度：两个端点的 $x_1, y_1, x_2, y_2$，或等价地表述为：位置 $(x,y)$ + 长度 $L$ + 角度 $\theta$。全约束意味着：用几何约束和尺寸约束将这 4 个自由度**全部锁定**。

$$
\text{全约束所需约束数} = \text{图元的总自由度数}
$$

> **建模纪律**：先全约束，再拉伸。绝不使用欠约束的草图生成三维特征。一个欠约束的草图是后续所有错误的根源——当你修改上游尺寸时，欠约束的图元会以你意料之外的方式"漂移"。

### 基于特征的建模

三维模型不是"一团材料"，而是**特征的线性序列**——这与[[05-组合体|第五章]]的形体分析法一脉相承：

```
三维模型 = 基础特征 + 附加特征₁ + 附加特征₂ + ... + 附加特征ₙ
```

常用特征类型：

| 类别 | 特征 | 说明 |
|:---|:---|:---|
| 加材料 | 拉伸凸台 | 将二维截面沿法向拉伸成实体 |
| 加材料 | 旋转凸台 | 将二维截面绕轴线旋转成实体（适合回转体） |
| 加材料 | 扫描 | 截面沿空间路径扫过 |
| 加材料 | 放样 | 多个截面间平滑过渡 |
| 减材料 | 拉伸切除 | 在已有实体上挖掉拉伸形状 |
| 减材料 | 旋转切除 | 绕轴挖掉回转体 |
| 减材料 | 扫描/放样切除 | 沿路径/多截面的切除 |
| 修饰 | 圆角、倒角 | 边线圆滑处理或倒斜角 |
| 修饰 | 抽壳 | 将实心体变成中空壳体 |
| 修饰 | 筋 | 增加加强筋（肋板） |
| 修饰 | 拔模 | 沿拔模方向倾斜面 |
| 阵列 | 线性/圆周阵列、镜像 | 重复已有的特征 |

**与形体分析法的对应关系**：叠加体 → 凸台特征序列，切割体 → 切除特征序列。你在[[05-组合体|第五章]]中培养的"拆分形体"能力，在 CAD 中直接转换为"规划特征序列"的能力。

### 设计意图

设计意图（Design Intent）是参数化建模的灵魂。通过以下机制，模型"记住"你的设计逻辑而非仅仅是形状：

- **参考基准面**：选择哪个面作为草图面，决定了父子依赖关系。选择越"稳定"的参考面，模型越"健壮"。
- **几何约束**：两条线平行、两个孔共线、一个面与基准面对称……这些关系定义了"应该如何"，而非"恰好这样"。
- **设计树**：SOLIDWORKS 左侧的 FeatureManager 设计树记录每一步的线性历史。你可以**回溯到任意一步**修改，所有后续步骤自动重建。

理解设计树的关键认知：**设计树不是"操作历史"，而是"特征依赖图"**。每一步特征依赖于它之前的所有特征和参考平面。当你在设计树中修改一个尺寸，依赖于此尺寸的所有后续特征自动重新计算——这就是参数化的威力。

### 参数化能力

通过**方程式**和**全局变量**，实现更高级的参数驱动设计：

$$
\text{底板厚度 } T = 10\text{mm}, \quad \text{凸台直径 } D = 2 \times T = 20\text{mm}, \quad \text{孔直径 } d = 0.6 \times T = 6\text{mm}
$$

修改 $T$ 为 12mm → $D$ 自动变为 24mm，$d$ 自动变为 7.2mm —— **改一参数，全局联动**。

## 12.4 从工程图到三维模型的工作流程

### 典型设计流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ ① 读图  │ → │ ② 规划  │ → │ ③ 草图  │ → │ ④ 特征  │ → │ ⑤ 检查  │ → │ ⑥ 出图  │
│  分析投影 │    │  定基准面 │    │  画截面  │    │  生成体  │    │  验证修改 │    │  投影标注 │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

各步骤详解：

1. **读图**：分析二维工程图的投影关系，在脑海中拆解形体（叠加/切割），想象三维形状。这一步依赖于[[05-组合体|第五章]]建立的空间想象力。
2. **规划**：确定基准面（前视/上视/右视），确定建模顺序——**先主后次、先加后减**，梳理特征间的参考关系。好的规划让模型"修改友好"。
3. **草图**：在选定的基准面上绘制二维截面，施加几何约束和尺寸约束 → **全约束（变黑）**。
4. **特征**：依序生成三维特征——先基础凸台建立"主体框架"，后附加切除"细化细节"，最后修饰（圆角/倒角）"做精修"。
5. **检查**：旋转观察模型，检查是否与原始图纸一致；尝试修改关键尺寸，确认所有依赖特征正确更新。
6. **出图**：从三维模型投影生成三视图和轴测图，标注尺寸和技术要求，与原始工程图交叉验证。这一步相当于"用软件重做一次[[01-制图基础与国家标准|第一章]]中的标注规范"。

### 实例：轴承座逆向建模

以[[05-组合体|第五章]]中的轴承座三视图为例，反向建立三维模型：

```
        ┌──────┐
        │ 圆筒  │  ← 特征2：拉伸凸台（两个同心圆截面）
        │      │      上视基准面→草图→拉伸
┌───────┼──────┼───────┐
│       │ 肋板  │       │  ← 特征3：筋（自动填充到圆筒与底板之间）
│  底板  │      │  底板  │  ← 特征1：拉伸凸台（矩形底板+两个圆头）
└───────┴──────┴───────┘      前视基准面→草图→拉伸
                            + 特征4：底板上4个安装孔（拉伸切除）
                            + 特征5：圆筒中心轴承孔（拉伸切除）
                            + 特征6：圆角/倒角修饰
```

建模步骤表（参考[[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]]）：

| 步骤 | 特征 | 草图面 | 操作 |
|:---:|:---|:---|:---|
| 1 | 底板 | 前视基准面 | 矩形+圆头草图（全约束）→ 拉伸凸台 |
| 2 | 圆筒 | 上视基准面 | 两个同心圆（全约束）→ 拉伸凸台，两侧对称 |
| 3 | 肋板 | 右视基准面 | 三角形轮廓（全约束）→ 筋特征，自动填充 |
| 4 | 安装孔 | 底板上表面 | 四个等径圆（全约束+镜像）→ 拉伸切除（通孔） |
| 5 | 轴承孔 | 圆筒端面 | 同心圆 → 拉伸切除（通孔） |
| 6 | 修饰 | 各边线 | 圆角（底板四角 R5、圆筒根部 R3）、倒角（孔口 C1） |

**关键思维转变**：你不画三视图，你**造零件**。三维模型建好后，三视图由软件自动投影——此时你可以将投影出的三视图与原始图纸逐视图对比，完成自我验证。

## 12.5 SOLIDWORKS 快速入门引导

本教程内置了详细的 [[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]]，包含完整安装指引、界面布局详解、核心工具栏说明和进阶操作示例。此处只给出**最小化入门路径**——读完这一节你就可以打开软件开始建模。

### 最少必备操作

| 操作目标 | SOLIDWORKS 操作 |
|:---|:---|
| 新建零件 | `文件 → 新建 → 零件` |
| 选择基准面 | 在 FeatureManager 中点击前视/上视/右视基准面 |
| 进入草图 | 点击 `草图绘制`（Sketch） |
| 画矩形 | `草图 → 边角矩形`，点击两点拉出矩形 |
| 画圆 | `草图 → 圆`，先定圆心再拖出半径 |
| 画直线 | `草图 → 直线`，点击起点和终点 |
| 尺寸约束 | `草图 → 智能尺寸`（工具栏最常用按钮），点选图元自动标注 |
| 几何约束 | `Ctrl + 选两个图元`，左侧属性面板会出现可用约束选项 |
| 完全约束确认 | 所有线条变为**黑色**（蓝色 = 欠约束，不可拉伸！） |
| 拉伸出实体 | `特征 → 拉伸凸台/基体`，输入深度值，确认方向 |
| 切除材料 | `特征 → 拉伸切除`，选草图轮廓，输入深度 |
| 旋转特征 | `特征 → 旋转凸台`，需草图中含中心线作为旋转轴 |
| 圆角 | `特征 → 圆角`，选边线或面，输入半径 |
| 倒角 | `特征 → 倒角`，选边线，选类型（角度-距离 / 距离-距离）|
| 抽壳 | `特征 → 抽壳`，选开口面，输入壁厚 |

### 五步建模法（通用逻辑，适用所有三维CAD）

```
 选面                 草图                  约束                 特征                  修饰
┌───────┐          ┌─────────┐          ┌─────────┐          ┌─────────┐          ┌─────────┐
│ 点选    │  ────→  │ 绘制     │  ────→  │ 添加     │  ────→  │ 生成     │  ────→  │ 细化     │
│ 基准面  │          │ 二维轮廓  │          │ 尺寸和   │          │ 三维实体  │          │ 边缘     │
│ 前/上/右│          │ 线框草图  │          │ 几何约束  │          │ 拉伸/旋转 │          │ 圆角/倒角 │
│         │          │          │          │  →变黑   │          │ /切除     │          │ /抽壳    │
└───────┘          └─────────┘          └─────────┘          └─────────┘          └─────────┘
```

**循环：一个零件 = 多次执行五步建模循环**。每完成一轮循环就得到一个特征，所有特征的叠加就是完整零件。

### 装配体入门

[[11-装配图|第十一章]]中学过的装配关系在 SOLIDWORKS 中对应为**配合**（Mate）：

1. `文件 → 新建 → 装配体`
2. 插入第一个零部件 → 自动固定于原点（相当于"定位基准件"）
3. 插入其他零部件 → 添加配合关系

常用配合类型：

| 配合 | 效果 | 对应装配关系 | 示例 |
|:---|:---|:---|:---|
| 重合 | 两个面贴合或对齐 | 面接触 | 螺母底面重合于被连接件顶面 |
| 同轴心 | 两个圆柱面共享轴线 | 轴孔配合 | 螺栓与螺栓孔 |
| 距离 | 两面平行且保持指定距离 | 间隙配合 | 端盖与轴承外圈留 0.5mm 间隙 |
| 平行/垂直 | 定向约束 | 位置定向 | 使零件端面与基准面平行 |
| 相切 | 曲面与平面/曲面相切 | 凸轮/齿轮接触 | 凸轮与从动件 |

### 工程图入门

SOLIDWORKS 工程图模块的完整操作流程（含视图生成、剖视图、尺寸标注、注解、BOM、图层、导出 PDF/DWG 等）已有独立教程：

> **→ [[SOLIDWORKS工程图教程|SOLIDWORKS 工程图完整教程]]** — 11 章实操指南，从模型到出图全流程。

以下为最小化入门路径：
1. `文件 → 从零件/装配体制作工程图`
2. 选择图纸幅面（A0~A4，与[[01-制图基础与国家标准|第一章]]中的 GB/T 14689 一致）
3. 从右侧**视图调色板**拖入标准三视图（主视图、俯视图、左视图）
4. 可额外拖入轴测图（通常放右上角，作为"看图助手"）
5. 使用 `智能尺寸` 工具添加尺寸标注
6. 添加粗糙度符号、形位公差框格、基准符号、技术要求文字

关于三维空间中的坐标变换和视角旋转，其数学基础为欧氏群 $SE(3)$：

$$
T = \begin{bmatrix} R & t \\ 0 & 1 \end{bmatrix}, \quad R \in SO(3), \quad t \in \mathbb{R}^3
$$

其中 $R$ 为 $3 \times 3$ 旋转矩阵满足 $R^T R = I$ 且 $\det(R) = 1$。更深入的变换理论和 C++ 实现参见 [[../../计算机类/Eigen库使用指南/README|Eigen]]。

## 12.6 本教程的继续学习路径

### 完成全部 12 章后你应具备的能力

- 读懂中等复杂程度的**零件图**（含主视图+辅助视图+剖视图+局部放大图）；
- 读懂中等复杂程度的**装配图**（含序号+明细栏+配合关系）；
- 绘制简单至中等复杂零件的完整视图表达方案；
- 理解尺寸公差、配合制度、表面粗糙度的含义并正确注写；
- 理解形位公差的基本概念（直线度、平面度、圆度、同轴度、垂直度……）；
- 使用 SOLIDWORKS 进行基础的零件建模、装配设计和工程图出图；
- 掌握"从二维工程图反推三维模型"的逆向建模能力；
- 初步具备**读图→建模→出图→验证**的完整数字设计思维。

### 继续提升的建议

1. **大量实践——图纸是"练"出来的**  
   找一本机械零件图册（学校图书馆有），从头临摹。画 50 张零件图后你的读图速度会有质变；画 30 张装配图后你会对公差和配合有"手感"；建 100 个三维模型后你会拥有不需要刻意思考的**空间直觉**。

2. **学会查表——国家标准是你终身的工具书**  
   [[01-制图基础与国家标准|第一章]]中国标不是背的，是学会查的：标准件规格表（螺栓 M8×30 到底外径多少？）、公差数值表（φ50H7 的公差带是多少微米？）、粗糙度推荐值（轴承座配合面 Ra 该标多少？）、形位公差等级表……这些是工程实践的"新华字典"，用得多了自然记住。

3. **三维建模实战——最深度的自检方式**  
   把[[05-组合体|第五章]]和[[11-装配图|第十一章]]中的每一张图纸都建出三维模型，再投影出二维图与原图逐处对比。如果投影图与原图有差异，说明你对图纸的理解有误——这是最高效的自我纠错训练。操作细节全在 [[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]]。

4. **亲手加工——图纸的最终目的是制造**  
   如果学校开设工程实训（金工实习），请无比认真对待。只有亲手装夹过毛坯、对过刀、车削/铣削出一个零件，然后用量具检验它是否符合图纸公差——你才能真正理解：为什么这里标注 $\phi30^{+0.021}_{0}$？为什么这个面标注 Ra 1.6？为什么那里要倒角 C2？为什么这个孔必须标注同轴度？

> **制图不是目的，制造才是目的。**  
> 图纸是设计师与制造者之间的"技术合同"，而三维模型是这份合同的"数字孪生"。  
> 你画出的每一条线、标注的每一个数字，都将在车间里变成真实的切屑和火花。

## 总结

本章完成了从"手工制图"到"计算机辅助设计"的跨越。核心要点回顾：

- **CAD 是工具而非替代**——前 11 章学到的投影理论、形体分析、标注规范、公差配合，全部是 CAD 建模和出图的基础。软件替你执行，但"该怎么做"由你的工程知识决定。
- **参数化建模的三根支柱**：全约束草图（不蓝不红只黑） → 序列化特征（特征树 = 建模历史） → 设计意图驱动（改一参数而全局联动）。
- **五步建模法**（选面 → 草图 → 约束 → 特征 → 修饰）是跨越所有机械三维 CAD 软件的通用逻辑。学会一种软件的方法论，切换其他软件只需重新记住按钮位置。
- **工程图是产物，三维模型是源头**——先建好三维模型，二维图纸自然生成。这正是为什么现代设计必须从三维开始。
- **学习制图的终点是制造**——图纸上的每一条线、每一个数字、每一个符号，背后都是加工工艺的约束和要求。理解"为什么这样标注"比记住"怎么标注"重要一百倍。

手工制图让你理解"为什么这样画"，CAD 让你高效地"画出所想"。二者结合，才构成一名合格现代机械工程师的完整技能。
