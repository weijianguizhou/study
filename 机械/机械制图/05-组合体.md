# 第五章 组合体

## 5.1 组合体的概念与组合形式

### 什么是组合体

任何复杂的机械零件，都可以看作是由若干个[[04-基本体与截交线|基本体（棱柱、棱锥、圆柱、圆锥、球等）]]通过一定的方式组合而成的。由两个或两个以上基本体经**叠加**、**切割**或两者**混合**方式构成的形体，称为组合体。

组合体是基本体向实际零件过渡的桥梁。掌握组合体的画图和读图方法，是学习机械制图的核心环节（又称"**画法几何**"的关键应用）。

### 三种组合形式

#### ① 叠加

由若干基本体以某种方式叠合在一起构成组合体。根据基本体间的表面关系，叠加又分为三种情况：

- **叠合**——两基本体的平面互相贴合，贴合处没有缝隙。
- **相切**——两基本体的表面（平面与曲面、或曲面与曲面）光滑相切。
- **相交**——两基本体的表面彼此相交，交线可能是截交线或相贯线。

**示例**：轴承座——底板（长方体）与圆筒（圆柱体）之间通过肋板（棱柱）叠加而成。

#### ② 切割

在基本体上切去一部分，或钻出孔洞，构成新的形体。

- **挖切**——从一个完整的形体上切去某一部分。例如，在长方体上切去一个四棱柱形成阶梯槽。
- **穿孔**——在形体上钻出通孔。例如，在圆柱体上钻一个圆柱孔。

**示例**：带槽方块——在长方体上挖切一个矩形通槽。

#### ③ 综合

多数实际零件同时包含叠加和切割两种形式，称为综合式组合体。

**示例**：轴承座底板钻有螺栓孔（切割），底板与圆筒之间通过肋板连接（叠加），整体属于综合式。

> 三种组合形式并非严格分隔，分析时重在抓住主要形体特征。

## 5.2 组合体表面的连接关系

**这是组合体画图最容易出错的地方！** 两基本体组合到一起后，它们的表面之间存在着不同的连接关系，直接决定了三视图中是否有分界线。

### 四种连接关系总结

| 连接关系 | 特征 | 是否画线 | 说明 |
|:---:|:---|:---:|:---|
| **相接（不平齐）** | 两表面不在同一平面 | **画线** | 产生台阶，应有分界线 |
| **相接（平齐）** | 两表面共面 | **不画线** | 表面融为一体，无分界线 |
| **相切** | 光滑过渡 | **不画线** | 相切处切线不画 |
| **相交** | 两表面交贯 | **必须画线** | 画出截交线或相贯线 |

### 相接——分齐与不平齐

**分两种情况：**

```
  不平齐——有分界线            平齐——无分界线
  
  ┌─────┐  ←高               ┌─────┐
  │  A  │                    │     │
  ├─────┤  ←矮     vs        │  C  │  ←完全平齐
  │  B  │                    │     │
  └─────┘                    └─────┘
  
  正视图中 A与B之间有实线      正视图中无分界线，
  分开两个表面。               C视为一个完整表面。
```

判断口诀：**两表面不在同一平面 → 画线分开；两表面共面 → 融为一个面，不画线。**

### 相切——光滑过渡

当平面与圆柱面相切或两曲面相切时，相切处的表面是光滑过渡的，没有明显的交线。

**核心规则：相切处不画线。**

```
   平面与圆柱面相切（截面示意）
   
   长方体 ──╮
            ╰── 光滑过渡 ── 圆柱面
            （此处不画任何线！）
```

画图时，相切处对应的视图中不应画出切线。但要注意：与相切面相关的轮廓线应画到切点位置为止。

### 相交——有交线，必须画出

两基本体的表面相交时，必然产生交线（截交线或相贯线）。交线是两表面共有点的集合。

**核心规则：相交处必须画出交线。**

```
   圆柱与圆柱正交相贯（俯视）
   
    ┌─────────┐
    │  ┌───┐  │
    │  │   │  │  ← 小圆柱
    │  └───┘  │
    └─────────┘
      大圆柱
    
   交线为空间曲线，
   在视图中表现为相贯线的投影。
```

**求相贯线的方法**（简单情况下）：
- 利用积聚性法：当相贯线在一个视图上有积聚性投影时，可由该投影确定相贯线上的点。
- 近似画法：在不需要精确绘制的场合，可以用圆弧近似代替相贯线。

关于截交线和相贯线的详细求法，见[[04-基本体与截交线|第四章 基本体与截交线]]。

## 5.3 画组合体三视图的方法与步骤

### 核心方法：形体分析法

**形体分析法**是画组合体视图的最基本方法。其核心思想是：**化整为零，逐个击破，再合零为整。**

具体来说，就是将组合体假想分解为若干个基本体，分析各基本体的形状、相互位置、组合形式和表面连接关系，然后逐个画出各基本体的三视图，最后按它们的相对位置组合起来。

> **形体分析法**贯穿组合体的画图和读图全过程，是本课程最重要的方法之一。

### 画三视图的完整步骤

#### 步骤① 形体分析

用形体分析法将组合体分解为若干组成部分（基本体）。确定：
- 每个部分是什么形体（棱柱？圆柱？圆锥？）
- 各部分之间的相对位置（上下、左右、前后关系）
- 各部分之间的组合形式（叠加还是切割）
- 各部分表面的连接关系（平齐、不平齐、相切还是相交）

#### 步骤② 选择主视图

主视图是三视图中最重要的视图，应遵循以下原则：
- **最能反映形体特征**——主视图应尽量多地表达组合体的形状和各部分的相对位置。
- **符合安放位置**——按组合体的工作位置或自然安放位置放置。
- **尽量减少虚线**——在其他视图表达清楚的前提下，主视图尽量少出现虚线。

#### 步骤③ 选比例、定图幅

根据组合体的大小和复杂程度选择合适的比例和图幅：
- 尽量选用 1:1 的比例，以便于直观感受形体大小。
- 图幅需留出标注尺寸和标题栏的空白位置。

#### 步骤④ 布置视图位置

在图纸上画出各视图的基准线（对称中心线、轴线、底面线、后端面线等），合理布置三个视图的位置。注意：
- 三个视图之间要留出适当的间距（用于标注尺寸）。
- 整体布局要均匀，不偏不斜。

#### 步骤⑤ 画底稿

遵循**"四先四后"**原则：
- **先主后次**——先画主要形体（如大底板、主体圆筒），后画次要形体（如肋板、凸台）。
- **先大后小**——先画大的基本体，后画小的结构。
- **先整体后局部**——先画出各基本体的整体轮廓，再处理局部细节（如圆角、倒角、小孔）。
- **先叠加后切割**——先画叠加形成的主体，再画切割去除的部分。

画每一个基本体时，应从反映该形体特征的视图画起，三个视图配合进行。充分利用"**长对正、高平齐、宽相等**"的投影规律（见[[03-投影基础|第三章 投影基础]]）。

#### 步骤⑥ 检查、描深

- 检查各视图是否符合投影规律。
- 检查表面连接关系处理是否正确（该画线处是否画了，不该画线处是否多画了）。
- 检查无误后，按线型标准描深图线。

### 完整示例：轴承座

以轴承座为例，演示完整的画图过程。

**轴承座的结构分解（形体分析）：**

```
          ┌──────────────┐
          │   圆  筒     │  ← 圆柱体（主承载体，带轴孔）
          └──┬────────┬──┘
             │ 肋  板 │      ← 三棱柱（支撑连接）
      ┌──────┴────────┴──────┐
      │      底     板      │  ← 长方体（安装基础）
      └─────────────────────┘
```

各部分分析：

| 部分 | 形体类型 | 特征 | 与相邻部分的连接 |
|:---|:---|:---|:---|
| 底板 | 长方体 | 带有螺栓孔（切割） | 与肋板叠加 |
| 圆筒 | 圆柱体 | 中心有通孔 | 与肋板相切 |
| 肋板 | 三棱柱 | 连接底板与圆筒 | 与底板相接（不平齐），与圆筒相切 |

**画图顺序：**

1. 画基准线（底板底面线、对称中心线、圆筒轴线）
2. 画底板的三视图（先画俯视图，反映底板形状特征）
3. 画圆筒的三视图（先画主视图或左视图，反映圆筒特征）
4. 画肋板的三视图
5. 处理连接关系：肋板与底板相接处画线；肋板与圆筒相切处不画线
6. 画底板上的螺栓孔（切割）
7. 画圆筒中心通孔
8. 检查、描深

## 5.4 组合体的尺寸标注

尺寸是制造和检验零件的依据。组合体的尺寸标注必须做到：**正确、完整、清晰**。

### 尺寸的三大类型

| 类型 | 定义 | 示例 |
|:---|:---|:---|
| **定形尺寸** | 确定各基本体自身形状大小的尺寸 | 长方体的长、宽、高；圆柱体的直径和高度 |
| **定位尺寸** | 确定各基本体之间相对位置的尺寸 | 两孔之间的中心距；圆筒轴线到底板底面的高度 |
| **总体尺寸** | 组合体的总长、总宽、总高 | 整个轴承座的总长、总宽、总高 |

$定形尺寸 + 定位尺寸 + 总体尺寸 = 完整标注$

### 尺寸基准的选择

标注定位尺寸必须选择**尺寸基准**——度量尺寸的起始位置。在三个方向上各需选定一个主要基准：

- **长度方向基准**——通常选对称面或重要的左右端面
- **宽度方向基准**——通常选对称面或重要的前后端面
- **高度方向基准**——通常选底面（安装面）

**基准选择原则**：优先选对称面、底面、重要端面作为基准。零件的设计基准和工艺基准应尽可能统一。

### 尺寸标注步骤

1. **形体分析**——将组合体分解为若干基本体
2. **选尺寸基准**——在长、宽、高三个方向各选一个基准
3. **逐个标注定形尺寸**——标注每一个基本体自身形状大小的尺寸
4. **标注定位尺寸**——标注各基本体间相对位置关系的尺寸
5. **标注总体尺寸**——标注总长、总宽、总高
6. **检查调整**——检查有无遗漏或重复，必要时进行调整（如总体尺寸可由定形尺寸和定位尺寸算出时，不需要重复标注）

### 轴承座尺寸标注实例

以轴承座为例，分析尺寸标注：

| 标注对象 | 定形尺寸 | 定位尺寸 | 基准说明 |
|:---|:---|:---|:---|
| 底板 | 长 L、宽 B、高 h1 | 长度方向对称 | 长度基准：对称面 |
| 圆筒 | 外径 ΦD、内径 Φd、长 b | 高度方向：轴线距底面 H | 高度基准：底板底面 |
| 肋板 | 厚度 t、高度 (H - R外) | 宽度方向：对称布置 | 宽度基准：对称面 |
| 螺栓孔 | Φd1 | 长度方向孔距 l1；宽度方向孔距 l2 | 对称面为基准 |
| **总体尺寸** | 总长 = L；总宽 = B；总高 = H + D/2（由定形和定位尺寸间接确定） |

标注时先在三个视图上合理分配尺寸，避免集中标注在某一视图上。直径尺寸尽量标注在非圆的视图上以体现孔深。

## 5.5 读组合体视图

### 读图概述

读图（看视图、想形状）是画图的逆过程——根据平面图形想象出空间立体的形状。

读组合体视图的基本要求：**能根据三视图（或两个视图）准确想象出组合体的空间形状和结构。**

### 两种基本方法

#### 一、形体分析法

**形体分析法**是读图的最基本方法。其步骤为：

$$
\text{分线框} \rightarrow \text{对投影} \rightarrow \text{定形体} \rightarrow \text{综合想整体}
$$

1. **分线框**——在主视图（或其他特征明显的视图）上，将视图分成若干个封闭的线框（每一个线框通常代表一个基本体的投影）。

2. **对投影**——利用"长对正、高平齐、宽相等"的投影规律，找出每个线框在其他两个视图中的对应投影。

3. **定形体**——根据各线框的三面投影，运用[[04-基本体与截交线|基本体的投影特征]]，判断每个线框所代表的基本体的形状。

4. **综合想整体**——根据各基本体的相互位置和组合形式，综合想象出整个组合体的空间形状。

#### 二、线面分析法

**线面分析法**是形体分析法的补充。当组合体某些局部的形状较难用形体分析法判断时，需借助线面分析法。

线面分析法的核心是对视图中**每一个封闭线框**和**每一条图线**进行空间意义的分析。

**核心法则：**

- **一框一面**——视图中的一个封闭线框，必定代表空间中的一个面（平面或曲面）。面的投影可能是类似形，也可能积聚为一条线。
- **一框一洞**——封闭线框也可能是通孔的投影，此时它不仅代表面，还代表被"挖掉"的空间。
- **一线三意义**——视图中的一条图线可能有三种空间意义：
  - ① 具有积聚性的面（如圆柱面的积聚投影）
  - ② 两面的交线（如截交线、相贯线）
  - ③ 曲面的轮廓线

$$
\text{视图中一条线} = 
\begin{cases}
\text{面（积聚）} \\
\text{交线} \\
\text{轮廓线}
\end{cases}
$$

### 读图步骤

以"**支架**"三视图为例说明读图过程。

**支架三视图示意（文字描述）：**
- 主视图：上部为带孔的圆（圆筒），下部为矩形（底板），中间通过一个梯形框（肋板）连接
- 俯视图：圆筒为矩形框（圆柱的俯视投影），底板为带孔的矩形
- 左视图：圆筒带孔，底板可见，肋板可见切点位置

**读图过程：**

| 步骤 | 操作 | 分析结果 |
|:---|:---|:---|
| ① 看视图、分线框 | 在主视图上分出三个主要线框 | 上部圆形线框 A / 中间梯形线框 B / 下部矩形线框 C |
| ② 对投影、想形状 | 对每个线框找另两个视图的对应投影 | A→圆筒（圆柱体） / B→肋板（三棱柱） / C→底板（长方体） |
| ③ 定位置、理连接 | 分析各部分的空间位置关系 | A在C上方，B连接A与C。B与C相接（不平齐，有交线）；B与A相切 |
| ④ 合起来、想整体 | 综合所有信息，想象整体形状 | 支架：带孔的圆柱形顶座，通过三棱柱肋板支撑在带孔的长方体底板上 |

读图的要点：**以形体分析法为主，线面分析法为辅。** 先整体后局部，先易后难地读图。

## 总结

- **组合体**是由基本体经叠加、切割或综合方式构成的形体。
- **表面连接关系**是画图和读图的核心：相接要看是否平齐，相切不画线，相交必须画线。
- **形体分析法**是贯穿全章的根本方法——将组合体"化整为零"分析，再"合零为整"综合。
- **尺寸标注**三要素：定形尺寸、定位尺寸、总体尺寸；三个方向各选一个基准。
- **读图**是画图的逆过程，以形体分析法为主、线面分析法为辅。
- **线面分析法**中的"一框一面"原则是解决疑难线框的利器。
