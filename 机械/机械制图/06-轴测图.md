# 第六章 轴测图

## 6.1 轴测图概述

轴测图是一种用平行投影法将物体连同其直角坐标系沿不平行于任一坐标面的方向投射到单一投影面上所得到的单面投影图。

**主要特点**：
- **立体感强**：能同时反映物体三个方向的形状，直观易懂
- **度量性差**：由于投影变形，不能直接量取实际尺寸

三视图（[[03-投影基础|第三章]]）度量性好但缺乏立体感，轴测图正好弥补这一不足。在现代 CAD 软件（如 [[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]]）中，只需一键即可从三维模型生成各类轴测视图。

### 基本术语

| 术语 | 符号 | 说明 |
|------|------|------|
| 轴测投影面 | $P$ | 投射到的单一投影面 |
| 轴测轴 | $O_1X_1,\ O_1Y_1,\ O_1Z_1$ | 直角坐标轴在投影面 $P$ 上的投影 |
| 轴间角 | $\angle X_1O_1Y_1,\ \angle Y_1O_1Z_1,\ \angle X_1O_1Z_1$ | 两轴测轴之间的夹角，三者之和为 $360^\circ$ |
| 轴向伸缩系数 | $p_1,\ q_1,\ r_1$ | 轴测轴方向上线段投影长与实际长之比 |

$$p_1 = \frac{O_1X_1}{OX},\quad q_1 = \frac{O_1Y_1}{OY},\quad r_1 = \frac{O_1Z_1}{OZ}$$

### 分类

**按投射线方向：**

| 类型 | 定义 | 特点 |
|------|------|------|
| 正轴测图 | 投射线 $\perp$ 轴测投影面 $P$ | 立体感好 |
| 斜轴测图 | 投射线不垂直于轴测投影面 $P$ | 至少一个面反映实形 |

**按轴向伸缩系数：**

| 类型 | 关系 | 常用种类 |
|------|------|----------|
| 等测 | $p_1 = q_1 = r_1$ | 正等测 |
| 二测 | $p_1 = r_1 \neq q_1$ | 斜二测、正二测 |
| 三测 | $p_1 \neq q_1 \neq r_1$ | 很少使用 |

### GB 推荐类型

国家标准 GB/T 4458.3 推荐三种轴测图：

| 推荐类型 | 轴间角 | 轴向伸缩系数 | 说明 |
|----------|--------|-------------|------|
| 正等轴测图 | 均为 $120^\circ$ | $p=q=r=1$（简化） | 最常用 |
| 正二等轴测图 | $131.4^\circ,\ 97.2^\circ,\ 131.4^\circ$ | $p=r=1,\ q=0.5$（简化） | 较少使用 |
| 斜二轴测图 | $90^\circ,\ 135^\circ,\ 135^\circ$ | $p=r=1,\ q=0.5$ | 常用 |

## 6.2 正等轴测图

正等轴测图是工程中最常用的轴测图类型，三个方向表达均匀，立体感最好。

### 关键参数

三个轴间角均为 $120^\circ$：

```
         Z₁
         │
         │   120°
         │
        /│\
       / │ \
      /  │  \
     /   │   \
    /120° │ 120°\
   /      │      \
  O₁──────────────X₁
   \
    \
     Y₁
```

**轴向伸缩系数**：

- 理论值：$p_1 = q_1 = r_1 = \sqrt{\frac{2}{3}} \approx 0.82$
- 简化值（GB 推荐）：$p = q = r = 1$，图形放大至 $\frac{1}{0.82} \approx 1.22$ 倍

简化后图形形状不变，仅大小略有放大，完全不影响表达。

### 三种基本画法（概念）

| 方法 | 思路 | 适用场景 |
|------|------|----------|
| 坐标法 | 沿轴测轴方向量取各顶点坐标后连线 | 任意形状 |
| 切割法 | 先画完整外形，再逐步切除多余部分 | 经切割成形的物体 |
| 叠加法 | 分解为若干基本形体，逐个绘制后组合 | 组合类物体 |

三种方法常综合运用，其形体分析思路与 [[05-组合体|第五章]] 组合体的形体分析法一致。在 CAD 中，这些方法已被自动求解替代。

## 6.3 正等轴测图中的圆

平行于坐标面的圆在正等轴测图中的投影均为椭圆。三个椭圆大小相同但方向各异：

| 圆所在坐标面 | 椭圆长轴方向 | 短轴方向 | 长轴尺寸 | 短轴尺寸 |
|-------------|-------------|----------|----------|----------|
| $XOY$（水平面） | 与 $X_1$ 轴成 $60^\circ$ | 与 $Z_1$ 轴平行 | $1.22d$ | $0.7d$ |
| $XOZ$（正面） | 与 $X_1$ 轴成 $60^\circ$ | 与 $Y_1$ 轴平行 | $1.22d$ | $0.7d$ |
| $YOZ$（侧面） | 与 $Y_1$ 轴成 $60^\circ$ | 与 $X_1$ 轴平行 | $1.22d$ | $0.7d$ |

其中 $d$ 为圆的直径。

**规律**：椭圆短轴平行于与圆所在坐标面垂直的轴测轴。

传统手工绘图采用"四心圆弧法"（菱形法）用四段圆弧近似椭圆。在 CAD 软件中，圆的正等测投影直接生成为精确椭圆，无需任何近似方法。

## 6.4 斜二轴测图

斜二轴测图属于斜轴测图，投射线倾斜于轴测投影面。

### 关键参数

**轴间角**：

$$\angle X_1O_1Z_1 = 90^\circ,\quad \angle X_1O_1Y_1 = \angle Y_1O_1Z_1 = 135^\circ$$

**轴向伸缩系数**：

$$p_1 = r_1 = 1,\quad q_1 = 0.5$$

即沿 $X_1$ 轴和 $Z_1$ 轴按实际尺寸量取，沿 $Y_1$ 轴（纵深方向）取实际尺寸的一半。

### 核心优势

**物体上平行于 $XOZ$ 坐标面的所有图形均反映实形**——圆的投影仍是圆，不变成椭圆！

这在以下情况极为方便：
- 物体在一个方向（通常是正面）有较多圆、圆弧或复杂曲线轮廓
- 法兰盘、端盖、手轮等端面有复杂形状的零件
- $X_1O_1Z_1$ 面可直接量取尺寸

不适合的场景：物体三个方向均有圆或圆弧（此时应选正等轴测图）。

## 6.5 轴测图类型选择

选择哪种轴测图取决于物体的结构特征：

| 物体特征 | 推荐类型 | 原因 |
|----------|----------|------|
| 三个方向均有圆或圆弧 | 正等轴测图 | 各方向均匀变形，整体效果好 |
| 仅一个方向（正面）有圆 | 斜二轴测图 | 正面反映实形，圆不变椭圆 |
| 一个方向有复杂曲线轮廓 | 斜二轴测图 | 简化作图，提高效率 |
| 轴类零件（沿轴向有多个截面） | 斜二轴测图 | 各截面反映实形 |
| 箱体类零件 | 正等轴测图 | 立体感最好 |
| 需要标注尺寸 | 斜二轴测图 | $X_1O_1Z_1$ 面可直接量取 |

教材实例（支架、开槽圆柱、法兰盘等）演示了综合运用坐标法、切割法、叠加法的绘图过程——在 CAD 中，选择上述推荐类型后由软件一键生成，无需手工分步操作。

## 6.6 轴测剖视图

当物体内部结构复杂时，可引入剖切形成**轴测剖视图**。

### 基本原理

- 剖切平面一般平行于坐标面
- 常用两个互垂剖切平面联合剖切，剖去前方 $1/4$ 角
- 尽量通过对称面或轴线剖切

### 各坐标面上剖面线的方向

| 剖切面所在坐标面 | 剖面线方向（正等测） |
|------------------|---------------------|
| $X_1O_1Z_1$ | 与 $X_1$ 轴平行（水平） |
| $X_1O_1Y_1$ | 与 $X_1$ 轴成 $60^\circ$ |
| $Y_1O_1Z_1$ | 与 $Z_1$ 轴成 $60^\circ$ |

### 典型应用

适用于箱体类零件的内部空腔、壳体类零件的壁厚与筋板、模具型腔、阀体泵体内部流道等表达。现代三维 CAD 软件（如 [[SOLIDWORKS 使用指南|SOLIDWORKS 使用指南]]）可直接在三维模型上定义剖切平面，一键生成轴测剖视图。

## 总结

轴测图是弥补三视图缺乏立体感的重要表达方法。面向 CAD 用户的核心要点：

| 内容 | 关键参数 |
|------|----------|
| 正等轴测图 | 轴间角 $120^\circ$，简化系数 $p=q=r=1$，图形放大 $1.22$ 倍 |
| 圆的正等测 | 椭圆长轴 $1.22d$，短轴 $0.7d$，短轴平行于垂直轴 |
| 斜二轴测图 | $\angle X_1O_1Z_1=90^\circ$，$p=r=1,\ q=0.5$，正面反映实形 |
| 类型选择 | 三向有圆选正等测，单向有圆选斜二测 |
| 轴测剖视图 | 剖切面平行于坐标面，剖面线方向因面而异 |

在 CAD 工作流中，轴测图的生成是自动化的——理解这些参数有助于正确设置视图方向和预期输出效果。
