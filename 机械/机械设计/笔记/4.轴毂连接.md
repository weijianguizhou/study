# 轴毂连接
## 键连接的类型及应用
根据键连接在装配时是否预紧，分为**松键连接**和**紧键连接**。
$$\text { 松键连接 }\left\{\begin{array}{l}
\text { 平键连接 }\left\{\begin{array}{l}
\text { 普通平键 } \\
\text { 导向平键 } \\
\text { 滑键 }
\end{array}\right.  \\
\text { 半圆键连接 }
\end{array}\right.$$
$$\text { 紧键连接 }\left\{\begin{array}{l}
\text { 楔键连接 } \\
\text { 切向键连接 }
\end{array}\right.$$

## 平键
工作面：两侧面

工作时考键与键槽侧面的挤压来传递扭矩

### 1.普通平键
田于静连接,即轴与轮毂之间无相对轴向移动。
![[普通平键.png]]
### 2.薄型平键
键高约为普通平键的60%~70%:圆头、方头和单圆头,常用于薄壁结构、空心轴等径向尺寸受限制的场合。
