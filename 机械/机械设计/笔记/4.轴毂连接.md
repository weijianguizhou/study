# 轴毂连接
## 键连接的类型及应用
根据键连接在装配时是否预紧，分为**松键连接**和**紧键连接**。
$$\text { 松键连接 }\left\{\begin{array}{l}
\text { 平键连接 }\left\{\begin{array}{l}
\text { 普通平键 } \\
\text { 导向平键 } \\
\text { 滑键 }
\end{array}\right.  \\
\text { 半圆键连接 }
\end{array}\right.$$
$$\text { 紧键连接 }\left\{\begin{array}{l}
\text { 楔键连接 } \\
\text { 切向键连接 }
\end{array}\right.$$

## 平键
工作面：两侧面

工作时考键与键槽侧面的挤压来传递扭矩

### 1.普通平键
田于静连接,即轴与轮毂之间无相对轴向移动。
![[普通平键.png]]
### 2.薄型平键
键高约为普通平键的60%~70%:圆头、方头和单圆头,常用于薄壁结构、空心轴等径向尺寸受限制的场合。
### 3.导向键和滑键
![[导向键和滑键.png]]

## 半圆键连接
![[半圆键.png]]
键槽用与半圆键形状相同的铣刀加工,键能在槽中绕几何中心摆动,工作时靠工作侧面的挤压传递扭矩。

**注意**：半圆键要注意画法：
1. 半圆键的两侧面为键的工作面只在接触面上画一条轮廓线
2. 应画出键上表面与轮毂的**间隙**
![[半圆键连接画法.png]]

## 楔键连接
键的上表面与轮毂键槽底均具有1:100的斜度,工作时键的上下表面与轮毂轴的键槽工作面压紧,靠摩擦力和挤压传递扭矩。
![[楔键连接.png]]
楔紧后,轴和轮毂产生偏心,在冲击载荷下易松脱,仅适用于低速轻载、精度要求不高的场合。
