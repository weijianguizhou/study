# 第4章 螺纹连接

> **对应课件**：04章螺纹连接｜**核心**：单个螺栓强度计算 → 螺栓组受力分析

---

## 4-1 螺纹

| 参数 | 符号 | 要点 |
|---|---|---|
| 大径（公称直径） | $d$ | 与外螺纹牙顶重合 |
| **小径** | $d_1$ | <font color="#ff0000">强度计算一律用它</font>（危险截面） |
| 中径 | $d_2$ | $d_2\approx\dfrac{d+d_1}{2}$，配合性质由它确定 |
| 螺距 / 导程 / 线数 | $P$ / $L$ / $n$ | $L=nP$ |
| 螺旋升角 | $\psi$ | $\psi=\arctan\dfrac{L}{\pi d_2}=\arctan\dfrac{nP}{\pi d_2}$ |
| 牙型角 | $\alpha$ | 轴向平面内牙型两侧边夹角 |

- 牙型：**联接**用三角形螺纹（60°）；**传动**用矩形、梯形、锯齿形螺纹（工作侧 3°）。
- 粗牙用于一般紧固件；细牙螺距小、自锁性好、强度高，适用于薄壁零件、细小零件及受冲击振动/变载荷的场合。

## 4-2 螺纹连接的基本类型

| 类型 | 结构特点 | 适用场合 |
|---|---|---|
| 普通螺栓（受拉） | 通孔**有间隙**，装拆方便 | 被联接件不太厚，应用最广 |
| 铰制孔用螺栓（受剪挤） | 无间隙，杆与孔壁直接接触 | 承受**横向载荷**，也可定位 |
| 双头螺柱 | 一端旋入被联接件，拆装只拆螺母 | 常拆卸且被联接件之一较厚 |
| 螺钉 | 不用螺母，直接旋入 | 被联接件之一较厚、受力不大、不需经常装拆 |
| 紧定螺钉 | 末端顶紧被联接件 | 固定相对位置，传力/力矩不大 |

## 4-3 预紧和防松

**预紧**：紧联接靠预紧力 $Q_P$ 工作，拧紧力矩
$$T=KQ_Pd,\qquad K=0.1\sim0.3$$
预紧力控制：测力矩扳手 / 定力矩扳手 / 测量螺栓伸长量。

**防松**：原理——消除或限制螺纹副的相对运动。
1. 摩擦防松：双螺母、弹簧垫圈、自锁螺母；
2. 机械防松：开槽螺母＋开口销、止动垫片、串联钢丝；
3. 永久防松：端铆、冲点、点焊、粘合。

## 4-4 单个螺栓连接的强度计算

失效：受拉螺栓——塑性变形或断裂；受剪螺栓——剪断或压溃。由强度条件求 $d_1$，再按标准取 $d$ 与 $P$。

### 1. 松螺栓（不拧紧，仅工作载荷 $F$）
$$\sigma=\frac{F}{\pi d_1^2/4}\le[\sigma]\quad\Rightarrow\quad d_1\ge\sqrt{\frac{4F}{\pi[\sigma]}}$$

### 2. 紧螺栓——仅受预紧力 $Q_P$
$$\sigma_{ca}=\frac{1.3Q_P}{\pi d_1^2/4}\le[\sigma]\quad\Rightarrow\quad d_1\ge\sqrt{\frac{4\times1.3Q_P}{\pi[\sigma]}}$$

> <font color="#ff0000">系数 1.3</font>：考虑拧紧时**螺纹扭转剪应力**的影响，把拉扭复合应力简化为纯拉伸（简化计算法）。

### 3. 受横向载荷的紧螺栓
- **普通螺栓**：靠拧紧产生的摩擦力防滑
$$ifQ_P\ge K_sR\quad\Rightarrow\quad Q_P\ge\frac{K_sR}{fi}\qquad(K_s=1.1\sim1.3)$$
求出 $Q_P$ 后按上节“仅预紧”条件算 $d_1$；
- **铰制孔螺栓**：
$$\tau=\frac{R}{\pi d_0^2/4}\le[\tau],\qquad\sigma_P=\frac{R}{d_0L_{\min}}\le[\sigma]_P$$
（$d_0$ 为杆/孔直径，$L_{\min}$ 为受挤压孔壁最小长度）

### 4. 受轴向载荷的紧螺栓（重点）
$$\Delta F=K_cF,\qquad K_c=\frac{C_b}{C_b+C_m}$$
$$Q=Q_P+\Delta F=Q'_P+F=Q_P+K_cF,\qquad Q_P=Q'_P+(1-K_c)F$$

残余预紧力 $Q'_P$ 取法：

| 工况 | $Q'_P$ |
|---|---|
| 有密封性要求 | $(1.5\sim1.8)F$ |
| 一般稳定载荷 | $(0.2\sim0.6)F$ |
| 一般不稳定载荷 | $(0.6\sim1.0)F$ |
| 地脚螺栓 | $Q'_P>F$ |

- 静强度：$\sigma_{ca}=\dfrac{1.3Q}{\pi d_1^2/4}\le[\sigma]$，$d_1\ge\sqrt{\dfrac{4\times1.3Q}{\pi[\sigma]}}$；
- 变载荷：$\sigma_{\max}=\dfrac{Q}{\pi d_1^2/4}$，$\sigma_{\min}=\dfrac{Q_P}{\pi d_1^2/4}$，按 $\sigma_{\min}=C$ 校核应力幅 $\sigma_a\le[\sigma_a]$；
- **紧密性条件**：结合面不出现缝隙，即残余预紧力 $Q'_P>0$；有密封性要求的联接（压力容器、气缸等）取 $Q'_P=(1.5\sim1.8)F$，据此定出 $Q_P$ 的下限。设计时需**同时满足强度条件与紧密性条件**。

### 5. 许用应力
$$[\sigma]=\frac{\sigma_s}{n}\qquad(\sigma_s\ \text{查材料表},\ n\ \text{查安全系数表})$$
- 强度级别：点前数字 $=\sigma_{B\min}/100$，点后数字 $=10\sigma_{s\min}/\sigma_{B\min}$；螺母级别应低于螺栓级别；
- **试算法**：先估计 $d$ 试算，与估计值比较后调整。

## 4-5 螺栓组连接的设计与受力分析

设计思路：结构设计（布局/数目）→ 受力分析 → 找受力最大的螺栓 → 按它设计 $d_1$ → 全组同尺寸。

| 工况               | 公式                                                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- |
| 轴向载荷 $P$（过中心）    | $F=\dfrac{P}{Z}$                                                                                                     |
| 横向载荷（铰制孔）        | $R_i=\dfrac{R_\Sigma}{Z}$                                                                                            |
| 旋转力矩 $T$（普通螺栓防滑） | $\sum fQ_Pr_i\ge K_sT\ \Rightarrow\ Q_P\ge\dfrac{K_sT}{f\sum r_i}$                                                   |
| 旋转力矩 $T$（铰制孔）    | $R_{\max}=\dfrac{Tr_{\max}}{\sum r_i^2}$                                                                             |
| 倾覆力矩 $M$         | $F_{\max}=\dfrac{ML_{\max}}{\sum L_i^2}$                                                                             |
| 接合面校核            | $\sigma_{P\max}=\dfrac{zQ_P}{A}+\dfrac{M}{W}\le[\sigma]_P$（不压溃）；$\sigma_{P\min}=\dfrac{zQ_P}{A}-\dfrac{M}{W}>0$（不开缝） |

> 接合面“不开缝”$\sigma_{P\min}>0$ 即螺栓组的**紧密性条件**（保证受压侧不出现间隙）。

## 4-6 提高强度的措施

- 改善牙间载荷分布：悬置螺母（+40%）、环槽螺母（+30%）、内斜螺母（+20%）；加厚螺母无效；
- 减小应力集中：加大过渡圆角、卸载槽、退刀槽；
- 降低应力幅：$C_b\downarrow$（空心/细长螺栓）＋ $C_m\uparrow$（硬垫片）＋适当增大 $Q_P$；
- 工艺：滚压螺纹（+30%~40%）、<font color="#ff0000">热处理后再滚压</font>（+70%~100%）。

## 例题

### 例题 1（轴向变载荷）
紧螺栓联接：$Q_P=4000\ \mathrm{N}$，工作载荷 $F$ 在 $0\sim4000\ \mathrm{N}$ 间变化，$C_b=0.5C_m$，$[\sigma]=80\ \mathrm{MPa}$。求螺栓总载荷的最大、最小值及所需 $d_1$。

**解**：
$$K_c=\frac{C_b}{C_b+C_m}=\frac{0.5C_m}{1.5C_m}=\frac{1}{3},\qquad \Delta F=K_cF=\frac{1}{3}\times4000=1333.3\ \mathrm{N}$$
- 总载荷最大值：$Q_{\max}=Q_P+\Delta F=4000+1333.3=5333.3\ \mathrm{N}$
- 总载荷最小值：$Q_{\min}=Q_P=4000\ \mathrm{N}$
- 残余预紧力：$Q'_{P,\max}=4000\ \mathrm{N}$，$Q'_{P,\min}=Q_P-(1-K_c)F=4000-\frac{2}{3}\times4000=1333.3\ \mathrm{N}$
- 按静强度求 $d_1$：
$$d_1\ge\sqrt{\frac{4\times1.3Q_{\max}}{\pi[\sigma]}}=\sqrt{\frac{4\times1.3\times5333.3}{\pi\times80}}\approx10.5\ \mathrm{mm}$$

> [!note] 课件笔误
> 课件将相对刚度写作 $K_c=\frac{1}{2}$，按条件 $C_b=0.5C_m$ 应为 $K_c=\frac{1}{3}$（后续 5333.3 N 也按 1/3 得出）。

### 例题 2（高压气缸螺栓组）
气缸工作压力 $p=5\ \mathrm{MPa}$，内径 $D=120\ \mathrm{mm}$，用 14 个 M18 螺栓（$d_1=16.376\ \mathrm{mm}$），$[\sigma]=135\ \mathrm{MPa}$，$K_c=0.3$，要求 $Q'_P\ge1.7F$。确定 $Q_P$ 的取值范围。

**解**：
$$F=\frac{\dfrac{\pi}{4}D^2p}{14}=\frac{\dfrac{\pi}{4}\times120^2\times5}{14}\approx4037\ \mathrm{N}$$
$$Q'_P=1.7F=6862.9\ \mathrm{N},\qquad \Delta F=K_cF=0.3\times4037=1211.1\ \mathrm{N}$$
- **紧密性条件**（定下限）：由 $Q'_P=Q_P-(1-K_c)F\ge1.7F$ 得
$$Q_P\ge1.7F+(1-K_c)F=1.7F+0.7F=2.4F=9688.8\ \mathrm{N}$$
- **强度条件**（定上限）：由 $Q=Q_P+\Delta F\le\dfrac{[\sigma]\,\dfrac{\pi}{4}d_1^2}{1.3}$ 得
$$Q_P\le\frac{[\sigma]\,\dfrac{\pi}{4}d_1^2}{1.3}-\Delta F=20650\ \mathrm{N}$$
$$\therefore\quad \boxed{9688.8\ \mathrm{N}\le Q_P\le20650\ \mathrm{N}}$$

### 例题 3（边板螺栓组）
边板用 4 个普通螺栓与立柱相连，外载荷 $F=18\ \mathrm{kN}$，作用点距螺栓组中心 400 mm，螺栓组尺寸 200 mm × 160 mm，$f=0.2$，$K_s=1.3$，$[\sigma]=80\ \mathrm{MPa}$。求受力最大螺栓的横向载荷及所需 $d_1$。

**解**（力向形心简化）：
- 平移分力（每螺栓）：$F_1=\dfrac{F}{4}=4500\ \mathrm{N}$；力矩：$T=F\times400=7200\ \mathrm{kN\cdot mm}$；
- 最远螺栓 $r_{\max}=\sqrt{100^2+80^2}=128.06\ \mathrm{mm}$，力矩分力：
$$F_2=\frac{T}{4r_{\max}}=\frac{7200}{4\times128.06}\approx14\ \mathrm{kN}$$
- 合成（$\cos\theta=\frac{80}{\sqrt{100^2+80^2}}=0.625$）：
$$F_{s\max}=\sqrt{F_1^2+F_2^2+2F_1F_2\cos\theta}=\sqrt{4.5^2+14^2+2\times4.5\times14\times0.625}\approx17.175\ \mathrm{kN}$$
- 防滑条件：$Q_P\ge\dfrac{K_sF_{s\max}}{f}=\dfrac{1.3\times17175}{0.2}\approx111.649\ \mathrm{kN}$
- 所需小径：
$$d_1\ge\sqrt{\frac{4\times1.3Q_P}{\pi[\sigma]}}=\sqrt{\frac{4\times1.3\times111649}{\pi\times80}}\approx48\ \mathrm{mm}$$

> [!note] 此类题方法
> 先“力向形心简化”，再求每个螺栓上“平移分力＋力矩分力”的矢量和，取最大者校核。
