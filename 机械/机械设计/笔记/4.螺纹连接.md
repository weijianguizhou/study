## 本节课要点
- **[[螺纹]]**：牙型（联接 60°/传动 3°）、参数体系（$d,\ d_1,\ d_2,\ P,\ L,\ n,\ \psi,\ \alpha$），强度计算一律用小径 $d_1$；
- **连接类型**：普通螺栓（受拉、有间隙）/ 铰制孔螺栓（受剪挤、无间隙）/ 双头螺柱 / 螺钉 / 紧定螺钉；
- **预紧与防松**：紧联接靠[[预紧力]] $Q_P$ 工作，$T=KQ_Pd$；防松三法（摩擦/机械/永久）；
- **单个螺栓强度**：核心是轴向紧螺栓——变形协调 → [[螺栓相对刚度]] $K_c$ → 总载荷 $Q=Q_P+K_cF$ → $Q'_P$ 四档取法 → $\sigma_{ca}=1.3Q/(\pi d_1^2/4)$；
- **螺栓组设计**：力向形心简化 → 求受力最大螺栓 → 按最大载荷设计 $d_1$ → 全组同尺寸；
- **提高强度**：改善牙间载荷分布、减小应力集中、降低应力幅（$C_b\downarrow+C_m\uparrow+Q_P\uparrow$）、合理工艺（热处理后再滚压）。

## 详细笔记

### 4-1 [[螺纹]]

#### 一、螺纹的形成
将直角三角形 $K$ 绕在圆柱体上，斜边在圆柱表面形成的空间曲线即**螺旋线**；沿螺旋线加工的沟槽即**螺纹**。
- 改变原始三角形 $K$ 的形状（牙底形状），可得到矩形、梯形、锯齿形、管螺纹等不同牙型。

#### 二、螺纹的分类

##### 1、按牙型分类
- **联接螺纹**：<font color="#ff0000">三角形螺纹（60°）</font>、锥螺纹（55°）、管螺纹（55°）；
- **传动螺纹**：矩形螺纹、梯形螺纹、锯齿形螺纹（工作侧牙型角 3°）。

**粗牙 vs 细牙**（同属三角形螺纹）：
- **粗牙**：作一般紧固件使用；
- **细牙**：同一公称直径下<font color="#ff0000">螺距最小</font>，牙细而浅，<font color="#ff0000">自锁性好</font>，强度较高，适于<font color="#ff0000">薄壁零件、细小零件、受冲击振动及变载荷</font>的场合。

##### 2、按位置分类
- **内螺纹**、**外螺纹**。

##### 3、按旋向分类
- **右旋**（常用）、**左旋**（如<font color="#ff0000">自行车脚踏曲柄上的螺纹为左旋</font>）。

##### 4、按螺旋线头数（线数）分类
- **单线**（$n=1$）：用于**联接**；
- **双线、多线**（$n\ge2$）：用于**传动**（升角大、效率高），一般 $n\le4$（便于制造）。

$$L=nP$$
- $L$：导程；$P$：螺距；$n$：线数。

#### 三、螺纹的主要参数

| 参数 | 符号 | 定义 |
|---|---|---|
| **外径（大径）** | $d$ | 与外螺纹牙顶相重合的假想圆柱面直径，亦称**公称直径** |
| **内径（小径）** | $d_1$ | 与外螺纹牙底相重合的假想圆柱面直径，<font color="#ff0000">强度计算中为计算直径</font> |
| **中径** | $d_2$ | 轴向剖面内牙厚与牙间宽相等处的假想圆柱面直径，$d_2\approx\dfrac{d+d_1}{2}$；确定螺纹几何参数和配合性质的直径 |
| **螺距** | $P$ | 螺纹相邻两牙型上对应点间的轴向距离 |
| **导程** | $L$ | 螺纹上任一点沿同一螺旋线旋转一周移动的轴向距离，$L=nP$ |
| **线数** | $n$ | 螺纹螺旋线数目 |
| **螺旋升角** | $\psi$ | 中径圆柱面上螺旋线的切线与垂直于螺纹轴线的平面间的夹角：$\psi=\arctan\dfrac{L}{\pi d_2}=\arctan\dfrac{nP}{\pi d_2}$ |
| **牙型角** | $\alpha$ | 螺纹轴向平面内螺纹牙型两侧边的夹角 |

> [!note] 注意
> 螺纹强度计算一律使用<font color="#ff0000">小径 $d_1$</font>（危险截面直径），不是大径 $d$（雨课堂单选 2）。

### 4-2 螺纹连接的类型及螺纹连接件

#### 一、螺纹连接的基本类型

| 类型 | 结构特点 | 适用场合 |
|---|---|---|
| **a) 普通螺栓联接**（受拉螺栓） | 被联接件开**通孔（不带螺纹）**，孔与螺杆之间有间隙且工作中不许消失；结构简单、装拆方便、可多次装拆 | 被联接件不太厚，应用最广 |
| **b) 铰制孔用螺栓联接**（受剪螺栓） | 装配后**无间隙**，螺栓杆与孔壁直接接触（基孔制配合） | 主要承受**横向载荷**，也可作定位用 |
| **双头螺柱联接** | 螺杆两端均有螺纹，一端旋入被联接件，另一端配螺母；拆装时只需拆螺母 | <font color="#ff0000">常拆卸且被联接件之一较厚</font> |
| **螺钉联接** | 不用螺母，直接旋入被联接件 | 被联接件之一较厚、受力不大、<font color="#ff0000">不需经常装拆</font> |
| **紧定螺钉联接** | 末端顶紧被联接件 | 固定两零件的相对位置，传递不大的力或力矩 |

**特殊用途螺钉**：吊环螺钉、地脚螺栓（固定机器于地基）。

#### 二、螺纹联接件
- **[[螺栓]]**：六角头螺栓（标准）、双头螺柱、螺钉；
- **螺母**：六角螺母（标准/扁/厚）、圆螺母（与止退垫圈配合使用）；
  - 圆螺母+止退垫圈：垫片内翅嵌入螺栓槽内，螺母拧紧后再将垫片外翅之一折嵌于螺母的槽内；
- **垫圈**：作用——<font color="#ff0000">保护被联接件表面、增大接触面积、遮掩不平表面</font>；
  - 普通垫圈（平垫圈、斜垫圈）；弹簧垫圈——防止螺母松脱；止动垫圈——配合圆螺母用。

**螺纹标准件的加工**：搓丝（碾牙、攻牙）机、六轴攻丝机、螺母丝锥。

### 4-3 螺纹连接的预紧和防松

#### 一、预紧

**螺纹联接分类**：
- **松联接**：装配时不拧紧，只有受外载荷时才受力；
- **紧联接**：装配时需拧紧，即承载时已预先受力（[[预紧力]] $Q_P$）。

**预紧目的**：<font color="#ff0000">增大联接的刚度、紧密性，提高防松能力</font>。

**预紧力** $Q_P$：预先施加的轴向作用力（拉力）。
- 预紧过紧：拧紧力过大，螺杆静载荷增大，降低螺杆强度；
- 预紧过松：拧紧力过小，工作不可靠。

**扳手拧紧力矩**：
$$T=F_H\cdot L=T_1+T_2$$
- $T_1$——螺纹摩擦阻力矩：$T_1=Q_P\tan(\psi+\varphi_v)\dfrac{d_2}{2}$；
- $T_2$——螺母端环形面与被联接件间的摩擦力矩：$T_2=f_cQ_P\cdot\dfrac{1}{3}\cdot\dfrac{D_1^3-d_0^3}{D_1^2-d_0^2}$；
- 拧紧力矩系数 $K=\dfrac{1}{2}\left[\dfrac{d_2}{d}\tan(\psi+\varphi_v)+\dfrac{2f_c}{3d}\cdot\dfrac{D_1^3-d_0^3}{D_1^2-d_0^2}\right]$；

$$\therefore\quad T=KQ_P d,\qquad K=0.1\sim0.3$$

**预紧力 $Q_P$ 的控制**：
1. **测力矩扳手**——测出预紧力矩；
2. **定力矩扳手**——达到固定的拧紧力矩时卡盘不转动；
3. **测量预紧前后螺栓伸长量**——精度较高。

#### 二、防松

**1、防松目的**：在振动、冲击、变载或温度变化时，螺纹副中正压力可能减小或瞬间消失，摩擦力为零，使螺纹联接松动；反复作用会使联接松驰而失效，必须防松。

**2、防松原理**：<font color="#ff0000">消除（或限制）螺纹副之间的相对运动，或增大相对运动的难度</font>。

**3、防松方法**：
- **1）摩擦防松**：双螺母（对顶螺母）、弹簧垫圈、自锁螺母（嵌尼龙圈、带颈收口、加金属防松装置）等；
- **2）机械防松**：开槽螺母与开口销、止动垫片、串联钢丝（注意正确穿法）等；
- **3）永久防松**：端铆、冲点、点焊、粘合。

### 4-4 单个螺栓连接的强度计算

#### 一、受力形式、失效形式与设计准则

- **螺栓杆受力形式**：轴向拉力、扭转力矩或横向剪力。
- **失效形式**：
  - 受拉螺栓：螺栓杆和螺纹可能发生<font color="#ff0000">塑性变形或断裂</font>；
  - 受剪螺栓：螺栓杆、孔壁可能发生<font color="#ff0000">剪断或压溃</font>。
- **统计**：90% 以上的螺栓属于<font color="#ff0000">疲劳破坏</font>，失效原因主要是应力集中促使疲劳裂纹的发生和发展。
  - 疲劳破坏位置：① 螺母支承面第一、第二牙圈处占 <font color="#ff0000">65%</font>；② 螺杆尾退刀槽处占 20%；③ 钉头支承面处占 15%。
- **设计准则**：
  - 受拉螺栓——保证螺栓的<font color="#ff0000">疲劳拉伸强度或静强度</font>；
  - 受剪螺栓——保证螺栓的<font color="#ff0000">挤压强度和剪切强度</font>。
- **计算方法**：由强度条件确定螺纹小径 $d_1$，按标准选相应的公称直径 $d$ 及螺距 $p$，其余尺寸按标准选取。

#### 二、松螺栓联接（如吊钩螺栓）

工作前不拧紧，无预紧力 $Q_P$，只有工作载荷 $F$ 起拉伸作用：
$$\sigma=\frac{F}{\dfrac{\pi}{4}d_1^2}\le[\sigma]\quad\text{——验算用}$$
$$d_1\ge\sqrt{\frac{4F}{\pi[\sigma]}}\quad\text{——设计用}$$
- $[\sigma]=\sigma_s/n$；$\sigma_s$ 查表 4-4，安全系数 $n$ 查表 4-5。

#### 三、紧螺栓联接——仅受预紧力（横向载荷的普通螺栓）

工作前拧紧，在预紧力和拧紧力矩联合作用下处于复合应力状态：
- 预紧力 $Q_P$ → 拉伸应力 $\sigma=\dfrac{Q_P}{\pi d_1^2/4}$；
- 螺纹摩擦力矩 $T_1$ → 剪应力 $\tau$，对 M10~M68 螺栓：
$$\tau\approx0.48\sigma\ (\text{或 }0.5\sigma)$$
- 按**第四强度理论**：
$$\sigma_{ca}=\sqrt{\sigma^2+3\tau^2}\approx1.3\sigma$$

$$\sigma_{ca}=\frac{1.3Q_P}{\dfrac{\pi}{4}d_1^2}\le[\sigma]\quad\Rightarrow\quad d_1\ge\sqrt{\frac{1.3\times4Q_P}{\pi[\sigma]}}$$

> [!note] 系数 1.3 的含义
> 1.3 将外载荷提高 30%，以考虑**螺纹扭转剪应力**对螺栓强度的影响，把拉扭复合应力状态简化为纯拉伸处理，故又称**简化计算法**（雨课堂单选 6 → D 扭转剪应力）。

#### 四、受横向载荷的紧螺栓联接

**（1）普通螺栓联接**——靠拧紧正压力 $Q_P$ 产生摩擦力平衡外载荷：
- 不产生相对滑移条件：
$$i\cdot f\cdot Q_P\ge K_sR\quad\Rightarrow\quad Q_P\ge\frac{K_sR}{f\cdot i}$$
- $f$——接缝面摩擦系数；$i$——接合界面数目；$K_s$——防滑（可靠性）系数，$K_s=1.1\sim1.3$；
- 然后按仅预紧的强度条件计算 $d_1$（见上节）。

**（2）铰制孔用螺栓联接**——螺杆直接承受**挤压**和**剪切**平衡外载荷 $R$：
$$\tau=\frac{R}{\dfrac{\pi}{4}d_0^2}\le[\tau]\qquad\text{剪切强度条件}$$
$$\sigma_P=\frac{R}{d_0L_{\min}}\le[\sigma]_P\qquad\text{挤压强度条件}$$
- $R$——横向载荷；$d_0$——螺杆或孔直径；$L_{\min}$——被联接件中受挤压孔壁的最小长度；$[\tau]$——许用剪应力。

#### 五、受轴向载荷的紧螺栓联接★

**工作特点**：工作前拧紧（有 $Q_P$），工作后加上工作载荷 $F$，工作过程中载荷变化。

**工作原理**：靠螺杆抗拉强度平衡外载 $F$。

**受力变形分析**：
- 拧紧（预紧状态）：螺栓受拉 $Q_P$ → 伸长 $\lambda_b$；被联接件受压 $Q_P$ → 压缩 $\lambda_m$；
- 加载 $F$（工作状态）：螺栓继续受拉，$Q_P\to Q=Q'_P+F$，总伸长 $\lambda'_b=\lambda_b+\Delta\lambda$；被联接件放松，$Q_P\to Q'_P$（**残余预紧力**），总压缩 $\lambda'_m=\lambda_m-\Delta\lambda$。

**力—变形关系**（螺栓刚度 $C_b$、被联接件刚度 $C_m$）：
$$C_b=\tan\theta_b=\frac{Q_P}{\lambda_b}=\frac{\Delta F}{\Delta\lambda},\qquad C_m=\tan\theta_m=\frac{Q_P}{\lambda_m}=\frac{F-\Delta F}{\Delta\lambda}$$

**[[螺栓相对刚度]]**：
$$K_c=\frac{C_b}{C_b+C_m}$$
$$\Delta F=\frac{C_b}{C_b+C_m}F=K_cF\quad\text{——部分工作载荷}$$

**螺栓总载荷**：
$$Q=F+Q'_P=\Delta F+Q_P=Q_P+K_cF$$
$$Q_P=Q'_P+(1-K_c)F$$

**残余预紧力 $Q'_P$ 的取法**：
| 工况 | $Q'_P$ |
|---|---|
| 有密封性要求 | $(1.5\sim1.8)F$ |
| 一般稳定载荷 | $(0.2\sim0.6)F$ |
| 一般不稳定载荷 | $(0.6\sim1.0)F$ |
| 地脚螺栓 | $Q'_P>F$ |

**$K_c$ 的讨论**：
- 最不利情况 $C_b\gg C_m$：$Q\approx Q_P+F$（外载几乎全由螺栓承受）；
- 最理想情况 $C_b\ll C_m$：$Q\approx Q_P$（外载几乎全由被联接件承受）；
- 不允许 $Q'_P<0$（出现缝隙，联接失效）。

**降低螺栓受力的措施**：采用刚度较小的螺栓（<font color="#ff0000">空心螺栓、加长螺栓、细颈</font>）+ 加硬垫片或拧紧凸缘（增大被联接件刚度）。

#### 六、轴向载荷紧螺栓的强度计算

计算时可任选其一：$Q=Q_P+\Delta F$ 或 $Q=Q'_P+F$。

**a) 轴向静力紧螺栓联接**（静力 $F$ 不变，$Q$ 为静力，考虑补充拧紧——防断）：
$$\sigma_{ca}=\frac{1.3Q}{\dfrac{\pi}{4}d_1^2}\le[\sigma]\quad\Rightarrow\quad d_1\ge\sqrt{\frac{1.3\times4Q}{\pi[\sigma]}}$$

**b) 轴向变载荷紧螺栓联接**：
- 工作载荷：$0\to F\to0$；螺栓总载荷：$Q_P\to Q\to Q_P$；
- 螺栓内拉应力变化：
$$\sigma_{\max}=\frac{Q}{\dfrac{\pi}{4}d_1^2},\qquad \sigma_{\min}=\frac{Q_P}{\dfrac{\pi}{4}d_1^2}$$
- 按 $\sigma_{\min}=C$ 的规律计算[[疲劳强度|疲劳安全系数]] $S_\sigma$，或校核应力幅：
$$\sigma_a\le[\sigma_a]$$

**c) 验算不满足时的措施**：
1. 增大直径 $d\uparrow\Rightarrow d_1\uparrow\Rightarrow\sigma_a\downarrow$；
2. 改善结构、降低应力集中，如 $C_m\uparrow$、$C_b\downarrow$。

#### 七、螺栓材料与许用应力

**1、材料**（表 4-4，常用螺栓材料）：

| 材料 | $\sigma_B$/MPa | $\sigma_s$/MPa | $\sigma_{-1}$/MPa | $\sigma_{-1tc}$/MPa |
|---|---|---|---|---|
| 10 | 340~420 | 210 | 160~220 | 120~150 |
| Q215 | 340~420 | 220 | — | — |
| Q235 | 410~470 | 240 | 170~220 | 120~160 |
| 35 | 540 | 320 | 220~300 | 170~220 |
| 45 | 610 | 360 | 250~340 | 190~250 |
| 40Cr | 750~1000 | 650~900 | 320~440 | 240~340 |

**2、安全系数**（表 4-5）：
- 松螺栓联接（静载荷）：$n=1.2\sim1.7$；
- 紧螺栓联接（普通螺栓，不控制预紧力）——碳钢：M6~M16 静 5~4 / 变 12.5~8.5，M16~M30 静 4~2.5 / 变 8.5，M30~M60 静 2.5~2 / 变 8.5~12.5；合金钢：M6~M16 静 5.7~5 / 变 10~6.8，M16~M30 静 5~3.4 / 变 6.8，M30~M60 静 3.4~3 / 变 6.8~10；
- 控制预紧力：静 1.2~1.5 / 变 1.2~1.5；
- 铰制孔用螺栓：钢 $n_\tau=2.5,\ n_P=1.25$（静）、$n_\tau=3.5\sim5,\ n_P=1.5$（变）；铸铁 $n_P=2.0\sim2.5$（静）、$2.5\sim3.0$（变）。

**许用应力**：
$$[\sigma]=\frac{\sigma_s}{n},\qquad [\tau]=\frac{\sigma_s}{n_\tau}$$

**3、强度级别（性能等级）**：
- 螺栓级别用带点数字表示：点前数字 $=\sigma_{B\min}/100$，点后数字 $=10\sigma_{s\min}/\sigma_{B\min}$；螺母级别 $=\sigma_{B\min}/100$；
- 注意：<font color="#ff0000">螺母的强度级别应低于螺栓的强度级别，螺母硬度稍低于螺栓硬度</font>（均低 20~40 HB）。

**4、试算法**：设计时先假设直径 $d$ 试算，选取一安全系数计算，将结果与估计直径比较，若仍在原先估计直径范围内即可，否则需重新估算。

##### 例题 1（轴向变载荷，课件原题）
紧螺栓联接：$Q_P=4000\ \mathrm{N}$，工作载荷 $F$ 在 $0\sim4000\ \mathrm{N}$ 间变化，$C_b=0.5C_m$，$[\sigma]=80\ \mathrm{MPa}$。求螺栓总载荷的最大、最小值及所需 $d_1$。

**解**：
$$K_c=\frac{C_b}{C_b+C_m}=\frac{0.5C_m}{1.5C_m}=\frac{1}{3}$$
$$\Delta F=K_cF=\frac{1}{3}\times4000=1333.3\ \mathrm{N}$$
- 总载荷最大值：$Q_{\max}=Q_P+\Delta F=4000+1333.3=5333.3\ \mathrm{N}$
- 总载荷最小值：$Q_{\min}=Q_P=4000\ \mathrm{N}$
- 残余预紧力：$Q'_{P,\max}=4000\ \mathrm{N},\qquad Q'_{P,\min}=Q_P-(1-K_c)F=4000-\frac{2}{3}\times4000=1333.3\ \mathrm{N}$
- 按静强度（$Q_{\max}$）求 $d_1$：
$$d_1\ge\sqrt{\frac{4\times1.3Q_{\max}}{\pi[\sigma]}}=\sqrt{\frac{4\times1.3\times5333.3}{\pi\times80}}\approx10.5\ \mathrm{mm}$$

> [!note] 课件笔误
> 课件本页将相对刚度写作 $K_c=\dfrac{1}{2}$ 的中间算式，但按已知条件 $C_b=0.5C_m$ 正确计算应为 $K_c=\dfrac{1}{3}$，且后续结果 5333.3 N 也按 1/3 得出。笔记按正确值记录。

##### 例题 2（高压气缸螺栓组，课件原题）
气缸工作压力 $p=5\ \mathrm{MPa}$，内径 $D=120\ \mathrm{mm}$，用 14 个 M18 螺栓（$d_1=16.376\ \mathrm{mm}$），$[\sigma]=135\ \mathrm{MPa}$，$K_c=0.3$，要求残余预紧力 $Q'_P\ge1.7F$。确定预紧力 $Q_P$ 的取值范围。

**解**：
- 每个螺栓的工作载荷：
$$F=\frac{\dfrac{\pi}{4}D^2p}{14}=\frac{\dfrac{\pi}{4}\times120^2\times5}{14}\approx4037\ \mathrm{N}$$
- 残余预紧力：$Q'_P=1.7F=1.7\times4037=6862.9\ \mathrm{N}$
- 部分工作载荷：$\Delta F=K_cF=0.3\times4037=1211.1\ \mathrm{N}$
- 强度条件：$Q=Q'_P+F\le\dfrac{[\sigma]\dfrac{\pi}{4}d_1^2}{1.3}$，即
$$Q'_P+F-\Delta F\ \le\ Q_P\ \le\ \frac{[\sigma]\dfrac{\pi}{4}d_1^2}{1.3}-\Delta F$$

$$\therefore\quad \boxed{9688.8\ \mathrm{N}\le Q_P\le20650\ \mathrm{N}}$$

### 4-5 [[螺栓组设计|螺栓组连接的设计与受力分析]]

工程中螺栓皆成组使用，单个使用极少；**单个螺栓计算是基础和前提条件**。

**螺栓组联接设计**：选布局 → 定数目 → 力分析 → 设计尺寸。

#### 一、结构设计原则
1. **布局尽量对称分布**，螺栓组中心与联接结合面形心重合（有利于分度、划线、钻孔），使受力均匀；
2. 受弯矩和扭矩作用的螺栓组，<font color="#ff0000">螺栓应尽量远离对称轴</font>；
3. 合理间距、适当边距，以利用扳手装拆（保证扳手操作空间）。

#### 二、受力分析基本假设
1. 各螺栓的材料、尺寸、预紧力相同；
2. 被联接件是刚性的，结合面受力后仍保持平面；
3. 螺栓的变形在弹性范围内。

**避免偏心载荷**：
- 偏心载荷的来源：支承面不平、螺母孔不正、被联接件刚度小、钩头螺栓；
- 防止偏载的措施：<font color="#ff0000">凸台、凹坑（鱼眼坑）、斜垫片</font>。

#### 三、典型载荷工况的受力分析

##### 1、受轴向载荷（$P$ 通过螺栓组中心）
$$F=\frac{P}{Z}\qquad\text{（各螺栓平均分担）}$$

##### 2、受横向载荷（$R$ 通过螺栓组中心）
- 普通螺栓（受拉）：按防滑条件求 $Q_P$，再校核强度（同 4-4）；
- 铰制孔螺栓（受剪挤）：各螺栓平均分担
$$R=\frac{R_\Sigma}{Z}$$

##### 3、受旋转力矩 $T$
- **普通螺栓联接**——不滑动条件：
$$\sum fQ_Pr_i\ge K_sT\quad\Rightarrow\quad Q_P\ge\frac{K_sT}{f\sum r_i}$$
- **铰制孔螺栓联接**——变形协调（$R_i/r_i=$ 常数）+ 力矩平衡：
$$R_{\max}=\frac{T\,r_{\max}}{\sum r_i^2}$$

##### 4、受倾覆力矩 $M$
- 变形协调：各螺栓所受载荷与其到倾覆轴线（转动中心）距离成正比，$F_i/L_i=$ 常数：
$$F_{\max}=\frac{ML_{\max}}{\sum L_i^2}$$

**接合面校核**：
- 右侧不压溃：$\sigma_{P\max}=\dfrac{zQ_P}{A}+\dfrac{M}{W}\le[\sigma]_P$
- 左侧不开缝：$\sigma_{P\min}=\dfrac{zQ_P}{A}-\dfrac{M}{W}>0$

#### 四、螺栓组连接的总设计思路
1. 结构设计（确定布局与数目）；
2. 受力分析（确定每个螺栓的载荷）；
3. 找出受力最大的螺栓；
4. 按最大载荷螺栓设计 $d_1$；
5. <font color="#ff0000">全组螺栓取相同尺寸</font>（便于互换、安装）。

##### 例题 3（边板螺栓组综合，课件原题）
边板用 4 个普通螺栓与立柱相连，外载荷 $F=18\ \mathrm{kN}$，作用点距螺栓组中心 400 mm，螺栓组尺寸 200 mm × 160 mm（图示），摩擦系数 $f=0.2$，$K_s=1.3$，$[\sigma]=80\ \mathrm{MPa}$。求受力最大螺栓的横向载荷及所需 $d_1$。

**解**：
- 将 $F$ 向螺栓组中心简化：轴向分力 $F_1=\dfrac{F}{4}=\dfrac{18000}{4}=4500\ \mathrm{N}$（每螺栓），力矩 $T=F\times400=7200\ \mathrm{kN\cdot mm}$；
- 距中心最远的螺栓（$r_{\max}=\sqrt{100^2+80^2}=128.06\ \mathrm{mm}$）由力矩产生的横向载荷：
$$F_2=\frac{T}{4r_{\max}}=\frac{7200}{4\times128.06}\approx14\ \mathrm{kN}$$
- 两力夹角余弦 $\cos\theta=\dfrac{80}{\sqrt{100^2+80^2}}=0.625$，合成：
$$F_{s\max}=\sqrt{F_1^2+F_2^2+2F_1F_2\cos\theta}=\sqrt{4.5^2+14^2+2\times4.5\times14\times0.625}\approx17.175\ \mathrm{kN}$$
- 防滑条件：
$$Q_P\ge\frac{K_sF_{s\max}}{f}=\frac{1.3\times17175}{0.2}\approx111.649\ \mathrm{kN}$$
- 所需小径：
$$d_1\ge\sqrt{\frac{4\times1.3Q_P}{\pi[\sigma]}}=\sqrt{\frac{4\times1.3\times111649}{\pi\times80}}\approx48\ \mathrm{mm}$$

> [!note] 说明
> 此类题先"力向形心简化"，再求每个螺栓上"平移分力＋力矩分力"的矢量和，找最大者校核（见雨课堂填空 11 同法）。

### 4-6 提高螺栓连接强度的措施

#### 一、改善牙间载荷分布
- 机理：螺栓受拉伸长、螺母受压缩短，导致<font color="#ff0000">第一圈螺纹受力最大</font>（约占总载荷 1/3），以后各圈递减；
- <font color="#ff0000">加厚螺母并不能提高强度</font>；
- 措施及效果：**悬置螺母**（受拉变形与螺栓一致，强度可提高约 +40%）、**环槽螺母**（+30%）、**内斜螺母**（+20%）、环槽—内斜组合螺母。

#### 二、减小应力集中
- 加大过渡圆角（$r\approx0.2d$）；
- 卸载槽、卸载过渡结构（$r_1\approx0.15d$、$r_2\approx1.0d$、$h\approx0.5d$）；
- 退刀槽。

#### 三、降低螺栓应力幅 $\sigma_a$
- **降低螺栓刚度 $C_b$**：空心螺栓、细长螺栓、柔性螺栓杆（图中 $\theta_{b2}<\theta_{b1}$）；
- **增大被联接件刚度 $C_m$**：用高硬度垫片、拧紧于铸铁表面（图中 $\theta_{m2}>\theta_{m1}$）；
- **理想方法**：$C_b\downarrow$ 与 $C_m\uparrow$ 双管齐下，并适当增大预紧力 $Q_P$（$\sigma_{a2}\ll\sigma_{a1}$）。

#### 四、合理的制造工艺
- 采用**挤压、滚压**方法制造螺纹（滚压螺纹）：疲劳强度提高 30%~40%；
- **冷作硬化**（氰化、氮化、喷丸）；
- <font color="#ff0000">热处理后再滚压</font>：疲劳强度提高 70%~100%；
- 控制螺距误差（制造与装配精度）。

> [!note] 注意
> 课件原文为"热处理后再滚压"（先热处理提高心部性能，再滚压获得表面残余压应力）。雨课堂选项"滚压螺纹后再进行热处理"顺序相反，为干扰项（见多选 12）。

### 知识脉络
```
螺纹参数（d/d1/d2/P/L/n/ψ/α） → 分类（牙型/旋向/线数）
  → 连接类型（普通/铰制孔/双头螺柱/螺钉/紧定螺钉）
  → 预紧（T=K·QP·d）→ 防松（摩擦/机械/永久）
  → 单个螺栓强度计算：
      松螺栓（σ=F/A1）
      紧螺栓（复合应力 → 1.3 系数）← 横向载荷（普通：防滑 QP≥KsR/(f·i)；铰制孔：τ/σP）
      轴向紧螺栓（核心推导链）：
        拧紧变形（λb、λm）→ 加载变形协调 → 刚度比 Cb/Cm
        → Kc=Cb/(Cb+Cm) → ΔF=KcF → Q=QP+ΔF=Q'P+F
        → 残余预紧力 Q'P 四档取法 → Kc 极限讨论（最不利/最理想/禁缝隙）
        → 静强度 σca=1.3Q/A1 ≤[σ]；变载荷校核 σmax/σmin/σa
  → 螺栓组设计：结构原则 → 力向形心简化 → 各工况（轴/横/扭/倾覆）
    → 求受力最大螺栓 → 接合面校核（不压溃/不开缝）→ 设计 d1 → 全组同尺寸
  → 提高强度：牙间载荷分布 / 应力集中 / 应力幅(Cb↓+Cm↑+QP↑) / 工艺
```

## 公式速查
- **螺纹几何**：$L=nP$，$\psi=\arctan\dfrac{nP}{\pi d_2}$
- **拧紧力矩**：$T=KQ_Pd$，$K=0.1\sim0.3$
- **松螺栓**：$d_1\ge\sqrt{\dfrac{4F}{\pi[\sigma]}}$
- **紧螺栓（仅预紧/静载）**：$\sigma_{ca}=\dfrac{1.3Q}{\pi d_1^2/4}\le[\sigma]$，$d_1\ge\sqrt{\dfrac{4\times1.3Q}{\pi[\sigma]}}$（1.3=拧紧力矩对强度的影响）
- **相对刚度**：$K_c=\dfrac{C_b}{C_b+C_m}$，$\Delta F=K_cF$，$Q=Q_P+\Delta F=Q'_P+F$
- **横向载荷（普通螺栓）**：$Q_P\ge\dfrac{K_sR}{f\cdot i}$（$K_s=1.1\sim1.3$）
- **横向载荷（铰制孔）**：$\tau=\dfrac{R}{\pi d_0^2/4}\le[\tau]$，$\sigma_P=\dfrac{R}{d_0L_{\min}}\le[\sigma]_P$
- **旋转力矩**：普通 $Q_P\ge\dfrac{K_sT}{f\sum r_i}$；铰制孔 $R_{\max}=\dfrac{Tr_{\max}}{\sum r_i^2}$
- **倾覆力矩**：$F_{\max}=\dfrac{ML_{\max}}{\sum L_i^2}$；接合面 $\sigma_{P\max}=\dfrac{zQ_P}{A}+\dfrac{M}{W}\le[\sigma]_P$，$\sigma_{P\min}=\dfrac{zQ_P}{A}-\dfrac{M}{W}>0$
