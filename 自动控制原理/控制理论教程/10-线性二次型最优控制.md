## 10.1 最优控制问题

### 10.1.1 一般最优控制问题

寻找控制律 $u(t)$ 使性能指标极小化：

$$
\min_{u(t)} J = \phi(x(t_f), t_f) + \int_{t_0}^{t_f} L(x(t), u(t), t) \, dt
$$

受约束于系统动态 $\dot{x} = f(x, u, t)$。

求解方法：**变分法**、**Pontryagin 极小值原理**、**动态规划（HJB 方程）**。

### 10.1.2 线性二次型问题

对于线性系统 $\dot{x} = Ax + Bu$，二次型性能指标：

$$
J = \frac{1}{2} x^T(t_f) S x(t_f) + \frac{1}{2} \int_{0}^{t_f} \left( x^T Q x + u^T R u \right) dt
$$

其中 $Q = Q^T \geq 0$（半正定），$R = R^T > 0$（正定），$S = S^T \geq 0$。

物理意义：$x^T Q x$ 惩罚状态偏差，$u^T R u$ 惩罚控制能量。

## 10.2 有限时间 LQR

### 10.2.1 Riccati 微分方程

最优控制律：

$$
u^*(t) = -R^{-1} B^T P(t) x(t) = -K(t) x(t)
$$

其中 $P(t)$ 满足 **Riccati 微分方程（DRE）**：

$$
-\dot{P}(t) = A^T P(t) + P(t) A - P(t) B R^{-1} B^T P(t) + Q, \quad P(t_f) = S
$$

这是一个向后积分（从 $t_f$ 到 $t_0$）的矩阵微分方程。

### 10.2.2 两点边值问题（TPBVP）

最优状态-协态方程组：

$$
\begin{bmatrix} \dot{x} \\ \dot{\lambda} \end{bmatrix} =
\begin{bmatrix} A & -B R^{-1} B^T \\ -Q & -A^T \end{bmatrix}
\begin{bmatrix} x \\ \lambda \end{bmatrix}
$$

边界条件：$x(t_0) = x_0$，$\lambda(t_f) = S x(t_f)$。

哈密顿矩阵：

$$
H = \begin{bmatrix} A & -B R^{-1} B^T \\ -Q & -A^T \end{bmatrix}
$$

## 10.3 无限时间 LQR

### 10.3.1 代数 Riccati 方程

当 $t_f \to \infty$ 且 $(A, B)$ 能稳，$P(t)$ 趋于常值 $P$，满足 **代数 Riccati 方程（ARE）**：

$$
A^T P + P A - P B R^{-1} B^T P + Q = 0
$$

最优控制律为**定常状态反馈**：

$$
u^*(t) = -R^{-1} B^T P \, x(t) = -K x(t)
$$

### 10.3.2 ARE 的求解

ARE 的解 $P$ 与哈密顿矩阵 $H$ 的特征结构有关。若 $H$ 无纯虚轴特征值，则存在唯一稳定化解 $P \geq 0$。

数值求解方法：
1. **Schur 分解法**（推荐）
2. **Kleinman 迭代**
3. **求解 Lyapunov 方程序列**

### Python 实现

```python
import numpy as np
import control as ct
from scipy.linalg import solve_continuous_are

# ===== 示例：二自由度机械系统 =====
m1, m2 = 1.0, 0.5
k1, k2 = 2.0, 1.0
d = 0.2  # 阻尼

A = np.array([[0, 1, 0, 0],
              [-(k1+k2)/m1, -d/m1, k2/m1, 0],
              [0, 0, 0, 1],
              [k2/m2, 0, -k2/m2, 0]])
B = np.array([[0], [1/m1], [0], [0]])

# ---------- 有限时间 LQR 仿真 ----------
def finite_horizon_lqr(A, B, Q, R, S, tf, x0, N=1000):
    """
    有限时间 LQR 仿真
    
    向后积分 Riccati 微分方程，再向前仿真系统轨迹
    """
    n = A.shape[0]
    dt = tf / N
    t = np.linspace(0, tf, N+1)
    
    # 向后积分 Riccati 微分方程
    P_list = [S]
    P = S.copy()
    for k in range(N, 0, -1):
        P_dot = -(A.T @ P + P @ A - P @ B @ np.linalg.inv(R) @ B.T @ P + Q)
        P = P - dt * P_dot  # Euler 向后
        P_list.insert(0, P.copy())
    
    # 向前仿真
    x = x0.copy()
    x_traj = [x.copy()]
    u_traj = []
    
    for k in range(N):
        P_k = P_list[k]
        K_k = np.linalg.inv(R) @ B.T @ P_k
        u = -K_k @ x
        u_traj.append(u)
        
        dx = A @ x + B @ u
        x = x + dt * dx
        x_traj.append(x.copy())
    
    return np.array(t), np.array(x_traj), np.array(u_traj)

# 参数设置
Q = np.diag([10, 0.1, 10, 0.1])
R = np.array([[0.1]])
S = np.diag([5, 1, 5, 1])
x0 = np.array([1.0, 0, -0.5, 0])

t_fin, x_fin, u_fin = finite_horizon_lqr(A, B, Q, R, S, tf=10, x0=x0)

print(f"初始状态: {x0}")
print(f"终端状态: {x_fin[-1, :]}")

# ---------- 无限时间 LQR ----------
P_inf = solve_continuous_are(A, B, Q, R)
K_inf = np.linalg.inv(R) @ B.T @ P_inf
print(f"\n无限时间 ARE 解 P =\n{P_inf}")
print(f"最优反馈增益 K = {K_inf}")

# 验证闭环稳定性
A_cl_inf = A - B @ K_inf
eig_cl = np.linalg.eigvals(A_cl_inf)
print(f"闭环极点: {eig_cl}")
print(f"所有极点在左半平面: {all(np.real(eig_cl) < 0)}")

# ---------- 对比有限时间与无限时间轨迹 ----------
def simulate_lqr_closed_loop(A, B, K, x0, tf, N=1000):
    dt = tf / N
    x = x0.copy()
    x_traj = [x.copy()]
    t = np.linspace(0, tf, N+1)
    for k in range(N):
        u = -K @ x
        dx = A @ x + B @ u
        x = x + dt * dx
        x_traj.append(x.copy())
    return np.array(t), np.array(x_traj)

t_inf, x_inf = simulate_lqr_closed_loop(A, B, K_inf, x0, tf=10)

import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 2, figsize=(12, 8))
labels = ['$x_1$ (位置1)', '$x_2$ (速度1)', '$x_3$ (位置2)', '$x_4$ (速度2)']
for i, ax in enumerate(axes.flat):
    ax.plot(t_fin, x_fin[:, i], 'b-', label='有限时间 LQR')
    ax.plot(t_inf, x_inf[:, i], 'r--', label='无限时间 LQR')
    ax.set_xlabel('t (s)')
    ax.set_ylabel(labels[i])
    ax.legend()
    ax.grid(True)
fig.suptitle('LQR 控制：有限时间 vs 无限时间')
plt.tight_layout()
plt.show()

# ---------- 权重矩阵影响分析 ----------
R_values = [0.01, 0.1, 1.0, 10.0]
Q = np.diag([10, 1, 10, 1])

fig2, axes2 = plt.subplots(2, 2, figsize=(12, 8))
for R_val, ax in zip(R_values, axes2.flat):
    R_mat = np.array([[R_val]])
    P = solve_continuous_are(A, B, Q, R_mat)
    K = np.linalg.inv(R_mat) @ B.T @ P
    t, x = simulate_lqr_closed_loop(A, B, K, x0, tf=10)
    
    ax.plot(t, x[:, 0], label='$x_1$')
    ax.plot(t, x[:, 2], label='$x_3$')
    ax.set_title(f'R = {R_val}')
    ax.set_xlabel('t (s)')
    ax.legend()
    ax.grid(True)
fig2.suptitle('不同控制权重 R 对响应的影响')
plt.tight_layout()
plt.show()
```

## 10.4 线性二次型高斯控制（LQG）

### 10.4.1 问题描述

当系统存在过程噪声 $w$ 和测量噪声 $v$ 时：

$$
\dot{x} = Ax + Bu + w, \quad y = Cx + v
$$

其中 $w \sim \mathcal{N}(0, W)$，$v \sim \mathcal{N}(0, V)$，且 $W \geq 0$，$V > 0$。

性能指标为期望值：

$$
J = \mathbb{E} \left[ \lim_{T \to \infty} \frac{1}{T} \int_0^T (x^T Q x + u^T R u) \, dt \right]
$$

### 10.4.2 LQG 分离定理

**定理 10.1（LQG 分离定理）**：LQG 问题的最优控制器由两部分独立组成：

1. **LQR 状态反馈增益**：$K = R^{-1} B^T P$
2. **Kalman 滤波器增益**：$L = \Sigma C^T V^{-1}$

其中 $P$ 和 $\Sigma$ 分别满足两个代数 Riccati 方程：

**控制 ARE**：

$$
A^T P + P A - P B R^{-1} B^T P + Q = 0
$$

**滤波 ARE**：

$$
A \Sigma + \Sigma A^T - \Sigma C^T V^{-1} C \Sigma + W = 0
$$

## 10.5 Kalman 滤波器

### 10.5.1 连续时间 Kalman 滤波器

滤波方程（Kalman-Bucy 滤波器）：

$$
\dot{\hat{x}} = A\hat{x} + Bu + L(t)(y - C\hat{x})
$$

增益：$L(t) = \Sigma(t) C^T V^{-1}$

协方差传播（Riccati 微分方程）：

$$
\dot{\Sigma}(t) = A\Sigma + \Sigma A^T - \Sigma C^T V^{-1} C \Sigma + W, \quad \Sigma(0) = \Sigma_0
$$

### 10.5.2 离散时间 Kalman 滤波器（五大公式）

离散系统模型：

$$
x_k = F x_{k-1} + G u_{k-1} + w_{k-1}, \quad w_k \sim \mathcal{N}(0, W)
$$
$$
y_k = H x_k + v_k, \quad v_k \sim \mathcal{N}(0, V)
$$

**五大核心公式**：

**预测步骤**：

$$
\begin{aligned}
\hat{x}_{k|k-1} &= F \hat{x}_{k-1|k-1} + G u_{k-1} \quad &\text{(1) 状态预测} \\
\Sigma_{k|k-1} &= F \Sigma_{k-1|k-1} F^T + W \quad &\text{(2) 协方差预测}
\end{aligned}
$$

**更新步骤**：

$$
\begin{aligned}
K_k &= \Sigma_{k|k-1} H^T (H \Sigma_{k|k-1} H^T + V)^{-1} \quad &\text{(3) Kalman 增益} \\
\hat{x}_{k|k} &= \hat{x}_{k|k-1} + K_k (y_k - H \hat{x}_{k|k-1}) \quad &\text{(4) 状态更新} \\
\Sigma_{k|k} &= (I - K_k H) \Sigma_{k|k-1} \quad &\text{(5) 协方差更新}
\end{aligned}
$$

### Python 实现：Kalman 滤波器仿真

```python
import numpy as np

class KalmanFilter:
    """离散时间 Kalman 滤波器"""
    def __init__(self, F, G, H, W, V, x0, P0):
        self.F = F; self.G = G; self.H = H
        self.W = W; self.V = V
        self.x = x0.reshape(-1, 1)
        self.P = P0
        self.n = F.shape[0]
    
    def predict(self, u=None):
        if u is None:
            u = np.zeros((self.G.shape[1], 1))
        else:
            u = u.reshape(-1, 1)
        
        self.x = self.F @ self.x + self.G @ u          # (1)
        self.P = self.F @ self.P @ self.F.T + self.W   # (2)
        return self.x.flatten(), self.P
    
    def update(self, y):
        y = y.reshape(-1, 1)
        
        # (3) Kalman 增益
        S = self.H @ self.P @ self.H.T + self.V
        K = self.P @ self.H.T @ np.linalg.inv(S)
        
        # (4) 状态更新
        innovation = y - self.H @ self.x
        self.x = self.x + K @ innovation
        
        # (5) 协方差更新
        self.P = (np.eye(self.n) - K @ self.H) @ self.P
        
        return self.x.flatten(), self.P, K

# ===== 仿真：目标跟踪 =====
dt = 0.1
# 状态: [位置, 速度]
F = np.array([[1, dt], [0, 1]])
G = np.array([[0.5*dt**2], [dt]])
H = np.array([[1, 0]])  # 仅测量位置

# 噪声协方差
W = np.diag([0.01, 0.1])  # 过程噪声
V = np.array([[0.5]])     # 测量噪声

# 真实轨迹
T = 20
t = np.arange(0, T, dt)
N = len(t)
x_true = np.zeros((2, N))
x_true[:, 0] = [0, 1]  # 初始位置0, 速度1
for k in range(1, N):
    w = np.random.multivariate_normal([0, 0], W)
    x_true[:, k] = F @ x_true[:, k-1] + w

y_meas = np.zeros(N)
for k in range(N):
    v = np.random.normal(0, np.sqrt(V[0,0]))
    y_meas[k] = H @ x_true[:, k] + v

# Kalman 滤波
kf = KalmanFilter(F, G, H, W, V,
                  x0=np.array([0, 0]),
                  P0=np.eye(2)*1)

x_est = np.zeros((2, N))
P_trace = np.zeros(N)

for k in range(N):
    kf.predict()
    x_est[:, k], P, _ = kf.update(np.array([y_meas[k]]))
    P_trace[k] = np.trace(P)

# 绘图
import matplotlib.pyplot as plt

fig, axes = plt.subplots(3, 1, figsize=(12, 9), sharex=True)

axes[0].plot(t, x_true[0, :], 'k-', linewidth=2, label='真实位置')
axes[0].scatter(t[::5], y_meas[::5], s=15, c='r', alpha=0.6, label='测量值')
axes[0].plot(t, x_est[0, :], 'b--', linewidth=1.5, label='Kalman 估计')
axes[0].set_ylabel('位置')
axes[0].legend(); axes[0].grid(True)

axes[1].plot(t, x_true[1, :], 'k-', linewidth=2, label='真实速度')
axes[1].plot(t, x_est[1, :], 'b--', linewidth=1.5, label='Kalman 估计')
axes[1].set_ylabel('速度')
axes[1].legend(); axes[1].grid(True)

pos_err = x_true[0, :] - x_est[0, :]
axes[2].plot(t, pos_err, 'g-', alpha=0.7)
axes[2].fill_between(t, -2*np.sqrt(P_trace[:N]),
                     2*np.sqrt(P_trace[:N]), alpha=0.2, color='g')
axes[2].set_ylabel('位置估计误差')
axes[2].set_xlabel('时间 (s)')
axes[2].grid(True)

fig.suptitle('Kalman 滤波器：一维目标跟踪')
plt.tight_layout()
plt.show()
```

## 10.6 扩展 Kalman 滤波器（EKF）

对于非线性系统：

$$
x_k = f(x_{k-1}, u_{k-1}) + w_{k-1}, \quad y_k = h(x_k) + v_k
$$

核心思想：对非线性函数进行一阶 Taylor 展开，线性化处理。

**预测步骤**：

$$
\begin{aligned}
\hat{x}_{k|k-1} &= f(\hat{x}_{k-1|k-1}, u_{k-1}) \\
\Sigma_{k|k-1} &= F_{k-1} \Sigma_{k-1|k-1} F_{k-1}^T + W
\end{aligned}
$$

其中 Jacobian $F_{k-1} = \frac{\partial f}{\partial x}\big|_{\hat{x}_{k-1|k-1}}$。

**更新步骤**：

$$
\begin{aligned}
K_k &= \Sigma_{k|k-1} H_k^T (H_k \Sigma_{k|k-1} H_k^T + V)^{-1} \\
\hat{x}_{k|k} &= \hat{x}_{k|k-1} + K_k (y_k - h(\hat{x}_{k|k-1})) \\
\Sigma_{k|k} &= (I - K_k H_k) \Sigma_{k|k-1}
\end{aligned}
$$

其中 Jacobian $H_k = \frac{\partial h}{\partial x}\big|_{\hat{x}_{k|k-1}}$。

## 10.7 LQR 的扩展形式

### 10.7.1 输出加权 LQR

当关心输出 $y = Cx$ 而非全状态时，性能指标可设为：

$$
J = \frac{1}{2} \int_0^\infty \left( y^T Q_y y + u^T R u \right) dt = \frac{1}{2} \int_0^\infty \left( x^T C^T Q_y C x + u^T R u \right) dt
$$

等效状态权重 $Q = C^T Q_y C$，直接代入标准 ARE 求解即可。

### 10.7.2 具有交叉项的 LQR

性能指标含状态-控制交叉项 $x^T N u$ 时：

$$
J = \frac{1}{2} \int_0^\infty \left( x^T Q x + 2x^T N u + u^T R u \right) dt
$$

ARE 变为：

$$
A^T P + P A - (P B + N) R^{-1} (B^T P + N^T) + Q = 0
$$

最优增益：$K = R^{-1}(B^T P + N^T)$

### 10.7.3 LQR 跟踪问题

问题：使输出 $y$ 跟踪参考信号 $r(t)$。对于阶跃参考信号（$\dot{r} = 0$），可使用 [[09-极点配置与状态反馈|09 章]] 的积分增广方法联合设计。

### 10.7.4 LQR 的频域特性

无限时间 LQR 具有优异的频域鲁棒性：

$$
\left| \frac{1}{1 + K(j\omega I - A)^{-1} B} \right|_\infty \leq 2
$$

即灵敏度函数峰值不超过 2（6 dB），保证了增益裕度 $(-6\text{ dB}, +\infty)$ 和至少 $60^\circ$ 的相位裕度。

## 10.8 离散时间 LQR

### 10.8.1 离散等价形式

离散系统 $x_{k+1} = A_d x_k + B_d u_k$，代价函数：

$$
J = \frac{1}{2} \sum_{k=0}^{\infty} \left( x_k^T Q x_k + u_k^T R u_k \right)
$$

**离散代数 Riccati 方程（DARE）**：

$$
P = A_d^T P A_d - A_d^T P B_d (R + B_d^T P B_d)^{-1} B_d^T P A_d + Q
$$

最优反馈增益：$K = (R + B_d^T P B_d)^{-1} B_d^T P A_d$

### Python 实现

```python
from scipy.linalg import solve_discrete_are

def discrete_lqr(A_d, B_d, Q, R):
    P = solve_discrete_are(A_d, B_d, Q, R)
    K = np.linalg.inv(R + B_d.T @ P @ B_d) @ B_d.T @ P @ A_d
    return K, P

# 示例：离散化倒立摆后求解
dt = 0.01
A_d_ct = np.eye(4) + dt * A
B_d_ct = dt * B
K_d, P_d = discrete_lqr(A_d_ct, B_d_ct, Q, R)
print(f"离散 LQR 增益 K = {K_d}")
```

### 10.8.2 离散与连续 LQR 的关系

当采样周期 $T_s \to 0$ 时，离散 LQR 增益趋于连续 LQR 增益。对于充分小的 $T_s$：

$$
K_d \approx K_c \left( I - \frac{T_s}{2} (A - B K_c) \right)
$$

## 10.9 LQG 回路传递恢复（LTR）

LQG 由 LQR + Kalman 组成，但其单独不保证与 LQR 同等的频域鲁棒性。

**LTR at input**：将 Kalman 滤波器的过程噪声协方差设为 $W = W_0 + q B B^T$。当 $q \to \infty$ 时，开环传递函数恢复为 LQR 的等价形式，从而恢复其鲁棒性（增益裕度、相位裕度）。代价为 $q$ 过大时噪声放大严重，需折中设计。

## 总结

| 方法 | 核心方程 | 适用场景 |
|------|---------|---------|
| 有限时间 LQR | $-\dot{P} = A^T P + PA - PBR^{-1}B^T P + Q$ | 终端时间固定 |
| 无限时间 LQR | $A^T P + PA - PBR^{-1}B^T P + Q = 0$ | 稳态调节 |
| Kalman 滤波 | 五大公式（预测+更新） | 线性高斯系统 |
| LQG | LQR + Kalman + 分离定理 | 含噪声的线性系统 |
| EKF | Jacobian 线性化 + Kalman | 弱非线性系统 |

> LQR/LQG 是现代控制理论中应用最广泛的最优控制方法，为多变量系统提供了一种系统化的设计框架。

> 权重矩阵 $Q$ 和 $R$ 的选择是 LQR 设计的关键：$Q$ 大则响应快但控制量大；$R$ 大则控制平滑但响应慢。实际应用中需反复调试。
