## 9.1 状态反馈的基本概念

### 9.1.1 状态反馈结构

考虑线性定常系统：

$$
\dot{x} = Ax + Bu, \quad y = Cx
$$

**状态反馈控制律**：

$$
u = -Kx + v
$$

其中 $K \in \mathbb{R}^{m \times n}$ 为状态反馈增益矩阵，$v$ 为参考输入。

闭环系统：

$$
\dot{x} = (A - BK)x + Bv
$$

闭环系统矩阵为 $A_{cl} = A - BK$。

### 9.1.2 输出反馈与状态反馈的比较

| 特性 | 输出反馈 $u = -Ky + v$ | 状态反馈 $u = -Kx + v$ |
|------|------------------------|------------------------|
| 反馈量 | 输出 $y$（可测） | 状态 $x$（未必可测） |
| 闭环系统矩阵 | $A - BKC$ | $A - BK$ |
| 自由度 | $m \times p$ | $m \times n$ |
| 极点配置能力 | 有限 | 完全（系统能控时） |

## 9.2 极点配置定理

### 9.2.1 极点配置的基本结论

**定理 9.1（极点配置定理）**：线性定常系统 $\dot{x} = Ax + Bu$ 可通过状态反馈 $u = -Kx$ **任意配置闭环极点**的充要条件是：系统**完全能控**。

即：$\text{rank}(Q_c) = \text{rank}[B, AB, \dots, A^{n-1}B] = n$。

### 9.2.2 多输入系统的极点配置

对于多输入系统 $(m > 1)$，极点配置的解不唯一。常用方法：

1. **转化为单输入问题**：取 $u = -Kx = -\rho f^T x$，将问题简化为选取 $f^T$ 使得 $(A, B\rho)$ 能控
2. **直接求解 Lyapunov 方程**
3. **特征结构配置**

### 9.2.3 单输入系统的极点配置

对于单输入系统，期望极点 $\lambda_1^*, \lambda_2^*, \dots, \lambda_n^*$ 对应期望特征多项式：

$$
\alpha^*(s) = \prod_{i=1}^{n}(s - \lambda_i^*) = s^n + a_{n-1}^* s^{n-1} + \cdots + a_1^* s + a_0^*
$$

状态反馈增益可唯一确定。

## 9.3 Ackermann 公式

对于单输入能控系统，状态反馈增益矩阵 $K$ 由 Ackermann 公式直接给出：

$$
K = [0 \ 0 \ \cdots \ 0 \ 1] \ Q_c^{-1} \ \alpha^*(A)
$$

其中 $\alpha^*(A)$ 是将期望特征多项式中的 $s$ 替换为系统矩阵 $A$ 得到：

$$
\alpha^*(A) = A^n + a_{n-1}^* A^{n-1} + \cdots + a_1^* A + a_0^* I
$$

### Python 实现

```python
import numpy as np
import control as ct

def ackermann(A, B, poles):
    """
    Ackermann 公式计算状态反馈增益 K
    
    参数:
        A: 系统矩阵 (n×n)
        B: 输入矩阵 (n×1), 仅支持单输入
        poles: 期望极点列表
    
    返回:
        K: 状态反馈增益矩阵 (1×n)
    """
    return ct.acker(A, B, poles)

# ===== 示例：倒立摆系统 =====
g = 9.81; l = 0.5; m = 0.2; M = 0.5

A = np.array([[0, 1, 0, 0],
              [0, 0, -m*g/M, 0],
              [0, 0, 0, 1],
              [0, 0, (M+m)*g/(M*l), 0]])
B = np.array([[0], [1/M], [0], [-1/(M*l)]])

# 检查能控性
Qc = ct.ctrb(A, B)
print(f"能控性矩阵秩: {np.linalg.matrix_rank(Qc)} (应等于 {A.shape[0]})")

# 期望极点（左半平面，使系统稳定）
desired_poles = [-2, -3, -2+1j, -2-1j]
K = ackermann(A, B, desired_poles)
print(f"状态反馈增益 K = {K}")

# 验证闭环极点
A_cl = A - B @ K
eig_cl = np.linalg.eigvals(A_cl)
print(f"闭环极点: {eig_cl}")
```

## 9.4 利用能控标准型进行极点配置

### 9.4.1 能控标准型方法

对于单输入系统 $(A, b)$，若系统能控，可先通过坐标变换 $z = T_c x$ 将系统化为第一能控标准型：

$$
\dot{z} = \begin{bmatrix}
0 & 1 & 0 & \cdots & 0 \\
0 & 0 & 1 & \cdots & 0 \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
0 & 0 & 0 & \cdots & 1 \\
-a_0 & -a_1 & -a_2 & \cdots & -a_{n-1}
\end{bmatrix} z +
\begin{bmatrix} 0 \\ 0 \\ \vdots \\ 0 \\ 1 \end{bmatrix} u
$$

其中 $a_0, \dots, a_{n-1}$ 为开环特征多项式 $\det(sI - A) = s^n + a_{n-1}s^{n-1} + \cdots + a_0$ 的系数。

设状态反馈 $u = -K_z z + v$，闭环系统矩阵为：

$$
A_z - b_z K_z = \begin{bmatrix}
0 & 1 & 0 & \cdots & 0 \\
0 & 0 & 1 & \cdots & 0 \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
0 & 0 & 0 & \cdots & 1 \\
-(a_0 + k_1) & -(a_1 + k_2) & -(a_2 + k_3) & \cdots & -(a_{n-1} + k_n)
\end{bmatrix}
$$

令期望闭环特征多项式为 $\alpha^*(s) = s^n + \alpha_{n-1}^* s^{n-1} + \cdots + \alpha_0^*$，则：

$$
k_i = \alpha_{i-1}^* - a_{i-1}, \quad i = 1, 2, \dots, n
$$

变换回原坐标：$K = K_z T_c$。

### 9.4.2 变换矩阵的构造

第一能控标准型的变换矩阵：

$$
T_c = \begin{bmatrix} t_1 \\ t_1 A \\ \vdots \\ t_1 A^{n-1} \end{bmatrix}^{-1}
$$

其中 $t_1 = [0 \ \dots \ 0 \ 1] Q_c^{-1}$ 为能控性矩阵逆的最后一行。

## 9.5 Luenberger 状态观测器

### 9.4.1 全维状态观测器

当状态 $x$ 不可直接测量时，需要设计**状态观测器**估计 $\hat{x}$。

**Luenberger 观测器方程**：

$$
\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x})
$$

其中 $L \in \mathbb{R}^{n \times p}$ 为观测器增益矩阵。

定义估计误差 $e = x - \hat{x}$，则误差动态：

$$
\dot{e} = (A - LC)e
$$

### 9.4.2 观测器极点配置

**定理 9.2（对偶原理）**：$(A, C)$ 能观的充要条件是 $(A^T, C^T)$ 能控。

因此，观测器极点配置问题等价于对 $(A^T, C^T)$ 进行状态反馈极点配置：

$$
L^T = \text{acker}(A^T, C^T, \text{desired\_observer\_poles})
$$

**设计原则**：观测器极点通常选为控制器极点的 2~5 倍快（实部更负），使估计误差快速衰减。

### 9.4.3 降维观测器

当部分状态可测时，只需估计不可测的状态，降低观测器阶数。

假设 $y = Cx = [I_p \ 0]x$，将状态分块：

$$
\begin{bmatrix} \dot{x}_1 \\ \dot{x}_2 \end{bmatrix} =
\begin{bmatrix} A_{11} & A_{12} \\ A_{21} & A_{22} \end{bmatrix}
\begin{bmatrix} x_1 \\ x_2 \end{bmatrix} +
\begin{bmatrix} B_1 \\ B_2 \end{bmatrix} u
$$

其中 $x_1 = y$ 可测，只需估计 $x_2$（$n-p$ 维）。

### Python 实现：全维观测器

```python
import numpy as np
import control as ct

def design_luenberger_observer(A, C, observer_poles):
    """
    设计 Luenberger 全维观测器
    
    返回:
        L: 观测器增益矩阵 (n×p)
    """
    # 利用对偶原理
    L = ct.acker(A.T, C.T, observer_poles).T
    return L

# ===== 示例：倒立摆观测器设计 =====
C = np.array([[1, 0, 0, 0],    # 测量小车位置
              [0, 0, 1, 0]])   # 测量摆角

# 观测器极点（比控制器极点快 3 倍）
obs_poles = [-6, -7, -6+3j, -6-3j]
L = design_luenberger_observer(A, C, obs_poles)
print(f"观测器增益 L =\n{L}")

# 验证观测器极点
A_obs = A - L @ C
eig_obs = np.linalg.eigvals(A_obs)
print(f"观测器极点: {eig_obs}")

# ===== 仿真：状态估计 =====
from scipy.integrate import solve_ivp

def observer_system(t, z, A, B, C, K, L):
    """z = [x; x_hat]"""
    n = A.shape[0]
    x = z[:n]
    x_hat = z[n:]

    u = -K @ x_hat  # 基于估计状态的控制
    y = C @ x       # 实际输出

    dx = A @ x + B @ u
    dx_hat = A @ x_hat + B @ u + L @ (y - C @ x_hat)

    return np.concatenate([dx, dx_hat])

# 初始状态
x0 = np.array([0.5, 0, 0.1, 0])
x0_hat = np.array([0, 0, 0, 0])
z0 = np.concatenate([x0, x0_hat])

t_span = (0, 10)
sol = solve_ivp(observer_system, t_span, z0,
                args=(A, B, C, K, L),
                max_step=0.01, rtol=1e-6)

# 绘制估计误差
import matplotlib.pyplot as plt
t = sol.t
e = sol.y[:4, :] - sol.y[4:, :]

fig, axes = plt.subplots(4, 1, figsize=(10, 8), sharex=True)
labels = ['小车位置', '小车速度', '摆角', '摆角速度']
for i in range(4):
    axes[i].plot(t, e[i, :])
    axes[i].set_ylabel(f'e_{i+1}: {labels[i]}')
    axes[i].grid(True)
axes[-1].set_xlabel('时间 t (s)')
fig.suptitle('状态估计误差')
plt.tight_layout()
plt.show()
```

## 9.7 分离原理

### 9.7.1 基本原理

**定理 9.3（分离原理 / Separation Principle）**：对于能控且能观的线性系统，状态反馈控制器和状态观测器可以**独立设计**，组合系统的极点集合为控制器极点与观测器极点的**并集**。

即：

$$
\Lambda(A_{cl}^{\text{combined}}) = \Lambda(A - BK) \cup \Lambda(A - LC)
$$

### 9.7.2 证明概要

组合系统状态为 $[x^T, e^T]^T$，其中 $e = x - \hat{x}$：

$$
\begin{bmatrix} \dot{x} \\ \dot{e} \end{bmatrix} =
\begin{bmatrix} A - BK & BK \\ 0 & A - LC \end{bmatrix}
\begin{bmatrix} x \\ e \end{bmatrix}
$$

该矩阵是**上三角分块矩阵**，特征值为对角块特征值的并集，即得证。

### 9.7.3 基于观测器的输出反馈控制器

完整控制器结构：

1. **设计状态反馈增益** $K$：使 $A-BK$ 具有期望极点
2. **设计观测器增益** $L$：使 $A-LC$ 具有期望极点（通常比 $A-BK$ 快 2~5 倍）
3. **组合实现**：

$$
\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x}), \quad u = -K\hat{x} + v
$$

## 9.8 积分型状态反馈（伺服系统设计）

为使系统输出无静差跟踪阶跃参考输入，引入积分器：

$$
\dot{x}_I = r - y = r - Cx
$$

增广系统：

$$
\begin{bmatrix} \dot{x} \\ \dot{x}_I \end{bmatrix} =
\begin{bmatrix} A & 0 \\ -C & 0 \end{bmatrix}
\begin{bmatrix} x \\ x_I \end{bmatrix} +
\begin{bmatrix} B \\ 0 \end{bmatrix} u +
\begin{bmatrix} 0 \\ I \end{bmatrix} r
$$

控制律：

$$
u = -Kx + K_I x_I
$$

增益 $[K, -K_I]$ 可通过极点配置确定。

### 9.8.1 积分型伺服系统的完整实现

```python
import numpy as np
import control as ct

def design_servo_system(A, B, C, desired_poles):
    """
    设计积分型伺服系统
    
    增广系统:
        [ẋ]   [A  0] [x]   [B]     [0]
        [ẋI] = [-C 0] [xI] + [0] u + [I] r
    """
    n = A.shape[0]
    p = C.shape[0]
    
    # 增广系统矩阵
    A_aug = np.block([[A, np.zeros((n, p))],
                      [-C, np.zeros((p, p))]])
    B_aug = np.block([[B], [np.zeros((p, B.shape[1]))]])
    
    # 极点配置
    K_aug = ct.acker(A_aug, B_aug, desired_poles)
    
    # 分离反馈增益和积分增益
    K = K_aug[:, :n]
    KI = -K_aug[:, n:]  # u = -Kx + KI*xI
    
    return K, KI

# ===== 示例 =====
# 使用之前的倒立摆系统 (A, B, C)
n_poles = A.shape[0] + C.shape[0]  # 增广系统阶数
servo_poles = [-2, -3, -4, -5, -6, -7]  # 6 个极点

K_servo, KI_servo = design_servo_system(A, B, C, servo_poles)
print(f"状态反馈增益 K = {K_servo}")
print(f"积分增益 KI = {KI_servo}")
```

### 9.8.2 与 PID 控制的关系

积分型状态反馈可被视为**多变量广义 PID**：

| PID 部件 | 状态反馈对应 |
|---------|------------|
| 比例 P | 状态反馈 $Kx$ 中的可测输出部分 |
| 积分 I | 积分增广 $K_I \int e \, dt$ |
| 微分 D | 状态反馈中的速率状态（如速度估计） |

## 9.9 极点选择的设计准则

### 9.9.1 主导极点法

对于高阶系统，响应主要由靠近虚轴的**主导极点**决定。

**设计步骤**：

1. 根据时域指标确定主导极点位置
2. 将非主导极点配置在比主导极点远 5~10 倍的位置
3. 验证非主导极点对响应的实际影响

### 9.9.2 常见极点配置模式

| 应用场景 | 典型极点位置 | 说明 |
|---------|------------|------|
| ITAE 最优 | 参考 ITAE 标准多项式 | 最小化时间乘绝对误差积分 |
| Butterworth | 均匀分布在左半圆 | 最大平坦幅频特性 |
| Bessel | 按 Bessel 多项式分布 | 最小相位失真 |
| 二项式 | 多重实极点 | 无超调响应 |

**ITAE 最优标准多项式系数**（以 $\omega_n$ 归一化）：

| 阶数 | 特征多项式 $s^n + a_{n-1} \omega_n s^{n-1} + \cdots + a_0 \omega_n^n$ |
|------|------|
| 2 | $s^2 + 1.4 \omega_n s + \omega_n^2$ |
| 3 | $s^3 + 1.75 \omega_n s^2 + 2.15 \omega_n^2 s + \omega_n^3$ |
| 4 | $s^4 + 2.1 \omega_n s^3 + 3.4 \omega_n^2 s^2 + 2.7 \omega_n^3 s + \omega_n^4$ |
| 5 | $s^5 + 2.8 \omega_n s^4 + 5.0 \omega_n^2 s^3 + 5.5 \omega_n^3 s^2 + 3.4 \omega_n^4 s + \omega_n^5$ |

### 9.9.3 执行器饱和的考虑

当执行器存在饱和 $|u| \leq u_{\max}$ 时，过于激进的极点（过快响应）会导致**积分 Windup** 和性能恶化。建议：

1. 根据执行器能力合理选择 $\omega_n$
2. 引入 Anti-Windup 机制
3. 在性能和控制能量之间折中（参见 [[10-线性二次型最优控制|LQR]] 的权重选择）

## 总结

| 概念 | 核心公式 | 条件 |
|------|---------|------|
| 状态反馈 | $u = -Kx + v$ | — |
| 极点配置 | $\det(sI - A + BK) = \alpha^*(s)$ | 系统能控 |
| Ackermann 公式 | $K = e_n^T Q_c^{-1} \alpha^*(A)$ | 单输入能控 |
| Luenberger 观测器 | $\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x})$ | 系统能观 |
| 分离原理 | $\Lambda = \Lambda(A-BK) \cup \Lambda(A-LC)$ | 能控+能观 |
| 积分型反馈 | 增广积分状态 $x_I$ | 消除静差 |

> 极点配置是实现状态反馈控制器设计的核心方法。结合 Luenberger 观测器和分离原理，可以构造出完整的基于观测器的输出反馈控制系统。
