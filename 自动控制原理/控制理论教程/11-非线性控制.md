## 11.1 非线性系统的特性

### 11.1.1 非线性现象的典型特征

与线性系统不同，非线性系统展现出独特的动力学行为：

| 现象 | 描述 | 示例 |
|------|------|------|
| **多平衡点** | 系统存在多个孤立平衡点 | 摆的竖直向下/向上位置 |
| **极限环** | 孤立的周期轨道（自激振荡） | van der Pol 振荡器 |
| **混沌** | 对初值极端敏感的确定性运动 | Lorenz 系统 |
| **分岔** | 参数变化时系统定性行为的突变 | Hopf 分岔 |
| **有限逃逸时间** | 状态在有限时间趋于无穷 | $\dot{x} = x^2$ |
| **死区/饱和/迟滞** | 常见的非光滑非线特性 | 执行器特性 |

### 11.1.2 非线性系统 vs 线性系统

| 性质 | 线性系统 | 非线性系统 |
|------|---------|-----------|
| 叠加原理 | 成立 | 不成立 |
| 稳定性 | 全局性质（与初值无关） | 局部性质（与初值相关） |
| 分析工具 | 传递函数、频率特性 | Lyapunov 函数、相平面 |
| 设计方法 | 极点配置、LQR | 反馈线性化、滑模、Backstepping |

### 11.1.3 非线性系统数学模型

一般形式：

$$
\dot{x} = f(x, u, t), \quad y = h(x, u, t)
$$

**仿射非线性系统**（最常见的工程模型）：

$$
\dot{x} = f(x) + g(x) u, \quad y = h(x)
$$

## 11.2 Lyapunov 稳定性理论

### 11.2.1 稳定性概念

考虑自治系统 $\dot{x} = f(x)$，$f(0) = 0$。

**定义**：

- **Lyapunov 稳定**：$\forall \varepsilon > 0, \exists \delta > 0$ 使得 $\|x(0)\| < \delta \Rightarrow \|x(t)\| < \varepsilon, \forall t \geq 0$
- **渐近稳定**：Lyapunov 稳定且 $\lim_{t \to \infty} x(t) = 0$
- **指数稳定**：$\exists \alpha, \lambda > 0$ 使得 $\|x(t)\| \leq \alpha \|x(0)\| e^{-\lambda t}$
- **全局渐近稳定**：渐近稳定且对任意初值成立

### 11.2.2 Lyapunov 直接法（第二方法）

**定理 11.1（Lyapunov 直接法）**：若能找到连续可微函数 $V(x)$ 满足：

1. $V(0) = 0$，$V(x) > 0, \forall x \neq 0$（正定）
2. $\dot{V}(x) = \frac{\partial V}{\partial x} f(x) \leq 0, \forall x$（半负定）

则原点 Lyapunov 稳定。若进一步 $\dot{V}(x) < 0$（负定），则原点是渐近稳定的。

**推论**：若 $V(x) \to \infty$ 当 $\|x\| \to \infty$（径向无界），且 $\dot{V} < 0$，则原点**全局渐近稳定**。

### 11.2.3 LaSalle 不变性原理

当 $\dot{V}$ 仅为半负定时，可通过 LaSalle 原理判断渐近稳定性：

设 $\Omega_c = \{x : V(x) \leq c\}$ 为紧集，且 $\dot{V}(x) \leq 0$ 在 $\Omega_c$ 上。令 $E = \{x \in \Omega_c : \dot{V}(x) = 0\}$，$M$ 为 $E$ 中的最大不变集。则当 $t \to \infty$ 时，轨线趋于 $M$。

### 11.2.4 构造 Lyapunov 函数的方法

1. **物理系统的总能量**：机械能、电磁能
2. **Krasovskii 方法**：$V(x) = f^T(x) P f(x)$
3. **变梯度法**：设 $\nabla V = [g_1(x), \dots, g_n(x)]^T$，通过旋度条件确定
4. **平方和（SOS）方法**：利用半定规划求解

## 11.3 滑模控制（Sliding Mode Control）

### 11.3.1 滑模控制的基本思想

滑模控制是一种**变结构控制**方法，通过不连续的控制律将系统状态驱动到预设的滑模面上，并沿滑模面滑动至平衡点。

**核心要素**：

1. **滑模面** $s(x) = 0$
2. **趋近律**：设计 $u$ 使 $s$ 快速趋于零
3. **抖振（Chattering）** 及其抑制

### 11.3.2 滑模面设计

对于 $n$ 阶系统 $\dot{x}_1 = x_2, \dot{x}_2 = x_3, \dots, \dot{x}_n = f(x) + g(x)u$：

线性滑模面：

$$
s(x) = \left( \frac{d}{dt} + \lambda \right)^{n-1} e
$$

其中 $e = x_1 - x_{1d}$ 为跟踪误差。当 $s = 0$ 时，误差按 $e^{(n-1)} + \cdots + \lambda^{n-1} e = 0$ 指数收敛。

### 11.3.3 趋近律设计

| 趋近律类型 | 数学表达式 | 特点 |
|-----------|-----------|------|
| 等速趋近律 | $\dot{s} = -\eta \, \text{sgn}(s)$ | 简单，收敛速度恒定 |
| 指数趋近律 | $\dot{s} = -\eta \, \text{sgn}(s) - k s$ | 快速收敛，减小抖振 |
| 幂次趋近律 | $\dot{s} = -k |s|^\alpha \text{sgn}(s)$ | 接近滑模面时趋近速度减小 |
| 一般趋近律 | $\dot{s} = -\eta \, \text{sgn}(s) - f(s)$ | $f(0)=0$，$sf(s) > 0$ |

### 11.3.4 抖振问题与抑制

抖振是由控制信号高频切换引起的非理想振荡。抑制方法：

1. **饱和函数代替符号函数**：$\text{sat}(s/\phi)$ 代替 $\text{sgn}(s)$
2. **连续函数近似**：$\frac{s}{|s| + \delta}$
3. **高阶滑模**（HOSM）：将不连续控制作用于高阶导数
4. **Super-Twisting 算法**：

$$
\begin{aligned}
u &= -k_1 |s|^{1/2} \text{sgn}(s) + v \\
\dot{v} &= -k_2 \text{sgn}(s)
\end{aligned}
$$

### Python 实现：倒立摆滑模控制仿真

```python
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

# ===== 倒立摆模型 =====
g = 9.81; l = 0.5; m = 0.2; M = 0.5
# 状态: x = [θ, θ̇]
# 非线性模型: (M+m*l*sin²θ)θ̈ + m*l*cosθ*sinθ*θ̇² + (M+m)*g*sinθ = u

def inverted_pendulum(t, x, u_func, args):
    """倒立摆非线性动力学"""
    theta, theta_dot = x
    u = u_func(t, x, args)
    
    denom = M + m * np.sin(theta)**2
    dtheta = theta_dot
    dtheta_dot = (u - m*l*np.cos(theta)*np.sin(theta)*theta_dot**2
                  - (M+m)*g*np.sin(theta)) / (denom * l)
    
    return [dtheta, dtheta_dot]

# ===== 滑模控制器设计 =====
def smc_controller(t, x, args):
    """
    滑模控制器: 倒立摆镇定
    
    滑模面: s = θ̇ + λ θ
    控制律: u = u_eq + u_sw
      其中 u_eq = (M+m)*g*sin(θ) - λ l*(M+m*sin²θ)*θ̇  (等效控制)
           u_sw = -K * l*(M+m*sin²θ) * sat(s/phi)     (切换控制)
    
    args: (lambda_, K, phi)
    """
    lam, K, phi = args
    theta, theta_dot = x
    
    s = theta_dot + lam * theta  # 滑模面
    
    # 等效控制
    denom = M + m * np.sin(theta)**2
    u_eq = (M+m)*g*np.sin(theta) - lam * l * denom * theta_dot
    
    # 切换控制（饱和函数抑制抖振）
    if abs(s) <= phi:
        sat = s / phi
    else:
        sat = np.sign(s)
    
    u_sw = -K * l * denom * sat
    
    return u_eq + u_sw

# ===== 仿真 =====
lambda_smc = 2.0    # 滑模面参数
K = 5.0             # 切换增益
phi = 0.1           # 边界层厚度

args_smc = (lambda_smc, K, phi)

# 初始摆角 θ₀ = 30°, 带动摆到竖直向上
theta0 = np.deg2rad(30)

sol = solve_ivp(inverted_pendulum, [0, 5], [theta0, 0],
                args=(smc_controller, args_smc),
                max_step=0.001, rtol=1e-6)

t = sol.t
theta = sol.y[0, :]
theta_dot = sol.y[1, :]

# 计算滑模面和控制的演化
s_hist = theta_dot + lambda_smc * theta
u_hist = np.array([smc_controller(0, [theta[i], theta_dot[i]], args_smc)
                   for i in range(len(t))])

# ===== 绘图 =====
fig, axes = plt.subplots(4, 1, figsize=(10, 10), sharex=True)

axes[0].plot(t, np.rad2deg(theta))
axes[0].axhline(0, color='k', linestyle='--', linewidth=0.5)
axes[0].set_ylabel('θ (deg)'); axes[0].grid(True)

axes[1].plot(t, theta_dot)
axes[1].set_ylabel('θ̇ (rad/s)'); axes[1].grid(True)

axes[2].plot(t, s_hist)
axes[2].axhline(0, color='k', linestyle='--', linewidth=0.5)
axes[2].set_ylabel('滑模面 s'); axes[2].grid(True)

axes[3].plot(t, u_hist)
axes[3].set_ylabel('控制输入 u'); axes[3].set_xlabel('时间 (s)')
axes[3].grid(True)

fig.suptitle('倒立摆滑模控制（SMC）仿真')
plt.tight_layout()
plt.show()

# ===== 相平面图 =====
plt.figure(figsize=(8, 6))
plt.plot(theta, theta_dot, 'b-', linewidth=1)
plt.plot(theta[0], theta_dot[0], 'ro', markersize=8, label='初始点')
plt.plot(0, 0, 'go', markersize=8, label='平衡点')
# 滑模面 s = 0 --> θ̇ = -λ θ
theta_range = np.linspace(theta.min(), theta.max(), 100)
plt.plot(theta_range, -lambda_smc * theta_range, 'r--', linewidth=2, label='滑模面 s=0')
plt.xlabel('θ (rad)'); plt.ylabel('θ̇ (rad/s)')
plt.title('相平面图')
plt.legend(); plt.grid(True)
plt.show()
```

## 11.4 反馈线性化

### 11.4.1 基本思想

通过非线性状态反馈和非线性坐标变换，将非线性系统**精确线性化**为等效的线性系统，然后使用线性控制方法设计。

### 11.4.2 相关定义

**Lie 导数**：标量函数 $h(x)$ 沿向量场 $f(x)$ 的 Lie 导数

$$
L_f h(x) = \frac{\partial h}{\partial x} f(x) = \nabla h \cdot f
$$

高阶 Lie 导数：

$$
L_f^k h(x) = L_f (L_f^{k-1} h(x))
$$

**相对阶**：系统 $\dot{x} = f(x) + g(x)u, y = h(x)$ 在 $x_0$ 处具有相对阶 $r$，如果：

1. $L_g L_f^k h(x) = 0$ 对 $x_0$ 邻域内所有 $x$，$k = 0, 1, \dots, r-2$
2. $L_g L_f^{r-1} h(x_0) \neq 0$

### 11.4.3 输入-输出反馈线性化

对于具有相对阶 $r$ 的系统：

$$
y^{(r)} = L_f^r h(x) + L_g L_f^{r-1} h(x) \cdot u
$$

取控制律：

$$
u = \frac{1}{L_g L_f^{r-1} h(x)} \left[ v - L_f^r h(x) \right]
$$

得线性微分方程 $y^{(r)} = v$，可进一步设计 $v$ 进行极点配置。

### 11.4.4 输入-状态线性化

寻找微分同胚变换 $z = T(x)$ 和状态反馈 $u = \alpha(x) + \beta(x)v$，使系统转化为 Brunovsky 标准型：

$$
\dot{z} = A_c z + B_c v
$$

其中 $(A_c, B_c)$ 为能控标准型。**充要条件**：分布 $\{g, \text{ad}_f g, \dots, \text{ad}_f^{n-1} g\}$ 是对合的且秩为 $n$。

## 11.5 Backstepping 控制

### 11.5.1 基本思想

Backstepping 是一种递推设计方法，特别适用于具有**下三角结构**（严格反馈形式）的非线性系统：

$$
\begin{aligned}
\dot{x}_1 &= f_1(x_1) + g_1(x_1) x_2 \\
\dot{x}_2 &= f_2(x_1, x_2) + g_2(x_1, x_2) x_3 \\
&\vdots \\
\dot{x}_n &= f_n(x_1, \dots, x_n) + g_n(x_1, \dots, x_n) u
\end{aligned}
$$

### 11.5.2 设计步骤（以二阶系统为例）

系统：

$$
\dot{x}_1 = f_1(x_1) + g_1(x_1) x_2, \quad \dot{x}_2 = f_2(x_1, x_2) + u
$$

**Step 1**：视 $x_2$ 为虚拟控制，设计虚拟控制律 $\alpha(x_1)$

选取 Lyapunov 函数 $V_1 = \frac{1}{2}x_1^2$，设计 $\alpha(x_1)$ 使 $\dot{V}_1 < 0$。

**Step 2**：引入误差 $z = x_2 - \alpha(x_1)$

选取 $V_2 = V_1 + \frac{1}{2}z^2$，设计实际控制 $u$ 使 $\dot{V}_2 < 0$。

最终控制律：

$$
u = -f_2 - \frac{\partial \alpha}{\partial x_1}(f_1 + g_1 x_2) - g_1 x_1 - k z
$$

### 11.5.3 Backstepping 的优势与局限

| 优势 | 局限 |
|------|------|
| 系统化的 Lyapunov 构造过程 | 仅适用严格反馈形式 |
| 可同时设计控制和 Lyapunov 函数 | 高阶系统计算膨胀（"复杂项爆炸"） |
| 可处理非匹配不确定性 | 需要模型精确已知 |

## 11.6 相平面分析

### 11.6.1 相平面与相轨迹

**相平面**是以两个状态变量为坐标轴的平面（通常为 $x$ vs $\dot{x}$）。对于二阶系统 $\ddot{x} = f(x, \dot{x})$，相轨迹满足：

$$
\frac{d\dot{x}}{dx} = \frac{f(x, \dot{x})}{\dot{x}}
$$

**等倾线法**：在相平面上绘制 $\frac{d\dot{x}}{dx} = const$ 的等倾线族，沿每条等倾线画出相应斜率的小线段，拼接得到相轨迹。

### 11.6.2 相平面上的奇点分类

对于线性化系统 $\dot{x} = A x$，根据特征值 $\lambda_{1,2}$ 分类：

| 特征值 | 奇点类型 | 相轨迹特征 |
|--------|---------|-----------|
| 负实根 | 稳定节点 | 所有轨迹收敛于原点 |
| 正实根 | 不稳定节点 | 所有轨迹从原点发散 |
| 实部为负的复根 | 稳定焦点 | 螺旋收敛 |
| 实部为正的复根 | 不稳定焦点 | 螺旋发散 |
| 纯虚根 | 中心 | 闭合椭圆轨道 |
| 一正一负实根 | 鞍点 | 仅两条轨线收敛 |

### 11.6.3 极限环判定

**Poincare-Bendixson 定理**：若 $R$ 为相平面上的有界闭区域，且 $R$ 内无奇点，轨线被限制在 $R$ 内，则 $R$ 内必存在极限环。

**Bendixson 判据（不存在极限环的充分条件）**：若在单连通区域 $D$ 内 $\nabla \cdot f = \frac{\partial f_1}{\partial x_1} + \frac{\partial f_2}{\partial x_2}$ 不变号且不恒为零，则 $D$ 内无闭轨。

### Python 实现：相平面绘制

```python
import numpy as np
import matplotlib.pyplot as plt

def phase_portrait(dynamics, x_range, y_range, args=(), N=20, T=10):
    """
    绘制二阶系统的相平面图
    
    参数:
        dynamics: dx/dt = [f1(x,y), f2(x,y)]
        x_range: (xmin, xmax)
        y_range: (ymin, ymax)
    """
    x = np.linspace(*x_range, N)
    y = np.linspace(*y_range, N)
    X, Y = np.meshgrid(x, y)
    
    U = np.zeros_like(X)
    V = np.zeros_like(Y)
    
    for i in range(N):
        for j in range(N):
            dx = dynamics(np.array([X[i,j], Y[i,j]]), *args)
            U[i,j], V[i,j] = dx[0], dx[1]
    
    M = np.sqrt(U**2 + V**2)
    U_n, V_n = U/(M+1e-10), V/(M+1e-10)
    
    fig, ax = plt.subplots(figsize=(8, 8))
    
    # 向量场
    ax.quiver(X, Y, U_n, V_n, M, cmap='viridis', alpha=0.6)
    
    # 从多个初值积分相轨迹
    from scipy.integrate import solve_ivp
    for x0 in np.linspace(x_range[0], x_range[1], 7):
        for y0 in np.linspace(y_range[0], y_range[1], 7):
            sol = solve_ivp(lambda t, z: dynamics(z, *args),
                            [0, T], [x0, y0],
                            t_eval=np.linspace(0, T, 200),
                            rtol=1e-8)
            ax.plot(sol.y[0], sol.y[1], 'r-', linewidth=0.5, alpha=0.5)
    
    ax.set_xlabel('$x_1$'); ax.set_ylabel('$x_2$')
    ax.set_title('相平面图')
    ax.grid(True)
    plt.tight_layout()
    return fig, ax

# ===== Van der Pol 振荡器 =====
mu = 1.0

def van_der_pol(z, mu):
    x, y = z
    return np.array([y, mu*(1 - x**2)*y - x])

phase_portrait(van_der_pol, (-4, 4), (-6, 6), args=(mu,))
plt.show()
```

## 11.7 描述函数法（谐波平衡）

### 11.7.1 基本原理

描述函数法是频域方法在非线性系统中的推广。将非线性环节的基波响应近似为**等效复增益**。

对于正弦输入 $x = A \sin(\omega t)$，非线性环节输出 $y(t) = f(A \sin(\omega t))$ 的 Fourier 展开：

$$
y(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} [a_n \cos(n\omega t) + b_n \sin(n\omega t)]
$$

**描述函数**（忽略高次谐波）：

$$
N(A) = \frac{b_1 + j a_1}{A} = \frac{1}{\pi A} \int_0^{2\pi} f(A \sin \theta) \, (\sin \theta + j \cos \theta) \, d\theta
$$

### 11.7.2 常见非线性环节的描述函数

| 非线性 | 描述函数 $N(A)$ | 说明 |
|--------|----------------|------|
| 理想继电器 | $\frac{4M}{\pi A}$ | 实增益，与 $A$ 反比 |
| 死区 | $k - \frac{2k}{\pi} \left[ \arcsin\frac{d}{A} + \frac{d}{A}\sqrt{1-(\frac{d}{A})^2} \right]$ | $A > d$ 时有效 |
| 饱和 | $\frac{2k}{\pi} \left[ \arcsin\frac{s}{A} + \frac{s}{A}\sqrt{1-(\frac{s}{A})^2} \right]$ | $A > s$ 时有效 |
| 滞环 | 复增益，与输入历史有关 | 产生相位滞后 |

### 11.7.3 极限环的预测

闭环特征方程：

$$
1 + N(A) G(j\omega) = 0 \quad \Rightarrow \quad G(j\omega) = -\frac{1}{N(A)}
$$

在复平面上绘制 $G(j\omega)$ 的 Nyquist 图和 $-1/N(A)$ 的负倒描述函数曲线，**交点**对应于可能的极限环。

**稳定性判定**：沿 $A$ 增大方向，若 $-1/N(A)$ 从 $G(j\omega)$ 包围区进入非包围区，则极限环稳定；反之不稳定。

## 总结

| 方法 | 核心思想 | 适用场景 | 优点 | 局限 |
|------|---------|---------|------|------|
| Lyapunov 直接法 | 能量函数 $V(x)$ | 稳定性分析 | 无需求解微分方程 | 构造 $V(x)$ 困难 |
| 滑模控制 | 滑模面 + 不连续控制 | 含不确定性的系统 | 强鲁棒性 | 抖振问题 |
| 反馈线性化 | 非线性变换 → 线性系统 | 精确模型已知 | 可移植线性方法 | 需要精确模型 |
| Backstepping | 递推 Lyapunov 构造 | 下三角系统 | 系统化、灵活 | 高阶复杂项爆炸 |

> 非线性控制系统设计没有统一的理论框架，不同方法适用于不同系统结构。滑模控制因其鲁棒性在工程中应用广泛，反馈线性化和 Backstepping 则在需要高精度控制的场景下发挥作用。

> 实际应用中常组合多种方法：如自适应滑模控制（处理参数不确定性）、Backstepping + 滑模（增强鲁棒性）、反馈线性化 + LQR（最优控制）等。
