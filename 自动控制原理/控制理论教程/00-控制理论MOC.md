## 符号约定

| 符号 | 含义 | 常见示例 |
|------|------|---------|
| $G(s)$ | 开环传递函数 | $G(s) = \frac{\omega_n^2}{s(s+2\zeta\omega_n)}$ |
| $\Phi(s)$ | 闭环传递函数 | $\Phi(s) = \frac{G(s)}{1+G(s)H(s)}$ |
| $A, B, C, D$ | 状态空间矩阵 | $\dot{x} = Ax + Bu, y = Cx + Du$ |
| $x \in \mathbb{R}^n$ | 状态向量 | $x = [\theta, \dot{\theta}, x_c, \dot{x}_c]^T$ |
| $u \in \mathbb{R}^m$ | 控制输入向量 | 电机电压、阀门开度 |
| $y \in \mathbb{R}^p$ | 输出向量 | 传感器测量值 |
| $K$ | 反馈增益矩阵 | $u = -Kx + v$ |
| $L$ | 观测器增益矩阵 | $\dot{\hat{x}} = A\hat{x} + Bu + L(y-C\hat{x})$ |
| $Q, R$ | LQR 权重矩阵 | $x^T Q x + u^T R u$ |
| $P$ | Riccati 方程解 | $A^T P + PA - PBR^{-1}B^T P + Q = 0$ |
| $\Sigma$ | 滤波协方差矩阵 | $\dot{\Sigma} = A\Sigma + \Sigma A^T - \dots + W$ |
| $Q_c$ | 能控性矩阵 | $Q_c = [B, AB, \dots, A^{n-1}B]$ |
| $Q_o$ | 能观性矩阵 | $Q_o = [C^T, A^T C^T, \dots, (A^T)^{n-1}C^T]^T$ |
| $V(x)$ | Lyapunov 函数 | $V > 0, \dot{V} < 0$ |
| $s(x)$ | 滑模面 | $s = (\frac{d}{dt} + \lambda)^{n-1}e$ |
| $\text{sgn}(\cdot)$ | 符号函数 | $\text{sgn}(s) = s/|s|, s \neq 0$ |
| $\mathcal{N}(\mu, \sigma^2)$ | 正态分布 | 噪声模型 |
| $\|\cdot\|_\infty$ | H∞ 范数 | $\|G\|_\infty = \sup_\omega \bar{\sigma}(G(j\omega))$ |
| $N$ | MPC 预测时域 | 预测 $N$ 步未来 |
