# 第8章 能控性与能观性

> 能控性与能观性是现代控制理论的两个基本结构性质，由 Kalman 于 1960 年提出。它们揭示了系统的内部结构——哪些状态可以被输入控制，哪些状态可以从输出观测。

## 8.1 能控性的定义

### 8.1.1 能控性的直观理解

**能控性**（Controllability）回答：能否通过施加适当的输入 $u(t)$，在有限时间内将系统状态从任意初始状态 $x(t_0)$ 转移到任意终端状态 $x(t_f)$？

```
u(t) → [系统 (A, B)] → x(t)
        ↑
        能否将 x 驱动到任意目标？
```

**注意**：能控性是状态的性质，而非输出的性质。输出能控性与状态能控性是不同的概念。

### 8.1.2 能控性的严格定义

对于线性定常系统：

$$\dot{x}(t) = A x(t) + B u(t)$$

**定义**（状态能控）：如果在有限时间 $[t_0, t_f]$ 内，存在一个无约束的控制输入 $u(t)$，能将系统状态从任意初始状态 $x(t_0)$ 转移到任意终端状态 $x(t_f)$，则称系统（或 $(A, B)$ 对）是**完全能控的**（Completely Controllable）。

等价的简化定义：若存在 $u(t)$ 能将系统从任意 $x(0)$ 在有限时间内驱动到原点 $x(t_f) = 0$，则系统能控。

## 8.2 能控性判据

### 8.2.1 能控性矩阵秩判据

**定理**（Kalman 秩判据）：线性定常系统 $(A, B)$ 完全能控的充要条件是能控性矩阵：

$$\mathcal{C} = \begin{bmatrix} B & AB & A^2 B & \cdots & A^{n-1} B \end{bmatrix} \in \mathbb{R}^{n \times nm}$$

满秩，即：

$$\text{rank}(\mathcal{C}) = n$$

其中 $n$ 是系统的阶数（$A \in \mathbb{R}^{n \times n}$）。

**推导思路**（基于 Cayley-Hamilton 定理）：

状态转移：
$$x(t_f) = e^{A(t_f-t_0)}x(t_0) + \int_{t_0}^{t_f} e^{A(t_f-\tau)} B u(\tau) d\tau$$

由 Cayley-Hamilton，$e^{A(t_f-\tau)}$ 可展开为 $I, A, \ldots, A^{n-1}$ 的线性组合。因此 $B, AB, \ldots, A^{n-1}B$ 的列空间决定了 $u(\tau)$ 能否生成任意状态变化。

```python
import numpy as np

def is_controllable(A, B):
    """判断系统 (A, B) 的能控性"""
    n = A.shape[0]
    C = np.zeros((n, n * B.shape[1]))

    # 构建能控性矩阵 C = [B, AB, A^2B, ..., A^{n-1}B]
    C[:, :B.shape[1]] = B
    A_power = A.copy()
    for i in range(1, n):
        C[:, i*B.shape[1]:(i+1)*B.shape[1]] = A_power @ B
        A_power = A_power @ A

    rank = np.linalg.matrix_rank(C)
    controllable = (rank == n)
    return controllable, rank, C

# 示例 1: 能控系统
A1 = np.array([[0, 1],
               [-2, -3]])
B1 = np.array([[0],
               [1]])

controllable, rank, _ = is_controllable(A1, B1)
print(f"示例 1 能控性: {controllable}, rank = {rank}, n = {A1.shape[0]}")

# 示例 2: 不能控系统 (A 有零特征值，但 B 无法影响某状态)
A2 = np.array([[-1, 0],
               [0, -2]])
B2 = np.array([[1],
               [0]])  # 第二个状态不受影响
controllable, rank, _ = is_controllable(A2, B2)
print(f"示例 2 能控性: {controllable}, rank = {rank}, n = {A2.shape[0]}")

# 示例 3: MIMO 系统
A3 = np.array([[0, 1, 0],
               [0, 0, 1],
               [-6, -11, -6]])
B3 = np.array([[1, 0],
               [0, 1],
               [0, 0]])
controllable, rank, _ = is_controllable(A3, B3)
print(f"示例 3 (MIMO) 能控性: {controllable}, rank = {rank}")
```

### 8.2.2 PBH 秩判据（Popov-Belevitch-Hautus）

**定理**（PBH 特征向量判据）：系统 $(A, B)$ 能控的充要条件是，对 $A$ 的每个特征值 $\lambda$：

$$\text{rank}\begin{bmatrix} \lambda I - A & B \end{bmatrix} = n$$

等价的表述：不存在非零左特征向量 $w$ 与 $B$ 正交——即不存在 $w \neq 0$ 满足 $w^T A = \lambda w^T$ 且 $w^T B = 0$。

**PBH 判据的优点**：
- 直接揭示哪一模态不能控（通过检查哪个 $\lambda_i$ 不满足秩条件）
- 对判断特定特征值是否能控特别有用

```python
import numpy as np

def pbh_controllability_test(A, B):
    """PBH 秩判据"""
    n = A.shape[0]
    eigenvalues = np.linalg.eigvals(A)

    for lam in eigenvalues:
        M = np.hstack([lam * np.eye(n) - A, B])
        rank_M = np.linalg.matrix_rank(M)
        if rank_M < n:
            print(f"  特征值 λ = {lam:.4f} 不能控 (rank = {rank_M} < {n})")
        else:
            print(f"  特征值 λ = {lam:.4f} 能控 (rank = {rank_M} = {n})")

A = np.array([[0, 1], [-2, -3]])
B = np.array([[0], [1]])
print("PBH 能控性检验：")
pbh_controllability_test(A, B)
```

### 8.2.3 对角标准型/约当标准型判据

当系统已化为对角线型或 Jordan 型时，判断更直观。

**对角型判据**：若 $A = \text{diag}(\lambda_1, \ldots, \lambda_n)$（$\lambda_i$ 互异），则系统能控的充要条件是 $B$ 矩阵**没有全零行**。

$$\mathcal{C} \text{ 满秩} \iff B \text{ 的每一行不全为零}$$

**Jordan 型判据**：若 $A$ 为 Jordan 型，对应于每个 Jordan 块最后一行所对应的 $B$ 的行线性无关。

```
对角型示例：
      [λ₁ 0 ]     [b₁]
  A = [0  λ₂], B = [b₂]
能控 ⇔ b₁ ≠ 0 且 b₂ ≠ 0
```

## 8.3 能观性的定义

### 8.3.1 能观性的直观理解

**能观性**（Observability）回答：能否通过在有限时间内测量系统的输出 $y(t)$ 和输入 $u(t)$，唯一地确定系统的初始状态 $x(t_0)$？

```
x(t) → [系统 (A, B, C)] → y(t)
        ↑
        能否从 y(t) 和 u(t) 推断 x(0)？
```

### 8.3.2 能观性的严格定义

**定义**（状态能观）：如果在有限时间 $[t_0, t_f]$ 内，通过观测输出 $y(t)$ 和输入 $u(t)$，能够唯一确定系统的初始状态 $x(t_0)$，则称系统（或 $(A, C)$ 对）是**完全能观的**（Completely Observable）。

## 8.4 能观性判据

### 8.4.1 能观性矩阵秩判据

**定理**（Kalman 秩判据）：线性定常系统 $(A, C)$ 完全能观的充要条件是能观性矩阵：

$$\mathcal{O} = \begin{bmatrix}
C \\ CA \\ CA^2 \\ \vdots \\ CA^{n-1}
\end{bmatrix} \in \mathbb{R}^{np \times n}$$

满秩，即：

$$\text{rank}(\mathcal{O}) = n$$

**推导**：在不失一般性下设 $u(t) \equiv 0$，输出为：

$$y(t) = C e^{At} x(0) = \sum_{k=0}^{n-1} \alpha_k(t) C A^k x(0)$$

要使 $y(t)$ 能唯一确定 $x(0)$，需要 $C, CA, \ldots, CA^{n-1}$ 的行空间张成 $\mathbb{R}^n$，即 $\mathcal{O}$ 满秩。

```python
import numpy as np

def is_observable(A, C):
    """判断系统 (A, C) 的能观性"""
    n = A.shape[0]
    p = C.shape[0]
    O = np.zeros((n * p, n))

    # 构建能观性矩阵 O = [C; CA; CA^2; ...; CA^{n-1}]
    O[:p, :] = C
    C_power = C.copy()
    for i in range(1, n):
        C_power = C_power @ A
        O[i*p:(i+1)*p, :] = C_power

    rank = np.linalg.matrix_rank(O)
    observable = (rank == n)
    return observable, rank, O

# 示例 1: 能观系统
A1 = np.array([[0, 1],
               [-2, -3]])
C1 = np.array([[1, 0]])

observable, rank, _ = is_observable(A1, C1)
print(f"示例 1 能观性: {observable}, rank = {rank}, n = {A1.shape[0]}")

# 示例 2: 不能观系统 (输出只能感知一个状态)
A2 = np.array([[-1, 0],
               [0, -2]])
C2 = np.array([[1, 0]])  # 只能观测第一个状态
observable, rank, _ = is_observable(A2, C2)
print(f"示例 2 能观性: {observable}, rank = {rank}, n = {A2.shape[0]}")
```

### 8.4.2 PBH 秩判据（能观性版本）

**定理**：系统 $(A, C)$ 能观的充要条件是，对 $A$ 的每个特征值 $\lambda$：

$$\text{rank}\begin{bmatrix} \lambda I - A \\ C \end{bmatrix} = n$$

等价的表述：不存在非零右特征向量 $v$ 与 $C$ 正交——即不存在 $v \neq 0$ 满足 $A v = \lambda v$ 且 $C v = 0$。

```python
import numpy as np

def pbh_observability_test(A, C):
    """PBH 秩判据（能观性版本）"""
    n = A.shape[0]
    eigenvalues = np.linalg.eigvals(A)

    for lam in eigenvalues:
        M = np.vstack([lam * np.eye(n) - A, C])
        rank_M = np.linalg.matrix_rank(M)
        if rank_M < n:
            print(f"  特征值 λ = {lam:.4f} 不能观 (rank = {rank_M} < {n})")
        else:
            print(f"  特征值 λ = {lam:.4f} 能观 (rank = {rank_M} = {n})")

A = np.array([[0, 1], [-2, -3]])
C = np.array([[0, 1]])  # 观测第二个状态变量
print("PBH 能观性检验：")
pbh_observability_test(A, C)
```

### 8.4.3 对角标准型/约当标准型判据

**对角型判据**：若 $A = \text{diag}(\lambda_1, \ldots, \lambda_n)$，则系统能观的充要条件是 $C$ 矩阵**没有全零列**。

$$C \text{ 的每一列不全为零} \iff \text{系统能观}$$

## 8.5 对偶原理（Duality）

### 8.5.1 对偶系统

给定原系统 $\Sigma(A, B, C)$，定义其对偶系统：

$$\begin{cases}
\dot{z}(t) = A^T z(t) + C^T v(t) \\
w(t) = B^T z(t)
\end{cases}$$

即对偶系统为 $\Sigma_d(A^T, C^T, B^T)$。

### 8.5.2 对偶原理

**定理**（对偶原理）：

> 原系统 $\Sigma$ 能控 $\iff$ 对偶系统 $\Sigma_d$ 能观
> 原系统 $\Sigma$ 能观 $\iff$ 对偶系统 $\Sigma_d$ 能控

**数学证明**：

能控性矩阵：$\mathcal{C} = [B, AB, \ldots, A^{n-1}B]$

对偶系统的能观性矩阵：

$$\mathcal{O}_d = \begin{bmatrix} B^T \\ B^T A^T \\ \vdots \\ B^T (A^T)^{n-1} \end{bmatrix}$$

由于 $B^T (A^T)^k = (A^k B)^T$，因此 $\mathcal{O}_d = \mathcal{C}^T$，行秩 = 列秩。

**对偶原理的意义**：
- 能控性问题和能观性问题可以相互转化
- 观测器设计问题（需要能观性）与控制律设计问题（需要能控性）是对偶的
- 简化了理论分析——只需研究其中之一

```python
import numpy as np

def duality_demonstration(A, B, C):
    """验证对偶原理"""
    # 原系统能控性
    n = A.shape[0]
    C_ctrl = B.copy()
    A_pow = A.copy()
    for _ in range(1, n):
        C_ctrl = np.hstack([C_ctrl, A_pow @ B])
        A_pow = A_pow @ A
    rank_ctrl = np.linalg.matrix_rank(C_ctrl)

    # 对偶系统能观性
    A_dual = A.T
    C_dual = B.T
    O_dual = C_dual.copy()
    C_pow = C_dual.copy()
    for _ in range(1, n):
        C_pow = C_pow @ A_dual
        O_dual = np.vstack([O_dual, C_pow])
    rank_obs_dual = np.linalg.matrix_rank(O_dual)

    print(f"原系统能控性 rank = {rank_ctrl}")
    print(f"对偶系统能观性 rank = {rank_obs_dual}")
    print(f"相等: {rank_ctrl == rank_obs_dual}")

    # 原系统能观性
    O_obs = C.copy()
    C_pow = C.copy()
    for _ in range(1, n):
        C_pow = C_pow @ A
        O_obs = np.vstack([O_obs, C_pow])
    rank_obs = np.linalg.matrix_rank(O_obs)

    # 对偶系统能控性
    B_dual = C.T
    C_ctrl_dual = B_dual.copy()
    A_pow_dual = A.T.copy()
    for _ in range(1, n):
        C_ctrl_dual = np.hstack([C_ctrl_dual, A_pow_dual @ B_dual])
        A_pow_dual = A_pow_dual @ A.T
    rank_ctrl_dual = np.linalg.matrix_rank(C_ctrl_dual)

    print(f"原系统能观性 rank = {rank_obs}")
    print(f"对偶系统能控性 rank = {rank_ctrl_dual}")
    print(f"相等: {rank_obs == rank_ctrl_dual}")

A = np.array([[0, 1], [-2, -3]])
B = np.array([[0], [1]])
C = np.array([[1, 0]])

print("=== 对偶原理验证 ===")
duality_demonstration(A, B, C)
```

## 8.6 Kalman 标准分解

### 8.6.1 分解的意义

并非所有系统都是完全能控且完全能观的。Kalman 分解将系统状态空间分为四个子空间，揭示系统的内部结构。

通过适当的线性变换 $\tilde{x} = Px$，任何系统 $(A, B, C)$ 可分解为：

$$\begin{bmatrix}
\dot{x}_{co} \\ \dot{x}_{c\bar{o}} \\ \dot{x}_{\bar{c}o} \\ \dot{x}_{\bar{c}\bar{o}}
\end{bmatrix} =
\begin{bmatrix}
A_{11} & 0 & A_{13} & 0 \\
A_{21} & A_{22} & A_{23} & A_{24} \\
0 & 0 & A_{33} & 0 \\
0 & 0 & A_{43} & A_{44}
\end{bmatrix}
\begin{bmatrix}
x_{co} \\ x_{c\bar{o}} \\ x_{\bar{c}o} \\ x_{\bar{c}\bar{o}}
\end{bmatrix} +
\begin{bmatrix}
B_1 \\ B_2 \\ 0 \\ 0
\end{bmatrix} u$$

$$y = \begin{bmatrix} C_1 & 0 & C_3 & 0 \end{bmatrix}
\begin{bmatrix} x_{co} \\ x_{c\bar{o}} \\ x_{\bar{c}o} \\ x_{\bar{c}\bar{o}} \end{bmatrix}$$

### 8.6.2 四个子系统的含义

| 子系统 | 符号 | 含义 | 传递函数 |
|--------|------|------|---------|
| 能控且能观 | $x_{co}$ | 既是可控的，又是可观测的 | 贡献传递函数的全部 |
| 能控不能观 | $x_{c\bar{o}}$ | 输入可影响，但输出看不到 | 传递函数中不出现 |
| 不能控能观 | $x_{\bar{c}o}$ | 输出可见，但输入影响不到 | 传递函数中不出现 |
| 不能控不能观 | $x_{\bar{c}\bar{o}}$ | 输入影响不到，输出看不到 | 传递函数中不出现 |

```
           输入 u 影响
          ┌──────────┐
          │ x_co  x_cō│
能观 ←────┤ x_čo  x_čō│
          └──────────┘
          输出 y 可见
```

**关键结论**：

1. 系统的传递函数仅由**能控且能观**子系统 $(A_{11}, B_1, C_1)$ 决定
2. 传递函数中可能出现零极点对消，对应能控不能观或不能控能观的模态
3. 传递函数描述的是系统的外部行为，无法反映不能控或不能观部分的内部动态

$$G(s) = C(sI - A)^{-1}B = C_1(sI - A_{11})^{-1}B_1$$

### 8.6.3 Kalman 分解的构造方法

1. 计算 $\mathcal{C} = [B, AB, \ldots, A^{n-1}B]$，取 $\mathcal{C}$ 的列空间基 → 能控子空间
2. 计算 $\mathcal{O} = [C^T, A^T C^T, \ldots, (A^T)^{n-1}C^T]^T$，取 $\mathcal{O}^T$ 的列空间基 → 能观子空间
3. 两个空间的交集 → 能控且能观子空间
4. 组合四个子空间构造变换矩阵 $P$

```python
import numpy as np
from scipy.linalg import orth

def kalman_decomposition(A, B, C):
    """
    Kalman 标准分解
    返回：变换后的 A_bar, B_bar, C_bar, 各子空间的维数
    """
    n = A.shape[0]

    # Step 1: 构建能控性矩阵
    C_ctrl = B.copy()
    A_pow = A.copy()
    for _ in range(1, n):
        C_ctrl = np.hstack([C_ctrl, A_pow @ B])
        A_pow = A_pow @ A

    # 能控子空间基
    U_c = orth(C_ctrl)  # 列空间的标准正交基
    dim_c = U_c.shape[1]

    # Step 2: 构建能观性矩阵
    O_obs = C.copy()
    C_pow = C.copy()
    for _ in range(1, n):
        C_pow = C_pow @ A
        O_obs = np.vstack([O_obs, C_pow])

    # 不能观子空间基（O_obs 的零空间）
    # O_obs x = 0 的解空间
    U_o_null = orth(np.linalg.null_space(O_obs.T).T.T)  # 修正
    # 能观子空间补
    U_o_comp = orth(O_obs.T)  # O_obs 行空间的正交补的补
    dim_o = U_o_comp.shape[1] if U_o_comp.size > 0 else 0

    # 简化处理：直接报告秩
    rank_c = np.linalg.matrix_rank(C_ctrl)
    rank_o = np.linalg.matrix_rank(O_obs)

    print(f"能控性矩阵秩: {rank_c} / {n}")
    print(f"能观性矩阵秩: {rank_o} / {n}")

    # 维数分配
    dim_co = min(rank_c, rank_o)  # 近似：能控且能观
    dim_c_no = rank_c - dim_co   # 能控不能观
    dim_nc_o = rank_o - dim_co   # 不能控能观
    dim_nc_no = n - rank_c - dim_nc_o  # 不能控不能观

    print(f"子空间维数:")
    print(f"  能控且能观:     {max(0, dim_co)}")
    print(f"  能控不能观:     {max(0, dim_c_no)}")
    print(f"  不能控能观:     {max(0, dim_nc_o)}")
    print(f"  不能控不能观:   {max(0, dim_nc_no)}")

    return rank_c, rank_o

# 示例
A = np.array([[0, 1, 0],
              [0, 0, 1],
              [-6, -11, -6]])
B = np.array([[0], [0], [1]])
C = np.array([[1, 0, 0]])

print("=== Kalman 分解示例 ===")
kalman_decomposition(A, B, C)
```

### 8.6.4 Kalman 分解与传递函数零极点对消

**重要结论**：

> 系统是**最小实现**（minimal realization）$\iff$ 系统既完全能控又完全能观（前三个能控性矩阵秩 = 能观性矩阵秩 = $n$）

当传递函数存在零极点对消时，必存在不能控或不能观的子系统。经典的例子：

$$G(s) = \frac{s+2}{(s+1)(s+2)} = \frac{1}{s+1}$$

零极点 $(s+2)$ 对消。构造状态空间实现，会发现存在不能控或不能观的模态 $\lambda = -2$。

## 8.7 最小实现

### 8.7.1 最小实现的定义

**定义**：给定传递函数 $G(s)$，若其状态空间实现 $(A, B, C, D)$ 是既能控又能观的，则称为 $G(s)$ 的**最小实现**（Minimal Realization）。

最小实现具有最小的状态维数——等于 $G(s)$ 的 **McMillan 阶**（分母多项式的最小公倍式的次数）。

### 8.7.2 最小实现的性质

1. **维数最小**：最小实现的状态维数等于传递函数的极点数（无零极点对消时等于分母次数）
2. **不唯一但等价**：所有最小实现通过相似变换相互转化
3. **能控/能观性**：最小实现必然既完全能控又完全能观
4. **渐近稳定性**：$A$ 的特征值为 $G(s)$ 的极点（即传递函数的分母多项式根）

### 8.7.3 从传递函数求最小实现

**步骤**：

1. 将传递函数写为最简形式（消除分子分母公因子）
2. 构造能控标准型或能观标准型实现
3. 如果构造时使用了最简形式，则所得实现天然为最小实现

```python
import numpy as np
import control as ct

def minimal_realization(num, den):
    """
    从传递函数求最小实现
    """
    # 消除公因子
    from numpy import poly1d
    num_poly = poly1d(num)
    den_poly = poly1d(den)

    # 求最大公因式并约分
    # 使用 control 库的 minreal
    sys_tf = ct.TransferFunction(num, den)
    sys_min = ct.minreal(sys_tf, verbose=False)

    # 转为状态空间
    sys_ss = ct.tf2ss(sys_min)

    # 验证能控能观性
    n = sys_ss.A.shape[0]
    C_ctrl = ct.ctrb(sys_ss.A, sys_ss.B)
    O_obs = ct.obsv(sys_ss.A, sys_ss.C)

    rank_ctrl = np.linalg.matrix_rank(C_ctrl)
    rank_obs = np.linalg.matrix_rank(O_obs)

    print(f"状态维数 n = {n}")
    print(f"能控性矩阵秩 = {rank_ctrl}")
    print(f"能观性矩阵秩 = {rank_obs}")
    print(f"是最小实现: {rank_ctrl == n and rank_obs == n}")

    return sys_ss

# 示例：G(s) = (s+2)/(s^2 + 3s + 2)
# 注意 s^2+3s+2 = (s+1)(s+2)，存在零极点对消
num = [1, 2]      # s+2
den = [1, 3, 2]   # s^2+3s+2

print("=== 最小实现 ===")
print(f"原始传递函数：G(s) = ({num[0]}s+{num[1]})/({den[0]}s^2+{den[1]}s+{den[2]})")
print(f"存在零极点对消: 因子 (s+2)")
sys_min = minimal_realization(num, den)
print(f"\n最小实现 A:\n{sys_min.A}")
print(f"B:\n{sys_min.B}")
print(f"C:\n{sys_min.C}")
```

## 8.8 应用：能控性与能观性分解的工程意义

### 8.8.1 状态反馈与极点配置

状态反馈 $u = -Kx + r$ 只能改变能控子系统的极点：

$$\dot{x} = (A - BK)x + Br$$

- 能控的极点可任意配置（详见极点配置章节）
- 不能控的极点保持不变

这意味着要想通过状态反馈实现任意极点配置，系统必须**完全能控**。

### 8.8.2 状态观测器设计

Luenberger 观测器：

$$\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x})$$

- 观测误差动态：$\dot{e} = (A - LC)e$
- $(A - LC)$ 的特征值可以任意配置 $\iff$ 系统**完全能观**
- 不能观的模态无法通过观测器重构

### 8.8.3 分离原理

对于完全能控且完全能观的系统：
- 状态反馈控制器 $K$ 和状态观测器 $L$ 可以**独立设计**
- 组合系统的极点 = 控制器极点 ∪ 观测器极点
- 这就是**分离原理**（Separation Principle）

## 总结

本章深入探讨了现代控制理论的两个结构性质：

1. **能控性**回答"能否通过输入控制全部状态"的问题。核心判据：$\text{rank}(\mathcal{C}) = \text{rank}[B, AB, \ldots, A^{n-1}B] = n$
2. **能观性**回答"能否从输出观测全部状态"的问题。核心判据：$\text{rank}(\mathcal{O}) = \text{rank}[C^T, A^T C^T, \ldots, (A^T)^{n-1}C^T]^T = n$
3. **对偶原理**建立了能控性与能观性之间的对称关系：原系统的能控性 $\iff$ 对偶系统的能观性
4. **PBH 判据**提供了模态级别的判断，对分析特定特征值的能控/能观性特别有用
5. **Kalman 分解**将系统状态空间分为四个子空间（能控能观、能控不能观、不能控能观、不能控不能观），揭示了传递函数仅反映能控且能观子系统的结构
6. **最小实现**是既能控又能观的实现，维数最小，是对应的传递函数的最简表示

能控性与能观性是现代控制理论中最基本的结构概念，它们是 [[07-状态空间基础]]的深化，也是后续极点配置、最优控制（LQR）、Kalman 滤波等现代设计方法的基础。
