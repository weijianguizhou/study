## 12.1 模型预测控制（MPC）

### 12.1.1 基本原理

模型预测控制（Model Predictive Control）是一种基于模型优化的控制方法，核心思想为**预测 → 优化 → 执行**的滚动时域控制。

**三大要素**：

1. **预测模型**：描述系统未来动态的数学模型
2. **滚动优化**：在每个采样时刻求解有限时域优化问题
3. **反馈校正**：仅执行当前控制量，下一时刻重新求解

### 12.1.2 MPC 的数学描述

考虑离散时间系统：

$$
x_{k+1} = f(x_k, u_k), \quad x_k \in \mathbb{X}, \quad u_k \in \mathbb{U}
$$

在每个时刻 $k$ 求解最优控制序列 $\{u_k, u_{k+1}, \dots, u_{k+N-1}\}$：

$$
\begin{aligned}
\min_{u_k, \dots, u_{k+N-1}} \quad & \sum_{i=0}^{N-1} \ell(x_{k+i}, u_{k+i}) + V_f(x_{k+N}) \\
\text{s.t.} \quad & x_{k+i+1} = f(x_{k+i}, u_{k+i}) \\
& x_{k+i} \in \mathbb{X}, \quad u_{k+i} \in \mathbb{U} \\
& x_{k+N} \in \mathbb{X}_f
\end{aligned}
$$

仅施加 $u_k^*$，下一时刻重新求解——这是 **Receding Horizon** 的核心。

### 12.1.3 线性 MPC（二次规划求解）

对于线性系统 $x_{k+1} = A x_k + B u_k$，二次型代价函数：

$$
J = \sum_{i=0}^{N-1} (x_{k+i}^T Q x_{k+i} + u_{k+i}^T R u_{k+i}) + x_{k+N}^T P x_{k+N}
$$

可将优化问题转化为**标准二次规划（QP）**：

$$
\min_{\mathbf{U}} \frac{1}{2} \mathbf{U}^T H \mathbf{U} + \mathbf{U}^T F^T x_k
$$

其中 $\mathbf{U} = [u_k^T, u_{k+1}^T, \dots, u_{k+N-1}^T]^T$。

### Python 实现：线性 MPC

```python
import numpy as np
from scipy.linalg import solve_discrete_are
from cvxopt import matrix, solvers
solvers.options['show_progress'] = False

class LinearMPC:
    def __init__(self, A, B, Q, R, N, x_lb=None, x_ub=None, u_lb=None, u_ub=None):
        """
        线性 MPC 控制器
        
        参数:
            N: 预测时域长度
            Q, R: 状态和控制权重
            x_lb, x_ub: 状态约束
            u_lb, u_ub: 控制约束
        """
        self.A, self.B = A, B
        self.Q, self.R = Q, R
        self.N = N
        self.nx, self.nu = A.shape[0], B.shape[1]
        
        self.x_lb = x_lb; self.x_ub = x_ub
        self.u_lb = u_lb; self.u_ub = u_ub
        
        # 终端代价矩阵（求解离散 ARE）
        self.P = solve_discrete_are(A, B, Q, R)
        
        # 构造 QP 矩阵
        self._build_qp_matrices()
    
    def _build_qp_matrices(self):
        """构造紧凑形式 QP 的 H 和 F 矩阵"""
        N, nx, nu = self.N, self.nx, self.nu
        
        # 预测系统矩阵
        # X = S_x * x_k + S_u * U
        S_u = np.zeros((N * nx, N * nu))
        S_x = np.zeros((N * nx, nx))
        
        A_pow = np.eye(nx)
        for i in range(N):
            S_x[i*nx:(i+1)*nx, :] = A_pow @ self.A
            A_pow = A_pow @ self.A
            
            for j in range(i+1):
                S_u[i*nx:(i+1)*nx, j*nu:(j+1)*nu] = (
                    np.linalg.matrix_power(self.A, i-j) @ self.B
                )
        
        # Q 和 R 的块对角矩阵
        Q_bar = np.kron(np.eye(N-1), self.Q)
        Q_bar = np.block([[Q_bar, np.zeros(((N-1)*nx, nx))],
                          [np.zeros((nx, (N-1)*nx)), self.P]])
        R_bar = np.kron(np.eye(N), self.R)
        
        # 二次规划标准型: min (1/2) U^T H U + U^T F^T x_k
        self.H = (S_u.T @ Q_bar @ S_u + R_bar)
        self.F = (S_u.T @ Q_bar @ S_x).T  # 转置使得 F^T * x_k
        
        self.S_u = S_u; self.S_x = S_x
        self.Q_bar = Q_bar; self.R_bar = R_bar
    
    def solve(self, x_k):
        """求解当前时刻的最优控制序列"""
        x_k = x_k.reshape(-1, 1)
        N, nu = self.N, self.nu
        
        # 目标函数
        P_qp = matrix(self.H)
        q_qp = matrix((self.F @ x_k).flatten())
        
        # 不等式约束 G * U <= h
        G_list = []; h_list = []
        
        # 控制约束
        if self.u_lb is not None:
            G_list.append(-np.eye(N * nu))
            h_list.append(-np.tile(self.u_lb, N))
        if self.u_ub is not None:
            G_list.append(np.eye(N * nu))
            h_list.append(np.tile(self.u_ub, N))
        
        # 状态约束
        if self.x_lb is not None:
            G_list.append(-self.S_u)
            h_list.append(-(np.tile(self.x_lb, N) - self.S_x @ x_k).flatten())
        if self.x_ub is not None:
            G_list.append(self.S_u)
            h_list.append((np.tile(self.x_ub, N) - self.S_x @ x_k).flatten())
        
        if G_list:
            G_qp = matrix(np.vstack(G_list))
            h_qp = matrix(np.hstack(h_list).reshape(-1, 1))
        else:
            G_qp = None; h_qp = None
        
        sol = solvers.qp(P_qp, q_qp, G_qp, h_qp)
        
        if sol['status'] != 'optimal':
            raise RuntimeError(f"QP 求解失败: {sol['status']}")
        
        U_opt = np.array(sol['x']).reshape(N, nu)
        return U_opt[0, :]  # 仅返回第一个控制量

# ===== 示例：倒立摆离散系统 MPC =====
dt = 0.05
A_c = np.array([[0, 1, 0, 0],
                [0, 0, -0.2*9.81/0.5, 0],
                [0, 0, 0, 1],
                [0, 0, (0.5+0.2)*9.81/(0.5*0.5), 0]])
B_c = np.array([[0], [1/0.5], [0], [-1/(0.5*0.5)]])

# 离散化
Ad = np.eye(4) + dt * A_c
Bd = dt * B_c

Q = np.diag([10, 1, 100, 1])  # 重视摆角
R = np.array([[0.01]])

mpc = LinearMPC(Ad, Bd, Q, R, N=15,
                u_lb=np.array([-20]), u_ub=np.array([20]))

# 闭环仿真
x0 = np.array([0, 0, 0.2, 0])  # 初始摆角偏移
T = 100
x = x0.copy()
x_traj = [x.copy()]; u_traj = []

for k in range(T):
    u_k = mpc.solve(x)
    x = Ad @ x + Bd @ u_k
    x_traj.append(x.copy())
    u_traj.append(u_k)

x_arr = np.array(x_traj); u_arr = np.array(u_traj)
t = np.arange(T+1) * dt

import matplotlib.pyplot as plt
fig, axes = plt.subplots(3, 1, figsize=(10, 8), sharex=True)
axes[0].plot(t, x_arr[:, 0], label='$x$ 小车位置')
axes[0].plot(t, x_arr[:, 2], label='$\\theta$ 摆角')
axes[0].set_ylabel('状态'); axes[0].legend(); axes[0].grid(True)

axes[1].plot(t, x_arr[:, 1], label='$\dot{x}$ 小车速度')
axes[1].plot(t, x_arr[:, 3], label='$\dot{\\theta}$ 摆角速度')
axes[1].set_ylabel('速度'); axes[1].legend(); axes[1].grid(True)

axes[2].step(t[:-1], u_arr.flatten(), where='post')
axes[2].set_ylabel('控制 u'); axes[2].set_xlabel('时间 (s)')
axes[2].grid(True)

fig.suptitle('倒立摆线性 MPC 控制')
plt.tight_layout()
plt.show()
```

### 12.1.4 非线性 MPC（NMPC）简介

对于非线性系统，预测模型为非线性：

$$
x_{k+1} = f(x_k, u_k)
$$

优化问题变为**非线性规划（NLP）**，通常使用：
- **直接单次打靶法**（Direct Single Shooting）
- **多次打靶法**（Direct Multiple Shooting）
- **配置法**（Direct Collocation）

计算量显著增加，对实时性要求高的场景需使用高效的 NLP 求解器（如 IPOPT、ACADOS）。

## 12.2 鲁棒 H∞ 控制

### 12.2.1 小增益定理

**定理（小增益定理）**：若稳定传递函数的无穷范数乘积小于 1，则反馈互联系统稳定。

对于图所示互联系统，若 $\|G(s)\|_\infty \cdot \|\Delta(s)\|_\infty < 1$，则闭环稳定。

$H_\infty$ 范数定义：

$$
\|G(s)\|_\infty = \sup_{\omega} \bar{\sigma}(G(j\omega))
$$

其中 $\bar{\sigma}$ 表示最大奇异值。

### 12.2.2 标准 H∞ 框架

广义被控对象：

$$
\begin{bmatrix} z \\ y \end{bmatrix} =
\begin{bmatrix} G_{11} & G_{12} \\ G_{21} & G_{22} \end{bmatrix}
\begin{bmatrix} w \\ u \end{bmatrix}
$$

控制 $u = K(s)y$，目标是最小化从外部输入 $w$ 到被控输出 $z$ 的 $H_\infty$ 范数：

$$
\min_K \| T_{zw}(s) \|_\infty = \min_K \| G_{11} + G_{12}K(I - G_{22}K)^{-1}G_{21} \|_\infty
$$

### 12.2.3 H∞ 求解思路

**DGKF 方法**（Doyle-Glover-Khargonekar-Francis）：

在标准假设下，H∞ 次优控制器存在当且仅当两个 Riccati 方程有半正定解 $X_\infty, Y_\infty$，且满足谱半径条件：

$$
\rho(X_\infty Y_\infty) < \gamma^2
$$

### 12.2.4 H∞ 与鲁棒性的关系

| 设计指标 | H∞ 范数约束 |
|---------|-------------|
| 灵敏度函数 | $\|W_1 S\|_\infty < 1$ → 跟踪性能 |
| 互补灵敏度 | $\|W_3 T\|_\infty < 1$ → 鲁棒稳定性 |
| 控制灵敏度 | $\|W_2 KS\|_\infty < 1$ → 控制能量约束 |

混合灵敏度问题（S/KS/T 加权）：

$$
\min_K \left\| \begin{bmatrix} W_1 S \\ W_2 K S \\ W_3 T \end{bmatrix} \right\|_\infty < \gamma
$$

## 12.3 自适应控制

### 12.3.1 基本概念

自适应控制是一类能自行调整控制器参数以适应被控对象特性变化的控制方法。

**两类主要方法**：

1. **模型参考自适应控制（MRAC）**：使被控对象输出跟踪参考模型输出
2. **自校正控制（STC）**：在线辨识系统参数 → 按确定性等价原则计算控制律

### 12.3.2 模型参考自适应控制（MRAC）

**MIT 法则**（梯度法）：

设可调参数 $\theta$，性能指标 $J = \frac{1}{2}e^2$（$e = y - y_m$），则：

$$
\frac{d\theta}{dt} = -\gamma \frac{\partial J}{\partial \theta} = -\gamma e \frac{\partial e}{\partial \theta}
$$

其中 $\gamma > 0$ 为自适应增益，$\partial e / \partial \theta$ 为灵敏度导数。

实际中常用**归一化 MIT 法则**以保证稳定性：

$$
\frac{d\theta}{dt} = -\gamma \frac{e \phi}{1 + \phi^T \phi}
$$

### 12.3.3 Lyapunov-MRAC

基于 Lyapunov 稳定性理论设计自适应律，保证全局稳定性。

基本结构：

被控对象 $\dot{x} = Ax + Bu$，参考模型 $\dot{x}_m = A_m x_m + B_m r$

控制律 $u = -K^*(t)x + L^*(t)r$

自适应律：

$$
\dot{K} = \Gamma_K B_m^T P e x^T, \quad \dot{L} = -\Gamma_L B_m^T P e r^T
$$

其中 $P = P^T > 0$ 满足 Lyapunov 方程 $A_m^T P + P A_m = -Q$。

### 12.3.4 自校正控制（STC）

**基本结构**：

1. **参数估计**：使用递推最小二乘法（RLS）在线辨识
2. **控制器设计**：按确定性等价原则，将估计参数当作真值计算控制律
3. **隐式 vs 显示**：隐式算法直接估计控制器参数，显式算法先估计系统参数再计算控制器

## 12.4 强化学习与控制

### 12.4.1 动态规划与最优控制

最优控制问题可描述为 Markov 决策过程（MDP）：

- 状态 $s \in \mathcal{S}$，动作 $a \in \mathcal{A}$
- 转移概率 $P(s'|s, a)$
- 奖励 $r(s, a)$
- 折扣因子 $\gamma \in [0, 1)$

**价值函数**：

$$
V^\pi(s) = \mathbb{E}_\pi \left[ \sum_{k=0}^{\infty} \gamma^k r(s_k, a_k) \mid s_0 = s \right]
$$

**Bellman 最优方程**：

$$
V^*(s) = \max_a \left[ r(s, a) + \gamma \sum_{s'} P(s'|s, a) V^*(s') \right]
$$

### 12.4.2 从 MDP 到 LQR

对于线性系统 $x_{k+1} = A x_k + B u_k$，二次型代价：

$$
r(x, u) = -(x^T Q x + u^T R u)
$$

最优价值函数为二次型：$V^*(x) = x^T P x$，其中 $P$ 满足离散 ARE。

这正是强化学习中**策略迭代**和**值迭代**在连续状态空间的特例。

### 12.4.3 自适应动态规划（ADP）

ADP 结合强化学习与最优控制，适用于大规模/非线性系统的近似最优控制。

**关键结构**：

- **Actor（策略网络）**：输出控制动作
- **Critic（价值网络）**：评估当前策略的价值
- 通过交互数据在线更新两个网络

**启发式动态规划（HDP）**：直接用神经网络逼近价值函数 $V(x)$

**双启发式动态规划（DHP）**：逼近价值函数的梯度 $\partial V / \partial x$

### 12.4.4 RL 在控制中的应用框架

```
环境（被控对象）
    ↓ 状态 s
Critic 网络 → 估计 V(s) 或 Q(s,a)
    ↓ TD 误差
Actor 网络 → 输出控制 u = π(s)
    ↓ 动作 a
环境 → 新状态 s', 奖励 r
    ↓
更新 Critic 和 Actor
```

典型算法：**DDPG**（连续控制）、**PPO**（策略优化）、**SAC**（最大熵框架）。

## 12.5 智能控制

### 12.5.1 模糊控制（Fuzzy Control）

基于模糊逻辑的控制方法，无需精确数学模型，依赖专家经验规则。

**基本结构**：

1. **模糊化**：将精确输入量映射为模糊集合的隶属度
2. **模糊推理**：基于 IF-THEN 规则库进行推理
3. **清晰化**：将模糊输出转化为精确控制量

**典型模糊 PID**：

$$
u_{\text{fuzzy-PID}} = f_{\text{fuzzy}}(e, \dot{e}, \ddot{e})
$$

模糊规则自动调节 PID 增益。

**TSK 模糊模型**（Takagi-Sugeno-Kang）：

规则 $i$：IF $x_1$ is $A_1^i$ AND $\dots$ AND $x_n$ is $A_n^i$ THEN $y^i = a_0^i + a_1^i x_1 + \dots + a_n^i x_n$

### 12.5.2 神经网络控制

利用神经网络的万能逼近特性实现非线性控制。

**主要方法**：

| 方法 | 描述 | 特点 |
|------|------|------|
| 直接逆控制 | 学习系统的逆动力学 | 需充分激励 |
| 监督学习控制 | NN 模仿人类/优化控制器的行为 | 需要训练数据 |
| 神经自适应控制 | NN 在线补偿模型不确定性 | 结合 Lyapunov 设计 |
| 神经 MPC | NN 作为预测模型 | 可处理复杂非线性 |

**神经网络在线补偿**（以二阶系统为例）：

系统 $\dot{x}_1 = x_2, \dot{x}_2 = f(x) + u$

若 $f(x)$ 未知，使用 RBF 神经网络逼近：

$$
\hat{f}(x) = W^T \Phi(x)
$$

其中 $\Phi(x) = [\phi_1(x), \dots, \phi_m(x)]^T$ 为 RBF 基函数：

$$
\phi_i(x) = \exp\left( -\frac{\|x - c_i\|^2}{2\sigma_i^2} \right)
$$

控制律 $u = -\hat{f}(x) - k_1 x_1 - k_2 x_2$，权重更新律：

$$
\dot{W} = \Gamma \Phi(x) e^T P B
$$

### 12.5.3 学习型 MPC（Learning-Based MPC）

将机器学习与 MPC 结合的新兴范式：

1. **数据驱动建模**：用 Gaussian Process / Neural Network 学习系统动态
2. **安全增强学习**：MPC 作为安全过滤器，约束 RL 的探索行为
3. **Tube MPC**：用 GP 学习不确定性的 tube 边界
4. **端到端学习**：直接学习 MPC 的隐式策略（可微 MPC）

## 12.6 多智能体与分布式控制

### 12.6.1 基本概念

**多智能体系统（MAS）**由多个自主智能体组成，通过局部信息交互实现全局协同目标。

典型任务：
- **一致性（Consensus）**：所有智能体状态趋于一致
- **编队控制（Formation）**：智能体维持期望的相对位置
- **蜂拥（Flocking）**：模拟鸟群/鱼群的自组织行为
- **包围（Containment）**：领导-跟随者框架

### 12.6.2 一致性协议

**一阶一致性**：

$$
\dot{x}_i = -\sum_{j \in \mathcal{N}_i} a_{ij} (x_i - x_j)
$$

其中 $\mathcal{N}_i$ 为智能体 $i$ 的邻居集合，$a_{ij} > 0$ 为邻接权重。

写成紧凑形式：$\dot{x} = -L x$，其中 $L$ 为图的 **Laplacian 矩阵**。

**一致性条件**：图含有一棵有向生成树（即 $L$ 的零特征值唯一，其余特征值实部为正）。

### 12.6.3 与图论的关系

| 图论概念 | 控制含义 |
|---------|---------|
| 邻接矩阵 $A$ | 智能体间通信拓扑 |
| Laplacian $L = D - A$ | 一致性动力学的系统矩阵 |
| 强连通图 | 各智能体充分互联 |
| 生成树 | 信息可达全体智能体 |

### 12.6.4 分布式 MPC

将集中式 MPC 分解为各智能体的子问题，每个智能体仅优化自身控制：

$$
\min_{u_i(\cdot)} J_i(x_i, u_i, \hat{x}_{-i})
$$

通过**迭代协商**或**非迭代耦合约束**保证全局性能。适用于大规模系统（智能电网、交通网络、无人机编队等）。

## 12.7 方法选择指南

| 应用场景 | 推荐方法 | 理由 |
|---------|---------|------|
| 线性 SISO、频域指标明确 | 经典 PID / 超前滞后 | 简单可靠 |
| 线性 MIMO、全状态可测 | LQR | 系统化多变量最优 |
| 状态不可测 | LQG / Kalman + 分离原理 | 最优状态估计 |
| 存在执行器/状态约束 | MPC | 显式约束处理 |
| 模型有不确性 | H∞ / 滑模控制 | 鲁棒性保证 |
| 参数在线变化 | 自适应控制 (MRAC) | 在线调节 |
| 强非线性 | 反馈线性化 + LQR | 线性化设计 |
| 模型未知 | RL / 模糊控制 / 神经控制 | 数据驱动 |
| 多智能体协同 | 一致性协议 + 分布式 MPC | 去中心化 |

---

## 总结

| 方法 | 核心思想 | 需要模型 | 处理约束 | 计算量 |
|------|---------|---------|---------|--------|
| **经典 PID** | 误差反馈 (P+I+D) | 不需要 | 不处理 | 极低 |
| **MPC** | 滚动时域优化 | 需要 | 显式处理 | 高 |
| **H∞** | 频域鲁棒分析 | 需要 | 间接（加权） | 中 |
| **自适应控制** | 在线参数辨识 | 结构已知 | 间接 | 中 |
| **RL 控制** | 试错学习最优策略 | 不需要 | 困难 | 很高 |
| **模糊控制** | 专家规则推理 | 不需要 | 软约束 | 低 |
| **神经控制** | NN 万能逼近 | 不需要 | 困难 | 中 |
| **分布式控制** | 局部交互+全局协同 | 部分需要 | 分散约束 | 中 |

> 不同高级控制方法各有侧重：MPC 擅长处理约束，H∞ 提供鲁棒性保证，自适应控制应对参数变化，RL 在无模型场景有优势。实际中常采用混合策略（如 Adaptive MPC、Robust MPC、Learning-based MPC），以实现综合优势。

> 控制理论的发展趋势是从"基于模型的控制"逐渐走向"数据驱动 + 模型"的混合范式，强化学习和智能控制方法在这一趋势中扮演着日益重要的角色。
