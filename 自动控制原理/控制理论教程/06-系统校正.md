# 第6章 系统校正

> 系统校正是经典控制理论的落地点：当原系统不能满足性能指标时，通过引入校正装置改变系统的动态和稳态特性，使系统达到期望的性能要求。

## 6.1 校正的基本概念

### 6.1.1 校正问题的提法

给定被控对象 $G_p(s)$ 和性能指标（时域指标或频域指标），设计校正装置 $G_c(s)$，使校正后的系统满足要求。

**校正的两种基本结构**：

**(1) 串联校正**（Cascade/Series Compensation）：

```
R(s) → [G_c(s)] → [G_p(s)] → C(s)
         ↑_________|
           H(s)
```

开环传递函数：$G_{ol}(s) = G_c(s)G_p(s)H(s)$

**(2) 反馈校正**（Feedback Compensation）：

校正装置 $G_f(s)$ 包围被控对象的部分环节，形成内环：

```
R(s) → [+] → [G_1(s)] → [G_2(s)] → C(s)
         ↑______|          |
         |   [G_f(s)] ←----|
```

### 6.1.2 性能指标

**时域指标**（见 [[02-时域分析]]）：
- 稳态误差 $e_{ss}$
- 超调量 $\sigma\%$
- 调节时间 $t_s$
- 上升时间 $t_r$

**频域指标**（见 [[05-频域分析]]）：
- 相位裕度 $\gamma$
- 增益裕度 $G_m$
- 剪切频率 $\omega_c$（带宽）
- 谐振峰值 $M_p$

**频域与时域指标的转换**：
- $\gamma \approx 100\zeta$（$\zeta < 0.7$）
- $\sigma\% \approx e^{-\pi\zeta/\sqrt{1-\zeta^2}} \times 100\%$
- $t_s \approx 3.5/(\zeta\omega_c)$（近似）

### 6.1.3 校正方式分类

| 校正方式 | 特点 | 适用场景 |
|---------|------|---------|
| 超前校正 | 增加相位裕度，提高带宽 | 稳态精度满足但稳定性不足 |
| 滞后校正 | 减小高频增益，提高稳态精度 | 稳定性满足但稳态精度不足 |
| 滞后-超前校正 | 兼具两者优点 | 综合性性能要求 |
| PID 控制 | 结构简单，适用性广 | 大多数工业过程 |
| 前馈校正 | 不改变闭环稳定性 | 扰动可测情况 |
| Smith 预估器 | 补偿大纯滞后 | 时滞系统 |

## 6.2 超前校正（Lead Compensation）

### 6.2.1 超前校正网络的传递函数

超前校正装置的传递函数为：

$$G_c(s) = K_c \cdot \frac{\alpha Ts + 1}{Ts + 1} = K_c \alpha \cdot \frac{s + 1/(\alpha T)}{s + 1/T}$$

其中 $\alpha > 1$（超前因子），$T > 0$。

写成零极点形式：

$$G_c(s) = K_c \alpha \cdot \frac{s + z_c}{s + p_c}, \quad z_c = \frac{1}{\alpha T},\; p_c = \frac{1}{T}$$

**频率特性**：

$$G_c(j\omega) = K_c \alpha \cdot \frac{j\omega + z_c}{j\omega + p_c}$$

### 6.2.2 最大超前角

超前网络的相频特性：

$$\varphi_c(\omega) = \arctan(\alpha T\omega) - \arctan(T\omega)$$

**最大超前角频率** $\omega_m$ 出现在两个转角频率的几何中点：

$$\omega_m = \frac{1}{T\sqrt{\alpha}} = \sqrt{z_c p_c}$$

**最大超前角**：

$$\varphi_m = \arcsin\left(\frac{\alpha - 1}{\alpha + 1}\right)$$

**设计反算公式**（由所需 $\varphi_m$ 计算 $\alpha$）：

$$\alpha = \frac{1 + \sin\varphi_m}{1 - \sin\varphi_m}$$

常用的 $\alpha$-$\varphi_m$ 对应关系：

| $\alpha$ | $\varphi_m$ | 说明 |
|----------|-------------|------|
| 2 | $19.5^\circ$ | 轻度超前 |
| 5 | $41.8^\circ$ | 中度超前 |
| 10 | $55.0^\circ$ | 较强超前 |
| 15 | $61.0^\circ$ | — |
| 20 | $64.8^\circ$ | 实用上限 |

> **注意**：实际设计中一般取 $\alpha \leq 15$，过大的 $\alpha$ 会引入过多的高频增益，放大噪声。

### 6.2.3 超前校正的设计步骤

给定被控对象 $G_p(s)$ 和期望的相位裕度 $\gamma^*$、剪切频率 $\omega_c^*$（或稳态误差系数 $K_v^*$）。

**Bode 图法设计步骤**：

1. 根据稳态误差要求确定开环增益 $K$
2. 绘制未校正系统的 Bode 图，求出 $\gamma_0$ 和 $\omega_{c0}$
3. 计算需要补充的相位超前角：
   $$\varphi_m = \gamma^* - \gamma_0 + \Delta\gamma$$
   其中 $\Delta\gamma = 5^\circ \sim 15^\circ$（补偿超前校正带来的剪切频率右移造成的相位损失）
4. 由 $\varphi_m$ 计算 $\alpha$：$\alpha = (1+\sin\varphi_m)/(1-\sin\varphi_m)$
5. 确定新的剪切频率 $\omega_c'$，满足：
   $$|G_p(j\omega_c')|_{dB} = -10\lg\alpha$$
6. 确定 $T$：$T = 1/(\omega_c'\sqrt{\alpha})$
7. 写出校正装置：$G_c(s) = \frac{\alpha Ts + 1}{Ts + 1}$
8. 验证校正后系统的性能指标

```python
import numpy as np
import scipy.signal as signal
import control as ct

def lead_compensator_design(Gp, gamma_desired, Kv=None):
    """
    超前校正设计
    Gp: 被控对象传递函数 (control.TransferFunction)
    gamma_desired: 期望相位裕度 (度)
    Kv: 期望速度误差系数 (可选)
    """
    # Step 1: 确定增益
    if Kv is not None:
        # 调整增益以满足 Kv 要求
        K = Kv * Gp.den[0][-1] / Gp.num[0][-1] if Gp.num[0][-1] != 0 else Kv
        Gp = ct.TransferFunction([K], [1]) * Gp

    # Step 2-3: 未校正系统的相位裕度
    gm0, pm0, wg0, wp0 = ct.margin(Gp)
    print(f"未校正系统：γ0 = {pm0:.1f}°, ωc0 = {wp0:.3f} rad/s")

    # Step 4: 计算需要的超前角
    delta = 10  # 补偿角 5~15°
    phi_m = gamma_desired - pm0 + delta
    if phi_m <= 0:
        print("无需超前校正，或需要滞后校正")
        return None

    # Step 5: 计算 alpha
    alpha = (1 + np.sin(np.deg2rad(phi_m))) / (1 - np.sin(np.deg2rad(phi_m)))
    alpha = min(alpha, 20)  # 限制 alpha
    phi_m = np.rad2deg(np.arcsin((alpha - 1) / (alpha + 1)))
    print(f"α = {alpha:.2f}, φ_m = {phi_m:.1f}°")

    # Step 6: 确定新剪切频率 ωc'
    mag_atten = -10 * np.log10(alpha)
    # 寻找满足 |Gp(jω)| = mag_atten 的频率
    w_test = np.logspace(np.log10(wp0*0.1), np.log10(wp0*10), 5000)
    _, mag, _ = signal.bode(
        signal.TransferFunction(Gp.num[0], Gp.den[0]), w_test
    )
    idx = np.argmin(np.abs(mag - mag_atten))
    wc_new = w_test[idx]
    print(f"新剪切频率 ωc' = {wc_new:.3f} rad/s")

    # Step 7: 计算 T
    T = 1 / (wc_new * np.sqrt(alpha))
    print(f"T = {T:.4f}")

    # 超前校正装置
    num_c = [alpha * T, 1]
    den_c = [T, 1]
    Gc = ct.TransferFunction(num_c, den_c)

    return Gc, alpha, T

# 示例：Gp(s) = 10 / s(s+1)
Gp = ct.TransferFunction([10], [1, 1, 0])
Gc, alpha, T = lead_compensator_design(Gp, gamma_desired=45)

print(f"\n校正装置：Gc(s) = ({alpha*T:.4f}s + 1) / ({T:.4f}s + 1)")

# 验证
Gol = ct.series(Gc, Gp)
gm, pm, wg, wp = ct.margin(Gol)
print(f"校正后：γ = {pm:.1f}°, ωc = {wp:.3f} rad/s")
```

### 6.2.4 超前校正的特点

**优点**：
- 增加相位裕度，改善相对稳定性
- 提高剪切频率，增大系统带宽，加快响应速度
- 不改变稳态精度

**缺点**：
- 高频增益提高，可能放大噪声
- 对于相位急剧下降的系统效果有限
- $\alpha$ 不能太大（通常 $\alpha \leq 20$）

## 6.3 滞后校正（Lag Compensation）

### 6.3.1 滞后校正网络的传递函数

滞后校正装置的传递函数为：

$$G_c(s) = K_c \cdot \frac{Ts + 1}{\beta Ts + 1}$$

其中 $\beta > 1$（滞后因子），$T > 0$。

写成零极点形式：

$$G_c(s) = \frac{K_c}{\beta} \cdot \frac{s + 1/T}{s + 1/(\beta T)}$$

### 6.3.2 滞后校正的衰减特性

滞后校正在高频段提供衰减：

$$|G_c(j\omega)|_{dB} \xrightarrow{\omega \to \infty} -20\lg\beta$$

**关键参数**：
- 高频衰减量：$20\lg\beta$ dB
- 滞后网络的相位滞后角在低频时最大：

$$\varphi_m^{lag} = -\arcsin\left(\frac{\beta-1}{\beta+1}\right)$$

### 6.3.3 滞后校正的设计步骤

1. 根据稳态误差要求确定开环增益 $K$
2. 绘制未校正系统的 Bode 图，求出 $\gamma_0$
3. 确定期望剪切频率 $\omega_c'$（选择在相位满足要求的位置）
4. 计算需要的衰减量 $L_0$：在 $\omega_c'$ 处，$|G_p|_{dB} + L_0 = 0$
5. 确定 $\beta$：$20\lg\beta = -L_0$，即 $\beta = 10^{-L_0/20}$
6. 确定 $T$：使滞后网络的转角频率远低于 $\omega_c'$，一般取 $1/T = \omega_c'/10$
7. 写出校正装置并验证

```python
import numpy as np
import control as ct

def lag_compensator_design(Gp, gamma_desired, Kv=None):
    """
    滞后校正设计
    """
    # Step 1: 确定增益
    if Kv is not None:
        K = Kv * Gp.den[0][-1] / Gp.num[0][-1] if Gp.num[0][-1] != 0 else Kv
        Gp = ct.TransferFunction(Gp.num[0] * K, Gp.den[0])

    gm0, pm0, wg0, wp0 = ct.margin(Gp)
    print(f"未校正系统：γ0 = {pm0:.1f}°, ωc0 = {wp0:.3f} rad/s")

    # Step 3: 寻找期望剪切频率（相位满足 γ_desired + 5°）
    phase_margin = gamma_desired + 10  # 安全裕量
    w_test = np.logspace(-2, 2, 5000)
    _, _, phase = ct.bode(Gp, w_test, plot=False)
    # 寻找满足相位 = -180 + phase_margin 的频率
    target_phase = -180 + phase_margin
    valid = phase > target_phase
    if not np.any(valid):
        print("无法找到合适的剪切频率")
        return None
    wc_new = w_test[np.where(valid)[0][-1]]
    print(f"新剪切频率 ωc' = {wc_new:.3f} rad/s (相位 = {phase[np.where(valid)[0][-1]]:.1f}°)")

    # Step 4: 计算需要的衰减量
    _, mag_at_wc, _ = ct.bode(Gp, [wc_new], plot=False)
    attenuation_needed = -mag_at_wc[0]
    print(f"需要衰减 {attenuation_needed:.1f} dB")

    # Step 5: 计算 beta
    beta = 10 ** (attenuation_needed / 20)
    print(f"β = {beta:.2f}")

    # Step 6: 确定 T
    T = 10 / wc_new  # 转角频率远低于剪切频率
    print(f"T = {T:.4f}")

    # 滞后校正装置
    num_c = [T, 1]
    den_c = [beta * T, 1]
    Gc = ct.TransferFunction(num_c, den_c)

    return Gc, beta, T

Gp = ct.TransferFunction([10], [1, 1, 0])
Gc, beta, T = lag_compensator_design(Gp, gamma_desired=45)
```

### 6.3.4 滞后校正的特点

**优点**：
- 提高系统的稳态精度（增大 $K_v$、$K_p$）
- 不降低系统的稳定性
- 抑制高频噪声

**缺点**：
- 降低剪切频率，减小带宽，减慢响应速度
- 引入相位滞后，需小心放置转角频率

## 6.4 滞后-超前校正（Lag-Lead Compensation）

滞后-超前校正装置综合了超前和滞后两种校正的特点：

$$G_c(s) = K_c \cdot \frac{(\tau_1 s + 1)(\tau_2 s + 1)}{(\beta\tau_1 s + 1)(\frac{\tau_2}{\alpha}s + 1)}$$

其中：
- 滞后部分（$\beta\tau_1 s$）：改善稳态精度，$\beta > 1$
- 超前部分（$\tau_2/\alpha$）：改善动态性能，$\alpha > 1$

**频率特性**：低频段表现为滞后校正，中频段表现为超前校正，高频段衰减。

**设计思路**：先设计超前部分满足动态要求，再设计滞后部分满足稳态要求。或反之。

```python
import numpy as np
import control as ct

def lag_lead_compensator_design(Gp, gamma_desired, wc_desired, Kv=None):
    """
    滞后-超前校正设计
    """
    # 先设计超前部分（满足动态要求）
    # 超前参数
    alpha = 10  # 典型取值
    phi_lead = np.rad2deg(np.arcsin((alpha - 1) / (alpha + 1)))
    print(f"超前部分：α = {alpha}, φ_lead = {phi_lead:.1f}°")

    T_lead = 1 / (wc_desired * np.sqrt(alpha))
    print(f"超前 T = {T_lead:.4f}")

    # 滞后部分（提高稳态精度）
    beta = 10  # 典型取值
    T_lag = 10 / wc_desired  # 转角频率远低于剪切频率
    print(f"滞后部分：β = {beta}, T_lag = {T_lag:.4f}")

    # 合成
    num_lead = [alpha * T_lead, 1]
    den_lead = [T_lead, 1]
    G_lead = ct.TransferFunction(num_lead, den_lead)

    num_lag = [T_lag, 1]
    den_lag = [beta * T_lag, 1]
    G_lag = ct.TransferFunction(num_lag, den_lag)

    Gc = ct.series(G_lag, G_lead)

    # 验证
    Gol = ct.series(Gc, Gp)
    gm, pm, wg, wp = ct.margin(Gol)
    print(f"\n校正后：γ = {pm:.1f}°, ωc = {wp:.3f} rad/s")

    return Gc

Gp = ct.TransferFunction([20], [1, 3, 2, 0])
Gc = lag_lead_compensator_design(Gp, gamma_desired=50, wc_desired=5.0)
```

## 6.5 PID 控制

PID（Proportional-Integral-Derivative）控制是最广泛应用的工业控制算法。

### 6.5.1 PID 控制器的结构

$$u(t) = K_p \left[ e(t) + \frac{1}{T_i}\int_0^t e(\tau)d\tau + T_d \frac{de(t)}{dt} \right]$$

传递函数：

$$G_c(s) = K_p \left(1 + \frac{1}{T_i s} + T_d s\right) = K_p + \frac{K_i}{s} + K_d s$$

其中 $K_i = K_p/T_i$，$K_d = K_p T_d$。

### 6.5.2 P、I、D 各自的作用

| 环节 | 传递函数 | 作用 | 副作用 |
|------|---------|------|--------|
| **P（比例）** | $K_p$ | 减小稳态误差，加快响应 | 过大引起振荡或不稳定 |
| **I（积分）** | $K_p/(T_i s)$ | 消除稳态误差（阶跃输入），提高系统型别 | 降低稳定性，可能引起积分饱和 |
| **D（微分）** | $K_p T_d s$ | 增加阻尼，减小超调，加快响应，预测误差趋势 | 放大高频噪声，不宜单独使用 |

**总结口诀**：
- P：现在（比例于当前误差）
- I：过去（累计历史误差）
- D：未来（预测误差变化趋势）

### 6.5.3 PID 的频域解释

在 [[05-频域分析]] 的框架下：
- **PI 控制**在低频段提高增益（改善稳态精度），相当于滞后校正
- **PD 控制**在中频段提供相位超前（改善稳定性），相当于超前校正
- **PID 控制**综合二者，相当于滞后-超前校正

### 6.5.4 Ziegler-Nichols 整定方法

Ziegler-Nichols 方法是最经典的 PID 参数整定方法，分为两种。

#### 方法一：阶跃响应法（开环法）

对开环系统施加单位阶跃输入，获得 S 形响应曲线，从中提取：

- $L$：滞后时间（延迟）
- $T$：时间常数
- 切线最大斜率 $R = K/T$

参数整定表：

| 控制器类型 | $K_p$ | $T_i$ | $T_d$ |
|-----------|-------|-------|-------|
| P | $T/(L)$ | — | — |
| PI | $0.9T/(L)$ | $3.3L$ | — |
| PID | $1.2T/(L)$ | $2L$ | $0.5L$ |

#### 方法二：临界振荡法（闭环法）

1. 将控制器设为纯比例（$T_i = \infty$，$T_d = 0$），$K_p$ 从 0 开始增大
2. 找到使系统持续等幅振荡的临界增益 $K_u$ 和对应的临界振荡周期 $T_u$
3. 按表整定：

| 控制器类型 | $K_p$ | $T_i$ | $T_d$ |
|-----------|-------|-------|-------|
| P | $0.5K_u$ | — | — |
| PI | $0.45K_u$ | $0.83T_u$ | — |
| PID | $0.6K_u$ | $0.5T_u$ | $0.125T_u$ |

```python
import numpy as np
import control as ct
import matplotlib.pyplot as plt

def ziegler_nichols_step_method(K, L, T, controller_type='PID'):
    """
    Ziegler-Nichols 阶跃响应法
    K: 稳态增益
    L: 滞后时间
    T: 时间常数
    """
    if controller_type == 'P':
        Kp = T / L
        Ti = np.inf
        Td = 0
    elif controller_type == 'PI':
        Kp = 0.9 * T / L
        Ti = 3.3 * L
        Td = 0
    elif controller_type == 'PID':
        Kp = 1.2 * T / L
        Ti = 2.0 * L
        Td = 0.5 * L

    Ki = Kp / Ti if Ti != np.inf else 0
    Kd = Kp * Td

    num_c = [Kd, Kp, Ki]
    den_c = [1, 0]  # 含积分器
    Gc = ct.TransferFunction(num_c, den_c)
    return Gc, Kp, Ki, Kd

def ziegler_nichols_ultimate_method(Ku, Tu, controller_type='PID'):
    """
    Ziegler-Nichols 临界振荡法
    Ku: 临界增益
    Tu: 临界振荡周期
    """
    if controller_type == 'P':
        Kp = 0.5 * Ku
        Ti = np.inf
        Td = 0
    elif controller_type == 'PI':
        Kp = 0.45 * Ku
        Ti = 0.83 * Tu
        Td = 0
    elif controller_type == 'PID':
        Kp = 0.6 * Ku
        Ti = 0.5 * Tu
        Td = 0.125 * Tu

    Ki = Kp / Ti if Ti != np.inf else 0
    Kd = Kp * Td

    num_c = [Kd, Kp, Ki]
    den_c = [1, 0]
    Gc = ct.TransferFunction(num_c, den_c)
    return Gc, Kp, Ki, Kd

# 示例：被控对象 Gp(s) = 1 / (s+1)^3
Gp = ct.TransferFunction([1], [1, 3, 3, 1])

# 方法二：寻找临界增益
w_test = np.logspace(-1, 1, 5000)
_, _, phase = ct.bode(Gp, w_test, plot=False)
# 相位穿越频率
idx = np.argmin(np.abs(phase + 180))
wu = w_test[idx]
_, mag_at_wu, _ = ct.bode(Gp, [wu], plot=False)
Ku = 1 / (10 ** (mag_at_wu[0] / 20))
Tu = 2 * np.pi / wu
print(f"临界增益 Ku = {Ku:.3f}, 临界周期 Tu = {Tu:.3f}s")

Gc, Kp, Ki, Kd = ziegler_nichols_ultimate_method(Ku, Tu, 'PID')
print(f"PID 参数：Kp = {Kp:.3f}, Ki = {Ki:.3f}, Kd = {Kd:.3f}")

# 闭环系统
Gol = ct.series(Gc, Gp)
Gcl = ct.feedback(Gol, 1)

# 阶跃响应
t, y = ct.step_response(Gcl, T=np.linspace(0, 30, 1000))
plt.figure(figsize=(8, 4))
plt.plot(t, y, 'b-', linewidth=1.5)
plt.axhline(y=1, color='k', linestyle='--', alpha=0.3)
plt.xlabel('Time (s)')
plt.ylabel('Output')
plt.title(f'PID 控制阶跃响应 (Z-N 法)\nKp={Kp:.2f}, Ki={Ki:.2f}, Kd={Kd:.2f}')
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()
```

### 6.5.5 PID 的实际问题

**(1) 积分饱和（Integral Windup）**

当执行器饱和时，积分器持续累积误差，导致超调增大。解决方法：
- 积分分离：大偏差时切断积分
- 遇限削弱积分法（Clamping）
- 反计算抗饱和（Back-calculation）

**(2) 微分噪声放大**

实际 PID 通常在微分项后加低通滤波：

$$D(s) = \frac{K_d s}{\tau_f s + 1}$$

其中 $\tau_f \ll T_d$，一般取 $\tau_f = T_d/N$，$N = 5 \sim 20$。

**(3) 无扰动切换**

手动/自动模式切换时，需保证控制量连续。常用方法：跟踪型 PID，使手动时积分项跟踪当前输出。

## 6.6 前馈-反馈复合控制

### 6.6.1 基本原理

前馈控制利用扰动信号直接产生补偿控制量，与反馈控制结合：

```
        ┌──── [G_f(s)] ────┐
        ↓                  ↓
D(s) → [+] → [G_c(s)] → [G_p(s)] → [+] → C(s)
         ↑___________|              ↑
                     反馈 H(s)       扰动 N(s)
```

其中 $G_f(s)$ 为前馈补偿器。

### 6.6.2 不变性原理

前馈补偿器 $G_f(s)$ 的设计目标是对扰动 $N(s)$ 实现**不变性**（Invariance），即使得扰动到输出的传递函数为零。

对于扰动可测的情况，若扰动作用通道为 $G_n(s)$，则前馈补偿器：

$$G_f(s) = -\frac{G_n(s)}{G_p(s)}$$

这样 $N(s)$ 对 $C(s)$ 的影响被完全抵消。

**前馈-反馈复合的优点**：
- 前馈补偿扰动，反馈保证鲁棒性
- 前馈不影响闭环稳定性
- 比纯反馈响应更快

## 6.7 Smith 预估器

### 6.7.1 纯滞后问题

当被控对象含有大纯滞后 $e^{-\tau s}$：

$$G_p(s) = G_0(s) e^{-\tau s}$$

常规 PID 控制效果很差，因为：
- 相位严重滞后（$-\omega\tau$），稳定性受限
- 控制量需等待 $\tau$ 时间才能看到效果

### 6.7.2 Smith 预估器结构

Smith 预估器通过模型预估消除纯滞后对反馈回路的影响：

```
R(s) → [+] → [G_c(s)] → [G_0(s)] → [e^{-τs}] → C(s)
         ↑_____|         ↑
         |               |
         └── [G_0(s)(1-e^{-τs})] ←┘
```

内环传递函数（Smith 预估后）：

$$G_{inner}(s) = G_c(s)G_0(s)$$

**关键思想**：反馈信号中消除了 $e^{-\tau s}$ 的影响，控制器 $G_c(s)$ 可针对无延迟的 $G_0(s)$ 设计。

**局限性**：
- 依赖精确的模型 $G_0(s)$ 和 $\tau$
- 对模型误差敏感
- 开环不稳定系统慎用

```python
import numpy as np
import control as ct
from scipy.signal import lti, lsim

def smith_predictor_sim(G0, tau, Gc, t, r_func):
    """
    Smith 预估器仿真
    G0: 无延迟部分传递函数
    tau: 纯滞后时间
    Gc: 控制器
    t: 时间向量
    r_func: 参考输入函数
    """
    dt = t[1] - t[0]
    delay_steps = int(tau / dt)
    n = len(t)
    y = np.zeros(n)
    y0 = np.zeros(n)  # 无延迟输出
    u = np.zeros(n)
    e = np.zeros(n)

    # 控制器状态
    xc = np.zeros(len(Gc.den[0]) - 1)
    # 无延迟模型状态
    x0 = np.zeros(len(G0.den[0]) - 1)

    for k in range(n - 1):
        r = r_func(t[k])
        y[k] = y0[k - delay_steps] if k >= delay_steps else 0
        # Smith 预估：反馈使用无延迟模型输出
        e[k] = r - y0[k]  # 注意：实际应用中需加修正项
        # 简化形式，仅示意
        break  # 完整实现较复杂，此处仅提供框架

    return t, y, u

# 简化示例
print("Smith 预估器适用于大纯滞后系统 G_p(s) = G_0(s) e^{-τs}")
print("控制器可针对 G_0(s) 设计，再套入 Smith 结构")
```

## 总结

本章涵盖了系统校正的核心内容：

1. **校正的本质**是引入校正装置 $G_c(s)$，通过改变开环频率特性使系统满足性能指标
2. **超前校正**提供相位超前，增加相位裕度，提高系统带宽和响应速度；设计关键是 $\alpha$ 和 $\omega_m$ 的确定
3. **滞后校正**提供高频衰减，提高稳态精度，但会降低带宽；设计关键是 $\beta$ 和转角频率的放置
4. **滞后-超前校正**综合两者的优点，先在低频段提供增益，再在中频段提供相位超前
5. **PID 控制**是最实用的校正方法：P 减小误差，I 消除静差，D 增加阻尼。Ziegler-Nichols 法提供了简便的参数整定途径
6. **前馈-反馈复合**利用不变性原理补偿可测扰动，不影响稳定性
7. **Smith 预估器**是处理大纯滞后系统的有效工具

校正是连接[[05-频域分析]]理论与工程实践的桥梁。频域法（Bode 图）是最直观的校正设计工具。
