# 拉格朗日乘数法

> **理论基础** → 参见 [[../../优化方法/非线性规划|非线性规划·KKT理论]]

拉格朗日乘数法将约束优化问题转化为无约束问题，是KKT条件的基础，用于求解等式/不等式约束的极值问题。

## 七、Python 代码实现
### 7.1 等式约束拉格朗日乘数法

```python
import numpy as np
from scipy.optimize import minimize

def lagrangian_equality(f, grad_f, h, jac_h, x0, lam0, rho=1.0, max_iter=100):
    """增广拉格朗日法求解等式约束问题"""
    x = x0.copy()
    lam = lam0.copy()
    
    for k in range(max_iter):
        # 求解增广拉格朗日函数的最小值
        def aug_lag(x_val):
            return f(x_val) + lam @ h(x_val) + (rho/2) * np.sum(h(x_val)**2)
        
        def aug_lag_grad(x_val):
            return grad_f(x_val) + jac_h(x_val).T @ (lam + rho * h(x_val))
        
        res = minimize(aug_lag, x, jac=aug_lag_grad, method='L-BFGS-B')
        x = res.x
        
        # 更新乘子
        lam = lam + rho * h(x)
        
        # 检查收敛
        if np.linalg.norm(h(x)) < 1e-8:
            break
    
    return x, lam

# 示例: min x^2 + y^2, s.t. x + y - 2 = 0
f = lambda x: x[0]**2 + x[1]**2
grad_f = lambda x: np.array([2*x[0], 2*x[1]])
h = lambda x: np.array([x[0] + x[1] - 2])
jac_h = lambda x: np.array([[1, 1]])

x0 = np.array([0.0, 0.0])
lam0 = np.array([0.0])

x_opt, lam_opt = lagrangian_equality(f, grad_f, h, jac_h, x0, lam0)
print(f"最优解: x={x_opt[0]:.4f}, y={x_opt[1]:.4f}")
print(f"拉格朗日乘子: lambda={lam_opt[0]:.4f}")
print(f"最优值: {f(x_opt):.4f}")
```

### 7.2 不等式约束（KKT条件验证）

```python
import numpy as np
from scipy.optimize import minimize

# min f(x) = (x1-1)^2 + (x2-2)^2
# s.t. x1 + x2 <= 3, x1 >= 0, x2 >= 0

f = lambda x: (x[0]-1)**2 + (x[1]-2)**2
grad_f = lambda x: np.array([2*(x[0]-1), 2*(x[1]-2)])

constraints = [
    {'type': 'ineq', 'fun': lambda x: 3 - x[0] - x[1]},  # g1 <= 0
]

bounds = [(0, None), (0, None)]

result = minimize(f, [0, 0], method='SLSQP', bounds=bounds, constraints=constraints)
x_star = result.x

print(f"最优解: x1={x_star[0]:.4f}, x2={x_star[1]:.4f}")
print(f"最优值: {f(x_star):.4f}")
print(f"g1(x*) = {3 - x_star[0] - x_star[1]:.4f}")
print(f"x1* = {x_star[0]:.4f}, x2* = {x_star[1]:.4f}")
```

### 7.3 次梯度方法

```python
import numpy as np

def subgradient_method(L, subgrad, lambda0, max_iter=200, alpha0=1.0):
    """次梯度方法最大化对偶函数 L(lambda)"""
    lam = lambda0.copy()
    best_lam = lam.copy()
    best_val = float('-inf')
    
    for k in range(max_iter):
        val = L(lam)
        if val > best_val:
            best_val = val
            best_lam = lam.copy()
        
        g = subgrad(lam)
        alpha = alpha0 / (k + 1)  # 递减步长
        
        lam = lam + alpha * g
        lam = np.maximum(lam, 0)  # 投影到非负象限
    
    return best_lam, best_val

# 示例
L_func = lambda lam: min(x**2 + lam*(1-x) for x in np.linspace(-5, 5, 1000))
subgrad_func = lambda lam: 1  # 简化示例

lam_opt, val = subgradient_method(L_func, subgrad_func, np.array([0.0]))
print(f"最优对偶变量: {lam_opt[0]:.4f}")
print(f"最优对偶值: {val:.4f}")
```

## 九、实际应用
### 9.1 资源配置

将有限资源在 $n$ 个项目之间分配，使总收益最大：

$$
\max \quad \sum_{i=1}^{n} f_i(x_i) \quad \text{s.t.} \quad \sum_{i=1}^{n} x_i = B
$$

拉格朗日条件：$f_i'(x_i^*) = \lambda$（所有项目的边际收益相等）。

### 9.2 最小能量问题

在力学中，平衡状态对应势能泛函的极值，受约束（如几何约束、运动学约束），拉格朗日乘子对应约束力。

## 十、关键要点总结
1. **拉格朗日乘数法**将约束优化转化为无约束优化，是约束优化的理论基石
2. **一阶必要条件**给出了 $\nabla f$ 与约束梯度共线的条件
3. **KKT条件**是处理不等式约束的必要条件，包含互补松弛
4. **对偶理论**揭示了原问题与对偶问题的关系，强对偶在凸优化下成立
5. **影子价格**（拉格朗日乘子）具有重要的经济学含义
6. **增广拉格朗日法**通过添加二次罚项改善收敛性
7. **拉格朗日松弛**将难约束放入目标函数，提供问题的界
8. 次梯度方法用于最大化非光滑的对偶函数
