# 分支定界法

## 一、分支定界法概述

分支定界法（Branch and Bound, B&B）是求解整数规划和组合优化问题最系统、最通用的精确算法。由 Land 和 Doig 于1960年提出，是现代整数规划求解器的核心框架。

### 1.1 基本思想

分支定界法通过三个核心操作来系统搜索解空间：

1. **分支（Branching）**：将问题分解为子问题，子问题的并集覆盖原问题的解空间
2. **定界（Bounding）**：利用松弛问题为每个子问题计算上界和下界
3. **剪枝（Pruning/Fathoming）**：根据界的信息排除不可能包含最优解的子问题

### 1.2 解空间的系统搜索

分支定界法可以看作是在一棵**搜索树**上进行的系统搜索：

- 根节点对应原问题
- 每个分支对应添加一个新的约束
- 叶节点对应不可再分的子问题
- 剪枝相当于将某个子树整体移除

### 1.3 界的概念

对于**最大化**整数规划问题：
- **上界（Upper Bound）**：子问题松弛解的最优值，是该分支最优值的上界
- **下界（Lower Bound）**：当前找到的最好整数可行解的值，是全局最优值的下界
- 当某个节点的上界 $\leq$ 当前下界时，该节点可被剪枝

## 二、分支定界法的完整框架

### 2.1 算法描述

**算法：分支定界法**

> **输入**：整数规划问题 $P$
> **输出**：最优整数解 $\mathbf{x}^*$ 及最优值 $z^*$

1. **初始化**：求解 $P$ 的松弛问题 $P_0$
   - 若 $P_0$ 不可行，则 $P$ 不可行，终止
   - 设当前下界 $LB = -\infty$（最大化问题）
   - 最优解 $\mathbf{x}^* = \text{None}$

2. **松弛求解**：求解当前子问题的松弛问题
   - 若不可行，剪枝
   - 若最优值 $\leq LB$，剪枝
   - 若松弛最优解为整数解，更新 $LB$（若优于当前 $LB$）
   - 否则，继续分支

3. **分支**：选择分数变量 $x_k$，生成两个子问题：
   - 子问题1：添加约束 $x_k \leq \lfloor \bar{x}_k \rfloor$
   - 子问题2：添加约束 $x_k \geq \lceil \bar{x}_k \rceil$

4. **剪枝规则**：
   - **不可行剪枝**：松弛问题无可行解
   - **界限剪枝**：松弛最优值 $\leq LB$
   - **整数解剪枝**：松弛最优解为整数解，更新 $LB$ 和 $\mathbf{x}^*$

5. **选择策略**：从未剪枝的节点中选择一个继续分支
6. 重复直到所有节点被剪枝或分支

### 2.2 搜索树示例

```
                    P0 (LP松弛)
                   /            \
            x1 <= 2             x1 >= 3
             /                    \
        P1 (LP)               P2 (LP)
       /      \                  |
  x2 <= 1   x2 >= 2          x2 <= 3
    /          \                /
 P1a(LP)    P1b(LP)         P2a(LP)
  整数解      无可行解      整数解
```

## 三、分支策略

### 3.1 深度优先搜索（DFS）

**策略**：优先向树的深处搜索，即优先处理最新创建的子节点。

**优点**：
- 内存效率高（只需存储当前路径上的节点）
- 能快速找到可行解，尽早建立较好的下界
- 实现简单

**缺点**：可能在非最优区域花费过多时间

### 3.2 广度优先搜索（BFS）

**策略**：优先处理同一层级的所有节点，再向下搜索。

**优点**：
- 能系统地搜索整个解空间
- 同时找到所有好的可行解

**缺点**：需要存储大量节点，内存消耗大

### 3.3 最佳优先搜索（Best-First）

**策略**：在所有未剪枝节点中，选择松弛最优值最大的节点优先处理。

**优点**：
- 理论上能最快逼近最优解
- 剪枝效率最高

**缺点**：需要维护所有未剪枝节点的信息，内存消耗大

### 3.4 混合策略

实际求解器通常采用混合策略：

- 用 DFS 进行初始搜索，快速找到可行解
- 当找到可行解后，切换到 Best-First 或 DFS
- 结合强分支等启发式方法选择变量

## 四、LP 松弛

### 4.1 LP 松弛的作用

LP 松弛是分支定界法的核心组件，它：

1. 为整数规划提供**上界**（最大化问题）或**下界**（最小化问题）
2. 指导分支决策（选择分数变量）
3. 提供对偶信息（如影子价格）用于灵敏度分析

### 4.2 松弛的类型

**（1）LP 松弛**：将整数约束放松为连续约束

$$
x_j \in \mathbb{Z}_+ \to x_j \geq 0
$$

**（2）LP 松弛 + 割平面**：在 LP 松弛基础上添加有效不等式

**（3）Lagrangian 松弛**：将部分约束通过拉格朗日乘子放入目标函数

**（4）半定规划（SDP）松弛**：利用半定规划提供更紧的界

### 4.3 松弛质量

松弛的质量直接影响分支定界法的效率：

- **紧松弛**：松弛最优值接近整数最优值，剪枝效率高
- **松松弛**：松弛最优值远离整数最优值，需要更多分支

提高松弛质量的方法：
- 添加有效不等式（割平面）
- 改进问题建模
- 使用 Lagrangian 松弛

## 五、分支定界法的改进技术

### 5.1 强分支（Strong Branching）

在选择进基变量时，对每个候选变量进行试探性分支，计算分支后的松弛值变化：

$$
\text{score}(j) = \min(\Delta_j^+, \Delta_j^-)
$$

其中 $\Delta_j^+$ 和 $\Delta_j^-$ 分别是 $x_j \geq \lceil \bar{x}_j \rceil$ 和 $x_j \leq \lfloor \bar{x}_j \rfloor$ 分支后目标函数的退化量。

选择 $\text{score}$ 最大的变量分支。

**代价**：需要对每个候选变量求解 LP，计算量大
**适用**：小规模问题，或在根节点使用

### 5.2 伪费用分支（Pseudocost Branching）

利用历史信息估计每个候选变量分支后的效果：

$$
\text{pseudocost}_j^+ = \frac{\text{目标函数退化量}}{\text{变量值与边界之差}}
$$

对每个候选变量，选择伪费用评分最高的分支。

### 5.3 预求解（Presolve）

在分支定界之前，对问题进行简化：

- **约束传播**：推导变量的紧界
- **冗余约束检测**：删除不起作用的约束
- **等式替换**：用等式约束消除变量
- **系数约简**：简化约束矩阵

### 5.4 割平面与分支定界结合（Branch and Cut）

在分支定界过程中动态添加割平面：

1. 求解 LP 松弛
2. 检查松弛解是否为整数
3. 若不是整数，尝试生成割平面
4. 将割平面加入松弛问题
5. 继续迭代

常见的割平面：
- Gomory 混合整数割平面
- 流覆盖割平面
- 分离割平面

## 六、固定费用问题的分支定界

### 6.1 问题描述

$$
\begin{aligned}
\min \quad & z = \sum_{j=1}^{n} (c_j x_j + f_j y_j) \\
\text{s.t.} \quad & A\mathbf{x} \leq \mathbf{b} \\
& x_j \leq M_j y_j, \quad j = 1, \ldots, n \\
& \mathbf{x} \geq \mathbf{0}, \quad y_j \in \{0, 1\}
\end{aligned}
$$

### 6.2 分支定界求解

1. 松弛所有 $y_j$ 为连续变量 $0 \leq y_j \leq 1$
2. 求解 LP 松弛
3. 若某些 $y_j$ 为分数，选择一个进行 0-1 分支
4. 利用互补松弛性和对偶信息加速求解

## 七、Python 代码实现

### 7.1 简易分支定界法

```python
import numpy as np
from scipy.optimize import linprog

class BranchAndBound:
    def __init__(self, c, A_ub, b_ub, A_eq=None, b_eq=None):
        self.c = np.array(c, dtype=float)
        self.A_ub = np.array(A_ub, dtype=float) if A_ub is not None else None
        self.b_ub = np.array(b_ub, dtype=float) if b_ub is not None else None
        self.A_eq = np.array(A_eq, dtype=float) if A_eq is not None else None
        self.b_eq = np.array(b_eq, dtype=float) if b_eq is not None else None
        self.n = len(c)
        self.best_val = float('inf')  # 最小化
        self.best_sol = None
        self.node_count = 0
    
    def solve_lp(self, bounds):
        """求解LP松弛"""
        result = linprog(
            self.c, A_ub=self.A_ub, b_ub=self.b_ub,
            A_eq=self.A_eq, b_eq=self.b_eq,
            bounds=bounds, method='highs'
        )
        return result
    
    def is_integer(self, x, tol=1e-6):
        """检查是否为整数解"""
        return all(abs(x[i] - round(x[i])) < tol for i in range(self.n))
    
    def branch(self, bounds, depth=0):
        """分支定界主过程"""
        self.node_count += 1
        
        # 求解LP松弛
        result = self.solve_lp(bounds)
        
        # 不可行剪枝
        if not result.success:
            return
        
        # 界限剪枝
        if result.fun >= self.best_val:
            return
        
        x = result.x
        
        # 整数解剪枝
        if self.is_integer(x):
            self.best_val = result.fun
            self.best_sol = np.round(x).astype(int)
            return
        
        # 选择分数变量分支
        frac_idx = None
        max_frac = 0
        for i in range(self.n):
            frac = abs(x[i] - round(x[i]))
            if frac > max_frac:
                max_frac = frac
                frac_idx = i
        
        if frac_idx is None:
            return
        
        # 分支
        val = x[frac_idx]
        
        # 子问题1: x[frac_idx] <= floor(val)
        bounds1 = list(bounds)
        bounds1[frac_idx] = (bounds[frac_idx][0], int(np.floor(val)))
        self.branch(bounds1, depth + 1)
        
        # 子问题2: x[frac_idx] >= ceil(val)
        bounds2 = list(bounds)
        bounds2[frac_idx] = (int(np.ceil(val)), bounds[frac_idx][1])
        self.branch(bounds2, depth + 1)
    
    def solve(self):
        bounds = [(0, None)] * self.n
        self.branch(bounds)
        return self.best_sol, self.best_val

# 示例: min z = -3x1 - 2x2 (即 max 3x1 + 2x2)
# s.t. 2x1 + x2 <= 7, x1 + 2x2 <= 8, x1, x2 >= 0, 整数
bb = BranchAndBound(
    c=[-3, -2],
    A_ub=[[2, 1], [1, 2]],
    b_ub=[7, 8]
)
sol, val = bb.solve()
print(f"最优解: {sol}")
print(f"最优值: {-val}")
print(f"访问节点数: {bb.node_count}")
```

### 7.2 使用 pulp 求解

```python
from pulp import *

prob = LpProblem("BnB_Example", LpMaximize)
x1 = LpVariable("x1", 0, cat='Integer')
x2 = LpVariable("x2", 0, cat='Integer')

prob += 3*x1 + 2*x2
prob += 2*x1 + x2 <= 7
prob += x1 + 2*x2 <= 8

prob.solve(PULP_CBC_CMD(msg=0))
print(f"x1={x1.varValue}, x2={x2.varValue}, z={value(prob.objective)}")
```

## 八、关键要点总结

1. **分支定界法**通过分支、定界、剪枝系统搜索整数规划的解空间
2. **LP松弛**为分支定界提供界的信息，是算法的核心
3. 分支策略（DFS、BFS、Best-First）影响搜索效率
4. 变量选择策略（强分支、伪费用分支）影响分支质量
5. **分支切割法**将割平面与分支定界结合，是现代求解器的核心技术
6. 预求解和约束传播可以显著加速求解
7. 分支定界法是**精确算法**，保证找到全局最优解
8. 实际求解中使用商业求解器（CPLEX、Gurobi）能处理大规模问题
