# 模拟退火详解

## 一、概述

模拟退火算法（Simulated Annealing, SA）是由 Kirkpatrick 等人于 1983 年提出的一种基于蒙特卡洛迭代的随机优化算法。其灵感来源于固体退火过程：将固体加热至高温，然后缓慢冷却，使原子达到能量最低的晶体状态。

SA 算法的核心思想是以一定概率接受劣解，从而跳出局部最优，最终以概率 1 收敛到全局最优解。

## 二、物理学基础

### 2.1 固体退火过程

固体退火的物理过程为：

1. **加热**：将固体加热到高温 $T_0$，使原子获得足够能量，脱离平衡位置
2. **等温过程**：在恒定温度下，系统达到热平衡
3. **冷却**：缓慢降低温度，原子逐渐回到能量较低的位置
4. **结晶**：当温度降至室温时，固体形成稳定的晶体结构（能量最低状态）

### 2.2 Metropolis 准则

在温度 $T$ 下，系统从能量状态 $E_i$ 转移到能量状态 $E_j$ 的概率为：

$$P(\Delta E) = \begin{cases} 1 & \text{if } \Delta E \leq 0 \\ \exp\left(-\frac{\Delta E}{k_B T}\right) & \text{if } \Delta E > 0 \end{cases}$$

其中 $\Delta E = E_j - E_i$，$k_B$ 为玻尔兹曼常数（在算法中通常设为 1）。

### 2.3 玻尔兹曼分布

在热平衡状态下，系统处于能量状态 $E$ 的概率遵循玻尔兹曼分布：

$$P(E) \propto \exp\left(-\frac{E}{k_B T}\right)$$

温度越高，系统越可能处于高能量状态；温度越低，系统越倾向于低能量状态。

## 三、算法原理

### 3.1 问题映射

| 物理退火 | 模拟退火 |
|---------|---------|
| 固体状态 | 解空间中的解 |
| 能量函数 | 目标函数（代价函数） |
| 温度 | 控制参数 |
| 冷却过程 | 迭代过程 |
| 最低能量状态 | 全局最优解 |

### 3.2 接受准则

SA 算法采用 Metropolis 接受准则：

$$P(\text{accept}) = \begin{cases} 1 & \text{if } \Delta f \leq 0 \\ \exp\left(-\frac{\Delta f}{T}\right) & \text{if } \Delta f > 0 \end{cases}$$

其中 $\Delta f = f(\mathbf{x}_{\text{new}}) - f(\mathbf{x}_{\text{old}})$ 为目标函数值的变化量（假设最小化问题），$T$ 为当前温度。

### 3.3 温度的作用

温度 $T$ 控制着算法接受劣解的概率：

- **高温阶段**（$T$ 较大）：$\exp(-\Delta f / T) \approx 1$，几乎接受所有解，算法进行全局探索
- **低温阶段**（$T$ 较小）：$\exp(-\Delta f / T) \approx 0$，只接受改善解，算法进行局部开发
- **温度递减**：从全局探索逐步过渡到局部开发

## 四、邻域结构

邻域结构定义了从当前解如何生成新解，是 SA 算法的关键组件。

### 4.1 连续优化问题

**高斯扰动**：
$$\mathbf{x}_{\text{new}} = \mathbf{x}_{\text{old}} + \boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})$$

**柯西扰动**：
$$\mathbf{x}_{\text{new}} = \mathbf{x}_{\text{old}} + \boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim \text{Cauchy}(0, \sigma)$$

柯西扰动比高斯扰动具有更重的尾部，更容易产生大幅度跳跃，有助于跳出局部最优。

**均匀扰动**：
$$\mathbf{x}_{\text{new}} = \mathbf{x}_{\text{old}} + \boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim U(-\Delta, \Delta)$$

### 4.2 组合优化问题（以 TSP 为例）

**交换邻域（Swap）**：随机交换两个城市的位置

$$\pi' = \text{swap}(\pi, i, j)$$

**反转邻域（Reverse）**：反转一段子路径

$$\pi' = \text{reverse}(\pi, i, j)$$

**插入邻域（Insert）**：将城市 $i$ 插入到位置 $j$

$$\pi' = \text{insert}(\pi, i, j)$$

**2-opt 邻域**：反转任意两个城市之间的路径段

### 4.3 自适应邻域

邻域半径可随温度自适应调整：

$$\sigma(T) = \sigma_0 \cdot \frac{T}{T_0}$$

高温时使用大邻域进行广域搜索，低温时使用小邻域进行精细搜索。

## 五、冷却进度表

冷却进度表（Cooling Schedule）控制温度下降的策略，直接影响算法的性能和收敛性。

### 5.1 常用冷却策略

**指数冷却**：
$$T_{k+1} = \alpha \cdot T_k, \quad \alpha \in [0.95, 0.99]$$

这是最常用的冷却策略，$\alpha$ 通常取 0.95-0.99。

**线性冷却**：
$$T_{k+1} = T_k - \Delta T$$

其中 $\Delta T$ 为固定的温度下降量。

**对数冷却**：
$$T_k = \frac{T_0}{\ln(1 + k)}$$

**反比冷却**：
$$T_k = \frac{T_0}{1 + \beta k}$$

其中 $\beta$ 为冷却系数。

### 5.2 冷却速度的影响

| 冷却速度 | 探索能力 | 收敛速度 | 解质量 |
|---------|---------|---------|--------|
| 快速冷却 | 弱 | 快 | 差（易陷入局部最优） |
| 缓慢冷却 | 强 | 慢 | 好（更接近全局最优） |
| 适中冷却 | 中 | 中 | 中等 |

### 5.3 温度更新方式

**固定步长更新**：每经过 $L$ 次迭代更新一次温度

**自适应更新**：根据当前搜索状态调整冷却速度

**回火重加热**：当搜索陷入停滞时，适当提高温度

## 六、算法流程

```
算法：模拟退火（SA）
输入：目标函数 f(x)，初始解 x_0，初始温度 T_0
输出：最优解 x*

1. 初始化：x = x_0, x_best = x_0, T = T_0
2. while 未满足停止准则 do
3.     for l = 1 to L(T) do    // L(T) 为每个温度的迭代次数
4.         生成邻域解 x' = Neighbor(x)
5.         计算目标函数值变化 Δf = f(x') - f(x)
6.         if Δf ≤ 0 then
7.             x = x'           // 接受改善解
8.         else
9.             生成随机数 r ~ U(0,1)
10.            if r < exp(-Δf / T) then
11.                x = x'       // 以概率接受劣解
12.        end if
13.        if f(x) < f(x_best) then
14.            x_best = x       // 更新全局最优
15.    end for
16.    T = CoolingSchedule(T)  // 降低温度
17. end while
18. return x_best
```

## 七、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from typing import Callable, List, Tuple

class SimulatedAnnealing:
    def __init__(self,
                 obj_func: Callable,
                 bounds: List[Tuple[float, float]],
                 T0: float = 100.0,
                 T_min: float = 1e-8,
                 alpha: float = 0.95,
                 L: int = 100,
                 sigma: float = 1.0):
        self.obj_func = obj_func
        self.bounds = np.array(bounds)
        self.T0 = T0
        self.T_min = T_min
        self.alpha = alpha
        self.L = L
        self.sigma = sigma
        self.dim = len(bounds)
        self.lb = self.bounds[:, 0]
        self.ub = self.bounds[:, 1]
        self.history = []
        
    def initialize(self) -> np.ndarray:
        return np.random.uniform(self.lb, self.ub, self.dim)
    
    def neighbor(self, x: np.ndarray, T: float) -> np.ndarray:
        scale = self.sigma * (T / self.T0)
        x_new = x + np.random.normal(0, scale, self.dim)
        x_new = np.clip(x_new, self.lb, self.ub)
        return x_new
    
    def acceptance_probability(self, delta_f: float, T: float) -> float:
        if delta_f <= 0:
            return 1.0
        return np.exp(-delta_f / T)
    
    def optimize(self) -> Tuple[np.ndarray, float]:
        x_current = self.initialize()
        f_current = self.obj_func(x_current)
        x_best = x_current.copy()
        f_best = f_current
        
        T = self.T0
        
        while T > self.T_min:
            for _ in range(self.L):
                x_new = self.neighbor(x_current, T)
                f_new = self.obj_func(x_new)
                delta_f = f_new - f_current
                
                if self.acceptance_probability(delta_f, T) > np.random.random():
                    x_current = x_new
                    f_current = f_new
                    
                    if f_current < f_best:
                        x_best = x_current.copy()
                        f_best = f_current
                        
            self.history.append(f_best)
            T *= self.alpha
            
        return x_best, f_best


def ackley(x):
    n = len(x)
    sum1 = sum(xi**2 for xi in x)
    sum2 = sum(np.cos(2 * np.pi * xi) for xi in x)
    return (-20 * np.exp(-0.2 * np.sqrt(sum1 / n)) 
            - np.exp(sum2 / n) + 20 + np.e)


if __name__ == "__main__":
    bounds = [(-5, 5)] * 3
    sa = SimulatedAnnealing(ackley, bounds, T0=100, T_min=1e-8, alpha=0.95, L=200)
    best_sol, best_val = sa.optimize()
    
    print(f"最优解: {best_sol}")
    print(f"最优值: {best_val}")
    
    plt.figure(figsize=(10, 6))
    plt.plot(sa.history)
    plt.xlabel('冷却阶段')
    plt.ylabel('最优值')
    plt.title('模拟退火收敛曲线')
    plt.grid(True)
    plt.show()
```

## 八、收敛性分析

### 8.1 马尔可夫链模型

SA 算法可以建模为一个非时齐（inhomogeneous）马尔可夫链。在每个温度下，系统在解空间中进行一系列状态转移。

设 $P_k(i, j)$ 为在温度 $T_k$ 下从状态 $i$ 转移到状态 $j$ 的概率：

$$P_k(i, j) = \begin{cases} G_k(i, j) \cdot A_k(i, j) & \text{if } j \neq i \\ 1 - \sum_{j \neq i} G_k(i, j) \cdot A_k(i, j) & \text{if } j = i \end{cases}$$

其中 $G_k(i, j)$ 为生成概率，$A_k(i, j)$ 为接受概率。

### 8.2 全局收敛性定理

**定理**：如果满足以下条件：
1. 解空间有限
2. 冷却进度满足 $\sum_{k=1}^{\infty} T_k = \infty$ 且 $\lim_{k \to \infty} T_k = 0$
3. 每个温度下进行足够多次迭代

则 SA 算法以概率 1 收敛到全局最优解。

**证明思路**：利用马尔可夫链的遍历性（Ergodicity），当温度趋近于 0 时，系统处于最优状态的概率趋近于 1。

### 8.3 理论最优冷却

理论最优的冷却进度为：

$$T_k = \frac{T_0}{\ln(1 + k)}$$

但该冷却速度过慢，实际中通常采用指数冷却 $T_k = \alpha^k T_0$。

## 九、改进策略

### 9.1 重加热策略

当搜索陷入停滞时，适当提高温度以跳出局部最优：

$$T_{\text{new}} = \beta \cdot T_{\text{current}}, \quad \beta > 1$$

触发条件可以是：连续多次迭代未改善、或适应度方差小于阈值。

### 9.2 并行模拟退火

维护多个独立的 SA 进程，定期交换信息：

$$\mathbf{x}_i^{\text{new}} = \begin{cases} \mathbf{x}_i & \text{with prob } 1-p_{\text{exchange}} \\ \mathbf{x}_j^* & \text{with prob } p_{\text{exchange}} \end{cases}$$

### 9.3 自适应温度调节

根据接受率自适应调整温度：

$$T_{k+1} = \begin{cases} \alpha_+ \cdot T_k & \text{if accept\_rate} < r_{\min} \\ \alpha_- \cdot T_k & \text{if accept\_rate} > r_{\max} \\ T_k & \text{otherwise} \end{cases}$$

### 9.4 快速模拟退火（FSA）

使用 Cauchy 分布代替高斯分布生成邻域解：

$$\mathbf{x}_{\text{new}} = \mathbf{x}_{\text{old}} + \frac{T \cdot \Delta \mathbf{x}}{1 + T}$$

其中 $\Delta \mathbf{x}$ 从 Cauchy 分布中采样。

## 十、与其他算法的比较

| 特性 | SA | GA | PSO |

## 十一、关键要点总结

1. **温度是核心**：温度 $T$ 控制着探索与开发的平衡
2. **接受劣解**：这是 SA 跳出局部最优的关键机制
3. **冷却速度**：过快则陷入局部最优，过慢则效率低下
4. **邻域设计**：好的邻域结构能显著提升算法性能
5. **充分迭代**：每个温度下需要足够的迭代次数以达到近似热平衡
6. **初始温度**：$T_0$ 应足够大，使初始接受率接近 1
7. **终止温度**：$T_{\min}$ 应足够小，使算法充分收敛
8. **重启策略**：多次重启可提高找到全局最优的概率
9. **与其他方法结合**：SA 常与局部搜索、遗传算法等结合使用
10. **理论保证**：在适当条件下，SA 具有全局收敛性
