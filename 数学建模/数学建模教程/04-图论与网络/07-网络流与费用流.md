# 网络流与费用流

> **理论基础** → 参见 [[../../图论算法/网络流算法|网络流理论]]

网络流理论研究在网络中流动的资源分配，最小费用最大流问题将流量优化与费用优化结合。

## 3. 连续最短增广路算法
### 3.1 算法思想

**连续最短增广路算法（Successive Shortest Path Algorithm）** 是求解最小费用流的经典算法。其核心思想：每次在残余网络中寻找**费用最小**的增广路径，增加尽可能多的流量。

### 3.2 残余网络

对于流 $f$，残余网络 $G_f$ 中每条边 $(u,v)$ 的费用为：

$$a_f(u,v) = \begin{cases} a(u,v), & \text{若 } f(u,v) < c(u,v) \\ -a(v,u), & \text{若 } f(u,v) > 0 \end{cases}$$

### 3.3 伪代码

```
算法: Successive-Shortest-Path(G, c, a, s, t, d)
输入: 流网络 G, 容量 c, 费用 a, 源点 s, 汇点 t, 需求量 d
输出: 最小费用最大流 f

1:  f = 0
2:  while |f| < d:
3:      在 G_f 中找从 s 到 t 的最短（费用最小）路径 P
4:      if P 不存在:
5:          return "不可行"
6:      Δ = min(d - |f|, min_{(u,v)∈P} c_f(u,v))
7:      沿 P 增广 Δ 的流量
8:  return f
```

### 3.4 最短路径的计算

在残余网络中，边的费用可能为负（反向边）。因此不能直接使用 Dijkstra 算法。

解决方法：
1. **Bellman-Ford**：$O(|V| \cdot |E|)$，支持负权边。
2. **势函数 + Dijkstra**：引入势函数 $h(v)$，使所有边的费用非负，然后使用 Dijkstra。

### 3.5 势函数方法

定义顶点势函数 $h(v)$，对每条边 $(u,v)$ 定义修改费用：

$$a'(u,v) = a(u,v) + h(u) - h(v)$$

**性质**：若 $h$ 满足 $a'(u,v) \geq 0$ 对所有 $(u,v) \in E_f$ 成立，则可以在修改费用上使用 Dijkstra。

**势函数更新**：$h(v) = h(v) + d(v)$，其中 $d(v)$ 是 Dijkstra 计算出的最短距离。

### 3.6 时间复杂度

$$O(d \cdot |V| \cdot |E|)$$

其中 $d$ 是需求量。

### 3.7 Python 实现

```python
import heapq
from collections import defaultdict

class MinCostFlow:
    def __init__(self, n):
        self.n = n
        self.graph = defaultdict(list)
    
    def add_edge(self, u, v, cap, cost):
        """添加边（正向和反向）"""
        self.graph[u].append([v, cap, cost, len(self.graph[v])])
        self.graph[v].append([u, 0, -cost, len(self.graph[u]) - 1])
    
    def min_cost_flow(self, s, t, max_flow):
        """
        连续最短增广路算法
        返回: (最小费用, 实际流量)
        """
        n = self.n
        prevv = [0] * n
        preve = [0] * n
        INF = float('inf')
        res = 0
        h = [0] * n  # 势函数
        flow = 0
        
        while flow < max_flow:
            # Dijkstra 找最短路径
            dist = [INF] * n
            dist[s] = 0
            pq = [(0, s)]
            
            while pq:
                d, v = heapq.heappop(pq)
                if dist[v] < d:
                    continue
                for i, (to, cap, cost, _) in enumerate(self.graph[v]):
                    if cap > 0 and dist[to] > dist[v] + cost + h[v] - h[to]:
                        dist[to] = dist[v] + cost + h[v] - h[to]
                        prevv[to] = v
                        preve[to] = i
                        heapq.heappush(pq, (dist[to], to))
            
            if dist[t] == INF:
                break  # 无法继续增广
            
            for v in range(n):
                h[v] += dist[v]
            
            # 计算增广量
            d = max_flow - flow
            v = t
            while v != s:
                d = min(d, self.graph[prevv[v]][preve[v]][1])
                v = prevv[v]
            
            flow += d
            res += d * h[t]
            
            # 更新残余网络
            v = t
            while v != s:
                e = self.graph[prevv[v]][preve[v]]
                e[1] -= d
                self.graph[v][e[3]][1] += d
                v = prevv[v]
        
        return res, flow

# 使用示例
mcf = MinCostFlow(4)
# 节点: s=0, a=1, b=2, t=3
mcf.add_edge(0, 1, 10, 2)  # s -> a, 容量 10, 费用 2
mcf.add_edge(0, 2, 8, 3)   # s -> b, 容量 8, 费用 3
mcf.add_edge(1, 2, 5, 1)   # a -> b, 容量 5, 费用 1
mcf.add_edge(1, 3, 7, 4)   # a -> t, 容量 7, 费用 4
mcf.add_edge(2, 3, 10, 2)  # b -> t, 容量 10, 费用 2

cost, flow = mcf.min_cost_flow(0, 3, 15)
print(f"最小费用: {cost}")
print(f"实际流量: {flow}")
```

## 4. 最小费用最大流
### 4.1 问题定义

**最小费用最大流（Minimum Cost Maximum Flow）** 是在所有最大流中费用最小的流。

### 4.2 与最小费用流的关系

当需求量 $d = \text{最大流的值}$ 时，最小费用流问题退化为最小费用最大流问题。

### 4.3 Python 实现

```python
def min_cost_max_flow(G, source, sink):
    """
    最小费用最大流
    G: networkx 有向图，边有 'capacity' 和 'cost' 属性
    返回: (最大流值, 最小费用)
    """
    mcf = MinCostFlow(len(G.nodes()))
    node_index = {node: i for i, node in enumerate(G.nodes())}
    
    for u, v, data in G.edges(data=True):
        mcf.add_edge(
            node_index[u], node_index[v],
            data.get('capacity', float('inf')),
            data.get('cost', 0)
        )
    
    s = node_index[source]
    t = node_index[sink]
    
    # 先计算最大流值
    # 使用简单的 BFS 或最大流算法
    max_flow = compute_max_flow(G, source, sink)
    
    cost, flow = mcf.min_cost_flow(s, t, max_flow)
    return flow, cost

def compute_max_flow(G, source, sink):
    """简单的最大流计算（用于确定需求量）"""
    from collections import deque
    
    flow = 0
    while True:
        parent = {source: None}
        queue = deque([source])
        found = False
        
        while queue:
            u = queue.popleft()
            for v in G.neighbors(u):
                cap = G[u][v].get('capacity', float('inf'))
                if v not in parent and cap > 0:
                    parent[v] = u
                    if v == sink:
                        found = True
                        break
                    queue.append(v)
        
        if not found:
            break
        
        path_flow = float('inf')
        v = sink
        while v != source:
            u = parent[v]
            path_flow = min(path_flow, G[u][v].get('capacity', float('inf')))
            v = u
        
        flow += path_flow
        v = sink
        while v != source:
            u = parent[v]
            G[u][v]['capacity'] -= path_flow
            v = u
    
    return flow
```

## 8. 实际应用
### 8.1 交通运输

最小费用流模型可以用于：
- 公交线路规划
- 货物运输调度
- 航班调度

### 8.2 电力系统

电力网络中的经济调度问题可以建模为最小费用流问题。

### 8.3 通信网络

通信网络中的路由优化可以使用最小费用流模型。

### 8.4 供应链管理

供应链中的库存管理、运输规划等可以使用网络流模型。

## 10. 关键点总结
| 要点 | 说明 |
|------|------|
| 最小费用流 | 在满足流量需求下最小化总费用 |
| 费用守恒 | 费用与流量的乘积 |
| 连续最短路 | 每次找费用最小的增广路径 |
| 势函数 | 将负权边转化为非负，支持 Dijkstra |
| 对偶理论 | 费用流与节点势的关系 |
| 网络单纯形 | 实践中最快的费用流算法 |
| 应用 | 交通、电力、通信、供应链 |
