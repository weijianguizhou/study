# 人口模型

> **理论基础** → 参见 [[../../微分方程建模/人口与生态模型|人口模型]]

人口模型通过微分方程描述种群数量随时间的变化规律，Malthus模型和Logistic模型是两大经典框架。

## 二、Malthus 人口模型
### 2.1 模型假设

- 在封闭环境下，不考虑迁入迁出
- 人口增长率恒定，即单位时间内人口增长比例不变
- 不存在资源限制

### 2.2 模型建立

设 $N(t)$ 为 $t$ 时刻的人口数量，$r$ 为内禀增长率（出生率减去死亡率），则：

$$\frac{dN}{dt} = rN$$

### 2.3 模型求解

分离变量法：

$$\frac{dN}{N} = r\,dt$$

$$\int \frac{dN}{N} = \int r\,dt$$

$$\ln N = rt + C$$

$$N(t) = N_0 e^{rt}$$

其中 $N_0 = N(0)$ 为初始人口数量。

### 2.4 模型分析

**特点：**
- 指数增长，人口呈爆炸式增长
- 增长率 $\frac{dN}{dt}$ 与当前人口 $N$ 成正比
- 适用于短时间尺度、资源充裕的情况

**局限性：**
- 未考虑资源、环境承载力的限制
- 长期预测严重偏离实际

### 2.5 数值示例

```python
import numpy as np
import matplotlib.pyplot as plt

# Malthus 模型
r = 0.02       # 内禀增长率
N0 = 10000     # 初始人口
t = np.linspace(0, 100, 500)

N_malthus = N0 * np.exp(r * t)

plt.figure(figsize=(10, 6))
plt.plot(t, N_malthus, 'b-', linewidth=2, label='Malthus 模型')
plt.xlabel('时间 (年)')
plt.ylabel('人口数量')
plt.title('Malthus 人口增长模型')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 三、Logistic 增长模型
### 3.1 模型假设

- 存在环境最大承载量 $K$
- 当 $N < K$ 时，人口增长
- 当 $N > K$ 时，人口减少
- 增长率随人口密度增加而递减

### 3.2 模型建立

$$\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right)$$

其中：
- $r$ 为内禀增长率
- $K$ 为环境承载力（容纳量）
- $\left(1 - \frac{N}{K}\right)$ 为密度制约因子

### 3.3 模型求解

令 $f(N) = rN\left(1 - \frac{N}{K}\right)$，使用分离变量法：

$$\frac{dN}{N\left(1 - \frac{N}{K}\right)} = r\,dt$$

利用部分分式分解：

$$\frac{1}{N\left(1 - \frac{N}{K}\right)} = \frac{1}{N} + \frac{1/K}{1 - N/K}$$

积分得：

$$N(t) = \frac{K}{1 + \left(\frac{K - N_0}{N_0}\right) e^{-rt}}$$

### 3.4 模型分析

**平衡点：** 令 $\frac{dN}{dt} = 0$，得 $N^* = 0$ 或 $N^* = K$

**稳定性分析：**

$$f'(N) = r\left(1 - \frac{2N}{K}\right)$$

- $f'(0) = r > 0$：$N^* = 0$ 不稳定
- $f'(K) = -r < 0$：$N^* = K$ 渐近稳定

**拐点：** 令 $\frac{d^2N}{dt^2} = 0$，得 $N = \frac{K}{2}$

**S 型曲线特征：**
- 当 $N < \frac{K}{2}$ 时，加速增长（$\frac{d^2N}{dt^2} > 0$）
- 当 $N > \frac{K}{2}$ 时，减速增长（$\frac{d^2N}{dt^2} < 0$）
- 当 $N = \frac{K}{2}$ 时，增长速度最大

### 3.5 数值示例

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint

# Logistic 模型
r = 0.05
K = 100000
N0 = 1000

def logistic(N, t):
    return r * N * (1 - N / K)

t = np.linspace(0, 200, 500)
N_logistic = odeint(logistic, N0, t)

plt.figure(figsize=(10, 6))
plt.plot(t, N_logistic, 'r-', linewidth=2, label=f'Logistic 模型 (K={K})')
plt.axhline(y=K, color='k', linestyle='--', alpha=0.5, label='承载力 K')
plt.axhline(y=K/2, color='g', linestyle=':', alpha=0.5, label='拐点 K/2')
plt.xlabel('时间 (年)')
plt.ylabel('人口数量')
plt.title('Logistic 人口增长模型')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 五、年龄结构人口模型
### 5.1 McKendrick 偏微分方程模型

设 $p(a,t)$ 为时刻 $t$ 年龄为 $a$ 的人口密度函数，则：

$$\frac{\partial p}{\partial t} + \frac{\partial p}{\partial a} = -\mu(a)\,p$$

边界条件（出生率）：

$$p(0,t) = \int_0^{\infty} \beta(a)\,p(a,t)\,da$$

初始条件：

$$p(a,0) = p_0(a)$$

其中 $\mu(a)$ 为年龄别死亡率，$\beta(a)$ 为年龄别生育率。

### 5.2 Leslie 矩阵离散模型

将年龄离散化为 $n$ 个年龄段，设 $\mathbf{N}_t = [N_1(t), N_2(t), \ldots, N_n(t)]^T$，则：

$$\mathbf{N}_{t+1} = \mathbf{L}\,\mathbf{N}_t$$

Leslie 矩阵为：

$$\mathbf{L} = \begin{pmatrix} f_1 & f_2 & \cdots & f_{n-1} & f_n \\ s_1 & 0 & \cdots & 0 & 0 \\ 0 & s_2 & \cdots & 0 & 0 \\ \vdots & & \ddots & & \vdots \\ 0 & 0 & \cdots & s_{n-1} & 0 \end{pmatrix}$$

其中 $f_i$ 为第 $i$ 年龄组的生育率，$s_i$ 为第 $i$ 年龄组的存活率。

**主要结论：** Leslie 矩阵的主特征值 $\lambda_1$ 决定长期增长趋势：
- $\lambda_1 > 1$：人口增长
- $\lambda_1 = 1$：人口稳定
- $\lambda_1 < 1$：人口减少

### 5.3 数值示例

```python
import numpy as np

# Leslie 矩阵模型
L = np.array([
    [0.0, 1.2, 0.8, 0.3],   # 生育率
    [0.9, 0.0, 0.0, 0.0],   # 存活率
    [0.0, 0.85, 0.0, 0.0],
    [0.0, 0.0, 0.8, 0.0]
])

N0 = np.array([100, 80, 60, 40])  # 初始各年龄段人口
years = 50

population = np.zeros((years + 1, 4))
population[0] = N0

for t in range(years):
    population[t + 1] = L @ population[t]

total_pop = population.sum(axis=1)

# 主特征值分析
eigenvalues = np.linalg.eigvals(L)
lambda1 = np.max(np.abs(eigenvalues))
print(f"主特征值 λ₁ = {lambda1:.4f}")

import matplotlib.pyplot as plt
plt.figure(figsize=(10, 6))
for i in range(4):
    plt.plot(range(years + 1), population[:, i], label=f'年龄组 {i+1}')
plt.plot(range(years + 1), total_pop, 'k--', linewidth=2, label='总人口')
plt.xlabel('时间 (年)')
plt.ylabel('人口数量')
plt.title('Leslie 年龄结构人口模型')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 八、实际应用案例
### 8.1 中国人口预测

| 年份 | 实际人口（亿） | Malthus 预测 | Logistic 预测 |
|------|---------------|-------------|--------------|
| 1950 | 5.5 | 5.5 | 5.5 |
| 1980 | 9.9 | 12.1 | 10.2 |
| 2000 | 12.7 | 26.8 | 12.5 |
| 2020 | 14.1 | 58.3 | 13.8 |

### 8.2 参数估计方法

**最小二乘法：** 设观测数据为 $(t_i, N_i)$，求解：

$$\min_{r, K} \sum_{i=1}^{n} \left[N_i - \frac{K}{1 + \left(\frac{K-N_0}{N_0}\right)e^{-r t_i}}\right]^2$$

**非线性回归：** 使用 Levenberg-Marquardt 算法进行参数拟合。

```python
from scipy.optimize import curve_fit

def logistic_func(t, N0, r, K):
    return K / (1 + ((K - N0) / N0) * np.exp(-r * t))

# 模拟数据
t_data = np.array([1950, 1960, 1970, 1980, 1990, 2000, 2010, 2020])
N_data = np.array([5.5, 6.6, 8.3, 9.9, 11.4, 12.7, 13.4, 14.1]) * 1e8

popt, pcov = curve_fit(logistic_func, t_data - 1950, N_data, p0=[5.5e8, 0.02, 16e8])
N0_fit, r_fit, K_fit = popt

print(f"拟合参数: N₀ = {N0_fit/1e8:.2f}亿, r = {r_fit:.4f}, K = {K_fit/1e8:.2f}亿")

t_pred = np.linspace(0, 120, 500)
N_pred = logistic_func(t_pred, N0_fit, r_fit, K_fit)

plt.figure(figsize=(10, 6))
plt.scatter(t_data, N_data / 1e8, color='red', s=50, zorder=5, label='实际数据')
plt.plot(t_pred + 1950, N_pred / 1e8, 'b-', linewidth=2, label='Logistic 拟合')
plt.axhline(y=K_fit / 1e8, color='k', linestyle='--', alpha=0.5)
plt.xlabel('年份')
plt.ylabel('人口 (亿)')
plt.title('中国人口 Logistic 模型拟合')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 九、关键要点总结
1. **Malthus 模型**：$N(t) = N_0 e^{rt}$，指数增长，适用于短期预测
2. **Logistic 模型**：$N(t) = \frac{K}{1 + Ce^{-rt}}$，S 型增长，考虑资源限制
3. **年龄结构模型**：用偏微分方程或 Leslie 矩阵描述不同年龄段的人口动态
4. **平衡点稳定性**：Malthus 模型 $N^*=0$ 不稳定；Logistic 模型 $N^*=K$ 渐近稳定
5. **拐点**：Logistic 模型在 $N = K/2$ 处增长最快
6. **参数估计**：可用最小二乘法或非线性回归拟合模型参数
7. **模型选择**：短期用 Malthus，长期用 Logistic；需要精细分析时用年龄结构模型
