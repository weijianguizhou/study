# 非线性方程求根

> **理论基础** → 参见 [[../../数值分析/非线性方程求根|求根理论]]

求根方法通过迭代策略寻找非线性方程的根，二分法、Newton法各有收敛特性和适用范围。

## 2. 二分法
### 2.1 基本思想

利用介值定理，通过不断缩小区间来逼近根。

### 2.2 算法步骤

**输入**：函数 $f$，区间 $[a, b]$，精度要求 $\epsilon$
**输出**：根的近似值 $x^*$

1. 检查 $f(a) \cdot f(b) < 0$
2. 当 $b - a > \epsilon$ 时：
   - $c = \frac{a + b}{2}$（中点）
   - 如果 $f(c) = 0$，返回 $c$
   - 如果 $f(a) \cdot f(c) < 0$，则 $b = c$
   - 否则 $a = c$
3. 返回 $\frac{a + b}{2}$

### 2.3 收敛性分析

**收敛速度**：线性收敛

**误差估计**：

$$|x_n - x^*| \leq \frac{b - a}{2^{n+1}}$$

**迭代次数**：

$$n \geq \log_2 \frac{b - a}{\epsilon} - 1$$

### 2.4 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def bisection_method(f, a, b, tol=1e-10, max_iter=100):
    """
    二分法
    
    参数:
        f: 函数
        a, b: 区间端点
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        root: 根的近似值
        iterations: 迭代次数
        history: 迭代历史
    """
    if f(a) * f(b) >= 0:
        raise ValueError("f(a) 和 f(b) 必须异号")
    
    history = [(a, b)]
    
    for k in range(max_iter):
        c = (a + b) / 2
        
        if abs(f(c)) < tol or (b - a) / 2 < tol:
            return c, k + 1, history
        
        if f(a) * f(c) < 0:
            b = c
        else:
            a = c
        
        history.append((a, b))
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return (a + b) / 2, max_iter, history

# 示例：求解 x² - 2 = 0
f = lambda x: x**2 - 2
a, b = 1.0, 2.0

root, iterations, history = bisection_method(f, a, b)
print(f"二分法结果: x = {root:.10f}")
print(f"迭代次数: {iterations}")
print(f"精确值: {np.sqrt(2):.10f}")
print(f"误差: {abs(root - np.sqrt(2)):.2e}")
```

## 3. 不动点迭代法
### 3.1 基本思想

将方程 $f(x) = 0$ 改写为等价形式：

$$x = g(x)$$

构造迭代格式：

$$x_{n+1} = g(x_n), \quad n = 0, 1, 2, \ldots$$

### 3.2 收敛条件

**定理**：如果 $g(x)$ 在 $[a, b]$ 上满足：
1. $g(x) \in [a, b]$，$\forall x \in [a, b]$
2. $|g'(x)| \leq L < 1$，$\forall x \in [a, b]$

则迭代收敛，且有误差估计：

$$|x_n - x^*| \leq \frac{L^n}{1 - L} |x_1 - x_0|$$

### 3.3 收敛速度

**线性收敛**：误差满足 $|e_{n+1}| \leq L|e_n|$

**超线性收敛**：$\lim_{n \to \infty} \frac{|e_{n+1}|}{|e_n|} = 0$

**二次收敛**：$|e_{n+1}| \leq C|e_n|^2$

### 3.4 Python 实现

```python
import numpy as np

def fixed_point_iteration(g, x0, tol=1e-10, max_iter=100):
    """
    不动点迭代法
    
    参数:
        g: 迭代函数
        x0: 初始值
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 根的近似值
        iterations: 迭代次数
    """
    x = x0
    
    for k in range(max_iter):
        x_new = g(x)
        
        if abs(x_new - x) < tol:
            return x_new, k + 1
        
        x = x_new
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return x, max_iter

# 示例：求解 x = cos(x)
g = lambda x: np.cos(x)
x0 = 0.5

root, iterations = fixed_point_iteration(g, x0)
print(f"不动点迭代结果: x = {root:.10f}")
print(f"迭代次数: {iterations}")
```

## 4. Newton 法（切线法）
### 4.1 基本思想

利用 Taylor 展开，在当前近似点处用切线逼近根。

### 4.2 迭代公式

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

### 4.3 几何意义

在点 $(x_n, f(x_n))$ 处作切线，切线与 $x$ 轴的交点为 $x_{n+1}$。

### 4.4 收敛性分析

**定理**：如果 $f(x)$ 在 $x^*$ 附近二阶连续可导，且 $f'(x^*) \neq 0$，则 Newton 法在 $x^*$ 附近二次收敛。

**误差公式**：

$$e_{n+1} = \frac{f''(\xi_n)}{2f'(x_n)} e_n^2$$

### 4.5 重根的情况

如果 $x^*$ 是 $m$ 重根，则 Newton 法变为线性收敛。

**改进的 Newton 法**：

$$x_{n+1} = x_n - m \frac{f(x_n)}{f'(x_n)}$$

### 4.6 算法步骤

**输入**：函数 $f$，导数 $f'$，初始值 $x_0$，精度要求 $\epsilon$，最大迭代次数 $N$
**输出**：根的近似值 $x^*$

1. 初始化 $x = x_0$
2. 对于 $k = 0, 1, \ldots, N-1$：
   - 如果 $|f'(x)| < \epsilon$，输出"导数接近零"
   - $x_{\text{new}} = x - \frac{f(x)}{f'(x)}$
   - 如果 $|x_{\text{new}} - x| < \epsilon$，返回 $x_{\text{new}}$
   - $x = x_{\text{new}}$
3. 输出"达到最大迭代次数"

### 4.7 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def newton_method(f, df, x0, tol=1e-10, max_iter=100):
    """
    Newton 法
    
    参数:
        f: 函数
        df: 导数
        x0: 初始值
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 根的近似值
        iterations: 迭代次数
        history: 迭代历史
    """
    x = x0
    history = [x]
    
    for k in range(max_iter):
        if abs(df(x)) < 1e-15:
            print("警告：导数接近零")
            return x, k, history
        
        x_new = x - f(x) / df(x)
        history.append(x_new)
        
        if abs(x_new - x) < tol:
            return x_new, k + 1, history
        
        x = x_new
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return x, max_iter, history

# 示例：求解 x³ - x - 1 = 0
f = lambda x: x**3 - x - 1
df = lambda x: 3*x**2 - 1
x0 = 1.5

root, iterations, history = newton_method(f, df, x0)
print(f"Newton 法结果: x = {root:.10f}")
print(f"迭代次数: {iterations}")

# 绘制收敛过程
plt.figure(figsize=(10, 6))
x_plot = np.linspace(0, 2, 100)
plt.plot(x_plot, f(x_plot), 'b-', label='f(x) = x³ - x - 1')
plt.axhline(y=0, color='k', linewidth=0.5)

for i, x in enumerate(history):
    plt.plot(x, f(x), 'ro', markersize=5)
    if i < len(history) - 1:
        plt.plot([x, x], [f(x), 0], 'g--', linewidth=0.5)

plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('Newton 法迭代过程')
plt.legend()
plt.grid(True)
plt.show()
```

## 5. 割线法
### 5.1 基本思想

割线法用差商代替导数，避免计算导数。

### 5.2 迭代公式

$$x_{n+1} = x_n - f(x_n) \frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}$$

### 5.3 收敛性分析

**收敛速度**：超线性收敛，收敛阶约为 1.618（黄金比例）

**误差公式**：

$$|e_{n+1}| \approx C |e_n|^{1.618}$$

### 5.4 算法步骤

**输入**：函数 $f$，初始值 $x_0, x_1$，精度要求 $\epsilon$，最大迭代次数 $N$
**输出**：根的近似值 $x^*$

1. 初始化 $x_{\text{old}} = x_0$，$x = x_1$
2. 对于 $k = 0, 1, \ldots, N-1$：
   - $f_{\text{old}} = f(x_{\text{old}})$
   - $f_{\text{curr}} = f(x)$
   - 如果 $|f_{\text{curr}} - f_{\text{old}}| < \epsilon$，输出"分母接近零"
   - $x_{\text{new}} = x - f_{\text{curr}} \cdot \frac{x - x_{\text{old}}}{f_{\text{curr}} - f_{\text{old}}}$
   - 如果 $|x_{\text{new}} - x| < \epsilon$，返回 $x_{\text{new}}$
   - $x_{\text{old}} = x$，$x = x_{\text{new}}$
3. 输出"达到最大迭代次数"

### 5.5 Python 实现

```python
import numpy as np

def secant_method(f, x0, x1, tol=1e-10, max_iter=100):
    """
    割线法
    
    参数:
        f: 函数
        x0, x1: 初始值
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 根的近似值
        iterations: 迭代次数
    """
    x_old, x = x0, x1
    
    for k in range(max_iter):
        f_old = f(x_old)
        f_curr = f(x)
        
        if abs(f_curr - f_old) < 1e-15:
            print("警告：分母接近零")
            return x, k
        
        x_new = x - f_curr * (x - x_old) / (f_curr - f_old)
        
        if abs(x_new - x) < tol:
            return x_new, k + 1
        
        x_old, x = x, x_new
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return x, max_iter

# 示例
f = lambda x: x**3 - x - 1
x0, x1 = 1.0, 2.0

root, iterations = secant_method(f, x0, x1)
print(f"割线法结果: x = {root:.10f}")
print(f"迭代次数: {iterations}")
```

## 6. 试位法（Regula Falsi）
### 6.1 基本思想

试位法结合了二分法和割线法的优点，在保持区间收缩的同时加速收敛。

### 6.2 迭代公式

$$c = a - f(a) \frac{b - a}{f(b) - f(a)}$$

### 6.3 算法步骤

**输入**：函数 $f$，区间 $[a, b]$，精度要求 $\epsilon$，最大迭代次数 $N$
**输出**：根的近似值 $x^*$

1. 检查 $f(a) \cdot f(b) < 0$
2. 对于 $k = 0, 1, \ldots, N-1$：
   - $c = a - f(a) \cdot \frac{b - a}{f(b) - f(a)}$
   - 如果 $|f(c)| < \epsilon$，返回 $c$
   - 如果 $f(a) \cdot f(c) < 0$：
     - $b = c$
   - 否则：
     - $a = c$
   - 如果 $|b - a| < \epsilon$，返回 $\frac{a + b}{2}$
3. 输出"达到最大迭代次数"

### 6.4 Python 实现

```python
import numpy as np

def regula_falsi(f, a, b, tol=1e-10, max_iter=100):
    """
    试位法
    
    参数:
        f: 函数
        a, b: 区间端点
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 根的近似值
        iterations: 迭代次数
    """
    if f(a) * f(b) >= 0:
        raise ValueError("f(a) 和 f(b) 必须异号")
    
    for k in range(max_iter):
        c = a - f(a) * (b - a) / (f(b) - f(a))
        
        if abs(f(c)) < tol:
            return c, k + 1
        
        if f(a) * f(c) < 0:
            b = c
        else:
            a = c
        
        if abs(b - a) < tol:
            return (a + b) / 2, k + 1
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return (a + b) / 2, max_iter

# 示例
f = lambda x: x**2 - 2
a, b = 1.0, 2.0

root, iterations = regula_falsi(f, a, b)
print(f"试位法结果: x = {root:.10f}")
print(f"迭代次数: {iterations}")
```

## 7. Brent 方法
### 7.1 基本思想

Brent 方法结合了二分法、割线法和逆二次插值的优点，是一种 robust 且高效的求根算法。

### 7.2 算法步骤

1. 初始化：确保 $|f(b)| < |f(a)|$，设置 $c = a$，$d = b - a$
2. 迭代：
   - 如果 $|f(b)| < |f(a)|$，交换 $a$ 和 $b$
   - 检查收敛
   - 尝试逆二次插值或割线法
   - 如果插值失败，使用二分法
3. 更新区间

### 7.3 Python 实现

```python
import numpy as np

def brent_method(f, a, b, tol=1e-10, max_iter=100):
    """
    Brent 方法
    """
    fa, fb = f(a), f(b)
    
    if fa * fb > 0:
        raise ValueError("f(a) 和 f(b) 必须异号")
    
    if abs(fa) < abs(fb):
        a, b = b, a
        fa, fb = fb, fa
    
    c = a
    fc = fa
    d = b - a
    
    for k in range(max_iter):
        if abs(fb) < tol:
            return b, k + 1
        
        if abs(fc) < abs(fb):
            a, b, c = b, c, b
            fa, fb, fc = fb, fc, fb
        
        m = 0.5 * (c - b)
        
        if abs(m) < tol or abs(fb) < tol:
            return b, k + 1
        
        if abs(d) >= tol and abs(fa) > abs(fb):
            s = fb / fa
            
            if a != c:
                # 逆二次插值
                q = fc / fa
                r = fb / fa
                p = s * (2 * m * q * (q - r) - (b - a) * (r - 1))
                q = (q - 1) * (r - 1) * (s - 1)
            else:
                # 割线法
                p = 2 * m * s
                q = 1 - s
            
            if p > 0:
                q = -q
            else:
                p = -p
            
            if 2 * p < min(3 * m * q - abs(tol * q), abs(d * q)):
                d = p / q
            else:
                d = m
        else:
            d = m
        
        a = b
        fa = fb
        
        if abs(d) > tol:
            b = b + d
        else:
            b = b + (m if m > 0 else tol)
        
        fb = f(b)
        
        if fb * fc > 0:
            c = a
            fc = fa
            d = b - a
    
    return b, max_iter

# 示例
f = lambda x: x**3 - x - 1
a, b = 1.0, 2.0

root, iterations = brent_method(f, a, b)
print(f"Brent 方法结果: x = {root:.10f}")
print(f"迭代次数: {iterations}")
```

## 8. 多重根的处理
### 8.1 重根的影响

当 $x^*$ 是 $f(x) = 0$ 的 $m$ 重根时：
- Newton 法收敛速度降为线性
- 二分法、割线法不受影响

### 8.2 改进的 Newton 法

如果已知重数 $m$：

$$x_{n+1} = x_n - m \frac{f(x_n)}{f'(x_n)}$$

### 8.3 不知道重数的情况

**方法 1**：使用 $f(x)/f'(x)$ 的 Newton 法

定义 $g(x) = \frac{f(x)}{f'(x)}$，则 $g(x) = 0$ 的根都是单根。

**方法 2**：同时估计重数

$$m_{n+1} = -\frac{f(x_n) f''(x_n)}{[f'(x_n)]^2}$$

### 8.4 Python 实现

```python
import numpy as np

def newton_multiplicity(f, df, x0, m=None, tol=1e-10, max_iter=100):
    """
    改进的 Newton 法（处理重根）
    """
    x = x0
    
    for k in range(max_iter):
        fx = f(x)
        dfx = df(x)
        
        if abs(dfx) < 1e-15:
            print("警告：导数接近零")
            return x, k
        
        if m is None:
            # 估计重数
            d2f = (df(x + 1e-8) - df(x - 1e-8)) / (2e-8)
            m_est = -fx * d2f / dfx**2
            m_est = max(1, round(m_est))
        else:
            m_est = m
        
        x_new = x - m_est * fx / dfx
        
        if abs(x_new - x) < tol:
            return x_new, k + 1
        
        x = x_new
    
    return x, max_iter

# 示例：求解 (x-1)² = 0，根 x=1 是二重根
f = lambda x: (x - 1)**2
df = lambda x: 2 * (x - 1)
x0 = 2.0

root, iterations = newton_multiplicity(f, df, x0, m=2)
print(f"改进 Newton 法结果: x = {root:.10f}")
print(f"迭代次数: {iterations}")
```

## 9. 方法比较
### 9.1 收敛速度比较

| 方法 | 收敛阶 | 每次迭代计算量 | 需要导数 | 稳定性 |
|------|--------|----------------|----------|--------|
| 二分法 | 1 | 低 | 否 | 高 |
| 不动点迭代 | 1 | 低 | 否 | 中 |
| Newton 法 | 2 | 中 | 是 | 中 |
| 割线法 | 1.618 | 中 | 否 | 中 |
| 试位法 | 1 | 低 | 否 | 高 |
| Brent 方法 | >1 | 中 | 否 | 高 |

### 9.2 选择建议

1. **初始区间已知**：使用二分法或 Brent 方法
2. **导数容易计算**：使用 Newton 法
3. **导数难以计算**：使用割线法
4. **需要高可靠性**：使用 Brent 方法
5. **简单实现**：使用二分法

## 10. 应用实例
### 10.1 实际应用

1. **工程计算**：求解非线性方程组
2. **物理模拟**：平衡态求解
3. **金融工程**：期权定价
4. **优化问题**：最优化条件求解

### 10.2 Python 示例：求解非线性方程组

```python
import numpy as np
from scipy.optimize import fsolve

# 非线性方程组
def equations(vars):
    x, y = vars
    eq1 = x**2 + y**2 - 4
    eq2 = x * y - 1
    return [eq1, eq2]

# 初始猜测
x0 = [1.0, 1.0]

# 求解
solution = fsolve(equations, x0)
print(f"解: x = {solution[0]:.6f}, y = {solution[1]:.6f}")

# 验证
print(f"验证: x² + y² = {solution[0]**2 + solution[1]**2:.6f}")
print(f"验证: x*y = {solution[0] * solution[1]:.6f}")
```

## 11. 总结与要点
### 11.1 关键要点

- 二分法简单可靠但收敛慢
- Newton 法收敛快但需要导数且可能不收敛
- 割线法避免计算导数但收敛阶较低
- Brent 方法综合了多种方法的优点
- 重根会降低 Newton 法的收敛速度
- 选择合适的方法需要考虑问题特点

### 11.2 实用建议

1. 首先检查函数性质（连续性、可导性）
2. 尝试绘制函数图像，了解根的大致位置
3. 对于简单问题，使用 Brent 方法
4. 对于需要高精度的情况，使用 Newton 法
5. 对于重根问题，使用改进的 Newton 法
6. 始终检查收敛性和解的正确性
