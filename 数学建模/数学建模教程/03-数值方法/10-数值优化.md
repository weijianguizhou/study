# 数值优化

> **理论基础** → 参见 [[../../优化方法/非线性规划|数值优化理论]]

数值优化方法通过迭代搜索目标函数的极值点，梯度下降法和牛顿法是两类基本的数值优化策略。

## 2. 梯度下降法
### 2.1 基本思想

沿负梯度方向搜索，梯度方向是函数增长最快的方向。

### 2.2 迭代公式

$$\mathbf{x}_{k+1} = \mathbf{x}_k - \alpha_k \nabla f(\mathbf{x}_k)$$

其中 $\alpha_k > 0$ 为步长。

### 2.3 步长选择

**固定步长**：$\alpha_k = \alpha$

**精确线搜索**：$\alpha_k = \arg\min_{\alpha > 0} f(\mathbf{x}_k - \alpha \nabla f(\mathbf{x}_k))$

**回溯线搜索**：
1. 初始化 $\alpha = 1$，$\rho = 0.5$，$c = 10^{-4}$
2. 当 $f(\mathbf{x}_k - \alpha \nabla f(\mathbf{x}_k)) > f(\mathbf{x}_k) - c\alpha \|\nabla f(\mathbf{x}_k)\|^2$ 时：
   - $\alpha = \rho \alpha$
3. 返回 $\alpha$

### 2.4 收敛性分析

**定理**：如果 $f$ 是 $L$-光滑的（即 $\|\nabla f(\mathbf{x}) - \nabla f(\mathbf{y})\| \leq L\|\mathbf{x} - \mathbf{y}\|$），且步长 $\alpha \leq 1/L$，则：

$$f(\mathbf{x}_{k}) - f(\mathbf{x}^*) \leq \frac{L\|\mathbf{x}_0 - \mathbf{x}^*\|^2}{2k}$$

收敛速度为 $O(1/k)$。

### 2.5 算法步骤

**输入**：函数 $f$，梯度 $\nabla f$，初始点 $\mathbf{x}_0$，精度要求 $\epsilon$，最大迭代次数 $N$
**输出**：近似极小点 $\mathbf{x}^*$

1. 初始化 $k = 0$
2. 计算 $\mathbf{g}_k = \nabla f(\mathbf{x}_k)$
3. 如果 $\|\mathbf{g}_k\| < \epsilon$，返回 $\mathbf{x}_k$
4. 选择步长 $\alpha_k$（线搜索）
5. 更新 $\mathbf{x}_{k+1} = \mathbf{x}_k - \alpha_k \mathbf{g}_k$
6. $k = k + 1$
7. 如果 $k < N$，返回步骤 2

### 2.6 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def gradient_descent(f, grad_f, x0, alpha=0.01, tol=1e-6, max_iter=1000):
    """
    梯度下降法
    
    参数:
        f: 目标函数
        grad_f: 梯度函数
        x0: 初始点
        alpha: 步长
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 近似极小点
        history: 迭代历史
    """
    x = x0.copy()
    history = [x.copy()]
    
    for k in range(max_iter):
        grad = grad_f(x)
        
        if np.linalg.norm(grad) < tol:
            break
        
        x = x - alpha * grad
        history.append(x.copy())
    
    return x, history

def backtracking_line_search(f, grad_f, x, alpha_init=1.0, rho=0.5, c=1e-4):
    """
    回溯线搜索
    """
    alpha = alpha_init
    grad = grad_f(x)
    fx = f(x)
    
    while f(x - alpha * grad) > fx - c * alpha * np.linalg.norm(grad)**2:
        alpha *= rho
    
    return alpha

# 示例：最小化 f(x, y) = (x-1)² + (y-2)²
f = lambda x: (x[0] - 1)**2 + (x[1] - 2)**2
grad_f = lambda x: np.array([2*(x[0] - 1), 2*(x[1] - 2)])

x0 = np.array([0.0, 0.0])
x_opt, history = gradient_descent(f, grad_f, x0, alpha=0.1)

print(f"最优解: x = {x_opt[0]:.6f}, y = {x_opt[1]:.6f}")
print(f"最优值: f(x*) = {f(x_opt):.6f}")

# 绘图
history = np.array(history)
x_range = np.linspace(-1, 2, 100)
y_range = np.linspace(-1, 3, 100)
X, Y = np.meshgrid(x_range, y_range)
Z = (X - 1)**2 + (Y - 2)**2

plt.figure(figsize=(10, 8))
plt.contour(X, Y, Z, levels=50, cmap='viridis')
plt.plot(history[:, 0], history[:, 1], 'ro-', markersize=3, label='梯度下降路径')
plt.plot(1, 2, 'r*', markersize=15, label='最优解')
plt.xlabel('x')
plt.ylabel('y')
plt.title('梯度下降法')
plt.legend()
plt.grid(True)
plt.show()
```

## 3. 共轭梯度法
### 3.1 基本思想

共轭梯度法是梯度下降法的改进，使用共轭方向代替梯度方向，加速收敛。

### 3.2 共轭方向

向量 $\mathbf{d}_0, \mathbf{d}_1, \ldots, \mathbf{d}_{n-1}$ 关于正定矩阵 $A$ 共轭，如果：

$$\mathbf{d}_i^T A \mathbf{d}_j = 0, \quad i \neq j$$

### 3.3 Fletcher-Reeves 公式

$$\beta_k = \frac{\mathbf{g}_k^T \mathbf{g}_k}{\mathbf{g}_{k-1}^T \mathbf{g}_{k-1}}$$

$$\mathbf{d}_k = -\mathbf{g}_k + \beta_k \mathbf{d}_{k-1}$$

其中 $\mathbf{g}_k = \nabla f(\mathbf{x}_k)$。

### 3.4 算法步骤

**输入**：函数 $f$，梯度 $\nabla f$，初始点 $\mathbf{x}_0$，精度要求 $\epsilon$
**输出**：近似极小点 $\mathbf{x}^*$

1. 初始化：
   - $\mathbf{g}_0 = \nabla f(\mathbf{x}_0)$
   - $\mathbf{d}_0 = -\mathbf{g}_0$
   - $k = 0$
2. 当 $\|\mathbf{g}_k\| > \epsilon$ 时：
   - 线搜索：$\alpha_k = \arg\min_{\alpha} f(\mathbf{x}_k + \alpha \mathbf{d}_k)$
   - 更新：$\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{d}_k$
   - 计算：$\mathbf{g}_{k+1} = \nabla f(\mathbf{x}_{k+1})$
   - 计算：$\beta_k = \frac{\mathbf{g}_{k+1}^T \mathbf{g}_{k+1}}{\mathbf{g}_k^T \mathbf{g}_k}$
   - 更新：$\mathbf{d}_{k+1} = -\mathbf{g}_{k+1} + \beta_k \mathbf{d}_k$
   - $k = k + 1$
3. 返回 $\mathbf{x}_k$

### 3.5 Python 实现

```python
import numpy as np

def conjugate_gradient_opt(f, grad_f, x0, tol=1e-6, max_iter=1000):
    """
    共轭梯度法优化
    """
    n = len(x0)
    x = x0.copy()
    g = grad_f(x)
    d = -g.copy()
    
    history = [x.copy()]
    
    for k in range(max_iter):
        if np.linalg.norm(g) < tol:
            break
        
        # 线搜索（简单实现）
        alpha = backtracking_line_search(f, grad_f, x, alpha_init=1.0)
        
        x = x + alpha * d
        g_new = grad_f(x)
        
        beta = np.dot(g_new, g_new) / np.dot(g, g)
        d = -g_new + beta * d
        
        g = g_new
        history.append(x.copy())
    
    return x, history

# 示例
f = lambda x: (x[0] - 1)**2 + (x[1] - 2)**2
grad_f = lambda x: np.array([2*(x[0] - 1), 2*(x[1] - 2)])

x0 = np.array([0.0, 0.0])
x_opt, history = conjugate_gradient_opt(f, grad_f, x0)

print(f"共轭梯度法最优解: x = {x_opt[0]:.6f}, y = {x_opt[1]:.6f}")
print(f"最优值: f(x*) = {f(x_opt):.6f}")
```

## 4. 牛顿法
### 4.1 基本思想

利用二阶 Taylor 展开近似目标函数，求解近似函数的极小点。

### 4.2 迭代公式

$$\mathbf{x}_{k+1} = \mathbf{x}_k - [\nabla^2 f(\mathbf{x}_k)]^{-1} \nabla f(\mathbf{x}_k)$$

其中 $\nabla^2 f(\mathbf{x}_k)$ 为 Hessian 矩阵。

### 4.3 收敛性分析

**收敛速度**：二次收敛（在解附近）

**优点**：
- 收敛速度快
- 不需要选择步长

**缺点**：
- 需要计算 Hessian 矩阵及其逆
- 计算量大（$O(n^3)$）
- 可能不收敛（如果 Hessian 不正定）

### 4.4 阻尼 Newton 法

为了保证全局收敛，使用线搜索：

$$\mathbf{x}_{k+1} = \mathbf{x}_k - \alpha_k [\nabla^2 f(\mathbf{x}_k)]^{-1} \nabla f(\mathbf{x}_k)$$

### 4.5 算法步骤

**输入**：函数 $f$，梯度 $\nabla f$，Hessian $\nabla^2 f$，初始点 $\mathbf{x}_0$，精度要求 $\epsilon$
**输出**：近似极小点 $\mathbf{x}^*$

1. 初始化 $k = 0$
2. 计算 $\mathbf{g}_k = \nabla f(\mathbf{x}_k)$，$H_k = \nabla^2 f(\mathbf{x}_k)$
3. 如果 $\|\mathbf{g}_k\| < \epsilon$，返回 $\mathbf{x}_k$
4. 求解 $H_k \mathbf{d}_k = -\mathbf{g}_k$
5. 线搜索：$\alpha_k = \arg\min_{\alpha} f(\mathbf{x}_k + \alpha \mathbf{d}_k)$
6. 更新：$\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{d}_k$
7. $k = k + 1$
8. 返回步骤 2

### 4.6 Python 实现

```python
import numpy as np

def newton_method_opt(f, grad_f, hessian_f, x0, tol=1e-6, max_iter=100):
    """
    Newton 法优化
    """
    x = x0.copy()
    history = [x.copy()]
    
    for k in range(max_iter):
        g = grad_f(x)
        H = hessian_f(x)
        
        if np.linalg.norm(g) < tol:
            break
        
        # 求解 H d = -g
        try:
            d = np.linalg.solve(H, -g)
        except np.linalg.LinAlgError:
            # Hessian 不可逆，使用梯度下降
            d = -g
        
        # 线搜索
        alpha = backtracking_line_search(f, grad_f, x, alpha_init=1.0)
        
        x = x + alpha * d
        history.append(x.copy())
    
    return x, history

# 示例：Rosenbrock 函数
def rosenbrock(x):
    return 100 * (x[1] - x[0]**2)**2 + (1 - x[0])**2

def rosenbrock_grad(x):
    return np.array([
        -400 * x[0] * (x[1] - x[0]**2) - 2 * (1 - x[0]),
        200 * (x[1] - x[0]**2)
    ])

def rosenbrock_hessian(x):
    return np.array([
        [-400 * (x[1] - 3 * x[0]**2) + 2, -400 * x[0]],
        [-400 * x[0], 200]
    ])

x0 = np.array([-1.0, 1.0])
x_opt, history = newton_method_opt(rosenbrock, rosenbrock_grad, rosenbrock_hessian, x0)

print(f"Newton 法最优解: x = {x_opt[0]:.6f}, y = {x_opt[1]:.6f}")
print(f"最优值: f(x*) = {rosenbrock(x_opt):.6f}")
```

## 5. 拟牛顿法
### 5.1 基本思想

拟牛顿法通过近似 Hessian 矩阵或其逆，避免计算二阶导数。

### 5.2 拟牛顿条件

$$B_{k+1}(\mathbf{x}_{k+1} - \mathbf{x}_k) = \nabla f(\mathbf{x}_{k+1}) - \nabla f(\mathbf{x}_k)$$

令 $\mathbf{s}_k = \mathbf{x}_{k+1} - \mathbf{x}_k$，$\mathbf{y}_k = \nabla f(\mathbf{x}_{k+1}) - \nabla f(\mathbf{x}_k)$，则：

$$B_{k+1} \mathbf{s}_k = \mathbf{y}_k$$

### 5.3 BFGS 方法

**更新公式**：

$$B_{k+1} = B_k + \frac{\mathbf{y}_k \mathbf{y}_k^T}{\mathbf{y}_k^T \mathbf{s}_k} - \frac{B_k \mathbf{s}_k \mathbf{s}_k^T B_k}{\mathbf{s}_k^T B_k \mathbf{s}_k}$$

**逆矩阵更新**：

$$H_{k+1} = \left( I - \frac{\mathbf{s}_k \mathbf{y}_k^T}{\mathbf{y}_k^T \mathbf{s}_k} \right) H_k \left( I - \frac{\mathbf{y}_k \mathbf{s}_k^T}{\mathbf{y}_k^T \mathbf{s}_k} \right) + \frac{\mathbf{s}_k \mathbf{s}_k^T}{\mathbf{y}_k^T \mathbf{s}_k}$$

### 5.4 L-BFGS 方法

L-BFGS 是 BFGS 的有限内存版本，只存储最近 $m$ 次迭代的信息。

### 5.5 Python 实现

```python
import numpy as np

def bfgs_method(f, grad_f, x0, tol=1e-6, max_iter=1000):
    """
    BFGS 方法
    """
    n = len(x0)
    x = x0.copy()
    H = np.eye(n)  # 初始逆 Hessian 近似
    
    history = [x.copy()]
    
    for k in range(max_iter):
        g = grad_f(x)
        
        if np.linalg.norm(g) < tol:
            break
        
        # 搜索方向
        d = -H @ g
        
        # 线搜索
        alpha = backtracking_line_search(f, grad_f, x, alpha_init=1.0)
        
        # 更新
        x_new = x + alpha * d
        g_new = grad_f(x_new)
        
        s = x_new - x
        y = g_new - g
        
        # 更新逆 Hessian 近似
        rho = 1.0 / np.dot(y, s)
        if rho > 0:  # 确保正定性
            I = np.eye(n)
            A1 = I - rho * np.outer(s, y)
            A2 = I - rho * np.outer(y, s)
            H = A1 @ H @ A2 + rho * np.outer(s, s)
        
        x = x_new
        history.append(x.copy())
    
    return x, history

# 示例
f = lambda x: (x[0] - 1)**2 + (x[1] - 2)**2
grad_f = lambda x: np.array([2*(x[0] - 1), 2*(x[1] - 2)])

x0 = np.array([0.0, 0.0])
x_opt, history = bfgs_method(f, grad_f, x0)

print(f"BFGS 方法最优解: x = {x_opt[0]:.6f}, y = {x_opt[1]:.6f}")
print(f"最优值: f(x*) = {f(x_opt):.6f}")
```

## 6. 约束优化
### 6.1 KKT 条件

对于约束优化问题，Karush-Kuhn-Tucker (KKT) 条件为：

$$\begin{aligned} \nabla f(\mathbf{x}^*) + \sum_{i=1}^{m} \lambda_i \nabla g_i(\mathbf{x}^*) + \sum_{j=1}^{p} \mu_j \nabla h_j(\mathbf{x}^*) &= 0 \\ \lambda_i g_i(\mathbf{x}^*) &= 0, \quad i = 1, \ldots, m \\ g_i(\mathbf{x}^*) &\leq 0, \quad i = 1, \ldots, m \\ h_j(\mathbf{x}^*) &= 0, \quad j = 1, \ldots, p \\ \lambda_i &\geq 0, \quad i = 1, \ldots, m \end{aligned}$$

### 6.2 罚函数法

**二次罚函数**：

$$\min_{\mathbf{x}} f(\mathbf{x}) + \frac{\mu}{2} \sum_{i=1}^{m} [\max(0, g_i(\mathbf{x}))]^2 + \frac{\mu}{2} \sum_{j=1}^{p} h_j(\mathbf{x})^2$$

其中 $\mu > 0$ 为罚参数。

### 6.3 内点法

**对数障碍函数**：

$$\min_{\mathbf{x}} f(\mathbf{x}) - \mu \sum_{i=1}^{m} \ln(-g_i(\mathbf{x}))$$

### 6.4 Python 实现

```python
import numpy as np
from scipy.optimize import minimize

# 无约束优化示例
def rosenbrock(x):
    return 100 * (x[1] - x[0]**2)**2 + (1 - x[0])**2

def rosenbrock_grad(x):
    return np.array([
        -400 * x[0] * (x[1] - x[0]**2) - 2 * (1 - x[0]),
        200 * (x[1] - x[0]**2)
    ])

x0 = np.array([-1.0, 1.0])

# 使用 scipy
result = minimize(rosenbrock, x0, jac=rosenbrock_grad, method='BFGS')
print("scipy BFGS 结果:")
print(f"最优解: x = {result.x[0]:.6f}, y = {result.x[1]:.6f}")
print(f"最优值: f(x*) = {result.fun:.6f}")

# 约束优化示例
def objective(x):
    return x[0]**2 + x[1]**2

def constraint1(x):
    return x[0] + x[1] - 1  # x + y <= 1

from scipy.optimize import minimize

cons = {'type': 'ineq', 'fun': constraint1}
bounds = [(0, None), (0, None)]

result_constrained = minimize(objective, x0, bounds=bounds, constraints=cons, method='SLSQP')
print("\n约束优化结果:")
print(f"最优解: x = {result_constrained.x[0]:.6f}, y = {result_constrained.x[1]:.6f}")
print(f"最优值: f(x*) = {result_constrained.fun:.6f}")
```

## 7. 全局优化
### 7.1 局部最优与全局最优

- **局部最优**：在某个邻域内的最优解
- **全局最优**：在整个定义域内的最优解

### 7.2 遗传算法

**基本步骤**：
1. 初始化种群
2. 计算适应度
3. 选择
4. 交叉
5. 变异
6. 重复 2-5 直到满足条件

### 7.3 模拟退火

**基本步骤**：
1. 初始化温度 $T$
2. 随机扰动产生新解
3. 如果新解更好，接受
4. 否则以概率 $e^{-\Delta f / T}$ 接受
5. 降低温度 $T$
6. 重复直到 $T$ 足够小

### 7.4 Python 实现

```python
import numpy as np

def simulated_annealing(f, x0, T0=100, alpha=0.99, max_iter=10000, tol=1e-6):
    """
    模拟退火算法
    """
    n = len(x0)
    x = x0.copy()
    fx = f(x)
    
    T = T0
    x_best = x.copy()
    fx_best = fx
    
    for k in range(max_iter):
        # 随机扰动
        x_new = x + np.random.randn(n) * 0.1
        fx_new = f(x_new)
        
        # 接受准则
        delta = fx_new - fx
        if delta < 0 or np.random.rand() < np.exp(-delta / T):
            x = x_new
            fx = fx_new
            
            if fx < fx_best:
                x_best = x.copy()
                fx_best = fx
        
        # 降温
        T *= alpha
        
        if T < tol:
            break
    
    return x_best, fx_best

# 示例
f = lambda x: (x[0] - 1)**2 + (x[1] - 2)**2 + 0.1 * np.sin(10 * x[0]) * np.sin(10 * x[1])

x0 = np.array([0.0, 0.0])
x_opt, f_opt = simulated_annealing(f, x0)

print(f"模拟退火最优解: x = {x_opt[0]:.6f}, y = {x_opt[1]:.6f}")
print(f"最优值: f(x*) = {f_opt:.6f}")
```

## 8. 应用实例
### 8.1 机器学习中的优化

**线性回归**：

$$\min_{\mathbf{w}} \frac{1}{2m} \sum_{i=1}^{m} (\mathbf{w}^T \mathbf{x}_i - y_i)^2 + \lambda \|\mathbf{w}\|^2$$

**逻辑回归**：

$$\min_{\mathbf{w}} -\frac{1}{m} \sum_{i=1}^{m} [y_i \log(h_{\mathbf{w}}(\mathbf{x}_i)) + (1 - y_i) \log(1 - h_{\mathbf{w}}(\mathbf{x}_i))] + \lambda \|\mathbf{w}\|^2$$

### 8.2 Python 示例

```python
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge

# 生成数据
np.random.seed(42)
X = np.random.randn(100, 2)
y = 3 * X[:, 0] + 2 * X[:, 1] + 1 + np.random.randn(100) * 0.5

# 普通最小二乘
lr = LinearRegression()
lr.fit(X, y)
print(f"普通最小二乘: w = {lr.coef_}, b = {lr.intercept_}")

# 岭回归（L2 正则化）
ridge = Ridge(alpha=0.1)
ridge.fit(X, y)
print(f"岭回归: w = {ridge.coef_}, b = {ridge.intercept_}")
```

## 9. 总结与要点
### 9.1 方法比较

| 方法 | 每次迭代计算量 | 收敛速度 | 需要导数 | 适用场景 |
|------|----------------|----------|----------|----------|
| 梯度下降 | 低 | 线性 | 一阶 | 大规模问题 |
| 共轭梯度 | 中 | 超线性 | 一阶 | 大规模问题 |
| Newton 法 | 高 | 二次 | 二阶 | 中小规模问题 |
| 拟牛顿法 | 中 | 超线性 | 一阶 | 一般问题 |
| 模拟退火 | 低 | 随机 | 不需要 | 全局优化 |

### 9.2 选择建议

1. **大规模问题**：使用梯度下降或共轭梯度
2. **中小规模问题**：使用拟牛顿法（BFGS）
3. **需要高精度**：使用 Newton 法
4. **全局优化**：使用模拟退火或遗传算法
5. **约束优化**：使用内点法或序列二次规划

### 9.3 关键要点

- 梯度下降法简单但收敛慢
- Newton 法收敛快但计算量大
- 拟牛顿法平衡了计算量和收敛速度
- 步长选择对收敛性有重要影响
- 实际应用中常使用成熟的优化库（如 scipy.optimize）
- 全局优化算法可以避免陷入局部最优
- 正则化可以改善优化问题的条件数
