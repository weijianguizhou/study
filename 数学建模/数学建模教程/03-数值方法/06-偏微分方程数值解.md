# 偏微分方程数值解

> **理论基础** → 参见 [[../../数值分析/偏微分方程数值解|PDE数值解理论]]

偏微分方程数值解通过有限差分法、有限元法等将PDE离散为代数方程组，广泛应用于物理仿真。

## 2. 有限差分法
### 2.1 基本思想

将求解区域离散为网格，用差商近似偏导数。

### 2.2 网格划分

对于矩形区域 $[0, L_x] \times [0, L_y]$，划分网格：

$$x_i = i \Delta x, \quad i = 0, 1, \ldots, N_x$$
$$y_j = j \Delta y, \quad j = 0, 1, \ldots, N_y$$

步长：$\Delta x = L_x / N_x$，$\Delta y = L_y / N_y$

### 2.3 差分格式

**二阶偏导数近似**：

$$\frac{\partial^2 u}{\partial x^2}\bigg|_{i,j} \approx \frac{u_{i+1,j} - 2u_{i,j} + u_{i-1,j}}{\Delta x^2}$$

$$\frac{\partial^2 u}{\partial y^2}\bigg|_{i,j} \approx \frac{u_{i,j+1} - 2u_{i,j} + u_{i,j-1}}{\Delta y^2}$$

**一阶偏导数近似**：

$$\frac{\partial u}{\partial t}\bigg|_{i,j}^n \approx \frac{u_{i,j}^{n+1} - u_{i,j}^n}{\Delta t}$$

### 2.4 Laplace 方程的差分格式

五点差分格式：

$$\frac{u_{i+1,j} - 2u_{i,j} + u_{i-1,j}}{\Delta x^2} + \frac{u_{i,j+1} - 2u_{i,j} + u_{i,j-1}}{\Delta y^2} = 0$$

当 $\Delta x = \Delta y = h$ 时：

$$u_{i,j} = \frac{1}{4}(u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1})$$

### 2.5 算法步骤

**输入**：网格大小 $N_x, N_y$，边界条件，收敛精度 $\epsilon$
**输出**：数值解 $u_{i,j}$

1. 初始化 $u_{i,j}$（例如设为零）
2. 迭代直到收敛：
   - 对于每个内点 $(i, j)$：
     - $u_{i,j}^{new} = \frac{1}{4}(u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1})$
   - 检查收敛：$\max|u^{new} - u^{old}| < \epsilon$
   - 更新 $u$

### 2.6 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def solve_laplace(Nx, Ny, boundary_func, tol=1e-6, max_iter=10000):
    """
    使用有限差分法求解 Laplace 方程
    
    参数:
        Nx, Ny: 网格点数
        boundary_func: 边界条件函数
        tol: 收敛精度
        max_iter: 最大迭代次数
    返回:
        u: 数值解
    """
    # 初始化
    u = np.zeros((Nx + 1, Ny + 1))
    
    # 设置边界条件
    for i in range(Nx + 1):
        for j in range(Ny + 1):
            u[i, j] = boundary_func(i / Nx, j / Ny)
    
    # Gauss-Seidel 迭代
    for iteration in range(max_iter):
        u_old = u.copy()
        
        for i in range(1, Nx):
            for j in range(1, Ny):
                u[i, j] = 0.25 * (u[i+1, j] + u[i-1, j] + u[i, j+1] + u[i, j-1])
        
        # 检查收敛
        if np.max(np.abs(u - u_old)) < tol:
            print(f"收敛于第 {iteration + 1} 次迭代")
            break
    
    return u

# 示例：边界条件
def boundary_func(x, y):
    """边界条件：上边界为正弦函数，其余为零"""
    if y == 1:
        return np.sin(np.pi * x)
    return 0.0

# 求解
Nx, Ny = 50, 50
u = solve_laplace(Nx, Ny, boundary_func)

# 绘图
x = np.linspace(0, 1, Nx + 1)
y = np.linspace(0, 1, Ny + 1)
X, Y = np.meshgrid(x, y)

plt.figure(figsize=(10, 8))
plt.contourf(X, Y, u.T, levels=50, cmap='hot')
plt.colorbar(label='u')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Laplace 方程数值解')
plt.show()
```

## 3. 热传导方程的数值解
### 3.1 显式差分格式

热传导方程：$\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$

**显式格式**：

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} = \alpha \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2}$$

整理得：

$$u_i^{n+1} = u_i^n + r(u_{i+1}^n - 2u_i^n + u_{i-1}^n)$$

其中 $r = \frac{\alpha \Delta t}{\Delta x^2}$。

**稳定性条件**：$r \leq \frac{1}{2}$

### 3.2 隐式差分格式

**隐式格式**：

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} = \alpha \frac{u_{i+1}^{n+1} - 2u_i^{n+1} + u_{i-1}^{n+1}}{\Delta x^2}$$

整理得：

$$-r u_{i-1}^{n+1} + (1 + 2r) u_i^{n+1} - r u_{i+1}^{n+1} = u_i^n$$

**特点**：无条件稳定，但需要求解线性方程组。

### 3.3 Crank-Nicolson 格式

**Crank-Nicolson 格式**：

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} = \frac{\alpha}{2} \left( \frac{u_{i+1}^{n+1} - 2u_i^{n+1} + u_{i-1}^{n+1}}{\Delta x^2} + \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2} \right)$$

**特点**：
- 无条件稳定
- 二阶精度（时间和空间都是二阶）
- 需要求解线性方程组

### 3.4 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def heat_equation_explicit(alpha, L, T, Nx, Nt, u0, bc_left, bc_right):
    """
    使用显式格式求解一维热传导方程
    
    参数:
        alpha: 热扩散系数
        L: 空间区间长度
        T: 时间区间长度
        Nx: 空间网格点数
        Nt: 时间步数
        u0: 初始条件
        bc_left, bc_right: 边界条件
    返回:
        x, t, u: 空间坐标、时间坐标、数值解
    """
    dx = L / Nx
    dt = T / Nt
    r = alpha * dt / dx**2
    
    # 稳定性检查
    if r > 0.5:
        print(f"警告: r = {r} > 0.5，显式格式不稳定")
    
    # 初始化
    x = np.linspace(0, L, Nx + 1)
    t = np.linspace(0, T, Nt + 1)
    u = np.zeros((Nt + 1, Nx + 1))
    
    # 初始条件
    u[0, :] = u0(x)
    
    # 边界条件
    u[:, 0] = bc_left(t)
    u[:, -1] = bc_right(t)
    
    # 时间推进
    for n in range(Nt):
        for i in range(1, Nx):
            u[n+1, i] = u[n, i] + r * (u[n, i+1] - 2*u[n, i] + u[n, i-1])
    
    return x, t, u

# 示例：一维热传导
alpha = 0.01
L = 1.0
T = 1.0

# 初始条件：正弦函数
u0 = lambda x: np.sin(np.pi * x)

# 边界条件：零
bc_left = lambda t: 0.0
bc_right = lambda t: 0.0

# 求解
Nx, Nt = 50, 1000
x, t, u = heat_equation_explicit(alpha, L, T, Nx, Nt, u0, bc_left, bc_right)

# 绘图
X, T_grid = np.meshgrid(x, t)

plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.contourf(X, T_grid, u, levels=50, cmap='hot')
plt.colorbar(label='u')
plt.xlabel('x')
plt.ylabel('t')
plt.title('热传导方程数值解')

plt.subplot(1, 2, 2)
time_indices = [0, 100, 200, 500, 999]
for idx in time_indices:
    plt.plot(x, u[idx, :], label=f't = {t[idx]:.2f}')
plt.xlabel('x')
plt.ylabel('u')
plt.title('不同时间的温度分布')
plt.legend()
plt.grid(True)

plt.tight_layout()
plt.show()
```

## 4. 波动方程的数值解
### 4.1 显式差分格式

波动方程：$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$

**显式格式**：

$$\frac{u_i^{n+1} - 2u_i^n + u_i^{n-1}}{\Delta t^2} = c^2 \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2}$$

整理得：

$$u_i^{n+1} = 2u_i^n - u_i^{n-1} + s^2(u_{i+1}^n - 2u_i^n + u_{i-1}^n)$$

其中 $s = \frac{c \Delta t}{\Delta x}$。

**稳定性条件**：$s \leq 1$

### 4.2 初始条件处理

波动方程需要两个初始条件：
- $u(x, 0) = u_0(x)$
- $\frac{\partial u}{\partial t}(x, 0) = v_0(x)$

**初始速度条件的处理**：

$$u_i^1 = u_i^0 + \Delta t v_0(x_i) + \frac{s^2}{2}(u_{i+1}^0 - 2u_i^0 + u_{i-1}^0)$$

### 4.3 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def wave_equation_explicit(c, L, T, Nx, Nt, u0, v0, bc_left, bc_right):
    """
    使用显式格式求解一维波动方程
    
    参数:
        c: 波速
        L: 空间区间长度
        T: 时间区间长度
        Nx: 空间网格点数
        Nt: 时间步数
        u0: 初始位移
        v0: 初始速度
        bc_left, bc_right: 边界条件
    返回:
        x, t, u: 空间坐标、时间坐标、数值解
    """
    dx = L / Nx
    dt = T / Nt
    s = c * dt / dx
    
    # 稳定性检查
    if s > 1.0:
        print(f"警告: s = {s} > 1.0，显式格式不稳定")
    
    # 初始化
    x = np.linspace(0, L, Nx + 1)
    t = np.linspace(0, T, Nt + 1)
    u = np.zeros((Nt + 1, Nx + 1))
    
    # 初始条件
    u[0, :] = u0(x)
    
    # 初始速度条件
    u[1, :] = u[0, :] + dt * v0(x) + 0.5 * s**2 * (np.roll(u[0, :], -1) - 2*u[0, :] + np.roll(u[0, :], 1))
    
    # 边界条件
    u[:, 0] = bc_left(t)
    u[:, -1] = bc_right(t)
    
    # 时间推进
    for n in range(1, Nt):
        for i in range(1, Nx):
            u[n+1, i] = 2*u[n, i] - u[n-1, i] + s**2 * (u[n, i+1] - 2*u[n, i] + u[n, i-1])
    
    return x, t, u

# 示例：波动方程
c = 1.0
L = 1.0
T = 2.0

# 初始条件：高斯脉冲
u0 = lambda x: np.exp(-100 * (x - 0.5)**2)
v0 = lambda x: 0.0

# 边界条件：固定端点
bc_left = lambda t: 0.0
bc_right = lambda t: 0.0

# 求解
Nx, Nt = 100, 200
x, t, u = wave_equation_explicit(c, L, T, Nx, Nt, u0, v0, bc_left, bc_right)

# 绘图
fig = plt.figure(figsize=(12, 8))

# 三维表面图
ax1 = fig.add_subplot(121, projection='3d')
X, T_grid = np.meshgrid(x, t)
ax1.plot_surface(X, T_grid, u, cmap='viridis')
ax1.set_xlabel('x')
ax1.set_ylabel('t')
ax1.set_zlabel('u')
ax1.set_title('波动方程数值解')

# 不同时刻的波形
ax2 = fig.add_subplot(122)
time_indices = [0, 25, 50, 75, 100]
for idx in time_indices:
    ax2.plot(x, u[idx, :], label=f't = {t[idx]:.2f}')
ax2.set_xlabel('x')
ax2.set_ylabel('u')
ax2.set_title('不同时刻的波形')
ax2.legend()
ax2.grid(True)

plt.tight_layout()
plt.show()
```

## 5. 有限元方法
### 5.1 基本思想

有限元方法将求解区域划分为有限个单元，在每个单元上用简单的插值函数近似解，通过变分原理建立代数方程组。

### 5.2 变分形式

对于 Poisson 方程：

$$-\nabla^2 u = f \quad \text{in } \Omega$$
$$u = 0 \quad \text{on } \partial\Omega$$

**弱形式**：求 $u \in H_0^1(\Omega)$ 使得：

$$\int_\Omega \nabla u \cdot \nabla v \, dx = \int_\Omega f v \, dx, \quad \forall v \in H_0^1(\Omega)$$

### 5.3 单元刚度矩阵

对于三角形单元 $K$，线性插值函数的刚度矩阵：

$$K_{ij}^e = \int_K \nabla \phi_i \cdot \nabla \phi_j \, dx$$

其中 $\phi_i$ 为形函数。

### 5.4 单元载荷向量

$$F_i^e = \int_K f \phi_i \, dx$$

### 5.5 总体组装

将所有单元的刚度矩阵和载荷向量组装成总体方程组：

$$K \mathbf{u} = \mathbf{F}$$

### 5.6 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.sparse import lil_matrix
from scipy.sparse.linalg import spsolve

def generate_mesh(Lx, Ly, Nx, Ny):
    """
    生成矩形区域的三角形网格
    """
    x = np.linspace(0, Lx, Nx + 1)
    y = np.linspace(0, Ly, Ny + 1)
    X, Y = np.meshgrid(x, y)
    
    nodes = np.column_stack([X.ravel(), Y.ravel()])
    
    elements = []
    for j in range(Ny):
        for i in range(Nx):
            n1 = j * (Nx + 1) + i
            n2 = n1 + 1
            n3 = n1 + (Nx + 1)
            n4 = n3 + 1
            
            # 两个三角形
            elements.append([n1, n2, n3])
            elements.append([n2, n4, n3])
    
    return nodes, np.array(elements)

def element_stiffness(node1, node2, node3):
    """
    计算三角形单元的刚度矩阵
    """
    # 节点坐标
    x1, y1 = node1
    x2, y2 = node2
    x3, y3 = node3
    
    # 面积
    area = 0.5 * abs((x2 - x1) * (y3 - y1) - (x3 - x1) * (y2 - y1))
    
    # 形函数的梯度
    b1, b2, b3 = y2 - y3, y3 - y1, y1 - y2
    c1, c2, c3 = x3 - x2, x1 - x3, x2 - x1
    
    # 刚度矩阵
    Ke = np.zeros((3, 3))
    for i in range(3):
        for j in range(3):
            bi = [b1, b2, b3][i]
            bj = [b1, b2, b3][j]
            ci = [c1, c2, c3][i]
            cj = [c1, c2, c3][j]
            
            Ke[i, j] = (bi * bj + ci * cj) / (4 * area)
    
    return Ke

def solve_poisson_fem(nodes, elements, f_func, bc_nodes, bc_values):
    """
    使用有限元方法求解 Poisson 方程
    """
    n_nodes = len(nodes)
    K = lil_matrix((n_nodes, n_nodes))
    F = np.zeros(n_nodes)
    
    # 组装刚度矩阵和载荷向量
    for elem in elements:
        n1, n2, n3 = elem
        node1, node2, node3 = nodes[n1], nodes[n2], nodes[n3]
        
        Ke = element_stiffness(node1, node2, node3)
        
        # 面积
        x1, y1 = node1
        x2, y2 = node2
        x3, y3 = node3
        area = 0.5 * abs((x2 - x1) * (y3 - y1) - (x3 - x1) * (y2 - y1))
        
        # 载荷向量（假设 f 为常数）
        fe = area / 3 * f_func((node1 + node2 + node3) / 3)
        
        for i, ni in enumerate([n1, n2, n3]):
            F[ni] += fe
            for j, nj in enumerate([n1, n2, n3]):
                K[ni, nj] += Ke[i, j]
    
    # 应用边界条件
    K = K.tocsr()
    for node, value in zip(bc_nodes, bc_values):
        K[node, :] = 0
        K[node, node] = 1
        F[node] = value
    
    # 求解
    u = spsolve(K, F)
    
    return u

# 示例：求解 -∇²u = 1 在 [0,1]×[0,1]，边界条件 u=0
nodes, elements = generate_mesh(1.0, 1.0, 20, 20)

# 边界节点
bc_nodes = []
bc_values = []
for i in range(len(nodes)):
    x, y = nodes[i]
    if x == 0 or x == 1 or y == 0 or y == 1:
        bc_nodes.append(i)
        bc_values.append(0.0)

# 求解
f_func = lambda x: 1.0
u = solve_poisson_fem(nodes, elements, f_func, bc_nodes, bc_values)

# 绘图
plt.figure(figsize=(10, 8))
plt.tricontourf(nodes[:, 0], nodes[:, 1], u, levels=50, cmap='hot')
plt.colorbar(label='u')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Poisson 方程有限元解')
plt.show()
```

### 7.2 实际案例：二维热传导

```python
import numpy as np
import matplotlib.pyplot as plt

def heat_equation_2d(alpha, Lx, Ly, T, Nx, Ny, Nt, u0, bc_func):
    """
    使用显式格式求解二维热传导方程
    """
    dx = Lx / Nx
    dy = Ly / Ny
    dt = T / Nt
    
    rx = alpha * dt / dx**2
    ry = alpha * dt / dy**2
    
    # 稳定性检查
    if rx + ry > 0.5:
        print(f"警告: rx + ry = {rx + ry} > 0.5，显式格式可能不稳定")
    
    # 初始化
    x = np.linspace(0, Lx, Nx + 1)
    y = np.linspace(0, Ly, Ny + 1)
    t = np.linspace(0, T, Nt + 1)
    
    u = np.zeros((Nx + 1, Ny + 1))
    
    # 初始条件
    for i in range(Nx + 1):
        for j in range(Ny + 1):
            u[i, j] = u0(x[i], y[j])
    
    # 时间推进
    u_history = [u.copy()]
    
    for n in range(Nt):
        u_new = u.copy()
        
        for i in range(1, Nx):
            for j in range(1, Ny):
                u_new[i, j] = u[i, j] + rx * (u[i+1, j] - 2*u[i, j] + u[i-1, j]) \
                                            + ry * (u[i, j+1] - 2*u[i, j] + u[i, j-1])
        
        # 边界条件
        u_new = bc_func(u_new, x, y, t[n+1])
        
        u = u_new
        u_history.append(u.copy())
    
    return x, y, t, u_history

# 示例：中心热源
Lx, Ly = 1.0, 1.0
alpha = 0.01
T = 0.5

# 初始条件：中心高斯热源
u0 = lambda x, y: np.exp(-100 * ((x - 0.5)**2 + (y - 0.5)**2))

# 边界条件：固定温度为零
def bc_func(u, x, y, t):
    u[0, :] = 0
    u[-1, :] = 0
    u[:, 0] = 0
    u[:, -1] = 0
    return u

# 求解
Nx, Ny, Nt = 30, 30, 100
x, y, t, u_history = heat_equation_2d(alpha, Lx, Ly, T, Nx, Ny, Nt, u0, bc_func)

# 绘图
fig = plt.figure(figsize=(15, 5))

X, Y = np.meshgrid(x, y)

time_steps = [0, 25, 50, 99]
for i, step in enumerate(time_steps):
    plt.subplot(1, 4, i + 1)
    plt.contourf(X, Y, u_history[step].T, levels=50, cmap='hot')
    plt.colorbar()
    plt.title(f't = {t[step]:.3f}')
    plt.xlabel('x')
    plt.ylabel('y')

plt.tight_layout()
plt.show()
```

## 8. 总结与要点
### 8.1 方法比较

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 有限差分法 | 简单、直观 | 网格规则 | 规则区域 |
| 有限元法 | 适应复杂几何 | 实现复杂 | 复杂区域 |
| 有限体积法 | 守恒性好 | 高阶精度难 | 流体力学 |

### 8.2 选择建议

1. **规则区域**：使用有限差分法
2. **复杂几何**：使用有限元法
3. **守恒问题**：使用有限体积法
4. **高精度要求**：使用高阶格式或自适应网格

### 8.3 关键要点

- 稳定性是选择数值格式的重要考虑因素
- 显式格式简单但有稳定性限制
- 隐式格式稳定但计算量大
- 网格密度影响计算精度和效率
- 边界条件的处理对解的精度有重要影响
- 实际应用中常使用成熟的软件包（如 FEniCS、COMSOL）
