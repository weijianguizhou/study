# 随机微分方程 (Stochastic Differential Equations)

> **理论基础** → 参见 [[../../随机过程/随机微分方程|随机微分方程]]

随机微分方程在常微分方程中引入随机扰动项，用于描述受噪声影响的动态系统建模。

## 三、Itô 引理 (Itô's Lemma)
### 3.1 标量 Itô 引理

设 $X_t$ 满足 $dX_t = a_t \, dt + b_t \, dW_t$，$f(t, x)$ 二阶连续可微，则：

$$df(t, X_t) = \left[\frac{\partial f}{\partial t} + a_t \frac{\partial f}{\partial x} + \frac{1}{2} b_t^2 \frac{\partial^2 f}{\partial x^2}\right] dt + b_t \frac{\partial f}{\partial x} \, dW_t$$

**与普通微积分的区别**：多出了 $\frac{1}{2} b_t^2 \frac{\partial^2 f}{\partial x^2}$ 项（Itô 修正项），源于 $dW_t^2 = dt$。

### 3.2 推导：为什么 $dW_t^2 = dt$

Itô 积分的二次变差：

$$[W, W]_t = \lim_{|\Pi| \to 0} \sum_{k} [W(t_{k+1}) - W(t_k)]^2 = t$$

因此 $dW_t \cdot dW_t = dt$。这是 Itô 微积分的核心等式。

**Itô 乘法表**：

|  | $dt$ | $dW_t$ |
|--|------|--------|
| $dt$ | 0 | 0 |
| $dW_t$ | 0 | $dt$ |

高阶项忽略：$dt^2 = 0$，$dt \cdot dW_t = 0$，$dW_t^3 = 0$。

### 3.3 多维 Itô 引理

设 $\mathbf{X}_t \in \mathbb{R}^d$ 满足：

$$d\mathbf{X}_t = \boldsymbol{\mu}(\mathbf{X}_t, t) \, dt + \boldsymbol{\sigma}(\mathbf{X}_t, t) \, d\mathbf{W}_t$$

$f: \mathbb{R}^{d+1} \to \mathbb{R}$ 为 $C^{2,1}$ 函数，则：

$$df = \frac{\partial f}{\partial t} dt + \sum_i \frac{\partial f}{\partial x_i} dX_{t,i} + \frac{1}{2} \sum_{i,j} \frac{\partial^2 f}{\partial x_i \partial x_j} dX_{t,i} \, dX_{t,j}$$

其中交叉项：$dW_{t,i} \, dW_{t,j} = \rho_{ij} \, dt$（$\rho_{ij}$ 为布朗运动之间的相关性）。

### 3.4 Itô 引理的应用示例

**几何布朗运动**：$dS = \mu S \, dt + \sigma S \, dW$

求 $f(S) = \ln S$：

$$d(\ln S) = \frac{1}{S} dS - \frac{1}{2} \frac{1}{S^2} (dS)^2 = \left(\mu - \frac{\sigma^2}{2}\right) dt + \sigma \, dW$$

积分得：

$$\ln S(t) = \ln S(0) + \left(\mu - \frac{\sigma^2}{2}\right) t + \sigma W(t)$$

$$S(t) = S(0) \exp\left[\left(\mu - \frac{\sigma^2}{2}\right) t + \sigma W(t)\right]$$

**Vasicek 利率模型**：$dr = \kappa(\theta - r) \, dt + \sigma \, dW$

令 $f(t, r) = e^{\kappa t} r$，利用 Itô 引理：

$$d(e^{\kappa t} r) = \kappa e^{\kappa t} r \, dt + e^{\kappa t} \, dr = e^{\kappa t}[\kappa \theta \, dt + \sigma \, dW]$$

积分得：

$$r(t) = r(0) e^{-\kappa t} + \theta(1 - e^{-\kappa t}) + \sigma \int_0^t e^{-\kappa(t-s)} \, dW_s$$

$r(t)$ 的分布为正态分布，均值和方差为：

$$E[r(t)] = r(0) e^{-\kappa t} + \theta(1 - e^{-\kappa t})$$
$$\text{Var}[r(t)] = \frac{\sigma^2}{2\kappa}(1 - e^{-2\kappa t})$$

```python
import numpy as np

def ito_lemma_example():
    """验证Itô引理：几何布朗运动"""
    S0, mu, sigma, T, dt = 100, 0.05, 0.2, 1.0, 0.001
    n = int(T / dt)
    t = np.linspace(0, T, n + 1)
    dW = np.random.normal(0, np.sqrt(dt), n)
    W = np.concatenate([[0], np.cumsum(dW)])
    S = S0 * np.exp((mu - 0.5 * sigma**2) * t + sigma * W)
    log_S = np.log(S0) + (mu - 0.5*sigma**2)*t + sigma*W
    print(f"S(T) direct: {S[-1]:.4f}")
    print(f"S(T) via log: {S0*np.exp(log_S[-1]):.4f}")
```

## 五、SDE 数值解法
### 5.1 Euler-Maruyama 方法

对 $dX_t = a(X_t) \, dt + b(X_t) \, dW_t$：

$$X_{n+1} = X_n + a(X_n) \Delta t + b(X_n) \Delta W_n$$

其中 $\Delta W_n \sim N(0, \Delta t)$。

**收敛阶**：强收敛 $O(\Delta t^{1/2})$，弱收敛 $O(\Delta t)$。

### 5.2 Milstein 方法

$$X_{n+1} = X_n + a(X_n) \Delta t + b(X_n) \Delta W_n + \frac{1}{2} b(X_n) b'(X_n) [(\Delta W_n)^2 - \Delta t]$$

**收敛阶**：强收敛 $O(\Delta t)$。比 Euler-Maruyama 精度更高。

### 5.3 Heun 方法（随机 Runge-Kutta）

预测-校正方法：

$$\tilde{X}_{n+1} = X_n + a(X_n) \Delta t + b(X_n) \Delta W_n$$
$$X_{n+1} = X_n + \frac{1}{2}[a(X_n) + a(\tilde{X}_{n+1})] \Delta t + \frac{1}{2}[b(X_n) + b(\tilde{X}_{n+1})] \Delta W_n$$

### 5.4 弱收敛与强收敛

**强收敛**：$E|X_T - X_T^{\Delta t}| \leq C \Delta t^{\gamma}$

**弱收敛**：$|E[f(X_T)] - E[f(X_T^{\Delta t})]| \leq C \Delta t^{\beta}$

通常弱收敛阶高于强收敛阶。

```python
import numpy as np
import matplotlib.pyplot as plt

def euler_maruyama(drift, diffusion, X0, T, n_steps, n_paths=1):
    """Euler-Maruyama数值解法"""
    dt = T / n_steps
    t = np.linspace(0, T, n_steps + 1)
    X = np.zeros((n_paths, n_steps + 1))
    X[:, 0] = X0
    for i in range(n_steps):
        dW = np.random.normal(0, np.sqrt(dt), n_paths)
        X[:, i+1] = X[:, i] + drift(X[:, i]) * dt + diffusion(X[:, i]) * dW
    return t, X

def milstein_method(drift, diffusion, diff_prime, X0, T, n_steps, n_paths=1):
    """Milstein数值解法"""
    dt = T / n_steps
    t = np.linspace(0, T, n_steps + 1)
    X = np.zeros((n_paths, n_steps + 1))
    X[:, 0] = X0
    for i in range(n_steps):
        dW = np.random.normal(0, np.sqrt(dt), n_paths)
        X_n = X[:, i]
        X[:, i+1] = (X_n + drift(X_n)*dt + diffusion(X_n)*dW
                     + 0.5*diffusion(X_n)*diff_prime(X_n)*(dW**2 - dt))
    return t, X

# 示例：几何布朗运动
mu, sigma, S0 = 0.05, 0.3, 100
drift_gb = lambda x: mu * x
diff_gb = lambda x: sigma * x
diff_prime_gb = lambda x: sigma

t, S = euler_maruyama(drift_gb, diff_gb, S0, 1.0, 252, 10)
plt.figure(figsize=(10, 5))
for i in range(10):
    plt.plot(t, S[i])
plt.title('Geometric Brownian Motion (Euler-Maruyama)')
plt.xlabel('Time')
plt.ylabel('S(t)')
plt.show()
```

### 5.5 隐式方法

对于 stiff SDE，显式方法可能不稳定。隐式 Euler 方法：

$$X_{n+1} = X_n + a(X_{n+1}) \Delta t + b(X_{n+1}) \Delta W_n$$

通常需要迭代求解非线性方程。

## 八、应用案例
### 8.1 Black-Scholes 期权定价

Black-Scholes PDE：

$$\frac{\partial V}{\partial t} + \frac{1}{2} \sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS \frac{\partial V}{\partial S} - rV = 0$$

欧式看涨期权的解析解（Black-Scholes 公式）：

$$C = S_0 \Phi(d_1) - K e^{-rT} \Phi(d_2)$$

$$d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T}$$

```python
import numpy as np
from scipy.stats import norm

def black_scholes(S0, K, r, sigma, T, option_type='call'):
    d1 = (np.log(S0/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)
    if option_type == 'call':
        return S0*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d2)
    else:
        return K*np.exp(-r*T)*norm.cdf(-d2) - S0*norm.cdf(-d1)

def mc_option_price(S0, K, r, sigma, T, n_sims=100000):
    Z = np.random.standard_normal(n_sims)
    ST = S0 * np.exp((r - 0.5*sigma**2)*T + sigma*np.sqrt(T)*Z)
    call_payoff = np.maximum(ST - K, 0)
    price = np.exp(-r*T) * np.mean(call_payoff)
    se = np.exp(-r*T) * np.std(call_payoff) / np.sqrt(n_sims)
    return price, se

bs_price = black_scholes(100, 100, 0.05, 0.2, 1.0)
mc_price, mc_se = mc_option_price(100, 100, 0.05, 0.2, 1.0)
print(f"Black-Scholes: {bs_price:.4f}")
print(f"Monte Carlo:   {mc_price:.4f} +/- {1.96*mc_se:.4f}")
```

### 8.2 Vasicek 利率模型蒙特卡洛模拟

```python
def simulate_vasicek(r0, kappa, theta, sigma, T, n_steps, n_paths):
    dt = T / n_steps
    t = np.linspace(0, T, n_steps + 1)
    r = np.zeros((n_paths, n_steps + 1))
    r[:, 0] = r0
    for i in range(n_steps):
        dW = np.random.normal(0, np.sqrt(dt), n_paths)
        r[:, i+1] = (r[:, i] + kappa*(theta - r[:, i])*dt + sigma*dW)
    return t, r

t, rates = simulate_vasicek(r0=0.03, kappa=0.1, theta=0.05, sigma=0.01, T=5.0, n_steps=250, n_paths=5)
```

## 九、关键要点总结
1. Itô 引理是随机微积分的核心工具，类比于确定性微积分的链式法则
2. 关键等式 $dW_t^2 = dt$ 导致了 Itô 修正项的出现
3. 几何布朗运动是金融建模的基础，其解析解为对数正态分布
4. Ornstein-Uhlenbeck 过程是最重要的均值回复模型
5. Euler-Maruyama 方法是最基本的 SDE 数值解法，收敛阶为 $O(\Delta t^{1/2})$
6. Milstein 方法通过增加二阶项达到 $O(\Delta t)$ 强收敛
7. Fokker-Planck 方程描述了 SDE 对应的概率密度演化
8. Girsanov 定理提供了测度变换的工具，是风险中性定价的理论基础
9. Feynman-Kac 公式连接了偏微分方程和随机过程，为数值定价提供途径
10. 随机微分方程为金融、物理、生态等领域的随机建模提供了严格的数学框架
