# MATLAB语言程序设计基础
## MATLAB语言的变量与常量
### MATLAB语言的变量名规则
1. 由一个字母引导，后面可以为其他字符
2. 区分大小写 `Abc` $\neq$ `ABc`
### MATLAB的保留常量
1. `eps, i, j, pi, NaN, Inf, i=sqrt(-1)`
2. `lastwarn, lasterr`

### MATLAB语言的数据结构
#### 数值型数据
##### 双精度数值变量
1. IEEE标准，64位 (8字节)
2. 11指数位，52数值位和一个符号位
3. 数据范围$-1.7\times 10^{308}\sim 1.7\times 10^{308}$
4. `double()` 函数的转换
##### 其他数据类型
1. 单精度数据结构 `single()`，32位
2. `uint8()`, 常用于图像表示和处理，8位
3. `int8()`,`int16()`,`int32()`,`uint16()`,`uint32()`

#### 符号型数据结构
##### 符号型，`sym(A)`，常用于公式推导和求解析解
1. 变量声明 `syms var_list var_props`
2. 显示符号变量的任何精度`vpa(A)``vpa(A,n)`默认精度——32位十进制有效数字
3. 显示符号变量的属性 `assumptions()`
4. 设置符号变量类型 `assume()`, `assumeAlso()`
```MATLAB
>>syms x real; assume(x>=-1); assumeAlso(x<5);
```

#### 符号型数值与双精度数值的区别（例2-1）
> 例 2-1：比较 `1/3` 在双精度与符号型下的存储差异。
1. 双精度存储——`0.333……33`，只有 15 位有限有效数字，其余数位全部被截断、没有规律
2. 符号型存储——一直精确存储 `1/3` 这个有理数
3. 二者的转换：`sym(1/3)`、`double(1/3)`
```MATLAB
>> sym(1/3)      % ans = 1/3
>> double(1/3)   % ans = 0.3333
```

#### 任意精度显示（例2-2）
> 例 2-2：求出圆周率 `pi` 的 300 位有效数字。
```MATLAB
>> vpa(pi,300)     % 显示 pi 的 300 位有效数字
```
- 符号运算可以"任意"增加有效数字的位数
- 但位数越多，运行时间越长；若要求位数过多可能无法完整显示

#### 用符号型精确表示大整数（例2-4）
> 例 2-4：用符号型数据结构表示数值 12345678901234567890。
- **直接输入会丢失精度**：`12345678901234567890` 会被当作 double 截断，得不到精确值
- **正确方法**：用字符串形式交给 `sym()`，符号运算会保留完整精度
```MATLAB
B=sym('12345678901234567890123456789012345678901234567890')
```

## MATLAB语言的其他数据结构类型

### 逻辑型数据结构（logical）
> MATLAB 用 `logical` 类型表示真/假，只占 1 字节，取值仅有 `true`(1) 和 `false`(0)。逻辑型在数组索引、条件判断、逻辑筛选（masking）中极为常用。

1. **创建**：直接赋值或通过比较/逻辑运算得到
```MATLAB
a = true;            b = false;          % 直接创建
c = 5 > 3;           % 比较运算返回 logical，结果为 true
d = isprime(17);     % 很多函数返回 logical
e = logical(0);      % 由数值强制转换，非 0 为 true
```
2. **逻辑运算**：`&`（与）、`|`（或）、`~`（非）、`xor`（异或）
```MATLAB
p = true; q = false;
p & q    % false
p | q    % true
~p       % false
xor(p,q) % true
```
3. **逻辑索引（关键用法）**：用逻辑数组对下标做筛选，返回满足条件的位置
```MATLAB
x = [1, 5, 2, 8, 3];
mask = x > 3;              % [false true false true false]
x(mask)                    % 取出所有 >3 的元素 → [5 8]
x(x > 3) = 0;              % 把 >3 的元素置 0
```
4. **逻辑值与数值的互换**：参与算术时 `true=1, false=0`
```MATLAB
sum([true,false,true])     % → 2
double(true)               % → 1
logical(3)                 % → true（非零即真）
```

### 字符型与字符串型数据结构（char / string）
> 字符型（`char`）是单个字符，多个字符组成**字符数组**（本质是数值数组的存储）；字符串型（`string`，R2016b 引入、R2017a 稳定）把一串文本当成一个整体对象，更方便拼接、比较和索引。

1. **char 字符数组**：单引号，本质是 `1×n` 的数值数组（存的是字符的 Unicode 码）
```MATLAB
s1 = 'Hello';                % char，1×5 字符数组
s2 = ['Hello',' World'];     % 用方括号拼接
s3 = 'Hello'; s3(1)          % 取第一个字符 → 'H'
class(s1)                    % → 'char'
double('A')                  % → 65（字符其实存的是码值）
char(65)                     % → 'A'
```
2. **string 字符串**：双引号，是一个整体标量
```MATLAB
str1 = "Hello";              % string
str2 = "World";
str1 + " " + str2            % 字符串拼接（+ 号）→ "Hello World"
strlength(str1)              % 长度 → 5
strcmp(str1,"Hello")         % 比较是否相等 → true
```
3. **字符串数组**：可以把多个字符串放进数组，按元素操作
```MATLAB
names = ["张三","李四","王五"];
names(2)                     % → "李四"
contains(names,"李")         % 逐个判断是否包含 → [false true false]
```
4. **常用转换**：
```MATLAB
num2str(42)                  % 数字 → 字符 '42'
str2num('3.14')              % 字符 → 数字 3.14
string(42)                   % 数字 → "42"
double("3.14")               % 字符串 → 数字 3.14
```
5. **格式化输出**：
```MATLAB
name = '张三'; age = 20;
fprintf('我叫%s，今年%d岁\n',name,age);   % 直接输出
str = sprintf('我叫%s，今年%d岁',name,age); % 返回字符串
```

### 元胞数组（cell array）
> 元胞数组的每个"格子"（cell）可以存放**不同类型、不同大小**的数据，包括字符、数值矩阵、甚至另一个元胞数组。它是 MATLAB 存放"异构数据"最常用的容器，用 `{}` 建立和索引。

1. **创建**：
```MATLAB
% 方式一：直接赋值（注意用大括号）
c = {'hello', [1 2 3], 3.14, zeros(2,2)};

% 方式二：cell() 预分配，再逐个填充
c2 = cell(2,3);              % 2×3 的空元胞数组
c2{1,1} = '张三';
c2{1,2} = 90;

% 方式三：逐元素拼接
c3{1} = 'test'; c3{2} = 42;
```
2. **索引：`{}` 取内容，`()` 取格子本身**（这是最容易混淆的地方）
```MATLAB
c = {'hello', [1 2 3], 3.14};
c{1}          % 取出内容 'hello'
c(1)          % 取出仍是一个元胞 {'hello'}
c{1,2}        % 多下标取出内容
[c{1},c{2}]   % 用逗号列表展开多个元素
```
3. **常用函数**：
```MATLAB
celldisp(c)    % 逐格显示内容
cellfun(@(x)size(x),c)   % 对每格做同样运算，返回数组
numel(c)       % 格子数量 → 3
```
4. **典型应用——混合类型记录**（例如一个学生的多项信息）
```MATLAB
student = {'张三', 20, [89 92 95], '自动化'};
student{1}      % '张三'
student{3}(2)   % 第 3 格是个向量，取其中第 2 个 → 92
```

### 结构体（struct）
> 结构体用**字段名**（field）来组织数据，每个字段有自己的名字和值，适合描述一个对象的"属性集合"。通过 `.` 访问字段。

1. **创建与访问**：
```MATLAB
% 方式一：逐个字段赋值（自动创建结构体）
stu.name = '张三';
stu.id  = 2023001;
stu.grades = [89 92 95];

stu.name           % → '张三'
stu.grades(2)      % → 92

% 方式二：struct() 一次性创建
s = struct('name','李四','age',20,'score',88);
```
2. **结构体数组**：多个结构体组成数组，共享相同字段
```MATLAB
stu(1).name='张三'; stu(1).age=20;
stu(2).name='李四'; stu(2).age=21;
stu(1).name         % '张三'
[stu.name]          % 取出所有 name 字段 → '张三'  '李四'
{stu.name}          % 若字段是字符串数组，用 {} 取成一个元胞数组
```
3. **常用函数**：
```MATLAB
fieldnames(stu)    % 列出所有字段名 → {'name';'age'}
isstruct(stu)      % 判断是否为结构体
rmfield(stu,'age') % 删除字段
```
4. **嵌套与数组结构体**：字段里可以再放数组或结构体
```MATLAB
res.A = [1 2 3];               % 字段存一个向量
res.info.date = '2024-01-01';  % 嵌套结构体
res.info.class = '1班';
```

### 函数句柄（function handle）
> 函数句柄是对函数的"引用"或"指针"，用 `@` 创建。它可以像变量一样传递、存储和调用，是回调、数值求解、匿名函数的基石。

1. **创建与调用**：
```MATLAB
f = @sin;          % 指向内置函数 sin
f(pi/2)            % → 1，等价于 sin(pi/2)

% 匿名函数（用 @ 定义一个小函数）
g = @(x) x.^2 + 2*x + 1;
g(3)               % → 16
```
2. **多输入匿名函数**：
```MATLAB
h = @(x,y) x.^2 + y.^2;
h(3,4)             % → 25
```
3. **典型应用——作为参数传递**（回调、数值求根、积分）
```MATLAB
fzero(@(x)x^2-2,1)        % 求根 x≈1.414
fplot(@sin,[0,2*pi])      % 绘制 sin 曲线
integral(@(x)x.^2,0,1)    % 求定积分 → 1/3
```
4. **检查句柄**：
```MATLAB
func2str(@sin)     % 由句柄还原函数名 → 'sin'
str2func('cos')    % 由字符串生成句柄
isa(f,'function_handle')   % → true
```

### 多维数组与高维数组（N-D array）
> 向量是一维、矩阵是二维，MATLAB 支持三维及以上的数组（如 RGB 彩色图像就是 `m×n×3`）。创建和索引在维度上自然扩展。

1. **创建高维数组**：
```MATLAB
A = zeros(2,3,4);        % 2×3×4 的全零数组
B = ones(2,2,2,2);       % 四维数组
C = rand(3,3,3);         % 随机数数组
```
2. **索引与维度**：
```MATLAB
A(2,1,3)            % 访问第 3 层上的 (2,1) 元素
size(A)             % → [2 3 4]
ndims(A)            % → 3（维度数）
```
3. **升维与降维**：
```MATLAB
v = 1:4;            % 向量
reshape(v,2,2)      % 转为 2×2 矩阵
permute(A,[3 1 2])  % 交换维度顺序
squeeze(A)          % 去掉大小为 1 的维度
```
4. **典型应用**：彩色图像（`m×n×3`，3 个通道）、批量仿真结果堆叠。

### 表数据类型（table）
> `table`（R2013b 引入）把"列向量"组织在一起，每一列可以有不同的数据类型，但列名统一，适合存放类似 Excel/数据库的**表格型数据**。比 cell/struct 更适合做数据分析。

1. **创建**：
```MATLAB
Age = [20;21;22];
Name = ["张三";"李四";"王五"];
Score = [89;92;95];
T = table(Name,Age,Score)          % 用等长向量建立表
T = table(Name,Age,Score,'VariableNames',{'姓名','年龄','分数'})  % 自定义列名
```
2. **访问**：
```MATLAB
T.姓名            % 整列 → 元胞/字符
T(2,:)            % 取第 2 行
T{2,3}            % 按行/列索引取内容 → 92
T(T.分数>90,:)     % 逻辑筛选，取出分数 >90 的行
```
3. **常用函数**：
```MATLAB
height(T)    % 行数
width(T)     % 列数
summary(T)   % 每列的统计摘要
sortrows(T,'分数','descend')   % 按分数降序排序
```

### 分类数组（categorical）与时间日期（datetime/duration）

1. **categorical 分类数组**：把有限取值（类别）的字符串映射为紧凑的类别编码
```MATLAB
c = categorical(["男","女","男"]);   % 分类数组
categories(c)      % 列出所有类别 → {'男','女'}
c(1)               % → 男
```
2. **datetime 日期时间**：精确表示日期+时刻，支持运算和显示
```MATLAB
t1 = datetime('2024-01-01');
t2 = datetime('2024-01-10');
t2 - t1            % 两个日期相减 → duration（9 天）
year(t1)           % → 2024
```
3. **duration 时长**：一段时间的长度
```MATLAB
d = hours(2.5) + minutes(30);   % 2 小时 30 分
```
4. **datetime 格式化显示**：
```MATLAB
datetime('now','Format','yyyy-MM-dd HH:mm')   % 当前时间按指定格式显示
```

### 容器 Map（containers.Map）
> `containers.Map` 提供**键值对（key→value）**映射，很像 Python 的字典。键可以是非数值类型（如字符串），用 `keys` 和 `values` 组织。

1. **创建与访问**：
```MATLAB
m = containers.Map({'a','b','c'},{1,2,3});   % 键→值
m('a')            % → 1
m('b') = 99;      % 新增/修改
```
2. **常用方法**：
```MATLAB
keys(m)      % 所有键
values(m)    % 所有值
isKey(m,'a') % 判断键是否存在 → true
remove(m,'a')
```

### 类与对象（class / object，面向对象编程）
> MATLAB 支持**面向对象编程**：把数据（属性）与操作它的函数（方法）封装成"类"（class），由类创建"对象"（object）。它是"其他数据结构"的高级形式，可以定义**重载函数**（同名函数对不同类的对象做出不同处理）。在控制理论里最典型的就是**传递函数对象**。

1. **类的构成**：`classdef` 块中定义属性（数据）与方法（函数）
```MATLAB
classdef MyClass
    properties                       % 属性（数据）
        value
    end
    methods                          % 方法（操作）
        function obj = MyClass(v)    % 构造函数
            obj.value = v;
        end
    end
end
```
2. **创建对象与访问属性**：
```MATLAB
obj = MyClass(42);       % 用类名构造一个对象
obj.value                % 访问对象属性 → 42
```
3. **面向对象的意义**：把数据和对它的操作绑定在一起、支持方法重载，是图形界面（GUI）与传递函数类等"对象"编程的基础
4. **控制学科最核心的对象——传递函数**：
   - 传递函数由**分子、分母多项式**描述，MATLAB 用 `tf()` 创建**传递函数对象**
   - 之后可直接对该对象统一调用 `step()`（阶跃响应）、`bode()`（Bode 图）、`rlocus()`（根轨迹），无需再手动处理多项式——这正是"把数据与操作封装成对象"的价值（详见后续章节）
```MATLAB
num = [1 2]; den = [1 3 2];     % 分子、分母多项式系数（按降幂排列）
G = tf(num, den)                % 构造传递函数对象
step(G); bode(G); rlocus(G)     % 直接对对象做分析
```

### 数据结构小结
1. **变量名命名规则**：由字母引导，可含字母/数字/下划线，区分大小写；`i,j` 默认是虚数单位
2. **保留常量**：`eps, i, j, pi, NaN, Inf`, 以及 `lastwarn, lasterr`。其中 `i,j,eps,NaN,Inf` **可以改写**（但它们有特殊含义，改写后需自行恢复）
3. **计算用数据结构**及其区别：
   - **双精度** `double`——默认的 IEEE 64 位浮点，精度有限（约 15 位有效数字）
   - **符号型** `syms, sym, vpa`——保存精确的表达式/有理数，可任意精度运算、适合公式推导与解析解
4. **其他数据结构**：字符串、结构体、类与对象（含传递函数对象）等

## 矩阵与向量的输入方法
> 矩阵与向量是 MATLAB 的基本核心，其输入主要依靠**两种语句结构**：直接赋值语句与函数调用语句。

### 两种基本语句结构
#### 直接赋值语句
- 基本结构为 `变量 = 表达式;`
```MATLAB
A = [1 2 3; 4 5 6]    % 直接输入一个 2×3 矩阵
v = [1 2 3 4]         % 直接输入一个行向量
w = [1; 2; 3]         % 分号隔开，得到列向量
```
- **分号**的作用：语句末尾加分号可**阻止显示运算结果**；不加分号则立刻在命令行回显结果
```MATLAB
x = 2 + 3;     % 不回显
y = 2 + 3      % 回显 ans = 5
```
- **保留变量 `ans`**：存放最近一次"无赋值变量语句"的运算结果
```MATLAB
2 + 3          % 结果自动存入 ans
ans            % → 5
```

#### 函数调用语句
- 基本结构为 `[返回变量] = 函数名(输入变量);`
```MATLAB
[V,D] = eig(A)          % 返回矩阵 A 的特征向量 V 与特征值 D
m = size(A,1)           % 返回行的个数
M = magic(3)            % 生成 3×3 幻方矩阵
```
- 函数可以通过不同方式被调用：内核函数、`.m` 函数（M-文件）、**匿名函数**、`inline` 函数（不建议使用）、**重载函数**、私有函数等

### 实数矩阵与复数矩阵的输入
#### 例2-5 矩阵输入方法
- 表示矩阵时用**方括号 `[]`**，同一行元素用**逗号或空格**分隔，不同行用**分号或回车**分隔
```MATLAB
% 直接输入矩阵
A = [1 2 3; 4 5 6; 7 8 9]
% 等价写法（换行输入）
A = [1 2 3
     4 5 6
     7 8 9]
```
- 其他命令（动态定维）：先用 `zeros()`、`ones()` 等预分配再填充，或通过变量拼接
```MATLAB
B = [A A]          % 左右拼接
C = [A; A]         % 上下拼接
```
#### 例2-6 复数矩阵输入
- 复数可以用 `i` 或 `j`（推荐 `1i`、`1j` 更清晰），也可用 `complex()` 函数
```MATLAB
B = [1+2i, 3-4i; 5+i, 6-3i]      % 直接输入复数矩阵
% 或
B = [1 3; 5 6] + [2 -4; 1 -3]*1i
```
- **需要避免的语句**：把 `i`、`j` 当作普通变量使用（它们默认是虚数单位），或者在复数元素中混用不当写法的下标表达式

### 冒号表达式与子矩阵提取
#### 冒号表达式
- 冒号表达式是**定义行向量**的有效方法，格式为 `s1:s2:s3`
- 开始于值 `s1`，步长为值 `s2`，终止于值 `s3`；默认步长值为 1（`s1:s3`）
```MATLAB
1:5            % → [1 2 3 4 5]
0:2:10         % → [0 2 4 6 8 10]
10:-2:0        % → [10 8 6 4 2 0]
```
#### 例2-7 冒号表达式生成
- 用不同的步距生成向量：
```MATLAB
t = 0:0.1:2        % 步长 0.1
```

#### 子矩阵提取
- 基本语句格式：`A(v1, v2)`，其中：
  - `v1` 表示子矩阵要**保留的行号**构成的向量
  - `v2` 表示要**保留的列号**构成的向量
  - `:` 表示提取所有行或列（取决于其位置）
  - `end` 表示最后一个下标
```MATLAB
A = [1 2 3; 4 5 6; 7 8 9];
A(1:2, 2:3)      % 保留第 1~2 行、第 2~3 列
A([1 3], :)      % 保留第 1 行和第 3 行所有列
A(:, end)        % 取最后一列
A(end, :)        % 取最后一行
```
#### 例2-8 子矩阵提取
- 对矩阵 `A` 的不同子矩阵提取：
```MATLAB
A(2, 3)          % 单个元素，第 2 行第 3 列 → 6
A(2:end, 1:2)    % 第 2 行到最后一行，第 1~2 列
A([1 2], [2 3])  % 交错保留行、列
```

## 矩阵的代数运算
> 矩阵的代数运算包括：转置、加减、乘法、除法、翻转、乘方与点运算；此外还有针对"元素级"的逻辑运算、比较运算，以及针对符号表达式的化简与数论运算。

### 矩阵转置
- 矩阵 `A`（n 行 m 列）记作 `n×m` 矩阵
- **一般转置**：`A'`（转置，行变列）
- **Hermite 转置**（共轭转置）：`A'`；实数矩阵的转置就是 `A.'`（点转置，不取共轭）
```MATLAB
A = [1 2 3; 4 5 6];
A'          % 共轭转置（实数时即普通转置）→ 3×2
A.'         % 只转置不共轭，对实数相同
```
- **区别**：对复数矩阵，`A'` 是共轭转置（转置+取共轭），`A.'` 是仅转置

### 加减法运算
- MATLAB 语法：`C = A + B` 或 `C = A - B`
- 注意：任一个变量可以为**标量**；若矩阵维数不匹配，系统会**报错**
```MATLAB
A = [1 2; 3 4];
B = [5 6; 7 8];
C = A + B        % 对应元素相加 → [6 8; 10 12]
D = A - B        % 对应元素相减
E = A + 10       % 标量可直接加
```

### 矩阵乘法
- 数学表示：`C = A B`，MATLAB 语法：`C = A * B`
- 系统**自动检测矩阵维数是否匹配**（A 的列数必须等于 B 的行数）；可直接用于标量、复数等
```MATLAB
A = [1 2; 3 4];
B = [5 6; 7 8];
C = A * B        % 行 × 列 的内积
```

### 矩阵的除法
#### 左除 `\`
- 用于求解线性方程组 `A x = B`，MATLAB 解法：`x = A \ B`
- 若 `A` 为非奇异方阵，则 `x = A \ B` 即为精确解；若超定，得到**最小二乘解**（使误差最小）
```MATLAB
A = [2 1; 1 3];
b = [1; 2];
x = A \ b        % 求解 Ax = b
```
#### 右除 `/`
- 求解线性方程组 `X A = B`，MATLAB 解法：`X = B / A`
- 等效运算：`B / A` 与 `B * inv(A)` 等价（但 `/` 更稳定、更推荐）

### 矩阵翻转
```MATLAB
A = [1 2 3; 4 5 6];
fliplr(A)      % 左右翻转 → [3 2 1; 6 5 4]
flipud(A)      % 上下翻转 → [4 5 6; 1 2 3]
rot90(A)       % 旋转 90°
rot90(A, 2)    % 旋转 180°（即两次 90°）
```

### 矩阵乘方
- 求矩阵 `A` 的 `x` 次幂：`A^x`，要求 `A` 必须为**方阵**
- `x` 为整数：`A^2 = A*A`；`x` 为非整数：会用到特征值分解
- **开方的多解**：`A^(1/3)` 得出的一个解，该解的 `k-1` 次标量倍（乘以旋转因子）为此矩阵的其他根
```MATLAB
A = [2 1; 1 2];
A^2          % 矩阵乘方
```
#### 例2-9 矩阵的三次方根
- 求矩阵 `A` 的全部三次方根并检验：`A^(1/3)` 只给出一个根，另两个根由该根乘以旋转因子得到
```MATLAB
A = [2 1; 1 2];
X = A^(1/3)          % 一个三次方根
X^3                  % 检验是否等于 A
```

### 点运算
- 点运算是对矩阵**对应元素的直接运算**，在运算符前加一个点：`.*`、`./`、`.^`
- 例：`A.^2` 是每个元素平方；`A.*B` 是对应元素相乘
```MATLAB
A = [1 2; 3 4];
A.^2          % 每个元素平方 → [1 4; 9 16]
A .* A        % 对应元素相乘
```
- **应用举例：绘图**时常用点运算对向量逐元素计算函数值，如 `y = t.^2 .* exp(-t)`

## 矩阵的其他运算
### 矩阵的逻辑运算
- **逻辑变量**：当前版本有逻辑变量，**非 0 表示逻辑 1**，0 表示逻辑 0
- 逻辑运算是**相应元素之间**的运算，相当于点运算
```MATLAB
A = [1 2 0]; B = [0 2 3];
A & B          % 与运算（对应元素都为真才真）
A | B          % 或运算
~A             % 非运算
xor(A, B)      % 异或运算
```

### 矩阵的比较运算
- 各种允许的比较关系：`>`, `>=`, `<`, `<=`, `==`, `~=`, `find()`, `all()`, `any()`
```MATLAB
A = [1 2 3; 4 5 6];
A > 3          % 元素级比较，返回逻辑数组
find(A > 4)    % 找出满足条件的元素位置（线性索引）
all(A > 0)     % 是否所有元素都大于 0
any(A > 5)     % 是否存在元素大于 5
```
#### 例2-10 比较运算实例
- 通过比较运算配合逻辑索引，快速筛选出满足条件的元素。

### 解析结果的化简与变换
- 函数 `simplify()` 用于数学公式的化简
- 其他常用化简函数：`numden()`（提取分子分母）、`collect()`（合并同类项）、`expand()`（展开）、`factor()`（因式分解）
```MATLAB

numden((x^2)/(x+1))             % 分子、分母

```
#### 数论运算与基本数据运算
- 常用计算函数：取整（`round`, `ceil`, `floor`, `fix`），求商余、最大公约数、最小公倍数等
#### 例2-11 多项式处理
- 化简多项式、用不同函数求解、因式分解与展开：

```MATLAB
p = x^3 - 6*x^2 + 11*x - 6;

```

### 变量替换与 LaTeX
- **变量替换语句**：`subs(expr, old, new)` 执行点运算替换；`subs(expr, {old1, old2}, {new1, new2})` 同时替换若干个变量
- **转换成 LaTeX 表示**：`latex(expr)` 得出字符串，需要 LaTeX 环境解释

#### 例2-12 双线性变换
- 用变量替换对多项式 `P(s)` 做双线性变换（如 `s = (z-1)/(z+1)`），使用 `subs()` 实现。

### 基本数论运算
- 常用函数：取整（`round/ceil/floor/fix`）、`gcd`（最大公约数）、`lcm`（最小公倍数）、`factor`（质因数分解）、`perms`（全排列）、`isprime`（素数判断）
#### 例2-13 不同的取整函数
- 对数据 `-0.2765, 0.5772, 1.4597, 2.1091, 1.191, -1.6187` 做取整：

```MATLAB
x = [-0.2765, 0.5772, 1.4597, 2.1091, 1.191, -1.6187];
```

#### 例2-15 最大公约数与最小公倍数

## MATLAB的流程控制结构
> 利用流程结构可以编写出复杂程序。MATLAB 支持的流程结构主要有四种：**循环结构**（for、while）、**转移结构**（if）、**开关结构**（switch）、**试探结构**（try/catch）。

### for 循环结构
- 基本结构：`for i=v` ... `end`
- `v` 为一个向量，循环变量 `i` 每次从 `v` 中取一个数值，执行一次循环体；直至遍历完 `v` 中所有分量
- `v` 的内容**可以任意排列**；这与 C 语言类似，但更灵活（`for i = 1:2:100`）
```MATLAB
for i = 1:5
    disp(i)       % 依次输出 1 2 3 4 5
end

for i = [3 1 4 2] % 向量的内容可任意排列
    disp(i)
end
```

### while 循环结构
- 基本结构：`while 条件` ... `end`
- `while` 结构的特点是可以**设置出口**（条件不满足时退出）
- `for` 和 `while` 侧重点不同：`for` 适合已知次数的遍历，`while` 适合"满足某条件才停止"的循环
```MATLAB
m = 0;
while m < 10
    m = m + 1;
end
disp(m)         % → 10
```

### 循环结构实例
#### 例2-18 循环求解
- 用循环求和：`sum` 也可以用向量化方法一次完成
```MATLAB
s = 0; for i = 1:100, s = s + i; end
% 更简单：s = sum(1:100)
```
#### 例2-19 While 循环
- 用循环求最小的 `m` 使下式成立（未知次数，用 while 最合适）
```MATLAB
s = 0; m = 0;
while s < 100
    m = m + 1; s = s + m;
end
```
- **这里不宜用 for 结构**，因为循环次数事先并不知道
#### 例2-20 向量化编程
- 求和既可用循环结构，也可用向量化运算方法（`sum` 更加高效）
```MATLAB
s = sum(1:100)     % 向量化，效率更高
```

### 条件转移结构（if）
- 基本结构：`if 条件` ... `elseif` ... `else` ... `end`
```MATLAB
if x > 0
    disp('正数');
elseif x < 0
    disp('负数');
else
    disp('零');
end
```
#### 例2-21 for 循环
- 用 for 循环求最大的 `m` 使下式成立：
```MATLAB
s = 0;
for m = 1:100
    if s + m > 100, break; end   % break 终止循环
    s = s + m;
end
```
- **远比 while 结构繁琐**——说明"已知次数用 for，未知次数用 while"的取舍

### 开关结构（switch）
- 基本结构：`switch 表达式` ... `case 值1` ... `otherwise` ... `end`
- **与 C 语言不同之处**：MATLAB 的 switch 匹配后**不需要 break**，且 `case` 可以是多个值的元胞数组
```MATLAB
switch grade
    case 'A'
        disp('优秀');
    case {'B','C'}
        disp('良好/中等');
    otherwise
        disp('其他');
end
```

### 试探结构（try/catch）
- **全新结构**：`try` ... `catch` ... `end`
- **优点**：设置**错误陷阱**，程序出错时不会中断而是转入 catch 处理；提高**算法的执行效率**
```MATLAB
try
    A = [1 2 3];
    B = A(5);         % 越界访问会出错
catch
    disp('出错，已捕获');   % 也能处理
end
```

### 控制流程结构小结
1. 循环结构的两种形式：`for` 与 `while`，各有优缺点与适用范围；`break` 可终止当前循环
2. 条件转移语句：`if else elseif`
3. 开关结构：`switch case`，及其与 C 语言的异同
4. 试探结构：`try catch`

## MATLAB函数编写
> 编程分为**脚本程序**与 **M-函数**（主流）。函数把输入变量处理后返回结果，是模块化、可复用的核心。

### 为什么使用 MATLAB 函数？
#### 例2-22 M-脚本文件实现
- M-脚本以 M-文件的形式存储，按顺序执行；但其缺点是**不易复用**
- 若最大值为 `N` 会变，M-文件就需要被修改
- **为什么需要函数**：M-函数以**输入变量**（如 `N`）与**返回变量**（如 `s, m`）的形式封装，修改参数只需改调用处，无需改程序本身

### MATLAB 语言函数的基本结构
- **信息处理单元**：`输入变量 → 函数 → 返回变量`
- 由 `function` 关键词引导，返回变量在前、输入变量在后：
```MATLAB
function [s, m] = myfun(N)
    % 函数体
    s = sum(1:N);  m = max(1:N);
end
```
#### 例2-23 M-函数实现
- 编写 M-函数，优点：**无需修改程序**，只需改变传入的 `N`
#### 例2-24 Hilbert 长方形矩阵
- 编写函数生成 `n×m` Hilbert 矩阵：
  - 输入变量：`n, m`，输出变量 `H`
  - 若只给出一个输入参数，则自动生成方阵
  - 在函数中给出合适的帮助信息
  - 检测输入和返回变量的个数 `nargin`、`nargout`
```MATLAB
function H = myhilb(n, m)
    if nargin == 1, m = n; end      % 只给一个参数时生成方阵
    for i = 1:n, for j = 1:m
        H(i,j) = 1/(i+j-1);
    end, end
end
% 帮助信息写在 function 行后的注释中，用 help myhilb 查看
```

### 递归调用与阶乘
#### 例2-25 阶乘的递归调用
- 利用函数的**递归调用**计算阶乘：
```MATLAB
function f = fact(n)
    if n <= 1, f = 1;              % 出口设置（关键）
    else f = n * fact(n-1); end    % 递归调用
end
```
- **存在的问题**：必须设置**出口**（递归终止条件），并检测变量，否则会无限递归
#### 阶乘的不同计算方法（计算 11!）
```MATLAB
fact(11)                 % 自己写的递归函数
prod(1:11)               % prod 求连乘
factorial(11)            % MATLAB 内置阶乘函数
sym('11!')               % 符号运算
```

### 可变输入输出个数的处理
- **varargin、varargout**：处理可变个数的输入/输出变量
- 变量的提取——用**单元数组（cell）**：`varargin{1}, varargin{2}, ..., varargin{n}`
```MATLAB
function y = mymul(varargin)
    y = varargin{1};
    for i = 2:length(varargin)
        y = y * varargin{i};
    end
end
```
#### 例2-27 任意多输入变元
- `conv()` 可计算两个多项式的积；用 `varargin` 实现**任意多个多项式的积**：
```MATLAB
function p = myconv(varargin)
    p = varargin{1};
    for i = 2:length(varargin)
        p = conv(p, varargin{i});   % 每次从 varargin 中取一个做累乘
    end
end
```

### inline 函数与匿名函数
- **inline 函数**（功能重叠，**不建议使用**）：免去编辑 M-文件
- **匿名函数**（MATLAB 7.0 以上版本）：`@(输入) 表达式`；工作空间内的变量可直接使用
```MATLAB
f = @(x) x^2 + 2*x + 1;    % 匿名函数
f(3)                       % → 16
g = inline('x^2+2*x+1')    % inline，已不建议
```

### 伪代码与代码保密处理
- **伪代码化的目的**：提高程序的执行速度；**保密**——把 ASCII 的 `.m` 文件转换成二进制代码
- **伪代码语句**：`pcode myfile` 生成 `.p` 文件
- **重要提示**：`p` 文件是**不可逆**的，用户一定要在安全位置保留 `.m` 源文件，不能轻易删除
```MATLAB
pcode myfun        % 生成 myfun.p
```

### MATLAB 函数编写小结
1. 为什么需要函数结构而不是脚本结构（复用、参数化）
2. 函数的入口与输入输出变元处理：`function` 关键词引导；`nargin, nargout`；`varargin, varargout`
3. 递归调用结构（注意出口设置）
4. 匿名函数、伪代码技术 `pcode`

## 二维图形绘制
> 科学可视化在科研中很重要，图形的本质是把数据直观地表示出来。

### 二维图形绘制基本语句
#### 已知数据绘图
- 用两个序列构造向量（`x` 和 `y` 等长），再绘图：
```MATLAB
t = 0:0.1:2*pi;
y = sin(t);
plot(t, y)         % 基本绘图
```

- 描述函数再绘图：`fplot` 自动选取步长

```MATLAB
fplot(@sin, [0 2*pi])          % 由函数句柄绘图

```
#### 例2-28 函数曲线绘制与检验
- 绘制函数曲线后**如何检查曲线**：用不同的步距（步长）看看能否得出同样的结果，以判断步长是否足够
#### 变步长向量

- 绘制饱和函数（分段函数），用互斥条件或折线 `plot`：


### 其他调用格式
- `t` 为向量、`y` 为矩阵：对 `y` 的每一列都画一条曲线
- `t` 和 `y` 为矩阵且行列数相同；或提供多对这样的向量/矩阵
- **更一般调用格式**：改变曲线性质（颜色、线型、标记）——`plot(x, y, 'r--')`、`plot(x, y, 'LineWidth', 2)`

### 图形修饰与属性设置
- 每一个窗口、曲线和坐标轴都是一个**对象**（图形对象）
- 对象的属性可以通过函数 `set()` 设置，通过 `get()` 获取
- 图形的属性还可以通过**快捷菜单（鼠标右键）**直接修改
```MATLAB
h = plot(t, y);
set(h, 'LineWidth', 2, 'Color', 'r')   % 设置属性
xlabel('时间 t'); ylabel('幅值 y'); title('曲线');
grid on
```
#### 例2-30 多纵轴曲线的绘制
- 若两条曲线**幅值相差悬殊**，调用**双纵轴**绘制函数 `plotyy()`
```MATLAB
t = 0:0.01:2*pi;
plotyy(t, sin(t), t, 100*cos(t))   % 左右两个纵轴
```
- 三、四纵轴图形可从 MathWorks File Exchange 下载 `plotyyy()`、`plot4y()`，或用 `plotxx()` 函数

3. 图形对象的句柄（`set`/`get`）
4. 多纵轴图形的绘制方法 `plotyy`；多横轴图形

## 面向对象的程序设计基础
> 图形界面的优劣往往决定着软件的档次。MATLAB 的图形用户界面（GUI）设计技术对设计出良好的通用软件十分重要。

### 主要内容
- 图形界面设计工具 **Guide**
- 句柄图形学及句柄对象属性
- 菜单系统设计
- 界面设计举例与技巧
- 工具栏设计

### 句柄图形学及句柄对象属性
- 图形用户界面编程主要是对**各个对象属性的读取和修改**技术
- **窗口**是一个对象，其上面的**每个控件**也都是对象，每个对象都有自己的属性
- 双击对象可打开对象属性浏览器；用 `set` 和 `get` 函数设置、读取属性
- 例：通过属性浏览器改变窗口属性（如颜色）

### 窗口对象的常用属性
| 属性 | 说明 |
|------|------|
| `MenuBar` | 设置图形窗口菜单形式 |
| `Name` | 设置图形窗口标题栏中的内容 |
| `Units` | 窗口尺寸单位，默认 `pixels`，还有 `normalized`、`inches` |
| `Position` | 窗口位置属性：左下角坐标 + 宽度、高度 4 个参数构成的向量 |
| `Toolbar` | 图形窗口可视编辑工具条 |
| `Visible` | 建立的窗口是否可见 |

### 控件的属性
- 双击控件打开属性编辑器
- **Tag 属性**：起有意义的名字，建议加前缀（`txt`、`btn`、`edt`、`chk`）
- **String 属性**：标注该控件的字符串
- **Units 与 Position 属性**：与窗口定义一致
- **Enable 属性**：表示此控件的使能状态
- **CData 属性**：将真色彩图形标注到控件上
- **UserData 属性**：控件之间数据交换与暂存，可存储复杂的变量（如单元数组）
- **FontSize 等属性**：可用 `set`、`get` 命令修改

### 对象属性的读取与修改
- 关键函数 `set` 和 `get`
- 常用的句柄：
  - `gcf`：得到当前窗口的句柄
  - `gco`：获得当前对象的句柄
  - `gca`：获得当前坐标系的句柄
  - `gcs`：获得当前 Simulink 模型的句柄
```MATLAB
set(gcf, 'Color', 'w')     % 设置当前窗口背景为白色
get(gca, 'XLim')           % 获取当前坐标轴的范围
```

### 图形界面设计工具 Guide
- 图形用户界面设计的两个内容：
  1. **画界面**：`guide` 命令启动图形用户界面设计程序；设置相关的初始属性
  2. **编程**：赋予功能；面向对象编程，区别于以往的编程方法
- **任务分派**：哪些控件是接收用的、哪些有主动动作；主要靠 `get` 和 `set` 两个命令读取、修改属性

### 简单的界面设计（例2-30）
- 设计一个窗口，有两个控件：**按钮**和**文本**；按钮按下后在文本位置显示 "Hello world!"
- 绘制原型窗口：打开空白原型窗口并绘制这两个控件
- 控件属性修改：
  - 文本控件的 **String 属性**先设置成空白字符串
  - **Tag 属性**很关键，设置成 `txtHello`
- 自动生成框架文件：把窗口存成 `.fig` 文件（如 `c2eggui1.fig`），会自动生成 `c2eggui1.m` 文件
- 程序框架的结构：主程序、打开窗口子函数、输出函数

### 图形用户界面设计（小结）
1. 对象的基本概念：窗口是对象，控件是对象，菜单等也是对象
2. 控件属性的编辑，**Tag 很重要**（有意义、独一无二）
