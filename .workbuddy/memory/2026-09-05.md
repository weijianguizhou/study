### 可复用经验
- **解析 md 清单的坑**：天标题带后缀（`### 10月1日 周四 · 第31天（国庆）`）用 `$` 结尾的正则会漏匹配，
  基础期漏 4 天、冲刺期漏 6 天。正则要写成 `第\s*(\d+)\s*天\s*(?:（([^）]*)）)?\s*$`，顺便把后缀提成 tag。
  校验手段：解析后打印每周天数，与「周标题里的日期范围」比对。
- **无 agent-browser 时的冒烟方案**：本机有 Chrome，
  `chrome.exe --headless=new --disable-gpu --no-sandbox --virtual-time-budget=6000 --dump-dom "file:///..."`
  即可 dump 渲染后的 DOM。再往 `<title>` 前插一段 `window.onerror` 捕获 + `setTimeout` 模拟点击并把结果写进
  `document.title`，就能在无头环境下同时验证「零运行时错误」和「交互链路」。比装 agent-browser（500MB）轻得多。
- `lint_database_sdk_usage.py` 两个必过项：① 含 `addRecord` 的页面必须有 `localStorage.removeItem/clear`
  （DSDK008）② 渲染 database 数据的页面要给 `<body>` 加 `data-sp-bindable="database" data-sp-database-id="<dbId>"`（DSDK012）。
- `create_database.py --help` 在无 token 时报 AUTH_REQUIRED，有 token 时报 schema 错误——没有真正的 help，

## 修复：六级备考计划台「离线模式无法保存进度」

- 现象：用户反馈离线模式下勾选进度刷新后丢失。
- 根因（推断 + 实测）：资料库 page 在 iframe-sandbox 内渲染（`library/page/database-sdk-contract.md#L8`
  明确「平台 iframe-sandbox 会在用户脚本前注入 SDK」），且 `data-page-flow.md` 注释「storage 不可用静默降级」。
  当 SDK 未注入（未登录/离线）且 iframe 为 opaque origin 时，`localStorage` 访问抛 `SecurityError`，
  原 `saveLocal()/loadLocal()` 的 `try/catch` **静默吞掉错误** → 进度既没进本机也没进云端，刷新即丢。
  本地 `file://` 打开的副本实测 localStorage 可用（Chrome 支持），因此该问题只发生在资料库内联渲染态。
- 修复（`template.html` 同步改 `build/`、`英语/六级备考计划台.html`、`.workbuddy/outputs/`）：
  1. 启动时 `probeLS()` 探测 localStorage 可用性，失败记录 `LS_ERR`（不再静默）。
  2. `saveLocal()` 失败不再吞错，返回 false；勾选时若「写本机失败且未连资料库」弹一次 `alert` 明确告知。
  3. 新增顶部红色告警条 `persistNotice`（「本机存储被禁用 + 未连资料库 → 进度无法保存」）+ 我的页
     `diagBox` 存储诊断（资料库/本机存储/最近写入/同步状态/已记录天数）。
  4. 同步层：`pendingKeys()` 计算待推送队列；`pushPending` 联网即推、`bindSyncEvents` 监听 `online`/
     `visibilitychange`/`beforeunload` 断网期间改动自动补推；失败按 5/15/40/90s 退避重试（非轮询）。
  5. `seedIfNeeded()` 移到 `pullRemote` 之后调用，避免新设备用 md 预置数据覆盖旧设备远端进度。
- 验证：inject 自检全绿 + `lint_database_sdk_usage.py` => `MINDX_DBSDK_LINT_OK`；headless Chrome 实测
  A) 本地 `file://` 勾选 189 字节写入并回读成功；B) 在 `<head>` 注入「localStorage 抛 SecurityError」模拟沙箱，
  页面正常渲染、告警条显示、诊断正确（本机存储 不可用 SecurityError / 同步状态 离线 进度无处可存），不崩溃。
