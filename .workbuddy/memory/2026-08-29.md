- 最终验收：9 个文件全部生成，真实残留问题 0；38 处图片引用全部命中；未解析引用 0；`$$` 围栏全配平；无 NUL 污染。第十章参考笔记未被改动。
- 输出约定：`# 第X章 标题` / `##` 节 / `###` 小节 / `####` 段；`> [!type] 标题` callout；`![[图片.png]]`；Markdown 表格；`$…$` 与 `$$…$$`。

### 踩过的坑（高度可复用）
1. **清理文本必须先保护数学**：用 `\x00N\x00` 占位符 stash `$$…$$` 再 stash `$…$`，清理只作用于纯文本段；否则 `\bm`/`\left\{` 等会被破坏。
2. **占位符嵌套**：`$$y$$` 被先 stash 后，外层 `$…$` 又把它包进去，导致内层占位符无法还原（表现为公式里出现裸数字索引 `0`，两侧是看不见的 NUL）。**必须递归展开占位符**直到稳定。
3. **相邻行内数学 `$x$$y$$z$`**：正确拆分规则是「内容短且不含反斜杠/等号/空格」的相邻 token 之间插 `, `，即
   `(\$[A-Za-z0-9_\^\{\}]{1,4}\$)(?=\$[A-Za-z0-9_\^\{\}]{1,4}\$)` → `\1, `。
   宽泛规则会把真显示公式 `$$…$$` 拆坏，也可能吞掉后一个变量的起始 `$`。
4. **`$$…$$` 与 `$…$` 天然歧义**：`$x$$y$$z$` 既可解析为「x 行内 + y 显示 + z 行内」，也可解析为三个行内。靠内容复杂度判别（显示公式必含命令或 `=`/空格）。
5. **星号形式的章节命令** `\section*{…}` 要单独匹配，否则原样残留。
6. **`\uppercase\expandafter{\romannumeral1}`**：源里花括号是**未转义**的 `{`，正则要写 `\{\\romannumeral(\d+)\}`；且必须在 `\{`→`{` 去转义之前处理。
7. **`\label` 被提前剥掉**：`box_handler` 里先跑了 `resolve_refs`（会删 `\label`），导致 `convert_figure/convert_table` 读不到标签。**必须在处理原文时先登记图表标签**。
8. **引用要两遍解析**：盒子内嵌的图表在处理顺序上晚于盒内 `\ref`，一遍解析会把裸 key 永久写死。做法：`resolve_refs` 只替换已登记的 key（未命中则原样保留），全部盒子处理完后再解析一遍，最后用 `finalize_refs` 兜底去掉 `fig:/tab:/eq:/sec:` 前缀。
9. **跨章引用**：章内 `state['labels']` 无法解析别的章的 `sec:` 标签 → 预扫全部源文件建全局标签表 `build_global_labels()`，登记「节标题」与「`\label` 附近的 `\caption`」。
10. **嵌套盒子必须先内后外**：先 `process_boxes(inner)` 再加 callout 的 `> ` 前缀，否则 `> ` 会落到原始 LaTeX 上，表格转换后 `> ` 混进单元格（表现为 `| > ` / `> 行 |`）。
11. **花括号包裹清理不能跨 `}`**：`\{\s*(\*[^*]+\*)\s*\}` 中的 `[^*]+` 会跨过 `}`，把一行里两个 `\multirow{2}{*}{…}` 粘在一起破坏掉 → 必须写成 `[^*}]+`。
12. **脚注要放在 `process_boxes` 之前处理**，否则 callout 的 `> ` 会混进脚注正文；脚注在 callout 内部时不要用 callout 渲染（嵌套需 `>>`），改成行内 `（脚注：…）` 最稳妥。
