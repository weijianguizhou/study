## 三个模块

1. **今日** —— 今天的任务清单 + 逾期未完成区。前几天没勾完的任务自动滚到这里标红，按天折叠，点开即可补勾。
2. **计划表** —— 按阶段切换，周卡片显示完成进度条，展开看每天任务；默认展开当前周和今天。
3. **我的** —— 考试倒计时（日期可改）、总进度概览、导出/导入 JSON、清空数据（需输入「清空」）。

顶部常驻条：今天日期 · 计划第 N 天 · 今日 x/y · 逾期 N 天/N 项（点击直达）· 距考试 N 天 · 同步状态。

## 数据与同步

- 即时写 localStorage（键 `wb_cetplan_v1`），断网照常用。
- 联网时通过资料库在线表双向同步：按「更新时间」时间戳仲裁，哪边新以哪边为准；勾选变化 600ms 后回推。
- `db.onUpdated` 订阅：他端改动会触发本页 300ms 去抖后重新拉取。
- 清空数据会同时删除本机记录和在线表中的全部记录。

## 本次修复：离线模式无法保存进度（2026-09-05）

**问题**：在资料库内联渲染态（iframe-sandbox）下，本机 `localStorage` 可能因 opaque origin 不可用，
原 `saveLocal()` 的 `try/catch` 静默吞掉了错误，导致进度既没存本机也没存云端、刷新即丢；且顶部一直显示「离线模式」但无任何提示。

**已修**：

1. 启动探测 localStorage 可用性，失败记录原因、不再静默。
2. `saveLocal()` 失败返回 false；若「写本机失败 + 未连资料库」则弹一次明确提示。
3. 顶部新增红色告警条 `（本机存储被禁用 + 未连资料库 → 进度无法保存，请导出留底）`；「我的」页新增「存储诊断」卡，
   实时显示：资料库是否连接 / 本机存储是否可用 / 最近写入时间 / 同步状态 / 已记录天数。
4. 同步层改造：计算待推送队列，监听 `online`/`visibilitychange`/`beforeunload`，断网期间的勾选在恢复连接后自动补推；
   推送失败按 5/15/40/90s 退避重试（非轮询）。
5. 预置数据 `seedIfNeeded()` 移到拉取远端之后，避免新设备用 md 预置覆盖旧设备进度。
