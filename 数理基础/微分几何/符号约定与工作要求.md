## 1. 符号约定

### 1.1 字型（粗体 / 正体）

| 对象 | 记号 | 说明 |
|---|---|---|
| 向量（含希腊字母） | `\boldsymbol{...}` | 位置向量 $\boldsymbol{r}$、切向量 $\boldsymbol{r}'(t)$、$\boldsymbol{r}_u$、$\boldsymbol{a}\times\boldsymbol{b}$ |
| 单位向量 / 单位向量组 | `\mathbf{...}` | $\mathbf{T}$、$\mathbf{N}$、$\mathbf{B}$、$\mathbf{n}$、$\mathbf{e}_i$ |
| 标量、系数、曲率 | 不加粗 | $E,F,G$、$L,M,N$、$\kappa,\tau,K,H$、$s$ |

**关键规则：**
- 一般向量与位置向量用 `\boldsymbol`；**模长为 1 的单位向量用 `\mathbf`**：
  Frenet 标架 $\mathbf{T},\mathbf{N},\mathbf{B}$、曲面法向量 $\mathbf{n}$、活动标架 $\mathbf{e}_i$。
- 第一/第二基本形式系数 $E,F,G$、$L,M,N$ 为标量，**不加粗**；
  系数 $N$ 与主法向量 $\mathbf{N}$ 用正粗体区分。
- 微分形式 $\omega^{i}$、$\omega_{i}^{j}$ 与各系数均不加粗（形式不是向量）。
- `\mathbf` 对希腊字母不生效，希腊向量一律用 `\boldsymbol`。

## 2. 工作要求（编辑规范）

### 2.1 公式环境

- 所有行间公式一律用 `equation` 环境并加 `\label`；
- **禁止** `$$...$$`、裸 `$$`、行内散落的 `(1)`、`(2)`… 手写编号、`\tag{}`；
- 多行公式用 `aligned` / `cases` / `equation` 组合。

### 2.2 label 命名

格式：`eq:小节:描述`，描述可用中文。

例：
```latex
\label{eq:曲率:定义}
\label{eq:Frenet公式:矩阵形式}
\label{eq:高斯曲率:定义}
\label{eq:曲面:Gauss方程}
\label{eq:附录:球面曲线关系}
```

### 2.3 交叉引用

- 用 `\eqref{label}`（编号带括号）、`\ref{label}`、`\pageref{label}`；
- 正文提到某式时写「由式~\eqref{...}」；
- 引用定理用 `\ref{thm:...}`。

### 2.4 记号一致性检查清单

- [ ] 一般向量与位置向量用 `\boldsymbol`，单位向量（T/N/B/n/e）用 `\mathbf`；
- [ ] 系数 $E,F,G$、$L,M,N$ 与曲率 $\kappa,\tau,K,H$ 不加粗；
- [ ] 微分形式 $\omega^{i}$、$\omega_{i}^{j}$ 不加粗；
- [ ] 外积用 `\wedge`，微分用 `\mathrm{d}`（正体）；
- [ ] 无手写编号 `(n)`，全部 `\eqref`；
- [ ] 基本形式符号用正体 `\mathrm{I}`、`\mathrm{II}`。
