# 主成分分析

参考：[[../代数/Linear algebra|线性代数]]

---

## 一、概述

主成分分析（Principal Component Analysis, PCA）是一种**线性降维**技术。其目标是通过正交变换将 $p$ 个可能相关的变量转换为 $m$ 个互不相关的主成分（$m \leq p$），同时尽可能保留原始数据的方差信息。

核心性质：
- 第一主成分具有最大方差
- 各主成分之间**互不相关**（正交）
- 主成分是原始变量的线性组合
- 降维时按方差降序保留前 $m$ 个主成分

---

## 二、数学原理

### 2.1 数据预处理

设数据矩阵 $\mathbf{X}$ 为 $n \times p$（$n$ 个样本，$p$ 个变量）。中心化后：

$$
\mathbf{X}_c = \mathbf{X} - \mathbf{1}_n \bar{\mathbf{x}}^T
$$

样本协方差矩阵（原始尺度）：

$$
\mathbf{S} = \frac{1}{n-1} \mathbf{X}_c^T \mathbf{X}_c
$$

若变量量纲不同，应先**标准化**：

$$
Z_{ij} = \frac{X_{ij} - \bar{X}_j}{S_j}
$$

标准化后 $\mathbf{S}$ 退化为样本相关矩阵 $\mathbf{R}$：

$$
\mathbf{R} = \frac{1}{n-1} \mathbf{Z}^T \mathbf{Z}, \quad R_{ij} = \frac{S_{ij}}{\sqrt{S_{ii} S_{jj}}}
$$

### 2.2 协方差矩阵的特征分解

对半正定矩阵 $\mathbf{S}$ 进行谱分解：

$$
\boxed{\mathbf{S} = \mathbf{U} \boldsymbol{\Lambda} \mathbf{U}^T = \sum_{k=1}^{p} \lambda_k \mathbf{u}_k \mathbf{u}_k^T}
$$

其中：
- $\boldsymbol{\Lambda} = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_p)$，且 $\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_p \geq 0$
- $\mathbf{U} = [\mathbf{u}_1, \mathbf{u}_2, \ldots, \mathbf{u}_p]$ 为 $p \times p$ 正交矩阵（$\mathbf{U}^T\mathbf{U} = \mathbf{I}$）
- $\mathbf{u}_k$ 为第 $k$ 个特征向量（主成分方向）

### 2.3 主成分的定义

第 $k$ 个主成分是所有标准化原始变量的线性组合：

$$
\boxed{Z_k = \mathbf{u}_k^T \mathbf{X} = u_{k1} X_1 + u_{k2} X_2 + \cdots + u_{kp} X_p}
$$

**方差**：

$$
\text{Var}(Z_k) = \mathbf{u}_k^T \mathbf{S} \mathbf{u}_k = \lambda_k
$$

**协方差**：

$$
\text{Cov}(Z_i, Z_j) = \mathbf{u}_i^T \mathbf{S} \mathbf{u}_j = \lambda_j \mathbf{u}_i^T \mathbf{u}_j = 0 \quad (i \neq j)
$$

**总方差不变**：

$$
\sum_{k=1}^{p} \text{Var}(Z_k) = \sum_{k=1}^{p} \lambda_k = \text{tr}(\mathbf{S}) = \sum_{j=1}^{p} \text{Var}(X_j)
$$

### 2.4 贡献率与累计贡献率

第 $k$ 个主成分的方差贡献率：

$$
\text{贡献率}_k = \frac{\lambda_k}{\sum_{i=1}^{p} \lambda_i}
$$

前 $m$ 个主成分的累计贡献率：

$$
\text{累计贡献率} = \frac{\sum_{k=1}^{m} \lambda_k}{\sum_{i=1}^{p} \lambda_i}
$$

---

## 三、方差最大化公式与证明

### 3.1 优化问题

第一主成分 $Z_1 = \mathbf{a}^T \mathbf{X}$ 的优化问题：

$$
\max_{\mathbf{a}} \text{Var}(\mathbf{a}^T \mathbf{X}) = \max_{\mathbf{a}} \mathbf{a}^T \mathbf{S} \mathbf{a} \quad \text{s.t.} \quad \|\mathbf{a}\|^2 = \mathbf{a}^T \mathbf{a} = 1
$$

### 3.2 拉格朗日乘子法

构造拉格朗日函数：

$$
\mathcal{L}(\mathbf{a}, \lambda) = \mathbf{a}^T \mathbf{S} \mathbf{a} - \lambda(\mathbf{a}^T \mathbf{a} - 1)
$$

对 $\mathbf{a}$ 求导并令其为零：

$$
\frac{\partial \mathcal{L}}{\partial \mathbf{a}} = 2\mathbf{S}\mathbf{a} - 2\lambda \mathbf{a} = \mathbf{0}
$$

即 $\mathbf{S}\mathbf{a} = \lambda \mathbf{a}$，说明最优 $\mathbf{a}$ 必为 $\mathbf{S}$ 的特征向量，对应的 $\lambda$ 为特征值。

目标函数值 $\mathbf{a}^T \mathbf{S}\mathbf{a} = \lambda \mathbf{a}^T \mathbf{a} = \lambda$，因此应取最大特征值 $\lambda_1$，对应的特征向量 $\mathbf{u}_1$ 即为第一主成分方向。

### 3.3 后续主成分

第 $k$ 个主成分的优化问题增加正交约束：

$$
\max_{\mathbf{a}_k} \mathbf{a}_k^T \mathbf{S} \mathbf{a}_k \quad \text{s.t.} \quad \|\mathbf{a}_k\| = 1, \; \mathbf{a}_k^T \mathbf{a}_j = 0 \;(j < k)
$$

类似推导可得 $\mathbf{a}_k = \mathbf{u}_k$（第 $k$ 个特征向量）。

---

## 四、载荷、得分与重构

### 4.1 因子载荷

载荷矩阵 $\mathbf{L}$ 的元素为主成分与原始变量的相关系数：

$$
l_{jk} = \text{Corr}(X_j, Z_k) = u_{jk} \sqrt{\lambda_k}
$$

载荷矩阵秩 $m$ 形式：$\mathbf{L} = \mathbf{U}_m \boldsymbol{\Lambda}_m^{1/2}$。

载荷平方和为变量方差中被前 $m$ 个主成分解释的部分：

$$
\sum_{k=1}^{m} l_{jk}^2 = \sum_{k=1}^{m} u_{jk}^2 \lambda_k
$$

### 4.2 主成分得分

样本 $i$ 在第 $k$ 个主成分上的得分：

$$
z_{ik} = \mathbf{x}_i^T \mathbf{u}_k = \sum_{j=1}^{p} u_{jk} x_{ij}
$$

矩阵形式：$\mathbf{Z} = \mathbf{X}_c \mathbf{U}_m$。

### 4.3 数据重构

用前 $m$ 个主成分重构原始数据：

$$
\hat{\mathbf{X}}_c = \mathbf{Z} \mathbf{U}_m^T = \mathbf{X}_c \mathbf{U}_m \mathbf{U}_m^T
$$

重构误差由$\mathbf{X}_c(\mathbf{I} - \mathbf{U}_m\mathbf{U}_m^T)$给出，其 Frobenius 范数平方等于被丢弃的特征值之和。

---

## 五、主成分的选取准则

### 5.1 累计贡献率准则

选取满足以下条件的最小 $m$：

$$
\frac{\sum_{k=1}^{m} \lambda_k}{\sum_{i=1}^{p} \lambda_i} \geq \alpha
$$

通常 $\alpha = 0.85$ 或 $0.90$。

### 5.2 Kaiser 准则

> 保留特征值 $\lambda_k > 1$ 的主成分

理论基础：标准化后总方差 $\text{tr}(\mathbf{R}) = p$，平均每个主成分的方差为 1。
特征值大于 1 的主成分包含的信息量超过了单个原始变量，有保留价值。

### 5.3 Scree 图（碎石图）

绘制特征值随主成分编号下降的折线图，寻找**拐点**（Elbow Point），即特征值下降速率明显变缓的位置。

**判断方法**：
- 视觉判断：坡度由陡变平的转折点
- 数值辅助：连续相邻特征值差的突变点

### 5.4 平行分析

基本思路：将实际特征值与同等规模的随机数据的特征值进行比较，保留实际特征值大于随机数据特征值的主成分。

步骤：
1. 生成大量（如 1000 次）与原始数据同规模的白噪声数据
2. 计算每次模拟的特征值分布（如 95% 分位数）
3. 保留 $\lambda_k^{\text{obs}} > \lambda_k^{\text{sim, 95\%}}$ 的主成分

这种方法比 Kaiser 准则和 Scree 图更稳健。

### 5.5 各准则比较

| 准则 | 优点 | 局限 |
|------|------|------|
| 累计贡献率 | 直观、可控 | 阈值主观 |
| Kaiser | 简单 | 倾向取过多成分 |
| Scree 图 | 直观视觉 | 拐点有时不明显 |
| 平行分析 | 统计上最优 | 计算量大 |

## 六、核 PCA（Kernel PCA）

### 6.1 基本思想

当数据存在非线性结构时，先将数据通过映射 $\phi$ 投影到高维特征空间，再在高维空间中执行线性 PCA。

映射：$\phi: \mathbb{R}^p \to \mathcal{H}$（$\mathcal{H}$ 为高维/无限维特征空间）。

### 6.2 核技巧

定义核函数避免显式计算高维映射：

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \langle \phi(\mathbf{x}_i), \phi(\mathbf{x}_j) \rangle
$$

中心化后的核矩阵 $\tilde{\mathbf{K}} = \mathbf{K} - \mathbf{1}_n \mathbf{K} - \mathbf{K} \mathbf{1}_n + \mathbf{1}_n \mathbf{K} \mathbf{1}_n$（其中 $\mathbf{1}_n$ 为每个元素 $=1/n$ 的矩阵）。

对 $\tilde{\mathbf{K}}$ 进行特征分解：$\tilde{\mathbf{K}} = \mathbf{V} \boldsymbol{\Lambda} \mathbf{V}^T$，第 $k$ 个成分得分 $z_{ik} = \sqrt{\lambda_k} v_{ik}$。

### 6.3 常用核函数

| 核函数 | 公式 | 参数 |
|--------|------|------|
| 线性核 | $K(\mathbf{x}, \mathbf{y}) = \mathbf{x}^T\mathbf{y}$ | — |
| 多项式核 | $K(\mathbf{x}, \mathbf{y}) = (\mathbf{x}^T\mathbf{y} + c)^d$ | $c, d$ |
| RBF 核 | $K(\mathbf{x}, \mathbf{y}) = \exp(-\gamma \|\mathbf{x} - \mathbf{y}\|^2)$ | $\gamma > 0$ |
| Sigmoid 核 | $K(\mathbf{x}, \mathbf{y}) = \tanh(\alpha \mathbf{x}^T\mathbf{y} + c)$ | $\alpha, c$ |

## 七、主成分回归（PCR）

当自变量间存在多重共线性时，可将 PCA 与回归结合：

1. 对 $\mathbf{X}$ 执行 PCA，得前 $m$ 个主成分 $\mathbf{Z}_{n \times m}$
2. 以 $\mathbf{Z}$ 为自变量对 $\mathbf{Y}$ 回归：$\hat{\boldsymbol{\beta}}_{\text{PCR}} = (\mathbf{Z}^T\mathbf{Z})^{-1} \mathbf{Z}^T \mathbf{Y}$
3. 转换回原始变量空间：$\hat{\boldsymbol{\beta}}_{\text{PCR}} = \mathbf{U}_m \hat{\boldsymbol{\beta}}_{\text{PCR}, Z}$

PCR 通过丢弃小特征值对应的主成分牺牲部分方差信息以换取估计稳定性。

---

## 八、PCA 的局限性

1. **线性假设**：PCA 仅捕捉线性结构，非线性数据需用核 PCA 或 t-SNE/UMAP
2. **方差最大化不保证判别力**：主成分方向可能与分类/回归任务无关
3. **尺度敏感**：变量量纲不同时必须先标准化（否则方差大的变量主导第一主成分）
4. **可解释性差**：主成分是原始变量的线性组合，物理含义可能模糊
5. **对异常值敏感**：少量异常值可显著改变协方差矩阵和主成分方向
6. **假设高斯性**：PCA 基于二阶统计量（协方差），隐含数据近似高斯的假设

---

## 九、PCA 与因子分析的对比

| 特征 | PCA | 因子分析 |
|------|-----|---------|
| 目的 | 降维，保留方差 | 解释相关性结构 |
| 数学模型 | $Z_k = \mathbf{u}_k^T \mathbf{X}$ | $\mathbf{X} = \mathbf{A}\mathbf{F} + \boldsymbol{\varepsilon}$ |
| 误差项 | 无（确定性） | 有特殊因子（概率模型） |
| 方差分解 | $\lambda_k$ | 共同度 $h_i^2$ + 特殊方差 $\psi_i$ |
| 解的唯一性 | 特征向量确定 | 旋转后可解释性提升 |

## 十、Python 实现

### 10.1 基于 sklearn 的标准 PCA

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 模拟数据：5个变量、100个样本
np.random.seed(42)
n, p = 100, 5
X = np.random.randn(n, p)
X[:, 1] = X[:, 0] * 0.8 + np.random.randn(n) * 0.3
X[:, 2] = X[:, 0] * 0.5 + X[:, 1] * 0.3 + np.random.randn(n) * 0.5

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# PCA
pca = PCA()
X_pca = pca.fit_transform(X_scaled)

print("各主成分方差解释比例:")
for i in range(p):
    cum = np.sum(pca.explained_variance_ratio_[:i+1])
    print(f"  PC{i+1}: {pca.explained_variance_ratio_[i]:.4f} (累计: {cum:.4f})")

print(f"\n特征值: {pca.explained_variance_}")
print(f"载荷矩阵 (components_):\n{pca.components_[:3]}")
```

### 10.2 手动实现 PCA 的完整过程

```python
def manual_pca(X, n_components=None):
    """从零实现 PCA（基于协方差矩阵的特征分解）"""
    n, p = X.shape
    
    # 1. 中心化
    X_centered = X - np.mean(X, axis=0)
    
    # 2. 协方差矩阵
    S = (X_centered.T @ X_centered) / (n - 1)
    
    # 3. 特征值分解（eigh 对对称矩阵更精确）
    eigenvalues, eigenvectors = np.linalg.eigh(S)
    
    # 4. 按特征值降序排列
    idx = np.argsort(-eigenvalues)  # 降序
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]
    
    # 5. 选择主成分数
    if n_components is None:
        n_components = p
    U_m = eigenvectors[:, :n_components]
    
    # 6. 计算得分
    scores = X_centered @ U_m
    
    # 7. 计算载荷矩阵 L = U * sqrt(Lambda)
    loadings = U_m * np.sqrt(eigenvalues[:n_components])
    
    # 贡献率
    total_var = np.sum(eigenvalues)
    explained_variance_ratio = eigenvalues[:n_components] / total_var
    
    return scores, eigenvalues, U_m, loadings, explained_variance_ratio

scores, evals, evecs, loadings, ratios = manual_pca(X_scaled, n_components=3)
print(f"手动 PCA 前3个PC贡献率: {ratios}")
print(f"累计: {np.sum(ratios):.4f}")

# 验证：PC得分协方差为对角矩阵
score_cov = np.cov(scores.T)
print(f"\nPC得分协方差矩阵 (应对角):\n{np.round(score_cov, 6)}")
```

### 10.4 核 PCA 示例

```python
from sklearn.decomposition import KernelPCA

# 非线性数据：同心圆
n_samples = 200
theta = np.random.uniform(0, 2*np.pi, n_samples)
inner = np.column_stack([np.cos(theta), np.sin(theta)]) * 0.5
outer = np.column_stack([np.cos(theta), np.sin(theta)])
X_nonlinear = np.vstack([inner, outer]) + np.random.normal(0, 0.05, (2*n_samples, 2))

# 线性 PCA
pca_linear = PCA(n_components=2)
X_pca_linear = pca_linear.fit_transform(X_nonlinear)

# RBF 核 PCA
kpca = KernelPCA(n_components=2, kernel='rbf', gamma=10)
X_kpca = kpca.fit_transform(X_nonlinear)

print(f"线性 PCA 解释方差: {pca_linear.explained_variance_ratio_}")
print(f"核 PCA (RBF) 已完成变换")
```

## 十一、关键公式汇总

| 项目 | 公式 |
|------|------|
| 协方差分解 | $\mathbf{S} = \mathbf{U}\boldsymbol{\Lambda}\mathbf{U}^T$ |
| 主成分 | $Z_k = \mathbf{u}_k^T \mathbf{X}$ |
| 方差 | $\text{Var}(Z_k) = \lambda_k$ |
| 载荷 | $l_{jk} = u_{jk} \sqrt{\lambda_k}$ |
| 贡献率 | $\lambda_k / \sum \lambda_i$ |
| 得分 | $\mathbf{Z} = \mathbf{X}_c \mathbf{U}_m$ |
| 核 PCA | $\tilde{\mathbf{K}} = \mathbf{V}\boldsymbol{\Lambda}\mathbf{V}^T$ |
| 重构 | $\hat{\mathbf{X}}_c = \mathbf{Z} \mathbf{U}_m^T$ |
