# 灰色系统理论

---

## 一、概述

灰色系统理论是中国学者邓聚龙教授于 1982 年创立的，专门针对**部分信息已知、部分信息未知**的不确定性系统。与传统统计方法不同，灰色系统理论适用于**小样本、贫信息**的数据分析场景。

### 1.1 系统分类

| 类型 | 信息状态 | 示例 |
|------|----------|------|
| **白色系统** | 信息完全已知 | 精确物理模型 |
| **黑色系统** | 信息完全未知 | 完全随机的黑箱 |
| **灰色系统** | 部分已知、部分未知 | 经济社会系统、生态数据 |

### 1.2 核心方法

灰色系统理论包含两大核心分析工具：
1. **GM(1,1) 模型**：灰色预测（单变量一阶微分方程）
2. **灰色关联分析（GRA）**：因素间的几何相似性比较

---

## 二、GM(1,1) 预测模型

### 2.1 原始序列与累加生成

设原始非负序列：

$$
X^{(0)} = (x^{(0)}(1), x^{(0)}(2), \ldots, x^{(0)}(n))
$$

**一次累加生成（1-AGO）**：

$$
\boxed{x^{(1)}(k) = \sum_{i=1}^{k} x^{(0)}(i), \quad k = 1, 2, \ldots, n}
$$

AGO 的作用是将无明显规律的序列转化为近似指数增长的单调递增序列，这对 GM(1,1) 建模至关重要。

### 2.2 紧邻均值生成

$$
z^{(1)}(k) = \frac{1}{2} \left[ x^{(1)}(k) + x^{(1)}(k-1) \right], \quad k = 2, 3, \ldots, n
$$

$z^{(1)}(k)$ 为 $[k-1, k]$ 区间上 $x^{(1)}(t)$ 的梯形近似值。

### 2.3 白化微分方程

GM(1,1) 的基本形式——白化微分方程：

$$
\boxed{\frac{dx^{(1)}}{dt} + a x^{(1)} = b}
$$

其中：
- $a$：**发展系数**（Development Coefficient），反映序列发展趋势
- $b$：**灰作用量**（Grey Input），反映数据的灰色输入

对应的差分形式（灰色微分方程）：

$$
x^{(0)}(k) + a z^{(1)}(k) = b, \quad k = 2, 3, \ldots, n
$$

### 2.4 最小二乘估计

将差分方程写成矩阵形式：

$$
\mathbf{Y} = \mathbf{B} \cdot \begin{pmatrix} a \\ b \end{pmatrix}
$$

其中：

$$
\mathbf{Y} = \begin{pmatrix} x^{(0)}(2) \\ x^{(0)}(3) \\ \vdots \\ x^{(0)}(n) \end{pmatrix}, \quad
\mathbf{B} = \begin{pmatrix} -z^{(1)}(2) & 1 \\ -z^{(1)}(3) & 1 \\ \vdots & \vdots \\ -z^{(1)}(n) & 1 \end{pmatrix}
$$

参数的最小二乘估计：

$$
\boxed{\begin{pmatrix} \hat{a} \\ \hat{b} \end{pmatrix} = (\mathbf{B}^T \mathbf{B})^{-1} \mathbf{B}^T \mathbf{Y}}
$$

### 2.5 时间响应函数与还原

白化微分方程在初始条件 $x^{(1)}(1) = x^{(0)}(1)$ 下的**解（时间响应函数）**：

$$
\boxed{\hat{x}^{(1)}(k+1) = \left( x^{(0)}(1) - \frac{b}{a} \right) e^{-ak} + \frac{b}{a}}
$$

对 $\hat{x}^{(1)}$ 做**一次累减生成（IAGO）**还原为预测值：

$$
\boxed{\hat{x}^{(0)}(k+1) = \hat{x}^{(1)}(k+1) - \hat{x}^{(1)}(k) = (1 - e^{a}) \left( x^{(0)}(1) - \frac{b}{a} \right) e^{-ak}}
$$

## 三、模型检验

### 3.1 残差检验

残差：$\varepsilon(k) = x^{(0)}(k) - \hat{x}^{(0)}(k)$

相对残差：

$$
\Delta_k = \frac{|\varepsilon(k)|}{x^{(0)}(k)} \times 100\%
$$

平均相对残差：$\bar{\Delta} = \frac{1}{n} \sum_{k=1}^{n} \Delta_k$

精度等级：$\bar{\Delta} < 5\%$ 为一级（优），$5\%-10\%$ 为二级（合格）。

### 3.2 后验差检验

记原始序列 $x^{(0)}$ 的均值与标准差为 $\bar{x}$ 和 $S_1$，残差序列的均值与标准差为 $\bar{\varepsilon}$ 和 $S_2$。

**后验差比值**：

$$
C = \frac{S_2}{S_1}
$$

**小误差概率**：

$$
P = P\left( |\varepsilon(k) - \bar{\varepsilon}| < 0.6745 S_1 \right)
$$

精度等级：

| 精度 | $C$ | $P$ |
|------|-----|-----|
| 一级（优） | $< 0.35$ | $> 0.95$ |
| 二级（合格） | $< 0.50$ | $> 0.80$ |
| 三级（勉强） | $< 0.65$ | $> 0.70$ |
| 四级（不合格） | $\geq 0.65$ | $\leq 0.70$ |

### 3.3 关联度检验

计算预测序列与原始序列的灰色关联度（见第五章），当 $\gamma > 0.6$ 时模型满意。

### 3.4 发展系数 $a$ 的适宜范围

- $|a| < 2$：GM(1,1) 可用
- $-a \leq 0.3$：适用于中长期预测
- $0.3 < -a \leq 0.5$：适用于短期预测
- $0.5 < -a \leq 0.8$：短期预测需谨慎
- $0.8 < -a \leq 1.0$：需残差修正
- $-a > 1.0$：不宜使用 GM(1,1)

## 四、GM(1,1) 的扩展模型

### 4.1 GM(1,N) 模型

有 $N$ 个变量（1 个因变量、$N-1$ 个自变量）的多变量灰色模型：

$$
\frac{dx_1^{(1)}}{dt} + a x_1^{(1)} = b_2 x_2^{(1)} + b_3 x_3^{(1)} + \cdots + b_N x_N^{(1)}
$$

适用于多变量系统的动态协调分析。

### 4.2 离散灰色模型 DGM(1,1)

避免连续到离散的近似误差：

$$
x^{(1)}(k+1) = \beta_1 x^{(1)}(k) + \beta_2
$$

参数估计 $\hat{\boldsymbol{\beta}} = (\mathbf{B}^T\mathbf{B})^{-1}\mathbf{B}^T\mathbf{Y}$，完全保持离散结构。

### 4.3 灰色 Verhulst 模型

适用于饱和型或 S 型增长序列：

$$
\frac{dx^{(1)}}{dt} + a x^{(1)} = b (x^{(1)})^2
$$

即灰色系统中的 Logistic 模型。

## 五、灰色关联分析（GRA）

### 5.1 基本概念

灰色关联分析通过比较序列**几何形状的相似程度**来判断因素之间的关联。

**参考序列（母序列）**：

$$
X_0 = (x_0(1), x_0(2), \ldots, x_0(n))
$$

**比较序列（子序列）**：$X_i = (x_i(1), x_i(2), \ldots, x_i(n))$，$i = 1, 2, \ldots, m$

### 5.2 经典灰色关联度（邓氏关联度）

**步骤 1：数据预处理（无量纲化）**

| 方法 | 公式 | 特点 |
|------|------|------|
| 初值化 | $x'(k) = x(k) / x(1)$ | 以首项为基准 |
| 均值化 | $x'(k) = x(k) / \bar{x}$ | 以均值为基准 |
| 区间化 | $x'(k) = (x(k) - \min) / (\max - \min)$ | 压缩至 [0,1] |
| 归一化 | $x'(k) = x(k) / \sum x(j)$ | 和为 1 |

**步骤 2：计算关联系数**

第 $i$ 个比较序列在时刻 $k$ 与参考序列的关联系数：

$$
\boxed{\xi_i(k) = \frac{\min_i \min_k \Delta_i(k) + \rho \cdot \max_i \max_k \Delta_i(k)}{\Delta_i(k) + \rho \cdot \max_i \max_k \Delta_i(k)}}
$$

其中 $\Delta_i(k) = |x_0(k) - x_i(k)|$ 为绝对差，$\rho \in (0, 1)$ 为**分辨系数**。

**步骤 3：计算关联度**

$$
\boxed{r_i = \frac{1}{n} \sum_{k=1}^{n} \xi_i(k)}
$$

$r_i$ 越接近 1，序列 $X_i$ 与 $X_0$ 的关联越紧密。

### 5.3 分辨系数的作用

- $\rho \to 0$：分辨力增强，关联系数差异被放大
- $\rho \to 1$：分辨力减弱，所有系数趋近 1
- 通常取 $\rho = 0.5$；区分度不足时可取 $\rho = 0.1$ 或 $0.3$

### 5.4 绝对关联度

反映**绝对量的变化关系**。计算步骤：

1. 计算始化零化像：$x_i^0(k) = x_i(k) - x_i(1)$
2. 计算折线面积：

$$
|s_i| = \left| \sum_{k=2}^{n-1} x_i^0(k) + \frac{1}{2} x_i^0(n) \right|
$$

$$
|s_i - s_0| = \left| \sum_{k=2}^{n-1} (x_i^0(k) - x_0^0(k)) + \frac{1}{2}(x_i^0(n) - x_0^0(n)) \right|
$$

3. 绝对关联度：

$$
\varepsilon_i = \frac{1 + |s_0| + |s_i|}{1 + |s_0| + |s_i| + |s_i - s_0|}
$$

### 5.5 相对关联度

反映**相对变化速率的关系**，对初值进行再处理：

$$
X_i' = \frac{X_i}{x_i(1)}
$$

然后计算始化零化像及关联度（同上）。相对关联度消除了初值差异的影响。

### 5.6 综合关联度（梯形关联度）

融合绝对变化和相对变化：

$$
\boxed{\rho_i = \theta \cdot \varepsilon_i + (1 - \theta) \cdot r_i}
$$

其中 $\theta \in [0, 1]$ 为权重，通常取 $\theta = 0.5$。

### 5.7 加权灰色关联度

引入各指标权重（来自 AHP、熵权法等）：

$$
R_i = \sum_{k=1}^{n} w_k \cdot \xi_i(k)
$$

## 六、GRA 的扩展应用

### 6.1 灰色关联聚类

基于关联度矩阵进行聚类：以关联度为相似度度量，通过设定阈值将序列归入不同类别。

### 6.2 灰色关联与回归分析结合

1. 用 GRA 筛选与因变量关联最强的自变量子集
2. 用选定的自变量建立回归模型（降维+去噪）

### 6.3 灰色关联 TOPSIS

将灰色关联度与 TOPSIS 的距离相融合，构造综合贴近度：

$$
D_i = \alpha \cdot C_i^{\text{TOPSIS}} + (1-\alpha) \cdot r_i^{\text{GRA}}
$$

## 七、关键公式汇总

| 项目 | 公式 |
|------|------|
| 1-AGO | $x^{(1)}(k) = \sum_{i=1}^{k} x^{(0)}(i)$ |
| GM(1,1) 白化方程 | $\frac{dx^{(1)}}{dt} + a x^{(1)} = b$ |
| LS 估计 | $(\hat{a}, \hat{b})^T = (\mathbf{B}^T\mathbf{B})^{-1}\mathbf{B}^T\mathbf{Y}$ |
| 时间响应函数 | $\hat{x}^{(1)}(k+1) = (x^{(0)}(1) - b/a)e^{-ak} + b/a$ |
| 关联系数 | $\xi_i(k) = \frac{\Delta_{\min} + \rho \Delta_{\max}}{\Delta_i(k) + \rho \Delta_{\max}}$ |
| 关联度 | $r_i = \frac{1}{n} \sum \xi_i(k)$ |
| 综合关联度 | $\rho_i = \theta \varepsilon_i + (1-\theta) r_i$ |
| 后验差比值 | $C = S_2 / S_1$ |

## 八、Python 实现

### 8.1 GM(1,1) 模型

```python
import numpy as np

class GM11:
    """GM(1,1) 灰色预测模型"""
    
    def __init__(self, data):
        """data: 非负等间隔原始序列"""
        self.X0 = np.array(data, dtype=float)
        self.n = len(self.X0)
    
    def fit(self):
        """参数估计与模型拟合"""
        # 1-AGO 累加生成
        self.X1 = np.cumsum(self.X0)
        
        # 紧邻均值序列 Z
        Z = 0.5 * (self.X1[1:] + self.X1[:-1])
        
        # 最小二乘估计 [a, b]
        B = np.column_stack([-Z, np.ones(self.n - 1)])
        Y = self.X0[1:]
        self.params = np.linalg.inv(B.T @ B) @ B.T @ Y
        a, b = self.params
        self.a, self.b = a, b
        
        # 时间响应函数
        const = self.X0[0] - b / a
        k = np.arange(self.n)
        self.X1_hat = const * np.exp(-a * k) + b / a
        
        # 还原 IAGO
        self.X0_hat = np.zeros(self.n)
        self.X0_hat[0] = self.X0[0]
        self.X0_hat[1:] = np.diff(self.X1_hat)
        
        return self
    
    def predict(self, steps=1):
        """向前预测 steps 步"""
        a, b = self.a, self.b
        const = self.X0[0] - b / a
        
        k = np.arange(self.n, self.n + steps)
        X1_pred = const * np.exp(-a * k) + b / a
        
        X0_pred = np.zeros(steps)
        X0_pred[0] = X1_pred[0] - self.X1_hat[-1]
        X0_pred[1:] = np.diff(X1_pred)
        
        return X0_pred
    
    def metrics(self):
        """残差与后验差检验"""
        residuals = self.X0 - self.X0_hat
        rel_errors = np.abs(residuals) / self.X0 * 100
        
        S1 = np.std(self.X0, ddof=1)
        S2 = np.std(residuals, ddof=1)
        
        # 后验差比值
        C = S2 / S1
        
        # 小误差概率
        eps_bar = np.mean(residuals)
        P = np.mean(np.abs(residuals - eps_bar) < 0.6745 * S1)
        
        return {
            'residuals': residuals,
            'rel_errors': rel_errors,
            'mean_rel_error': np.mean(rel_errors),
            'C': C, 'P': P,
            'a': self.a, 'b': self.b
        }


# 示例：预测 GDP
gdp_data = [45.8, 51.2, 57.3, 64.0, 71.5, 80.0, 89.5]
model = GM11(gdp_data).fit()
print(f"发展系数 a = {model.a:.4f}, 灰作用量 b = {model.b:.4f}")
print(f"拟合值: {np.round(model.X0_hat, 2)}")

m = model.metrics()
print(f"平均相对误差: {m['mean_rel_error']:.2f}%")
print(f"后验差比值 C={m['C']:.4f}, 小误差概率 P={m['P']:.4f}")

# 预测未来3期
forecast = model.predict(3)
print(f"未来3期预测: {np.round(forecast, 2)}")
```

### 8.2 灰色关联分析（经典方法）

```python
class GreyRelationalAnalysis:
    """灰色关联分析"""
    
    def __init__(self, ref_seq, compare_seqs, rho=0.5, method='mean'):
        self.ref = np.array(ref_seq, dtype=float)
        self.comps = np.array(compare_seqs, dtype=float)
        self.rho = rho
        self.method = method
    
    def _normalize(self, data):
        if self.method == 'init':
            return data / data[0]
        elif self.method == 'mean':
            return data / np.mean(data)
        elif self.method == 'minmax':
            return (data - data.min()) / (data.max() - data.min())
        return data
    
    def compute(self):
        ref_norm = self._normalize(self.ref)
        comps_norm = np.array([self._normalize(c) for c in self.comps])
        
        diff = np.abs(ref_norm - comps_norm)
        delta_min = np.min(diff)
        delta_max = np.max(diff)
        
        xi = (delta_min + self.rho * delta_max) / (diff + self.rho * delta_max)
        r = np.mean(xi, axis=1)
        ranking = np.argsort(-r)
        
        return {
            'coefficients': xi,
            'degree': r,
            'ranking': ranking + 1,
            'delta_min': delta_min,
            'delta_max': delta_max
        }


# 示例：影响因素分析
reference = np.array([85, 92, 78, 105, 88])  # AQI
factors = np.array([
    [45, 52, 38, 65, 48],   # PM2.5
    [850, 920, 780, 1050, 880],  # 交通流量
    [35, 32, 38, 28, 33],   # 绿化率
])

gra = GreyRelationalAnalysis(reference, factors, rho=0.5, method='mean')
result = gra.compute()

print("关联度排名:")
names = ['PM2.5', '交通流量', '绿化率']
for rank_idx in result['ranking']:
    idx = rank_idx - 1
    print(f"  第{list(result['ranking']).index(rank_idx)+1}名: {names[idx]} "
          f"({result['degree'][idx]:.4f})")
```

### 8.3 加权灰色关联评价

```python
def weighted_grey_evaluation(data, weights, cost_idx=None, rho=0.5):
    """加权灰色关联评价"""
    m, n = data.shape
    if cost_idx is None:
        cost_idx = []
    
    # 正向化成本型指标
    data_pos = data.copy().astype(float)
    for j in cost_idx:
        data_pos[:, j] = data_pos[:, j].max() - data_pos[:, j]
    
    # 参考序列：每列最大值
    reference = data_pos.max(axis=0)
    
    # 均值化
    data_norm = data_pos / data_pos.mean(axis=0)
    ref_norm = reference / data_pos.mean(axis=0)
    
    # 关联系数
    diff = np.abs(data_norm - ref_norm)
    d_min, d_max = diff.min(), diff.max()
    xi = (d_min + rho * d_max) / (diff + rho * d_max)
    
    # 加权关联度
    degree = xi @ weights
    ranking = np.argsort(-degree)
    
    return degree, ranking + 1, xi

# 示例
data = np.array([
    [92, 78, 85, 88],
    [85, 90, 78, 82],
    [88, 82, 90, 75],
    [80, 85, 82, 90],
])
weights = np.array([0.3, 0.25, 0.25, 0.2])
cost_idx = [1]  # 第2个指标为成本型

deg, rank, xi = weighted_grey_evaluation(data, weights, cost_idx)
for r, idx in enumerate(rank):
    print(f"第{r+1}名: 方案{idx} (关联度={deg[idx-1]:.4f})")
```

## 九、注意事项

1. **数据要求**：GM(1,1) 要求数据非负且等间隔
2. **样本量限制**：GRA 最少仅需 4 个数据点，无需大样本或分布假设
3. **分辨系数**：需根据数据波动程度调节；波动大时可取较小的 $\rho$
4. **无量纲化方法的选择影响结果**：初值化对首项敏感，均值化较稳定
5. **GM(1,1) 仅适用于近似指数增长的数据**：当数据波动剧烈时应先平滑或改用其他灰色模型
6. **灰色理论与统计的区别**：灰色理论重点在于信息的"少数据"建模，而非统计推断
