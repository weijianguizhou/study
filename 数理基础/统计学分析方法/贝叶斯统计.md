## 一、概述

贝叶斯统计将**不确定性**通过概率分布系统地表征。与频率学派不同，贝叶斯学派将参数 $\theta$ 视为**随机变量**，利用观测数据 $x$ 更新对参数的认知。

核心公式——贝叶斯定理：

$$
\boxed{\pi(\theta | x) = \frac{f(x | \theta) \, \pi(\theta)}{\int f(x | \theta) \, \pi(\theta) \, d\theta} \propto f(x|\theta) \cdot \pi(\theta)}
$$

即**后验 ∝ 似然 × 先验**。

### 频率学派 vs 贝叶斯学派

| 维度 | 频率学派 | 贝叶斯学派 |
|------|----------|------------|
| 参数性质 | 固定未知常数 | 随机变量（有分布） |
| 概率定义 | 长期频率 | 信念/不确定性度量 |
| 推断基础 | 样本数据 | 先验 + 样本数据 |
| 区间估计 | 置信区间（含概率频率解释） | 可信区间（直接概率解释） |
| 假设检验 | p 值 | 贝叶斯因子 / 后验概率 |
| 先验信息 | 不使用 | 核心要素 |
| 计算 | 多为解析解 | 常需 MCMC 数值近似 |

## 二、贝叶斯定理的展开

### 2.1 离散形式

$$
P(\theta_i | x) = \frac{P(x | \theta_i) P(\theta_i)}{\sum_{j} P(x | \theta_j) P(\theta_j)}
$$

### 2.2 连续形式

$$
\pi(\theta | x) = \frac{f(x | \theta) \pi(\theta)}{m(x)}, \quad m(x) = \int_{\Theta} f(x | \theta) \pi(\theta) \, d\theta
$$

其中 $m(x)$ 为**边际似然**（Marginal Likelihood），又称**证据**（Evidence），是模型比较的核心量。

### 2.3 先验的影响

- $n$ 小：先验主导后验
- $n$ 大：似然主导后验（先验消解，Prior Washout）

先验类型：
- **无信息先验**：$\pi(\theta) \propto 1$（Jeffreys 先验、Reference 先验）
- **信息先验**：包含领域知识
- **分层先验**：先验本身含超参数

## 三、共轭先验

**共轭性**：若先验和后验属于同一分布族，则称该先验为**共轭先验**。共轭先验使后验具有封闭形式的解析解。

### 3.1 Beta-Binomial 共轭（二项成功率）

**模型**：$X \sim \text{Binomial}(n, \theta)$

**先验**：$\theta \sim \text{Beta}(\alpha, \beta)$

先验密度：

$$
\pi(\theta) = \frac{\Gamma(\alpha + \beta)}{\Gamma(\alpha)\Gamma(\beta)} \theta^{\alpha - 1} (1 - \theta)^{\beta - 1}, \quad \theta \in (0, 1)
$$

先验均值：$E(\theta) = \frac{\alpha}{\alpha + \beta}$

**似然**：

$$
f(x|\theta) = \binom{n}{x} \theta^x (1 - \theta)^{n - x} \propto \theta^x (1 - \theta)^{n - x}
$$

**后验推导**：

$$
\pi(\theta|x) \propto \theta^{\alpha - 1} (1 - \theta)^{\beta - 1} \cdot \theta^x (1 - \theta)^{n - x}
= \theta^{(\alpha + x) - 1} (1 - \theta)^{(\beta + n - x) - 1}
$$

即：

$$
\boxed{\theta | x \sim \text{Beta}(\alpha + x, \;\beta + n - x)}
$$

**后验均值**：

$$
E(\theta|x) = \frac{\alpha + x}{\alpha + \beta + n}
$$

可解读为：先验等效于 $(\alpha + \beta)$ 次试验中成功 $\alpha$ 次，加上观测到 $x$ 次成功和 $n$ 次试验后更新。

**后验方差**：

$$
\text{Var}(\theta|x) = \frac{(\alpha + x)(\beta + n - x)}{(\alpha + \beta + n)^2 (\alpha + \beta + n + 1)}
$$

### 3.2 Normal-Normal 共轭（已知方差下的均值）

**模型**：$X_1, \ldots, X_n | \mu \overset{\text{iid}}{\sim} N(\mu, \sigma^2)$，$\sigma^2$ 已知

**先验**：$\mu \sim N(\mu_0, \tau_0^2)$

**后验推导**：

似然函数：

$$
f(\mathbf{x}|\mu) \propto \exp\left( -\frac{1}{2\sigma^2} \sum_{i=1}^{n} (x_i - \mu)^2 \right)
\propto \exp\left( -\frac{n}{2\sigma^2} (\mu - \bar{x})^2 \right)
$$

结合先验：

$$
\pi(\mu|\mathbf{x}) \propto \exp\left( -\frac{1}{2\tau_0^2} (\mu - \mu_0)^2 \right) \cdot
\exp\left( -\frac{n}{2\sigma^2} (\mu - \bar{x})^2 \right)
$$

配平方得后验：

$$
\boxed{\mu | \mathbf{x} \sim N\left( \frac{\frac{\mu_0}{\tau_0^2} + \frac{n\bar{x}}{\sigma^2}}{\frac{1}{\tau_0^2} + \frac{n}{\sigma^2}}, \; \frac{1}{\frac{1}{\tau_0^2} + \frac{n}{\sigma^2}} \right)}
$$

**精度参数化**：令 $\tau_1 = 1/\tau_0^2$（先验精度）、$\tau = 1/\sigma^2$（数据精度），则后验精度 $\tau_{\text{post}} = \tau_1 + n\tau$，后验均值为精度加权平均。

### 3.3 Gamma-Poisson 共轭（泊松率参数）

**模型**：$X_i | \lambda \overset{\text{iid}}{\sim} \text{Poisson}(\lambda)$

**先验**：$\lambda \sim \text{Gamma}(\alpha, \beta)$（速率参数化）

先验密度：

$$
\pi(\lambda) = \frac{\beta^\alpha}{\Gamma(\alpha)} \lambda^{\alpha - 1} e^{-\beta \lambda}, \quad \lambda > 0
$$

先验均值 $E(\lambda) = \alpha / \beta$，先验方差 $\text{Var}(\lambda) = \alpha / \beta^2$。

**似然**（$n$ 个观测）：

$$
f(\mathbf{x}|\lambda) = \prod_{i=1}^{n} \frac{\lambda^{x_i} e^{-\lambda}}{x_i!} \propto \lambda^{\sum x_i} e^{-n\lambda}
$$

**后验推导**：

$$
\pi(\lambda|\mathbf{x}) \propto \lambda^{\alpha - 1} e^{-\beta \lambda} \cdot \lambda^{\sum x_i} e^{-n\lambda}
= \lambda^{(\alpha + \sum x_i) - 1} e^{-(\beta + n)\lambda}
$$

即：

$$
\boxed{\lambda | \mathbf{x} \sim \text{Gamma}(\alpha + \sum_{i=1}^{n} x_i, \; \beta + n)}
$$

## 四、共轭先验汇总

| 似然 | 参数 | 共轭先验 | 后验参数 |
|------|------|----------|----------|
| Binomial$(n,\theta)$ | $\theta$ | Beta$(\alpha,\beta)$ | Beta$(\alpha+x,\;\beta+n-x)$ |
| Poisson$(\lambda)$ | $\lambda$ | Gamma$(\alpha,\beta)$ | Gamma$(\alpha+\sum x_i,\;\beta+n)$ |
| Normal$(\mu, \sigma^2_0)$ | $\mu$ ($\sigma^2_0$已知) | Normal$(\mu_0,\tau_0^2)$ | Normal（见上推导） |
| Normal$(\mu_0, \sigma^2)$ | $\sigma^2$ ($\mu_0$已知) | Inv-Gamma$(\alpha,\beta)$ | Inv-Gamma$(\alpha+n/2,\;\beta+\sum(x_i-\mu_0)^2/2)$ |
| Normal$(\mu, \sigma^2)$ | $(\mu,\sigma^2)$ | Normal-Inv-Gamma | Normal-Inv-Gamma |
| Multinomial | $\mathbf{p}$ | Dirichlet$(\boldsymbol{\alpha})$ | Dirichlet$(\boldsymbol{\alpha} + \mathbf{n})$ |
| Exponential$(\lambda)$ | $\lambda$ | Gamma$(\alpha,\beta)$ | Gamma$(\alpha+n,\;\beta+\sum x_i)$ |

## 五、后验推断

### 5.1 点估计

- **后验均值**（最小化平方误差损失）：$\hat{\theta} = E[\theta|x] = \int \theta \, \pi(\theta|x) \, d\theta$
- **后验中位数**（最小化绝对误差损失）：$P(\theta \leq m|x) = 0.5$
- **MAP 估计**（最大化后验概率，最小化 0-1 损失）：$\hat{\theta}_{\text{MAP}} = \arg\max_\theta \pi(\theta|x)$

### 5.2 区间估计：可信区间

$1-\alpha$ **等尾可信区间**：

$$
P(\theta_L \leq \theta \leq \theta_U | x) = 1 - \alpha
$$

其中 $\theta_L$ 和 $\theta_U$ 分别是后验的 $\alpha/2$ 和 $1-\alpha/2$ 分位数。

**最高后验密度区间（HPD）**：区间内每点的后验密度 ≥ 区间外密度，且区间长度最短。

$$
\text{HPD}_{\alpha} = \{ \theta : \pi(\theta|x) \geq k_\alpha \}
$$

其中 $k_\alpha$ 使得 $\int_{\text{HPD}} \pi(\theta|x) \, d\theta = 1-\alpha$。

**关键区别**：可信区间可直接解释为"参数有 95% 的概率落在该区间内"，而频率学派的置信区间不能。

### 5.3 假设检验：贝叶斯因子

**贝叶斯因子**衡量数据对两个假设的支持程度之比：

$$
\boxed{BF_{10} = \frac{P(x | H_1)}{P(x | H_0)} = \frac{\int f(x|\theta_1) \pi_1(\theta_1) \, d\theta_1}{\int f(x|\theta_0) \pi_0(\theta_0) \, d\theta_0}}
$$

即两个假设的边际似然之比。

**后验几率与先验几率的关系**：

$$
\frac{P(H_1|x)}{P(H_0|x)} = \frac{P(x|H_1)}{P(x|H_0)} \cdot \frac{P(H_1)}{P(H_0)} = BF_{10} \cdot \frac{P(H_1)}{P(H_0)}
$$

**Jeffreys 解释标度**：

| $BF_{10}$ | 证据强度 | 对数（$\ln BF_{10}$） |
|-----------|----------|----------------------|
| 1 — 3 | 弱 / 不值得提及 | 0 — 1.1 |
| 3 — 10 | 中等 | 1.1 — 2.3 |
| 10 — 30 | 强 | 2.3 — 3.4 |
| 30 — 100 | 非常强 | 3.4 — 4.6 |
| > 100 | 决定性 | > 4.6 |

$BF_{10} = 1/3$ 表示 $H_0$ 有中等证据支持（与 $BF_{01} = 3$ 等价）。

## 六、后验预测分布

对新观测 $x_{\text{new}}$ 进行预测，考虑参数的所有不确定性：

$$
\boxed{P(x_{\text{new}} | x) = \int f(x_{\text{new}} | \theta) \, \pi(\theta | x) \, d\theta}
$$

### Beta-Binomial 的后验预测

$X_{\text{new}} | x \sim \text{Beta-Binomial}(1, \alpha+x, \beta+n-x)$，即：

$$
P(X_{\text{new}} = 1 | x) = E[\theta|x] = \frac{\alpha + x}{\alpha + \beta + n}
$$

### 后验预测 p 值

用于模型检验：生成复制数据 $x^{\text{rep}}$ 并计算检验统计量 $T(x)$ 的分布：

$$
p_B = P(T(x^{\text{rep}}) \geq T(x^{\text{obs}}) | x^{\text{obs}})
$$

极端值（接近 0 或 1）表示模型拟合不佳。

## 七、MCMC 方法简介

当后验无解析解时，用**马尔可夫链蒙特卡洛**（Markov Chain Monte Carlo）方法从后验中抽样。

### 7.1 Metropolis-Hastings 算法

从提议分布 $q(\theta^*|\theta^{(t)})$ 生成候选值，以概率接受：

$$
\alpha = \min\left\{ 1, \frac{f(x|\theta^*) \pi(\theta^*) \cdot q(\theta^{(t)} | \theta^*)}{f(x|\theta^{(t)}) \pi(\theta^{(t)}) \cdot q(\theta^* | \theta^{(t)})} \right\}
$$

对称提议分布（如随机游走 $N(\theta^{(t)}, \sigma^2)$）时，$q$ 项消去。

**收敛诊断**：
- $\hat{R}$ (Gelman-Rubin)：所有链的 $\hat{R} < 1.1$
- 有效样本量（ESS）
- Trace plot 和自相关图

### 7.2 Gibbs 采样

当全条件分布 $P(\theta_i | \theta_{-i}, x)$ 可直接抽样时，轮流从每个参数的条件后验中抽取：

1. $\theta_1^{(t+1)} \sim P(\theta_1 | \theta_2^{(t)}, \ldots, \theta_p^{(t)}, x)$
2. $\theta_2^{(t+1)} \sim P(\theta_2 | \theta_1^{(t+1)}, \theta_3^{(t)}, \ldots, \theta_p^{(t)}, x)$
3. $\ldots$

Gibbs 采样是 M-H 在 $\alpha = 1$ 时的特例。

## 八、贝叶斯模型比较

### 8.1 贝叶斯因子（回顾）

$BF_{10} = \frac{m_1(x)}{m_0(x)}$，直接比较两个模型的边际似然。

### 8.2 信息准则

**DIC**（Deviance Information Criterion）：

$$
DIC = \bar{D} + p_D = 2\bar{D} - D(\hat{\theta})
$$

**WAIC**（Widely Applicable Information Criterion）：

$$
WAIC = -2 \left( \text{lppd} - p_{\text{WAIC}} \right)
$$

WAIC 比 DIC 更完全贝叶斯（基于整个后验分布，而非点估计）。

### 8.3 LOO-CV

留一法交叉验证的对数预测密度：

$$
\text{elpd}_{\text{loo}} = \sum_{i=1}^{n} \log P(y_i | y_{-i})
$$

可通过 Pareto Smoothed Importance Sampling（PSIS）高效近似。

## 九、贝叶斯方法在建模中的应用

1. **小样本推断**：先验信息弥补数据不足
2. **层次模型**：处理多层嵌套数据（多城市、多时间点）
3. **贝叶斯模型平均（BMA）**：融合多个模型加权预测
4. **缺失数据处理**：将缺失值作为参数联合推断
5. **不确定性量化**：后验预测分布自然给出预测区间

## 十、Python 实现

### 10.1 Beta-Binomial 共轭分析

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# 先验: Beta(2, 5)，对成功率持悲观态度
alpha_prior, beta_prior = 2, 5

# 观测数据: 100次试验，65次成功
n_trials, n_success = 100, 65

# 后验: Beta(alpha_prior + n_success, beta_prior + n - n_success)
alpha_post = alpha_prior + n_success
beta_post = beta_prior + n_trials - n_success

# 后验统计
post_mean = alpha_post / (alpha_post + beta_post)
post_var = (alpha_post * beta_post) / ((alpha_post + beta_post)**2 *
                                         (alpha_post + beta_post + 1))
post_std = np.sqrt(post_var)

# 95% 等尾可信区间
ci_low = stats.beta.ppf(0.025, alpha_post, beta_post)
ci_high = stats.beta.ppf(0.975, alpha_post, beta_post)

print(f"先验 Beta({alpha_prior}, {beta_prior}) → 先验均值={alpha_prior/(alpha_prior+beta_prior):.3f}")
print(f"后验 Beta({alpha_post}, {beta_post})")
print(f"  后验均值: {post_mean:.4f}")
print(f"  后验标准差: {post_std:.4f}")
print(f"  95% 可信区间: [{ci_low:.4f}, {ci_high:.4f}]")
print(f"  MLE (频率): {n_success/n_trials:.4f}")

# 后验预测: 新试验20次中成功的次数
n_new = 20
# Beta-Binomial 分布的均值
pred_mean = n_new * post_mean
# Beta-Binomial 方差
pred_var = n_new * alpha_post * beta_post * (alpha_post + beta_post + n_new) / \
           ((alpha_post + beta_post)**2 * (alpha_post + beta_post + 1))
print(f"\n后验预测 (n={n_new}): 期望成功 {pred_mean:.1f} 次, "
      f"标准差 {np.sqrt(pred_var):.2f}")
```

### 10.2 Metropolis-Hastings 采样

```python
np.random.seed(42)

def log_likelihood(mu, data, sigma=1.0):
    """正态似然"""
    return np.sum(stats.norm.logpdf(data, loc=mu, scale=sigma))

def log_prior(mu):
    """先验 N(0, 10²)"""
    return stats.norm.logpdf(mu, loc=0, scale=10.0)

def log_posterior(mu, data):
    return log_likelihood(mu, data) + log_prior(mu)

# 生成数据 (真实均值=3.0)
true_mu = 3.0
data = np.random.normal(true_mu, 1.0, size=50)

# Metropolis-Hastings
n_iter = 10000
burn_in = 2000
mu_chain = np.zeros(n_iter)
mu_chain[0] = 0.0
proposal_sd = 0.5
accept_count = 0

for t in range(1, n_iter):
    # 从随机游走提议分布生成候选值
    mu_proposal = mu_chain[t-1] + np.random.normal(0, proposal_sd)
    
    # 对数接受概率
    log_alpha = (log_posterior(mu_proposal, data) -
                 log_posterior(mu_chain[t-1], data))
    
    if np.log(np.random.uniform()) < log_alpha:
        mu_chain[t] = mu_proposal
        accept_count += 1
    else:
        mu_chain[t] = mu_chain[t-1]

mu_samples = mu_chain[burn_in:]

print(f"\nM-H 采样结果:")
print(f"  接受率: {accept_count/n_iter:.4f} (理想: 0.2-0.5)")
print(f"  后验均值: {np.mean(mu_samples):.4f} (真实: {true_mu})")
print(f"  后验标准差: {np.std(mu_samples):.4f}")
print(f"  95% 可信区间: [{np.percentile(mu_samples, 2.5):.4f}, "
      f"{np.percentile(mu_samples, 97.5):.4f}]")

# 有效样本量
def ess(chain):
    """有效样本量"""
    n = len(chain)
    # 自相关
    auto_corr = np.correlate(chain - np.mean(chain),
                             chain - np.mean(chain), mode='full')[n-1:]
    auto_corr /= auto_corr[0]
    # 找到首个 ≤ 0.05 的自相关
    k = np.where(auto_corr <= 0.05)[0]
    max_lag = k[0] if len(k) > 0 else len(auto_corr)
    sum_ac = np.sum(auto_corr[1:max_lag])
    return n / (1 + 2 * sum_ac)

print(f"  有效样本量: {ess(mu_samples):.0f}")
```

### 10.3 贝叶斯因子计算

```python
from scipy.integrate import quad

def marginal_likelihood_normal(data, mu0, tau0, sigma=1.0):
    """Normal-Normal 模型的边际似然"""
    n = len(data)
    xbar = np.mean(data)
    
    # 后验参数
    tau_post = 1 / (1/tau0**2 + n/sigma**2)
    mu_post = tau_post * (mu0/tau0**2 + n*xbar/sigma**2)
    
    # 边际似然 (对数形式)
    log_marginal = (
        -n/2 * np.log(2*np.pi*sigma**2)
        - 0.5 * np.log(tau0**2 / tau_post)
        - 0.5 * np.sum((data - mu_post)**2) / sigma**2
        - 0.5 * (mu_post - mu0)**2 / tau0**2
    )
    return np.exp(log_marginal)

# 比较 H0: mu=2.5 vs H1: mu≠2.5 (先验 mu~N(3,1²))
m0 = marginal_likelihood_normal(data, mu0=2.5, tau0=0.01)  # H0: 近点先验
m1 = marginal_likelihood_normal(data, mu0=3.0, tau0=1.0)   # H1

BF10 = m1 / m0
print(f"\n贝叶斯因子 BF10 = {BF10:.3f}")
print(f"数据对 H1 的支持程度是 H0 的 {BF10:.1f} 倍")
```

```python
# 后验预测p值
n_rep = 500
simulated_means = np.zeros(n_rep)
for i in range(n_rep):
    # 从后验抽取 θ*
    mu_star = np.random.choice(mu_samples)
    # 生成复制数据
    y_rep = np.random.normal(mu_star, 1.0, len(data))
    simulated_means[i] = np.mean(y_rep)

# 检验统计量: 样本均值
observed_stat = np.mean(data)
ppp = np.mean(simulated_means >= observed_stat)

print(f"\n后验预测检验:")
print(f"  观测统计量 = {observed_stat:.4f}")
print(f"  后验预测p值 = {ppp:.4f} (接近0.5表示拟合良好)")
```

## 十一、关键公式汇总

| 项目 | 公式 |
|------|------|
| 贝叶斯定理 | $\pi(\theta|x) \propto f(x|\theta) \pi(\theta)$ |
| Beta-Binomial | $\theta|x \sim \text{Beta}(\alpha+x, \beta+n-x)$ |
| Normal-Normal | 精度加权平均后验 |
| Gamma-Poisson | $\lambda|\mathbf{x} \sim \text{Gamma}(\alpha+\sum x_i, \beta+n)$ |
| MAP | $\arg\max_\theta \pi(\theta|x)$ |
| HPD 区间 | $\{\theta: \pi(\theta|x) \geq k_\alpha\}$ |
| 贝叶斯因子 | $BF_{10} = m_1(x) / m_0(x)$ |
| 后验预测 | $P(x_{\text{new}}|x) = \int f(x_{\text{new}}|\theta) \pi(\theta|x) d\theta$ |
| M-H 接受率 | $\alpha = \min\{1, (f\pi q)_{\text{ratio}}\}$ |
