## 一、概述

因子分析（Factor Analysis, FA）是一种**潜在变量模型**，假设观测变量之间的相关性可由少数不可观测的潜变量（公共因子）来解释。与 PCA 不同，FA 是生成式概率模型，明确包含测量误差。

**核心问题**：$p$ 个观测变量背后有多少个潜变量在驱动？它们分别解释了哪些观测变量？

---

## 二、因子分析模型

### 2.1 正交因子模型

对标准化的 $p$ 维随机向量 $\mathbf{X}$：

$$
\boxed{\mathbf{X}_{p \times 1} = \mathbf{A}_{p \times m} \mathbf{F}_{m \times 1} + \boldsymbol{\varepsilon}_{p \times 1}}
$$

写成标量形式：

$$
X_i = a_{i1}F_1 + a_{i2}F_2 + \cdots + a_{im}F_m + \varepsilon_i, \quad i = 1, 2, \ldots, p
$$

**基本假设**：
1. $E(\mathbf{F}) = \mathbf{0}$，$\text{Cov}(\mathbf{F}) = \mathbf{I}_m$（公共因子标准化且互不相关）
2. $E(\boldsymbol{\varepsilon}) = \mathbf{0}$，$\text{Cov}(\boldsymbol{\varepsilon}) = \boldsymbol{\Psi} = \text{diag}(\psi_1, \psi_2, \ldots, \psi_p)$
3. $\text{Cov}(\mathbf{F}, \boldsymbol{\varepsilon}) = \mathbf{0}$（公共因子与特殊因子不相关）

### 2.2 协方差结构

由上述假设得观测变量协方差矩阵的分解：

$$
\boxed{\boldsymbol{\Sigma} = \text{Cov}(\mathbf{X}) = \mathbf{A}\mathbf{A}^T + \boldsymbol{\Psi}}
$$

这是 FA 的核心方程——将 $\boldsymbol{\Sigma}$ 分解为两部分：
- $\mathbf{A}\mathbf{A}^T$：由 $m$ 个公共因子解释的方差（共同部分）
- $\boldsymbol{\Psi}$：特殊（独特）方差

模型参数个数：$pm + p$，而 $\boldsymbol{\Sigma}$ 有 $p(p+1)/2$ 个充分统计量。可识别条件：

$$
p(p+1)/2 \geq pm + p - \frac{m(m-1)}{2}
$$

### 2.3 关键概念

#### 因子载荷

$a_{ij}$ 为第 $i$ 个变量在第 $j$ 个公共因子上的载荷，等价于相关系数：

$$
a_{ij} = \text{Cov}(X_i, F_j) = \text{Corr}(X_i, F_j)
$$

载荷绝对值接近 1 说明变量主要由该因子驱动。

#### 共同度（Communality）

第 $i$ 个变量的共同度：

$$
h_i^2 = \sum_{j=1}^{m} a_{ij}^2 = (\mathbf{A}\mathbf{A}^T)_{ii}
$$

表示被 $m$ 个公共因子共同解释的方差比例，$0 \leq h_i^2 \leq 1$。

#### 特殊方差（Uniqueness）

$$
\psi_i = 1 - h_i^2
$$

包含两部分：特异方差（变量独有） + 测量误差方差。

#### 特征值（因子贡献）

第 $j$ 个因子对 $p$ 个变量的总贡献：

$$
S_j^2 = \sum_{i=1}^{p} a_{ij}^2
$$

方差贡献率：$S_j^2 / p$。

## 三、载荷矩阵的估计方法

### 3.1 主成分法

最基本的估计方法，计算步骤：

1. 计算样本相关矩阵 $\mathbf{R}$ 的特征分解：$\mathbf{R} = \mathbf{U}\boldsymbol{\Lambda}\mathbf{U}^T$
2. 取前 $m$ 个特征值和特征向量
3. 估计载荷矩阵：$\hat{\mathbf{A}} = \mathbf{U}_m \boldsymbol{\Lambda}_m^{1/2}$，即 $\hat{a}_{ij} = u_{ij}\sqrt{\lambda_j}$
4. 估计共同度：$\hat{h}_i^2 = \sum_{j=1}^{m} \hat{a}_{ij}^2$
5. 估计特殊方差：$\hat{\psi}_i = 1 - \hat{h}_i^2$

### 3.2 主因子法（Principal Factor Method）

主成分法的改进，迭代估计共同度：

1. **初始步**：以 SMC（Squared Multiple Correlation，即 $R_i^2$）为共同度初值
2. **构建约相关矩阵**：$\mathbf{R}^* = \mathbf{R} - \hat{\boldsymbol{\Psi}}$，其中 $\hat{\psi}_i = 1 - \hat{h}_i^2$
3. 对 $\mathbf{R}^*$ 进行特征分解，取前 $m$ 个载荷更新 $\hat{\mathbf{A}}$
4. 重新计算共同度 $\hat{h}_i^2 = \sum_{j=1}^{m} \hat{a}_{ij}^2$
5. 迭代至共同度收敛

**特点**：$\mathbf{R}^*$ 不再保证正定性，可能出现负特征值。

### 3.3 极大似然法（Maximum Likelihood）

假设 $\mathbf{X} \sim N_p(\mathbf{0}, \boldsymbol{\Sigma})$，其中 $\boldsymbol{\Sigma} = \mathbf{A}\mathbf{A}^T + \boldsymbol{\Psi}$。

对数似然函数（忽略常数项）：

$$
\ell(\mathbf{A}, \boldsymbol{\Psi}) = -\frac{n}{2} \left[ \ln|\boldsymbol{\Sigma}| + \text{tr}(\mathbf{S} \boldsymbol{\Sigma}^{-1}) \right]
$$

在约束 $\mathbf{A}^T \boldsymbol{\Psi}^{-1} \mathbf{A} = \boldsymbol{\Delta}$（$\boldsymbol{\Delta}$ 为对角矩阵）下通过 EM 算法或数值优化求解。

**优势**：可提供标准误和拟合优度检验（$\chi^2$ 检验），但需要正态性假设。

### 3.4 三种方法对比

| 特征 | 主成分法 | 主因子法 | 极大似然法 |
|------|----------|----------|------------|
| 计算复杂度 | 低 | 中 | 高 |
| 共同度处理 | 先验（特征值大的） | 迭代估计 | 联合估计 |
| 正态性要求 | 无 | 无 | 需要 |
| 拟合检验 | 无 | 无 | $\chi^2$ 检验 |
| 收敛性 | 保证 | 可能不收敛 | 可能不收敛 |

## 四、因子旋转

### 4.1 旋转的动机

原始解往往难以解释——同一变量可能在多个因子上有中等大小的载荷。对载荷矩阵施行正交或斜交旋转，追求**简单结构**（Thurstone, 1947）：

- 每个变量只在少数因子上有高载荷（行简单）
- 每个因子只在少数变量上有高载荷（列简单）
- 高载荷接近 ±1，低载荷接近 0

旋转不改变模型的拟合程度（共同度不变）：

$$
\mathbf{A} \mathbf{A}^T = (\mathbf{A}\mathbf{T})(\mathbf{A}\mathbf{T})^T = \mathbf{A} \mathbf{T} \mathbf{T}^T \mathbf{A}^T
$$

需 $\mathbf{T}\mathbf{T}^T = \mathbf{I}$（正交）或 $\mathbf{T}\mathbf{T}^T = \boldsymbol{\Phi}$（斜交）。

### 4.2 Varimax 旋转（最常用正交旋转）

最大化所有因子上标准化载荷的方差之和：

$$
V = \frac{1}{p} \sum_{j=1}^{m} \left[ \frac{1}{p} \sum_{i=1}^{p} \tilde{a}_{ij}^4 - \left( \frac{1}{p} \sum_{i=1}^{p} \tilde{a}_{ij}^2 \right)^2 \right] = \max
$$

其中 $\tilde{a}_{ij} = a_{ij} / h_i$ 为标准化载荷（除以变量共同度的平方根）。

旋转后的载荷矩阵：$\mathbf{B} = \mathbf{A}\mathbf{T}$，$\mathbf{T}$ 为 $m \times m$ 正交矩阵。

### 4.3 Promax 旋转（斜交旋转）

先进行 Varimax 正交旋转得目标矩阵 $\mathbf{B}_{\text{target}}$，再通过幂次变换获得斜交解。

载荷矩阵定义为 $\mathbf{B}$ 的第 $k$ 次幂（通常 $k=4$）的标准化形式。

因子间相关矩阵：

$$
\boldsymbol{\Phi} = (\mathbf{T}^T \mathbf{T})^{-1}
$$

当 $\boldsymbol{\Phi}$ 非单位矩阵时，因子之间存在相关关系，需同时报告**模式矩阵**（pattern）和**结构矩阵**（structure）。

### 4.4 正交与斜交的选择

| 特征 | 正交旋转 | 斜交旋转 |
|------|----------|----------|
| 因子间相关性 | 无（人为约束） | 允许相关 |
| 理论假设 | 各因子独立 | 因子可能相关 |
| 解释清晰度 | 更简洁 | 更符合实际 |
| 典型方法 | Varimax, Quartimax | Promax, Oblimin |

## 五、因子得分

对每个样本估计其在各公共因子上的取值：

### 5.1 回归法（Thompson 得分）

$$
\hat{\mathbf{F}} = \mathbf{A}^T \boldsymbol{\Sigma}^{-1} \mathbf{X} = \mathbf{A}^T (\mathbf{A}\mathbf{A}^T + \boldsymbol{\Psi})^{-1} \mathbf{X}
$$

是最小化 MSE 意义上的最优估计。

### 5.2 Bartlett 得分（加权最小二乘）

$$
\hat{\mathbf{F}} = (\mathbf{A}^T \boldsymbol{\Psi}^{-1} \mathbf{A})^{-1} \mathbf{A}^T \boldsymbol{\Psi}^{-1} \mathbf{X}
$$

得到无偏但可能无效的得分。

## 六、模型拟合检验

### 6.1 拟合优度 $\chi^2$ 检验

原假设 $H_0$：$m$ 个因子的模型能充分拟合数据。

检验统计量（Bartlett 修正）：

$$
\chi^2 = \left[ n - 1 - \frac{2p + 4m + 5}{6} \right] \ln \left( \frac{|\hat{\boldsymbol{\Sigma}}|}{|\mathbf{S}|} \right)
$$

自由度 $df = \frac{1}{2}[(p - m)^2 - (p + m)]$。

拒绝 $H_0$ 表示模型拟合不佳。但 $\chi^2$ 对大样本过度敏感，需结合其他指标。

### 6.2 拟合指数

**RMSEA**（Root Mean Square Error of Approximation）：

$$
\text{RMSEA} = \sqrt{\frac{\max(\chi^2 - df, 0)}{df \cdot (n-1)}}
$$

- RMSEA < 0.05：优良拟合
- RMSEA < 0.08：可接受
- RMSEA > 0.10：拟合不佳

**CFI**（Comparative Fit Index）：

$$
\text{CFI} = 1 - \frac{\max(\chi^2 - df, 0)}{\max(\chi^2_0 - df_0, \chi^2 - df, 0)}
$$

- CFI > 0.95：优良
- CFI > 0.90：可接受

**TLI**（Tucker-Lewis Index，又称 NNFI）：

$$
\text{TLI} = \frac{\chi^2_0 / df_0 - \chi^2 / df}{\chi^2_0 / df_0 - 1}
$$

- TLI > 0.95：优良
- TLI > 0.90：可接受

**SRMR**（Standardized Root Mean Square Residual）：

$$
\text{SRMR} = \sqrt{\frac{2}{p(p+1)} \sum_{i=1}^{p} \sum_{j=1}^{i} (r_{ij} - \hat{\rho}_{ij})^2}
$$

- SRMR < 0.08：可接受

## 七、因子数目的确定

| 方法 | 准则 |
|------|------|
| **Kaiser 准则** | 保留特征值 > 1 的因子 |
| **累计贡献率** | 前 $m$ 个因子累计贡献 ≥ 85% |
| **Scree 图** | 拐点法选择因子数 |
| **平行分析** | 比较实际与随机数据的特征值 |
| **BIC/AIC** | 使信息准则最小的因子数 |
| **理论驱动** | 根据理论或已有量表结构预设 |

一般建议结合多种方法，并以可解释性作为最终判断依据。

## 八、适用性检验

在执行因子分析前需确认数据适合进行因子分析：

### 8.1 KMO 检验（Kaiser-Meyer-Olkin）

$$
KMO = \frac{\sum_{i \neq j} r_{ij}^2}{\sum_{i \neq j} r_{ij}^2 + \sum_{i \neq j} a_{ij}^2}
$$

其中 $a_{ij}$ 为偏相关系数（控制其他变量后的相关）。KMO > 0.6 才适合做因子分析，> 0.8 为良好。

### 8.2 Bartlett 球形检验

$$
\chi^2 = -\left(n - 1 - \frac{2p + 5}{6}\right) \ln|\mathbf{R}|
$$

检验总体相关矩阵是否为单位阵。$p < 0.05$ 时拒绝球形假设，适合进行分析。

---

## 九、样本量要求

- 绝对最小：$n \geq 100$ 或 $n \geq 5p$
- 良好：$n \geq 300$ 或 $n \geq 10p$
- 变量-因子比：每个因子至少 3-5 个高载荷变量（> 0.5）
- 共同度：各变量共同度应 > 0.3（建议 > 0.5）

### 10.1 基于 sklearn 的因子分析

```python
import numpy as np
from sklearn.decomposition import FactorAnalysis
from sklearn.preprocessing import StandardScaler
import pandas as pd

# 模拟问卷数据：8 个题目、3 个潜在因子
np.random.seed(42)
n = 300
F1 = np.random.randn(n)  # 因子1：能力
F2 = np.random.randn(n)  # 因子2：态度
F3 = np.random.randn(n)  # 因子3：动机

data = {
    'Q1': 0.8*F1 + 0.1*np.random.randn(n),
    'Q2': 0.75*F1 + 0.15*np.random.randn(n),
    'Q3': 0.7*F1 + 0.2*np.random.randn(n),
    'Q4': 0.1*F1 + 0.8*F2 + 0.1*np.random.randn(n),
    'Q5': 0.15*F1 + 0.75*F2 + 0.15*np.random.randn(n),
    'Q6': 0.8*F2 + 0.15*np.random.randn(n),
    'Q7': 0.75*F3 + 0.2*np.random.randn(n),
    'Q8': 0.7*F3 + 0.25*F2 + 0.15*np.random.randn(n),
}
df = pd.DataFrame(data)

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)

# 因子分析 (3个因子, Varimax旋转)
fa = FactorAnalysis(n_components=3, rotation='varimax', random_state=42)
fa_scores = fa.fit_transform(X_scaled)

print("因子载荷矩阵 (旋转后):")
loadings_df = pd.DataFrame(
    fa.components_.T,
    index=df.columns,
    columns=[f'因子{i+1}' for i in range(3)]
)
print(loadings_df.round(3))

# 共同度与特殊方差
communalities = 1 - fa.noise_variance_
print(f"\n共同度: {np.round(communalities, 3)}")
print(f"特殊方差 (uniqueness): {np.round(fa.noise_variance_, 3)}")
```

### 10.2 KMO 与 Bartlett 检验

```python
from scipy.stats import chi2
from scipy import linalg

def kmo_test(corr_matrix):
    """KMO 抽样充分性检验"""
    # 偏相关矩阵的逆
    corr_inv = np.linalg.inv(corr_matrix)
    # 偏相关矩阵
    n = corr_matrix.shape[0]
    partial_corr = np.zeros_like(corr_matrix)
    for i in range(n):
        for j in range(n):
            if i != j:
                partial_corr[i, j] = -corr_inv[i, j] / np.sqrt(corr_inv[i, i] * corr_inv[j, j])
    
    # 计算 KMO
    r_sq = 0
    p_sq = 0
    for i in range(n):
        for j in range(i+1, n):
            r_sq += corr_matrix[i, j]**2
            p_sq += partial_corr[i, j]**2
    
    kmo = r_sq / (r_sq + p_sq)
    return kmo

def bartlett_test(data, n_factors):
    """Bartlett 球形检验"""
    n, p = data.shape
    corr = np.corrcoef(data, rowvar=False)
    # 检验统计量
    det_corr = np.linalg.det(corr)
    chi_sq = -(n - 1 - (2*p + 5)/6) * np.log(det_corr)
    df = p * (p - 1) / 2
    p_value = 1 - chi2.cdf(chi_sq, df)
    return chi_sq, df, p_value

corr_matrix = np.corrcoef(X_scaled, rowvar=False)
kmo = kmo_test(corr_matrix)
print(f"KMO = {kmo:.4f}")

chi_sq, df, p_val = bartlett_test(X_scaled, 3)
print(f"Bartlett χ² = {chi_sq:.2f}, df = {df:.0f}, p = {p_val:.6f}")
```

### 10.3 平行分析（辅助确定因子数）

```python
def parallel_analysis(data, n_iter=100, percentile=95):
    """平行分析"""
    n, p = data.shape
    # 实际特征值
    corr = np.corrcoef(data, rowvar=False)
    actual_evals = np.sort(np.linalg.eigvalsh(corr))[::-1]
    
    # 模拟随机数据的特征值分布
    sim_evals = np.zeros((n_iter, p))
    for i in range(n_iter):
        random_data = np.random.normal(size=(n, p))
        random_corr = np.corrcoef(random_data, rowvar=False)
        sim_evals[i] = np.sort(np.linalg.eigvalsh(random_corr))[::-1]
    
    # 取指定分位数
    threshold = np.percentile(sim_evals, percentile, axis=0)
    
    # 因子数为实际特征值 > 随机特征值阈值的个数
    n_factors = np.sum(actual_evals > threshold)
    
    return n_factors, actual_evals, threshold

n_factors, actual, threshold = parallel_analysis(X_scaled, n_iter=200)
print(f"\n平行分析建议因子数: {n_factors}")
print(f"实际特征值: {np.round(actual[:6], 3)}")
print(f"95% 随机阈值: {np.round(threshold[:6], 3)}")
```

### 10.4 手动实现主成分法因子分析

```python
def factor_analysis_pca(X, n_factors):
    """主成分法因子分析"""
    n, p = X.shape
    X_c = X - np.mean(X, axis=0)
    R = np.cov(X_c, rowvar=False)  # 或 np.corrcoef(X_c, rowvar=False)
    
    # 特征分解
    eigenvalues, eigenvectors = np.linalg.eigh(R)
    idx = np.argsort(-eigenvalues)
    eigenvalues = eigenvalues[idx][:n_factors]
    eigenvectors = eigenvectors[:, idx][:, :n_factors]
    
    # 载荷矩阵 A
    A = eigenvectors * np.sqrt(eigenvalues)
    
    # 共同度
    h2 = np.sum(A**2, axis=1)
    
    # 特殊方差
    psi = np.diag(R) - h2
    
    return A, h2, psi, eigenvalues

A, h2, psi, evals = factor_analysis_pca(X_scaled, 3)
print(f"\nPCA法载荷矩阵:\n{np.round(A, 3)}")
print(f"共同度: {np.round(h2, 3)}")
print(f"特殊方差: {np.round(psi, 3)}")
```

## 十一、关键公式汇总

| 项目 | 公式 |
|------|------|
| 因子模型 | $\mathbf{X} = \mathbf{A}\mathbf{F} + \boldsymbol{\varepsilon}$ |
| 协方差分解 | $\boldsymbol{\Sigma} = \mathbf{A}\mathbf{A}^T + \boldsymbol{\Psi}$ |
| 共同度 | $h_i^2 = \sum_{j=1}^{m} a_{ij}^2$ |
| Varimax 准则 | $\max \frac{1}{p} \sum_j \left[ \frac{1}{p} \sum_i \tilde{a}_{ij}^4 - (\frac{1}{p} \sum_i \tilde{a}_{ij}^2)^2 \right]$ |
| Bartlett 得分 | $(\mathbf{A}^T\boldsymbol{\Psi}^{-1}\mathbf{A})^{-1}\mathbf{A}^T\boldsymbol{\Psi}^{-1}\mathbf{X}$ |
| RMSEA | $\sqrt{\max(\chi^2 - df, 0) / [df(n-1)]}$ |
| KMO | $\frac{\sum_{i \neq j} r_{ij}^2}{\sum_{i \neq j} r_{ij}^2 + \sum_{i \neq j} a_{ij}^2}$ |
| 平行分析 | 保留 $\lambda_k^{\text{obs}} > \lambda_k^{\text{sim}}$ 的因子 |
