# 壹、多项式

> 参考：[Advanced Modern Algebra (Rotman, Ch3.3–3.4)]、[Linear Algebra Done Right (Axler, Ch4)]

## 一、多项式环的基本概念

### 1. 定义

设 $R$ 为交换环，$R[x]$ 表示以 $x$ 为未定元、系数取自 $R$ 的全体多项式构成的**多项式环**：

$$
f(x) = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n, \quad a_i \in R
$$

- **次数** $\deg f$：最大指数（$a_n \neq 0$）
- **首项系数**：最高次项系数
- **首一多项式 (Monic)**：首项系数为 1
- 零多项式：$\deg 0 = -\infty$（约定）

### 2. 次数公式

对 $f, g \in R[x]$（$R$ 为整环）：
- $\deg(f + g) \leq \max(\deg f, \deg g)$
- $\deg(fg) = \deg f + \deg g$

> **推导**：$(f+g)$ 的最高次可能抵消；$(fg)$ 的首项 = $f$ 的首项 $\times$ $g$ 的首项。由于 $R$ 无零因子，首项系数之积非零，故 $\deg(fg) = \deg f + \deg g$。若 $R$ 有零因子，首项可能消为零。

## 二、多项式的整除理论

### 1. 带余除法（多项式除法算法）

设 $F$ 为域，$f, g \in F[x]$ 且 $g \neq 0$，存在唯一 $q, r \in F[x]$ 使得：

$$
f(x) = q(x)g(x) + r(x), \quad \deg r < \deg g
$$

> **推导（对 $\deg f$ 归纳）**：若 $\deg f < \deg g$，取 $q = 0, r = f$ 即可。若 $\deg f = n \geq m = \deg g$，令 $a_n$ 和 $b_m$ 分别为 $f, g$ 的首项系数，构造 $q_1(x) = \frac{a_n}{b_m} x^{n-m}$（因 $F$ 是域，除法可做）。则 $f_1(x) = f(x) - q_1(x)g(x)$ 的 $x^n$ 项被消去，$\deg f_1 < n$。由归纳假设，存在 $q_2, r$ 使 $f_1 = q_2 g + r$ 且 $\deg r < \deg g$。取 $q = q_1 + q_2$ 即得。

### 2. Bezout 恒等式的推导

Euclid 算法可逆推得到 Bezout 系数。从最后一步开始：若 $\gcd(f,g) = r_k$，第 $i$ 步有 $r_{i-1} = q_{i+1} r_i + r_{i+1}$，改写为 $r_{i+1} = r_{i-1} - q_{i+1} r_i$。从 $i = k-1$ 倒推至 $i = 1$，逐步回代消去中间余式，最终将 $r_k$ 表为 $f$ 和 $g$ 的线性组合 $\gcd(f,g) = sf + tg$。

### 3. 整除与因子

$g$ **整除** $f$（$g \mid f$）若存在 $h \in F[x]$ 使得 $f = gh$。

### 4. 最大公因式 (GCD)

$d = \gcd(f, g)$ 若：(a) $d \mid f$ 且 $d \mid g$；(b) 若 $c \mid f$ 且 $c \mid g$，则 $c \mid d$。

**Euclid 算法**：
$$
\begin{aligned}
f &= q_1 g + r_1, \quad \deg r_1 < \deg g \\
g &= q_2 r_1 + r_2, \quad \deg r_2 < \deg r_1 \\
&\vdots \\
r_{k-1} &= q_{k+1} r_k
\end{aligned}
$$
则 $\gcd(f, g) = r_k$（归一化后）。

> **Euclid 算法正确性**：每一步 $\gcd(f,g) = \gcd(g,r_1) = \gcd(r_1,r_2) = \cdots = \gcd(r_{k-1},r_k) = r_k$。因为 $(f,g)$ 与 $(g,f-q_1g)$ 有相同公因子集。次数严格递减保证在有限步后停止。

## 三、因式分解

### 1. 根与因式的关系

$(x - \alpha) \mid f(x)$ $\iff$ $f(\alpha) = 0$（$\alpha$ 是 $f$ 的根）。

> **推导**：由带余除法，$f(x) = q(x)(x-\alpha) + r$，$\deg r < 1$ 即 $r$ 为常数。代入 $x = \alpha$：$f(\alpha) = q(\alpha) \cdot 0 + r = r$。故 $f(\alpha) = 0 \iff r = 0 \iff (x-\alpha) \mid f(x)$。

### 2. 不可约多项式

$p(x) \in F[x]$ 称为 **$F$ 上的不可约多项式**若 $\deg p \geq 1$ 且若 $p = fg$，则 $f$ 或 $g$ 为常数。

### 3. 唯一因式分解定理

$F[x]$ 是**UFD**：每个次数 $\geq 1$ 的多项式可唯一表为不可约多项式之积。

> **推导思路**：存在性由归纳法（若可约则分解为更低次因子，次数递减至不可约）；唯一性用 **Euclid 引理**：若 $p$ 不可约且 $p \mid fg$，则 $p \mid f$ 或 $p \mid g$（由 Bezout 恒等式可证：若 $p \nmid f$，则 $\gcd(p,f)=1$，存在 $sp + tf = 1$，乘以 $g$ 得 $spg + tfg = g$，因 $p \mid fg$，故 $p \mid g$）。

### 4. 次数为 $n$ 的多项式至多有 $n$ 个根（计重数）

> **推导**：若 $\alpha_1$ 是根，$f(x) = (x-\alpha_1)g(x)$，$\deg g = n-1$。若 $g$ 还有根 $\alpha_2$，继续提取。最多提取 $n$ 次，故至多 $n$ 个根。

### 5. 形式导数判别重根

$f$ 在扩展域中有重根 $\iff$ $\gcd(f, f') \neq 1$。

> **推导**：若 $\alpha$ 是 $k$ 重根，$f(x) = (x-\alpha)^k g(x)$ 且 $g(\alpha) \neq 0$。则 $f'(x) = k(x-\alpha)^{k-1}g(x) + (x-\alpha)^k g'(x) = (x-\alpha)^{k-1}[kg(x) + (x-\alpha)g'(x)]$。当 $k \geq 2$ 时 $(x-\alpha) \mid f'$，故 $(x-\alpha) \mid \gcd(f,f')$。若 $k=1$ 则 $(x-\alpha) \nmid f'$（因 $g(\alpha) \neq 0$）。

## 四、Vieta 定理与有理根测试

### 1. Vieta 定理

对 $f(x) = (x-r_1)\cdots(x-r_n) = x^n + a_{n-1} x^{n-1} + \cdots + a_0$：
$$
r_1 + \cdots + r_n = -a_{n-1},\quad \prod r_i = (-1)^n a_0
$$

> **推导**：将根形式的乘积逐层展开。$x^{n-1}$ 的系数来自 $(n-1)$ 个 $x$ 与 1 个 $-r_i$ 的乘积，共 $n$ 项，和为 $-\sum r_i$，故 $a_{n-1} = -\sum r_i$。常数项 $= \prod(-r_i) = (-1)^n \prod r_i$。一般地，$a_{n-k}$ 是 $(-1)^k \cdot$(根的 $k$ 元初等对称多项式)。

### 2. 有理根测试

$f(x) = a_n x^n + \cdots + a_0 \in \mathbb{Z}[x]$，若 $p/q$（既约分数）是根，则 $p \mid a_0$，$q \mid a_n$。

> **推导**：代入 $x = p/q$ 乘 $q^n$：$a_n p^n + a_{n-1} p^{n-1} q + \cdots + a_0 q^n = 0$。移项得 $p(a_n p^{n-1} + \cdots) = -a_0 q^n$，因 $\gcd(p,q)=1$，$p \mid a_0$。同理 $q \mid a_n$。

### 3. Eisenstein 不可约判据

若存在素数 $p$ 使 $p \mid a_i$（$i < n$），$p \nmid a_n$，$p^2 \nmid a_0$，则 $f$ 在 $\mathbb{Q}[x]$ 上不可约。

> **推导（模 $p$ 约化法）**：若 $f = gh$ 在 $\mathbb{Z}[x]$ 中（Gauss 引理保证有理分解可升为整数分解），模 $p$ 约化得 $\bar{f} = \bar{g} \bar{h}$，而 $\bar{f}(x) = \bar{a}_n x^n$（所有次数 $< n$ 的系数被 $p$ 消）。因 $\overline{a}_n \neq 0$，$\bar{g}$ 和 $\bar{h}$ 都必形如 $\bar{b} x^k$ 且 $k \geq 1$。这意味着 $g,h$ 的常数项均被 $p$ 整除，则 $a_0$ 被 $p^2$ 整除——与条件矛盾。

## 五、最小多项式与 Cayley-Hamilton

**最小多项式** $m_A(x)$：满足 $m_A(A) = 0$ 的最低次首一多项式。

$m_A(x) \mid p_A(x)$（最小多项式整除特征多项式）。

> **推导**：由带余除法，$p_A(x) = q(x) m_A(x) + r(x)$，$\deg r < \deg m_A$。代入 $x = A$：$p_A(A) = q(A) m_A(A) + r(A)$。由 Cayley-Hamilton $p_A(A) = 0$，$m_A(A) = 0$，故 $r(A) = 0$。若 $r \neq 0$ 则 $r$ 是比 $m_A$ 次数更低的零化多项式，与 $m_A$ 的最小性矛盾。故 $r = 0$，即 $m_A \mid p_A$。

$m_A(x)$ 和 $p_A(x)$ 有相同的不可约因子（重数可能不同）。

# 贰、矩阵

## 一、特征值与特征向量

### 1. 定义与特征方程推导

$A \mathbf{v} = \lambda \mathbf{v}$，$\mathbf{v} \neq \mathbf{0}$。

变形为 $(A - \lambda I) \mathbf{v} = \mathbf{0}$。此齐次方程组有**非零解** $\iff$ $A - \lambda I$ 不可逆（秩不足） $\iff \det(A - \lambda I) = 0$。

### 2. 特征多项式的展开形式

$$
p_A(\lambda) = \det(A - \lambda I) = (-1)^n \lambda^n + (-1)^{n-1}(\operatorname{tr} A) \lambda^{n-1} + \cdots + \det A
$$

> **$\lambda^{n-1}$ 系数推导**：行列式 $\det(A - \lambda I)$ 中，$\lambda^{n-1}$ 的项来自：选取 $(n-1)$ 个对角元 $(a_{ii} - \lambda)$ 和 1 个非对角元时，非对角元必须配对（$a_{ij}$ 和 $a_{ji}$）才能形成非零置换循环。计入正负号整理后，展开式中 $\lambda^{n-1}$ 的总系数为 $(\operatorname{tr} A) \times (-1)^{n-1}$（因每个对角元 $a_{ii} - \lambda$ 的 $-\lambda$ 部分在被 $(n-1)$ 个选中时贡献 $\lambda^{n-1}$，共 $n$ 个这样的项）。更简单地说：$p_A(0) = \det A$，且 $p_A(\lambda) = \prod_i (\lambda_i - \lambda)$，展开后 $\lambda^{n-1}$ 系数 $= \sum \lambda_i = \operatorname{tr} A$。

---

## 二、代数重数与几何重数的推导

### 1. 几何重数公式

$$
GM = \dim E_\lambda = n - \operatorname{rank}(A - \lambda I)
$$

> **推导**：$E_\lambda = \ker(A - \lambda I)$。由秩-零度定理（对矩阵 $A - \lambda I$）：$\dim \ker(A - \lambda I) = n - \operatorname{rank}(A - \lambda I)$。这是因为 $A - \lambda I$ 是 $n \times n$ 矩阵，其零空间维数 = 列数 - 列秩。

### 2. $1 \leq GM \leq AM$ 的严格证明

**$GM \geq 1$**：$\lambda$ 为特征值 $\implies \exists \mathbf{v} \neq 0$ 满足 $(A - \lambda I)\mathbf{v} = 0 \implies \mathbf{v} \in \ker(A - \lambda I) \implies \dim \ker \geq 1$。

**$GM \leq AM$**：

> 设 $g = GM$，取 $E_\lambda$ 的一组基 $\{\mathbf{v}_1, \ldots, \mathbf{v}_g\}$。将其扩充为 $\mathbb{C}^n$ 的基 $B = \{\mathbf{v}_1, \ldots, \mathbf{v}_g, \mathbf{w}_1, \ldots, \mathbf{w}_{n-g}\}$。以 $B$ 为列构成可逆矩阵 $P = [\mathbf{v}_1 \cdots \mathbf{v}_g \; \mathbf{w}_1 \cdots \mathbf{w}_{n-g}]$。则：
> $$
> AP = P \begin{pmatrix} \lambda I_g & B \\ 0 & C \end{pmatrix}
> $$
> 因为前 $g$ 列 $A \mathbf{v}_i = \lambda \mathbf{v}_i$。由相似性，$A$ 和 $\begin{pmatrix} \lambda I_g & B \\ 0 & C \end{pmatrix}$ 有相同特征多项式：
> $$
> p_A(\mu) = \det\begin{pmatrix} (\lambda - \mu) I_g & B \\ 0 & C - \mu I \end{pmatrix} = (\lambda - \mu)^g \det(C - \mu I)
> $$
> 故 $(\lambda - \mu)^g$ 整除 $p_A(\mu)$，从而 $\lambda$ 的代数重数 $\geq g = GM$。$\square$

### 3. 矩阵可对角化的判定

$A$ 可对角化 $\iff$ 对所有特征值 $\lambda$，$GM_\lambda = AM_\lambda$。

> **推导**：可对角化 $\iff$ 存在 $n$ 个线性无关的特征向量。所有特征空间的维数和 $= \sum GM_\lambda \leq \sum AM_\lambda = n$。等式成立 $\iff$ 对所有 $\lambda$，$GM_\lambda = AM_\lambda$，此时 $\sum GM_\lambda = n$，特征向量足以构成全空间基。

# 叁、行列式

## 一、行列式定义与基本性质推导

### 1. 定义

$$
\det A = \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma) \, a_{1,\sigma(1)} a_{2,\sigma(2)} \cdots a_{n,\sigma(n)}
$$

> **结构**：$n!$ 项求和，每项取每行每列恰好一个元素的积，符号 $\pm 1$ 取决于排列的奇偶性。

### 2. 交换两行变号的推导

交换 $r, s$ 行（$r < s$）后，排列 $\sigma$ 变为 $\sigma' = \sigma \circ (r\; s)$（先交换，再按原排列取）。则 $\operatorname{sgn}(\sigma') = -\operatorname{sgn}(\sigma)$（因乘了一个对换），而每项乘积不变（只是重新排列了因子顺序）。故行列式变号 $\det A' = -\det A$。

另一种推导（公理化）：令 $f(a_1,\ldots,a_n) = \det(a_1|a_2|\cdots|a_n)$（列向量）。由交错性和多重线性：
> $$0 = f(\cdots,a_r + a_s,\cdots,a_r + a_s,\cdots) = f(\cdots,a_r,\cdots,a_r,\cdots) + f(\cdots,a_r,\cdots,a_s,\cdots) + f(\cdots,a_s,\cdots,a_r,\cdots) + f(\cdots,a_s,\cdots,a_s,\cdots)$$
> 第一、四项 $=0$（重复行），故 $f(\cdots,a_s,\cdots,a_r,\cdots) = -f(\cdots,a_r,\cdots,a_s,\cdots)$。

### 3. 倍加不变性推导

$R_i \leftarrow R_i + \alpha R_j$（$i \neq j$）。由行线性：
$$\det(\cdots, a_i + \alpha a_j, \cdots) = \det(\cdots, a_i, \cdots) + \alpha \det(\cdots, a_j, \cdots, a_j, \cdots)$$
后一项有两行相同（第 $i$ 行和第 $j$ 行均为 $a_j$），由交错性 $=0$。$\square$

### 4. 三角矩阵行列式

上（下）三角矩阵的行列式 $= \prod_i a_{ii}$。

> **推导**：非零项必须每行每列取恰好一个元素。第 1 行除 $a_{11}$ 外均为 0（上三角），故必须选 $a_{11}$；消去第 1 列后第 2 行只能选 $a_{22}$，依此类推。唯一可能的非零排列是恒等排列 $\sigma = \text{id}$，其符号为 $+1$。

### 5. 乘法定理推导 $\det(AB) = \det A \cdot \det B$

> **第一类证明（初等矩阵法）**：将 $A$ 分解为初等矩阵之积或经初等变换化三角。对每类初等矩阵 $E$，验证 $\det(EB) = \det E \cdot \det B$（倍加型 $\det E = 1$ 结合倍加不变性；交换型 $\det E = -1$；倍乘型 $\det E = \alpha$）。由此累乘即得。
>
> **第二类证明（直接展开）**：由 $\det(AB) = \sum_{\sigma} \operatorname{sgn}(\sigma) \prod_i (AB)_{i,\sigma(i)}$ 而 $(AB)_{ik} = \sum_j a_{ij} b_{jk}$，展开后利用行列式对列的多重线性性质，可整理为 $\det A \cdot \det B$。

### 6. 转置不变性推导 $\det(A^T) = \det A$

$$
\det(A^T) = \sum_{\sigma} \operatorname{sgn}(\sigma) \prod_i a_{\sigma(i), i}
$$

令 $\tau = \sigma^{-1}$。因为 $\sigma \mapsto \sigma^{-1}$ 是 $S_n$ 的双射且 $\operatorname{sgn}(\sigma) = \operatorname{sgn}(\sigma^{-1})$：
$$\det(A^T) = \sum_{\tau} \operatorname{sgn}(\tau) \prod_j a_{j, \tau(j)} = \det A$$
其中 $\prod_i a_{\sigma(i), i}$ 在 $\tau = \sigma^{-1}$ 下变为 $\prod_j a_{j, \tau(j)}$（重排乘积次序）。$\square$

### 7. Cramer 法则推导

设 $A$ 的列为 $\mathbf{a}_1, \ldots, \mathbf{a}_n$。$A\mathbf{x} = \mathbf{b}$ 即 $\sum_{j=1}^n x_j \mathbf{a}_j = \mathbf{b}$。

将 $\mathbf{b}$ 替换第 $i$ 列：
$$
\begin{aligned}
\det(\mathbf{a}_1, \ldots, \mathbf{a}_{i-1}, \mathbf{b}, \mathbf{a}_{i+1}, \ldots, \mathbf{a}_n) &= \det(\mathbf{a}_1, \ldots, \sum_j x_j \mathbf{a}_j, \ldots, \mathbf{a}_n) \\
&= \sum_j x_j \det(\mathbf{a}_1, \ldots, \mathbf{a}_{i-1}, \mathbf{a}_j, \mathbf{a}_{i+1}, \ldots, \mathbf{a}_n) \\
&= x_i \det A \quad (\because j \neq i \text{ 时行列式有重复列})
\end{aligned}
$$
故 $x_i = \dfrac{\det A_i}{\det A}$。$\square$

## 二、Jacobi 公式的完整推导

$$
\frac{d}{dx} \det A(x) = \det A(x) \cdot \operatorname{tr}\!\left(A(x)^{-1} \frac{dA}{dx}\right)
$$

> **推导**：将行列式视为每列的函数 $F(\mathbf{a}_1, \ldots, \mathbf{a}_n) = \det A$。由多重线性，全微分：
> $$dF = \sum_{k=1}^n F(\mathbf{a}_1, \ldots, \mathbf{a}_{k-1}, d\mathbf{a}_k, \mathbf{a}_{k+1}, \ldots, \mathbf{a}_n)$$
> 即 $F$ 对每列求方向导数。
>
> 由 Cramer 法则：$F$ 对第 $k$ 列第 $i$ 个元素的偏导 $= C_{ik}$（$(i,k)$ 的代数余子式），即 $\frac{\partial \det A}{\partial a_{ik}} = C_{ik} = (\det A)(A^{-1})_{ki}$。
>
> 因此：
> $$\frac{d}{dx} \det A = \sum_{i,k} C_{ik} \frac{d a_{ik}}{dx} = \det A \cdot \sum_{i,k} (A^{-1})_{ki} \frac{d a_{ik}}{dx} = \det A \cdot \operatorname{tr}\!\left(A^{-1} \frac{dA}{dx}\right)$$
> 最后一步由迹的定义 $\operatorname{tr}(XY) = \sum_{i,j} X_{ji} Y_{ij}$。

**条件**：$A(x)$ 在 $x$ 处可逆。

### 代数余子式形式（不需要可逆）

$$
\frac{d}{dx} \det A(x) = \sum_{i=1}^n \sum_{j=1}^n C_{ij} \frac{d a_{ij}}{d x} = \operatorname{tr}\!\left(\operatorname{adj}(A)^{\top} \frac{dA}{dx}\right)
$$

## 三、雅可比行列式与变量替换推导

当在 $\mathbb{R}^n$ 中进行变量替换 $\mathbf{x} = \mathbf{g}(\mathbf{u})$：

$$
\int_{\Omega} f(\mathbf{x}) \,d\mathbf{x} = \int_{\Omega'} f(\mathbf{g}(\mathbf{u})) \left|\det\!\left(\frac{\partial \mathbf{x}}{\partial \mathbf{u}}\right)\right| d\mathbf{u}
$$

> **推导思想**：在 $\mathbf{u}$ 空间取微元 $d\mathbf{u} = [\Delta u_1, \ldots, \Delta u_n]^{\top}$。对应 $\mathbf{x}$ 空间的像为 $\Delta \mathbf{x} \approx J \Delta \mathbf{u}$，其中 $J = \frac{\partial \mathbf{x}}{\partial \mathbf{u}}$ 是 Jacobi 矩阵。微元的体积变换比为 $|\det J|$（因为线性变换的体积缩放因子 = 其行列式的绝对值）。对全区域积分取 Riemann 和极限即得上述公式。

# 肆、Newton 恒等式的推导

设 $p_k = \sum_{i=1}^n x_i^k$（幂和），$e_k$ 为初等对称多项式（$e_0 = 1$）。Newton 恒等式：

$$
k e_k = \sum_{i=1}^k (-1)^{i-1} e_{k-i} p_i \quad (k = 1, \ldots, n)
$$

> **推导（生成函数法）**：考虑多项式 $P(t) = \prod_{i=1}^n (1 + x_i t) = 1 + e_1 t + e_2 t^2 + \cdots + e_n t^n$。
>
> 对 $P(t)$ 取对数导数：
> $$\frac{P'(t)}{P(t)} = \sum_{i=1}^n \frac{x_i}{1 + x_i t} = \sum_{i=1}^n x_i \sum_{j=0}^\infty (-x_i t)^j = \sum_{j=0}^\infty (-1)^j p_{j+1} t^j$$
>
> 同时 $P'(t) = e_1 + 2 e_2 t + \cdots + n e_n t^{n-1}$。故：
> $$(e_1 + 2e_2 t + \cdots + n e_n t^{n-1}) = (1 + e_1 t + e_2 t^2 + \cdots) \cdot \sum_{j=0}^\infty (-1)^j p_{j+1} t^j$$
>
> 比较 $t^{k-1}$ 系数（$k \leq n$）：
> $$k e_k = p_1 e_{k-1} - p_2 e_{k-2} + \cdots + (-1)^{k-1} p_k e_0$$
> 即 $k e_k = \sum_{i=1}^k (-1)^{i-1} p_i e_{k-i}$。$\square$
