# 传染病动力学模型

> 从 SIR 仓室模型到网络传播——以 $R_0$ 为核心的传染病数学

---

## 一、SIR 模型——经典仓室模型

### 1.1 模型假设

- 总人口 $N$ 恒定（不考虑出生死亡）
- 人群均匀混合（homogeneous mixing）
- 传播为频率依赖型：感染风险 $\propto I/N$（标准发生率）
- 感染后以恒定速率 $\gamma$ 康复，且获得永久免疫
- 疾病无潜伏期（感染者立即具有传染性）

### 1.2 微分方程

$$\begin{cases} \dfrac{dS}{dt} = -\beta S \dfrac{I}{N} \\[8pt] \dfrac{dI}{dt} = \beta S \dfrac{I}{N} - \gamma I \\[8pt] \dfrac{dR}{dt} = \gamma I \end{cases}$$

**参数解释：**
- $\beta$：有效接触率（单位时间内与感染者有效接触并传播的概率 × 接触率）
- $\gamma$：恢复率（$\frac{1}{\gamma}$ 为平均感染期）
- $S + I + R = N$（守恒恒等式）

### 1.3 无量纲化

令 $s = S/N$，$i = I/N$，$r = R/N$（$\tau = \gamma t$）：

$$\begin{cases} \dfrac{ds}{d\tau} = -R_0 s i \\[6pt] \dfrac{di}{d\tau} = R_0 s i - i \\[6pt] \dfrac{dr}{d\tau} = i \end{cases}$$

系统由单一参数 $R_0 = \beta / \gamma$ 完全刻画。

## 二、基本再生数 $R_0$

### 2.1 定义与推导

**基本再生数（basic reproduction number）：** 在完全易感人群中，一个典型感染者在其整个感染期间平均传染的人数。

$$R_0 = \frac{\beta}{\gamma}$$

- $\beta$：单位时间内平均产生 $\beta$ 个有效接触（假设全员易感）
- $1/\gamma$：平均感染期长度
- 因此 $R_0 = \beta \times (1/\gamma)$ = 传染率 × 传染时间

### 2.2 $R_0$ 的流行病学意义

| $R_0$ 值 | 动力学含义 |
|:---:|:---|
| $R_0 < 1$ | 疫情自然消退（每个感染者传播少于 1 人） |
| $R_0 = 1$ | 临界阈值——感染人数恒定，地方病平衡 |
| $R_0 > 1$ | 疫情爆发（指数增长初期） |

### 2.3 典型疾病 $R_0$ 参考值

| 疾病 | 估计 $R_0$ | 传播途径 |
|:---|---:|:---|
| 麻疹 | 12–18 | 空气飞沫 |
| 百日咳 | 12–17 | 空气飞沫 |
| 白喉 | 6–7 | 唾液 |
| 天花 | 5–7 | 近距离接触 |
| COVID-19 (原始株) | 2.5–3.5 | 飞沫 + 空气 |
| 流感 (1918) | 1.8–2.0 | 飞沫 |
| 埃博拉 | 1.5–2.5 | 体液接触 |

### 2.4 敏感性分析（$R_0$ 的参数依赖）

从 $R_0 = \beta/\gamma$：
- 降低 $\beta$（社交距离、口罩、减少接触）直接降低 $R_0$
- 增大 $\gamma$（缩短感染期，如抗病毒治疗）也降低 $R_0$
- 免疫比例 $p$ 使有效再生数 $R_{\text{eff}} = R_0(1-p)$

## 三、SIR 模型的数学分析

### 3.1 相平面分析

消去时间 $t$，由 $dI/dS$：

$$\frac{dI}{dS} = \frac{\beta SI/N - \gamma I}{-\beta SI/N} = -1 + \frac{\gamma N}{\beta S} = -1 + \frac{N}{R_0 S}$$

分离变量积分（$R_0 = \beta / \gamma$）：

$$\int dI = \int\left(-1 + \frac{N}{R_0 S}\right)dS$$

$$I = -S + \frac{N}{R_0}\ln S + C$$

积分常数由初始条件确定：$C = I_0 + S_0 - \frac{N}{R_0}\ln S_0$

### 3.2 无病平衡点

$$E_0 = (S^*, I^*, R^*) = (N, 0, 0)$$

**雅可比矩阵：**

$$\mathbf{J}(S,I) = \begin{pmatrix} -\beta I/N & -\beta S/N \\[4pt] \beta I/N & \beta S/N - \gamma \end{pmatrix}$$

在 $E_0$ 处：

$$\mathbf{J}(N,0) = \begin{pmatrix} 0 & -\beta \\[4pt] 0 & \beta - \gamma \end{pmatrix}$$

特征值：$\lambda_1 = 0$（由守恒 $S+I+R=N$ 导致），$\lambda_2 = \beta - \gamma$。

- $\beta - \gamma < 0 \iff R_0 < 1$：$E_0$ 局部渐近稳定（无病平衡吸引）
- $\beta - \gamma > 0 \iff R_0 > 1$：$E_0$ 不稳定（疫情爆发）

### 3.3 地方病平衡点（带出生死亡的 SIR）

若引入出生率 $\Lambda$ 和自然死亡率 $\mu$（$dS/dt = \Lambda - \beta SI/N - \mu S$），则 $R_0 = \beta/(\gamma + \mu)$。

当 $R_0 > 1$ 时，存在唯一正的地方病平衡点：

$$S^* = \frac{N}{R_0}, \quad I^* = \frac{\mu N}{\beta}(R_0 - 1) = \frac{\Lambda}{\gamma + \mu}\left(1 - \frac{1}{R_0}\right)$$

其中 $N = \Lambda/\mu$。$I^*$ 随 $R_0$ 增大而单调递增。

## 四、最终规模关系（Final Size Relation）

### 4.1 推导

疫情结束时 $I_\infty = 0$。由相平面轨线，$t \to \infty$ 时：

$$I_\infty + S_\infty - \frac{N}{R_0}\ln S_\infty = I_0 + S_0 - \frac{N}{R_0}\ln S_0$$

设 $S(0) \approx N$（绝大多数人为易感者），$I(0) \approx 0$：

$$S_\infty - \frac{N}{R_0}\ln S_\infty = N$$

### 4.2 超越方程

定义攻击率（attack rate）$z = 1 - S_\infty/N$（即最终被感染的比例）：

$$z = 1 - e^{-R_0 z}$$

或等价地：

$$\ln\left(1 - z\right) = -R_0 z$$

这是 $z$ 的超越方程，其解为：

$$z = 1 + \frac{1}{R_0} W(-R_0 e^{-R_0})$$

其中 $W$ 为 Lambert $W$ 函数（多值，取其 0 分支）。

### 4.3 大 $R_0$ 渐近

当 $R_0 \gg 1$ 时，$z \to 1 - e^{-R_0}$，即几乎全部人口最终被感染。

## 五、流行病阈值理论

### 5.1 爆发条件

由 $dI/dt|_{t=0} = (\beta S_0/N - \gamma)I_0$，初始爆发条件为：

$$S_0 > \frac{\gamma N}{\beta} = \frac{N}{R_0}$$

等价地：**易感比例** $s_0 = S_0/N > 1/R_0$ 时爆发。

### 5.2 峰值大小

疫情达到峰值时 $dI/dt = 0$，即 $S_{\text{peak}} = N/R_0$：

$$I_{\text{max}} = I_0 + S_0 - \frac{N}{R_0} - \frac{N}{R_0}\ln\left(\frac{S_0 R_0}{N}\right)$$

- $I_{\text{max}}$ 决定医疗资源是否超载
- 更高 $R_0$ 意味着更高 $I_{\text{max}}$

## 六、SEIR、SIS 与 SIRS 变体

### 6.1 SEIR 模型（带潜伏期）

$$\begin{cases} \dfrac{dS}{dt} = -\beta S \dfrac{I}{N} \\[8pt] \dfrac{dE}{dt} = \beta S \dfrac{I}{N} - \sigma E \\[8pt] \dfrac{dI}{dt} = \sigma E - \gamma I \\[8pt] \dfrac{dR}{dt} = \gamma I \end{cases}$$

**新增参数：** $\sigma$ 为潜伏期倒数（$1/\sigma$ 为平均潜伏期）。

**基本再生数**通过下一代矩阵法（next-generation matrix）计算：

$$R_0 = \frac{\beta}{\gamma} \cdot \frac{\sigma}{\sigma + \gamma}$$

- 潜伏期的引入降低有效 $R_0$（部分个体在潜伏期内可能因其他原因死亡）
- SEIR 优于 SIR 之处：峰值延迟、更符合潜伏期疾病

### 6.2 SIS 模型（无免疫）

适用于不产生永久免疫的疾病（如某些性传播疾病、细菌感染）：

$$\begin{cases} \dfrac{dS}{dt} = -\beta S \dfrac{I}{N} + \gamma I \\[8pt] \dfrac{dI}{dt} = \beta S \dfrac{I}{N} - \gamma I \end{cases}$$

利用 $S = N - I$，化简为一维方程：

$$\frac{dI}{dt} = (\beta - \gamma)I - \frac{\beta}{N}I^2 = \gamma(R_0 - 1)I - \frac{\beta}{N}I^2$$

这正是**Logistic 方程**！因此 SIS 的动力学内含了 S 型增长。

**平衡点：**
- $I^* = 0$（无病平衡）：$R_0 \leq 1$ 时稳定
- $I^* = N(1 - 1/R_0)$（地方病平衡）：$R_0 > 1$ 时全局渐近稳定

### 6.3 SIRS 模型（有限期免疫）

$$\begin{cases} \dfrac{dS}{dt} = -\beta S \dfrac{I}{N} + \omega R \\[8pt] \dfrac{dI}{dt} = \beta S \dfrac{I}{N} - \gamma I \\[8pt] \dfrac{dR}{dt} = \gamma I - \omega R \end{cases}$$

其中 $\omega$ 为免疫丧失率（平均免疫期 $1/\omega$）。$R_0 = \beta / \gamma$ 不变。当 $R_0 > 1$ 时，存在全局渐近稳定的地方病平衡点——阻尼振荡收敛。

## 七、疫苗接种与群体免疫

### 7.1 疫苗效力与覆盖率

设疫苗效力为 $VE$（vaccine efficacy），接种覆盖率为 $p$。有效免疫比例为 $p \cdot VE$。

**有效再生数（effective reproduction number）：**

$$R_{\text{eff}} = R_0 \cdot (1 - p \cdot VE)$$

### 7.2 群体免疫阈值

消除传播所需的最小免疫比例 $p_c$ 满足 $R_{\text{eff}} = 1$：

$$p_c = \frac{1 - \frac{1}{R_0}}{VE}$$

若 $VE = 100\%$（完美疫苗），则：

$$\boxed{p_c = 1 - \frac{1}{R_0}}$$

### 7.3 群体免疫阈值的计算示例

| 疾病 | $R_0$ | $p_c$（完美疫苗） |
|:---|---:|:---:|
| 麻疹 | 15 | 93% |
| 百日咳 | 15 | 93% |
| 天花 | 6 | 83% |
| COVID-19 | 3 | 67% |
| 流感 | 1.5 | 33% |

### 7.4 疫苗方程的微分形式

在 SIR 中引入疫苗接种子比例（立即免疫）：

$$S(0) = (1 - p)N, \quad R(0) = pN$$

其余方程不变。$R_{\text{eff}} = R_0(1-p)$。

## 八、隔离与控制措施的建模

### 8.1 通过拉低 $\beta$ 实现控制

设不受控传染率为 $\beta_0$，控制强度为 $q \in [0,1]$：

$$\beta_{\text{eff}} = (1 - q)\beta_0$$

$$R_{\text{eff}} = \frac{(1 - q)\beta_0}{\gamma} = (1 - q)R_0$$

### 8.2 时变控制强度

实际防控（如 lockdown）随时间变化 $q(t)$：

$$\frac{dI}{dt} = (1 - q(t))\beta S I/N - \gamma I$$

$R_{\text{eff}}(t) = (1 - q(t))R_0 \cdot S(t)/N$，需始终低于 1 以控制疫情。

## 九、复杂网络传播动力学

### 9.1 异质网络

实际接触并非均匀混合——某些个体有更多连接（"超级传播者"）。

设网络度分布为 $P(k)$（随机选一个节点有 $k$ 个邻居的概率），平均度 $\langle k \rangle$。

在配置模型网络中，通过 SIR 的线性化分析：

$$R_0^{\text{network}} = \frac{\beta}{\gamma} \cdot \frac{\langle k^2 \rangle - \langle k \rangle}{\langle k \rangle}$$

**关键结论：** 若 $P(k)$ 为幂律分布（度异质性高），则 $\langle k^2 \rangle \gg \langle k \rangle^2$，$R_0^{\text{network}}$ 可能非常大——即使 $\beta/\gamma$ 很小，异质性传播仍可使 $R_0 > 1$。

### 9.2 无标度网络的无阈值现象

在无限无标度网络中（$P(k) \sim k^{-\gamma}$，$2 < \gamma \leq 3$），$\langle k^2 \rangle \to \infty$ 意味着 $R_0 \to \infty$——不存在非零的流行阈值！即任意 $\beta > 0$ 均可引发大规模爆发。

这解释了为何某些疾病（如计算机病毒）即使在传播率极低的情况下也能持续存在。

### 9.3 均匀混合 vs 网络 SIR 比较

| 特性 | 均匀混合 SIR | 网络 SIR |
|:---|:---|:---|
| $R_0$ | $\beta /\gamma$ | $\frac{\beta}{\gamma} \cdot \frac{\langle k^2 \rangle}{\langle k \rangle}$ |
| 阈值 | $R_0 > 1$ | 取决于度分布 |
| 最终规模 | $z = 1 - e^{-R_0 z}$ | 由相关组分大小决定 |
| 超级传播者 | 未建模 | 自然产生（高度节点） |

## 十、空间传播与反应扩散模型

### 10.1 空间 SIR

$$\begin{cases} \dfrac{\partial S}{\partial t} = D_S \nabla^2 S - \beta S I / N \\[8pt] \dfrac{\partial I}{\partial t} = D_I \nabla^2 I + \beta S I / N - \gamma I \\[8pt] \dfrac{\partial R}{\partial t} = D_R \nabla^2 R + \gamma I \end{cases}$$

### 10.2 最小传播速度

Fisher-KPP 类比：一维行波解 $S(x - ct), I(x - ct)$ 的最小波速：

$$c_{\min} = 2\sqrt{D_I(\beta - \gamma)} = 2\sqrt{D_I \gamma (R_0 - 1)}$$

- $c_{\min} > 0$ 当且仅当 $R_0 > 1$
- 扩散系数 $D_I$ 越大，疫情传播越快
- 高 $R_0$ 加速空间传播

## 十一、随机灭绝概率

### 11.1 连续时间马尔可夫链

在连续时间随机 SIR 模型中（种群大小 $N$ 有限），当 $I$ 很小时随机效应显著。

从 $I_0$ 个初始感染者出发，疫情爆发（不立即灭绝）的概率近似为：

$$P(\text{爆发} \mid I_0) \approx 1 - \left(\frac{1}{R_0}\right)^{I_0}$$

当 $R_0 > 1$ 且 $I_0 = 1$ 时，灭绝概率为 $1/R_0$。

### 11.2 含义

即使 $R_0 > 1$，小疫情仍有不可忽略的灭绝概率（随机消失）。这也是各国执行"清零"策略的数学基础——在 $I_0$ 很小时通过接触追踪和隔离消灭传播链。

## 十二、关键要点总结

1. **SIR 模型**：$\dot{S} = -\beta SI/N$，$\dot{I} = \beta SI/N - \gamma I$，守恒 $S+I+R=N$
2. **基本再生数**：$R_0 = \beta / \gamma$，$R_0 > 1$ 爆发，$R_0 < 1$ 消退
3. **最终规模**：$z = 1 - e^{-R_0 z}$，超越函数由 Lambert $W$ 给出
4. **SEIR 模型**：引入潜伏期 E，$R_0 = \frac{\beta}{\gamma} \cdot \frac{\sigma}{\sigma+\gamma}$，峰值延迟
5. **SIS 模型**：无免疫，简化为 Logistic 方程，地方病平衡点
6. **群体免疫**：$p_c = 1 - 1/R_0$（完美疫苗），$R_{\text{eff}} < 1$ 终止传播
7. **网络 SIR**：度分布异质性提高 $R_0$，无标度网络无阈值
8. **随机 SIR**：小 $I_0$ 下灭绝概率 $1/R_0^{I_0}$，爆发不确定性大
