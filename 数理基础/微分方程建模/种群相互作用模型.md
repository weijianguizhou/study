## 一、经典 Lotka-Volterra 捕食者-猎物模型

### 1.1 模型方程

设 $x(t)$ 为猎物密度，$y(t)$ 为捕食者密度：

$$\begin{cases} \dfrac{dx}{dt} = \alpha x - \beta xy \\[8pt] \dfrac{dy}{dt} = \delta xy - \gamma y \end{cases}$$

**参数含义：**
- $\alpha$：猎物内禀增长率（无捕食者时）
- $\beta$：捕食率系数（单位捕食者单位时间捕食的猎物数）
- $\delta$：转化效率（每消耗一个猎物产生的新捕食者数）
- $\gamma$：捕食者自然死亡率

### 1.2 无相互作用平衡点

$$E_0 = (0, 0) \quad \text{（灭绝平衡点）}$$

雅可比矩阵：

$$\mathbf{J}(0, 0) = \begin{pmatrix} \alpha & 0 \\ 0 & -\gamma \end{pmatrix}$$

特征值 $\lambda_1 = \alpha > 0$，$\lambda_2 = -\gamma < 0$ → **鞍点**，不稳定。

### 1.3 共存平衡点

$$E_1 = (x^*, y^*) = \left(\frac{\gamma}{\delta}, \frac{\alpha}{\beta}\right)$$

**含义：**

- 猎物平衡密度 $x^*$ 完全由捕食者的参数（死亡率与转化效率之比）决定——捕食者"调控"猎物
- 捕食者平衡密度 $y^*$ 完全由猎物的参数（增长率与捕食率之比）决定——猎物"供养"捕食者

雅可比矩阵在 $E_1$：

$$\mathbf{J}(x^*, y^*) = \begin{pmatrix} \alpha - \beta y^* & -\beta x^* \\[4pt] \delta y^* & \delta x^* - \gamma \end{pmatrix} = \begin{pmatrix} 0 & -\beta \gamma/\delta \\[4pt] \alpha \delta/\beta & 0 \end{pmatrix}$$

特征方程：

$$\det(\mathbf{J} - \lambda \mathbf{I}) = \lambda^2 + \alpha\gamma = 0$$

$$\lambda = \pm i\sqrt{\alpha\gamma}$$

**纯虚特征值 → 中心点**（线性化为中性稳定）。

### 1.4 Hamilton 首次积分

经典 Lotka-Volterra 系统是**Hamilton 系统**，存在守恒量：

$$H(x, y) = \delta x - \gamma \ln x + \beta y - \alpha \ln y$$

沿解曲线 $\dfrac{dH}{dt} = 0$，故 $H(x, y) = C$（常数）。

**含义：** 相轨线为闭合轨道——种群呈现**周期性振荡**，振幅由初始条件决定。

### 1.5 平均密度与周期

**平均密度（沿一完整周期）：**

$$\bar{x} = \frac{1}{T}\int_0^T x(t) dt = \frac{\gamma}{\delta} = x^*$$

$$\bar{y} = \frac{1}{T}\int_0^T y(t) dt = \frac{\alpha}{\beta} = y^*$$

即**时间平均值等于平衡点数值**（等距原理）。

**周期近似（小振幅）：**

$$T \approx \frac{2\pi}{\sqrt{\alpha\gamma}}$$

## 二、带承载力的修正 LV 模型

### 2.1 方程

$$\begin{cases} \dfrac{dx}{dt} = \alpha x\left(1 - \dfrac{x}{K}\right) - \beta xy \\[8pt] \dfrac{dy}{dt} = \delta xy - \gamma y \end{cases}$$

其中 $K$ 为猎物环境承载力。

### 2.2 共存平衡点

$$x^* = \frac{\gamma}{\delta}, \quad y^* = \frac{\alpha}{\beta}\left(1 - \frac{x^*}{K}\right) = \frac{\alpha}{\beta}\left(1 - \frac{\gamma}{\delta K}\right)$$

共存条件：$K > \gamma / \delta$（承载力必须超过捕食者生存所需的最小猎物密度）。

### 2.3 稳定性

雅可比矩阵在共存平衡点：

$$\mathbf{J} = \begin{pmatrix} -\dfrac{\alpha x^*}{K} & -\beta x^* \\[4pt] \delta y^* & 0 \end{pmatrix}$$

$$\text{tr}(\mathbf{J}) = -\frac{\alpha x^*}{K} < 0$$

$$\det(\mathbf{J}) = \beta \delta x^* y^* > 0$$

**正的行列式 + 负的迹 → 稳定焦点或稳定节点**（阻尼振荡收敛或单调收敛）。

### 2.4 与经典 LV 的关键区别

| 特性 | 经典 LV | 带承载力 LV |
|:---|:---|:---|
| 稳定性 | 中性稳定（中心） | 渐近稳定（焦点/节点） |
| 振荡 | 持续振荡 | 阻尼振荡 |
| 振幅依赖性 | 由初始条件决定 | 无（收敛至平衡点） |
| 周期 | 约 $2\pi/\sqrt{\alpha\gamma}$ | 无周期（焦点）或非周期 |

## 三、Holling 功能反应函数

### 3.1 概念

功能反应（functional response）$f(x)$：单个捕食者在单位时间内捕食的猎物数量，为猎物密度 $x$ 的函数。

数示反应（numerical response）：将功能反应的产出转化为捕食者繁殖（$g(x) \propto f(x)$）。

### 3.2 Holling Type I — 线性型

$$f_I(x) = ax$$

- 捕食率无上限，随猎物密度线性增长
- 对应经典 LV 模型的捕食项
- 适用于滤食性生物（如须鲸吞食磷虾）

### 3.3 Holling Type II — 圆盘方程

$$f_{II}(x) = \frac{ax}{b + x}$$

- $a$：最大捕食率（饱和上限）
- $b$：半饱和常数——$x = b$ 时 $f_{II}(x) = a/2$
- 源于 Holling (1959) 的"圆盘实验"
- **机理**：捕食者需要处理时间（handling time）$\tau_h$，导致捕食率饱和

**参数化与处理时间的关系：** $a = 1 / \tau_h$，$b = 1 / (c \tau_h)$，其中 $c$ 为搜寻效率。

### 3.4 Holling Type III — 加速型（S 型）

$$f_{III}(x) = \frac{ax^n}{b^n + x^n}, \quad n > 1$$

（通常取 $n = 2$）

- 低密度时捕食率低（猎物稀少时捕食者不易定位/切换搜索图像）
- 密度增加时捕食率加速上升，随后饱和
- 适用于捕食者存在**搜索图像转换**（prey switching）的情景

### 3.5 Holling Type IV — 减速型（Monod-Haldane）

$$f_{IV}(x) = \frac{ax}{b + x^2}$$

- 高猎物密度时捕食率**下降**（猎物形成防御集群或毒素释放导致捕食者逐避）

### 3.6 Holling 类型的极限环条件

对 Holling II 型功能反应下的捕食者-猎物模型：

$$\begin{cases} \dfrac{dx}{dt} = rx\left(1 - \dfrac{x}{K}\right) - \dfrac{axy}{b + x} \\[8pt] \dfrac{dy}{dt} = \dfrac{e a x y}{b + x} - dy \end{cases}$$

共存平衡点在参数空间某区域成为**不稳定焦点**，由 Hopf 分岔产生**极限环**（稳定周期振荡）。Holling I 型（线性）的带承载力 LV 无极限环。

## 四、种间竞争模型

### 4.1 Lotka-Volterra 竞争方程

$$\begin{cases} \dfrac{dx_1}{dt} = r_1 x_1 \left(1 - \dfrac{x_1 + \alpha_{12}x_2}{K_1}\right) \\[8pt] \dfrac{dx_2}{dt} = r_2 x_2 \left(1 - \dfrac{x_2 + \alpha_{21}x_1}{K_2}\right) \end{cases}$$

- $\alpha_{12}$：物种 2 的一单位对物种 1 产生的竞争压力（等效于 $\alpha_{12}$ 个物种 1 个体）
- $\alpha_{21}$：物种 1 的一单位对物种 2 产生的竞争压力

### 4.2 零增长等斜线（Nullclines）

等斜线 $dx_1/dt = 0$（物种 1 的零等斜）：

$$x_2 = \frac{K_1 - x_1}{\alpha_{12}}$$

等斜线 $dx_2/dt = 0$（物种 2 的零等斜）：

$$x_2 = K_2 - \alpha_{21} x_1$$

### 4.3 四种竞争结果

**情况 1：稳定共存**

条件：$\alpha_{12} < K_1/K_2$ 且 $\alpha_{21} < K_2/K_1$（等价于 $\alpha_{12} \alpha_{21} < 1$）

> 种内竞争强于种间竞争——两个物种共存于唯一正的内部平衡点

**情况 2：不稳定共存（双稳态）**

条件：$\alpha_{12} > K_1/K_2$ 且 $\alpha_{21} > K_2/K_1$（等价于 $\alpha_{12} \alpha_{21} > 1$）

> 种间竞争强于种内竞争——胜利者取决于初始条件（历史效应）

**情况 3：物种 1 胜出**

条件：$\alpha_{12} < K_1/K_2$ 且 $\alpha_{21} > K_2/K_1$

> 物种 2 对物种 1 的竞争弱，物种 1 对物种 2 的竞争强 → 物种 2 灭绝

**情况 4：物种 2 胜出**

条件：$\alpha_{12} > K_1/K_2$ 且 $\alpha_{21} < K_2/K_1$

> 对称于情况 3

### 4.4 竞争排斥原理（Gause 原理）

**数学表述：** 当 $\alpha_{12} = \alpha_{21} = 1$ 且 $K_1 \neq K_2$ 时，两物种不能共存——$K$ 更大的物种在竞争中胜出。

**生态学含义：** 两个生态位完全相同的物种无法长期共存。竞争排斥原理的数学基础正是上述四种竞争结果分析。

## 五、Tilman $R^*$ 理论

### 5.1 资源显式模型

不同于 LV 模型的隐含竞争，Tilman (1982) 显式建模资源动态：

$$\frac{dR_j}{dt} = \rho_j(S_j - R_j) - \sum_{i=1}^{n} c_{ij} N_i R_j$$

$$\frac{dN_i}{dt} = N_i\left(\sum_j e_{ij} c_{ij} R_j - m_i\right)$$

其中：
- $R_j$：资源 $j$ 的密度
- $S_j$：资源 $j$ 的供应浓度
- $\rho_j$：资源的周转速率
- $c_{ij}$：物种 $i$ 对资源 $j$ 的消费率
- $e_{ij}$：转化效率
- $m_i$：物种 $i$ 的死亡率

### 5.2 $R^*$ 规则

在平衡态，单物种 $i$ 的资源稳态浓度：

$$R_{ij}^* = \frac{m_i}{e_{ij} c_{ij}}$$

**$R^*$ 竞争规则：** 在单一限制性资源下，$R^*$ 最小的物种在竞争中胜出（它能在其他物种灭绝的低资源水平下维持正增长）。

- $R^*$ 规则提供了资源竞争的直观预测
- 解释了为何物种分化（利用不同资源）可以共存
- 多种资源下，共存需要物种数 $\leq$ 资源数

## 六、互利共生模型

### 6.1 无条件互利共生

$$\begin{cases} \dfrac{dN_1}{dt} = r_1 N_1 \left(1 - \dfrac{N_1 - \alpha_{12} N_2}{K_1}\right) \\[8pt] \dfrac{dN_2}{dt} = r_2 N_2 \left(1 - \dfrac{N_2 - \alpha_{21} N_1}{K_2}\right) \end{cases}$$

**注意：** 共生模型中等斜线交叉项的符号为正（+ $\alpha_{ij} N_j$），表示另一物种的存在**提高**了有效承载力。

- 无界增长风险：若 $\alpha_{12}\alpha_{21} \geq 1$，正反馈导致无界爆炸
- 约束条件：需 $\alpha_{12}\alpha_{21} < 1$ 以保证有界平衡

### 6.2 兼性 vs 专性共生

**兼性共生**（两个物种均可独立生存）：

$$\frac{dN_1}{dt} = r_1 N_1\left(1 - \frac{N_1}{K_1}\right) + \beta_{12} N_1 N_2$$

**专性共生**（物种 1 依赖物种 2 生存）：

$$\frac{dN_1}{dt} = N_1(-d_1 + \beta_{12} N_2)$$

专性共生存在灭绝风险——当伙伴密度低于关键阈值时。

### 6.3 偏利共生

物种 1 不受物种 2 影响，但物种 2 受益于物种 1：

$$\begin{cases} \dfrac{dN_1}{dt} = r_1 N_1 \left(1 - \dfrac{N_1}{K_1}\right) \\[8pt] \dfrac{dN_2}{dt} = r_2 N_2 \left(1 - \dfrac{N_2 - \alpha_{21} N_1}{K_2}\right) \end{cases}$$

海洋中鮣鱼（吸附大型海洋生物）与寄主的关系即偏利共生。

## 七、反应扩散系统与 Turing 不稳定性

### 7.1 一维反应扩散捕食者-猎物系统

$$\begin{cases} \dfrac{\partial x}{\partial t} = D_x \dfrac{\partial^2 x}{\partial \xi^2} + f(x, y) \\[8pt] \dfrac{\partial y}{\partial t} = D_y \dfrac{\partial^2 y}{\partial \xi^2} + g(x, y) \end{cases}$$

其中 $f, g$ 为局部动力学（如捕食者-猎物或竞争方程），$D_x, D_y$ 为扩散系数。

### 7.2 线性稳定性分析与色散关系

设 $(x^*, y^*)$ 为均匀稳态。考虑扰动：

$$\begin{pmatrix} \tilde{x} \\ \tilde{y} \end{pmatrix} = \begin{pmatrix} \hat{x} \\ \hat{y} \end{pmatrix} e^{\sigma t + i k \xi}$$

代入线性化系统：

$$\sigma \begin{pmatrix} \hat{x} \\ \hat{y} \end{pmatrix} = \left[\mathbf{J} - k^2 \begin{pmatrix} D_x & 0 \\ 0 & D_y \end{pmatrix}\right] \begin{pmatrix} \hat{x} \\ \hat{y} \end{pmatrix}$$

其中 $\mathbf{J} = \begin{pmatrix} f_x & f_y \\ g_x & g_y \end{pmatrix}$ 为反应项的 Jacobian 矩阵。

非平凡解要求：

$$\det\begin{pmatrix} f_x - D_x k^2 - \sigma & f_y \\ g_x & g_y - D_y k^2 - \sigma \end{pmatrix} = 0$$

展开得**色散关系**：

$$\sigma^2 - \tau(k^2) \sigma + \Delta(k^2) = 0$$

其中：

$$\tau(k^2) = \text{tr}(\mathbf{J}) - (D_x + D_y)k^2$$

$$\Delta(k^2) = \det(\mathbf{J}) - (D_x g_y + D_y f_x)k^2 + D_x D_y k^4$$

### 7.3 Turing 不稳定性条件

均匀稳态在无扩散时稳定（$\sigma(k=0)$ 有负实部），但在某波数 $k > 0$ 下不稳定。必要条件：

1. **反应稳定：** $\text{tr}(\mathbf{J}) = f_x + g_y < 0$，$\det(\mathbf{J}) = f_x g_y - f_y g_x > 0$
2. **扩散驱动不稳定：** 存在 $k^2 > 0$ 使得 $\text{Re}(\sigma(k^2)) > 0$

推导得关键的 Turing 条件：

$$D_y f_x + D_x g_y > 2\sqrt{D_x D_y \det(\mathbf{J})}$$

**必要条件：**
- $f_x$ 与 $g_y$ 异号（必须一个是活化子，一个是抑制子）
- $D_y \gg D_x$（抑制子系统扩散远快于活化子系统——**长程抑制 + 短程活化**）

### 7.4 临界波数

最不稳定波数（$\sigma$ 最大对应的 $k$）：

$$k_c^2 = \sqrt{\frac{\det(\mathbf{J})}{D_x D_y}}$$

对应的**特征图案波长：**

$$\lambda_c = \frac{2\pi}{k_c} = 2\pi \left(\frac{D_x D_y}{\det(\mathbf{J})}\right)^{1/4}$$

### 7.5 Turing 斑图在生态学中的应用

| 现象 | 机制 | 文献 |
|:---|:---|:---|
| 植物半干旱区带状分布 | 水扩散 + 植物生长 | Klausmeier (1999) |
| 贻贝潮间带迷宫状斑图 | 捕食者-猎物 + 扩散 | van de Koppel et al. (2005) |
| 浮游动物空间斑块 | 活化-抑制动力学 | Levin & Segel (1976) |
| 珊瑚礁规则空间分布 | 藻类-珊瑚竞争扩散 | Mistro et al. (2012) |

### 7.6 数值示例：一维植被斑图

```python
# 一维捕食者-猎物反应扩散模拟草图
# dx/dt = D_x * d^2x/dξ^2 + rx(1-x/K) - axy/(b+x)
# dy/dt = D_y * d^2y/dξ^2 + e*axy/(b+x) - my

L = 100; N = 200; dx_val = L/N
Dx, Dy = 0.01, 1.0  # 抑制子扩散 >> 活化子扩散

# 5点拉普拉斯算子
laplacian_1d = lambda u: (np.roll(u,-1) + np.roll(u,1) - 2*u) / dx_val**2

for step in range(T_steps):
    Lu = laplacian_1d(u); Lv = laplacian_1d(v)
    u += dt * (Dx * Lu + f(u, v))
    v += dt * (Dy * Lv + g(u, v))
```

## 八、多物种网络动力学

### 8.1 广义 Lotka-Volterra (gLV)

$$\frac{dN_i}{dt} = N_i\left(r_i + \sum_{j=1}^{S} A_{ij} N_j\right), \quad i = 1,\ldots,S$$

其中交互矩阵 $\mathbf{A} = [A_{ij}]$ 的元素 $A_{ij}$ 表示物种 $j$ 对物种 $i$ 单位密度的效应。

- $A_{ii} < 0$：种内竞争（密度制约）
- $A_{ij} < 0, i \neq j$：竞争 / 捕食
- $A_{ij} > 0$：共生（互利 / 猎物 → 捕食者）
- 捕食者-猎物对：$A_{ij} < 0$（猎物被吃），$A_{ji} > 0$（捕食者受益）

### 8.2 May 的复杂性-稳定性关系

Robert May (1972) 发现：**大型随机生态网络往往不稳定**。对于随机交互矩阵 $\mathbf{A}$（非对角元均值为 0、方差 $\sigma^2$）：

$$\sqrt{S}\sigma < C \quad \text{（稳定性条件）}$$

其中 $C$ 为种内自调节强度。$S$ 越大、$\sigma$ 越大，系统越不稳定。这与直觉相反——自然界生物多样性高，是因其并非完全随机。

### 8.3 嵌套性与模块化

真实生态网络的结构特征（嵌套性 nestedness、模块化 modularity）增强了系统的稳定性。不同于 May 的随机矩阵，真实互作网络的非随机拓扑结构（如食物网的 trophic coherence）是维持生物多样性的关键。

## 九、分岔总结

| 模型 | 分岔类型 | 参数条件 | 新吸引子 |
|:---|:---|:---|:---|
| 经典 LV | 无 | — | — |
| 带承载力 LV (Holling I) | 无（焦点稳定） | 无条件 | — |
| Holling II 捕食者-猎物 | **Hopf 分岔** | 承载力 $K$ 增大 | 极限环 |
| LV 竞争 | 跨临界分岔 | 等斜线相对位置变化 | 物种替换 |
| Turing | **Turing 分岔** | $D_y/D_x$ 越过临界值 | 空间斑图 |

## 十、关键要点总结

1. **经典 LV 模型**：Hamilton 系统，守恒量 $H(x,y)$，中心点，闭合轨道
2. **带承载力 LV**：稳定焦点 / 节点，阻尼振荡收敛
3. **Holling 功能反应**：I 型线性（无饱和），II 型饱和（处理时间），III 型 S 型（搜索图像），IV 型减速（高密度回避）
4. **Holling II 型 + 带承载力** → Hopf 分岔 → 极限环
5. **LV 竞争方程**：四种结果取决于 $\alpha_{12}\alpha_{21} \lessgtr 1$ 以及等斜线相对位置
6. **竞争排斥原理**：生态位完全相同则不能共存（$\alpha_{12}=\alpha_{21}=1$ 且 $K_1 \neq K_2$）
7. **Tilman $R^*$ 理论**：$R^*$ 最小的物种胜出，资源分化促进共存
8. **Turing 不稳定性**：长程抑制 + 短程活化 + 扩散比悬殊 → 自发斑图形成
9. **May 理论**：大型随机生态网络不稳定；真实网络因嵌套性和模块性而稳定
10. **$N_i(r_i + \sum A_{ij}N_j)$** 是生态动力学最通用的建模框架
