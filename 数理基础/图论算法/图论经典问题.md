# 图论经典问题 —— 数学理论

## 第一部分：最小生成树（MST）

### 1. 问题定义与基本性质

#### 1.1 形式化定义

给定连通无向加权图 $G = (V, E, w)$，其中 $w: E \to \mathbb{R}^+$。**最小生成树（MST）** $T = (V, E_T)$ 是 $G$ 的一个子图，满足：

- $T$ 是一棵树（连通且无环）
- $T$ 包含所有 $V$ 中的顶点
- 总权 $\sum_{e \in E_T} w(e)$ 在所有生成树中最小

$$\min_{T \in \mathcal{T}(G)} \sum_{e \in E_T} w(e)$$

其中 $\mathcal{T}(G)$ 是 $G$ 所有生成树的集合。

#### 1.2 生成树的存在性

**定理**：每个连通图至少有一棵生成树。证明：连通性保证了 BFS/DFS 可找到一棵生成树。

#### 1.3 切割性质（Cut Property）

> **引理**：对于任意非空严格子集 $S \subset V$，考虑切割 $(S, V \setminus S)$。设 $e$ 是跨此切割的权值最小的边。则存在一棵最小生成树包含 $e$。

**证明**：假设存在一棵 MST $T$ 不包含 $e$。在 $T$ 中添加 $e$ 会产生唯一的环。此环上必有一条跨切割的边 $e' \neq e$ 才能闭合。由假设，$w(e) \leq w(e')$。替换 $e'$ 为 $e$ 得到 $T'$，且 $w(T') = w(T) - w(e') + w(e) \leq w(T)$，故 $T'$ 也是 MST。

#### 1.4 环性质（Cycle Property）

> **引理**：对于图中任意环 $C$，设 $e$ 是 $C$ 上权值最大的边。则 $e$ 不属于任何最小生成树。

**证明**：假设存在 MST $T$ 包含 $e$。从 $T$ 中删除 $e$ 将 $T$ 分成两个连通分量 $S$ 和 $V \setminus S$。环 $C$ 上的其他边中至少有一条跨 $S$ 和 $V \setminus S$，设为 $e'$。由假设 $w(e') < w(e)$。用 $e'$ 替换 $e$ 得到更小权值的生成树，矛盾。

#### 1.5 唯一性

**推论**：若 $G$ 的所有边权重两两不同，则最小生成树是**唯一**的。

### 2. Kruskal 算法

#### 2.1 贪心选边 + 并查集

按权重升序遍历所有边。若该边的两端点属于不同的连通分量（用并查集判断），则将此边加入 MST 并合并两分量；否则跳过。

#### 2.2 伪代码

```
算法 Kruskal(G, w):
    T = 空集
    将 E 中的边按权重升序排列
    初始化并查集（每个顶点自成一个集合）
    for each (u, v) in sorted(E):
        if Find(u) != Find(v):
            T = T 并 {(u, v)}
            Union(u, v)
    return T
```

#### 2.3 正确性证明

**定理**：Kruskal 算法返回最小生成树。

**证明**：由环性质直接得证。被跳过的每条边在加入时都与已选边形成了环，且其权重不小于环上任何已选边，根据环性质，不应属于 MST。

**形式化**：对于每条被选中加入 $T$ 的边 $e = (u, v)$，在加入 $e$ 的时刻，将 $u$ 所在的连通分量记为 $S$。$e$ 是跨切割 $(S, V \setminus S)$ 的未处理边中权值最小的（边按权重升序处理，更小的边若跨切割也已被处理，但因为两分量尚未连通，它们也被选中了）。由切割性质，$e$ 属于某 MST。

#### 2.4 时间复杂度

- 排序边：$O(|E| \log |E|)$
- 并查集操作：$O(|E| \cdot \alpha(|V|))$，其中 $\alpha$ 是反阿克曼函数（实际可视为常数）
- **总计**：$O(|E| \log |E|)$

并查集的**路径压缩**与**按秩合并**保证均摊 $O(\alpha(n))$，其中 $\alpha$ 增长极慢（对任何实际输入 $\alpha(n) \leq 4$）。

### 3. Prim 算法

#### 3.1 贪心扩展

从任意起点出发，维护已选顶点集 $S$（初始 $S = \{s\}$）。每次选择连接 $S$ 与 $V \setminus S$ 的最小权边 $(u, v)$（其中 $u \in S, v \notin S$），将 $v$ 加入 $S$。

#### 3.2 伪代码

```
算法 Prim(G, w, s):
    for each v in V:
        key(v) = 无穷大
        pi(v) = NIL
    key(s) = 0
    Q = V   (以 key 为键的最小优先队列)
    while Q 非空:
        u = Extract-Min(Q)
        for each v in Adj(u):
            if v in Q and w(u, v) < key(v):
                pi(v) = u
                key(v) = w(u, v)
                Decrease-Key(Q, v, key(v))
    return {(pi(v), v) : v != s}
```

#### 3.3 正确性证明

**定理**：Prim 算法返回最小生成树。

**证明**：由切割性质直接得证。每次 Extract-Min 选出的边跨切割 $(S, V \setminus S)$，其中 $S$ 是已提取的顶点集。该边是跨此切割的最小权边，由切割性质属于某 MST。

#### 3.4 时间复杂度

| 实现方式 | 时间复杂度 | 适用图类型 |
|---------|-----------|-----------|
| 数组（线性扫描 Extract-Min） | $O(|V|^2)$ | 稠密图 $(|E| \approx |V|^2)$ |
| 二叉堆 + 邻接表 | $O((|V|+|E|)\log|V|)$ | 一般图 |
| 斐波那契堆 + 邻接表 | $O(|E| + |V|\log|V|)$ | 理论最优，稀疏图 |

对于稠密图，数组实现的 Prim 优于 Kruskal，因为避免了 $O(|V|^2 \log|V|)$ 的排序。

#### 3.5 Kruskal vs Prim

|  | Kruskal | Prim |
|--|---------|------|
| 核心数据结构 | 并查集 | 优先队列 |
| 最佳适用 | 稀疏图 | 稠密图（数组） |
| 并行性 | 边可独立处理（在合并阶段外） | 逐步扩展，较难并行 |
| 是否正确处理非连通图 | 输出最小生成森林 | 只生成包含起点的连通分量 |

## 第二部分：二部图匹配

### 4. 二部图与匹配

**二部图** $G = (U \cup V, E)$：每条边的一个端点在 $U$，另一个在 $V$。

**匹配（Matching）** $M \subseteq E$：任意两条边无公共顶点。

**最大匹配**：包含边数最多的匹配，记为 $\nu(G)$。

**完美匹配**：$|M| = |U| = |V|$，每个顶点均被匹配。

### 5. Konig 定理

> **定理（Konig, 1931）**：在二部图中，最大匹配的大小等于最小顶点覆盖的大小。
> $$\nu(G) = \tau(G)$$

其中 $\nu(G)$ 是最大匹配大小，$\tau(G)$ 是最小顶点覆盖大小。

**推论**：
- 最大独立集 = $|V| - \nu(G)$
- 最小边覆盖 = $|V| - \nu(G)$（无孤立点时）

**证明思路（通过最大流）**：构建流网络——源点 $s$ 连向 $U$ 中所有顶点（容量 1），$V$ 中所有顶点连向汇点 $t$（容量 1），原二部图的边方向为 $U \to V$（容量 $\infty$）。最大流的值 = 最大匹配的大小。

由 Min-Cut Max-Flow 定理，最大流 = 最小割容量。最小割对应最小顶点覆盖（被割边"切断"的顶点集合）。

### 6. Hall 婚姻定理

> **定理（Hall, 1935）**：二部图 $G = (U \cup V, E)$ 存在覆盖 $U$ 的匹配的充要条件是：
> $$\forall S \subseteq U, \quad |N(S)| \geq |S|$$
> 其中 $N(S)$ 是 $S$ 中所有顶点的邻居集合。

**必要性证明**：若存在匹配 $M$ 覆盖 $U$，则 $S$ 中的每个顶点通过 $M$ 匹配到 $N(S)$ 中的不同顶点，因此 $|N(S)| \geq |S|$。

**充分性证明（反证法 + Konig）**：假设最大匹配不能覆盖 $U$，即 $\nu(G) < |U|$。由 Konig 定理存在顶点覆盖 $C = A \cup B$（$A \subseteq U, B \subseteq V$），$|C| < |U|$。令 $S = U \setminus A$。可证 $N(S) \subseteq B$（因为任何 $S$ 中的顶点到 $V \setminus B$ 的边都不被 $C$ 覆盖，但 $C$ 是顶点覆盖，矛盾）。因此：
$$|N(S)| \leq |B| = |C| - |A| < |U| - |A| = |S|$$
违反 Hall 条件。证毕。

**推论**：若 $G$ 是 $r$-正则二部图（$r \geq 1$），则 $G$ 有完美匹配。

### 7. 匈牙利算法（最大匹配）

#### 7.1 增广路径

在匹配 $M$ 中，**交替路径**的边交错属于 $M$ 和非 $M$。**增广路径**是起点和终点均为未匹配顶点的交替路径。

**Berge 定理（1957）**：$M$ 是最大匹配当且仅当不存在关于 $M$ 的增广路径。

#### 7.2 算法

从 $U$ 的每个未匹配顶点出发，用 DFS 寻找增广路径。找到后沿路径"翻转"匹配状态（匹配边 ↔ 非匹配边），匹配大小 +1。

**时间复杂度**：$O(|U| \cdot |E|) = O(|V| \cdot |E|)$。

**Hopcroft-Karp 优化**：每轮用 BFS 构建层次图，DFS 寻找多条不相交的最短增广路径。复杂度 $O(\sqrt{|V|} \cdot |E|)$。

### 8. Kuhn-Munkres 算法（带权完美匹配 / 分配问题）

#### 8.1 问题

给定 $n \times n$ 代价矩阵 $C$，求排列 $\pi$ 最小化 $\sum_{i=1}^{n} C_{i, \pi(i)}$。

#### 8.2 顶点标号与等式子图

维护标号 $u_i$（行）和 $v_j$（列），满足**可行标号条件**：对所有 $i,j$，$u_i + v_j \leq C_{ij}$。

**等式子图** $G_{=} = \{(i, j) : u_i + v_j = C_{ij}\}$。

> **Kuhn-Munkres 定理**：若等式子图 $G_{=}$ 有完美匹配，则该匹配是原问题的最优分配。

#### 8.3 算法流程

1. 初始化：$u_i = \max_j C_{ij}$，$v_j = 0$
2. 在等式子图中用匈牙利算法求最大匹配
3. 若未达到完美匹配，计算：
   $$\delta = \min_{i \in S, j \notin T} (C_{ij} - u_i - v_j)$$
   其中 $S$ 是 DFS 从 $U$ 中未匹配顶点可达的 $U$ 顶点集，$T$ 是可达的 $V$ 顶点集。
   更新：$u_i \leftarrow u_i + \delta$（$i \in S$），$v_j \leftarrow v_j - \delta$（$j \in T$）
4. 重复 2-3 直到完美匹配

时间复杂度：$O(n^3)$。

## 第三部分：旅行商问题（TSP）

### 9. 问题定义

给定 $n$ 个城市及距离矩阵 $d_{ij}$，求排列 $\pi$ 最小化总巡回距离：

$$\min_{\pi} \sum_{i=1}^{n} d_{\pi(i), \pi(i+1)}, \quad \pi(n+1) = \pi(1)$$

TSP 是经典的 **NP-hard** 问题。Metric TSP（距离满足三角不等式 $d_{ik} \leq d_{ij} + d_{jk}$）仍是 NP-hard。

### 10. ILP 形式化（MTZ 约束）

**决策变量**：$x_{ij} = 1$ 若从 $i$ 直接走到 $j$，否则 0。

$$\min \sum_{i=1}^{n}\sum_{j=1}^{n} d_{ij} x_{ij}$$

约束：
$$\sum_{j} x_{ij} = 1 \quad \forall i, \qquad \sum_{i} x_{ij} = 1 \quad \forall j$$

$$x_{ij} \in \{0, 1\}$$

**Miller-Tucker-Zemlin（MTZ）子回路消除约束**：

$$u_i - u_j + n \cdot x_{ij} \leq n - 1, \quad \forall i \neq j, \; i, j \geq 2$$
$$1 \leq u_i \leq n - 1$$

其中 $u_i$ 表示城市 $i$ 在回路中的访问顺序（辅助变量）。这个约束保证了不会形成不包括城市 1 的子回路。

### 11. Christofides 算法（3/2-近似）

> **定理**：对于 Metric TSP，Christofides 算法给出 $\frac{3}{2}$-近似解。

#### 11.1 算法步骤

1. **计算 MST** $T$（作为 TSP 回路的下界）
2. **奇度顶点集** $O = \{v \in V : \deg_T(v) \text{ 为奇数}\}$
   - 注：任何图中奇度顶点数为偶数（握手定理）
3. **在 $O$ 上求最小权完美匹配** $M$（在完全图 $K_{|O|}$ 上，边权为原图距离）
4. **合并** $T \cup M$：得到所有顶点度数为偶数的多重图（欧拉图）
5. **求欧拉回路** $C$
6. **Shortcut**：沿 $C$ 遍历，跳过已访问的顶点，得到 Hamilton 回路（TSP 解）

#### 11.2 近似比证明（$3/2$）

1. **$w(T) \leq OPT$**：最优 TSP 回路删去一条边后是一棵生成树，其代价 $\geq w(T)$
2. **$w(M) \leq OPT/2$**：考虑最优 TSP 回路。沿回路顺序考虑 $O$ 中的顶点（$|O|$ 为偶数）。将这些顶点按回路顺序排列，交错地选择边，得到两个匹配 $M_1$ 和 $M_2$。由三角不等式，$w(M_1) + w(M_2) \leq OPT$。因此 $\min(w(M_1), w(M_2)) \leq OPT/2$。而 $M$ 是 $O$ 上的最小权匹配，故 $w(M) \leq OPT/2$
3. 欧拉回路代价：$w(T) + w(M) \leq OPT + OPT/2 = \frac{3}{2} OPT$
4. Shortcut 不增加距离：由三角不等式保证

**时间复杂度**：$O(n^3)$。瓶颈在于最小权完美匹配的计算。

### 12. 动态规划精确解（Held-Karp）

$$dp(S, j) = \text{从城市 1 出发，经集合 } S \text{ 中所有城市一次到达 } j \text{ 的最短距离}$$

**递推关系**：
$$dp(S, j) = \min_{i \in S \setminus \{j\}} \left[dp(S \setminus \{j\}, i) + d_{ij}\right]$$

**边界**：$dp(\{1\}, 1) = 0$

**答案**：$\text{TSP} = \min_{j \neq 1} [dp(V, j) + d_{j1}]$

**时间复杂度**：$O(n^2 \cdot 2^n)$，空间 $O(n \cdot 2^n)$。

### 13. 2-opt 局部搜索

**操作**：选取路径中两条不相邻的边 $(a,b)$ 和 $(c,d)$（其中 $a \to b \to \cdots \to c \to d$），替换为 $(a,c)$ 和 $(b,d)$，同时反转 $b$ 到 $c$ 之间的路径段。

**改进条件**：$d_{a,c} + d_{b,d} < d_{a,b} + d_{c,d}$

反复对所有边对应用 2-opt，直到无改进，得到局部最优解。

## 第四部分：关键路径方法（CPM）

### 14. 项目规划 DAG 模型

项目由一组任务组成，任务间有先后依赖关系构成 DAG。每个任务 $v$ 有持续时间 $t(v)$。

**目标**：求项目的最早完成时间和关键路径（任何延误都会延迟整个项目的任务序列）。

### 15. 最早开始时间（Earliest Start）

沿拓扑排序递推：
$$ES(v) = \max_{(u,v) \in E} [ES(u) + t(u)]$$

其中 $ES(\text{start}) = 0$。

项目最早完成时间：$\text{makespan} = \max_v [ES(v) + t(v)]$。

### 16. 最晚开始时间（Latest Start）

逆拓扑排序递推：
$$LS(u) = \min_{(u,v) \in E} [LS(v) - t(u)]$$

其中 $LS(\text{end}) = \text{makespan}$。

### 17. 关键路径

**总时差（Total Float）**：
$$TF(v) = LS(v) - ES(v)$$

**关键路径**：$TF(v) = 0$ 的任务构成的路径。关键路径上的任何延误都会造成项目延期。

**数学等价**：CPM 等价于在边权为 $t(u)$ 的 DAG 上求**最长路径**。DAG 上最长路径可在 $O(V+E)$ 内求解（将边权取负后运行 DAG 最短路径算法）。

### 18. 综合对比

| 问题 | 复杂度类别 | 核心算法 | 关键定理 |
|------|-----------|---------|---------|
| **MST** | P 类 | Kruskal / Prim $O(E \log V)$ | 切割性质 + 环性质 |
| **二部图最大匹配** | P 类 | 匈牙利 $O(VE)$ / Hopcroft-Karp $O(\sqrt{V}E)$ | Konig & Hall 定理 |
| **带权匹配** | P 类 | Kuhn-Munkres $O(n^3)$ | 等式子图定理 |
| **Metric TSP** | NP-hard | Christofides $O(n^3)$ ($\frac{3}{2}$-近似) | 三角不等式 |
| **一般 TSP** | NP-hard | Held-Karp $O(n^2 2^n)$（精确） | DP + 状态压缩 |
| **CPM** | P 类 | 拓扑排序 $O(V+E)$ | DAG 最长路径 |

### 19. 关键要点总结

| 要点 | 说明 |
|------|------|
| 切割性质 | 跨切割的最小权边属于某 MST |
| 环性质 | 环上最大权边不属于任何 MST |
| Kruskal | 排序边 + 并查集，$O(E \log E)$ |
| Prim | 优先队列扩展，稠密图用数组 $O(V^2)$ |
| Konig 定理 | 二部图中最大匹配 = 最小顶点覆盖 |
| Hall 定理 | 完美匹配 ⇔ $\forall S, |N(S)| \geq |S|$ |
| Berge 定理 | 无增广路径 → 已达到最大匹配 |
| Kuhn-Munkres | 带权匹配，标号法 + 等式子图 |
| Christofides | Metric TSP 的 $3/2$-近似算法 |
| Held-Karp | TSP 精确 DP，$O(n^2 2^n)$ |
| MTZ 约束 | TSP 的 ILP 子回路消除方法 |
| 2-opt | TSP 局部搜索：交换两条边 |
| CPM | 拓扑排序 + DAG 最长路径 = $O(V+E)$ |
| 关键路径 | TF = LS - ES = 0 的任务序列 |
