# 最短路径算法 —— 数学理论

## 1. 问题的形式化定义

### 1.1 加权有向图

考虑加权有向图 $G = (V, E, w)$，其中 $w: E \to \mathbb{R}$ 为边权函数。

**最短路径问题（Shortest Path Problem）**：对于源点 $s \in V$ 和目标点 $t \in V$，寻找路径 $P = (v_0, v_1, \ldots, v_k)$（其中 $v_0 = s$, $v_k = t$），使得总权重最小：

$$\min_{P} \sum_{i=1}^{k} w(v_{i-1}, v_i)$$

若不存在从 $s$ 到 $t$ 的路径，则最短距离记为 $\infty$。

记 $\delta(s, t)$ 为从 $s$ 到 $t$ 的最短距离。

### 1.2 最优子结构引理

**引理（最优子结构）**：若 $P = (v_0, v_1, \ldots, v_k)$ 是从 $v_0$ 到 $v_k$ 的最短路径，则对于任意 $0 \leq i \leq j \leq k$，子路径 $P_{ij} = (v_i, v_{i+1}, \ldots, v_j)$ 是从 $v_i$ 到 $v_j$ 的最短路径。

**证明**（反证法）：若存在更短的 $v_i \sim v_j$ 路径，则在 $P$ 中替换该子路径会得到更短的 $v_0 \sim v_k$ 路径，与 $P$ 的最优性矛盾。

### 1.3 三角不等式

对于所有顶点 $u, v, w \in V$：

$$\delta(s, v) \leq \delta(s, u) + w(u, v)$$

这由最优子结构直接推出。

## 2. Dijkstra 算法

### 2.1 前提假设

Dijkstra 算法**要求所有边权非负**：$w(u, v) \geq 0$。这是算法正确性的必要条件。

### 2.2 算法策略：贪心

Dijkstra 算法采用**贪心策略**：维护一个集合 $S$ 表示已确定最短距离的顶点，每次从 $V \setminus S$ 中选择具有最小当前最短估计 $d(v)$ 的顶点加入 $S$，并用该顶点对其邻居做**松弛操作**。

**松弛操作**（Relaxation）：

$$\text{if } d(v) > d(u) + w(u, v) \text{ then } d(v) \leftarrow d(u) + w(u, v); \; \pi(v) \leftarrow u$$

### 2.3 伪代码

```
算法 Dijkstra(G, w, s):
    for each v in V:
        d(v) = ∞
        π(v) = NIL
    d(s) = 0
    S = ∅
    Q = V   // 最小优先队列，键为 d(v)
    while Q ≠ ∅:
        u = Extract-Min(Q)
        S = S ∪ {u}
        for each v in Adj(u):
            if d(v) > d(u) + w(u, v):
                d(v) = d(u) + w(u, v)
                π(v) = u
                Decrease-Key(Q, v, d(v))
    return (d, π)
```

### 2.4 正确性证明

**定理**：Dijkstra 算法终止时，对于所有 $v \in V$，$d(v) = \delta(s, v)$。

**证明**（归纳法）：

证明在顶点 $u$ 被加入 $S$ 的瞬间，$d(u) = \delta(s, u)$。

**归纳假设**：对所有已被加入 $S$ 的顶点 $x$，$d(x) = \delta(s, x)$。

考虑当前 $Q$ 中 $d(u)$ 最小的顶点 $u$（即 Extract-Min 选出的）。反设 $d(u) > \delta(s, u)$。设 $P$ 为从 $s$ 到 $u$ 的最短路径，$P = (s, \ldots, y, z, \ldots, u)$。由于 $d(s) = 0 = \delta(s, s)$，沿 $P$ 前进定会遇到第一个不在 $S$ 中的顶点，设为 $y$（其前驱 $x \in S$）。

由最优子结构和归纳假设：
$$\delta(s, y) = \delta(s, x) + w(x, y) = d(x) + w(x, y)$$

$y$ 的邻居 $x$ 在我们加入 $S$ 时已经松弛过 $y$，故：
$$d(y) \leq d(x) + w(x, y) = \delta(s, y)$$

又由于 $y$ 在 $u$ 之前出现在 $P$ 上且边权非负，有：
$$\delta(s, y) \leq \delta(s, u)$$

**关键**：由于所有边权非负，$\delta(s, y) \leq \delta(s, u) < d(u)$。因此：
$$d(y) \leq \delta(s, y) \leq \delta(s, u) < d(u)$$

但这与 $u$ 是 $Q$ 中 $d$ 值最小的顶点矛盾！因此假设不成立，$d(u) = \delta(s, u)$。

**注意**：证明中"所有边权非负"的假设用于保证 $\delta(s, y) \leq \delta(s, u)$（沿 $P$ 前进距离不减小）。这是 Dijkstra 不能处理负权边的根本原因。

### 2.5 时间复杂度

| 实现 | 时间复杂度 | 最佳场景 |
|------|-----------|---------|
| 数组（线性扫描 Extract-Min） | $O(V^2)$ | 稠密图 ($E = \Theta(V^2)$) |
| 二叉堆 + 邻接表 | $O((V + E) \log V)$ | 一般图 |
| 斐波那契堆 + 邻接表 | $O(E + V \log V)$ | 稀疏理论最优 |
| `std::set`（平衡 BST） | $O((V + E) \log V)$ | C++ 工程常用 |

在稀疏图（$|E| = O(|V|)$）中，二叉堆实现达到 $O(V \log V)$；在稠密图（$|E| \approx V^2$）中，数组实现反而更快。

## 3. Bellman-Ford 算法

### 3.1 动机：负权边

当图中存在**负权边**时，Dijkstra 的贪心策略失效。Bellman-Ford 算法通过 **$|V|-1$ 轮全边松弛**来处理负权边。

### 3.2 动态规划视角

设 $d^{(k)}(v)$ 为从 $s$ 到 $v$ 的、经过至多 $k$ 条边的最短路径长度：

$$d^{(0)}(v) = \begin{cases} 0, & v = s \\ \infty, & v \neq s \end{cases}$$

$$d^{(k)}(v) = \min\left\{d^{(k-1)}(v), \min_{(u,v) \in E} [d^{(k-1)}(u) + w(u, v)]\right\}$$

因为最长简单路径至多含 $|V|-1$ 条边，所以 $d^{(|V|-1)}(v) = \delta(s, v)$（若无负权环）。

### 3.3 伪代码

```
算法 BellmanFord(G, w, s):
    d(s) = 0
    for each v in V\{s}: d(v) = ∞
    for i = 1 to |V| - 1:
        for each edge (u, v) in E:
            if d(u) + w(u, v) < d(v):
                d(v) = d(u) + w(u, v)
                π(v) = u
    // 负权环检测：
    for each edge (u, v) in E:
        if d(u) + w(u, v) < d(v):
            return "存在负权环"
    return (d, π)
```

### 3.4 负权环检测

如果第 $|V|$ 轮仍然发生松弛，说明存在从 $s$ 可达的负权环。因为若无负权环，任何最短路径不会重复访问顶点，至多含 $|V|-1$ 条边。

**定理**：图 $G$ 包含从 $s$ 可达的负权环，当且仅当经过 $|V|-1$ 轮后，第 $|V|$ 轮仍可松弛某条边。

### 3.5 正确性证明

**定理（上界性质）**：算法在任何时刻都满足 $d(v) \geq \delta(s, v)$（若 $\delta(s, v) = -\infty$ 时可能违反，但有负权环）。

**归纳证明**：经过 $k$ 轮松弛后，$d(v)$ 不超过从 $s$ 到 $v$ 的、经过至多 $k$ 条边的最短路径长度。由此可得，$|V|-1$ 轮后 $d(v) = \delta(s, v)$。

### 3.6 时间复杂度

$$O(|V| \cdot |E|)$$

空间复杂度：$O(|V|)$。

## 4. Floyd-Warshall 算法

### 4.1 问题：全源最短路径

Floyd-Warshall 计算**所有顶点对之间的最短路径**（All-Pairs Shortest Paths, APSP）。

### 4.2 动态规划递推

设 $d_{ij}^{(k)}$ 为从 $i$ 到 $j$ 且中间顶点编号只允许在 $\{1, 2, \ldots, k\}$ 中的最短距离。

**边界条件**（$k = 0$，无中间顶点）：

$$d_{ij}^{(0)} = \begin{cases} 0, & i = j \\ w(i, j), & (i, j) \in E \\ \infty, & (i, j) \notin E \end{cases}$$

**递推关系**（考虑是否经过顶点 $k$）：

$$d_{ij}^{(k)} = \min\left(d_{ij}^{(k-1)},\; d_{ik}^{(k-1)} + d_{kj}^{(k-1)}\right)$$

**解释**：
- 第一条路径：不经过 $k$，距离不变
- 第二条路径：从 $i$ 到 $k$（中间节点在 $\{1,\ldots,k-1\}$ 中），再从 $k$ 到 $j$（同样约束）

### 4.3 算法伪代码

```
算法 FloydWarshall(W):       // W 是 n×n 邻接矩阵
    D = W
    Π = 前驱矩阵 (初始 Π[i][j] = i if (i,j)∈E else NIL)
    for k = 1 to n:
        for i = 1 to n:
            for j = 1 to n:
                if D[i][k] + D[k][j] < D[i][j]:
                    D[i][j] = D[i][k] + D[k][j]
                    Π[i][j] = Π[k][j]
    return (D, Π)
```

注意：空间可优化至 $O(n^2)$，因为 $k$ 层可原地更新；$d_{ik}^{(k)} = d_{ik}^{(k-1)}$ 且 $d_{kj}^{(k)} = d_{kj}^{(k-1)}$（路径不会以 $k$ 为中间节点后又回到 $k$，因为路径是简单的）。

### 4.4 负权环检测

若任何 $D[i][i] < 0$，则顶点 $i$ 位于一个负权环中。

### 4.5 时间复杂度

$$O(|V|^3)$$

对稠密图（$|E| = \Theta(|V|^2)$）最优；对稀疏图，Johnson 算法（$O(V^2 \log V + VE)$）更优。

### 4.6 传递闭包（Transitive Closure）

将 Floyd-Warshall 应用于布尔邻接矩阵（有边 = true，无边 = false），用**逻辑或**和**逻辑与**代替 $\min$ 和 $+$，可得图的传递闭包：

$$R_{ij}^{(k)} = R_{ij}^{(k-1)} \lor \left(R_{ik}^{(k-1)} \land R_{kj}^{(k-1)}\right)$$

## 5. A* 算法

### 5.1 启发式搜索

A* 算法是 Dijkstra 的**启发式扩展**，使用启发函数 $h(v)$（估计从 $v$ 到目标 $t$ 的距离）来引导搜索方向。

### 5.2 代价函数

$$f(v) = g(v) + h(v)$$

- $g(v)$：从起点 $s$ 到 $v$ 的实际最短距离
- $h(v)$：从 $v$ 到目标 $t$ 的启发式估计

A* 在搜索时优先扩展 $f$ 值最小的节点。

### 5.3 可接受性（Admissibility）

**定义**：启发函数 $h$ 是**可接受的**，如果对于所有顶点 $v$：

$$h(v) \leq h^*(v)$$

其中 $h^*(v)$ 是从 $v$ 到 $t$ 的真实最短距离。换言之，$h$ 永不高估实际距离。

**定理**：若 $h$ 是可接受的，则 A* 是**最优的**（保证找到最短路径）。

### 5.4 一致性（Consistency / Monotonicity）

**定义**：启发函数 $h$ 是**一致的**，如果对于所有边 $(u, v)$：

$$h(u) \leq w(u, v) + h(v)$$

且 $h(t) = 0$。

一致性蕴含可接受性，且保证 A* 在首次扩展一个节点时即找到其最短路径（类似于 Dijkstra 的行为）。

### 5.5 常用启发函数（网格/地图）

| 场景 | 启发函数 | 可接受性 |
|------|---------|---------|
| 网格（4 方向） | 曼哈顿距离：$|x_v-x_t| + |y_v-y_t|$ | 可接受且一致 |
| 网格（8 方向） | 切比雪夫距离：$\max(|x_v-x_t|, |y_v-y_t|)$ | 可接受且一致 |
| 任意地图 | 欧氏距离：$\sqrt{(x_v-x_t)^2 + (y_v-y_t)^2}$ | 可接受且一致 |
| 最短路径 | $h(v) = 0$ | 可接受（退化为 Dijkstra） |

### 5.6 A* 与 Dijkstra 的关系

A* 在以下两种情况退化为 Dijkstra：
1. $h(v) = 0$ 对所有 $v$（可接受但不提供信息）
2. $w(u, v) = 0$（无权图或所有边权重相同）

A* 的信息效率完全取决于 $h$ 与 $h^*$ 的接近程度。

## 6. Johnson 算法（APSP 含负权边）

### 6.1 核心思想

Johnson 算法通过**势函数重新赋权**（Reweighting），将负权边转化为非负权边，然后对每个顶点运行 Dijkstra。

### 6.2 重新赋权

设 $h(v)$ 是由一次 Bellman-Ford 获得的势函数（以新增的超级源点到各顶点的最短距离）。

定义新权值：

$$w'(u, v) = w(u, v) + h(u) - h(v)$$

**非负性验证**：由三角不等式，$\delta(s, v) \leq \delta(s, u) + w(u, v)$，因此：
$$h(v) \leq h(u) + w(u, v) \;\Rightarrow\; w(u, v) + h(u) - h(v) \geq 0$$

**等距性**：对于任意路径 $P = (v_0, \ldots, v_k)$：
$$\sum_{i=1}^{k} w'(v_{i-1}, v_i) = \sum_{i=1}^{k} w(v_{i-1}, v_i) + h(v_0) - h(v_k)$$

因此 $w'$ 和 $w$ 保持相同的"最短路径"：在 $w'$ 下的最短路径，还原为 $w$ 下也是最短路径。

### 6.3 时间复杂度

$$O(|V| \cdot |E| + |V|^2 \log |V|) = O(VE + V^2 \log V)$$

在稀疏图（$|E| = O(|V|)$）中优于 Floyd-Warshall 的 $O(V^3)$。

## 7. DAG 上的最短路径

### 7.1 拓扑排序 + 松弛

对于有向无环图（DAG），按拓扑排序后的顺序对每个顶点的出边做一次松弛，可在 $O(V + E)$ 时间内求解单源最短路径（无需优先队列）。

**关键性质**：拓扑排序保证在松弛 $(u, v)$ 时，$d(u)$ 已经是 $\delta(s, u)$。

### 7.2 最长路径问题（CPM / Critical Path Method）

DAG 上的**最长路径**只需将边权取反（$w' = -w$）后运行 DAG 最短路径算法即可。

## 8. 算法对比

| 算法 | 适用范围 | 时间复杂度 | 支持负权边 | 特点 |
|------|---------|-----------|-----------|------|
| **Dijkstra** | 非负权图，单源 | $O((V+E)\log V)$ | 否 | 贪心，最优复杂度 |
| **Bellman-Ford** | 任意图，单源 | $O(VE)$ | 是 | 可检测负权环 |
| **Floyd-Warshall** | 任意图，全源 | $O(V^3)$ | 是 | DP 递推，适合稠密图 |
| **Johnson** | 任意图，全源 | $O(VE + V^2 \log V)$ | 是 | 重赋权 + Dijkstra |
| **A\*** | 非负权 + 启发函数 | $O(E)$ 平均 | 否 | 启发式，可定向搜索 |
| **DAG-SP** | DAG 图，单源 | $O(V + E)$ | 是 | 拓扑排序 |

## 9. 关键要点总结

| 要点 | 说明 |
|------|------|
| 最优子结构 | 最短路径的子路径也是最短路径 |
| 松弛操作 | 核心操作：$d(v) = \min\{d(v), d(u) + w(u,v)\}$ |
| Dijkstra 正确性 | 依赖所有边权非负（否则贪心失效） |
| Bellman-Ford | $|V|-1$ 轮全边松弛，$O(VE)$，可检测负权环 |
| Floyd-Warshall | DP：$d_{ij}^{(k)} = \min(d_{ij}^{(k-1)}, d_{ik}^{(k-1)} + d_{kj}^{(k-1)})$ |
| A* 可接受性 | $h(v) \leq h^*(v)$ 保证最优性 |
| 一致性 | $h(u) \leq w(u,v) + h(v)$，更强条件 |
| Johnson 重赋权 | $w'(u,v) = w(u,v) + h(u) - h(v) \geq 0$ |
| DAG 最短路径 | 拓扑排序 + 单轮松弛 = $O(V+E)$ |
