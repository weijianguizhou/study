# 决策树与集成学习 —— 数学理论

## 第一部分：决策树

### 1. 信息论基础

#### 1.1 信息熵（Shannon Entropy）

对于 $K$ 类分类问题，数据集 $D$ 的**信息熵**定义为类别分布的香农熵：

$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

其中 $p_k = \frac{|D_k|}{|D|}$ 是类别 $k$ 在 $D$ 中的占比。

**性质**：
- $H(D) \geq 0$，等号成立当且仅当所有样本同属一个类别
- $H(D) \leq \log_2 K$，等号成立当且仅当各类别均匀分布
- $H(D)$ 是 $p_k$ 的凹函数
- 熵的单位是比特（bit，以 2 为底）或纳特（nat，以 $e$ 为底）

**熵的 Shannon 公理化基础**：熵是满足以下三条公理的唯一函数形式（差一个常数因子）：
1. **连续性**：$H(p_1, \ldots, p_K)$ 关于各 $p_k$ 连续
2. **极值性**：均匀分布时熵最大
3. **可加性**：$H(p_1 q_1, p_1 q_2, \ldots, p_K q_K) = H(p) + \sum p_k H(q)$

#### 1.2 条件熵

在已知特征 $A$ 的条件下，数据集 $D$ 的条件熵为：

$$H(D \mid A) = \sum_{v \in \text{Values}(A)} \frac{|D_v|}{|D|} H(D_v)$$

其中 $D_v = \{x \in D : A(x) = v\}$ 是特征 $A$ 取值为 $v$ 的子集。

#### 1.3 互信息与信息增益

特征 $A$ 与类别标签 $Y$ 之间的**互信息**（即信息增益）：

$$g(D, A) = H(D) - H(D \mid A) = I(A; Y)$$

展开形式：

$$g(D, A) = H(D) - \sum_{v} \frac{|D_v|}{|D|} H(D_v)$$

信息增益度量了知道特征 $A$ 后类标签不确定性的减少量。

**性质**：
- $g(D, A) \geq 0$（数据处理不等式）
- $g(D, A) = 0$ 当且仅当 $A$ 与 $Y$ 在 $D$ 上独立
- 互信息的对称性：$I(A; Y) = I(Y; A)$

#### 1.4 基尼指数（Gini Impurity）

基尼指数度量了从数据集中随机抽取两个样本，类别标签不一致的概率：

$$\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2 = \sum_{k=1}^{K} p_k (1 - p_k)$$

**性质**：
- $\text{Gini}(D) \in [0, 1 - 1/K]$
- 二分类情况下：$\text{Gini}(D) = 2p(1-p)$，在 $p = 0.5$ 时最大
- 与熵的关系：$\text{Gini}(D) \approx H(D) / 2 \log 2$（在 $p_k$ 较接近时）
- 计算上比熵更高效（无对数运算）

特征 $A$ 对数据集 $D$ 的基尼增益：

$$\Delta \text{Gini}(D, A) = \text{Gini}(D) - \sum_{v} \frac{|D_v|}{|D|} \text{Gini}(D_v)$$

#### 1.5 分类误差率

$$\text{Error}(D) = 1 - \max_k p_k$$

分类误差率对概率变化不敏感（只考虑多数类），一般不直接用作分裂准则（对概率的微小变化不连续）。

### 2. 三大经典算法

#### 2.1 ID3 算法（Iterative Dichotomiser 3）

**Quinlan, 1986**

**分裂准则**：信息增益 $\max_A g(D, A)$

**算法流程**：

```
函数 ID3(D, A):
1. 若 D 中所有样本属于同一类别 → 返回叶子节点（该类别）
2. 若 A = ∅ → 返回叶子节点（D 中多数类别）
3. 选择 A* = argmax_{A∈A} g(D, A)
4. 以 A* 为根节点
5. for each A* 的取值 v:
6.     若 D_v = ∅ → 创建叶子节点（D 中多数类别）
7.     否则 → 递归构建子树 ID3(D_v, A \ {A*})
8. 返回树
```

**局限性**：
- 只能处理**离散特征**
- 信息增益**偏好**取值较多的特征（因为划分更细使得条件熵更小）
- 无剪枝机制，容易**过拟合**于训练数据

#### 2.2 C4.5 算法

**Quinlan, 1993**

**分裂准则**：信息增益率（Gain Ratio）

$$g_R(D, A) = \frac{g(D, A)}{H_A(D)}$$

其中**分裂信息**（Split Information / Intrinsic Value）：

$$H_A(D) = -\sum_{v} \frac{|D_v|}{|D|} \log_2 \frac{|D_v|}{|D|}$$

$H_A(D)$ 可理解为特征 $A$ 自身的熵：取值越多，$H_A(D)$ 越大，从而惩罚了多值特征。

在 C4.5 实际实现中，先筛选出信息增益高于平均水平的特征，再从中选择增益率最大的。

**C4.5 的核心改进**：

1. **连续特征处理（二分法）**：
   - 将特征 $A$ 的取值排序 $a_1 < a_2 < \cdots < a_m$
   - 候选分裂点：$t_i = \frac{a_i + a_{i+1}}{2}$（$i = 1, \ldots, m-1$）
   - 对每个 $t_i$ 计算增益率 $g_R(D, A \leq t_i)$，选择最大的

2. **缺失值处理**：
   - 训练阶段：样本按非缺失值比例分配到各分支
   - 预测阶段：沿各分支按权重走，最终取加权表决

   定义样本权值 $w(x, A, v)$：若 $x$ 在特征 $A$ 上无缺失，$w = 1$（若 $A(x) = v$）或 $w = 0$；若有缺失，$w = |D_v|/\sum_{v'\neq\text{missing}}|D_{v'}|$。

3. **后剪枝**：先生成完整树，再自底向上剪枝（详见第 3 节）

#### 2.3 CART 算法（Classification and Regression Trees）

**Breiman, Friedman, Olshen, Stone, 1984**

**分类分裂准则**：基尼指数 $\min \Delta\text{Gini}$

**回归分裂准则**：最小均方误差（MSE）

给定分裂点 $s$（特征 $A$ 上），划分为 $R_1 = \{x: x_A \leq s\}$ 和 $R_2 = \{x: x_A > s\}$：

$$\min_{A,s} \left[ \sum_{x \in R_1} (y - \bar{y}_1)^2 + \sum_{x \in R_2} (y - \bar{y}_2)^2 \right]$$

其中 $\bar{y}_1, \bar{y}_2$ 分别为两个区域的目标均值。对于回归树，叶节点输出为该节点内所有样本目标值的均值。

**CART 的特性**：
- 只生成**二叉树**
- 同时支持**分类和回归**
- 使用代价复杂度剪枝（Cost-Complexity Pruning）

### 3. 剪枝理论

#### 3.1 代价复杂度剪枝（Cost-Complexity Pruning / Minimal Cost-Complexity Pruning）

对于树 $T$，定义代价复杂度准则：

$$C_\alpha(T) = C(T) + \alpha |T|$$

其中：
- $C(T)$ = 训练集上的误分类代价（或总不纯度）
- $|T|$ = 树的叶节点数量
- $\alpha \geq 0$ = 复杂度惩罚参数

对于子树 $T_t$（以节点 $t$ 为根）：

$$\alpha_t = \frac{C(t) - C(T_t)}{|T_t| - 1}$$

$C(t)$ 是将 $t$ 作为一个叶节点时的代价。$\alpha_t$ 度量了"保留子树 $T_t$ 与退化为叶节点 $t$ 之间的代价差异"。

**剪枝流程**：
1. 计算每个内部节点的 $\alpha_t$
2. 剪掉 $\alpha_t$ 最小的节点子树
3. 重复直到整棵树退化为根节点
4. 将每个 $\alpha$ 得到的子树作为候选，用验证集选择最优 $\alpha$

#### 3.2 预剪枝（Pre-pruning）

在树的生长过程中，通过提前停止条件来控制：

| 参数 | 含义 | 效果 |
|------|------|------|
| `max_depth` | 树的最大深度 | 限制树的复杂度 |
| `min_samples_split` | 节点分裂所需最小样本数 | 防止过细分裂 |
| `min_samples_leaf` | 叶节点最小样本数 | 保证统计意义 |
| `min_impurity_decrease` | 不纯度减少最小阈值 | 仅在增益足够大时分裂 |

#### 3.3 两种剪枝的数学权衡

- **预剪枝**：计算高效，但可能过早停止（"视野局限"问题）
- **后剪枝**：计算开销大，但通常效果更好，因为完整树保留了所有可能的交互结构

### 4. 决策树的理论性质

#### 4.1 偏差-方差分解

决策树的**偏差较低**（可以拟合任意复杂的决策边界），但**方差极高**（对训练数据的微小变动极为敏感）。

$$\mathbb{E}[(f(x) - \hat{f}(x))^2] = \text{Bias}^2(\hat{f}(x)) + \text{Var}(\hat{f}(x)) + \sigma^2$$

- 无剪枝的决策树：Bias $\downarrow$，Variance $\uparrow\uparrow$
- 强剪枝后：Bias $\uparrow$，Variance $\downarrow$

这正是集成方法（Bagging、随机森林）要解决的问题：降低方差。

#### 4.2 一致性

在适当的正则条件下（样本量 $n \to \infty$，分裂的最小样本量满足 $n_t \to \infty$ 且 $n_t/n \to 0$），CART 算法是**一致的**（consistent），即学习的决策规则收敛于贝叶斯最优规则。

## 第二部分：集成学习

### 5. Bagging（Bootstrap Aggregating）

#### 5.1 Bootstrap 采样

从大小为 $n$ 的训练集 $D$ 中有放回地采样，得到 $T$ 个 Bootstrap 样本 $D_1, D_2, \ldots, D_T$，每个 $|D_t| = n$。

样本 $x_i$ 未被包含在第 $t$ 个 Bootstrap 样本中的概率：

$$P(x_i \notin D_t) = \left(1 - \frac{1}{n}\right)^n \approx e^{-1} \approx 0.368$$

因此：
- 约 **63.2%** 的样本在每个 Bootstrap 样本中出现（可能重复）
- 约 **36.8%** 的样本不在某个 Bootstrap 样本中 → 构成 OOB 样本

#### 5.2 聚合方式

**分类（硬投票/Majority Voting）**：

$$\hat{y} = \arg\max_k \sum_{t=1}^{T} \mathbf{1}(h_t(x) = k)$$

**回归（简单平均）**：

$$\hat{y} = \frac{1}{T} \sum_{t=1}^{T} h_t(x)$$

#### 5.3 方差缩减原理（Variance Reduction）

设 $T$ 个基学习器的预测为 $h_1(x), h_2(x), \ldots, h_T(x)$，每个具有方差 $\sigma^2$，相互之间的相关系数为 $\rho$。

Bagging 集成后的方差：

$$\text{Var}\left(\frac{1}{T}\sum_{t=1}^{T} h_t(x)\right) = \rho\sigma^2 + \frac{1-\rho}{T}\sigma^2$$

**推导**：
$$\text{Var}(\bar{h}) = \frac{1}{T^2}\left(\sum_{t}\text{Var}(h_t) + \sum_{t \neq s}\text{Cov}(h_t, h_s)\right) = \frac{\sigma^2}{T} + \frac{T-1}{T}\rho\sigma^2 = \rho\sigma^2 + \frac{1-\rho}{T}\sigma^2$$

**关键观察**：
- 当 $T \to \infty$：$\text{Var} \to \rho\sigma^2$
- 降低 $\rho$（基学习器间的相关性）是进一步降低方差的关键
- Bootstrap 采样引入了基学习器之间的**多样性**，降低了 $\rho$

#### 5.4 OOB 误差估计

对于样本 $x_i$，仅使用那些**未包含** $x_i$ 的 Bootstrap 样本所训练的基学习器做预测。定义 OOB 预测：

$$\hat{y}_i^{\text{OOB}} = \arg\max_k \sum_{t: x_i \notin D_t} \mathbf{1}(h_t(x_i) = k)$$

**OOB 误差**：

$$E_{\text{OOB}} = \frac{1}{n}\sum_{i=1}^{n} \mathbf{1}(y_i \neq \hat{y}_i^{\text{OOB}})$$

OOB 误差是泛化误差的**无偏估计**，等价于留一交叉验证（LOOCV），但计算成本更低。

### 6. 随机森林（Random Forest）

**Breiman, 2001**

#### 6.1 双重随机性

随机森林 = Bagging + **随机子空间**（Random Subspace / Feature Bagging）：

1. **行采样**：用 Bootstrap 从训练集中采样
2. **列采样**：每个节点分裂时，从 $d$ 个特征中随机选择 $m$ 个特征，仅在该子集中选择最优分裂

典型取值：
- **分类**：$m = \lfloor\sqrt{d}\rfloor$ 或 $\lfloor\log_2 d + 1\rfloor$
- **回归**：$m = \lfloor d/3\rfloor$

#### 6.2 方差缩减的深化

设基学习器的方差为 $\sigma^2$，平均相关系数为 $\rho$：

$$\text{Var}_{\text{RF}} \approx \rho\sigma^2 + \frac{1-\rho}{T}\sigma^2$$

随机特征选择降低了树间的相关系数 $\rho$，使得 $\rho\sigma^2$ 更小。

两棵树在某个节点上选择相同特征作为最优分裂的概率：

$$P_{\text{same}} = \frac{\binom{d-1}{m-1}}{\binom{d}{m}} = \frac{m}{d}$$

当 $m = \sqrt{d}$ 时，$P_{\text{same}} = 1/\sqrt{d}$，随维度增大而迅速减小，有效地降低了相关性。

#### 6.3 泛化误差界

Breiman 证明，随机森林的泛化误差随着树数量增加而收敛。由 Hoeffding 不等式：

$$P(|E_{\text{RF}} - \mathbb{E}[E_{\text{RF}}]| > \epsilon) \leq 2\exp\left(-\frac{2T\epsilon^2}{B^2}\right)$$

其中 $B$ 是损失的上界。

**更强的结论**（Breiman, 2001）：$\lim_{T \to \infty} E_{\text{RF}}$ 存在且有限，并且
$$E_{\text{RF}} \leq \bar{\rho} \cdot \frac{1-s^2}{s^2}$$

其中 $\bar{\rho}$ 是树间的平均相关性，$s$ 是每棵树的强度（strength）。这表明误差上界由"相关性/强度"的比值控制。

#### 6.4 一致性

Breiman 证明，在以下条件下随机森林是一致的（当 $n \to \infty$ 时，误差趋于贝叶斯误差）：
1. 每棵树都是完全生长的（无剪枝）
2. 特征子集大小 $m$ 随 $n$ 增长，但 $m/n \to 0$
3. 基学习器本身（不剪枝的决策树）是一致的

### 7. 特征重要性

#### 7.1 MDI（Mean Decrease in Impurity / 基于不纯度的重要性）

特征 $X_j$ 在所有树的所有节点上带来的不纯度减少总量的加权平均值：

$$\text{FI}_{\text{MDI}}(X_j) = \frac{1}{T} \sum_{t=1}^{T} \sum_{v \in \mathcal{N}_t} \mathbf{1}(\text{split}(v) = X_j) \cdot \frac{|D_v|}{n} \cdot \Delta I_v$$

其中 $\mathcal{N}_t$ 是树 $t$ 的内部节点集合，$\Delta I_v$ 是节点 $v$ 的不纯度减少：

$$\Delta I_v = I(D_v) - \frac{|D_{v,L}|}{|D_v|} I(D_{v,L}) - \frac{|D_{v,R}|}{|D_v|} I(D_{v,R})$$

**MDI 的偏倚**：倾向于高估**高基数特征**（取值多的特征）和**连续特征**的重要性。

#### 7.2 MDA（Mean Decrease in Accuracy / 排列重要性）

对每个特征 $X_j$，将其在 OOB 样本中的取值随机打乱，度量预测准确率的下降：

$$\text{FI}_{\text{MDA}}(X_j) = \frac{1}{T} \sum_{t=1}^{T} \left[\text{Acc}(\text{OOB}_t) - \text{Acc}(\text{OOB}_t^{\pi_j})\right]$$

其中 $\text{OOB}_t^{\pi_j}$ 是将特征 $j$ 随机排列后的 OOB 样本。

**优势**：
- 考虑**特征交互**效应
- 不依赖具体的不纯度函数
- 可以检测"不降低不纯度但影响预测"的特征

**排列重要性的方差估计**：重复多次排列，使用多次测量的标准差作为置信区间。

#### 7.3 条件排列重要性

标准 MDA 会高估相关性高的特征。**条件排列重要性**（Conditional Permutation Importance）在保持与其他特征的条件分布下打乱目标特征，以消除虚假关联。

### 8. 三种算法对比

| 特性 | ID3 | C4.5 | CART |
|------|-----|------|------|
| 树结构 | 多叉树 | 多叉树 | 二叉树 |
| 分裂准则 | 信息增益 | 信息增益率 | 基尼指数（分类）/ MSE（回归） |
| 连续特征 | 不支持 | 二分法 | 二分法 |
| 缺失值 | 不支持 | 基于概率的处理 | 代理分裂（Surrogate Splits） |
| 剪枝 | 无 | 后剪枝（REP） | 代价复杂度剪枝 |
| 回归 | 不支持 | 不支持 | 支持 |
| 年份 | 1986 | 1993 | 1984 |

### 9. 特征分割的数学优化

#### 9.1 连续特征的最优分裂点

对于排序后的特征值 $a_1 < a_2 < \cdots < a_m$，分裂标准关于分裂点 $t$ 是**分段常数**函数，只需在 $m-1$ 个候选点测试。

对于均方误差（CART 回归）：

$$\min_t \left[\frac{1}{|D_{\leq t}|}\sum_{x \in D_{\leq t}} y^2 + \frac{1}{|D_{>t}|}\sum_{x \in D_{>t}} y^2\right]$$

可以通过维护左子集的累积和（$S_L = \sum_{i \leq t} y_i$, $SQ_L = \sum_{i \leq t} y_i^2$）在 $O(m)$ 时间内找到最优 $t$。

#### 9.2 对类别不平衡的鲁棒性

对于类别不平衡问题，可以：
- 在分裂准则中引入**类别权重**：$\text{Gini}_w(D) = 1 - \sum_k w_k p_k^2$
- 使用**平衡准确率**或 **F1-score** 作为剪枝的评估指标

### 10. 关键要点总结

#### 决策树

| 要点 | 说明 |
|------|------|
| ID3 | 信息增益 = $H(D) - H(D \mid A)$，偏好多值特征 |
| C4.5 | 信息增益率 = $g(D,A)/H_A(D)$，能处理连续值和缺失值 |
| CART | 基尼指数 $1 - \sum p_k^2$（分类）或 MSE（回归），二叉树 |
| 信息熵 | $H(D) = -\sum p_k \log_2 p_k$，度量不确定性 |
| 基尼指数 | $\text{Gini}(D) = 1 - \sum p_k^2$，计算效率高 |
| 预剪枝 | 在生长过程中提前停止（max_depth, min_samples_leaf 等） |
| 后剪枝 | 先生成完整树，再代价复杂度剪枝 $C_\alpha(T) = C(T) + \alpha|T|$ |

#### 集成学习

| 要点 | 说明 |
|------|------|
| Bagging | Bootstrap 采样 → 独立训练 → 聚合（投票/平均） |
| 方差公式 | $\text{Var} = \rho\sigma^2 + (1-\rho)\sigma^2/T$ |
| OOB 误差 | 约 36.8% 未采样数据作为验证集，近似无偏估计 |
| 随机森林 | Bagging + 随机特征子集（$m = \sqrt{d}$ 分类，$m = d/3$ 回归） |
| 随机子空间 | 高维中 $P_{\text{same}} = m/d$，多样化基学习器 |
| MDI | 基于不纯度减少的特征重要性，偏好多值/连续特征 |
| MDA | 基于排列的特征重要性，考虑了特征交互 |
| RF 一致性 | 无剪枝完整树 + $m$ 随 $n$ 增长但 $m/n \to 0$ |
