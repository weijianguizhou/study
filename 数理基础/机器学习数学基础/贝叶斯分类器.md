# 贝叶斯分类器 —— 数学理论

## 第一部分：贝叶斯决策论

### 1. 贝叶斯决策规则

#### 1.1 最小错误率决策

在模式识别中，给定特征向量 $x \in \mathbb{R}^d$，观测到 $x$ 后将其分类。贝叶斯决策规则：选择使得**后验概率最大**的类别。

对于 $K$ 类问题，决策规则为：

$$\hat{y} = \arg\max_{k \in \{1,\ldots,K\}} P(Y = y_k \mid X = x)$$

由贝叶斯公式展开：

$$\hat{y} = \arg\max_{k} \frac{P(X = x \mid Y = y_k) \cdot P(Y = y_k)}{P(X = x)}$$

由于证据 $P(X = x)$ 对所有类别相同（仅作为归一化因子），等价的决策规则为：

$$\hat{y} = \arg\max_{k} P(X = x \mid Y = y_k) \cdot P(Y = y_k)$$

#### 1.2 贝叶斯风险

设有损失函数 $L(y_k, \hat{y})$（将真实类别 $y_k$ 误判为 $\hat{y}$ 的代价），条件风险（Conditional Risk）为：

$$R(\hat{y} \mid x) = \sum_{k=1}^{K} L(y_k, \hat{y}) \cdot P(Y = y_k \mid X = x)$$

最优决策是选择使条件风险最小的动作：

$$\hat{y}^* = \arg\min_{\hat{y}} R(\hat{y} \mid x)$$

当使用 0-1 损失 $L(y_k, \hat{y}) = \mathbf{1}(y_k \neq \hat{y})$ 时，条件风险退化为错误概率，最小风险决策退化为最大后验决策。

#### 1.3 贝叶斯最优错误率

贝叶斯最优错误率（Bayes Error）是不能被任何分类器超越的理论下界：

$$P_{\text{error}}^* = \int \left[1 - \max_k P(Y = y_k \mid X = x)\right] p(x) \, dx$$

当类别完全重叠（$P(Y = y_k \mid X = x)$ 对某个 $x$ 完全相同）时，贝叶斯错误率达到最大。

### 2. 朴素贝叶斯（Naive Bayes）

#### 2.1 条件独立性假设

朴素贝叶斯的核心在于"朴素"假设：在给定类别 $Y$ 的条件下，各特征之间**条件独立**：

$$P(X_1 = x_1, X_2 = x_2, \ldots, X_d = x_d \mid Y = y_k) = \prod_{j=1}^{d} P(X_j = x_j \mid Y = y_k)$$

这个假设大幅简化了参数估计。在一般情况（不做独立性假设时），估计联合分布 $P(X_1, \ldots, X_d \mid Y)$ 需要 $O(|\mathcal{X}|^d \cdot K)$ 量级的参数；而朴素贝叶斯只需 $O(d \cdot K \cdot |\mathcal{X}_j|)$ 量级的参数。

#### 2.2 朴素贝叶斯分类器

$$\hat{y} = \arg\max_{y_k} P(Y = y_k) \prod_{j=1}^{d} P(X_j = x_j \mid Y = y_k)$$

**数值稳定性（对数空间）**：将乘法转换为加法以避免下溢：

$$\hat{y} = \arg\max_{y_k} \left[\log P(Y = y_k) + \sum_{j=1}^{d} \log P(X_j = x_j \mid Y = y_k)\right]$$

#### 2.3 先验概率的估计

**极大似然估计（MLE）**：

$$\hat{P}(Y = y_k) = \frac{|D_k|}{n}$$

其中 $|D_k|$ 是训练集中类别 $k$ 的样本数，$n$ 是总样本数。

**最大后验估计（MAP）**（使用 Dirichlet 先验 $Dir(\alpha_1, \ldots, \alpha_K)$）：

$$\hat{P}(Y = y_k) = \frac{|D_k| + \alpha_k - 1}{n + \sum_k (\alpha_k - 1)}$$

### 3. 高斯朴素贝叶斯（Gaussian NB）

#### 3.1 似然函数

假设每个类别的每个特征服从高斯分布：

$$P(X_j = x_j \mid Y = y_k) = \frac{1}{\sqrt{2\pi \sigma_{jk}^2}} \exp\left(-\frac{(x_j - \mu_{jk})^2}{2\sigma_{jk}^2}\right)$$

参数估计（MLE）：

$$\hat{\mu}_{jk} = \frac{1}{|D_k|} \sum_{i \in D_k} x_{ij}$$

$$\hat{\sigma}_{jk}^2 = \frac{1}{|D_k|} \sum_{i \in D_k} (x_{ij} - \hat{\mu}_{jk})^2$$

#### 3.2 决策边界的数学形式

高斯朴素贝叶斯在两类情况下，决策边界是二次曲面。将似然比取对数：

$$\log\frac{P(Y=y_1\mid x)}{P(Y=y_2\mid x)} = \log\frac{P(Y=y_1)}{P(Y=y_2)} + \sum_{j=1}^{d} \left[\log\frac{\sigma_{2j}}{\sigma_{1j}} - \frac{(x_j-\mu_{1j})^2}{2\sigma_{1j}^2} + \frac{(x_j-\mu_{2j})^2}{2\sigma_{2j}^2}\right] = 0$$

展开后是关于 $x$ 的**二次型**（quardratic discriminant analysis, QDA 的特例）。

如果进一步假设所有类共享相同方差（$\sigma_{1j}^2 = \sigma_{2j}^2 = \sigma_j^2$），则决策边界退化为线性（LDA 方向）。

---

### 4. 多项式朴素贝叶斯（Multinomial NB）

#### 4.1 似然函数

适用于**计数特征**（词频、事件计数等）：

$$P(X_1 = x_1, \ldots, X_d = x_d \mid Y = y_k) = \frac{(x_1 + \cdots + x_d)!}{x_1! \cdots x_d!} \prod_{j=1}^{d} \theta_{jk}^{x_j}$$

其中 $\theta_{jk} = P(\text{特征 } j \mid Y = y_k)$ 且 $\sum_j \theta_{jk} = 1$。

在实际分类时，多项式因子与类别 $k$ 无关，可以省略：

$$\hat{y} = \arg\max_k \left[\log P(Y = y_k) + \sum_{j=1}^{d} x_j \log \theta_{jk}\right]$$

#### 4.2 参数估计（带 Laplace 平滑）

$$P(X_j = x_j \mid Y = y_k) = \theta_{jk}^{x_j}$$

其中

$$\hat{\theta}_{jk} = \frac{\sum_{i \in D_k} x_{ij} + \alpha}{\sum_{j=1}^{d} \sum_{i \in D_k} x_{ij} + \alpha d}$$

- $N_{jk} = \sum_{i \in D_k} x_{ij}$：类别 $k$ 中特征 $j$ 的总计数
- $N_k = \sum_j N_{jk}$：类别 $k$ 中所有特征的总计数
- $\alpha$：Laplace 平滑参数（$\alpha = 1$ 为经典 Laplace 平滑）

适用场景：文本分类（TF 特征、各类计数特征）。

---

### 5. 伯努利朴素贝叶斯（Bernoulli NB）

#### 5.1 似然函数

适用于**二值特征**（特征出现/不出现）：

$$P(X_j = x_j \mid Y = y_k) = p_{jk}^{x_j} (1 - p_{jk})^{1 - x_j}$$

其中 $x_j \in \{0, 1\}$，$p_{jk} = P(X_j = 1 \mid Y = y_k)$。

参数估计（带平滑）：

$$\hat{p}_{jk} = \frac{N_{jk} + \alpha}{N_k + 2\alpha}$$

适用场景：短文本分类（词是否出现，而非词频）、布尔特征。

---

### 6. Laplace 平滑的贝叶斯解释

#### 6.1 零概率问题

若某特征值在训练集中对某类别从未出现，MLE 给该概率赋值为 0，导致整个后验概率归零。

#### 6.2 Dirichlet 先验与 MAP 估计

Laplace 平滑等价于对参数 $\theta$ 使用对称 Dirichlet 先验 $\theta \sim Dir(\alpha, \alpha, \ldots, \alpha)$，并取后验期望（posterior mean）或众数（posterior mode）。

后验分布：

$$P(\theta \mid D) \propto P(D \mid \theta) \cdot P(\theta) \propto \prod_{j=1}^{d} \theta_j^{N_{jk}} \cdot \prod_{j=1}^{d} \theta_j^{\alpha - 1} = \prod_{j=1}^{d} \theta_j^{N_{jk} + \alpha - 1}$$

后验众数（MAP 估计）：

$$\hat{\theta}_j^{\text{MAP}} = \frac{N_{jk} + \alpha - 1}{N_k + (\alpha - 1)d}$$

当 $\alpha = 1$ 时：

$$\hat{\theta}_j^{\text{Laplace}} = \frac{N_{jk} + 1}{N_k + d}$$

（这里减去了初值后的标准化）

#### 6.3 平滑参数的影响

| $\alpha$ | 名称 | 效果 |
|-----------|------|------|
| $\alpha = 0$ | MLE | 无平滑，可能零概率 |
| $\alpha = 1$ | Laplace 平滑 | 每个特征出现次数均匀"预加"一次 |
| $0 < \alpha < 1$ | Lidstone 平滑 | 弱平滑 |
| $\alpha > 1$ | — | 强正则化 |

### 7. 理论性质

#### 7.1 分类误差界

朴素贝叶斯的分类错误率与贝叶斯最优错误率之间的关系：

$$R_{\text{NB}} - R^* \leq \frac{1}{2} \sum_{j \neq l} \left|\text{Cov}(X_j, X_l \mid Y)\right|$$

**解释**：NB 的额外误差受控于特征之间的**条件协方差**绝对值之和。当特征间条件独立时（$\text{Cov}(X_j, X_l \mid Y) = 0$），NB 达到最优。

这也从理论上解释了为什么 NB 在特征间条件不强相关的场景中表现出色——即使独立假设不严格成立，只要协方差足够小，误差就受控。

#### 7.2 半朴素贝叶斯：TAN（Tree-Augmented Naive Bayes）

放松完全独立假设，允许每个特征依赖最多一个其他特征和一个父节点，形成树结构：

$$P(X_1, \ldots, X_d \mid Y) = \prod_{j=1}^{d} P(X_j \mid \text{pa}(X_j), Y)$$

其中 $\text{pa}(X_j)$ 是 $X_j$ 在依赖树中的父节点。

TAN 通过学习特征间的条件互信息（Conditional Mutual Information）来构建最大生成树：

$$\text{CMI}(X_i, X_j \mid Y) = \sum_{y} P(Y=y) \sum_{x_i} \sum_{x_j} P(x_i, x_j \mid y) \log\frac{P(x_i, x_j \mid y)}{P(x_i \mid y)P(x_j \mid y)}$$

## 第二部分：K-近邻（KNN）算法

### 8. 非参数密度估计

#### 8.1 KNN 的密度估计视角

KNN 可以被理解为基于近邻的**非参数密度估计**。对于查询点 $x$，局部密度近似为：

$$\hat{p}(x) = \frac{K}{n \cdot V_K(x)}$$

其中 $V_K(x)$ 是以 $x$ 为中心的球的体积，该球刚好包含 $K$ 个训练样本。

#### 8.2 基本分类规则

$$\hat{y} = \arg\max_c \sum_{i \in N_K(x)} \mathbf{1}(y_i = c)$$

其中 $N_K(x)$ 是 $x$ 的 $K$ 个最近邻的索引集。

---

### 9. 距离度量

#### 9.1 闵可夫斯基距离（Minkowski Distance）

$$d_p(x, y) = \left(\sum_{j=1}^{d} |x_j - y_j|^p\right)^{1/p}$$

| $p$ | 名称 | 特点 |
|----|------|------|
| $p = 1$ | 曼哈顿距离（$L_1$） | 对异常值更鲁棒，适合高维稀疏数据 |
| $p = 2$ | 欧氏距离（$L_2$） | 最常用，旋转不变，适合低维稠密数据 |
| $p \to \infty$ | 切比雪夫距离（$L_\infty$） | $\max_j |x_j - y_j|$ |

**距离度量公理**：
1. 非负性：$d(x, y) \geq 0$，且 $d(x, y) = 0 \iff x = y$
2. 对称性：$d(x, y) = d(y, x)$
3. 三角不等式：$d(x, z) \leq d(x, y) + d(y, z)$

#### 9.2 马氏距离（Mahalanobis Distance）

$$d_M(x, y) = \sqrt{(x - y)^T \Sigma^{-1} (x - y)}$$

其中 $\Sigma$ 是数据的协方差矩阵。马氏距离**考虑了特征间的相关性**，等价于将数据白化（whitening）后在欧氏空间中的距离。

当 $\Sigma = I$（独立标准正态）时，马氏距离退化为欧氏距离。

#### 9.3 余弦距离

$$d_{\cos}(x, y) = 1 - \frac{x \cdot y}{\|x\| \cdot \|y\|} = 1 - \cos(x, y)$$

忽略向量的模长，只关注方向。适合文本（TF-IDF 向量）和高维稀疏数据。

---

### 10. 加权 KNN

#### 10.1 距离加权投票

赋予近邻不同的投票权重，离查询点越近的邻居权重越大：

$$\hat{y} = \arg\max_c \sum_{i \in N_K(x)} w(x, x_i) \cdot \mathbf{1}(y_i = c)$$

**逆距离权重**：

$$w(x, x_i) = \frac{1}{d(x, x_i)^p}$$

常用 $p = 1$ 或 $p = 2$。为避免除零，通常 $w(x, x_i) = 1/(d(x, x_i) + \epsilon)$。

**高斯核权重**：

$$w(x, x_i) = \exp\left(-\frac{d(x, x_i)^2}{2\sigma^2}\right)$$

其中 $\sigma$ 可取为第 $K$ 个近邻的距离（自适应带宽）。

#### 10.2 权重对偏差-方差的影响

距离加权减少了**偏差**（远处的噪音邻居影响力降低），但可能略微增大**方差**。在实践中，距离加权通常优于均匀投票。

### 11. 理论分析

#### 11.1 Cover-Hart 不等式

**Cover & Hart (1967)** 证明了关于 1-NN 错误率的不等式：

$$R^* \leq R_{1\text{-NN}} \leq 2R^* \left(1 - \frac{R^*}{K+1}\right)$$

其中 $R^*$ 是贝叶斯最优错误率，$R_{1\text{-NN}}$ 是 1-NN 的渐近错误率。

**简化界**（也是 Cover-Hart 的推论）：

$$R^* \leq R_{1\text{-NN}} \leq 2R^*$$

即 1-NN 的错误率不超过贝叶斯最优错误率的两倍。对于 $K$-NN：

$$R^* \leq R_{K\text{-NN}} \leq R^* + \frac{1}{\sqrt{K e}}$$

（当 $n$ 足够大且 $K$ 合适时）

#### 11.2 渐近一致性（Asymptotic Consistency）

当 $n \to \infty$，且 $K$ 满足：

$$K \to \infty \quad \text{且} \quad \frac{K}{n} \to 0$$

时有：

$$R_{K\text{-NN}} \to R^*$$

即 KNN 在渐近意义下是**一致**的分类器。

#### 11.3 维度灾难（Curse of Dimensionality）

KNN 面临严重的维度灾难。在高维空间中：

$$\frac{\max_i d(x, x_i) - \min_i d(x, x_i)}{\min_i d(x, x_i)} \to 0 \quad \text{as } d \to \infty$$

所有点之间的距离趋于相等，KNN 失去区分能力。

**定量分析**：为在 $d$ 维空间中保持 KNN 的统计精度，需要的样本量按 $O(K \cdot \epsilon^{-d})$ 增长，随维度呈指数爆炸。

#### 11.4 K 值选择的偏差-方差折衷

| $K$ 值 | 偏差 | 方差 | 决策边界 |
|--------|------|------|---------|
| $K = 1$ | 最小 | 最大 | 复杂，过度拟合训练集 |
| $K$ 小 | 较低 | 较高 | 不规则 |
| $K$ 大 | 较高 | 较低 | 平滑，趋向于线性 |
| $K = n$ | 最大 | 最小 | 总是预测多数类 |

**经验法则**：
- $K$ 取奇数以避免投票平局
- 起点：$K \approx \sqrt{n}$
- 通过交叉验证确定最优 $K$

### 12. KNN 的加速结构

#### 12.1 KD-Tree

KD-Tree 递归地用过每个维度（轴对齐）的超平面对空间进行二分。每个节点存储一个点。

**查询**：利用边界框（bounding box）剪枝，只访问可能与查询点产生最近邻的子树。

**复杂度**：
- 构建：$O(n \log n)$
- 查询：$O(\log n)$（低维，$d < 20$），$O(n)$（高维退化）

#### 12.2 Ball Tree

Ball Tree 使用超球体层次划分数据。对高维数据更友好。

**查询**：利用球体间的距离下界剪枝。复杂度与 KD-Tree 类似，但在 $d \approx 30-100$ 范围内退化更慢。

---

### 13. 贝叶斯分类器与 KNN 的关系

KNN 可以视为**局部贝叶斯分类器**：在查询点 $x$ 的局部邻域内，使用相对频率近似后验概率：

$$\hat{P}(Y = y_k \mid x) \approx \frac{|\{i \in N_K(x) : y_i = y_k\}|}{K}$$

当距离度量选择合理且 $K$ 适当时，这是一种有效的局部密度估计。

---

### 14. 关键要点总结

#### 贝叶斯分类器

| 要点 | 说明 |
|------|------|
| 贝叶斯决策 | $\hat{y} = \arg\max_k P(Y=y_k)P(X=x\mid Y=y_k)$ |
| 条件独立 | $P(X\mid Y) = \prod_j P(X_j \mid Y)$ |
| 高斯 NB | 连续特征用高斯似然 |
| 多项式 NB | 计数特征用多项式似然，文本分类首选 |
| 伯努利 NB | 二值特征用伯努利似然 |
| Laplace 平滑 | $\hat{\theta} = \frac{N + \alpha}{N_{\text{total}} + \alpha|X|}$，$\alpha=1$ |
| MAP 估计 | Dirichlet 先验 + 后验众数 |
| 误差界 | $R_{\text{NB}} - R^* \leq \frac{1}{2}\sum_{j\neq l}|\text{Cov}(X_j,X_l\mid Y)|$ |

#### KNN

| 要点 | 说明 |
|------|------|
| 懒惰学习 | 无训练阶段，预测时计算距离 |
| 距离度量 | 闵可夫斯基距离族：$p=1$ 曼哈顿，$p=2$ 欧氏 |
| Cover-Hart 界 | $R^* \leq R_{\text{1-NN}} \leq 2R^*$ |
| 渐近一致性 | $K \to \infty, K/n \to 0 \implies R_{\text{K-NN}} \to R^*$ |
| 维度灾难 | 高维空间中所有距离趋于相等 |
| 加权 KNN | $w(x, x_i) \propto 1/d(x, x_i)$ 或高斯核 |
| 加速结构 | KD-Tree $(d < 20)$，Ball Tree $(d < 100)$ |
