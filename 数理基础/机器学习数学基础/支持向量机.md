# 支持向量机（SVM）—— 数学理论

## 1. 最大间隔分类器

### 1.1 问题设定

给定训练数据 $\{(x_i, y_i)\}_{i=1}^{n}$，其中 $x_i \in \mathbb{R}^d$，$y_i \in \{-1, +1\}$。SVM 的目标是寻找一个决策超平面

$$w \cdot x + b = 0$$

使得两类数据之间的**几何间隔**最大化。

### 1.2 函数间隔与几何间隔

**函数间隔（Functional Margin）**：给定超平面 $(w, b)$，点 $(x_i, y_i)$ 的函数间隔定义为

$$\hat{\gamma}_i = y_i(w \cdot x_i + b)$$

整个训练集上的函数间隔为 $\hat{\gamma} = \min_i \hat{\gamma}_i$。

**几何间隔（Geometric Margin）**：考虑超平面的法向量 $\frac{w}{\|w\|}$，几何间隔为

$$\gamma_i = \frac{y_i(w \cdot x_i + b)}{\|w\|}$$

几何间隔具有**尺度不变性**：若将 $(w, b)$ 缩放为 $(\lambda w, \lambda b)$，几何间隔不变，而函数间隔缩放 $\lambda$ 倍。

### 1.3 硬间隔原问题

最大间隔分类器的基础优化问题（**硬间隔 SVM 原问题**）：

$$\min_{w, b} \frac{1}{2}\|w\|^2$$

$$\text{s.t.} \quad y_i(w \cdot x_i + b) \geq 1, \quad i = 1, 2, \ldots, n$$

**推导**：通过缩放 $(w, b)$，使 $\min_i y_i(w \cdot x_i + b) = 1$，则最大化几何间隔 $\frac{1}{\|w\|}$ 等价于最小化 $\|w\|^2$。

约束 $y_i(w \cdot x_i + b) \geq 1$ 确保了所有点都正确分类且在间隔边界之外。

### 1.4 支持向量与间隔宽度

- **支持向量**：使约束取等号的点，即 $y_i(w \cdot x_i + b) = 1$
- **间隔宽度**：

$$\text{margin} = \frac{2}{\|w\|}$$

决策函数仅依赖于支持向量，大部分训练样本的对应乘子为零，这是 SVM 稀疏性的来源。

## 2. 拉格朗日对偶与 KKT 条件

### 2.1 拉格朗日函数

引入拉格朗日乘子 $\alpha_i \geq 0$（$i = 1, 2, \ldots, n$），构造拉格朗日函数：

$$L(w, b, \alpha) = \frac{1}{2}\|w\|^2 - \sum_{i=1}^{n} \alpha_i \left[y_i(w \cdot x_i + b) - 1\right]$$

注意：原问题是最小化 $L$ 关于 $(w, b)$，同时最大化关于 $\alpha$（鞍点）。

### 2.2 对偶问题推导

**步骤 1**：对 $w$ 和 $b$ 求偏导并令其为零

$$\frac{\partial L}{\partial w} = w - \sum_{i=1}^{n} \alpha_i y_i x_i = 0 \;\Rightarrow\; w = \sum_{i=1}^{n} \alpha_i y_i x_i$$

$$\frac{\partial L}{\partial b} = -\sum_{i=1}^{n} \alpha_i y_i = 0 \;\Rightarrow\; \sum_{i=1}^{n} \alpha_i y_i = 0$$

**步骤 2**：将 $w$ 的表达式代回 $L$，利用 $\sum\alpha_i y_i = 0$ 化简

$$
\begin{aligned}
L(w, b, \alpha) &= \frac{1}{2} \sum_{i,j} \alpha_i \alpha_j y_i y_j (x_i \cdot x_j) - \sum_i \alpha_i y_i \left(\sum_j \alpha_j y_j (x_j \cdot x_i) + b\right) + \sum_i \alpha_i \\
&= \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (x_i \cdot x_j)
\end{aligned}
$$

### 2.3 硬间隔对偶问题

$$\max_{\alpha} \quad W(\alpha) = \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (x_i \cdot x_j)$$

$$\text{s.t.} \quad \alpha_i \geq 0, \quad i = 1, \ldots, n$$

$$\sum_{i=1}^{n} \alpha_i y_i = 0$$

对偶问题是**凸二次规划**，具有唯一最大值（在 $\alpha$ 处）。

### 2.4 完整的 KKT 条件（Hard-Margin SVM）

对于原问题的最优解 $(w^*, b^*, \alpha^*)$，KKT 条件为：

1. **原始可行性（Primal Feasibility）**：
   $$y_i(w^* \cdot x_i + b^*) \geq 1, \quad \forall i$$

2. **对偶可行性（Dual Feasibility）**：
   $$\alpha_i^* \geq 0, \quad \forall i$$

3. **互补松弛（Complementary Slackness）**：
   $$\alpha_i^* \left[y_i(w^* \cdot x_i + b^*) - 1\right] = 0, \quad \forall i$$

4. **稳定性条件（Stationarity）**：
   $$\nabla_w L = 0 \;\Rightarrow\; w^* = \sum_{i=1}^{n} \alpha_i^* y_i x_i$$
   $$\nabla_b L = 0 \;\Rightarrow\; \sum_{i=1}^{n} \alpha_i^* y_i = 0$$

互补松弛条件的含义：
- $\alpha_i^* > 0 \;\Rightarrow\; y_i(w^* \cdot x_i + b^*) = 1$（点 $x_i$ 是**支持向量**，在间隔边界上）
- $\alpha_i^* = 0 \;\Rightarrow\; y_i(w^* \cdot x_i + b^*) \geq 1$（点 $x_i$ 不是支持向量）

### 2.5 决策函数

$$\hat{y} = \text{sign}\left(\sum_{i=1}^{n} \alpha_i y_i (x_i \cdot x) + b\right)$$

$b$ 可通过任一支持向量 $x_k$ 求解：$b = y_k - \sum_{i=1}^{n} \alpha_i y_i (x_i \cdot x_k)$。

## 3. 软间隔 SVM

### 3.1 动机

现实数据往往线性不可分，或存在噪声。硬间隔 SVM 对此极为敏感。

### 3.2 引入松弛变量

对每个训练样本引入**松弛变量** $\xi_i \geq 0$，允许部分点违反间隔约束：

$$\min_{w, b, \xi} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \xi_i$$

$$\text{s.t.} \quad y_i(w \cdot x_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0, \quad \forall i$$

惩罚参数 $C > 0$ 权衡间隔最大化与误分类容忍度：
- $C \to \infty$：退化为硬间隔 SVM
- $C \to 0$：允许大量误分类以获得极大间隔

### 3.3 软间隔拉格朗日函数

引入两组乘子 $\alpha_i \geq 0$ 和 $\mu_i \geq 0$：

$$L(w, b, \xi, \alpha, \mu) = \frac{1}{2}\|w\|^2 + C\sum_{i=1}^{n}\xi_i - \sum_{i=1}^{n}\alpha_i\left[y_i(w \cdot x_i + b) - 1 + \xi_i\right] - \sum_{i=1}^{n}\mu_i\xi_i$$

### 3.4 KKT 条件（Soft-Margin SVM）

1. **原始可行性**：
   $$y_i(w \cdot x_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0, \quad \forall i$$

2. **对偶可行性**：
   $$\alpha_i \geq 0, \quad \mu_i \geq 0, \quad \forall i$$

3. **互补松弛**：
   $$\alpha_i\left[y_i(w \cdot x_i + b) - 1 + \xi_i\right] = 0$$
   $$\mu_i \xi_i = 0$$

4. **稳定性**：
   $$w = \sum_i \alpha_i y_i x_i, \quad \sum_i \alpha_i y_i = 0, \quad C - \alpha_i - \mu_i = 0$$

由 $C - \alpha_i - \mu_i = 0$ 和 $\mu_i \geq 0$ 得到框约束：$0 \leq \alpha_i \leq C$。

### 3.5 软间隔对偶问题

$$\max_{\alpha} \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (x_i \cdot x_j)$$

$$\text{s.t.} \quad 0 \leq \alpha_i \leq C, \quad \sum_{i=1}^{n} \alpha_i y_i = 0$$

与硬间隔的唯一区别：$\alpha_i$ 有上界 $C$。

### 3.6 $\alpha_i$ 的分类意义

| $\alpha_i$ 值 | 位置 | 含义 |
|---------------|------|------|
| $\alpha_i = 0$ | 间隔外 | 正确分类，不在间隔边界上 |
| $0 < \alpha_i < C$ | 间隔边界上 | $y_i(w \cdot x_i + b) = 1$，自由支持向量 |
| $\alpha_i = C$ | 间隔内/误分类 | $\xi_i > 0$，有分类误差或落在间隔内 |

## 4. 核技巧（Kernel Trick）

### 4.1 特征映射与核函数

当数据在原空间 $\mathbb{R}^d$ 中线性不可分时，通过非线性映射 $\phi$ 将数据映射到高维特征空间 $\mathcal{H}$：

$$\phi: \mathbb{R}^d \to \mathcal{H}$$

核函数避免了显式计算 $\phi(x)$，只需计算 $\mathcal{H}$ 中的内积：

$$K(x_i, x_j) = \langle \phi(x_i), \phi(x_j) \rangle_{\mathcal{H}}$$

核化后的对偶问题：

$$\max_{\alpha} \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j K(x_i, x_j)$$

核化后的决策函数：

$$f(x) = \text{sign}\left(\sum_{i \in SV} \alpha_i y_i K(x_i, x) + b\right)$$

### 4.2 常用核函数

| 核名称 | 公式 | 参数 |
|--------|------|------|
| **线性核** | $K(x_i, x_j) = x_i \cdot x_j$ | 无 |
| **多项式核** | $K(x_i, x_j) = (\gamma x_i \cdot x_j + r)^d$ | $\gamma, r, d$ |
| **RBF（高斯）核** | $K(x_i, x_j) = \exp(-\gamma\|x_i - x_j\|^2)$ | $\gamma = 1/(2\sigma^2)$ |
| **Sigmoid 核** | $K(x_i, x_j) = \tanh(\gamma x_i \cdot x_j + r)$ | $\gamma, r$ |

**线性核**：等价于无映射的线性 SVM，适合高维稀疏数据（如文本分类）。

**多项式核**：映射到维度为 $\binom{d+\text{degree}}{\text{degree}}$ 的特征空间，可捕捉特征之间的交互项。

**RBF 核**：
- 隐式映射到**无限维**的再生核希尔伯特空间（RKHS）
- 泰勒展开：$\exp(-\gamma\|x_i - x_j\|^2) = \exp(-\gamma\|x_i\|^2)\exp(-\gamma\|x_j\|^2)\sum_{k=0}^{\infty}\frac{(2\gamma x_i \cdot x_j)^k}{k!}$
- $\gamma$ 大：决策边界复杂（过拟合风险）
- $\gamma$ 小：决策边界平滑（欠拟合风险）

**Sigmoid 核**：只有当 $\gamma$ 和 $r$ 取特定值时才是有效核（满足 Mercer 条件）。

### 4.3 Mercer 定理（Mercer's Theorem）

**定理**：函数 $K: \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ 可以作为核函数的**充要条件**是：

对于任意有限数据集 $\{x_1, x_2, \ldots, x_m\} \subseteq \mathcal{X}$，由 $K$ 定义的核矩阵

$$G = [K(x_i, x_j)]_{m \times m}$$

是**半正定矩阵**（即 $G \succeq 0$，对任意非零向量 $v \in \mathbb{R}^m$ 有 $v^T G v \geq 0$）。

**证明思路**：若 $K$ 对应某特征映射的内积，则 $G$ 必然半正定；反之，若 $G$ 半正定，可通过 Mercer 定理构造对应的特征映射（RKHS 表示定理）。

### 4.4 核的运算性质

已知 $K_1, K_2$ 是有效核，则以下也是有效核：
1. $K(x, z) = \alpha K_1(x, z)$（$\alpha > 0$）
2. $K(x, z) = K_1(x, z) + K_2(x, z)$
3. $K(x, z) = K_1(x, z) \cdot K_2(x, z)$
4. $K(x, z) = f(x)K_1(x, z)f(z)$（$f$ 为任意实函数）
5. $K(x, z) = \lim_{n\to\infty} K_n(x, z)$（若极限存在）

## 5. SMO（序列最小优化）算法

### 5.1 算法概述

SMO（Sequential Minimal Optimization）由 John Platt 于 1998 年提出，是训练 SVM 的实际标准方法。其核心思想是：

- 完整对偶问题涉及 $n$ 个变量，难以一次性优化
- 每步只选择**两个乘子** $\alpha_i, \alpha_j$ 进行优化，固定其余变量
- 两个变量的子问题有**解析解**（因为约束 $\sum \alpha_k y_k = 0$ 将两个变量耦合）

### 5.2 两变量子问题求解

选择 $\alpha_i, \alpha_j$。约束条件：

$$\alpha_i y_i + \alpha_j y_j = \text{const} = -\sum_{k \neq i,j} \alpha_k^{\text{old}} y_k$$

记 $S = y_i y_j$，则 $\alpha_j = \gamma - S\alpha_i$（其中 $\gamma$ 为常数）。

约化后的目标函数是关于 $\alpha_j$ 的一元二次函数：

$$W(\alpha_j) = \text{const} + \text{(linear term)} \cdot \alpha_j + \text{(quadratic term)} \cdot \alpha_j^2$$

**无约束最优解**：

$$\alpha_j^{\text{new, unc}} = \alpha_j^{\text{old}} + \frac{y_j(E_i - E_j)}{\eta}$$

其中：
- $E_k = f(x_k) - y_k$ 是第 $k$ 个样本的预测误差
- $\eta = K(x_i, x_i) + K(x_j, x_j) - 2K(x_i, x_j)$

**约束裁剪**：设 $L \leq \alpha_j \leq H$
$$\alpha_j^{\text{new}} = \begin{cases} H, & \text{if } \alpha_j^{\text{new, unc}} > H \\ \alpha_j^{\text{new, unc}}, & \text{if } L \leq \alpha_j^{\text{new, unc}} \leq H \\ L, & \text{if } \alpha_j^{\text{new, unc}} < L \end{cases}$$

由 $\alpha_i^{\text{new}} = \alpha_i^{\text{old}} + S(\alpha_j^{\text{old}} - \alpha_j^{\text{new}})$ 得到 $\alpha_i$。

### 5.3 乘子选择启发式

1. **外循环**：选择违反 KKT 条件最严重的 $\alpha_i$（第一个乘子）
2. **内循环**：选择使 $|E_i - E_j|$ 最大的 $\alpha_j$（第二个乘子），以最大化目标函数的增量

### 5.4 阈值 $b$ 的更新

若 $0 < \alpha_i^{\text{new}} < C$（即 $x_i$ 为自由支持向量）：
$$b_i = b^{\text{old}} - E_i - y_i K_{ii}(\alpha_i^{\text{new}} - \alpha_i^{\text{old}}) - y_j K_{ij}(\alpha_j^{\text{new}} - \alpha_j^{\text{old}})$$

同理计算 $b_j$。若 $\alpha_i^{\text{new}}$ 和 $\alpha_j^{\text{new}}$ 都在边界上，取 $b = (b_i + b_j) / 2$。

## 6. 支持向量回归（SVR）

### 6.1 $\epsilon$-不敏感损失

SVR 使用 $\epsilon$ 管道损失：预测值 $f(x)$ 与真实值 $y$ 的偏差不超过 $\epsilon$ 时损失为零。

$$L_\epsilon(y, f(x)) = \max(0, |y - f(x)| - \epsilon)$$

即：

$$L_\epsilon(y, f(x)) = \begin{cases} 0, & |y - f(x)| \leq \epsilon \\ |y - f(x)| - \epsilon, & \text{otherwise} \end{cases}$$

### 6.2 SVR 原问题

对每个样本引入两个松弛变量 $\xi_i$（上偏差）和 $\xi_i^*$（下偏差）：

$$\min_{w, b, \xi, \xi^*} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} (\xi_i + \xi_i^*)$$

$$\text{s.t.} \quad \begin{cases} y_i - (w \cdot x_i + b) \leq \epsilon + \xi_i \\ (w \cdot x_i + b) - y_i \leq \epsilon + \xi_i^* \\ \xi_i \geq 0, \quad \xi_i^* \geq 0 \end{cases}$$

### 6.3 SVR 对偶问题

引入四个拉格朗日乘子 $\alpha_i, \alpha_i^*, \mu_i, \mu_i^* \geq 0$，化简得到：

$$\max_{\alpha, \alpha^*} -\frac{1}{2}\sum_{i,j}(\alpha_i - \alpha_i^*)(\alpha_j - \alpha_j^*)K(x_i, x_j) - \epsilon\sum_i(\alpha_i + \alpha_i^*) + \sum_i y_i(\alpha_i - \alpha_i^*)$$

$$\text{s.t.} \quad \begin{cases} 0 \leq \alpha_i, \alpha_i^* \leq C \\ \sum_i (\alpha_i - \alpha_i^*) = 0 \end{cases}$$

### 6.4 SVR 决策函数

$$f(x) = \sum_{i=1}^{n} (\alpha_i - \alpha_i^*) K(x_i, x) + b$$

与分类 SVM 的区别：乘子变为 $\tilde{\alpha}_i = \alpha_i - \alpha_i^*$，可取负值。$|\tilde{\alpha}_i| > 0$ 的点是 SVR 的支持向量。

### 6.5 几何解释

SVR 试图找到一个宽度为 $2\epsilon$ 的管道，使尽可能多的训练点落入管道内。管道外部的点贡献损失，管道内部的点损失为零。

## 7. 理论分析

### 7.1 VC 维与泛化界

记 $R$ 为包含所有数据点的最小超球半径，$\|w\|$ 为超平面的范数。SVM 的 VC 维满足：

$$h \leq \min\left(R^2\|w\|^2, d\right) + 1$$

泛化误差的 VC 界：

$$R_{\text{test}} \leq R_{\text{train}} + \sqrt{\frac{h(\log(2n/h) + 1) - \log(\eta/4)}{n}}$$

最大化间隔等价于最小化 $R^2\|w\|^2$，从而最小化 VC 维，这是 SVM 良好泛化性能的理论保证。

### 7.2 表示定理（Representer Theorem）

对于具有正则项 $\|w\|^2$ 的优化问题，最优解 $w^*$ 可以表示为训练样本的某种线性组合：

$$w^* = \sum_{i=1}^{n} \alpha_i \phi(x_i)$$

这是 SVM 在 RKHS 框架下成立的核心定理。

### 7.3 合页损失（Hinge Loss）形式

软间隔 SVM 等价于以下无约束优化：

$$\min_{w, b} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \max\left(0, 1 - y_i(w \cdot x_i + b)\right)$$

即 **L2 正则化 + 合页损失**。其中合页损失 $\max(0, 1 - y f(x))$ 是二分类损失函数的一种，相比 0-1 损失是凸的上界。

## 8. 多分类与结构 SVM

### 8.1 多分类策略

| 策略 | 分类器数量 | 说明 |
|------|-----------|------|
| One-vs-One (OvO) | $K(K-1)/2$ | 每对类别训练一个二分类器 |
| One-vs-All (OvA) | $K$ | 每个类别 vs 其余所有 |
| Crammer-Singer | 1 | 直接优化多类目标（结构化 SVM） |

### 8.2 结构化 SVM

将 SVM 框架推广到结构化预测：输入 $x$，输出结构 $y \in \mathcal{Y}$（如序列标注、句法分析等）：

$$\min_{w, \xi} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \xi_i$$

$$\text{s.t.} \quad w \cdot \Delta \Phi(x_i, y_i, y) \geq \Delta(y_i, y) - \xi_i, \quad \forall i, \forall y \neq y_i$$

其中 $\Delta(y_i, y)$ 是结构化损失，$\Delta\Phi$ 是联合特征差。

## 9. 关键要点总结

| 要点 | 说明 |
|------|------|
| 最大间隔 | 选择使 $\frac{2}{\|w\|}$ 最大的超平面 |
| 原问题 | $\min_{w,b} \frac{1}{2}\|w\|^2$ s.t. $y_i(w \cdot x_i + b) \geq 1$ |
| 对偶问题 | 凸二次规划，$\max_\alpha \sum\alpha_i - \frac{1}{2}\sum\alpha_i\alpha_j y_i y_j (x_i \cdot x_j)$ |
| KKT 条件 | 互补松弛是稀疏性的保证：$\alpha_i = 0$ 的点不参与决策 |
| 软间隔 | 松弛变量 $\xi_i$ + 惩罚 $C$，对偶中 $\alpha_i$ 有上界 $C$ |
| 核技巧 | $K(x_i, x_j) = \langle\phi(x_i), \phi(x_j)\rangle$，避免显式高维映射 |
| Mercer 定理 | 核矩阵半正定是有效核的充要条件 |
| RBF 核 | 映射到无限维 RKHS，$\gamma$ 控制平滑性 |
| SMO 算法 | 每次优化两个乘子，有解析解 |
| SVR | $\epsilon$ 管道，允许 $\pm\epsilon$ 的偏差免于惩罚 |
| 表示定理 | $w = \sum_i \alpha_i y_i x_i$，解在训练样本张成的空间中 |
| 合页损失 | $\max(0, 1 - y f(x))$，是 0-1 损失的凸上界 |
