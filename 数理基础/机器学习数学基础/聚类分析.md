# 聚类分析 —— 数学理论

## 第一部分：K-means 聚类

### 1. 目标函数与优化

#### 1.1 问题形式化

给定数据集 $X = \{x_1, x_2, \dots, x_n\} \subseteq \mathbb{R}^d$，K-means 的目标是将数据划分为 $K$ 个不相交的簇 $\{C_1, C_2, \ldots, C_K\}$，使得簇内平方误差和（Within-Cluster Sum of Squares, WCSS）最小：

$$J = \sum_{k=1}^{K} \sum_{x_i \in C_k} \|x_i - \mu_k\|_2^2$$

其中 $\mu_k = \frac{1}{|C_k|}\sum_{x_i \in C_k} x_i$ 是簇 $C_k$ 的质心。

#### 1.2 等价形式

$J$ 可以等价地写为总方差减去簇间方差：

$$J = \sum_{i=1}^{n}\|x_i - \bar{x}\|^2 - \sum_{k=1}^{K}|C_k| \cdot \|\mu_k - \bar{x}\|^2$$

其中 $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$ 是全局均值。最小化 WCSS 等价于最大化簇间方差。

#### 1.3 Lloyd 算法（标准 K-means）

**Lloyd 算法**（1957/1982）在两个步骤之间交替迭代：

**分配步骤**（Assignment / E-step analogue）：
$$C_k^{(t)} = \left\{x_i : \|x_i - \mu_k^{(t)}\|^2 \leq \|x_i - \mu_j^{(t)}\|^2, \; \forall j \neq k\right\}$$

**更新步骤**（Update / M-step analogue）：
$$\mu_k^{(t+1)} = \frac{1}{|C_k^{(t)}|}\sum_{x_i \in C_k^{(t)}} x_i$$

#### 1.4 收敛性证明

**引理 1（目标函数单调递减）**：每次完整迭代（分配+更新）后，$J$ 不增。

证明：
1. 分配步骤：给定固定的 $\{\mu_k\}$，通过将每个 $x_i$ 分配给最近的质心，$J$ 最小化
2. 更新步骤：给定固定的分配 $\{C_k\}$，质心取均值使 $J$ 最小化（由 $\frac{\partial}{\partial \mu_k}\sum_{x_i \in C_k}\|x_i - \mu_k\|^2 = \sum_{x_i \in C_k}2(\mu_k - x_i) = 0$ 得到）

**引理 2（有限收敛）**：由于分配方式只有有限多种（至多 $K^n$ 种），且 $J$ 严格递减则不可能重复访问同一状态，因此算法在有限步内收敛。

**注意**：收敛到**局部最优**而非全局最优。目标函数 $J$ 是非凸的，陷入局部最优是 K-means 的核心局限。

#### 1.5 时间复杂度

| 复杂度类型 | 值 | 说明 |
|-----------|----|------|
| 每轮迭代 | $O(nKd)$ | $n$ 个点分配 + $K$ 个质心更新 |
| 总复杂度 | $O(nKdT)$ | $T$ 为迭代次数 |
| 空间 | $O(nK + nd)$ | 存储分配和质心 |

实际中 $T$ 通常很小（10-50 次迭代），但理论上可能是指数级的（在最坏构造下）。

### 2. K-means++ 初始化

#### 2.1 随机初始化的缺陷

随机均匀选择 $K$ 个初始质心可能产生"糟糕"的初始化——多个质心聚集在同一簇内，或质心落在稀疏区域。目标函数的非凸性意味着糟糕的初始化会导致差的局部最优。

#### 2.2 K-means++ 算法

**Arthur & Vassilvitskii, 2007**

1. 随机均匀选择第一个质心 $\mu_1$ 从 $X$ 中
2. 对于 $k = 2, 3, \ldots, K$：
   a. 对每个点 $x_i$，计算 $D(x_i) = \min_{j<k} \|x_i - \mu_j\|^2$（到最近已选质心的距离）
   b. 以正比于 $D(x_i)$ 的概率选择 $x_i$ 作为下一个质心：

   $$P(x_i \text{ 被选为 } \mu_k) = \frac{D(x_i)}{\sum_{j=1}^{n} D(x_j)}$$

3. 重复步骤 2 直到选出 $K$ 个质心
4. 以这些质心为初始化，运行标准 K-means

#### 2.3 K-means++ 的近似保证

**定理（Arthur & Vassilvitskii, 2007）**：设 $J_{\text{opt}}$ 为最优 K-means 聚类代价。K-means++ 初始化后（不做迭代），期望代价满足：

$$\mathbb{E}[J] \leq 8(\ln K + 2) \cdot J_{\text{opt}}$$

这表明 K-means++ 在期望意义下达到 $O(\log K)$ 近似比。实际中加上后续的 Lloyd 迭代，效果通常极佳。

### 3. K-means 的推广

#### 3.1 K-medoids（PAM 算法）

用数据集中实际的点（medoid）代替均值作为簇代表，对异常值更鲁棒：

$$J_{\text{med}} = \sum_{k=1}^{K} \sum_{x_i \in C_k} d(x_i, m_k)$$

其中 $m_k \in C_k$ 是簇 $C_k$ 的 medoid。

PAM（Partitioning Around Medoids）使用交换启发式，$O(K(n-K)^2)$，适合较小数据集。

CLARANS（Clustering Large Applications based on RANdomized Search）进一步加速。

#### 3.2 Mini-batch K-means

每次迭代仅在一小批样本（mini-batch）上更新质心：

$$\mu_k \leftarrow (1 - \eta)\mu_k + \eta \cdot \frac{1}{|M_k|}\sum_{x \in M_k} x$$

其中 $M_k$ 是小批次中分配给簇 $k$ 的样本集。

**优势**：$O(bKd)$ 每轮（$b$ 为批次大小），适合大规模数据。

## 第二部分：层次聚类

### 4. 凝聚型层次聚类

#### 4.1 算法框架

```
1. 初始化：每个点自身为一个簇（n 个簇）
2. 计算所有簇对之间的距离
3. 合并距离最近的两个簇
4. 更新距离矩阵（重新计算新簇与其他簇的距离）
5. 重复 3-4 直到仅剩一个簇（或达到目标簇数）
```

#### 4.2 核心：链接方法（Linkage Criteria）

给定两个簇 $C_p$ 和 $C_q$：

**单链接（Single Linkage / MIN）**：

$$d_{\text{single}}(C_p, C_q) = \min_{x \in C_p, y \in C_q} d(x, y)$$

- 本质：两个簇的距离由最近的点对决定
- 性质：容易出现**链式效应**（chaining），可发现细长/非球形簇
- 与图论的最小生成树（MST）的等价性：单链接层次聚类等价于在 MST 上按权重递减删除边

**完全链接（Complete Linkage / MAX）**：

$$d_{\text{complete}}(C_p, C_q) = \max_{x \in C_p, y \in C_q} d(x, y)$$

- 本质：两个簇的距离由最远的点对决定
- 性质：产生紧凑、直径相近的球形簇
- 定义簇的**直径**：$\max_{x,y\in C} d(x,y)$；完全链接倾向于合并直径最小的两个簇

**平均链接（Average Linkage / UPGMA）**：

$$d_{\text{average}}(C_p, C_q) = \frac{1}{|C_p| \cdot |C_q|} \sum_{x \in C_p} \sum_{y \in C_q} d(x, y)$$

- Unweighted Pair Group Method with Arithmetic Mean
- 对噪声的鲁棒性居中，是系统发育学中最常用的方法
- 时间复杂度 $O(n^2)$ 如果用动态更新（Lance-Williams 公式）

**Ward 方法**：

$$d_{\text{Ward}}(C_p, C_q) = \frac{|C_p| \cdot |C_q|}{|C_p| + |C_q|} \| \mu_p - \mu_q \|^2$$

- 合并后簇内方差的增加量：$\Delta_{\text{Ward}} = \sum_{x \in C_p \cup C_q}\|x - \mu_{p\cup q}\|^2 - \sum_{x \in C_p}\|x - \mu_p\|^2 - \sum_{x \in C_q}\|x - \mu_q\|^2$
- 等价于上式
- 目标函数与 K-means 一致（最小化总簇内方差），倾向产生大小均匀的球形簇

#### 4.3 Lance-Williams 公式

所有上述链接方法可通过统一的**Lance-Williams 更新公式**高效实现（合并 $C_p$ 和 $C_q$ 为 $C_r$ 后，$C_r$ 与其他簇 $C_s$ 的距离）：

$$d(C_r, C_s) = \alpha_p d(C_p, C_s) + \alpha_q d(C_q, C_s) + \beta d(C_p, C_q) + \gamma |d(C_p, C_s) - d(C_q, C_s)|$$

不同链接方法的参数：

| 方法 | $\alpha_p$ | $\alpha_q$ | $\beta$ | $\gamma$ |
|------|-----------|-----------|--------|---------|
| Single | 1/2 | 1/2 | 0 | -1/2 |
| Complete | 1/2 | 1/2 | 0 | +1/2 |
| Average | $\frac{|C_p|}{|C_r|}$ | $\frac{|C_q|}{|C_r|}$ | 0 | 0 |
| Ward | $\frac{|C_p|+|C_s|}{|C_r|+|C_s|}$ | $\frac{|C_q|+|C_s|}{|C_r|+|C_s|}$ | $\frac{-|C_s|}{|C_r|+|C_s|}$ | 0 |

使用 Lance-Williams 公式后，每次合并只需 $O(n)$ 时间更新距离矩阵，总时间复杂度 $O(n^2)$。

#### 4.4 树状图（Dendrogram）

树状图是层次聚类输出的二叉树形可视化：
- **纵轴**：合并发生时的距离
- **横轴**：数据点（重排后）
- **切割线**：在某个距离/高度画水平线，将树切分为多个簇

**一致性相关系数（Cophenetic Correlation Coefficient）**：

$$C_{\text{coph}} = \frac{\sum_{i<j}(d_{ij} - \bar{d})(c_{ij} - \bar{c})}{\sqrt{\sum_{i<j}(d_{ij} - \bar{d})^2 \cdot \sum_{i<j}(c_{ij} - \bar{c})^2}}$$

其中 $d_{ij}$ 是原始距离，$c_{ij}$ 是树状图中的**一致距离**（$x_i$ 和 $x_j$ 首次被合并到同一簇时的距离高度）。$C_{\text{coph}} \to 1$ 表示树状图很好地保持了原始距离结构。

## 第三部分：基于密度的聚类

### 5. DBSCAN

**Ester, Kriegel, Sander, & Xu, 1996**

#### 5.1 核心定义

**$\epsilon$-邻域**：

$$N_\epsilon(x) = \{y \in X : d(x, y) \leq \epsilon\}$$

**点分类**：

| 类型 | 条件 | 定义 |
|------|------|------|
| 核心点（Core） | $\|N_\epsilon(x)\| \geq \text{MinPts}$ | 密度足够高的区域中心 |
| 边界点（Border） | $\|N_\epsilon(x)\| < \text{MinPts}$ 且 $\exists \text{core point } c: x \in N_\epsilon(c)$ | 核心点邻域内但不满足核心条件 |
| 噪声点（Noise） | 既非核心也非边界 | 孤立点/异常值 |

#### 5.2 密度连通关系

**密度直达（Directly Density-Reachable）**：
$$x \text{ is directly density-reachable from } p \iff p \text{ is core} \land x \in N_\epsilon(p)$$

注意**不对称**：边界点不能密度直达其他点（只限核心点）。

**密度可达（Density-Reachable）**：
存在链 $p = x_0 \to x_1 \to \cdots \to x_m = x$，其中每个 $x_{k+1}$ 从 $x_k$ 密度直达。

**密度相连（Density-Connected）**：
$$\exists \text{ core point } o: x \text{ is density-reachable from } o \land y \text{ is density-reachable from } o$$

密度相连是对称的，用于定义簇。

#### 5.3 形式化定义

**簇** $C \subseteq X$ 是满足以下条件的最大点集：
1. （极大性）$\forall p, q \in X$：若 $p \in C$ 且 $q$ 从 $p$ 密度可达，则 $q \in C$
2. （连通性）$\forall p, q \in C$：$p$ 和 $q$ 是密度相连的

**噪声** $N = \{x \in X : \forall i, x \notin C_i\}$

#### 5.4 算法正确性

DBSCAN 在给定 $\epsilon$ 和 $\text{MinPts}$ 的情况下**确定性地**生成唯一的簇划分（与点的处理顺序无关，但边界点可能依赖于处理顺序被分配到不同的核心点所在簇）。

#### 5.5 参数选择理论

**MinPts**：通常取 $\text{MinPts} \geq d + 1$（$d$ 为数据维度），实践中 $\text{MinPts} = 2 \times d$ 是推荐起点。

**$\epsilon$ 的 k-距离图方法**：
1. 计算每个点到其第 $k$ 个最近邻的距离（$k = \text{MinPts} - 1$）
2. 对所有点的 $k$-距离排序
3. 寻找"拐点"（elbow）—— 在此点之后距离急剧增大
4. 拐点处的 $k$-距离值即为推荐的 $\epsilon$

**理论依据**：核心点区域的 $k$-距离小而稳定（因为在密集区域）；噪声区域的 $k$-距离较大。拐点标记了从密集区域到稀疏区域的过渡。

### 6. HDBSCAN

**Campello, Moulavi, & Sander, 2013**

#### 6.1 核心距离（Core Distance）

$$\text{core}_k(x) = d(x, \text{NN}_k(x))$$

其中 $\text{NN}_k(x)$ 是 $x$ 的第 $k$ 个最近邻（按的距离排序）。$k = \text{MinPts} - 1$。

核心距离反映了 $x$ 处密度的倒数：密度越高，核心距离越小。

#### 6.2 互达距离（Mutual Reachability Distance）

$$d_{\text{mreach}-k}(x, y) = \max\{\text{core}_k(x), \text{core}_k(y), d(x, y)\}$$

**几何解释**：将稠密区域中的点"推开"，使得互达距离在稠密区域主要取决于 $k$-距离，在稀疏区域取决于实际距离。这创造了一个密度感知的距离度量。

#### 6.3 算法结构

1. 构建基于互达距离的最小生成树（MST）
2. 按边的互达距离降序删除 MST 的边 → 产生层次聚类结构
3. 通过**稳定性（Stability）**指标选择最优的"压缩树"（Condensed Tree）切割

$$\text{Stability}(C) = \sum_{x \in C} (\lambda_{\text{birth}}(x, C) - \lambda_{\text{death}}(C))$$

其中 $\lambda_{\text{birth}}$ 是点 $x$ "出生"在簇 $C$ 时的密度阈值（互达距离的倒数），$\lambda_{\text{death}}$ 是簇 $C$ "死亡"（分裂）时的密度阈值。

#### 6.4 相对 DBSCAN 的优势

- 仅需一个参数 $\text{MinPts}$
- 能处理**变密度**的簇
- 自动选择最优簇数
- 提供每个点的簇成员概率（软聚类）

### 7. 簇数评估指标

#### 7.1 轮廓系数（Silhouette Coefficient）

对每个点 $x_i \in C_k$：

**簇内紧凑度**（平均簇内距离）：

$$a(i) = \frac{1}{|C_k| - 1} \sum_{x_j \in C_k, j \neq i} d(x_i, x_j)$$

**簇间分离度**（到最近其他簇的平均距离）：

$$b(i) = \min_{l \neq k} \frac{1}{|C_l|} \sum_{x_j \in C_l} d(x_i, x_j)$$

**轮廓系数**：

$$s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}} \in [-1, 1]$$

- $s(i) \approx 1$：与自身簇紧密，与其他簇远离 → 良好聚类
- $s(i) \approx 0$：处在两个簇的边界上
- $s(i) \approx -1$：可能被分错簇了

全局轮廓系数：$S = \frac{1}{n}\sum_{i=1}^{n} s(i)$

#### 7.2 肘部法则（Elbow Method）

绘制 $K$ 对 WCSS 的曲线：

$$W_K = \sum_{k=1}^{K} \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$

随着 $K$ 增大，$W_K$ 单调递减。在最优 $K$ 附近，下降速率显著减缓（形成"肘部"）。

**数学解释**：$W_K$ 的递减可分解为
$$\Delta W_K = W_{K-1} - W_K$$

当 $\Delta W_K$ 突然变小，说明增加一个簇的边际收益降低。

#### 7.3 Gap Statistic

**Tibshirani, Walther, & Hastie, 2001**

将实际数据的 WCSS 与均匀分布零假设下的期望 WCSS 比较：

$$\text{Gap}(K) = \frac{1}{B}\sum_{b=1}^{B} \log(W_K^{*b}) - \log(W_K)$$

其中 $W_K^{*b}$ 是第 $b$ 个参考数据集（在数据范围的超立方体中均匀生成）的 WCSS。

选择满足以下条件的最小 $K$：

$$\text{Gap}(K) \geq \text{Gap}(K+1) - s_{K+1}$$

其中 $s_{K+1} = \text{sd}_K \cdot \sqrt{1 + 1/B}$ 模拟了参考数据集间的变异性。

#### 7.4 Davies-Bouldin 指数

$$\text{DB} = \frac{1}{K}\sum_{k=1}^{K} \max_{l \neq k} \frac{\sigma_k + \sigma_l}{d(\mu_k, \mu_l)}$$

其中 $\sigma_k = \frac{1}{|C_k|}\sum_{x \in C_k} d(x, \mu_k)$ 是簇内平均距离。DB 越小越好。

### 8. 聚类方法的数学对比

| 特性 | K-means | 层次聚类 | DBSCAN | HDBSCAN |
|------|---------|---------|--------|---------|
| 簇形状 | 球形 | 取决于链接 | 任意 | 任意 |
| 需指定 $K$ | 是 | 否（可后切割） | 否 | 否 |
| 参数数量 | 1 (K) | 0（+链接方法） | 2 ($\epsilon$, MinPts) | 1 (MinPts) |
| 噪声处理 | 强制分配 | 强制分配 | 显式标记噪声 | 显式标记噪声 |
| 时间复杂度 | $O(nKdT)$ | $O(n^2)$ | $O(n \log n)$（有索引） | $O(n \log n)$ |
| 对初始化敏感 | 是 | 否 | 否 | 否 |
| 变密度 | 否 | 部分方法可以 | 否 | **是** |
| 确定性 | 否 | 是 | 接近确定 | 是 |

### 9. 关键要点总结

| 要点 | 公式/说明 |
|------|----------|
| K-means 目标 | $J = \sum_k \sum_{x \in C_k} \|x - \mu_k\|^2$，最小化 WCSS |
| Lloyd 算法 | 分配 → 更新 → 收敛（单调递减，有限步收敛到局部最优） |
| K-means++ | $P(x_i) \propto \min_j \|x_i - \mu_j\|^2$，$O(\log K)$ 近似保证 |
| 单链接 | $\min_{x \in A, y \in B} d(x, y)$，链式效应，$\equiv$ MST 聚类 |
| 完全链接 | $\max_{x \in A, y \in B} d(x, y)$，紧凑球形簇 |
| Ward 方法 | $\frac{|A||B|}{|A|+|B|}\|\mu_A - \mu_B\|^2$，最小化方差增加 |
| Lance-Williams | 统一 $O(n^2)$ 层次聚类更新的递推公式 |
| $\epsilon$-邻域 | $N_\epsilon(x) = \{y : d(x, y) \leq \epsilon\}$ |
| 核心点 | $\|N_\epsilon(x)\| \geq \text{MinPts}$ |
| 密度相连 | 簇定义为最大密度相连点集 |
| HDBSCAN | 互达距离 MST → 压缩树 → 稳定性选择 |
| 轮廓系数 | $s(i) = \frac{b(i)-a(i)}{\max\{a(i),b(i)\}}$ |
| Gap Statistic | $\text{Gap}(K) = E[\log W_K^*] - \log W_K$ |
