## 微分方程的背景

- 微分方程及相关学科几乎贯穿各类科学研究，是现代数学的重要分支，也是解决实际问题的工具
- 与代数方程不同：代数方程寻求**未知量与已知量**的关系；微分方程还涉及**未知量的变化率（导数）**，描述"变化问题"
  - 例：自由落体关心"下落距离如何随时间变化"；火箭关心"飞行轨道如何随时间演化"
- **基本思想**：找出已知函数与未知函数的关系，从含未知函数及其导数的方程中求得未知函数表达式
- **历史**：与微积分同时产生——牛顿用级数求解简单微分方程；雅各布·贝努利、欧拉、克雷洛、达朗贝尔、拉格朗日丰富其理论；Poincaré 与 Lyapunov 奠定现代微分方程理论（动力系统）基础

- 微分方程反映量与量之间的关系，与时间有关，是**动态系统**
- 从自然规律出发，考虑主要因素，构造含自变量、未知函数及其导数的关系式 → 数学模型
- 研究解和解结构的性质，与实际对照，不断改进模型；可由微分方程发现或预测新规律

## 1.2 微分方程的基本概念

### 微分方程的定义

联系**自变量、未知函数及未知函数的导数（或微分）**的关系式称为微分方程。

例 1：下列关系式都是微分方程：

$$\frac{dy}{dx} = x^2 \tag{1}$$
$$x\,dy - y\,dx = 0 \tag{2}$$
$$\frac{d^2x}{dt^2} + tx\left(\frac{dx}{dt}\right)^3 + x = 0 \tag{3}$$
$$\frac{d^4x}{dt^4} + 5\frac{d^2x}{dt^2} + 3x = \sin t \tag{4}[?]$$
$$\frac{\partial z}{\partial x} + \frac{\partial z}{\partial y} = z \tag{5}$$
$$\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + xy - u = 0 \tag{6}[?]$$

### 常微分方程与偏微分方程

- **常微分方程（ODE）**：自变量个数只有一个
  - 例：(1)–(4)
- **偏微分方程（PDE）**：自变量个数为两个或两个以上
  - 例：(5)(6)
- 注：本课程主要研究常微分方程，简称微分方程或方程

### 微分方程的阶

微分方程中出现的**未知函数的最高阶导数（或微分）的阶数**称为微分方程的阶数。

- (1) 一阶；(2) 一阶；(3) 二阶；(4) 四阶

$n$ 阶微分方程的一般形式：

$$F\left(x, y, \frac{dy}{dx}, \ldots, \frac{d^n y}{dx^n}\right) = 0$$

其中 $x$ 是自变量，$y$ 是未知函数，且一定含有 $\dfrac{d^n y}{dx^n}$。

### 线性与非线性

如果方程 $F\left(x, y, \dfrac{dy}{dx}, \ldots, \dfrac{d^n y}{dx^n}\right) = 0$ 的左端是 $y, y', \ldots, y^{(n)}$ 的一次有理式，则称为 $n$ 阶线性方程；否则为非线性方程。

$n$ 阶线性微分方程的一般形式：

$$a_n(x)\frac{d^n y}{dx^n} + a_{n-1}(x)\frac{d^{n-1} y}{dx^{n-1}} + \cdots + a_1(x)\frac{dy}{dx} + a_0(x)y = f(x)$$

其中 $a_n(x), \ldots, a_1(x), a_0(x), f(x)$ 为 $x$ 的已知函数。

- 线性：(1)(2)(4)；非线性：(3)（含 $\left(\frac{dx}{dt}\right)^3$ 项）

### 微分方程的解

**定义**：若函数 $y = \varphi(x)$ 在区间 $I$ 上有直到 $n$ 阶的连续导数，且对 $\forall x \in I$ 有

$$F\left(x, \varphi(x), \varphi'(x), \ldots, \varphi^{(n)}(x)\right) \equiv 0$$

则称 $y = \varphi(x)$ 为方程在 $I$ 上的一个解，称为**显式解**。

例：验证 $y = \sin x$ 与 $y = \cos x$ 都是 $y'' + y = 0$ 在 $(-\infty, +\infty)$ 上的解。
（$y = \sin x \Rightarrow y' = \cos x, y'' = -\sin x \Rightarrow y'' + y = -\sin x + \sin x = 0$ ✓）

### 显式解与隐式解

若关系式 $\Phi(x, y) = 0$ 确定的隐函数 $y = \varphi(x)$ 是方程的解，则称 $\Phi(x, y) = 0$ 为方程的**隐式解**。

例：一阶方程 $\dfrac{dy}{dx} = - \dfrac{x}{y}$ 有显式解 $y = -\sqrt{1-x^2}$ 与 $y = \sqrt{1-x^2}$，隐式解 $x^2 + y^2 = 1$。

> 注：显式解与隐式解统称为微分方程的解。

### 通解与特解

**定义**：若微分方程的解中含有任意常数，且所含**相互独立的任意常数的个数与方程的阶数相同**，则称为方程的**通解**。

例：$y = c_1 \sin x + c_2 \cos x$（$c_1, c_2$ 为任意常数）是 $y'' + y = 0$ 的通解。

$n$ 阶微分方程通解的一般形式：

$$y = \varphi(x, c_1, c_2, \ldots, c_n)$$

其中 $c_1, \ldots, c_n$ 为相互独立的任意常数（独立性的行列式判别条件：Wronski 型行列式 $\neq 0$）。

例：验证 $y = c_1 e^x + c_2 e^{-x} + c_3 e^{2x} + \dfrac{1}{2}$ 是 $y''' - 2y'' - y' + 2y = 6$ 的通解（代入计算可证，且 Wronski 行列式非零）。

- **隐式通解（通积分）**：隐式解中含有任意常数且个数与阶数相同
- 以后不区分显式通解与隐式通解，统称**通解**

**特解**：在通解中给任意常数以确定的值而得到的解。

例：通解 $y = c_1 \sin x + c_2 \cos x$ 中取 $c_1 = 0, c_2 = 1$ 得 $y = \cos x$；取 $c_1 = 1, c_2 = 0$ 得 $y = \sin x$，均为 $y'' + y = 0$ 的特解。

### 定解条件与初值问题（Cauchy 问题）

- **定解条件**：根据实际问题附加的条件；求满足定解条件的解的问题称**定解问题**
- **初始条件**：$n$ 阶微分方程的初始条件指 $n$ 个条件（当 $x = x_0$ 时）：

$$y(x_0) = y_0, \quad y'(x_0) = y_0^{(1)}, \quad \ldots, \quad y^{(n-1)}(x_0) = y_0^{(n-1)}$$

其中 $x_0, y_0, y_0^{(1)}, \ldots, y_0^{(n-1)}$ 为给定的 $n+1$ 个常数。

- 定解条件为初始条件时，相应定解问题称为**初值问题（Cauchy 问题）**

例（P9）：验证 $y = c_1 e^x + c_2 e^{-4x}$ 是 $y'' + 5y' + 4y = 0$ 的通解，并求满足 $y(0) = 2, y'(0) = 1$ 的特解。

解：由初始条件得方程组
$$\begin{cases} c_1 + c_2 = 2 \\ c_1 - 4c_2 = 1 \end{cases} \Rightarrow c_1 = \frac{9}{5}, \; c_2 = \frac{1}{5}[?]$$

（PDF 原文计算为 $c_1 = 3, c_2 = -1$，与 $y(0)=2,\ y'(0)=1$ 核对不符，疑为讲义笔误，待校对）

> [!note] 校对点
> 讲义原文解出 $c_1 = 3,\ c_2 = -1$，代回 $y'(0) = 3 - 4(-1) = 7 \neq 1$，与初始条件矛盾；按 $y(0)=2, y'(0)=1$ 应得 $c_1 = 9/5, c_2 = 1/5$。

### 积分曲线与方向场

- **积分曲线**：一阶方程 $\dfrac{dy}{dx} = f(x, y)$ 的解 $y = \varphi(x)$ 在 $xy$ 平面上表示的曲线；通解对应一族积分曲线
- **方向场**：在 $f(x, y)$ 的定义域 $D$ 内每一点画一个以 $f(x, y)$ 为斜率、中心在该点的直线段，带有这种直线段的区域称为方程的方向场
- **等斜线**：方向场中方向相同的点的几何轨迹。方程 $\dfrac{dy}{dx} = f(x, y)$ 的等斜线为 $f(x, y) = k$（$k$ 为参数）

### 驻定（自治）与非驻定（非自治）

- 驻定（自治）系统：右端不显含自变量

### 相空间、轨线与奇点

- **相空间**：不含自变量、仅由未知函数组成的空间
- **轨线**：积分曲线在相空间中的投影
- **奇点（平衡点）**：平衡解（驻定解、常数解）对应的点

例：$\begin{cases} \dot{u} = v \\ \dot{v} = -u \end{cases}$，$u(0) = 1, v(0) = 0$ 的解为 $(u(t), v(t)) = (\cos t, -\sin t)$，轨线为相平面中的圆（$u^2 + v^2 = 1$）。
