# 第三章 一阶微分方程解的存在定理

> 来源：课堂讲义《第三章 3.1 / 3.2 解的延拓定理 / 3.3 奇解》

- §3.1 解的存在唯一性定理和逐步逼近法
- §3.2 解的延拓和解对初值的连续性和可微性
- §3.3 奇解

**核心问题**：初值问题 $\begin{cases} \dfrac{dy}{dx} = f(x,y) \\ y(x_0) = y_0 \end{cases}$ 的解是否存在？若存在是否唯一？

- 通解一般有无限多个，给定初始条件后：解可能**不存在**；若存在，可能**唯一**也可能**不唯一**
- 例（解不唯一）：$y' = y^{2/3}, y(0) = 0$ 有解 $y \equiv 0$ 与 $y = (x-c)^3/27$ 族
- 例（解不存在）：$\dfrac{dy}{dx} = \dfrac{1}{x}, y(0) = 0$ 无解
- 解的存在唯一性定理是**最基本的定理**：它是数值解的前提，也是解对初值连续依赖性的基础

## §3.1 解的存在唯一性定理与逐步逼近法

### 一、存在唯一性定理

**定理 1**：考虑初值问题

$$\frac{dy}{dx} = f(x, y), \quad y(x_0) = y_0 \tag{3.1}$$

其中 $f(x,y)$ 在矩形区域

$$R: \ |x - x_0| \le a, \ |y - y_0| \le b \tag{3.2}$$

上连续，并且对 $y$ 满足 **Lipschitz 条件**：存在 $L > 0$，使对所有 $(x, y_1), (x, y_2) \in R$ 成立

$$|f(x, y_1) - f(x, y_2)| \le L|y_1 - y_2|$$

则初值问题 (3.1) 在区间 $|x - x_0| \le h$ 上的解**存在且唯一**。这里

$$h = \min\left\{a, \frac{b}{M}\right\}, \qquad M = \max_{(x,y) \in R}|f(x,y)|$$

### 证明思路（逐步逼近法）

初值问题 (3.1) 等价于**积分方程**

$$y(x) = y_0 + \int_{x_0}^{x} f(t, y(t))\,dt \tag{3.5}$$

的连续解。证明分五个命题：

- **命题 1**：初值问题 (3.1) 等价于积分方程 (3.5)
  - 若 $\varphi(x)$ 是 (3.1) 的解，对 $\varphi'(x) = f(x, \varphi(x))$ 从 $x_0$ 到 $x$ 积分即得 (3.5)
  - 反之，若 $\varphi(x)$ 是 (3.5) 的连续解，由于 $f$ 连续，两边求导得 (3.1)
- **命题 2（Picard 逐步逼近函数列）**：构造

$$\varphi_0(x) = y_0, \qquad \varphi_{n+1}(x) = y_0 + \int_{x_0}^{x} f(t, \varphi_n(t))\,dt \quad (n = 0, 1, 2, \ldots) \tag{3.7}$$

则所有 $\varphi_n(x)$ 在 $[x_0, x_0 + h]$ 上连续且满足 $|\varphi_n(x) - y_0| \le b$（数学归纳法证明）
- **命题 3**：函数序列 $\{\varphi_n(x)\}$ 在 $[x_0, x_0+h]$ 上**一致收敛**
  - 由 Lipschitz 条件归纳得 $|\varphi_n(x) - \varphi_{n-1}(x)| \le \dfrac{ML^{n-1}}{n!}|x - x_0|^n$
  - 因正项级数 $\sum \dfrac{ML^{n-1}h^n}{n!}$ 收敛，由 **Weierstrass 判别法**得一致收敛
- **命题 4**：极限 $\varphi(x) = \lim_{n\to\infty}\varphi_n(x)$ 是积分方程 (3.5) 在 $[x_0, x_0+h]$ 上的连续解（利用 $f$ 的一致收敛性取极限）
- **命题 5（唯一性）**：设 $\psi(x)$ 是 (3.5) 的另一个连续解，令 $g(x) = |\varphi(x) - \psi(x)|$，由 Lipschitz 条件得

$$g(x) \le L\int_{x_0}^{x} g(t)\,dt$$

令 $u(x) = \int_{x_0}^{x} L g(t)\,dt$，则 $u'(x) \le Lu(x)$，即 $(u(x)e^{-Lx})' \le 0$，积分得 $u(x)e^{-Lx} \le u(x_0)e^{-Lx_0} = 0$，故 $g(x) \equiv 0$，唯一性得证。

### 定理的说明

1. **Lipschitz 条件的两个容易判断的充分条件**：
   - 若 $\dfrac{\partial f}{\partial y}$ 在 $R$ 上**存在且有界**，则 $f$ 关于 $y$ 满足 Lipschitz 条件
   - 若 $\dfrac{\partial f}{\partial y}$ 在 $R$ 上**连续**，则 $f$ 关于 $y$ 满足 Lipschitz 条件（由拉格朗日中值定理）
2. **几何意义**：$h = \min\{a, b/M\}$。矩形 $R$ 中 $|f(x,y)| \le M$，故解曲线的斜率介于 $-M$ 与 $M$ 之间；为保证解不跑出矩形 $R$ 的上下界，取 $h \le b/M$。
3. **注释 1**：存在唯一性也可用泛函分析中 **Banach 不动点定理**证明
4. **注释 2**：若仅说明解的存在性，可不要求 Lipschitz 连续性，利用 **Schauder 不动点定理**证明
5. 当方程为线性方程 $y' + P(x)y = Q(x)$ 时，只要 $P(x), Q(x)$ 在 $[\alpha, \beta]$ 上连续，定理条件必能满足，且任一初值 $y(x_0) = y_0$（$x_0 \in [\alpha,\beta]$）所确定的解在 $[\alpha, \beta]$ 上有定义且连续

### 一阶隐方程解存在唯一性定理

**定理 2**：考虑一阶隐方程

$$F(x, y, y') = 0 \tag{3.5}$$

如果在点 $(x_0, y_0, y'_0)$ 的某邻域中：
1. $F$ 对所有变元连续且存在连续偏导数
2. $F(x_0, y_0, y'_0) = 0$
3. $\dfrac{\partial F}{\partial y'}(x_0, y_0, y'_0) \neq 0$

则方程 (3.5) 存在唯一解 $y = y(x)$（$|x - x_0| \le h$，$h$ 为足够小的正数），满足初始条件

$$y(x_0) = y_0, \quad y'(x_0) = y'_0$$

### 三、近似计算和误差估计

Picard 逐步逼近法：第 $n$ 次近似解 $\varphi_n(x)$ 与真正解 $\varphi(x)$ 在 $[x_0, x_0+h]$ 内的误差估计为

$$|\varphi_n(x) - \varphi(x)| \le \frac{ML^n}{(n+1)!}h^{n+1} \tag{3.19}$$

**例 1**：讨论初值问题 $\dfrac{dy}{dx} = x^2 + y^2, y(0) = 0$ 在矩形 $R: |x| \le 1, |y| \le 1$ 上解的存在唯一区间，并求误差不超过 0.05 的近似解表达式。

解：$M = \max_R |x^2+y^2| = 2$，$h = \min\{1, \frac{1}{2}\} = \frac{1}{2}$，故存在唯一区间为 $|x| \le \frac{1}{2}$。

由于 $\dfrac{\partial f}{\partial y} = 2y$，$L \le 2$。由 (3.19)：

$$|\varphi_n(x) - \varphi(x)| \le \frac{ML^n}{(n+1)!}h^{n+1} = \frac{1}{(n+1)!} < 0.05$$

取 $n = 3$，逐步逼近：

$$\varphi_0 = 0, \quad \varphi_1 = \frac{x^3}{3}, \quad \varphi_2 = \frac{x^3}{3} + \frac{2x^7}{63}, \quad \varphi_3 = \frac{x^3}{3} + \frac{2x^7}{63} + \frac{x^{11}}{2079} + \frac{2x^{15}}{59535}$$

$\varphi_3(x)$ 即为所求近似解，在 $[-\frac{1}{2}, \frac{1}{2}]$ 上误差不超过 0.05。

**例 2**：求初值问题 $\dfrac{dy}{dx} = y^2 + 1, y(0) = 0$ 的解的存在唯一区间。

解：$M = 1 + b^2$，$h = \min\{a, \frac{b}{1+b^2}\}$。$\dfrac{b}{1+b^2}$ 在 $b = 1$ 时取最大值 $\frac{1}{2}$，故取 $a = 1, b = 1$，$h = \frac{1}{2}$，存在唯一区间为 $|x| \le \frac{1}{2}$。（实际解 $y = \tan x$，在 $|x| < \pi/2$ 有定义，说明定理给出的是充分条件而非必要条件）

**例 3**：用 Picard 迭代法求初值问题 $\dfrac{dy}{dx} = 2x(1 + y^2), y(0) = 0$ 的解。

解：迭代序列 $y_n(x) = x^2 + \dfrac{x^6}{2!} + \cdots + \dfrac{x^{4n-2}}{n!}$，取极限得 $y = e^{x^2} - 1$。

## §3.2 解的延拓和解对初值的连续性与可微性

### 3.2.1 解的延拓

#### 1. 局部 Lipschitz 条件

函数 $f(x,y)$ 在某一有界区域 $G$ 中有意义，若对区域 $G$ 内的**每一点**，存在以其为中心的完全含于 $G$ 内的矩形域 $R$，在 $R$ 上 $f(x,y)$ 满足 Lipschitz 条件，则称 $f(x,y)$ 在 $G$ 内满足**局部 Lipschitz 条件**。（注意：点不同，域 $R$ 大小和常数 $L$ 可能不同）

#### 2. 解的延拓

设 $y = \varphi(x)$（$x \in [a, b]$）是初值问题的解，若 $y = \psi(x)$（$x \in [a_1, b_1]$）也是初值问题的解，$[a, b] \subset [a_1, b_1]$，且当 $x \in [a, b]$ 时 $\psi(x) \equiv \varphi(x)$，则称解 $\psi(x)$ 是解 $\varphi(x)$ 在区间 $[a, b]$ 上的**延拓**。

#### 3. 延拓方法

以 $x$ 增大方向为例：解 $\varphi(x)$ 在 $[x_0 - h, x_0 + h]$ 上有定义，取端点 $(x_0+h, \varphi(x_0+h))$ 为新初值点，重新用存在唯一性定理将解延拓到更大的区间，如此反复。

### 解的延拓定理及其推论

**解的延拓定理**：如果方程 (3.1) 右端的函数 $f(x,y)$ 在有界区域 $G$ 中连续，且在 $G$ 内满足局部 Lipschitz 条件，那么方程 (3.1) 通过 $G$ 内任何一点 $(x_0, y_0)$ 的解 $y = \varphi(x)$ 可以延拓，直到点 $(x, \varphi(x))$ 任意接近区域 $G$ 的**边界**。

- 以向 $x$ 增大一方的延拓来说，如果 $y = \varphi(x)$ 只能延拓到区间 $[x_0, m)$ 上（$m$ 有限），则当 $x \to m^-$ 时，$(x, \varphi(x))$ 趋近于区域 $G$ 的边界。

**推论**：如果 $G$ 是无界区域，在上述条件下，通过点 $(x_0, y_0)$ 的解 $y = \varphi(x)$ 向 $x$ 增大一方延拓时：
1. 解可以延拓到区间 $[x_0, +\infty)$；或
2. 解只可以延拓到区间 $[x_0, m)$（$m$ 为有限数），则当 $x \to m^-$ 时，或者 $\varphi(x)$ **无界**，或者 $(x, \varphi(x))$ 趋于区域 $G$ 的**边界**。

**例 1**：讨论方程 $\dfrac{dy}{dx} = \dfrac{y^2 - 1}{2}$ 以及通过点 $(\ln 2, -3)$ 的解的存在区间。

解：通解 $y = \dfrac{1 + ce^{-x}}{1 - ce^{-x}}$[?]。

- 通过点 $(0,0)$ 的解为 $y = \dfrac{1 - e^{-x}}{1 + e^{-x}}$，存在区间为 $(-\infty, +\infty)$
- 通过点 $(\ln 2, -3)$ 的解为 $y = \dfrac{1 + e^{-x}}{1 - e^{-x}}$，向右可延拓到 $+\infty$，向左只能延拓到 $0$（因为当 $x \to 0^+$ 时 $y \to -\infty$，无界），这对应推论中 (2) 的第一种情况

**例 2**：讨论方程 $\dfrac{dy}{dx} = \dfrac{1}{x} + \ln x$ 满足 $y(1) = 0$ 的解的存在区间。

解：通过点 $(1,0)$ 的解为 $y = x\ln x$，存在区间为 $(0, +\infty)$。向右可延拓到 $+\infty$，向左只能延拓到 $0$；当 $x \to 0^+$ 时 $y = x\ln x \to 0$（趋于 $G$ 的边界 $y = 0$），这对应推论中 (2) 的第二种情况。

**例 3**：用解的延拓定理证明：如果 $f(x,y)$ 在整个 $xy$ 平面上定义、连续且有界（$|f(x,y)| \le K$），且存在关于 $y$ 的一阶连续偏导数，则方程 $\dfrac{dy}{dx} = f(x,y)$ 的任一解均可延拓到区间 $(-\infty, +\infty)$。

证明：若解 $\varphi(x)$ 的斜率满足 $|\varphi'(x)| = |f(x, \varphi(x))| \le K$，则其值域必在两条直线 $y = y_0 \pm K(x - x_0)$ 夹成的阴影区内，否则将与 $|f| \le K$ 矛盾。由解的延拓定理推论，解的斜率有界 ⇒ 不会无界、也不会趋于边界，故可延拓到 $(-\infty, +\infty)$。

### 解对初值的连续依赖性定理

**定理**：假设 $f(x,y)$ 于域 $G$ 内连续且关于 $y$ 满足局部 Lipschitz 条件，$y = \varphi(x, x_0, y_0)$ 是初值问题的解，于区间 $a \le x \le b$ 有定义。那么，对任意给定的 $\varepsilon > 0$，必存在正数 $\delta = \delta(\varepsilon, a, b)$，使得当

$$(x_0 - \bar{x}_0)^2 + (y_0 - \bar{y}_0)^2 \le \delta^2$$

时，方程满足条件 $y(\bar{x}_0) = \bar{y}_0$ 的解 $y = \varphi(x, \bar{x}_0, \bar{y}_0)$ 在区间 $a \le x \le b$ 也有定义，并且

$$|\varphi(x, x_0, y_0) - \varphi(x, \bar{x}_0, \bar{y}_0)| < \varepsilon, \quad a \le x \le b$$

即解作为 $(x, x_0, y_0)$ 的函数在其存在范围内是**连续的**。

**证明关键（引理）**：如果 $f(x,y)$ 在某域 $D$ 内连续且关于 $y$ 满足 Lipschitz 条件（常数为 $L$），则方程任意两个解 $\varphi(x)$ 与 $\psi(x)$ 在它们公共存在区间上成立不等式

$$|\varphi(x) - \psi(x)| \le |\varphi(x_0) - \psi(x_0)|e^{L|x - x_0|}$$

证明：令 $V(x) = [\varphi(x) - \psi(x)]^2$，则 $V'(x) \le 2LV(x)$，即 $(V(x)e^{-2Lx})' \le 0$，得 $V(x) \le V(x_0)e^{2L(x-x_0)}$，两边开方即得。

证明要点：构造满足 Lipschitz 条件的有界闭区域 $D$（用有限覆盖定理），再用反证法结合引理证明解 $\psi$ 必落在区间 $[a,b]$ 内。

### 含参数方程与解对初值和参数的连续依赖性

**含参数的一阶方程**：

$$\frac{dy}{dx} = f(x, y, \lambda), \quad \lambda \in E \ (\alpha < \lambda < \beta)$$

其中 $f(x, y, \lambda)$ 在 $G_\lambda$ 内连续，且在 $G_\lambda$ 内关于 $y$ **一致地**满足局部 Lipschitz 条件（$L$ 与 $\lambda$ 无关）。

**解对初值和参数的连续依赖性定理**：若 $y = \varphi(x, x_0, y_0, \lambda_0)$ 是方程通过点 $(x_0, y_0)$ 的解（$\lambda = \lambda_0$），在区间 $a \le x \le b$ 有定义，则对任意 $\varepsilon > 0$，存在 $\delta = \delta(\varepsilon, a, b) > 0$，使得当

$$(x_0 - \bar{x}_0)^2 + (y_0 - \bar{y}_0)^2 + (\lambda_0 - \bar{\lambda}_0)^2 \le \delta^2$$

时，解 $y = \varphi(x, \bar{x}_0, \bar{y}_0, \bar{\lambda})$ 在 $[a, b]$ 上也有定义，且

$$|\varphi(x, x_0, y_0, \lambda_0) - \varphi(x, \bar{x}_0, \bar{y}_0, \bar{\lambda})| < \varepsilon, \quad a \le x \le b$$

### 解对初值的可微性定理

**定理**：若函数 $f(x,y)$ 以及 $\dfrac{\partial f}{\partial y}$ 都在区域 $G$ 内连续，则方程的解 $y = \varphi(x, x_0, y_0)$ 作为 $(x, x_0, y_0)$ 的函数在其存在范围内是**连续可微**的，且

$$\frac{\partial \varphi}{\partial x_0} = -f(x_0, \varphi(x_0, x_0, y_0)) \exp\left(\int_{x_0}^{x} \frac{\partial f}{\partial y}(t, \varphi)\,dt\right) = -f(x_0, y_0)\exp\left(\int_{x_0}^{x} \frac{\partial f}{\partial y}\,dt\right)$$

$$\frac{\partial \varphi}{\partial y_0} = \exp\left(\int_{x_0}^{x} \frac{\partial f}{\partial y}(t, \varphi(t, x_0, y_0))\,dt\right)$$

$$\frac{\partial \varphi}{\partial x} = f(x, \varphi(x, x_0, y_0))$$

**课堂练习**：设 $y = \varphi(x, x_0, y_0)$ 是初值问题 $\begin{cases} \dfrac{dy}{dx} = f(x,y) \\ y(x_0) = y_0 \end{cases}$ 的解，试证明 $f(x_0, y_0)\dfrac{\partial \varphi}{\partial y_0} + \dfrac{\partial \varphi}{\partial x_0} = 0$。

## §3.3 奇解

### 一、包络和奇解的定义

**曲线族的包络**：指这样的曲线，它本身并不包含在曲线族中，但过这条曲线上的每一点，有曲线族中的一条曲线与其在此点相切。

**奇解**：在有些微分方程中，存在一条特殊的积分曲线，它并不属于这个方程的积分曲线族，但在这条特殊的积分曲线上的每一点处，都有积分曲线族中的一条曲线与其在此点相切。这条特殊的积分曲线所对应的解称为方程的**奇解**。

> **注**：奇解上每一点都有方程的另一解存在（即奇解上每一点都不唯一）。

**例**：单参数曲线族 $(x - c)^2 + y^2 = R^2$（$R$ 为常数，$c$ 为参数），$y = \pm R$ 是曲线族的包络。一般的曲线族并不一定有包络（如同心圆族、平行线族）。

### 二、求奇解（包络线）的方法

#### 1. C-判别曲线法

设一阶方程 $F(x, y, y') = 0$ 的通积分为 $\Phi(x, y, C) = 0$。

**结论**：通积分作为曲线族的包络线（奇解）包含在下列方程组消去 $C$ 而得到的曲线中：

$$\begin{cases} \Phi(x, y, C) = 0 \\ \Phi_C(x, y, C) = 0 \end{cases}$$

注意：C-判别曲线中除了包络外，还有其他曲线，**尚需检验**。

**例 1**：求直线族 $x\cos\alpha + y\sin\alpha = p$ 的包络（$\alpha$ 是参数，$p$ 是常数）。

解：对参数 $\alpha$ 求导得 $-x\sin\alpha + y\cos\alpha = 0$，联立消去 $\alpha$ 得 $x^2 + y^2 = p^2$，经检验是所求包络线。

**例 2**：求直线族 $(y - c)^2 = (x - c)^3$ 的包络（$c$ 是参数）。

解：对参数 $c$ 求导 $-2(y-c) = -3(x-c)^2$，联立消去 $c$ 得两条曲线 $y = x$ 与 $y = x - \frac{2}{9}$[?]，经检验 $y = x - \frac{2}{9}$[?] 是所求包络线。

> [!note] 校对点
> 例 2 讲义结论为 "$y = x$" 与 "$y = x - \frac{4}{27}$" 两条 C-判别曲线，其中 $y = x - \frac{4}{27}$[?] 是包络。原文 "$\frac{9}{2}$" 与 "$\frac{2}{9}$" 混排，请对照原讲义核实常数。

#### 2. P-判别曲线法

**结论**：方程 $F(x, y, y') = 0$ 的奇解包含在下列方程组消去 $p$ 而得到的曲线中：

$$\begin{cases} F(x, y, p) = 0 \\ F_p(x, y, p) = 0 \end{cases}$$

注意：P-判别曲线中除了包络外，还有其他曲线，**尚需检验**。

**例 3**：求方程 $\left(\dfrac{dy}{dx}\right)^2 + y^2 - 1 = 0$ 的奇解。

解：从 $\begin{cases} p^2 + y^2 - 1 = 0 \\ 2p = 0 \end{cases}$ 消去 $p$，得到 P-判别曲线 $y = \pm 1$。原方程通解为 $y = \sin(x + c)$，而 $y = \pm 1$ 是方程的解，且正好是通解的包络。经检验它们是方程的奇解。

**例 4**：求方程 $y = x\dfrac{dy}{dx} - \left(\dfrac{dy}{dx}\right)^2$ 的奇解。

解：从 $\begin{cases} y = xp - p^2 \\ x - 2p = 0 \end{cases}$ 消去 $p$，得 P-判别曲线 $y = \dfrac{x^2}{4}$，经检验它不是方程的解，故此方程**没有奇解**。

> 注意：以上两种方法只提供求奇解的途径，所得 C-判别曲线和 P-判别曲线是不是奇解，**必须进行检验**。

#### 3. 克莱罗（Clairaut）方程

**形式**：$y = xp + f(p)$，其中 $p = \dfrac{dy}{dx}$，$f(p)$ 是 $p$ 的连续函数。

**解法**：两边对 $x$ 求导得 $p = p + xp' + f'(p)p'$，即 $p'[x + f'(p)] = 0$。

- 由 $p' = 0$ 得 $p = c$，代入得**通解**：$y = cx + f(c)$
- 由 $x + f'(p) = 0$ 得**奇解**的参数形式：

$$\begin{cases} x = -f'(p) \\ y = f(p) - pf'(p) \end{cases}$$

**例 5**：求解方程 $y = xp + \dfrac{1}{p}$。

解：这是克莱罗方程，通解为 $y = cx + \dfrac{1}{c}$。由 $\begin{cases} x = \dfrac{1}{c^2} \\ y = cx + \dfrac{1}{c} \end{cases}$ 消去 $c$ 得奇解 $y^2 = 4x$。

**例 6**：求一曲线，使在其上每一点的切线截割坐标轴而成的直角三角形面积都等于 2。

解：设曲线为 $y = y(x)$，过点 $(x,y)$ 的切线方程 $Y = y + y'(X - x)$，与坐标轴交点为 $(x - \dfrac{y}{y'}, 0)$ 和 $(0, y - xy')$。三角形面积

$$\frac{1}{2}\left|(x - \frac{y}{y'})(y - xy')\right| = 2$$

化简得 $y = xp \pm \dfrac{2}{p}$[?]，这是克莱罗方程，通解 $y = cx \pm \dfrac{2}{c}$，消去 $c$ 得奇解 $xy = 1$（等腰双曲线），即为满足要求的曲线。

> [!note] 校对点
> 例 6 讲义推导为 $y = xp \pm \dfrac{2}{p}$ 型克莱罗方程，通解 $y = cx \pm \dfrac{2}{c}$，奇解 $xy = \pm 1$[?]，最终取 $xy = 1$。请对照原讲义核实符号。
