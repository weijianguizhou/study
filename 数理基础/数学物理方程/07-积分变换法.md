# 07 积分变换法

## 简介

积分变换法（Method of Integral Transforms）是求解偏微分方程的另一重要方法。其核心思想是通过积分变换将偏微分方程中的某些自变量"变换掉"，从而降低方程的维数，将偏微分方程转化为常微分方程或代数方程求解。最常见的积分变换包括傅里叶变换（Fourier Transform）和拉普拉斯变换（Laplace Transform）。

> [!tip] 方法选择指南
> - **傅里叶变换**：适用于定义在无穷域（全空间或半空间）上的问题
> - **拉普拉斯变换**：适用于初值问题（$t \geq 0$），特别适合处理因果信号

---

## 傅里叶变换及其定义

### 傅里叶变换

函数 $f(x)$ 的傅里叶变换定义为：

$$\hat{f}(\xi) = \mathcal{F}[f(x)] = \int_{-\infty}^{+\infty} f(x) e^{-i\xi x} \, dx$$

### 傅里叶逆变换

$$f(x) = \mathcal{F}^{-1}[\hat{f}(\xi)] = \frac{1}{2\pi} \int_{-\infty}^{+\infty} \hat{f}(\xi) e^{i\xi x} \, d\xi$$

> [!note] 不同定义
> 傅里叶变换有多种等价定义方式（归一化因子的分配不同）。此处采用的是非对称形式。部分文献使用 $\frac{1}{\sqrt{2\pi}}$ 对称分配的方式。

### 重要性质

| 性质 | 时域 | 频域 |
|------|------|------|
| 线性性 | $af + bg$ | $a\hat{f} + b\hat{g}$ |
| 微分性质 | $f'(x)$ | $i\xi \hat{f}(\xi)$ |
| 积分性质 | $\int_{-\infty}^x f(t) dt$ | $\frac{\hat{f}(\xi)}{i\xi}$ |
| 平移性质 | $f(x - a)$ | $e^{-ia\xi}\hat{f}(\xi)$ |
| 卷积定理 | $f * g$ | $\hat{f} \cdot \hat{g}$ |
| 乘积定理 | $f \cdot g$ | $\frac{1}{2\pi}\hat{f} * \hat{g}$ |
| 对称性 | $\hat{f}(x)$ | $2\pi f(-\xi)$ |

### 微分性质的推导

这是最重要的性质，推导如下：

$$\mathcal{F}[f'(x)] = \int_{-\infty}^{+\infty} f'(x) e^{-i\xi x} \, dx$$

分部积分（假设 $f(x) \to 0$ 当 $|x| \to \infty$）：

$$= \left[f(x) e^{-i\xi x}\right]_{-\infty}^{+\infty} + i\xi \int_{-\infty}^{+\infty} f(x) e^{-i\xi x} \, dx = i\xi \hat{f}(\xi)$$

递推得到：$\mathcal{F}[f^{(n)}(x)] = (i\xi)^n \hat{f}(\xi)$

## 傅里叶变换求解偏微分方程

### 例1：全空间热传导方程

求解：

$$\frac{\partial u}{\partial t} = k \frac{\partial^2 u}{\partial x^2}, \quad -\infty < x < +\infty, \; t > 0$$

初始条件：$u(x, 0) = \varphi(x)$

**求解步骤**：

**步骤1**：对 $x$ 做傅里叶变换，令 $\hat{u}(\xi, t) = \mathcal{F}[u(x, t)]$

$$\frac{\partial \hat{u}}{\partial t} = k(i\xi)^2 \hat{u} = -k\xi^2 \hat{u}$$

**步骤2**：这是一个关于 $t$ 的常微分方程：

$$\hat{u}(\xi, t) = \hat{\varphi}(\xi) e^{-k\xi^2 t}$$

**步骤3**：做傅里叶逆变换。注意到：

$$\mathcal{F}^{-1}\left[e^{-k\xi^2 t}\right] = \frac{1}{\sqrt{4\pi k t}} e^{-x^2/(4kt)}$$

利用卷积定理：

$$u(x, t) = \varphi(x) * \frac{1}{\sqrt{4\pi k t}} e^{-x^2/(4kt)} = \frac{1}{\sqrt{4\pi k t}} \int_{-\infty}^{+\infty} \varphi(\xi) e^{-(x-\xi)^2/(4kt)} \, d\xi$$

这个核函数 $G(x, t; \xi, 0) = \frac{1}{\sqrt{4\pi k t}} e^{-(x-\xi)^2/(4kt)}$ 就是热传导方程的**基本解**（热核）。

### 例2：全空间波动方程

求解 $u_{tt} = a^2 u_{xx}$，$u(x, 0) = \varphi(x)$，$u_t(x, 0) = \psi(x)$

对 $x$ 做傅里叶变换后：

$$\hat{u}_{tt} = -a^2 \xi^2 \hat{u}$$

解为：

$$\hat{u}(\xi, t) = \hat{\varphi}(\xi)\cos(a\xi t) + \frac{\hat{\psi}(\xi)}{a\xi}\sin(a\xi t)$$

逆变换后得到 **d'Alembert 公式**：

$$u(x, t) = \frac{1}{2}[\varphi(x+at) + \varphi(x-at)] + \frac{1}{2a}\int_{x-at}^{x+at} \psi(\xi) \, d\xi$$

## 拉普拉斯变换及其定义

### 定义

函数 $f(t)$（$t \geq 0$）的拉普拉斯变换定义为：

$$F(s) = \mathcal{L}[f(t)] = \int_0^{+\infty} f(t) e^{-st} \, dt$$

其中 $s = \sigma + i\omega$ 是复变量，要求 $\text{Re}(s) > \sigma_0$（收敛横坐标）。

### 逆变换

$$f(t) = \mathcal{L}^{-1}[F(s)] = \frac{1}{2\pi i} \int_{\gamma - i\infty}^{\gamma + i\infty} F(s) e^{st} \, ds$$

### 常用变换对

| $f(t)$ | $F(s)$ |
|---------|--------|
| $1$ | $\frac{1}{s}$ |
| $t^n$ | $\frac{n!}{s^{n+1}}$ |
| $e^{at}$ | $\frac{1}{s-a}$ |
| $\sin \omega t$ | $\frac{\omega}{s^2 + \omega^2}$ |
| $\cos \omega t$ | $\frac{s}{s^2 + \omega^2}$ |
| $e^{at}f(t)$ | $F(s-a)$ |
| $u(t-a)$（阶跃） | $\frac{e^{-as}}{s}$ |

### 重要性质

| 性质 | 表达式 |
|------|--------|
| 线性性 | $\mathcal{L}[af+bg] = aF+bG$ |
| 微分性质 | $\mathcal{L}[f'(t)] = sF(s) - f(0)$ |
| 二阶微分 | $\mathcal{L}[f''(t)] = s^2F(s) - sf(0) - f'(0)$ |
| 积分性质 | $\mathcal{L}\left[\int_0^t f(\tau)d\tau\right] = \frac{F(s)}{s}$ |
| 平移性质 | $\mathcal{L}[f(t-a)u(t-a)] = e^{-as}F(s)$ |
| 频移性质 | $\mathcal{L}[e^{at}f(t)] = F(s-a)$ |
| 卷积定理 | $\mathcal{L}[f * g] = F(s) \cdot G(s)$ |

## 拉普拉斯变换求解偏微分方程

### 例：半无限长杆的热传导

$$\frac{\partial u}{\partial t} = k \frac{\partial^2 u}{\partial x^2}, \quad x > 0, \; t > 0$$

边界条件：$u(0, t) = u_0$（恒温）

初始条件：$u(x, 0) = 0$

**求解**：对 $t$ 做拉普拉斯变换，令 $U(x, s) = \mathcal{L}[u(x, t)]$

$$sU - u(x, 0) = k \frac{d^2 U}{dx^2}$$

$$\frac{d^2 U}{dx^2} - \frac{s}{k} U = 0$$

解为：$U(x, s) = A e^{-x\sqrt{s/k}} + B e^{x\sqrt{s/k}}$

由 $u$ 有界性要求 $B = 0$，由 $u(0, t) = u_0$ 得 $U(0, s) = u_0/s$，故 $A = u_0/s$：

$$U(x, s) = \frac{u_0}{s} e^{-x\sqrt{s/k}}$$

利用拉普拉斯逆变换表：

$$u(x, t) = u_0 \, \text{erfc}\left(\frac{x}{2\sqrt{kt}}\right)$$

其中 $\text{erfc}$ 是互补误差函数。

## 卷积定理和应用

### 定义

函数 $f$ 和 $g$ 的卷积为：

$$(f * g)(t) = \int_0^t f(\tau) g(t - \tau) \, d\tau$$

### 卷积定理

> [!important] 定理
> $$\mathcal{L}[f * g] = F(s) \cdot G(s)$$
> 等价地：$\mathcal{L}^{-1}[F \cdot G] = f * g$

### 应用：Duhamel 原理

对于非齐次热传导方程：

$$\frac{\partial u}{\partial t} = k \frac{\partial^2 u}{\partial x^2} + f(x, t), \quad u(x, 0) = 0$$

利用拉普拉斯变换和卷积定理，解可表示为：

$$u(x, t) = \int_0^t \int_{-\infty}^{+\infty} G(x - \xi, t - \tau) f(\xi, \tau) \, d\xi \, d\tau$$

其中 $G$ 是热核。

## Python代码示例

以下代码演示用拉普拉斯变换（数值方法）求解半无限长杆的热传导方程：

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import special

def analytical_solution_semi_infinite_heat(x, t, u0, k):
    """
    半无限长杆热传导方程的解析解：
    u(x, t) = u0 * erfc(x / (2*sqrt(k*t)))
    
    参数:
        x : 空间坐标数组
        t : 时间
        u0: 边界温度
        k : 热扩散系数
    """
    result = np.zeros_like(x, dtype=float)
    mask = t > 0
    if np.any(mask):
        result[mask] = u0 * special.erfc(x[mask] / (2 * np.sqrt(k * t[mask])))
    return result

def numerical_laplace_inverse(F_func, t, n_terms=50):
    """
    使用 Crump 方法（级数展开）数值计算拉普拉斯逆变换
    
    参数:
        F_func: 拉普拉斯变换 F(s) 的函数
        t     : 时间点数组
        n_terms: 级数项数
    """
    gamma = 5.0  # Bromwich 积分路径的实部
    result = np.zeros_like(t, dtype=complex)
    
    for k in range(n_terms):
        # 使用梯形法则近似
        s_k = gamma + 1j * k * np.pi / t
        result += np.real(F_func(s_k) * np.exp(s_k * t)) / t
    
    result = gamma / np.pi * np.real(result)
    return result

# 参数设置
L = 5.0         # 空间范围
u0 = 100.0      # 边界温度 (°C)
k = 0.1         # 热扩散系数

x = np.linspace(0, L, 200)
times = [0.1, 0.5, 1.0, 2.0, 5.0]

# 可视化解析解
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 左图：不同时刻的温度分布
ax1 = axes[0]
colors = plt.cm.hot(np.linspace(0.2, 0.9, len(times)))
for t_val, color in zip(times, colors):
    u = analytical_solution_semi_infinite_heat(x, np.array([t_val]), u0, k)
    ax1.plot(x, u, color=color, linewidth=2, label=f't = {t_val} s')

ax1.set_xlabel('位置 x (m)', fontsize=12)
ax1.set_ylabel('温度 u (°C)', fontsize=12)
ax1.set_title('半无限长杆热传导 — 解析解', fontsize=14)
ax1.legend(fontsize=10)
ax1.grid(True, alpha=0.3)
ax1.set_ylim(0, u0 + 5)

# 右图：热流密度
ax2 = axes[1]
for t_val, color in zip(times, colors):
    # 热流密度 q = -k * du/dx = u0 * k / (sqrt(π*k*t)) * exp(-x²/(4kt))
    if t_val > 0:
        q = u0 * k / np.sqrt(np.pi * k * t_val) * np.exp(-x**2 / (4 * k * t_val))
        ax2.plot(x, q, color=color, linewidth=2, label=f't = {t_val} s')

ax2.set_xlabel('位置 x (m)', fontsize=12)
ax2.set_ylabel('热流密度 q (W/m²)', fontsize=12)
ax2.set_title('热流密度分布', fontsize=14)
ax2.legend(fontsize=10)
ax2.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('laplace_heat_solution.png', dpi=150)
plt.show()
```

## 注意事项和常见错误

> [!caution] 常见错误
> 1. **傅里叶变换的可积性条件**：不是所有函数都有傅里叶变换，需要满足绝对可积条件 $\int_{-\infty}^{+\infty} |f(x)| dx < \infty$（或在广义函数意义下存在）。
> 2. **拉普拉斯变换的收敛域**：求逆变换时必须注意收敛域，不同收敛域对应不同的逆变换结果。
> 3. **混淆变换变量**：在偏微分方程中做变换后，注意区分原变量和变换后的变量。
> 4. **逆变换的计算**：很多情况下逆变换没有简单的闭合形式，需要查表或数值方法。

> [!tip] 实用建议
> - 傅里叶变换适合无穷域问题；有限域问题更适合用 [[06-分离变量法|分离变量法]]
> - 拉普拉斯变换对初值问题特别有效，因为它自动处理了初始条件
> - 常用变换对应该熟记，可以大幅提高解题效率
> - 卷积定理将时域的卷积运算化为频域的乘积运算，大大简化计算

## 本章小结

- 傅里叶变换将对 $x$ 的微分变为乘以 $i\xi$，将偏微分方程化为常微分方程
- 拉普拉斯变换将对 $t$ 的微分变为乘以 $s$ 并减去初值项
- 卷积定理是积分变换法的核心工具，将时域卷积转化为频域乘积
- 热传导方程的基本解（热核）是通过傅里叶变换法得到的重要结果
- Duhamel 原理利用卷积定理将非齐次方程的求解化为齐次方程的求解

## 练习题

1. **基础题**：利用傅里叶变换求解 $u_t = u_{xx}$，$-\infty < x < +\infty$，$u(x, 0) = e^{-|x|}$。

2. **进阶题**：利用拉普拉斯变换求解 $u_{xx} = u_t$，$x > 0$，$t > 0$，$u(x, 0) = 0$，$u(0, t) = 1$，$u$ 有界。

3. **推导题**：从傅里叶变换的定义出发，推导卷积定理。

4. **编程题**：数值计算 $\mathcal{L}^{-1}\left[\frac{1}{s^2 + 1}\right]$ 并与解析结果 $\sin t$ 比较。
