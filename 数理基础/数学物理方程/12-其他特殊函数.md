# 12 - 其他特殊函数

## 章节简介

除了贝塞尔函数和勒让德多项式之外，数学物理中还有许多重要的特殊函数。本章将介绍厄米多项式、拉盖尔多项式、超几何函数、伽马函数和贝塔函数等。这些函数在量子力学、概率论、统计物理等领域有着广泛的应用。理解这些特殊函数的定义、性质和相互关系，对于深入学习数学物理方法至关重要。

## 12.1 厄米多项式 $H_n(x)$

### 厄米方程

**厄米方程**（Hermite Equation）为：

$$y'' - 2xy' + 2ny = 0$$

该方程出现在量子力学中一维谐振子的薛定谔方程求解过程中。

### 定义

**厄米多项式**（Hermite Polynomial）的 Rodrigues 公式为：

$$\boxed{H_n(x) = (-1)^n e^{x^2}\frac{d^n}{dx^n}e^{-x^2}}$$

### 前几个厄米多项式

$$H_0(x) = 1$$

$$H_1(x) = 2x$$

$$H_2(x) = 4x^2 - 2$$

$$H_3(x) = 8x^3 - 12x$$

$$H_4(x) = 16x^4 - 48x^2 + 12$$

### 生成函数

$$e^{2xt - t^2} = \sum_{n=0}^{\infty} H_n(x)\frac{t^n}{n!}$$

### 递推关系

$$H_{n+1}(x) = 2x\,H_n(x) - 2n\,H_{n-1}(x)$$

$$H_n'(x) = 2n\,H_{n-1}(x)$$

### 正交性

$$\int_{-\infty}^{+\infty} H_m(x)\,H_n(x)\,e^{-x^2}\,dx = \sqrt{\pi}\,2^n\,n!\,\delta_{mn}$$

权重函数为 $w(x) = e^{-x^2}$（高斯权重）。

### 应用：量子谐振子

一维量子谐振子的波函数为：

$$\psi_n(x) = \left(\frac{m\omega}{\pi\hbar}\right)^{1/4}\frac{1}{\sqrt{2^n n!}}H_n\left(\sqrt{\frac{m\omega}{\hbar}}x\right)e^{-m\omega x^2/(2\hbar)}$$

能量本征值为 $E_n = \left(n + \frac{1}{2}\right)\hbar\omega$。

```

## 12.2 拉盖尔多项式 $L_n(x)$

### 拉盖尔方程

**拉盖尔方程**（Laguerre Equation）为：

$$xy'' + (1-x)y' + ny = 0$$

该方程出现在氢原子的径向波函数求解中。

### 定义

**拉盖尔多项式**（Laguerre Polynomial）的 Rodrigues 公式为：

$$\boxed{L_n(x) = \frac{e^x}{n!}\frac{d^n}{dx^n}(x^n e^{-x})}$$

### 关联拉盖尔多项式

**关联拉盖尔多项式**（Associated Laguerre Polynomial）定义为：

$$L_n^k(x) = \frac{d^k}{dx^k}L_{n+k}(x)$$

或用 Rodrigues 公式：

$$L_n^k(x) = \frac{x^{-k}e^x}{n!}\frac{d^n}{dx^n}(x^{n+k}e^{-x})$$

### 前几个拉盖尔多项式

$$L_0(x) = 1$$

$$L_1(x) = 1 - x$$

$$L_2(x) = 1 - 2x + \frac{x^2}{2}$$

### 递推关系

$$(n+1)L_{n+1}(x) = (2n+1-x)L_n(x) - n\,L_{n-1}(x)$$

### 正交性

$$\int_0^{+\infty} L_m(x)\,L_n(x)\,e^{-x}\,dx = \delta_{mn}$$

对于关联拉盖尔多项式：

$$\int_0^{+\infty} L_n^k(x)\,L_m^k(x)\,x^k e^{-x}\,dx = \frac{(n+k)!}{n!}\,\delta_{nm}$$

### 应用：氢原子

氢原子径向波函数为：

$$R_{nl}(r) = N_{nl}\left(\frac{2r}{na_0}\right)^l e^{-r/(na_0)} L_{n-l-1}^{2l+1}\left(\frac{2r}{na_0}\right)$$

其中 $a_0$ 为玻尔半径，$N_{nl}$ 为归一化常数。

## 12.3 超几何函数 $_2F_1(a,b;c;x)$

### 定义

**高斯超几何函数**（Gauss Hypergeometric Function）是许多特殊函数的"母函数"，定义为级数：

$$\boxed{_2F_1(a,b;c;x) = \sum_{k=0}^{\infty}\frac{(a)_k(b)_k}{(c)_k}\frac{x^k}{k!}, \quad |x| < 1}$$

其中 $(a)_k = a(a+1)(a+2)\cdots(a+k-1)$ 为 Pochhammer 符号（升阶乘），$(a)_0 = 1$。

### 与已知特殊函数的关系

超几何函数是一个"统一框架"，许多特殊函数是它的特例：

| 特殊函数 | 与超几何函数的关系 |
|---|---|
| 勒让德多项式 | $P_n(x) = {}_2F_1(-n, n+1; 1; \frac{1-x}{2})$ |
| 切比雪夫多项式 | $T_n(x) = {}_2F_1(-n, n; \frac{1}{2}; \frac{1-x}{2})$ |
| 雅可比多项式 | $P_n^{(\alpha,\beta)}(x) = \binom{n+\alpha}{n}{}_2F_1(-n, n+\alpha+\beta+1; \alpha+1; \frac{1-x}{2})$ |

### 微分方程

$_2F_1$ 满足超几何微分方程：

$$x(1-x)y'' + [c-(a+b+1)x]y' - aby = 0$$

### 解析延拓

超几何函数可以通过**解析延拓**扩展到 $|x| \geq 1$ 的区域，但需要注意割线的选择。具体公式较为复杂，参见相关专著。

## 12.4 伽马函数 $\Gamma(x)$ 和贝塔函数 $B(x,y)$

### 伽马函数

**伽马函数**（Gamma Function）是阶乘函数在实数（及复数）上的推广：

$$\boxed{\Gamma(x) = \int_0^{+\infty} t^{x-1}e^{-t}\,dt}, \quad \text{Re}(x) > 0$$

#### 基本性质

$$\Gamma(n+1) = n! \quad (\text{正整数})$$

$$\Gamma(x+1) = x\,\Gamma(x) \quad (\text{递推关系})$$

$$\Gamma\left(\frac{1}{2}\right) = \sqrt{\pi}$$

$$\Gamma(x)\Gamma(1-x) = \frac{\pi}{\sin(\pi x)} \quad (\text{余元公式})$$

#### 高斯乘积公式（Legendre duplication formula）

$$\Gamma(x)\Gamma\left(x+\frac{1}{2}\right) = \frac{\sqrt{\pi}}{2^{2x-1}}\Gamma(2x)$$

```

### 贝塔函数

**贝塔函数**（Beta Function）定义为：

$$\boxed{B(x,y) = \int_0^1 t^{x-1}(1-t)^{y-1}\,dt}, \quad \text{Re}(x), \text{Re}(y) > 0$$

#### 与伽马函数的关系

$$\boxed{B(x,y) = \frac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)}}$$

#### 性质

$$B(x,y) = B(y,x) \quad (\text{对称性})$$

$$B(x,y) = 2\int_0^{\pi/2}(\sin\theta)^{2x-1}(\cos\theta)^{2y-1}\,d\theta \quad (\text{三角形式})$$

## 12.5 椭圆函数简介

### 起源

椭圆函数起源于椭圆积分。考虑积分：

$$u = \int_0^{\phi} \frac{d\theta}{\sqrt{1 - k^2\sin^2\theta}}$$

这称为**第一类不完全椭圆积分**，记为 $F(\phi, k)$，其中 $k$ 为模数（modulus）。

### 椭圆函数的定义

椭圆函数是椭圆积分的反函数。令 $\text{sn}(u, k)$ 表示 Jacobi 椭圆函数：

$$\phi = \text{am}(u, k) \implies \text{sn}(u, k) = \sin\phi, \quad \text{cn}(u, k) = \cos\phi, \quad \text{dn}(u, k) = \sqrt{1 - k^2\sin^2\phi}$$

### 基本性质

- $\text{sn}(u, k)$ 类似 $\sin(u)$，但是**双周期**函数
- 当 $k = 0$ 时：$\text{sn}(u, 0) = \sin(u)$，退化为三角函数
- 当 $k = 1$ 时：$\text{sn}(u, 1) = \tanh(u)$，退化为双曲函数

### 应用

- 单摆的大角度振动精确解
- 弹性力学中的非线性问题
- 椭圆曲线密码学（数论/密码学）

## 12.6 注意事项和常见错误

1. **伽马函数的定义域**：$\Gamma(x)$ 在 $x = 0, -1, -2, \ldots$（非正整数）处有极点，值趋于无穷。在这些点附近使用时需特别注意。

2. **Pochhammer 符号**：$(a)_k = a(a+1)\cdots(a+k-1)$，注意 $(0)_0 = 1$，但 $(a)_k$ 在 $a$ 为负整数时可能为零。不要将其与阶乘 $a!$ 混淆。

3. **超几何函数的收敛条件**：$_2F_1(a,b;c;x)$ 的级数定义仅在 $|x| < 1$ 内收敛。在 $|x| \geq 1$ 处需使用解析延拓公式。

4. **关联拉盖尔多项式的指标**：$L_n^k(x)$ 中 $n$ 和 $k$ 的含义不要混淆。$n$ 是多项式的次数，$k$ 是关联指标。

5. **椭圆积分的模数约定**：不同的文献对模数 $k$ 和参数 $m = k^2$ 的使用不一致，使用时需注意上下文。

## 12.7 本章小结

- **厄米多项式** $H_n(x)$ 是量子谐振子波函数的核心组成部分，权重函数为高斯函数 $e^{-x^2}$。
- **拉盖尔多项式** $L_n(x)$ 和关联拉盖尔多项式 $L_n^k(x)$ 出现在氢原子径向波函数中。
- **超几何函数** $_2F_1(a,b;c;x)$ 是一个统一框架，许多特殊函数都是它的特例。
- **伽马函数** $\Gamma(x)$ 是阶乘的推广，**贝塔函数** $B(x,y)$ 通过 $\Gamma$ 函数与之关联。
- **椭圆函数**是椭圆积分的反函数，具有双周期性，是三角函数的非线性推广。
