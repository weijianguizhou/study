# 11 - 勒让德多项式

## 章节简介

勒让德多项式（Legendre Polynomial）是在球坐标系下求解偏微分方程时出现的重要特殊函数。当我们在球坐标系中对拉普拉斯方程、亥姆霍兹方程进行分离变量时，极角部分的方程就是勒让德方程，其解为勒让德多项式。本章将介绍勒让德方程的推导、勒让德多项式的定义与性质，并引入广义勒让德多项式和球谐函数。

## 11.1 勒让德方程的推导

### 球坐标下的分离变量

在球坐标系 $(r, \theta, \phi)$ 下，拉普拉斯方程为：

$$\nabla^2 u = \frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial u}{\partial r}\right) + \frac{1}{r^2\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial u}{\partial\theta}\right) + \frac{1}{r^2\sin^2\theta}\frac{\partial^2 u}{\partial\phi^2} = 0$$

令 $u(r,\theta,\phi) = R(r)\Theta(\theta)\Phi(\phi)$，经分离变量后：

- 径向方程：$r^2R'' + 2rR' - \lambda R = 0$（欧拉方程，解为 $r^l$ 和 $r^{-(l+1)}$）
- 方位角方程：$\Phi'' + m^2\Phi = 0$（解为 $e^{\pm im\phi}$）
- 极角方程（勒让德方程）：令 $x = \cos\theta$

$$\frac{d}{dx}\left[(1-x^2)\frac{dP}{dx}\right] + \left[\lambda - \frac{m^2}{1-x^2}\right]P = 0$$

### 标准勒让德方程

当 $m = 0$ 时（轴对称问题），方程简化为**标准勒让德方程**：

$$\boxed{(1-x^2)y'' - 2xy' + n(n+1)y = 0}$$

其中 $\lambda = n(n+1)$，$n$ 为非负整数（物理上要求的有界解条件所决定）。

## 11.2 勒让德多项式 $P_n(x)$ 的定义

### Rodrigues 公式

勒让德多项式最简洁的定义来自 **Rodrigues 公式**：

$$\boxed{P_n(x) = \frac{1}{2^n n!}\frac{d^n}{dx^n}(x^2-1)^n}$$

### 前几个勒让德多项式

$$P_0(x) = 1$$

$$P_1(x) = x$$

$$P_2(x) = \frac{1}{2}(3x^2 - 1)$$

$$P_3(x) = \frac{1}{2}(5x^3 - 3x)$$

$$P_4(x) = \frac{1}{8}(35x^4 - 30x^2 + 3)$$

### 生成函数

勒让德多项式的**生成函数**为：

$$\frac{1}{\sqrt{1 - 2xt + t^2}} = \sum_{n=0}^{\infty} P_n(x)\,t^n, \quad |t| < 1$$

这个公式可以用来推导勒让德多项式的各种性质。

### 图形特征

## 11.3 勒让德多项式的性质

### 递推关系

重要的递推公式：

$$\boxed{(n+1)P_{n+1}(x) = (2n+1)x\,P_n(x) - n\,P_{n-1}(x)}$$

导数递推关系：
$$P_{n+1}'(x) - P_{n-1}'(x) = (2n+1)P_n(x)$$

$$(1-x^2)P_n'(x) = n\,P_{n-1}(x) - nx\,P_n(x)$$

### 正交性

勒让德多项式在 $[-1, 1]$ 上关于权重函数 $w(x) = 1$ 正交：

$$\boxed{\int_{-1}^{1} P_m(x)\,P_n(x)\,dx = \frac{2}{2n+1}\,\delta_{mn}}$$

这是**勒让德级数**展开的理论基础。任意函数 $f(x)$（在 $[-1,1]$ 上满足适当条件）可以展开为：

$$f(x) = \sum_{n=0}^{\infty} c_n P_n(x), \quad c_n = \frac{2n+1}{2}\int_{-1}^{1} f(x)P_n(x)\,dx$$

### 特殊值

$$P_n(1) = 1, \quad P_n(-1) = (-1)^n$$

$$P_n(0) = \begin{cases} 0, & n \text{为奇数} \\ (-1)^{n/2}\frac{(n-1)!!}{n!!}, & n \text{为偶数} \end{cases}$$

其中 $n!!$ 表示双阶乘。

### 渐近公式

当 $n$ 很大时：
$$P_n(\cos\theta) \approx \sqrt{\frac{2}{\pi n\sin\theta}}\cos\left[\left(n+\frac{1}{2}\right)\theta - \frac{\pi}{4}\right], \quad 0 < \theta < \pi$$

## 11.4 广义勒让德多项式 $P_n^m(x)$

### 定义

**关联勒让德函数**（Associated Legendre Function）定义为：

$$\boxed{P_n^m(x) = (-1)^m(1-x^2)^{m/2}\frac{d^m}{dx^m}P_n(x)}, \quad m \geq 0$$

对于负 $m$，有：
$$P_n^{-m}(x) = (-1)^m\frac{(n-m)!}{(n+m)!}P_n^m(x)$$

### 前几个关联勒让德函数

$$P_1^1(x) = -(1-x^2)^{1/2} = -\sin\theta \quad (\text{令} \; x = \cos\theta)$$

$$P_2^1(x) = -3x(1-x^2)^{1/2} = -3\cos\theta\sin\theta$$

$$P_2^2(x) = 3(1-x^2) = 3\sin^2\theta$$

### 正交性

$$\int_{-1}^{1} P_n^m(x)\,P_{n'}^m(x)\,dx = \frac{2}{2n+1}\frac{(n+m)!}{(n-m)!}\,\delta_{nn'}$$

## 11.5 球谐函数 $Y_l^m(\theta, \phi)$

### 定义

**球谐函数**（Spherical Harmonics）是球面上拉普拉斯算子的本征函数，在量子力学、电磁学中有极其重要的地位：

$$\boxed{Y_l^m(\theta, \phi) = N_{lm}\,P_l^m(\cos\theta)\,e^{im\phi}}$$

其中归一化常数为：

$$N_{lm} = \sqrt{\frac{2l+1}{4\pi}\frac{(l-m)!}{(l+m)!}}$$

$(-l \leq m \leq l)$

### 正交性

球谐函数在球面上正交：

$$\int_0^{2\pi}\int_0^{\pi} Y_l^m(\theta,\phi)\,Y_{l'}^{m'*}(\theta,\phi)\,\sin\theta\,d\theta\,d\phi = \delta_{ll'}\delta_{mm'}$$

### 前几个球谐函数

$$Y_0^0 = \frac{1}{2\sqrt{\pi}}$$

$$Y_1^0 = \sqrt{\frac{3}{4\pi}}\cos\theta$$

$$Y_1^{\pm 1} = \mp\sqrt{\frac{3}{8\pi}}\sin\theta\,e^{\pm i\phi}$$

### 应用场景

- 量子力学中氢原子波函数的角度部分
- 地球物理学中地球重力场、磁场的展开
- 计算机图形学中基于球谐函数的光照模型（SH Lighting）

```

         _____

      |    +    |
```

## 11.6 注意事项和常见错误

1. **$P_n(x)$ 的定义域**：$x \in [-1, 1]$。在球坐标中 $x = \cos\theta$，所以自然在此区间。如果需要扩展到 $|x| > 1$，应使用第二类勒让德函数 $Q_n(x)$。

2. **关联勒让德函数的 Condon-Shortley 相位**：定义中的 $(-1)^m$ 因子（或不加）因文献而异，使用时需注意与参考书保持一致。

3. **球谐函数的复共轭**：在内积计算中，$Y_l^{m*} = (-1)^m Y_l^{-m}$，不要忘记取共轭。

4. **正交归一化**：球谐函数是归一化的（系数为1），但关联勒让德函数的正交性包含额外的归一化因子 $\frac{(n+m)!}{(n-m)!}$，不要混淆。

5. **$P_n(-x) = (-1)^n P_n(x)$**：利用此性质可以简化对称区间的积分计算。

## 11.7 本章小结

- 勒让德方程 $(1-x^2)y'' - 2xy' + n(n+1)y = 0$ 来自球坐标系下极角部分的分离变量。
- 勒让德多项式 $P_n(x)$ 可通过 Rodrigues 公式、生成函数或递推关系定义。
- 勒让德多项式在 $[-1,1]$ 上关于常数权重正交，构成完备正交函数系。
- 广义（关联）勒让德多项式 $P_n^m(x)$ 是勒让德多项式的高阶导数与因子的组合。
- 球谐函数 $Y_l^m(\theta,\phi)$ 是球面上的完备正交基，在量子物理中有核心地位。
