# 03-波动方程

> **本章简介**：波动方程是描述波现象（如声波、电磁波、弦振动等）的基本偏微分方程。本章将从一维弦振动问题出发推导波动方程，介绍达朗贝尔公式及其物理意义，讨论三维波动方程，并阐述波的传播、叠加原理和能量守恒。

## 1. 一维波动方程的推导（弦振动）

考虑一根长度为 $L$ 的均匀弹性弦，两端固定，弦在平衡位置附近作微小横向振动。设 $u(x, t)$ 表示弦上位置 $x$ 处在时刻 $t$ 的横向位移。

**假设**：
1. 弦是均匀的，线密度 $\rho$ 为常数。
2. 张力 $T$ 很大且保持不变。
3. 振动幅度很小，弦的斜率很小（$\left|\frac{\partial u}{\partial x}\right| \ll 1$）。
4. 忽略重力和空气阻力。

**推导**：取弦的一小段 $[x, x+\Delta x]$，根据牛顿第二定律，横向运动方程为：
$$
\rho \Delta x \frac{\partial^2 u}{\partial t^2} = T \sin \theta_2 - T \sin \theta_1
$$
其中 $\theta_1$ 和 $\theta_2$ 是弦段两端切线与水平线的夹角。

对于小振幅振动，$\sin \theta \approx \tan \theta = \frac{\partial u}{\partial x}$，因此：
$$
\rho \Delta x \frac{\partial^2 u}{\partial t^2} \approx T \left( \frac{\partial u}{\partial x}(x+\Delta x, t) - \frac{\partial u}{\partial x}(x, t) \right)
$$
两边除以 $\Delta x$ 并令 $\Delta x \to 0$，得到：
$$
\rho \frac{\partial^2 u}{\partial t^2} = T \frac{\partial^2 u}{\partial x^2}
$$
令 $c^2 = T/\rho$，则得到标准的一维波动方程：
$$
\boxed{\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}}
$$
其中 $c$ 是波的传播速度。

**定解条件**：
- **初始条件**：
  - 初始位移：$u(x, 0) = \phi(x)$
  - 初始速度：$\frac{\partial u}{\partial t}(x, 0) = \psi(x)$
- **边界条件**（两端固定）：
  - $u(0, t) = 0$
  - $u(L, t) = 0$

## 2. 达朗贝尔公式（D'Alembert's Formula）

对于无限长弦（$-\infty < x < \infty$）的波动方程初值问题：
$$
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad u(x, 0) = \phi(x), \quad \frac{\partial u}{\partial t}(x, 0) = \psi(x)
$$
其解由**达朗贝尔公式**给出：
$$
\boxed{u(x, t) = \frac{1}{2} [\phi(x+ct) + \phi(x-ct)] + \frac{1}{2c} \int_{x-ct}^{x+ct} \psi(s) \, ds}
$$

**物理解释**：
- 解由两部分组成：$\frac{1}{2} [\phi(x+ct) + \phi(x-ct)]$ 表示以速度 $c$ 向右和向左传播的行波。
- 积分项表示初始速度的影响。
- 波形保持形状不变，以速度 $c$ 传播。

**例**：设 $\phi(x) = e^{-x^2}$，$\psi(x) = 0$，则解为：
$$
u(x, t) = \frac{1}{2} [e^{-(x+ct)^2} + e^{-(x-ct)^2}]
$$
这是两个高斯波包分别向左和右传播。

## 3. 三维波动方程

三维波动方程描述声波、电磁波等在三维空间中的传播：
$$
\boxed{\frac{\partial^2 u}{\partial t^2} = c^2 \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} \right) = c^2 \Delta u}
$$
其中 $\Delta = \nabla^2$ 是拉普拉斯算子。

**Kirchhoff 公式**（三维波动方程初值问题的解）：
对于 $u_{tt} = c^2 \Delta u$，$u|_{t=0} = \phi$，$u_t|_{t=0} = \psi$，解为：
$$
u(x, t) = \frac{1}{4\pi c^2 t} \int_{|y-x|=ct} \psi(y) \, dS_y + \frac{\partial}{\partial t} \left( \frac{1}{4\pi c^2 t} \int_{|y-x|=ct} \phi(y) \, dS_y \right)
$$
**物理意义**：三维波动具有**无后效性**（Huygens 原理）：波在某点 $x$ 的影响只依赖于以 $x$ 为心、半径为 $ct$ 的球面上的初始数据，而不依赖于球内的数据。

## 4. 波的传播和叠加原理

### 4.1 叠加原理（Superposition Principle）
对于线性齐次偏微分方程，如果 $u_1, u_2, \dots, u_n$ 是方程的解，则它们的任意线性组合
$$
u = \sum_{i=1}^n c_i u_i
$$
也是方程的解。

**应用**：利用叠加原理，可以通过分离变量法构造级数解。

### 4.2 行波（Traveling Waves）
形如 $u(x, t) = f(x \pm ct)$ 的解表示以速度 $c$ 向右（负号）或向左（正号）传播的行波。

### 4.3 驻波（Standing Waves）
通过叠加两个相反方向传播的行波可以得到驻波。例如：
$$
u(x, t) = \sin(kx) \cos(\omega t)
$$
其中 $\omega = ck$。

## 5. 能量守恒

波动方程描述的系统具有能量守恒性质。

**动能**：$E_k(t) = \frac{1}{2} \rho \int_0^L \left( \frac{\partial u}{\partial t} \right)^2 dx$

**势能**：$E_p(t) = \frac{1}{2} T \int_0^L \left( \frac{\partial u}{\partial x} \right)^2 dx$

**总能量**：$E(t) = E_k(t) + E_p(t)$

**定理**（能量守恒）：对于满足波动方程和固定端点边界条件的解，总能量 $E(t)$ 是常数，即 $\frac{dE}{dt} = 0$。

**证明思路**：直接计算 $\frac{dE}{dt}$，利用方程和边界条件可得结果为零。

## 7. Python 代码示例：模拟一维弦振动

以下代码使用有限差分法模拟一维弦的振动过程：

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

# 参数设置
L = 1.0          # 弦长
T_total = 2.0    # 总模拟时间
c = 1.0          # 波速
rho = 1.0        # 线密度
nx = 100         # 空间网格点数
nt = 200         # 时间步数
dx = L / (nx - 1)
dt = T_total / nt
r = c * dt / dx  # CFL数，应小于1

print(f"CFL数 r = {r:.3f} (应小于1)")

# 初始条件
x = np.linspace(0, L, nx)
phi = np.sin(np.pi * x)  # 初始位移：正弦波
psi = np.zeros(nx)        # 初始速度：0

# 初始化解
u_prev = phi.copy()       # u(n-1)
u_current = phi + psi * dt + 0.5 * r**2 * (np.roll(phi, -1) - 2*phi + np.roll(phi, 1))  # u(n)

# 应用边界条件
u_current[0] = 0.0
u_current[-1] = 0.0
u_prev[0] = 0.0
u_prev[-1] = 0.0

# 存储所有时间步用于动画
u_all = [u_current.copy()]

# 时间推进
for n in range(1, nt):
    u_next = np.zeros(nx)
    
    # 内部点：有限差分格式
    for i in range(1, nx - 1):
        u_next[i] = (2*u_current[i] - u_prev[i] + 
                     r**2 * (u_current[i+1] - 2*u_current[i] + u_current[i-1]))
    
    # 边界条件
    u_next[0] = 0.0
    u_next[-1] = 0.0
    
    # 更新
    u_prev = u_current.copy()
    u_current = u_next.copy()
    u_all.append(u_current.copy())

# 创建动画
fig, ax = plt.subplots(figsize=(10, 6))
line, = ax.plot(x, u_all[0], 'b-', linewidth=2)
ax.set_xlim(0, L)
ax.set_ylim(-1.2, 1.2)
ax.set_xlabel('位置 x')
ax.set_ylabel('位移 u(x, t)')
ax.set_title('一维弦振动模拟 (有限差分法)')
ax.grid(True, alpha=0.3)

def update(frame):
    line.set_ydata(u_all[frame])
    ax.set_title(f'一维弦振动模拟 (t = {frame * dt:.3f}s)')
    return line,

ani = FuncAnimation(fig, update, frames=len(u_all), interval=50, blit=True)
plt.show()

# 也可以绘制几个时刻的静态图
plt.figure(figsize=(12, 8))
time_steps = [0, nt//4, nt//2, 3*nt//4, nt-1]
for i, t in enumerate(time_steps):
    plt.subplot(2, 3, i+1)
    plt.plot(x, u_all[t], 'b-', linewidth=2)
    plt.title(f't = {t*dt:.3f}s')
    plt.xlabel('x')
    plt.ylabel('u(x, t)')
    plt.grid(True, alpha=0.3)
    plt.ylim(-1.2, 1.2)

plt.subplot(2, 3, 6)
plt.plot(x, phi, 'r--', label='初始时刻', linewidth=2)
plt.plot(x, u_all[-1], 'b-', label=f'最终时刻 (t={T_total}s)', linewidth=2)
plt.legend()
plt.title('初始与最终时刻对比')
plt.xlabel('x')
plt.ylabel('u(x, t)')
plt.grid(True, alpha=0.3)
plt.ylim(-1.2, 1.2)

plt.tight_layout()
plt.show()
```

**代码说明**：
1. 使用有限差分法（中心差分）离散波动方程。
2. 采用显式格式，要求 CFL 条件 $r = c\Delta t/\Delta x < 1$ 以保证稳定性。
3. 模拟了初始位移为正弦波的弦振动过程。
4. 输出显示不同时刻弦的形状。

## 8. 注意事项和常见错误

### 注意事项
1. **CFL 条件**：使用有限差分法求解波动方程时，必须满足 $c\Delta t/\Delta x \le 1$，否则数值解不稳定。
2. **边界条件处理**：正确施加边界条件对解的准确性至关重要。
3. **能量检验**：可以计算总能量随时间的变化来验证数值解的准确性（应近似守恒）。
4. **初始条件相容性**：初始条件应满足边界条件（相容性条件），否则解在初始时刻可能不光滑。

### 常见错误
1. **数值不稳定**：时间步长太大导致 CFL 条件不满足，解发散。
2. **反射错误**：边界条件处理不当导致非物理反射。
3. **混淆公式**：在有限域问题中错误地使用无限域的达朗贝尔公式。
4. **忽略物理意义**：得到数学解后未检验其物理合理性。

## 9. 本章小结

- **一维波动方程** $\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$ 描述弦振动等物理现象。
- **达朗贝尔公式**给出了无限域上波动方程初值问题的解，揭示了波的传播特性。
- **三维波动方程**满足 **Huygens 原理**（无后效性）。
- **叠加原理**是线性波动方程的重要性质，可用于构造复杂解。
- **能量守恒**是波动方程的重要性质，可用于验证解的正确性。
