# 08 格林函数法

## 简介

格林函数法（Green's Function Method）是求解线性偏微分方程边值问题和初值问题的一种统一而优雅的方法。格林函数的本质是**单位点源产生的响应**——即在某一点施加一个单位强度的脉冲源，求解由此产生的场。一旦获得了格林函数，任意源项下的解都可以通过积分表示出来。

> [!tip] 核心思想
> 线性方程 $Lu = f$ 的解可以写成 $u(x) = \int G(x; \xi) f(\xi) d\xi$，其中 $G$ 就是格林函数。

---

## 核心概念

### 1. 格林函数的定义

对于线性微分算子 $L$，格林函数 $G(x; \xi)$ 定义为满足以下方程的函数：

$$L_x G(x; \xi) = \delta(x - \xi)$$

其中 $\delta(x - \xi)$ 是 Dirac $\delta$ 函数（单位脉冲函数）。

**物理意义**：$G(x; \xi)$ 表示在点 $\xi$ 处放置单位强度的源时，在点 $x$ 处产生的响应。

### 2. 格林函数的性质

- **对称性**：对于自伴算子（self-adjoint operator），格林函数满足互易关系 $G(x; \xi) = G(\xi; x)$
- **奇异性**：格林函数在 $x = \xi$ 处有奇异性（与 $\delta$ 函数的奇异性对应）
- **边界条件**：格林函数需要满足与原问题相同的齐次边界条件

### 3. 利用格林函数表示解

若已知格林函数 $G(x; \xi)$，则非齐次方程 $Lu = f$ 满足齐次边界条件的解为：

$$u(x) = \int_\Omega G(x; \xi) f(\xi) \, d\xi$$

对于初值问题，解的表示形式更复杂，需要包含初始条件的贡献。

## 泊松方程的格林函数

### 问题描述

三维泊松方程：

$$\nabla^2 u = -f(\mathbf{r}), \quad \mathbf{r} \in \Omega$$

边界条件：$u|_{\partial\Omega} = 0$

### 格林函数方程

$$\nabla^2 G(\mathbf{r}; \mathbf{r}') = -\delta(\mathbf{r} - \mathbf{r}')$$

### 自由空间的基本解

在无界空间中，三维泊松方程的基本解（自由空间格林函数）为：

$$G_0(\mathbf{r}; \mathbf{r}') = \frac{1}{4\pi |\mathbf{r} - \mathbf{r}'|}$$

验证：$\nabla^2 \frac{1}{|\mathbf{r}|} = -4\pi \delta(\mathbf{r})$

对于二维问题：$G_0(\mathbf{r}; \mathbf{r}') = -\frac{1}{2\pi} \ln|\mathbf{r} - \mathbf{r}'|$

### 第一积分公式（格林第一恒等式）

$$\int_\Omega (u \nabla^2 v - v \nabla^2 u) \, dV = \oint_{\partial\Omega} \left(u \frac{\partial v}{\partial n} - v \frac{\partial u}{\partial n}\right) dS$$

利用此公式可以证明解的积分表示的正确性。

---

## 热传导方程的格林函数

### 问题描述

$$\frac{\partial u}{\partial t} = k \nabla^2 u + f(\mathbf{r}, t)$$

$u(\mathbf{r}, 0) = g(\mathbf{r})$

### 格林函数定义

热传导方程的格林函数（热核）$G(\mathbf{r}, t; \mathbf{r}', t')$ 满足：

$$\frac{\partial G}{\partial t} = k \nabla^2 G + \delta(\mathbf{r} - \mathbf{r}')\delta(t - t')$$

且当 $t < t'$ 时 $G = 0$（因果性条件）。

### 自由空间热核

一维：$$G(x, t; \xi, \tau) = \frac{1}{\sqrt{4\pi k(t-\tau)}} \exp\left(-\frac{(x-\xi)^2}{4k(t-\tau)}\right)$$

三维：$$G(\mathbf{r}, t; \mathbf{r}', \tau) = \frac{1}{[4\pi k(t-\tau)]^{3/2}} \exp\left(-\frac{|\mathbf{r}-\mathbf{r}'|^2}{4k(t-\tau)}\right)$$

### 解的积分表示

$$u(\mathbf{r}, t) = \int_\Omega G(\mathbf{r}, t; \mathbf{r}', 0) g(\mathbf{r}') \, d\mathbf{r}' + \int_0^t \int_\Omega G(\mathbf{r}, t; \mathbf{r}', \tau) f(\mathbf{r}', \tau) \, d\mathbf{r}' \, d\tau$$

---

## 波动方程的格林函数

### 问题描述（三维）

$$\frac{\partial^2 u}{\partial t^2} = a^2 \nabla^2 u + f(\mathbf{r}, t)$$

### 波动方程格林函数的特殊性

波动方程的格林函数为：

$$G(\mathbf{r}, t; \mathbf{r}', t') = \frac{\delta(t - t' - |\mathbf{r}-\mathbf{r}'|/a)}{4\pi |\mathbf{r}-\mathbf{r}'|}$$

> [!important] 物理意义
> 波动方程的格林函数具有**推迟性**（retarded）：在 $\mathbf{r}'$ 处 $t'$ 时刻的源，只在满足 $|\mathbf{r} - \mathbf{r}'| = a(t - t')$ 的时刻 $t$ 才在 $\mathbf{r}$ 处产生响应。这就是**推迟势**的概念。

### 推迟势公式

三维波动方程的解（Duhamel 原理）：

$$u(\mathbf{r}, t) = \frac{1}{4\pi a^2} \iiint \frac{f(\mathbf{r}', t - |\mathbf{r}-\mathbf{r}'|/a)}{|\mathbf{r}-\mathbf{r}'|} \, dV'$$

> [!note] 维数效应
> - 三维波动方程：解依赖于**推迟势**（只依赖球面上的值）
> - 二维波动方程：解依赖于圆盘内的积分（Huygens 原理不严格成立）
> - 一维波动方程：解依赖于区间内的积分

## 格林函数的构造方法

### 方法1：镜像法（Method of Images）

**适用场景**：某些具有简单几何边界的区域

**基本思想**：在区域外部放置适当强度的"像源"，使得边界条件得到满足。

#### 例：半平面的泊松方程

问题：$\nabla^2 G = -\delta(x - \xi, y - \eta)$，$y > 0$，$G|_{y=0} = 0$

构造：在 $(x, \xi, -\eta)$ 处放置负像源

$$G = \frac{1}{4\pi}\left(\frac{1}{\sqrt{(x-\xi)^2 + (y-\eta)^2}} - \frac{1}{\sqrt{(x-\xi)^2 + (y+\eta)^2}}\right)$$

验证边界条件：当 $y = 0$ 时，两项相等相减为零。

### 方法2：本征函数展开法

**适用场景**：具有规则几何形状的区域

**基本思想**：利用施图姆-刘维尔特征函数系展开格林函数。

#### 步骤

1. 求解特征值问题 $L\phi_n = \lambda_n \phi_n$，得到特征值 $\lambda_n$ 和特征函数 $\phi_n(x)$
2. 格林函数展开为：

$$G(x; \xi) = \sum_{n=1}^{\infty} \frac{\phi_n(x) \phi_n(\xi)}{\lambda_n}$$

> [!warning] 注意
> 此级数在 $x = \xi$ 处不收敛（因为格林函数在那里有奇异性），但在分布意义下成立。

### 方法3：格林函数的级数构造

对于一般区域，可以用本征函数展开：

$$G(x; \xi) = \sum_{n} \frac{u_n(x) u_n(\xi)}{-\lambda_n}$$

其中 $u_n$ 是满足边界条件的正交归一化本征函数。

## Python代码示例

以下代码演示用格林函数法（本征函数展开）求解一维泊松方程：

```python
import numpy as np
import matplotlib.pyplot as plt

def green_function_1d_poisson(n_terms=100):
    """
    一维泊松方程 -u'' = f(x), u(0)=u(1)=0 的格林函数
    
    特征函数: φ_n(x) = sqrt(2) * sin(nπx)
    特征值: λ_n = (nπ)²
    
    格林函数: G(x; ξ) = Σ φ_n(x)*φ_n(ξ) / λ_n
    """
    L = 1.0  # 区间长度
    
    # 在 x 和 ξ 网格上计算格林函数
    Nx = 200
    x = np.linspace(0, L, Nx)
    xi = np.linspace(0, L, Nx)
    X, XI = np.meshgrid(x, xi, indexing='ij')
    
    G = np.zeros_like(X)
    for n in range(1, n_terms + 1):
        lambda_n = (n * np.pi / L) ** 2
        phi_x = np.sqrt(2) * np.sin(n * np.pi * X / L)
        phi_xi = np.sqrt(2) * np.sin(n * np.pi * XI / L)
        G += phi_x * phi_xi / lambda_n
    
    return x, G

def solve_poisson_via_green_function(x, G, f_func):
    """
    利用格林函数求解 -u'' = f(x) 的解
    u(x) = ∫ G(x; ξ) f(ξ) dξ
    """
    L = x[-1]
    dx = x[1] - x[0]
    N = len(x)
    u = np.zeros(N)
    
    for i in range(N):
        # 数值积分 (梯形法则)
        integrand = G[i, :] * f_func(x)
        u[i] = np.trapz(integrand, x)
    
    return u

# ---- 主程序 ----

# 定义源项 f(x) = π² sin(πx) （精确解应为 u = sin(πx)）
f = lambda x: np.pi**2 * np.sin(np.pi * x)

# 计算格林函数
n_terms = 50
x, G = green_function_1d_poisson(n_terms)

# 求解
u_numerical = solve_poisson_via_green_function(x, G, f)
u_exact = np.sin(np.pi * x)

# 可视化
fig, axes = plt.subplots(1, 3, figsize=(16, 5))

# 左图：格林函数（截面图）
ax1 = axes[0]
xi_probe = [0.25, 0.5, 0.75]
for xi_val in xi_probe:
    idx = np.argmin(np.abs(x - xi_val))
    ax1.plot(x, G[:, idx], label=f'ξ = {xi_val}', linewidth=2)
ax1.set_xlabel('x', fontsize=12)
ax1.set_ylabel('G(x; ξ)', fontsize=12)
ax1.set_title('格林函数 (不同 ξ 值)', fontsize=13)
ax1.legend()
ax1.grid(True, alpha=0.3)

# 中图：格林函数曲面图
ax2 = axes[1]
X_mesh, XI_mesh = np.meshgrid(x, x, indexing='ij')
cf = ax2.contourf(X_mesh, XI_mesh, G, levels=30, cmap='viridis')
ax2.set_xlabel('x', fontsize=12)
ax2.set_ylabel('ξ', fontsize=12)
ax2.set_title('格林函数 G(x; ξ) 曲面', fontsize=13)
plt.colorbar(cf, ax=ax2, shrink=0.8)

# 右图：解的比较
ax3 = axes[2]
ax3.plot(x, u_numerical, 'b-', linewidth=2, label='格林函数法 (数值)')
ax3.plot(x, u_exact, 'r--', linewidth=2, label='精确解 sin(πx)')
ax3.fill_between(x, u_numerical, u_exact, alpha=0.2, color='gray')
ax3.set_xlabel('x', fontsize=12)
ax3.set_ylabel('u(x)', fontsize=12)
ax3.set_title('解的比较', fontsize=13)
ax3.legend(fontsize=11)
ax3.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('green_function_poisson.png', dpi=150)
plt.show()

# 输出最大误差
max_error = np.max(np.abs(u_numerical - u_exact))
print(f"最大误差: {max_error:.6e}")
print(f"使用的展开项数: {n_terms}")
```

## 注意事项和常见错误

> [!caution] 常见错误
> 1. **混淆格林函数的类型**：
>    - **推迟格林函数**（retarded）：用于波动方程，因果性要求 $t > t'$
>    - **超前格林函数**（advanced）：数学上存在但物理上不常用
>    - **稳态格林函数**：用于不含时间的方程（如泊松方程）
>
> 2. **边界条件匹配**：构造的格林函数必须满足**齐次**边界条件。若原问题边界条件非齐次，需先处理。
>
> 3. **奇异性处理**：格林函数在 $x = \xi$ 处有奇异性，数值计算时需要特殊处理（如奇异性减除技术）。
>
> 4. **收敛性问题**：本征函数展开法得到的级数可能收敛很慢，需要足够多的项数。

> [!tip] 实用建议
> - 镜像法仅适用于几何形状简单的区域（半空间、圆、球等）
> - 对于复杂几何区域，本征函数展开法或数值方法更为实际
> - 格林函数法与 [[07-积分变换法|积分变换法]] 密切相关：基本解就是自由空间的格林函数
> - 对于自伴算子，格林函数的对称性 $G(x;\xi) = G(\xi;x)$ 可用于简化计算

## 本章小结

- 格林函数是单位点源的响应，是线性算子的"逆"的积分核
- 泊松方程的基本解：三维为 $\frac{1}{4\pi r}$，二维为 $-\frac{1}{2\pi}\ln r$
- 热传导方程的格林函数是热核（高斯函数），具有扩散特性
- 波动方程的格林函数具有推迟性，反映了因果律和有限传播速度
- 构造格林函数的三大方法：镜像法、本征函数展开法、一般级数法
- 格林函数法将求解偏微分方程的问题转化为求解格林函数的问题

## 练习题

1. **基础题**：验证三维自由空间格林函数 $G = \frac{1}{4\pi r}$ 满足 $\nabla^2 G = -\delta(\mathbf{r})$。

2. **镜像法**：利用镜像法求解球域 $|\mathbf{r}| < R$ 上的 Dirichlet 问题的格林函数。

3. **本征函数展开**：用本征函数展开法求解一维波动方程 $u_{tt} = u_{xx}$，$0 < x < \pi$ 的格林函数。

4. **思考题**：解释为什么波动方程的格林函数具有推迟性（retarded），而热传导方程的格林函数不具有波动特征。

5. **编程题**：用格林函数法求解二维泊松方程 $\nabla^2 u = -\sin(\pi x)\sin(\pi y)$，$0 < x, y < 1$，$u|_{\partial\Omega} = 0$。
