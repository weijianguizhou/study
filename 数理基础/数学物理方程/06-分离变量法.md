# 06 分离变量法

## 简介

分离变量法（Method of Separation of Variables）是求解偏微分方程最基本、最重要的方法之一。其核心思想是将多变量函数表示为单变量函数的乘积，从而将偏微分方程转化为若干个常微分方程分别求解。该方法适用于具有齐次边界条件的线性偏微分方程。

> [!tip] 关键前提
> 分离变量法要求方程和边界条件都是**齐次的**。若边界条件非齐次，通常需要先通过函数替换将其齐次化。

---

## 核心概念

### 1. 分离变量的基本思想

设未知函数 $u(x, t)$ 可以写成：

$$u(x, t) = X(x) \cdot T(t)$$

其中 $X(x)$ 仅是 $x$ 的函数，$T(t)$ 仅是 $t$ 的函数。将此形式代入偏微分方程后，可以将方程拆分为只含一个自变量的常微分方程。

### 2. 分离变量法的一般步骤

1. **假设解的形式**：令 $u(x, t) = X(x) \cdot T(t)$
2. **代入方程**：将乘积形式代入原偏微分方程
3. **分离变量**：将等式两边整理，使得一端只含 $x$，另一端只含 $t$
4. **令两端等于常数**：由于等式对所有 $x$ 和 $t$ 成立，两端必须等于同一常数（分离常数）
5. **求解常微分方程**：分别求解得到的常微分方程
6. **利用边界条件**：确定特征值和特征函数
7. **叠加原理**：将所有特解线性组合得到通解
8. **利用初始条件**：确定展开系数

## 施图姆-刘维尔问题

### 定义

施图姆-刘维尔（Sturm-Liouville）问题是一类二阶常微分方程的特征值问题，标准形式为：

$$\frac{d}{dx}\left[p(x)\frac{dy}{dx}\right] + q(x)y + \lambda w(x) y = 0$$

其中 $p(x) > 0$，$w(x) > 0$ 为权函数，$\lambda$ 为特征值。

### 重要定理：施图姆-刘维尔定理

> [!important] 定理
> 对于正则施图姆-刘维尔问题：
> 1. 特征值 $\lambda_1, \lambda_2, \lambda_3, \ldots$ 全为实数，且可以排列为 $\lambda_1 < \lambda_2 < \lambda_3 < \cdots$
> 2. 对应于不同特征值的特征函数关于权函数 $w(x)$ 正交：
> $$\int_a^b w(x) \phi_m(x) \phi_n(x) \, dx = 0, \quad m \neq n$$
> 3. 特征函数系 $\{\phi_n(x)\}$ 构成完备的正交函数系

## 一维波动方程的分离变量

### 问题描述

考虑两端固定的弦的自由振动：

$$\frac{\partial^2 u}{\partial t^2} = a^2 \frac{\partial^2 u}{\partial x^2}, \quad 0 < x < L, \; t > 0$$

边界条件：

$$u(0, t) = 0, \quad u(L, t) = 0$$

初始条件：

$$u(x, 0) = \varphi(x), \quad \frac{\partial u}{\partial t}(x, 0) = \psi(x)$$

### 求解过程

**步骤1**：令 $u(x, t) = X(x) \cdot T(t)$，代入方程：

$$X(x) T''(t) = a^2 X''(x) T(t)$$

**步骤2**：分离变量：

$$\frac{T''(t)}{a^2 T(t)} = \frac{X''(x)}{X(x)} = -\lambda$$

**步骤3**：得到两个常微分方程：

$$X'' + \lambda X = 0, \quad X(0) = 0, \; X(L) = 0$$

$$T'' + \lambda a^2 T = 0$$

**步骤4**：求解特征值问题：

$$\lambda_n = \left(\frac{n\pi}{L}\right)^2, \quad X_n(x) = \sin\frac{n\pi x}{L}, \quad n = 1, 2, 3, \ldots$$

**步骤5**：叠加得到通解：

$$u(x, t) = \sum_{n=1}^{\infty} \left(A_n \cos\frac{n\pi a t}{L} + B_n \sin\frac{n\pi a t}{L}\right) \sin\frac{n\pi x}{L}$$

## 一维热传导方程的分离变量

### 问题描述

$$\frac{\partial u}{\partial t} = k \frac{\partial^2 u}{\partial x^2}, \quad 0 < x < L, \; t > 0$$

边界条件：$u(0, t) = 0, \quad u(L, t) = 0$

初始条件：$u(x, 0) = \varphi(x)$

### 求解结果

$$u(x, t) = \sum_{n=1}^{\infty} B_n e^{-k\left(\frac{n\pi}{L}\right)^2 t} \sin\frac{n\pi x}{L}$$

其中：

$$B_n = \frac{2}{L} \int_0^L \varphi(x) \sin\frac{n\pi x}{L} \, dx$$

> [!warning] 注意
> 热传导方程的解随时间指数衰减，最终趋于零，这反映了热量的耗散特性。而波动方程的解保持振荡，不随时间衰减。

## 矩形域上的分离变量

对于矩形域 $0 < x < a$，$0 < y < b$ 上的拉普拉斯方程：

$$\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0$$

令 $u(x, y) = X(x) \cdot Y(y)$，可分离为：

$$\frac{X''}{X} = -\frac{Y''}{Y} = -\lambda$$

求解后得到：

$$u(x, y) = \sum_{n=1}^{\infty} \left(A_n \cosh\frac{n\pi y}{a} + B_n \sinh\frac{n\pi y}{a}\right) \sin\frac{n\pi x}{a}$$

---

## 圆域上的分离变量

### 极坐标下的分离

在极坐标 $(r, \theta)$ 下，拉普拉斯方程为：

$$\frac{\partial^2 u}{\partial r^2} + \frac{1}{r}\frac{\partial u}{\partial r} + \frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2} = 0$$

令 $u(r, \theta) = R(r) \cdot \Theta(\theta)$，分离后得到：

$$r^2 R'' + r R' - \lambda R = 0 \quad \text{(欧拉方程)}$$

$$\Theta'' + \lambda \Theta = 0 \quad \text{(周期性条件)}$$

### 解的形式

周期性要求 $\lambda = n^2$（$n = 0, 1, 2, \ldots$），解为：

$$u(r, \theta) = \frac{a_0}{2} + \sum_{n=1}^{\infty} r^n \left(a_n \cos n\theta + b_n \sin n\theta\right)$$

这本质上就是傅里叶级数在极坐标下的表现形式。

## Python代码示例

以下代码演示如何用分离变量法求解一维热传导方程，并可视化结果：

```python
import numpy as np
import matplotlib.pyplot as plt

def heat_equation_separation_of_variables(L, k, T_max, n_terms, phi_func, x_points=100, t_points=200):
    """
    用分离变量法求解一维热传导方程：
        du/dt = k * d²u/dx²
        u(0,t) = u(L,t) = 0
        u(x,0) = phi(x)
    
    参数:
        L       : 杆的长度
        k       : 热扩散系数
        T_max   : 最大时间
        n_terms : 傅里叶级数项数
        phi_func: 初始温度分布函数
        x_points: 空间网格点数
        t_points: 时间网格点数
    返回:
        x, t, u : 坐标数组和解矩阵
    """
    x = np.linspace(0, L, x_points)
    t = np.linspace(0, T_max, t_points)
    X, T = np.meshgrid(x, t)
    U = np.zeros_like(X)
    
    # 计算傅里叶系数 B_n
    for n in range(1, n_terms + 1):
        # 数值积分计算 B_n
        integrand = lambda xi: phi_func(xi) * np.sin(n * np.pi * xi / L)
        xi = np.linspace(0, L, 500)
        B_n = (2.0 / L) * np.trapz(integrand(xi), xi)
        
        # 累加第 n 项
        U += B_n * np.exp(-k * (n * np.pi / L)**2 * T) * np.sin(n * np.pi * X / L)
    
    return x, t, U

# 定义初始条件：u(x, 0) = sin(πx/L)
L = 1.0
phi = lambda x: np.sin(np.pi * x / L)

# 求解
x, t, u = heat_equation_separation_of_variables(
    L=L, k=0.01, T_max=2.0, n_terms=5, phi_func=phi
)

# 可视化
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 左图：三维曲面图
ax1 = axes[0]
cf = ax1.contourf(x, t, u, levels=50, cmap='hot')
ax1.set_xlabel('位置 x')
ax1.set_ylabel('时间 t')
ax1.set_title('热传导方程解 u(x, t)')
plt.colorbar(cf, ax=ax1, label='温度')

# 右图：不同时刻的温度分布
ax2 = axes[1]
snapshots = [0, 0.1, 0.5, 1.0, 2.0]
for t_val in snapshots:
    idx = np.argmin(np.abs(t - t_val))
    ax2.plot(x, u[idx, :], label=f't = {t_val}')
ax2.set_xlabel('位置 x')
ax2.set_ylabel('温度 u')
ax2.set_title('不同时刻的温度分布')
ax2.legend()
ax2.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('heat_equation_solution.png', dpi=150)
plt.show()
```

## 注意事项和常见错误

> [!caution] 常见错误
> 1. **忘记验证方程和边界条件的齐次性**：分离变量法要求方程和边界条件都为齐次。若边界条件非齐次，必须先做函数替换使其齐次化。
> 2. **分离常数符号选择错误**：对于不同的方程和边界条件，分离常数 $\lambda$ 的符号可能为正、负或零。需要根据物理意义和边界条件逐一讨论。
> 3. **忽略周期性边界条件**：在极坐标问题中，$\theta$ 方向的解必须满足 $2\pi$ 周期性。
> 4. **收敛性问题**：截断项数不足会导致解不精确，特别是在初始条件有间断点时（Gibbs 现象）。

> [!tip] 实用建议
> - 矩形域问题通常使用直角坐标，圆形域使用极坐标，球域使用球坐标
> - 傅里叶系数的计算可利用正交性公式，避免逐项积分
> - 对于非齐次边界条件，先令 $u = v + w$，其中 $w$ 满足非齐次边界条件，$v$ 满足齐次边界条件

## 本章小结

- 分离变量法是将偏微分方程化为常微分方程组求解的基本方法
- 施图姆-刘维尔理论为分离变量法提供了数学基础，保证了特征函数的正交性和完备性
- 波动方程的解是振荡的，热传导方程的解是衰减的
- 坐标系的选择至关重要：矩形域用直角坐标，圆域用极坐标
- 叠加原理允许将无穷多个特解线性组合得到通解

## 练习题

1. **基础题**：求解热传导方程 $u_t = u_{xx}$，$0 < x < \pi$，$u(0,t) = u(\pi, t) = 0$，$u(x, 0) = x(\pi - x)$。

2. **进阶题**：求解矩形域上的拉普拉斯方程 $u_{xx} + u_{yy} = 0$，$0 < x < \pi$，$0 < y < 1$，边界条件为 $u(0, y) = u(\pi, y) = 0$，$u(x, 0) = 0$，$u(x, 1) = \sin x$。

3. **思考题**：为什么分离变量法要求边界条件是齐次的？如果边界条件非齐次，应该如何处理？

4. **编程题**：编写Python程序，用分离变量法求解两端绝热的杆的热传导问题，即边界条件改为 $u_x(0, t) = u_x(L, t) = 0$。
