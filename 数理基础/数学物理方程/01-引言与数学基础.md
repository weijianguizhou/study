## 课程简介

数学物理方程是研究物理现象中出现的偏微分方程及其求解方法的学科。它连接了数学理论与物理应用，是理论物理、应用数学、工程科学等领域的重要基础。

**核心内容：**
- 三大典型偏微分方程（波动、热传导、拉普拉斯）
- 主要求解方法（分离变量、积分变换、格林函数、变分法）
- 特殊函数理论（贝塞尔函数、勒让德多项式）

---

## 数学物理方程的研究对象

### 三大典型方程

| 类型 | 方程 | 物理意义 |
|------|------|----------|
| **双曲型** | $\frac{\partial^2 u}{\partial t^2} = a^2 \nabla^2 u$ | 波动现象（振动、声波、电磁波） |
| **抛物型** | $\frac{\partial u}{\partial t} = k \nabla^2 u$ | 扩散过程（热传导、物质扩散） |
| **椭圆型** | $\nabla^2 u = 0$ | 平衡状态（稳态温度、静电场） |

### 方程的分类意义

不同类型方程的解具有不同的性质：
- **双曲型**：解具有有限传播速度，存在特征线
- **抛物型**：解具有无穷传播速度，存在极值原理
- **椭圆型**：解具有无穷可微性，存在最大值原理

## 求解方法概述

### 主要方法

1. **分离变量法**
   - 基本思想：将偏微分方程转化为常微分方程
   - 适用条件：规则区域、齐次边界条件
   - 数学基础：傅里叶级数

2. **积分变换法**
   - 傅里叶变换：适用于无限区域
   - 拉普拉斯变换：适用于初值问题
   - 优点：将微分运算转化为代数运算

3. **格林函数法**
   - 基本思想：利用点源响应构造一般解
   - 物理意义：格林函数是点源的响应函数
   - 优点：适用于非齐次方程

4. **变分法**
   - 基本思想：将微分方程问题转化为泛函极值问题
   - 优点：适合数值求解
   - 应用：有限元法的理论基础

## 数学基础回顾

### 向量分析

#### 梯度、散度、旋度

设 $u$ 为标量场，$\mathbf{F} = (F_1, F_2, F_3)$ 为向量场：

**梯度（Gradient）：**
$$\nabla u = \left( \frac{\partial u}{\partial x}, \frac{\partial u}{\partial y}, \frac{\partial u}{\partial z} \right)$$

**散度（Divergence）：**
$$\nabla \cdot \mathbf{F} = \frac{\partial F_1}{\partial x} + \frac{\partial F_2}{\partial y} + \frac{\partial F_3}{\partial z}$$

**旋度（Curl）：**
$$\nabla \times \mathbf{F} = \begin{vmatrix}
\mathbf{i} & \mathbf{j} & \mathbf{k} \\
\frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\
F_1 & F_2 & F_3
\end{vmatrix}$$

#### 基本性质

- $\nabla \times (\nabla u) = \mathbf{0}$（梯度的旋度为零）
- $\nabla \cdot (\nabla \times \mathbf{F}) = 0$（旋度的散度为零）
- $\nabla^2 u = \nabla \cdot (\nabla u)$（拉普拉斯算子）

### 积分定理

#### 高斯散度定理

$$\iiint_{\Omega} \nabla \cdot \mathbf{F} \, dV = \oiint_{\partial\Omega} \mathbf{F} \cdot d\mathbf{S}$$

**物理意义：** 体积内源的总强度等于通过封闭曲面的通量。

#### 格林第一公式

$$\iiint_{\Omega} (u \nabla^2 v + \nabla u \cdot \nabla v) \, dV = \oiint_{\partial\Omega} u \frac{\partial v}{\partial n} \, dS$$

### 傅里叶级数

#### 定义

设 $f(x)$ 在 $[-L, L]$ 上满足狄利克雷条件，则：

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos\frac{n\pi x}{L} + b_n \sin\frac{n\pi x}{L} \right)$$

其中：
- $a_n = \frac{1}{L} \int_{-L}^{L} f(x) \cos\frac{n\pi x}{L} \, dx$
- $b_n = \frac{1}{L} \int_{-L}^{L} f(x) \sin\frac{n\pi x}{L} \, dx$

#### 收敛性

傅里叶级数在以下点收敛：
- 连续点：收敛于 $f(x)$
- 间断点：收敛于 $\frac{f(x^+) + f(x^-)}{2}$

## 物理背景

### 弦振动问题

一根长度为 $L$ 的弹性弦，其横向振动满足波动方程：

$$\frac{\partial^2 u}{\partial t^2} = a^2 \frac{\partial^2 u}{\partial x^2}$$

其中 $a = \sqrt{T/\rho}$，$T$ 是张力，$\rho$ 是线密度。

**边界条件：**
- 固定端：$u(0,t) = u(L,t) = 0$
- 自由端：$\frac{\partial u}{\partial x}(0,t) = \frac{\partial u}{\partial x}(L,t) = 0$

### 热传导问题

一根均匀细杆的热传导，温度分布满足：

$$\frac{\partial u}{\partial t} = k \frac{\partial^2 u}{\partial x^2}$$

其中 $k = K/(\rho c)$ 是热扩散系数。

**初始条件：** $u(x,0) = f(x)$

### 静电场问题

真空中静电场的电势满足泊松方程：

$$\nabla^2 \varphi = -\frac{\rho}{\varepsilon_0}$$

其中 $\rho$ 是电荷密度，$\varepsilon_0$ 是真空介电常数。

在无电荷区域（$\rho = 0$），退化为拉普拉斯方程：

$$\nabla^2 \varphi = 0$$

## Python 示例：傅里叶级数近似

```python
import numpy as np
import matplotlib.pyplot as plt

def fourier_series(x, n_terms):
    """计算傅里叶级数近似"""
    result = 0
    for n in range(1, n_terms + 1):
        result += ((-1)**(n+1)) * np.sin(n * x) / n
    return result

# 生成数据
x = np.linspace(-np.pi, np.pi, 1000)
f_true = x  # 目标函数

# 绘图
plt.figure(figsize=(10, 6))
plt.plot(x, f_true, 'k-', label='真实函数 $f(x)=x$', linewidth=2)

for n_terms in [1, 3, 5, 10]:
    f_approx = fourier_series(x, n_terms)
    plt.plot(x, f_approx, label=f'{n_terms} 项近似')

plt.xlabel('$x$')
plt.ylabel('$f(x)$')
plt.title('傅里叶级数近似')
plt.legend()
plt.grid(True)
plt.show()
```

**输出说明：**
- 随着项数增加，傅里叶级数逐渐逼近真实函数
- 在间断点附近会出现吉布斯现象（过冲）
