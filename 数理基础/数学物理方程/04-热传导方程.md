# 04-热传导方程

> **本章简介**：热传导方程是描述热量扩散、物质扩散等物理过程的基本偏微分方程。本章将从傅里叶热传导定律出发推导一维热传导方程，介绍极值原理、热核函数（基本解），并讨论解的唯一性和稳定性。

## 1. 热传导定律（傅里叶定律）

**傅里叶热传导定律**（Fourier's Law of Heat Conduction）指出：热流密度（单位时间通过单位面积的热量）与温度梯度成正比，方向相反。

数学表达式：
$$
\mathbf{q} = -k \nabla T
$$
其中：
- $\mathbf{q}$：热流密度向量（单位：$\text{W/m}^2$）
- $k$：材料的热导率（Thermal Conductivity），$k > 0$（单位：$\text{W/(m·K)}$）
- $T$：温度场（单位：K 或 ℃）
- $\nabla T$：温度梯度

**物理解释**：热量从高温区域流向低温区域，热流方向与温度梯度方向相反。

**热传导系数** $\alpha = k/(\rho c_p)$ 称为**热扩散系数**（Thermal Diffusivity），其中 $\rho$ 是密度，$c_p$ 是比热容。

## 2. 一维热传导方程推导

考虑一根均匀细杆，沿 $x$ 方向放置，截面积为 $A$。假设：
1. 杆是均匀的，热导率 $k$、密度 $\rho$、比热容 $c_p$ 均为常数。
2. 杆的侧面绝热，热量只沿 $x$ 方向传导。
3. 温度 $u(x, t)$ 只依赖于位置 $x$ 和时间 $t$。

**能量守恒**：在微元段 $[x, x+\Delta x]$ 上，热量守恒要求：
$$
\text{流入热量} - \text{流出热量} = \text{内部热量增加}
$$

**推导**：
1. 流入微元段的热流：$Q_{\text{in}} = -kA \frac{\partial u}{\partial x} \big|_x$
2. 流出微元段的热流：$Q_{\text{out}} = -kA \frac{\partial u}{\partial x} \big|_{x+\Delta x}$
3. 微元段内热量增加：$\rho c_p A \Delta x \frac{\partial u}{\partial t}$

根据能量守恒：
$$
Q_{\text{in}} - Q_{\text{out}} = \rho c_p A \Delta x \frac{\partial u}{\partial t}
$$
代入表达式并整理：
$$
kA \left( \frac{\partial u}{\partial x} \big|_{x+\Delta x} - \frac{\partial u}{\partial x} \big|_x \right) = \rho c_p A \Delta x \frac{\partial u}{\partial t}
$$
两边除以 $A\Delta x$ 并令 $\Delta x \to 0$：
$$
k \frac{\partial^2 u}{\partial x^2} = \rho c_p \frac{\partial u}{\partial t}
$$
令 $\alpha = k/(\rho c_p)$，得到**一维热传导方程**：
$$
\boxed{\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}}
$$
**物理意义**：温度随时间的变化率与温度空间分布的二阶导数（曲率）成正比。

**定解条件**：
- **初始条件**：$u(x, 0) = \phi(x)$（初始温度分布）
- **边界条件**（常见类型）：
  1. **第一类（Dirichlet）**：$u(0, t) = T_1$，$u(L, t) = T_2$（端点温度固定）
  2. **第二类（Neumann）**：$\frac{\partial u}{\partial x}(0, t) = 0$（绝热边界）
  3. **第三类（Robin）**：$\frac{\partial u}{\partial x} + h u = 0$（对流边界）

## 3. 极值原理（Maximum Principle）

极值原理是热传导方程的重要性质，反映了热传导的物理特性。

**定理**（弱极值原理）：设 $u(x, t)$ 在矩形区域 $\Omega = [0, L] \times [0, T]$ 上满足热传导方程 $u_t = \alpha u_{xx}$，则 $u$ 在 $\Omega$ 上的最大值和最小值必在抛物边界 $\Gamma = \partial\Omega \setminus \{(x, T) : 0 < x < L\}$ 上达到。

**推论**：如果 $u$ 在 $\Omega$ 内部达到最大值或最小值，则 $u$ 是常数。

**物理解释**：热量从高温流向低温，因此温度的极值点要么在初始时刻，要么在边界上，不会在内部“凭空”产生极值。

**应用**：
1. **唯一性**：如果两个解在抛物边界上相等，则它们在整个区域内相等。
2. **稳定性**：边界数据或初始数据的小扰动只引起解的小扰动。
3. **比较原理**：如果 $u \le v$ 在抛物边界上成立，且 $u_t - \alpha u_{xx} \le v_t - \alpha v_{xx}$，则 $u \le v$ 在 $\Omega$ 内成立。

## 4. 热核函数（Heat Kernel）

热核函数（也称基本解、格林函数）是热传导方程初值问题的解，具有重要意义。

**定义**：一维热核函数为：
$$
\Phi(x, t) = \frac{1}{\sqrt{4\pi\alpha t}} \exp\left(-\frac{x^2}{4\alpha t}\right), \quad t > 0
$$
**性质**：
1. 满足热传导方程：$\frac{\partial \Phi}{\partial t} = \alpha \frac{\partial^2 \Phi}{\partial x^2}$
2. 初始条件：$\lim_{t \to 0^+} \Phi(x, t) = \delta(x)$（Dirac δ 函数）
3. 归一化：$\int_{-\infty}^{\infty} \Phi(x, t) \, dx = 1$ 对所有 $t > 0$ 成立。

**解的表示**：热传导方程初值问题的解可表示为初始条件与热核的卷积：
$$
u(x, t) = \int_{-\infty}^{\infty} \Phi(x-y, t) \phi(y) \, dy = \frac{1}{\sqrt{4\pi\alpha t}} \int_{-\infty}^{\infty} e^{-\frac{(x-y)^2}{4\alpha t}} \phi(y) \, dy
$$
**物理解释**：热核函数表示在 $t=0$ 时刻在原点放置单位热量后，在时刻 $t$ 的温度分布。解是初始温度分布的“平滑化”。

**高维热核**：
- 二维：$\Phi(x, y, t) = \frac{1}{4\pi\alpha t} \exp\left(-\frac{x^2+y^2}{4\alpha t}\right)$
- 三维：$\Phi(x, y, z, t) = \left(\frac{1}{4\pi\alpha t}\right)^{3/2} \exp\left(-\frac{x^2+y^2+z^2}{4\alpha t}\right)$

## 5. 解的唯一性和稳定性

**唯一性定理**：设 $u_1, u_2$ 是热传导方程在区域 $\Omega = \{0 \le x \le L, 0 \le t \le T\}$ 上的两个解，且它们在抛物边界上取值相同，则 $u_1 \equiv u_2$。

**证明思路**：令 $w = u_1 - u_2$，则 $w$ 满足齐次方程和齐次边界/初始条件。由极值原理，$w$ 在 $\Omega$ 上的最大值和最小值均为零，故 $w \equiv 0$。

**稳定性**：设 $u$ 是解，$\tilde{u}$ 是扰动后的解（边界或初始数据有小扰动）。则存在常数 $C$ 使得：
$$
\sup_{\Omega} |u - \tilde{u}| \le C \left( \sup_{\text{抛物边界}} |u - \tilde{u}| \right)
$$
即解连续依赖于定解数据。

## 7. Python 代码示例：热传导过程模拟

以下代码模拟一维热传导过程，并展示热核函数的演化：

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.special import erf

# 参数设置
L = 1.0          # 杆长
alpha = 0.01     # 热扩散系数
nx = 100         # 空间网格点数
dx = L / (nx - 1)
x = np.linspace(0, L, nx)

# 方法1：解析解（使用误差函数）
def heat_conduction_analytical(x, t, alpha, L):
    """两端固定温度为0的热传导方程解析解"""
    # 初始条件：正弦波 u(x,0) = sin(πx/L)
    u = np.zeros_like(x)
    for n in range(1, 101):
        u += (2/(n*np.pi)) * np.sin(n*np.pi*x/L) * np.exp(-alpha*(n*np.pi/L)**2 * t)
    return u

# 方法2：有限差分法数值解
def solve_heat_equation_fdm(alpha, L, nx, nt, dt):
    """有限差分法求解热传导方程"""
    dx = L / (nx - 1)
    x = np.linspace(0, L, nx)
    r = alpha * dt / dx**2
    
    print(f"稳定性参数 r = {r:.4f} (应 ≤ 0.5)")
    
    # 初始条件
    u = np.sin(np.pi * x)
    u[0] = 0.0  # 边界条件
    u[-1] = 0.0
    
    u_history = [u.copy()]
    times = [0.0]
    
    # 时间推进（显式格式）
    for n in range(1, nt):
        u_new = u.copy()
        for i in range(1, nx - 1):
            u_new[i] = u[i] + r * (u[i+1] - 2*u[i] + u[i-1])
        
        u_new[0] = 0.0
        u_new[-1] = 0.0
        u = u_new
        
        if n % (nt // 10) == 0:
            u_history.append(u.copy())
            times.append(n * dt)
    
    return x, u_history, times

# 模拟参数
nt = 500
dt = 0.001
t_final = nt * dt

# 求数值解
x_num, u_history, times = solve_heat_equation_fdm(alpha, L, nx, nt, dt)

# 绘制不同时刻的温度分布
plt.figure(figsize=(12, 8))

plt.subplot(2, 2, 1)
for i, t in enumerate(times):
    u_exact = heat_conduction_analytical(x_num, t, alpha, L)
    plt.plot(x_num, u_exact, label=f't={t:.3f}')
plt.xlabel('位置 x')
plt.ylabel('温度 u(x, t)')
plt.title('热传导过程解析解')
plt.legend()
plt.grid(True, alpha=0.3)
plt.ylim(0, 1.1)

plt.subplot(2, 2, 2)
for i, t in enumerate(times):
    plt.plot(x_num, u_history[i], label=f't={t:.3f}')
plt.xlabel('位置 x')
plt.ylabel('温度 u(x, t)')
plt.title('热传导过程数值解 (有限差分法)')
plt.legend()
plt.grid(True, alpha=0.3)
plt.ylim(0, 1.1)

# 热核函数演化
plt.subplot(2, 2, 3)
t_values = [0.001, 0.005, 0.01, 0.05]
x_heat = np.linspace(-2, 2, 200)
for t in t_values:
    kernel = np.exp(-x_heat**2 / (4*alpha*t)) / np.sqrt(4*np.pi*alpha*t)
    plt.plot(x_heat, kernel, label=f't={t}')
plt.xlabel('x')
plt.ylabel('Φ(x, t)')
plt.title('热核函数 Φ(x, t) 的演化')
plt.legend()
plt.grid(True, alpha=0.3)

# 极值原理验证
plt.subplot(2, 2, 4)
u_final = heat_conduction_analytical(x_num, t_final, alpha, L)
plt.plot(x_num, u_final, 'b-', linewidth=2, label=f'最终分布 (t={t_final})')
plt.axhline(y=np.max(u_final), color='r', linestyle='--', label=f'最大值={np.max(u_final):.4f}')
plt.axhline(y=np.min(u_final), color='g', linestyle='--', label=f'最小值={np.min(u_final):.4f}')
plt.fill_between(x_num, 0, u_final, alpha=0.3)
plt.xlabel('位置 x')
plt.ylabel('温度 u(x, t)')
plt.title('最终温度分布与极值')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('heat_conduction.png', dpi=150, bbox_inches='tight')
plt.show()

# 计算误差
print(f"\n数值模拟完成")
print(f"时间步长 dt = {dt}, 空间步长 dx = {dx:.4f}")
print(f"稳定性参数 r = {alpha*dt/dx**2:.4f}")
print(f"最终时刻 t = {t_final}")
```

**代码说明**：
1. 使用有限差分法（显式格式）求解热传导方程。
2. 要求稳定性条件 $r = \alpha\Delta t/\Delta x^2 \le 0.5$。
3. 绘制了不同时刻的温度分布，展示了热量扩散过程。
4. 可视化了热核函数的演化（峰值降低，宽度增加）。

## 8. 注意事项和常见错误

### 注意事项
1. **稳定性条件**：使用显式有限差分法时，必须满足 $r = \alpha\Delta t/\Delta x^2 \le 0.5$，否则数值解不稳定。
2. **边界条件类型**：正确选择边界条件类型（Dirichlet、Neumann、Robin）对解的物理意义至关重要。
3. **初始条件相容性**：初始条件应满足边界条件（相容性条件），否则解在初始时刻可能不光滑。
4. **无量纲化**：进行无量纲化可以简化方程和参数，便于分析。

### 常见错误
1. **数值不稳定**：时间步长太大导致稳定性条件不满足，解发散或振荡。
2. **边界反射**：错误处理边界条件导致非物理的反射。
3. **混淆方程**：将热传导方程与波动方程混淆（热传导方程是一阶时间导数，波动方程是二阶）。
4. **忽略物理约束**：热扩散系数 $\alpha$ 必须为正数，否则不符合物理规律。

## 9. 本章小结

- **热传导方程** $\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$ 描述热量扩散过程。
- **傅里叶定律**是热传导方程的物理基础：热流与温度梯度成正比。
- **极值原理**表明温度极值在抛物边界上达到，是热传导方程的重要性质。
- **热核函数**是热传导方程的基本解，解可表示为初始条件与热核的卷积。
- **唯一性和稳定性**由极值原理保证，解连续依赖于定解数据。
