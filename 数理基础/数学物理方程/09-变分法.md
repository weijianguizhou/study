# 09 变分法

## 简介

变分法（Calculus of Variations）是研究泛函极值问题的数学分支。与普通微积分求函数极值不同，变分法求解的是"函数的函数"（即泛函）的极值问题。在数学物理方程中，变分法不仅提供了将物理问题转化为偏微分方程的途径（最小作用量原理），还提供了求解偏微分方程近似解的强大工具（瑞利-里兹方法、有限元法）。

> [!tip] 变分法的意义
> - **物理层面**：自然界的许多规律可以表述为某个泛函取极值的条件
> - **数学层面**：偏微分方程的边值问题等价于某个泛函的极小化问题
> - **计算层面**：变分原理为有限元法等数值方法奠定了理论基础

---

## 核心概念

### 1. 泛函（Functional）

泛函是从函数空间到实数（或复数）的映射。设 $J[y]$ 是定义在函数集合上的实值函数，则 $J$ 称为泛函。

**例子**：

- $J[y] = \int_a^b F(x, y, y') \, dx$ — 这是最常见的一维变分问题
- $J[u] = \iint_\Omega \left[|\nabla u|^2 + 2fu\right] dx \, dy$ — 泊松方程对应的能量泛函

### 2. 变分（Variation）

函数 $y(x)$ 的变分 $\delta y$ 是一个依赖于参数 $\epsilon$ 的函数族的导数：

$$\delta y = \left.\frac{d}{d\epsilon} y(x; \epsilon)\right|_{\epsilon=0}$$

其中 $y(x; \epsilon)$ 是 $y(x)$ 的一个邻近函数族，且 $y(x; 0) = y(x)$。

### 3. 泛函的变分

泛函 $J[y]$ 的一次变分定义为：

$$\delta J = \left.\frac{d}{d\epsilon} J[y + \epsilon \delta y]\right|_{\epsilon=0}$$

泛函取极值的必要条件是：$\delta J = 0$

---

## 欧拉-拉格朗日方程

### 一维情形

**问题**：求函数 $y(x)$ 使得泛函

$$J[y] = \int_a^b F(x, y, y') \, dx$$

取极值，其中 $y(a) = A$，$y(b) = B$ 固定。

> [!important] 欧拉-拉格朗日方程 (Euler-Lagrange Equation)
> 泛函 $J[y]$ 取极值的必要条件是 $y(x)$ 满足：
> $$\frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\partial F}{\partial y'} = 0$$

### 推导

考虑 $y(x) + \epsilon \eta(x)$，其中 $\eta(a) = \eta(b) = 0$：

$$J(\epsilon) = \int_a^b F(x, y + \epsilon\eta, y' + \epsilon\eta') \, dx$$

令 $\frac{dJ}{d\epsilon}\bigg|_{\epsilon=0} = 0$：

$$\int_a^b \left(\frac{\partial F}{\partial y}\eta + \frac{\partial F}{\partial y'}\eta'\right) dx = 0$$

对第二项分部积分：

$$\int_a^b \left(\frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\partial F}{\partial y'}\right)\eta \, dx + \left[\frac{\partial F}{\partial y'}\eta\right]_a^b = 0$$

由 $\eta(a) = \eta(b) = 0$，边界项为零。由变分基本引理得欧拉方程。

### 重要推论

1. **$F$ 不含 $y$**：$\frac{\partial F}{\partial y'} = C$（常数）
2. **$F$ 不含 $x$**：$F - y'\frac{\partial F}{\partial y'} = C$（Beltrami 公式）
3. **$F$ 不含 $y'$**：$\frac{\partial F}{\partial y} = 0$（退化为普通极值问题）

### 二维及更高维情形

对于二元函数 $u(x, y)$ 的泛函：

$$J[u] = \iint_\Omega F(x, y, u, u_x, u_y) \, dx \, dy$$

欧拉-拉格朗日方程为：

$$\frac{\partial F}{\partial u} - \frac{\partial}{\partial x}\frac{\partial F}{\partial u_x} - \frac{\partial}{\partial y}\frac{\partial F}{\partial u_y} = 0$$

## 条件变分问题

### 等周问题

在约束条件 $G[y] = \int_a^b g(x, y, y') dx = C$ 下，求 $J[y]$ 的极值。

**解法**：引入拉格朗日乘子 $\lambda$，求解无约束泛函：

$$\tilde{J}[y] = J[y] + \lambda G[y]$$

的极值。

### 应用：最短曲线问题

在固定弧长 $l$ 的约束下，求两点间的最短曲线。这正是拉格朗日力学中约束系统的变分原理。

## 变分法在偏微分方程中的应用

### 变分原理与边值问题的等价性

**泊松方程的变分原理**：

边值问题：

$$-\nabla^2 u = f \text{ in } \Omega, \quad u|_{\partial\Omega} = 0$$

等价于能量泛函的极小化：

$$\min_{u \in H_0^1(\Omega)} J[u], \quad J[u] = \int_\Omega \left[\frac{1}{2}|\nabla u|^2 - fu\right] dV$$

> [!important] 定理
> $u$ 是泊松方程的解，当且仅当 $u$ 是能量泛函 $J[u]$ 的极小点（在 Sobolev 空间 $H_0^1$ 中）。

**证明思路**：对 $J[u]$ 取变分，得到的欧拉方程正是泊松方程。

### 瑞利商与特征值问题

对于特征值问题：

$$-\nabla^2 u = \lambda u, \quad u|_{\partial\Omega} = 0$$

最小特征值可以表示为瑞利商（Rayleigh quotient）的极小值：

$$\lambda_1 = \min_{u \in H_0^1} R[u] = \min_{u \in H_0^1} \frac{\int_\Omega |\nabla u|^2 \, dV}{\int_\Omega u^2 \, dV}$$

## 瑞利-里兹方法

### 基本思想

将泛函极小化问题限制在有限维子空间中进行近似求解。

### 方法步骤

1. **选择试探函数空间**：选取 $N$ 个线性无关的基函数 $\{\phi_1, \phi_2, \ldots, \phi_N\}$，构造近似解：

$$u_N(x) = \sum_{i=1}^N c_i \phi_i(x)$$

2. **代入泛函**：将 $u_N$ 代入能量泛函 $J[u]$

3. **极小化**：对参数 $c_i$ 求导并令其为零：

$$\frac{\partial J[u_N]}{\partial c_i} = 0, \quad i = 1, 2, \ldots, N$$

4. **求解线性方程组**：得到 $c_i$ 的值

### 收敛性

> [!important] 定理
> 当基函数空间逐步扩大（$N \to \infty$）且满足完备性条件时，瑞利-里兹近似解 $u_N$ 收敛到精确解 $u$。

## 有限元法简介

### 从瑞利-里兹到有限元

有限元法（Finite Element Method, FEM）本质上是瑞利-里兹方法的特殊实现，关键区别在于：

| 特征 | 瑞利-里兹方法 | 有限元法 |
|------|--------------|----------|
| 基函数 | 全局光滑函数 | 局部支撑的分片多项式 |
| 适用域 | 规则区域 | 任意复杂区域 |
| 矩阵性质 | 满矩阵 | 稀疏矩阵 |
| 计算规模 | 小规模问题 | 可处理大规模问题 |

### 有限元法的基本步骤

1. **网格划分**：将计算区域 $\Omega$ 剖分为有限个单元（三角形、四边形、四面体等）
2. **选择形函数**：在每个单元上定义局部多项式插值函数（形函数）
3. **单元分析**：在每个单元上计算刚度矩阵和载荷向量
4. **总体装配**：将所有单元的贡献装配成总体线性方程组
5. **施加边界条件**：处理 Dirichlet 和 Neumann 边界条件
6. **求解**：求解稀疏线性方程组
7. **后处理**：计算所需物理量

### 变分形式（弱形式）

将泊松方程 $-\nabla^2 u = f$ 两边乘以试验函数 $v$，在 $\Omega$ 上积分并利用格林公式：

$$\int_\Omega \nabla u \cdot \nabla v \, dV = \int_\Omega f v \, dV, \quad \forall v \in H_0^1(\Omega)$$

这就是**弱形式**（weak form），有限元法正是基于此离散化的。

## Python代码示例

以下代码演示用瑞利-里兹方法（有限元法）求解一维泊松方程：

```python
import numpy as np
import matplotlib.pyplot as plt

def fem_1d_poisson(N=20):
    """
    用线性有限元法求解一维泊松方程：
        -u'' = f(x),  0 < x < 1
        u(0) = u(1) = 0
    
    精确解: u(x) = sin(πx)，对应 f(x) = π²sin(πx)
    
    参数:
        N : 单元数量（节点数 = N+1）
    返回:
        x_nodes: 节点坐标
        u_fem  : 有限元近似解
        u_exact: 精确解
    """
    # 网格生成
    h = 1.0 / N
    x_nodes = np.linspace(0, 1, N + 1)
    
    # 源项
    f = lambda x: np.pi**2 * np.sin(np.pi * x)
    
    # 组装刚度矩阵 K 和载荷向量 F
    K = np.zeros((N + 1, N + 1))
    F = np.zeros(N + 1)
    
    for i in range(N):
        # 单元 i: [x_i, x_{i+1}]
        x_left = x_nodes[i]
        x_right = x_nodes[i + 1]
        h_e = x_right - x_left
        x_mid = (x_left + x_right) / 2
        
        # 单元刚度矩阵 (2x2)
        k_e = (1.0 / h_e) * np.array([[1, -1], [-1, 1]])
        
        # 单元载荷向量 (梯形积分)
        f_left = f(x_left)
        f_right = f(x_right)
        f_mid = f(x_mid)
        f_e = h_e / 6.0 * np.array([
            2 * f_left + f_mid,
            f_left + 2 * f_mid
        ])
        
        # 装配到全局矩阵
        for loc_i in range(2):
            for loc_j in range(2):
                K[i + loc_i, i + loc_j] += k_e[loc_i, loc_j]
            F[i + loc_i] += f_e[loc_i]
    
    # 施加 Dirichlet 边界条件 u(0) = u(1) = 0
    # 方法：置1法
    K[0, :] = 0; K[:, 0] = 0; K[0, 0] = 1; F[0] = 0
    K[-1, :] = 0; K[:, -1] = 0; K[-1, -1] = 1; F[-1] = 0
    
    # 求解线性方程组
    u_fem = np.linalg.solve(K, F)
    
    # 精确解
    u_exact = np.sin(np.pi * x_nodes)
    
    return x_nodes, u_fem, u_exact

def convergence_study():
    """收敛性分析：不同网格下的误差"""
    N_list = [4, 8, 16, 32, 64, 128, 256]
    errors = []
    
    for N in N_list:
        x, u_fem, u_exact = fem_1d_poisson(N)
        error = np.max(np.abs(u_fem - u_exact))
        errors.append(error)
    
    return N_list, errors

# ---- 主程序 ----

# 求解
N = 30
x, u_fem, u_exact = fem_1d_poisson(N)

# 收敛性分析
N_list, errors = convergence_study()

# 可视化
fig, axes = plt.subplots(1, 3, figsize=(18, 5))

# 左图：有限元解与精确解
ax1 = axes[0]
ax1.plot(x, u_fem, 'bo-', markersize=4, linewidth=1.5, label=f'FEM (N={N})')
ax1.plot(x, u_exact, 'r-', linewidth=2, label='精确解 sin(πx)')
ax1.set_xlabel('x', fontsize=12)
ax1.set_ylabel('u(x)', fontsize=12)
ax1.set_title('有限元解 vs 精确解', fontsize=13)
ax1.legend(fontsize=11)
ax1.grid(True, alpha=0.3)

# 中图：误差分布
ax2 = axes[1]
error = np.abs(u_fem - u_exact)
ax2.bar(x, error, width=1.0/N, color='steelblue', alpha=0.7)
ax2.set_xlabel('x', fontsize=12)
ax2.set_ylabel('|u_FEM - u_exact|', fontsize=12)
ax2.set_title(f'逐点误差 (L∞ = {np.max(error):.2e})', fontsize=13)
ax2.grid(True, alpha=0.3)

# 右图：收敛率
ax3 = axes[2]
h_list = [1.0 / n for n in N_list]
ax3.loglog(h_list, errors, 'rs-', markersize=8, linewidth=2, label='FEM误差')
# 参考线：O(h²)
h_ref = np.array(h_list)
ref_line = errors[0] / h_list[0]**2 * h_ref**2
ax3.loglog(h_ref, ref_line, 'k--', linewidth=1.5, label='O(h²) 参考线')
ax3.set_xlabel('网格尺寸 h', fontsize=12)
ax3.set_ylabel('最大误差', fontsize=12)
ax3.set_title('收敛率分析 (h² 收敛)', fontsize=13)
ax3.legend(fontsize=11)
ax3.grid(True, alpha=3)

plt.tight_layout()
plt.savefig('fem_1d_poisson.png', dpi=150)
plt.show()

# 输出数值
print(f"网格数 N = {N}")
print(f"最大误差 = {np.max(error):.6e}")
print(f"收敛阶估计 (从最后两点): {np.log(errors[-1]/errors[-2])/np.log(h_list[-1]/h_list[-2]):.2f}")
```

## 注意事项和常见错误

> [!caution] 常见错误
> 1. **混淆变分问题和微分问题的等价条件**：变分问题通常要求解在 Sobolev 空间 $H^1$ 中，而不是经典意义下。弱解可能不具有二阶导数。
>
> 2. **基函数选择不当**：瑞利-里兹方法中，基函数必须线性无关且满足（或近似满足）边界条件。否则可能导致刚度矩阵奇异。
>
> 3. **边界条件处理错误**：有限元法中 Dirichlet 边界条件的处理必须正确。常用方法有：置1法、罚函数法、拉格朗日乘子法。
>
> 4. **网格质量**：在有限元法中，过于畸形的网格会导致数值精度严重下降。

> [!tip] 实用建议
> - **先验证再使用**：对简单问题验证程序正确性（如与解析解比较），再应用于复杂问题
> - **收敛性测试**：逐步细化网格，观察解是否收敛，确认数值结果可靠
> - **基函数阶数**：线性元精度为 $O(h^2)$，二次元为 $O(h^3)$，高阶元精度更高但计算量更大
> - **利用对称性**：如果问题具有对称性，可以只计算对称区域的一半，减小计算量
> - 对于特征值问题，瑞利商给出的近似值总是**上界**（对于最小特征值）

## 本章小结

- 变分法将偏微分方程的求解转化为泛函极值问题
- 欧拉-拉格朗日方程是泛函取极值的必要条件，是变分法的核心公式
- 泊松方程等价于能量泛函的极小化问题（变分原理）
- 瑞利-里兹方法通过有限维逼近求解变分问题，是有限元法的理论基础
- 有限元法用分片多项式基函数实现瑞利-里兹方法，适用于任意复杂几何区域
- 变分法连接了物理原理（最小作用量）和数学求解方法（有限元法）

## 练习题

1. **基础题**：求泛函 $J[y] = \int_0^1 (y'^2 + y^2 + 2xy) \, dx$，$y(0) = 0$，$y(1) = 1$ 的极值函数。

2. **推导题**：从欧拉-拉格朗日方程出发，推导波动方程的最小作用量原理。

3. **有限元**：用瑞利-里兹方法（取两个基函数 $\phi_1 = \sin\pi x$，$\phi_2 = \sin 2\pi x$）近似求解 $-u'' = 1$，$u(0) = u(1) = 0$，并与精确解比较。

4. **编程题**：实现二维三角形有限元法求解 Laplace 方程 $\nabla^2 u = 0$，在单位正方形上，$u$ 在四条边上分别为不同的值。

5. **思考题**：解释为什么瑞利-里兹近似得到的最小特征值总是上界，而不会低于精确值。
