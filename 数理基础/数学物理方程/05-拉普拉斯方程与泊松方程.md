# 05-拉普拉斯方程与泊松方程

> **本章简介**：拉普拉斯方程和泊松方程是描述稳态现象（如静电场、稳态温度分布、引力场等）的基本偏微分方程。本章将介绍调和函数的定义和性质，讨论三类边值问题（Dirichlet、Neumann、Robin），引入格林函数方法，并阐述唯一性定理和极值原理。

## 1. 调和函数定义和性质

### 1.1 拉普拉斯方程与泊松方程

**拉普拉斯方程**（Laplace's Equation）：
$$
\Delta u = 0 \quad \text{或} \quad \nabla^2 u = 0
$$
其中 $\Delta = \sum_{i=1}^n \frac{\partial^2}{\partial x_i^2}$ 是拉普拉斯算子。

**泊松方程**（Poisson's Equation）：
$$
\Delta u = f(x)
$$
其中 $f(x)$ 是给定的源项。

**物理意义**：
- 拉普拉斯方程描述无源区域的稳态现象（如真空中的静电场）。
- 泊松方程描述有源区域的稳态现象（如电荷分布产生的电势）。

### 1.2 调和函数

**定义**：在区域 $\Omega \subset \mathbb{R}^n$ 上二阶连续可微且满足 $\Delta u = 0$ 的函数 $u$ 称为**调和函数**（Harmonic Function）。

**泊松方程的解**称为**次调和函数**（subharmonic）或**超调和函数**（superharmonic），取决于不等式方向。

### 1.3 调和函数的性质

1. **平均值性质**（Mean Value Property）：
   - **球面平均值**：若 $u$ 在 $\Omega$ 上调和，$B_r(x_0) \subset \Omega$，则
     $$
     u(x_0) = \frac{1}{|\partial B_r|} \int_{\partial B_r(x_0)} u(x) \, dS
     $$
   - **球体平均值**：
     $$
     u(x_0) = \frac{1}{|B_r|} \int_{B_r(x_0)} u(x) \, dx
     $$

2. **极值原理**（Maximum Principle）：
   - **强极值原理**：如果 $u$ 在连通开集 $\Omega$ 上调和且非常数，则 $u$ 不能在 $\Omega$ 内部达到最大值或最小值。
   - **弱极值原理**：$u$ 在 $\bar{\Omega}$ 上的最大值和最小值必在边界 $\partial\Omega$ 上达到。

3. **唯一性**：如果 $u_1, u_2$ 在 $\Omega$ 上调和且在边界 $\partial\Omega$ 上相等，则 $u_1 \equiv u_2$。

4. **光滑性**：调和函数是实解析的（real analytic），即在任意点附近可以展开为收敛的幂级数。

5. **Liouville 定理**：在整个 $\mathbb{R}^n$ 上有界的调和函数必为常数。

6. **Harnack 不等式**：对于紧集 $K \subset \Omega$，存在常数 $C$（依赖于 $K$ 和 $\Omega$）使得
   $$
   \sup_K u \le C \inf_K u
   $$
   对所有非负调和函数 $u$ 成立。

## 2. 边值问题（Boundary Value Problems）

拉普拉斯方程和泊松方程通常需要边界条件来确定唯一解。常见的边值问题有：

### 2.1 Dirichlet 问题（第一类边值问题）
**问题**：求 $u$ 使得
$$
\begin{cases}
\Delta u = f(x) & \text{in } \Omega \\
u = g(x) & \text{on } \partial\Omega
\end{cases}
$$
**物理意义**：给定边界上的势值，求区域内的势函数（如固定边界温度的稳态温度分布）。

**存在性**：对于光滑边界 $\partial\Omega$，Dirichlet 问题总有解（Perron 方法）。

### 2.2 Neumann 问题（第二类边值问题）
**问题**：求 $u$ 使得
$$
\begin{cases}
\Delta u = f(x) & \text{in } \Omega \\
\frac{\partial u}{\partial n} = g(x) & \text{on } \partial\Omega
\end{cases}
$$
其中 $\frac{\partial u}{\partial n}$ 是外法向导数。

**物理意义**：给定边界上的热流密度或电场法向分量，求区域内的势函数。

**可解性条件**：Neumann 问题有解当且仅当
$$
\int_\Omega f(x) \, dx = \int_{\partial\Omega} g(x) \, dS
$$
（积分守恒条件）。解在相差一个常数的意义下唯一。

### 2.3 Robin 问题（第三类边值问题）
**问题**：求 $u$ 使得
$$
\begin{cases}
\Delta u = f(x) & \text{in } \Omega \\
\alpha u + \beta \frac{\partial u}{\partial n} = g(x) & \text{on } \partial\Omega
\end{cases}
$$
其中 $\alpha, \beta$ 是给定常数，$\alpha^2 + \beta^2 \ne 0$。

**物理意义**：描述对流换热边界条件（Newton 冷却定律）。

## 3. 格林函数（Green's Function）

### 3.1 格林函数的定义

对于区域 $\Omega$ 上的 Dirichlet 问题，格林函数 $G(x, y)$ 定义为：
$$
\begin{cases}
\Delta_y G(x, y) = \delta(x - y) & \text{in } \Omega \\
G(x, y) = 0 & \text{on } \partial\Omega
\end{cases}
$$
其中 $\delta$ 是 Dirac δ 函数。

**物理解释**：格林函数表示在点 $x$ 放置单位点电荷时，在点 $y$ 产生的电势（满足接地边界条件）。

### 3.2 格林函数的性质

1. **对称性**：$G(x, y) = G(y, x)$
2. **奇性**：当 $x = y$ 时，$G(x, y)$ 有奇性，其奇性与基本解相同。
3. **非正性**：对于 Dirichlet 问题，$G(x, y) \le 0$

### 3.3 用格林函数表示解

Dirichlet 问题的解可用格林函数表示为：
$$
u(x) = \int_{\partial\Omega} g(y) \frac{\partial G}{\partial n_y}(x, y) \, dS_y - \int_\Omega G(x, y) f(y) \, dy
$$
其中 $\frac{\partial G}{\partial n_y}$ 是格林函数在边界上的法向导数。

**格林第三公式**（调和函数的表示）：
若 $u$ 调和，则
$$
u(x) = \int_{\partial\Omega} u(y) \frac{\partial G}{\partial n_y}(x, y) \, dS_y
$$

### 3.4 特殊区域的格林函数

1. **半空间**：$\mathbb{R}^n_+$ 的格林函数可用镜像法构造。
2. **球**：$B_R(0)$ 的格林函数为
   $$
   G(x, y) = \Phi(y - x) - \Phi\left(\frac{|x|}{R}(y - x^*)\right)
   $$
   其中 $x^* = \frac{R^2}{|x|^2}x$ 是 $x$ 关于球的反演点，$\Phi$ 是基本解。

## 4. 唯一性定理

**定理**（Dirichlet 问题的唯一性）：
设 $\Omega$ 是有界区域，$u_1, u_2$ 是 $\Delta u = f$ 在 $\Omega$ 上的两个解，且 $u_1 = u_2$ 在 $\partial\Omega$ 上成立，则 $u_1 \equiv u_2$。

**证明**：令 $w = u_1 - u_2$，则 $\Delta w = 0$ 在 $\Omega$ 内，$w = 0$ 在 $\partial\Omega$ 上。由极值原理，$w \le 0$ 且 $w \ge 0$，故 $w \equiv 0$。

**推论**：
1. Neumann 问题的解在相差一个常数的意义下唯一。
2. Robin 问题的解唯一。

**物理意义**：稳态现象由边界条件唯一确定（给定边界上的势值或法向导数，区域内的势函数唯一确定）。

## 5. 极值原理（Maximum Principle）

### 5.1 调和函数的极值原理

**定理**（强极值原理）：
设 $u$ 在连通开集 $\Omega$ 上调和且非常数，则 $u$ 不能在 $\Omega$ 内部达到最大值或最小值。

**定理**（弱极值原理）：
设 $u$ 在有界区域 $\Omega$ 上连续，在 $\Omega$ 内调和，则
$$
\max_{\bar{\Omega}} u = \max_{\partial\Omega} u, \quad \min_{\bar{\Omega}} u = \min_{\partial\Omega} u
$$

### 5.2 泊松方程的极值原理

对于泊松方程 $\Delta u = f$，如果 $f \ge 0$（次调和函数），则 $u$ 在内部不能达到最大值；如果 $f \le 0$（超调和函数），则 $u$ 在内部不能达到最小值。

### 5.3 应用

1. **唯一性证明**：极值原理是证明解唯一性的有力工具。
2. **先验估计**：可以通过边界数据估计解的大小。
3. **比较原理**：如果 $u \le v$ 在边界上成立，且 $\Delta u \ge \Delta v$，则 $u \le v$ 在区域内成立。

## 7. Python 代码示例：使用有限差分法求解 Dirichlet 问题

以下代码使用有限差分法求解二维 Laplace 方程的 Dirichlet 问题：

```python
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def solve_laplace_dirichlet(nx=50, ny=50, max_iter=10000, tol=1e-6):
    """
    使用有限差分法求解矩形区域上的 Laplace 方程 Dirichlet 问题
    Δu = 0, u|∂Ω = g(x,y)
    """
    # 区域设置
    x = np.linspace(0, 1, nx)
    y = np.linspace(0, 1, ny)
    X, Y = np.meshgrid(x, y)
    
    # 初始化解
    u = np.zeros((ny, nx))
    
    # 边界条件 (Dirichlet)
    # 下边界 y=0: u(x,0) = sin(πx)
    u[0, :] = np.sin(np.pi * x)
    # 上边界 y=1: u(x,1) = 0
    u[-1, :] = 0.0
    # 左边界 x=0: u(0,y) = 0
    u[:, 0] = 0.0
    # 右边界 x=1: u(1,y) = 0
    u[:, -1] = 0.0
    
    # Jacobi 迭代法求解
    for iteration in range(max_iter):
        u_old = u.copy()
        
        # 内部点更新
        u[1:-1, 1:-1] = 0.25 * (
            u_old[1:-1, 2:] + u_old[1:-1, :-2] +
            u_old[2:, 1:-1] + u_old[:-2, 1:-1]
        )
        
        # 保持边界条件
        u[0, :] = np.sin(np.pi * x)
        u[-1, :] = 0.0
        u[:, 0] = 0.0
        u[:, -1] = 0.0
        
        # 检查收敛
        error = np.max(np.abs(u - u_old))
        if iteration % 100 == 0:
            print(f"迭代 {iteration}, 误差 = {error:.2e}")
        if error < tol:
            print(f"收敛于迭代 {iteration}, 误差 = {error:.2e}")
            break
    
    return X, Y, u

def plot_results(X, Y, u):
    """绘制结果"""
    fig = plt.figure(figsize=(15, 5))
    
    # 3D 表面图
    ax1 = fig.add_subplot(131, projection='3d')
    surf = ax1.plot_surface(X, Y, u, cmap='viridis', alpha=0.8)
    ax1.set_xlabel('X')
    ax1.set_ylabel('Y')
    ax1.set_zlabel('u(x, y)')
    ax1.set_title('Laplace 方程 Dirichlet 问题的解\n（3D 视图）')
    fig.colorbar(surf, ax=ax1, shrink=0.5)
    
    # 等高线图
    ax2 = fig.add_subplot(132)
    contour = ax2.contourf(X, Y, u, levels=20, cmap='viridis')
    ax2.set_xlabel('X')
    ax2.set_ylabel('Y')
    ax2.set_title('等高线图')
    ax2.set_aspect('equal')
    fig.colorbar(contour, ax=ax2)
    
    # 热图
    ax3 = fig.add_subplot(133)
    im = ax3.imshow(u, extent=[0, 1, 0, 1], origin='lower', cmap='viridis')
    ax3.set_xlabel('X')
    ax3.set_ylabel('Y')
    ax3.set_title('热图')
    fig.colorbar(im, ax=ax3)
    
    plt.tight_layout()
    plt.savefig('laplace_solution.png', dpi=150, bbox_inches='tight')
    plt.show()

def verify_boundary_conditions(X, Y, u):
    """验证边界条件"""
    nx, ny = u.shape
    
    print("\n边界条件验证:")
    print(f"下边界 (y=0): 最大误差 = {np.max(np.abs(u[0, :] - np.sin(np.pi * X[0, :]))):.2e}")
    print(f"上边界 (y=1): 最大误差 = {np.max(np.abs(u[-1, :])):.2e}")
    print(f"左边界 (x=0): 最大误差 = {np.max(np.abs(u[:, 0])):.2e}")
    print(f"右边界 (x=1): 最大误差 = {np.max(np.abs(u[:, -1])):.2e}")
    
    # 验证调和性（内部点 Δu ≈ 0）
    dx = X[0, 1] - X[0, 0]
    dy = Y[1, 0] - Y[0, 0]
    laplacian = (u[1:-1, 2:] - 2*u[1:-1, 1:-1] + u[1:-1, :-2]) / dx**2 + \
                (u[2:, 1:-1] - 2*u[1:-1, 1:-1] + u[:-2, 1:-1]) / dy**2
    
    print(f"内部点 Δu 的最大值: {np.max(np.abs(laplacian)):.2e}")
    print(f"内部点 Δu 的平均值: {np.mean(np.abs(laplacian)):.2e}")

# 主程序
if __name__ == "__main__":
    print("求解 Laplace 方程 Dirichlet 问题...")
    print("边界条件: u(x,0)=sin(πx), u(x,1)=0, u(0,y)=0, u(1,y)=0")
    print("-" * 50)
    
    X, Y, u = solve_laplace_dirichlet(nx=50, ny=50, max_iter=5000, tol=1e-6)
    
    plot_results(X, Y, u)
    verify_boundary_conditions(X, Y, u)
    
    print("\n计算完成！")
```

**代码说明**：
1. 使用 Jacobi 迭代法求解矩形区域上的 Laplace 方程。
2. 边界条件为：下边界 $u(x,0) = \sin(\pi x)$，其他三边为零。
3. 绘制了 3D 表面图、等高线图和热图。
4. 验证了边界条件和调和性（内部点拉普拉斯算子接近零）。

## 8. 注意事项和常见错误

### 注意事项
1. **边界条件类型**：正确区分 Dirichlet、Neumann 和 Robin 问题，选择合适的解法。
2. **唯一性**：Neumann 问题的解不唯一（相差常数），通常需要附加条件（如平均值为零）。
3. **可解性条件**：Neumann 问题需要满足积分守恒条件，否则无解。
4. **数值方法**：有限差分法要求网格足够细，且满足稳定性条件。

### 常见错误
1. **混淆方程**：将 Laplace 方程（$\Delta u = 0$）与 Poisson 方程（$\Delta u = f$）混淆。
2. **边界条件错误**：Neumann 问题中误用 Dirichlet 条件。
3. **忽略唯一性**：Neumann 问题解不唯一，需注意附加条件。
4. **数值发散**：迭代法不收敛，可能是边界条件不兼容或网格太粗。

## 9. 本章小结

- **拉普拉斯方程** $\Delta u = 0$ 和 **泊松方程** $\Delta u = f$ 描述稳态现象。
- **调和函数**满足平均值性质、极值原理、唯一性等重要性质。
- **边值问题**包括 Dirichlet（给定边界值）、Neumann（给定边界法向导数）、Robin（混合条件）。
- **格林函数**是求解边值问题的有力工具，可用镜像法等构造。
- **极值原理**是调和函数的核心性质，用于证明唯一性、进行先验估计等。
