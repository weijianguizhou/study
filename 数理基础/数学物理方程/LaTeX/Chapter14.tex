\chapter{总结与展望}
\intro{本章总结全书内容，介绍进阶学习方向。}

\section{内容回顾}

\begin{enumerate}
	\item 三大典型方程的物理背景和数学分类。
	\item 分离变量法、积分变换法、格林函数法。
	\item 特殊函数（贝塞尔函数、勒让德多项式）和施图姆-刘维尔理论。
	\item 数值解法基础。
	\item 工程应用实例。
\end{enumerate}

\section{进阶方向}

\begin{enumerate}
	\item \textbf{偏微分方程现代理论}：索伯列夫空间、弱解理论。
	\item \textbf{非线性方程}：KdV 方程、非线性薛定谔方程。
	\item \textbf{数学物理方法}：量子力学、广义相对论中的方程。
	\item \textbf{数值分析}：有限元方法、谱方法、深度学习求解 PDE（PINN）。
\end{enumerate}

\begin{remark}
数学物理方程是连接数学理论与物理应用的桥梁。掌握这些工具，可以为后续的数学物理方法、高等数学分析和工程应用奠定坚实的基础。
\end{remark}
