## 14.1 弦振动问题完整求解

### 问题描述

长度为 $L$ 的均匀弦，两端固定，初始位移为 $f(x)$，初始速度为 $g(x)$。

**数学模型**：
$$\frac{\partial^2 u}{\partial t^2} = c^2\frac{\partial^2 u}{\partial x^2}, \quad 0 < x < L, \; t > 0$$

**边界条件**：$u(0, t) = u(L, t) = 0$（两端固定）

**初始条件**：
$$u(x, 0) = f(x), \quad \frac{\partial u}{\partial t}(x, 0) = g(x)$$

### 求解过程

**第一步：分离变量**

设 $u(x, t) = X(x)T(t)$，代入方程并分离：

$$\frac{T''}{c^2 T} = \frac{X''}{X} = -\lambda$$

得到两个常微分方程：
- $X'' + \lambda X = 0$，$X(0) = X(L) = 0$
- $T'' + \lambda c^2 T = 0$

**第二步：求解特征值问题**

$X'' + \lambda X = 0$ 的通解为 $X(x) = A\cos(\sqrt{\lambda}x) + B\sin(\sqrt{\lambda}x)$。

由 $X(0) = 0$ 得 $A = 0$；由 $X(L) = 0$ 得 $\sin(\sqrt{\lambda}L) = 0$，即 $\sqrt{\lambda}L = n\pi$。

特征值和特征函数：
$$\lambda_n = \left(\frac{n\pi}{L}\right)^2, \quad X_n(x) = \sin\frac{n\pi x}{L}, \quad n = 1, 2, 3, \ldots$$

**第三步：求解时间方程**

$$T_n(t) = C_n\cos\frac{n\pi ct}{L} + D_n\sin\frac{n\pi ct}{L}$$

**第四步：叠加**

$$u(x, t) = \sum_{n=1}^{\infty}\left[C_n\cos\frac{n\pi ct}{L} + D_n\sin\frac{n\pi ct}{L}\right]\sin\frac{n\pi x}{L}$$

**第五步：确定系数**

由初始条件 $u(x,0) = f(x)$：

$$C_n = \frac{2}{L}\int_0^L f(x)\sin\frac{n\pi x}{L}\,dx$$

由 $\frac{\partial u}{\partial t}(x,0) = g(x)$：

$$D_n = \frac{2}{n\pi c}\int_0^L g(x)\sin\frac{n\pi x}{L}\,dx$$

### 具体实例：初始位移为三角形

设 $f(x) = \begin{cases} \frac{2h}{L}x, & 0 \leq x \leq L/2 \\ \frac{2h}{L}(L-x), & L/2 \leq x \leq L \end{cases}$，$g(x) = 0$。

计算系数 $C_n$：

$$C_n = \frac{2}{L}\left[\int_0^{L/2}\frac{2hx}{L}\sin\frac{n\pi x}{L}dx + \int_{L/2}^{L}\frac{2h(L-x)}{L}\sin\frac{n\pi x}{L}dx\right]$$

$$C_n = \frac{8h}{n^2\pi^2}\sin\frac{n\pi}{2}$$

因此 $C_n$ 仅在 $n$ 为奇数时非零：$C_{2k+1} = \frac{8h}{(2k+1)^2\pi^2}(-1)^k$

## 14.2 热传导问题完整求解

### 问题描述

长度为 $L$ 的均匀细杆，初始温度分布为 $f(x)$，两端保持零度。

**数学模型**：
$$\frac{\partial u}{\partial t} = \alpha\frac{\partial^2 u}{\partial x^2}, \quad 0 < x < L, \; t > 0$$

**边界条件**：$u(0, t) = u(L, t) = 0$

**初始条件**：$u(x, 0) = f(x) = T_0\sin\frac{\pi x}{L}$

### 求解过程

**分离变量法**

同样设 $u(x, t) = X(x)T(t)$，得到：
- $X'' + \lambda X = 0$，$X(0) = X(L) = 0$ → $X_n(x) = \sin\frac{n\pi x}{L}$，$\lambda_n = \left(\frac{n\pi}{L}\right)^2$
- $T' + \alpha\lambda_n T = 0$ → $T_n(t) = e^{-\alpha(n\pi/L)^2 t}$

通解：
$$u(x, t) = \sum_{n=1}^{\infty} B_n \sin\frac{n\pi x}{L}\,e^{-\alpha(n\pi/L)^2 t}$$

**系数确定**

由于初始条件 $f(x) = T_0\sin\frac{\pi x}{L}$ 恰好是第一个特征函数的形式：

$$B_n = \frac{2}{L}\int_0^L T_0\sin\frac{\pi x}{L}\sin\frac{n\pi x}{L}\,dx = \begin{cases} T_0, & n = 1 \\ 0, & n \neq 1 \end{cases}$$

**最终解**：

$$\boxed{u(x, t) = T_0\sin\frac{\pi x}{L}\,e^{-\alpha\pi^2 t/L^2}}$$

### 物理分析

- 温度按指数规律衰减，衰减速率为 $\alpha\pi^2/L^2$
- 杆越长（$L$ 越大），衰减越慢
- 热扩散系数 $\alpha$ 越大，衰减越快
- 第一个模态（$n=1$）衰减最慢，长期行为由第一项主导

```
温度衰减示意（x = L/2 处）：

    |      *

0.0 |--------------------*--------> t
    0   τ    2τ    3τ    4τ    5τ

```

## 14.3 电磁场问题

### 波导中的电磁波

矩形波导（截面 $a \times b$）中 TM 模的电场 $E_z$ 满足 Helmholtz 方程：

$$\nabla^2 E_z + k^2 E_z = 0$$

其中 $k^2 = \omega^2\mu\epsilon - (m\pi/a)^2 - (n\pi/b)^2$。

在矩形截面内分离变量：

$$E_z(x, y, z, t) = E_0\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}\,e^{i(k_z z - \omega t)}$$

**截止频率**：

$$f_{c,mn} = \frac{1}{2\sqrt{\mu\epsilon}}\sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2}$$

频率低于截止频率的模式无法在波导中传播。

### 圆柱谐振腔

在圆柱坐标系下求解 Helmholtz 方程，径向部分导出贝塞尔方程（参见 [[10-贝塞尔函数]]）：

$$E_z = E_0 J_n\left(\frac{\alpha_{nm}r}{R}\right)\cos(n\theta)\sin\frac{p\pi z}{L}$$

其中 $\alpha_{nm}$ 是 $J_n(x)$ 的第 $m$ 个正零点。

谐振频率：

$$f_{nmp} = \frac{c}{2\pi}\sqrt{\left(\frac{\alpha_{nm}}{R}\right)^2 + \left(\frac{p\pi}{L}\right)^2}$$

## 14.4 量子力学中的应用

### 一维无限深方势阱

粒子被约束在 $0 < x < L$ 的区域内，势能为：

$$V(x) = \begin{cases} 0, & 0 < x < L \\ \infty, & \text{其他} \end{cases}$$

定态薛定谔方程：

$$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} = E\psi, \quad 0 < x < L$$

边界条件：$\psi(0) = \psi(L) = 0$（与弦振动相同！）

解为：

$$\psi_n(x) = \sqrt{\frac{2}{L}}\sin\frac{n\pi x}{L}, \quad E_n = \frac{n^2\pi^2\hbar^2}{2mL^2}$$

### 三维氢原子

径向方程：

$$-\frac{\hbar^2}{2m_e}\left[\frac{d^2R}{dr^2} + \frac{2}{r}\frac{dR}{dr}\right] + \left[\frac{l(l+1)\hbar^2}{2m_er^2} - \frac{e^2}{4\pi\epsilon_0 r}\right]R = ER$$

经过变量替换 $\rho = r/a_0$（$a_0$ 为玻尔半径），径向部分的解包含关联拉盖尔多项式（参见 [[12-其他特殊函数]]）：

$$R_{nl}(r) = N_{nl}\left(\frac{2r}{na_0}\right)^l e^{-r/(na_0)} L_{n-l-1}^{2l+1}\left(\frac{2r}{na_0}\right)$$

能量本征值：$E_n = -\frac{13.6\,\text{eV}}{n^2}$

### 氢原子波函数角度部分

角度部分由球谐函数 $Y_l^m(\theta, \phi)$ 描述（参见 [[11-勒让德多项式]]）。

## 14.5 流体力学中的应用

### Navier-Stokes 方程

不可压缩流体的 Navier-Stokes 方程：

$$\frac{\partial \mathbf{v}}{\partial t} + (\mathbf{v}\cdot\nabla)\mathbf{v} = -\frac{1}{\rho}\nabla p + \nu\nabla^2\mathbf{v} + \mathbf{f}$$

$$\nabla\cdot\mathbf{v} = 0$$

其中 $\mathbf{v}$ 为速度场，$p$ 为压力，$\rho$ 为密度，$\nu$ 为运动粘度，$\mathbf{f}$ 为体积力。

### Poiseuille 流（管内层流）

平行平板间的定常层流（一维简化）：

$$\nu\frac{d^2 v_x}{dy^2} = \frac{1}{\rho}\frac{dp}{dx}$$

解为抛物线分布：

$$v_x(y) = \frac{1}{2\mu}\left(-\frac{dp}{dx}\right)y(H-y)$$

这是 Navier-Stokes 方程在简单几何下的解析解。

### Couette 流（剪切流）

两平行板间，上板以速度 $U$ 运动：

$$v_x(y) = U\frac{y}{H}$$

线性速度分布。

### Reynolds 数与流态

**Reynolds 数**是流体力学中最重要的无量纲参数：

$$\text{Re} = \frac{\rho U L}{\mu} = \frac{UL}{\nu}$$

| Re 范围 | 流态 | 特征 |
|---------|------|------|
| $\text{Re} < 2300$（管流） | 层流 | 流线规则，粘性主导 |
| $2300 < \text{Re} < 4000$ | 过渡态 | 不稳定，可能转捩 |
| $\text{Re} > 4000$ | 湍流 | 涡旋结构，混沌行为 |


### Kármán 涡街

圆柱绕流在 $30 < \text{Re} < 300$ 范围内，圆柱后方交替脱落涡旋，形成 Kármán 涡街。涡脱落频率满足 **Strouhal 数**关系：

$$\text{St} = \frac{fD}{U} \approx 0.2 \quad (\text{Re 在 } 10^2 \sim 10^5 \text{ 范围内})$$

其中 $f$ 为涡脱落频率，$D$ 为圆柱直径，$U$ 为来流速度。

## 14.6 注意事项和常见错误

1. **模型的适用条件**：每个物理模型都有其适用范围。例如，弦振动方程假设小振幅振动（线性化）；Navier-Stokes 方程假设连续介质。

2. **量纲分析**：实际工程问题中，务必先进行量纲分析和无量纲化，避免数量级错误。

3. **边界条件的物理意义**：Dirichlet 条件对应固定值（如固定端、恒温），Neumann 条件对应固定通量（如绝热、自由端），Robin 条件对应混合约束（如对流换热）。

4. **解析解的局限性**：大多数实际问题无法获得解析解，需要借助 [[13-数值解法|数值方法]]。解析解的价值在于验证数值方法的正确性。

5. **对称性的利用**：充分分析问题的对称性可以大大简化求解过程。例如，轴对称问题可以消去 $\theta$ 方向的依赖。

## 14.7 本章小结

- **弦振动问题**通过分离变量法和傅里叶级数展开得到达朗贝尔解。
- **热传导问题**的解按指数衰减，长期行为由最低阶模态主导。
- **电磁场问题**中，矩形波导利用 [[11-勒让德多项式|正弦函数]]，圆柱谐振腔利用 [[10-贝塞尔函数|贝塞尔函数]]。
- **量子力学**中的无限深势阱与弦振动数学结构相同；氢原子径向方程的解涉及 [[12-其他特殊函数|拉盖尔多项式]]。
- **Navier-Stokes 方程**是流体力学的核心方程，层流情况下可获得解析解（Poiseuille 流、Couette 流）。
