# 常用软件工具

## 一、工具概览

### 1.1 数学建模常用工具体系

$$
\text{建模工具} = \underbrace{\text{数学计算}}_{\text{MATLAB/Python}} + \underbrace{\text{优化求解}}_{\text{LINGO/CPLEX}} + \underbrace{\text{统计分析}}_{\text{SPSS/R}} + \underbrace{\text{论文排版}}_{\text{LaTeX}} + \underbrace{\text{可视化}}_{\text{Origin/matplotlib}}
$$

### 1.2 工具选择原则

| 原则 | 说明 |
|------|------|
| 熟练优先 | 比赛时用自己最熟悉的工具 |
| 功能匹配 | 根据问题类型选择最适合的工具 |
| 协同配合 | 团队成员使用兼容的工具链 |
| 提前准备 | 赛前确认软件环境、许可证等 |

## 二、MATLAB

### 2.1 MATLAB 简介

MATLAB（Matrix Laboratory）是 MathWorks 公司开发的商业数学软件，是数学建模中最常用的工具之一。

**优势：**
- 矩阵运算能力强
- 内置大量数学函数和工具箱
- 绘图功能强大
- 文档和社区资源丰富

**劣势：**
- 商业软件，需要许可证
- 运行速度相对 Python 较慢
- 不适合处理大规模数据

### 2.2 建模常用 MATLAB 功能

#### 矩阵与线性代数

```matlab
% 矩阵运算
A = [1 2 3; 4 5 6; 7 8 9];
b = [1; 2; 3];
x = A \ b;              % 求解线性方程组 Ax = b

% 特征值分解
[V, D] = eig(A);        % V: 特征向量矩阵, D: 特征值对角矩阵

% 奇异值分解
[U, S, V] = svd(A);
```

#### 优化求解

```matlab
% 线性规划
% min f'*x, s.t. A*x <= b, Aeq*x = beq, lb <= x <= ub
f = [-1; -2];
A = [1 1; 1 -1; -1 2];
b = [2; 1; 2];
lb = [0; 0];
[x, fval] = linprog(f, A, b, [], [], lb);

% 非线性规划
fun = @(x) (x(1)-1)^2 + (x(2)-2.5)^2;
x0 = [0; 0];
options = optimoptions('fmincon', 'Display', 'iter');
[x, fval] = fmincon(fun, x0, A, b, [], [], lb, ub, [], options);

% 整数规划
intcon = [1, 2];  % 指定整数变量
[x, fval] = intlinprog(f, intcon, A, b, [], [], lb, ub);
```

#### 微分方程求解

```matlab
% 常微分方程（ODE）求解
% dy/dt = -2y + sin(t), y(0) = 1
dydt = @(t, y) -2*y + sin(t);
[t, y] = ode45(dydt, [0 10], 1);
plot(t, y);

% 带参数的ODE（用于参数拟合）
% SIR模型: dS/dt = -beta*S*I, dI/dt = beta*S*I - gamma*I
beta = 0.3; gamma = 0.1;
sir = @(t, Y) [-beta*Y(1)*Y(2); beta*Y(1)*Y(2) - gamma*Y(2)];
[t, Y] = ode45(sir, [0 100], [0.99; 0.01]);
```

#### 数据处理与拟合

```matlab
% 多项式拟合
x = [1 2 3 4 5 6];
y = [2.1 3.9 6.2 7.8 10.1 12.3];
p = polyfit(x, y, 2);     % 2次多项式拟合
y_fit = polyval(p, x);

% 自定义函数拟合
f = @(a, x) a(1)*exp(a(2)*x);
[a, resnorm] = lsqcurvefit(f, [1 0.1], x, y);
```

#### 绘图

```matlab
% 二维绘图
figure;
plot(x, y, 'r-o', 'LineWidth', 2);
xlabel('x轴标签');
ylabel('y轴标签');
title('图标题');
legend('数据点', 'Location', 'best');
grid on;

% 三维绘图
[X, Y] = meshgrid(-2:0.1:2, -2:0.1:2);
Z = X.*exp(-X.^2 - Y.^2);
surf(X, Y, Z);
colorbar;
xlabel('X'); ylabel('Y'); zlabel('Z');
title('三维曲面图');

% 热力图
imagesc(data);
colormap('jet');
colorbar;
```

### 3.4 Python 建模代码模板

```python
"""
数学建模代码模板
"""
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import optimize, integrate

# ============ 1. 数据读取与预处理 ============
def load_and_preprocess(filepath):
    """读取数据并进行预处理"""
    df = pd.read_csv(filepath)
    df = df.dropna()
    return df

# ============ 2. 模型定义 ============
def model(params, x):
    """定义数学模型"""
    a, b = params
    return a * np.exp(b * x)

# ============ 3. 参数拟合 ============
def fit_model(x_data, y_data):
    """拟合模型参数"""
    def residual(params):
        return model(params, x_data) - y_data
    
    result = optimize.least_squares(residual, [1, 0.1])
    return result.x

# ============ 4. 结果可视化 ============
def plot_results(x_data, y_data, x_fit, y_fit):
    """绘制结果"""
    plt.figure(figsize=(10, 6))
    plt.scatter(x_data, y_data, label='实际数据', color='blue')
    plt.plot(x_fit, y_fit, 'r-', label='拟合曲线', linewidth=2)
    plt.xlabel('X')
    plt.ylabel('Y')
    plt.title('模型拟合结果')
    plt.legend()
    plt.grid(True)
    plt.savefig('result.png', dpi=300)
    plt.show()

# ============ 5. 主函数 ============
if __name__ == '__main__':
    # 示例数据
    x_data = np.array([1, 2, 3, 4, 5])
    y_data = np.array([2.5, 4.8, 7.2, 9.8, 12.1])
    
    # 拟合
    params = fit_model(x_data, y_data)
    print(f"拟合参数: a={params[0]:.4f}, b={params[1]:.4f}")
    
    # 绘图
    x_fit = np.linspace(1, 5, 100)
    y_fit = model(params, x_fit)
    plot_results(x_data, y_data, x_fit, y_fit)
```

## 四、LINGO

### 4.1 LINGO 简介

LINGO 是专门用于求解**线性、非线性和整数优化问题**的软件，由 LINDO Systems 开发。

**优势：**
- 语法简洁，建模直观
- 求解优化问题效率高
- 内置建模语言，表达力强

**劣势：**
- 仅限于优化问题
- 商业软件（有教学版限制）
- 学习成本较高

### 4.2 LINGO 基础语法

**线性规划示例：**

$$
\begin{aligned}
\max \quad & z = 3x_1 + 5x_2 \\
\text{s.t.} \quad & x_1 \leq 4 \\
& 2x_2 \leq 12 \\
& 3x_1 + 2x_2 \leq 18 \\
& x_1, x_2 \geq 0
\end{aligned}
$$

**LINGO 代码：**

```
MODEL:
MAX = 3*X1 + 5*X2;
X1 <= 4;
2*X2 <= 12;
3*X1 + 2*X2 <= 18;
END
```

### 4.3 LINGO 集合与循环

```
MODEL:
SETS:
    FACTORIES /1..3/: CAPACITY;
    STORES /1..4/: DEMAND;
    LINKS(FACTORIES, STORES): COST, SHIP;
ENDSETS

DATA:
    CAPACITY = 30 25 20;
    DEMAND = 15 17 22 12;
    COST = 6 2 6 5
           4 9 5 2
           8 8 1 9;
ENDDATA

MIN = @SUM(LINKS(I,J): COST(I,J) * SHIP(I,J));

@FOR(FACTORIES(I):
    @SUM(STORES(J): SHIP(I,J)) <= CAPACITY(I)
);

@FOR(STORES(J):
    @SUM(FACTORIES(I): SHIP(I,J)) = DEMAND(J)
);

@FOR(LINKS: @GIN(SHIP));
END
```

### 4.4 LINGO 常用函数

| 函数 | 功能 | 示例 |
|------|------|------|
| `@SUM` | 求和 | `@SUM(SET(I): X(I))` |
| `@MAX` | 最大值 | `@MAX(SET(I): X(I))` |
| `@MIN` | 最小值 | `@MIN(SET(I): X(I))` |
| `@FOR` | 循环约束 | `@FOR(SET(I): X(I) >= 0)` |
| `@GIN` | 整数变量 | `@GIN(X)` |
| `@BIN` | 0-1变量 | `@BIN(Y)` |
| `@BND` | 变量界 | `@BND(0, X, 100)` |
| `@ABS` | 绝对值 | `@ABS(X - Y)` |

## 五、SPSS

### 5.1 SPSS 简介

SPSS（Statistical Package for the Social Sciences）是一款广泛使用的**统计分析软件**，以图形界面操作为主。

**优势：**
- 图形界面友好，上手快
- 统计分析功能全面
- 输出结果专业规范
- 适合非编程背景的用户

**劣势：**
- 不适合复杂建模
- 商业软件（有教学版）
- 灵活性不如 R/Python

### 5.2 SPSS 常用统计功能

#### 描述性统计

- 频率分析
- 描述统计（均值、标准差、偏度、峰度）
- 交叉表分析

#### 假设检验

| 检验方法 | 适用场景 | SPSS 操作 |
|----------|----------|-----------|
| t 检验 | 两组均值比较 | 分析 → 比较均值 → 独立样本t检验 |
| 方差分析(ANOVA) | 多组均值比较 | 分析 → 比较均值 → 单因素ANOVA |
| 卡方检验 | 分类变量关联 | 分析 → 描述统计 → 交叉表 |
| Mann-Whitney U | 非参数两组比较 | 分析 → 非参数检验 |

#### 回归分析

```
分析 → 回归 → 线性
  - 因变量：Y
  - 自变量：X1, X2, X3
  - 方法：逐步 / 强制进入
```

**输出内容：**
- 模型摘要（$R^2$, 调整 $R^2$）
- ANOVA 表（$F$ 检验）
- 系数表（$\beta$ 值、$t$ 值、$p$ 值）
- 残差图

#### 因子分析

```
分析 → 降维 → 因子
  - 变量：选择分析变量
  - 提取：主成分法
  - 旋转：最大方差法
```

### 5.3 SPSS 结果导出

- **复制粘贴**：直接将表格复制到 Word
- **导出**：文件 → 导出 → 选择格式（HTML/PDF/Excel）
- **语法输出**：保存 `.sps` 语法文件，便于复现

u(x, 0) &= u_0(x) \\
\frac{\partial u}{\partial n}\bigg|_{\partial\Omega} &= 0
\end{aligned}
$$

## 九、关键要点总结

1. **Python 和 MATLAB 是数学建模最核心的计算工具**，至少要熟练掌握一个
2. **LaTeX 是论文排版的首选**，建议赛前至少练习 2-3 篇论文的排版
3. **SPSS 适合快速统计分析**，特别适合不擅长编程的队员
4. **LINGO 适合纯优化问题**，语法简洁高效
5. **工具的选择要根据问题类型和团队能力**来决定
6. **赛前务必进行环境测试**，避免比赛中出现软件问题

## 十、常见错误

- ❌ 比赛时才开始安装软件或配置环境
- ❌ 不熟悉 LaTeX，比赛中临时学习排版
- ❌ 过度依赖 GUI 工具（SPSS），无法处理复杂建模需求
- ❌ Python 代码没有注释，事后无法理解
- ❌ MATLAB 代码大量使用循环而不用向量化，效率低下
- ❌ 图表没有保存高分辨率版本，论文中模糊不清
- ❌ 没有备份代码和论文文件
- ❌ 不同队员使用不兼容的软件版本
- ❌ 把所有计算都用 Excel 做，效率极低
- ❌ 忽略代码的可复现性（缺少随机种子设置等）
