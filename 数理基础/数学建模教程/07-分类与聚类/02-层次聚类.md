# 层次聚类算法

## 1. 算法概述

层次聚类（Hierarchical Clustering）是一种通过构建簇的**层次结构**来进行聚类的方法。与 K-means 不同，层次聚类不需要预先指定簇数，而是生成一棵**聚类树（dendrogram）**，用户可以在不同层次上切割以获得所需的簇数。

层次聚类分为两大类：

| 类型 | 英文 | 策略 | 起始状态 |
|------|------|------|----------|
| 凝聚型（自底向上） | Agglomerative | 合并 | $n$ 个数据点各为一个簇 |
| 分裂型（自顶向下） | Divisive | 分裂 | 所有数据点为一个簇 |

---

## 2. 凝聚型层次聚类（Agglomerative）

### 2.1 基本流程

**输入：** 数据集 $X = \{x_1, x_2, \dots, x_n\}$，距离矩阵 $D$

**算法步骤：**

1. **初始化：** 将每个数据点视为一个簇，共 $n$ 个簇
2. **计算距离：** 计算所有簇对之间的距离
3. **合并最近簇：** 找到距离最近的两个簇 $C_i$ 和 $C_j$，将它们合并为新簇
4. **更新距离矩阵：** 重新计算新簇与其他簇之间的距离
5. **重复：** 直到所有数据点合并为一个簇，或达到预定的簇数

### 2.2 距离矩阵的表示

初始距离矩阵 $D$ 为 $n \times n$ 的对称矩阵：

$$D_{ij} = d(x_i, x_j), \quad D_{ii} = 0, \quad D_{ij} = D_{ji}$$

---

## 3. 链接方法（Linkage Methods）

链接方法定义了如何计算两个簇之间的距离。假设有两个簇 $C_p$ 和 $C_q$，不同的链接方法给出不同的距离度量。

### 3.1 单链接（Single Linkage）

又称最近邻链接，取两簇中最近数据点之间的距离：

$$d_{\text{single}}(C_p, C_q) = \min_{x_i \in C_p, x_j \in C_q} d(x_i, x_j)$$

**性质：**
- 倾向于产生**链式效应**（chaining effect）
- 能发现**非球形**、**细长**的簇
- 对噪声和异常值**敏感**

### 3.2 完全链接（Complete Linkage）

又称最远邻链接，取两簇中最远数据点之间的距离：

$$d_{\text{complete}}(C_p, C_q) = \max_{x_i \in C_p, x_j \in C_q} d(x_i, x_j)$$

**性质：**
- 产生**紧凑**、**直径相近**的簇
- 对噪声和异常值**较不敏感**
- 倾向于产生球形簇

### 3.3 平均链接（Average Linkage / UPGMA）

取两簇中所有数据点对距离的平均值：

$$d_{\text{average}}(C_p, C_q) = \frac{1}{|C_p| \cdot |C_q|} \sum_{x_i \in C_p} \sum_{x_j \in C_q} d(x_i, x_j)$$

**性质：**
- 是单链接和完全链接的折中
- 对噪声的鲁棒性中等
- 是系统发育学中最常用的方法

### 3.4 质心链接（Centroid Linkage / UPGMC）

取两簇质心之间的距离：

$$d_{\text{centroid}}(C_p, C_q) = \| \mu_p - \mu_q \|$$

其中 $\mu_p = \frac{1}{|C_p|}\sum_{x_i \in C_p} x_i$

**性质：**
- 可能出现**倒置**（inversion）现象，即合并后的距离反而减小
- 计算相对简单

### 3.5 Ward 方法

合并后使簇内方差增加最小的两个簇：

$$\Delta_{\text{Ward}}(C_p, C_q) = \frac{|C_p| \cdot |C_q|}{|C_p| + |C_q|} \| \mu_p - \mu_q \|^2$$

等价于最小化合并后的总簇内方差增加量：

$$\Delta J = \frac{|C_p| \cdot |C_q|}{|C_p| + |C_q|} \sum_{d=1}^{D} (\bar{x}_{p,d} - \bar{x}_{q,d})^2$$

**性质：**
- 倾向于产生**大小相近**的球形簇
- 与 K-means 的目标函数有密切联系
- 实践中效果通常较好

### 3.6 链接方法对比

| 链接方法 | 倾向的簇形状 | 噪声敏感性 | 计算复杂度 |
|----------|-------------|-----------|-----------|
| Single | 长条/链状 | 高 | $O(n^2)$ |
| Complete | 紧凑/球形 | 低 | $O(n^2)$ |
| Average | 适中 | 中等 | $O(n^2)$ |
| Centroid | 球形 | 中等 | $O(n^2)$ |
| Ward | 大小相近的球形 | 低 | $O(n^2)$ |

## 4. 距离度量

### 4.1 欧氏距离

$$d(x_i, x_j) = \sqrt{\sum_{k=1}^{d} (x_{ik} - x_{jk})^2} = \| x_i - x_j \|_2$$

### 4.2 曼哈顿距离

$$d(x_i, x_j) = \sum_{k=1}^{d} |x_{ik} - x_{jk}| = \| x_i - x_j \|_1$$

### 4.3 闵可夫斯基距离

$$d(x_i, x_j) = \left( \sum_{k=1}^{d} |x_{ik} - x_{jk}|^p \right)^{1/p} = \| x_i - x_j \|_p$$

### 4.4 余弦距离

$$d_{\cos}(x_i, x_j) = 1 - \cos(x_i, x_j) = 1 - \frac{x_i \cdot x_j}{\|x_i\| \|x_j\|}$$

## 5. 分裂型层次聚类（Divisive）

### 5.1 基本思想

与凝聚型相反，分裂型从**一个大簇**开始，逐步将其分裂为更小的簇。

**算法步骤：**

1. 将所有数据点放入一个簇
2. 选择一个簇进行分裂（通常选择最"不纯"的簇）
3. 使用二分 K-means 或其他方法将其分为两个子簇
4. 重复直到每个数据点自成一个簇，或达到预定的簇数

### 5.2 DIANA 算法

DIANA（Divisive Analysis）是最经典的分裂型层次聚类算法：

**分裂判据 — 直径（diameter）：**

$$\text{diam}(C) = \max_{x_i, x_j \in C} d(x_i, x_j)$$

**算法流程：**

1. 从包含所有数据点的簇开始
2. 找到直径最大的簇
3. 在该簇中找到**最相异**的数据点（平均相异度最高）
4. 用单链接思想逐步将其他点分配到该点的"近邻"簇中
5. 产生两个子簇
6. 重复直到簇数满足要求

## 6. 树状图（Dendrogram）

### 6.1 树状图的解读

树状图是层次聚类结果的可视化表示：

- **横轴**：数据点（或簇标签）
- **纵轴**：合并时的距离（高度）
- **分支**：表示簇的合并关系

通过在不同高度画水平线，可以得到不同数量的簇：

$$\text{在高度 } h \text{ 处切割} \Rightarrow \text{得到若干个簇}$$

### 6.2 一致性系数

一致性系数（Cophenetic Correlation）衡量树状图保持原始距离关系的程度：

$$C_{\text{coph}} = \frac{\sum_{i<j} (d_{ij} - \bar{d})(c_{ij} - \bar{c})}{\sqrt{\sum_{i<j}(d_{ij} - \bar{d})^2 \cdot \sum_{i<j}(c_{ij} - \bar{c})^2}}$$

其中 $d_{ij}$ 为原始距离，$c_{ij}$ 为树状图中的一致性距离（两个点首次被合并到同一簇时的高度）。

$C_{\text{coph}}$ 越接近 1，说明层次结构越能保持原始距离关系。

---

## 7. 复杂度分析

| 操作 | 凝聚型 | 分裂型 |
|------|--------|--------|
| 距离矩阵计算 | $O(n^2 d)$ | $O(n^2 d)$ |
| 每步最近对查找 | $O(n^2)$ | $O(n^2)$ |
| 总时间复杂度 | $O(n^3)$ | $O(2^n)$（最坏情况） |
| 空间复杂度 | $O(n^2)$ | $O(n^2)$ |

对于大规模数据，可使用**优化算法**降低复杂度：
- **SLINK**（单链接）：$O(n^2)$
- **CLINK**（完全链接）：$O(n^2)$

## 8. Python 实现

### 8.1 基本层次聚类

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import AgglomerativeClustering
from sklearn.datasets import make_moons, make_blobs
from scipy.cluster.hierarchy import dendrogram, linkage, fcluster
from scipy.spatial.distance import pdist
from sklearn.metrics import silhouette_score

X, y_true = make_blobs(n_samples=200, centers=4, cluster_std=0.8, random_state=42)

agg = AgglomerativeClustering(n_clusters=4, linkage='ward')
y_pred = agg.fit_predict(X)

print(f"轮廓系数: {silhouette_score(X, y_pred):.4f}")

fig, ax = plt.subplots(figsize=(8, 6))
scatter = ax.scatter(X[:, 0], X[:, 1], c=y_pred, cmap='viridis', s=50, alpha=0.7)
ax.set_title('凝聚型层次聚类结果 (Ward 链接)')
plt.tight_layout()
plt.show()
```

### 8.2 树状图可视化

```python
Z = linkage(X, method='ward', metric='euclidean')

fig, ax = plt.subplots(figsize=(14, 7))
dendrogram(
    Z,
    truncate_mode='lastp',
    p=30,
    leaf_rotation=90,
    leaf_font_size=10,
    show_contracted=True,
    ax=ax
)
ax.set_title('树状图 (Ward 链接)')
ax.set_xlabel('样本索引或簇大小')
ax.set_ylabel('距离')
plt.tight_layout()
plt.show()
```

### 8.3 不同链接方法对比

```python
X, y_true = make_moons(n_samples=300, noise=0.1, random_state=42)

linkages = ['ward', 'complete', 'average', 'single']
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

for ax, link in zip(axes.flat, linkages):
    agg = AgglomerativeClustering(n_clusters=2, linkage=link)
    labels = agg.fit_predict(X)
    sil = silhouette_score(X, labels) if len(set(labels)) > 1 else 0
    ax.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis', s=30, alpha=0.7)
    ax.set_title(f'{link} linkage (轮廓系数: {sil:.3f})')

plt.tight_layout()
plt.show()
```

### 8.4 利用树状图确定簇数

```python
def find_optimal_clusters(Z, max_k=10):
    last_merges = Z[-max_k:, 2]
    last_distances = last_merges[::-1]
    differences = np.diff(last_distances)

    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

    ax1.plot(range(1, max_k + 1), last_distances, 'bo-')
    ax1.set_xlabel('簇数')
    ax1.set_ylabel('合并距离')
    ax1.set_title('合并距离变化')

    ax2.plot(range(2, max_k + 1), differences, 'rs-')
    ax2.set_xlabel('簇数变化')
    ax2.set_ylabel('距离差')
    ax2.set_title('距离差的跳变')

    plt.tight_layout()
    plt.show()

    best_k = np.argmax(differences) + 2
    return best_k

Z = linkage(X, method='ward')
optimal_k = find_optimal_clusters(Z)
print(f"推荐簇数: {optimal_k}")
```

## 9. 实际案例：基因表达聚类

```python
import pandas as pd

np.random.seed(42)
n_genes = 100
n_conditions = 8

gene_names = [f'Gene_{i}' for i in range(n_genes)]
condition_names = [f'Cond_{j}' for j in range(n_conditions)]

expression_data = np.vstack([
    np.random.normal(3, 0.5, (25, n_conditions)),
    np.random.normal(7, 0.5, (25, n_conditions)),
    np.random.normal(5, 1.0, (25, n_conditions)),
    np.random.normal(1, 0.3, (25, n_conditions))
])

df = pd.DataFrame(expression_data, index=gene_names, columns=condition_names)

Z_gene = linkage(df.values, method='average', metric='correlation')

fig, ax = plt.subplots(figsize=(16, 6))
dendrogram(Z_gene, labels=gene_names, leaf_rotation=90, leaf_font_size=6, ax=ax)
ax.set_title('基因表达数据的层次聚类树状图')
ax.set_ylabel('相关距离')
plt.tight_layout()
plt.show()

labels = fcluster(Z_gene, t=3, criterion='maxclust')
print(f"在3个簇时的聚类分配:")
for k in range(1, 4):
    genes_in_cluster = [g for g, l in zip(gene_names, labels) if l == k]
    print(f"  簇 {k}: {len(genes_in_cluster)} 个基因")
```

## 10. 凝聚型与分裂型的对比

| 特性 | 凝聚型 | 分裂型 |
|------|--------|--------|
| 方向 | 自底向上 | 自顶向下 |
| 复杂度 | $O(n^3)$ | 最坏 $O(2^n)$ |
| 全局最优性 | 局部贪婪 | 可能更全局 |
| 适用规模 | 中等规模 | 较小规模 |
| 实现难度 | 简单 | 较复杂 |
| 应用广泛度 | 高 | 低 |

---

## 11. 关键要点总结

| 要点 | 说明 |
|------|------|
| 核心思想 | 构建簇的层次树结构 |
| 凝聚型 | 从 $n$ 个单点簇逐步合并 |
| 分裂型 | 从一个大簇逐步分裂 |
| Ward 方法 | 最小化簇内方差增加，实践中效果好 |
| 单链接 | 容易产生链式效应 |
| 完全链接 | 产生紧凑的球形簇 |
| 树状图 | 直观展示层次结构，在不同高度切割得到不同簇数 |
| 距离矩阵 | 空间复杂度 $O(n^2)$，限制了在大规模数据上的应用 |
| 一致性系数 | 评估层次结构保持原始距离关系的程度 |
| 适用场景 | 需要层次结构、不确定簇数、中等规模数据 |

层次聚类的最大优势在于其**层次化的结果表示**，允许用户在不同粒度上理解数据的聚类结构，这在生物学、社会科学等领域尤为重要。
