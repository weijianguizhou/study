# 决策树算法

> **理论基础** → 参见 [[../../机器学习数学基础/决策树与集成学习|决策树与集成学习]]

决策树通过树状结构进行决策和分类，可解释性强，是集成学习的基础组件。

## 3. 经典决策树算法
### 3.1 ID3 算法

**选择标准：** 信息增益 $g(D, A)$

**算法流程：**

```
输入: 训练数据集 D, 特征集 A
输出: 决策树 T

1. if D 中所有样本属于同一类别 then:
2.   return 叶节点（该类别）
3. end if
4. if A 为空集 then:
5.   return 叶节点（D 中最多的类别）
6. end if
7. 从 A 中选择信息增益最大的特征 A*
8. for A* 的每个取值 v do:
9.   令 D_v 为 D 中 A* = v 的子集
10.  if D_v 为空 then:
11.    return 叶节点（D 中最多的类别）
12.  else:
13.    递归构建子树 T_v = ID3(D_v, A \ {A*})
14.  end if
15. end for
16. 以 A* 为根节点，将各子树 T_v 作为分支
17. return T
```

**局限性：**
- 只能处理离散特征
- 对取值多的特征有偏好（信息增益的固有缺陷）
- 不能进行剪枝

### 3.2 C4.5 算法

**选择标准：** 信息增益率 $g_R(D, A)$

**改进点：**

1. **使用增益率**而非信息增益
2. **处理连续特征**：通过二分法将连续特征离散化
   - 将特征 $A$ 的取值排序：$a_1 < a_2 < \cdots < a_m$
   - 在每个候选分裂点 $a_i = \frac{a_i + a_{i+1}}{2}$ 处二分
   - 选择使增益率最大的分裂点
3. **处理缺失值**：
   - 训练时：按非缺失样本的比例分配到各分支
   - 预测时：沿所有分支按概率加权
4. **后剪枝**：先生成完整的树，再自底向上剪枝

**连续特征的二分法：**

$$g_R(D, A, t) = \frac{g(D, A, t)}{H_A(D, t)}$$

其中：
$$g(D, A, t) = H(D) - \frac{|D_{A \leq t}|}{|D|} H(D_{A \leq t}) - \frac{|D_{A > t}|}{|D|} H(D_{A > t})$$

### 3.3 CART 算法

CART（Classification and Regression Trees）可以同时处理分类和回归任务。

**分类任务选择标准：** 基尼指数

**回归任务选择标准：** 均方误差（MSE）

$$\min_{A, s} \left[ \min_{c_1} \sum_{x_i \in R_1(A, s)} (y_i - c_1)^2 + \min_{c_2} \sum_{x_i \in R_2(A, s)} (y_i - c_2)^2 \right]$$

其中 $R_1(A, s) = \{x | x_A \leq s\}$，$R_2(A, s) = \{x | x_A > s\}$，$c_1, c_2$ 分别为两个区域的均值。

**CART 只产生二叉树。**

## 5. 三种算法对比
| 特性 | ID3 | C4.5 | CART |
|------|-----|------|------|
| 树类型 | 多叉树 | 多叉树 | 二叉树 |
| 选择准则 | 信息增益 | 增益率 | 基尼指数 |
| 连续特征 | 不支持 | 支持（二分法） | 支持 |
| 缺失值 | 不支持 | 支持 | 支持 |
| 剪枝 | 不支持 | 后剪枝 | 预剪枝 + 后剪枝 |
| 回归 | 不支持 | 不支持 | 支持 |

## 7. Python 实现
### 7.1 基本决策树

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeClassifier, plot_tree, export_text
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import accuracy_score, classification_report

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42
)

dt_gini = DecisionTreeClassifier(criterion='gini', max_depth=3, random_state=42)
dt_gini.fit(X_train, y_train)

dt_entropy = DecisionTreeClassifier(criterion='entropy', max_depth=3, random_state=42)
dt_entropy.fit(X_train, y_train)

print(f"Gini 准确率: {accuracy_score(y_test, dt_gini.predict(X_test)):.4f}")
print(f"Entropy 准确率: {accuracy_score(y_test, dt_entropy.predict(X_test)):.4f}")
```

fig, ax = plt.subplots(figsize=(20, 10))

### 7.3 参数对过拟合的影响

```python
max_depths = range(1, 20)
train_scores = []
test_scores = []

for depth in max_depths:
    dt = DecisionTreeClassifier(max_depth=depth, random_state=42)
    dt.fit(X_train, y_train)
    train_scores.append(accuracy_score(y_train, dt.predict(X_train)))
    test_scores.append(accuracy_score(y_test, dt.predict(X_test)))

fig, ax = plt.subplots(figsize=(10, 6))
ax.plot(max_depths, train_scores, 'b-o', label='训练集准确率')
ax.plot(max_depths, test_scores, 'r-o', label='测试集准确率')
ax.set_xlabel('树的最大深度')
ax.set_ylabel('准确率')
ax.set_title('决策树深度 vs 准确率 (过拟合分析)')
ax.legend()
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

### 7.4 代价复杂度剪枝

```python
path = dt_gini.cost_complexity_pruning_path(X_train, y_train)
ccp_alphas = path.ccp_alphas
impurities = path.impurities

clfs = []
for ccp_alpha in ccp_alphas:
    clf = DecisionTreeClassifier(random_state=42, ccp_alpha=ccp_alpha)
    clf.fit(X_train, y_train)
    clfs.append(clf)

train_scores_ccp = [accuracy_score(y_train, clf.predict(X_train)) for clf in clfs]
test_scores_ccp = [accuracy_score(y_test, clf.predict(X_test)) for clf in clfs]

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

ax1.plot(ccp_alphas, impurities, 'g-')
ax1.set_xlabel('α (复杂度参数)')
ax1.set_ylabel('总叶节点不纯度')
ax1.set_title('α vs 不纯度')

ax2.plot(ccp_alphas, train_scores_ccp, 'b-o', markersize=3, label='训练集')
ax2.plot(ccp_alphas, test_scores_ccp, 'r-o', markersize=3, label='测试集')
ax2.set_xlabel('α')
ax2.set_ylabel('准确率')
ax2.set_title('α vs 准确率')
ax2.legend()

plt.tight_layout()
plt.show()

best_alpha = ccp_alphas[np.argmax(test_scores_ccp)]
print(f"最佳 α: {best_alpha:.6f}")
print(f"最佳测试准确率: {max(test_scores_ccp):.4f}")
```

## 8. 回归决策树
```python
from sklearn.tree import DecisionTreeRegressor
from sklearn.metrics import mean_squared_error, r2_score

np.random.seed(42)
X_reg = np.sort(5 * np.random.rand(200, 1), axis=0)
y_reg = np.sin(X_reg).ravel() + np.random.normal(0, 0.2, X_reg.shape[0])

X_train_r, X_test_r, y_train_r, y_test_r = train_test_split(X_reg, y_reg, test_size=0.3, random_state=42)

depths = [2, 5, 10, None]
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

for ax, depth in zip(axes.flat, depths):
    dtr = DecisionTreeRegressor(max_depth=depth, random_state=42)
    dtr.fit(X_train_r, y_train_r)
    y_pred_r = dtr.predict(X_test_r)
    r2 = r2_score(y_test_r, y_pred_r)

    X_plot = np.linspace(X_reg.min(), X_reg.max(), 500).reshape(-1, 1)
    y_plot = dtr.predict(X_plot)

    ax.scatter(X_train_r, y_train_r, s=10, alpha=0.5, label='训练')
    ax.scatter(X_test_r, y_test_r, s=10, alpha=0.5, label='测试')
    ax.plot(X_plot, y_plot, 'r-', linewidth=2, label='预测')
    ax.set_title(f'max_depth={depth} (R²={r2:.3f})')
    ax.legend()

plt.tight_layout()
plt.show()
```

## 9. 实际案例：信用风险评估
```python
import pandas as pd

np.random.seed(42)
n = 500
credit_data = pd.DataFrame({
    '年龄': np.random.randint(18, 65, n),
    '年收入': np.random.lognormal(10.5, 0.5, n).astype(int),
    '负债比': np.random.uniform(0, 0.8, n),
    '信用历史(年)': np.random.randint(0, 30, n),
    '是否有违约': np.random.choice([0, 1], n, p=[0.8, 0.2])
})

X_credit = credit_data.drop('是否有违约', axis=1)
y_credit = credit_data['是否有违约']

X_tr, X_te, y_tr, y_te = train_test_split(X_credit, y_credit, test_size=0.3, random_state=42)

dt_credit = DecisionTreeClassifier(
    max_depth=4, min_samples_leaf=10, random_state=42
)
dt_credit.fit(X_tr, y_tr)

print(f"准确率: {accuracy_score(y_te, dt_credit.predict(X_te)):.4f}")
print(classification_report(y_te, dt_credit.predict(X_te)))

fig, ax = plt.subplots(figsize=(16, 8))
plot_tree(dt_credit, feature_names=list(X_credit.columns),
          class_names=['低风险', '高风险'], filled=True, ax=ax, fontsize=9)
ax.set_title('信用风险评估决策树')
plt.tight_layout()
plt.show()
```

## 10. 优缺点总结
### 优点

1. **可解释性强**：决策过程直观，易于理解
2. **无假设**：不要求数据分布假设
3. **处理混合类型**：可同时处理数值和类别特征
4. **对缺失值鲁棒**：C4.5 和 CART 可处理缺失值
5. **计算效率高**：预测时间 $O(\log n)$

### 缺点

1. **容易过拟合**：需要剪枝或限制深度
2. **不稳定**：数据的微小变化可能导致完全不同的树
3. **贪心算法**：不能保证全局最优
4. **对类别不平衡敏感**：偏向于多数类
5. **轴对齐决策边界**：只能学习轴平行的划分

## 11. 关键要点总结
| 要点 | 说明 |
|------|------|
| ID3 | 使用信息增益，处理离散特征 |
| C4.5 | 使用增益率，支持连续特征和缺失值 |
| CART | 使用基尼指数（分类）/ MSE（回归），生成二叉树 |
| 信息熵 | $H(D) = -\sum p_k \log_2 p_k$，衡量不确定性 |
| 基尼指数 | $\text{Gini}(D) = 1 - \sum p_k^2$，衡量不纯度 |
| 剪枝 | 预剪枝（简单但可能欠拟合）vs 后剪枝（更优但计算量大） |
| 特征重要性 | 基于不纯度减少的加权和 |
| 过拟合控制 | max_depth, min_samples_leaf, ccp_alpha |
| 适用场景 | 需要可解释性、混合类型特征、快速原型 |
| 核心局限 | 不稳定、轴对齐边界、贪心优化 |

决策树是更复杂集成方法（随机森林、梯度提升树等）的基础，理解决策树的原理对于掌握这些高级算法至关重要。
