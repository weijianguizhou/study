# 随机森林算法

## 1. 算法概述

随机森林（Random Forest）是由 Leo Breiman 于 2001 年提出的一种基于 **Bagging** 和 **随机子空间** 的集成学习算法。它通过构建多棵决策树并综合它们的预测结果来提高分类或回归的性能和稳定性。

### 核心思想

$$\text{随机森林} = \text{Bagging} + \text{随机特征选择} + \text{决策树}$$

通过对训练数据和特征的**双重随机采样**，构建大量**多样性**的决策树，再通过**投票**或**平均**得到最终预测。

---

## 2. 集成学习基础

### 2.1 集成学习的动机

单个学习器（如决策树）容易过拟合且不稳定。集成学习通过组合多个学习器来提升性能。

**定理（集成误差界）：** 如果每个学习器的错误率为 $\epsilon < 0.5$，且学习器之间相互独立，则 $T$ 个学习器的多数投票错误率为：

$$P(\text{error}) = \sum_{k=\lceil T/2 \rceil}^{T} \binom{T}{k} \epsilon^k (1-\epsilon)^{T-k}$$

当 $T$ 足够大时，该误差趋近于 0。

### 2.2 Bagging（Bootstrap Aggregating）

Bagging 是 Breiman 于 1996 年提出的并行式集成方法：

**步骤：**

1. 从训练集 $D$（$|D| = n$）中有放回地抽取 $T$ 个 bootstrap 样本 $D_1, D_2, \dots, D_T$
2. 在每个 bootstrap 样本 $D_t$ 上训练一个基学习器 $h_t$
3. 最终预测：
   - 分类：多数投票 $H(x) = \arg\max_y \sum_{t=1}^{T} \mathbb{1}(h_t(x) = y)$
   - 回归：平均 $H(x) = \frac{1}{T}\sum_{t=1}^{T} h_t(x)$

**Bootstrap 样本的性质：**

每个 bootstrap 样本包含约 $63.2\%$ 的原始数据（$1 - (1 - \frac{1}{n})^n \approx 1 - e^{-1} \approx 0.632$），约 $36.8\%$ 的数据未被选中（out-of-bag, OOB）。

### 2.3 Bagging 降低方差

Bagging 的核心作用是**降低方差**（variance reduction）：

$$\text{Var}\left(\frac{1}{T}\sum_{t=1}^{T} h_t(x)\right) = \rho \sigma^2 + \frac{1-\rho}{T}\sigma^2$$

其中：
- $\sigma^2$ 是单棵树的方差
- $\rho$ 是树之间的平均相关系数
- $T$ 是树的数量

**降低方差的两个途径：**
1. 减小 $\rho$（树之间的相关性）→ **随机特征选择**
2. 增大 $T$（树的数量）→ **更多树**

---

## 3. 随机森林的随机性来源

### 3.1 数据随机性（Bootstrap）

每棵树使用从原始训练集中有放回采样的 bootstrap 样本。

### 3.2 特征随机性（随机子空间）

在决策树的每个节点分裂时，不是从所有 $d$ 个特征中选择最优特征，而是从随机选择的 $m$ 个特征子集中选择：

- **分类问题：** 通常 $m = \lfloor\sqrt{d}\rfloor$
- **回归问题：** 通常 $m = \lfloor d/3 \rfloor$

**数学分析：**

设两棵树在某节点上使用相同的最优特征的概率为：

$$P_{\text{same}} = \frac{\binom{d-1}{m-1}}{\binom{d}{m}} = \frac{m}{d}$$

当 $m = \sqrt{d}$ 时，$P_{\text{same}} = \frac{1}{\sqrt{d}}$，随维度增大而减小，有效降低了树之间的相关性。

---

## 4. 算法流程

### 4.1 训练过程

```
输入: 训练集 D, 树的数量 T, 特征子集大小 m
输出: 随机森林 {h_1, h_2, ..., h_T}

for t = 1 to T do:
  1. 从 D 中有放回抽取 bootstrap 样本 D_t
  2. 在 D_t 上构建决策树 h_t:
     - 每个节点分裂时，从 m 个随机特征中选择最优分裂
     - 递归生长直到停止条件
  3. 不进行剪枝（让树充分生长）
end for
return {h_1, h_2, ..., h_T}
```

### 4.4 预测过程

**分类：**

$$\hat{y} = \arg\max_{k} \sum_{t=1}^{T} \mathbb{1}(h_t(x) = k)$$

**回归：**

$$\hat{y} = \frac{1}{T} \sum_{t=1}^{T} h_t(x)$$

---

## 5. Out-of-Bag（OOB）估计

### 5.1 OOB 原理

每个 bootstrap 样本约有 $36.8\%$ 的数据未被使用。对于第 $i$ 个样本，只有在那些**未使用**该样本的树上进行预测：

$$\hat{y}_i^{\text{OOB}} = \arg\max_k \sum_{t: x_i \notin D_t} \mathbb{1}(h_t(x_i) = k)$$

OOB 估计近似等价于交叉验证，可以用来：
- 估计泛化误差
- 选择超参数
- 无需额外的验证集

### 5.2 OOB 误差

$$\text{OOB error} = \frac{1}{n} \sum_{i=1}^{n} \mathbb{1}(y_i \neq \hat{y}_i^{\text{OOB}})$$

---

## 6. 特征重要性

### 6.1 基于不纯度的重要性（Mean Decrease Impurity, MDI）

特征 $X_j$ 的重要性为该特征在所有树中带来的不纯度减少的总和：

$$\text{FI}_{\text{MDI}}(X_j) = \frac{1}{T} \sum_{t=1}^{T} \sum_{v \in \text{nodes}_t} \mathbb{1}(\text{split feature}_v = X_j) \cdot \Delta I_v$$

其中 $\Delta I_v$ 是节点 $v$ 处的不纯度减少：

$$\Delta I_v = I(D_v) - \frac{|D_{v,L}|}{|D_v|} I(D_{v,L}) - \frac{|D_{v,R}|}{|D_v|} I(D_{v,R})$$

### 6.2 基于排列的重要性（Mean Decrease Accuracy, MDA）

通过随机打乱特征 $X_j$ 的值来衡量其重要性：

$$\text{FI}_{\text{MDA}}(X_j) = \frac{1}{T}\sum_{t=1}^{T} \left[\text{Acc}_t(D) - \text{Acc}_t(D_{\pi_j})\right]$$

其中 $D_{\pi_j}$ 是将特征 $X_j$ 的值随机打乱后的数据集。

**优点：** 考虑了特征之间的交互作用，更可靠。

### 6.3 SHAP 值

基于 Shapley 值的特征重要性提供了更精细的特征贡献度量：

$$\phi_j = \sum_{S \subseteq N \setminus \{j\}} \frac{|S|!(|N|-|S|-1)!}{|N|!}[f(S \cup \{j\}) - f(S)]$$

---

## 7. 数学性质

### 7.1 泛化误差界

随机森林的泛化误差随着树的数量 $T$ 增加而收敛：

$$P(E_t - E_{RF} > \epsilon) \leq \exp\left(-\frac{2T\epsilon^2}{c^2}\right)$$

其中 $E_t$ 是单棵树的误差，$E_{RF}$ 是随机森林的误差，$c$ 是常数。

### 7.2 相关性与方差

设单棵树的方差为 $\sigma^2$，树之间的相关系数为 $\rho$：

$$\text{Var}_{RF} = \rho \sigma^2 + \frac{1-\rho}{T}\sigma^2$$

- 当 $T \to \infty$：$\text{Var}_{RF} \to \rho \sigma^2$
- 随机特征选择通过减小 $\rho$ 来降低方差

### 7.3 一致性条件

Breiman 证明，随机森林在以下条件下是一致的（consistent）：

1. 随着 $T \to \infty$，每棵树的误差趋近于贝叶斯误差
2. 特征子集大小 $m$ 不随样本量 $n$ 增长太快

## 8. Python 实现

### 8.1 基本随机森林

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import accuracy_score, classification_report

X, y = make_classification(n_samples=1000, n_features=20, n_informative=10,
                           n_redundant=5, n_clusters_per_class=2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

rf = RandomForestClassifier(
    n_estimators=100,
    max_depth=None,
    min_samples_split=2,
    max_features='sqrt',
    oob_score=True,
    random_state=42,
    n_jobs=-1
)
rf.fit(X_train, y_train)

y_pred = rf.predict(X_test)
print(f"OOB Score: {rf.oob_score_:.4f}")
print(f"测试集准确率: {accuracy_score(y_test, y_pred):.4f}")
print(classification_report(y_test, y_pred))
```

### 8.2 树数量与性能

```python
n_trees_range = [1, 5, 10, 20, 50, 100, 200, 300, 500]
oob_scores = []
test_scores = []

for n_trees in n_trees_range:
    rf = RandomForestClassifier(n_estimators=n_trees, oob_score=True, random_state=42, n_jobs=-1)
    rf.fit(X_train, y_train)
    oob_scores.append(rf.oob_score_)
    test_scores.append(accuracy_score(y_test, rf.predict(X_test)))

fig, ax = plt.subplots(figsize=(10, 6))
ax.plot(n_trees_range, oob_scores, 'b-o', label='OOB 准确率')
ax.plot(n_trees_range, test_scores, 'r-o', label='测试集准确率')
ax.set_xlabel('树的数量')
ax.set_ylabel('准确率')
ax.set_title('随机森林：树的数量 vs 准确率')
ax.legend()
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

## 9. 随机森林回归

```python
from sklearn.metrics import mean_squared_error, r2_score

np.random.seed(42)
X_reg = np.sort(5 * np.random.rand(200, 1), axis=0)
y_reg = np.sin(X_reg).ravel() + np.random.normal(0, 0.2, X_reg.shape[0])

X_tr_r, X_te_r, y_tr_r, y_te_r = train_test_split(X_reg, y_reg, test_size=0.3, random_state=42)

rf_reg = RandomForestRegressor(n_estimators=100, random_state=42)
rf_reg.fit(X_tr_r, y_tr_r)

X_plot = np.linspace(X_reg.min(), X_reg.max(), 500).reshape(-1, 1)
y_plot = rf_reg.predict(X_plot)

y_pred_r = rf_reg.predict(X_te_r)

fig, ax = plt.subplots(figsize=(10, 6))
ax.scatter(X_tr_r, y_tr_r, s=15, alpha=0.5, label='训练')
ax.scatter(X_te_r, y_te_r, s=15, alpha=0.5, label='测试')
ax.plot(X_plot, y_plot, 'r-', linewidth=2, label='RF 预测')
ax.fill_between(X_plot.ravel(),
                rf_reg.predict(X_plot) - np.std([t.predict(X_plot) for t in rf_reg.estimators_], axis=0),
                rf_reg.predict(X_plot) + np.std([t.predict(X_plot) for t in rf_reg.estimators_], axis=0),
                alpha=0.2, color='red')
ax.set_title(f'随机森林回归 (R²={r2_score(y_te_r, y_pred_r):.3f})')
ax.legend()
plt.tight_layout()
plt.show()
```

## 10. 实际案例：特征选择

```python
from sklearn.feature_selection import SelectFromModel

np.random.seed(42)
n_samples, n_features = 500, 50
X_fs = np.random.randn(n_samples, n_features)
true_coefs = np.zeros(n_features)
true_coefs[:5] = [3, -2, 1.5, -1, 0.5]
y_fs = X_fs @ true_coefs + np.random.randn(n_samples) * 0.5

X_tr_fs, X_te_fs, y_tr_fs, y_te_fs = train_test_split(X_fs, y_fs, test_size=0.3, random_state=42)

rf_fs = RandomForestRegressor(n_estimators=200, random_state=42)
rf_fs.fit(X_tr_fs, y_tr_fs)

selector = SelectFromModel(rf_fs, threshold='median', prefit=True)
X_tr_selected = selector.transform(X_tr_fs)
X_te_selected = selector.transform(X_te_fs)

selected_features = np.where(selector.get_support())[0]
print(f"选择的特征: {selected_features}")
print(f"选择前: {X_tr_fs.shape[1]} 特征 → 选择后: {X_tr_selected.shape[1]} 特征")

from sklearn.linear_model import LinearRegression
lr_full = LinearRegression().fit(X_tr_fs, y_tr_fs)
lr_selected = LinearRegression().fit(X_tr_selected, y_tr_fs)
print(f"全部特征 R²: {lr_full.score(X_te_fs, y_te_fs):.4f}")
print(f"选择后 R²: {lr_selected.score(X_te_selected, y_te_fs):.4f}")
```

## 11. 优缺点总结

### 优点

1. **泛化能力强**：集成多棵树，不易过拟合
2. **对高维数据友好**：随机特征选择降低维度影响
3. **可处理缺失值**：通过代理分裂处理
4. **特征重要性**：自然提供特征重要性度量
5. **并行化**：各棵树独立训练，易于并行
6. **对异常值鲁棒**：Bootstrap 采样降低异常值影响
7. **无需特征缩放**：基于树的方法不依赖距离度量

### 缺点

1. **可解释性降低**：比单棵决策树更难解释
2. **存储开销大**：需要存储 $T$ 棵树
3. **预测速度**：需要遍历所有树
4. **对噪声大的回归问题**：可能过拟合
5. **对类别不平衡**：可能偏向多数类

---

## 12. 关键要点总结

| 要点 | 说明 |
|------|------|
| 核心思想 | Bagging + 随机特征选择 |
| 两个随机性 | Bootstrap 数据采样 + 随机特征子集 |
| 方差降低 | $\text{Var} = \rho\sigma^2 + \frac{(1-\rho)\sigma^2}{T}$ |
| OOB 估计 | 约 36.8% 未用数据可做验证，近似等价交叉验证 |
| 特征重要性 | MDI（基于不纯度）和 MDA（基于排列） |
| 默认参数 | $m = \sqrt{d}$（分类），$m = d/3$（回归） |
| 树数量 | 越多越好（但收益递减），通常 100-500 |
| 过拟合控制 | 不剪枝，靠集成降低过拟合 |
| 适用场景 | 中等规模数据，需要特征重要性，基线模型 |

随机森林是机器学习中最常用的算法之一，以其**稳定性好、效果可靠、调参简单**而著称，是实际项目中首选的基线模型之一。
