# 支持向量机（SVM）

## 1. 算法概述

支持向量机（Support Vector Machine, SVM）是由 Vladimir Vapnik 等人于 1990 年代提出的一种监督学习算法。SVM 的核心思想是找到一个**最优超平面**，使得不同类别之间的**间隔（margin）最大化**。

### 核心思想

给定线性可分的训练数据 $\{(x_i, y_i)\}_{i=1}^{n}$，其中 $x_i \in \mathbb{R}^d$，$y_i \in \{-1, +1\}$，SVM 寻找一个决策超平面：

$$w \cdot x + b = 0$$

使得两类数据之间的间隔最大化。

---

## 2. 线性可分 SVM（硬间隔）

### 2.1 间隔的定义

决策超平面 $w \cdot x + b = 0$ 到数据点 $x_i$ 的函数间隔：

$$\hat{\gamma}_i = y_i(w \cdot x_i + b)$$

几何间隔（考虑 $\|w\|$ 的归一化）：

$$\gamma_i = \frac{y_i(w \cdot x_i + b)}{\|w\|}$$

### 2.2 最大间隔优化问题

SVM 的目标是最大化所有点到超平面的最小几何间隔：

$$\max_{w, b} \min_i \gamma_i = \max_{w, b} \min_i \frac{y_i(w \cdot x_i + b)}{\|w\|}$$

通过缩放 $w$ 和 $b$，可以令 $\min_i y_i(w \cdot x_i + b) = 1$，则优化问题等价于：

$$\min_{w, b} \frac{1}{2} \|w\|^2$$

$$\text{s.t.} \quad y_i(w \cdot x_i + b) \geq 1, \quad i = 1, 2, \dots, n$$

### 2.3 支持向量

使约束 $y_i(w \cdot x_i + b) = 1$ 取等号的数据点称为**支持向量（Support Vectors）**。这些点恰好位于间隔边界上，是决定最优超平面的关键数据点。

间隔的宽度为：

$$\text{margin} = \frac{2}{\|w\|}$$

---

## 3. 对偶问题

### 3.1 拉格朗日对偶

引入拉格朗日乘子 $\alpha_i \geq 0$，构造拉格朗日函数：

$$L(w, b, \alpha) = \frac{1}{2}\|w\|^2 - \sum_{i=1}^{n} \alpha_i [y_i(w \cdot x_i + b) - 1]$$

对 $w$ 和 $b$ 求偏导并令其为零：

$$\frac{\partial L}{\partial w} = 0 \Rightarrow w = \sum_{i=1}^{n} \alpha_i y_i x_i$$

$$\frac{\partial L}{\partial b} = 0 \Rightarrow \sum_{i=1}^{n} \alpha_i y_i = 0$$

### 3.2 对偶问题

将上述关系代入拉格朗日函数，得到对偶问题：

$$\max_{\alpha} \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (x_i \cdot x_j)$$

$$\text{s.t.} \quad \alpha_i \geq 0, \quad i = 1, \dots, n$$

$$\sum_{i=1}^{n} \alpha_i y_i = 0$$

### 3.3 KKT 条件

最优解满足 KKT（Karush-Kuhn-Tucker）互补松弛条件：

$$\alpha_i [y_i(w \cdot x_i + b) - 1] = 0, \quad \forall i$$

这意味着：
- 如果 $\alpha_i > 0$，则 $y_i(w \cdot x_i + b) = 1$（$x_i$ 是支持向量）
- 如果 $\alpha_i = 0$，则 $y_i(w \cdot x_i + b) > 1$（$x_i$ 不是支持向量）

### 3.4 决策函数

求解对偶问题后，决策函数为：

$$f(x) = \text{sign}\left(\sum_{i=1}^{n} \alpha_i y_i (x_i \cdot x) + b\right)$$

由于大部分 $\alpha_i = 0$，决策函数只依赖于支持向量。

---

## 4. 软间隔 SVM

### 4.1 动机

现实数据往往不是完全线性可分的，硬间隔 SVM 对噪声和异常值非常敏感。软间隔 SVM 允许部分数据点违反间隔约束。

### 4.2 优化问题

引入松弛变量 $\xi_i \geq 0$：

$$\min_{w, b, \xi} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \xi_i$$

$$\text{s.t.} \quad y_i(w \cdot x_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0$$

其中 $C > 0$ 是惩罚参数：
- $C$ 大：对误分类的惩罚大 → 间隔小，训练误差小
- $C$ 小：对误分类的惩罚小 → 间隔大，可能有更多误分类

### 4.3 对偶问题

$$\max_{\alpha} \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (x_i \cdot x_j)$$

$$\text{s.t.} \quad 0 \leq \alpha_i \leq C, \quad \sum_{i=1}^{n} \alpha_i y_i = 0$$

与硬间隔的区别仅在于 $\alpha_i$ 有了上界 $C$。

### 4.4 支持向量的分类

在软间隔 SVM 中：
- $\alpha_i = 0$：正确分类且在间隔外
- $0 < \alpha_i < C$：在间隔边界上（$w \cdot x_i + b = y_i$）
- $\alpha_i = C$：在间隔内部或被误分类（$\xi_i > 0$）

## 5. 核技巧（Kernel Trick）

### 5.1 核心思想

当数据在原始空间中线性不可分时，可以将数据映射到高维特征空间 $\mathcal{H}$：

$$\phi: \mathbb{R}^d \rightarrow \mathcal{H}$$

在高维空间中，数据可能变得线性可分。但直接计算 $\phi(x)$ 的代价可能很高。

### 5.2 核函数

核函数允许我们**隐式地**计算高维空间中的内积，而无需显式计算映射：

$$K(x_i, x_j) = \phi(x_i) \cdot \phi(x_j)$$

将核函数代入对偶问题，只需计算 $K(x_i, x_j)$：

$$\max_{\alpha} \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j K(x_i, x_j)$$

决策函数变为：

$$f(x) = \text{sign}\left(\sum_{i \in SV} \alpha_i y_i K(x_i, x) + b\right)$$

### 5.3 常用核函数

| 核函数 | 表达式 | 特点 |
|--------|--------|------|
| 线性核 | $K(x_i, x_j) = x_i \cdot x_j$ | 无映射，等价于线性 SVM |
| 多项式核 | $K(x_i, x_j) = (x_i \cdot x_j + c)^p$ | 特征空间维度有限 |
| RBF（高斯）核 | $K(x_i, x_j) = \exp\left(-\frac{\|x_i - x_j\|^2}{2\sigma^2}\right)$ | 无限维特征空间 |
| Sigmoid 核 | $K(x_i, x_j) = \tanh(\kappa \cdot x_i \cdot x_j + c)$ | 类似神经网络 |

### 5.4 Mercer 定理

核函数 $K$ 是有效核的充要条件：对于任意数据集 $\{x_1, \dots, x_m\}$，核矩阵

$$G = [K(x_i, x_j)]_{m \times m}$$

是**半正定**的，即 $G \succeq 0$。

### 5.5 RBF 核的性质

RBF 核 $K(x_i, x_j) = \exp\left(-\frac{\|x_i - x_j\|^2}{2\sigma^2}\right)$：

- 映射到**无限维**特征空间
- 参数 $\sigma$ 控制函数的"宽度"
  - $\sigma$ 大：决策边界平滑（欠拟合风险）
  - $\sigma$ 小：决策边界复杂（过拟合风险）
- 与 $\gamma = \frac{1}{2\sigma^2}$ 等价：$K(x_i, x_j) = \exp(-\gamma \|x_i - x_j\|^2)$

## 6. SVM 的求解算法

### 6.1 SMO（序列最小优化）

John Platt 提出的 SMO 算法是训练 SVM 的标准方法：

**核心思想：** 每次选择两个变量 $\alpha_i, \alpha_j$，固定其他变量，在约束条件下解析求解这两个变量的最优值。

**步骤：**
1. 选择一对需要更新的变量 $\alpha_i, \alpha_j$
2. 固定其他变量，在约束 $\alpha_i y_i + \alpha_j y_j = \text{const}$ 下，解析更新 $\alpha_i$ 和 $\alpha_j$
3. 更新阈值 $b$
4. 重复直到收敛

### 6.2 随机梯度下降

对于大规模数据，可以使用 SGD 训练线性 SVM：

$$w \leftarrow w - \eta \cdot \nabla_w L$$

其中 $L$ 是合页损失（hinge loss）：

$$L_{\text{hinge}}(y, f(x)) = \max(0, 1 - y \cdot f(x))$$

## 7. SVM 的扩展

### 7.1 多分类 SVM

SVM 原生是二分类器，多分类策略：

| 策略 | 方法 | 说明 |
|------|------|------|
| One-vs-One (OvO) | $\frac{K(K-1)}{2}$ 个分类器 | 每对类别训练一个 SVM |
| One-vs-All (OvA) | $K$ 个分类器 | 每个类别 vs 其余 |
| Direct Multi-class | 直接优化多类目标 | Crammer & Singer 方法 |

### 7.2 支持向量回归（SVR）

SVR 使用 $\epsilon$-不敏感损失：

$$L_\epsilon(y, f(x)) = \max(0, |y - f(x)| - \epsilon)$$

优化问题：

$$\min_{w, b} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} (\xi_i + \xi_i^*)$$

$$\text{s.t.} \begin{cases} y_i - (w \cdot x_i + b) \leq \epsilon + \xi_i \\ (w \cdot x_i + b) - y_i \leq \epsilon + \xi_i^* \\ \xi_i, \xi_i^* \geq 0 \end{cases}$$

## 8. Python 实现

### 8.1 线性 SVM

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.svm import SVC
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report, accuracy_score
from sklearn.preprocessing import StandardScaler

X, y = make_classification(n_samples=300, n_features=2, n_redundant=0,
                           n_informative=2, random_state=42, n_clusters_per_class=1)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

svm_linear = SVC(kernel='linear', C=1.0)
svm_linear.fit(X_train_scaled, y_train)

y_pred = svm_linear.predict(X_test_scaled)
print(f"线性 SVM 准确率: {accuracy_score(y_test, y_pred):.4f}")
print(f"支持向量数: {len(svm_linear.support_vectors_)}")
print(classification_report(y_test, y_pred))
```

### 8.2 决策边界可视化

```python
def plot_svm_decision_boundary(model, X, y, title, scaler=None):
    fig, ax = plt.subplots(figsize=(8, 6))

    xx, yy = np.meshgrid(
        np.linspace(X[:, 0].min() - 1, X[:, 0].max() + 1, 500),
        np.linspace(X[:, 1].min() - 1, X[:, 1].max() + 1, 500)
    )
    grid = np.c_[xx.ravel(), yy.ravel()]
    if scaler:
        grid = scaler.transform(grid)
    Z = model.decision_function(grid).reshape(xx.shape)

    ax.contourf(xx, yy, Z, levels=[-1, 0, 1], alpha=0.3, cmap='RdBu')
    ax.contour(xx, yy, Z, levels=[-1, 0, 1], linestyles=['--', '-', '--'], colors='black')

    sv = model.support_vectors_
    ax.scatter(sv[:, 0], sv[:, 1], s=200, facecolors='none', edgecolors='red', linewidths=2, label='支持向量')

    mask0 = y == 0
    mask1 = y == 1
    ax.scatter(X[mask0, 0], X[mask0, 1], c='blue', s=30, alpha=0.6, label='类别 0')
    ax.scatter(X[mask1, 0], X[mask1, 1], c='red', s=30, alpha=0.6, label='类别 1')

    ax.set_title(title)
    ax.legend()
    plt.tight_layout()
    plt.show()

plot_svm_decision_boundary(svm_linear, X_train_scaled, y_train, '线性 SVM')
```

## 9. 实际案例：文本分类

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.pipeline import Pipeline

texts = [
    "这部电影非常精彩，值得一看", "剧情很棒，演员演技好",
    "特效震撼，视觉效果极佳", "强烈推荐这部好电影",
    "浪费时间，剧情无聊", "演技差，故事平淡无奇",
    "太难看了，不推荐", "节奏拖沓，毫无亮点"
]
labels = [1, 1, 1, 1, 0, 0, 0, 0]

pipeline = Pipeline([
    ('tfidf', TfidfVectorizer(max_features=1000)),
    ('svm', SVC(kernel='linear', C=1.0))
])
pipeline.fit(texts, labels)

new_texts = ["好看推荐", "很差不值得"]
predictions = pipeline.predict(new_texts)
for text, pred in zip(new_texts, predictions):
    print(f"'{text}' → {'正面' if pred == 1 else '负面'}")
```

## 10. 关键要点总结

| 要点 | 说明 |
|------|------|
| 核心目标 | 最大化间隔 $\frac{2}{\|w\|}$ |
| 优化问题 | 凸二次规划，有全局最优解 |
| 支持向量 | 决策边界由少数支持向量决定 |
| 软间隔 | 通过参数 $C$ 控制误分类惩罚 |
| 核技巧 | 隐式映射到高维空间，避免维度灾难 |
| 常用核 | RBF 核最通用，线性核适合高维稀疏数据 |
| SMO 算法 | 标准求解方法，每次优化两个变量 |
| 合页损失 | $\max(0, 1 - yf(x))$，SVM 的损失函数 |
| 适用场景 | 小样本、高维数据、二分类 |
| 关键参数 | $C$（正则化）、$\gamma$（RBF 核宽度）、核类型 |

SVM 因其优秀的理论基础和泛化能力，在深度学习兴起之前一直是机器学习中最强的分类算法之一。即使在今天，SVM 在小样本和高维数据场景中仍然是非常有竞争力的选择。
