# 数据清洗与预处理

## 1. 数据清洗概述

数据清洗是数据分析流程中最基础也是最关键的环节。真实世界的数据往往是"脏"的，包含缺失值、异常值、重复记录、格式不一致等问题。高质量的数据是后续建模和分析的前提保障。

数据清洗的核心目标：

- **完整性**：确保数据尽可能完整，减少缺失
- **一致性**：统一数据格式和编码规则
- **准确性**：识别并修正错误数据
- **时效性**：保证数据反映当前状态

## 2. 缺失值处理

### 2.1 缺失值的类型

缺失值按其产生机制可分为三类：

| 类型 | 含义 | 示例 |
|------|------|------|
| MCAR（完全随机缺失） | 缺失与任何变量无关 | 设备随机故障导致数据丢失 |
| MAR（随机缺失） | 缺失与其他观测变量有关 | 女性更不愿填写体重 |
| MNAR（非随机缺失） | 缺失与缺失值本身有关 | 高收入者拒绝填写收入 |

### 2.2 缺失值检测

在 Python 中，利用 `pandas` 可以快速检测缺失值分布：

```python
import pandas as pd
import numpy as np

# 加载数据
df = pd.read_csv('data.csv')

# 总体缺失值统计
print("各列缺失值数量：")
print(df.isnull().sum())

# 缺失值比例
print("\n缺失值比例：")
print(df.isnull().mean() * 100)

# 缺失值矩阵（可视化）
import missingno as msno
msno.matrix(df)
msno.heatmap(df)
```

### 2.3 缺失值处理方法

#### 2.3.1 删除法

当缺失比例较小或缺失机制为 MCAR 时，可直接删除：

```python
# 删除含缺失值的行
df_dropped_rows = df.dropna()

# 删除缺失比例超过 50% 的列
threshold = 0.5
df_dropped_cols = df.dropna(axis=1, thresh=int(len(df) * (1 - threshold)))

# 仅删除全部为缺失值的行
df.dropna(how='all', inplace=True)
```

删除法的数学表达：对于数据矩阵 $X \in \mathbb{R}^{n \times p}$，删除含有缺失值的行后得到子矩阵 $\tilde{X} \in \mathbb{R}^{\tilde{n} \times p}$，其中 $\tilde{n} \leq n$。

#### 2.3.2 均值/中位数/众数填充

```python
from sklearn.impute import SimpleImputer

# 数值型：均值填充
num_imputer = SimpleImputer(strategy='mean')
df[['age', 'salary']] = num_imputer.fit_transform(df[['age', 'salary']])

# 数值型：中位数填充（对异常值更鲁棒）
num_imputer_median = SimpleImputer(strategy='median')

# 分类型：众数填充
cat_imputer = SimpleImputer(strategy='most_frequent')
df[['gender', 'city']] = cat_imputer.fit_transform(df[['gender', 'city']])
```

均值填充的数学公式：

$$\hat{x}_i = \bar{x} = \frac{1}{n_{obs}} \sum_{j: x_j \neq \text{NaN}} x_j$$

其中 $n_{obs}$ 为已观测到的样本数量。

#### 2.3.3 插值法

适用于时间序列或有序数据：

```python
# 线性插值
df['temperature'] = df['temperature'].interpolate(method='linear')

# 时间序列插值
df['date'] = pd.to_datetime(df['date'])
df.set_index('date', inplace=True)
df['value'] = df['value'].interpolate(method='time')

# 样条插值
df['value_spline'] = df['value'].interpolate(method='spline', order=3)

# 前向填充与后向填充
df['forward_fill'] = df['value'].fillna(method='ffill')
df['backward_fill'] = df['value'].fillna(method='bfill')
```

#### 2.3.4 模型填充（多重插补）

利用其他变量建立预测模型来估计缺失值：

```python
from sklearn.experimental import enable_iterative_imputer
from sklearn.impute import IterativeImputer
from sklearn.ensemble import RandomForestRegressor

# 基于随机森林的多重插补
iter_imputer = IterativeImputer(
    estimator=RandomForestRegressor(n_estimators=100, random_state=42),
    max_iter=10,
    random_state=42
)

df_imputed = pd.DataFrame(
    iter_imputer.fit_transform(df),
    columns=df.columns
)
```

多重插补（MICE）的核心思想是迭代地为每个含有缺失值的变量建立条件预测模型：

$$X_j^{(t+1)} \sim P(X_j \mid X_{-j}^{(t)}, \theta_j^{(t)})$$

#### 2.3.5 KNN 填充

```python
from sklearn.impute import KNNImputer

knn_imputer = KNNImputer(n_neighbors=5, weights='distance')

    knn_imputer.fit_transform(df),
```

## 3. 异常值处理

### 3.1 异常值检测方法

#### 3.1.1 Z-Score 方法

假设数据服从正态分布 $X \sim N(\mu, \sigma^2)$，Z-Score 定义为：

$$z_i = \frac{x_i - \bar{x}}{s}$$

当 $|z_i| > 3$ 时，通常将 $x_i$ 视为异常值。

```python
from scipy import stats

z_scores = np.abs(stats.zscore(df.select_dtypes(include=[np.number])))
outliers_z = (z_scores > 3).any(axis=1)
df_clean_z = df[~outliers_z]
```

#### 3.1.2 IQR（四分位距）方法

$$IQR = Q_3 - Q_1$$

异常值判定范围：

$$\text{下界} = Q_1 - 1.5 \times IQR, \quad \text{上界} = Q_3 + 1.5 \times IQR$$

```python
def detect_outliers_iqr(df, column):
    Q1 = df[column].quantile(0.25)
    Q3 = df[column].quantile(0.75)
    IQR = Q3 - Q1
    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR
    return df[(df[column] >= lower) & (df[column] <= upper)]

df_clean_iqr = detect_outliers_iqr(df, 'salary')
```

#### 3.1.3 孤立森林（Isolation Forest）

详见 [04-异常检测.md](04-异常检测.md) 中的详细介绍。

#### 3.1.4 基于聚类的方法

```python
from sklearn.cluster import DBSCAN

scaler = StandardScaler()
X_scaled = scaler.fit_transform(df.select_dtypes(include=[np.number]))

dbscan = DBSCAN(eps=0.5, min_samples=5)

# label == -1 表示异常点

```

```python
def full_to_half(text):
    result = []
    for char in str(text):
        code = ord(char)
        if code == 0x3000:
            code = 0x0020
        elif 0xFF01 <= code <= 0xFF5E:
            code -= 0xFEE0
        result.append(chr(code))
    return ''.join(result)
```

## 6. 数据归一化与标准化

### 6.1 Min-Max 归一化

将数据缩放到 $[0, 1]$ 区间：

$$x_{norm} = \frac{x - x_{min}}{x_{max} - x_{min}}$$

```python
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()
df_scaled = pd.DataFrame(
    scaler.fit_transform(df[numerical_cols]),
    columns=numerical_cols
)
```

### 6.2 Z-Score 标准化

将数据转换为标准正态分布 $N(0, 1)$：

$$x_{std} = \frac{x - \mu}{\sigma}$$

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
df_standardized = pd.DataFrame(
    scaler.fit_transform(df[numerical_cols]),
    columns=numerical_cols
)
```

### 6.3 RobustScaler（鲁棒标准化）

使用中位数和 IQR，对异常值不敏感：

$$x_{robust} = \frac{x - Q_2}{Q_3 - Q_1}$$

```python
from sklearn.preprocessing import RobustScaler

scaler = RobustScaler()
df_robust = pd.DataFrame(
    scaler.fit_transform(df[numerical_cols]),
    columns=numerical_cols
)
```

### 6.4 MaxAbsScaler（最大绝对值缩放）

$$x_{scaled} = \frac{x}{\max(|x|)}$$

适用于稀疏数据，缩放后范围为 $[-1, 1]$。

### 6.5 对数变换

处理右偏分布，使数据更接近正态分布：

$$x_{log} = \log(1 + x)$$

```python
df['income_log'] = np.log1p(df['income'])

# Box-Cox 变换（要求数据为正）
from scipy.stats import boxcox
df['value_boxcox'], lambda_ = boxcox(df['value'] + 1)

# Yeo-Johnson 变换（支持负数）
from sklearn.preprocessing import PowerTransformer
pt = PowerTransformer(method='yeo-johnson')
df[numerical_cols] = pt.fit_transform(df[numerical_cols])
```

## 9. 数据预处理流水线

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer

# 定义数值和分类列
numerical_cols = ['age', 'salary', 'score']
categorical_cols = ['city', 'gender']

# 数值处理流水线
numerical_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])

# 分类处理流水线
categorical_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='most_frequent')),
    ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
])

# 组合流水线
preprocessor = ColumnTransformer([
    ('num', numerical_pipeline, numerical_cols),
    ('cat', categorical_pipeline, categorical_cols)
])

# 一键预处理
X_processed = preprocessor.fit_transform(df)
```

## 10. 实际案例：泰坦尼克号数据预处理

```python
import seaborn as sns

# 加载数据
titanic = sns.load_dataset('titanic')

# 1. 查看缺失值
print(titanic.isnull().sum())

# 2. 删除无用列
titanic.drop(columns=['deck', 'embark_town', 'alive'], inplace=True)

# 3. 填充缺失值
titanic['age'].fillna(titanic['age'].median(), inplace=True)
titanic['embarked'].fillna(titanic['embarked'].mode()[0], inplace=True)

# 4. 特征构造
titanic['family_size'] = titanic['sibsp'] + titanic['parch'] + 1
titanic['is_alone'] = (titanic['family_size'] == 1).astype(int)

# 5. 编码
titanic['sex'] = titanic['sex'].map({'male': 0, 'female': 1})
titanic = pd.get_dummies(titanic, columns=['embarked', 'class'], drop_first=True)

# 6. 特征选择
features = ['pclass', 'sex', 'age', 'sibsp', 'parch', 'fare',
            'family_size', 'is_alone']
X = titanic[features]
y = titanic['survived']
```

## 11. 关键要点总结

1. **缺失值处理**：先判断缺失机制，MCAR 可删除，MAR 用模型填充，MNAR 需结合业务理解
2. **异常值处理**：多种方法结合使用，删除前先确认是否为有意义的极端值
3. **归一化/标准化**：距离类模型（KNN、SVM）必须标准化，树模型无需标准化
4. **编码选择**：基数低用 One-Hot，基数高用 Target/Frequency Encoding
5. **流水线**：始终使用 `Pipeline` 和 `ColumnTransformer` 确保训练/测试一致
6. **数据泄露**：`fit` 只在训练集上进行，`transform` 应用到测试集
7. **对数变换**：处理右偏数据时，`np.log1p` 比 `np.log` 更安全（处理零值）
8. **业务理解**：技术手段需结合业务背景，不能机械套用
