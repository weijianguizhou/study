# 数据可视化

## 1. 可视化概述

### 1.1 可视化的重要性

数据可视化是将数据转化为图形表示的过程，是数据分析和沟通的核心环节。优秀的可视化能够：

- **发现模式**：快速识别数据中的趋势、聚类和异常
- **验证假设**：直观检验分析结论是否合理
- **传递信息**：将复杂数据以易于理解的方式呈现
- **支持决策**：为管理层提供清晰的数据洞察

### 1.2 可视化设计原则

基于 Edward Tufte 的数据可视化原则：

1. **数据墨水比（Data-Ink Ratio）**：最大化用于展示数据的墨水比例

$$\text{数据墨水比} = \frac{\text{数据墨水}}{\text{总墨水}}$$

2. **图表垃圾（Chartjunk）**：去除不必要的装饰元素（网格线、3D 效果、背景色等）
3. **图形完整性（Graphical Integrity）**：不扭曲数据，坐标轴从零开始
4. **多变量思维**：尽量在一张图中展示多个维度的信息

### 1.3 图表选择指南

| 分析目的 | 推荐图表 | 适用场景 |
|----------|----------|----------|
| 分布 | 直方图、箱线图、密度图 | 查看单变量分布 |
| 关系 | 散点图、气泡图、热力图 | 查看变量间关系 |
| 比较 | 柱状图、雷达图 | 类别间比较 |
| 趋势 | 折线图、面积图 | 时间序列变化 |
| 构成 | 饼图、树状图、旭日图 | 占比/组成分析 |
| 地理 | 地图、热力地图 | 空间数据展示 |

## 2. Matplotlib 基础

### 2.1 图形层次结构

Matplotlib 图形由以下层次组成：

```
Figure（画布）
  └── Axes（坐标系）= 子图
        ├── XAxis（X 轴）
        ├── YAxis（Y 轴）
        └── 标题、图例等
```

## 6. 特定分析场景可视化

### 6.1 A/B 测试可视化

```python
np.random.seed(42)
n_a, n_b = 1000, 1000
conversion_a = np.random.binomial(1, 0.10, n_a)
conversion_b = np.random.binomial(1, 0.12, n_b)

fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# 转化率对比
rates = [conversion_a.mean(), conversion_b.mean()]
axes[0].bar(['对照组', '实验组'], rates, color=['#2196F3', '#FF5722'],
            edgecolor='white', linewidth=1.5)
for i, v in enumerate(rates):
    axes[0].text(i, v + 0.002, f'{v:.1%}', ha='center', fontweight='bold')
axes[0].set_ylabel('转化率')
axes[0].set_title('A/B 测试转化率')

# Bootstrap 置信区间
from scipy.stats import bootstrap

def calc_diff(data1, data2):
    return (np.mean(data1),)  # 返回元组

boot_a = bootstrap((conversion_a,), np.mean, n_resamples=10000)
boot_b = bootstrap((conversion_b,), np.mean, n_resamples=10000)

axes[1].hist(boot_a.confidence_interval.confidence_interval, alpha=0.5,
             color='#2196F3', label='对照组', bins=30)
axes[1].hist(boot_b.confidence_interval.confidence_interval, alpha=0.5,
             color='#FF5722', label='实验组', bins=30)
axes[1].set_title('Bootstrap 置信区间')
axes[1].legend()

# 累积转化率
cum_a = np.cumsum(conversion_a) / np.arange(1, n_a + 1)
cum_b = np.cumsum(conversion_b) / np.arange(1, n_b + 1)
axes[2].plot(range(1, n_a + 1), cum_a, label='对照组', color='#2196F3')
axes[2].plot(range(1, n_b + 1), cum_b, label='实验组', color='#FF5722')
axes[2].set_xlabel('样本数')
axes[2].set_ylabel('累积转化率')
axes[2].set_title('累积转化率趋势')
axes[2].legend()

plt.tight_layout()
plt.show()
```

### 6.2 漏斗图

```python
stages = ['访问', '注册', '浏览商品', '加入购物车', '提交订单', '支付成功']
values = [10000, 6000, 4500, 2500, 1500, 1200]

fig, ax = plt.subplots(figsize=(10, 6))

# 漏斗图（水平柱状图变体）
widths = [v / max(values) for v in values]
y_pos = range(len(stages))
colors = plt.cm.RdYlGn(np.linspace(0.2, 0.8, len(stages)))

bars = ax.barh(y_pos, widths, color=colors, edgecolor='white', height=0.6)
ax.set_yticks(y_pos)
ax.set_yticklabels(stages, fontsize=12)
ax.invert_yaxis()
ax.set_xlim(0, 1.1)

# 标注数值和转化率
for i, (bar, val) in enumerate(zip(bars, values)):
    ax.text(val / max(values) + 0.02, i, f'{val:,}',
            va='center', fontweight='bold', fontsize=11)
    if i > 0:
        rate = val / values[i-1]
        ax.text(val / max(values) + 0.15, i, f'{rate:.1%}',
                va='center', color='gray', fontsize=10)

ax.set_title('用户转化漏斗', fontsize=14, fontweight='bold')
ax.set_xlabel('比例')
plt.tight_layout()
plt.show()
```

## 8. 可视化最佳实践

### 8.1 常见错误与避免

| 错误 | 问题 | 正确做法 |
|------|------|----------|
| 3D 饼图 | 难以比较面积 | 使用水平柱状图 |
| 双 Y 轴 | 容易误导 | 分图展示 |
| 彩虹色图 | 不利于色盲人群 | 使用 viridis 等感知均匀色图 |
| 起点非零 | 夸大差异 | 坐标轴从零开始 |
| 过多颜色 | 信息过载 | 限制 5-7 种颜色 |

### 8.3 可视化检查清单

1. **标题**：是否清晰描述了图表展示的内容？
2. **轴标签**：是否标注了变量名和单位？
3. **图例**：是否在必要时提供了图例说明？
4. **颜色**：是否选择了合适的颜色方案？是否考虑了色盲友好？
5. **比例**：坐标轴是否合理？是否存在误导性缩放？
6. **字体**：字体大小是否合适？是否可读？
7. **简洁性**：是否移除了不必要的装饰元素？
8. **数据来源**：是否标注了数据来源和时间范围？

## 9. 关键要点总结

1. **先思考后绘图**：明确要回答的问题，再选择合适的图表类型
2. **简洁至上**：删除一切不传达信息的元素
3. **选择正确的图表**：分布用直方图/密度图，关系用散点图，趋势用折线图
4. **颜色要有目的**：用颜色编码有意义的变量，不要随意使用
5. **中文显示**：设置 `SimHei` 字体并关闭 `unicode_minus`
6. **交互式优先**：复杂数据推荐使用 Plotly/Bokeh 等交互式库
7. **批量对比**：使用 FacetGrid/SubplotGrid 进行多组数据对比
8. **输出格式**：论文用 PDF/SVG，网页用 PNG，注意 DPI 设置
9. **面向受众**：技术报告可以详细，面向管理层要简洁直观
10. **可复现**：使用代码生成图表，避免手动修改
