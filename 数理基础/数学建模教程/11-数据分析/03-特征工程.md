# 特征工程

## 1. 特征工程概述

特征工程是利用领域知识和统计方法，从原始数据中提取、构造和选择有效特征的过程。它是机器学习中最能体现创造力和专业能力的环节，被誉为"数据科学家的核心技能"。

### 1.1 特征工程的范畴

特征工程包含三个核心环节：

- **特征提取（Feature Extraction）**：从原始数据（文本、图像、时间序列）中提取结构化特征
- **特征构造（Feature Construction）**：基于现有特征组合生成新特征
- **特征选择（Feature Selection）**：从候选特征中筛选最优子集

### 1.2 特征工程流程

$$\text{原始数据} \xrightarrow{\text{提取}} \text{候选特征} \xrightarrow{\text{构造}} \text{扩展特征集} \xrightarrow{\text{选择}} \text{最优特征子集}$$

## 2. 数值特征构造

### 2.1 多项式特征

通过特征的交叉与幂次组合生成新特征：

$$(x_1, x_2) \xrightarrow{\text{degree=2}} (1, x_1, x_2, x_1^2, x_1 x_2, x_2^2)$$

一般地，对于 $p$ 个特征，阶数为 $d$ 的多项式特征数为：

$$\binom{p + d}{d} = \frac{(p+d)!}{p! \cdot d!}$$

```python
from sklearn.preprocessing import PolynomialFeatures
import numpy as np
import pandas as pd

# 示例数据
df = pd.DataFrame({
    'height': [170, 165, 180, 175],
    'weight': [65, 55, 80, 70]
})

# 生成二次多项式特征
poly = PolynomialFeatures(degree=2, include_bias=False, interaction_only=False)
X_poly = poly.fit_transform(df)
print("特征名：", poly.get_feature_names_out(['height', 'weight']))
print("变换后数据：\n", X_poly)
```

### 2.2 交互特征

特征之间的交互可以捕获变量间的协同效应：

$$x_{\text{interaction}} = x_i \times x_j$$

```python
# 手动构造交互特征
df['height_weight_ratio'] = df['height'] / df['weight']
df['height_x_weight'] = df['height'] * df['weight']
df['bmi'] = df['weight'] / (df['height'] / 100) ** 2

# 基于现有特征的非线性变换
```

### 2.4 滚动窗口特征

时间序列数据的核心特征构造方法：

```python
# 创建时间序列数据
dates = pd.date_range('2024-01-01', periods=365, freq='D')
df_ts = pd.DataFrame({
    'date': dates,
    'value': np.cumsum(np.random.randn(365)) + 100
})
df_ts.set_index('date', inplace=True)

# 滚动窗口特征
for window in [7, 14, 30]:
    df_ts[f'rolling_mean_{window}'] = df_ts['value'].rolling(window=window).mean()
    df_ts[f'rolling_std_{window}'] = df_ts['value'].rolling(window=window).std()
    df_ts[f'rolling_max_{window}'] = df_ts['value'].rolling(window=window).max()
    df_ts[f'rolling_min_{window}'] = df_ts['value'].rolling(window=window).min()

# 指数加权移动平均
df_ts['ewm_mean_7'] = df_ts['value'].ewm(span=7).mean()

# 差分特征
df_ts['diff_1'] = df_ts['value'].diff(1)
df_ts['diff_7'] = df_ts['value'].diff(7)

# 滞后特征
for lag in [1, 7, 14]:
    df_ts[f'lag_{lag}'] = df_ts['value'].shift(lag)

# 周期性特征
df_ts['dayofweek'] = df_ts.index.dayofweek
df_ts['month'] = df_ts.index.month
df_ts['quarter'] = df_ts.index.quarter
df_ts['is_month_end'] = df_ts.index.is_month_end.astype(int)
```

### 2.5 分箱（Binning）

将连续变量离散化：

```python

import numpy as np

# 自定义分箱
bins = [0, 18, 30, 45, 60, 100]
labels = ['少年', '青年', '中年', '中老年', '老年']
df['age_custom'] = pd.cut(df['age'], bins=bins, labels=labels)

# 基于决策树的最优分箱
from sklearn.tree import DecisionTreeClassifier

def optimal_binning(X, y, max_bins=5):
    """基于决策树的最优分箱"""
    tree = DecisionTreeClassifier(max_leaf_nodes=max_bins, random_state=42)
    tree.fit(X.values.reshape(-1, 1), y)
    thresholds = sorted(tree.tree_.threshold[tree.tree_.threshold != -2])
    return thresholds

# 分箱后的信息增益
def calc_woe_iv(df, feature, target, bins=10):
    """计算 WoE 和 IV 值"""
    df_binned = pd.DataFrame({feature: pd.cut(df[feature], bins=bins)})
    grouped = df_binned.groupby(feature, observed=False)[target].agg(['count', 'sum'])
    grouped.columns = ['total', 'bad']
    grouped['good'] = grouped['total'] - grouped['bad']

    total_bad = grouped['bad'].sum()
    total_good = grouped['good'].sum()

    grouped['bad_rate'] = grouped['bad'] / total_bad
    grouped['good_rate'] = grouped['good'] / total_good
    grouped['woe'] = np.log((grouped['good_rate'] + 1e-6) / (grouped['bad_rate'] + 1e-6))
    grouped['iv'] = (grouped['good_rate'] - grouped['bad_rate']) * grouped['woe']

    print(f"IV 值：{grouped['iv'].sum():.4f}")
    if grouped['iv'].sum() < 0.02:
        print("预测力：无")
    elif grouped['iv'].sum() < 0.1:
        print("预测力：弱")
    elif grouped['iv'].sum() < 0.3:
        print("预测力：中等")
    else:
        print("预测力：强")

    return grouped
```

### 3.3 目标编码（Target Encoding）

用目标变量的统计量替换类别值：

$$\text{encoding}(x_i) = \frac{n_i \cdot \bar{y}_i + m \cdot \bar{y}}{n_i + m}$$

其中 $n_i$ 是类别 $x_i$ 的样本数，$\bar{y}_i$ 是类别 $x_i$ 的目标均值，$\bar{y}$ 是全局目标均值，$m$ 是平滑参数（防止过拟合）。

```python
# 手动实现目标编码
def target_encode(train, col, target, m=10):
    global_mean = train[target].mean()
    agg = train.groupby(col)[target].agg(['mean', 'count'])
    smooth_mean = (agg['count'] * agg['mean'] + m * global_mean) / (agg['count'] + m)
    return train[col].map(smooth_mean)

df['color_encoded'] = target_encode(df, 'color', 'target')

# category_encoders 库

```

```python
def extract_text_features(texts):
    """提取文本统计特征"""
    features = pd.DataFrame()
    features['char_count'] = texts.apply(len)
    features['word_count'] = texts.apply(lambda x: len(x.split()))
    features['avg_word_length'] = texts.apply(
        lambda x: np.mean([len(w) for w in x.split()]) if len(x.split()) > 0 else 0
    )
    features['unique_word_ratio'] = texts.apply(
        lambda x: len(set(x.split())) / len(x.split()) if len(x.split()) > 0 else 0
    )
    features['has_numbers'] = texts.apply(lambda x: int(any(c.isdigit() for c in x)))
    features['exclamation_count'] = texts.apply(lambda x: x.count('!'))
    return features

text_features = extract_text_features(pd.Series(corpus))
print(text_features)
```

## 5. 特征选择

### 5.1 过滤法（Filter Methods）

基于统计指标对特征进行评分和排序，与模型无关：

#### 5.1.1 方差阈值

$$\text{Var}(X_j) = \frac{1}{n} \sum_{i=1}^{n} (x_{ij} - \bar{x}_j)^2$$

```python
from sklearn.feature_selection import VarianceThreshold

selector = VarianceThreshold(threshold=0.01)
X_var = selector.fit_transform(X_scaled)
print(f"保留特征数：{X_var.shape[1]}")
```

#### 5.1.2 相关系数

Pearson 相关系数：

$$r_{xy} = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \cdot \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 特征相关性矩阵
corr_matrix = df[numerical_cols].corr()

# 热力图可视化
plt.figure(figsize=(10, 8))
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm', center=0, fmt='.2f')
plt.title('特征相关性矩阵')
plt.show()

# 高相关性特征对
def get_high_correlation_pairs(corr_matrix, threshold=0.9):
    pairs = []
    for i in range(len(corr_matrix.columns)):
        for j in range(i + 1, len(corr_matrix.columns)):
            if abs(corr_matrix.iloc[i, j]) > threshold:
                pairs.append((corr_matrix.columns[i], corr_matrix.columns[j],
                              corr_matrix.iloc[i, j]))
    return pairs

print("高相关性特征对：", get_high_correlation_pairs(corr_matrix, 0.9))
```

#### 5.1.3 互信息

$$I(X; Y) = \sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} p(x, y) \log \frac{p(x, y)}{p(x) p(y)}$$

```python
from sklearn.feature_selection import mutual_info_classif, mutual_info_regression

# 分类任务
mi_scores = mutual_info_classif(X, y, random_state=42)

# 回归任务
mi_scores_reg = mutual_info_regression(X, y)
```

#### 5.1.4 卡方检验

$$\chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{c} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$

### 5.3 嵌入法（Embedded Methods）

在模型训练过程中自动进行特征选择：

#### 5.3.1 L1 正则化（Lasso）

$$\min_w \; \frac{1}{2n} \|y - Xw\|^2 + \alpha \|w\|_1$$

L1 正则化会使部分系数变为精确零值，实现自动特征选择。

```python
from sklearn.linear_model import LassoCV, LogisticRegressionCV

# 回归任务
lasso = LassoCV(cv=5, random_state=42)
lasso.fit(X_scaled, y)
selected = np.abs(lasso.coef_) > 1e-5
print(f"Lasso 选中 {selected.sum()} 个特征")

# 分类任务
logistic = LogisticRegressionCV(
    penalty='l1', solver='saga', cv=5, random_state=42, max_iter=1000
)
logistic.fit(X_scaled, y)
selected_l1 = np.abs(logistic.coef_).max(axis=0) > 1e-5
```

### 5.4 特征选择方法对比

| 方法 | 类型 | 优点 | 缺点 |
|------|------|------|------|
| 方差阈值 | 过滤法 | 简单快速 | 未考虑特征间关系 |
| 相关系数 | 过滤法 | 直观易理解 | 仅衡量线性关系 |
| 互信息 | 过滤法 | 捕获非线性关系 | 计算开销较大 |
| RFE | 包装法 | 考虑特征交互 | 计算开销大 |
| L1 正则化 | 嵌入法 | 自动选择 | 对特征尺度敏感 |
| 树模型重要性 | 嵌入法 | 捕获非线性 | 可能偏向高基数特征 |

## 7. 实战案例：电商用户特征工程

```python
np.random.seed(42)
n = 5000
users = pd.DataFrame({
    'user_id': range(n),
    'age': np.random.randint(18, 65, n),
    'gender': np.random.choice(['M', 'F'], n),
    'city': np.random.choice(['北京', '上海', '广州', '深圳', '成都'], n),
    'total_orders': np.random.poisson(10, n),
    'total_amount': np.random.exponential(500, n),
    'avg_order_amount': np.random.normal(200, 50, n),
    'days_since_last_order': np.random.exponential(30, n),
    'category_count': np.random.randint(1, 20, n),
})

# === 特征构造 ===

# 1. 比率特征
users['amount_per_order'] = users['total_amount'] / (users['total_orders'] + 1)
users['orders_per_category'] = users['total_orders'] / (users['category_count'] + 1)

# 2. 分箱特征
users['age_group'] = pd.cut(users['age'], bins=[0, 25, 35, 50, 100],
                             labels=['Z世代', '青年', '中年', '中老年'])
users['amount_level'] = pd.qcut(users['total_amount'], q=4,
                                 labels=['低消费', '中低消费', '中高消费', '高消费'])

# 3. RFM 特征（最近购买时间、购买频率、消费金额）
users['recency_score'] = pd.qcut(users['days_since_last_order'], q=5,
                                  labels=[5, 4, 3, 2, 1]).astype(int)
users['frequency_score'] = pd.qcut(users['total_orders'].clip(upper=users['total_orders'].quantile(0.99)),
                                     q=5, labels=[1, 2, 3, 4, 5]).astype(int)
users['monetary_score'] = pd.qcut(users['total_amount'].clip(upper=users['total_amount'].quantile(0.99)),
                                    q=5, labels=[1, 2, 3, 4, 5]).astype(int)
users['rfm_score'] = users['recency_score'] * 100 + users['frequency_score'] * 10 + users['monetary_score']

# 4. 编码特征
users = pd.get_dummies(users, columns=['gender', 'city', 'age_group', 'amount_level'],
                        drop_first=True)

print(f"最终特征数：{users.shape[1]}")
print(users.head())
```

## 8. 关键要点总结

1. **领域知识最重要**：好的特征来自对业务的深刻理解
2. **先理解后构造**：每个新特征都应有明确的业务含义
3. **多项式特征谨慎使用**：维度爆炸风险，需配合特征选择
4. **分箱是把双刃剑**：降低过拟合但损失信息，需平衡
5. **目标编码防过拟合**：必须使用留一法或 K-Fold 方式编码
6. **文本特征用 TF-IDF**：比词袋模型效果更好
7. **特征选择减少过拟合**：去除无关特征能显著提升泛化能力
8. **SHAP > 特征重要性**：SHAP 值提供更可靠的特征贡献解释
9. **RFM 模型经典实用**：在用户分群和营销场景中广泛应用
