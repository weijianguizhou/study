# 异常检测

## 1. 异常检测概述

### 1.1 异常的定义

异常（Anomaly / Outlier）是指与数据集中大多数样本显著不同的数据点。异常检测的目标是识别出这些偏离正常模式的观测值。

异常的三种类型：

| 类型 | 描述 | 示例 |
|------|------|------|
| 点异常（Point Anomaly） | 单个数据点相对于整体异常 | 信用卡欺诈交易 |
| 上下文异常（Contextual Anomaly） | 在特定上下文中异常 | 夏季出现冬季气温 |
| 集体异常（Collective Anomaly） | 一组数据点整体异常 | 网络攻击中的异常流量序列 |

### 1.2 异常检测的应用

- **金融**：欺诈检测、反洗钱、异常交易监控
- **网络安全**：入侵检测、DDoS 攻击识别
- **工业**：设备故障预警、质量控制
- **医疗**：疾病早期诊断、医疗异常事件
- **社交网络**：虚假账户检测、异常行为分析

### 1.3 异常检测方法分类

$$\text{异常检测方法} \begin{cases} \text{统计方法} \\ \text{基于距离} \\ \text{基于密度} \\ \text{基于模型} \\ \text{基于深度学习} \end{cases}$$

## 2. 基于统计的异常检测

### 2.1 参数化方法

假设数据服从已知分布（如正态分布），利用分布参数检测异常。

#### 2.1.1 Z-Score 方法

假设 $X \sim N(\mu, \sigma^2)$，Z-Score 定义为：

$$z_i = \frac{x_i - \mu}{\sigma}$$

当 $|z_i| > \tau$（通常 $\tau = 3$）时，判定为异常。

```python
import numpy as np
import pandas as pd
from scipy import stats

np.random.seed(42)
data = np.concatenate([np.random.normal(0, 1, 990), np.random.normal(5, 1, 10)])
df = pd.DataFrame({'value': data})

# Z-Score 方法
z_scores = np.abs(stats.zscore(df['value']))
df['is_outlier_zscore'] = z_scores > 3
print(f"Z-Score 检测到 {df['is_outlier_zscore'].sum()} 个异常点")
```

#### 2.1.2 Modified Z-Score

使用中位数绝对偏差（MAD）代替均值和标准差，对异常值更鲁棒：

$$\text{MAD} = \text{median}(|x_i - \text{median}(X)|)$$

$$\text{Modified Z-Score} = 0.6745 \times \frac{x_i - \text{median}(X)}{\text{MAD}}$$

```python
median = df['value'].median()
mad = np.median(np.abs(df['value'] - median))
modified_z = 0.6745 * (df['value'] - median) / mad
df['is_outlier_mz'] = np.abs(modified_z) > 3.5
```

#### 2.1.3 Grubbs 检验

$$G = \frac{\max_i |x_i - \bar{x}|}{s}$$

临界值：

$$G_{\text{critical}} = \frac{n-1}{\sqrt{n}} \sqrt{\frac{t_{\alpha/(2n), n-2}^2}{n - 2 + t_{\alpha/(2n), n-2}^2}}$$

```python
from scipy.stats import t

def grubbs_test(data, alpha=0.05):
    n = len(data)
    mean = np.mean(data)
    std = np.std(data, ddof=1)
    abs_diff = np.abs(data - mean)
    max_idx = np.argmax(abs_diff)
    G = abs_diff[max_idx] / std

    t_critical = t.ppf(1 - alpha / (2 * n), n - 2)
    G_critical = ((n - 1) / np.sqrt(n)) * np.sqrt(
        t_critical ** 2 / (n - 2 + t_critical ** 2)
    )

    return G > G_critical, max_idx, G, G_critical

is_outlier, idx, G_stat, G_crit = grubbs_test(data)
print(f"Grubbs 检验统计量：{G_stat:.4f}，临界值：{G_crit:.4f}")
```

#### 2.1.4 Dixon Q 检验

适用于小样本数据（$n < 30$）：

$$Q = \frac{|x_{\text{suspect}} - x_{\text{nearest}}|}{x_{\text{max}} - x_{\text{min}}}$$

```python
def dixon_q_test(data, alpha=0.05):
    sorted_data = np.sort(data)
    n = len(sorted_data)

    Q_critical_table = {
        3: 0.941, 4: 0.765, 5: 0.642, 6: 0.560,
        7: 0.507, 8: 0.468, 9: 0.437, 10: 0.412
    }

    if n not in Q_critical_table:
        print("样本量超出 Dixon Q 检验范围")
        return None

    Q_crit = Q_critical_table[n]
    Q_low = (sorted_data[1] - sorted_data[0]) / (sorted_data[-1] - sorted_data[0])
    Q_high = (sorted_data[-1] - sorted_data[-2]) / (sorted_data[-1] - sorted_data[0])

    return max(Q_low, Q_high) > Q_crit
```

### 2.2 非参数方法

不假设数据服从特定分布：

#### 2.2.1 IQR 方法

$$\text{异常值} \in (-\infty, Q_1 - k \cdot IQR) \cup (Q_3 + k \cdot IQR, +\infty)$$

其中 $IQR = Q_3 - Q_1$，$k$ 通常取 1.5（温和异常）或 3（极端异常）。

```python
def iqr_outlier_detection(data, k=1.5):
    Q1 = np.percentile(data, 25)
    Q3 = np.percentile(data, 75)
    IQR = Q3 - Q1
    lower = Q1 - k * IQR
    upper = Q3 + k * IQR
    return (data < lower) | (data > upper)

df['is_outlier_iqr'] = iqr_outlier_detection(df['value'])
```

#### 2.2.2 分位数方法

```python
# 直接用分位数界定
lower = df['value'].quantile(0.01)
upper = df['value'].quantile(0.99)
df['is_outlier_quantile'] = (df['value'] < lower) | (df['value'] > upper)
```

## 3. 基于距离的异常检测

### 3.1 k-近邻距离

数据点 $x_i$ 的 $k$-近邻距离定义为：

$$\text{dist}_k(x_i) = d(x_i, x_i^{(k)})$$

其中 $x_i^{(k)}$ 是 $x_i$ 的第 $k$ 个最近邻。异常点的 $k$-近邻距离通常较大。

### 3.2 基于距离的异常因子

$$\text{DB}(x_i, k) = \frac{1}{|\text{N}_k(x_i)|} \sum_{x_j \in \text{N}_k(x_i)} d(x_i, x_j)$$

```python
from sklearn.neighbors import NearestNeighbors

def knn_outlier_detection(X, k=5, threshold_percentile=95):
    nn = NearestNeighbors(n_neighbors=k)
    nn.fit(X)
    distances, indices = nn.kneighbors(X)

    # 使用第 k 个近邻的距离作为异常分数
    k_distances = distances[:, -1]

    # 基于阈值判定
    threshold = np.percentile(k_distances, threshold_percentile)
    outliers = k_distances > threshold

    return outliers, k_distances

# 多维数据示例
np.random.seed(42)
normal_data = np.random.randn(400, 2)
outlier_data = np.random.uniform(-6, 6, size=(20, 2))
X_multi = np.vstack([normal_data, outlier_data])
y_true = np.array([0] * 400 + [1] * 20)

outliers_knn, distances_knn = knn_outlier_detection(X_multi, k=10)
print(f"检测到 {outliers_knn.sum()} 个异常点")
```

## 4. 基于密度的异常检测

### 4.1 局部异常因子（LOF）

LOF（Local Outlier Factor）通过比较数据点的局部密度与其邻居的局部密度来识别异常。

**核心概念：**

1. **$k$-距离**：$k\text{-distance}(x) = d(x, x^{(k)})$
2. **可达距离**：$\text{rbd}_k(x, o) = \max(k\text{-distance}(o), d(x, o))$
3. **局部可达密度**：$\text{lrd}_k(x) = \frac{1}{\frac{1}{|\text{N}_k(x)|} \sum_{o \in \text{N}_k(x)} \text{rbd}_k(x, o)}$
4. **局部异常因子**：

$$\text{LOF}_k(x) = \frac{\frac{1}{|\text{N}_k(x)|} \sum_{o \in \text{N}_k(x)} \text{lrd}_k(o)}{\text{lrd}_k(x)}$$

当 $\text{LOF}(x) \approx 1$ 时，$x$ 与邻居密度相当（正常）；
当 $\text{LOF}(x) > 1$ 时，$x$ 处于低密度区域（异常）。

```python
from sklearn.neighbors import LocalOutlierFactor

# LOF 检测
lof = LocalOutlierFactor(n_neighbors=20, contamination=0.05)
y_pred_lof = lof.fit_predict(X_multi)
lof_scores = -lof.negative_outlier_factor_

# 可视化
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

axes[0].scatter(X_multi[y_true == 0, 0], X_multi[y_true == 0, 1],
                c='blue', alpha=0.5, label='正常')
axes[0].scatter(X_multi[y_true == 1, 0], X_multi[y_true == 1, 1],
                c='red', alpha=0.8, label='异常（真实）')
axes[0].set_title('真实标签')
axes[0].legend()

colors = np.where(y_pred_lof == -1, 'red', 'blue')
axes[1].scatter(X_multi[:, 0], X_multi[:, 1], c=colors, alpha=0.5)
axes[1].set_title(f'LOF 检测结果（异常数：{(y_pred_lof == -1).sum()}）')

plt.tight_layout()
plt.show()
```

### 4.2 LOF 的局限性

- 对参数 `n_neighbors` 敏感
- 在密度变化剧烈的数据中可能产生误报
- 高维数据中效果下降

## 5. 孤立森林（Isolation Forest）

### 5.1 算法原理

孤立森林（Isolation Forest）基于一个核心观察：**异常点比正常点更容易被"隔离"**。

**构建孤立树（iTree）：**

1. 随机选择一个特征 $q$
2. 在该特征的最小值和最大值之间随机选择一个分割点 $p$
3. 根据 $p$ 将数据分为左右子树
4. 递归直到满足终止条件（叶节点只有一个样本或达到深度限制）

**异常分数：**

$$s(x, n) = 2^{-\frac{E[h(x)]}{c(n)}}$$

其中：
- $E[h(x)]$ 是样本 $x$ 在所有孤立树中的平均路径长度
- $c(n) = 2H(n-1) - \frac{2(n-1)}{n}$ 是二叉搜索树的平均路径长度
- $H(i) = \ln(i) + 0.5772$ 是调和数

异常分数解读：
- $s \to 1$：高度异常
- $s \to 0.5$：正常
- $s \to 0$：不异常

### 5.2 代码实现

```python
from sklearn.ensemble import IsolationForest
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

np.random.seed(42)

# 生成数据
X_normal = np.random.randn(300, 2) * 0.5 + np.array([2, 2])
X_normal2 = np.random.randn(300, 2) * 0.5 + np.array([-2, -2])
X_outlier = np.random.uniform(-6, 6, size=(30, 2))
X_if = np.vstack([X_normal, X_normal2, X_outlier])

# 孤立森林
iso_forest = IsolationForest(
    n_estimators=100,
    contamination=0.05,  # 预估异常比例
    max_samples='auto',
    random_state=42
)

# 预测：1 为正常，-1 为异常
y_pred_if = iso_forest.fit_predict(X_if)
anomaly_scores = iso_forest.decision_function(X_if)

# 可视化
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
colors = np.where(y_pred_if == -1, 'red', 'blue')
plt.scatter(X_if[:, 0], X_if[:, 1], c=colors, alpha=0.6)
plt.title(f'孤立森林检测结果（异常数：{(y_pred_if == -1).sum()}）')

plt.subplot(1, 2, 2)
plt.scatter(X_if[:, 0], X_if[:, 1], c=anomaly_scores, cmap='RdYlBu_r', alpha=0.6)
plt.colorbar(label='异常分数')
plt.title('异常分数分布')

plt.tight_layout()
plt.show()
```

### 5.3 孤立森林的优势

| 对比项 | 孤立森林 | LOF | DBSCAN |
|--------|---------|-----|--------|
| 时间复杂度 | $O(t \cdot n \log \psi)$ | $O(n^2)$ 或 $O(n \log n)$ | $O(n \log n)$ |
| 可扩展性 | 好 | 一般 | 差 |
| 高维表现 | 较好 | 差 | 差 |
| 全局/局部 | 全局 | 局部 | 局部 |
| 参数敏感度 | 低 | 中 | 高 |

## 6. 基于聚类的异常检测

### 6.1 DBSCAN

DBSCAN 将密度低于核心点邻域的点标记为噪声（异常）：

```python
from sklearn.cluster import DBSCAN

dbscan = DBSCAN(eps=0.5, min_samples=5)
labels = dbscan.fit_predict(X_if)

# label == -1 为噪声点（异常）
n_outliers = (labels == -1).sum()
print(f"DBSCAN 检测到 {n_outliers} 个异常点")

plt.figure(figsize=(8, 6))
unique_labels = set(labels)
colors = plt.cm.viridis(np.linspace(0, 1, len(unique_labels)))
for label, color in zip(unique_labels, colors):
    mask = labels == label
    if label == -1:
        plt.scatter(X_if[mask, 0], X_if[mask, 1], c='red', marker='x',
                    s=100, label='噪声')
    else:
        plt.scatter(X_if[mask, 0], X_if[mask, 1], c=[color], alpha=0.6,
                    label=f'簇 {label}')
plt.legend()
plt.title('DBSCAN 聚类结果')
plt.show()
```

### 6.2 基于 K-Means 的异常检测

$$\text{异常分数}(x_i) = \min_k \|x_i - \mu_k\|^2$$

离最近聚类中心最远的点视为异常：

```python
from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
kmeans.fit(X_if)

# 计算到最近聚类中心的距离
distances = kmeans.transform(X_if).min(axis=1)
threshold = np.percentile(distances, 95)
outliers_km = distances > threshold

print(f"K-Means 检测到 {outliers_km.sum()} 个异常点")
```

## 7. 基于模型的异常检测

### 7.1 One-Class SVM

```python
from sklearn.svm import OneClassSVM

ocsvm = OneClassSVM(kernel='rbf', gamma='scale', nu=0.05)
y_pred_svm = ocsvm.fit_predict(X_if)

print(f"One-Class SVM 检测到 {(y_pred_svm == -1).sum()} 个异常点")
```

One-Class SVM 的优化目标：

$$\min_{w, \xi, \rho} \frac{1}{2} \|w\|^2 + \frac{1}{\nu n} \sum_{i=1}^{n} \xi_i - \rho$$

$$\text{s.t.} \quad w \cdot \phi(x_i) \geq \rho - \xi_i, \quad \xi_i \geq 0$$

### 7.2 Elliptic Envelope

假设数据服从多元正态分布，利用马氏距离检测异常：

$$D_M(x) = \sqrt{(x - \mu)^T \Sigma^{-1} (x - \mu)}$$

```python
from sklearn.covariance import EllipticEnvelope

ee = EllipticEnvelope(contamination=0.05, random_state=42)

print(f"Elliptic Envelope 检测到 {(y_pred_ee == -1).sum()} 个异常点")
```

## 8. 基于深度学习的异常检测

### 8.1 自编码器（AutoEncoder）

利用自编码器的重构误差检测异常：

$$\text{异常分数} = \|x - \hat{x}\|^2 = \|x - f_\theta(x)\|^2$$

```python
import torch
import torch.nn as nn

class AutoEncoder(nn.Module):
    def __init__(self, input_dim, hidden_dim=64, latent_dim=16):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, latent_dim),
            nn.ReLU()
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim)
        )

    def forward(self, x):
        z = self.encoder(x)
        x_recon = self.decoder(z)
        return x_recon

# 训练（仅使用正常数据）
input_dim = X_if.shape[1]
model = AutoEncoder(input_dim)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.MSELoss()

X_tensor = torch.FloatTensor(X_if)
dataset = torch.utils.data.TensorDataset(X_tensor, X_tensor)
loader = torch.utils.data.DataLoader(dataset, batch_size=64, shuffle=True)

for epoch in range(100):
    for batch_x, _ in loader:
        x_recon = model(batch_x)
        loss = criterion(x_recon, batch_x)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

# 计算重构误差
model.eval()
with torch.no_grad():
    X_recon = model(X_tensor)
    recon_errors = torch.mean((X_tensor - X_recon) ** 2, dim=1).numpy()

# 异常判定
threshold_ae = np.percentile(recon_errors, 95)
outliers_ae = recon_errors > threshold_ae
print(f"自编码器检测到 {outliers_ae.sum()} 个异常点")
```

### 8.2 VAE（变分自编码器）

$$\mathcal{L}(\theta, \phi; x) = \mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] - D_{KL}(q_\phi(z|x) \| p(z))$$

VAE 的异常分数为重构概率而非简单的重构误差。

## 9. 多方法集成

### 9.1 投票法

```python
from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.svm import OneClassSVM
from sklearn.covariance import EllipticEnvelope

methods = {
    'IsolationForest': IsolationForest(contamination=0.05, random_state=42),
    'LOF': LocalOutlierFactor(n_neighbors=20, contamination=0.05),
    'OneClassSVM': OneClassSVM(kernel='rbf', nu=0.05),
    'EllipticEnvelope': EllipticEnvelope(contamination=0.05, random_state=42),
}

predictions = {}
for name, method in methods.items():
    pred = method.fit_predict(X_if)
    predictions[name] = (pred == -1).astype(int)

pred_matrix = np.column_stack(list(predictions.values()))

# 多数投票
vote_sum = pred_matrix.sum(axis=1)
ensemble_outlier = vote_sum >= 3  # 至少 3 种方法认为是异常

print(f"集成方法检测到 {ensemble_outlier.sum()} 个异常点")
```

### 9.2 异常分数融合

```python
# 标准化各方法的异常分数后加权平均
```

### 10.2 无标签评估

在没有真实标签时，可以使用以下方法评估：

- **稳定性分析**：多次运行结果的一致性
- **人工审查**：抽样检查异常点是否确实异常
- **业务验证**：异常检测结果是否符合业务逻辑
- **轮廓系数**：将正常和异常分别视为两组，计算聚类质量

## 11. 关键要点总结

1. **没有万能方法**：不同方法适用于不同的数据分布和异常类型
2. **孤立森林是首选**：速度快、参数少、适合大多数场景
3. **LOF 擅长局部异常**：适合密度不均匀的数据
4. **集成方法更稳健**：多方法投票能减少误报
5. **参数调优很重要**：`contamination`、`n_neighbors` 等参数对结果影响大
6. **无监督为主**：异常检测通常没有标签，评估困难
7. **深度学习方法**：适合复杂高维数据，但需要大量正常样本
8. **结果需要人工审查**：自动检测的结果必须经过人工验证
9. **异常不一定是错误**：有时异常点包含最有价值的信息
