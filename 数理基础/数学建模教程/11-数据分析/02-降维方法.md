# 降维方法

## 1. 降维概述

### 1.1 为什么要降维

高维数据带来一系列问题，统称为**维度灾难**（Curse of Dimensionality）：

- **计算复杂度**：特征数 $p$ 增大，模型训练和推理时间呈指数级增长
- **过拟合风险**：参数量随维度增长，模型在有限样本上容易过拟合
- **数据稀疏**：高维空间中数据点之间距离趋于相等，距离度量失效
- **可视化困难**：人类只能直观理解 2-3 维空间

降维的目标是在尽可能保留原始信息的前提下，将数据从 $p$ 维映射到 $d$ 维（$d \ll p$）。

### 1.2 降维分类

| 方法 | 类型 | 特点 |
|------|------|------|
| PCA | 线性/无监督 | 最大化方差 |
| LDA | 线性/有监督 | 最大化类间可分性 |
| t-SNE | 非线性/无监督 | 保持局部结构，适合可视化 |
| UMAP | 非线性/无监督 | 更快，可保持全局结构 |
| AutoEncoder | 非线性/无监督 | 学习非线性编码映射 |
| ICA | 线性/无监督 | 最大化统计独立性 |

## 2. 主成分分析（PCA）

### 2.1 数学原理

给定中心化数据矩阵 $X \in \mathbb{R}^{n \times p}$（每列均值为零），PCA 寻找投影方向 $w$，使得投影后数据方差最大：

$$\max_{w} \; w^T S w \quad \text{s.t.} \quad w^T w = 1$$

其中 $S = \frac{1}{n} X^T X$ 为协方差矩阵。

通过 Lagrange 乘子法，上述优化等价于求解特征值问题：

$$S w = \lambda w$$

特征值从大到小排序 $\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_p$，对应的特征向量 $w_1, w_2, \ldots, w_p$ 即为主成分方向。

第 $k$ 个主成分的方差贡献率为：

$$\text{解释方差比}_k = \frac{\lambda_k}{\sum_{i=1}^{p} \lambda_i}$$

累积方差贡献率：

$$\text{累积贡献率} = \frac{\sum_{i=1}^{d} \lambda_i}{\sum_{i=1}^{p} \lambda_i}$$

通常选取 $d$ 使得累积贡献率达到 85%-95%。

### 2.2 SVD 视角

PCA 可以通过对 $X$ 的奇异值分解（SVD）来实现：

$$X = U \Sigma V^T$$

其中 $V$ 的列向量就是主成分方向，$\Sigma$ 的对角元素 $\sigma_i$ 与特征值的关系为 $\lambda_i = \sigma_i^2 / n$。

### 2.3 代码实现

```python
import numpy as np
import pandas as pd
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 加载数据
from sklearn.datasets import load_iris
iris = load_iris()
X = iris.data
y = iris.target

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# PCA 降维
pca = PCA()
X_pca = pca.fit_transform(X_scaled)

# 查看各主成分的方差解释比
print("各主成分解释方差比：", pca.explained_variance_ratio_)
print("累积解释方差比：", np.cumsum(pca.explained_variance_ratio_))

# 选择保留 95% 方差的维度
pca_95 = PCA(n_components=0.95)
X_pca_95 = pca_95.fit_transform(X_scaled)
print(f"降维后维度：{X_pca_95.shape[1]}")

# 指定维度
pca_2d = PCA(n_components=2)
X_2d = pca_2d.fit_transform(X_scaled)

# 可视化
plt.figure(figsize=(10, 5))

plt.subplot(1, 2, 1)
plt.plot(range(1, len(pca.explained_variance_ratio_) + 1),
         np.cumsum(pca.explained_variance_ratio_), 'bo-')
plt.xlabel('主成分数量')
plt.ylabel('累积解释方差比')
plt.title('碎石图（Scree Plot）')

plt.subplot(1, 2, 2)
for label in np.unique(y):
    mask = y == label
    plt.scatter(X_2d[mask, 0], X_2d[mask, 1], label=iris.target_names[label])
plt.xlabel(f'PC1 ({pca_2d.explained_variance_ratio_[0]:.1%})')
plt.ylabel(f'PC2 ({pca_2d.explained_variance_ratio_[1]:.1%})')
plt.legend()
plt.title('PCA 二维投影')

plt.tight_layout()
plt.show()
```

### 2.4 载荷分析

主成分载荷（loading）反映了原始特征对主成分的贡献：

$$\text{loading}_{ij} = w_{ij} \sqrt{\lambda_j}$$

```python
# 载荷矩阵
loadings = pd.DataFrame(
    pca_2d.components_.T * np.sqrt(pca_2d.explained_variance_),
    columns=['PC1', 'PC2'],
    feature_names=iris.feature_names
)
print(loadings)

# 双标图（Biplot）
plt.figure(figsize=(8, 6))
plt.scatter(X_2d[:, 0], X_2d[:, 1], c=y, cmap='viridis', alpha=0.6)

# 绘制载荷箭头
for i, feature in enumerate(iris.feature_names):
    plt.annotate('',
                 xy=(loadings.iloc[i, 0] * 3, loadings.iloc[i, 1] * 3),
                 xytext=(0, 0),
                 arrowprops=dict(arrowstyle='->', color='red', lw=2))
    plt.text(loadings.iloc[i, 0] * 3.3, loadings.iloc[i, 1] * 3.3,
             feature, color='red', fontsize=10)

plt.xlabel('PC1')
plt.ylabel('PC2')
plt.title('PCA 双标图')
plt.show()
```

### 2.5 核 PCA（Kernel PCA）

当数据存在非线性结构时，核 PCA 通过核函数将数据映射到高维特征空间，再进行 PCA：

$$K_{ij} = \phi(x_i)^T \phi(x_j) = \kappa(x_i, x_j)$$

常用核函数：

- 多项式核：$\kappa(x, y) = (x^T y + c)^d$
- RBF 核：$\kappa(x, y) = \exp(-\gamma \|x - y\|^2)$
- Sigmoid 核：$\kappa(x, y) = \tanh(\alpha x^T y + c)$

```python
from sklearn.decomposition import KernelPCA

kpca = KernelPCA(n_components=2, kernel='rbf', gamma=15)
X_kpca = kpca.fit_transform(X_scaled)
```

## 3. 线性判别分析（LDA）

### 3.1 数学原理

LDA 是一种有监督降维方法，目标是找到投影方向，使**类间方差最大化**、**类内方差最小化**。

定义：

- 类内散布矩阵：$S_W = \sum_{k=1}^{K} \sum_{x_i \in C_k} (x_i - \mu_k)(x_i - \mu_k)^T$
- 类间散布矩阵：$S_B = \sum_{k=1}^{K} n_k (\mu_k - \mu)(\mu_k - \mu)^T$

LDA 的目标函数：

$$\max_{w} \; J(w) = \frac{w^T S_B w}{w^T S_W w}$$

通过对广义特征值问题求解：

$$S_B w = \lambda S_W w$$

最多可得到 $K-1$ 个判别向量（$K$ 为类别数）。

### 3.2 代码实现

```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

# LDA 降维
lda = LinearDiscriminantAnalysis(n_components=2)
X_lda = lda.fit_transform(X_scaled, y)

print("各判别式的解释方差比：", lda.explained_variance_ratio_)

# 可视化
plt.figure(figsize=(8, 6))
for label in np.unique(y):
    mask = y == label
    plt.scatter(X_lda[mask, 0], X_lda[mask, 1],
                label=iris.target_names[label], alpha=0.7)
plt.xlabel(f'LD1 ({lda.explained_variance_ratio_[0]:.1%})')
plt.ylabel(f'LD2 ({lda.explained_variance_ratio_[1]:.1%})')
plt.legend()
plt.title('LDA 二维投影')
plt.show()
```

### 3.3 PCA vs LDA

| 对比项 | PCA | LDA |
|--------|-----|-----|
| 监督性 | 无监督 | 有监督 |
| 目标 | 最大化全局方差 | 最大化类间可分性 |
| 降维上限 | 特征数 $p$ | 类别数 $K-1$ |
| 适用场景 | 数据压缩、去噪 | 分类前预处理 |
| 对标签依赖 | 不需要 | 需要 |

## 4. t-SNE

### 4.1 算法原理

t-SNE（t-distributed Stochastic Neighbor Embedding）是一种非线性降维方法，特别适合高维数据的可视化。

**步骤1：高维空间中的相似度**

对数据点 $x_i$ 和 $x_j$，定义条件概率：

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}$$

对称化后得到联合概率：

$$p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}$$

其中 $\sigma_i$ 通过困惑度（perplexity）参数自动确定。

**步骤2：低维空间中的相似度**

在低维空间中使用自由度为 1 的 t 分布（Student t-distribution）：

$$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|y_k - y_l\|^2)^{-1}}$$

使用 t 分布的原因：长尾特性可以缓解"拥挤问题"（crowding problem）。

**步骤3：优化目标**

最小化两个分布的 KL 散度：

$$\text{KL}(P \| Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

梯度为：

$$\frac{\delta \text{KL}}{\delta y_i} = 4 \sum_{j} (p_{ij} - q_{ij})(y_i - y_j)(1 + \|y_i - y_j\|^2)^{-1}$$

### 4.2 困惑度（Perplexity）

困惑度可理解为"有效邻居数"，通常设为 5-50。较低的困惑度强调局部结构，较高的困惑度强调全局结构。

### 4.3 代码实现

```python
from sklearn.manifold import TSNE

# t-SNE 降维
tsne = TSNE(n_components=2, perplexity=30, random_state=42,
            n_iter=1000, learning_rate='auto', init='pca')
X_tsne = tsne.fit_transform(X_scaled)

# 可视化
plt.figure(figsize=(8, 6))
scatter = plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='viridis', alpha=0.7)
plt.colorbar(scatter)
plt.title(f't-SNE 二维投影 (KL散度: {tsne.kl_divergence_:.4f})')
plt.show()

# 不同困惑度的对比
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, perplexity in zip(axes, [5, 30, 50]):
    tsne_temp = TSNE(n_components=2, perplexity=perplexity, random_state=42)
    X_temp = tsne_temp.fit_transform(X_scaled)
    ax.scatter(X_temp[:, 0], X_temp[:, 1], c=y, cmap='viridis', alpha=0.7)
    ax.set_title(f'Perplexity = {perplexity}')
plt.tight_layout()
plt.show()
```

### 4.4 t-SNE 的局限性

- 计算复杂度为 $O(n^2)$，大数据集很慢
- 结果受随机种子影响，每次运行可能不同
- 不保留全局距离关系，仅保持局部结构
- 新数据无法直接映射（不能 `transform`）

## 5. UMAP

### 5.1 算法原理

UMAP（Uniform Manifold Approximation and Projection）基于黎曼几何和代数拓扑理论，速度更快且能更好地保留全局结构。

**步骤1：构建高维图**

基于 $k$-近邻图，为每条边赋予权重：

$$w_{ij} = \exp\left(-\frac{\max(0, d(x_i, x_j) - \rho_i)}{\sigma_i}\right)$$

其中 $\rho_i$ 是到第 $k$ 近邻的距离，$\sigma_i$ 通过交叉熵确定。

**步骤2：构建低维图**

在低维空间中，边权重定义为：

$$w_{ij} = \frac{1}{1 + a \cdot \|y_i - y_j\|^{2b}}$$

参数 $a$ 和 $b$ 通过最小二乘拟合确定。

**步骤3：优化**

最小化交叉熵：

$$C = \sum_{(i,j)} \left[ w_{ij} \log \frac{w_{ij}}{v_{ij}} + (1 - w_{ij}) \log \frac{1 - w_{ij}}{1 - v_{ij}} \right]$$

### 5.2 代码实现

```python
import umap

# UMAP 降维
reducer = umap.UMAP(n_components=2, n_neighbors=15, min_dist=0.1,
                     metric='euclidean', random_state=42)
X_umap = reducer.fit_transform(X_scaled)

# 可视化
plt.figure(figsize=(8, 6))
plt.scatter(X_umap[:, 0], X_umap[:, 1], c=y, cmap='viridis', alpha=0.7)
plt.title('UMAP 二维投影')
plt.show()
```

### 5.3 UMAP 参数说明

| 参数 | 说明 | 影响 |
|------|------|------|
| `n_neighbors` | 近邻数 | 小→局部结构，大→全局结构 |
| `min_dist` | 点之间最小距离 | 小→聚集，大→分散 |
| `n_components` | 输出维度 | 通常为 2 或 3 |
| `metric` | 距离度量 | euclidean, cosine, manhattan 等 |

### 5.4 t-SNE vs UMAP

| 对比项 | t-SNE | UMAP |
|--------|-------|------|
| 速度 | 慢 $O(n^2)$ | 快 $O(n)$ |
| 全局结构 | 保留差 | 保留好 |
| 新数据映射 | 不支持 | 支持（`transform`） |
| 参数 | perplexity | n_neighbors, min_dist |
| 可扩展性 | 差 | 好，支持大数据集 |

## 6. 其他降维方法简介

### 6.1 独立成分分析（ICA）

寻找统计独立的分量，适用于盲源分离（BSS）问题：

$$X = A S$$

其中 $A$ 为混合矩阵，$S$ 为独立源信号。

```python
from sklearn.decomposition import FastICA

ica = FastICA(n_components=2, random_state=42)
X_ica = ica.fit_transform(X_scaled)
```

### 6.2 随机投影（Random Projection）

基于 Johnson-Lindenstrauss 引理：高维数据可以随机投影到低维空间而近似保持距离关系。

$$\epsilon \text{-preserve: } (1-\epsilon)\|u-v\|^2 \leq \|Ru-Rv\|^2 \leq (1+\epsilon)\|u-v\|^2$$

其中 $R \in \mathbb{R}^{d \times p}$ 为随机矩阵。

```python
from sklearn.random_projection import GaussianRandomProjection

rp = GaussianRandomProjection(n_components=2, random_state=42)
X_rp = rp.fit_transform(X_scaled)
```

### 6.3 多维缩放（MDS）

保持样本间距离的降维方法：

$$\min \sum_{i<j} (\|x_i - x_j\| - \|y_i - y_j\|)^2$$

```python
from sklearn.manifold import MDS

mds = MDS(n_components=2, random_state=42)
X_mds = mds.fit_transform(X_scaled)
```

## 7. 降维方法对比实验

```python
from sklearn.datasets import make_moons, make_circles

# 生成非线性数据
X_moons, y_moons = make_moons(n_samples=300, noise=0.1, random_state=42)

# 对比不同方法
methods = {
    'PCA': PCA(n_components=2),
    'LDA': LinearDiscriminantAnalysis(n_components=2),  # LDA 需要标签
    'Kernel PCA': KernelPCA(n_components=2, kernel='rbf', gamma=15),
    't-SNE': TSNE(n_components=2, perplexity=30, random_state=42),
    'UMAP': umap.UMAP(n_components=2, random_state=42),
}

fig, axes = plt.subplots(2, 3, figsize=(15, 10))
for ax, (name, method) in zip(axes.flatten(), methods.items()):
    if name == 'LDA':
        X_proj = method.fit_transform(X_moons, y_moons)
    else:
        X_proj = method.fit_transform(X_moons)
    ax.scatter(X_proj[:, 0], X_proj[:, 1], c=y_moons, cmap='viridis', alpha=0.7)
    ax.set_title(name)

axes.flatten()[-1].axis('off')
plt.tight_layout()
plt.show()
```

## 8. 降维方法选择指南

### 8.1 选择决策树

1. **目的为数据压缩/去噪** → PCA
2. **目的为分类预处理** → LDA
3. **目的为可视化（$n < 10000$）** → t-SNE
4. **目的为可视化（$n \geq 10000$）** → UMAP
5. **目的为特征预处理** → PCA 或 UMAP
6. **数据有非线性结构** → Kernel PCA / UMAP
7. **需要处理新数据** → PCA / UMAP（t-SNE 不行）

### 8.2 维度选择准则

- **Kaiser 准则**：保留特征值 $\lambda_k > 1$ 的主成分
- **累计方差准则**：保留累积解释方差 $\geq 85\%$ 的主成分
- **碎石图准则**：选择特征值曲线"拐点"之前的主成分
- **交叉验证准则**：以最终任务（如分类）性能为准

## 9. 关键要点总结

1. **PCA 是首选**：简单高效，适用于大多数场景，是降维的默认选择
2. **标准化很重要**：PCA 对特征尺度敏感，使用前必须标准化
3. **t-SNE 仅用于可视化**：结果不可复现，不能用于特征工程
4. **UMAP 是更好的选择**：比 t-SNE 快，保留全局结构，支持 `transform`
5. **LDA 需要标签**：但降维上限为 $K-1$，类别多时维度受限
6. **核方法处理非线性**：Kernel PCA 适合中等规模的非线性数据
7. **降维后需评估**：通过可视化和下游任务性能综合评估降维效果
