# 随机过程基础 (Random Processes)

## 一、概述

随机过程是定义在概率空间上的一族随机变量 $\{X_t : t \in T\}$，用于描述随时间（或空间）演化的随机现象。当 $t$ 取离散值时为离散时间随机过程，取连续值时为连续时间随机过程。

### 1.1 基本定义

**定义**：随机过程是一个二元函数 $X(t, \omega)$，其中 $t \in T$（参数集），$\omega \in \Omega$（样本空间）。

- 固定 $t$，$X(t, \cdot)$ 是一个随机变量
- 固定 $\omega$，$X(\cdot, \omega)$ 是一条样本路径（实现）

### 1.2 分类

| 分类标准 | 类别 |
|----------|------|
| 参数集 | 离散时间 / 连续时间 |
| 状态空间 | 离散状态 / 连续状态 |
| 统计特性 | 独立增量 / 马尔可夫性 / 平稳性 |
| 分布类型 | 泊松过程 / 布朗运动 / 马尔可夫链 |

## 二、随机过程的统计描述

### 2.1 均值函数和自相关函数

**均值函数**：

$$\mu_X(t) = E[X(t)]$$

**自相关函数**：

$$R_X(t_1, t_2) = E[X(t_1) X(t_2)]$$

**自协方差函数**：

$$C_X(t_1, t_2) = \text{Cov}(X(t_1), X(t_2)) = R_X(t_1, t_2) - \mu_X(t_1) \mu_X(t_2)$$

### 2.2 平稳性

**严平稳（强平稳）**：对任意 $n, t_1, \ldots, t_n$ 和 $\tau$，$(X(t_1), \ldots, X(t_n))$ 与 $(X(t_1 + \tau), \ldots, X(t_n + \tau))$ 有相同的联合分布。

**宽平稳（弱平稳）**：
1. $E[X(t)] = \mu$（常数）
2. $\text{Var}(X(t)) < \infty$
3. $R_X(t_1, t_2)$ 仅依赖于 $t_1 - t_2$

对宽平稳过程，自相关函数可写为 $R_X(\tau) = E[X(t) X(t + \tau)]$。

### 2.3 功率谱密度

对宽平稳过程，功率谱密度为自相关函数的 Fourier 变换：

$$S_X(\omega) = \int_{-\infty}^{\infty} R_X(\tau) e^{-i\omega \tau} \, d\tau$$

反变换关系（Wiener-Khinchin 定理）：

$$R_X(\tau) = \frac{1}{2\pi} \int_{-\infty}^{\infty} S_X(\omega) e^{i\omega \tau} \, d\omega$$

## 三、泊松过程 (Poisson Process)

### 3.1 定义与性质

泊松过程 $\{N(t), t \geq 0\}$ 是计数过程，描述事件在时间轴上的随机到达。

**定义性质**：
1. $N(0) = 0$
2. 具有独立增量
3. 对 $s < t$，$N(t) - N(s) \sim \text{Poisson}(\lambda(t - s))$
4. 增量的概率：$P(N(t) - N(s) = k) = \frac{[\lambda(t-s)]^k}{k!} e^{-\lambda(t-s)}$

其中 $\lambda > 0$ 为强度参数（到达率）。

### 3.2 泊松过程的性质

**均值和方差**：

$$E[N(t)] = \lambda t, \quad \text{Var}(N(t)) = \lambda t$$

**自相关函数**：

$$E[N(t) N(s)] = \lambda \min(t, s) + \lambda^2 ts$$

**自协方差函数**：

$$\text{Cov}(N(t), N(s)) = \lambda \min(t, s)$$

### 3.3 等待时间与到达间隔

设 $T_n$ 为第 $n$ 次到达的时刻，$W_n = T_n - T_{n-1}$ 为第 $n$ 个到达间隔。

**定理**：到达间隔 $W_1, W_2, \ldots$ 独立同分布，服从参数为 $\lambda$ 的指数分布：

$$f_W(t) = \lambda e^{-\lambda t}, \quad t \geq 0$$

**定理**：第 $n$ 次到达时刻 $T_n$ 服从 Erlang（伽马）分布：

$$f_{T_n}(t) = \frac{\lambda^n t^{n-1}}{(n-1)!} e^{-\lambda t}, \quad t \geq 0$$

即 $T_n \sim \text{Gamma}(n, \lambda)$。

### 3.4 泊松过程的到达时间均匀分布性质

**定理**：在 $[0, T]$ 内已知有 $n$ 次到达的条件下，到达时刻 $T_1, T_2, \ldots, T_n$ 的联合分布等同于 $n$ 个独立 $U(0, T)$ 随机变量的顺序统计量。

### 3.5 非齐次泊松过程

强度函数 $\lambda(t)$ 随时间变化：

$$P(N(t) - N(s) = k) = \frac{\left[\int_s^t \lambda(u) \, du\right]^k}{k!} \exp\left[-\int_s^t \lambda(u) \, du\right]$$

### 3.6 复合泊松过程

$$X(t) = \sum_{i=1}^{N(t)} Y_i$$

其中 $N(t)$ 为泊松过程，$Y_i$ 为独立同分布的随机变量。

**矩生成函数**：

$$E[e^{sX(t)}] = \exp\left\{\lambda t \left[M_Y(s) - 1\right]\right\}$$

其中 $M_Y(s) = E[e^{sY}]$ 为 $Y$ 的矩生成函数。

```python
import numpy as np
import matplotlib.pyplot as plt

def simulate_poisson(lam, T, n_paths=5):
    """模拟泊松过程"""
    fig, ax = plt.subplots(figsize=(10, 4))
    for _ in range(n_paths):
        n_events = np.random.poisson(lam * T)
        event_times = np.sort(np.random.uniform(0, T, n_events))
        times = np.concatenate([[0], event_times, [T]])
        counts = np.arange(len(times))
        ax.step(times, counts, where='post')
    ax.set_xlabel('Time')
    ax.set_ylabel('N(t)')
    ax.set_title(f'Poisson Process (λ={lam})')
    plt.show()

def poisson_arrival_intervals(lam, n_events):
    """模拟泊松过程的到达间隔"""
    intervals = np.random.exponential(1/lam, n_events)
    arrival_times = np.cumsum(intervals)
    return intervals, arrival_times
```

## 四、布朗运动 (Brownian Motion)

### 4.1 定义

标准布朗运动（维纳过程）$\{W(t), t \geq 0\}$ 满足：

1. $W(0) = 0$
2. 具有独立增量
3. 对 $s < t$，$W(t) - W(s) \sim N(0, t - s)$
4. 样本路径几乎必然连续

### 4.2 基本性质

**有限维分布**：对 $0 = t_0 < t_1 < \cdots < t_n$，增量 $W(t_1) - W(t_0), \ldots, W(t_n) - W(t_{n-1})$ 独立，且：

$$W(t_i) - W(t_{i-1}) \sim N(0, t_i - t_{i-1})$$

**均值和方差**：

$$E[W(t)] = 0, \quad \text{Var}(W(t)) = t$$

**自相关函数**：

$$E[W(t_1) W(t_2)] = \min(t_1, t_2)$$

**自协方差函数**：

$$\text{Cov}(W(t_1), W(t_2)) = \min(t_1, t_2)$$

### 4.3 重要性质

**反射原理**：对 $a > 0$：

$$P\left(\max_{0 \leq s \leq t} W(s) \geq a\right) = 2 P(W(t) \geq a) = 2\left[1 - \Phi\left(\frac{a}{\sqrt{t}}\right)\right]$$

**最大值分布**：

$$P\left(\max_{0 \leq s \leq t} W(s) \leq x\right) = 2\Phi\left(\frac{x}{\sqrt{t}}\right) - 1, \quad x \geq 0$$

**首达时**：$T_a = \inf\{t > 0 : W(t) = a\}$

$$P(T_a \leq t) = 2\left[1 - \Phi\left(\frac{|a|}{\sqrt{t}}\right)\right]$$

$T_a$ 的密度为：

$$f_{T_a}(t) = \frac{|a|}{\sqrt{2\pi t^3}} e^{-a^2/(2t)}$$

这是逆高斯分布（Lévy 分布）。

### 4.4 几何布朗运动

$$dS(t) = \mu S(t) \, dt + \sigma S(t) \, dW(t)$$

解为：

$$S(t) = S(0) \exp\left[\left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W(t)\right]$$

几何布朗运动是 Black-Scholes 期权定价模型的基础。

### 4.5 布朗运动的尺度不变性

对 $c > 0$，$\{c^{-1/2} W(ct) : t \geq 0\}$ 仍是标准布朗运动。

### 4.6 布朗桥

在条件 $W(0) = 0$ 和 $W(T) = 0$ 下，$\{W(t), 0 \leq t \leq T\}$ 称为布朗桥。

$$E[W(t) | W(T) = 0] = 0$$
$$\text{Cov}(W(s), W(t) | W(T) = 0) = \min(s, t) - \frac{st}{T}$$

```python
import numpy as np
import matplotlib.pyplot as plt

def simulate_brownian_motion(n_steps, T, n_paths=5):
    """模拟标准布朗运动"""
    dt = T / n_steps
    t = np.linspace(0, T, n_steps + 1)
    fig, ax = plt.subplots(figsize=(10, 4))
    for _ in range(n_paths):
        dW = np.random.normal(0, np.sqrt(dt), n_steps)
        W = np.concatenate([[0], np.cumsum(dW)])
        ax.plot(t, W)
    ax.set_xlabel('Time')
    ax.set_ylabel('W(t)')
    ax.set_title('Standard Brownian Motion')
    plt.show()

def simulate_geometric_brownian(S0, mu, sigma, T, n_steps, n_paths=5):
    """模拟几何布朗运动"""
    dt = T / n_steps
    t = np.linspace(0, T, n_steps + 1)
    fig, ax = plt.subplots(figsize=(10, 4))
    for _ in range(n_paths):
        dW = np.random.normal(0, np.sqrt(dt), n_steps)
        W = np.concatenate([[0], np.cumsum(dW)])
        S = S0 * np.exp((mu - 0.5 * sigma**2) * t + sigma * W)
        ax.plot(t, S)
    ax.set_xlabel('Time')
    ax.set_ylabel('S(t)')
    ax.set_title(f'Geometric Brownian Motion (μ={mu}, σ={sigma})')
    plt.show()
```

## 五、其他重要随机过程

### 5.1 马尔可夫过程

**马尔可夫性（无记忆性）**：

$$P(X(t_n) \leq x_n | X(t_1) = x_1, \ldots, X(t_{n-1}) = x_{n-1}) = P(X(t_n) \leq x_n | X(t_{n-1}) = x_{n-1})$$

### 5.2 平稳过程

**遍历性**：时间平均等于集合平均：

$$\lim_{T \to \infty} \frac{1}{T} \int_0^T X(t) \, dt = E[X(t)] \quad \text{a.s.}$$

### 5.3 Lévy 过程

具有独立平稳增量的随机过程，包括：
- 布朗运动（高斯 Lévy 过程）
- 泊松过程（整数值 Lévy 过程）
- 复合泊松过程
- 稳定过程

### 5.4 鞅 (Martingale)

**定义**：$\{X_t, \mathcal{F}_t\}$ 是鞅，若：
1. $E[|X_t|] < \infty$ 对所有 $t$
2. $E[X_t | \mathcal{F}_s] = X_s$ 对所有 $s < t$

**例子**：
- 布朗运动 $W(t)$ 是鞅
- 泊松过程 $N(t) - \lambda t$ 是鞅
- 几何布朗运动 $S(t)/e^{\mu t}$ 在适当测度下是鞅

**Doob 鞅不等式**：

$$P\left(\max_{0 \leq s \leq t} |X_s| \geq \lambda\right) \leq \frac{E[|X_t|^p]}{\lambda^p}, \quad p \geq 1$$

## 六、随机过程的模拟方法

### 6.1 离散化方法

对于连续时间随机过程，通常需要离散化后在计算机上模拟。

**Euler-Maruyama 方法**：

对 $dX_t = a(X_t) \, dt + b(X_t) \, dW_t$：

$$X_{n+1} = X_n + a(X_n) \Delta t + b(X_n) \Delta W_n$$

其中 $\Delta W_n \sim N(0, \Delta t)$。

**Milstein 方法**（更高阶精度）：

$$X_{n+1} = X_n + a(X_n) \Delta t + b(X_n) \Delta W_n + \frac{1}{2} b(X_n) b'(X_n) [(\Delta W_n)^2 - \Delta t]$$

### 6.2 泊松过程模拟

```python
import numpy as np

def simulate_poisson_thinning(lam_func, T, lam_max):
    """薄化法模拟非齐次泊松过程"""
    events = []
    t = 0
    while t < T:
        t += np.random.exponential(1 / lam_max)
        if t < T:
            if np.random.uniform() < lam_func(t) / lam_max:
                events.append(t)
    return np.array(events)
```

### 6.3 布朗运动路径生成

```python
def brownian_bridge_path(t_points, W_T):
    """生成通过指定端点的布朗桥路径"""
    n = len(t_points) - 1
    path = np.zeros(n + 1)
    path[0] = 0
    path[-1] = W_T
    # 随机二分法
    indices = list(range(1, n))
    np.random.shuffle(indices)
    for idx in indices:
        t_left = t_points[idx - 1]
        t_right = t_points[idx + 1] if idx + 1 <= n else t_points[-1]
        t_curr = t_points[idx]
        W_left = path[idx - 1]
        W_right = path[idx + 1] if idx + 1 <= n else W_T
        mean = W_left + (W_right - W_left) * (t_curr - t_left) / (t_right - t_left)
        var = (t_right - t_curr) * (t_curr - t_left) / (t_right - t_left)
        path[idx] = mean + np.random.normal(0, np.sqrt(var))
    return path
```

## 七、实际应用案例

### 7.1 保险精算：索赔过程

保险公司在时间段 $[0, T]$ 内的总索赔额：

$$S(T) = \sum_{i=1}^{N(T)} Y_i$$

其中 $N(t)$ 为泊松过程（索赔次数），$Y_i$ 为独立同分布的索赔额（如 Pareto 分布）。

**总理赔额的分布**：利用复合泊松分布：

$$M_S(u) = \exp\left\{\lambda T \left[M_Y(u) - 1\right]\right\}$$

### 7.2 金融：股票价格建模

几何布朗运动模型：

$$dS = \mu S \, dt + \sigma S \, dW$$

对数收益率 $r_t = \ln(S_{t+1}/S_t)$ 服从：

$$r_t \sim N\left[\left(\mu - \frac{\sigma^2}{2}\right)\Delta t, \sigma^2 \Delta t\right]$$

### 7.3 排队论：到达过程

M/M/1 队列中的到达过程为泊松过程，服务时间服从指数分布。

## 八、关键要点总结

1. 随机过程是随机变量的参数族，用于描述随时间演化的随机现象
2. 泊松过程是最基本的计数过程，到达间隔服从指数分布
3. 布朗运动是连续时间随机过程的基本构件，具有独立正态增量
4. 几何布朗运动是金融中资产价格建模的核心工具
5. 平稳性和遍历性使得时间平均可替代集合平均
6. 鞅理论是随机分析的基础，许多金融模型建立在鞅框架上
7. Euler-Maruyama 方法是模拟随机微分方程的最基本数值方法
8. 布朗桥在路径模拟和统计检验中有重要应用
