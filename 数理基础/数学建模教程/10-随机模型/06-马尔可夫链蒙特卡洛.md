# 马尔可夫链蒙特卡洛 (MCMC Methods)

## 一、概述

马尔可夫链蒙特卡洛（MCMC）是一类从复杂概率分布中采样的算法。当目标分布的归一化常数未知或直接采样困难时，MCMC 通过构造一个以目标分布为平稳分布的马尔可夫链来间接采样。

### 1.1 核心思想

设目标分布为 $\pi(x)$（可能仅知未归一化形式 $\tilde{\pi}(x)$），构造马尔可夫链 $\{X_t\}$，使得：

$$\lim_{t \to \infty} P(X_t \in A) = \int_A \pi(x) \, dx$$

经过足够多的迭代（burn-in），链的样本近似服从 $\pi(x)$。

### 1.2 为什么需要 MCMC

- 高维后验分布直接采样不可行
- 拒绝采样在高维空间效率极低
- 重要性采样在高维空间方差爆炸
- MCMC 可以在不知归一化常数的情况下采样

### 1.3 MCMC 的应用领域

| 领域 | 应用 |
|------|------|
| 贝叶斯统计 | 后验分布采样 |
| 机器学习 | 隐变量模型、图模型推断 |
| 统计物理 | Ising 模型、蒙特卡洛积分 |
| 计算生物 | 系统发育推断 |
| 图像处理 | 图像分割、去噪 |

## 二、马尔可夫链基础

### 2.1 马尔可夫链的定义

离散时间马尔可夫链 $\{X_n\}$ 满足：

$$P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, \ldots) = P(X_{n+1} = j | X_n = i) = p_{ij}$$

**转移概率矩阵** $P = [p_{ij}]$ 满足 $p_{ij} \geq 0$ 且 $\sum_j p_{ij} = 1$。

### 2.2 平稳分布

**定义**：分布 $\pi$ 是转移矩阵 $P$ 的平稳分布，若 $\pi P = \pi$。

即 $\pi_j = \sum_i \pi_i p_{ij}$ 对所有 $j$ 成立。

### 2.3 遍历性定理

**定理**：若马尔可夫链满足：
1. 不可约（irreducible）：任意两个状态之间可达
2. 非周期（aperiodic）：状态周期为 1
3. 正常返（positive recurrent）

则存在唯一平稳分布 $\pi$，且对任意初始状态 $i$：

$$\lim_{n \to \infty} p_{ij}^{(n)} = \pi_j$$

### 2.4 细致平衡方程 (Detailed Balance)

**定义**：若 $\pi_i p_{ij} = \pi_j p_{ji}$ 对所有 $i, j$ 成立，则称马尔可夫链满足细致平衡条件。

**重要性质**：满足细致平衡的马尔可夫链以 $\pi$ 为平稳分布。

证明：$\sum_i \pi_i p_{ij} = \sum_i \pi_j p_{ji} = \pi_j \sum_i p_{ji} = \pi_j$。

细致平衡是充分条件（比 $\pi P = \pi$ 更强），但构造起来最方便。

## 三、Metropolis-Hastings 算法

### 3.1 算法描述

**输入**：未归一化目标密度 $\tilde{\pi}(x)$，提议分布 $q(x^* | x)$

**算法**：

1. 初始化 $X_0$
2. 对 $t = 1, 2, \ldots$：
   a. 从 $q(x^* | X_{t-1})$ 生成候选样本 $x^*$
   b. 计算接受概率：

$$\alpha(x^* | X_{t-1}) = \min\left(1, \frac{\tilde{\pi}(x^*) q(X_{t-1} | x^*)}{\tilde{\pi}(X_{t-1}) q(x^* | X_{t-1})}\right)$$

   c. 以概率 $\alpha$ 接受：$X_t = x^*$；否则 $X_t = X_{t-1}$

### 3.2 正确性证明

验证细致平衡条件。对于状态 $x$ 和 $x^*$：

$$\pi(x) q(x^* | x) \alpha(x^* | x) = \pi(x) q(x^* | x) \min\left(1, \frac{\pi(x^*) q(x | x^*)}{\pi(x) q(x^* | x)}\right) = \min(\pi(x) q(x^* | x), \pi(x^*) q(x | x^*))$$

上式关于 $x$ 和 $x^*$ 对称，因此细致平衡成立。

### 3.3 提议分布的选择

**对称提议**：$q(x^* | x) = q(x | x^*)$（如随机游走提议）

$$q(x^* | x) = N(x^*, \sigma^2 I)$$

此时接受概率简化为：

$$\alpha = \min\left(1, \frac{\tilde{\pi}(x^*)}{\tilde{\pi}(x)}\right)$$

**非对称提议**：
- 独立提议：$q(x^* | x) = q(x^*)$
- 漂移随机游走：$q(x^* | x) = N(x^* | x + \mu, \sigma^2)$

### 3.4 随机游走 Metropolis

最常见的 MH 变体：

$$x^* = x + \epsilon, \quad \epsilon \sim N(0, \sigma^2 I)$$

**调节策略**：调整 $\sigma$ 使接受率约为 $23.4\%$（Roberts et al., 1997 对高维正态目标的最优值）。

### 3.5 独立 Metropolis-Hastings

提议分布与当前状态无关：$q(x^* | x) = q(x^*)$

$$\alpha = \min\left(1, \frac{\tilde{\pi}(x^*) / q(x^*)}{\tilde{\pi}(x) / q(x)}\right)$$

要求 $q$ 的尾部比 $\pi$ 厚，否则链会卡住。

```python
import numpy as np

def metropolis_hastings(target_log_pdf, initial, n_samples, proposal_std=1.0, d=1):
    """基本Metropolis-Hastings算法（随机游走提议）"""
    samples = np.zeros((n_samples, d))
    current = np.array(initial, dtype=float)
    current_log_prob = target_log_pdf(current)
    accepted = 0
    for i in range(n_samples):
        candidate = current + np.random.normal(0, proposal_std, size=d)
        candidate_log_prob = target_log_pdf(candidate)
        log_alpha = candidate_log_prob - current_log_prob
        if np.log(np.random.uniform()) < log_alpha:
            current = candidate
            current_log_prob = candidate_log_prob
            accepted += 1
        samples[i] = current
    print(f"Acceptance rate: {accepted/n_samples:.3f}")
    return samples

# 示例：从N(0,1)采样（已知归一化常数，用于验证）
target = lambda x: -0.5 * x[0]**2
samples = metropolis_hastings(target, initial=[0.0], n_samples=50000, proposal_std=0.5, d=1)
print(f"Sample mean: {np.mean(samples):.4f} (true: 0)")
print(f"Sample std:  {np.std(samples):.4f} (true: 1)")
```

## 四、Gibbs 采样

### 4.1 算法描述

Gibbs 采样是 MH 的特殊情况，每次更新一个变量（或一组变量），提议被自动接受。

**算法**：

1. 初始化 $\mathbf{x}^{(0)} = (x_1^{(0)}, \ldots, x_d^{(0)})$
2. 对 $t = 1, 2, \ldots$：
   a. 从 $p(x_1 | x_2^{(t-1)}, \ldots, x_d^{(t-1)})$ 采样 $x_1^{(t)}$
   b. 从 $p(x_2 | x_1^{(t)}, x_3^{(t-1)}, \ldots, x_d^{(t-1)})$ 采样 $x_2^{(t)}$
   c. ...
   d. 从 $p(x_d | x_1^{(t)}, \ldots, x_{d-1}^{(t)})$ 采样 $x_d^{(t)}$

### 4.2 条件分布推导

对于联合分布 $p(x_1, x_2) \propto f(x_1) g(x_2) h(x_1, x_2)$：

$$p(x_1 | x_2) \propto f(x_1) h(x_1, x_2)$$

$$p(x_2 | x_1) \propto g(x_2) h(x_1, x_2)$$

### 4.3 为什么不需要接受/拒绝

在 Gibbs 采样中，全条件分布已经是目标分布的边缘，因此从全条件分布采样自动满足细致平衡（接受率为 100%）。

### 4.4 二维正态分布示例

设 $(X, Y) \sim N(\boldsymbol{0}, \Sigma)$，其中 $\Sigma = \begin{pmatrix} 1 & \rho \\ \rho & 1 \end{pmatrix}$。

全条件分布：

$$X | Y = y \sim N(\rho y, 1 - \rho^2)$$
$$Y | X = x \sim N(\rho x, 1 - \rho^2)$$

```python
import numpy as np
import matplotlib.pyplot as plt

def gibbs_sampling_bivariate_normal(rho, n_samples, x0=0, y0=0):
    """Gibbs采样二维正态分布"""
    samples = np.zeros((n_samples, 2))
    x, y = x0, y0
    for i in range(n_samples):
        x = np.random.normal(rho * y, 1 - rho**2)
        y = np.random.normal(rho * x, 1 - rho**2)
        samples[i] = [x, y]
    return samples

rho = 0.9
samples = gibbs_sampling_bivariate_normal(rho, 50000)
print(f"Mean: ({np.mean(samples[:,0]):.4f}, {np.mean(samples[:,1]):.4f})")
print(f"Correlation: {np.corrcoef(samples[:,0], samples[:,1])[0,1]:.4f} (true: {rho})")
```

### 4.5 混合问题

当条件分布之间高度相关时（如 $\rho$ 接近 1），Gibbs 采样效率很低——链在参数空间中移动缓慢。

**改进策略**：
- 随机扫描 Gibbs：每步随机选择更新的变量
- 块 Gibbs：同时更新一组相关变量
- 椭圆切片采样（Elliptical Slice Sampling）

## 五、Gibbs 采样的高级变体

### 5.1 随机扫描 Gibbs

每步以概率 $p_j$ 选择更新变量 $x_j$：

$$P(\text{update } x_j) = p_j, \quad \sum_{j=1}^{d} p_j = 1$$

然后从 $p(x_j | \mathbf{x}_{-j})$ 采样。

### 5.2 块 Gibbs 采样 (Block Gibbs)

将变量分为若干组，每次更新一组：

$$\mathbf{x}_1^{(t)} \sim p(\mathbf{x}_1 | \mathbf{x}_2^{(t-1)}, \mathbf{x}_3^{(t-1)})$$
$$\mathbf{x}_2^{(t)} \sim p(\mathbf{x}_2 | \mathbf{x}_1^{(t)}, \mathbf{x}_3^{(t-1)})$$
$$\mathbf{x}_3^{(t)} \sim p(\mathbf{x}_3 | \mathbf{x}_1^{(t)}, \mathbf{x}_2^{(t)})$$

### 5.3 系统扫描 Gibbs

按固定顺序遍历所有变量，与标准 Gibbs 类似但使用确定性顺序。

## 六、MCMC 的收敛诊断

### 6.1 问题：如何判断链已收敛到目标分布

MCMC 不会告诉你链何时收敛，只能通过诊断工具判断。

### 6.2 Gelman-Rubin 诊断 ($\hat{R}$)

从多个不同初始点运行 $m$ 条链，每条链长度为 $n$。

$$\hat{R} = \sqrt{\frac{\hat{V}}{W} \cdot \frac{n-1}{n} + \frac{1}{n} \cdot \frac{B}{W}}$$

其中 $W$ 为链内方差，$B$ 为链间方差，$\hat{V}$ 为总方差估计。

**判断标准**：$\hat{R} < 1.1$（保守值 $< 1.05$）表示收敛。

```python
def gelman_rubin(chains):
    """计算Gelman-Rubin诊断统计量"""
    m = len(chains)
    n = len(chains[0])
    means = np.array([np.mean(chain) for chain in chains])
    variances = np.array([np.var(chain, ddof=1) for chain in chains])
    W = np.mean(variances)
    B = n * np.var(means, ddof=1)
    V_hat = (1 - 1.0/n) * W + (1.0/n) * B
    R_hat = np.sqrt(V_hat / W)
    return R_hat
```

### 6.3 有效样本量 (ESS)

由于自相关，MCMC 样本的有效样本量远小于实际样本量：

$$\text{ESS} = \frac{n}{1 + 2\sum_{k=1}^{\infty} \rho_k}$$

其中 $\rho_k$ 为滞后 $k$ 的自相关系数。

### 6.4 自相关函数 (ACF)

$$\rho_k = \frac{\text{Cov}(X_t, X_{t+k})}{\text{Var}(X_t)}$$

**判断标准**：ACF 应快速衰减到 0。衰减慢表示混合差。

### 6.5 迹图 (Trace Plot)

绘制 $X_t$ 随迭代次数的变化：
- **好的混合**：迹图像"毛毛虫"，快速波动
- **差的混合**：迹图有趋势或长周期波动

### 6.6 Geweke 诊断

比较迹图前 10% 和后 50% 的均值：

$$G = \frac{\bar{X}_{\text{early}} - \bar{X}_{\text{late}}}{\sqrt{S_{\text{early}}/n_{\text{early}} + S_{\text{late}}/n_{\text{late}}}} \sim N(0, 1)$$

## 七、高级 MCMC 方法

### 7.1 Hamiltonian Monte Carlo (HMC)

利用目标分布的梯度信息，通过模拟哈密顿动力学来提议远距离移动。

**哈密顿动力学**：

$$H(\mathbf{q}, \mathbf{p}) = U(\mathbf{q}) + K(\mathbf{p}) = -\log \pi(\mathbf{q}) + \frac{1}{2} \mathbf{p}^T M^{-1} \mathbf{p}$$

**蛙跳积分器**（Leapfrog Integration）：

$$\mathbf{p}(t + \epsilon/2) = \mathbf{p}(t) + \frac{\epsilon}{2} \nabla U(\mathbf{q}(t))$$
$$\mathbf{q}(t + \epsilon) = \mathbf{q}(t) + \epsilon M^{-1} \mathbf{p}(t + \epsilon/2)$$
$$\mathbf{p}(t + \epsilon) = \mathbf{p}(t + \epsilon/2) + \frac{\epsilon}{2} \nabla U(\mathbf{q}(t + \epsilon))$$

**HMC 优点**：
- 利用梯度信息，在高维空间中高效
- 接受率高，混合快
- 自动调节步长

```python
def hmc(target_log_pdf, grad_log_pdf, initial, n_samples, step_size, n_leapfrog, d=1):
    """Hamiltonian Monte Carlo"""
    samples = np.zeros((n_samples, d))
    current_q = np.array(initial, dtype=float)
    accepted = 0
    for i in range(n_samples):
        q = current_q.copy()
        p = np.random.normal(0, 1, size=d)
        current_H = -target_log_pdf(q) + 0.5 * np.sum(p**2)
        # Leapfrog integration
        p += 0.5 * step_size * grad_log_pdf(q)
        for _ in range(n_leapfrog - 1):
            q += step_size * p
            p += step_size * grad_log_pdf(q)
        q += step_size * p
        p += 0.5 * step_size * grad_log_pdf(q)
        p = -p
        proposed_H = -target_log_pdf(q) + 0.5 * np.sum(p**2)
        log_alpha = current_H - proposed_H
        if np.log(np.random.uniform()) < log_alpha:
            current_q = q
            accepted += 1
        samples[i] = current_q
    print(f"Acceptance rate: {accepted/n_samples:.3f}")
    return samples

target = lambda x: -0.5 * np.sum(x**2)
grad = lambda x: -x
samples = hmc(target, grad, initial=np.array([0.0, 0.0]), n_samples=10000,
              step_size=0.1, n_leapfrog=20, d=2)
print(f"Mean: {np.mean(samples, axis=0)}")
print(f"Std:  {np.std(samples, axis=0)}")
```

### 7.2 NUTS (No-U-Turn Sampler)

HMC 的自适应版本，自动确定积分步数，避免"U-turn"问题。Stan 和 PyMC3 中的默认采样器。

### 7.3 Slice Sampling

从 $p(x)$ 采样的另一种方法：

1. 从 $U(0, p(x_t))$ 采样 $u$
2. 在水平线 $y = u$ 与 $p(x)$ 的交点范围内采样 $x_{t+1}$

**优点**：无需调节步长参数，自动适应局部密度。

### 7.4 Tempered Transitions

在不同"温度"的分布之间跳转，帮助跨越多峰分布中的低密度区域：

$$\pi_\beta(x) \propto \pi(x)^\beta, \quad \beta \in [0, 1]$$

### 7.5 Reversible Jump MCMC

在不同维度的参数空间之间移动，用于模型选择和可变维度推断。

## 八、实现细节与最佳实践

### 8.1 Burn-in（预热期）

丢弃初始样本，因为链尚未收敛：

```python
def mcmc_with_burnin(samples, burnin=0.5):
    n_burnin = int(len(samples) * burnin)
    return samples[n_burnin:]
```

### 8.2 Thinning（稀疏化）

每隔 $k$ 步取一个样本以减少自相关：

```python
def thin(samples, k=10):
    return samples[::k]
```

### 8.3 多链运行

从不同的分散初始点运行多条链，用于诊断收敛。

### 8.4 参数调节

| 方法 | 关键参数 | 调节目标 |
|------|----------|----------|
| Random Walk MH | 提议方差 $\sigma^2$ | 接受率 $\approx 23\%-44\%$ |
| HMC | 步长 $\epsilon$、步数 $L$ | 接受率 $\approx 65\%-80\%$ |
| Gibbs | 条件分布 | 无需调节 |

### 8.5 完整贝叶斯推断示例

```python
import numpy as np

def bayesian_regression_gibbs(X, y, n_samples=10000, sigma2_prior=1.0, tau2_prior=10.0):
    """贝叶斯线性回归的Gibbs采样"""
    n, p = X.shape
    XtX = X.T @ X
    Xty = X.T @ y
    
    beta_samples = np.zeros((n_samples, p))
    sigma2_samples = np.zeros(n_samples)
    
    beta = np.zeros(p)
    sigma2 = 1.0
    
    for i in range(n_samples):
        # Sample sigma2 given beta
        residual = y - X @ beta
        sigma2 = 1.0 / np.random.gamma(
            n/2 + 1, 2.0 / (np.sum(residual**2) + sigma2_prior)
        )
        
        # Sample beta given sigma2
        Lambda = XtX / sigma2 + np.eye(p) / tau2_prior
        Lambda_inv = np.linalg.inv(Lambda)
        mu = Lambda_inv @ (Xty / sigma2)
        beta = mu + np.linalg.cholesky(Lambda_inv) @ np.random.standard_normal(p)
        
        beta_samples[i] = beta
        sigma2_samples[i] = sigma2
    
    return beta_samples, sigma2_samples

np.random.seed(42)
n, p = 100, 3
X = np.random.randn(n, p)
true_beta = np.array([1.0, -2.0, 0.5])
y = X @ true_beta + np.random.randn(n) * 0.5

beta_samples, sigma2_samples = bayesian_regression_gibbs(X, y)
print("Posterior means:")
for j in range(p):
    print(f"  beta[{j}]: {np.mean(beta_samples[:,j]):.4f} (true: {true_beta[j]})")
print(f"  sigma2:  {np.mean(sigma2_samples):.4f} (true: 0.25)")
```

## 九、MCMC 的局限性与改进

### 9.1 主要挑战

1. **高维空间**：维度增加时混合变慢
2. **多峰分布**：链可能困在一个峰中
3. **自相关**：有效样本量可能远小于实际样本量
4. **收敛诊断**：无法确定性地判断收敛

### 9.2 改进策略

1. **预处理**：参数变换（如对数变换）改善条件数
2. **并行化**：多链同时运行
3. **自适应 MCMC**：迭代调节提议分布参数
4. **变分推断替代**：当 MCMC 太慢时，可用变分近似
5. **嵌套采样**：用于计算边缘似然和贝叶斯因子

---

## 十、关键要点总结

1. MCMC 通过构造以目标分布为平稳分布的马尔可夫链来间接采样
2. Metropolis-Hastings 是最通用的 MCMC 算法，核心是接受概率和细致平衡
3. Gibbs 采样是 MH 的特殊情况，利用全条件分布，接受率为 100%
4. 提议分布的选择至关重要：随机游走 MH 的接受率应约为 23%-44%
5. HMC 利用梯度信息在高维空间中高效移动，是现代贝叶斯推断的首选
6. 收敛诊断（$\hat{R}$、ACF、ESS、迹图）是 MCMC 分析不可或缺的步骤
7. Burn-in 和 thinning 是处理 MCMC 输出的标准步骤
8. 多峰分布是 MCMC 的最大挑战，需要特殊方法（如并行回火）
9. NUTS 自动调节 HMC 参数，大大降低了使用门槛
10. MCMC 与变分推断互补：MCMC 精确但慢，变分推断快但近似
