# 蒙特卡洛方法 (Monte Carlo Methods)

## 一、概述

蒙特卡洛方法是一类基于随机抽样的数值计算方法，广泛应用于积分估计、优化、模拟和推断等问题。其核心思想是利用大数定律，通过大量重复随机试验来逼近确定性结果。

### 1.1 历史背景

蒙特卡洛方法由 Stanislaw Ulam、John von Neumann 和 Nicholas Metropolis 在 20 世纪 40 年代于洛斯阿拉莫斯国家实验室提出，以摩纳哥的蒙特卡洛赌场命名。Ulam 在养病期间玩纸牌游戏时萌生了利用随机抽样解决确定性问题的想法。

### 1.2 基本原理

设随机变量 $X$ 的期望值为 $\mu = E[X]$，则根据大数定律：

$$\bar{X}_n = \frac{1}{n} \sum_{i=1}^{n} X_i \xrightarrow{P} \mu, \quad n \to \infty$$

其中 $X_1, X_2, \ldots, X_n$ 为独立同分布的样本。蒙特卡洛估计的标准误差为：

$$\text{SE} = \frac{\sigma}{\sqrt{n}}$$

其中 $\sigma^2 = \text{Var}(X)$。这意味着误差以 $O(n^{-1/2})$ 的速率收敛，与维度无关。

### 1.3 蒙特卡洛方法的分类

| 类别 | 代表方法 | 应用场景 |
|------|----------|----------|
| 直接抽样 | 均匀采样、逆变换法 | 积分估计 |
| 重要性采样 | 重要性采样 (IS) | 低概率事件估计 |
| 方差缩减 | 对偶变量、控制变量、分层抽样 | 提高估计精度 |
| 马尔可夫链蒙特卡洛 | MH 算法、Gibbs 采样 | 高维后验分布采样 |
| 序列蒙特卡洛 | 粒子滤波 | 动态系统状态估计 |

## 二、基础蒙特卡洛积分

### 2.1 均匀采样法

目标：估计积分 $I = \int_a^b f(x) \, dx$

将其改写为期望形式：

$$I = (b - a) \int_a^b f(x) \cdot \frac{1}{b-a} \, dx = (b - a) \cdot E[f(X)]$$

其中 $X \sim U(a, b)$。蒙特卡洛估计为：

$$\hat{I}_n = \frac{b - a}{n} \sum_{i=1}^{n} f(X_i), \quad X_i \sim U(a, b)$$

**方差分析：**

$$\text{Var}(\hat{I}_n) = \frac{(b - a)^2}{n} \text{Var}(f(X)) = \frac{(b - a)^2}{n} \left[ \frac{1}{b-a}\int_a^b f^2(x) \, dx - \left(\frac{I}{b-a}\right)^2 \right]$$

### 2.2 多重积分的蒙特卡洛方法

蒙特卡洛方法在高维积分中具有独特优势。对于 $d$ 维积分：

$$I = \int_{\Omega} f(\mathbf{x}) \, d\mathbf{x}$$

蒙特卡洛估计为：

$$\hat{I}_n = V(\Omega) \cdot \frac{1}{n} \sum_{i=1}^{n} f(\mathbf{X}_i)$$

其中 $V(\Omega)$ 为积分区域 $\Omega$ 的体积，$\mathbf{X}_i \sim U(\Omega)$。

**关键优势**：收敛速度 $O(n^{-1/2})$ 与维度 $d$ 无关，而数值积分方法（如梯形法则）的收敛速度为 $O(n^{-1/d})$。

### 2.3 多重积分实例

估计 $\pi$ 值 —— 计算单位圆面积：

```python
import numpy as np

def estimate_pi(n_samples):
    """通过蒙特卡洛方法估计π值"""
    x = np.random.uniform(-1, 1, n_samples)
    y = np.random.uniform(-1, 1, n_samples)
    inside_circle = np.sum(x**2 + y**2 <= 1.0)
    pi_estimate = 4.0 * inside_circle / n_samples
    return pi_estimate

# 不同样本量的估计
for n in [1000, 10000, 100000, 1000000]:
    pi_est = estimate_pi(n)
    error = abs(pi_est - np.pi)
    print(f"n={n:>8d}, π̂={pi_est:.6f}, |error|={error:.6f}")
```

## 三、随机数生成

### 3.1 逆变换法 (Inverse Transform Method)

**定理**：若 $U \sim U(0, 1)$，$F$ 为连续累积分布函数，则 $X = F^{-1}(U)$ 的分布为 $F$。

**证明**：

$$P(X \leq x) = P(F^{-1}(U) \leq x) = P(U \leq F(x)) = F(x)$$

其中利用了 $F$ 的单调性和 $U$ 的均匀分布性质。

**常用分布的逆变换：**

**指数分布**：$F(x) = 1 - e^{-\lambda x}$，$x \geq 0$

$$F^{-1}(u) = -\frac{1}{\lambda} \ln(1 - u)$$

由于 $1 - U \sim U(0, 1)$，简化为 $X = -\frac{1}{\lambda} \ln(U)$

**均匀分布**：$F(x) = \frac{x - a}{b - a}$

$$F^{-1}(u) = a + (b - a) u$$

**柯西分布**：$F(x) = \frac{1}{\pi} \arctan(x) + \frac{1}{2}$

$$F^{-1}(u) = \tan\left(\pi\left(u - \frac{1}{2}\right)\right)$$

### 3.2 Box-Muller 变换

生成标准正态分布随机数的经典方法。

**原理**：设 $U_1, U_2 \sim U(0, 1)$ 独立，则：

$$Z_0 = \sqrt{-2 \ln U_1} \cos(2\pi U_2)$$
$$Z_1 = \sqrt{-2 \ln U_1} \sin(2\pi U_2)$$

则 $Z_0, Z_1 \sim N(0, 1)$ 独立。

**证明**：利用极坐标变换，$(Z_0, Z_1)$ 的联合密度为：

$$f(z_0, z_1) = \frac{1}{2\pi} e^{-(z_0^2 + z_1^2)/2}$$

即两个独立标准正态分布的乘积。

```python
import numpy as np

def box_muller(n):
    """Box-Muller变换生成标准正态随机数"""
    u1 = np.random.uniform(0, 1, n)
    u2 = np.random.uniform(0, 1, n)
    z0 = np.sqrt(-2 * np.log(u1)) * np.cos(2 * np.pi * u2)
    z1 = np.sqrt(-2 * np.log(u1)) * np.sin(2 * np.pi * u2)
    return z0, z1
```

### 3.3 Rejection Sampling（拒绝采样）

当目标分布 $f(x)$ 难以直接采样时，可使用包络分布 $g(x)$ 进行拒绝采样。

**算法**：

1. 选择包络分布 $g(x)$ 和常数 $M$，使得 $f(x) \leq M \cdot g(x)$ 对所有 $x$ 成立
2. 从 $g(x)$ 生成候选样本 $X^*$
3. 从 $U(0, 1)$ 生成均匀随机数 $U$
4. 若 $U \leq \frac{f(X^*)}{M \cdot g(X^*)}$，接受 $X^*$；否则拒绝

**接受概率**：$P(\text{accept}) = \frac{1}{M}$，因此 $M$ 越小效率越高。

```python
def rejection_sampling(target_pdf, proposal_pdf, proposal_sampler, M, n_samples):
    """拒绝采样"""
    samples = []
    while len(samples) < n_samples:
        x = proposal_sampler()
        u = np.random.uniform(0, 1)
        if u <= target_pdf(x) / (M * proposal_pdf(x)):
            samples.append(x)
    return np.array(samples)
```

## 四、重要性采样 (Importance Sampling)

### 4.1 基本原理

在标准蒙特卡洛中，我们从分布 $p(x)$ 抽样估计 $E_p[f(X)]$。重要性采样从另一个分布 $q(x)$（重要性分布）抽样：

$$E_p[f(X)] = \int f(x) p(x) \, dx = \int f(x) \frac{p(x)}{q(x)} q(x) \, dx = E_q\left[f(X) \frac{p(X)}{q(X)}\right]$$

其中 $w(x) = \frac{p(x)}{q(x)}$ 称为重要性权重。

**估计量**：

$$\hat{\mu}_{IS} = \frac{1}{n} \sum_{i=1}^{n} f(X_i) w(X_i), \quad X_i \sim q(x)$$

### 4.2 最优重要性分布

选择 $q(x)$ 使得 $\hat{\mu}_{IS}$ 的方差最小化。最优重要性分布为：

$$q^*(x) = \frac{|f(x)| p(x)}{\int |f(x')| p(x') \, dx'}$$

此时方差为：

$$\text{Var}_{q^*}(\hat{\mu}_{IS}) = \left[\int |f(x)| p(x) \, dx\right]^2 - \mu^2$$

**实际中不可用**：因为 $q^*$ 依赖于我们要估计的量。通常选择与 $f(x) p(x)$ 形状相似的分布。

### 4.3 自归一化重要性采样

当 $p(x)$ 的归一化常数未知时（常见于贝叶斯推断），使用自归一化估计量：

$$\hat{\mu}_{\text{SNIS}} = \frac{\sum_{i=1}^{n} f(X_i) \tilde{w}(X_i)}{\sum_{i=1}^{n} \tilde{w}(X_i)}$$

其中 $\tilde{w}(x) = \frac{\tilde{p}(x)}{q(x)}$，$\tilde{p}(x)$ 为 $p(x)$ 的未归一化版本。

该估计量是渐近无偏的（但不是有限样本无偏的）。

### 4.4 有效样本量 (Effective Sample Size, ESS)

衡量重要性采样效率的关键指标：

$$\text{ESS} = \frac{\left(\sum_{i=1}^{n} w_i\right)^2}{\sum_{i=1}^{n} w_i^2} = \frac{n}{1 + \text{CV}^2(w)}$$

其中 $\text{CV}(w)$ 为权重的变异系数。$\text{ESS} \approx n$ 表示效率高，$\text{ESS} \ll n$ 表示少数样本主导估计。

```python
import numpy as np
from scipy import stats

def importance_sampling(n_samples, target_log_pdf, proposal_dist, proposal_sampler):
    """重要性采样示例"""
    samples = proposal_sampler(n_samples)
    log_weights = target_log_pdf(samples) - proposal_dist.logpdf(samples)
    weights = np.exp(log_weights)
    ess = (np.sum(weights))**2 / np.sum(weights**2)
    return samples, weights, ess

# 示例：估计标准正态分布下E[X^4]
target_log = lambda x: -0.5 * x**2  # 标准正态（未归一化）
proposal = stats.norm(loc=0, scale=2)  # 宽于目标的正态分布
samples, weights, ess = importance_sampling(
    100000, target_log, proposal, proposal.rvs
)
weighted_mean = np.average(samples**4, weights=weights)
print(f"Estimate: {weighted_mean:.4f}, True: 3.0, ESS: {ess:.0f}")
```

## 五、方差缩减技术

### 5.1 对偶变量法 (Antithetic Variates)

**思想**：若 $X$ 和 $Y$ 负相关，则 $\text{Var}\left(\frac{X + Y}{2}\right) < \frac{1}{2}\text{Var}(X)$。

**方法**：对每对均匀随机数 $(U_i, 1 - U_i)$，生成 $X_i = f(U_i)$ 和 $\tilde{X}_i = f(1 - U_i)$：

$$\hat{\mu}_{AV} = \frac{1}{n} \sum_{i=1}^{n} \frac{X_i + \tilde{X}_i}{2}$$

**方差缩减条件**：当 $f$ 为单调函数时，$X_i$ 和 $\tilde{X}_i$ 负相关，方差必然减小。

**方差分析**：

$$\text{Var}(\hat{\mu}_{AV}) = \frac{1}{2n} \text{Var}(X + \tilde{X}) = \frac{1}{2n} \left[\text{Var}(X) + \text{Var}(\tilde{X}) + 2\text{Cov}(X, \tilde{X})\right]$$

当 $\text{Cov}(X, \tilde{X}) < 0$ 时，方差减小。

```python
def antithetic_variates(f, n):
    """对偶变量法"""
    u = np.random.uniform(0, 1, n)
    x = f(u)
    x_tilde = f(1 - u)
    return np.mean((x + x_tilde) / 2)
```

### 5.2 控制变量法 (Control Variates)

**思想**：利用已知期望的相关随机变量来减少方差。

设已知 $E[h(X)] = \mu_h$，构造控制变量估计量：

$$\hat{\mu}_{CV} = \frac{1}{n} \sum_{i=1}^{n} f(X_i) - c \left[\frac{1}{n} \sum_{i=1}^{n} h(X_i) - \mu_h\right]$$

**最优控制系数**：

$$c^* = \frac{\text{Cov}(f(X), h(X))}{\text{Var}(h(X))}$$

**方差缩减**：

$$\text{Var}(\hat{\mu}_{CV}) = \text{Var}(f(X)) \cdot (1 - \rho_{fh}^2)$$

其中 $\rho_{fh}$ 为 $f(X)$ 和 $h(X)$ 的相关系数。$|\rho_{fh}|$ 越大，方差缩减越明显。

```python
def control_variate(f, h, h_mean, n):
    """控制变量法"""
    samples = np.random.uniform(0, 1, n)
    f_vals = f(samples)
    h_vals = h(samples)
    c_star = np.cov(f_vals, h_vals)[0, 1] / np.var(h_vals)
    estimate = np.mean(f_vals) - c_star * (np.mean(h_vals) - h_mean)
    return estimate
```

### 5.3 分层抽样 (Stratified Sampling)

**思想**：将抽样空间分成互不重叠的层，在每层内独立抽样。

**等比例分配**：将 $[0, 1]$ 均匀分为 $k$ 层，每层 $n_j = n/k$ 个样本：

$$\hat{\mu}_{\text{ST}} = \frac{1}{k} \sum_{j=1}^{k} \left[\frac{1}{n_j} \sum_{i=1}^{n_j} f\left(\frac{i - 1 + U_{ji}}{n}\right)\right]$$

**方差**：$\text{Var}(\hat{\mu}_{\text{ST}}) = \frac{1}{n} \sum_{j=1}^{k} p_j \sigma_j^2$，其中 $\sigma_j^2$ 为第 $j$ 层的方差。

由于组间方差被消除，$\text{Var}(\hat{\mu}_{\text{ST}}) \leq \text{Var}(\hat{\mu}_{\text{MC}})$。

```python
def stratified_sampling(f, n_strata, samples_per_stratum):
    """分层抽样"""
    total = 0
    for j in range(n_strata):
        lower = j / n_strata
        upper = (j + 1) / n_strata
        u = np.random.uniform(lower, upper, samples_per_stratum)
        total += np.mean(f(u))
    return total / n_strata
```

### 5.4 重要性采样 + 方差缩减组合

在实践中，常将多种技术组合使用。例如，先用重要性采样将采样集中到贡献大的区域，再用对偶变量或控制变量进一步缩减方差。

## 六、蒙特卡洛方法的收敛性分析

### 6.1 中心极限定理

对于蒙特卡洛估计 $\bar{X}_n$，根据中心极限定理：

$$\sqrt{n} \left(\bar{X}_n - \mu\right) \xrightarrow{d} N(0, \sigma^2)$$

因此，对于 $95\%$ 置信区间：

$$\mu \in \left[\bar{X}_n - 1.96 \frac{\hat{\sigma}}{\sqrt{n}}, \; \bar{X}_n + 1.96 \frac{\hat{\sigma}}{\sqrt{n}}\right]$$

### 6.2 收敛速度比较

| 方法 | 收敛速度 | 维度依赖性 |
|------|----------|------------|
| 蒙特卡洛 | $O(n^{-1/2})$ | 无 |
| 梯形法则 (1D) | $O(n^{-2})$ | 有 |
| Simpson 法则 (1D) | $O(n^{-4})$ | 有 |
| 拟蒙特卡洛 | $O(n^{-1} \log^d n)$ | 弱依赖 |

### 6.3 误差估计

样本方差的估计：

$$\hat{\sigma}^2 = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \bar{X}_n)^2$$

相对误差：

$$\text{RE} = \frac{\hat{\sigma}/\sqrt{n}}{|\bar{X}_n|}$$

## 七、高级话题

### 7.1 拟蒙特卡洛 (Quasi-Monte Carlo)

使用低差异序列（如 Sobol 序列、Halton 序列）替代伪随机数，理论收敛速度可达 $O(n^{-1})$。

```python
import numpy as np
from scipy.stats import qmc

def quasi_monte_carlo_integration(f, n_samples, d=1):
    """使用Sobol序列的拟蒙特卡洛积分"""
    sampler = qmc.Sobol(d=d, scramble=True)
    points = sampler.random(n_samples)
    return np.mean(f(points))
```

### 7.2 条件蒙特卡洛 (Conditional Monte Carlo)

利用条件方差不等式 $\text{Var}(X) = E[\text{Var}(X|Y)] + \text{Var}(E[X|Y])$，通过条件化降低方差。

### 7.3 多重重要性采样 (Multiple Importance Sampling, MIS)

结合多个重要性分布 $q_1, \ldots, q_K$：

$$\hat{\mu}_{\text{MIS}} = \frac{1}{n} \sum_{i=1}^{K} \sum_{j=1}^{n_i} w_i(X_{ij}) f(X_{ij}) \frac{p(X_{ij})}{q_i(X_{ij})}$$

其中 $w_i(x)$ 为满足 $\sum_i w_i(x) = 1$ 的权重函数（如平衡启发式）。

### 7.4 嵌套蒙特卡洛 (Nested Monte Carlo)

用于估计期望中的期望：

$$I = E_{X}\left[E_{Y|X}[f(X, Y)]\right]$$

内层和外层均使用蒙特卡洛估计，但需注意双重嵌套带来的方差累积。

## 八、实际应用案例

### 8.1 期权定价（欧式看涨期权）

Black-Scholes 模型下，欧式看涨期权价格：

$$C = e^{-rT} E\left[(S_T - K)^+\right]$$

其中 $S_T = S_0 \exp\left[\left(r - \frac{\sigma^2}{2}\right)T + \sigma \sqrt{T} Z\right]$，$Z \sim N(0, 1)$。

```python
import numpy as np

def european_call_mc(S0, K, r, sigma, T, n_sims):
    """蒙特卡洛定价欧式看涨期权"""
    Z = np.random.standard_normal(n_sims)
    ST = S0 * np.exp((r - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z)
    payoff = np.maximum(ST - K, 0)
    price = np.exp(-r * T) * np.mean(payoff)
    std_err = np.exp(-r * T) * np.std(payoff) / np.sqrt(n_sims)
    return price, std_err

price, se = european_call_mc(S0=100, K=100, r=0.05, sigma=0.2, T=1.0, n_sims=1000000)
print(f"期权价格: {price:.4f} ± {1.96*se:.4f}")
```

### 8.2 高维积分计算

$$I = \int_0^1 \int_0^1 \cdots \int_0^1 \prod_{i=1}^{d} \frac{3x_i - 1}{3x_i + 1} \, dx_1 \, dx_2 \cdots dx_d$$

当 $d$ 很大时（如 $d = 100$），数值积分方法不可行，蒙特卡洛方法仍能有效估计。

### 8.3 风险价值 (Value at Risk, VaR) 估计

```python
def estimate_var(returns, confidence=0.95, n_bootstrap=10000):
    """蒙特卡洛估计VaR"""
    n = len(returns)
    var_samples = []
    for _ in range(n_bootstrap):
        sample = np.random.choice(returns, size=n, replace=True)
        var_samples.append(-np.percentile(sample, (1 - confidence) * 100))
    return np.mean(var_samples), np.std(var_samples)
```

## 九、蒙特卡洛方法的局限性

1. **维度灾难的替代方案**：虽不受维度直接影响，但高维问题中方差可能增大
2. **收敛速度慢**：$O(n^{-1/2})$ 收敛，需要大量样本才能获得高精度
3. **随机性**：每次运行结果不同，需要报告置信区间
4. **低概率事件**：估计罕见事件概率时效率极低（需配合重要性采样）
5. **相关性问题**：时间序列数据中样本不独立时需要特殊处理

## 十、关键要点总结

1. 蒙特卡洛方法利用随机抽样逼近确定性量，收敛速度 $O(n^{-1/2})$ 与维度无关
2. 逆变换法是生成各类分布随机数的基础方法
3. 重要性采样通过从"更重要"的区域抽样来减少方差
4. 方差缩减技术（对偶变量、控制变量、分层抽样）可显著提高效率
5. ESS 是衡量重要性采样效率的关键指标
6. 拟蒙特卡洛使用低差异序列可提高收敛速度到 $O(n^{-1})$
7. 蒙特卡洛方法在高维积分、金融定价、贝叶斯推断等领域有独特优势
8. 实际应用中应组合多种方差缩减技术以获得最佳效果
