# 排队论 (Queueing Theory)

## 一、概述

排队论研究拥挤现象中的随机规律，广泛应用于通信网络、交通系统、生产线、计算机系统等领域。核心问题是平衡服务能力和等待时间，优化系统设计。

### 1.1 排队系统的组成

一个排队系统由以下要素组成：

1. **到达过程**：顾客按某种规律到达系统
2. **服务机制**：服务台数量、服务时间分布
3. **排队规则**：FIFO、LIFO、优先级等
4. **系统容量**：排队容量限制
5. **顾客源**：有限或无限顾客源

### 1.2 Kendall 记号

Kendall 使用 $A/B/c/K/N/D$ 六重记号描述排队系统：

- $A$：到达过程分布
- $B$：服务时间分布
- $c$：服务台数量
- $K$：系统容量（默认 $\infty$）
- $N$：顾客源大小（默认 $\infty$）
- $D$：排队规则（默认 FIFO）

常用简写 $M/M/1$ 表示：$M$（马尔可夫/泊松到达）、$M$（马尔可夫/指数服务时间）、$1$ 个服务台。

### 1.3 关键性能指标

| 符号 | 含义 |
|------|------|
| $L$ | 系统中的平均顾客数 |
| $L_q$ | 排队中的平均顾客数 |
| $W$ | 平均逗留时间（系统中） |
| $W_q$ | 平均等待时间（排队中） |
| $\rho$ | 服务台利用率 |
| $P_0$ | 系统为空的概率 |
| $P_n$ | 系统中有 $n$ 个顾客的概率 |

**Little 公式**（最普适的关系）：

$$L = \lambda W, \quad L_q = \lambda W_q$$

其中 $\lambda$ 为有效到达率。

## 二、M/M/1 排队模型

### 2.1 模型假设

- 到达过程：参数为 $\lambda$ 的泊松过程
- 服务时间：参数为 $\mu$ 的指数分布
- 1 个服务台
- 无限容量、无限顾客源
- FIFO 排队规则

### 2.2 生灭过程分析

M/M/1 系统的状态 $\{Q(t)\}$ 构成连续时间马尔可夫链（生灭过程），状态转移率为：

$$q_{n, n+1} = \lambda, \quad q_{n, n-1} = \mu, \quad n \geq 1$$
$$q_{0, 1} = \lambda$$

### 2.3 平稳分布

**条件**：$\rho = \frac{\lambda}{\mu} < 1$（系统稳定）

**状态概率**：

$$P_n = (1 - \rho) \rho^n, \quad n = 0, 1, 2, \ldots$$

**推导**：利用平衡方程 $\lambda P_{n-1} = \mu P_n$，递推得 $P_n = \rho^n P_0$。归一化条件：

$$\sum_{n=0}^{\infty} P_n = P_0 \sum_{n=0}^{\infty} \rho^n = \frac{P_0}{1 - \rho} = 1$$

因此 $P_0 = 1 - \rho$。

### 2.4 性能指标推导

**系统中平均顾客数**：

$$L = \sum_{n=0}^{\infty} n P_n = (1 - \rho) \sum_{n=0}^{\infty} n \rho^n = (1 - \rho) \cdot \frac{\rho}{(1-\rho)^2} = \frac{\rho}{1 - \rho}$$

**排队中平均顾客数**：

$$L_q = \sum_{n=1}^{\infty} (n-1) P_n = L - (1 - P_0) = L - \rho = \frac{\rho^2}{1 - \rho}$$

**平均逗留时间**（由 Little 公式）：

$$W = \frac{L}{\lambda} = \frac{1}{\mu - \lambda}$$

**平均等待时间**：

$$W_q = \frac{L_q}{\lambda} = \frac{\rho}{\mu - \lambda}$$

**关系**：$W = W_q + \frac{1}{\mu}$（逗留时间 = 等待时间 + 服务时间）

### 2.5 等待时间分布

设 $T_q$ 为等待时间（排队时间），则：

$$P(T_q = 0) = 1 - \rho$$

$$P(T_q > t) = \rho e^{-(\mu - \lambda)t}, \quad t > 0$$

**逗留时间** $T$ 的分布：

$$P(T > t) = e^{-(\mu - \lambda)t}, \quad t > 0$$

即逗留时间服从参数为 $\mu - \lambda$ 的指数分布。

```python
import numpy as np

class MM1Queue:
    def __init__(self, arrival_rate, service_rate):
        self.lam = arrival_rate
        self.mu = service_rate
        self.rho = arrival_rate / service_rate

    def is_stable(self):
        return self.rho < 1

    def steady_state_probs(self, n):
        return (1 - self.rho) * self.rho**n

    def L(self):
        return self.rho / (1 - self.rho)

    def Lq(self):
        return self.rho**2 / (1 - self.rho)

    def W(self):
        return 1.0 / (self.mu - self.lam)

    def Wq(self):
        return self.rho / (self.mu - self.lam)

    def simulate(self, n_customers):
        inter_arrivals = np.random.exponential(1/self.lam, n_customers)
        service_times = np.random.exponential(1/self.mu, n_customers)
        arrival_times = np.cumsum(inter_arrivals)
        start_service = np.zeros(n_customers)
        finish_service = np.zeros(n_customers)
        start_service[0] = arrival_times[0]
        finish_service[0] = start_service[0] + service_times[0]
        for i in range(1, n_customers):
            start_service[i] = max(arrival_times[i], finish_service[i-1])
            finish_service[i] = start_service[i] + service_times[i]
        waits = start_service - arrival_times
        sojourns = finish_service - arrival_times
        return np.mean(waits), np.mean(sojourns)

q = MM1Queue(arrival_rate=3.0, service_rate=5.0)
print(f"rho={q.rho:.2f}, L={q.L():.2f}, Lq={q.Lq():.2f}")
print(f"W={q.W():.4f}, Wq={q.Wq():.4f}")
sim_w, sim_s = q.simulate(100000)
print(f"Simulated Wq={sim_w:.4f}, W={sim_s:.4f}")
```

### 2.6 M/M/1 灵敏度分析

系统性能对利用率 $\rho$ 非常敏感。当 $\rho \to 1$ 时，$L \to \infty$，$W \to \infty$。

| $\rho$ | $L$ | $L_q$ | $W \cdot \mu$ | $W_q \cdot \mu$ |
|--------|-----|-------|---------------|-----------------|
| 0.1 | 0.11 | 0.01 | 1.11 | 0.11 |
| 0.5 | 1.00 | 0.50 | 2.00 | 1.00 |
| 0.7 | 2.33 | 1.63 | 3.33 | 2.33 |
| 0.9 | 9.00 | 8.10 | 10.00 | 9.00 |
| 0.95 | 19.00 | 18.05 | 20.00 | 19.00 |

## 三、M/M/c 排队模型

### 3.1 模型假设

- $c$ 个并行服务台
- 到达：泊松过程（率 $\lambda$）
- 服务时间：指数分布（率 $\mu$，每个服务台相同）
- 所有服务台共享一个队列

### 3.2 平稳分布

**条件**：$\rho = \frac{\lambda}{c\mu} < 1$

状态转移率：
$$q_{n, n+1} = \lambda, \quad q_{n, n-1} = \begin{cases} n\mu, & 1 \leq n < c \\ c\mu, & n \geq c \end{cases}$$

**状态概率**（利用细致平衡方程）：

$$P_n = \begin{cases} \frac{(c\rho)^n}{n!} P_0, & 0 \leq n < c \\ \frac{c^c \rho^n}{c!} P_0, & n \geq c \end{cases}$$

其中 $P_0$ 由归一化条件确定：

$$P_0 = \left[\sum_{n=0}^{c-1} \frac{(c\rho)^n}{n!} + \frac{(c\rho)^c}{c!} \cdot \frac{1}{1-\rho}\right]^{-1}$$

### 3.3 Erlang C 公式

**Erlang C 公式**给出顾客需要等待的概率：

$$C(c, \lambda/\mu) = P(\text{wait} > 0) = \frac{\frac{(c\rho)^c}{c!(1-\rho)} P_0}{1} = \frac{\frac{(c\rho)^c}{c!(1-\rho)}}{\sum_{n=0}^{c-1}\frac{(c\rho)^n}{n!} + \frac{(c\rho)^c}{c!(1-\rho)}}$$

### 3.4 性能指标

**平均排队顾客数**：

$$L_q = \frac{P_0 (c\rho)^c \rho}{c!(1-\rho)^2}$$

**平均逗留顾客数**：

$$L = L_q + c\rho$$

**平均等待时间**：

$$W_q = \frac{L_q}{\lambda}$$

**平均逗留时间**：

$$W = W_q + \frac{1}{\mu}$$

```python
import math

class MMcQueue:
    def __init__(self, arrival_rate, service_rate, n_servers):
        self.lam = arrival_rate
        self.mu = service_rate
        self.c = n_servers
        self.rho = arrival_rate / (n_servers * service_rate)

    def is_stable(self):
        return self.rho < 1

    def P0(self):
        c, rho = self.c, self.rho
        crho = c * rho
        s1 = sum(crho**n / math.factorial(n) for n in range(c))
        s2 = crho**c / math.factorial(c) / (1 - rho)
        return 1.0 / (s1 + s2)

    def erlang_c(self):
        c, rho = self.c, self.rho
        crho = c * rho
        s1 = sum(crho**n / math.factorial(n) for n in range(c))
        s2 = crho**c / math.factorial(c) / (1 - rho)
        return s2 / (s1 + s2)

    def Lq(self):
        return self.erlang_c() * self.rho / (1 - self.rho)

    def L(self):
        return self.Lq() + self.c * self.rho

    def Wq(self):
        return self.Lq() / self.lam

    def W(self):
        return self.Wq() + 1.0 / self.mu

q = MMcQueue(arrival_rate=8.0, service_rate=3.0, n_servers=3)
print(f"rho={q.rho:.4f}, P(wait)={q.erlang_c():.4f}")
print(f"L={q.L():.4f}, Lq={q.Lq():.4f}")
print(f"W={q.W():.4f}, Wq={q.Wq():.4f}")
```

## 四、M/M/c/K 有限容量模型

### 4.1 模型描述

系统容量限制为 $K$（包括正在服务的），当系统满时（$K$ 个顾客），新到达的顾客被拒绝。

有效到达率为：

$$\lambda_{\text{eff}} = \lambda (1 - P_K)$$

### 4.2 状态概率

$$P_n = \begin{cases} \frac{(c\rho)^n}{n!} P_0, & 0 \leq n < c \\ \frac{c^c \rho^n}{c!} P_0, & c \leq n \leq K \end{cases}$$

$$P_0 = \left[\sum_{n=0}^{c-1} \frac{(c\rho)^n}{n!} + \frac{c^c}{c!} \sum_{n=c}^{K} \rho^n\right]^{-1}$$

### 4.3 丢弃概率

$$P_{\text{loss}} = P_K = \frac{\frac{c^c \rho^K}{c!} P_0}{1}$$

这是 Erlang B 公式（适用于 $c = K$ 的情况）。

### 4.4 Erlang B 公式

当 $K = c$（无排队，只有服务台）时：

$$B(c, \lambda/\mu) = \frac{\frac{(\lambda/\mu)^c}{c!}}{\sum_{n=0}^{c} \frac{(\lambda/\mu)^n}{n!}}$$

```python
def erlang_b(c, a):
    """Erlang B公式：a=lambda/mu为交通强度"""
    B = 1.0
    for n in range(1, c + 1):
        B = a * B / (n + a * B)
    return B

def erlang_c(c, a):
    """Erlang C公式"""
    B = erlang_b(c, a)
    return B / (1 - (a/c) * (1 - B)) if c > a else 1.0

a_values = [0.5, 1.0, 2.0, 3.0, 5.0]
for a in a_values:
    for c in [2, 5, 10]:
        if a < c:
            loss = erlang_b(c, a)
            wait = erlang_c(c, a)
            print(f"c={c}, a={a:.1f}: P(loss)={loss:.4f}, P(wait)={wait:.4f}")
```

## 五、M/G/1 排队模型

### 5.1 模型描述

- 到达：泊松过程（率 $\lambda$）
- 服务时间：一般分布，均值 $1/\mu$，方差 $\sigma^2$
- 单服务台

### 5.2 Pollaczek-Khinchine 公式

**平均排队顾客数**（P-K 公式）：

$$L_q = \frac{\lambda^2 \sigma^2 + \rho^2}{2(1 - \rho)} = \frac{\rho^2 (1 + C_s^2)}{2(1 - \rho)}$$

其中 $C_s = \sigma \mu$ 为服务时间的变异系数（CV），$\rho = \lambda / \mu$。

**推导过程**：

考虑忙期 $B$ 和闲期 $I$ 的交替。在一个循环中：

$$E[L_q] = \frac{E[L_q \text{ at departure}]}{2} + \frac{\lambda^2 \sigma^2}{2}$$

利用嵌入马尔可夫链方法，在每个顾客离开时刻观察系统。

**关键观察**：$L_q$ 受服务时间方差影响，方差越大排队越长。

### 5.3 性能指标

$$L = L_q + \rho$$

$$W_q = \frac{L_q}{\lambda} = \frac{\rho (1 + C_s^2)}{2\mu(1 - \rho)}$$

$$W = W_q + \frac{1}{\mu}$$

### 5.4 特殊情况

**M/D/1 模型**（确定性服务时间）：$C_s = 0$

$$L_q^{M/D/1} = \frac{\rho^2}{2(1 - \rho)} = \frac{1}{2} L_q^{M/M/1}$$

确定性服务时间将排队长度减半。

**M/H_2/1 模型**（超指数服务时间）：$C_s > 1$，排队更长。

## 六、排队网络

### 6.1 串联排队网络

多个排队系统串联，前一个系统的输出是后一个的输入。

对于 Jackson 网络，每个节点 $i$ 表现为独立的 M/M/1 队列（到达率 $\gamma_i$ 由流量平衡方程确定）。

**流量平衡方程**：

$$\gamma_i = \lambda_i + \sum_{j} \gamma_j p_{ji}, \quad i = 1, 2, \ldots, N$$

其中 $\lambda_i$ 为外部到达率，$p_{ji}$ 从节点 $j$ 到节点 $i$ 的路由概率。

### 6.2 Jackson 定理

在稳态下，Jackson 网络中各节点的状态独立，节点 $i$ 的状态分布等价于 M/M/1 队列：

$$P(n_1, n_2, \ldots, n_N) = \prod_{i=1}^{N} (1 - \rho_i) \rho_i^{n_i}$$

其中 $\rho_i = \gamma_i / \mu_i$。

### 6.3 BCMP 网络

Jackson 网络的推广，允许：
- 多服务台
- 一般服务时间分布（在特定条件下）
- LIFO-PR 排队规则

## 七、有限源模型

### 7.1 M/M/1/K/K 模型（机器维修问题）

$K$ 台机器，1 个维修工。每台机器故障率为 $\lambda$，修复率为 $\mu$。

$$P_n = \binom{K}{n} \rho^n (1-\rho)^K \cdot \frac{1}{\text{norm}}$$

实际上这是有限状态的生灭过程：

$$P_n = \binom{K}{n} \left(\frac{\lambda}{\mu}\right)^n P_0$$

### 7.2 性能指标

- 平均故障机器数：$L = K - \frac{\mu}{\lambda}(1 - P_0)$
- 机器可用率：$A = 1 - \frac{L}{K}$

```python
def finite_source_model(K, lam, mu):
    """M/M/1/K/K模型（机器维修问题）"""
    rho = lam / mu
    P = [0] * (K + 1)
    for n in range(K + 1):
        P[n] = math.comb(K, n) * rho**n
    Z = sum(P)
    P = [p / Z for p in P]
    L = sum(n * P[n] for n in range(K + 1))
    availability = 1 - L / K
    return L, availability, P

L, avail, dist = finite_source_model(K=10, lam=0.1, mu=1.0)
print(f"Average broken machines: {L:.4f}")
print(f"Machine availability: {avail:.4f}")
```

## 八、实际应用案例

### 8.1 呼叫中心人员配置

问题：某呼叫中心平均每小时接到 120 个电话，每个通话平均 4 分钟。要求 80% 的来电在等待不超过 30 秒内被接听。

```python
def call_center_analysis(lam_per_min, avg_service_min, target_wait_sec):
    lam = lam_per_min
    mu = 1.0 / avg_service_min
    target_wait = target_wait_sec / 60.0
    for c in range(1, 50):
        rho = lam / (c * mu)
        if rho >= 1:
            continue
        q = MMcQueue(lam, mu, c)
        wq = q.Wq()
        p_wait = q.erlang_c()
        if wq <= target_wait and rho < 0.85:
            print(f"c={c}: Wq={wq*60:.1f}s, P(wait)={p_wait:.3f}, rho={rho:.3f}")
            return c
    return None

call_center_analysis(lam_per_min=2.0, avg_service_min=4.0, target_wait_sec=30)
```

Web 服务器请求处理建模：

## 九、排队论的关键要点总结

1. Little 公式 $L = \lambda W$ 和 $L_q = \lambda W_q$ 是最普适的关系，适用于绝大多数排队模型
2. M/M/1 的平稳分布为几何分布 $P_n = (1-\rho)\rho^n$
3. M/M/c 模型中 Erlang C 公式给出了等待概率
4. 系统稳定性条件为 $\rho = \lambda/(c\mu) < 1$
5. 服务时间的方差对排队长度有显著影响（P-K 公式）
6. 确定性服务时间（M/D/1）比指数服务时间（M/M/1）排队长度减半
7. Jackson 定理使得复杂网络可分解为独立节点分析
8. 实际应用中常需通过仿真验证解析结果的适用性
9. 有限容量模型引入了顾客丢失概率，需在服务质量和成本间权衡
10. 排队论为系统容量规划和资源优化提供了严格的数学框架
