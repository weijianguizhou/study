# 支持向量机预测模型

## 一、支持向量机基础

### 1.1 线性可分与最大间隔

支持向量机（Support Vector Machine, SVM）最初由Vapnik等人于1990年代提出，其核心思想是寻找一个**最大间隔超平面**将数据分开。

**线性分类器**：对于线性可分数据，超平面为：

$$\mathbf{w}^T\mathbf{x} + b = 0$$

**函数间隔**：

$$\hat{\gamma}_i = y_i(\mathbf{w}^T\mathbf{x}_i + b)$$

**几何间隔**：

$$\gamma_i = \frac{y_i(\mathbf{w}^T\mathbf{x}_i + b)}{\|\mathbf{w}\|}$$

**最大间隔分类器**：

$$\max_{\mathbf{w}, b} \frac{2}{\|\mathbf{w}\|} \quad \text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1, \quad i = 1, 2, \ldots, n$$

等价于：

$$\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1$$

### 1.2 对偶问题

引入拉格朗日乘子 $\alpha_i \geq 0$：

$$\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha}) = \frac{1}{2}\|\mathbf{w}\|^2 - \sum_{i=1}^{n}\alpha_i[y_i(\mathbf{w}^T\mathbf{x}_i + b) - 1]$$

对 $\mathbf{w}$ 和 $b$ 求偏导并令其为零：

$$\mathbf{w} = \sum_{i=1}^{n}\alpha_i y_i \mathbf{x}_i, \quad \sum_{i=1}^{n}\alpha_i y_i = 0$$

代入得到对偶问题：

$$\max_{\boldsymbol{\alpha}} \sum_{i=1}^{n}\alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n}\alpha_i\alpha_j y_i y_j \mathbf{x}_i^T\mathbf{x}_j$$

$$\text{s.t.} \quad \alpha_i \geq 0, \quad \sum_{i=1}^{n}\alpha_i y_i = 0$$

### 1.3 KKT条件

$$\alpha_i[y_i(\mathbf{w}^T\mathbf{x}_i + b) - 1] = 0$$

满足 $\alpha_i > 0$ 的样本称为**支持向量**，位于间隔边界上。

### 1.4 软间隔

对于线性不可分数据，引入松弛变量 $\xi_i \geq 0$：

$$\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^{n}\xi_i$$

$$\text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0$$

其中 $C > 0$ 为惩罚参数，控制对误分类的惩罚程度。

---

## 二、核方法

### 2.1 核技巧

当数据在原始空间中线性不可分时，通过映射 $\phi: \mathbb{R}^d \rightarrow \mathbb{R}^D$ 将数据映射到高维空间，在高维空间中使用线性SVM。

**核函数**：$K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T\phi(\mathbf{x}_j)$

核技巧使得无需显式计算 $\phi(\mathbf{x})$，直接计算内积。

### 2.2 常用核函数

| 核函数 | 表达式 | 参数 | 特点 |
|--------|--------|------|------|
| 线性核 | $K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i^T\mathbf{x}_j$ | 无 | 计算快 |
| 多项式核 | $K(\mathbf{x}_i, \mathbf{x}_j) = (\gamma\mathbf{x}_i^T\mathbf{x}_j + r)^d$ | $\gamma, r, d$ | 非线性 |
| RBF核（高斯核） | $K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma\|\mathbf{x}_i - \mathbf{x}_j\|^2)$ | $\gamma$ | 最常用 |
| Sigmoid核 | $K(\mathbf{x}_i, \mathbf{x}_j) = \tanh(\gamma\mathbf{x}_i^T\mathbf{x}_j + r)$ | $\gamma, r$ | 类神经网络 |

### 2.3 RBF核的直觉理解

RBF核将数据映射到无限维空间：

$$\exp(-\gamma\|\mathbf{x}_i - \mathbf{x}_j\|^2) = \sum_{k=0}^{\infty}\frac{(\gamma\mathbf{x}_i^T\mathbf{x}_j)^k}{k!}e^{-\gamma(\|\mathbf{x}_i\|^2 + \|\mathbf{x}_j\|^2)}$$

$\gamma$ 参数控制"影响范围"：
- $\gamma$ 大：每个支持向量影响范围小，决策边界复杂
- $\gamma$ 小：每个支持向量影响范围大，决策边界平滑

### 2.4 Mercer定理

核函数 $K(\mathbf{x}_i, \mathbf{x}_j)$ 是有效的核函数当且仅当对任意样本 $\mathbf{x}_1, \ldots, \mathbf{x}_n$，核矩阵 $K_{ij} = K(\mathbf{x}_i, \mathbf{x}_j)$ 是半正定的。

## 三、支持向量回归（SVR）

### 3.1 $\epsilon$-不敏感损失

SVR使用$\epsilon$-不敏感损失函数：

$$L_\epsilon(y, f(\mathbf{x})) = \max(0, |y - f(\mathbf{x})| - \epsilon)$$

即当预测误差小于 $\epsilon$ 时不计损失。

### 3.2 SVR优化问题

$$\min_{\mathbf{w}, b, \boldsymbol{\xi}, \boldsymbol{\xi}^*} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^{n}(\xi_i + \xi_i^*)$$

$$\text{s.t.} \begin{cases} y_i - \mathbf{w}^T\phi(\mathbf{x}_i) - b \leq \epsilon + \xi_i \\ \mathbf{w}^T\phi(\mathbf{x}_i) + b - y_i \leq \epsilon + \xi_i^* \\ \xi_i, \xi_i^* \geq 0 \end{cases}$$

### 3.3 SVR对偶问题

$$\min_{\boldsymbol{\alpha}, \boldsymbol{\alpha}^*} \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n}(\alpha_i - \alpha_i^*)(\alpha_j - \alpha_j^*)K(\mathbf{x}_i, \mathbf{x}_j) + \epsilon\sum_{i=1}^{n}(\alpha_i + \alpha_i^*) - \sum_{i=1}^{n}y_i(\alpha_i - \alpha_i^*)$$

$$\text{s.t.} \quad 0 \leq \alpha_i, \alpha_i^* \leq C, \quad \sum_{i=1}^{n}(\alpha_i - \alpha_i^*) = 0$$

### 3.4 SVR预测函数

$$f(\mathbf{x}) = \sum_{i=1}^{n}(\alpha_i - \alpha_i^*)K(\mathbf{x}_i, \mathbf{x}) + b$$

只有满足 $0 < \alpha_i < C$ 或 $0 < \alpha_i^* < C$ 的样本才是支持向量。

---

## 四、超参数选择

### 4.1 网格搜索

在参数空间中遍历所有组合：

$$C \in \{2^{-5}, 2^{-3}, \ldots, 2^{15}\}, \quad \gamma \in \{2^{-15}, 2^{-13}, \ldots, 2^{3}\}$$

### 4.2 交叉验证

**K折交叉验证**：将数据分为K份，每次用K-1份训练、1份验证，重复K次。

$$CV = \frac{1}{K}\sum_{k=1}^{K}L_k$$

### 4.3 贝叶斯优化

使用高斯过程建模目标函数，通过采集函数选择下一个评估点。

## 五、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.svm import SVR, SVC
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import GridSearchCV, TimeSeriesSplit
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

class SVRPredictor:
    """支持向量回归预测模型"""
    
    def __init__(self, kernel='rbf', C=1.0, epsilon=0.1, gamma='scale'):
        """
        参数:
            kernel: 核函数类型
            C: 惩罚参数
            epsilon: epsilon不敏感损失参数
            gamma: RBF核参数
        """
        self.kernel = kernel
        self.C = C
        self.epsilon = epsilon
        self.gamma = gamma
        self.model = None
        self.scaler_X = StandardScaler()
        self.scaler_y = StandardScaler()
        
    def fit(self, X, y, scale=True):
        """拟合模型"""
        if scale:
            X = self.scaler_X.fit_transform(X)
            y = self.scaler_y.fit_transform(y.reshape(-1, 1)).ravel()
        
        self.model = SVR(
            kernel=self.kernel,
            C=self.C,
            epsilon=self.epsilon,
            gamma=self.gamma
        )
        self.model.fit(X, y)
        return self
    
    def predict(self, X, scale=True):
        """预测"""
        if scale:
            X = self.scaler_X.transform(X)
        
        y_pred = self.model.predict(X)
        
        if scale:
            y_pred = self.scaler_y.inverse_transform(y_pred.reshape(-1, 1)).ravel()
        
        return y_pred
    
    def get_metrics(self, X, y):
        """计算评估指标"""
        y_pred = self.predict(X)
        return {
            'R²': r2_score(y, y_pred),
            'MSE': mean_squared_error(y, y_pred),
            'RMSE': np.sqrt(mean_squared_error(y, y_pred)),
            'MAE': mean_absolute_error(y, y_pred),
            'MAPE': np.mean(np.abs((y - y_pred) / y)) * 100
        }
    
    def grid_search(self, X, y, param_grid=None, cv=5):
        """网格搜索超参数"""
        if param_grid is None:
            param_grid = {
                'C': [0.1, 1, 10, 100],
                'gamma': ['scale', 'auto', 0.01, 0.1, 1],
                'epsilon': [0.01, 0.05, 0.1, 0.2]
            }
        
        X_scaled = self.scaler_X.fit_transform(X)
        y_scaled = self.scaler_y.fit_transform(y.reshape(-1, 1)).ravel()
        
        svr = SVR(kernel=self.kernel)
        grid_search = GridSearchCV(svr, param_grid, cv=cv, 
                                   scoring='neg_mean_squared_error',
                                   n_jobs=-1, verbose=0)
        grid_search.fit(X_scaled, y_scaled)
        
        self.C = grid_search.best_params_['C']
        self.gamma = grid_search.best_params_['gamma']
        self.epsilon = grid_search.best_params_['epsilon']
        
        print(f"最优参数: {grid_search.best_params_}")
        print(f"最优MSE: {-grid_search.best_score_:.6f}")
        
        # 用最优参数重新训练
        self.fit(X, y)
        
        return grid_search
    
    def visualize_fit(self, X, y):
        """可视化拟合结果"""
        y_pred = self.predict(X)
        
        fig, axes = plt.subplots(1, 3, figsize=(18, 5))
        
        # 拟合曲线
        axes[0].scatter(y, y_pred, alpha=0.5, s=20)
        min_val = min(y.min(), y_pred.min())
        max_val = max(y.max(), y_pred.max())
        axes[0].plot([min_val, max_val], [min_val, max_val], 'r--', linewidth=2)
        axes[0].set_xlabel('实际值')
        axes[0].set_ylabel('预测值')
        axes[0].set_title('实际值 vs 预测值')
        axes[0].grid(True, alpha=0.3)
        
        # 残差
        residuals = y - y_pred
        axes[1].scatter(y_pred, residuals, alpha=0.5, s=20)
        axes[1].axhline(y=0, color='r', linestyle='--')
        axes[1].set_xlabel('预测值')
        axes[1].set_ylabel('残差')
        axes[1].set_title('残差图')
        axes[1].grid(True, alpha=0.3)
        
        # 残差分布
        axes[2].hist(residuals, bins=30, edgecolor='black', alpha=0.7)
        axes[2].set_xlabel('残差')
        axes[2].set_ylabel('频数')
        axes[2].set_title('残差分布')
        axes[2].grid(True, alpha=0.3)
        
        plt.tight_layout()
        plt.show()


class SVMTimeSeriesPredictor:
    """基于SVM的时间序列预测"""
    
    def __init__(self, seq_length=10, **svr_params):
        self.seq_length = seq_length
        self.svr = SVRPredictor(**svr_params)
        
    def create_features(self, data):
        """将时间序列转化为监督学习问题"""
        X, y = [], []
        for i in range(len(data) - self.seq_length):
            X.append(data[i:i+self.seq_length])
            y.append(data[i+self.seq_length])
        return np.array(X), np.array(y)
    
    def fit(self, data, test_ratio=0.2):
        """拟合模型"""
        X, y = self.create_features(data)
        
        split = int(len(X) * (1 - test_ratio))
        X_train, X_test = X[:split], X[split:]
        y_train, y_test = y[:split], y[split:]
        
        self.svr.fit(X_train, y_train)
        
        self.train_metrics = self.svr.get_metrics(X_train, y_train)
        self.test_metrics = self.svr.get_metrics(X_test, y_test)
        
        return self
    
    def predict_next(self, recent_data):
        """预测下一个值"""
        if len(recent_data) < self.seq_length:
            raise ValueError(f"需要至少{self.seq_length}个数据点")
        
        x = np.array(recent_data[-self.seq_length:]).reshape(1, -1)
        return self.svr.predict(x)[0]
    
    def predict_multi_step(self, data, steps=10):
        """多步预测"""
        predictions = list(data)
        all_preds = []
        
        for _ in range(steps):
            pred = self.predict_next(predictions)
            predictions.append(pred)
            all_preds.append(pred)
        
        return np.array(all_preds)

np.random.seed(42)

for kernel in kernels:

    svr.fit(X_train, y_train)
    metrics = svr.get_metrics(X_test, y_test)

# RBF核参数优化

    'C': [1, 10, 100],
    'gamma': [0.1, 1, 10],
    'epsilon': [0.05, 0.1, 0.2]
}, cv=5)

metrics_opt = svr_opt.get_metrics(X_test, y_test)
print(f"\n优化后: R²={metrics_opt['R²']:.4f}, RMSE={metrics_opt['RMSE']:.4f}")

svr_opt.visualize_fit(X_test, y_test)
```

## 六、实际案例：PM2.5浓度预测

### 6.1 数据准备

```python
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler

# 模拟PM2.5数据（含天气因素）
np.random.seed(42)
n_days = 365 * 3

# 特征
temperature = 15 + 15 * np.sin(2 * np.pi * np.arange(n_days) / 365) + np.random.normal(0, 3, n_days)
humidity = 60 + 20 * np.sin(2 * np.pi * np.arange(n_days) / 365 + np.pi/4) + np.random.normal(0, 5, n_days)
wind_speed = np.abs(np.random.normal(3, 2, n_days))
pm25 = 50 + 0.5 * temperature - 0.3 * humidity - 2 * wind_speed + np.random.normal(0, 10, n_days)
pm25 = np.maximum(pm25, 0)

df = pd.DataFrame({
    'temperature': temperature,
    'humidity': humidity,
    'wind_speed': wind_speed,
    'pm25': pm25
})

# 创建滞后特征
for lag in [1, 2, 3]:
    df[f'pm25_lag{lag}'] = df['pm25'].shift(lag)

df = df.dropna()
print(f"数据形状: {df.shape}")
print(df.head())
```

### 6.2 建模与评估

```python
from sklearn.model_selection import train_test_split

feature_cols = ['temperature', 'humidity', 'wind_speed', 
                'pm25_lag1', 'pm25_lag2', 'pm25_lag3']
X = df[feature_cols].values
y = df['pm25'].values

# 时序分割（避免数据泄露）
split_idx = int(len(X) * 0.8)
X_train, X_test = X[:split_idx], X[split_idx:]
y_train, y_test = y[:split_idx], y[split_idx:]

# SVR模型

# 评估
train_metrics = svr.get_metrics(X_train, y_train)
test_metrics = svr.get_metrics(X_test, y_test)

print("=== SVR PM2.5预测 ===")
print(f"训练集: R²={train_metrics['R²']:.4f}, RMSE={train_metrics['RMSE']:.2f}")
print(f"测试集: R²={test_metrics['R²']:.4f}, RMSE={test_metrics['RMSE']:.2f}")

# 预测对比
y_pred = svr.predict(X_test)

plt.figure(figsize=(14, 5))
plt.plot(y_test[:100], 'b-', label='实际值', alpha=0.7)

plt.xlabel('样本')
plt.ylabel('PM2.5 (μg/m³)')
plt.title('SVR PM2.5浓度预测')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

## 八、关键要点总结

1. **SVM的核心思想**：最大间隔分类/回归
2. **核技巧**：隐式映射到高维空间，避免维度灾难
3. **$\epsilon$-不敏感损失**：SVR的关键，允许预测误差在 $\epsilon$ 范围内
4. **支持向量**：决定决策边界的少数样本点
5. **核函数选择**：RBF核是最通用的选择，线性核适合高维数据
6. **超参数 $C$**：控制模型复杂度与拟合度的平衡
7. **超参数 $\gamma$**：RBF核的带宽参数，控制决策边界的复杂度
8. **数据标准化**：对SVM性能影响很大，必须进行
9. **时间序列应用**：需要将序列数据转化为监督学习格式
10. **SVM的优势**：泛化能力强、理论基础坚实、适合中小样本
11. **SVM的局限**：训练时间复杂度 $O(n^2 \sim n^3)$、对大规模数据不友好、核函数选择困难
