# 马尔可夫预测模型

## 一、马尔可夫链基本概念

### 1.1 随机过程与马尔可夫性

**随机过程**是一族依赖于时间参数的随机变量 $\{X(t), t \in T\}$。

**马尔可夫性（无后效性）**：系统未来的状态只与当前状态有关，与过去的状态无关。即：

$$P\{X(t_{n+1}) = j \mid X(t_n) = i, X(t_{n-1}) = i_{n-1}, \ldots, X(t_0) = i_0\} = P\{X(t_{n+1}) = j \mid X(t_n) = i\}$$

### 1.2 马尔可夫链的定义

若随机过程 $\{X_n, n = 0, 1, 2, \ldots\}$ 的状态空间为 $S = \{s_1, s_2, \ldots, s_N\}$，且满足：

$$P\{X_{n+1} = s_j \mid X_n = s_i, X_{n-1} = s_{i_{n-1}}, \ldots, X_0 = s_{i_0}\} = P\{X_{n+1} = s_j \mid X_n = s_i\}$$

则称 $\{X_n\}$ 为**马尔可夫链**（Markov Chain）。

### 1.3 状态空间

状态空间 $S$ 是所有可能状态的集合。例如：

- 天气预测：$S = \{\text{晴}, \text{阴}, \text{雨}\}$
- 股票市场：$S = \{\text{涨}, \text{跌}, \text{平}\}$
- 设备状态：$S = \{\text{正常}, \text{故障}\}$

---

## 二、转移概率与转移矩阵

### 2.1 一步转移概率

从状态 $s_i$ 转移到状态 $s_j$ 的**一步转移概率**定义为：

$$p_{ij} = P\{X_{n+1} = s_j \mid X_n = s_i\}$$

转移概率满足：
1. **非负性**：$p_{ij} \geq 0$
2. **归一性**：$\sum_{j=1}^{N} p_{ij} = 1$（每行之和为1）

### 2.2 一步转移概率矩阵

$$P = \begin{pmatrix} p_{11} & p_{12} & \cdots & p_{1N} \\ p_{21} & p_{22} & \cdots & p_{2N} \\ \vdots & \vdots & \ddots & \vdots \\ p_{N1} & p_{N2} & \cdots & p_{NN} \end{pmatrix}$$

### 2.3 $k$ 步转移概率

从状态 $s_i$ 经过 $k$ 步转移到状态 $s_j$ 的概率：

$$p_{ij}^{(k)} = P\{X_{n+k} = s_j \mid X_n = s_i\}$$

**Chapman-Kolmogorov 方程**：

$$p_{ij}^{(k)} = \sum_{r=1}^{N} p_{ir}^{(m)} \cdot p_{rj}^{(k-m)}, \quad 0 < m < k$$

特别地，$k$ 步转移概率矩阵：

$$P^{(k)} = P^k$$

即 $k$ 步转移矩阵等于一步转移矩阵的 $k$ 次幂。

---

## 三、平稳分布与稳态预测

### 3.1 平稳分布

若存在概率向量 $\pi = (\pi_1, \pi_2, \ldots, \pi_N)$ 满足：

$$\pi P = \pi, \quad \sum_{i=1}^{N} \pi_i = 1, \quad \pi_i \geq 0$$

则称 $\pi$ 为马尔可夫链的**平稳分布**（steady-state distribution）。

### 3.2 稳态存在条件

**定理**：有限马尔可夫链若满足以下条件，则存在唯一平稳分布：

1. **不可约**（irreducible）：任意两个状态之间可达
2. **非周期**（aperiodic）：所有状态的周期为1
3. **正常返**（positive recurrent）：有限状态空间自动满足

### 3.3 稳态求解方法

**方法一：直接求解线性方程组**

$$\begin{cases} \pi P = \pi \\ \sum_{i=1}^{N} \pi_i = 1 \end{cases}$$

等价于求解 $(P^T - I)\pi^T = 0$，加上归一化条件。

**方法二：幂迭代法**

选取任意初始概率向量 $\pi^{(0)}$，反复迭代：

$$\pi^{(k+1)} = \pi^{(k)} P$$

直至 $\pi^{(k+1)} \approx \pi^{(k)}$ 收敛。

**方法三：求解 $(P^T - I)\pi^T = 0$ 的零空间**

将归一化条件替换方程组中的某一个方程。

## 四、马尔可夫预测模型

### 4.1 基本预测步骤

1. **确定状态空间** $S = \{s_1, s_2, \ldots, s_N\}$
2. **统计转移频率**，估计转移概率矩阵 $P$
3. **确定当前状态** $X_0$
4. **计算 $k$ 步后的状态分布**：$\pi^{(k)} = \pi^{(0)} P^k$

### 4.2 转移概率的估计

设有状态序列 $x_1, x_2, \ldots, x_n$，从状态 $s_i$ 转移到状态 $s_j$ 的次数为 $n_{ij}$，则：

$$\hat{p}_{ij} = \frac{n_{ij}}{\sum_{k=1}^{N} n_{ik}}$$

### 4.3 状态分类与特征

| 状态类型 | 定义 | 说明 |
|----------|------|------|
| 吸收态 | $p_{ii} = 1$ | 一旦进入永远不离开 |
| 常返态 | 以概率1返回 | 会反复访问 |
| 遍历态 | 常返且非周期 | 存在平稳分布 |
| 暂态 | 非常返 | 以正概率永不返回 |

## 五、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

class MarkovChain:
    """马尔可夫链模型"""
    
    def __init__(self, states, transition_matrix):
        """
        参数:
            states: 状态列表，如 ['晴', '阴', '雨']
            transition_matrix: 转移概率矩阵（numpy数组）
        """
        self.states = states
        self.n_states = len(states)
        self.P = np.array(transition_matrix, dtype=float)
        
        # 验证转移矩阵
        assert self.P.shape == (self.n_states, self.n_states), "转移矩阵维度不匹配"
        assert np.allclose(self.P.sum(axis=1), 1), "转移矩阵每行之和应为1"
    
    def k_step_transition(self, k):
        """计算k步转移矩阵"""
        return np.linalg.matrix_power(self.P, k)
    
    def predict(self, initial_state, steps):
        """
        预测未来状态分布
        参数:
            initial_state: 初始状态索引或概率向量
            steps: 预测步数
        返回:
            每步的状态概率分布
        """
        if isinstance(initial_state, int):
            pi = np.zeros(self.n_states)
            pi[initial_state] = 1.0
        else:
            pi = np.array(initial_state, dtype=float)
        
        results = [pi.copy()]
        for _ in range(steps):
            pi = pi @ self.P
            results.append(pi.copy())
        
        return np.array(results)
    
    def steady_state(self, method='power'):
        """
        计算平稳分布
        参数:
            method: 'power'(幂迭代) 或 'solve'(直接求解)
        """
        if method == 'power':
            pi = np.ones(self.n_states) / self.n_states
            for _ in range(1000):
                pi_new = pi @ self.P
                if np.allclose(pi, pi_new, atol=1e-10):
                    break
                pi = pi_new
            return pi
        
        elif method == 'solve':
            # 求解 (P^T - I)π^T = 0
            A = (self.P.T - np.eye(self.n_states))
            # 替换最后一行为归一化条件
            A[-1, :] = 1
            b = np.zeros(self.n_states)
            b[-1] = 1
            return np.linalg.solve(A, b)
    
    def classify_states(self):
        """状态分类（简化版）"""
        P_k = self.P.copy()
        classification = {}
        
        for i in range(self.n_states):
            # 检查是否为吸收态
            if self.P[i, i] == 1.0:
                classification[self.states[i]] = '吸收态'
                continue
            
            # 计算返回概率
            # 通过幂次计算返回概率
            return_prob = 0
            for k in range(1, 100):
                P_k = np.linalg.matrix_power(self.P, k)
                return_prob += P_k[i, i]
                if return_prob > 0.999:
                    classification[self.states[i]] = '常返态'
                    break
            else:
                classification[self.states[i]] = '暂态'
        
        return classification
    
    def absorption_probability(self, absorption_states):
        """
        计算吸收概率（吸收马尔可夫链）
        参数:
            absorption_states: 吸收态的索引列表
        返回:
            从各状态被各吸收态吸收的概率矩阵
        """
        # 将状态排序：非常返态在前，吸收态在后
        transient = [i for i in range(self.n_states) if i not in absorption_states]
        recurrent = absorption_states
        
        n_t = len(transient)
        n_r = len(recurrent)
        
        # 提取子矩阵
        Q = self.P[np.ix_(transient, transient)]  # 非常返→非常返
        R = self.P[np.ix_(transient, recurrent)]  # 非常返→吸收态
        
        # 基本矩阵 N = (I - Q)^{-1}
        N = np.linalg.inv(np.eye(n_t) - Q)
        
        # 吸收概率矩阵 B = N @ R
        B = N @ R
        
        return B, transient, recurrent
    
    def visualize(self, initial_state=0, steps=20):
        """可视化状态概率演变"""
        results = self.predict(initial_state, steps)
        
        fig, axes = plt.subplots(1, 2, figsize=(14, 5))
        
        # 左图：概率演变曲线
        ax1 = axes[0]
        for j in range(self.n_states):
            ax1.plot(range(steps + 1), results[:, j], 
                    'o-', label=self.states[j], linewidth=2, markersize=4)
        ax1.set_xlabel('步数')
        ax1.set_ylabel('概率')
        ax1.set_title('状态概率演变')
        ax1.legend()
        ax1.grid(True, alpha=0.3)
        
        # 右图：转移矩阵热力图
        ax2 = axes[1]
        im = ax2.imshow(self.P, cmap='YlOrRd', vmin=0, vmax=1)
        ax2.set_xticks(range(self.n_states))
        ax2.set_yticks(range(self.n_states))
        ax2.set_xticklabels(self.states)
        ax2.set_yticklabels(self.states)
        ax2.set_title('转移概率矩阵')
        
        for i in range(self.n_states):
            for j in range(self.n_states):
                ax2.text(j, i, f'{self.P[i,j]:.2f}', 
                        ha='center', va='center', fontsize=12)
        
        plt.colorbar(im, ax=ax2)
        plt.tight_layout()
        plt.show()


# ============ 示例1：天气预测 ============
states = ['晴', '阴', '雨']
P_weather = [
    [0.6, 0.3, 0.1],   # 晴→晴、阴、雨
    [0.2, 0.5, 0.3],   # 阴→晴、阴、雨
    [0.1, 0.3, 0.6]    # 雨→晴、阴、雨
]

mc_weather = MarkovChain(states, P_weather)

# 今天是晴天，预测未来5天
print("=== 天气预测 ===")
results = mc_weather.predict(0, steps=5)
for day in range(6):
    probs = results[day]
    pred_state = states[np.argmax(probs)]
    if day == 0:
        print(f"第0天（今天）: {pred_state}天 (确定)")
    else:
        print(f"第{day}天: {pred_state}天 "
              f"(P(晴)={probs[0]:.3f}, P(阴)={probs[1]:.3f}, P(雨)={probs[2]:.3f})")

# 平稳分布
pi = mc_weather.steady_state()
print(f"\n平稳分布: P(晴)={pi[0]:.4f}, P(阴)={pi[1]:.4f}, P(雨)={pi[2]:.4f}")

mc_weather.visualize(initial_state=0, steps=20)


# ============ 示例2：市场份额预测 ============
brands = ['品牌A', '品牌B', '品牌C']
P_market = [
    [0.7, 0.2, 0.1],
    [0.15, 0.65, 0.2],
    [0.1, 0.15, 0.75]
]

mc_market = MarkovChain(brands, P_market)

print("\n=== 市场份额预测 ===")

for k in [1, 2, 3, 5, 10, 20]:
    share_k = np.array(current_share) @ np.linalg.matrix_power(np.array(P_market), k)
    share_k = share_k / share_k.sum()  # 归一化
    print(f"{k}步后: A={share_k[0]:.3f}, B={share_k[1]:.3f}, C={share_k[2]:.3f}")

steady = mc_market.steady_state()
print(f"稳态份额: A={steady[0]:.3f}, B={steady[1]:.3f}, C={steady[2]:.3f}")


# ============ 示例3：设备状态预测 ============
states_equip = ['正常', '需维修', '故障']
P_equip = [
    [0.85, 0.10, 0.05],
    [0.20, 0.60, 0.20],
    [0.0,  0.0,  1.0]   # 故障为吸收态
]

mc_equip = MarkovChain(states_equip, P_equip)

print("\n=== 设备状态预测 ===")
# 设备目前正常，预测10步后状态
```

## 六、实际案例：产品市场占有率预测

### 6.1 问题描述

某市场有A、B、C三个品牌的洗衣液，根据市场调查得到消费者的品牌转换情况如下：

| 从\到 | A | B | C |
|--------|---|---|---|
| A | 280 | 80 | 40 |
| B | 60 | 270 | 70 |
| C | 30 | 50 | 220 |

当前市场占有率为：A占40%，B占35%，C占25%。预测6个月后的市场占有率。

### 6.2 解题过程

```python
import numpy as np

# Step 1: 计算转移概率矩阵
raw_data = np.array([
    [280, 80, 40],
    [60, 270, 70],
    [30, 50, 220]
], dtype=float)

# 按行归一化
P = raw_data / raw_data.sum(axis=1, keepdims=True)
print("转移概率矩阵:")
print(P)

# Step 2: 构建马尔可夫链
brands = ['A', 'B', 'C']
mc = MarkovChain(brands, P)

# Step 3: 预测未来市场占有率
current = np.array([0.40, 0.35, 0.25])
print(f"\n初始市场占有率: A={current[0]:.2f}, B={current[1]:.2f}, C={current[2]:.2f}")

for month in [1, 2, 3, 4, 5, 6]:
    share = current @ np.linalg.matrix_power(P, month)
    print(f"{month}个月后: A={share[0]:.4f}, B={share[1]:.4f}, C={share[2]:.4f}")

# Step 4: 稳态市场占有率
steady = mc.steady_state()
print(f"\n稳态市场占有率: A={steady[0]:.4f}, B={steady[1]:.4f}, C={steady[2]:.4f}")
```

## 七、高级方法

### 7.1 加权马尔可夫预测

对于多指标序列 $X_1, X_2, \ldots, X_m$，分别计算各序列的自相关系数 $\rho_k^{(i)}$，以自相关系数为权重进行加权预测：

$$P_j = \sum_{i=1}^{m} w_i \cdot P_j^{(i)}$$

其中 $w_i = \frac{|\rho_k^{(i)}|}{\sum_{i=1}^{m}|\rho_k^{(i)}|}$。

### 7.2 马尔可夫链蒙特卡洛（MCMC）

当直接采样困难时，构造马尔可夫链使其平稳分布为目标分布 $\pi$：

**Metropolis-Hastings算法**：
1. 从提议分布 $q(x'|x_t)$ 生成候选状态 $x'$
2. 计算接受概率：
$$\alpha = \min\left\{1, \frac{\pi(x')q(x_t|x')}{\pi(x_t)q(x'|x_t)}\right\}$$
3. 以概率 $\alpha$ 接受 $x'$，否则保留 $x_t$

**Gibbs采样**：MH算法的特殊情况，提议分布为条件分布 $q(x_j|x_{-j}) = \pi(x_j|x_{-j})$。

### 7.3 隐马尔可夫模型（HMM）

当状态不可直接观测时，使用隐马尔可夫模型：

$$\lambda = (\pi, A, B)$$

- $\pi$：初始状态概率
- $A$：状态转移矩阵
- $B$：观测概率矩阵（发射概率）

三个基本问题：
1. **评估问题**：给定模型 $\lambda$，计算 $P(O|\lambda)$（前向算法）
2. **解码问题**：给定模型 $\lambda$ 和观测序列 $O$，求最优状态序列（Viterbi算法）
3. **学习问题**：估计模型参数使 $P(O|\lambda)$ 最大（Baum-Welch算法）

```python
class HiddenMarkovModel:
    """隐马尔可夫模型（简化实现）"""
    
    def __init__(self, n_states, n_obs):
        self.n_states = n_states
        self.n_obs = n_obs
        self.pi = np.ones(n_states) / n_states       # 初始概率
        self.A = np.ones((n_states, n_states)) / n_states  # 转移矩阵
        self.B = np.ones((n_states, n_obs)) / n_obs    # 发射概率
    
    def forward(self, observations):
        """前向算法：计算 P(O|λ)"""
        T = len(observations)
        alpha = np.zeros((T, self.n_states))
        
        # 初始化
        alpha[0] = self.pi * self.B[:, observations[0]]
        
        # 递推
        for t in range(1, T):
            for j in range(self.n_states):
                alpha[t, j] = np.sum(alpha[t-1] * self.A[:, j]) * self.B[j, observations[t]]
        
        # 终止
        return np.sum(alpha[T-1])
    
    def viterbi(self, observations):
        """Viterbi算法：最可能的状态序列"""
        T = len(observations)
        delta = np.zeros((T, self.n_states))
        psi = np.zeros((T, self.n_states), dtype=int)
        
        # 初始化
        delta[0] = self.pi * self.B[:, observations[0]]
        
        # 递推
        for t in range(1, T):
            for j in range(self.n_states):
                temp = delta[t-1] * self.A[:, j]
                psi[t, j] = np.argmax(temp)
                delta[t, j] = temp[psi[t, j]] * self.B[j, observations[t]]
        
        # 回溯
        states = np.zeros(T, dtype=int)
        states[T-1] = np.argmax(delta[T-1])
        for t in range(T-2, -1, -1):
            states[t] = psi[t+1, states[t+1]]
        
        return states, delta[T-1, states[T-1]]
    
    def baum_welch(self, observations, n_iter=100):
        """Baum-Welch算法：参数估计"""
        T = len(observations)
        
        for _ in range(n_iter):
            # E步：前向-后向算法
            alpha = np.zeros((T, self.n_states))
            beta = np.zeros((T, self.n_states))
            
            alpha[0] = self.pi * self.B[:, observations[0]]
            for t in range(1, T):
                for j in range(self.n_states):
                    alpha[t, j] = np.sum(alpha[t-1] * self.A[:, j]) * self.B[j, observations[t]]
            
            beta[T-1] = 1
            for t in range(T-2, -1, -1):
                for i in range(self.n_states):
                    beta[t, i] = np.sum(self.A[i, :] * self.B[:, observations[t+1]] * beta[t+1])
            
            # 计算 gamma 和 xi
            gamma = alpha * beta
            gamma = gamma / gamma.sum(axis=1, keepdims=True)
            
            # M步：更新参数
            self.pi = gamma[0]
            
            for i in range(self.n_states):
                for j in range(self.n_states):
                    xi_sum = 0
                    gamma_sum = 0
                    for t in range(T-1):
                        xi_sum += alpha[t, i] * self.A[i, j] * self.B[j, observations[t+1]] * beta[t+1, j]
                        gamma_sum += gamma[t, i]
                    self.A[i, j] = xi_sum / (gamma_sum + 1e-10)
                
                # 归一化
                self.A[i] /= self.A[i].sum()
                
                for k in range(self.n_obs):
                    gamma_k_sum = np.sum(gamma[:, i] * (observations == k))
                    self.B[i, k] = gamma_k_sum / (gamma.sum(axis=0)[i] + 1e-10)
```

## 八、关键要点总结

1. **马尔可夫性**：未来状态只依赖于当前状态，不依赖历史
2. **转移矩阵**是马尔可夫链的核心：$P^{(k)} = P^k$
3. **平稳分布**满足 $\pi P = \pi$，代表系统的长期均衡状态
4. **预测方法**：$\pi^{(k)} = \pi^{(0)} P^k$，通过矩阵幂运算实现
5. **加权马尔可夫**适用于多指标预测问题
6. **HMM** 适用于状态不可直接观测的场景
7. **MCMC方法**将马尔可夫链用于贝叶斯推断中的采样
8. **实际应用**：市场份额预测、天气预报、基因序列分析、语音识别等
