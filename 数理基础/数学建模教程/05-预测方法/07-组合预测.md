# 组合预测模型

## 一、组合预测概述

### 1.1 基本概念

组合预测（Combined Forecasting / Ensemble Forecasting）是将多种单一预测方法的结果按一定规则组合，以获得比任何单一方法更优的预测效果。

**核心思想**：不同预测方法在不同条件下各有优势，通过合理组合可以"取长补短"，提高预测精度和稳健性。

### 1.2 理论基础

Bates和Granger（1969）首次提出组合预测理论。其数学基础是：

**定理**：设 $f_1, f_2, \ldots, f_m$ 为 $m$ 个无偏预测，组合预测 $\hat{f} = \sum_{i=1}^{m}w_i f_i$ 的方差满足：

$$\text{Var}(\hat{f}) \leq \min_{i}\text{Var}(f_i)$$

当且仅当所有预测方法完全相关时等号成立。即**只要预测方法之间不完全相关，组合预测的精度就优于任何单一方法。**

### 1.3 组合预测的分类

| 分类方式 | 类型 | 说明 |
|----------|------|------|
| 权重确定 | 等权组合 | 各方法权重相同 |
| | 方差倒数法 | 以误差方差的倒数为权重 |
| | 最优化方法 | 以最小化误差为目标优化权重 |
| | 自适应方法 | 权重随时间动态调整 |
| 组合对象 | 预测值组合 | 直接组合预测结果 |
| | 模型组合 | 组合模型结构 |
| | 信息组合 | 组合多源信息 |

---

## 二、等权组合法

### 2.1 基本原理

最简单的组合方法，赋予每种预测方法相同的权重：

$$\hat{Y}_t = \frac{1}{m}\sum_{i=1}^{m}\hat{Y}_{it}$$

其中 $\hat{Y}_{it}$ 为第 $i$ 种方法在 $t$ 时刻的预测值。

### 2.2 适用条件

- 各预测方法的精度相近
- 对各方法的可靠性没有先验信息
- 预测方法的数量不多（通常 $m \leq 5$）

### 2.3 理论依据

当各预测方法的误差不相关时，等权组合可以将方差降低为：

$$\text{Var}(\hat{Y}) = \frac{1}{m}\bar{\sigma}^2$$

其中 $\bar{\sigma}^2$ 为各方法误差方差的均值。

---

## 三、方差倒数法

### 3.1 基本原理

以各预测方法的误差方差的倒数为权重，精度越高的方法权重越大：

$$w_i = \frac{1/\sigma_i^2}{\sum_{j=1}^{m}1/\sigma_j^2}$$

其中 $\sigma_i^2$ 为第 $i$ 种方法的预测误差方差。

### 3.2 方差估计

在实际应用中，方差通常用样本误差的均方来估计：

$$\hat{\sigma}_i^2 = \frac{1}{n}\sum_{t=1}^{n}(Y_t - \hat{Y}_{it})^2$$

### 3.3 改进：考虑相关性的方差倒数法

当预测方法的误差相关时，组合预测的方差为：

$$\text{Var}(\hat{Y}) = \mathbf{w}^T\boldsymbol{\Sigma}\mathbf{w}$$

其中 $\boldsymbol{\Sigma}$ 为误差协方差矩阵。

---

## 四、最优化组合法

### 4.1 最小二乘法确定权重

**目标函数**：

$$\min_{\mathbf{w}} \sum_{t=1}^{n}\left(Y_t - \sum_{i=1}^{m}w_i \hat{Y}_{it}\right)^2$$

$$\text{s.t.} \sum_{i=1}^{m}w_i = 1, \quad w_i \geq 0$$

### 4.2 矩阵形式

设 $\mathbf{e}_t = (e_{1t}, e_{2t}, \ldots, e_{mt})^T$ 为 $t$ 时刻各方法的预测误差，则：

$$\min_{\mathbf{w}} \sum_{t=1}^{n}(\mathbf{w}^T\mathbf{e}_t)^2 = \mathbf{w}^T\mathbf{E}\mathbf{w}$$

其中 $\mathbf{E} = \sum_{t=1}^{n}\mathbf{e}_t\mathbf{e}_t^T$ 为误差信息矩阵。

**最优解**：

$$\mathbf{w}^* = \frac{\mathbf{E}^{-1}\mathbf{1}}{\mathbf{1}^T\mathbf{E}^{-1}\mathbf{1}}$$

### 4.3 非负约束的求解

当要求 $w_i \geq 0$ 时，这是一个二次规划问题，可以使用拉格朗日乘子法或数值优化方法求解。

### 4.4 基于不同误差准则的优化

**最小化MAE**：

$$\min_{\mathbf{w}} \sum_{t=1}^{n}\left|Y_t - \sum_{i=1}^{m}w_i \hat{Y}_{it}\right|$$

**最小化MAPE**：

$$\min_{\mathbf{w}} \sum_{t=1}^{n}\left|\frac{Y_t - \sum_{i=1}^{m}w_i \hat{Y}_{it}}{Y_t}\right|$$

---

## 五、自适应组合预测

### 5.1 时变权重

权重随时间变化，反映各方法在不同时期的表现：

$$\hat{Y}_t = \sum_{i=1}^{m}w_{it}\hat{Y}_{it}$$

### 5.2 递推更新

$$w_{i,t+1} = w_{it} + \eta \cdot e_t \cdot \hat{Y}_{it}$$

其中 $\eta$ 为学习率，$e_t = Y_t - \hat{Y}_t$ 为组合预测误差。

### 5.3 指数加权法

近期误差赋予更大权重：

$$w_i = \frac{\exp(-\lambda \cdot MSE_i)}{\sum_{j=1}^{m}\exp(-\lambda \cdot MSE_j)}$$

其中 $MSE_i$ 为第 $i$ 种方法在滑动窗口内的均方误差，$\lambda$ 为敏感度参数。

---

## 六、贝叶斯模型平均（BMA）

### 6.1 基本原理

贝叶斯模型平均基于贝叶斯定理，为每个模型分配后验概率作为权重：

$$P(M_k|D) = \frac{P(D|M_k)P(M_k)}{\sum_{j=1}^{K}P(D|M_j)P(M_j)}$$

### 6.2 边际似然

$$P(D|M_k) = \int P(D|\theta_k, M_k)P(\theta_k|M_k)d\theta_k$$

对于正态线性回归模型：

$$P(D|M_k) = \left(\frac{1}{2\pi}\right)^{n/2} \frac{|\mathbf{X}_k^T\mathbf{X}_k|^{-1/2} \cdot s_k^{-(n-p_k)}}{(2\sigma_0^2)^{p_k/2}}$$

### 6.3 BMA预测

$$\hat{Y} = \sum_{k=1}^{K}P(M_k|D)\hat{Y}_k$$

### 6.4 信息准则近似

使用AIC或BIC近似BMA权重：

$$w_k \propto \exp\left(-\frac{1}{2}\Delta_k\right)$$

其中 $\Delta_k = AIC_k - AIC_{min}$（AIC权重）或 $\Delta_k = BIC_k - BIC_{min}$（BIC权重）。

## 七、Python 实现

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.optimize import minimize

class CombinedForecaster:
    """组合预测模型"""
    
    def __init__(self, forecasts, actual):
        """
        参数:
            forecasts: 各单一模型的预测值矩阵，shape=(n, m)
                      n为样本数，m为模型数
            actual: 实际值，shape=(n,)
        """
        self.forecasts = np.array(forecasts)
        self.actual = np.array(actual)
        self.n, self.m = self.forecasts.shape
        self.weights = None
        
    def equal_weight(self):
        """等权组合"""
        self.weights = np.ones(self.m) / self.m
        return self
    
    def variance_inverse(self):
        """方差倒数法"""
        errors = self.actual.reshape(-1, 1) - self.forecasts
        variances = np.var(errors, axis=0)
        
        # 避免除零
        variances = np.maximum(variances, 1e-10)
        inv_var = 1.0 / variances
        self.weights = inv_var / inv_var.sum()
        return self
    
    def optimal_weights(self, method='OLS'):
        """
        最优化组合法
        method: 'OLS'(最小二乘), 'MAE'(最小绝对误差)
        """
        if method == 'OLS':
            # 最小二乘：min w^T E w, s.t. 1^T w = 1, w >= 0
            errors = self.actual.reshape(-1, 1) - self.forecasts
            E = errors.T @ errors
            
            def objective(w):
                return w @ E @ w
            
            constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
            bounds = [(0, 1)] * self.m
            w0 = np.ones(self.m) / self.m
            
            result = minimize(objective, w0, method='SLSQP',
                            bounds=bounds, constraints=constraints)
            self.weights = result.x
        
        elif method == 'MAE':
            def objective(w):
                combined = self.forecasts @ w
                return np.mean(np.abs(self.actual - combined))
            
            constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
            bounds = [(0, 1)] * self.m
            w0 = np.ones(self.m) / self.m
            
            result = minimize(objective, w0, method='SLSQP',
                            bounds=bounds, constraints=constraints)
            self.weights = result.x
        
        return self
    
    def adaptive_weights(self, window=10, decay=0.9):
        """自适应权重（滑动窗口）"""
        self.adaptive_w = np.zeros((self.n, self.m))
        
        # 初始权重为等权
        self.adaptive_w[:window] = 1.0 / self.m
        
        for t in range(window, self.n):
            # 计算窗口内各方法的MSE
            start = max(0, t - window)
            errors = self.actual[start:t].reshape(-1, 1) - self.forecasts[start:t]
            mse = np.mean(errors**2, axis=0)
            
            # 指数加权MSE
            if t == window:
                exp_mse = mse
            else:
                exp_mse = decay * exp_mse + (1 - decay) * mse
            
            # MSE倒数作为权重
            inv_mse = 1.0 / np.maximum(exp_mse, 1e-10)
            self.adaptive_w[t] = inv_mse / inv_mse.sum()
        
        self.weights = self.adaptive_w[-1]
        return self
    
    def predict(self, new_forecasts=None):
        """预测"""
        if new_forecasts is None:
            return self.forecasts @ self.weights
        return np.array(new_forecasts) @ self.weights
    
    def evaluate(self):
        """评估组合效果"""
        combined = self.predict()
        results = {'组合预测': self._metrics(combined)}
        
        for i in range(self.m):
            results[f'方法{i+1}'] = self._metrics(self.forecasts[:, i])
        
        return pd.DataFrame(results).T
    
    def _metrics(self, pred):
        """计算误差指标"""
        errors = self.actual - pred
        return {
            'MAE': np.mean(np.abs(errors)),
            'MSE': np.mean(errors**2),
            'RMSE': np.sqrt(np.mean(errors**2)),
            'MAPE': np.mean(np.abs(errors / self.actual)) * 100
        }
    
    def visualize(self):
        """可视化"""
        fig, axes = plt.subplots(1, 3, figsize=(18, 5))
        
        # 权重分布
        axes[0].bar(range(self.m), self.weights)
        axes[0].set_xticks(range(self.m))
        axes[0].set_xticklabels([f'方法{i+1}' for i in range(self.m)])
        axes[0].set_ylabel('权重')
        axes[0].set_title('组合权重分布')
        
        # 预测对比
        axes[1].plot(self.actual, 'k-', label='实际值', linewidth=2)
        combined = self.predict()
        axes[1].plot(combined, 'r--', label='组合预测', linewidth=2)
        for i in range(self.m):
            axes[1].plot(self.forecasts[:, i], alpha=0.5, label=f'方法{i+1}')
        axes[1].legend(fontsize=8)
        axes[1].set_title('预测值对比')
        
        # 误差分布
        errors = self.actual - combined
        axes[2].hist(errors, bins=20, edgecolor='black', alpha=0.7)
        axes[2].axvline(x=0, color='r', linestyle='--')
        axes[2].set_xlabel('预测误差')
        axes[2].set_title('组合预测误差分布')
        
        plt.tight_layout()
        plt.show()


class BayesianModelAveraging:
    """贝叶斯模型平均"""
    
    def __init__(self, models_info):
        """
        参数:
            models_info: 字典列表，每个包含 'name', 'log_likelihood', 'n_params'
        """
        self.models = models_info
        self.n_models = len(models_info)
        self.weights = None
        
    def compute_bma_weights(self, criterion='BIC'):
        """计算BMA权重"""
        if criterion == 'BIC':
            scores = [m['bic'] for m in self.models]
        elif criterion == 'AIC':
            scores = [m['aic'] for m in self.models]
        
        # 转换为权重
        delta = np.array(scores) - np.min(scores)
        log_weights = -0.5 * delta
        log_weights -= np.max(log_weights)  # 数值稳定性
        weights = np.exp(log_weights)
        self.weights = weights / weights.sum()
        
        return self.weights
    
    def predict(self, predictions_list):
        """BMA组合预测"""
        if self.weights is None:
            self.compute_bma_weights()
        
        pred_matrix = np.array(predictions_list)
        return pred_matrix.T @ self.weights
    
    def summary(self):
        """输出摘要"""
        if self.weights is None:
            self.compute_bma_weights()
        
        print("=== 贝叶斯模型平均权重 ===")
        for i, model in enumerate(self.models):
            print(f"{model['name']}: {self.weights[i]:.4f}")


# ============ 示例1：基本组合预测 ============
np.random.seed(42)
n = 100
t = np.arange(n)
actual = 50 + 2*t + 10*np.sin(2*np.pi*t/12) + np.random.normal(0, 5, n)

# 生成各单一模型的预测（模拟不同方法的特性）
forecast1 = actual + np.random.normal(0, 3, n)   # 方法1：ARIMA类
forecast2 = actual + np.random.normal(0, 5, n)   # 方法2：指数平滑类
forecast3 = actual + np.random.normal(0, 4, n)   # 方法3：回归类
# 加入系统偏差
forecast1 += 2
forecast2 -= 1
forecast3 += 0.5

forecasts = np.column_stack([forecast1, forecast2, forecast3])

# 组合预测
cf = CombinedForecaster(forecasts, actual)

# 等权组合
cf.equal_weight()
print("=== 等权组合 ===")
print(f"权重: {cf.weights}")
print(cf.evaluate())

# 方差倒数法
cf.variance_inverse()
print("\n=== 方差倒数法 ===")
print(f"权重: {cf.weights}")
print(cf.evaluate())

# 最优化组合
cf.optimal_weights(method='OLS')
print("\n=== 最优化组合（OLS）===")
print(f"权重: {cf.weights}")
print(cf.evaluate())

# 自适应组合
cf.adaptive_weights(window=15)
print("\n=== 自适应组合 ===")
print(f"最终权重: {cf.weights}")
print(cf.evaluate())

cf.visualize()

    """比较各方法的预测误差"""
    results = []
    for name, pred in forecasts_dict.items():
        errors = actual - pred
        results.append({
            '方法': name,
            'MAE': np.mean(np.abs(errors)),
            'RMSE': np.sqrt(np.mean(errors**2)),
            'MAPE': np.mean(np.abs(errors / actual)) * 100
        })
    
    return pd.DataFrame(results).sort_values('RMSE')
```

## 八、实际案例：GDP增长预测

### 8.1 问题描述

使用多种方法预测某省GDP增长率，然后进行组合预测。

### 8.2 建模过程

```python
import numpy as np

# 模拟GDP增长率数据
np.random.seed(123)
years = np.arange(2010, 2024)
gdp_growth = np.array([10.6, 9.5, 8.0, 7.8, 7.3, 7.0, 6.8, 6.9, 6.7, 6.0, 2.3, 8.1, 3.0, 5.2])

# 各单一方法的预测（基于历史数据的不同模型）
# 方法1：ARIMA预测
pred_arima = gdp_growth + np.random.normal(0, 0.3, len(gdp_growth))
pred_arima[-1] = 5.0  # 最新预测

# 方法2：指数平滑预测
pred_ets = gdp_growth + np.random.normal(0, 0.4, len(gdp_growth))
pred_ets[-1] = 4.8

# 方法3：回归预测
pred_reg = gdp_growth + np.random.normal(0, 0.35, len(gdp_growth))
pred_reg[-1] = 5.3

# 方法4：灰色预测
pred_grey = gdp_growth + np.random.normal(0, 0.45, len(gdp_growth))
pred_grey[-1] = 5.1

# 使用前12个数据确定权重，最后2个数据验证
train_n = 12
forecasts_train = np.column_stack([
    pred_arima[:train_n], 
    pred_ets[:train_n], 
    pred_reg[:train_n],
    pred_grey[:train_n]
])
actual_train = gdp_growth[:train_n]

# 确定权重
cf = CombinedForecaster(forecasts_train, actual_train)
cf.optimal_weights()
weights = cf.weights

# 预测
pred_combined = (pred_arima[-1] * weights[0] + pred_ets[-1] * weights[1] + 
                 pred_reg[-1] * weights[2] * weights[2] + pred_grey[-1] * weights[3])

print("=== 组合预测结果 ===")
print(f"ARIMA预测: {pred_arima[-1]:.2f}%")
print(f"指数平滑预测: {pred_ets[-1]:.2f}%")
print(f"回归预测: {pred_reg[-1]:.2f}%")
print(f"灰色预测: {pred_grey[-1]:.2f}%")
print(f"组合权重: {weights}")
print(f"组合预测: {pred_combined:.2f}%")
```

## 九、关键要点总结

1. **组合预测优于单一预测**：除非预测方法完全相关
2. **等权组合**是最简单但往往不差的方法
3. **方差倒数法**自动给精度高的方法更大权重
4. **最优化组合**通过最小化误差确定最优权重
5. **自适应组合**可以跟踪各方法性能的动态变化
6. **贝叶斯模型平均**提供了概率框架下的模型组合
7. **权重约束**：通常要求权重非负且和为1
8. **过拟合风险**：组合权重可能过拟合历史数据
9. **实践中**：建议使用交叉验证评估组合效果
10. **组合预测的本质**：通过分散化降低预测风险
