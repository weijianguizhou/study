# 灰色预测模型

## 一、灰色系统理论概述

### 1.1 基本概念

灰色系统理论由我国学者邓聚龙教授于1982年创立，是一种研究"少数据、不确定"问题的方法论。灰色系统介于白色系统（信息完全明确）和黑色系统（信息完全未知）之间，系统内部特征部分已知、部分未知。

灰色预测的核心思想：**对原始数据进行生成处理，寻找系统变动规律，生成有较强规律性的数据序列，然后建立相应的微分方程模型，从而预测事物未来的发展趋势。**

### 1.2 适用条件

灰色预测模型适用于以下场景：

- **数据量少**：通常只需要4个以上数据即可建模
- **数据无明显规律**：不需要数据服从特定的概率分布
- **短期预测**：适合近中期预测，远期预测精度下降
- **单调变化序列**：数据呈递增或递减趋势时效果最佳

### 1.3 灰色预测的分类

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| GM(1,1) | 一阶一元灰色模型 | 单序列预测 |
| GM(1,N) | 一阶N元灰色模型 | 多变量关联预测 |
| GM(0,N) | 零阶N元灰色模型 | 静态分析 |
| DGM(1,1) | 离散灰色模型 | 修正的GM(1,1) |
| NGM(1,1) | 非齐次灰色模型 | 非齐次指数增长 |

## 二、GM(1,1) 模型原理

### 2.1 原始数据序列

设原始非负数据序列为：

$$X^{(0)} = \{x^{(0)}(1), x^{(0)}(2), \ldots, x^{(0)}(n)\}$$

其中 $x^{(0)}(k) \geq 0, \quad k = 1, 2, \ldots, n$。

### 2.2 一次累加生成（AGO）

对原始序列做一次累加生成（Accumulated Generating Operation）：

$$x^{(1)}(k) = \sum_{i=1}^{k} x^{(0)}(i), \quad k = 1, 2, \ldots, n$$

生成的新序列为：

$$X^{(1)} = \{x^{(1)}(1), x^{(1)}(2), \ldots, x^{(1)}(n)\}$$

**累加生成的目的**：将杂乱无章的原始数据转化为具有近似指数增长规律的序列，从而可以用微分方程来拟合。

### 2.3 紧邻均值生成序列

构造 $X^{(1)}$ 的紧邻均值生成序列：

$$z^{(1)}(k) = \frac{1}{2}\left[x^{(1)}(k) + x^{(1)}(k-1)\right], \quad k = 2, 3, \ldots, n$$

### 2.4 GM(1,1) 微分方程

GM(1,1) 的白化微分方程（连续模型）为：

$$\frac{dx^{(1)}}{dt} + ax^{(1)} = b$$

其中：
- $a$ 为**发展系数**（development coefficient），反映 $X^{(1)}$ 的发展趋势
- $b$ 为**灰色作用量**（grey action quantity），反映数据变化的关系

### 2.5 参数估计（最小二乘法）

将微分方程离散化，得到：

$$x^{(0)}(k) + az^{(1)}(k) = b, \quad k = 2, 3, \ldots, n$$

写成矩阵形式 $Y = B\hat{a}$：

$$\begin{pmatrix} x^{(0)}(2) \\ x^{(0)}(3) \\ \vdots \\ x^{(0)}(n) \end{pmatrix} = \begin{pmatrix} -z^{(1)}(2) & 1 \\ -z^{(1)}(3) & 1 \\ \vdots & \vdots \\ -z^{(1)}(n) & 1 \end{pmatrix} \begin{pmatrix} a \\ b \end{pmatrix}$$

利用最小二乘法求解参数：

$$\hat{a} = \begin{pmatrix} a \\ b \end{pmatrix} = (B^T B)^{-1} B^T Y$$

### 2.6 时间响应函数

白化微分方程的解（时间响应函数）为：

$$\hat{x}^{(1)}(k+1) = \left[x^{(1)}(1) - \frac{b}{a}\right] e^{-ak} + \frac{b}{a}, \quad k = 0, 1, 2, \ldots$$

### 2.7 还原预测值

通过累减还原（IAGO）得到原始序列的预测值：

$$\hat{x}^{(0)}(k+1) = \hat{x}^{(1)}(k+1) - \hat{x}^{(1)}(k) = (1 - e^a)\left[x^{(1)}(1) - \frac{b}{a}\right]e^{-ak}$$

特别地：

$$\hat{x}^{(0)}(1) = x^{(0)}(1)$$

## 三、模型检验

### 3.1 残差检验

计算残差和相对误差：

$$\varepsilon(k) = x^{(0)}(k) - \hat{x}^{(0)}(k)$$

$$\Delta_k = \frac{|\varepsilon(k)|}{x^{(0)}(k)} \times 100\%$$

模型精度等级：

| 精度等级 | 平均相对误差 | 说明 |
|----------|-------------|------|
| 一级（好） | $< 1\%$ | 预测精度很高 |
| 二级（合格） | $1\% \sim 5\%$ | 预测精度较高 |
| 三级（勉强） | $5\% \sim 10\%$ | 预测精度一般 |
| 四级（不合格） | $\geq 10\%$ | 预测精度较差 |

### 3.2 关联度检验

计算预测曲线与原始曲线的关联度。设分辨系数 $\rho \in (0,1)$，通常取 $\rho = 0.5$：

$$\xi(k) = \frac{\min_k|\varepsilon(k)| + \rho \max_k|\varepsilon(k)|}{|\varepsilon(k)| + \rho \max_k|\varepsilon(k)|}$$

$$r = \frac{1}{n-1}\sum_{k=2}^{n}\xi(k)$$

一般要求 $r > 0.6$。

### 3.3 后验差检验

计算后验差比值 $C$ 和小误差概率 $P$：

$$\bar{x}^{(0)} = \frac{1}{n}\sum_{k=1}^{n}x^{(0)}(k)$$

$$S_1^2 = \frac{1}{n}\sum_{k=1}^{n}\left[x^{(0)}(k) - \bar{x}^{(0)}\right]^2$$

$$\bar{\varepsilon} = \frac{1}{n-1}\sum_{k=2}^{n}\varepsilon(k)$$

$$S_2^2 = \frac{1}{n-1}\sum_{k=2}^{n}\left[\varepsilon(k) - \bar{\varepsilon}\right]^2$$

$$C = \frac{S_2}{S_1}, \quad P = P\left\{|\varepsilon(k) - \bar{\varepsilon}| < 0.6745 S_1\right\}$$

| 精度等级 | $C$ | $P$ |
|----------|-----|-----|
| 一级（好） | $< 0.35$ | $> 0.95$ |
| 二级（合格） | $< 0.50$ | $> 0.80$ |
| 三级（勉强） | $< 0.65$ | $> 0.70$ |
| 四级（不合格） | $\geq 0.65$ | $\leq 0.70$ |

## 四、模型适用范围与发展系数

### 4.1 发展系数 $a$ 的含义

| $|a|$ 范围 | 预测精度 | 建议 |
|-----------|----------|------|
| $\leq 0.3$ | 适合中长期预测 | 可直接使用 |
| $0.3 < |a| \leq 0.5$ | 适合短期预测 | 需谨慎使用 |
| $0.5 < |a| \leq 0.8$ | 短期预测精度较低 | 修正后使用 |
| $0.8 < |a| \leq 1.0$ | 预测精度差 | 建议残差修正 |
| $> 1.0$ | 不适合预测 | 改用其他方法 |

### 4.2 新陈代谢模型

当数据波动较大时，可采用新陈代谢GM(1,1)模型：

1. 用前 $m$ 个数据建立GM(1,1)模型，预测第 $m+1$ 个值
2. 去掉最早的第1个数据，加入新预测的第 $m+1$ 个数据
3. 重新建立GM(1,1)模型，预测第 $m+2$ 个值
4. 重复上述过程

## 五、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

class GM11:
    """GM(1,1) 灰色预测模型"""
    
    def __init__(self, data):
        """
        参数:
            data: 原始数据序列（列表或numpy数组）
        """
        self.raw_data = np.array(data, dtype=float)
        self.n = len(data)
        self.a = None  # 发展系数
        self.b = None  # 灰色作用量
        
    def _ago(self):
        """一次累加生成"""
        return np.cumsum(self.raw_data)
    
    def _mean_sequence(self, x1):
        """紧邻均值生成"""
        z = 0.5 * (x1[1:] + x1[:-1])
        return z
    
    def fit(self):
        """拟合模型，估计参数"""
        x1 = self._ago()
        z = self._mean_sequence(x1)
        
        # 构造矩阵B和向量Y
        B = np.column_stack([-z, np.ones(self.n - 1)])
        Y = self.raw_data[1:]
        
        # 最小二乘求解
        self.a, self.b = np.linalg.inv(B.T @ B) @ B.T @ Y
        return self
    
    def predict(self, steps=1):
        """
        预测未来值
        参数:
            steps: 预测步数
        返回:
            预测序列（包含拟合值）
        """
        x1 = self._ago()
        result = []
        
        for k in range(self.n - 1 + steps):
            val = (self.raw_data[0] - self.b / self.a) * np.exp(-self.a * k) + self.b / self.a
            result.append(val)
        
        # 累减还原
        predict_x0 = [result[0]]
        for i in range(1, len(result)):
            predict_x0.append(result[i] - result[i-1])
        
        return np.array(predict_x0)
    
    def accuracy(self):
        """计算模型精度"""
        predict = self.predict(steps=0)
        residuals = self.raw_data - predict
        relative_errors = np.abs(residuals) / self.raw_data * 100
        return {
            'mean_absolute_error': np.mean(np.abs(residuals)),
            'mean_relative_error': np.mean(relative_errors[1:]),
            'max_relative_error': np.max(relative_errors[1:]),
            'relative_errors': relative_errors
        }
    
    def summary(self):
        """输出模型摘要"""
        print("=" * 50)
        print("GM(1,1) 灰色预测模型")
        print("=" * 50)
        print(f"发展系数 a = {self.a:.6f}")
        print(f"灰色作用量 b = {self.b:.6f}")
        acc = self.accuracy()
        print(f"平均相对误差: {acc['mean_relative_error']:.2f}%")
        print(f"最大相对误差: {acc['max_relative_error']:.2f}%")
        print("=" * 50)


# ============ 示例1：GDP预测 ============
# 某地区GDP数据（亿元）
gdp_data = [1043.5, 1198.3, 1368.6, 1593.6, 1847.5, 2150.7, 2500.1]

model = GM11(gdp_data)
model.fit()
model.summary()

# 预测未来3年
predict_values = model.predict(steps=3)
print("\n拟合与预测结果:")
for i, val in enumerate(predict_values):
    if i < len(gdp_data):
        print(f"  第{i+1}年: 实际={gdp_data[i]:.1f}, 拟合={val:.1f}")
    else:
        print(f"  第{i+1}年: 预测={val:.1f}")

# 绘图
plt.figure(figsize=(10, 6))
plt.plot(range(1, len(gdp_data)+1), gdp_data, 'bo-', label='实际值')
plt.plot(range(1, len(predict_values)+1), predict_values, 'r*--', label='拟合/预测值')
plt.axvline(x=len(gdp_data), color='gray', linestyle=':', alpha=0.7)
plt.xlabel('年份序号')
plt.ylabel('GDP (亿元)')
plt.title('GM(1,1) 灰色预测模型')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()


# ============ 示例2：新陈代谢模型 ============
class MetabolismGM11:
    """新陈代谢GM(1,1)模型"""
    
    def __init__(self, data, window=5):
        """
        参数:
            data: 完整数据序列
            window: 滑动窗口大小
        """
        self.data = np.array(data, dtype=float)
        self.window = window
        self.predictions = []
    
    def predict(self):
        """逐步预测"""
        n = len(self.data)
        for i in range(self.window, n):
            window_data = self.data[i-self.window:i]
            gm = GM11(window_data)
            gm.fit()
            pred = gm.predict(steps=1)[-1]
            self.predictions.append(pred)
        return self.predictions
    
    def full_predict(self, steps=1):
        """预测未来值"""
        # 使用最后window个数据建立模型
        window_data = self.data[-self.window:]
        gm = GM11(window_data)
        gm.fit()
        return gm.predict(steps=steps)

# 使用示例
extended_data = [1043.5, 1198.3, 1368.6, 1593.6, 1847.5, 2150.7, 2500.1, 2863.2, 3210.5]
met_model = MetabolismGM11(extended_data, window=5)
met_model.predict()
print(f"\n新陈代谢模型预测: {met_model.full_predict(steps=2)}")
```

## 六、实际案例：某市人口预测

### 6.1 问题描述

某市近6年的人口数据如下（单位：万人），预测未来3年的人口。

| 年份 | 2015 | 2016 | 2017 | 2018 | 2019 | 2020 |
|------|------|------|------|------|------|------|
| 人口 | 523.7 | 531.2 | 538.9 | 547.1 | 555.8 | 564.3 |

### 6.2 建模步骤

```python
import numpy as np

# 原始数据
years = [2015, 2016, 2017, 2018, 2019, 2020]
population = [523.7, 531.2, 538.9, 547.1, 555.8, 564.3]

# Step 1: 建立GM(1,1)模型
model = GM11(population)
model.fit()

# Step 2: 模型检验
acc = model.accuracy()
print(f"平均相对误差: {acc['mean_relative_error']:.2f}%")

# Step 3: 预测
predict_all = model.predict(steps=3)
print("\n人口预测结果:")
for i, p in enumerate(predict_all):
    year = 2015 + i
    if i < len(population):
        print(f"{year}: 实际={population[i]}, 拟合={p:.2f}, "
              f"误差={abs(population[i]-p)/population[i]*100:.2f}%")
    else:
        print(f"{year}: 预测={p:.2f}")

# Step 4: 输出模型参数
print(f"\n模型方程: dx/dt + ({model.a:.4f})x = {model.b:.4f}")
print(f"时间响应函数: x̂(k+1) = {(population[0] - model.b/model.a):.2f} * "
      f"exp({-model.a:.4f}*k) + {model.b/model.a:.2f}")
```

## 七、GM(1,1) 的改进方法

### 7.1 初始值改进

传统模型以 $\hat{x}^{(1)}(1) = x^{(0)}(1)$ 作为初始条件，改进方法选取 $\hat{x}^{(1)}(1) = c$（常数），通过最小化拟合误差确定 $c$：

$$\min_c \sum_{k=1}^{n}\left[\hat{x}^{(1)}(k) - x^{(1)}(k)\right]^2$$

### 7.2 背景值改进

将传统的紧邻均值背景值：

$$z^{(1)}(k) = \frac{1}{2}x^{(1)}(k) + \frac{1}{2}x^{(1)}(k-1)$$

替换为加权背景值：

$$z^{(1)}(k) = \lambda x^{(1)}(k) + (1-\lambda)x^{(1)}(k-1), \quad \lambda \in [0,1]$$

通过优化 $\lambda$ 来提高模型精度。

### 7.3 残差修正模型

当GM(1,1)模型精度不高时，可用残差序列建立新的GM(1,1)模型进行修正：

1. 计算残差序列 $\varepsilon^{(0)}(k) = x^{(0)}(k) - \hat{x}^{(0)}(k)$
2. 取残差绝对值序列，建立GM(1,1)模型
3. 将残差预测值加到原预测值上

### 7.4 灰色Verhulst模型

对于非单调变化的序列，可使用灰色Verhulst模型：

$$\frac{dx^{(1)}}{dt} + ax^{(1)} = b(x^{(1)})^2$$

其解为：

$$\hat{x}^{(1)}(k+1) = \frac{ax^{(1)}(1)}{bx^{(1)}(1) + (a - bx^{(1)}(1))e^{ak}}$$

## 八、关键要点总结

1. **灰色预测的核心**：通过累加生成将无规律数据转化为近似指数序列，用微分方程拟合
2. **GM(1,1)是最基本的灰色预测模型**：一阶微分方程、一个变量
3. **发展系数 $a$ 决定模型适用性**：$|a| \leq 0.3$ 时适合中长期预测
4. **模型检验三步走**：残差检验、关联度检验、后验差检验
5. **新陈代谢模型**可以有效提高预测精度
6. **灰色预测的优势**：数据需求少、计算简单、不需要概率分布假设
7. **灰色预测的局限**：适合单调序列，对波动大的数据效果差
8. **改进方向**：初始值优化、背景值优化、残差修正、与其他方法组合
