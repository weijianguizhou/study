# 模糊预测模型

## 一、模糊集合理论基础

### 1.1 模糊集合的定义

经典集合（Crisp Set）中，一个元素要么属于集合（隶属度为1），要么不属于（隶属度为0）。而**模糊集合**允许部分隶属。

**定义**：论域 $U$ 上的模糊集合 $\tilde{A}$ 由隶属函数 $\mu_{\tilde{A}}: U \rightarrow [0, 1]$ 完全确定。

$$\tilde{A} = \{(u, \mu_{\tilde{A}}(u)) \mid u \in U\}$$

### 1.2 常用隶属函数

**三角形隶属函数**：

$$\mu(x; a, b, c) = \begin{cases} 0, & x \leq a \\ \frac{x-a}{b-a}, & a < x \leq b \\ \frac{c-x}{c-b}, & b < x < c \\ 0, & x \geq c \end{cases}$$

**梯形隶属函数**：

$$\mu(x; a, b, c, d) = \begin{cases} 0, & x \leq a \\ \frac{x-a}{b-a}, & a < x \leq b \\ 1, & b < x \leq c \\ \frac{d-x}{d-c}, & c < x < d \\ 0, & x \geq d \end{cases}$$

**高斯隶属函数**：

$$\mu(x; c, \sigma) = \exp\left(-\frac{(x-c)^2}{2\sigma^2}\right)$$

**钟形隶属函数**：

$$\mu(x; a, b, c) = \frac{1}{1 + \left|\frac{x-c}{a}\right|^{2b}}$$

### 1.3 模糊集合的运算

设 $\tilde{A}$ 和 $\tilde{B}$ 为论域 $U$ 上的两个模糊集合：

- **并集**：$\mu_{\tilde{A} \cup \tilde{B}}(u) = \max(\mu_{\tilde{A}}(u), \mu_{\tilde{B}}(u))$
- **交集**：$\mu_{\tilde{A} \cap \tilde{B}}(u) = \min(\mu_{\tilde{A}}(u), \mu_{\tilde{B}}(u))$
- **补集**：$\mu_{\tilde{A}^c}(u) = 1 - \mu_{\tilde{A}}(u)$

### 1.4 $\alpha$-截集

模糊集合 $\tilde{A}$ 的 $\alpha$-截集为经典集合：

$$A_\alpha = \{u \in U \mid \mu_{\tilde{A}}(u) \geq \alpha\}, \quad \alpha \in [0, 1]$$

## 三、模糊时间序列预测

### 3.1 基本概念

**模糊时间序列**由Song和Chisholm于1993年提出，处理语言值时间序列。

**定义**：设 $Y(t)$ 为论域 $U$ 上的时间序列，$F(t)$ 为 $Y(t)$ 上的模糊集合，则 $F(t)$ 称为模糊时间序列。

### 3.2 模糊关系模型

**步骤1：确定论域和划分**

设论域 $U = [a, b]$，将其划分为 $n$ 个区间：

$$U = [u_1, u_2] \cup [u_2, u_3] \cup \cdots \cup [u_n, u_{n+1}]$$

**步骤2：定义模糊集合**

在每个区间上定义模糊集合 $A_i$（通常用三角形或梯形隶属函数）。

**步骤3：模糊化**

将精确数据转化为模糊集合：

$$F(t) = A_i \quad \text{if} \quad Y(t) \in [u_i, u_{i+1}]$$

**步骤4：建立模糊关系**

计算模糊关系矩阵 $R$：

$$R = \bigcup_{t=1}^{n-1}(F(t) \times F(t+1))$$

其中 $\times$ 为笛卡尔积。

**步骤5：预测**

$$F(t+1) = F(t) \circ R$$

其中 $\circ$ 为合成运算（通常取max-min合成）。

### 3.3 改进的高阶模糊时间序列

**二阶模型**：

$$F(t+1) = F(t-1) \circ R_1 \cup F(t) \circ R_2$$

其中 $R_1$ 和 $R_2$ 分别为一阶和二阶模糊关系矩阵。

## 四、模糊回归预测

### 4.1 模糊线性回归模型

$$\tilde{Y} = \tilde{A}_0 + \tilde{A}_1 X_1 + \cdots + \tilde{A}_p X_p$$

其中 $\tilde{A}_i$ 为模糊数（通常为三角模糊数）。

### 4.2 三角模糊数

三角模糊数 $\tilde{A} = (a, b, c)$ 的隶属函数：

$$\mu_{\tilde{A}}(x) = \begin{cases} \frac{x-a}{b-a}, & a \leq x \leq b \\ \frac{c-x}{c-b}, & b \leq x \leq c \\ 0, & \text{其他} \end{cases}$$

### 4.3 模糊最小二乘法

对于 $n$ 个数据点 $(X_i, Y_i)$，最小化：

$$J = \sum_{i=1}^{n}|\mu_{\tilde{Y}_i}(Y_i)|$$

### 4.4 模糊参数估计

使用$\alpha$-截集方法：

对于每个 $\alpha \in [0, 1]$，模糊回归变为区间回归：

$$Y_i(\alpha) = [y_{iL}(\alpha), y_{iR}(\alpha)]$$

$$y_{iL}(\alpha) = \sum_{j=0}^{p}[a_{jL}(\alpha) + c_{jL}(\alpha)|X_{ij}|]$$

$$y_{iR}(\alpha) = \sum_{j=0}^{p}[a_{jR}(\alpha) + c_{jR}(\alpha)|X_{ij}|]$$

## 五、模糊推理系统

### 5.1 模糊推理系统的组成

```
输入 → 模糊化 → 规则库+推理机 → 去模糊化 → 输出
```

### 5.2 Mamdani模糊系统

**规则形式**：

$$R_i: \text{IF } x_1 \text{ is } A_{i1} \text{ AND } x_2 \text{ is } A_{i2} \text{ THEN } y \text{ is } B_i$$

**推理过程**：

1. **模糊化**：计算输入对各模糊集合的隶属度
2. **规则激活度**：$\mu_i = \min(\mu_{A_{i1}}(x_1), \mu_{A_{i2}}(x_2))$
3. **规则输出**：$\mu_{B_i'}(y) = \min(\mu_i, \mu_{B_i}(y))$
4. **合成**：$\mu_B(y) = \max_i(\mu_{B_i'}(y))$

### 5.3 TSK模糊系统（Takagi-Sugeno-Kang）

**规则形式**：

$$R_i: \text{IF } x_1 \text{ is } A_{i1} \text{ AND } x_2 \text{ is } A_{i2} \text{ THEN } y = f_i(\mathbf{x})$$

其中 $f_i(\mathbf{x})$ 为线性函数：

$$f_i(\mathbf{x}) = a_{i0} + a_{i1}x_1 + \cdots + a_{ip}x_p$$

**输出计算**：

$$\hat{y} = \frac{\sum_{i=1}^{K}\mu_i \cdot f_i(\mathbf{x})}{\sum_{i=1}^{K}\mu_i}$$

### 5.4 去模糊化方法

**重心法（Center of Gravity）**：

$$\hat{y} = \frac{\int y \cdot \mu_B(y)dy}{\int \mu_B(y)dy}$$

**面积中心法**：

$$\hat{y} = \frac{\sum_{i} y_i \cdot \mu_B(y_i)}{\sum_{i}\mu_B(y_i)}$$

**最大隶属度法**：

$$\hat{y} = \arg\max_y \mu_B(y)$$

## 六、自适应神经模糊推理系统（ANFIS）

### 6.1 ANFIS结构

ANFIS结合了模糊推理系统和神经网络：

**第1层（模糊化层）**：

$$O_i^{(1)} = \mu_{A_i}(x)$$

**第2层（规则层）**：

$$O_i^{(2)} = w_i = \prod_j \mu_{A_{ij}}(x_j)$$

**第3层（归一化层）**：

$$O_i^{(3)} = \bar{w}_i = \frac{w_i}{\sum_j w_j}$$

**第4层（去模糊化层）**：

$$O_i^{(4)} = \bar{w}_i f_i = \bar{w}_i(p_{i0} + p_{i1}x_1 + \cdots + p_{ip}x_p)$$

**第5层（输出层）**：

$$O^{(5)} = \sum_i \bar{w}_i f_i$$

### 6.2 混合学习算法

- **前向传播**：固定前提参数，用最小二乘法估计结论参数
- **反向传播**：固定结论参数，用梯度下降更新前提参数

```python
import numpy as np
import matplotlib.pyplot as plt

class FuzzyNumber:
    """三角模糊数"""
    
    def __init__(self, a, b, c):
        """(a, b, c): 左端点、中心、右端点"""
        self.a = a
        self.b = b
        self.c = c
    
    def membership(self, x):
        """计算隶属度"""
        if isinstance(x, np.ndarray):
            mu = np.zeros_like(x, dtype=float)
            mask1 = (x >= self.a) & (x <= self.b)
            mask2 = (x > self.b) & (x <= self.c)
            mu[mask1] = (x[mask1] - self.a) / (self.b - self.a + 1e-10)
            mu[mask2] = (self.c - x[mask2]) / (self.c - self.b + 1e-10)
            return mu
        else:
            if self.a <= x <= self.b:
                return (x - self.a) / (self.b - self.a + 1e-10)
            elif self.b < x <= self.c:
                return (self.c - x) / (self.c - self.b + 1e-10)
            else:
                return 0.0
    
    def alpha_cut(self, alpha):
        """alpha截集"""
        left = self.a + alpha * (self.b - self.a)
        right = self.c - alpha * (self.c - self.b)
        return (left, right)
    
    def __add__(self, other):
        return FuzzyNumber(self.a + other.a, self.b + other.b, self.c + other.c)
    
    def __mul__(self, scalar):
        if scalar >= 0:
            return FuzzyNumber(self.a * scalar, self.b * scalar, self.c * scalar)
        else:
            return FuzzyNumber(self.c * scalar, self.b * scalar, self.a * scalar)
    
    def __repr__(self):
        return f"FuzzyNumber({self.a:.2f}, {self.b:.2f}, {self.c:.2f})"
    
    def plot(self, ax=None, label=None):
        """绘制隶属函数"""
        if ax is None:
            fig, ax = plt.subplots(1, 1, figsize=(8, 4))
        
        x = np.linspace(self.a - 0.5*(self.c-self.a), 
                        self.c + 0.5*(self.c-self.a), 200)
        y = self.membership(x)
        
        ax.plot(x, y, 'b-', linewidth=2, label=label)
        ax.fill_between(x, y, alpha=0.3)
        ax.set_ylim(-0.05, 1.1)
        ax.set_xlabel('x')
        ax.set_ylabel('隶属度')
        if label:
            ax.legend()
        
        return ax


class FuzzyTimeSeries:
    """模糊时间序列预测"""
    
    def __init__(self, order=1):
        self.order = order
        self.fuzzy_sets = {}
        self.relations = {}
        self.universe_min = None
        self.universe_max = None
    
    def _define_universe(self, data, n_sets=7):
        """定义论域和模糊集合"""
        self.universe_min = min(data) - 0.1 * (max(data) - min(data))
        self.universe_max = max(data) + 0.1 * (max(data) - min(data))
        
        step = (self.universe_max - self.universe_min) / n_sets
        
        self.fuzzy_sets = {}
        for i in range(n_sets):
            left = self.universe_min + i * step
            center = left + step / 2
            right = left + step
            self.fuzzy_sets[i] = FuzzyNumber(left, center, right)
        
        return self.fuzzy_sets
    
    def _fuzzify(self, data):
        """数据模糊化"""
        fuzzified = []
        for x in data:
            max_mu = -1
            best_set = 0
            for idx, fs in self.fuzzy_sets.items():
                mu = fs.membership(x)
                if mu > max_mu:
                    max_mu = mu
                    best_set = idx
            fuzzified.append(best_set)
        return fuzzified
    
    def fit(self, data):
        """建立模糊时间序列模型"""
        data = np.array(data)
        
        # 定义模糊集合
        n_sets = max(5, int(np.sqrt(len(data))))
        self._define_universe(data, n_sets)
        
        # 模糊化
        fuzzy_data = self._fuzzify(data)
        
        # 建立模糊关系
        if self.order == 1:
            self._build_first_order_relations(fuzzy_data)
        else:
            self._build_higher_order_relations(fuzzy_data)
        
        return self
    
    def _build_first_order_relations(self, fuzzy_data):
        """建立一阶模糊关系"""
        n_sets = len(self.fuzzy_sets)
        self.relations = np.zeros((n_sets, n_sets))
        
        for t in range(len(fuzzy_data) - 1):
            i = fuzzy_data[t]
            j = fuzzy_data[t + 1]
            self.relations[i][j] = max(self.relations[i][j], 1)
    
    def _build_higher_order_relations(self, fuzzy_data):
        """建立高阶模糊关系"""
        n_sets = len(self.fuzzy_sets)
        self.relations = {}
        
        for order in range(1, self.order + 1):
            R = np.zeros((n_sets, n_sets))
            for t in range(len(fuzzy_data) - order):
                i = fuzzy_data[t]
                j = fuzzy_data[t + order]
                R[i][j] = max(R[i][j], 1)
            self.relations[order] = R
    
    def predict(self, last_values, steps=1):
        """预测"""
        predictions = []
        recent_data = list(last_values)
        
        for _ in range(steps):
            # 模糊化最近的值
            fuzzy_recent = self._fuzzify(recent_data[-self.order:])
            
            n_sets = len(self.fuzzy_sets)
            result_membership = np.zeros(n_sets)
            
            if self.order == 1:
                # 一阶预测
                current_fuzzy = fuzzy_recent[-1]
                result_membership = np.maximum(result_membership, 
                                              self.relations[current_fuzzy])
            else:
                # 高阶预测
                for o in range(1, self.order + 1):
                    if o <= len(fuzzy_recent):
                        current_fuzzy = fuzzy_recent[-o]
                        result_membership = np.maximum(
                            result_membership, 
                            self.relations[o][current_fuzzy]
                        )
            
            # 去模糊化（重心法）
            if result_membership.sum() > 0:
                center_sum = 0
                weight_sum = 0
                for idx in range(n_sets):
                    if result_membership[idx] > 0:
                        center_sum += self.fuzzy_sets[idx].b * result_membership[idx]
                        weight_sum += result_membership[idx]
                pred = center_sum / weight_sum
            else:
                pred = recent_data[-1]
            
            predictions.append(pred)
            recent_data.append(pred)
        
        return predictions


class FuzzyLinearRegression:
    """模糊线性回归"""
    
    def __init__(self):
        self.coefficients = []  # [(a, b, c), ...] 三角模糊数
        self.h = 1.0  # 模糊度参数
    
    def fit(self, X, y, h=1.0):
        """
        模糊线性回归
        参数:
            X: 自变量矩阵
            y: 因变量（精确值或模糊数）
            h: 模糊度参数（控制输出模糊度）
        """
        self.h = h
        n, p = X.shape
        
        # 使用alpha截集方法
        # 对于alpha=0和alpha=1
        # 每个系数为三角模糊数 (a_i, c_i_i, d_i)
        
        # 简化实现：用最小二乘法拟合中心值
        from sklearn.linear_model import LinearRegression
        lr = LinearRegression()
        lr.fit(X, y)
        
        # 估计模糊度
        y_pred = lr.predict(X)
        residuals = np.abs(y - y_pred)
        
        self.coefficients = []
        self.coefficients.append(FuzzyNumber(
            lr.intercept_ - h * np.std(residuals),
            lr.intercept_,
            lr.intercept_ + h * np.std(residuals)
        ))
        
        for i in range(p):
            self.coefficients.append(FuzzyNumber(
                lr.coef_[i] - h * np.std(residuals) * 0.5,
                lr.coef_[i],
                lr.coef_[i] + h * np.std(residuals) * 0.5
            ))
        
        return self
    
    def predict(self, X, alpha=0.5):
        """预测（返回模糊数）"""
        predictions = []
        
        for x in X:
            # 中心值
            center = self.coefficients[0].b
            for i, c in enumerate(x):
                center += self.coefficients[i + 1].b * c
            
            # alpha截集的左右端点
            left_sum = self.coefficients[0].alpha_cut(alpha)[0]
            right_sum = self.coefficients[0].alpha_cut(alpha)[1]
            
            for i, c in enumerate(x):
                cl, cr = self.coefficients[i + 1].alpha_cut(alpha)
                if c >= 0:
                    left_sum += cl * c
                    right_sum += cr * c
                else:
                    left_sum += cr * c
                    right_sum += cl * c
            
            predictions.append(FuzzyNumber(left_sum, center, right_sum))
        
        return predictions

# ============ 示例3：简单模糊推理系统 ============
class SimpleFIS:
    """简单模糊推理系统（TSK型）"""
    
    def __init__(self):
        self.rules = []
    
    def add_rule(self, antecedent_func, consequent_params):
        """添加规则"""
        self.rules.append({
            'antecedent': antecedent_func,
            'consequent': consequent_params
        })
    
    def predict(self, x):
        """推理预测"""
        weights = []
        outputs = []
        
        for rule in self.rules:
            w = rule['antecedent'](x)
            params = rule['consequent']
            y = params[0] + params[1] * x  # 一阶TSK
            weights.append(w)
            outputs.append(y)
        
        weights = np.array(weights)
        outputs = np.array(outputs)
        
        if weights.sum() > 0:
            return np.sum(weights * outputs) / np.sum(weights)
        return np.mean(outputs)

# 创建模糊系统
fis = SimpleFIS()

# 定义规则
fis.add_rule(lambda x: max(0, 1 - abs(x - 2)/2), [1, 0.5])    # x接近2
fis.add_rule(lambda x: max(0, 1 - abs(x - 5)/2), [2, 0.3])    # x接近5
fis.add_rule(lambda x: max(0, 1 - abs(x - 8)/2), [3, 0.1])    # x接近8

# 测试
x_test = np.linspace(0, 10, 100)
y_test = [fis.predict(x) for x in x_test]

plt.figure(figsize=(10, 5))
plt.plot(x_test, y_test, 'b-', linewidth=2)
plt.xlabel('x')
plt.ylabel('y')
plt.title('模糊推理系统输出')
plt.grid(True, alpha=0.3)
plt.show()
```

## 八、关键要点总结

1. **模糊集合理论**是处理不确定性和语言信息的数学工具
2. **模糊时间序列**适合处理语言变量和非精确数据
3. **模糊回归**可以同时给出预测值和模糊区间
4. **模糊推理系统**（Mamdani/TSK）可以结合专家知识
5. **ANFIS**结合了模糊系统的可解释性和神经网络的学习能力
6. **去模糊化**是将模糊推理结果转化为精确值的关键步骤
7. **隶属函数的选择**影响预测效果，需要根据问题特点确定
8. **模糊方法的优势**：处理不确定性、可解释性强、可以融合专家知识
9. **模糊方法的局限**：计算复杂、规则库设计困难、缺乏系统化的学习框架
10. **实际应用**：控制、决策、模式识别、预测等
