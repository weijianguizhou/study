# 蒙特卡洛模拟

## 一、蒙特卡洛方法概述

### 1.1 基本思想

蒙特卡洛方法（Monte Carlo Method）是一种基于**随机采样**的数值计算方法。其核心思想是：利用大量随机样本的统计特征来近似求解数学问题。

**名称由来**：以摩纳哥的蒙特卡洛赌场命名，由Metropolis和Ulam在二战期间提出。

### 1.2 基本原理

根据大数定律，样本均值收敛于期望值：

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n}X_i \xrightarrow{a.s.} E(X)$$

根据中心极限定理：

$$\sqrt{n}(\bar{X}_n - \mu) \xrightarrow{d} N(0, \sigma^2)$$

因此，可以用样本均值来近似期望值，并且估计误差为 $O(1/\sqrt{n})$。

### 1.3 适用场景

| 场景 | 说明 |
|------|------|
| 高维积分 | 蒙特卡洛积分不受维度诅咒 |
| 复杂分布采样 | MCMC方法 |
| 风险评估 | VaR、CVaR计算 |
| 期权定价 | Black-Scholes模型的数值验证 |
| 物理模拟 | 粒子输运、统计力学 |
| 优化问题 | 模拟退火、遗传算法 |

## 二、随机数生成

### 2.1 均匀分布随机数

**线性同余法（LCG）**：

$$X_{n+1} = (aX_n + c) \mod m$$

**Mersenne Twister**：Python/NumPy默认的随机数生成器，周期为 $2^{19937}-1$。

### 2.2 常见分布的生成

**逆变换法**：若 $F$ 为累积分布函数，$U \sim \text{Uniform}(0,1)$，则 $X = F^{-1}(U)$ 服从分布 $F$。

- **指数分布**：$X = -\frac{1}{\lambda}\ln(1-U)$
- **均匀分布**：$X = a + (b-a)U$
- **Bernoulli分布**：$X = \mathbb{1}(U < p)$

**Box-Muller变换**：生成标准正态分布

$$Z_1 = \sqrt{-2\ln U_1}\cos(2\pi U_2)$$
$$Z_2 = \sqrt{-2\ln U_1}\sin(2\pi U_2)$$

其中 $U_1, U_2 \sim \text{Uniform}(0,1)$。

**拒绝采样**：从复杂分布采样

1. 选取容易采样的提议分布 $g(x)$
2. 找到常数 $c$ 使得 $f(x) \leq c \cdot g(x)$
3. 从 $g(x)$ 采样 $x$，从 $\text{Uniform}(0, cg(x))$ 采样 $u$
4. 若 $u \leq f(x)$，接受 $x$；否则拒绝

### 2.3 伪随机数的质量检验

- **均匀性检验**：Kolmogorov-Smirnov检验、卡方检验
- **独立性检验**：自相关检验、游程检验
- **有效性检验**：生日间隔检验

## 三、蒙特卡洛积分

### 3.1 基本蒙特卡洛积分

估计积分 $I = \int_a^b f(x)dx$：

$$\hat{I} = (b-a) \cdot \frac{1}{n}\sum_{i=1}^{n}f(X_i), \quad X_i \sim \text{Uniform}(a, b)$$

### 3.2 重要性采样

若 $g(x)$ 为与 $f(x)$ 相似的概率密度函数：

$$I = \int f(x)dx = \int \frac{f(x)}{g(x)} g(x)dx = E_g\left[\frac{f(X)}{g(X)}\right]$$

$$\hat{I} = \frac{1}{n}\sum_{i=1}^{n}\frac{f(X_i)}{g(X_i)}, \quad X_i \sim g$$

### 3.3 方差缩减技术

**对偶变量法**：

$$\hat{I} = \frac{1}{n}\sum_{i=1}^{n}\frac{f(X_i) + f(1-X_i)}{2}$$

当 $f$ 为单调函数时，$f(X)$ 与 $f(1-X)$ 负相关，方差减小。

**控制变量法**：

$$\hat{I} = \bar{f} + \beta(\bar{g} - E[g])$$

其中 $\bar{f}$ 为 $f$ 的样本均值，$g$ 为已知期望的函数，$\beta$ 为回归系数。

**分层采样**：将积分域分层，在每层内独立采样。

## 四、马尔可夫链蒙特卡洛（MCMC）

### 4.1 Metropolis-Hastings算法

从复杂分布 $\pi(x)$ 采样：

1. 初始化 $x_0$
2. 对于 $t = 0, 1, 2, \ldots$
   - 从提议分布 $q(x'|x_t)$ 生成候选状态 $x'$
   - 计算接受概率：
$$\alpha = \min\left\{1, \frac{\pi(x')q(x_t|x')}{\pi(x_t)q(x'|x_t)}\right\}$$
   - 以概率 $\alpha$ 接受 $x'$，令 $x_{t+1} = x'$；否则 $x_{t+1} = x_t$

**收敛性**：当 $t \to \infty$ 时，样本分布收敛于目标分布 $\pi(x)$。

### 4.2 Gibbs采样

Gibbs采样是Metropolis-Hastings的特殊情况，适用于联合分布已知但边缘分布易求的情况。

对于 $d$ 维变量 $\mathbf{x} = (x_1, x_2, \ldots, x_d)$：

1. 初始化 $\mathbf{x}^{(0)}$
2. 对于 $t = 0, 1, 2, \ldots$
   - $x_1^{(t+1)} \sim \pi(x_1 | x_2^{(t)}, x_3^{(t)}, \ldots, x_d^{(t)})$
   - $x_2^{(t+1)} \sim \pi(x_2 | x_1^{(t+1)}, x_3^{(t)}, \ldots, x_d^{(t)})$
   - $\vdots$
   - $x_d^{(t+1)} \sim \pi(x_d | x_1^{(t+1)}, x_2^{(t+1)}, \ldots, x_{d-1}^{(t+1)})$

### 4.3 混合诊断

**Gelman-Rubin诊断（$\hat{R}$）**：

$$\hat{R} = \sqrt{\frac{\hat{V}}{W}}$$

其中 $W$ 为链内方差，$\hat{V}$ 为总方差估计。$\hat{R} < 1.1$ 通常认为收敛。

## 五、蒙特卡洛模拟在预测中的应用

### 5.1 预测区间估计

对于回归模型 $Y = f(X) + \varepsilon$，$\varepsilon \sim N(0, \sigma^2)$：

1. 估计模型参数 $\hat{\theta}$
2. 从 $\varepsilon$ 的分布中采样 $\varepsilon^{(1)}, \ldots, \varepsilon^{(N)}$
3. 生成 $N$ 个预测值：$\hat{Y}^{(i)} = f(X_{new}; \hat{\theta}) + \varepsilon^{(i)}$
4. 计算预测区间的分位数

### 5.2 风险价值（VaR）

$$\text{VaR}_\alpha = -\inf\{x: P(L \leq x) \geq \alpha\}$$

通过蒙特卡洛模拟估计损失 $L$ 的分布。

### 5.3 情景分析

模拟多种未来情景，评估不同情景下的结果：

1. 确定影响因素的概率分布
2. 从各分布中独立采样生成情景
3. 对每种情景计算结果
4. 汇总分析结果的分布

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

class MonteCarloSimulator:
    """蒙特卡洛模拟器"""
    
    def __init__(self, n_simulations=10000, random_seed=42):
        self.n_simulations = n_simulations
        self.rng = np.random.RandomState(random_seed)
    
    def integral(self, func, a, b):
        """蒙特卡洛积分"""
        samples = self.rng.uniform(a, b, self.n_simulations)
        values = func(samples)
        
        estimate = (b - a) * np.mean(values)
        std_error = (b - a) * np.std(values) / np.sqrt(self.n_simulations)
        
        return {
            'estimate': estimate,
            'std_error': std_error,
            'ci_95': (estimate - 1.96 * std_error, estimate + 1.96 * std_error)
        }
    
    def importance_sampling(self, func, target_dist, proposal_dist, 
                           proposal_sampler, proposal_pdf):
        """重要性采样"""
        samples = proposal_sampler(self.n_simulations)
        
        # 重要性权重
        weights = target_dist(samples) / (proposal_pdf(samples) + 1e-10)
        weights = weights / weights.sum()
        
        values = func(samples)
        estimate = np.sum(weights * values)
        
        # 方差估计
        variance = np.sum(weights * (values - estimate)**2)
        std_error = np.sqrt(variance / self.n_simulations)
        
        return {
            'estimate': estimate,
            'std_error': std_error,
            'effective_sample_size': 1.0 / np.sum(weights**2)
        }
    
    def var_estimate(self, returns, confidence=0.05):
        """风险价值(VaR)估计"""
        sorted_returns = np.sort(returns)
        var_index = int(self.n_simulations * confidence)
        
        var = -sorted_returns[var_index]
        cvar = -np.mean(sorted_returns[:var_index])
        
        return {
            'VaR': var,
            'CVaR': cvar,
            'returns_distribution': sorted_returns
        }
    
    def path_simulation(self, s0, mu, sigma, dt, n_steps, n_paths=None):
        """几何布朗运动路径模拟"""
        if n_paths is None:
            n_paths = self.n_simulations
        
        Z = self.rng.standard_normal((n_paths, n_steps))
        
        # GBM
        drift = (mu - 0.5 * sigma**2) * dt
        diffusion = sigma * np.sqrt(dt) * Z
        
        log_returns = drift + diffusion
        log_prices = np.concatenate([
            np.zeros((n_paths, 1)),
            np.cumsum(log_returns, axis=1)
        ], axis=1)
        
        prices = s0 * np.exp(log_prices)
        return prices
    
    def bootstrap(self, data, n_bootstrap=10000, statistic=np.mean):
        """Bootstrap估计"""
        n = len(data)
        bootstrap_stats = np.zeros(n_bootstrap)
        
        for i in range(n_bootstrap):
            sample = self.rng.choice(data, size=n, replace=True)
            bootstrap_stats[i] = statistic(sample)
        
        ci_lower = np.percentile(bootstrap_stats, 2.5)
        ci_upper = np.percentile(bootstrap_stats, 97.5)
        
        return {
            'statistic': statistic(data),
            'bootstrap_mean': np.mean(bootstrap_stats),
            'bootstrap_std': np.std(bootstrap_stats),
            'ci_95': (ci_lower, ci_upper),
            'distribution': bootstrap_stats
        }


class MarkovChainMonteCarlo:
    """MCMC采样器"""
    
    def __init__(self, target_log_prob, n_samples=10000, random_seed=42):
        self.target_log_prob = target_log_prob
        self.n_samples = n_samples
        self.rng = np.random.RandomState(random_seed)
    
    def metropolis_hastings(self, initial, proposal_scale=1.0):
        """Metropolis-Hastings算法"""
        dim = len(initial)
        samples = np.zeros((self.n_samples, dim))
        current = initial.copy()
        current_log_prob = self.target_log_prob(current)
        
        n_accepted = 0
        
        for i in range(self.n_samples):
            # 提议
            proposal = current + self.rng.normal(0, proposal_scale, dim)
            proposal_log_prob = self.target_log_prob(proposal)
            
            # 接受概率
            log_alpha = proposal_log_prob - current_log_prob
            log_alpha = min(0, log_alpha)
            
            # 接受/拒绝
            if np.log(self.rng.uniform()) < log_alpha:
                current = proposal
                current_log_prob = proposal_log_prob
                n_accepted += 1
            
            samples[i] = current
        
        acceptance_rate = n_accepted / self.n_samples
        return samples, acceptance_rate
    
    def gibbs_sampling(self, initial, conditional_samplers):
        """Gibbs采样"""
        dim = len(initial)
        samples = np.zeros((self.n_samples, dim))
        current = initial.copy()
        
        for i in range(self.n_samples):
            for j in range(dim):
                current[j] = conditional_samplers[j](current)
            samples[i] = current
        
        return samples
    
    def diagnostics(self, samples):
        """MCMC诊断"""
        n_chains = 1
        n_samples = len(samples)
        
        # 基本统计
        stats_dict = {
            'mean': np.mean(samples, axis=0),
            'std': np.std(samples, axis=0),
            'effective_sample_size': self._effective_sample_size(samples)
        }
        
        return stats_dict
    
    def _effective_sample_size(self, samples):
        """有效样本大小"""
        n = len(samples)
        if samples.ndim > 1:
            return [self._effective_sample_size(samples[:, i]) 
                   for i in range(samples.shape[1])]
        
        # 自相关
        mean = np.mean(samples)
        var = np.var(samples)
        if var == 0:
            return n
        
        autocorr = np.correlate(samples - mean, samples - mean, mode='full')
        autocorr = autocorr[n-1:] / (var * n)
        
        # 求和自相关
        lag = 1
        sum_autocorr = 0
        while lag < n - 1 and autocorr[lag] > 0:
            sum_autocorr += autocorr[lag]
            lag += 1
        
        ess = n / (1 + 2 * sum_autocorr)
        return max(1, ess)

# 计算 π 的近似值（单位圆面积 / 正方形面积 = π/4）
def circle_indicator(x):
    y_samples = np.random.uniform(0, 1, len(x))
    return (x**2 + y_samples**2 <= 1).astype(float)

result = mc.integral(circle_indicator, 0, 1)
print("=== 蒙特卡洛估计 π ===")
print(f"估计值: {4 * result['estimate']:.6f}")
print(f"实际值: {np.pi:.6f}")
print(f"标准误差: {4 * result['std_error']:.6f}")

# 从二维正态分布采样
def log_target(x):
    """二维正态分布的对数概率密度"""
    mu = np.array([0, 0])
    Sigma = np.array([[1, 0.5], [0.5, 1]])
    return -0.5 * (x - mu) @ np.linalg.inv(Sigma) @ (x - mu)

mcmc = MarkovChainMonteCarlo(log_target, n_samples=5000)

# MH采样

)
```

## 七、实际案例：项目投资决策

### 7.1 问题描述

某公司考虑一个投资项目，初始投资1000万元。未来5年的年收入不确定，服从正态分布 $N(300, 50^2)$ 万元，年成本服从均匀分布 $U(150, 250)$ 万元。折现率为10%。评估该项目的净现值（NPV）。

### 7.2 蒙特卡洛模拟

```python
import numpy as np

np.random.seed(42)
n_simulations = 10000

# 参数
initial_investment = 1000
discount_rate = 0.10
n_years = 5

# 蒙特卡洛模拟
npvs = np.zeros(n_simulations)

for i in range(n_simulations):
    cash_flows = []
    for year in range(n_years):
        revenue = np.random.normal(300, 50)
        cost = np.random.uniform(150, 250)
        net_cf = revenue - cost
        cash_flows.append(net_cf)
    
    # 计算NPV
    npv = -initial_investment
    for t, cf in enumerate(cash_flows):
        npv += cf / (1 + discount_rate) ** (t + 1)
    npvs[i] = npv

# 统计结果
print("=== 项目NPV蒙特卡洛模拟 ===")
print(f"NPV均值: {np.mean(npvs):.2f} 万元")
print(f"NPV标准差: {np.std(npvs):.2f} 万元")
print(f"P(NPV > 0): {(npvs > 0).mean():.2%}")
print(f"5% VaR: {np.percentile(npvs, 5):.2f} 万元")
print(f"95%分位数: {np.percentile(npvs, 95):.2f} 万元")
```

## 八、关键要点总结

1. **蒙特卡洛的核心思想**：用随机采样的统计特征近似求解确定性问题
2. **收敛速度**：$O(1/\sqrt{n})$，与维度无关
3. **方差缩减技术**可以显著提高估计精度：对偶变量、重要性采样、分层采样
4. **MCMC方法**用于从复杂分布采样：MH算法、Gibbs采样
5. **蒙特卡洛模拟的应用**：积分计算、风险评估、期权定价、项目评估
6. **随机数质量**直接影响模拟结果，需要进行质量检验
7. **样本量选择**：通常需要 $10^4 \sim 10^6$ 次模拟
8. **收敛诊断**：Gelman-Rubin诊断、轨迹图、自相关图
9. **蒙特卡洛的优势**：直观、通用、不受维度限制
10. **蒙特卡洛的局限**：计算量大、收敛速度慢、需要分布假设
