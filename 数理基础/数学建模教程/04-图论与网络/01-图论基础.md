# 图论基础

## 1. 图的基本概念

### 1.1 图的定义

一个图 $G$ 由顶点集 $V$ 和边集 $E$ 组成，记作 $G = (V, E)$。

- **顶点（Vertex）**：图中的基本元素，也称为节点。
- **边（Edge）**：连接两个顶点的线段，表示顶点之间的关系。

若边具有方向，则称为**有向图（Directed Graph）**；若边没有方向，则称为**无向图（Undirected Graph）**。

### 1.2 图的分类

| 分类标准 | 类型 | 说明 |
|---------|------|------|
| 按边的方向 | 有向图/无向图 | 边是否有方向 |
| 按边的权重 | 加权图/无权图 | 边是否有数值权重 |
| 按顶点和边的关系 | 简单图/多重图 | 是否有自环和平行边 |
| 按连通性 | 连通图/非连通图 | 任意两点间是否可达 |

### 1.3 基本术语

- **相邻（Adjacent）**：若两个顶点之间有边相连，则称这两个顶点相邻。
- **关联（Incident）**：边与其连接的顶点之间的关系。
- **度（Degree）**：顶点 $v$ 的度 $d(v)$ 是与该顶点关联的边的数目。
- **路径（Path）**：顶点序列 $v_0, v_1, \ldots, v_k$，其中每对相邻顶点之间都有边相连。
- **简单路径（Simple Path）**：路径中所有顶点互不相同。
- **回路/环（Cycle）**：起点和终点相同的路径。
- **连通（Connected）**：若图中任意两个顶点之间都存在路径，则称图是连通的。

## 2. 图的表示方法

### 2.1 邻接矩阵

对于有 $n$ 个顶点的图 $G=(V,E)$，其邻接矩阵 $A$ 是一个 $n \times n$ 的矩阵，定义为：

$$A_{ij} = \begin{cases} 1, & \text{若 } (v_i, v_j) \in E \\ 0, & \text{否则} \end{cases}$$

对于**加权图**，邻接矩阵可以表示为：

$$A_{ij} = \begin{cases} w_{ij}, & \text{若 } (v_i, v_j) \in E \\ \infty, & \text{若 } (v_i, v_j) \notin E \text{ 且 } i \neq j \\ 0, & \text{若 } i = j \end{cases}$$

**邻接矩阵的性质：**

- 无向图的邻接矩阵是对称矩阵，即 $A = A^T$。
- 第 $i$ 行（或第 $i$ 列）的元素之和等于顶点 $v_i$ 的度。
- $A^k$ 的第 $(i,j)$ 个元素表示从 $v_i$ 到 $v_j$ 长度为 $k$ 的路径数目。

### 2.2 邻接表

邻接表是图的链式存储结构，为每个顶点维护一个链表，存储与该顶点相邻的所有顶点。

- **空间复杂度**：$O(|V| + |E|)$，适合稀疏图。
- **优点**：空间效率高，便于遍历某顶点的所有邻居。

### 2.3 关联矩阵

关联矩阵 $M$ 是一个 $|V| \times |E|$ 的矩阵，定义为：

$$M_{ij} = \begin{cases} 1, & \text{若顶点 } v_i \text{ 是边 } e_j \text{ 的端点} \\ 0, & \text{否则} \end{cases}$$

对于有向图，可以用 $+1$ 和 $-1$ 分别表示出边和入边。

## 3. 度与度序列

### 3.1 度的定义

在无向图 $G=(V,E)$ 中，顶点 $v$ 的度 $d(v)$ 定义为与 $v$ 关联的边的数目（自环计算两次）。

在有向图中：
- **出度（Out-degree）** $d^+(v)$：以 $v$ 为起点的边的数目。
- **入度（In-degree）** $d^-(v)$：以 $v$ 为终点的边的数目。
- **总度** $d(v) = d^+(v) + d^-(v)$。

### 3.2 握手定理

> **握手定理**：在任意无向图 $G=(V,E)$ 中，所有顶点的度之和等于边数的两倍：
> $$\sum_{v \in V} d(v) = 2|E|$$

推论：度数为奇数的顶点个数必为偶数。

### 3.3 度序列

图的所有顶点的度按非递减（或非递增）顺序排列形成的序列称为**度序列**。

> **Erdős–Gallai 定理**：非负整数序列 $d_1 \geq d_2 \geq \cdots \geq d_n$ 是某个无向图的度序列的充要条件是 $\sum_{i=1}^n d_i$ 为偶数，且对每个 $k \in \{1, 2, \ldots, n\}$：
> $$\sum_{i=1}^k d_i \leq k(k-1) + \sum_{i=k+1}^n \min(d_i, k)$$

## 4. 特殊图类

### 4.1 完全图

$n$ 个顶点的**完全图** $K_n$ 是每对顶点之间都有一条边相连的简单无向图。边数为：

$$|E| = \binom{n}{2} = \frac{n(n-1)}{2}$$

### 4.2 二部图

图 $G=(V,E)$ 是**二部图（Bipartite Graph）**，如果 $V$ 可以划分为两个不相交的子集 $V_1$ 和 $V_2$，使得每条边的两个端点分别属于 $V_1$ 和 $V_2$。

> **König 定理**：二部图中最大匹配的大小等于最小顶点覆盖的大小。

### 4.3 正则图

若图中每个顶点的度都相同，即 $d(v) = r$ 对所有 $v \in V$ 成立，则称该图为 **$r$-正则图**。

### 4.4 平面图

如果一个图可以画在平面上，使得边与边之间只在端点处相交，则称该图为**平面图（Planar Graph）**。

> **欧拉公式**：对于连通平面图，$|V| - |E| + |F| = 2$，其中 $|F|$ 是面的数目。

## 5. 图的连通性

### 5.1 连通分量

无向图的**连通分量**是极大的连通子图。若图只有一个连通分量，则图是连通的。

### 5.2 割点与桥

- **割点（Cut Vertex）**：删除该顶点后，图的连通分量数目增加。
- **桥（Bridge）**：删除该边后，图的连通分量数目增加。

### 5.3 连通度

- **点连通度 $\kappa(G)$**：使图不连通或变为平凡图所需删除的最少顶点数。
- **边连通度 $\lambda(G)$**：使图不连通所需删除的最少边数。

> **惠特尼不等式**：$\kappa(G) \leq \lambda(G) \leq \delta(G)$，其中 $\delta(G)$ 是图的最小度。

## 6. 路径与距离

### 6.1 最短路径

顶点 $u$ 到 $v$ 的**最短距离** $d(u,v)$ 是连接 $u$ 和 $v$ 的最短路径的边数。在加权图中，最短距离是路径上所有边权之和的最小值。

### 6.2 图的直径

图的**直径**定义为所有顶点对之间最短距离的最大值：

$$\text{diam}(G) = \max_{u,v \in V} d(u,v)$$

### 6.3 图的中心

图的**中心**是使到其他所有顶点的最大距离最小的顶点：

$$\text{center}(G) = \left\{ v \in V : \max_{u \in V} d(v,u) = \min_{w \in V} \max_{u \in V} d(w,u) \right\}$$

## 7. 有向图的特殊性质

### 7.1 强连通性

有向图 $G$ 是**强连通的**，如果任意两个顶点 $u$ 和 $v$ 之间都存在从 $u$ 到 $v$ 和从 $v$ 到 $u$ 的有向路径。

### 7.2 有向无环图（DAG）

**DAG（Directed Acyclic Graph）** 是不含有向环的有向图。DAG 可以进行**拓扑排序**，即找到顶点的一个线性排列，使得对于每条有向边 $(u,v)$，$u$ 都排在 $v$ 前面。

### 7.3 拓扑排序

拓扑排序是 DAG 的顶点的线性排列，满足：若 $(u,v) \in E$，则 $u$ 在排列中位于 $v$ 之前。

拓扑排序可以通过 **Kahn 算法**实现：
1. 找到所有入度为 0 的顶点，加入队列。
2. 从队列中取出顶点，将其加入排序结果。
3. 将该顶点的所有邻居的入度减 1，若某邻居入度变为 0，则加入队列。
4. 重复步骤 2-3 直到队列为空。

## 8. Python 实现

### 8.1 使用 networkx 创建和操作图

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建无向图
G = nx.Graph()
G.add_edges_from([(0, 1), (1, 2), (2, 3), (3, 0), (0, 2)])

# 基本信息
print(f"顶点数: {G.number_of_nodes()}")
print(f"边数: {G.number_of_edges()}")
print(f"是否连通: {nx.is_connected(G)}")

# 度序列
print(f"度序列: {sorted([d for n, d in G.degree()])}")

# 邻接矩阵
adj_matrix = nx.adjacency_matrix(G).toarray()
print(f"邻接矩阵:\n{adj_matrix}")

# 可视化
nx.draw(G, with_labels=True, node_color='lightblue', 
        node_size=500, font_size=16, font_weight='bold')
plt.title("图的可视化")
plt.show()
```

### 8.2 使用 networkx 创建有向图

```python
import networkx as nx

# 创建有向图
DG = nx.DiGraph()
DG.add_edges_from([(0, 1), (1, 2), (2, 0), (2, 3)])

# 出度和入度
for node in DG.nodes():
    print(f"顶点 {node}: 出度={DG.out_degree(node)}, 入度={DG.in_degree(node)}")

# 检查是否强连通
print(f"是否强连通: {nx.is_strongly_connected(DG)}")

# 拓扑排序
if nx.is_directed_acyclic_graph(DG):
    topo_order = list(nx.topological_sort(DG))
    print(f"拓扑排序: {topo_order}")
```

### 8.3 图的矩阵表示

```python
import numpy as np
import networkx as nx

def analyze_graph_matrix(G):
    """分析图的矩阵性质"""
    A = nx.adjacency_matrix(G).toarray().astype(float)
    n = A.shape[0]
    
    # 度矩阵
    D = np.diag(np.sum(A, axis=1))
    
    # 拉普拉斯矩阵 L = D - A
    L = D - A
    
    # 特征值
    eigenvalues = np.linalg.eigvalsh(L)
    
    print(f"邻接矩阵:\n{A}")
    print(f"度矩阵:\n{D}")
    print(f"拉普拉斯矩阵:\n{L}")
    print(f"拉普拉斯矩阵特征值: {np.sort(eigenvalues)}")
    print(f"连通分量数(0特征值重数): {np.sum(np.abs(eigenvalues) < 1e-10)}")

# 示例
G = nx.cycle_graph(5)
analyze_graph_matrix(G)
```

### 8.4 连通性分析

```python
import networkx as nx

def connectivity_analysis(G):
    """图的连通性综合分析"""
    print(f"是否连通: {nx.is_connected(G)}")
    print(f"连通分量数: {nx.number_connected_components(G)}")
    
    if nx.is_connected(G):
        print(f"点连通度: {nx.node_connectivity(G)}")
        print(f"边连通度: {nx.edge_connectivity(G)}")
        print(f"图的直径: {nx.diameter(G)}")
        print(f"图的半径: {nx.radius(G)}")
        print(f"图的中心: {nx.center(G)}")
        print(f"图的外围: {nx.periphery(G)}")
    
    # 割点
    articulation = list(nx.articulation_points(G))
    print(f"割点: {articulation}")
    
    # 桥
    bridges = list(nx.bridges(G))
    print(f"桥: {bridges}")

G = nx.barbell_graph(5, 1)
connectivity_analysis(G)
```

## 9. 实际应用

### 9.1 社交网络分析

社交网络可以用图来建模，其中人是顶点，关系是边。社交网络分析的关键指标包括：

- **度分布**：$P(d) \sim d^{-\gamma}$，许多社交网络呈现幂律分布。
- **聚类系数**：衡量邻居之间也互为邻居的程度。
- **最短路径**：社交网络通常具有"小世界"特性，平均路径长度较短。

### 9.2 互联网与网页排名

网页可以用有向图建模，其中网页是顶点，超链接是有向边。Google 的 PageRank 算法基于此模型计算网页的重要性。

### 9.3 生物网络

蛋白质-蛋白质相互作用网络、基因调控网络、代谢网络等都可以用图来建模和分析。

### 9.4 交通网络

城市道路网络、地铁网络、航空网络等都是图论的重要应用场景。

## 10. 关键点总结

| 概念 | 定义/公式 | 重要性 |
|------|----------|--------|
| 邻接矩阵 | $A_{ij}$ 表示顶点间的连接关系 | 图的基本表示方法 |
| 握手定理 | $\sum d(v) = 2\|E\|$ | 度与边数的关系 |
| 欧拉公式 | $|V| - |E| + |F| = 2$ | 平面图的基本性质 |
| 连通分量 | 极大连通子图 | 图的结构分析 |
| 强连通 | 任意两点互相可达 | 有向图的连通性 |
| 度序列 | 所有顶点度的排序序列 | 图的特征描述 |
| 完全图 | 每对顶点间都有边 | 边数最多的简单图 |
| 二部图 | 顶点可二染色 | 特殊图结构 |
