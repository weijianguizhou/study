## 8. Python 实现
### 8.1 使用 networkx 创建和操作图

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建无向图
G = nx.Graph()
G.add_edges_from([(0, 1), (1, 2), (2, 3), (3, 0), (0, 2)])

# 基本信息
print(f"顶点数: {G.number_of_nodes()}")
print(f"边数: {G.number_of_edges()}")
print(f"是否连通: {nx.is_connected(G)}")

# 度序列
print(f"度序列: {sorted([d for n, d in G.degree()])}")

# 邻接矩阵
adj_matrix = nx.adjacency_matrix(G).toarray()
print(f"邻接矩阵:\n{adj_matrix}")

# 可视化
nx.draw(G, with_labels=True, node_color='lightblue', 
        node_size=500, font_size=16, font_weight='bold')
plt.title("图的可视化")
plt.show()
```

### 8.2 使用 networkx 创建有向图

```python
import networkx as nx

# 创建有向图
DG = nx.DiGraph()
DG.add_edges_from([(0, 1), (1, 2), (2, 0), (2, 3)])

# 出度和入度
for node in DG.nodes():
    print(f"顶点 {node}: 出度={DG.out_degree(node)}, 入度={DG.in_degree(node)}")

# 检查是否强连通
print(f"是否强连通: {nx.is_strongly_connected(DG)}")

# 拓扑排序
if nx.is_directed_acyclic_graph(DG):
    topo_order = list(nx.topological_sort(DG))
    print(f"拓扑排序: {topo_order}")
```

### 8.3 图的矩阵表示

```python
import numpy as np
import networkx as nx

def analyze_graph_matrix(G):
    """分析图的矩阵性质"""
    A = nx.adjacency_matrix(G).toarray().astype(float)
    n = A.shape[0]
    
    # 度矩阵
    D = np.diag(np.sum(A, axis=1))
    
    # 拉普拉斯矩阵 L = D - A
    L = D - A
    
    # 特征值
    eigenvalues = np.linalg.eigvalsh(L)
    
    print(f"邻接矩阵:\n{A}")
    print(f"度矩阵:\n{D}")
    print(f"拉普拉斯矩阵:\n{L}")
    print(f"拉普拉斯矩阵特征值: {np.sort(eigenvalues)}")
    print(f"连通分量数(0特征值重数): {np.sum(np.abs(eigenvalues) < 1e-10)}")

# 示例
G = nx.cycle_graph(5)
analyze_graph_matrix(G)
```

### 8.4 连通性分析

```python
import networkx as nx

def connectivity_analysis(G):
    """图的连通性综合分析"""
    print(f"是否连通: {nx.is_connected(G)}")
    print(f"连通分量数: {nx.number_connected_components(G)}")
    
    if nx.is_connected(G):
        print(f"点连通度: {nx.node_connectivity(G)}")
        print(f"边连通度: {nx.edge_connectivity(G)}")
        print(f"图的直径: {nx.diameter(G)}")
        print(f"图的半径: {nx.radius(G)}")
        print(f"图的中心: {nx.center(G)}")
        print(f"图的外围: {nx.periphery(G)}")
    
    # 割点
    articulation = list(nx.articulation_points(G))
    print(f"割点: {articulation}")
    
    # 桥
    bridges = list(nx.bridges(G))
    print(f"桥: {bridges}")

G = nx.barbell_graph(5, 1)
connectivity_analysis(G)
```

## 9. 实际应用
### 9.1 社交网络分析

社交网络可以用图来建模，其中人是顶点，关系是边。社交网络分析的关键指标包括：

- **度分布**：$P(d) \sim d^{-\gamma}$，许多社交网络呈现幂律分布。
- **聚类系数**：衡量邻居之间也互为邻居的程度。
- **最短路径**：社交网络通常具有"小世界"特性，平均路径长度较短。

### 9.2 互联网与网页排名

网页可以用有向图建模，其中网页是顶点，超链接是有向边。Google 的 PageRank 算法基于此模型计算网页的重要性。

### 9.3 生物网络

蛋白质-蛋白质相互作用网络、基因调控网络、代谢网络等都可以用图来建模和分析。

### 9.4 交通网络

城市道路网络、地铁网络、航空网络等都是图论的重要应用场景。

## 10. 关键点总结
| 概念 | 定义/公式 | 重要性 |
|------|----------|--------|
| 邻接矩阵 | $A_{ij}$ 表示顶点间的连接关系 | 图的基本表示方法 |
| 握手定理 | $\sum d(v) = 2\|E\|$ | 度与边数的关系 |
| 欧拉公式 | $|V| - |E| + |F| = 2$ | 平面图的基本性质 |
| 连通分量 | 极大连通子图 | 图的结构分析 |
| 强连通 | 任意两点互相可达 | 有向图的连通性 |
| 度序列 | 所有顶点度的排序序列 | 图的特征描述 |
| 完全图 | 每对顶点间都有边 | 边数最多的简单图 |
| 二部图 | 顶点可二染色 | 特殊图结构 |
