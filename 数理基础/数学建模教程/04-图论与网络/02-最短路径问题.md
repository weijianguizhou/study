# 最短路径问题

## 1. 问题概述

### 1.1 问题定义

**最短路径问题**是图论中最经典的问题之一。给定一个加权图 $G=(V,E)$，以及源点 $s$ 和目标点 $t$，求从 $s$ 到 $t$ 的一条路径，使得路径上所有边的权重之和最小。

形式化地，设路径 $P = (v_0, v_1, \ldots, v_k)$，其中 $v_0 = s$，$v_k = t$，则最短路径的目标是：

$$\min_{P} \sum_{i=1}^{k} w(v_{i-1}, v_i)$$

### 1.2 问题分类

| 问题类型 | 说明 | 适用算法 |
|---------|------|---------|
| 单源最短路径 | 从一个源点到所有其他顶点 | Dijkstra, Bellman-Ford |
| 单对最短路径 | 从一个源点到一个目标点 | Dijkstra, A* |
| 全源最短路径 | 所有顶点对之间的最短路径 | Floyd-Warshall, Johnson |
| 受限最短路径 | 对路径有额外约束 | 动态规划 |

### 1.3 最优子结构

最短路径问题具有**最优子结构**性质：若从 $s$ 到 $t$ 的最短路径经过顶点 $v$，则从 $s$ 到 $v$ 的子路径也是从 $s$ 到 $v$ 的最短路径。

这一性质是动态规划求解最短路径问题的理论基础。

## 2. Dijkstra 算法

### 2.1 算法思想

Dijkstra 算法是求解**非负权图**单源最短路径问题的经典算法。其核心思想是**贪心策略**：每次从未确定最短距离的顶点中选择距离最小的顶点，更新其邻居的距离。

### 2.2 算法步骤

1. 初始化：$d(s) = 0$，$d(v) = \infty$（对所有 $v \neq s$），集合 $S = \emptyset$。
2. 选择不在 $S$ 中的距离最小的顶点 $u$：$u = \arg\min_{v \notin S} d(v)$。
3. 将 $u$ 加入 $S$。
4. 对 $u$ 的每个邻居 $v$，执行松弛操作：$d(v) = \min(d(v), d(u) + w(u,v))$。
5. 重复步骤 2-4，直到 $S = V$。

### 2.3 松弛操作

**松弛（Relaxation）** 是最短路径算法的核心操作：

```
松弛(u, v, w):
    if d(v) > d(u) + w(u, v):
        d(v) = d(u) + w(u, v)
        π(v) = u
```

其中 $\pi(v)$ 记录 $v$ 的前驱顶点，用于重建最短路径。

### 2.4 伪代码

```
算法: Dijkstra(G, w, s)
输入: 图 G=(V,E), 权重函数 w, 源点 s
输出: 从 s 到所有顶点的最短距离和前驱

1:  for each vertex v ∈ V:
2:      d(v) = ∞
3:      π(v) = NIL
4:  d(s) = 0
5:  Q = V    // 优先队列
6:  while Q ≠ ∅:
7:      u = Extract-Min(Q)
8:      for each vertex v ∈ Adj(u):
9:          if d(v) > d(u) + w(u, v):
10:             d(v) = d(u) + w(u, v)
11:             π(v) = u
12:             Decrease-Key(Q, v, d(v))
13: return d, π
```

### 2.5 正确性证明

**定理**：Dijkstra 算法正确地计算出从源点 $s$ 到所有可达顶点的最短距离。

**证明思路**：通过归纳法。假设算法已正确处理了集合 $S$ 中所有顶点，需要证明下一个被加入 $S$ 的顶点 $u$ 的距离 $d(u)$ 等于真实的最短距离 $\delta(s, u)$。

反证法：假设 $d(u) > \delta(s, u)$。设从 $s$ 到 $u$ 的最短路径为 $P$，则 $P$ 上一定存在某个顶点 $y$ 不在 $S$ 中，且其前驱 $x$ 在 $S$ 中。由于 $w$ 非负，$d(y) \leq d(x) + w(x,y) = \delta(s,y) \leq \delta(s,u) < d(u)$。但算法选择了 $u$ 而非 $y$，矛盾。

### 2.6 时间复杂度

| 数据结构 | 时间复杂度 |
|---------|-----------|
| 数组 | $O(|V|^2)$ |
| 二叉堆 | $O((|V| + |E|) \log |V|)$ |
| 斐波那契堆 | $O(|E| + |V| \log |V|)$ |

对于稀疏图（$|E| = O(|V|)$），使用优先队列的 Dijkstra 算法时间复杂度为 $O(|V| \log |V|)$。

### 2.7 Python 实现

```python
import heapq
import networkx as nx

def dijkstra(G, source):
    """
    Dijkstra 算法的实现
    G: networkx 图
    source: 源点
    返回: 距离字典和前驱字典
    """
    distances = {node: float('inf') for node in G.nodes()}
    predecessors = {node: None for node in G.nodes()}
    distances[source] = 0
    
    # 优先队列: (距离, 顶点)
    pq = [(0, source)]
    visited = set()
    
    while pq:
        dist, u = heapq.heappop(pq)
        
        if u in visited:
            continue
        visited.add(u)
        
        for v in G.neighbors(u):
            if v not in visited:
                weight = G[u][v].get('weight', 1)
                new_dist = dist + weight
                if new_dist < distances[v]:
                    distances[v] = new_dist
                    predecessors[v] = u
                    heapq.heappush(pq, (new_dist, v))
    
    return distances, predecessors

def reconstruct_path(predecessors, target):
    """重建从源点到目标点的最短路径"""
    path = []
    current = target
    while current is not None:
        path.append(current)
        current = predecessors[current]
    return path[::-1]

# 使用示例
G = nx.DiGraph()
edges = [
    ('A', 'B', 4), ('A', 'C', 2),
    ('B', 'C', 1), ('B', 'D', 5),
    ('C', 'D', 8), ('C', 'E', 10),
    ('D', 'E', 2), ('D', 'F', 6),
    ('E', 'F', 3)
]
G.add_weighted_edges_from(edges)

distances, predecessors = dijkstra(G, 'A')
print("最短距离:", distances)
print("到 F 的路径:", reconstruct_path(predecessors, 'F'))
```

## 3. Bellman-Ford 算法

### 3.1 算法动机

Dijkstra 算法要求所有边权非负。当图中存在**负权边**时，需要使用 Bellman-Ford 算法。

### 3.2 算法思想

Bellman-Ford 算法基于**动态规划**：对所有边进行 $|V|-1$ 轮松弛操作。在第 $i$ 轮松弛后，$d(v)$ 存储的是从 $s$ 到 $v$ 经过至多 $i$ 条边的最短距离。

### 3.3 伪代码

```
算法: Bellman-Ford(G, w, s)
输入: 图 G=(V,E), 权重函数 w, 源点 s
输出: 最短距离, 或检测到负权环

1:  d(s) = 0
2:  for each vertex v ∈ V - {s}:
3:      d(v) = ∞
4:  for i = 1 to |V| - 1:
5:      for each edge (u, v) ∈ E:
6:          if d(v) > d(u) + w(u, v):
7:              d(v) = d(u) + w(u, v)
8:              π(v) = u
9:  // 检测负权环
10: for each edge (u, v) ∈ E:
11:     if d(v) > d(u) + w(u, v):
12:         return "存在负权环"
13: return d, π
```

### 3.4 负权环检测

若在第 $|V|$ 轮松弛后仍能继续松弛，说明图中存在**负权环（Negative Cycle）**，即环上所有边权之和小于 0。

### 3.5 时间复杂度

- **时间复杂度**：$O(|V| \cdot |E|)$
- **空间复杂度**：$O(|V|)$

### 3.6 Python 实现

```python
def bellman_ford(G, source):
    """
    Bellman-Ford 算法
    G: networkx 图
    source: 源点
    返回: 距离字典, 前驱字典, 是否存在负权环
    """
    nodes = list(G.nodes())
    edges = list(G.edges(data=True))
    
    distances = {node: float('inf') for node in nodes}
    predecessors = {node: None for node in nodes}
    distances[source] = 0
    
    # 松弛 |V|-1 轮
    for _ in range(len(nodes) - 1):
        updated = False
        for u, v, data in edges:
            weight = data.get('weight', 1)
            if distances[u] + weight < distances[v]:
                distances[v] = distances[u] + weight
                predecessors[v] = u
                updated = True
        if not updated:
            break  # 提前终止
    
    # 检测负权环
    has_negative_cycle = False
    for u, v, data in edges:
        weight = data.get('weight', 1)
        if distances[u] + weight < distances[v]:
            has_negative_cycle = True
            break
    
    return distances, predecessors, has_negative_cycle

# 使用示例
G = nx.DiGraph()
G.add_weighted_edges_from([
    (0, 1, 4), (0, 2, 5),
    (1, 2, -3), (1, 3, 8),
    (2, 4, 2), (3, 4, -2),
    (4, 3, 1)
])

distances, preds, has_cycle = bellman_ford(G, 0)
print(f"最短距离: {distances}")
print(f"是否存在负权环: {has_cycle}")
```

## 4. Floyd-Warshall 算法

### 4.1 算法思想

Floyd-Warshall 算法求解**全源最短路径（All-Pairs Shortest Path）**问题。其核心思想是动态规划：对于每对顶点 $(i,j)$，考虑是否经过中间顶点 $k$ 可以缩短距离。

### 4.2 递推公式

设 $d^{(k)}(i,j)$ 为从 $i$ 到 $j$ 且只经过编号不超过 $k$ 的中间顶点的最短距离：

$$d^{(k)}(i,j) = \begin{cases} w(i,j), & k = 0 \\ \min\left(d^{(k-1)}(i,j), \; d^{(k-1)}(i,k) + d^{(k-1)}(k,j)\right), & k \geq 1 \end{cases}$$

最终，$d^{(|V|)}(i,j)$ 即为从 $i$ 到 $j$ 的最短距离。

### 4.3 伪代码

```
算法: Floyd-Warshall(G, w)
输入: 图 G=(V,E), 权重函数 w
输出: 所有顶点对之间的最短距离矩阵

1:  n = |V|
2:  D[0] = 邻接矩阵 (D[i][j] = w(i,j) 或 ∞)
3:  for k = 1 to n:
4:      for i = 1 to n:
5:          for j = 1 to n:
6:              D[k][i][j] = min(D[k-1][i][j], 
7:                                D[k-1][i][k] + D[k-1][k][j])
8:  return D[n]
```

### 4.4 时间复杂度

- **时间复杂度**：$O(|V|^3)$
- **空间复杂度**：$O(|V|^2)$（可优化，因为只需要前一层的结果）

### 4.5 路径重建

为了重建最短路径，维护前驱矩阵 $\pi$：

$$\pi(i,j) = \begin{cases} i, & \text{若 } d(i,j) = w(i,j) \text{ 或 } i = j \\ \pi(k,j), & \text{若 } d(i,j) = d(i,k) + d(k,j) \end{cases}$$

### 4.6 Python 实现

```python
import numpy as np

def floyd_warshall(G):
    """
    Floyd-Warshall 算法
    G: networkx 图
    返回: 距离矩阵, 前驱矩阵
    """
    nodes = list(G.nodes())
    n = len(nodes)
    node_index = {node: i for i, node in enumerate(nodes)}
    
    # 初始化距离矩阵
    dist = np.full((n, n), np.inf)
    pred = np.full((n, n), -1, dtype=int)
    
    for i in range(n):
        dist[i][i] = 0
        pred[i][i] = i
    
    for u, v, data in G.edges(data=True):
        i, j = node_index[u], node_index[v]
        weight = data.get('weight', 1)
        dist[i][j] = weight
        pred[i][j] = i
    
    # Floyd-Warshall 主循环
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
                    pred[i][j] = pred[k][j]
    
    return dist, pred, nodes

def get_path(pred, nodes, i, j):
    """重建从节点 i 到节点 j 的路径"""
    if pred[i][j] == -1:
        return []
    path = [nodes[j]]
    current = j
    while current != i:
        current = pred[i][current]
        path.append(nodes[current])
    return path[::-1]

# 使用示例
G = nx.DiGraph()
G.add_weighted_edges_from([
    (0, 1, 3), (0, 2, 8), (1, 2, 2),
    (2, 3, 1), (1, 3, 7), (3, 0, 2)
])

dist, pred, nodes = floyd_warshall(G)
print("距离矩阵:")
print(dist)
```

## 5. A* 算法

### 5.1 算法思想

A* 算法是 Dijkstra 算法的启发式改进版本。它使用启发函数 $h(v)$ 估计从顶点 $v$ 到目标点 $t$ 的距离，优先扩展最有希望的顶点。

### 5.2 代价函数

$$f(v) = g(v) + h(v)$$

其中：
- $g(v)$：从源点 $s$ 到 $v$ 的实际距离。
- $h(v)$：从 $v$ 到目标 $t$ 的启发式估计距离。

### 5.3 可接受性条件

若启发函数 $h(v)$ 满足 $h(v) \leq h^*(v)$（对所有 $v$），其中 $h^*(v)$ 是从 $v$ 到 $t$ 的真实最短距离，则称 $h$ 是**可接受的（Admissible）**。

> **定理**：若 $h$ 是可接受的，则 A* 算法一定能找到最短路径。

### 5.4 常用启发函数

- **欧几里得距离**：$h(v) = \sqrt{(x_v - x_t)^2 + (y_v - y_t)^2}$
- **曼哈顿距离**：$h(v) = |x_v - x_t| + |y_v - y_t|$
- **切比雪夫距离**：$h(v) = \max(|x_v - x_t|, |y_v - y_t|)$

### 5.5 Python 实现

```python
import heapq
import math

def astar(G, source, target, heuristic=None):
    """
    A* 算法
    G: networkx 图（需要有坐标属性 'pos'）
    source: 源点
    target: 目标点
    heuristic: 启发函数
    """
    if heuristic is None:
        def heuristic(u, v):
            pos_u = G.nodes[u].get('pos', (0, 0))
            pos_v = G.nodes[v].get('pos', (0, 0))
            return math.sqrt((pos_u[0]-pos_v[0])**2 + (pos_u[1]-pos_v[1])**2)
    
    g_score = {node: float('inf') for node in G.nodes()}
    g_score[source] = 0
    f_score = {node: float('inf') for node in G.nodes()}
    f_score[source] = heuristic(source, target)
    predecessors = {node: None for node in G.nodes()}
    
    open_set = [(f_score[source], source)]
    closed_set = set()
    
    while open_set:
        _, current = heapq.heappop(open_set)
        
        if current == target:
            path = []
            while current is not None:
                path.append(current)
                current = predecessors[current]
            return path[::-1]
        
        closed_set.add(current)
        
        for neighbor in G.neighbors(current):
            if neighbor in closed_set:
                continue
            
            weight = G[current][neighbor].get('weight', 1)
            tentative_g = g_score[current] + weight
            
            if tentative_g < g_score[neighbor]:
                predecessors[neighbor] = current
                g_score[neighbor] = tentative_g
                f_score[neighbor] = tentative_g + heuristic(neighbor, target)
                heapq.heappush(open_set, (f_score[neighbor], neighbor))
    
    return None  # 无路径
```

## 6. Johnson 算法

### 6.1 算法思想

Johnson 算法用于求解**稀疏图**的全源最短路径问题，结合了 Bellman-Ford 和 Dijkstra 算法。

### 6.2 算法步骤

1. 在图 $G$ 中添加一个新顶点 $s$，从 $s$ 到所有其他顶点添加权值为 0 的边。
2. 以 $s$ 为源点运行 Bellman-Ford 算法，得到势函数 $h(v)$。
3. 对每条边 $(u,v)$ 重新赋权：$w'(u,v) = w(u,v) + h(u) - h(v)$。
4. 对每个顶点 $u$，以 $u$ 为源点运行 Dijkstra 算法（使用重新赋权后的边）。
5. 还原真实距离：$d(u,v) = d'(u,v) - h(u) + h(v)$。

### 6.3 时间复杂度

$O(|V| \cdot |E| + |V|^2 \log |V|)$，比 Floyd-Warshall 的 $O(|V|^3)$ 在稀疏图上更优。

## 7. 算法比较

| 算法 | 时间复杂度 | 负权边 | 适用场景 |
|------|-----------|--------|---------|
| Dijkstra | $O((|V|+|E|)\log |V|)$ | 不允许 | 非负权图单源最短路径 |
| Bellman-Ford | $O(|V| \cdot |E|)$ | 允许 | 一般图单源最短路径 |
| Floyd-Warshall | $O(|V|^3)$ | 允许 | 全源最短路径 |
| A* | $O(|E|)$ 平均 | 不允许 | 有良好启发函数时 |
| Johnson | $O(|V||E| + |V|^2\log|V|)$ | 允许 | 稀疏图全源最短路径 |

## 8. 实际应用

### 8.1 导航系统

GPS 导航系统使用最短路径算法（通常是 Dijkstra 或 A* 的变种）计算两点之间的最优路线。

### 8.2 网络路由

互联网路由协议（如 OSPF）使用最短路径优先算法确定数据包的最佳转发路径。

### 8.3 物流配送

物流系统使用最短路径算法优化配送路线，降低运输成本。

### 8.4 社交网络

社交网络中的"六度分隔"理论与最短路径密切相关。

## 9. 关键点总结

| 要点 | 说明 |
|------|------|
| Dijkstra | 非负权图，贪心策略，$O((|V|+|E|)\log|V|)$ |
| Bellman-Ford | 支持负权边，可检测负权环，$O(|V| \cdot |E|)$ |
| Floyd-Warshall | 全源最短路径，$O(|V|^3)$ |
| A* | 启发式搜索，需可接受启发函数 |
| 最优子结构 | 最短路径的子路径也是最短路径 |
| 负权环 | 使最短路径无定义（可无限减小） |
