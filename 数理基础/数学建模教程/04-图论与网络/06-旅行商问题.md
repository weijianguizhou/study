# 旅行商问题

> **理论基础** → 参见 [[../../图论算法/图论经典问题|TSP理论]]

旅行商问题(TSP)寻找遍历所有城市且总路程最短的回路，是典型的NP-hard组合优化问题。

## 2. 精确算法
### 2.1 动态规划（Held-Karp 算法）

#### 2.1.1 状态定义

设 $S$ 是已访问城市的集合，$j \in S$ 是当前所在城市。

$$dp(S, j) = \text{从起点出发，访问 } S \text{ 中所有城市，最终到达 } j \text{ 的最短路径长度}$$

#### 2.1.2 递推关系

$$dp(S, j) = \min_{i \in S \setminus \{j\}} \left[ dp(S \setminus \{j\}, i) + d_{ij} \right]$$

初始条件：$dp(\{1\}, 1) = 0$。

最终答案：

$$\text{TSP} = \min_{j \neq 1} \left[ dp(\{1, 2, \ldots, n\}, j) + d_{j1} \right]$$

#### 2.1.3 时间复杂度

- **时间复杂度**：$O(n^2 \cdot 2^n)$
- **空间复杂度**：$O(n \cdot 2^n)$

#### 2.1.4 Python 实现

```python
import numpy as np

def held_karp(dist_matrix):
    """
    Held-Karp 动态规划算法求解 TSP
    dist_matrix: n x n 距离矩阵
    返回: 最短距离和最优路径
    """
    n = len(dist_matrix)
    INF = float('inf')
    
    # dp[S][j] = 从 0 出发，访问 S 中所有城市，最终到达 j 的最短距离
    # S 用位掩码表示
    dp = [[INF] * n for _ in range(1 << n)]
    parent = [[-1] * n for _ in range(1 << n)]
    
    dp[1][0] = 0  # 只访问城市 0，当前在城市 0
    
    for S in range(1 << n):
        for j in range(n):
            if dp[S][j] == INF:
                continue
            if not (S & (1 << j)):
                continue
            
            for k in range(n):
                if S & (1 << k):
                    continue  # k 已访问
                
                new_S = S | (1 << k)
                new_dist = dp[S][j] + dist_matrix[j][k]
                
                if new_dist < dp[new_S][k]:
                    dp[new_S][k] = new_dist
                    parent[new_S][k] = j
    
    # 找到最短回路
    full_mask = (1 << n) - 1
    min_dist = INF
    last_city = -1
    
    for j in range(1, n):
        dist = dp[full_mask][j] + dist_matrix[j][0]
        if dist < min_dist:
            min_dist = dist
            last_city = j
    
    # 重建路径
    path = []
    S = full_mask
    j = last_city
    while j != -1:
        path.append(j)
        prev_j = parent[S][j]
        S ^= (1 << j)
        j = prev_j
    path.reverse()
    
    return min_dist, path

# 使用示例
dist = np.array([
    [0, 10, 15, 20],
    [10, 0, 35, 25],
    [15, 35, 0, 30],
    [20, 25, 30, 0]
])

min_dist, path = held_karp(dist)
print(f"最短距离: {min_dist}")
print(f"路径: {path}")
```

### 2.2 分支定界法

#### 2.2.1 算法思想

分支定界法通过系统地枚举所有可能的路径，利用**下界**剪枝来加速搜索。

#### 2.2.2 下界计算

常用的下界：
- **1-树下界**：最小生成树的代价加上与根节点相连的两条最小边的代价。
- **LP 松弛下界**：TSP 的线性规划松弛的最优值。

#### 2.2.3 分支策略

- **边选择分支**：对某条边 $(i,j)$，分为包含 $(i,j)$ 和不包含 $(i,j)$ 两个分支。
- **城市选择分支**：对某城市 $i$，选择其下一个访问的城市。

### 2.3 割平面法

#### 2.3.1 整数线性规划模型

TSP 的 ILP 模型（Miller-Tucker-Zemlin 约束）：

$$\min \sum_{i=1}^{n} \sum_{j=1}^{n} d_{ij} x_{ij}$$

约束条件：

$$\sum_{j=1}^{n} x_{ij} = 1, \quad \forall i$$
$$\sum_{i=1}^{n} x_{ij} = 1, \quad \forall j$$
$$x_{ij} \in \{0, 1\}, \quad \forall i, j$$

子回路消除约束：

$$u_i - u_j + n \cdot x_{ij} \leq n - 1, \quad \forall i, j \geq 2$$

#### 2.3.2 割平面

- **子回路消除割（SEC）**：消除不包含所有城市的子回路。
- **梳状割（Comb Inequalities）**：更一般的割平面。
- **双边割（Blossom Inequalities）**：处理奇数阶子图。

## 3. 近似算法
### 3.1 最近邻算法

#### 3.1.1 算法描述

从起点出发，每次选择距离当前城市最近的未访问城市，直到所有城市都被访问，最后返回起点。

#### 3.1.2 伪代码

```
算法: Nearest-Neighbor(T, s)
输入: 距离矩阵 T, 起点 s
输出: 近似回路

1:  visited = {s}
2:  current = s
3:  path = [s]
4:  while |visited| < n:
5:      j = argmin_{j ∉ visited} T[current][j]
6:      visited = visited ∪ {j}
7:      path.append(j)
8:      current = j
9:  path.append(s)
10: return path
```

#### 3.1.3 近似比

最近邻算法的近似比为 $O(\log n)$，不是常数近似。

### 3.2 Christofides 算法

#### 3.2.1 算法步骤

1. 求最小生成树 $T$。
2. 在 $T$ 的奇数度顶点集合上求最小权完美匹配 $M$。
3. 将 $T$ 和 $M$ 合并，得到一个欧拉图。
4. 在欧拉图中找欧拉回路。
5. 在欧拉回路中跳过重复访问的城市，得到 TSP 回路。

#### 3.2.2 近似比

> **定理**：对于满足三角不等式的 TSP，Christofides 算法的近似比为 $\frac{3}{2}$。

#### 3.2.3 时间复杂度

$$O(n^3)$$

### 3.3 2-近似算法

#### 3.3.1 算法步骤

1. 构建最小生成树 $T$。
2. 对 $T$ 进行深度优先遍历，得到欧拉回路。
3. 跳过重复访问的城市，得到 TSP 回路。

#### 3.3.2 近似比证明

设 TSP 最优解为 $OPT$，MST 的代价为 $|T|$。

$$|T| \leq OPT$$

欧拉回路的代价 $\leq 2|T| \leq 2 \cdot OPT$。

跳过重复城市后，由三角不等式，代价不增加。

因此近似比为 2。

### 3.4 改进的近似算法

- **Karlin-Klein-Oveis Gharan 算法**（2020）：近似比为 $1.5 - 10^{-36}$，突破了 $\frac{3}{2}$ 的障碍。

## 4. 启发式算法
### 4.1 2-opt 局部搜索

#### 4.1.1 算法思想

通过交换路径中两条不相邻的边来改进解。

设当前路径为 $\ldots \to a \to b \to \ldots \to c \to d \to \ldots$，将边 $(a,b)$ 和 $(c,d)$ 替换为 $(a,c)$ 和 $(b,d)$，反转 $b$ 到 $c$ 之间的路径。

#### 4.1.2 改进条件

若 $d_{ac} + d_{bd} < d_{ab} + d_{cd}$，则交换后路径更短。

#### 4.1.3 Python 实现

```python
def two_opt(route, dist_matrix):
    """
    2-opt 局部搜索
    route: 当前路径
    dist_matrix: 距离矩阵
    返回: 改进后的路径
    """
    n = len(route)
    improved = True
    
    while improved:
        improved = False
        for i in range(1, n - 1):
            for j in range(i + 1, n):
                # 计算改进量
                old_dist = (dist_matrix[route[i-1]][route[i]] + 
                           dist_matrix[route[j]][route[(j+1) % n]])
                new_dist = (dist_matrix[route[i-1]][route[j]] + 
                           dist_matrix[route[i]][route[(j+1) % n]])
                
                if new_dist < old_dist:
                    route[i:j+1] = reversed(route[i:j+1])
                    improved = True
    
    return route
```

### 4.3 模拟退火

#### 4.3.1 算法框架

```
算法: Simulated-Annealing(T)
输入: 初始温度 T
输出: 近似最优解

1:  S = 初始解
2:  T = T_0 (初始温度)
3:  while T > T_min:
4:      S' = 随机邻域解
5:      ΔE = cost(S') - cost(S)
6:      if ΔE < 0:
7:          S = S'
8:      else:
9:          S = S' with probability exp(-ΔE / T)
10:     T = T × α (冷却)
11: return S
```

### 4.4 遗传算法

#### 4.4.1 算法步骤

1. **编码**：使用城市排列编码。
2. **初始化**：随机生成初始种群。
3. **适应度**：$f = 1 / \text{路径总距离}$。
4. **选择**：轮盘赌选择。
5. **交叉**：顺序交叉（OX）。
6. **变异**：交换变异。
7. **精英保留**：保留最优个体。

### 4.5 蚁群算法

#### 4.5.1 算法思想

蚁群算法模拟蚂蚁觅食行为，通过信息素引导搜索。

#### 4.5.2 信息素更新

$$\tau_{ij}(t+1) = (1-\rho) \cdot \tau_{ij}(t) + \sum_{k=1}^{m} \Delta\tau_{ij}^k$$

其中：

$$\Delta\tau_{ij}^k = \begin{cases} Q / L_k, & \text{若蚂蚁 } k \text{ 经过边 } (i,j) \\ 0, & \text{否则} \end{cases}$$

#### 4.5.3 转移概率

$$p_{ij}^k = \frac{[\tau_{ij}]^\alpha \cdot [\eta_{ij}]^\beta}{\sum_{l \in \text{allowed}_k} [\tau_{il}]^\alpha \cdot [\eta_{il}]^\beta}$$

其中 $\eta_{ij} = 1/d_{ij}$ 是启发信息。

## 6. 下界方法
### 6.1 线性规划松弛

将 TSP 的 ILP 松弛为 LP，得到最优值作为下界。

### 6.2 1-树下界

1-树是包含顶点 1 的生成树加上顶点 1 的两条最短边。

### 6.3 拉格朗日松弛

通过拉格朗日松弛将子回路消除约束加入目标函数，迭代优化拉格朗日乘子来收紧下界。

## 7. 实际应用
### 7.1 物流配送

物流公司使用 TSP 算法优化配送路线，减少运输成本和时间。

### 7.2 电路板钻孔

在电路板制造中，钻孔机需要在所有孔位之间移动，TSP 模型可以最小化移动距离。

### 7.3 DNA 测序

在 DNA 序列组装中，TSP 模型可以用于确定片段的最优排列顺序。

### 7. 机器人路径规划

工业机器人在多个工作点之间的移动路径规划可以建模为 TSP。

## 8. 计算复杂性
| 变种 | 复杂性 | 说明 |
|------|--------|------|
| 对称 TSP | NP-hard | 经典问题 |
| 非对称 TSP | NP-hard | 更一般 |
| Metric TSP | NP-hard | 有近似算法 |
| 欧几里得 TSP | NP-hard | 有 PTAS |
| 线上 TSP | 无法近似 | 需要在线算法 |

## 9. 关键点总结
| 要点 | 说明 |
|------|------|
| TSP 定义 | 访问所有城市一次并回到起点的最短回路 |
| NP-hard | 目前没有多项式时间精确算法 |
| Held-Karp | $O(n^2 2^n)$ 动态规划 |
| Christofides | Metric TSP 的 $\frac{3}{2}$-近似 |
| 2-opt | 局部搜索改进 |
| 启发式 | 模拟退火、遗传、蚁群等元启发式 |
| 应用 | 物流、电路板、DNA 测序等 |
