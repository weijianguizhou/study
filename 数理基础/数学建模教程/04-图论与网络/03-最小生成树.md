# 最小生成树

## 1. 基本概念

### 1.1 树的定义

**树（Tree）** 是一个无环连通图。等价地，树 $T=(V,E)$ 满足以下性质：
- 连通且无环。
- 任意两个顶点之间有且仅有一条简单路径。
- $|E| = |V| - 1$。
- 添加任意一条不在 $E$ 中的边都会恰好产生一个环。

### 1.2 生成树

给定连通图 $G=(V,E)$，其**生成树（Spanning Tree）** 是一个子图 $T=(V,E')$，其中 $E' \subseteq E$，$T$ 是一棵包含 $G$ 所有顶点的树。

### 1.3 最小生成树

**最小生成树（Minimum Spanning Tree, MST）** 是边权之和最小的生成树。

对于连通加权无向图 $G=(V,E)$，其最小生成树 $T^*=(V,E^*)$ 满足：

$$E^* = \arg\min_{E' \in \mathcal{T}(G)} \sum_{e \in E'} w(e)$$

其中 $\mathcal{T}(G)$ 是 $G$ 所有生成树的集合。

> **定理**：若 $G$ 的所有边权互不相同，则最小生成树唯一。

### 1.4 最小生成树的性质

设 $T^*$ 是图 $G$ 的最小生成树，$e$ 是 $G$ 的一条边：

1. **切割性质**：若 $e$ 是某个切割中权值最小的边，则 $e \in T^*$。
2. **环性质**：若 $e$ 是某个环上权值最大的边，则 $e \notin T^*$。

## 2. 最小割与最大流的关系

### 2.1 切割

图 $G=(V,E)$ 的一个**切割（Cut）** 是将顶点集 $V$ 划分为两个非空子集 $S$ 和 $V-S$。切割 $(S, V-S)$ 的权值定义为：

$$w(S, V-S) = \sum_{\substack{e=(u,v) \in E \\ u \in S, v \notin V-S}} w(e)$$

### 2.2 最小割最大流定理

**最小割最大流定理**是网络流理论的基础：

> 在任意流网络中，最大流的值等于最小割的容量。

$$\max_{f} |f| = \min_{(S,T)} c(S,T)$$

## 3. Kruskal 算法

### 3.1 算法思想

Kruskal 算法是一种**贪心算法**，按边权从小到大的顺序考虑每条边，若该边连接两个不同的连通分量，则将其加入最小生成树。

### 3.2 伪代码

```
算法: Kruskal(G, w)
输入: 连通加权无向图 G=(V,E), 权重函数 w
输出: 最小生成树 T

1:  T = ∅
2:  将 E 中的边按权重从小到大排序
3:  初始化并查集，每个顶点为一个独立集合
4:  for each edge (u,v) ∈ E (按权重升序):
5:      if Find(u) ≠ Find(v):
6:          T = T ∪ {(u,v)}
7:          Union(u, v)
8:  return T
```

### 3.3 并查集

并查集（Union-Find）是 Kruskal 算法的关键数据结构，支持三个操作：

- **MakeSet(x)**：创建只包含 $x$ 的集合。
- **Find(x)**：返回 $x$ 所在集合的代表元素。
- **Union(x, y)**：合并 $x$ 和 $y$ 所在的集合。

通过**路径压缩**和**按秩合并**，并查集的均摊时间复杂度为 $O(\alpha(n))$，其中 $\alpha$ 是反阿克曼函数，实际上可视为常数。

### 3.4 时间复杂度

- 排序边：$O(|E| \log |E|)$
- 并查集操作：$O(|E| \cdot \alpha(|V|))$
- **总时间复杂度**：$O(|E| \log |E|)$

### 3.5 Python 实现

```python
class UnionFind:
    """并查集数据结构"""
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        """路径压缩的查找操作"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        """按秩合并"""
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True

def kruskal(G):
    """
    Kruskal 最小生成树算法
    G: networkx 图
    返回: 最小生成树的边列表和总权重
    """
    edges = sorted(G.edges(data=True), key=lambda x: x[2].get('weight', 1))
    uf = UnionFind(G.number_of_nodes())
    node_index = {node: i for i, node in enumerate(G.nodes())}
    
    mst_edges = []
    total_weight = 0
    
    for u, v, data in edges:
        i, j = node_index[u], node_index[v]
        if uf.union(i, j):
            mst_edges.append((u, v, data.get('weight', 1)))
            total_weight += data.get('weight', 1)
    
    return mst_edges, total_weight

# 使用示例
import networkx as nx

G = nx.Graph()
edges = [
    (0, 1, 4), (0, 2, 8), (1, 2, 11),
    (1, 3, 8), (2, 4, 7), (3, 4, 1),
    (3, 5, 4), (4, 5, 14), (5, 6, 2)
]
G.add_weighted_edges_from(edges)

mst_edges, total = kruskal(G)
print(f"MST 边: {mst_edges}")
print(f"总权重: {total}")
```

## 4. Prim 算法

### 4.1 算法思想

Prim 算法从一个顶点开始，每次添加一条连接已选顶点和未选顶点的最小权边，逐步扩展生成树。

### 4.2 伪代码

```
算法: Prim(G, w, s)
输入: 连通加权无向图 G=(V,E), 权重函数 w, 起点 s
输出: 最小生成树 T

1:  key(v) = ∞ for all v ∈ V
2:  key(s) = 0
3:  π(v) = NIL for all v ∈ V
4:  Q = V    // 优先队列
5:  while Q ≠ ∅:
6:      u = Extract-Min(Q)
7:      for each vertex v ∈ Adj(u):
8:          if v ∈ Q and w(u,v) < key(v):
9:              π(v) = u
10:             key(v) = w(u,v)
11:             Decrease-Key(Q, v, key(v))
12: return edges {(π(v), v) : v ∈ V - {s}}
```

### 4.3 时间复杂度

| 数据结构 | 时间复杂度 |
|---------|-----------|
| 数组 | $O(|V|^2)$ |
| 二叉堆 | $O((|V| + |E|) \log |V|)$ |
| 斐波那契堆 | $O(|E| + |V| \log |V|)$ |

对于**稠密图**（$|E| \approx |V|^2$），使用数组实现的 Prim 算法更高效。

### 4.4 Python 实现

```python
import heapq
import networkx as nx

def prim(G, start=None):
    """
    Prim 最小生成树算法
    G: networkx 图
    start: 起始顶点（可选）
    返回: MST 边列表和总权重
    """
    if start is None:
        start = next(iter(G.nodes()))
    
    visited = set()
    mst_edges = []
    total_weight = 0
    
    # (权重, 当前顶点, 父顶点)
    pq = [(0, start, None)]
    
    while pq and len(visited) < G.number_of_nodes():
        weight, u, parent = heapq.heappop(pq)
        
        if u in visited:
            continue
        visited.add(u)
        
        if parent is not None:
            mst_edges.append((parent, u, weight))
            total_weight += weight
        
        for v in G.neighbors(u):
            if v not in visited:
                edge_weight = G[u][v].get('weight', 1)
                heapq.heappush(pq, (edge_weight, v, u))
    
    return mst_edges, total_weight

# 使用示例
G = nx.Graph()
edges = [
    (0, 1, 2), (0, 3, 6), (1, 2, 3),
    (1, 3, 8), (1, 4, 5), (2, 4, 7),
    (3, 4, 9), (3, 5, 1), (4, 5, 4)
]
G.add_weighted_edges_from(edges)

mst_edges, total = prim(G)
print(f"MST 边: {mst_edges}")
print(f"总权重: {total}")
```

## 5. Borůvka 算法

### 5.1 算法思想

Borůvka 算法是最早的最小生成树算法之一。每轮迭代中，每个连通分量选择连接到其他分量的最小权边，将这些边加入 MST，直到只剩一个连通分量。

### 5.2 伪代码

```
算法: Borůvka(G, w)
输入: 连通加权无向图 G=(V,E)
输出: 最小生成树 T

1:  T = ∅
2:  初始化并查集，每个顶点为一个独立集合
3:  while |T| < |V| - 1:
4:      for each component C (由并查集确定):
5:          找到连接 C 和其他分量的最小权边 e_C
6:          if e_C 的两个端点属于不同分量:
7:              T = T ∪ {e_C}
8:              Union(e_C 的两个端点)
9:  return T
```

### 5.3 时间复杂度

$O(|E| \log |V|)$，每轮迭代连通分量数至少减半，共 $O(\log |V|)$ 轮。

## 6. 最小生成树的应用

### 6.1 网络设计

在通信网络、电力网络、供水网络的设计中，目标是以最小的总成本连接所有节点。MST 提供了最优解。

### 6.2 聚类分析

基于 MST 的聚类算法：
1. 构建数据点的完全图，边权为距离。
2. 计算 MST。
3. 删除 MST 中权值最大的 $k-1$ 条边，得到 $k$ 个聚类。

### 6.3 近似算法

MST 可用于求解旅行商问题（TSP）的近似解。在满足三角不等式的 TSP 中，MST 的代价是 TSP 最优解的上界，且可以构造不超过最优解 2 倍的近似解。

### 6.4 图像分割

在图像处理中，基于 MST 的方法可以用于图像分割，将图像分割为具有相似属性的区域。

### 7.2 数据压缩

**Huffman 编码**与最小生成树密切相关。在构建 Huffman 树时，每次合并频率最低的两个节点，这与 Kruskal 算法的贪心策略类似。

## 8. 特殊图类的 MST

### 8.1 完全图

$n$ 个顶点的完全图有 $\binom{n}{2}$ 条边。对于完全图，Prim 算法的时间复杂度为 $O(n^2)$，优于 Kruskal 的 $O(n^2 \log n)$。

### 8.2 稀疏图

对于边数 $|E| = O(|V|)$ 的稀疏图，Kruskal 和 Prim（使用堆）的性能相当。

### 8.3 边权范围有限

若边权为不超过 $W$ 的整数，可以使用**基数排序**将 Kruskal 算法的时间复杂度优化到 $O(|E| \cdot \alpha(|V|))$。

## 9. 算法比较

| 算法 | 时间复杂度 | 最佳场景 | 核心操作 |
|------|-----------|---------|---------|
| Kruskal | $O(|E| \log |E|)$ | 稀疏图 | 排序 + 并查集 |
| Prim（数组） | $O(|V|^2)$ | 稠密图 | 线性扫描 |
| Prim（堆） | $O((|V|+|E|) \log |V|)$ | 一般图 | 优先队列 |
| Borůvka | $O(|E| \log |V|)$ | 并行算法 | 分量合并 |

## 10. 关键点总结

| 要点 | 说明 |
|------|------|
| MST 定义 | 连通图的边权和最小的生成树 |
| 切割性质 | 跨切割的最小权边属于 MST |
| 环性质 | 环上最大权边不属于 MST |
| Kruskal | 贪心选边 + 并查集判环 |
| Prim | 逐步扩展 + 优先队列 |
| 唯一性 | 边权互不同时 MST 唯一 |
| 应用 | 网络设计、聚类、近似算法 |
