# 二部图匹配

## 1. 基本概念

### 1.1 二部图的定义

**二部图（Bipartite Graph）** $G=(V,E)$ 是一个图，其顶点集 $V$ 可以划分为两个不相交的子集 $V_1$ 和 $V_2$（$V = V_1 \cup V_2$，$V_1 \cap V_2 = \emptyset$），使得每条边的两个端点分别属于 $V_1$ 和 $V_2$。

### 1.2 匹配

图 $G=(V,E)$ 的一个**匹配（Matching）** $M \subseteq E$ 是一组两两不相邻的边，即 $M$ 中任意两条边没有公共顶点。

- **匹配数**：$|M|$，匹配中边的数量。
- **最大匹配（Maximum Matching）**：匹配数最大的匹配。
- **完美匹配（Perfect Matching）**：每个顶点都被匹配的匹配。

### 1.3 关联矩阵

二部图的邻接矩阵具有分块结构：

$$A = \begin{pmatrix} 0 & B \\ B^T & 0 \end{pmatrix}$$

其中 $B$ 是 $|V_1| \times |V_2|$ 的矩阵，$B_{ij} = 1$ 当且仅当 $V_1$ 中的第 $i$ 个顶点与 $V_2$ 中的第 $j$ 个顶点相邻。

## 2. König 定理

### 2.1 定理陈述

> **König 定理**：在二部图中，最大匹配的大小等于最小顶点覆盖的大小。

### 2.2 相关概念

- **顶点覆盖（Vertex Cover）**：顶点子集 $C \subseteq V$，使得每条边至少有一个端点在 $C$ 中。
- **最小顶点覆盖**：大小最小的顶点覆盖。

### 2.3 推论

对于二部图 $G=(V_1 \cup V_2, E)$：

$$\text{最大匹配数} = \text{最小顶点覆盖数}$$

由 König 定理和对偶关系：

$$\text{最小顶点覆盖数} + \text{最大独立集数} = |V|$$

因此：

$$\text{最大独立集数} = |V| - \text{最小顶点覆盖数} = |V| - \text{最大匹配数}$$

## 3. Hall 定理

### 3.1 定理陈述

> **Hall 定理**：二部图 $G=(V_1 \cup V_2, E)$ 存在覆盖 $V_1$ 的匹配（即 $V_1$ 中每个顶点都被匹配）的充要条件是：对任意 $S \subseteq V_1$，
> $$|N(S)| \geq |S|$$
> 其中 $N(S)$ 是 $S$ 的邻居集合。

### 3.2 推论

- $G$ 存在完美匹配的充要条件是对所有 $S \subseteq V_1$，$|N(S)| \geq |S|$，且 $|V_1| = |V_2|$。
- 若对所有 $k$-元子集 $S \subseteq V_1$，$|N(S)| \geq k + d$，则存在匹配覆盖 $V_1$ 中除最多 $d$ 个顶点外的所有顶点。

### 3.3 缺口条件

设 $G$ 是正则二部图（每个顶点的度为 $r$），则 $G$ 有完美匹配。

## 4. 匈牙利算法

### 4.1 算法思想

匈牙利算法（Hungarian Algorithm）是求解二部图最大匹配的经典算法，基于**增广路径**的思想。

### 4.2 增广路径

在匹配 $M$ 中，一条**增广路径（Augmenting Path）** 是一条从 $V_1$ 中未匹配顶点到 $V_2$ 中未匹配顶点的路径，路径上的边交替属于 $M$ 和 $E \setminus M$。

> **Berge 定理**：匹配 $M$ 是最大匹配的充要条件是不存在关于 $M$ 的增广路径。

### 4.3 交替环

**交替环（Alternating Cycle）** 是一个环，其边交替属于 $M$ 和 $E \setminus M$。

### 4.4 伪代码

```
算法: Hungarian(G)
输入: 二部图 G=(V1 ∪ V2, E)
输出: 最大匹配 M

1:  M = ∅
2:  for each vertex u ∈ V1 (未匹配):
3:      visited = {false} for all vertices
4:      DFS-Search(u)
5:  return M

函数 DFS-Search(u):
    for each vertex v ∈ Adj(u):
        if not visited[v]:
            visited[v] = true
            if v 未匹配 or DFS-Search(与 v 匹配的顶点):
                M = M ∪ {(u, v)} \ {(v, matched(v))}
                return true
    return false
```

### 4.5 时间复杂度

$$O(|V_1| \cdot |V_1| \cdot |E|) = O(|V|^2 \cdot |E|)$$

在实践中，匈牙利算法通常非常高效。

### 4.6 Python 实现

```python
class HungarianAlgorithm:
    def __init__(self, n, m):
        """
        n: V1 的大小
        m: V2 的大小
        """
        self.n = n
        self.m = m
        self.graph = [[] for _ in range(n)]
        self.match_v2 = [-1] * m  # V2 中每个顶点匹配的 V1 顶点
        self.visited = [False] * m
    
    def add_edge(self, u, v):
        """添加 V1 中顶点 u 到 V2 中顶点 v 的边"""
        self.graph[u].append(v)
    
    def dfs(self, u):
        """DFS 寻找增广路径"""
        for v in self.graph[u]:
            if not self.visited[v]:
                self.visited[v] = True
                if self.match_v2[v] == -1 or self.dfs(self.match_v2[v]):
                    self.match_v2[v] = u
                    return True
        return False
    
    def max_matching(self):
        """计算最大匹配"""
        matching_size = 0
        for u in range(self.n):
            self.visited = [False] * self.m
            if self.dfs(u):
                matching_size += 1
        return matching_size
    
    def get_matching(self):
        """获取匹配结果"""
        matching = {}
        for v in range(self.m):
            if self.match_v2[v] != -1:
                matching[self.match_v2[v]] = v
        return matching

# 使用示例
# V1 = {0, 1, 2}, V2 = {0, 1, 2}
hungarian = HungarianAlgorithm(3, 3)
hungarian.add_edge(0, 0)
hungarian.add_edge(0, 1)
hungarian.add_edge(1, 1)
hungarian.add_edge(1, 2)
hungarian.add_edge(2, 0)
hungarian.add_edge(2, 2)

print(f"最大匹配数: {hungarian.max_matching()}")
print(f"匹配: {hungarian.get_matching()}")
```

## 5. Kuhn-Munkres 算法

### 5.1 问题定义

**最优分配问题**：给定一个 $n \times n$ 的代价矩阵 $C$，找到一个一一对应 $\pi: \{1,\ldots,n\} \rightarrow \{1,\ldots,n\}$，使得总代价最小：

$$\min_{\pi} \sum_{i=1}^{n} C_{i,\pi(i)}$$

### 5.2 标号法

Kuhn-Munkres 算法（也称匈牙利算法的加权版本）通过维护**顶点标号**来求解最优分配。

设 $u_i$ 和 $v_j$ 分别是 $V_1$ 和 $V_2$ 中顶点的标号，满足 $u_i + v_j \leq c_{ij}$。

**等式子图**：由满足 $u_i + v_j = c_{ij}$ 的边构成的子图。

### 5.3 算法步骤

1. 初始化标号：$u_i = \max_j c_{ij}$，$v_j = 0$。
2. 构建等式子图。
3. 在等式子图中寻找完美匹配。
4. 若找到完美匹配，算法结束。
5. 若未找到，更新标号使等式子图中增加新的边，返回步骤 2。

### 5.4 时间复杂度

$$O(n^3)$$

## 6. 二部图匹配的应用

### 6.1 任务分配

将任务分配给工人，使得每个工人最多执行一个任务，每个任务最多由一个工人执行。

```python
def task_assignment(cost_matrix):
    """
    使用匈牙利算法求解最优任务分配
    cost_matrix: n x n 代价矩阵
    返回: 最优分配和最小总代价
    """
    from scipy.optimize import linear_sum_assignment
    import numpy as np
    
    row_ind, col_ind = linear_sum_assignment(cost_matrix)
    total_cost = cost_matrix[row_ind, col_ind].sum()
    
    assignment = list(zip(row_ind, col_ind))
    return assignment, total_cost

# 示例
cost = np.array([
    [9, 2, 7, 8],
    [6, 4, 3, 7],
    [5, 8, 1, 8],
    [7, 6, 9, 4]
])
assignment, cost = task_assignment(cost)
print(f"最优分配: {assignment}")
print(f"最小总代价: {cost}")
```

### 6.2 稳定婚姻问题

**稳定婚姻问题（Stable Marriage Problem）**：给定 $n$ 个男性和 $n$ 个女性的偏好列表，找到一个稳定匹配。

**Gale-Shapley 算法**（延迟接受算法）：

```
算法: Gale-Shapley(男性偏好, 女性偏好)
输入: 每个男性和女性的偏好列表
输出: 稳定匹配

1:  所有男性和女性都标记为"未配对"
2:  while 存在未配对的男性 m:
3:      m 向他最喜欢且尚未求婚的女性 w 求婚
4:      if w 未配对:
5:          将 m 和 w 配对
6:      else if w 已与 m' 配对且 w 更偏好 m:
7:          将 m' 标记为未配对
8:          将 m 和 w 配对
9:      else:
10:         w 拒绝 m
11: return 所有配对
```

### 6.3 学校招生

**延迟接受算法**（Gale-Shapley 的变种）在学区分配、住院医师匹配等方面有广泛应用。

### 6.4 网络匹配

在通信网络中，二部图匹配可以用于资源分配，如将用户分配到可用信道。

## 7. 二部图的最大独立集

### 7.1 定义

**独立集（Independent Set）** 是顶点子集 $I \subseteq V$，使得 $I$ 中任意两个顶点之间没有边相连。

在二部图中，由 König 定理：

$$\alpha(G) = |V| - \nu(G)$$

其中 $\alpha(G)$ 是最大独立集的大小，$\nu(G)$ 是最大匹配的大小。

## 8. 二部图的边染色

### 8.1 Vizing 定理

> **Vizing 定理**：简单图 $G$ 的边色数 $\chi'(G)$ 满足 $\Delta(G) \leq \chi'(G) \leq \Delta(G) + 1$。

对于二部图，等号成立：

$$\chi'(G) = \Delta(G)$$

即二部图的边色数等于最大度。

## 9. 实际应用案例

### 9.1 推荐系统

二部图匹配可以用于推荐系统中的匹配推荐：
- $V_1$：用户集合
- $V_2$：商品集合
- 边：用户对商品的潜在兴趣

### 9.2 生物信息学

在蛋白质相互作用网络中，二部图匹配用于：
- 蛋白质功能预测
- 药物-靶点匹配
- 基因表达分析

### 9.3 计算机视觉

在目标跟踪中，二部图匹配用于帧间数据关联：
- $V_1$：当前帧检测到的目标
- $V_2$：下一帧检测到的目标
- 边权：目标间的相似度

## 10. 关键点总结

| 要点 | 说明 |
|------|------|
| 二部图 | 顶点可二染色的图 |
| 匹配 | 两两无公共顶点的边集 |
| König 定理 | 最大匹配 = 最小顶点覆盖 |
| Hall 定理 | 完美匹配的充要条件 |
| Berge 定理 | 无增广路径 ↔ 最大匹配 |
