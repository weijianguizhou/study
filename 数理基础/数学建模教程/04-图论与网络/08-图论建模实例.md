# 图论建模实例

## 1. 引言

图论是数学建模中的重要工具，许多实际问题都可以通过构建图模型来求解。本章通过具体实例展示图论在设施选址、车辆路径、网络设计等方面的应用。

## 2. 设施选址问题

### 2.1 P-中位问题

**P-中位问题（P-Median Problem）**：给定 $n$ 个需求点和候选设施位置，选择 $p$ 个设施位置，使得所有需求点到最近设施的加权距离之和最小。

设 $x_j \in \{0,1\}$ 表示是否在位置 $j$ 建立设施，$y_{ij} \in \{0,1\}$ 表示需求点 $i$ 是否被设施 $j$ 服务。

$$\min \sum_{i=1}^{n} \sum_{j=1}^{n} w_i \cdot d_{ij} \cdot y_{ij}$$

约束条件：

$$\sum_{j=1}^{n} y_{ij} = 1, \quad \forall i$$
$$y_{ij} \leq x_j, \quad \forall i, j$$
$$\sum_{j=1}^{n} x_j = p$$

### 2.2 基于最短路径的求解

```python
import networkx as nx
import numpy as np
from itertools import combinations

def p_median_shortest_path(cities, distances, p):
    n = len(cities)
    best_cost = float('inf')
    best_facilities = None
    
    for facilities in combinations(range(n), p):
        total_cost = sum(min(distances[i][j] for j in facilities) for i in range(n))
        if total_cost < best_cost:
            best_cost = total_cost
            best_facilities = facilities
    
    return best_facilities, best_cost

cities = ['A', 'B', 'C', 'D', 'E']
distances = np.array([
    [0, 10, 15, 20, 25],
    [10, 0, 8, 12, 18],
    [15, 8, 0, 6, 14],
    [20, 12, 6, 0, 10],
    [25, 18, 14, 10, 0]
])

facilities, cost = p_median_shortest_path(cities, distances, 2)
print(f"设施位置: {[cities[i] for i in facilities]}")
print(f"最小总距离: {cost}")
```

### 2.3 P-中心问题

**P-中心问题（P-Center Problem）** 目标是最小化最大服务距离：

$$\min \max_{i} \min_{j} d_{ij} \cdot x_j$$

### 2.4 集合覆盖问题

选择最少的设施位置，使得每个需求点都被某个设施覆盖（在给定距离 $R$ 内）：

$$\min \sum_{j} x_j \quad \text{s.t.} \quad \sum_{j: d_{ij} \leq R} x_j \geq 1, \; \forall i$$

## 3. 车辆路径问题

### 3.1 问题描述

**车辆路径问题（VRP）**：给定配送中心和客户点，使用 $m$ 辆车辆配送货物，最小化总行驶距离。

### 3.2 带容量约束的 VRP (CVRP)

每辆车容量为 $Q$，客户 $i$ 需求为 $q_i$。

$$\min \sum_{k=1}^{m} \sum_{i,j} d_{ij} \cdot x_{ij}^k$$

约束：每个客户恰好被一辆车访问一次，每辆车总需求不超过容量。

### 3.3 Clarke-Wright 节约算法

```python
def clarke_wright_vrp(n_customers, distances, demands, capacity):
    savings = []
    for i in range(1, n_customers + 1):
        for j in range(i + 1, n_customers + 1):
            s = distances[0][i] + distances[0][j] - distances[i][j]
            savings.append((s, i, j))
    
    savings.sort(reverse=True)
    routes = {i: [0, i, 0] for i in range(1, n_customers + 1)}
    route_of = {i: i for i in range(1, n_customers + 1)}
    
    for s, i, j in savings:
        ri, rj = route_of[i], route_of[j]
        if ri == rj:
            continue
        total_demand = sum(demands[n] for n in routes[ri] if n != 0) + \
                       sum(demands[n] for n in routes[rj] if n != 0)
        if total_demand > capacity:
            continue
        new_route = routes[ri][:-1] + routes[rj][1:]
        for node in new_route:
            if node != 0:
                route_of[node] = ri
        routes[ri] = new_route
        del routes[rj]
    
    return routes

distances = np.array([
    [0, 10, 15, 20, 25, 30],
    [10, 0, 35, 25, 20, 15],
    [15, 35, 0, 30, 20, 25],
    [20, 25, 30, 0, 15, 10],
    [25, 20, 20, 15, 0, 35],
    [30, 15, 25, 10, 35, 0]
])
demands = [0, 5, 10, 8, 12, 6]
routes = clarke_wright_vrp(5, distances, demands, 20)
for rid, route in routes.items():
    print(f"路线 {rid}: {route}, 需求: {sum(demands[i] for i in route if i != 0)}")
```

## 4. Steiner 树问题

### 4.1 问题定义

给定图 $G=(V,E)$ 和终端集合 $R \subseteq V$，找到包含 $R$ 中所有顶点的最小权子树。

### 4.2 2-近似算法

```python
import networkx as nx

def steiner_tree_approximation(G, terminals):
    T = nx.Graph()
    for u in terminals:
        for v in terminals:
            if u != v:
                T.add_edge(u, v, weight=nx.shortest_path_length(G, u, v, weight='weight'))
    
    mst = nx.minimum_spanning_tree(T)
    steiner_tree = nx.Graph()
    for u, v in mst.edges():
        path = nx.shortest_path(G, u, v, weight='weight')
        for i in range(len(path) - 1):
            steiner_tree.add_edge(path[i], path[i+1],
                                 weight=G[path[i]][path[i+1]]['weight'])
    
    changed = True
    while changed:
        changed = False
        leaves = [n for n in steiner_tree.nodes()
                 if steiner_tree.degree(n) == 1 and n not in terminals]
        if leaves:
            steiner_tree.remove_node(leaves[0])
            changed = True
    return steiner_tree

G = nx.Graph()
edges = [(0,1,2),(0,2,3),(1,2,1),(1,3,4),(2,3,2),(2,4,3),(3,4,1),(3,5,5),(4,5,2)]
for u, v, w in edges:
    G.add_edge(u, v, weight=w)

steiner = steiner_tree_approximation(G, {0, 3, 5})
print(f"Steiner 树边: {list(steiner.edges(data=True))}")
```

## 5. 关键路径法 (CPM)

### 5.1 问题描述

**关键路径法**使用 DAG 建模项目活动，找到决定项目最短完成时间的关键路径。

### 5.2 Python 实现

```python
import networkx as nx

def critical_path(activities):
    G = nx.DiGraph()
    G.add_node('start', duration=0)
    G.add_node('end', duration=0)
    
    for name, duration, predecessors in activities:
        G.add_node(name, duration=duration)
        for pred in predecessors:
            G.add_edge(pred, name)
    
    for name, duration, predecessors in activities:
        if not predecessors:
            G.add_edge('start', name)
    
    for name, _, _ in activities:
        if not any(name in pl for _, _, pl in activities):
            G.add_edge(name, 'end')
    
    earliest = {}
    for node in nx.topological_sort(G):
        preds = list(G.predecessors(node))
        if preds:
            earliest[node] = max(earliest[p] + G.nodes[p]['duration'] for p in preds)
        else:
            earliest[node] = 0
    
    latest = {}
    for node in reversed(list(nx.topological_sort(G))):
        succs = list(G.successors(node))
        if succs:
            latest[node] = min(latest[s] - G.nodes[node]['duration'] for s in succs)
        else:
            latest[node] = earliest[node]
    
    critical = [n for n in G.nodes() if earliest[n] == latest[n] 
                and n not in ('start', 'end')]
    return critical, earliest['end']

activities = [
    ('A', 3, []), ('B', 2, []), ('C', 4, ['A']),
    ('D', 3, ['B']), ('E', 5, ['A', 'B']),
    ('F', 2, ['C', 'D']), ('G', 3, ['E', 'F'])
]

critical, duration = critical_path(activities)
print(f"关键路径: {critical}")
print(f"最短完成时间: {duration}")
```

## 6. 网络可靠性

### 6.1 问题描述

计算网络在边随机故障下保持连通的概率。

### 6.2 评估方法

- **精确计算**：枚举所有边状态，检查连通性。
- **蒙特卡洛模拟**：随机删除边，统计连通比例。
- **网络流方法**：利用最小割分析网络瓶颈。

```python
import networkx as nx
import random

def network_reliability(G, p, num_samples=10000):
    connected_count = 0
    for _ in range(num_samples):
        H = G.copy()
        edges_to_remove = [e for e in H.edges() if random.random() > p]
        H.remove_edges_from(edges_to_remove)
        if nx.is_connected(H):
            connected_count += 1
    return connected_count / num_samples

G = nx.erdos_renyi_graph(10, 0.3, seed=42)
reliability = network_reliability(G, 0.8)
print(f"网络可靠性: {reliability:.4f}")
```

## 7. 物流网络优化

### 7.1 问题描述

物流公司需要在网络中分配运输资源，同时考虑成本和时效。

### 7.2 综合模型

结合多种图论方法：
- **最短路径**：确定最优运输路线
- **最小生成树**：设计基础网络拓扑
- **最大流**：评估网络容量
- **费用流**：最小化运输成本

### 7.3 Python 实现

```python
import networkx as nx

def logistics_optimization():
    G = nx.DiGraph()
    edges = [
        ('仓库', 'A点', 100, 5),
        ('仓库', 'B点', 80, 4),
        ('A点', '客户1', 50, 3),
        ('A点', '客户2', 60, 2),
        ('B点', '客户3', 70, 3),
        ('B点', '客户1', 40, 5),
        ('客户1', '客户2', 30, 1),
        ('客户2', '客户3', 50, 2),
    ]
    for u, v, cap, cost in edges:
        G.add_edge(u, v, capacity=cap, cost=cost)
    
    # 最短路径
    path = nx.shortest_path(G, '仓库', '客户3', weight='cost')
    print(f"最低成本路径: {path}")
    
    # 最大流
    max_flow = nx.maximum_flow_value(G, '仓库', '客户3')
    print(f"最大流量: {max_flow}")
    
    return G

logistics_optimization()
```

## 8. 社交网络分析

### 8.1 关键指标

- **度中心性**：$C_D(v) = \frac{d(v)}{n-1}$
- **介数中心性**：$C_B(v) = \sum_{s \neq v \neq t} \frac{\sigma_{st}(v)}{\sigma_{st}}$
- **接近中心性**：$C_C(v) = \frac{n-1}{\sum_{u \neq v} d(v,u)}$
- **聚类系数**：$C(v) = \frac{2|E_{N(v)}|}{|N(v)|(|N(v)|-1)}$

```python
import networkx as nx

G = nx.karate_club_graph()
degree_c = nx.degree_centrality(G)
betweenness_c = nx.betweenness_centrality(G)
closeness_c = nx.closeness_centrality(G)

top_degree = sorted(degree_c.items(), key=lambda x: x[1], reverse=True)[:5]
top_betweenness = sorted(betweenness_c.items(), key=lambda x: x[1], reverse=True)[:5]

print("度中心性 Top 5:", top_degree)
print("介数中心性 Top 5:", top_betweenness)
```
