# 网络流与费用流

## 1. 网络流基础

### 1.1 流网络

**流网络** $G=(V,E)$ 是一个有向图，其中：
- 每条边 $(u,v)$ 有**容量** $c(u,v) \geq 0$。
- 每条边 $(u,v)$ 有**费用** $a(u,v)$（单位流量的费用）。
- 有一个**源点** $s$ 和一个**汇点** $t$。

### 1.2 流的定义

**流** $f$ 是一个函数 $f: V \times V \rightarrow \mathbb{R}$，满足：

1. **容量约束**：$0 \leq f(u,v) \leq c(u,v)$。
2. **流量守恒**：对所有 $v \in V \setminus \{s,t\}$，$\sum_u f(u,v) = \sum_w f(v,w)$。

### 1.3 流的值和费用

**流的值**：

$$|f| = \sum_v f(s,v) - \sum_v f(v,s)$$

**流的费用**：

$$\text{cost}(f) = \sum_{(u,v) \in E} f(u,v) \cdot a(u,v)$$

## 2. 最小费用流问题

### 2.1 问题定义

**最小费用流问题（Minimum Cost Flow Problem）**：给定流网络 $G=(V,E)$、源点 $s$、汇点 $t$ 和需求量 $d$，找到一个流 $f$ 使得：

$$\min \text{cost}(f) = \sum_{(u,v) \in E} f(u,v) \cdot a(u,v)$$

约束条件：

$$|f| = d$$

$$0 \leq f(u,v) \leq c(u,v), \quad \forall (u,v) \in E$$

$$\sum_u f(u,v) - \sum_w f(v,w) = \begin{cases} d, & v = s \\ -d, & v = t \\ 0, & \text{否则} \end{cases}$$

### 2.2 多源多汇问题

多源多汇最小费用流可以通过添加**超级源**和**超级汇**转化为单源单汇问题。

### 2.3 节点供需

每个节点 $v$ 有供需量 $b(v)$：

$$\sum_u f(u,v) - \sum_w f(v,w) = b(v)$$

其中 $b(v) > 0$ 表示供应，$b(v) < 0$ 表示需求，$\sum_v b(v) = 0$。

## 3. 连续最短增广路算法

### 3.1 算法思想

**连续最短增广路算法（Successive Shortest Path Algorithm）** 是求解最小费用流的经典算法。其核心思想：每次在残余网络中寻找**费用最小**的增广路径，增加尽可能多的流量。

### 3.2 残余网络

对于流 $f$，残余网络 $G_f$ 中每条边 $(u,v)$ 的费用为：

$$a_f(u,v) = \begin{cases} a(u,v), & \text{若 } f(u,v) < c(u,v) \\ -a(v,u), & \text{若 } f(u,v) > 0 \end{cases}$$

### 3.3 伪代码

```
算法: Successive-Shortest-Path(G, c, a, s, t, d)
输入: 流网络 G, 容量 c, 费用 a, 源点 s, 汇点 t, 需求量 d
输出: 最小费用最大流 f

1:  f = 0
2:  while |f| < d:
3:      在 G_f 中找从 s 到 t 的最短（费用最小）路径 P
4:      if P 不存在:
5:          return "不可行"
6:      Δ = min(d - |f|, min_{(u,v)∈P} c_f(u,v))
7:      沿 P 增广 Δ 的流量
8:  return f
```

### 3.4 最短路径的计算

在残余网络中，边的费用可能为负（反向边）。因此不能直接使用 Dijkstra 算法。

解决方法：
1. **Bellman-Ford**：$O(|V| \cdot |E|)$，支持负权边。
2. **势函数 + Dijkstra**：引入势函数 $h(v)$，使所有边的费用非负，然后使用 Dijkstra。

### 3.5 势函数方法

定义顶点势函数 $h(v)$，对每条边 $(u,v)$ 定义修改费用：

$$a'(u,v) = a(u,v) + h(u) - h(v)$$

**性质**：若 $h$ 满足 $a'(u,v) \geq 0$ 对所有 $(u,v) \in E_f$ 成立，则可以在修改费用上使用 Dijkstra。

**势函数更新**：$h(v) = h(v) + d(v)$，其中 $d(v)$ 是 Dijkstra 计算出的最短距离。

### 3.6 时间复杂度

$$O(d \cdot |V| \cdot |E|)$$

其中 $d$ 是需求量。

### 3.7 Python 实现

```python
import heapq
from collections import defaultdict

class MinCostFlow:
    def __init__(self, n):
        self.n = n
        self.graph = defaultdict(list)
    
    def add_edge(self, u, v, cap, cost):
        """添加边（正向和反向）"""
        self.graph[u].append([v, cap, cost, len(self.graph[v])])
        self.graph[v].append([u, 0, -cost, len(self.graph[u]) - 1])
    
    def min_cost_flow(self, s, t, max_flow):
        """
        连续最短增广路算法
        返回: (最小费用, 实际流量)
        """
        n = self.n
        prevv = [0] * n
        preve = [0] * n
        INF = float('inf')
        res = 0
        h = [0] * n  # 势函数
        flow = 0
        
        while flow < max_flow:
            # Dijkstra 找最短路径
            dist = [INF] * n
            dist[s] = 0
            pq = [(0, s)]
            
            while pq:
                d, v = heapq.heappop(pq)
                if dist[v] < d:
                    continue
                for i, (to, cap, cost, _) in enumerate(self.graph[v]):
                    if cap > 0 and dist[to] > dist[v] + cost + h[v] - h[to]:
                        dist[to] = dist[v] + cost + h[v] - h[to]
                        prevv[to] = v
                        preve[to] = i
                        heapq.heappush(pq, (dist[to], to))
            
            if dist[t] == INF:
                break  # 无法继续增广
            
            for v in range(n):
                h[v] += dist[v]
            
            # 计算增广量
            d = max_flow - flow
            v = t
            while v != s:
                d = min(d, self.graph[prevv[v]][preve[v]][1])
                v = prevv[v]
            
            flow += d
            res += d * h[t]
            
            # 更新残余网络
            v = t
            while v != s:
                e = self.graph[prevv[v]][preve[v]]
                e[1] -= d
                self.graph[v][e[3]][1] += d
                v = prevv[v]
        
        return res, flow

# 使用示例
mcf = MinCostFlow(4)
# 节点: s=0, a=1, b=2, t=3
mcf.add_edge(0, 1, 10, 2)  # s -> a, 容量 10, 费用 2
mcf.add_edge(0, 2, 8, 3)   # s -> b, 容量 8, 费用 3
mcf.add_edge(1, 2, 5, 1)   # a -> b, 容量 5, 费用 1
mcf.add_edge(1, 3, 7, 4)   # a -> t, 容量 7, 费用 4
mcf.add_edge(2, 3, 10, 2)  # b -> t, 容量 10, 费用 2

cost, flow = mcf.min_cost_flow(0, 3, 15)
print(f"最小费用: {cost}")
print(f"实际流量: {flow}")
```

## 4. 最小费用最大流

### 4.1 问题定义

**最小费用最大流（Minimum Cost Maximum Flow）** 是在所有最大流中费用最小的流。

### 4.2 与最小费用流的关系

当需求量 $d = \text{最大流的值}$ 时，最小费用流问题退化为最小费用最大流问题。

### 4.3 Python 实现

```python
def min_cost_max_flow(G, source, sink):
    """
    最小费用最大流
    G: networkx 有向图，边有 'capacity' 和 'cost' 属性
    返回: (最大流值, 最小费用)
    """
    mcf = MinCostFlow(len(G.nodes()))
    node_index = {node: i for i, node in enumerate(G.nodes())}
    
    for u, v, data in G.edges(data=True):
        mcf.add_edge(
            node_index[u], node_index[v],
            data.get('capacity', float('inf')),
            data.get('cost', 0)
        )
    
    s = node_index[source]
    t = node_index[sink]
    
    # 先计算最大流值
    # 使用简单的 BFS 或最大流算法
    max_flow = compute_max_flow(G, source, sink)
    
    cost, flow = mcf.min_cost_flow(s, t, max_flow)
    return flow, cost

def compute_max_flow(G, source, sink):
    """简单的最大流计算（用于确定需求量）"""
    from collections import deque
    
    flow = 0
    while True:
        parent = {source: None}
        queue = deque([source])
        found = False
        
        while queue:
            u = queue.popleft()
            for v in G.neighbors(u):
                cap = G[u][v].get('capacity', float('inf'))
                if v not in parent and cap > 0:
                    parent[v] = u
                    if v == sink:
                        found = True
                        break
                    queue.append(v)
        
        if not found:
            break
        
        path_flow = float('inf')
        v = sink
        while v != source:
            u = parent[v]
            path_flow = min(path_flow, G[u][v].get('capacity', float('inf')))
            v = u
        
        flow += path_flow
        v = sink
        while v != source:
            u = parent[v]
            G[u][v]['capacity'] -= path_flow
            v = u
    
    return flow
```

## 5. 最小费用循环流

### 5.1 问题定义

**最小费用循环流（Minimum Cost Circulation）** 是在不指定源点和汇点的情况下，找到使费用最小的流。

### 5.2 转化为最小费用流

通过添加一条从 $t$ 到 $s$ 的边（容量为 $\infty$，费用为 0），将最小费用流问题转化为最小费用循环流问题。

### 5.3 0-1 最小费用循环流

当所有容量为 0 或 1 时，最小费用循环流可以转化为**最小费用完美匹配**问题。

## 6. 其他网络流问题

### 6.1 最大费用最大流

将所有费用取反，转化为最小费用最大流问题。

### 6.2 有上下界的网络流

每条边 $(u,v)$ 有容量上下界 $l(u,v) \leq f(u,v) \leq c(u,v)$。

**求解方法**：
1. 引入**超级源**和**超级汇**。
2. 对每条边 $(u,v)$，设置 $c'(u,v) = c(u,v) - l(u,v)$。
3. 调整节点供需。

### 6.3 动态流

**动态流（Dynamic Flow）** 考虑边上的**传输时间**，流量在边上需要时间传播。

## 7. 费用流的对偶

### 7.1 线性规划模型

最小费用流可以表示为线性规划：

$$\min \sum_{(u,v) \in E} a(u,v) \cdot f(u,v)$$

$$\text{s.t.} \quad \sum_v f(u,v) - \sum_w f(w,u) = b(u), \quad \forall u$$

$$0 \leq f(u,v) \leq c(u,v), \quad \forall (u,v)$$

### 7.2 对偶问题

$$\max \sum_u b(u) \cdot \pi(u) - \sum_{(u,v)} c(u,v) \cdot \sigma(u,v)$$

$$\text{s.t.} \quad \pi(u) - \pi(v) - \sigma(u,v) \leq a(u,v)$$

其中 $\pi(u)$ 是节点势，$\sigma(u,v) \geq 0$ 是边的对偶变量。

### 7.3 互补松弛

在最优解处，互补松弛条件成立：

$$f(u,v) > 0 \Rightarrow \pi(u) - \pi(v) = a(u,v)$$

$$f(u,v) < c(u,v) \Rightarrow \sigma(u,v) = 0$$

## 8. 实际应用

### 8.1 交通运输

最小费用流模型可以用于：
- 公交线路规划
- 货物运输调度
- 航班调度

### 8.2 电力系统

电力网络中的经济调度问题可以建模为最小费用流问题。

### 8.3 通信网络

通信网络中的路由优化可以使用最小费用流模型。

### 8.4 供应链管理

供应链中的库存管理、运输规划等可以使用网络流模型。

## 9. 算法比较

| 算法 | 时间复杂度 | 特点 |
|------|-----------|------|
| 连续最短增广路 | $O(d \cdot |V| \cdot |E|)$ | 简单直观 |
| 原始-对偶 | $O(d \cdot |V| \cdot |E|)$ | 与连续最短路等价 |
| 消圈算法 | $O(|V| \cdot |E|^2)$ | 适用于循环流 |
| 罢工对偶 | $O(|V|^2 \cdot |E|)$ | 并行友好 |
| 网络单纯形 | $O(|V| \cdot |E| \cdot \log |V|)$ 平均 | 实践高效 |

## 10. 关键点总结

| 要点 | 说明 |
|------|------|
| 最小费用流 | 在满足流量需求下最小化总费用 |
| 费用守恒 | 费用与流量的乘积 |

| 势函数 | 将负权边转化为非负，支持 Dijkstra |
