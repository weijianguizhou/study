# 最大流问题

## 1. 问题概述

### 1.1 流网络

**流网络（Flow Network）** 是一个有向图 $G=(V,E)$，其中：
- 每条边 $(u,v)$ 有一个**容量** $c(u,v) \geq 0$。
- 有一个**源点（Source）** $s \in V$ 和一个**汇点（Sink）** $t \in V$。

### 1.2 流的定义

网络上的**流（Flow）** 是一个函数 $f: V \times V \rightarrow \mathbb{R}$，满足：

1. **容量约束**：对所有 $(u,v) \in E$，$0 \leq f(u,v) \leq c(u,v)$。
2. **流量守恒**：对所有 $v \in V \setminus \{s, t\}$，$\sum_{u} f(u,v) = \sum_{w} f(v,w)$。

### 1.3 流的值

流的值定义为从源点流出的总流量（等于流入汇点的总流量）：

$$|f| = \sum_{v \in V} f(s,v) - \sum_{v \in V} f(v,s)$$

### 1.4 问题目标

**最大流问题**：找到使 $|f|$ 最大的可行流。

## 2. 基本概念

### 2.1 残余网络

给定流 $f$，**残余网络（Residual Network）** $G_f = (V, E_f)$ 定义为：

$$E_f = \{(u,v) : c_f(u,v) > 0\}$$

其中残余容量：

$$c_f(u,v) = \begin{cases} c(u,v) - f(u,v), & (u,v) \in E \\ f(v,u), & (v,u) \in E \\ 0, & \text{否则} \end{cases}$$

### 2.2 增广路径

残余网络 $G_f$ 中从 $s$ 到 $t$ 的路径称为**增广路径（Augmenting Path）**。

增广路径的**瓶颈容量**定义为路径上残余容量的最小值：

$$\text{bottleneck}(P) = \min_{(u,v) \in P} c_f(u,v)$$

### 2.3 割

网络 $G=(V,E)$ 的一个**割（Cut）** $(S, T)$ 是将 $V$ 划分为 $S$（包含 $s$）和 $T$（包含 $t$）的划分。

割的**容量**定义为从 $S$ 到 $T$ 的所有边的容量之和：

$$c(S, T) = \sum_{\substack{(u,v) \in E \\ u \in S, v \in T}} c(u,v)$$

### 2.4 最小割

**最小割（Minimum Cut）** 是容量最小的割：

$$(S^*, T^*) = \arg\min_{(S,T)} c(S, T)$$

## 3. Ford-Fulkerson 方法

### 3.1 算法思想

Ford-Fulkerson 方法的核心思想：反复在残余网络中寻找增广路径并增加流量，直到不存在增广路径。

### 3.2 伪代码

```
算法: Ford-Fulkerson(G, c, s, t)
输入: 流网络 G, 容量函数 c, 源点 s, 汇点 t
输出: 最大流 f

1:  f(u,v) = 0 for all (u,v) ∈ E
2:  while 残余网络 G_f 中存在增广路径 P:
3:      c_f(P) = min{c_f(u,v) : (u,v) ∈ P}
4:      for each edge (u,v) ∈ P:
5:          if (u,v) ∈ E:
6:              f(u,v) = f(u,v) + c_f(P)
7:          else:
8:              f(v,u) = f(v,u) - c_f(P)
9:  return f
```

### 3.3 增广过程示例

```
初始状态:
    s --5--> a --4--> t
    s --4--> b --5--> t
    a --2--> b

残余网络中的增广路径:
路径1: s -> a -> t, 瓶颈=4, 流量增加4
路径2: s -> b -> t, 瓶颈=4, 流量增加4
路径3: s -> a -> b -> t, 瓶颈=1, 流量增加1

最大流 = 9
```

### 3.4 时间复杂度

- 若每次增广流量至少增加 1（整数容量），时间复杂度为 $O(|E| \cdot |f^*|)$，其中 $|f^*|$ 是最大流的值。
- 在一般图上，Ford-Fulkerson 方法的复杂度取决于增广路径的选择方式。

## 4. Edmonds-Karp 算法

### 4.1 算法思想

Edmonds-Karp 算法是 Ford-Fulkerson 方法的具体实现，使用 **BFS** 寻找最短增广路径（边数最少）。

### 4.2 伪代码

```
算法: Edmonds-Karp(G, c, s, t)
输入: 流网络 G, 容量函数 c, 源点 s, 汇点 t
输出: 最大流 f

1:  f(u,v) = 0 for all (u,v) ∈ E
2:  while BFS 在 G_f 中找到从 s 到 t 的最短路径 P:
3:      c_f(P) = min{c_f(u,v) : (u,v) ∈ P}
4:  沿 P 增广 c_f(P) 的流量
5:  return f
```

### 4.3 时间复杂度

$$O(|V| \cdot |E|^2)$$

**关键引理**：每次增广后，至少有一条边变为饱和边。每条边最多成为饱和边 $O(|V|)$ 次，总增广次数为 $O(|V| \cdot |E|)$。

### 4.4 Python 实现

```python
from collections import deque
import networkx as nx

def edmonds_karp(G, source, sink):
    """
    Edmonds-Karp 最大流算法
    G: networkx 有向图（边有 'capacity' 属性）
    source: 源点
    sink: 汇点
    返回: 最大流值和流字典
    """
    # 初始化流
    flow = {}
    for u, v in G.edges():
        flow[(u, v)] = 0
    
    max_flow = 0
    
    while True:
        # BFS 寻找增广路径
        parent = {source: None}
        queue = deque([source])
        found = False
        
        while queue and not found:
            u = queue.popleft()
            for v in G.neighbors(u):
                capacity = G[u][v].get('capacity', float('inf'))
                residual = capacity - flow[(u, v)]
                if v not in parent and residual > 0:
                    parent[v] = u
                    if v == sink:
                        found = True
                        break
                    queue.append(v)
        
        if not found:
            break
        
        # 计算瓶颈容量
        path_flow = float('inf')
        v = sink
        while v != source:
            u = parent[v]
            capacity = G[u][v].get('capacity', float('inf'))
            residual = capacity - flow[(u, v)]
            path_flow = min(path_flow, residual)
            v = u
        
        # 沿路径增广
        v = sink
        while v != source:
            u = parent[v]
            flow[(u, v)] += path_flow
            flow[(v, u)] -= path_flow
            v = u
        
        max_flow += path_flow
    
    return max_flow, flow

# 使用示例
G = nx.DiGraph()
edges = [
    ('s', 'a', 10), ('s', 'b', 8),
    ('a', 'b', 5), ('a', 'c', 7),
    ('b', 'd', 10), ('c', 'd', 5),
    ('c', 't', 10), ('d', 't', 7)
]
for u, v, cap in edges:
    G.add_edge(u, v, capacity=cap)

max_flow, flow = edmonds_karp(G, 's', 't')
print(f"最大流: {max_flow}")
```

## 5. Dinic 算法

### 5.1 算法思想

Dinic 算法引入**层次图**的概念，通过 BFS 构建层次图，然后在层次图中使用 DFS 寻找多条增广路径。

### 5.2 层次图

对于残余网络 $G_f$，**层次图** $L_f$ 是满足 $d(v) = d(u) + 1$ 的所有边 $(u,v)$ 构成的子图，其中 $d(v)$ 是 $v$ 到源点 $s$ 的最短距离。

### 5.3 阻塞流

在层次图中，**阻塞流（Blocking Flow）** 是不能再增广的流。Dinic 算法在每个阶段计算阻塞流。

### 5.4 伪代码

```
算法: Dinic(G, c, s, t)
输入: 流网络 G, 容量函数 c, 源点 s, 汇点 t
输出: 最大流 f

1:  f = 0
2:  while BFS 构建的层次图中 t 可达:
3:      while 存在阻塞流 g:
4:          f = f + g
5:  return f
```

### 5.5 时间复杂度

$$O(|V|^2 \cdot |E|)$$

Dinic 算法在特殊网络上的表现更优：
- **单位容量网络**：$O(\min(|V|^{2/3}, |E|^{1/2}) \cdot |E|)$
- **二部图匹配**：$O(\sqrt{|V|} \cdot |E|)$

### 5.6 Python 实现

```python
from collections import deque

class Dinic:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]
        self.level = [0] * n
        self.ptr = [0] * n
    
    def add_edge(self, u, v, capacity):
        """添加边及其反向边"""
        self.graph[u].append([v, capacity, len(self.graph[v])])
        self.graph[v].append([u, 0, len(self.graph[u]) - 1])
    
    def bfs(self, s, t):
        """BFS 构建层次图"""
        self.level = [-1] * self.n
        self.level[s] = 0
        queue = deque([s])
        
        while queue:
            u = queue.popleft()
            for v, cap, rev in self.graph[u]:
                if cap > 0 and self.level[v] == -1:
                    self.level[v] = self.level[u] + 1
                    queue.append(v)
        
        return self.level[t] != -1
    
    def dfs(self, u, t, pushed):
        """DFS 寻找阻塞流"""
        if u == t:
            return pushed
        
        for i in range(self.ptr[u], len(self.graph[u])):
            self.ptr[u] = i
            v, cap, rev = self.graph[u][i]
            
            if cap > 0 and self.level[v] == self.level[u] + 1:
                tr = self.dfs(v, t, min(pushed, cap))
                if tr > 0:
                    self.graph[u][i][1] -= tr
                    self.graph[v][rev][1] += tr
                    return tr
        
        return 0
    
    def max_flow(self, s, t):
        """计算最大流"""
        flow = 0
        while self.bfs(s, t):
            self.ptr = [0] * self.n
            while True:
                pushed = self.dfs(s, t, float('inf'))
                if pushed == 0:
                    break
                flow += pushed
        return flow

# 使用示例
dinic = Dinic(6)
# 节点编号: s=0, a=1, b=2, c=3, d=4, t=5
dinic.add_edge(0, 1, 10)
dinic.add_edge(0, 2, 8)
dinic.add_edge(1, 2, 5)
dinic.add_edge(1, 3, 7)
dinic.add_edge(2, 4, 10)
dinic.add_edge(3, 4, 5)
dinic.add_edge(3, 5, 10)
dinic.add_edge(4, 5, 7)

print(f"最大流: {dinic.max_flow(0, 5)}")
```

## 6. 最小割最大流定理

### 6.1 定理陈述

> **最小割最大流定理**：在任意流网络中，以下三个条件等价：
> 1. $f$ 是最大流。
> 2. 残余网络 $G_f$ 中不存在增广路径。
> 3. 存在割 $(S, T)$ 使得 $|f| = c(S, T)$。

### 6.2 证明思路

$$|f| = \sum_{v \in V} f(s,v) - \sum_{v \in V} f(v,s)$$

对于任意割 $(S, T)$：

$$|f| = \sum_{\substack{(u,v) \in E \\ u \in S, v \in T}} f(u,v) - \sum_{\substack{(u,v) \in E \\ u \in T, v \in S}} f(u,v)$$

由于 $0 \leq f(u,v) \leq c(u,v)$：

$$|f| \leq \sum_{\substack{(u,v) \in E \\ u \in S, v \in T}} c(u,v) = c(S, T)$$

因此 $|f| \leq c(S, T)$ 对所有割成立。

### 6.3 如何找到最小割

在最大流 $f$ 对应的残余网络 $G_f$ 中：
- $S$ = 从 $s$ 可达的所有顶点。
- $T = V \setminus S$。

$(S, T)$ 即为最小割。

### 6.4 Python 实现最小割

```python
from collections import deque

def find_min_cut(G, source, sink, max_flow_func):
    """
    找到最小割
    返回: (S, T, min_cut_capacity)
    """
    # 先计算最大流
    max_flow, flow = max_flow_func(G, source, sink)
    
    # BFS 找从 source 可达的顶点
    visited = set()
    queue = deque([source])
    visited.add(source)
    
    while queue:
        u = queue.popleft()
        for v in G.neighbors(u):
            capacity = G[u][v].get('capacity', float('inf'))
            residual = capacity - flow.get((u, v), 0)
            if v not in visited and residual > 0:
                visited.add(v)
                queue.append(v)
    
    S = visited
    T = set(G.nodes()) - S
    
    # 计算最小割容量
    min_cut_cap = 0
    for u in S:
        for v in T:
            if G.has_edge(u, v):
                min_cut_cap += G[u][v].get('capacity', 0)
    
    return S, T, min_cut_cap
```

## 7. 多源多汇问题

### 7.1 超级源和超级汇

对于多源多汇问题，可以添加**超级源** $s^*$ 和**超级汇** $t^*$：

1. 从 $s^*$ 到每个源点 $s_i$ 添加容量为 $\infty$ 的边。
2. 从每个汇点 $t_j$ 到 $t^*$ 添加容量为 $\infty$ 的边。
3. 在新网络上求解单源单汇最大流问题。

### 7.2 节点容量

若顶点也有容量限制，可以将每个顶点 $v$ 拆分为两个顶点 $v_{in}$ 和 $v_{out}$，并添加容量为节点容量的边 $(v_{in}, v_{out})$。

## 8. 应用场景

### 8.1 二部图最大匹配

最大流可以用于求解二部图最大匹配：构建源点到左侧顶点、右侧顶点到汇点的边（容量为 1），以及二部图中的边（容量为 1）。

### 8.2 网络可靠性

通过最小割分析网络的可靠性：最小割越小，网络越脆弱。

### 8.3 图像分割

图像分割可以建模为最小割问题（s-t cut），使用最大流算法求解。

### 8.4 项目选择

最大闭合子图问题可以转化为最大流问题求解。

## 9. 算法比较

| 算法 | 时间复杂度 | 特点 |
|------|-----------|------|
| Ford-Fulkerson | $O(\|E\| \cdot \|f^*\|)$ | 依赖增广路径选择 |
| Edmonds-Karp | $O(\|V\| \cdot \|E\|^2)$ | BFS 找最短增广路径 |
| Dinic | $O(\|V\|^2 \cdot \|E\|)$ | 层次图 + 阻塞流 |
| Push-Relabel | $O(\|V\|^2 \cdot \|E\|)$ 或 $O(\|V\|^3)$ | 预流推进 |
| ISAP | $O(\|V\|^2 \cdot \|E\|)$ | 改进的最短增广路 |

## 10. 关键点总结

| 要点 | 说明 |
|------|------|
| 流网络 | 有向图 + 容量限制 + 源点/汇点 |
| 流守恒 | 中间节点流入 = 流出 |
| 残余网络 | 反映可调整的流量空间 |
| 增广路径 | 残余网络中的 $s$-$t$ 路径 |
| 最小割最大流定理 | 最大流 = 最小割 |
| Ford-Fulkerson | 反复增广直到无增广路径 |
| Dinic | 层次图 + 多路增广 |
