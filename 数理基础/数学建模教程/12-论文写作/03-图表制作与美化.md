# 图表制作与美化指南

## 一、图表在论文中的作用

图表是数学建模论文中不可或缺的组成部分，其主要作用包括：

1. **直观展示数据**：将枯燥的数字转化为可视化的图形
2. **辅助模型说明**：帮助读者理解模型结构和求解过程
3. **增强说服力**：用图表佐证分析结论
4. **提高论文质量**：美观规范的图表体现专业水平

---

## 二、图表规范总则

### 2.1 编号规则

- 图片编号：图 1、图 2、图 3……（在图的**下方**标注）
- 表格编号：表 1、表 2、表 3……（在表的**上方**标注）
- 公式编号：(1)、(2)、(3)……（在公式的**右侧**标注）
- 编号应连续，全文统一

### 2.2 标题格式

- 图表标题应**简洁明确**，能独立说明图表内容
- 标题字体一般为**五号宋体**
- 标题与图表之间留适当间距

### 2.3 分辨率要求

- 屏幕显示：72–150 dpi
- 打印输出：300 dpi 以上
- 推荐使用矢量图（PDF、SVG）以保证缩放清晰

## 三、使用 Matplotlib 制作图表

### 3.1 基础设置与中文字体

```python
import matplotlib.pyplot as plt
import matplotlib
import numpy as np

# Windows 中文字体设置
matplotlib.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
matplotlib.rcParams['axes.unicode_minus'] = False  # 解决负号显示问题

# 全局样式设置
plt.rcParams['figure.dpi'] = 150
plt.rcParams['savefig.dpi'] = 300
plt.rcParams['figure.figsize'] = (8, 5)
plt.rcParams['font.size'] = 12
```

### 3.2 折线图

```python
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)
y3 = np.sin(x) * np.exp(-0.1 * x)

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, y1, color='#E63946', linewidth=2, label=r'$\sin(x)$', linestyle='-')
ax.plot(x, y2, color='#457B9D', linewidth=2, label=r'$\cos(x)$', linestyle='--')
ax.plot(x, y3, color='#2A9D8F', linewidth=2, label=r'$\sin(x) \cdot e^{-0.1x}$', linestyle='-.')

ax.set_xlabel('时间 $t$', fontsize=13)
ax.set_ylabel('幅值', fontsize=13)
ax.set_title('三角函数及其衰减曲线', fontsize=14, fontweight='bold')
ax.legend(loc='upper right', fontsize=11)
ax.grid(True, linestyle='--', alpha=0.6)
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)

plt.tight_layout()
plt.savefig('fig1_line.pdf', bbox_inches='tight')
plt.show()
```

### 3.3 散点图与回归线

```python
np.random.seed(42)
n = 50
x = np.random.uniform(0, 10, n)
y = 2.5 * x + 3 + np.random.normal(0, 2, n)

# 线性回归
coeffs = np.polyfit(x, y, 1)
y_fit = np.polyval(coeffs, x)

fig, ax = plt.subplots(figsize=(7, 5))
ax.scatter(x, y, c='#264653', s=40, alpha=0.7, edgecolors='white',
           linewidths=0.5, label='观测数据')
ax.plot(np.sort(x), y_fit[np.argsort(x)], color='#E76F51', linewidth=2,
        label=f'拟合直线: $y = {coeffs[0]:.2f}x + {coeffs[1]:.2f}$')

ax.set_xlabel('$x$', fontsize=13)
ax.set_ylabel('$y$', fontsize=13)
ax.set_title('散点图与线性回归', fontsize=14, fontweight='bold')
ax.legend(fontsize=11)
ax.grid(True, linestyle='--', alpha=0.4)

plt.tight_layout()
plt.savefig('fig2_scatter.pdf', bbox_inches='tight')
plt.show()
```

### 3.4 柱状图

```python
categories = ['方法 A', '方法 B', '方法 C', '方法 D', '方法 E']
```

## 四、表格制作规范

### 4.1 LaTeX 表格基础

```latex
% 基本三线表
\begin{table}[htbp]
\centering
\caption{模型求解结果}
\begin{tabular}{lcc}
\toprule
方法 & 准确率 (\%) & 运行时间 (s) \\
\midrule
方法 A & 92.3 & 1.25 \\
方法 B & 87.6 & 0.89 \\
方法 C & 95.1 & 2.34 \\
\bottomrule
\end{tabular}
\label{tab:result}
\end{table}
```

### 4.2 带合并单元格的表格

```latex
\begin{table}[htbp]
\centering
\caption{多行表头示例}
\begin{tabular}{lccc}
\toprule
\multirow{2}{*}{年份} & \multicolumn{2}{c}{产量} & \multirow{2}{*}{增长率} \\
\cmidrule(lr){2-3}
& 东部 & 西部 & \\
\midrule
2020 & 1200 & 800 & 5.2\% \\
2021 & 1350 & 950 & 12.5\% \\
2022 & 1500 & 1100 & 11.1\% \\
\bottomrule
\end{tabular}
\end{table}
```

需要在导言区引入 `\usepackage{multirow}` 和 `\usepackage{booktabs}`。

### 4.3 Python 生成表格

```python
import pandas as pd

data = {
    '模型': ['线性回归', '决策树', '随机森林', 'SVM', '神经网络'],
    '训练集准确率': ['93.2%', '98.5%', '97.8%', '94.1%', '99.2%'],
    '测试集准确率': ['91.5%', '88.3%', '93.6%', '92.7%', '91.8%'],
    '训练时间 (s)': [0.5, 1.2, 15.3, 8.7, 45.2]
}
df = pd.DataFrame(data)
print(df.to_latex(index=False, caption='不同模型的性能对比'))
```

### 4.4 表格排版要点

1. **三线表**：顶线（`\toprule`）、栏目线（`\midrule`）、底线（`\bottomrule`），无竖线
2. **数字对齐**：小数点对齐，整数右对齐
3. **单位标注**：在表头中标注单位，如"时间 (s)"
4. **脚注说明**：用 `\multicolumn` 或脚注符号补充说明
5. **避免换行**：尽量让内容在单元格内不换行

## 五、流程图与示意图

### 5.1 使用 tikz 绘制流程图

```latex
\usepackage{tikz}
\usetikzlibrary{shapes, arrows, positioning}

\begin{tikzpicture}[
    node distance=1.5cm,
    startstop/.style={rectangle, rounded corners, minimum width=3cm,
                      minimum height=1cm, text centered, draw=black, fill=red!30},
    process/.style={rectangle, minimum width=3cm, minimum height=1cm,
                    text centered, draw=black, fill=blue!30},
    decision/.style={diamond, minimum width=3cm, minimum height=1cm,
                     text centered, draw=black, fill=green!30},
    arrow/.style={thick,->,>=stealth}
]
\node (start) [startstop] {开始};
\node (pro1) [process, below of=start] {数据预处理};
\node (dec1) [decision, below of=pro1, yshift=-0.5cm] {数据完整?};
\node (pro2) [process, below of=dec1, yshift=-0.5cm] {建立模型};
\node (pro3) [process, right of=dec1, xshift=3cm] {补全缺失值};
\node (end) [startstop, below of=pro2] {结束};

\draw [arrow] (start) -- (pro1);
\draw [arrow] (pro1) -- (dec1);
\draw [arrow] (dec1) -- node[anchor=east] {是} (pro2);
\draw [arrow] (dec1) -- node[anchor=south] {否} (pro3);
\draw [arrow] (pro3) |- (pro1);
\draw [arrow] (pro2) -- (end);
\end{tikzpicture}
```

### 5.2 Python 绘制流程图（networkx）

```python
import networkx as nx

G = nx.DiGraph()
nodes = ['开始', '数据清洗', '特征工程', '模型训练', '模型评估', '输出结果']
G.add_nodes_from(nodes)
edges = [('开始', '数据清洗'), ('数据清洗', '特征工程'),
         ('特征工程', '模型训练'), ('模型训练', '模型评估'),
         ('模型评估', '输出结果')]
G.add_edges_from(edges)

pos = nx.spring_layout(G, seed=42)
plt.figure(figsize=(10, 4))
nx.draw(G, pos, with_labels=True, node_color='#457B9D', node_size=2500,
        font_size=11, font_color='white', font_weight='bold',
        arrows=True, arrowsize=20, edge_color='#264653', width=2)
plt.title('建模流程图', fontsize=14, fontweight='bold')
plt.tight_layout()
plt.savefig('fig7_flowchart.pdf', bbox_inches='tight')
plt.show()
```

## 六、配色方案推荐

### 6.1 学术配色（色盲友好）

```python
# 推荐学术配色方案
colors_qualitative = ['#264653', '#2A9D8F', '#E9C46A', '#F4A261', '#E76F51']
colors_diverging  = ['#457B9D', '#F1FAEE', '#E63946']
colors_sequential = ['#F1FAEE', '#A8DADC', '#457B9D', '#1D3557']
```

### 6.2 配色原则

1. **一致性**：全篇图表使用统一的配色方案
2. **可区分性**：不同数据系列颜色差异明显
3. **色盲友好**：避免仅用红绿区分
4. **打印友好**：考虑黑白打印时的可辨识度
5. **简洁美观**：避免使用过多颜色（一般不超过 6 种）

## 七、图表常见问题与优化

### 7.1 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 图片模糊 | 分辨率过低 | 使用 300 dpi 或矢量格式 |
| 坐标轴标签重叠 | 标签过长 | 旋转标签或增加图幅宽度 |
| 图例遮挡数据 | 图例位置不当 | 移动图例到空白区域 |
| 中文显示方框 | 缺少中文字体 | 设置 `rcParams['font.sans-serif']` |
| 表格竖线过多 | 使用了竖线 | 改用三线表 |
| 公式符号不统一 | 图表与正文不一致 | 统一变量符号 |

### 7.2 优化建议

1. **使用矢量图**：PDF、SVG 格式在任何缩放比例下都清晰
2. **保持高对比度**：确保文字、线条在背景上清晰可见
3. **添加网格线**：适量的网格线有助于读取数据
4. **标注关键数据**：在图上直接标注重要数值
5. **统一字体大小**：图中文字一般不小于 10pt

---

## 八、关键要点总结

1. **图表编号连续**，标题位于图下表上
2. **优先使用矢量图**（PDF），保证打印质量
3. **中文字体设置**是 matplotlib 绘图的第一步
4. **三线表**是学术论文表格的标准格式
5. **配色方案**全篇统一，色盲友好，不超过 6 种主色
6. **子图**使用 `subplots` 统一布局，添加子图编号
7. **流程图**使用 tikz 或专业工具绘制，逻辑清晰
8. **图例**位置合理，不遮挡数据
9. **坐标轴标签**完整，包含变量名和单位
10. **图表要能独立阅读**，不依赖正文即可理解
