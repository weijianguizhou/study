# 粒子群算法详解

## 一、概述

粒子群优化算法（Particle Swarm Optimization, PSO）是由 Kennedy 和 Eberhart 于 1995 年提出的一种群体智能优化算法。其灵感来源于鸟群觅食行为：鸟群在搜索食物时，每只鸟根据自身经验和群体经验调整飞行方向和速度。

PSO 算法具有概念简单、参数少、易于实现等优点，已广泛应用于函数优化、神经网络训练、工程优化等领域。

## 二、生物学背景

### 2.1 鸟群觅食模型

考虑一个鸟群在区域中搜索食物的场景：

1. 每只鸟不知道食物在哪里，但知道当前位置距离食物有多远
2. 每只鸟记住自己曾经找到的离食物最近的位置
3. 每只鸟知道整个鸟群中谁曾经找到的离食物最近

通过综合利用这三条信息，鸟群能够高效地找到食物。

### 2.2 社会行为模拟

PSO 模拟了以下社会行为：

- **个体认知**：粒子根据自身历史经验调整行为
- **社会学习**：粒子根据群体历史经验调整行为
- **信息共享**：群体中的信息通过最优位置传播

## 三、算法原理

### 3.1 基本 PSO

在 $D$ 维搜索空间中，第 $i$ 个粒子的位置和速度分别为：

$$\mathbf{x}_i = (x_{i1}, x_{i2}, \ldots, x_{iD})$$
$$\mathbf{v}_i = (v_{i1}, v_{i2}, \ldots, v_{iD})$$

粒子的速度和位置更新公式为：

$$\mathbf{v}_i^{t+1} = \mathbf{v}_i^t + c_1 r_1 (\mathbf{p}_i^t - \mathbf{x}_i^t) + c_2 r_2 (\mathbf{g}^t - \mathbf{x}_i^t)$$

$$\mathbf{x}_i^{t+1} = \mathbf{x}_i^t + \mathbf{v}_i^{t+1}$$

其中：
- $\mathbf{p}_i^t$：粒子 $i$ 的个体最优位置（pbest）
- $\mathbf{g}^t$：群体最优位置（gbest）
- $c_1$：认知学习因子（个体经验权重）
- $c_2$：社会学习因子（群体经验权重）
- $r_1, r_2 \sim U(0, 1)$：随机数

### 3.2 速度更新的三部分

速度更新公式可以分解为三部分：

$$\mathbf{v}_i^{t+1} = \underbrace{\mathbf{v}_i^t}_{\text{惯性部分}} + \underbrace{c_1 r_1 (\mathbf{p}_i^t - \mathbf{x}_i^t)}_{\text{认知部分}} + \underbrace{c_2 r_2 (\mathbf{g}^t - \mathbf{x}_i^t)}_{\text{社会部分}}$$

**惯性部分**：保持粒子原来的运动趋势，体现粒子的"惯性"

**认知部分**：向个体最优位置移动，体现粒子的"自我学习"

**社会部分**：向群体最优位置移动，体现粒子的"社会学习"

### 3.3 带惯性权重的 PSO

Shi 和 Eberhart 于 1998 年引入了惯性权重 $w$：

$$\mathbf{v}_i^{t+1} = w \cdot \mathbf{v}_i^t + c_1 r_1 (\mathbf{p}_i^t - \mathbf{x}_i^t) + c_2 r_2 (\mathbf{g}^t - \mathbf{x}_i^t)$$

惯性权重 $w$ 控制粒子对前一速度的继承程度：
- $w$ 较大：全局探索能力强
- $w$ 较小：局部开发能力强

### 3.4 收敛系数 PSO（Clerc）

Clerc 提出了收缩因子法，保证算法收敛：

$$\mathbf{v}_i^{t+1} = \chi \left[\mathbf{v}_i^t + c_1 r_1 (\mathbf{p}_i^t - \mathbf{x}_i^t) + c_2 r_2 (\mathbf{g}^t - \mathbf{x}_i^t)\right]$$

其中收缩因子：

$$\chi = \frac{2}{|2 - \varphi - \sqrt{\varphi^2 - 4\varphi}|}$$

$\varphi = c_1 + c_2$，通常取 $\varphi > 4$（如 $c_1 = c_2 = 2.05$，则 $\varphi = 4.1$，$\chi \approx 0.729$）。

## 四、拓扑结构

### 4.1 全局拓扑（gbest）

所有粒子相互连接，每个粒子都向全局最优学习：

- 优点：信息传播快，收敛速度快
- 缺点：容易过早收敛（Premature Convergence）

### 4.2 局部拓扑（lbest）

每个粒子只与其邻域内的粒子交互：

$$\mathbf{v}_i^{t+1} = w \cdot \mathbf{v}_i^t + c_1 r_1 (\mathbf{p}_i^t - \mathbf{x}_i^t) + c_2 r_2 (\mathbf{l}_i^t - \mathbf{x}_i^t)$$

其中 $\mathbf{l}_i^t$ 为粒子 $i$ 邻域内的最优位置。

常见邻域结构：
- **环形拓扑**：每个粒子与左右各 $k$ 个粒子相连
- **星形拓扑**：每个粒子与中心粒子相连
- **冯·诺依曼拓扑**：网格结构，每个粒子与上下左右的粒子相连

### 4.3 拓扑对算法的影响

| 拓扑类型 | 信息传播速度 | 探索能力 | 收敛速度 |
|---------|------------|---------|---------|
| 全局（gbest） | 快 | 弱 | 快 |
| 局部（lbest） | 慢 | 强 | 慢 |
| 自适应 | 中 | 中 | 中 |

### 4.4 动态拓扑

为平衡探索与开发，可动态调整拓扑结构：

- **随机拓扑**：定期重新随机分配邻域
- **进化拓扑**：根据粒子间的相似度动态调整邻域
- **时间递减拓扑**：初期使用局部拓扑，后期切换为全局拓扑

## 五、参数设置

### 5.1 惯性权重

**固定权重**：$w$ 取常数，通常 $w \in [0.4, 0.9]$

**线性递减权重**：

$$w(t) = w_{\max} - \frac{(w_{\max} - w_{\min}) \cdot t}{T_{\max}}$$

通常 $w_{\max} = 0.9$，$w_{\min} = 0.4$。

**自适应权重**：根据搜索状态动态调整 $w$

$$w(t) = w_0 + \alpha \cdot \frac{\sigma_g}{\sigma_g + \sigma_p}$$

其中 $\sigma_g$ 和 $\sigma_p$ 分别为全局和个体最优的多样性指标。

### 5.2 学习因子

**对称设置**：$c_1 = c_2$，通常取 $c_1 = c_2 = 2.0$

**非对称设置**：
- $c_1 > c_2$：强调个体认知，有利于探索
- $c_1 < c_2$：强调社会学习，有利于开发

**时变设置**：
$$c_1(t) = c_{1,\max} - \frac{(c_{1,\max} - c_{1,\min}) \cdot t}{T_{\max}}$$
$$c_2(t) = c_{2,\min} + \frac{(c_{2,\max} - c_{2,\min}) \cdot t}{T_{\max}}$$

### 5.3 种群规模

种群规模 $N$ 通常取 $N \in [20, 50]$：
- $N$ 过小：搜索不充分
- $N$ 过大：计算量增加，但不一定提高解质量

### 5.4 速度限制

为防止粒子飞出搜索空间，需要限制速度：

$$v_{i,d} = \begin{cases} v_{\max} & \text{if } v_{i,d} > v_{\max} \\ -v_{\max} & \text{if } v_{i,d} < -v_{\max} \end{cases}$$

通常 $v_{\max}$ 取搜索空间范围的 $10\%-20\%$。

## 六、算法流程

```
算法：粒子群优化（PSO）
输入：目标函数 f(x)，搜索空间维度 D
输出：最优解 x*

1. 初始化参数：w, c1, c2, N, T_max, v_max
2. 初始化粒子群：
   随机生成粒子位置 x_i ~ U(lb, ub)
   随机生成粒子速度 v_i ~ U(-v_max, v_max)
3. 评估每个粒子的适应度 f(x_i)
4. 初始化个体最优 p_i = x_i
5. 初始化全局最优 g = argmin f(x_i)
6. for t = 1 to T_max do
7.     for each particle i do
8.         更新速度：v_i = w*v_i + c1*r1*(p_i-x_i) + c2*r2*(g-x_i)
9.         限制速度：v_i = clip(v_i, -v_max, v_max)
10.        更新位置：x_i = x_i + v_i
11.        限制位置：x_i = clip(x_i, lb, ub)
12.        评估适应度 f(x_i)
13.        if f(x_i) < f(p_i) then
14.            p_i = x_i
15.        if f(x_i) < f(g) then
16.            g = x_i
17.    更新惯性权重 w
18. end for
19. return g
```

## 七、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from typing import Callable, List, Tuple

class PSO:
    def __init__(self,
                 obj_func: Callable,
                 bounds: List[Tuple[float, float]],
                 pop_size: int = 30,
                 max_iter: int = 500,
                 w: float = 0.729,
                 c1: float = 2.05,
                 c2: float = 2.05,
                 v_max_ratio: float = 0.2,
                 w_mode: str = 'fixed'):
        self.obj_func = obj_func
        self.bounds = np.array(bounds)
        self.dim = len(bounds)
        self.pop_size = pop_size
        self.max_iter = max_iter
        self.w_init = w
        self.c1 = c1
        self.c2 = c2
        self.lb = self.bounds[:, 0]
        self.ub = self.bounds[:, 1]
        self.v_max = v_max_ratio * (self.ub - self.lb)
        self.w_mode = w_mode
        
        self.positions = None
        self.velocities = None
        self.pbest_positions = None
        self.pbest_values = None
        self.gbest_position = None
        self.gbest_value = np.inf
        self.history = []
        
    def initialize(self):
        self.positions = np.random.uniform(self.lb, self.ub, (self.pop_size, self.dim))
        self.velocities = np.random.uniform(-self.v_max, self.v_max, (self.pop_size, self.dim))
        
        self.pbest_positions = self.positions.copy()
        self.pbest_values = np.full(self.pop_size, np.inf)
        
        for i in range(self.pop_size):
            fitness = self.obj_func(self.positions[i])
            if fitness < self.pbest_values[i]:
                self.pbest_values[i] = fitness
                self.pbest_positions[i] = self.positions[i].copy()
                if fitness < self.gbest_value:
                    self.gbest_value = fitness
                    self.gbest_position = self.positions[i].copy()
    
    def get_inertia_weight(self, t: int) -> float:
        if self.w_mode == 'fixed':
            return self.w_init
        elif self.w_mode == 'linear':
            w_min, w_max = 0.4, 0.9
            return w_max - (w_max - w_min) * t / self.max_iter
        elif self.w_mode == 'adaptive':
            diversity = np.mean(np.std(self.positions, axis=0))
            return 0.5 + diversity / (np.max(self.ub - self.lb))
    
    def optimize(self) -> Tuple[np.ndarray, float]:
        self.initialize()
        
        for t in range(self.max_iter):
            w = self.get_inertia_weight(t)
            
            for i in range(self.pop_size):
                r1 = np.random.random(self.dim)
                r2 = np.random.random(self.dim)
                
                cognitive = self.c1 * r1 * (self.pbest_positions[i] - self.positions[i])
                social = self.c2 * r2 * (self.gbest_position - self.positions[i])
                
                self.velocities[i] = w * self.velocities[i] + cognitive + social
                self.velocities[i] = np.clip(self.velocities[i], -self.v_max, self.v_max)
                
                self.positions[i] += self.velocities[i]
                self.positions[i] = np.clip(self.positions[i], self.lb, self.ub)
                
                fitness = self.obj_func(self.positions[i])
                
                if fitness < self.pbest_values[i]:
                    self.pbest_values[i] = fitness
                    self.pbest_positions[i] = self.positions[i].copy()
                    
                    if fitness < self.gbest_value:
                        self.gbest_value = fitness
                        self.gbest_position = self.positions[i].copy()
            
            self.history.append(self.gbest_value)
            
        return self.gbest_position, self.gbest_value


def sphere(x):
    return sum(xi**2 for xi in x)


def rosenbrock(x):
    return sum(100*(x[i+1]-x[i]**2)**2 + (1-x[i])**2 for i in range(len(x)-1))


if __name__ == "__main__":
    bounds = [(-10, 10)] * 5
    pso = PSO(sphere, bounds, pop_size=30, max_iter=300, w_mode='linear')
    best_sol, best_val = pso.optimize()
    
    print(f"最优解: {best_sol}")
    print(f"最优值: {best_val}")
    
    plt.figure(figsize=(10, 6))
    plt.semilogy(pso.history)
    plt.xlabel('迭代次数')
    plt.ylabel('最优值 (log scale)')
    plt.title('PSO 收敛曲线')
    plt.grid(True)
    plt.show()
```

## 八、收敛性分析

### 8.1 简化模型分析

忽略随机性，PSO 的确定性行为可以表示为：

$$\mathbf{v}^{t+1} = w \mathbf{v}^t + c_1 (\mathbf{p} - \mathbf{x}^t) + c_2 (\mathbf{g} - \mathbf{x}^t)$$
$$\mathbf{x}^{t+1} = \mathbf{x}^t + \mathbf{v}^{t+1}$$

设 $\boldsymbol{\phi} = c_1 + c_2$，$\mathbf{p}^* = \frac{c_1 \mathbf{p} + c_2 \mathbf{g}}{c_1 + c_2}$，则：

$$\mathbf{x}^{t+1} = (1 + \phi) \mathbf{x}^t + w \mathbf{v}^t - \phi \mathbf{p}^*$$

### 8.2 收敛条件

PSO 收敛的充分条件为：

$$w < 1, \quad \phi > 0, \quad 2w > \phi - 2$$

或者等价地：
$$\phi < 2(1 + w)$$

### 8.3 稳定点分析

PSO 的稳定点（不动点）为：

$$\mathbf{x}^* = \mathbf{p}^* = \frac{c_1 \mathbf{p} + c_2 \mathbf{g}}{c_1 + c_2}$$

当算法收敛时，所有粒子都趋向于这个加权平均位置。

### 8.4 早熟收敛

PSO 容易出现早熟收敛现象，即所有粒子过早地聚集在某个非最优位置附近。原因包括：

1. 粒子速度过早衰减到零
2. 全局最优陷入局部最优
3. 种群多样性丧失

## 九、改进 PSO 变体

### 9.1 自适应 PSO

根据搜索状态自适应调整参数：

$$w = w_0 \cdot (1 - \frac{t}{T_{\max}}) + 0.4 \cdot \frac{t}{T_{\max}}$$

$$c_1 = c_1^{\max} - (c_1^{\max} - c_1^{\min}) \cdot \frac{t}{T_{\max}}$$

$$c_2 = c_2^{\min} + (c_2^{\max} - c_2^{\min}) \cdot \frac{t}{T_{\max}}$$

### 9.2 混沌 PSO

使用混沌序列替代随机数，增强搜索的遍历性：

$$r_i(t) = 4 \cdot r_i(t-1) \cdot (1 - r_i(t-1))$$

### 9.3 变异 PSO

引入变异操作维持种群多样性：

$$x_{i,d}^{t+1} = \begin{cases} x_{i,d}^{t+1} & \text{if } \rho > p_m \\ x_{\min,d} + r \cdot (x_{\max,d} - x_{\min,d}) & \text{if } \rho \leq p_m \end{cases}$$

### 9.4 多群 PSO

将种群分为多个子群，每个子群独立优化，定期交换信息：

$$\text{SubSwarm}_k: \quad \mathbf{g}_k = \text{local\_best}(\text{SubSwarm}_k)$$
$$\text{Global}: \quad \mathbf{g} = \arg\min_k f(\mathbf{g}_k)$$

## 十、与 GA 的比较

| 特性 | PSO | GA |
|------|-----|-----|
| 信息共享 | 通过全局最优 | 通过选择/交叉 |
| 个体记忆 | 有（pbest） | 无 |
| 算子 | 速度更新 | 选择、交叉、变异 |
| 参数数量 | 少 | 多 |
| 实现难度 | 简单 | 中等 |
| 收敛速度 | 快 | 中等 |
| 全局搜索 | 中等 | 强 |

## 十一、关键要点总结

1. **惯性权重是关键**：$w$ 控制探索与开发的平衡
2. **学习因子选择**：$c_1 = c_2 = 2.0$ 是常用设置
3. **速度限制**：防止粒子飞出搜索空间
4. **拓扑结构影响**：全局拓扑收敛快但易早熟，局部拓扑探索强但收敛慢
5. **参数自适应**：根据搜索阶段动态调整参数可提高性能
6. **种群多样性**：避免早熟收敛的关键
7. **初始化策略**：均匀初始化有助于覆盖搜索空间
8. **终止准则**：最大迭代次数或适应度停滞
9. **适用范围**：PSO 特别适合连续优化问题
10. **并行化**：PSO 天然适合并行计算
