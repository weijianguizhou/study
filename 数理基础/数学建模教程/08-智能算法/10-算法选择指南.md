# 算法选择指南

## 一、概述

智能算法的选择是数学建模和工程优化中的关键问题。不同的算法适用于不同类型的问题，没有一种算法能够在所有问题上都表现最佳（No Free Lunch 定理）。本文从多个维度对常用智能算法进行比较，为算法选择提供系统化的指导。

## 四、问题类型与算法匹配

### 4.1 连续优化问题

**低维问题（$D < 10$）**：

推荐算法：PSO, DE, CS

$$\min f(\mathbf{x}), \quad \mathbf{x} \in \mathbb{R}^D, \quad D < 10$$

理由：问题简单，快速收敛的算法更合适。

**高维问题（$D \geq 10$）**：

推荐算法：DE, ABC, CS

$$\min f(\mathbf{x}), \quad \mathbf{x} \in \mathbb{R}^D, \quad D \geq 10$$

理由：高维空间需要强全局搜索能力的算法。

**大规模问题（$D \geq 100$）**：

推荐算法：L-SHADE, CLPSO, CMA-ES

理由：需要自适应参数和维度处理能力。

### 4.2 组合优化问题

**旅行商问题（TSP）**：

推荐算法：ACO, TS, VNS

$$\min \sum_{i=1}^{n} d(\pi_i, \pi_{i+1})$$

理由：ACO 天然适合路径优化，TS 和 VNS 有强大的局部搜索能力。

**调度问题**：

推荐算法：GA, TS, VNS

$$\min C_{\max} \quad \text{or} \quad \min \sum C_i$$

理由：GA 的编码灵活性好，TS 和 VNS 适合邻域搜索。

**车辆路径问题（VRP）**：

推荐算法：ACO, GA, TS

理由：ACO 适合路径构建，GA 适合组合编码，TS 适合局部优化。

### 4.3 约束优化问题

推荐算法：GA, DE, SA

处理策略：
1. 罚函数法：将约束违反量加入目标函数
2. 可行域保持法：确保搜索在可行域内进行
3. 混合方法：结合罚函数和可行域保持

$$\min f(\mathbf{x}) + \alpha \cdot \max\{0, g(\mathbf{x})\}$$

### 4.4 多目标优化问题

推荐算法：NSGA-II, MOEA/D, MOPSO

$$\min \mathbf{F}(\mathbf{x}) = (f_1(\mathbf{x}), f_2(\mathbf{x}), \ldots, f_m(\mathbf{x}))$$

关键概念：Pareto 最优、拥挤度距离、分解方法

### 4.5 动态优化问题

推荐算法：动态 PSO, 动态 GA, 适应性 ACO

关键策略：
1. 种群多样性维持
2. 记忆机制
3. 响应性调整

## 五、算法选择决策树

```
开始
├── 问题类型？
│   ├── 连续优化
│   │   ├── 低维（D<10）→ PSO 或 DE
│   │   ├── 中维（10≤D<100）→ DE 或 ABC
│   │   └── 高维（D≥100）→ L-SHADE 或 CMA-ES
│   ├── 组合优化
│   │   ├── 路径问题 → ACO
│   │   ├── 调度问题 → GA + TS
│   │   └── 分配问题 → GA 或 ACO
│   ├── 约束优化 → GA 或 DE（带罚函数）
│   └── 多目标优化 → NSGA-II 或 MOEA/D
├── 计算资源？
│   ├── 有限 → PSO 或 DE
│   └── 充足 → GA 或 ACO
├── 精度要求？
│   ├── 高 → SA 或 VNS（混合使用）
│   └── 中 → PSO 或 DE
└── 实时性要求？
    ├── 是 → PSO 或 DE
    └── 否 → 任意算法
```

## 六、混合策略

### 6.1 全局-局部混合

将全局搜索算法与局部搜索算法结合：

$$\text{混合算法} = \text{全局搜索（GA/PSO/DE）} + \text{局部搜索（TS/VNS/SA）}$$

**Memetic Algorithm**：GA + 局部搜索

**PSO + SA**：PSO 全局搜索 + SA 局部优化

### 6.2 多算法协同

使用多种算法协同搜索：

$$\text{结果} = \text{合并(Algorithm}_1, \text{Algorithm}_2, \ldots, \text{Algorithm}_k)$$

**自适应选择**：根据搜索状态选择最合适的算法

### 6.3 序列混合

先用一种算法进行粗搜索，再用另一种算法精搜索：

$$\mathbf{x}_{\text{final}} = \text{FineSearch}(\text{CoarseSearch}(\mathbf{x}_0))$$

## 七、Python 实现：统一接口

```python
import numpy as np
from typing import Callable, List, Tuple, Dict
from abc import ABC, abstractmethod

class Optimizer(ABC):
    @abstractmethod
    def optimize(self) -> Tuple[np.ndarray, float]:
        pass

class PSO(Optimizer):
    def __init__(self, func, bounds, N=30, T=300, w=0.729, c1=2.05, c2=2.05):
        self.func = func
        self.bounds = np.array(bounds)
        self.N, self.T, self.w, self.c1, self.c2 = N, T, w, c1, c2
        self.lb, self.ub = self.bounds[:, 0], self.bounds[:, 1]
        self.dim = len(bounds)

    def optimize(self):
        X = np.random.uniform(self.lb, self.ub, (self.N, self.dim))
        V = np.random.uniform(-(self.ub-self.lb)*0.2, (self.ub-self.lb)*0.2, (self.N, self.dim))
        pbest = X.copy()
        pbest_val = np.array([self.func(x) for x in X])
        gbest = pbest[np.argmin(pbest_val)]
        gbest_val = np.min(pbest_val)
        for _ in range(self.T):
            r1, r2 = np.random.random((self.N, self.dim)), np.random.random((self.N, self.dim))
            V = self.w*V + self.c1*r1*(pbest-X) + self.c2*r2*(gbest-X)
            X = np.clip(X + V, self.lb, self.ub)
            val = np.array([self.func(x) for x in X])
            better = val < pbest_val
            pbest[better] = X[better]
            pbest_val[better] = val[better]
            if np.min(val) < gbest_val:
                gbest = X[np.argmin(val)].copy()
                gbest_val = np.min(val)
        return gbest, gbest_val

class DE(Optimizer):
    def __init__(self, func, bounds, N=50, T=300, F=0.8, CR=0.2):
        self.func = func
        self.bounds = np.array(bounds)
        self.N, self.T, self.F, self.CR = N, T, F, CR
        self.lb, self.ub = self.bounds[:, 0], self.bounds[:, 1]
        self.dim = len(bounds)

    def optimize(self):
        X = np.random.uniform(self.lb, self.ub, (self.N, self.dim))
        val = np.array([self.func(x) for x in X])
        for _ in range(self.T):
            for i in range(self.N):
                idxs = [j for j in range(self.N) if j != i]
                r1, r2, r3 = np.random.choice(idxs, 3, replace=False)
                mutant = np.clip(X[r1] + self.F*(X[r2]-X[r3]), self.lb, self.ub)
                cross = np.random.random(self.dim) < self.CR
                j_rand = np.random.randint(self.dim)
                cross[j_rand] = True
                trial = np.where(cross, mutant, X[i])
                trial_val = self.func(trial)
                if trial_val <= val[i]:
                    X[i] = trial
                    val[i] = trial_val
        best_idx = np.argmin(val)
        return X[best_idx], val[best_idx]

class SA(Optimizer):
    def __init__(self, func, bounds, T0=100, T_min=1e-8, alpha=0.95, L=100):
        self.func = func
        self.bounds = np.array(bounds)
        self.T0, self.T_min, self.alpha, self.L = T0, T_min, alpha, L
        self.lb, self.ub = self.bounds[:, 0], self.bounds[:, 1]
        self.dim = len(bounds)

    def optimize(self):
        x = np.random.uniform(self.lb, self.ub, self.dim)
        best_x, best_val = x.copy(), self.func(x)
        T = self.T0
        while T > self.T_min:
            for _ in range(self.L):
                neighbor = x + np.random.normal(0, 0.1*(self.ub-self.lb)*(T/self.T0))
                neighbor = np.clip(neighbor, self.lb, self.ub)
                dv = self.func(neighbor) - self.func(x)
                if dv < 0 or np.random.random() < np.exp(-dv/T):
                    x = neighbor
                if self.func(x) < best_val:
                    best_x, best_val = x.copy(), self.func(x)
            T *= self.alpha
        return best_x, best_val


def compare_algorithms(func, bounds, n_runs=5):
    algorithms = {
        'PSO': PSO(func, bounds),
        'DE': DE(func, bounds),
        'SA': SA(func, bounds),
    }
    results = {}
    for name, algo in algorithms.items():
        vals = []
        for _ in range(n_runs):
            _, val = algo.optimize()
            vals.append(val)
        results[name] = {'mean': np.mean(vals), 'std': np.std(vals), 'min': np.min(vals)}
    return results


if __name__ == "__main__":
    def sphere(x):
        return sum(xi**2 for xi in x)

    bounds = [(-10, 10)] * 5
    results = compare_algorithms(sphere, bounds, n_runs=5)

    print("算法比较结果：")
    print(f"{'算法':<8} {'平均值':<15} {'标准差':<15} {'最优值':<15}")
    print("-" * 53)
    for name, res in results.items():
        print(f"{name:<8} {res['mean']:<15.6e} {res['std']:<15.6e} {res['min']:<15.6e}")
```

## 八、性能指标

### 8.1 收敛性指标

**成功率**：
$$\text{SR} = \frac{\text{成功运行次数}}{\text{总运行次数}} \times 100\%$$

**收敛精度**：
$$\text{精度} = |f(\mathbf{x}^*) - f(\mathbf{x}_{\text{opt}})|$$

### 8.2 效率指标

**平均收敛代数**：
$$\text{ACG} = \frac{1}{R} \sum_{r=1}^{R} t_r$$

其中 $t_r$ 为第 $r$ 次运行首次达到目标精度的迭代次数。

**计算时间**：
$$\text{CPU Time} = \frac{1}{R} \sum_{r=1}^{R} \text{time}_r$$

### 8.3 鲁棒性指标

**标准差**：
$$\sigma = \sqrt{\frac{1}{R-1} \sum_{r=1}^{R} (f_r - \bar{f})^2}$$

**四分位距**：
$$\text{IQR} = Q_3 - Q_1$$

## 九、基准测试函数

### 9.1 单峰函数

**Sphere 函数**：
$$f_1(\mathbf{x}) = \sum_{i=1}^{D} x_i^2$$

**Rosenbrock 函数**：
$$f_2(\mathbf{x}) = \sum_{i=1}^{D-1} [100(x_{i+1} - x_i^2)^2 + (1-x_i)^2]$$

**Schwefel 函数**：
$$f_3(\mathbf{x}) = \sum_{i=1}^{D} |x_i| + \prod_{i=1}^{D} |x_i|$$

### 9.2 多峰函数

**Rastringin 函数**：
$$f_4(\mathbf{x}) = 10D + \sum_{i=1}^{D} [x_i^2 - 10\cos(2\pi x_i)]$$

**Ackley 函数**：
$$f_5(\mathbf{x}) = -20\exp\left(-0.2\sqrt{\frac{1}{D}\sum_{i=1}^{D}x_i^2}\right) - \exp\left(\frac{1}{D}\sum_{i=1}^{D}\cos(2\pi x_i)\right) + 20 + e$$

**Griewank 函数**：
$$f_6(\mathbf{x}) = 1 + \frac{1}{4000}\sum_{i=1}^{D}x_i^2 - \prod_{i=1}^{D}\cos\left(\frac{x_i}{\sqrt{i}}\right)$$

### 9.3 函数特性与算法推荐

| 函数类型 | 特征 | 推荐算法 |
|---------|------|---------|
| 单峰 | 无局部最优 | DE, PSO |
| 多峰 | 多个局部最优 | CS, ABC, GA |
| 高维 | 维度高 | L-SHADE, CMA-ES |
| 噪声 | 目标函数有噪声 | PSO, DE |
| 非凸 | 搜索空间不规则 | GA, SA |

## 十、实际应用建议

### 10.1 建模竞赛

在数学建模竞赛中，算法选择建议：

1. **时间充裕**：使用混合算法（如 GA + TS）
2. **时间紧张**：使用参数少的算法（如 PSO 或 DE）
3. **组合优化**：优先考虑 ACO 或 TS
4. **连续优化**：优先考虑 DE 或 PSO

### 10.2 工程优化

1. **函数评估昂贵**：使用代理模型辅助优化
2. **实时优化**：使用 PSO 或 DE
3. **多目标优化**：使用 NSGA-II 或 MOEA/D
4. **约束优化**：使用 GA 或 DE（带罚函数）

### 10.3 参数调优建议

1. **先用默认参数**：大多数算法的默认参数已经过调优
2. **逐步调整**：一次只调整一个参数
3. **多次运行**：取平均值评估参数效果
4. **使用自适应版本**：如 JADE、SHADE、自适应 PSO

## 十一、关键要点总结

1. **No Free Lunch**：没有一种算法在所有问题上都是最优的
2. **问题分析优先**：先分析问题特点，再选择算法
3. **连续优化**：DE 是首选，PSO 和 CS 也是好选择
4. **组合优化**：ACO 和 TS 是首选，VNS 也是好选择
5. **混合策略**：全局搜索 + 局部搜索通常效果最好
6. **参数调优**：参数对算法性能影响显著
7. **多次运行**：随机算法需要多次运行取平均
8. **基准测试**：在标准函数上测试算法性能
9. **实际应用**：根据实际约束（时间、资源）选择算法
10. **持续学习**：关注最新的算法改进和新算法
