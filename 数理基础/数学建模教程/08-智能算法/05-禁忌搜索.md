# 禁忌搜索详解

## 一、概述

禁忌搜索（Tabu Search, TS）是由 Glover 于 1986 年提出的一种元启发式优化算法。其核心思想是通过引入"禁忌表"来避免搜索过程陷入局部最优或出现循环，同时通过"特赦准则"在适当时候允许禁忌移动。

TS 是一种确定性的邻域搜索算法，与 GA、PSO 等随机搜索算法不同，TS 在每一步都选择邻域中的最优解（即使该解比当前解差），从而具有较强的局部搜索能力。

## 二、基本概念

### 2.1 搜索空间

设问题的解空间为 $\mathcal{S}$，当前解为 $\mathbf{x} \in \mathcal{S}$。邻域函数 $N: \mathcal{S} \to 2^{\mathcal{S}}$ 将当前解映射到一组邻域解：

$$N(\mathbf{x}) = \{\mathbf{x}_1', \mathbf{x}_2', \ldots, \mathbf{x}_m'\}$$

### 2.2 移动（Move）

从当前解 $\mathbf{x}$ 到邻域解 $\mathbf{x}'$ 的转换称为一个移动，记为 $m(\mathbf{x}, \mathbf{x}')$。

移动的评价函数为：

$$\Delta(\mathbf{x}, \mathbf{x}') = f(\mathbf{x}') - f(\mathbf{x})$$

- $\Delta < 0$：改善移动
- $\Delta > 0$：劣化移动
- $\Delta = 0$：中性移动

### 2.3 禁忌表（Tabu List）

禁忌表记录了最近进行过的移动，禁止在一定期限内重复这些移动。禁忌表的长度 $L$ 称为禁忌长度（Tabu Tenure）。

$$TL = \{(m_t, \text{expiry}_t) | t = 1, 2, \ldots, L\}$$

### 2.4 特赦准则（Aspiration Criteria）

当某个禁忌移动满足特赦准则时，可以被允许执行。常用的特赦准则包括：

1. **基于目标值的特赦**：如果禁忌移动能产生新的全局最优解
2. **基于方向的特赦**：如果禁忌移动的方向与全局最优方向一致
3. **基于频率的特赦**：如果某个移动被禁忌的次数超过阈值

## 三、算法流程

```
算法：禁忌搜索（TS）
输入：目标函数 f(x)，初始解 x_0，邻域结构 N，禁忌长度 L
输出：最优解 x*

1. 初始化：x = x_0, x_best = x_0, TL = ∅
2. while 未满足停止准则 do
3.     生成邻域解集 N(x)
4.     for each x' ∈ N(x) do
5.         if x' ∉ TL or Aspiration(x') then
6.             评估 Δ(x, x')
7.     end for
8.     选择最优的非禁忌邻域解 x* = argmin Δ(x, x')
9.     执行移动：x = x*
10.    更新禁忌表 TL
11.    if f(x) < f(x_best) then
12.        x_best = x
13. end while
14. return x_best
```

## 四、禁忌表管理

### 4.1 固定禁忌长度

禁忌长度 $L$ 固定不变，通常取：

$$L = \sqrt{n}$$

其中 $n$ 为问题规模。

### 4.2 动态禁忌长度

禁忌长度根据搜索状态动态调整：

$$L_t = \begin{cases} L_{\min} & \text{if 搜索进展顺利} \\ L_{\max} & \text{if 搜索停滞} \end{cases}$$

### 4.3 频率记忆

记录每个移动被禁忌的次数，用于指导禁忌长度的调整：

$$\text{freq}(m) = \text{移动 } m \text{ 被禁忌的次数}$$

### 4.4 禁忌表的更新策略

**先进先出（FIFO）**：最早加入禁忌表的移动最先被移除

**基于到期时间**：每个移动有一个到期时间，到期后自动移除

**自适应更新**：根据搜索状态动态调整禁忌表的内容

## 五、邻域结构

### 5.1 TSP 问题的邻域

**2-opt 邻域**：反转两个城市之间的路径段

$$\pi' = \text{reverse}(\pi, i, j)$$

路径长度变化：

$$\Delta = d(\pi_{i-1}, \pi_j) + d(\pi_i, \pi_{j+1}) - d(\pi_{i-1}, \pi_i) - d(\pi_j, \pi_{j+1})$$

**or-opt 邻域**：将一段子路径移动到另一个位置

$$\pi' = \text{relocate}(\pi, i, j, k)$$

**3-opt 邻域**：同时反转三个路径段，更复杂但搜索更充分

### 5.2 作业调度问题的邻域

**交换邻域**：交换两个作业的顺序

**插入邻域**：将一个作业插入到另一个位置

**反转邻域**：反转一段作业序列

### 5.3 连续优化问题的邻域

**高斯邻域**：
$$\mathbf{x}' = \mathbf{x} + \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})$$

**坐标轮换邻域**：每次只改变一个坐标

$$\mathbf{x}' = \mathbf{x} + \delta \cdot \mathbf{e}_i$$

## 六、特赦准则详解

### 6.1 绝对特赦

如果禁忌移动能产生全局最优解，则允许执行：

$$\text{Aspiration}(\mathbf{x}') = \begin{cases} \text{True} & \text{if } f(\mathbf{x}') < f(\mathbf{x}_{\text{best}}) \\ \text{False} & \text{otherwise} \end{cases}$$

### 6.2 相对特赦

如果禁忌移动的目标值优于邻域中非禁忌解的目标值，则允许执行：

$$\text{Aspiration}(\mathbf{x}') = \begin{cases} \text{True} & \text{if } f(\mathbf{x}') < f(\mathbf{x}_{\text{best\_non\_tabu}}) \\ \text{False} & \text{otherwise} \end{cases}$$

### 6.3 基于频率的特赦

如果某个移动被禁忌的次数超过阈值，则允许执行：

$$\text{Aspiration}(\mathbf{x}') = \begin{cases} \text{True} & \text{if freq}(m) > F_{\max} \\ \text{False} & \text{otherwise} \end{cases}$$

### 6.4 多准则特赦

综合多个准则进行判断：

$$\text{Aspiration}(\mathbf{x}') = \bigvee_{i=1}^{k} C_i(\mathbf{x}')$$

## 七、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from typing import List, Tuple, Callable

class TabuSearch:
    def __init__(self,
                 obj_func: Callable,
                 bounds: List[Tuple[float, float]],
                 tabu_tenure: int = 10,
                 neighborhood_size: int = 50,
                 max_iter: int = 500,
                 aspiration: bool = True):
        self.obj_func = obj_func
        self.bounds = np.array(bounds)
        self.dim = len(bounds)
        self.tabu_tenure = tabu_tenure
        self.neighborhood_size = neighborhood_size
        self.max_iter = max_iter
        self.aspiration = aspiration
        self.lb = self.bounds[:, 0]
        self.ub = self.bounds[:, 1]
        
        self.best_solution = None
        self.best_value = np.inf
        self.history = []
        
    def initialize(self) -> np.ndarray:
        return np.random.uniform(self.lb, self.ub, self.dim)
    
    def generate_neighbors(self, x: np.ndarray) -> np.ndarray:
        neighbors = np.zeros((self.neighborhood_size, self.dim))
        for i in range(self.neighborhood_size):
            step = (self.ub - self.lb) * 0.1
            perturbation = np.random.uniform(-step, step, self.dim)
            neighbor = x + perturbation
            neighbor = np.clip(neighbor, self.lb, self.ub)
            neighbors[i] = neighbor
        return neighbors
    
    def move_signature(self, x_old: np.ndarray, x_new: np.ndarray) -> str:
        diff = np.round(x_new - x_old, 4)
        return str(diff.tolist())
    
    def optimize(self) -> Tuple[np.ndarray, float]:
        current = self.initialize()
        current_value = self.obj_func(current)
        self.best_solution = current.copy()
        self.best_value = current_value
        
        tabu_list = {}
        
        for iteration in range(self.max_iter):
            neighbors = self.generate_neighbors(current)
            
            best_neighbor = None
            best_neighbor_value = np.inf
            best_move = None
            
            for i in range(self.neighborhood_size):
                neighbor = neighbors[i]
                neighbor_value = self.obj_func(neighbor)
                move = self.move_signature(current, neighbor)
                
                is_tabu = move in tabu_list and tabu_list[move] > iteration
                is_aspiration = (self.aspiration and 
                                neighbor_value < self.best_value)
                
                if (not is_tabu or is_aspiration):
                    if neighbor_value < best_neighbor_value:
                        best_neighbor = neighbor
                        best_neighbor_value = neighbor_value
                        best_move = move
            
            if best_neighbor is None:
                non_tabu_neighbors = []
                for i in range(self.neighborhood_size):
                    neighbor = neighbors[i]
                    move = self.move_signature(current, neighbor)
                    is_tabu = move in tabu_list and tabu_list[move] > iteration
                    if not is_tabu:
                        non_tabu_neighbors.append((neighbor, self.obj_func(neighbor)))
                
                if non_tabu_neighbors:
                    best_neighbor, best_neighbor_value = min(non_tabu_neighbors, key=lambda x: x[1])
                    best_move = self.move_signature(current, best_neighbor)
                else:
                    continue
            
            current = best_neighbor
            current_value = best_neighbor_value
            
            if best_move:
                tabu_list[best_move] = iteration + self.tabu_tenure
            
            expired = [m for m, exp in tabu_list.items() if exp <= iteration]
            for m in expired:
                del tabu_list[m]
            
            if current_value < self.best_value:
                self.best_value = current_value
                self.best_solution = current.copy()
            
            self.history.append(self.best_value)
            
        return self.best_solution, self.best_value


def six_hump_camel_back(x):
    return ((4 - 2.1*x[0]**2 + x[0]**4/3) * x[0]**2 + 
            x[0]*x[1] + (-4 + 4*x[1]**2) * x[1]**2)


if __name__ == "__main__":
    bounds = [(-3, 3), (-2, 2)]
    ts = TabuSearch(six_hump_camel_back, bounds, tabu_tenure=15, 
                    neighborhood_size=50, max_iter=200)
    best_sol, best_val = ts.optimize()
    
    print(f"最优解: {best_sol}")
    print(f"最优值: {best_val}")
    
    plt.figure(figsize=(10, 6))
    plt.plot(ts.history)
    plt.xlabel('迭代次数')
    plt.ylabel('目标函数值')
    plt.title('禁忌搜索收敛曲线')
    plt.grid(True)
    plt.show()
```

## 八、收敛性分析

### 8.1 理论收敛条件

TS 在以下条件下具有有限收敛性：

1. 解空间有限
2. 邻域结构能到达所有解
3. 禁忌表长度有限

**定理**：TS 在有限解空间上，如果邻域结构是强连通的（即从任意解出发，有限步内可达任意其他解），则 TS 最终会访问所有解。

### 8.2 收敛速度

TS 的收敛速度取决于：
- 邻域大小 $|N(\mathbf{x})|$
- 禁忌长度 $L$
- 特赦准则的有效性

### 8.3 与局部搜索的比较

TS 通过禁忌机制避免了简单局部搜索的循环问题：

| 特性 | 简单局部搜索 | 禁忌搜索 |
|------|------------|---------|
| 循环问题 | 有 | 无 |
| 解质量 | 局部最优 | 接近全局最优 |
| 计算开销 | 低 | 中 |
| 鲁棒性 | 弱 | 强 |

## 九、高级策略

### 9.1 分层禁忌搜索（Hierarchical TS）

使用多层禁忌表管理不同类型的移动：

$$TL = \{TL_1, TL_2, \ldots, TL_k\}$$

每层管理不同类型或不同粒度的移动。

### 9.2 自适应禁忌搜索

根据搜索状态动态调整禁忌策略：

- **搜索进展快**：减少禁忌长度，加快搜索
- **搜索停滞**：增加禁忌长度，扩大搜索范围

### 9.3 长期记忆

记录搜索历史中的频率信息，用于指导搜索方向：

$$\text{freq}_{ij} = \text{边 } (i,j) \text{ 在历史解中出现的次数}$$

频率信息可以用于：
- 调整邻域结构
- 修改禁忌策略
- 引导搜索方向

### 9.4 多起点禁忌搜索

从多个初始点运行 TS，取最优解：

$$\mathbf{x}_{\text{best}} = \arg\min_{k} f(\mathbf{x}_k^*)$$

## 十一、关键要点总结

1. **禁忌表是核心**：避免搜索陷入局部最优或循环
2. **特赦准则**：在适当时候允许禁忌移动，避免错过优质解
3. **禁忌长度选择**：过短易循环，过长失去灵活性
4. **邻域结构**：好的邻域结构是 TS 成功的关键
5. **确定性搜索**：TS 每步选择最优非禁忌解
6. **内存利用**：TS 利用搜索历史指导搜索方向
7. **参数少**：主要参数为禁忌长度和邻域大小
8. **组合优化首选**：TS 特别适合 TSP、调度等组合优化问题
9. **与其他方法结合**：TS 可与 GA、SA 等结合形成混合算法
10. **局部搜索增强**：TS 是对简单局部搜索的重要改进
