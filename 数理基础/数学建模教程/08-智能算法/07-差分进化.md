# 差分进化详解

## 一、概述

差分进化（Differential Evolution, DE）是由 Storn 和 Price 于 1995 年提出的一种基于种群的全局优化算法。DE 的核心思想是通过个体间的差分向量来实现变异操作，具有结构简单、参数少、鲁棒性强等优点。

DE 特别适合解决连续优化问题，已在工程优化、机器学习、信号处理等领域得到广泛应用。

## 二、算法原理

### 2.1 基本思想

DE 的核心思想是利用种群中个体间的差分信息来引导搜索：

$$\mathbf{v}_i = \mathbf{x}_{r1} + F \cdot (\mathbf{x}_{r2} - \mathbf{x}_{r3})$$

其中 $r1, r2, r3$ 为互不相同的随机索引，$F \in [0, 2]$ 为缩放因子。

### 2.2 差分向量的作用

差分向量 $\mathbf{d} = \mathbf{x}_{r2} - \mathbf{x}_{r3}$ 提供了以下信息：

1. **搜索方向**：差分向量指向种群分布的方向
2. **搜索步长**：差分向量的大小自适应于种群的分散程度
3. **自适应性**：随着种群的进化，差分向量自动调整

### 2.3 变异策略

DE 的变异策略通常记为 `DE/x/y/z`，其中：
- `x`：基向量的选择方式（rand/best）
- `y`：差分向量的数量
- `z`：交叉策略（bin/exp）

## 三、DE 算法流程

### 3.1 基本 DE（DE/rand/1/bin）

```
算法：差分进化（DE/rand/1/bin）
输入：目标函数 f(x)，搜索空间维度 D，种群大小 N，最大迭代次数 T
输出：最优解 x*

1. 初始化：
   随机生成种群 P = {x_1, x_2, ..., x_N}
   评估每个个体的适应度 f(x_i)
2. for t = 1 to T do
3.     for each xi ∈ P do
4.         变异：v_i = x_r1 + F * (x_r2 - x_r3)
5.         交叉：u_i = Crossover(x_i, v_i)
6.         选择：if f(u_i) ≤ f(x_i) then x_i = u_i
7.     end for
8. end for
9. return 全局最优解
```

### 3.2 变异操作

**DE/rand/1**：

$$\mathbf{v}_i = \mathbf{x}_{r1} + F \cdot (\mathbf{x}_{r2} - \mathbf{x}_{r3})$$

**DE/rand/2**：

$$\mathbf{v}_i = \mathbf{x}_{r1} + F \cdot (\mathbf{x}_{r2} - \mathbf{x}_{r3}) + F \cdot (\mathbf{x}_{r4} - \mathbf{x}_{r5})$$

**DE/best/1**：

$$\mathbf{v}_i = \mathbf{x}_{\text{best}} + F \cdot (\mathbf{x}_{r1} - \mathbf{x}_{r2})$$

**DE/best/2**：

$$\mathbf{v}_i = \mathbf{x}_{\text{best}} + F \cdot (\mathbf{x}_{r1} - \mathbf{x}_{r2}) + F \cdot (\mathbf{x}_{r3} - \mathbf{x}_{r4})$$

**DE/current-to-best/1**：

$$\mathbf{v}_i = \mathbf{x}_i + F \cdot (\mathbf{x}_{\text{best}} - \mathbf{x}_i) + F \cdot (\mathbf{x}_{r1} - \mathbf{x}_{r2})$$

### 3.3 交叉操作

**二项交叉（Binomial Crossover）**：

$$u_{i,j} = \begin{cases} v_{i,j} & \text{if } r_j \leq CR \text{ or } j = j_{\text{rand}} \\ x_{i,j} & \text{otherwise} \end{cases}$$

其中 $r_j \sim U(0,1)$，$j_{\text{rand}}$ 为随机选择的维度索引（确保至少有一个维度来自变异向量）。

**指数交叉（Exponential Crossover）**：

从随机维度 $j$ 开始，连续选择 $L$ 个维度来自变异向量：

$$u_{i,j} = \begin{cases} v_{i,j} & \text{if } j \in [j, j+L-1] \mod D \\ x_{i,j} & \text{otherwise} \end{cases}$$

其中 $L$ 由交叉概率 $CR$ 决定。

### 3.4 选择操作

DE 使用贪婪选择策略：

$$\mathbf{x}_i^{t+1} = \begin{cases} \mathbf{u}_i & \text{if } f(\mathbf{u}_i) \leq f(\mathbf{x}_i^t) \\ \mathbf{x}_i^t & \text{otherwise} \end{cases}$$

## 四、参数设置

### 4.1 缩放因子 $F$

$F$ 控制差分向量的缩放程度，通常取 $F \in [0.4, 1.0]$。

- $F$ 过小：搜索步长小，容易陷入局部最优
- $F$ 过大：搜索步长过大，收敛速度慢

### 4.2 交叉概率 $CR$

$CR$ 控制交叉操作中变异向量的维度比例，通常取 $CR \in [0.1, 0.9]$。

- $CR$ 过小：只有少数维度来自变异向量，搜索保守
- $CR$ 过大：大多数维度来自变异向量，搜索激进

### 4.3 种群大小 $N$

$N$ 通常取 $N = 10D$，其中 $D$ 为问题维度。

### 4.4 参数推荐设置

| 问题类型 | $F$ | $CR$ | $N$ |
|---------|-----|------|-----|
| 单峰函数 | 0.5 | 0.9 | $10D$ |
| 多峰函数 | 0.8 | 0.2 | $20D$ |
| 噪声函数 | 0.9 | 0.1 | $30D$ |

## 五、DE 变体

### 5.1 DEGL（DE with Global and Local Neighbors）

结合全局和局部邻域信息：

$$\mathbf{v}_i = \mathbf{x}_i + \alpha \cdot (\mathbf{x}_{\text{best}} - \mathbf{x}_i) + (1-\alpha) \cdot (\mathbf{x}_{\text{local}} - \mathbf{x}_{\text{local2}})$$

其中 $\alpha$ 为权重，$\mathbf{x}_{\text{local}}$ 为局部邻域中的个体。

### 5.2 JADE（Adaptive DE with Optional External Archive）

JADE 引入了可选的外部存档和自适应参数：

$$F_i = \text{clamp}(F_\mu + 0.1 \cdot \mathcal{N}(0, 1), 0, 1)$$
$$CR_i = \text{clamp}(CR_\mu + 0.1 \cdot \mathcal{N}(0, 1), 0, 1)$$

其中 $F_\mu$ 和 $CR_\mu$ 为自适应参数的均值。

### 5.3 SHADE（Success-History based Adaptive DE）

SHADE 使用成功历史来调整参数：

$$F_i = \text{Sample}_{Cauchy}(\mu_F, 0.1)$$
$$CR_i = \text{Sample}_{Normal}(\mu_{CR}, 0.1)$$

参数均值根据成功案例更新：

$$\mu_F = \text{ LehmerMean}(w_S, F_S)$$
$$\mu_{CR} = \text{Mean}(CR_S)$$

### 5.4 L-SHADE（Linear SHADE）

L-SHADE 使用线性递减的种群大小：

$$N(t) = N_{\min} + \frac{T - t}{T} \cdot (N_{\max} - N_{\min})$$

### 5.5 CoDE（Composite DE）

CoDE 随机选择变异策略和参数组合：

$$\text{Strategy}_i \in \{\text{DE/rand/1}, \text{DE/rand/2}, \text{DE/current-to-rand/1}\}$$

## 六、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from typing import Callable, List, Tuple

class DifferentialEvolution:
    def __init__(self,
                 obj_func: Callable,
                 bounds: List[Tuple[float, float]],
                 pop_size: int = None,
                 max_iter: int = 500,
                 F: float = 0.8,
                 CR: float = 0.2,
                 strategy: str = 'rand1bin'):
        self.obj_func = obj_func
        self.bounds = np.array(bounds)
        self.dim = len(bounds)
        self.pop_size = pop_size or 10 * self.dim
        self.max_iter = max_iter
        self.F = F
        self.CR = CR
        self.strategy = strategy
        self.lb = self.bounds[:, 0]
        self.ub = self.bounds[:, 1]
        
        self.population = None
        self.fitness = None
        self.best_idx = None
        self.history = []
        
    def initialize(self):
        self.population = np.random.uniform(self.lb, self.ub, (self.pop_size, self.dim))
        self.fitness = np.array([self.obj_func(ind) for ind in self.population])
        self.best_idx = np.argmin(self.fitness)
        
    def mutate(self, idx: int) -> np.ndarray:
        if self.strategy.startswith('rand1'):
            r1, r2, r3 = np.random.choice(self.pop_size, 3, replace=False)
            v = self.population[r1] + self.F * (self.population[r2] - self.population[r3])
            
        elif self.strategy.startswith('rand2'):
            r1, r2, r3, r4, r5 = np.random.choice(self.pop_size, 5, replace=False)
            v = self.population[r1] + self.F * (self.population[r2] - self.population[r3]) + \
                self.F * (self.population[r4] - self.population[r5])
                
        elif self.strategy.startswith('best1'):
            r1, r2 = np.random.choice(self.pop_size, 2, replace=False)
            v = self.population[self.best_idx] + self.F * (self.population[r1] - self.population[r2])
            
        elif self.strategy.startswith('best2'):
            r1, r2, r3, r4 = np.random.choice(self.pop_size, 4, replace=False)
            v = self.population[self.best_idx] + self.F * (self.population[r1] - self.population[r2]) + \
                self.F * (self.population[r3] - self.population[r4])
                
        elif self.strategy.startswith('currenttobest1'):
            r1, r2 = np.random.choice(self.pop_size, 2, replace=False)
            v = self.population[idx] + self.F * (self.population[self.best_idx] - self.population[idx]) + \
                self.F * (self.population[r1] - self.population[r2])
                
        else:
            raise ValueError(f"Unknown strategy: {self.strategy}")
            
        return np.clip(v, self.lb, self.ub)
    
    def crossover(self, target: np.ndarray, mutant: np.ndarray) -> np.ndarray:
        trial = target.copy()
        
        if 'bin' in self.strategy:
            j_rand = np.random.randint(self.dim)
            for j in range(self.dim):
                if np.random.random() < self.CR or j == j_rand:
                    trial[j] = mutant[j]
                    
        elif 'exp' in self.strategy:
            j = np.random.randint(self.dim)
            L = 0
            while np.random.random() < self.CR and L < self.dim:
                trial[(j + L) % self.dim] = mutant[(j + L) % self.dim]
                L += 1
                
        return trial
    
    def optimize(self) -> Tuple[np.ndarray, float]:
        self.initialize()
        
        for gen in range(self.max_iter):
            for i in range(self.pop_size):
                mutant = self.mutate(i)
                trial = self.crossover(self.population[i], mutant)
                
                trial_fitness = self.obj_func(trial)
                
                if trial_fitness <= self.fitness[i]:
                    self.population[i] = trial
                    self.fitness[i] = trial_fitness
                    
                    if trial_fitness < self.fitness[self.best_idx]:
                        self.best_idx = i
                        
            self.history.append(self.fitness[self.best_idx])
            
        return self.population[self.best_idx], self.fitness[self.best_idx]


class SHADE:
    def __init__(self,
                 obj_func: Callable,
                 bounds: List[Tuple[float, float]],
                 pop_size: int = None,
                 max_iter: int = 500,
                 H: int = 20):
        self.obj_func = obj_func
        self.bounds = np.array(bounds)
        self.dim = len(bounds)
        self.pop_size = pop_size or 6 * self.dim
        self.max_iter = max_iter
        self.H = H
        self.lb = self.bounds[:, 0]
        self.ub = self.bounds[:, 1]
        
        self.history = []
        
    def optimize(self) -> Tuple[np.ndarray, float]:
        NP = self.pop_size
        population = np.random.uniform(self.lb, self.ub, (NP, self.dim))
        fitness = np.array([self.obj_func(ind) for ind in population])
        
        mu_F = 0.5 * np.ones(self.H)
        mu_CR = 0.5 * np.ones(self.H)
        S_F, S_CR = [], []
        
        best_idx = np.argmin(fitness)
        best_solution = population[best_idx].copy()
        best_value = fitness[best_idx]
        
        for gen in range(self.max_iter):
            r = np.random.randint(0, self.H, NP)
            
            F = np.clip(np.random.standard_cauchy(NP) * 0.1 + mu_F[r], 0, 1)
            CR = np.clip(np.random.normal(mu_CR[r], 0.1), 0, 1)
            
            for i in range(NP):
                p = 2 + int(2 * np.random.random())
                top_indices = np.argsort(fitness)[:p]
                
                x_best = population[np.random.choice(top_indices)]
                
                candidates = list(range(NP))
                candidates.remove(i)
                r1, r2 = np.random.choice(candidates, 2, replace=False)
                
                mutant = population[i] + F[i] * (x_best - population[i]) + \
                         F[i] * (population[r1] - population[r2])
                mutant = np.clip(mutant, self.lb, self.ub)
                
                trial = population[i].copy()
                j_rand = np.random.randint(self.dim)
                for j in range(self.dim):
                    if np.random.random() < CR[i] or j == j_rand:
                        trial[j] = mutant[j]
                
                trial_fitness = self.obj_func(trial)
                
                if trial_fitness < fitness[i]:
                    S_F.append(F[i])
                    S_CR.append(CR[i])
                    population[i] = trial
                    fitness[i] = trial_fitness
                    
                    if trial_fitness < best_value:
                        best_value = trial_fitness
                        best_solution = trial.copy()
            
            if len(S_F) > 0:
                mu_F[gen % self.H] = np.sum(np.array(S_F)**2) / np.sum(S_F)
                mu_CR[gen % self.H] = np.mean(S_CR) if S_CR else mu_CR[gen % self.H]
                S_F, S_CR = [], []
            
            self.history.append(best_value)
            
        return best_solution, best_value


def sphere(x):
    return sum(xi**2 for xi in x)

def rosenbrock(x):
    return sum(100*(x[i+1]-x[i]**2)**2 + (1-x[i])**2 for i in range(len(x)-1))


if __name__ == "__main__":
    bounds = [(-10, 10)] * 5
    
    de = DifferentialEvolution(sphere, bounds, pop_size=50, max_iter=300, strategy='rand1bin')
    best_sol, best_val = de.optimize()
    print(f"DE/rand/1/bin - 最优值: {best_val:.6e}")
    
    shade = SHADE(sphere, bounds, pop_size=50, max_iter=300)
    best_sol_shade, best_val_shade = shade.optimize()
    print(f"SHADE - 最优值: {best_val_shade:.6e}")
    
    plt.figure(figsize=(10, 6))
    plt.semilogy(de.history, label='DE/rand/1/bin')
    plt.semilogy(shade.history, label='SHADE')
    plt.xlabel('迭代次数')
    plt.ylabel('最优值 (log scale)')
    plt.title('差分进化收敛曲线')
    plt.legend()
    plt.grid(True)
    plt.show()
```

## 七、收敛性分析

### 7.1 理论分析

DE 的收敛性可以通过以下因素分析：

1. **多样性保持**：差分向量提供了自然的多样性
2. **自适应步长**：步长随种群分散程度自适应调整
3. **贪婪选择**：保证种群质量单调不降

### 7.2 收敛条件

DE 在以下条件下以概率 1 收敛到全局最优：

1. $F \in (0, 2)$，确保差分向量的探索能力
2. 种群大小 $N$ 足够大
3. 交叉概率 $CR$ 适当

### 7.3 早熟收敛

DE 可能出现早熟收敛，原因包括：
- 种群多样性丧失
- 差分向量退化
- 参数设置不当

## 八、与其他算法的比较

| 特性 | DE | GA | PSO | SA |
|------|----|----|-----|-----|
| 变异方式 | 差分向量 | 随机变异 | 速度更新 | 随机扰动 |
| 参数数量 | 少（$F, CR$） | 多 | 少 | 少 |
| 收敛速度 | 快 | 中 | 快 | 慢 |
| 全局搜索 | 强 | 强 | 中 | 强 |
| 实现难度 | 简单 | 中等 | 简单 | 简单 |
| 适用问题 | 连续优化 | 通用 | 连续优化 | 通用 |

## 九、关键要点总结

1. **差分向量是核心**：自适应的搜索步长
2. **$F$ 的选择**：通常取 0.5-1.0
3. **$CR$ 的选择**：根据问题特点调整
4. **种群大小**：通常取 $10D$
5. **策略选择**：DE/rand/1/bin 是最常用的策略
6. **参数自适应**：JADE、SHADE 等自适应策略性能更好
7. **边界处理**：需要合理处理超出边界的个体
8. **贪婪选择**：保证种群质量单调不降
9. **连续优化**：DE 特别适合连续优化问题
10. **与其他方法结合**：DE 可与局部搜索等方法结合
