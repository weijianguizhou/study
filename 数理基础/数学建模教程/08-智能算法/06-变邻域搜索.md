# 变邻域搜索详解

## 一、概述

变邻域搜索（Variable Neighborhood Search, VNS）是由 Mladenović 和 Hansen 于 1997 年提出的一种元启发式优化算法。其核心思想是系统性地改变邻域结构，以扩大搜索范围，避免陷入局部最优。

VNS 的理论基础是以下两个事实：
1. 一个邻域结构的局部最优解在另一个邻域结构中可能不是局部最优
2. 全局最优解对所有邻域结构都是局部最优的

## 二、基本概念

### 2.1 邻域结构集

设问题的解空间为 $\mathcal{S}$，定义 $K$ 个邻域结构 $\{N_k | k = 1, 2, \ldots, K\}$，每个邻域结构 $N_k$ 将当前解映射到一组邻域解：

$$N_k(\mathbf{x}) = \{\mathbf{x}' \in \mathcal{S} | d(\mathbf{x}, \mathbf{x}') \leq r_k\}$$

其中 $r_k$ 为第 $k$ 个邻域的半径。

### 2.2 邻域结构的递进性

邻域结构通常按"大小"或"强度"递进排列：

$$N_1 \subset N_2 \subset \cdots \subset N_K$$

或者邻域结构的搜索范围逐渐增大。

### 2.3 局部最优的定义

对于邻域结构 $N_k$，解 $\mathbf{x}$ 是局部最优的，当且仅当：

$$\forall \mathbf{x}' \in N_k(\mathbf{x}): f(\mathbf{x}') \geq f(\mathbf{x})$$

## 三、基本 VNS 算法

### 3.1 算法流程

```
算法：变邻域搜索（VNS）
输入：目标函数 f(x)，初始解 x_0，邻域结构集 {N_1,...,N_K}
输出：最优解 x*

1. 初始化：x = x_0, k = 1
2. while 未满足停止准则 do
3.     震动（Shake）：从 N_k(x) 中随机选择 x' 
4.     局部搜索：以 x' 为初始点，用 N_1 进行局部搜索，得到局部最优 x''
5.     邻域变更：
6.         if f(x'') < f(x) then
7.             x = x'', k = 1    // 找到更好的解，从头开始
8.         else
9.             k = k + 1          // 增大邻域
10.    end if
11. end while
12. return x
```

### 3.2 震动操作（Shaking）

震动操作在当前邻域 $N_k$ 中随机选择一个解，以跳出当前局部最优：

$$\mathbf{x}' \leftarrow \text{Random}(N_k(\mathbf{x}))$$

### 3.3 局部搜索

局部搜索以 $\mathbf{x}'$ 为起点，使用邻域 $N_1$ 进行下降搜索，直到找到局部最优 $\mathbf{x}''$。

## 四、VNS 变体

### 4.1 变邻域下降（VND, Variable Neighborhood Descent）

VND 是 VNS 的确定性版本，不使用震动操作：

```
算法：变邻域下降（VND）
输入：初始解 x，邻域结构集 {N_1,...,N_K}
输出：局部最优 x*

1. x* = x, k = 1
2. while k ≤ K do
3.     x' = LocalSearch(x*, N_k)
4.     if f(x') < f(x*) then
5.         x* = x', k = 1
6.     else
7.         k = k + 1
8.     end if
9. end while
10. return x*
```

### 4.2 广义 VNS（GVNS, Generalized VNS）

GVNS 将 VNS 与 GRASP（贪婪随机自适应搜索）结合：

```
算法：广义 VNS（GVNS）
输入：初始解 x，邻域结构集 {N_1,...,N_K}
输出：最优解 x*

1. while 未满足停止准则 do
2.     x = GRASP Construction()
3.     x = GVNS(x, K)
4.     if f(x) < f(x_best) then
5.         x_best = x
6. end while
7. return x_best
```

### 4.3 自适应 VNS（AVNS）

AVNS 根据搜索状态自适应调整邻域结构的选择：

$$p(N_k) = \frac{w_k}{\sum_{j=1}^{K} w_j}$$

其中 $w_k$ 为邻域 $N_k$ 的权重，根据历史表现动态更新。

### 4.4 分裂 VNS（BVNS, Bi-objective VNS）

BVNS 用于多目标优化问题，同时优化多个目标函数：

$$\min \mathbf{F}(\mathbf{x}) = (f_1(\mathbf{x}), f_2(\mathbf{x}), \ldots, f_m(\mathbf{x}))$$

### 4.5 偏好 VNS（PVNS）

PVNS 引入决策者的偏好信息，引导搜索方向。

## 五、邻域结构设计

### 5.1 TSP 问题的邻域结构

**邻域 $N_1$**：2-opt（反转两个城市之间的路径）

$$N_1(\pi) = \{\text{reverse}(\pi, i, j) | 1 \leq i < j \leq n\}$$

**邻域 $N_2$**：or-opt（移动一段子路径）

$$N_2(\pi) = \{\text{relocate}(\pi, i, j, k) | 1 \leq i < j < k \leq n\}$$

**邻域 $N_3$**：3-opt（同时反转三个路径段）

$$N_3(\pi) = \{\text{3-opt}(\pi, i, j, k, l) | \text{所有有效索引}\}$$

### 5.2 连续优化问题的邻域结构

**邻域 $N_k$**：高斯扰动，步长递增

$$N_k(\mathbf{x}) = \{\mathbf{x} + \sigma_k \cdot \mathcal{N}(\mathbf{0}, \mathbf{I})\}$$

其中 $\sigma_k = \sigma_0 \cdot 2^{k-1}$。

### 5.3 调度问题的邻域结构

**邻域 $N_1$**：交换两个作业

$$N_1(\pi) = \{\text{swap}(\pi, i, j) | 1 \leq i < j \leq n\}$$

**邻域 $N_2$**：插入一个作业

$$N_2(\pi) = \{\text{insert}(\pi, i, j) | 1 \leq i \neq j \leq n\}$$

**邻域 $N_3$**：反转一段作业序列

$$N_3(\pi) = \{\text{reverse}(\pi, i, j) | 1 \leq i < j \leq n\}$$

## 六、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from typing import List, Tuple, Callable, Optional

class VariableNeighborhoodSearch:
    def __init__(self,
                 obj_func: Callable,
                 bounds: List[Tuple[float, float]],
                 max_iter: int = 200,
                 shake_sizes: List[float] = None,
                 local_search_max: int = 50):
        self.obj_func = obj_func
        self.bounds = np.array(bounds)
        self.dim = len(bounds)
        self.max_iter = max_iter
        self.lb = self.bounds[:, 0]
        self.ub = self.bounds[:, 1]
        self.local_search_max = local_search_max
        
        if shake_sizes is None:
            self.shake_sizes = [0.05, 0.1, 0.2, 0.3, 0.5]
        else:
            self.shake_sizes = shake_sizes
        self.n_neighborhoods = len(self.shake_sizes)
        
        self.best_solution = None
        self.best_value = np.inf
        self.history = []
        
    def initialize(self) -> np.ndarray:
        return np.random.uniform(self.lb, self.ub, self.dim)
    
    def shake(self, x: np.ndarray, k: int) -> np.ndarray:
        scale = self.shake_sizes[k] * (self.ub - self.lb)
        x_new = x + np.random.uniform(-scale, scale, self.dim)
        return np.clip(x_new, self.lb, self.ub)
    
    def local_search(self, x: np.ndarray, step_size: float) -> np.ndarray:
        current = x.copy()
        current_value = self.obj_func(current)
        
        for _ in range(self.local_search_max):
            neighbor = current + np.random.uniform(-step_size, step_size, self.dim)
            neighbor = np.clip(neighbor, self.lb, self.ub)
            neighbor_value = self.obj_func(neighbor)
            
            if neighbor_value < current_value:
                current = neighbor
                current_value = neighbor_value
                
        return current
    
    def optimize(self) -> Tuple[np.ndarray, float]:
        x = self.initialize()
        self.best_solution = x.copy()
        self.best_value = self.obj_func(x)
        
        k = 0
        iteration = 0
        
        while iteration < self.max_iter:
            x_shake = self.shake(x, k)
            
            x_local = self.local_search(x_shake, self.shake_sizes[0])
            local_value = self.obj_func(x_local)
            
            if local_value < self.best_value:
                x = x_local
                self.best_solution = x.copy()
                self.best_value = local_value
                k = 0
            else:
                k += 1
                if k >= self.n_neighborhoods:
                    k = 0
            
            self.history.append(self.best_value)
            iteration += 1
            
        return self.best_solution, self.best_value


class TSP_VNS:
    def __init__(self, distance_matrix: np.ndarray, max_iter: int = 200):
        self.dist_matrix = distance_matrix
        self.n_cities = len(distance_matrix)
        self.max_iter = max_iter
        self.best_tour = None
        self.best_length = np.inf
        self.history = []
        
    def tour_length(self, tour: np.ndarray) -> float:
        length = 0
        for i in range(len(tour)):
            length += self.dist_matrix[tour[i], tour[(i+1) % len(tour)]]
        return length
    
    def two_opt_swap(self, tour: np.ndarray, i: int, j: int) -> np.ndarray:
        new_tour = tour.copy()
        new_tour[i:j+1] = tour[i:j+1][::-1]
        return new_tour
    
    def or_opt(self, tour: np.ndarray, i: int, j: int, k: int) -> np.ndarray:
        new_tour = tour.copy()
        segment = tour[i:j].copy()
        new_tour = np.delete(new_tour, range(i, j))
        new_tour = np.insert(new_tour, k, segment)
        return new_tour
    
    def local_search_2opt(self, tour: np.ndarray) -> np.ndarray:
        best_tour = tour.copy()
        improved = True
        
        while improved:
            improved = False
            for i in range(1, self.n_cities - 1):
                for j in range(i + 1, self.n_cities):
                    new_tour = self.two_opt_swap(best_tour, i, j)
                    if self.tour_length(new_tour) < self.tour_length(best_tour):
                        best_tour = new_tour
                        improved = True
                        
        return best_tour
    
    def local_search_or_opt(self, tour: np.ndarray) -> np.ndarray:
        best_tour = tour.copy()
        improved = True
        
        while improved:
            improved = False
            for seg_len in [1, 2, 3]:
                for i in range(self.n_cities - seg_len):
                    for j in range(i + seg_len, self.n_cities):
                        new_tour = self.or_opt(best_tour, i, i + seg_len, j)
                        if self.tour_length(new_tour) < self.tour_length(best_tour):
                            best_tour = new_tour
                            improved = True
                            
        return best_tour
    
    def shake(self, tour: np.ndarray, k: int) -> np.ndarray:
        new_tour = tour.copy()
        n_shakes = k + 1
        
        for _ in range(n_shakes):
            i = np.random.randint(0, self.n_cities)
            j = np.random.randint(0, self.n_cities)
            while j == i:
                j = np.random.randint(0, self.n_cities)
            new_tour = self.two_opt_swap(new_tour, min(i,j), max(i,j))
            
        return new_tour
    
    def optimize(self) -> Tuple[np.ndarray, float]:
        self.best_tour = np.random.permutation(self.n_cities)
        self.best_length = self.tour_length(self.best_tour)
        
        k = 0
        max_k = 3
        
        for iteration in range(self.max_iter):
            x_shake = self.shake(self.best_tour, k)
            
            x_local = self.local_search_2opt(x_shake)
            local_length = self.tour_length(x_local)
            
            if local_length < self.best_length:
                self.best_tour = x_local
                self.best_length = local_length
                k = 0
            else:
                k += 1
                if k >= max_k:
                    k = 0
            
            self.history.append(self.best_length)
            
        return self.best_tour, self.best_length


def create_distance_matrix(n_cities: int, seed: int = 42) -> Tuple[np.ndarray, np.ndarray]:
    np.random.seed(seed)
    coords = np.random.uniform(0, 100, (n_cities, 2))
    dist_matrix = np.zeros((n_cities, n_cities))
    for i in range(n_cities):
        for j in range(n_cities):
            dist_matrix[i, j] = np.linalg.norm(coords[i] - coords[j])
    return dist_matrix, coords


if __name__ == "__main__":
    def sphere(x):
        return sum(xi**2 for xi in x)
    
    bounds = [(-10, 10)] * 5
    vns = VariableNeighborhoodSearch(sphere, bounds, max_iter=200)
    best_sol, best_val = vns.optimize()
    
    print(f"连续优化 - 最优解: {best_sol}")
    print(f"连续优化 - 最优值: {best_val}")
    
    n_cities = 30
    dist_matrix, coords = create_distance_matrix(n_cities)

    print(f"\nTSP - 最短路径: {best_length:.2f}")
    
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))

    plt.tight_layout()
    plt.show()
```

## 七、收敛性分析

### 7.1 基本定理

**定理**：如果以下条件满足：
1. 每个邻域结构 $N_k$ 都是有限的
2. 从任意解出发，通过邻域操作可以到达任意其他解
3. 局部搜索在有限步内终止

则 VNS 在有限时间内收敛到全局最优解。

### 7.2 收敛速度

VNS 的收敛速度取决于：
- 邻域结构的数量 $K$
- 每个邻域的大小
- 震动操作的有效性
- 局部搜索的效率

### 7.3 邻域结构的影响

邻域结构的选择对 VNS 性能有重要影响：

- 邻域结构应具有互补性
- 小邻域适合精细搜索，大邻域适合广域搜索
- 邻域结构之间应有适当的递进关系

## 八、与其他算法的比较

| 特性 | VNS | TS | SA | GA |
|------|-----|----|----|-----|
| 邻域结构 | 多个 | 一个 | 一个 | 无 |
| 禁忌机制 | 无 | 有 | 无 | 无 |
| 随机性 | 低 | 低 | 高 | 高 |
| 局部搜索能力 | 强 | 强 | 中 | 弱 |
| 参数数量 | 少 | 少 | 少 | 多 |
| 实现难度 | 简单 | 简单 | 简单 | 中等 |

## 九、高级策略

### 9.1 邻域结构学习

根据搜索历史自动学习有效的邻域结构：

$$w_k(t+1) = w_k(t) + \Delta w \cdot \mathbb{1}[\text{邻域 } N_k \text{ 产生改善}]$$

### 9.2 混合 VNS

将 VNS 与其他元启发式算法结合：

- **VNS + GA**：使用 GA 生成初始解，VNS 进行局部优化
- **VNS + SA**：使用 SA 的接受准则处理劣化移动
- **VNS + ACO**：使用 ACO 的信息素引导邻域选择

### 9.3 并行 VNS

多个 VNS 进程并行运行，定期交换信息：

$$\mathbf{x}_i^{\text{new}} = \begin{cases} \mathbf{x}_i^{\text{local}} & \text{with prob } 1-p_{\text{share}} \\ \mathbf{x}_j^{\text{best}} & \text{with prob } p_{\text{share}} \end{cases}$$

## 十、关键要点总结

1. **核心思想**：系统性地改变邻域结构以跳出局部最优
2. **邻域递进**：从小邻域到大邻域逐步扩大搜索范围
3. **震动操作**：在当前邻域中随机选择解以跳出局部最优
4. **局部搜索**：使用小邻域进行精细搜索
5. **邻域选择**：邻域结构应具有互补性和递进性
6. **参数简单**：主要参数为邻域数量和震动强度
7. **组合优化**：VNS 特别适合组合优化问题
8. **与其他方法结合**：VNS 可与 GA、SA 等结合
9. **并行化**：VNS 天然适合并行计算
10. **灵活性**：VNS 框架易于适应不同问题
