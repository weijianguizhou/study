# 布谷鸟搜索详解

## 一、概述

布谷鸟搜索算法（Cuckoo Search, CS）是由 Xin-She Yang 和 Suash Deb 于 2009 年提出的一种元启发式优化算法。其灵感来源于布谷鸟的巢寄生行为和 Lévy 飞行机制。

CS 算法具有参数少、全局搜索能力强、易于实现等优点，已广泛应用于工程优化、机器学习、图像处理等领域。

## 二、生物学基础

### 2.1 布谷鸟的巢寄生行为

布谷鸟是一种巢寄生鸟类，其繁殖行为包括：

1. **巢寄生**：布谷鸟不自己筑巢，而是将蛋产在其他鸟类的巢中
2. **蛋的模仿**：布谷鸟的蛋与宿主鸟的蛋相似，以避免被发现
3. **雏鸟竞争**：布谷鸟雏鸟孵化后，会将宿主鸟的蛋或雏鸟推出巢外
4. **宿主行为**：宿主鸟会发现并抛弃异常的蛋，重新筑巢

### 2.2 Lévy 飞行

Lévy 飞行是一种随机行走方式，其步长服从 Lévy 分布：

$$L(s) \sim s^{-\mu}, \quad 1 < \mu \leq 3$$

Lévy 飞行的特点是：大多数步长很小，偶尔出现大步长跳跃。这种特性使得 Lévy 飞行在局部搜索和全局搜索之间取得了良好的平衡。

### 2.3 Lévy 飞行与布朗运动的比较

| 特性 | Lévy 飞行 | 布朗运动 |
|------|----------|---------|
| 步长分布 | 重尾分布 | 正态分布 |
| 大步长概率 | 较高 | 极低 |
| 探索能力 | 强 | 弱 |
| 局部搜索 | 有效 | 有效 |
| 全局搜索 | 高效 | 低效 |

## 三、算法原理

### 3.1 基本假设

CS 算法基于以下三个理想化假设：

1. 每只布谷鸟一次只产一个蛋，并随机选择巢寄生
2. 最好的巢会被保留到下一代
3. 可用巢的数量固定，宿主鸟发现布谷鸟蛋的概率为 $p_a \in [0, 1]$

### 3.2 位置更新

布谷鸟的位置更新公式为：

$$\mathbf{x}_i^{t+1} = \mathbf{x}_i^t + \alpha \oplus \text{Lévy}(\lambda)$$

其中：
- $\alpha$ 为步长控制参数
- $\oplus$ 为逐元素乘法
- $\text{Lévy}(\lambda)$ 为 Lévy 分布的随机步长

### 3.3 Lévy 分布的采样

Lévy 分布可以通过 Mantegna 算法采样：

$$\text{Lévy} \sim \frac{u}{|v|^{1/\beta}}$$

其中：
- $u \sim \mathcal{N}(0, \sigma_u^2)$，$\sigma_u = \left(\frac{\Gamma(1+\beta) \sin(\pi\beta/2)}{\Gamma((1+\beta)/2) \beta 2^{(\beta-1)/2}}\right)^{1/\beta}$
- $v \sim \mathcal{N}(0, 1)$
- $\beta = 1.5$（通常取值）

### 3.4 宿主鸟的发现

当宿主鸟发现布谷鸟蛋时，会抛弃该巢并重新筑巢：

$$\mathbf{x}_i^{t+1} = \begin{cases} \mathbf{x}_i^t + r \cdot (\mathbf{x}_j^t - \mathbf{x}_k^t) & \text{if } r < p_a \\ \mathbf{x}_i^t + \alpha \oplus \text{Lévy}(\lambda) & \text{otherwise} \end{cases}$$

其中 $r \sim U(0,1)$，$j, k$ 为随机选择的巢。

## 四、算法流程

```
算法：布谷鸟搜索（CS）
输入：目标函数 f(x)，搜索空间维度 D，巢数量 n，最大迭代次数 T
输出：最优解 x*

1. 初始化：
   随机生成 n 个巢的位置 x_i
   评估每个巢的适应度 f(x_i)
   找到当前最优巢 x_best
2. for t = 1 to T do
3.     通过 Lévy 飞行生成新巢 v_i
4.     if f(v_i) < f(x_i) then
5.         x_i = v_i
6.     随机选择一些巢，以概率 p_a 被发现并替换
7.     保留最好的巢
8.     更新 x_best
9. end for
10. return x_best
```

## 五、参数设置

### 5.1 步长控制参数 $\alpha$

$\alpha$ 控制 Lévy 飞行的步长大小：

$$\alpha = \alpha_0 \cdot (\mathbf{x}_{\max} - \mathbf{x}_{\min})$$

通常 $\alpha_0 = 0.01$。

### 5.2 发现概率 $p_a$

$p_a$ 控制宿主鸟发现布谷鸟蛋的概率，通常取 $p_a \in [0.1, 0.5]$。

- $p_a$ 过大：太多巢被替换，搜索不稳定
- $p_a$ 过小：搜索多样性不足

### 5.3 Lévy 指数 $\beta$

$\beta$ 控制 Lévy 分布的形状，通常取 $\beta = 1.5$。

### 5.4 巢数量 $n$

巢数量 $n$ 通常取 $n \in [15, 50]$。

## 六、Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from math import gamma
from typing import Callable, List, Tuple

class CuckooSearch:
    def __init__(self,
                 obj_func: Callable,
                 bounds: List[Tuple[float, float]],
                 n_nests: int = 25,
                 max_iter: int = 500,
                 pa: float = 0.25,
                 alpha0: float = 0.01,
                 beta: float = 1.5):
        self.obj_func = obj_func
        self.bounds = np.array(bounds)
        self.dim = len(bounds)
        self.n_nests = n_nests
        self.max_iter = max_iter
        self.pa = pa
        self.alpha0 = alpha0
        self.beta = beta
        self.lb = self.bounds[:, 0]
        self.ub = self.bounds[:, 1]
        self.alpha = self.alpha0 * np.max(self.ub - self.lb)
        self.nests = None
        self.fitness = None
        self.best_nest = None
        self.best_value = np.inf
        self.history = []

    def levy_flight(self) -> np.ndarray:
        sigma_u = (gamma(1 + self.beta) * np.sin(np.pi * self.beta / 2) /
                   (gamma((1 + self.beta) / 2) * self.beta *
                    2**((self.beta - 1) / 2)))**(1 / self.beta)
        u = np.random.normal(0, sigma_u, self.dim)
        v = np.random.normal(0, 1, self.dim)
        return u / np.abs(v)**(1 / self.beta)

    def initialize(self):
        self.nests = np.random.uniform(self.lb, self.ub, (self.n_nests, self.dim))
        self.fitness = np.array([self.obj_func(nest) for nest in self.nests])
        best_idx = np.argmin(self.fitness)
        self.best_nest = self.nests[best_idx].copy()
        self.best_value = self.fitness[best_idx]

    def get_cuckoos(self):
        for i in range(self.n_nests):
            step = self.levy_flight()
            step_size = self.alpha * step * (self.nests[i] - self.best_nest)
            new_nest = self.nests[i] + step_size * np.random.random(self.dim)
            new_nest = np.clip(new_nest, self.lb, self.ub)
            new_fitness = self.obj_func(new_nest)
            if new_fitness < self.fitness[i]:
                self.nests[i] = new_nest
                self.fitness[i] = new_fitness

    def get_abandoned(self):
        for i in range(self.n_nests):
            if np.random.random() < self.pa:
                j, k = np.random.choice(self.n_nests, 2, replace=False)
                step_size = np.random.random() * (self.nests[j] - self.nests[k])
                new_nest = self.nests[i] + step_size
                new_nest = np.clip(new_nest, self.lb, self.ub)
                new_fitness = self.obj_func(new_nest)
                if new_fitness < self.fitness[i]:
                    self.nests[i] = new_nest
                    self.fitness[i] = new_fitness

    def optimize(self) -> Tuple[np.ndarray, float]:
        self.initialize()
        for t in range(self.max_iter):
            self.get_cuckoos()
            self.get_abandoned()
            best_idx = np.argmin(self.fitness)
            if self.fitness[best_idx] < self.best_value:
                self.best_nest = self.nests[best_idx].copy()
                self.best_value = self.fitness[best_idx]
            self.history.append(self.best_value)
        return self.best_nest, self.best_value


class EnhancedCuckooSearch(CuckooSearch):
    def adaptive_levy(self, t: int) -> np.ndarray:
        alpha_t = self.alpha * (1 - t / self.max_iter)
        sigma_u = (gamma(1 + self.beta) * np.sin(np.pi * self.beta / 2) /
                   (gamma((1 + self.beta) / 2) * self.beta *
                    2**((self.beta - 1) / 2)))**(1 / self.beta)
        u = np.random.normal(0, sigma_u, self.dim)
        v = np.random.normal(0, 1, self.dim)
        return alpha_t * u / np.abs(v)**(1 / self.beta)

    def opposition_based_init(self):
        opp_nests = self.lb + self.ub - self.nests
        opp_nests = np.clip(opp_nests, self.lb, self.ub)
        combined = np.vstack([self.nests, opp_nests])
        combined_fit = np.array([self.obj_func(n) for n in combined])
        best_idx = np.argsort(combined_fit)[:self.n_nests]
        self.nests = combined[best_idx]
        self.fitness = combined_fit[best_idx]


def sphere(x):
    return sum(xi**2 for xi in x)

def ackley(x):
    n = len(x)
    s1 = sum(xi**2 for xi in x)
    s2 = sum(np.cos(2 * np.pi * xi) for xi in x)
    return -20*np.exp(-0.2*np.sqrt(s1/n)) - np.exp(s2/n) + 20 + np.e

def griewank(x):
    s = sum(xi**2 for xi in x) / 4000
    p = np.prod([np.cos(xi/np.sqrt(i+1)) for i, xi in enumerate(x)])
    return s - p + 1


if __name__ == "__main__":
    bounds = [(-10, 10)] * 5
    cs = CuckooSearch(sphere, bounds, n_nests=25, max_iter=300)
    best_sol, best_val = cs.optimize()
    print(f"CS - 最优值: {best_val:.6e}")

    ecs = EnhancedCuckooSearch(ackley, bounds, n_nests=25, max_iter=300)
    best_sol_e, best_val_e = ecs.optimize()
    print(f"ECS - 最优值: {best_val_e:.6e}")

    plt.figure(figsize=(10, 6))
    plt.semilogy(cs.history, label='CS on Sphere')
    plt.semilogy(ecs.history, label='ECS on Ackley')
    plt.xlabel('迭代次数')
    plt.ylabel('最优值 (log scale)')
    plt.title('布谷鸟搜索收敛曲线')
    plt.legend()
    plt.grid(True)
    plt.show()
```

## 七、收敛性分析

### 7.1 Lévy 飞行的遍历性

Lévy 飞行具有遍历性（Ergodicity），即在无限时间内能够访问搜索空间中的所有区域。这保证了 CS 算法的全局搜索能力。

### 7.2 收敛定理

**定理**：对于有界搜索空间上的连续优化问题，CS 算法以概率 1 收敛到全局最优解。

### 7.3 收敛速度

CS 的收敛速度受以下因素影响：
- Lévy 指数 $\beta$：较小的 $\beta$ 产生更大的步长跳跃
- 发现概率 $p_a$：影响搜索多样性的维持
- 巢数量 $n$：影响种群多样性

### 7.4 与其他随机行走的比较

Lévy 飞行的搜索效率优于纯随机行走和高斯随机行走：

$$\langle r^2(t) \rangle \sim t^{2/(3-\mu)}, \quad 1 < \mu < 3$$

当 $\mu \approx 2$ 时，Lévy 飞行的扩散速度接近最优。

## 八、高级策略

### 8.1 自适应 Lévy 飞行

根据搜索阶段自适应调整 $\beta$ 和 $\alpha$：

$$\beta(t) = \beta_0 + \frac{\beta_{\max} - \beta_0}{T} \cdot t$$

### 8.2 混合 CS

将 CS 与其他算法结合：

- **CS + GA**：使用 GA 的交叉操作
- **CS + PSO**：使用 PSO 的速度更新
- **CS + DE**：使用 DE 的变异策略

### 8.3 多群 CS

将巢分为多个子群，每个子群独立优化，定期交换信息。

## 十、关键要点总结

1. **Lévy 飞行是核心**：提供高效的全局搜索能力
2. **参数简单**：主要参数为 $p_a$ 和 $\beta$
3. **巢寄生模型**：通过发现和替换机制维持多样性
4. **重尾分布**：大步长跳跃帮助跳出局部最优
5. **$\beta = 1.5$**：通常是最佳选择
6. **$p_a = 0.25$**：推荐的发现概率
7. **巢数量**：通常取 15-50
8. **适用范围**：CS 特别适合连续优化问题
9. **与其他方法结合**：CS 可与 GA、PSO、DE 等结合
10. **理论基础**：Lévy 飞行的遍历性保证了全局收敛
