# 线性方程组迭代法

## 1. 问题概述

### 1.1 线性方程组

考虑 $n$ 阶线性方程组：

$$A\mathbf{x} = \mathbf{b}$$

其中 $A$ 为 $n \times n$ 系数矩阵，$\mathbf{x}$ 为未知向量，$\mathbf{b}$ 为右端项。

### 1.2 迭代法的基本思想

将方程组改写为等价形式：

$$\mathbf{x} = B\mathbf{x} + \mathbf{c}$$

构造迭代格式：

$$\mathbf{x}^{(k+1)} = B\mathbf{x}^{(k)} + \mathbf{c}, \quad k = 0, 1, 2, \ldots$$

其中 $B$ 为迭代矩阵，$\mathbf{c}$ 为常数向量，$\mathbf{x}^{(0)}$ 为初始近似解。

### 1.3 收敛性条件

**定理**：迭代法收敛的充要条件是 $\rho(B) < 1$，其中 $\rho(B)$ 为迭代矩阵 $B$ 的谱半径。

**实用判据**：$\|B\| < 1$（任何算子范数）

## 2. Jacobi 迭代法

### 2.1 基本思想

将系数矩阵 $A$ 分解为 $A = D - L - U$，其中：
- $D$ 为对角矩阵
- $L$ 为严格下三角矩阵
- $U$ 为严格上三角矩阵

### 2.2 迭代格式

$$D\mathbf{x}^{(k+1)} = (L + U)\mathbf{x}^{(k)} + \mathbf{b}$$

$$\mathbf{x}^{(k+1)} = D^{-1}(L + U)\mathbf{x}^{(k)} + D^{-1}\mathbf{b}$$

**分量形式**：

$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{\substack{j=1 \\ j \neq i}}^{n} a_{ij} x_j^{(k)} \right), \quad i = 1, 2, \ldots, n$$

### 2.3 迭代矩阵

$$B_J = D^{-1}(L + U)$$

$$\mathbf{c}_J = D^{-1}\mathbf{b}$$

### 2.4 算法步骤

**输入**：矩阵 $A$，向量 $\mathbf{b}$，初始解 $\mathbf{x}^{(0)}$，精度要求 $\epsilon$，最大迭代次数 $N$
**输出**：近似解 $\mathbf{x}$

1. 初始化 $k = 0$
2. 对于 $i = 1, 2, \ldots, n$：
   - $x_i^{(1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j \neq i} a_{ij} x_j^{(0)} \right)$
3. 如果 $\|\mathbf{x}^{(1)} - \mathbf{x}^{(0)}\| < \epsilon$，返回 $\mathbf{x}^{(1)}$
4. $\mathbf{x}^{(0)} \leftarrow \mathbf{x}^{(1)}$，$k \leftarrow k + 1$
5. 如果 $k < N$，返回步骤 2
6. 输出"达到最大迭代次数"

### 2.5 Python 实现

```python
import numpy as np

def jacobi_iteration(A, b, x0=None, tol=1e-10, max_iter=1000):
    """
    Jacobi 迭代法
    
    参数:
        A: 系数矩阵
        b: 右端项
        x0: 初始解
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 近似解
        k: 迭代次数
        history: 迭代历史
    """
    n = len(b)
    if x0 is None:
        x0 = np.zeros(n)
    
    x = x0.copy()
    history = [x.copy()]
    
    for k in range(max_iter):
        x_new = np.zeros(n)
        
        for i in range(n):
            sigma = 0
            for j in range(n):
                if j != i:
                    sigma += A[i, j] * x[j]
            x_new[i] = (b[i] - sigma) / A[i, i]
        
        # 检查收敛
        if np.linalg.norm(x_new - x) < tol:
            return x_new, k + 1, history
        
        x = x_new
        history.append(x.copy())
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return x, max_iter, history

# 示例
A = np.array([[10, -1, 2],
              [-1, 11, -1],
              [2, -1, 10]], dtype=float)
b = np.array([6, 25, -11], dtype=float)

x_jacobi, k_jacobi, history_jacobi = jacobi_iteration(A, b)
print(f"Jacobi 迭代次数: {k_jacobi}")
print(f"近似解: {x_jacobi}")
print(f"精确解: {np.linalg.solve(A, b)}")
```

## 3. Gauss-Seidel 迭代法

### 3.1 基本思想

Gauss-Seidel 迭代法使用最新计算的分量值，加速收敛。

### 3.2 迭代格式

$$D\mathbf{x}^{(k+1)} = L\mathbf{x}^{(k+1)} + U\mathbf{x}^{(k)} + \mathbf{b}$$

$$(D - L)\mathbf{x}^{(k+1)} = U\mathbf{x}^{(k)} + \mathbf{b}$$

$$\mathbf{x}^{(k+1)} = (D - L)^{-1}U\mathbf{x}^{(k)} + (D - L)^{-1}\mathbf{b}$$

**分量形式**：

$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j=1}^{i-1} a_{ij} x_j^{(k+1)} - \sum_{j=i+1}^{n} a_{ij} x_j^{(k)} \right)$$

### 3.3 迭代矩阵

$$B_{GS} = (D - L)^{-1}U$$

$$\mathbf{c}_{GS} = (D - L)^{-1}\mathbf{b}$$

### 3.4 算法步骤

**输入**：矩阵 $A$，向量 $\mathbf{b}$，初始解 $\mathbf{x}^{(0)}$，精度要求 $\epsilon$，最大迭代次数 $N$
**输出**：近似解 $\mathbf{x}$

1. 初始化 $k = 0$，$\mathbf{x} = \mathbf{x}^{(0)}$
2. 对于 $i = 1, 2, \ldots, n$：
   - $\sigma_1 = \sum_{j=1}^{i-1} a_{ij} x_j$（使用最新值）
   - $\sigma_2 = \sum_{j=i+1}^{n} a_{ij} x_j$（使用旧值）
   - $x_i = \frac{1}{a_{ii}} (b_i - \sigma_1 - \sigma_2)$
3. 如果 $\|\mathbf{x} - \mathbf{x}^{(0)}\| < \epsilon$，返回 $\mathbf{x}$
4. $\mathbf{x}^{(0)} \leftarrow \mathbf{x}$，$k \leftarrow k + 1$
5. 如果 $k < N$，返回步骤 2

### 3.5 Python 实现

```python
import numpy as np

def gauss_seidel_iteration(A, b, x0=None, tol=1e-10, max_iter=1000):
    """
    Gauss-Seidel 迭代法
    
    参数:
        A: 系数矩阵
        b: 右端项
        x0: 初始解
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 近似解
        k: 迭代次数
    """
    n = len(b)
    if x0 is None:
        x0 = np.zeros(n)
    
    x = x0.copy()
    
    for k in range(max_iter):
        x_old = x.copy()
        
        for i in range(n):
            sigma = 0
            for j in range(n):
                if j != i:
                    sigma += A[i, j] * x[j]
            x[i] = (b[i] - sigma) / A[i, i]
        
        # 检查收敛
        if np.linalg.norm(x - x_old) < tol:
            return x, k + 1
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return x, max_iter

# 示例
A = np.array([[10, -1, 2],
              [-1, 11, -1],
              [2, -1, 10]], dtype=float)
b = np.array([6, 25, -11], dtype=float)

x_gs, k_gs = gauss_seidel_iteration(A, b)
print(f"Gauss-Seidel 迭代次数: {k_gs}")
print(f"近似解: {x_gs}")
print(f"精确解: {np.linalg.solve(A, b)}")
```

## 4. SOR 方法（逐次超松弛迭代）

### 4.1 基本思想

SOR 方法是 Gauss-Seidel 方法的加速版本，引入松弛因子 $\omega$。

### 4.2 迭代格式

$$x_i^{(k+1)} = (1 - \omega)x_i^{(k)} + \frac{\omega}{a_{ii}} \left( b_i - \sum_{j=1}^{i-1} a_{ij} x_j^{(k+1)} - \sum_{j=i+1}^{n} a_{ij} x_j^{(k)} \right)$$

### 4.3 迭代矩阵

$$B_{\omega} = (D - \omega L)^{-1}[(1 - \omega)D + \omega U]$$

### 4.4 最优松弛因子

对于某些特殊矩阵（如对称正定矩阵），最优松弛因子为：

$$\omega_{\text{opt}} = \frac{2}{1 + \sqrt{1 - \rho(B_J)^2}}$$

其中 $\rho(B_J)$ 为 Jacobi 迭代矩阵的谱半径。

### 4.5 算法步骤

**输入**：矩阵 $A$，向量 $\mathbf{b}$，松弛因子 $\omega$，初始解 $\mathbf{x}^{(0)}$，精度要求 $\epsilon$
**输出**：近似解 $\mathbf{x}$

1. 初始化 $\mathbf{x} = \mathbf{x}^{(0)}$
2. 对于 $i = 1, 2, \ldots, n$：
   - $\sigma = \sum_{j \neq i} a_{ij} x_j$
   - $x_i^{\text{new}} = (1 - \omega)x_i + \frac{\omega}{a_{ii}}(b_i - \sigma)$
   - $x_i \leftarrow x_i^{\text{new}}$
3. 如果 $\|\mathbf{x} - \mathbf{x}^{(0)}\| < \epsilon$，返回 $\mathbf{x}$
4. 返回步骤 2

### 4.6 Python 实现

```python
import numpy as np

def sor_iteration(A, b, omega, x0=None, tol=1e-10, max_iter=1000):
    """
    SOR 迭代法
    
    参数:
        A: 系数矩阵
        b: 右端项
        omega: 松弛因子
        x0: 初始解
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 近似解
        k: 迭代次数
    """
    n = len(b)
    if x0 is None:
        x0 = np.zeros(n)
    
    x = x0.copy()
    
    for k in range(max_iter):
        x_old = x.copy()
        
        for i in range(n):
            sigma = 0
            for j in range(n):
                if j != i:
                    sigma += A[i, j] * x[j]
            x[i] = (1 - omega) * x[i] + omega * (b[i] - sigma) / A[i, i]
        
        # 检查收敛
        if np.linalg.norm(x - x_old) < tol:
            return x, k + 1
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return x, max_iter

# 示例
A = np.array([[10, -1, 2],
              [-1, 11, -1],
              [2, -1, 10]], dtype=float)
b = np.array([6, 25, -11], dtype=float)

# 测试不同松弛因子
omegas = [0.5, 1.0, 1.2, 1.5]
for omega in omegas:
    x_sor, k_sor = sor_iteration(A, b, omega)
    print(f"ω = {omega}: 迭代次数 = {k_sor}, 误差 = {np.linalg.norm(x_sor - np.linalg.solve(A, b)):.2e}")
```

## 5. 收敛性分析

### 5.1 收敛定理

**定理 1**：迭代法 $\mathbf{x}^{(k+1)} = B\mathbf{x}^{(k)} + \mathbf{c}$ 收敛的充要条件是 $\rho(B) < 1$。

**定理 2**：如果 $\|B\| < 1$，则迭代法收敛，且有误差估计：

$$\|\mathbf{x}^{(k)} - \mathbf{x}^*\| \leq \frac{\|B\|^k}{1 - \|B\|} \|\mathbf{x}^{(1)} - \mathbf{x}^{(0)}\|$$

### 5.2 对角占优矩阵

**定义**：矩阵 $A$ 是对角占优的，如果：

$$|a_{ii}| > \sum_{\substack{j=1 \\ j \neq i}}^{n} |a_{ij}|, \quad i = 1, 2, \ldots, n$$

**定理**：如果 $A$ 是对角占优矩阵，则 Jacobi 和 Gauss-Seidel 迭代法都收敛。

### 5.3 对称正定矩阵

**定理**：如果 $A$ 是对称正定矩阵，则：
- Gauss-Seidel 迭代法收敛
- SOR 方法当 $0 < \omega < 2$ 时收敛

### 5.4 Python 示例

```python
import numpy as np

def check_diagonal_dominance(A):
    """检查矩阵是否对角占优"""
    n = A.shape[0]
    for i in range(n):
        if abs(A[i, i]) <= np.sum(np.abs(A[i, :])) - abs(A[i, i]):
            return False
    return True

def check_symmetric_positive_definite(A):
    """检查矩阵是否对称正定"""
    if not np.allclose(A, A.T):
        return False
    eigenvalues = np.linalg.eigvals(A)
    return np.all(eigenvalues > 0)

# 示例矩阵
A1 = np.array([[10, -1, 2],
               [-1, 11, -1],
               [2, -1, 10]], dtype=float)

A2 = np.array([[4, 1, 0],
               [1, 3, 1],
               [0, 1, 2]], dtype=float)

print("矩阵 A1:")
print(f"  对角占优: {check_diagonal_dominance(A1)}")
print(f"  对称正定: {check_symmetric_positive_definite(A1)}")

print("\n矩阵 A2:")
print(f"  对角占优: {check_diagonal_dominance(A2)}")
print(f"  对称正定: {check_symmetric_positive_definite(A2)}")
```

## 6. 共轭梯度法

### 6.1 基本思想

共轭梯度法是求解对称正定线性方程组的有效方法，可以看作是迭代法和直接法的结合。

### 6.2 算法步骤

**输入**：对称正定矩阵 $A$，向量 $\mathbf{b}$，初始解 $\mathbf{x}^{(0)}$，精度要求 $\epsilon$
**输出**：近似解 $\mathbf{x}$

1. 初始化：
   - $\mathbf{r}_0 = \mathbf{b} - A\mathbf{x}_0$
   - $\mathbf{p}_0 = \mathbf{r}_0$
   - $k = 0$
2. 当 $\|\mathbf{r}_k\| > \epsilon$ 时：
   - $\alpha_k = \frac{\mathbf{r}_k^T \mathbf{r}_k}{\mathbf{p}_k^T A \mathbf{p}_k}$
   - $\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{p}_k$
   - $\mathbf{r}_{k+1} = \mathbf{r}_k - \alpha_k A \mathbf{p}_k$
   - $\beta_k = \frac{\mathbf{r}_{k+1}^T \mathbf{r}_{k+1}}{\mathbf{r}_k^T \mathbf{r}_k}$
   - $\mathbf{p}_{k+1} = \mathbf{r}_{k+1} + \beta_k \mathbf{p}_k$
   - $k = k + 1$
3. 返回 $\mathbf{x}_k$

### 6.3 Python 实现

```python
import numpy as np

def conjugate_gradient(A, b, x0=None, tol=1e-10, max_iter=None):
    """
    共轭梯度法
    
    参数:
        A: 对称正定矩阵
        b: 右端项
        x0: 初始解
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        x: 近似解
        k: 迭代次数
    """
    n = len(b)
    if max_iter is None:
        max_iter = n
    
    if x0 is None:
        x0 = np.zeros(n)
    
    x = x0.copy()
    r = b - A @ x
    p = r.copy()
    
    for k in range(max_iter):
        Ap = A @ p
        alpha = np.dot(r, r) / np.dot(p, Ap)
        
        x = x + alpha * p
        r_new = r - alpha * Ap
        
        if np.linalg.norm(r_new) < tol:
            return x, k + 1
        
        beta = np.dot(r_new, r_new) / np.dot(r, r)
        p = r_new + beta * p
        r = r_new
    
    return x, max_iter

# 示例
A = np.array([[4, 1, 0],
              [1, 3, 1],
              [0, 1, 2]], dtype=float)
b = np.array([1, 2, 3], dtype=float)

x_cg, k_cg = conjugate_gradient(A, b)
print(f"共轭梯度法迭代次数: {k_cg}")
print(f"近似解: {x_cg}")
print(f"精确解: {np.linalg.solve(A, b)}")
```

## 7. 预条件技术

### 7.1 基本思想

预条件技术通过变换方程组，改善系数矩阵的条件数，加速迭代收敛。

### 7.2 预条件共轭梯度法

**左预条件**：

$$M^{-1}A\mathbf{x} = M^{-1}\mathbf{b}$$

其中 $M$ 为预条件矩阵，要求 $M$ 易于求逆且 $M^{-1}A$ 的条件数比 $A$ 小。

### 7.3 常用预条件子

**对角预条件**：$M = \text{diag}(A)$

**不完全 Cholesky 预条件**：$M = LL^T$，其中 $L$ 为不完全 Cholesky 因子

**代数多重网格预条件**：适用于大型稀疏系统

### 7.4 Python 实现

```python
import numpy as np
from scipy.sparse.linalg import cg
from scipy.sparse import csr_matrix

def preconditioned_conjugate_gradient(A, b, M_inv=None, x0=None, tol=1e-10, max_iter=None):
    """
    预条件共轭梯度法
    """
    n = len(b)
    if max_iter is None:
        max_iter = n
    
    if x0 is None:
        x0 = np.zeros(n)
    
    x = x0.copy()
    r = b - A @ x
    
    if M_inv is not None:
        z = M_inv @ r
    else:
        z = r
    
    p = z.copy()
    
    for k in range(max_iter):
        Ap = A @ p
        rz = np.dot(r, z)
        alpha = rz / np.dot(p, Ap)
        
        x = x + alpha * p
        r_new = r - alpha * Ap
        
        if np.linalg.norm(r_new) < tol:
            return x, k + 1
        
        if M_inv is not None:
            z_new = M_inv @ r_new
        else:
            z_new = r_new
        
        beta = np.dot(r_new, z_new) / rz
        p = z_new + beta * p
        
        r = r_new
        z = z_new
    
    return x, max_iter

# 示例：使用对角预条件
A = np.array([[100, 1, 2],
              [1, 10, -1],
              [2, -1, 10]], dtype=float)
b = np.array([100, 10, 10], dtype=float)

# 对角预条件矩阵
M_inv = np.diag(1.0 / np.diag(A))

x_pcg, k_pcg = preconditioned_conjugate_gradient(A, b, M_inv)
print(f"预条件共轭梯度法迭代次数: {k_pcg}")
print(f"近似解: {x_pcg}")
```

2. **流体力学**：Navier-Stokes 方程离散化
3. **电磁学**：Maxwell 方程数值解

5. **机器学习**：支持向量机、高斯过程

### 8.2 实际案例：有限元方程求解

```python
import numpy as np
from scipy.sparse import lil_matrix
from scipy.sparse.linalg import cg

def generate_poisson_matrix(N):
    """
    生成二维 Poisson 方程的系数矩阵
    """
    n = N * N
    A = lil_matrix((n, n))
    
    for i in range(N):
        for j in range(N):
            k = i * N + j
            A[k, k] = 4
            
            if i > 0:
                A[k, k - N] = -1
            if i < N - 1:
                A[k, k + N] = -1
            if j > 0:
                A[k, k - 1] = -1
            if j < N - 1:
                A[k, k + 1] = -1
    
    return A.tocsr()

# 生成问题
N = 50
A = generate_poisson_matrix(N)
b = np.ones(N * N)

# 使用共轭梯度法求解
x, info = cg(A, b, tol=1e-6)

print(f"共轭梯度法收敛: {info == 0}")
print(f"残差范数: {np.linalg.norm(A @ x - b):.2e}")

# 绘制解
```

## 9. 总结与要点

### 9.1 方法比较

| 方法 | 每次迭代计算量 | 收敛速度 | 存储需求 | 适用场景 |
|------|----------------|----------|----------|----------|
| Jacobi | 低 | 慢 | 低 | 教学、简单问题 |
| Gauss-Seidel | 低 | 中 | 低 | 一般问题 |
| SOR | 低 | 较快 | 低 | 优化松弛因子 |
| 共轭梯度 | 中 | 快 | 中 | 对称正定系统 |

### 9.2 选择建议

1. **小型稠密系统**：使用直接法（LU 分解）
2. **大型稀疏系统**：使用迭代法
3. **对称正定系统**：使用共轭梯度法
4. **非对称系统**：使用 GMRES 或 BiCGSTAB
5. **病态系统**：使用预条件技术

### 9.3 关键要点

- 迭代法的收敛性取决于迭代矩阵的谱半径
- 对角占优矩阵保证 Jacobi 和 Gauss-Seidel 方法收敛
- SOR 方法可以通过选择最优松弛因子加速收敛
- 共轭梯度法是求解对称正定系统的最有效方法之一
- 预条件技术可以显著改善迭代法的收敛性
- 实际应用中常使用成熟的库（如 scipy.sparse.linalg）
