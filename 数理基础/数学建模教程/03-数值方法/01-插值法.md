# 插值法

## 1. 插值问题概述

### 1.1 插值问题的定义

给定区间 $[a, b]$ 上的 $n+1$ 个互不相同的节点 $x_0, x_1, \ldots, x_n$ 及其对应的函数值 $y_0, y_1, \ldots, y_n$，寻找一个函数 $\varphi(x)$ 使得：

$$\varphi(x_i) = y_i, \quad i = 0, 1, \ldots, n$$

则称 $\varphi(x)$ 为插值函数，$x_0, x_1, \ldots, x_n$ 为插值节点，$[a, b]$ 为插值区间。

### 1.2 插值条件

插值函数必须满足：
- **插值条件**：在每个节点处，插值函数值等于给定函数值
- **光滑性**：插值函数应具有一定的光滑性
- **唯一性**：对于给定的节点，插值多项式是唯一的

### 1.3 误差估计

插值余项（误差）为：

$$R_n(x) = f(x) - \varphi(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!} \prod_{i=0}^{n}(x - x_i)$$

其中 $\xi \in [a, b]$ 且依赖于 $x$。

## 2. Lagrange 插值法

### 2.1 基本思想

Lagrange 插值法通过构造插值基函数来构建插值多项式。对于 $n+1$ 个节点，定义 Lagrange 基函数：

$$l_i(x) = \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{x - x_j}{x_i - x_j}, \quad i = 0, 1, \ldots, n$$

### 2.2 Lagrange 插值多项式

Lagrange 插值多项式为：

$$L_n(x) = \sum_{i=0}^{n} y_i l_i(x) = \sum_{i=0}^{n} y_i \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{x - x_j}{x_i - x_j}$$

### 2.3 算法步骤

**输入**：节点 $(x_i, y_i)$，$i = 0, 1, \ldots, n$，以及插值点 $x$
**输出**：插值结果 $L_n(x)$

1. 初始化 $result = 0$
2. 对于每个 $i = 0, 1, \ldots, n$：
   - 计算基函数 $l_i(x) = 1$
   - 对于每个 $j = 0, 1, \ldots, n$ 且 $j \neq i$：
     - $l_i(x) = l_i(x) \times \frac{x - x_j}{x_i - x_j}$
   - $result = result + y_i \times l_i(x)$
3. 返回 $result$

### 2.4 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def lagrange_interpolation(x_nodes, y_nodes, x):
    """
    Lagrange 插值法
    
    参数:
        x_nodes: 插值节点 x 坐标
        y_nodes: 插值节点 y 坐标
        x: 插值点
    返回:
        插值结果
    """
    n = len(x_nodes)
    result = 0.0
    
    for i in range(n):
        # 计算基函数 l_i(x)
        basis = 1.0
        for j in range(n):
            if j != i:
                basis *= (x - x_nodes[j]) / (x_nodes[i] - x_nodes[j])
        result += y_nodes[i] * basis
    
    return result

# 示例使用
x_nodes = np.array([0, 1, 2, 3, 4])
y_nodes = np.array([1, 3, 2, 5, 4])
x = np.linspace(0, 4, 100)
y = [lagrange_interpolation(x_nodes, y_nodes, xi) for xi in x]

plt.figure(figsize=(10, 6))
plt.plot(x, y, 'b-', label='Lagrange 插值')
plt.plot(x_nodes, y_nodes, 'ro', label='插值节点')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Lagrange 插值法示例')
plt.legend()
plt.grid(True)
plt.show()
```

### 2.5 特点分析

**优点**：
- 理论简单，易于理解
- 公式对称，形式美观
- 适用于理论分析

**缺点**：
- 计算量大，时间复杂度 $O(n^2)$
- 增加节点时需要重新计算所有基函数
- 可能出现 Runge 现象（高次插值振荡）

## 3. Newton 插值法

### 3.1 差商定义

**一阶差商**：

$$f[x_i, x_j] = \frac{f(x_j) - f(x_i)}{x_j - x_i}$$

**二阶差商**：

$$f[x_i, x_j, x_k] = \frac{f[x_j, x_k] - f[x_i, x_j]}{x_k - x_i}$$

**k 阶差商**：

$$f[x_0, x_1, \ldots, x_k] = \frac{f[x_1, x_2, \ldots, x_k] - f[x_0, x_1, \ldots, x_{k-1}]}{x_k - x_0}$$

### 3.2 Newton 插值多项式

Newton 插值多项式为：

$$N_n(x) = f[x_0] + f[x_0, x_1](x - x_0) + f[x_0, x_1, x_2](x - x_0)(x - x_1) + \cdots + f[x_0, x_1, \ldots, x_n](x - x_0)(x - x_1)\cdots(x - x_{n-1})$$

可以写成：

$$N_n(x) = \sum_{k=0}^{n} f[x_0, x_1, \ldots, x_k] \prod_{j=0}^{k-1}(x - x_j)$$

### 3.3 差商表构造

差商表的构造方法：

| $i$ | $x_i$ | $f(x_i)$ | 一阶差商 | 二阶差商 | 三阶差商 |
|-----|--------|-----------|----------|----------|----------|
| 0 | $x_0$ | $f(x_0)$ | | | |
| 1 | $x_1$ | $f(x_1)$ | $f[x_0, x_1]$ | | |
| 2 | $x_2$ | $f(x_2)$ | $f[x_1, x_2]$ | $f[x_0, x_1, x_2]$ | |
| 3 | $x_3$ | $f(x_3)$ | $f[x_2, x_3]$ | $f[x_1, x_2, x_3]$ | $f[x_0, x_1, x_2, x_3]$ |

### 3.4 算法步骤

**输入**：节点 $(x_i, y_i)$，$i = 0, 1, \ldots, n$，以及插值点 $x$
**输出**：插值结果 $N_n(x)$

1. 构造差商表：
   - 初始化 $c_i = y_i$，$i = 0, 1, \ldots, n$
   - 对于 $k = 1, 2, \ldots, n$：
     - 对于 $i = n, n-1, \ldots, k$：
       - $c_i = \frac{c_i - c_{i-1}}{x_i - x_{i-k}}$
2. 计算插值结果：
   - $result = c_n$
   - 对于 $k = n-1, n-2, \ldots, 0$：
     - $result = result \times (x - x_k) + c_k$
3. 返回 $result$

### 3.5 Python 实现

```python
import numpy as np

def newton_interpolation(x_nodes, y_nodes, x):
    """
    Newton 插值法
    
    参数:
        x_nodes: 插值节点 x 坐标
        y_nodes: 插值节点 y 坐标
        x: 插值点
    返回:
        插值结果
    """
    n = len(x_nodes)
    
    # 构造差商表
    divided_diff = np.zeros((n, n))
    divided_diff[:, 0] = y_nodes
    
    for j in range(1, n):
        for i in range(j, n):
            divided_diff[i, j] = (divided_diff[i, j-1] - divided_diff[i-1, j-1]) / (x_nodes[i] - x_nodes[i-j])
    
    # 提取差商系数（第一行）
    coefficients = divided_diff[0, :]
    
    # 计算 Newton 插值结果
    result = coefficients[n-1]
    for k in range(n-2, -1, -1):
        result = result * (x - x_nodes[k]) + coefficients[k]
    
    return result

# 示例使用
x_nodes = np.array([0, 1, 2, 3, 4])
y_nodes = np.array([1, 3, 2, 5, 4])
x = np.linspace(0, 4, 100)
y = [newton_interpolation(x_nodes, y_nodes, xi) for xi in x]

plt.figure(figsize=(10, 6))
plt.plot(x, y, 'g-', label='Newton 插值')
plt.plot(x_nodes, y_nodes, 'ro', label='插值节点')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Newton 插值法示例')
plt.legend()
plt.grid(True)
plt.show()
```

### 3.6 与 Lagrange 插值的比较

**相同点**：
- 都是 $n$ 次多项式插值
- 插值多项式唯一
- 在相同节点上结果相同

**不同点**：
- Newton 插值可以递推计算，增加节点时只需增加一项
- Newton 插值使用差商，计算更高效
- Newton 插值适合动态添加节点的情况

## 4. 三次样条插值

### 4.1 样条插值定义

给定节点 $x_0 < x_1 < \cdots < x_n$ 和对应的函数值 $y_0, y_1, \ldots, y_n$，三次样条插值函数 $S(x)$ 满足：

1. **分段三次多项式**：在每个子区间 $[x_i, x_{i+1}]$ 上，$S(x)$ 是三次多项式
2. **连续性**：$S(x) \in C^2[x_0, x_n]$，即 $S(x)$ 具有连续的一阶和二阶导数
3. **插值条件**：$S(x_i) = y_i$，$i = 0, 1, \ldots, n$

### 4.2 样条函数表示

在每个区间 $[x_i, x_{i+1}]$ 上，样条函数可以表示为：

$$S_i(x) = a_i + b_i(x - x_i) + c_i(x - x_i)^2 + d_i(x - x_i)^3$$

其中 $i = 0, 1, \ldots, n-1$。

### 4.3 边界条件

**自然边界条件**（Natural Spline）：

$$S''(x_0) = 0, \quad S''(x_n) = 0$$

**固定边界条件**（Clamped Spline）：

$$S'(x_0) = f'(x_0), \quad S'(x_n) = f'(x_n)$$

**周期边界条件**（Periodic Spline）：

$$S(x_0) = S(x_n), \quad S'(x_0) = S'(x_n), \quad S''(x_0) = S''(x_n)$$

### 4.4 算法步骤（自然样条）

**输入**：节点 $(x_i, y_i)$，$i = 0, 1, \ldots, n$
**输出**：样条系数 $a_i, b_i, c_i, d_i$

1. 计算步长 $h_i = x_{i+1} - x_i$
2. 构造线性方程组：
   - 令 $m_i = S''(x_i)$
   - 对于 $i = 1, 2, \ldots, n-1$：
     $$h_{i-1}m_{i-1} + 2(h_{i-1} + h_i)m_i + h_i m_{i+1} = 6\left(\frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}\right)$$
3. 应用自然边界条件：$m_0 = 0$，$m_n = 0$
4. 求解三对角线性方程组得到 $m_i$
5. 计算系数：
   - $a_i = y_i$
   - $b_i = \frac{y_{i+1} - y_i}{h_i} - \frac{h_i}{6}(2m_i + m_{i+1})$
   - $c_i = \frac{m_i}{2}$
   - $d_i = \frac{m_{i+1} - m_i}{6h_i}$

### 4.5 Python 实现

```python
import numpy as np
from scipy import interpolate

def natural_cubic_spline(x_nodes, y_nodes, x):
    """
    自然三次样条插值
    
    参数:
        x_nodes: 插值节点 x 坐标
        y_nodes: 插值节点 y 坐标
        x: 插值点
    返回:
        插值结果
    """
    n = len(x_nodes)
    h = np.diff(x_nodes)
    
    # 构造线性方程组
    A = np.zeros((n, n))
    b = np.zeros(n)
    
    # 自然边界条件
    A[0, 0] = 1
    A[n-1, n-1] = 1
    
    for i in range(1, n-1):
        A[i, i-1] = h[i-1]
        A[i, i] = 2 * (h[i-1] + h[i])
        A[i, i+1] = h[i]
        b[i] = 6 * ((y_nodes[i+1] - y_nodes[i]) / h[i] - (y_nodes[i] - y_nodes[i-1]) / h[i-1])
    
    # 求解 m (二阶导数)
    m = np.linalg.solve(A, b)
    
    # 计算插值结果
    # 找到 x 所在的区间
    idx = np.searchsorted(x_nodes, x) - 1
    idx = np.clip(idx, 0, n-2)
    
    # 计算样条值
    dx = x - x_nodes[idx]
    result = (a[idx] + b[idx] * dx + c[idx] * dx**2 + d[idx] * dx**3)
    
    return result

# 使用 scipy 的样条插值
x_nodes = np.array([0, 1, 2, 3, 4])
y_nodes = np.array([1, 3, 2, 5, 4])
x = np.linspace(0, 4, 100)

# 创建样条插值函数
spline_func = interpolate.CubicSpline(x_nodes, y_nodes, bc_type='natural')
y_spline = spline_func(x)

# 创建 Lagrange 插值
lagrange_func = interpolate.lagrange(x_nodes, y_nodes)
y_lagrange = lagrange_func(x)

plt.figure(figsize=(12, 6))
plt.plot(x, y_lagrange, 'b-', label='Lagrange 插值')
plt.plot(x, y_spline, 'r-', label='三次样条插值')
plt.plot(x_nodes, y_nodes, 'ko', label='插值节点')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Lagrange 插值与三次样条插值比较')
plt.legend()
plt.grid(True)
plt.show()
```

### 4.6 样条插值的优点

- **光滑性好**：具有连续的一阶和二阶导数
- **避免 Runge 现象**：使用低次多项式分段插值
- **局部性**：改变一个节点只影响相邻区间
- **稳定性好**：对数据扰动不敏感

## 5. 插值法的收敛性分析

### 5.1 多项式插值的收敛性

对于等距节点的多项式插值，当插值多项式次数 $n \to \infty$ 时，插值多项式不一定收敛到被插值函数。

**Runge 现象**：对于某些函数（如 Runge 函数），高次多项式插值会出现严重振荡。

### 5.2 Runge 函数示例

Runge 函数：

$$f(x) = \frac{1}{1 + 25x^2}, \quad x \in [-1, 1]$$

在等距节点上进行高次插值时，插值多项式在区间端点附近会出现剧烈振荡。

### 5.3 收敛条件

多项式插值收敛的条件：

1. **函数光滑性**：被插值函数足够光滑
2. **节点选择**：使用 Chebyshev 节点而非等距节点
3. **插值次数**：适当选择插值次数，避免过高次插值

### 5.4 Chebyshev 节点

Chebyshev 节点定义为：

$$x_k = \cos\left(\frac{2k+1}{2(n+1)}\pi\right), \quad k = 0, 1, \ldots, n$$

使用 Chebyshev 节点可以最小化插值误差的上界。

## 6. 应用实例

### 6.1 数据插值

在实际应用中，插值法常用于：
- 数据补全：填补缺失数据点
- 数据加密：增加数据点密度
- 函数逼近：用简单函数逼近复杂函数

### 6.2 图形学应用

在计算机图形学中，插值法用于：
- 曲线绘制：Bézier 曲线、B 样条曲线
- 图像缩放：双线性插值、双三次插值
- 动画生成：关键帧插值

### 6.3 数值积分与微分

插值法是许多数值方法的基础：
- **数值积分**：基于插值多项式的 Newton-Cotes 公式
- **数值微分**：基于插值多项式的微分公式
- **常微分方程数值解**：基于插值的多步法

## 7. 总结与要点

### 7.1 插值方法比较

| 方法 | 计算复杂度 | 稳定性 | 适用场景 |
|------|-----------|--------|----------|
| Lagrange 插值 | $O(n^2)$ | 较差 | 理论分析 |
| Newton 插值 | $O(n^2)$ | 较好 | 动态添加节点 |
| 三次样条插值 | $O(n)$ | 好 | 实际应用 |

### 7.2 选择建议

1. **节点数少**（$n \leq 5$）：使用 Lagrange 或 Newton 插值
2. **节点数多**（$n > 5$）：使用三次样条插值
3. **需要光滑性**：使用三次样条插值
4. **动态添加节点**：使用 Newton 插值

### 7.3 关键要点

- 插值函数必须通过所有给定节点
- 高次多项式插值可能出现 Runge 现象
- 三次样条插值是实际应用中最常用的方法
- 节点选择对插值效果有重要影响
- 插值误差与被插值函数的光滑性密切相关
