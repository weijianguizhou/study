# 常微分方程数值解

## 1. 问题概述

### 1.1 初值问题

考虑一阶常微分方程初值问题：

$$\begin{cases} \frac{dy}{dx} = f(x, y) \\ y(x_0) = y_0 \end{cases}$$

其中 $f(x, y)$ 为已知函数，$y_0$ 为初始条件。

### 1.2 解的存在唯一性

**Picard 定理**：如果 $f(x, y)$ 在矩形区域 $R = \{(x, y) : |x - x_0| \leq a, |y - y_0| \leq b\}$ 上连续，且关于 $y$ 满足 Lipschitz 条件：

$$|f(x, y_1) - f(x, y_2)| \leq L|y_1 - y_2|$$

则初值问题在 $[x_0 - h, x_0 + h]$ 上存在唯一解，其中 $h = \min(a, b/M)$，$M = \max_R |f(x, y)|$。

### 1.3 数值解的目标

寻找离散点 $x_n = x_0 + nh$ 上的近似解 $y_n \approx y(x_n)$。

## 2. Euler 方法

### 2.1 基本思想

使用差商近似导数：

$$\frac{dy}{dx}\bigg|_{x=x_n} \approx \frac{y_{n+1} - y_n}{h}$$

代入微分方程得到：

$$\frac{y_{n+1} - y_n}{h} = f(x_n, y_n)$$

### 2.2 显式 Euler 公式

$$y_{n+1} = y_n + hf(x_n, y_n)$$

**局部截断误差**：

$$T_{n+1} = y(x_{n+1}) - y_{n+1} = \frac{h^2}{2}y''(\xi_n)$$

**全局截断误差**：

$$|y(x_n) - y_n| \leq \frac{hM}{2L}(e^{L(x_n - x_0)} - 1)$$

误差阶为 $O(h)$。

### 2.3 隐式 Euler 公式

$$y_{n+1} = y_n + hf(x_{n+1}, y_{n+1})$$

**特点**：
- 需要求解非线性方程
- 无条件稳定
- 误差阶为 $O(h)$

### 2.4 梯形公式

$$y_{n+1} = y_n + \frac{h}{2}[f(x_n, y_n) + f(x_{n+1}, y_{n+1})]$$

**特点**：
- 二阶精度 $O(h^2)$
- 隐式方法
- 无条件稳定

### 2.5 改进 Euler 方法（预测-校正法）

**预测步**：$\bar{y}_{n+1} = y_n + hf(x_n, y_n)$

**校正步**：$y_{n+1} = y_n + \frac{h}{2}[f(x_n, y_n) + f(x_{n+1}, \bar{y}_{n+1})]$

**误差阶**：$O(h^2)$

### 2.6 算法步骤（显式 Euler）

**输入**：函数 $f$，初始条件 $(x_0, y_0)$，步长 $h$，计算步数 $N$
**输出**：数值解 $(x_n, y_n)$，$n = 0, 1, \ldots, N$

1. 初始化 $x = x_0$，$y = y_0$
2. 对于 $n = 0, 1, \ldots, N-1$：
   - 计算 $k = f(x, y)$
   - 更新 $y = y + hk$
   - 更新 $x = x + h$
3. 返回所有 $(x_n, y_n)$

### 2.7 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def euler_method(f, x0, y0, h, N):
    """
    显式 Euler 方法
    
    参数:
        f: 函数 f(x, y)
        x0, y0: 初始条件
        h: 步长
        N: 计算步数
    返回:
        x, y: 数值解
    """
    x = np.zeros(N + 1)
    y = np.zeros(N + 1)
    x[0] = x0
    y[0] = y0
    
    for n in range(N):
        y[n+1] = y[n] + h * f(x[n], y[n])
        x[n+1] = x[n] + h
    
    return x, y

def improved_euler_method(f, x0, y0, h, N):
    """
    改进 Euler 方法（预测-校正法）
    
    参数:
        f: 函数 f(x, y)
        x0, y0: 初始条件
        h: 步长
        N: 计算步数
    返回:
        x, y: 数值解
    """
    x = np.zeros(N + 1)
    y = np.zeros(N + 1)
    x[0] = x0
    y[0] = y0
    
    for n in range(N):
        # 预测步
        y_predict = y[n] + h * f(x[n], y[n])
        # 校正步
        y[n+1] = y[n] + h/2 * (f(x[n], y[n]) + f(x[n+1], y_predict))
        x[n+1] = x[n] + h
    
    return x, y

# 示例：dy/dx = y, y(0) = 1，精确解 y = exp(x)
f = lambda x, y: y
x0, y0 = 0.0, 1.0
exact_solution = lambda x: np.exp(x)

# 不同步长的数值解
h_values = [0.5, 0.2, 0.1, 0.05]
x_range = [0, 2]

plt.figure(figsize=(12, 8))

for i, h in enumerate(h_values):
    N = int((x_range[1] - x_range[0]) / h)
    x_euler, y_euler = euler_method(f, x0, y0, h, N)
    x_improved, y_improved = improved_euler_method(f, x0, y0, h, N)
    
    # 精确解
    x_exact = np.linspace(x_range[0], x_range[1], 100)
    y_exact = exact_solution(x_exact)
    
    plt.subplot(2, 2, i + 1)
    plt.plot(x_exact, y_exact, 'k-', label='精确解', linewidth=2)
    plt.plot(x_euler, y_euler, 'bo-', label='Euler 方法', markersize=4)
    plt.plot(x_improved, y_improved, 'rs-', label='改进 Euler', markersize=4)
    plt.title(f'h = {h}')
    plt.xlabel('x')
    plt.ylabel('y')
    plt.legend()
    plt.grid(True)

plt.tight_layout()
plt.show()
```

## 3. Runge-Kutta 方法

### 3.1 基本思想

Runge-Kutta 方法通过在一步内计算多个点的函数值，组合得到高精度近似。

### 3.2 经典四阶 Runge-Kutta 方法（RK4）

$$\begin{aligned} k_1 &= f(x_n, y_n) \\ k_2 &= f(x_n + \frac{h}{2}, y_n + \frac{h}{2}k_1) \\ k_3 &= f(x_n + \frac{h}{2}, y_n + \frac{h}{2}k_2) \\ k_4 &= f(x_n + h, y_n + hk_3) \\ y_{n+1} &= y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4) \end{aligned}$$

**误差阶**：$O(h^4)$

### 3.3 三阶 Runge-Kutta 方法

$$\begin{aligned} k_1 &= f(x_n, y_n) \\ k_2 &= f(x_n + \frac{h}{2}, y_n + \frac{h}{2}k_1) \\ k_3 &= f(x_n + h, y_n - hk_1 + 2hk_2) \\ y_{n+1} &= y_n + \frac{h}{6}(k_1 + 4k_2 + k_3) \end{aligned}$$

**误差阶**：$O(h^3)$

### 3.4 二阶 Runge-Kutta 方法（改进 Euler）

$$\begin{aligned} k_1 &= f(x_n, y_n) \\ k_2 &= f(x_n + h, y_n + hk_1) \\ y_{n+1} &= y_n + \frac{h}{2}(k_1 + k_2) \end{aligned}$$

**误差阶**：$O(h^2)$

### 3.5 算法步骤（RK4）

**输入**：函数 $f$，初始条件 $(x_0, y_0)$，步长 $h$，计算步数 $N$
**输出**：数值解 $(x_n, y_n)$

1. 初始化 $x = x_0$，$y = y_0$
2. 对于 $n = 0, 1, \ldots, N-1$：
   - $k_1 = f(x, y)$
   - $k_2 = f(x + h/2, y + h k_1/2)$
   - $k_3 = f(x + h/2, y + h k_2/2)$
   - $k_4 = f(x + h, y + h k_3)$
   - $y = y + h(k_1 + 2k_2 + 2k_3 + k_4)/6$
   - $x = x + h$
3. 返回所有 $(x_n, y_n)$

### 3.6 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def runge_kutta_4(f, x0, y0, h, N):
    """
    经典四阶 Runge-Kutta 方法
    
    参数:
        f: 函数 f(x, y)
        x0, y0: 初始条件
        h: 步长
        N: 计算步数
    返回:
        x, y: 数值解
    """
    x = np.zeros(N + 1)
    y = np.zeros(N + 1)
    x[0] = x0
    y[0] = y0
    
    for n in range(N):
        k1 = f(x[n], y[n])
        k2 = f(x[n] + h/2, y[n] + h*k1/2)
        k3 = f(x[n] + h/2, y[n] + h*k2/2)
        k4 = f(x[n] + h, y[n] + h*k3)
        
        y[n+1] = y[n] + h * (k1 + 2*k2 + 2*k3 + k4) / 6
        x[n+1] = x[n] + h
    
    return x, y

# 示例：dy/dx = y, y(0) = 1
f = lambda x, y: y
x0, y0 = 0.0, 1.0
exact_solution = lambda x: np.exp(x)

# 不同步长的数值解
h_values = [0.5, 0.2, 0.1, 0.05]
x_range = [0, 2]

plt.figure(figsize=(12, 8))

for i, h in enumerate(h_values):
    N = int((x_range[1] - x_range[0]) / h)
    x_rk4, y_rk4 = runge_kutta_4(f, x0, y0, h, N)
    
    # 精确解
    x_exact = np.linspace(x_range[0], x_range[1], 100)
    y_exact = exact_solution(x_exact)
    
    # 计算误差
    y_exact_at_nodes = exact_solution(x_rk4)
    max_error = np.max(np.abs(y_rk4 - y_exact_at_nodes))
    
    plt.subplot(2, 2, i + 1)
    plt.plot(x_exact, y_exact, 'k-', label='精确解', linewidth=2)
    plt.plot(x_rk4, y_rk4, 'go-', label='RK4', markersize=4)
    plt.title(f'h = {h}, 最大误差 = {max_error:.2e}')
    plt.xlabel('x')
    plt.ylabel('y')
    plt.legend()
    plt.grid(True)

plt.tight_layout()
plt.show()
```

## 4. Adams 方法

### 4.1 线性多步法

线性多步法的一般形式：

$$\sum_{j=0}^{k} \alpha_j y_{n+j} = h \sum_{j=0}^{k} \beta_j f(x_{n+j}, y_{n+j})$$

其中 $\alpha_j$ 和 $\beta_j$ 为系数，$k$ 为步数。

### 4.2 Adams-Bashforth 方法（显式）

**二阶 Adams-Bashforth**：

$$y_{n+2} = y_{n+1} + \frac{h}{2}[3f(x_{n+1}, y_{n+1}) - f(x_n, y_n)]$$

**三阶 Adams-Bashforth**：

$$y_{n+3} = y_{n+2} + \frac{h}{12}[23f(x_{n+2}, y_{n+2}) - 16f(x_{n+1}, y_{n+1}) + 5f(x_n, y_n)]$$

**四阶 Adams-Bashforth**：

$$y_{n+4} = y_{n+3} + \frac{h}{24}[55f(x_{n+3}, y_{n+3}) - 59f(x_{n+2}, y_{n+2}) + 37f(x_{n+1}, y_{n+1}) - 9f(x_n, y_n)]$$

### 4.3 Adams-Moulton 方法（隐式）

**二阶 Adams-Moulton（梯形公式）**：

$$y_{n+1} = y_n + \frac{h}{2}[f(x_n, y_n) + f(x_{n+1}, y_{n+1})]$$

**三阶 Adams-Moulton**：

$$y_{n+2} = y_{n+1} + \frac{h}{12}[5f(x_{n+2}, y_{n+2}) + 8f(x_{n+1}, y_{n+1}) - f(x_n, y_n)]$$

**四阶 Adams-Moulton**：

$$y_{n+3} = y_{n+2} + \frac{h}{24}[9f(x_{n+3}, y_{n+3}) + 19f(x_{n+2}, y_{n+2}) - 5f(x_{n+1}, y_{n+1}) + f(x_n, y_n)]$$

### 4.4 预测-校正方法

**Adams 预测-校正法**：

1. **预测**：使用显式 Adams-Bashforth 公式计算 $y_{n+1}^P$
2. **校正**：使用隐式 Adams-Moulton 公式计算 $y_{n+1}^C$

**四阶 Adams 预测-校正**：

$$\begin{aligned} y_{n+1}^P &= y_n + \frac{h}{24}[55f_n - 59f_{n-1} + 37f_{n-2} - 9f_{n-3}] \\ y_{n+1}^C &= y_n + \frac{h}{24}[9f(x_{n+1}, y_{n+1}^P) + 19f_n - 5f_{n-1} + f_{n-2}] \end{aligned}$$

### 4.5 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def adams_bashforth_4(f, x0, y0, h, N, x_init, y_init):
    """
    四阶 Adams-Bashforth 方法
    
    参数:
        f: 函数 f(x, y)
        x0, y0: 初始条件
        h: 步长
        N: 计算步数
        x_init, y_init: 前 4 个点的值（用于启动）
    返回:
        x, y: 数值解
    """
    x = np.zeros(N + 1)
    y = np.zeros(N + 1)
    
    # 使用初始值
    x[:4] = x_init
    y[:4] = y_init
    
    # 计算前 4 个点的函数值
    f_values = [f(x[i], y[i]) for i in range(4)]
    
    for n in range(3, N):
        # Adams-Bashforth 公式
        y[n+1] = y[n] + h/24 * (55*f_values[n] - 59*f_values[n-1] + 
                                  37*f_values[n-2] - 9*f_values[n-3])
        x[n+1] = x[n] + h
        f_values.append(f(x[n+1], y[n+1]))
    
    return x, y

# 示例：dy/dx = y, y(0) = 1
f = lambda x, y: y
x0, y0 = 0.0, 1.0
exact_solution = lambda x: np.exp(x)

# 使用 RK4 计算启动值
h = 0.1
x_rk4, y_rk4 = runge_kutta_4(f, x0, y0, h, 3)
x_init = x_rk4[:4]
y_init = y_rk4[:4]

# Adams-Bashforth 计算
N = 20
x_adams, y_adams = adams_bashforth_4(f, x0, y0, h, N, x_init, y_init)

# 精确解
x_exact = np.linspace(0, 2, 100)
y_exact = exact_solution(x_exact)

plt.figure(figsize=(10, 6))
plt.plot(x_exact, y_exact, 'k-', label='精确解', linewidth=2)
plt.plot(x_adams, y_adams, 'mo-', label='Adams-Bashforth 4', markersize=5)
plt.xlabel('x')
plt.ylabel('y')
plt.title('Adams-Bashforth 方法')
plt.legend()
plt.grid(True)
plt.show()
```

## 5. 收敛性与稳定性

### 5.1 收敛性定义

数值方法收敛是指当 $h \to 0$ 时，$y_n \to y(x_n)$。

**定理**：如果数值方法是相容的且零稳定的，则该方法收敛。

### 5.2 相容性

数值方法与微分方程相容是指其局部截断误差 $T_n \to 0$ 当 $h \to 0$。

**Euler 方法**：$T_n = O(h)$，相容

**RK4 方法**：$T_n = O(h^4)$，相容

### 5.3 零稳定性

数值方法零稳定是指差分方程的齐次部分的解当 $h \to 0$ 时保持有界。

**Euler 方法**：零稳定

**Adams 方法**：对于步长 $h$ 满足 $|1 + h\lambda| \leq 1$ 时稳定（$\lambda$ 为 Jacobian 的特征值）

### 5.4 绝对稳定性

**定义**：对于测试方程 $y' = \lambda y$（$\text{Re}(\lambda) < 0$），数值方法满足 $|y_{n+1}| \leq |y_n|$。

**Euler 方法**：绝对稳定区域为 $|1 + h\lambda| \leq 1$

**RK4 方法**：绝对稳定区域为 $|1 + h\lambda + \frac{(h\lambda)^2}{2} + \frac{(h\lambda)^3}{6} + \frac{(h\lambda)^4}{24}| \leq 1$

### 5.5 稳定性区域

```python
import numpy as np
import matplotlib.pyplot as plt

def stability_region(method='euler'):
    """
    绘制数值方法的绝对稳定性区域
    """
    # 复平面上的网格
    x = np.linspace(-3, 1, 200)
    y = np.linspace(-2, 2, 200)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j * Y
    
    if method == 'euler':
        # Euler 方法的稳定性函数
        R = np.abs(1 + Z)
    elif method == 'rk4':
        # RK4 方法的稳定性函数
        R = np.abs(1 + Z + Z**2/2 + Z**3/6 + Z**4/24)
    elif method == 'ab4':
        # Adams-Bashforth 4 方法的稳定性函数（近似）
        R = np.abs(1 + Z * (55/24 - 59/24*np.exp(-Z) + 37/24*np.exp(-2*Z) - 9/24*np.exp(-3*Z)))
    
    # 绘制稳定性区域
    plt.figure(figsize=(8, 8))
    plt.contour(X, Y, R, levels=[1], colors='blue')
    plt.fill(np.real(Z[R <= 1]), np.imag(Z[R <= 1]), alpha=0.3, color='blue')
    plt.axhline(y=0, color='k', linewidth=0.5)
    plt.axvline(x=0, color='k', linewidth=0.5)
    plt.xlabel('Re(hλ)')
    plt.ylabel('Im(hλ)')
    plt.title(f'{method.upper()} 方法稳定性区域')
    plt.grid(True)
    plt.axis('equal')
    plt.show()

# 绘制不同方法的稳定性区域
stability_region('euler')
stability_region('rk4')
```

## 6. 刚性问题

### 6.1 刚性定义

刚性问题是指微分方程中存在多个时间尺度，其中某些分量变化很快，而另一些分量变化很慢。

**刚性比**：

$$s = \frac{\max_i |\text{Re}(\lambda_i)|}{\min_i |\text{Re}(\lambda_i)|}$$

其中 $\lambda_i$ 为 Jacobian 矩阵的特征值。

### 6.2 刚性问题的挑战

- 显式方法需要非常小的步长才能保持稳定
- 计算量巨大
- 需要使用隐式方法

### 6.3 隐式方法求解刚性问题

**隐式 Euler 方法**：

$$y_{n+1} = y_n + hf(x_{n+1}, y_{n+1})$$

需要求解非线性方程组：

$$F(y) = y - y_n - hf(x_{n+1}, y) = 0$$

**求解方法**：Newton 迭代

### 6.4 Python 示例

```python
import numpy as np
from scipy.integrate import solve_ivp

# 刚性问题示例：Van der Pol 方程
def vanderpol(t, y, mu=1000):
    """Van der Pol 方程"""
    return [y[1], mu*(1 - y[0]**2)*y[1] - y[0]]

# 使用不同方法求解
t_span = [0, 3000]
y0 = [2.0, 0.0]

# 显式方法（可能失败）
try:
    sol_explicit = solve_ivp(vanderpol, t_span, y0, method='RK45', 
                             max_step=0.1, args=(1000,))
    print("RK45 方法成功")
except:
    print("RK45 方法失败或太慢")

# 隐式方法（适用于刚性问题）
sol_implicit = solve_ivp(vanderpol, t_span, y0, method='Radau', 
                         args=(1000,))
print(f"Radau 方法: {len(sol_implicit.t)} 个点")
```

## 7. 边值问题

### 7.1 两点边值问题

考虑二阶常微分方程边值问题：

$$\begin{cases} y'' = f(x, y, y') \\ y(a) = \alpha \\ y(b) = \beta \end{cases}$$

### 7.2 打靶法

**基本思想**：将边值问题转化为初值问题序列。

1. 猜测 $y'(a) = s$
2. 求解初值问题：$y'' = f(x, y, y')$，$y(a) = \alpha$，$y'(a) = s$
3. 检查 $y(b) = \beta$ 是否满足
4. 调整 $s$ 直到满足边界条件

### 7.3 有限差分法

**基本思想**：将导数用差分近似，将微分方程转化为代数方程组。

**二阶导数近似**：

$$y''(x_i) \approx \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}$$

**差分方程**：

$$\frac{y_{i+1} - 2y_i + y_{i-1}}{h^2} = f(x_i, y_i, \frac{y_{i+1} - y_{i-1}}{2h})$$

### 7.4 Python 实现

```python
import numpy as np
from scipy.integrate import solve_bvp

# 边值问题：y'' + y = 0, y(0) = 0, y(pi) = 0
def ode(x, y):
    """微分方程"""
    return np.vstack([y[1], -y[0]])

def bc(ya, yb):
    """边界条件"""
    return np.array([ya[0], yb[0]])

# 初始猜测
x = np.linspace(0, np.pi, 100)
y_guess = np.zeros((2, x.size))
y_guess[0] = np.sin(x)  # 初始猜测

# 求解
sol = solve_bvp(ode, bc, x, y_guess)

# 精确解
x_plot = np.linspace(0, np.pi, 100)
y_exact = np.sin(x_plot)

# 绘图
plt.figure(figsize=(10, 6))
plt.plot(x_plot, y_exact, 'k-', label='精确解', linewidth=2)
plt.plot(sol.x, sol.y[0], 'ro', label='数值解', markersize=3)
plt.xlabel('x')
plt.ylabel('y')
plt.title('边值问题数值解')
plt.legend()
plt.grid(True)
plt.show()
```

## 8. 应用实例

### 8.2 实际案例：Lotka-Volterra 方程

捕食者-猎物模型：

$$\begin{aligned} \frac{dx}{dt} &= \alpha x - \beta xy \\ \frac{dy}{dt} &= \delta xy - \gamma y \end{aligned}$$

其中 $x$ 为猎物数量，$y$ 为捕食者数量。

```python
import numpy as np
from scipy.integrate import solve_ivp

def lotka_volterra(t, z, alpha=1.0, beta=0.1, delta=0.075, gamma=1.5):
    """Lotka-Volterra 方程"""
    x, y = z
    dxdt = alpha * x - beta * x * y
    dydt = delta * x * y - gamma * y
    return [dxdt, dydt]

# 初始条件
z0 = [10, 5]  # 初始猎物和捕食者数量
t_span = [0, 30]

# 求解
sol = solve_ivp(lotka_volterra, t_span, z0, dense_output=True)

# 绘图
t = np.linspace(0, 30, 1000)
z = sol.sol(t)

plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(t, z[0], 'b-', label='猎物')
plt.plot(t, z[1], 'r-', label='捕食者')
plt.xlabel('时间 t')
plt.ylabel('数量')
plt.title('Lotka-Volterra 方程时间序列')
plt.legend()
plt.grid(True)

plt.subplot(1, 2, 2)
plt.plot(z[0], z[1], 'g-')
plt.xlabel('猎物数量 x')
plt.ylabel('捕食者数量 y')
plt.title('相图')
plt.grid(True)

plt.tight_layout()
plt.show()
```

## 9. 总结与要点

### 9.1 方法比较

| 方法 | 阶数 | 稳定性 | 计算量 | 适用场景 |
|------|------|--------|--------|----------|
| Euler 方法 | 1 | 条件稳定 | 低 | 简单问题 |
| 改进 Euler | 2 | 条件稳定 | 中 | 一般问题 |
| RK4 | 4 | 条件稳定 | 中 | 非刚性问题 |
| Adams 方法 | 4 | 条件稳定 | 低 | 长时间积分 |
| 隐式方法 | 可变 | 无条件稳定 | 高 | 刚性问题 |

### 9.2 选择建议

1. **非刚性问题**：使用 RK4 或 Adams 方法
2. **刚性问题**：使用隐式方法（如 Radau、BDF）
3. **长时间积分**：使用 Adams 方法
4. **高精度要求**：使用高阶方法或自适应步长

### 9.3 关键要点

- 显式方法简单但可能不稳定
- 隐式方法稳定但计算量大
- 步长选择需要平衡精度和稳定性
- 刚性问题需要特殊处理
- 边值问题需要不同的数值方法
- 实际应用中常使用现成的求解器（如 scipy.integrate）
