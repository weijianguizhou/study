# 曲线拟合

## 1. 曲线拟合概述

### 1.1 拟合问题定义

给定数据点 $(x_i, y_i)$，$i = 1, 2, \ldots, m$，寻找函数 $\varphi(x)$ 使得在某种意义下误差最小。与插值不同，拟合不要求函数通过所有数据点，而是追求整体逼近效果。

### 1.2 拟合与插值的区别

**插值**：
- 要求 $\varphi(x_i) = y_i$，$i = 1, 2, \ldots, m$
- 函数严格通过所有数据点
- 适用于数据精确的情况

**拟合**：
- 要求 $\sum_{i=1}^{m} [\varphi(x_i) - y_i]^2$ 最小
- 函数不一定要通过所有数据点
- 适用于数据有噪声的情况

### 1.3 拟合标准

最常见的拟合标准是最小二乘准则：

$$\min \sum_{i=1}^{m} w_i [\varphi(x_i) - y_i]^2$$

其中 $w_i > 0$ 为权重系数。

## 2. 最小二乘法

### 2.1 线性最小二乘问题

给定数据点 $(x_i, y_i)$，$i = 1, 2, \ldots, m$，寻找线性函数 $y = a_0 + a_1 x$ 使得：

$$S(a_0, a_1) = \sum_{i=1}^{m} (a_0 + a_1 x_i - y_i)^2$$

最小。

### 2.2 法方程组

对 $S$ 关于 $a_0$ 和 $a_1$ 求偏导并令其为零：

$$\frac{\partial S}{\partial a_0} = 2\sum_{i=1}^{m} (a_0 + a_1 x_i - y_i) = 0$$

$$\frac{\partial S}{\partial a_1} = 2\sum_{i=1}^{m} x_i(a_0 + a_1 x_i - y_i) = 0$$

整理得到法方程组：

$$\begin{cases} ma_0 + a_1 \sum_{i=1}^{m} x_i = \sum_{i=1}^{m} y_i \\ a_0 \sum_{i=1}^{m} x_i + a_1 \sum_{i=1}^{m} x_i^2 = \sum_{i=1}^{m} x_i y_i \end{cases}$$

### 2.3 解析解

法方程组的解为：

$$a_1 = \frac{m\sum_{i=1}^{m} x_i y_i - \sum_{i=1}^{m} x_i \sum_{i=1}^{m} y_i}{m\sum_{i=1}^{m} x_i^2 - (\sum_{i=1}^{m} x_i)^2}$$

$$a_0 = \frac{\sum_{i=1}^{m} y_i - a_1 \sum_{i=1}^{m} x_i}{m} = \bar{y} - a_1 \bar{x}$$

其中 $\bar{x} = \frac{1}{m}\sum_{i=1}^{m} x_i$，$\bar{y} = \frac{1}{m}\sum_{i=1}^{m} y_i$。

### 2.4 算法步骤

**输入**：数据点 $(x_i, y_i)$，$i = 1, 2, \ldots, m$
**输出**：拟合直线 $y = a_0 + a_1 x$

1. 计算 $\sum_{i=1}^{m} x_i$，$\sum_{i=1}^{m} y_i$，$\sum_{i=1}^{m} x_i^2$，$\sum_{i=1}^{m} x_i y_i$
2. 计算 $a_1 = \frac{m\sum x_i y_i - \sum x_i \sum y_i}{m\sum x_i^2 - (\sum x_i)^2}$
3. 计算 $a_0 = \frac{\sum y_i - a_1 \sum x_i}{m}$
4. 返回拟合直线 $y = a_0 + a_1 x$

### 2.5 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def linear_least_squares(x_data, y_data):
    """
    线性最小二乘拟合
    
    参数:
        x_data: x 数据点
        y_data: y 数据点
    返回:
        拟合系数 a0, a1
    """
    n = len(x_data)
    
    # 计算各种和
    sum_x = np.sum(x_data)
    sum_y = np.sum(y_data)
    sum_x2 = np.sum(x_data**2)
    sum_xy = np.sum(x_data * y_data)
    
    # 计算系数
    a1 = (n * sum_xy - sum_x * sum_y) / (n * sum_x2 - sum_x**2)
    a0 = (sum_y - a1 * sum_x) / n
    
    return a0, a1

# 示例数据
np.random.seed(42)
x_data = np.linspace(0, 10, 20)
y_data = 2.5 * x_data + 1.0 + np.random.normal(0, 1.5, len(x_data))

# 线性拟合
a0, a1 = linear_least_squares(x_data, y_data)
print(f"拟合直线: y = {a0:.4f} + {a1:.4f}x")

# 绘图
x_fit = np.linspace(0, 10, 100)
y_fit = a0 + a1 * x_fit

plt.figure(figsize=(10, 6))
plt.scatter(x_data, y_data, label='数据点', color='blue', alpha=0.6)
plt.plot(x_fit, y_fit, 'r-', label=f'拟合直线: y = {a0:.2f} + {a1:.2f}x')
plt.xlabel('x')
plt.ylabel('y')
plt.title('线性最小二乘拟合')
plt.legend()
plt.grid(True)
plt.show()
```

## 3. 多项式拟合

### 3.1 多项式拟合问题

给定数据点 $(x_i, y_i)$，$i = 1, 2, \ldots, m$，寻找 $n$ 次多项式：

$$P_n(x) = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n$$

使得：

$$S(a_0, a_1, \ldots, a_n) = \sum_{i=1}^{m} [P_n(x_i) - y_i]^2$$

最小。

### 3.2 法方程组

对 $S$ 关于各系数求偏导并令其为零，得到法方程组：

$$\begin{bmatrix} m & \sum x_i & \cdots & \sum x_i^n \\ \sum x_i & \sum x_i^2 & \cdots & \sum x_i^{n+1} \\ \vdots & \vdots & \ddots & \vdots \\ \sum x_i^n & \sum x_i^{n+1} & \cdots & \sum x_i^{2n} \end{bmatrix} \begin{bmatrix} a_0 \\ a_1 \\ \vdots \\ a_n \end{bmatrix} = \begin{bmatrix} \sum y_i \\ \sum x_i y_i \\ \vdots \\ \sum x_i^n y_i \end{bmatrix}$$

### 3.3 矩阵形式

令：

$$X = \begin{bmatrix} 1 & x_1 & x_1^2 & \cdots & x_1^n \\ 1 & x_2 & x_2^2 & \cdots & x_2^n \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 1 & x_m & x_m^2 & \cdots & x_m^n \end{bmatrix}, \quad \mathbf{a} = \begin{bmatrix} a_0 \\ a_1 \\ \vdots \\ a_n \end{bmatrix}, \quad \mathbf{y} = \begin{bmatrix} y_1 \\ y_2 \\ \vdots \\ y_m \end{bmatrix}$$

则法方程组可以写成：

$$X^T X \mathbf{a} = X^T \mathbf{y}$$

解为：

$$\mathbf{a} = (X^T X)^{-1} X^T \mathbf{y}$$

### 3.4 算法步骤

**输入**：数据点 $(x_i, y_i)$，$i = 1, 2, \ldots, m$，多项式次数 $n$
**输出**：拟合多项式系数 $a_0, a_1, \ldots, a_n$

1. 构造 Vandermonde 矩阵 $X$
2. 计算 $X^T X$ 和 $X^T \mathbf{y}$
3. 求解线性方程组 $X^T X \mathbf{a} = X^T \mathbf{y}$
4. 返回系数向量 $\mathbf{a}$

### 3.5 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def polynomial_least_squares(x_data, y_data, degree):
    """
    多项式最小二乘拟合
    
    参数:
        x_data: x 数据点
        y_data: y 数据点
        degree: 多项式次数
    返回:
        拟合多项式系数
    """
    # 构造 Vandermonde 矩阵
    X = np.vander(x_data, degree + 1)
    
    # 求解法方程组
    coeffs = np.linalg.lstsq(X, y_data, rcond=None)[0]
    
    return coeffs[::-1]  # 返回系数从高次到低次

# 示例数据
np.random.seed(42)
x_data = np.linspace(-2, 2, 30)
y_data = 1.5 * x_data**3 - 0.5 * x_data**2 + 2 * x_data + 1 + np.random.normal(0, 0.5, len(x_data))

# 多项式拟合
degrees = [1, 2, 3, 4]
plt.figure(figsize=(12, 8))

for i, degree in enumerate(degrees):
    coeffs = polynomial_least_squares(x_data, y_data, degree)
    
    # 拟合曲线
    x_fit = np.linspace(-2, 2, 100)
    y_fit = np.polyval(coeffs, x_fit)
    
    # 计算拟合误差
    y_pred = np.polyval(coeffs, x_data)
    mse = np.mean((y_data - y_pred)**2)
    
    plt.subplot(2, 2, i + 1)
    plt.scatter(x_data, y_data, s=20, alpha=0.6, label='数据点')
    plt.plot(x_fit, y_fit, 'r-', linewidth=2, label=f'{degree}次多项式拟合')
    plt.title(f'{degree}次多项式拟合 (MSE={mse:.4f})')
    plt.xlabel('x')
    plt.ylabel('y')
    plt.legend()
    plt.grid(True)

plt.tight_layout()
plt.show()
```

### 3.6 多项式次数选择

**欠拟合**：多项式次数太低，无法捕捉数据特征
**过拟合**：多项式次数太高，拟合了噪声

选择多项式次数的方法：
1. **交叉验证**：将数据分为训练集和验证集
2. **信息准则**：AIC、BIC 等
3. **观察法**：观察拟合曲线的光滑性

## 4. 非线性最小二乘拟合

### 4.1 非线性拟合问题

给定数据点 $(x_i, y_i)$，$i = 1, 2, \ldots, m$，寻找非线性函数 $y = f(x; \boldsymbol{\theta})$ 使得：

$$S(\boldsymbol{\theta}) = \sum_{i=1}^{m} [f(x_i; \boldsymbol{\theta}) - y_i]^2$$

最小，其中 $\boldsymbol{\theta}$ 为参数向量。

### 4.2 Gauss-Newton 方法

**迭代公式**：

$$\boldsymbol{\theta}^{(k+1)} = \boldsymbol{\theta}^{(k)} - (J^T J)^{-1} J^T \mathbf{r}(\boldsymbol{\theta}^{(k)})$$

其中：
- $J$ 为 Jacobian 矩阵，$J_{ij} = \frac{\partial f(x_i; \boldsymbol{\theta})}{\partial \theta_j}$
- $\mathbf{r}(\boldsymbol{\theta})$ 为残差向量，$r_i = f(x_i; \boldsymbol{\theta}) - y_i$

### 4.3 Levenberg-Marquardt 方法

Levenberg-Marquardt 方法是 Gauss-Newton 方法的改进，加入阻尼项：

$$\boldsymbol{\theta}^{(k+1)} = \boldsymbol{\theta}^{(k)} - (J^T J + \lambda I)^{-1} J^T \mathbf{r}(\boldsymbol{\theta}^{(k)})$$

其中 $\lambda > 0$ 为阻尼参数。

**算法特点**：
- 当 $\lambda$ 较小时，接近 Gauss-Newton 方法
- 当 $\lambda$ 较大时，接近梯度下降法
- 可以自动调整 $\lambda$ 以保证收敛

### 4.4 算法步骤（Levenberg-Marquardt）

**输入**：数据点 $(x_i, y_i)$，模型函数 $f(x; \boldsymbol{\theta})$，初始参数 $\boldsymbol{\theta}^{(0)}$
**输出**：最优参数 $\boldsymbol{\theta}^*$

1. 初始化 $\boldsymbol{\theta} = \boldsymbol{\theta}^{(0)}$，$\lambda = 0.001$
2. 计算残差 $\mathbf{r}(\boldsymbol{\theta})$ 和 Jacobian 矩阵 $J$
3. 计算 $A = J^T J$，$\mathbf{b} = -J^T \mathbf{r}$
4. 求解 $(A + \lambda \text{diag}(A)) \Delta \boldsymbol{\theta} = \mathbf{b}$
5. 如果 $S(\boldsymbol{\theta} + \Delta \boldsymbol{\theta}) < S(\boldsymbol{\theta})$：
   - 接受更新：$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \Delta \boldsymbol{\theta}$
   - 减小 $\lambda$：$\lambda \leftarrow \lambda / 10$
6. 否则：
   - 增大 $\lambda$：$\lambda \leftarrow \lambda \times 10$
7. 检查收敛条件：$\|\Delta \boldsymbol{\theta}\| < \epsilon$ 或 $|S^{(k+1)} - S^{(k)}| < \epsilon$
8. 如果未收敛，返回步骤 2

### 4.5 Python 实现

```python
import numpy as np
from scipy.optimize import curve_fit
import matplotlib.pyplot as plt

# 定义非线性模型
def model_func(x, a, b, c):
    """指数衰减模型: y = a * exp(-b * x) + c"""
    return a * np.exp(-b * x) + c

# 生成示例数据
np.random.seed(42)
x_data = np.linspace(0, 5, 50)
y_true = 3.0 * np.exp(-0.8 * x_data) + 1.0
y_data = y_true + np.random.normal(0, 0.2, len(x_data))

# 非线性最小二乘拟合
popt, pcov = curve_fit(model_func, x_data, y_data, p0=[3.0, 1.0, 1.0])
a_opt, b_opt, c_opt = popt

print(f"拟合参数: a = {a_opt:.4f}, b = {b_opt:.4f}, c = {c_opt:.4f}")

# 计算拟合误差
perr = np.sqrt(np.diag(pcov))
print(f"参数标准误差: a = {perr[0]:.4f}, b = {perr[1]:.4f}, c = {perr[2]:.4f}")

# 绘图
x_fit = np.linspace(0, 5, 100)
y_fit = model_func(x_fit, a_opt, b_opt, c_opt)

plt.figure(figsize=(10, 6))
plt.scatter(x_data, y_data, label='数据点', alpha=0.6)
plt.plot(x_fit, y_fit, 'r-', linewidth=2, 
         label=f'拟合曲线: y = {a_opt:.2f}·exp(-{b_opt:.2f}x) + {c_opt:.2f}')
plt.plot(x_fit, 3.0 * np.exp(-0.8 * x_fit) + 1.0, 'g--', label='真实曲线')
plt.xlabel('x')
plt.ylabel('y')
plt.title('非线性最小二乘拟合')
plt.legend()
plt.grid(True)
plt.show()
```

## 5. 加权最小二乘拟合

### 5.1 加权拟合问题

当数据点的可靠性不同时，可以使用加权最小二乘：

$$S(\boldsymbol{\theta}) = \sum_{i=1}^{m} w_i [f(x_i; \boldsymbol{\theta}) - y_i]^2$$

其中 $w_i > 0$ 为权重系数，表示第 $i$ 个数据点的可靠性。

### 5.2 权重选择

**基于方差的权重**：

$$w_i = \frac{1}{\sigma_i^2}$$

其中 $\sigma_i^2$ 为第 $i$ 个数据点的方差。

**基于距离的权重**：

$$w_i = \frac{1}{d(x_i, \bar{x})^2}$$

其中 $d(x_i, \bar{x})$ 为 $x_i$ 到中心点 $\bar{x}$ 的距离。

### 5.3 Python 实现

```python
import numpy as np
from scipy.optimize import curve_fit

def weighted_least_squares(x_data, y_data, weights, model_func, p0):
    """
    加权最小二乘拟合
    
    参数:
        x_data: x 数据点
        y_data: y 数据点
        weights: 权重系数
        model_func: 模型函数
        p0: 初始参数
    返回:
        拟合参数和协方差矩阵
    """
    # 使用 scipy 的 curve_fit，sigma 参数为标准差的倒数
    sigma = 1.0 / np.sqrt(weights)
    popt, pcov = curve_fit(model_func, x_data, y_data, p0=p0, sigma=sigma)
    
    return popt, pcov

# 示例：不同精度的数据点
np.random.seed(42)
x_data = np.linspace(0, 10, 30)

# 前10个点精度高，后20个点精度低
y_true = 2.0 * x_data + 1.0
noise = np.concatenate([
    np.random.normal(0, 0.1, 10),   # 高精度
    np.random.normal(0, 1.0, 20)    # 低精度
])
y_data = y_true + noise

# 权重：与方差成反比
weights = np.concatenate([
    np.ones(10) * 100,   # 高精度，大权重
    np.ones(20) * 1      # 低精度，小权重
])

# 加权拟合
def linear_model(x, a, b):
    return a * x + b

popt, pcov = weighted_least_squares(x_data, y_data, weights, linear_model, [1.0, 0.0])
print(f"加权拟合: y = {popt[0]:.4f}x + {popt[1]:.4f}")

# 普通最小二乘拟合
popt_unweighted, _ = curve_fit(linear_model, x_data, y_data, p0=[1.0, 0.0])
print(f"普通拟合: y = {popt_unweighted[0]:.4f}x + {popt_unweighted[1]:.4f}")
```

## 6. 正交多项式拟合

### 6.1 正交多项式

正交多项式满足：

$$\sum_{i=1}^{m} p_j(x_i) p_k(x_i) = 0, \quad j \neq k$$

常用的正交多项式：
- **Legendre 多项式**：$P_n(x) = \frac{1}{2^n n!} \frac{d^n}{dx^n}(x^2 - 1)^n$
- **Chebyshev 多项式**：$T_n(x) = \cos(n \arccos x)$
- **Hermite 多项式**：$H_n(x) = (-1)^n e^{x^2} \frac{d^n}{dx^n} e^{-x^2}$

### 6.2 正交多项式拟合的优点

1. **数值稳定性好**：避免法方程组的病态问题
2. **计算效率高**：可以逐次增加拟合次数
3. **易于选择最佳次数**：通过观察系数大小判断

### 6.3 递推关系

Legendre 多项式的递推关系：

$$P_0(x) = 1$$
$$P_1(x) = x$$
$$(n+1)P_{n+1}(x) = (2n+1)x P_n(x) - n P_{n-1}(x)$$

## 7. 拟合优度评价

### 7.1 决定系数 $R^2$

$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum_{i=1}^{m} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{m} (y_i - \bar{y})^2}$$

其中：
- $SS_{res}$ 为残差平方和
- $SS_{tot}$ 为总平方和
- $\bar{y}$ 为 $y$ 的均值

$R^2$ 越接近 1，拟合效果越好。

### 7.2 均方误差（MSE）

$$\text{MSE} = \frac{1}{m} \sum_{i=1}^{m} (y_i - \hat{y}_i)^2$$

### 7.3 均方根误差（RMSE）

$$\text{RMSE} = \sqrt{\text{MSE}} = \sqrt{\frac{1}{m} \sum_{i=1}^{m} (y_i - \hat{y}_i)^2}$$

### 7.4 平均绝对误差（MAE）

$$\text{MAE} = \frac{1}{m} \sum_{i=1}^{m} |y_i - \hat{y}_i|$$

### 7.5 信息准则

**AIC（赤池信息准则）**：

$$\text{AIC} = m \ln(\text{MSE}) + 2p$$

**BIC（贝叶斯信息准则）**：

$$\text{BIC} = m \ln(\text{MSE}) + p \ln(m)$$

其中 $p$ 为模型参数个数。

### 8.2 实际应用案例

**案例：人口增长模型拟合**

Logistic 增长模型：

$$P(t) = \frac{K}{1 + e^{-r(t - t_0)}}$$

其中：
- $K$ 为环境容纳量
- $r$ 为增长率
- $t_0$ 为拐点时间

```python
import numpy as np
from scipy.optimize import curve_fit

def logistic_model(t, K, r, t0):
    """Logistic 增长模型"""
    return K / (1 + np.exp(-r * (t - t0)))

# 模拟人口数据
np.random.seed(42)
t_data = np.linspace(1900, 2020, 30)
P_true = logistic_model(t_data, 12e9, 0.03, 1970)
P_data = P_true + np.random.normal(0, 0.5e9, len(t_data))

# 拟合
popt, pcov = curve_fit(logistic_model, t_data, P_data, p0=[10e9, 0.02, 1960])
K_opt, r_opt, t0_opt = popt

print(f"环境容纳量 K = {K_opt/1e9:.2f} 亿")
print(f"增长率 r = {r_opt:.4f}")
print(f"拐点时间 t0 = {t0_opt:.1f} 年")
```

## 9. 总结与要点

### 9.1 拟合方法比较

| 方法 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| 线性最小二乘 | 线性关系 | 简单、快速 | 只能拟合线性模型 |
| 多项式拟合 | 近似多项式关系 | 灵活 | 可能过拟合 |
| 非线性最小二乘 | 复杂非线性关系 | 适应性强 | 需要初始值 |
| 加权最小二乘 | 数据精度不同 | 考虑数据可靠性 | 权重选择困难 |

### 9.2 选择建议

1. **数据线性关系明显**：使用线性最小二乘
2. **需要高精度拟合**：使用多项式拟合（注意次数选择）
3. **模型有物理意义**：使用非线性最小二乘
4. **数据精度差异大**：使用加权最小二乘

### 9.3 关键要点

- 拟合不等于插值，不要求通过所有数据点
- 选择合适的模型比优化算法更重要
- 避免过拟合，适当选择模型复杂度
- 拟合结果需要结合实际背景解释
- 交叉验证是评估模型泛化能力的有效方法
- 残差分析是检验拟合效果的重要手段
