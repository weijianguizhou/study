# 数值微分

> **理论基础** → 参见 [[../../数值分析/数值积分与微分|数值微分理论]]

数值微分用差商近似导数，在离散数据分析和微分方程数值求解中必不可少。

## 2. 有限差分方法
### 2.1 前向差分

**公式**：

$$f'(x_0) \approx \frac{f(x_0 + h) - f(x_0)}{h}$$

**截断误差**：

$$R = \frac{h}{2}f''(\xi), \quad \xi \in [x_0, x_0 + h]$$

**误差阶**：$O(h)$

### 2.2 后向差分

**公式**：

$$f'(x_0) \approx \frac{f(x_0) - f(x_0 - h)}{h}$$

**截断误差**：

$$R = -\frac{h}{2}f''(\xi), \quad \xi \in [x_0 - h, x_0]$$

**误差阶**：$O(h)$

### 2.3 中心差分

**公式**：

$$f'(x_0) \approx \frac{f(x_0 + h) - f(x_0 - h)}{2h}$$

**截断误差**：

$$R = -\frac{h^2}{6}f'''(\xi), \quad \xi \in [x_0 - h, x_0 + h]$$

**误差阶**：$O(h^2)$

### 2.4 三种差分方法比较

| 方法 | 公式 | 误差阶 | 优点 | 缺点 |
|------|------|--------|------|------|
| 前向差分 | $\frac{f(x_0+h)-f(x_0)}{h}$ | $O(h)$ | 简单 | 精度低 |
| 后向差分 | $\frac{f(x_0)-f(x_0-h)}{h}$ | $O(h)$ | 简单 | 精度低 |
| 中心差分 | $\frac{f(x_0+h)-f(x_0-h)}{2h}$ | $O(h^2)$ | 精度高 | 需要两侧点 |

### 2.5 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def forward_difference(f, x, h):
    """前向差分"""
    return (f(x + h) - f(x)) / h

def backward_difference(f, x, h):
    """后向差分"""
    return (f(x) - f(x - h)) / h

def central_difference(f, x, h):
    """中心差分"""
    return (f(x + h) - f(x - h)) / (2 * h)

# 示例：计算 sin(x) 在 x = 0 处的导数
f = np.sin
x = 0.0
exact_derivative = np.cos(x)  # 精确值为 1

h_values = np.logspace(-1, -10, 100)
errors_forward = []
errors_backward = []
errors_central = []

for h in h_values:
    df_forward = forward_difference(f, x, h)
    df_backward = backward_difference(f, x, h)
    df_central = central_difference(f, x, h)
    
    errors_forward.append(abs(df_forward - exact_derivative))
    errors_backward.append(abs(df_backward - exact_derivative))
    errors_central.append(abs(df_central - exact_derivative))

# 绘制误差图
plt.figure(figsize=(10, 6))
plt.loglog(h_values, errors_forward, 'b-', label='前向差分 O(h)')
plt.loglog(h_values, errors_backward, 'g-', label='后向差分 O(h)')
plt.loglog(h_values, errors_central, 'r-', label='中心差分 O(h²)')
plt.xlabel('步长 h')
plt.ylabel('绝对误差')
plt.title('有限差分方法误差比较')
plt.legend()
plt.grid(True)
plt.show()
```

## 3. 高阶导数的数值计算
### 3.1 二阶导数

**中心差分公式**：

$$f''(x_0) \approx \frac{f(x_0 + h) - 2f(x_0) + f(x_0 - h)}{h^2}$$

**截断误差**：

$$R = -\frac{h^2}{12}f^{(4)}(\xi), \quad \xi \in [x_0 - h, x_0 + h]$$

**误差阶**：$O(h^2)$

### 3.2 三阶导数

**中心差分公式**：

$$f'''(x_0) \approx \frac{-f(x_0 + 2h) + 2f(x_0 + h) - 2f(x_0 - h) + f(x_0 - 2h)}{2h^3}$$

**误差阶**：$O(h^2)$

### 3.3 四阶导数

**中心差分公式**：

$$f^{(4)}(x_0) \approx \frac{f(x_0 + 2h) - 4f(x_0 + h) + 6f(x_0) - 4f(x_0 - h) + f(x_0 - 2h)}{h^4}$$

**误差阶**：$O(h^2)$

### 3.4 Python 实现

```python
import numpy as np

def second_derivative_central(f, x, h):
    """二阶导数中心差分"""
    return (f(x + h) - 2 * f(x) + f(x - h)) / h**2

def third_derivative_central(f, x, h):
    """三阶导数中心差分"""
    return (-f(x + 2*h) + 2*f(x + h) - 2*f(x - h) + f(x - 2*h)) / (2*h**3)

def fourth_derivative_central(f, x, h):
    """四阶导数中心差分"""
    return (f(x + 2*h) - 4*f(x + h) + 6*f(x) - 4*f(x - h) + f(x - 2*h)) / h**4

# 示例：计算 sin(x) 在 x = 0 处的高阶导数
f = np.sin
x = 0.0
h = 0.01

# 精确值
exact_values = {
    'f\'\'(x)': -np.sin(x),   # 0
    'f\'\'\'(x)': -np.cos(x), # -1
    'f''''''(x)': np.sin(x)   # 0
}

# 数值计算
numerical_values = {
    'f\'\'(x)': second_derivative_central(f, x, h),
    'f\'\'\'(x)': third_derivative_central(f, x, h),
    'f''''''(x)': fourth_derivative_central(f, x, h)
}

print("高阶导数数值计算:")
for key in exact_values:
    print(f"{key}: 数值={numerical_values[key]:.6f}, 精确={exact_values[key]:.6f}, "
          f"误差={abs(numerical_values[key] - exact_values[key]):.2e}")
```

## 4. Richardson 外推法
### 4.1 基本思想

Richardson 外推法通过组合不同步长的差分近似，提高导数的计算精度。

设 $D(h)$ 为步长 $h$ 的差分近似，且：

$$D(h) = f'(x_0) + c_1 h + c_2 h^2 + c_3 h^3 + \cdots$$

则可以通过外推消除低阶误差项。

### 4.2 外推公式

**一阶外推**：

$$D_1(h) = 2D(h/2) - D(h)$$

消除 $O(h)$ 误差项，得到 $O(h^2)$ 精度。

**二阶外推**：

$$D_2(h) = \frac{4D_1(h/2) - D_1(h)}{3}$$

消除 $O(h^2)$ 误差项，得到 $O(h^3)$ 精度。

**一般外推公式**：

$$D_k(h) = \frac{2^k D_{k-1}(h/2) - D_{k-1}(h)}{2^k - 1}$$

### 4.3 算法步骤

**输入**：函数 $f$，求导点 $x_0$，初始步长 $h$，外推阶数 $m$
**输出**：导数近似值

1. 计算 $D_0(h) = \frac{f(x_0 + h) - f(x_0 - h)}{2h}$
2. 对于 $k = 1, 2, \ldots, m$：
   - $h \leftarrow h/2$
   - 计算 $D_0(h)$
   - 对于 $j = k, k-1, \ldots, 1$：
     - $D_j = \frac{2^j D_{j-1}(h/2) - D_{j-1}(h)}{2^j - 1}$
3. 返回 $D_m$

### 4.4 Python 实现

```python
import numpy as np

def richardson_extrapolation(f, x0, h, m):
    """
    Richardson 外推法计算导数
    
    参数:
        f: 函数
        x0: 求导点
        h: 初始步长
        m: 外推阶数
    返回:
        导数近似值
    """
    D = np.zeros((m + 1, m + 1))
    
    # 第一列：不同步长的中心差分
    for i in range(m + 1):
        h_i = h / (2 ** i)
        D[i, 0] = (f(x0 + h_i) - f(x0 - h_i)) / (2 * h_i)
    
    # 外推
    for j in range(1, m + 1):
        for i in range(j, m + 1):
            D[i, j] = (2**j * D[i, j-1] - D[i-1, j-1]) / (2**j - 1)
    
    return D[m, m]

# 示例
f = np.sin
x0 = 0.0
exact_derivative = np.cos(x0)

h = 0.1
m_values = [1, 2, 3, 4, 5]

print("Richardson 外推法:")
print("外推阶数\t近似值\t\t绝对误差")
for m in m_values:
    D = richardson_extrapolation(f, x0, h, m)
    error = abs(D - exact_derivative)
    print(f"{m}\t\t{D:.10f}\t{error:.2e}")
```

## 5. 样条插值微分
### 5.1 基本思想

使用样条插值函数的导数来近似原函数的导数。

对于三次样条插值 $S(x)$，其导数 $S'(x)$ 可以作为 $f'(x)$ 的近似。

### 5.2 样条导数公式

在区间 $[x_i, x_{i+1}]$ 上，样条函数为：

$$S_i(x) = a_i + b_i(x - x_i) + c_i(x - x_i)^2 + d_i(x - x_i)^3$$

其导数为：

$$S_i'(x) = b_i + 2c_i(x - x_i) + 3d_i(x - x_i)^2$$

二阶导数为：

$$S_i''(x) = 2c_i + 6d_i(x - x_i)$$

### 5.3 Python 实现

```python
import numpy as np
from scipy.interpolate import CubicSpline

def spline_derivative(x_data, y_data, x_eval):
    """
    使用样条插值计算导数
    
    参数:
        x_data: 节点 x 坐标
        y_data: 节点 y 坐标
        x_eval: 求导点
    返回:
        导数值
    """
    # 创建三次样条插值
    cs = CubicSpline(x_data, y_data)
    
    # 计算一阶导数
    return cs(x_eval, 1)

# 示例
x_data = np.array([0, 1, 2, 3, 4])
y_data = np.array([0, 1, 4, 9, 16])  # f(x) = x²
x_eval = 2.0
exact_derivative = 4.0  # f'(2) = 4

# 样条导数
spline_deriv = spline_derivative(x_data, y_data, x_eval)
print(f"样条导数: {spline_deriv:.6f}")
print(f"精确值: {exact_derivative:.6f}")
print(f"误差: {abs(spline_deriv - exact_derivative):.2e}")
```

## 6. 数值微分的稳定性
### 6.1 病态问题

数值微分是典型的病态问题：
- 舍入误差会被放大
- 步长 $h$ 不能太小，否则舍入误差占主导
- 步长 $h$ 不能太大，否则截断误差占主导

### 6.2 误差平衡

总误差 = 截断误差 + 舍入误差

对于前向差分：

$$\text{总误差} \leq \frac{h}{2}|f''(\xi)| + \frac{\epsilon}{h}$$

其中 $\epsilon$ 为机器精度。

最优步长：

$$h_{\text{opt}} = \sqrt{\frac{2\epsilon}{|f''(\xi)|}}$$

最小误差：

$$\text{误差}_{\text{min}} = \sqrt{2\epsilon|f''(\xi)|}$$

### 6.3 Python 示例

```python
import numpy as np

def numerical_derivative_analysis(f, x, exact_derivative):
    """
    分析数值微分的误差
    """
    h_values = np.logspace(-16, 0, 200)
    errors = []
    
    for h in h_values:
        # 避免 h 太小导致除零
        if h < 1e-16:
            errors.append(np.inf)
            continue
        
        # 中心差分
        try:
            df = (f(x + h) - f(x - h)) / (2 * h)
            errors.append(abs(df - exact_derivative))
        except:
            errors.append(np.inf)
    
    return h_values, errors

# 示例：f(x) = sin(x), x = 1
f = np.sin
x = 1.0
exact_derivative = np.cos(x)

h_values, errors = numerical_derivative_analysis(f, x, exact_derivative)

# 找到最优步长
min_error_idx = np.argmin(errors)
optimal_h = h_values[min_error_idx]
min_error = errors[min_error_idx]

print(f"最优步长: {optimal_h:.2e}")
print(f"最小误差: {min_error:.2e}")

# 绘图
plt.figure(figsize=(10, 6))
plt.loglog(h_values, errors, 'b-')
plt.axvline(x=optimal_h, color='r', linestyle='--', label=f'最优步长 h={optimal_h:.2e}')
plt.xlabel('步长 h')
plt.ylabel('绝对误差')
plt.title('数值微分误差分析')
plt.legend()
plt.grid(True)
plt.show()
```

## 7. 多元函数的数值偏导数
### 7.1 偏导数的数值计算

对于二元函数 $f(x, y)$，偏导数的数值计算：

**关于 $x$ 的偏导数**：

$$\frac{\partial f}{\partial x}(x_0, y_0) \approx \frac{f(x_0 + h, y_0) - f(x_0 - h, y_0)}{2h}$$

**关于 $y$ 的偏导数**：

$$\frac{\partial f}{\partial y}(x_0, y_0) \approx \frac{f(x_0, y_0 + h) - f(x_0, y_0 - h)}{2h}$$

### 7.2 混合偏导数

$$\frac{\partial^2 f}{\partial x \partial y}(x_0, y_0) \approx \frac{f(x_0+h, y_0+k) - f(x_0+h, y_0-k) - f(x_0-h, y_0+k) + f(x_0-h, y_0-k)}{4hk}$$

### 7.3 Python 实现

```python
import numpy as np

def partial_derivative_x(f, x, y, h=1e-5):
    """计算关于 x 的偏导数"""
    return (f(x + h, y) - f(x - h, y)) / (2 * h)

def partial_derivative_y(f, x, y, h=1e-5):
    """计算关于 y 的偏导数"""
    return (f(x, y + h) - f(x, y - h)) / (2 * h)

def mixed_partial_derivative(f, x, y, h=1e-5, k=1e-5):
    """计算混合偏导数"""
    return (f(x+h, y+k) - f(x+h, y-k) - f(x-h, y+k) + f(x-h, y-k)) / (4*h*k)

# 示例：f(x, y) = x²y + xy²
def f(x, y):
    return x**2 * y + x * y**2

x0, y0 = 1.0, 2.0

# 精确偏导数
exact_df_dx = 2*x0*y0 + y0**2  # = 8
exact_df_dy = x0**2 + 2*x0*y0  # = 5
exact_d2f_dxdy = 2*x0 + 2*y0   # = 6

# 数值计算
num_df_dx = partial_derivative_x(f, x0, y0)
num_df_dy = partial_derivative_y(f, x0, y0)
num_d2f_dxdy = mixed_partial_derivative(f, x0, y0)

print(f"∂f/∂x: 数值={num_df_dx:.6f}, 精确={exact_df_dx:.6f}")
print(f"∂f/∂y: 数值={num_df_dy:.6f}, 精确={exact_df_dy:.6f}")
print(f"∂²f/∂x∂y: 数值={num_d2f_dxdy:.6f}, 精确={exact_d2f_dxdy:.6f}")
```

## 8. 应用实例
### 8.1 数值微分的应用

1. **微分方程数值解**：将微分方程离散化
2. **优化算法**：梯度下降法需要计算梯度
3. **数据平滑**：对噪声数据求导
4. **物理模拟**：计算速度、加速度等

### 8.2 数值微分与积分的比较

| 特性 | 数值微分 | 数值积分 |
|------|----------|----------|
| 稳定性 | 不稳定（病态） | 稳定 |
| 误差敏感性 | 高 | 低 |
| 收敛速度 | 较慢 | 较快 |
| 主要误差来源 | 舍入误差放大 | 截断误差 |

### 8.3 Python 示例：数值微分在优化中的应用

```python
import numpy as np

def gradient_numerical(f, x, h=1e-5):
    """
    数值计算梯度
    
    参数:
        f: 多元函数
        x: 求梯度的点
        h: 步长
    返回:
        梯度向量
    """
    n = len(x)
    grad = np.zeros(n)
    
    for i in range(n):
        x_plus = x.copy()
        x_minus = x.copy()
        
        x_plus[i] += h
        x_minus[i] -= h
        
        grad[i] = (f(x_plus) - f(x_minus)) / (2 * h)
    
    return grad

def gradient_descent(f, x0, learning_rate=0.01, max_iter=1000, tol=1e-6):
    """
    梯度下降法（使用数值梯度）
    """
    x = x0.copy()
    history = [x.copy()]
    
    for i in range(max_iter):
        grad = gradient_numerical(f, x)
        x = x - learning_rate * grad
        history.append(x.copy())
        
        if np.linalg.norm(grad) < tol:
            break
    
    return x, history

# 示例：最小化 f(x, y) = (x-1)² + (y-2)²
def objective(x):
    return (x[0] - 1)**2 + (x[1] - 2)**2

x0 = np.array([0.0, 0.0])
x_opt, history = gradient_descent(objective, x0)

print(f"最优解: x = {x_opt[0]:.6f}, y = {x_opt[1]:.6f}")
print(f"最优值: f(x*) = {objective(x_opt):.6f}")
```

## 9. 总结与要点
### 9.1 方法比较

| 方法 | 误差阶 | 稳定性 | 适用场景 |
|------|--------|--------|----------|
| 前向差分 | $O(h)$ | 较差 | 简单计算 |
| 后向差分 | $O(h)$ | 较差 | 简单计算 |
| 中心差分 | $O(h^2)$ | 较好 | 一般应用 |
| Richardson 外推 | 可达 $O(h^{m+1})$ | 较好 | 高精度要求 |
| 样条微分 | 取决于样条 | 好 | 数据求导 |

### 9.2 选择建议

1. **一般应用**：使用中心差分
2. **高精度要求**：使用 Richardson 外推
3. **数据求导**：使用样条插值微分
4. **实时计算**：使用前向或后向差分

### 9.3 关键要点

- 数值微分是病态问题，对误差敏感
- 步长选择需要平衡截断误差和舍入误差
- 中心差分比前向/后向差分精度高
- Richardson 外推可以显著提高精度
- 样条插值微分适合对离散数据求导
- 多元函数的偏导数可以类似地计算
- 数值微分的稳定性通常不如数值积分
