# 数值积分

## 1. 数值积分概述

### 1.1 问题定义

计算定积分：

$$I = \int_a^b f(x) dx$$

当 $f(x$ 的原函数难以求得或不存在初等表达式时，需要使用数值积分方法。

### 1.2 基本思想

用数值积分公式近似计算定积分：

$$\int_a^b f(x) dx \approx \sum_{i=0}^{n} w_i f(x_i)$$

其中 $x_i$ 为求积节点，$w_i$ 为求积系数（权重）。

### 1.3 求积公式的一般形式

**插值型求积公式**：基于插值多项式的积分

$$\int_a^b f(x) dx \approx \int_a^b P_n(x) dx = \sum_{i=0}^{n} w_i f(x_i)$$

**求积公式的代数精度**：如果求积公式对所有次数不超过 $m$ 的多项式精确成立，但对 $x^{m+1}$ 不精确，则称其具有 $m$ 次代数精度。

## 2. Newton-Cotes 公式

### 2.1 基本思想

将积分区间 $[a, b]$ 等分为 $n$ 份，步长 $h = \frac{b-a}{n}$，节点 $x_i = a + ih$，$i = 0, 1, \ldots, n$。

使用 Lagrange 插值多项式近似 $f(x)$：

$$\int_a^b f(x) dx \approx \int_a^b L_n(x) dx = \sum_{i=0}^{n} w_i f(x_i)$$

### 2.2 梯形公式（$n=1$）

**公式**：

$$T = \frac{h}{2}[f(a) + f(b)]$$

其中 $h = b - a$。

**几何意义**：用梯形面积近似曲边梯形面积。

**代数精度**：1 次

**截断误差**：

$$R[T] = -\frac{h^3}{12} f''(\xi), \quad \xi \in [a, b]$$

### 2.3 Simpson 公式（$n=2$）

**公式**：

$$S = \frac{h}{3}[f(a) + 4f(a+h) + f(b)]$$

其中 $h = \frac{b-a}{2}$。

**几何意义**：用抛物线下面积近似曲边梯形面积。

**代数精度**：3 次

**截断误差**：

$$R[S] = -\frac{h^5}{90} f^{(4)}(\xi), \quad \xi \in [a, b]$$

### 2.4 Simpson 3/8 公式（$n=3$）

**公式**：

$$S_{3/8} = \frac{3h}{8}[f(a) + 3f(a+h) + 3f(a+2h) + f(b)]$$

其中 $h = \frac{b-a}{3}$。

**代数精度**：3 次

### 2.5 Cotes 公式（$n=4$）

**公式**：

$$C = \frac{2h}{45}[7f(a) + 32f(a+h) + 12f(a+2h) + 32f(a+3h) + 7f(b)]$$

其中 $h = \frac{b-a}{4}$。

**代数精度**：5 次

### 2.6 Newton-Cotes 公式系数表

| $n$ | 公式名称 | 系数 $w_i/h$ | 代数精度 |
|-----|----------|--------------|----------|
| 1 | 梯形公式 | $\frac{1}{2}, \frac{1}{2}$ | 1 |
| 2 | Simpson 公式 | $\frac{1}{6}, \frac{4}{6}, \frac{1}{6}$ | 3 |
| 3 | Simpson 3/8 公式 | $\frac{1}{8}, \frac{3}{8}, \frac{3}{8}, \frac{1}{8}$ | 3 |
| 4 | Cotes 公式 | $\frac{7}{90}, \frac{32}{90}, \frac{12}{90}, \frac{32}{90}, \frac{7}{90}$ | 5 |

## 3. 复合求积公式

### 3.1 复合梯形公式

将 $[a, b]$ 等分为 $n$ 个子区间，每个子区间上使用梯形公式：

$$T_n = \frac{h}{2}\left[f(a) + 2\sum_{i=1}^{n-1} f(x_i) + f(b)\right]$$

其中 $h = \frac{b-a}{n}$，$x_i = a + ih$。

**截断误差**：

$$R[T_n] = -\frac{(b-a)h^2}{12} f''(\xi), \quad \xi \in [a, b]$$

### 3.2 复合 Simpson 公式

将 $[a, b]$ 等分为 $n$（偶数）个子区间，每两个子区间上使用 Simpson 公式：

$$S_n = \frac{h}{3}\left[f(a) + 4\sum_{i=1}^{n/2} f(x_{2i-1}) + 2\sum_{i=1}^{n/2-1} f(x_{2i}) + f(b)\right]$$

其中 $h = \frac{b-a}{n}$。

**截断误差**：

$$R[S_n] = -\frac{(b-a)h^4}{180} f^{(4)}(\xi), \quad \xi \in [a, b]$$

### 3.3 算法步骤（复合 Simpson）

**输入**：函数 $f$，积分区间 $[a, b]$，子区间数 $n$（偶数）
**输出**：积分近似值

1. 计算步长 $h = \frac{b-a}{n}$
2. 初始化 $S = f(a) + f(b)$
3. 对于 $i = 1, 3, 5, \ldots, n-1$：
   - $S = S + 4f(a + ih)$
4. 对于 $i = 2, 4, 6, \ldots, n-2$：
   - $S = S + 2f(a + ih)$
5. 返回 $\frac{h}{3} S$

### 3.4 Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt

def composite_trapezoidal(f, a, b, n):
    """
    复合梯形公式
    
    参数:
        f: 被积函数
        a, b: 积分区间
        n: 子区间数
    返回:
        积分近似值
    """
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    y = f(x)
    
    # 梯形公式
    integral = h * (y[0] / 2 + np.sum(y[1:-1]) + y[-1] / 2)
    
    return integral

def composite_simpson(f, a, b, n):
    """
    复合 Simpson 公式
    
    参数:
        f: 被积函数
        a, b: 积分区间
        n: 子区间数（必须为偶数）
    返回:
        积分近似值
    """
    if n % 2 != 0:
        raise ValueError("子区间数必须为偶数")
    
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    y = f(x)
    
    # Simpson 公式
    integral = y[0] + y[-1]
    integral += 4 * np.sum(y[1:-1:2])  # 奇数点
    integral += 2 * np.sum(y[2:-1:2])  # 偶数点
    integral *= h / 3
    
    return integral

# 示例：计算 sin(x) 在 [0, pi] 的积分
f = np.sin
a, b = 0, np.pi
exact_value = 2.0  # 精确值

# 计算不同步长的误差
n_values = [4, 8, 16, 32, 64, 128]
errors_trapezoidal = []
errors_simpson = []

for n in n_values:
    I_trap = composite_trapezoidal(f, a, b, n)
    I_simp = composite_simpson(f, a, b, n)
    
    errors_trapezoidal.append(abs(I_trap - exact_value))
    errors_simpson.append(abs(I_simp - exact_value))

# 绘制误差收敛图
plt.figure(figsize=(10, 6))
plt.loglog(n_values, errors_trapezoidal, 'bo-', label='复合梯形公式')
plt.loglog(n_values, errors_simpson, 'rs-', label='复合 Simpson 公式')
plt.xlabel('子区间数 n')
plt.ylabel('绝对误差')
plt.title('数值积分误差收敛性')
plt.legend()
plt.grid(True)
plt.show()
```

## 4. Romberg 积分法

### 4.1 基本思想

Romberg 积分法利用 Richardson 外推技术，从复合梯形公式出发，构造高精度积分公式。

### 4.2 Richardson 外推

设 $T(h)$ 为步长 $h$ 的梯形公式近似值，且：

$$T(h) = I + c_1 h^2 + c_2 h^4 + c_3 h^6 + \cdots$$

则有：

$$T(h) = I + O(h^2)$$

**外推公式**：

$$T_k^{(j)} = \frac{4^j T_k^{(j-1)} - T_{k-1}^{(j-1)}}{4^j - 1}, \quad j = 1, 2, \ldots$$

其中 $T_k^{(0)} = T(h_k)$ 为步长 $h_k = \frac{b-a}{2^k}$ 的梯形公式。

### 4.3 Romberg 表

| $k$ | $h_k$ | $T_k^{(0)}$ | $T_k^{(1)}$ | $T_k^{(2)}$ | $T_k^{(3)}$ |
|-----|--------|--------------|--------------|--------------|--------------|
| 0 | $b-a$ | $T_0^{(0)}$ | | | |
| 1 | $\frac{b-a}{2}$ | $T_1^{(0)}$ | $T_1^{(1)}$ | | |
| 2 | $\frac{b-a}{4}$ | $T_2^{(0)}$ | $T_2^{(1)}$ | $T_2^{(2)}$ | |
| 3 | $\frac{b-a}{8}$ | $T_3^{(0)}$ | $T_3^{(1)}$ | $T_3^{(2)}$ | $T_3^{(3)}$ |

### 4.4 算法步骤

**输入**：函数 $f$，积分区间 $[a, b]$，精度要求 $\epsilon$
**输出**：积分近似值

1. 初始化 $k = 0$，$T_0^{(0)} = \frac{b-a}{2}[f(a) + f(b)]$
2. $k = k + 1$
3. 计算 $T_k^{(0)}$：
   - $h_k = \frac{b-a}{2^k}$
   - 在新增节点处计算 $f$ 值
   - $T_k^{(0)} = \frac{1}{2} T_{k-1}^{(0)} + h_k \sum_{i=1}^{2^{k-1}} f(a + (2i-1)h_k)$
4. 外推计算 $T_k^{(j)}$，$j = 1, 2, \ldots, k$：
   - $T_k^{(j)} = \frac{4^j T_k^{(j-1)} - T_{k-1}^{(j-1)}}{4^j - 1}$
5. 如果 $|T_k^{(k)} - T_{k-1}^{(k-1)}| < \epsilon$，返回 $T_k^{(k)}$
6. 否则，返回步骤 2

### 4.5 Python 实现

```python
import numpy as np

def romberg_integration(f, a, b, tol=1e-10, max_iter=20):
    """
    Romberg 积分法
    
    参数:
        f: 被积函数
        a, b: 积分区间
        tol: 精度要求
        max_iter: 最大迭代次数
    返回:
        积分近似值
    """
    # 初始化 Romberg 表
    R = np.zeros((max_iter, max_iter))
    
    # 第一列：复合梯形公式
    h = b - a
    R[0, 0] = h * (f(a) + f(b)) / 2
    
    for k in range(1, max_iter):
        # 计算新增节点的函数值之和
        h /= 2
        sum_new = 0
        for i in range(1, 2**k, 2):
            x = a + i * h
            sum_new += f(x)
        
        # 复合梯形公式
        R[k, 0] = R[k-1, 0] / 2 + h * sum_new
        
        # Richardson 外推
        for j in range(1, k + 1):
            R[k, j] = (4**j * R[k, j-1] - R[k-1, j-1]) / (4**j - 1)
        
        # 检查收敛性
        if abs(R[k, k] - R[k-1, k-1]) < tol:
            return R[k, k]
    
    print(f"警告：达到最大迭代次数 {max_iter}")
    return R[max_iter-1, max_iter-1]

# 示例
f = lambda x: np.exp(-x**2)
a, b = 0, 1

# Romberg 积分
I_romberg = romberg_integration(f, a, b)
print(f"Romberg 积分结果: {I_romberg:.10f}")

# 对比其他方法
from scipy import integrate
I_scipy, error = integrate.quad(f, a, b)
print(f"SciPy 积分结果: {I_scipy:.10f}")
```

## 5. Gauss 求积公式

### 5.1 基本思想

Gauss 求积公式通过选择最优的节点和权重，使得在相同节点数下达到最高的代数精度。

对于 $n$ 个节点的 Gauss 求积公式，可以达到 $2n-1$ 次代数精度。

### 5.2 Gauss-Legendre 求积公式

**节点**：Legendre 多项式 $P_n(x)$ 的零点

**权重**：

$$w_i = \frac{2}{(1-x_i^2)[P_n'(x_i)]^2}, \quad i = 1, 2, \ldots, n$$

**积分公式**：

$$\int_{-1}^{1} f(x) dx \approx \sum_{i=1}^{n} w_i f(x_i)$$

### 5.3 常用 Gauss 求积公式

| 公式名称 | 积分区间 | 权重函数 | 适用情况 |
|----------|----------|----------|----------|
| Gauss-Legendre | $[-1, 1]$ | $1$ | 一般积分 |
| Gauss-Chebyshev | $[-1, 1]$ | $\frac{1}{\sqrt{1-x^2}}$ | 含权函数积分 |
| Gauss-Laguerre | $[0, +\infty)$ | $e^{-x}$ | 无穷区间积分 |
| Gauss-Hermite | $(-\infty, +\infty)$ | $e^{-x^2}$ | 无穷区间积分 |

### 5.4 变量替换

对于一般区间 $[a, b]$ 上的积分，使用变量替换：

$$x = \frac{b-a}{2}t + \frac{a+b}{2}, \quad dx = \frac{b-a}{2}dt$$

则：

$$\int_a^b f(x) dx = \frac{b-a}{2} \int_{-1}^{1} f\left(\frac{b-a}{2}t + \frac{a+b}{2}\right) dt$$

### 5.5 Python 实现

```python
import numpy as np
from numpy.polynomial.legendre import leggauss

def gauss_legendre_integration(f, a, b, n):
    """
    Gauss-Legendre 求积公式
    
    参数:
        f: 被积函数
        a, b: 积分区间
        n: 求积节点数
    返回:
        积分近似值
    """
    # 获取 Gauss-Legendre 节点和权重
    x, w = leggauss(n)
    
    # 变量替换到 [a, b]
    x_ab = 0.5 * (b - a) * x + 0.5 * (a + b)
    w_ab = 0.5 * (b - a) * w
    
    # 计算积分
    integral = np.sum(w_ab * f(x_ab))
    
    return integral

# 示例
f = lambda x: np.sin(x)
a, b = 0, np.pi

# 不同节点数的 Gauss 求积
n_values = [2, 3, 4, 5, 6]
exact_value = 2.0

print("Gauss-Legendre 求积公式:")
print("节点数\t\t近似值\t\t绝对误差")
for n in n_values:
    I = gauss_legendre_integration(f, a, b, n)
    error = abs(I - exact_value)
    print(f"{n}\t\t{I:.10f}\t{error:.2e}")
```

## 6. 自适应积分法

### 6.1 基本思想

自适应积分法根据被积函数的变化自动调整步长，在函数变化剧烈的区域使用较小的步长，在函数变化平缓的区域使用较大的步长。

### 6.2 自适应 Simpson 积分

**算法思想**：
1. 在区间 $[a, b]$ 上使用 Simpson 公式计算 $S_1$
2. 将区间分为两半，在每个子区间上使用 Simpson 公式计算 $S_2$
3. 如果 $|S_2 - S_1| < \epsilon$，则接受 $S_2$
4. 否则，对每个子区间递归应用此过程

**误差控制**：

$$|S_2 - S_1| < \epsilon \implies |S_2 - I| \leq \frac{|S_2 - S_1|}{15}$$

### 6.3 算法步骤

**输入**：函数 $f$，积分区间 $[a, b]$，精度要求 $\epsilon$
**输出**：积分近似值

1. 计算 $S_1 = \text{Simpson}(f, a, b)$
2. 计算 $S_2 = \text{Simpson}(f, a, c) + \text{Simpson}(f, c, b)$，其中 $c = \frac{a+b}{2}$
3. 如果 $|S_2 - S_1| < 15\epsilon$，返回 $S_2 + \frac{S_2 - S_1}{15}$
4. 否则：
   - 递归计算左半区间：$I_1 = \text{自适应积分}(f, a, c, \epsilon/2)$
   - 递归计算右半区间：$I_2 = \text{自适应积分}(f, c, b, \epsilon/2)$
   - 返回 $I_1 + I_2$

### 6.4 Python 实现

```python
import numpy as np

def adaptive_simpson(f, a, b, tol=1e-8, max_depth=20):
    """
    自适应 Simpson 积分
    
    参数:
        f: 被积函数
        a, b: 积分区间
        tol: 精度要求
        max_depth: 最大递归深度
    返回:
        积分近似值
    """
    def simpson(f, a, b):
        """计算 Simpson 公式"""
        c = (a + b) / 2
        h = b - a
        return h * (f(a) + 4 * f(c) + f(b)) / 6
    
    def adaptive_simpson_recursive(f, a, b, tol, whole, depth):
        """递归计算"""
        c = (a + b) / 2
        left = simpson(f, a, c)
        right = simpson(f, c, b)
        result = left + right
        
        if depth >= max_depth:
            return result
        
        if abs(result - whole) <= 15 * tol:
            return result + (result - whole) / 15
        
        return (adaptive_simpson_recursive(f, a, c, tol/2, left, depth+1) +
                adaptive_simpson_recursive(f, c, b, tol/2, right, depth+1))
    
    whole = simpson(f, a, b)
    return adaptive_simpson_recursive(f, a, b, tol, whole, 0)

# 示例
f = lambda x: np.sin(x)
a, b = 0, np.pi

I = adaptive_simpson(f, a, b)
print(f"自适应 Simpson 积分: {I:.10f}")
print(f"精确值: {2.0:.10f}")
print(f"绝对误差: {abs(I - 2.0):.2e}")
```

## 7. 数值积分的误差分析

### 7.1 截断误差

**梯形公式**：

$$R[T] = -\frac{h^3}{12} f''(\xi), \quad \xi \in [a, b]$$

**Simpson 公式**：

$$R[S] = -\frac{h^5}{90} f^{(4)}(\xi), \quad \xi \in [a, b]$$

### 7.2 复合公式的误差

**复合梯形公式**：

$$R[T_n] = -\frac{(b-a)h^2}{12} f''(\xi)$$

误差阶为 $O(h^2)$。

**复合 Simpson 公式**：

$$R[S_n] = -\frac{(b-a)h^4}{180} f^{(4)}(\xi)$$

误差阶为 $O(h^4)$。

### 7.3 收敛阶比较

| 方法 | 收敛阶 | 截断误差 |
|------|--------|----------|
| 复合梯形公式 | 2 | $O(h^2)$ |
| 复合 Simpson 公式 | 4 | $O(h^4)$ |
| Romberg 积分 | 可达 $2k$ | $O(h^{2k})$ |
| Gauss 求积 | $2n-1$ | $O(h^{2n})$ |

## 8. 应用实例

### 8.1 不定积分的数值计算

对于不定积分 $\int f(x) dx$，可以使用数值积分方法计算一系列点的积分值，然后进行插值得到近似的原函数。

### 8.2 广义积分

**无穷区间积分**：

$$\int_0^{+\infty} f(x) dx = \lim_{b \to +\infty} \int_0^b f(x) dx$$

**处理方法**：
1. 截断法：选择足够大的 $b$，计算 $\int_0^b f(x) dx$
2. 变量替换：令 $t = \frac{1}{x+1}$，将无穷区间映射到有限区间

**瑕积分**：

$$\int_a^b \frac{f(x)}{(x-a)^\alpha} dx, \quad 0 < \alpha < 1$$

**处理方法**：
1. 变量替换：消除奇异性
2. 自适应积分：在奇点附近使用较小步长

### 8.3 Python 实现

```python
import numpy as np
from scipy import integrate

# 无穷区间积分
def integrand(x):
    return np.exp(-x**2)

# 使用 scipy 计算
result, error = integrate.quad(integrand, 0, np.inf)
print(f"无穷区间积分: {result:.10f}")
print(f"估计误差: {error:.2e}")

# 瑕积分
def singular_integrand(x):
    return np.sqrt(x) * np.sin(x)

# 在 x=0 处有奇异性
result, error = integrate.quad(singular_integrand, 0, 1)
print(f"瑕积分: {result:.10f}")
```

## 9. 总结与要点

### 9.1 方法比较

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 复合梯形公式 | 简单、稳定 | 收敛慢 | 一般积分 |
| 复合 Simpson 公式 | 精度高、收敛快 | 需要偶数子区间 | 光滑函数 |
| Romberg 积分 | 高精度、自动外推 | 计算量较大 | 高精度要求 |
| Gauss 求积 | 最高代数精度 | 需要计算节点和权重 | 特定类型积分 |
| 自适应积分 | 自动调整步长 | 实现复杂 | 奇异函数 |

### 9.2 选择建议

1. **一般积分**：使用复合 Simpson 公式
2. **高精度要求**：使用 Romberg 积分或 Gauss 求积
3. **奇异函数**：使用自适应积分法
4. **无穷区间**：使用变量替换或 Gauss-Laguerre 公式

### 9.3 关键要点

- 选择合适的积分方法需要考虑被积函数的性质
- 复合公式通过增加节点数提高精度
- Gauss 求积在相同节点数下精度最高
- 自适应方法可以自动处理函数变化剧烈的区域
- 误差估计是选择积分方法的重要依据
- 数值积分的稳定性通常优于数值微分
