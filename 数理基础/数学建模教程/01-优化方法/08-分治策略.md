# 分治策略

## 一、分治策略概述

分治策略（Divide and Conquer）是算法设计的基本范式之一。其核心思想是将一个大规模问题分解为若干规模较小的子问题，递归求解子问题，然后将子问题的解合并为原问题的解。

### 1.1 基本步骤

1. **分解（Divide）**：将原问题分解为若干个规模较小的子问题
2. **解决（Conquer）**：递归求解各子问题；若子问题规模足够小，则直接求解
3. **合并（Combine）**：将子问题的解合并为原问题的解

### 1.2 分治法的适用条件

- 问题可以分解为**若干个规模较小的相同问题**
- 子问题的解可以**合并**为原问题的解
- 子问题之间**相互独立**（无重叠子问题，否则用动态规划更合适）

### 1.3 分治与其他策略的关系

| 策略 | 特点 | 典型应用 |
|------|------|---------|
| 分治 | 分解-递归-合并，子问题独立 | 归并排序、快速排序 |
| 动态规划 | 子问题有重叠，存储解 | 背包、最短路径 |
| 贪心 | 局部最优，不回溯 | 活动选择、Huffman |
| 回溯 | 尝试所有可能，剪枝 | 八皇后、旅行商 |

## 二、分治法的时间复杂度分析

### 2.1 递推关系

分治算法的时间复杂度通常满足如下递推关系：

$$
T(n) = aT(n/b) + f(n)
$$

其中：
- $a \geq 1$ 为子问题个数
- $b > 1$ 为每个子问题的规模缩小比例
- $f(n)$ 为分解和合并的代价

### 2.2 主定理（Master Theorem）

**定理**：对于 $T(n) = aT(n/b) + \Theta(n^d)$，其中 $a \geq 1$，$b > 1$，$d \geq 0$：

$$
T(n) = \begin{cases}
\Theta(n^d), & \text{若 } d > \log_b a \\
\Theta(n^d \log n), & \text{若 } d = \log_b a \\
\Theta(n^{\log_b a}), & \text{若 } d < \log_b a
\end{cases}
$$

**推论**：设 $a \geq 1, b > 1$：

- 若 $f(n) = O(n^{\log_b a - \epsilon})$（$\epsilon > 0$），则 $T(n) = \Theta(n^{\log_b a})$
- 若 $f(n) = \Theta(n^{\log_b a})$，则 $T(n) = \Theta(n^{\log_b a} \log n)$
- 若 $f(n) = \Omega(n^{\log_b a + \epsilon})$（$\epsilon > 0$），且 $af(n/b) \leq cf(n)$（$c < 1$），则 $T(n) = \Theta(f(n))$

### 2.3 常见递推关系求解

| 递推式 | 解 | 对应算法 |
|--------|-----|---------|
| $T(n) = 2T(n/2) + O(n)$ | $O(n \log n)$ | 归并排序 |
| $T(n) = T(n/2) + O(1)$ | $O(\log n)$ | 二分查找 |
| $T(n) = 2T(n/2) + O(1)$ | $O(n)$ | 遍历 |
| $T(n) = T(n-1) + O(n)$ | $O(n^2)$ | 朴素排序 |
| $T(n) = 7T(n/2) + O(n^2)$ | $O(n^{\log_2 7}) \approx O(n^{2.807})$ | Strassen矩阵乘 |

## 三、归并排序

### 3.1 算法描述

归并排序（Merge Sort）是分治法的经典应用：

1. **分解**：将数组从中间分成两半
2. **解决**：递归排序左半和右半
3. **合并**：将两个有序子数组合并为一个有序数组

### 3.2 递推关系

$$
T(n) = 2T(n/2) + O(n)
$$

由主定理，$T(n) = O(n \log n)$。

### 3.3 合并操作

合并两个长度各为 $n/2$ 的有序数组，需要 $O(n)$ 时间：

```
合并过程:
1. 创建辅助数组，大小为 n
2. 设置两个指针 i, j 分别指向两个子数组的起始位置
3. 比较 arr[i] 和 arr[j]，将较小者放入结果
4. 移动指针，重复直到一个子数组遍历完毕
5. 将剩余元素放入结果
```

### 3.4 空间复杂度

归并排序需要 $O(n)$ 的额外空间（用于合并操作）。

### 3.5 稳定性

归并排序是**稳定排序**，即相等元素的相对顺序不会改变。

### 3.6 代码实现

```python
def merge_sort(arr):
    """归并排序"""
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    
    return merge(left, right)

def merge(left, right):
    """合并两个有序数组"""
    result = []
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    result.extend(left[i:])
    result.extend(right[j:])
    return result

# 就地归并排序
def merge_sort_inplace(arr, left, right):
    """就地归并排序"""
    if left < right:
        mid = (left + right) // 2
        merge_sort_inplace(arr, left, mid)
        merge_sort_inplace(arr, mid + 1, right)
        merge_inplace(arr, left, mid, right)

def merge_inplace(arr, left, mid, right):
    """就地合并（使用辅助数组）"""
    temp = arr[left:mid+1]
    i, j, k = 0, mid+1, left
    
    while i < len(temp) and j <= right:
        if temp[i] <= arr[j]:
            arr[k] = temp[i]
            i += 1
        else:
            arr[k] = arr[j]
            j += 1
        k += 1
    
    while i < len(temp):
        arr[k] = temp[i]
        i += 1
        k += 1

# 测试
import random
arr = [random.randint(0, 100) for _ in range(10)]
print(f"排序前: {arr}")
print(f"排序后: {merge_sort(arr)}")
```

## 四、快速排序

### 4.1 算法描述

快速排序（Quicksort）是实际应用中最快的排序算法之一：

1. **分解**：选择一个基准元素（pivot），将数组分为小于和大于等于 pivot 的两部分
2. **解决**：递归排序两部分
3. **合并**：无需合并（分区操作已经完成了排序）

### 4.2 分区策略

**Lomuto 分区**：选择最后一个元素作为 pivot

```python
def partition_lomuto(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i+1], arr[high] = arr[high], arr[i+1]
    return i + 1
```

**Hoare 分区**：选择第一个元素作为 pivot，使用双指针

```python
def partition_hoare(arr, low, high):
    pivot = arr[low]
    i = low - 1
    j = high + 1
    while True:
        i += 1
        while arr[i] < pivot:
            i += 1
        j -= 1
        while arr[j] > pivot:
            j -= 1
        if i >= j:
            return j
        arr[i], arr[j] = arr[j], arr[i]
```

### 4.3 时间复杂度分析

**最好情况**：每次分区均匀，$T(n) = 2T(n/2) + O(n) = O(n \log n)$

**最坏情况**：每次分区极不均匀（如已排序数组选首元素为 pivot），$T(n) = T(n-1) + O(n) = O(n^2)$

**平均情况**：$O(n \log n)$

### 4.4 随机化快速排序

随机选择 pivot，将最坏情况的概率降至极低：

```python
import random

def randomized_partition(arr, low, high):
    pivot_idx = random.randint(low, high)
    arr[pivot_idx], arr[high] = arr[high], arr[pivot_idx]
    return partition_lomuto(arr, low, high)
```

### 4.5 快速选择（QuickSelect）

快速选择算法用于在 $O(n)$ 平均时间内找到第 $k$ 小元素：

```python
def quickselect(arr, k):
    """找到arr中第k小的元素"""
    if len(arr) == 1:
        return arr[0]
    
    pivot = arr[random.randint(0, len(arr)-1)]
    lows = [x for x in arr if x < pivot]
    highs = [x for x in arr if x > pivot]
    pivots = [x for x in arr if x == pivot]
    
    if k <= len(lows):
        return quickselect(lows, k)
    elif k <= len(lows) + len(pivots):
        return pivot
    else:
        return quickselect(highs, k - len(lows) - len(pivots))
```

### 4.6 代码实现

```python
def quicksort(arr, low=0, high=None):
    """快速排序"""
    if high is None:
        high = len(arr) - 1
    
    if low < high:
        pivot_idx = randomized_partition(arr, low, high)
        quicksort(arr, low, pivot_idx - 1)
        quicksort(arr, pivot_idx + 1, high)

arr = [3, 6, 8, 10, 1, 2, 1]
quicksort(arr)
print(f"排序后: {arr}")
```

## 五、Strassen 矩阵乘法

### 5.1 朴素矩阵乘法

计算两个 $n \times n$ 矩阵的乘积 $C = AB$，朴素方法需要 $O(n^3)$ 次运算。

### 5.2 分治方法

将矩阵分为四个 $n/2 \times n/2$ 的子矩阵：

$$
\begin{pmatrix} C_{11} & C_{12} \\ C_{21} & C_{22} \end{pmatrix} = \begin{pmatrix} A_{11} & A_{12} \\ A_{21} & A_{22} \end{pmatrix} \begin{pmatrix} B_{11} & B_{12} \\ B_{21} & B_{22} \end{pmatrix}
$$

朴素分治需要8次子矩阵乘法：

$$
C_{11} = A_{11}B_{11} + A_{12}B_{21}
$$
$$
C_{12} = A_{11}B_{12} + A_{12}B_{22}
$$
$$
C_{21} = A_{21}B_{11} + A_{22}B_{21}
$$
$$
C_{22} = A_{21}B_{12} + A_{22}B_{22}
$$

$T(n) = 8T(n/2) + O(n^2) = O(n^3)$，无改善。

### 5.3 Strassen 方法

Strassen 发现只需 7 次子矩阵乘法即可完成计算：

$$
\begin{aligned}
M_1 &= (A_{11} + A_{22})(B_{11} + B_{22}) \\
M_2 &= (A_{21} + A_{22})B_{11} \\
M_3 &= A_{11}(B_{12} - B_{22}) \\
M_4 &= A_{22}(B_{21} - B_{11}) \\
M_5 &= (A_{11} + A_{12})B_{22} \\
M_6 &= (A_{21} - A_{11})(B_{11} + B_{12}) \\
M_7 &= (A_{12} - A_{22})(B_{21} + B_{22})
\end{aligned}
$$

$$
\begin{aligned}
C_{11} &= M_1 + M_4 - M_5 + M_7 \\
C_{12} &= M_3 + M_5 \\
C_{21} &= M_2 + M_4 \\
C_{22} &= M_1 - M_2 + M_3 + M_6
\end{aligned}
$$

$T(n) = 7T(n/2) + O(n^2) = O(n^{\log_2 7}) \approx O(n^{2.807})$

## 六、最近点对问题

### 6.1 问题描述

给定平面上 $n$ 个点，求距离最近的一对点。

### 6.2 朴素方法

检查所有点对的距离，$O(n^2)$。

### 6.3 分治法

1. **分解**：按 $x$ 坐标将点集分为左右两半
2. **解决**：递归求解左右两半的最近点对距离 $\delta_L$ 和 $\delta_R$
3. **合并**：$\delta = \min(\delta_L, \delta_R)$，检查跨越分界线的点对

关键：只需检查距离分界线 $\delta$ 范围内的点对，每个点最多检查常数个点，合并代价 $O(n \log n)$（排序）或 $O(n)$（预排序）。

$$
T(n) = 2T(n/2) + O(n) = O(n \log n)
$$

## 七、大整数乘法（Karatsuba算法）

### 7.1 问题描述

将两个 $n$ 位大整数相乘。

### 7.2 朴素方法

$O(n^2)$。

### 7.3 Karatsuba 方法

将 $n$ 位整数分为两半：$x = x_1 \cdot 10^{n/2} + x_0$，$y = y_1 \cdot 10^{n/2} + y_0$

$$
xy = x_1 y_1 \cdot 10^n + [(x_1 + x_0)(y_1 + y_0) - x_1 y_1 - x_0 y_0] \cdot 10^{n/2} + x_0 y_0
$$

只需 3 次 $n/2$ 位乘法：

$$
T(n) = 3T(n/2) + O(n) = O(n^{\log_2 3}) \approx O(n^{1.585})
$$

## 八、Python 代码实现

### 8.1 归并排序（计数逆序对）

```python
def count_inversions(arr):
    """归并排序计算逆序对数"""
    if len(arr) <= 1:
        return arr, 0
    
    mid = len(arr) // 2
    left, left_inv = count_inversions(arr[:mid])
    right, right_inv = count_inversions(arr[mid:])
    merged, split_inv = merge_count(left, right)
    
    return merged, left_inv + right_inv + split_inv

def merge_count(left, right):
    result = []
    inversions = 0
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            inversions += len(left) - i
            j += 1
    
    result.extend(left[i:])
    result.extend(right[j:])
    return result, inversions

arr = [2, 4, 1, 3, 5]
_, inversions = count_inversions(arr)
print(f"逆序对数: {inversions}")
```

### 8.2 最近点对

```python
import math

def closest_pair(points):
    """最近点对问题 - 分治法"""
    points_sorted = sorted(points, key=lambda p: p[0])
    return closest_helper(points_sorted)

def closest_helper(points):
    n = len(points)
    if n <= 3:
        return min_dist_brute(points)
    
    mid = n // 2
    mid_point = points[mid]
    
    dl = closest_helper(points[:mid])
    dr = closest_helper(points[mid:])
    d = min(dl, dr)
    
    # 检查分界线附近的点
    strip = [p for p in points if abs(p[0] - mid_point[0]) < d]
    strip.sort(key=lambda p: p[1])
    
    for i in range(len(strip)):
        for j in range(i + 1, min(i + 8, len(strip))):
            dist = math.dist(strip[i], strip[j])
            if dist < d:
                d = dist
    
    return d

def min_dist_brute(points):
    min_d = float('inf')
    for i in range(len(points)):
        for j in range(i + 1, len(points)):
            min_d = min(min_d, math.dist(points[i], points[j]))
    return min_d

points = [(2, 3), (12, 30), (40, 50), (5, 1), (12, 10), (3, 4)]
d = closest_pair(points)
print(f"最近点对距离: {d:.4f}")
```

### 8.3 Strassen 矩阵乘法

```python
import numpy as np

def strassen(A, B):
    """Strassen矩阵乘法"""
    n = A.shape[0]
    
    if n <= 2:
        return A @ B
    
    mid = n // 2
    A11, A12 = A[:mid, :mid], A[:mid, mid:]
    A21, A22 = A[mid:, :mid], A[mid:, mid:]
    B11, B12 = B[:mid, :mid], B[:mid, mid:]
    B21, B22 = B[mid:, :mid], B[mid:, mid:]
    
    M1 = strassen(A11 + A22, B11 + B22)
    M2 = strassen(A21 + A22, B11)
    M3 = strassen(A11, B12 - B22)
    M4 = strassen(A22, B21 - B11)
    M5 = strassen(A11 + A12, B22)
    M6 = strassen(A21 - A11, B11 + B12)
    M7 = strassen(A12 - A22, B21 + B22)
    
    C = np.zeros_like(A)
    C[:mid, :mid] = M1 + M4 - M5 + M7
    C[:mid, mid:] = M3 + M5
    C[mid:, :mid] = M2 + M4
    C[mid:, mid:] = M1 - M2 + M3 + M6
    
    return C

# 测试 (padding到2的幂次)
n = 4
A = np.random.randint(0, 10, (n, n))
B = np.random.randint(0, 10, (n, n))

C_strassen = strassen(A, B)
C_numpy = A @ B
print(f"Strassen结果与numpy一致: {np.allclose(C_strassen, C_numpy)}")
```

## 九、关键要点总结

1. **分治三步**：分解、解决、合并，是分治算法的标准框架
2. **主定理**提供了求解递推关系 $T(n) = aT(n/b) + f(n)$ 的系统方法
3. **归并排序** $O(n \log n)$ 是稳定的分治排序算法
4. **快速排序**平均 $O(n \log n)$，是实践中最快的通用排序算法
5. **Strassen矩阵乘法**将复杂度从 $O(n^3)$ 降至 $O(n^{2.807})$
6. **最近点对**分治法将 $O(n^2)$ 降至 $O(n \log n)$
7. 分治与动态规划的关键区别：分治的子问题相互独立，DP的子问题有重叠
8. 分治法的效率取决于子问题的个数、规模和合并代价
