# 线性规划

> **理论基础** → 参见 [[../../优化方法/线性规划|线性规划理论]]

线性规划是数学建模中最基本的优化方法，用于求解线性目标函数在线性约束下的最优解。广泛应用于生产计划、资源分配、运输问题等场景。

## 七、Python 代码实现
### 7.1 使用 scipy.optimize.linprog

```python
import numpy as np
from scipy.optimize import linprog

# 目标函数系数 (min c^T x)
c = [-2, -3]  # 注意：linprog 默认求最小值，求最大值需取负

# 不等式约束 A_ub @ x <= b_ub
A_ub = [
    [1, 1],
    [2, 1],
    [1, 2]
]
b_ub = [4, 6, 5]

# 变量范围 x >= 0
x_bounds = [(0, None), (0, None)]

# 求解
result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=x_bounds, method='highs')

print(f"最优解: x1={result.x[0]:.4f}, x2={result.x[1]:.4f}")
print(f"最优值: z={-result.fun:.4f}")  # 取负恢复原始目标函数值
```

### 7.2 简易单纯形法实现

```python
import numpy as np

def simplex(c, A, b):
    """
    单纯形法求解 max c^T x, s.t. Ax <= b, x >= 0
    """
    m, n = A.shape
    
    # 构建增广表: [A | I | b]
    # 行 [0..m-1]: 约束
    # 行 m: 目标函数 (检验数)
    table = np.zeros((m + 2, n + m + 1))
    table[:m, :n] = A
    table[:m, n:n+m] = np.eye(m)
    table[:m, -1] = b
    table[m+1, :n] = -c  # 检验数行 (注意取负)
    
    basis = list(range(n, n + m))  # 基变量索引
    
    while True:
        # 1. 最优性检验
        obj_row = table[m + 1, :-1]
        if np.all(obj_row >= -1e-10):
            break
        
        # 2. 选择进基变量 (最小检验数)
        enter = np.argmin(obj_row)
        
        # 3. 最小比值法则
        ratios = np.full(m, np.inf)
        for i in range(m):
            if table[i, enter] > 1e-10:
                ratios[i] = table[i, -1] / table[i, enter]
        
        if np.all(ratios == np.inf):
            print("问题无界!")
            return None
        
        leave = np.argmin(ratios)
        
        # 4. 转轴运算
        pivot = table[leave, enter]
        table[leave] /= pivot
        for i in range(m + 2):
            if i != leave:
                table[i] -= table[i, enter] * table[leave]
        
        basis[leave] = enter
    
    # 提取最优解
    x = np.zeros(n)
    for i, b_var in enumerate(basis):
        if b_var < n:
            x[b_var] = table[i, -1]
    
    optimal_value = table[m + 1, -1]
    return x, optimal_value

# 示例
c = np.array([2, 3])
A = np.array([
    [1, 1],
    [2, 1],
    [1, 2]
])
b = np.array([4, 6, 5])

x_opt, z_opt = simplex(c, A, b)
print(f"最优解: {x_opt}")
print(f"最优值: {z_opt}")
```

## 九、实际应用案例
### 9.1 生产计划问题

某工厂生产两种产品 $A$ 和 $B$。生产一件产品 $A$ 需要2小时人工和1小时机器时间，利润为40元；生产一件产品 $B$ 需要1小时人工和2小时机器时间，利润为50元。工厂每天有120小时人工和100小时机器时间。求最优生产计划。

**数学模型**：

$$
\begin{aligned}
\max \quad & z = 40x_1 + 50x_2 \\
\text{s.t.} \quad & 2x_1 + x_2 \leq 120 \\
& x_1 + 2x_2 \leq 100 \\
& x_1, x_2 \geq 0
\end{aligned}
$$

**求解**：利用单纯形法或软件求解，最优解为 $x_1 = 46.67$，$x_2 = 26.67$，最优利润 $z = 3200$ 元。

### 9.2 运输问题

设有 $m$ 个供应点和 $n$ 个需求点，供应量为 $s_i$，需求量为 $d_j$，单位运输成本为 $c_{ij}$。求最小运输成本。

$$
\begin{aligned}
\min \quad & z = \sum_{i=1}^{m}\sum_{j=1}^{n} c_{ij} x_{ij} \\
\text{s.t.} \quad & \sum_{j=1}^{n} x_{ij} = s_i, \quad i=1,\ldots,m \\
& \sum_{i=1}^{m} x_{ij} = d_j, \quad j=1,\ldots,n \\
& x_{ij} \geq 0
\end{aligned}
$$

## 十、关键要点总结
1. **线性规划的标准形式**要求最大化、等式约束、变量非负，是单纯形法的前提
2. **单纯形法**是求解线性规划最基本的方法，通过在基可行解之间迭代寻找最优解
3. **对偶理论**揭示了原问题与对偶问题之间的深刻联系，互补松弛定理可用来检验最优性
4. **灵敏度分析**研究参数变化对最优解的影响，具有重要的实际意义
5. **两阶段法**和**大M法**用于寻找初始基可行解
6. 内点法是多项式时间算法，大规模问题中表现优异
7. 实际求解通常使用成熟的优化软件（如 CPLEX、Gurobi、scipy）
