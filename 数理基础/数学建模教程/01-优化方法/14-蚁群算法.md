# 蚁群算法

## 一、蚁群算法概述

蚁群算法（Ant Colony Optimization, ACO）由 Marco Dorigo 于1992年提出，灵感来源于真实蚂蚁通过信息素（pheromone）间接通信的觅食行为。

### 1.1 生物学背景

- 蚂蚁在行走过程中释放信息素
- 后续蚂蚁倾向于选择信息素浓度高的路径
- 信息素随时间挥发
- 较短路径上的蚂蚁往返更快，信息素积累更多
- 正反馈机制最终使所有蚂蚁收敛到最短路径

### 1.2 算法特点

- **正反馈**：好的解通过信息素积累得到加强
- **分布式计算**：多个蚂蚁同时搜索
- **启发式引导**：结合问题特定的启发式信息
- **天然适合组合优化**：尤其是图上的路径问题

---

## 二、蚁群算法基本框架

### 2.1 转移概率

蚂蚁 $k$ 在节点 $i$ 选择下一个节点 $j$ 的概率：

$$
p_{ij}^k = \begin{cases}
\frac{[\tau_{ij}]^\alpha \cdot [\eta_{ij}]^\beta}{\sum_{l \in \mathcal{N}_i^k} [\tau_{il}]^\alpha \cdot [\eta_{il}]^\beta}, & j \in \mathcal{N}_i^k \\
0, & \text{otherwise}
\end{cases}
$$

其中 $\tau_{ij}$ 为信息素浓度，$\eta_{ij}$ 为启发式信息，$\alpha$ 和 $\beta$ 分别控制信息素和启发式的权重。

### 2.2 信息素更新

**挥发**：$\tau_{ij} \leftarrow (1 - \rho) \cdot \tau_{ij}$

**沉积**：$\tau_{ij} \leftarrow \tau_{ij} + \sum_{k=1}^{m} \Delta\tau_{ij}^k$

Ant System 的沉积规则：

$$
\Delta\tau_{ij}^k = \begin{cases}
\frac{Q}{L_k}, & \text{若蚂蚁 } k \text{ 经过边 } (i, j) \\
0, & \text{otherwise}
\end{cases}
$$

---

## 三、信息素更新策略

### 3.1 Ant Colony System（ACS）

- **全局更新**：只有最优蚂蚁更新信息素
- **局部更新**：蚂蚁每次经过一条边后立即更新

$$
\tau_{ij} \leftarrow (1-\xi) \cdot \tau_{ij} + \xi \cdot \tau_0
$$

### 3.2 MAX-MIN Ant System（MMAS）

限制信息素浓度在 $[\tau_{\min}, \tau_{\max}]$ 之间：

$$
\tau_{\max} = \frac{1}{\rho} \cdot \frac{1}{f(s^{\text{gb}})}, \quad \tau_{\min} = \frac{\tau_{\max}(1 - \sqrt[n]{p_{\text{best}}})}{(n/2 - 1)\sqrt[n]{p_{\text{best}}}}
$$

### 3.3 Rank-Based Ant System

蚂蚁按解的质量排序，排名前 $w$ 的蚂蚁更新信息素，权重与排名成正比。

---

## 四、参数设置

| 参数 | 含义 | 推荐值 |
|------|------|-------|
| $\alpha$ | 信息素重要程度 | $1 \sim 2$ |
| $\beta$ | 启发式信息重要程度 | $2 \sim 5$ |
| $\rho$ | 信息素挥发率 | $0.1 \sim 0.5$ |
| $Q$ | 信息素沉积常数 | 问题相关 |
| $m$ | 蚂蚁数量 | $10 \sim 50$ |

## 五、Python 代码实现

### 5.1 蚁群算法求解 TSP

```python
import numpy as np
import random

class AntColonyTSP:
    def __init__(self, dist_matrix, n_ants=20, n_iter=100,
                 alpha=1.0, beta=3.0, rho=0.1, Q=100):
        self.dist = np.array(dist_matrix, dtype=float)
        self.n = len(self.dist)
        self.n_ants = n_ants
        self.n_iter = n_iter
        self.alpha = alpha
        self.beta = beta
        self.rho = rho
        self.Q = Q
        self.tau = np.ones((self.n, self.n)) * 0.1
        self.eta = np.zeros((self.n, self.n))
        for i in range(self.n):
            for j in range(self.n):
                if i != j:
                    self.eta[i][j] = 1.0 / self.dist[i][j]

    def construct_solution(self, start):
        visited = [start]
        current = start
        while len(visited) < self.n:
            probs = np.zeros(self.n)
            for j in range(self.n):
                if j not in visited:
                    probs[j] = (self.tau[current][j] ** self.alpha *
                               self.eta[current][j] ** self.beta)
            total = probs.sum()
            if total > 0:
                probs /= total
                next_city = np.random.choice(self.n, p=probs)
            else:
                unvisited = [j for j in range(self.n) if j not in visited]
                next_city = random.choice(unvisited)
            visited.append(next_city)
            current = next_city
        return visited

    def route_distance(self, route):
        return sum(self.dist[route[i]][route[(i+1) % len(route)]]
                   for i in range(len(route)))

    def update_pheromone(self, solutions, distances):
        self.tau *= (1 - self.rho)
        for sol, dist in zip(solutions, distances):
            deposit = self.Q / dist
            for i in range(len(sol)):
                j = (i + 1) % len(sol)
                self.tau[sol[i]][sol[j]] += deposit
                self.tau[sol[j]][sol[i]] += deposit

    def solve(self):
        best_route = None
        best_dist = float('inf')
        for iteration in range(self.n_iter):
            solutions = []
            distances = []
            for k in range(self.n_ants):
                start = random.randint(0, self.n - 1)
                route = self.construct_solution(start)
                dist = self.route_distance(route)
                solutions.append(route)
                distances.append(dist)
            self.update_pheromone(solutions, distances)
            min_idx = np.argmin(distances)
            if distances[min_idx] < best_dist:
                best_dist = distances[min_idx]
                best_route = solutions[min_idx][:]
        return best_route, best_dist

np.random.seed(42)
n = 25
coords = np.random.rand(n, 2) * 100
dist = np.sqrt(((coords[:, None] - coords[None, :]) ** 2).sum(axis=2))

aco = AntColonyTSP(dist, n_ants=20, n_iter=150, alpha=1.0, beta=5.0, rho=0.3)
route, total_dist = aco.solve()
print(f"最优距离: {total_dist:.2f}")
```

### 5.2 蚁群算法求解车辆路径问题（VRP）

```python
import numpy as np
import random

class AntColonyVRP:
    def __init__(self, dist_matrix, demand, capacity, n_ants=20, n_iter=100,
                 alpha=1.0, beta=3.0, rho=0.1, Q=100):
        self.dist = np.array(dist_matrix)
        self.demand = demand
        self.capacity = capacity
        self.n = len(dist_matrix)
        self.n_ants = n_ants
        self.n_iter = n_iter
        self.alpha = alpha
        self.beta = beta
        self.rho = rho
        self.Q = Q
        self.tau = np.ones((self.n, self.n)) * 0.1
        self.eta = np.zeros((self.n, self.n))
        for i in range(self.n):
            for j in range(self.n):
                if i != j:
                    self.eta[i][j] = 1.0 / self.dist[i][j]

    def construct_solution(self):
        routes = []
        visited = {0}
        current_load = 0
        current = 0
        route = [0]

        while len(visited) < self.n:
            probs = np.zeros(self.n)
            for j in range(self.n):
                if j not in visited and current_load + self.demand[j] <= self.capacity:
                    probs[j] = (self.tau[current][j] ** self.alpha *
                               self.eta[current][j] ** self.beta)
            total = probs.sum()
            if total > 0:
                probs /= total
                next_city = np.random.choice(self.n, p=probs)
            else:
                routes.append(route + [0])
                route = [0]
                current_load = 0
                current = 0
                continue

            route.append(next_city)
            visited.add(next_city)
            current_load += self.demand[next_city]
            current = next_city

        routes.append(route + [0])
        return routes

    def total_distance(self, routes):
        return sum(self.dist[route[i]][route[i+1]]
                   for route in routes for i in range(len(route)-1))

    def solve(self):
        best_routes = None
        best_dist = float('inf')

        for iteration in range(self.n_iter):
            all_routes = []
            all_dists = []
            for _ in range(self.n_ants):
                routes = self.construct_solution()
                dist = self.total_distance(routes)
                all_routes.append(routes)
                all_dists.append(dist)

            min_idx = np.argmin(all_dists)
            if all_dists[min_idx] < best_dist:
                best_dist = all_dists[min_idx]
                best_routes = all_routes[min_idx]

            self.tau *= (1 - self.rho)
            best_r = all_routes[min_idx]
            for route in best_r:
                deposit = self.Q / best_dist
                for i in range(len(route) - 1):
                    self.tau[route[i]][route[i+1]] += deposit
                    self.tau[route[i+1]][route[i]] += deposit

        return best_routes, best_dist
```

## 六、关键要点总结

1. 蚁群算法通过**信息素的正反馈机制**逐步收敛到最优解
2. **转移概率**结合信息素浓度和启发式信息进行路径选择
3. **信息素挥发**防止过早收敛，保持探索能力
4. **MMAS** 和 **ACS** 是最成功的 ACO 变体
5. 参数 $\alpha, \beta, \rho$ 的合理设置对算法性能至关重要
6. ACO 天然适合 TSP、VRP 等组合优化问题
7. ACO 可与其他局部搜索方法（如 2-opt）结合提高性能
8. ACO_R 扩展了算法在连续优化领域的应用
