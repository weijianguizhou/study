# 遗传算法

## 一、遗传算法概述

遗传算法（Genetic Algorithm, GA）是由 John Holland 于1975年提出的基于自然选择和遗传学原理的随机搜索与优化算法。它模拟生物进化过程中的选择、交叉和变异操作，在解空间中搜索最优解。

### 1.1 基本概念对应关系

| 生物学概念 | 遗传算法概念 |
|-----------|-------------|
| 染色体 | 解的编码 |
| 基因 | 编码中的每一位 |
| 个体 | 一个候选解 |
| 种群 | 候选解的集合 |
| 适应度 | 目标函数值 |
| 自然选择 | 选择操作 |
| 交叉繁殖 | 交叉操作 |
| 基因突变 | 变异操作 |
| 进化 | 迭代优化过程 |

### 1.2 遗传算法流程

```
初始化种群
while (未满足终止条件) do
    计算每个个体的适应度
    选择操作
    交叉操作
    变异操作
    更新种群
end while
输出最优个体
```

## 二、编码方式

### 2.1 二进制编码

将解编码为0-1字符串：

$$
\mathbf{x} = (x_1, x_2, \ldots, x_L), \quad x_i \in \{0, 1\}
$$

**解码**：若变量 $x^{(j)}$ 的范围为 $[a_j, b_j]$，编码长度为 $l_j$，则：

$$
x^{(j)} = a_j + \frac{x^{(j)} \text{ 对应的十进制值}}{2^{l_j} - 1} \cdot (b_j - a_j)
$$

### 2.2 实数编码

直接用实数表示解，适用于连续优化问题：

$$
\mathbf{x} = (x_1, x_2, \ldots, x_n), \quad x_i \in \mathbb{R}
$$

### 2.3 排列编码（整数编码）

用于组合优化问题（如旅行商问题），每个基因表示一个城市的访问顺序。

### 2.4 格雷码

相邻编码只差一位：

$$
000 \to 001 \to 011 \to 010 \to 110 \to 111 \to 101 \to 100
$$

优点：减少海明悬崖效应，使搜索更平滑。

## 三、适应度函数

### 3.1 适应度函数的设计

适应度函数 $F(\mathbf{x})$ 用于评价个体的优劣。对于最大化问题，$F(\mathbf{x}) = f(\mathbf{x})$；对于最小化问题：

$$
F(\mathbf{x}) = \frac{1}{1 + f(\mathbf{x})} \quad \text{或} \quad F(\mathbf{x}) = C_{\max} - f(\mathbf{x})
$$

### 3.2 适应度缩放

**线性缩放**：

$$
F' = aF + b
$$

**指数缩放**：

$$
F' = e^{\alpha F}
$$

**排序缩放**：按适应度排序分配选择概率，避免超个体（适应度远大于其他个体的个体）主导种群。

---

## 四、选择操作

选择操作根据适应度从当前种群中选择个体作为下一代的父代。适应度越高的个体被选中的概率越大。

### 4.1 轮盘赌选择（Roulette Wheel Selection）

个体 $i$ 被选中的概率与其适应度成正比：

$$
p_i = \frac{F_i}{\sum_{j=1}^{N} F_j}
$$

**缺点**：当适应度差异很大时，高适应度个体可能过度主导。

### 4.2 锦标赛选择（Tournament Selection）

从种群中随机选择 $k$ 个个体（通常 $k = 2$ 或 $3$），选择其中适应度最高的个体作为父代。

**优点**：不需要归一化，选择压力可调。

### 4.3 顺序选择（Rank Selection）

按适应度排序，第 $r$ 个个体的选择概率为：

$$
p_r = \frac{2(N - r + 1)}{N(N + 1)}
$$

其中 $N$ 为种群大小，$r$ 为排序位置（$r = 1$ 为最优）。

### 4.4 精英保留策略

将当前种群中适应度最高的 $k$ 个个体直接复制到下一代，确保最优解不丢失。

$$
\text{精英数} \quad k = \lceil p_e \cdot N \rceil
$$

通常取 $p_e = 0.05 \sim 0.1$。

---

## 五、交叉操作

交叉操作是遗传算法的核心操作，通过交换两个父代个体的部分基因来产生新的个体。

### 5.1 单点交叉（Single-Point Crossover）

随机选择一个交叉点，交换该点之后的基因：

```
父代1: A B C | D E F G
父代2: a b c | d e f g
        ↓
子代1: A B C | d e f g
子代2: a b c | D E F G
```

### 5.2 两点交叉（Two-Point Crossover）

随机选择两个交叉点，交换两点之间的基因：

```
父代1: A B | C D | E F
父代2: a b | c d | e f
        ↓
子代1: A B | c d | E F
子代2: a b | C D | e f
```

### 5.3 均匀交叉（Uniform Crossover）

每个基因位以概率 $p_c$ 从父代1或父代2中继承：

$$
\text{child}_i = \begin{cases} \text{parent1}_i & \text{若 } r_i < p_c \\ \text{parent2}_i & \text{否则} \end{cases}
$$

### 5.4 算术交叉（实数编码）

$$
\text{child} = \alpha \cdot \text{parent1} + (1-\alpha) \cdot \text{parent2}
$$

其中 $\alpha \in [0, 1]$ 为随机数。

### 5.5 交叉概率

交叉概率 $p_c$ 控制交叉操作的频率，通常取 $0.6 \sim 0.9$。

---

## 六、变异操作

变异操作以较小的概率随机改变个体的某些基因，增加种群多样性，避免过早收敛。

### 6.1 位翻转变异（二进制编码）

以变异概率 $p_m$ 翻转每个基因位：

$$
x_i = 1 - x_i \quad \text{以概率 } p_m
$$

### 6.2 均匀变异（实数编码）

随机选择变异位，用范围内的随机值替换：

$$
x_i' = x_i^{\min} + r \cdot (x_i^{\max} - x_i^{\min})
$$

其中 $r \in [0, 1]$ 为随机数。

### 6.3 高斯变异（实数编码）

在当前值上添加高斯噪声：

$$
x_i' = x_i + N(0, \sigma^2)
$$

### 6.4 变异概率

变异概率 $p_m$ 通常取 $0.001 \sim 0.1$。过大会导致随机搜索，过小会丧失多样性。

---

## 七、遗传算法参数设置

### 7.1 种群大小 $N$

- $N$ 太小：搜索能力不足，容易早熟收敛
- $N$ 太大：计算量增加，收敛变慢
- 通常取 $20 \sim 200$，复杂问题可增大

### 7.2 编码长度 $L$

- 影响搜索空间的精细度
- 二进制编码中，$L$ 越长精度越高

### 7.3 交叉概率 $p_c$

- 通常取 $0.6 \sim 0.9$
- 过高可能破坏好个体，过低搜索效率低

### 7.4 变异概率 $p_m$

- 通常取 $0.001 \sim 0.1$
- 自适应变异：$p_m$ 随适应度调整

### 7.5 终止条件

- 达到最大迭代次数
- 适应度不再改善
- 种群多样性低于阈值

---

## 八、自适应遗传算法

### 8.1 自适应交叉和变异概率

根据个体的适应度动态调整 $p_c$ 和 $p_m$：

$$
p_c = \begin{cases}
k_1 \cdot \frac{f_{\max} - f'}{f_{\max} - \bar{f}}, & f' \geq \bar{f} \\
k_3, & f' < \bar{f}
\end{cases}
$$

$$
p_m = \begin{cases}
k_2 \cdot \frac{f_{\max} - f}{f_{\max} - \bar{f}}, & f \geq \bar{f} \\
k_4, & f < \bar{f}
\end{cases}
$$

其中 $f_{\max}$ 为最大适应度，$\bar{f}$ 为平均适应度，$f'$ 为交叉个体中较大适应度，$f$ 为变异个体的适应度。

## 九、Python 代码实现

### 9.1 基本遗传算法

```python
import numpy as np
import random

class GeneticAlgorithm:
    def __init__(self, fitness_func, n_var, bounds, pop_size=50,
                 max_gen=100, pc=0.8, pm=0.1):
        self.fitness_func = fitness_func
        self.n_var = n_var
        self.bounds = np.array(bounds)
        self.pop_size = pop_size
        self.max_gen = max_gen
        self.pc = pc
        self.pm = pm
        self.population = None
        self.best_history = []
    
    def init_population(self):
        """初始化种群"""
        lows = self.bounds[:, 0]
        highs = self.bounds[:, 1]
        self.population = np.random.uniform(lows, highs, (self.pop_size, self.n_var))
    
    def evaluate(self):
        """计算适应度"""
        fitness = np.array([self.fitness_func(ind) for ind in self.population])
        return fitness
    
    def selection(self, fitness):
        """轮盘赌选择"""
        # 最小化问题转换
        max_fit = np.max(fitness)
        probs = (max_fit - fitness + 1e-10)
        probs = probs / probs.sum()
        
        indices = np.random.choice(self.pop_size, self.pop_size, p=probs)
        return self.population[indices].copy()
    
    def crossover(self, parent1, parent2):
        """实数编码算术交叉"""
        if random.random() < self.pc:
            alpha = random.random()
            child1 = alpha * parent1 + (1 - alpha) * parent2
            child2 = (1 - alpha) * parent1 + alpha * parent2
            return child1, child2
        return parent1.copy(), parent2.copy()
    
    def mutate(self, individual):
        """高斯变异"""
        for i in range(self.n_var):
            if random.random() < self.pm:
                sigma = (self.bounds[i, 1] - self.bounds[i, 0]) * 0.1
                individual[i] += np.random.normal(0, sigma)
                individual[i] = np.clip(individual[i], self.bounds[i, 0], self.bounds[i, 1])
        return individual
    
    def evolve(self):
        """主进化循环"""
        self.init_population()
        
        for gen in range(self.max_gen):
            fitness = self.evaluate()
            best_idx = np.argmin(fitness)
            self.best_history.append((self.population[best_idx].copy(), fitness[best_idx]))
            
            # 精英保留
            elite_idx = np.argsort(fitness)[:2]
            elites = self.population[elite_idx].copy()
            
            # 选择
            selected = self.selection(fitness)
            
            # 交叉和变异
            new_pop = []
            for i in range(0, self.pop_size - 2, 2):
                c1, c2 = self.crossover(selected[i], selected[i+1])
                new_pop.append(self.mutate(c1))
                new_pop.append(self.mutate(c2))
            
            new_pop = np.array(new_pop[:self.pop_size - 2])
            self.population = np.vstack([new_pop, elites])
        
        fitness = self.evaluate()
        best_idx = np.argmin(fitness)
        return self.population[best_idx], fitness[best_idx]

# 示例: min f(x) = x1^2 + x2^2 - x1*x2 - 2*x1 - 5*x2
def objective(x):
    return x[0]**2 + x[1]**2 - x[0]*x[1] - 2*x[0] - 5*x[1]

ga = GeneticAlgorithm(objective, n_var=2, bounds=[(-10, 10), (-10, 10)],
                       pop_size=50, max_gen=200)
best_sol, best_val = ga.evolve()
print(f"最优解: x1={best_sol[0]:.4f}, x2={best_sol[1]:.4f}")
print(f"最优值: {best_val:.4f}")
```

### 9.2 旅行商问题（TSP）遗传算法

```python
import numpy as np
import random

def tsp_ga(distance_matrix, n_cities, pop_size=100, max_gen=500):
    """TSP遗传算法 (排列编码)"""
    
    def fitness(route):
        return sum(distance_matrix[route[i]][route[i+1]] for i in range(len(route)-1))
    
    def init_pop():
        return [random.sample(range(n_cities), n_cities) for _ in range(pop_size)]
    
    def order_crossover(p1, p2):
        """顺序交叉 (OX)"""
        size = len(p1)
        start, end = sorted(random.sample(range(size), 2))
        
        child = [-1] * size
        child[start:end+1] = p1[start:end+1]
        
        fill_values = [x for x in p2 if x not in child]
        idx = 0
        for i in range(size):
            if child[i] == -1:
                child[i] = fill_values[idx]
                idx += 1
        return child
    
    def swap_mutation(route, pm=0.2):
        """交换变异"""
        for i in range(len(route)):
            if random.random() < pm:
                j = random.randint(0, len(route) - 1)
                route[i], route[j] = route[j], route[i]
        return route
    
    # 初始化
    population = init_pop()
    best_ever = min(population, key=fitness)
    best_ever_fit = fitness(best_ever)
    
    for gen in range(max_gen):
        fits = [fitness(ind) for ind in population]
        
        # 选择 (锦标赛)
        def tournament(k=3):
            candidates = random.sample(range(pop_size), k)
            winner = min(candidates, key=lambda i: fits[i])
            return population[winner]
        
        new_pop = []
        # 精英保留
        best_idx = np.argmin(fits)
        new_pop.append(population[best_idx])
        
        while len(new_pop) < pop_size:
            p1 = tournament()
            p2 = tournament()
            child = order_crossover(p1, p2)
            child = swap_mutation(child)
            new_pop.append(child)
        
        population = new_pop[:pop_size]
        
        gen_best = min(population, key=fitness)
        gen_fit = fitness(gen_best)
        if gen_fit < best_ever_fit:
            best_ever = gen_best[:]
            best_ever_fit = gen_fit
    
    return best_ever, best_ever_fit

# 示例
np.random.seed(42)
n = 10
coords = np.random.rand(n, 2) * 100
dist = np.sqrt(((coords[:, None] - coords[None, :]) ** 2).sum(axis=2))

route, dist_val = tsp_ga(dist, n)
print(f"最优路线: {route}")
print(f"总距离: {dist_val:.2f}")
```

## 十、关键要点总结

1. 遗传算法通过**选择、交叉、变异**三个操作模拟生物进化过程
2. **编码方式**决定了算法的表达能力和效率
3. **选择压力**需要平衡探索和利用：压力过大导致早熟，过小收敛慢
4. **交叉**是主要的搜索算子，**变异**提供多样性保障
5. **精英保留**确保最优解不丢失
6. 参数设置（种群大小、交叉率、变异率）对性能影响显著
7. 遗传算法适合**多峰、非线性、不可微**的复杂优化问题
8. 自适应遗传算法根据搜索进度动态调整参数，提高鲁棒性
