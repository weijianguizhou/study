# 动态规划

## 一、动态规划概述

动态规划（Dynamic Programming, DP）是由 Richard Bellman 于1957年提出的解决多阶段决策过程最优化问题的数学方法。动态规划的核心思想是将复杂问题分解为一系列相互关联的子问题，通过求解子问题来构建原问题的解。

### 1.1 适用条件

一个问题能用动态规划求解，需要满足以下条件：

**（1）最优子结构（Optimal Substructure）**

问题的最优解包含其子问题的最优解。即原问题的最优解可以通过子问题的最优解构造得到。

**（2）重叠子问题（Overlapping Subproblems）**

在求解过程中，相同的子问题会被反复计算多次。动态规划通过存储子问题的解来避免重复计算。

**（3）无后效性（Markov Property）**

某个阶段的状态一旦确定，后续过程的发展只与当前状态有关，而与如何到达该状态的历史路径无关。

### 1.2 基本要素

- **阶段（Stage）**：将决策过程按时间或空间划分为若干阶段
- **状态（State）**：每个阶段开始时的状况描述
- **决策（Decision）**：每个阶段在某个状态下做出的选择
- **状态转移方程（State Transition）**：由当前状态和决策决定下一阶段状态的规则
- **指标函数（Objective Function）**：衡量整个过程优劣的数量指标

## 二、Bellman 方程

### 2.1 递归方程

Bellman 方程（最优性方程）是动态规划的核心：

$$
V_k(\mathbf{s}) = \min_{\mathbf{d} \in D(\mathbf{s})} \left\{ r(\mathbf{s}, \mathbf{d}) + V_{k+1}(\mathbf{s}') \right\}
$$

或等价地（最大化形式）：

$$
V_k(\mathbf{s}) = \max_{\mathbf{d} \in D(\mathbf{s})} \left\{ r(\mathbf{s}, \mathbf{d}) + V_{k+1}(\mathbf{s}') \right\}
$$

其中：
- $V_k(\mathbf{s})$ 为从第 $k$ 阶段状态 $\mathbf{s}$ 出发到最终阶段的最优值
- $r(\mathbf{s}, \mathbf{d})$ 为在状态 $\mathbf{s}$ 下采取决策 $\mathbf{d}$ 的即时收益
- $\mathbf{s}' = T(\mathbf{s}, \mathbf{d})$ 为转移后的新状态
- $D(\mathbf{s})$ 为状态 $\mathbf{s}$ 下的可行决策集

### 2.2 边界条件

$$
V_N(\mathbf{s}) = \phi(\mathbf{s})
$$

其中 $\phi(\mathbf{s})$ 为终端阶段的指标函数值。

### 2.3 最优策略

在每个阶段，最优策略 $\pi^*(\mathbf{s})$ 为：

$$
\pi^*(\mathbf{s}) = \arg\min_{\mathbf{d} \in D(\mathbf{s})} \left\{ r(\mathbf{s}, \mathbf{d}) + V_{k+1}(T(\mathbf{s}, \mathbf{d})) \right\}
$$

## 三、动态规划的两种求解方法

### 3.1 逆序求解法（Backward Induction）

从最后一个阶段开始，逆向递推到初始阶段：

1. **初始化**：计算终端阶段 $V_N(\mathbf{s})$
2. **逆向递推**：对 $k = N-1, N-2, \ldots, 1$，计算 $V_k(\mathbf{s})$
3. **正向回溯**：根据最优策略回溯最优路径

$$
\begin{aligned}
k = N: \quad & V_N(\mathbf{s}) = \phi(\mathbf{s}) \\
k = N-1: \quad & V_{N-1}(\mathbf{s}) = \min_{\mathbf{d}} \{r_{N-1}(\mathbf{s}, \mathbf{d}) + V_N(\mathbf{s}')\} \\
& \vdots \\
k = 1: \quad & V_1(\mathbf{s}_0) = \min_{\mathbf{d}} \{r_1(\mathbf{s}_0, \mathbf{d}) + V_2(\mathbf{s}')\}
\end{aligned}
$$

### 3.2 顺序求解法（Forward Induction）

从初始阶段开始，正向递推到最终阶段：

$$
\begin{aligned}
k = 1: \quad & V_1(\mathbf{s}) = r_1(\mathbf{s}) \\
k = 2: \quad & V_2(\mathbf{s}) = \min_{\mathbf{d}} \{V_1(\mathbf{s}') + r_2(\mathbf{s}, \mathbf{d})\} \\
& \vdots
\end{aligned}
$$

## 四、经典动态规划问题

### 4.1 背包问题

**0-1 背包问题**：有 $n$ 个物品，第 $i$ 个物品重量为 $w_i$，价值为 $v_i$，背包容量为 $W$。选择若干物品装入背包，使总价值最大。

**状态定义**：$V(i, j)$ 为考虑前 $i$ 个物品、背包剩余容量为 $j$ 时的最大价值。

**Bellman 方程**：

$$
V(i, j) = \begin{cases}
0, & i = 0 \text{ 或 } j = 0 \\
V(i-1, j), & w_i > j \\
\max\{V(i-1, j), V(i-1, j-w_i) + v_i\}, & w_i \leq j
\end{cases}
$$

**最优值**：$V(n, W)$

**时间复杂度**：$O(nW)$

**空间复杂度**：$O(nW)$（可用滚动数组优化到 $O(W)$）

```python
def knapsack_01(weights, values, W):
    n = len(weights)
    dp = [0] * (W + 1)
    
    for i in range(n):
        for j in range(W, weights[i] - 1, -1):  # 逆序遍历
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    
    return dp[W]
```

### 4.2 最短路径问题

给定有向图 $G = (V, E)$，求从源点 $s$ 到终点 $t$ 的最短路径。

**Bellman 方程**：

$$
V(v) = \min_{(v, u) \in E} \{w(v, u) + V(u)\}
$$

其中 $V(u)$ 为从节点 $u$ 到 $t$ 的最短距离，$w(v, u)$ 为边 $(v, u)$ 的权重。

**Bellman-Ford 算法**（可处理负权边）：

$$
d[v] = \min(d[v], d[u] + w(u, v)), \quad \forall (u, v) \in E
$$

重复 $|V|-1$ 次松弛操作。

### 4.3 矩阵链乘法

给定 $n$ 个矩阵 $A_1, A_2, \ldots, A_n$，其中 $A_i$ 的维度为 $p_{i-1} \times p_i$，确定矩阵乘法的最优括号化方案使标量乘法次数最少。

**状态定义**：$m[i, j]$ 为计算 $A_i A_{i+1} \cdots A_j$ 的最少乘法次数。

**Bellman 方程**：

$$
m[i, j] = \begin{cases}
0, & i = j \\
\min_{i \leq k < j} \{m[i, k] + m[k+1, j] + p_{i-1} p_k p_j\}, & i < j
\end{cases}
$$

**时间复杂度**：$O(n^3)$

**空间复杂度**：$O(n^2)$

### 4.4 最长公共子序列（LCS）

给定两个序列 $X = x_1 x_2 \cdots x_m$ 和 $Y = y_1 y_2 \cdots y_n$，求它们的最长公共子序列。

**Bellman 方程**：

$$
c[i, j] = \begin{cases}
0, & i = 0 \text{ 或 } j = 0 \\
c[i-1, j-1] + 1, & x_i = y_j \\
\max\{c[i-1, j], c[i, j-1]\}, & x_i \neq y_j
\end{cases}
$$

### 4.5 编辑距离

将字符串 $A$ 转换为字符串 $B$ 所需的最少操作数（插入、删除、替换）。

**Bellman 方程**：

$$
d[i, j] = \begin{cases}
j, & i = 0 \\
i, & j = 0 \\
d[i-1, j-1], & a_i = b_j \\
1 + \min\{d[i-1, j], d[i, j-1], d[i-1, j-1]\}, & a_i \neq b_j
\end{cases}
$$

## 五、资源分配问题

### 5.1 问题描述

将总量为 $c$ 的资源分配给 $n$ 个部门，第 $i$ 个部门分配 $x_i$ 单位资源后的收益为 $g_i(x_i)$。求使总收益最大的分配方案。

$$
\begin{aligned}
\max \quad & \sum_{i=1}^{n} g_i(x_i) \\
\text{s.t.} \quad & \sum_{i=1}^{n} x_i \leq c \\
& x_i \geq 0, \quad i = 1, \ldots, n
\end{aligned}
$$

### 5.2 动态规划建模

**阶段**：$i = 1, 2, \ldots, n$（每个部门为一个阶段）

**状态**：$s$ 为当前剩余可分配的资源量

**决策**：$x_i$ 为分配给第 $i$ 个部门的资源量

**状态转移**：$s' = s - x_i$

**Bellman 方程**：

$$
V_i(s) = \max_{0 \leq x_i \leq s} \{g_i(x_i) + V_{i+1}(s - x_i)\}
$$

**边界条件**：$V_{n+1}(s) = 0$

## 六、生产库存问题

### 6.1 问题描述

某工厂需要在 $T$ 个时期内满足各期需求 $d_t$。第 $t$ 期生产 $x_t$ 单位产品的成本为 $c_t(x_t)$，持有库存 $s_t$ 的成本为 $h_t(s_t)$。求最小总成本。

### 6.2 动态规划建模

**状态**：$s_t$ 为第 $t$ 期初的库存量

**决策**：$x_t$ 为第 $t$ 期的生产量

**状态转移**：$s_{t+1} = s_t + x_t - d_t$

**Bellman 方程**：

$$
V_t(s_t) = \min_{x_t \geq 0} \{c_t(x_t) + h_t(s_{t+1}) + V_{t+1}(s_{t+1})\}
$$

约束条件：$s_t + x_t \geq d_t$（不能缺货），$x_t \leq u_t$（产能限制）

## 七、随机动态规划

### 7.1 基本思想

当状态转移具有随机性时，问题变为随机动态规划：

$$
V_k(\mathbf{s}) = \min_{\mathbf{d}} \left\{ r(\mathbf{s}, \mathbf{d}) + \mathbb{E}[V_{k+1}(\mathbf{s}')] \right\}
$$

其中 $\mathbf{s}'$ 是随机变量，期望 $\mathbb{E}$ 是对所有可能的转移取的。

### 7.2 马尔可夫决策过程（MDP）

MDP 的 Bellman 方程：

$$
V(s) = \min_{\pi} \left\{ R(s, \pi(s)) + \gamma \sum_{s'} P(s'|s, \pi(s)) V(s') \right\}
$$

**Bellman 最优方程**：

$$
V^*(s) = \min_{a} \left\{ R(s, a) + \gamma \sum_{s'} P(s'|s, a) V^*(s') \right\}
$$

**策略迭代**：
1. 策略评估：固定策略 $\pi$，求解 $V^\pi$
2. 策略改进：根据 $V^\pi$ 更新策略 $\pi$

**值迭代**：
$$
V_{k+1}(s) = \min_{a} \left\{ R(s, a) + \gamma \sum_{s'} P(s'|s, a) V_k(s') \right\}
$$

## 八、Python 代码实现

### 8.1 0-1 背包问题

```python
def knapsack_01_dp(weights, values, W):
    """0-1背包问题 - 完整DP实现"""
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    
    # 填表
    for i in range(1, n + 1):
        for j in range(W + 1):
            dp[i][j] = dp[i-1][j]  # 不选第i个物品
            if j >= weights[i-1]:
                dp[i][j] = max(dp[i][j], dp[i-1][j-weights[i-1]] + values[i-1])
    
    # 回溯最优解
    items = []
    j = W
    for i in range(n, 0, -1):
        if dp[i][j] != dp[i-1][j]:
            items.append(i - 1)
            j -= weights[i - 1]
    
    items.reverse()
    return dp[n][W], items

# 示例
weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
W = 8
max_val, items = knapsack_01_dp(weights, values, W)
print(f"最大价值: {max_val}")
print(f"选择的物品: {items}")
```

### 8.2 最短路径（Bellman-Ford）

```python
def bellman_ford(V, edges, source, target):
    """Bellman-Ford 算法"""
    dist = {v: float('inf') for v in V}
    prev = {v: None for v in V}
    dist[source] = 0
    
    # 松弛 |V|-1 次
    for _ in range(len(V) - 1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                prev[v] = u
    
    # 回溯路径
    path = []
    current = target
    while current is not None:
        path.append(current)
        current = prev[current]
    path.reverse()
    
    return dist[target], path

# 示例
V = ['A', 'B', 'C', 'D', 'E']
edges = [
    ('A', 'B', 4), ('A', 'C', 2),
    ('B', 'C', 1), ('B', 'D', 5),
    ('C', 'D', 8), ('C', 'E', 10),
    ('D', 'E', 2), ('D', 'A', -3)  # 负权边
]

dist, path = bellman_ford(V, edges, 'A', 'E')
print(f"最短距离: {dist}")
print(f"路径: {' -> '.join(path)}")
```

### 8.3 矩阵链乘法

```python
def matrix_chain_order(p):
    """矩阵链乘法最优括号化"""
    n = len(p) - 1
    m = [[0] * n for _ in range(n)]
    s = [[0] * n for _ in range(n)]
    
    for length in range(2, n + 1):  # 链长度
        for i in range(n - length + 1):
            j = i + length - 1
            m[i][j] = float('inf')
            for k in range(i, j):
                q = m[i][k] + m[k+1][j] + p[i] * p[k+1] * p[j+1]
                if q < m[i][j]:
                    m[i][j] = q
                    s[i][j] = k
    
    def print_optimal_parens(s, i, j):
        if i == j:
            return f"A{i+1}"
        k = s[i][j]
        left = print_optimal_parens(s, i, k)
        right = print_optimal_parens(s, k+1, j)
        return f"({left} x {right})"
    
    return m[0][n-1], print_optimal_parens(s, 0, n-1)

# 示例: A1(30x35) x A2(35x15) x A3(15x5) x A4(5x10) x A5(10x20) x A6(20x25)
p = [30, 35, 15, 5, 10, 20, 25]
cost, formula = matrix_chain_order(p)
print(f"最少乘法次数: {cost}")
print(f"最优括号化: {formula}")
```

### 8.4 编辑距离

```python
def edit_distance(s1, s2):
    """编辑距离"""
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(
                    dp[i-1][j],      # 删除
                    dp[i][j-1],      # 插入
                    dp[i-1][j-1]     # 替换
                )
    
    return dp[m][n]

print(f"编辑距离: {edit_distance('kitten', 'sitting')}")  # 3
print(f"编辑距离: {edit_distance('saturday', 'sunday')}")  # 3
```

% 动态规划 - 背包问题
function [maxVal, items] = knapsack_dp(weights, values, W)
    n = length(weights);
    dp = zeros(n+1, W+1);
    
    for i = 1:n
        for j = 0:W
            dp(i+1, j+1) = dp(i, j+1);
            if j >= weights(i)
                dp(i+1, j+1) = max(dp(i+1, j+1), dp(i, j+1-weights(i)) + values(i));
            end
        end
    end
    
    maxVal = dp(n+1, W+1);
    
    % 回溯
    items = [];
    j = W;
    for i = n:-1:1
        if dp(i+1, j+1) ~= dp(i, j+1)
            items = [items, i];
            j = j - weights(i);
        end
    end
    items = fliplr(items);
end

## 十、关键要点总结

1. **最优子结构**和**重叠子问题**是动态规划的两个核心特征
2. **Bellman 方程**是动态规划的理论核心，体现了"最优性原理"
3. 背包问题、最短路径、矩阵链乘法、LCS是经典DP应用
4. 动态规划的时间复杂度通常为 $O(n \cdot W)$ 或 $O(n^2)$ 到 $O(n^3)$
5. **滚动数组**可以将空间复杂度降低
6. 随机动态规划（MDP）广泛用于强化学习
7. 状态定义是设计DP算法的关键，好的状态定义能大幅简化问题
8. DP与贪心、分治的关系：DP通过存储子问题解避免重复计算，而贪心只做局部最优选择
