# 多目标规划

> **理论基础** → 参见 [[../../优化方法/多目标优化|多目标优化理论]]

多目标规划处理同时优化多个相互冲突的目标函数的问题，通过Pareto最优解集进行权衡分析。

## 二、求解方法分类
### 2.1 方法概览

| 类别 | 方法 | 特点 |
|------|------|------|
| 先验方法 | 加权法、目标规划法 | 决策者预先提供偏好信息 |
| 后验方法 | ε-约束法、多目标进化算法 | 先求解后选择 |
| 交互方法 | STEM法、逐次多目标规划 | 逐步引导决策者 |
| 混合方法 | 参考点法 | 结合先验和后验 |

## 九、Python 代码实现
### 9.1 加权求和法

```python
import numpy as np
from scipy.optimize import minimize

def weighted_sum_multi_obj(objectives, weights, constraints, x0):
    """加权求和法求解多目标规划"""
    def combined_obj(x):
        return sum(w * f(x) for w, f in zip(weights, objectives))
    
    result = minimize(combined_obj, x0, constraints=constraints, method='SLSQP')
    return result.x, result.fun

# 示例: min f1 = x^2, f2 = (x-2)^2
objectives = [lambda x: x[0]**2, lambda x: (x[0]-2)**2]
x0 = np.array([1.0])

# 生成Pareto前沿
weights_list = np.linspace(0, 1, 20)
pareto_x = []
pareto_f = []

for w in weights_list:
    weights = [w, 1-w]
    if w == 0:
        weights = [0.001, 0.999]
    if w == 1:
        weights = [0.999, 0.001]
    
    x_opt, _ = weighted_sum_multi_obj(objectives, weights, [], x0)
    pareto_x.append(x_opt[0])
    pareto_f.append([f([x_opt[0]]) for f in objectives])

pareto_f = np.array(pareto_f)
print("Pareto 前沿点:")
for i in range(0, len(pareto_f), 5):
    print(f"  f1={pareto_f[i,0]:.4f}, f2={pareto_f[i,1]:.4f}")
```

### 9.2 ε-约束法

```python
import numpy as np
from scipy.optimize import minimize

def epsilon_constraint(obj_main, obj_others, epsilons, constraints, x0):
    """ε-约束法"""
    def combined_obj(x):
        return obj_main(x)
    
    eps_constraints = list(constraints) if constraints else []
    for j, (obj, eps) in enumerate(zip(obj_others, epsilons)):
        eps_constraints.append({'type': 'ineq', 'fun': lambda x, o=obj, e=eps: e - o(x)})
    
    result = minimize(combined_obj, x0, constraints=eps_constraints, method='SLSQP')
    return result.x, [f(result.x) for f in [obj_main] + obj_others]

# 示例
f1 = lambda x: x[0]**2
f2 = lambda x: (x[0] - 2)**2

# 扫描 ε 值
eps_values = np.linspace(0.1, 3.9, 15)
for eps in eps_values:
    x_opt, vals = epsilon_constraint(f1, [f2], [eps], [], [1.0])
    print(f"ε={eps:.1f}: f1={vals[0]:.4f}, f2={vals[1]:.4f}")
```

### 9.3 目标规划法

```python
import numpy as np
from scipy.optimize import minimize

def goal_programming(objectives, goals, priorities, x0):
    """优先级目标规划"""
    def objective(x):
        total = 0
        for i, (f, g, p) in enumerate(zip(objectives, goals, priorities)):
            val = f(x) - g
            total += p * val**2  # 简化为最小化偏差平方
        return total
    
    result = minimize(objective, x0, method='Nelder-Mead')
    return result.x

# 示例: f1=x^2, goal=1; f2=(x-2)^2, goal=0.5
f1 = lambda x: x[0]**2
f2 = lambda x: (x[0]-2)**2

x_opt = goal_programming([f1, f2], [1, 0.5], [3, 1], [1.0])
print(f"目标规划最优解: x={x_opt[0]:.4f}")
print(f"f1={f1(x_opt):.4f}, f2={f2(x_opt):.4f}")
```

### 9.4 使用 pymoo 框架

```python
# pip install pymoo
from pymoo.algorithms.moo.nsga2 import NSGA2
from pymoo.core.problem import Problem
from pymoo.optimize import minimize as pymoo_minimize
from pymoo.visualization.scatter import Scatter
import numpy as np

class MyProblem(Problem):
    def __init__(self):
        super().__init__(n_var=2, n_obj=2, xl=np.array([-5, -5]),
                         xu=np.array([5, 5]))
    
    def _evaluate(self, X, out, *args, **kwargs):
        f1 = X[:, 0]**2 + X[:, 1]**2
        f2 = (X[:, 0] - 1)**2 + (X[:, 1] - 1)**2
        out["F"] = np.column_stack([f1, f2])

problem = MyProblem()
algorithm = NSGA2(pop_size=100)
res = pymoo_minimize(problem, algorithm, ('n_gen', 200), seed=1, verbose=False)

print(f"Pareto 前沿解数量: {len(res.F)}")
print(f"前5个解:")
for i in range(min(5, len(res.F))):
    print(f"  f1={res.F[i,0]:.4f}, f2={res.F[i,1]:.4f}")
```

某工厂生产两种产品，需要同时考虑利润最大化和环境污染最小化：

$$
\begin{aligned}
\max \quad & f_1 = 40x_1 + 30x_2 \quad \text{(利润)} \\
\min \quad & f_2 = 2x_1 + x_2 \quad \text{(污染)} \\
\text{s.t.} \quad & 2x_1 + x_2 \leq 100 \\
& x_1 + 2x_2 \leq 80 \\
& x_1, x_2 \geq 0
\end{aligned}
$$

## 十二、关键要点总结
1. 多目标规划的核心概念是 **Pareto最优解** 和 **Pareto前沿**
2. **加权法**简单直观但无法找到非凸部分的Pareto解
3. **ε-约束法**能处理非凸情况，物理意义更直观
4. **目标规划**适合有明确目标值的决策场景
5. **NSGA-II** 和 **MOEA/D** 是最常用的多目标进化算法
6. **交互式方法**适合决策者能逐步提供偏好的场景
7. 实际应用中需要根据问题特点选择合适的方法
8. Pareto前沿的均匀采样和多样性保持是算法设计的关键
