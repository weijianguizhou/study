# 模拟退火

## 一、模拟退火概述

模拟退火算法（Simulated Annealing, SA）是由 Kirkpatrick 等人于1983年提出的受物理退火过程启发的随机优化算法。它能以一定概率接受较差的解，从而跳出局部最优，最终收敛到全局最优。

### 1.1 物理退火过程

物理退火是将固体加热到高温后缓慢冷却的过程：
1. **加热**：使粒子处于高能随机状态
2. **退火（冷却）**：缓慢降温，粒子逐渐排列成有序的晶体结构
3. **凝固**：达到能量最低的基态

### 1.2 Metropolis 准则

在温度 $T$ 下，系统从状态 $i$ 转移到状态 $j$ 的接受概率为：

$$
P(\text{accept}) = \begin{cases}
1, & \text{若 } E_j \leq E_i \\
e^{-(E_j - E_i)/T}, & \text{若 } E_j > E_i
\end{cases}
$$

其中 $E_i, E_j$ 为状态 $i, j$ 的能量（对应目标函数值），$T$ 为温度。

### 1.3 与优化问题的对应

| 物理退火 | 模拟退火 |
|---------|---------|
| 系统状态 | 解 |
| 能量 | 目标函数值 |
| 温度 | 控制参数 |
| 冷却 | 降温过程 |
| 基态 | 最优解 |

## 二、算法框架

### 2.1 基本流程

**算法：模拟退火**

> **输入**：初始解 $\mathbf{x}_0$，初始温度 $T_0$，降温系数 $\alpha$
> **输出**：最优解 $\mathbf{x}^*$

1. **初始化**：$\mathbf{x} = \mathbf{x}_0$，$T = T_0$，$\mathbf{x}^* = \mathbf{x}_0$
2. **内循环**（在固定温度下）：
   - 生成新解 $\mathbf{x}' = \text{neighbor}(\mathbf{x})$
   - 计算 $\Delta E = f(\mathbf{x}') - f(\mathbf{x})$
   - 若 $\Delta E < 0$（改善），接受 $\mathbf{x} = \mathbf{x}'$
   - 否则以概率 $e^{-\Delta E / T}$ 接受 $\mathbf{x} = \mathbf{x}'$
   - 若 $f(\mathbf{x}) < f(\mathbf{x}^*)$，更新 $\mathbf{x}^* = \mathbf{x}$
3. **降温**：$T = \alpha T$（$\alpha$ 通常取 $0.9 \sim 0.99$）
4. 重复步骤 2-3 直到满足终止条件
5. 输出 $\mathbf{x}^*$

### 2.2 伪代码

```
x = x0; T = T0; x_best = x0
while T > T_min:
    for i in range(L):  # L 为内循环次数
        x_new = neighbor(x)
        delta_E = f(x_new) - f(x)
        if delta_E < 0 or random() < exp(-delta_E / T):
            x = x_new
        if f(x) < f(x_best):
            x_best = x
    T = alpha * T
return x_best
```

## 三、冷却进度表

冷却进度表（Cooling Schedule）控制温度下降的过程，是模拟退火算法最重要的设计要素。

### 3.1 初始温度 $T_0$

初始温度应足够高，使得几乎所有候选解都被接受：

$$
T_0 = \frac{-\bar{\Delta E}^+}{\ln p_0}
$$

其中 $\bar{\Delta E}^+$ 为随机产生的候选解中目标函数增大的平均值，$p_0$ 为初始接受概率（通常取 $0.8 \sim 0.95$）。

### 3.2 降温函数

**（1）指数降温（Geometric Cooling）**

$$
T_{k+1} = \alpha \cdot T_k, \quad \alpha \in (0.9, 0.99)
$$

简单高效，最常用的降温方式。

**（2）对数降温**

$$
T_k = \frac{T_0}{\ln(1 + k)}
$$

理论收敛性保证，但实际收敛太慢。

**（3）线性降温**

$$
T_k = T_0 - k \cdot \Delta T
$$

降温速度较快。

**（4）自适应降温**

根据接受率调整降温速度：

$$
\alpha_k = \begin{cases}
\alpha_{\text{high}}, & \text{若接受率} > \text{目标接受率} \\
\alpha_{\text{low}}, & \text{若接受率} < \text{目标接受率}
\end{cases}
$$

### 3.3 内循环长度 $L$

在每个温度下的迭代次数。常见策略：
- **固定长度**：$L = c \cdot n$（$n$ 为问题规模，$c$ 为常数）
- **温度相关**：$L_k = L_0 \cdot \beta^k$
- **自适应**：根据接受率调整

### 3.4 终止条件

- **温度终止**：$T < T_{\min}$（如 $T_{\min} = 10^{-6}$）
- **连续无改善**：连续 $M$ 次降温后最优解不变
- **最大迭代次数**：总迭代次数达到上限

## 四、邻域结构

邻域结构决定了如何从当前解生成新解。好的邻域结构应满足：
- 从任意解出发，通过有限次邻域操作可到达任意其他解（连通性）
- 邻域操作简单快速

### 4.1 连续优化问题

**高斯扰动**：

$$
\mathbf{x}' = \mathbf{x} + \mathcal{N}(\mathbf{0}, \sigma^2 I)
$$

**均匀扰动**：

$$
x_i' = x_i + \text{Uniform}(-\delta_i, \delta_i)
$$

### 4.2 组合优化问题（以TSP为例）

**2-opt**：交换两个城市的位置。

**or-opt**：将一段连续城市移到另一个位置。

**交换变异**：随机交换两个城市。

## 五、理论基础

### 5.1 马尔可夫链

在固定温度 $T$ 下，模拟退火的搜索过程构成一个**马尔可夫链**。状态转移概率为：

$$
P_{ij}(T) = \begin{cases}
G_{ij} \cdot A_{ij}(T), & i \neq j \\
1 - \sum_{k \neq i} G_{ik} \cdot A_{ik}(T), & i = j
\end{cases}
$$

其中 $G_{ij}$ 为生成概率（从状态 $i$ 生成状态 $j$ 的概率），$A_{ij}(T)$ 为接受概率。

### 5.2 细致平衡条件

$$
\pi_i \cdot P_{ij}(T) = \pi_j \cdot P_{ji}(T)
$$

其中 $\pi_i \propto e^{-E_i / T}$ 为 Boltzmann 分布。

当温度足够低且降温足够慢时，$\pi$ 集中在全局最优状态上。

### 5.3 收敛性定理

**定理**：若满足以下条件，模拟退火算法以概率1收敛到全局最优解：

1. 温度按 $T_k = \frac{C}{\ln(1+k)}$ 降温（$C$ 足够大）
2. 每个温度下的马尔可夫链达到稳态
3. 邻域结构满足连通性

实际中通常使用更快的降温策略，牺牲理论保证换取效率。

## 六、参数选择指南

### 6.1 推荐参数范围

| 参数 | 推荐值 | 说明 |
|------|-------|------|
| $T_0$ | 使初始接受率 $\approx 0.8$ | 通过试运行确定 |
| $\alpha$ | $0.95 \sim 0.99$ | 越接近1越慢但越精确 |
| $L$ | $100n \sim 1000n$ | $n$ 为问题规模 |
| $T_{\min}$ | $10^{-4} \sim 10^{-6}$ | 太小浪费计算 |

### 6.2 参数调整经验

- 若算法过早收敛，增大 $T_0$ 或 $\alpha$
- 若算法收敛太慢，减小 $\alpha$ 或 $L$
- 降温速度应在探索和利用之间取得平衡

## 七、Python 代码实现

### 7.1 基本模拟退火

```python
import numpy as np
import math
import random

def simulated_annealing(obj_func, x0, bounds, T0=1000, alpha=0.95,
                        L=100, T_min=1e-6, max_iter=10000):
    """模拟退火算法"""
    x = np.array(x0, dtype=float)
    x_best = x.copy()
    f_best = obj_func(x)
    f_current = f_best
    T = T0
    
    history = [f_best]
    total_iter = 0
    
    while T > T_min and total_iter < max_iter:
        for _ in range(L):
            # 生成邻域解
            x_new = x.copy()
            idx = random.randint(0, len(x) - 1)
            sigma = (bounds[idx][1] - bounds[idx][0]) * 0.1
            x_new[idx] += np.random.normal(0, sigma)
            x_new[idx] = np.clip(x_new[idx], bounds[idx][0], bounds[idx][1])
            
            f_new = obj_func(x_new)
            delta_E = f_new - f_current
            
            # Metropolis 准则
            if delta_E < 0 or random.random() < math.exp(-delta_E / T):
                x = x_new
                f_current = f_new
                
                if f_current < f_best:
                    x_best = x.copy()
                    f_best = f_current
            
            total_iter += 1
        
        T *= alpha
        history.append(f_best)
    
    return x_best, f_best, history

# 示例: Rastrigin函数 (多峰函数)
def rastrigin(x):
    A = 10
    return A * len(x) + sum(xi**2 - A * math.cos(2 * math.pi * xi) for xi in x)

bounds = [(-5.12, 5.12)] * 5
x0 = [random.uniform(-5, 5) for _ in range(5)]

best_sol, best_val, hist = simulated_annealing(
    rastrigin, x0, bounds, T0=100, alpha=0.95, L=200
)
print(f"最优解: {np.round(best_sol, 4)}")
print(f"最优值: {best_val:.6f}")
```

### 7.2 TSP 模拟退火

```python
import numpy as np
import math
import random

def tsp_sa(distance_matrix, n_cities, T0=10000, alpha=0.997, L=500):
    """TSP模拟退火"""
    
    def route_distance(route):
        return sum(distance_matrix[route[i]][route[(i+1)%len(route)]]
                   for i in range(len(route)))
    
    # 初始解
    current = list(range(n_cities))
    random.shuffle(current)
    current_dist = route_distance(current)
    
    best = current[:]
    best_dist = current_dist
    T = T0
    
    while T > 1e-4:
        for _ in range(L):
            # 2-opt 邻域
            new_route = current[:]
            i, j = sorted(random.sample(range(n_cities), 2))
            new_route[i:j+1] = reversed(new_route[i:j+1])
            new_dist = route_distance(new_route)
            
            delta = new_dist - current_dist
            if delta < 0 or random.random() < math.exp(-delta / T):
                current = new_route
                current_dist = new_dist
                
                if current_dist < best_dist:
                    best = current[:]
                    best_dist = current_dist
        
        T *= alpha
    
    return best, best_dist

# 示例
np.random.seed(42)
n = 30
coords = np.random.rand(n, 2) * 100
dist = np.sqrt(((coords[:, None] - coords[None, :]) ** 2).sum(axis=2))

route, total_dist = tsp_sa(dist, n)
print(f"最优距离: {total_dist:.2f}")
print(f"路线: {route}")
```

## 八、关键要点总结

1. 模拟退火通过 **Metropolis 准则** 以概率接受差解，从而跳出局部最优
2. **冷却进度表**（$T_0$, $\alpha$, $L$, $T_{\min}$）是算法性能的关键
3. 降温越慢，找到全局最优的概率越大，但计算时间越长
4. **邻域结构**的设计影响搜索效率和质量
5. 理论上需要对数降温才能保证收敛，实践中常用指数降温
6. 模拟退火适用于**大规模组合优化**和**多峰函数优化**
7. 与遗传算法相比，模拟退火是**单点搜索**，内存需求小
8. 多次运行取最优结果可以提高算法的鲁棒性
