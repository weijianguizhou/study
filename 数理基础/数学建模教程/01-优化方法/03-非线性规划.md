# 非线性规划

> **理论基础** → 参见 [[../../优化方法/非线性规划|非线性规划理论]]

非线性规划处理目标函数或约束条件包含非线性项的问题，是工程技术、经济管理中常见的优化工具。

## 六、约束优化的积极集策略
### 6.1 基本思想

在迭代过程中，确定哪些不等式约束是**活跃的**（取等号），然后只考虑活跃约束，将问题转化为等式约束问题求解。

### 6.2 积极集策略流程

1. 给定初始可行点 $\mathbf{x}_0$，确定初始活跃集 $W_0$
2. 在活跃约束下求解等式约束问题，得到搜索方向
3. 线搜索确定步长
4. 若步长受非活跃约束限制，将其加入活跃集
5. 若某个活跃约束的拉格朗日乘子为负，将其从活跃集中删除
6. 重复直到所有乘子非负且搜索方向为零

## 七、Python 代码实现
### 7.1 梯度下降法

```python
import numpy as np

def gradient_descent(f, grad_f, x0, alpha=0.01, tol=1e-6, max_iter=10000):
    """梯度下降法"""
    x = x0.copy()
    history = [x.copy()]
    
    for k in range(max_iter):
        g = grad_f(x)
        if np.linalg.norm(g) < tol:
            break
        x = x - alpha * g
        history.append(x.copy())
    
    return x, f(x), history

# 示例: min f(x,y) = x^2 + 4*y^2
f = lambda x: x[0]**2 + 4*x[1]**2
grad_f = lambda x: np.array([2*x[0], 8*x[1]])

x0 = np.array([3.0, 2.0])
x_opt, f_opt, hist = gradient_descent(f, grad_f, x0, alpha=0.1)
print(f"最优解: {x_opt}")
print(f"最优值: {f_opt}")
```

### 7.2 使用 scipy.optimize.minimize

```python
from scipy.optimize import minimize
import numpy as np

# 无约束优化
def objective(x):
    return x[0]**2 + x[1]**2 + x[0]*x[1] - 4*x[0] - 5*x[1]

def objective_grad(x):
    return np.array([2*x[0] + x[1] - 4, 2*x[1] + x[0] - 5])

x0 = np.array([0.0, 0.0])
result = minimize(objective, x0, jac=objective_grad, method='BFGS')
print(f"无约束最优解: {result.x}, 最优值: {result.fun}")

# 有约束优化
def constraint1(x):  # x + y <= 4
    return 4 - x[0] - x[1]

def constraint2(x):  # x >= 0, y >= 0 (通过 bounds 设置)
    return x[0]

cons = {'type': 'ineq', 'fun': constraint1}
bounds = [(0, None), (0, None)]

result_con = minimize(objective, x0, jac=objective_grad, method='SLSQP',
                      bounds=bounds, constraints=cons)
print(f"约束最优解: {result_con.x}, 最优值: {result_con.fun}")
```

### 7.3 KKT 条件验证

```python
import numpy as np
from scipy.optimize import minimize

# min f(x) = x1^2 + x2^2
# s.t. x1 + x2 >= 1 (即 -(x1+x2) + 1 <= 0)

def f(x):
    return x[0]**2 + x[1]**2

def g(x):  # g(x) <= 0 形式
    return -(x[0] + x[1]) + 1

from scipy.optimize import minimize

cons = {'type': 'ineq', 'fun': lambda x: x[0] + x[1] - 1}
result = minimize(f, [0.5, 0.5], method='SLSQP', constraints=cons)
x_star = result.x

# KKT 验证
# 平稳性: grad_f + lambda * grad_g = 0
grad_f = np.array([2*x_star[0], 2*x_star[1]])
grad_g = np.array([-1, -1])

# 数值估计 lambda
lam = -grad_f[0] / grad_g[0]  # 应该等于 0.5
print(f"最优解: {x_star}")
print(f"拉格朗日乘子: lambda = {lam}")
print(f"互补松弛: lambda * g(x*) = {lam * g(x_star):.6f}")
```

## 九、实际应用案例
### 9.1 投资组合优化（Markowitz模型）

$$
\begin{aligned}
\min \quad & \mathbf{w}^T \Sigma \mathbf{w} \\
\text{s.t.} \quad & \boldsymbol{\mu}^T \mathbf{w} \geq r_{\min} \\
& \sum_{i=1}^{n} w_i = 1 \\
& w_i \geq 0, \quad i = 1, \ldots, n
\end{aligned}
$$

其中 $\mathbf{w}$ 为投资权重向量，$\Sigma$ 为协方差矩阵，$\boldsymbol{\mu}$ 为期望收益率向量，$r_{\min}$ 为最低期望收益率。

### 9.2 非线性最小二乘

$$
\min \quad \sum_{i=1}^{m} r_i(\mathbf{x})^2
$$

其中 $r_i(\mathbf{x})$ 为残差函数。可用 Gauss-Newton 法或 Levenberg-Marquardt 法求解。

## 十、关键要点总结
1. **KKT条件**是约束优化的核心理论，四个条件缺一不可
2. **梯度下降法**简单稳健但收敛慢；**牛顿法**收敛快但计算量大
3. **拟牛顿法（BFGS）** 兼顾效率和速度，是实践中最常用的方法
4. **罚函数法**将约束问题转化为无约束问题求解
5. **SQP方法**是求解约束非线性规划最有效的方法之一
6. 对于**凸规划**，局部最优解即全局最优解
7. 约束规范（如LICQ）是KKT条件成立的前提
8. 增广拉格朗日法结合了拉格朗日函数和罚函数的优点，收敛性更好
