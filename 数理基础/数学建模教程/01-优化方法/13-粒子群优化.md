# 粒子群优化

## 一、粒子群优化概述

粒子群优化（Particle Swarm Optimization, PSO）是由 Kennedy 和 Eberhart 于1995年提出的一种群体智能优化算法。其灵感来源于鸟群觅食行为：鸟群在搜索食物时，每个个体根据自身经验和群体经验调整飞行方向和速度。

### 1.1 基本思想

在 PSO 中，每个粒子代表一个候选解，在搜索空间中飞行。粒子通过两个信息更新自己的速度和位置：

1. **个体最优（Personal Best, pBest）**：该粒子历史上找到的最好位置
2. **全局最优（Global Best, gBest）**：整个种群历史上找到的最好位置

### 1.2 粒子的属性

每个粒子 $i$ 具有以下属性：
- **位置** $\mathbf{x}_i = (x_{i1}, x_{i2}, \ldots, x_{in})$：当前候选解
- **速度** $\mathbf{v}_i = (v_{i1}, v_{i2}, \ldots, v_{in})$：搜索方向和步长
- **个体最优** $\mathbf{p}_i$：粒子 $i$ 历史最优位置
- **适应度** $f(\mathbf{x}_i)$：当前位置的目标函数值

---

## 二、速度与位置更新

### 2.1 速度更新公式

$$
v_{id}^{(t+1)} = \underbrace{w \cdot v_{id}^{(t)}}_{\text{惯性项}} + \underbrace{c_1 \cdot r_1 \cdot (p_{id} - x_{id}^{(t)})}_{\text{认知项}} + \underbrace{c_2 \cdot r_2 \cdot (g_d - x_{id}^{(t)})}_{\text{社会项}}
$$

其中：
- $w$ 为惯性权重
- $c_1$ 为个体学习因子（认知参数）
- $c_2$ 为社会学习因子（社会参数）
- $r_1, r_2 \sim U(0, 1)$ 为随机数
- $p_{id}$ 为粒子 $i$ 的个体最优第 $d$ 维分量
- $g_d$ 为全局最优第 $d$ 维分量

### 2.2 位置更新公式

$$
x_{id}^{(t+1)} = x_{id}^{(t)} + v_{id}^{(t+1)}
$$

### 2.3 三项的含义

**惯性项** $w \cdot v_{id}^{(t)}$：
- 保持粒子原来的运动方向
- $w$ 越大，全局搜索能力越强
- $w$ 越小，局部搜索能力越强

**认知项** $c_1 \cdot r_1 \cdot (p_{id} - x_{id}^{(t)})$：
- 引导粒子向个体最优方向移动
- 体现粒子的"记忆"和"自我认知"

**社会项** $c_2 \cdot r_2 \cdot (g_d - x_{id}^{(t)})$：
- 引导粒子向全局最优方向移动
- 体现群体的信息共享

---

## 三、参数设置

### 3.1 惯性权重 $w$

$w$ 控制粒子对前一速度的继承程度：

- $w$ 大（如 $w > 0.9$）：全局搜索能力强，探索阶段
- $w$ 小（如 $w < 0.4$）：局部搜索能力强，开发阶段

**线性递减惯性权重（LDIW）**：

$$
w = w_{\max} - \frac{w_{\max} - w_{\min}}{T_{\max}} \cdot t
$$

通常取 $w_{\max} = 0.9$，$w_{\min} = 0.4$。

### 3.2 学习因子 $c_1, c_2$

- $c_1$：个体学习因子，控制粒子对自身经验的信任程度
- $c_2$：社会学习因子，控制粒子对群体经验的信任程度

**常见设置**：
- $c_1 = c_2 = 2.0$（经典值）
- $c_1 = 2.05$，$c_2 = 2.05$（Clerc 收缩因子）
- 自适应调整：$c_1$ 从大到小，$c_2$ 从小到大

### 3.3 种群大小 $N$

- $N = 20 \sim 50$：一般问题
- $N = 50 \sim 200$：复杂问题
- 过大增加计算量，过小搜索不充分

### 3.4 速度限制

$$
v_{id} \in [-v_{\max}, v_{\max}]
$$

通常 $v_{\max}$ 设为搜索空间范围的 $10\% \sim 20\%$。速度限制防止粒子飞出搜索空间。

## 四、PSO 变体

### 4.1 标准 PSO（SPSO）

使用惯性权重 $w$ 和线性递减策略：

$$
\mathbf{v}_i^{(t+1)} = w \mathbf{v}_i^{(t)} + c_1 r_1 (\mathbf{p}_i - \mathbf{x}_i^{(t)}) + c_2 r_2 (\mathbf{g} - \mathbf{x}_i^{(t)})
$$

### 4.2 收缩因子 PSO（Clerc）

$$
\mathbf{v}_i^{(t+1)} = \chi \left[ \mathbf{v}_i^{(t)} + c_1 r_1 (\mathbf{p}_i - \mathbf{x}_i^{(t)}) + c_2 r_2 (\mathbf{g} - \mathbf{x}_i^{(t)}) \right]
$$

其中 $\chi = \frac{2}{|2 - \phi - \sqrt{\phi^2 - 4\phi}|}$，$\phi = c_1 + c_2 > 4$。

取 $c_1 = c_2 = 2.05$，则 $\chi \approx 0.729$。

### 4.3 局部 PSO（Lbest PSO）

每个粒子只与邻域内的粒子通信，而非全局限制：

$$
\mathbf{v}_i^{(t+1)} = w \mathbf{v}_i^{(t)} + c_1 r_1 (\mathbf{p}_i - \mathbf{x}_i^{(t)}) + c_2 r_2 (\mathbf{l}_i - \mathbf{x}_i^{(t)})
$$

其中 $\mathbf{l}_i$ 为粒子 $i$ 邻域内的最优位置。

**邻域拓扑**：
- 环形拓扑：每个粒子与相邻粒子连接
- 星形拓扑：等价于全局 PSO
- 随机动态拓扑：定期重新随机连接

### 4.4 自适应 PSO

根据搜索状态动态调整参数：

$$
w(t) = w_{\max} \cdot e^{-\alpha \cdot t / T_{\max}}
$$

或根据种群多样性调整：

$$
w = w_0 + (w_1 - w_0) \cdot \frac{\sigma_f}{\sigma_{f,\max}}
$$

### 4.5 混合 PSO

- PSO + 遗传算法：用遗传算子增强搜索
- PSO + 模拟退火：用退火机制避免早熟
- PSO + 局部搜索：在全局搜索后进行精细搜索

## 五、收敛性分析

### 5.1 粒子轨迹的稳定性

单个粒子在没有外部干扰下的运动方程：

$$
\mathbf{v}^{(t+1)} = w\mathbf{v}^{(t)} + c_1 r_1 (\mathbf{p} - \mathbf{x}^{(t)}) + c_2 r_2 (\mathbf{g} - \mathbf{x}^{(t)})
$$

$$
\mathbf{x}^{(t+1)} = \mathbf{x}^{(t)} + \mathbf{v}^{(t+1)}
$$

### 5.2 收缩因子的推导

为保证收敛，特征方程的根必须在单位圆内。Clerc 推导出：

$$
\chi = \frac{2}{|2 - \phi - \sqrt{\phi^2 - 4\phi}|}
$$

当 $\phi = c_1 + c_2 > 4$ 时，系统收敛。

### 5.3 探索与利用的平衡

- **探索（Exploration）**：搜索解空间的新区域
- **利用（Exploitation）**：在已知好区域附近精细搜索
- $w$ 大、$c_2$ 小有利于探索
- $w$ 小、$c_2$ 大有利于利用

## 六、Python 代码实现

### 6.1 标准 PSO

```python
import numpy as np

class PSO:
    def __init__(self, obj_func, n_var, bounds, n_particles=30,
                 w=0.7, c1=1.5, c2=1.5, max_iter=200):
        self.obj_func = obj_func
        self.n_var = n_var
        self.bounds = np.array(bounds)
        self.n_particles = n_particles
        self.w = w
        self.c1 = c1
        self.c2 = c2
        self.max_iter = max_iter
        
        lows = self.bounds[:, 0]
        highs = self.bounds[:, 1]
        
        # 初始化粒子
        self.positions = np.random.uniform(lows, highs, (n_particles, n_var))
        self.velocities = np.random.uniform(
            -(highs - lows) * 0.1, (highs - lows) * 0.1,
            (n_particles, n_var)
        )
        
        # 个体最优
        self.p_best = self.positions.copy()
        self.p_best_fit = np.full(n_particles, np.inf)
        
        # 全局最优
        self.g_best = None
        self.g_best_fit = np.inf
        
        self.history = []
    
    def optimize(self):
        for t in range(self.max_iter):
            # 评估适应度
            for i in range(self.n_particles):
                fit = self.obj_func(self.positions[i])
                
                if fit < self.p_best_fit[i]:
                    self.p_best_fit[i] = fit
                    self.p_best[i] = self.positions[i].copy()
                
                if fit < self.g_best_fit:
                    self.g_best_fit = fit
                    self.g_best = self.positions[i].copy()
            
            self.history.append(self.g_best_fit)
            
            # 更新速度和位置
            r1 = np.random.random((self.n_particles, self.n_var))
            r2 = np.random.random((self.n_particles, self.n_var))
            
            self.velocities = (
                self.w * self.velocities +
                self.c1 * r1 * (self.p_best - self.positions) +
                self.c2 * r2 * (self.g_best - self.positions)
            )
            
            # 速度限制
            v_max = (self.bounds[:, 1] - self.bounds[:, 0]) * 0.2
            self.velocities = np.clip(self.velocities, -v_max, v_max)
            
            # 更新位置
            self.positions += self.velocities
            
            # 位置限制
            lows = self.bounds[:, 0]
            highs = self.bounds[:, 1]
            self.positions = np.clip(self.positions, lows, highs)
            
            # 边界反弹
            for d in range(self.n_var):
                hit_low = self.positions[:, d] <= lows[d]
                hit_high = self.positions[:, d] >= highs[d]
                self.velocities[hit_low, d] *= -0.5
                self.velocities[hit_high, d] *= -0.5
        
        return self.g_best, self.g_best_fit

# 示例: Sphere函数
sphere = lambda x: np.sum(x**2)

pso = PSO(sphere, n_var=5, bounds=[(-10, 10)] * 5, n_particles=30, max_iter=200)
best_sol, best_val = pso.optimize()
print(f"最优解: {best_sol}")
print(f"最优值: {best_val:.8f}")
```

### 6.2 带线性递减权重的 PSO

```python
import numpy as np

def pso_ldiw(obj_func, n_var, bounds, n_particles=30, max_iter=200,
             w_max=0.9, w_min=0.4, c1=2.0, c2=2.0):
    """线性递减惯性权重PSO"""
    lows = np.array(bounds)[:, 0]
    highs = np.array(bounds)[:, 1]
    
    pos = np.random.uniform(lows, highs, (n_particles, n_var))
    vel = np.random.uniform(-(highs-lows)*0.1, (highs-lows)*0.1, (n_particles, n_var))
    
    p_best = pos.copy()
    p_best_fit = np.array([obj_func(pos[i]) for i in range(n_particles)])
    
    g_best_idx = np.argmin(p_best_fit)
    g_best = p_best[g_best_idx].copy()
    g_best_fit = p_best_fit[g_best_idx]
    
    for t in range(max_iter):
        w = w_max - (w_max - w_min) * t / max_iter
        
        for i in range(n_particles):
            fit = obj_func(pos[i])
            if fit < p_best_fit[i]:
                p_best_fit[i] = fit
                p_best[i] = pos[i].copy()
            
            if fit < g_best_fit:
                g_best_fit = fit
                g_best = pos[i].copy()
        
        r1 = np.random.random((n_particles, n_var))
        r2 = np.random.random((n_particles, n_var))
        
        vel = w * vel + c1 * r1 * (p_best - pos) + c2 * r2 * (g_best - pos)
        
        v_max = (highs - lows) * 0.2
        vel = np.clip(vel, -v_max, v_max)
        
        pos = pos + vel
        pos = np.clip(pos, lows, highs)
    
    return g_best, g_best_fit

best, val = pso_ldiw(lambda x: np.sum(x**2), 5, [(-10, 10)] * 5)
print(f"LDIW-PSO最优值: {val:.8f}")
```

### 6.3 多目标 PSO

```python
import numpy as np

def mopso(obj_funcs, n_var, bounds, n_particles=50, max_iter=200):
    """多目标PSO (简化版)"""
    lows = np.array(bounds)[:, 0]
    highs = np.array(bounds)[:, 1]
    n_obj = len(obj_funcs)
    
    pos = np.random.uniform(lows, highs, (n_particles, n_var))
    vel = np.zeros((n_particles, n_var))
    
    # Pareto档案
    archive = []
    archive_fits = []
    
    for t in range(max_iter):
        fits = np.array([[f(pos[i]) for f in obj_funcs] for i in range(n_particles)])
        
        # 更新Pareto档案
        for i in range(n_particles):
            dominated = False
            to_remove = []
            for j, af in enumerate(archive_fits):
                if np.all(af <= fits[i]) and np.any(af < fits[i]):
                    dominated = True
                    break
                if np.all(fits[i] <= af) and np.any(fits[i] < af):
                    to_remove.append(j)
            
            if not dominated:
                for j in sorted(to_remove, reverse=True):
                    archive.pop(j)
                    archive_fits.pop(j)
                archive.append(pos[i].copy())
                archive_fits.append(fits[i].copy())
        
        # 从档案中选择引导者
        if len(archive) > 0:
            for i in range(n_particles):
                leader_idx = np.random.randint(len(archive))
                leader = archive[leader_idx]
                
                r1 = np.random.random(n_var)
                r2 = np.random.random(n_var)
                
                vel[i] = 0.5 * vel[i] + r1 * (pos[i] - leader) + r2 * np.random.randn(n_var) * 0.1
                pos[i] = pos[i] + vel[i]
                pos[i] = np.clip(pos[i], lows, highs)
    
    return archive, archive_fits

# 示例: ZDT1
def zdt1_f1(x): return x[0]
def zdt1_f2(x):
    g = 1 + 9 * np.mean(x[1:]) / (len(x) - 1)
    return g * (1 - np.sqrt(x[0] / g))

archive, fits = mopso([zdt1_f1, zdt1_f2], 5, [(0, 1)] * 5, n_particles=30, max_iter=100)
print(f"Pareto前沿解数量: {len(archive)}")
```

## 七、关键要点总结

1. PSO 通过**速度-位置更新**模拟粒子在解空间中的飞行搜索
2. 三个组成部分：**惯性项**（探索）、**认知项**（个体经验）、**社会项**（群体经验）
3. **惯性权重 $w$** 控制探索与利用的平衡，线性递减策略是常用改进
4. **学习因子 $c_1, c_2$** 分别控制个体和群体经验的影响
5. 收缩因子法提供了理论收敛保证
6. 局部 PSO（Lbest）比全局 PSO 更不容易早熟但收敛较慢
7. PSO 适用于连续优化问题，离散版本可用于组合优化
8. 与其他群智能算法相比，PSO 概念简单、参数少、实现容易
