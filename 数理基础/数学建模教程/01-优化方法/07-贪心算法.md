# 贪心算法

## 一、贪心算法概述

贪心算法（Greedy Algorithm）在每一步都做出当前看起来最优的选择，即局部最优选择，希望由此达到全局最优。贪心算法不需要回溯，因此效率通常较高。

### 1.1 基本思想

贪心算法适用于具有**贪心选择性质**和**最优子结构**的问题：

**（1）贪心选择性质（Greedy Choice Property）**

通过做出局部最优选择，能够达到全局最优。即存在一个最优解包含贪心选择。

**（2）最优子结构（Optimal Substructure）**

原问题的最优解包含子问题的最优解。

### 1.2 贪心算法与动态规划的区别

| 特性 | 贪心算法 | 动态规划 |
|------|---------|---------|
| 选择方式 | 每步选择局部最优 | 考虑所有子问题组合 |
| 回溯 | 不回溯 | 隐含回溯 |
| 适用范围 | 较窄（需贪心选择性质） | 较广 |
| 效率 | 通常更高 | 通常较低 |
| 正确性 | 需严格证明 | 通过最优子结构保证 |

### 1.3 贪心算法的一般框架

```
贪心算法框架:
1. 将问题分解为若干子问题
2. 对每个子问题，做出当前最优的贪心选择
3. 将所有子问题的解合并为原问题的解
4. 证明贪心选择的正确性
```

## 二、活动选择问题

### 2.1 问题描述

有 $n$ 个活动，每个活动 $i$ 有开始时间 $s_i$ 和结束时间 $f_i$。同一时段只能进行一个活动。选择尽可能多的互不冲突的活动。

### 2.2 贪心策略

**策略**：按结束时间 $f_i$ 升序排序，每次选择结束最早且与已选活动不冲突的活动。

### 2.3 正确性证明

**定理**：按结束时间升序的贪心选择是最优的。

**证明**：设贪心选择的活动集合为 $G = \{a_1, a_2, \ldots, a_k\}$，其中 $f_{a_1} \leq f_{a_2} \leq \cdots \leq f_{a_k}$。

设最优解为 $O = \{b_1, b_2, \ldots, b_m\}$，其中 $m \geq k$。

由于 $f_{a_1} \leq f_{b_1}$（贪心选最早结束），将 $b_1$ 替换为 $a_1$ 不会使解变差。归纳可证 $k = m$。

### 2.4 算法步骤

1. 将所有活动按结束时间升序排序
2. 选择第一个活动（结束最早）
3. 对后续每个活动，若其开始时间不早于上一个已选活动的结束时间，则选中
4. 重复直到所有活动被检查

### 2.5 代码实现

```python
def activity_selection(activities):
    """
    活动选择问题
    activities: [(start, end), ...]
    返回: 选中的活动索引列表
    """
    n = len(activities)
    # 按结束时间排序
    sorted_acts = sorted(range(n), key=lambda i: activities[i][1])
    
    selected = [sorted_acts[0]]
    last_end = activities[sorted_acts[0]][1]
    
    for i in range(1, n):
        idx = sorted_acts[i]
        if activities[idx][0] >= last_end:
            selected.append(idx)
            last_end = activities[idx][1]
    
    return selected

# 示例
activities = [(1, 4), (3, 5), (0, 6), (5, 7), (3, 9), (5, 9), (6, 10),
              (8, 11), (8, 12), (2, 14), (12, 16)]
selected = activity_selection(activities)
print(f"选中活动数: {len(selected)}")
for i in selected:
    print(f"  活动 {i}: ({activities[i][0]}, {activities[i][1]})")
```

## 三、分数背包问题

### 3.1 问题描述

有 $n$ 个物品，第 $i$ 个物品重量为 $w_i$，价值为 $v_i$。背包容量为 $W$。每个物品可以取分数部分。求最大价值。

### 3.2 贪心策略

**策略**：按价值密度 $v_i / w_i$ 降序排序，依次装入。若当前物品不能完全装入，则装入剩余容量对应的分数。

### 3.3 正确性

**定理**：按价值密度降序的贪心策略得到最优解。

**证明思路**：若最优解中存在两个物品 $i, j$，使得 $v_i/w_i < v_j/w_j$ 但 $i$ 满载而 $j$ 未满载，则交换它们的分配比例可以使总价值增加，矛盾。

### 3.4 代码实现

```python
def fractional_knapsack(weights, values, W):
    """分数背包问题"""
    n = len(weights)
    # 按价值密度降序排序
    items = sorted(range(n), key=lambda i: values[i]/weights[i], reverse=True)
    
    total_value = 0
    remaining = W
    taken = []
    
    for i in items:
        if remaining <= 0:
            break
        if weights[i] <= remaining:
            total_value += values[i]
            remaining -= weights[i]
            taken.append((i, 1.0))
        else:
            fraction = remaining / weights[i]
            total_value += values[i] * fraction
            taken.append((i, fraction))
            remaining = 0
    
    return total_value, taken

# 示例
weights = [10, 20, 30]
values = [60, 100, 120]
W = 50
max_val, taken = fractional_knapsack(weights, values, W)
print(f"最大价值: {max_val}")
for i, frac in taken:
    print(f"  物品{i}: 取 {frac:.1%}")
```

## 四、Huffman 编码

### 4.1 问题描述

给定 $n$ 个字符及其出现频率，设计前缀编码使得总编码长度最短。

### 4.2 Huffman 算法

1. 为每个字符创建一个叶节点，权重为频率
2. 将所有节点放入优先队列（最小堆）
3. 重复以下步骤直到只剩一个节点：
   - 从队列中取出权重最小的两个节点
   - 创建一个新节点作为它们的父节点，权重为两者之和
   - 将新节点加入队列
4. 最后剩下的节点为根节点

### 4.3 正确性证明

**引理**：在最优前缀编码树中，频率最低的两个字符是兄弟节点。

**证明**：设 $a, b$ 为频率最低的两个字符。若在最优树 $T$ 中 $a, b$ 不是兄弟，将它们与当前是兄弟的两个叶节点交换，编码长度不会增加。

### 4.4 编码长度

$$
L = \sum_{i=1}^{n} f_i \cdot d_i
$$

其中 $f_i$ 为字符 $i$ 的频率，$d_i$ 为其编码长度（树中的深度）。

### 4.5 代码实现

```python
import heapq
from collections import defaultdict

class HuffmanNode:
    def __init__(self, char=None, freq=0, left=None, right=None):
        self.char = char
        self.freq = freq
        self.left = left
        self.right = right
    
    def __lt__(self, other):
        return self.freq < other.freq

def huffman_encoding(text):
    """Huffman编码"""
    # 统计频率
    freq = defaultdict(int)
    for c in text:
        freq[c] += 1
    
    # 构建优先队列
    heap = [HuffmanNode(c, f) for c, f in freq.items()]
    heapq.heapify(heap)
    
    # 构建Huffman树
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        parent = HuffmanNode(freq=left.freq + right.freq, left=left, right=right)
        heapq.heappush(heap, parent)
    
    root = heap[0] if heap else None
    
    # 生成编码表
    codes = {}
    def build_codes(node, code=""):
        if node is None:
            return
        if node.char is not None:
            codes[node.char] = code if code else "0"
            return
        build_codes(node.left, code + "0")
        build_codes(node.right, code + "1")
    
    build_codes(root)
    
    # 编码
    encoded = "".join(codes[c] for c in text)
    
    return codes, encoded

# 示例
text = "abracadabra"
codes, encoded = huffman_encoding(text)
print("编码表:")
for c, code in sorted(codes.items()):
    print(f"  '{c}': {code}")
print(f"原始长度: {len(text)*8} bits")
print(f"编码后长度: {len(encoded)} bits")
```

## 五、活动选择问题的推广

### 5.1 带权重的活动选择

每个活动 $i$ 有权重 $w_i$，求最大权重的互不冲突活动集合。此时贪心不再适用，需要使用动态规划或区间调度的加权版本。

### 5.2 区间着色问题

用最少的颜色对区间着色，使得重叠区间颜色不同。贪心策略：按开始时间排序，每次选择可用的最小颜色编号。

### 5.3 任务调度问题（Interval Partitioning）

给定 $n$ 个区间（任务），确定最少需要多少个机器（资源）来同时处理所有任务。贪心策略：按开始时间排序，当所有机器都被占用时增加一台新机器。

## 六、贪心算法在图论中的应用

### 6.1 Kruskal 最小生成树算法

**贪心策略**：将所有边按权重升序排序，依次加入不形成环的边。

**算法步骤**：
1. 将所有边按权重升序排序
2. 初始化并查集（Union-Find）
3. 依次检查每条边 $(u, v)$：
   - 若 $u$ 和 $v$ 不在同一连通分量，加入该边
   - 否则跳过（会形成环）
4. 直到加入 $n-1$ 条边

**时间复杂度**：$O(E \log E)$

### 6.2 Prim 最小生成树算法

**贪心策略**：从一个顶点开始，每次加入连接已选顶点和未选顶点的最小权重边。

**算法步骤**：
1. 选择任意起始顶点 $s$，加入已选集合 $S$
2. 维护一个优先队列，存储所有从 $S$ 到 $V \setminus S$ 的边
3. 重复 $n-1$ 次：
   - 从优先队列中取出最小边 $(u, v)$
   - 将 $v$ 加入 $S$，将边 $(u, v)$ 加入最小生成树
   - 更新优先队列
4. 优先队列为空时终止

**时间复杂度**：$O(E \log V)$（使用二叉堆）

### 6.3 Dijkstra 最短路径算法

**贪心策略**：维护从源点到各顶点的最短距离估计，每次选择距离最小的未确定顶点。

**算法步骤**：
1. 初始化距离 $d[s] = 0$，$d[v] = \infty$（$v \neq s$）
2. 将所有顶点放入优先队列
3. 重复 $n$ 次：
   - 从优先队列中取出距离最小的顶点 $u$
   - 对 $u$ 的每个邻居 $v$：
     - 若 $d[u] + w(u, v) < d[v]$，更新 $d[v] = d[u] + w(u, v)$

**时间复杂度**：$O((V + E) \log V)$（使用二叉堆）

## 七、区间调度与贪心证明技巧

### 7.1 交换论证（Exchange Argument）

证明贪心正确的标准方法：

1. 假设存在一个最优解 $O$ 不包含贪心选择
2. 将 $O$ 中的一个元素与贪心选择做交换
3. 证明交换后解不会变差
4. 因此存在一个包含贪心选择的最优解

### 7.2 贪心保留性质（Greedy Stays Ahead）

证明贪心在每一步都不比最优解差：

1. 定义贪心选择与最优解的比较度量
2. 归纳证明：在第 $k$ 步后，贪心不比最优解差
3. 最终得出贪心等于最优

## 八、Python 代码实现

### 8.1 区间着色问题

```python
def interval_coloring(intervals):
    """区间着色问题 - 贪心算法"""
    n = len(intervals)
    sorted_intervals = sorted(range(n), key=lambda i: intervals[i][0])
    
    colors = [0] * n
    available_times = []  # (结束时间, 颜色)
    
    for idx in sorted_intervals:
        start, end = intervals[idx]
        # 回收已完成的颜色
        new_available = []
        for et, color in available_times:
            if et <= start:
                continue
            new_available.append((et, color))
        available_times = new_available
        
        # 分配最小可用颜色
        used_colors = {color for _, color in available_times}
        color = 0
        while color in used_colors:
            color += 1
        
        colors[idx] = color
        available_times.append((end, color))
    
    return colors

intervals = [(0, 3), (1, 4), (2, 5), (3, 6), (4, 7), (5, 8)]
colors = interval_coloring(intervals)
print(f"最少颜色数: {max(colors) + 1}")
for i, (s, e) in enumerate(intervals):
    print(f"  区间 ({s},{e}): 颜色 {colors[i]}")
```

### 8.2 Kruskal 最小生成树

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True

def kruskal(n, edges):
    """Kruskal最小生成树"""
    # edges: [(weight, u, v), ...]
    edges_sorted = sorted(edges)
    uf = UnionFind(n)
    mst = []
    total_weight = 0
    
    for w, u, v in edges_sorted:
        if uf.union(u, v):
            mst.append((w, u, v))
            total_weight += w
            if len(mst) == n - 1:
                break
    
    return mst, total_weight

edges = [(4, 0, 1), (2, 0, 2), (1, 1, 2), (5, 1, 3), (3, 2, 3)]
mst, total = kruskal(4, edges)
print(f"最小生成树权重: {total}")
for w, u, v in mst:
    print(f"  边 ({u},{v}): 权重 {w}")
```

### 8.3 Dijkstra 最短路径

```python
import heapq

def dijkstra(graph, source, n):
    """Dijkstra最短路径算法"""
    dist = [float('inf')] * n
    prev = [-1] * n
    dist[source] = 0
    
    pq = [(0, source)]
    
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                prev[v] = u
                heapq.heappush(pq, (dist[v], v))
    
    return dist, prev

# 邻接表表示
graph = [
    [(1, 4), (2, 1)],   # 0
    [(3, 1)],            # 1
    [(1, 2), (3, 5)],   # 2
    []                   # 3
]

dist, prev = dijkstra(graph, 0, 4)
print("最短距离:")
for i, d in enumerate(dist):
    print(f"  从0到{i}: {d}")
```

## 九、关键要点总结

1. **贪心选择性质**和**最优子结构**是贪心算法正确的两个必要条件
2. 活动选择问题的贪心策略是按结束时间排序
3. 分数背包的贪心策略是按价值密度排序（0-1背包不适用贪心）
4. **Huffman编码**是贪心算法的经典应用，产生最优前缀编码
5. **Kruskal**和**Prim**算法都是最小生成树的贪心算法
6. **Dijkstra**算法是单源最短路径的贪心算法（不能处理负权边）
7. **交换论证**和**贪心保留性质**是证明贪心正确的两大工具
8. 贪心算法效率高但适用范围有限，需要严格证明正确性
