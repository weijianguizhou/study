# 综合评价方法比较与选择

## 一、概述

综合评价是对多属性体系结构描述的事物做出全局性、整体性的评价。不同的评价方法有不同的理论基础、适用条件和优缺点。本文系统比较常用综合评价方法的特点，帮助在实际问题中选择合适的方法。

## 二、常用评价方法一览

### 2.1 方法分类

| 类别 | 方法 | 特点 |
|:--|:--|:--|
| **主观赋权** | 层次分析法（AHP） | 专家判断，两两比较 |
| **客观赋权** | 熵权法、CRITIC 法 | 数据驱动，不依赖专家 |
| **距离评价** | TOPSIS 法 | 正负理想解距离 |
| **模糊评价** | 模糊综合评价 | 处理模糊性和不确定性 |
| **效率评价** | 数据包络分析（DEA） | 多输入多输出效率 |
| **非参数评价** | 秩和比法（RSR） | 基于秩次，分布无关 |
| **关联分析** | 灰色关联分析 | 序列几何相似度 |
| **降维评价** | 因子分析、PCA | 消除指标相关性 |

### 2.2 核心思想对比

| 方法 | 核心思想 | 评价方式 |
|:--|:--|:--|
| AHP | 分层比较，综合判断 | 主观确定权重后加权 |
| TOPSIS | 最接近正理想解 | 计算与理想解的距离 |
| 模糊综合评价 | 隶属度映射 | 模糊变换 + 最大隶属度 |
| DEA | 前沿面效率分析 | 线性规划求效率值 |
| 熵权法 | 信息量决定权重 | 信息熵确定权重 |
| RSR | 秩次综合 | 秩次平均 + 分档 |
| 灰色关联 | 曲线几何相似 | 关联系数 + 关联度 |
| 因子分析 | 公因子解释方差 | 降维 + 因子得分 |
| PCA | 方差最大化降维 | 特征值分解 + 综合得分 |

## 三、详细对比分析

### 3.1 权重确定方式

| 方法 | 权重来源 | 客观性 | 主观性 |
|:--|:--|:--|:--|
| AHP | 专家两两比较 | 低 | 高 |
| 熵权法 | 数据信息熵 | 高 | 低 |
| CRITIC 法 | 数据对比强度和冲突性 | 高 | 低 |
| TOPSIS | 需外部确定 | 取决于权重来源 | 取决于权重来源 |
| PCA | 方差贡献率 | 高 | 低 |
| 因子分析 | 方差贡献率 | 高 | 低 |
| 模糊综合评价 | 需外部确定 | 取决于权重来源 | 取决于权重来源 |

**客观赋权方法比较**：

熵权法：依据指标数据的变异程度赋权，变异越大权重越大。

$$
w_j = \frac{1 - E_j}{\sum_{k=1}^{n}(1 - E_k)}, \quad E_j = -\frac{1}{\ln m}\sum_{i=1}^{m}p_{ij}\ln p_{ij}
$$

CRITIC 法：同时考虑指标的对比强度和指标间的冲突性。

$$
C_j = \sigma_j \sum_{k=1}^{n}(1 - r_{jk}), \quad w_j = \frac{C_j}{\sum_{k=1}^{n} C_k}
$$

### 3.3 适用场景对比

#### AHP 层次分析法

- 适合：指标数量适中（2-9个）、需要专家参与的决策
- 不适合：数据量大、指标过多
- 典型场景：方案选优、资源分配、政策评估

#### TOPSIS 法

- 适合：需要精确排序、数据完整
- 不适合：指标间高度相关、数据缺失严重
- 典型场景：供应商评价、方案排序、绩效考核

#### 模糊综合评价

- 适合：边界模糊、定性定量混合、评价等级有模糊性
- 不适合：数据精确、等级边界清晰
- 典型场景：水质评价、教学质量评价、风险评估

#### DEA 数据包络分析

- 适合：多输入多输出的效率评价、公共服务评价
- 不适合：单一输出评价、样本量过少
- 典型场景：银行效率、高校效率、医院效率

#### 熵权法

- 适合：需要客观赋权、减少主观性
- 不适合：指标重要性差异大但数据变异小
- 典型场景：作为权重确定的辅助方法

#### 秩和比法（RSR）

- 适合：数据分布未知、需要分档评价
- 不适合：需要精确数值比较
- 典型场景：医疗质量评价、卫生统计

#### 灰色关联分析

- 适合：数据量少、信息不完全
- 不适合：数据量大、信息完整
- 典型场景：小样本评价、时间序列分析

#### 因子分析和 PCA

- 适合：指标多且相关性强、需要降维
- 不适合：指标独立性强、样本量过小
- 典型场景：经济竞争力评价、综合实力评价

### 3.4 对样本量的要求

| 方法 | 最小样本量 | 推荐样本量 | 说明 |
|:--|:--|:--|:--|
| AHP | 无要求 | - | 不依赖样本量 |
| TOPSIS | 3 | 5-100 | 至少3个方案 |
| 模糊综合评价 | 无要求 | - | 依赖专家判断 |
| DEA | 2(m+s) | 3(m+s)以上 | m输入s输出 |
| 熵权法 | 3 | 5-50 | 过少不稳定 |
| RSR | 5 | 10以上 | 过少分档不精确 |
| 灰色关联 | 4 | 5-30 | 小样本优势 |
| 因子分析 | 5p | 100以上 | p为变量数 |
| PCA | 5p | 100以上 | p为变量数 |

## 四、组合评价方法

### 4.1 AHP + 熵权法组合赋权

结合主观和客观权重：

$$
w_j^{\text{综合}} = \frac{w_j^{\text{AHP}} \cdot w_j^{\text{熵}}}{\sum_{k=1}^{n} w_k^{\text{AHP}} \cdot w_k^{\text{熵}}}
$$

### 4.2 熵权 + TOPSIS

用熵权法确定权重，再用 TOPSIS 排序：

```python
import numpy as np

def entropy_topsis(data, cost_indices=None):
    """熵权-TOPSIS 组合评价"""
    data = np.array(data, dtype=float)
    m, n = data.shape
    cost_idx = cost_idx if cost_indices else []

    # 熵权法
    for j in cost_idx:
        data[:, j] = data[:, j].max() - data[:, j]
    P = data / data.sum(axis=0)
    P_safe = np.where(P > 0, P, 1)
    E = -(1/np.log(m)) * (P_safe * np.log(P_safe)).sum(axis=0)
    D = 1 - E
    weights = D / D.sum()

    # TOPSIS
    norm = np.sqrt((data ** 2).sum(axis=0))
    R = data / norm
    V = R * weights
    A_plus = V.max(axis=0)
    A_minus = V.min(axis=0)
    D_plus = np.sqrt(((V - A_plus)**2).sum(axis=1))
    D_minus = np.sqrt(((V - A_minus)**2).sum(axis=1))
    C = D_minus / (D_plus + D_minus + 1e-10)

    return C, weights
```

### 4.3 PCA + TOPSIS

用 PCA 降维后，再用 TOPSIS 排序。

### 4.4 灰色关联 + AHP

用 AHP 确定权重，再用灰色关联计算加权关联度。

### 4.5 多方法集成评价

综合多种方法的排序结果，取平均排名或投票决定最终排序。

$$
\text{综合排名}_i = \frac{1}{K} \sum_{k=1}^{K} \text{排名}_{ik}
$$

### 5.1 选择流程

```
问题分析
  |

  |     +-- 效率评价 --> DEA
```

## 六、方法组合的 Python 实现

```python
import numpy as np


class CombinedEvaluation:
    """多方法组合评价系统"""

    def __init__(self, data, cost_indices=None, var_names=None):
        self.data = np.array(data, dtype=float)
        self.m, self.n = self.data.shape
        self.cost_indices = cost_indices or []
        self.var_names = var_names or [f'X{i+1}' for i in range(self.n)]

    def entropy_weights(self):
        d = self.data.copy()
        for j in self.cost_indices:
            d[:, j] = d[:, j].max() - d[:, j]
        P = d / d.sum(axis=0)
        P_safe = np.where(P > 0, P, 1)
        E = -(1/np.log(self.m)) * (P_safe * np.log(P_safe)).sum(axis=0)
        return (1 - E) / (1 - E).sum()

    def topsis_score(self, weights=None):
        if weights is None:
            weights = self.entropy_weights()
        d = self.data.copy()
        norm = np.sqrt((d**2).sum(axis=0))
        R = d / norm
        V = R * weights
        A_plus = V.max(axis=0)
        A_minus = V.min(axis=0)
        D_plus = np.sqrt(((V - A_plus)**2).sum(axis=1))
        D_minus = np.sqrt(((V - A_minus)**2).sum(axis=1))
        return D_minus / (D_plus + D_minus + 1e-10)

    def grey_relational_score(self):
        d = self.data.copy()
        for j in self.cost_indices:
            d[:, j] = d[:, j].max() - d[:, j]
        ref = d.max(axis=0)
        d_std = d / d.mean(axis=0)
        ref_std = ref / ref.mean()
        delta = np.abs(d_std - ref_std)
        rho = 0.5
        xi = (delta.min() + rho * delta.max()) / (delta + rho * delta.max())
        return xi.mean(axis=1)

    def rsr_score(self):
        d = self.data.copy()
        for j in self.cost_indices:
            d[:, j] = d[:, j].max() - d[:, j]
        ranks = np.zeros_like(d, dtype=float)
        for j in range(self.n):
            idx = np.argsort(d[:, j])
            for k, i in enumerate(idx):
                ranks[i, j] = k + 1
        return ranks.mean(axis=1)

    def combined_rank(self):
        topsis = self.topsis_score()
        grey = self.grey_relational_score()
        rsr = self.rsr_score()

        rank_topsis = np.argsort(-topsis).argsort()
        rank_grey = np.argsort(-grey).argsort()
        rank_rsr = np.argsort(-rsr).argsort()

        avg_rank = (rank_topsis + rank_grey + rank_rsr) / 3.0
        final_ranking = np.argsort(avg_rank)

        print("=" * 65)
        print("组合评价结果")
        print("=" * 65)
        print(f"{'对象':<8}{'TOPSIS':<10}{'灰色关联':<10}{'RSR':<10}{'平均排名':<10}{'最终排名'}")
        print("-" * 65)
        for rank, idx in enumerate(final_ranking):
            print(f"  {idx+1:<6}{topsis[idx]:<10.4f}{grey[idx]:<10.4f}"
                  f"{rsr[idx]:<10.4f}{avg_rank[idx]:<10.2f}{rank+1}")

        return final_ranking


data = [
    [85, 90, 78, 92],
    [78, 85, 88, 80],
    [92, 75, 82, 88],
    [88, 82, 90, 85],
    [75, 92, 85, 90],
]

model = CombinedEvaluation(data)
model.combined_rank()
```

## 七、评价方法的验证与敏感性分析

### 7.1 方法一致性检验

使用多种方法评价后，用 **Kendall 协和系数** 检验各方法排序的一致性：

$$
W = \frac{12S}{K^2 n(n^2 - 1)}
$$

其中 $K$ 为方法数，$n$ 为对象数，$S = \sum_{i=1}^{n}(R_i - \bar{R})^2$。

- $W$ 接近 1：各方法排序高度一致
- $W$ 接近 0：各方法排序差异很大

### 7.2 权重敏感性分析

改变权重配置，观察评价结果的稳定性：

$$
\text{敏感度} = \frac{\Delta S / S}{\Delta w / w}
$$

若权重变化引起排名大幅变化，说明评价结果不够稳健。

### 7.3 参数敏感性分析

对 TOPSIS 的标准化方法、灰色关联的分辨系数 $\rho$、模糊评价的合成算子等参数进行敏感性分析。

## 八、常见问题与建议

### 8.1 方法选择的常见误区

1. **盲目追求复杂**：简单问题用简单方法即可
2. **单一方法**：建议至少用 2-3 种方法交叉验证
3. **忽视数据预处理**：标准化和正向化是关键步骤
4. **权重确定随意**：权重对结果影响巨大，需严谨确定

### 8.2 竞赛建议

1. **时间有限**时：选择 TOPSIS + 熵权法组合
2. **追求创新**时：尝试组合评价方法或改进模型
3. **结果敏感**时：用多种方法对比验证
4. **数据特殊**时：根据数据特征选择适合的方法

### 8.3 论文写作建议

1. 清楚说明选择该方法的**理由**
2. 详细描述**数据预处理**过程
3. 给出**参数选择**的依据
4. 进行**敏感性分析**验证结果稳健性
5. 与其他方法进行**对比分析**

## 九、关键要点总结

| 要点 | 内容 |
|:--|:--|
| 方法选择原则 | 适合问题特点，不盲目追求复杂 |
| 权重确定 | 客观（熵权法）+ 主观（AHP）结合 |
| 数据预处理 | 标准化、正向化、异常值处理 |
| 结果验证 | 多方法交叉验证 |
| 敏感性分析 | 参数和权重的稳健性检验 |
| 组合评价 | 综合多种方法的优势 |
| 核心公式 | 各方法有独立的数学框架 |
| 实践建议 | 竞赛用 TOPSIS+熵权，论文多方法对比 |

综合评价方法的选择应根据具体问题特点、数据特征和评价目的来决定。没有"万能"的评价方法，关键在于理解各方法的原理和适用条件，合理选择和组合，才能得到科学、可靠的评价结果。在数学建模竞赛中，建议掌握 2-3 种核心方法，并能灵活组合运用。
