# 主成分评价法

## 一、概述

主成分分析（Principal Component Analysis, PCA）由 Karl Pearson 于 1901 年提出，是一种经典的多元统计降维方法。在综合评价中，PCA 通过线性变换将多个相关指标转换为少数几个**互不相关的主成分**，以主成分的加权综合得分作为评价依据。

核心思想：

- 通过正交变换，将原始相关变量转换为**不相关**的主成分
- 第一主成分包含最多的信息（方差最大）
- 后续主成分依次包含递减的信息
- 选取前 $m$ 个主成分即可保留大部分信息

与因子分析的区别：

- PCA 是**降维技术**，不假设潜在因子模型
- 因子分析是**结构模型**，假设存在潜在公共因子
- PCA 的主成分是原始变量的精确线性组合
- 因子分析中原始变量是公共因子的近似线性组合

## 二、基本原理

### 2.1 数学模型

设有 $n$ 个样本，$p$ 个指标，原始数据矩阵为 $X_{n \times p}$（已标准化）。

主成分是原始变量的线性组合：

$$
\begin{aligned}
Z_1 &= l_{11}X_1 + l_{12}X_2 + \cdots + l_{1p}X_p \\
Z_2 &= l_{21}X_1 + l_{22}X_2 + \cdots + l_{2p}X_p \\
&\vdots \\
Z_p &= l_{p1}X_1 + l_{p2}X_2 + \cdots + l_{pp}X_p
\end{aligned}
$$

约束条件：

$$
\sum_{j=1}^{p} l_{ij}^2 = 1, \quad i = 1, 2, \ldots, p
$$

### 2.2 主成分的性质

- 各主成分之间**互不相关**：$\text{Cov}(Z_i, Z_j) = 0, \, i \neq j$
- 方差依次递减：$\text{Var}(Z_1) \geq \text{Var}(Z_2) \geq \cdots \geq \text{Var}(Z_p)$
- 方差之和等于原始变量方差之和：$\sum_{i=1}^{p} \text{Var}(Z_i) = p$

### 2.3 求解方法

主成分的系数向量是相关系数矩阵 $R$ 的特征向量。

相关系数矩阵：

$$
R = \frac{1}{n-1} X^T X
$$

特征值分解：

$$
R \mathbf{l}_i = \lambda_i \mathbf{l}_i
$$

其中 $\lambda_i$ 为特征值（第 $i$ 个主成分的方差），$\mathbf{l}_i$ 为对应的特征向量（系数向量）。

### 2.4 方差贡献率

第 $k$ 个主成分的方差贡献率：

$$
\text{贡献率}_k = \frac{\lambda_k}{\sum_{i=1}^{p} \lambda_i}
$$

前 $m$ 个主成分的累计方差贡献率：

$$
\text{累计贡献率}_m = \frac{\sum_{k=1}^{m} \lambda_k}{\sum_{i=1}^{p} \lambda_i}
$$

### 2.5 主成分个数确定

#### Kaiser 准则

选择特征值 $\lambda_k > 1$ 的主成分（适用于标准化数据）。

#### 累计贡献率准则

选择使累计方差贡献率达到 **70%~85%** 以上的最少主成分个数。

#### 碎石图准则

绘制特征值的碎石图，选择曲线"拐点"之前的主成分个数。

#### 平行分析法

将实际特征值与随机数据的特征值进行比较，选择实际特征值大于随机特征值的主成分。

### 2.6 主成分得分

各主成分的得分计算：

$$
Z_k = l_{k1}X_1 + l_{k2}X_2 + \cdots + l_{kp}X_p, \quad k = 1, 2, \ldots, m
$$

### 2.7 综合评价得分

以各主成分的方差贡献率为权重，计算综合得分：

$$
S = \frac{\lambda_1}{\sum \lambda_k} Z_1 + \frac{\lambda_2}{\sum \lambda_k} Z_2 + \cdots + \frac{\lambda_m}{\sum \lambda_k} Z_m
$$

$$
S = \sum_{k=1}^{m} w_k Z_k, \quad w_k = \frac{\lambda_k}{\sum_{i=1}^{m} \lambda_i}
$$

## 三、计算步骤

1. **数据标准化**：$X_{ij}^* = (X_{ij} - \bar{X}_j) / S_j$
2. **计算相关系数矩阵** $R$
3. **特征值分解**：求 $R$ 的特征值和特征向量
4. **确定主成分个数** $m$
5. **计算因子载荷矩阵** $A = (l_{ij} \sqrt{\lambda_j})$
6. **计算主成分得分** $Z_k$
7. **计算综合得分** $S$
8. **排序和评价**

## 四、Python 实现

### 4.1 基本 PCA 评价

```python
import numpy as np


class PCAEvaluation:
    """主成分分析综合评价"""

    def __init__(self, data, var_names=None):
        self.raw = np.array(data, dtype=float)
        self.n, self.p = self.raw.shape
        self.var_names = var_names or [f'X{i+1}' for i in range(self.p)]

    def standardize(self):
        self.mean = self.raw.mean(axis=0)
        self.std = self.raw.std(axis=0, ddof=1)
        self.Z = (self.raw - self.mean) / self.std
        return self.Z

    def correlation_matrix(self):
        self.standardize()
        self.R = np.corrcoef(self.Z, rowvar=False)
        return self.R

    def eigen_decomposition(self):
        self.correlation_matrix()
        eigenvalues, eigenvectors = np.linalg.eigh(self.R)
        idx = np.argsort(-eigenvalues)
        self.eigenvalues = eigenvalues[idx]
        self.eigenvectors = eigenvectors[:, idx]
        return self.eigenvalues, self.eigenvectors

    def kaiser_criterion(self):
        self.eigen_decomposition()
        self.n_components = np.sum(self.eigenvalues > 1.0)
        self.n_components = max(self.n_components, 1)
        return self.n_components

    def cumulative_variance(self, threshold=0.85):
        self.eigen_decomposition()
        cum_var = np.cumsum(self.eigenvalues) / self.p
        self.n_components = np.searchsorted(cum_var, threshold) + 1
        self.n_components = max(self.n_components, 1)
        return self.n_components

    def scree_plot_data(self):
        self.eigen_decomposition()
        return self.eigenvalues

    def loadings(self, n_components=None):
        if n_components is None:
            n_components = self.kaiser_criterion()
        self.n_components = n_components

        self.eigen_decomposition()
        L = self.eigenvectors[:, :n_components] * np.sqrt(self.eigenvalues[:n_components])
        self.L = L
        return L

    def principal_scores(self, n_components=None):
        L = self.loadings(n_components)
        self.standardize()
        self.scores = self.Z @ L
        return self.scores

    def comprehensive_score(self, n_components=None):
        scores = self.principal_scores(n_components)
        var_exp = self.eigenvalues[:self.n_components]
        weights = var_exp / var_exp.sum()
        self.composite = scores @ weights
        return self.composite

    def summary(self, n_components=None, threshold=0.85):
        self.eigen_decomposition()
        cum_var = np.cumsum(self.eigenvalues) / self.p * 100
        n_kaiser = np.sum(self.eigenvalues > 1.0)
        n_cum = np.searchsorted(cum_var, threshold) + 1

        print("=" * 65)
        print("主成分分析综合评价结果")
        print("=" * 65)

        print("\n特征值与方差贡献率:")
        print(f"  {'主成分':<10}{'特征值':<12}{'贡献率%':<12}{'累计%':<12}")
        print("  " + "-" * 46)
        for i in range(self.p):
            flag = ""
            if i < max(n_kaiser, 1):
                flag = " <-- Kaiser"
            elif i < n_cum:
                flag = " <-- 累计"
            print(f"  PC{i+1:<8}{self.eigenvalues[i]:<12.4f}"
                  f"{self.eigenvalues[i]/self.p*100:<12.2f}"
                  f"{cum_var[i]:<12.2f}{flag}")

        n_comp = n_components or n_kaiser
        n_comp = max(n_comp, 1)

        L = self.loadings(n_comp)
        print(f"\n因子载荷矩阵 ({n_comp}个主成分):")
        header = f"  {'变量':<10}"
        for j in range(n_comp):
            header += f"{'PC'+str(j+1):<12}"
        print(header)
        print("  " + "-" * 46)
        for i in range(self.p):
            line = f"  {self.var_names[i]:<10}"
            for j in range(n_comp):
                line += f"{L[i, j]:<12.4f}"
            print(line)

        scores = self.comprehensive_score(n_comp)
        ranking = np.argsort(-scores)
        print(f"\n综合得分排名:")
        for rank, idx in enumerate(ranking):
            print(f"  第{rank+1}名: 样本{idx+1}, 得分={scores[idx]:.4f}")

        return scores, L


# 示例
np.random.seed(42)
n, p = 12, 6
data = np.column_stack([
    np.random.uniform(100, 500, n),
    np.random.uniform(50, 250, n),
    np.random.uniform(60, 95, n),
    np.random.uniform(40, 90, n),
    np.random.uniform(30, 80, n),
    np.random.uniform(50, 100, n),
])

pca = PCAEvaluation(data)
scores, L = pca.summary()
```

### 4.2 基于 sklearn 的 PCA

```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA


def pca_with_sklearn(data, n_components=None):
    """使用 sklearn 进行 PCA 评价"""
    scaler = StandardScaler()
    Z = scaler.fit_transform(data)

    if n_components is None:
        pca_temp = PCA()
        pca_temp.fit(Z)
        cum_var = np.cumsum(pca_temp.explained_variance_ratio_)
        n_components = np.searchsorted(cum_var, 0.85) + 1
        n_components = max(n_components, 1)

    pca = PCA(n_components=n_components)
    scores = pca.fit_transform(Z)

    weights = pca.explained_variance_ratio_
    composite = scores @ weights

    print("sklearn PCA 结果:")
    print(f"  选取主成分数: {n_components}")
    print(f"  方差贡献率: {np.round(weights * 100, 2)}%")
    print(f"  累计贡献率: {sum(weights) * 100:.2f}%")

    ranking = np.argsort(-composite)
    print("\n综合排名:")
    for rank, idx in enumerate(ranking):
        print(f"  第{rank+1}名: 样本{idx+1}, 得分={composite[idx]:.4f}")

    return composite, pca


data_example = np.random.rand(10, 5) * 100
pca_with_sklearn(data_example)
```

## 五、实际案例：区域经济竞争力评价

```python
import numpy as np


def regional_economy_pca():
    """区域经济竞争力 PCA 评价"""
    regions = ['北京', '上海', '广东', '江苏', '浙江', '山东', '四川', '湖北']

    # 指标: GDP, 固定资产投资, 社会消费品零售总额, 进出口总额, 居民收入, 财政收入
    data = np.array([
        [36102, 8500, 12000, 28000, 69434, 5832],
        [32679, 7800, 13500, 35000, 72232, 7165],
        [110760, 42000, 42000, 71000, 35000, 12500],
        [102700, 48000, 38000, 42000, 42000, 10000],
        [64600, 35000, 26000, 32000, 52000, 7800],
        [83000, 38000, 33000, 24000, 35000, 6800],
        [48600, 28000, 22000, 8000, 28000, 4200],
        [50000, 25000, 20000, 6000, 30000, 3800],
    ])

    indicators = ['GDP', '固定资产投资', '消费品零售额', '进出口总额', '居民收入', '财政收入']

    m, p = data.shape

    # 标准化
    mean = data.mean(axis=0)
    std = data.std(axis=0, ddof=1)
    Z = (data - mean) / std

    # 相关矩阵与特征值分解
    R = np.corrcoef(Z, rowvar=False)
    eigenvalues, eigenvectors = np.linalg.eigh(R)
    idx = np.argsort(-eigenvalues)
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]

    cum_var = np.cumsum(eigenvalues) / p
    n_comp = np.searchsorted(cum_var, 0.80) + 1
    n_comp = max(n_comp, 1)

    # 主成分得分
    L = eigenvectors[:, :n_comp] * np.sqrt(eigenvalues[:n_comp])
    scores = Z @ L
    weights = eigenvalues[:n_comp] / eigenvalues[:n_comp].sum()
    composite = scores @ weights

    print("区域经济竞争力 PCA 评价")
    print("=" * 60)
    print(f"选取 {n_comp} 个主成分，累计贡献率: {cum_var[n_comp-1]*100:.1f}%")
    print(f"权重: {np.round(weights, 4)}")
    print("-" * 60)

    ranking = np.argsort(-composite)
    for rank, idx in enumerate(ranking):
        print(f"  第{rank+1}名: {regions[idx]}, 得分={composite[idx]:.4f}")


regional_economy_pca()
```

## 六、PCA 评价的改进

### 6.1 核主成分分析（KPCA）

通过核函数将数据映射到高维空间，再进行 PCA，适合非线性数据。

$$
K(x_i, x_j) = \phi(x_i)^T \phi(x_j)
$$

常用核函数：

- 高斯核：$K(x, y) = \exp(-\|x - y\|^2 / 2\sigma^2)$
- 多项式核：$K(x, y) = (x^T y + c)^d$

### 6.2 稀疏 PCA

在主成分中引入稀疏约束，使载荷矩阵中许多元素为 0，便于解释：

$$
\max \quad \text{Var}(Xw) \quad \text{s.t.} \quad \|w\|_2 = 1, \, \|w\|_0 \leq k
$$

### 6.3 加权 PCA

对不同指标赋予不同重要性：

$$
R_w = X^T W X
$$

其中 $W$ 为权重对角矩阵。

## 七、PCA 与因子分析的比较

| 特征 | PCA | 因子分析 |
|:--|:--|:--|
| 模型 | 精确变换 | 近似分解 |
| 目标 | 降维、方差最大化 | 结构发现 |
| 特殊因子 | 无 | 有 |
| 因子相关 | 主成分不相关 | 公因子可以不相关 |
| 适用场景 | 综合评价、降维 | 潜在结构分析 |
| 解释性 | 较弱 | 较强 |

## 八、注意事项

1. **数据标准化**：PCA 对数据尺度敏感，必须先标准化
2. **指标方向**：不同方向的指标需先正向化
3. **样本量要求**：样本量应大于变量数，建议 $n \geq 5p$
4. **共线性处理**：高度共线性不影响 PCA，反而有利于降维
5. **主成分解释**：有时主成分的实际含义难以明确解释
6. **综合得分的权重**：通常用方差贡献率，也可用其他方式

## 九、关键要点总结

| 要点 | 内容 |
|:--|:--|
| 核心思想 | 正交变换，方差最大化 |
| 数学基础 | 相关矩阵的特征值分解 |
| 载荷矩阵 | $A = L \Lambda^{1/2}$ |
| 方差贡献率 | $\lambda_k / \sum \lambda_i$ |
| 主成分选择 | Kaiser(>1) 或累计贡献率(>70%-85%) |
| 综合得分 | $S = \sum w_k Z_k$，权重为贡献率 |
| 优势 | 消除指标相关性、降维客观 |
| 局限 | 结果解释困难、对异常值敏感 |

主成分分析是综合评价中最常用的客观方法之一，通过降维消除了指标间的相关性，用方差贡献率作为权重避免了主观赋权。在数学建模竞赛中，PCA 常与其他评价方法结合使用，以获得更加全面和稳健的评价结果。
