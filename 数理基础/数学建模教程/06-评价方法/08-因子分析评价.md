# 因子分析评价法

## 一、概述

因子分析（Factor Analysis）是由 Charles Spearman 于 1904 年提出的一种多元统计分析方法。其基本思想是将多个相关变量综合为少数几个**公共因子**，用这些公共因子来解释原始变量之间的相关关系，从而实现降维和综合评价。

核心思想：

- 原始变量可以表示为公共因子的线性组合
- 公共因子之间相互独立（不相关）
- 通过因子旋转使因子含义更加明确
- 利用因子得分进行综合评价

适用场景：

- 指标降维：将大量相关指标综合为少数因子
- 综合评价：利用因子得分进行排序
- 数据结构探索：发现潜在的因子结构
- 指标分类：根据因子载荷对指标分类

## 二、基本原理

### 2.1 因子分析模型

设有 $p$ 个原始变量 $X_1, X_2, \ldots, X_p$（已标准化），$m$ 个公共因子 $F_1, F_2, \ldots, F_m$（$m < p$），因子分析模型为：

$$
\begin{pmatrix} X_1 \\ X_2 \\ \vdots \\ X_p \end{pmatrix}
=
\begin{pmatrix}
a_{11} & a_{12} & \cdots & a_{1m} \\
a_{21} & a_{22} & \cdots & a_{2m} \\
\vdots & \vdots & \ddots & \vdots \\
a_{p1} & a_{p2} & \cdots & a_{pm}
\end{pmatrix}
\begin{pmatrix} F_1 \\ F_2 \\ \vdots \\ F_m \end{pmatrix}
+
\begin{pmatrix} \varepsilon_1 \\ \varepsilon_2 \\ \vdots \\ \varepsilon_p \end{pmatrix}
$$

简记为：

$$
\mathbf{X} = A \mathbf{F} + \boldsymbol{\varepsilon}
$$

其中：

- $A$：因子载荷矩阵，$a_{ij}$ 为第 $i$ 个变量在第 $j$ 个因子上的载荷
- $\mathbf{F}$：公共因子向量
- $\boldsymbol{\varepsilon}$：特殊因子向量（不能被公共因子解释的部分）

### 2.2 因子载荷的含义

因子载荷 $a_{ij}$ 表示变量 $X_i$ 与公共因子 $F_j$ 之间的**相关系数**：

$$
a_{ij} = \text{Corr}(X_i, F_j)
$$

- $|a_{ij}|$ 越接近 1，说明 $X_i$ 与 $F_j$ 的相关性越强
- $|a_{ij}|$ 越接近 0，说明 $X_i$ 与 $F_j$ 的相关性越弱

### 2.3 方差贡献

#### 变量的共同度

第 $i$ 个变量的共同度（公因子方差）：

$$
h_i^2 = \sum_{j=1}^{m} a_{ij}^2
$$

$h_i^2$ 表示 $m$ 个公共因子对变量 $X_i$ 的总解释比例。

#### 因子的方差贡献

第 $j$ 个公共因子的方差贡献：

$$
S_j^2 = \sum_{i=1}^{p} a_{ij}^2
$$

#### 方差贡献率

$$
\text{方差贡献率}_j = \frac{S_j^2}{\sum_{i=1}^{p} \text{Var}(X_i)} = \frac{S_j^2}{p}
$$

#### 累计方差贡献率

$$
\text{累计贡献率}_m = \frac{\sum_{j=1}^{m} S_j^2}{p} \times 100\%
$$

通常要求累计方差贡献率达到 **70%~85%** 以上。

### 2.4 因子旋转

因子旋转的目的是使因子载荷矩阵的结构更加简单，便于解释因子含义。

#### 正交旋转（方差最大法 Varimax）

保持因子之间的不相关性，使每个因子上少数变量有较大载荷，其余变量载荷较小。

#### 斜交旋转（Promax）

允许因子之间存在相关性，适用于因子之间确实存在关联的情况。

### 2.5 因子得分

将公共因子表示为原始变量的线性组合：

$$
\hat{F}_j = b_{j1} X_1 + b_{j2} X_2 + \cdots + b_{jp} X_p
$$

常用的因子得分估计方法：

- **回归法**（Bartlett 得分）
- **最小二乘法**（Thomson 得分）

## 三、计算步骤

1. **数据标准化**：消除量纲影响
2. **适用性检验**：KMO 检验和 Bartlett 球形检验
3. **提取因子**：主成分法、主因子法等
4. **确定因子个数**：特征值准则、累计贡献率准则
5. **因子旋转**：使因子含义更明确
6. **因子命名和解释**
7. **计算因子得分**
8. **综合评价**

## 四、适用性检验

### 4.1 KMO 检验

KMO（Kaiser-Meyer-Olkin）检验用于衡量变量之间的偏相关性：

$$
KMO = \frac{\sum \sum_{i \neq j} r_{ij}^2}{\sum \sum_{i \neq j} r_{ij}^2 + \sum \sum_{i \neq j} p_{ij}^2}
$$

其中 $r_{ij}$ 为简单相关系数，$p_{ij}$ 为偏相关系数。

| KMO 值 | 适合程度 |
|:--|:--|
| > 0.9 | 非常适合 |
| 0.8 ~ 0.9 | 适合 |
| 0.7 ~ 0.8 | 一般 |
| 0.6 ~ 0.7 | 不太适合 |
| < 0.6 | 不适合 |

### 4.2 Bartlett 球形检验

检验相关系数矩阵是否为单位矩阵：

$$
\chi^2 = -\left[(n - 1) - \frac{2p + 5}{6}\right] \ln |R|
$$

其中 $R$ 为相关系数矩阵，$n$ 为样本量，$p$ 为变量数。

- 原假设 $H_0$：相关系数矩阵为单位矩阵（变量之间不相关）
- 若 $p < 0.05$，拒绝原假设，适合做因子分析

## 五、Python 实现

### 5.1 基本因子分析

```python
import numpy as np
from numpy.linalg import eig, inv
from scipy.stats import bartlett


class FactorAnalysis:
    """因子分析综合评价"""

    def __init__(self, data, var_names=None):
        self.raw = np.array(data, dtype=float)
        self.m, self.p = self.raw.shape
        self.var_names = var_names or [f'X{i+1}' for i in range(self.p)]

    def standardize(self):
        self.mean = self.raw.mean(axis=0)
        self.std = self.raw.std(axis=0, ddof=1)
        self.Z = (self.raw - self.mean) / self.std
        return self.Z

    def correlation_matrix(self):
        self.standardize()
        self.R = np.corrcoef(self.Z, rowvar=False)
        return self.R

    def bartlett_test(self):
        self.correlation_matrix()
        chi2, p_value = bartlett(self.R)
        return chi2, p_value

    def eigen_decomposition(self):
        self.correlation_matrix()
        eigenvalues, eigenvectors = eig(self.R)
        idx = np.argsort(-eigenvalues)
        self.eigenvalues = eigenvalues[idx].real
        self.eigenvectors = eigenvectors[:, idx].real
        return self.eigenvalues, self.eigenvectors

    def determine_factors(self, threshold=0.85):
        self.eigen_decomposition()
        cum_var = np.cumsum(self.eigenvalues) / self.p
        n_factors = np.searchsorted(cum_var, threshold) + 1
        n_factors = max(n_factors, 1)
        self.n_factors = min(n_factors, self.p)
        return self.n_factors

    def extract_factors(self, n_factors=None):
        if n_factors is None:
            n_factors = self.determine_factors()
        self.n_factors = n_factors

        L = self.eigenvectors[:, :n_factors] * np.sqrt(self.eigenvalues[:n_factors])
        self.loadings = L
        return self.loadings

    def varimax_rotation(self, loadings, max_iter=100):
        n_rows, n_cols = loadings.shape
        R = np.eye(n_cols)
        for _ in range(max_iter):
            L = loadings @ R
            u, s, vt = np.linalg.svd(
                loadings.T @ (L**3 - L * (L**2).mean(axis=0))
            )
            R = u @ vt
        rotated = loadings @ R
        return rotated

    def factor_scores(self, rotated_loadings=None):
        if rotated_loadings is None:
            rotated_loadings = self.loadings

        self.standardize()
        H2 = (rotated_loadings ** 2).sum(axis=1)
        uniqueness = 1 - H2
        uniqueness = np.where(uniqueness < 0.001, 0.001, uniqueness)

        Psi = np.diag(uniqueness)
        inv_R = np.linalg.inv(self.R)
        W = inv_R @ rotated_loadings
        self.scores = self.Z @ W
        return self.scores

    def comprehensive_score(self, rotated_loadings=None):
        scores = self.factor_scores(rotated_loadings)
        var_exp = (self.loadings ** 2).sum(axis=0)[:self.n_factors]
        weights = var_exp / var_exp.sum()
        self.composite = scores @ weights
        return self.composite

    def summary(self, var_names=None):
        if var_names:
            self.var_names = var_names

        n_factors = self.determine_factors()
        loadings = self.extract_factors(n_factors)
        rotated = self.varimax_rotation(loadings)
        scores = self.comprehensive_score(rotated)

        print("=" * 65)
        print("因子分析结果")
        print("=" * 65)

        # 特征值
        print("\n特征值与方差贡献率:")
        cum = np.cumsum(self.eigenvalues) / self.p * 100
        for i in range(min(6, self.p)):
            flag = " <-- 选取" if i < n_factors else ""
            print(f"  因子{i+1}: 特征值={self.eigenvalues[i]:.4f}, "
                  f"贡献率={self.eigenvalues[i]/self.p*100:.2f}%, "
                  f"累计={cum[i]:.2f}%{flag}")

        # 旋转后因子载荷
        print(f"\n旋转后因子载荷矩阵 ({n_factors}个因子):")
        header = f"  {'变量':<10}"
        for j in range(n_factors):
            header += f"{'F'+str(j+1):<12}"
        print(header)
        print("  " + "-" * 50)
        for i in range(self.p):
            line = f"  {self.var_names[i]:<10}"
            for j in range(n_factors):
                line += f"{rotated[i, j]:<12.4f}"
            print(line)

        # 综合得分排名
        ranking = np.argsort(-scores)
        print(f"\n综合得分排名:")
        for rank, idx in enumerate(ranking):
            print(f"  第{rank+1}名: 对象{idx+1}, 得分={scores[idx]:.4f}")

        return scores, rotated

np.random.seed(42)
n = 10
data = np.column_stack([
    np.random.uniform(200, 800, n),   # GDP
    np.random.uniform(30000, 80000, n),  # 人均收入
    np.random.uniform(70, 98, n),     # 教育水平
    np.random.uniform(60, 95, n),     # 医疗水平
    np.random.uniform(65, 95, n),     # 环境质量
    np.random.uniform(50, 90, n),     # 交通便利度
    np.random.uniform(40, 85, n),     # 科技水平
])

fa = FactorAnalysis(data)
```

## 六、实际案例：企业竞争力评价

```python
import numpy as np


def enterprise_competitiveness():
    """企业竞争力因子分析评价"""
    enterprises = [f'企业{i+1}' for i in range(8)]

    # 指标: 营业收入, 净利润, 市场份额, 研发投入, 员工满意度, 品牌价值
    indicators = ['营业收入', '净利润', '市场份额', '研发投入', '员工满意度', '品牌价值']

    data = np.array([
        [5200, 800, 12.5, 350, 82, 90],
        [3800, 550, 8.3, 280, 78, 75],
        [6100, 950, 15.2, 420, 85, 95],
        [2900, 380, 6.1, 200, 75, 65],
        [4500, 700, 10.8, 310, 80, 82],
        [3200, 420, 7.5, 240, 72, 68],
        [5800, 880, 14.0, 400, 88, 92],
        [4100, 620, 9.2, 290, 76, 78],
    ])

    m, p = data.shape

    # 标准化
    mean = data.mean(axis=0)
    std = data.std(axis=0, ddof=1)
    Z = (data - mean) / std

    # 相关系数矩阵
    R = np.corrcoef(Z, rowvar=False)

    # 特征值分解
    eigenvalues, eigenvectors = np.linalg.eigh(R)
    idx = np.argsort(-eigenvalues)
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]

    cum_var = np.cumsum(eigenvalues) / p
    n_factors = np.searchsorted(cum_var, 0.80) + 1

    print("企业竞争力因子分析评价")
    print("=" * 60)
    print("\n特征值与累计方差贡献率:")
    for i in range(p):
        flag = " <--" if i < n_factors else ""
        print(f"  F{i+1}: eigenvalue={eigenvalues[i]:.4f}, "
              f"cumulative={cum_var[i]*100:.1f}%{flag}")

    # 因子载荷
    L = eigenvectors[:, :n_factors] * np.sqrt(eigenvalues[:n_factors])

    print(f"\n因子载荷矩阵 ({n_factors}个因子):")
    for i in range(p):
        line = f"  {indicators[i]:<10}"
        for j in range(n_factors):
            line += f"  F{j+1}={L[i,j]:.4f}"
        print(line)

    # 因子得分和综合得分
    var_exp = eigenvalues[:n_factors]
    weights = var_exp / var_exp.sum()
    scores = Z @ L
    composite = scores @ weights

    ranking = np.argsort(-composite)
    print(f"\n企业综合竞争力排名:")
    for rank, idx in enumerate(ranking):
        print(f"  第{rank+1}名: {enterprises[idx]}, 得分={composite[idx]:.4f}")

    return composite


enterprise_competitiveness()
```

## 七、注意事项

1. **样本量要求**：通常要求样本量 $n \geq 5p$ 或至少 $n \geq 100$
2. **KMO 检验**：KMO > 0.6 才适合做因子分析
3. **因子个数选择**：通常选择特征值 > 1 或累计贡献率 > 70% 的因子数
4. **因子旋转**：旋转后需重新解释因子含义
5. **缺失值处理**：因子分析不支持缺失值，需预先处理
6. **异常值影响**：因子分析对异常值敏感，需进行检验和处理

## 八、关键要点总结

| 要点 | 内容 |
|:--|:--|
| 模型 | $\mathbf{X} = A\mathbf{F} + \varepsilon$ |
| 因子载荷 | $a_{ij} = \text{Corr}(X_i, F_j)$ |
| 共同度 | $h_i^2 = \sum a_{ij}^2$ |
| 方差贡献 | $S_j^2 = \sum a_{ij}^2$ |
| 适用性检验 | KMO > 0.6, Bartlett p < 0.05 |
| 因子选择 | 特征值 > 1 或累计贡献率 > 70% |
| 旋转目的 | 使因子含义更明确 |
| 综合得分 | 加权因子得分之和 |
| 优势 | 降维、消除指标相关性 |
| 局限 | 对样本量要求高、结果解释需专业知识 |

因子分析是处理多指标综合评价问题的有力工具，特别适合指标间存在较强相关性的场景。通过降维和因子旋转，可以提取出更有意义的综合因子，为评价和决策提供科学依据。
