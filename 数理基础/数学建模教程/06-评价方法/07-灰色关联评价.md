# 灰色关联评价法

## 一、概述

灰色关联分析（Grey Relational Analysis, GRA）是由中国学者邓聚龙教授于 1982 年提出的灰色系统理论的重要组成部分。该方法通过计算各比较序列与参考序列之间的**关联度**，来衡量它们之间的相似程度和变化趋势的一致性，从而实现对评价对象的排序和优选。

核心思想：

- 系统因素之间存在**灰色关系**（部分信息已知、部分未知）
- 通过序列曲线的**几何相似程度**判断关联性
- 曲线越相似，关联度越大，该因素对参考序列的影响越大
- 据此可以进行因素分析、优势分析和综合评价

适用场景：

- 系统因素分析和主要因素识别
- 多方案/多指标综合评价
- 数据量少、信息不完全的评价问题
- 时间序列的关联分析

## 二、基本原理

### 2.1 灰色系统理论基础

**灰色系统**：信息不完全、不明确的系统。介于白色系统（信息完全）和黑色系统（信息完全未知）之间。

系统的关联性分析是比较各因素发展态势的相似或相异程度。

### 2.2 灰色关联度的定义

设参考序列为：

$$
X_0 = (x_0(1), x_0(2), \ldots, x_0(n))
$$

比较序列为：

$$
X_i = (x_i(1), x_i(2), \ldots, x_i(n)), \quad i = 1, 2, \ldots, m
$$

### 2.3 灰色关联系数

第 $i$ 个比较序列在第 $k$ 个时刻的关联系数为：

$$
\xi_i(k) = \frac{\min_i \min_k |x_0(k) - x_i(k)| + \rho \cdot \max_i \max_k |x_0(k) - x_i(k)|}{|x_0(k) - x_i(k)| + \rho \cdot \max_i \max_k |x_0(k) - x_i(k)|}
$$

其中：

- $\min_i \min_k |x_0(k) - x_i(k)|$：两级最小差
- $\max_i \max_k |x_0(k) - x_i(k)|$：两级最大差
- $\rho$：分辨系数，$\rho \in (0, 1)$，通常取 $\rho = 0.5$

### 2.4 灰色关联度

#### 等权关联度

$$
r_i = \frac{1}{n} \sum_{k=1}^{n} \xi_i(k)
$$

#### 加权关联度

$$
r_i = \sum_{k=1}^{n} w_k \cdot \xi_i(k)
$$

其中 $w_k$ 为第 $k$ 个指标的权重，满足 $\sum_{k=1}^{n} w_k = 1$。

### 2.5 分辨系数的作用

分辨系数 $\rho$ 影响关联系数的灵敏度：

- $\rho$ 越小，分辨率越高，区分度越大
- $\rho$ 越大，分辨率越低，区分度越小
- 通常取 $\rho = 0.5$
- 当数据噪声较大时，可适当增大 $\rho$

### 2.6 关联度排序

根据关联度 $r_i$ 的大小对比较序列排序：

$$
r_i > r_j \Rightarrow X_i \text{ 与 } X_0 \text{ 的关联性更强}
$$

## 三、计算步骤

1. **确定参考序列和比较序列**
2. **数据无量纲化处理**（初值化或均值化）
3. **计算差序列** $\Delta_i(k) = |x_0(k) - x_i(k)|$
4. **确定两级最大差和最小差**
5. **计算关联系数** $\xi_i(k)$
6. **计算关联度** $r_i$
7. **排序和分析**

## 四、数据无量纲化方法

### 4.1 初值化

$$
x_i'(k) = \frac{x_i(k)}{x_i(1)}
$$

适用于各指标有统一量纲或随时间变化的数据。

### 4.2 均值化

$$
x_i'(k) = \frac{x_i(k)}{\bar{x}_i}, \quad \bar{x}_i = \frac{1}{n} \sum_{k=1}^{n} x_i(k)
$$

适用于各指标量纲不同或数量级差异较大的数据。

### 4.3 极差化

$$
x_i'(k) = \frac{x_i(k) - \min_k x_i(k)}{\max_k x_i(k) - \min_k x_i(k)}
$$

将数据映射到 $[0, 1]$ 区间。

## 五、Python 实现

### 5.1 基本灰色关联分析

```python
import numpy as np


class GreyRelationalAnalysis:
    """灰色关联分析"""

    def __init__(self, reference, comparators, method='mean'):
        self.x0 = np.array(reference, dtype=float)
        self.X = np.array(comparators, dtype=float)
        if self.X.ndim == 1:
            self.X = self.X.reshape(1, -1)
        self.m, self.n = self.X.shape
        self.method = method

    def standardize(self):
        if self.method == 'init':
            x0_std = self.x0 / self.x0[0]
            X_std = self.X / self.X[:, 0:1]
        elif self.method == 'mean':
            x0_std = self.x0 / self.x0.mean()
            X_std = self.X / self.X.mean(axis=1, keepdims=True)
        elif self.method == 'minmax':
            x0_range = self.x0.max() - self.x0.min()
            x0_std = (self.x0 - self.x0.min()) / x0_range
            X_range = self.X.max(axis=1) - self.X.min(axis=1)
            X_range = np.where(X_range == 0, 1, X_range)
            X_std = (self.X - self.X.min(axis=1, keepdims=True)) / X_range[:, None]
        else:
            x0_std = self.x0.copy()
            X_std = self.X.copy()
        return x0_std, X_std

    def calc_delta(self):
        x0_std, X_std = self.standardize()
        self.delta = np.abs(X_std - x0_std)
        return self.delta

    def grey_relational_coefficient(self, rho=0.5):
        self.calc_delta()
        delta_min = self.delta.min()
        delta_max = self.delta.max()
        numerator = delta_min + rho * delta_max
        denominator = self.delta + rho * delta_max
        self.xi = numerator / denominator
        return self.xi

    def grey_relational_grade(self, weights=None, rho=0.5):
        self.grey_relational_coefficient(rho)
        if weights is None:
            self.r = self.xi.mean(axis=1)
        else:
            self.r = self.xi @ np.array(weights)
        return self.r

    def rank(self):
        self.grey_relational_grade()
        ranking = np.argsort(-self.r)
        return ranking, self.r

    def summary(self, names=None):
        ranking, r = self.rank()
        print("=" * 50)
        print("灰色关联分析结果")
        print("=" * 50)
        print(f"{'排名':<6}{'序列':<10}{'关联度':<10}")
        print("-" * 50)
        for rank, idx in enumerate(ranking):
            name = names[idx] if names else f"X{idx+1}"
            print(f"{rank+1:<6}{name:<10}{r[idx]:.4f}")
        return ranking, r


# 示例
reference = [100, 95, 88, 82, 75, 70]
comparators = [
    [98, 93, 87, 80, 74, 69],
    [95, 90, 85, 80, 76, 72],
    [90, 88, 90, 85, 80, 75],
    [100, 96, 89, 83, 76, 71],
]

names = ['方案A', '方案B', '方案C', '方案D']
gra = GreyRelationalAnalysis(reference, comparators, method='init')
gra.summary(names)
```

### 5.2 灰色关联用于综合评价

```python
import numpy as np


def grey_relational_evaluation(data, cost_indices=None):
    """灰色关联综合评价"""
    data = np.array(data, dtype=float)
    m, n = data.shape

    # 正向化
    if cost_indices:
        for j in cost_indices:
            data[:, j] = data[:, j].max() - data[:, j]

    # 参考序列：各指标最优值
    ref = data.max(axis=0)

    # 均值化
    ref_std = ref / ref.mean()
    data_std = data / data.mean(axis=1, keepdims=True)

    # 差序列
    delta = np.abs(data_std - ref_std)
    delta_min = delta.min()
    delta_max = delta.max()

    # 关联系数
    rho = 0.5
    xi = (delta_min + rho * delta_max) / (delta + rho * delta_max)

    # 关联度
    r = xi.mean(axis=1)

    ranking = np.argsort(-r)
    return ranking, r


data = [
    [85, 90, 78, 92],
    [78, 85, 88, 80],
    [92, 75, 82, 88],
    [88, 82, 90, 85],
    [75, 92, 85, 90],
]

ranking, r = grey_relational_evaluation(data)
print("灰色关联综合评价:")
for rank, idx in enumerate(ranking):
    print(f"  第{rank+1}名: 方案{idx+1}, 关联度={r[idx]:.4f}")
```

## 六、实际案例：水质灰色关联评价

```python
import numpy as np


def water_quality_gra():
    """水质灰色关联评价"""
    indicators = ['pH', 'DO', 'COD', 'NH3-N', 'TP']
    grades = ['I类', 'II类', 'III类', 'IV类', 'V类']

    # 各类水质标准值
    standard = np.array([
        [6, 9, 15, 0.15, 0.02],
        [6, 7.5, 15, 0.5, 0.1],
        [6, 6, 20, 1.0, 0.2],
        [6, 5, 30, 1.5, 0.3],
        [6, 3, 40, 2.0, 0.4]
    ])

    # 监测值
    monitor = np.array([7.2, 5.8, 22, 0.8, 0.15])

    # 均值化
    ref = monitor / monitor.mean()
    std_mean = standard.mean(axis=1, keepdims=True)
    std_std = standard / std_mean

    delta = np.abs(std_std - ref)
    delta_min = delta.min()
    delta_max = delta.max()

    rho = 0.5
    xi = (delta_min + rho * delta_max) / (delta + rho * delta_max)
    r = xi.mean(axis=1)

    print("水质灰色关联评价")
    print("=" * 45)
    for i in np.argsort(-r):
        print(f"  {grades[i]}: 关联度={r[i]:.4f}")
    print(f"\n监测水质判定为: {grades[np.argmax(r)]}")

water_quality_gra()
```

## 七、灰色关联的扩展方法

### 7.1 灰色关联聚类

利用关联度矩阵进行聚类分析，将关联度较高的对象归为一类。

### 7.2 灰色关联优势分析

判断哪些因素对参考序列的影响最大：

$$
r_{0j} = \frac{1}{m} \sum_{i=1}^{m} \xi_{0j}(i)
$$

$r_{0j}$ 越大，说明第 $j$ 个因素对系统行为的影响越显著。

### 7.3 灰色关联+熵权法

用熵权法确定权重，再计算加权关联度，减少主观性。

## 八、注意事项

1. **参考序列选择**：参考序列的选取直接影响评价结果
2. **无量纲化方法**：初值化适合时间序列，均值化适合截面数据
3. **分辨系数取值**：通常取 0.5，可根据数据特性调整
4. **指标正向化**：评价前需统一指标方向
5. **数据量要求**：灰色关联对小样本评价效果较好

## 九、关键要点总结

| 要点 | 内容 |
|:--|:--|
| 核心思想 | 序列几何相似性度量 |
| 关联系数 | $\xi_i(k) = \frac{\Delta_{\min} + \rho\Delta_{\max}}{\Delta_i(k) + \rho\Delta_{\max}}$ |
| 关联度 | 关联系数的均值或加权平均 |
| 分辨系数 | $\rho \in (0,1)$，通常取 0.5 |
| 无量纲化 | 初值化、均值化、极差化 |
| 优势 | 小样本、少数据适用 |
| 局限 | 分辨系数选择具有主观性 |

灰色关联评价法特别适合数据量少、信息不完全的评价问题，是数学建模中处理不确定性问题的重要工具。在实际应用中，应合理选择参考序列、无量纲化方法和分辨系数，以保证评价结果的可靠性。
