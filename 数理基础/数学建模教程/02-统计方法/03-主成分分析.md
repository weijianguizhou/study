# 主成分分析

## 1. 主成分分析概述

主成分分析（Principal Component Analysis, PCA）是一种常用的降维技术，通过正交变换将原始变量转换为少数几个互不相关的综合变量（主成分），同时尽可能保留原始数据中的信息。

### 1.1 基本思想

- 将 $p$ 个相关变量转换为 $m$ 个不相关变量（$m \leq p$）
- 第一主成分包含最大方差
- 后续主成分依次包含剩余方差的最大部分
- 各主成分之间互不相关（正交）

### 1.2 目标

$$
\max \text{Var}(\mathbf{a}^T \mathbf{X}) \quad \text{s.t.} \quad \|\mathbf{a}\| = 1
$$

即寻找投影方向 $\mathbf{a}$，使得数据在该方向上的方差最大。

## 2. 数学原理

### 2.1 协方差矩阵

设数据矩阵 $\mathbf{X}$ 为 $n \times p$ 维（$n$ 个样本，$p$ 个变量），样本协方差矩阵为：

$$
\mathbf{S} = \frac{1}{n-1} \mathbf{X}_c^T \mathbf{X}_c
$$

其中 $\mathbf{X}_c$ 为数据中心化后的矩阵。

相关矩阵（标准化后）：

$$
\mathbf{R} = \frac{1}{n-1} \mathbf{Z}^T \mathbf{Z}
$$

其中 $\mathbf{Z}$ 为标准化后的数据矩阵，$R_{ij} = \frac{S_{ij}}{\sqrt{S_{ii}S_{jj}}}$。

### 2.2 特征值分解

对协方差矩阵 $\mathbf{S}$ 进行特征值分解：

$$
\mathbf{S} = \mathbf{U} \boldsymbol{\Lambda} \mathbf{U}^T
$$

其中：
- $\mathbf{U} = [\mathbf{u}_1, \mathbf{u}_2, \ldots, \mathbf{u}_p]$ 为特征向量矩阵（正交矩阵）
- $\boldsymbol{\Lambda} = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_p)$ 为特征值矩阵，$\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_p \geq 0$

### 2.3 主成分的计算

第 $k$ 个主成分为原始变量的线性组合：

$$
Z_k = \mathbf{u}_k^T \mathbf{X} = u_{k1}X_1 + u_{k2}X_2 + \cdots + u_{kp}X_p
$$

主成分的方差等于对应的特征值：

$$
\text{Var}(Z_k) = \lambda_k
$$

主成分之间的协方差为零：

$$
\text{Cov}(Z_i, Z_j) = 0, \quad i \neq j
$$

### 2.4 信息保留率

第 $k$ 个主成分的贡献率：

$$
\text{贡献率}_k = \frac{\lambda_k}{\sum_{i=1}^{p} \lambda_i}
$$

前 $m$ 个主成分的累计贡献率：

$$
\text{累计贡献率} = \frac{\sum_{k=1}^{m} \lambda_k}{\sum_{i=1}^{p} \lambda_i}
$$

通常要求累计贡献率达到 85% 以上。

## 3. 主成分的性质

### 3.1 方差最大化

第一主成分 $Z_1 = \mathbf{u}_1^T \mathbf{X}$ 是所有单位向量 $\mathbf{a}$ 中使 $\text{Var}(\mathbf{a}^T\mathbf{X})$ 最大的方向。

证明：设 $\mathbf{S} = \mathbf{U}\boldsymbol{\Lambda}\mathbf{U}^T$，令 $\mathbf{a} = \mathbf{U}\mathbf{c}$，则：

$$
\text{Var}(\mathbf{a}^T\mathbf{X}) = \mathbf{a}^T\mathbf{S}\mathbf{a} = \mathbf{c}^T\boldsymbol{\Lambda}\mathbf{c} = \sum_{i=1}^{p} \lambda_i c_i^2
$$

在约束 $\|\mathbf{a}\| = 1$（即 $\|\mathbf{c}\| = 1$）下，$\sum c_i^2 = 1$，上式在 $c_1 = 1, c_2 = \cdots = c_p = 0$ 时取最大值 $\lambda_1$。

### 3.2 载荷矩阵

载荷（Loading）反映主成分与原始变量之间的相关关系：

$$
l_{jk} = u_{jk} \sqrt{\lambda_k}
$$

$$
\text{Corr}(X_j, Z_k) = l_{jk} = u_{jk}\sqrt{\lambda_k}
$$

### 3.3 得分

每个样本在第 $k$ 个主成分上的得分：

$$
z_{ik} = \mathbf{x}_i^T \mathbf{u}_k = \sum_{j=1}^{p} u_{jk} x_{ij}
$$

## 4. 主成分的选择

### 4.1 累计贡献率准则

选择使累计贡献率达到预定阈值（如85%、90%）的最小主成分数 $m$：

$$
\frac{\sum_{k=1}^{m} \lambda_k}{\sum_{i=1}^{p} \lambda_i} \geq \alpha
$$

### 4.2 Kaiser准则

选择特征值 $\lambda_k > 1$ 的主成分（适用于标准化数据，此时总方差等于变量数 $p$）。

### 4.3 Scree图（碎石图）

绘制特征值的碎石图，选择特征值下降趋势变缓的"拐点"处作为截断点。

### 4.4 平行分析

将实际特征值与随机数据的特征值进行比较，选择实际特征值大于随机特征值的主成分。

## 5. 数据标准化

### 5.1 为什么需要标准化

当变量的量纲或数量级不同时，协方差矩阵受量纲影响较大。使用相关矩阵（即对标准化数据进行PCA）可以消除量纲影响。

### 5.2 标准化方法

$$
Z_{ij} = \frac{X_{ij} - \bar{X}_j}{S_j}
$$

其中 $\bar{X}_j$ 和 $S_j$ 分别为第 $j$ 个变量的均值和标准差。

## 6. 主成分回归

当自变量之间存在多重共线性时，可以使用主成分回归（PCR）：

1. 对自变量进行PCA，得到主成分 $Z_1, Z_2, \ldots, Z_m$
2. 用前 $m$ 个主成分对因变量 $Y$ 进行回归：

$$
Y = \beta_0 + \beta_1 Z_1 + \beta_2 Z_2 + \cdots + \beta_m Z_m + \varepsilon
$$

3. 将结果转换回原始变量空间

## 7. 核PCA（非线性PCA）

当数据存在非线性结构时，可以使用核PCA。其基本思想是将数据映射到高维特征空间，在高维空间中进行线性PCA。

核函数选择：

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)
$$

常用核函数：
- 多项式核：$K(\mathbf{x}, \mathbf{y}) = (\mathbf{x}^T\mathbf{y} + c)^d$
- RBF核：$K(\mathbf{x}, \mathbf{y}) = \exp(-\gamma\|\mathbf{x} - \mathbf{y}\|^2)$

## 8. Python实现

### 8.1 基本PCA

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 示例数据：5个变量，20个样本
np.random.seed(42)
n, p = 20, 5
X = np.random.randn(n, p)
# 添加相关性
X[:, 1] = X[:, 0] * 0.8 + np.random.randn(n) * 0.3
X[:, 2] = X[:, 0] * 0.5 + np.random.randn(n) * 0.5

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# PCA
pca = PCA()
X_pca = pca.fit_transform(X_scaled)

print("各主成分的方差解释比例:")
for i, ratio in enumerate(pca.explained_variance_ratio_):
    print(f"  PC{i+1}: {ratio:.4f} (累计: {sum(pca.explained_variance_ratio_[:i+1]):.4f})")

print(f"\n特征值: {pca.explained_variance_}")
print(f"载荷矩阵:\n{pca.components_}")
```

```python
import matplotlib.pyplot as plt

```

### 8.3 手动实现PCA

```python
import numpy as np

def my_pca(X, n_components=None):
    """手动实现PCA"""
    # 中心化
    X_centered = X - np.mean(X, axis=0)
    
    # 计算协方差矩阵
    cov_matrix = np.cov(X_centered, rowvar=False)
    
    # 特征值分解
    eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
    
    # 按特征值降序排列
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]
    
    # 选择主成分
    if n_components is not None:
        eigenvectors = eigenvectors[:, :n_components]
        eigenvalues = eigenvalues[:n_components]
    
    # 计算得分
    scores = X_centered @ eigenvectors
    
    # 计算贡献率
    explained_variance_ratio = eigenvalues / np.sum(np.linalg.eigvalsh(cov_matrix))
    
    return scores, eigenvalues, eigenvectors, explained_variance_ratio

scores, eigenvalues, eigenvectors, ratios = my_pca(X_scaled, n_components=3)
print(f"前3个主成分贡献率: {ratios}")
print(f"累计贡献率: {np.sum(ratios):.4f}")
```

## 9. 实际应用案例：学生综合素质评价

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# 学生数据：数学、物理、化学、语文、英语成绩
np.random.seed(42)
n_students = 50
data = {
    '数学': np.random.normal(75, 15, n_students),
    '物理': np.random.normal(70, 12, n_students),
    '化学': np.random.normal(72, 10, n_students),
    '语文': np.random.normal(80, 8, n_students),
    '英语': np.random.normal(78, 9, n_students)
}

# 添加学科间的相关性
data['物理'] = data['数学'] * 0.7 + np.random.normal(0, 5, n_students)
data['化学'] = data['数学'] * 0.5 + np.random.normal(0, 6, n_students)

import pandas as pd
df = pd.DataFrame(data)

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)

# PCA
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

print("主成分载荷:")
for i in range(2):
    print(f"PC{i+1}: ", end="")
    for j, col in enumerate(df.columns):
        print(f"{col}={pca.components_[i,j]:.3f} ", end="")
    print()

print(f"\n累计贡献率: {sum(pca.explained_variance_ratio_):.4f}")
```

## 10. PCA的局限性

1. **线性假设**：PCA只能捕捉线性结构
2. **方差最大化**：可能选择方差大但与目标无关的方向
3. **可解释性**：主成分的解释可能不够直观
4. **对异常值敏感**：少数异常值可能显著影响结果
5. **尺度敏感**：必须标准化（或使用相关矩阵）

## 11. 关键要点总结

| 要点 | 内容 |
|------|------|
| 核心思想 | 正交变换，方差最大化 |
| 数学基础 | 协方差矩阵的特征值分解 |
| 主成分 | $Z_k = \mathbf{u}_k^T\mathbf{X}$，方差=$\lambda_k$ |
| 选择准则 | 累计贡献率≥85%，Kaiser准则，Scree图 |
| 标准化 | 变量量纲不同时必须标准化 |
| 载荷 | 反映主成分与原始变量的相关关系 |
| 应用 | 降维、可视化、去噪、主成分回归 |
| 注意 | 不适用于非线性结构、对异常值敏感 |
