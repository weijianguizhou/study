# 贝叶斯统计

> **理论基础** → 参见 [[../../统计学分析方法/贝叶斯统计|贝叶斯统计理论]]

贝叶斯统计将先验信息与样本数据结合进行统计推断，通过后验分布对未知参数做出概率描述。

## 五、MCMC 方法简介
### 5.1 为什么需要 MCMC

当后验分布没有解析解时，需要使用数值方法近似。马尔可夫链蒙特卡洛（MCMC）方法通过构造马尔可夫链来从后验分布中抽样。

### 5.2 Metropolis-Hastings 算法

```
输入：似然函数 f(x|θ)，先验 π(θ)，提议分布 q(θ*|θ^(t))
初始化：θ^(0)

for t = 1, 2, ..., T:
    1. 从 q(θ*|θ^(t-1)) 生成候选值 θ*
    2. 计算接受概率：
       α = min{1, [f(x|θ*) π(θ*) q(θ^(t-1)|θ*)] / [f(x|θ^(t-1)) π(θ^(t-1)) q(θ*|θ^(t-1))]}
    3. 从 Uniform(0,1) 抽取 u
    4. if u ≤ α:
           θ^(t) = θ*
       else:
           θ^(t) = θ^(t-1)
```

### 5.3 Gibbs 采样

Gibbs 采样是 Metropolis-Hastings 的特例，当条件分布 $P(\theta_i | \theta_{-i}, x)$ 可直接抽样时使用：

```
初始化：θ^(0) = (θ_1^(0), ..., θ_p^(0))

for t = 1, 2, ..., T:
    从 P(θ_1 | θ_2^(t-1), ..., θ_p^(t-1), x) 抽取 θ_1^(t)
    从 P(θ_2 | θ_1^(t), θ_3^(t-1), ..., θ_p^(t-1), x) 抽取 θ_2^(t)
    ...
    从 P(θ_p | θ_1^(t), ..., θ_{p-1}^(t), x) 抽取 θ_p^(t)
```

## 七、Python 实现
### 7.1 二项分布的贝叶斯推断

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# 二项分布-贝塔共轭先验
alpha_prior, beta_prior = 2, 5  # 先验 Beta(2, 5)

# 观测数据
n_trials = 100
n_success = 65

# 后验参数
alpha_post = alpha_prior + n_success
beta_post = beta_prior + n_trials - n_success

# 后验分布
theta_range = np.linspace(0, 1, 1000)
prior_pdf = stats.beta.pdf(theta_range, alpha_prior, beta_prior)
posterior_pdf = stats.beta.pdf(theta_range, alpha_post, beta_post)

# 后验统计量
post_mean = alpha_post / (alpha_post + beta_post)
post_std = np.sqrt((alpha_post * beta_post) / 
                    ((alpha_post + beta_post)**2 * (alpha_post + beta_post + 1)))
hpd_low = stats.beta.ppf(0.025, alpha_post, beta_post)
hpd_high = stats.beta.ppf(0.975, alpha_post, beta_post)

print(f"先验: Beta({alpha_prior}, {beta_prior})")
print(f"后验: Beta({alpha_post}, {beta_post})")
print(f"后验均值: {post_mean:.4f}")
print(f"后验标准差: {post_std:.4f}")
print(f"95% 可信区间: [{hpd_low:.4f}, {hpd_high:.4f}]")
print(f"频率学派 MLE: {n_success/n_trials:.4f}")
```

### 7.2 MCMC 采样（Metropolis-Hastings）

```python
import numpy as np
from scipy import stats

# 目标：估计正态分布的均值 μ（已知 σ² = 1）
np.random.seed(42)
true_mu = 3.0
data = np.random.normal(true_mu, 1.0, size=50)

# 似然：Normal(μ, 1)
def log_likelihood(mu, data):
    return np.sum(stats.norm.logpdf(data, loc=mu, scale=1.0))

# 先验：Normal(0, 10²)
def log_prior(mu):
    return stats.norm.logpdf(mu, loc=0, scale=10.0)

def log_posterior(mu, data):
    return log_likelihood(mu, data) + log_prior(mu)

# Metropolis-Hastings
n_iter = 10000
mu_chain = np.zeros(n_iter)
mu_chain[0] = 0.0  # 初始值

proposal_sd = 0.5
accept_count = 0

for i in range(1, n_iter):
    # 提议
    mu_proposal = mu_chain[i-1] + np.random.normal(0, proposal_sd)
    
    # 接受概率
    log_alpha = log_posterior(mu_proposal, data) - log_posterior(mu_chain[i-1], data)
    
    if np.log(np.random.uniform()) < log_alpha:
        mu_chain[i] = mu_proposal
        accept_count += 1
    else:
        mu_chain[i] = mu_chain[i-1]

# 丢弃前 2000 个样本（burn-in）
burn_in = 2000
mu_samples = mu_chain[burn_in:]

print(f"接受率: {accept_count/n_iter:.4f}")
print(f"MCMC 后验均值: {np.mean(mu_samples):.4f}")
print(f"MCMC 后验标准差: {np.std(mu_samples):.4f}")
print(f"95% 可信区间: [{np.percentile(mu_samples, 2.5):.4f}, "
      f"{np.percentile(mu_samples, 97.5):.4f}]")
print(f"真实值: {true_mu}")
```

### 7.3 使用 PyMC3 进行贝叶斯回归

```python
# 需要安装: pip install pymc3 arviz
import numpy as np

# 模拟数据
np.random.seed(42)
n = 100
X = np.random.uniform(0, 10, n)
true_beta0, true_beta1 = 2.0, 1.5
Y = true_beta0 + true_beta1 * X + np.random.normal(0, 1.0, n)

print("=== 贝叶斯线性回归 ===")
print(f"数据点: {n}")
print(f"真实参数: β0={true_beta0}, β1={true_beta1}")

# 如果没有安装 pymc3，用简单的贝叶斯线性回归实现
from scipy import linalg

# 贝叶斯线性回归（解析解）
# 先验: β ~ N(0, τ²I), σ² 已知
tau_sq = 100  # 先验方差
sigma_sq = 1.0  # 假设已知

X_design = np.column_stack([np.ones(n), X])
# 后验协方差
posterior_cov = np.linalg.inv(X_design.T @ X_design / sigma_sq + np.eye(2) / tau_sq)
# 后验均值
posterior_mean = posterior_cov @ (X_design.T @ Y / sigma_sq)

print(f"\n贝叶斯后验均值:")
print(f"  β0 = {posterior_mean[0]:.4f}")
print(f"  β1 = {posterior_mean[1]:.4f}")

# 后验预测
X_new = np.array([[1, 5.0]])
pred_mean = X_new @ posterior_mean
pred_var = X_new @ posterior_cov @ X_new.T + sigma_sq
pred_std = np.sqrt(pred_var[0, 0])
print(f"\nx=5 时的后验预测:")
print(f"  均值: {pred_mean[0, 0]:.4f}")
print(f"  标准差: {pred_std:.4f}")
print(f"  95% 预测区间: [{pred_mean[0,0]-1.96*pred_std:.4f}, "
      f"{pred_mean[0,0]+1.96*pred_std:.4f}]")
```

### 7.4 后验预测检验

```python
import numpy as np
from scipy import stats

# 后验预测检验示例
np.random.seed(42)
n = 50
data = np.random.poisson(lam=3.5, size=n)

# 先验: Gamma(2, 0.5)
alpha_prior, beta_prior = 2, 0.5

# 后验
alpha_post = alpha_prior + np.sum(data)
beta_post = beta_prior + n

# 从后验抽样
n_samples = 1000
lambda_samples = np.random.gamma(alpha_post, 1/beta_post, n_samples)

# 后验预测
simulated_datasets = np.array([
    np.random.poisson(lam=lam, size=n) for lam in lambda_samples[:500]
])

# 计算检验统计量（方差/均值比）
observed_stat = np.var(data) / np.mean(data)
simulated_stats = np.var(simulated_datasets, axis=1) / np.mean(simulated_datasets, axis=1)

# 后验预测 p 值
ppp_value = np.mean(simulated_stats >= observed_stat)
print(f"观测数据方差/均值比: {observed_stat:.4f}")
print(f"后验预测 p 值: {ppp_value:.4f}")
print(f"（p 值接近 0.5 表示模型拟合良好）")

# 后验预测区间
pred_intervals = np.percentile(simulated_datasets, [2.5, 50, 97.5], axis=0)
print(f"\nx=0 的后验预测:")
print(f"  中位数: {pred_intervals[1, 0]:.0f}")
print(f"  95% 预测区间: [{pred_intervals[0, 0]:.0f}, {pred_intervals[2, 0]:.0f}]")
```

## 九、数学建模中的贝叶斯方法应用
### 9.1 应用场景

1. **小样本推断**：先验信息可以弥补数据不足
2. **参数不确定性量化**：后验分布自然给出参数的不确定性
3. **模型融合**：贝叶斯模型平均（BMA）融合多个模型的预测
4. **层次模型**：处理多层嵌套数据（如多城市、多时间段）
5. **缺失数据**：将缺失值作为参数进行联合推断

### 9.2 注意事项

- 先验选择应具有**实际意义**或使用**无信息先验**
- MCMC 需要检查**收敛性**（$\hat{R}$ 统计量 < 1.1）
- 后验预测检验是模型验证的重要步骤
- 样本量较小时，先验的影响较大，需谨慎选择

## 关键要点
1. **贝叶斯定理**：$\text{后验} \propto \text{似然} \times \text{先验}$，是贝叶斯推断的核心公式
2. **共轭先验**使后验有解析解：Beta-Binomial、Normal-Normal、Gamma-Poisson
3. **后验推断**包括点估计（后验均值/MAP）、区间估计（可信区间/HPD）、假设检验（贝叶斯因子）
4. **MCMC 方法**（MH、Gibbs）是后验分布无解析解时的标准数值方法
5. **后验预测分布**将参数不确定性纳入预测，$P(x_{\text{new}}|x) = \int f(x_{\text{new}}|\theta) \pi(\theta|x) d\theta$
6. 贝叶斯方法特别适合**小样本、层次结构、不确定性量化**的建模场景
7. 使用 MCMC 时必须检查**链的收敛性**（burn-in、$\hat{R}$、有效样本量）
8. 贝叶斯因子提供比 p 值更直观的假设比较证据
