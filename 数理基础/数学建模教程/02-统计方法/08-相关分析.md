# 相关分析

## 1. 相关分析概述

相关分析（Correlation Analysis）研究两个或多个变量之间关联的方向和程度。相关系数是度量变量间线性关系强度的统计量。

### 1.1 相关与因果

- **相关不等于因果**：两个变量相关不意味着一个导致另一个
- **相关的方向**：正相关（同向变化）、负相关（反向变化）、不相关
- **相关的强度**：$|r|$ 接近1表示强相关，接近0表示弱相关

## 2. Pearson相关系数

### 2.1 定义

对于连续变量 $X$ 和 $Y$，Pearson积矩相关系数为：

$$
r = \frac{\text{Cov}(X, Y)}{\sqrt{\text{Var}(X) \cdot \text{Var}(Y)}} = \frac{\sum_{i=1}^{n}(X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum_{i=1}^{n}(X_i - \bar{X})^2 \sum_{i=1}^{n}(Y_i - \bar{Y})^2}}
$$

### 2.2 性质

- $r \in [-1, 1]$
- $r > 0$：正相关；$r < 0$：负相关；$r = 0$：不相关
- $r = \pm 1$：完全线性相关
- 对变量的线性变换不变：$r(aX+b, cY+d) = r(X,Y)$（$a, c$ 同号时）
- 反映的是**线性**关系

### 2.3 检验

检验 $H_0: \rho = 0$（总体相关系数为零）：

$$
t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}} \sim t(n-2)
$$

### 2.4 相关系数的置信区间

Fisher Z变换：

$$
Z = \frac{1}{2}\ln\frac{1+r}{1-r} = \text{arctanh}(r)
$$

$Z$ 近似服从正态分布：

$$
Z \sim N\left(\frac{1}{2}\ln\frac{1+\rho}{1-\rho}, \frac{1}{n-3}\right)
$$

置信区间：

$$
Z \pm z_{\alpha/2} \cdot \frac{1}{\sqrt{n-3}}
$$

反变换回 $r$：

$$
r = \frac{e^{2Z} - 1}{e^{2Z} + 1} = \tanh(Z)
$$

## 3. Spearman秩相关系数

### 3.1 定义

当变量不服从正态分布或存在非线性单调关系时，使用Spearman秩相关系数：

$$
r_s = 1 - \frac{6\sum_{i=1}^{n} d_i^2}{n(n^2 - 1)}
$$

其中 $d_i = \text{rank}(X_i) - \text{rank}(Y_i)$ 为秩次之差。

### 3.2 一般形式

Spearman相关系数等价于对秩次计算的Pearson相关系数：

$$
r_s = \frac{\sum_{i=1}^{n}(\text{rank}(X_i) - \overline{\text{rank}(X)})(\text{rank}(Y_i) - \overline{\text{rank}(Y)})}{\sqrt{\sum_{i=1}^{n}(\text{rank}(X_i) - \overline{\text{rank}(X)})^2 \sum_{i=1}^{n}(\text{rank}(Y_i) - \overline{\text{rank}(Y)})^2}}
$$

### 3.3 检验

对于大样本（$n > 30$）：

$$
Z = r_s \sqrt{n-1} \sim N(0, 1)
$$

## 4. Kendall $\tau$ 秩相关系数

### 4.1 定义

Kendall $\tau$ 基于一致对（concordant）和不一致对（discordant）的数量：

$$
\tau = \frac{C - D}{\binom{n}{2}} = \frac{C - D}{n(n-1)/2}
$$

其中：
- $C$ 为一致对数：$x_i > x_j$ 且 $y_i > y_j$（或同方向）
- $D$ 为不一致对数：$x_i > x_j$ 且 $y_i < y_j$

### 4.2 性质

- $\tau \in [-1, 1]$
- 对异常值比Spearman更鲁棒
- 适用于有序分类数据

## 5. 偏相关分析

### 5.1 定义

在控制其他变量影响的条件下，度量两个变量之间的净相关关系。

控制变量 $Z$ 后，$X$ 和 $Y$ 的偏相关系数：

$$
r_{XY \cdot Z} = \frac{r_{XY} - r_{XZ}r_{YZ}}{\sqrt{(1 - r_{XZ}^2)(1 - r_{YZ}^2)}}
$$

### 5.2 一般公式

控制 $k$ 个变量 $\mathbf{Z} = (Z_1, \ldots, Z_k)$ 后，$X$ 和 $Y$ 的偏相关系数：

$$
r_{XY \cdot \mathbf{Z}} = -\frac{P_{XY}}{\sqrt{P_{XX} P_{YY}}}
$$

其中 $P_{XY}$ 为精度矩阵（逆协方差矩阵）的对应元素。

### 5.3 偏相关矩阵

$$
\mathbf{P} = \boldsymbol{\Sigma}^{-1}
$$

其中 $\boldsymbol{\Sigma}$ 为相关矩阵。

## 6. 复相关分析

### 6.1 定义

复相关系数（Multiple Correlation Coefficient）衡量一个变量与多个变量之间的整体相关程度：

$$
R_{Y \cdot X_1 X_2 \cdots X_p} = \sqrt{1 - \frac{|\mathbf{R}|}{R_{YY}}}
$$

等价于 $Y$ 与 $Y$ 的回归预测值 $\hat{Y}$ 之间的Pearson相关系数：

$$
R = r(Y, \hat{Y}) = \sqrt{R^2}
$$

### 6.2 与简单相关系数的关系

$$
R \geq |r_{XY_j}| \quad \text{for all } j
$$

即复相关系数不小于任何简单的相关系数。

## 7. 等级相关与关联度

### 7.1 典型相关分析（CCA）

研究两组变量之间的整体相关关系。

设有两组变量 $\mathbf{X} = (X_1, \ldots, X_p)^T$ 和 $\mathbf{Y} = (Y_1, \ldots, Y_q)^T$，寻找线性组合：

$$
U = \mathbf{a}^T\mathbf{X}, \quad V = \mathbf{b}^T\mathbf{Y}
$$

使得 $\text{Corr}(U, V)$ 最大。

### 7.2 求解

$$
\max_{\mathbf{a}, \mathbf{b}} \frac{\mathbf{a}^T \boldsymbol{\Sigma}_{XY} \mathbf{b}}{\sqrt{\mathbf{a}^T \boldsymbol{\Sigma}_{XX} \mathbf{a}} \sqrt{\mathbf{b}^T \boldsymbol{\Sigma}_{YY} \mathbf{b}}}
$$

求解广义特征值问题：

$$
\boldsymbol{\Sigma}_{XX}^{-1} \boldsymbol{\Sigma}_{XY} \boldsymbol{\Sigma}_{YY}^{-1} \boldsymbol{\Sigma}_{YX} \mathbf{a} = \lambda^2 \mathbf{a}
$$

## 8. Python实现

### 8.1 Pearson相关系数

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# 示例数据
np.random.seed(42)
X = np.random.randn(100)
Y = 2 * X + np.random.randn(100) * 0.5
Z = -X + np.random.randn(100) * 0.8

# Pearson相关系数
r_XY, p_XY = stats.pearsonr(X, Y)
r_XZ, p_XZ = stats.pearsonr(X, Z)

print(f"Pearson相关系数:")
print(f"  X-Y: r={r_XY:.4f}, p={p_XY:.6f}")
print(f"  X-Z: r={r_XZ:.4f}, p={p_XZ:.6f}")

# 散点图
fig, axes = plt.subplots(1, 2, figsize=(12, 5))
axes[0].scatter(X, Y, alpha=0.5)
axes[0].set_title(f'X-Y: r={r_XY:.4f}')
axes[0].set_xlabel('X')
axes[0].set_ylabel('Y')

axes[1].scatter(X, Z, alpha=0.5)
axes[1].set_title(f'X-Z: r={r_XZ:.4f}')
axes[1].set_xlabel('X')
axes[1].set_ylabel('Z')

plt.tight_layout()
plt.show()
```

### 8.2 Spearman秩相关系数

```python
from scipy.stats import spearmanr, kendalltau

# 示例数据（非线性单调关系）
t = np.linspace(0, 2*np.pi, 100)
X = np.sin(t) + np.random.randn(100) * 0.1
Y = np.sin(t)**3 + np.random.randn(100) * 0.1

# Spearman相关
r_s, p_s = spearmanr(X, Y)
print(f"Spearman相关系数: r_s={r_s:.4f}, p={p_s:.6f}")

# Kendall tau
tau, p_tau = kendalltau(X, Y)
print(f"Kendall tau: τ={tau:.4f}, p={p_tau:.6f}")
```

### 8.3 偏相关分析

```python
import numpy as np
from pingouin import partial_corr
import pandas as pd

# 生成示例数据
np.random.seed(42)
n = 100
X = np.random.randn(n)
Z = 0.5 * X + np.random.randn(n) * 0.5
Y = 0.6 * X + 0.3 * Z + np.random.randn(n) * 0.3

df = pd.DataFrame({'X': X, 'Y': Y, 'Z': Z})

# 简单相关
r_simple = np.corrcoef(X, Y)[0, 1]
print(f"简单相关系数: r={r_simple:.4f}")

# 偏相关（控制Z）
result = partial_corr(data=df, x='X', y='Y', covar='Z')
print(f"偏相关系数: r={result['r'].values[0]:.4f}, p={result['p-val'].values[0]:.6f}")
```

### 8.4 相关矩阵热力图

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 多变量数据
np.random.seed(42)
n = 200
data = {
    '身高': np.random.normal(170, 10, n),
    '体重': np.random.normal(65, 12, n),
    '年龄': np.random.normal(30, 8, n),
    '收入': np.random.normal(10000, 3000, n),
    '教育': np.random.normal(14, 3, n)
}
df = pd.DataFrame(data)
# 添加相关性
df['体重'] = 0.5 * df['身高'] + np.random.randn(n) * 5
df['收入'] = 0.4 * df['教育'] + np.random.randn(n) * 2000

# 相关矩阵
corr_matrix = df.corr()

# 热力图
plt.figure(figsize=(8, 6))
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm', center=0,
            fmt='.3f', square=True)
plt.title('相关矩阵热力图')
plt.show()
```

## 9. 实际应用案例：教育数据分析

```python
import numpy as np
import pandas as pd
from scipy import stats

# 学生数据
np.random.seed(42)
n = 150
data = {
    '学习时间': np.random.exponential(3, n),
    '考试成绩': np.random.normal(75, 15, n),
    '睡眠时间': np.random.normal(7, 1, n),
    '课外活动': np.random.poisson(3, n)
}
df = pd.DataFrame(data)
# 添加相关性
df['考试成绩'] = 70 + 5 * df['学习时间'] + 0.5 * df['睡眠时间'] + np.random.randn(n) * 8

# 各变量间相关系数
print("Pearson相关系数:")
for i, col1 in enumerate(df.columns):
    for j, col2 in enumerate(df.columns):
        if i < j:
            r, p = stats.pearsonr(df[col1], df[col2])
            sig = "***" if p < 0.001 else "**" if p < 0.01 else "*" if p < 0.05 else ""
            print(f"  {col1} vs {col2}: r={r:.4f}, p={p:.4f} {sig}")

# Fisher Z变换比较两个相关系数
r1, _ = stats.pearsonr(df['学习时间'], df['考试成绩'])
r2, _ = stats.pearsonr(df['睡眠时间'], df['考试成绩'])
n1 = n2 = n

z1 = np.arctanh(r1)
z2 = np.arctanh(r2)
z_diff = (z1 - z2) / np.sqrt(1/(n1-3) + 1/(n2-3))
p_diff = 2 * (1 - stats.norm.cdf(abs(z_diff)))
print(f"\n两个相关系数差异检验: z={z_diff:.4f}, p={p_diff:.4f}")
```

## 10. 常见误区

1. **非线性关系**：Pearson相关系数只能检测线性关系
2. **异常值敏感**：一个异常值可能大幅改变相关系数
3. **辛普森悖论**：分组数据可能显示相反的相关方向
4. **样本量影响**：大样本时微弱相关也可能显著
5. **相关不等于因果**：需要实验设计或因果推断方法

## 11. 关键要点总结

| 要点 | 内容 |
|------|------|
| Pearson r | 度量线性相关，$r \in [-1,1]$ |
| Spearman $r_s$ | 基于秩次，适用于单调非线性关系 |
| Kendall $\tau$ | 基于一致对，对异常值鲁棒 |
| 偏相关 | 控制其他变量后的净相关 |
| 复相关 | 一个变量与多个变量的整体相关 |
| 检验 | $t$ 检验、Fisher Z变换 |
| 注意 | 相关≠因果、非线性、异常值 |
