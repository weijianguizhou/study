# 非参数检验

## 一、概述

非参数检验（Non-parametric Tests）是一类不依赖于总体分布具体形式的统计检验方法，也称为**分布自由检验**（Distribution-free Tests）。当数据不满足参数检验所要求的正态性、方差齐性等假设时，非参数检验是更可靠的选择。

### 1.1 参数检验与非参数检验的对比

| 特征 | 参数检验 | 非参数检验 |
|------|----------|------------|
| 分布假设 | 假设总体服从特定分布（如正态分布） | 不依赖总体分布形式 |
| 检验对象 | 均值、方差等参数 | 分布位置、中位数、分布形状 |
| 统计量 | 基于样本均值和方差 | 基于秩次、符号、排列 |
| 检验效能 | 满足假设时最高 | 略低于参数检验（通常为参数检验的95%） |
| 数据要求 | 连续型数据 | 连续或有序分类数据 |
| 适用场景 | 大样本、正态分布数据 | 小样本、偏态分布、含离群值数据 |

### 1.2 何时选择非参数检验

- **样本量小**：$n < 30$ 时，难以验证正态性假设
- **数据分布未知或偏态**：无法确定总体分布
- **存在离群值**：非参数检验基于秩次，对离群值不敏感
- **序数数据**：如 Likert 量表评分（1-5分）
- **方差不齐**：两组或多组方差差异较大

## 二、Wilcoxon 符号秩检验

### 2.1 基本思想

Wilcoxon 符号秩检验（Wilcoxon Signed-Rank Test）是配对样本 t 检验的非参数替代方法，用于检验**两个相关样本**或**单个样本的中位数**是否与假设值有显著差异。

### 2.2 检验步骤

**假设设定：**

$$H_0: \text{中位数} = \mu_0 \quad \text{vs} \quad H_1: \text{中位数} \neq \mu_0$$

**计算步骤：**

1. 计算每对观测值的差值 $d_i = x_i - \mu_0$（去掉 $d_i = 0$ 的配对）
2. 取绝对值 $|d_i|$，对绝对值赋予秩次 $R_i$
3. 对正差值和负差值分别求秩和：

$$W^+ = \sum_{d_i > 0} R_i, \quad W^- = \sum_{d_i < 0} R_i$$

4. 取检验统计量 $T = \min(W^+, W^-)$

**正态近似（$n > 20$ 时）：**

$$Z = \frac{T - E(T)}{\text{Var}(T)} = \frac{T - \frac{n(n+1)}{4}}{\sqrt{\frac{n(n+1)(2n+1)}{24}}}$$

其中 $n$ 为非零差值的个数。

### 2.3 Python 实现

```python
import numpy as np
from scipy import stats

# 示例数据：10名患者的治疗前后血压
before = np.array([142, 135, 150, 148, 155, 130, 160, 138, 145, 152])
after = np.array([130, 132, 140, 135, 142, 125, 148, 130, 138, 140])

# 方法一：scipy 直接检验
statistic, p_value = stats.wilcoxon(before, after)
print(f"Wilcoxon 统计量: {statistic:.4f}")
print(f"p 值: {p_value:.4f}")

# 方法二：手动计算
diff = before - after
diff_nonzero = diff[diff != 0]
ranks = stats.rankdata(np.abs(diff_nonzero))
W_plus = np.sum(ranks[diff_nonzero > 0])
W_minus = np.sum(ranks[diff_nonzero < 0])
T_stat = min(W_plus, W_minus)
print(f"W+ = {W_plus}, W- = {W_minus}, T = {T_stat}")

# 判断结果
alpha = 0.05
if p_value < alpha:
    print("拒绝 H0：治疗前后血压有显著差异")
else:
    print("不拒绝 H0：治疗前后血压无显著差异")
```

### 2.4 数学建模应用

在数学建模中，Wilcoxon 符号秩检验常用于：

- **干预效果评估**：比较某种策略实施前后的指标变化
- **模型对比**：比较两种算法在同一数据集上的表现差异
- **稳定性分析**：检验多次运行结果的中位数是否偏离期望值

## 三、Mann-Whitney U 检验

### 3.1 基本思想

Mann-Whitney U 检验（也称 Wilcoxon 秩和检验）是独立样本 t 检验的非参数替代，用于检验**两个独立样本**是否来自同一分布（或同一中位数）。

### 3.2 检验步骤

**假设设定：**

$$H_0: F_1(x) = F_2(x) \quad \text{vs} \quad H_1: F_1(x) \neq F_2(x)$$

**计算步骤：**

1. 将两组样本混合，按从小到大排列赋予秩次
2. 分别计算两组的秩和 $R_1$ 和 $R_2$
3. 计算 U 统计量：

$$U_1 = n_1 n_2 + \frac{n_1(n_1+1)}{2} - R_1$$

$$U_2 = n_1 n_2 + \frac{n_2(n_2+1)}{2} - R_2$$

$$U = \min(U_1, U_2)$$

**正态近似（$n_1, n_2 > 10$ 时）：**

$$Z = \frac{U - \frac{n_1 n_2}{2}}{\sqrt{\frac{n_1 n_2 (n_1 + n_2 + 1)}{12}}}$$

### 3.3 Python 实现

```python
import numpy as np
from scipy import stats

# 示例数据：两种教学方法的考试成绩
method_a = np.array([85, 78, 92, 88, 76, 95, 82, 90, 73, 87])
method_b = np.array([72, 68, 80, 75, 85, 70, 78, 82, 65, 77])

# scipy 直接检验
statistic, p_value = stats.mannwhitneyu(method_a, method_b, alternative='two-sided')
print(f"U 统计量: {statistic:.4f}")
print(f"p 值: {p_value:.4f}")

# 效应量（r = Z / sqrt(N)）
n1, n2 = len(method_a), len(method_b)
z_score = stats.norm.ppf(1 - p_value / 2)
effect_size = z_score / np.sqrt(n1 + n2)
print(f"效应量 r: {effect_size:.4f}")

# 判断
alpha = 0.05
if p_value < alpha:
    print("两种教学方法的成绩分布有显著差异")
else:
    print("两种教学方法的成绩分布无显著差异")
```

### 3.4 效应量计算

$$r = \frac{Z}{\sqrt{N}}$$

其中 $N = n_1 + n_2$，$r$ 值解释：$|r| < 0.1$ 微小效应，$0.1 \leq |r| < 0.3$ 小效应，$0.3 \leq |r| < 0.5$ 中效应，$|r| \geq 0.5$ 大效应。

## 四、Kruskal-Wallis 检验

### 4.1 基本思想

Kruskal-Wallis 检验是单因素方差分析（ANOVA）的非参数替代，用于检验**三个或更多独立样本**是否来自同一分布。

### 4.2 检验统计量

$$H = \frac{12}{N(N+1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i} - 3(N+1)$$

其中：
- $k$：组数
- $n_i$：第 $i$ 组的样本量
- $R_i$：第 $i$ 组的秩和
- $N = \sum_{i=1}^{k} n_i$：总样本量

当存在结（tie）时，修正为：

$$H_{\text{adj}} = \frac{H}{1 - \frac{\sum_{j=1}^{g}(t_j^3 - t_j)}{N^3 - N}}$$

其中 $g$ 为结的组数，$t_j$ 为第 $j$ 个结中相同观测值的个数。

$H$ 统计量近似服从自由度为 $k-1$ 的 $\chi^2$ 分布。

### 4.3 Python 实现

```python
import numpy as np
from scipy import stats

# 示例数据：三种不同材料的强度
material_a = np.array([45, 42, 48, 44, 40, 46])
material_b = np.array([50, 47, 52, 55, 48, 51])
material_c = np.array([38, 35, 40, 36, 42, 37])

# Kruskal-Wallis 检验
statistic, p_value = stats.kruskal(material_a, material_b, material_c)
print(f"Kruskal-Wallis H 统计量: {statistic:.4f}")
print(f"p 值: {p_value:.4f}")

# 事后比较：成对 Mann-Whitney U 检验（Bonferroni 校正）
from itertools import combinations
groups = {'A': material_a, 'B': material_b, 'C': material_c}
alpha = 0.05
n_comparisons = len(list(combinations(groups.keys(), 2)))
bonferroni_alpha = alpha / n_comparisons

for (name1, g1), (name2, g2) in combinations(groups.items(), 2):
    _, p = stats.mannwhitneyu(g1, g2, alternative='two-sided')
    sig = "显著" if p < bonferroni_alpha else "不显著"
    print(f"{name1} vs {name2}: p = {p:.4f} ({sig})")
```

## 五、卡方检验

### 5.1 卡方独立性检验

卡方检验用于检验两个分类变量之间是否存在关联。

**检验统计量：**

$$\chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{c} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$

其中：
- $O_{ij}$：观察频数
- $E_{ij} = \frac{R_i \cdot C_j}{N}$：期望频数
- $R_i$：第 $i$ 行合计，$C_j$：第 $j$ 列合计，$N$：总样本量

$\chi^2$ 统计量服从自由度为 $(r-1)(c-1)$ 的卡方分布。

### 5.2 卡方拟合优度检验

检验样本是否来自某个特定分布：

$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}$$

自由度为 $k - 1 - p$，其中 $p$ 为从数据中估计的参数个数。

### 5.3 Python 实现

```python
import numpy as np
from scipy import stats

# 卡方独立性检验：性别与产品偏好
observed = np.array([
    [50, 30, 20],   # 男性
    [35, 45, 20]    # 女性
])
chi2, p_value, dof, expected = stats.chi2_contingency(observed)
print(f"χ² = {chi2:.4f}, p = {p_value:.4f}, df = {dof}")
print("期望频数：")
print(expected)

# 卡方拟合优度检验
observed_freq = np.array([25, 30, 20, 15, 10])
expected_freq = np.array([20, 20, 20, 20, 20])
chi2, p_value = stats.chisquare(observed_freq, f_exp=expected_freq)
print(f"\n拟合优度检验: χ² = {chi2:.4f}, p = {p_value:.4f}")
```

### 5.4 注意事项

- 每个单元格的期望频数应 $\geq 5$，否则需使用 Fisher 精确检验
- 样本量应足够大，通常 $N \geq 40$
- 分类变量的类别应互斥且穷尽

## 六、Kolmogorov-Smirnov 检验

### 6.1 单样本 K-S 检验

K-S 检验用于检验样本是否来自某个指定的理论分布。

**检验统计量：**

$$D = \sup_x |F_n(x) - F_0(x)|$$

其中 $F_n(x)$ 为经验分布函数，$F_0(x)$ 为假设的理论分布函数。

**经验分布函数：**

$$F_n(x) = \frac{1}{n} \sum_{i=1}^{n} I(X_i \leq x)$$

### 6.2 双样本 K-S 检验

检验两个样本是否来自同一分布：

$$D = \sup_x |F_{n_1}(x) - F_{n_2}(x)|$$

### 6.3 Python 实现

```python
import numpy as np
from scipy import stats

# 单样本 K-S 检验：检验是否服从正态分布
np.random.seed(42)
data = np.random.normal(loc=50, scale=10, size=100)

# K-S 检验正态性
statistic, p_value = stats.kstest(data, 'norm', args=(np.mean(data), np.std(data, ddof=1)))
print(f"单样本 K-S 检验: D = {statistic:.4f}, p = {p_value:.4f}")

# 也可以使用 Shapiro-Wilk 检验（小样本更精确）
sw_stat, sw_p = stats.shapiro(data)
print(f"Shapiro-Wilk 检验: W = {sw_stat:.4f}, p = {sw_p:.4f}")

# 双样本 K-S 检验
sample1 = np.random.normal(50, 10, 80)
sample2 = np.random.normal(55, 12, 80)
statistic, p_value = stats.ks_2samp(sample1, sample2)
print(f"\n双样本 K-S 检验: D = {statistic:.4f}, p = {p_value:.4f}")

# K-S 检验在模型验证中的应用
simulated = np.random.exponential(scale=2.0, size=200)
actual = np.random.exponential(scale=2.0, size=200)
stat, p = stats.ks_2samp(simulated, actual)
print(f"\n模型验证 K-S 检验: D = {stat:.4f}, p = {p:.4f}")
```

## 七、综合案例：数学建模中的非参数检验

### 7.1 案例：多城市空气质量评价

```python
import numpy as np
from scipy import stats
import warnings
warnings.filterwarnings('ignore')

# 五个城市的空气质量指数（AQI）数据
city_a = np.array([65, 72, 58, 80, 55, 68, 75, 62, 70, 59])
city_b = np.array([85, 92, 78, 88, 95, 82, 90, 87, 93, 80])
city_c = np.array([45, 52, 38, 55, 42, 48, 50, 44, 53, 40])
city_d = np.array([110, 98, 105, 115, 95, 108, 102, 112, 99, 106])
city_e = np.array([70, 75, 68, 82, 72, 78, 74, 69, 80, 73])

# 步骤1：正态性检验
all_groups = [city_a, city_b, city_c, city_d, city_e]
city_names = ['A', 'B', 'C', 'D', 'E']
print("=== 正态性检验 (Shapiro-Wilk) ===")
all_normal = True
for name, group in zip(city_names, all_groups):
    _, p = stats.shapiro(group)
    status = "正态" if p > 0.05 else "非正态"
    print(f"城市 {name}: p = {p:.4f} ({status})")
    if p <= 0.05:
        all_normal = False

# 步骤2：Kruskal-Wallis 检验
print("\n=== Kruskal-Wallis 检验 ===")
H_stat, p_value = stats.kruskal(*all_groups)
print(f"H = {H_stat:.4f}, p = {p_value:.4f}")
if p_value < 0.05:
    print("结论：城市间空气质量存在显著差异")

# 步骤3：效应量（Epsilon squared）
k = len(all_groups)
N = sum(len(g) for g in all_groups)
epsilon_sq = (H_stat - k + 1) / (N - k)
print(f"效应量 ε² = {epsilon_sq:.4f}")

# 步骤4：事后两两比较（Mann-Whitney U + Bonferroni）
print("\n=== 事后两两比较 (Bonferroni 校正) ===")
from itertools import combinations
n_pairs = len(list(combinations(range(k), 2)))
alpha_bonf = 0.05 / n_pairs
print(f"校正后显著性水平: α = {alpha_bonf:.4f}")

for i, j in combinations(range(k), 2):
    u, p = stats.mannwhitneyu(all_groups[i], all_groups[j], alternative='two-sided')
    sig = "***" if p < alpha_bonf else "ns"
    print(f"城市 {city_names[i]} vs {city_names[j]}: U = {u:.0f}, p = {p:.4f} {sig}")
```

## 八、非参数检验选择流程

```
研究问题
│
├── 单样本/配对样本?
│   ├── 数据连续且近似正态 → 配对 t 检验
│   └── 数据非正态/序数 → Wilcoxon 符号秩检验
│
├── 两独立样本?
│   ├── 数据正态且方差齐 → 独立样本 t 检验
│   └── 数据非正态/方差不齐 → Mann-Whitney U 检验
│
├── 三组及以上独立样本?
│   ├── 数据正态且方差齐 → 单因素 ANOVA
│   └── 数据非正态/方差不齐 → Kruskal-Wallis 检验
│
├── 分类变量关联?
│   └── 卡方独立性检验
│
└── 检验分布形态?
    └── K-S 检验 / Anderson-Darling 检验
```

---

## 关键要点

1. **非参数检验不假设总体分布**，适用于小样本、偏态数据、含离群值的情况
2. **Wilcoxon 符号秩检验**是配对 t 检验的非参数替代，检验统计量基于差值的秩次
3. **Mann-Whitney U 检验**是独立样本 t 检验的非参数替代，适用于两组独立样本比较
4. **Kruskal-Wallis 检验**是单因素 ANOVA 的非参数替代，用于三组及以上比较，需配合事后检验
5. **卡方检验**用于分类变量的独立性和拟合优度检验，注意期望频数 $\geq 5$ 的前提条件
6. **K-S 检验**基于经验分布函数与理论分布的最大偏差，可用于模型验证
7. 多重比较时需进行 **Bonferroni 校正**等多重比较校正，控制整体错误率
8. 非参数检验虽灵活，但在满足参数检验条件时，**参数检验的效能更高**
