# 时间序列分析

## 1. 时间序列分析概述

时间序列（Time Series）是按时间顺序排列的一系列观测值。时间序列分析的目标是理解数据的生成机制，并进行预测。

### 1.1 时间序列的组成成分

$$
Y_t = T_t + S_t + C_t + \varepsilon_t
$$

- **趋势项 $T_t$**：长期上升或下降趋势
- **季节项 $S_t$**：周期性波动
- **周期项 $C_t$**：非固定周期的波动
- **随机项 $\varepsilon_t$**：白噪声

### 1.2 时间序列的类型

- **平稳时间序列**：统计性质不随时间变化
- **非平稳时间序列**：统计性质随时间变化

## 2. 平稳性

### 2.1 严平稳

对于所有 $t_1, t_2, \ldots, t_k$，联合分布满足：

$$
F(X_{t_1}, X_{t_2}, \ldots, X_{t_k}) = F(X_{t_1+\tau}, X_{t_2+\tau}, \ldots, X_{t_k+\tau})
$$

### 2.2 弱平稳（二阶平稳）

满足以下条件：

$$
E(X_t) = \mu \quad \text{（常数均值）}
$$

$$
\text{Var}(X_t) = \sigma^2 \quad \text{（常数方差）}
$$

$$
\text{Cov}(X_t, X_{t+h}) = \gamma(h) \quad \text{（自协方差只与滞后 $h$ 有关）}
$$

### 2.3 自协方差与自相关函数

**自协方差函数（ACVF）**：

$$
\gamma(h) = \text{Cov}(X_t, X_{t+h})
$$

**自相关函数（ACF）**：

$$
\rho(h) = \frac{\gamma(h)}{\gamma(0)} = \frac{\text{Cov}(X_t, X_{t+h})}{\text{Var}(X_t)}
$$

**偏自相关函数（PACF）**：

$$
\phi_{hh} = \text{Corr}(X_t, X_{t+h} | X_{t+1}, \ldots, X_{t+h-1})
$$

## 3. 白噪声与随机游走

### 3.1 白噪声

$$
\varepsilon_t \sim WN(0, \sigma^2)
$$

满足：$E(\varepsilon_t) = 0$，$\text{Var}(\varepsilon_t) = \sigma^2$，$\text{Cov}(\varepsilon_t, \varepsilon_s) = 0$（$t \neq s$）。

### 3.2 随机游走

$$
X_t = X_{t-1} + \varepsilon_t
$$

展开：

$$
X_t = X_0 + \sum_{i=1}^{t} \varepsilon_i
$$

方差：$\text{Var}(X_t) = t\sigma^2$（随时间增长，非平稳）。

## 4. 平稳性检验

### 4.1 ADF检验（Augmented Dickey-Fuller）

检验假设：

- $H_0$：序列有单位根（非平稳）
- $H_1$：序列平稳

回归模型：

$$
\Delta X_t = \alpha + \beta t + \gamma X_{t-1} + \sum_{i=1}^{p} \delta_i \Delta X_{t-i} + \varepsilon_t
$$

检验统计量：

$$
\text{ADF} = \frac{\hat{\gamma}}{\text{SE}(\hat{\gamma})}
$$

### 4.2 KPSS检验

- $H_0$：序列平稳
- $H_1$：序列有单位根

### 4.3 PP检验（Phillips-Perron）

非参数修正的ADF检验，对异方差和自相关具有鲁棒性。

## 5. ARIMA模型

### 5.1 AR(p)模型——自回归

$$
X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + \varepsilon_t
$$

特征方程：

$$
1 - \phi_1 z - \phi_2 z^2 - \cdots - \phi_p z^p = 0
$$

平稳条件：特征根均在单位圆外。

ACF性质：拖尾（指数衰减）

PACF性质：$p$ 步截尾

### 5.2 MA(q)模型——移动平均

$$
X_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q}
$$

可逆条件：特征根均在单位圆外。

ACF性质：$q$ 步截尾

PACF性质：拖尾

### 5.3 ARMA(p,q)模型

$$
X_t = c + \sum_{i=1}^{p} \phi_i X_{t-i} + \varepsilon_t + \sum_{j=1}^{q} \theta_j \varepsilon_{t-j}
$$

### 5.4 ARIMA(p,d,q)模型

对非平稳序列先进行 $d$ 阶差分，使其平稳化，再建立ARMA模型。

$$
\Delta^d X_t = (1-B)^d X_t
$$

其中 $B$ 为后移算子：$BX_t = X_{t-1}$。

ARIMA模型：

$$
\phi(B)(1-B)^d X_t = \theta(B)\varepsilon_t
$$

### 5.5 季节ARIMA（SARIMA）

$$
\Phi_P(B^s)\phi_p(B)(1-B)^d(1-B^s)^D X_t = \Theta_Q(B^s)\theta_q(B)\varepsilon_t
$$

记为ARIMA$(p,d,q) \times (P,D,Q)_s$。

## 6. 模型定阶

### 6.1 ACF/PACF定阶

| 模型 | ACF | PACF |
|------|-----|------|
| AR(p) | 拖尾 | $p$ 步截尾 |
| MA(q) | $q$ 步截尾 | 拖尾 |
| ARMA(p,q) | 拖尾 | 拖尾 |

### 6.2 信息准则

$$
\text{AIC} = -2\ln L + 2k
$$

$$
\text{BIC} = -2\ln L + k\ln n
$$

$$
\text{AICc} = \text{AIC} + \frac{2k(k+1)}{n-k-1}
$$

选择使信息准则最小的模型。

## 7. 指数平滑

### 7.1 简单指数平滑

$$
\hat{X}_{t+1} = \alpha X_t + (1-\alpha)\hat{X}_t
$$

展开：

$$
\hat{X}_{t+1} = \alpha \sum_{j=0}^{t-1} (1-\alpha)^j X_{t-j} + (1-\alpha)^t X_0
$$

### 7.2 Holt线性趋势模型

水平：

$$
\ell_t = \alpha X_t + (1-\alpha)(\ell_{t-1} + b_{t-1})
$$

趋势：

$$
b_t = \beta(\ell_t - \ell_{t-1}) + (1-\beta)b_{t-1}
$$

预测：

$$
\hat{X}_{t+h} = \ell_t + h b_t
$$

### 7.3 Holt-Winters季节模型

**加法模型**：

$$
\ell_t = \alpha(X_t - S_{t-s}) + (1-\alpha)(\ell_{t-1} + b_{t-1})
$$

$$
b_t = \beta(\ell_t - \ell_{t-1}) + (1-\beta)b_{t-1}
$$

$$
S_t = \gamma(X_t - \ell_t) + (1-\gamma)S_{t-s}
$$

**乘法模型**：

$$
\ell_t = \alpha \frac{X_t}{S_{t-s}} + (1-\alpha)(\ell_{t-1} + b_{t-1})
$$

$$
S_t = \gamma \frac{X_t}{\ell_t} + (1-\gamma)S_{t-s}
$$

## 8. Python实现

### 8.1 时间序列分解

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.seasonal import seasonal_decompose

# 生成示例数据
np.random.seed(42)
dates = pd.date_range(start='2020-01-01', periods=200, freq='M')
trend = np.linspace(100, 200, 200)
seasonal = 20 * np.sin(2 * np.pi * np.arange(200) / 12)
noise = np.random.randn(200) * 5
ts = pd.Series(trend + seasonal + noise, index=dates)

# 时间序列分解
decomposition = seasonal_decompose(ts, model='additive', period=12)

import matplotlib.pyplot as plt
fig, axes = plt.subplots(4, 1, figsize=(10, 8))
axes[0].plot(ts)
axes[0].set_title('原始序列')
axes[1].plot(decomposition.trend)
axes[1].set_title('趋势')
axes[2].plot(decomposition.seasonal)
axes[2].set_title('季节性')
axes[3].plot(decomposition.resid)
axes[3].set_title('残差')
plt.tight_layout()
plt.show()
```

### 8.2 ADF平稳性检验

```python
from statsmodels.tsa.stattools import adfuller

# ADF检验
result = adfuller(ts)
print(f'ADF统计量: {result[0]:.4f}')
print(f'p值: {result[1]:.6f}')
for key, value in result[4].items():
    print(f'  {key}: {value:.4f}')

if result[1] < 0.05:
    print("序列平稳（拒绝单位根假设）")
else:
    print("序列非平稳（不能拒绝单位根假设）")
```

### 8.3 ARIMA建模

```python
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

# 差分使序列平稳
ts_diff = ts.diff().dropna()

# ACF和PACF
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
plot_acf(ts_diff, ax=axes[0], lags=30)
plot_pacf(ts_diff, ax=axes[1], lags=30)
plt.show()

# 拟合ARIMA模型
model = ARIMA(ts, order=(1, 1, 1))
fitted = model.fit()
print(fitted.summary())

# 预测
forecast = fitted.forecast(steps=24)
print(f"\n未来24期预测:\n{forecast}")
```

### 8.4 自动定阶

```python
import pmdarima as pm

# 自动选择ARIMA参数
auto_model = pm.auto_arima(ts, seasonal=True, m=12,
                           stepwise=True, suppress_warnings=True,
                           error_action='ignore')
print(auto_model.summary())

# 预测
forecast, conf_int = auto_model.predict(n_periods=24, return_conf_int=True)
```

### 8.5 指数平滑

```python
from statsmodels.tsa.holtwinters import ExponentialSmoothing

# 简单指数平滑
model_se = ExponentialSmoothing(ts, trend=None, seasonal=None)
fit_se = model_se.fit(smoothing_level=0.3)

# Holt-Winters季节模型
model_hw = ExponentialSmoothing(ts, trend='add', seasonal='add',
                                 seasonal_periods=12)
fit_hw = model_hw.fit()

# 预测
forecast_hw = fit_hw.forecast(24)

# 可视化
plt.figure(figsize=(12, 5))
plt.plot(ts, label='历史数据')
plt.plot(forecast_hw, label='Holt-Winters预测', color='red')
plt.legend()
plt.title('Holt-Winters季节性预测')
plt.show()
```

## 9. 实际应用案例：股票价格预测

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
import matplotlib.pyplot as plt

# 模拟股票数据
np.random.seed(42)
n = 500
returns = np.random.normal(0.001, 0.02, n)
price = 100 * np.exp(np.cumsum(returns))
dates = pd.date_range(start='2022-01-01', periods=n, freq='B')
ts = pd.Series(price, index=dates)

# 划分训练集和测试集
train = ts[:-30]
test = ts[-30:]

# 拟合ARIMA
model = ARIMA(train, order=(2, 1, 1))
fitted = model.fit()

# 预测
forecast = fitted.forecast(steps=30)

# 计算误差
mae = np.mean(np.abs(forecast.values - test.values))
rmse = np.sqrt(np.mean((forecast.values - test.values)**2))
print(f"MAE: {mae:.4f}")
print(f"RMSE: {rmse:.4f}")

# 可视化
plt.figure(figsize=(12, 5))
plt.plot(train[-100:], label='训练数据')
plt.plot(test, label='真实值')
plt.plot(forecast, label='预测值', color='red')
plt.legend()
plt.title('ARIMA股票价格预测')
plt.show()
```

## 10. 关键要点总结

| 要点 | 内容 |
|------|------|
| 组成成分 | 趋势+季节+周期+随机 |
| 平稳性 | 弱平稳：常数均值、方差、自协方差 |
| ARIMA(p,d,q) | 自回归+差分+移动平均 |
| ACF/PACF | 模型识别：截尾与拖尾 |
| 信息准则 | AIC、BIC选择最优模型 |
| 指数平滑 | 简单、Holt、Holt-Winters |
| 预测 | 点预测+区间预测 |
| 注意 | 先检验平稳性，再建模 |
