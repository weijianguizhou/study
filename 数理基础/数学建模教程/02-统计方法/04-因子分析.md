# 因子分析

## 1. 因子分析概述

因子分析（Factor Analysis, FA）是一种多元统计方法，通过研究变量之间的相关关系，用少数几个不可观测的潜在变量（因子）来解释原始变量之间的依赖关系。

### 1.1 与PCA的区别

| 特征 | PCA | 因子分析 |
|------|-----|---------|
| 目标 | 降维，保留方差 | 解释相关性，寻找潜在因子 |
| 模型 | 确定性变换 | 统计模型 |
| 误差 | 无 | 有特殊因子 |
| 因子 | 原始变量的线性组合 | 潜在变量 |

### 1.2 应用场景

- 量表开发与验证
- 数据降维
- 结构发现
- 变量分组

## 2. 数学模型

### 2.1 因子分析模型

$$
X_i = a_{i1}F_1 + a_{i2}F_2 + \cdots + a_{im}F_m + \varepsilon_i
$$

矩阵形式：

$$
\mathbf{X} = \mathbf{A}\mathbf{F} + \boldsymbol{\varepsilon}
$$

其中：
- $\mathbf{X}$ 为 $p \times 1$ 的标准化随机向量
- $\mathbf{F} = (F_1, F_2, \ldots, F_m)^T$ 为 $m \times 1$ 的公共因子向量
- $\mathbf{A}$ 为 $p \times m$ 的因子载荷矩阵
- $\boldsymbol{\varepsilon}$ 为 $p \times 1$ 的特殊因子向量

### 2.2 基本假设

1. 公共因子均值为零：$E(\mathbf{F}) = \mathbf{0}$
2. 公共因子互不相关且方差为1：$\text{Cov}(\mathbf{F}) = \mathbf{I}_m$
3. 特殊因子与公共因子不相关：$\text{Cov}(\mathbf{F}, \boldsymbol{\varepsilon}) = \mathbf{0}$
4. 特殊因子互不相关：$\text{Cov}(\boldsymbol{\varepsilon}) = \boldsymbol{\Psi} = \text{diag}(\psi_1, \psi_2, \ldots, \psi_p)$

### 2.3 协方差结构

在上述假设下：

$$
\boldsymbol{\Sigma} = \text{Var}(\mathbf{X}) = \mathbf{A}\mathbf{A}^T + \boldsymbol{\Psi}
$$

协方差矩阵分解为两部分：
- $\mathbf{A}\mathbf{A}^T$：由公共因子解释的部分（共同度）
- $\boldsymbol{\Psi}$：特殊因子的方差（特殊方差）

## 3. 关键概念

### 3.1 因子载荷

$a_{ij}$ 为第 $i$ 个变量在第 $j$ 个因子上的载荷，反映了该变量与因子之间的相关程度。

$$
a_{ij} = \text{Corr}(X_i, F_j)
$$

### 3.2 共同度（Communality）

第 $i$ 个变量的共同度为所有公共因子对该变量方差贡献之和：

$$
h_i^2 = \sum_{j=1}^{m} a_{ij}^2
$$

共同度 $h_i^2 \in [0, 1]$，越大说明公共因子对该变量的解释力越强。

### 3.3 特殊方差（Uniqueness）

$$
\psi_i = 1 - h_i^2
$$

表示不能被公共因子解释的方差部分。

### 3.4 因子贡献

第 $j$ 个因子对所有变量的总贡献：

$$
\text{贡献}_j = \sum_{i=1}^{p} a_{ij}^2 = S_j^2
$$

第 $j$ 个因子的方差贡献率：

$$
\text{贡献率}_j = \frac{S_j^2}{p}
$$

## 4. 因子载荷矩阵的估计

### 4.1 主成分法

基于相关矩阵 $\mathbf{R}$ 的特征值分解：

$$
\mathbf{R} = \mathbf{U}\boldsymbol{\Lambda}\mathbf{U}^T
$$

取前 $m$ 个特征值对应的特征向量，因子载荷矩阵为：

$$
\mathbf{A} = \mathbf{U}_m \boldsymbol{\Lambda}_m^{1/2}
$$

即 $a_{ij} = u_{ij}\sqrt{\lambda_j}$。

### 4.2 主因子法

使用迭代方法估计因子载荷：

1. 从初始共同度估计出发（如 $h_i^2 = R_i^2$，即 $X_i$ 对其他变量的复相关系数的平方）
2. 构建约相关矩阵：$\mathbf{R}^* = \mathbf{R} - \boldsymbol{\Psi}$
3. 对 $\mathbf{R}^*$ 进行特征值分解，得到新的载荷矩阵
4. 更新共同度估计，重复迭代直至收敛

### 4.3 极大似然法

假设数据服从多元正态分布 $\mathbf{X} \sim N(\mathbf{0}, \boldsymbol{\Sigma})$，其中 $\boldsymbol{\Sigma} = \mathbf{A}\mathbf{A}^T + \boldsymbol{\Psi}$。

对数似然函数（忽略常数项）：

$$
\ell(\mathbf{A}, \boldsymbol{\Psi}) = -\frac{n}{2} \left[ \ln|\boldsymbol{\Sigma}| + \text{tr}(\mathbf{S}\boldsymbol{\Sigma}^{-1}) \right]
$$

其中 $\mathbf{S}$ 为样本协方差矩阵。通过数值优化求解 $\mathbf{A}$ 和 $\boldsymbol{\Psi}$。

## 5. 因子旋转

### 5.1 旋转的目的

原始因子载荷矩阵可能难以解释（每个变量在多个因子上都有中等大小的载荷）。旋转的目标是使载荷矩阵的结构更简单，便于解释。

### 5.2 简单结构原则

- 每个变量在尽可能少的因子上有高载荷
- 每个因子上有尽可能少的高载荷变量

### 5.3 正交旋转（Varimax）

Varimax旋转使每个因子上载荷平方的方差最大化：

$$
V = \frac{1}{p} \sum_{j=1}^{m} \left[ \frac{1}{p} \sum_{i=1}^{p} \tilde{a}_{ij}^4 - \left(\frac{1}{p}\sum_{i=1}^{p} \tilde{a}_{ij}^2\right)^2 \right]
$$

其中 $\tilde{a}_{ij} = a_{ij} / h_i$ 为标准化载荷。

旋转矩阵 $\mathbf{T}$ 满足 $\mathbf{T}^T\mathbf{T} = \mathbf{I}$，旋转后的载荷矩阵为：

$$
\mathbf{B} = \mathbf{A}\mathbf{T}
$$

### 5.4 斜交旋转（Promax）

允许因子之间存在相关，更符合实际情况。先进行Varimax旋转，然后通过幂次变换（通常 $k=4$）得到斜交解。

因子间的相关矩阵：

$$
\boldsymbol{\Phi} = (\mathbf{T}^T\mathbf{T})^{-1}
$$

## 6. 因子数目的确定

### 6.1 Kaiser准则

保留特征值 $\lambda_j > 1$ 的因子（基于相关矩阵）。

### 6.2 累计方差贡献率

$$
\frac{\sum_{j=1}^{m} \lambda_j}{p} \geq 0.85
$$

### 6.3 Scree图

绘制特征值的碎石图，选择拐点处的因子数。

### 6.4 平行分析

比较实际特征值与随机数据特征值，保留实际值大于随机值的因子。

### 6.5 BIC/AIC信息准则

$$
\text{BIC} = -2\ell + k\ln(n)
$$

$$
\text{AIC} = -2\ell + 2k
$$

选择使信息准则最小的因子数。

## 7. 因子得分

### 7.1 回归法（Bartlett得分）

$$
\hat{\mathbf{F}} = (\mathbf{A}^T\boldsymbol{\Psi}^{-1}\mathbf{A})^{-1}\mathbf{A}^T\boldsymbol{\Psi}^{-1}\mathbf{X}
$$

### 7.2 加权最小二乘法（Thomson得分）

$$
\hat{\mathbf{F}} = \mathbf{A}^T\boldsymbol{\Sigma}^{-1}\mathbf{X}
$$

### 7.3 回归法（多元回归）

$$
\hat{\mathbf{F}} = (\mathbf{A}^T\mathbf{R}^{-1}\mathbf{A})^{-1}\mathbf{A}^T\mathbf{R}^{-1}\mathbf{X}
$$

## 8. 模型拟合检验

### 8.1 模型拟合度

比较观测协方差矩阵与模型隐含协方差矩阵：

$$
\boldsymbol{\Sigma} \approx \hat{\boldsymbol{\Sigma}} = \hat{\mathbf{A}}\hat{\mathbf{A}}^T + \hat{\boldsymbol{\Psi}}
$$

拟合函数：

$$
F_{ML} = \text{tr}(\boldsymbol{\Sigma}\boldsymbol{\Sigma}_0^{-1}) + \ln|\boldsymbol{\Sigma}_0\boldsymbol{\Sigma}^{-1}| - p
$$

### 8.2 残差矩阵

$$
\mathbf{D} = \mathbf{R} - (\hat{\mathbf{A}}\hat{\mathbf{A}}^T + \hat{\boldsymbol{\Psi}})
$$

理想的残差矩阵应接近零。

### 8.3 模型评价指标

- **RMSEA**（近似误差均方根）：

$$
\text{RMSEA} = \sqrt{\frac{\max(\chi^2 - df, 0)}{df \cdot (n-1)}}
$$

- **CFI**（比较拟合指数）：$> 0.9$
- **TLI**（Tucker-Lewis指数）：$> 0.9$

## 9. Python实现

### 9.1 基本因子分析

```python
import numpy as np
from sklearn.decomposition import FactorAnalysis
from sklearn.preprocessing import StandardScaler
import pandas as pd

# 示例数据：心理测量问卷
np.random.seed(42)
n = 200
# 3个潜在因子
F1 = np.random.randn(n)  # 智力因子
F2 = np.random.randn(n)  # 性格因子
F3 = np.random.randn(n)  # 动机因子

# 观测变量（每个因子影响3-4个变量）
data = {
    'Q1': 0.8*F1 + 0.1*np.random.randn(n),
    'Q2': 0.7*F1 + 0.2*np.random.randn(n),
    'Q3': 0.6*F1 + 0.3*np.random.randn(n),
    'Q4': 0.1*F1 + 0.8*F2 + 0.1*np.random.randn(n),
    'Q5': 0.2*F1 + 0.7*F2 + 0.2*np.random.randn(n),
    'Q6': 0.1*F2 + 0.8*F3 + 0.1*np.random.randn(n),
    'Q7': 0.2*F2 + 0.7*F3 + 0.2*np.random.randn(n),
    'Q8': 0.3*F3 + 0.6*np.random.randn(n),
}

df = pd.DataFrame(data)

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)

# 因子分析
fa = FactorAnalysis(n_components=3, rotation='varimax', random_state=42)
X_fa = fa.fit_transform(X_scaled)

print("因子载荷矩阵:")
loadings = pd.DataFrame(fa.components_.T, index=df.columns,
                        columns=['因子1', '因子2', '因子3'])
print(loadings.round(3))

print(f"\n特殊方差: {fa.noise_variance_}")
print(f"共同度: {1 - fa.noise_variance_}")
```

### 9.2 手动实现因子分析

```python
import numpy as np

def factor_analysis(X, n_factors, method='pca'):
    """手动实现因子分析"""
    n, p = X.shape
    X_centered = X - np.mean(X, axis=0)
    R = np.cov(X_centered, rowvar=False)
    
    if method == 'pca':
        eigenvalues, eigenvectors = np.linalg.eigh(R)
        idx = np.argsort(eigenvalues)[::-1]
        eigenvalues = eigenvalues[idx][:n_factors]
        eigenvectors = eigenvectors[:, idx][:, :n_factors]
        
        # 因子载荷矩阵
        A = eigenvectors * np.sqrt(eigenvalues)
        
        # 共同度
        communalities = np.sum(A**2, axis=1)
        
        # 特殊方差
        uniquenesses = np.diag(R) - communalities
        
        return A, communalities, uniquenesses, eigenvalues

A, comm, uniq, eigenvalues = factor_analysis(X_scaled, n_factors=3)
print("因子载荷矩阵:\n", A.round(3))
print("共同度:", comm.round(3))
print("特殊方差:", uniq.round(3))
```

## 10. 实际应用案例：消费者满意度调查

```python
import numpy as np
from sklearn.decomposition import FactorAnalysis
from sklearn.preprocessing import StandardScaler
import pandas as pd

# 模拟消费者满意度数据
np.random.seed(42)
n = 300

# 潜在因子
quality = np.random.normal(3.5, 0.8, n)
service = np.random.normal(3.8, 0.7, n)
value = np.random.normal(3.2, 0.9, n)

survey_data = {
    '产品质量': np.clip(0.8*quality + np.random.randn(n)*0.3, 1, 5),
    '产品外观': np.clip(0.7*quality + np.random.randn(n)*0.4, 1, 5),
    '产品功能': np.clip(0.6*quality + 0.2*value + np.random.randn(n)*0.3, 1, 5),
    '服务态度': np.clip(0.8*service + np.random.randn(n)*0.3, 1, 5),
    '服务速度': np.clip(0.7*service + np.random.randn(n)*0.3, 1, 5),
    '服务专业性': np.clip(0.6*service + np.random.randn(n)*0.4, 1, 5),
    '价格合理性': np.clip(0.7*value + np.random.randn(n)*0.3, 1, 5),
    '性价比': np.clip(0.6*value + 0.3*quality + np.random.randn(n)*0.3, 1, 5),
}

df = pd.DataFrame(survey_data)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)

fa = FactorAnalysis(n_components=3, rotation='varimax', random_state=42)
fa.fit(X_scaled)

loadings = pd.DataFrame(fa.components_.T, index=df.columns,
                        columns=['产品质量', '服务质量', '性价比'])
print("旋转后因子载荷:")
print(loadings.round(3))

# 共同度
communalities = 1 - fa.noise_variance_
print(f"\n各变量共同度: {np.round(1 - fa.noise_variance_, 3)}")
```

## 11. 关键要点总结

| 要点 | 内容 |
|------|------|
| 模型 | $\mathbf{X} = \mathbf{A}\mathbf{F} + \boldsymbol{\varepsilon}$ |
| 载荷 | $a_{ij} = \text{Corr}(X_i, F_j)$ |
| 共同度 | $h_i^2 = \sum_j a_{ij}^2$，公共因子解释的方差 |
| 特殊方差 | $\psi_i = 1 - h_i^2$ |
| 旋转 | Varimax（正交）、Promax（斜交），简化结构 |
| 因子数确定 | Kaiser准则、累计贡献率、Scree图、BIC/AIC |
| 应用 | 量表开发、结构发现、数据降维 |
| 注意 | 需足够样本量（通常 $n > 5p$） |
