# 因子分析

> **理论基础** → 参见 [[../../统计学分析方法/因子分析|因子分析理论]]

因子分析从变量群中提取共性因子，揭示观测变量背后的潜在结构，实现数据降维和因素解释。

## 3. 关键概念
### 3.1 因子载荷

$a_{ij}$ 为第 $i$ 个变量在第 $j$ 个因子上的载荷，反映了该变量与因子之间的相关程度。

$$
a_{ij} = \text{Corr}(X_i, F_j)
$$

### 3.2 共同度（Communality）

第 $i$ 个变量的共同度为所有公共因子对该变量方差贡献之和：

$$
h_i^2 = \sum_{j=1}^{m} a_{ij}^2
$$

共同度 $h_i^2 \in [0, 1]$，越大说明公共因子对该变量的解释力越强。

### 3.3 特殊方差（Uniqueness）

$$
\psi_i = 1 - h_i^2
$$

表示不能被公共因子解释的方差部分。

### 3.4 因子贡献

第 $j$ 个因子对所有变量的总贡献：

$$
\text{贡献}_j = \sum_{i=1}^{p} a_{ij}^2 = S_j^2
$$

第 $j$ 个因子的方差贡献率：

$$
\text{贡献率}_j = \frac{S_j^2}{p}
$$

## 9. Python实现
### 9.1 基本因子分析

```python
import numpy as np
from sklearn.decomposition import FactorAnalysis
from sklearn.preprocessing import StandardScaler
import pandas as pd

# 示例数据：心理测量问卷
np.random.seed(42)
n = 200
# 3个潜在因子
F1 = np.random.randn(n)  # 智力因子
F2 = np.random.randn(n)  # 性格因子
F3 = np.random.randn(n)  # 动机因子

# 观测变量（每个因子影响3-4个变量）
data = {
    'Q1': 0.8*F1 + 0.1*np.random.randn(n),
    'Q2': 0.7*F1 + 0.2*np.random.randn(n),
    'Q3': 0.6*F1 + 0.3*np.random.randn(n),
    'Q4': 0.1*F1 + 0.8*F2 + 0.1*np.random.randn(n),
    'Q5': 0.2*F1 + 0.7*F2 + 0.2*np.random.randn(n),
    'Q6': 0.1*F2 + 0.8*F3 + 0.1*np.random.randn(n),
    'Q7': 0.2*F2 + 0.7*F3 + 0.2*np.random.randn(n),
    'Q8': 0.3*F3 + 0.6*np.random.randn(n),
}

df = pd.DataFrame(data)

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)

# 因子分析
fa = FactorAnalysis(n_components=3, rotation='varimax', random_state=42)
X_fa = fa.fit_transform(X_scaled)

print("因子载荷矩阵:")
loadings = pd.DataFrame(fa.components_.T, index=df.columns,
                        columns=['因子1', '因子2', '因子3'])
print(loadings.round(3))

print(f"\n特殊方差: {fa.noise_variance_}")
print(f"共同度: {1 - fa.noise_variance_}")
```

### 9.2 手动实现因子分析

```python
import numpy as np

def factor_analysis(X, n_factors, method='pca'):
    """手动实现因子分析"""
    n, p = X.shape
    X_centered = X - np.mean(X, axis=0)
    R = np.cov(X_centered, rowvar=False)
    
    if method == 'pca':
        eigenvalues, eigenvectors = np.linalg.eigh(R)
        idx = np.argsort(eigenvalues)[::-1]
        eigenvalues = eigenvalues[idx][:n_factors]
        eigenvectors = eigenvectors[:, idx][:, :n_factors]
        
        # 因子载荷矩阵
        A = eigenvectors * np.sqrt(eigenvalues)
        
        # 共同度
        communalities = np.sum(A**2, axis=1)
        
        # 特殊方差
        uniquenesses = np.diag(R) - communalities
        
        return A, communalities, uniquenesses, eigenvalues

A, comm, uniq, eigenvalues = factor_analysis(X_scaled, n_factors=3)
print("因子载荷矩阵:\n", A.round(3))
print("共同度:", comm.round(3))
print("特殊方差:", uniq.round(3))
```

## 10. 实际应用案例：消费者满意度调查
```python
import numpy as np
from sklearn.decomposition import FactorAnalysis
from sklearn.preprocessing import StandardScaler
import pandas as pd

# 模拟消费者满意度数据
np.random.seed(42)
n = 300

# 潜在因子
quality = np.random.normal(3.5, 0.8, n)
service = np.random.normal(3.8, 0.7, n)
value = np.random.normal(3.2, 0.9, n)

survey_data = {
    '产品质量': np.clip(0.8*quality + np.random.randn(n)*0.3, 1, 5),
    '产品外观': np.clip(0.7*quality + np.random.randn(n)*0.4, 1, 5),
    '产品功能': np.clip(0.6*quality + 0.2*value + np.random.randn(n)*0.3, 1, 5),
    '服务态度': np.clip(0.8*service + np.random.randn(n)*0.3, 1, 5),
    '服务速度': np.clip(0.7*service + np.random.randn(n)*0.3, 1, 5),
    '服务专业性': np.clip(0.6*service + np.random.randn(n)*0.4, 1, 5),
    '价格合理性': np.clip(0.7*value + np.random.randn(n)*0.3, 1, 5),
    '性价比': np.clip(0.6*value + 0.3*quality + np.random.randn(n)*0.3, 1, 5),
}

df = pd.DataFrame(survey_data)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)

fa = FactorAnalysis(n_components=3, rotation='varimax', random_state=42)
fa.fit(X_scaled)

loadings = pd.DataFrame(fa.components_.T, index=df.columns,
                        columns=['产品质量', '服务质量', '性价比'])
print("旋转后因子载荷:")
print(loadings.round(3))

# 共同度
communalities = 1 - fa.noise_variance_
print(f"\n各变量共同度: {np.round(1 - fa.noise_variance_, 3)}")
```

## 11. 关键要点总结
| 要点 | 内容 |
|------|------|
| 模型 | $\mathbf{X} = \mathbf{A}\mathbf{F} + \boldsymbol{\varepsilon}$ |
| 载荷 | $a_{ij} = \text{Corr}(X_i, F_j)$ |
| 共同度 | $h_i^2 = \sum_j a_{ij}^2$，公共因子解释的方差 |
| 特殊方差 | $\psi_i = 1 - h_i^2$ |
| 旋转 | Varimax（正交）、Promax（斜交），简化结构 |
| 因子数确定 | Kaiser准则、累计贡献率、Scree图、BIC/AIC |
| 应用 | 量表开发、结构发现、数据降维 |
| 注意 | 需足够样本量（通常 $n > 5p$） |
