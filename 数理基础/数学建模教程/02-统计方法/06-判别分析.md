# 判别分析

## 1. 判别分析概述

判别分析（Discriminant Analysis）是一种有监督的分类方法，根据已知类别的训练样本，建立判别规则，对新样本进行分类。

### 1.1 基本思想

- 已知 $k$ 个类别 $G_1, G_2, \ldots, G_k$
- 每个类别有若干训练样本
- 建立判别函数，将新样本分配到最可能的类别

### 1.2 与回归的区别

| 特征 | 判别分析 | 回归分析 |
|------|---------|---------|
| 因变量 | 分类变量（名义） | 连续变量 |
| 目标 | 分类 | 预测数值 |
| 输出 | 类别标签 | 数值 |

## 2. Fisher线性判别分析（LDA）

### 2.1 基本原理

Fisher判别的目标是找到一个投影方向 $\mathbf{w}$，使得投影后类间方差与类内方差的比值最大。

$$
J(\mathbf{w}) = \frac{\mathbf{w}^T \mathbf{S}_B \mathbf{w}}{\mathbf{w}^T \mathbf{S}_W \mathbf{w}} \to \max
$$

其中：
- $\mathbf{S}_B$ 为类间散度矩阵（Between-class Scatter Matrix）
- $\mathbf{S}_W$ 为类内散度矩阵（Within-class Scatter Matrix）

### 2.2 散度矩阵

**类内散度矩阵**：

$$
\mathbf{S}_W = \sum_{k=1}^{K} \sum_{\mathbf{x}_i \in G_k} (\mathbf{x}_i - \boldsymbol{\mu}_k)(\mathbf{x}_i - \boldsymbol{\mu}_k)^T
$$

其中 $\boldsymbol{\mu}_k$ 为第 $k$ 类的均值向量。

**类间散度矩阵**：

$$
\mathbf{S}_B = \sum_{k=1}^{K} n_k (\boldsymbol{\mu}_k - \boldsymbol{\mu})(\boldsymbol{\mu}_k - \boldsymbol{\mu})^T
$$

其中 $\boldsymbol{\mu}$ 为总均值向量，$n_k$ 为第 $k$ 类的样本数。

### 2.3 最优投影方向

对广义特征值问题求解：

$$
\mathbf{S}_B \mathbf{w} = \lambda \mathbf{S}_W \mathbf{w}
$$

等价于：

$$
\mathbf{S}_W^{-1} \mathbf{S}_B \mathbf{w} = \lambda \mathbf{w}
$$

取最大特征值对应的特征向量作为投影方向。对于 $K$ 类问题，最多有 $K-1$ 个有效的判别方向。

### 2.4 多类推广

当有 $K$ 个类别时，可以得到 $K-1$ 个判别方向 $\mathbf{w}_1, \mathbf{w}_2, \ldots, \mathbf{w}_{K-1}$，构成投影矩阵：

$$
\mathbf{W} = [\mathbf{w}_1, \mathbf{w}_2, \ldots, \mathbf{w}_{K-1}]
$$

投影后的数据：

$$
\mathbf{y} = \mathbf{W}^T \mathbf{x}
$$

### 2.5 Fisher判别准则的推导

设投影 $y = \mathbf{w}^T\mathbf{x}$，则：

类间均值之差：$\tilde{\mu}_1 - \tilde{\mu}_2 = \mathbf{w}^T(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)$

类内方差：$\tilde{s}_1^2 + \tilde{s}_2^2 = \mathbf{w}^T(\mathbf{S}_1 + \mathbf{S}_2)\mathbf{w} = \mathbf{w}^T\mathbf{S}_W\mathbf{w}$

Fisher准则函数：

$$
J(\mathbf{w}) = \frac{(\tilde{\mu}_1 - \tilde{\mu}_2)^2}{\tilde{s}_1^2 + \tilde{s}_2^2} = \frac{\mathbf{w}^T\mathbf{S}_B\mathbf{w}}{\mathbf{w}^T\mathbf{S}_W\mathbf{w}}
$$

## 3. Bayes判别分析

### 3.1 Bayes定理

$$
P(G_k | \mathbf{x}) = \frac{P(\mathbf{x} | G_k) P(G_k)}{P(\mathbf{x})}
$$

其中：
- $P(G_k | \mathbf{x})$ 为后验概率
- $P(\mathbf{x} | G_k)$ 为类条件密度（似然）
- $P(G_k)$ 为先验概率

### 3.2 判别规则

**最大后验概率准则**：

$$
\hat{y} = \underset{k}{\arg\max} P(G_k | \mathbf{x})
$$

等价于：

$$
\hat{y} = \underset{k}{\arg\max} \left[ \ln P(\mathbf{x} | G_k) + \ln P(G_k) \right]
$$

### 3.3 正态判别

假设每个类别的数据服从多元正态分布：

$$
\mathbf{x} | G_k \sim N(\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)
$$

**判别函数**（对数形式）：

$$
\delta_k(\mathbf{x}) = -\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_k)^T \boldsymbol{\Sigma}_k^{-1} (\mathbf{x} - \boldsymbol{\mu}_k) - \frac{1}{2}\ln|\boldsymbol{\Sigma}_k| + \ln P(G_k)
$$

### 3.4 三种情况

**情况1：$\boldsymbol{\Sigma}_k = \sigma^2 \mathbf{I}$（各协方差矩阵相等且为球形）**

判别函数简化为：

$$
\delta_k(\mathbf{x}) = -\frac{\|\mathbf{x} - \boldsymbol{\mu}_k\|^2}{2\sigma^2} + \ln P(G_k)
$$

等价于最近均值分类器。

**情况2：$\boldsymbol{\Sigma}_k = \boldsymbol{\Sigma}$（各协方差矩阵相等）**

$$
\delta_k(\mathbf{x}) = \boldsymbol{\mu}_k^T \boldsymbol{\Sigma}^{-1} \mathbf{x} - \frac{1}{2}\boldsymbol{\mu}_k^T \boldsymbol{\Sigma}^{-1} \boldsymbol{\mu}_k + \ln P(G_k)
$$

这是线性判别分析（LDA）。

**情况3：$\boldsymbol{\Sigma}_k$ 各不相同（二次判别分析QDA）**

$$
\delta_k(\mathbf{x}) = -\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_k)^T \boldsymbol{\Sigma}_k^{-1} (\mathbf{x} - \boldsymbol{\mu}_k) - \frac{1}{2}\ln|\boldsymbol{\Sigma}_k| + \ln P(G_k)
$$

判别边界为二次曲面。

## 4. 判别函数

### 4.1 线性判别函数

$$
\delta_k(\mathbf{x}) = \mathbf{w}_k^T \mathbf{x} + b_k
$$

其中：

$$
\mathbf{w}_k = \boldsymbol{\Sigma}^{-1} \boldsymbol{\mu}_k, \quad b_k = -\frac{1}{2}\boldsymbol{\mu}_k^T \boldsymbol{\Sigma}^{-1} \boldsymbol{\mu}_k + \ln P(G_k)
$$

### 4.2 判别边界

两类别之间的判别边界为：

$$
\delta_i(\mathbf{x}) = \delta_j(\mathbf{x})
$$

$$
(\mathbf{w}_i - \mathbf{w}_j)^T \mathbf{x} + (b_i - b_j) = 0
$$

这是一个超平面方程。

## 5. 判别分析的假设检验

### 5.1 均值向量的检验

检验 $H_0: \boldsymbol{\mu}_1 = \boldsymbol{\mu}_2 = \cdots = \boldsymbol{\mu}_K$（各组均值向量相同）。

**Hotelling's $T^2$ 统计量**（两组情况）：

$$
T^2 = \frac{n_1 n_2}{n_1 + n_2} (\bar{\mathbf{x}}_1 - \bar{\mathbf{x}}_2)^T \mathbf{S}_W^{-1} (\bar{\mathbf{x}}_1 - \bar{\mathbf{x}}_2)
$$

转换为F统计量：

$$
F = \frac{n_1 + n_2 - p}{p(n_1 + n_2 - 2)} T^2 \sim F(p, n_1 + n_2 - p - 1)
$$

### 5.2 协方差矩阵的检验

检验 $H_0: \boldsymbol{\Sigma}_1 = \boldsymbol{\Sigma}_2 = \cdots = \boldsymbol{\Sigma}_K$。

**Box's M检验**：

$$
M = (N-K)\ln|\mathbf{S}_W| - \sum_{k=1}^{K}(n_k - 1)\ln|\mathbf{S}_k|
$$

## 6. 误判率估计

### 6.1 回代法（Resubstitution）

用全部训练样本作为检验样本，计算误判率。

### 6.2 交叉验证法

将数据分为训练集和验证集，计算交叉验证误判率。

### 6.3 留一法（Leave-One-Out）

每次留一个样本作为检验，用其余样本训练，对所有样本重复。

$$
\text{LOO CV} = \frac{1}{n}\sum_{i=1}^{n} \mathbb{I}(\hat{y}_i \neq y_i)
$$

## 7. Python实现

### 7.1 Fisher线性判别分析

```python
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report
from sklearn.datasets import load_iris

# 加载数据
iris = load_iris()
X, y = iris.data, iris.target

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# LDA
lda = LinearDiscriminantAnalysis()
lda.fit(X_train, y_train)

# 预测
y_pred = lda.predict(X_test)
print(f"准确率: {accuracy_score(y_test, y_pred):.4f}")
print(f"\n分类报告:\n{classification_report(y_test, y_pred, target_names=iris.target_names)}")

# 判别得分（投影后的数据）
scores = lda.transform(X_test)
print(f"投影后维度: {scores.shape}")  # (n_samples, n_classes-1)
```

### 7.2 手动实现Fisher LDA

```python
import numpy as np

def fisher_lda(X, y, n_components=None):
    """手动实现Fisher LDA"""
    classes = np.unique(y)
    K = len(classes)
    p = X.shape[1]
    
    if n_components is None:
        n_components = K - 1
    
    # 计算各类均值和总均值
    means = {}
    for k in classes:
        means[k] = np.mean(X[y == k], axis=0)
    overall_mean = np.mean(X, axis=0)
    
    # 计算类内散度矩阵
    S_W = np.zeros((p, p))
    for k in classes:
        X_k = X[y == k]
        S_W += (X_k - means[k]).T @ (X_k - means[k])
    
    # 计算类间散度矩阵
    S_B = np.zeros((p, p))
    for k in classes:
        n_k = np.sum(y == k)
        diff = (means[k] - overall_mean).reshape(-1, 1)
        S_B += n_k * diff @ diff.T
    
    # 求解广义特征值问题
    eigenvalues, eigenvectors = np.linalg.eig(np.linalg.inv(S_W) @ S_B)
    
    # 按特征值降序排列
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[idx].real
    eigenvectors = eigenvectors[:, idx].real
    
    # 选择前n_components个
    W = eigenvectors[:, :n_components]
    
    return W, eigenvalues, eigenvectors

W, eigenvalues, eigenvectors = fisher_lda(X, y)
print("投影矩阵W:\n", W)
print("特征值:", eigenvalues[:3])

# 投影
X_projected = X @ W
print(f"投影后形状: {X_projected.shape}")
```

### 7.3 二次判别分析（QDA）

```python
from sklearn.discriminant_analysis import QuadraticDiscriminantAnalysis
from sklearn.datasets import make_classification

# 生成数据
X, y = make_classification(n_samples=300, n_features=2, n_informative=2,
                           n_redundant=0, n_classes=3, n_clusters_per_class=1,
                           random_state=42)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# QDA
qda = QuadraticDiscriminantAnalysis()
qda.fit(X_train, y_train)
y_pred = qda.predict(X_test)

print(f"QDA准确率: {accuracy_score(y_test, y_pred):.4f}")

# LDA对比
lda = LinearDiscriminantAnalysis()
lda.fit(X_train, y_train)
y_pred_lda = lda.predict(X_test)
print(f"LDA准确率: {accuracy_score(y_test, y_pred_lda):.4f}")
```

## 8. 实际应用案例：信用评分

```python
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.model_selection import cross_val_score
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline

# 模拟信用数据
np.random.seed(42)
n_good, n_bad = 200, 50

# 好客户
X_good = np.random.normal([50000, 15, 200], [10000, 5, 60], (n_good, 3))
# 坏客户
X_bad = np.random.normal([30000, 8, 350], [8000, 3, 80], (n_bad, 3))

X = np.vstack([X_good, X_bad])
y = np.array([0]*n_good + [1]*n_bad)

# 创建Pipeline
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('lda', LinearDiscriminantAnalysis())
])

# 交叉验证
scores = cross_val_score(pipe, X, y, cv=5, scoring='accuracy')
print(f"5折交叉验证准确率: {scores.mean():.4f} ± {scores.std():.4f}")

# 判别系数
pipe.fit(X, y)
lda = pipe.named_steps['lda']
print(f"\n判别系数:\n{lda.coef_}")
print(f"截距: {lda.intercept_}")
```

## 9. LDA vs QDA vs 朴素贝叶斯

| 方法 | 协方差假设 | 决策边界 | 参数量 |
|------|----------|---------|-------|
| 朴素贝叶斯 | 对角矩阵 | 线性 | $O(p)$ |
| LDA | 公共协方差矩阵 | 线性 | $O(p^2)$ |
| QDA | 各类独立协方差矩阵 | 二次 | $O(Kp^2)$ |

## 10. 关键要点总结

| 要点 | 内容 |
|------|------|
| Fisher LDA | 最大化类间方差/类内方差 |
| Bayes判别 | 最大后验概率分类 |
| LDA假设 | 各类协方差相等，决策边界为线性 |
| QDA | 允许各类协方差不同，决策边界为二次 |
| 判别函数 | $\delta_k(\mathbf{x}) = \mathbf{w}_k^T\mathbf{x} + b_k$ |
| 假设检验 | Hotelling's $T^2$、Box's M |
| 误判率估计 | 回代法、交叉验证、留一法 |
| 注意 | 要求正态性、协方差相等（LDA） |
