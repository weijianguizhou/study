# 聚类分析

## 1. 聚类分析概述

聚类分析（Cluster Analysis）是一种无监督学习方法，目标是将数据对象分成若干组（簇），使得同一簇内的对象尽可能相似，不同簇的对象尽可能不同。

### 1.1 与分类的区别

| 特征 | 聚类 | 分类 |
|------|------|------|
| 学习方式 | 无监督 | 有监督 |
| 标签 | 无 | 有 |
| 目标 | 发现数据结构 | 预测类别 |
| 典型算法 | K-means, 层次聚类 | SVM, 决策树 |

### 1.2 聚类的应用

- 客户细分
- 图像分割
- 文档聚类
- 生物信息学
- 异常检测

## 2. 距离与相似性度量

### 2.1 连续变量距离

**欧氏距离（Euclidean Distance）**：

$$
d(\mathbf{x}_i, \mathbf{x}_j) = \sqrt{\sum_{k=1}^{p} (x_{ik} - x_{jk})^2} = \|\mathbf{x}_i - \mathbf{x}_j\|_2
$$

**曼哈顿距离（Manhattan Distance）**：

$$
d(\mathbf{x}_i, \mathbf{x}_j) = \sum_{k=1}^{p} |x_{ik} - x_{jk}| = \|\mathbf{x}_i - \mathbf{x}_j\|_1
$$

**闵可夫斯基距离（Minkowski Distance）**：

$$
d(\mathbf{x}_i, \mathbf{x}_j) = \left(\sum_{k=1}^{p} |x_{ik} - x_{jk}|^q\right)^{1/q}
$$

**马氏距离（Mahalanobis Distance）**：

$$
d(\mathbf{x}_i, \mathbf{x}_j) = \sqrt{(\mathbf{x}_i - \mathbf{x}_j)^T \mathbf{S}^{-1} (\mathbf{x}_i - \mathbf{x}_j)}
$$

其中 $\mathbf{S}$ 为协方差矩阵。马氏距离不受变量量纲和相关性影响。

### 2.2 相似性度量

**余弦相似度**：

$$
\cos(\mathbf{x}_i, \mathbf{x}_j) = \frac{\mathbf{x}_i^T \mathbf{x}_j}{\|\mathbf{x}_i\| \|\mathbf{x}_j\|}
$$

**皮尔逊相关系数**：

$$
r_{ij} = \frac{\sum_{k=1}^{p}(x_{ik}-\bar{x}_i)(x_{jk}-\bar{x}_j)}{\sqrt{\sum_{k=1}^{p}(x_{ik}-\bar{x}_i)^2 \sum_{k=1}^{p}(x_{jk}-\bar{x}_j)^2}}
$$

### 2.3 类间距离

设 $G_p$ 和 $G_q$ 为两个簇：

**最短距离法（Single Linkage）**：

$$
D(G_p, G_q) = \min_{\mathbf{x}_i \in G_p, \mathbf{x}_j \in G_q} d(\mathbf{x}_i, \mathbf{x}_j)
$$

**最长距离法（Complete Linkage）**：

$$
D(G_p, G_q) = \max_{\mathbf{x}_i \in G_p, \mathbf{x}_j \in G_q} d(\mathbf{x}_i, \mathbf{x}_j)
$$

**类平均法（Average Linkage）**：

$$
D(G_p, G_q) = \frac{1}{n_p n_q} \sum_{\mathbf{x}_i \in G_p} \sum_{\mathbf{x}_j \in G_q} d(\mathbf{x}_i, \mathbf{x}_j)
$$

**重心法（Centroid Linkage）**：

$$
D(G_p, G_q) = \|\bar{\mathbf{x}}_p - \bar{\mathbf{x}}_q\|
$$

**Ward法（离差平方和法）**：

$$
\Delta D = \frac{n_p n_q}{n_p + n_q} \|\bar{\mathbf{x}}_p - \bar{\mathbf{x}}_q\|^2
$$

## 3. K-means聚类

### 3.1 算法流程

1. **初始化**：随机选择 $k$ 个初始质心 $\boldsymbol{\mu}_1, \boldsymbol{\mu}_2, \ldots, \boldsymbol{\mu}_k$
2. **分配步骤**：将每个样本分配到最近的质心所在簇

$$
C_i = \underset{j}{\arg\min} \|\mathbf{x}_i - \boldsymbol{\mu}_j\|^2
$$

3. **更新步骤**：重新计算每个簇的质心

$$
\boldsymbol{\mu}_j = \frac{1}{|C_j|} \sum_{\mathbf{x}_i \in C_j} \mathbf{x}_i
$$

4. 重复步骤2-3直至收敛

### 3.2 目标函数

最小化簇内平方和（WCSS）：

$$
J = \sum_{j=1}^{k} \sum_{\mathbf{x}_i \in C_j} \|\mathbf{x}_i - \boldsymbol{\mu}_j\|^2
$$

### 3.3 K值选择

**肘部法则（Elbow Method）**：绘制WCSS随 $k$ 变化的曲线，选择拐点。

$$
\text{Gap}(k) = \ln(\text{WCSS}_k^{\text{real}}) - \ln(\text{WCSS}_k^{\text{random}})
$$

**轮廓系数（Silhouette Score）**：

$$
s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}
$$

其中：
- $a(i)$：样本 $i$ 与同簇其他样本的平均距离
- $b(i)$：样本 $i$ 与最近邻簇中所有样本的平均距离

轮廓系数 $s(i) \in [-1, 1]$，越接近1越好。

**Gap统计量**：

$$
\text{Gap}(k) = E^*[\ln(W_k)] - \ln(W_k)
$$

### 3.4 K-means的局限性

1. 需要预先指定 $k$
2. 对初始中心敏感
3. 只能发现球形簇
4. 对异常值敏感
5. 不适用于大小差异大的簇

## 4. K-means++ 初始化

K-means++ 优化了初始质心的选择：

1. 随机选择第一个质心
2. 对每个样本，计算其与最近质心的距离 $D(\mathbf{x})$
3. 以概率 $\frac{D(\mathbf{x})^2}{\sum D(\mathbf{x})^2}$ 选择下一个质心
4. 重复直到选出 $k$ 个质心

## 5. 层次聚类

### 5.1 凝聚层次聚类（自底向上）

1. 将每个样本视为一个簇
2. 合并最接近的两个簇
3. 重复直到达到预定簇数

### 5.2 分裂层次聚类（自顶向下）

1. 将所有样本视为一个簇
2. 将最不紧凑的簇分裂为两个
3. 重复直到每个样本自成一簇

### 5.3 树状图（Dendrogram）

树状图直观展示聚类过程，横轴为样本，纵轴为合并距离。通过在不同高度切割树状图，可以得到不同数量的簇。

## 6. DBSCAN

DBSCAN（Density-Based Spatial Clustering of Applications with Noise）是一种基于密度的聚类算法。

### 6.1 基本概念

- **$\varepsilon$-邻域**：$N_\varepsilon(\mathbf{x}) = \{\mathbf{y} : d(\mathbf{x}, \mathbf{y}) \leq \varepsilon\}$
- **核心点**：$|N_\varepsilon(\mathbf{x})| \geq \text{MinPts}$
- **边界点**：不是核心点，但在某个核心点的 $\varepsilon$-邻域内
- **噪声点**：既不是核心点也不是边界点

### 6.2 算法步骤

1. 找到核心点
2. 从任意核心点出发，将其邻域内的所有点归入同一簇
3. 如果边界点属于多个簇，则归入最近的核心点所在簇
4. 重复直到所有点被处理

### 6.3 参数选择

- $\varepsilon$：使用k-distance图选择
- MinPts：通常 $2 \leq \text{MinPts} \leq 2p$

## 7. 高斯混合模型（GMM）

### 7.1 模型定义

假设数据来自 $k$ 个高斯分布的混合：

$$
p(\mathbf{x}) = \sum_{j=1}^{k} \pi_j \mathcal{N}(\mathbf{x} | \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)
$$

其中 $\pi_j$ 为混合权重，$\sum_{j=1}^{k} \pi_j = 1$。

### 7.2 EM算法

**E步**：计算后验概率（软分配）

$$
\gamma_{ij} = \frac{\pi_j \mathcal{N}(\mathbf{x}_i | \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)}{\sum_{l=1}^{k} \pi_l \mathcal{N}(\mathbf{x}_i | \boldsymbol{\mu}_l, \boldsymbol{\Sigma}_l)}
$$

**M步**：更新参数

$$
\pi_j = \frac{1}{n}\sum_{i=1}^{n} \gamma_{ij}
$$

$$
\boldsymbol{\mu}_j = \frac{\sum_{i=1}^{n} \gamma_{ij} \mathbf{x}_i}{\sum_{i=1}^{n} \gamma_{ij}}
$$

$$
\boldsymbol{\Sigma}_j = \frac{\sum_{i=1}^{n} \gamma_{ij} (\mathbf{x}_i - \boldsymbol{\mu}_j)(\mathbf{x}_i - \boldsymbol{\mu}_j)^T}{\sum_{i=1}^{n} \gamma_{ij}}
$$

## 8. Python实现

### 8.1 K-means聚类

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, silhouette_samples
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 生成示例数据
from sklearn.datasets import make_blobs
X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=42)

# K-means聚类
kmeans = KMeans(n_clusters=4, init='k-means++', n_init=10, random_state=42)
labels = kmeans.fit_predict(X)

# 评估
print(f"WCSS: {kmeans.inertia_:.2f}")
print(f"轮廓系数: {silhouette_score(X, labels):.4f}")

# 可视化
plt.figure(figsize=(10, 5))
plt.subplot(1, 2, 1)
plt.scatter(X[:, 0], X[:, 1], c=y_true, cmap='viridis')
plt.title('真实标签')

plt.subplot(1, 2, 2)
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis')
plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1],
            s=200, c='red', marker='X', label='质心')
plt.title('K-means聚类结果')
plt.legend()
plt.show()
```

### 8.2 K值选择

```python
# 肘部法则
inertias = []
sil_scores = []
K_range = range(2, 10)

for k in K_range:
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    kmeans.fit(X)
    inertias.append(kmeans.inertia_)
    sil_scores.append(silhouette_score(X, kmeans.labels_))

fig, axes = plt.subplots(1, 2, figsize=(12, 5))
axes[0].plot(K_range, inertias, 'bo-')
axes[0].set_xlabel('K')
axes[0].set_ylabel('WCSS')
axes[0].set_title('肘部法则')

axes[1].plot(K_range, sil_scores, 'ro-')
axes[1].set_xlabel('K')
axes[1].set_ylabel('轮廓系数')
axes[1].set_title('轮廓系数法')

plt.tight_layout()
plt.show()
```

### 8.3 层次聚类

```python
from scipy.cluster.hierarchy import dendrogram, linkage, fcluster
from sklearn.cluster import AgglomerativeClustering

# 生成数据
X, _ = make_blobs(n_samples=100, centers=3, random_state=42)

# 凝聚层次聚类
linkage_matrix = linkage(X, method='ward')

# 树状图
plt.figure(figsize=(10, 6))
dendrogram(linkage_matrix, truncate_mode='lastp', p=30)
plt.title('Ward层次聚类树状图')
plt.xlabel('样本')
plt.ylabel('距离')
plt.show()

# 切割树状图
labels = fcluster(linkage_matrix, t=3, criterion='maxclust')
print(f"簇标签: {np.unique(labels)}")

# 使用sklearn
agg = AgglomerativeClustering(n_clusters=3, linkage='ward')
labels = agg.fit_predict(X)
```

### 8.4 DBSCAN

```python
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

# 生成月牙形数据
X, _ = make_moons(n_samples=300, noise=0.1, random_state=42)

# DBSCAN
dbscan = DBSCAN(eps=0.2, min_samples=5)
labels = dbscan.fit_predict(X)

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise = list(labels).count(-1)

print(f"发现的簇数: {n_clusters}")
print(f"噪声点数: {n_noise}")

# 可视化
plt.figure(figsize=(8, 6))
unique_labels = set(labels)
colors = [plt.cm.Spectral(each) for each in np.linspace(0, 1, len(unique_labels))]

for k, col in zip(unique_labels, colors):
    if k == -1:
        col = [0, 0, 0, 1]
    class_member_mask = (labels == k)
    xy = X[class_member_mask]
    plt.scatter(xy[:, 0], xy[:, 1], c=[col], s=50, label=f'簇{k}')

plt.title(f'DBSCAN: {n_clusters}个簇, {n_noise}个噪声点')
plt.legend()
plt.show()
```

## 9. 实际应用案例：客户细分

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import pandas as pd

# 客户数据：年消费金额、消费频率、最近一次消费距今天数
np.random.seed(42)
n_customers = 500

data = {
    '年消费金额': np.concatenate([
        np.random.normal(5000, 1000, 200),
        np.random.normal(15000, 3000, 200),
        np.random.normal(50000, 10000, 100)
    ]),
    '消费频率': np.concatenate([
        np.random.normal(5, 2, 200),
        np.random.normal(15, 3, 200),
        np.random.normal(30, 5, 100)
    ]),
    '最近消费天数': np.concatenate([
        np.random.normal(180, 60, 200),
        np.random.normal(60, 30, 200),
        np.random.normal(15, 10, 100)
    ])
}

df = pd.DataFrame(data)

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)

# K-means聚类
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
df['簇'] = kmeans.fit_predict(X_scaled)

# 各簇统计
print("各簇特征均值:")
print(df.groupby('簇').mean().round(2))

# 簇的解释
cluster_names = {0: '低价值客户', 1: '中等价值客户', 2: '高价值客户'}
df['客户类型'] = df['簇'].map(cluster_names)
print(f"\n客户分布:\n{df['客户类型'].value_counts()}")
```

## 10. 关键要点总结

| 要点 | 内容 |
|------|------|
| K-means | 简单快速，假设球形簇，需指定K |
| 层次聚类 | 无需预设K，可生成树状图，计算复杂度高 |
| DBSCAN | 发现任意形状簇，自动处理噪声，对参数敏感 |
| GMM | 软聚类，基于概率模型，EM算法求解 |
| K值选择 | 肘部法则、轮廓系数、Gap统计量 |
| 距离度量 | 欧氏距离、马氏距离、余弦相似度 |
| 标准化 | 不同量纲时必须标准化 |
| 应用 | 客户细分、图像分割、文档聚类 |
