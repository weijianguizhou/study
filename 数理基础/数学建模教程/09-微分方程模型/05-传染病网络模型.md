## 二、网络基础
### 2.1 图论基本概念

**图** $G = (V, E)$，其中 $V$ 为节点集，$E$ 为边集。

**邻接矩阵** $A$：

$$A_{ij} = \begin{cases} 1 & \text{节点 } i \text{ 与 } j \text{ 相连} \\ 0 & \text{其他} \end{cases}$$

### 2.2 度分布

节点的度 $k_i$：与节点 $i$ 相连的边数。

$$k_i = \sum_{j} A_{ij}$$

**度分布** $P(k)$：随机选择一个节点，其度恰好为 $k$ 的概率。

**平均度**：$\langle k \rangle = \sum_k k P(k)$

### 2.3 常见网络类型

**随机网络（Erdos-Renyi）：**
$$P(k) = \binom{N}{k} p^k (1-p)^{N-k}$$
度分布服从二项分布，近似泊松分布。

**无标度网络（Barabasi-Albert）：**
$$P(k) \sim k^{-\gamma}, \quad 2 < \gamma \leq 3$$
度分布服从幂律分布，存在少量高度节点（枢纽节点）。

**小世界网络（Watts-Strogatz）：**
- 高聚类系数
- 短平均路径长度
- 介于规则网络和随机网络之间

### 2.4 网络特征参数

**聚类系数：**

$$C = \frac{3 \times \text{三角形数}}{\text{连通三元组数}}$$

**平均最短路径长度：**

$$\ell = \frac{1}{N(N-1)}\sum_{i \neq j} d(i,j)$$

import numpy as np

## 三、网络上的 SIR 模型
### 3.1 微观描述

设节点 $i$ 的状态为 $s_i \in \{S, I, R\}$，感染概率与邻居感染数相关。

### 3.2 度异质网络的平均场方程

设 $\rho_k(t)$ 为度为 $k$ 的节点中感染者的比例：

$$\frac{d\rho_k}{dt} = -\beta k \rho_k \Theta + \gamma (1 - \rho_k - \sigma_k) \rho_k$$

$$\frac{d\sigma_k}{dt} = \gamma \rho_k$$

其中 $\Theta$ 为边传播概率：

$$\Theta = \frac{\sum_k k P(k) \rho_k}{\langle k \rangle}$$

### 3.3 简化 SIS 模型

在 $\rho_k \ll 1$ 时线性化：

$$\frac{d\rho_k}{dt} = \rho_k (\gamma - \beta k \Theta)$$

解得：$\rho_k(t) \propto e^{(\gamma - \beta k \Theta)t}$，度越大的节点感染增长越快。

### 3.4 基本再生数（网络版）

$$R_0 = \frac{\beta \langle k^2 \rangle}{\gamma \langle k \rangle}$$

**关键结论：** 对于无标度网络 $P(k) \sim k^{-\gamma}$：
- 当 $\gamma \leq 3$ 时，$\langle k^2 \rangle \to \infty$，$R_0 \to \infty$
- 即使传染率 $\beta$ 很小，疾病也可传播

### 3.5 数值模拟

```python
from scipy.integrate import odeint

def network_SIR(y, t, beta, gamma, pk, k_values):
    rho_k = y[:len(k_values)]
    sigma_k = y[len(k_values):]
    Theta = np.sum(k_values * pk * rho_k) / np.sum(k_values * pk)
    drho = -beta * k_values * rho_k * Theta + gamma * (1 - rho_k - sigma_k) * rho_k
    dsigma = gamma * rho_k
    return np.concatenate([drho, dsigma])

k_min, k_max = 1, 50
gamma_pl = 2.5
k_values = np.arange(k_min, k_max + 1)
pk = k_values ** (-gamma_pl)
pk = pk / pk.sum()

beta = 0.15
gamma_rec = 0.05

rho0 = np.zeros(len(k_values))
rho0[0] = 0.01
sigma0 = np.zeros(len(k_values))
y0 = np.concatenate([rho0, sigma0])

t = np.linspace(0, 100, 1000)
sol = odeint(network_SIR, y0, t, args=(beta, gamma_rec, pk, k_values))
rho_k_sol = sol[:, :len(k_values)]

total_I = np.sum(pk * rho_k_sol, axis=1)

k2_mean = np.sum(k_values**2 * pk)
k_mean = np.sum(k_values * pk)
R0 = beta * k2_mean / (gamma_rec * k_mean)
print(f"R0 = {R0:.3f}")

plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.plot(t, total_I, 'r-', linewidth=2)
plt.xlabel('时间')
plt.ylabel('总感染比例')
plt.title(f'网络 SIR 模型 (R0={R0:.2f})')
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
for k_idx in [0, 5, 10, 15, 20]:
    plt.plot(t, rho_k_sol[:, k_idx], linewidth=2, label=f'k={k_values[k_idx]}')
plt.xlabel('时间')
plt.ylabel('感染比例 rho_k')
plt.title('不同度节点的感染动态')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

## 五、接触网络上的随机模拟
```python
def simulate_SIR_on_network(G, beta=0.3, gamma=0.1, initial_infected=5):
    states = {node: 'S' for node in G.nodes()}
    infected = list(np.random.choice(list(G.nodes()), initial_infected, replace=False))
    for node in infected:
        states[node] = 'I'

    I_history = [len(infected)]
    R_history = [0]
    S_history = [G.number_of_nodes() - len(infected)]

    while infected:
        new_infected = []
        recovered = []
        for node in infected:
            for neighbor in G.neighbors(node):
                if states[neighbor] == 'S' and np.random.random() < beta:
                    states[neighbor] = 'I'
                    new_infected.append(neighbor)
        for node in infected:
            if np.random.random() < gamma:
                states[node] = 'R'
                recovered.append(node)
        infected = [n for n in infected if n not in recovered]
        infected.extend(new_infected)
        I_history.append(len(infected))
        R_history.append(sum(1 for s in states.values() if s == 'R'))
        S_history.append(G.number_of_nodes() - len(infected) - R_history[-1])

    return S_history, I_history, R_history
```

## 六、枢纽节点与超级传播者
### 6.1 枢纽节点的重要性

在无标度网络中，度为 $k$ 的节点感染概率与 $k$ 正相关。

### 6.2 免疫策略比较

**随机免疫**：效果有限，$R_0$ 变化不大。

**目标免疫**：优先免疫度最大的节点，效果显著。

```python
def targeted_immunization(G, fraction):
    G_imm = G.copy()
    sorted_nodes = sorted(G_imm.degree(), key=lambda x: x[1], reverse=True)
    to_remove = [n for n, _ in sorted_nodes[:int(fraction * len(G))]]
    G_imm.remove_nodes_from(to_remove)
    return G_imm

def random_immunization(G, fraction):
    G_imm = G.copy()
    nodes = list(G_imm.nodes())
    to_remove = np.random.choice(nodes, int(fraction * len(nodes)), replace=False)
    G_imm.remove_nodes_from(to_remove)
    return G_imm
```

### 9.1 COVID-19 网络建模

- 接触追踪数据构建真实网络

### 9.2 关键结论

| 网络类型 | $R_0$ | 传播特征 |
|---------|-------|---------|
| 随机网络 | $\beta \langle k \rangle / \gamma$ | 指数增长后饱和 |
| 无标度网络 | $\beta \langle k^2 \rangle / (\gamma \langle k \rangle)$ | 快速爆发，枢纽节点先感染 |
| 小世界网络 | 介于两者之间 | 局部爆发到全局 |

## 十、关键要点总结
1. **度分布决定传播**：$P(k)$ 的二阶矩 $\langle k^2 \rangle$ 是关键参数
2. **网络 $R_0$**：$R_0 = \beta \langle k^2 \rangle / (\gamma \langle k \rangle)$
3. **无标度网络**：$\gamma \leq 3$ 时无传播阈值，极小传染率也能爆发
4. **枢纽节点**：超级传播者，目标免疫的优先对象
5. **平均场方法**：按度分组的异质平均场是主要分析工具
6. **随机模拟**：agent-based 模拟验证理论预测
7. **多层网络**：层间耦合改变传播动力学
8. **实际应用**：接触追踪 + 网络分析 = 精准防控
