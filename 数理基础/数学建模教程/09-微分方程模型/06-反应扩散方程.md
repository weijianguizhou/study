# 反应扩散方程

> **理论基础** → 参见 [[../../微分方程建模/种群相互作用模型#反应扩散|反应扩散]]

反应扩散方程将空间扩散项与局部反应动力学结合，描述物质在空间中同时扩散和反应的动态过程。

## 四、Turing 不稳定性
### 4.1 基本思想

Alan Turing (1952) 提出：均匀稳态在纯反应系统中稳定，但加入扩散后可能变得不稳定，导致空间图案自发形成。

### 4.2 两组分反应扩散系统

$$\begin{cases} \dfrac{\partial u}{\partial t} = D_u \nabla^2 u + f(u, v) \\[8pt] \dfrac{\partial v}{\partial t} = D_v \nabla^2 v + g(u, v) \end{cases}$$

### 4.3 线性稳定性分析

设 $(u_0, v_0)$ 为均匀稳态，即 $f(u_0, v_0) = 0$，$g(u_0, v_0) = 0$。

小扰动展开：

$$u = u_0 + \epsilon \hat{u}\,e^{i\mathbf{k}\cdot\mathbf{x} + \sigma t}, \quad v = v_0 + \epsilon \hat{v}\,e^{i\mathbf{k}\cdot\mathbf{x} + \sigma t}$$

代入线性化方程，得色散关系：

$$\det\begin{pmatrix} f_u - D_u k^2 - \sigma & f_v \\ g_u & g_v - D_v k^2 - \sigma \end{pmatrix} = 0$$

其中 $f_u = \partial f/\partial u|_{(u_0,v_0)}$，$k = |\mathbf{k}|$ 为波数。

### 4.4 Turing 不稳定条件

**条件 1（纯反应稳定）：**

$$\text{tr}(\mathbf{J}) = f_u + g_v < 0$$

$$\det(\mathbf{J}) = f_u g_v - f_v g_u > 0$$

**条件 2（扩散导致不稳定）：**

存在 $k^2 > 0$ 使 $\sigma(k^2) > 0$，即：

$$D_v f_u + D_u g_v > 2\sqrt{D_u D_v \det(\mathbf{J})}$$

**必要条件：** $f_u$ 和 $g_v$ 异号（一个激活，一个抑制）

**扩散比条件：** $D_v \gg D_u$（抑制子扩散更快）

### 4.5 临界波数

最不稳定波数：

$$k_c^2 = \sqrt{\frac{\det(\mathbf{J})}{D_u D_v}}$$

临界波长：

$$\lambda_c = \frac{2\pi}{k_c}$$

### 4.6 数值示例：图灵斑图

```python
import numpy as np
import matplotlib.pyplot as plt

# Schnakenberg 模型
# du/dt = D_u * laplacian(u) + a - u + u^2 * v
# dv/dt = D_v * laplacian(v) + b - u^2 * v

L = 2.0        # 区域大小
N = 100        # 网格数
dx = L / N
Du = 0.0001    # u 扩散系数
Dv = 0.01      # v 扩散系数
a = 0.1
b = 0.9
dt = 0.001
steps = 20000

# 初始化
u = a + b + 0.1 * np.random.randn(N, N)
v = b / (a + b)**2 + 0.1 * np.random.randn(N, N)

def laplacian(Z):
    """五点差分 Laplacian"""
    return (
        np.roll(Z, 1, axis=0) + np.roll(Z, -1, axis=0) +
        np.roll(Z, 1, axis=1) + np.roll(Z, -1, axis=1) - 4 * Z
    ) / dx**2

for step in range(steps):
    Lu = laplacian(u)
    Lv = laplacian(v)
    uvv = u**2 * v
    u += dt * (Du * Lu + a - u + uvv)
    v += dt * (Dv * Lv + b - uvv)

    if step % 5000 == 0:
        print(f"Step {step}/{steps}")

fig, axes = plt.subplots(1, 3, figsize=(15, 5))

axes[0].imshow(u, cmap='RdBu_r', origin='lower')
axes[0].set_title('Activator u')
axes[0].set_xlabel('x')
axes[0].set_ylabel('y')

axes[1].imshow(v, cmap='RdBu_r', origin='lower')
axes[1].set_title('Inhibitor v')
axes[1].set_xlabel('x')
axes[1].set_ylabel('y')

axes[2].plot(u[N//2, :], 'b-', linewidth=2, label='u (midline)')
axes[2].plot(v[N//2, :], 'r-', linewidth=2, label='v (midline)')
axes[2].set_xlabel('x')
axes[2].set_ylabel('浓度')
axes[2].set_title('沿中心线的浓度分布')
axes[2].legend()
axes[2].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 六、生态学中的反应扩散模型
### 6.1 带扩散的 Lotka-Volterra

$$\begin{cases} \dfrac{\partial x}{\partial t} = D_x \nabla^2 x + \alpha x - \beta xy \\[8pt] \dfrac{\partial y}{\partial t} = D_y \nabla^2 y + \delta xy - \gamma y \end{cases}$$

### 6.2 Turing 不稳定性在生态学中的应用

- 捕食者-猎物系统的空间斑图
- 植被分布的干旱区斑图（如纳米布沙漠的圆环）
- 珊瑚礁的空间结构

### 6.3 图灵不稳定的生态学条件

对于 Lotka-Volterra 系统：

$$f_u = 0, \quad f_v = -\beta x^*, \quad g_u = \delta y^*, \quad g_v = 0$$

需要 $D_y \gg D_x$（捕食者扩散更快），且满足色散关系条件。

```python
# 一维 Fisher-KPP 方程的行波解
L = 50.0
N = 500
dx = L / N
D = 1.0
r = 1.0
dt = 0.001
steps = 10000

x = np.linspace(0, L, N)
u = np.where(x < 5, 1.0, 0.0)  # 初始阶跃

def laplacian_1d(Z):
    Zp = np.roll(Z, -1)
    Zm = np.roll(Z, 1)
    return (Zp + Zm - 2*Z) / dx**2

c_theory = 2 * np.sqrt(D * r)
print(f"理论最小波速 c = {c_theory:.4f}")

snapshots = [0, 2000, 5000, 10000]
fig, ax = plt.subplots(figsize=(10, 6))

for step in range(steps + 1):
    Lu = laplacian_1d(u)
    u += dt * (D * Lu + r * u * (1 - u))
    if step in snapshots:
        ax.plot(x - c_theory * step * dt, u, linewidth=2, label=f't={step*dt:.1f}')

ax.set_xlabel('x - ct')
ax.set_ylabel('u')
ax.set_title(f'Fisher-KPP 行波 (c_theory = {c_theory:.2f})')
ax.legend()
ax.grid(True, alpha=0.3)
plt.show()
```

## 九、关键要点总结
1. **反应扩散方程**：$\partial u/\partial t = D\nabla^2 u + f(u)$，描述扩散与反应的耦合
2. **Turing 不稳定性**：均匀稳态因扩散变得不稳定，产生空间图案
3. **必要条件**：一个激活子 + 一个抑制子，且抑制子扩散更快
4. **临界波长**：$\lambda_c = 2\pi/k_c$ 决定图案的特征尺度
5. **Fisher-KPP**：行波最小波速 $c = 2\sqrt{Dr}$
6. **数值方法**：显式差分法简单但受 CFL 条件限制
7. **自然图案**：动物皮毛、指纹、植被分布都可用 Turing 机制解释
8. **模型丰富性**：不同反应项产生斑点、条纹、迷宫等多样图案
