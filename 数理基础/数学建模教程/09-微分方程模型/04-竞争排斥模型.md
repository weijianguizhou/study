# 竞争排斥模型

## 一、引言

竞争排斥原理（Competitive Exclusion Principle），又称高斯原理（Gause's Principle），指出两个生态位完全相同的物种不能长期共存。本节从微分方程角度分析竞争排斥的数学机制、生态位理论及其数学建模。

---

## 二、竞争排斥原理的数学基础

### 2.1 Lotka-Volterra 竞争模型

$$\begin{cases} \dfrac{dx_1}{dt} = r_1 x_1 \left(1 - \dfrac{x_1 + \alpha_{12} x_2}{K_1}\right) \\[8pt] \dfrac{dx_2}{dt} = r_2 x_2 \left(1 - \dfrac{x_2 + \alpha_{21} x_1}{K_2}\right) \end{cases}$$

参数含义：
- $x_i$：物种 $i$ 的种群密度
- $r_i$：物种 $i$ 的内禀增长率
- $K_i$：物种 $i$ 的环境承载力
- $\alpha_{12}$：物种 2 对物种 1 的竞争系数
- $\alpha_{21}$：物种 1 对物种 2 的竞争系数

### 2.2 零增长等斜线

**物种 1 的零等斜线（$\frac{dx_1}{dt} = 0$）：**

$$x_1 + \alpha_{12} x_2 = K_1 \implies x_2 = \frac{K_1 - x_1}{\alpha_{12}}$$

**物种 2 的零等斜线（$\frac{dx_2}{dt} = 0$）：**

$$x_2 + \alpha_{21} x_1 = K_2 \implies x_2 = K_2 - \alpha_{21} x_1$$

### 2.3 四种竞争结果

**情况 1：稳定共存**

条件：$\alpha_{12} < \frac{K_1}{K_2}$ 且 $\alpha_{21} < \frac{K_2}{K_1}$

即种内竞争大于种间竞争。

**情况 2：不稳定共存（双稳态）**

条件：$\alpha_{12} > \frac{K_1}{K_2}$ 且 $\alpha_{21} > \frac{K_2}{K_1}$

即种间竞争大于种内竞争，结果取决于初始条件。

**情况 3：物种 1 胜出**

条件：$\alpha_{12} < \frac{K_1}{K_2}$ 且 $\alpha_{21} > \frac{K_2}{K_1}$

**情况 4：物种 2 胜出**

条件：$\alpha_{12} > \frac{K_1}{K_2}$ 且 $\alpha_{21} < \frac{K_2}{K_1}$

### 2.4 数值示例

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

def competition(y, t, r1, r2, K1, K2, a12, a21):
    x1, x2 = y
    dx1 = r1 * x1 * (1 - (x1 + a12 * x2) / K1)
    dx2 = r2 * x2 * (1 - (x2 + a21 * x1) / K2)
    return [dx1, dx2]

# 参数设置
r1, r2 = 1.0, 0.8
K1, K2 = 100, 80

# 四种情况的参数
cases = [
    (0.5, 0.4, "稳定共存"),
    (1.5, 1.2, "不稳定共存"),
    (0.5, 1.5, "物种 1 胜出"),
    (1.5, 0.5, "物种 2 胜出")
]

fig, axes = plt.subplots(2, 2, figsize=(12, 10))
axes = axes.flatten()

t = np.linspace(0, 50, 1000)
initial_conditions = [(10, 10), (50, 60), (80, 20), (20, 70)]

for idx, (a12, a21, title) in enumerate(cases):
    ax = axes[idx]

    # 画零等斜线
    x1_range = np.linspace(0, K1 + 20, 200)
    iso1_x2 = (K1 - x1_range) / a12  # dx1/dt = 0
    iso2_x2 = K2 - a21 * x1_range     # dx2/dt = 0

    valid1 = iso1_x2 >= 0
    valid2 = iso2_x2 >= 0

    ax.plot(x1_range[valid1], iso1_x2[valid1], 'b-', linewidth=2, label='$dx_1/dt=0$')
    ax.plot(x1_range[valid2], iso2_x2[valid2], 'r-', linewidth=2, label='$dx_2/dt=0$')

    # 多个初始条件的轨迹
    for x1_0, x2_0 in [(5, 5), (50, 5), (5, 50), (50, 50), (80, 80)]:
        sol = odeint(competition, [x1_0, x2_0], t, args=(r1, r2, K1, K2, a12, a21))
        ax.plot(sol[:, 0], sol[:, 1], 'k-', linewidth=0.5, alpha=0.5)

    # 平衡点
    # 内部平衡点（如果存在）
    det = 1 - a12 * a21
    if abs(det) > 1e-10:
        x1_eq = (K1 - a12 * K2) / det
        x2_eq = (K2 - a21 * K1) / det
        if x1_eq > 0 and x2_eq > 0:
            ax.plot(x1_eq, x2_eq, 'g*', markersize=15, label=f'共存点 ({x1_eq:.1f}, {x2_eq:.1f})')

    ax.set_xlabel('物种 1 密度')
    ax.set_ylabel('物种 2 密度')
    ax.set_title(f'{title}\n($\\alpha_{{12}}={a12}$, $\\alpha_{{21}}={a21}$)')
    ax.legend(fontsize=8)
    ax.grid(True, alpha=0.3)
    ax.set_xlim(0, K1 + 20)
    ax.set_ylim(0, K2 + 20)

plt.tight_layout()
plt.show()
```

## 三、生态位理论

### 3.1 生态位的数学定义

**Hutchinson 生态位**：$n$ 维超体积

$$\mathcal{N}_i = \{(e_1, e_2, \ldots, e_n) : \text{物种 } i \text{ 在该环境条件下可存活}\}$$

其中 $e_j$ 为第 $j$ 个环境变量（温度、湿度、食物大小等）。

### 3.2 生态位重叠

两物种的生态位重叠度：

$$\alpha_{12} = \frac{\int \min\{p_1(e), p_2(e)\}\,de}{\int p_1(e)\,de}$$

或使用加权重叠：

$$\alpha_{12} = \frac{\int p_1(e) \cdot p_2(e)\,de}{\int [p_1(e)]^2\,de}$$

### 3.3 竞争系数与生态位重叠的关系

当生态位完全重合时，$\alpha_{12} = \alpha_{21} = 1$，竞争排斥发生。

当生态位部分重叠时，$0 < \alpha_{ij} < 1$，可能共存。

### 3.4 数值分析

```python
import numpy as np
from scipy.stats import norm
import matplotlib.pyplot as plt

# 两个物种的生态位（正态分布）
e = np.linspace(0, 20, 500)
mu1, sigma1 = 7, 2    # 物种 1 的最适环境
mu2, sigma2 = 13, 2   # 物种 2 的最适环境

p1 = norm.pdf(e, mu1, sigma1)
p2 = norm.pdf(e, mu2, sigma2)

# 生态位重叠计算
overlap = np.minimum(p1, p2)
alpha_12 = np.trapz(overlap, e) / np.trapz(p1, e)
alpha_21 = np.trapz(overlap, e) / np.trapz(p2, e)

plt.figure(figsize=(10, 6))
plt.plot(e, p1, 'b-', linewidth=2, label=f'物种 1 (μ={mu1}, σ={sigma1})')
plt.plot(e, p2, 'r-', linewidth=2, label=f'物种 2 (μ={mu2}, σ={sigma2})')
plt.fill_between(e, overlap, alpha=0.3, color='green', label='生态位重叠')
plt.xlabel('环境梯度')
plt.ylabel('适合度')
plt.title(f'生态位重叠分析\n$\\alpha_{{12}}={alpha_12:.3f}$, $\\alpha_{{21}}={alpha_21:.3f}$')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 四、资源竞争模型

### 4.1 MacArthur 资源利用模型

设 $R_j$ 为第 $j$ 种资源的密度：

$$\frac{dR_j}{dt} = r_j R_j \left(1 - \frac{R_j}{K_j}\right) - \sum_{i=1}^{n} c_{ij} x_i R_j$$

$$\frac{dx_i}{dt} = x_i \left(\sum_{j=1}^{m} e_{ij} c_{ij} R_j - d_i\right)$$

其中：
- $c_{ij}$：物种 $i$ 对资源 $j$ 的消耗率
- $e_{ij}$：物种 $i$ 利用资源 $j$ 的转化效率
- $d_i$：物种 $i$ 的死亡率

### 4.2 平衡点分析

在平衡态，$n$ 个物种共存需要 $m \geq n$ 种资源（资源数量不少于物种数量）。

### 4.3 Tilman 资源竞争理论

对于两种物种竞争两种资源：

$$\frac{dN_1}{dt} = N_1(e_{11}c_{11}R_1 + e_{12}c_{12}R_2 - d_1)$$

$$\frac{dN_2}{dt} = N_2(e_{21}c_{21}R_1 + e_{22}c_{22}R_2 - d_2)$$

**零等斜线在资源空间中：**

$R_1^* = \frac{d_1}{e_{11}c_{11}}$（物种 1 的 $R_1$ 零等斜线）

$R_2^* = \frac{d_1}{e_{12}c_{12}}$（物种 1 的 $R_2$ 零等斜线）

**竞争结果取决于 $R^*$ 值：** $R^*$ 更低的物种获胜。

## 五、竞争排斥的机制分析

### 5.1 种内竞争 vs 种间竞争

**关键参数：** $\frac{\alpha_{ij}\alpha_{ji}}{1}$

- $\alpha_{ij} \alpha_{ji} < 1$：种内竞争 > 种间竞争 → 稳定共存
- $\alpha_{ij} \alpha_{ji} > 1$：种间竞争 > 种内竞争 → 排斥

### 5.2 竞争排斥的时间尺度

竞争过程的时间尺度：

$$T_{\text{comp}} \sim \frac{1}{r_1 |\alpha_{12} - K_1/K_2|}$$

当生态位差异越小（$\alpha_{12}$ 越接近 $K_1/K_2$），竞争时间越长。

### 5.3 竞争-共存的临界条件

定义竞争强度：

$$C = \frac{\alpha_{12} \alpha_{21} K_1 K_2}{K_1 K_2} = \alpha_{12} \alpha_{21}$$

- $C < 1$：共存
- $C = 1$：临界
- $C > 1$：排斥

## 六、扩展模型

### 6.1 带 Allee 效应的竞争模型

$$\begin{cases} \dfrac{dx_1}{dt} = r_1 x_1 \left(\dfrac{x_1}{K_1} - 1\right)\left(1 - \dfrac{x_1 + \alpha_{12} x_2}{K_1}\right) \\[8pt] \dfrac{dx_2}{dt} = r_2 x_2 \left(\dfrac{x_2}{K_2} - 1\right)\left(1 - \dfrac{x_2 + \alpha_{21} x_1}{K_2}\right) \end{cases}$$

### 6.2 带时滞的竞争模型

$$\frac{dx_1}{dt} = r_1 x_1(t) \left(1 - \frac{x_1(t-\tau_1) + \alpha_{12} x_2(t-\tau_{12})}{K_1}\right)$$

时滞可能导致：
- 稳定共存变为不稳定振荡
- Hopf 分岔产生极限环

### 6.3 空间竞争模型（反应扩散）

$$\begin{cases} \dfrac{\partial x_1}{\partial t} = D_1 \nabla^2 x_1 + r_1 x_1\left(1 - \dfrac{x_1 + \alpha_{12}x_2}{K_1}\right) \\[8pt] \dfrac{\partial x_2}{\partial t} = D_2 \nabla^2 x_2 + r_2 x_2\left(1 - \dfrac{x_2 + \alpha_{21}x_1}{K_2}\right) \end{cases}$$

**空间结构效应：** 即使在局部竞争排斥的条件下，空间异质性也可能促进共存。

### 6.4 随机竞争模型

$$dx_i = r_i x_i\left(1 - \frac{x_i + \alpha_{ij}x_j}{K_i}\right)dt + \sigma_i x_i\,dW_i$$

噪声可以：
- 增强或减弱共存稳定性
- 导致随机振荡

## 七、竞争排斥的实验证据

### 7.1 Gause 的草履虫实验

- *Paramecium aurelia* 和 *Paramecium caudatum* 竞争
- 混合培养时 *P. aurelia* 总是胜出
- 验证了竞争排斥原理

### 7.2 密度依赖的竞争强度

竞争强度随密度增加而增加：

$$\alpha_{ij}(N) = \alpha_0 \left(1 + \frac{N}{K}\right)$$

```python
# 竞争排斥的动态过程
r1, r2 = 1.0, 0.9
K1, K2 = 100, 90
a12, a21 = 0.8, 1.3  # 物种 2 胜出

sol = odeint(competition, [50, 50], np.linspace(0, 100, 1000),
             args=(r1, r2, K1, K2, a12, a21))

plt.figure(figsize=(10, 6))
plt.plot(sol[:, 0], 'b-', linewidth=2, label='物种 1')
plt.plot(sol[:, 1], 'r-', linewidth=2, label='物种 2')
plt.axhline(y=0, color='k', linestyle='--', alpha=0.3)
plt.xlabel('时间')
plt.ylabel('种群密度')
plt.title(f'竞争排斥动态 ($\\alpha_{{12}}={a12}$, $\\alpha_{{21}}={a21}$)')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 八、共存机制总结

### 8.1 促进共存的因素

| 因素 | 机制 |
|------|------|
| 生态位分化 | 降低竞争系数 |
| 资源分区 | 利用不同资源 |
| 时间分区 | 在不同时间活跃 |
| 空间分区 | 占据不同空间 |
| 频率依赖 | 优势随密度变化 |
| 干扰机制 | 周期性重置竞争 |

### 8.2 竞争-共存的数学判据

$$\text{共存条件} \iff \begin{cases} \alpha_{12} < K_1/K_2 \\ \alpha_{21} < K_2/K_1 \end{cases}$$

或等价地：

$$\alpha_{12} \alpha_{21} < 1 \quad \text{且} \quad K_1/K_2 \cdot K_2/K_1 = 1$$

---

## 九、关键要点总结

1. **竞争排斥原理**：生态位完全相同的物种不能共存
2. **稳定共存条件**：种内竞争 > 种间竞争（$\alpha_{12}\alpha_{21} < 1$）
3. **零等斜线分析**：两条零等斜线的相对位置决定竞争结果
4. **生态位理论**：$n$ 维超体积模型描述物种需求空间
5. **资源竞争**：$R^*$ 最低的物种在竞争中获胜
6. **空间效应**：空间异质性可促进局部排斥的物种共存
7. **Allee 效应**：低密度时增长率为负，增加共存复杂性
8. **实验证据**：Gause 草履虫实验是竞争排斥的经典验证
