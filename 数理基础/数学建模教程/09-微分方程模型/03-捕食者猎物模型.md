# 捕食者猎物模型

> **理论基础** → 参见 [[../../微分方程建模/种群相互作用模型|种群相互作用]]

捕食者-猎物模型(Lotka-Volterra)描述两个种群间的捕食关系，揭示了生态系统的周期性振荡。

## 二、经典 Lotka-Volterra 模型
### 2.1 模型假设

- 只有一种捕食者和一种猎物
- 猎物在无捕食者时呈指数增长
- 捕食者在无猎物时呈指数衰减
- 捕食者的增长依赖于捕食猎物的数量
- 群体密度足够大，使用连续确定性模型

### 2.2 模型建立

设 $x(t)$ 为猎物密度，$y(t)$ 为捕食者密度：

$$\begin{cases} \dfrac{dx}{dt} = \alpha x - \beta xy \\[8pt] \dfrac{dy}{dt} = \delta xy - \gamma y \end{cases}$$

其中：
- $\alpha$：猎物的内禀增长率
- $\beta$：捕食率（捕食者对猎物的消耗率）
- $\delta$：捕食者将猎物转化为自身繁殖的效率
- $\gamma$：捕食者的自然死亡率

### 2.3 平衡点分析

令 $\frac{dx}{dt} = 0$，$\frac{dy}{dt} = 0$：

**平衡点 1：** $(x_1^*, y_1^*) = (0, 0)$（灭绝平衡点）

**平衡点 2：** $(x_2^*, y_2^*) = \left(\frac{\gamma}{\delta}, \frac{\alpha}{\beta}\right)$（共存平衡点）

### 2.4 雅可比矩阵与线性化

$$\mathbf{J}(x,y) = \begin{pmatrix} \alpha - \beta y & -\beta x \\ \delta y & \delta x - \gamma \end{pmatrix}$$

**在 $(0, 0)$ 处：**

$$\mathbf{J}(0,0) = \begin{pmatrix} \alpha & 0 \\ 0 & -\gamma \end{pmatrix}$$

特征值 $\lambda_1 = \alpha > 0$，$\lambda_2 = -\gamma < 0$ → 鞍点（不稳定）

**在 $(\gamma/\delta, \alpha/\beta)$ 处：**

$$\mathbf{J}\left(\frac{\gamma}{\delta}, \frac{\alpha}{\beta}\right) = \begin{pmatrix} 0 & -\beta\gamma/\delta \\ \alpha\delta/\beta & 0 \end{pmatrix}$$

特征方程：

$$\lambda^2 + \frac{\alpha\gamma}{\beta}\cdot\frac{\beta}{\delta}\cdot\delta = 0$$

$$\lambda^2 + \alpha\gamma = 0$$

$$\lambda = \pm i\sqrt{\alpha\gamma}$$

纯虚根 → 中心点（线性化分析为中性稳定，但实际为周期轨道）

### 2.5 守恒量与相轨线

定义 Hamilton 函数（首次积分）：

$$H(x, y) = \delta x - \gamma \ln x + \beta y - \alpha \ln y$$

沿解曲线 $H(x,y) = C$（常数），相轨线为闭合曲线。

**周期性质：**
- 振幅依赖于初始条件
- 平均值：$\bar{x} = \frac{\gamma}{\delta}$，$\bar{y} = \frac{\alpha}{\beta}$
- 周期 $T = \frac{2\pi}{\sqrt{\alpha\gamma}}$

### 2.6 数值示例

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

# 经典 Lotka-Volterra 模型参数
alpha = 1.0   # 猎物增长率
beta = 0.5    # 捕食率
delta = 0.3   # 转化效率
gamma = 0.8   # 捕食者死亡率

x0 = 10.0     # 初始猎物
y0 = 5.0      # 初始捕食者

def lotka_volterra(y, t, alpha, beta, delta, gamma):
    x, p = y
    dxdt = alpha * x - beta * x * p
    dpdt = delta * x * p - gamma * p
    return [dxdt, dpdt]

t = np.linspace(0, 50, 2000)
solution = odeint(lotka_volterra, [x0, y0], t, args=(alpha, beta, delta, gamma))
x_sol, y_sol = solution.T

# 计算平衡点
x_star = gamma / delta
y_star = alpha / beta
print(f"共存平衡点: x* = {x_star:.2f}, y* = {y_star:.2f}")

fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# 时间序列
axes[0].plot(t, x_sol, 'b-', linewidth=2, label='猎物 x')
axes[0].plot(t, y_sol, 'r-', linewidth=2, label='捕食者 y')
axes[0].axhline(y=x_star, color='b', linestyle='--', alpha=0.5)
axes[0].axhline(y=y_star, color='r', linestyle='--', alpha=0.5)
axes[0].set_xlabel('时间')
axes[0].set_ylabel('种群密度')
axes[0].set_title('时间序列')
axes[0].legend()
axes[0].grid(True, alpha=0.3)

# 相平面
axes[1].plot(x_sol, y_sol, 'g-', linewidth=2)
axes[1].plot(x_star, y_star, 'ko', markersize=10, label='平衡点')
axes[1].set_xlabel('猎物密度 x')
axes[1].set_ylabel('捕食者密度 y')
axes[1].set_title('相平面图')
axes[1].legend()
axes[1].grid(True, alpha=0.3)

# 向量场
X, Y = np.meshgrid(np.linspace(1, 25, 20), np.linspace(1, 12, 20))
U = alpha * X - beta * X * Y
V = delta * X * Y - gamma * Y
axes[2].quiver(X, Y, U, V, alpha=0.5)
axes[2].plot(x_star, y_star, 'ko', markersize=10, label='平衡点')
axes[2].set_xlabel('猎物密度 x')
axes[2].set_ylabel('捕食者密度 y')
axes[2].set_title('向量场')
axes[2].legend()
axes[2].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 三、带有承载力的 Lotka-Volterra 模型
### 3.1 模型改进

在猎物方程中加入逻辑斯蒂增长项：

$$\begin{cases} \dfrac{dx}{dt} = \alpha x\left(1 - \dfrac{x}{K}\right) - \beta xy \\[8pt] \dfrac{dy}{dt} = \delta xy - \gamma y \end{cases}$$

其中 $K$ 为猎物的环境承载力。

### 3.2 平衡点分析

**共存平衡点：**

$$x^* = \frac{\gamma}{\delta}, \quad y^* = \frac{\alpha}{\beta}\left(1 - \frac{\gamma}{\delta K}\right)$$

共存条件：$K > \frac{\gamma}{\delta}$（承载力足够大）

**稳定性：** 该平衡点是稳定焦点或节点（具有阻尼振荡或单调收敛）

### 3.3 数值比较

```python
# 带承载力的模型
K = 20  # 承载力

def lv_with_carrying(y, t, alpha, beta, delta, gamma, K):
    x, p = y
    dxdt = alpha * x * (1 - x / K) - beta * x * p
    dpdt = delta * x * p - gamma * p
    return [dxdt, dpdt]

sol_K = odeint(lv_with_carrying, [x0, y0], t, args=(alpha, beta, delta, gamma, K))

plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.plot(t, sol_K[:, 0], 'b-', linewidth=2, label='猎物')
plt.plot(t, sol_K[:, 1], 'r-', linewidth=2, label='捕食者')
plt.xlabel('时间')
plt.ylabel('种群密度')
plt.title(f'带承载力的 Lotka-Volterra (K={K})')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.plot(sol_K[:, 0], sol_K[:, 1], 'g-', linewidth=2)
plt.plot(gamma/delta, (alpha/beta)*(1-gamma/(delta*K)), 'ko', markersize=10)
plt.xlabel('猎物密度')
plt.ylabel('捕食者密度')
plt.title('相平面图（稳定焦点）')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

## 四、功能性反应函数
### 4.1 Holling I 型（线性型）

$$f(x) = ax$$

捕食率与猎物密度成线性关系。

### 4.2 Holling II 型（饱和型）

$$f(x) = \frac{ax}{b + x}$$

- $a$：最大捕食率
- $b$：半饱和常数（$f(x) = a/2$ 时的 $x$ 值）
- 捕食率随猎物密度增加而饱和

模型：

$$\begin{cases} \dfrac{dx}{dt} = \alpha x\left(1 - \dfrac{x}{K}\right) - \dfrac{axy}{b + x} \\[8pt] \dfrac{dy}{dt} = \dfrac{eaxy}{b + x} - \gamma y \end{cases}$$

### 4.3 Holling III 型（加速型）

$$f(x) = \frac{ax^n}{b^n + x^n}, \quad n > 1$$

### 4.4 Holling IV 型（减速型）

$$f(x) = \frac{ax}{b + x^2}$$

### 4.5 各类型比较

```python
x = np.linspace(0.01, 10, 200)
a, b = 1.0, 2.0
n = 2

f_I = a * x
f_II = a * x / (b + x)
f_III = a * x**n / (b**n + x**n)
f_IV = a * x / (b + x**2)

plt.figure(figsize=(10, 6))
plt.plot(x, f_I, 'b-', linewidth=2, label='Holling I (线性)')
plt.plot(x, f_II, 'r-', linewidth=2, label='Holling II (饱和)')
plt.plot(x, f_III, 'g-', linewidth=2, label='Holling III (加速)')
plt.plot(x, f_IV, 'm-', linewidth=2, label='Holling IV (减速)')
plt.xlabel('猎物密度 x')
plt.ylabel('功能性反应 f(x)')
plt.title('Holling 功能性反应函数比较')
plt.legend()
plt.grid(True, alpha=0.3)
plt.ylim(0, 1.5)
plt.show()
```

## 七、三维 Lotka-Volterra 系统
### 7.1 三物种食物链模型

$$\begin{cases} \dfrac{dx}{dt} = \alpha x - \beta_1 xy \\[6pt] \dfrac{dy}{dt} = \delta_1 xy - \beta_2 yz - \gamma_1 y \\[6pt] \dfrac{dz}{dt} = \delta_2 yz - \gamma_2 z \end{cases}$$

其中 $x$ 为猎物，$y$ 为初级捕食者，$z$ 为次级捕食者。

### 7.2 混沌行为

适当参数选择下，三维 Lotka-Volterra 系统可展现混沌动力学：
- 初值敏感性
- 奇异吸引子
- 正的 Lyapunov 指数

```python
# 三物种食物链模型（展示周期行为）
def food_chain(y, t, a, b1, d1, b2, g1, d2, g2):
    x, p1, p2 = y
    dxdt = a * x - b1 * x * p1
    dp1dt = d1 * x * p1 - b2 * p1 * p2 - g1 * p1
    dp2dt = d2 * p1 * p2 - g2 * p2
    return [dxdt, dp1dt, dp2dt]

# 参数设置
a = 1.0; b1 = 0.5; d1 = 0.3; b2 = 0.2
g1 = 0.4; d2 = 0.1; g2 = 0.3

y0_3d = [10, 5, 2]
t_long = np.linspace(0, 200, 5000)
sol_3d = odeint(food_chain, y0_3d, t_long, args=(a, b1, d1, b2, g1, d2, g2))

fig = plt.figure(figsize=(14, 5))
ax1 = fig.add_subplot(121)
ax1.plot(t_long, sol_3d[:, 0], 'b-', linewidth=1, label='猎物 x')
ax1.plot(t_long, sol_3d[:, 1], 'g-', linewidth=1, label='初级捕食者 y')
ax1.plot(t_long, sol_3d[:, 2], 'r-', linewidth=1, label='次级捕食者 z')
ax1.set_xlabel('时间')
ax1.set_ylabel('种群密度')
ax1.set_title('三物种食物链')
ax1.legend()
ax1.grid(True, alpha=0.3)

ax2 = fig.add_subplot(122, projection='3d')
ax2.plot(sol_3d[:, 0], sol_3d[:, 1], sol_3d[:, 2], 'g-', linewidth=1)
ax2.set_xlabel('x')
ax2.set_ylabel('y')
ax2.set_zlabel('z')
ax2.set_title('三维相空间')

plt.tight_layout()
plt.show()
```

## 八、应用实例
### 8.1 北极旅鼠-狐狸周期

- 旅鼠种群周期约 3-4 年
- 狐狸种群滞后旅鼠约 1 年
- Lotka-Volterra 模型可以定性解释该现象

### 8.2 鲸鱼-磷虾生态系统

- 南极磷虾（猎物）与须鲸（捕食者）
- 需要考虑承载力和环境因素
- 模型指导捕鲸配额制定

### 8.3 生物防治

- 引入天敌控制害虫
- 模型预测引入天敌后的种群动态
- 需确保 $R_0$ 足够大以建立天敌种群

## 九、关键要点总结
1. **经典 LV 模型**：闭合轨道，中性稳定，周期振荡
2. **平衡点**：$(0,0)$ 鞍点不稳定；$(\gamma/\delta, \alpha/\beta)$ 中心点
3. **周期**：$T = 2\pi/\sqrt{\alpha\gamma}$，与振幅无关
4. **承载力效应**：加入逻辑斯蒂项后，平衡点变为稳定焦点/节点
5. **功能性反应**：Holling II 型最常用，捕食率存在饱和
6. **竞争模型**：零增长等斜线的相对位置决定竞争结果
7. **多物种系统**：食物链可产生周期或混沌行为
8. **守恒量**：经典 LV 系统存在首次积分 $H(x,y) = C$
