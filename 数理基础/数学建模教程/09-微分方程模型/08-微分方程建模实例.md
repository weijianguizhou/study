## 二、药物浓度模型（房室模型）

### 2.1 问题描述

患者口服药物后，药物在体内如何分布和代谢？如何设计给药方案使血药浓度维持在治疗窗口内？

### 2.2 单室模型

**假设：**
- 身体为单一均匀房室
- 药物以速率 $k$ 排出（一级动力学）
- 口服吸收速率为 $k_a$

$$\frac{dC}{dt} = k_a D_{\text{dose}} e^{-k_a t} - k C$$

其中 $C$ 为血药浓度，$D_{\text{dose}}$ 为给药量。

**解析解：**

$$C(t) = \frac{k_a D_{\text{dose}}}{k_a - k}(e^{-kt} - e^{-k_a t})$$

### 2.3 两室模型

$$\begin{cases} \dfrac{dA_1}{dt} = -k_a A_1 - k_{12} A_1 + k_{21} A_2 \\[6pt] \dfrac{dA_2}{dt} = k_{12} A_1 - k_{21} A_2 - k_e A_2 \end{cases}$$

其中 $A_1$ 为中央室（血液），$A_2$ 为周边室（组织）。

### 2.4 多次给药模型

$$C(t) = \sum_{n=0}^{N-1} \frac{k_a D_{\text{dose}}}{k_a - k}\left[e^{-k(t-n\tau)} - e^{-k_a(t-n\tau)}\right] \cdot \mathbf{1}_{[n\tau, \infty)}(t)$$

稳态浓度范围：

$$C_{\max}^{\text{ss}} = \frac{k_a D_{\text{dose}}}{k_a - k} \cdot \frac{1}{1 - e^{-k\tau}}$$

$$C_{\min}^{\text{ss}} = C_{\max}^{\text{ss}} \cdot e^{-k\tau}$$

### 2.5 数值示例

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

# 单室模型参数
ka = 1.5     # 吸收速率
k = 0.2      # 排出速率
Dose = 500   # 给药量 (mg)

def drug_concentration_single(t, Dose, ka, k):
    return (ka * Dose / (ka - k)) * (np.exp(-k * t) - np.exp(-ka * t))

t = np.linspace(0, 24, 500)
C = drug_concentration_single(t, Dose, ka, k)

# 多次给药
tau = 8       # 给药间隔 (小时)
n_doses = 4
C_multi = np.zeros_like(t)

for i in range(n_doses):
    mask = t >= i * tau
    t_shifted = t[mask] - i * tau
    C_multi[mask] += drug_concentration_single(t_shifted, Dose, ka, k)

# 治疗窗口
C_min_therapeutic = 5   # mg/L
C_max_therapeutic = 20  # mg/L

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 单次给药
axes[0].plot(t, C, 'b-', linewidth=2, label='血药浓度')
axes[0].axhline(y=C_min_therapeutic, color='g', linestyle='--', label='治疗下限')
axes[0].axhline(y=C_max_therapeutic, color='r', linestyle='--', label='治疗上限')
axes[0].fill_between(t, C_min_therapeutic, C_max_therapeutic, alpha=0.1, color='green')
axes[0].set_xlabel('时间 (小时)')
axes[0].set_ylabel('血药浓度 (mg/L)')
axes[0].set_title('单次给药')
axes[0].legend()
axes[0].grid(True, alpha=0.3)

# 多次给药
axes[1].plot(t, C_multi, 'b-', linewidth=2, label='多次给药')
axes[1].axhline(y=C_min_therapeutic, color='g', linestyle='--', label='治疗下限')
axes[1].axhline(y=C_max_therapeutic, color='r', linestyle='--', label='治疗上限')
axes[1].fill_between(t, C_min_therapeutic, C_max_therapeutic, alpha=0.1, color='green')
axes[1].set_xlabel('时间 (小时)')
axes[1].set_ylabel('血药浓度 (mg/L)')
axes[1].set_title(f'多次给药 (间隔 {tau}h)')
axes[1].legend()
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 三、牛顿冷却定律

### 3.1 问题描述

一杯热咖啡在室温下如何冷却？死亡时间推断？

### 3.2 模型建立

$$\frac{dT}{dt} = -k(T - T_{\text{env}})$$

其中 $T$ 为物体温度，$T_{\text{env}}$ 为环境温度，$k$ 为冷却系数。

### 3.3 模型求解

分离变量：

$$\frac{dT}{T - T_{\text{env}}} = -k\,dt$$

$$T(t) = T_{\text{env}} + (T_0 - T_{\text{env}}) e^{-kt}$$

**半衰期：**

$$t_{1/2} = \frac{\ln 2}{k}$$

### 3.4 法医学应用（死亡时间推断）

设尸体温度 $T_{\text{body}}$，初始体温 $T_0 = 37°C$：

$$T_{\text{body}}(t) = T_{\text{env}} + (37 - T_{\text{env}}) e^{-kt}$$

通过测量尸体温度，反推死亡时间：

$$t = -\frac{1}{k} \ln\frac{T_{\text{body}} - T_{\text{env}}}{37 - T_{\text{env}}}$$

### 3.5 数值示例

```python
# 牛顿冷却定律
T_env = 22       # 室温 (°C)
T0 = 90          # 初始温度 (°C)
k_cool = 0.1     # 冷却系数

t_cool = np.linspace(0, 30, 500)
T_cool = T_env + (T0 - T_env) * np.exp(-k_cool * t_cool)

# 法医学应用
T_body_measured = 30  # 尸体温度
T_env_crime = 20      # 犯罪现场环境温度
k_body = 0.05         # 人体冷却系数
t_death = -1/k_body * np.log((T_body_measured - T_env_crime) / (37 - T_env_crime))

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 咖啡冷却
axes[0].plot(t_cool, T_cool, 'r-', linewidth=2)
axes[0].axhline(y=T_env, color='b', linestyle='--', alpha=0.5, label=f'室温 {T_env}°C')
axes[0].set_xlabel('时间 (分钟)')
axes[0].set_ylabel('温度 (°C)')
axes[0].set_title('牛顿冷却定律 - 咖啡冷却')
axes[0].legend()
axes[0].grid(True, alpha=0.3)

# 死亡时间推断
t_forensic = np.linspace(0, 20, 500)
T_forensic = T_env_crime + (37 - T_env_crime) * np.exp(-k_body * t_forensic)

axes[1].plot(t_forensic, T_forensic, 'b-', linewidth=2)
axes[1].plot(t_death, T_body_measured, 'ro', markersize=10, label=f'测量温度 ({T_body_measured}°C)')
axes[1].axhline(y=37, color='r', linestyle=':', alpha=0.5, label='正常体温 37°C')
axes[1].axhline(y=T_env_crime, color='k', linestyle='--', alpha=0.5)
axes[1].set_xlabel('死亡后时间 (小时)')
axes[1].set_ylabel('体温 (°C)')
axes[1].set_title(f'死亡时间推断: 约 {t_death:.1f} 小时前')
axes[1].legend()
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 四、弹簧振动模型（阻尼振动）

### 4.1 问题描述

弹簧-质量-阻尼器系统的运动方程。

### 4.2 模型建立

$$m\frac{d^2x}{dt^2} + c\frac{dx}{dt} + kx = F(t)$$

其中 $m$ 为质量，$c$ 为阻尼系数，$k$ 为弹簧常数，$F(t)$ 为外力。

### 4.3 自由振动分析

令 $F(t) = 0$，特征方程：

$$m\lambda^2 + c\lambda + k = 0$$

$$\lambda = \frac{-c \pm \sqrt{c^2 - 4mk}}{2m}$$

**三种情况：**

| 条件 | 类型 | 行为 |
|------|------|------|
| $c^2 > 4mk$ | 过阻尼 | 指数衰减，无振荡 |
| $c^2 = 4mk$ | 临界阻尼 | 最快衰减，无振荡 |
| $c^2 < 4mk$ | 欠阻尼 | 衰减振荡 |

### 4.4 欠阻尼解

$$x(t) = A e^{-\gamma t} \cos(\omega_d t + \phi)$$

其中：
- $\gamma = \frac{c}{2m}$（衰减率）
- $\omega_d = \sqrt{\omega_0^2 - \gamma^2}$（阻尼振动频率）
- $\omega_0 = \sqrt{k/m}$（固有频率）

### 4.5 共振

外力 $F(t) = F_0 \cos(\omega t)$，稳态解：

$$x_{ss}(t) = \frac{F_0/k}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}} \cos(\omega t - \phi)$$

其中 $r = \omega/\omega_0$，$\zeta = c/(2\sqrt{mk})$。

共振频率：$\omega_{\text{res}} = \omega_0\sqrt{1 - 2\zeta^2}$

### 4.6 数值示例

```python
# 弹簧振动
m, c, k = 1.0, 0.5, 4.0
omega0 = np.sqrt(k/m)
zeta = c / (2 * np.sqrt(m * k))

print(f"固有频率 omega0 = {omega0:.2f} rad/s")
print(f"阻尼比 zeta = {zeta:.3f}")

def spring_system(y, t, m, c, k, F0, omega):
    x, v = y
    dxdt = v
    dvdt = (F0 * np.cos(omega * t) - c * v - k * x) / m
    return [dxdt, dvdt]

t_spring = np.linspace(0, 20, 2000)

# 欠阻尼自由振动
sol_free = odeint(spring_system, [1.0, 0.0], t_spring, args=(m, c, k, 0, 0))

# 受迫振动（接近共振）
omega_drive = omega0 * 0.95
F0 = 2.0
sol_forced = odeint(spring_system, [0.0, 0.0], t_spring, args=(m, c, k, F0, omega_drive))

fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# 不同阻尼的自由振动
for zeta_val, label in [(0.05, '欠阻尼'), (0.5, '欠阻尼(重)'), (1.5, '过阻尼')]:
    c_val = 2 * zeta_val * np.sqrt(m * k)
    sol = odeint(spring_system, [1.0, 0.0], t_spring, args=(m, c_val, k, 0, 0))
    axes[0].plot(t_spring, sol[:, 0], linewidth=2, label=f'{label} (z={zeta_val})')

axes[0].set_xlabel('时间')
axes[0].set_ylabel('位移 x')
axes[0].set_title('自由振动')
axes[0].legend()
axes[0].grid(True, alpha=0.3)

# 受迫振动
axes[1].plot(t_spring, sol_forced[:, 0], 'b-', linewidth=1)
axes[1].set_xlabel('时间')
axes[1].set_ylabel('位移 x')
axes[1].set_title(f'受迫振动 (omega={omega_drive:.2f})')
axes[1].grid(True, alpha=0.3)

# 幅频响应
omega_range = np.linspace(0.1, 3 * omega0, 500)
amplitude = (F0/k) / np.sqrt((1 - (omega_range/omega0)**2)**2 +
            (2 * 0.1 * omega_range/omega0)**2)
axes[2].plot(omega_range/omega0, amplitude, 'r-', linewidth=2)
axes[2].axvline(x=1, color='k', linestyle='--', alpha=0.5, label='共振')
axes[2].set_xlabel('频率比 omega/omega0')
axes[2].set_ylabel('振幅')
axes[2].set_title('幅频响应曲线 (zeta=0.1)')
axes[2].legend()
axes[2].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 五、传染病传播实例（COVID-19）

### 5.1 SEIR 模型应用

$$\begin{cases} \dfrac{dS}{dt} = -\beta SI/N \\[6pt] \dfrac{dE}{dt} = \beta SI/N - \sigma E \\[6pt] \dfrac{dI}{dt} = \sigma E - \gamma I \\[6pt] \dfrac{dR}{dt} = \gamma I \end{cases}$$

### 5.2 参数估计

| 参数 | 含义 | 参考值 |
|------|------|--------|
| $\beta$ | 传染率 | 0.3/天 |
| $\sigma$ | 潜伏期倒数 | 1/5/天 |
| $\gamma$ | 恢复率 | 1/10/天 |
| $R_0$ | 基本再生数 | $\beta/\gamma \approx 3$ |

### 5.3 数值模拟与预测

```python
from scipy.integrate import odeint

def seir_model(y, t, beta, sigma, gamma, N):
    S, E, I, R = y
    dS = -beta * S * I / N
    dE = beta * S * I / N - sigma * E
    dI = sigma * E - gamma * I
    dR = gamma * I
    return [dS, dE, dI, dR]

N = 1e6
I0, E0, R0_init = 10, 100, 0
S0 = N - I0 - E0 - R0_init

beta, sigma, gamma = 0.3, 0.2, 0.1
R0_val = beta / gamma
print(f"R0 = {R0_val}")

t = np.linspace(0, 200, 1000)
sol = odeint(seir_model, [S0, E0, I0, R0_init], t, args=(beta, sigma, gamma, N))

plt.figure(figsize=(10, 6))
plt.plot(t, sol[:, 0]/N, 'b-', linewidth=2, label='S')
plt.plot(t, sol[:, 1]/N, 'orange', linewidth=2, label='E')
plt.plot(t, sol[:, 2]/N, 'r-', linewidth=2, label='I')
plt.plot(t, sol[:, 3]/N, 'g-', linewidth=2, label='R')
plt.xlabel('时间 (天)')
plt.ylabel('比例')
plt.title(f'COVID-19 SEIR 模型 (R0={R0_val})')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 六、种群生态实例

### 6.1 捕食者-猎物动态

以北极旅鼠-狐狸为背景：

$$\begin{cases} \dfrac{dx}{dt} = 0.5x - 0.02xy \\[6pt] \dfrac{dy}{dt} = 0.01xy - 0.4y \end{cases}$$

```python
def prey_predator(y, t):
    x, p = y
    dxdt = 0.5 * x - 0.02 * x * p
    dpdt = 0.01 * x * p - 0.4 * p
    return [dxdt, dpdt]

t_pop = np.linspace(0, 60, 2000)
sol_pop = odeint(prey_predator, [20, 30], t_pop)

fig, axes = plt.subplots(1, 2, figsize=(12, 5))
axes[0].plot(t_pop, sol_pop[:, 0], 'b-', linewidth=2, label='猎物')
axes[0].plot(t_pop, sol_pop[:, 1], 'r-', linewidth=2, label='捕食者')
axes[0].set_xlabel('时间 (年)')

axes[0].set_title('旅鼠-狐狸周期')

axes[1].plot(sol_pop[:, 0], sol_pop[:, 1], 'g-', linewidth=2)
```

## 七、RC 电路模型（电学应用）

### 7.1 电路方程

$$RC\frac{dV_C}{dt} + V_C = V_{\text{in}}$$

### 7.2 充放电过程

**充电：** $V_C(t) = V_0(1 - e^{-t/(RC)})$

**放电：** $V_C(t) = V_0 e^{-t/(RC)}$

时间常数 $\tau = RC$。

```python
RC = 1.0
V0 = 5.0
t_rc = np.linspace(0, 5*RC, 500)

V_charge = V0 * (1 - np.exp(-t_rc / RC))
V_discharge = V0 * np.exp(-t_rc / RC)

plt.figure(figsize=(10, 6))
plt.plot(t_rc/RC, V_charge, 'b-', linewidth=2, label='充电')
plt.plot(t_rc/RC, V_discharge, 'r-', linewidth=2, label='放电')
plt.axhline(y=V0, color='k', linestyle='--', alpha=0.3)
plt.axhline(y=V0*(1-1/np.e), color='g', linestyle=':', alpha=0.5, label=f'63.2% at t=RC')
plt.xlabel('t / RC')
plt.ylabel('电容电压 V')
plt.title('RC 电路充放电')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 八、放射性衰变模型

### 8.1 基本方程

$$\frac{dN}{dt} = -\lambda N$$

解：$N(t) = N_0 e^{-\lambda t}$

半衰期：$t_{1/2} = \frac{\ln 2}{\lambda}$

### 8.2 放射性衰变链

$$\begin{cases} \dfrac{dN_1}{dt} = -\lambda_1 N_1 \\[6pt] \dfrac{dN_2}{dt} = \lambda_1 N_1 - \lambda_2 N_2 \\[6pt] \dfrac{dN_3}{dt} = \lambda_2 N_2 \end{cases}$$

### 8.3 碳-14 年代测定

$$\text{年龄} = -\frac{t_{1/2}}{\ln 2} \ln\left(\frac{A}{A_0}\right)$$

其中 $A$ 为当前放射性活度，$A_0$ 为初始活度。

## 九、人口预测实例

### 9.1 Logistic 拟合

```python
from scipy.optimize import curve_fit

def logistic(t, N0, r, K):
    return K / (1 + ((K - N0) / N0) * np.exp(-r * t))

years = np.array([1950, 1960, 1970, 1980, 1990, 2000, 2010, 2020])
population = np.array([2.5, 3.0, 3.7, 4.4, 5.3, 6.1, 6.9, 7.8])  # 十亿

popt, pcov = curve_fit(logistic, years - 1950, population, p0=[2.5, 0.02, 10])
N0_fit, r_fit, K_fit = popt

t_pred = np.linspace(0, 150, 500)
pop_pred = logistic(t_pred, N0_fit, r_fit, K_fit)

plt.figure(figsize=(10, 6))
plt.scatter(years, population, color='red', s=50, zorder=5, label='实际数据')
plt.plot(t_pred + 1950, pop_pred, 'b-', linewidth=2, label='Logistic 拟合')
plt.axhline(y=K_fit, color='k', linestyle='--', alpha=0.5, label=f'K={K_fit:.1f}B')
plt.xlabel('年份')
plt.ylabel('人口 (十亿)')
plt.title(f'世界人口预测 (r={r_fit:.4f}, K={K_fit:.1f}B)')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 十、建模方法论总结

### 10.1 建模流程

1. **问题分析**：明确目标，识别变量
2. **模型假设**：简化现实，建立假设
3. **方程建立**：根据物理/生物定律列方程
4. **求解方法**：解析或数值求解
5. **结果分析**：解释物理意义
6. **模型验证**：与实验/观测数据对比
7. **模型改进**：根据偏差修正假设

### 10.2 常用求解方法

| 方法 | 适用场景 | 优缺点 |
|------|---------|--------|
| 分离变量 | 简单可分离方程 | 精确，但适用范围有限 |
| 积分因子 | 一阶线性方程 | 精确解析解 |
| Laplace 变换 | 线性常系数方程 | 可处理不连续输入 |
| 数值积分 | 复杂非线性系统 | 通用，但有截断误差 |
| 相平面分析 | 二维自治系统 | 直观理解全局动力学 |

## 十一、关键要点总结

1. **药物动力学**：房室模型，$C(t)$ 随时间指数衰减与吸收的竞争
2. **牛顿冷却**：$T(t) = T_{\text{env}} + (T_0 - T_{\text{env}})e^{-kt}$
3. **阻尼振动**：$c^2 < 4mk$ 为欠阻尼，产生衰减振荡
4. **共振**：外力频率接近固有频率时振幅最大
5. **传染病**：SEIR 模型预测疫情发展，$R_0$ 决定是否爆发
6. **生态模型**：捕食者-猎物产生周期振荡
7. **RC 电路**：时间常数 $\tau = RC$，充放电呈指数规律
8. **放射性衰变**：$N(t) = N_0 e^{-\lambda t}$，半衰期恒定
9. **建模方法**：问题分析 → 假设简化 → 方程建立 → 求解验证
10. **模型选择**：根据问题复杂度选择合适的模型精度
