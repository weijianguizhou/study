# 传染病模型

## 一、引言

传染病动力学是数学建模的重要应用领域。通过建立微分方程模型，我们可以理解传染病的传播规律，预测疫情发展趋势，评估防控措施效果。本节介绍经典的仓室模型及其扩展。

---

## 二、SIR 模型

### 2.1 模型假设

- 总人口 $N$ 恒定（不考虑出生死亡）
- 人群分为三类：易感者（S）、感染者（I）、移除者（R）
- 传播为频率依赖型（ mass action ）
- 感染者以固定速率 $\gamma$ 康复并获得永久免疫

### 2.2 模型建立

$$\begin{cases} \dfrac{dS}{dt} = -\beta SI/N \\[8pt] \dfrac{dI}{dt} = \beta SI/N - \gamma I \\[8pt] \dfrac{dR}{dt} = \gamma I \end{cases}$$

其中：
- $\beta$ 为有效接触率（传染率）
- $\gamma$ 为恢复率（$\frac{1}{\gamma}$ 为平均感染期）
- $S + I + R = N$（守恒）

### 2.3 基本再生数

$$R_0 = \frac{\beta}{\gamma}$$

**含义：** 在完全易感人群中，一个感染者平均传染的人数。

- $R_0 > 1$：疫情爆发
- $R_0 < 1$：疫情消退
- $R_0 = 1$：临界阈值

### 2.4 模型分析

**无感染平衡点：** $(S^*, I^*, R^*) = (N, 0, 0)$

**地方病平衡点（当 $R_0 > 1$ 时）：**

$$S^* = \frac{N}{R_0}, \quad I^* = \frac{N(R_0 - 1)}{R_0}, \quad R^* = N - S^* - I^*$$

**相平面分析：**

由 $\frac{dI}{dS} = \frac{\beta SI/N - \gamma I}{-\beta SI/N} = -1 + \frac{\gamma N}{\beta S} = -1 + \frac{N}{R_0 S}$

积分得：

$$I = -S + \frac{N}{R_0}\ln S + C$$

其中常数 $C$ 由初始条件确定。

**最终规模关系：**

设 $S_\infty$ 为最终易感者数量，$R_\infty$ 为最终移除者数量：

$$R_\infty = N - S_\infty$$

$$\ln\frac{S_\infty}{S_0} = -R_0\left(1 - \frac{S_\infty}{N}\right)$$

### 2.5 数值示例

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

# SIR 模型参数
beta = 0.3    # 传染率
gamma = 0.1   # 恢复率
N = 1000      # 总人口
I0 = 1        # 初始感染者
R0 = 0        # 初始移除者
S0 = N - I0 - R0

R_0 = beta / gamma
print(f"基本再生数 R₀ = {R_0}")

def SIR(y, t, beta, gamma, N):
    S, I, R = y
    dS = -beta * S * I / N
    dI = beta * S * I / N - gamma * I
    dR = gamma * I
    return [dS, dI, dR]

t = np.linspace(0, 100, 1000)
y0 = [S0, I0, R0]
solution = odeint(SIR, y0, t, args=(beta, gamma, N))

S, I, R = solution.T

plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.plot(t, S, 'b-', linewidth=2, label='S (易感者)')
plt.plot(t, I, 'r-', linewidth=2, label='I (感染者)')
plt.plot(t, R, 'g-', linewidth=2, label='R (移除者)')
plt.xlabel('时间 (天)')
plt.ylabel('人数')
plt.title(f'SIR 模型 (R₀ = {R_0})')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.plot(S, I, 'r-', linewidth=2)
plt.xlabel('S (易感者)')
plt.ylabel('I (感染者)')
plt.title('SIR 相平面图')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

## 三、SEIR 模型

### 3.1 模型假设

在 SIR 基础上增加暴露期（E）：
- 感染后不立即具有传染性，经历潜伏期（E）
- 潜伏期平均长度为 $\frac{1}{\sigma}$

### 3.2 模型建立

$$\begin{cases} \dfrac{dS}{dt} = -\beta SI/N \\[8pt] \dfrac{dE}{dt} = \beta SI/N - \sigma E \\[8pt] \dfrac{dI}{dt} = \sigma E - \gamma I \\[8pt] \dfrac{dR}{dt} = \gamma I \end{cases}$$

### 3.3 基本再生数

$$R_0 = \frac{\beta \sigma}{\gamma(\sigma + \gamma)}$$

### 3.4 平衡点分析

**无病平衡点：** $(S^*, E^*, I^*, R^*) = (N, 0, 0, 0)$

**地方病平衡点（当 $R_0 > 1$ 时）：**

$$S^* = \frac{N}{R_0}$$

$$E^* = \frac{\gamma N(R_0 - 1)}{\sigma R_0}$$

$$I^* = \frac{\sigma N(R_0 - 1)}{\sigma R_0}$$

### 3.5 数值示例

```python
# SEIR 模型
sigma = 0.2   # 1/潜伏期 = 1/5 天
gamma = 0.1   # 恢复率

def SEIR(y, t, beta, sigma, gamma, N):
    S, E, I, R = y
    dS = -beta * S * I / N
    dE = beta * S * I / N - sigma * E
    dI = sigma * E - gamma * I
    dR = gamma * I
    return [dS, dE, dI, dR]

E0 = 0
y0_seir = [S0, E0, I0, R0]
sol_seir = odeint(SEIR, y0_seir, t, args=(beta, sigma, gamma, N))
S_seir, E_seir, I_seir, R_seir = sol_seir.T

plt.figure(figsize=(10, 6))
plt.plot(t, S_seir, 'b-', linewidth=2, label='S')
plt.plot(t, E_seir, 'orange', linewidth=2, label='E')
plt.plot(t, I_seir, 'r-', linewidth=2, label='I')
plt.plot(t, R_seir, 'g-', linewidth=2, label='R')
plt.xlabel('时间 (天)')
plt.ylabel('人数')
plt.title('SEIR 传染病模型')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 四、SIS 模型

### 4.1 模型假设

- 康复后不获得永久免疫，重新变为易感者
- 适用于如流感等可反复感染的疾病

### 4.2 模型建立

$$\begin{cases} \dfrac{dS}{dt} = -\beta SI/N + \gamma I \\[8pt] \dfrac{dI}{dt} = \beta SI/N - \gamma I \end{cases}$$

由于 $S + I = N$，化简为：

$$\frac{dI}{dt} = (\beta - \gamma)I - \frac{\beta}{N}I^2$$

### 4.3 平衡点分析

这是一维 Logistic 方程的形式！

- $I^* = 0$（无病平衡点）：当 $R_0 \leq 1$ 时稳定
- $I^* = N\left(1 - \frac{1}{R_0}\right)$（地方病平衡点）：当 $R_0 > 1$ 时稳定

### 4.4 数值示例

```python
# SIS 模型
def SIS(y, t, beta, gamma, N):
    S, I = y
    dS = -beta * S * I / N + gamma * I
    dI = beta * S * I / N - gamma * I
    return [dS, dI]

y0_sis = [S0, I0]
sol_sis = odeint(SIS, y0_sis, t, args=(beta, gamma, N))
S_sis, I_sis = sol_sis.T

plt.figure(figsize=(10, 6))
plt.plot(t, S_sis, 'b-', linewidth=2, label='S')
plt.plot(t, I_sis, 'r-', linewidth=2, label='I')
plt.xlabel('时间 (天)')
plt.ylabel('人数')
plt.title(f'SIS 传染病模型 (R₀ = {R_0})')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 五、带有出生和死亡的 SIR 模型

### 5.1 模型建立

$$\begin{cases} \dfrac{dS}{dt} = \Lambda - \beta SI/N - \mu S \\[8pt] \dfrac{dI}{dt} = \beta SI/N - (\gamma + \mu) I \\[8pt] \dfrac{dR}{dt} = \gamma I - \mu R \end{cases}$$

其中 $\Lambda$ 为出生率（新进入易感人群的速率），$\mu$ 为自然死亡率。

### 5.2 基本再生数

$$R_0 = \frac{\beta}{\gamma + \mu}$$

### 5.3 平衡点

**无病平衡点：**

$$S^* = \frac{\Lambda}{\mu}, \quad I^* = 0, \quad R^* = \frac{\gamma \Lambda}{\mu(\gamma + \mu)}$$

**地方病平衡点（当 $R_0 > 1$ 时）：**

$$S^* = \frac{N^*}{R_0}, \quad I^* = \frac{\mu N^*(R_0 - 1)}{\beta}$$

其中 $N^* = \frac{\Lambda}{\mu}$

## 六、时滞传染病模型

### 6.1 具有时滞的 SIR 模型

考虑感染到具有传染性之间的时滞 $\tau$：

$$\frac{dI}{dt} = \beta S(t) I(t-\tau)/N - \gamma I(t)$$

### 6.2 特征方程分析

在无病平衡点线性化，设 $I(t) = I_0 e^{\lambda t}$：

$$\lambda + \gamma = \beta R_0 e^{-\lambda \tau}$$

稳定性分析需要研究该超越方程的根的分布。

## 七、空间传染病模型

### 7.1 反应扩散 SIR 模型

$$\begin{cases} \dfrac{\partial S}{\partial t} = D_S \nabla^2 S - \beta SI/N \\[8pt] \dfrac{\partial I}{\partial t} = D_I \nabla^2 I + \beta SI/N - \gamma I \\[8pt] \dfrac{\partial R}{\partial t} = D_R \nabla^2 R + \gamma I \end{cases}$$

其中 $D_S, D_I, D_R$ 为各仓室的扩散系数。

### 7.2 行波解

假设存在行波解 $S(x,t) = S(x - ct)$，$I(x,t) = I(x - ct)$，其中 $c$ 为波速。

最小波速：

$$c_{\min} = 2\sqrt{D_I(\beta - \gamma)}$$

## 八、防控措施建模

### 8.1 疫苗接种模型

设接种比例为 $p$，则初始条件改为：

$$S(0) = (1-p)N, \quad R(0) = pN$$

有效再生数：

$$R_{\text{eff}} = R_0 \cdot (1-p)$$

群体免疫阈值：

$$p_c = 1 - \frac{1}{R_0}$$

### 8.2 隔离措施模型

$$\begin{cases} \dfrac{dS}{dt} = -\beta SI/N - q\beta SI/N \\[8pt] \dfrac{dI}{dt} = \beta SI/N - \gamma I \end{cases}$$

其中 $q$ 为隔离率。有效再生数变为：

$$R_{\text{eff}} = \frac{\beta(1-q)}{\gamma}$$

### 8.3 数值比较

```python
# 不同防控措施的效果比较
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# 无防控
sol0 = odeint(SIR, [S0, I0, 0], t, args=(0.3, 0.1, N))
axes[0].plot(t, sol0[:, 1], 'r-', linewidth=2)
axes[0].set_title('无防控 (R₀=3)')
axes[0].set_ylabel('感染者数 I')

# 接种疫苗 (p = 60%)
S0_vac = 0.4 * N
I0_vac = 1
sol_vac = odeint(SIR, [S0_vac, I0_vac, 0.6*N], t, args=(0.3, 0.1, N))
axes[1].plot(t, sol_vac[:, 1], 'r-', linewidth=2)
axes[1].set_title(f'疫苗接种 (p=60%, R_eff={0.3/0.1*0.4:.1f})')

# 隔离 (q = 50%)
def SIR_isolation(y, t, beta, gamma, q, N):
    S, I, R = y
    dS = -(1-q) * beta * S * I / N
    dI = (1-q) * beta * S * I / N - gamma * I
    dR = gamma * I
    return [dS, dI, dR]

sol_iso = odeint(SIR_isolation, [S0, I0, 0], t, args=(0.3, 0.1, 0.5, N))
axes[2].plot(t, sol_iso[:, 1], 'r-', linewidth=2)
axes[2].set_title(f'隔离 (q=50%, R_eff={0.3/0.1*0.5:.1f})')

for ax in axes:
    ax.set_xlabel('时间 (天)')
    ax.grid(True, alpha=0.3)
    ax.set_ylim(0, max(sol0[:, 1]) * 1.1)

plt.tight_layout()
plt.show()
```

## 九、实际应用：COVID-19 建模

### 9.1 参数估计

| 参数 | 含义 | COVID-19 参考值 |
|------|------|----------------|
| $\beta$ | 传染率 | 0.3-0.5 /天 |
| $\gamma$ | 恢复率 | 0.1 /天（10天恢复） |
| $\sigma$ | 潜伏期倒数 | 0.14 /天（7天潜伏） |
| $R_0$ | 基本再生数 | 2.5-3.5 |

### 9.2 有效再生数的动态估计

$$R_{\text{eff}}(t) = R_0 \cdot \frac{S(t)}{N} \cdot (1 - p(t))$$

其中 $p(t)$ 为 $t$ 时刻的疫苗接种率。

## 十、关键要点总结

1. **SIR 模型**：三个仓室，$R_0 = \beta / \gamma$，相平面为单调曲线
2. **SEIR 模型**：增加潜伏期，$R_0 = \beta\sigma / [\gamma(\sigma + \gamma)]$，疫情峰值延迟
3. **SIS 模型**：无永久免疫，存在地方病平衡点
4. **$R_0 > 1$**：疫情爆发；$R_0 < 1$：疫情消退
5. **群体免疫**：接种比例 $p_c = 1 - 1/R_0$
6. **空间模型**：引入扩散项，行波解描述疫情的空间传播
7. **防控策略**：疫苗接种、隔离、社交距离均可降低 $R_{\text{eff}}$
8. **参数估计**：结合实际数据拟合模型参数，是预测和决策的基础
