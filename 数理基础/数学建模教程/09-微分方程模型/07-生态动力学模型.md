# 生态动力学模型

> **理论基础** → 参见 [[../../微分方程建模/种群相互作用模型|种群相互作用]]

生态动力学模型通过微分方程组描述生态系统中多个种群的相互作用和动态演化规律。

## 二、单种群增长模型
### 2.1 指数增长模型

$$\frac{dN}{dt} = rN$$

解：$N(t) = N_0 e^{rt}$，种群无限制增长。

### 2.2 Logistic 增长模型

$$\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right)$$

- $K$ 为环境承载力
- S 型增长曲线
- 增长最快点在 $N = K/2$

### 2.3 带 Allee 效应的模型

$$\frac{dN}{dt} = rN\left(\frac{N}{A} - 1\right)\left(1 - \frac{N}{K}\right)$$

其中 $A$ 为最小可行种群规模（Allee 阈值）。

**平衡点分析：**
- $N^* = 0$：稳定
- $N^* = A$：不稳定（Allee 阈值）
- $N^* = K$：稳定

当 $N < A$ 时种群灭绝，$N > A$ 时种群增长至 $K$。

### 2.4 数值比较

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

N = np.linspace(0, 120, 500)
r, K, A = 0.5, 100, 20

dN_exp = r * N
dN_log = r * N * (1 - N / K)
dN_allee = r * N * (N/A - 1) * (1 - N/K)

plt.figure(figsize=(10, 6))
plt.plot(N, dN_exp, 'b-', linewidth=2, label='指数增长')
plt.plot(N, dN_log, 'r-', linewidth=2, label='Logistic')
plt.plot(N, dN_allee, 'g-', linewidth=2, label='Allee 效应')
plt.axhline(y=0, color='k', linestyle='--', alpha=0.3)
plt.xlabel('种群密度 N')
plt.ylabel('dN/dt')
plt.title('单种群增长模型比较')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 四、多种群竞争模型
### 4.1 Lotka-Volterra 竞争模型

$$\begin{cases} \dfrac{dN_1}{dt} = r_1 N_1 \left(1 - \dfrac{N_1 + \alpha_{12} N_2}{K_1}\right) \\[8pt] \dfrac{dN_2}{dt} = r_2 N_2 \left(1 - \dfrac{N_2 + \alpha_{21} N_1}{K_2}\right) \end{cases}$$

### 4.2 平衡点与稳定性

**共存平衡点：**

$$N_1^* = \frac{K_1 - \alpha_{12}K_2}{1 - \alpha_{12}\alpha_{21}}, \quad N_2^* = \frac{K_2 - \alpha_{21}K_1}{1 - \alpha_{12}\alpha_{21}}$$

**共存条件：** $\alpha_{12} < K_1/K_2$ 且 $\alpha_{21} < K_2/K_1$

```python
# 竞争动态
def competition(y, t, r1, r2, K1, K2, a12, a21):
    N1, N2 = y
    dN1 = r1 * N1 * (1 - (N1 + a12*N2) / K1)
    dN2 = r2 * N2 * (1 - (N2 + a21*N1) / K2)
    return [dN1, dN2]

t = np.linspace(0, 50, 1000)
r1, r2, K1, K2 = 1.0, 0.8, 100, 80
a12, a21 = 0.5, 0.4

sol = odeint(competition, [20, 20], t, args=(r1, r2, K1, K2, a12, a21))

plt.figure(figsize=(10, 6))
plt.plot(t, sol[:, 0], 'b-', linewidth=2, label='物种 1')
plt.plot(t, sol[:, 1], 'r-', linewidth=2, label='物种 2')
plt.xlabel('时间')
plt.ylabel('种群密度')
plt.title('两物种稳定共存')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 八、空间生态动力学
### 8.1 反应扩散竞争模型

$$\begin{cases} \dfrac{\partial N_1}{\partial t} = D_1 \nabla^2 N_1 + r_1 N_1\left(1 - \dfrac{N_1 + \alpha_{12}N_2}{K_1}\right) \\[8pt] \dfrac{\partial N_2}{\partial t} = D_2 \nabla^2 N_2 + r_2 N_2\left(1 - \dfrac{N_2 + \alpha_{21}N_1}{K_2}\right) \end{cases}$$

### 8.2 元胞自动机模型

离散空间、离散时间的种群动态模型：
- 每个格点有状态（空/物种1/物种2）
- 邻域交互规则
- 扩散与竞争同时发生

### 8.3 空间异质性对共存的影响

- 均质环境中排斥的物种在空间异质环境中可能共存
- 源-汇动态（source-sink dynamics）
- 生境破碎化效应

## 十、应用实例
### 10.1 渔业资源管理

**最大可持续产量（MSY）：**

$$\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right) - h$$

使 $h$ 最大化且 $dN/dt = 0$：

$$N_{\text{MSY}} = \frac{K}{2}, \quad h_{\text{MSY}} = \frac{rK}{4}$$

### 10.2 害虫管理

阈值理论：害虫密度低于经济阈值时不施药。

### 10.3 保护生物学

最小可行种群（MVP）估算：
- 考虑 Allee 效应
- 环境随机性
- 遗传多样性

```python
# 渔业 MSY 分析
r, K = 0.5, 1000
h_max = r * K / 4
N_msy = K / 2

N_range = np.linspace(0, K, 200)
growth = r * N_range * (1 - N_range / K)

plt.figure(figsize=(10, 6))
plt.plot(N_range, growth, 'b-', linewidth=2)
plt.axhline(y=h_max, color='r', linestyle='--', label=f'MSY = {h_max:.0f}')
plt.axvline(x=N_msy, color='g', linestyle=':', label=f'N_MSY = {N_msy:.0f}')
plt.fill_between(N_range, growth, h_max, where=(growth > h_max),
                 alpha=0.2, color='green')
plt.xlabel('种群大小 N')
plt.ylabel('增长率')
plt.title('最大可持续产量 (MSY) 分析')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 十一、关键要点总结
1. **Logistic 模型**：$\dot{N} = rN(1-N/K)$，S 型增长，$N^*=K$ 稳定
2. **Allee 效应**：低密度时增长率为负，存在灭绝阈值 $A$
3. **种间竞争**：$\alpha_{12}\alpha_{21} < 1$ 为共存条件
4. **时滞效应**：$\tau > \pi/(2r)$ 导致 Hopf 分岔和振荡
5. **MSY**：$h_{\text{MSY}} = rK/4$，$N_{\text{MSY}} = K/2$
6. **空间效应**：异质性促进共存，扩散改变竞争结果
7. **随机性**：环境和内在随机性增加灭绝风险
8. **模型选择**：根据生态学问题选择合适的模型复杂度
