## 12.1 算法的基本概念

### 12.1.1 算法的定义与特性

> **定义 12.1（算法 Algorithm）**：算法是一组定义明确的有穷指令序列，用于解决特定问题。它必须满足以下五个特性：

| 特性 | 说明 |
|:---|:---|
| **有限性**（Finiteness） | 算法必须在执行有限步骤后终止 |
| **确定性**（Definiteness） | 每一步操作必须精确定义、无歧义 |
| **可行性**（Effectiveness） | 每一步都必须足够基本，在有限时间内可执行 |
| **输入**（Input） | 有零个或多个输入 |
| **输出**（Output） | 至少有一个输出（问题的解） |

> **算法 vs 程序**：程序是算法在具体编程语言中的实现。程序可以不满足有限性（如操作系统永远运行），但算法必须终止。

### 12.1.2 算法的表示

#### 伪代码（Pseudocode）

伪代码是介于自然语言和编程语言之间的描述方式，强调算法思想而非具体语法。

**示例 12.1（冒泡排序的伪代码）**：
```
算法: BubbleSort(A[1..n])
输入: 数组 A，长度 n
输出: 升序排列的数组 A

for i = 1 to n-1 do
    for j = 1 to n-i do
        if A[j] > A[j+1] then
            swap(A[j], A[j+1])
        end if
    end for
end for
```

#### 流程图

流程图通过图形元素（开始/结束框、处理框、判断框、箭头）直观表达算法流程，适合初学者理解控制流。

## 12.2 算法复杂度分析

### 12.2.1 时间复杂度的渐进记号

> **核心思想**：我们关心的是当输入规模 $n$ **趋于无穷大**时，算法运行时间的增长阶（Order of Growth），忽略常数因子和低阶项。

> **定义 12.2（大 $O$ 记号 — 上界）**：
> $$f(n) = O(g(n))$$
> 若存在正常数 $c$ 和 $n_0$，使得对所有 $n \geq n_0$，有 $0 \leq f(n) \leq c \cdot g(n)$。

> **定义 12.3（大 $\Omega$ 记号 — 下界）**：
> $$f(n) = \Omega(g(n))$$
> 若存在正常数 $c$ 和 $n_0$，使得对所有 $n \geq n_0$，有 $0 \leq c \cdot g(n) \leq f(n)$。

> **定义 12.4（大 $\Theta$ 记号 — 紧确界）**：
> $$f(n) = \Theta(g(n))$$
> 若 $f(n) = O(g(n))$ 且 $f(n) = \Omega(g(n))$，即存在 $c_1, c_2, n_0$ 使得 $0 \leq c_1 g(n) \leq f(n) \leq c_2 g(n)$ 对所有 $n \geq n_0$ 成立。

**直观理解**：
- $O$ — $f$ 的增长"不快于" $g$
- $\Omega$ — $f$ 的增长"不慢于" $g$
- $\Theta$ — $f$ 的增长"恰等于" $g$（同阶）

**示例 12.2**：
- $3n^2 + 5n - 7 = O(n^2)$：$\because 3n^2 + 5n - 7 \leq 4n^2$（$n \geq 6$）
- $3n^2 + 5n - 7 = \Omega(n^2)$：$\because 3n^2 + 5n - 7 \geq n^2$（$n \geq 1$）
- 故 $3n^2 + 5n - 7 = \Theta(n^2)$

### 12.2.2 常见复杂度排序

从快到慢排列：

| 复杂度 | 名称 | $n=10^6$ 时的典型时间 | 常见算法 |
|:---|:---|:---|:---|
| $O(1)$ | 常数 | 1 ns | 哈希表查找、数组索引 |
| $O(\log n)$ | 对数 | ~20 ns | 二分查找、平衡树操作 |
| $O(n)$ | 线性 | 1 ms | 线性搜索、遍历数组 |
| $O(n \log n)$ | 线性对数 | ~20 ms | 归并排序、堆排序、FFT |
| $O(n^2)$ | 平方 | ~17 min | 简单排序、动态规划 |
| $O(n^3)$ | 立方 | ~32 年 | 朴素矩阵乘法、Floyd-Warshall |
| $O(2^n)$ | 指数 | 天文数字 | 穷举搜索、子集枚举 |
| $O(n!)$ | 阶乘 | 无法想象 | 旅行商问题穷举 |

> **关键认知**：当 $n = 10^6$，$O(\log n) \approx 20$，$O(n \log n) \approx 2 \times 10^7$。两者相差 100 万倍！对数的威力极其巨大。

### 12.2.3 空间复杂度

**空间复杂度**描述算法执行所需的额外内存空间（不计输入数据占用的空间）。

**示例 12.3**：
- 冒泡排序：$O(1)$ 额外空间（原地排序）
- 归并排序：$O(n)$ 额外空间（需要临时数组）
- 递归 Fibonacci：$O(n)$ 调用栈空间

### 12.2.4 最好/最坏/平均情况分析

| 分析类型 | 含义 | 示例（快速排序） |
|:---|:---|:---|
| **最好情况**（Best Case） | 输入最有利时的复杂度 | $O(n \log n)$（每次均匀划分） |
| **最坏情况**（Worst Case） | 输入最不利时的复杂度 | $O(n^2)$（每次极不均匀划分） |
| **平均情况**（Average Case） | 对所有可能输入取平均的复杂度 | $O(n \log n)$（随机输入期望） |

> **实践中我们通常关心最坏情况**，因为它提供了性能的"上界保证"。

## 12.3 经典算法设计策略

### 12.3.1 贪心算法（Greedy Algorithm）

> **核心思想**：在每一步都做出**当前看起来最优**的选择（局部最优），希望通过局部最优的累积得到全局最优解。

**适用条件**：问题具有**贪心选择性质**（Greedy Choice Property）和**最优子结构**（Optimal Substructure）。

**示例 12.4（找零钱问题）**：
人民币面值为 $\{100, 50, 20, 10, 5, 1\}$。找零 187 元的最少硬币/纸币数：
$$187 = 100 + 50 + 20 + 10 + 5 + 1 + 1 \Rightarrow 7 \text{ 张}$$
策略：每次选不超过余额的最大面值。

> **注意**：贪心不一定总是最优。若面值为 $\{1, 3, 4\}$，找零 6 元：贪心给出 $6 = 4 + 1 + 1$（3 张），最优是 $6 = 3 + 3$（2 张）。

**示例 12.5（活动选择问题）**：
给定 $n$ 个活动，各有开始时间 $s_i$ 和结束时间 $f_i$。选择最大数量的不冲突活动。

**贪心策略**：每次选**结束时间最早**的兼容活动。该策略可以获得最优解（可证明）。

### 12.3.2 分治算法（Divide and Conquer）

> **核心思想**：将原问题分解为若干个**规模较小的、互相独立的**子问题，递归求解后合并。

**三部曲**：
1. **分解**（Divide）：将问题分解为更小的子问题
2. **解决**（Conquer）：递归求解各子问题（直到 trivial case）
3. **合并**（Combine）：将子问题的解合并为原问题的解

**示例 12.6（归并排序）**：
$$\begin{aligned}
&\text{MergeSort}(A[l..r]): \\
&\quad \text{if } l \geq r: \text{ return} \\
&\quad mid = (l+r)/2 \\
&\quad \text{MergeSort}(A[l..mid]) \quad \color{gray}{\text{// 分解+解决左半}} \\
&\quad \text{MergeSort}(A[mid+1..r]) \quad \color{gray}{\text{// 分解+解决右半}} \\
&\quad \text{Merge}(A[l..mid], A[mid+1..r]) \quad \color{gray}{\text{// 合并}}
\end{aligned}$$

**复杂度**：$T(n) = 2T(n/2) + O(n) \Rightarrow T(n) = O(n \log n)$。

**示例 12.7（快速排序）**：
1. 选枢轴（Pivot）
2. 划分：小于枢轴的放左边，大于的放右边
3. 递归排序左右两部分

平均复杂度 $O(n \log n)$，最坏 $O(n^2)$（可通过随机化避免）。

### 12.3.3 动态规划（Dynamic Programming, DP）

> **核心思想**：将问题分解为**重叠子问题**，**自底向上**求解，用表格存储子问题的解以避免重复计算。

**适用条件**：
1. **最优子结构**：问题的最优解包含子问题的最优解
2. **重叠子问题**：递归过程中同一个子问题被多次求解

> **DP vs 分治**：分治的子问题是独立的（如归并排序）；DP 的子问题是重叠的（如 Fibonacci）。

**DP 的一般步骤**：
1. 定义状态：确定 DP 数组（表）的含义
2. 确定状态转移方程：描述状态之间的关系
3. 确定初始条件和边界
4. 确定计算顺序（通常自底向上填表）

#### 示例 12.8（0-1 背包问题）

**问题**：有 $n$ 件物品，第 $i$ 件重量 $w_i$，价值 $v_i$。背包容量 $W$。每件物品要么全放入要么不放入（0-1）。求最大总价值。

**DP 解法**：
- **状态定义**：$dp[i][j]$ = 考虑前 $i$ 件物品，背包容量为 $j$ 时的最大价值
- **状态转移**：
  $$dp[i][j] = \begin{cases}
  dp[i-1][j], & \text{若 } w_i > j \text{（放不下）} \\
  \max(dp[i-1][j],\; dp[i-1][j-w_i] + v_i), & \text{否则（选或不选）}
  \end{cases}$$
- **初始条件**：$dp[0][j] = 0$（无物品，价值为 0）
- **时间复杂度**：$O(nW)$
- **空间优化**：可降至 $O(W)$（滚动数组）

#### 示例 12.9（最长公共子序列 LCS）

**问题**：求两字符串的最长公共子序列（不要求连续）。

**DP 解法**：
- **定义**：$dp[i][j]$ = $X[1..i]$ 和 $Y[1..j]$ 的 LCS 长度
- **转移**：
  $$dp[i][j] = \begin{cases}
  dp[i-1][j-1] + 1, & \text{若 } X[i] = Y[j] \\
  \max(dp[i-1][j],\; dp[i][j-1]), & \text{若 } X[i] \neq Y[j]
  \end{cases}$$
- **复杂度**：$O(mn)$

#### 示例 12.10（Floyd-Warshall 全源最短路径）

**问题**：求图中任意两点之间的最短路径。

**DP 解法**：
- **定义**：$d[i][j][k]$ = 从 $i$ 到 $j$ 且只经过 $\{1,\ldots,k\}$ 为中间节点的最短路径
- **转移**：
  $$d[i][j][k] = \min(d[i][j][k-1],\; d[i][k][k-1] + d[k][j][k-1])$$
- **空间优化后**（就地更新）：
  ```python
  for k in range(n):
      for i in range(n):
          for j in range(n):
              dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
  ```
- **复杂度**：$O(V^3)$

## 12.4 计算理论入门

### 12.4.1 形式语言与 Chomsky 谱系

> **定义 12.5（字母表 Alphabet）**：一个有限的非空符号集合 $\Sigma$。

> **定义 12.6（字符串 String / Word）**：由 $\Sigma$ 中符号组成的有限序列。空串记为 $\varepsilon$。

> **定义 12.7（语言 Language）**：$\Sigma^*$（所有字符串的集合）的任意子集。

#### Chomsky 谱系（Chomsky Hierarchy）

| 类型 | 名称 | 对应的自动机 | 对应的文法 | 例子 |
|:---:|:---|:---|:---|:---|
| 3 | 正则语言（Regular） | 有限自动机（FA） | 正则文法 / 正则表达式 | 合法的标识符、关键词匹配 |
| 2 | 上下文无关语言（CFL） | 下推自动机（PDA） | 上下文无关文法（CFG） | 编程语言语法（括号匹配、表达式） |
| 1 | 上下文有关语言（CSL） | 线性有界自动机（LBA） | 上下文有关文法 | $a^n b^n c^n$ |
| 0 | 递归可枚举语言（RE） | 图灵机（TM） | 无限制文法 | 一切计算机"可识别"的问题 |

### 12.4.2 有限自动机

> **定义 12.8（确定型有限自动机 DFA）**：DFA 是一个五元组 $M = (Q, \Sigma, \delta, q_0, F)$：
> - $Q$：有限状态集合
> - $\Sigma$：输入字母表
> - $\delta : Q \times \Sigma \to Q$：状态转移函数（完全确定）
> - $q_0 \in Q$：起始状态
> - $F \subseteq Q$：接受状态集合

**DFA 的运作方式**：从 $q_0$ 开始，依次读入输入字符 $w_1 w_2 \cdots w_n$，每步根据当前状态和输入字符决定下一状态。读完整个字符串后若处于接受状态 $F$，则接受该字符串。

**示例 12.11**：设计 DFA 识别所有以 `01` 结尾的二进制串。

- $Q = \{q_0, q_1, q_2\}$（$q_0$ 起始，$q_2$ 接受）
- $\Sigma = \{0, 1\}$
- 转移表：

| 当前状态 | 输入 0 | 输入 1 |
|:---:|:---:|:---:|
| $q_0$ | $q_1$ | $q_0$ |
| $q_1$ | $q_1$ | $q_2$ |
| $q_2$ | $q_1$ | $q_0$ |

**运行举例**：输入 `1001`
$$\begin{aligned}
&q_0 \xrightarrow{1} q_0 \xrightarrow{0} q_1 \xrightarrow{0} q_1 \xrightarrow{1} q_2 \quad \text{（接受！）}
\end{aligned}$$

#### 非确定型有限自动机（NFA）

NFA 与 DFA 的主要区别：
- $\delta$ 可能返回**多个**后继状态（或空集）
- 允许 $\varepsilon$ 转移（不消耗输入的状态转移）

> **定理 12.1**：每个 NFA 都存在一个等价的 DFA（通过**子集构造法**）。但 DFA 的状态数可能是指数级的（最坏 $2^{|Q|}$）。

### 12.4.3 正则表达式

正则表达式是描述正则语言的代数表示。

| 表达式 | 含义 | 匹配的串 |
|:---|:---|:---|
| $\varnothing$ | 空语言 | 无 |
| $\varepsilon$ | 仅含空串的语言 | $\varepsilon$ |
| $a$ | 单字符 | `"a"` |
| $R_1 R_2$ | 连接 | 任何 $R_1$ 匹配的串后接 $R_2$ 匹配的串 |
| $R_1 \mid R_2$ | 并（Union） | 匹配 $R_1$ 或 $R_2$ 的串 |
| $R^*$ | Kleene 星闭包 | $R$ 匹配的串的零次或多次连接 |

**示例 12.12**：
- `[01]*` — 所有二进制串
- `0*10*` — 恰好含一个 1 的二进制串
- `(a|b)*abb` — 以 `abb` 结尾的由 `a,b` 组成的串

> **定理 12.2（Kleene）**：正则表达式描述的语言与有限自动机接受的语言完全相同——即都是正则语言。

### 12.4.4 图灵机（Turing Machine）

> **定义 12.9（图灵机 TM）**：图灵机是一个七元组 $M = (Q, \Sigma, \Gamma, \delta, q_0, q_{\text{accept}}, q_{\text{reject}})$，其中：
> - 有一条**无限长的纸带**（Tape），划分为格子，每个格子存一个符号
> - 有一个**读写头**，可在纸带上左右移动、读写符号
> - $\delta: Q \times \Gamma \to Q \times \Gamma \times \{L, R\}$ 为转移函数

图灵机是计算理论中最核心的模型。它可以模拟任何已知的计算过程。

> **Church-Turing 论题**：任何直觉上"可计算"的函数都可以被图灵机计算。

这**不是定理**（无法证明），而是对计算能力的"信仰声明"。目前为止没有反例。

## 12.5 P 与 NP 问题简介

### 12.5.1 问题与判定问题

- **判定问题**（Decision Problem）：答案仅为"是/否"的问题
- **优化问题**通常可以转化为判定问题（如"是否存在长度 $\leq K$ 的路径"）

### 12.5.2 P 类与 NP 类

> **定义 12.10（P 类）**：存在**多项式时间**确定性算法求解的判定问题的集合。

**例子**：排序、最短路径、最大流、二分图匹配。这些都属于 P。

> **定义 12.11（NP 类）**：给定一个证书（Certificate/Witness），可以在**多项式时间**验证其正确性的判定问题的集合。

**例子**：
- 合数判定：给定整数 $n$ 和证书 $d$，验证 $d \mid n$ 可在 $O(\log n)$ 时间完成
- 哈密顿回路：给定图 $G$ 和证书（回路），验证回路覆盖所有顶点可在多项式时间完成

> **显然有 $P \subseteq NP$**（能在多项式时间求解的问题也必然能在多项式时间验证）。

### 12.5.3 NP 完全性（NP-Completeness）

> **定义 12.12（多项式时间归约）**：问题 $A$ 可多项式时间归约到问题 $B$（记作 $A \leq_P B$），若存在多项式时间的变换 $f$，使得 $x \in A \iff f(x) \in B$。

> **定义 12.13（NP-难 NP-Hard）**：问题 $B$ 称为 NP-难，若对**任意** $A \in NP$，有 $A \leq_P B$。

> **定义 12.14（NP-完全 NPC）**：问题 $B$ 称为 NP-完全，若 $B \in NP$ 且 $B$ 是 NP-难的。

**经典 NPC 问题**：
- SAT（布尔可满足性问题）— 第一个被证明为 NPC
- 3SAT
- 顶点覆盖（Vertex Cover）
- 团问题（Clique）
- 哈密顿回路（Hamiltonian Cycle）
- 0-1 背包判定问题
- 旅行商问题（TSP 判定版）

### 12.5.4 P = NP 问题

> **世纪难题**：$P = NP$ 还是 $P \neq NP$？

这是 Clay 数学研究所的七大千年难题之一，悬赏 100 万美元。

**如果 P = NP**：
- 所有 NPC 问题都存在多项式时间算法
- 密码学（RSA 等）将崩溃（大整数分解有高效算法）
- AI 中的许多"困难"问题（如定理证明、蛋白质折叠）可高效求解

**如果 P ≠ NP**：
- 目前已知的 NPC 问题真的没有多项式算法
- 密码学（基于某些"平均情况困难"假设）依然安全

> **共识**：绝大多数计算机科学家相信 **$P \neq NP$**，但尚无严格证明。

### 12.5.5 Cook-Levin 定理

> **定理 12.3（Cook-Levin, 1971）**：SAT（布尔可满足性问题）是 NP-完全的。

这是计算理论中最重要的定理之一。Cook 首先证明任何 NP 问题都可多项式时间归约到 SAT。这意味着如果某人发现 SAT 有多项式算法，则**所有 NP 问题**都能在多项式时间内解决（P = NP）。

## 12.6 编程实现

### 12.6.1 递归 vs 递推：Fibonacci 对比

```cpp
// C++ 递归 vs 递推（迭代）的 Fibonacci
#include <iostream>
#include <chrono>
using namespace std;

long long fib_rec(int n) {
    if (n <= 1) return n;
    return fib_rec(n - 1) + fib_rec(n - 2);
}

long long fib_iter(int n) {
    if (n <= 1) return n;
    long long a = 0, b = 1, c;
    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return b;
}

int main() {
    int n = 45;

    auto start = chrono::high_resolution_clock::now();
    cout << "Fib(45) 迭代 = " << fib_iter(n) << endl;
    auto end = chrono::high_resolution_clock::now();
    cout << "用时: " << chrono::duration<double>(end - start).count() << "s\n";
```

```python
    if n <= 1:
        return n
    return fib_rec(n - 1) + fib_rec(n - 2)

        return n

    return b
```

### 12.6.2 0-1 背包问题

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int knapsack_01(const vector<int>& w, const vector<int>& v, int W) {
    int n = w.size();
    // dp[j] = 容量为 j 时的最大价值（空间优化版）
    vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; i++) {
        // 从大到小遍历，确保每件物品只用一次
        for (int j = W; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[W];
}

int main() {
    vector<int> weights = {2, 3, 4, 5};
    vector<int> values  = {3, 4, 5, 6};
    int W = 8;
    cout << "最大价值: " << knapsack_01(weights, values, W) << endl;
    // 预期输出 10（选物品2和物品4：3+5=8重，4+6=10值）
}
```

```python
def knapsack_01(weights: list[int], values: list[int], capacity: int) -> int:
    """0-1 背包 DP，空间优化版 O(n*W) 时间，O(W) 空间"""
    n = len(weights)
    dp = [0] * (capacity + 1)

    for i in range(n):
        w, v = weights[i], values[i]
        for j in range(capacity, w - 1, -1):
            dp[j] = max(dp[j], dp[j - w] + v)

    return dp[capacity]

print(knapsack_01([2, 3, 4, 5], [3, 4, 5, 6], 8))  # 10
```

### 12.6.3 最长公共子序列（LCS）

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

int lcs_length(const string& X, const string& Y) {
    int m = X.size(), n = Y.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (X[i-1] == Y[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}

// 回溯构造 LCS 字符串
string get_lcs(const string& X, const string& Y) {
    int m = X.size(), n = Y.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++) {
            if (X[i-1] == Y[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }

    string lcs;
    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (X[i-1] == Y[j-1]) {
            lcs = X[i-1] + lcs;
            i--; j--;
        } else if (dp[i-1][j] > dp[i][j-1]) {
            i--;
        } else {
            j--;
        }
    }
    return lcs;
}
```

```python
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if X[i-1] == Y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    lcs_chars = []
    i, j = m, n
    while i > 0 and j > 0:
        if X[i-1] == Y[j-1]:
            lcs_chars.append(X[i-1])
            i -= 1; j -= 1
        elif dp[i-1][j] > dp[i][j-1]:
            i -= 1
        else:
            j -= 1

    return ''.join(reversed(lcs_chars))
```

### 12.6.4 DFA 模拟器

```python
class DFA:
    """DFA 模拟器"""
    def __init__(self, states, alphabet, transitions, start_state, accept_states):
        self.states = set(states)
        self.alphabet = set(alphabet)
        self.transitions = transitions  # dict: (state, char) -> next_state
        self.start_state = start_state
        self.accept_states = set(accept_states)

    def run(self, input_string: str) -> bool:
        current = self.start_state
        for ch in input_string:
            if (current, ch) not in self.transitions:
                return False
            current = self.transitions[(current, ch)]
        return current in self.accept_states

# 示例：识别以 "01" 结尾的二进制串
dfa = DFA(
    states=['q0', 'q1', 'q2'],
    alphabet=['0', '1'],
    transitions={
        ('q0', '0'): 'q1', ('q0', '1'): 'q0',
        ('q1', '0'): 'q1', ('q1', '1'): 'q2',
        ('q2', '0'): 'q1', ('q2', '1'): 'q0',
    },
    start_state='q0',
    accept_states=['q2']
)

test_strings = ['', '01', '101', '1001', '110', '010']
for s in test_strings:
    print(f"  '{s}' -> {'接受' if dfa.run(s) else '拒绝'}")
```

### 12.6.5 正则表达式匹配

```python
import re

# Python 的正则引擎（基于回溯）功能远超理论上的"正则语言"
# 这里演示正则理论中的基本匹配

def is_binary_multiple_of_3(s: str) -> bool:
    """
    判断二进制串对应的数是否是 3 的倍数
    原理：DFA 状态表示当前余数
    """
    state = 0  # 余数
    for ch in s:
        if ch not in '01':
            return False
        # 已读数 = 之前的值 * 2 + 当前位
        # 状态跟踪的是 mod 3 余数
        digit = int(ch)
        state = (state * 2 + digit) % 3
    return state == 0

# 正则验证（仅作参考）
pattern = re.compile(r'^(0|1(01*0)*1)*$')
for n in range(20):
    b = bin(n)[2:]
    m1 = pattern.fullmatch(b) is not None
    m2 = is_binary_multiple_of_3(b) if b else True
    assert m1 == m2, f"Mismatch at {n} ({b}): re={m1}, dfa={m2}"
print("所有测试通过 ✅")
```
