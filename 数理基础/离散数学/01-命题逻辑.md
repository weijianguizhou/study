# 01-命题逻辑

> **命题逻辑**（Propositional Logic）是数理逻辑的基础分支，研究由命题和逻辑联结词构成的复合命题的真值关系与推理规则。命题逻辑不涉及命题内部的结构（即不分析主语和谓语），只关心命题整体的真假。

---

## 1.1 命题与真值

### 1.1.1 命题的定义

**命题**（Proposition）是具有唯一确定真值的**陈述句**。即：一个命题要么为真（True，记作 $T$ 或 $1$），要么为假（False，记作 $F$ 或 $0$），二者必居其一且只居其一。

**命题三要素**：
1. 必须是**陈述句**——疑问句、祈使句、感叹句不是命题。
2. 必须有唯一确定的**真值**。
3. 真值非真即假（排中律）。

**示例**：

| 语句 | 是否为命题 | 说明 |
|------|-----------|------|
| $2 + 2 = 4$ | 是，真值为 $T$ | 数学陈述句 |
| 北京是中国的首都 | 是，真值为 $T$ | 事实陈述 |
| $1 + 1 = 3$ | 是，真值为 $F$ | 假命题仍是命题 |
| 请你开门 | 否 | 祈使句 |
| $x > 5$ | 否 | 含自由变元，真值不确定 |
| 这句话是假的 | 否 | 悖论（自指矛盾） |

### 1.1.2 简单命题与复合命题

- **简单命题**（原子命题，Atomic Proposition）：不能再分解为更简单命题的命题。通常用小写字母 $p, q, r, \dots$ 表示。
- **复合命题**（Compound Proposition）：由简单命题通过**逻辑联结词**组合而成的命题。

**示例**：
- $p$：今天下雨（简单命题）
- $q$：今天刮风（简单命题）
- $p \land q$：今天下雨且刮风（复合命题）

### 1.1.3 真值表

**真值表**（Truth Table）是将命题中所有命题变元的每种可能真值组合列出，并给出复合命题对应真值的表格。

> 若复合命题含 $n$ 个不同的命题变元，则真值表有 $2^n$ 行。

---

## 1.2 逻辑联结词

逻辑联结词（Logical Connectives）是将简单命题组合为复合命题的运算符号。

### 1.2.1 否定（Negation）—— $\neg$

**定义**：否定联结词 $\neg$ 作用于一个命题 $p$，得到新命题 $\neg p$（读作"非 $p$"），其真值与 $p$ 相反。

**真值表**：

| $p$ | $\neg p$ |
|------|----------|
| $T$ | $F$ |
| $F$ | $T$ |

**自然语言**："并非 $p$"、"$p$ 不成立"、"$p$ 是假的"。

**编程对应**：

```cpp
// C++: ! 运算符
bool p = true;
bool not_p = !p;  // false
```

```python
# Python: not 关键字
p = True
not_p = not p  # False
```

---

### 1.2.2 合取（Conjunction）—— $\land$

**定义**：合取联结词 $\land$ 连接两个命题 $p, q$，得到 $p \land q$（读作"$p$ 且 $q$"），当且仅当 $p$ 和 $q$ 同时为真时，$p \land q$ 为真。

**真值表**：

| $p$ | $q$ | $p \land q$ |
|------|------|-------------|
| $T$ | $T$ | $T$ |
| $T$ | $F$ | $F$ |
| $F$ | $T$ | $F$ |
| $F$ | $F$ | $F$ |

**自然语言**："$p$ 并且 $q$"、"$p$ 与 $q$"、"既 $p$ 又 $q$"。

**编程对应**：

```cpp
// C++: && 运算符
bool p = true, q = false;
bool result = p && q;  // false — 短路求值
```

```python
# Python: and 关键字
p, q = True, False
result = p and q  # False — 短路求值
```

---

### 1.2.3 析取（Disjunction）—— $\lor$

**定义**：析取联结词 $\lor$ 连接两个命题 $p, q$，得到 $p \lor q$（读作"$p$ 或 $q$"），当且仅当 $p$ 和 $q$ **至少有一个**为真时，$p \lor q$ 为真。

**真值表**：

| $p$ | $q$ | $p \lor q$ |
|------|------|-------------|
| $T$ | $T$ | $T$ |
| $T$ | $F$ | $T$ |
| $F$ | $T$ | $T$ |
| $F$ | $F$ | $F$ |

> 注意：$\lor$ 是**可兼或**（inclusive OR），即 $p$ 和 $q$ 可以同时为真。

**自然语言**："$p$ 或者 $q$"、"至少有一个成立"。

**编程对应**：

```cpp
// C++: || 运算符
bool p = true, q = false;
bool result = p || q;  // true — 短路求值
```

```python
# Python: or 关键字
p, q = True, False
result = p or q  # True — 短路求值
```

---

### 1.2.4 异或（Exclusive OR）—— $\oplus$

**定义**：$p \oplus q$（读作"$p$ 异或 $q$"）当且仅当 $p$ 和 $q$ 的真值**不同**时为真。

**真值表**：

| $p$ | $q$ | $p \oplus q$ |
|------|------|-------------|
| $T$ | $T$ | $F$ |
| $T$ | $F$ | $T$ |
| $F$ | $T$ | $T$ |
| $F$ | $F$ | $F$ |

**逻辑等价关系**：$p \oplus q \equiv (p \lor q) \land \neg(p \land q) \equiv (p \land \neg q) \lor (\neg p \land q)$

**自然语言**："要么 $p$，要么 $q$，但并非两者都"（不可兼或）。

**编程对应**：

```cpp
// C++: ^ 运算符（按位异或，对 bool 也可用）
bool p = true, q = false;
bool result = p ^ q;      // true
// 或: (p && !q) || (!p && q);  --- 无短路版本
```

```python
# Python: ^ 运算符
p, q = True, False
result = p ^ q  # True
# 等同于: (p and not q) or (not p and q)
```

---

### 1.2.5 与非（NAND）和或非（NOR）

#### 与非（NAND）—— $\uparrow$

与非是合取后取否定：$p \uparrow q \equiv \neg(p \land q)$

| $p$ | $q$ | $p \uparrow q$ |
|------|------|-----------------|
| $T$ | $T$ | $F$ |
| $T$ | $F$ | $T$ |
| $F$ | $T$ | $T$ |
| $F$ | $F$ | $T$ |

> $\{\uparrow\}$ 是一个**功能完备集**——仅用 $\uparrow$ 即可表达所有逻辑运算。

#### 或非（NOR）—— $\downarrow$

或非是析取后取否定：$p \downarrow q \equiv \neg(p \lor q)$

| $p$ | $q$ | $p \downarrow q$ |
|------|------|-------------------|
| $T$ | $T$ | $F$ |
| $T$ | $F$ | $F$ |
| $F$ | $T$ | $F$ |
| $F$ | $F$ | $T$ |

> $\{\downarrow\}$ 同样是一个**功能完备集**。

---

### 1.2.6 蕴涵（Implication）—— $\rightarrow$

**定义**：$p \rightarrow q$（读作"如果 $p$ 则 $q$"或"$p$ 蕴涵 $q$"），当且仅当 $p$ 为真且 $q$ 为假时，$p \rightarrow q$ 为假。

**真值表**：

| $p$ | $q$ | $p \rightarrow q$ |
|------|------|--------------------|
| $T$ | $T$ | $T$ |
| $T$ | $F$ | $F$ |
| $F$ | $T$ | $T$ |
| $F$ | $F$ | $T$ |

**术语**：
- $p$ 称为**前件**（antecedent）或**前提**（hypothesis）
- $q$ 称为**后件**（consequent）或**结论**（conclusion）

**关键理解**：
- $p$ 为假时，$p \rightarrow q$ 恒为真（**虚真**，vacuous truth）
- $p \rightarrow q \equiv \neg p \lor q$
- 蕴涵不要求因果关系，只关注真假组合

**相关蕴涵形式**：
- **逆命题**（Converse）：$q \rightarrow p$
- **否命题**（Inverse）：$\neg p \rightarrow \neg q$
- **逆否命题**（Contrapositive）：$\neg q \rightarrow \neg p$

> **重要结论**：原命题 $\equiv$ 逆否命题，即 $p \rightarrow q \equiv \neg q \rightarrow \neg p$

**自然语言**："如果 $p$，则 $q$"、"$p$ 仅当 $q$"、"$q$ 是 $p$ 的必要条件"、"$p$ 是 $q$ 的充分条件"。

**编程对应**：

```cpp
// C++: if-else 逻辑
bool p = true, q = false;
bool implies = !p || q;  // true: p→q ≡ ¬p ∨ q
```

```python
# Python: if-else 逻辑
p, q = True, False
implies = (not p) or q  # True
```

---

### 1.2.7 等价（Biconditional）—— $\leftrightarrow$

**定义**：$p \leftrightarrow q$（读作"$p$ 当且仅当 $q$"），当且仅当 $p$ 和 $q$ 的真值**相同**时为真。

**真值表**：

| $p$ | $q$ | $p \leftrightarrow q$ |
|------|------|------------------------|
| $T$ | $T$ | $T$ |
| $T$ | $F$ | $F$ |
| $F$ | $T$ | $F$ |
| $F$ | $F$ | $T$ |

**逻辑等价关系**：

$$p \leftrightarrow q \equiv (p \rightarrow q) \land (q \rightarrow p) \equiv (\neg p \lor q) \land (p \lor \neg q)$$

**自然语言**："$p$ 当且仅当 $q$"、"$p$ 是 $q$ 的充要条件"。

**编程对应**：

```cpp
// C++: == 运算符
bool p = true, q = true;
bool equivalent = (p == q);  // true
```

```python
# Python: == 运算符
p, q = True, True
equivalent = (p == q)  # True
```

---

### 1.2.8 联结词优先级

为减少括号使用，约定联结词优先级（从高到低）：

1. $\neg$ （最高）
2. $\land$
3. $\lor$
4. $\rightarrow$
5. $\leftrightarrow$ （最低）

## 1.3 命题公式

### 1.3.1 合式公式

**定义**（合式公式，Well-Formed Formula, WFF）：命题逻辑中的合式公式递归定义如下：

1. （**基底**）单个命题变元（$p, q, r, \dots$）和真值常量 $T, F$ 是合式公式。
2. （**递归步**）若 $A$ 是合式公式，则 $(\neg A)$ 是合式公式。
3. 若 $A$ 和 $B$ 是合式公式，则下列均为合式公式：
   - $(A \land B)$
   - $(A \lor B)$
   - $(A \rightarrow B)$
   - $(A \leftrightarrow B)$
   - $(A \oplus B)$
4. 只有有限次使用（1）—（3）得到的符号串才是合式公式。

**示例**：
- $((p \land q) \rightarrow (\neg r))$ 是 WFF（可简写为 $p \land q \rightarrow \neg r$）
- $\land p q$ **不是** WFF（联结词位置不对）
- $(p \rightarrow (q \land))$ **不是** WFF（联结词缺少操作数）

### 1.3.2 公式的真值与赋值

**赋值**（Assignment/Interpretation）是对公式中每个命题变元指定一个真值（$T$ 或 $F$）的函数。含 $n$ 个命题变元的公式共有 $2^n$ 种不同的赋值。

**公式在赋值下的真值**：按照联结词的语义规则，从内向外递归计算。

> **定义**（成真赋值与成假赋值）：使公式 $A$ 为真的赋值称为 $A$ 的**成真赋值**（model）；使 $A$ 为假的赋值称为 $A$ 的**成假赋值**（countermodel）。

---

## 1.4 永真式、永假式、可满足式

### 1.4.1 分类定义

设 $A$ 为命题公式：

| 类型 | 定义 | 记号 |
|------|------|------|
| **永真式**（重言式，Tautology） | 所有赋值下 $A$ 均为真 | $\models A$ |
| **永假式**（矛盾式，Contradiction） | 所有赋值下 $A$ 均为假 | — |
| **可满足式**（Satisfiable） | 至少有一个赋值使 $A$ 为真 | — |

> **注意**：永真式一定是可满足式；永假式一定不可满足。

### 1.4.2 判断方法

**方法一：真值表法**。列出所有赋值，逐行判断。

**示例**：判断 $A: (p \rightarrow q) \leftrightarrow (\neg p \lor q)$ 的类型。

| $p$ | $q$ | $p \rightarrow q$ | $\neg p \lor q$ | $A$ |
|------|------|--------------------|-----------------|------|
| $T$ | $T$ | $T$ | $T$ | $T$ |
| $T$ | $F$ | $F$ | $F$ | $T$ |
| $F$ | $T$ | $T$ | $T$ | $T$ |
| $F$ | $F$ | $T$ | $T$ | $T$ |

$A$ 在所有赋值下为真，故 $A$ 是永真式。

**方法二：等价变换法**。将公式化为规范形式（如主范式）。

## 1.5 逻辑等价

### 1.5.1 基本概念

**定义**：设 $A, B$ 是两个命题公式，若对于任意赋值，$A$ 与 $B$ 具有相同的真值，则称 $A$ 与 $B$ **逻辑等价**（Logically Equivalent），记作 $A \equiv B$。

> 注意区分：$\equiv$ 是元语言符号，$\leftrightarrow$ 是对象语言符号。$A \equiv B$ 当且仅当 $A \leftrightarrow B$ 是永真式。

### 1.5.2 重要逻辑等价式

以下等价式中，$p, q, r$ 是任意命题公式，$T$ 表示永真式，$F$ 表示永假式。

#### （一）基本等价律

| 编号 | 名称 | 等价式 |
|------|------|--------|
| E1 | 双重否定律 | $\neg\neg p \equiv p$ |
| E2 | 幂等律 | $p \lor p \equiv p$, $p \land p \equiv p$ |
| E3 | 交换律 | $p \lor q \equiv q \lor p$, $p \land q \equiv q \land p$ |
| E4 | 结合律 | $(p \lor q) \lor r \equiv p \lor (q \lor r)$, $(p \land q) \land r \equiv p \land (q \land r)$ |
| E5 | 分配律 | $p \lor (q \land r) \equiv (p \lor q) \land (p \lor r)$, $p \land (q \lor r) \equiv (p \land q) \lor (p \land r)$ |

**证明**（分配律 $p \lor (q \land r) \equiv (p \lor q) \land (p \lor r)$，用真值表）：

| $p$ | $q$ | $r$ | $q \land r$ | $p \lor (q \land r)$ | $p \lor q$ | $p \lor r$ | $(p \lor q) \land (p \lor r)$ |
|------|------|------|-------------|----------------------|------------|------------|-------------------------------|
| T | T | T | T | T | T | T | T |
| T | T | F | F | T | T | T | T |
| T | F | T | F | T | T | T | T |
| T | F | F | F | T | T | T | T |
| F | T | T | T | T | T | T | T |
| F | T | F | F | F | T | F | F |
| F | F | T | F | F | F | T | F |
| F | F | F | F | F | F | F | F |

两列完全一致，证毕。

#### （二）德摩根律（De Morgan's Laws）

| 编号 | 等价式 |
|------|--------|
| E6 | $\neg(p \land q) \equiv \neg p \lor \neg q$ |
| E7 | $\neg(p \lor q) \equiv \neg p \land \neg q$ |

**证明**（E6 用真值表）：

| $p$ | $q$ | $p \land q$ | $\neg(p \land q)$ | $\neg p$ | $\neg q$ | $\neg p \lor \neg q$ |
|------|------|-------------|-------------------|----------|----------|---------------------|
| T | T | T | F | F | F | F |
| T | F | F | T | F | T | T |
| F | T | F | T | T | F | T |
| F | F | F | T | T | T | T |

#### （三）同一律与零律

| 编号 | 名称 | 等价式 |
|------|------|--------|
| E8 | 同一律 | $p \lor F \equiv p$, $p \land T \equiv p$ |
| E9 | 零律 | $p \lor T \equiv T$, $p \land F \equiv F$ |

#### （四）排中律与矛盾律

| 编号 | 名称 | 等价式 |
|------|------|--------|
| E10 | 排中律 | $p \lor \neg p \equiv T$ |
| E11 | 矛盾律 | $p \land \neg p \equiv F$ |

#### （五）吸收律

| 编号 | 等价式 |
|------|--------|
| E12 | $p \lor (p \land q) \equiv p$ |
| E13 | $p \land (p \lor q) \equiv p$ |

**证明**（E12）：
$$p \lor (p \land q) \equiv (p \land T) \lor (p \land q) \equiv p \land (T \lor q) \equiv p \land T \equiv p$$

#### （六）蕴涵与等价的展开

| 编号 | 名称 | 等价式 |
|------|------|--------|
| E14 | 蕴涵展开 | $p \rightarrow q \equiv \neg p \lor q$ |
| E15 | 等价展开 | $p \leftrightarrow q \equiv (p \rightarrow q) \land (q \rightarrow p) \equiv (\neg p \lor q) \land (p \lor \neg q)$ |
| E16 | 逆否命题 | $p \rightarrow q \equiv \neg q \rightarrow \neg p$ |

#### （七）其他重要等价式

| 编号 | 等价式 |
|------|--------|
| E17 | $(p \rightarrow q) \land (p \rightarrow \neg q) \equiv \neg p$ （归谬法） |
| E18 | $(p \rightarrow r) \land (q \rightarrow r) \equiv (p \lor q) \rightarrow r$ |
| E19 | $(p \rightarrow q) \land (p \rightarrow r) \equiv p \rightarrow (q \land r)$ |
| E20 | $\neg p \rightarrow (q \land \neg q) \equiv p$ |

### 1.5.3 逻辑等价的证明方法

**方法一：真值表法**——列出所有可能赋值，比较真值列是否一致。

**方法二：等价变换法**——利用已知等价式，逐步将一个公式变换为另一个公式。

**示例**：证明 $(p \land q) \rightarrow r \equiv p \rightarrow (q \rightarrow r)$

$$
\begin{aligned}
(p \land q) \rightarrow r &\equiv \neg(p \land q) \lor r \quad &\text{(E14 蕴涵展开)} \\
&\equiv (\neg p \lor \neg q) \lor r \quad &\text{(E6 德摩根律)} \\
&\equiv \neg p \lor (\neg q \lor r) \quad &\text{(E4 结合律)} \\
&\equiv \neg p \lor (q \rightarrow r) \quad &\text{(E14 蕴涵展开)} \\
&\equiv p \rightarrow (q \rightarrow r) \quad &\text{(E14 蕴涵展开)}
\end{aligned}
$$

> 此等价式称为**输出律**（Exportation Law）。

## 1.6 范式

范式（Normal Form）是将命题公式写为某种规范形式的方法，使得两个逻辑等价的公式具有相同的范式。

### 1.6.1 文字与子句

- **文字**（Literal）：命题变元 $p$ 或其否定 $\neg p$。
- **互补对**（Complementary Pair）：$p$ 和 $\neg p$ 互为互补对。
- **简单合取式**：若干文字的合取，如 $p \land \neg q \land r$。
- **简单析取式**：若干文字的析取，如 $p \lor \neg q \lor r$。

### 1.6.2 析取范式（DNF）

**定义**：一个命题公式称为**析取范式**（Disjunctive Normal Form），若它是由一个或多个**简单合取式**通过析取联结而成的公式。

**一般形式**：
$$(L_{11} \land \dots \land L_{1k_1}) \lor (L_{21} \land \dots \land L_{2k_2}) \lor \dots \lor (L_{m1} \land \dots \land L_{mk_m})$$

其中每个 $L_{ij}$ 是文字。

**求DNF的步骤**：
1. 消去 $\rightarrow$ 和 $\leftrightarrow$：$p \rightarrow q \equiv \neg p \lor q$；$p \leftrightarrow q \equiv (\neg p \lor q) \land (p \lor \neg q)$
2. 将 $\neg$ 移到命题变元前（德摩根律 + 双重否定律）
3. 用分配律 $p \land (q \lor r) \equiv (p \land q) \lor (p \land r)$ 将 $\land$ 提入 $\lor$ 中

**示例**：求 $(p \rightarrow q) \land \neg r$ 的 DNF。

$$
\begin{aligned}
(p \rightarrow q) \land \neg r &\equiv (\neg p \lor q) \land \neg r \\
&\equiv (\neg p \land \neg r) \lor (q \land \neg r)
\end{aligned}
$$

### 1.6.3 合取范式（CNF）

**定义**：一个命题公式称为**合取范式**（Conjunctive Normal Form），若它是由一个或多个**简单析取式**通过合取联结而成的公式。

**一般形式**：
$$(L_{11} \lor \dots \lor L_{1k_1}) \land (L_{21} \lor \dots \lor L_{2k_2}) \land \dots \land (L_{m1} \lor \dots \lor L_{mk_m})$$

**求CNF的步骤**：
1. 消去 $\rightarrow$ 和 $\leftrightarrow$
2. 将 $\neg$ 移到命题变元前
3. 用分配律 $p \lor (q \land r) \equiv (p \lor q) \land (p \lor r)$ 将 $\lor$ 提入 $\land$ 中

**示例**：求 $(p \lor \neg q) \rightarrow r$ 的 CNF。

$$
\begin{aligned}
(p \lor \neg q) \rightarrow r &\equiv \neg(p \lor \neg q) \lor r \\
&\equiv (\neg p \land q) \lor r \\
&\equiv (\neg p \lor r) \land (q \lor r)
\end{aligned}
$$

### 1.6.4 主析取范式（主合取范式）

若公式含有命题变元 $p_1, p_2, \dots, p_n$：

- **极小项**（Minterm）：每个命题变元或其否定恰好出现一次（不能同时出现）的简单合取式。

  例如，含 $p, q$ 的极小项有 4 个：$p \land q$，$p \land \neg q$，$\neg p \land q$，$\neg p \land \neg q$。

- **极大项**（Maxterm）：每个命题变元或其否定恰好出现一次（不能同时出现）的简单析取式。

  例如，含 $p, q$ 的极大项有 4 个：$p \lor q$，$p \lor \neg q$，$\neg p \lor q$，$\neg p \lor \neg q$。

**编码约定**：
- 极小项 $m_i$：命题变元取 $1$ 对应其本身，$0$ 对应其否定；将编码视为二进制数 $i$。
  - 例如 $p \land \neg q \land r$ → 编码 $(1,0,1)_2 = 5$ → $m_5$

- 极大项 $M_i$：命题变元取 $0$ 对应其本身，$1$ 对应其否定；将编码视为二进制数 $i$。
  - 例如 $p \lor \neg q \lor r$ → 编码 $(0,1,0)_2 = 2$ → $M_2$

**主析取范式**（Principal DNF）：由不同极小项析取而成的范式。即：

$$A \equiv m_{i_1} \lor m_{i_2} \lor \dots \lor m_{i_k} \equiv \sum (i_1, i_2, \dots, i_k)$$

**主合取范式**（Principal CNF）：由不同极大项合取而成的范式。即：

$$A \equiv M_{j_1} \land M_{j_2} \land \dots \land M_{j_l} \equiv \prod (j_1, j_2, \dots, j_l)$$

**关系**：对含 $n$ 个命题变元的公式，若其主析取范式中含 $k$ 个极小项，则其主合取范式含剩余的 $2^n - k$ 个极大项。

**求主范式的方法**：

**方法一：真值表法**。
1. 列出真值表，找出所有成真赋值（使 $A$ 为 $T$ 的行）。
2. 每个成真赋值对应一个极小项，所有极小项的析取即为主析取范式。
3. 成假赋值对应极大项，所有极大项的合取即为主合取范式。
4. 若某变元在该行取 $T$，则极小项中取其本身，极大项中取其否定；反之亦然。

**方法二：等价变换法**。
1. 先求出一般范式（DNF 或 CNF）。
2. 对每个缺少某变元的简单合取式，用 $p \lor \neg p \equiv T$ 进行扩充。
3. 合并重复极小项/极大项，整理排序。

**方法三：等值推演法**（利用 $A \lor \neg A \equiv T$ 补全缺失变元）。

## 1.7 推理理论

### 1.7.1 基本概念

**定义**（有效推理）：设 $A_1, A_2, \dots, A_n$ 是前提（premises），$C$ 是结论（conclusion）。若对于任意赋值，当所有前提为真时结论也为真，则称此推理**有效**（valid），记作：

$$A_1, A_2, \dots, A_n \models C$$

等价地，$A_1 \land A_2 \land \dots \land A_n \rightarrow C$ 是永真式。

> **注意**：逻辑推理关注的是推理形式的有效性，而非前提或结论在实际中是否为真。

### 1.7.2 基本推理规则

以下列出命题逻辑中常用的推理规则：

| 规则名称 | 推理形式 | 记法 |
|----------|----------|------|
| **假言推理**（Modus Ponens） | $p, p \rightarrow q \models q$ | 分离规则 |
| **拒取式**（Modus Tollens） | $\neg q, p \rightarrow q \models \neg p$ | 否定后件 |
| **假言三段论**（Hypothetical Syllogism） | $p \rightarrow q, q \rightarrow r \models p \rightarrow r$ | 蕴涵传递 |
| **析取三段论**（Disjunctive Syllogism） | $p \lor q, \neg p \models q$ | 消去析取 |
| **附加律**（Addition） | $p \models p \lor q$ | 引入析取 |
| **化简律**（Simplification） | $p \land q \models p$ | 消去合取 |
| **合取律**（Conjunction） | $p, q \models p \land q$ | 引入合取 |
| **消解律**（Resolution） | $p \lor q, \neg p \lor r \models q \lor r$ | 归结原理 |

### 1.7.3 推理规则证明示例

**证明**（析取三段论 $p \lor q, \neg p \models q$）：

用真值表法：在所有使得前提 $p \lor q$ 和 $\neg p$ 同时为真的行中，$q$ 是否为真？

| $p$ | $q$ | $p \lor q$ | $\neg p$ | $q$ |
|------|------|------------|----------|------|
| T | T | T | F | T |
| T | F | T | F | F |
| F | T | T | T | T |
| F | F | F | T | F |

仅第三行前提全真，此时 $q = T$，推理有效。

**证明**（拒取式 $\neg q, p \rightarrow q \models \neg p$）：

$$
\begin{aligned}
1.\quad &\neg q \quad &\text{（前提）} \\
2.\quad &p \rightarrow q \quad &\text{（前提）} \\
3.\quad &\neg p \lor q \quad &\text{（2, 蕴涵展开 E14）} \\
4.\quad &\neg p \quad &\text{（1, 3, 析取三段论）}
\end{aligned}
$$

### 1.7.4 形式证明

**形式证明**（Formal Proof）：从前提出发，每一步使用推理规则或逻辑等价式推出中间结论，直到推出所要求的结论为止。

**示例**：证明 $p \rightarrow q, q \rightarrow r, p \models r$

$$
\begin{aligned}
1.\quad &p \quad &\text{（前提）} \\
2.\quad &p \rightarrow q \quad &\text{（前提）} \\
3.\quad &q \quad &\text{（1, 2, 假言推理 MP）} \\
4.\quad &q \rightarrow r \quad &\text{（前提）} \\
5.\quad &r \quad &\text{（3, 4, 假言推理 MP）}
\end{aligned}
$$

**附加前提证明法（CP规则）**：若要证明 $A_1, A_2, \dots, A_n \models B \rightarrow C$，等价于证明 $A_1, A_2, \dots, A_n, B \models C$。即将结论的前件作为附加前提引入。

**归谬法（反证法）**：若要证明 $A_1, A_2, \dots, A_n \models C$，可以证明 $A_1, A_2, \dots, A_n, \neg C \models F$（矛盾）。即假设结论的否定，推导出矛盾。

#include <iostream>
#include <vector>
#include <string>
#include <cmath>
#include <map>
#include <stack>
#include <cctype>
using namespace std;

// 命题变元（最多 26 个）
vector<char> vars;
map<char, bool> assign;

// 获取变元在 assign 中的值
bool evalVar(char var) {
    return assign[var];
}

// 解析并计算表达式的值
// 支持的运算符: ! (非), & (与), | (或), > (蕴涵), = (等价), ^ (异或)
// 使用双栈法或递归下降。简化起见，此处使用后缀表达式求值。
int prec(char op) {
    if (op == '!') return 4;
    if (op == '&') return 3;
    if (op == '|') return 2;
    if (op == '^') return 2;
    if (op == '>') return 1;
    if (op == '=') return 0;
    return -1;
}

// 将中缀表达式转换为后缀表达式
string infixToPostfix(string expr) {
    string post;
    stack<char> ops;
    for (int i = 0; i < (int)expr.size(); i++) {
        char c = expr[i];
        if (isalpha(c)) {
            post += c;
        } else if (c == '(') {
            ops.push(c);
        } else if (c == ')') {
            while (!ops.empty() && ops.top() != '(') {
                post += ops.top(); ops.pop();
            }
            if (!ops.empty()) ops.pop();
        } else {
            while (!ops.empty() && ops.top() != '(' &&
                   prec(ops.top()) >= prec(c)) {
                post += ops.top(); ops.pop();
            }
            ops.push(c);
        }
    }
    while (!ops.empty()) {
        post += ops.top(); ops.pop();
    }
    return post;
}

// 求后缀表达式的值
bool evalPostfix(string post) {
    stack<bool> st;
    for (char c : post) {
        if (isalpha(c)) {
            st.push(evalVar(c));
        } else if (c == '!') {
            bool v = st.top(); st.pop();
            st.push(!v);
        } else {
            bool b = st.top(); st.pop();
            bool a = st.top(); st.pop();
            switch (c) {
                case '&': st.push(a && b); break;
                case '|': st.push(a || b); break;
                case '^': st.push(a ^ b); break;
                case '>': st.push(!a || b); break;
                case '=': st.push(a == b); break;
            }
        }
    }
    return st.top();
}

int main() {
    string expr;
    cout << "输入命题公式（变元用小写字母，联结词：! & | > = ^）：";
    getline(cin, expr);

    // 提取变元
    bool seen[26] = {false};
    for (char c : expr) {
        if (islower(c)) seen[c - 'a'] = true;
    }
    for (int i = 0; i < 26; i++) {
        if (seen[i]) vars.push_back('a' + i);
    }

    string post = infixToPostfix(expr);
    int n = (int)vars.size();
    int rows = 1 << n;
    int trueCount = 0, falseCount = 0;

    // 打印表头
    for (char v : vars) cout << v << "\t";
    cout << "| 结果" << endl;
    for (int i = 0; i < n; i++) cout << "——\t";
    cout << "| ——" << endl;

    // 遍历所有赋值
    for (int mask = 0; mask < rows; mask++) {
        for (int j = 0; j < n; j++) {
            assign[vars[n - 1 - j]] = (mask >> j) & 1;
        }
        bool res = evalPostfix(post);
        for (char v : vars) cout << (assign[v] ? 'T' : 'F') << "\t";
        cout << "| " << (res ? 'T' : 'F') << endl;
        if (res) trueCount++; else falseCount++;
    }

    // 判断类型
    cout << endl;
    if (trueCount == rows)
        cout << "结论：永真式（重言式）" << endl;
    else if (falseCount == rows)
        cout << "结论：永假式（矛盾式）" << endl;
    else
        cout << "结论：可满足式（非永真）" << endl;

    // 输出主范式（用极小项/极大项的编号表示）
    cout << "主析取范式（极小项编号）：Σ(";
    bool first = true;
    for (int mask = 0; mask < rows; mask++) {
        for (int j = 0; j < n; j++) {
            assign[vars[n - 1 - j]] = (mask >> j) & 1;
        }
        if (evalPostfix(post)) {
            if (!first) cout << ", ";
            cout << mask;
            first = false;
        }
    }
    cout << ")" << endl;

    cout << "主合取范式（极大项编号）：Π(";
    first = true;
    for (int mask = 0; mask < rows; mask++) {
        for (int j = 0; j < n; j++) {
            assign[vars[n - 1 - j]] = (mask >> j) & 1;
        }
        if (!evalPostfix(post)) {
            if (!first) cout << ", ";
            cout << mask;
            first = false;
        }
    }
    cout << ")" << endl;

    return 0;
}

### 1.8.2 Python：真值表生成器与主范式求解

```python
import itertools
from typing import List, Dict, Callable


OPERATORS = {
    '!': (lambda a, _: not a, 4, 1),      # 单目
    '&': (lambda a, b: a and b, 3, 2),    # 合取
    '|': (lambda a, b: a or b, 2, 2),     # 析取
    '^': (lambda a, b: a ^ b, 2, 2),      # 异或
    '>': (lambda a, b: not a or b, 1, 2), # 蕴涵
    '=': (lambda a, b: a == b, 0, 2),     # 等价
}


def infix_to_postfix(expr: str) -> str:
    """中缀表达式转后缀（逆波兰表示法）"""
    output = []
    stack = []
    precedence = {op: info[1] for op, info in OPERATORS.items()}

    for ch in expr:
        if ch.isalpha():
            output.append(ch)
        elif ch == '(':
            stack.append(ch)
        elif ch == ')':
            while stack and stack[-1] != '(':
                output.append(stack.pop())
            if stack:
                stack.pop()
        elif ch in OPERATORS:
            while (stack and stack[-1] != '(' and
                   precedence.get(stack[-1], -1) >= precedence[ch]):
                output.append(stack.pop())
            stack.append(ch)

    while stack:
        output.append(stack.pop())

    return ''.join(output)


def eval_postfix(postfix: str, assign: Dict[str, bool]) -> bool:
    """后缀表达式求值"""
    stack = []
    for ch in postfix:
        if ch.isalpha():
            stack.append(assign[ch])
        else:
            func = OPERATORS[ch][0]
            arity = OPERATORS[ch][2]
            if arity == 1:
                a = stack.pop()
                stack.append(func(a, None))
            else:
                b = stack.pop()
                a = stack.pop()
                stack.append(func(a, b))
    return stack[0]


def truth_table(expr: str) -> dict:
    """
    生成命题公式的真值表，判断类型，并求主范式。
    返回包含真值表、分类、主范式信息的字典。
    """
    # 提取变元
    variables = sorted(set(ch for ch in expr if ch.isalpha()))
    postfix = infix_to_postfix(expr)
    n = len(variables)
    all_combos = list(itertools.product([False, True], repeat=n))

    table_rows = []
    true_masks = []   # 成真赋值的十进制编码
    false_masks = []  # 成假赋值的十进制编码

    for combo in all_combos:
        assign = {var: val for var, val in zip(variables, combo)}
        result = eval_postfix(postfix, assign)
        mask = sum((1 if val else 0) << (n - 1 - i) for i, val in enumerate(combo))
        table_rows.append((assign.copy(), result, mask))
        if result:
            true_masks.append(mask)
        else:
            false_masks.append(mask)

    # 判断类型
    total = 1 << n
    if len(true_masks) == total:
        category = "永真式（重言式）"
    elif len(true_masks) == 0:
        category = "永假式（矛盾式）"
    else:
        category = "可满足式"

    return {
        'variables': variables,
        'postfix': postfix,
        'table': table_rows,
        'category': category,
        'true_masks': sorted(true_masks),
        'false_masks': sorted(false_masks),
    }


def print_truth_table(expr: str):
    """格式化输出真值表及分析结果"""
    result = truth_table(expr)
    variables = result['variables']

    # 打印表头
    header = '  '.join(variables) + '  |  结果'
    print(header)
    print('-' * len(header))

    # 打印每行
    for assign, val, _ in result['table']:
        row = '  '.join('T' if assign[v] else 'F' for v in variables)
        row += '  |  ' + ('T' if val else 'F')
        print(row)

    print()
    print(f"类型判断：{result['category']}")
    print(f"主析取范式（极小项）：Σ({', '.join(str(m) for m in result['true_masks'])})")
    print(f"主合取范式（极大项）：Π({', '.join(str(m) for m in result['false_masks'])})")


def is_tautology(expr: str) -> bool:
    """判断是否为永真式"""
    info = truth_table(expr)
    return info['category'] == "永真式（重言式）"


def is_contradiction(expr: str) -> bool:
    """判断是否为永假式"""
    info = truth_table(expr)
    return info['category'] == "永假式（矛盾式）"


def is_satisfiable(expr: str) -> bool:
    """判断是否为可满足式"""
    info = truth_table(expr)
    return info['category'] != "永假式（矛盾式）"


# =================== 示例 ===================
if __name__ == "__main__":
    test_expr = "(p>q)&!r"
    print(f"公式: {test_expr}")
    print()
    print_truth_table(test_expr)
```

### 1.8.3 Python：消解原理实现（SAT初步）

```python
def resolve(clause1: set, clause2: set) -> set | None:
    """
    对两个子句（文字的集合）进行消解。
    若存在互补对，返回消解结果（新子句）；否则返回 None。
    """
    for lit in clause1:
        complement = f"~{lit}" if not lit.startswith("~") else lit[1:]
        if complement in clause2:
            # 找到互补对，合并剩余文字
            new_clause = (clause1 | clause2) - {lit, complement}
            return new_clause
    return None


def resolution_prove(clauses: list[set], goal: set) -> bool:
    """
    用消解原理证明 goal 是 clauses 的逻辑结论。
    等价于证明 clauses ∪ {~goal} 不可满足（推出空子句）。
    """
    # 将 goal 的否定加入前提
    neg_goal = {f"~{lit}" if not lit.startswith('~') else lit[1:]
                for lit in goal}
    all_clauses = clauses[:]
    if neg_goal:
        all_clauses.append(neg_goal)

    while True:
        n = len(all_clauses)
        for i in range(n):
            for j in range(i + 1, n):
                new_c = resolve(all_clauses[i], all_clauses[j])
                if new_c is not None:
                    if not new_c:  # 空子句 → 矛盾 → 证明成功
                        return True
                    if new_c not in all_clauses:
                        all_clauses.append(new_c)
        if len(all_clauses) == n:
            return False  # 无法产生新子句，证明失败


# 示例：证明 (p ∨ q), (¬p ∨ r) ⊨ q ∨ r
clauses = [{"p", "q"}, {"~p", "r"}]
goal = {"q", "r"}
print("消解证明:", "成功" if resolution_prove(clauses, goal) else "失败")
```
