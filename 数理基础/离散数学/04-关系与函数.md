# 04-关系与函数

## 1. 关系的基本概念

### 1.1 二元关系的定义

**定义（二元关系）**：设 $A$ 和 $B$ 是两个集合，**从 $A$ 到 $B$ 的二元关系**（binary relation）$R$ 是笛卡尔积 $A \times B$ 的一个子集，即

$$R \subseteq A \times B = \{(a, b) \mid a \in A, b \in B\}$$

- 若 $(a, b) \in R$，称 $a$ 与 $b$ 有关系 $R$，记作 $aRb$ 或 $R(a, b)$。
- 若 $(a, b) \notin R$，记作 $a \not R b$。
- 当 $A = B$ 时，称 $R$ 是 **$A$ 上的关系**（relation on $A$）。

**空关系**：$R = \emptyset$，没有任何有序对。

**全域关系**：$R = A \times B$，包含所有可能的有序对。

**恒等关系**：$A$ 上的恒等关系 $I_A = \{(a, a) \mid a \in A\}$。

> **例 1**：设 $A = \{1, 2, 3\}$，$B = \{a, b\}$，定义 $R = \{(1, a), (1, b), (2, a)\}$，则 $R$ 是从 $A$ 到 $B$ 的关系。$1Rb$ 成立，但 $2 \not R b$。

> **例 2**：在自然数集 $\mathbb{N}$ 上定义整除关系 $|$，即 $a \mid b$ 当且仅当存在 $k \in \mathbb{N}$ 使 $b = ak$。

### 1.2 关系的表示法

#### 关系矩阵（Relation Matrix）

设 $A = \{a_1, a_2, \dots, a_m\}$，$B = \{b_1, b_2, \dots, b_n\}$，关系 $R \subseteq A \times B$ 的**关系矩阵** $M_R = (m_{ij})_{m \times n}$ 定义为：

$$m_{ij} = \begin{cases} 1, & \text{若 } (a_i, b_j) \in R \\ 0, & \text{若 } (a_i, b_j) \notin R \end{cases}$$

> **例 3**：$A = \{1, 2, 3\}$，$B = \{a, b\}$，$R = \{(1, a), (1, b), (2, a)\}$，其关系矩阵为：
>
> $$M_R = \begin{pmatrix} 1 & 1 \\ 1 & 0 \\ 0 & 0 \end{pmatrix}$$

#### 关系图（Directed Graph）

将集合 $A$ 中的元素用点（顶点）表示，若 $(a_i, a_j) \in R$，则从 $a_i$ 到 $a_j$ 画一条有向边（弧）。当 $R$ 是 $A$ 上的关系时，关系图是一个有向图。

> **例 4**：$A = \{1, 2, 3\}$，$R = \{(1, 1), (1, 2), (2, 3), (3, 2)\}$ 的关系图中：
> - 顶点 1 有一个自环
> - 从 1 到 2 有一条边
> - 从 2 到 3 有一条边
> - 从 3 到 2 有一条边

### 1.3 定义域、值域与域

**定义**：设 $R \subseteq A \times B$，

- **定义域（domain）**：$\text{dom}(R) = \{a \in A \mid \exists b \in B, (a, b) \in R\}$
- **值域（range）**：$\text{ran}(R) = \{b \in B \mid \exists a \in A, (a, b) \in R\}$
- **域**：$\text{fld}(R) = \text{dom}(R) \cup \text{ran}(R)$

> **例 5**：$R = \{(1, a), (1, b), (2, a)\}$，则 $\text{dom}(R) = \{1, 2\}$，$\text{ran}(R) = \{a, b\}$。

### 1.4 关系总数

**定理**：设 $|A| = m$，$|B| = n$，则从 $A$ 到 $B$ 的不同关系有 $2^{mn}$ 个。

**证明**：$A \times B$ 有 $mn$ 个元素，每个元素可以选入或不选入 $R$，因此 $R$ 的个数为 $2^{mn}$。

## 2. 关系的运算

### 2.1 逆关系

**定义**：设 $R \subseteq A \times B$，$R$ 的**逆关系**（inverse relation）定义为

$$R^{-1} = \{(b, a) \mid (a, b) \in R\}$$

显然 $R^{-1} \subseteq B \times A$。

**性质**：
1. $(R^{-1})^{-1} = R$
2. $M_{R^{-1}} = (M_R)^T$（关系矩阵的转置）
3. $\text{dom}(R^{-1}) = \text{ran}(R)$，$\text{ran}(R^{-1}) = \text{dom}(R)$

> **例 6**：$R = \{(1, a), (2, b)\}$，则 $R^{-1} = \{(a, 1), (b, 2)\}$。

### 2.2 复合关系

**定义**：设 $R \subseteq A \times B$，$S \subseteq B \times C$，则 $R$ 与 $S$ 的**复合关系**（composite relation）$R \circ S$ 定义为：

$$R \circ S = \{(a, c) \mid \exists b \in B,\ (a, b) \in R \land (b, c) \in S\}$$

**注意**：有些教材记作 $S \circ R$。本文采用 $(R \circ S)(a, c)$ 当且仅当存在 $b$ 满足 $(a,b)\in R$ 且 $(b,c)\in S$。

**性质**：
1. **结合律**：$(R \circ S) \circ T = R \circ (S \circ T)$
2. $R \circ I_B = R$，$I_A \circ R = R$
3. $(R \circ S)^{-1} = S^{-1} \circ R^{-1}$（注意次序颠倒）
4. 复合一般不满足交换律：$R \circ S \neq S \circ R$

> **例 7**：设 $R = \{(1, 2), (1, 3)\}$，$S = \{(2, a), (3, b)\}$，则
> $$R \circ S = \{(1, a), (1, b)\}$$

### 2.3 关系矩阵乘法与布尔积

关系复合的矩阵表示使用**布尔积**：

$$M_{R \circ S} = M_R \odot M_S$$

其中布尔积定义为：$(M_R \odot M_S)_{ij} = \bigvee_{k=1}^{n} (m_{ik}^{(R)} \land m_{kj}^{(S)})$

即：将普通矩阵乘法中的 $+$ 替换为 $\lor$（逻辑或），$\times$ 替换为 $\land$（逻辑与）。

**关系矩阵的基本性质**：
- $M_{R^{-1}} = (M_R)^T$
- $M_{R_1 \cup R_2} = M_{R_1} \lor M_{R_2}$
- $M_{R_1 \cap R_2} = M_{R_1} \land M_{R_2}$

> **例 8**：$M_R = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$，$M_S = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$，则
> $$M_R \odot M_S = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$$

## 3. 关系的性质（重点）

设 $R$ 是集合 $A$ 上的关系。

### 3.1 自反性与反自反性

**定义（自反性）**：若对每个 $a \in A$，都有 $(a, a) \in R$，则称 $R$ 是**自反的**（reflexive）。

$$\forall a \in A, (a, a) \in R$$

**关系矩阵判断**：主对角线元素全为 $1$。

**关系图判断**：每个顶点都有自环。

**定义（反自反性）**：若对每个 $a \in A$，都有 $(a, a) \notin R$，则称 $R$ 是**反自反的**（irreflexive）。

$$\forall a \in A, (a, a) \notin R$$

**关系矩阵判断**：主对角线元素全为 $0$。

> **例 9**：在 $\mathbb{R}$ 上，$\leq$ 是自反的（每个数等于自身），$<$ 是反自反的（没有数小于自身）。

**重要注记**：存在既非自反也非反自反的关系。例如 $A = \{1, 2, 3\}$ 上 $R = \{(1, 1), (2, 2)\}$——3 与自身没有关系。

### 3.2 对称性与反对称性

**定义（对称性）**：若对任意 $a, b \in A$，$(a, b) \in R$ 蕴涵 $(b, a) \in R$，则称 $R$ 是**对称的**（symmetric）。

$$\forall a, b \in A, (a, b) \in R \Rightarrow (b, a) \in R$$

**关系矩阵判断**：$M_R$ 是对称矩阵（$M_R^T = M_R$）。

**关系图判断**：任意两个顶点间的有向边都是成对出现的（双向边）。

**定义（反对称性）**：若对任意 $a, b \in A$，$(a, b) \in R$ 且 $(b, a) \in R$ 蕴涵 $a = b$，则称 $R$ 是**反对称的**（antisymmetric）。

$$\forall a, b \in A, (a, b) \in R \land (b, a) \in R \Rightarrow a = b$$

等价的逆否命题：若 $a \neq b$，则 $(a, b)$ 与 $(b, a)$ 不能同时属于 $R$。

**关系矩阵判断**：若 $i \neq j$，则 $m_{ij}$ 与 $m_{ji}$ 不能同时为 $1$。

**关系图判断**：任意两个不同顶点间至多有一条单向边（不允许双向边，但自环允许）。

> **例 10**：
> - $A = \{1, 2, 3\}$ 上 $R = \{(1, 2), (2, 1), (1, 1)\}$：对称但非反对称（因为 $(1,2)$ 和 $(2,1)$ 同时存在而 $1 \neq 2$）。
> - $R = \{(1, 2), (1, 3)\}$：反对称。
> - $R = \{(1, 1), (2, 2)\}$：既对称又反对称。

### 3.3 传递性

**定义（传递性）**：若对任意 $a, b, c \in A$，$(a, b) \in R$ 且 $(b, c) \in R$ 蕴涵 $(a, c) \in R$，则称 $R$ 是**传递的**（transitive）。

$$\forall a, b, c \in A, (a, b) \in R \land (b, c) \in R \Rightarrow (a, c) \in R$$

**关系矩阵判断**：$M_{R \circ R} \preceq M_R$（即若 $(R \circ R)_{ij} = 1$，则必有 $R_{ij} = 1$）。等价地：$R \circ R \subseteq R$。

> **例 11**：
> - $R = \{(1, 2), (2, 3), (1, 3)\}$ 是传递的。
> - $R = \{(1, 2), (2, 3)\}$ 不是传递的（缺少 $(1, 3)$）。

### 3.4 性质之间的关系与复合

**定理**：设 $R$ 和 $S$ 是 $A$ 上的关系，则：

| 性质 | $R^{-1}$ 保持 | $R \cap S$ 保持 | $R \cup S$ 保持 | $R \circ S$ 保持 |
|------|:---:|:---:|:---:|:---:|
| 自反性 | ✓ | ✓ | ✓ | ✓ |
| 反自反性 | ✓ | ✓ | ✓ | ✗ |
| 对称性 | ✓ | ✓ | ✓ | ✗ |
| 反对称性 | ✓ | ✓ | ✗ | ✗ |
| 传递性 | ✓ | ✓ | ✗ | ✗ |

> **例 12**：$R = \{(1, 2)\}$ 和 $S = \{(2, 1)\}$ 都是反对称的，但 $R \cup S = \{(1, 2), (2, 1)\}$ 不是反对称的。

## 4. 闭包

**动机**：给定一个关系 $R$，我们希望用最少的有序对将其扩展为具有某种性质（自反、对称、传递）的关系。

### 4.1 定义

**定义**：设 $R$ 是 $A$ 上的关系，$P$ 是某种性质（自反性、对称性、传递性），则 $R$ 关于性质 $P$ 的**闭包**（closure）$R_P$ 是满足以下条件的最小关系：

1. $R \subseteq R_P$（闭包包含 $R$）
2. $R_P$ 具有性质 $P$
3. 若 $R'$ 具有性质 $P$ 且 $R \subseteq R'$，则 $R_P \subseteq R'$（最小性）

**三种基本闭包**：

| 符号 | 名称 | 构造方法 |
|------|------|---------|
| $r(R)$ | 自反闭包 | $r(R) = R \cup I_A$ |
| $s(R)$ | 对称闭包 | $s(R) = R \cup R^{-1}$ |
| $t(R)$ | 传递闭包 | $t(R) = \bigcup_{i=1}^{\infty} R^i$ |

> **例 13**：$A = \{1, 2, 3\}$，$R = \{(1, 2), (2, 3), (3, 1)\}$，
> - $r(R) = \{(1,1), (2,2), (3,3), (1,2), (2,3), (3,1)\}$
> - $s(R) = \{(1,2), (2,1), (2,3), (3,2), (3,1), (1,3)\}$
> - $t(R) = I_A \cup \{(1,2), (2,3), (3,1), (1,3), (2,1), (3,2)\}$

**性质与闭包的复合**：$sr(R) = rs(R)$；$tr(R) = rt(R)$；$ts(R) \supseteq st(R)$。

### 4.2 Warshall 算法求传递闭包

**Warshall 算法**（1962）用于计算有限集上关系的传递闭包，时间复杂度 $O(n^3)$。

**算法思想**：逐步构造矩阵序列 $W_0, W_1, \dots, W_n$，其中 $W_k[i][j] = 1$ 当且仅当存在从 $i$ 到 $j$ 的路径且内部顶点编号不超过 $k$。

- $W_0 = M_R$（零步可达即为直接关系）
- $W_n = M_{t(R)}$（传递闭包的关系矩阵）

**递推公式**：

$$W_k[i][j] = W_{k-1}[i][j] \lor (W_{k-1}[i][k] \land W_{k-1}[k][j])$$

**C++ 实现**：

```cpp
#include <iostream>
#include <vector>
using namespace std;

void warshall(vector<vector<int>>& W) {
    int n = W.size();
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            if (W[i][k]) {
                for (int j = 0; j < n; j++) {
                    W[i][j] = W[i][j] || W[k][j];
                }
            }
        }
    }
}

int main() {
    int n = 4;
    vector<vector<int>> W = {
        {1, 0, 1, 0},
        {0, 1, 0, 1},
        {0, 0, 1, 0},
        {0, 0, 0, 1}
    };

    warshall(W);

    for (auto& row : W) {
        for (int v : row) cout << v << " ";
        cout << endl;
    }
    return 0;
}
```

**Python 实现**：

```python
def warshall(W):
    n = len(W)
    for k in range(n):
        for i in range(n):
            if W[i][k]:
                for j in range(n):
                    W[i][j] = W[i][j] or W[k][j]
    return W

W = [
    [1, 0, 1, 0],
    [0, 1, 0, 1],
    [0, 0, 1, 0],
    [0, 0, 0, 1]
]

result = warshall(W)
for row in result:
    print(row)
```

## 5. 等价关系

### 5.1 定义

**定义**：集合 $A$ 上的关系 $R$ 若满足**自反性、对称性、传递性**，则称 $R$ 为一个**等价关系**（equivalence relation），通常记作 $\sim$。

> **例 14（模 $n$ 同余）**：在 $\mathbb{Z}$ 上，$a \equiv b \pmod{n}$（即 $n \mid (a - b)$）是等价关系。
> - 自反：$a - a = 0$ 被任何 $n$ 整除 ✓
> - 对称：若 $n \mid (a-b)$，则 $n \mid (b-a)$ ✓
> - 传递：若 $n \mid (a-b)$ 且 $n \mid (b-c)$，则 $n \mid (a-b)+(b-c) = a-c$ ✓

> **例 15（相等关系）**：在任何集合上，$a = b$ 是等价关系。

> **例 16（平行关系）**：在平面上所有直线的集合中，$l_1 \parallel l_2$ 是等价关系。

### 5.2 等价类与商集

**定义（等价类）**：设 $\sim$ 是 $A$ 上的等价关系，$a \in A$，则 $a$ 的**等价类**（equivalence class）定义为

$$[a]_\sim = \{x \in A \mid x \sim a\}$$

$a$ 称为该等价类的**代表元**（representative）。

**定理**：设 $\sim$ 是 $A$ 上的等价关系，$a, b \in A$，则下列三个命题等价：
1. $a \sim b$
2. $[a] = [b]$
3. $[a] \cap [b] \neq \emptyset$

**定义（商集）**：$A$ 关于等价关系 $\sim$ 的**商集**（quotient set）为所有等价类的集合：

$$A/{\sim} = \{[a]_\sim \mid a \in A\}$$

> **例 17**：模 3 同余下，$\mathbb{Z}/{\equiv_3} = \{[0], [1], [2]\}$，其中 $[0] = \{\dots, -6, -3, 0, 3, 6, \dots\}$。

### 5.3 划分与等价关系的一一对应

**定义（划分）**：集合 $A$ 的一个**划分**（partition）是一个由 $A$ 的非空子集构成的集合族 $\mathcal{P} = \{A_1, A_2, \dots, A_k\}$，满足：
1. $\bigcup_{i=1}^{k} A_i = A$（覆盖 $A$）
2. $A_i \cap A_j = \emptyset$ 当 $i \neq j$（两两不交）

**核心定理**：$A$ 上的等价关系与 $A$ 的划分之间存在一一对应。

- **等价关系 $\rightarrow$ 划分**：等价类的集合 $A/{\sim}$ 构成 $A$ 的一个划分。
- **划分 $\rightarrow$ 等价关系**：定义 $a \sim b$ 当 $a$ 与 $b$ 属于划分的同一块。

> **例 18**：$A = \{1, 2, 3, 4, 5\}$，划分 $\{\{1, 3\}, \{2, 5\}, \{4\}\}$ 对应的等价关系中，等价类为 $[1] = [3] = \{1, 3\}$，$[2] = [5] = \{2, 5\}$，$[4] = \{4\}$。

## 6. 偏序关系

### 6.1 定义

**定义**：集合 $A$ 上的关系 $R$ 若满足**自反性、反对称性、传递性**，则称 $R$ 为一个**偏序关系**（partial order），通常记作 $\preceq$。称 $(A, \preceq)$ 为**偏序集**（partially ordered set, POSET）。

> **例 19**：
> - $(\mathbb{R}, \leq)$ 是偏序集
> - $(\mathcal{P}(X), \subseteq)$ 是偏序集（集合的包含关系）
> - $(\mathbb{N}, \mid)$ 是偏序集（整除关系）

**定义（可比性）**：在偏序集 $(A, \preceq)$ 中，若 $a \preceq b$ 或 $b \preceq a$，称 $a$ 与 $b$ **可比**（comparable）；否则称**不可比**（incomparable）。

### 6.2 哈塞图

**哈塞图**（Hasse Diagram）是有限偏序集的图形表示法，绘制规则如下：

1. 用小圆圈表示每个元素
2. 若 $a \prec b$（即 $a \preceq b$ 且 $a \neq b$），且不存在 $c$ 使得 $a \prec c \prec b$，则将 $a$ 放在 $b$ 下方并用线段连接（无箭头）
3. 不画出自反性产生的自环
4. 不画出由传递性可推出的边

> **例 20**：$A = \{1, 2, 3, 4\}$，偏序为整除关系 $\mid$。哈塞图：4 在最上方，2 和 3 在中间（2 在 4 下方与之相连），1 在最下方（同时连接 2 和 3）。3 与 2 不可比。

### 6.3 极大元/极小元、最大元/最小元

设 $(A, \preceq)$ 是偏序集：

| 概念 | 定义 | 存在性 |
|------|------|--------|
| **极大元** (maximal) | $a \in A$ 使得不存在 $b \in A$ 满足 $a \prec b$ | 必有，可能多个 |
| **极小元** (minimal) | $a \in A$ 使得不存在 $b \in A$ 满足 $b \prec a$ | 必有，可能多个 |
| **最大元** (greatest) | $a \in A$ 使得对所有 $b \in A$，$b \preceq a$ | 至多一个 |
| **最小元** (least) | $a \in A$ 使得对所有 $b \in A$，$a \preceq b$ | 至多一个 |

> **例 21**：$A = \{2, 3, 4, 6\}$，整除偏序。极大元：$4$ 和 $6$；极小元：$2$ 和 $3$；无最大元和最小元。

### 6.4 上界/下界、上确界/下确界

设 $(A, \preceq)$ 是偏序集，$B \subseteq A$：

| 概念 | 定义 |
|------|------|
| **上界** (upper bound) | $a \in A$ 使得对所有 $b \in B$，$b \preceq a$ |
| **下界** (lower bound) | $a \in A$ 使得对所有 $b \in B$，$a \preceq b$ |
| **上确界** (supremum) | $B$ 的最小上界（least upper bound, LUB），记作 $\sup B$ |
| **下确界** (infimum) | $B$ 的最大下界（greatest lower bound, GLB），记作 $\inf B$ |

> **例 22**：在 $(\mathbb{R}, \leq)$ 中，$B = (0, 1)$ 的上界为 $[1, +\infty)$，上确界为 $1$（但 $1 \notin B$）。

### 6.5 全序与良序

**定义（全序 / 线性序）**：若 $(A, \preceq)$ 是偏序集且 $A$ 中任意两个元素都可比，则称为**全序集**或**线序集**（totally ordered set / chain）。

> **例 23**：$(\mathbb{R}, \leq)$ 是全序集；$(\mathcal{P}(\{1,2\}), \subseteq)$ 不是（$\{1\}$ 与 $\{2\}$ 不可比）。

**定义（良序）**：若 $(A, \preceq)$ 是全序集且 $A$ 的每个非空子集都有最小元，则称为**良序集**（well-ordered set）。

> **例 24**：$(\mathbb{N}, \leq)$ 是良序集；$(\mathbb{Z}, \leq)$ 不是（$\mathbb{Z}$ 本身无最小元）。

### 6.6 字典序与积序

**定义（字典序）**：在积集 $A_1 \times A_2 \times \dots \times A_n$ 上，其中每个 $(A_i, \preceq_i)$ 是偏序集，字典序定义为：

$$(a_1, \dots, a_n) \prec (b_1, \dots, b_n) \text{ 当 } \exists k: a_1 = b_1, \dots, a_{k-1} = b_{k-1}, a_k \prec_k b_k$$

**定义（积序）**：$(a_1, \dots, a_n) \preceq (b_1, \dots, b_n)$ 当对所有 $i$，$a_i \preceq_i b_i$。

## 7. 函数

### 7.1 函数的定义

**定义**：设 $f \subseteq A \times B$ 是一个关系，若满足**单值性**——对每个 $a \in A$，存在**唯一的** $b \in B$ 使 $(a, b) \in f$，则称 $f$ 为**从 $A$ 到 $B$ 的函数**（function），记作 $f: A \to B$。$(a, b) \in f$ 记作 $f(a) = b$。

- $A$ 称为**定义域**（domain）
- $B$ 称为**陪域**（codomain）
- $f(A) = \{f(a) \mid a \in A\}$ 称为**值域**（range/image）

> **例 25**：$R = \{(1, a), (1, b)\}$ 不是函数（1 对应两个值）；$f = \{(1, a), (2, a)\}$ 是函数。

**函数相等**：$f = g$ 当且仅当 $\text{dom}(f) = \text{dom}(g)$ 且对所有 $a \in \text{dom}(f)$，$f(a) = g(a)$。

### 7.2 单射、满射、双射

设 $f: A \to B$：

| 类型 | 定义 | 等价条件 |
|------|------|---------|
| **单射** (injective) | $a_1 \neq a_2 \Rightarrow f(a_1) \neq f(a_2)$ | $f(a_1) = f(a_2) \Rightarrow a_1 = a_2$ |
| **满射** (surjective) | $f(A) = B$（值域等于陪域） | 对每个 $b \in B$，存在 $a \in A$ 使 $f(a) = b$ |
| **双射** (bijective) | 既单射又满射 | 建立 $A$ 与 $B$ 之间的一一对应 |

> **例 26**：
> - $f: \mathbb{R} \to \mathbb{R}, f(x) = e^x$：单射（严格单调）但非满射（无负数输出）
> - $f: \mathbb{R} \to \mathbb{R}, f(x) = x^3 - x$：满射（三次函数值域为 $\mathbb{R}$）但非单射（$f(-1) = f(0) = f(1)$）
> - $f: \mathbb{R} \to \mathbb{R}, f(x) = x$：双射

### 7.3 函数的复合与逆函数

**定义（函数复合）**：设 $f: A \to B$，$g: B \to C$，则复合函数 $(g \circ f): A \to C$ 定义为

$$(g \circ f)(a) = g(f(a))$$

**性质**：
1. 若 $f$ 和 $g$ 都是单射，则 $g \circ f$ 也是单射
2. 若 $f$ 和 $g$ 都是满射，则 $g \circ f$ 也是满射
3. 若 $f$ 和 $g$ 都是双射，则 $g \circ f$ 也是双射
4. 复合满足结合律：$h \circ (g \circ f) = (h \circ g) \circ f$

**定义（逆函数）**：设 $f: A \to B$ 是双射，则 $f$ 的**逆函数** $f^{-1}: B \to A$ 定义为：

$$f^{-1}(b) = a \text{ 当且仅当 } f(a) = b$$

**定理**：$f: A \to B$ 存在逆函数的充要条件是 $f$ 为双射。

**性质**：
- $(f^{-1})^{-1} = f$
- $f^{-1} \circ f = I_A$，$f \circ f^{-1} = I_B$
- $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$

### 7.4 几类特殊函数

**常值函数**：$f: A \to B$，存在 $b_0 \in B$ 使得对所有 $a \in A$，$f(a) = b_0$。

**恒等函数**：$I_A: A \to A$，$I_A(a) = a$。

**特征函数**：设 $U$ 为全集，$A \subseteq U$，$A$ 的特征函数 $\chi_A: U \to \{0, 1\}$ 定义为：

$$\chi_A(x) = \begin{cases} 1, & x \in A \\ 0, & x \notin A \end{cases}$$

**取整函数**：
- 下取整（floor）：$\lfloor x \rfloor = \max\{n \in \mathbb{Z} \mid n \leq x\}$
- 上取整（ceiling）：$\lceil x \rceil = \min\{n \in \mathbb{Z} \mid n \geq x\}$

### 7.5 鸽巢原理

**定理（鸽巢原理基本形式）**：若把 $n+1$ 个物体放入 $n$ 个盒子，则至少有一个盒子包含至少 $2$ 个物体。

**证明**：反证法。若每个盒子至多包含 $1$ 个物体，则 $n$ 个盒子至多包含 $n$ 个物体，与有 $n+1$ 个物体矛盾。

**加强形式**：若把 $q_1 + q_2 + \dots + q_n - n + 1$ 个物体放入 $n$ 个盒子，则存在某个 $i$ 使得第 $i$ 个盒子包含至少 $q_i$ 个物体。

**平均形式**：若 $m$ 个物体放入 $n$ 个盒子，则至少有一个盒子包含至少 $\lceil m/n \rceil$ 个物体。

> **例 27**：在任意 $13$ 个人中，至少有 $2$ 人生日在同一个月。

> **例 28**：从 $1$ 到 $2n$ 的整数中任取 $n+1$ 个，必有两个数互质。（因为任意两个相邻整数 $(k, k+1)$ 互质，而 $n+1$ 个数跨越 $2n$ 个位置。）

### 8.1 关系矩阵表示与性质检查（C++）

```cpp
#include <iostream>
#include <vector>
using namespace std;

class Relation {
public:
    vector<vector<int>> matrix;
    int n;

    Relation(int size) : n(size), matrix(size, vector<int>(size, 0)) {}

    void add(int a, int b) { matrix[a][b] = 1; }

    bool isReflexive() {
        for (int i = 0; i < n; i++)
            if (!matrix[i][i]) return false;
        return true;
    }

    bool isIrreflexive() {
        for (int i = 0; i < n; i++)
            if (matrix[i][i]) return false;
        return true;
    }

    bool isSymmetric() {
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (matrix[i][j] != matrix[j][i]) return false;
        return true;
    }

    bool isAntisymmetric() {
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (i != j && matrix[i][j] && matrix[j][i]) return false;
        return true;
    }

    bool isTransitive() {
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                for (int k = 0; k < n; k++)
                    if (matrix[i][j] && matrix[j][k] && !matrix[i][k])
                        return false;
        return true;
    }

    bool isEquivalence() {
        return isReflexive() && isSymmetric() && isTransitive();
    }

    bool isPartialOrder() {
        return isReflexive() && isAntisymmetric() && isTransitive();
    }

    vector<vector<int>> transitiveClosure() {
        auto W = matrix;
        for (int k = 0; k < n; k++)
            for (int i = 0; i < n; i++)
                if (W[i][k])
                    for (int j = 0; j < n; j++)
                        W[i][j] = W[i][j] || W[k][j];
        return W;
    }

    vector<vector<int>> findEquivalenceClasses() {
        auto closure = transitiveClosure();
        auto sym_closure = closure;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                sym_closure[i][j] = sym_closure[i][j] || closure[j][i];

        vector<bool> visited(n, false);
        vector<vector<int>> classes;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                vector<int> eq_class;
                for (int j = 0; j < n; j++) {
                    if (sym_closure[i][j]) {
                        eq_class.push_back(j);
                        visited[j] = true;
                    }
                }
                classes.push_back(eq_class);
            }
        }
        return classes;
    }
};

int main() {
    Relation R(4);
    // 模2同余关系: (0,0),(0,2),(1,1),(1,3),(2,0),(2,2),(3,1),(3,3)
    R.add(0, 0); R.add(1, 1); R.add(2, 2); R.add(3, 3);
    R.add(0, 2); R.add(2, 0); R.add(1, 3); R.add(3, 1);

    cout << "Reflexive: " << R.isReflexive() << endl;
    cout << "Symmetric: " << R.isSymmetric() << endl;
    cout << "Transitive: " << R.isTransitive() << endl;
    cout << "Equivalence: " << R.isEquivalence() << endl;
    cout << "Partial order: " << R.isPartialOrder() << endl;

    auto classes = R.findEquivalenceClasses();
    cout << "Equivalence classes:" << endl;
    for (auto& c : classes) {
        cout << "{";
        for (int x : c) cout << x << " ";
        cout << "}" << endl;
    }
    return 0;
}
```

### 8.2 关系性质检查（Python）

```python
class Relation:
    def __init__(self, n):
        self.n = n
        self.matrix = [[0] * n for _ in range(n)]

    def add(self, a, b):
        self.matrix[a][b] = 1

    def is_reflexive(self):
        return all(self.matrix[i][i] for i in range(self.n))

    def is_irreflexive(self):
        return all(not self.matrix[i][i] for i in range(self.n))

    def is_symmetric(self):
        return all(self.matrix[i][j] == self.matrix[j][i]
                   for i in range(self.n) for j in range(self.n))

    def is_antisymmetric(self):
        for i in range(self.n):
            for j in range(self.n):
                if i != j and self.matrix[i][j] and self.matrix[j][i]:
                    return False
        return True

    def is_transitive(self):
        for i in range(self.n):
            for j in range(self.n):
                for k in range(self.n):
                    if self.matrix[i][j] and self.matrix[j][k] \
                       and not self.matrix[i][k]:
                        return False
        return True

    def is_equivalence(self):
        return self.is_reflexive() and self.is_symmetric() \
               and self.is_transitive()

    def is_partial_order(self):
        return self.is_reflexive() and self.is_antisymmetric() \
               and self.is_transitive()

    def transitive_closure(self):
        W = [row[:] for row in self.matrix]
        for k in range(self.n):
            for i in range(self.n):
                if W[i][k]:
                    for j in range(self.n):
                        W[i][j] = W[i][j] or W[k][j]
        return W

    def equivalence_classes(self):
        closure = self.transitive_closure()
        n = self.n
        # Make symmetric reachability
        reach = [[closure[i][j] or closure[j][i] for j in range(n)]
                 for i in range(n)]
        visited = [False] * n
        classes = []
        for i in range(n):
            if not visited[i]:
                eq_class = [j for j in range(n) if reach[i][j]]
                for j in eq_class:
                    visited[j] = True
                classes.append(eq_class)
        return classes

print("Reflexive:", R.is_reflexive())
print("Symmetric:", R.is_symmetric())
print("Transitive:", R.is_transitive())
print("Equivalence:", R.is_equivalence())
print("Equivalence classes:", R.equivalence_classes())
```

### 8.3 哈塞图绘制（Python）

```python
import networkx as nx
import matplotlib.pyplot as plt

def transitive_reduction(G):
    """Compute transitive reduction for Hasse diagram"""
    n = len(G)
    closure = [[G[i][j] for j in range(n)] for i in range(n)]

    # Warshall for transitive closure
    for k in range(n):
        for i in range(n):
            if closure[i][k]:
                for j in range(n):
                    closure[i][j] = closure[i][j] or closure[k][j]

    # Remove edges that are implied by transitivity
    reduced = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            if G[i][j] and i != j:
                # Check if there is a longer path
                implied = False
                for k in range(n):
                    if k != i and k != j and G[i][k] and closure[k][j]:
                        implied = True
                        break
                if not implied:
                    reduced[i][j] = 1

    return reduced


def draw_hassse(matrix, labels=None):
    """Draw Hasse diagram using networkx"""
    reduced = transitive_reduction(matrix)
    n = len(matrix)

    G = nx.DiGraph()
    for i in range(n):
        for j in range(n):
            if reduced[i][j]:
                G.add_edge(i, j)

    pos = nx.spring_layout(G, seed=42)
    label_dict = {i: labels[i] if labels else str(i) for i in range(n)}

    plt.figure(figsize=(6, 5))
    nx.draw(G, pos, labels=label_dict, with_labels=True,
            node_size=800, node_color='lightblue',
            edge_color='gray', arrows=False,
            font_size=12)
    plt.title("Hasse Diagram")
    plt.axis('off')
    plt.show()
```

## 总结

本章从**关系**这一离散数学核心概念出发，系统介绍了：

| 主题 | 核心要点 |
|------|---------|
| 关系基础 | 笛卡尔积子集、矩阵/图表示、域的概念 |
| 关系运算 | 逆关系、复合关系、布尔积 |
| 关系性质 | 自反/反自反、对称/反对称、传递（五性质判断） |

等价关系和偏序关系是离散数学中最重要的两类关系，它们分别刻画了"相等"和"大小"这两种最基本的数学概念。
