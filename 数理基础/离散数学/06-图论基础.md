# 06-图论基础

图论（Graph Theory）研究由**顶点**和连接顶点的**边**构成的离散结构。它起源于 1736 年欧拉对哥尼斯堡七桥问题的研究，如今已成为计算机科学、网络分析等领域的基础工具。

---

## 1. 图的基本概念

### 1.1 无向图与有向图的定义

**定义（无向图）**：一个**无向图**（undirected graph）是一个有序二元组 $G = (V, E)$，其中：
- $V$ 是非空的**顶点集**（vertex set），元素称为顶点（vertex/node）
- $E$ 是**边集**（edge set），每条边是 $V$ 中的**无序对** $\{u, v\}$，其中 $u, v \in V$ 且通常 $u \neq v$

**定义（有向图）**：一个**有向图**（directed graph / digraph）是一个有序二元组 $G = (V, E)$，其中：
- $V$ 是非空的**顶点集**
- $E$ 是**弧集**（arc set），每条弧是 $V$ 中的**有序对** $(u, v)$，$u$ 称为起点（tail），$v$ 称为终点（head）

**图的阶（order）**：$|V|$，即顶点数，常用 $n$ 表示。
**图的规模（size）**：$|E|$，即边数，常用 $m$ 表示。

> **例 1**：$G = (V, E)$，$V = \{1, 2, 3, 4\}$，$E = \{\{1, 2\}, \{1, 3\}, \{2, 3\}, \{3, 4\}\}$。这是一个 4 阶 4 边的无向图。

> **例 2**：$D = (V, E)$，$V = \{1, 2, 3\}$，$E = \{(1, 2), (2, 3), (3, 1)\}$ 是一个有向图（形成有向三角形）。

### 1.2 邻接、关联、度

**邻接（adjacent）**：
- 无向图：若 $\{u, v\} \in E$，称 $u$ 与 $v$ **邻接**。
- 有向图：若 $(u, v) \in E$，称 $u$ **邻接到** $v$，$v$ 由 $u$ **邻接**。

**关联（incident）**：边 $\{u, v\}$ 与顶点 $u$ 和 $v$ **关联**。

**度（degree）**：
- 无向图：顶点 $v$ 的**度** $\deg(v)$ 是与 $v$ 关联的边数，自环计 2 次。
- 有向图：
  - **入度** $\deg^{-}(v)$：以 $v$ 为终点的弧数
  - **出度** $\deg^{+}(v)$：以 $v$ 为起点的弧数
  - $\deg(v) = \deg^{-}(v) + \deg^{+}(v)$

**孤立点**：度为 $0$ 的顶点。
**悬挂点**：度为 $1$ 的顶点。

### 1.3 握手定理

**定理（握手定理 / Handshaking Lemma）**：对任意无向图 $G = (V, E)$，

$$\sum_{v \in V} \deg(v) = 2|E|$$

**证明**：每条边 $\{u, v\}$ 在计算度数时被计数两次（一次给 $u$，一次给 $v$）。因此所有顶点的度数之和等于边数的两倍。

**推论**：任何无向图中，度数为奇数的顶点个数必为偶数。

**有向图的握手定理**：

$$\sum_{v \in V} \deg^{+}(v) = \sum_{v \in V} \deg^{-}(v) = |E|$$

> **例 3**：在一场聚会上，用顶点表示人，若两人握手则连边。则**握手次数为奇数的人数为偶数**。

> **例 4**：一个图中若所有顶点的度都相等（$k$-正则图），且 $\sum \deg(v) = 2|E| = nk$，则 $|E| = nk/2$。

### 1.4 图的同构

**定义**：图 $G = (V, E)$ 与 $H = (V', E')$ **同构**（isomorphic），记作 $G \cong H$，若存在双射 $f: V \to V'$ 使得：

$$\{u, v\} \in E \iff \{f(u), f(v)\} \in E'$$

即 $f$ 保留了邻接关系。

**判断同构的常用不变量**（必要条件）：
- 顶点数相同，边数相同
- 度序列相同（多重集意义上的相同）
- 相同长度的回路数目相同
- 连通分量数目相同

> **例 5**：以下两个图同构：$G$ 的顶点为 $\{1, 2, 3, 4\}$，边为 $\{12, 23, 34, 41\}$（四边形）；$H$ 的顶点为 $\{a, b, c, d\}$，边为 $\{ab, bc, cd, da\}$（也是四边形）。同构映射：$1 \to a, 2 \to b, 3 \to c, 4 \to d$。

## 2. 图的分类

### 2.1 简单图、多重图、完全图

**简单图**（simple graph）：无自环（loop）且任意两顶点之间至多一条边的无向图。

**多重图**（multigraph）：允许有多重边（两顶点间有不止一条边）的图。

**完全图 $K_n$**：$n$ 个顶点的简单图，任意两不同顶点之间都有一条边。

$$|E(K_n)| = \binom{n}{2} = \frac{n(n-1)}{2}$$

> **例 6**：$K_5$ 有 $5$ 个顶点，$\binom{5}{2} = 10$ 条边。

**竞赛图**：$K_n$ 的定向版本，将 $K_n$ 的每条边指定一个方向。

### 2.2 二部图（二分图）

**定义**：图 $G = (V, E)$ 是**二部图**（bipartite graph）若存在 $V$ 的一个划分 $V = X \cup Y$（$X \cap Y = \emptyset$）使得 $G$ 的每条边都连接 $X$ 中的一个顶点与 $Y$ 中的一个顶点。

**完全二部图 $K_{m,n}$**：$X$ 有 $m$ 个顶点，$Y$ 有 $n$ 个顶点，且 $X$ 中每个顶点与 $Y$ 中每个顶点都有一条边。

$$|E(K_{m,n})| = m \cdot n$$

**定理**：$G$ 是二部图 $\iff$ $G$ 中无奇数长度的回路。

> **例 7**：$K_{3,3}$ 有 $6$ 个顶点和 $9$ 条边。它是"煤窖-房屋-水"问题的图模型。

> **例 8**：树（tree）是二部图（所有树都可以二着色）。

### 2.3 正则图、补图

**$k$-正则图**（$k$-regular graph）：所有顶点的度都等于 $k$ 的简单图。

- $K_n$ 是 $(n-1)$-正则图
- Petersen 图是 $3$-正则图（是著名的反例来源）

**补图**（complement）：图 $G = (V, E)$ 的补图 $\overline{G} = (V, \overline{E})$，其中

$$\overline{E} = \{\{u, v\} \mid u, v \in V, u \neq v, \{u, v\} \notin E\}$$

> **例 9**：$K_n$ 的补图是 $n$ 个孤立点的空图 $\overline{K_n}$。

### 2.4 子图、生成子图、导出子图

**子图**（subgraph）：$H = (V_H, E_H)$ 是 $G = (V, E)$ 的子图若 $V_H \subseteq V$ 且 $E_H \subseteq E$。

**生成子图**（spanning subgraph）：$V_H = V$ 的子图（覆盖所有顶点）。

**导出子图**（induced subgraph）：由顶点子集 $S \subseteq V$ **导出**的子图 $G[S]$，包含 $S$ 中的所有顶点以及 $G$ 中**两端点都在 $S$ 中的所有边**。即

$$G[S] = (S, \{\{u, v\} \in E \mid u, v \in S\})$$

> **例 10**：在 $K_5$ 中，若 $S$ 是 3 个顶点，则 $G[S]$ 是 $K_3$（三角形），因为 $K_5$ 中这 3 个顶点间有所有可能的边。

## 3. 图的表示

### 3.1 邻接矩阵

**定义**：设 $G = (V, E)$ 的顶点集 $V = \{v_1, v_2, \dots, v_n\}$，则 $G$ 的**邻接矩阵** $A = (a_{ij})_{n \times n}$ 定义为：

$$a_{ij} = \begin{cases} 1, & \text{若 } \{v_i, v_j\} \in E \\ 0, & \text{否则} \end{cases}$$

（对于有向图：$a_{ij} = 1$ 若 $(v_i, v_j) \in E$）

**性质**：

1. 无向图的邻接矩阵是对称矩阵：$A^T = A$
2. 对角线元素 $a_{ii}$：无向图简单图中为 $0$（无自环）
3. 第 $i$ 行（或第 $i$ 列）的和 = $\deg(v_i)$（无向图）
4. **$A^k$ 的意义**：$(A^k)_{ij}$ = 从 $v_i$ 到 $v_j$ 的长度为 $k$ 的通路数

> **例 11**：三角形 $K_3$ 的邻接矩阵：
> $$A = \begin{pmatrix} 0 & 1 & 1 \\ 1 & 0 & 1 \\ 1 & 1 & 0 \end{pmatrix}$$

### 3.2 邻接表

**邻接表**（adjacency list）为每个顶点维护一个邻接顶点链表。对于稀疏图（$|E| \ll \binom{n}{2}$），邻接表比邻接矩阵更省空间。

> **例 12**：图 $G$ 的边集为 $\{\{1, 2\}, \{1, 3\}, \{2, 3\}, \{3, 4\}\}$，邻接表：
> - $1: 2, 3$
> - $2: 1, 3$
> - $3: 1, 2, 4$
> - $4: 3$

### 3.3 关联矩阵

**定义**：设 $G = (V, E)$，$V = \{v_1, \dots, v_n\}$，$E = \{e_1, \dots, e_m\}$，则 $G$ 的**关联矩阵** $B = (b_{ij})_{n \times m}$ 为：

$$b_{ij} = \begin{cases} 1, & \text{若 } v_i \text{ 与 } e_j \text{ 关联} \\ 0, & \text{否则} \end{cases}$$

对于有向图：$b_{ij} = 1$（$v_i$ 是 $e_j$ 的起点），$b_{ij} = -1$（$v_i$ 是 $e_j$ 的终点），$b_{ij} = 0$（不关联）。

## 4. 路径与连通性

### 4.1 通路与回路

**定义**：

- **通路**（walk / path）：顶点和边交替出现的序列 $v_0 e_1 v_1 e_2 v_2 \dots e_k v_k$，其中 $e_i$ 连接 $v_{i-1}$ 与 $v_i$。通路的**长度**为边数 $k$。
- **迹**（trail）：边不重复的通路。
- **路径**（path）：顶点不重复的通路（简单通路）。
- **回路**（circuit / cycle）：起点 = 终点的通路。长度为 $k$ 的回路称为 $k$-回路。

> **例 13**：在四边形 $C_4$ 中，$(v_1, v_2, v_3, v_4, v_1, v_2)$ 是通路但不是路径；$(v_1, v_2, v_3, v_4, v_1)$ 是回路（4-回路）。

**定理（$A^k$ 与通路数）**：在邻接矩阵 $A$ 中，$(A^k)_{ij}$ = 从 $v_i$ 到 $v_j$ 的长度为 $k$ 的通路数。

### 4.2 无向图的连通性

**定义**：无向图 $G$ 中，若存在从 $u$ 到 $v$ 的通路，则称 $u$ 与 $v$ **连通**（connected）。连通关系是顶点集上的一个等价关系。

**连通图**：若图中任意两顶点都连通，则称该图为**连通图**。

**连通分量**（connected component）：连通关系下的等价类，即极大连通子图。

> **例 14**：有 5 个孤立顶点的图的连通分量数为 5。

### 4.3 有向图的强连通与弱连通

**定义**：有向图 $D$ 中，

- 若存在从 $u$ 到 $v$ 的有向通路，称 $u$ 可到达 $v$。
- 若任意两顶点**双向可到达**，称 $D$ 是**强连通**（strongly connected）的。
- 若把 $D$ 中所有弧的方向忽略后得到的无向图是连通的，称 $D$ 是**弱连通**（weakly connected）的。

**强连通分量**（SCC）：极大强连通子图。

> **例 15**：有向三角形 $(1 \to 2, 2 \to 3, 3 \to 1)$ 是强连通的。$1 \to 2 \to 3$ 是弱连通但不是强连通（3 不能到达 1）。

### 4.4 割点与桥

**定义**：

- **割点**（cut vertex / articulation point）：删除该顶点（及其关联边）后连通分量数增加的顶点。
- **桥**（cut edge / bridge）：删除该边后连通分量数增加的边。

> **例 16**：在路径图 $P_4$ 中，中间两个顶点是割点，所有边都是桥。

**定理**：$e$ 是桥 $\iff$ $e$ 不在任何简单回路中。

### 4.5 点连通度与边连通度

**定义**：

- **点连通度** $\kappa(G)$：使 $G$ 不连通或成为平凡图所需删除的最少顶点数。
- **边连通度** $\lambda(G)$：使 $G$ 不连通所需删除的最少边数。
- **最小度** $\delta(G)$：$\min_{v \in V} \deg(v)$。

**惠特尼不等式（Whitney Inequality）**：

$$\kappa(G) \leq \lambda(G) \leq \delta(G)$$

> **例 17**：对于完全图 $K_n$：$\kappa(K_n) = \lambda(K_n) = \delta(K_n) = n-1$。

**$k$-连通图**：$\kappa(G) \geq k$ 的图，即删除任意 $k-1$ 个顶点后仍然连通。

## 5. 欧拉图与哈密顿图

### 5.1 欧拉通路与欧拉回路

**定义**：

- **欧拉通路**（Eulerian trail）：经过图中每条边**恰好一次**的通路。
- **欧拉回路**（Eulerian circuit）：经过图中每条边**恰好一次**的回路。
- **欧拉图**：存在欧拉回路的图。

**定理（欧拉回路存在条件）**：连通无向图 $G$ 存在欧拉回路 $\iff$ $G$ 中所有顶点的度均为**偶数**。

**证明（必要性）**：欧拉回路每经过一个顶点一次，就消耗该顶点的两条关联边（一条进入，一条离开）。因此每个顶点的度必须是偶数。

**定理（欧拉通路存在条件）**：连通无向图 $G$ 存在欧拉通路（但非欧拉回路）$\iff$ $G$ 中**恰有两个奇数度顶点**（这两个顶点为通路的起点和终点）。

**有向图的欧拉回路条件**：强连通有向图存在欧拉回路 $\iff$ 每个顶点的入度等于出度。

> **例 18（哥尼斯堡七桥）**：四个区域的度分别为 3, 3, 3, 5（全为奇数），因此不存在欧拉通路，更不存在欧拉回路。

> **例 19**：一笔画游戏——若图有 0 个或 2 个奇数度顶点则可一笔画出。

### 5.2 哈密顿通路与哈密顿回路

**定义**：

- **哈密顿通路**（Hamiltonian path）：经过图中每个顶点**恰好一次**的通路。
- **哈密顿回路**（Hamiltonian cycle）：经过图中每个顶点**恰好一次**的回路。
- **哈密顿图**：存在哈密顿回路的图。

**与欧拉图的区别**：欧拉关心**边**，哈密顿关心**顶点**。判断哈密顿性是一个 NP-完全问题。

**充分条件**：

**Dirac 定理**（1952）：若 $G$ 是 $n \geq 3$ 个顶点的简单图且 $\delta(G) \geq n/2$，则 $G$ 是哈密顿图。

**Ore 定理**（1960）：若 $G$ 是 $n \geq 3$ 个顶点的简单图，且对任意不相邻的 $u, v \in V$ 有 $\deg(u) + \deg(v) \geq n$，则 $G$ 是哈密顿图。

> **例 20**：$K_n$（$n \geq 3$）是哈密顿图（沿所有顶点走一圈即可）。

> **例 21**：Petersen 图（10 个顶点，3-正则）不是哈密顿图（尽管很多条件看起来不错，这是一个经典的极小反例）。

### 5.3 Fleury 算法求欧拉回路

**Fleury 算法**（用于求欧拉回路/通路）：

1. 检查图是否满足欧拉条件（所有度为偶数 + 连通）
2. 从合适起点开始（欧拉通路从奇数度顶点开始）
3. 每步选择一条边，**除非别无选择，否则不选桥（即割边）**
4. 删除已走过的边，继续在剩余子图中走

**为什么避免桥？** 若过早走过桥，会把剩余图分成多个连通分量，无法走完。

**算法复杂度**：$O(|E|^2)$（朴素实现），可优化至 $O(|E|)$。

> **例 22**：在包含两个奇数度顶点（1 和 5）的图中，从 1 开始按 Fleury 算法走，可得欧拉通路：$1 \to 2 \to 3 \to 4 \to 5 \to 3 \to 6 \to 1 \to 5$。

## 6. 图的矩阵表示与谱

### 6.1 邻接矩阵、度矩阵、拉普拉斯矩阵

设 $G = (V, E)$ 是 $n$ 个顶点的简单无向图，$A$ 为其邻接矩阵。

**度矩阵** $D$：$D = \text{diag}(\deg(v_1), \deg(v_2), \dots, \deg(v_n))$（对角矩阵，对角线元素为各顶点的度）。

**拉普拉斯矩阵（Laplacian）** $L$：

$$L = D - A$$

即

$$L_{ij} = \begin{cases} \deg(v_i), & i = j \\ -1, & i \neq j \text{ 且 } \{v_i, v_j\} \in E \\ 0, & \text{否则} \end{cases}$$

### 6.2 拉普拉斯矩阵的特征值与图的性质

**基本性质**：

1. $L$ 是对称半正定矩阵
2. $L$ 的最小特征值为 $0$，且其重数等于图的连通分量数
3. $L$ 的所有行和为 $0$，全 1 向量 $\vec{1}$ 是对应于特征值 $0$ 的特征向量
4. **代数连通度**：$L$ 的第二小特征值 $\lambda_2$（代数连通度 / Fiedler 特征值）度量了图的连通程度——$\lambda_2 > 0 \iff G$ 连通，$\lambda_2$ 越大，图"越连通"

**矩阵树定理（Kirchhoff）**：$G$ 的**生成树数目** = $L$ 的任意 $n-1$ 阶主子式的行列式值。

> **例 23**：$K_3$（三角形）的拉普拉斯矩阵：
> $$L = \begin{pmatrix} 2 & -1 & -1 \\ -1 & 2 & -1 \\ -1 & -1 & 2 \end{pmatrix}$$
> 特征值：$0, 3, 3$。第二小特征值 $\lambda_2 = 3$。

## 7. 平面图

### 7.1 平面图的定义

**定义**：一个图若能在平面上画出，使得**任意两条边只在顶点处相交**（没有边交叉），则称为**平面图**（planar graph）。这样的画法称为该图的**平面嵌入**（planar embedding）。

> **例 24**：$K_4$（4 个顶点的完全图）是平面图；$K_5$ 和 $K_{3,3}$ 不是平面图。

### 7.2 欧拉公式

**定理（欧拉公式）**：设 $G$ 是连通的平面图，有 $n$ 个顶点、$m$ 条边，且其平面嵌入将平面划分为 $f$ 个面（含外部的无限面），则

$$n - m + f = 2$$

**证明**（对边数 $m$ 归纳）：

- 基始：$m = 0$，$n = 1, f = 1$，$1 - 0 + 1 = 2$ ✓
- 归纳步：加一条边。
  - 若新边连接两个已有顶点，则 $m' = m+1, f' = f+1$（边将一个面一分为二），$n' = n$，$n' - m' + f' = n - (m+1) + (f+1) = n - m + f = 2$。
  - 若新边一端为新顶点，则 $n' = n+1, m' = m+1, f' = f$（新顶点在已有面上），同样保持平衡。

**推论**：
1. 对 $n \geq 3$ 的简单连通平面图：$m \leq 3n - 6$
2. 对 $n \geq 3$ 且无三角形的简单连通平面图：$m \leq 2n - 4$
3. $K_5$ 不满足 $m \leq 3n-6$（$10 \not\leq 9$），故 $K_5$ 非平面图
4. $K_{3,3}$ 不满足 $m \leq 2n-4$（$9 \not\leq 8$），故 $K_{3,3}$ 非平面图

### 7.3 Kuratowski 定理

**定义**：**边初等细分**（elementary subdivision）——在一条边上插入一个度为 2 的新顶点，或反之删除一个度为 2 的顶点并连接其两个邻点。两个图**同胚**（homeomorphic）若它们可以通过有限次初等细分变为同构的图。

**定理（Kuratowski, 1930）**：一个图是平面图 $\iff$ 它不包含与 $K_5$ 或 $K_{3,3}$ **同胚**的子图。

等价地：一个图是平面图 $\iff$ 它不以 $K_5$ 或 $K_{3,3}$ 为**子式**（minor）。

> **例 25**：Petersen 图不是平面图（它包含 $K_5$ 的一个细分）。

## 8. 图的着色

### 8.1 顶点着色与色数

**定义**：图 $G$ 的一个**正常 $k$-着色**（proper $k$-coloring）是一个函数 $c: V \to \{1, 2, \dots, k\}$，使得相邻顶点的颜色不同：$\{u, v\} \in E \Rightarrow c(u) \neq c(v)$。

**色数（chromatic number）$\chi(G)$**：使 $G$ 可正常着色的最小颜色数 $k$。

> **例 26**：
> - $\chi(K_n) = n$（每个顶点颜色必须不同）
> - $\chi(\text{二部图}) = 2$（除非无边，则为 1）
> - $\chi(\text{偶回路 } C_{2k}) = 2$，$\chi(\text{奇回路 } C_{2k+1}) = 3$

**基本界**：
- $\chi(G) \geq \omega(G)$（团数，即最大完全子图的阶）
- $\chi(G) \leq \Delta(G) + 1$（Brooks 定理给出了更紧的界）
- 平面图的色数 $\leq 4$（四色定理）

### 8.2 四色定理

**定理（四色定理 / Four Color Theorem）**：任何平面图的色数不超过 4。

等价表述：任何地图（平面嵌入的平面图）用 4 种颜色即可正常着色。

**历史意义**：这是第一个主要依靠计算机辅助证明的数学定理（Appel 和 Haken, 1976）。

> **例 27**：实际中有一些平面图确实需要 4 种颜色（如 $K_4$ 本身），所以 4 色定理是最优的。

### 8.3 贪心着色算法

**贪心着色**（Greedy Coloring）：按某个顺序遍历所有顶点，给每个顶点分配当前已遍历的邻点中未使用的最小颜色编号。

```cpp
vector<int> greedyColoring(vector<vector<int>>& adj, vector<int>& order) {
    int n = adj.size();
    vector<int> color(n, -1);
    for (int u : order) {
        vector<bool> used(n, false);
        for (int v : adj[u])
            if (color[v] != -1)
                used[color[v]] = true;
        int c = 0;
        while (used[c]) c++;
        color[u] = c;
    }
    return color;
}
```

**性质**：贪心着色使用的颜色数 ≤ $\Delta(G) + 1$（最大度 + 1）。

**注**：着色效果高度依赖于顶点遍历顺序。存在某种顺序使贪心着色达到最优（完美消去序适用于弦图）。

### 9.2 连通性检查（DFS/BFS）（Python）

```python
from collections import deque, defaultdict

def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    visited.add(start)
    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
    return visited

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    while queue:
        u = queue.popleft()
        for v in graph[u]:
            if v not in visited:
                visited.add(v)
                queue.append(v)
    return visited

def connected_components(graph, n):
    visited = set()
    components = []
    for v in range(n):
        if v not in visited:
            comp = bfs(graph, v)
            visited.update(comp)
            components.append(comp)
    return components
```

### 9.3 欧拉回路的 Fleury 算法（Python）

```python
def is_bridge(adj, u, v, edge_count):
    """Check if edge (u,v) is a bridge in the current graph"""
    if edge_count[u][v] > 1:
        return False

    # Count vertices reachable from u without using edge (u,v)
    visited = set()
    def dfs_count(x):
        visited.add(x)
        for w in adj[x]:
            if edge_count[x].get(w, 0) > 0 and w not in visited:
                dfs_count(w)

    # Temporarily remove the edge
    edge_count[u][v] -= 1
    edge_count[v][u] -= 1

    dfs_count(u)
    reachable_count = len(visited)

    # Restore
    edge_count[u][v] += 1
    edge_count[v][u] += 1

    # Count reachable from u with edge present
    visited_all = set()
    def dfs_all(x):
        visited_all.add(x)
        for w in adj[x]:
            if edge_count[x].get(w, 0) > 0 and w not in visited_all:
                dfs_all(x)
    dfs_all(u)

    return reachable_count < len(visited_all)


def fleury(adj, n):
    """Fleury's algorithm for Eulerian circuit/path"""
    # Build edge count (for multigraph support)
    edge_count = [{} for _ in range(n)]
    for u in range(n):
        for v in adj[u]:
            edge_count[u][v] = edge_count[u].get(v, 0) + 1

    # Find start vertex
    start = 0
    odd_vertices = [v for v in range(n) if len(adj[v]) % 2 == 1]
    if len(odd_vertices) not in (0, 2):
        return None  # No Eulerian path
    if len(odd_vertices) == 2:
        start = odd_vertices[0]

    path = [start]
    current = start
    while any(edge_count[current]):
        # Choose next edge
        for v in adj[current]:
            if edge_count[current].get(v, 0) > 0:
                if not is_bridge(adj, current, v, edge_count) or \
                   all(edge_count[current].get(w, 0) <= 0 for w in adj[current] if w != v):
                    path.append(v)
                    edge_count[current][v] -= 1
                    edge_count[v][current] -= 1
                    current = v
                    break
        else:
            break

    return path


# 测试：三角形 + 悬挂边
adj = {
    0: [1, 2], 1: [0, 2, 3], 2: [0, 1],
    3: [1, 4], 4: [3]
}
path = fleury(adj, 5)
print("Eulerian path:", path)
```

### 9.5 强连通分量 Kosaraju 算法（Python）

```python
def kosaraju(adj, n):
    """Find strongly connected components"""
    # First DFS pass to get finishing order
    visited = [False] * n
    order = []

    def dfs1(u):
        visited[u] = True
        for v in adj[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)

    for u in range(n):
        if not visited[u]:
            dfs1(u)

    # Reverse graph
    rev_adj = [[] for _ in range(n)]
    for u in range(n):
        for v in adj[u]:
            rev_adj[v].append(u)

    # Second DFS pass in reverse finishing order
    visited = [False] * n
    sccs = []

    def dfs2(u, comp):
        visited[u] = True
        comp.append(u)
        for v in rev_adj[u]:
            if not visited[v]:
                dfs2(v, comp)

    for u in reversed(order):
        if not visited[u]:
            comp = []
            dfs2(u, comp)
            sccs.append(comp)

    return sccs


# 示例
adj = [
    [1],       # 0 -> 1
    [2],       # 1 -> 2
    [0, 3],    # 2 -> 0, 3
    [4],       # 3 -> 4
    [5],       # 4 -> 5
    [3]        # 5 -> 3
]
sccs = kosaraju(adj, 6)
print("Strongly Connected Components:", sccs)
```
