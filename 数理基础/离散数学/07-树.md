# 第07章：树 (Tree)

> 树是无向图中最重要的一类——它是最"薄"的连通图,也是图论中应用最广泛的结构之一。

---

## 7.1 树的基本概念

### 7.1.1 树的定义

**定义7.1（树）**：一个**无回路的连通无向图**称为**树(Tree)**，通常记作 $T$。

$$
\boxed{\text{树} \;=\; \text{连通} \;+\; \text{无回路}}
$$

- 树的边数恰好比顶点数少 $1$。
- 树是极小连通图：删去任意一条边，图就不再连通。
- 树是极大无回路图：添加任意一条边，图就产生回路。

**例子**：
- $n=1$ 的平凡树：只有一个顶点，没有边。
- $n=2$ 的树：两个顶点由一条边相连。
- $n=3$ 的树只有一种形状（一条路 $P_3$）。
- $n=4$ 的树有两种非同构形状：路 $P_4$ 和星 $K_{1,3}$。

### 7.1.2 树的等价定义

以下是树的**六个等价条件**，设 $T$ 是 $n$ 阶无向简单图（$n \geq 1$）：

> **定理7.1（树的等价刻画）**：以下命题等价：

| 编号 | 条件 |
|:---:|------|
| (1) | $T$ 连通且无回路（树的原始定义） |
| (2) | $T$ 无回路且有 $n-1$ 条边 |
| (3) | $T$ 连通且有 $n-1$ 条边 |
| (4) | $T$ 连通，但删去任一边后不再连通（极小连通图） |
| (5) | $T$ 无回路，但添加任一边后恰有一个回路（极大无回路图） |
| (6) | $T$ 中任意两顶点间有唯一简单路径 |

---

**证明（等价性）**：

**策略**：我们证明 $(1)\Rightarrow(2)\Rightarrow(3)\Rightarrow(4)\Rightarrow(5)\Rightarrow(6)\Rightarrow(1)$。

---

**$(1)\Rightarrow(2)$**：$T$ 连通无回路 $\Rightarrow$ $T$ 无回路且有 $n-1$ 条边。

对 $n$ 归纳。
- $n=1$：无回路，边数为 $0 = 1-1$，成立。
- 假设对少于 $n$ 个顶点的树成立。在 $T$ 中任取一边 $e=(u,v)$，由 $T$ 无回路，删去 $e$ 后图分为两个连通分支 $T_1$ 和 $T_2$（因为 $T$ 连通且无回路意味着 $e$ 是割边）。设 $T_1$ 有 $n_1$ 个顶点，$T_2$ 有 $n_2$ 个顶点，$n_1+n_2=n$。$T_1$ 和 $T_2$ 均连通无回路，由归纳假设，边数分别为 $n_1-1$ 和 $n_2-1$。所以 $T$ 的边数为：

$$m = (n_1-1)+(n_2-1)+1 = n_1+n_2-1 = n-1$$

---

**$(2)\Rightarrow(3)$**：$T$ 无回路且有 $n-1$ 条边 $\Rightarrow$ $T$ 连通且有 $n-1$ 条边。

设 $T$ 有 $c$ 个连通分支 $T_1,T_2,\dots,T_c$，每个分支作为无向图无回路（即其本身就是树）。设第 $i$ 个分支有 $n_i$ 个顶点，则由 $(1)\Rightarrow(2)$ 的结论，$T_i$ 有 $n_i-1$ 条边。于是：

$$m = \sum_{i=1}^c (n_i-1) = n - c$$

已知 $m=n-1$，所以 $n-1 = n-c$，得 $c=1$，即 $T$ 连通。

---

**$(3)\Rightarrow(4)$**：$T$ 连通且有 $n-1$ 条边 $\Rightarrow$ $T$ 极小连通。

设 $T$ 连通且有 $n-1$ 条边。任删一边 $e$，得图 $T'=T-e$，顶点数仍为 $n$，边数变为 $n-2$。由连通图的边数下界（连通 $n$ 阶图至少 $n-1$ 条边），$T'$ 不可能连通。故 $T$ 是极小连通图。

---

**$(4)\Rightarrow(5)$**：$T$ 极小连通 $\Rightarrow$ $T$ 无回路且极大无回路。

先证无回路：若 $T$ 有回路 $C$，删去 $C$ 上任一边 $e$，$T-e$ 仍连通，与极小连通矛盾。

再证极大无回路：$T$ 已证无回路。任加一边 $e=(u,v)$（$e\notin E(T)$）。由于 $T$ 连通，$u$ 和 $v$ 间已有路径 $P$，$P\cup\{e\}$ 形成回路。若有两个不同回路，则 $T$ 中已有回路（两个回路合并再删去 $e$ 产生回路），矛盾。故恰有一个回路。

---

**$(5)\Rightarrow(6)$**：$T$ 无回路且极大 $\Rightarrow$ 任意两点间有唯一简单路径。

先证连通性：若 $T$ 不连通，则存在分属不同连通分支的顶点 $u,v$，添加边 $(u,v)$ 不会产生回路（因为 $u,v$ 间原本无路径），矛盾。故 $T$ 连通。

再证唯一性：$T$ 连通保证了任意两点间至少一条路径。若有两条不同路径，则它们的对称差含有回路（取两条路径的第一个分叉点和第一个汇合点构成回路），与无回路矛盾。故路径唯一。

---

**$(6)\Rightarrow(1)$**：任意两点间有唯一路径 $\Rightarrow$ 连通无回路。

连通性显然（有路径即连通）。无回路：若存在回路 $C$，则 $C$ 上任意相邻两顶点间的边和回路其余部分给出两条不同路径，矛盾。

$\blacksquare$

---

### 7.1.3 森林

**定义7.2（森林）**：一个无回路（但可以不连通）的无向图称为**森林(Forest)**。

- 森林的每个连通分支都是树。
- 若森林有 $n$ 个顶点、$c$ 个连通分支，则边数 $m = n - c$。

### 7.1.4 树叶与生成树

**定义7.3（树叶与分支结点）**：
- 树中度数为 $1$ 的顶点称为**树叶(Leaf)**。
- 树中度数 $\geq 2$ 的顶点称为**分支结点(Branch Node/Internal Node)**。

**定理7.2**：任何非平凡的树（$n\geq 2$）至少有 $2$ 片树叶。

**证明**：设树 $T$ 有 $n$ 个顶点，$m=n-1$ 条边。设树叶数为 $k$，非树叶数为 $n-k$。由握手定理：

$$2m = \sum_{v\in V} \deg(v) \geq k \cdot 1 + (n-k) \cdot 2 = 2n - k$$

代入 $m=n-1$：

$$2(n-1) \geq 2n-k \;\Rightarrow\; 2n-2 \geq 2n-k \;\Rightarrow\; k \geq 2$$

$\blacksquare$

## 7.2 生成树

### 7.2.1 定义与存在性

**定义7.4（生成树）**：设 $G$ 是连通无向图。$G$ 的一个**生成树(Spanning Tree)**是 $G$ 的一个生成子图 $T$，且 $T$ 是树。

**等价说法**：从 $G$ 中删去一些边，使得剩下的图连通且无回路。

**定理7.3（存在性）**：每个连通无向图至少有一棵生成树。

**证明（构造性）**：
- **破圈法**：若 $G$ 无回路，则 $G$ 本身是树。否则找到任意一个回路，删去回路中的一条边。重复此过程直到图中无回路。由于每次删边不破坏连通性且减少回路数，有限步后终止，得到生成树。
- **避圈法**：从空边集开始，每次选取一条不产生回路的新边加入，直到选满 $n-1$ 条边。

$\blacksquare$

---

### 7.2.2 最小生成树 (MST)

**定义7.5（最小生成树）**：给定连通带权无向图 $G=(V,E,w)$，其中 $w: E \to \mathbb{R}^+$，$G$ 的**最小生成树(Minimum Spanning Tree, MST)**是 $G$ 的一棵生成树 $T$，使得总权值

$$w(T)=\sum_{e\in E(T)} w(e)$$

在所有生成树中最小。

#### Prim算法

**核心思想**：从任意一个顶点出发，每次选择**当前已选顶点集与未选顶点集之间权值最小的边**，将对应顶点加入已选集合，直到所有顶点都被选入。

**算法描述**：

```
输入：连通带权图 G=(V,E,w)，|V|=n
输出：最小生成树 T

1. 任选起点 v0 ∈ V
2. S = {v0}，T = ∅
3. 重复 n-1 次：
   a. 在所有跨 S 和 V\S 的边中，选权值最小的边 e=(u,v)，其中 u∈S, v∈V\S
   b. T = T ∪ {e}
   c. S = S ∪ {v}
4. 返回 T
```

**复杂度分析**：
- 朴素实现（邻接矩阵）：每次找最小边扫描 $O(n^2)$，总复杂度 $O(n^2)$，适合稠密图。
- 二叉堆优化：使用优先队列维护跨割边，总复杂度 $O(m\log n)=O(m\log m)$，适合稀疏图。
- Fibonacci堆优化：可达 $O(m + n\log n)$。

#### Kruskal算法

**核心思想**：按边权从小到大排序，依次考虑每条边：若该边连接的两个顶点当前属于不同的连通分量，则选取该边，否则跳过。用并查集(Union-Find)维护连通分量。

**算法描述**：

```
输入：连通带权图 G=(V,E,w)，|V|=n, |E|=m
输出：最小生成树 T

1. 将所有边按权值从小到大排序
2. T = ∅
3. 初始化并查集：每个顶点自成一个集合
4. 按排序顺序遍历每条边 e=(u,v)：
   a. 若 find(u) ≠ find(v)（u,v 不在同一集合）：
       T = T ∪ {e}
       union(u, v)
   b. 若 |T| = n-1，停止
5. 返回 T
```

**复杂度分析**：
- 排序：$O(m\log m) = O(m\log n)$。
- 并查集操作：$O(m \cdot \alpha(n))$，其中 $\alpha(n)$ 是Ackermann函数的反函数，约等于常数。
- 总复杂度：$O(m\log m)$，适合稀疏图。

### 7.2.3 生成树的计数：Cayley定理

**定理7.4（Cayley定理）**：$n$ 个标号顶点的完全图 $K_n$ 中，不同生成树的个数为：

$$\boxed{T(n) = n^{n-2}}$$

> 换句话说，$n$ 个不同标号的顶点能构成的不同树（不是同构类）的个数为 $n^{n-2}$。

**例子**：
- $n=1$：$1^{-1}=1$
- $n=2$：$2^0=1$
- $n=3$：$3^1=3$（三顶点完全图的三条边各可生成一棵树）
- $n=4$：$4^2=16$

**Prufer编码**（证明Cayley定理的工具）：
1. 从标号树构造Prufer序列：重复"找标号最小的树叶，记录其父结点，删去该树叶"直到剩下2个顶点。得到长度为 $n-2$ 的序列。
2. 从Prufer序列构造标号树：逆向操作。
3. Prufer序列与标号树一一对应，而Prufer序列的每一位可取 $1$ 到 $n$ 的任意值，故有 $n^{n-2}$ 种不同序列。

## 7.3 有根树

### 7.3.1 基本定义

**定义7.6（有根树）**：选定树的一个顶点作为**根(Root)**，并规定所有边的方向为远离根的方向，得到的**有向树**称为**有根树(Rooted Tree)**。

- 在画法上，根画在最上方，边朝下。
- 顶点 $v$ 的**层数**或**深度**是从根到 $v$ 的唯一路径长度（边数）。
- 树的高度是最大层数。

### 7.3.2 家谱术语

| 术语 | 英文 | 含义 |
|:---|:---|:---|
| 父结点 | Parent | $v$ 的上层邻接顶点 |
| 子结点 | Child | $v$ 的下层邻接顶点 |
| 兄弟 | Sibling | 同父结点下的子结点 |
| 祖先 | Ancestor | 从根到某顶点的路径上的所有顶点（含自身） |
| 后代 | Descendant | 以某顶点为根的子树中的所有顶点 |
| 子树 | Subtree | 以某顶点及其所有后代构成的子图 |
| 树叶 | Leaf | 无子结点的顶点 |

### 7.3.3 m叉树

**定义7.7（m叉树）**：有根树中，每个顶点最多有 $m$ 个子结点的称为 $m$ 叉树 ($m$-ary Tree)。

- **正则 $m$ 叉树** (Regular $m$-ary Tree)：每个分支结点恰好有 $m$ 个子结点。
- **完全 $m$ 叉树** (Full/Complete $m$-ary Tree)：树叶都在同一层，且每个内结点恰有 $m$ 个子结点。

**定理7.5**：正则 $m$ 叉树中，设 $i$ 为分支结点数，$l$ 为树叶数，则

$$l = (m-1)i + 1$$

**证明**：顶点总数 $n = i+l$，边数 $m_{边}=n-1$。每个分支结点出度 $m$，树叶出度0，边数也等于 $m\cdot i$。故：

$$m\cdot i = n-1 = (i+l)-1 = i+l-1$$

$$m\cdot i = i+l-1 \;\Rightarrow\; (m-1)i = l-1 \;\Rightarrow\; l = (m-1)i+1$$

$\blacksquare$

## 7.4 二叉树

### 7.4.1 定义与区分

**定义7.8（二叉树）**：一棵二叉树是有限个顶点的集合，它或者为空，或者由一个根顶点和两棵互不相交的、分别称为**左子树**和**右子树**的二叉树组成。

> **关键区别**：二叉树不是 $m=2$ 的普通2叉树。在二叉树的定义中：
> - 二叉树的子树有**左右之分**（即使一个子树为空）。
> - 普通的有根树中，子结点是无序的。
> - 在二叉树中，只有一个子结点时，也需区分是左子还是右子。

因此，三棵不同形态的二叉树可能对应于同一棵普通有根树。

### 7.4.2 满二叉树与完全二叉树

**定义7.9（满二叉树）**：深度为 $k$ 且含有 $2^k-1$ 个结点的二叉树称为**满二叉树(Full Binary Tree)**。

**定义7.10（完全二叉树）**：深度为 $k$ 且有 $n$ 个结点的二叉树，当且仅当其每个结点都与深度为 $k$ 的满二叉树中**编号从1到 $n$** 的结点一一对应时，称为**完全二叉树(Complete Binary Tree)**。

> 即：完全二叉树是"按层序依次填满"的二叉树，最后一层可以不满，但必须靠左排列。

### 7.4.3 二叉树的基本性质

**性质7.1**：二叉树第 $i$ 层（$i\geq 1$）最多有 $2^{i-1}$ 个结点。

**证明**（归纳法）：
- $i=1$：第1层只有根，$1=2^0$。
- 假设第 $i$ 层最多 $2^{i-1}$ 个结点。每个结点最多2个子结点，故第 $i+1$ 层最多 $2\times 2^{i-1}=2^i$ 个结点。

$\blacksquare$

---

**性质7.2**：深度为 $k$ 的二叉树最多有 $2^k-1$ 个结点。

**证明**：最大总结点数 $= \sum_{i=1}^{k}2^{i-1}=2^k-1$。

$\blacksquare$

---

**性质7.3**：对任意二叉树，若度为2的结点个数为 $n_2$，树叶个数为 $n_0$，则

$$\boxed{n_0 = n_2 + 1}$$

**证明**：设有 $n$ 个结点，$m$ 条边，$n_1$ 个度为1的结点。则：

$$n = n_0 + n_1 + n_2$$

所有结点度数之和等于边数的2倍：

$$n_1 + 2n_2 = 2m$$

在树中，$m=n-1$。代入得：

$$n_1 + 2n_2 = 2(n_0 + n_1 + n_2 - 1)$$

$$n_1 + 2n_2 = 2n_0 + 2n_1 + 2n_2 - 2$$

$$0 = 2n_0 + n_1 - 2$$

$$2n_0 = 2 - n_1 \leq 2$$

更精确的等价推导（利用 $n = m+1$，$m = n_1 + 2n_2$）：

$$n_0 + n_1 + n_2 = (n_1 + 2n_2) + 1$$

$$n_0 = n_2 + 1$$

$\blacksquare$

---

### 7.4.4 二叉树的遍历

遍历二叉树是按某种搜索路径访问每个结点，且每个结点恰好访问一次。

#### 三种深度优先遍历

| 遍历方式 | 缩写 | 次序 | 递归定义 |
|:---|:---:|:---|:---|
| 前序遍历 | DLR | 根→左→右 | 访问根；前序遍历左子树；前序遍历右子树 |
| 中序遍历 | LDR | 左→根→右 | 中序遍历左子树；访问根；中序遍历右子树 |
| 后序遍历 | LRD | 左→右→根 | 后序遍历左子树；后序遍历右子树；访问根 |

**例子**：以下二叉树（表达式树形式）：

```
        +
       / \
      *   -
     / \   \
    a   b   c
```

- **前序**：`+ * a b - c`（前缀波兰表示法）
- **中序**：`a * b + c -`（中缀表示，需加括号才是 `a*b + (-c)`）
- **后序**：`a b * c - +`（后缀逆波兰表示法）

### 7.4.5 由遍历序列重建二叉树

**定理7.6**：
- **前序序列 + 中序序列** 可以唯一确定一棵二叉树。
- **后序序列 + 中序序列** 可以唯一确定一棵二叉树。
- 仅有前序和后序无法唯一确定二叉树。

**重建算法（前序+中序）**：
1. 前序序列的第一个元素是根。
2. 在中序序列中找到根的位置，将中序序列划分为左子树和右子树的中序序列。
3. 用左子树的大小对应分割前序序列。
4. 递归对左右子树执行相同操作。

## 7.5 最优树与哈夫曼编码

### 7.5.1 哈夫曼树 (Huffman Tree)

**定义7.11（带权路径长度）**：设二叉树有 $n$ 个带权树叶，权值分别为 $w_1,w_2,\dots,w_n$，树叶的路径长度（从根到树叶的边数）为 $l_1,l_2,\dots,l_n$。则二叉树的**带权路径长度(WPL)**定义为：

$$\boxed{\text{WPL} = \sum_{i=1}^{n} w_i \cdot l_i}$$

**定义7.12（最优二叉树 / 哈夫曼树）**：给定一组权值，使得WPL最小的二叉树称为**最优二叉树**或**哈夫曼树(Huffman Tree)**。

### 7.5.2 哈夫曼算法

**输入**：$n$ 个权值 $w_1,w_2,\dots,w_n$

**输出**：一棵哈夫曼树

**算法步骤**：

1. 构造 $n$ 棵单结点二叉树（每个结点携带一个权值），放入集合 $F$。
2. 重复 $n-1$ 次：
   a. 从 $F$ 中取出两棵根权值最小的树作为左右子树。
   b. 构造一棵新二叉树，新树的根权值为左右子树根权值之和。
   c. 将新树加入 $F$。
3. $F$ 中只剩一棵树，即为哈夫曼树。

**复杂度**：使用最小堆（优先队列），总复杂度 $O(n\log n)$。

**例子**：给定权值 $\{5,9,12,13,16,45\}$，构造哈夫曼树。

```
步骤1: 取出5和9 → 合并为14
步骤2: 取出12和13 → 合并为25
步骤3: 取出14和16 → 合并为30
步骤4: 取出25和30 → 合并为55
步骤5: 取出45和55 → 合并为100

最终WPL = 5×4 + 9×4 + 12×3 + 13×3 + 16×3 + 45×1 = 20+36+36+39+48+45 = 224
```

### 7.5.3 哈夫曼编码

**定义7.13（前缀码）**：一个编码集合，其中没有任何一个编码是另一个编码的前缀。

**最优前缀码**：对于给定的字符频率，哈夫曼树给出的编码是**最优前缀码**（平均码长最短）。

**构造方法**：
1. 以字符频率为权值构建哈夫曼树。
2. 在哈夫曼树上，左分支标记为 `0`，右分支标记为 `1`。
3. 每个字符的编码为从根到该字符树叶的路径标记序列。

## 7.6 树的应用

### 7.6.1 二叉搜索树 (BST)

**定义7.14**：二叉搜索树是一棵二叉树，且对每个结点 $x$：
- 左子树中所有结点的值 $<$ $x$ 的值。
- 右子树中所有结点的值 $>$ $x$ 的值。

支持高效查找、插入、删除，平均时间复杂度 $O(\log n)$。

### 7.6.2 决策树

在比较排序中，排序 $n$ 个元素的任何基于比较的算法可以建模为二叉树（决策树），每个内结点表示一次比较，树叶表示一种可能的排序结果。由此可证明基于比较的排序下界为 $\Omega(n\log n)$。

### 7.6.3 表达式树

算术表达式可表示为二叉树：
- 运算符存储在内结点。
- 操作数存储在树叶。
- 三种遍历对应三种表达式表示法：

| 遍历 | 表示法 | 例子 |
|:---|:---|:---|
| 前序 (DLR) | 前缀表示（波兰式） | $+ * a\;b - c$ |
| 中序 (LDR) | 中缀表示 | $(a*b)+(c-)$ |
| 后序 (LRD) | 后缀表示（逆波兰式） | $a\;b\;*\;c\;-\;+$ |

后缀表达式特别适合计算机求值（用栈即可，无需括号和优先级）。

```cpp
#include <iostream>
#include <stack>
#include <queue>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

// ── 递归遍历 ──

void preorderRec(TreeNode* root) {
    if (!root) return;
    cout << root->val << " ";
    preorderRec(root->left);
    preorderRec(root->right);
}

void inorderRec(TreeNode* root) {
    if (!root) return;
    inorderRec(root->left);
    cout << root->val << " ";
    inorderRec(root->right);
}

void postorderRec(TreeNode* root) {
    if (!root) return;
    postorderRec(root->left);
    postorderRec(root->right);
    cout << root->val << " ";
}

// ── 非递归遍历 ──

void preorderIter(TreeNode* root) {
    if (!root) return;
    stack<TreeNode*> st;
    st.push(root);
    while (!st.empty()) {
        TreeNode* p = st.top(); st.pop();
        cout << p->val << " ";
        if (p->right) st.push(p->right);  // 先右后左
        if (p->left)  st.push(p->left);
    }
}

void inorderIter(TreeNode* root) {
    stack<TreeNode*> st;
    TreeNode* p = root;
    while (p || !st.empty()) {
        while (p) {
            st.push(p);
            p = p->left;
        }
        p = st.top(); st.pop();
        cout << p->val << " ";
        p = p->right;
    }
}

void postorderIter(TreeNode* root) {
    if (!root) return;
    stack<TreeNode*> st1, st2;
    st1.push(root);
    while (!st1.empty()) {
        TreeNode* p = st1.top(); st1.pop();
        st2.push(p);
        if (p->left)  st1.push(p->left);
        if (p->right) st1.push(p->right);
    }
    while (!st2.empty()) {
        cout << st2.top()->val << " ";
        st2.pop();
    }
}

// ── 层序遍历 ──

void levelOrder(TreeNode* root) {
    if (!root) return;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        TreeNode* p = q.front(); q.pop();
        cout << p->val << " ";
        if (p->left)  q.push(p->left);
        if (p->right) q.push(p->right);
    }
}
```

#### Python 实现

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import Optional, List
from collections import deque

@dataclass
class TreeNode:
    val: int
    left: Optional[TreeNode] = None
    right: Optional[TreeNode] = None


# ── 递归遍历 ──

def preorder_rec(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    return [root.val] + preorder_rec(root.left) + preorder_rec(root.right)

def inorder_rec(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    return inorder_rec(root.left) + [root.val] + inorder_rec(root.right)

def postorder_rec(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    return postorder_rec(root.left) + postorder_rec(root.right) + [root.val]


# ── 非递归遍历 ──

def preorder_iter(root: Optional[TreeNode]) -> List[int]:
    res, stack = [], [root] if root else []
    while stack:
        p = stack.pop()
        res.append(p.val)
        if p.right:
            stack.append(p.right)
        if p.left:
            stack.append(p.left)
    return res

def inorder_iter(root: Optional[TreeNode]) -> List[int]:
    res, stack = [], []
    p = root
    while p or stack:
        while p:
            stack.append(p)
            p = p.left
        p = stack.pop()
        res.append(p.val)
        p = p.right
    return res

def postorder_iter(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    res, st1, st2 = [], [root], []
    while st1:
        p = st1.pop()
        st2.append(p)
        if p.left:
            st1.append(p.left)
        if p.right:
            st1.append(p.right)
    while st2:
        res.append(st2.pop().val)
    return res


# ── 层序遍历 ──

def level_order(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        p = q.popleft()
        res.append(p.val)
        if p.left:
            q.append(p.left)
        if p.right:
            q.append(p.right)
    return res
```

### 7.7.2 哈夫曼树构建与编码

#### C++ 实现

```cpp
#include <iostream>
#include <queue>
#include <unordered_map>
#include <vector>
#include <string>
using namespace std;

struct HuffNode {
    char ch;
    int freq;
    HuffNode *left, *right;
    HuffNode(char c, int f) : ch(c), freq(f), left(nullptr), right(nullptr) {}
};

struct Compare {
    bool operator()(HuffNode* a, HuffNode* b) {
        return a->freq > b->freq; // 最小堆
    }
};

void encode(HuffNode* root, string code,
            unordered_map<char, string>& huffCode) {
    if (!root) return;
    if (!root->left && !root->right) { // 树叶
        huffCode[root->ch] = code;
    }
    encode(root->left,  code + "0", huffCode);
    encode(root->right, code + "1", huffCode);
}

HuffNode* buildHuffman(const unordered_map<char, int>& freqMap) {
    priority_queue<HuffNode*, vector<HuffNode*>, Compare> pq;
    for (auto& [ch, f] : freqMap) {
        pq.push(new HuffNode(ch, f));
    }
    while (pq.size() > 1) {
        HuffNode* left = pq.top(); pq.pop();
        HuffNode* right = pq.top(); pq.pop();
        HuffNode* parent = new HuffNode('\0', left->freq + right->freq);
        parent->left = left;
        parent->right = right;
        pq.push(parent);
    }
    return pq.top();
}

// 使用示例
int main() {
    unordered_map<char, int> freq = {
        {'a', 5}, {'b', 9}, {'c', 12}, {'d', 13}, {'e', 16}, {'f', 45}
    };
    HuffNode* root = buildHuffman(freq);
    unordered_map<char, string> huffCode;
    encode(root, "", huffCode);
    for (auto& [ch, code] : huffCode) {
        cout << ch << " : " << code << endl;
    }
    return 0;
}
```

#### Python 实现

```python
import heapq
from typing import Dict, Optional


class HuffNode:
    def __init__(self, ch: str, freq: int):
        self.ch = ch
        self.freq = freq
        self.left: Optional[HuffNode] = None
        self.right: Optional[HuffNode] = None

    def __lt__(self, other):
        return self.freq < other.freq


def build_huffman(freq_map: Dict[str, int]) -> HuffNode:
    heap = [HuffNode(ch, f) for ch, f in freq_map.items()]
    heapq.heapify(heap)

    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        parent = HuffNode('', left.freq + right.freq)
        parent.left = left
        parent.right = right
        heapq.heappush(heap, parent)

    return heap[0]


def encode(root: HuffNode, code: str, huff_code: Dict[str, str]):
    if not root:
        return
    if not root.left and not root.right:
        huff_code[root.ch] = code
        return
    encode(root.left,  code + '0', huff_code)
    encode(root.right, code + '1', huff_code)


# 使用示例
freq_map = {'a': 5, 'b': 9, 'c': 12, 'd': 13, 'e': 16, 'f': 45}
root = build_huffman(freq_map)
huff_code = {}
encode(root, '', huff_code)
for ch, code in huff_code.items():
    print(f"{ch} : {code}")
```

### 7.7.3 Prim和Kruskal算法

#### C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

const int INF = 0x3f3f3f3f;

// ── Prim算法（邻接矩阵） ──

int prim(vector<vector<int>>& g, int n) {
    vector<int> dist(n, INF);
    vector<bool> visited(n, false);
    dist[0] = 0;
    int totalWeight = 0;

    for (int i = 0; i < n; i++) {
        int u = -1, minDist = INF;
        for (int j = 0; j < n; j++) {
            if (!visited[j] && dist[j] < minDist) {
                minDist = dist[j];
                u = j;
            }
        }
        if (u == -1) break;
        visited[u] = true;
        totalWeight += minDist;

        for (int v = 0; v < n; v++) {
            if (!visited[v] && g[u][v] < dist[v]) {
                dist[v] = g[u][v];
            }
        }
    }
    return totalWeight;
}

// ── Kruskal算法 ──

struct Edge {
    int u, v, w;
    bool operator<(const Edge& e) const { return w < e.w; }
};

struct DSU {
    vector<int> parent, rank;
    DSU(int n) : parent(n), rank(n, 0) {
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }
    void unite(int x, int y) {
        x = find(x); y = find(y);
        if (x == y) return;
        if (rank[x] < rank[y]) swap(x, y);
        parent[y] = x;
        if (rank[x] == rank[y]) rank[x]++;
    }
};

int kruskal(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end());
    DSU dsu(n);
    int totalWeight = 0, cnt = 0;
    for (auto& e : edges) {
        if (dsu.find(e.u) != dsu.find(e.v)) {
            dsu.unite(e.u, e.v);
            totalWeight += e.w;
            cnt++;
            if (cnt == n - 1) break;
        }
    }
    return totalWeight;
}
```

#### Python 实现

```python
import sys
from typing import List, Tuple


def prim(graph: List[List[int]], n: int) -> int:
    INF = float('inf')
    dist = [INF] * n
    visited = [False] * n
    dist[0] = 0
    total_weight = 0

    for _ in range(n):
        u = -1
        min_dist = INF
        for j in range(n):
            if not visited[j] and dist[j] < min_dist:
                min_dist = dist[j]
                u = j
        if u == -1:
            break
        visited[u] = True
        total_weight += min_dist

        for v in range(n):
            if not visited[v] and graph[u][v] < dist[v]:
                dist[v] = graph[u][v]

    return total_weight


class DSU:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int):
        x = self.find(x)
        y = self.find(y)
        if x == y:
            return
        if self.rank[x] < self.rank[y]:
            x, y = y, x
        self.parent[y] = x
        if self.rank[x] == self.rank[y]:
            self.rank[x] += 1


def kruskal(edges: List[Tuple[int, int, int]], n: int) -> int:
    edges.sort(key=lambda e: e[2])
    dsu = DSU(n)
    total_weight = 0
    cnt = 0
    for u, v, w in edges:
        if dsu.find(u) != dsu.find(v):
            dsu.union(u, v)
            total_weight += w
            cnt += 1
            if cnt == n - 1:
                break
    return total_weight
```

### 7.7.4 由前序+中序序列构建二叉树

```python
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def build_tree(preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
    if not preorder or not inorder:
        return None

    root_val = preorder[0]
    root = TreeNode(root_val)

    # 在中序中找到根的位置
    pivot = inorder.index(root_val)

    # 中序：左子树 [0:pivot]，右子树 [pivot+1:]
    # 前序：左子树 [1:1+pivot]，右子树 [1+pivot:]
    root.left = build_tree(preorder[1:1+pivot], inorder[:pivot])
    root.right = build_tree(preorder[1+pivot:], inorder[pivot+1:])

    return root


# 使用示例
preorder = [3, 9, 20, 15, 7]
inorder  = [9, 3, 15, 20, 7]
root = build_tree(preorder, inorder)
```

## 总结

| 概念 | 核心要点 |
|:---|:---|
| **树** | $n$ 个顶点，$n-1$ 条边的连通无回路图。六个等价条件。 |
| **树叶** | 非平凡树至少2片树叶。 |
| **生成树** | 连通图的极小连通生成子图。 |
| **MST** | Prim $O(n^2)$ 适合稠密图，Kruskal $O(m\log m)$ 适合稀疏图。 |
| **Cayley定理** | $n$ 个标号顶点的不同树有 $n^{n-2}$ 个。 |
| **二叉树性质** | $n_0=n_2+1$，第 $i$ 层最多 $2^{i-1}$ 个结点。 |
| **遍历** | 前序(DLR)、中序(LDR)、后序(LRD)。前序+中序 或 后序+中序可重建二叉树。 |
| **哈夫曼树** | 带权路径长度最小的二叉树，$O(n\log n)$ 构建。 |
| **哈夫曼编码** | 最优前缀码，压缩存储与传输。 |
| **表达式树** | 前序 = 波兰式，后序 = 逆波兰式，适合栈求值。 |
