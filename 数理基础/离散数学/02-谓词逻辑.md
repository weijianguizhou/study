# 02-谓词逻辑

> **谓词逻辑**（Predicate Logic），又称一阶逻辑（First-Order Logic），是对[[01-命题逻辑|命题逻辑]]的扩展。命题逻辑将原子命题视为不可分割的整体，忽略其内部结构；谓词逻辑进一步分析命题的内部成分——个体对象和谓词关系，并引入全称量词 $\forall$ 和存在量词 $\exists$，使推理表达能力大幅增强。

---

## 2.1 谓词与个体

### 2.1.1 个体词

**个体词**（Individual）是表示所讨论对象（物体、人、数等）的符号。个体词分为两类：

- **个体常元**（Individual Constant）：表示特定对象的符号，通常用小写字母 $a, b, c, \dots$ 表示。
- **个体变元**（Individual Variable）：表示泛指某类对象的符号，通常用 $x, y, z, \dots$ 表示。

**论域**（Domain of Discourse / Universe）：个体变元的取值范围，记作 $D$。论域可以是有限集或无限集。

**示例**：
- 论域 $D$ = "全体实数"，个体常元 $a = \pi$，个体变元 $x \in \mathbb{R}$。
- 论域 $D$ = "全体人类"，个体常元 $b = \text{苏格拉底}$。

### 2.1.2 谓词

**谓词**（Predicate）是表示个体性质或个体间关系的符号。谓词本身不是命题，但填入个体词后就成为命题。

- **一元谓词** $P(x)$：表示个体 $x$ 的**性质**（Property）。
- **二元谓词** $R(x, y)$：表示个体 $x$ 与 $y$ 之间的**关系**（Relation）。
- **$n$ 元谓词** $P(x_1, x_2, \dots, x_n)$：表示 $n$ 个个体之间的关系。

**示例**：

| 谓词符号 | 含义 | 元数 |
|----------|------|------|
| $H(x)$ | $x$ 是人 | 一元 |
| $M(x)$ | $x$ 会死 | 一元 |
| $L(x, y)$ | $x$ 爱 $y$ | 二元 |
| $G(x, y, z)$ | $x$ 在 $y$ 和 $z$ 之间 | 三元 |

**谓词与命题的区别**：

| | 命题（命题逻辑） | 谓词（谓词逻辑） |
|------|-----------------|------------------|
| 结构 | 不可分割的整体 | 可分解为谓词 + 个体词 |
| 真值 | 直接有真值 | 填入具体个体后才有真值 |
| 示例 | $p$：苏格拉底是人 | $H(a)$：$a$ 是人 |

> 命题是 **0 元谓词**（不含量词和自由变元）。

### 2.1.3 谓词逻辑中的翻译

将自然语言翻译为谓词公式是谓词逻辑的核心能力。

**常用翻译模板**：

| 自然语言 | 谓词公式 |
|----------|----------|
| 所有 $P$ 是 $Q$ | $\forall x (P(x) \rightarrow Q(x))$ |
| 有些 $P$ 是 $Q$ | $\exists x (P(x) \land Q(x))$ |
| 没有 $P$ 是 $Q$ | $\forall x (P(x) \rightarrow \neg Q(x))$ 或 $\neg\exists x (P(x) \land Q(x))$ |
| 有些 $P$ 不是 $Q$ | $\exists x (P(x) \land \neg Q(x))$ |
| 所有 $P$ 不是 $Q$ | $\forall x (P(x) \rightarrow \neg Q(x))$ |

> **关键规律**：全称量词 $\forall$ 后通常跟**蕴涵** $\rightarrow$，存在量词 $\exists$ 后通常跟**合取** $\land$。

**示例**：将"每个人都爱某个人"翻译为谓词公式。

设论域为全体人类，$L(x, y)$ 表示 "$x$ 爱 $y$"。

$$\forall x \exists y \, L(x, y)$$

注意：$\forall x \exists y \, L(x, y)$（每人都爱某个可能不同的人）与 $\exists y \forall x \, L(x, y)$（存在一个被所有人爱的人）意义不同！

## 2.2 量词

### 2.2.1 全称量词 $\forall$

**定义**：全称量词 $\forall x \, P(x)$ 读作"对任意 $x$（在论域中），$P(x)$ 成立"。当且仅当论域中的**每一个**个体都满足 $P$ 时，$\forall x \, P(x)$ 为真。

**语义**：

$$\forall x \, P(x) \equiv \bigwedge_{a \in D} P(a)$$

（在有限论域中等价于所有个体代入后的合取）

**示例**：
- 论域 $D = \{1, 2, 3\}$，$P(x)$："$x > 0$"，则 $\forall x P(x)$ 为真。
- 论域 $D = \mathbb{N}$，$P(x)$："$x$ 是偶数"，则 $\forall x P(x)$ 为假（3 就不满足）。

### 2.2.2 存在量词 $\exists$

**定义**：存在量词 $\exists x \, P(x)$ 读作"存在 $x$（在论域中），使得 $P(x)$ 成立"。当且仅当论域中**至少有一个**个体满足 $P$ 时，$\exists x \, P(x)$ 为真。

**语义**：

$$\exists x \, P(x) \equiv \bigvee_{a \in D} P(a)$$

（在有限论域中等价于所有个体代入后的析取）

**唯一存在量词** $\exists!$：$\exists! x \, P(x)$ 表示"存在**唯一**的 $x$ 使得 $P(x)$ 成立"。

$$\exists! x\, P(x) \equiv \exists x\, [P(x) \land \forall y\, (P(y) \rightarrow y = x)]$$

**量词之间的对偶性**：
- $\forall$ 与 $\exists$ 是互相对偶的。
- $\neg\forall x P(x) \equiv \exists x \neg P(x)$
- $\neg\exists x P(x) \equiv \forall x \neg P(x)$

### 2.2.3 辖域与变元

**辖域**（Scope）：量词的作用范围。

- 在 $\forall x \, P(x) \rightarrow Q(x)$ 中，量词 $\forall x$ 的辖域仅为 $P(x)$，$Q(x)$ 中的 $x$ 是自由变元。
- 在 $\forall x \, (P(x) \rightarrow Q(x))$ 中，辖域是整个 $P(x) \rightarrow Q(x)$。

**约束变元**（Bound Variable）：出现在量词辖域中、且与该量词使用的变元名相同（被"捕获"）的变元。

**自由变元**（Free Variable）：未受任何量词约束的变元。

**示例**：区分公式 $\forall x (P(x) \rightarrow \exists y Q(x, y)) \lor R(z)$ 中的自由变元与约束变元。

- $\forall x$ 约束了 $P(x)$ 和 $Q(x, y)$ 中的 $x$。
- $\exists y$ 约束了 $Q(x, y)$ 中的 $y$。
- $z$ 是自由变元。

> 含自由变元的公式不是命题，其真值依赖于对自由变元的具体赋值。

### 2.2.4 变元的改名规则（$\alpha$-转换）

在谓词逻辑中，约束变元的名称可以更改而不改变公式的含义，但必须遵守规则。

**改名规则**：
1. 只对约束变元改名，不能改自由变元。
2. 改名后的变元不能与辖域中已有的其他自由变元同名（避免变量捕获）。

**示例**：
- $\forall x \, P(x) \equiv \forall y \, P(y)$（合法改名）
- $\forall x \, (P(x) \land Q(y))$ 不能改为 $\forall y \, (P(y) \land Q(y))$（$y$ 原是自由变元，改名后被捕获，含义改变）

## 2.3 谓词公式

### 2.3.1 项与原子公式

**项**（Term）的递归定义：
1. 个体常元是项。
2. 个体变元是项。
3. 若 $f$ 是 $n$ 元函数符号，$t_1, \dots, t_n$ 是项，则 $f(t_1, \dots, t_n)$ 是项。

**原子公式**（Atomic Formula）：若 $P$ 是 $n$ 元谓词符号，$t_1, \dots, t_n$ 是项，则 $P(t_1, \dots, t_n)$ 是原子公式。

### 2.3.2 合式公式

谓词逻辑的**合式公式**（WFF）递归定义如下：

1. （**基底**）每个原子公式是合式公式。
2. （**递归步**）若 $A$ 是 WFF，则 $(\neg A)$ 是 WFF。
3. 若 $A$ 和 $B$ 是 WFF，则 $(A \land B)$、$(A \lor B)$、$(A \rightarrow B)$、$(A \leftrightarrow B)$ 是 WFF。
4. 若 $A$ 是 WFF，$x$ 是变元，则 $(\forall x \, A)$ 和 $(\exists x \, A)$ 是 WFF。
5. 只有有限次使用（1）—（4）得到的才是 WFF。

**封闭公式**（Sentence / Closed Formula）：不含自由变元的 WFF。封闭公式是命题——有确定的真值。

## 2.4 谓词公式的解释

### 2.4.1 解释的构成

谓词公式的**解释**（Interpretation）$\mathcal{I}$ 由以下成分构成：

1. **论域** $D$：一个非空集合。
2. **常元指派**：将每个个体常元 $a$ 映射到 $D$ 中的某个元素 $a^{\mathcal{I}} \in D$。
3. **函数符号指派**：将每个 $n$ 元函数符号 $f$ 映射到一个函数 $f^{\mathcal{I}}: D^n \rightarrow D$。
4. **谓词符号指派**：将每个 $n$ 元谓词符号 $P$ 映射到一个关系 $P^{\mathcal{I}} \subseteq D^n$。

### 2.4.2 公式在解释下的真值

封闭公式在给定解释下有确定的真值，按 Tarski 语义递归计算：

- $\mathcal{I} \models P(t_1, \dots, t_n)$ 当 $(t_1^{\mathcal{I}}, \dots, t_n^{\mathcal{I}}) \in P^{\mathcal{I}}$
- $\mathcal{I} \models \neg A$ 当 $\mathcal{I} \not\models A$
- $\mathcal{I} \models A \land B$ 当 $\mathcal{I} \models A$ 且 $\mathcal{I} \models B$
- $\mathcal{I} \models \forall x A(x)$ 当对每个 $d \in D$，$\mathcal{I}[x := d] \models A(x)$
- $\mathcal{I} \models \exists x A(x)$ 当存在 $d \in D$，$\mathcal{I}[x := d] \models A(x)$

**示例**：设论域 $D = \{1, 2, 3\}$，$P(x)$："$x$ 是偶数"（$P^{\mathcal{I}} = \{2\}$），$Q(x)$："$x > 0$"（$Q^{\mathcal{I}} = \{1, 2, 3\}$）。

- $\mathcal{I} \models \forall x \, Q(x)$（所有数都 $>0$ ✓）
- $\mathcal{I} \not\models \forall x \, P(x)$（1 不是偶数 ✗）
- $\mathcal{I} \models \exists x \, P(x)$（存在偶数 2 ✓）

## 2.5 谓词逻辑的永真式与等价

### 2.5.1 永真式

在谓词逻辑中，**普遍有效式**（谓词逻辑中的永真式）指在所有解释下均为真的封闭公式。

> 注意：与命题逻辑不同，谓词逻辑的永真式是不可判定的（丘奇定理），即不存在通用算法判定任意谓词公式是否为永真式。

### 2.5.2 量词的否定律

| 编号 | 定理 | 名称 |
|------|------|------|
| Q1 | $\neg\forall x P(x) \equiv \exists x \neg P(x)$ | 全称量词的否定 |
| Q2 | $\neg\exists x P(x) \equiv \forall x \neg P(x)$ | 存在量词的否定 |

**证明**（Q1）：
- 直观：$\forall x P(x)$ 为假，意味着并非所有 $x$ 都使 $P(x)$ 成立 → 存在某个 $x$ 使 $P(x)$ 不成立 → $\exists x \neg P(x)$ 为真。
- 形式：$\neg\forall x P(x)$ 为真 ⟺ 存在 $d \in D$ 使 $P(d)$ 为假 ⟺ $\exists x \neg P(x)$ 为真。

### 2.5.3 量词的分配律

| 编号 | 等价/蕴涵关系 | 说明 |
|------|--------------|------|
| Q3 | $\forall x (P(x) \land Q(x)) \equiv \forall x P(x) \land \forall x Q(x)$ | $\forall$ 对 $\land$ 可分配 |
| Q4 | $\exists x (P(x) \lor Q(x)) \equiv \exists x P(x) \lor \exists x Q(x)$ | $\exists$ 对 $\lor$ 可分配 |
| Q5 | $\forall x P(x) \lor \forall x Q(x) \models \forall x (P(x) \lor Q(x))$ | 反向不成立 |
| Q6 | $\exists x (P(x) \land Q(x)) \models \exists x P(x) \land \exists x Q(x)$ | 反向不成立 |

**证明**（Q3）：
$$
\begin{aligned}
\forall x (P(x) \land Q(x)) &\equiv \bigwedge_{a \in D} (P(a) \land Q(a)) \\
&\equiv \left(\bigwedge_{a \in D} P(a)\right) \land \left(\bigwedge_{a \in D} Q(a)\right) \\
&\equiv \forall x P(x) \land \forall x Q(x)
\end{aligned}
$$

**反例**（Q5 反向不成立）：论域 $D = \mathbb{N}$，$P(x)$："$x$ 是偶数"，$Q(x)$："$x$ 是奇数"。
- $\forall x (P(x) \lor Q(x))$ 为真（每个自然数非偶即奇）。
- $\forall x P(x) \lor \forall x Q(x)$ 为假（并非所有数都是偶数，也并非所有数都是奇数）。

### 2.5.4 量词作用域的扩张与收缩

如果公式 $B$ 不含自由变元 $x$，则有以下等价式：

| 编号 | 等价式 |
|------|--------|
| Q7 | $\forall x (A(x) \land B) \equiv \forall x A(x) \land B$ |
| Q8 | $\forall x (A(x) \lor B) \equiv \forall x A(x) \lor B$ |
| Q9 | $\exists x (A(x) \land B) \equiv \exists x A(x) \land B$ |
| Q10 | $\exists x (A(x) \lor B) \equiv \exists x A(x) \lor B$ |
| Q11 | $\forall x (A(x) \rightarrow B) \equiv \exists x A(x) \rightarrow B$ |
| Q12 | $\exists x (A(x) \rightarrow B) \equiv \forall x A(x) \rightarrow B$ |
| Q13 | $\forall x (B \rightarrow A(x)) \equiv B \rightarrow \forall x A(x)$ |
| Q14 | $\exists x (B \rightarrow A(x)) \equiv B \rightarrow \exists x A(x)$ |

### 2.5.5 量词顺序与互换

- $\forall x \forall y \, P(x, y) \equiv \forall y \forall x \, P(x, y)$（同种量词可交换）
- $\exists x \exists y \, P(x, y) \equiv \exists y \exists x \, P(x, y)$（同种量词可交换）
- $\exists x \forall y \, P(x, y) \models \forall y \exists x \, P(x, y)$（反向不成立！）

> **重要**：$\forall y \exists x \, P(x, y)$（对每个 $y$，存在某个 $x$）**不能**推出 $\exists x \forall y \, P(x, y)$（存在一个统一的 $x$ 对所有 $y$ 成立）。

## 2.6 前束范式

### 2.6.1 定义

**前束范式**（Prenex Normal Form）：一个谓词公式称为前束范式，若其具有形式：

$$Q_1 x_1 \, Q_2 x_2 \, \dots \, Q_n x_n \, M$$

其中：
- 每个 $Q_i$ 是 $\forall$ 或 $\exists$（量词）
- $M$ 是不含量词的公式（称为**母式**，Matrix）
- 所有量词都在公式的最前面

**示例**：
- $\forall x \exists y (P(x) \rightarrow Q(y))$ ✓ 前束范式
- $\forall x P(x) \rightarrow \exists y Q(y)$ ✗ 不是前束范式（蕴涵不在量词辖域内）

### 2.6.2 求前束范式的步骤

**步骤详解**：

1. **消去 $\rightarrow$ 和 $\leftrightarrow$**：
   - $A \rightarrow B \equiv \neg A \lor B$
   - $A \leftrightarrow B \equiv (A \rightarrow B) \land (B \rightarrow A)$

2. **将否定深入**（德摩根律）：
   - $\neg\neg A \equiv A$
   - $\neg(A \land B) \equiv \neg A \lor \neg B$
   - $\neg(A \lor B) \equiv \neg A \land \neg B$
   - $\neg\forall x A(x) \equiv \exists x \neg A(x)$
   - $\neg\exists x A(x) \equiv \forall x \neg A(x)$

3. **变元改名**（避免变量名冲突）：
   - 若不同量词使用了相同的约束变元名，将其中的约束变元改为新名。
   - 确保不存在某变元既是约束的又是自由的（同名冲突）。

4. **量词前移**（利用量词作用域扩张律）：
   - 将量词逐步移到公式前面，利用前述的 Q7–Q14 等价式。

**示例**：求 $\forall x P(x) \rightarrow \exists y Q(y)$ 的前束范式。

$$
\begin{aligned}
\forall x P(x) \rightarrow \exists y Q(y)
&\equiv \neg\forall x P(x) \lor \exists y Q(y) \quad &\text{（消去 →）} \\
&\equiv \exists x \neg P(x) \lor \exists y Q(y) \quad &\text{（量词否定律）} \\
&\equiv \exists x (\neg P(x) \lor \exists y Q(y)) \quad &\text{（∃ 对 ∨ 扩张）} \\
&\equiv \exists x \exists y (\neg P(x) \lor Q(y)) \quad &\text{（∃ 对 ∨ 扩张）}
\end{aligned}
$$

**示例**：求 $\exists x P(x) \land \forall y Q(y)$ 的前束范式。

$$
\begin{aligned}
\exists x P(x) \land \forall y Q(y)
&\equiv \exists x (P(x) \land \forall y Q(y)) \quad &\text{（x 不在 ∀yQ(y) 中自由）} \\
&\equiv \exists x \forall y (P(x) \land Q(y)) \quad &\text{（y 不在 P(x) 中自由？检查后可用 ∀ 扩张）}
\end{aligned}
$$

但此处需注意：$\forall x \exists y$ 与 $\exists y \forall x$ 顺序不同含义可能不同。原式中 $\exists x$ 在 $\forall y$ 外，所以前束范式应为 $\exists x \forall y (P(x) \land Q(y))$。

**全程示例**：求 $\forall x (P(x) \rightarrow \exists y \, R(x, y)) \lor \exists z \, S(z)$ 的前束范式。

$$
\begin{aligned}
&\forall x (P(x) \rightarrow \exists y \, R(x, y)) \lor \exists z \, S(z) \\
&\equiv \forall x (\neg P(x) \lor \exists y \, R(x, y)) \lor \exists z \, S(z) \quad &\text{（消去 →）} \\
&\equiv \forall x \exists y (\neg P(x) \lor R(x, y)) \lor \exists z \, S(z) \quad &\text{（∃ 扩张）} \\
&\equiv \forall x \exists y \exists z ((\neg P(x) \lor R(x, y)) \lor S(z)) \quad &\text{（∀, ∃ 扩张）} \\
&\equiv \forall x \exists y \exists z (\neg P(x) \lor R(x, y) \lor S(z)) \quad &\text{（结合律）}
\end{aligned}
$$

## 2.7 谓词逻辑推理

### 2.7.1 量词的推理规则

| 规则 | 名称 | 形式 |
|------|------|------|
| **UI** | 全称实例化（Universal Instantiation） | $\forall x P(x) \models P(a)$（$a$ 为任意个体常元） |
| **EI** | 存在实例化（Existential Instantiation） | $\exists x P(x) \models P(c)$（$c$ 为新常元，不在之前出现） |
| **UG** | 全称泛化（Universal Generalization） | $P(a)$ 对任意 $a$ 成立 $\models \forall x P(x)$ |
| **EG** | 存在泛化（Existential Generalization） | $P(a) \models \exists x P(x)$ |

**UI 规则详解**：从"对所有 $x$，$P(x)$ 成立"可推出"对论域中任意特定个体 $a$，$P(a)$ 成立"。

**EI 规则详解**：从"存在 $x$ 使 $P(x)$ 成立"可引入一个新常元 $c$ 代表那个满足 $P$ 的个体，推出 $P(c)$。

> **EI 关键约束**：$c$ 必须是**新**常元——此前未在前提、已推出的结论中出现过，并且不能出现在最终结论中。

**UG 规则详解**：如果可以证明 $P(a)$ 对任意（未加特殊假设的）个体 $a$ 成立，则可以推出 $\forall x P(x)$。

> **UG 关键约束**：$a$ 不能是已被特殊假设（如来自 EI）限制的个体。

### 2.7.2 形式证明示例

**例 1**：证明 $\forall x (H(x) \rightarrow M(x)), H(s) \models M(s)$（经典三段论：所有人都会死，苏格拉底是人，所以苏格拉底会死。）

$$
\begin{aligned}
1.\quad &\forall x (H(x) \rightarrow M(x)) \quad &\text{（前提）} \\
2.\quad &H(s) \quad &\text{（前提）} \\
3.\quad &H(s) \rightarrow M(s) \quad &\text{（1, UI：将 } x \text{ 实例化为 } s\text{）} \\
4.\quad &M(s) \quad &\text{（2, 3, 假言推理 MP）}
\end{aligned}
$$

**例 2**：证明 $\forall x (P(x) \rightarrow Q(x)), \exists x P(x) \models \exists x Q(x)$

$$
\begin{aligned}
1.\quad &\forall x (P(x) \rightarrow Q(x)) \quad &\text{（前提）} \\
2.\quad &\exists x P(x) \quad &\text{（前提）} \\
3.\quad &P(c) \quad &\text{（2, EI：引入新常元 } c\text{）} \\
4.\quad &P(c) \rightarrow Q(c) \quad &\text{（1, UI）} \\
5.\quad &Q(c) \quad &\text{（3, 4, MP）} \\
6.\quad &\exists x Q(x) \quad &\text{（5, EG）}
\end{aligned}
$$

**例 3**：证明 $\exists x \forall y \, L(x, y) \models \forall y \exists x \, L(x, y)$

$$
\begin{aligned}
1.\quad &\exists x \forall y \, L(x, y) \quad &\text{（前提）} \\
2.\quad &\forall y \, L(c, y) \quad &\text{（1, EI：} c \text{ 是新常元）} \\
3.\quad &L(c, a) \quad &\text{（2, UI）} \\
4.\quad &\exists x \, L(x, a) \quad &\text{（3, EG）} \\
5.\quad &\forall y \exists x \, L(x, y) \quad &\text{（4, UG：} a \text{ 是任意的）}
\end{aligned}
$$

> 注意：例 3 的逆（$\forall y \exists x \, L(x, y) \models \exists x \forall y \, L(x, y)$）不成立。直观理解：每人爱某个人（依赖 $y$ 的 $x$）$\not\Rightarrow$ 存在一个被所有人爱的人（统一的 $x$）。

**例 4**：含自由变元的推理。证明 $\forall x (P(x) \lor Q(x)), \neg P(a) \models Q(a)$

$$
\begin{aligned}
1.\quad &\forall x (P(x) \lor Q(x)) \quad &\text{（前提）} \\
2.\quad &\neg P(a) \quad &\text{（前提）} \\
3.\quad &P(a) \lor Q(a) \quad &\text{（1, UI）} \\
4.\quad &Q(a) \quad &\text{（2, 3, 析取三段论）}
\end{aligned}
$$

### 2.7.3 常见推理错误

| 错误 | 描述 |
|------|------|
| **逆命题错误** | 从 $P(x) \rightarrow Q(x)$ 推出 $Q(x) \rightarrow P(x)$ |
| **量词跳跃** | 从 $\forall y \exists x P(x, y)$ 错误推出 $\exists x \forall y P(x, y)$ |
| **EI 使用不当** | 引入的常元在前提中已出现，或出现在最终结论中 |
| **UG 使用不当** | 对由 EI 引入的特定个体使用全称泛化 |

```cpp
// D 是一个 vector，predicate 是一元谓词函数

template<typename T>
bool forall(const vector<T>& D, function<bool(const T&)> pred) {
    for (const T& x : D) {
        if (!pred(x)) return false;
    }
    return true;
}

template<typename T>
bool exists(const vector<T>& D, function<bool(const T&)> pred) {
    for (const T& x : D) {
        if (pred(x)) return true;
    }
    return false;
}

template<typename T>
bool exists_unique(const vector<T>& D, function<bool(const T&)> pred) {
    int count = 0;
    for (const T& x : D) {
        if (pred(x)) count++;
        if (count > 1) return false;
    }
    return count == 1;
}

// 二元谓词的全称量词评估（对每个 x 存在 y 使 P(x, y) 成立）
template<typename T>
bool forall_exists(const vector<T>& D,
                   function<bool(const T&, const T&)> pred) {
    for (const T& x : D) {
        bool hasY = false;
        for (const T& y : D) {
            if (pred(x, y)) { hasY = true; break; }
        }
        if (!hasY) return false;
    }
    return true;
}

int main() {
    // 论域 D = {1, 2, 3, 4, 5}
    vector<int> D = {1, 2, 3, 4, 5};

    // P(x): x 是正数（恒真）
    auto isPositive = [](int x) { return x > 0; };
    cout << "∀x P(x): " << (forall(D, isPositive) ? "真" : "假") << endl;

    // Q(x): x 是偶数
    auto isEven = [](int x) { return x % 2 == 0; };
    cout << "∀x Q(x): " << (forall(D, isEven) ? "真" : "假") << endl;
    cout << "∃x Q(x): " << (exists(D, isEven) ? "真" : "假") << endl;

    // 验证量词否定律: ¬∀x Q(x) ≡ ∃x ¬Q(x)
    auto notQ = [&](int x) { return !isEven(x); };
    bool lhs = !forall(D, isEven);
    bool rhs = exists(D, notQ);
    cout << "¬∀x Q(x) ≡ ∃x ¬Q(x): " << (lhs == rhs ? "成立" : "不成立") << endl;

    // 二元谓词: L(x, y): x < y
    auto lessThan = [](int x, int y) { return x < y; };
    cout << "∀x∃y (x < y): "
         << (forall_exists(D, lessThan) ? "真" : "假") << endl;

    // ∃!x (x 是大于 4 的数)
    auto greaterThan4 = [](int x) { return x > 4; };
    cout << "∃!x (x > 4): "
         << (exists_unique(D, greaterThan4) ? "真" : "假") << endl;

    return 0;
}
```

### 2.8.3 Python：前束范式转换辅助工具

```python
import re
from typing import List, Tuple


def prenex_normal_form(expr: str) -> str:
    """
    将谓词公式转换为前束范式的简化辅助工具。
    处理的联结词：¬, ∧, ∨, →, ↔
    量词：∀ (或 A), ∃ (或 E)
    前提：公式已正确格式化为带括号的字符串。
    
    这是一个概念演示实现，完整的谓词逻辑前束范式
    转换需要更复杂的解析器。
    """
    # 规则字典
    rules = {
        # 消去蕴涵 A → B ≡ ¬A ∨ B
        # 消去等价 A ↔ B ≡ (A→B)∧(B→A)
        # 量词否定 ¬∀xA ≡ ∃x¬A, ¬∃xA ≡ ∀x¬A
        # 量词前移规则
    }
    
    # 简化示例：处理量词否定
    def push_negation(formula: str) -> str:
        """将否定深入公式内部（含量词处理）"""
        # ¬∀x P(x) → ∃x ¬P(x)
        formula = re.sub(r'¬∀(\w+)\s', r'∃\1 ¬', formula)
        # ¬∃x P(x) → ∀x ¬P(x)
        formula = re.sub(r'¬∃(\w+)\s', r'∀\1 ¬', formula)
        return formula

    def extract_quantifiers(formula: str) -> Tuple[str, str]:
        """
        提取公式开头的所有量词，返回 (量词前缀, 剩余部分)
        """
        prefix = ''
        rest = formula
        while rest.startswith('∀') or rest.startswith('∃'):
            # 提取量词部分，例如 "∀x "
            match = re.match(r'([∀∃])(\w+)\s', rest)
            if match:
                prefix += match.group(0)
                rest = rest[match.end():]
            else:
                break
        return prefix, rest

    # 示例用法
    test = "¬∀x (P(x) → ∃y Q(x,y))"
    result = push_negation(test)
    result = result.replace('→', '∨¬')  # 简化替代
    print(f"原始: {test}")
    print(f"处理: {result}")
    
    return result


# ======== 完整的前束范式转换器（简化版） ========

class PrenexConverter:
    """
    谓词公式的前束范式转换器（简化版）。
    支持标准谓词逻辑语法，假设输入格式为带括号的字符串。
    """

    # 量词作用域扩张规则 (Q7–Q14)
    # 条件：B 中不含自由变元 x
    EXPANSIONS = {
        # ∀x (A ∧ B) ≡ ∀x A ∧ B （若 x 不在 B 中自由）
        'forall_and': ('∀{v}({A}∧{B})', '∀{v}{A}∧{B}'),
        'forall_or':  ('∀{v}({A}∨{B})', '∀{v}{A}∨{B}'),
        'exists_and': ('∃{v}({A}∧{B})', '∃{v}{A}∧{B}'),
        'exists_or':  ('∃{v}({A}∨{B})', '∃{v}{A}∨{B}'),
        # ∀x (A → B) ≡ ∃x A → B (若 x 不在 B 中自由)
        'forall_imp': ('∀{v}({A}→{B})', '∃{v}{A}→{B}'),
        # ∃x (A → B) ≡ ∀x A → B
        'exists_imp': ('∃{v}({A}→{B})', '∀{v}{A}→{B}'),
        # ∀x (B → A) ≡ B → ∀x A
        'forall_imp2': ('∀{v}({B}→{A})', '{B}→∀{v}{A}'),
        # ∃x (B → A) ≡ B → ∃x A
        'exists_imp2': ('∃{v}({B}→{A})', '{B}→∃{v}{A}'),
    }

    def __init__(self):
        self.steps = []

    def eliminate_implication(self, expr: str) -> str:
        """消除蕴涵连接词 A→B ≡ ¬A∨B"""
        # 简化实现
        return expr.replace('→', '∨¬')  # 需要更精确的解析

    def negate_into(self, expr: str) -> str:
        """将否定深入到原子公式前，并处理量词否定"""
        # ¬∀xP ≡ ∃x¬P
        # ¬∃xP ≡ ∀x¬P
        patterns = [
            (r'¬∀(\w+)', r'∃\1¬'),
            (r'¬∃(\w+)', r'∀\1¬'),
        ]
        for pat, repl in patterns:
            expr = re.sub(pat, repl, expr)
        return expr

    def to_prenex(self, expr: str) -> str:
        """
        将谓词公式转换为前束范式。
        返回前束范式的字符串表示。
        """
        self.steps = [expr]
        result = expr

        # Step 1: 消去 → 和 ↔
        # (简化实现，实际需要解析器)
        result = self.eliminate_implication(result)
        self.steps.append(f"消去→: {result}")

        # Step 2: 将否定深入（含量词否定）
        result = self.negate_into(result)
        self.steps.append(f"否定深入: {result}")

        # Step 3: 变元改名（简化跳过）
        # Step 4: 量词前移（简化实现）
        self.steps.append(f"量词前移: {result}")

        return result


if __name__ == "__main__":
    converter = PrenexConverter()
    test = "∀x P(x) → ∃y Q(y)"
    print(f"原始公式: {test}")
    print(f"前束范式: {converter.to_prenex(test)}")
    print("\n步骤:")
    for i, step in enumerate(converter.steps):
        print(f"  {i+1}. {step}")
```
