# 03-集合论

> **集合论**（Set Theory）是现代数学的基石。几乎所有数学对象都可以用集合来定义。本章讨论朴素集合论（Naive Set Theory）的核心概念，包括集合的基本定义、运算、关系以及容斥原理。

---

## 3.1 集合的基本概念

### 3.1.1 集合与元素的定义

**集合**（Set）是由确定对象构成的整体。构成集合的对象称为该集合的**元素**（Element）或**成员**（Member）。用 $a \in A$ 表示 $a$ 是集合 $A$ 的元素；用 $a \notin A$ 表示 $a$ 不是 $A$ 的元素。

**集合的基本特征**：
1. **确定性**：对任意对象 $x$，$x \in A$ 和 $x \notin A$ 二者必居其一且只居其一。
2. **无序性**：$\{1, 2, 3\} = \{3, 1, 2\}$——元素的排列顺序无关。
3. **互异性**：$\{1, 1, 2, 2, 3\} = \{1, 2, 3\}$——重复元素只算一次。

### 3.1.2 集合的表示法

#### （一）列举法（Enumeration）

将集合中的所有元素逐一列出，用大括号括起，元素之间用逗号分隔。

**示例**：
- $A = \{1, 2, 3, 4, 5\}$（有限集）
- $B = \{a, b, c, \dots, z\}$（用省略号表示有规律的元素）
- $\mathbb{N} = \{0, 1, 2, 3, \dots\}$（无限集）

#### （二）描述法（Set-Builder Notation）

通过描述元素应满足的性质来定义集合：

$$A = \{x \mid P(x)\}$$

读作"满足 $P(x)$ 的所有 $x$ 构成的集合"，其中 $P(x)$ 是一个谓词（性质）。

**示例**：
- $A = \{x \mid x \in \mathbb{R}, x > 2\}$（大于 2 的所有实数）
- $B = \{x \mid x \text{ 是偶数且 } 0 \leq x \leq 10\} = \{0, 2, 4, 6, 8, 10\}$
- $C = \{x \mid \exists n \in \mathbb{N}, x = 2n\}$（所有偶数）

**描述法的一般形式**：$\{x \in X \mid P(x)\}$，其中 $X$ 是已知集合（论域）。

#### （三）文氏图（Venn Diagram）

文氏图是用平面上的封闭曲线（圆或椭圆）直观表示集合及其关系的图形工具。集合用圆表示，元素用点表示。

常见文氏图布局：用矩形表示全集 $U$，内部用圆表示各集合。

### 3.1.3 外延公理与概括公理

**外延公理**（Axiom of Extensionality）：两个集合相等当且仅当它们具有相同的元素。

$$\forall A \forall B \, (A = B \leftrightarrow \forall x \, (x \in A \leftrightarrow x \in B))$$

**内涵**：集合由它的元素唯一确定，不依赖于描述方式。$\{1, 3, 5\}$ 和 $\{x \mid x \text{ 是奇数}, 1 \leq x \leq 5\}$ 表示同一个集合。

**概括公理**（Axiom of Comprehension）：对任意性质 $P$，存在一个集合 $A$ 恰好由满足 $P$ 的元素构成。

$$A = \{x \mid P(x)\}$$

> **罗素悖论**：若取 $P(x)$ 为 "$x \notin x$"，则 $R = \{x \mid x \notin x\}$。问 $R \in R$ 是否成立？——无论怎样回答都导出矛盾。这说明无限制的概括公理会导致悖论。现代公理集合论（ZFC）对概括公理加以限制（分离公理模式）。

### 3.1.4 特殊集合

#### 空集（Empty Set）$\varnothing$

**定义**：不含任何元素的集合称为**空集**，记作 $\varnothing$ 或 $\{\}$。

$$\varnothing = \{x \mid x \neq x\}$$

**性质**：
- $|\varnothing| = 0$
- 空集是唯一的（由外延公理可知）
- 对任意集合 $A$，$\varnothing \subseteq A$（空集是任何集合的子集）

#### 单元素集（Singleton）

**定义**：仅含一个元素的集合，如 $\{a\}$。

> 注意区分 $a$ 和 $\{a\}$：$a \in \{a\}$，但 $a \neq \{a\}$（除非在非良基集合论中）。

#### 全集（Universal Set）$U$

**定义**：在特定讨论范围内，包含所有考虑的元素的集合，记作 $U$。

> 注意：在 ZFC 中不存在包含一切集合的"绝对"全集（因为会导致罗素悖论），但在特定语境下可以定义一个讨论范围的"相对全集"。

### 3.1.5 基数与有限/无限集

**基数**（Cardinality）是集合中元素的"个数"。集合 $A$ 的基数记作 $|A|$。

- **有限集**（Finite Set）：$|A|$ 是有限自然数。例如 $|\{a, b, c\}| = 3$。
- **无限集**（Infinite Set）：元素个数无限。例如 $|\mathbb{N}| = \aleph_0$（阿列夫零，可数无穷）。
- **可数集**（Countable Set）：可与 $\mathbb{N}$ 建立一一对应的集合。
  - 可数有限集和可数无限集统称可数集。
- **不可数集**（Uncountable Set）：不能与 $\mathbb{N}$ 建立一一对应的无限集，如 $\mathbb{R}$（$|\mathbb{R}| = \mathfrak{c} = 2^{\aleph_0}$）。

## 3.2 子集与集合相等

### 3.2.1 子集

**定义**：若集合 $A$ 中的每个元素都是集合 $B$ 中的元素，则称 $A$ 是 $B$ 的**子集**，记作 $A \subseteq B$。

$$A \subseteq B \iff \forall x (x \in A \rightarrow x \in B)$$

**性质**（偏序关系的三性）：

1. **自反性**：$A \subseteq A$（任何集合是自身的子集）
2. **反对称性**：若 $A \subseteq B$ 且 $B \subseteq A$，则 $A = B$
3. **传递性**：若 $A \subseteq B$ 且 $B \subseteq C$，则 $A \subseteq C$

**证明**（反对称性——集合相等的关键判定法）：
- 若 $A \subseteq B$，则 $\forall x (x \in A \rightarrow x \in B)$
- 若 $B \subseteq A$，则 $\forall x (x \in B \rightarrow x \in A)$
- 综合得 $\forall x (x \in A \leftrightarrow x \in B)$
- 由外延公理，$A = B$。$\square$

### 3.2.2 真子集

**定义**：若 $A \subseteq B$ 且 $A \neq B$（即 $B$ 中至少有一个元素不在 $A$ 中），则称 $A$ 是 $B$ 的**真子集**，记作 $A \subset B$ 或 $A \subsetneqq B$。

$$A \subset B \iff A \subseteq B \land A \neq B$$

**示例**：$\{1, 2\} \subset \{1, 2, 3\}$；$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$

### 3.2.3 幂集

**定义**：集合 $A$ 的所有子集构成的集合称为 $A$ 的**幂集**（Power Set），记作 $\mathcal{P}(A)$ 或 $2^A$。

$$\mathcal{P}(A) = \{X \mid X \subseteq A\}$$

**定理**：若 $|A| = n$（有限集），则 $|\mathcal{P}(A)| = 2^n$。

**证明**（组合论证）：对 $A$ 中的 $n$ 个元素，每个元素在子集中有"出现"和"不出现"两种选择，因此子集总数为 $2^n$。

**示例**：
- $A = \{1, 2\}$，$\mathcal{P}(A) = \{\varnothing, \{1\}, \{2\}, \{1, 2\}\}$，$|\mathcal{P}(A)| = 2^2 = 4$
- $A = \{a, b, c\}$，$\mathcal{P}(A) = \{\varnothing, \{a\}, \{b\}, \{c\}, \{a, b\}, \{a, c\}, \{b, c\}, \{a, b, c\}\}$，$|\mathcal{P}(A)| = 2^3 = 8$
- $A = \varnothing$，$\mathcal{P}(\varnothing) = \{\varnothing\}$，$|\mathcal{P}(\varnothing)| = 2^0 = 1$

**幂集的性质**：
1. $\varnothing \in \mathcal{P}(A)$ 且 $A \in \mathcal{P}(A)$
2. 若 $A \subseteq B$，则 $\mathcal{P}(A) \subseteq \mathcal{P}(B)$
3. $\mathcal{P}(A \cap B) = \mathcal{P}(A) \cap \mathcal{P}(B)$
4. $\mathcal{P}(A \cup B) \supseteq \mathcal{P}(A) \cup \mathcal{P}(B)$（通常不等）

### 3.2.4 集合相等的判定

由外延公理，判定两个集合相等的充分必要条件是它们互为子集：

$$A = B \iff A \subseteq B \land B \subseteq A$$

**证明集合相等的标准策略**：
1. 任取 $x \in A$，证明 $x \in B$（即 $A \subseteq B$）
2. 任取 $x \in B$，证明 $x \in A$（即 $B \subseteq A$）
3. 由（1）（2）和外延公理，$A = B$

## 3.3 集合运算

### 3.3.1 并集（Union）

**定义**：属于 $A$ 或属于 $B$（或同时属于两者）的所有元素构成的集合。

$$A \cup B = \{x \mid x \in A \lor x \in B\}$$

**文氏图**：两个圆的总覆盖区域。

**性质**：
1. 幂等律：$A \cup A = A$
2. 交换律：$A \cup B = B \cup A$
3. 结合律：$(A \cup B) \cup C = A \cup (B \cup C)$
4. 同一律：$A \cup \varnothing = A$
5. 零律：$A \cup U = U$
6. $A \subseteq A \cup B$，$B \subseteq A \cup B$
7. $A \subseteq B \iff A \cup B = B$

### 3.3.2 交集（Intersection）

**定义**：同时属于 $A$ 和 $B$ 的所有元素构成的集合。

$$A \cap B = \{x \mid x \in A \land x \in B\}$$

**文氏图**：两个圆的重叠区域。

**性质**：
1. 幂等律：$A \cap A = A$
2. 交换律：$A \cap B = B \cap A$
3. 结合律：$(A \cap B) \cap C = A \cap (B \cap C)$
4. 同一律：$A \cap U = A$
5. 零律：$A \cap \varnothing = \varnothing$
6. $A \cap B \subseteq A$，$A \cap B \subseteq B$
7. $A \subseteq B \iff A \cap B = A$

**互斥（不相交）集合**：若 $A \cap B = \varnothing$，则称 $A$ 和 $B$ 不相交（Disjoint）。

### 3.3.3 差集与补集

**差集**（Set Difference）：

$$A - B = A \setminus B = \{x \mid x \in A \land x \notin B\}$$

**补集**（Complement）：当讨论给定全集 $U$ 时，$A$ 的补集是 $U - A$，记作 $\overline{A}$、$A'$ 或 $A^c$。

$$\overline{A} = U - A = \{x \in U \mid x \notin A\}$$

**文氏图**（补集）：全集矩形内、集合圆外的区域。

**补集性质**：
1. $\overline{\overline{A}} = A$（双重补等于自身）
2. $\overline{U} = \varnothing$，$\overline{\varnothing} = U$
3. $A \cup \overline{A} = U$（排中律）
4. $A \cap \overline{A} = \varnothing$（矛盾律）
5. $\overline{A \cup B} = \overline{A} \cap \overline{B}$（德摩根律）
6. $\overline{A \cap B} = \overline{A} \cup \overline{B}$（德摩根律）

### 3.3.4 对称差

**定义**：属于 $A$ 或属于 $B$ 但不同时属于两者的元素构成的集合。

$$A \triangle B = (A - B) \cup (B - A) = (A \cup B) - (A \cap B)$$

**文氏图**：两个圆的非重叠部分（并集减去交集）。

**性质**：
1. $A \triangle B = B \triangle A$（交换律）
2. $(A \triangle B) \triangle C = A \triangle (B \triangle C)$（结合律）
3. $A \triangle \varnothing = A$
4. $A \triangle A = \varnothing$
5. $A \triangle B = \varnothing \iff A = B$

### 3.3.5 广义并和广义交（对集族）

**集族**（Family of Sets）是以集合为元素的集合，例如 $\mathcal{A} = \{A_1, A_2, \dots, A_n\}$。

#### 广义并（Generalized Union）

$$\bigcup \mathcal{A} = \bigcup_{i=1}^{n} A_i = \{x \mid \exists A \in \mathcal{A}, x \in A\}$$

即：属于 $\mathcal{A}$ 中至少一个集合的元素的集合。

**示例**：$\mathcal{A} = \{\{1, 2\}, \{2, 3\}, \{3, 4\}\}$，则 $\bigcup \mathcal{A} = \{1, 2, 3, 4\}$。

#### 广义交（Generalized Intersection）

$$\bigcap \mathcal{A} = \bigcap_{i=1}^{n} A_i = \{x \mid \forall A \in \mathcal{A}, x \in A\}$$

即：同时属于 $\mathcal{A}$ 中所有集合的元素的集合。

**示例**：$\mathcal{A} = \{\{1, 2, 3\}, \{2, 3, 4\}, \{2, 3, 5\}\}$，则 $\bigcap \mathcal{A} = \{2, 3\}$。

**注意**：当 $\mathcal{A} = \varnothing$ 时，$\bigcap \mathcal{A}$ 需特殊处理（在 ZFC 中，$\bigcap \varnothing$ 通常不定义）。

## 3.4 集合恒等式

以下列出 20+ 个重要集合恒等式。每个可用子集法证明（证明 $左 \subseteq 右$ 且 $右 \subseteq 左$）。

### 3.4.1 基本恒等式列表

设 $A, B, C$ 为任意集合，$U$ 为全集，$\varnothing$ 为空集。

| 编号 | 名称 | 恒等式 |
|------|------|--------|
| S1 | 幂等律 | $A \cup A = A$；$A \cap A = A$ |
| S2 | 交换律 | $A \cup B = B \cup A$；$A \cap B = B \cap A$ |
| S3 | 结合律 | $(A \cup B) \cup C = A \cup (B \cup C)$；$(A \cap B) \cap C = A \cap (B \cap C)$ |
| S4 | 分配律 | $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ |
|  |  | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ |
| S5 | 同一律 | $A \cup \varnothing = A$；$A \cap U = A$ |
| S6 | 零律 | $A \cup U = U$；$A \cap \varnothing = \varnothing$ |
| S7 | 排中律 | $A \cup \overline{A} = U$ |
| S8 | 矛盾律 | $A \cap \overline{A} = \varnothing$ |
| S9 | 德摩根律 | $\overline{A \cup B} = \overline{A} \cap \overline{B}$ |
|  |  | $\overline{A \cap B} = \overline{A} \cup \overline{B}$ |
| S10 | 吸收律 | $A \cup (A \cap B) = A$；$A \cap (A \cup B) = A$ |
| S11 | 补余律 | $\overline{\overline{A}} = A$ |
| S12 | 差集恒等式 | $A - B = A \cap \overline{B}$ |
| S13 | 对称差 | $A \triangle B = (A \cup B) - (A \cap B) = (A - B) \cup (B - A)$ |
| S14 | | $A \cup (B - A) = A \cup B$ |
| S15 | | $A \cap (B - A) = \varnothing$ |
| S16 | | $A - (B \cup C) = (A - B) \cap (A - C)$ |
| S17 | | $A - (B \cap C) = (A - B) \cup (A - C)$ |
| S18 | | $(A \cup B) - C = (A - C) \cup (B - C)$ |
| S19 | | $(A \cap B) - C = (A - C) \cap (B - C)$ |
| S20 | 对称差展开 | $A \triangle B = (A \cap \overline{B}) \cup (\overline{A} \cap B)$ |

### 3.4.2 恒等式证明示例

**证明 S4（分配律）**：$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$

（一）证 $A \cup (B \cap C) \subseteq (A \cup B) \cap (A \cup C)$：

任取 $x \in A \cup (B \cap C)$，则：
- 若 $x \in A$，则 $x \in A \cup B$ 且 $x \in A \cup C$，故 $x \in (A \cup B) \cap (A \cup C)$。
- 若 $x \in B \cap C$，则 $x \in B$ 且 $x \in C$，故 $x \in A \cup B$ 且 $x \in A \cup C$，即 $x \in (A \cup B) \cap (A \cup C)$。

因此 $A \cup (B \cap C) \subseteq (A \cup B) \cap (A \cup C)$。

（二）证 $(A \cup B) \cap (A \cup C) \subseteq A \cup (B \cap C)$：

任取 $x \in (A \cup B) \cap (A \cup C)$，则 $x \in A \cup B$ 且 $x \in A \cup C$。
- 若 $x \in A$，则 $x \in A \cup (B \cap C)$。
- 若 $x \notin A$，则由 $x \in A \cup B$ 知 $x \in B$；由 $x \in A \cup C$ 知 $x \in C$。故 $x \in B \cap C$，从而 $x \in A \cup (B \cap C)$。

因此 $(A \cup B) \cap (A \cup C) \subseteq A \cup (B \cap C)$。

由（一）（二）得证。$\square$

**证明 S9（德摩根律）**：$\overline{A \cup B} = \overline{A} \cap \overline{B}$

$$
\begin{aligned}
x \in \overline{A \cup B}
&\iff x \notin A \cup B \\
&\iff \neg(x \in A \lor x \in B) \\
&\iff \neg(x \in A) \land \neg(x \in B) \quad \text{（命题逻辑德摩根律）} \\
&\iff x \notin A \land x \notin B \\
&\iff x \in \overline{A} \land x \in \overline{B} \\
&\iff x \in \overline{A} \cap \overline{B}
\end{aligned}
$$

> 可以看到，集合恒等式的证明本质上归结为[[01-命题逻辑|命题逻辑]]中等价式的证明。

**证明 S10（吸收律）**：$A \cap (A \cup B) = A$

（一）$A \cap (A \cup B) \subseteq A$：由交集定义，显然成立。

（二）$A \subseteq A \cap (A \cup B)$：任取 $x \in A$，则 $x \in A \cup B$（因为 $A \subseteq A \cup B$），故 $x \in A \cap (A \cup B)$。

因此 $A \cap (A \cup B) = A$。$\square$

## 3.5 有序对与笛卡尔积

### 3.5.1 有序对

**定义**（库拉托夫斯基有序对）：$(a, b) = \{\{a\}, \{a, b\}\}$

有序对的核心性质：$(a, b) = (c, d) \iff a = c \land b = d$

> 注意区分 $\{a, b\} = \{b, a\}$（无序对）与 $(a, b) \neq (b, a)$（除非 $a = b$）。

### 3.5.2 笛卡尔积

**定义**：集合 $A$ 与 $B$ 的**笛卡尔积**（Cartesian Product）是所有可能的有序对 $(a, b)$ 构成的集合，其中 $a \in A$，$b \in B$。

$$A \times B = \{(a, b) \mid a \in A \land b \in B\}$$

**示例**：
- $A = \{1, 2\}$，$B = \{a, b, c\}$
- $A \times B = \{(1, a), (1, b), (1, c), (2, a), (2, b), (2, c)\}$

**基数**：$|A \times B| = |A| \cdot |B|$

**性质**：
1. $A \times \varnothing = \varnothing \times A = \varnothing$
2. 一般 $A \times B \neq B \times A$（不满足交换律）
3. $(A \times B) \cap (C \times D) = (A \cap C) \times (B \cap D)$
4. $(A \times B) \cup (C \times D) \subseteq (A \cup C) \times (B \cup D)$（通常不等）
5. $A \times (B \cup C) = (A \times B) \cup (A \times C)$（分配律）
6. $A \times (B \cap C) = (A \times B) \cap (A \times C)$（分配律）
7. $A \times (B - C) = (A \times B) - (A \times C)$

### 3.5.3 $n$ 元有序组

**递归定义**：
- $n = 2$：$(a_1, a_2)$ 是有序对。
- $n \geq 3$：$(a_1, a_2, \dots, a_n) = ((a_1, \dots, a_{n-1}), a_n)$

$n$ 个集合的笛卡尔积：

$$A_1 \times A_2 \times \dots \times A_n = \{(a_1, a_2, \dots, a_n) \mid a_i \in A_i, i = 1, \dots, n\}$$

特别地，$A^n = \underbrace{A \times A \times \dots \times A}_{n \text{ 个}}$。

**示例**：
- $\mathbb{R}^2 = \mathbb{R} \times \mathbb{R}$（平面上的点）
- $\mathbb{R}^3 = \mathbb{R} \times \mathbb{R} \times \mathbb{R}$（三维空间中的点）
- $\mathbb{B}^n = \{0, 1\}^n$（$2^n$ 个元素，即所有 $n$ 位二进制串）

## 3.6 集合的计数与容斥原理

### 3.6.1 两集合容斥原理

$$|A \cup B| = |A| + |B| - |A \cap B|$$

**直观解释**：分别计算 $|A|$ 和 $|B|$ 时，$A \cap B$ 中的元素被计算了两次，因此需要减去一次。

### 3.6.2 三集合容斥原理

$$
\begin{aligned}
|A \cup B \cup C| &= |A| + |B| + |C| \\
&\quad - |A \cap B| - |A \cap C| - |B \cap C| \\
&\quad + |A \cap B \cap C|
\end{aligned}
$$

**直观解释**：先加所有单集基数，减去两两交集的基数（因为被重复计算），再加回三个集合的交集的基数（因为在前两步被减掉了三次，实际只需减一次）。

### 3.6.3 一般 $n$ 个集合的容斥原理

$$
\left|\bigcup_{i=1}^{n} A_i\right| = \sum_{k=1}^{n} (-1)^{k-1} \sum_{1 \leq i_1 < \dots < i_k \leq n} |A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}|
$$

展开形式（对称形式）：

$$
\left|\bigcup_{i=1}^{n} A_i\right| = \sum_{\varnothing \neq J \subseteq \{1,\dots,n\}} (-1)^{|J|-1} \left|\bigcap_{j \in J} A_j\right|
$$

**符号规则**：奇数个集合的交集前符号为正（$+$），偶数个集合的交集前符号为负（$-$）。

**证明思路**（组合计数论证）：任取 $x \in \bigcup_{i=1}^{n} A_i$，设 $x$ 恰好属于 $m$ 个集合（$m \geq 1$），则 $x$ 在右侧和被计数的总次数为：

$$\binom{m}{1} - \binom{m}{2} + \binom{m}{3} - \dots + (-1)^{m-1}\binom{m}{m} = 1 - (1 - 1)^m = 1$$

因此每个元素恰好被计数一次。$\square$

### 3.6.4 容斥原理应用示例

**例 1**：1 到 100 中能被 3 或 5 整除的整数有多少个？

设 $A = \{x \mid 1 \leq x \leq 100, 3 \mid x\}$，$B = \{x \mid 1 \leq x \leq 100, 5 \mid x\}$。

$|A| = \lfloor\frac{100}{3}\rfloor = 33$，$|B| = \lfloor\frac{100}{5}\rfloor = 20$

$|A \cap B| = \lfloor\frac{100}{15}\rfloor = 6$（能被 3 且 5 整除 → 能被 15 整除）

$|A \cup B| = 33 + 20 - 6 = 47$

**例 2**：三集合问题。某班 50 人，学英语 30 人，学日语 20 人，学法语 15 人；学英+日 10 人，学英+法 7 人，学日+法 5 人；三门都学 3 人。问至少学一门的有多少人？

根据三集合容斥原理：

$|E \cup J \cup F| = 30 + 20 + 15 - 10 - 7 - 5 + 3 = 46$

**补集形式的容斥原理**（计算补集的基数）：

$$\left|\bigcap_{i=1}^{n} \overline{A_i}\right| = |U| - \left|\bigcup_{i=1}^{n} A_i\right| = \sum_{J \subseteq \{1,\dots,n\}} (-1)^{|J|} \left|\bigcap_{j \in J} A_j\right|$$

其中约定 $\bigcap_{j \in \varnothing} A_j = U$。

template<typename T>
vector<set<T>> generate_powerset(const set<T>& S) {
    vector<T> elements(S.begin(), S.end());
    int n = (int)elements.size();
    vector<set<T>> powerSet;
    int total = 1 << n;

    for (int mask = 0; mask < total; mask++) {
        set<T> subset;
        for (int i = 0; i < n; i++) {
            if ((mask >> i) & 1) {
                subset.insert(elements[i]);
            }
        }
        powerSet.push_back(subset);
    }
    return powerSet;
}

        cout << "{";
        bool first = true;
        for (int x : subset) {
            if (!first) cout << ", ";
            cout << x;
            first = false;

    if not sets:
        return {()}
    result = {(x,) for x in sets[0]}
    for s in sets[1:]:
        result = {r + (y,) for r in result for y in s}
    return result

def powerset(s: Set[Any]) -> Set[frozenset]:
    """
    生成集合的幂集 P(s)。
    返回 frozenset 的集合（因为 set 不可哈希）。
    """
    elements = list(s)
    n = len(elements)
    result = set()
    for mask in range(1 << n):  # 0 到 2^n - 1
        subset = frozenset(elements[i] for i in range(n)
                           if (mask >> i) & 1)
        result.add(subset)
    return result

# ============ 容斥原理计算 ============
def inclusion_exclusion(sets: List[Set[Any]],
                        universal: Set[Any] = None) -> int:
    """
    计算 |A1 U A2 U ... U An| 使用容斥原理。
    """
    n = len(sets)
    total = 0
    for k in range(1, n + 1):
        sign = (-1) ** (k - 1)
        for indices in combinations(range(n), k):
            # 计算 k 个集合的交集
            inter = sets[indices[0]]
            for idx in indices[1:]:
                inter = inter & sets[idx]
            total += sign * len(inter)

    if universal is not None:
        complement = len(universal) - total
        print(f"Complement cardinality: {complement}")

    return total

def generalized_union(family: List[Set[Any]]) -> Set[Any]:
    """广义并"""
    if not family:
        return set()
    return set.union(*family)


def generalized_intersection(family: List[Set[Any]]) -> Set[Any]:
    """广义交"""
    if not family:
        return set()
    result = family[0].copy()
    for s in family[1:]:
        result &= s
    return result

def verify_set_laws():
    """用随机集合验证集合恒等式"""
    import random
    U = set(range(20))  # 全集
    A = set(random.sample(list(U), 8))
    B = set(random.sample(list(U), 8))
    C = set(random.sample(list(U), 8))
    Ac = U - A   # A 的补集

    # 德摩根律
    assert (U - (A | B)) == ((U - A) & (U - B)), "De Morgan 1 failed"
    assert (U - (A & B)) == ((U - A) | (U - B)), "De Morgan 2 failed"

    # 分配律
    assert A | (B & C) == (A | B) & (A | C), "Distributive 1 failed"
    assert A & (B | C) == (A & B) | (A & C), "Distributive 2 failed"

    # 吸收律
    assert A | (A & B) == A, "Absorption 1 failed"
    assert A & (A | B) == A, "Absorption 2 failed"

    print("All set identity verifications passed!")
