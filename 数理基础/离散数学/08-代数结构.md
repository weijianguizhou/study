# 第08章：代数结构 (Algebraic Structures)

> 代数结构是数学抽象化的核心——将具体运算（加法、乘法、函数复合等）抽象为集合上的二元运算，研究其公理化性质。

---

## 8.1 代数系统的基本概念

### 8.1.1 二元运算

**定义8.1（二元运算）**：设 $S$ 是一个非空集合。一个**二元运算(Binary Operation)** $*$ 是从 $S\times S$ 到 $S$ 的一个映射：

$$* : S \times S \to S, \quad (a,b) \mapsto a * b$$

**性质**：

| 性质 | 定义 | 含义 |
|:---|:---|:---|
| **封闭性(Closure)** | $\forall a,b\in S,\; a*b \in S$ | 运算结果仍在集合中(封闭性是二元运算定义的一部分) |
| **结合律(Associative)** | $\forall a,b,c\in S,\; (a*b)*c = a*(b*c)$ | 运算次序不影响结果 |
| **交换律(Commutative)** | $\forall a,b\in S,\; a*b = b*a$ | 运算次序可交换 |

**例子**：
- $(\mathbb{N}, +)$：封闭、结合、交换。
- $(\mathbb{N}, -)$：不封闭（$2-3\notin\mathbb{N}$），不结合（$(a-b)-c \neq a-(b-c)$），不交换。
- $(\mathbb{R}^n, \text{向量加法})$：封闭、结合、交换。
- $(M_n(\mathbb{R}), \times)$（矩阵乘法）：封闭、结合，但**不交换**。

### 8.1.2 特殊元素

**定义8.2（幺元/单位元）**：设 $(S,*)$ 是代数系统。元素 $e\in S$ 称为：

- **左幺元**：$\forall a\in S,\; e*a = a$
- **右幺元**：$\forall a\in S,\; a*e = a$
- **幺元(Identity)**：既是左幺元又是右幺元。

**定理8.1（幺元的唯一性）**：若幺元存在，则幺元唯一。

**证明**：设 $e_1, e_2$ 都是幺元。则

$$e_1 = e_1 * e_2 = e_2$$

（第一个等号：$e_2$ 是右幺元；第二个等号：$e_1$ 是左幺元）

$\blacksquare$

---

**定义8.3（零元）**：设 $(S,*)$ 是代数系统。元素 $\theta \in S$ 称为：

- **左零元**：$\forall a\in S,\; \theta * a = \theta$
- **右零元**：$\forall a\in S,\; a * \theta = \theta$
- **零元(Zero Element)**：既是左零元又是右零元。

**定理8.2（零元的唯一性）**：若零元存在，则零元唯一（证明类似幺元）。

**例子**：在 $(\mathbb{R}, \times)$ 中，$1$ 是幺元，$0$ 是零元。

---

**定义8.4（逆元）**：设 $(S,*)$ 有幺元 $e$。对于 $a \in S$，若存在 $b\in S$ 使得：

- **左逆元**：$b*a = e$
- **右逆元**：$a*b = e$
- **逆元(Inverse)**：$b$ 既为左逆元又为右逆元，记作 $a^{-1}$。

**定理8.3（逆元的唯一性）**：若运算满足结合律且有幺元，则每个元素最多有一个逆元。

**证明**：设 $b,c$ 都是 $a$ 的逆元：

$$b = b*e = b*(a*c) = (b*a)*c = e*c = c$$

$\blacksquare$

---

**补充性质**：

**幂等元(Idempotent)**：元素 $x$ 满足 $x*x=x$。幺元 $e$ 是幂等元；在群中，幺元是**唯一**的幂等元。

**可约元(Cancelable)**：元素 $a$ 若满足 $\forall x,y\, (a*x=a*y \Rightarrow x=y)$，则称 $a$ 是左可约的。

### 8.1.3 代数系统与子代数

**定义8.5（代数系统）**：非空集合 $S$ 连同其上定义的一个或多个二元运算称为一个**代数系统(Algebraic System)**，记作 $(S, *_1, *_2, \dots)$。

**定义8.6（子代数）**：设 $(S,*)$ 是代数系统，$T\subseteq S$ 非空。若 $T$ 关于 $*$ 封闭（即 $\forall a,b\in T,\; a*b\in T$），则 $(T,*)$ 称为 $(S,*)$ 的**子代数(Subalgebra)**。

### 8.1.4 群的定义（总览）

| 结构 | 条件 | 英文 |
|:---|:---|:---|
| **广群(Groupoid)** | 封闭性 | Magma / Groupoid |
| **半群(Semigroup)** | 封闭性 + 结合律 | Semigroup |
| **幺半群(Monoid)** | 半群 + 幺元 | Monoid |
| **群(Group)** | 幺半群 + 每个元素有逆元 | Group |
| **交换群(Abel群)** | 群 + 交换律 | Abelian Group |

$$\boxed{\text{半群} \;\subset\; \text{幺半群} \;\subset\; \text{群} \;\subset\; \text{Abel群}}$$

---

**定义8.7（群）**：代数系统 $(G,*)$ 称为**群(Group)**，当满足：

1. **封闭性**：$\forall a,b\in G,\; a*b \in G$
2. **结合律**：$\forall a,b,c\in G,\; (a*b)*c = a*(b*c)$
3. **幺元存在**：$\exists e\in G,\; \forall a\in G,\; e*a = a*e = a$
4. **逆元存在**：$\forall a\in G,\; \exists a^{-1}\in G,\; a*a^{-1} = a^{-1}*a = e$

若还满足**交换律** $\forall a,b\in G,\; a*b=b*a$，则称为**交换群(Abel群)**。

---

## 8.2 半群与幺半群

### 8.2.1 半群

**定义8.8**：$(S,*)$ 是**半群(Semigroup)**当且仅当 $*$ 封闭且满足结合律。

**常见例子**：
- $(\mathbb{N}, +)$：自然数加法半群。
- $(\mathbb{N}, \times)$：自然数乘法半群。
- $(\mathbb{Z}^+, \max)$：正整数取最大值，结合。
- $(\mathbb{Z}^+, \min)$：正整数取最小值，结合。
- $(M_n(\mathbb{R}), \times)$：$n$ 阶实方阵的乘法半群。
- $(\Sigma^+, \circ)$：非空字符串的拼接操作构成半群。
- $(\{0,1\}, \land)$ 和 $(\{0,1\}, \lor)$：布尔运算构成半群。

**定义8.9（子半群）**：半群 $S$ 的非空子集 $T$，若关于运算封闭，则 $(T,*)$ 是 $S$ 的**子半群(Subsemigroup)**。

**定义8.10（循环半群）**：半群中，若存在元素 $a$ 使得

$$S = \{a^n \mid n\in \mathbb{Z}^+\}$$

则称 $(S,*)$ 为**循环半群(Cyclic Semigroup)**，$a$ 称为**生成元(Generator)**。

- 记 $a^n = \underbrace{a*a*\cdots*a}_{n\text{次}}$。
- 循环半群总是交换的。
- 有限循环半群中必存在幂等元。

**例子**：$(\{2^n \mid n\in \mathbb{N}\}, \times)$ 是循环半群，生成元为 $2$。

### 8.2.2 幺半群

**定义8.11**：$(M,*)$ 是**幺半群(Monoid)**当且仅当 $(M,*)$ 是半群且存在幺元 $e\in M$。

**常见例子**：

| 幺半群 | 运算 | 幺元 |
|:---|:---|:---|
| $(\mathbb{N}_0, +)$ | 加法 | $0$ |
| $(\mathbb{N}, \times)$ | 乘法 | $1$ |
| $(\Sigma^*, \circ)$ | 字符串拼接 | 空串 $\varepsilon$ |
| $(\mathcal{P}(X), \cup)$ | 集合并 | $\emptyset$ |
| $(\mathcal{P}(X), \cap)$ | 集合交 | $X$ |
| $(M_n(\mathbb{R}), \times)$ | 矩阵乘法 | 单位阵 $I_n$ |
| $(\mathbb{Z}_n, \otimes_n)$ | 模 $n$ 乘法 | $\bar{1}$ |

**定义8.12（可逆元）**：幺半群 $M$ 中，元素 $a$ 若存在 $b$ 使得 $a*b=b*a=e$，则 $a$ 称为**可逆元(Invertible Element)** 或**单位(Unit)**。

**例子**：$(M_n(\mathbb{R}),\times)$ 中，可逆元是可逆矩阵（即非奇异矩阵）。

**定理8.4**：幺半群中所有可逆元的集合构成一个群。

## 8.3 群的深入理论

### 8.3.1 群的基本性质

**定理8.5（消去律）**：在群 $(G,*)$ 中，对任意 $a,b,c\in G$：

1. **左消去律**：若 $a*b = a*c$，则 $b = c$。
2. **右消去律**：若 $b*a = c*a$，则 $b = c$。

**证明**：用 $a^{-1}$ 左乘 $a*b=a*c$：

$$a^{-1}*(a*b) = a^{-1}*(a*c) \;\Rightarrow\; (a^{-1}*a)*b = (a^{-1}*a)*c \;\Rightarrow\; e*b = e*c \;\Rightarrow\; b = c$$

右消去律类似。$\blacksquare$

---

**定理8.6（方程可解性）**：在群 $(G,*)$ 中，对任意 $a,b\in G$：

- 方程 $a*x=b$ 有唯一解 $x=a^{-1}*b$。
- 方程 $y*a=b$ 有唯一解 $y=b*a^{-1}$。

**证明**：$a^{-1}*b$ 是解（代入验证）。唯一性由消去律保证。$\blacksquare$

---

**定理8.7**：在群中，幺元是唯一的幂等元。

**证明**：若 $x*x = x$，则 $x = x*e = x*(x*x^{-1}) = (x*x)*x^{-1} = x*x^{-1} = e$。$\blacksquare$

---

**定理8.8**：$(a^{-1})^{-1} = a$，且 $(a*b)^{-1} = b^{-1}*a^{-1}$。

**证明**：$(a*b)*(b^{-1}*a^{-1}) = a*(b*b^{-1})*a^{-1} = a*e*a^{-1} = a*a^{-1}=e$。$\blacksquare$

### 8.3.2 子群

**定义8.13（子群）**：群 $(G,*)$ 的非空子集 $H$，若 $(H,*)$ 也构成群，则 $H$ 称为 $G$ 的**子群(Subgroup)**，记作 $H \leq G$。

- 若 $H\neq G$，称 $H$ 为**真子群(Proper Subgroup)**，记作 $H < G$。
- $\{e\}$ 和 $G$ 本身称为**平凡子群(Trivial Subgroup)**。

**定理8.9（子群判定定理1——一步检验）**：$G$ 的非空子集 $H$ 是子群当且仅当：

$$\forall a,b \in H,\; a*b^{-1} \in H$$

**证明**：
- ($\Rightarrow$) 若 $H\leq G$，则 $b\in H \Rightarrow b^{-1}\in H$，再由封闭性 $a*b^{-1}\in H$。
- ($\Leftarrow$) (1) 取 $a=b$ 得 $e=a*a^{-1}\in H$。(2) 取 $a=e$ 得 $b^{-1}=e*b^{-1}\in H$。(3) 对任意 $a,b\in H$，$b^{-1}\in H$，故 $a*b=a*(b^{-1})^{-1}\in H$。结合律继承自 $G$。

$\blacksquare$

---

**定理8.10（子群判定定理2——两步检验）**：$H\leq G$ 当且仅当 (1) $H$ 非空；(2) 封闭性：$\forall a,b\in H, a*b\in H$；(3) 逆元：$\forall a\in H, a^{-1}\in H$。

**定理8.11（有限子群判定）**：若 $H$ 是 $G$ 的有限非空子集且对运算封闭，则 $H\leq G$。

**证明**：只需证逆元存在。对任意 $a\in H$，由封闭性，$a,a^2,a^3,\dots$ 都在 $H$ 中。$H$ 有限，故存在 $i<j$ 使得 $a^i=a^j$。两边右乘 $(a^i)^{-1}$（在 $G$ 中的逆）得 $e=a^{j-i}$。所以 $a*a^{j-i-1}=e$，即 $a^{-1}=a^{j-i-1}\in H$。$\blacksquare$

**例子**：
- $n\mathbb{Z} = \{nk \mid k\in\mathbb{Z}\} \leq \mathbb{Z}$。
- $SL_n(\mathbb{R}) = \{A\in GL_n(\mathbb{R}) \mid \det A = 1\} \leq GL_n(\mathbb{R})$。
- $\{e\} \leq G$，$G \leq G$。

### 8.3.3 循环群

**定义8.14（循环群）**：群 $G$ 若存在元素 $a\in G$ 使得

$$G = \{a^k \mid k\in \mathbb{Z}\}$$

则称 $G$ 为**循环群(Cyclic Group)**，$a$ 称为**生成元**。记作 $G = \langle a \rangle$。

**定义8.15（元素的阶）**：群中元素 $a$ 的**阶(Order)**，记作 $|a|$ 或 $\text{ord}(a)$，是满足 $a^k=e$ 的最小正整数 $k$。若不存在这样的 $k$，则称 $a$ 的阶为无穷大（无限阶）。

**性质**：

**(1)** 若 $|a|=n$，则循环群 $\langle a \rangle = \{e, a, a^2, \dots, a^{n-1}\}$，且 $|\langle a \rangle| = n$。

**(2)** $a^k = e$ 当且仅当 $n \mid k$（$n$ 为 $a$ 的阶）。

**(3)** $a^k$ 的阶为：

$$\frac{n}{\gcd(n,k)}$$

**(4)** $a^k$ 是 $\langle a \rangle$ 的生成元当且仅当 $\gcd(n,k)=1$。

**(5)** 循环群的子群仍然是循环群。

**(6)** 若 $G=\langle a \rangle$ 是 $n$ 阶循环群，则对 $n$ 的每个正因子 $d$，$G$ 恰有一个 $d$ 阶子群（由 $a^{n/d}$ 生成）。

**重要例子**：
- $(\mathbb{Z}, +)$：无限循环群，生成元为 $1$ 和 $-1$。
- $(\mathbb{Z}_n, \oplus_n)$：$n$ 阶循环群，生成元为所有与 $n$ 互质的元素。个数为 $\varphi(n)$（欧拉函数）。
- 复数乘法群 $\{e^{2\pi i k/n} \mid k=0,1,\dots,n-1\}$：$n$ 次单位根群，循环群。

### 8.3.4 拉格朗日定理

**定义8.16（左陪集）**：设 $H\leq G$，$a\in G$。则

$$aH = \{a*h \mid h\in H\}$$

称为 $H$ 在 $G$ 中的**左陪集(Left Coset)**。类似定义右陪集 $Ha = \{h*a \mid h\in H\}$。

**性质**：
1. $|aH| = |H|$（双射 $h\mapsto ah$）。
2. 任意两个左陪集要么相等，要么不相交。
3. 所有左陪集的并等于 $G$。
4. 因此左陪集构成 $G$ 的一个**划分(Partition)**。

**定理8.12（拉格朗日定理）**：若 $G$ 是有限群，$H\leq G$，则

$$\boxed{|H| \;\big|\; |G|}$$

且商 $[G:H] = |G|/|H|$ 称为 $H$ 在 $G$ 中的**指数(Index)**。

**证明**：左陪集构成 $G$ 的划分，每个陪集大小等于 $|H|$，设共有 $k$ 个不同左陪集，则 $|G|=k\cdot |H|$，即 $|H|$ 整除 $|G|$。$\blacksquare$

---

**推论8.1**：有限群中任意元素 $a$ 的阶 $|a|$ 整除 $|G|$。

**证明**：$\langle a \rangle \leq G$，由拉格朗日定理 $|\langle a \rangle|$ 整除 $|G|$，而 $|a| = |\langle a \rangle|$。$\blacksquare$

---

**推论8.2**：素数阶群必为循环群（从而必为Abel群）。

**证明**：设 $|G|=p$ 为素数，取 $a\in G, a\neq e$，则 $|\langle a \rangle|$ 整除 $p$，且 $|\langle a \rangle|>1$，故 $|\langle a \rangle|=p$，即 $G=\langle a \rangle$。$\blacksquare$

---

**推论8.3（费马小定理的群论证明）**：对任意 $a\in \mathbb{Z}_p^*$（$p$ 素数），$a^{p-1}\equiv 1 \pmod p$。

**证明**：$|\mathbb{Z}_p^*|=p-1$，由推论8.1，$|a|$ 整除 $p-1$，设 $p-1 = k\cdot|a|$，则 $a^{p-1}=(a^{|a|})^k = 1^k = 1$。$\blacksquare$

### 8.3.5 正规子群与商群

**定义8.17（正规子群）**：子群 $N \leq G$ 称为**正规子群(Normal Subgroup)**，若对任意 $g\in G$：

$$gNg^{-1} = N \quad \text{（即 }\forall g\in G,\forall n\in N,\; gng^{-1}\in N\text{）}$$

记作 $N \trianglelefteq G$。若还 $N\neq G$，记作 $N \triangleleft G$。

- Abel群的任何子群都是正规子群。
- 对任意同态 $\varphi: G\to H$，$\ker\varphi \trianglelefteq G$。
- 指数为2的子群必为正规子群。

**定义8.18（商群）**：设 $N \trianglelefteq G$。在左陪集的集合 $G/N = \{aN \mid a\in G\}$ 上定义运算：

$$(aN)*(bN) = (ab)N$$

则 $(G/N, *)$ 构成群，称为 $G$ 关于 $N$ 的**商群(Factor Group / Quotient Group)**。

- 商群的幺元是 $eN=N$。
- $aN$ 的逆元是 $a^{-1}N$。
- 若 $G$ 有限，$|G/N| = |G|/|N| = [G:N]$。

**例子**：$n\mathbb{Z} \trianglelefteq \mathbb{Z}$，商群 $\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}_n$。

### 8.3.6 群同态与同构定理

**定义8.19（同态）**：设 $(G,*)$ 和 $(H,\circ)$ 是群。映射 $\varphi: G\to H$ 称为**群同态(Group Homomorphism)**，若：

$$\forall a,b\in G,\; \varphi(a*b) = \varphi(a)\circ \varphi(b)$$

**定义8.20（核与像）**：
- **核(Kernel)**：$\ker\varphi = \{g\in G \mid \varphi(g)=e_H\}$。$\ker\varphi \trianglelefteq G$。
- **像(Image)**：$\operatorname{im}\varphi = \{\varphi(g) \mid g\in G\}$。$\operatorname{im}\varphi \leq H$。

**性质**：
- $\varphi$ 是单射当且仅当 $\ker\varphi = \{e_G\}$。
- $\varphi$ 保持幺元：$\varphi(e_G)=e_H$。
- $\varphi$ 保持逆元：$\varphi(a^{-1}) = (\varphi(a))^{-1}$。

**定义8.21（同构）**：若 $\varphi$ 是双射，则称 $\varphi$ 为**同构(Isomorphism)**，$G$ 与 $H$ **同构**，记作 $G\cong H$。

---

**定理8.13（第一同构定理）**：设 $\varphi: G\to H$ 是群同态，则

$$\boxed{G / \ker\varphi \;\cong\; \operatorname{im}\varphi}$$

**证明思路**：定义 $\psi: G/\ker\varphi \to \operatorname{im}\varphi$ 为 $\psi(gK)=\varphi(g)$（其中 $K=\ker\varphi$）。需证 $\psi$ 是良定义的、同态、单射、满射。

**定理8.14（第二同构定理）**：设 $H\leq G$，$N\trianglelefteq G$，则 $H\cap N \trianglelefteq H$ 且 $HN/N \cong H/(H\cap N)$。

**定理8.15（第三同构定理）**：设 $M\trianglelefteq G$，$N\trianglelefteq G$，且 $M\subseteq N$，则 $N/M \trianglelefteq G/M$ 且 $(G/M)/(N/M) \cong G/N$。

**定理8.16（Cayley定理）**：任意群 $G$ 同构于某个对称群的子群。特别地，若 $|G|=n$，则 $G$ 同构于 $S_n$ 的某个子群。

**证明思路**：对每个 $g\in G$，定义左乘变换 $\lambda_g: G\to G$，$\lambda_g(x)=gx$。$\lambda_g$ 是 $G$ 上的一个置换。映射 $g\mapsto \lambda_g$ 给出了 $G\to S_{|G|}$ 的单同态。

## 8.4 置换群

### 8.4.1 置换的表示

**定义8.22（置换）**：有限集合 $X=\{1,2,\dots,n\}$ 上的**置换(Permutation)**是一个双射 $\sigma: X\to X$。

常用Cauchy双行表示法或单行表示法：

$$\sigma = \begin{pmatrix}
1 & 2 & 3 & 4 & 5 \\
3 & 1 & 5 & 2 & 4
\end{pmatrix}$$

表示 $\sigma(1)=3,\sigma(2)=1,\sigma(3)=5,\sigma(4)=2,\sigma(5)=4$。

**定义8.23（轮换）**：长度为 $k$ 的**轮换(Cycle)** $(a_1\;a_2\;\cdots\;a_k)$ 表示置换：

$$a_1\mapsto a_2,\; a_2\mapsto a_3,\;\dots,\; a_{k-1}\mapsto a_k,\; a_k\mapsto a_1$$

其余元素不动。

- $k=1$ 为恒等置换（常省略）。
- $k=2$ 为**对换(Transposition)**。

**定理8.17（轮换分解定理）**：每个置换可以唯一（不计轮换次序和循环移位）地分解为不相交轮换的乘积。

**例子**：$\begin{pmatrix}1&2&3&4&5&6\\ 3&1&5&6&2&4\end{pmatrix} = (1\;3\;5\;2)(4\;6)$

**定理8.18**：每个置换可以表示为对换的乘积。表示不唯一，但对换个数的**奇偶性**唯一。

**证明概要**：对轮换 $(a_1\;a_2\;\cdots\;a_k) = (a_1\;a_k)(a_1\;a_{k-1})\cdots(a_1\;a_2)$。

### 8.4.2 对称群与交错群

**定义8.24（对称群）**：$n$ 元集合上所有置换关于置换复合运算构成群，称为 $n$ 次**对称群(Symmetric Group)**，记作 $S_n$。

$$|S_n| = n!$$

**定义8.25（奇偶性）**：
- **奇置换(Odd Permutation)**：可分解为奇数个对换的乘积。
- **偶置换(Even Permutation)**：可分解为偶数个对换的乘积。
- 置换的**符号(Sign)**：$\operatorname{sgn}(\sigma)=+1$（偶）或 $-1$（奇）。

**定义8.26（交错群）**：$S_n$ 中所有偶置换构成的子群称为 $n$ 次**交错群(Alternating Group)**，记作 $A_n$。

$$|A_n| = \frac{n!}{2} \quad (n\geq 2)$$

$A_n \trianglelefteq S_n$（指数为2）。

**重要事实**：
- $S_3 \cong D_3$（6阶非Abel群，同构于正三角形二面体群）。
- $A_3 \cong \mathbb{Z}_3$（3阶循环群）。
- $A_n$（$n\geq 5$）是单群（无非平凡正规子群）。

**定理8.19**：$n$ 次交错群可由所有长度为3的轮换生成。

## 8.5 环

### 8.5.1 环的定义

**定义8.27（环）**：代数系统 $(R,+,\cdot)$ 称为**环(Ring)**，若：

1. $(R,+)$ 是**Abel群**（加法幺元记作 $0$，$a$ 的加法逆元记作 $-a$）。
2. $(R,\cdot)$ 是**半群**（乘法满足封闭性和结合律）。
3. **分配律**成立：
   $$\forall a,b,c\in R,\; 
   \begin{aligned}
   a\cdot(b+c) &= a\cdot b + a\cdot c \quad \text{（左分配律）} \\
   (a+b)\cdot c &= a\cdot c + b\cdot c \quad \text{（右分配律）}
   \end{aligned}$$

**环中的基本计算**：
- $0\cdot a = a\cdot 0 = 0$
- $(-a)\cdot b = a\cdot (-b) = -(a\cdot b)$
- $(-a)\cdot (-b) = a\cdot b$

### 8.5.2 环的类型

| 环的类型 | 额外条件 |
|:---|:---|
| **交换环(Commutative Ring)** | 乘法满足交换律：$a\cdot b = b\cdot a$ |
| **含幺环(Ring with Unity)** | 乘法有幺元 $1$，且 $1\neq 0$ |
| **无零因子环** | 若 $a\cdot b = 0$，则 $a=0$ 或 $b=0$ |
| **整环(Integral Domain)** | 交换含幺环 + 无零因子 |
| **除环/体(Division Ring)** | 含幺环 + 每个非零元 $a$ 有乘法逆元 $a^{-1}$ |
| **域(Field)** | 交换的除环 |

$$\boxed{\text{域} \;\subset\; \text{除环} \;\subset\; \text{含幺环}}$$

$$\boxed{\text{域} \;\subset\; \text{整环} \;\subset\; \text{交换含幺环} \;\subset\; \text{环}}$$

### 8.5.3 零因子与整环

**定义8.28（零因子）**：环 $R$ 中，非零元 $a$ 称为**左零因子(Left Zero Divisor)**，若存在 $b\neq 0$ 使得 $a\cdot b = 0$。类似定义右零因子。统称为**零因子(Zero Divisor)**。

**例子**：
- 在 $\mathbb{Z}_6$ 中，$\bar{2} \cdot \bar{3} = \bar{6} = \bar{0}$，故 $\bar{2}$ 和 $\bar{3}$ 是零因子。
- 在 $M_2(\mathbb{R})$ 中，$\begin{pmatrix}1&0\\0&0\end{pmatrix}\begin{pmatrix}0&0\\1&0\end{pmatrix}=0$，故这两个矩阵是零因子。

**定理8.20**：$\mathbb{Z}_n$ 是整环 $\iff$ $\mathbb{Z}_n$ 是域 $\iff$ $n$ 是素数。

**定理8.21**：有限整环必为域。

**证明**：设 $R$ 是有限整环，$|R|=n$。对任意 $a\in R,a\neq 0$，映射 $x\mapsto a\cdot x$ 是 $R\to R$ 的单射（若 $a\cdot x=a\cdot y$，则 $a(x-y)=0$，由无零因子得 $x-y=0$）。有限集的单射即双射，故存在 $b$ 使得 $a\cdot b=1$，即 $a$ 有乘法逆元。$\blacksquare$

**常见例子总览**：

| 结构 | 例子 |
|:---|:---|
| 非交换环 | $M_n(\mathbb{R})$，四元数 $\mathbb{H}$ |
| 交换环（非整环） | $\mathbb{Z}_6, \mathbb{Z}\times\mathbb{Z}$ |
| 整环（非域） | $\mathbb{Z}, \mathbb{R}[x]$（多项式环） |
| 除环（非域） | 四元数 $\mathbb{H}$ |
| 域 | $\mathbb{Q},\mathbb{R},\mathbb{C},\mathbb{Z}_p$ |

### 8.5.4 子环与理想

**定义8.29（子环）**：环 $R$ 的非空子集 $S$，若 $(S,+,\cdot)$ 也构成环，则 $S$ 是 $R$ 的**子环(Subring)**。

**定义8.30（理想）**：环 $R$ 的子环 $I$ 称为**左理想**，若 $\forall r\in R,\forall i\in I,\; r\cdot i\in I$（吸收性）。类似定义右理想。既是左理想又是右理想的称为**理想(Ideal)**（或双理想）。

- 在交换环中，左理想和右理想重合。
- $I\trianglelefteq R$ 是理想的判据：$I\neq\emptyset$，$\forall a,b\in I,\;a-b\in I$，$\forall r\in R,\forall a\in I,\;r\cdot a\in I$ 且 $a\cdot r\in I$。

**例子**：
- $n\mathbb{Z} = \{nk \mid k\in\mathbb{Z}\}$ 是 $\mathbb{Z}$ 的理想。
- 多项式环 $\mathbb{R}[x]$ 中以 $0$ 为根的多项式集合 $\{f\in\mathbb{R}[x]\mid f(0)=0\}$ 是理想。

## 8.6 域

### 8.6.1 域的定义

**定义8.31（域）**：代数系统 $(F,+,\cdot)$ 称为**域(Field)**，若：

1. $(F,+)$ 是Abel群（幺元 $0$）
2. $(F\setminus\{0\}, \cdot)$ 是Abel群（幺元 $1$）
3. 乘法对加法满足分配律

等价地说，域是**交换除环**。

### 8.6.2 子域与素域

- **子域(Subfield)**：域的子集在同一运算下也构成域。
- **素域(Prime Field)**：不含真子域的域。
- **特征(Characteristic)**：域 $F$ 的特征 $\operatorname{char}(F)$ 是满足 $n\cdot 1=0$ 的最小正整数 $n$；若无此类 $n$，则 $\operatorname{char}(F)=0$。

**定理8.22**：域的特征要么为0，要么为素数。

### 8.6.3 有限域（Galois域）

**定理8.23**：有限域的阶（元素个数）必为 $p^n$，其中 $p$ 是素数（域的特征），$n$ 是正整数。

**定理8.24**：对每个素数幂 $q=p^n$，存在唯一（同构意义下）的 $q$ 元有限域，记作 $\text{GF}(q)$ 或 $\mathbb{F}_q$。

- $\text{GF}(p) \cong \mathbb{Z}_p$。
- $\text{GF}(p^n)$ 的加法群同构于 $(\mathbb{Z}_p)^n$。
- $\text{GF}(p^n)$ 的乘法群 $\text{GF}(p^n)^*$ 是 $p^n-1$ 阶**循环群**。

**例子——构造 $\text{GF}(4)$**：

$$\text{GF}(4) \cong \mathbb{Z}_2[x] / (x^2+x+1)$$

元素：$\{0, 1, \alpha, \alpha+1\}$，其中 $\alpha^2+\alpha+1=0$（在 $\mathbb{Z}_2$ 中即 $\alpha^2=\alpha+1$）。

| $+$ | 0 | 1 | $\alpha$ | $\alpha+1$ |
|:---|:---|:---|:---|:---|
| 0 | 0 | 1 | $\alpha$ | $\alpha+1$ |
| 1 | 1 | 0 | $\alpha+1$ | $\alpha$ |
| $\alpha$ | $\alpha$ | $\alpha+1$ | 0 | 1 |
| $\alpha+1$ | $\alpha+1$ | $\alpha$ | 1 | 0 |

| $\times$ | 0 | 1 | $\alpha$ | $\alpha+1$ |
|:---|:---|:---|:---|:---|
| 0 | 0 | 0 | 0 | 0 |
| 1 | 0 | 1 | $\alpha$ | $\alpha+1$ |
| $\alpha$ | 0 | $\alpha$ | $\alpha+1$ | 1 |
| $\alpha+1$ | 0 | $\alpha+1$ | 1 | $\alpha$ |

## 8.7 格 (Lattice)

### 8.7.1 格作为偏序集

**定义8.32（格）**：偏序集 $(L, \preceq)$ 若满足任意两个元素 $a,b\in L$ 都有：

- **最小上界（上确界/并）**：记作 $a\vee b$（读作"$a$ join $b$"），满足 $a\preceq a\vee b$，$b\preceq a\vee b$，且对任意满足 $a\preceq c$ 和 $b\preceq c$ 的 $c$，有 $a\vee b\preceq c$。
- **最大下界（下确界/交）**：记作 $a\wedge b$（读作"$a$ meet $b$"），满足 $a\wedge b\preceq a$，$a\wedge b\preceq b$，且对任意满足 $c\preceq a$ 和 $c\preceq b$ 的 $c$，有 $c\preceq a\wedge b$。

则称 $(L,\preceq)$ 为**格(Lattice)**。

**例子**：
- $(\mathcal{P}(X), \subseteq)$ 是格：$A\vee B = A\cup B$，$A\wedge B = A\cap B$。
- $(\mathbb{N}, \mid)$（整除偏序）是格：$a\vee b = \operatorname{lcm}(a,b)$，$a\wedge b = \gcd(a,b)$。
- $(\mathbb{Z}, \leq)$ 是格（全序集都是格，$a\vee b=\max(a,b)$，$a\wedge b=\min(a,b)$）。
- **子群格**：群 $G$ 的所有子群按包含关系形成的格。

### 8.7.2 格作为代数结构

**定义8.33**：代数系统 $(L, \vee, \wedge)$ 称为**格**，若对任意 $a,b,c\in L$：

1. **交换律**：$a\vee b = b\vee a$，$a\wedge b = b\wedge a$
2. **结合律**：$(a\vee b)\vee c = a\vee(b\vee c)$，$(a\wedge b)\wedge c = a\wedge(b\wedge c)$
3. **吸收律(Absorption)**：$a\vee(a\wedge b)=a$，$a\wedge(a\vee b)=a$

两种定义是等价的（通过 $a\preceq b \iff a\wedge b=a \iff a\vee b=b$ 建立联系）。

### 8.7.3 特殊格

| 类型 | 额外条件 |
|:---|:---|
| **有界格(Bounded Lattice)** | 存在最大元 $1$ 和最小元 $0$ |
| **分配格(Distributive Lattice)** | 对任意 $a,b,c$：$a\wedge(b\vee c) = (a\wedge b)\vee(a\wedge c)$<br>等价地：$a\vee(b\wedge c) = (a\vee b)\wedge(a\vee c)$ |
| **有补格(Complemented Lattice)** | 有界格且每个元素 $a$ 存在**补元(Complement)** $a'$：<br>$a\vee a'=1$，$a\wedge a'=0$ |
| **布尔格(Boolean Lattice)** | 有补分配格 |

布尔格即布尔代数，将在 [[09-布尔代数|布尔代数]] 中详细讨论。

**典型非分配格**：五边形格 $N_5$ 和菱形格 $M_3$。

**定理8.25（Birkhoff刻画）**：一个格是模格（Modular Lattice）当且仅当它不包含同构于 $N_5$ 的子格。

**定理8.26**：一个格是分配格当且仅当它不包含同构于 $N_5$ 或 $M_3$ 的子格。

## 8.8 编程实现

### 8.8.1 模 $n$ 剩余类的加法和乘法群

```python
import math
from typing import Set, Tuple


def extended_gcd(a: int, b: int) -> Tuple[int, int, int]:
    """扩展欧几里得算法：返回 (g, x, y) 使 ax + by = gcd(a,b)"""
    if b == 0:
        return (a, 1, 0)
    g, x1, y1 = extended_gcd(b, a % b)
    return (g, y1, x1 - (a // b) * y1)


class Z_n:
    """模 n 剩余类环"""
    def __init__(self, n: int):
        if n < 1:
            raise ValueError("n 必须为正整数")
        self.n = n

    def add(self, a: int, b: int) -> int:
        return (a + b) % self.n

    def neg(self, a: int) -> int:
        return (-a) % self.n

    def mul(self, a: int, b: int) -> int:
        return (a * b) % self.n

    def inv_mul(self, a: int) -> int:
        """乘法逆元（需 gcd(a,n)=1）"""
        g, x, _ = extended_gcd(a, self.n)
        if g != 1:
            raise ValueError(f"{a} 与 {self.n} 不互质，无乘法逆元")
        return x % self.n

    def add_group(self) -> Set[int]:
        """加法群：整个 Z_n"""
        return set(range(self.n))

    def mul_group(self) -> Set[int]:
        """乘法群：与 n 互质的元素"""
        return {a for a in range(1, self.n) if math.gcd(a, self.n) == 1}

    def is_field(self) -> bool:
        """判定是否为域（即 n 为素数）"""
        if self.n <= 1:
            return False
        return all(self.n % i != 0 for i in range(2, int(math.isqrt(self.n)) + 1))

    def cayley_table_add(self) -> str:
        """加法凯莱表"""
        header = "+ | " + " ".join(f"{i:2}" for i in range(self.n))
        rows = [header]
        for i in range(self.n):
            row = f"{i:1} | " + " ".join(f"{self.add(i, j):2}" for j in range(self.n))
            rows.append(row)
        return "\n".join(rows)

    def cayley_table_mul_units(self) -> str:
        """乘法群凯莱表"""
        units = sorted(self.mul_group())
        header = "× | " + " ".join(f"{u:2}" for u in units)
        rows = [header]
        for a in units:
            row = f"{a:1} | " + " ".join(f"{self.mul(a, b):2}" for b in units)
            rows.append(row)
        return "\n".join(rows)


# 示例
if __name__ == "__main__":
    z7 = Z_n(7)
    print(f"Z_7 是域？ {z7.is_field()}")
    print(f"Z_7 乘法群：{z7.mul_group()}")
    print(f"3的乘法逆元 mod 7：{z7.inv_mul(3)}")
    print("\nZ_7 加法表：")
    print(z7.cayley_table_add())
    print("\nZ_7 乘法群表：")
    print(z7.cayley_table_mul_units())
```

### 8.8.2 置换的表示与运算

```python
from typing import List, Tuple, Dict


class Permutation:
    """n 元置换"""

    def __init__(self, mapping: Dict[int, int]):
        self.n = max(mapping.keys(), default=0)
        # 未显式指定的元素映射到自身
        self.mapping = {i: mapping.get(i, i) for i in range(1, self.n + 1)}

    def __call__(self, x: int) -> int:
        return self.mapping.get(x, x)

    def __mul__(self, other: "Permutation") -> "Permutation":
        """置换复合：(σ·τ)(x) = σ(τ(x))"""
        all_keys = set(self.mapping.keys()) | set(other.mapping.keys())
        new_map = {i: self(other(i)) for i in all_keys}
        return Permutation(new_map)

    def __pow__(self, k: int) -> "Permutation":
        """置换的幂"""
        if k == 0:
            return Permutation.identity(self.n)
        if k < 0:
            return (self.inverse()) ** (-k)
        result = Permutation.identity(self.n)
        base = self
        while k:
            if k & 1:
                result = result * base
            base = base * base
            k >>= 1
        return result

    def inverse(self) -> "Permutation":
        """逆置换"""
        inv_map = {v: k for k, v in self.mapping.items()}
        return Permutation(inv_map)

    def to_cycles(self) -> List[Tuple[int, ...]]:
        """分解为不相交轮换"""
        visited = set()
        cycles = []
        for start in range(1, self.n + 1):
            if start in visited:
                continue
            cycle = []
            cur = start
            while cur not in visited:
                visited.add(cur)
                cycle.append(cur)
                cur = self.mapping[cur]
            if len(cycle) > 1:
                cycles.append(tuple(cycle))
        return cycles

    def to_transpositions(self) -> List[Tuple[int, int]]:
        """分解为对换的乘积"""
        trans = []
        for cycle in self.to_cycles():
            # (a1 a2 ... ak) = (a1 ak)(a1 a_{k-1})...(a1 a2)
            for i in range(len(cycle) - 1, 0, -1):
                trans.append((cycle[0], cycle[i]))
        return trans

    def parity(self) -> int:
        """奇偶性：0=偶置换，1=奇置换"""
        return len(self.to_transpositions()) % 2

    def order(self) -> int:
        """置换的阶 = 各轮换长度的 LCM"""
        from math import lcm
        lengths = [len(c) for c in self.to_cycles()]
        if not lengths:
            return 1
        result = lengths[0]
        for L in lengths[1:]:
            result = result * L // math.gcd(result, L)
        return result

    def is_identity(self) -> bool:
        return all(self.mapping[i] == i for i in self.mapping)

    @staticmethod
    def identity(n: int) -> "Permutation":
        return Permutation({i: i for i in range(1, n + 1)})

    @staticmethod
    def from_cycle(cycle: Tuple[int, ...]) -> "Permutation":
        """从轮换构造置换"""
        n = max(cycle) if cycle else 0
        mapping = {}
        k = len(cycle)
        for idx in range(k):
            mapping[cycle[idx]] = cycle[(idx + 1) % k]
        return Permutation(mapping)

    def __repr__(self):
        cycles = self.to_cycles()
        if not cycles:
            return "id"
        return " · ".join(
            "(" + " ".join(str(x) for x in c) + ")" for c in cycles
        )


# 示例
if __name__ == "__main__":
    sigma = Permutation({1: 2, 2: 3, 3: 1, 4: 5, 5: 4})
    print(f"σ = {sigma}")                      # (1 2 3) · (4 5)
    print(f"对换分解：{sigma.to_transpositions()}")  # [(1, 3), (1, 2), (4, 5)]
    print(f"奇偶性：{sigma.parity()}")          # 1 (奇)
    print(f"σ的阶：{sigma.order()}")            # lcm(3,2)=6
    print(f"σ的逆：{sigma.inverse()}")          # (1 3 2) · (4 5)
    print(f"σ^2 = {sigma ** 2}")               # (1 3 2)
```

```python
import math
from typing import List, Set, Dict


def generators_of_Z_n(n: int) -> List[int]:
    """Z_n 加法群的所有生成元"""
    return [k for k in range(1, n) if math.gcd(k, n) == 1]


def order_of_element_in_Z_n(n: int, a: int) -> int:
    """元素 a 在 Z_n 加法群中的阶"""
    if a % n == 0:
        return 1
    g = math.gcd(a, n)
    return n // g


def subgroups_of_Z_n(n: int) -> Dict[int, List[int]]:
    """Z_n 的所有子群：(子群阶 → 子群元素列表)"""
    subgroups = {}
    for d in range(1, n + 1):
        if n % d == 0:
            g = n // d  # 生成元
            subgroup = sorted((k * g) % n for k in range(d))
            subgroups[d] = subgroup
    return subgroups


def cyclic_group_info(n: int) -> None:
    """打印 Z_n 的完整信息"""
    print(f"Z_{n} 是 {n} 阶循环群")
    print(f"  生成元（共 φ({n})={len(generators_of_Z_n(n))} 个）：{generators_of_Z_n(n)}")
    print(f"  子群：")
    for order, elements in subgroups_of_Z_n(n).items():
        print(f"    {order} 阶：{elements}")
```

### 8.8.4 子群判定

```python
from typing import Set, Callable


def is_subgroup_one_step(G: Set, op: Callable, inv: Callable,
                         H: Set) -> bool:
    """一步检验法：a * b^{-1} ∈ H"""
    if not H or not H.issubset(G):
        return False
    for a in H:
        for b in H:
            if op(a, inv(b)) not in H:
                return False
    return True


def is_subgroup_two_step(G: Set, op: Callable, inv: Callable,
                         H: Set) -> bool:
    """两步检验法：封闭性 + 逆元"""
    if not H or not H.issubset(G):
        return False
    for a in H:
        if inv(a) not in H:
            return False
        for b in H:
            if op(a, b) not in H:
                return False
    return True


def is_subgroup_finite(G: Set, op: Callable, H: Set) -> bool:
    """有限子群判定：仅需封闭性"""
    if not H or not H.issubset(G):
        return False
    for a in H:
        for b in H:
            if op(a, b) not in H:
                return False
    return True


def is_normal_subgroup(G: Set, op: Callable, inv: Callable,
                       H: Set) -> bool:
    """判定 H ∘ G（正规子群）：gHg^{-1} ⊆ H"""
    if not is_subgroup_one_step(G, op, inv, H):
        return False
    for g in G:
        for h in H:
            if op(op(g, h), inv(g)) not in H:  # ghg^{-1}
                return False
    return True


# 示例：Z_6 加法群，验证 H={0,2,4} 是否为子群/正规子群
Z6 = set(range(6))
add = lambda a, b: (a + b) % 6
inv = lambda a: (-a) % 6
H = {0, 2, 4}

print(f"H 一步检验：{is_subgroup_one_step(Z6, add, inv, H)}")   # True
print(f"H 两步检验：{is_subgroup_two_step(Z6, add, inv, H)}")   # True
print(f"H 有限检验：{is_subgroup_finite(Z6, add, H)}")          # True
print(f"H 是正规子群？{is_normal_subgroup(Z6, add, inv, H)}")   # True (Abel群)
```

## 总结

| 结构 | 定义关键条件 | 经典例子 |
|:---|:---|:---|
| **半群** | 封闭 + 结合律 | $(\mathbb{N},+), (\Sigma^+,\circ)$ |
| **幺半群** | 半群 + 幺元 | $(\mathbb{N}_0,+), (\Sigma^*,\circ)$ |
| **群** | 幺半群 + 每个元素有逆元 | $(\mathbb{Z},+), S_n, GL_n(\mathbb{R})$ |
| **Abel群** | 群 + 交换律 | $(\mathbb{Z},+), (\mathbb{Z}_n,\oplus)$ |
| **环** | Abel加法群 + 半群乘法 + 分配律 | $(\mathbb{Z},+,\times)$ |
| **整环** | 交换含幺环 + 无零因子 | $\mathbb{Z}, \mathbb{Z}[x]$ |
| **除环** | 含幺环 + 非零元可逆 | 四元数 $\mathbb{H}$ |
| **域** | 交换除环 | $\mathbb{Q},\mathbb{R},\mathbb{C},\mathbb{Z}_p$ |
| **格** | 偏序集中任意两元有上下确界 | $(\mathcal{P}(X),\subseteq)$ |

**五大核心定理**：

| 定理 | 内容 |
|:---|:---|
| **拉格朗日定理** | 子群阶整除群阶，推论：元素的阶整除群的阶 |
| **Cayley定理** | 每个群同构于某个对称群的子群 |
| **第一同构定理** | $G/\ker\varphi \cong \operatorname{im}\varphi$ |
| **循环群结构定理** | $n$ 阶循环群对每个 $d\mid n$ 恰有一个 $d$ 阶子群 |
| **有限整环即域** | 有限整环必为域 |
