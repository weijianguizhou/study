# 离散数学 · 学习笔记索引

## 学习路线建议

### 先修知识
- **高中数学**：代数运算、初等数论基础、排列组合基础
- **基础编程**：至少掌握 C++ 或 Python 的基本语法（用于代码实现部分）

### 建议学习顺序

**第一阶段（基础）**：第 01 → 02 → 03 → 04 章
- 命题逻辑与集合论是所有后续章节的语言基础

**第二阶段（结构与计数）**：第 05 → 06 → 07 → 08 → 09 章
- 图论与树是数据结构的基础；组合数学为概率论铺路

**第三阶段（高级主题）**：第 10 → 11 → 12 章
- 递推与生成函数是算法分析的重要工具
- 初等数论是密码学的基础
- 算法与计算理论是理论计算机科学的入门

### 学习建议

1. **先学逻辑**（第1章）：离散数学的语言就是逻辑，必须先掌握
2. **边学边编程**：每章的编程实现部分建议自己动手敲一遍
3. **关注联系**：注意各章之间的交叉引用（如生成函数解递推、数论用于密码学）
4. **做习题**：每章末尾的 `## 习题与思考` 必须完成，这是巩固概念的唯一方式
5. **参考经典教材**：本笔记为学习辅助，建议配合 Rosen 教材同步阅读
