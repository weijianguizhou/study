# 数值积分与微分

## 1. 数值积分的基本理论与构造原理

### 1.1 问题的数学表述

考虑定积分

$$I(f) = \int_a^b f(x) \, dx$$

当被积函数 $f(x)$ 的原函数无法用初等函数表示，或 $f$ 仅由离散数据给出时，需使用数值积分方法。数值积分的一般形式为**求积公式**（quadrature rule）：

$$Q_n(f) = \sum_{i=0}^{n} w_i f(x_i) \approx I(f)$$

其中 $\{x_i\} \subset [a,b]$ 为求积节点，$\{w_i\}$ 为求积系数（权），$n$ 为节点数。

称 $E_n(f) = I(f) - Q_n(f)$ 为求积误差（截断误差）。

### 1.2 代数精度

> **定义 1.1（代数精度）**：若求积公式对所有次数 $\le m$ 的多项式精确成立（$E_n(p) = 0$），而存在某个 $m+1$ 次多项式使 $E_n(p) \neq 0$，则称该求积公式具有 $m$ 次代数精度。

代数精度是衡量求积公式精度的重要指标。由于积分是线性泛函，测试代数精度只需验证 $f(x) = 1, x, x^2, \ldots, x^m$ 精确成立即可。

> **定理 1.2**：$n+1$ 个节点的插值型求积公式至少具有 $n$ 次代数精度。当节点为 Gauss 节点时可达 $2n+1$ 次。

### 1.3 插值型求积公式

构造求积公式的基本方法是用插值多项式逼近被积函数。设 $P_n(x)$ 为 $f(x)$ 在节点 $\{x_i\}$ 上的 Lagrange 插值多项式：

$$f(x) = P_n(x) + R_n(x) = \sum_{i=0}^{n} f(x_i) l_i(x) + \frac{f^{(n+1)}(\xi_x)}{(n+1)!}\omega_{n+1}(x)$$

积分得：

$$\int_a^b f(x) dx = \sum_{i=0}^{n} \left(\int_a^b l_i(x) dx\right) f(x_i) + \int_a^b R_n(x) dx$$

因此求积系数为

$$w_i = \int_a^b l_i(x) dx,\quad i = 0, 1, \ldots, n$$

此即**插值型求积公式**。其截断误差为 $E_n(f) = \int_a^b R_n(x) dx$。

## 2. Newton-Cotes 公式

### 2.1 等距节点的插值型求积

将 $[a,b]$ 等分为 $n$ 份，步长 $h = \frac{b-a}{n}$，节点 $x_i = a + ih$。此时

$$w_i = \int_a^b l_i(x) dx = h \int_0^n \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{s - j}{i - j} ds$$

令 $C_i^{(n)} = \frac{w_i}{b-a}$ 为**Cotes 系数**，则 Newton-Cotes 公式为：

$$\int_a^b f(x) dx \approx (b-a) \sum_{i=0}^{n} C_i^{(n)} f(x_i)$$

Cotes 系数具有对称性：$C_i^{(n)} = C_{n-i}^{(n)}$ 且 $\sum_{i=0}^{n} C_i^{(n)} = 1$。

### 2.2 梯形公式（$n = 1$）

$$T(f) = \frac{b-a}{2}[f(a) + f(b)] = \frac{h}{2}[f(a) + f(b)],\quad h = b-a$$

**代数精度**：1次。

**几何意义**：用梯形面积近似曲边梯形面积。

> **定理 2.2（梯形公式误差）**：若 $f \in C^2[a,b]$，则存在 $\xi \in (a,b)$ 使得
>
> $$E_T = I(f) - T(f) = -\frac{(b-a)^3}{12}f''(\xi) = -\frac{h^3}{12}f''(\xi)$$

*证明*：由插值余项积分得

$$E_T = \int_a^b \frac{f''(\xi_x)}{2!}(x-a)(x-b) dx$$

注意到 $(x-a)(x-b) \le 0$ 对 $x \in [a,b]$ 恒成立，由积分中值定理即得。$\square$

### 2.3 Simpson 公式（$n = 2$）

$$S(f) = \frac{h}{3}[f(a) + 4f(a+h) + f(b)],\quad h = \frac{b-a}{2}$$

**代数精度**：3次（值得注意的是Simpson公式对三次多项式精确成立，代数精度比节点数"多了1级"）。

> **定理 2.3（Simpson 公式误差）**：若 $f \in C^4[a,b]$，则存在 $\xi \in (a,b)$ 使得
>
> $$E_S = I(f) - S(f) = -\frac{h^5}{90}f^{(4)}(\xi) = -\frac{(b-a)^5}{2880}f^{(4)}(\xi)$$

Simpson 公式是实际中应用最广泛的低阶 Newton-Cotes 公式。

### 2.4 Newton-Cotes 公式的通用形式

| $n$ | 名称 | Cotes系数 | 代数精度 |
|:---:|:---:|:---:|:---:|
| 1 | 梯形公式 | $\frac{1}{2}, \frac{1}{2}$ | 1 |
| 2 | Simpson公式 | $\frac{1}{6}, \frac{4}{6}, \frac{1}{6}$ | 3 |
| 3 | Simpson 3/8公式 | $\frac{1}{8}, \frac{3}{8}, \frac{3}{8}, \frac{1}{8}$ | 3 |
| 4 | Cotes公式 | $\frac{7}{90}, \frac{32}{90}, \frac{12}{90}, \frac{32}{90}, \frac{7}{90}$ | 5 |

**高次 Newton-Cotes 公式的数值不稳定性**：当 $n \ge 8$ 时，Cotes 系数出现正负交替且绝对值较大，导致舍入误差严重放大，因此高阶 Newton-Cotes 公式很少直接使用。通常使用复合低阶公式。

## 3. 复合求积公式与收敛阶

### 3.1 复合梯形公式

将 $[a,b]$ 分为 $n$ 个等长小区间，在每个小区间上应用梯形公式并求和：

$$T_n = \frac{h}{2}\left[f(a) + 2\sum_{i=1}^{n-1} f(x_i) + f(b)\right],\quad h = \frac{b-a}{n}$$

> **定理 3.1**：若 $f \in C^2[a,b]$，则存在 $\eta \in (a,b)$ 使得
>
> $$E_{T_n} = I(f) - T_n = -\frac{(b-a)h^2}{12} f''(\eta) = O(h^2)$$

因此复合梯形公式为**二阶方法**。

### 3.2 复合 Simpson 公式

将 $[a,b]$ 分为 $n$ 个等长小区间（$n$ 为偶数），每两区间应用一次 Simpson 公式：

$$S_n = \frac{h}{3}\left[f(a) + 4\sum_{i=1,3,5,\ldots}^{n-1} f(x_i) + 2\sum_{i=2,4,6,\ldots}^{n-2} f(x_i) + f(b)\right],\quad h = \frac{b-a}{n}$$

> **定理 3.2**：若 $f \in C^4[a,b]$，则
>
> $$E_{S_n} = I(f) - S_n = -\frac{(b-a)h^4}{180} f^{(4)}(\eta) = O(h^4)$$

复合 Simpson 公式为**四阶方法**。

### 3.3 Euler-Maclaurin 求和公式

这是复合梯形公式的理论根基。

> **定理 3.3（Euler-Maclaurin）**：若 $f \in C^{2m+2}[a,b]$，则
>
> $$T_n = I(f) + \sum_{k=1}^{m} \frac{B_{2k}}{(2k)!} h^{2k} [f^{(2k-1)}(b) - f^{(2k-1)}(a)] + O(h^{2m+2})$$
>
> 其中 $B_{2k}$ 为 Bernoulli 数：$B_2 = \frac{1}{6}, B_4 = -\frac{1}{30}, B_6 = \frac{1}{42}, \ldots$

Euler-Maclaurin 公式揭示：对充分光滑的周期函数，复合梯形公式有**谱精度**（指数收敛）；且此公式是 Romberg 外推的理论基础。

## 4. Romberg 积分

### 4.1 Richardson 外推思想

设近似量 $A(h)$ 有如下渐近展开：

$$A(h) = A^* + c_1 h^p + c_2 h^{2p} + \cdots$$

取半步长 $h/2$：

$$A(h/2) = A^* + c_1\left(\frac{h}{2}\right)^p + c_2\left(\frac{h}{2}\right)^{2p} + \cdots$$

消去 $h^p$ 项得：

$$A^*(h) = \frac{2^p A(h/2) - A(h)}{2^p - 1} = A^* + d_2 h^{2p} + \cdots$$

> **定理 4.1（Richardson 外推）**：设 $T(h)$ 是复合梯形公式（步长 $h$），由 Euler-Maclaurin 公式，
>
> $$T(h) = I(f) + c_1 h^2 + c_2 h^4 + c_3 h^6 + \cdots$$
>
> 外推公式为：
>
> $$T_k^{(j)} = \frac{4^j T_k^{(j-1)} - T_{k-1}^{(j-1)}}{4^j - 1},\quad j = 1,2,\ldots,k$$
>
> 其中 $T_k^{(0)} = T(h/2^k)$。则 $T_k^{(j)} = I(f) + O(h^{2(j+1)})$。

### 4.2 Romberg 积分算法

Romberg 表如下：

| $k$ | $h$ | $T_k^{(0)}$ | $T_k^{(1)}$ | $T_k^{(2)}$ | $T_k^{(3)}$ | $\cdots$ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | $h_0$ | $T_0^{(0)}$ | | | | |
| 1 | $h_0/2$ | $T_1^{(0)}$ | $T_1^{(1)}$ | | | |
| 2 | $h_0/4$ | $T_2^{(0)}$ | $T_2^{(1)}$ | $T_2^{(2)}$ | | |
| 3 | $h_0/8$ | $T_3^{(0)}$ | $T_3^{(1)}$ | $T_3^{(2)}$ | $T_3^{(3)}$ | |

计算 $T_k^{(0)}$ 的递推公式：

$$T_0^{(0)} = \frac{b-a}{2}[f(a) + f(b)]$$

$$T_k^{(0)} = \frac{1}{2}T_{k-1}^{(0)} + h_k \sum_{i=1,3,5,\ldots}^{2^k-1} f(a + i h_k),\quad h_k = \frac{b-a}{2^k}$$

这一递推利用了 $T_{k-1}^{(0)}$ 已有的函数值，只需求新增中点处的函数值。

最终 $T_k^{(k)}$ 为 $O(h^{2k+2})$ 精度的近似。Romberg 积分以较低的额外计算代价实现了高阶收敛。

## 5. Gauss 求积公式

### 5.1 最优节点选择原理

Newton-Cotes 公式固定了节点为等距点，仅优化权系数。Gauss 求积则**同时优化节点和权系数**，在 $n+1$ 个节点的条件下达到最高代数精度 $2n+1$。

> **定理 5.1**：对于任意给定的 $n+1$ 个节点 $\{x_i\}$ 和权系数 $\{w_i\}$，求积公式的代数精度不超过 $2n+1$。当且仅当节点恰为关于权函数 $w(x)$ 的 $n+1$ 次正交多项式的零点时，代数精度达到 $2n+1$。

### 5.2 Gauss-Legendre 求积公式

以 $w(x) \equiv 1$ 为标准区间 $[-1, 1]$ 上的 Gauss-Legendre 求积：

$$\int_{-1}^{1} f(x) dx \approx \sum_{i=1}^{n} w_i f(x_i)$$

节点 $\{x_i\}$ 为 Legendre 多项式 $P_n(x)$ 的零点。

> **定义 5.2（Legendre 多项式）**：
>
> $$P_n(x) = \frac{1}{2^n n!}\frac{d^n}{dx^n}[(x^2 - 1)^n]\quad\text{(Rodrigues 公式)}$$

满足正交性：$\int_{-1}^{1} P_m(x) P_n(x) dx = \frac{2}{2n+1}\delta_{mn}$。

递推公式：$P_0(x) = 1,\; P_1(x) = x,\; (n+1)P_{n+1}(x) = (2n+1)x P_n(x) - n P_{n-1}(x)$。

**Gauss-Legendre 权系数**：

$$w_i = \frac{2}{(1 - x_i^2)[P_n'(x_i)]^2}$$

计算性质：$w_i > 0$（保证了数值稳定性），$\sum w_i = 2$。

常用 Gauss-Legendre 节点和权值：

| $n$ | 节点 $\pm x_i$ | 权 $w_i$ |
|:---:|:---:|:---:|
| 2 | $\pm 0.5773502692$ | $1.0$ |
| 3 | $0, \pm 0.7745966692$ | $0.8888888889, 0.5555555556$ |
| 4 | $\pm 0.3399810436, \pm 0.8611363116$ | $0.6521451549, 0.3478548451$ |
| 5 | $0, \pm 0.5384693101, \pm 0.9061798459$ | $0.5688888889, 0.4786286705, 0.2369268851$ |

### 5.3 Gauss 求积的误差公式

> **定理 5.3**：若 $f \in C^{2n}[a,b]$，则存在 $\xi \in (a,b)$ 使得
>
> $$E_n^{\text{Gauss}} = \frac{f^{(2n)}(\xi)}{(2n)!} \int_a^b \prod_{i=1}^{n}(x - x_i)^2 dx$$

特别地，对于 $n$ 点 Gauss-Legendre 求积：

$$E_n^{\text{GL}} = \frac{2^{2n+1}(n!)^4}{(2n+1)[(2n)!]^3} f^{(2n)}(\xi),\quad \xi \in (-1,1)$$

### 5.4 区间变换与权函数

一般区间 $[a,b]$ 上的积分通过线性变换映射到 $[-1,1]$：

$$\int_a^b f(x) dx = \frac{b-a}{2} \int_{-1}^{1} f\!\left(\frac{b-a}{2}t + \frac{a+b}{2}\right) dt$$

### 5.5 其他 Gauss 型求积公式

**Gauss-Chebyshev**：权函数 $w(x) = 1/\sqrt{1-x^2}$，区间 $[-1,1]$，节点为 $x_i = \cos\frac{(2i-1)\pi}{2n}$，所有权系数相等 $w_i = \pi/n$。

$$\int_{-1}^{1} \frac{f(x)}{\sqrt{1-x^2}} dx \approx \frac{\pi}{n}\sum_{i=1}^{n} f(x_i)$$

**Gauss-Laguerre**：权函数 $w(x) = e^{-x}$，区间 $[0,\infty)$，节点为 Laguerre 多项式 $L_n(x)$ 的零点。

$$\int_0^\infty e^{-x}f(x) dx \approx \sum_{i=1}^{n} w_i f(x_i)$$

**Gauss-Hermite**：权函数 $w(x) = e^{-x^2}$，区间 $(-\infty,\infty)$，节点为 Hermite 多项式 $H_n(x)$ 的零点。

$$\int_{-\infty}^\infty e^{-x^2}f(x) dx \approx \sum_{i=1}^{n} w_i f(x_i)$$

### 5.6 Gauss-Kronrod 求积与误差估计

Gauss-Kronrod 公式在 $n$ 个 Gauss 节点的基础上添加 $n+1$ 个新节点（Kronrod 节点），使得新求积公式具有 $3n+1$ 次代数精度。其误差估计：

$$|E| \approx (200 |G - K|)^{3/2}$$

其中 $G$ 为 Gauss 结果，$K$ 为 Kronrod 结果。

## 6. 自适应积分法

### 6.1 自适应策略的基本原理

自适应积分根据被积函数的局部行为自动调整步长。以自适应 Simpson 为例：

**核心公式**：在 $[a,b]$ 上，一次 Simpson 近似为 $S(a,b)$，将区间二等分后两次 Simpson 近似和为 $S(a,m) + S(m,b)$。有误差估计：

$$|I - [S(a,m) + S(m,b)]| \approx \frac{1}{15}|S(a,m) + S(m,b) - S(a,b)|$$

**递推策略**：
1. 计算 $S_1 = S(a,b)$
2. 计算 $S_2 = S(a, \frac{a+b}{2}) + S(\frac{a+b}{2}, b)$
3. 若 $|S_2 - S_1| < 15\varepsilon$，则接受结果 $S_2 + \frac{S_2 - S_1}{15}$
4. 否则对左右子区间分别递归

### 6.2 区间二等分的最优性

自适应策略将计算集中于函数变化剧烈区域。对于在奇点附近积分发散的函数（如 $\int_0^1 \frac{1}{\sqrt{x}}dx$），自适应方法可以高效处理，而等步长复合方法则需要极多节点。

## 7. 数值微分

### 7.1 差分逼近的基本理论

用 Taylor 展开分析差分近似的截断误差。

**前向差分**（forward difference）：

$$\begin{aligned} f(x + h) &= f(x) + h f'(x) + \frac{h^2}{2} f''(x) + \frac{h^3}{6} f'''(x) + O(h^4) \end{aligned}$$

$$\Rightarrow f'(x) = \frac{f(x+h) - f(x)}{h} - \frac{h}{2}f''(x) + O(h^2)$$

即前向差分为一阶精度 $O(h)$。

**中心差分**（central difference）：

$$f(x + h) - f(x - h) = 2h f'(x) + \frac{h^3}{3}f'''(x) + O(h^5)$$

$$\Rightarrow f'(x) = \frac{f(x+h) - f(x-h)}{2h} - \frac{h^2}{6}f'''(x) + O(h^4)$$

即中心差分为二阶精度 $O(h^2)$。

**二阶导数中心差分**：

$$f(x+h) - 2f(x) + f(x-h) = h^2 f''(x) + \frac{h^4}{12}f^{(4)}(x) + O(h^6)$$

$$\Rightarrow f''(x) = \frac{f(x+h) - 2f(x) + f(x-h)}{h^2} - \frac{h^2}{12}f^{(4)}(x) + O(h^4)$$

### 7.2 高阶精度差分模板

利用更多点可构造高阶差分格式。五点模板用于一阶导数：

$$f'(x) \approx \frac{-f(x+2h) + 8f(x+h) - 8f(x-h) + f(x-2h)}{12h} + O(h^4)$$

五点模板用于二阶导数：

$$f''(x) \approx \frac{-f(x+2h) + 16f(x+h) - 30f(x) + 16f(x-h) - f(x-2h)}{12h^2} + O(h^4)$$

一般 $2m$ 个点的对称有限差分可通过 Lagrange 插值多项式的导数公式导出。参见上一节 [[插值法]] 中 Newton 差商与逼近导数的联系。

### 7.3 数值微分的 Richardson 外推

与数值积分类似，差分也可用 Richardson 外推提高精度。对于中心差分

$$D(h) = \frac{f(x+h) - f(x-h)}{2h}$$

有渐近展开

$$D(h) = f'(x) + c_1 h^2 + c_2 h^4 + c_3 h^6 + \cdots$$

外推公式：

$$D_k^{(j)} = \frac{2^{2j} D_k^{(j-1)} - D_{k-1}^{(j-1)}}{2^{2j} - 1}$$

### 7.4 数值微分的病态性与最优步长

数值微分是典型的**病态问题**（ill-posed problem）：函数的微小扰动可能导致导数的巨大变化。总误差由截断误差和舍入误差构成。

对于中心差分，截断误差 $\sim \frac{h^2}{6}|f'''(x)|$，舍入误差 $\sim \frac{2\varepsilon}{h}$（$\varepsilon$ 为机器精度），总误差：

$$\text{总误差} \lesssim \frac{h^2}{6}|f'''(x)| + \frac{2\varepsilon}{h}$$

最优步长由差分极小化得出：

$$h_{\text{opt}} \approx \sqrt[3]{\frac{3\varepsilon}{|f'''(x)|}}$$

最小误差 $\sim \varepsilon^{2/3}$。相比之下数值积分为**适定问题**（well-posed），总误差可无界降低。

### 7.5 复步长方法

**复步长导数**（complex-step derivative）通过函数在复平面上的取值计算导数，避免了减法相消：

$$f'(x) \approx \frac{\operatorname{Im}[f(x + i h)]}{h} + O(h^2)$$

该方法的截断误差为 $O(h^2)$，且可取 $h$ 非常小（如 $h = 10^{-100}$）而不受舍入误差影响，在处理复杂函数（如上万行的工程代码）时尤为有效。

### 7.6 多元函数的数值偏导数

对于 $f: \mathbb{R}^d \to \mathbb{R}$：

$$\frac{\partial f}{\partial x_j}(\mathbf{x}) \approx \frac{f(\mathbf{x} + h\mathbf{e}_j) - f(\mathbf{x} - h\mathbf{e}_j)}{2h} + O(h^2)$$

混合偏导数：

$$\frac{\partial^2 f}{\partial x_i \partial x_j} \approx \frac{1}{4h^2}[f(\mathbf{x} + h\mathbf{e}_i + h\mathbf{e}_j) - f(\mathbf{x} + h\mathbf{e}_i - h\mathbf{e}_j) - f(\mathbf{x} - h\mathbf{e}_i + h\mathbf{e}_j) + f(\mathbf{x} - h\mathbf{e}_i - h\mathbf{e}_j)] + O(h^2)$$

Hessian 矩阵的全部元素可通过 $O(d^2)$ 次函数求值得到。在大规模优化中，常使用**自动微分**（Automatic Differentiation）代替数值差分，以获得精确导数。

### 7.7 样条插值微分

由 [[插值法]] 中的三次样条理论，在子区间 $[x_i, x_{i+1}]$ 上：

$$S_i'(x) = b_i + 2c_i(x - x_i) + 3d_i(x - x_i)^2$$
$$S_i''(x) = 2c_i + 6d_i(x - x_i)$$

样条导数在数据点处的误差为 $O(h^3)$（一阶导数）和 $O(h^2)$（二阶导数），优于直接差分。

数值积分的本质：将分析中的积分运算转化为代数中的加权求和；数值微分的本质：用局部多项式插值的导数逼近原函数的导数。二者在有限元、谱方法等现代数值方法中统一于**加权残量法**框架。

## 9. 总结

| 方法 | 精度阶 | 代数精度 | 适用范围 | 主要局限 |
|:---|:---|:---|:---|:---|
| 梯形公式 | $O(h^2)$ | 1 | 简单积分 | 精度低 |
| Simpson公式 | $O(h^4)$ | 3 | 光滑函数 | 需偶数子区间 |
| Romberg 积分 | 可任意高 | - | 光滑函数 | 节点成倍增加 |
| Gauss-Legendre | $O(h^{2n})$ | $2n-1$ | 光滑函数 | 需正交多项式零点 |
| 自适应 Simpson | 可变 | - | 含奇点的函数 | 实现复杂 |
| 中心差分 | $O(h^2)$ | - | 导数计算 | 舍入误差放缩 |
| Richardson 外推 | 可任意高 | - | 导数高精度 | 函数需充分光滑 |
| 复步长导数 | $O(h^2)$ | - | 复杂函数导数 | 需复函数支持 |
