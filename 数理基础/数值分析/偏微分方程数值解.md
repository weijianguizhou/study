# 偏微分方程数值解

## 1. 偏微分方程的分类与基本性质

### 1.1 二阶线性 PDE 的分类

考虑一般形式（$n$ 个自变量）：

$$\sum_{i,j=1}^{n} a_{ij} \frac{\partial^2 u}{\partial x_i \partial x_j} + \sum_{i=1}^{n} b_i \frac{\partial u}{\partial x_i} + c u = f$$

其类型由系数矩阵 $A = [a_{ij}]$ 的特征值符号决定：

> **定义 1.1（PDE 分类）**：设 $\lambda_1,\ldots,\lambda_n$ 为 $A$ 的特征值。
> - **椭圆型**（elliptic）：所有 $\lambda_i$ 同号且非零
> - **抛物型**（parabolic）：一个特征值为零，其余同号（退化椭圆型）
> - **双曲型**（hyperbolic）：除一个特征值符号与其余相反外，其余同号
> - **超双曲型**（ultrahyperbolic）：其他情况

### 1.2 三大经典方程

**椭圆型——Poisson 方程**（稳态扩散/位势问题）：

$$\nabla^2 u = -\frac{\partial^2 u}{\partial x^2} - \frac{\partial^2 u}{\partial y^2} = f(x, y)\quad \text{in } \Omega$$

当 $f = 0$ 时为 Laplace 方程 $\nabla^2 u = 0$。

**抛物型——热传导方程**（扩散过程）：

$$\frac{\partial u}{\partial t} = \alpha \nabla^2 u = \alpha\left(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2}\right)$$

**双曲型——波动方程**（波传播）：

$$\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u$$

### 1.3 定解条件

**初始条件**（抛物型和双曲型）：
- $u(x, 0) = u_0(x)$ （初始状态）
- $u_t(x, 0) = v_0(x)$ （双曲型还需初始速度）

**边界条件**：
- **Dirichlet**（第一类）：$u|_{\partial\Omega} = g$
- **Neumann**（第二类）：$\frac{\partial u}{\partial \mathbf{n}}|_{\partial\Omega} = g$
- **Robin**（第三类）：$\alpha u + \beta \frac{\partial u}{\partial \mathbf{n}}|_{\partial\Omega} = g$

### 1.4 适定性

> **定理 1.2（Hadamard 意义下的适定性）**：PDE 问题适定当且仅当解存在、唯一、且连续依赖于给定数据。

椭圆型方程的 Dirichlet 问题在适当光滑条件下适定；对抛物型，初边值问题适定；对双曲型，初值问题（Cauchy 问题）适定。

## 2. 有限差分法（Finite Difference Method, FDM）

### 2.1 网格与差分算子

在矩形区域上引入均匀网格：

$$\begin{aligned} x_i &= i\Delta x, \quad i = 0,1,\ldots,N_x \\ y_j &= j\Delta y, \quad j = 0,1,\ldots,N_y \\ t_n &= n\Delta t, \quad n = 0,1,\ldots,N_t \end{aligned}$$

记 $u_{i,j}^n \approx u(x_i, y_j, t_n)$。

**基本差分算子**（一维为例）：

前向差分：$\Delta_+ u_i = u_{i+1} - u_i$、$\delta_+ u_i = (u_{i+1} - u_i)/h$

后向差分：$\Delta_- u_i = u_i - u_{i-1}$、$\delta_- u_i = (u_i - u_{i-1})/h$

中心差分：$\Delta_0 u_i = u_{i+1} - u_{i-1}$、$\delta_0 u_i = (u_{i+1} - u_{i-1})/(2h)$

二阶中心差分：$\delta^2 u_i = (u_{i+1} - 2u_i + u_{i-1})/h^2$

### 2.2 Laplace/Poisson 方程的五点差分格式

对于 $\nabla^2 u = -f$，有

$$\frac{u_{i+1,j} - 2u_{i,j} + u_{i-1,j}}{\Delta x^2} + \frac{u_{i,j+1} - 2u_{i,j} + u_{i,j-1}}{\Delta y^2} = -f_{i,j}$$

若 $\Delta x = \Delta y = h$，则有著名的**五点模板**：

$$-\frac{1}{h^2}(u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1} - 4u_{i,j}) = f_{i,j}$$

> **定理 2.1（五点格式的截断误差）**：若 $u \in C^4$，则局部截断误差为 $O(h^2)$。

此离散格式导出形如 $A\mathbf{u} = \mathbf{f}$ 的稀疏线性方程组。$A$ 为对称正定的块三对角矩阵（具有 M-矩阵性质），可用共轭梯度法或多重网格法高效求解。参见 [[线性方程组迭代法]]。

### 2.3 热传导方程的差分格式

#### 显式格式（Forward Time, Centered Space, FTCS）

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} = \alpha \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2}$$

整理得：

$$u_i^{n+1} = u_i^n + r(u_{i+1}^n - 2u_i^n + u_{i-1}^n)$$

其中 $r = \alpha \Delta t / \Delta x^2$ 为无量纲数（Fourier 数）。

**稳定性条件**：$r \le 1/2$。

#### 隐式格式（Backward Time, Centered Space）

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} = \alpha \frac{u_{i+1}^{n+1} - 2u_i^{n+1} + u_{i-1}^{n+1}}{\Delta x^2}$$

即：

$$-r u_{i-1}^{n+1} + (1 + 2r) u_i^{n+1} - r u_{i+1}^{n+1} = u_i^n$$

每时间层需求解三对角线性方程组，但**无条件稳定**。

#### Crank-Nicolson 格式

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} = \frac{\alpha}{2}\left(\frac{u_{i+1}^{n+1} - 2u_i^{n+1} + u_{i-1}^{n+1}}{\Delta x^2} + \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2}\right)$$

Crank-Nicolson 格式对时间和空间均为二阶精度 $O(\Delta t^2 + \Delta x^2)$，且无条件稳定。

### 2.4 $	heta$ 方法

将显式和隐式统一于单参数族：

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} = \alpha\left[\theta \frac{u_{i+1}^{n+1} - 2u_i^{n+1} + u_{i-1}^{n+1}}{\Delta x^2} + (1-\theta)\frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2}\right]$$

- $\theta = 0$：显式 Euler
- $\theta = 1/2$：Crank-Nicolson（梯形法则）
- $\theta = 1$：全隐式

$\theta$ 方法的稳定性条件：当 $\theta \ge 1/2$ 时无条件稳定；当 $\theta < 1/2$ 则要求 $r \le 1/(2-4\theta)$。

### 2.5 波动方程的差分格式

双曲型方程 $\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$ 的显式格式：

$$\frac{u_i^{n+1} - 2u_i^n + u_i^{n-1}}{\Delta t^2} = c^2 \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2}$$

整理：

$$u_i^{n+1} = 2u_i^n - u_i^{n-1} + s^2(u_{i+1}^n - 2u_i^n + u_{i-1}^n)$$

其中 $s = c\Delta t/\Delta x$ 为 CFL 数。

**CFL 条件**：$s \le 1$。此即 Courant-Friedrichs-Lewy 条件，是格式稳定的必要条件。

初始速度条件的离散（虚拟时间层法）：

$$u_i^1 = u_i^0 + \Delta t \, v_0(x_i) + \frac{s^2}{2}(u_{i+1}^0 - 2u_i^0 + u_{i-1}^0)$$

### 2.6 对流方程的迎风格式

对一阶双曲型方程（输运方程）$\frac{\partial u}{\partial t} + a \frac{\partial u}{\partial x} = 0$：

中心差分会引起非物理振荡。**迎风格式**（upwind scheme）根据流速方向选择单边差分：

$$u_i^{n+1} = u_i^n - \frac{a\Delta t}{\Delta x}\begin{cases} u_i^n - u_{i-1}^n, & a > 0 \\ u_{i+1}^n - u_i^n, & a < 0 \end{cases}$$

此格式一阶精度，但满足**单调性**和**TVD**（Total Variation Diminishing）性质。

## 3. Von Neumann 稳定性分析

### 3.1 基本原理

Von Neumann（Fourier）稳定性分析假设数值解可展开为 Fourier 模态：

$$u_j^n = G^n e^{i k j \Delta x}$$

其中 $G$ 为**放大因子**（amplification factor），$k$ 为波数。稳定性要求 $|G| \le 1$ 对所有 $k$ 成立（严格要求 $|G| \le 1 + C\Delta t$）。

### 3.2 各格式的放大因子

**FTCS 格式**（热传导）：

将 $u_j^n = G^n e^{i k j \Delta x}$ 代入离散方程：

$$G = 1 + r(e^{i k \Delta x} - 2 + e^{-i k \Delta x}) = 1 - 4r \sin^2\left(\frac{k \Delta x}{2}\right)$$

要求 $|G| \le 1$ 对所有 $k$ 成立，得 $|1 - 4r \sin^2(\theta/2)| \le 1$，即 $r \le 1/2$。

**隐式格式**（热传导）：

$$G = \frac{1}{1 + 4r \sin^2(k \Delta x / 2)} \in [0, 1]$$

**无条件稳定**。

**Crank-Nicolson**：

$$G = \frac{1 - 2r \sin^2(k \Delta x / 2)}{1 + 2r \sin^2(k \Delta x / 2)}$$

$|G| \le 1$ 对所有 $r > 0$ 成立，无条件稳定。

**波动方程显式格式**：

$$G^2 - 2[1 - 2s^2 \sin^2(k \Delta x / 2)] G + 1 = 0$$

当 $s^2 \le 1$ 时，$|G| = 1$（无耗散，仅有色散）；当 $s^2 > 1$ 时，$|G| > 1$（不稳定）。即 CFL 条件 $s \le 1$。

### 3.3 稳定性条件汇总

| 格式 | 方程类型 | 稳定性条件 | 精度 |
|:---|:---|:---|:---|
| FTCS | 热传导 | $r \le 1/2$ | $O(\Delta t, \Delta x^2)$ |
| 隐式 | 热传导 | 无条件稳定 | $O(\Delta t, \Delta x^2)$ |
| Crank-Nicolson | 热传导 | 无条件稳定 | $O(\Delta t^2, \Delta x^2)$ |
| 显式 | 波动 | $s \le 1$ | $O(\Delta t^2, \Delta x^2)$ |
| 迎风 | 对流 | $\text{CFL} \le 1$ | $O(\Delta t, \Delta x)$ |

### 3.4 矩阵稳定性分析

Von Neumann 分析假设无限域/周期边界条件，适用于初值问题。对于更一般的边界条件，需要矩阵稳定性分析：离散方程可写为 $\mathbf{u}^{n+1} = G\mathbf{u}^n$，稳定性要求 $\rho(G) \le 1$（或 $|\lambda_i(G)| \le 1$ 且模为 1 的特征值是单根）。

## 4. CFL 条件与物理直观

### 4.1 CFL 条件的物理起源

> **定理 4.1（CFL 条件）**：对于双曲型方程，数值方法的依赖域必须包含 PDE 真解的依赖域，否则格式不可能收敛。

对波动方程，信息以速度 $c$ 沿特征线 $x = x_0 \pm ct$ 传播。经过 $\Delta t$ 时间，信息传播的距离为 $c\Delta t$。数值格式中，$u_i^{n+1}$ 只依赖于 $\{u_{i-1}^n, u_i^n, u_{i+1}^n\}$。为使数值依赖域覆盖物理依赖域，必须有

$$c\Delta t \le \Delta x \iff s = \frac{c\Delta t}{\Delta x} \le 1$$

### 4.2 色散与耗散误差

数值格式不可避免地引入**色散**（dispersion，不同波数的波速不同）和**耗散**（dissipation，振幅衰减）误差。

- 一阶迎风格式有强数值耗散（人工粘性），会抹平间断
- 中心二阶格式有数值色散，产生伪振荡（Gibbs 现象）
- Crank-Nicolson 对高频分量有弱耗散（$G \to -1$），可能导致时间振荡

## 5. 有限元方法（Finite Element Method, FEM）

### 5.1 变分原理与弱形式

以 Poisson 方程 $-\nabla^2 u = f$ in $\Omega$，$u = 0$ on $\partial\Omega$ 为例。

乘以检验函数 $v \in H_0^1(\Omega)$ 并在 $\Omega$ 上积分：

$$\int_\Omega -\nabla^2 u \, v \, dx = \int_\Omega f v \, dx$$

分部积分（Green 公式）：

$$\int_\Omega \nabla u \cdot \nabla v \, dx - \int_{\partial\Omega} \frac{\partial u}{\partial \mathbf{n}} v \, ds = \int_\Omega f v \, dx$$

由于 $v = 0$ on $\partial\Omega$，边界项消失，得**弱形式**（变分形式）：

$$a(u, v) = (f, v),\quad \forall v \in V$$

其中 $V = H_0^1(\Omega)$（Sobolev 空间），双线性形式 $a(u,v) = \int_\Omega \nabla u \cdot \nabla v \, dx$ 连续且强制的（由 Poincaré 不等式保证）。

由 Lax-Milgram 引理，弱形式存在唯一解 $u \in V$。

### 5.2 Galerkin 逼近

选取有限维子空间 $V_h \subset V$（例如分片多项式空间），求 $u_h \in V_h$ 使得

$$a(u_h, v_h) = (f, v_h),\quad \forall v_h \in V_h$$

令 $\{\phi_1, \ldots, \phi_N\}$ 为 $V_h$ 的一组基（形函数），设 $u_h = \sum_{j=1}^{N} U_j \phi_j$，则

$$\sum_{j=1}^{N} a(\phi_j, \phi_i) U_j = (f, \phi_i),\quad i = 1,\ldots,N$$

即线性方程组

$$K \mathbf{U} = \mathbf{F}$$

其中
- **刚度矩阵**（stiffness matrix）：$K_{ij} = a(\phi_j, \phi_i) = \int_\Omega \nabla \phi_i \cdot \nabla \phi_j \, dx$
- **载荷向量**（load vector）：$F_i = (f, \phi_i) = \int_\Omega f \phi_i \, dx$

$K$ 为稀疏对称正定矩阵。参见 [[矩阵分解]] 中 Cholesky 分解及 [[线性方程组迭代法]] 中共轭梯度法的应用。

### 5.3 三角形单元的形函数与刚度矩阵

对线性三角形单元，三个顶点 $\mathbf{x}_1, \mathbf{x}_2, \mathbf{x}_3$，形函数为

$$\phi_i(\mathbf{x}) = \alpha_i + \beta_i x + \gamma_i y,\quad i = 1,2,3$$

满足 $\phi_i(\mathbf{x}_j) = \delta_{ij}$。

在单元 $K$ 上，$\nabla \phi_i = (\beta_i, \gamma_i)^T$ 为常数，故单元刚度矩阵

$$K_{ij}^{(e)} = \int_K (\beta_i \beta_j + \gamma_i \gamma_j) \, dx = \text{area}(K) \cdot (\beta_i \beta_j + \gamma_i \gamma_j)$$

通过**总体装配**（assembly），将所有单元贡献累加到全局矩阵中。

### 5.4 误差估计与 Céa 引理

> **引理 5.1（Céa 引理）**：设 $a(\cdot,\cdot)$ 为强制连续双线性形式，$u$ 为真解，$u_h$ 为 Galerkin 逼近解，则
>
> $$\|u - u_h\|_V \le \frac{M}{\alpha} \inf_{v_h \in V_h} \|u - v_h\|_V$$
>
> 其中 $M$ 为连续性常数，$\alpha$ 为强制性常数。

这意味着有限元解的误差（在能量范数下）由最佳逼近误差所控制。配合下面插值估计可得收敛阶。

**插值误差估计**：若 $u \in H^{p+1}(\Omega)$ 且使用 $p$ 次多项式单元，则

$$\|u - I_h u\|_{H^1} \le C h^p \|u\|_{H^{p+1}}$$

因此 Galerkin 逼近在 $H^1$ 范数下具有 $p$ 阶收敛性。

### 5.5 Aubin-Nitsche 对偶技巧与 $L^2$ 收敛

通过解对偶问题可得 $L^2$ 意义下的超收敛：

$$\|u - u_h\|_{L^2} \le C h^{p+1} \|u\|_{H^{p+1}}$$

### 5.6 有限元方法的应用框架

FEM 的核心优势在于处理**复杂几何**和**自适应网格细化**。对抛物型问题 $\frac{\partial u}{\partial t} = \nabla^2 u + f$：

- **空间离散**：用 FEM 得到半离散系统 $M \dot{\mathbf{U}} = -K\mathbf{U} + \mathbf{F}$
- **时间离散**：用 ODE 方法（例如 Crank-Nicolson 或 BDF）推进

这正是**方法线**（Method of Lines）的核心思想，将 PDE 数值解与 [[常微分方程数值解]] 联系起来。

参见：
- [[数值积分与微分]] — 弱形式中的 Gauss 求积
- [[矩阵分解]] — 刚度矩阵的 Cholesky、LU 分解
- [[线性方程组迭代法]] — 大规模稀疏系统的迭代求解

## 6. 总结

### 6.1 三类方程数值方法总览

| 方程类型 | 典型代表 | FDM 格式 | FEM 策略 |
|:---|:---|:---|:---|
| 椭圆型 | Poisson | 五点差分 → 线性系统 | 弱形式 → Galerkin → 刚度矩阵 |
| 抛物型 | 热传导 | FTCS / Crank-Nicolson | 半离散 + ODE 时间推进 |
| 双曲型 | 波动 | 显式中心差分 | 半离散 + Newmark / 时间推进 |

### 6.2 方法选择

- **规则区域 + 简单边界**：有限差分法（易实现，精度可控）
- **复杂几何 + 复杂边界**：有限元法（三角剖分灵活）
- **守恒律 + 流体力学**：有限体积法（局部守恒性）
- **高精度 + 光滑问题**：谱方法（指数收敛）

### 6.3 关键原理

- 稳定性、相容性、收敛性三者的 Lax 等价定理是 PDE 数值解的理论支柱
- CFL 条件揭示了显式方法的物理约束
- Von Neumann 分析是判断格式稳定性的标准工具
- 有限元的 Céa 引理将数值误差化为逼近论问题
- 方法线（MOL）统一了空间离散和时间推进
