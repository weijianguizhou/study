# 蒙特卡洛方法

## 一、蒙特卡洛积分的理论基础

### 1.1 大数定律基础

蒙特卡洛方法的核心理论基础是辛钦大数定律 (Khinchin's Weak Law of Large Numbers)。设随机变量 $X$ 的数学期望为 $\mu = \mathbb{E}[X]$，且 $\text{Var}(X) = \sigma^2 < \infty$。对于独立同分布的样本 $\{X_i\}_{i=1}^n$，样本均值

$$\bar{X}_n = \frac{1}{n} \sum_{i=1}^{n} X_i$$

依概率收敛到 $\mu$：

$$\bar{X}_n \xrightarrow{P} \mu, \quad n \to \infty$$

等价地，对任意 $\varepsilon > 0$：

$$\lim_{n \to \infty} P\left(|\bar{X}_n - \mu| > \varepsilon\right) = 0$$

### 1.2 收敛速率分析——$O(1/\sqrt{n})$

蒙特卡洛估计的标准误差由中心极限定理 (Central Limit Theorem, CLT) 给出。根据 Lindeberg-Lévy CLT：

$$\sqrt{n}\left(\bar{X}_n - \mu\right) \xrightarrow{d} N(0, \sigma^2)$$

因此，$\bar{X}_n$ 渐近服从 $N\left(\mu, \frac{\sigma^2}{n}\right)$。标准误差为：

$$\text{SE}(\bar{X}_n) = \frac{\sigma}{\sqrt{n}}$$

这意味着蒙特卡洛估计的误差以速率 $O(n^{-1/2})$ 收敛。**关键性质：此收敛速率与积分维度 $d$ 无关。**

#### 数值积分对比

| 方法 | 收敛速率 | 维度依赖性 |
|------|----------|-----------|
| 蒙特卡洛 | $O(n^{-1/2})$ | 无 |
| 梯形法则 (1D) | $O(n^{-2})$ | $O(n^{-2/d})$ |
| Simpson 法则 (1D) | $O(n^{-4})$ | $O(n^{-4/d})$ |
| Gauss-Legendre (1D) | $O(e^{-cn})$ | $O(e^{-cn^{1/d}})$ |
| 拟蒙特卡洛 (Sobol) | $O(n^{-1} \log^d n)$ | 弱依赖 |

**维度突破点**：当 $d \geq 4$ 时，两个点的梯形法则已慢于蒙特卡洛；当 $d \geq 8$ 时，Simpson 法则也劣于蒙特卡洛。这是蒙特卡洛高维积分的根本优势。

### 1.3 蒙特卡洛积分的基本公式

目标：估计积分 $I = \int_{\Omega} f(\mathbf{x}) \, d\mathbf{x}$。

将积分改写为期望形式。引入任意概率密度 $p(\mathbf{x})$（$p(\mathbf{x}) > 0$ 在 $\Omega$ 上）：

$$I = \int_{\Omega} \frac{f(\mathbf{x})}{p(\mathbf{x})} \cdot p(\mathbf{x}) \, d\mathbf{x} = \mathbb{E}_{p}\left[\frac{f(X)}{p(X)}\right]$$

蒙特卡洛估计为：

$$\hat{I}_n = \frac{1}{n} \sum_{i=1}^{n} \frac{f(X_i)}{p(X_i)}, \quad X_i \sim p(\mathbf{x})$$

#### 均匀采样特例

当 $\Omega = [a, b]$ 且选择 $p(x) = \frac{1}{b-a}$（均匀分布）时：

$$\hat{I}_n = \frac{b-a}{n} \sum_{i=1}^{n} f(X_i), \quad X_i \sim U(a, b)$$

方差分析：

$$\text{Var}(\hat{I}_n) = \frac{(b-a)^2}{n} \text{Var}(f(X)) = \frac{(b-a)^2}{n} \left[\frac{1}{b-a}\int_a^b f^2(x) \, dx - \left(\frac{I}{b-a}\right)^2\right]$$

### 1.4 置信区间构造

由 CLT，$(1-\alpha)$ 水平的渐近置信区间为：

$$\mu \in \left[\bar{X}_n - z_{\alpha/2} \frac{\hat{\sigma}}{\sqrt{n}}, \; \bar{X}_n + z_{\alpha/2} \frac{\hat{\sigma}}{\sqrt{n}}\right]$$

其中 $\hat{\sigma}^2 = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \bar{X}_n)^2$，$z_{\alpha/2}$ 为标准正态分位数。

**精度与样本量关系**：要使精度提高 $10$ 倍（误差减少到 $1/10$），需要 $100$ 倍的样本量。

## 二、随机数生成

### 2.1 伪随机数生成器基础

计算机生成的随机数实质为伪随机数 (Pseudo-Random Numbers)，由确定性递推产生。

#### 线性同余生成器 (Linear Congruential Generator, LCG)

$$X_{n+1} = (a X_n + c) \bmod m$$

其中 $a$ 为乘子，$c$ 为增量，$m$ 为模数。常用参数：$a = 1664525$，$c = 1013904223$，$m = 2^{32}$。

归一化输出：$U_n = X_n / m$。

LCG 的局限：高维空间中样本排列于超平面上（Marsaglia 效应），不适合高维积分。

#### Mersenne Twister (MT19937)

现代标准伪随机数生成器，周期为 $2^{19937} - 1$（Mersenne 素数）。623 维等分布性质 (equidistribution property)，使生成的点在 623 维立方体中均匀分布。

### 2.2 逆变换法 (Inverse Transform Method)

**定理 (Probability Integral Transform)**：设 $F$ 为累积分布函数，其广义逆定义为

$$F^{-1}(u) = \inf\{x : F(x) \geq u\}, \quad u \in (0, 1)$$

若 $U \sim U(0, 1)$，则 $X = F^{-1}(U)$ 的分布函数为 $F$。

**证明**：
$$P(X \leq x) = P(F^{-1}(U) \leq x) = P(U \leq F(x)) = F(x)$$

其中第二等式利用 $F$ 的右连续性（广义逆的性质），第三等式利用 $U$ 的均匀分布。

#### 逆变换法的应用实例

**指数分布** $\text{Exp}(\lambda)$：$F(x) = 1 - e^{-\lambda x}$，$x \geq 0$

$$F^{-1}(u) = -\frac{1}{\lambda} \ln(1 - u) \;\; \overset{1-U \sim U(0,1)}{\Longrightarrow} \;\; X = -\frac{1}{\lambda} \ln(U)$$

**Weibull 分布** $\text{Weibull}(\lambda, k)$：$F(x) = 1 - e^{-(x/\lambda)^k}$

$$F^{-1}(u) = \lambda (-\ln(1-u))^{1/k}$$

**Cauchy 分布** $\text{Cauchy}(0, 1)$：$F(x) = \frac{1}{\pi} \arctan x + \frac{1}{2}$

$$F^{-1}(u) = \tan\left(\pi\left(u - \frac{1}{2}\right)\right)$$

**Pareto 分布** $\text{Pareto}(x_m, \alpha)$：$F(x) = 1 - (x_m/x)^\alpha$

$$F^{-1}(u) = x_m (1-u)^{-1/\alpha}$$

**逆变换法的局限**：要求 $F^{-1}$ 有闭式表达，对正态分布、Gamma 分布等不可直接使用。

### 2.3 Box-Muller 变换

生成标准正态随机数的经典方法。

**原理**：设 $U_1, U_2 \sim U(0, 1)$ 独立，定义

$$Z_0 = \sqrt{-2 \ln U_1} \cos(2\pi U_2)$$
$$Z_1 = \sqrt{-2 \ln U_1} \sin(2\pi U_2)$$

则 $Z_0, Z_1 \sim N(0, 1)$ 且相互独立。

**推导**：将 $(U_1, U_2)$ 映射到 $(R, \Theta)$ 极坐标系：

$$R = \sqrt{-2 \ln U_1}, \quad \Theta = 2\pi U_2$$

$(U_1, U_2)$ 的联合密度为 $\mathbf{1}_{[0,1]^2}(u_1, u_2)$。由变量变换：

$$f_{R,\Theta}(r, \theta) = f_{U_1, U_2}(e^{-r^2/2}, \theta/(2\pi)) \cdot \left|\det\frac{\partial(u_1, u_2)}{\partial(r, \theta)}\right| = 1 \cdot \frac{r e^{-r^2/2}}{2\pi}$$

即 $R$ 的密度为 $r e^{-r^2/2}$（Rayleigh 分布），$\Theta \sim U(0, 2\pi)$ 且独立。由 $Z_0 = R \cos\Theta$，$Z_1 = R \sin\Theta$，利用二维正态分布的性质：

$$f_{Z_0, Z_1}(z_0, z_1) = \frac{1}{2\pi} e^{-(z_0^2 + z_1^2)/2}$$

**Polar 形式 (Marsaglia 方法)**：避免三角函数计算

1. 生成 $(V_1, V_2) \sim U(-1, 1)^2$
2. 计算 $S = V_1^2 + V_2^2$，若 $S \geq 1$ 则拒绝并返回步骤 1
3. 计算 $\sqrt{-2\ln S / S}$，得 $Z_0 = V_1\sqrt{-2\ln S / S}$，$Z_1 = V_2\sqrt{-2\ln S / S}$

接受概率为 $\pi/4 \approx 78.5\%$。

### 2.4 拒绝采样 (Rejection Sampling)

**基本算法**：对目标密度 $f(x)$，选择提案密度 $g(x)$ 和常数 $M$ 使 $f(x) \leq M g(x)$ 对所有 $x$ 成立。

1. 从 $g(x)$ 生成样本 $X^*$
2. 从 $U(0, 1)$ 生成 $U$
3. 若 $U \leq \frac{f(X^*)}{M g(X^*)}$，则接受 $X^*$；否则拒绝并重复

**接受概率**：$P(\text{accept}) = \frac{1}{M}$，因此 $M$ 应尽可能小（最优 $M = \sup_x f(x)/g(x)$）。

**逐点包络**：在不知道 $f$ 在全域上的上界时可用 squeeze 技术——若存在 squeeze 函数 $s(x) \leq f(x) \leq M g(x)$，则先在 squeeze 处快速接受。

**自适应拒绝采样 (ARS)**：对 log-concave 目标分布（$\log f(x)$ 为凹函数），利用分段指数包络自适应构建包络函数。Gilks & Wild (1992) 提出 ARS，是 WinBUGS/OpenBUGS 的核心采样技术。

## 三、重要性采样 (Importance Sampling)

### 3.1 基本原理与无偏性

标准蒙特卡洛从分布 $p(\mathbf{x})$ 抽样估计期望 $\mathbb{E}_p[f(X)]$。重要性采样改为从重要性分布 $q(\mathbf{x})$ 抽样：

$$\mathbb{E}_p[f(X)] = \int f(\mathbf{x}) p(\mathbf{x}) \, d\mathbf{x} = \int f(\mathbf{x}) \frac{p(\mathbf{x})}{q(\mathbf{x})} q(\mathbf{x}) \, d\mathbf{x} = \mathbb{E}_q\left[f(X) \frac{p(X)}{q(X)}\right]$$

其中 $w(\mathbf{x}) = \frac{p(\mathbf{x})}{q(\mathbf{x})}$ 称为重要性权重 (importance weight)。重要性采样估计量：

$$\hat{\mu}_{\text{IS}} = \frac{1}{n} \sum_{i=1}^{n} f(X_i) w(X_i), \quad X_i \sim q$$

**无偏性**：$\mathbb{E}_q[\hat{\mu}_{\text{IS}}] = \mathbb{E}_q[f(X) w(X)] = \mathbb{E}_p[f(X)] = \mu$。

### 3.2 方差分析

$$\text{Var}_q(\hat{\mu}_{\text{IS}}) = \frac{1}{n} \text{Var}_q(f(X) w(X)) = \frac{1}{n} \left[\mathbb{E}_q[f^2(X) w^2(X)] - \mu^2\right]$$

展开：

$$\text{Var}_q(\hat{\mu}_{\text{IS}}) = \frac{1}{n} \left[\int \frac{f^2(\mathbf{x}) p^2(\mathbf{x})}{q(\mathbf{x})} \, d\mathbf{x} - \mu^2\right]$$

**关键结论**：若 $q(\mathbf{x})$ 在 $f(\mathbf{x})p(\mathbf{x})$ 大的区域也大，则方差小；若 $q$ 的尾部比 $f p$ 薄，权重可能无界，方差无穷大。

### 3.3 最优重要性分布

最小化 $\text{Var}_q(\hat{\mu}_{\text{IS}})$ 等价于最小化 $\mathbb{E}_q[f^2(X) w^2(X)]$。由 Jensen 不等式：

$$\mathbb{E}_q[f^2(X) w^2(X)] \geq (\mathbb{E}_q[|f(X)| w(X)])^2 = \left(\int |f(\mathbf{x})| p(\mathbf{x}) \, d\mathbf{x}\right)^2$$

等式成立当且仅当 $f(\mathbf{x}) w(\mathbf{x})$ 为常数（几乎处处），即

$$q^*(\mathbf{x}) = \frac{|f(\mathbf{x})| p(\mathbf{x})}{\int |f(\mathbf{x})| p(\mathbf{x}) \, d\mathbf{x}}$$

最优分布 $q^*$ 使方差为：

$$\text{Var}_{q^*}(\hat{\mu}_{\text{IS}}) = \frac{1}{n} \left[\left(\int |f(\mathbf{x})| p(\mathbf{x}) \, d\mathbf{x}\right)^2 - \mu^2\right]$$

当 $f(\mathbf{x}) \geq 0$ 时，$\text{Var}_{q^*}(\hat{\mu}_{\text{IS}}) = 0$——但 $q^*$ 依赖于未知量 $\int f p \, d\mathbf{x}$（即我们想估计的 $I$），实际中不可行。

### 3.4 自归一化重要性采样 (Self-Normalized IS)

当 $p(\mathbf{x})$ 仅以未归一化形式 $\tilde{p}(\mathbf{x})$ 已知时（贝叶斯推断的常见情况），使用自归一化重要性采样：

$$\hat{\mu}_{\text{SNIS}} = \frac{\sum_{i=1}^{n} f(X_i) \tilde{w}(X_i)}{\sum_{i=1}^{n} \tilde{w}(X_i)} = \frac{\frac{1}{n} \sum_{i=1}^{n} f(X_i) \tilde{w}(X_i)}{\frac{1}{n} \sum_{i=1}^{n} \tilde{w}(X_i)}$$

其中 $\tilde{w}(\mathbf{x}) = \tilde{p}(\mathbf{x}) / q(\mathbf{x})$。

**性质**：
- 渐近无偏（$\hat{\mu}_{\text{SNIS}} \xrightarrow{a.s.} \mu$），但有限样本有偏
- 偏差为 $O(n^{-1})$，比方差 $O(n^{-1/2})$ 更小阶
- 渐近方差：

$$\text{Var}(\hat{\mu}_{\text{SNIS}}) \approx \frac{1}{n} \mathbb{E}_q\left[\tilde{w}^2(X) (f(X) - \mu)^2\right]$$

### 3.5 有效样本量 (Effective Sample Size, ESS)

衡量重要性采样质量的量化指标：

$$\text{ESS} = \frac{\left(\sum_{i=1}^{n} w_i\right)^2}{\sum_{i=1}^{n} w_i^2} = \frac{n}{1 + \text{CV}^2(w)}$$

其中 $\text{CV}(w) = \text{std}(w) / \text{mean}(w)$ 为权重的变异系数。

**解释**：
- $\text{ESS} \approx n$：权重均匀，采样效率高
- $\text{ESS} \ll n$：少数大权重样本主导估计，绝大多数样本浪费
- 当 $\text{ESS} / n < 0.5$ 时，通常需要改进重要性分布

**与方差的关系**：

$$\text{Var}_q(\hat{\mu}_{\text{IS}}) \approx \frac{\sigma_p^2}{n} \cdot \frac{n}{\text{ESS}}$$

即 ESS 降低直接导致方差等比例增大。

## 四、方差缩减技术

### 4.1 对偶变量法 (Antithetic Variates)

**核心思想**：利用负相关变量对来抵消波动。

对每对样本 $(X, \tilde{X})$，若 $\text{Cov}(X, \tilde{X}) < 0$，则

$$\text{Var}\left(\frac{X + \tilde{X}}{2}\right) = \frac{1}{4}\left[\text{Var}(X) + \text{Var}(\tilde{X}) + 2\text{Cov}(X, \tilde{X})\right] < \frac{1}{2}\text{Var}(X)$$

**标准实现**：利用均匀随机数的对称性

$$X = F^{-1}(U), \quad \tilde{X} = F^{-1}(1-U), \quad U \sim U(0,1)$$

估计量：

$$\hat{\mu}_{\text{AV}} = \frac{1}{n} \sum_{i=1}^{n} \frac{f(X_i) + f(\tilde{X}_i)}{2}$$

**方差缩减效果**：当 $f \circ F^{-1}$ 为单调函数时，$f(X)$ 和 $f(\tilde{X})$ 负相关，方差必然减小。在实际问题中，方差缩减因子通常为 $2$ 到 $10$。

### 4.2 控制变量法 (Control Variates)

**基本设定**：设 $h(X)$ 为控制变量，已知 $\mathbb{E}[h(X)] = \mu_h$。

控制变量估计量：

$$\hat{\mu}_{\text{CV}}(c) = \frac{1}{n} \sum_{i=1}^{n} \left[f(X_i) - c\,(h(X_i) - \mu_h)\right]$$

对任意 $c$，$\hat{\mu}_{\text{CV}}(c)$ 无偏（因为 $\mathbb{E}[h(X_i) - \mu_h] = 0$）。

**方差**：

$$\text{Var}(\hat{\mu}_{\text{CV}}(c)) = \frac{1}{n} \left[\text{Var}(f) - 2c\,\text{Cov}(f, h) + c^2 \text{Var}(h)\right]$$

**最优控制系数**：

对 $c$ 求导并令为零：

$$\frac{d}{dc} \text{Var}(\hat{\mu}_{\text{CV}}(c)) = \frac{1}{n} \left[-2\text{Cov}(f, h) + 2c\,\text{Var}(h)\right] = 0$$

$$\Rightarrow \boxed{c^* = \frac{\text{Cov}(f(X), h(X))}{\text{Var}(h(X))}}$$

**最优方差缩减比**：

$$\frac{\text{Var}(\hat{\mu}_{\text{CV}}(c^*))}{\text{Var}(\hat{\mu}_{\text{MC}})} = 1 - \rho_{fh}^2$$

其中 $\rho_{fh} = \text{Corr}(f(X), h(X))$。若 $\rho_{fh} = 0.9$，方差缩减到原来的 $19\%$（约 $5$ 倍）。

**实践中**：$c^*$ 通常需从样本估计——使用 pilot run 的所有样本估计协方差和方差，再用于主估计。

### 4.3 分层抽样 (Stratified Sampling)

**原理**：将积分域 $\Omega$ 划分为 $K$ 个互不重叠的层 $\Omega_1, \ldots, \Omega_K$（$\bigcup_k \Omega_k = \Omega$，$\Omega_i \cap \Omega_j = \emptyset$）。设第 $k$ 层的概率为 $p_k = P(X \in \Omega_k)$。

全期望公式：$\mu = \mathbb{E}[f(X)] = \sum_{k=1}^{K} p_k \mathbb{E}[f(X) | X \in \Omega_k]$

分层估计量：

$$\hat{\mu}_{\text{ST}} = \sum_{k=1}^{K} p_k \cdot \frac{1}{n_k} \sum_{j=1}^{n_k} f(X_{kj}), \quad X_{kj} \sim \text{distribution restricted to } \Omega_k$$

其中 $\sum_k n_k = n$ 为总样本量。

**方差**：$\text{Var}(\hat{\mu}_{\text{ST}}) = \sum_{k=1}^{K} \frac{p_k^2 \sigma_k^2}{n_k}$

**方差分解 (ANOVA 分解)**：

$$\text{Var}(f(X)) = \underbrace{\sum_{k=1}^{K} p_k \sigma_k^2}_{\text{组内方差}} + \underbrace{\sum_{k=1}^{K} p_k (\mu_k - \mu)^2}_{\text{组间方差}}$$

其中 $\sigma_k^2 = \text{Var}(f(X) | X \in \Omega_k)$，$\mu_k = \mathbb{E}[f(X) | X \in \Omega_k]$。

对标准 MC（按比例分配 $n_k = n p_k$）：

$$\text{Var}(\hat{\mu}_{\text{MC}}) = \frac{\text{Var}(f(X))}{n} = \frac{1}{n}\left[\sum_k p_k \sigma_k^2 + \sum_k p_k (\mu_k - \mu)^2\right]$$

对比例分层抽样：

$$\text{Var}(\hat{\mu}_{\text{ST}}^{\text{prop}}) = \frac{1}{n} \sum_k p_k \sigma_k^2 = \text{Var}(\hat{\mu}_{\text{MC}}) - \frac{1}{n} \sum_k p_k (\mu_k - \mu)^2$$

**关键结论**：分层抽样**必然**不增加方差（相比标准 MC），因为消去了组间方差项。缩减量取决于各层均值 $\mu_k$ 与总均值 $\mu$ 的差异。

**最优分配 (Neyman 分配)**：在给定总样本量 $n$ 下最小化方差：

$$n_k^* = n \cdot \frac{p_k \sigma_k}{\sum_{j=1}^{K} p_j \sigma_j}$$

即每层的样本量与该层规模 $p_k$ 和标准差 $\sigma_k$ 成正比。

## 五、拟蒙特卡洛 (Quasi-Monte Carlo)

### 5.1 基本思想

拟蒙特卡洛 (QMC) 以确定性低差异序列替代伪随机序列，利用 Koksma-Hlawka 不等式得到确定性误差界：

$$\left|I - \frac{1}{n} \sum_{i=1}^{n} f(\mathbf{x}_i)\right| \leq V(f) \cdot D_n^*(\mathbf{x}_1, \ldots, \mathbf{x}_n)$$

其中：
- $V(f)$：$f$ 的 Hardy-Krause 变差（函数正则性度量）
- $D_n^*$：点集的星差异 (star discrepancy)，衡量点的偏离均匀程度

### 5.2 星差异与低差异序列

$n$ 个点 $\{ \mathbf{x}_1, \ldots, \mathbf{x}_n \} \subset [0, 1]^d$ 的星差异定义为：

$$D_n^* = \sup_{\mathbf{a} \in [0,1]^d} \left| \frac{\#\{i : \mathbf{x}_i \in [0, \mathbf{a})\}}{n} - \prod_{j=1}^{d} a_j \right|$$

对随机序列 $D_n^* = O(\sqrt{\log\log n / n})$（来自 Dvoretzky-Kiefer-Wolfowitz）；对好的低差异序列 $D_n^* = O(n^{-1} \log^d n)$。

### 5.3 Sobol 序列

Sobol 序列基于二进制展开和方向数 (direction numbers) 构造：

$$x_n^{(j)} = \sum_{k=0}^{\infty} \left( \sum_{l=1}^{k} v_{l}^{(j)} b_{n,k-l+1} \right)_2$$

其中 $b_{n,k}$ 为 $n$ 的二进制表示的第 $k$ 位，$v_l^{(j)}$ 为第 $j$ 维的方向数，加法为按位异或。

**性质**：
- 第 $j$ 维的 Sobol 序列具有 $t^{(j)}$ 值，$t$ 越小越好（衡量低维投影的质量）
- 随机化的 Sobol 序列（scrambled Sobol）通过 Owen 置乱消除偏倚并提供误差估计
- 实践中 QMC 误差常表现为 $O(n^{-1})$ 左右，比标准 MC 的 $O(n^{-1/2})$ 高效
- 在中等维度（$d \leq 50$）尤其有效

### 5.4 Halton 序列

基于互素的基构造：

$$x_n = \left(\phi_{b_1}(n), \phi_{b_2}(n), \ldots, \phi_{b_d}(n)\right)$$

其中 $\phi_b(n)$ 将 $n$ 在基 $b$ 下的数字反转，$b_1, \ldots, b_d$ 为前 $d$ 个素数。高维时相关性变强，需使用 scrambled Halton。

## 六、蒙特卡洛的统计误差分析

### 6.1 均方误差分解

对任意蒙特卡洛估计 $\hat{\mu}_n$：

$$\text{MSE}(\hat{\mu}_n) = \mathbb{E}[(\hat{\mu}_n - \mu)^2] = \underbrace{\text{Var}(\hat{\mu}_n)}_{\text{方差}} + \underbrace{(\mathbb{E}[\hat{\mu}_n] - \mu)^2}_{\text{偏差}^2}$$

- 标准 MC：偏差 $= 0$，MSE $= \sigma^2 / n$
- 重要性采样：偏差 $= 0$（标准 IS），MSE $= \text{Var}_q(f w) / n$
- 自归一化 IS：偏差 $= O(n^{-1})$，MSE 受方差主导

### 6.2 相对误差控制

相对误差：$\text{RE} = \frac{\text{SE}}{|\mu|} = \frac{\hat{\sigma}}{\sqrt{n} |\bar{X}_n|}$

要达到目标相对误差 $\varepsilon$，需要 $n \approx \left(\frac{\sigma/\mu}{\varepsilon}\right)^2$ 个样本。信噪比 $\sigma/\mu$ 是关键参数。

## 七、应用

### 7.1 欧式期权定价

Black-Scholes 模型下的欧式看涨期权价格为：

$$C = e^{-rT} \mathbb{E}_Q\left[(S_T - K)^+\right]$$

其中 $Q$ 为风险中性测度，$S_T = S_0 \exp\left[(r - \sigma^2/2)T + \sigma\sqrt{T} Z\right]$，$Z \sim N(0, 1)$。

标准 MC 估计的方差为：

$$\text{Var}(C_{\text{MC}}) = \frac{e^{-2rT}}{n} \text{Var}\left[(S_T - K)^+\right]$$

**方差缩减策略**：

1. **对偶变量**：对每对 $(Z, -Z)$ 生成 $\bar{C} = \frac{1}{2}(C_+(Z) + C_+(-Z))$，Payoff 的单调性保证负相关
2. **控制变量**：以标的资产本身 $e^{-rT} S_T$ 为控制变量（$\mathbb{E}_Q[e^{-rT} S_T] = S_0$），$f = e^{-rT}(S_T - K)^+$，$h = e^{-rT} S_T$
3. **重要性采样**（增加 $S_T > K$ 区间的采样概率）

### 7.2 Bootstrap 方法

Bootstrap 是统计学中最重要的蒙特卡洛应用之一。对于统计量 $\hat{\theta} = T(X_1, \ldots, X_n)$：

1. 从经验分布 $\hat{F}_n$ 中有放回地抽取 $B$ 组 bootstrap 样本，每组 $n$ 个
2. 计算每组上的统计量 $\hat{\theta}_b^*$
3. 以 $\{\hat{\theta}_b^*\}_{b=1}^B$ 的经验分布近似 $\hat{\theta}$ 的抽样分布

**Bootstrap 方差估计**：

$$\widehat{\text{Var}}(\hat{\theta}) = \frac{1}{B-1} \sum_{b=1}^{B} (\hat{\theta}_b^* - \bar{\theta}^*)^2$$

**Bootstrap 百分位置信区间**：以 $\hat{\theta}_{(\lfloor B\alpha/2 \rfloor)}^*$ 和 $\hat{\theta}_{(\lceil B(1-\alpha/2) \rceil)}^*$ 为下、上界。

### 7.3 高维积分

$$I_d = \int_{[0,1]^d} \prod_{j=1}^{d} g_j(x_j) \, d\mathbf{x} = \prod_{j=1}^{d} \int_0^1 g_j(x_j) \, dx_j$$

对于 $d = 50$ 或 $d = 100$ 的积分：
- 数值积分（Gauss-Legendre + 张量积）：不可行（$m^d$ 个节点）
- 稀疏网格 (Sparse Grid)：$O(n \log^{d-1} n)$ 节点，但仅对足够光滑的被积函数有效
- 蒙特卡洛：无维度灾难，$n$ 个节点即可

## 八、蒙特卡洛方法的理论局限与超越

### 8.1 收敛速度的根本限制

蒙特卡洛方法的 $O(n^{-1/2})$ 收敛速度源于中心极限定理，这是随机性的本质限制。提高精度到 $O(n^{-3/2})$ 或更好需要在有偏估计的框架下（如 Richardson 外推的 SDE 弱近似），或以确定性序列（QMC）替代随机数。

### 8.2 方差的根本不等式

Cramér-Rao 下界给出估计方差的基本下限：

$$\text{Var}(\hat{\theta}) \geq \frac{1}{n \cdot I(\theta)}$$

其中 $I(\theta) = \mathbb{E}[(\partial \log p(X; \theta) / \partial \theta)^2]$ 为 Fisher 信息。这一下界适用于任何无偏估计，蒙特卡洛估计亦不例外。

### 8.3 多级蒙特卡洛 (Multilevel Monte Carlo, MLMC)

对 SDE 模拟等场景，MLMC 通过层次分解大幅降低计算成本：

$$\mathbb{E}[P_L] = \mathbb{E}[P_0] + \sum_{\ell=1}^{L} \mathbb{E}[P_\ell - P_{\ell-1}]$$

各层次使用不同的时间步长和样本量——粗层次用大量便宜样本，细层次用少量昂贵样本。Giles (2008) 证明 MLMC 可将计算复杂度从 $O(\varepsilon^{-3})$ 降至 $O(\varepsilon^{-2} (\log\varepsilon)^2)$（对 Lipschitz payoff）。

## 九、关键总结

1. **理论基础**：大数定律保证收敛性，中心极限定理给出 $O(n^{-1/2})$ 收敛速度和置信区间
2. **维度独立性**：蒙特卡洛是唯一收敛速度与维度无关的通用积分方法，高维积分的必然选择
3. **随机数生成**：逆变换法是最通用的非均匀采样方法，Box-Muller 是正态采样标准手段
4. **重要性采样**：通过改变采样分布集中样本于重要区域，$q^*$ 可理论上零方差但实践中不可行
5. **ESS 指标**：$\text{ESS} = n / (1 + \text{CV}^2(w))$ 量化重要性采样的效率，ESS 过小则需改进 $q$
6. **控制变量**：最优系数 $c^* = \text{Cov}(f, h) / \text{Var}(h)$，方差缩减率 $1 - \rho_{fh}^2$
7. **分层抽样**：通过消除组间方差必然降低方差
8. **拟蒙特卡洛**：以确定性低差异序列达到理论 $O(n^{-1})$ 收敛
9. **应用范围**：期权定价、Bootstrap、高维积分、贝叶斯计算、粒子滤波
10. **展望**：MLMC、准蒙特卡洛、自适应重要性采样是现代蒙特卡洛研究的前沿方向
