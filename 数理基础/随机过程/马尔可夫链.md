# 马尔可夫链

## 一、马尔可夫性与转移矩阵

### 1.1 马尔可夫性质 (Markov Property)

**定义 1.1 (离散时间马尔可夫链)**：随机过程 $\{X_n : n = 0, 1, 2, \ldots\}$ 取值于可数状态空间 $S$，若满足马尔可夫性

$$P(X_{n+1} = j \mid X_n = i, X_{n-1} = i_{n-1}, \ldots, X_0 = i_0) = P(X_{n+1} = j \mid X_n = i)$$

对任意 $n \geq 0$ 和 $i, j, i_{n-1}, \ldots, i_0 \in S$ 成立，则称 $\{X_n\}$ 为马尔可夫链。

**物理解释**：给定现在，未来与过去独立。系统的下一状态仅由当前状态决定，与历史路径无关。这一"无记忆性"（或"无后效性"）是马尔可夫模型最根本的简化假设。

**时间齐次性 (Time-homogeneity)**：若 $P(X_{n+1} = j \mid X_n = i) = p_{ij}$ 与 $n$ 无关，则链是时齐的。本文以下仅讨论时齐马尔可夫链。

### 1.2 转移概率矩阵

**定义 1.2 (一步转移概率矩阵)**：

$$P = (p_{ij})_{i,j \in S}, \quad p_{ij} = P(X_{n+1} = j \mid X_n = i)$$

转移矩阵满足随机矩阵性质：
1. **非负性**：$p_{ij} \geq 0$ 对所有 $i, j$
2. **行和为一**：$\sum_{j \in S} p_{ij} = 1$ 对所有 $i$

**概率向量的传播**：若 $\boldsymbol{\pi}^{(0)} = (\pi_1^{(0)}, \pi_2^{(0)}, \ldots)$ 为 $X_0$ 的分布（行向量），则 $X_n$ 的分布为

$$\boldsymbol{\pi}^{(n)} = \boldsymbol{\pi}^{(0)} P^n$$

其中 $P^n$ 为 $P$ 的 $n$ 次矩阵幂。

**证明 (归纳法)**：由全概率公式：

$$\pi_j^{(n+1)} = P(X_{n+1} = j) = \sum_{i} P(X_{n+1} = j \mid X_n = i) P(X_n = i) = \sum_{i} \pi_i^{(n)} p_{ij} = (\boldsymbol{\pi}^{(n)} P)_j$$

由此递推得 $\boldsymbol{\pi}^{(n)} = \boldsymbol{\pi}^{(0)} P^n$。

### 1.3 $n$ 步转移概率

**定义 1.3**：$n$ 步转移概率 $p_{ij}^{(n)} = P(X_{m+n} = j \mid X_m = i) = (P^n)_{ij}$

由于时齐性，$p_{ij}^{(n)}$ 仅依赖于时间跨度 $n$ 而不依赖起始时刻 $m$。

## 二、Chapman-Kolmogorov 方程

### 2.1 方程推导

**定理 2.1 (Chapman-Kolmogorov 方程)**：对任意 $0 < m < n$ 和 $i, j \in S$，

$$p_{ij}^{(n)} = \sum_{k \in S} p_{ik}^{(m)} p_{kj}^{(n-m)}$$

或等价的矩阵形式：$P^{(n)} = P^{(m)} P^{(n-m)}$。特别地，$P^{(n)} = P^n$。

**证明**：对 $m < n$，在时刻 $m$ 的状态取条件：

$$\begin{aligned}
p_{ij}^{(n)} &= P(X_n = j \mid X_0 = i) \\
&= \sum_{k \in S} P(X_n = j \mid X_m = k, X_0 = i) P(X_m = k \mid X_0 = i) \\
&= \sum_{k \in S} P(X_n = j \mid X_m = k) P(X_m = k \mid X_0 = i) \quad (\text{马尔可夫性}) \\
&= \sum_{k \in S} p_{ik}^{(m)} p_{kj}^{(n-m)}
\end{aligned}$$

**半群性质**：C-K 方程表明转移算子 $\{P^n\}_{n \geq 0}$ 构成一个半群：$P^{m+n} = P^m P^n$。

### 2.2 C-K 方程的应用

C-K 方程是将有限步分割为两段进行分析的基础工具。例如：
- **首达概率分解**：将 $n$ 步到达 $j$ 分解为首次到达 $j$ 的时间与剩余步数
- **平稳分布验证**：若 $\boldsymbol{\pi} = \boldsymbol{\pi} P$，则 $\boldsymbol{\pi} = \boldsymbol{\pi} P^n$ 对所有 $n$ 成立

## 三、状态分类

### 3.1 可达性与互通

**定义 3.1 (可达)**：称状态 $j$ 从状态 $i$ 可达，记作 $i \to j$，若存在 $n \geq 0$ 使 $p_{ij}^{(n)} > 0$。

**定义 3.2 (互通)**：若 $i \to j$ 且 $j \to i$，则 $i$ 和 $j$ 互通，记作 $i \leftrightarrow j$。

互通关系是等价关系（满足自反性、对称性、传递性），将状态空间划分为互通的等价类。

### 3.3 常返与暂态

**定义 3.3 (首达概率)**：从 $i$ 出发，首次到达 $j$ 的时间为 $n$ 的概率：

$$f_{ij}^{(n)} = P(X_n = j, X_k \neq j \text{ for } 1 \leq k < n \mid X_0 = i)$$

$f_{ij} = \sum_{n=1}^{\infty} f_{ij}^{(n)}$ 为从 $i$ 出发最终到达 $j$ 的概率。

**定义 3.4 (常返与暂态)**：
- 状态 $i$ 是**常返的** (recurrent)，若 $f_{ii} = 1$（从 $i$ 出发必然返回）
- 状态 $i$ 是**暂态的** (transient)，若 $f_{ii} < 1$（以正概率永不返回）

**等价刻画**：

$$\text{常返} \iff \sum_{n=1}^{\infty} p_{ii}^{(n)} = \infty$$
$$\text{暂态} \iff \sum_{n=1}^{\infty} p_{ii}^{(n)} < \infty$$

直觉：常返态被无限次访问，暂态仅被有限次访问（几乎必然）。

#### 正常返与零常返

设 $\mu_i = \mathbb{E}_i[T_i]$ 为从 $i$ 出发首次返回 $i$ 的平均时间（$T_i = \inf\{n \geq 1 : X_n = i\}$）：
- **正常返** (positive recurrent)：$f_{ii} = 1$ 且 $\mu_i < \infty$
- **零常返** (null recurrent)：$f_{ii} = 1$ 且 $\mu_i = \infty$

有限马尔可夫链中，至少存在一个常返态（Dirichlet 原理），且所有常返态均为正常返。

### 3.4 周期性与遍历性

**定义 3.5 (周期)**：状态 $i$ 的周期为

$$d_i = \gcd\{n \geq 1 : p_{ii}^{(n)} > 0\}$$

若 $d_i = 1$ 则称 $i$ 为非周期的 (aperiodic)；若 $d_i > 1$ 则称为周期的 (periodic)。

**重要性质**：互通的状态具有相同的周期。

**定义 3.6 (遍历性)**：若状态既是正常返的又是非周期的，则称为遍历的 (ergodic)。

## 四、平稳分布

### 4.1 定义与基本性质

**定义 4.1 (平稳分布)**：概率向量 $\boldsymbol{\pi} = (\pi_1, \pi_2, \ldots)$ 是转移矩阵 $P$ 的平稳分布（或不变分布），若

$$\boldsymbol{\pi} P = \boldsymbol{\pi}$$

即 $\pi_j = \sum_{i} \pi_i p_{ij}$ 对所有 $j$ 成立。

**物理解释**：若链的当前分布是平稳分布，则下一时刻的分布仍为此分布。系统达到统计平衡。

**不变性推广**：$\boldsymbol{\pi} = \boldsymbol{\pi} P$ 推出 $\boldsymbol{\pi} = \boldsymbol{\pi} P^n$ 对所有 $n$ 成立，即平稳分布在任何时间步数后保持不变。

### 4.2 平稳分布的存在性

**定理 4.1 (平稳分布存在性)**：设马尔可夫链满足
1. **不可约** (irreducible)：任意两个状态相互可达
2. **正常返**：所有状态均为正常返

则存在唯一的平稳分布 $\boldsymbol{\pi}$，且 $\pi_i = 1 / \mu_i$，其中 $\mu_i = \mathbb{E}_i[T_i]$ 为从 $i$ 出发的平均返回时间。

**定理 4.2 (极限分布的充分条件)**：若链不可约且非周期，则极限

$$\lim_{n \to \infty} p_{ij}^{(n)} = \pi_j$$

存在且与初始状态 $i$ 无关，$\boldsymbol{\pi}$ 为平稳分布。对有限链，不可约 + 非周期已经保证了正常返。

### 4.4 有限链的平稳分布求解

**直接法**：求解线性方程组

$$\begin{cases}
\boldsymbol{\pi} P = \boldsymbol{\pi} \\
\sum_{i=1}^{N} \pi_i = 1
\end{cases}$$

等价于 $(P^T - I) \boldsymbol{\pi}^T = \boldsymbol{0}$ 加上归一化约束。将归一化条件替换方程组中任一方程构成非齐次系统：

$$\begin{pmatrix}
P^T - I \\
\mathbf{1}^T
\end{pmatrix} \text{(with one row replaced by } \mathbf{1}^T\text{)} \cdot \boldsymbol{\pi}^T = \begin{pmatrix} \mathbf{0} \\ 1 \end{pmatrix}$$

**幂迭代法**：从任意正初始概率向量出发，反复乘以 $P$：

$$\boldsymbol{\pi}^{(k+1)} = \boldsymbol{\pi}^{(k)} P$$

对遍历链，$\boldsymbol{\pi}^{(k)} \to \boldsymbol{\pi}$（几何速率收敛）。

### 4.5 平稳分布与极限分布的关系

- **不可约正常返非周期链**：存在唯一平稳分布，且是极限分布
- **不可约正常返周期链**：平稳分布仍存在（$\pi_i = 1/\mu_i$），但 $p_{ij}^{(n)}$ 不收敛（震荡），平均值 $\frac{1}{N} \sum_{n=1}^{N} p_{ij}^{(n)} \to \pi_j$ 成立

## 五、吸收概率与基本矩阵

### 5.1 吸收马尔可夫链

**定义 5.1 (吸收链)**：包含至少一个吸收态（$p_{ii} = 1$），且从每个暂态都可以到达至少一个吸收态的马尔可夫链。

将状态空间重排为 $S = T \cup A$，其中 $T$ 为暂态集，$A$ 为吸收态集。写成标准型：

$$P = \begin{pmatrix} Q_{|T| \times |T|} & R_{|T| \times |A|} \\ \mathbf{0}_{|A| \times |T|} & I_{|A| \times |A|} \end{pmatrix}$$

- $Q$：暂态之间的转移概率
- $R$：从暂态到吸收态的转移概率
- $I$：吸收态的自转移（单位矩阵）

### 5.2 基本矩阵 $N$

**定义 5.2 (基本矩阵)**：

$$N = (I - Q)^{-1} = I + Q + Q^2 + Q^3 + \cdots$$

$(I - Q)$ 对吸收链总是可逆的（谱半径 $\rho(Q) < 1$）。

**定理 5.1 (基本矩阵的统计解释)**：
- $n_{ij}$（$N$ 的 $(i, j)$ 元素）= 从暂态 $i$ 出发，在吸收前访问暂态 $j$ 的期望次数
- $\sum_{j \in T} n_{ij}$ = 从暂态 $i$ 出发直到吸收的期望步数

**证明思路**：$p_{ij}^{(m)}$（$(Q^m)_{ij}$）为$m$ 步后仍在 $j$ 且未吸收的概率，其期望和 $N = \sum_{m=0}^{\infty} Q^m$。

### 5.3 吸收概率矩阵

**定理 5.2**：从暂态 $i$ 出发，最终被吸收态 $a \in A$ 吸收的概率为

$$B = N R$$

即 $b_{ia}$（$B$ 的 $(i, a)$ 元素）= 从 $i$ 出发最终被 $a$ 吸收的概率。

**证明**：

$$b_{ia} = p_{ia} + \sum_{k \in T} p_{ik} b_{ka}$$

矩阵形式：$B = R + Q B$，即 $(I - Q)B = R$，故 $B = NR$。

**推论**：对任意吸收状态 $a$，$\sum_{a \in A} b_{ia} = 1$（必然被某个吸收态吸收）。

### 5.4 吸收时间的方差

从暂态 $i$ 出发直到吸收所需步数的方差：

$$\text{Var}_i[T] = (2N - I)\, N \mathbf{1} - (N \mathbf{1}) \odot (N \mathbf{1})$$

其中 $\mathbf{1}$ 为全 1 向量，$\odot$ 为逐元素乘法。推导基于 $T$ 的二阶矩为 $\mathbb{E}_i[T^2] = (2N - I) N \mathbf{1}$。

## 六、隐马尔可夫模型 (Hidden Markov Model, HMM)

### 6.1 模型描述

隐马尔可夫模型是一个双重随机过程：
1. **隐状态链** $\{X_t\}$：不可直接观测的马尔可夫链
2. **观测序列** $\{O_t\}$：通过隐状态到观测的概率映射生成

**参数表示**：$\lambda = (A, B, \boldsymbol{\pi})$
- 转移矩阵 $A = (a_{ij})$，$a_{ij} = P(X_{t+1} = j \mid X_t = i)$
- 发射矩阵 $B = (b_j(k))$，$b_j(k) = P(O_t = k \mid X_t = j)$
- 初始分布 $\boldsymbol{\pi} = (\pi_i)$，$\pi_i = P(X_1 = i)$

### 6.2 HMM 的三个基本问题

**问题 1 — 评估问题 (Evaluation)**：给定模型 $\lambda$ 和观测序列 $O = (o_1, \ldots, o_T)$，计算 $P(O \mid \lambda)$。

**解法：前向算法 (Forward Algorithm)**

定义前向变量 $\alpha_t(i) = P(o_1, \ldots, o_t, X_t = i \mid \lambda)$

递推：
1. 初始化：$\alpha_1(i) = \pi_i \cdot b_i(o_1)$
2. 递推：$\alpha_{t+1}(j) = \left[\sum_{i=1}^{N} \alpha_t(i) a_{ij}\right] b_j(o_{t+1})$
3. 终止：$P(O \mid \lambda) = \sum_{i=1}^{N} \alpha_T(i)$

**计算复杂度**：$O(N^2 T)$，而非暴力枚举的 $O(T N^T)$。

**后向算法 (Backward Algorithm)**：后向变量 $\beta_t(i) = P(o_{t+1}, \ldots, o_T \mid X_t = i, \lambda)$

递推：
1. 初始化：$\beta_T(i) = 1$
2. $\beta_t(i) = \sum_{j=1}^{N} a_{ij} b_j(o_{t+1}) \beta_{t+1}(j)$
3. $P(O \mid \lambda) = \sum_{i=1}^{N} \pi_i b_i(o_1) \beta_1(i)$

对任意 $t$，$P(O \mid \lambda) = \sum_{i=1}^{N} \alpha_t(i) \beta_t(i)$。

---

**问题 2 — 解码问题 (Decoding)**：给定 $\lambda$ 和 $O$，求最可能的状态序列 $X^* = \arg\max_X P(X \mid O, \lambda)$。

**解法：Viterbi 算法**

定义 $\delta_t(i) = \max_{x_1, \ldots, x_{t-1}} P(x_1, \ldots, x_{t-1}, X_t = i, o_1, \ldots, o_t \mid \lambda)$

递推：
1. 初始化：$\delta_1(i) = \pi_i \cdot b_i(o_1)$，$\psi_1(i) = 0$
2. 递推：
   $$\delta_t(j) = \max_{1 \leq i \leq N} [\delta_{t-1}(i) a_{ij}] \cdot b_j(o_t)$$
   $$\psi_t(j) = \arg\max_{1 \leq i \leq N} [\delta_{t-1}(i) a_{ij}]$$
3. 终止：$P^* = \max_i \delta_T(i)$，$x_T^* = \arg\max_i \delta_T(i)$
4. 回溯：$x_t^* = \psi_{t+1}(x_{t+1}^*)$，$t = T-1, T-2, \ldots, 1$

---

**问题 3 — 学习问题 (Learning)**：给定观测序列 $O$，估计模型参数 $\lambda$ 使 $P(O \mid \lambda)$ 最大化。

**解法：Baum-Welch 算法 (EM 算法的 HMM 特例)**

E 步计算：
- $\gamma_t(i) = P(X_t = i \mid O, \lambda) = \frac{\alpha_t(i) \beta_t(i)}{P(O \mid \lambda)}$
- $\xi_t(i, j) = P(X_t = i, X_{t+1} = j \mid O, \lambda) = \frac{\alpha_t(i) a_{ij} b_j(o_{t+1}) \beta_{t+1}(j)}{P(O \mid \lambda)}$

M 步更新：
- $\hat{\pi}_i = \gamma_1(i)$
- $\hat{a}_{ij} = \frac{\sum_{t=1}^{T-1} \xi_t(i, j)}{\sum_{t=1}^{T-1} \gamma_t(i)}$
- $\hat{b}_j(k) = \frac{\sum_{t=1}^{T} \gamma_t(j) \cdot \mathbf{1}_{[o_t = k]}}{\sum_{t=1}^{T} \gamma_t(j)}$

**收敛性**：Baum-Welch 迭代单调增加似然，但可能收敛到局部极大值而非全局最优。多初始值的策略可缓解此问题。

### 6.3 HMM 的数学基础——前向-后向算法推导

前向变量的递推利用马尔可夫性质：

$$\begin{aligned}
\alpha_{t+1}(j) &= P(o_1, \ldots, o_{t+1}, X_{t+1} = j) \\
&= \sum_{i} P(o_1, \ldots, o_{t+1}, X_t = i, X_{t+1} = j) \\
&= \sum_{i} P(o_{t+1} \mid X_{t+1} = j) P(X_{t+1} = j \mid X_t = i) P(o_1, \ldots, o_t, X_t = i) \\
&= b_j(o_{t+1}) \sum_{i} a_{ij} \alpha_t(i)
\end{aligned}$$

### 6.4 拓展：连续观测 HMM

当观测是连续值时，发射分布 $b_j(\cdot)$ 常用混合高斯模型：

$$b_j(\mathbf{o}) = \sum_{m=1}^{M} c_{jm} \mathcal{N}(\mathbf{o} \mid \boldsymbol{\mu}_{jm}, \boldsymbol{\Sigma}_{jm})$$

训练时需在 Baum-Welch 的 M 步中加入 GMM 参数的更新。

## 七、马尔可夫链的遍历理论

### 7.1 遍历定理

**定理 7.1 (遍历定理)**：对不可约正常返马尔可夫链，对任意有界函数 $f: S \to \mathbb{R}$，

$$\lim_{n \to \infty} \frac{1}{n} \sum_{k=1}^{n} f(X_k) = \sum_{i \in S} \pi_i f(i) \quad \text{a.s.}$$

即时间平均以概率 1 收敛到空间平均（平稳分布下的期望）。这是 Monte Carlo 积分中 MCMC 方法的理论基础。

**不可约正常返非周期链**还有更强的收敛：分布收敛——$X_n$ 的边际分布收敛到 $\boldsymbol{\pi}$。

### 7.2 收敛速率

**几何遍历性**：若链以几何速率收敛到平稳分布，即存在 $\rho \in (0, 1)$ 和常数 $C$，使得

$$\|P^n(i, \cdot) - \boldsymbol{\pi}\|_{\text{TV}} \leq C \rho^n$$

$\|\cdot\|_{\text{TV}}$ 为全变差距离。有限不可约非周期链总满足几何遍历性。收敛速率由 $P$ 的第二大特征值的绝对值决定：

$$\rho = \max\{|\lambda| : \lambda \text{ 是 } P \text{ 的特征值且 } \lambda \neq 1\}$$

$1$ 是转移矩阵的必然特征值（对应 $\boldsymbol{\pi}$ 为左特征向量）。

### 7.3 平稳分布的刻画——矩阵几何

对吸收马尔可夫链及准生灭过程 (Quasi-Birth-Death Process)，平稳分布由矩阵几何解给出：

$$\boldsymbol{\pi}_n = \boldsymbol{\pi}_0 R^n$$

其中 $R$ 为率矩阵，是矩阵二次方程 $R^2 C + R B + A = 0$ 的最小非负解（$A, B, C$ 为生灭过程的分块转移矩阵）。

## 八、马尔可夫链的应用

### 8.1 天气预报

状态空间 $S = \{\text{晴}, \text{阴}, \text{雨}\}$，转移矩阵：

$$P = \begin{pmatrix} 0.6 & 0.3 & 0.1 \\ 0.2 & 0.5 & 0.3 \\ 0.1 & 0.3 & 0.6 \end{pmatrix}$$

已知今日天气分布 $\boldsymbol{\pi}^{(0)}$，$k$ 天后分布为 $\boldsymbol{\pi}^{(k)} = \boldsymbol{\pi}^{(0)} P^k$。

### 8.2 市场份额预测

消费者在品牌间转换构成马尔可夫链。品牌忠诚度对应自转移概率 $p_{ii}$。平稳分布 $\boldsymbol{\pi}$ 给出长期均衡市场份额。

### 8.3 PageRank

Google 的 PageRank 算法将网页视为状态，超链接视为转移，转移矩阵为：

$$P = \alpha S + (1 - \alpha) \frac{1}{N} \mathbf{1}\mathbf{1}^T$$

其中 $S$ 为由出站链接构造的随机矩阵，$\alpha \approx 0.85$ 为阻尼因子。平稳分布 $\boldsymbol{\pi}$（$\boldsymbol{\pi} = \boldsymbol{\pi} P$）为页面的 PageRank 值。

### 8.4 遗传学——Wright-Fisher 模型

$2N$ 个基因副本中某个等位基因的数量构成吸收马尔可夫链（$X_t = 0$ 和 $X_t = 2N$ 为吸收态）。这是种群遗传学的基础模型。

## 九、与连续时间马尔可夫链的关系

离散时间马尔可夫链可视为连续时间马尔可夫链的 uniformization：

对转移率矩阵 $Q$（$q_{ii} = -\sum_{j \neq i} q_{ij}$，$q_{ij} \geq 0$，$i \neq j$），选择均匀化速率 $\nu \geq \max_i |q_{ii}|$，定义嵌入的离散链：

$$P = I + \frac{1}{\nu} Q$$

连续时间链的跳跃次数服从 Poisson 过程（率 $\nu$），跳跃之间的转移服从离散链 $P$。

## 十、关键总结

1. **马尔可夫性**：未来仅依赖于当前状态——这是简化复杂随机系统的最有力假设
2. **Chapman-Kolmogorov 方程**：$P^{(m+n)} = P^{(m)} P^{(n)}$，是马尔可夫链分析的分割-组合基础
3. **状态分类**：常返/暂态区分了长期行为，周期/非周期影响收敛模式
4. **平稳分布**：$\boldsymbol{\pi} = \boldsymbol{\pi} P$，不可约正常返非周期链的唯一极限分布
5. **基本矩阵**：$N = (I - Q)^{-1}$ 蕴含吸收前访问次数和吸收时间的全部信息
6. **吸收概率**：$B = N R$ 给出各暂态到各吸收态的最终吸收分布
7. **HMM 三大算法**：Forward 算法（评估）— Viterbi 算法（解码）— Baum-Welch 算法（学习）
8. **遍历理论**：时间平均 = 空间平均的严格保证，是 MCMC 的理论基石
9. **收敛速率**：由 $P$ 的第二大特征值决定，几何收敛速率在有限链中普遍成立
10. **应用广度**：从语音识别 (HMM) 到搜索引擎 (PageRank) 到种群遗传学 (Wright-Fisher)
