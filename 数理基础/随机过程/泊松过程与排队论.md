# 泊松过程与排队论

## 一、泊松过程 (Poisson Process)

### 1.1 定义与等价刻画

泊松过程 $\{N(t), t \geq 0\}$ 是计数过程，$N(t)$ 表示 $[0, t]$ 时间内事件发生的次数。

**定义 1.1 (泊松过程的三条公理)**：
1. $N(0) = 0$
2. **独立增量**：对 $0 \leq t_1 < t_2 < \cdots < t_n$，增量 $N(t_1) - N(0), N(t_2) - N(t_1), \ldots, N(t_n) - N(t_{n-1})$ 相互独立
3. **泊松增量**：对 $s < t$，$N(t) - N(s) \sim \text{Poisson}(\lambda(t - s))$

即：

$$P(N(t) - N(s) = k) = \frac{[\lambda(t-s)]^k}{k!} e^{-\lambda(t-s)}, \quad k = 0, 1, 2, \ldots$$

其中 $\lambda > 0$ 为强度（率）参数。

**等价刻画 — 指数到达间隔**：泊松过程等价于到达间隔 $\{W_n\}$ 独立同分布于 $\text{Exp}(\lambda)$：

$$f_{W_n}(t) = \lambda e^{-\lambda t}, \quad t \geq 0$$

这一等价性在排队论中至关重要——"到达为泊松过程" 等价于 "到达间隔为独立指数分布"。

### 1.2 均值、方差与协方差

**均值函数**：$\mathbb{E}[N(t)] = \lambda t$

**方差函数**：$\text{Var}(N(t)) = \lambda t$

（均值等于方差是泊松分布的独特性质）

**自协方差函数**：

$$\text{Cov}(N(s), N(t)) = \lambda \min(s, t)$$

**推导**：对 $s < t$，$N(s)(N(t) - N(s))$ 中的两个因子为独立随机变量（独立增量），故

$$\begin{aligned}
\mathbb{E}[N(s) N(t)] &= \mathbb{E}[N(s)^2] + \mathbb{E}[N(s)(N(t) - N(s))] \\
&= \lambda s + (\lambda s)^2 + (\lambda s) \cdot \lambda(t-s) \\
&= \lambda s + \lambda^2 s t
\end{aligned}$$

因此 $\text{Cov}(N(s), N(t)) = (\lambda s + \lambda^2 s t) - (\lambda s)(\lambda t) = \lambda s = \lambda \min(s, t)$。

### 1.3 到达间隔与到达时刻

设 $T_n$ 为第 $n$ 次事件到达的时刻，$W_n = T_n - T_{n-1}$（约定 $T_0 = 0$）为第 $n$ 个到达间隔。

**定理 1.1 (到达间隔分布)**：$W_1, W_2, \ldots$ 为独立同分布，$W_n \sim \text{Exp}(\lambda)$。

**证明思路**：$P(W_1 > t) = P(N(t) = 0) = e^{-\lambda t}$。对于 $n > 1$，由无记忆性（指数分布特性）和独立增量性导出。

**定理 1.2 (到达时刻分布)**：第 $n$ 次到达时刻 $T_n = \sum_{i=1}^{n} W_i$ 服从 Erlang 分布（形状参数 $n$，尺度参数 $\lambda$ 的 Gamma 分布）：

$$f_{T_n}(t) = \frac{\lambda^n t^{n-1}}{(n-1)!} e^{-\lambda t}, \quad t \geq 0$$

等价地，$T_n \sim \text{Gamma}(n, \lambda)$。

**证明**：$n$ 个独立 $\text{Exp}(\lambda)$ 随机变量之和特征函数为 $(1 - i t / \lambda)^{-n}$，即 $\text{Gamma}(n, \lambda)$ 的特征函数。

### 1.4 泊松过程的条件均匀分布性质

**定理 1.3 (给定计数的条件分布)**：在 $N(t) = n$ 的条件下，$n$ 个到达时刻 $T_1, T_2, \ldots, T_n$ 的联合分布等同于 $n$ 个独立 $U(0, t)$ 随机变量的顺序统计量。

数学表述：对 $0 < t_1 < t_2 < \cdots < t_n < t$，

$$P(T_1 \in dt_1, \ldots, T_n \in dt_n \mid N(t) = n) = \frac{n!}{t^n} \, dt_1 \cdots dt_n$$

**证明**：

$$\begin{aligned}
P(T_1 \in dt_1, \ldots, T_n \in dt_n, N(t) = n) &= \lambda e^{-\lambda t_1} dt_1 \cdot \lambda e^{-\lambda(t_2-t_1)} dt_2 \cdots \lambda e^{-\lambda(t_n-t_{n-1})} dt_n \cdot e^{-\lambda(t-t_n)} \\
&= \lambda^n e^{-\lambda t} \, dt_1 \cdots dt_n
\end{aligned}$$

而 $P(N(t) = n) = \frac{(\lambda t)^n}{n!} e^{-\lambda t}$，两者相除即得结论。

**应用**：这一性质使得泊松过程的模拟极其简单——先确定事件总数，再独立采样到达时刻并排序。

### 1.5 非齐次泊松过程 (Non-Homogeneous Poisson Process)

当强度随时间变化 $\lambda = \lambda(t)$ 时，定义累积强度函数：

$$\Lambda(t) = \int_0^t \lambda(s) \, ds$$

则 $N(t) - N(s) \sim \text{Poisson}(\Lambda(t) - \Lambda(s))$。均值为 $\mathbb{E}[N(t)] = \Lambda(t)$。

**模拟方法 — 薄化 (Thinning)**：
1. 取 $\lambda_{\max} \geq \sup_t \lambda(t)$
2. 以率 $\lambda_{\max}$ 的齐次泊松过程生成候选时刻
3. 对每个候选时刻 $t_i$，以概率 $\lambda(t_i) / \lambda_{\max}$ 保留

### 1.6 复合泊松过程 (Compound Poisson Process)

$$X(t) = \sum_{i=1}^{N(t)} Y_i$$

其中 $N(t)$ 为强度 $\lambda$ 的泊松过程，$\{Y_i\}$ 为 i.i.d. 随机变量（与 $N(t)$ 独立）。$Y_i$ 通常表示每次"跳跃"的大小。

**特征函数**：$\phi_{X(t)}(u) = \mathbb{E}[e^{iu X(t)}] = \exp\left(\lambda t (\phi_Y(u) - 1)\right)$

**均值和方差**：

$$\mathbb{E}[X(t)] = \lambda t \,\mathbb{E}[Y], \quad \text{Var}(X(t)) = \lambda t \,\mathbb{E}[Y^2]$$

**保险精算应用**：$N(t)$ 为索赔次数，$Y_i$ 为第 $i$ 次索赔额，$X(t)$ 为总理赔额。

## 二、布朗运动基础

### 2.1 定义

标准布朗运动（维纳过程）$\{W(t), t \geq 0\}$ 满足：
1. $W(0) = 0$
2. **独立增量**：对 $0 \leq t_1 < t_2 < \cdots < t_n$，增量 $W(t_k) - W(t_{k-1})$ 独立
3. **正态增量**：$W(t) - W(s) \sim N(0, t - s)$，$0 \leq s < t$
4. **连续路径**：样本路径 $t \mapsto W(t)$ 几乎必然连续

**与非随机过程的对比**：布朗运动同时具备独立增量（类似泊松过程）和连续路径（类似可微函数），但样本路径几乎处处不可微（Paley-Wiener-Zygmund 定理）。这促使了 Itô 随机微积分的发展。

### 2.2 基本统计性质

$$\mathbb{E}[W(t)] = 0, \quad \mathbb{E}[W(t)^2] = t$$
$$\text{Cov}(W(s), W(t)) = \min(s, t)$$

自协方差形式 "$\min(s, t)$" 与泊松过程一致，这源于两者均为独立增量过程。

**鞅性质**：布朗运动是鞅：$\mathbb{E}[W(t) \mid \mathcal{F}_s] = W(s)$，$s < t$。

**Markov 性质**：布朗运动是连续时间马尔可夫过程，转移密度为

$$p(t, x, y) = \frac{1}{\sqrt{2\pi t}} e^{-(y-x)^2/(2t)}$$

### 2.3 重要性质

**尺度不变性**：对任意 $c > 0$，$\{\frac{1}{\sqrt{c}} W(c t)\}$ 也是标准布朗运动。

**反射原理**：$\displaystyle P\left(\max_{0 \leq s \leq t} W(s) \geq a\right) = 2 P(W(t) \geq a) = 2\left[1 - \Phi\left(\frac{a}{\sqrt{t}}\right)\right]$，$a > 0$

**首达时**：$T_a = \inf\{t > 0 : W(t) = a\}$ 的密度为 Lévy 分布：

$$f_{T_a}(t) = \frac{|a|}{\sqrt{2\pi t^3}} e^{-a^2/(2t)}, \quad t > 0$$

$\mathbb{E}[T_a] = \infty$（尽管以概率 1 有限到达）。

**布朗桥**：在条件 $W(0) = 0$ 且 $W(T) = b$ 下，$\{W(t), 0 \leq t \leq T\}$ 为布朗桥：

$$\mathbb{E}[W(t) \mid W(T) = b] = \frac{bt}{T}, \quad \text{Cov}(W(s), W(t) \mid W(T) = b) = \min(s, t) - \frac{st}{T}$$

（详细内容见 [[../随机过程/随机微分方程|随机微分方程]] 中布朗运动的数学基础）

## 三、Kendall 记号与排队系统要素

### 3.1 Kendall 记号 $A/B/c/K/N/D$

排队论的标准化描述：$A/B/c/K/N/D$

| 位置 | 符号 | 含义 | 常用分布 |
|------|------|------|----------|
| $A$ | 到达过程 | 到达间隔分布 | $M$ (泊松), $D$ (确定), $GI$ (一般独立), $G$ (一般) |
| $B$ | 服务过程 | 服务时间分布 | $M$ (指数), $D$ (确定), $G$ (一般), $H_k$ ($k$ 阶超指数) |
| $c$ | 服务台数 | 并行服务台 | 正整数 ($1 \leq c < \infty$) |
| $K$ | 系统容量 | 最大系统人数 | $1 \leq K \leq \infty$（默认 $\infty$） |
| $N$ | 顾客源 | 潜在顾客总数 | $1 \leq N \leq \infty$（默认 $\infty$） |
| $D$ | 排队规则 | 服务顺序 | FIFO, LIFO, SIRO, PRI (优先级) |

省略后三个参数时，默认 $K = N = \infty$ 且 $D = \text{FIFO}$。例如 $M/M/1$ 即泊松到达、指数服务、单服务台、无限容量、FIFO。

### 3.2 关键性能指标

| 符号 | 定义 |
|------|------|
| $L$ | 系统稳态平均顾客数 |
| $L_q$ | 队列稳态平均顾客数（排队的） |
| $W$ | 顾客在系统中的平均逗留时间 |
| $W_q$ | 顾客在队列中的平均等待时间 |
| $\rho$ | 服务台利用率 |
| $P_n$ | 系统中有 $n$ 个顾客的稳态概率 |
| $P_0$ | 系统为空的状态概率 |

## 四、Little 定律 ($L = \lambda W$)

### 4.1 定律陈述

**Little 定律** (John Little, 1961)：在稳态排队系统中，

$$L = \lambda W$$

其中 $L$ 为系统中的平均人数，$\lambda$ 为有效到达率，$W$ 为平均逗留时间。对队列部分同样成立：

$$L_q = \lambda W_q$$

### 4.2 证明概要

考虑系统在 $[0, T]$ 内的演化。令 $A(T)$ 为到达总数（且已完成服务离开），$D(T)$ 为离开总数，$L_s(T)$ 为平均系统人数。

基本恒等式（面积 = 累积时间）：

$$\int_0^T L(t) \, dt = \sum_{i=1}^{A(T)} (\text{顾客 } i \text{ 的逗留时间})$$

两边除以 $T$：

$$\frac{1}{T} \int_0^T L(t) \, dt = \frac{A(T)}{T} \cdot \frac{1}{A(T)} \sum_{i=1}^{A(T)} W_i$$

令 $T \to \infty$，若各极限存在，则：

$$L = \lambda \cdot W$$

### 4.3 基本关系的推导

由 Little 定律和服务时间均值为 $1/\mu$ 的定义，可导出：

$$W = W_q + \frac{1}{\mu}$$

（逗留时间 = 等待时间 + 服务时间）

## 五、M/M/1 排队系统

### 5.1 模型设定

- 到达：强度 $\lambda$ 的泊松过程（到达间隔 $\sim \text{Exp}(\lambda)$）
- 服务：率 $\mu$ 的指数服务时间（均值 $1/\mu$）
- 单服务台、无限容量、FIFO

### 5.2 生灭过程分析

系统状态 $X(t)$ = 系统内顾客数。状态转移率为：

$$q_{n, n+1} = \lambda \quad (\text{到达}), \qquad q_{n, n-1} = \mu \quad (n \geq 1, \text{离开})$$

这是一个生灭过程 (birth-death process)。

**全局平衡方程 (Global Balance Equations)**：

$$\lambda P_0 = \mu P_1$$
$$(\lambda + \mu) P_n = \lambda P_{n-1} + \mu P_{n+1}, \quad n \geq 1$$

由第一个方程：$P_1 = \frac{\lambda}{\mu} P_0$。将第二个方程从 $n=1$ 迭代，可证明（实际上正是细致平衡）：

$$\lambda P_{n-1} = \mu P_n \quad \text{对所有 } n \geq 1$$

### 5.3 平稳分布

递推得 $P_n = \rho^n P_0$，其中 $\rho = \lambda / \mu$（服务台利用率）。由归一化条件 $\sum_{n=0}^{\infty} P_n = 1$：

$$P_0 \sum_{n=0}^{\infty} \rho^n = \frac{P_0}{1 - \rho} = 1 \quad \Rightarrow \quad P_0 = 1 - \rho \quad (\rho < 1)$$

**平稳分布**：

$$\boxed{P_n = (1 - \rho) \rho^n, \quad n = 0, 1, 2, \ldots}$$

即系统人数服从几何分布（含 $n = 0$）。稳定性条件为 $\rho < 1$。

**物理含义**：当 $\rho \to 1$ 时，系统逼近拥堵——$P_0 \to 0$（系统几乎永不空闲），排队长度发散。

### 5.4 性能指标推导

**系统平均人数**：

$$L = \sum_{n=0}^{\infty} n P_n = (1 - \rho) \sum_{n=0}^{\infty} n \rho^n$$

利用 $\sum_{n=0}^{\infty} n \rho^n = \frac{\rho}{(1 - \rho)^2}$（几何级数的导数形式），得

$$\boxed{L = \frac{\rho}{1 - \rho}}$$

**队列平均人数**：

$$L_q = \sum_{n=1}^{\infty} (n-1) P_n = L - (1 - P_0) = L - \rho = \frac{\rho^2}{1 - \rho}$$

验证 $L = L_q + \rho$（系统人数 = 队列人数 + 正在服务的人数期望）。

**由 Little 定律**：

$$W = \frac{L}{\lambda} = \frac{1}{\mu - \lambda}, \qquad W_q = \frac{L_q}{\lambda} = \frac{\rho}{\mu - \lambda}$$

**注意事项**：当 $\rho \to 1$ 时 $L \to \infty$ 且 $W \to \infty$——这对系统设计与容量规划有重要启示。

### 5.5 逗留时间与等待时间的分布

**逗留时间 $T$** 在系统中服从指数分布：

$$P(T > t) = e^{-(\mu - \lambda)t}, \quad t \geq 0$$

**证明思路**：在 $M/M/1$ 队列中，当顾客到达时，他看到的前方顾客数分布与稳态分布相同（PASTA 性质——泊松到达看到时间平均）。所有前方顾客的服务时间之和为 Erlang 分布，加上自身服务时间，利用指数分布的无记忆性得出总逗留时间 $\sim \text{Exp}(\mu - \lambda)$。

**等待时间 $T_q$**（纯排队不包含服务）：

$$P(T_q = 0) = 1 - \rho$$
$$P(T_q > t) = \rho e^{-(\mu - \lambda)t}, \quad t > 0$$

## 六、M/M/c 排队系统

### 6.1 模型与状态转移率

$c$ 个并行服务台，共享一个队列。服务率为 $\mu$（每个服务台）。到达率为 $\lambda$。

状态转移率：

$$q_{n, n+1} = \lambda, \quad q_{n, n-1} = \begin{cases} n \mu, & 1 \leq n < c \\ c \mu, & n \geq c \end{cases}$$

利用率：$\rho = \frac{\lambda}{c\mu} < 1$（稳定条件）

### 6.2 平稳分布

由细致平衡递推：

$$P_n = \begin{cases}
\frac{(c\rho)^n}{n!} P_0, & 0 \leq n < c \\[5pt]
\frac{c^c \rho^n}{c!} P_0, & n \geq c
\end{cases}$$

归一化：

$$P_0 = \left[\sum_{n=0}^{c-1} \frac{(c\rho)^n}{n!} + \frac{(c\rho)^c}{c!} \cdot \frac{1}{1 - \rho}\right]^{-1}$$

### 6.3 Erlang C 公式

**Erlang C 公式**（顾客到达时必须等待的概率）：

$$C(c, a) = P(\text{wait} > 0) = P(N \geq c) = \frac{\frac{a^c}{c!} \cdot \frac{c}{c - a}}{\sum_{n=0}^{c-1} \frac{a^n}{n!} + \frac{a^c}{c!} \cdot \frac{c}{c - a}}$$

其中 $a = \lambda / \mu$ 为交通强度（erlangs）。

等价形式：

$$P(\text{wait} > 0) = \frac{\frac{(c\rho)^c}{c! (1 - \rho)}}{\sum_{n=0}^{c-1} \frac{(c\rho)^n}{n!} + \frac{(c\rho)^c}{c! (1 - \rho)}}$$

### 6.4 性能指标

**平均队列长度**：

$$L_q = \frac{P_0 (c\rho)^c \rho}{c! (1 - \rho)^2} = \frac{\rho}{1 - \rho} \cdot C(c, a)$$

**其他指标**：$W_q = L_q / \lambda$，$W = W_q + 1/\mu$，$L = L_q + c\rho$

### 6.5 Erlang B 公式（损失系统）

当 $K = c$（无等待空间，顾客被阻塞即丢失）时：

$$B(c, a) = \frac{a^c / c!}{\sum_{n=0}^{c} a^n / n!}$$

这是经典的电话交换系统模型。

## 七、M/G/1 排队与 Pollaczek-Khinchine 公式

### 7.1 模型推广

M/G/1 模型将服务时间从指数分布推广到一般分布，是排队论中最重要的理论突破之一。到达仍为泊松过程（率 $\lambda$），服务时间 $S$ 满足：
- 均值 $\mathbb{E}[S] = 1/\mu$
- 二阶矩 $\mathbb{E}[S^2]$（或等价的方差 $\sigma^2$）

利用率：$\rho = \lambda \mathbb{E}[S] = \lambda / \mu < 1$

### 7.2 Pollaczek-Khinchine (P-K) 公式

**P-K 公式**给出 M/G/1 队列的平均队列长度：

$$L_q = \frac{\lambda^2 \mathbb{E}[S^2]}{2(1 - \rho)} = \frac{\rho^2 (1 + C_s^2)}{2(1 - \rho)}$$

其中 $C_s^2 = \text{Var}(S) / (\mathbb{E}[S])^2 = \sigma^2 \mu^2$ 为服务时间的平方变异系数。

**全系统人数**：$L = L_q + \rho$

**由 Little 定律**：$W_q = L_q / \lambda = \frac{\lambda \mathbb{E}[S^2]}{2(1 - \rho)}$

### 7.3 P-K 公式的完整推导（嵌入马尔可夫链方法）

在顾客离开的时刻观察系统。设 $X_n$ 为第 $n$ 个顾客离开时系统内剩余的顾客数。

递推关系：

$$X_{n+1} = X_n - \mathbf{1}_{[X_n > 0]} + A_{n+1}$$

其中 $A_{n+1}$ 为第 $n+1$ 个顾客服务期间新到达的顾客数，其分布仅依赖于服务时间 $S_{n+1}$：

$$P(A_{n+1} = k) = \int_0^{\infty} \frac{(\lambda t)^k}{k!} e^{-\lambda t} f_S(t) \, dt$$

其中 $f_S(t)$ 为服务时间密度。此分布的前两阶矩为：

$$\mathbb{E}[A] = \lambda \mathbb{E}[S] = \rho$$
$$\mathbb{E}[A^2] = \lambda \mathbb{E}[S] + \lambda^2 \mathbb{E}[S^2] = \rho + \lambda^2 \mathbb{E}[S^2]$$

平方递推关系并取稳态期望。在稳态 $\mathbb{E}[X_{n+1}] = \mathbb{E}[X_n] = L_q$ 下，通过精心处理指示函数 $\mathbf{1}_{[X > 0]}$ 和稳态独立假设，得到：

$$L_q = \frac{\lambda^2 \mathbb{E}[S^2]}{2(1 - \rho)}$$

**关键洞察**：P-K 公式表明队列长度不仅依赖于服务时间均值（通过 $\rho$），还强烈依赖于服务时间的变异。服务时间越不稳定（$C_s^2$ 越大），排队越长。

### 7.4 特殊比较

| 模型 | $C_s^2$ | $L_q$ |
|------|---------|-------|
| **M/M/1** | $1$ | $\frac{\rho^2}{1 - \rho}$ |
| **M/D/1** | $0$ | $\frac{\rho^2}{2(1 - \rho)} = \frac{1}{2} L_q^{M/M/1}$ |
| **M/E_k/1** | $1/k$ | $\frac{\rho^2(1 + 1/k)}{2(1 - \rho)}$ |
| **M/H_2/1** | $>1$ | $> L_q^{M/M/1}$ |

**规则**：服务时间方差越小，排队越短。确定服务时间（$M/D/1$）使排队长度恰好为 $M/M/1$ 的一半。

## 八、Jackson 排队网络

### 8.1 模型描述

Jackson 网络由 $N$ 个节点组成，每个节点 $i$ 是单服务台队列，服务率为 $\mu_i$，服务时间服从指数分布。顾客从外部以率 $\lambda_i^{\text{ext}}$ 到达节点 $i$，完成服务后以概率 $p_{ij}$ 路由至节点 $j$，以概率 $p_{i0}$ 离开系统。

路由矩阵 $P = (p_{ij})_{i,j=1,\ldots,N}$（$p_{i0} = 1 - \sum_j p_{ij}$）。

**流量平衡方程**：节点 $i$ 的总到达率 $\gamma_i$ 满足

$$\gamma_i = \lambda_i^{\text{ext}} + \sum_{j=1}^{N} \gamma_j p_{ji}$$

矩阵形式：$\boldsymbol{\gamma} = \boldsymbol{\lambda}^{\text{ext}} + P^T \boldsymbol{\gamma}$

### 8.2 Jackson 定理

**Jackson 定理** (1957)：若对每个节点 $i$ 有 $\rho_i = \gamma_i / \mu_i < 1$，则 Jackon 网络的稳态联合分布为乘积形式：

$$\boxed{P(n_1, n_2, \ldots, n_N) = \prod_{i=1}^{N} (1 - \rho_i) \rho_i^{n_i}}$$

其中 $n_i$ 为节点 $i$ 中的顾客数。

**重要性**：尽管网络中顾客在各节点间流动（非独立），各节点的稳态边际分布竟表现为独立的 $M/M/1$ 队列！这是排队网络理论中最优美也最深刻的结果之一。

**证明要点**：验证全局平衡方程。乘积形式解代入平衡方程后，利用流量平衡条件约化为各节点的局部平衡。

### 8.3 网络性能指标

各节点的平均人数 $L_i = \rho_i / (1 - \rho_i)$，网络中总平均人数 $L = \sum_i L_i$。

由 Little 定律：全网络平均逗留时间 $W = L / \lambda^{\text{total}}$，其中 $\lambda^{\text{total}} = \sum_i \lambda_i^{\text{ext}}$ 为外部到达总率。

### 8.4 BCMP 网络

BCMP 定理 (Baskett-Chandy-Muntz-Palacios, 1975) 将 Jackson 的结果推广到：
- 多类型顾客
- 多服务台节点
- 一般服务时间分布（Coxian 分布的特定情况）
- LIFO-PR、processor-sharing 等排队规则

BCMP 网络同样保持乘积形式解，但需满足服务时间分布的特定条件。

## 九、排队系统的模拟验证

### 9.1 事件驱动的离散事件仿真

对 $M/M/c$ 队列的仿真：

```python
import numpy as np

def mmc_simulation(lam, mu, c, n_customers):
    # 到达间隔和服务时间
    inter_arrivals = np.random.exponential(1.0 / lam, n_customers)
    service_times = np.random.exponential(1.0 / mu, n_customers)
    arrival_times = np.cumsum(inter_arrivals)

    # 每个服务台的可用时间
    server_free = np.zeros(c)
    wait_times = np.zeros(n_customers)

    for i in range(n_customers):
        # 最先空闲的服务台
        earliest = np.argmin(server_free)
        start_time = max(arrival_times[i], server_free[earliest])
        wait_times[i] = start_time - arrival_times[i]
        server_free[earliest] = start_time + service_times[i]

    return np.mean(wait_times), np.mean(wait_times + service_times)
```

### 9.2 排队论的工程应用

- **呼叫中心**：用 Erlang C 公式确定代理人数以满足服务等级协议 (SLA)
- **Web 服务器**：用 $M/G/c$ 模型预测响应时间，服务时间通常为 Log-normal 分布
- **医院急诊室**：用非齐次排队模型描述时变到达率
- **生产系统**：$M/M/1/K$ 模型用于缓冲区容量规划

## 十、关键总结

1. **泊松过程**：到达间隔 $\sim \text{Exp}(\lambda)$，$N(t) \sim \text{Poisson}(\lambda t)$；条件均匀分布性质使模拟简单
2. **布朗运动**：连续鞅、独立正态增量、几乎处处不可微——是随机微积分的基础构件
3. **Kendall 记号**：$A/B/c/K/N/D$ 精确刻画排队系统的六大要素
4. **Little 定律**：$L = \lambda W$ 是排队论中最普适的关系，适用于几乎所有稳态排队系统
5. **M/M/1 平稳分布**：$P_n = (1 - \rho) \rho^n$（几何分布），系统人数为几何分布
6. **M/M/1 性能指标**：$L = \rho/(1 - \rho)$，$W = 1/(\mu - \lambda)$；当 $\rho \to 1$ 时全部发散
7. **Erlang C**：$C(c, a)$ 给出 $M/M/c$ 中顾客需要等待的概率
8. **P-K 公式**：$L_q = \frac{\lambda^2 \mathbb{E}[S^2]}{2(1 - \rho)}$，服务时间方差显著影响排队长度
9. **M/D/1 对比**：确定服务时间使排队长度减半（相对 M/M/1）
10. **Jackson 定理**：网络中节点的稳态分布分解为独立的 $M/M/1$ 乘积形式
