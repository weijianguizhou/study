\section{课程定位}
控制工程基础研究控制系统分析与设计的基本方法。方框图（block diagram）是设计与分析控制系统的有力工具，可被系统地操纵与简化。本章从增益与方框图的基本变换入手，建立对系统结构的基本认识。

\section{符号说明}
为便于表述，本笔记沿用以下记号：
\begin{itemize}
	\item $X$：系统输入信号；
	\item $Y$：系统输出信号；
	\item $K$：系统（稳态）增益；
	\item $P_1,P_2$：前向通路（或支路）的传递/增益环节；
	\item 求和节点（summing junction）：其输出为各输入之代数和。
\end{itemize}
