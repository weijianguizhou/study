## 快速使用

1. 复制对应 `.tex` 文件到你的工作目录（保留同目录的图片/引用文件）；
2. 用 VS Code + LaTeX Workshop 或 TeXstudio 打开，替换所有 `【】` 标记内容；
3. `xelatex` 编译两次即可出 PDF。

## 模板规范说明

- 所有模板使用 `\documentclass` 文章类或 beamer 类，导言区已配置完整宏包；
- 中文用 `ctex` 宏包，无需额外配置字体（XeLaTeX 自动选择系统中文字体）；
- 数学公式统一用 `amsmath`，图表用 `graphicx + booktabs`；
- 参考文献推荐 `natbib + .bib`，手写方案已在模板中注释备用。
