# 课程笔记封面模板索引

`模板/课程笔记/` 下的所有封面均为**同构的 `titlepage` 片段**：字段一致、结构一致，
只换背景与插图。一次只 `\input{}` 一个。

## 1. 切换方式

在笔记本主文件 `\begin{document}` 之后，把

```latex
\input{cover}                   % 默认：深蓝学科插图风
```

换成下列任意一行（其余保持注释）：

```latex
% \input{cover_Impression风}     % 莫奈《日出·印象》
% \input{cover_Guernica风}       % 毕加索《格尔尼卡》
% \input{cover_向日葵风}         % 梵高《向日葵》
% \input{cover_呐喊风}           % 蒙克《呐喊》
% \input{cover_蒙娜丽莎风}       % 达·芬奇《蒙娜丽莎》
% \input{cover_雾海漫游者风}     % 弗里德里希《雾海上的漫游者》
% \input{cover_富春山居图风}     % 黄公望《富春山居图》
% \input{cover_千里江山图风}     % 王希孟《千里江山图》
% \input{cover_墨竹图风}         % 文同《墨竹图》
% \input{cover_墨梅图风}         % 王冕《墨梅图》
```

## 3. 可用字段

在主文件导言区用 `\newcommand` 预定义即可覆盖；封面文件内已用 `\providecommand` 兜底。

| 字段 | 说明 | 缺省值 |
|---|---|---|
| `\notename` | 主标题（**必填**，主文件定义） | 【课程名称】 |
| `\noteauthor` | 作者（**必填**，主文件定义） | 【作者姓名】 |
| `\notecourseen` | 眉题英文 | `Course Notes`（学科插图风为对应课程英文名） |
| `\notesubtitle` | 副标题 | 「学习笔记」 |
| `\noteextra` | 底部附加信息（如学期、学院） | 空（不显示） |

## 4. 二次定制

- **默认封面**（`cover.tex`，深蓝学科插图风）结构固定为 11 段：
  改第 1 段 `\shade` 换底色，改第 4 段（右上插图）与第 5 段（左下插图）换主题图形，
  其余（边框、眉题、标题、饰线、署名）无需改动。
- **艺术风**（印象 / 格尔尼卡 / 向日葵 / 呐喊 / 蒙娜丽莎 / 雾海漫游者 / 富春山居图 / 千里江山图 / 墨竹 / 墨梅）：改 `preamble.tex` 中对应配色前缀的定义即可整体换调。
- 向日葵封面的笔触与花心由 `\pgfmathsetseed` 生成随机数，改种子值可换一种笔触分布。

## 5. 坑（改封面时务必注意）

- **整页绘制的封面必须包裹 scope。** 印象风与格尔尼卡风是整幅作画，
  所有以「页面左下角为原点、单位 cm」书写的坐标，
  必须放在 `\begin{scope}[shift={(current page.south west)}]` 内；
  若直接写 `(x,y)`，在 xelatex + `overlay` 下图形会落到页面外而**完全不可见**。
  默认封面 `cover.tex` 用的是 `[xshift=…,yshift=…]current page.*` 相对写法，无此问题。
- 依赖 `\ifstrempty`（`etoolbox`）与 `calc` TikZ 库，二者 `preamble.tex` 已加载。
- 封面内主题色用 `\providecolor` 定义，单独复制封面文件到别处也能编译。
