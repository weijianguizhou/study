# 12 · 进阶技巧与资源

## 12.1 常用宏包推荐

以下按用途分类列出 LaTeX 生态中最常用的宏包：

**多语言与编码**：
- `ctex`：中文排版首选，支持 xeCJK 引擎，自动配置中文字体
- `babel`：西文多语言支持（连字规则、日期格式等）
- `polyglossia`：XeTeX/LuaTeX 下的多语言方案
- `fontspec`：XeTeX/LuaTeX 下加载系统字体

**页面布局**：
- `geometry`：灵活的页面边距设置，`\usepackage[top=2cm, left=3cm]{geometry}`
- `fancyhdr`：自定义页眉页脚
- `setspace`：行距控制（`\onehalfspacing`、`\doublespacing`）
- `titlesec` / `titletoc`：自定义标题格式和目录样式

**表格增强**：
- `tabularx`：自动宽度表格列（`X` 列类型）
- `longtable`：跨页长表格
- `booktabs`：出版物级表格线（`\toprule`、`\midrule`、`\bottomrule`）
- `multirow` / `makecell`：单元格合并与复杂表头

**算法与伪代码**：
- `algorithm2e`：灵活算法排版
- `algorithmicx` + `algpseudocode`：简洁的伪代码环境
- `listings`：源代码排版（支持语法高亮）
- `minted`：基于 Python Pygments 的高质量代码排版

**化学与物理**：
- `mhchem`：化学方程式（`\ce{H2O}`）
- `chemfig`：化学结构式
- `siunitx`：物理量和单位排版（`\SI{10}{\meter\per\second}`）
- `physics`：物理符号快捷键

**索引与术语**：
- `makeindex` / `imakeidx`：创建索引
- `glossaries`：术语表与缩略语

**其他实用宏包**：
- `enumitem`：列表自定义
- `footmisc`：脚注控制
- `multicol`：多栏排版
- `xcolor`：颜色扩展（`\color{red!30!blue}`）
- `graphicx`：图片插入
- `hyperref`：超链接（建议在导言区最后加载）
- `caption` / `subcaption`：图标题与子图

引用：Mittelbach et al., *The LaTeX Companion*, Part III 提供了宏包分类参考。

## 12.2 模板推荐

**学术论文**：
- Elsevier 模板（elsarticle）：https://www.elsevier.com/authors/policies-and-guidelines/latex-instructions
- IEEE 模板：https://template-selector.ieee.org
- ACM 模板：https://www.acm.org/publications/proceedings-template
- 国内期刊通常提供各自模板

**学位论文**：
- 各高校通常有校内模板（搜索"XX大学 LaTeX 论文模板"）
- 清华大学出版社的 *LaTeX 论文模板* 方案较为通用

**简历与求职**：
- `moderncv`：现代 CV 模板
- `altacv`：多彩 CV 模板
- `friggeri-cv`：极简设计
- Awesome-CV：https://github.com/posquit0/Awesome-CV

**书籍与笔记**：
- `memoir` 文档类：自带完整的书籍排版功能
- `tufte-book` / `tufte-handout`：爱德华·塔夫特风格的边注布局
- `kaobook`：现代书籍排版模板

**演示文稿**：
- 除 Beamer 外，`metropolis` 主题近年人气较高：`\usetheme{metropolis}`

  - 在线：https://texdoc.org

## 12.4 版本兼容与注意事项

**TeX Live 年度版**：TeX Live 每年发布新版（如 TeX Live 2025）。建议锁定年度版本，避免宏包更新引发不兼容问题。

**LaTeX2ε 与 LaTeX3**：当前稳定版本为 LaTeX2ε（自 1994 年）。LaTeX3（现已重命名为 LaTeX 内核的一部分）正在逐步整合入标准发行版。可通过 `\usepackage{xparse}` 使用 LaTeX3 风格的命令定义。

**常见陷阱**：
- `hyperref` 应尽可能在导言区**最后**加载（与其他宏包冲突较多）
- 宏包更新可能改变命令行为。查阅 `changes.pdf` 获取更新日志
- `babel` 与某些宏包存在兼容性问题，注意查阅文档
