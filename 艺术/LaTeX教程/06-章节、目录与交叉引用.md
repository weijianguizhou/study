# 第6章：章节、目录与交叉引用

结构化编排是 LaTeX 的核心优势之一。本章介绍如何组织章节层级、自动生成目录以及建立交叉引用网络。

---

## 6.1 章节目录层级

### 6.1.1 各级标题命令

LaTeX 文档类定义了完整的标题层级：

**article 文档类**（从高到低）：

| 命令 | 层级 | 说明 |
|------|------|------|
| `\section{title}` | 1 | 节 |
| `\subsection{title}` | 2 | 小节 |
| `\subsubsection{title}` | 3 | 子小节 |
| `\paragraph{title}` | 4 | 段 |
| `\subparagraph{title}` | 5 | 子段 |

**report / book 文档类** 增加 `\part`（部）和 `\chapter`（章）：

| 命令 | 层级 | 说明 |
|------|------|------|
| `\part{title}` | -1 | 部（book 特有） |
| `\chapter{title}` | 0 | 章（report/book） |
| `\section{title}` | 1 | 节 |

**示例：完整章节结构**

```latex
\documentclass[a4paper]{book}
\begin{document}
\tableofcontents
\chapter{引言}
\section{研究背景}
\subsection{国内外现状}
\subsubsection{国外研究}
\paragraph{主要方法}
\section{研究意义}
\end{document}
```

### 6.1.2 星号版本——不编号章节

在所有章节命令后加星号 `*` 可生成不编号、不入目录的标题：

```latex
\section*{致谢}
\subsection*{资助信息}
```

### 6.1.3 附录切换

`\appendix` 命令将后续章节切换为附录模式，编号变为 A, B, C, …：

```latex
\appendix
\chapter{实验数据补充}
\section{数据集描述}
```

### 6.1.4 控制编号深度

通过 `secnumdepth` 计数器控制哪些层级的标题编号：

```latex
\setcounter{secnumdepth}{3}
% article: section(1), subsection(2), subsubsection(3) 被编号
% book: chapter(0), section(1), subsection(2), subsubsection(3) 被编号
```

默认值见下表：

| 文档类 | secnumdepth 默认值 |
|--------|-------------------|
| article | 3 |
| report | 3 |
| book | 2 |

### 6.1.5 目录生成

`\tableofcontents` 自动从 `.toc` 文件读取目录结构：

```latex
\documentclass{article}
\begin{document}
\tableofcontents
\section{第一小节}
...
\end{document}
```

> **关键提醒**：目录需**编译两次**方可正确生成——第一遍写 `.toc` 文件，第二遍读取并排版。参见 Oetiker 等 *The Not So Short Introduction to LaTeX2ε* 第 2.3 节。

## 6.2 交叉引用

### 6.2.1 基本引用：\label, \ref, \pageref

LaTeX 通过一个三命令系统实现交叉引用：

| 命令 | 作用 |
|------|------|
| `\label{⟨key⟩}` | 在目标处打标签 |
| `\ref{⟨key⟩}` | 引用该处的编号 |
| `\pageref{⟨key⟩}` | 引用该处的页码 |

**示例：完整的节交叉引用**

```latex
\documentclass{article}
\begin{document}
\section{理论基础}\label{sec:theory}
...
如第~\ref{sec:theory}~节（第~\pageref{sec:theory}~页）所述，
我们采用...
\end{document}
```

`~` 为不可断行空格，确保编号不会与前面的文字断开到两行。

### 6.2.2 编译流程

交叉引用需要多遍编译：第一遍将引用信息写入 `.aux` 文件，第二遍读取并回填。对于含参考文献的文档，标准流程为：

```
xelatex → xelatex
```

若第一次编译时看到 "LaTeX Warning: Label(s) may have changed. Rerun to get cross-references right."，是正常现象，再次编译即可。

### 6.2.3 varioref 宏包：智能页码引用

`varioref` 宏包提供 `\vref` 命令，根据目标与被引用处的相对位置自动选择表述方式：

```latex
\usepackage{varioref}
```

```latex
\section{讨论}\label{sec:discuss}
...
如~\vref{sec:discuss}~所示，...
```

当目标在同一页时输出"第X节"；在不同页时输出"第X节（见第Y页）"。

### 6.2.4 cleveref 宏包：自动类型名称

`cleveref` 宏包极大地简化了引用书写，能根据标签自动识别类型（节、图、表等）：

```latex
\usepackage{cleveref}
```

```latex
\section{方法}\label{sec:method}
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{example-image}
  \caption{实验流程}\label{fig:pipeline}
\end{figure}

如~\cref{sec:method}~所述，图~\cref{fig:pipeline}~展示了流程。
```

输出为"如第1节所述，图1展示了流程"。`\Cref` 用于句首大写形式。

> 刘海洋《LaTeX 入门》第 5 章指出，cleveref 和 hyperref 配合使用时，需要注意加载顺序：**先 hyperref，后 cleveref**。

## 6.3 超链接

### 6.3.1 hyperref 宏包

`hyperref` 是 LaTeX 中实现 PDF 超链接的核心宏包：

```latex
\usepackage{hyperref}
```

加载后，它会自动将以下元素转换为可点击的超链接：

- `\tableofcontents` 中的目录项
- `\ref` / `\pageref` 的交叉引用
- `\cite` 的参考文献引用
- 文档中的 URL 文本

### 6.3.2 手动超链接命令

```latex
\href{https://example.com}{示例网站}
\url{https://www.ctan.org}
```

### 6.3.3 颜色与外观设置

通过 `\hypersetup` 配置超链接颜色和样式：

```latex
\usepackage{hyperref}
\hypersetup{
  colorlinks=true,       % 启用彩色链接（取代方框）
  linkcolor=blue,        % 内部链接颜色
  citecolor=green,       % 引用链接颜色
  urlcolor=red,          % URL 链接颜色
  bookmarks=true,        % 生成 PDF 书签
  bookmarksnumbered=true % 书签中显示编号
}
```

### 6.3.4 注意事项

> **关键原则**：`hyperref` 应尽量在导言区的**最后**加载。Mittelbach 等 *The LaTeX Companion* 第 2 版第 9 章强调了这一顺序——因为 hyperref 需要重定义 LaTeX 内核中的许多命令，晚加载可避免与其他宏包的冲突。

```latex
% 推荐加载顺序
\usepackage{graphicx}
\usepackage{amsmath}
\usepackage{natbib}
\usepackage{hyperref}   % 尽量靠后
\usepackage{cleveref}   % hyperref 之后
```
