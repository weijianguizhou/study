# 03 · 文字与段落排版

## 3.1 字体族与命令

LaTeX 的字体属性有三个维度：**字体族**（family）、**系列**（series）、**形状**（shape）。

**字体族**：

| 命令 | 效果 |
|------|------|
| `\textrm{...}` 或 `\rmfamily` | Roman（罗马体，有衬线） |
| `\textsf{...}` 或 `\sffamily` | Sans Serif（无衬线） |
| `\texttt{...}` 或 `\ttfamily` | Typewriter（等宽） |

**系列**（粗细/宽度）：

| 命令 | 效果 |
|------|------|
| `\textmd{...}` 或 `\mdseries` | Medium（中等） |
| `\textbf{...}` 或 `\bfseries` | Bold（粗体） |

**形状**：

| 命令 | 效果 |
|------|------|
| `\textup{...}` 或 `\upshape` | 直立 |
| `\textit{...}` 或 `\itshape` | 斜体 |
| `\textsl{...}` 或 `\slshape` | 倾斜 |
| `\textsc{...}` 或 `\scshape` | 小型大写 |

**字号**：从 `\tiny` 到 `\Huge` 共 10 级命令，皆为声明式（影响后续内容直至分组结束）。

```latex
{\tiny 极小} {\small 小} {\normalsize 正常} {\large 大} {\Large 更大} {\huge 巨大}
```

**中文字体**：使用 ctex 宏包后，可用 `\songti`（宋体）、`\heiti`（黑体）、`\kaishu`（楷书）、`\fangsong`（仿宋）。

## 3.2 段落控制

段落由空行分隔。相关控制：

- `\par`：显式段结束
- `\parindent`：段落缩进长度，`\setlength{\parindent}{2em}` 设为两字宽
- `\parskip`：段间距，`\setlength{\parskip}{0.5em}`
- `\linespread{factor}`：行距倍数，`\linespread{1.5}` 相当于 Word 1.5 倍行距
- 更精细的行距控制可用 `setspace` 宏包：`\singlespacing`、`\onehalfspacing`、`\doublespacing`

段落对齐环境：

| 环境 | 效果 | 对应声明 |
|------|------|----------|
| `center` | 居中对齐 | `\centering` |
| `flushleft` | 左对齐 | `\raggedright` |
| `flushright` | 右对齐 | `\raggedleft` |

```latex
\begin{center}
居中的段落内容。
\end{center}
```

## 3.3 列表环境

LaTeX 提供三种列表环境：

```latex
% 无序列表
\begin{itemize}
  \item 第一项
  \item 第二项
\end{itemize}

% 有序列表
\begin{enumerate}
  \item 第一步
  \item 第二步
\end{enumerate}

% 描述列表
\begin{description}
  \item[术语] 定义内容
  \item[LaTeX] 排版系统
\end{description}
```

列表可嵌套（最多四层），每层自动使用不同的标签符号。**enumitem** 宏包提供高级控制：

```latex
\usepackage{enumitem}
\begin{enumerate}[label=\alph*), itemsep=0pt]
  \item 自定义标签
  \item 无间距
\end{enumerate}
```

## 3.4 断词与对齐

LaTeX 默认采用两端对齐（justified），为达到均匀行尾而自动断词。断词控制：

- 手动断词点：`\-`，如 `hy\-phen\-ation`
- 全局规则：`\hyphenation{hy-phen-ation}`
- 宽松断词：`\sloppy`（允许更大间距），恢复：`\fussy`
