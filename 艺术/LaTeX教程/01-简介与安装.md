# 01 · 简介与安装

## 1.1 什么是 TeX / LaTeX

TeX 是美国计算机科学家 Donald E. Knuth（高德纳）于 1978 年发布的排版引擎。Knuth 因其著作《计算机程序设计艺术》（*The Art of Computer Programming*）的排版质量不满，遂自行开发了一套排版系统。他在 *The TeXbook*（1986）中写道："TeX 旨在用于生成高质量的技术文本和数学公式书籍。它特别擅长处理数学公式，但这并不意味着它仅限于数学领域。"（Knuth, *The TeXbook*, p.1）

LaTeX 是 Leslie Lamport 于 1984 年基于 TeX 开发的一套宏包集合。Lamport 在 *LaTeX: A Document Preparation System*（2nd ed., 1994）中这样表述："LaTeX 是一套用于排版的宏包，它让作者能够专注于内容本身，而非格式的细节。"（Lamport, 1994, p.1）LaTeX 的核心哲学是**内容与样式分离**：作者用标记描述文档的逻辑结构（标题、章节、图表），而格式细节交由文档类与宏包自动处理。

LaTeX 与 Word 等所见即所得（WYSIWYG）编辑器的根本差异在于：

| 特征 | LaTeX | Word |
|------|-------|------|
| 内容与样式关系 | 分离（标记式） | 混合（直接操作） |
| 数学公式 | 极致精美 | 勉强可用 |
| 大型文档管理 | 强（自动编号、交叉引用） | 弱（需手动维护） |
| 跨平台一致性 | 完全相同 | 依赖版本和字体 |
| 学习曲线 | 陡峭 | 平缓 |

常用的 LaTeX 编译引擎对比如下（详见第11章）：

- **pdflatex**：直接输出 PDF，中文支持需额外配置
- **xelatex**：支持 Unicode 和操作系统字体，**推荐中文用户**
- **lualatex**：支持 Lua 脚本扩展，字体处理更为灵活

## 1.2 TeX 发行版选择

一个"TeX 发行版"打包了 TeX/LaTeX 引擎、数千个宏包、字体和辅助工具。主流发行版有三个：

**TeX Live**（跨平台，推荐）：
- 涵盖 Windows / macOS / Linux
- 每年更新（如 TeX Live 2025）
- 安装时建议选择"full scheme"获得完整宏包
- 验证安装：`tex --version`、`xelatex --version`

**MiKTeX**（Windows）：
- 按需自动安装缺失宏包（联网）
- 管理界面更图形化
- 适合硬盘空间有限的用户

**MacTeX**（macOS）：
- 本质上是 TeX Live 的 macOS 版本
- 包含 TeXShop 编辑器等附加工具

## 1.3 编辑器配置

**VS Code + LaTeX Workshop（推荐）**：
1. 安装 VS Code
2. 在扩展市场搜索安装 LaTeX Workshop
3. 配置 `settings.json`：
```json
{
  "latex-workshop.latex.tools": [
    {"name": "xelatex", "command": "xelatex", "args": ["-synctex=1", "-interaction=nonstopmode", "%DOC%"]}
  ],
  "latex-workshop.latex.recipes": [
    {"name": "xelatex*2", "tools": ["xelatex", "xelatex"]}
  ]
}
```

**TeXstudio**：图形化集成环境，内置公式预览，适合初学者。

**Overleaf**：在线 LaTeX 编辑器，无需本地安装，支持协作编辑。

## 1.4 第一个 LaTeX 文档

```latex
\documentclass{article}
\usepackage{ctex}      % 中文支持

\begin{document}
\title{我的第一个 LaTeX 文档}
\author{作者}
\date{\today}
\maketitle

\section{引言}
这是用 \LaTeX{} 排版的第一个文档。
\end{document}
```

将上述内容保存为 `hello.tex`，然后运行：

```
xelatex hello.tex
xelatex hello.tex   (第二遍确保目录与引用正确)
```

两次编译的原因：第一遍将辅助信息写入 `.aux` 文件，第二遍读取信息生成正确的交叉引用。成功后将得到 `hello.pdf`。
