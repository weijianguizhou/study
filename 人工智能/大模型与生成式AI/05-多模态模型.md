# 多模态模型

> 人类通过视觉、语言、声音感知世界。多模态模型把**图像、文本、音频、视频**统一进同一个神经网络。本篇覆盖三大方向：**视觉语言模型（VLM）**、**文生图（扩散模型）**、**文生视频与音频**，并给出 CLIP 的完整实战。

## 1. 什么是多模态

### 1.1 定义

多模态模型处理多种模态数据（$\mathbf{x}_{\text{text}}, \mathbf{x}_{\text{image}}, \mathbf{x}_{\text{audio}}, \mathbf{x}_{\text{video}}$），并建模它们的**联合分布**或**跨模态对齐**：

$$
P(\mathbf{x}_{\text{text}}, \mathbf{x}_{\text{image}}, \mathbf{x}_{\text{audio}}) = ?
$$

两个关键任务方向：
- **理解**：图→文（VQA、图像描述）、文→图（检索）、音→文（ASR）；
- **生成**：文→图（Stable Diffusion）、文→视频（Sora）、文→音（TTS）。

### 1.2 模态分类概览

| 方向 | 输入 → 输出 | 代表模型 |
|------|-------------|----------|
| 视觉语言理解 | 图+文 → 文 | CLIP、BLIP-2、Qwen-VL、GPT-4o、Gemini |
| 文生图 | 文 → 图 | Stable Diffusion、DALL·E、FLUX |
| 文生视频 | 文/图 → 视频 | Sora、Runway、可灵 |
| 语音识别 | 音 → 文 | Whisper |
| 文生语音 | 文 → 音 | VITS、ChatTTS |

## 2. 视觉编码器与跨模态对齐

### 2.1 ViT：视觉 Transformer

把图像切成 $P \times P$ 的 patch（如 16×16），展平后加位置编码送入 Transformer（[[../深度学习教程/09-卷积神经网络CNN|CNN]] 提到 CNN 做局部感知，ViT 用自注意力做全局建模）：

$$
\mathbf{x} = [\text{CLS}; \; E p_1; \; E p_2; \dots; E p_N] + \mathbf{P}_{pos} \in \mathbb{R}^{(N+1) \times d}
$$

ViT 在 `CLS` token 上接分类头，预训练后即视觉特征提取器。

### 2.2 CLIP：图文对比学习

CLIP（Contrastive Language-Image Pre-training）核心思想：把**图像和文本映射到同一向量空间**，用对比学习对齐。对一批 $N$ 个（图, 文）对，最大化对角线相似度、最小化非对角线：

$$
\mathcal{L}_{\text{CLIP}} = -\frac{1}{2}\left( \log \frac{e^{s/\tau}}{\sum_{j} e^{s_{i,j}/\tau}} + \log \frac{e^{s_{i,i}/\tau}}{\sum_{j} e^{s_{j,i}/\tau}} \right), \quad s_{i,j} = \frac{\mathbf{v}_i \cdot \mathbf{t}_j}{\|\mathbf{v}_i\| \|\mathbf{t}_j\|}
$$

其中 $\mathbf{v}_i$ 是图像编码器输出，$\mathbf{t}_j$ 是文本编码器输出，$\tau$ 是温度。训练后：**图文检索、zero-shot 分类、作为下游 VLM/文生图的底座**。

### 2.3 从 CLIP 到 VLM：连接器

VLM 需要"看图+读文+对话"，但语言模型只能吃文本。于是用**连接器**把视觉特征映射为语言模型能用的"视觉 token"：

| 方法 | 连接器 | 说明 |
|------|--------|------|
| LLaVA | 线性投影 + MLP | 视觉特征直接投影，简单有效 |
| BLIP-2 | Q-Former（可学习 Query） | 用 Query 交叉注意力"抽取"视觉信息 |
| Qwen-VL / MiniGPT | 重采样器（Perceiver） | 压缩视觉 token 数，省计算 |

**Q-Former 思路**：用一组可学习的 query 向量 $\mathbf{Q} \in \mathbb{R}^{M \times d}$，通过交叉注意力从视觉特征 $\mathbf{V}$ 中提取 $M$ 个"视觉摘要 token"，再送入 LLM：

$$
\mathbf{Q}' = \text{CrossAttention}(\mathbf{Q}, \mathbf{V}, \mathbf{V}) \approx \text{softmax}\left(\frac{\mathbf{Q}\mathbf{V}^T}{\sqrt{d}}\right)\mathbf{V}
$$

**视觉 token 数量**是 VLM 的显存/算力瓶颈：一张 448×448 图在 patch 14 下约 1024 个 token；Qwen-VL 用重采样器压到 256 个。

### 2.4 主流 VLM 对比

| 模型 | 视觉编码器 | 连接器 | 多语言 | 特点 |
|------|-----------|--------|--------|------|
| LLaVA 1.5 | CLIP ViT-L | MLP | 英文 | 开源标杆、SFT 数据开放 |
| BLIP-2 | CLIP | Q-Former | 英文 | 高效、通用 |
| Qwen-VL | ViT | 重采样器 | 中文好 | 中文 VLM 首选 |
| InternVL | ViT+ | 多级融合 | 中英 | 开源性能强 |
| GPT-4o / Gemini | 原生统一 | — | 多语 | 端到端多模态 |

## 3. 文生图：Stable Diffusion

### 3.1 扩散模型基础

扩散模型在 [[../深度学习教程/15-扩散模型|扩散模型]] 中完整展开，这里只给出 Stbl Diffusion 用到的最小闭环。扩散过程（前向加噪）与去噪（反向生成）：

前向：$\mathbf{x}_t = \sqrt{\bar{\alpha}_t}\,\mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t}\,\epsilon$

去噪网络 $\epsilon_\theta$ 预测噪声，损失：

$$
\mathcal{L} = \mathbb{E}_{t, \epsilon}\left[ \left\| \epsilon - \epsilon_\theta(\mathbf{x}_t, t) \right\|^2 \right]
$$

### 3.2 Stable Diffusion 三段式

Stable Diffusion 引入**潜空间（Latent Space）**，在 VAE 的隐变量上做扩散，大幅降低计算量：

```
文本 "一只戴眼镜的柴犬宇航员" 
   │
   ├─► 文本编码器(CLIP Text) ──► 文本条件 c
   │
   ├─► VAE 编码器: 图像 → 潜变量 z₀（64×64×4，比 512×512×3 小 64 倍）
   │
   ├─► U-Net + 交叉注意力 在潜空间去噪（条件为 c）
   │       z_t → z_{t-1} → ... → z₀
   │
   └─► VAE 解码器: z₀ → 512×512 RGB 图像
```

U-Net 中的**交叉注意力**把文本条件注入每个去噪步（[CLIP Text] 作 K/V，图像特征作 Q）：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d}}\right) V, \quad K, V \text{ 来自文本编码器}
$$

### 3.3 三类文生图对比

| 模型 | 范式 | 生成质量 | 速度 | 开源 |
|------|------|----------|------|------|
| DALL·E 2 | CLIP 引导扩散 | 高 | 慢 | 否 |
| Stable Diffusion | 潜空间扩散 | 中高 | 快 | ✅ |
| FLUX | 整流流（Rectified Flow） | 高 | 中 | ✅ |
| 自回归生成（Gemini 2.0） | token 化图像 | 高 | 快 | — |

## 4. 文生视频：Sora 与 DiT

### 4.1 视频 = 带时间维的图像

视频生成的关键是建模**空间 + 时间**。Sora 的做法：

1. 用视频压缩网络把视频编码为**时空 patch（spatio-temporal patches）**；
2. 用 **DiT（Diffusion Transformer）** 在 patch 序列上做扩散去噪（Transformer 替换 U-Net 作为去噪主干）；
3. 输出 patch 再解码为视频帧。

DiT 的核心：对潜变量 patch 序列 $\mathbf{z}_1..\mathbf{z}_N$ 走标准 Transformer 块（自适应 LayerNorm 注入时间步 $t$ 与条件）：

$$
\text{AdaLN: } h' = \gamma(t, c) \cdot \frac{h - \mu}{\sigma} + \beta(t, c)
$$

### 4.2 视频生成的难点

| 难点 | 表现 | 当前对策 |
|------|------|----------|
| 时间一致性 | 物体闪烁、变形 | 时空注意力、长程建模 |
| 物理规律 | 杯子下落不真实 | 大模型数据学习 + 物理约束 |
| 计算量 | 视频 token 是图像数倍 | 高效注意力、蒸馏 |
| 时长 | 只能生成短片段 | 滑动窗口、自回归扩帧 |

### 4.3 视频生成的两种范式

| 范式 | 代表 | 思路 | 特点 |
|------|------|------|------|
| 潜空间扩散 | Stable Video Diffusion | 图像扩散扩展到视频 | 质量高，速度慢 |
| DiT | Sora | 时空 patch + Transformer | 长程一致性好，算力大 |
| 自回归 | Gemini 2.0 | 视频 token 化逐帧预测 | 快、可控 |
| 蒸馏/级联 | 可灵、Veo | 关键帧 + 插帧 | 工程成熟 |

## 5. 音频与语音：Whisper

Whisper（OpenAI，2023）是 ASR（自动语音识别）的标杆，采用 encoder-decoder 结构：

- 输入：80 通道 log-Mel 频谱特征；
- 输出：文本 token；
- 训练：30 秒音频片段 + 对应文本，多语言、多任务（识别/翻译/时间戳）。

推理流程：音频 → 频谱 → encoder → decoder 自回归生成文本。

### 5.1 Whisper 实战（ASR）

```python

model = whisper.load_model("base")        # tiny/base/small/medium/large
result = model.transcribe("meeting.wav", language="zh")
print(result["text"])

```

## 6. 多模态统一训练范式

多模态模型的训练通常分三阶段（以 VLM 为例）：

1. **预训练（对齐）**：图文对比（CLIP）或图文生成，让视觉与文本表征对齐；
2. **指令微调（SFT）**：用图文对话数据教"看图说话"；
3. **偏好对齐（DPO/RLHF）**：偏好数据教"答得更好"。

$$
\text{Image} \xrightarrow{\text{Encoder}} \mathbf{v} \xrightarrow{\text{Connector}} \text{VL token} \xrightarrow{\text{LLM}} \text{回答}
$$

原生多模态（Gemini、GPT-4o）更进一步：所有模态直接 token 化进同一 Transformer 联合预训练，跨模态对齐由数据自动涌现，不再依赖"编码器 + 连接器"的拼装。

## 7. 多模态评估与挑战

### 7.1 评估维度

| 方向 | 指标 | 说明 |
|------|------|------|
| VLM | VQA 准确率、图文检索 Recall@k | 理解质量 |
| 文生图 | FID、CLIP-Score、人类偏好 | 生成分布相似度 + 语义对齐 |
| 文生视频 | FVD、时序一致性、人类评估 | 视频质量 + 时间连贯 |
| ASR | WER（词错误率） | 字准度 |

FID（Fréchet Inception Distance）：衡量生成图像分布与真实分布的差距：

$$
\text{FID} = \|\mu_g - \mu_r\|^2 + \text{Tr}\left( \Sigma_g + \Sigma_r - 2(\Sigma_g \Sigma_r)^{1/2} \right)
$$

### 7.2 核心挑战

1. **跨模态幻觉**：模型"看图说话"时可能生成图里没有的内容；
2. **对齐成本**：不同模态 Token 化、分辨率、采样率各异，统一困难；
3. **安全**：文生图版权、人脸生成滥用、色情内容；
4. **评测难**：生成质量主观，缺乏统一自动指标；
5. **算力**：视频/高分辨率图像 token 数爆炸。

## 8. Python 实战：CLIP 图文匹配

### 8.1 零样本分类 / 图文匹配

```python
# pip install transformers pillow
from transformers import CLIPProcessor, CLIPModel
from PIL import Image

model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

image = Image.open("cat.png")
texts = ["a photo of a cat", "a photo of a dog", "a photo of a bird"]

inputs = processor(text=texts, images=image, return_tensors="pt", padding=True)
with torch.no_grad():
    outputs = model(**inputs)
    logits_per_image = outputs.logits_per_image   # 图 × 文 相似度
    probs = logits_per_image.softmax(dim=-1)

print({t: round(p, 3) for t, p in zip(texts, probs[0].tolist())})
# {'a photo of a cat': 0.98, 'a photo of a dog': 0.01, 'a photo of a bird': 0.01}
```

### 8.2 图文检索（embedding 检索，类似 RAG）

```python
import torch
import torch.nn.functional as F

def embed_images(paths):
    imgs = [Image.open(p) for p in paths]
    inputs = processor(images=imgs, return_tensors="pt", padding=True)
    with torch.no_grad():
        return model.get_image_features(**inputs)

def embed_texts(texts):
    inputs = processor(text=texts, return_tensors="pt", padding=True)
    with torch.no_grad():
        return model.get_text_features(**inputs)

img_vecs = embed_images(["a.png", "b.png", "c.png"])
text_vec = embed_texts(["夕阳下的海滩"])

score = F.cosine_similarity(text_vec, img_vecs)
best = score.argmax().item()
print(f"最匹配图片: {paths[best]}, 相似度 {score[best]:.3f}")
```

### 8.3 加载 VLM 做图文对话

```python
from transformers import AutoProcessor, Qwen2VLForConditionalGeneration

processor = AutoProcessor.from_pretrained("Qwen/Qwen2-VL-2B-Instruct")
model = Qwen2VLForConditionalGeneration.from_pretrained("Qwen/Qwen2-VL-2B-Instruct")

messages = [{
    "role": "user",
    "content": [
        {"type": "image", "image": "chart.png"},
        {"type": "text", "text": "这张图说明了什么趋势？请用中文回答。"},
    ],
}]
text = processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
inputs = processor(text=[text], images=["chart.png"], return_tensors="pt")
out = model.generate(**inputs, max_new_tokens=128)
print(processor.decode(out[0], skip_special_tokens=True))
```

## 9. 选型建议

| 需求 | 推荐 |
|------|------|
| 中文图文理解 | Qwen-VL / InternVL |
| 英文高质量图文 | GPT-4o / Claude / LLaVA-Next |
| 文生图（开源） | SDXL / FLUX |
| 文生视频（开源） | DiT 系 / 可灵 |
| 语音识别 | Whisper |

> 多模态的统一趋势：**原生多模态**（Gemini、GPT-4o）不再"拼接"各模态编码器，而是把所有模态 token 化进同一个 Transformer，跨模态对齐由联合预训练自动涌现。
