# 大模型与生成式 AI · 索引

> 大语言模型（LLM）与生成式 AI 是 2020 年代以来 AI 领域最大的范式跃迁：把"教模型学知识"变成"从海量文本中预测下一个词"，却在零样本/少样本任务上涌现出推理、规划、工具使用等能力。本目录从原理出发，覆盖提示工程、微调、RAG、多模态、智能体与推理部署，构成一条从"理解 Transformer"到"搭建生产级大模型应用"的完整路径。

## 主流模型家族

### 按公司/组织划分

| 家族 | 代表模型 | 开源 | 特点 | 技术要点 |
|------|----------|------|------|----------|
| OpenAI GPT | GPT-3 / GPT-4 / o1 | 否 | 首发 RLHF、指令遵循最强 | decoder-only + RLHF + CoT 推理链 |
| Meta Llama | Llama 2 / 3 | ✅ | 开源生态标杆 | RoPE、GQA、Llama 3 训练 15T tokens |
| DeepSeek | DeepSeek-V3 / R1 | ✅ | 极致低成本、推理强 | MoE + MLA（Multi-head Latent Attention） |
| 阿里 Qwen | Qwen 1.5 / 2.5 / 3 | ✅ | 中文最优之一、Agent 工具调用好 | 长上下文、Function Calling |
| Anthropic Claude | Claude 3/3.5/4 | 否 | 长上下文、安全对齐强 | Constitutional AI、宪法式对齐 |
| Google Gemini | Gemini 1.5 / 2.0 | 部分 | 原生多模态、超长上下文 | 1M tokens 上下文、原生多模态训练 |

### 按规模与设计思想划分

- **稠密模型（Dense）**：所有参数每 token 都激活，如 Llama 70B、GPT-3。
- **稀疏专家混合（MoE）**：总参数量大、每次只激活一部分，如 DeepSeek-V3（671B 总 / 37B 激活）、Mixtral 8x7B。见 01 篇 MoE 小节。
- **推理链模型（Reasoning）**：o1、DeepSeek-R1，显式生成"思维过程"再作答，见 02 篇 CoT。
- **多模态（Multimodal）**：Gemini、GPT-4o、Qwen-VL，见 05 篇。

### 开源 vs 闭源怎么选

| 维度 | 闭源 API（GPT-4、Claude） | 开源自部署（Llama、Qwen、DeepSeek） |
|------|---------------------------|--------------------------------------|
| 成本 | 按 token 计费，小规模划算 | 前期算力投入高，规模化后边际成本低 |
| 数据安全 | 数据出域，受供应商政策约束 | 数据本地化，满足合规要求 |
| 定制能力 | 仅能通过 prompt / Function 定制 | 可微调、可蒸馏、可接入内部系统 |
| 性能上限 | 通常领先（生态与算力） | 追赶中，部分任务已持平 |
| 延迟 | 受网络影响 | 本地可控 |

> 工程上的务实做法：**快速原型用 API，稳定服务看数据敏感性自部署**，两者通过 OpenAI 兼容接口无缝切换（见 07 篇）。

## 一个最小技术演进时间线

```
2017 Transformer ──► 2018 GPT-1 / BERT（预训练+微调范式）
   ──► 2020 GPT-3（175B，In-Context Learning 被发现）
   ──► 2022 ChatGPT（RLHF 对齐，ChatGPT 效应）
   ──► 2023 GPT-4、Llama 2、文生图扩散模型成熟
   ──► 2024 开源追赶（Qwen/Llama 3/DeepSeek）、Agent 元年、长上下文
   ──► 2025 推理链模型（o1/R1）、多模态统一、Agent 工程化
```

每个阶段的完整原理分别在 01（预训练与对齐）、02（ICL 的发现）、05（多模态）、06（Agent）中展开。

> 规律总结：每隔 1–2 年出现一次"能力台阶"（指令遵循 → 多模态 → 长上下文 → 推理链 → Agent），但每级台阶都踩在上一步的架构与数据之上——掌握机制，就不怕新名词。

## 大模型能力评测基准

选择或比较模型时，常看这几类基准（评估方法论见 [[../机器学习教程/01-模型评估与交叉验证|模型评估]]）：

| 基准 | 测什么 | 说明 |
|------|--------|------|
| MMLU / MMLU-Pro | 知识广度 | 57 学科多项选择，看世界知识 |
| GSM8K / MATH | 数学推理 | 小学/竞赛级算术，看推理链 |
| HumanEval / MBPP | 代码能力 | 从 docstring 生成函数 |
| GPQA / ARC | 难题与科学推理 | 人类专家也难的高难度集 |
| IFEval | 指令遵循 | 是否遵守格式/长度/约束 |
| LongBench | 长上下文 | 长文档理解与检索 |
| Arena / LLM-Judge | 人类偏好 | 双盲对战胜率 |

> 读论文别只看"一个分"，要看**基准是否被污染**（训练数据含测试题）与任务是否匹配你的场景。垂直场景应自建评估集。

## 本目录核心公式速查

以下公式在本目录各篇中展开推导，这里集中一处便于检索：

| 公式 | 内容 | 出处 |
|------|------|------|
| 交叉熵损失 | $\mathcal{L} = -\frac{1}{N}\sum\sum \log P_\theta(x_t \mid x_{<t})$ | 01 |
| 缩放定律 | $L(N) = a N^{-\alpha} + L_0$ | 01 |
| LoRA | $W' = W + BA$，参数 $r(d_{in}+d_{out})$ | 03 |
| 余弦相似度 | $\text{sim} = \frac{\mathbf{q}\cdot\mathbf{d}}{\|\mathbf{q}\|\|\mathbf{d}\|}$ | 04 |
| RRF 融合 | $\text{RRF}(d) = \sum_r \frac{1}{k + \text{rank}_r(d)}$ | 04 |
| DPO 损失 | $-\log\sigma\left(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right)$ | 01/03 |
| 量化误差 | $\hat{x} = x_q \cdot s$，误差 $\approx s^2$ 量级 | 07 |
| 相似度检索 | $\text{Top-}k$ 近邻（ANN/HNSW） | 04 |

## 本套笔记的组织约定

- **命名**：`NN-主题.md`，`00` 是索引，`01–07` 按"原理 → 应用 → 工程"排序；
- **层级**：`#` 篇标题、`##` 章节、`###` 小节；公式一律 `$$...$$` 独立成块；
- **链接**：站内用 wiki-link 相对路径（`[[../深度学习教程/...|别名]]`），目录内部互链用短名（`[[03-微调|微调]]`）；
- **代码**：Python 片段标注所需依赖，示例多为可运行的最小实现；
- **更新原则**：模型/框架迭代快，笔记更新时优先修正"机制类"内容，避免堆砌过期版本号。

## 常见问题（FAQ）

**Q：需要先学强化学习吗？**
RLHF 只用到 PPO 的直觉（旧笔记见 [[../RL-PPO理论|PPO]]），01 篇会给出不依赖前置的简述；若只做应用层，跳过 RLHF 数学细节不影响 02–07。

**Q：现在学这些会不会很快过时？**
底层三件事长期稳定：自回归目标、注意力架构、缩放定律。提示工程、Agent 框架、推理引擎迭代快，但都是这三件事的工程外延。

**Q：数学基础不扎实，能跟上吗？**
能。本篇公式只用到概率、矩阵与信息论的基础（[[../深度学习教程/01-数学基础-线性代数|线性代数]]、[[../深度学习教程/03-数学基础-概率与统计|概率统计]]），遇到推导卡壳就点进对应教程回炉，不要硬啃。

**Q：没有 GPU 能学吗？**
能。01–04、06 用 API + 小模型即可；07 涉及部署可在 Ollama / 云 GPU（Colab）上练习。

**Q：一套笔记读完，掌握的标准是什么？**
能不看笔记完成"面试考点清单"中至少 8 题，并独立跑通"推荐实验项目"的第 2、3 项——此时已具备进入真实项目的入场券。
