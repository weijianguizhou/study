# 语音识别与语音合成

> 语音是人与机器最自然的交互方式。本章覆盖两大方向：**ASR（自动语音识别）**——把语音变成文字，和 **TTS（语音合成）**——把文字变成语音，并顺带介绍声纹识别与语音情感分析。从信号基础、MFCC 特征讲到端到端模型与 Whisper 大模型。

---

## 1. 语音信号基础

### 1.1 声音是什么

声音是空气压强的波动，麦克风以固定频率**采样**把它变成数字序列 $x[n]$：

```
模拟声波 → 采样（每秒 fs 个点）→ 量化 → 数字语音 x[n]
```

- **采样率 $f_s$**：每秒采样次数。电话 8kHz、WAV 16kHz、音乐 44.1kHz。
- **奈奎斯特定理**：要保留最高频率 $f_{\max}$ 的信号，必须 $f_s \ge 2 f_{\max}$。
- 每样本位深：16bit 常见，量化电平 $2^{16} = 65536$。

### 1.2 短时分析

语音是**非平稳**信号（清浊音交替），但在 ~25ms 的短窗内可视为**平稳**，因此按**帧**处理：

- **帧长**：25ms；**帧移（hop）**：10ms。
- 对每帧加窗（汉明窗）→ 做 FFT → 得到频谱。

### 1.3 MFCC 特征

**MFCC（Mel 频率倒谱系数）** 是经典语音特征，模拟人耳"对低频敏感、对高频迟钝"的特性。提取流程：

```
预加重 → 分帧加窗 → FFT → Mel 滤波器组 → 取对数 → DCT → MFCC
```

1. **预加重**：$y[n] = x[n] - \alpha x[n-1]$（$\alpha \approx 0.97$），提升高频。
2. **分帧加窗**：25ms/10ms，Hamming 窗。
3. **FFT**：每帧得功率谱 $|X[k]|^2$。
4. **Mel 滤波器组**：将频率映射到 Mel 刻度：

$$
f_{\text{mel}} = 2595 \log_{10}\left(1 + \frac{f}{700}\right)
$$

5. **取对数 + DCT**：压缩动态范围，去相关，得 13–40 维 MFCC 向量。

> 每帧得到一个 MFCC 向量，整段语音就是**特征序列** $\mathbf{x}_{1:T}$，可直接喂给 HMM 或深度模型。现在端到端模型常直接用原始波形或 Fbank（不做 DCT）。

## 2. ASR 演进：GMM-HMM → 端到端 → 大模型

### 2.1 任务定义

输入声学特征序列 $\mathbf{x}_{1:T}$，输出文字序列 $\mathbf{w}_{1:N}$（$N \ll T$，因为一帧 ~10ms）：

$$
\hat{\mathbf{w}} = \arg\max_{\mathbf{w}} P(\mathbf{w} \mid \mathbf{x})
$$

经典分解（语言模型 × 声学模型，由贝叶斯导出）：

$$
P(\mathbf{w} \mid \mathbf{x}) \propto \underbrace{P(\mathbf{x} \mid \mathbf{w})}_{\text{声学模型}} \cdot \underbrace{P(\mathbf{w})}_{\text{语言模型}}
$$

### 2.2 传统方案：GMM-HMM（2000s 主流）

- **HMM**：建模音素序列（状态），与 NLP 中用于词性标注的 HMM 同源（见 [[../自然语言处理NLP/02-序列标注与HMM|序列标注与 HMM]]）。
- **GMM**：对每个状态的声学特征分布建模：$P(\mathbf{x} \mid \text{状态}) = \sum_k \pi_k \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \Sigma_k)$。

```
文字 → 发音词典 → 音素序列 → HMM 状态序列
声学特征 → GMM 打分 → Viterbi 对齐解码
```

- 训练需要**强制对齐**（人分好状态边界），工程复杂（三音素、决策树聚类）。
- 1990s–2010s 统治 ASR，现在已基本退出主流。

### 2.3 深度时代的过渡：DNN-HMM（2012）

用 **DNN** 替代 GMM 输出状态后验 $P(\text{状态} \mid \mathbf{x})$，精度大幅提升，但仍保留 HMM 的时间结构与强制对齐。

### 2.4 端到端：CTC（2015）

**CTC（Connectionist Temporal Classification）** 解决了"输入帧数 ≫ 输出字数"的**对齐问题**：不再需要人标对齐，模型输出一个比文本长的序列，通过**去重 + 去空白**还原文字。

**对齐机制**：引入"空白符" $\epsilon$，允许重复。给定输入 $\mathbf{x}$，模型对每帧输出概率 $P(y_t \mid \mathbf{x})$，路径 $\boldsymbol{\pi}$ 经**折叠规则**映射为文字序列：

- 合并相邻相同符号 → 删除空白 $\epsilon$。

$$
\text{abcc} \to \text{abc}, \qquad \text{a}\epsilon\text{b}\epsilon \to \text{ab}
$$

CTC 损失：所有能折叠成目标文本 $\mathbf{w}$ 的路径概率之和取负对数：

$$
\mathcal{L}_{\text{CTC}} = -\log \sum_{\boldsymbol{\pi} \in \mathcal{B}^{-1}(\mathbf{w})} \prod_{t=1}^{T} P(\pi_t \mid \mathbf{x})
$$

求和用**动态规划（前向后向算法）**高效计算（$O(T \cdot |\mathbf{w}|)$）。

> **直觉**：模型每帧可以输出文字或空白，允许"拖延与重复"；只要所有合法路径加起来概率高就行——天然解耦"对齐"与"识别"，无需强制对齐标注。

### 2.5 端到端：Attention / Transformer ASR

- **Attention Seq2Seq**：encoder 编码声学特征，decoder 用注意力逐步生成文字，直接端到端。
- **Transformer ASR**（Conformer 等）：卷积增强的 Transformer 编码器。
- **RNN-T**（2018）：流式实时识别的主力，输出"文字或空白"两种动作，逐帧决策。

> 模型结构基础见 [[../深度学习教程/12-Transformer与大模型|Transformer]] 与 [[../深度学习教程/11-RNN与LSTM|RNN/LSTM]]。

### 2.6 大模型时代：Whisper（2022）

**OpenAI Whisper** 是多语言弱监督 ASR 大模型（680k 小时数据），特点：

- **多任务**：识别、翻译、语言检测、时间戳——单模型全包。
- **编码器-解码器 Transformer**，30s 音频窗口，LogMel 谱图输入。
- 覆盖 96+ 种语言，中文识别效果好，尤其对噪声/口音鲁棒。
- 开源权重 `tiny/base/small/medium/large`，本地可跑。

```
音频 → 16kHz 重采样 → LogMel 谱 → [Whisper Encoder] → [Whisper Decoder]
      → 文字 / 翻译 / 时间戳
```

> Whisper 是"语音大模型"的代表，与文本大模型共用 Transformer 架构，只是输入模态不同（见 [[../大模型与生成式AI/05-多模态模型|多模态]]）。

## 3. CTC 损失直觉补充

为什么 CTC 能"不用对齐标注"？

- **生成式思路**：把"正确文字"看成很多条对齐路径的集合，训练就是**把集合总概率最大化**。
- 例：目标文本 "cat"，$T=6$ 帧，合法路径如：

```
c a t ϵ ϵ ϵ   c c a t ϵ ϵ   c ϵ a a t t   c a ϵ t t ϵ ...
```

- 模型学会"早点说、晚点说、重复说都可以"，最终在解码时取总概率最大的文本（或加语言模型做 beam search）。

**CTC vs Attention**：

| | CTC | Attention |
|--|-----|-----------|
| 对齐 | 隐式（动态规划求和） | 显式注意力权重 |
| 单调性 | 天然单调（适合语音） | 不强制 |
| 流式 | 容易（帧级输出） | 难（需整个输入） |
| 常见场景 | 语音、OCR 序列 | 翻译、摘要 |

## 4. TTS：语音合成

### 4.1 任务定义

**TTS（Text to Speech）**：把文字 $\mathbf{w}$ 合成为语音波形 $\mathbf{x}$。三大技术路线演进：

### 4.2 统计参数 TTS（2000s）

```
文本 → 前端（分词/韵律）→ 声学模型（HMM）→ 参数（F0、频谱包络）
     → 声码器（Vocoder）重建波形
```

代表：HTS 系统。声音像"机器人"，需要大量工程。

### 4.3 神经 TTS（2016 – 2019）

**Tacotron（2016）**：Seq2Seq + Attention，直接从文本到 Mel 谱图，再交给**声码器**（WaveNet/GRU-LSTM）合成波形。

**Tacotron 2**：文本 → Mel 谱 → WaveNet 声码器，质量接近自然语音。

**单模型全流程**：FastSpeech（非自回归、快）、**VITS（2021）**——用 VAE + GAN + 归一化流，**文本直接端到端合成波形**，兼顾高质量与快速度，是开源 TTS 标杆。

```
VITS：文本 → 音素 → VAE 隐变量 → 声学解码器（GAN 判别）→ 波形
```

### 4.4 大模型 TTS（2022 – ）

- **语音大模型**：把语音离散成 token（如 HuBERT 的 unit），再用语言模型建模，实现**任意说话人、情感、零样本克隆**。

| 代表模型 | 思想 |
|----------|------|
| **VALL-E** | 把语音当成语言建模（neural codec + LLM） |
| **Bark / SpeechT5** | 多任务语音大模型（TTS/ASR/翻译统一） |
| **CosyVoice / GPT-SoVITS** | 中文零样本克隆、低成本微调 |
| **Whisper 生态** | ASR 为主，部分支持翻译 |

> 趋势：ASR 与 TTS 正在统一到"语音大模型"框架下（Whisper 负责听，VALL-E/GPT-SoVITS 负责说）。

## 5. 声纹识别与语音情感

### 5.1 声纹识别（Speaker Verification）

判断**谁在说话**，而非说了什么：

- **Embedding 模型**：把一段语音映射成固定维向量（声纹 embedding），如 **x-vector**（TDNN）、**ECAPA-TDNN**（SOTA）、**WavLM**（自监督）。
- **验证**：两段语音的向量余弦相似度与阈值比较：

$$
\text{speaker}(\mathbf{x}) = \text{Encoder}(\mathbf{x}) \in \mathbb{R}^d, \qquad
\text{similarity} = \cos(\mathbf{e}_1, \mathbf{e}_2)
$$

- **指标**：EER（等错误率）、DET 曲线。用于门禁、银行身份认证、诈骗电话拦截。

### 5.2 语音情感识别（SER）

判断语音中的情绪（高兴/生气/悲伤/平静……）：

```
音频 → 特征（MFCC/韵律 F0/能量）→ 分类模型（CNN/LSTM）→ 情感类别
```

用于客服质检、人机交互、游戏配音测试。与文本情感分析互补（见 [[../自然语言处理NLP/03-文本分类与情感分析|文本情感分析]]）——语音情感还看语调与节奏。

## 6. Python 实践

### 6.1 transformers 跑 Whisper（ASR）

```python
# pip install transformers torch torchaudio librosa soundfile
import torch
from transformers import pipeline

pipe = pipeline("automatic-speech-recognition",
                model="openai/whisper-small",
                device=0 if torch.cuda.is_available() else -1)

result = pipe("sample.wav")
print(result["text"])            # "今天天气真不错，我们去公园散步吧。"

# 输出带时间戳 / 翻译选项
result = pipe("sample.wav", return_timestamps=True, generate_kwargs={"task": "translate"})
```

模型选择：中文场景 `whisper-small` 起，追求质量用 `whisper-medium/large`；流式实时用 `faster-whisper`。

### 6.2 speech_recognition + 麦克风（经典方案）

```python
# pip install SpeechRecognition pyaudio
import speech_recognition as sr

r = sr.Recognizer()
with sr.Microphone() as source:
    audio = r.listen(source, timeout=5)      # 录音
try:
    text = r.recognize_google(audio, language="zh-CN")   # 在线 Google
    print(text)
except sr.UnknownValueError:
    print("听不懂")
except sr.RequestError:
    print("网络错误")
```

`recognize_sphinx` 可离线（需 pocketspinx，效果一般）。生产建议 Whisper / FunASR。

### 6.3 librosa 提取 MFCC

```python
# pip install librosa
import librosa
import numpy as np

y, sr = librosa.load("sample.wav", sr=16000)         # 16kHz 重采样
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=40,
                            n_fft=400, hop_length=160)   # 25ms 帧 / 10ms 移
print(mfcc.shape)   # (40, T)  → 40 维特征 × 帧数
```

`librosa` 也提供 Fbank/频谱；`torchaudio` 的 `MFCC`/`Spectrogram` 是 GPU 友好的等价物。

### 6.4 端到端 CTC 训练骨架（PyTorch 示意）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SmallASR(nn.Module):
    """Encoder + CTC：输入 Fbank，输出按帧的字符概率"""
    def __init__(self, in_dim=80, hidden=256, n_chars=30):
        super().__init__()
        self.gru = nn.GRU(in_dim, hidden, num_layers=2, batch_first=True,
                          bidirectional=True)
        self.fc = nn.Linear(hidden * 2, n_chars)

    def forward(self, fbank):                 # [B, T, 80]
        out, _ = self.gru(fbank)
        return F.log_softmax(self.fc(out), dim=-1)   # [B, T, n_chars]

# 训练时：labels 是变长文本 id，用 CTC 解码器对齐
import torchaudio
ctc_loss = nn.CTCLoss(blank=0, zero_infinity=True)
model = SmallASR()
for batch in dataloader:
    logits = model(batch["fbank"])                       # [B, T, C]
    loss = ctc_loss(logits.transpose(0, 1),              # 需要 [T, B, C]
                    batch["text_ids"], batch["text_len"],
                    batch["fbank_len"])
    loss.backward(); optimizer.step()
```

`nn.CTCLoss` 内部实现了第 2.4 节的前向-后向求和。

## 7. 关键对照表

| 方向 | 输入 → 输出 | 代表方法 |
|------|-------------|----------|
| ASR | 语音 → 文字 | GMM-HMM → CTC → Whisper |
| TTS | 文字 → 语音 | 统计参数 → Tacotron → VITS |
| 声纹识别 | 语音 → 说话人 | x-vector / ECAPA / WavLM |
| 情感识别 | 语音 → 情感类别 | MFCC + 分类网络 |
| 语音翻译 | 语音(A语) → 文字(B语) | Whisper translate / SpeechT5 |
| 语音克隆 | 短样本 → 目标说话人声音 | VALL-E / GPT-SoVITS |

**通用链路**：语音 →（16kHz）→ 声学特征（MFCC/Fbank/原始波形）→ 深度模型（CTC/Attention/LLM）→ 下游（文字/标签/波形）。
