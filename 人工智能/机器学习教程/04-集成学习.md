# 04 集成学习（Ensemble Learning）

> "三个臭皮匠，顶个诸葛亮。" 集成学习把多个弱学习器组合成一个强学习器——这是表格数据竞赛（Kaggle）中最能打的一族方法。**随机森林**、**GBDT**、**XGBoost** 是三大支柱，理解它们之间的"方差 vs 偏差"哲学差异是掌握集成学习的关键。

---

## 1. 为什么集成有效：偏差-方差视角

回顾 [[01-模型评估与交叉验证|偏差-方差分解]]：误差 = 偏差² + 方差 + 噪声。

考虑 $M$ 个独立同分布的弱学习器 $\hat{f}_i$，每个方差为 $\sigma^2$。取平均后 $\bar{f} = \frac{1}{M}\sum \hat{f}_i$：

$$\text{Var}(\bar{f}) = \text{Var}\left(\frac{1}{M}\sum_i \hat{f}_i\right) = \frac{\sigma^2}{M}$$

**方差下降为原来的 $1/M$**——这就是 **Bagging** 有效的原理。而 **Boosting** 则是逐步降低**偏差**。两种路线互补：

| 思路 | 主攻 | 代表 |
|------|------|------|
| 让弱模型更"独立"，平均掉波动 | 方差 | Bagging / 随机森林 |
| 逐步拟合残差，逼近真实函数 | 偏差 | AdaBoost / GBDT / XGBoost |
| 用模型预测训练元模型 | 偏差+方差 | Stacking |

## 2. Bagging 与随机森林

### 2.1 Bagging（Bootstrap Aggregating）

1. 用**自助采样**（有放回抽样 $n$ 次）生成 $M$ 个训练子集，每个子集约含 $1 - e^{-1} \approx 63.2\%$ 的样本（重复）。
2. 在每个子集上独立训练一个基学习器。
3. 预测时投票（分类）/ 取平均（回归）。

**为什么有效**：基学习器之间因数据扰动而"去相关"，方差大幅下降。训练可以**并行**。

### 2.2 随机森林（Random Forest）

在 Bagging 之上再加一层随机性：**每个节点分裂时，只从随机选出的 $m$ 个特征中挑最优**（$m \approx \sqrt{d}$）。

- 特征随机进一步去相关：如果所有树都用最强特征划分，树之间太相似，平均效果差。
- **两个随机**（样本随机 + 特征随机）让每棵树既好又"各看各的"。

### 2.3 袋外误差（Out-of-Bag, OOB）

Bagging 中每棵树没见过约 36.8% 的样本（袋外）。**对每棵树，用它的袋外样本测误差，再对每个样本取其"没见过它的那些树"的投票**——得到 OOB 误差，**无需额外验证集**即可评估泛化性能。OOB 估计 ≈ K 折交叉验证的精度，是随机森林的一大卖点。

### 2.4 特征重要性

- **基于不纯度**（默认）：把该特征在森林中所有节点上降低的基尼不纯度加权求和再归一化。**偏向高基数特征**。
- **基于置换**（permutation importance）：打乱某列后看模型得分下降多少。更可靠但更慢。

```python
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=100, oob_score=True, random_state=42)
rf.fit(X_train, y_train)
print(rf.oob_score_)                       # OOB 精度
print(rf.feature_importances_)             # 不纯度重要性
# permutation_importance: sklearn.inspection.permutation_importance(...)
```

## 3. Boosting：逐步拟合残差

Bagging 是"并行平均"，Boosting 是**串行补漏**：每个新模型专门纠正前面模型的错误。

### 3.1 AdaBoost（Adaptive Boosting）

**核心机制：样本加权**。第 $t$ 轮：加大被错分样本的权重，让下一棵弱树更关注难样本。

$$\alpha_t = \frac{1}{2}\ln\frac{1 - \varepsilon_t}{\varepsilon_t} \qquad\text{（错误率 $\varepsilon_t$ 越低的树话语权越大）}$$

最终预测是各弱树带权投票：

$$f(x) = \text{sign}\left(\sum_{t=1}^{T} \alpha_t\, h_t(x)\right)$$

- 对噪声极其敏感（噪声样本会被不断放大权重）。
- 可用任意"弱学习器"，经典配**决策树桩**（深度 1 的树）。

### 3.2 GBDT（Gradient Boosting Decision Tree）

**核心机制：拟合残差（负梯度）**。把 Boosting 统一为"每一步在损失函数下降最快的方向（负梯度）上加一棵树"：

$$F_{t}(x) = F_{t-1}(x) + \eta \cdot h_t(x), \qquad h_t \approx -\frac{\partial \mathcal{L}}{\partial F}$$

- 损失为 MSE 时，负梯度就是残差 $y - F_{t-1}(x)$；换成对数损失就成了分类版。
- 每一步用**回归树**拟合负梯度（"伪残差"），$\eta$（learning rate）收缩步长防止过拟合。
- **串行，无法并行**，但每棵树在构建时可用直方图近似加速。

### 3.3 XGBoost（eXtreme Gradient Boosting）

GBDT 的工程+算法增强版：

**目标函数** = 损失 + 正则化，并用**二阶泰勒展开**逼近损失：

$$\mathcal{L}^{(t)} = \sum_{i=1}^{n} \underbrace{\ell(y_i, \hat{y}_i^{(t-1)})}_{\text{常数}} + g_i\, f_t(x_i) + \frac{1}{2} h_i\, f_t^2(x_i) + \Omega(f_t)$$

其中一阶梯度 $g_i = \partial_{\hat y} \ell$，二阶梯度 $h_i = \partial^2_{\hat y} \ell$，正则项 $\Omega(f_t) = \gamma T + \frac{1}{2}\lambda\sum_j w_j^2$。

**相比 GBDT 的关键增益**：
1. **二阶信息**：梯度下降只用了切线（一阶），XGBoost 用了曲率（二阶）→ 收敛更快更准。
2. **显式正则化**：对树的结构（叶数 $T$）和叶权重（$w_j$）加惩罚。
3. **工程优化**：特征分位点直方图、稀疏感知（缺省方向）、缓存/并行列块、早停。

### 3.4 常用 Boost 库速查

| 库 | 特点 | 接口 |
|----|------|------|
| `sklearn.ensemble.GradientBoostingClassifier` | 教学用、易用 | sklearn 风格 |
| `xgboost` | 二阶+正则，竞赛王者，需 `pip install xgboost` | `XGBClassifier` |
| `lightgbm` | 基于直方图、快、内存省、支持类别特征 | `LGBMClassifier` |
| `catboost` | 对类别特征友好、过拟合小 | `CatBoostClassifier` |

> 实践中 Kaggle 表格赛通常 **LightGBM / XGBoost / CatBoost 取平均** 就能拿高分。

## 4. Stacking（堆叠）

- **Level-0（基学习器）**：多种异质模型（RF、SVM、XGBoost…）用交叉验证分别预测，把预测概率当新特征。
- **Level-1（元学习器）**：用新特征训练一个"裁判"模型（如逻辑回归）组合各模型。
- 关键：**元学习器的训练数据不能来自基模型在训练集上的直接预测**（否则泄漏），要用交叉验证的袋外预测生成。

```
原始特征
 ├── 基模型1 (RF)    → 预测概率 p1
 ├── 基模型2 (SVM)   → 预测概率 p2      ─┐
 └── 基模型3 (XGB)   → 预测概率 p3      ─┴→ 新特征 [p1,p2,p3] → 元学习器 → 最终预测
```

实现可用 `mlxtend` 的 `StackingClassifier` 或手动 K 折。**能涨分，但训练成本翻倍、可解释性变差**。

## 5. RF vs GBDT vs XGBoost

| 维度 | 随机森林 RF | GBDT | XGBoost |
|------|------------|------|---------|
| 思想 | Bagging（平均） | Boosting（残差） | Boosting（二阶+正则） |
| 主攻 | 降方差 | 降偏差 | 降偏差 |
| 训练方式 | **可并行** | 串行 | 串行（内部并行优化） |
| 对噪声 | 稳健 | 敏感 | 中等（正则缓解） |
| 正则化 | 无显式 | 弱 | **强（γ, λ）** |
| 特征重要性 | 有 | 有 | 有 |
| 处理缺失值 | 有限 | 有限 | **内置（缺省方向）** |
| 可解释性 | 较好 | 差 | 差 |
| 速度(大数据) | 快 | 慢 | 快（直方图） |
| 典型调参重点 | n_estimators, max_depth | learning_rate, n_estimators, subsample | learning_rate, max_depth, subsample, reg_lambda |
| 使用场景 | 快速基线、稳健 | 精度优先中小数据 | **竞赛/工业表格首选** |

**粗配经验**：数据噪声大 / 特征多 → 优先 RF；追求最高精度 → 优先 XGBoost/LightGBM；数据量大 → LightGBM；类别特征多 → CatBoost。

## 6. 实战：泰坦尼克号生存预测

用同一份数据跑通 RF / AdaBoost / XGBoost，并对比 OOB、特征重要性、调参。

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import (RandomForestClassifier, AdaBoostClassifier)
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

# ---------- 1. 数据准备（Kaggle Titanic 的结构化流水线） ----------
# 特征工程：Age 用中位数填充、Sex/Embarked 编码、构造 FamilySize、提取 Title
df = pd.DataFrame({
    'Age':  [22, 38, 26, 35, np.nan, 54, 2, 27],
    'Sex':  [1, 0, 0, 1, 1, 0, 1, 0],
    'Pclass': [3, 1, 3, 1, 3, 1, 3, 3],
    'Fare': [7.25, 71.28, 7.92, 53.1, 8.05, 51.86, 21.07, 11.13],
    'Survived': [0, 1, 1, 1, 0, 0, 1, 0],
})
df['Age'] = df['Age'].fillna(df['Age'].median())
X = df[['Age', 'Sex', 'Pclass', 'Fare']].values
y = df['Survived'].values

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y)

# ---------- 2. 随机森林（看 OOB 与特征重要性） ----------
rf = RandomForestClassifier(
    n_estimators=200, max_depth=4, oob_score=True, random_state=42)
rf.fit(X_train, y_train)
print(f"RF OOB 精度 : {rf.oob_score_:.3f}")
print(f"RF 测试精度 : {rf.score(X_test, y_test):.3f}")
print(f"RF 特征重要性: {np.round(rf.feature_importances_, 3)}")

# ---------- 3. AdaBoost（树桩基学习器） ----------
ada = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1),
    n_estimators=100, learning_rate=1.0, random_state=42)
ada.fit(X_train, y_train)
print(f"AdaBoost 测试精度: {ada.score(X_test, y_test):.3f}")

# ---------- 4. XGBoost（需 pip install xgboost） ----------
try:
    from xgboost import XGBClassifier
    xgb = XGBClassifier(
        n_estimators=100, learning_rate=0.1, max_depth=3,
        subsample=0.9, reg_lambda=1.0,
        use_label_encoder=False, eval_metric='logloss', random_state=42)
    xgb.fit(X_train, y_train)
    print(f"XGBoost 测试精度: {xgb.score(X_test, y_test):.3f}")

    # 调参示例：网格搜索关键超参
    grid = GridSearchCV(
        XGBClassifier(use_label_encoder=False, eval_metric='logloss',
                      random_state=42),
        {'max_depth': [2, 3, 5], 'learning_rate': [0.05, 0.1, 0.2],
         'subsample': [0.8, 1.0]},
        cv=3, scoring='accuracy', n_jobs=-1)
    grid.fit(X_train, y_train)
    print(f"XGBoost 最优超参: {grid.best_params_}")
    print(f"XGBoost 最优 CV 精度: {grid.best_score_:.3f}")
except ImportError:
    print("未安装 xgboost，请运行: pip install xgboost")
```

**调参速查**（重要性降序）：
- XGBoost：`learning_rate` → `n_estimators`（联合调）→ `max_depth` → `subsample/colsample_bytree` → `min_child_weight` → `reg_lambda/reg_alpha`。
- 随机森林：`n_estimators`（越大越好但有收益递减）→ `max_features` → `max_depth` → `min_samples_leaf`。
- 通用技巧：**先用默认参数跑通，再粗调再细调**；`learning_rate` 降一半时 `n_estimators` 应翻倍；用早停（`early_stopping_rounds`）省时间。

## 7. LightGBM 与 CatBoost 快速上手

除了 XGBoost，竞赛圈还有两个 Boost 主力：

```python
# LightGBM：基于直方图算法，训练快、内存省，支持类别特征
from lightgbm import LGBMClassifier
lgbm = LGBMClassifier(
    n_estimators=500, learning_rate=0.05, num_leaves=31,
    subsample=0.8, colsample_bytree=0.8, random_state=42)
lgbm.fit(X_train, y_train, eval_set=[(X_test, y_test)],
         callbacks=[early_stopping(20)])   # 自带早停

# CatBoost：对高基数类别特征最友好
from catboost import CatBoostClassifier
cat = CatBoostClassifier(iterations=500, learning_rate=0.05,
                         depth=6, verbose=False, random_state=42)
cat.fit(X_train, y_train, cat_features=[0])  # 声明哪几列是类别特征
```

| 库 | 最大卖点 | 何时用 |
|----|----------|--------|
| XGBoost | 二阶+正则、生态成熟 | 通用首选 |
| LightGBM | 直方图加速、最快 | 大数据、时间有限 |
| CatBoost | 类别特征原生、ordered boosting 防过拟合 | 大量类别特征、小数据 |

## 8. 早停与学习率

**学习率（$\eta$）收缩**是 Boosting 的灵魂：每棵新树只修正一部分残差。$\eta$ 越小，模型越稳，但需要更多树。

**早停（Early Stopping）**：每加一棵树就在验证集上测一次，连续 $n$ 轮没有提升就停止。同时解决两个问题：
- 不用预先猜 `n_estimators`（会自动停在最佳位置）。
- 防止"加树到过拟合"。

```python
# sklearn 版本无原生早停，手动循环或先给足 n_estimators 再网格搜索
# XGBoost / LightGBM 原生支持:
# xgb.fit(X, y, eval_set=[(X_val, y_val)], early_stopping_rounds=10)
```

**调参联动经验**：`learning_rate` 减半 → `n_estimators` 约翻倍，两者是同一"预算"的两面。

## 9. 集成思想在深度学习中

| 经典集成 | 深度学习对应 |
|----------|--------------|
| Bagging 平均 | 模型快照平均、Dropout（隐式集成） |
| Boosting 串行补漏 | 残差网络 ResNet（学习残差） |
| Stacking 元学习 | 模型蒸馏 / 集成蒸馏 |
| 多基学习器投票 | MC-Dropout、Deep Ensembles 不确定性估计 |

> 现代大模型"更宽的模型 + 更强的单模型"让显式集成的占比下降，但 Bagging 的思想（数据增强、多快照平均）仍是工程标配。

## 10. 集成学习常见坑

| 坑 | 说明 |
|----|------|
| 忽略类别不均衡 | 用 `class_weight='balanced'` 或采样 |
| 树太多 | `n_estimators` 收益递减，用 OOB/早停判断 |
| 直接上 XGBoost 不预处理 | 树模型不需要标准化，但缺失/编码要处理 |
| Boosting 对噪声敏感 | 数据脏时先清洗或改用 RF |
| 调参只盯着测试集 | 用交叉验证，测试集留最后 |
| Stacking 泄漏 | 元学习器必须用交叉验证的袋外预测 |
