# 07 降维（Dimensionality Reduction）

> 数据特征太多不是"信息多"，而是**问题难**。降维的任务是：在尽量保留结构的同时，把数据压缩到低维空间。本笔记覆盖两条主流路线——**PCA**（线性、可解释、用于压缩/预处理）和 **t-SNE**（非线性、强可视化）。完整代数推导在数理基础，这里讲动机、直觉与 sklearn 实操。

---

## 1. 为什么降维

### 1.1 维度灾难

回顾 [[02-最近邻与朴素贝叶斯|维度灾难]]：高维下样本稀疏、距离失效，模型（KNN、核方法等）性能崩坏。降维可把样本"聚拢"回有结构的方向。

### 1.2 三大动机

1. **可视化**：人类只能看 2D/3D。降维是把高维结构"压"成可看的图。
2. **压缩与去噪**：去掉冗余/噪声维，减小存储与计算。
3. **预处理**：为 KNN、SVM 等对距离/尺度敏感的模型清洗数据，缓解多重共线性。

---

## 2. PCA：主成分分析

### 2.1 核心思想

找到一组**正交方向**，让数据在方向上的投影**方差最大**（信息最多），且各方向不相关。第一主成分是方差最大的方向，第二主成分在与第一正交的方向中方差最大，依此类推。

```
数据沿长轴方差大（保留） ←→ 沿短轴方差小（可丢弃）
    ↑ 第一主成分 PC1
    → 第二主成分 PC2 (与 PC1 正交)
```

> **直觉**：方差 = 信息。某个方向上方差接近 0，说明这个方向上数据都挤在一起，丢掉的"形状"极少。PCA 就是依次找"最能区分样本"的方向。

### 2.2 数学链路（直觉版）

设数据已中心化（减去均值），协方差矩阵 $S = \frac{1}{n}X^T X$（$n$ 个样本，$d$ 维）。

1. 求 $S$ 的特征分解：$S v = \lambda v$。
2. 特征值 $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_d \ge 0$ = 各主成分方向的方差；对应特征向量 $v_1,\dots,v_d$ = 主成分方向（载荷）。
3. 取前 $k$ 个特征向量组成投影矩阵 $W \in \mathbb{R}^{d\times k}$，降维结果 $Z = XW$。

**等价 SVD 求解**：对中心化矩阵做奇异值分解 $X = U\Sigma V^T$，$V$ 的列正是主成分方向，奇异值平方 $\propto$ 特征值。**数值上 SVD 更稳定**（不需要算 $X^TX$），sklearn 用随机化 SVD。

> 完整推导（最大化投影方差 ⇔ 特征分解，约束优化）见 [[../../数理基础/统计学分析方法/主成分分析|主成分分析]]。

### 2.3 方差解释率（Explained Variance Ratio）

$$\text{解释率}_k = \frac{\lambda_k}{\sum_{i=1}^{d}\lambda_i}$$

累计前 $k$ 个的解释率 = 保留了多少信息。**选 k 的经验**：累计解释率达到 80%~95%，或看碎石图（scree plot）的拐点。

### 2.4 白化（Whitening）

把主成分方向投影后**再除以各自标准差**，使各分量方差都为 1（各向同性）。去相关 + 归一，常用于预处理，如 ICA 前、某些特征工程。sklearn：`PCA(whiten=True)`。

### 2.5 注意事项

- PCA **对尺度敏感**：必须先把各特征标准化（否则方差大的特征主导）。
- 主成分是**特征的线性组合**，方向可解释但组合含义常难命名。
- 数据有强**非线性流形**时 PCA 会失败（见 t-SNE）。

## 3. t-SNE：t 分布随机邻域嵌入

### 3.1 核心思想

把"高维里谁跟谁亲近"的关系，在低维里尽量复刻出来。高维用高斯分布定义相似度，低维用**t 分布**定义相似度，然后**最小化两者的 KL 散度**。

高维相似度（条件概率，衡量点 i 把点 j 当邻居的概率）：

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i}\exp(-\|x_i - x_k\|^2/2\sigma_i^2)}$$

低维相似度（用 t 分布缓解拥挤问题）：

$$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l}(1 + \|y_k - y_l\|^2)^{-1}}$$

损失（两个概率分布的距离，非对称，KL 散度）：

$$C = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

梯度下降迭代更新低维坐标 $y_i$。

### 3.2 困惑度（Perplexity）

控制高斯核的带宽 $\sigma_i$，即"每个点考虑多少个邻居"。典型值 5~50，默认 30。**太小** → 局部碎片化；**太大** → 过度全局化、拥挤。

### 3.3 读图要点（重要！）

- ✅ 擅长展现**局部聚类结构**，聚类越近越可信。
- ❌ **簇间距离没有意义**：t-SNE 只保局部关系，两个簇相距多远不代表真实距离多近。
- ❌ 簇的大小、密度不代表真实大小/密度。
- ❌ 每次运行结果不同（随机初始化 + 随机梯度），多跑几次看稳定结构。

### 3.4 用途边界

- 只用于**可视化**，**不能用于压缩/后续建模**（低维坐标不可复现、不能泛化到新样本，没有 transform 接口，只能对整批数据算）。
- 数据量大时很慢（$O(n^2)$），通常先用 PCA 降到 30~50 维再喂 t-SNE。

## 4. PCA vs t-SNE vs UMAP

| 维度 | PCA | t-SNE | UMAP |
|------|-----|-------|------|
| 原理 | 最大方差/特征分解 | KL 散度最小化 | 拓扑流形+图嵌入 |
| 线性/非线性 | **线性** | 非线性 | 非线性 |
| 保全局结构 | ✅ | ❌（只保局部） | ✅（兼顾全局+局部） |
| 可解释性 | ✅（主成分方向） | ❌ | ❌ |
| 新样本预测 | ✅（transform） | ❌ | ✅（近似变换） |
| 速度 | 极快 | 慢 | 快（相对 t-SNE） |
| 超参数 | k | perplexity, n_iter | n_neighbors, min_dist |
| 典型用途 | 压缩、预处理、特征提取 | 2D 可视化 | 可视化+嵌入（深度学习语境） |
| 是否稳定 | ✅ 确定性 | ❌ 每次不同 | 较稳定 |

> 现代可视化基线是 **UMAP**：比 t-SNE 快、保留全局结构、可嵌入新样本。本教程按经典路径以 PCA/t-SNE 为主，工程上建议了解 UMAP（`pip install umap-learn`）。

## 5. 实战一：PCA 人脸数据降维与可视化

用 `olivetti_faces`（64×64 像素，4096 维）演示"降维→保留多少信息"。

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_olivetti_faces
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

faces = fetch_olivetti_faces(shuffle=True, random_state=42)
X = faces.data      # (400, 4096)
n_components = 100

# 1) 拟合 PCA（图像像素天然 0~1，可不标准化，但这里演示可先标准化）
pca = PCA(n_components=n_components, whiten=True, svd_solver='randomized')
X_pca = pca.fit_transform(X)

# 2) 方差解释率曲线（选 k 的关键依据）
cum = np.cumsum(pca.explained_variance_ratio_)
plt.figure(figsize=(7, 4))
plt.plot(cum, lw=2)
plt.axhline(0.9, color='r', ls='--', label='90% 阈值')
plt.xlabel('主成分数 k'); plt.ylabel('累计解释率')
plt.title(f"前 {n_components} 个主成分累计解释率: {cum[-1]:.2%}")
plt.legend(); plt.grid(alpha=0.3); plt.show()

# 3) 重建对比：原图 vs 用 100 维 PCA 重建
X_recon = pca.inverse_transform(X_pca)
fig, axes = plt.subplots(2, 10, figsize=(15, 3))
for i in range(10):
    axes[0, i].imshow(X[i].reshape(64, 64), cmap='gray'); axes[0, i].axis('off')
    axes[1, i].imshow(X_recon[i].reshape(64, 64), cmap='gray'); axes[1, i].axis('off')
axes[0, 0].set_ylabel('原图'); axes[1, 0].set_ylabel('重建(100维)')
plt.show()

# 4) 数据量很大的可选操作：IncrementalPCA 分批训练
# from sklearn.decomposition import IncrementalPCA
```

**说明**：图像这种强结构数据 PCA 重建效果惊人——4096 维 → 100 维仍能认出人脸。这也解释了为什么 PCA 是人脸识别（Eigenfaces）的经典方案。

## 6. 实战二：t-SNE 手写数字可视化

```python
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.manifold import TSNE
from sklearn.decomposition import PCA

digits = load_digits()      # 64 维，10 类
X, y = digits.data, digits.target

# 1) 先 PCA 降到 40 维再 t-SNE（标准提速做法）
X_pca40 = PCA(n_components=40, random_state=42).fit_transform(X)

tsne = TSNE(n_components=2, perplexity=30, n_iter=1000, random_state=42)
X_tsne = tsne.fit_transform(X_pca40)

# 2) 可视化：每个数字一类，颜色编码
plt.figure(figsize=(9, 7))
scatter = plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y,
                      cmap='tab10', s=12, alpha=0.8)
plt.colorbar(scatter)
plt.title('t-SNE: 手写数字 (digits)')
plt.grid(alpha=0.3); plt.show()

# 3) 对照组：直接 PCA 到 2D（看线性降维的差距）
X_pca2 = PCA(n_components=2, random_state=42).fit_transform(X)
plt.figure(figsize=(9, 7))
plt.scatter(X_pca2[:, 0], X_pca2[:, 1], c=y, cmap='tab10', s=12, alpha=0.8)
plt.title('PCA 直接降到 2D（对比用）')
plt.grid(alpha=0.3); plt.show()
```

**预期观察**：t-SNE 把 10 个数字分成 10 个紧致的"云团"；PCA 降到 2 维后数字相互重叠、边界模糊。数字识别的流行做法（经典 MNIST 可视化）就是靠 t-SNE 呈现的。

## 7. 降维常见坑

| 坑 | 对策 |
|----|------|
| PCA 前不标准化 | 先 `StandardScaler`（尺度敏感） |
| 把 t-SNE 当压缩/喂给后续模型 | 只当可视化；压缩用 PCA/UMAP/自编码器 |
| 过度解读 t-SNE 的簇间距/大小 | 只信局部聚类，不信全局几何 |
| 用 PCA 解释业务方向时强行命名 | 结合载荷系数（`components_`）审慎解读 |
| 数据维度远超样本量 | 用随机化 SVD / IncrementalPCA |

## 8. 其他线性降维方法

### 8.1 LDA（线性判别分析）

PCA 是**无监督**（只看方差），LDA 是**有监督**（用标签找方向）。LDA 找的方向最大化"类间散布 ÷ 类内散布"：

$$\max_w \frac{w^T S_b\, w}{w^T S_w\, w}$$

- 结果方向天然利于分类（可同时做降维与分类）。
- 类别多时最多降到 $C-1$ 维。
- sklearn：`LinearDiscriminantAnalysis`（`n_components` 控制）。

### 8.2 核 PCA（Kernel PCA）

PCA 是线性操作，对非线性流形无能为力。用**核技巧**（同 [[05-支持向量机|SVM 核技巧]]）把数据先映射到高维再做 PCA——能"展开"非线性结构，但没有线性主成分的可解释性。

```python
from sklearn.decomposition import KernelPCA
kpca = KernelPCA(n_components=2, kernel='rbf', gamma=0.1)
```

### 8.3 MDS（多维标度）

只给定**两两相似度/距离矩阵**，在低维空间重现这些距离（保距）。是 t-SNE 的前身；t-SNE 可看作"保局部距离"的 MDS 改良。

### 8.4 ICA（独立成分分析）

目标是把混合信号分解成**统计独立**的成分（盲源分离，如"鸡尾酒会问题"）。与 PCA（只去相关）不同，ICA 追求独立性，常用于脑电/语音信号处理。

```python
from sklearn.decomposition import FastICA
ica = FastICA(n_components=2).fit_transform(X)
```

## 9. 降维方法选择决策树

```text
需要保留可解释的主成分/做预处理？ ──是──► PCA（线性）
            │
            └──否
需要 2D 可视化？──────────────────是──► t-SNE / UMAP
            │
            └──否
数据量很大？─────────────────────是──► UMAP / IncrementalPCA
            │
            └──否
有标签可用？─────────────────────是──► LDA（分类导向）
            │
            └──否
结构非线性？─────────────────────是──► Kernel PCA / Autoencoder
                                        └──► 否则 PCA
```

> 工程速查：**压缩/预处理 → PCA**；**可视化 → UMAP（或 t-SNE）**；**非线性表征学习 → 自编码器（[[../深度学习教程/06-PyTorch入门|PyTorch]]）**。

## 10. 降维工作流完整示例

```python
from sklearn.pipeline import Pipeline
from sklearn.decomposition import PCA
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import cross_val_score

# 用 Pipeline 把"标准化 → 降维 → 分类"串成一体（避免数据泄漏）
pipe = Pipeline([
    ('scale', StandardScaler()),
    ('pca', PCA(n_components=0.95)),      # 按解释率自动选 k
    ('knn', KNeighborsClassifier(n_neighbors=5)),
])
print(cross_val_score(pipe, X, y, cv=5).mean())
```
