# 06 聚类（Clustering）

> 分类是"有标准答案"，聚类是"自己找结构"。聚类在无监督学习里是最重要的一类任务：**没有标签，把相似样本自动归组**。本笔记覆盖三大聚类流派——划分式（K-Means）、密度式（DBSCAN）、层次式（层次聚类），并用 sklearn 在同一数据上对比。

---

## 1. 无监督学习概述

| | 分类（监督） | 聚类（无监督） |
|---|---|---|
| 数据 | 有标签 $(x, y)$ | 只有 $x$ |
| 目标 | 学从 $x$ 到 $y$ 的映射 | 发现数据内在分组 |
| 输出 | 类别标签（有语义） | 簇编号（语义靠人工解读） |
| 评估 | 与真值比（准确率） | 无真值，用内部指标（轮廓系数）或外部指标（NMI 等） |
| 典型应用 | 图像分类、垃圾邮件 | 客户分群、图像分割、异常检测、推荐冷启动 |

> 聚类"簇"本身没有语义，**给簇起名字是人的工作**（如"高价值客户""年轻用户"）。这既是它的灵活性，也是它的主观性。

## 2. K-Means

### 2.1 目标函数

把 $n$ 个样本分成 $K$ 簇，最小化簇内平方和（WCSS，组内误差平方和 SSE）：

$$\min_{\{C_k\},\{\mu_k\}}\ \text{WCSS} = \sum_{k=1}^{K}\sum_{x \in C_k} \|x - \mu_k\|^2$$

其中 $\mu_k = \frac{1}{|C_k|}\sum_{x\in C_k} x$ 是簇心。**直觉**：每个点到自己簇心越近越好。

> 这是 NP-hard 的优化问题，K-Means 只是找到局部最优的**迭代启发式**，不保证全局最优。

### 2.2 算法流程（Lloyd 算法）

```
输入：数据 X，簇数 K
1. 初始化 K 个簇心 μ_1..μ_K
2. 重复直到收敛：
   a. 分配：每个样本 x 分到最近的簇心
      c_i = argmin_k ‖x_i - μ_k‖²
   b. 更新：重新计算每个簇心为其成员均值
      μ_k = (1/|C_k|) Σ_{x∈C_k} x
3. 输出：簇划分（与簇心）
```

- 每步都保证 WCSS 单调不增 → 必收敛（到局部最优）。
- **复杂度**：每轮 $O(n \cdot K \cdot d)$，迭代 $t$ 轮共 $O(nKdt)$。大数据上非常快。

### 2.3 K-Means++（初始化）

初始簇心选得太差 → 局部最优差。K-Means++ 让初始簇心**尽量分散**：
1. 随机选第一个簇心。
2. 每个后续簇心按"距已选簇心最远平方距离"成概率分布抽样。
3. 重复到 K 个。

sklearn 默认 `init='k-means++'`。效果：更快收敛、结果更稳定。

### 2.4 K 怎么选

- **肘部法则（Elbow）**：画 K-WCSS 曲线，找"拐点"（再增 K 收益骤减处）。
- **轮廓系数（Silhouette）**：对每个点 $s_i = \frac{b_i - a_i}{\max(a_i, b_i)}$，其中 $a_i$ = 到同簇其他点的平均距离（内聚），$b_i$ = 到最近其他簇的平均距离（分离）。$s \in [-1,1]$，越大越好。取**平均轮廓系数**最大的 K。

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

K_range = range(2, 9)
wcss, sil = [], []
for k in K_range:
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X)
    wcss.append(km.inertia_)                                  # WCSS
    sil.append(silhouette_score(X, km.labels_))
# 画两幅图：肘部图 + 轮廓系数图，交叉决定 K
```

### 2.5 K-Means 的缺点

- ❌ 需预先给定 K；结果对初始化和 K 敏感。
- ❌ **只适合凸形、大小相近的簇**（基于欧氏距离的球状假设）。
- ❌ 对异常值敏感（均值被拉偏）。
- ❌ 本质假设各特征同尺度 → 必须标准化。

## 3. DBSCAN（基于密度）

### 3.1 核心概念

- **邻域**：以某点为中心、半径 $\varepsilon$（eps）内的点。
- **核心点**：邻域内点数 $\ge$ `min_samples`。
- **边界点**：在核心点的邻域内，但自身邻域不足 min_samples。
- **噪声点**：既非核心也非边界——**不属于任何簇**。

### 3.2 算法流程

```
1. 对每个点判断是否为核心点
2. 从任一未访问的核心点出发，沿"密度可达"关系扩展成簇
   （核心点邻域内的点都并入该簇，若它们也是核心点则继续扩散）
3. 剩余点标记为噪声
```

**密度可达**：A 在 B 邻域内，B 是核心点 → A 密度可达 B；可传递。

### 3.3 两个参数

- **eps**：邻域半径。太小 → 多数点成噪声；太大 → 都并成一簇。可用 **k-距离图**辅助选：画"每个点到第 min_samples 近点的距离"排序曲线，拐点处取 eps。
- **min_samples**：一般取 $2 \times d$（d 为维数）起步。越大 → 越难成为核心点 → 簇越少、噪声越多。

### 3.4 优势与限制

- ✅ **不需指定 K**，自动发现簇数。
- ✅ 能处理**任意形状**（环形、条状）簇，对噪声稳健。
- ❌ 密度差异大时（如既有密簇又有疏簇）效果差（单一 eps）。
- ❌ 高维下距离失效 → 效果差。
- ❌ 两个参数较难调。

> 直觉类比：EPS=半径画圆，圆里人够多就"传染"，从圆心一路传染成团；落单的圈外人就是噪声。

## 4. 层次聚类（Hierarchical）

### 4.1 两种方向

- **AGNES（自底向上，凝聚）**：先把每个样本当一簇，每次合并距离最近的两簇，直到目标簇数。
- **DIANA（自顶向下，分裂）**：从一整簇开始，每次拆一簇。

**簇间距离（连接准则）**：
| 准则 | 距离定义 | 特点 |
|------|----------|------|
| 单连接（single） | 两簇最近点距离 | 易连成链状、对噪声敏感 |
| 全连接（complete） | 两簇最远点距离 | 偏向紧凑球状簇 |
| 平均连接（average） | 两簇所有点对平均 | 均衡，较稳健 |
| 沃德法（ward） | 合并后 WCSS 增量最小 | **最常用**，倾向紧凑均衡簇 |

### 4.2 树状图（Dendrogram）

合并历史画成一棵树，**从任意高度横切一刀**就得到该高度的簇划分——所以层次聚类可以"一次算、多次看"。

### 4.3 优势与限制

- ✅ 不用预设 K（看树状图切一刀即可）。
- ✅ 树状图提供**多尺度视角**（不同层次的结构）。
- ❌ 计算量大：$O(n^2)$ 内存 + $O(n^3)$（朴素）时间，**n 超过上万就吃力**（可用 `AgglomerativeClustering` 的 `connectivity` 或先抽样）。
- ❌ 合并/分裂不可逆，一步错步步错。

## 5. 三种聚类方法对比

| 维度 | K-Means | DBSCAN | 层次聚类 |
|------|---------|--------|----------|
| 簇形状 | 凸/球状 | **任意形状** | 任意（看连接准则） |
| 簇数 K | 必须指定 | 自动 | 切树指定 |
| 噪声点 | 不支持（全部分簇） | **支持** | 不支持（可后处理） |
| 参数 | K, init | eps, min_samples | 连接准则、K/高度 |
| 时间复杂度 | $O(nKdt)$ | $O(n^2)$ | $O(n^2)$~$O(n^3)$ |
| 大数据 | ✅ 快 | 中 | ❌ 慢 |
| 对密度差异 | 不好 | 不好 | 较好 |
| 应用 | 客户分群、压缩 | 异常检测、地理聚类 | 基因/层次结构分析 |

> **选择建议**：数据大、簇近球形 → K-Means；形状复杂、有噪声 → DBSCAN；想同时看多个粒度 / 样本量小 → 层次聚类。

## 6. 聚类质量评估

### 6.1 内部指标（无真值）
- **WCSS / inertia**：越小越好，但随 K 单调递减 → 只能看相对下降幅度（肘部）。
- **轮廓系数**：综合内聚+分离，$[-1, 1]$，大样本快算。
- **DBI（Davies-Bouldin Index）**：簇内分散度 vs 簇间距离的比值，**越小越好**。优化目标常被用在聚类初始化选择上（相关项目见下方链接）。

### 6.2 外部指标（有真值，如模拟数据）
- **NMI（归一化互信息）**：$[0,1]$，衡量划分与真值的互信息。
- **调整兰德指数 ARI**：$[-1,1]$，考虑随机一致性，**越大越好**。

> 有真值时优先 ARI / NMI；无真值时轮廓系数 + 业务合理性判断。

## 7. 实战：同数据上对比三种聚类

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs, make_moons
from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score, adjusted_rand_score

# 两个数据集：球状（blobs）+ 新月（moons）
X1, y1 = make_blobs(n_samples=300, centers=4, random_state=42)
X2, y2 = make_moons(n_samples=300, noise=0.06, random_state=42)

X1 = StandardScaler().fit_transform(X1)
X2 = StandardScaler().fit_transform(X2)

def fit_all(X, n_clusters):
    models = {
        'K-Means': KMeans(n_clusters=n_clusters, n_init=10, random_state=42),
        'DBSCAN': DBSCAN(eps=0.3, min_samples=5),
        '层次聚类': AgglomerativeClustering(n_clusters=n_clusters, linkage='ward'),
    }
    return {name: m.fit_predict(X) for name, m in models.items()}

for i, (X, y_true) in enumerate([(X1, y1), (X2, y2)]):
    n_clusters = 4 if i == 0 else 2
    labels = fit_all(X, n_clusters)
    fig, axes = plt.subplots(1, 3, figsize=(15, 4))
    for ax, (name, lab) in zip(axes, labels.items()):
        ax.scatter(X[:, 0], X[:, 1], c=lab, cmap='tab10', s=20,
                   edgecolor='k', alpha=0.8)
        # DBSCAN 中 label=-1 是噪声，自动显示为独立颜色
        ax.set_title(f"{name}  (ARI={adjusted_rand_score(y_true, lab):.2f})")
        ax.grid(alpha=0.3)
    plt.suptitle(f"数据集 {'blobs' if i==0 else 'moons'} 对比")
    plt.tight_layout(); plt.show()
```

**预期观察**：
- **blobs（球状）**：三个方法都接近完美，K-Means 最快。
- **moons（新月）**：K-Means 把两个弧形"从中间切开"（它只会球状切分）；DBSCAN 与层次（ward）能贴合弧形结构，DBSCAN 表现最佳。

| 场景 | 推荐 |
|------|------|
| 数据量大、特征标准化后近球形 | K-Means（记得 K-Means++） |
| 形状未知、含噪声/离群点 | DBSCAN（k-距离图调 eps） |
| 需要多粒度解读、样本量小 | 层次聚类（ward + 树状图） |

## 9. K-Means 与 EM 算法、谱聚类

### 9.1 K-Means = 硬分配的 EM

K-Means 的"分配-更新"两步迭代，本质是 **EM（期望最大化）算法**在"高斯混合、各向同性、硬分配"下的特例：
- **E 步（分配）**：给定簇心，把每个样本归到最近簇（硬分配）。
- **M 步（更新）**：给定分配，更新簇心为均值。

理解这一点，就能自然过渡到**高斯混合模型 GMM**（软分配：样本以概率属于多个簇）。完整的混合模型视角见 [[../../数理基础/机器学习数学基础/聚类分析|聚类分析]]。

### 9.2 谱聚类（Spectral Clustering）

把聚类转化为**图划分**问题：按相似度建图，取拉普拉斯矩阵的前 $k$ 个特征向量做降维，再对降维后的坐标跑 K-Means。能处理**非凸、互相缠绕**的簇（DBSCAN 之外的另一解），但建图与特征分解开销大。

```python
from sklearn.cluster import SpectralClustering
sp = SpectralClustering(n_clusters=2, affinity='nearest_neighbors',
                        random_state=42).fit_predict(X)
```

## 10. 大规模聚类的工程技巧

| 问题 | 解法 |
|------|------|
| 样本量巨大（>100 万） | `MiniBatchKMeans`（分批更新，快 10~100 倍） |
| 特征高维 | 先 [[07-降维|PCA]] 到 50~100 维再聚类 |
| 特征量纲不同 | 标准化（聚类基于距离） |
| 类别型特征多 | 用 Gower 距离或 one-hot + 降维 |
| 需要可复现 | 固定 `random_state` 与 `n_init` |

```python
from sklearn.cluster import MiniBatchKMeans
```

## 11. 如何向业务解读聚类结果

1. 对每个簇打印**特征均值画像**（如：簇 0 = 高消费、年轻、已婚）。
2. 用轮廓系数 / DBI 量化簇质量，但**业务合理性优先**。
3. 用 [[07-降维|t-SNE/PCA]] 画图辅助验证簇是否真的分离。
4. 聚类是探索工具：先聚类发现分组 → 再为每个组建监督模型。
