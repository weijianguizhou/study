# 05 支持向量机（Support Vector Machine）

> 在深度网络成为主流之前，SVM 是分类问题的"最强单品"。它的思想极其优雅：**找一个离两类数据都尽量远的分隔面**。完整的对偶推导、KKT 条件、核函数理论在数理基础笔记里，这里聚焦几何直觉、算法流程与 sklearn 调参。

---

## 1. 核心思想：最大间隔超平面

线性分类器找超平面 $w^T x + b = 0$。逻辑回归找的是"概率恰为 0.5"的分界面，而 **SVM 找的是"离两类最近样本都最远"的分界面**。

```
           o  o
    o  o        o
          ↑ 间隔 margin = 2/‖w‖
    x  x        x
       x  x  x
```

- **支持向量**：距离超平面最近的那些样本点，它们"顶住"了超平面。只有它们决定分界面，其余样本无关。
- **间隔 (margin)** = 两类支持向量到超平面距离之和 $= 2/\|w\|$。
- **目标**：最大化间隔 $\Leftrightarrow$ 最小化 $\|w\|$。

> 直觉：间隔越大，分界面越"靠中间"，对未知数据的泛化越稳。支持向量 = 数据中最具代表性、最难分类的点。

---

## 2. 硬间隔 SVM（线性可分）

约束每个样本分类正确且离超平面至少 1（可缩放标准化）：

$$w^T x_i + b \ge +1 \quad (y_i = +1), \qquad w^T x_i + b \le -1 \quad (y_i = -1)$$

合并写为 $y_i(w^T x_i + b) \ge 1$。优化问题（凸二次规划）：

$$\min_{w,b}\ \frac{1}{2}\|w\|^2 \quad \text{s.t.}\quad y_i(w^T x_i + b) \ge 1,\ \forall i$$

最大化间隔 $\Leftrightarrow$ 最小化 $\frac{1}{2}\|w\|^2$。这就是**硬间隔**：要求数据严格线性可分。

---

## 3. 软间隔 SVM（线性不可分）

现实中数据几乎都带噪声/不可分。允许少量样本**越过边界**（甚至分错），引入**松弛变量** $\xi_i \ge 0$：

$$\min_{w,b,\xi}\ \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \xi_i \quad \text{s.t.}\quad y_i(w^T x_i + b) \ge 1 - \xi_i,\ \xi_i \ge 0$$

- $\xi_i > 0$：第 $i$ 个样本违反了间隔（在间隔内或分错一侧）。
- **$C$（正则化强度）**：允许犯错的总代价。$C$ 大 → 惩罚重 → 边界窄、硬；$C$ 小 → 容忍错误 → 边界宽、软。

**等价角度（hinge loss）**：软间隔问题等价于最小化合页损失 + L2 正则：

$$\min_w\ \sum_{i=1}^{n} \underbrace{\max(0,\ 1 - y_i(w^T x_i + b))}_{\text{hinge loss}} + \frac{1}{2}\|w\|^2$$

- Hinge loss 对"已经正确且离边界远"的样本损失为 0——这是它与逻辑回归（log loss 永远有梯度）的本质区别。
- **直觉对比**：逻辑回归"所有点都参与学习"，SVM"只有犯错的点（支持向量）参与学习"。

> 完整推导（拉格朗日对偶、KKT、$\xi$ 的互补松弛条件）见 [[../../数理基础/机器学习数学基础/支持向量机|SVM数学理论]]。

## 4. 对偶问题与核技巧

### 4.1 对偶问题

原问题拉格朗日对偶后，只依赖样本间的**内积**：

$$\max_{\alpha}\ \sum_{i=1}^{n}\alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i \alpha_j y_i y_j \langle x_i, x_j \rangle \quad \text{s.t.}\quad 0 \le \alpha_i \le C,\ \sum_i \alpha_i y_i = 0$$

- 只有支持向量对应 $\alpha_i > 0$。
- 预测公式：$f(x) = \text{sign}\left(\sum_{i \in SV} \alpha_i y_i \langle x_i, x \rangle + b\right)$。

**对偶的好处**：① 数据维度不直接出现在目标里；② 把内积换成核函数即可映射到高维空间——**核技巧**呼之欲出。

### 4.2 核技巧（Kernel Trick）

数据线性不可分时，映射到高维 $\phi(x)$ 就可能可分。核函数**隐式**计算高维内积，无需显式写出 $\phi$：

$$K(x_i, x_j) = \langle \phi(x_i), \phi(x_j) \rangle$$

经典核函数：

| 核 | 表达式 | 特点 |
|----|--------|------|
| 线性核 | $K = \langle x_i, x_j \rangle$ | 无映射，等价线性 SVM |
| **多项式核** | $K = (\gamma\langle x_i,x_j \rangle + r)^d$ | 可拟合多项式边界，$d$ 控制复杂度 |
| **RBF 核** | $K = \exp(-\gamma \|x_i - x_j\|^2)$ | **最常用**，高斯式局部相似度 |
| Sigmoid 核 | $K = \tanh(\gamma\langle x_i,x_j \rangle + r)$ | 类似两层神经网络 |

**RBF 核的直觉**：把每个样本当作高斯"原型"，新样本按到原型的距离加权——几乎可以拟合任意形状的边界（核空间维度无穷大）。

**核函数选择经验**：数据量大特征少 → 默认 **RBF**；特征多（文本等）→ 线性核；有先验多项式结构 → 多项式核。

### 4.3 为什么要对偶 + 核：完整链路

```
线性不可分数据
  → 映射 φ 到高维空间（可能可分）
  → 高维内积太贵/不可写 → 用核函数 K(x_i,x_j) 隐式计算
  → 对偶问题中只需 K，解 α
  → 支持向量 + 核 → 预测
```

> Mercer 定理保证合法核函数对应某个内积空间。核技巧也可以用在 PCA、K-Means 等模型上（kernel PCA / kernel K-means）。

## 5. SMO 算法简述

对偶问题是二次规划（QP），直接解 $O(n^3)$ 太慢。**SMO（Sequential Minimal Optimization）**把问题分解成一系列两变量子问题：

1. 每次固定其它 $\alpha$，只优化两个 $\alpha_i, \alpha_j$（利用等式约束 $\sum \alpha_i y_i = 0$，两变量只剩一个自由）。
2. 每个两变量子问题有**解析解**（闭式）。
3. 用启发式挑选"最违反 KKT 条件"的变量对，反复迭代到收敛。

复杂度接近 $O(n^2)$，这就是 libsvm / sklearn `SVC` 的实际求解器。

---

## 6. 多分类策略

- **一对多（OvR / OvA）**：训练 $K$ 个"本类 vs 其余"分类器，取得分最高者。SVM 输出是距离（无概率），需校准或比较距离。$K$ 个分类器，更快。
- **一对一（OvO）**：训练 $C_K^2$ 个两两分类器，投票。训练量大但每个子问题简单，sklearn `SVC` **默认 OvO**。

> 注意：`SVC` 的 `predict_proba` 需要 `probability=True`（会用 Platt 缩放做额外交叉验证拟合，更慢）。OvR 更适合要概率的场景。

## 7. 实战：RBF 核调参与决策边界可视化

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.svm import SVC
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

# 1) 数据：两个交错的半圆（线性不可分）
X, y = make_moons(n_samples=300, noise=0.2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

# 2) 标准化：SVM 基于距离，尺度敏感
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# 3) 网格搜索 RBF 的 C 和 gamma
param_grid = {'C': [0.1, 1, 10, 100], 'gamma': [0.01, 0.1, 1, 10]}
grid = GridSearchCV(SVC(kernel='rbf'), param_grid, cv=5,
                    scoring='accuracy', n_jobs=-1)
grid.fit(X_train, y_train)
print(f"最优参数: C={grid.best_params_['C']}, gamma={grid.best_params_['gamma']}")
print(f"最优 CV 精度: {grid.best_score_:.3f}")
print(f"测试精度: {grid.score(X_test, y_test):.3f}")

# 4) 可视化决策边界
def plot_decision_boundary(model, X, y, ax):
    x_min, x_max = X[:, 0].min() - 0.5, X[:, 0].max() + 0.5
    y_min, y_max = X[:, 1].min() - 0.5, X[:, 1].max() + 0.5
    xx, yy = np.meshgrid(np.linspace(x_min, x_max, 300),
                         np.linspace(y_min, y_max, 300))
    Z = model.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
    ax.contourf(xx, yy, Z, alpha=0.3, cmap='coolwarm')
    ax.scatter(X[:, 0], X[:, 1], c=y, cmap='coolwarm', edgecolor='k', s=20)
    # 高亮支持向量
    ax.scatter(model.support_vectors_[:, 0], model.support_vectors_[:, 1],
               s=80, facecolors='none', edgecolors='k', linewidths=1.5,
               label='支持向量')
    ax.legend(); ax.grid(alpha=0.3)

fig, axes = plt.subplots(1, 2, figsize=(12, 5))
for ax, C, gamma in zip(axes, [0.1, 10], [0.1, 10]):
    svc = SVC(kernel='rbf', C=C, gamma=gamma)
    svc.fit(X_train, y_train)
    plot_decision_boundary(svc, X_train, y_train, ax)
    ax.set_title(f"C={C}, gamma={gamma}")
plt.show()
```

**C 与 gamma 的直觉（RBF 核）**：
- **C 大**：间隔窄、错误零容忍 → 过拟合风险；**C 小**：间隔宽、允许错误 → 欠拟合。
- **gamma 大**：高斯"半径"小，每点影响范围窄 → 边界绕圈、过拟合；**gamma 小**：影响范围广 → 边界平滑、欠拟合。

两者相互影响，**必须联合调**。数据量更大时可用 `NuSVC`（用 $\nu$ 控制支持向量比例）。

## 8. SVM vs 逻辑回归

| 维度 | SVM | 逻辑回归 |
|------|-----|----------|
| 目标 | 最大化间隔 | 最大化似然 / 最小化 log loss |
| 损失 | hinge loss | log loss |
| 参与学习的样本 | 仅支持向量（边界附近） | 全部样本 |
| 输出 | 距离（无原生概率） | **原生概率** |
| 边界类型 | 硬间隔→软间隔 | 概率分界面 |
| 高维特征 | 擅长（核技巧） | 有正则也能扛 |
| 大数据 | 慢 | 快 |
| 可解释性 | 中（核空间难解释） | 好（系数即影响） |
| 缺省选择 | 中小数据集、边界复杂 | 需要概率/解释、大样本 |

> 工业界逻辑回归仍常用于**在线/超大样本/需要概率与解释**的场景；SVM 在中低维、中小样本、边界不规则的分类上表现优秀。两者都在深度模型出现前长期霸榜。

## 9. SVR：SVM 做回归

SVM 不仅能分类，还能回归（SVR）。思想反过来：**不是"让间隔内没有点"，而是"让尽可能多的点落在 $\epsilon$-管道内"**。

$$\min_{w,b,\xi}\ \frac{1}{2}\|w\|^2 + C\sum_{i=1}^{n}(\xi_i + \xi_i^*) \quad \text{s.t.}\quad \begin{cases} y_i - (w^T x_i + b) \le \epsilon + \xi_i \\ (w^T x_i + b) - y_i \le \epsilon + \xi_i^* \\ \xi_i, \xi_i^* \ge 0 \end{cases}$$

- 落在宽度 $2\epsilon$ 的管道内的点**不产生损失**（只惩罚管道外的点）。
- 依然只有"支持向量"（管道边缘/之外的点）参与决定函数，依旧可用核技巧。

```python
from sklearn.svm import SVR
svr = SVR(kernel='rbf', C=10, gamma='scale', epsilon=0.1)
svr.fit(X_train, y_train)
```

## 10. 扩展：异常检测与 NuSVC

- **One-Class SVM**：只给"正常"数据训练，学出一个包围正常数据的边界，新样本在边界外即视为异常。用于**无监督异常检测**。
  ```python
  from sklearn.svm import OneClassSVM
  ocsvm = OneClassSVM(kernel='rbf', nu=0.05, gamma='scale')
  ocsvm.fit(X_normal)          # 返回 +1 正常 / -1 异常
  ```
- **NuSVC**：用参数 $\nu \in (0,1)$ 代替 $C$，$\nu$ 同时上界"支持向量比例"和"错分比例"，语义更直观，但训练略慢。

> 对异常检测，若追求可解释性与速度，也可考虑隔离森林（Isolation Forest）或基于密度的方法（见 [[06-聚类|DBSCAN]]）。

## 11. 调参实践清单

| 步骤 | 操作 |
|------|------|
| 1 | **标准化**（`StandardScaler`）——SVM 不做等于白做 |
| 2 | 默认 `kernel='rbf'`，`C=1.0`，`gamma='scale'` 跑基线 |
| 3 | 网格搜索 `C ∈ [0.1,1,10,100]`、`gamma ∈ [0.01,0.1,1,10]`（对数网格） |
| 4 | 需要概率时设 `probability=True`（注意速度与校准代价） |
| 5 | 样本量大（>10⁴）考虑 `SGDClassifier(loss='hinge')`（线性）加速 |
| 6 | 验证是否过拟合：画决策边界 / 看训练-验证得分差 |

> **为何必须标准化**：RBF 核里的距离 $\|x_i - x_j\|^2$ 对尺度敏感，量纲大的特征会主导整个相似度。

---

## 12. SVM 的现代定位

- 深度网络崛起后，SVM 在**图像/语音/文本大样本**上退居二线。
- 但在**中小规模、结构化表格、边界复杂**的任务上仍是高性价比之选；SVM 的**核思想**、**支持向量**、**对偶与稀疏解**影响了后续所有模型（kernel 方法、SVR、One-class、多分类策略 OvO/OvR 到处在用）。
- 理解 SVM 约等于理解"优化的建模艺术"：把目标写成凸问题，用对偶换来核技巧。
