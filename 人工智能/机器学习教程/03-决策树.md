# 03 决策树

> 决策树是**最可解释**的机器学习模型：它把"要不要给这个人放贷？"翻译成一连串"是/否"判断。它也是集成学习（随机森林、XGBoost）的**基学习器**，理解它等于理解了 80% 的现代表格数据模型。信息熵的完整推导在数理基础，这里讲流程、直觉与 sklearn 实现。

---

## 1. 决策树结构

```
                  根节点：花瓣长度 < 2.5 ?
                 /                    \
        是（类别A叶节点）            内部节点：花瓣宽度 < 1.8 ?
                                    /                \
                           类别B叶节点          类别C叶节点
```

- **根节点**：第一次划分的节点，包含全部样本。
- **内部节点**：对某个特征做一次判断，继续分流。
- **叶节点**：给出最终预测（类别或回归值）。

**三个问题**：选哪个特征划分？何时停止？如何避免过拟合？——这构成了决策树理论的全部。

---

## 2. 特征选择：纯度度量

划分的目标是让子节点越来越"纯"（同类样本集中）。三种经典纯度度量对应三个经典算法：

### 2.1 信息熵与信息增益（ID3）

**熵**（不确定性度量，$\log$ 以 2 为底）：

$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

- $p_k$ 是类别 $k$ 的占比。熵 = 0 表示纯节点（所有样本一类）；$K$ 类均匀分布时熵最大 $= \log_2 K$。

**条件熵**（特征 $A$ 划分后加权平均剩余熵）：

$$H(D|A) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} H(D^v)$$

**信息增益**（划分后"不确定性的减少量"）：

$$\text{Gain}(D, A) = H(D) - H(D|A)$$

**ID3** 每次都选增益最大的特征。**偏向取值多的特征**（特征取值越多，划分越细，熵降得越快）——这是它的缺点。

### 2.2 信息增益率（C4.5）

为修正 ID3 的偏好，除以"固有值"（特征自身熵）：

$$\text{GainRatio}(D, A) = \frac{\text{Gain}(D, A)}{H_A(D)}, \qquad H_A(D) = -\sum_{v=1}^{V}\frac{|D^v|}{|D|}\log_2 \frac{|D^v|}{|D|}$$

**C4.5**：先筛出增益高于平均的特征，再在其中选增益率最大的。偏好转弯抹角一点，但不再一味偏爱多取值特征。

### 2.3 基尼指数（CART）

基尼系数（随机抽两个样本不同类的概率）：

$$\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2$$

划分后加权平均基尼：

$$\text{Gini\_index}(D, A) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} \text{Gini}(D^v)$$

**CART（Classification And Regression Tree）**选基尼指数最小的特征。**sklearn 的 `DecisionTreeClassifier` 默认 `criterion='gini'`**。

| 度量 | 算法 | 公式核心 | 偏好 |
|------|------|----------|------|
| 信息增益 | ID3 | $H(D) - H(D\|A)$ | 多取值特征 |
| 信息增益率 | C4.5 | 增益 ÷ 固有值 | 均衡 |
| 基尼指数 | CART | $1 - \sum p_k^2$ | 均衡、计算快 |

> 三者本质都是"划分后纯度提升"的不同测度。CART 的基尼无需对数计算，数值更快，且**天然支持回归**（叶节点输出均值，损失用 MSE）。

## 3. 剪枝：对付过拟合

决策树极易**过拟合**——它可以把树长到每个训练样本一个叶节点，准确率 100%。剪枝就是为了控制复杂度，本质是偏差-方差权衡（见 [[01-模型评估与交叉验证|模型评估]]）。

### 3.1 预剪枝（Pre-pruning）

生成过程中提前停止：
- 叶节点样本数低于阈值（`min_samples_leaf`）
- 深度超过限制（`max_depth`）
- 划分提升的信息增益/基尼减少不足阈值
- 验证集上该节点划分后得分反而下降

✅ 快、避免分支，❌ 有"视野局限"——当前没用的划分，深层可能带来大收益。

### 3.2 后剪枝（Post-pruning）

先生成完整树，再自底向上把验证集上无提升的内部节点替换为叶节点。更可靠但更慢。

### 3.3 代价复杂度剪枝（CCP，sklearn 默认后剪枝方式）

目标函数同时惩罚错误率和树的复杂度：

$$R_\alpha(T) = R(T) + \alpha \cdot |T_{leaf}|$$

- $R(T)$：训练误差；$|T_{leaf}|$：叶节点数；$\alpha$：复杂度惩罚系数。
- $\alpha$ 越大，树越简单。sklearn 用 `ccp_alpha` 控制，可用 `cost_complexity_pruning_path` 找有效的 $\alpha$ 序列，再在验证集上选。

```python
from sklearn.tree import DecisionTreeClassifier

clf = DecisionTreeClassifier(ccp_alpha=0.01, random_state=42)
```

**sklearn 常用剪枝超参数**：`max_depth`、`min_samples_split`（内部节点最少样本数）、`min_samples_leaf`、`max_leaf_nodes`、`ccp_alpha`。

---

## 4. 连续特征处理

- **二分法（CART 用）**：特征 $A$ 有 $n$ 个不同取值，排序后相邻取值取中点为候选阈值，逐一计算纯度，选最优切分点。计算量 $O(n)$ 次纯度评估。
- **多分法（C4.5 用）**：把连续特征当离散，每个取值一叉，树会迅速膨胀且过拟合，现已少用。

> 决策树对连续特征本质是**单特征分点**，这使它只能近似线性边界（阶梯状），但组合多棵树的深度后也能表达复杂非线性。

---

## 5. 缺失值处理

C4.5 的经典方案（sklearn 也内置支持）：
1. **划分时**：用"无缺失样本"的子集 $D'$ 计算增益，再按"有缺失样本占比" $\rho = |D'|/|D|$ 打折：$\text{Gain} = \rho \cdot \text{Gain}(D', A)$。
2. **分配时**：缺失样本按该节点各分支的样本比例加权分配到各子节点（同一份样本按权重分到多支）。
3. **预测时**：缺失样本同时走所有分支，按比例加权投票。

> 实操上，很多团队直接对缺失特征**填充**（均值/中位数/众数）或用专门的缺失指示列，比让树自己处理更可控。

## 6. 实战：鸢尾花分类（DecisionTreeClassifier）

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier, plot_tree, export_text
from sklearn.model_selection import train_test_split, cross_val_score

data = load_iris()
X, y = data.data, data.target

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

# 1) 默认基尼树
clf = DecisionTreeClassifier(random_state=42)
clf.fit(X_train, y_train)
print(f"训练精度: {clf.score(X_train, y_train):.3f}")
print(f"测试精度: {clf.score(X_test, y_test):.3f}")
print(f"树的深度: {clf.get_depth()}, 叶节点数: {clf.get_n_leaves()}")

# 2) 受限的树（预剪枝）——防止过拟合
clf2 = DecisionTreeClassifier(
    max_depth=3, min_samples_leaf=3, random_state=42)
clf2.fit(X_train, y_train)
print(f"剪枝后测试精度: {clf2.score(X_test, y_test):.3f}")

# 3) 可视化决策树
plt.figure(figsize=(14, 8))
plot_tree(clf2, filled=True, feature_names=data.feature_names,
          class_names=data.target_names.tolist(), rounded=True)
plt.show()

# 4) 文本形式的树
print(export_text(clf2, feature_names=list(data.feature_names)))

# 5) 特征重要性（CART 的默认输出）
for name, imp in zip(data.feature_names, clf2.feature_importances_):
    print(f"{name}: {imp:.3f}")
```

**特征重要性**的算法：把每个节点用该特征划分所降低的不纯度（基尼减少量 × 该节点样本占比）沿树累加，归一化得到。它是随机森林重要性（见 [[04-集成学习|集成学习]]）的基础。

## 11. 决策树的优缺点

### 优点
- ✅ **可解释**：可视化后是白盒，适合需要审计的领域（医疗、信贷）。
- ✅ **不需要标准化/归一化**，对特征尺度、单调变换不敏感。
- ✅ 天然处理混合类型特征、缺失值、非线性关系。
- ✅ 训练快，适合大表格数据。

### 缺点
- ❌ **单棵树过拟合严重**、不稳定（数据微小扰动树结构大变）。
- ❌ 只能产生**轴对齐**的矩形划分，难以表示斜边界（除非用多棵）。
- ❌ 数据不均衡时偏向多数类。

## 12. 决策树 → 随机森林

单棵树的"高方差、不稳定"恰恰为集成提供素材：**多棵独立树取平均，方差大幅下降**。这是 [[04-集成学习|随机森林]] 的核心逻辑——决策树的价值一半在自身，一半在作为集成基学习器。

## 7. sklearn 决策树超参数一览

```python
DecisionTreeClassifier(
    criterion='gini',        # 'gini' / 'entropy' / 'log_loss'
    max_depth=None,          # 树最大深度（预剪枝核心参数）
    min_samples_split=2,     # 内部节点最少样本数
    min_samples_leaf=1,      # 叶节点最少样本数（防过拟合常用）
    max_features=None,       # 每个节点考虑的特征数（RF 思想）
    max_leaf_nodes=None,     # 最多叶节点数
    min_impurity_decrease=0.0, # 分裂需达到的最小纯度提升
    ccp_alpha=0.0,           # 代价复杂度剪枝（后剪枝）
    class_weight=None,       # 类别不均衡时用 'balanced'
    random_state=42,         # 复现结果
)
```

**调参经验（按重要性排序）**：
1. 先限制 `max_depth`（3~10）与 `min_samples_leaf`——80% 的过拟合来自树太深。
2. 再用 `ccp_alpha` 做代价复杂度剪枝（配合 `cost_complexity_pruning_path` 画曲线选拐点）。
3. 最后看 `feature_importances_` 做特征选择。

```python
from sklearn.tree import DecisionTreeClassifier, cost_complexity_pruning_path

clf = DecisionTreeClassifier(random_state=42).fit(X_train, y_train)
path = cost_complexity_pruning_path(clf, X_train, y_train)
ccp_alphas, impurities = path.ccp_alphas, path.impurities

# 训练不同 α 的树，在验证集上选最优
best_score, best_alpha = 0, 0
for alpha in ccp_alphas:
    c = DecisionTreeClassifier(ccp_alpha=alpha, random_state=42)
    c.fit(X_train, y_train)
    s = c.score(X_val, y_val)
    if s > best_score:
        best_score, best_alpha = s, alpha
print(f"最优 ccp_alpha={best_alpha:.4f}, 验证精度={best_score:.3f}")
```

## 8. CART 回归树（DecisionTreeRegressor）

分类树输出类别，回归树**叶节点输出该簇样本的均值**。分裂准则从基尼/熵换成**最小化 MSE**：

$$\text{loss}(D, A, t) = \sum_{v} \frac{|D^v|}{|D|}\left(\frac{1}{|D^v|}\sum_{i\in D^v}(y_i - \bar{y}^v)^2\right)$$

本质是**二分递归的最小二乘拟合**——在每个节点找"特征+阈值"，把两侧样本的方差和降到最低。因此决策树回归得到的预测是**分段常数函数**。

```python
from sklearn.tree import DecisionTreeRegressor
from sklearn.datasets import make_regression

X_r, y_r = make_regression(n_samples=200, n_features=1, noise=15, random_state=42)
reg = DecisionTreeRegressor(max_depth=4, random_state=42).fit(X_r, y_r)
print(f"R² = {reg.score(X_r, y_r):.3f}")
```

> 树模型做回归的局限：预测值只能是"叶子均值"的有限集合，无法外推到样本范围之外（对趋势外推任务要谨慎）。

## 9. 决策树 vs 其他模型

| 维度 | 决策树 | 逻辑回归 | KNN | 随机森林 |
|------|--------|----------|-----|----------|
| 可解释性 | ★★★★★ | ★★★★ | ★★★ | ★★ |
| 需要标准化 | 否 | 是 | 是 | 否 |
| 非线性 | 轴对齐阶梯 | 线性（核可扩展） | 任意 | 强 |
| 训练速度 | 快 | 快 | 无需训练 | 快(可并行) |
| 对高维稀疏 | 尚可 | 好 | 差 | 好 |
| 过拟合倾向 | 严重（需剪枝） | 低（正则） | 低 | 低 |
| 概率输出 | 无原生 | 有 | 投票比例 | 有（vote 比例） |

> 单独用决策树的时候很少，它的高方差正好被 [[04-集成学习|随机森林/GBDT]] 平均/串行补救。

## 10. 决策树实战技巧总结

| 场景 | 建议 |
|------|------|
| 特征单位不同/量纲差大 | 无需标准化，直接用 |
| 类别不均衡 | `class_weight='balanced'` 或先欠采样 |
| 特征缺失多 | 让树自行处理或先填充 |
| 想可视化解释给业务 | `plot_tree` 导出 + 限制 `max_depth<=4` |
| 追求精度 | 别用单棵树，直接上随机森林/XGBoost |
