# 08 半监督学习（Semi-Supervised Learning）

> 现实中标注很贵，数据很多。一张医学 CT 要专家标注几小时，而互联网上有海量未标注图像。**半监督学习**的目标：用少量标注 + 大量无标注数据，取得接近"全标注"的性能。它的思想直通深度学习的**预训练-微调**范式，是连接经典 ML 与 LLM 的重要桥梁。

---

## 1. 动机与设定

### 1.1 为什么需要半监督

- 标注成本高（人力、专家、时间），无标注数据近乎免费。
- 常见设定：$L$ 个标注样本 + $U$ 个无标注样本，且 $U \gg L$（如 $U = 100L$）。

### 1.2 核心假设（为什么无标注数据能帮忙）

无标注数据的价值取决于以下假设成立的程度：

1. **平滑性（Smoothness）**：特征相近的样本，标签倾向相同。
2. **聚类假设（Cluster）**：同类样本聚成簇，决策边界应避开高密度区域。
3. **低密度分离（Low-density separation）**：决策边界应穿过数据稀疏的"峡谷"。
4. **流形假设（Manifold）**：高维数据躺在低维流形上，标签沿流形平滑变化。

> 直觉：无标注数据相当于给决策边界"地图"——边界不用穿越数据密集区，所以更符合真实分布。若假设不成立（边界本来就在密集区），半监督可能**帮倒忙**。

### 1.3 理论理解（直觉）

可以近似理解：$U$ 个无标注样本提供了关于 $P(X)$ 的信息，帮助更准确地估计后验 $P(y|x)$。在生成式框架（如高斯混合）里，无标注样本直接参与似然估计，让每个类的高斯"云团"形状更精确。

## 2. 主要方法

## 2.1 自训练（Self-Training）

```
1. 用已标注数据 L 训练初始模型
2. 对无标注数据 U 预测，选出"高置信度"的伪标注样本
3. 把伪标注样本加入训练集，重新训练
4. 重复直到 U 耗尽或达到迭代上限
```

- **风险**：早期错误会自我放大（"确认偏误"）。对策：只收高置信度、设置信度阈值、按置信度加权。
- 这是最通用、最朴素的方法，可套在任何分类器上。

## 2.2 协同训练（Co-Training）

**多视图假设**：特征天然分成两个独立视图（如网页 = 文字 + 链接）。在两个视图上分别训练两个模型，各自挑选高置信度样本去"教"对方。

```
视图 A 模型 → 高置信样本 → 标注后加入视图 B 训练集（反之亦然）
```

要求视图条件独立——严格满足的场景不多，但思想影响深远（后来的多模型互教）。

## 2.3 伪标签（Pseudo-Labeling）

本质是**自训练在深度学习中的形态**：用已训练模型给无标注数据打伪标签，混合进训练。关键超参：**置信度阈值**（如 0.95 才采纳）与伪标签损失权重（随训练轮次动态上升）。

## 2.4 一致性正则（Consistency Regularization）

**核心思想**：对同一个样本做两次不同的数据增强，两次预测应一致。把"一致性"作为损失项：

$$\mathcal{L} = \mathcal{L}_{sup} + \lambda \sum_{i} d\big(f(\text{aug}_1(x_i)),\ f(\text{aug}_2(x_i))\big)$$

- 无标注样本不强制"属于哪类"，只强制"扰动下预测稳定"。
- 经典方案：**Temporal Ensembling → Mean Teacher → FixMatch / MixMatch**。
- **FixMatch**（2020，SOTA 级）：弱增强样本预测置信度超过阈值才生成伪标签，并用该伪标签监督**强增强**样本的预测。低密度分离 + 平滑性两个假设一起用。

$$\mathcal{L} = \ell_{sup} + \lambda \cdot \mathbb{1}[\max(p_w) \ge \tau]\ \ell\big(p_s,\ \hat{p}_w\big)$$

> 一致性正则与现代深度学习数据增强一脉相承，是半监督 + 深度学习的标配。

## 3. 图半监督学习：标签传播

把数据建成**图**：样本是节点，样本间相似度是边权（如 RBF 核 $w_{ij} = \exp(-\gamma\|x_i - x_j\|^2)$）。标签沿着边**传播**：已知标签的节点把标签"渗"给邻居，迭代到收敛。

### 3.1 Label Propagation（标签传播）

迭代更新每个节点的标签分布为邻居标签的加权平均：

$$F^{(t+1)} = \alpha\, S\, F^{(t)} + (1-\alpha)\, Y$$

- $S$：归一化相似度矩阵；$Y$：初始已知标签；$\alpha$ 控制传播强度。
- **有标签节点会被"拉回"初始值**（软约束），保证不遗忘已知信息。

### 3.2 Label Spreading

在传播中给已知标签节点一个**固定权重**，数学上等价于解一个带约束的扩散方程，收敛更快更稳，**sklearn 推荐用 `LabelSpreading`**。

```python
from sklearn.semi_supervised import LabelSpreading, LabelPropagation
# 注意：无标注样本的标签用 -1 占位
y_semi = np.full(n_samples, -1); y_semi[idx_labeled] = y_labeled
model = LabelSpreading(kernel='rbf', gamma=20, alpha=0.8)
model.fit(X, y_semi)          # X 包含所有标注+无标注样本
```

**直觉**：这利用了**流形/平滑假设**——相似样本连边，标签沿"数据流形"爬行，绕开低密度区域。

> 图构建的代价是 $O(n^2)$，样本量大时需用 kNN 稀疏图近似。

## 4. 半监督 → 深度学习的预训练范式

现代 LLM 的成功本质是**最大规模的半监督/自监督**：

- **无监督预训练**：在海量无标注文本上用自监督任务（预测下一个 token、掩码恢复）学习通用表征——相当于在大规模 $U$ 上学 $P(X)$ 的结构。
- **有监督微调（SFT）**：用少量高质量标注数据（指令/偏好）对齐到目标任务——相当于在 $L$ 上做定向优化。
- 这与经典半监督"无标注学结构 + 少量标注学任务"是**同一个配方**，只是规模巨大化。

| 经典半监督 | 预训练-微调 |
|-----------|-------------|
| 自训练/伪标签 | 模型自生成数据（蒸馏、自举） |
| 一致性正则 | 对比学习、数据增强鲁棒性 |
| 图标签传播 | 表征空间中的最近邻标签 |
| 少量标注 $L$ + 大量 $U$ | 预训练（$U$）+ SFT（$L$） |

> 详见 [[../深度学习教程/12-Transformer与大模型|Transformer 与大模型]] 的预训练-微调章节。

## 5. 实战：LabelSpreading 在部分标注数据上的对比

用鸢尾花（150 个样本）只标注少量样本，对比"只监督"与"半监督"的性能差距。

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.semi_supervised import LabelSpreading
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

data = load_iris()
X, y = data.data, data.target

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

# 只保留 6 个标注样本（每类 2 个），其余当无标注
n_labeled = 6
rng = np.random.RandomState(42)
idx_all = np.arange(len(X_train))
rng.shuffle(idx_all)
idx_labeled = idx_all[:n_labeled]

y_semi = np.full(len(X_train), -1)          # -1 = 无标注占位
y_semi[idx_labeled] = y_train[idx_labeled]

# 1) 纯监督基线：只用 6 个标注样本
lr = LogisticRegression(max_iter=1000)
lr.fit(X_train[idx_labeled], y_train[idx_labeled])
print(f"仅监督（6 标注样本）: {accuracy_score(y_test, lr.predict(X_test)):.3f}")

# 2) 半监督：6 标注 + 99 无标注，全量训练
lp = LabelSpreading(kernel='rbf', gamma=20, alpha=0.8, max_iter=100)
lp.fit(X_train, y_semi)
print(f"半监督 LabelSpreading: {accuracy_score(y_test, lp.predict(X_test)):.3f}")

# 3) 上界参照：全部标注
lr_full = LogisticRegression(max_iter=1000)
lr_full.fit(X_train, y_train)
print(f"全监督上界（全部标注）: {accuracy_score(y_test, lr_full.predict(X_test)):.3f}")

# 4) 查看模型给无标注样本打出的"伪标签"分布
unlabeled_mask = y_semi == -1
print("无标注样本伪标签分布:", np.bincount(lp.transduction_[unlabeled_mask],
      minlength=3))
```

**预期结论**：`6 个标注样本的监督` 往往跌到 50%~70%；`LabelSpreading 半监督` 通常能追到 90%+，逼近全监督上界。这说明**大量无标注数据确实重构了决策边界**。

> 注：`transduction_` 保存训练集（含无标注样本）的最终标签，方便观察传播结果。核与 $\alpha$、$\gamma$ 需要调（这里 `gamma=20` 对 iris 合适）。

## 6. 方法总览

| 方法 | 核心机制 | 依赖假设 | 适用 |
|------|----------|----------|------|
| 自训练 | 高置信伪标签加入训练 | 平滑性 | 通用、简单 |
| 协同训练 | 多视图互教 | 特征可分视图 | 多视图数据 |
| 伪标签 | 阈值过滤伪标签 | 平滑性 | 深度学习 |
| 一致性正则（FixMatch） | 增强不变性 | 平滑性+低密度分离 | 深度学习图像/文本 |
| 标签传播 | 图上传标签扩散 | 流形/平滑 | 小规模、图结构 |

## 7. 常见坑

| 坑 | 对策 |
|----|------|
| 无标注数据含异质分布（域偏移） | 检查 $U$ 与 $L$ 是否同分布 |
| 伪标签错误自我放大 | 高阈值 + 按置信度加权 + 早停 |
| 图构建 $O(n^2)$ 内存爆炸 | kNN 稀疏图（`sklearn.neighbors`） |
| 假设不成立反而变差 | 用验证集对比"纯监督 vs 半监督"再决定是否用 |
| 把半监督当万能 | 标注预算允许时优先加标注 |

## 8. 生成式半监督：混合模型 + EM（直觉）

以高斯混合模型（GMM）为例：若我们已知 $P(X)$ 由 $K$ 个高斯成分组成，**无标注样本也能参与估计**。用 EM 迭代：

- **E 步**：用当前参数估计每个样本属于各成分的后验 $P(z_k|x_i)$（标注样本的 $z$ 已知，直接固定）。
- **M 步**：把后验当权重，重新估计各成分的均值/协方差/混合系数。

**为什么无标注数据有用**：它帮助精确定位每个高斯"云团"的形状，而标注样本只负责告诉模型"哪朵云对应哪一类"。当类别的高斯假设大致成立时，效果逼近全监督。更一般的数学框架见 [[../../数理基础/机器学习数学基础/贝叶斯分类器|贝叶斯分类器]]。

```python
from sklearn.mixture import GaussianMixture
# 无监督 GMM 学 P(X)，再用少量标签映射"成分→类别"也是常见基线
gmm = GaussianMixture(n_components=3, random_state=42).fit(X)
```

## 9. 半监督 vs 主动学习

两者都解决"标注贵"，但路线不同：

| | 半监督学习 | 主动学习 |
|---|---|---|
| 无标注数据的用法 | 直接参与训练（自学习） | 选出最"值钱"的样本**交给人工标注** |
| 谁产生标签 | 模型（伪标签） | 人类专家（真标签） |
| 成本 | 零标注成本 | 仍需有限次标注 |
| 关键 | 模型质量决定伪标签质量 | 采样策略（不确定性/多样性） |

> 组合使用是标配：先用半监督利用现有数据，再用主动学习挑选**最有价值的**少量样本标注后加入。

## 10. 深度学习中的一致性正则实操（伪代码）

```python
# FixMatch 的核心逻辑（示意）
threshold = 0.95
for x_weak, x_strong in zip(batch_weak, batch_strong):     # 数据增强对
    p_weak = model(x_weak)
    mask = (p_weak.max(dim=1).values > threshold)          # 只有高置信才用
    pseudo = p_weak.argmax(dim=1)
    loss_consistency = CE(model(x_strong), pseudo) * mask  # 强增强对齐伪标签
    loss = loss_sup + lambda * loss_consistency
```

要点：**弱增强**生成可靠伪标签，**强增强**提供对抗性扰动，迫使模型学鲁棒边界——这就是"低密度分离"在深度空间里的实现。

## 11. 半监督评估的坑

| 坑 | 对策 |
|----|------|
| 无标注数据与标注分布不一致 | 检查域漂移，必要时过滤 |
| 只看最终精度 | 与"纯监督基线"同设置对比，确认无标注数据真的有用 |
| 伪标签全接受 | 设置信度阈值 + 类别平衡采样 |
| 图方法数据量大 | 用 kNN 稀疏图 / 子采样 |
| 类别不均衡导致伪标签偏向多数类 | 按类别的伪标签数量加权/重采样 |

## 12. 半监督学习脉络小结

```
经典（小数据）
  自训练 → 协同训练 → 图传播(LabelSpreading)
                    ↘ 生成式(EM/GMM)
现代（大数据 + 深度学习）
  伪标签 → Mean Teacher → MixMatch → FixMatch → 预训练-微调
```

内核始终是同一句话：**让无标注数据在模型看来"有结构"——要么被贴伪标签，要么被要求扰动下保持稳定，要么沿图/流形传播**。
