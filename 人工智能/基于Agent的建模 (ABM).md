## 基于Agent的建模 (ABM) 概述

### 核心概念

ABM 将系统描述为一组**代理人 (Agents)**、一个**环境 (Environment)** 以及代理人之间及其与环境之间的**相互作用 (Interactions)**。

### 主要组成要素

|**要素**|**描述**|**关键特征**|
|---|---|---|
|**代理人 (Agent)**|系统的基本单位（如个体、组织、细胞、汽车等）。|1. **自主性：** 能根据自己的规则行事。 2. **异质性：** 可以有不同的属性、状态和行为规则。 3. **社会性：** 能与其他代理人互动。 4. **反应性/目标导向性：** 能对环境或他人做出反应。|
|**环境 (Environment)**|代理人生活和互动的空间。|可以是物理空间（如网格、地理坐标）、社会网络（如社交图谱），或者只是一个共享的数据结构。|
|**相互作用 (Interactions)**|代理人之间以及代理人与环境之间的影响和通信。|遵循局部规则，例如：邻居模仿、交易、感染传播、碰撞避免等。|
|**突现 (Emergence)**|系统的宏观模式和行为，它们是从大量的局部相互作用中自发产生的，而不是直接由模型设计者预设的。|ABM 的核心价值所在。|

### 工作流程

1. **定义代理人：** 确定代理人的状态变量（属性）、行为规则（决策逻辑）。
    
2. **定义环境：** 确定环境的拓扑结构（如格子、网络）。
    
3. **定义互动：** 确定代理人如何发现并影响彼此。
    
4. **初始化与运行：** 设定初始条件，让模型随着时间步（Time Step）迭代运行。
    
5. **分析：** 观察宏观结果，将模型的突现行为与现实世界的现象进行比较和验证。

## 2. ABM 的优势和应用

### 核心优势

- **处理异质性：** 能够直接建模个体之间的差异，这对于很多社会和生物系统至关重要。
    
- **处理非线性：** 能够捕获高度非线性的、局部相互作用引起的复杂动态。
    
- **突现现象：** 是研究系统宏观行为如何从微观互动中产生的最佳工具。
    
- **适应性：** 代理人可以有学习和适应性行为，使模型更贴近真实世界。
    

### 典型应用领域

|**领域**|**典型研究问题**|
|---|---|
|**社会科学**|舆论形成、社会隔离、文化传播、群体行为、应急疏散。|
|**经济学**|市场崩溃/泡沫、金融系统稳定性、交易策略、创新扩散。|
|**生态学**|种群动态、物种竞争、病毒/疾病传播（流行病学）。|
|**交通与物流**|交通拥堵、行人流、自动驾驶汽车调度。|
|**军事/安全**|战争模拟、恐怖主义网络分析、反恐策略评估。|
