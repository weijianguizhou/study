# 人工智能体系 · 总览

> 本文是人工智能板块的**地图**：按照「AI ⊃ 机器学习 ⊃ 深度学习」的包含关系组织全部教程，每一条都指向具体的笔记。

---

## 0. 体系全景

```
人工智能 (AI)                              ← 让机器模拟人类智能的学科总称
│
├── 符号派 / 经典 AI（规则驱动）
│   ├── 专家系统（知识库 + 推理规则）
│   ├── 知识图谱（实体关系表示）
│   ├── 搜索算法（A*、博弈树、Minimax）
│   └── 逻辑推理 / 自动规划
│
├── 机器学习 (ML)                          ← 从数据中学习规律，而非人工编程
│   ├── 监督学习（有标签）
│   │   ├── 回归：线性回归、岭回归、SVM 回归
│   │   └── 分类：逻辑回归、决策树、随机森林、SVM、KNN、朴素贝叶斯、XGBoost
│   ├── 无监督学习（无标签）
│   │   ├── 聚类：K-Means、DBSCAN、层次聚类
│   │   └── 降维：PCA、t-SNE
│   ├── 半监督学习（少量标签）
│   ├── 强化学习 (RL)
│   │   ├── 基于价值：Q-Learning、DQN
│   │   └── 基于策略：Policy Gradient、PPO、AlphaGo/AlphaZero
│   └── 深度学习 (DL)                      ← ML 的一个子集，多层神经网络
│       ├── CNN（卷积神经网络）            → 图像
│       ├── RNN / LSTM / GRU              → 序列
│       ├── Transformer                    → 自注意力，现代大模型的基石
│       ├── GAN（生成对抗网络）            → 图像生成
│       ├── 自编码器 / VAE / 扩散模型       → 表示学习与生成
│       └── 大模型 / 生成式 AI             ← DL 最新形态
│           ├── 大语言模型 (LLM)：GPT、DeepSeek
│           ├── 多模态模型：GPT-4V、文生图
│           └── 智能体 (Agent)：规划、工具调用、多 Agent
│
└── 其他 AI 领域（不完全属于 ML）
    ├── 计算机视觉 (CV)
    ├── 自然语言处理 (NLP)
    ├── 语音识别 / 合成
    ├── 机器人与运动控制
    └── 进化计算、专家系统等
```
