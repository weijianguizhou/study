# 计算机视觉（CV）· 索引

> 计算机视觉（Computer Vision, CV）研究让计算机"看懂"图像与视频：识别物体、定位目标、理解场景、生成图像。视觉是人类获取信息最重要的通道，也是深度学习最早突破、落地最广的领域之一。

---

## 1. 什么是计算机视觉

### 1.1 定义

**CV** = 从图像/视频中提取信息、理解内容并作出反应的计算方法。

"看"这个行为远超像素本身——像素只是 $H \times W \times C$ 的数值矩阵，**语义**才是目标：

$$
\text{图像} = \underbrace{(r, g, b)}_{H \times W \text{ 个像素}} \xrightarrow{\text{表示学习}} \underbrace{\text{"一只在草地上的橘猫"}}_{\text{语义}}
$$

### 1.2 为什么 CV 难

| 挑战 | 说明 | 例子 |
|------|------|------|
| 视点变化 | 同一物体不同角度 | 正面/侧面看同一辆车 |
| 光照变化 | 光照改变外观 | 白天/夜晚同一街道 |
| 遮挡与截断 | 物体被部分遮挡 | 人群中的半张脸 |
| 背景杂波 | 目标淹没在背景中 | 树丛中的鸟 |
| 类内差异 | 同类外观差异大 | 不同品种的狗 |
| 形变与运动 | 物体形状变化 | 奔跑中的人、飘动的旗 |

深度学习用**卷积网络的平移等变性**和**大规模数据**大幅缓解了这些问题（见 [[../深度学习教程/09-卷积神经网络CNN|CNN]]）。

## 2. 任务全景

### 2.1 图像分类（Image Classification）

判断整张图是什么：`猫 / 狗 / 飞机……`。最基础的任务，也是其他任务的骨架。

$$
\hat{y} = \arg\max_k P(y = k \mid I)
$$

代表数据集：ImageNet（1000 类）、CIFAR-10。架构演进：AlexNet → VGG → ResNet → ViT（见 [[../深度学习教程/10-经典CNN架构|经典 CNN 架构]]）。

### 2.2 目标检测（Object Detection）

**定位 + 分类**：找出一张图中所有目标，并给出每个目标的**边界框**和**类别**。

$$
\text{Detection}(I) = \{(x_1, y_1, x_2, y_2, c, s)_k\}_{k=1}^{K}
$$

代表模型：R-CNN 系（两阶段）、YOLO/SSD（单阶段）、DETR（Transformer）。评估指标 IoU、mAP。→ 详见 [[01-目标检测|目标检测]] 与 [[../机器学习项目/YOLO.tex|YOLO 项目]]。

### 2.3 语义分割（Semantic Segmentation）

对**每个像素**打类别标签（不做个体区分）：

$$
\text{Seg}(I) \in \{0,1,\dots,K-1\}^{H \times W}
$$

代表模型：FCN、U-Net（医学影像）、DeepLab、Mask2Former。

### 2.4 实例分割（Instance Segmentation）

分割 + 区分个体：每只狗自己的像素集合。

$$
\text{Instance}(I) = \{ \text{mask}_k \}_{k=1}^{K}, \quad \text{mask}_k \in \{0,1\}^{H \times W}
$$

代表模型：Mask R-CNN、SOLO、SAM（Segment Anything）。

### 2.5 姿态估计（Pose Estimation）

估计人体/物体的关键点位置与骨架结构：

$$
\text{Pose}(I) = \{ (x_j, y_j, c_j) \}_{j=1}^{J}, \quad J = 17 \sim 133 \text{ 个关键点}
$$

代表模型：OpenPose、HRNet、MediaPipe。

### 2.6 OCR（光学字符识别）

识别图像中的文字：**文本检测**（定位文字区域）+ **文本识别**（把区域转为字符串）。

```
打印文字、手写体、车牌、票据、身份证……
```

代表模型：EAST/PSE（检测）、CRNN/TrOCR（识别）、PaddleOCR 全家桶。

### 2.7 3D 视觉（3D Vision）

从 2D 图像恢复三维结构：

- **深度估计**：单目/双目估计每像素深度。
- **3D 重建 / NeRF / 3DGS**：多视角重建场景（高斯泼溅 3DGS 是 2023 年热点）。
- **SLAM**：同时定位与建图（机器人/自动驾驶）。

### 2.8 图像生成（Image Generation）

从文本/噪声/条件生成图像，是生成式 AI 的视觉侧：

$$
\text{Generate}(\text{"一只戴帽子的猫"}) \rightarrow I
$$

代表模型：GAN（见 [[../深度学习教程/14-生成对抗网络GAN|GAN]]）、扩散模型（Stable Diffusion，见 [[../深度学习教程/15-扩散模型|扩散模型]]）、VAE（见 [[../深度学习教程/13-自编码器与变分自编码器|VAE]]）。

### 2.9 其他热门任务

视频理解（行为识别）、图像检索、图像质量评估、异常检测（工业质检）、风格迁移、图像超分辨率、自动驾驶感知（检测+分割+深度+轨迹）。

> **一句话**：分类给"整图一个标签"，检测给"多个框+标签"，分割给"每像素标签"，姿态给"关键点"，OCR 给"文字"，3D 给"深度/几何"，生成给"新图像"。

## 3. 发展史

### 3.1 特征工程时代（1990s – 2012）

**手工设计特征 + 传统分类器**（SVM、Boosting）统治 CV：

- **SIFT**（2004）：尺度不变特征转换，检测/描述图像局部特征，对缩放、旋转、光照鲁棒：

  - 检测：尺度空间极值点（DoG）。
  - 描述：关键点邻域的梯度方向直方图（128 维向量）。

- **HOG**（2005）：方向梯度直方图，统计局部梯度方向分布，行人检测的经典特征：

$$
\text{HOG}(x) = \text{hist}(\nabla I(x)),\quad \nabla I = (\partial_x I, \partial_y I)
$$

- **LBP、Haar、Gabor**：纹理、人脸（Haar + AdaBoost 是 OpenCV 人脸检测经典）。

范式：

```
图像 → 手工特征（SIFT/HOG/颜色直方图）→ 编码（BoW/空间金字塔）→ SVM 分类
```

局限：特征依赖专家设计、无法逐级抽象高层语义、泛化差。

### 3.2 深度学习时代（2012 – 2020）

**2012 AlexNet** 引爆一切：8 层 CNN + ReLU + Dropout + GPU，ImageNet 准确率从 ~74% 跳到 ~84%，错误率对半砍。

- **2014 VGG**：加深到 19 层，3×3 小卷积堆叠。
- **2015 ResNet**：残差连接解决退化问题，152 层，ImageNet 冠军（见 [[../深度学习教程/10-经典CNN架构|经典 CNN 架构]]）。
- **2013–2016 检测**：R-CNN → Fast R-CNN → Faster R-CNN → YOLO → SSD（详见 [[01-目标检测|目标检测]]）。
- **2015–2018 分割**：FCN、U-Net、Mask R-CNN。

范式：

```
图像 → CNN 自动学习多层特征（边缘→纹理→部件→物体）→ 任务头（分类/检测/分割）
```

### 3.3 大模型 / 视觉基础模型时代（2021 – ）

视觉不再"每个任务训一个模型"，而是**多模态 + 通用模型**：

| 模型 | 年份 | 思想 | 意义 |
|------|------|------|------|
| **CLIP** | 2021 | 图像与文本对齐（对比学习） | 图像有"语义标签"，零样本分类 |
| **ViT** | 2021 | 图像切成 patch 进 Transformer | 视觉也吃 Transformer |
| **SAM** | 2023 | 通用分割（Segment Anything） | 提示驱动的分割基础模型 |
| **DALL·E / Stable Diffusion** | 2022 | 文生图扩散模型 | 视觉生成大模型 |
| **GPT-4o / Gemini** | 2023– | 原生多模态 VLM | 看图聊天、视觉问答 |
| **3DGS / NeRF** | 2023 | 3D 场景表示 | 新视角合成 |

范式：

```
(图像, 文本) → 跨模态对齐/生成 → 一个模型适配所有视觉任务（零样本/少样本）
```

CLIP 的核心是图文对比学习：拉近匹配的(图,文)对，推远不匹配的对：

$$
\mathcal{L}_{\text{CLIP}} = -\log \frac{\exp(\text{sim}(I_i, T_i)/\tau)}{\sum_j \exp(\text{sim}(I_i, T_j)/\tau)}
$$

其中 $\text{sim}$ 为图像编码器与文本编码器的余弦相似度。详见 [[../大模型与生成式AI/05-多模态模型|多模态]]。

### 3.4 时间线速览

```
1999 SIFT ──► 2005 HOG ──► 2012 AlexNet ──► 2015 Faster R-CNN / ResNet
──► 2016 YOLO / Mask R-CNN ──► 2021 CLIP / ViT ──► 2022 扩散模型
──► 2023 SAM / GPT-4V / 3DGS ──► 2025 多模态大模型全面成熟
```

## 6. 学习路径建议

```
① 图像分类：CNN 全流程（深度学习教程 09/10）
② 目标检测：本目录 01 + YOLO 项目（mAP 评估、Anchor、损失）
③ 分割/姿态：读综述 + 复现 U-Net / HRNet 小任务
④ 生成：扩散模型（深度学习教程 15）
⑤ 大模型：CLIP / SAM / VLM（大模型教程 05）
```

**动手三件事**：用 torchvision 加载 COCO 预训练 Faster R-CNN 跑通检测推理（见 `01`）；用 Ultralytics 在自己图片上训练一个 YOLO 检测器；用 CLIP 做零样本图像分类。
