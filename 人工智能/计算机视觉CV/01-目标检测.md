# 目标检测

> 目标检测（Object Detection）要在图中"找到什么 + 在哪"：为每个目标输出类别与边界框。本文讲清任务定义、IoU/mAP 评估、两阶段与单阶段两条技术路线、Anchor 机制与损失函数，并给出 torchvision Faster R-CNN 推理示例。YOLO 的论文级推导见已有 [[../机器学习项目/YOLO.tex|YOLO 项目]]，本文不重复推导，重点在原理与评估。

---

## 1. 任务定义

### 1.1 输入输出

输入图像 $I \in \mathbb{R}^{H \times W \times 3}$，输出**不定数量**的目标：

$$
\{(x_1^{(k)}, y_1^{(k)}, x_2^{(k)}, y_2^{(k)}, c^{(k)}, s^{(k)})\}_{k=1}^{K}
$$

- $(x_1, y_1), (x_2, y_2)$：边界框（bounding box）的左上/右下角坐标。
- $c$：类别；$s$：置信度得分。

### 1.2 为什么比分类难

- **数量不定**：图中目标个数未知，且可能重叠。
- **定位回归**：除了分类还要精确定位框坐标。
- **类别不平衡**：大量背景（负样本）vs 少量前景（正样本）。
- **尺度多样**：同一类别目标大小差异巨大。

### 1.3 检测 vs 分类 vs 分割

```
分类：整图 → 一个标签
检测：整图 → N 个 (框, 类别)
分割：整图 → 每像素标签（语义）或 每个实例的像素集（实例）
```

## 2. 评估指标

### 2.1 IoU（交并比）

衡量预测框 $\mathbf{b}_p$ 与真实框 $\mathbf{b}_g$ 的重叠程度：

$$
\text{IoU}(\mathbf{b}_p, \mathbf{b}_g) = \frac{|A_p \cap A_g|}{|A_p \cup A_g|}
= \frac{\text{交集面积}}{\text{并集面积}}
$$

- $\text{IoU} \in [0, 1]$，越接近 1 越准。
- 通常 $\text{IoU} \ge 0.5$ 记为"命中"（detected）；COCO 用 $\text{IoU} \in \{0.5, 0.75, \dots\}$ 的多种阈值。

### 2.2 匹配规则与 TP/FP/FN

给定 IoU 阈值（如 0.5），逐类计算：

- **TP（真阳）**：预测框与某真实框 IoU ≥ 阈值（每真实框最多匹配一个预测框）。
- **FP（假阳）**：预测框没有匹配到任何真实框。
- **FN（假阴）**：真实框没有被任何预测框匹配。

### 2.3 Precision-Recall 曲线

把所有预测框按置信度 $s$ **从高到低排序**，依次判定为"检出"，计算累计的：

$$
\text{Precision} = \frac{TP}{TP + FP}, \qquad
\text{Recall} = \frac{TP}{TP + FN}
$$

阈值越低，检出的框越多，Recall 上升、Precision 下降，形成 P-R 曲线。

### 2.4 AP（Average Precision）

AP = P-R 曲线下的面积。COCO 用 **101 点插值**：

$$
\text{AP} = \frac{1}{101} \sum_{r \in \{0, 0.01, \dots, 1\}} P_{\text{interp}}(r)
$$

其中插值规则：在召回率 $r$ 处的 Precision 取"右侧最大的 Precision"：

$$
P_{\text{interp}}(r) = \max_{\tilde{r} \ge r} P(\tilde{r})
$$

> 直觉：曲线越"贴右上角"（高 P 高 R），AP 越大。

### 2.5 mAP（mean Average Precision）

对所有类别取平均：

$$
\text{mAP} = \frac{1}{C} \sum_{c=1}^{C} \text{AP}_c
$$

COCO 常用记法：

- `mAP@0.5`：IoU 阈值 0.5 的 mAP（PASCAL 风格，YOLO 常用）。
- `mAP@0.5:0.95`：IoU 从 0.5 到 0.95、步长 0.05 共 10 个阈值取平均（COCO 主指标）。

**mAP 计算流程**：

```
1. 收集所有预测框，按置信度降序排列
2. 逐框匹配真实框（IoU≥阈值，每 GT 只配一次）→ TP/FP
3. 累计 Precision / Recall 序列
4. 画 P-R 曲线 → 插值 → AP（每类）
5. 所有类 AP 平均 → mAP
```

> 细节实现用 pycocotools：`from pycocotools.coco import COCO; from pycocotools.cocoeval import COCOeval`，勿手写。

## 3. 两阶段检测（Two-Stage）

"**先粗提候选框，再精细分类回归**"，精度高、速度慢。

### 3.1 R-CNN（2014）——区域 + CNN

流程：选择性搜索（Selective Search）生成 ~2000 个候选框 → 每个框裁剪缩放后过 CNN 提特征 → SVM 分类 + 线性回归精修框。

- 缺点：2000 个框分别过 CNN，训练分多阶段、推理极慢（每图 ~50s）。

### 3.2 Fast R-CNN（2015）——共享卷积

改进：整张图**只过一次 CNN** 得到特征图；候选框通过 **ROI Pooling** 映射到特征图上，得到定长特征，再分类 + 回归。

- ROI Pooling：把任意大小的 ROI 区域切成 $h \times w$ 格子，每格最大池化，输出固定尺寸。
- 多任务损失合并训练，速度比 R-CNN 快 ~25 倍。

### 3.3 Faster R-CNN（2016）——RPN 网络

核心：用 **RPN（Region Proposal Network）** 替代选择性搜索，在特征图上直接预测候选框，并与检测网络**端到端联合训练**。

```
图像 → CNN 骨干（如 ResNet）→ 特征图
          ↓
     [RPN 分支]：在特征图上滑 3×3 卷积 → 对每个锚框输出
          ① objectness 得分（是否有目标）② 锚框修正量
          → 选出 ~300 个 proposal
          ↓
     [ROI 分支]：ROI Pooling → 分类 + 框回归
```

**RPN 与锚框**：特征图每个位置生成 $k$ 个**锚框（Anchor）**（不同尺度/长宽比），RPN 判断每个锚框是前景/背景并回归偏移。详见第 6 节。

### 3.4 Faster R-CNN 损失

两个分支各带损失，联合训练：

$$
\mathcal{L} = \underbrace{\mathcal{L}_{\text{cls}}}_{\text{RPN 分类}}
+ \underbrace{\mathcal{L}_{\text{reg}}}_{\text{RPN 回归}}
+ \underbrace{\mathcal{L}_{\text{cls}}'}_{\text{检测分类}}
+ \underbrace{\mathcal{L}_{\text{reg}}'}_{\text{检测回归}}
$$

## 4. 单阶段检测（One-Stage）

"**一步到位直接预测框和类别**"，速度快，适合实时（YOLO 的 y 就是 "You Only Look Once"）。

### 4.1 YOLO v1（2016）

把图像分成 $S \times S$ 网格，每个网格预测 $B$ 个框 + 每个框的置信度 + $C$ 类条件概率：

```
输出张量：S × S × (B×5 + C)
 5 = (x, y, w, h, confidence)
```

- 每个网格只负责中心点落在其内的目标。
- 缺点：小目标、密集目标检测差；框的坐标直接回归，不稳定。

### 4.2 SSD（2016）——多尺度

- 在**多个不同尺寸的特征图**上预测（浅层特征框小目标，深层特征框大目标）。
- 每个位置用多个预置的 Default Box（类似 Anchor）。
- 速度与精度平衡好，是多尺度思想的奠基作。

### 4.3 YOLO v2/v3（2017–2018）

- **v2（YOLO9000）**：引入 **Anchor**、BatchNorm、多尺度训练。
- **v3（2018）**：多尺度预测（FPN 思想）+ 特征金字塔 + Darknet-53 骨干。把"回归中心点"改为"相对锚框的偏移"，稳定训练。

### 4.4 YOLO v4–v8（2020–2023）

| 版本 | 关键改进 |
|------|----------|
| v4 | CSPDarknet、Mish、自对抗训练、CIoU 损失 |
| v5 | 工程化（易用）、AutoAnchor、超参数进化 |
| v6 | 无锚框（anchor-free）化、重参数化 |
| v7 | E-ELAN 高效聚合 |
| v8 | anchor-free + C2f 模块 + 解耦头，Ultralytics 生态 |

> 论文级细节（损失、训练技巧）见已有 [[../机器学习项目/YOLO.tex|YOLO 目标检测项目]]，本文不展开推导。

### 4.5 Anchor-free 与 Transformer

- **Anchor-free**（FCOS、CenterNet、YOLOv8）：直接预测"中心点 + 距离"，省去 Anchor 调参。
- **DETR（2020）**：Transformer + set prediction，把检测变成集合匹配问题（Hungarian 匹配），去掉 NMS 与 Anchor，是检测的大模型化起点（架构见 [[../深度学习教程/12-Transformer与大模型|Transformer]]）。

## 5. 损失函数

### 5.1 分类损失

用交叉熵（Faster R-CNN 两分支分别计算）：

$$
\mathcal{L}_{\text{cls}} = -\sum_{k} \big[ \mathbb{1}\{y_k = \text{前景}\} \log p_k + \mathbb{1}\{y_k = \text{背景}\} \log (1 - p_k) \big]
$$

单阶段模型常用 **Focal Loss** 缓解前景/背景不平衡：

$$
\mathcal{L}_{\text{FL}} = -\alpha_t (1 - p_t)^{\gamma} \log p_t
$$

$(1-p_t)^\gamma$ 项降低"已分对样本"的权重，让模型聚焦难例（RetinaNet 核心）。

### 5.2 回归损失

早期用 L1/L2，后来标准选择 **Smooth L1**：

$$
\text{Smooth}_{L_1}(x) = \begin{cases}
0.5 x^2 / \beta, & |x| < \beta \\
|x| - 0.5 \beta, & \text{otherwise}
\end{cases}
$$

- 小误差时用平方（梯度温和），大误差时用线性（对离群点鲁棒，梯度恒为 ±1）。

### 5.3 IoU 系列损失

Smooth L1 是"逐坐标独立优化"，不完全对应"框重叠得多好"。直接用 IoU 优化更好：

- **IoU 损失**：$\mathcal{L}_{\text{IoU}} = 1 - \text{IoU}$。但 IoU 无重叠时梯度为 0。
- **GIoU**：引入包含两框的最小外接矩形 $C$：

$$
\mathcal{L}_{\text{GIoU}} = 1 - \text{IoU} + \frac{|C \setminus (A \cup B)|}{|C|}
$$

- **CIoU**（YOLOv4+ 默认）：在 DIoU 基础上加**长宽比一致性**惩罚：

$$
\mathcal{L}_{\text{CIoU}} = 1 - \text{IoU} + \frac{\rho^2(\mathbf{b}, \mathbf{b}^{gt})}{c^2} + \alpha v
$$

$$
v = \frac{4}{\pi^2}\left(\arctan\frac{w^{gt}}{h^{gt}} - \arctan\frac{w}{h}\right)^2, \qquad
\alpha = \frac{v}{(1 - \text{IoU}) + v}
$$

其中 $\rho$ 是中心点欧氏距离，$c$ 是最小外接框对角线长。CIoU 同时惩罚**中心距离、重叠度、长宽比**，收敛更快更稳。

## 6. 锚框（Anchor）机制

### 6.1 什么是 Anchor

Anchor 是**预置在特征图每个位置的候选框模板**（不同尺度、长宽比），模型学的是"相对 Anchor 的修正量"而非绝对坐标：

```
特征图位置 (i, j) 生成 k 个 Anchor：
  尺度 s ∈ {32, 64, 128, 256, 512}
  长宽比 r ∈ {0.5, 1.0, 2.0}
  常见配置 k = 9 个锚框
```

### 6.2 为什么用 Anchor

- 目标尺度/长宽比千变万化，直接回归绝对坐标难收敛。
- 预置模板把搜索空间约束到"有意义的框形"附近，学习更容易、更稳。

### 6.3 参数化回归

预测偏移 $\mathbf{t} = (t_x, t_y, t_w, t_h)$ 相对 Anchor 编码：

$$
t_x = \frac{x - x_a}{w_a}, \qquad t_y = \frac{y - y_a}{h_a}, \qquad
t_w = \log\frac{w}{w_a}, \qquad t_h = \log\frac{h}{h_a}
$$

真实目标 $\mathbf{t}^*$ 同理用 GT 框计算，回归损失作用于 $\mathbf{t}$ 与 $\mathbf{t}^*$ 之差（$x_a, w_a$ 为 Anchor 中心与宽高）。

### 6.4 Anchor 的代价与替代

- 代价：超参多（尺度/比例需按数据集调）、正负样本不平衡、每个 Anchor 都算分类。
- 替代：**Anchor-free**（FCOS/YOLOv8 预测"到边界的距离"）、**DETR**（学习 object query 替代 Anchor）。

## 7. Python 实践

### 7.1 torchvision Faster R-CNN 推理

```python
# pip install torch torchvision
import torch
import torchvision
from torchvision import transforms
from PIL import Image

model = torchvision.models.detection.fasterrcnn_resnet50_fpn(
    weights=torchvision.models.detection.FasterRCNN_ResNet50_FPN_Weights.DEFAULT
)
model.eval()

img = Image.open("cat_and_dog.jpg").convert("RGB")
tensor = transforms.ToTensor()(img).unsqueeze(0)   # [1, 3, H, W]

with torch.no_grad():
    preds = model(tensor)[0]                        # dict: boxes/scores/labels

keep = preds["scores"] > 0.7                        # 置信度过滤
for box, score, label in zip(preds["boxes"][keep],
                             preds["scores"][keep],
                             preds["labels"][keep]):
    x1, y1, x2, y2 = [round(v, 1) for v in box.tolist()]
    print(f"{COCO_LABELS[label.item()]}: ({x1},{y1})-({x2},{y2}), conf={score:.2f}")
```

`COCO_LABELS` 可用 `weights.meta["categories"]` 获取（80 类）。Faster R-CNN 输出已含置信度与框，无需自己写 NMS。

### 7.3 numpy 计算 IoU 与 mAP

```python
import numpy as np

def iou(a, b):
    """a, b: [x1, y1, x2, y2]"""
    ix1, iy1 = max(a[0], b[0]), max(a[1], b[1])
    ix2, iy2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, ix2 - ix1) * max(0, iy2 - iy1)
    ua = (a[2]-a[0])*(a[3]-a[1]) + (b[2]-b[0])*(b[3]-b[1]) - inter
    return inter / ua

def compute_ap(preds, gts, iou_thr=0.5):
    # preds: list of (conf, box, cls)；gts: list of (box, cls)
    preds = sorted(preds, key=lambda p: -p[0])     # 按置信度降序
    tp, fp = [], []
    gt_used = set()
    for conf, box, cls in preds:
        matches = [(g, iou(box, g[0])) for i, g in enumerate(gts)
                   if g[1] == cls and iou(box, g[0]) >= iou_thr
                   and i not in gt_used]
        if matches:
            best = max(matches, key=lambda m: m[1])[0]
            gt_used.add(next(i for i, g in enumerate(gts) if g == best))
            tp.append(1); fp.append(0)
        else:
            tp.append(0); fp.append(1)
    tp = np.cumsum(tp); fp = np.cumsum(fp)
    prec = tp / np.maximum(tp + fp, 1e-8)
    rec  = tp / max(len(gts), 1)
    ap = np.sum(np.diff(np.append(0, rec)) * prec)   # 面积积分
    return ap, prec, rec
```

> 生产环境请直接用 pycocotools / Ultralytics 的评估，上面的 numpy 版用于理解原理。

## 8. 选型建议

| 场景 | 方案 |
|------|------|
| 实时（摄像头/移动端） | YOLOv8-n/s、YOLO-Tiny |
| 精度优先（学术/小目标） | Faster R-CNN、Cascade R-CNN |
| 密集小目标 | SSD/FPN 多尺度、anchor-free |
| 任意物体分割 | SAM（通用分割大模型） |
| 零样本/大模型 | DETR、Grounding DINO、SAM + CLIP |

**通用工作流**：先用 COCO 预训练模型跑通（7.1/7.2）→ 收集标注数据（LabelImg/CVAT）→ 微调 YOLO → 用 mAP@0.5:0.95 评估 → 部署（ONNX/TensorRT）。
