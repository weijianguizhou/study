# 自编码器与变分自编码器

> 前 12 章我们学习的所有模型都是**判别式**的：给定输入，输出标签或特征。本章开始进入**生成式**世界——让模型自己创造数据。自编码器（AE）是理解潜在空间的起点，而变分自编码器（VAE）则是第一个能"从噪声中生成新样本"的神经网络模型，也是后面 GAN、扩散模型的伏笔。

---

## 1. 为什么需要生成模型

### 1.1 从判别到生成

回顾 [[07-神经网络|神经网络]] 和 [[09-卷积神经网络CNN|CNN]]，我们做的是：

$$p(y \mid x) \quad \text{判别模型：条件概率，分类/回归}$$

而生成模型学习的是**数据本身的分布**：

$$p(x) \quad \text{生成模型：无条件概率，密度估计}$$

两者区别的直观理解：

- 判别模型像"考官"——给图像打标签（猫/狗）；
- 生成模型像"画家"——学会猫长什么样，然后凭空画出一只新的猫。

### 1.2 为什么生成模型重要

| 应用场景 | 为什么需要生成模型 |
|---------|------------------|
| 图像生成 | 画出不存在的照片（人脸、艺术画） |
| 数据增强 | 为训练集合成新样本，缓解数据稀缺 |
| 缺失数据补全 | 修复老照片、图像 inpainting |
| 表示学习 | 学到数据的高层抽象特征，可迁移到下游任务 |
| 密度估计 | 异常检测（低密度区域视为异常） |

### 1.3 三类主流生成模型

| 模型 | 思路 | 优点 | 缺点 |
|------|------|------|------|
| **VAE**（本章） | 隐变量 + 变分推断 | 训练稳定、有隐空间 | 生成样本偏模糊 |
| **GAN**（第14章） | 生成器与判别器博弈 | 样本清晰锐利 | 训练不稳定、模式坍缩 |
| **扩散模型**（第15章） | 逐步去噪 | 最稳定、质量最高 | 采样速度慢 |

## 2. 自编码器（Autoencoder, AE）

### 2.1 结构：编码器-解码器

自编码器由两部分组成：

- **编码器**（Encoder）：$f_\phi: \mathbb{R}^d \to \mathbb{R}^k$，把高维输入压缩成低维表示（潜在编码）；
- **解码器**（Decoder）：$g_\theta: \mathbb{R}^k \to \mathbb{R}^d$，把潜在编码还原回原始空间。

整体流程：$\hat{x} = g_\theta(f_\phi(x))$，目标是让 $\hat{x} \approx x$。

```
输入 x ──▶ 编码器 f_φ ──▶ 潜在编码 z ──▶ 解码器 g_θ ──▶ 重建 x̂
        (压缩, 提取特征)    (k 维向量)      (解压, 还原)
```

### 2.2 重构损失

AE 通过最小化**重构误差**训练，最常用的是均方误差（MSE）：

$$
\mathcal{L}(\phi, \theta) = \mathbb{E}_{x \sim p_{\text{data}}} \left[ \| x - g_\theta(f_\phi(x)) \|_2^2 \right]
$$

对于像素值在 $[0,1]$ 的图像，也可以使用二值交叉熵（等价于把输出当作伯努利分布的均值参数）：

$$
\mathcal{L} = -\mathbb{E}_x \left[ x \log \hat{x} + (1-x) \log(1-\hat{x}) \right]
$$

**为什么重建任务能学到特征？** 因为 $k \ll d$ 时，网络必须"丢"掉冗余信息、只保留最本质的结构。被保留下来的一定是对数据最有判别力的方向——这就是潜在空间的含义。

### 2.3 欠完备与过完备

| 类型 | 条件 | 效果 |
|------|------|------|
| **欠完备**（Undercomplete） | $k < d$ | 强制压缩，学到主要结构；这是最常用配置 |
| **过完备**（Overcomplete） | $k \geq d$ | 潜在维度大于输入，模型可能退化为恒等映射（复制粘贴），学不到有意义特征 |

对于过完备 AE，必须引入正则化（稀疏、去噪等）才有意义。

### 2.4 正则化变体

**稀疏自编码器（Sparse AE）**：在重构损失上加入对隐单元激活的稀疏性惩罚（L1 正则或 KL 散度约束）：

$$
\mathcal{L} = \|x - \hat{x}\|^2 + \lambda \sum_j \left| h_j(x) \right| \quad \text{或} \quad \lambda \sum_j KL\left(\rho \,\|\, \hat{\rho}_j\right)
$$

其中 $\hat{\rho}_j$ 是第 $j$ 个隐单元的平均激活率，$\rho$ 是期望的稀疏水平（如 0.05）。稀疏约束使每个隐单元只对特定的输入模式响应，从而学到**过完备且有意义**的特征（类似生物神经元的稀疏编码）。

**去噪自编码器（Denoising AE, DAE）**：对输入加噪 $\tilde{x} = x + \epsilon$，再要求网络重建干净的 $x$：

$$
\mathcal{L} = \mathbb{E}_{x, \epsilon} \left[ \| x - g_\theta(f_\phi(\tilde{x})) \|^2 \right]
$$

DAE 被迫学会**鲁棒特征**：即使部分像素被噪声破坏，也能根据全局结构推断出原始内容。这赋予了潜在表示很强的抗噪能力，也是 Masked Autoencoder（MAE，BERT 在视觉中的翻版，见 [[12-Transformer与大模型|Transformer]]）的思想源头。

### 2.5 AE 与 PCA 的关系

经典的线性 AE（无激活函数、单隐层）在 MSE 损失下，学到的正是 **PCA 的主子空间**！详见 [[../机器学习教程/07-降维|降维]]。

| 对比项 | PCA | 线性 AE |
|--------|-----|---------|
| 数学原理 | 协方差矩阵特征分解 / SVD | 梯度下降最小化重构误差 |
| 潜在方向 | 正交、按方差排序 | 不一定正交 |
| 非线性 | 否（线性变换） | 加激活函数后为非线性 |
| 学习方式 | 闭式解 | 数据驱动、可在线学习 |
| 深层 | 无 | 可堆叠成深度网络 |

关键结论：**深度非线性 AE 是 PCA 的泛化**。PCA 只能捕捉线性流形，而深层 AE 可以展开"卷曲"的非线性流形，因此对图像等复杂数据压缩能力远强于 PCA。

### 2.6 潜在空间的几何理解

训练好的 AE，其编码器把高维数据"摊平"到低维潜在空间：

- 每个数据点 $x$ 对应潜在空间中的一个点 $z = f_\phi(x)$；
- 语义相近的数据在潜在空间中距离近（数字 3 和 8 相邻，1 和 7 相邻）；
- 潜在空间的某些方向对应着数据的某个**可解释属性**（比如笔画粗细、倾斜角度）。

这本质上是学习数据分布所在的**流形**（manifold）：真实数据虽然生活在高维像素空间，但真实的有效自由度远小于像素维度，AE 学到的就是这张"低维流形地图"。

### 2.7 AE 的致命缺陷：潜在空间不连续

AE 的编码器只定义了**从数据到潜在点的映射**，它从未"见过"潜在空间中空白区域长什么样。这带来两个问题：

1. **潜在空间不连续**：两个簇之间可能有巨大的空洞。若在这些空洞处解码，输出往往是毫无意义的噪声图像。
2. **无法生成新样本**：想生成新图像，需要先从潜在空间采样一个 $z$，但 AE 不知道"哪些 $z$ 对应合法图像"——它没有对潜在空间的概率建模。

**一句话总结：AE 是"压缩器"，不是"生成器"。** 它只会压缩/还原已有的数据，而无法创造新数据。这正是 VAE 要解决的。

## 3. AE 的 PyTorch 实现（MNIST）

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
torch.manual_seed(42)

# ========== 数据加载 ==========
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,)),
])
train_data = datasets.MNIST(root='./data', train=True, download=True,
                            transform=transform)
train_loader = DataLoader(train_data, batch_size=128, shuffle=True)

# ========== 自编码器模型 ==========
class Autoencoder(nn.Module):
    def __init__(self, input_dim=784, latent_dim=32):
        super().__init__()
        # 编码器: 784 -> 256 -> 128 -> latent
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
            nn.Linear(128, latent_dim),
        )
        # 解码器: latent -> 128 -> 256 -> 784
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 128), nn.ReLU(),
            nn.Linear(128, 256), nn.ReLU(),
            nn.Linear(256, input_dim),
        )

    def forward(self, x):
        z = self.encoder(x)
        return self.decoder(z), z

model = Autoencoder().to(device)
optimizer = optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.MSELoss()

# ========== 训练 ==========
EPOCHS = 10
for epoch in range(EPOCHS):
    total_loss = 0.0
    for x, _ in train_loader:
        x = x.view(x.size(0), -1).to(device)
        x_hat, _ = model(x)
        loss = criterion(x_hat, x)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * x.size(0)
    print(f'Epoch {epoch+1:3d} | 重构损失: {total_loss/len(train_loader.dataset):.4f}')

# ========== 可视化重构结果 ==========
model.eval()
with torch.no_grad():
    x, _ = next(iter(train_loader))
    x = x[:10].view(-1, 784).to(device)
    x_hat, z = model(x)

fig, axes = plt.subplots(2, 10, figsize=(16, 3.2))
for i in range(10):
    axes[0, i].imshow(x[i].view(28, 28).cpu().numpy(), cmap='gray')
    axes[0, i].axis('off')
    axes[1, i].imshow(x_hat[i].view(28, 28).cpu().numpy(), cmap='gray')
    axes[1, i].axis('off')
axes[0, 0].set_title('原始图像')
axes[1, 0].set_title('AE 重构')
plt.tight_layout()
plt.show()
```

运行上面的代码可以看到：AE 能近乎完美地重建训练过的数字，但你无法从中"发明"一个数字——因为潜在空间没有被概率化。

## 4. 变分自编码器（VAE）

VAE（Kingma & Welling, 2013）在 AE 的基础上加入**概率建模**，让潜在空间连续、可采样，从而成为一个真正的生成模型。

### 4.1 概率视角

假设数据由潜在变量 $z$ 生成：

1. 从先验分布采样潜在变量：$z \sim p(z)$（通常取标准正态 $\mathcal{N}(0, I)$）；
2. 从条件分布生成数据：$x \sim p_\theta(x \mid z)$。

联合分布 $p_\theta(x, z) = p_\theta(x \mid z)p(z)$。我们希望学习参数 $\theta$，使模型生成的数据分布 $p_\theta(x)$ 尽量接近真实分布 $p_{\text{data}}(x)$，即最大化**边际似然**：

$$
\max_\theta \; \mathbb{E}_{x \sim p_{\text{data}}} \left[ \log p_\theta(x) \right], \qquad p_\theta(x) = \int p_\theta(x \mid z) \, p(z) \, dz
$$

### 4.2 两个棘手问题

- **后验不可解**：贝叶斯定理告诉我们后验 $p_\theta(z \mid x) = \dfrac{p_\theta(x\mid z)p(z)}{p_\theta(x)}$，但分母 $p_\theta(x)$ 需要对高维 $z$ 积分，无法解析计算；
- **先验采样效率极低**：如果直接对 $z \sim p(z)$ 采样再算 $p_\theta(x\mid z)$，绝大部分样本与 $x$ 无关，方差爆炸。

### 4.3 ELBO 推导（本章核心推导）

**思路：用一个可解的后验分布 $q_\phi(z \mid x)$ 去逼近不可解的真后验 $p_\theta(z \mid x)$。**

从对数边际似然出发：

$$
\log p_\theta(x) = \log \int_z p_\theta(x, z) \, dz
$$

引入 $q_\phi(z \mid x)$，乘除凑项：

$$
\log p_\theta(x) = \log \int_z q_\phi(z\mid x) \frac{p_\theta(x, z)}{q_\phi(z\mid x)} \, dz
$$

利用 **Jensen 不等式**（对数凹函数：$\log \mathbb{E}[y] \geq \mathbb{E}[\log y]$）：

$$
\log p_\theta(x) \geq \int_z q_\phi(z\mid x) \log \frac{p_\theta(x, z)}{q_\phi(z\mid x)} \, dz
= \mathbb{E}_{q_\phi(z\mid x)}\left[ \log \frac{p_\theta(x, z)}{q_\phi(z\mid x)} \right]
$$

右侧即 **ELBO（Evidence Lower Bound，证据下界）**。把联合分布拆开 $p_\theta(x,z) = p_\theta(x\mid z)p(z)$：

$$
\boxed{\;\text{ELBO}(\theta, \phi; x)
= \mathbb{E}_{q_\phi(z\mid x)}\left[ \log p_\theta(x \mid z) \right]
- KL\!\left( q_\phi(z \mid x) \,\|\, p(z) \right)\;}
$$

**ELBO 就是我们要最大化的目标**。它由两项组成：

1. **重构项**：$\mathbb{E}_{q}[\log p_\theta(x\mid z)]$——解码器从 $z$ 重建 $x$ 的对数似然（越大越好）；
2. **正则项**：$KL(q_\phi(z\mid x) \| p(z))$——编码器输出的后验与先验（标准正态）的差距（越小越好，防止后验偏离先验）。

**ELBO 与真后验的缺口**：

$$
\log p_\theta(x) - \text{ELBO} = KL\!\left( q_\phi(z\mid x) \,\|\, p_\theta(z\mid x) \right) \geq 0
$$

所以最大化 ELBO 等价于同时：逼近真后验（减小 KL 缺口）＋ 逼近真分布（增大证据）。

### 4.4 优化目标

由于我们最小化损失，把最大化 ELBO 写成最小化负 ELBO：

$$
\boxed{\;\mathcal{L}_{\text{VAE}} = -\mathbb{E}_{q_\phi(z\mid x)}\left[ \log p_\theta(x \mid z) \right]
+ KL\!\left( q_\phi(z \mid x) \,\|\, p(z) \right)\;}
$$

### 4.5 重参数化技巧（Reparameterization Trick）

问题：$\mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)]$ 的梯度要穿过随机采样操作。但"从 $q_\phi(z|x)$ 采样 $z$"这一步是**不可导**的——梯度无法通过随机采样回传到 $\phi$。

**解决办法：把随机性从参数中"剥离"出来。**

$$
\boxed{\;z = \mu_\phi(x) + \sigma_\phi(x) \odot \varepsilon, \qquad \varepsilon \sim \mathcal{N}(0, I)\;}
$$

其中 $\odot$ 为逐元素乘，$\mu_\phi(x)$、$\sigma_\phi(x)$ 是编码器输出的均值与标准差。这样 $z$ 的随机性全部来自与参数无关的标准正态噪声 $\varepsilon$，梯度可以正常地沿 $\mu_\phi$、$\sigma_\phi$ 回传。

```
不可导路径:  z ~ q_φ(z|x)          → 梯度断掉
可导路径:    z = μ_φ(x) + σ_φ(x)·ε   → 梯度穿过 μ_φ, σ_φ，ε 视为常数
```

### 4.6 KL 项的闭式解

当先验 $p(z)=\mathcal{N}(0, I)$、后验 $q_\phi(z|x)=\mathcal{N}(\mu, \text{diag}(\sigma^2))$ 都是高斯时，KL 散度有解析解（推导用到多元高斯 KL 公式，见 [[03-数学基础-概率与统计|概率与统计]]）：

$$
KL\!\left(\mathcal{N}(\mu, \sigma^2) \,\|\, \mathcal{N}(0, 1)\right)
= \frac{1}{2} \sum_{j=1}^{J} \left( \mu_j^2 + \sigma_j^2 - 1 - \log \sigma_j^2 \right)
$$

用 $ \log\sigma^2 $ 记作 logvar：

$$
KL = \frac{1}{2} \sum_{j=1}^{J} \left( \mu_j^2 + e^{\text{logvar}_j} - 1 - \text{logvar}_j \right)
$$

**直觉**：当编码器输出 $\mu \to 0$、$\sigma \to 1$ 时，后验趋近标准正态，KL 项趋于 0——这意味着潜在变量不再与具体输入绑定，分布被"摊平"到先验上。这也解释了为什么 KL 项能让潜在空间连续、无空洞。

### 4.7 完整损失函数

把重构项实例化（输出为伯努利/MSE）并加上 KL 项：

$$
\mathcal{L}_{\text{VAE}}(x)
= \underbrace{\left\| x - g_\theta(z) \right\|^2}_{\text{重构误差}}
+ \underbrace{\frac{1}{2} \sum_{j=1}^{J} \left( \mu_j^2 + e^{\text{logvar}_j} - 1 - \text{logvar}_j \right)}_{\text{KL 正则项}}
$$

### 4.8 β-VAE

β-VAE（Higgins et al., 2017）给 KL 项加权重 $\beta > 1$：

$$
\mathcal{L}_{\beta\text{-VAE}} = -\mathbb{E}_{q}[\log p_\theta(x\mid z)] + \beta \cdot KL(q_\phi(z\mid x)\|p(z))
$$

**效果**：更强的 KL 约束迫使潜在维度更加**解耦**（disentangled）——每个维度独立编码一个可解释属性（如旋转、粗细、形状）。代价是重构质量下降（$\beta$ 越大重构越模糊）。这是可控生成与表示学习的重要工具。

## 5. VAE vs AE 对比表

| 对比维度 | AE | VAE |
|---------|----|-----|
| 潜在表示 | 确定性点 $z = f(x)$ | 概率分布 $z \sim q_\phi(z\mid x)$ |
| 潜在空间 | 不连续、有空洞 | 连续、被"摊平"到先验 |
| 能否生成新样本 | 否 | 是（从 $p(z)$ 采样再解码） |
| 损失函数 | 重构损失 | 重构损失 + KL 正则 |
| 潜在空间约束 | 无（可能恒等映射） | 正则化到 $\mathcal{N}(0,I)$ |
| 训练稳定性 | 稳定 | 稳定（无对抗） |
| 生成质量 | 高（但只能重建） | 偏低（模糊），可加 VQ-VAE 等改进 |
| 数学基础 | 压缩 | 变分推断、ELBO |

## 6. MNIST VAE 完整实现

### 6.1 模型定义

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt
import numpy as np

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
torch.manual_seed(42)

class VAE(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=400, latent_dim=20):
        super().__init__()
        self.latent_dim = latent_dim

        # 编码器: 输入 -> 隐层 -> (μ, log σ²)
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.ReLU(),
        )
        self.mu_layer = nn.Linear(hidden_dim, latent_dim)
        self.logvar_layer = nn.Linear(hidden_dim, latent_dim)

        # 解码器: 潜在变量 -> 隐层 -> 输入
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, input_dim), nn.Sigmoid(),
        )

    def encode(self, x):
        h = self.encoder(x)
        return self.mu_layer(h), self.logvar_layer(h)

    def reparameterize(self, mu, logvar):
        """重参数化技巧: z = μ + σ·ε, ε ~ N(0, I)"""
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decoder(z), mu, logvar, z

    def loss(self, x):
        """VAE 损失 = 重构项 + KL 项（闭式解）"""
        recon_x, mu, logvar, _ = self.forward(x)
        # 重构项: 二值交叉熵（逐元素，再对 batch 求和）
        recon_loss = F.binary_cross_entropy(recon_x, x, reduction='sum')
        # KL 项: 0.5 * Σ(μ² + e^logvar - 1 - logvar)
        kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
        return recon_loss + kl_loss, recon_loss, kl_loss
```

### 6.2 训练循环

```python
transform = transforms.ToTensor()
train_data = datasets.MNIST(root='./data', train=True, download=True,
                            transform=transform)
train_loader = DataLoader(train_data, batch_size=128, shuffle=True)

model = VAE(latent_dim=20).to(device)
optimizer = optim.Adam(model.parameters(), lr=1e-3)

history = []
for epoch in range(15):
    total_recon, total_kl = 0.0, 0.0
    for x, _ in train_loader:
        x = x.view(x.size(0), -1).to(device)
        loss, recon, kl = model.loss(x)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        total_recon += recon.item()
        total_kl += kl.item()
    n = len(train_loader.dataset)
    history.append((total_recon / n, total_kl / n))
    print(f'Epoch {epoch+1:3d} | 重构: {total_recon/n:.4f} | '
          f'KL: {total_kl/n:.4f} | 总损失: {(total_recon+total_kl)/n:.4f}')

# 损失曲线
plt.figure(figsize=(8, 4))
plt.plot([h[0] for h in history], label='重构损失', linewidth=2)
plt.plot([h[1] for h in history], label='KL 损失', linewidth=2)
plt.xlabel('Epoch'); plt.ylabel('Loss'); plt.legend(); plt.grid(alpha=0.3)
plt.title('VAE 训练曲线')
plt.show()
```

def generate_digits(model, n=16, latent_dim=20):

# ========== 潜在空间插值（两个数字之间渐变） ==========
def interpolate(model, z1, z2, steps=10):
    alphas = torch.linspace(0, 1, steps).unsqueeze(1)
    z = (1 - alphas) * z1 + alphas * z2
    with torch.no_grad():
        imgs = model.decoder(z.to(device)).cpu()
    return imgs.view(steps, 28, 28)

- 两个数字编码之间线性插值，图像平滑渐变——说明潜在空间**连续且有结构**。

## 7. VAE 常见问题与技巧

### 7.1 后验坍缩（Posterior Collapse）

在强解码器（如 Transformer/LSTM 解码器）下，KL 项会趋于 0，编码器退化为先验 $\mathcal{N}(0,I)$，潜在变量被忽略——模型退化成纯自回归解码器。

**缓解手段**：
- KL 退火（训练初期 $\beta$ 从 0 缓慢增大）；
- 对 KL 项设置下界（free bits）；
- 限制解码器容量，迫使它依赖 $z$。

### 7.2 生成样本模糊

VAE 用均方/交叉熵做重构，天然鼓励"平均化"的输出——把所有可能结果的均值画出来，自然模糊。

**改进方向**：
- VQ-VAE（离散潜在变量 + 自回归先验）；
- VAE-GAN（解码器换成判别器驱动的损失）；
- NVAE（层次化潜在变量）。

### 7.3 训练技巧

| 技巧 | 说明 |
|------|------|
| $\beta$ 退火 | 先只训练重构，再逐步加 KL 权重 |
| 梯度裁剪 | 防止早期 KL 梯度爆炸 |
| 标准化输入 | 输入归一到 $[0,1]$，配合 Sigmoid 输出 |
| 潜在维度选择 | 常用 2~50；过小丢信息、过大 KL 主导 |
| 用 ELBO 监控 | 训练时同时观察重构项与 KL 项的变化 |

## 8. 评估指标

| 指标 | 度量什么 | 如何计算 |
|------|---------|---------|
| **重构误差** | AE/VAE 重建质量 | $\|x - \hat{x}\|^2$，越小越好 |
| **ELBO** | 生成质量上界 | $E_q[\log p(x\mid z)] - KL$，越大越好 |
| **边际对数似然 $\log p(x)$** | 真生成质量 | 重要性采样估计：$\log \frac{1}{K}\sum_k \frac{p(x, z_k)}{q(z_k\mid x)}$ |
| **隐空间指标** | 可解释性/解耦 | β-VAE metric、factorVAE metric |

（FID、IS 等基于特征的指标在 [[14-生成对抗网络GAN|GAN]]、[[15-扩散模型|扩散模型]] 章节详细展开。）

## 9. 小结：从 AE 到 VAE

```
AE:     x →(编码)→ z →(解码)→ x̂         压缩，不能生成
VAE:    x →(编码)→ N(μ,σ²) → 采样z → x̂  压缩 + 生成
        z ~ N(0,I) → 解码 → 新样本        连续潜在空间
```

- AE 是理解潜在空间的起点，问题在于潜在空间不连续、无法生成；
- VAE 引入变分推断与 ELBO，把潜在空间概率化，成为真正的生成模型；
- VAE 训练稳定、有可解释隐空间，但样本偏模糊；
- VAE 的重参数化技巧、KL 正则思想，将在扩散模型的 ELBO 推导中再次登场。
