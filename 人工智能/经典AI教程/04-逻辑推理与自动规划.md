# 逻辑推理与自动规划（Logic Reasoning & Automated Planning）

> 符号逻辑是经典 AI 的"语法"，自动规划是符号逻辑的"工程化应用"。从命题逻辑、一阶谓词逻辑，到归结原理与 STRIPS 规划，这一支构成了"符号主义 AI"的推理与规划引擎。今天的大模型虽以联结主义为主，但思维链（CoT）与 AI Agent 的"规划—执行"循环，处处回响着逻辑推理的影子。

## 命题逻辑（Propositional Logic）

**命题**（Proposition）是可判定真假的陈述句，用符号 $P, Q, R$ 表示。命题逻辑只研究命题之间的真值关系。

### 逻辑连接词

| 连接词 | 符号 | 读法 | 真值规则 |
|--------|------|------|----------|
| 合取 | $P \land Q$ | 且 | 两者均真才真 |
| 析取 | $P \lor Q$ | 或 | 至少一个真 |
| 否定 | $\neg P$ | 非 | 取反 |
| 蕴含 | $P \to Q$ | 如果…则… | 仅 $P$ 真 $Q$ 假时为假 |
| 等价 | $P \leftrightarrow Q$ | 当且仅当 | 同真同假 |

### 真值表

$P \to Q$ 的真值表（注意蕴含的"空真"：前提为假时整个蕴含为真）：

| $P$ | $Q$ | $P \land Q$ | $P \lor Q$ | $P \to Q$ | $P \leftrightarrow Q$ |
|-----|-----|-------------|------------|-----------|------------------------|
| T | T | T | T | T | T |
| T | F | F | T | F | F |
| F | T | F | T | T | F |
| F | F | F | F | T | T |

### 常用等价式（永真等价）

$$
P \to Q \equiv \neg P \lor Q
$$

$$
P \leftrightarrow Q \equiv (P \to Q) \land (Q \to P)
$$

$$
\neg(P \land Q) \equiv \neg P \lor \neg Q \quad (\text{德摩根})
$$

$$
\neg(P \lor Q) \equiv \neg P \land \neg Q \quad (\text{德摩根})
$$

$$
P \to Q \equiv \neg Q \to \neg P \quad (\text{逆否命题})
$$

**合取范式（CNF）**：用 $\land$ 连接若干"子句（clause）"，每个子句是文字（$L$ 或 $\neg L$）的析取，是归结推理的标准输入形式：

$$
(P \lor Q) \land (\neg P \lor R) \land (Q \lor R)
$$

## 一阶谓词逻辑（First-Order Logic, FOL）

在命题逻辑之上增加**谓词**、**量词**、**项**与**函数**，表达能力大幅提升。

### 基本要素

| 要素 | 例子 | 说明 |
|------|------|------|
| 常量 | `张三`, `北京` | 指称具体对象 |
| 变量 | $x, y$ | 泛指对象 |
| 函数 | `父亲(张三)`, `Plus(x,1)` | 对象到对象的映射 |
| 谓词 | `老师(张三)`, `父(X,Y)` | 对象之间的性质或关系 |
| 全称量词 | $\forall x$ | "对所有 x" |
| 存在量词 | $\exists x$ | "存在 x" |

### 量词规则

$$
\neg \forall x \, P(x) \equiv \exists x \, \neg P(x)
$$

$$
\neg \exists x \, P(x) \equiv \forall x \, \neg P(x)
$$

$$
\forall x (P \land Q) \equiv \forall x P \land \forall x Q
$$

$$
\exists x (P \lor Q) \equiv \exists x P \lor \exists x Q
$$

**注意**：全称量词不分配析取，存在量词不分配合取。

### 一阶逻辑表述示例

- "所有人都会死"：$\forall x\, \big(\text{人}(x) \to \text{会死}(x)\big)$
- "有些鸟不会飞"：$\exists x\, \big(\text{鸟}(x) \land \neg \text{会飞}(x)\big)$
- "每个学生都有一个老师"：$\forall x\, \big(\text{学生}(x) \to \exists y\, \big(\text{老师}(y) \land \text{教}(y, x)\big)\big)$

## 推理规则与归结原理

### 基本推理规则

**假言推理（Modus Ponens）**：

$$
\frac{P \quad P \to Q}{Q}
$$

**拒取式（Modus Tollens）**：

$$
\frac{\neg Q \quad P \to Q}{\neg P}
$$

**三段论（Hypothetical Syllogism）**：

$$
\frac{P \to Q \quad Q \to R}{P \to R}
$$

### 合一（Unification）

合一就是把两个原子公式通过变量代换变得相同。代换 $\sigma$ 把变量替换为项，如：

$$
\text{子句1: } \text{父}(x, \text{张三}) \qquad \text{子句2: } \neg \text{父}(\text{李四}, y)
$$

代换 $\sigma = \{ x/\text{李四},\; y/\text{张三} \}$ 后两个互补文字相同，可归结。

最一般合一子（MGU）是约束最少的代换，保证归结不丢失信息。

### 归结原理（Resolution）

归结是一阶逻辑的**完备**推理规则。对两个子句，找出互补文字（$L$ 与 $\neg L$）并消去：

$$
\frac{C_1 \lor L \qquad C_2 \lor \neg L}{C_1 \lor C_2}
$$

例：子句 $(P \lor Q)$ 与 $(\neg P \lor R)$ 归结得 $(Q \lor R)$。

### 归结反驳证明（Resolution Refutation）

要证明 $\Gamma \vdash \alpha$，做法：

1. 把 $\Gamma \cup \{\neg \alpha\}$ 全部转化为 CNF（子句集）。
2. **斯柯伦化（Skolemization）**：消除存在量词（用斯柯伦函数/常量替换），只保留全称量词。
3. 反复应用归结规则产生新子句。
4. 若归结出**空子句 $\square$**（矛盾），则证明成立：$\Gamma \vdash \alpha$。

**完整例子**——证明"苏格拉底会死"：

知识库（KB）：
1. 所有人都会死：$\forall x\, \big(\text{人}(x) \to \text{会死}(x)\big)$
2. 苏格拉底是人：$\text{人}(\text{苏格拉底})$

目标：$\text{会死}(\text{苏格拉底})$

| 步骤 | 子句 | 说明 |
|------|------|------|
| 1 | $\neg \text{人}(x) \lor \text{会死}(x)$ | KB 规则转 CNF |
| 2 | $\text{人}(\text{苏格拉底})$ | KB 事实 |
| 3 | $\neg \text{会死}(\text{苏格拉底})$ | 目标取反 |
| 4 | $\neg \text{人}(\text{苏格拉底})$ | 由 1、3 归结：$x/\text{苏格拉底}$ |
| 5 | $\square$ | 由 2、4 归结 → 矛盾 |

得证：苏格拉底会死。

## 自动规划（Automated Planning）

### 规划问题定义

一个规划问题 $P = (S, s_0, G, A)$：

- $S$：状态集合（用一阶逻辑文字集合表示）；
- $s_0$：初始状态；
- $G$：目标（一集要成立的文字）；
- $A$：动作集合，每个动作有**前提（precondition）**与**效果（effect）**。

规划器输出一个**动作序列**（plan），使从 $s_0$ 出发执行后达到 $G$。

### STRIPS 表示

**STRIPS**（Stanford Research Institute Problem Solver, 1971）动作表示：

$$
\text{动作 act}(p_1, \dots, p_k): \quad \text{前提: } pre; \quad \text{删除: } del; \quad \text{添加: } add
$$

执行语义：前提 $pre$ 都成立才能执行；执行后删除 $del$ 中文字、添加 $add$ 中文字。

例（积木世界"拿起"动作）：

```
Action(PickUp(x)):
    pre:  Clear(x), On(x, Table), HandEmpty
    del:  On(x, Table), Clear(x), HandEmpty
    add:  Holding(x)
```

### 规划搜索策略

| 策略 | 思想 | 特点 |
|------|------|------|
| 前向搜索（Progression） | 从 $s_0$ 沿动作效果前进 | 直观，但分支因子大、目标无关动作多 |
| 后向搜索（Regression） | 从目标反向找前提 | 更聚焦目标，但需目标相关推理 |
| 部分有序规划（POP） | 逐步约束动作间的**偏序关系**而非固定序列 | 动作可并行，适合复杂任务分解 |
| 图规划（GraphPlan） | 用"规划图"并行推进 | 结合前向/后向，可并行动作 |

### 经典问题：积木世界（Blocks World）

状态用谓词表示：`On(A,B)`、`Clear(C)`、`OnTable(C)`、`HandEmpty`。

```
目标: On(A, B) ∧ On(B, C)

初始:          目标:
  A               A
  B               B
  C               C
  ____            ____
  桌子            桌子
```

规划序列：`PickUp(A)` → `Stack(A,B)` → `PickUp(B)`…（实际需小心前提顺序）。

### 经典问题：八数码（滑动谜题）

目标测试是"数字按序排列"，动作是"空格向 4 个方向移动"，代价统一。可用 A*（曼哈顿启发）或 STRIPS 式状态转移求解。

## Python 实现一：STRIPS 积木世界规划器（前向搜索 + BFS）

```python
"""
STRIPS 积木世界：前向搜索规划器（BFS 保证最短动作序列）
运行：python blocksworld.py
"""
from collections import deque
from dataclasses import dataclass
from typing import Dict, FrozenSet, List, Set, Tuple


@dataclass(frozen=True)
class Action:
    """STRIPS 动作：前提/删除/添加都是文字集合"""
    name: str
    pre: FrozenSet[str]
    del_eff: FrozenSet[str]
    add_eff: FrozenSet[str]


def can_apply(state: frozenset, act: Action) -> bool:
    return act.pre.issubset(state)


def apply_action(state: frozenset, act: Action) -> frozenset:
    return (state - act.del_eff) | act.add_eff


def make_actions() -> List[Action]:
    """积木世界：A/B/C 三块积木的典型动作"""
    blocks = ["A", "B", "C"]
    acts: List[Action] = []
    # PickUp(x): 从桌上拿起
    for x in blocks:
        acts.append(Action(
            f"PickUp({x})",
            frozenset({f"Clear({x})", f"OnTable({x})", "HandEmpty"}),
            frozenset({f"OnTable({x})", f"Clear({x})", "HandEmpty"}),
            frozenset({f"Holding({x})"}),
        ))
    # PutDown(x): 放回桌上
    for x in blocks:
        acts.append(Action(
            f"PutDown({x})",
            frozenset({f"Holding({x})"}),
            frozenset({f"Holding({x})"}),
            frozenset({f"OnTable({x})", f"Clear({x})", "HandEmpty"}),
        ))
    # Stack(x, y): x 放到 y 上
    for x in blocks:
        for y in blocks:
            if x == y:
                continue
            acts.append(Action(
                f"Stack({x},{y})",
                frozenset({f"Holding({x})", f"Clear({y})"}),
                frozenset({f"Holding({x})", f"Clear({y})"}),
                frozenset({f"On({x},{y})", f"Clear({x})", "HandEmpty"}),
            ))
    # UnStack(x, y): 从 y 上取下 x
    for x in blocks:
        for y in blocks:
            if x == y:
                continue
            acts.append(Action(
                f"UnStack({x},{y})",
                frozenset({f"On({x},{y})", f"Clear({x})", "HandEmpty"}),
                frozenset({f"On({x},{y})", f"Clear({x})", "HandEmpty"}),
                frozenset({f"Holding({x})", f"Clear({y})"}),
            ))
    return acts


def bfs_plan(start: frozenset, goal: frozenset, actions: List[Action]):
    """BFS 前向搜索规划：返回最短动作序列"""
    queue = deque([(start, [])])
    visited = {start}
    while queue:
        state, plan = queue.popleft()
        if goal.issubset(state):
            return plan
        for act in actions:
            if can_apply(state, act):
                nxt = apply_action(state, act)
                if nxt not in visited:
                    visited.add(nxt)
                    queue.append((nxt, plan + [act.name]))
    return None


if __name__ == "__main__":
    # 初始：A 在桌上，B 在 A 上，C 在 B 上；目标是 B 在 C 上、A 在 B 上
    start = frozenset({"OnTable(C)", "On(C,B)", "On(B,A)", "OnTable(A)",
                       "Clear(C)", "HandEmpty"})
    goal = frozenset({"On(B,C)", "On(A,B)", "OnTable(C)", "Clear(A)",
                      "Clear(A)", "HandEmpty"})
    plan = bfs_plan(start, goal, make_actions())
    print("=== STRIPS 积木世界规划（BFS） ===")
    print("目标:", sorted(goal))
    print("规划方案:", plan if plan else "未找到")

    print("\n=== 可视化建议 ===")
    print("1) 用 matplotlib 画 3 列积木的堆叠图，逐帧展示动作序列")
    print("2) 用 graphviz 画规划树（state -> action -> state）")
    print("3) 换目标测试启发式（如 A* with 启发：放错位置的积木数）")
```

## Python 实现二：简单一阶逻辑推理器（Horn 子句 + 前向链接）

```python
"""
一阶逻辑推理器：Horn 子句（规则/事实）+ 前向链（Forward Chaining）
适用于类似 Prolog 的规则集。运行：python fol_inference.py
"""
from collections import deque
from typing import Dict, List, Tuple


# 变量：小写开头；常量：大写开头或引号字符串
def is_var(term: str) -> bool:
    return term and term[0].islower()


def unify(t1: str, t2: str, theta: Dict[str, str] = None) -> Dict[str, str] | None:
    """合一：返回使 t1、t2 相等的代换，失败返回 None"""
    theta = dict(theta or {})
    t1, t2 = theta.get(t1, t1), theta.get(t2, t2)
    if t1 == t2:
        return theta
    if is_var(t1):
        theta[t1] = t2
        return theta
    if is_var(t2):
        theta[t2] = t1
        return theta
    return None


class FOLReasoner:
    """基于规则的事实库推理：RULES = [(前提列表, 结论)]"""

    def __init__(self):
        self.facts: List[str] = []
        self.rules: List[Tuple[List[str], str]] = []

    def add_fact(self, fact: str):
        self.facts.append(fact)

    def add_rule(self, premises: List[str], conclusion: str):
        self.rules.append((premises, conclusion))

    def forward_chain(self, max_iter=50) -> List[str]:
        derived = list(self.facts)
        for _ in range(max_iter):
            changed = False
            for premises, conclusion in self.rules:
                new_facts = self._apply(premises, conclusion, derived)
                for f in new_facts:
                    if f not in derived:
                        derived.append(f)
                        changed = True
            if not changed:
                break
        return derived

    def _apply(self, premises, conclusion, derived):
        """尝试所有代换，使所有前提都被满足"""
        results = []
        self._backtrack(premises, conclusion, derived, {}, results, 0)
        return results

    def _backtrack(self, premises, conclusion, derived, theta, results, idx):
        if idx == len(premises):
            c = self._substitute(conclusion, theta)
            if c not in results:
                results.append(c)
            return
        p = premises[idx]
        for fact in derived:
            if self._match_pattern(p, fact, theta):
                self._backtrack(premises, conclusion, derived,
                                dict(theta), results, idx + 1)

    def _match_pattern(self, pattern, fact, theta) -> bool:
        pat_tokens = pattern.split("(")
        if len(pat_tokens) != 2:
            return False
        pred, args_s = pat_tokens
        args = args_s.rstrip(")").split(",")
        fact_tokens = fact.split("(")
        if len(fact_tokens) != 2 or fact_tokens[0] != pred:
            return False
        fact_args = fact_tokens[1].rstrip(")").split(",")
        if len(args) != len(fact_args):
            return False
        for a, b in zip(args, fact_args):
            u = unify(a, b, theta)
            if u is None:
                return False
            theta.update(u)
        return True

    def _substitute(self, term, theta) -> str:
        if "(" not in term:
            return theta.get(term, term)
        head = term.split("(")[0]
        args = term.split("(")[1].rstrip(")").split(",")
        new_args = ",".join(theta.get(a.strip(), a.strip()) for a in args)
        return f"{head}({new_args})"


if __name__ == "__main__":
    kb = FOLReasoner()
    kb.add_fact("父(张三,李四)")
    kb.add_fact("父(李四,王五)")
    # 祖父(X,Z) :- 父(X,Y), 父(Y,Z)
    kb.add_rule(["父(x,y)", "父(y,z)"], "祖父(x,z)")
    # 人(X) :- 父(X,_)    （有孩子即为人）
    kb.add_rule(["父(x,y)"], "人(x)")

    result = kb.forward_chain()
    print("=== 一阶逻辑推理结果（Horn 前向链） ===")
    for f in result:
        print("  ", f)

    print("\n=== 解释 ===")
    print("1) 由 父(张三,李四) ∧ 父(李四,王五) → 祖父(张三,王五)")
    print("2) 由 父(张三,李四) → 人(张三)，由 父(李四,王五) → 人(李四)")

    print("\n=== 可视化建议 ===")
    print("1) networkx 把 父/祖父 关系画成有向图")
    print("2) 用 graphviz 画推理树，标注每条规则匹配的实例")
```

## 逻辑编程语言 Prolog 简介

**Prolog** 是基于**一阶逻辑 + 归结（SLD 归结）**的声明式编程语言，1960-70 年代由 Alain Colmerauer 与 Robert Kowalski 开发。

- **事实（Fact）**：`父(张三, 李四).`
- **规则（Rule）**：`祖父(X, Z) :- 父(X, Y), 父(Y, Z).`
- **查询（Query）**：`?- 祖父(张三, W).` → `W = 王五`

```
% family.pl
父(张三, 李四).
父(李四, 王五).
祖父(X, Z) :- 父(X, Y), 父(Y, Z).

?- 祖父(张三, W).
W = 王五.
```

Prolog 引擎自动完成**合一**、**回溯**与**深度优先搜索**，程序员只描述"是什么"而非"怎么做"。

## 现代意义：符号逻辑被大模型超越了吗？

| 维度 | 符号逻辑 | 大模型（联结主义） |
|------|----------|--------------------|
| 可解释性 | 强（证明树） | 弱（黑箱） |
| 严格性 | 精确、可验证 | 概率性、可能幻觉 |
| 知识来源 | 人工/知识库 | 海量语料学习 |
| 推理能力 | 形式化完备（一阶归结） | 常识强但易出错 |
| 扩展性 | 脆弱、依赖编码 | 泛化好、可迁移 |
| 规划 | STRIPS/POP 精确 | Agent 规划灵活但不可靠 |

**结论**：符号逻辑没有被"淘汰"，而是角色变了——

1. **思维链（Chain-of-Thought）**：让大模型"逐步推理"，本质是在**模拟逻辑推导的显式轨迹**，把隐含推理显式化。
2. **符号工具增强**：大模型调用求解器、规则引擎、Prolog/SMT 求解器完成精确计算，符号系统成为 LLM 的"外挂大脑"。
3. **神经符号推理（Neuro-Symbolic）**：用神经网络学习感知与常识，用符号逻辑保证推理正确性，是当前研究热点。
4. **AI Agent 规划**：Agent 的"思考—行动—观察"循环（ReAct、Plan-and-Execute），是自动规划思想在现代 LLM Agent 中的复活。

> 一句话：大模型解决了"看懂世界"，符号逻辑提供"严格推理"，二者正在走向融合。
