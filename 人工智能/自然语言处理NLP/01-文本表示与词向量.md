# 文本表示与词向量

> 计算机无法直接理解"汉字"，一切 NLP 任务的第一步都是**把文本变成向量**。本章完整走一遍文本表示的演进史：One-hot → TF-IDF → Word2Vec（CBOW / Skip-gram）→ GloVe → ELMo → BERT 上下文表示，并给出可运行的 Word2Vec 实现。

---

## 1. 为什么要"表示"文本？

任何机器学习模型都吃**数值**，所以必须把离散的语言符号映射为向量。这一映射的优劣直接决定任务上限：

- **表示需要保留语义**："苹果"和"水果"应接近，"苹果"和"香蕉"不应遥远。
- **表示需要可计算**：相似度、类比、加减都要在向量空间里成立。

文本表示的粒度从小到大：**词（token）→ 句子 → 篇章**。本章聚焦**词**的表示，它是一切的基础。

---

## 2. 表示演进总览

| 表示方法 | 类型 | 维度 | 是否含上下文 | 语义能力 |
|----------|------|------|:---:|------|
| One-hot | 离散/局部 | $V$（词表大小） | 否 | 无语义，正交 |
| TF-IDF | 离散/稀疏 | $V$ | 仅文档级统计 | 弱，词频权重 |
| Word2Vec（2013） | 稠密/静态 | 100–300 | 否（窗口内） | 强，词义与类比 |
| GloVe（2014） | 稠密/静态 | 100–300 | 否（共现统计） | 强，融合统计 |
| FastText（2016） | 稠密/静态 | 100–300 | 否 | 支持子词，OOV 友好 |
| ELMo（2018） | 稠密/**动态** | LSTM 隐状态 | ✅ 是 | 一词多义初见曙光 |
| BERT（2018） | 稠密/**动态** | 768+ | ✅ 双向 | 上下文表示，任务自适应 |

> 关键分水岭：**静态表示（Static）** 一个词无论出现在哪都只有一个向量；**上下文表示（Contextual）** 同一个词在不同句子中获得不同向量，从而解决**一词多义**。

---

## 3. 最早的表示：One-hot 与 TF-IDF

### 3.1 One-hot 独热编码

把每个词映射为 $\mathbb{R}^{V}$ 中的一个标准基向量：

$$
\mathbf{w}_i = \mathbf{e}_i = (0, \dots, 1, \dots, 0), \quad \text{第 } i \text{ 位为 } 1
$$

**致命缺点**：

- **维数灾难**：中文词表 $V \approx 10^5 \sim 10^6$，向量极度稀疏。
- **无语义**：任意两个不同词的内积为 0，$\langle \mathbf{e}_i, \mathbf{e}_j \rangle = \delta_{ij}$，"猫"和"狗"与"猫"和"苹果"没有任何区别。

### 3.2 TF-IDF

TF-IDF 仍是稀疏向量，但给每个维度加了**词频与稀有度**权重：

$$
\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \text{IDF}(t)
$$

- 词频（Term Frequency）：

$$
\text{TF}(t, d) = \frac{\text{词 } t \text{ 在文档 } d \text{ 中出现的次数}}{\text{文档 } d \text{ 的总词数}}
$$

- 逆文档频率（Inverse Document Frequency）：

$$
\text{IDF}(t) = \log \frac{N}{1 + \text{df}(t)}
$$

其中 $N$ 是文档总数，$\text{df}(t)$ 是包含词 $t$ 的文档数。**越稀有、越有区分力的词 IDF 越高**（"的""了"这类停用词 IDF 接近 0）。

- 优点：可解释、计算快，文本分类/检索的经典基线。
- 缺点：维度仍是 $V$、**不含词序与语义**、文档间相似度只靠词袋重叠。

> One-hot 与 TF-IDF 是**局部表示（local representation）**，Word2Vec 引入的是**分布式表示（distributed representation）**：每个词的语义分散在向量的多个维度上，维度可以很低。

## 4. Word2Vec：分布式表示的开端

### 4.1 核心思想

**分布假说（Distributional Hypothesis）**：

> 一个词的意义由其**上下文**决定——"You shall know a word by the company it keeps."（Firth, 1957）

Word2Vec（Mikolov et al., 2013）用一个**浅层神经网络**，从语料中学习每个词的稠密向量 $\mathbf{v} \in \mathbb{R}^{d}$（通常 $d=100\sim300$）。两种结构：

```
         CBOW：       上下文 → 预测中心词           Skip-gram：中心词 → 预测上下文
      w[t-2]                                       w[t-2]
      w[t-1]                                        w[t-1]
        ↘  sum/avg                                      ↘  (共享)
        [隐藏层] w[t] 预测目标词                        w[t]  → 预测 w[t+1], w[t+2], ...
        ↗                                          （两个方向）
      w[t+1]
      w[t+2]
```

### 4.2 CBOW 目标函数

给定中心词 $w_t$ 及其窗口上下文 $C = \{w_{t-c}, \dots, w_{t+c}\} \setminus \{w_t\}$（窗口半径 $c$），CBOW 用上下文的词向量**平均**预测中心词：

$$
\mathbf{h} = \frac{1}{2c} \sum_{w_j \in C} \mathbf{v}_{w_j}
$$

输出层对每个候选词 $w$ 计算打分，Softmax 得到概率：

$$
P(w_t \mid C) = \frac{\exp\left(\mathbf{u}_{w_t}^{\top} \mathbf{h}\right)}{\sum_{w \in V} \exp\left(\mathbf{u}_w^{\top} \mathbf{h}\right)}
$$

训练目标为最大化对数似然（等价于最小化负对数）：

$$
\mathcal{L}_{\text{CBOW}} = -\sum_{(C, w_t) \in \mathcal{D}} \log P(w_t \mid C)
$$

其中 $\mathbf{v}_w$ 是**输入向量**（第一层查表权重），$\mathbf{u}_w$ 是**输出向量**（输出层权重），两者是同一词的两种表示，常用最终向量 $\mathbf{v}_w + \mathbf{u}_w$ 或 $\mathbf{v}_w$。

### 4.3 Skip-gram 目标函数

Skip-gram 反过来：给定中心词 $w_t$，预测窗口内每个上下文词 $w_c$，且**每个上下文词独立**：

$$
P(w_c \mid w_t) = \frac{\exp\left(\mathbf{u}_{w_c}^{\top} \mathbf{v}_{w_t}\right)}{\sum_{w \in V} \exp\left(\mathbf{u}_w^{\top} \mathbf{v}_{w_t}\right)}
$$

$$
\mathcal{L}_{\text{SG}} = -\sum_{t=1}^{T} \sum_{c \in \text{window}(t)} \log P(w_c \mid w_t)
$$

**CBOW vs Skip-gram**：

- CBOW：训练快，对常见词平滑；适合小语料。
- Skip-gram：对**稀有词**更友好，能学到更细粒度语义，但训练更慢。

### 4.4 负采样（Negative Sampling）

Softmax 需要对整个词表 $V$（百万级）求和，不可行。负采样把"多分类"改造成"二分类判别"：中心词 $w_t$ 与上下文词 $w_c$ 配对是**正样本**，与随机采样的 $K$ 个噪声词 $w_k$ 配对是**负样本**。

对每个（中心词，上下文）对，目标函数：

$$
\mathcal{L}_{\text{NEG}} = - \log \sigma(\mathbf{u}_{w_c}^{\top} \mathbf{v}_{w_t})
                - \sum_{k=1}^{K} \log \sigma(-\mathbf{u}_{w_k}^{\top} \mathbf{v}_{w_t})
$$

其中 $\sigma(x) = \frac{1}{1+e^{-x}}$ 是 Sigmoid。第一项拉近正样本，第二项推远负样本。

负样本按**加权的 unigram 分布**采样，降低高频词被过度采样：

$$
P(w) \propto \frac{\text{cnt}(w)^{3/4}}{\sum_{w'} \text{cnt}(w')^{3/4}}
$$

取 $3/4$ 次幂是经验选择：既降低高频词，又不至于让低频词消失。

### 4.5 层次 Softmax（Hierarchical Softmax）

另一种加速方法：用一棵**霍夫曼树**（Huffman Tree）组织词表，每个词是叶子节点。从根到叶的路径上，每一步是二分类（左/右），不再对全词表 Softmax：

$$
P(w \mid \text{context}) = \prod_{j=1}^{L(w)-1} \sigma\left(\mathbf{1}\{\text{node}_j \to \text{left}\} \cdot \mathbf{v}_{n_j}^{\top} \mathbf{h}\right)
$$

其中 $L(w)$ 是词 $w$ 到根的路径长度。计算量从 $O(V)$ 降到 $O(\log V)$。

> **一句话**：负采样是把任务变成判别式二分类；层次 Softmax 是把树路径概率相乘。两者都为了绕开 $O(V)$ 的 Softmax 分母。

## 5. 词向量的使用

### 5.1 余弦相似度

两个词向量 $\mathbf{a}, \mathbf{b}$ 的相似度用**余弦**衡量（只关心方向，不关心模长）：

$$
\text{sim}(\mathbf{a}, \mathbf{b}) = \cos\theta = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \cdot \|\mathbf{b}\|}
= \frac{\sum_i a_i b_i}{\sqrt{\sum_i a_i^2}\sqrt{\sum_i b_i^2}}
$$

余弦值域 $[-1, 1]$，越大越相似。"苹果"与"香蕉"相似度高，"苹果"与"卷积"相似度低。

### 5.2 词类比（Analogy）

词向量最惊艳的性质是**语义方向的线性可加性**：

$$
\mathbf{v}_{\text{king}} - \mathbf{v}_{\text{man}} + \mathbf{v}_{\text{woman}} \approx \mathbf{v}_{\text{queen}}
$$

即"皇室的性别差异方向" $\mathbf{v}_{\text{man}} - \mathbf{v}_{\text{woman}}$ 是稳定的。其他经典类比：

```
北京 - 中国 + 日本 ≈ 东京
Paris - France + Italy ≈ Rome
```

求解类比问题：在词表中找 $\arg\max_w \cos(\mathbf{v}_w,\ \mathbf{v}_{\text{king}} - \mathbf{v}_{\text{man}} + \mathbf{v}_{\text{woman}})$。

> 注意：类比性质是**经验现象**而非严格定理，且会继承语料偏见（如性别刻板印象），实际应用中要谨慎。

### 5.3 词向量可视化

把 300 维词向量用 **t-SNE / PCA** 降到 2D 后点图，语义相近的词自然聚在一起（技术细节见 [[../机器学习教程/07-降维|降维]]）：

```python
from sklearn.manifold import TSNE
import matplotlib.pyplot as plt

def plot_words(model, words):
    vecs  = [model.wv[w] for w in words]
    xy    = TSNE(n_components=2, perplexity=10, random_state=42).fit_transform(vecs)
    for w, (x, y) in zip(words, xy):
        plt.scatter(x, y); plt.annotate(w, (x, y))
    plt.axis("off"); plt.show()
```

## 6. GloVe：融合共现统计

Word2Vec 只利用窗口内上下文；GloVe（Global Vectors, 2014）**显式利用全语料的共现矩阵**。记 $X_{ij}$ 为词 $j$ 在词 $i$ 上下文中出现的次数。GloVe 的目标函数：

$$
\mathcal{L}_{\text{GloVe}} = \sum_{i,j=1}^{V} f(X_{ij}) \left(\mathbf{v}_i^{\top} \tilde{\mathbf{v}}_j + b_i + \tilde{b}_j - \log X_{ij}\right)^2
$$

权重函数 $f$ 截断高频、保留中频：

$$
f(x) = \begin{cases}
(x/x_{\max})^{3/4}, & x < x_{\max} \\
1, & \text{otherwise}
\end{cases}
$$

**直觉**：$\mathbf{v}_i^{\top}\tilde{\mathbf{v}}_j$ 近似 $\log X_{ij}$，即让两个向量的内积直接编码共现频次的对数。相比 Word2Vec，GloVe 训练更快、对高频词更稳，但效果总体相当。

---

## 7. ELMo：第一个上下文表示

Word2Vec/GloVe 是**静态**向量："bank"只有一个向量，无法区分"river bank"和"bank account"。ELMo（Embeddings from Language Models, 2018）用**双向 LSTM 语言模型**，对每个词在不同句子中生成**动态表示**：

$$
\text{ELMo}(w_t) = \gamma \sum_{k} s_k \mathbf{h}_t^{(k)}
$$

即所有 LSTM 层的隐藏状态 $\mathbf{h}_t^{(k)}$ 的加权平均，权重 $s_k$ 由任务学习。底层 LSTM 编码**句法**信息，高层编码**语义**信息，一词多义问题首次被系统解决。

> ELMo 的意义：把"预训练语言模型 + 动态表示"引入主流，是 BERT 的直接前身。

---

## 8. BERT：双向上下文表示

ELMo 是"两个单向 LSTM 拼接"，BERT（2018）用 **Transformer 双向编码器**一次看到完整句子，靠 **Masked Language Model（MLM）** 预训练：

随机 mask 掉 15% 的 token，让模型只凭上下文重建它们：

$$
\mathcal{L}_{\text{MLM}} = -\sum_{t \in \text{masked}} \log P_\theta(w_t \mid \text{完整句子去掉} w_t)
$$

BERT 输出每个位置的**上下文表示**，直接用 softmax 接各类任务头即可做分类/序列标注/问答，即"预训练 + 微调"范式（架构细节见 [[../深度学习教程/12-Transformer与大模型|Transformer]]）。

> **表示能力的三个台阶**：静态（Word2Vec，一个词一个向量）→ 上下文（ELMo，同词不同向量）→ 通用预训练（BERT，可微调适配所有任务）。大模型的 tokenizer 与隐藏表示本质上仍是"词向量"的升级版。

---

## 9. 子词嵌入：FastText 与 BPE

### 9.1 FastText：单词拆成字符 n-gram

FastText（2016）把每个词表示为它内部的**字符 n-gram 向量之和**。词 "where"（n=3）：

```
whw, whe, her, ere, rew, <wh, where>...
\mathbf{v}_{\text{where}} = \sum_{g \in \text{ngrams}} \mathbf{v}_g
```

- 好处 1：**子词共享**，"watch"与"watches"共享大量 n-gram。
- 好处 2：**OOV（未登录词）可解**：生词也能用其 n-gram 向量合成，不再是无向量词。
- 好处 3：对形态丰富的语言（德语、俄语、中文多字词）特别有效。

### 9.2 BPE：数据驱动的子词切分

Word2Vec/FastText 的粒度仍是"词"。而现代大模型用 **BPE（Byte Pair Encoding）** 把文本切成**子词（subword）**，直接缓解 OOV：

**BPE 算法**（迭代合并最高频字符对）：

1. 初始：语料中的每个字符是一个 token，统计相邻对频率。
2. 合并频率最高的一对（如 `e` + `n` → `en`），加入词表。
3. 重复直到词表达到预定大小（如 32k–256k）。

词表由"常见词整体 + 少见词拆分子词"组成：

```
"low"    → "low"         （常见，整体保留）
"lowest" → "low" + "est" （子词拆解）
```

- GPT 系用 BPE；BERT 用 WordPiece（类似 BPE，按概率合并）。
- 中文没有天然词边界，BPE 通常从**字/字节**开始合并，模型天然学会了"字符 → 词"的切分。
- 细节与代码见 [[../大模型与生成式AI/01-大语言模型原理|LLM 原理]] 的 tokenizer 章节。

> 路线图总结：**词粒度（Word2Vec）→ 字符子词粒度（FastText）→ 数据驱动子词粒度（BPE）**。表示单元不断细化，鲁棒性不断上升。

## 10. 动手实现：Word2Vec

### 10.1 用 gensim 训练（最快）

```python
# pip install gensim jieba
from gensim.models import Word2Vec
import jieba

corpus = [
    "我喜欢自然语言处理",
    "机器学习和深度学习是人工智能的分支",
    "词向量让机器理解词的语义",
    "自然语言处理包括分词和词性标注",
    "深度学习需要大量的数据和算力",
]
sentences = [jieba.lcut(s) for s in corpus]

model = Word2Vec(sentences, vector_size=100, window=3, min_count=1,
                 sg=1,        # 1 = Skip-gram，0 = CBOW
                 negative=5,  # 负采样数量
                 epochs=20)
model.wv["自然语言处理"]
model.wv.similarity("机器学习", "深度学习")
model.wv.most_similar("分词", topn=5)
model.wv.most_similar(positive=["机器", "学习"], topn=3)
```

`model.wv` 提供了 `similarity`、`most_similar`、`analogy` 等封装；换英文语料时只需把 `jieba.lcut` 换成 `sentence.split()`。

### 10.2 用 PyTorch 手写 Skip-gram（最小实现）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import Dataset, DataLoader

class SGNS(nn.Module):
    """Skip-gram with Negative Sampling (SGNS)"""
    def __init__(self, vocab_size, emb_dim):
        super().__init__()
        self.in_emb  = nn.Embedding(vocab_size, emb_dim)   # 中心词向量 v
        self.out_emb = nn.Embedding(vocab_size, emb_dim)   # 上下文词向量 u

    def forward(self, center, context, negatives):
        # center: [B], context: [B], negatives: [B, K]
        v_c = self.in_emb(center)                                  # [B, d]
        u_w = self.out_emb(context)                                # [B, d]
        u_n = self.out_emb(negatives)                              # [B, K, d]

        pos = torch.log(torch.sigmoid((v_c * u_w).sum(dim=1)))     # [B]
        neg = torch.log(torch.sigmoid(-torch.einsum(
              "bd,bkd->bk", v_c, u_n))).sum(dim=1)                 # [B]
        return -(pos + neg).mean()

def sample_negatives(vocab_size, num_neg, counts, batch_size):
    # 按 counts^{0.75} 加权采样 K 个负样本
    probs = torch.tensor(counts, dtype=torch.float).pow(0.75)
    probs = probs / probs.sum()
    return torch.multinomial(probs, num_samples=batch_size * num_neg,
                             replacement=True).view(batch_size, num_neg)

# 使用示例（batch 构造：对每个中心词采样窗口内上下文词）
model = SGNS(vocab_size=10000, emb_dim=100)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
for center, ctx, neg in dataloader:            # 自定义 Dataset 提供这三者
    loss = model(center, ctx, neg)
    optimizer.zero_grad(); loss.backward(); optimizer.step()
```

上面第 4 节的负采样损失在代码中一一对应：`pos` 项 $\log\sigma(\mathbf{u}_{w_c}^\top\mathbf{v}_{w_t})$，`neg` 项 $\sum_k \log\sigma(-\mathbf{u}_{w_k}^\top\mathbf{v}_{w_t})$。

### 10.3 numpy 简单版（直觉演示）

仅用 numpy 实现负采样更新的最小循环（演示核心，工程上用 gensim/PyTorch）：

```python
import numpy as np

def train_sgns(pairs, vocab, counts, d=50, lr=0.05, K=5, iters=1000):
    V = len(vocab)
    vin, vout = np.random.randn(V, d) * 0.1, np.random.randn(V, d) * 0.1
    p = counts ** 0.75 / (counts ** 0.75).sum()
    for _ in range(iters):
        w, c = pairs[np.random.randint(len(pairs))]        # 中心词, 上下文
        neg = np.random.choice(V, size=K, p=p)
        e_in, e_out = np.zeros(d), np.zeros(d)
        for u in np.concatenate([[c], neg]):
            s = 1 if u == c else 0
            g = (sigmoid(vin[w] @ vout[u]) - s) * vout[u]
            e_in += g
            vout[u] -= lr * (sigmoid(vin[w] @ vout[u]) - s) * vin[w]
        vin[w] -= lr * e_in
    return vin
```

> 工程建议：中小实验用 `gensim`，自定义损失/大规模用 PyTorch，理解算法用 numpy 版。
