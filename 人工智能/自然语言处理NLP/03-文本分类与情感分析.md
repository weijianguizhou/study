# 文本分类与情感分析

> 文本分类是 NLP 最成熟、最常用的任务：垃圾邮件、情感分析、意图识别、主题分类都是它的实例。本章从朴素贝叶斯讲起，经过 TF-IDF + 线性模型、深度 CNN/RNN/Transformer，给出一个完整可运行的 sklearn 情感分类实战，并讲清评估指标。

---

## 1. 文本分类任务定义

### 1.1 形式化

输入文本 $s$，输出 $K$ 个类别之一：

$$
\hat{y} = \arg\max_{k \in \{1,\dots,K\}} P(y = k \mid s)
$$

分类对象可以是词/句子/段落/整篇文档，对应粒度不同。本质上就是"文本表示 + 分类器"：

```
文本 → 表示（TF-IDF / 词向量 / 预训练）→ 分类器（NB / SVM / 网络）→ 标签
```

### 1.2 常见任务

| 任务 | 类别示例 | 输出粒度 |
|------|----------|----------|
| 垃圾邮件过滤 | 垃圾/正常 | 二分类 |
| **情感分析** | 正面/负面/中性 | 二或三分类（或多类如 1–5 星） |
| 新闻主题分类 | 体育/财经/科技…… | 多分类 |
| 意图识别 | 订票/查天气/闲聊 | 多分类（对话系统） |
| 关系分类 | 是/否/未知 | 二分类 |
| 多标签分类 | 多个标签可同时成立 | 多标签 |

## 2. 朴素贝叶斯（Naive Bayes）

### 2.1 原理

用贝叶斯定理求后验概率（理论见 [[../机器学习教程/02-最近邻与朴素贝叶斯|朴素贝叶斯]]）：

$$
P(y \mid s) = \frac{P(s \mid y) P(y)}{P(s)}
$$

分类取后验最大的类（由于 $P(s)$ 与 $y$ 无关，可省略）：

$$
\hat{y} = \arg\max_y P(y) \prod_{t=1}^{n} P(x_t \mid y)
$$

这里用到了**朴素假设**：给定类别 $y$，文本中的各个词**条件独立**（词袋模型，忽略词序）。于是联合概率分解成词概率的乘积。

### 2.2 平滑处理

某个词在某类中没出现过会导致概率为 0，需要 **Laplace 平滑**：

$$
P(x_t \mid y) = \frac{\text{count}(x_t, y) + \alpha}{\sum_{x'} \text{count}(x', y) + \alpha |V|}
$$

- 多项式朴素贝叶斯（MultinomialNB）：直接对上式建模，文本分类的默认选择。
- 伯努利朴素贝叶斯：只考虑"词是否出现"而非频次。

### 2.3 优缺

- 优点：训练**极快**、参数少、小样本也能用、结果可解释（每个词的贡献是乘性项）。
- 缺点：朴素假设过于天真——词并不独立（"不"+"好吃"强相关）；对复杂语义无能为力。

> 实践要点：为防下溢，实际实现把连乘取对数：$\log P(y) + \sum_t \log P(x_t \mid y)$，与 MLE 目标一致。

## 3. TF-IDF + 线性模型

### 3.1 流程

1. 分词 + 去停用词 → 词袋/ngram。
2. 用 TF-IDF 加权（公式见 [[01-文本表示与词向量|01 文本表示]]）：

$$
\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \log \frac{N}{1 + \text{df}(t)}
$$

3. 训练线性分类器：Logistic 回归 / SVM（LinearSVC）/ 朴素贝叶斯。

### 3.2 为什么线性模型往往够用

文本特征**稀疏但维度高**，绝大多数任务在高维稀疏空间里**近似线性可分**。Logistic/SVM 在 TF-IDF 上常常强于浅层非线性模型：

$$
P(y \mid \mathbf{w}, \mathbf{x}) = \text{softmax}(\mathbf{W}\mathbf{x} + \mathbf{b})
$$

这构成了"工业界基线上限"：**先跑 TF-IDF + LinearSVC，再决定是否需要深度模型**。

### 3.3 TF-IDF + 线性模型的局限

- 词袋丢词序："不 好"和"好 不"一样；"not bad"丢失否定信息。
- 无法建模"一词多义"（静态权重）。
- 长距离依赖（"虽然……但是……"）无能为力。

## 4. 深度学习方案

### 4.1 TextCNN

把句子看成一维信号，用多个卷积核提取 n-gram 特征，再全局池化 + 全连接：

```
[词向量序列] → Conv1D(核宽 k=2,3,4 各若干) → 最大池化 → 拼接 → Softmax
```

- 优点：参数少、训练快、能捕捉局部 n-gram 组合（如"不 好"）。
- 结构细节见 [[../深度学习教程/09-卷积神经网络CNN|CNN]]。

### 4.2 RNN/LSTM

把句子按顺序过 BiLSTM，取最后状态（或注意力加权）作为句向量，再接分类头：

```
[词向量序列] → BiLSTM → 池化/最后时刻 → Softmax
```

- 优点：天然建模词序与长程依赖。
- 缺点：训练比 CNN 慢、难并行。细节见 [[../深度学习教程/11-RNN与LSTM|RNN/LSTM]]。

### 4.3 Transformer / 预训练模型

微调 BERT 类模型是当前 SOTA：用 `[CLS]` 位置的输出接分类头。

$$
P(y \mid s) = \text{softmax}\left(\mathbf{W}\,\text{BERT}(s)_{\text{[CLS]}} + \mathbf{b}\right)
$$

- 优点：上下文表示、迁移学习、小数据也能有好效果。
- 缺点：需要 GPU、推理慢、成本高。架构见 [[../深度学习教程/12-Transformer与大模型|Transformer]]，微调见 [[../大模型与生成式AI/03-微调|微调]]。

### 4.4 LLM 时代的情感分类

用大模型做分类是 2023 年后的主流捷径：**零样本/少样本提示**即可完成任务，无需训练数据。

- 直接问："判断下面评论的情感（正面/负面）：……"
- 结构化输出（JSON）便于程序消费。
- 局限：成本、延迟、一致性（temperature>0 时可能抖动）。

详见 [[../大模型与生成式AI/02-提示工程|提示工程]] 中的分类用例。

## 5. 情感分析应用场景

**情感分析（Sentiment Analysis / Opinion Mining）** 是文本分类最重要的商业落地：

| 场景 | 数据 | 目标 |
|------|------|------|
| 电商评论 | 商品评论 | 满意度、差评预警 |
| 舆情监控 | 微博/新闻 | 品牌口碑、危机公关 |
| 金融 | 股吧帖子/研报 | 市场情绪指标、量化信号 |
| 影视 | 影评 | 票房预测、推荐 |
| 客服 | 用户反馈工单 | 满意度分、投诉分级 |
| 对话产品 | 用户输入 | 情感跟随（共情回复） |

> 工程上常见进阶：**方面级情感分析（Aspect-based）**——"手机屏幕好但电池差"中"屏幕"正面、"电池"负面，需要**多分类 + 序列标注**结合。

## 6. 完整 sklearn 实战（中文评论情感分类）

> 依赖：`pip install scikit-learn jieba`。本例用中文商品评论，可换成任意英文数据（把分词换成 `split()`）。

```python
import jieba
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.linear_model import LogisticRegression
from sklearn.svm import LinearSVC
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import accuracy_score, f1_score, confusion_matrix, classification_report
import numpy as np

# ---------- 1. 构造小数据集（真实使用请换成自己的 csv） ----------
texts = [
    "这个手机屏幕清晰，手感很好，非常满意",
    "物流很快，包装完好，值得回购",
    "性价比很高，做工精致，推荐购买",
    "质量一般，用几天就出问题，不推荐",
    "客服态度差，售后也不理人，差评",
    "续航太短了，充电还慢，很失望",
]
labels = [1, 1, 1, 0, 0, 0]           # 1=正面, 0=负面

# ---------- 2. 中文分词 ----------
def cut(s):
    return " ".join(jieba.cut(s))     # 空格连接便于向量化

X = [cut(t) for t in texts]
print("分词结果：", X[0])             # 这个 手机 屏幕 清晰 ， 手感 很好 ， 非常 满意

# ---------- 3. TF-IDF 向量化 ----------
vec = TfidfVectorizer(ngram_range=(1, 2), min_df=1)
X_vec = vec.fit_transform(X)          # 稀疏矩阵
print("特征维度:", X_vec.shape[1])

# ---------- 4. 训练集/测试集（数据小，用交叉验证代替） ----------
X_train, X_test, y_train, y_test = train_test_split(
    X_vec, labels, test_size=0.33, random_state=42, stratify=labels)

# ---------- 5. 朴素贝叶斯 ----------
nb = MultinomialNB(alpha=1.0)
nb.fit(X_train, y_train)
y_pred_nb = nb.predict(X_test)

# ---------- 6. 对比：线性 SVM ----------
svm = LinearSVC()
svm.fit(X_train, y_train)
y_pred_svm = svm.predict(X_test)

# ---------- 7. 评估 ----------
print("朴素贝叶斯 准确率: {:.2f}".format(accuracy_score(y_test, y_pred_nb)))
print("LinearSVC   准确率: {:.2f}".format(accuracy_score(y_test, y_pred_svm)))

# 交叉验证估计泛化能力（更可信）
cv_scores = cross_val_score(LinearSVC(), X_vec, labels, cv=3, scoring="f1")
print("LinearSVC 3折F1: {:.2f} ± {:.2f}".format(cv_scores.mean(), cv_scores.std()))

# 混淆矩阵与分类报告
print(confusion_matrix(y_test, y_pred_nb))
print(classification_report(y_test, y_pred_nb, target_names=["负面", "正面"]))
```

**预测新评论**：

```python
new = cut("这款耳机降噪效果一流，音质很棒，强烈推荐")
print("预测为正面" if svm.predict(vec.transform([new]))[0] == 1 else "预测为负面")
```

> 小数据上结论仅供参考；数据量放大后，线性 SVM 通常稳定优于朴素贝叶斯，两者都明显弱于微调后的 BERT。

## 7. 深度学习版本（PyTorch 简版）

用 torch 文本工具快速搭 TextCNN（结构见 [[../深度学习教程/09-卷积神经网络CNN|CNN]]）：

```python
import torch
import torch.nn as nn

class TextCNN(nn.Module):
    def __init__(self, vocab_size, emb_dim=100, n_filters=128, num_classes=2):
        super().__init__()
        self.emb = nn.Embedding(vocab_size, emb_dim, padding_idx=0)
        self.convs = nn.ModuleList([
            nn.Conv1d(emb_dim, n_filters, k, padding=k // 2) for k in (2, 3, 4)
        ])
        self.fc = nn.Linear(n_filters * 3, num_classes)

    def forward(self, x):                       # x: [B, L] 词 id
        e = self.emb(x).transpose(1, 2)         # [B, d, L]
        pooled = [torch.relu(c(e)).max(dim=2).values for c in self.convs]
        out = torch.cat(pooled, dim=1)          # [B, 3*n_filters]
        return self.fc(out)
```

训练循环、`nn.CrossEntropyLoss`、DataLoader 与 [[../深度学习教程/06-PyTorch入门|PyTorch 入门]] 一致；序列模型可把 `convs` 换成 `nn.LSTM(bidirectional=True)`。

## 8. 评估指标

分类模型不能只看准确率，尤其是**类别不平衡**时（差评通常只占少数）。

### 8.1 混淆矩阵

|  | 预测正 | 预测负 |
|--|--------|--------|
| **实际正** | TP（真阳） | FN（假阴） |
| **实际负** | FP（假阳） | TN（真阴） |

### 8.2 核心指标

**准确率（Accuracy）**：

$$
\text{Acc} = \frac{TP + TN}{TP + TN + FP + FN}
$$

**精确率（Precision）**——预测为正里有多少真为正：

$$
P = \frac{TP}{TP + FP}
$$

**召回率（Recall）**——真正例里被找出多少：

$$
R = \frac{TP}{TP + FN}
$$

**F1 分数**——两者的调和平均：

$$
F_1 = \frac{2PR}{P + R}
$$

**宏平均/加权平均**：多分类时，`macro` 先算每类 F1 再平均（对少数类敏感），`weighted` 按样本量加权（实际最常用）。

> 行业经验：情感分类关注 F1（特别是差评类的 Recall——漏掉差评比误伤好评更危险）；垃圾邮件过滤关注 Precision（误杀正常邮件代价高）。选择指标本质是选择"哪类错误的代价更大"。

### 8.3 阈值与 ROC

输出概率分类器可通过调整**阈值**权衡 P/R，绘制 **PR 曲线 / ROC 曲线**，用 AUC 作为与阈值无关的整体度量。

## 9. 小结：怎么选方案

| 方案 | 数据量 | 效果 | 速度 | 场景 |
|------|--------|------|------|------|
| 朴素贝叶斯 + TF-IDF | 小 | 基线 | 秒级 | 快速原型 |
| LinearSVC + TF-IDF | 中 | 稳 | 分钟级 | 工业基线 |
| TextCNN | 中 | 较好 | 快 | 需要低延迟 |
| BiLSTM | 中 | 较好 | 慢 | 强调词序 |
| 微调 BERT | 中–大 | SOTA | 慢 | 效果优先 |
| 大模型提示 | 无需标注 | 优（中文也稳） | 取决于 API | 快速上线、少数据 |

**推荐路径**：TF-IDF 基线上线 → 数据积累 → 需要提升再上 BERT → 预算/延迟敏感用蒸馏模型。
