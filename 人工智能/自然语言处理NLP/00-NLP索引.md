# 自然语言处理（NLP）· 索引

> 自然语言处理（Natural Language Processing, NLP）是让机器理解、生成和处理人类语言的学科。它横跨语言学、计算机科学与机器学习，是深度学习时代最重要的落地领域之一：从搜索引擎、输入法，到机器翻译、对话机器人、大语言模型，底层都是 NLP 技术。

---

## 1. NLP 是什么

### 1.1 定义

**NLP（Natural Language Processing）** = 用计算方法研究语言的结构与规律，让计算机能够**理解（understand）**、**生成（generate）** 和 **处理（process）** 自然语言（中文、英文、日文……）。

NLP 的完整链条可以概括为：

```
语言现象（语料）
  → 语言表示（分词、词向量、句法树）
  → 语言模型（概率模型、神经网络）
  → 任务系统（分类、翻译、对话……）
  → 评估（BLEU、F1、准确率……）
```

### 1.2 语言数据的特殊性

与图像、表格数据相比，语言数据有三个根本难点：

| 特性 | 说明 | 例子 |
|------|------|------|
| **离散与稀疏** | 词汇是离散符号，组合空间巨大（$V$ 个词有 $V^n$ 种句子） | "苹果"≠"果苹" |
| **结构层次化** | 词 → 短语 → 从句 → 句子 → 篇章，层层组合 | 递归句法树 |
| **歧义与长尾** | 一词多义、结构歧义、省略与指代 | "他在打乒乓球" vs "他在打手机" |

### 1.3 为什么 NLP 难（乔姆斯基 vs 统计派之争）

- **规则派**（Chomsky，1950s）：认为语言是递归生成的形式系统，主张用语法规则解析语言。
- **统计派**（1950s–2010s）：认为语言行为可以概率建模，"语言就是概率分布"。马尔可夫模型、HMM、n-gram 皆属此类。
- **神经派**（2013–）：用分布式表示（词向量）+ 深度网络自动学习特征，不再手工设计规则与特征。
- **大模型派**（2018–）：预训练 + 缩放，语言能力从"任务建模"走向"通用能力"。

> 这四种范式在本目录中都能找到对应章节，它们不是互相取代，而是层层叠加。

## 2. 任务全景

NLP 任务可按**输出形态**分为五大类：

### 2.1 文本分类

输入一段文本，输出**一个标签**（类别）。

$$
\text{classify}(s) \in \{c_1, c_2, \dots, c_K\}
$$

典型任务：情感分析、垃圾邮件检测、主题分类、意图识别。→ 详见 `03-文本分类与情感分析.md`

### 2.2 序列标注

输入一个词序列，输出**等长的标签序列**，即对每个词打一个标签。

$$
\text{tag}(w_1 w_2 \cdots w_n) = (t_1, t_2, \dots, t_n)
$$

典型任务：中文分词（B/I/E 标注）、词性标注（POS）、命名实体识别（NER）、槽位填充。→ 详见 `02-序列标注与HMM.md`

### 2.3 文本生成

输入一段文本（或一个前缀），输出**新生成的文本**。

$$
\text{gen}(s_{<t}) \rightarrow s_t,\quad P(s_t \mid s_{<t})
$$

典型任务：摘要、写作辅助、对话回复、代码生成。现代生成模型本质都是**自回归语言模型**（下一个词预测），见 [[../大模型与生成式AI/01-大语言模型原理|LLM 原理]]。

### 2.4 机器翻译（MT）

把源语言句子映射为目标语言句子，是**序列到序列（Seq2Seq）**的典型问题。

$$
\text{MT}(\text{英文句子}) \rightarrow \text{中文句子}
$$

从统计机器翻译（SMT，phrase-based）到神经机器翻译（NMT，attention-based），再到大规模多语模型（GPT、Whisper），翻译是 NLP 最重要的"试金石"之一。

### 2.5 问答与对话

输入是"问题 + 上下文"，输出是"答案"。

- **抽取式问答**：从文档中圈出答案片段（BERT 系）。
- **生成式问答**：用 LLM 直接生成答案（GPT 系）。
- **检索式问答 / RAG**：先检索后生成，见 [[../大模型与生成式AI/04-RAG检索增强生成|RAG]]。

### 2.6 其他任务

句法分析（依存树/成分树）、指代消解（"他"指谁）、文本相似度/复述、信息抽取（关系抽取）、文本纠错、语音与文本的跨模态（见 [[../语音识别/01-语音识别与语音合成|语音识别]]）。

> **一句话总览**：分类给出"一个答案"，序列标注给出"一列答案"，生成给出"一段文本"，翻译与问答是前者的组合应用。几乎所有 NLP 任务都可以归入这四种输出形态。

## 3. 演进路线

### 3.1 统计 NLP 时代（1950s – 2010s）

核心思想：**用概率给语言建模**。

- **n-gram 语言模型**：第 $t$ 个词只依赖前 $n-1$ 个词：

$$
P(w_1 w_2 \cdots w_m) = \prod_{t=1}^{m} P(w_t \mid w_{t-1}, \dots, w_{t-n+1})
$$

- **HMM / 最大熵 / CRF**：解决分词、词性标注、NER 等序列标注问题（见 `02`）。
- **TF-IDF / BM25**：把文本变成稀疏向量，配合 SVM、朴素贝叶斯做分类（见 `01`、`03`）。
- 代表工作：IBM Model（机器翻译）、Jelinek（统计语言模型）、Blei（LDA 主题模型）。

特点：**可解释、数据需求中等，但特征工程繁重**，且无法建模长距离依赖。

### 3.2 深度学习时代（2013 – 2018）

核心思想：**把词映射为稠密向量，用神经网络端到端学习**。

- **2013 Word2Vec**：分布式表示（distributed representation），词向量开始大规模应用（见 `01`）。
- **2014 Seq2Seq + Attention**：机器翻译范式革新，[[../深度学习教程/11-RNN与LSTM|RNN/LSTM]] 成为序列建模主力。
- **2017 Transformer**：Self-Attention 取代 RNN，成为之后一切大模型的底座（见 [[../深度学习教程/12-Transformer与大模型|Transformer]]）。
- **2018 ELMo / GPT / BERT**：预训练 + 微调（Pretrain-Finetune）范式确立，NLP 进入"第二人生"。

### 3.3 预训练语言模型时代（2018 – 2022）

- **BERT**（双向编码器）：适合理解类任务（分类、序列标注、问答）。
- **GPT**（自回归解码器）：适合生成类任务，规模一路放大。
- 核心公式（MLM 目标）：

$$
\mathcal{L}_{\text{MLM}} = -\sum_{x \in \text{被mask的位置}} \log P_\theta(x \mid \text{上下文})
$$

### 3.4 大模型时代（2020s）

- **2020 GPT-3**：175B 参数，涌现出 **上下文学习（In-Context Learning）**：不改参数，给几个示例就能学会新任务。
- **2022 ChatGPT**：RLHF 对齐（人类反馈强化学习），模型学会"有用、无害、诚实"。
- **2023 – 2025**：指令微调（InstructGPT）、思维链（CoT）、MoE 稀疏架构（DeepSeek-V3/R1）、多模态统一（GPT-4o、Qwen-VL、Whisper）。

> 详见 [[../大模型与生成式AI/00-大模型索引|大模型索引]]。NLP 的主战场已从"为每个任务训练模型"转向"用一个大模型适配所有任务"。

### 3.5 演进时间线速览

```
1950s 规则 NLP（符号主义）──► 1990s 统计 NLP（n-gram / HMM / CRF）
──► 2013 Word2Vec 分布式表示 ──► 2017 Transformer / 2018 BERT·GPT 预训练范式
──► 2020 GPT-3 上下文学习 ──► 2022 ChatGPT 对齐 ──► 2023+ 多模态 / Agent / 推理链
```

## 5. 中文 NLP 的特殊性

### 5.1 分词：中文 NLP 的第一道坎

英文以**空格**为天然词边界（word token），而中文是**连续书写**的，词与词之间没有空格：

```
英文： I   love   natural   language   processing
中文： 我 喜欢 自然 语言 处理       ← 需要程序切分
```

**分词（Segmentation）** 就是把连续的汉字序列切分成词序列。它看似简单，实则充满歧义：

| 歧义类型 | 例子 | 正确切分 |
|----------|------|----------|
| 交集型歧义 | "研究生命科学" | 研究 / 生命 / 科学（而非 研究/生命/科学…的其它切分） |
| 组合型歧义 | "北京大学" | 可整体作一词，也可切为 北京/大学 |
| 未登录词（OOV） | "GPT-4o"、"王者荣耀" | 词典外的新词、专名 |

中文分词的三种主流做法：

1. **词典 + 规则**：最大匹配（Forward/Backward Maximum Matching）、最短路径分词。速度快，依赖词典，OOV 差。
2. **统计方法**：把分词建模为**序列标注**问题（B/M/E/S 标注），用 HMM/CRF 求解（见 `02`）。
3. **深度学习/大模型**：BERT 等模型内置 WordPiece/BPE tokenizer，模型在字/子词级别工作，分词"隐藏"在 tokenizer 内部（见 `01` 的 BPE 小节）。

> 实践经验：中文任务默认按**字（char）**或**子词**建模往往比按"词典词"更鲁棒——OOV 更少，模型自由度更高。这直接导致了 `01` 中 BPE/WordPiece 的兴起。

### 5.2 中文的其他特殊性

- **无形态变化**：中文没有英文的时态/单复数/格变化，句法信息主要靠词序和虚词。
- **简繁/异体字**：简体、繁体、异体字需归一化处理。
- **口语与网络语**："yyds""栓Q""绝绝子"等新词高频迭代，OOV 压力远大于英文。
- **标点与单位**：中文标点全角、数字/英文/中文混排，预处理更繁琐。
